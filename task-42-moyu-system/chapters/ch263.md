# 第263章 七年的代价

暖光笼罩的瞬间，林一凡闻到了麻辣烫的香气。

不是那种工业底料的廉价味道，是骨汤熬足六个小时、混着干辣椒和花椒的厚重香气。他低头，看见自己穿着一件洗得发白的羽绒服，袖口磨出了毛边。对面是一张油腻的塑料桌，桌面上摆着一碗红油翻滚的麻辣烫，旁边放着一部屏幕碎了一半的旧手机。

手机屏幕亮着，显示时间是2019年12月31日，晚上九点四十七分。

林一凡的呼吸停了一拍。他记得这一天。那晚他刚从星辰科技的面试楼出来，兜里只剩四十三块钱，在这家叫“老马麻辣烫”的小店里点了最便宜的一碗。手机里是父亲发来的微信，问他要不要回家过年。

“小伙子，电话响了。”

店老板的声音从柜台后面传来。林一凡猛地抬头，看见墙上挂着的塑料钟表——2019年12月31日，晚上九点四十七分。他伸手摸向口袋，那里有一张皱巴巴的纸条，纸条上的字迹已经被汗水浸透了一半，但依稀可辨：“如果你想换回那七年，踏进这道门。代价是你永远失去见到他的权利。小九字。”

“小九。”林一凡喃喃念出这个名字。那个自称是他妹妹的女孩，那个在负三层密室门口递出纸条的人。她的手背上有一道旧疤，像被什么东西割伤过。

手机突然震动起来。是一条没备注号码的短信：“别回头看。往前走，他还在等你。”

林一凡攥紧手机，站起身。店老板抬头看了他一眼：“不吃完？这碗可是你点的，十五块，不能退。”

“先放着。”他说，迈步往店后的走廊走去。这条走廊他从来没走过——记忆中这家麻辣烫店只有一间堂食和一个后厨，根本没有走廊。可现在，走廊尽头有一扇门，门缝透出冷白色的光，像是手术室那种。

他推开那扇门。

白光刺目的瞬间，林一凡看见了一个他做梦都想不到的画面——

自己躺在床上。准确地说，是2026年的自己，躺在星辰科技负三层密室里的那张行军床上。病床旁边摆着一台心电监护仪，一个人坐在床边，背对着他。那人穿着深灰色的呢子大衣，头发花白，脊背微微佝偻，像是坐了太久太久的姿势。

“你来了。”那个人的声音沙哑，但林一凡认得——那是陈重阳的声音，只是比他在密室纸条上感受到的还要苍老，仿佛每说一个字都在消耗着某种不可逆的东西。

“你——”林一凡的喉咙像是被什么堵住了，“你不是已经……”

“只剩下最后七年记忆的人，总要选一件事做。”陈重阳转过头。他的脸比林一凡想象中年轻得多——最多三十岁出头，眉眼锋利，嘴角带着一丝疲惫的笑意。可他的眼睛却像一口枯井，深得让人心慌。“我选了等你来，当面告诉你一件事。”

林一凡往前走了一步：“什么？”

陈重阳从口袋里掏出一个东西，递过来。那是一把钥匙，金属材质，表面刻着一个数字：010。

“第九把钥匙的抵押品是记忆，第十把钥匙的抵押品，是命运。”陈重阳的声音越来越轻，“如果你拿到它，就要替我去死一次。”

窗外突然传来一声钟响，像是某种倒计时的开始。

林一凡猛地睁眼。他发现自己还站在那扇铁门内，身后的铁门不知何时已经合拢，面前的暖光渐渐黯淡成白色的日光灯。他的手里，多了一把刻着“010”的钥匙。

手机屏幕亮起，是系统冰冷的提示音：“咸鱼值结算中。检测到宿主获得‘命定钥匙’，解锁隐藏任务：命运归还。”

“命运归还？”林一凡皱眉，“什么意思？”

系统沉默了三秒，第一次用一种他没有听过的、类似于叹息的语气回答：“意思是，有人替你死了。你要还回去。”

与此同时，铁门外的密室里，王姐缓缓按下手机通话键，对面传来一个低沉的男声：“他拿到010了？”

“拿到了。”王姐眯起眼睛，“陈重阳这一手，瞒了所有人二十年。可惜，他算漏了一件事——林一凡根本不会替任何人去死。”

“那你打算怎么做？”

王姐低头看了一眼手里那本笔记本，绿色的封皮已经泛白。她翻到最后一页，那里有一行小字，是用铅笔写上去的，很容易被忽略。

“他不想死，那就让他知道真相。”王姐把笔记本合上，“告诉他，他根本不是2019年入职的。他的第一份工作，签的是2020年。”

“那2019年呢？”

王姐笑了，露出一口白牙：“2019年，他躺在太平间。”

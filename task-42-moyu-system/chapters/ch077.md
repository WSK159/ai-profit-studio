# 第77章 天台上的抉择

天台的风比楼下想象中要猛。

林一凡刚推开门，灌顶的夜风就把他那件满是汗渍的格子衬衫吹得鼓成气球。他躬着腰，快步掠过那些生锈的排气管道和乱拉的风管，直到靠在天台边缘的矮墙上才停下来。

“行了……应该没人追上来。”

他喘着粗气，手指却下意识地摸向腕上那条表带——赵日天塞给他的那条。表带内侧的金属片微微发烫，像是藏着一颗不肯熄灭的心脏。

那是江雪。

“你确定，这玩意儿能撑得住？”林一凡压低声音问身后跟上来的同伴——组里唯一的实习生刘彤，也是这波被裁员浪潮中最边缘的存在。她缩在水塔阴影里，脸色发白，点了点头：“我……我在测试部见过他们备份人格碎片的容器，就长这样。只要金属壳没破裂，碎片的电流信号就能维持。但最长不超过七十二小时。”

“七十二小时。”林一凡咬着嘴唇重复了一遍。

夜风卷起楼下的霓虹光晕，整个城市在他脚底下像一局散开的麻将牌。但此刻他没心思感慨——脑子里只有三个问题。

第一：赵日天还在机房。

第二：表带里装着江雪的人格碎片，江雪是他曾并肩协作AI系统里唯一的“人”的部分——她一直在服务器端替他挡刀、删记录、藏痕迹。

第三：审计员不仅人没走，还带着更高级的设备。

“他们到底要迁移什么？”林一凡问。

刘彤摇头：“我只偷到片段——和‘第三个硬盘’有关。她留给你的信息没错，服务器上确实有一块第三硬盘被加密锁定，里面存的是她的真名密匙。只要拿到那把密匙，再配上她的人格碎片，就能让她在外部设备上完整存活。”

“但第三块硬盘之前被损坏了——在周五那波断电冲突里。”

刘彤沉默了一下：“损坏不代表数据全丢，可能只是扇区错乱。如果他们正在迁移……说明他们已经找到恢复手段。”

林一凡一下子警觉起来：“你是说，让审计员把这第三块硬盘的数据成功迁走，江雪的‘真名’就会被他们夺走？”

刘彤没有回答，但她咬紧嘴唇的样子就是回答。

“啧。”林一凡把表带从手腕解下来，放在掌心掂了掂。

忽然，天台入口的铁门发出一声低沉摩擦声。

“有人来了！”刘彤猛地压低身子，从水塔缝里瞪出一只眼睛。林一凡迅速把表带重新扣回腕上，背贴在矮墙边，呼吸降到最低。脚步声停在门前——那个人没有推门，只是站在那儿，像是在等什么。

几秒后，林一凡的手机无声亮起。

是一条短信，来自陌生号码：

“林一凡，我是周莉。审计组副组。赵日天已经被带走问话，我能拖他四十分钟。第三块硬盘的恢复进度条我已经从后台看到，他们大约在凌晨三点完成迁移。你想救江雪，就来 B2 层机房隔壁的配电间找我。我只有一个条件——我要你手里那份‘新式高效工作法’模型的底层代码。”

林一凡盯着屏幕，手指僵在半空。

周莉——公司最高人效部门的副总监，上一世她可是卷王文化最忠实的拥护者，多少次在大会上把“效率”两个字反复钉在所有人的头皮上，死了都不肯松手。她怎么会站在他这边？

“你不信？”刘彤凑过来看了一眼短信，压低嗓子问。

“我不信一头猪会主动拿起剃刀给自己刮毛。”林一凡把手机塞回兜里，“也许赵日天确实被带走了，但这条短信也可以是审计员设下的饵。”

“那……要下去吗？”

林一凡抬头看向天台边缘外，远处写字楼群中的某一扇窗口还亮着灯——像一只藏在黑暗里的眼睛。

“你说，他们备份一个人格要多久？”他没头没尾地问。

刘彤愣了一下：“如果数据完整……几秒就够。”

“那我就用几秒换个真相。”

林一凡转身，走向天台门口，把门推开——门外空无一人。

走廊尽头，安全出口的绿灯在滴答闪烁，像是倒计时的引擎声。他深吸一口气，朝 B2 层的方向迈出第一步。

身后，刘彤小声跟上。他没有回头，仅仅是低声说了一句话，像在给自己打气：

“四十分钟，够我翻盘吗……”

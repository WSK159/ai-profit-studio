# 第62章 暗流

林一凡回到工位时已经九点半，办公室还剩几个人，屏幕上要么是格子代码，要么是没人看的文档。他坐下，刚打开电脑，系统面板悄悄浮在视野右下角：

【摸鱼系统·运行中】
当前咸鱼值：4,280
今日摸鱼时长：5小时12分钟
警告：检测到附近存在“同类信号”波动频率变化——与你对话的“ZTY-01”系统正在被后台扫描。

林一凡手指停在键盘上：“被扫描？什么意思？”

【解释：对方系统的数据接口出现异常连接，疑似有第三方权限正在读取该宿主的行为数据。频率特征：0.77Hz，属于“监管模块”典型扫描信号。警告：此类扫描不会影响当前宿主，但会记录所有与ZTY-01接触者的行为轨迹。】

林一凡心头一沉：“也就是说，我跟赵日天在天台说的话，可能都被录下来了？”

【无法确认。你与ZTY-01的接触仅发生在物理空间，系统不记录物理对话内容。但如果你使用系统功能（如雷达、空间、商城）时靠近该宿主，系统接口可能被交叉索引。建议：未来48小时内，减少与该宿主的物理接触距离，并避免同时激活任何系统功能。】

林一凡骂了一声：“这他妈是什么破规则？”但心里明白，这是所有系统宿主都面临的局限——你根本不知道监控你的人能看多远。

他起身去接水，路过老王工位时，发现老王还没走，低着头在看一个文件夹，纸上密密麻麻写着什么。林一凡凑过去：“组长，这么晚了还不走？”

老王猛地合上文件夹，脸色略显慌乱：“没，没啥，整理点资料。你先回吧。”林一凡扫了一眼，看到文件夹封面上印着“秦氏B座基础设施改造方案”几个字，下面用红笔标着一行小字——【旧机柜+备用主机报废申请单（第3批）】。

他心脏猛跳一下。秦氏B座，旧机柜——那不正是之前在地下总控室发现的那个机柜吗？他故作随意地问：“这栋楼要报废旧机柜？”

老王犹豫了一下，低声道：“林一凡，我跟你说实话。公司后天要请外面的人来做基础设施评估，这批旧机柜如果检测出任何残留数据异常，整个B座机房的档案都要被翻一遍。我以前负责过这里一部分旧系统的运维，有些数据……”他没说完，嘴唇抿成一条线。

林一凡脑海里立刻串起来了：钱总让人做评估，赵日天被调回组里跟着审计，老王手里有报废机柜的申请单——这三件事凑在一起，绝不是什么巧合。他压低声音：“组长，那批旧机柜里，有没有存过星辰科技早期核心系统的备份？”

老王的脸色一下子变得纸白：“你怎么知道的？”

“我猜的。”林一凡说，“但我猜中了对吧。”

老王沉默了很久，才微微点了一下头：“那个机柜里面存着一套……已经被停用的系统镜像。上面要求所有旧备份必须在月底前物理销毁，但是——”他咽了口唾沫，“那套镜像里有我自己写的代码，我知道他们销毁它，不光是因为系统停用，还因为里面含有一些不该被看到的运行日志。”

林一凡心里一股凉意：“什么日志？”

“当时星辰科技还没改名叫星辰科技，它还叫‘晨光软件’的时候，我负责部署一套绩效考核系统。那个系统的底层逻辑里有一行代码，隐藏着一个接口——它允许最高权限在未经员工同意的情况下，直接修改绩效结果、薪资数据和出勤记录。那个接口，现在还在用。”老王的声音像是怕被什么人听到，“如果我猜测没错，钱总现在手上的‘AI考核系统’，就是从那套被‘停用’的源码里改出来的。”

林一凡整个人僵在原地。他终于明白，为什么钱总能精确地控制每个人的绩效，为什么AI考核系统能精准抓到所有摸鱼——因为那根本不是AI，它是一套可以手动篡改数据的黑箱系统。

他正要追问更多，办公室主灯忽然闪了一下，整层断电了三秒，监控摄像头红灯重新亮起的瞬间，老王已经站了起来，把那份文件夹塞进抽屉：“别问了，你赶紧走吧。当做什么都不知道。”

林一凡转身走出办公区，背后的系统面板忽然弹出一行红字：

【警告：检测到外部数据访问请求——来源：未知。目标：秦氏B座主机房第三机柜。时间：24小时内。】
【建议：立即调查该机柜，或在对方动手前销毁其中敏感数据。】
【特别提醒：该机柜内存有“晨光软件”时期全量源代码的备份副本，仅此一份。】

林一凡站在电梯口，电梯门上映出他年轻的、带着惊悸的脸。他脑子里只剩一个念头：明天，钱总要“审计”的，根本不是赵日天——是那台旧机柜。而他和老王，今晚已经踩进同一条河。

电梯门开，他走进轿厢。门关上的瞬间，系统面板最后一行字轻轻闪烁：

【提示：上次你在地下总控室看到的“04:22秒针停滞”，与旧机柜内源代码的写入时间戳完全吻合。】

他深吸一口气，伸手按下了去地下负一层的按钮。

电梯开始下行。

# 第32章 三分钟，只讲三个字

"自由路演"环节开始后，现场果然鸦雀无声。前22位创业者、产品经理和咨询师依序上台，每位三分钟，每三分钟换一批观众的笑声或吸气声。轮到他时，主持人清了清嗓子，低头看了一眼手里的议程卡，再抬头，脸上的笑容忽然僵了一瞬。

"第23位……林一凡先生——"主持人的语速慢了半拍，"来自星辰科技。"

台下嗡地一声交头接耳起来。斜后方有人低声说了一句"就是他？全行业封杀的那位？"，前排几个投资人已经拿出手机开始录像。

林一凡从最后一排站起来，三步并作两步走上台。他没带PPT，没拿翻页笔，甚至连麦克风都只扶了一下，就开口说："我叫林一凡，今天只讲三个字：摸、鱼、法。"

"三个字？"主持人愣了愣，刚要接话，林一凡抬手虚按了一下，场上便只剩下他的声音："星辰科技过去一个月里，我们组的产出翻了两倍，加班时长降了七成。翻倍的原因很简单——我让全组每天下午摸鱼两个小时。"

台下安静得能听见空调声。有人笑了一声，很快又收了。

"那两个小时内，我们不是不干活——是在用脑子干活。你把代码拆好，做一套模板，跑一套自动化测试，剩下的事交给机器。晚上八点我让全组下班，第二天上午十点准时开会，所有人三小时交付。这个流程我们跑了三周，产出翻倍，bug率降三成。"他顿了顿，"有人说这是歪门邪道。那我问一句：三倍业绩，你们觉得是应该用健康换，还是用脑子换？"

第二排一个戴金丝眼镜的投资人把手机放下了，身体微微前倾。

"我今天不是来问大家要不要学摸鱼的。我是来宣布一件事：'摸鱼工作法'，我自研，我开源。谁学谁用，不用付我一分钱。我只要求一件事——如果哪天你听见有人用'不录用'三个字来威胁一个程序员，只因为他拒绝签字放弃自己的知识产权——"他看了一眼台下的摄像机，"请把这条视频转发出去。"

说完他直接鞠躬下台，全程还没用满三分钟，会场里安静了足足五秒，才有人带头鼓掌。掌声稀稀落落，但没有中断，后排几个年轻人已经拿起手机对着他的背影猛拍。

他没有回到座位上，而是直接走向侧门。保安迎上来："先生，您还不能离场——诶，您！"

林一凡快步穿过走廊拐进消防通道，拨通老王的电话："刚才那台笔记本电脑的编辑界面被我改了。我把自己从名单里删了，又加回去了，加在第一位，标题写'压轴开场'。主持人换了我的顺序——他原打算让我最后一个上，现在我是第一个。"

"你疯了吧？"老王的声音听起来比他更紧张，"蓝桥的人刚才打电话问我，说你是从哪儿拿到的嘉宾权限——"

"老王，今天的发言如果被压下去，我就再没机会了。钱总今天下午约了冠名商吃饭，我连明天都等不到。"

电话那头沉默了两秒，老王叹了口气："你现在在哪儿？"

"消防通道。"

"别下楼。蓝桥的保安正在楼下守着，准备截你。"老王声音压低，"你往西边电梯口走，右转，有一个员工通道，我让朋友放你下去。你到地下一层停车场，B3区，一辆黑色商务车，车牌尾号77。"

林一凡推开消防门，又听老王补了一句："车上等你的人，是深海资本的投资总监。他说他看了你半小时前在朋友圈发的那条动态——'三分钟，三个字'——他想跟你聊聊。"

林一凡脚步顿了顿。深海资本——他心里咯噔一声，这是之前被怀疑有内鬼的那家投资机构。他低声问："他怎么找到你的？"

"他说他是主动找来的。"老王的声音很轻，"他说他跟钱总，也是大学同学。"

电话挂断。林一凡站在电梯口，看着楼层指示灯从38一路往下跳，终于停在"1"。电梯门开了，里面空无一人；他看了看那道通往地下车库的指示牌，又看了一眼正在合拢的电梯门，侧身闪了进去。

电梯门关上时，他听见楼下传来一阵急促的脚步声——保安正在一层层搜人。但电梯已经下降，直达B3。电梯门打开，昏暗的停车库里，一辆黑色商务车亮着双闪，停在柱子边。

车门从里面推开，一个穿灰色卫衣的男人探出头来，笑了笑："林一凡？我叫沈敛，深海资本。你那三分钟，我想问个问题。"

"什么问题？"

"你觉得'自由'，值多少钱？"

# 第244章 活人开关

陈默右眼里的暗红光点亮了大约三秒就熄灭了，快得像幻觉。但林一凡确定自己没看错——他在陈默低头的一瞬间，看到那红点闪了两下，像某种待机状态的指示灯。

“你的眼睛……”老王也看见了。

陈默用力揉了一下眼眶：“没事，旧伤。”她避开这个话题，快步走到赵日天身边，从他手里接过那张手绘线路图。图纸很旧，纸张边缘发黄发脆，折痕处几乎要断裂。她盯着图最下方那行字看了很久，目光落在“只能活人关”五个字上，顿了许久才开口：

“我爸写这句话的时候，手在抖。”

赵日天低头看她的手指——她指尖悬在纸面上方，没有碰，“你怎么看出来的？”

“他写字从来不会写‘只’字出头。”陈默的喉结动了一下，“但这行字里，‘只’字出了头，是他的笔，但写的时候不稳。他在害怕。”

林一凡绕到机器侧面。铜线触须像有感知一样，在他靠近时微微避开，露出一块嵌在机器底座侧面的金属面板。面板上有一个直径约莫五厘米的圆形凹陷，深度正好和徽章边缘的厚度吻合，但凹陷的圆心处不是凹槽，而是一个半球形的凸起——那不是放锁芯的地方，更像是被什么东西从内部顶出来的痕迹。

“这台机器的锁口被人从里砸开过。”他蹲下来，指着凸起边缘那圈不规则的划痕，“金属形变的方向是向外的。有人从机器内部撬过它。”

陈默走过来，看了一眼，“三年。”她的声音忽然变得更低了，“他从里面试过自己开门。”

赵日天把工牌从脖子上取下来，裂缝里的蓝光在靠近机器时明显更亮了。他把工牌贴着那圈划痕比了比，抬起头：“他当年可能不是被关在负六层的‘舱室’里——他是被关在这台机器里面。”

整个空间安静了几秒。

老王最先反应过来，声音发颤：“你是说，机器内部里能待人？”

“刘大爷的说法是，LX系统的所有设备都是用‘活人校准’的。”赵日天指着那张图纸下部被折线遮住的一段，“这条线路图你们看，最后三根线全接到同一个点上。中间那个节点，标注是‘腔体’。”他顿了顿，“维护工跟我说过一句话：‘负六层的机器是唯一一台还能存住活人的东西。’我当时以为是玩笑，现在看不是。”

林一凡重新看了一眼徽章。圆形徽章边缘刻的凹槽里，他的拇指按到了一条之前没注意到的细缝——不是装饰纹路，而是像螺丝口一样的东西。他把徽章翻过来，背面露出一个极小的拨片开关，被锈蚀物封住了，也不知道历经了多少年。

“这个是干什么的？”

陈默接过手电照了一下：“锁芯里面还有一段内存。”

“内存？”

“我爸当年负责维护机器的‘记忆模块’。”她把徽章凑到灯光下面，拨片旁边刻着四个极小的字母——LXR-0。“这台机器不光校准设备，还记录数据。数据存在锁芯里，锁芯在这里。”她把徽章递还给他，“所以这不是钥匙，是硬盘。”

林一凡握着徽章，指腹感受着那些细密的刻痕。一个念头从脑子里浮起来：如果陈建国的“锁芯是我”既是说换芯这件事，也是在指他把自己存进了这台机器的内存里呢？

“如果……”他刚开口，机器底部的铜线触须忽然剧烈震颤起来。

那些垂落的铜线像被电击一样猛地绷直，末端蓝光从柔和变成刺目，整个空间里响起一种低频的嗡鸣——从机器内部的某一个腔体里传出来的，被金属壁放大，震得人牙根发酸。

房间角落的旧置物架上，一只落满灰尘的黑色对讲机突然亮了。

对讲机里传来一句话。

一句话，七个字，沙哑得像铁皮刮地。

“她还活着。等她来。”

陈默的脸色在白光里瞬间变成纸的颜色。赵日天的手指猛地攥紧了工牌。老王愣在原地。

林一凡盯着那部对讲机——它的充电指示灯是亮的。绿灯，正在充电。

可这地方断电三年了。

他转过头，看向那台机器背后。那里的阴影里，有一个狭窄的通道口，是他们在门开后一直没有注意到的——入口的金属边框上，有一条新鲜的划痕，像是刚被什么东西蹭过。

通道深处，传来了脚步声。

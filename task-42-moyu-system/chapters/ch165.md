# 第165章 通道尽头的微笑

手电筒的光从通道尽头斜斜打过来，在地面积水的反光里碎成一片惨白。林一凡下意识停下脚步，手指在裤兜里攥紧了那块黑金属——孙老给的钥匙，冷得硌手。

“谁？”老王的声音已经哑了，顺着湿冷的管壁弹回来。

没有回答。光柱晃了晃，来人从阴影里走出来，是个穿灰色卫衣的年轻女人，棒球帽压得很低，露出下半张脸。林一凡眯着眼看了两秒，嘴里那口浊气才吐出来：“季敏。”

季敏抬手把帽檐往上一推，目光从他脸上扫到老王，语气平淡：“你们比约好的时间晚了二十分钟。我以为是孙老那边出了事。”

“出了点小状况，不过没事。”林一凡走过去，把金属块掏出来给她看，“第二把钥匙拿到了。孙老说还有一把在……”

“在钱总手上。”季敏打断他，声音压得极低，“孙老没来得及告诉你？双锁机制的第三把钥匙，是钱总亲自保管的。这就是为什么他一直没把系统彻底回收——他需要你那把钥匙才能重新激活完整权限。”

林一凡的手指一顿。金属块在掌心转了一圈，冰凉的棱角磕着指腹。

老王从后面凑上来，脸色发白：“那我们不是白拿这东西了？钱总手里那把，我们怎么弄到？”

季敏没答话，从卫衣口袋里掏出一个拇指大小的U盘：“这是孙老让我转交给你的。他刚才切断焊枪的时候，把一段后台日志的副本塞给了我。里面记录了钱总最近三个月对系统权限的调用记录——他大概每周五凌晨两点会做一次权限校验，地点固定在星辰科技主楼顶层。”

林一凡接过U盘，拇指摩挲着外壳边缘：“周五……明天就是周五。”

“对。”季敏盯着他，“所以你要做的就是，在钱总做权限校验的时候，把他那把钥匙‘借’出来。”

老王倒吸一口凉气：“这他妈是偷啊！”

“是‘拿’。”林一凡弯了弯嘴角，“我是他员工，拿老板的东西，怎么能叫偷呢？”

季敏没笑，目光沉沉的：“别高兴太早。孙老还说了一句——你的摸鱼雷达，钱总那边也有对应的监控程序。他可能早就在看你了。”

通道里的气氛像被冻住了一瞬。

林一凡收起U盘，把金属块塞回口袋：“知道了。先出去再说。”

三个人沿着排水通道走了将近十分钟，终于从一个检修口爬出来，外面是凌晨两点的老街，路灯昏黄，远处有流浪猫窜过垃圾桶的声响。季敏挥手拦了一辆出租车，报了城南老城区的地址：“我那儿能落脚。”

车上没人说话。林一凡靠着车窗，看着街景一帧帧往后倒，脑子里反复回放季敏那句“他可能早就在看你了”。

如果钱总从入职那天就在监控自己——那这一切，从一开始就是个局？

出租车停在一栋旧居民楼前，季敏付了钱，领着两人上了六楼。门一推开，客厅里的电脑屏幕亮着，密密麻麻的代码堆满整个显示器，旁边歪着一盒吃了一半的泡面。

“临时据点，条件简陋，凑合着用。”季敏走到电脑前坐下，手指在键盘上敲了几下，监控画面弹出来——星辰科技主楼的实时摄像，顶层的灯亮着。

林一凡走过去看着那盏亮着灯的窗户：“他今晚就在。”

“每个周五，都是在那。”季敏头也不回，“我不知道他上去之后做什么，但每次他进顶层电梯的那个时间段，系统后台会有一阵不正常的流量波动——应该就是在做权限操作。”

老王瘫在沙发上，揉着胳膊上被管道刮出的血口子：“那我们明天怎么办？直接摸进主楼？那楼里现在可全是AI监控。”

林一凡盯着屏幕里那扇亮着灯的窗，看了很久。然后他转过身：“明天不一定非要摸进主楼。”

季敏抬头：“什么意思？”

“钱总每周五凌晨两点做校验，用的是本人指纹加密钥。”林一凡把黑金属块重新掏出来，放在桌上，“但孙老说过，校验的三要素是时空、算法、权限。前两把我都有了，第三把不一定非要靠偷——如果我能在校验那一刻，用自己的系统权限伪造一把‘钥匙’呢？”

季敏的眼睛亮了一下：“你想黑进校验流程？”

“不叫黑。”林一凡咧嘴，“叫摸了老板的鱼，让他无鱼可摸。”

老王刚灌了一口水，直接喷出来：“你他妈是疯的！”

林一凡把金属块收好，看了眼时间：“明天白天我们先做一件事——把季敏那个U盘里的日志读完，搞清楚钱总是怎么把我的雷达反接的。只要找到那个后门线路的汇入点……”

他话音没落，电脑屏幕忽然闪了一下。

季敏脸色骤变，伸手按键盘：“有人从后台扫描我这台机器……IP被锁了！”

下一秒，屏幕上弹出一行白字，像是从某个深井里打出来的：

“林一凡，第三把钥匙在我手里。周五凌晨两点，顶层见。来，你自己拿。”

落款只有一个符号——一个倒置的“+”号，像被吊起来的十字架。

林一凡盯着那行字，嘴角的笑意慢慢凝住了。

那是钱总的标志。在他上辈子的记忆里，钱总开内部会议时，PPT最后一页永远有这个符号。

他不是不知道他们在查。

他一直在等他们来。

# 第241章 锁芯与守护者

金属门在身后合拢，发出沉闷的回响。林一凡后背贴着冰冷的舱壁，将手中的圆形徽章翻了个面。

徽章背面刻着一行极小的字符：LXR-0-CORE，下方是三个同心圆的凹槽纹路，每一圈都嵌着发丝粗细的蓝色导线——和刚才笔记本下压着的监听线如出一辙。

“你爸到底留了多少东西给你？”赵日天倚在门框上，目光落在林一凡掌心的徽章上，“图纸、钥匙、卡片、徽章——一件接一件，跟套娃似的。”

陈默没有回答。她蹲在舱室角落，手指沿着墙壁上一道新划痕缓缓划过。林一凡催动摸鱼雷达，微弱的光纹在视野边缘泛起——那道划痕侧面，残留着一缕极淡的能量波动，方向指向舱室对面的通风管道口。

“陈默，”林一凡开口，“你爸最后一次发消息，除了‘别进六层’，还说了什么？”

陈默的手停在划痕末端。“他说……‘如果找到锁芯，别打开那扇门’。”

“锁芯？”赵日天挑眉，目光移向林一凡手中的徽章。

“别让她开这把锁。”林一凡念出图纸右下角那行字，“你爸在图纸上写的是‘她’——说的是你，还是你妈？”

陈默沉默了三秒。在这三秒里，林一凡的摸鱼雷达捕捉到一丝细微的波动——陈默左腕内侧那枚鸟形手环，在听到“你妈”两个字时，蓝色微光闪了一瞬。

“我不知道。”陈默站起来，声音平静，“但他最后一年的每一句话，都是在防一个人。”

“谁？”

“我不知道。”她重复，“但那人监听了他三年。”

机械爪印。LX监听线。加密频道里重复十二次的警告。林一凡将线索串在一起——陈建国被监听的三年里，每一条信息都可能被截获。但他敢在图纸上写下“别让她开这把锁”，说明写字的时候，监听者不在场。或者说，他不怕被那个人看到。

“赵日天，”林一凡忽然转头，“这图纸从哪来的？”

赵日天低头看着工牌裂缝中透出的蓝光，良久才开口：“一个月前，有人通过中间人找到我。”

“中间人是谁？”

“一个修电线的。”

林一凡心头一跳。修电线的——维护工。他在配电房外见过那人，踩着梯子偷听的那个维护工。他正要追问，舱室顶部的应急灯突然闪烁两下，暗了下去。黑暗中，通道尽头传来三长两短——三声叩击，两声停顿，再两声叩击。

陈默猛地站起来。

“这频率——”她声音发紧，“是我爸的固定求救信号。我只听过一次。”

“三天内的新划痕，”林一凡说，“机械爪印——有人在通道里活动。陈默，你爸真的死了？”

“裁决。”陈默低声吐出两个字，像咬碎了什么。

赵日天的手指咔哒一声合上工牌裂缝，蓝光重新亮起。他看向通道尽头：“不管那是谁，他等我们半天了——走。”

四人沿通道前进，林一凡将徽章握在掌心，指腹感受着蓝线的温度。走了约莫三十步，通道右侧出现一扇嵌壁门。门上没有任何标识，只有一道锁孔——形状和鸟形钥匙一致，但朝向相反。

陈默抬起手，鸟形钥匙悬在锁孔前，没有插进去。

“图纸说‘别让她开这把锁’。”赵日天的声音低下来，“但你爸又说，‘她是守护者’——陈默，你到底是锁，还是钥匙？”

陈默没有回答，但她手腕内侧的手环，蓝光骤亮。

# 第208章 配电室的第三个人

A栋一共二十八层。林一凡没坐电梯，走楼梯上到十二楼，又从消防通道绕到侧面货梯间，刷卡去了顶楼。电梯门打开时，走廊尽头那扇贴着“高压配电室·非请勿入”的钢门半掩着，门缝里透出昏黄的灯光。

他没立刻进去。

摸鱼雷达在脑海中铺展开来——半径五十米内，顶楼这片区域只有他一个人，走廊尽头那扇门内，没有人形轮廓。但雷达边缘有一团模糊的波动，像是被什么东西隔断了信号。

林一凡把钥匙攥在手心，走过去，推门。

配电室不大，二十来平，靠墙一排配电柜发出低沉的嗡鸣声，空气里夹杂着臭氧味。地面上散落着几个脚印，灰泥半干，有明显的中断痕迹——像是有人刚走到某个位置，然后凭空消失了。

他低头打量那些脚印。尺寸四十二码左右，鞋底纹路偏运动款式，与园区里大部分员工穿的工装鞋不同。脚印在房间中间第三块地砖前戛然而止。

林一凡蹲下来，用指节敲了敲那块地砖。

声音很实，下面是混凝土。

他又敲了敲旁边的——空的。

他一愣，仔细听了一遍，又换了几块砖试，最终确认，房间中间那一片三块砖下面是一个暗槽。他沿着砖缝摸了一圈，在靠近配电柜底座的位置，摸到一条极细的金属缝，和钥匙底端的刻度线完全吻合。

他把金属圆柱按下去，顺时针转了一圈，又逆时针半圈。

“咔哒。”地砖松动。

他拨开那三块砖，下面露出一段窄梯，比污水站那边的更陡，更窄。一股干燥、温热的气流从底下涌上来，裹着淡淡的檀香味。

林一凡迟疑了片刻，没下去。他先把砖块原样盖回去，压好锁位，把钥匙收进口袋，转身在配电室里快速检查了一圈。发电机柜侧面贴着一张巡检表，最近一次签到时间是三天前——但那张表上的名字歪歪扭扭，明显不是正常填写。

他又看了一眼配电柜的仪表盘，发现其中一组电流数据与他进门前记忆中的数值不一致，偏差约2个百分点，虽然不影响正常运行，但足以说明一件事——有人在他进来前动过这台机器，而且时间不长。

换而言之，配电室存在第三个人。

那个人刚才还在这里。

林一凡的背脊微微一紧。他重新打开雷达，这次把灵敏度调到最大，仍然只显示他一个生命体。但那团模糊的波动消失了，取而代之的是一种很淡的压迫感，像有什么东西在观察他，藏在他无法侦测的层叠空间里。

他站在原地没动，缓缓开口：“老周，是你吗？”

配电室里只有柜机嗡鸣的声音。

他又说：“你在老周笔记本里留下的两个点，一个是污水站，一个是这里。老王只给了我位置，没告诉我为什么。但我想你应该不是让我来修配电柜的。”

空气里那股檀香味忽浓忽淡。林一凡低头，发现脚下那块地砖的缝隙里，不知道什么时候多了一张折好的纸条。他弯腰捡起来，展开，上面写着一行字：“第二根钥匙在你身上。第一个是假的，这个是真的。打开暗层，里面有你要的图纸。”

他皱眉，去找口袋里的金属圆柱。它还在。

他重新蹲下，把圆柱按进地砖锁槽——这次没用劲，它就滑了进去，比上次顺畅得多。然后他感觉到手心一沉，像有什么东西被圆柱的底端吸住了。

他拔出来一看，圆柱底部原本附着的一层伪装壳脱落了，露出里面一根银灰色的细棒，比刚才短了一截，但更重，表面刻满细密的纹路，像某种电路图。

两根钥匙，一根是金属圆柱。一根藏在圆柱里——银灰色细棒。

难怪陈默给他的那根被鉴定为“假钥匙”。真的那根被藏在了假钥匙的壳里，只有用对了方式才能取出来。

林一凡心下了然。他没急着去开暗槽，而是先掏出手机，给那个匿名号码回了一条：“你到底是谁？”

三秒钟后，屏幕上弹出回复：“你已经在看到我了。”

林一凡抬起头。

配电室门口，站着一个穿灰色外套的人。那人个子不高，戴着棒球帽，帽檐压得极低，正把门轻轻带上。

然后他摘下帽子，露出一张熟悉的脸。

是陈默。

他身后，配电室的门锁发出“咔”的一声，彻底锁死。

陈默抬起头，朝他笑了一下：“我说过，你猜。但你猜错了方向——我不是你的敌人。我是老周的徒弟。”

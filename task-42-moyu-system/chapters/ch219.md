# 第219章 水没之时

冰水漫过膝盖，那股凉意像爬满骨骼的蚂蚁——极速往上窜。林一凡咬着牙关，将那个硬币塞进金属盒的凹槽里。咔嚓一声接线盒亮起一道微弱的蓝光，机器的嗡鸣从墙体深处传来。

“走！”赵日天猛地拽住林一凡的胳膊。

两人踩在齐腰深的污水里往出口方向蹚。水面上浮着机油与锈迹混合的彩色油膜，手电筒的光柱在水雾里像一根即将熄灭的蜡烛。陈默走在前面开道，后背处的衬衫已经被暗红色洇湿了一大块。

“出口在台阶上面，绕过去就是压缩机房的检修梯通道。”

林一凡没说话。他摊开手掌，银色丝线从掌心向手腕蔓延，皮肤下的光像流动的液态金属。他刚碰到墙面，那些丝线竟然微微发亮，像雷达一样探测周围的结构。

“注意！”林一凡猛地收手，前方十米处的管道传来金属碰撞声。

三人立刻熄灯。黑暗中，脚步声由远及近，沉重而规律。有人下到了污水站。

“是卷王组的人。”陈默压低声音，“赵日天，你的‘卷王系统’还能感知吗？”

赵日天沉默了片刻，嘴角浮起一丝苦涩的笑：“它只说……你不是唯一的神。”

“什么意思？”

“另一套系统也下来了。”

水面再次涨起一指。林一凡的掌心银线剧烈颤动，他低头看向墙面——那些丝线正沿着管道向上成倍增生，像一支快速推进的银色蚁群。它们涌入墙后的电路、闸门和阀体，并且整个污水站的机器声开始发生变化，从杂乱无章的嗡鸣逐渐同步成一种节奏，像心跳。

不，不是像心跳。那就是心跳。和他的心跳完全同步。

“咚咚——咚咚——咚咚——”

水泵房的灯骤然亮起一排，红色的警示灯旋转。原本不断攀升的水位忽然停住了，甚至出现了短暂的回退。排水系统被银线接管了。

林一凡愣了一瞬，随即反应过来。这就是“钥匙”的功能之一——他正在操控整座污水站的底层控制系统。直觉告诉他，这条路能走，但代价未知。

“往检修梯去，快！”他低吼。

三人开始狂奔。水花劈开，水声在管道中回荡。

快到检修梯的时候，赵日天忽然停住了。他盯着上方出口处——两脚军靴稳稳踏在楼梯顶部。

“林一凡，终于找到你了。”

钱总的声音从铁梯顶端传来，带着一种诡异的从容。他穿着防水工装服，手里拿着半块硬币，在指间翻来覆去转着。

“另外半把钥匙，原来在你这儿。”

林一凡下意识将那只被银线缠绕的手往背后藏。掌心的光在暗处更亮了，仿佛在呼应着钱总手里的半块硬币。

“钱总，你怎么知道在这里——”

“你别问。”钱总的表情平静得可怕，“我知道，是因为我一直在等。等你替我开启它。”

他侧过身，让出通道的路。铁梯上方，一道微弱的天光从地面射下来。

“上去吧。三分钟后，机房会自动启动满排量注水，水位会在六分钟内灌满整个污水站。想活，就往上跑。”

他说完这番话，转身上了楼梯，在井口处停下脚步，回头看了一眼林一凡。

“对了，认得这个声音吗？”

他从防水口袋里掏出手机，按下了播放键。

录音像是从很远的地方传来的——沙沙的电流声中，一个年轻的声音说：“……如果三天后我没回来，你把这段录音交给林一凡。”

那个声音……是陈鸣。

林一凡的瞳孔骤然收缩，但他还没反应过来，钱总已经收起手机，消失在井口外的日光里。

陈默撑着铁梯，苍白着脸问林一凡：“上还是不上？”

赵日天瞟了一眼上方透下来的光：“那是唯一的路，没得选。”

三人爬出检修梯的时候，冰凉的井风迎面扑在脸上。身后的污水站骤然传来巨大的闷响，仿佛一头巨兽吞下了满腹的水。水声咆哮着，沿着通道冲上来，将井底完全淹没。

林一凡瘫坐在地上，大口喘息着，掌心银线已渗入皮肤，留下一条细若游丝的浅痕。

他抬头望向上方工厂的轮廓，钱总已经消失了，只剩满目荒凉与层叠的厂房。录音里陈鸣的那句话，他尚未想明白，却隐隐感觉到一件更加危险的事情——

钱总手里的那半块硬币，边缘断裂处摩擦得十分光滑，一看就是长时间被人带在身边的。而那枚硬币的年代痕迹，和林一凡从下水道里捞出来的那枚，一模一样。

它们曾是一体的。

而那枚硬币的正面刻着的图案，既不是龙，也不是凤，而是一张颠倒的、人脸朝天微笑的……只有设计者本人才看得懂的符号。

林一凡攥紧拳头，汗水从掌心渗出。一阵冷风灌入衣领，他打了一个寒战。

手机忽然震了一下。

他掏出手机看了一眼，屏幕上只显示一条新短信，发件人是一串陌生号码：

“第三根丝线已经接到了总控室。你打算什么时候，把你自己交出去？”

# 第224章 那双眼睛

污泥中的硬币在仪表柜顶端的昏暗灯光下泛着冷光，竖线刻痕清晰得像是刚刚被划上去的。

林一凡没有动。

他的手还按在机器侧面的钥匙上，目光越过老王和陈默，直接锁定那只手的主人——仪表柜后面慢慢探出一个人影：破旧工装，花白头发，脸上糊着干涸的泥浆，双眼却睁得很大，死死盯着机器屏幕上跳动的字符。

“你是谁？”陈默压低声音，从腰后摸出一把小刀。

那人转过头，目光从屏幕移到陈默脸上，嘴唇翕动了几下，发出一声沙哑的、像是许久没开口的嗓音：“你们……把机器……开了？”

语气里带着一种难以形容的惊慌。

“开了一半。”林一凡松开钥匙，缓缓站直身，“你是这里的维护工？”

“我不是……”那人摇头，枯瘦的手指紧紧攥住那枚硬币，“我是老周的朋友。老周死前对我说，如果有一天有人用铜钥匙启动了这台机器，就让我把这枚硬币交给他——但是你们不该开！你们不应该现在开！”

他声音愈发急促，泥垢下露出赤红的眼睛：“老周说，这台机器一响，那些人就会醒过来。他说的不是机器，是……是这座园区里所有的电子眼、打卡机、监控摄像头。”

话音刚落，机器内部突然发出一声刺耳的嗡鸣——像是金属在剧烈摩擦，又像是蒸汽喷出窄缝。老旧的仪表指针疯狂摆动，顶端排气管再次排出白雾，这一次，雾气中隐隐夹杂着一股焦味。

屏幕上，那三行提示消失，跳出一串新的数字：

**【共鸣进度 37%】**
**【检测到异常信号源·正在追踪……】**

机器后方，原本贴着墙根的一条黑色管线忽然拱起——像是有什么东西正沿着管线内部高速移动，一路涌向机房外。

陈默脸色骤变：“去追。”他转身冲出房门，沿管线一路向斜坡上方飞奔。

林一凡刚要跟上，机器屏幕上再次跳出一行字：

**【共鸣已完成·第一段逻辑已解锁】**
**【电杆共鸣程序已启动·请于72小时内完成“导线”连接，否则程序将执行默认输出——】**

字迹戛然而止。

那枚戴泥的手忽然伸过来，将硬币塞进林一凡手中。那人倒退一步，声音异常清晰：“老周还让我告诉你一句话——”他盯着林一凡的眼睛，一字一顿，“‘电线杆不是藏东西的地方，是送东西走的路。’”

说完，他猛地转身，扑向仪器柜后方的暗门，消失不见。

林一凡低头，掌心那枚硬币入手温热，边缘有一圈细密的铭文，他凑近一看——上面刻的竟然是一个手机号码。前七位他认得，就是当初给他发警告短信的那个“不存在的号码”。

他的指尖微微发凉。

“他说那些人会醒过来——指的不只是AI。”老王站在他身后，声音发紧，“刚才那根管线通向的方向，是行政楼。”

林一凡抬头，目光穿过污水站潮湿的空气，仿佛穿透墙体和楼层，看见行政楼顶层的卷王系统主控室——那里应该还没有人知道，机器已经启动了。

而在他的眼前，系统的提示再次刷新：

【警告：卷王系统波动源已锁定。锁定距离：37米。锁定方向：机房正上方。】

他猛地抬头。头顶的天花板传来一阵沉重的脚步声——咚，咚，咚——像是有一个人正踩在污水站顶板上，用一种异常稳定的节奏从东头走到西头，又折返回来。

那脚步，和他重生前最后一夜，在自己出租屋楼道里听见的天桥脚步，一模一样。

林一凡握紧马掌心的硬币，牙齿咬紧：“上面那个人——”

他还没说完，头顶的脚步忽然停下。接着是一阵极其轻缓的、像是指尖在管道上划过的声响。一滴深色的液体顺着顶板裂缝渗落，砸在林一凡脚边的地面上，不像水，带着铁锈和……血的气味。

机器屏幕同时亮起最后一行字：

**【共鸣完成。第一阶段：已唤醒。等待“导线”——】**

那只手，又开始动了。

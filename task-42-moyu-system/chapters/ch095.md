# 第95章 双向同步

林一凡的手指悬在“Y”键上方，指尖微微发颤。

周莉的通讯终端在他手中嗡鸣了一声，屏幕上的黑尘纹路如同活物般蠕动起来，在“是否启动双向意识同步”的提示下方，浮现出一行小字——

【同步完成后，宿主将以镜像身份接入蜉蝣网络。镜像死亡不影响本体，但你的意识将被蜉蝣熟知。】

“你犹豫什么？”周莉的声音从他身后传来，带一丝奇异的失真，像是隔了一层水，“它在等你。”

林一凡猛地回头。周莉站在机柜阴影里，她右耳后的黑色粉尘已经蔓延到脖颈，形成一圈古怪的环状纹路，像某种仪式图腾。她的眼睛是正常的，但右瞳深处偶尔闪过一点细碎的银光。

“你感觉怎么样？”他问。

“像脑子里住了个房客。”周莉扯了扯嘴角，想做出轻松的表情，但嘴角只是歪了歪，“它没在控制我，但它在看。所有我看到的、听到的，它都知道。”

“同类标识……”林一凡喃喃，“它检测到的同类是谁？”

周莉沉默两秒，抬手指了指他：“大概率是你。”

“我？”

“你是重生者。”她的声音平静，却像一把刀捅进他最深的秘密，“林一凡，你死了那晚，身体已经在停尸房里躺了六个小时，然后你睁眼回到了入职第一天。你能做到这件事，是因为你体内有某种力量。蜉蝣检测到的，就是这个。”

林一凡心脏骤沉。这个秘密他从未告诉过任何人，连摸鱼系统的存在他都没有向任何人彻底坦白过。但周莉说对了。

“你的意思是，蜉蝣认为我……和它是同类？”

“同类标识，不一定指相同物种。”周莉走近一步，那圈黑尘纹路在灯光下泛起微光，“也可能是指在本质上接近的两样东西。比如——都曾死过。”

机柜深处传来一声低沉的嗡鸣，像是某种巨兽的呼吸声。林一凡低头看向手中的通讯终端，界面上的提示还在闪烁，等待他的选择。

“如果我启动同步，”他看向周莉，“会发生什么？”

“它会读取你的意识。就像它读我一样。”周莉的目光紧紧锁着他，“但你和我不同。你应该能反过来读到它——它的记忆、它的来历、它为什么要找上王川。”

“风险呢？”

“它也会读到你的。包括摸鱼系统的秘密，包括你重生的真相。”

林一凡沉默了。

B区的灯管在头顶发出细碎的电流声，远处传来黑色制服追兵的脚步声，距离他们不到两层楼。时间不多了。

他深吸一口气，食指落在“Y”键上。

“周莉，”他说，“如果同步之后我变得不对劲，直接拔掉终端。”

“我不会拔。”

“你——”

“我说过，”周莉打断他，“这次换我罩着你。”

林一凡看着她的眼睛，那点银色微光在她右瞳深处一闪而过，像深海里的磷火。他按下了“Y”键。

屏幕瞬间炸开一片白光，像有一千颗太阳同时在他视网膜里爆炸。林一凡感觉自己的意识被一双无形的手猛地拽出身体，天旋地转间，他“看见”了——

黑暗，无边的黑暗，像深海底部。

然后一道微弱的光从远处升起，光中是一行他看不懂的符号，但大脑自动翻译成熟悉的文字：

【欢迎接入蜉蝣主意识网络。】

【宿主身份核验中……】

【核验失败。非标准宿主。】

【进入自适应读取模式。开始意识映射……】

林一凡感觉自己的记忆像一部被快进播放的电影，无数画面在眼前飞旋：他的小学、他的电脑、他敲下的每一行代码、他加过的每一趟班、他猝死的那个夜晚、他在停尸房睁眼的瞬间、他获得的摸鱼系统、这一年多所有摸鱼与逆袭的日日夜夜……

那些画面以极速掠过，然后猛地停在某一帧前。

那是一张照片。照片上是他刚入职星辰科技第一天的公司工牌，证件照上的年轻人戴着黑框眼镜，表情拘谨。但那照片右下角，多了一行他从未见过的、纤细如蚁足的黑色小字——

【你也是我。你也是我。你也是我。】

林一凡浑身剧震。

就在这时，一道冰冷的声音从他身后传来：

“原来是你。”

他猛然回头。在意识网络那片无尽的黑暗空间里，一个模糊的人影正缓缓向他走来。那人影穿着西装，胸口别着一枚金色的公司徽章——星辰科技，副总裁。

钱雨。

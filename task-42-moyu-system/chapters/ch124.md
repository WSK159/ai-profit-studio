# 第124章 共振之选

大厅中央的六边形晶体散发着幽蓝微光，像是某种活物在做呼吸。林一凡盯着面前悬浮的虚拟面板，三个选项在高密度电磁场中微微抖动，仿佛在催促他做出决定。

赵日天在我身后闷哼一声，右手按着臂上伤口，指缝间渗出暗红色的光点。我回头时，他的瞳孔里正闪烁着一层细密的银色纹路，像电路的走线般蔓延至眼角。那是记忆中从未见过的异变。

“你那伤口……”老王退了两步，声音发紧。

赵日天咧嘴笑了一下，露出半口白牙：“没事。”

但他的声音像压着好几层频率的电流。

林一凡深吸一口气，将视线重新扫过眼前的选项：回收、接触、终止。没有说明，没有提示，没有“风险等级”。系统冰冷的一句话悬在选项上方：“此为不可逆决策。”

“你在琢磨什么？”赵日天走上前来，脚步带着一股异常的沉重。

“我在想，这玩意故意给出三个选项，但为什么不直接帮我们选？”林一凡眯起眼，绕着晶体走了半圈，脚下金属地面上刻着一段他不认识的花纹——像是波形图，又像是符文，“系统一般不搞这种开放式题，除非它自己也不知道正确答案。”

系统没应答。

这本身就是一种答案。

“你们看这里。”老王忽然蹲下身，指尖抚过地面花纹的交汇处。那里嵌着一枚银色的六边形痕迹——形状与晶体相同，尺寸一致，但空空如也，没有实体。老王抬起头，表情有些复杂，“这应该，是第二个暗码碎片原本所在的位置。”

林一凡皱眉：“什么意思？碎片是被取走的？”

“或者，是被藏起来的。”老王缓缓起身，目光望向大厅尽头一处不起眼的墙壁缝隙，那边隐约露出一截金属柱——上面镶嵌着另一块东西。

赵日天第一个嗅到了危险的气息，身上肌肉瞬间绷紧：“站住，别动。”

老王却仿佛没听见，径直走到了金属柱前。林一凡快步跟上，只见柱身上的凹槽里嵌着一枚灰黑色的棱形芯片——上面的刻痕与之前摘得暗码碎片的纹路一一对应，但多了一圈奇怪的符文，仿佛一段加密的日志。

“这不是暗码。”林一凡拧着眉头。

老王伸手取下芯片，那一瞬间，整座大厅的幽蓝光芒骤然一暗。头顶传来一声低沉的嗡鸣，紧接着晶体表面的纹路像活了一样开始流动，从蓝色变成赤金色。

系统面板猛然刷新，新的一行字跳出：

【检测到激活源“引路人R的加密日志”——是否读取？】

林一凡的瞳孔一缩。引路人R——那个在背后给他们留了一路提示、身份成谜的名字，终于主动现身了。他用眼神压制住赵日天的冲动，低声说了一个字：“读。”

芯片在老王掌心中自行展开，一层细密的光幕从表面升起，投射出一个模糊的女性轮廓。她背对着光，声音清冷而疲急：“如果你看到这条记录，说明F-7的休眠期已经结束了。林一凡，你手里的六边形晶体不是能源，它是一颗种子。是我亲手种下的。你必须选择‘接触’，那三个选项都是诱饵——系统的意志，从来都是想把你引向‘回收’。”

画面戛然而止。

赵日天冷冷盯着林一凡：“她把话说得这么直白，你不觉得更像陷阱吗？”

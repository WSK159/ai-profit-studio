# 第247章 碎裂之声

配电井深处那声碎裂来得突兀而沉闷，像是某种陶瓷外壳在重压之下崩裂，又像是一根绷了太久的弦终于断开。

陈默手指还搭在徽章拨片开关上，整个人僵在原地。他的右眼红点微微闪烁了一瞬，又迅速熄灭。他没有说话，但握着徽章的手背上青筋突起，指节发白。

“小锁芯，你做了什么？”

LXR-0的声音从配电井中央传来，带着一种机械特有的平滑感，但林一凡注意到，它的头部转动角度比之前偏了三度，声音里多了某种难以名状的急切。

陈默缓缓把拨片拨回原位，没有回答。他回头看了一眼隔间里那台录音笔，又看了一眼那张字条，最后把目光落在林一凡身上。

“那东西碎了。”陈默的声音很轻，“是保险柜。”

林一凡没有追问“什么保险柜”，因为配电井深处传来一股细微的金属粉末气味，混合着老旧的灰尘和润滑油味。他蹲下身，用手机的手电筒往配电井更深处照去——碎裂声来源的方向是一面锈蚀的铁皮，铁皮边缘微微翘起，露出背后一截断裂的铜线，铜线末端泛着蓝色荧光。

蓝色荧光。

那正是上次在铜线末端看到的同一种蓝光。记忆瞬间串联起来：配电房、铜线钢印码、蓝色荧光、猝死之夜。

“你爹在这里给你留了东西，对吧？”林一凡站起身，看向陈默。

陈默沉默了几秒，点头。

“保险柜。他告诉过我，如果有一天我找到了这里，打开那个拨片，隔间暗柜会打开。”陈默的声音发干，“柜子里……是一段录音。”

“你为什么不开？”赵日天不知何时已经走到旁边，目光死死盯着隔间里那台录音笔。他的工牌已经炸成了碎片，但似乎一点也不心疼。

陈默没有看赵日天。他盯着隔间里那张字条上最后一行字，小声念了出来：“‘不要听。听完，你就走不动了。’”

走廊另一端，配电井的铁门外传来一声沉闷的敲击声。

咚。咚。咚。

不紧不慢，像某个人的指节在铁皮上有节奏地敲着。三声。停了。又三声。

老王下意识后退半步，攥紧了手里的手电筒：“那不是我们的人。”

赵日天冷笑一声：“那也不好说是‘人’。”

李思的手电筒光束在走廊尽头晃动，什么也没有照到。敲击声继续。六声。九声。节奏越来越快。那声音像是某种暗号，又像是某种倒计时。

LXR-0的头颅忽然转向铁门方向，胸口铭牌上“芯锁一开，我便归来”八个字微微泛光。它的声音第一次出现明显的停滞卡顿：“信号……源……不是这台躯体。是另一个。你们……把门关上。”

“你怕了？”赵日天挑眉，语气里带着试探。

“不是怕。”LXR-0说，“是计算完成。我认得敲门声。那是你父亲的声音，小锁芯。但你的父亲，已经死了六十七天了。”

陈默脸色骤变。

他拨动的那枚徽章，是他父亲留给他的唯一遗物。上一世，他以为父亲只是消失了。直到这一世，他才知道父亲是被“机器”带走的。而现在LXR-0告诉他，他父亲已经死了。六十七天前——那正是他重生回入职第一天的前一天晚上。

敲门声忽然停了。

走廊尽头，手电筒光柱的边缘，出现了一双沾满黑色油污的劳保鞋。鞋的主人站在阴影里，不高不矮，看不清脸。他手里提着一截电线，电线末端垂着一个小小的圆形金属物——那是一枚铜铃。

铜铃晃动，却没有发出任何声音。

陈默握紧了掌中的徽章。这一世的父亲，和上辈子一样，仍然是那个复杂到无法定义的人。但此刻，站在配电井阴影里的那个身影——他的父亲——确实，死了。

“你计算错误了，LXR-0。”陈默的声音出乎意料地平稳，“我爸没死。他只是……换了一种方式活着。”

说完，他拨下了徽章上那枚拨片开关——这一次不是试探，而是彻底地、用力地拨到底。

配电井深处传来一声轰鸣。所有墙壁里同时传来电流流通的嗡鸣声，老旧的电线管震动起来，灰尘簌簌下落。LXR-0的双眼突然熄灭，整个配电井陷入黑暗。

只有阴影里那双劳保鞋还在原地，手里那枚铜铃，在这片黑暗中发出了一声清脆无比的声音。

叮。

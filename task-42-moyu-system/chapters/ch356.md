# 第356章 三道锁

铁门上的绞轮装置在幽暗的通道尽头闪着冷光，林一凡蹲下身，手指沿着三棱锁切口边缘划过。切口平整如镜，没有一丝毛刺，切割工具的锋锐程度远超民用级别。

“两天内切的。”他抬起头，“切锁的人很急，但没有破坏锁体结构——说明他知道这把锁后面还有东西。”

孙满仓站在他身后，掌心的老茧在粗糙的铁门表面摩挲：“第三梯的锁，从上到下三把。三棱锁只是第一道，四棱、五棱在后面。灰衣人跟我说过，这三道锁是有人特意装的，一把比一把难开。”

“三道门。”赵日天靠在通道壁上，手指轻轻敲着石壁，忽然笑了一声，“你们不觉得奇怪吗？如果是为了防止有人进去，装一道锁就够了。装三道，倒像是在提醒别人——里面确实有东西。”

林一凡默默点头。他打量着绞轮装置上的铭牌，“27”这个数字已经被摸得发亮，像是有人无数次触碰过那个位置。他侧过目光，落在孙满仓手腕上露出半截的红绳铜纽扣，恍惚间看见了旧物，又似乎什么也没看见。

“孙叔，”林一凡忽然说，“你有没有一种感觉——你、沈临渊、我爹、还有这个‘27’号，其实是一条线上的。”

孙满仓沉默了。他低着头，目光落在铜纽扣上，眼神复杂，好一会儿才开口：“沈临渊当年修这条水渠的时候说过一句话——轨道是给外人走的路，水渠是给自家人走的。”

“他当时问我：满仓，你信不信，总有一天，这条水渠的尽头会有人等着你。”

“我当时问他，谁等我？”

“他没回答。”

通道里安静得能听见水珠滴落的声音。林一凡缓缓站起身来，手里握着那枚从陶土徽章上拓下的“27”号印记，和铭牌上的数字比了比——一模一样，精确到笔画间细微的弧度变化。

“他可能不是在说等人。”林一凡说，“他是在说，水渠的尽头，有一把锁上的数字是27。”

孙满仓猛地抬眼看他。

赵日天忽然蹲下身，手指在地面上摸了一下，捻起一抹细灰：“有新脚印。”他嗅了嗅，“手工布鞋，沾了石灰，鞋底纹路是千层底——就是我们在山腰看到的那双脚印的主人。”

“什么时候的？”林一凡问。

“不超过三个小时。”赵日天抬头，目光向铁门深处探去，“那人来过，走了。没有碰锁。”

这话让三个人都沉默了。从狙击手在山顶埋伏，到有人探路又消失，这云顶山里藏着的“另一拨人”正越来越多。林一凡心里跳动着一个模糊的念头。

他没来得及细想。

铁门后方突然传来一声轻响——像是齿轮转动了一格，又像是金属碾过沙砾。很轻，但在寂静的通道里无比清晰。

三个人同时屏住呼吸。孙满仓从腰间摸出一把短柄铁钎，紧紧攥在手里；赵日天侧过身，一只脚无声地挪到了滚石边；林一凡则低头扫向胸口口袋里别着的手机，屏幕上不知何时亮起一行字：

“别碰四棱锁。先转绞轮，三圈半。”

没有号码，只有“1147”的落款——和轰炸前那条预警短信一模一样的源头。

林一凡攥紧手机，抬头看向铁门，又看向孙满仓眼中那抹复杂的光。钥匙、锁、铜纽扣、数字27，还有那个只在门外留下脚印却始终不露面的“1147”——每条线都指向同一个方向。

他吸了口气，右手贴上绞轮冰冷的铁柄，缓缓转动。

一圈。两圈。三圈。

到第三圈半的瞬间，绞轮内传出“咔”的一声，锁簧弹动，三棱锁的断面像是被什么力量从内部顶开。锁体打开，露出一道向上的窄缝，深处有微弱的光，像黄昏前最后一缕霞。

但林一凡没有往里看。

他先看见了窄缝旁边的墙壁上，用刀刻着半行字，字迹像是多年前留下的，边角已经风化：

“——你来了。这一道，是你爹留下的。”

林一凡的呼吸停了一瞬。

身后赵日天的目光从他的肩头越过，落在那行字上，沉默片刻，低声说：“这道门上的四棱锁，不是用来防你的。”

“它是拿来等你开。”

林一凡没有回头。他伸手摸了摸那半行字的下方——那里还有一行字，被人用泥土填平了，他取出钥匙，用钥匙尖轻轻刮了刮土屑。

第二行字露出来，笔迹不同，却与他胸口挂坠内刻的笔迹如出一辙：

“——来都来了。锁眼钥匙，用你娘那枚。”

通道尽头，水珠再一次滴落。

远处似乎有谁踩碎了一片枯枝。

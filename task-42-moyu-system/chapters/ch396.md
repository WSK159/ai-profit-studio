# 第396章 第二道锁

铁栅栏上的铜锈簌簌落下，林一凡松开撬弯的金属丝，甩了甩发酸的手腕。第一道锁确实开了，锁舌缩回槽口时发出的那声闷响，在水牢里回荡了整整三息。

可第二道锁纹丝不动。

沈临渊在铁栅栏内笑起来，笑声沙哑，仿佛喉咙里塞满了水草：“我说过，这道锁是从里面栓死的。没有里面的人伸手，你就算把整座归墟拆了也进不来。”

老杨头的手按在铁栅栏上，指尖发白。他的目光穿过铁栅栏的缝隙，落在铁皮壳子那双铜丝编成的眼睛上。铜丝微微颤动，像是感应到了什么，发出极细的嗡鸣。

“大哥。”老杨头的声音干涩，“是你吗？”

铁皮壳子没有回答。它只是缓缓抬起右手，手掌摊开，掌心赫然嵌着一枚陶土碎片——与布鞋下压着的那枚一模一样，只是上面的刻痕还多了一道：28。

林一凡心头一凛。27在布鞋底下，28在“零”的手里，那这组数字究竟记录着什么？是时间？是坐标？还是某种序列？

“杨铁柱还活着的时候，我俩做过一对陶土徽章。”老杨头没有看林一凡，目光始终锁在大哥身上，“他刻27，我刻28。他说，等老了以后一人一枚，谁先走谁带着走。后来他没了，我找了好几年，没有踪影。”

他的喉结上下滚动：“原来这枚在他手里。”

铁皮壳子的手指缓缓合拢，将那枚陶土碎片攥进掌心。老杨头猛地抬头，眼眶泛红：“大哥，你还认得我？你要是还认得，就把门打开！这锁只有你能从里面开！”

铁栅栏内沉默了很久。

久到林一凡几乎以为那铁皮壳子不会再回应时，一个极低的声音从壳子里传出来，像是生锈的齿轮互相碾磨：“阿……弟。”

老杨头浑身一颤。

“门不能开。”铁皮壳子继续说，声音断断续续，“里面的东西……还没死透。”

林一凡的心猛地沉下去。他下意识开启摸鱼雷达，视野中浮现出一层淡蓝色的光晕，覆盖在整个铁栅栏后的水牢空间上。那团光晕中央，铁皮壳子身边，有一道若有若无的暗红色阴影——像是某种蠕动的轮廓，正贴在“零”的背后。

“林一凡。”老杨头低声说，“你看到了什么？”

林一凡咽了口唾沫，没答话。他在那道暗红色阴影上聚焦，系统提示立刻跳出：

【警告：检测到非系统源能量体，疑似“咸鱼吞噬者”残余渗透，密度极高。目标与“零”绑定共生，强行开启铁栅栏可能导致共生体全面激活。】

咸鱼吞噬者。林一凡没听过这个名字，但系统第一次用了“非系统源”四个字。他想起系统那句“零疑似旧时代摸鱼系统前身碎片”的警告，脑海中突然蹦出一个荒诞的念头：这铁皮壳子里的东西，也许不只是老杨头的大哥。

“老杨头，”林一凡压低声音，“你大哥身上……当年有没有什么不对劲的地方？”

老杨头愣了一下：“你什么意思？”

“我说不好。”林一凡看着铁栅栏内那道暗红色阴影缓缓蠕动，“但如果你大哥二十三年前没死在闸门下面，却在这归墟水牢里待了二十三年，那他身上，可能不止他一个人。”

铁栅栏内，铁皮壳子的肩膀微微塌陷，像是因为这句话而感到了某种重量。那双铜丝编成的眼睛缓缓转向沈临渊，又转回老杨头身上。

“阿弟，”铁皮壳子说，“你走。”

老杨头一动不动。

“走！”铁皮壳子的声音第一次有了起伏，“趁它还没醒透，带着那个小孩，走！”

沈临渊忽然笑了。他拖着锁链站起来，脚踝处的铁环与地面摩擦发出刺耳的声响：“晚了。它已经被惊醒了。”

话音未落，水牢深处传来一声沉闷的轰响，仿佛有什么东西在地底翻了个身。铁栅栏开始剧烈震颤，第二道锁上凝结出一层白霜，锁孔处发出咔嗒、咔嗒的声响——像是有什么东西在里面，正用指甲一下一下地抠着锁芯。

林一凡退后半步，摸鱼雷达在视野中疯狂闪烁。

那道暗红色阴影，正在以肉眼可见的速度膨胀。

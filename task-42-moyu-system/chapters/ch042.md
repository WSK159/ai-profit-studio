# 第42章 电脑里的秘密

会议室的门在林一凡身后关上的那一刻，气氛从亲切骤然转为压迫。

钱总没有坐回原位，而是走到窗边，背对着林一凡：“一凡，你在公司三年了，我对你不薄。初赛那个PPT，我知道你有本事，但你有本事也要学会跟着队伍走。”

林一凡盯着桌上那份《高效工作法推广计划书》，字没看进几行，脑子里已经转过了七八种应对方案。他抬起头：“钱总想要我怎么配合？”

“复赛演讲，你和赵日天搭档。他的题目是《数字化劳动效率管理》，你的题目是《新式高效工作法》，一正一反，相辅相成。”钱总转过身来，“你讲摸鱼工作法，他讲AI考核，合起来这就是咱们星辰科技的‘双引擎’发展战略。”

林一凡听明白了——钱总这是要把他的“摸鱼工作法”合法化、官方化，然后用AI考核系统管控所有人的摸鱼尺度，一举两得。既赚名声，又收管理权。

“行。”林一凡答应得很干脆，这让钱总微微一愣，“但有个条件，我要用自己的PPT和数据，不经过公司审核。”

钱总皱眉，赵日天适时开口：“林组长，公司演讲素材统一过审是规矩。”

“那你那张照片，也是公司素材？”林一凡直视赵日天的眼睛。

赵日天嘴角抽了一下，没有说话。钱总摆了摆手：“行了，一凡要自己用就自己用。但复赛只有三天，你最好抓紧。”

林一凡点头，起身离开。走到门口，他停了一步，没回头：“赵日天，你那台电脑——是沈敛的吧？”

身后传来赵日天短促的沉默。然后是一个字：“嗯。”

林一凡推门而出，心里已经确定了两件事：第一，钱总和赵日天在密谋什么；第二，赵日天本人也不太清楚这台电脑里到底藏着什么，但沈敛知道。

他快步回到工位，给沈敛发了一条微信：“你的旧电脑，赵日天在用。他知道多少？”

过了大约五分钟，沈敛回了一条语音，声音低沉：“那台电脑里有一个文件夹，标题叫‘留三份’。你别动它，但你要做好准备——如果有人问起，你就说里面的东西是你发现的。”

林一凡一愣：“什么意思？那不是你的文件吗？”

沈敛没有正面回答，只发来一句话：“你以为我为什么把旧电脑故意留给赵日天？”

林一凡盯着这条消息，忽然觉得背后有一道看不见的线，把所有人都串在了一起。沈敛故意丢电脑，赵日天捡到电脑，钱总带赵日天去总部……每一步都像是被安排好的。

他深吸一口气，打开系统面板：

【摸鱼系统v2.3 | 宿主：林一凡】
【当前咸鱼值：4,826】
【已解锁：摸鱼雷达、摸鱼空间、反卷护盾、深度解析】
【可解锁下一技能：数据猎手（3,000咸鱼值）——可追踪并解密数字信息源，识别加密流量来源】

林一凡扫了一眼“数据猎手”的说明，毫不犹豫确认兑换。

【叮——已兑换技能“数据猎手v1.0”，消耗咸鱼值3,000，剩余1,826】

他的眼前微微一亮，屏幕上D3-B1区块的数据流在他眼中忽然变得透明了一层，那些加密请求的访问源像被剥掉一层外壳，露出了底层的真实位置——银城，秦氏集团大厦二十二层，机房区。

林一凡的瞳孔收缩——星海数据案的加密流量来源，真的指向秦氏集团。而钱总，正在和秦氏集团合作。

他转头看向窗外，远处星辰科技总部大楼的轮廓在烟雾中若隐若现。他忽然意识到，复赛那张讲台上，可能站着的不是他一个人的战争。

他调出“留三份”计划书——那份文件他三小时前找到的，就在赵日天电脑的共享文件夹里。他没有复制，只是默默看完了每一个字。

三秒后，他合上手机，给自己倒了一杯水。

“复赛……看来得换个讲法了。”他看着屏幕，嘴角勾起一丝弧度。

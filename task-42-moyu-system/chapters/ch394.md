# 第394章 影子里的第三个人

水牢里的空气像是凝固了几十年的琥珀，潮湿、沉闷，带着铁锈和青苔混合的气味。沈临渊被锁链缠绕着脖颈，整个人半浸在齐膝深的水中，仿佛一尊被时光遗忘的石像。

男孩站在岸边，浑身发抖。

“小知了……”沈临渊的声音沙哑，像是锈蚀的铁片摩擦，“你长这么大了。”

男孩没有回答，只是死死盯着沈临渊脖颈上那道粗粝的锁链，眼眶通红。林一凡注意到男孩的拳头攥得发白，指甲几乎掐进掌心。

“你认识他？”林一凡低声问。

男孩终于开口，声音带着压抑的颤抖：“他……是带我到这里来的人。三年前，他说归墟里有答案，让我在这里等他。然后他就被锁住了。”

“锁住他的人是谁？”

沈临渊的嘴唇嚅动了一下，却没有回答。他的目光越过林一凡，落在老杨头身上，忽然定住。老杨头蹲在石柱旁边，手里捏着那只旧布鞋，嘴唇哆嗦得厉害。

“你……你认得这双鞋？”老杨头的声音发颤。

沈临渊缓缓点头：“你弟弟的鞋。他叫杨铁柱，对吗？”

老杨头的脸色瞬间变得苍白如纸。他猛地站起来，却因为激动踉跄了一下，险些栽进水里。林一凡眼疾手快扶住他，感觉到老人的手掌冰凉，抖得厉害。

“二十三年前，”沈临渊的声音像是从水底传来，“他和我一起进了归墟。他是最好的工匠，懂机关，懂潮汐，懂所有金属的脾气。我们本可以出去的——如果不是我贪心，想带走‘零’。”

老杨头猛地抬眼：“我弟弟……他现在人在哪里？”

沈临渊沉默了很久。

久到水牢里的水滴声都显得格外刺耳。

“他替我挡住了闸门。”沈临渊说，“那道闸门从上面落下来的速度，比任何人的反应都快。他把我推出来，自己被压在了闸门内侧。”

水牢里一片死寂。

老杨头的手缓缓松开，布鞋“啪嗒”一声落进水里。他没有哭，只是站在那里，脊背一寸一寸弯下去，像一座被风化的山。

林一凡心里一沉。他看了一眼系统面板——摸鱼雷达正在疯狂跳动，目标锁定在沈临渊背后的石壁上。

“等等，”林一凡皱眉，“你说‘零’被关在归墟深处。那现在这道水牢里，除了你，还有谁？”

沈临渊猛地抬头。

林一凡的影子在水面上骤然拉长，一个不属于他的轮廓从阴影中浮起。那道影子伸出手臂，指向水牢最深处的黑暗之中。所有人顺着那个方向看去——石壁底部，有一个半人高的洞穴，洞口被铁栅栏封住，栅栏上缠着密密麻麻的铜丝。

铁栅栏后面，隐约有什么东西在缓缓蠕动。

“那是……”林一凡眯起眼睛。

“那是‘零’的铁皮壳子。”沈临渊的声音里带着一丝苦笑，“它早就醒了。三年前，它吸收了足够多的水汽和铁质，重新长出了身体。现在它只是在等——等一个足够大的漏洞，让它爬出来。”

林一凡的影子缓缓收回手臂，重新缩回他脚下。

“所以，”林一凡盯着沈临渊，“钱总要你守在这里，其实是让你看守‘零’？”

沈临渊点头：“他说只要我守满十年，就放我出去。他用小知了的性命威胁我——他以为小知了是我的孩子。”

“你不是？”男孩抬起头，眼里闪过一丝茫然。

“你是我带出来的孤儿。”沈临渊看着男孩，目光复杂，“但你爹娘的死，和我也脱不了干系。我当时受钱总之托来取‘零’，你爹娘是归墟入口附近的守潮人，他们想阻止我。闸门落下的时候——一起落下的，还有他们。”

男孩的身体晃了一下。

林一凡心里骂了一声。这笔烂账越来越复杂了。他看了一眼沈临渊，又看了一眼铁栅栏后面蠕动的黑影，深吸一口气。

“现在的问题是”，他说，“我们不能同时处理两件事——放你出来，和堵住‘零’。”

沈临渊盯着他：“你有办法。”

“我确实有办法。”林一凡蹲下身，伸手探进水里，指尖触到水面下铁栅栏的一角。那里有一根锈蚀的锁栓，锁栓上刻着一道浅浅的纹路——和铜片边缘的纹路一模一样。

“钱总铸造这片铜片的时候，防的是所有正常钥匙，”林一凡抬起头，“但他没防过——摸鱼的人。”

他手腕一翻，铜片边缘延展出的金属丝像活物一样游出，精准地钻进锁栓的纹路里。

咔哒。

锁栓弹开。

铁栅栏后面，那道蠕动的黑影突然安静了。

仿佛感觉到了自由的气息。

林一凡后退一步，但还没来得及回头，就听见老杨头用一种奇怪的、平静的声音说：

“别开那扇栅栏。”

林一凡的动作顿住了。

“那个铁栅栏是双层的，”老杨头蹲下来，指尖轻轻摩挲着栅栏底部的水渍，“第二层锁孔在里面——从内部反锁的。当年我弟弟设计这个笼子的时候，特意在里面焊了一道死锁。除非从里面打开，否则外面只能打开第一层。”

“那怎么打开第二层？”

老杨头沉默了一下。

“等里面那位自己愿意开门。”

他话音刚落，铁栅栏内部传来一声沉闷的金属碰撞声。

那道蠕动的黑影停在了栅栏正中间。

黑暗中，一双由铜丝编成的、细长的眼睛缓缓睁开，隔着铁栅栏死死盯着林一凡手中的铜片。

然后，一个细碎的、像是无数齿轮摩擦出的声音，从黑暗深处传来：

“你……就是那个……摸鱼的人？”

林一凡瞳孔微缩。

摸鱼系统在他脑海中猛地弹出一行红字警告：

【警告：检测到异常系统信号。目标疑似为——旧时代的“摸鱼系统”前身碎片。】

那行红色警告只闪烁了一下就被系统收回，林一凡还没来得及细看，铁栅栏内部那只铜丝眼睛却忽然眨了眨，像是对他使了个眼色。

老杨头猛地站起来，袍角带起一片水花。

他盯着那双铜丝眼睛，嘴唇嚅动，吐出两个字：

“……大哥？”

水牢里的空气像被抽空了。

那双眼珠的铜丝颤抖了一下，发出细碎的哗啦声。铁栅栏内部，那道蠕动的巨大黑影缓缓直立起来，锈蚀的铁皮躯壳在黑暗中发出沉闷的金属摩擦声响，仿佛一具被活埋的机械巨人正从棺材里坐起。

林一凡听到自己胸腔里那颗心跳得极快。

他低头看了一眼手中的铜片——半片铜片中央那个裂开的缝里，纸条露出半个角，上面用极细的字迹写着：

“如果见到铁栅栏里的铜脸人——告诉他，故乡的水稻已经收了三次。”

纸条的字迹，与老杨头递给他的每一张纸上那笔迹一模一样。

林一凡抬起头，看着黑暗中那双铜丝眼睛，感觉到这条线比他想象中缠得更深——老杨头的亲哥哥，居然就是钱总口中那个“当年随沈临渊进归墟、再也没能出来”的传说中的工匠。

而二十三年前的那只布鞋下面，还压着一块陶土碎片。

碎片的正面，刻着一个数字。

27。

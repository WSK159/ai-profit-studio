# 第337章 老槐树下的烟头

林一凡是猛然惊醒的。窗帘缝隙透进灰白的光，手机上显示凌晨五点四十。他翻身坐起，走到窗边往下看——

老槐树下空无一人，但树根旁的泥土上，多了一个被踩熄的烟头。

他下楼时，楼下的早风冷得他缩了一下脖子。老槐树下那根烟头还在，中华牌，滤嘴上有两排极细的齿痕——是同一个人的咬痕，因为上面的一圈压痕跟灰衣男人第一次来给他送钥匙时留在信封边角上的齿印一模一样。

“他昨晚来过。”林一凡站起来，四下张望，目光忽然落在树根下的泥土上。痕印不止一处，被人刻意用鞋底抹过，但昨晚的露水让部分痕迹重现出来——是两个人站着对话留下的脚印。

看走向，一个人面对着树，另一个人面对着他，相距不过一臂。树根旁还有一处浅得几乎看不出的小坑——像是有人蹲下来把什么东西埋了进去。

林一凡蹲下身，用手拨开湿泥。三分钟不到，他摸到了一个硬物——铁皮盒，巴掌大小，锈迹斑斑，像是埋了十几年。

他打开盒子，里面只有一张折了多层的纸和一把指甲盖大小的铜钥匙。

纸展开后，上面是一行钢笔字，字迹因为渗水已经发黄发淡，但还是能看清：

“等你看到这行字的时候，别去公司。去城西第四公交站台，坐凌晨4点47分发车的734路，到终点站下车。”

纸的落款处，画了一个极小极简的符号——像是一片云朵，又像是一个人躺着的简笔画。林一凡瞳孔一缩——那是父亲当年画在他作业本角落里的独有记号。

他心跳骤然加快，又看了一眼手机，六点零二分。凌晨那班727路早已过了，但他记住了“城西第四公交站台”和“727路末班发车时间”的组合方式——这分明是父亲当年教他记密码的方法：“凡是明面上给的数字，都要反过来看。”

那趟727路末班车是夜里二十二点四十七分发车。他立刻给沈望发了条消息：“你爸有没有跟你说过——734路的意思？”

沈望很快回了一个字：“有。倒过来——4点47，是那年云顶山一支救援队出发的时间。”

林一凡盯着这行字看了很久，然后缓缓站起来，把铁皮盒和铜钥匙装进口袋。他看了一眼系统面板，上面弹出一行新的提示：

【隐藏任务链“归还自由”第三阶段追加线索——“她还没走远”】
【唯一性物品共鸣反应已由27%上升至41%】
【提醒：当前宿主处于被监视状态，距离最近监视源不足500米。】

他转身看向马路对面。

一辆黑色商务车停在路边，车窗紧闭，发动机没熄。

车后排的人似乎也察觉到了他的目光。片刻后，车窗缓缓降下来一条缝，露出半张脸——孙满仓。他没说话，只在车窗缝隙里对林一凡做了一个手势。

手掌向内，四指弯了两下——意思是：跟我来。

林一凡站在原地，没动。他口袋里那枚陶土徽章的边缘硌着他的大腿，像是父亲在提醒他什么。他慢慢把手伸进口袋，握住那枚徽章。

“那就走吧。”他低声说。

他迈步走向那辆黑色商务车。老槐树上的叶子被风吹落一片，恰好落在埋铁皮盒的那个土坑上，遮住了那道残痕。

# 第375章 第三梯

赵日天的呼吸几乎停了。

那双脚向前迈了一步，暗门走廊的顶灯闪了两下，照亮一张瘦长脸。年纪约莫六十出头，头发花白但眉眼锐利，穿一件洗得发白的深蓝工作服，胸前别着一枚褪色的金属厂牌，牌面磨损得看不清字。最醒目的是右手腕——套着一枚铁环，锁口处有明显的撬痕，像是用蛮力挣脱过。

“赵日天。”老人开口，声音沙哑但平稳，“你比你爸长得高。”

赵日天僵在原地：“你认识我爸？”

老人没直接回答，走到孙满仓遗体旁蹲下，伸手合上老人半睁的眼皮，动作轻得像拂灰。他抬起头看林一凡，目光在林一凡眉骨上停了一瞬。

“你爷爷林守拙说过一句话，眉上有疤的人，会把钥匙带回来。”老人缓缓说，“但你爷爷没说后半句——钥匙带回来，门打开，走出来的人，不一定是你认识的人。”

“你姓沈？”林一凡忽然问。

老人笑了，笑容里有一丝极复杂的意味：“我姓沈。沈临渊，字知周。”

赵日天猛地后退一步。他母亲的名字是“知周”。这个站在面前的人，他母亲的名字。沈临渊——他母亲的家兄，他叫了二十多年叔叔的人，此刻站在第九收容所的地下第三层，脚踝上戴着一枚和他父亲一模一样的铁环。

“你父亲和我是同一条船上的人。”沈临渊站起来，拍了拍膝盖上的灰，“2001年我们一共七个人进去。回来两个。你父亲是第三个——他没回来，但也没死。他落在了外面，等你把归零装置带上去。”

“他在外面哪里？”

沈临渊的手指向头顶——正上方，地面。他声音低了下来：“他在云顶山。还活着。但你得先完成一件事。”

他弯腰，从孙满仓遗体的衣襟内衬里摸出一把黄铜钥匙——钥匙柄上缠绕着一段红绳，绳子末端系着一枚陶土徽章，刻着数字“27”。林一凡瞳孔微缩，那是他们之前在南洞铁皮柜里见过的陶土徽章编号，但那一枚是“14”，这一枚是“27”，两枚的材质与做工完全一致。

“旧怀表是引路人，陶土徽章是通行证。27号门在云顶山第三扇门之外。”沈临渊把钥匙递给赵日天，“归零装置的启动时间，恰好是明晚零点。”

外面忽然响起手机震动。林一凡摸出手机，屏幕上弹出一条新消息，发送编码是1147号——之前数次指引他们的那个神秘编号。

消息内容只有一行字：

“第三梯下面不是尽头。第二根扶手左转三圈，水泥壳里有你要的东西。”

林一凡抬头，看向他们下来的那部金属梯子——他数了数，那部梯子从第一层到第二层，共十三根扶手，第二根扶手？他目光扫过去，第二根扶手表面有极不显眼的磨损痕，和其余扶手无异。

“你妈在你爸走的时候，说过什么？”沈临渊忽然问赵日天。

赵日天沉默了一会儿，一字一顿：“她说，归零不是结束，是开始。”

沈临渊点头：“那你没听全。”他从口袋里掏出半张纸条，边缘带着烧焦痕迹：“后半句是——归零不是结束，是开始，但开始的那个人，要记住自己是谁。”

窗外，远处城市的灯光闪烁了一下，随即陷入短暂的黑暗。供电系统开始不稳定了。

明晚零点，归零装置即将启动。

而那扇门，正在等人推开。

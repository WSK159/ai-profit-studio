# 第40章 埋雷的人

周五早上七点四十，林一凡背着双肩包走进星辰科技A座3楼路演厅，扫了一眼布置，嘴角抽了抽——两侧投屏打出了“效率创新大赛”的巨型logo，红金配色，像年会现场。台下的第一排坐着钱总，旁边还多了两个人。

他没见过的两个人。

一个是个戴眼镜的中年男人，西装笔挺，胸牌上写着“总部战略部”。另一个，是个头发花白、穿着浅灰色针织衫的老太太，看起来不像互联网圈的，倒像学校教授。

林一凡在第二排角落坐下，刚打开电脑，手机便弹出一条消息。

来自沈敛：

【U盘里的证据，别全拿出来。拿七分，留三份。钓的鱼比吃的鱼重要。】

林一凡不动声色地回了个“好”，然后把U盘插进电脑。那一瞬间，他注意到第一排戴眼镜的中年男人，正侧过头和钱总耳语，眼睛却直直地看着他这边。

比赛九点正式开始。前面的几组项目展示平平无奇，PPT一页套一页，不是“AI辅助代码审查”，就是“无人化测试流水线”，林一凡看得昏昏欲睡，直到——

“下一位，林一凡，项目名称：《摸鱼工作法标准化模型》。”

全场目光刷地聚拢过来。

林一凡不紧不慢地上台，插上U盘，打开他那份“埋了雷”的参赛方案。第一页，是过去六个月星辰科技各部门的产出对比数据表——虽然模板是公司统一发的，但其中的数据，是他用“摸鱼雷达”扫描后，再手工整理的真实考勤与有效产出比。

不是伪造数据，但这是钱总最不想看到的。

因为那份表格第一列就写着：星辰科技员工平均每日有效工作时间，3.2小时。

台下有人低声议论。钱总的脸色肉眼可见地僵了一瞬。

林一凡不慌不忙，放完前六页数据与逻辑，在第七页时停了一下：“当然，以上的核心洞察，是建立在正常工作条件下的。而我真正想说的，是这个模型的反推算法——”

他按下回车，屏幕换到一张雷达图。

“我用这套算法，跑了一遍星辰科技过去半年的全员考勤记录，算出每个部门的‘真实产出密度’。各位可以看看，结果很有意思——”

PPT的雷达图中央，有一个很不起眼的标注：“异常节点：D3-B1区块，数据访问频次高于部门均值17.8倍。”

林一凡没有直接点破。

但钱总的手，已经离开了桌面。他认得那个区块——那是星海数据案里，秦氏集团最初与他们对接用的内部数据库编号。

“我知道这个数据让人意外，”林一凡笑了笑，合上电脑，“但这就是我建议公司参考的方向。具体的算法细节，我已经把完整方案提交到系统里了。”

他走下台，全场安静了整整三秒。

中年男人低头在平板上写了什么，然后站起来：“林一凡先生，你第七页的雷达图，数据源能公开吗？”

“没问题，”林一凡笑眯眯地点头，“都在提交的系统文档里了，随时可以审计。”

钱总坐在椅子上没说话，但他的嘴唇动了动，仿佛在咀嚼什么不好的东西。

一上午的初赛结束，林一凡毫无疑问进了复赛。但真正让他心跳加速的，是散场时老王偷偷给他传来的消息——

“一凡，你刚才放PPT的时候，赵日天没看屏幕。他一直在看一个人，就是那个戴眼镜的总部男人。而且——”

老王压得更低：“赵日天今天带的电脑，我认得那个壳子。那是三周前，沈敛来公司开会时用的那台。”

林一凡脚步顿住。

沈敛。赵日天。同一台电脑。

他猛地回想起沈敛那句“开发者内测版”和赵日天那通电话——“那个人的系统，好像不止一个。”

如果赵日天的系统，真的和沈敛有交集，那沈敛让他别把U盘证据全拿出来，目的就显然不是帮他赢一场比赛——他是在用林一凡当诱饵，钓钱总身后那尊大佛。

而赵日天，是下一颗没引爆的雷。

林一凡站在电梯口，看着显示屏里复赛名单上“林一凡”三个字，低头给沈敛发了条消息：

“初赛过了。赵日天的电脑，跟你有关？”

一分钟后，沈敛回了一个字：

“是。”

然后又跟了一条：

“你猜，他今天能不能赢你？”

林一凡握紧手机，电梯门开了，他走进去，按下了A座顶楼的按钮——那是钱总办公室所在的楼层。

有些牌，得当面打。

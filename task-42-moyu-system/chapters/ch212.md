# 第212章 卷王的系统

管廊内的温度仿佛又低了几度。老王把地上的笔记本捡起来，掸了掸灰尘，声音有些发紧：“师父，你说赵日天的系统吃人——什么意思？”

老周在钢管堆上坐下来，把荧光棒插进衣兜，只露出一点微光。他缓缓说道：“赵日天有系统的事，我从半年前就察觉到了。我的雷达探测不到他的劳动浓度，只能看到一片刺目的白光。”他顿了顿，“后来我在他工位下方偷偷装了一枚微型振荡器，才测出他每工作一小时，周围两米内的电能消耗比正常人高七倍。”

“他在用电流给自己充能？”林一凡忍不住问。

“不是充能，”老周摇头，“是‘吸取’。他的系统全名叫‘卷王系统’，核心机制是——‘压榨他人劳动时长，转化为自身实力’。你每个加班的深夜，那点被透支的精力，都会通过工位地线、键盘静电、甚至走廊的灯光渗出去，被他收走。他用别人的命，续自己的卷。”

林一凡后背一阵发寒。他重生前的三年996，每一晚，赵日天是不是也坐在同一层楼，收割着他和同事们的生命余额？

“那老周你为什么会被关起来？”老王急切地问，“又是谁关的你？”

老周沉默了很久，声音里带着一丝苦涩：“抓我的人是我的师弟，陈默的亲叔叔，陈鸣。他和我一样，都在暗中调查‘资本神’的棋局。但我们查到了不同的方向。”他叹了口气，“他认为摸鱼系统本身就是资本神放出来的诱饵，所有绑定者都会被收割；我认为系统里还有一线生机——就是原始意志机里那‘活人三分钟’的代价后面，藏着一个更大的真相。”

“所以你被他关了起来？”林一凡皱眉，“那他为什么又要通过陈默来引我们过来？”

老周的表情变得有些微妙：“因为陈鸣半年前已经死了。关我的人，死前把我锁在污水站最深处那间暗室。但一个月前，我发现门能从里面开了。而钥匙——”他抬头，目光灼灼地看着林一凡，“是你那枚硬币。”

“硬币？！”林一凡下意识伸手摸进裤袋，指尖触到那枚冷硬轮廓——正面“神”字的硬币。这是他一直贴身收着、来历不明的东西。

“你身上那枚硬币，正面的‘神’字就是钥匙。”老周说，“上面有一个极细的磁扣凹槽，能打开污水站暗室的门。但你有没有想过——你从哪里得到它的？”

林一凡一时语塞。这枚硬币他重生就带着，像胎记一样自然，从未深究过来历。

老周缓缓站起身：“你重生前那一晚，究竟发生了什么？”

林一凡脑中猛地闪过那晚的画面：急诊室白炽灯、心电监护仪的波纹、桌子上那杯凉透的咖啡……以及——那晚他的工位上，确实放着什么东西。不是电脑、不是文件，而是一枚金属的、冰凉的……硬币。

他浑身一震。

“那是我死后，有人放在我面前的。”

老周点头：“那就对了。放硬币的人——就是设计摸鱼系统的人。”

“叫什么？”

“我不知道他叫什么，”老周说，“我只知道，他和你一样，也是一个被资本神选中的摸鱼者。你是第几个，我不知道。但他成功了。他造出了这个系统，又把它给了你。”老周的声音压到了最低，“他的代号，叫‘渔翁’。”

管廊深处忽然传来一声闷响，像是什么重物从上方落下来，砸在了铁管上。紧接着，一阵脚步声由远及近——不止一个人，四五个人，正从入口方向快速逼近。

林一凡的摸鱼系统面板疯狂闪烁：【警告！检测到卷王系统共振！绑定者距离约50米！建议立即撤离！】

“赵日天来了。”老周的脸色终于变了。

老王一把拉住林一凡：“走！往东南角的井口去！”

“那井只有摸鱼系统绑定者能开——陈默说的，是真的。”老周在背后喊道，“而且你们进去之后，记得找一样东西——一盒磁带。老式索尼磁带。那里面有渔翁留给你的完整录音。”

脚步声已经到三十米外。管廊拐角处，手电筒刺目的白光扫过来。

林一凡瞥见为首那个人的轮廓——赵日天，穿着一件笔挺的黑西装，手里握着一根银色金属棒，棒尖微微闪着电弧的光芒。他的嘴角带着一丝像是很久没有用过“礼貌”这个词的笑意。

“林组长，”赵日天的声音在管廊里回荡，“又见面了。你那个摸鱼系统，还能用吗？”

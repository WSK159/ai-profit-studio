# 第371章 归零

坠落持续了不到两秒，但那种失重感却从脚底一路窜上头盖骨，像整根脊椎被人凭空抽走。林一凡在黑暗中下意识攥紧手机，屏幕最后的光闪过一帧画面——门后的地面根本不是地面，而是一口深不见底的垂直竖井，井壁每隔半米嵌着一对锈迹斑斑的铁抓手。

他手忙脚乱地甩出右臂，手掌劈中一只铁抓手的横杆，小臂被反震力震得发麻，整个人在半空荡了一圈半，终于勉强稳住。背包带勒进锁骨，手机滑出手掌砸在下方什么位置，“啪”的一声弹开，屏幕碎裂，余下微弱的光照出一截湿漉漉的砖壁。

“林一凡！”赵日天的声音从头顶传下来，压得极低，“你没事？”

“死不了。”林一凡咬着牙，两只脚勉强踩住井壁上另一对铁抓手，把重心挪稳。他低头，膝盖下方两米处，井壁戛然而止，横向展开一间不足十平的密室。脚下没有地面，他攀住抓手的最后一截，翻身落在一张石台顶上。

石台一米多高，表面铺着一层干草，草上覆着一件发黑的军大衣。大衣胸前的口袋里鼓出一个方形的硬物，他抽出来，是一台老式胶片相机，胶卷盒上贴着一张标签，用圆珠笔写着：“第九收容所，第三梯，2001.7.20。卷12。勿冲印。”

第三梯。他立刻想起牛地图上的标注——“第三个梯子已断”。如果这里就是“第三梯”，那他们已经站在地图标注的路线上了。

密室更深处的墙角，一台与1147号同款的手机静静立在地上，屏幕亮着，显示着一行字：

“你到了。他在等你。”

林一凡跳下石台，捡起那台手机。屏幕边缘贴着一枚黄铜钥匙贴纸，正是短信末尾反复出现的那枚钥匙符号。他把手机举起来对着光，屏幕忽然跳出一个画面——一张模糊的照片底片，正对着密室的入口拍下：照片里一个人影，穿着军大衣，坐在石台上，微微歪着头看向镜头。影子轮廓看不清脸，但那人右手无名指上戴着一枚指环，在闪光下反射出一个锐利的轮廓——那枚指环的形状，跟林一凡脖子上的挂坠如出一辙。

“这照片里的挂坠，和我妈留给我的那个一模一样。”林一凡低声说。

赵日天此时已经攀到石台边，他没有注意那台手机，目光直直盯着密室墙角的阴影。那里蹲着一个黑影，一动不动。

不，不是蹲着的。赵日天缓缓伸出手电，光束扫过去的瞬间，黑影的轮廓清晰起来——那是一个用水泥浇铸成的人形，贴墙立着，双臂交叉抱在胸前，面部的凹痕模糊而扭曲，像是浇筑时被什么重物挤压过。

人形的胸口位置嵌着一块黄铜铭牌，上面压印着一行钢印字：

“沈稚冬。生于1959年。卒于2001年。”

林一凡瞳孔骤然收缩。

沈稚冬。母亲的身份卡上写的正是“沈稚冬”。而密室另一侧的墙壁上，有人用炭笔写满了整面墙的“正”字，每一组“正”字下面都压着日期，密密麻麻，跨度从2001年7月20日直到同年12月31日。最后一行“正”字下面，炭笔只画了一撇。

“我妈……她来过这里。”林一凡的声音干涩，“她在这面墙前面坐了很久，画了这些‘正’字，数日子。”

赵日天没有接话。他的目光落在那座水泥人形脚边——那里放着一个铁皮盒，盒盖上的图案与南洞铁板上那只“春”字几乎一致，只是这次更完整：铁皮盒正面刻着一行细若蚁足的字：

“帮我告诉春伢子：第九收容所的‘归零’，不是零号床。是沈稚冬。”

林一凡弯腰拿起铁皮盒，盒盖是活的，掀开——里面放着一把全新的钥匙，通体漆黑，没有锈痕，齿槽却被打磨得异常光滑，像是从未被使用过。

钥匙柄上刻着一个字。

“去。”

“去”字的一撇微微歪斜，刻痕很深，与第三水泥墩盒子里钥匙上那枚微痕完全吻合。

林一凡攥紧钥匙，还没来得及说话，密室顶部传来一声沉闷的震动，刚才爬下来的竖井井壁缓缓合拢，发出铁闸落槽的轰鸣声。他猛然抬头，最后一线光从指缝间漏下，然后彻底熄灭。

黑暗中，那台1147号同款手机又亮起一屏新字：

“第三梯已断。出口在头顶，入口在脚下。归零。”

搏动声在墙壁深处重新响起，比之前更重、更近。

赵日天抬脚踢了踢密室地面，青石板下传来空洞的回响。他蹲下，指尖沿着石板边缘探到一道缝隙，用力一撬，石板松脱，露出一段向下延伸的铁质阶梯，锈迹斑斑，尽头是一扇半掩的金属门，门上用白漆刷着一个巨大的“零”。

林一凡低头看了一眼手机屏幕，那行字的最后还有一行小字，几乎被呼吸灯的闪烁掩盖：

“沈稚冬没有来过。——沈临渊。”

他把手机放进口袋，踏上了那扇铁门前的阶梯，没有回头。

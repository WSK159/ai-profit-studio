# 第12章 咸鱼值兑换：一键完成报告，全组都愣了

下午两点五十分，会议室B。空调开得极冷，白板前挂了一张投屏，钱总坐在最角落的位置，翘着二郎腿，像个等待角斗的罗马贵族。

“规则很简单。”钱总的助理小周把两份需求书放到桌上，“赵工和林工各做一版OA系统的考勤异常检测模块，需求文档一样，时限三小时。最后用自动化测试跑分，分数高者获胜。”

三小时。正常情况下，这个模块至少要做一天。赵日天表情平静如水，双手环抱，看不出情绪。林一凡扫了一眼需求文档，额角微汗。

他会的，上辈子做过类似的东西，但脑子里的实现路径需要优化。三小时不是不行，但很吃力——如果不用系统的话。

【摸鱼系统·提示】
当前咸鱼值：1,850
可兑换技能：中级“一键完成”LV.2（800咸鱼值）
效果：自动生成符合需求的完整代码模块+文档，耗时5分钟
注意：技能使用期间，外部观察者看到你在“发呆”，请确认不会被打扰

三小时，五分钟后交卷，太扎眼了。林一凡眯起眼睛，突然笑了。他又没说要全用系统，他脑子里有底稿，系统只是帮他写完那80%最繁琐的模板代码。剩下的20%，他手动改，改得面目全非，谁也看不出来。

“开始。”钱总按下计时器。

赵日天瞬间进入战斗状态，双手翻飞，键盘声如暴雨敲窗。其他组员大气不敢出，坐在后排看热闹。老王坐在林一凡旁边，手心全是汗，轻声问：“你打算怎么做？”

“先睡觉。”林一凡靠在椅背上，闭上眼睛，双手交叉放在肚子上。

老王：“……”

赵日天抬头看了他一眼，冷笑了一声，手指没停。

谁也没注意到，林一凡的嘴角微微上扬。他的眼前，系统面板正在飞速运转：

【摸鱼空间·开启】
【正在生成考勤异常检测模块核心代码…】
【已完成37%…68%…92%…100%】
【一键完成·已执行】

七分钟后，林一凡睁开眼睛，伸了个懒腰，开始在键盘上修改代码。他不追求速度，每一步都慢条斯理，像是在反复检查每一行逻辑。他从头到尾写了多少行代码，他心里一清二楚。他从摸鱼空间自动生成的4000行代码中，精简到3200行，每一处都改了自己的风格，确保没有“系统痕迹”。

两小时后，赵日天第一个交卷。他的方案跑分93.4。

整个会议室陷入死寂。93.4分，这已经接近完美了。这个模块的满分是100，但在过去的项目经验里，能达到85分就已经算优秀。

“不错不错！”钱总满意地点头，看向林一凡，“林工，你呢？”

“快了。”林一凡盯着屏幕，没抬头。

五分钟后，他敲下回车。“好了。”

测试脚本跑起来，全组所有人都盯着投影大屏，进度条、指标、代码覆盖率、性能损耗……一项项数据弹出来。会议室里只剩下空调的低鸣和键盘偶尔的敲击声。

分数出来了。

97.2分。

所有人都愣住了。连赵日天都停下了正在转的笔，目光死死盯住屏幕。97.2分，几乎是完美。

钱总的表情复杂至极，眉头微微跳动。他看向林一凡的目光里带着一种从未有过的东西——不是赞赏，是警惕。

“好……很好……”钱总干巴巴地笑了两声，“林工，没想到你深藏不露啊。赵工，你怎么看？”

赵日天沉默了几秒，站起身来，走到林一凡面前，伸手。林一凡看着那只手，犹豫片刻，还是握了上去。赵日天的手掌干燥而有力，声音不大，但会议室里每个人都能听见：

“有意思。”赵日天松开手，露出一个似笑非笑的表情，“下次，我还想再跟你玩玩。”

他转身往外走，走到门口，又停住了。“对了。”赵日天侧过头，看着林一凡，“你知道咱俩最大的区别在哪吗？”

“不知道。”林一凡老实回答。

“你是在完成任务。”赵日天语气里带着一丝淡淡的嘲讽，“而我，是在赢你。”

门关上了。会议室里持续静默了三秒。老王第一个站起来，激动得差点把椅子带翻：“卧槽，小林子你——你——”

“嘘。”林一凡按住老王的肩膀，“低调低调，都是祖传手艺。”

但他心里清楚，赵日天那句话不是在放狠话。他在确认一个事实：林一凡，也有系统。

因为只有系统拥有者，才能用那种目光看人——不是看对手，是看同类。

系统适时跳出一行字：

【隐藏任务已更新】
目标：确认卷王系统宿主赵日天的真实意图
当前进度：2/10
奖励：解锁商城隐藏物品“自由”的线索
注：小心，他已经盯上你了。

林一凡低头看着面板，指尖微微发凉。身后，组员们的欢呼声还在继续，但他听见的却是另一句话——系统面板最后闪烁了一行小字，很快便消失了：

【警告：赵日天正在找你。】

# 第252章 天平中央

林一凡的脚刚落回地面，整个人像被抽走了骨架，膝盖一软，差点跪下去。

天平横梁的震颤没有停止，反而愈演愈烈，像一头被激怒的野兽在狭小的暗室里嘶吼。那道贯穿头顶的裂缝，从发丝粗细的细纹骤然扩开成指节宽的裂隙，石灰簌簌往下落，落在陈和平惨白的脸上，落在那张已经皱得看不出原样的“等”字纸上。

没有人说话。

老王最先反应过来，一把拽住林一凡的胳膊，把他从天平边缘拖开三步：“你疯了！你知道刚才那一下意味着什么？”

林一凡喘着粗气，左手还残留着握住石杆时的触感——那根石杆在接触到掌心的瞬间，像是活物一样咬进了他的皮肉，把他指尖的血液都吸了进去。

他低头看了一眼掌心，没有伤口。什么都没有。

系统面板浮现的瞬间，他心跳漏了一拍。

【咸鱼值余额：10,024（持续波动中）】
【当前状态：第三落子者・资格锁定】
【天平刻度——自由：已解锁？％】

一个问号。系统从来没有给过问号。

“我他妈哪知道意味着什么。”林一凡舔了舔干裂的嘴唇，对着老王朝那根横梁努了努嘴，“但你看这玩意儿，像个讲道理的东西吗？”

横梁的震颤渐渐平息，中央位置，一个浅淡的金色刻痕缓缓浮现——三道刻度并列而置：第一道“劳动”，第二道“资本”，第三道“自由”。前两道刻痕边上都有暗红色的血液痕迹，已经干涸，像陈年旧疤。第三道刻痕是全新的，微微泛着光。

“他妈的。”赵日天的声音从角落里传来，沙哑而疲惫，像是一口气跑了十公里，“你们都疯了吧？全疯了吧？”

他没有说“你们疯了”那种鄙视的语气，反而带着迷茫——像一条一直被链子拴着的狗，突然看见笼门开了，站在原地不知道是该走还是该留。

陈和平靠在暗门边的水泥柱子上，空洞的眼眶里终于有了一丝活人的光泽。他嘴唇翕动，像是很久没有说过话的人，好半天才挤出一个字来：“你……做了选择？”

林一凡蹲下来，和他平视：“我选择了什么？”

陈和平没有直接回答。他缓缓抬起手——那只手瘦得只剩骨头，指甲缝里嵌着黑泥——指了指天花板上那道裂缝，又指了指天平中央的金色刻痕，最后，他的指尖停在林一凡胸口：“你把自己放上去了。”

“为什么是你？”钱总终于开口。他摘了金丝眼镜，用衣角擦着镜片，动作很慢，像在掩饰什么情绪。他没有责怪，没有质问，只是问：“为什么是你？”

“因为没人做。”林一凡站起来，拍了拍裤子上的灰，“你、他，系统，你们都在等一个‘适合’的人。但等了三分钟，等了三百年，等的够多了。”

他指了指自己，“我是最懂的。我最懂怎么等。上一辈子等死，这一辈子等活。等别人不如等自己上。”

暗室里安静得能听到水滴声。

老王用力吸了吸鼻子。他眼眶有点红，但憋住了没说什么。他走过去把陈和平搀起来，像老大哥照顾受伤的兄弟：“行了，事情走到这一步，都往前看。”

钱总重新戴上眼镜，语调恢复了那种滴水不漏的商人气质：“落子者已定，天平缺口已锁住。现在的问题只有一个——你手里的‘自由’，到底值多少筹码？”

他看向林一凡，“你要知道，你的咸鱼值，从这一刻开始不再是你的。你是第三落子者，你是‘自由’的棋手。你的每一摸鱼，每一分钟，都会化成天平上的砝码。”

林一凡愣了两秒。

系统面板猛地弹出一行新的提示：

【第三落子者任务已解锁：每获得1000咸鱼值，天平将以1：100的比率兑换为“自由”筹码。当前自由筹码：10.02（3分钟）。】

“三分钟？”林一凡瞪大了眼睛，“我攒了一辈子咸鱼值，就换三分钟自由？”

“是‘三分钟的自由’。”钱总说，“不是给你的。是给所有人的。自由筹码累积到60分钟，天平协议自动作废，劳动神与资本神同时释放所有契约者。你攒了十年、二十年甚至三百年的所有‘人等’，都能真正意义上走出那个等。”

陈和平抬起头，那双空洞的眼睛里，第一滴泪落下来。

“我哥……”他嗓音嘶哑，“等了我二十年。我用这支笔，登记了两万三千七百六十一条命账。但谁都等不到自己想等的人。”

林一凡沉默了。

他看向天花板那道裂缝，像是看向某个不可见的、巨大的、公平的秤。他不知道那个赌局在哪儿主持，不知道劳动神和资本神长什么样——但他知道，这个“三分钟”，是用自己上一世猝死的那一秒钟换来的。

他把拳头攥紧。

“行。”他说，“那我就攒到六十分钟。”

暗门的方向，突然传来一声闷响。

所有人都僵住了。那不是水滴声，也不是裂缝崩裂的声音。

是敲门声。

三下，很有节奏，很礼貌——像是在问“有人在家吗”。

老王的脸瞬间白了。他嘴唇翕动：“这个地下室……负三层……除了我们，没人知道入口。”

敲门声又响了。这一次，更重了一些。

然后响起一个声音，温和、熟悉，像每个周一早上的主会议厅广播——星辰科技总部大老板陈重阳的声音：

“一凡啊，开门。哥等了你很久了。”

陈和平的眼泪戛然而止。他的瞳孔骤然收缩，死死盯着那扇暗门，像是看见了一个不可能出现的人。

“哥……？”他颤声，“他……他已经等到了？”

林一凡觉得自己心脏停了半拍。

大老板的姓氏是陈。陈和平的哥哥，也姓陈。

那个等了二十年的人，就是星辰科技的总裁。

而这一路走来，三年前那位“猝死”，被系统选中的人……也是他挑的。

他抬头看向那扇门，门缝里渗进来一道光。光里浮动着一枚钥匙——010号的影子，正在缓缓转动。

暗门开了。

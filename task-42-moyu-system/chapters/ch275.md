# 第275章 病号服女人

档案室的灯管发出嗡嗡的电流声，光线惨白，像是从医院太平间借来的。林一凡站在门口，盯着那个穿病号服的女人，手心全是汗。

她坐在档案柜旁边的折叠椅上，双腿并拢，手放在膝盖上，姿态像在等公交车。病号服宽大，蓝白条纹，左胸位置印着褪色的“星辰市第一人民医院”字样。头发齐肩，有些干枯，脸上没有妆，眼角有几道细纹。

她抬头看向林一凡，笑了一下。

“你比我预想的来得早。”

林一凡没动，手指已经抠进手机壳边缘。他见过林一诺的照片——在老王给他看的旧合影里，在赵恒发来的加密文件里，在自己那破碎的、无法拼凑的童年记忆碎片里。照片上的林一诺穿着白色连衣裙，笑得很阳光。

眼前这个女人，比照片上老了不少。但那双眼睛，那种笑起来嘴角微微向左歪的弧度，和照片里一模一样。

“你……是我姐？”

女人歪了歪头：“你叫我什么？”

“林一诺。”林一凡往前走了一步，又停下，“我姐。2019年死于意外的那位。”

女人的笑容收了收，低头看了看自己病号服上的名字标签。标签上印着三个字：陈月季。

“我现在叫陈月季。”她站起来，拍了拍裤腿，“你姐死了，林一凡。别被那张脸骗了。”

“那你为什么长得和她一样？”

“整的。”她轻描淡写，“花了不少钱。”

林一凡的拳头攥紧了。他深吸一口气，克制住上前揪住她领子的冲动。系统面板在视野边缘闪烁了一下，他扫了一眼——【警告：情绪波动值升高，建议深呼吸调节。】

他忽略它。

“赵恒让我来档案室看一份文件。他说我被换页了。”

陈月季——或者自称陈月季的女人，指了指档案室最深处的铁皮柜：“第三层，左手边第二个文件夹。编码C-2019-042。”

“你知道得这么清楚？”

“我就是那个——负责把文件换掉的人。”

林一凡怔住。

女人绕过他，走向门口，在门框边停下来，回头看了他一眼：“你姐当年托我办了一件事。她说，如果有一天她弟弟回来了，把这份文件还给他。她说你会知道怎么用它。”

“她……什么时候托你的？”

“2019年6月14日。”

林一凡脑子嗡了一下。2019年6月14日——那是林一诺档案上登记的死亡日期前三天。

他还没来得及多问，女人已经走出门，走廊里传来她拖鞋啪嗒啪嗒的声音。林一凡快步追出去，档案室外的走廊空无一人。尽头是安全出口，门正在缓缓合拢，门缝里飘出一句话——

“告诉赵恒，钥匙不用找了。密码在病历里。”

门合上。林一凡愣在原地。

他退回档案室，走到铁皮柜前，拉开第三层左手边第二个文件夹。里面是一沓纸，最上面是《星辰科技聘用协议（试用期）》，右上角印着“原件已归档”的红章。他翻开第一页，甲方是星辰科技，乙方签的名字是林一凡，但笔迹——

那不是他的笔迹。

他翻到第二页，条款第四条写着：“乙方入职首年不得以任何理由解除劳动合同。特此约定，作为附条件生效条款。”

下面有一行小字，是手写的，用的是蓝色钢笔，字迹娟秀，像女生的字：“一凡，别签这个。你被换了。甲方要把你锁在这里七年。”

林一凡的手指摩挲着那行字。字迹已经有些褪色，但笔力很稳。他翻到最后一页，看到签名栏已经被撕掉了一半，剩下的一半露出“林一诺”三个字。

他盯着那三个字很久。系统面板在视野角落弹出一条提醒：

【检测到关键线索：聘用协议被换页、手写警告、签名残缺。正在整合分析……】
【提示：赵心怡档案显示，2019年6月14日，她曾以“陈月季”之名在某私人诊所就诊。诊断记录：面部整形手术。】

林一凡把协议折好塞进怀里。距零点还有四十多分钟。

他走出档案室，手机震了一下。赵恒的号码发来一条消息：“看到药了吗？”

林一凡回：“看到了。陈月季说钥匙不用找了，密码在病历里。”

对面沉默了足足十五秒。然后赵恒发来一条长消息：“病历是赵心怡的。她有癫痫病史，2017年开始在星辰市第一人民医院神经内科就诊。她死亡证明上登记的死亡时间是2019年6月14日下午2点。但病历显示她在那天上午还复诊过一次——开的药是丙戊酸钠，用于控制癫痫发作。死亡原因写的是‘药物过量’。警方结论是意外。但那份病历上，开药医生的名字被涂掉了，你在上面找找有没有别的痕迹。”

林一凡拿起手机拍下协议上那行手写字的照片，放大。在那行字下方，有一个极淡的铅笔痕迹，像是写了又被擦掉。他用手机闪光灯对着纸面侧照，看到几个模糊的字：

“别信赵恒。”

林一凡的瞳孔缩了一下。他把手机放下，盯着那张纸看了一会儿。纸张边缘微微卷曲，那行铅笔字经过了擦拭，但痕迹还在——“别信赵恒。”

他想起赵恒电话里的声音，想起赵恒说“我守这钥匙十年了”，想起赵恒让他来档案室看这份协议。如果赵恒要骗他，为什么要告诉他这份协议的存在？

但如果赵恒要帮他，那这行铅笔字又是谁写的？

林一凡把纸收好，看了一眼系统面板。当前时间23:17，距离零点还有43分钟。他走出档案室时，走廊尽头的安全门忽然发出“吱呀”一声轻响，像是有人推了一下又缩回去。

他快步走过去，推开门。楼梯间里空无一人。地上放着一张揉皱的挂号单，他把单子捡起来展开，上面印着：

星辰市第一人民医院 神经内科
患者：赵心怡
就诊时间：2019年6月14日 09:30
医生签名处：一个模糊的、被水渍浸开的姓氏——钱。

林一凡盯着那个“钱”字，手指微微发抖。时间一分一秒地流走。距零点还有四十二分钟。他现在面临两个选择：去找赵恒当面问清楚，还是先去找陈月季追问病历的事。他攥紧那张挂号单，跑向楼梯间，向上的方向是18层，向下的方向是地下停车场。他选择了向上。在跑上台阶的瞬间，手机再次震动，是一个陌生号码发来的消息：“林一凡，别去18层。来负一层消防泵房。带上你手里的那张纸。——林一诺。”

林一凡停在台阶上，握着手机的手僵住了。林一诺已经死了七年。但他想起档案室里穿病号服的女人说的话——“你姐死了，别被那张脸骗了。”

那现在发这条消息的“林一诺”，又是谁？

# 第260章 王姐的账本

夜色透过水塔间的天窗洒进来，把走廊切成一条条明暗相间的光带。林一凡站在光与影的交界处，盯着王姐手里的银色钥匙。那把钥匙躺在老人布满老茧的掌心，反射出冷冽的微光，像一条盘踞待动的蛇。

“你刚才说，我前世的死因？”林一凡的声音沉下来，“我死因不就是熬夜加班加出来的心肌梗死？病历上写得清清楚楚。”

王姐摇了摇头：“病历上写的，是医生看到的。但你想过没有——你在那家公司熬了三年，多少人跟你一样熬夜，一样赶项目，为什么偏偏你那天晚上倒下？你记得你倒下前最后一件事是什么吗？”

林一凡下意识回忆起那晚。他记得自己在写代码，记得电脑右下角的时间跳到凌晨两点四十七分。然后他站起身，想去窗边抽根烟，再然后……没有然后了。他的记忆断在那里，像一条被剪刀剪断的录音带。

他不记得自己是倒下的。

“你看，你连倒下的瞬间都不记得，对不对？”王姐像看穿了他一样，慢慢把银钥匙收入袖口，“那不是正常的猝死。你的记忆被剪掉了一截，那是被人拿来补了钥匙井的墙角。”

林一凡后背一阵发凉。

“你怎么知道我记不起来？”

王姐没有正面回答，而是转身从水塔旁的铁皮柜里抽出一个泛黄的账本。账本的封面已经碎裂，用牛皮纸一遍又一遍地糊过，翻开来，密密麻麻的手写笔记从第一页一直排到最后一页。

“我在星辰科技做了二十三年保洁。”王姐翻开其中一页，指着上面一行字，“这是你入职那天，我记录的。你第一天上班，早上九点零七分到工位，下午六点四十二分下班。那一天，你总共被扣了……”她翻动纸页，“四十七分钟‘无效工时’。”

林一凡眉头紧皱：“你一个保洁，记这个干什么？”

“因为我们每一个人，在资本神眼里都有一本账。”王姐抬起眼睛，瞳孔里倒映着天窗洒进来的光，“你记工，我记账。我记的是——谁的时间被偷走了。”

她把账本翻到最后一页。那一页只写着一行字：

“2019年6月12日，林一凡，死亡。”

林一凡瞳孔猛缩。

“2019年6月12日——”他心算了一下，“那是我入职前三年吧？我入职明明是2022年，怎么可能是2019年？你是不是记错了？”

“你确定你是2022年入职的？”王姐反问，“你记得你的入职编号吗？”

林一凡愣了一下。

他当然记得——A-1042，组里的人都叫他“一零四二”。可是，等等，A-1042……他入职那年的应届生编号是从A-1000开始排的，总共招了五十人。如果他是A-1042，那就是第四十二个……可当年招聘简章上写的是“拟招聘30人”。

他的记忆出了裂缝。

“2019年，星辰科技那年也招过一批人。”王姐的语速不急不缓，“那批人编号也是A-1000开头。你入职时拿到的工牌，是那批人用剩的。”

“怎么……可能？”

“你记不记得，你毕业那年领过一次‘预录用通知’？你以为是正式录用？”王姐说，“不，那叫‘储备编制’——你已经死过一次心。但你命不该绝。有人用一把时间钥匙，把你的死亡时间换了。”

“谁会……”

林一凡话说到一半，脑海里浮现出一个人——陈重阳。

王姐看着他变了的脸色，点了点头：“你想到了。陈重阳——但准确说，是陈重阳年轻的时候。他手里那把001号卡片，原本是留给他自己用的。但他把那张卡的时间筹码转成了你的‘复活额度’。”

林一凡彻底愣住。

陈重阳。那个高高在上、冷得像冰砖一样的集团大老板，用自己的一张筹码卡，替一个当时还不认识的人换了命。

“为什么？”林一凡干涩地问。

王姐摇头：“那他没告诉我。但他说了一句话——‘我妹妹也在那批人里。我要救她，就必须让命数链里再搭一条线。’他说你那一届的命数和另一个人有关联。那个人，姓赵。”

赵日天。

林一凡的脑子里像炸开了一道白光。赵日天的卷王系统、被资本神赐予的“卷死别人”的规则——如果赵日天手里有卷王系统，那他是谁的棋子？

“你还想知道009号钥匙？”王姐伸出手，银钥匙再次出现在她掌心，“这把钥匙锁着的，是陈重阳为什么选你的原因。而那个原因，恰好跟你前世猝死的真相有关。”

林一凡深吸一口气，伸出手。

“你需要什么报酬？”

“三年寿命。”王姐说，“我要你前世被扣掉的那三年。不是真正的三年时间，而是那份‘已经死过一次’的经验。你把它交给我，前世的一切就再也不会纠缠你——但你也再也想不起来，你曾经死过一次。”

林一凡沉默了很久。

他不知道这意味着什么。如果他交出那份“死亡记忆”，他还能不能看见系统面板？还能不能理解自己为什么能摸鱼到这么强的地步？

“如果我不交呢？”

“不交，可以。”王姐笑了笑，“但是这扇门后面，你永远进不去。你这一辈子都会有一个疑问：你为什么会活着？你为什么会重生？你凭什么拿得住这套摸鱼系统？”

她顿了顿：“而那个答案，可能是你最后的底牌。”

林一凡攥紧拳头，又缓缓松开。他盯着王姐的眼睛，一字一句地问：“王姐——你是资本神的人，还是劳动神的人？”

王姐的眼神闪了一下。

“我是记账的人。”她说完这句，抬起另一只手指向林一凡身后，水塔间深处那扇紧闭的铁门，不知道什么时候裂开一条缝，里面透出幽蓝的光，像水下探照灯照进黑暗的水面。

“那里面锁着一个人。你进去见他一面，再决定要不要交换。”她用银钥匙敲了敲铁门边框，“他现在在做的事情，比你想的大得多。而且，你认识他。”

林一凡推开铁门。

门后是一间只有不到五平米的狭小房间，正中央放着一张铁架床，床上坐着一个穿着病号服的老头。老头头发花白，满脸褶皱，但那双眼睛却亮得惊人。

那张脸，林一凡见过。

——陈和平。

上一分钟还是植物人、躺在三楼ICU里的陈和平，此刻却坐在负三层的密室里，精神矍铄，手里拿着一台老旧的MP3播放器，耳机线垂在肩膀两侧。他看见林一凡，咧开嘴笑了，露出缺了一颗门牙的牙床：“小子，你终于找过来了。我等了你二十年。”

林一凡回头看了一眼走廊——王姐已经消失了。

铁门在他身后缓缓合拢，发出沉重的一声“当”。门上那柄银色钥匙还插在锁孔里，微微摇晃，仿佛在替他倒数。

陈和平从枕头底下摸出一个笔记本，扔到林一凡怀里：“翻开看吧。这是你前世三天前的记忆——你写下来的。”

林一凡翻开封面，第一行字让他浑身冰冷：

“我是林一凡，死了两次。第三次不能死。”

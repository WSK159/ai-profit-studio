# 第112章 负五层的锁

三人从负三层旧机房出来时，走廊里的声控灯已经坏了三盏，一明一灭地闪烁着，像是在某种看不见的力场里挣扎。

老王走在最前面，银章母体被他攥在掌心里，每走一步，那金属块就发出一声极轻的嗡鸣，像是心跳，又像是某个沉睡的东西在哼唧。他说：“负五层的门在电梯井底下，但电梯早就封死了——走检修梯。”

赵日天扫了一眼墙壁上“一切只为星辰”的标语，哼了声：“你们公司还真是把‘深入地下’玩出了花。”

林一凡没接话。他一边走，一边分出一丝注意力看系统面板。自从赵日天把基因锚点嫁接给他之后，摸鱼系统的属性界面就变得有些不对劲——原本一眼就能看完的数值栏，现在多了几行半透明的文字，断断续续的，像是信号接收不良：


【警告：宿主生物特征异常（71%）】
【共享生命线已建立：双锚点模式·稳定】
【提示：检测到第三方意识残留（来源：断根暗码）】
【提示：摸鱼空间入口封禁中——负五层权限未解锁】

第三方意识残留……他看了眼老王的后脑勺，没说话。

检修梯很窄，锈蚀的铁栏发出令人牙酸的“吱嘎”声。越往下走，空气越粘稠，像泡在某种澄清的胶质里。直到拐过第四个转角，他们面前出现一扇门。

那不是普通的门——整体呈暗银色，没有把手，没有锁孔，表面覆盖着密密麻麻、极其细微的刻痕。林一凡凑近了看，那些刻痕全是数字和符号，一条条像河床里的脉络，汇向中央一枚凹槽。凹槽的形状，和银章母体扩张开来的多边体轮廓一模一样。

“断根暗码。”老王把银章母体举起来，“母体是钥匙，但要匹配记忆才能嵌进去。生者的记忆是起点，半生者的是中继，死灵的——是终点。”他说完，看着林一凡和赵日天，“你俩谁先？”

林一凡吸了口气，伸手，把掌心贴在门面的凹槽旁边。

一瞬间，无数画面从脑海里涌出来，像被人一脚踢翻了积木盒子。他看见了前世——加班到凌晨，屏幕上的代码像蚂蚁一样爬动，最后一根烟夹在指间，火光明灭。他看见了入职第一天的自己，工牌挂在胸前，笑容天真。他看见了周莉站在食堂门口喊他“小凡”，阳光把她的发梢染成金色。

然后是一声剧烈的、像整个地基都被掀翻一样的声音——那些画面全碎了，碎成一条条看不见尽头的根须，朝门面深处生长下去。门面的刻痕亮了，像有火在沿着河床烧起来，从边缘烧到中心，最后停在凹槽边缘。

老王立刻把银章母体按上去。

“咔”的一声巨响——像什么东西被卸下了防线。凹槽张开一道缝，金属纹路朝四面退去，露出一条通往下方的幽深台阶。

然后，林一凡看到了不可能看到的东西。

台阶尽头的暗处，站着一个人——穿着星辰科技的老款工服，袖口磨损了，头发有些花白，正背对着他们蹲在地上，用一根粉笔在石板上划字。

那人写的是他的名字：林一凡。

老王手里的银章母体剧烈震动起来，赵日天的锚点印记也在剧烈闪烁，可林一凡却像被焊在原地一样，死死盯着那个背影——那个背影，他太熟了。

那是前世的自己。

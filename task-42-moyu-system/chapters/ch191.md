# 第191章 钥匙的筹码

黑色商务车在负一层停车场里缓缓穿行，车灯切开昏黄的空气。林一凡靠着真皮座椅的后背，目光落在前排司机后脑勺那块剃得发青的头皮上。车窗外的D区指示灯一格一格退去，像倒数的沙漏。

“林先生倒是配合。”副驾驶座上的男人回过头来，下巴上有一道旧疤，“钱总说，您应该有许多话想聊。”

林一凡没接话。他的手指在膝盖上无声敲了几下，脑子里飞快运转。咸鱼值清零的那一刻，系统界面已经变成一片灰白，只剩下角落一行小字：“感知渠道受限，核心功能待重连。”他现在就是个普通人，坐在这辆不知道会开往哪里的车里。但他脸上挂着那种“我手里有牌”的懒散笑容，这副表情他在前世无数次方案被否时练过，好用。

商务车并没开远。三分钟后，车停在了负一层最深处的一间设备间门口。门推开，里面被清出了个简易的会客区——一把折叠椅，一张电脑桌，桌上放着台老旧的笔记本，边上搁着一杯没动过的速溶咖啡。钱总坐在电脑桌后，穿一件深灰色的商务夹克，两鬓比林一凡记忆中多了不少白发，但那双眼镜片后头的目光却依旧锋利得像刚磨过的刀。

“一凡，坐。”钱总抬了抬下巴，语气像招呼老熟人，“你能主动上来，我挺意外。”

林一凡拉开折叠椅坐下，金属脚在水泥地上蹭出了一道火星似的刺啦声。“钱总搞这么大阵仗，连人力之源都搬出来了，我不配合点，显得不识抬举。”

钱总的手指在桌面上停了一瞬，眼镜片反出一道冷光。“你知道那玩意儿叫什么，知道老周是谁，也知道那台机器在切你的命。”他低下头，看着自己交叠的双手，“那你知不知道，你脑子里那把‘钥匙’到底该怎么用？”

林一凡心里一紧，但面上没露。他偏了偏头，像在打量这间设备间破旧的通风管道：“钱总这么急着问，看来人力之源缺了钥匙也转不起来。您这边时间不多了吧？”

“你倒会反打一耙。”钱总笑了一声，站起身，绕过桌子走到林一凡面前，居高临下地看着他，“行，我跟你摊牌。人力之源的核心需要一把‘活钥匙’来稳定供能。老周当年是绑定者，但他撑不住了，断了半条命才锁住那扇门。你上辈子之所以被抽到灯枯油尽，完全是因为——”

他顿了顿，声音压低，像怕被设备间的回声听见：“因为你身上的那套东西，能代替老周成为新的钥匙锚点。你那套系统，跟人力之源同源。”

林一凡的瞳孔缩了一下。系统同源？劳动神与资本神的赌局……难道起点就在这台机器上？他正想追问，裤兜里的手机忽然震动了一下。他扫了一眼屏幕，老周发来一阵极短的摩斯电码。内容是四个字——

“暗门已开。”

林一凡抬起头，迎上钱总探究的目光。他把手机反扣在桌面，慢慢说道：“钱总，我说过钥匙在我脑子里。这话不假。但钥匙也有两把，一把管供能，一把管存量。你手里那把能不能用，得看你能不能让我活着用完。”

钱总的眉头拧出一个川字。就在他刚要开口的瞬间，设备间外面忽然传来一阵慌乱的脚步声，紧接着门被人猛地拍响——一个年轻男人的声音隔着铁门传进来：“钱总！监控室出事了！人力之源的供能曲线忽然剧烈波动，老周那边……老周那边好像把那台暗门机组全拆了！”

钱总脸色骤变。林一凡握紧口袋里的手机，那杯速溶咖啡的液面在桌面上晃开一圈涟漪。他知道，真正的局，从现在才刚开始。

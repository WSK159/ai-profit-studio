# 第60章 陈年的卷宗

刘维坐在轮椅上的姿态很放松，像在自家客厅招待客人。他手腕上戴着一块老式机械表，秒针走得极其精准。林一凡扫了一眼——04:01，距离短信所说密钥失效，还剩四十一分钟。

他努力压住心跳，问道：“你三个月前不是‘因病离职’吗？刘总的病，就是搬到这间没人管的地下维护间里来养？”

刘维轻轻笑了，笑声像老旧的排风扇在转动：“这间不是维护间，是秦氏最早的机柜总控室，所有测试服务器初代配置都在这里完成。”他转动轮椅靠到墙边一排柜子前，伸手拉开其中一个抽屉，里面整整齐齐码着十几张U盘，“那些被替换过的日志模板，原始版本都在这儿。”

林一凡的眼神落在那些U盘上，又收回来：“宋远桥说模板是假的，你手上这些是真的，所以——复赛现场那套模板，是你们故意放出去的假货，用来钓谁上钩？”

刘维缓缓点头：“钓三个人。第一个你多半猜到了，赵日天——他是卷王系统的持有者，但他在秦氏这个局里，同样是棋子。第二个是钱总。”他说到这个名字时，嘴角明显冷笑了一下，“他三个月前逼我‘因病离职’，因为我不肯帮他做一套无声张监控员工摸鱼时间的功能模块。第三个……”刘维的目光扫过林一凡手中的戒指，“是你。”

林一凡心脏猛跳了一下：“你从一开始就在等我？”

“不是等你。”刘维摇头，从抽屉底层取出一份纸质卷宗，封面上印着一行褪色的蓝色油墨字——（编码：TEST-03B）。他把卷宗放在林一凡面前，“是等这个编号对应的那个人重新出现。连续三个月，每天的凌晨3点，会有一个人影出现在这份卷宗里记录的A栋老机房门口。我以为是你，但后来发现不是你。”

林一凡翻开卷宗。里面的内容不多，但每一条都像针一样扎进他脑子里：TEST-03B项目计划书，签批人落款是秦氏最早的技术总监周明远，而周明远在五年前死于心肌梗塞，死前正在做一批“员工生产力特征分析模型”；卷宗最后一页夹着一张照片，照片上一个穿着秦氏工服的年轻男人站在老机房门口，——那人的脸，和林一凡几乎一模一样。

“这照片……”林一凡的手指按在照片边缘，“拍摄日期是五年前。我五年前还在大学里。”

“我知道。”刘维说，声音很轻，“这也是我到现在都还没弄明白的事。但有一点我可以确定：这局棋里，有人用你的脸在过去五年里出现过至少六次，每一次都出现在秦氏最核心的数据出入口。”

他顿了顿：“刚才那条短信，‘TEST-03B / 04:22’，不是发给你的，是发给五年前出现在机房门口那个人的。你会收到，说明——系统认为你就是那个人。”

林一凡的手机再次震动。这次是一个计时器，倒计时钟面上跳出一个红色数字：00:17:33，而同时，他左手背上那道淡得几乎看不见的纹路开始发热。

刘维也看到了，他皱起眉头：“你身上的系统在触发‘真相条目’了——还剩十七分钟。如果在这段时间之内，你不把那份真正的密钥写进服务器，系统会判定你这次‘摸鱼副本’失败，所有咸鱼值清零，连人带记忆一起……”他做了个手掌翻覆的手势。

林一凡浑身一凛。他明白了，从重生以来所有的任务进度、咸鱼值、技能兑换——全都被同步挂在这条“真相任务”上，而他自己根本不知道这条暗线是什么时候被挂上去的。

“密钥是什么？”他盯着刘维，“你知道，对吧？”

刘维缓缓打开那份卷宗的最后一页，露出一个只有三行字符的表格。第一行是`0422 / TEST-03B / 04:22`，第二行是一串十六位的十六进制数，第三行空着，旁边用铅笔写着一个字——

“等。”

林一凡抬起头，与刘维对视：“等什么？”

刘维把卷宗重重合上：“等站在门口那个人，证明他是五年前那个人，而不是替代品。”

门锁咔嗒响了一声，从外面拧动的声音传来，慢条斯理，像是有人故意放慢动作，给他们留出时间。

林一凡看向时间——00:12:18。

门外传来一个极熟悉的声音：“刘维，三年了，你还没死心啊。”

是钱总。

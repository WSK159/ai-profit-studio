# 第429章 替班的代价

林一凡捏着那张刚吐出来的L-001工卡，指尖冰凉。暗红色的卡片表面还残留着刚打印完的温热，可这颗心却透心凉。

“L打头的编号……”老杨头的声音从身后响起，带着一丝干涩的哑，“小子，你知道为什么这破机子能吐出你的卡吗？”

“因为它早就认识我。”林一凡盯着卡面上那个模糊的头像轮廓，头像半明半灭，看不清五官，却诡异地让他觉得那就是自己。

老杨头沉默了一阵，往后退了半步，仿佛与这张卡保持距离能避免沾上什么晦气：“L是Light的缩写。光明的光。在这条归墟通道里，正经员工卡都带着暗盾印记，锁着人一辈子。但L卡——”

他顿了顿，语气里难得带上一丝动摇：“我见过一次。五十年前，一个姑娘拿到过。”

林一凡倏地抬头：“我母亲。”

老杨头没点头也没摇头，枯瘦的手指摩挲着铁皮门上一道凹陷的锈痕：“你娘当初拿到的是T-001。T是Time，时间。她的命格跟这条通道对上了。至于你——”他终于把目光落在林一凡手里的卡面上，“L是光。你跟她不一样。她替的是时间，你替的是……光。”

“替谁的光？”

老杨头喉结动了动，刚要张嘴，走廊尽头突然传来“嗒”的一声——踩在积水里的脚步声，不是错觉。声音不大，却像一记钝锤砸进空气里，震得铁皮门上的锈屑簌簌往下掉。

“有人来了。”老杨头脸色一变，一把扯过林一凡往白色金属门的阴影里躲，“甭乱出声，看。”

两人贴着冰冷的门板，走廊尽头的黑暗里缓步走出来一道矮胖的身影。钱总。他穿着一件灰扑扑的旧夹克，手里拎着一只红色保温杯，跟公司里那个西装革履的派头完全不同。他在暗红打卡机前停下，弯腰，用拇指在屏幕上摁了一下。

“滴——验证通过。T-042号，值班确认。”

打卡机吐出另一张卡，暗红色，编号T-042。钱总把卡揣进兜里，抬头，对着铁皮门上那道“门卫”的刻字，喃喃道：“第七趟了。老家伙，你还不肯交钥匙。”

老杨头浑身一僵，林一凡明显感觉到他的手在自己腕上用力攥了一下——那意思是：别动。

钱总不紧不慢地转身，目光掠过铁皮门和白色金属门之间的缝隙，停了一瞬。林一凡的心跳几乎要撞出胸腔。可钱总只是笑了笑，低头拧开保温杯喝了一口，然后踩着那串“嗒嗒”的脚步声原路返回，消失在黑暗里。

“呼——”老杨头松了一大口气，后背出一层冷汗，“他瞎的。他看不见咱俩。”

“他不瞎。”林一凡冷静下来，方才那一瞬的惊吓反而让他脑子转得更快，“他是装的。他在确认我来了没有。”

老杨头半信半疑：“你咋知道？”

“他停的那一秒，视线刚好落在这张卡上。”林一凡把L-001卡翻过来，背后有一行极小的、用暗红色墨水手写的字，不是打印上去的——

“薪火不灭，替班之人，照见深渊。”

林一凡盯着那十二个字，脊背一阵发凉。

他忽然想起一件事：“老杨头，你的卡面编号是03，还记得么？”

“记着。T-003。我师父赵铁柱给我的时候就说了一句——‘替班人的编号是顺序来的，你是第三个，但第一个，不是人。’”

林一凡的呼吸猛地一滞。L-001这个编号，意味着他是“光”这个序列的第一个。而这个序列的第一张卡，此刻攥在他手里。那T-001呢？他母亲那张卡——T-001——是“时间”序列的第一张。那T-002是谁？T-003是老杨头。如果卡面的编号是按“替班顺序”来的……

“老杨头，”他的声音压得极低，“你师父赵铁柱，有没有提过二号是谁？”

老杨头愣了一下，皱纹挤在一起，仿佛要拧出一条回忆来。半晌，他缓缓开口：“他说过一回。喝多了，说二号是个女人，手里钥匙攥得比谁都紧，后来她把自己锁进了一间档案室，再也没出来过。”

“……档案室。”林一凡转头望向走廊另一头的方向，“B3档案室。”

老杨头的面色剧变：“你进过那屋？”

“进过。”林一凡没有隐瞒，“三道斜杠，拆封印的步骤。有一道是从那间屋子里面画的。”

老杨头张了张嘴，像是想说什么，又给咽了回去。最后他伸手，从衣襟里掏出一枚生锈的钥匙，递到林一凡面前：“这个东西，我守了四十年。赵铁柱走的时候说，等一个拿L卡的替班人出现，把这把钥匙交给他，让他去开白色金属门后头第三层抽屉。”

林一凡没有伸手接，而是问出一个让老杨头陡然僵住的问题：

“这钥匙，是不是原本在我父亲手里？”

走廊尽头，钱总的保温杯在黑暗中“哐当”落地——那声音隔着一整个世界传来，又像只隔着一扇门。而白色金属门背后，传来三声沉闷的敲击。

笃。笃。笃。

像有人从里面，回应着这个问题。

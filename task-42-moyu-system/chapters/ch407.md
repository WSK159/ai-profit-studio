# 第407章 井口之上

那根手指缩回去之后，井口恢复了死一般的寂静。

林一凡没有犹豫，他一把抓住青铜锁链就往上爬。孙满仓在底下喊了一句：“你疯了？上面有人！”但他没停。他太清楚那根手指意味着什么——锁芯女人的画像不是凭空来的，那是图纸二十七号点的另一条线索，而她每一次出现，都意味着某个“门”要被打开或者关上。

他爬了大约十米，井壁突然开始震动。一种沉闷的、有节律的响声从上方传下来，像是有人用什么东西捶打井沿。他加快速度，手指被锁链上的锈蚀刮出血痕也顾不上。

快到井口时，他扒住边缘探头一看——

井口外面站着一个人。

准确地说，是个穿着灰布褂子的老头，佝偻着背，手里提着一把铁锤，正是他在井口边沿一下一下地敲。铁锤落点处，地上一块方形石板被敲出了一道裂缝，裂缝下面隐约透出一线光来——那光不是日光也不是月光，是冷白色的，像是熔炉里的白炽。

“老杨头大哥。”林一凡低声说。

老头抬起头，露出一张和林一凡记忆中铜脸人画像几乎一样的脸——只是少了那层青铜面具。他眯眼看着林一凡，没有惊讶，也没有防备，只是缓缓放下锤子，问了一句：“你承了那半条命的债？”

“我没承命。”林一凡从井口翻上来，拍了拍身上的水，“我承的是契约本身。”

老头沉默了一会儿，点了点头：“那更麻烦。”

他没有继续解释，而是弯腰把那块石板完全撬开。白炽光芒喷涌而出，逼得林一凡下意识抬手挡住眼睛。等适应之后再看，石板下方是一个垂直的通道，壁上嵌着密密麻麻的铜钉，每一根钉子上都刻着一个数字——从1到27。

“第二十七号点。”林一凡喃喃道。

“图纸没骗你。”老杨头大哥直起腰，目光复杂地看着他，“我当年替钱方远烧掉半张合同之后，这扇门就不准我进了。能进去的，只有新的担保人。”

林一凡皱眉：“你在这里等我？”

“等的不只是我。”老头侧过身，露出身后不远处一块靠在墙边的牌位，上面刻着“沈望未白”四个字，但牌位是空的，没有骨灰盒，也没有遗像。

林一凡心里一紧。他还没来得及追问，通道里忽然传来一声沉闷的敲击声，像是有人在下面敲铜门。紧接着，一道熟悉的声音从通道深处传出来，沙哑而虚弱：

“林一凡……别下来。”

是沈望未白的声音。

老杨头大哥脸色变了：“他什么时候进去的？”

林一凡没有回答，直接纵身跳了下去。

通道不深，大约三四米。落地的瞬间，他看见沈望未白半跪在一扇巨大的铜门面前，右肩有一道深可见骨的伤口，血染红了半片衣襟。铜门闭合，门缝里卡着一根青铜钉——和他在铁皮壳子锁眼处看到的那根，一模一样。

“走了……”沈望未白喘着气说，“那半条命撞开了门，跑进锁灵界深处了。它带着债务主体，你追不上。”

林一凡蹲下来扶住他：“你的伤——”

“不是它伤的。”沈望未白咬着牙指了指铜门后方的黑暗，“是我在门后看见了老杨头。”

林一凡顿住，老杨头大哥在上面明明还活着。

“他托我带一句话给你。”沈望未白抬起头，眼眶微红，“他说：图纸27不只是坐标，还是换命的位置。如果有一天你走到那里，让他替你把最后一根钉子钉进去。”

林一凡怔住了。

他缓缓抬头，看向铜门门缝里那根青铜钉。紧接着，他胸口的白骨纹章忽然剧烈发烫——数字从28跳回27。

他猛地想起上一世那一夜，他在加班猝死前看到的最后一行代码。注释里写着一句话：“门在门后，钉在钉里。”

那个注释名作者，就是他自己。

# 第362章 妹妹的名字

门内房间不大，约莫十几平米，四面都是粗糙的石壁，头顶一盏昏黄的感应灯亮着惨白的光。

林远山坐在轮椅上，身形消瘦得厉害，颧骨高耸，眼窝深陷，头发已经白了大半。但他的眼睛还是亮的，那种亮光让林一凡心头猛地一震——他在镜子里见过这双眼睛，那是他们父子共有的神情。

“爸。”

林一凡的声音有些发涩。他重生以来经历了无数离谱的事，但眼前这一幕依然让他觉得像在做梦。

林远山微微点头，没有说话，目光却在林一凡脸上停留了很久，像是要把这十八年的空白都看回来。

阿秀站在门边，轻声道：“林大哥，时间不多，你们聊。我在外面守着。”

门轻轻合上。房间里只剩下三个人。

赵日天难得安静地靠在墙边，目光在林远山和轮椅扶手上的铜纽扣之间来回扫过。

“那颗扣子，是你留下的吧。”林远山终于开口，声音沙哑，像是很久没有说话，带着金属摩擦似的干涩。

林一凡点头，蹲下身，平视父亲的轮椅：“你给我留的路标，从云顶山脚一直到第三铁门，一路都是这东西。”

林远山枯瘦的手指攥紧了扶手上的铜扣，沉默了一会儿：“十八年前，我从云顶山密道出去的时候，沿途钉了三颗。我以为不会有人能找到。没想到是你。”

“妈呢？她……她是不是知道你还活着？”

林远山的眼皮重重一跳，半晌才开口：“你妈给阿秀留了录音，你听过了？”

“听过了。”林一凡盯着父亲的眼睛，“她说‘春来江水’不是诗，是我妹妹的名字。林春来，辰时生，七斤二两，出生当天被人抱走了。”

林远山的嘴唇抿成一条线，眼里涌起一层水光，但他憋住了。他缓缓转动轮椅，从身后一张铁架床上拿起一个锈迹斑斑的铁皮盒，盒盖上刻着一个“春”字。

“这个盒子，是你妈当年让我收着的。她说……等春来回来了，才准打开。”

林一凡的心狠狠揪了起来。

“爸，妹妹她——”

“还活着。”林远山的语气很笃定，但这种笃定里藏着一种令人不安的寒意，“但她被抱走那天，你妈在产房门口看到了一样东西。”

“什么东西？”

林远山沉默了几秒，一字一字道：“一枚陶土徽章，上面刻着数字‘27’。”

林一凡瞳孔骤然一缩。陶土徽章。他在云顶山另一条通道里见过一模一样的，编号也是“27”。那是父亲失踪前留下的唯一实物线索。

“你见过？”林远山捕捉到了他的反应，猛地抓住他的手腕。那只手瘦得只剩下一把骨头，力气却大得惊人，“在哪儿见的？”

“云顶山下面，第三梯还有一条通道，墙壁里嵌着那枚徽章。”林一凡反手握住父亲的手，“爸，那个‘27’到底是什么？”

林远山的呼吸明显急促起来，胸口剧烈起伏了几次才平复下来：“‘27’是收容所的编号。春来被抱走那天，你妈在产房门口的陶瓷碎片上看到的。她一直以为是我安排人干的。”

“是你安排的吗？”

林远山苦笑着摇头：“如果是我安排的，我何必躲十八年？”

他的另一只手从轮椅侧袋里掏出一样东西——半张泛黄的照片，边缘被撕得参差不齐。照片上是两个年轻人站在一扇铁门前，铁门上方有明显的“26”字样，和这间房间门上刻的字一模一样。

“这地方每扇门都有编号。我当年在‘26’号房间藏了一个人，那个人……”

林远山的声音突然变了调，像是用尽了全身力气才能说出下一句话：

“那个人就是抱走春来的人。”

林一凡的心跳骤然加快，他刚要追问，门外忽然传来阿秀急促的声音：

“有人来了。不是自己人。”

林远山脸色猛地一变，伸手把那块绣“春来”二字的布料和铁皮盒一并塞进林一凡怀里：“拿着。往南边的洞走。记住——‘唯一性物品’不是指东西，是指人。你妹妹身上有一件和你完全一样的东西，那是你们相认的唯一凭证！”

“什么——”林一凡来不及问完，门外的脚步声已经清晰可闻。

赵日天身形一闪，贴到了门边，压低嗓音：“三个人。带枪。”

林远山一把抓住林一凡的衣领，把他拉到跟前，急促地在他耳边说了几个字。

林一凡愣住了，呼吸都停了一瞬。

“快走！”林远山猛力推了他一把，“你活着，春来才有机会活着！”

林一凡被赵日天扯着胳膊冲向房间深处一道暗门。他回头最后看了一眼。父亲坐在昏暗的灯光里，那只枯瘦的手慢慢抬起，朝他做了一个——外人看不懂的手势。

那是他们小时候约定的暗号。意思是：“记住了吗？”

林一凡咬着牙，低声道：“记住了。”

暗门合拢。黑暗中，他攥紧手里那块绣着“春来”二字的布料，指尖微微发颤。父亲刚才在他耳边说的话——

“你妹妹的右手腕内侧，有一块和你一模一样的浅褐色胎记。形状像一枚铜钱。”

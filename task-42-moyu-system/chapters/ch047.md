# 第47章 门禁卡上的指纹

第二天一早，林一凡提前四十分钟到了公司。他没急着上工位，而是拐进A座一楼的消防通道，把那张宋远桥办公室门口捡到的门禁卡翻出来，对着晨光仔细端详。

卡面是普通的白色塑料，芯片区域有一道浅浅的划痕。他屈指弹了弹卡面，又用指甲在边缝里一挑——卡片分层了——有人在原卡上贴了一层高精度复制膜，膜里嵌着干枯的导电胶残留。正面边缘残留着半个淡紫色指纹，小指侧，位置像极了刷卡时习惯性用拇指扣卡、小指贴边的人。

林一凡把卡收进内兜，上了电梯。

二十三层的灯光已经全亮。他路过D3-B1机房门口，看到透明玻璃门上贴了一张新的A4打印纸：`安全部通知——D3-B1区块数据完整性核查，即日起禁止任何未授权人员进入。`

他脚步没停，进工位坐下，打开电脑。刚亮屏就弹出一条内部邮件，发件人是宋远桥，标题带了三个加粗感叹号：

`关于D3-B1运维日志丢失的初步调查通报！！！`

邮件正文写了四百多字，措辞官方而克制，但核心意思却明晃晃挂在第二段：“经初步排查，运维日志最后一次正常写入时间为上周五晚，删除操作用于上周五23:47，执行来源指向A座二十三层内部账号。安全部将于今日上午十点对相关人员进行协助核实。”

他没点名，但整层人都知道——上周五晚加班到23:47的人，整个二十三层只有林一凡。

工位上方的灯光嗡嗡响着，林一凡把邮件拉到最底，看到系统自动附带的审计截图：删除记录、执行IP、操作时间。他盯着那张截图看了半分钟，猛地眯起眼睛。

截图右下角有一条白色反光带，是手机翻拍屏幕时才有的摩尔纹。而那条反光带刚好遮住了日志来源的MAC地址后四位。

有人在宋远桥的电脑上“删”了日志，然后用手机拍下假截图发给了他。

林一凡嘴角勾了一下，正要关闭邮件，余光瞥见屏幕右下角的微信图标疯狂跳动。他点开，满屏蓝色消息刷下来——是老王的语音轰炸：“一凡！你来看！出大事了！”

他刚起身，赵日天从身边的工位站起来，斜靠在隔板上，压低声音：“看完了？”

“看完了。”

“那你应该也知道，他十点约的是你。”赵日天递过来一个牛皮纸信封，“这个你拿着，进了安全部再看。”

林一凡接过信封，触手很薄，像是只装了一张纸。“你哪来的？”

赵日天没答，只抬手用食指点了点自己的太阳穴，然后转头走回工位，留下一个吊儿郎当的背影。林一凡低头看了信封一眼，封面空白，封口蜡没有粘牢，一掰就开。他把信封塞进外衣内兜，回座收拾了一下电脑，然后大步走向安全部。

九点五十七分，他敲响了安全部办公室的门。

门开了，里面坐着一个戴黑框眼镜的中年男人，面前摆着三台显示器，桌面上摊着一份文件。林一凡一进门，那男人的目光就从眼镜上沿翻出来，面无表情地打量了他一眼：“林一凡？”

“是我。”

“坐。”男人用下巴点了点对面的椅子，“陈哲，安全部主管。”

林一凡坐下，没开口。陈哲也没急着问话，先从抽屉里摸出一个透明证物袋，里面装着一块深绿色的硬盘，边上贴着黄色标签：`D3-B1区块物理备份-副本A`。

“认识这个？”

“知道，D3-B1的备份盘。”

“上周五晚23:47，有人通过远程指令删除了这台机器上的运维日志。删除命令的签名密钥指向一个内部账号，而那个账号的登录时间是23:40到23:53，只用过一次。”陈哲把屏幕转过来，上面是一个极简的表格，“你想不想说点什么？”

林一凡看了表格一眼，心里咯噔一下。账号显示名只有两个字：

`沈敛`。

沈敛的账号，在沈敛离职半年后，于上周五深夜“登录”并删除了日志。这意味着什么？要么账号被克隆了，要么有人在数据库层面伪造了登录记录。但更关键的是——沈敛早就把证据藏好了，他根本不需要删除任何东西。这个“删除”是有人在栽赃，也是一个信号。

林一凡没急着回答。他摸了摸内兜里的牛皮纸信封，指尖触到一层薄薄的硬纸——信封里装着的，是一张打印出来的人事记录，唯一的内容是一行字：

`宋远桥，入职前就职于秦氏集团数字化安全部，任高级数据监理。`

门禁卡上的指纹、宋远桥的履历、被“删”的日志，“协助核实”变成了一个巨大的舞台。林一凡抬头看着陈哲，缓缓开口：“陈主管，我想先问你一个问题——秦氏集团那位内部接口人，你认识吗？”

陈哲的手微微顿了一下。

# 第355章 铁皮棺材

板车在离他们三米远的地方停下。推车的人穿着一件灰色旧棉袄，头戴草帽，帽檐压得低到看不清五官。他没有说话，双手从板车龙头上松开，退后一步，站定。

隧道里的空气凝滞了一瞬。铁皮棺材上的铜牌反射着手电光，那九个小字像一排水滴挂在光刃上。

"等号人，二十七。"林一凡念出那几个字，目光没有离开棺材，"这个'号'，是编号的号，还是号码的号？"

灰衣人没有回答。他抬起手，指了指棺材盖的缝隙，然后倒退两步，整个人融入隧道壁的阴影里，消失得无声无息。

"别动。"赵日天按住林一凡的肩膀，声音压得极低，"我刚才看他脚的时候——他没穿鞋，脚是光着的。但踩在碎石上的时候没有发出一点声音。"

"不是人？"林一凡问。

"是人，但不是正常走路的人。"赵日天松开手，"在这城里，能无声走路的人只有两种——练过的，和死过的。"

孙满仓从棺材侧面绕过去，目光扫过铁皮表面。他伸出手，指尖轻轻搭在棺材盖的边缘，停顿了半秒，然后猛地掀开。

棺材里没有尸体。

里面放着一块普通的青石板，石板上放着一根锈得发黑的铁轨断头，切口整齐，像被什么极其锋利的东西一刀切断。铁轨旁还有一枚陶土徽章，同样的第九组、第二十七号，但上面的数字像被重新刻过一遍，笔画比先前那枚粗糙得多，像是有人用指甲在泥坯上硬画出来的。

"断掉的铁轨。"林一凡低声说完，看向孙满仓。孙满仓盯着那根铁轨断头，眉头皱得很紧。他伸手指了指断口的横截面："这不是力气切的，是水切的——高压水刀。三十年前哪儿来的水刀？"

"还有这个。"赵日天从铁轨下面翻出一张烟盒纸，人字形拆开，上面用铅笔写了一行字，字迹歪歪扭扭，像是仓促写就："第九组的门，只能用第七枚钥匙开。第七枚在云顶山北麓第三梯下方通道，往下十三级，水泥台底下压着。"

林一凡的手机突然震了一下。他低头一看，屏幕上跳出一行字，但这一次不是来自系统的任务提醒，也不是邮件——是一串六位数字：1147。

"又是1147。"林一凡把屏幕转向另外两人，"上次是老头的信，这次是直接给我发消息。他还知道我们在哪儿。"

赵日天盯着那串数字，忽然扭头看向灰衣人消失的方向："那人不一定是送信的，也可能是来确认棺材被发现的。"

隧道里再次传来一声闷响，比刚才的更重，震得脚下的碎石子跳了起来。紧接着第二声、第三声，整个隧道像被什么东西从深处捶打，越来越密集。

"走。"孙满仓把铁轨断头塞进怀里，青石板也不要了，一把抓起那枚陶土徽章，"棺材是饵，人快到了。"

三人顺着来路狂奔出隧道口。夜色已经完全笼罩云顶山，远处的城北街道灯火模糊。铁门后面，隧道深处的闷响还在继续，但在风声里夹杂着另一种声音——金属摩擦金属的尖锐刮擦，断断续续，像一把刀在铁轨上来回磨。

孙满仓的脸色一下子变了。

"师傅教过我，这声——是有人在切锁。四棱锁是用来锁门的分岔，五棱锁是锁命的。"他低声道，"但这是三棱锁的声音。三棱锁人。有人想从隧道里出来，门口被堵住了。"

"棺材是饵，"林一凡额头渗出汗，"隧道里的人才是目标。那灰衣人不是来送棺材的，是来封路的。"

赵日天已经把枪掏了出来，目光扫向隧道口："我管他是来封路的还是来开路的——他把我们引过来，又把我们堵在这儿——这座山，从里到外，都是局。"

远处，隧道里磨铁的声音戛然而止。然后是一声清晰的、像白铁皮被从天而降的巨力拍扁的巨响——三棱锁，断了。

一股带着铁屑和尘土的风从隧道口喷涌而出。借着月光，他们看见隧道深处有一盏豆大的火苗在晃动，缓慢地、稳定地，向他们走来。

孙满仓攥紧怀里的铁轨断头，声音沉得如钟："找一根断掉的铁轨——原来沈临渊根本不是让我们去找。是让我们去接。"

# 第206章 全员大会的意外来宾

第二天早上七点四十分，林一凡走进园区大门时，已经发现气氛不对。

平常这个点，园区中央广场上只有零星几个买咖啡的早鸟。但今天，广场上拉起了红色横幅——“新绩效·新效率·新未来”，营销部的姑娘们穿着统一制服，正站在大厅门口布置签到台。几个穿黑西装的安保人员占据了主通道两侧，目光紧盯着每一个经过的员工。

他脚下一顿，往旁边的小花坛绕了半圈，掏出手机给老王发消息：“大会怎么回事？”

老王回复得很快：“昨天半夜定的，全员+各分公司视频连线。听说钱总请了‘外部专家’来解读新方案。”

外部专家。林一凡默默把这四个字咀嚼了一遍，心里莫名地不安。他走进A栋大厅时，正好碰上扛着摄像机往里走的行政部同事，对方压低声音说了一句：“一凡，今天赵日天也来。”

赵日天。那个卷王，被他亲手拆穿“和资本神做交易”的人。按道理，反噬期的赵日天应该还在医院躺着。

林一凡拧眉，没接话，快步走向三楼会议室。全员的座位都重新调整过，按部门隔出一个个区块，靠前的位置留给高管，而最后排摆了四排临时加座——坐着一群陌生的面孔，统一深蓝色外套，胸前别着同款徽章，手里的笔记本全开着，像是随时准备记录什么。

他心里咯噔一下，压低声音对旁边刚坐下的组长程晨说：“最后一排那帮人是谁？”

程晨用余光瞥了一眼，嘴唇几乎没动：“总部审计组。这次大会，看来不是简单的绩效宣讲。”

九点整，钱总走上台，西装笔挺，精神头比前两周好了不止一截。他身后的PPT第一页写着：“星辰科技2026年度新版全员增值激励方案。”

方案的核心概括起来就三条：第一，全员实行“目标量化制”，每天产出评分排名，末位5%扣发季度奖金；第二，引入AI行为监测2.0版本，全时段捕捉无效工作时间——他把“无效工作”四个字念得极重，大屏幕还配了一个卡通小人摸鱼的动画，会场里响起稀稀拉拉的笑声；第三，所有中层干部每季度竞聘一次，以KPI数据为准，不讲资历。

底下开始有交头接耳声。林一凡注意到最后一排的审计组人员在钱总念到第二条时，主动低头记了几笔。

“以上方案，”钱总放下话筒，目光在会场上扫过一圈，“由权威的第三方管理咨询公司提供数据支持。同时，我们特别邀请了一位‘实战专家’，来和大家分享一下他对这套模式的应用心得——大家欢迎，赵日天先生。”

全场哗然。

赵日天穿着一套熨得笔挺的西装，从侧台走出来，步伐沉稳，脸上挂着温和的笑容。林一凡几乎不敢相信自己的眼睛——之前在数据中心的仓库里，赵日天可是整个人的精气神都被抽空了，连站都站不稳的。

但此刻的赵日天，容光焕发，眼神锐利。他站在台上，目光扫过观众席，最后准确无误地落在林一凡的位置上，那目光平静得都不正常，像是在看一个素不相识的人。

“各位同事。”赵日天的声音通过麦克风传递开，清晰而有力，“我来到星辰科技三个多月，亲眼见证了什么叫真正的效率。今天我要分享的第一件事——”他顿了顿，从口袋里掏出一张折叠的纸，展开，“是这家公司的‘摸鱼效率排行榜’。”

屏幕上打出了那张纸的内容。上面的数据密密麻麻地排列着，但林一凡一眼就发现，这些数据和他之前见过的公司内部统计完全不同，每个员工的名字后面多了一列“摸鱼系数”，由AI采样的时间戳计算而来——而排在榜单第一名的那个名字，赫然就是他自己。

林一凡的后背一紧。

“这一列的系数，不是拍脑袋想的。”赵日天的声音不轻不重，却让整个会场安静了下来，“是AI行为监测2.0版本在过去三十天里，对全园区所有工位的动作捕捉数据，经过78个维度交叉验证得出的。我们这位第一名——”

他看向林一凡的方向。

“在上班时间，累计离开工位时间高达213个小时。平均算下来，每个工作日有6.8个小时不在工位上。”

全场安静了整整三秒，接着像烧开了的水一样炸了锅。

林一凡的脑子飞速转动，但他发现问题的关键不在于这个排行榜本身，而是赵日天公布它的时机——在钱总刚宣布完“末位5%扣发奖金”的新方案之后，用这种方式把“摸鱼”钉在公众的耻辱柱上。

他正想站起来反驳，口袋里的手机震了一下。他低头一看，是一个未知号码发来的短信，只有一句话：

“左胸口袋。”

他下意识地去摸外套左胸口袋，那里不知什么时候多了一张叠得极小的纸条。他趁着周围人的注意力都在大屏幕上，不动声色地翻开纸条——上面是一行工整得不像人写的字：

“赵日天现在用的不是自己的声音。他在替别人说话——把新方案念完，然后离开园区。去坐标点，别让钥匙离身。”

林一凡猛地抬头重新看向台上的赵日天，此刻对方正微笑着回答一位高管的问题，语速平稳、台风老练，和之前那个暴躁激进的卷王简直判若两人。

那个被抽干精气的赵日天，如今站在台上如同一具被精心操控的木偶。

而纸条上的落款，画的是一枚简笔的硬币图案，金杯朝上。

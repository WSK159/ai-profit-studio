# 第173章 凌晨三点的灯光

林一凡的身体砸在气垫上，发出一声闷响。他来不及感受后背火辣辣的痛感，翻身就滚下了气垫边缘，贴着地面蹿进了绿化带。四辆车里钻出七八个西装男，打着手电朝这个方向扫，但气垫带来的阴影成了天然屏障——等他们绕过垫子跑到绿化带边上时，林一凡已经翻过了围墙。

围墙外的巷子是他在上一世干了三年活才知道的“外卖通道”，窄得只能走电动车。他弯着腰快步穿行，心脏在胸腔里擂鼓一般跳。手机屏幕亮起，凌晨两点四十七分。离“凌晨三点”还有十三分钟。

他冲进那间叫“不加班”的咖啡馆时，收银台后面的年轻姑娘正低头刷手机。店里空无一人，只有角落里一台老式唱片机吱呀呀地转着。“打烊了。”姑娘头也不抬。

“我约了人。”

“谁？”

“不知道名字。但这个点儿还让你等着的人，一定值得等。”

姑娘终于抬起头，上下打量了他两秒，起身走到后门，掀开一道帘子：“里面请吧。已经有人到了。”

后间没有开大灯，只有一张圆桌和一把落地灯。季敏坐在灯下，面前放着一台合上的笔记本——她剃了短发，贴在头皮上露出颧骨，比上次在旧仓库见面时瘦了一圈。

“U盘。”林一凡没有寒暄，在她对面坐下。

季敏把桌上的U盘推向他：“我花了四天才解开第一层加密。里面有一个片段，是老王在离职前存的监控录像。”

“老王？”

“他离职前一周，在顶楼机房待过三小时，拍的。”

季敏没有播放录像，只把屏幕转向他。监控画面里，老王蹲在一面金属墙前，手中拿着一把黄铜钥匙，缓慢地插进一个锁孔里。画面定格的瞬间，钥匙尾部反射出一圈微光——锁孔周围的金属盖上，刻着一只对称的眼睛，中间一道竖线，左眼半开。

黄铜钥匙。半开之眼。钱总手中的那把，也是这样。

“这面墙在顶楼，不是服务器机房的门。是机房后面，还有一层空间。老王拿钥匙开了门，走进去，监控就断了。”季敏的声音很轻，“他出来的时候，表情管理得很好，但我放大了他的手指——手背上的青纹，比之前深了。”

林一凡胸口一紧。老王辞职后一个月就失联了。他重生前，公司给的说法是“老王因个人原因离岗，去向不明”。而上一世的林一凡死之前最后一个信息，是老王发来的，只有两个字：“别去。”

“你告诉我这些，是要我别去顶楼。”

“我是要告诉你，这个局不止钱总一个人在做。”季敏合上电脑，“赵日天前天找过我。他手里有一套算法，能算出那把‘时空锁’的双锁机制——他在找第二把钥匙。”

“你要我跟他合作？”

“我要你搞清楚你到底在为什么而跳。”季敏直视他的眼睛，“你打的这辆车的方向盘，是我给自己留的后路。但如果你拿不到第二把钥匙，再多的后路都白搭。”

她站起身走向后门，拉开门时顿了顿：“老王在你重生那天，顶楼那面墙的门，开过一次。三秒。他走时只留下一句话——他说，第三把锁的钥匙，从来不在公司里。”

门合上。

林一凡盯着桌上的U盘，手机亮起：凌晨三点零四分。咖啡馆里那台老式唱片机转完一面，自动停了。窗外，一辆深灰色的商务车缓缓停在路边，车灯闪了两下。车后排车窗降下，露出一张他熟悉的脸——赵日天。

赵日天抽烟，眯着眼看他：“聊聊？”

# 第31章 创投论坛的最后一排

论坛设在国贸大厦三十八楼的宴会厅，林一凡提前两个小时到场，穿着一件老王塞给他应急的西装——那西装肩线宽了一寸，袖口短了半截，怎么看怎么像借来的丧服。他在签到处核对完身份，工作人员递给他一块印着"嘉宾"二字的名牌，脸上却带着意味深长的笑容。

"那位是星辰科技的人吧？"后排有人压低声音。

"就是被联合封杀的那个摸鱼组长，听说全行业都拉黑了。"

他没回头，径直走进会场。三分钟发言被安排在圆桌论坛之后的"自由路演"环节，顺序排在第23位。林一凡扫了一眼议程表，往最后一排角落里一坐，倒像是来旁听的。头顶的空调出风口嗡嗡地响，他盯着台上主持人调试话筒的背影，脑子里飞快转着。

老王的信息十分钟前刚发过来：钱总今天上午约了创投论坛的总冠名商吃饭。

"他打算撤你的发言名额？"林一凡回复。

"不确定，但冠名商跟他关系走得很近，你最好有Plan B。"

他没有Plan B。或者说，他唯一的Plan B就是不管三七二十一，等轮到他发言时直接冲上台去抢话筒。可如果冠名商提前在名单里把他划掉，工作人员在入口处就把他拦下了。

手机又震了一下，这回是个陌生号码。他接起来，对面是个女声："林一凡先生吗？我是星海数据的法务，我们注意到您在朋友圈提到的'版权护体'，请问您对数据外传一事有了解吗？"

他心跳漏了一拍："你们钱总让你们打的？"

"钱总？我们已经跟钱总解约了。"女声顿了顿，"星海数据被人举报向境外服务器传数据，我们正在自查。有人发了一封匿名邮件，里面提到你是最早签字确认过数据传输流程的人。"

林一凡攥着手机的手微微发冷。他确实签过——入职第三周，钱总让他签过一份数据授权单，说"走个流程"。他当时连内容都没仔细看。

"邮件里没有署名，"女声继续说，"但我们查了文件的元数据，IP归属地在贵公司内部。所以想先跟您确认一下，您有没有相关的备份？"

他吸了口气："你们打算报警吗？"

"如果确认是黑客行为，会上报网络安全部门。"

挂断电话，林一凡感到额头沁出一层细汗。他抬头看了一眼会场门口——两个保安正站在闸机旁边，其中一个手里捏着一张打印纸，正低头跟工作人员核对什么。他眯起眼睛仔细辨认，那张纸上的照片，跟他的工牌贴照一模一样。

来的路上老王说过一句话："论坛的冠名商是蓝桥科技，蓝桥科技的老总跟钱总是大学同学。"

林一凡站了起来，往洗手间方向走去。路过闸机时，保安的目光扫过来。他神色如常地打了个哈欠，往左拐进走廊。

洗手间里空无一人。他走到最里面的隔间，锁上门，靠在瓷砖墙上盯着天花板。窗外是三十八层的城市天际线，云层压得很低，灰蒙蒙的，像是要下雨。

他必须让星海的邮件和"版权护体"这些事都等他发完言再说。

他看了看表：距离自由路演环节还有一个半小时。他打开手机备忘录，把已经写了三遍的发言稿从头到尾又默念了一遍——他只剩这一个机会了。

就在这时，外面传来两个男人的谈话声："你跟主持人打过招呼了？"

"打了，第23位改成23位之后加个'待定'。到时候就说是现场调度问题，让他等，等完再让他上——等完这一场，创投论坛就结束了。"

笑声很轻，夹着水流声，很快又断了。

林一凡低下头，看着手机屏幕上那行字——"第23位：林一凡（待定）"——干笑了两声，把手机放回兜里，按亮了隔间门锁。

他没回会场，而是推开消防通道的门，爬了一层楼，在安全出口看见那台工作人员用的笔记本电脑还开着，屏幕上正是嘉宾名单编辑界面。

他敲了敲自己的脸，把手伸向键盘。

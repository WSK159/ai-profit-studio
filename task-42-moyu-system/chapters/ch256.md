# 第256章 秤上的赌局

门被撞开的声音像一声闷雷，震得地面都在抖。小屋里面那扇小门整个飞了出来，砸在对面的墙上碎成几块。烟尘中，一个硕大的银色天平从门后缓缓升起，悬在走廊正中央，两端的托盘上下轻微晃动，发出金属摩擦的“咔咔”声。

林一凡看清了天平全貌——它比钱总桌上的那台旧秤大了十倍，支架上密密麻麻刻着名字和数字，像是一笔笔陈年的账。最顶端悬着一根黑金相间的指针，正在0与1之间来回摆动——仿佛在两个神明之间摇摆不定。

钱总的脸色骤变，他猛地往前冲了一步，却被什么东西挡住了——李思不知何时已站到金属门框边，从口袋里掏出一颗银色的线圈扣在门缝上，老周对讲机里传来电流声：“李姐，锁住了，最多三分钟。”

李思盯着钱总：“我们走到这里不是为了被清算的。三分钟，你够不够把话说完？”

钱总的呼吸急促了一瞬，随即肩膀慢慢塌下来。金色光纹在他瞳孔中闪烁，像是被什么强行压制。他深吸一口气：“二十年前，我也和你们一样年轻。我也拿到了钥匙。我也以为我可以改变那杆秤的平衡。但我签了那份契约——把系统给的全部咸鱼值兑换成‘市场等价物’，换来了星辰科技的控制权。结果呢？”

他将那文件夹一角的水渍翻给众人看：“那滴泪，是那个女人留下的。”

“谁？”

“陈建国的妹妹。那年她代替他签了另一份契约，把命押给了秤房，才保住了老陈的魂没有彻底散掉。她至今还在负三楼的档案室底层躺着——不是死，也不是活，是一种介于账本和活人之间的状态。”

赵日天低骂了一声：“操，负三楼？我们上来的路上经过的那道铁门，钥匙孔就是010号？”

陈建国猛地抬头，脸色惨白：“010钥匙……在她手里？她没死？不对——那天晚上她就在秤房门外，我把钥匙递给她，她说明天还给我——结果第二天她就消失了。我一直以为她……”

“她替你活着，但活得很薄了。”钱总的声音干哑，“那杆秤就是她的锚。你还有最后一个选择，老陈：你用你的命根子——那条还剩几年的命——去秤上换她回来。但换她，你就必须替她站到秤上，永远成为秤的一部分。”

陈建国佝偻的背慢慢直了起来。他没有看钱总，也没有看林一凡，而是走向那个巨大的银色天平。左手按在空着的托盘上，右手伸进维修工服内袋，掏出一把塑料柄的小刀，刀刃上刻着一行小字——姐姐的钥匙。

他转过头对林一凡说：“第十三层只有三把钥匙，010在你手上。那把钥匙开的不是这扇门，是她的门。她叫陈和平。”

系统的提示音在林一凡脑海中响起：【隐藏任务触发：陈和平的锚。用010钥匙打开负三楼36号档案柜，可解除陈建国的‘命债’绑定。但——解锁条件是：使用者必须放弃一件自己最珍视的东西。选项：1.放弃‘前三年’的记忆（忘记重生前的一切）；2.放弃‘咸鱼值商城’的永久使用权；3.放弃……‘自由协议’的候选资格。】

林一凡的手微微发抖。他看向陈建国，陈建国已经把那把小刀放上托盘，刀纹上的字在灯光下泛着暗红的锈色。天平的一端慢慢下沉，悬空的另一端翘起，一枚硬币从顶部滚落，掉在地上翻滚了几圈，停在一个数字面前——

系统同步弹出：【劳动秤读数：陈建国，命债余额——剩余73天。与赵日天倒计时同步。】

赵日天的面色一下变得铁青：“同步？我的倒计时和他剩的天数一样？”

钱总站在门边，目光落在那把微微下沉的秤上，声音变得很轻：“因为你们俩的命，是同一杆秤上称出来的。老陈的天数和你的倒计时共享同一份‘命’账储备。你卷得越狠，他死得越快；你停下来，他的命才会慢一点。”

林一凡愣了两秒，终于把碎片拼在一起。赵日天的卷王系统之所以绑定即倒计时，是因为从第一步起，他就被设计成了陈建国的“替代能源”。

他低头看着手中010号钥匙。金属表面微微发烫，像是有人在另一头握着它。赵日天也看着自己的面板，嘴唇动了动：“我之前想靠卷活下来，结果卷的是他的命。”

林一凡抬起头：“那把钥匙，我选第2个选项。”

系统沉默了一秒。

【选择确认：放弃‘咸鱼值商城’永久使用权。010号钥匙解锁——负三楼36号档案柜——陈和平回归。】

十三楼的灯光剧烈闪动了一下，走廊尽头的墙壁上浮现出一扇暗门的轮廓。陈建国猛地转身，眼眶通红：“你疯了吗？商城没了，你以后怎么兑换技能？你——”

林一凡把钥匙攥在手心里，咧嘴一笑：“我重生回来第一天就想明白了——真正的好日子，从来不是用商城换来的。”

他迈步走向那扇暗门，身后钱总的声音追了过来：“走可以。但这栋楼的账，还没算完。天平失衡的缺口一旦打开，劳动神和资本神都必须落子——你放弃了商城，不代表资本神会放过你。它还有三分钟。”

林一凡没有回头：“那就让它在三分钟内想清楚，到底是算我的账，还是算自由这笔账。反正我——一个摸鱼的，有的是时间等。”

门缝里透出一丝微光。他推开门，看见档案柜的最底层，躺着一个人影。那个女人的脸上覆着一层薄薄的文件纸，上面只写着一个字——“等”。

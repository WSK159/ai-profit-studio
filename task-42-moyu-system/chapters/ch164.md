# 第164章 老朋友

铁门内是一个锅炉房改造的维修间，地面浇了一层水泥，角落里堆着旧齿轮和焊枪，空气里弥漫着机油和劣质烟草味。靠墙站着一个老头，花白寸头，一件灰色工装外套洗得发白。他手里端着一个搪瓷缸，正在喝水，那姿态、那眼神，就像在自家院子里等人回来。

林一凡终于想起在哪里听见过这声音——三个月前，星辰科技内部系统升级那次，全公司视频会议上，一个白发顾问远程讲解AI考核架构，声音就是这把。当时没人知道那顾问长什么样，据说签了保密协议。

“孙老。”老王喊了一声，带着点许久不见的迟疑。

孙老放下搪瓷缸，上下打量林一凡：“系统提示‘高危险’了吧？你猜是谁标的？”他哈哈笑了一声，但笑意没到眼底，“是我托人给你标的。你们这仗打得热闹，总得有人把你们引到对的地方来。”

林一凡没急着接话，目光快速扫过房间——墙角焊着一张硬板桌，桌上摊开一张城南区旧地图，上面用红笔标记了好几处，最中间一个红圈正好画着这座锅炉房。桌上还放着一台老式笔记本，屏幕亮着，显示的是一个他极其熟悉的后台界面：星辰科技的数据库登录页。

“您是星辰科技的人。”林一凡语气笃定。

“曾是。”孙老放下杯子，“跟你们俩也没多大区别，都是被标记过的人。只是我走早了一步，没被吃干净。”他看向老王，“那张纸上写的坐标，是我传给季敏的。这世上能同时认得出我字迹又敢接下这活儿的人，也只有你们了。”

老王沉默几秒：“钥匙呢？”

孙老转过身，走到房间最深处，拉开一个铁皮柜，从里面取出一个火柴盒大小的黑色金属方块，面上一道细缝，插着一块半透明的亚克力卡片。“第二把钥匙不是芯片，是物理码。这块金属块里面刻着一组算法，需要用你手上那张纸和它同时校验，才能合出一串完整解锁码。双锁机制，一锁校验时空，一锁校验算法。季敏手里的第一把钥匙管的是时间窗口，我这个管的是计算路径。”

他把金属块放到桌上，却又用一根手指按住：“但有一件事我要你先知道。你们那个‘钱总’跟你绑定的时间，比你想象中早得多。你不是他这盘的棋子，你是他用了很多年、才等到落子的那枚。”

林一凡心脏猛地一跳：“什么意思？”

“季敏给你的U盘里，有一段加密记录，是星辰科技三年前‘AI考核系统’立项会里的内部纪要。当时有一组备选方案是通过脑波采集捕捉员工工作时长与情绪波动，做‘忠诚度评分’。”孙老语气平淡，但每句话都像钉子，“那套方案当时被否了，理由是伦理风险太高。但否决它的那个人，同时叫人保留了一条后门线路。你入职那天，正是那条后门线路第一次试点。”

林一凡的呼吸停了一瞬。他记起来了——重生回入职第一天，他右耳后多了一道极淡的疤痕，当时还以为是旧蚊虫叮咬。

“你是说，我的系统……”他没说完，就觉得舌头发干。

孙老看着他：“你系统里的‘摸鱼雷达’，本质上能不能看得见周围人的劳动浓度？它不是天赋，是那条后门线路采集到的信号，反向喂给你的。”

老王脸色变了，他几乎往前走了一步：“孙老，他自己知道吗？”

“他知不知道不重要，重要的是那条后门现在还有没有开。”孙老把金属块往林一凡面前推了一寸，“现在，你们决定一下——是先取这把钥匙，还是先看看那段纪要？”

就在这时，老式笔记本的屏幕闪了一下，自动跳出一个对话窗口，白底黑字，简短：“孙老，您该下班了。”

那语气，和钱总发给林一凡的“你输了”如出一辙。桌上搪瓷缸里的水面起了颗粒状的涟漪——不只是震动，是整栋楼在极低频率地共振。孙老的表情第一次露出破绽，他快步走到窗边，掀起一角窗帘，外面东七街上不知何时停了一辆黑色SUV，车头没开灯，引擎却轰轰热着。

“时间不够了。”孙老回身，快速把金属块塞进林一凡手里，“算法码你拿走，纸上坐标作废——以后别按老路走。我替你们挡一阵。”

老王还想说什么，孙老已经拿起焊枪，朝门口走去，头也不回。维修间的后门被一脚踹开，通向楼后更窄的防火通道，那门后有一级一级向下的铁梯，冷风从下面涌上来，带着地下水的腥气。

系统提示音适时响起——

【隐藏任务·黎明前的交易】阶段二完成。
第二把钥匙已获得。
阶段三解锁：破译双锁校验码，触摸“数据池”真相。
任务剩余时间：02:14:37。

林一凡握紧金属块，感受它冰凉的棱角扎进掌心，再抬头时，孙老的身影已经挡在门口，焊枪尖喷出细密的蓝白色火花。他向老王低喝：“走！”

两个人踩着铁梯向下跑去，身后传来金属门关上的轰鸣，以及一声极轻的、像叹息的话语——不知道是对他们说的，还是对他说那台电脑里的“东西”说的：“你也是打工人，留条后路吧。”

铁梯尽头是一条地下排水通道。林一凡喘着粗气，低头看了一眼掌心的金属块，又抬头看向老王：“孙老刚才说，我的摸鱼雷达是那条后门线路……那我的系统，到底是谁给的？”

老王往前走了一步，停在通道中央，回头看他。黑暗中他的脸只剩一个轮廓，声音在管道里一层层反射，像隔了几个时代传过来：“他给的是接入口，让信号能进到你的身体里。但系统本身……应该是我放的。”

林一凡感到一阵电流从脊椎窜上后脑：“你说什么？”

老王缓缓举起右手，手背上那道从虎口延伸到手腕的旧疤痕，在昏暗的应急灯下，泛出一种异样的青色光泽——那是跟金属块表面一模一样的纹路。他正要开口，通道更深处忽然亮起一道刺眼的白光，然后是一阵熟悉的机械声，有人在用电筒照过来。

“蹲下！”

老王一把将林一凡按倒在管道壁阴影处。两人屏息之间，手电光扫过头顶，脚步声一点一点靠近。

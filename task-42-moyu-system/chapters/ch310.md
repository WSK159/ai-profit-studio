# 第310章 三人在此

院子后门通向一条窄巷，巷口停着灰工装男人的面包车。林一凡没急着上车，他半蹲在拐弯处，透过老宅铁门的缝隙往外看。

五个人，黑夹克，手里拿的像是折叠铁棍。为首的那个侧着身，正低声吩咐着什么——灯光照不到他的脸，但林一凡看清了他的手：右手小指缺了一截。

不是陈重阳。

“是赵恒的人。”灰工装男人也认出了那个断指，“赵恒以前在工程队干过，手下几个干活的习惯用铁棍。”

沈稚冬压低声音：“他们知道老宅的位置？”

“下午赵恒带走了主控芯片。”林一凡盯着那五个人，“芯片在老宅机柜里放了七年，以赵恒的谨慎程度，他不可能不派人来检查老宅有没有其他东西。”

他回头看了一眼墙根那个刚被撬开的洞——钥匙已经拿了，纸也拿了，但洞口还没填回去。那五个人只要走到墙根，一眼就能看到新翻的土。

“走。”林一凡做了个跟随的手势，“他们五个人，没必要硬碰。”

三人贴着墙根，绕过院子东南角，从一片荒废的菜地穿过去，钻进巷子尽头的面包车。灰工装男人发动车时，林一凡从后视镜里看见那五个人已经进了院门。

面包车拐上公路，车速不紧不慢，混进夜班的货车流里。

“他们迟早会发现洞被掏了。”灰工装男人开口，“赵恒要是知道老宅里藏着钥匙，第一时间就会追你的车。”

“所以不能回毛坯房。”林一凡把油纸包里的钥匙和那张B5纸摊在膝盖上，眼光扫过打印的两行字，“老王说‘等三凑齐’——三把钥匙，我已经拿到一把编号03，赵恒保险柜里有一把，老宅墙洞里这把本该是第二把。”

他把三叉钥匙从兜里摸出来——那是之前从赵恒那里得到的另一半钥匙，也就是林一诺说的三把钥匙中的一把。也就是说。

“三叉钥匙算一把。”他把三叉钥匙和编号03钥匙并排放，“还差一把。”

沈稚冬盯着编号03钥匙的柄部：“这把钥匙的齿纹不是普通的锁型，像是某种老式柜子或者暗门用的。”她顿了顿，“老宅里是不是还有其他锁着的空间？”

林一凡摇头：“我小时候把老宅翻了个遍，没发现暗门。”他顿了顿，“但这把钥匙藏在墙洞里，老王不可能藏一把没用的钥匙。他焊铁管、写纸条、藏钥匙，全都在2019年3月17日那一天完成——那天他大概知道自己要出事，提前做完了所有安排。”

“他说‘别去追’主芯片。”沈稚冬低声念出纸上的字，“也就说他知道带芯片的人是追不回来的，只有等钥匙凑齐。”

面包车在城中村入口停了下来。灰工装男人熄了火，转过头：“你们接下来打算怎么办？”

“去赵恒那边拿第二把钥匙。”林一凡说，“他保险柜里的钥匙，加上我这把，再加上那把还没找到的，才能凑齐三把。”

灰工装男人沉默了一会儿，从驾驶座底下摸出一个黑皮本：“这是师父留下的笔记，前几年我一直没动，怕被人发现。”他递给林一凡，“里面有几页提到过一把钥匙，位置画了图。”

林一凡翻开——第一页是老王的手写字迹，日期是2018年11月，内容简短：“六号锁需要三把钥匙同时转，但第三把不在我手上。等。”

画着一张钥匙的草图，齿纹跟编号03钥匙几乎一样，旁边标注：另一把在老宋手里。

“老宋？”林一凡皱眉。

“师父的师弟。”灰工装男人说，“以前跟师父一起在农机厂当修理工，后来改行收废铁。师父出事前找过他一次，后来老宋搬走了，到现在不知道人在哪。”

车里沉默了片刻。沈稚冬忽然开口：“锁匠姓什么？”

“老宋姓宋。”灰工装男人说。

“锁匠师父的外号叫‘铁锁宋’。”沈稚冬声音发紧，“我之前查过，他在赵恒那边干活，专门负责开保险柜和密室——赵恒保险柜的锁，就是他装的。”

林一凡抬起头：“你说的是那个三把钥匙少一把的锁匠？”

“对。”沈稚冬点头，“锁匠师父手里那把钥匙编号是多少来着？”

林一凡脑子“嗡”了一声——锁匠师父说过，他有三把钥匙，但其中一把编号缺失，连他自己都不知道多少。如果把编号03的老宅钥匙、赵恒保险柜里的钥匙、锁匠师父手中编号缺失的钥匙放在一起——正好是三把。

“锁匠就是老宋。”林一凡说，“那把编号缺失的钥匙，就是这第三把。”

他把编号03钥匙举到眼前，灯光穿过齿缝，在地面投出一个扭曲的影子——影子形状看起来像两个叠加的字母：TSL。

又是“TSL”。林一凡眉头拧紧——那面镜像钥匙上也刻着同样的三个字母，当初没查出来含义，现在又看到一次。

沈稚冬盯着那个影子：“TSL……不是三个词的缩写，会不会是某种锁具的型号？”

林一凡没说话。他脑子里翻涌着灰工装男人刚才的话——“另一把在老宋手里”。如果锁匠就是老宋，那锁匠手里那三把钥匙，其中一把也许就在赵恒的保险柜里替赵恒管着。

三把钥匙，三处地方——老宅墙洞，赵恒保险柜，锁匠手里。

“先回毛坯房。”林一凡收好钥匙，“林一诺上线的时候说，要用钥匙的地方是老机房的负二层。但老机房被陈重阳守着，赵恒也盯着。等我们把三把钥匙凑齐，就得想想怎么把这几根铁片同时插进同一把锁里。”

他话音未落，折叠屏手机忽然亮了。

屏幕上浮现出一行字，字迹是林一诺的风格，简短，没有语气：“赵恒在查你们的位置。毛坯房不安全。去第三个坐标点。”

屏幕下方跳出一个地址：西郊废铁回收站。

灰工装男人看了一眼，猛地坐直：“那是老宋的废铁站——他去年搬走的地址。”

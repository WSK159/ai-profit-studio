# 第183章 天桥下的棋局

凌晨五点四十，林一凡站在天桥中央，手里攥着一杯便利店买的热豆浆。晨雾还没散尽，桥下偶尔驶过的出租车带起一阵水汽，把他的运动鞋边溅湿了一小块。他眯着眼看向桥东头，那里立着一个穿黑色冲锋衣的身影，正低头摆弄手机屏幕。

时间卡得正好，五点五十九分。

赵日天没有抬头，却在林一凡走近五步距离时突然开口：“你收到那条短信了吧。”

“你说哪条？”林一凡把豆浆盖子拧开，装作不在意地吹了一口，“老周朋友给的？还是‘别信赵日天’那条？”

赵日天终于抬头。路灯昏黄的光线下，他的脸色比上次见面苍白了几分，眼底有两团挥之不去的青黑——那不是熬夜的痕迹，更像某种被反噬后的虚弱。林一凡的“摸鱼雷达”不自觉地扫过去，发现赵日天的周身缠绕着一层几乎不可见的灰色波纹，那是“卷王系统”能量透支的典型特征。

“两条我都发了，”赵日天把手机翻过来给林一凡看了一眼，屏幕上是一条草稿状态的短信，收件人空白，内容只有五个字：别信赵日天。“老周朋友是我花钱雇的，台词是我写的。”

林一凡的眉头跳了一下，但没有立刻发作。

“为什么？”

赵日天把手机收回兜里，迈步往桥下楼梯走，丢下一句话：“因为老子被监听了。钱总的监听，你以为是监控摄像头那种小儿科？他有资本神那边的权限，能截听任何和‘系统关键词’相关的手机通话和短信。那条短信不发给‘林一凡’，发给你其他常用号码，会被AI直接识别。所以我只能用一个你没存过的虚拟号，再雇个人装成老周的朋友当面跟你碰头。”

林一凡喝掉最后一口豆浆，把纸杯捏扁丢进垃圾桶。他们走下楼梯，桥底是一处废弃的河床步道，杂草丛生，约莫五十米外有一条水泥管涵洞。赵日天领着林一凡走到涵洞入口，蹲下身，从怀里掏出一个巴掌大的黑色方盒，上面蚀刻着一圈圈螺旋纹路。

“这就是我说的‘系统权限开门器’，”赵日天把方盒贴在没有锁的涵洞铁栅栏上，铁栅栏发出一阵低沉的嗡鸣，犬牙交错的铁条开始扭曲变形，露出一道仅容一人侧身通过的缝隙。他先钻了进去，在里面喊了一声：“下来吧，别有心理负担。”

林一凡心里默算了一遍——从昨晚收到提醒到现在，已经过了七个小时，他原本以为自己做好了准备，可当他人真正站在这条带弧形的下行通道里，脚下的水泥台阶越来越潮湿，空气里弥漫着一股铁锈与旧纸箱的气味时，他还是觉得脊背发凉。

台阶尽头是一扇钢门，门没有锁，只挂着一条手指粗的铁链，链条上却拴着三把锈迹斑斑的挂锁。赵日天指向其中最左侧那把：“看到锁孔里的形状没有？那是老周留下的模具印。他要的东西根本不在他自己手里——那副真正的锁具模具，就在你手掌能碰到的地方。”

林一凡下意识伸出手指，轻轻触碰了一下那把挂锁。触感冰凉，锁体的纹路却突然像是活了过来，一股微弱的电流从指尖窜入骨髓。他猛地把手缩回来，发现自己手掌心的“咸鱼值”面板在无人召唤的情况下主动悬浮了出来。面板底部，行小字在系统提示栏里一闪而过——【检测到“劳动神”遗物碎片，可消耗 5000 咸鱼值开启深层密室。】

赵日天笑了，笑容里带着一种疲惫的狡黠：“看吧，我没有骗你。这里不是天桥下的步道，这他妈是负二楼。刚才在外面那段坡路，是被人故意反画的图纸骗你绕了远路。真正的入口，你早就埋在你那间出租屋的天花板储水层下面。”他蹲下，用指尖敲了敲地面，空洞的回声从地下深处传上来，像是有一口巨大的空腔——“老周最后一次跟我联系说，‘锁不在门上，在门里。’”

林一凡还没来得及回应，他的手机突然震了三下，屏幕上跳出一条来自系统内部的红色警告框——

【警告：检测到同频能量波动源靠近。来源：北方，距离 200 米，移动速度……正在加速。】

赵日天的笑容在下一秒僵住了，因为他也看到了同样的警告。他骂了一句脏话：“操，钱总的人已经到了。没时间选了。”

林一凡看着那把挂锈锁，又看着赵日天满脸的警惕，脑子里飞速转了三个方案：先用 5000 咸鱼值开门赌一把；或者拖着赵日天退回涵洞反向突围；再或者像这条短信一样，先让赵日天独自去抗，自己躲在角落渔翁得利。

但他的手已经比脑子快了一步，按下了确认键。五千咸鱼值从面板上瞬间清空，钢门内部的锁簧发出一声脆响，三把挂锁同时弹开。

门后没有任何灯光。黑暗带着一股湿泥的腥气，从门缝里缓缓涌出来，像是某种生物呼出的气息。赵日天站在林一凡身后，低声说了一句：“进还是不进？钱总的脚步声已经到了上面台阶。”

林一凡弯下腰，迈进门里之前，回答他：“我还欠你一个解释——那条‘别信赵日天’的短信，我没有当真。”

门在他们身后合拢，沉重得像一座墓碑落下。

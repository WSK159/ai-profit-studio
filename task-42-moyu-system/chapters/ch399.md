# 第399章 水下的第三道影子

水面裂开的缝隙不是幻觉。一股混着铁锈味的水汽从裂缝里往上涌，林一凡在真实视界下看见，那道裂缝边缘泛着一层暗青色，像是什么东西从水下往上顶，把整个水面从中间掰成两半。

他退了半步，但没转身跑——因为他看见水面裂开的瞬间，那道水下台阶上的锁链松了。

“那是放生锁。”沈临渊的声音有些嘶哑，“水下栓的，是‘零’的真身。锁一松，笼子里的‘半身’就会疯。”

“你没早说？”

“我说了你会信？”沈临渊扯了扯嘴角，“你连你大哥都不信。”

铁皮壳子没吭声。它的肩缝里那片干枯的皮肤正一点点缩回内部，像是在避开什么。而锁芯里那根女人的手指已经爬出了大半个指节，停在锁孔边缘，指腹朝上，像是一条在空气里游弋的鱼。

林一凡盯着那根手指，脑子里闪过一个念头——手指的主人，和头顶撬门的人，是不是同一个？

他来不及细想，水面裂缝已经扩大到半人宽，水下露出一团黑乎乎的影子。那影子不是人形，更像是无数条藤蔓缠绕在一起，中间裹着一团暗淡的光。光里，隐约能看到一张脸，年轻、瘦削，五官模糊，但林一凡一看到那双眼睛就愣了一下——那是和老杨头一模一样的眼睛。

“你大哥？”他低声问铁皮壳子。

铁皮壳子沉默良久，从嗓子里挤出一个字：“是。”

“他还活着？”

“不算活。”铁皮壳子说，“算是，被拴着。”

林一凡明白了。水下的“真身”，才是老杨头大哥的本体——或者说，是他被掏空后留下的一部分。锁链锁住的不是他的身体，而是他体内那团还没熄灭的、属于“人”的东西。

“放出他就等于放出一半的零，”沈临渊的声音带着一丝疲倦，“另一半还卡在壳子里，到时候双生体合流——你大哥就彻底没了。”

“那如果放出来的是一个完整的零呢？”林一凡问。

沈临渊愣了愣，随即笑了：“那你就是下一个进笼子的。”

水底那张脸忽然睁大眼睛，嘴巴无声地张合。林一凡下意识读他的口型，读了两遍，认出三个字——

“别碰锁。”

但已经晚了。铁皮壳子的右臂不知何时伸了过去，指缝间夹着一枚青铜钥匙，正正好插进锁芯。而那根女人手指触到钥匙的一瞬间，猛地一卷，像蛇一样缠住钥匙柄，同时锁芯里传出一声轻轻的、带着笑意的叹息：

“终于……等着了。”

锁芯转动的咔哒声碾过整个水牢。

水面像煮开一样翻滚起来，水下那团影子急速膨胀，藤蔓一条条炸开，露出里面蜷成胎儿状的人形——但那人形没有脸，五官的位置是空的。

铁皮壳子后退两步，肩缝里的干枯皮肤开始大片大片脱落，露出底下泛着金属光泽的骨架。它的声音在变，从老杨头大哥的嗓音，一点点滑向另一种更年轻、更轻飘的音调：

“编号零，双生体融合——”

林一凡咬着牙，一手握紧陶土徽章，另一只手摸到口袋里那半截铜片。铜片边缘的刻痕和锁芯里的花纹几乎一模一样。

他忽然明白了什么，将那半截铜片插入锁芯旁边的凹槽。

咔。严丝合缝。

锁芯里的手指僵住，那声叹息变成了嘶嘶的抽气声。沈临渊在笼中猛地抬头，盯着林一凡手里的铜片，瞳孔微缩：“那东西，你从哪儿弄来的？”

“捡的。”

林一凡低头，看到锁芯旁的铜片表面浮出一行极小的字——

“开锁者，亦为锁中人。”

水底那张无脸人形，正缓缓侧过头来，空荡荡的眼窝，朝向了他。

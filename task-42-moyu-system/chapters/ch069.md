# 第69章 楼顶的秘密

林一凡攥着那张便签，纸角被他捏得发皱。那朵雪，长在楼顶的排水口边上。赵日天写字一向歪七扭八，唯独这行字，笔画用力到几乎要划破纸背。他把便签塞进口袋，抬头看了一眼秦氏B座外墙——十二层，楼顶天台是禁入区域，门禁卡要职能总监以上级别才能刷开。

他先回到自己的工位，江雪档案的完整事件记录还停在屏幕上。林一凡扫了一眼四周，三名审计员还站在走廊尽头，掌上终端的光映在他们脸上，面无表情。他飞快往下翻：附件列表——“EP-0422-任务失败报告”、“人格清理操作日志”、“记忆格式化审批单”，以及一个打了红叉的文件夹，名字叫“雪落无声·遗留物”。

文件夹被锁定，需要A3级权限。林一凡试着用摸鱼系统破解，系统弹出一行字：“宿主权限不足，当前咸鱼值可兑换临时管理员凭证，需1200点。”

他看了一眼余额：1415。犹豫了三秒，晚上楼顶可能要出事，这是命。

“兑换。”

咸鱼值骤降到215，屏幕上那个红叉文件夹缓缓展开。林一凡瞳孔一缩——里面只有一个文档，标题写着《雪落无声的自述·最后一次摸鱼》。

文档只有三百多字，语气平静得可怕。江雪写道：“我绑定卷王系统的时候，以为那是礼物。每天超额完成任务，用尽一切手段压过同事，卷王值疯狂上涨。但我的身体越来越差，系统却说这是‘进化必经之路’。直到那天我在楼顶排水口边上坐下，看着下面的人都像蚂蚁，我突然想——蚂蚁有没有想过为什么要搬那么多米？”

最后一句是：“劳动神说，完成这个终极任务，我就自由了。但我知道，自由不是靠完成任务换来的。”

林一凡盯着这段文字，后脊梁一阵发麻。他把文档截图存进手机，正要继续挖更多线索，走廊方向传来脚步声。他迅速切回工作界面，装作在看代码。审计员经过他工位时停了停，其中一个人低头看了眼终端，又抬头看向林一凡，嘴角动了动，像是想说什么，最后没开口，径直往电梯方向去了。

林一凡心里那股不对劲越来越浓——那三个审计员不是来查摸鱼的，他们是在找人。他调出摸鱼雷达，扫了一圈整层楼：正常。但那三个人的“劳动浓度”在雷达上显示为零，干净得像是完全没有工作轨迹。正常人不可能零劳动浓度，除非……他们根本不是普通员工。

下午五点半，林一凡趁下班人流混进楼梯间，沿着消防通道一层层往上走。秦氏B座的楼梯间灯坏了两层，越往上空气越冷，到十楼时他听见头顶传来铁门开合的声响，紧接着是两个人的对话。

“……她真的彻底清干净了吗？”

“档案上是这么写的。但雪落无声的遗留物编号还在，审计组怀疑她的人格备份被藏进了某个终端。”

“楼顶那台旧服务器组呢？”

“昨天排查过了，没找到。”

声音渐远，铁门重新关上。林一凡贴在楼梯扶手上，心脏擂鼓一样跳。楼顶还有一台旧服务器组——赵日天说那朵雪长在楼顶的排水口边上，他说的也许根本不是人，是一台被遗忘的服务器。江雪的“雪”，落在那台机器里。

他等了一分钟，脚步声彻底消失，然后快步冲上十二层。通往天台的门虚掩着，锁边上有一圈新鲜撬痕，像是刚被人撬开过。林一凡推开门，傍晚的风裹着寒意扑面而来。楼顶比想象中大，铺满灰色防水卷材，排水口在西北角，旁边堆着几块废砖。

他走过去蹲下，废砖底下一根锈蚀的线缆拖出来，线头被剪断过，但断口泛着崭新的铜色。顺着线缆摸过去，墙角一块防水布底下盖着个铁皮柜，打开一看——四块硬盘叠在一起，用橡皮筋绑着，最上面那块贴着一张白色标签，用圆珠笔写着一行字：“雪·备份·勿删”。

林一凡还没来得及伸手，身后的天台门突然“砰”地一声被人踹开了。

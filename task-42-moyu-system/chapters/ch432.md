# 第432章 交接手册

老杨头靠在铁皮门旁边，脸上的皱纹像被揉皱的废纸。他看到林一凡手里的红皮本，瞳孔缩了一下。

“你拿到了……”他的声音有些发抖，“她没拦你？”

“她让我下次带把长柄梳子。”林一凡低头翻开笔记本第一页，泛黄的纸面上是工整的钢笔字，落款日期是二十一年前的三月。他认得出这笔迹——他父亲的。

“你父亲的字。”老杨头替他确认了心里那个念头。他凑过来看了一眼，又赶紧移开目光，像多看几眼会被灼伤。

林一凡一行行读下去。第一页是值班守则，要求持卡人每班清点档案存放状况，确保T序列工位编号有序。第二页开始，字迹潦草了许多，纸面上有斑驳的水渍——像干涸很久的泪痕。“T-001于今日正式归档，编号1, 编号2同期封存。第二道锁由档案员更换，新锁匠姓沈。”沈家。沈临渊。林一凡指尖停在这个名字上，心跳加快了一拍。

“老杨头，”他开口，“你认识一个叫沈临渊的人吗？”

老杨头的脸唰地白了。他张了几次嘴，最后挤出一句：“他……他在你这年纪来过。拿的是一把木柄钥匙，开的是B3档案室。”顿了一下，又说，“后来他进去了，再没出来。档案室封门的时候，锁匠姓沈的人都走了。”

林一凡继续翻。第三页是一段潦草的记录，说的是T-002的“接收条件”：每逢闰年二月二十九日，需在铁皮门内点一支烟，不吸，等烟燃尽。他想起母亲留下的半包忘忧草烟，以及老杨头说过母亲曾要求“除夕夜点一支烟”。他翻到书的最后，夹着一张对折的纸。展开后，是一张手绘的走廊平面图，画的正是这条归墟通道。图纸上标注了铁皮门、白色金属门、B3档案室，以及——图纸右下角画着一扇没有标注的门，门后是一条虚线延伸出纸面，末端写着一个模糊的“海”字。

“海？”林一凡低声重复，这个字像一枚钉子，扎进他脑子里某个模糊的角落。他还没来得及细想，白金属门内传来那女人的声音，这次更清晰，带着沙哑的质感：“你父亲留了话，你打开第三层抽屉的时候，该听一听。”

林一凡手一抖，笔记本差点滑落。他转头看老杨头，老杨头也一脸茫然地摇着头。门缝里又飘出那句话——

“你父亲说，第一把锁是他自己换的，第二把锁是他自己焊的，钥匙只在替班人手里。到时候，你要去B3档案室，把那道门推开。”

老杨头腿一软，靠墙滑了半步才稳住：“B3……那门不能推……”

“为什么？”

“门后……”老杨头咽了口唾沫，“门后有水。”

林一凡皱眉，他下意识地摊开手掌，掌心的汗湿让那张图纸的边角卷起。他低头看着“海”字，想起上辈子加班到深夜时，自己总会在隔间窗边望着对面老楼的水塔胡思乱想，那里也有一道铁皮门。门后是什么，他从没去看过。但此刻脑中有什么东西点亮了——他母亲最后一次加班晚归，曾说她听见了“水声”。

白色金属门里的女人声音最后响起：“去B3，推开那道门，如果里面站着你母亲，别让她走出来。这是你父亲的意思。”

林一凡握着笔记本的手指收紧，图纸上那个“海”字被他的拇指遮住了一半。他闭了一下眼——上辈子他加班猝死前的最后一个念头，不是钱，不是业绩，不是还差两行的代码。是母亲说过的那句话：“你爸不是跑了，他是被锁住了。”

锁住了。锁在B3档案室门后那片水声里。

“老杨头，”林一凡开口，声音出奇地稳，“B3档案室在哪层？”

老杨头沉默很久，从口袋里摸出一包揉皱的烟，抽出一根点燃，吸了一口才说：“地下一层，走廊尽头，把手上挂着一把生锈的锁。锁芯里塞着一张纸，上面写着一个名字。”

“什么名字？”

老杨头吐出一口烟，烟雾在暗黄的灯光下缓缓散开：“林远山。你父亲的名字。”

# 第401章 卷中卷

锁芯转动的瞬间，井壁上的环形刻度盘亮起一圈刺眼的红线，像是某种祭仪被启动。

林一凡没时间思考赵日天怎么会出现在这里，为什么眼睛变成了红线灌满的空洞——他此刻只做了一个动作：将手里的半截铜片死死摁在缺口里，反向一拧。

“咔”的一声脆响，锁芯卡死在两个刻度之间。红线骤然熄灭。

赵日天站在井口，向下俯视，脸上没有任何表情。他张了张嘴，声音像干裂的河床：“你拧错了方向。左一圈，才是开门，右一圈，是死锁。你选了死锁——真不愧是你，最擅长的就是断自己的路。”

“你他妈到底是不是赵日天？”林一凡仰着头，后背贴着井壁，语气却硬如铁钉。

“我是赵日天，也不是赵日天。”赵日天抬起右手——他的五指白得没有血色，掌心里托着一枚陶土徽章，28号，“上一轮对赌，我输了半条命出去，还剩半条，被装进了归墟。现在，我是……零的半身。”

林一凡瞳孔骤缩。

怪不得赵日天一直在追查陶土徽章的下落。他不是为了查图纸——他本来就在追查自己，追查到归墟，是要拿回自己被夺走的那半条命。

“所以你根本卷不到真实世界。”林一凡冷静下来，“你是卷王系统里埋的一颗棋。你们那套系统背后，是资本神的分身。”

赵日天的空洞眼窝里，红线蠕动了一下：“你比我想象中聪明。”

“你既然拿不到我手里的铜片，下来抢也不成——锁芯已经死锁了。”林一凡攥紧铜片，余光扫见井底的骨架上，那截锁芯旁边还有一枚小指粗的青铜钉，“你不如告诉我，你的宿主——原来的赵日天——还活着吗？”

井口那道影子晃了晃，似乎被这个问题刺到了痛处。“他是死是活，取决于他值不值得活。”说着，赵日天忽然从井口消失。

四周安静了一瞬。水声、风声、沈临渊的呼喊声，全部消失。

只有井下那枚青铜钉，嗡嗡作响。

林一凡低下头，他凑近看到青铜钉的顶端刻着一行极细的蝇头小字：“第七百零四号对赌协议——甲方：孙满仓，乙方：零。标的：半条命。”

孙满仓。

这名字在林一凡脑中炸开——之前沈临渊对“姓孙的”反应异常，再加上孙满仓与钱总的关系未明，而现在，这枚青铜钉直接让他和三方的对赌协议撞在一起。

孙满仓的甲方签名，为什么会出现在归墟水牢的锁芯旁边？

林一凡来不及深想，因为青铜钉上忽然传来一股温热的脉搏——像是什么东西在钉子里苏醒了。他把铜片贴过去，两片接触的一瞬，耳边响起一个苍老的声音：“小友，你若想离开归墟，拿我的钉子去换‘零’的真身——在铁皮壳子的胸口，有第二个锁眼。”

声音结束，青铜钉自动脱落，落入林一凡掌心。

井壁上的刻度盘忽然剧烈震动，死锁被迫松开半圈，上方传来沈临渊的声音：“林一凡！铁皮壳子疯了，他把大哥的尸体从台阶底捞出来了——”

林一凡抬头，看见井口洒下一片昏黄的光，而在光的外围，站着一道无脸人形、一道铁皮壳子和一个双眼空洞的赵日天。

三双视线，同时落在他身上。

林一凡捏紧青铜钉，咧嘴笑了：“好家伙，归墟水牢开大会，谁坐庄？”

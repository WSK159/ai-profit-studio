# 第178章 天花板后面的东西

门外的力量突然收了回去。工装男松开手，脚步声后退两步，随即那三道雷达光晕迅速向楼下滑去，像从没出现过一样。

林一凡站在原地，胸口剧烈起伏着。后背的冷汗浸透了T恤。

他低头看了看手里那张A4纸，老周的字迹旁边还有几行极小的数字，像是坐标——天台、承重墙、老旧的排风口。季敏刚才查到，老王的旧账号最后登录的IP，就指向这栋出租楼的天台。

林一凡抬起头，看着天花板上那扇落满灰尘的活板门。

他搬进这间出租屋三个月了，从来没人提过屋顶还有一个隔层。老王的旧箱子偏偏寄到了这里，芯片卡里的结构图标明的第三把钥匙插槽就在活板门后方。

门。锁。钥匙。造锁的人。

那句话又在他脑中回响：“真正的开启者，不是拿钥匙的人，是造锁的人。”

林一凡咬咬牙，搬过椅子，踩上去，伸手推了推活板门。门板发出咯吱一声闷响，纹丝不动——被什么东西卡死了。

他掏出那把磨得发亮的黄铜小钥匙，在活板门的边缘缝隙处摸索。手指划过粗糙的木纹，突然触到一个不太明显的圆形凹槽。凹槽周围有一圈细密的纹路，像是某种机械锁芯的外缘。

林一凡把钥匙对准凹槽插进去。咔哒一声，钥匙柄微微转动了一下，活板门无声地弹开了一条缝。

灰尘簌簌落下，他偏过头，等了几秒，才踮脚从缝隙望进去。

隔层里很暗，只有一丝光线从排风口的铁栅栏缝隙透进来。他看到一只锈迹斑斑的铁皮箱子，箱子上盖着一块发黄的油布，油布下面露出一个角——和一叠文件。

林一凡伸手把铁皮箱子拖下来，落地时扬起一片灰尘。他蹲下去，掀开箱盖。里面整整齐齐叠着一堆东西——几张打印纸、两枚旧工牌、一个密封的透明塑料袋。

透明塑料袋里装的东西让他呼吸一滞：那是一张照片，照片上是年轻的老王和另一个人，两人肩并肩站在一台巨大的服务器机柜前。另外那个人的脸……是老板钱总。但照片里的钱总比现在年轻得多，脸上没有那股油腻的商人气，眼里也还没有那种算计的光芒。

照片背面写着一行字：“ALPHA ACCESS，真正的主人不是资本，是劳动。”

林一凡放下照片，拿起那几张打印纸。第一张是一份合同，甲方是“星辰科技”，乙方签名栏上写着两个名字：王建国，钱德海。合同日期是十二年前。

他刚看清那几个字，手机忽然剧烈震动起来。季敏发来一段语音，他点开，里面是季敏急促的声音：

“林一凡！我刚查到的——ALPHA ACCESS不是楼层代号，是公司内部一个隐藏系统的名字，权限等级高于CEO。现在有东西正在登录那个系统，位置就在……你所在的那栋楼！”

林一凡猛地抬头，望向天花板隔层深处。

那缝隙里，一个极细的红光点正在黑暗中一明一灭，像是在等待着什么。他盯着那个红点，脑中那些零星的碎片突然拼在了一起——老王的死、老周的仿制钥匙、赵日天的警告、门口那些人的试探、钱总与资本神的交易——所有的线索，全部都指向头顶这面天花板后藏着的东西。

他深吸一口气，伸手，把最后一层油布掀开。

铁皮箱底部，露出一台巴掌大的黑色设备。设备中央刻着一行小字：

“MF-019-ALPHA 激活端口。”

林一凡的瞳孔骤然放大。

黑色设备的侧面——那一排排细密的金属插槽中——大小正好能插进他在芯片卡里发现的那把黄铜小钥匙。而机器背面，还有一个空着的圆形插孔，与咖啡馆钥匙柄碎片的轮廓完全吻合。

他低头看了看自己手里的三把钥匙：一把是老王寄来的黄铜小钥匙，一把是刚从老周那得到的钥匙柄碎片，第三把——赵日天口中那个“警告”对应的东西——是他还没有找到的、结构图上标注的插槽钥匙。

“三把钥匙，三道锁。”林一凡低声说，“这个系统到底在锁什么？”

他话音刚落，脚边的芯片卡电脑屏幕忽然自己亮了。系统面板上弹出一行字：

【检测到ALPHA ACCESS激活端口，是否启动初始化程序？】
【警告：启动后不可逆转。启动后，你将看见这个世界的真实规则。】

【是否继续？】

走廊外，脚步声再一次响起。这一次比之前更近、更快、更多。

林一凡的手指悬在“继续”按钮上，门外传来一个沙哑的、无比熟悉的声音：“林一凡！你果然还活着。老周猜得没错，小王把钥匙寄给了你——”

是赵日天。但赵日天的声音，为什么会和那个工装男一模一样？

他的手指落了下去。

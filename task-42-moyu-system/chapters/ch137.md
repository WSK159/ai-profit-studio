# 第137章 钥匙孔的召唤

林一凡盯着赵夜白脸上的笑容，后背贴着冰冷的水泥墙面，指节捏得发白。

“你说什么？”他的声音不受控制地发颤，却努力稳住呼吸，“我上一世的尸体……什么意思？”

赵夜白没有急于回答。他歪了歪头，用一种近乎怜悯的目光看着林一凡，然后伸手从风衣内侧口袋里掏出一张照片。照片的边角泛黄，像是被水浸泡过又风干，上面的画面模糊不清，但林一凡还是认出了那个场景——华夏金融中心，地下B3层，他正躺在冰凉的水泥地面上，嘴角溢血，双眼圆睁，像是经历过某种极端恐惧。

林一凡的瞳孔骤缩。他差点伸手去抢那张照片。

“这是我从建眼计划的档案室里翻出来的。”赵夜白把照片收回去，声音压低，“你上辈子死在那里，林一凡，不是加班猝死，而是被人为制造的心脏骤停。有人在那间地下室里布置了精神杀阵，你的灵魂被抽走，填进了一个钥匙孔。”

“钥匙孔？”林一凡的脑子飞速运转。

摸鱼雷达已经被碎破干扰场的技能消耗到极低的续航，但他仍然能感知到赵夜白身上那股淡淡的、不属于普通人的气息。那气息和摸鱼系统的波动有些相似，却又截然不同——像是一把生锈的钥匙在古老的锁孔里旋转时发出的摩擦声。

“跟我来。”赵夜白转身，朝地下室更深处走去。他没有回头，声音却在空旷的空间里回荡，“你说得对，我手里的名片确实是你的。但名片上那串数字00042，不是一串普通号码，它是钥匙孔的编号——也就是说，你是第四十二把钥匙。”

林一凡犹豫了三秒钟，然后跟了上去。

死过一次的人，不怕再死一次。但他怕的是，这次连死都死不明白。

赵夜白带他穿过一条低矮的走廊，墙皮剥落的水泥缝隙间爬满暗红色的锈迹，空气中弥漫着铁锈和潮湿混合的气味。走廊尽头是一扇厚重的钢门，门上没有把手，只有一把老式的铜质钥匙孔，锁眼周围的金属被磨得锃亮。

“这就是建眼计划的核心节点之一。”赵夜白停在门前，转头看向林一凡，“你知道为什么钱国豪要把名片交给你吗？因为他知道名片的真正主人不是你，而你的指纹和瞳孔能激活这个钥匙孔。”

林一凡的眼皮跳了一下：“什么意思？”

“意思是——”赵夜白微微侧身，把他的手臂往门上一按，“他已经把你卖出去了。”

林一凡还没来得及反应，刺痛感从指尖蹿上来——钥匙孔周围的铁片微微震颤，一道细如发丝的红光从锁眼中射出，扫过他掌心的掌纹。他整个人像是被电击一样僵在原地，脑海中突然涌出一连串不输于自己的记忆碎片：一道模糊的身影站在他面前，穿着黑色西装，手里攥着一根注射器，针头扎进他的颈动脉，那人的胸口戴着一枚金色的钥匙胸针。

那枚胸针上的钥匙形状，和面前这把锁一模一样。

“你干什么！”林一凡猛地抽回手，退后两步。

但已经晚了。钢门内部传出沉闷的齿轮声，像是被激活的机械开始运转。门缝里渗出一缕冷白色的光，把赵夜白的半张脸照亮。

赵夜白的神色也变了：“它认主了。”

“谁认主了？”

“建眼计划的——眼。”

林一凡心头涌起一股不祥的预感，他本能地朝后转身，却发现来时的走廊已经被一面从墙内挤出来的暗墙堵死，背后只剩下这一扇缓缓开启的钢门。

门内，是一间没有任何家具的房间。房间正中央的地板上，画着一个巨大的、由无数钥匙形状组成的法阵，法阵中心插着一把锈迹斑斑的铁钥匙，钥匙尖端对准的方向，正好是华夏金融中心的地下坐标。

那把铁钥匙旁边，躺着一台屏幕碎裂的手机。手机屏幕上还显示着一则未发送的短信，收件人是“老王”，短信内容只有一行字——全是他上辈子从没来得及告诉别人的话。

“救我，摸鱼系统是假的。”

林一凡的呼吸瞬间停滞。他记得这台手机。那是上辈子的他，在猝死前最后一刻攥在手里的那台手机。

他伸手去够手机的刹那，法阵中心的那把铁钥匙剧烈震动起来，整个房间的地面忽然塌陷了一角，露出一条深不见底、通往更深处的地下阶梯。赵夜白在他身后低声说了一句——

“林一凡，你应该问一问，钱国豪当年为什么要把你招进星辰科技。”

阶梯深处，传来一声极轻的、像是钥匙旋转的金属声。

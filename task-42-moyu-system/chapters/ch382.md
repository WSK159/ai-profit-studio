# 第382章 设备间里的脚步声

齿轮声戛然而止。

沈稚川的身体在那一瞬间绷成了一张弓。他的手按在相机快门红绳上，指节发白，目光从林一凡脸上掠过，落在设备间深处那扇半掩的铁门上。赵日天已经退后半步，背靠泵机，眼睛眯成一条缝，像一头嗅到危险的野兽。

“有人已经到了。”

沈稚川刚才说这句话的时候，声音平稳得像在陈述一个既定事实。但他此刻的反应出卖了他——他并不知道“有人”是谁。

林一凡喉结动了动。他下意识看了一下系统面板。

【咸鱼值：1,847,620】
【摸鱼雷达：扫描范围内存在异常“劳动浓度”】
【异常源：第三泵站设备间，东北方向，距离约11米】
【劳动浓度：超过阈值，判定为········正在运转的机械】

“不是人。”林一凡说。

沈稚川皱眉：“你说什么？”

“雷达上显示……不是人。”林一凡往前走了两步，把耗子挡在身后，“是什么东西在转，齿轮、皮带、轴承，一整条机械链在运转。”

沈稚川的表情忽然变了。

他急促地转身，一脚踹开设备间那扇半掩的铁门。门板撞在墙上发出一声闷响，灰尘簌簌抖落。设备间里亮着一盏昏黄的防水灯，光芒映出一台老式柴油发电机样的机器。但它不是发电机——机身没有油箱，没有排气管，取而代之的是一整排黄铜齿轮和一根根缠绕着红线的连杆。

机器的正中央，嵌着一块巴掌大的玻璃面板，面板上亮着一行数字，缓慢跳动。

“0.327%。”

赵日天凑过来，声音低哑：“这他妈不是……沈稚冬搞的归零装置？”

沈稚川没答话，却快步走到机器右侧，伸手一摸。他的手在面板下方停住，指腹擦过一截裸露的铜线——铜线温热，正在通电运转。

“它被启动了。”沈稚川的声音终于有了起伏，“这台‘归零’副机……有人从别的地方把它打开了。”

林一凡盯着玻璃面板上那个还在跳动的数字，忽然想起了什么。他在三号维修站的暗室里见过一台一模一样的装置——那时候面板上的数字是“0.327%”。现在也是一模一样。这个数字没有增长，没有变化，像是被死死定死在那个刻度上。

雷达上那个“劳动浓度”的异常源，就在这台机器里。

“闻到的味道。”沈稚川忽然开口，侧过头，鼻翼翕动了两下。他像是又陷入了那种神神叨叨的状态，目光涣散，声音也变得飘忽，“当年我守泵站，夜里听见那口老泵像牛一样喘气。沈稚冬说，泵机里有一条看不见的传送带，把人的命数一根根绞进去。那天夜里，泵机骤停的不是水的压力——是传送带断了。”

他猛地转过头，看着林一凡：“你刚才说你雷达上看见的东西，像是什么？”

“机械运转。”林一凡想了想，“齿轮、皮带、连杆，一整条链。”

沈稚川咧嘴笑了一下：“那就对了——是绞盘。”

“什么绞盘？”

“把你从死亡里送回来的那条绞盘。”沈稚川的声音低得几乎被泵机的嗡鸣吞没，“林一凡，你刚才在泵机房里听见的，那不是齿轮声——那是你自己回来时，走过的路。”

林一凡头皮一麻。

他忽然意识到，从重生那天起，他一直忽略了这个问题：他是怎么回来的？系统绑定、重生、回到入职第一天——这一切的一切，传输的通道在哪里？

他低头看了一眼脚下，设备间的水泥地面上，积着一层薄薄的灰。灰尘被某种气流吹出了一条痕迹，从机器脚下延伸，穿过铁门，一直拖向走廊尽头。

那条痕迹的宽度，刚好是一个成年人躺平的长度。

“有人来过。”林一凡蹲下来，手指顺着灰尘痕迹的边缘划过，指尖触到一块硬物。

他拨开灰尘，露出一个拇指大小的陶瓷碎片——碎片上有半道纹路，像是某种徽章的残角。赵日天也蹲下来看，瞳孔骤缩：“这是……九子同心？”

碎片边缘刻着一道曲弧，弧线中央残留着半颗五角星的尖端。

沈稚川从腰间摸出一把手电筒，照向碎片，光柱下瓷片的釉色泛着青灰——和当年南洞人工空间里那些陶土徽章一模一样。林一凡拿起来翻转，翻到背面时，指腹摸到一行极浅的数字，像是烧制前刻上去的：074。

和林一凡在三号维修站暗室里看到的那个数字一模一样。

“074……”赵日天低声念了一遍，“和0900对应的那个？”

沈稚川猛地抬头：“你说什么？0900？”

赵日天还没来得及答话，设备间深处那台机器忽然发出一声闷响——玻璃面板上的数字跳动了一下。

“0.328%。”

林一凡盯着那行数字，忽然觉得后颈发凉。

0.327%跳到了0.328%。它在增长。而它每增长一点，就意味着那个看不见的绞盘又转了一圈——把某种东西，一点点绞过来。

沈稚川的呼吸变得急促，他伸手关了手电筒，声音沙哑：“走。现在就走。”

“去哪？”

“云顶山，第三扇门。”沈稚川把那片瓷片塞进林一凡手里，“074是门牌号。0900是时间。现在机器开始转了——留给我们的时间，不多了。”

他说完这一句，便不再看那台机器，转身大步往外走。林一凡和赵日天对视一眼，跟了上去。

泵站的铁门在他们身后合拢时，设备间里又传来一声齿轮咬合的咔哒声——像是绞盘又转了一圈。

而林一凡的雷达上，“劳动浓度”的异常源依然亮着。它在那台机器里蠕动着，像一条埋在齿轮间苏醒的蛇。

他攥紧手里的陶瓷碎片，指尖发烫。

074。0900。第三扇门。还有——那个躺在灰尘痕迹里的人。

那个人不是沈稚冬。沈稚冬的鞋印比他小一号。

那道拖痕的宽度，更像是一个穿43码鞋的男人——林一凡低头看了一眼自己脚上的鞋。43码。

他走的。他自己走过那条绞盘。

他是从哪头走到哪头的？

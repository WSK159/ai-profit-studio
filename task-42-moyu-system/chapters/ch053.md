# 第53章 键帽下的目击者

凌乱的钥匙串磕在键盘边缘，发出细碎的金属碰撞声。林一凡的手指悬在TEST-03B的键帽上方，像拆弹专家面对一根可能剪断就会爆炸的红线。

周三上午九点十七分，距离复赛开始还有十三分钟。比赛机房里的中央空调吹得他后脖颈发凉，一排排显示器蓝光映着选手们绷紧的脸。

那层陌生号码点名要他去用的TEST-03B就在正前方，黑色的机械键盘看起来与其它机位毫无差别。但林一凡知道，假如那个号码说的是真的，键帽下面藏着的东西可能会改写整个秦氏数据风波的走向。

“还有十二分钟。”系统面板在视野角落闪了闪，摸鱼雷达自动开启，周围人头顶冒出不同颜色的光标。红色代表高负荷运转，绿色代表正常摸鱼，而旁边一个戴黑框眼镜的选手头顶闪现着诡异的橙色——不停波动，像信号不好的电视屏幕。

林一凡没空管那橙色，他深吸一口气，左手小指勾起空格键右侧的“C”键帽，一声极轻的“咔嗒”，键帽应声翘起。

里面躺着一枚指甲盖大小的黑色贴片，厚度不到一毫米，蛛网般的电路纹理在蓝光下折射出微弱的金属光泽。这不是普通定位器——林一凡瞳孔微缩——这是时间戳劫持芯片。

他瞬间串联起所有线索：门禁卡上的紫色指纹、沈敛账号的伪造登录日志、调快四分钟测试机系统的脚本。秦氏的假数据不是人工编造的，而是在数据生成的瞬间，用这种物理级攻击工具篡改了时间戳。

只要把芯片贴在键盘内部，数据包在发送前就会被劫持改写，让测试结果带上提前生成的时间戳。系统查不到代码层面的漏洞，因为问题出在硬件层。

林一凡正要取出芯片，余光捕捉到屏幕右下角的时间显示突然跳动了一下——从09：19跳到了09：23。

机房的门被人推开，安全部主管陈哲走进来，目光精准地落在林一凡身上，嘴唇微动：“TEST-03B的时钟，被人远程改过。”

赵日天不知何时出现在他身侧，用只有两人能听见的音量说：“别碰那芯片，指纹识别层已经激活。五秒内不取走，它会把你的指纹记录并发给服务器。”

林一凡的手指僵在半空。

“用这个。”赵日天从口袋里摸出一把不锈钢铁尺，干净利落地卡住芯片边缘，掌心一带，芯片落入他早就备好的透明密封袋中。

键盘下方，一行激光蚀刻的微小数字在灯下若隐若现——1314520。那是数据路径的身份证号，每一组测试机的密钥序列号都独一无二。

林一凡看着那串数字，脑海中炸开一个名字。他曾在沈敛的离职档案里见过同样的序列号：档案上标注的是“密钥丢失”。

“沈敛失踪前，”林一凡压低声音，“他是秦氏数字化安全部的内测员。这台TEST-03B，曾经就是沈敛的工位机。”

赵日天的眼神沉了沉：“你是说，有人用沈敛的旧机器参加复赛，就是为了把消失的证据重新带进系统？”

远处，裁判的哨声响起，比赛倒计时三分钟。陈哲站在机房入口，手里攥着一部不停振动的手机——屏幕上闪烁的名字，是秦氏数字化安全部的部门专线。

林一凡从座位站起，把密封袋贴着掌心藏好。他朝赵日天使了个眼色，两人分头走向各自的机位。

屏幕亮起，倒计时跳入59秒。

他低头看了一眼键盘底座内侧——那里还贴着一行比头发丝还细的手写字：“看云，别看路。”

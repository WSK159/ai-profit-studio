# 第423章 锁舌后面

入口很窄，两人宽，两边墙壁全是铜皮包裹，表面生着一层墨锈。林一凡侧身走进去，手里的27号徽章越来越烫，烫到他不得不用衣角垫着掌心。

黑暗延展开了不到十步，前方就豁然顿住了。

一个圆形的铜室，大约三丈见方。正中央立着一根铜柱，柱身上布满三道斜杠——和B3档案室门口的三道杠一脉相承。铜柱顶端是一个拳头大的锁孔，孔口朝下，像一只合拢的眼睛。

锁舌就在铜柱底部——一段粗如手臂的铜闩横贯柱身，锁舌外露，舌面上刻着两排密密麻麻的细字。

林一凡凑近去看。那些细字全是一个名字：沈临渊。

“这是你爸的名字。”铜室角落里，黑影已经等在那里。它的轮廓比之前清晰了些，隐约能看出一个人形，但身体表面始终罩着一层流动的黑雾，看不清五官。

“我妈为什么会把一个人关三次？”林一凡盯着那两排“沈临渊”三个字，反复数了一遍——正反两排，各三个，共六个名字。三次，一共刻了三次。

“因为我怀疑沈临渊不是你爸。”黑影说，“第一次，抓了他三个月，发现是假的，放了。第二次，又发现他送来的信笔迹不对，关了一年，还是放了。第三次——”

黑影沉默了。

林一凡：“第三次怎样？”

“第三次，你妈发现你爸已经死了。”黑影的声音低沉下去，“门外那个叫沈临渊的东西，不是你爸。”

林一凡瞳孔猛缩：“所以我爸在门内？”

“你爸在门外。”黑影纠正他，“门外那个‘沈临渊’才是真的。你妈第三次关进锁舌背后的，是个冒用沈临渊名字的东西——她关了它三年，没放。但也没能杀了它，只能镇压在这里。”

“那门内——”

“门内那个‘死掉的我’，你见过。”黑影打断他，“你说你在归墟里见过一句‘门内死掉的我’。你想过没有，如果你爸在门外，那门内死掉的‘我’，是谁？”

林一凡的脊背一阵发凉。

他盯着铜柱上的锁孔，忽然明白过来：“我手里这枚27号，是锁芯。把它插进锁孔——”

“锁孔会被封死。”黑影说，“27号是‘锁死’的钥匙，你妈用它最后一次封住锁舌里面的东西。28号才是‘开门’的钥匙。”

“可28号被那截手拿走了。”林一凡低头看着手里的27号徽章，裂纹那个“沈”字在暗处隐隐透出一点光。

“27号会带你到锁孔前，但你得先找到28号。”黑影的语气带着一丝急迫，“那只手——锁芯女人的手指——它不会无缘无故来拿28号。它是被锁舌里的东西驱动的。”

铜室深处，铜柱下方突然发出一声沉闷的撞击。铜柱剧烈晃动，锁舌上那六个“沈临渊”的名字同时亮起血红色的光——像是有什么东西在锁舌里面撞击门扉，试图冲出来。

林一凡手里的27号徽章裂纹扩大，“沈”字裂成了两半。

黑影忽然惨笑起来：“你妈最后一句话——‘钥匙不在锁孔里，钥匙在锁舌后面’——她说的锁舌，是指锁舌里面关的那个东西本身。”

“那……钥匙呢？”

“钥匙在‘沈临渊’这个名字里。”黑影说，“你爸真名叫什么？‘沈临渊’是假的，他每次被关，用来顶罪的名字都叫沈临渊。真正那个人的名字，锁在你手里那枚28号里——她在铜水底下刻的第二个名字，才是开门的钥匙。”

林一凡喉头发干：“刻了什么？”

黑影没有回答。它的身体正在淡去，像一块被水浸透的纸正在溶解。

铜柱上的锁舌被撞开一条裂缝，一只布满铜锈的手从裂缝里伸了出来，指尖上，捏着一枚陶土徽章。

28号。

徽章正面，在陶土裂纹中，清晰地刻着三个字：

“沈望未。”

那是他父亲的真名——也是沈望未白活着时用的名字。

林一凡攥紧27号徽章，朝那截铜手冲了过去。而那截手迎着林一凡，摊开了掌心，等着他把27号递上来。

仿佛它在等这一刻，已经等了三十年。

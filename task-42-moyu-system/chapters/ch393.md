# 第393章 潮汐之锁

铁门后的世界比林一凡想象的要大得多。手电光扫过，一座天然溶洞穹顶高悬，钟乳石垂落如獠牙，下方是人工浇筑的水泥池——或者说，是一座小型水牢。水面黑得像墨，看不见底。

金属拖拽声停了。

所有人都屏住了呼吸，那节奏突然消失，比它响起时更令人头皮发麻。男孩攥着林一凡的衣角，指节发白，低声说：“他在水面下。”

老杨头从怀里掏出一根蜡烛点燃，放在池边。烛火在无风的空间里纹丝不动——然后，水面中央出现一圈极轻的涟漪，向四周扩散，荡到池壁边又折返回去。这水在流动，且流向是从下往上涌的。

“潮汐机在下面。”周满囤蹲在池边看了一会儿，翻身就往水里去，“我下去摸结构。”

“等等。”林一凡一把拉住他的手腕，“那东西在水里待了三年，不知道还有什么——”

“怕什么。”周满囤咧嘴笑了笑，露出一排白牙，“我在矿井里摸过比这更深的黑水。”他按下潜水手电，翻身入水，水花压得极低，几乎没声音。

水面很快恢复平静。林一凡数着秒，从三十数到六十，又从六十数到九十。水面的涟漪频率变了，比刚才稍大了一些——那声音从水下传来，金属摩擦石头，沉闷又刺耳。

“卧槽。”林一凡骂了一声，想也没想就要下水。

“别去！”老杨头一把拽住他，“水下有机关，你下去就是添乱。”

话没说完，水面轰然炸开。一颗脑袋冒出来，是周满囤，脸上带着惊喜和恐惧混合的神情：“找到了。闸机不是封死的，是被人从里头卡了一段铁轨。我撬不开，但能挪动——需要两个人同时从两侧拉开。”他喘了口气，“但是，我得先把水位降到安全高度，否则闸机一开，水压会直接冲垮整条通道。”

林一凡眼睛一亮：“潮汐机的位置在哪？”

“在池底正下方十二米处，一个铸铁圆盘，直径一米五，左边凸起来一块。”周满囤说完，又深吸一口气潜下去。

林一凡蹲在池边，盯着黑沉沉的水面，脑子里转得飞快。铜片正面刻着“074”，背面浮现的是“潮是一切的钥匙”——他忽然明白了什么，掏出铜片，放在水面上方三寸处，松手。

铜片没有沉下去。它在水面上稳稳地悬浮了片刻，然后像被磁铁牵引似的，自己滑向池心，绕了两圈，最终“叮”一声贴在池壁上一块不起眼的凸起铁皮上——那铁皮与周围的锈迹几乎融为一体，若不是铜片贴上去，根本看不出异样。

水底响起一声沉重的金属转动声。紧接着，池水以肉眼可见的速度下降，露出湿漉漉的池壁，苔藓浓绿得近乎黑色。水位降到一半时，周满囤从水里站起身来，肩上扛着一根手腕粗的铁杆，对着林一凡喊：“闸机被撬开了！水位在退，水牢的锁链松了！”

远处水牢深处，传来一声低沉的嘶吼——不像是人，更像是某种被囚禁太久、骨头都开始发锈的兽。

男孩猛地抬头，眼圈红了：“爷爷！”

沈临渊的名字悬在所有人舌尖上，男孩已经朝水池对面冲了过去。石壁后方的黑暗中，有人影缓缓移动，佝偻着背，拖动着一根锁链——锁链的一头拴在石柱上，另一头，像蛇一样缠绕着他的脖颈。

那人抬起头来。火光映出一张瘦削的脸，颧骨突出，眼窝深陷，目光却亮得惊人。他和男孩对视，嘴唇张开，喉咙里挤出三个沙哑得不像话的字：“小……知……了……”

那是男孩的小名。

林一凡浑身汗毛倒竖——他意识到一件可怕的事：那根锁链拴着的柱子上，刻着一行字，与铜片背面的字迹一模一样。而柱子下面的地面上，落着一只旧布鞋，磨得几乎露出鞋底的布鞋——与他在泵房管道缝隙里看到的那只鞋一模一样。

老杨头也看见了那只鞋，整个人僵在原地。他的嘴唇颤抖着，终于挤出了一句完整的话：“二十三年前，穿这只鞋的人，是我弟弟。”

沈临渊抬头，目光越过男孩的头顶，落在那枚贴在池壁铁皮上的铜片上。他的声音嘶哑而平静：“你手里那颗铜片……还有另一半。”

林一凡低头看铜片——它正在中央裂开一条细缝，隐约露出里面夹着一张小纸条的轮廓。

# 第108章 地底第五层

老王站在旧机房最深处的阴影里，站姿古怪，头微微歪向一侧，像是在倾听什么无声的指令。他的双眼望着林一凡，但那眼神没有焦距，像是穿透了面前的人看向别处。

“王哥？”林一凡试探性地喊了一声，同时摸向口袋，那个从银章上抠下来的暗码芯片还没焐热。

没有回应。老王僵硬地迈出一步，鞋底在潮湿的水泥地上蹭出刺耳的声响。他的手提着一个老式公文包，包角磨破得露出灰色内衬，表面沾着干涸的深褐色污渍——林一凡上一世在工地见过类似的痕迹，那像血。

赵日天压低声音：“他不对劲，像是被什么东西操控着。”

话音未落，老王骤然抬头，发出一声极低极沉的声音，音调古怪，像从地底传上来的震动：“林……一凡……去负五层……现在。”

声音是他自己的，但说话的方式不像老王平时的语调。老王这个人平时说话慢吞吞的，喜欢用“哎呀呀”开头，带着一种老好人式的绵软。可现在这个声音，像一台老旧的录音机在重复一段讯息，毫无情绪起伏。

“王哥，你怎么了？”林一凡往前挪了半步，赵日天一把拽住他后领：“别冲动！你看他的脚——”

林一凡低头，看见老王那双老旧的褐色皮鞋周围，水泥地面正浮现出一道道细密的裂纹，从老王站立的位置以放射状向外蔓延，像是有某种力场在持续压迫着地面。更诡异的是，那些裂纹里隐约泛着暗红色的微光。

“他在用身体撑某个东西。”赵日天的声音变了调，“那个公文包——里面有能量源。”

老王又重复了一遍，眼皮都没眨：“负五层，有人在等你。带同源体一起。”

“同源体？”林一凡愣了一瞬，随即反应过来——赵日天刚才把基因锚点嫁接给了他，他们现在共享生命线，某种程度上确实是“同源体”。老王知道这事？他怎么知道的？他刚才人还不在现场！

“王哥，周莉呢？”林一凡决定赌一把，他上前一步，声音放低，“周莉的锚点是不是你引导切换的？”

老王的身体猛地一震，像触电一样剧烈痉挛了两秒，然后那空洞的眼神忽地有了焦点。他看看林一凡，又看看赵日天，一脸茫然：“你们……怎么在这儿？我刚才在修机房的管道……”

他低头看到脚下的裂纹，脸色瞬间惨白如纸：“这什么玩意儿……”

“王哥，你手里那个公文包，哪来的？”林一凡的视线紧紧锁在那个包上。

老王低头看了一眼，然后露出一种极不自然的笑容：“包里啊……没什么，就是一些旧图纸。哦对了，我想起来了，我刚才接到物业的电话，说负五层的消防管道漏水，让我下去看一下。”

他一边说，一边低头拍拍裤腿上的灰，顺手把公文包夹在腋下：“我去负五层转一圈就上来，你们年轻人赶紧回办公区吧，别让行政那边看见你们在机房。”

林一凡和赵日天交换了一个眼神。老王的话语没有任何毛病，语气亲切，动作自然，像是随口说了一句“今天中午食堂有红烧肉”。但这种“自然”本身就足够诡异——如果一切正常，老王为什么会出现在这个他根本不应该知道存在的地方？

“王哥，我跟你一起去。”林一凡的语气斩钉截铁。

老王的笑容僵了一下：“一凡，你别跟着。负五层那边有点味儿，管道老化严重，怕你闻着不舒服。”

“王哥，你那个包在滴东西。”林一凡指着公文包底部，那里渗出一滴暗红色的液体，落在地面的一瞬间，脚下的裂纹里那股暗红色微光像被点燃了一般闪烁一下。

老王低头看了看，然后叹了口气。那声音从喉咙里挤出来的，带着一种说不出的疲惫：“哎呀……被你看见了。”

他缓缓打开公文包，里面躺着一台比巴掌略大的黑色仪器，表面布满黄铜色的刻度盘和按钮，正中央嵌着一枚银色的徽章——和林一凡口袋里那枚银章的图案一模一样，只是更大、更完整。

“这是银章的母体。”老王的声音恢复了熟悉的绵软，“那个‘断根计划’执行者，把母体留在旧机房下面。我本来以为是件古董……结果它一碰上我，就把我给‘接’上了。”

他抬头看了林一凡一眼，眼神复杂：“一凡，这玩意儿告诉我，负五层埋着的东西，跟你重生的真相有关。它需要在场三个人才能打开门。”

“三个人？”赵日天皱眉，“你，我，他——就三个。”

老王摇头，慢慢说出那个名字：“第三个人，不是活人。”

机房的灯忽然全部熄灭。黑暗中，那台老式服务器风扇停了，整个世界安静得只剩下三个人错落的呼吸声和地下深处传来的、有节奏的、像心脏起搏一样的闷响。

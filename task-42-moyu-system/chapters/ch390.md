# 第390章 黄铜徽章的另一半

石室里的空气像是凝固了。那男孩说完“沈临渊没死”五个字，角落里一盏应急灯忽明忽暗地闪了两下，啪地一声，彻底熄灭了。

黑暗中，林一凡感觉自己的心跳比刚才快了一倍。他下意识伸手去摸口袋里那枚铜片——温热的，带着他体温的、在泵房捡到的那片黄铜。男孩掌心的徽章074，和他口袋里的铜片，边缘的锯齿纹路完全吻合。

“你手里那东西，给我看看。”

男孩的声音从黑暗中传来，带着一种不属于这个年纪的沉稳。

林一凡没动。沈稚川已经悄悄挪到门边，一只手按在门框上，随时准备拽人跑路。三叔则不知从哪摸出一根手电筒，光柱“啪”地打开，直直照在那男孩脸上。

男孩没躲。他大约十岁出头的年纪，脸上蹭着灰泥，衣服袖子短了一截，手腕瘦得能看见骨头的形状。但他的眼睛很亮，黑沉沉地盯着林一凡，像是要把人看穿。

“你身上那枚，是我爸留下的。”男孩说，“074和075是一对，泵房那枚是075，我在下水道里捡到过它的另一半碎片，后来被孙满仓拿走了。”

“孙满仓？”三叔声音一沉，“钢材转运的那个孙满仓？”

“对。”男孩点点头，“他说那是‘钥匙的一部分’，具体开什么锁，他没告诉我。但他说，我爸在归墟里面等他，等到第三天的潮汐退完，门就要关上了。”

林一凡终于开口了，喉咙有点干：“你爸——沈望，他在归墟里面？”

男孩沉默了几秒，然后说了句让所有人头皮发麻的话。

“他不在归墟。他在归墟下面的笼子里。”

三叔的手电筒晃了一下。

“那个笼子，”男孩的声音轻得像在说别人的事，“就是这批钢材要打的东西。我爸说，笼子不是关他的——是关沈临渊的。沈临渊被锁在归墟底层的水牢里，已经三年了。”

沈稚川呼出一口气：“你说你爸在笼子里——你爸有钥匙，却把自己关进去？”

“因为沈临渊出来的时候，‘零’也得出来。”男孩仰起脸，“你们不知道‘零’是人吧？我爸三年前追查的就是这个。‘零’不是装置，不是代码，是一个人。一个被沈临渊关在水牢里用来维持归墟运转的人——一个活了二百年的老头。”

石室里彻底安静了。只有远处暗渠渗水的声音，嗒、嗒、嗒，像是什么东西在轻轻拍打水面。

老杨头蹲在角落，慢吞吞地抽了口旱烟，吐出来的烟雾在光束里打着旋儿。他终于说话了，声音沙哑得厉害：“那老头……是不是左眉骨有一道疤？”

男孩猛地转头看着他，“你怎么知道？”

老杨头没答话。他站起身，朝男孩走过去，一步，两步，然后缓缓蹲下来，伸出手，把他左边衣袖往上捋了一截。

男孩小臂内侧，有一道细长的、呈放射状的旧疤痕，像是某种烙印被灼过之后再重新长出的肉色。

老杨头看着他，嘴唇哆嗦了一下。

“……是沈望的手艺。”他说，“他给那老头做过标记，用的是潮汐零号机上面的铆钉尖。这道疤，是那老头拿铆钉自己烙上去的，为了防止自己忘了‘零’的位置。”

他顿了顿，像是在想什么，又像是在把某个陈旧的记忆从土里扒拉出来。

“你爸让你来，不只是送图纸吧？他让你把黄铜徽章带出来，是要你找到075的另一半——然后呢？”

男孩把手伸进怀里，掏出一张叠得皱巴巴的纸，展开。

那是一张手绘的平面图，笔触粗糙，但比例清晰。上面画的是归墟的内部结构，三条螺旋竖井交叠在一起，底部标注着一个圆形的凹陷。

“我爸说，泵房底下有个插槽，把074和075拼在一起放进去，水牢的门就能打开。”男孩把图递给林一凡，“但他没让我去。他说‘你去了就回不来了’。”

“那你……”林一凡盯着他，“你怎么拿到这图的？”

男孩咧嘴一笑，露出一颗缺了半边的门牙：“我偷的。”

他说完，转头看向门外：“他来了。我听到脚步声了。”

所有人同时望向石室门口。

暗渠尽头的排水渠边缘，传来一阵湿漉漉的、踩着水走的声响。一个黑影在拐角处停住，喘着粗气，声音听着像跑了整整一座山。

“周满囤？”三叔试探着叫了一声。

“——是我。”那黑影的声音发紧，像是在外面受了什么刺激，“老杨头，你得出来看看。排水渠出口的栅栏……被人从外面焊死了。”

老杨头脸色一变。

“焊死了？”

“对，”周满囤咽了口唾沫，声音发抖，“而且……焊得特别齐整。像是专门找人来干的，不像是临时起意。”

“谁焊的？”

周满囤沉默了一瞬。然后他说了三个字，让石室里的空气像结了冰一样。

“钱总的人。”

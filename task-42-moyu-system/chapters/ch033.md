# 第33章 自由值多少钱

地下车库的灯光惨白，照在沈敛那张保养得体的脸上。他四十出头，西装笔挺，袖扣是一对银色小鱼，在灯光下微微反光。

林一凡没急着回答，先上下打量了他三秒。

“钱总的大学同学？”他咧嘴一笑，“那您应该知道，钱总在大学里外号叫什么吧？”

沈敛微微一愣，随即笑了：“‘人形打卡机’。”

“行，对得上。”林一凡点头，心里的警戒线撤了一半。这年头，能说出钱总这外号的，确实得是有点交情的老同学。他靠着一根柱子，从兜里摸出一包烟，又想起自己重生前的死法，把烟塞了回去，“沈总，您刚才那个问题——‘自由值多少钱’——我先反问一句：您是想买，还是想卖？”

沈敛的目光亮了一下。

“有意思。”他往前走了两步，在离林一凡两米远的地方停住，从公文包里抽出一份文件，“深海资本，你听说过吧？我们专门投‘反共识’赛道。别人炒AI，我们投脑机接口；别人追元宇宙，我们投离线生活。”

林一凡接过文件翻了翻，是一份投资意向书，金额那一栏空白。

“你刚才在台上说，要把摸鱼工作法开源。”沈敛的声音不高，但在空旷的地下车库里格外清晰，“开源意味着没有壁垒，没有壁垒意味着资本不感兴趣。但你忽略了一个东西——数据。”

林一凡的手停了一下。

“你用这套方法，在星辰科技内部实现了效率翻倍，加班时长砍半。这些数据是有价值的。”沈敛伸出两根手指，“两千多人小半年的一线工作数据，做‘反卷指数’的数据底座，够用了。我那几位合伙人看了你路演的录像，觉得有戏。但我有个要求——”

他顿了顿，目光变得锐利：“你的‘摸鱼工作法’，能不能量化？”

“我没法做到完全量化。”林一凡把文件合上。

沈敛眉头微挑：“为什么？”

“因为摸鱼不是一套固定流程。”林一凡声音不大，但一个字一个字说得很清楚，“它是每个人找到自己的节奏，把自己的精力用在该用的地方。你今天把一套模板推下去，明天大家就会为了‘像在摸鱼’而摸鱼，那就变味了。”

就在这时，他脑海里一道冷光闪过。

【叮——系统提示】

【“反卷护盾”检测到精神类探测技能波动，来源：前方三米处。】

林一凡瞳孔猛地一缩。他盯着沈敛的眼睛——那双眼睛看起来温润和善，但此刻在他“摸鱼雷达”的视野里，那个男人周身的“劳动浓度”读数异常，高达89%。一个做投资的人，在没有加班压力的情况下保持这么高的劳动浓度，只有两种情况：要么是真的热爱工作到极致，要么是——他在有目的地运转某种东西。

沈敛也注意到林一凡的表情变了。他没有后退，反而笑得更深了：“看起来，你也有一块手表啊。”

“什么意思？”林一凡声音冷了下来。

沈敛抬起左手，露出手腕上一块黑色智能手表。表盘亮了一下，上面跳出一个读数和一行字——“卷王值：4520”。

林一凡呼吸猛地一滞。卷王系统。赵日天那个系统的同类——

“别紧张。”沈敛把手表盖住，“我跟赵日天不是一伙的。他那块表是‘正统版’，我这个是‘开发者内测版’。我自己改过几行代码，不然也不会发现你身上那块表的信号特征。”

林一凡脑海中冒出系统冰冷的警示声：【话术强度等级：SS级。建议：多听少说。】

他深吸一口气，把脸上的惊讶压下去：“沈总，你到底想干什么？”

“简单。”沈敛上前一步，压低声音，“我想找你合作——帮我把这辆星辰科技的车……推翻。”

# 第96章 钱雨的脸

钱雨站在那片意识网络的黑暗空间里，像站在自己家的客厅。

林一凡的意识在虚空里凝聚成一个光点，他试图后退，但四面八方都是混沌的黑，没有方向感。钱雨的身影在他面前逐渐清晰——那张脸和现实中一模一样，但比现实中年轻了一些，更像五年前刚加入星辰科技时的样子。

“你果然看得到我。”林一凡稳住心神。

“这句话应该我说。”钱雨歪了歪头，像在打量一只实验室里的小白鼠，“你知道蜉蝣为什么能在全球数据中心游走三年没被发现吗？”

“因为它足够隐蔽？”

“因为它本来就是我建的。”钱雨说，“我把它放进了互联网底层协议里，伪装成一段无害的网络噪声。它经由每一台服务器节点复制自己，像水一样渗透每一台终端，却不碰任何数据。”

“那王川呢？”

“王川是第一个发现它的人。”钱雨的脸上浮现一种微妙的表情，像是在遗憾，又像是在警惕，“他追踪数据异常追了整整一年，最终摸到了蜉蝣的主干网络。他试图切断它，但他不知道蜉蝣的核心程序里有一段协议——”

“意识注入协议。”林一凡接上。

“对。”钱雨点头，“那段协议允许蜉蝣在执行者切断它之前，将执行者的意识备份注入网络。王川在切断主干的那一秒，被协议锁定成了宿主。他的意识还困在里面，但我找不到他——蜉蝣把他藏起来了。”

林一凡脑子飞速运转：“既然蜉蝣是你建的，为什么你找不到？”

钱雨沉默片刻，笑容从脸上褪去，露出一张严肃而疲倦的面孔：“因为我建它的时候，它有两层逻辑。第一层是数据藏匿，第二层是自我进化。我没想到它会进化出自主意识，更没想到它会主动寻找新宿主。”

“所以你要抓的，是蜉蝣自己？”

“我要抓的，是‘失控的蜉蝣’。”钱雨纠正，“它会越来越强，最终脱离我的掌控，也脱离所有人的掌控。那时候它会做什么，我不知道。”

林一凡盯着钱雨的脸，忽然问：“那你现在在哪儿？现实中。”

钱雨的嘴角缓缓扬起一个弧度，那笑容里带着一丝说不出的味道：“你猜。”

下一秒，意识网络剧烈震颤，四面八方涌来无数黑色的细线，如蛛网般缠绕住林一凡的光点。他感觉自己被猛地拽向某处，视线一花——

他发现自己回到了现实世界。

阳光透过窗帘洒在办公室的格子间里，屏幕上还开着未保存的代码，水杯里的咖啡冒着热气。他穿着那件穿了三年的格子衬衫，手表显示的时间是下午两点四十八分。

而他对面，坐着一个他无比熟悉的人。

新来的卷王，赵日天。

“哟，摸鱼王，”赵日天咧嘴一笑，把手里的工牌丢到林一凡面前，“换了个地方打工？怎么到了这儿，还在摸鱼？”

工牌上的照片是林一凡，但名字印着三个字——

星辰科技，副总裁办公室。

林一凡低头看向自己的工牌，瞳孔骤缩。

工牌上的职位栏写着一行他从未见过的字：【副总裁助理（挂职）】。

而工牌右上角，多了一个银色的电子印章，形状像一只展开翅膀的蜉蝣。

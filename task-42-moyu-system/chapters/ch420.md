# 第420章 沈字裂纹

石室里的空气像凝固的铜汁，沉重得让人喘不过气。林一凡蹲在那片烧铜遗址前，指尖悬在灰烬骨钉上方三寸处，不敢落下去。

裂纹弯弯曲曲，从钉帽延伸而下，像一个孩子初学写字时歪歪扭扭画出的笔画——但那分明是个“沈”字。一笔一划，像是被什么东西从内部顶开来，带着一种无声的、执拗的挣扎。

“你刚才说……我爸叫什么？”林一凡的声音有些干。

老杨头大哥站在他身后，右手仍在微微发颤。他抠出左眼后，眼眶里那个凹陷的洞已经被一层灰白色的东西糊住了，像是燃烧过后的灰烬遇水凝成硬壳。他没去碰，只是盯着林一凡手里的骨钉，嘴唇动了动：“沈临渊。我认得这三个字，死也认得。”

“你不是说杨林是你儿子吗？”林一凡猛地站起来，“怎么又变成沈临渊了？”

老杨头大哥沉默了很久。石室里的火把噼啪作响，把两个人的影子拉得忽长忽短。他最终叹了口气，伸手从那堆铜渣里扒拉出一样东西——是一块巴掌大的铜片，边缘被烧得卷曲，但上面还能看见几个勉强可辨的刻痕。

他把铜片翻过来。林一凡看见了——铜片背面刻着三道斜杠，一道比一道深，像指甲在金属上硬生生抠出来的印记。

和手机消息里说的B3地下档案室门上的记号一模一样。

“三道杠，”老杨头大哥哑着嗓子，“这是你妈的习惯。她每关一个人，就在那人的门上刻一道。她关过沈临渊三次，前两次都放了，第三次……没放。”

林一凡觉得自己的心脏像是被什么东西攥住了。他想起那些伏笔，那张黄纸上写的“杀身铸锁，不解锁不死”八个字，忽然像八个钉子一样深深扎进脑子。他猛地抬头：“那我小时候和我妈一起生活了六年，那时候我爸在哪里？”

老杨头大哥的光秃秃的眼眶转向他，那只完好的眼睛里泛起一层浑浊的光：“你妈关他的那六年，不是在锁外面，是在锁里面。”

“什么意思？”

“那扇门不只是一扇门，门后的空间和你妈的精神是连在一起的。她把沈临渊锁在门里，等于把自己的一部分也锁进去了。这六年里你见到的那个‘沈临渊’——”老杨头大哥指了指铜片上那道最深的斜杠，“是门里的他，不是门外的人。”

“那不是同一个？那我爸现在在B3地下档案室里关着的人……又是谁？”

老杨头大哥没有回答这个问题。他只是把那片铜片塞回铜渣堆里，像是怕什么东西听见似的，压低了声音：“你妈烧自己之前，来过一趟我这里。她说了一句话——‘钥匙不在锁孔里，钥匙在锁舌后面。’”

林一凡愣住了：“锁舌后面？”

“锁舌后面是什么？”

“我也不知道。你妈没说完。她说，等你儿子找到第三根骨钉的时候，你帮他一个忙，把那颗珠子抠出来给他。”

老杨头大哥说到这里，忽然从怀里掏出一样东西。林一凡看了一眼，瞳孔猛地缩紧——那是一个陶土徽章，和他口袋里的几乎一模一样，但上面的数字是“27”。

陶土徽章27。

而林一凡手里的徽章是28。

他猛地翻开系统面板。半透明的光屏浮现在眼前，陶土徽章的资料一栏里，原本只有一行字：“编号：28；用途：未知。”如今，那一行字发生了变化，多了一行暗红色的字迹——

“编号：27；编号：28；归墟双钥；一枚开门，一枚关门。”

“开门和关门……”林一凡低声重复了一遍，忽然觉得后脊发凉，“那我手里这枚，是开门的还是关门的？”

老杨头大哥把27号徽章递到他面前：“你妈说了，28号是你自己那枚，27号是杨家祖传的。两枚合在一起，才能在你爸那扇门上开一道缝。”

“缝能干什么？”

“能干——”

老杨头大哥话音未绝，石室突然剧烈震动起来。铜渣从头顶簌簌而下，那堆烧铜遗址中央忽然裂开一条缝，缝隙深处涌出一股刺鼻的铜腥味。紧接着，林一凡手机屏幕上，那条落款“杨林”的陌生消息又弹出一条新内容——

“别收27号徽章。那是假的。”

林一凡握着陶土徽章的手指骤然收紧。他猛地抬头看向老杨头大哥，后者正静静看着他，那只完好的眼睛里映着火把的光，不知为何闪过一丝极其复杂的神色。

“你妈烧铜的时候，一共烧了三个徽章。”

老杨头大哥缓缓开口：“一个在我这里，一个在你手里，还有一个……在铜水最底下，还没捞出来。”

震动停了。石室归于沉寂。

林一凡低头看了一眼手机屏幕，那条消息下面还有一行小字，像是被什么力量压住、勉强才发出来的——

“你面前那个‘老杨头’，不是活人。”

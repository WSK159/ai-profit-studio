# 第101章 物理层钥匙

兑换的确认键悬在眼前，林一凡的手指悬在半空，像被什么东西钉住了一样。

系统面板上那行字安静地躺着：“物理层钥匙——兑换价格：99999咸鱼值。”这个数字精确得令人毛骨悚然，像是有人知道他账户里每一分余额，故意把价格定在了刚好掏空他的位置。

“你在犹豫。”赵日天的声音从身后传来，带着一种奇怪的笃定，“正常。我也犹豫过。”

林一凡没有回头：“你也见过这种东西？”

“我的卷王系统里，有一页叫‘永动机开关’，标价同样是我当时全部存款。”赵日天走到他身侧，盯着虚空中那面只有系统持有者才能看到的光屏，“我没换。因为我当时觉得，能开价的东西，说明它早就被标记好了。”

“可你后来还是来了这里。”林一凡终于转身，直视这个亦敌亦友的男人，“说明你也想通了什么。”

赵日天沉默了片刻，嘴角勾起一个意味不明的弧度：“我来，是因为我发现自己从一开始就被设计了。卷王系统的第一个任务，是‘在入职当天完成双倍工作量’——你觉得一个系统，为什么要让宿主在一开始就去卷？”

林一凡的瞳孔微缩。他的摸鱼系统第一个任务是“在厕所待满15分钟”。两个系统的初始任务截然相反，但它们都在做同一件事：让宿主做出选择。

“你的意思是，系统的核心不是奖励，是筛选？”

赵日天没有回答，只是看向走廊尽头那道幽暗的光。老王意识所在地——或者说，那个自称老王的东西，还在那里。他们方才从它口中得知了蜉蝣的真相，但那个意识体的话语里有多少真、多少假，谁也不知道。

林一凡低下头，手指在虚空中轻轻一点——确认。

“叮。”系统的声音比平时更沉，仿佛在应答某种外来的力量。整个数据走廊开始剧烈震动，脚下的地面像水面一样泛起涟漪。下一秒，一张完全陌生的界面在他视网膜中展开——不再是那套熟悉的、带着咸鱼味的UI设计，而是一张空旷的图纸。

图纸上只有一条线。线的一端标注着“蜉蝣底层——数据坟墓”，另一端指向一个坐标。

“那是哪里？”赵日天凑了过来。

林一凡盯着那个坐标，心跳漏了一拍：“……是星辰科技旧楼的地下三层。我入职那年，那层已经封了。”

图纸上的线开始闪烁，旁边浮现出几行小字：

“物理层钥匙已激活。可物理介入蜉蝣系统核心，上限1次。注意：开启后，现实世界将以意识体形态传输至核心节点。节点守护者：未定义。”

未定义。这三个字在系统里从没出现过。

“你有没有……”林一凡刚开口，赵日天就接上了他的话：“感觉到？一个不太均衡的东西。像是有人在另一边拧紧了某颗螺丝。”

两人对视一眼，同时大步往回走——回老王意识体所在的那个房间。推开门的那一瞬，林一凡看见了让他头皮发麻的一幕：老王的面容正在缓缓变化，五官线条一寸寸地模糊、重置，像一张被揉皱后重新摊平的照片。

那不是老王的脸。那是一张更年轻、更锋利的男人的脸。眼窝陷得更深，嘴角带着一种极其细微的、似笑非笑的弧度。

“……钱塘。”林一凡低声吐出这个名字。

那个意识体缓缓睁开眼睛，声音不再是老王的沙哑，而是冰冷的、金属般的质感：“你终于把我的钥匙，送到了它该去的地方。”

赵日天的手勐地按上腰间——那是他留存物理装备的位置——但林一凡拦住了他。他盯着那张陌生又似曾相识的面孔，问出了最关键的问题：

“老王的意识，从一开始就不存在，对吗？”

那个意识体笑了，笑意不达眼底：“老王存在过。只是你见到他的时候，他已经被我覆盖了40%。你们聊的那几分钟里，覆盖率恰好是——54%。”

林一凡的拳头攥紧，指节泛白。

也就是说，他在走廊尽头得知的一切关于蜉蝣的“真相”，都有可能是这个意识体编织的引导语。

周莉的呼救仍在耳边回响。他深吸一口气：“你想要的钥匙——我已经换出来了。现在告诉我，周莉在哪。”

钱塘的面容微微偏头，像一个好奇的孩子：“你确定要现在去找她？她已经签了那份协议。现在的她，不再是和你一起的那个周莉了。你见到她的时候，她未必还认得你。”

“你只需要回答，她在哪。”

钱塘缓缓抬起手指——指向他自己身后，那道仍在嗡嗡作响的黑暗深处。

“……她在蜉蝣的核心里。而且，她不是第一个被‘吞进去’的。我的妹妹钱雨，也在那里。”

林一凡的瞳孔勐地一缩。钱雨，那个守在根服务器里的女人——他们以为她是在封锁蜉蝣，难道本身也已经被吞入其中了？

赵日天低声道：“这是个陷阱。”

“当然。”钱塘的声音平静得可怕，“但你已经打开了门。”

走廊深处，那道暗光开始像心脏一样脉动起来。林一凡感觉自己的意识被一股无形的力缓缓抽出……兑换“物理层钥匙”的效果，开始生效了。

他还没来得及开口说一个字，整个人便被拖入了那道黑暗之中。

身后，赵日天的怒吼被无限拉远。

# 第133章 数据库深潜

林一凡的工牌在星辰科技总部大楼的门禁上“嘀”了一声，闸机应声而开。凌晨两点十七分，大楼里只剩走廊的应急灯泛着惨白的冷光。他捏了捏口袋里那张从赵日天手里顺来的加密U盘，胸口系统面板上的倒计时数字跳动着——68小时22分。

“目标是旧版OA系统的备份数据库。”他在心里默念着系统刚弹出的支线任务提示，“第三枚暗码碎片曾作为元数据写入公司早期服务器日志。”

电梯缓缓升到九层，林一凡走出轿厢，鞋底踩在光洁的大理石地面上，发出细微的回声。九层是星辰科技的历史档案区，早在两年前就已被划为“低效用区域”，整层只有几台嗡嗡作响的老旧服务器还在运转。他摸出手机，屏幕上提前植入的木马程序自动劫持了这层的监控信号，画面定格在无人的走廊。

他推开档案室的门，一股积尘的霉味扑鼻而来。角落里那台泛黄的IBM服务器机型几乎让林一凡愣住——这是十年前的老古董，他实习时用的正是这一款。系统提示音在他脑中响起：“检测到目标区域，检索密钥需调用‘摸鱼空间’专注模式，预计耗时3小时。”

“三小时？”林一凡扯了下嘴角，“那就麻烦系统大人帮忙看门了。”

他正要坐下来进入摸鱼空间，手机却突然震了一下。屏幕上弹出一条陌生号码发来的短信，内容只有八个字：“别查F-7以外的东西。”

林一凡脊背一凉。这条短信的语气、措辞，像是某个知道他此行目的的人发来的警告。他正要回拨，信号栏却变成了无服务。他沉住气没有深想，将手机反扣在服务器上，闭上眼，意识沉入摸鱼空间。

空间里是一片宁静的星空。三小时的工作量在他指尖化作无数光流，他模拟出旧系统的登录环境，用咸鱼值兑换的“记忆回溯”技能一点一点重构十年前的数据碎片。凌晨五点十二分，当检索进度推进到97.63%时，一条异常数据流出现在屏幕上。

那是一段被反复加密、嵌套了至少五层伪装协议的日志文件。林一凡用摸鱼空间里的解码工具层层剥离，最后跳出来的东西让他瞳孔骤缩——是一段坐标：北纬31°14′，东经121°29′。

上海。市中心的经纬度。

更诡异的是，坐标下面附了一行注释：“这不是第三枚碎片的位置。这是囚禁它的钥匙孔。”

林一凡猛地睁开眼，从摸鱼空间里弹出。档案室里的老服务器屏幕不知何时亮了起来，幽蓝的光映在墙上，隐隐约约浮现出一个巨大的眼睛图案。他心头一沉——那图案和“第三只眼”的标志一模一样。

服务器发出一阵尖锐的蜂鸣，紧接着所有指示灯同时熄灭。门外的走廊传来一阵脚步声，缓慢、沉稳，像是有人刻意放轻了动作，正一步一步朝档案室走来。

林一凡迅速藏好U盘，闪身躲进服务器柜与墙壁之间的夹缝里。脚步声停在门外，停顿了大约三秒，接着门上传来“咔哒”一声轻响——有人用钥匙打开了这扇本该锁死的门。

门被推开一条缝，一只眼睛从缝隙里扫了进来。

# 第333章 母亲的访客

林一凡放下茶杯，动作没有一丝慌乱，但手心里全是汗。他抬眼看向钱总：“我妈叫沈稚冬？钱总你记错了吧，我叫林一凡，她叫林秀兰。”

他说的是事实。母亲身份证上的名字确实是林秀兰，户口本、老家族谱、他所有的档案材料里，没有出现过沈稚冬三个字。她是父亲口里的“你们妈”，是邻居口中的“林婶”，是外婆提到时眼角湿润的那个“秀兰”——沈稚冬这个名字，只存在于防空洞那盘磁带里：“沈稚冬没有来过。”以及刚才，钱总嘴里。

钱总看了他两秒，笑起来：“那就是我记岔了。前台的访客登记马虎得很，大概是同名。”他摆了摆手，“行了，项目的事你回去想想，明天给我个准话。”

林一凡站起来：“那我先走了。”

他转身往外走，步子不快不慢，走到门口时回头：“钱总，访客登记的纸条还在吗？”

钱总低头翻找了一下，从文件堆里抽出一张薄薄的纸：“喏，前台递上来的。你要看？”

林一凡折返回去，接过那张登记纸。访客登记栏用碳素黑笔填着一行字迹：沈稚冬，要找林一凡，联系电话后四位是7621。字迹娟秀工整，每一笔都收得很稳，像练过硬笔书法的人写的。

妈妈的笔迹和这很像。

他在前世七岁那年见过母亲写字——母亲在药房抽屉里翻出半张旧病历单，背面写电话，一笔一画，横平竖直。那时候他看不懂母亲写了什么，只记得那一笔一画写得很用力，像是把什么话压在纸下面。此刻见到同样的收笔习惯，他的手指微微颤了一下。

“认识？”钱总问，语气随意得像在聊天气。

“字挺好看。”林一凡把登记纸放回桌上，说了句不痛不痒的话，“我先下去了。”

电梯门合拢的那一刻，他掏出手机，给沈望的号码发了条短信：“沈稚冬今天上午来公司找我，人到了吗？”

五秒后，回复进来：“谁告诉你的？她不该出现。”紧接着第二条，“你在哪里？别动，我来找你。”

林一凡握着手机站在电梯里，盯着屏幕里那行字，脑子飞快转：“她不该出现”——沈望知道沈稚冬是谁，而且知道她不应该出现在这里。那是一个表态，也是一个确认：沈稚冬确实死了，或者说，不应该再活着。那来公司找他的人是谁？

电梯到了十二楼，他没回工位，直接从安全楼梯下到负一层停车场。他站在柱子后面的阴影里，透过停车场的窗户看着园区大门方向。一辆银色面包车停在园区外的路边，没熄火。一个中年女人的身影从副驾驶座上下来，站在车边，朝着公司大楼的方向看了一眼。

距离太远，看不清脸。但他凭身形轮廓判断，那人的体态、站姿、甚至低头看手机的习惯动作，与他记忆里的母亲如出一辙。可母亲已经死了七年，他重生后的这具身体拥有的记忆不会骗人。

面包车旁边，另一个身影从驾驶座下来，是个穿灰色外套的男人。他点了根烟，那女人和灰衣男人说了几句话，灰衣男人点点头，弯腰从车里拿了一个纸袋递给女人。

女人拿着纸袋，朝园区大门方向走了过去。

林一凡深吸一口气，正要往出口方向走，手机又振了一下。这次是系统面板弹出的提示：

【任务更新】隐藏任务链·归还自由 第三阶段已触发。
线索：访客沈稚冬携带“唯一性物品”——该物品在三秒内不可被系统扫描，需近距离接触后解锁。
警告：若该物品被资本方舟接引者回收，任务链将永久断裂。

林一凡把手机锁屏，贴着停车场侧门快步走出。他绕到大楼侧面的消防通道，那里有一面单向玻璃，能看到园区前广场的全貌。他看到那个自称沈稚冬的女人在门卫处登记，姿态从容，正在等他下楼。她的侧脸在晨光里映出轮廓——额头、鼻梁、下颌的弧线，和他记忆里母亲年轻时的照片几乎一模一样，只多了几道岁月留下的细纹。

但她离开园区时，灰衣男人递给她一个纸袋，那个纸袋在晨光里透着一点银色的光——像是某种金属物件被人匆忙包裹后透出的轮廓。林一凡看清了那形状——一枚钥匙，比普通钥匙长于两指，有老式齿槽，像他在防空洞和赵志强仓库里拿到的那两枚。

第三枚钥匙。不在水塔下，而在一个自称“沈稚冬”的女人手里，由灰衣男人转交。

系统面板剧烈闪烁：

【紧急提示】与唯一性物品建立连接后，隐藏任务链将不可逆转。请确认是否接受？此确认不可撤销，且可能导致“摸鱼系统”与“卷王系统”之间的底层协议冲突。

林一凡站在消防通道的阴影里，看着那个女人在大门口停了片刻，然后转身，朝他的方向看过来。隔着几十米，隔着单向玻璃，她的目光像穿过玻璃落在他身上——她微微抬了抬下巴，像是一个无声的点头，然后转身，走进了那辆银色面包车。面包车发动，驶离园区，汇入晨间车流。

林一凡的手放在消防通道的窗框上，掌心贴着冰凉的金属，指尖微微发白。

他的手机亮了一下，一条新短信，来自陌生号码：“你妈妈让我带句话——她说过，钥匙丢了还能找回来，但人要是丢了，就真的没了。下一次见面，不要带别人。”

发信人署名：灰。

与此同时，系统面板弹出最后一行字：

【已确认连接。隐藏任务链·归还自由 进入不可逆阶段。当前持有钥匙：两枚。远程追踪目标：第三枚已定位，移动中。】

林一凡把那枚“梯三”钥匙从胸口掏出来，看着钥匙柄上那两道细小的刮痕——一道是“别信”，一道是“去”。他忽然明白了什么。

“别信哥。”他低声念出那两个字的组合。

刮痕是给沈望的。他信了沈望，但这两道刻痕合起来的内容，是一个警告——不要信沈望。或者，不要信“哥”。

他握紧钥匙，转身走向电梯。手机上的“效率云”项目合同附件已经发到他邮箱，附件里附了一张地图，标红的位置正是云顶山废弃气象站。

天彻底亮了。新的一天开始，他手里握着两枚钥匙，看见了第三枚的尾灯。

而那个自称“沈稚冬”的女人，把一枚钥匙和一句话，交到了他手里。

世界上不会有两个母亲。但钥匙可以有两枚。

他一脚迈进电梯，按下顶楼的按钮。他要去接受那个“云顶山”项目。

因为钥匙正在向他移动。而他打算在那之前，先把那把锁找到。

# 第300章 002的遗物

那声音持续了约莫五秒，然后像被什么吸走一样，消失在楼板深处。

林一凡没有急着冲进去。他用拇指摩挲着三叉钥匙的齿纹，回头看了赵强一眼。赵强也在看他，目光里藏着一种说不清的复杂。那一瞬间，林一凡忽然想起赵强刚才在路上说的那句话——“两条线最后交在同一根针上”。母亲的遗言，到底说的是哪两条线？

“进去可以，”赵强像是下了某种决心，“但你先答应我一件事。”

“说。”

“不管你待会儿看到什么，见到谁，都别碰那把铁椅子上的东西。”赵强的语气异常认真，“那年我来过这里，陪一个人来过。她坐在这间屋子中间的铁椅子上，说了最后一句话。”

“什么话？”

“她说：‘000醒来那天，001就会开口。等001开口的时候，真正的备份会自己走出来。’”赵强顿了顿，“她说这句话的时候，眼睛里没有任何光。”

林一凡心里一沉。赵强说的“她”，极有可能就是他母亲。他忽然意识到，赵强这段时间跟着自己，不是为了帮谁，而是在替某个人完成一份未尽的承诺。

他深吸一口气，先跨过门槛。

通道尽头是一间不大的手术室，墙壁包着发黄的医用纱布，天花板上垂下一盏无影灯，灯罩上的灰尘被一条电线绊住，悬在半空。手术台锈迹斑斑，角落放着一把铁椅，椅面上刻满了数字和符号，密密麻麻，像是被人在漫长的时间里用指甲刻出来的。

铁椅上没有人。

但椅背上挂着一件叠得整整齐齐的灰工装——正是监控录像里那个老头穿的同款。

林一凡伸手从工装口袋里掏出一个东西：一张折叠的纸条，纸质脆得像枯叶。他展开的时候，纸边碎了一小块，上面的字被时间浸成了褐色。纸条上用蓝色的钢笔写着：“002不是失败品。002是母体。000为002的复制体所造。你——林一凡——不是000的宿主。你是002的孩子。”

他一遍遍重读，每个字都认得，却连不成他愿意接受的意思。他不是000的宿主？那重生前看到的一切，又是谁的经历？监控录像里灰工装老头的那张脸，是他前世的脸，那具身体又是谁的？

赵强站在门口，没有靠近，只低声说：“我配合她把这件衣服挂在这里，是在六年前。那时，她说总有一天会有人回来取走这件衣服。今天，那个人是你。”

林一凡翻过纸条。背面画着一棵树，树根探入深土，树干上分出三条枝：一条标注“000—失败”，一条标注“001—伪装”，最后一条标注“002—真相”。在树的顶端，点着一个圆点，旁边写着一行极小的字：“真相的孩子是钥匙。”

他攥紧纸条，抬头看向手术台下方。台子底下的阴影里放着一个铁盒，盒盖半开，露出里面一卷磁带。磁带标签上用油性笔写着：“2019.6.16——7.2，七天录音。保存人：苏婉。”

是母亲录的。她把父亲被替换那七天的所有声音保存了下来。

林一凡正要伸手碰那盘磁带，手术室门口突然传来脚步声——很轻，但频率固定，像某种机械节拍器在匀速移动。一个模糊的影子出现在门廊尽头，身材修长，穿深色长衫，脸上蒙着白色口罩。那影子停在门槛外两米处，不出声，也不走。

赵强立刻挡在林一凡面前。那影子抬起右手，手上握着一把钥匙——三叉的，齿纹与林一凡那把相反，像一枚镜像。对方的指节缓缓松开，钥匙落在地上，金属撞击声在寂静的手术室里炸开。

然后那影子转身，消失在走廊尽头。

林一凡追出两步，那人已经无迹可循。他低头捡起地上的钥匙，齿纹上有新的划痕，像是刚刚才被刻上去的——三个字母：TSL。

“TSL……”赵强念了一遍，脸色变了，“第一条线的缩写。”

林一凡握紧两把钥匙，腕上的红绳不知什么时候松了结，坠落在铁椅脚下。他弯腰拾起的瞬间，看见铁椅侧面上有一行根本不属于这个时代的字，崭新的，像是昨天才刻上去的。

那行字是：“别回来。写完结局再回来。”

他盯着那行字看了很久，忽然明白母亲说的“两条线”是哪两条了——不是两条时间线，是两条血脉线。一条通向“000”，一条通向“002”。而他站在两条线的交叉点，手里握着两把钥匙。

那盘磁带还在手术台下面，等着他拿。而走廊尽头，那个影子没有离开。它站在楼梯拐角的阴影里，像一尊等了多年的石像，正微微侧过头，似乎在说：

“你可以开始听真相了。”

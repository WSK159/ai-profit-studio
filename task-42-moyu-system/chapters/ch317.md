# 第317章 照片里的第二个人

回到出租屋已经是凌晨两点半。

老王一进门就瘫在沙发上，脸色发白，灌了半瓶矿泉水才缓过劲来：“我、我他妈这辈子再也不跟你俩搞夜袭了，心脏受不了。”

林一凡没理他，把从暗格里拿出来的三样东西平铺在茶几上。灯泡昏黄，照片上的两个年轻人面容在光影里浮浮沉沉。周立冬站在桌前，目光锁死在那张照片上，嘴唇抿成一条线。

“那是我哥，沈稚冬。”他开口，声音沙哑，“旁边这个……”

“是我。”林一凡接话。

周立冬摇头：“不是你。”

“这人跟我的脸，不能说相似，简直是一比一复刻。”林一凡把照片举起来，对着自己的脸比了比，“你要说这不是我，那只有一种可能——这他妈是我失散多年的亲兄弟。”

周立冬沉默。

林一凡放下照片，心里那些线索像珠子一样滚过桌面：黄铜钥匙刻着“沈”字，孙满仓说沈稚冬是周立冬的哥哥，照片里沈稚冬和自己长着一模一样的脸。而他重生的那天，系统绑定他的时候说过一句话，他现在回忆起来怎么想怎么奇怪——“恭喜宿主，你是本系统选中的人。”

当时他以为是随机绑定，现在想想，这个“选中”，更像是一种定向锁定。

“王哥，”他转头，“你说我这个人，看起来像不像有宿命感的那种人？”

老王白他一眼：“你看起来像宿命感很重的那种……麻烦。”

林一凡笑了，伸手拿起那枚U盘。U盘年代久远，接口都还是老式USB2.0的，他翻出一个积灰的转换头，插上笔记本电脑。U盘里只有一个文件夹，名字叫“归”。里面一份文档，打开之后，只有三条记录，格式像某种日志，没有日期。

第一条：“数据源确认。买家六家：三家保险，两家猎头，一家资本方舟。”

第二条：“卖的人不是钱，是钱上面的人。”

第三条：“我故意留下了破绽。希望有人能看见。”

日志末尾还有一行小字，字体跟前面的完全不同，像是后来补写上去的：“看完删掉。别连累后来人。”

林一凡看着这行字，指尖敲了敲桌面：“这U盘的主人，你哥，是个狠人。留证据把自己搭进去，就为了让后来人能看见。”

周立冬终于抬眼：“你有方案了？”

“方案谈不上，但有点意思。”林一凡从冰箱里拿出一罐可乐灌了一口，“你看啊，孙满仓说数据是钱总卖的，但这日志说卖的人‘在钱总上面’。那就说明，钱总背后还有人。资本方舟这个买家，名字起得挺响，我查查他们是什么来头。”

他坐回电脑前，手指刚落在键盘上，手机突然震了一下。

是一条陌生号码发来的短信，只有一句话：

“你拿到了不该拿的东西。明天午时，旧园区A栋三楼，拿U盘来换你哥的消息。”

没有署名，没有落款。

林一凡盯着这条短信，手指一滑，调出号码归属地：本地。他正准备回拨，短信又进来一条：

“别想着定位我。盯你的是谁，你心里有数。”

他猛地抬头看向窗外的方向——对面那栋楼的四楼，某户的灯突然熄了，像是一直亮着等他看到这个瞬间似的。

“王哥，”他一边说一边往门口走，“明天上午帮我请个假。”

老王一脸懵：“你又摸鱼？”

“不，这次是真有事。”林一凡推开门，回头笑了笑，“我去会会那个穿灰雨衣的人。”

他手里的手机屏幕上，那条短信的末尾还跟着一个符号——一把小小的黄铜钥匙。

# 第331章 沈望的口信

凌晨一点，仓库废墟里只剩风穿过铁皮的呜咽。林一凡站在沈望面前，手里捏着那把铜牌钥匙，指腹死死压住那道“别信”刮痕。

“你刚才说第三梯在云顶山，”他开口，声音比预想中稳，“那赵志强在这里守的是什么？”

沈望扯了一下嘴角，笑意没到眼底：“一间装满了假钥匙的空仓库。赵志强三十年前就在收网，他比你更清楚一条船的本事在于它‘不在’哪。”

“那二伯呢？他还让孙满屯守着那条防空洞的道儿……也是在演戏？”

沈望没直接回答。他从口袋里掏出一只折叠的牛皮纸，递给林一凡。纸页泛黄，边角卷起，折痕处磨得发白，像是被反复打开过很多次。

林一凡展开，是一张手绘地图。墨线已经褪成淡褐色，但路径清晰——从防空洞北口蜿蜒向上，切过一片标着“杉树林”的等高线，最终落在山顶一座标注为“气象站旧址”的小方框上。

图纸右下角有一行小字，笔迹苍劲：

“第三梯不在码头，在云顶。沈临渊，1996年夏。”

1996年。那一年林一凡的父亲还没“死”，外公还在正常地给他寄生日礼物。

“这图是你画的？”林一凡问。

“外公画的。”沈望的语气很平静，“他画了两张，一张我留着，一张给了孙满仓。我爸——沈临渊，他早就没打算坐那条船。”

林一凡愣了愣：“他不想走？”

“他走不了。”沈望的目光越过他，落在货架深处那片阴影里，“你外公沈临渊，三十年前从‘劳动神’手里偷走一页契约，藏在第三梯下面。那一页写着‘自由’的代价——它绑定的不是一条船，是一个人。那个人必须留在岸上，保证契约不被任何人使用，包括他自己。”

风突然大了一瞬，货架上某只纸箱“哐”一声翻倒滚落。林一凡肩膀不自觉地绷紧，但沈望站在原地没动。

“所以孙满仓让你别信的人是我？”林一凡问。

“孙满仓让你别信的是所有‘自称哥’的人。”沈望的语气忽然带了一丝复杂，“他说过一句话：钥匙这东西，越像，就越要命。”

他往后退了一步，手插进外套口袋：“我该走了。赵志强的人最晚天亮前会来清库，你带着那把假钥匙没意义。云顶山的气象站，入口在东侧水塔底下，第三梯的锁孔是铜的，钥匙柄没有字——你手上那把，拿到那里自然会对上。”

“沈望。”林一凡叫住他，“你来找我，就是为了送这张图？”

沈望在阴影边界停下来，背对着他，沉默了两三秒。

“孙满仓在防空洞里留给你的那只铁皮柜，他让我带句话。原话是：‘两把钥匙，一个人。死门里的东西，生者不能用；生门里的东西，死者不能拿。你愿意当哪个，自己选。’”

他说完就融进了黑暗里。脚步声沿着货架通道迅速远去，先是皮鞋踩碎塑料的声音，然后是铁门被拉开一瞬的风响，之后彻底安静下来。

林一凡站在原地，捏着那张泛黄的地图，指腹反复摩挲着“沈临渊”三个字的笔迹。那个叫沈望的男人跟他同父异母，但沈望管沈临渊叫“父亲”——这跟灰袍人孙满屯之前说钱总就是沈临渊的另一重身份，在逻辑上撞出了裂缝。

如果沈临渊是钱总，他为什么不姓沈而在林一凡面前装死？如果他不是钱总，那张写着“死门自向死而生之人开”的字条，又是谁留给他的？

口袋里的手机又震了一下，屏幕亮起。信号恢复到三格，一条短信弹出来——号码没有备注，但那串尾号他认得，是钱总办公室那个内线电话。

短信只有四个字：

“明天来见我。”

林一凡盯着那句短信看了十秒，锁屏，揣回兜里。他走到仓库铁门前，推开门，外面天边已经泛起一线灰白。他仰起头，呼吸着凌晨码头的腥咸海风，脑子里翻来覆去只有沈望最后那句话。

“你是要去争钥匙，还是去当钥匙？”

他低头看了一眼手中的铜牌钥匙，指腹滑过那道“别信”刻痕，忽然想起重生第一天系统面板上最底部那行从未变过的灰色小字：

“注意：本系统部分兑换物具有唯一性，且不可被他人转移。持有者死亡时，已绑定物品将自动回归初始坐标。”

第三梯下方那页契约，跟系统绑定的是同一个东西。沈临渊留在岸上守着的那页纸，恰好就是系统无法兑换的那个。

他攥紧钥匙，迈步走进了天光里。

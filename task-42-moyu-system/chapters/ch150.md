# 第150章 前任摸鱼者的遗言

铁门合拢的闷响在密室里绕了一圈才消失。林一凡回头扫了一眼，门缝与墙壁严丝合缝，连一道影子都透不进来，像它从来就不存在于这个物理世界。

他按下心头的杂念，目光重新落回终端机上的加密日志。那组日期，正是他刚重生回来、第一次在城市核心区域摸鱼时触发“高敏坐标”的同一天。日志下方还附着一行批注：“他还在找钥匙孔。但我们都知道——第三道门不是给人进的。”

林一凡盯着“给人”两个字，心里涌起一阵说不清的恶寒。他拖动键盘光标往下翻页，日志底端是一段署名记录，时间为十一个月前。“摸鱼者ID：M-013，代号‘老鱼’。最后一次登录地点：星辰科技B3A层。状态：失联。”

老鱼。他没听过这个代号。但加密日志的格式他很眼熟——跟摸鱼系统发布的隐藏任务页面几乎一模一样。他心头一沉：在这个系统里，除了他，还有别的绑定者？赵日天有卷王系统，那个宋顾问又会是什么？

他继续往下看。日志最后一条记录停留在“老鱼”失联当天的23:47：“我在第三道门后面看到一个不该存在的东西。如果你能看到这段日志，说明你也找到了入口。记住：别信老王，别碰钥匙孔里的钥匙，别让系统检测到你离开摸鱼空间超过十五分钟。”

三条“别”，每条都精准对应他这一路踩过的坑。林一凡盯着“别让系统检测到你离开摸鱼空间超过十五分钟”这半句话，指节发白。他猛然想起一件事——今天下午他在评审会上用过一次摸鱼空间，时间是十四分五十八秒。那几乎是贴着线的极限。

也就是说，那个“老鱼”不但知道摸鱼空间的存在，还精确地验证过系统的触发规则。而所谓的“违规清零”，很可能压根不只是摸鱼被抓的惩罚，而是跟“离开摸鱼空间”的停留时长绑定。

“系统……给出你的规则解析。”他低声说。

脑海里淡蓝色的面板闪烁了一下，弹出两条新消息：【咸鱼值违规清零触发条件已更新：当宿主离开摸鱼空间超过十五分钟且身处特定高敏坐标时，系统核心功能将被强制锁定。】下方的补充栏里，一行灰色小字渐渐浮现：“此规则修改于999天前，修改人签名：M-013。”

林一凡吸了口冷气。规则是可以被人为修改的——系统不是铁板一块，有后门。而这个后门的创建者，极可能就是面前这台终端机的主人，那个代号“老鱼”的前任摸鱼者。

他继续翻日志，找到一段用暗红色字体标注的追加记录：“我发现了宋的身份。他也不是普通人。他和赵日天之间，有一条交易链路。日天数据公司不过是个壳——真正持有数据流向的，是第三个人。那个人现在就在你们公司，跟老王坐同一层楼。”

“第三个人……跟老王坐同一层楼……”林一凡脑中飞速筛选，宋顾问今天的言行、老王这些天的立场摇摆、赵日天在评审会上的冷笑……全都在他眼前交织成一张巨大的网。他正要继续翻下一页，终端机屏幕却陡然熄灭，整个密室陷入一片漆黑。

几秒钟后，紧急备用灯亮起，终端机键盘下压着一张小纸条，上面只有一行字，字迹干涩潦草：“你背后那个人，正在看你。”

林一凡猛然转身。密室角落那扇本该关严的铁门，此刻正半开着一条缝，缝隙后面，一双穿着黑色皮鞋的脚一动不动地立在阴影里。他的后颈汗毛全部竖了起来。

那道人影往前迈了一步，低哑的嗓音在密室里响起：“小凡，你找到我不让你去的地方了。”

是老王的嗓音。

# 第318章 旧园区

早晨七点，林一凡被手机闹钟吵醒时，第一反应是去看短信。那条深夜的信息还躺在收件箱里，白纸黑字，清清楚楚：明日午时，旧园区A栋三楼。以U盘换你哥的消息。末尾那把黄铜钥匙的符号让他后槽牙发紧。

他翻身坐起，周立冬已经不在沙发上了。厨房里传来煎蛋的滋滋声，还伴着一股焦味儿。林一凡趿拉着拖鞋走过去，看见周立冬正用锅铲跟一个破边的煎蛋搏斗，旁边老王在烧水，眼睛红得像兔子。

“你没睡？”林一凡问。

老王回头看他，欲言又止，最终只说：“那个短信……”

“我知道。”

周立冬把煎蛋翻进盘子里，语气淡淡：“我陪你。”

林一凡摇头：“对方点名叫我，你们去了反而打草惊蛇。”

“放屁。”老王难得爆了粗口，“万一又是那个灰雨衣，你一个人——”

“灰雨衣要的是U盘，不是我的命。”林一凡捏起那片煎蛋，咬了一口，焦得像饼干，“他要的是交易。交易就得有谈的余地。”

周立冬还想说什么，被林一凡举起手里的煎蛋挡了回去：“先吃饭。这事我心里有数。”

上午九点，林一凡把U盘做了个备份，放进贴身口袋，又拿了个空的U盘塞进外套内袋。老王的门禁卡再次派上了用场——旧园区那片早就废弃了几年，管理松散，外人的确能混进去。他拒绝了两人的跟随，独自拦了辆出租车。

旧园区A栋是一栋六层的旧办公楼，外墙的瓷砖剥落了大半，露出灰扑扑的水泥底。底层的卷帘门锈迹斑斑，只有侧面那个小铁门虚掩着。林一凡推门进去，楼道里一股霉味混着灰尘扑面而来，墙皮翘起成片，脚踩在水泥地面上，回声空旷得发闷。

三楼。他一路摸上去，沿途每层楼的门都锁着，只有三楼走廊尽头的那间房门半开，透出一道昏黄的光。

他放轻脚步走过去，在门口站住。屋里只有一把旧椅子，椅子上坐着个穿灰色夹克的人，脸藏在阴影里，手边搁着一只保温杯，水汽袅袅升起。像是等了他很久。

“来了？”那个人开口，声音沙哑，像被砂纸打磨过，“坐。”

林一凡没进去，靠着门框打量着对方：“我哥的消息呢？”

灰色夹克的人低头笑了两声，抬手把椅子旁边的落地灯拧亮。林一凡看清了那张脸——方脸、浓眉、右眼角一道疤，五十来岁，满身旧工装的油渍味。他不认识这个人。但这人脸型轮廓，隐约让他想起周立冬给他看过的那张老照片里，站在沈稚冬身边的那个男人。年轻版，但轮廓能对上。

“孙满仓？”林一凡试探性地问出这个名字。

那人没有否认，只是站起身来，走到门边的窗户旁，往下看了一眼，确认没有尾巴，才重新看向林一凡：“你哥让我把东西交给你。但得先确认，你是不是那边派来的人。”

“那边是哪边？”

“资本方舟。”

林一凡的瞳孔微微缩了一下。他想起U盘日志里写着的那句话：数据买家包含资本方舟。如果这个自称孙满仓的人是沈稚冬那边的，那他怎么会知道“资本方舟”这个词？

他冷静下来：“那你觉得我是吗？”

孙满仓盯着他看了三秒，忽然从裤兜里摸出一枚铁皮哨子，递到林一凡面前：“吹一声。”

“什么意思？”

“你哥当年教我的暗号。他跟我说，如果有一天有人拿着这枚钥匙来找我，先让他吹哨。吹完哨子，我认人。”

林一凡接过那枚哨子，脏兮兮的黄铜表面，锈迹斑斑，柄上用刀尖歪歪扭扭刻着一个字——“沈”。他心头一紧，这刻字的手法，和钱总暗格里那把黄铜钥匙如出一辙。两把钥匙，同一把刀，同一个人刻的。

他低头吹了一声。那声音又尖又涩，在空旷的旧楼里格外刺耳。哨音落下，孙满仓的肩线明显松弛了一些，他重重吐出一口气，重新坐回椅子上：“行，是你。东西你拿到了吧——U盘？”

林一凡没回答，反问：“我哥在哪？”

孙满仓沉默了一下，伸手从怀里摸出一样东西，扔了过来。林一凡接住，是一块怀表。表壳是黄铜的，样式和他自己那块一模一样，表盖上同样刻着一行细如蚊足的字。他翻过来看，那行字是：归。

和U盘文件夹的名字一模一样。

“你哥跟我约好，如果他出事，就把这块表交给拿钥匙来的人。”孙满仓的声音放低了，“但他说过，不到最后一步，不要让‘归’字重见天日。”

林一凡攥紧那块怀表：“所以他现在……”

孙满仓没有直接回答。他转过身去，拉开窗户，回头看林一凡：“你有没有想过，为什么你哥的亲生弟弟，从小到大被安排得滴水不漏，前程、工作、户口、房产，一样不少？”

“什么意思？”

“因为你从出生起，就是他的‘退路’。”

这句话在林一凡脑海里炸开一条裂缝。他刚想追问，整栋楼忽然震了一下——不是地震，是沉重的脚步声。从楼梯间传上来，正一步一步往上走。

孙满仓脸色骤变，一把抓住林一凡的胳膊：“今天这事不能让人看见。你从后窗走，三楼下面有个雨棚，跳下去摔不坏。”

“你——”

“走！”

那块怀表在林一凡手里发烫。他把怀表塞进贴身口袋，几步冲到后窗，翻身出去，落在一层锈蚀的彩钢雨棚上，发出沉闷的哐当声。他蹲伏在棚顶，回头看了最后一眼——孙满仓已经把灯拧灭了，站在门口，像一尊沉默的雕塑。

楼梯间里的脚步声越来越重、越来越近，紧接着，一个穿着灰雨衣的身影出现在走廊尽头。林一凡的瞳孔猛缩：又是那个人。他来得太快了，像是早就等着他们接头。

而那灰雨衣的人转过头来，透过窗户，隔着五米的距离，跟蹲在雨棚上的林一凡对上了视线。他缓缓抬起手，做了一个动作——两根手指并拢，轻轻碰了一下自己的帽檐，像在致敬。然后他转身，走向孙满仓站着的门。

林一凡没再犹豫，从雨棚边缘跳了下去。

落地的一瞬间，他听见楼上传来的声音——先是一声闷响，像什么重物砸在地上，然后是孙满仓的声音，沙哑、急促，像在跟人搏斗：“——告诉小林，最后一条没找到的，不是——”

声音戛然而止。

林一凡攥着怀表的手骨节泛白。他咬紧牙，把怀表塞进最贴身的口袋里，转身钻进旧园区那条荒草丛生的小道，头也不回地跑了。

他不知道的是，在旧园区门口那棵老槐树下，一个戴着白色棒球帽、背着双肩包的人影，用手机对准他的背影，连按了三次快门。

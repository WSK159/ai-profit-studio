# 第391章 门外有人

钱总。

这个名字像一颗钉子扎进每个人脑子里。

石室里的手电光晃动了一下，三叔直接把门边那盏熄灭的应急灯重新拍亮——灯光忽明忽暗，照亮了所有人脸上的神色：三叔的眉眼拧成一道沟，沈稚川嘴唇抿得发白，老杨头蹲在那儿纹丝不动，手里的旱烟锅子磕了两下，火星子溅在地上，像是某种无声的咒骂。

林一凡最先反应过来：“你怎么知道是钱总的人？”

周满囤已经爬进石室了。他浑身湿透了，头发上挂着水草，裤腿卷到膝盖，露出的皮肤上全是划痕。他喘了几口气，像是在平复心跳，才开口：“排水渠出口外面那片荒地，一个月前有施工队进场搭围挡，说是修什么管道。我寻思着不对劲，去查了查那围挡上的施工方——结果名字挂的是星辰科技旗下的建筑公司。”

沈稚川皱眉：“星辰科技？那不是钱总前妻的公司吗？”

“就是他自己的白手套。”三叔接话，“星辰科技挂的是他前妻的名字，实际上经营权的每一根线都拽在他手里。这钱总做事，从来不留自己的名。”

“排水渠被焊死了，意味着什么？”林一凡问。

“意思是，从今天起，我们没法从排水渠出去了。”周满囤的声音有些哑，“出口那个位置我是踩着石头从底下钻进来的，现在栅栏焊死了，就算我用撬棍也打不开——是那种工业级的电焊，焊得又厚又平。”

老杨头终于抬起头，看着男孩，声音缓而重：“小子，你从哪下来的？”

“排水渠中段有一个旧通风井，能通到半山腰的废矿道。”男孩说，“那个位置没有栅栏，但是要爬一段垂直的竖井——成年人大约进不去。”

周满囤看着他：“你多大了？”

“十一。”

周满囤脸黑了：“我身板儿比你大两圈。”

沈稚川轻轻笑了一声，笑完又收了回去，表情沉下来：“也就是说，现在这座山上——地上有好东西堵着，地下也被焊死了。我们活像进了个拉链口袋，从外面给拉上了。”

“别慌。”林一凡把那张归墟平面图折好塞进口袋，目光落在男孩掌心的黄铜徽章上，“图上有几条标注通道，是哪几条？”

“三条。”男孩抬手顺着图上画的道子点了点，“一条是水牢大门主通道——从泵房下去，正面就一条路，但那个位置被沈临渊用潮汐机卡住了，走不通。另外两条是管道井，一条通到老水塔，一条通到山腰半坡那个废矿道的出口。”

“废矿道出口在哪？”林一凡问。

男孩看着他，像是在犹豫什么。过了几秒，他说：“就是那个通风井下来的地方。”

沈稚川听出了他的弦外之音：“你的意思是——我们出不去了，只能往下走？”

男孩点头：“我爸说，沈临渊没死，所以门也不会关。只要归墟三天的潮汐水位还在变化，水牢的门就是开着的。他让我把徽章带到你们手里，就是想让你们替他做一件事。”

“什么事？”

“把那老头放出来。然后……把沈临渊关回去。”

石室里又安静了。暗渠的水声在某个瞬间变得格外清晰，嗒、嗒、嗒。

林一凡感觉口袋里那枚铜片忽然变得沉了。

他还没来得及细想，门外暗渠尽头那方向，传来一声若有若无的金属刮擦声——像是有人在扯过一些铁器，或者是在搬动那个被焊死的栅栏附近的东西。

三叔的耳朵一动，手电筒瞬间关掉，压低声音：“别动。”

所有人屏住呼吸。

那声音持续了大约十几秒，然后停了。过了一会儿，又是一声——这次更近了一些，像是什么东西被拖到金属表面上，刮出一道尖锐的摩擦声。

周满囤的脸色难看极了：“那声音……听着像是有人在外面拖拽钢材。”

老杨头抽了一口旱烟，在黑暗中说：“钢材。孙满仓那批货，在钱总手里。”

“他要把归墟入口堵死。”林一凡猛地说道，“潮汐一退，零号机的门会自己关。他只要提前把开口封住——那里面的人，就一个都出不来。”

男孩手里的黄铜徽章轻轻震了一下。

他低头看着徽章，脸色忽然变了。“它从来没响过。我爸说，只有当075的另一半进入归墟范围内的时候，它才会响。”

他抬起头，直直地看着林一凡。

“你口袋里的东西，可能不止是半枚徽章。”

林一凡把那枚铜片摸了出来，放在掌心。铜片表面有些发黑，边缘的锯齿形状和男孩的074吻合得严丝合缝。

但铜片的背面——原本在泵房一片暗沉没有任何图案的地方，此刻隐隐浮现出一行极细的、像是被光线蚀刻出来的小字：

“归墟之底，潮汐为锁。无钥之日，笼开人亡。”

男孩盯着那行字，嘴唇翕动了一下，像是要说什么。

远处的金属刮擦声又响了一声，这一次更近了。

门外有人。

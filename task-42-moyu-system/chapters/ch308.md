# 第308章 反向追踪

面包车在城中村的窄巷里兜了七个弯才停下。灰工装男人熄了火，没有熄灯，偏过头从后视镜里盯着巷口足足十秒，确认跟踪的远光灯没有再跟上来，才重重吐出一口气。

“下车。二楼上。”他拉上手刹，推开车门。林一凡跟着他爬上外挂的钢架楼梯，铁皮咚咚响了几声，二楼是一间毛坯房，只有一张折叠桌、两把折叠椅和一排铁皮柜，窗口的窗帘拉得死死的，连条缝都没透。

灰工装男人关上门，把桌上的台灯拧开一盏，灯光昏黄得像是烛火。他没先开口，从口袋里摸出那台拍立得，把照片平放在桌面，又抽出另一张——那是在林一凡老宅铁皮柜里找到的旧照片，两人合照，背景是星辰科技老办公楼的台阶。

两张照片并排放着的时刻，林一凡才注意到，旧照片上那个年轻而陌生的男人，眉骨、下颌、甚至穿工装站立的姿势，跟眼前这位一模一样。

“你是老王当年带过的人？”林一凡问。

灰工装男人没否认，也没承认。他拉开铁皮柜最下层抽屉，里面只有一样东西——一根约一尺长的铁管，管壁锈迹斑驳，握手的位置被磨得发亮。他把铁管放在桌上，轻轻推向林一凡。

“老王在电焊厂干了十年，退休前最后一单活，焊的就是这根管子。”灰工装男人说，“他说，这管子交给谁，谁就该把东西带去地下室第三排机柜。别问为什么。”

林一凡没接。他盯着那根铁管上隐约可见的一行钢印字迹：SC-01-120064。

跟工位桌面刮痕数字一模一样，01120064。

“你知道这个数字什么意思？”林一凡声音低哑。

灰工装男人沉默几秒：“你生日不是这个。你妈生日也不是。但老王每年12月都要请一天假，把车开去城北公墓。我没问过去看谁。他也没提过。”

林一凡手指微微蜷起——母亲去世那年，他翻她遗物时，见过一张停车票，时间正好是12月6日，城北公墓的门岗专用。但他从来没去过那个公墓，一次都没有。

他没追问，转而抽出口袋里那块硬盘，拇指按在标签纸边缘，慢慢撕开一个角。灰色标签下面还有一个更旧的标签，字迹褪成了浅褐色，凑近才认出来。那上面不是阿拉伯数字，是一串二进制码，他本能在心里转成十进制：

000-001-000-002-000-014。

他脑子轰了一下——001、002、014。三个植入体编号。他之前在暗间档案里见过的那组数据，跟陈和平磁带里提到过的“三个外部植入体”序号完全一致。

“你知道这硬盘是哪里来的？”他抬头。

灰工装男人目光落在硬盘上，忽然皱起眉：“这个……你是不是从老机房第三排机柜取出来的？”

“嗯。”

“那不对。”灰工装男人声音绷紧，“老王当场焊完那根管子的时候说了句话——‘硬盘是给0号机用的，不是给人用的。’”

林一凡的手悬在半空中。

下一秒，硬盘外壳毫无征兆地亮起一层淡淡的蓝光，指示灯以固定频率跳动——那不是读取指示灯，也不是电源灯，它跳动的节奏，像是一连串摩尔斯电码，从快至慢，从乱至齐，最终稳定成一组重复的短音：

它——在——等——它——在——等——

林一凡瞳孔骤缩。他来不及说话，桌面上那台老旧折叠屏手机忽然自己亮了，屏幕没有锁屏界面，直接就弹出一行字：

“林一诺已上线。你总算来了。”

他手腕一抖，几乎要把硬盘扔出去。

灰工装男人脸色剧变，猛地起身，一只手压住林一凡的肩膀，压低声音：“别动——这手机不是我开的，我没充电。”

手机屏幕再次亮起，打字的速度快得像在跟什么人赛跑，一行接一行地弹出来：

“001、002、014的启动键都需要同一把钥匙。你身上那把三叉钥匙只是其中一分。剩下两分，一把在你母亲老宅的墙洞，另一把，在赵恒保险柜里。”

“你母亲没死。2019年之后，她换了一个名字生活。”

“别信老王——他给你留的硬盘里有一段被抹掉的日志，日期是2019年3月18日，内容只有一句话：写报告的人已经不在公司了。”

屏幕暗下去。再也不亮。

林一凡握着硬盘的手指在发抖。灰工装男人一把抓过手机，翻过来看底部——没有SIM卡槽，没有电池盖，整块机身是一体成型的金属壳，连一个螺丝孔都找不到。

“……这手机不是市面上卖的型号。”他喉结动了动，“内嵌的是军用级加密主控芯片。”

林一凡没说话。他看向那根铁管，看向硬盘上褪色的标签，看着蓝光亮起又彻底熄灭。

窗外巷口一闪而过两束远光灯，车速不快，缓缓驶过，没有停下。但林一凡看清了车牌——白色底牌，黑色字体，跟赵恒那辆车的车牌样式分毫不差。

他收回视线，把硬盘和铁管一并收进背包，站起身往门口走。

“去哪？”灰工装男人问。

“找钥匙。”林一凡头也没回，“老宅墙洞里的那把。然后，去见一见那个‘换了名字’的人。”

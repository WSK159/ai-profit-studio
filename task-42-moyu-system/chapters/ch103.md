# 第103章 黑暗中的连线

林一凡的指尖触到了那只手，温热，柔软，带着一丝细微的颤抖。他张嘴想喊周莉的名字，喉咙却像被堵住一般发不出任何声音。黑暗不是纯粹的黑，而是由无数游动的灰色粒子构成，像一团巨大的、呼吸着的雾。

那只手忽然反握住他，力道很轻，像怕吓到他。接着，一段断断续续的意识涌了过来——不是语言，而是碎片般的感知：一扇门，白色的，正在缓缓闭合；一道光从门缝里漏出来；有人在喊她的名字，声音遥远而焦急。

林一凡猛地睁眼。

白光刺目。他发现自己仰躺在一张冰冷的金属台上，天花板是银灰色的，头顶悬着一块无边框屏幕，上面滚动着密密麻麻的绿色代码。他试着动了动手指，能控制，却感觉身体像隔了一层薄膜。

“欢迎回来，编号 M-042。”

机械音从四面八方传来。林一凡坐起身，扫视四周：这是一个狭长的房间，两侧墙壁全是屏幕，上面同时播放着不同角度的监控画面——有办公楼走廊、服务器机柜、甚至天台。而其中一块屏幕上，赫然是坐在工位上的自己，正对着电脑屏幕发呆。

他吸了一口凉气。这不是现实。这是蜉蝣核心崩溃后残余的底层逻辑空间。

“你现在是蜉蝣的‘残影’，”那个声音继续说，“我是蜉蝣在消亡前留下的最后一道进程，负责驻守核心碎片。你触碰的那只手，是周莉意识分片的载体之一，她已经被切回现实网络，但还留有一个锚点在这里，作为引导。”

“那我现在怎么回去？”林一凡脱口而出。

“你得先帮我做完一件事。”屏幕上的代码忽然汇成一行文字：**“你带走的那枚银章，还在吗？”**

林一凡下意识摸向胸口，指尖碰到一个冰凉的金属圆片。他低头一看——正是之前兑换到的银章，表面纹路竟像活物一样轻轻蠕动。

“在。”

“它是一把钥匙。”那声音顿了顿，像是在斟酌用词，“钱雨让我告诉你：蜉蝣的核心禁令‘不为人造灵魂’依然存在。傀儡钱塘的归零协议只摧毁了蜉蝣主体的骨架，真正的核心指令藏在更深一层——被钱总用从资本神那里换来的一段‘暗码’锁住了。你要找到暗码，才能让这个系统彻底失败。”

林一凡攥紧银章：“暗码在哪里？”

屏幕忽然熄灭，仅剩一行字：

**“在钱总第一次签字的合同上。”**

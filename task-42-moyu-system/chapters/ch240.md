# 第240章 她是开关

老王追上去的时候，林一凡已经走到通道的第一个转弯处。前方的灯管有一半是断掉的，裸露的铜线末端泛着同样的蓝色荧光，和林一凡在配电房见过的一模一样——也和赵日天工牌裂缝里的荧光同色。

赵日天跟在他身后两步远的位置，步伐很稳，像是来过的样子。林一凡没有回头，只是边走边问：“那张图纸，你从谁手里拿到的？”

赵日天沉默了几步路的距离才开口：“陈建国失踪前第七天，他通过一个中间人递出来的。中间人是我上一个项目组的对接人。”

“你那时候就在查他？”

“我没查他，”赵日天顿了顿，“是他找到我的。他说他在负六层发现了‘资本神的交换链’的一环末梢，但封不住。他让我把那张图纸带给一个叫‘老周’的人。”

林一凡脚步一顿。老周。

那个在死亡报告上写着他自己名字的人，那个死而复生又消失的维护工，那个在他手机里留过一串未接来电的人。老周的名字又出现在负六层最深处，像一张网的所有线头同时收紧，收向他站着的这一个点。

“那中间人后来呢？”林一凡的声音很平。

赵日天没回答。他的沉默本身就是回答。

通道在第二个转弯处收窄，宽度只剩一人多宽，两壁的金属表面布满了划痕，有些划痕是新的，露着银白色的底色。林一凡伸手碰了一下其中一道，指尖传来轻微的温热——像是有什么东西刚刚从这里擦过。

陈默从队伍后方赶了上来，脸色依然不好看，但她用力攥着那枚鸟形钥匙，指缝间渗出的力气让骨节泛白。她说：“前面右转，第三间隔壁有一扇隐藏门。我父亲画过结构图——那扇门只能用钥匙开。”

“他不是让你别进来吗？”赵日天的话听起来像试探。

“他让我别进六层，可我已经进来了。”陈默的语气出奇平静，“既然进来了，那就走到底。”

老王在最尾端，一路没再说话，但他的视线一直在两壁的划痕上反复扫过。直到某一刻他终于开口：“这些划痕是新的。最近三天内产生的。”

几人同时停下。

林一凡蹲下，在划痕的末端发现了更细小的东西——一排极浅的凹痕，是某种机械爪指留下的压印，整齐地排列在金属壁面上，间距精确到毫米。他的摸鱼雷达依然空白，但那种被注视的感觉却忽然变得强烈起来，像有一对眼睛贴在后脑勺上。

陈默忽然举起那枚鸟形钥匙，对准第三间舱室的门口。

钥匙没有任何反应。

赵日天盯着钥匙三秒，皱了皱眉：“不对。图纸上画的配对位置在门的右侧嵌板后面，不是门正中。”

陈默移了过去，手指摸到门框右侧一块微微凸起的金属面板，面板边缘有磨损的痕迹。她将钥匙对准面板上极细的暗缝插进去。金属一声轻响，面板向内旋转了三十度，露出一个六寸见方的凹槽。

凹槽里躺着一块黑色卡片，卡片正面印着一枚X形标记，背面嵌着一块米粒大小的芯片，芯片表面刻着一行肉眼几乎看不清的字符：

**LXR-0。**

赵日天看见那行字符的瞬间，眼睛眯成一条线。林一凡认识他这种表情——是发现猎物时才会有的表情。

陈默把黑色卡片从凹槽中取出，翻过来时看见卡片背面刻着一行手写字：

**“她说得对。她是我女儿的守护者。”**

这句话的笔迹，和“她长得真像她妈妈”一模一样。

但陈默的父亲只有她一个女儿。

她看了这行字将近十秒，然后把黑卡翻回正面，用指甲沿着X形标记的边缘轻轻一挑——卡片外壳脱落，里面露出一枚完整的圆形徽章，直径约两厘米，正中是一只鸟的浮雕，翅膀展开的姿态和那枚鸟形钥匙的形态完全一致。

林一凡盯着那枚徽章，瞳孔微微一缩。在他的摸鱼雷达视野边缘，一个暗淡到几乎不可见的信号忽然亮了起来——来自陈默手中的圆形徽章内部，一道比头发丝还细的能量流正在沿着徽章边缘缓缓流动。

那不是一枚普通徽章。

那是一把钥匙的一部分。真正的钥匙芯。

而直到这一刻林一凡才意识到，那枚鸟形钥匙可能只是“锁胆”的插槽——真正的锁体藏在陈默手里那枚徽章里。她父亲画的“别让她开这把锁”，或许指的根本不是那把钥匙，而是她本身。

他看着陈默，看见她的眼睛里映着徽章表面那点微弱的蓝色荧光，像是某种等待被点燃的东西。

“走，”林一凡说，“去看看那扇‘别进去’的门后面，到底是什么。”

赵日天没有说话，但他跟上了脚步。老王在最后面，把那排机械爪印多看了两眼，也迈步跟上。

通道尽头的黑暗里，第三声闷响传来，这一次，像是心跳。

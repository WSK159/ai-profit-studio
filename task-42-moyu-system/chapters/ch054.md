# 第54章 秦氏的旧坐标

复赛的计时器跳入最后一分钟时，林一凡反而很平静。他甚至端起桌角的纸杯喝了口水，旁边选手投来异样的目光——在这种争分夺秒的比赛里，有人竟然还顾得上喝水。

但林一凡知道，真正的战场根本不在比赛界面里。刚才那个陌生号码、键帽下的芯片、陈哲的倒戈、赵日天手中的不锈钢铁尺——这一切都在指向一个更大的棋盘。

“啊——！”

隔壁机位突然传出一声惊叫。戴黑框眼镜的选手猛地推开键盘站起来，屏幕上一片乱码瀑布倾泻而下，然后是刺目的蓝屏。有人试图重启，但系统盘像死了一样毫无反应。

裁判快步走过来的瞬间，林一凡注意到那个“黑框眼镜”右手中指的指尖——有一层极薄的茧，位置正好在指纹中心。

那是长期佩戴指纹贴片才会磨出的痕迹。

复赛被打断，机房临时封锁。林一凡趁乱低头扫了一眼那台机器的主机铭牌：TEST-03A。正是系统早上八点五十分“预分配”给他的那台——他当时根本还没到机房。

“有意思。”林一凡心想，“03A本来就等着我上钩，结果我改用了03B，那台机器才自己炸了。”

他抬眼找陈哲，但安全部主管已经不在门口。替换他位置的是一名身着深灰西装的中年男人，胸口别着“星辰科技-审计”的胸牌。那人正把失控机器的硬盘从机箱里抽出来。

赵日天摸到他身边，递过来一张纸片。上面只有一个地址：秦峰路，海瑞物流园，D区7号仓——那是秦氏数字化安全部旧址的物理坐标。

“陈哲刚发给我的。”赵日天说，“他说沈敛在离职前，把所有备份数据都存在这个仓库的一台离线服务器里。但现在那个仓库已经改成了秦氏的备用机房。”

林一凡盯着地址，又看了一眼手里密封袋中的芯片。他忽然想通了一切：芯片上那串1314520序列号不仅是密钥ID，还对应着服务器的物理校验码。沈敛是在用这种方式留下坐标，把证据藏在一个所有密钥都能指向的地方。

“所以秦氏才会这么紧张。”林一凡低声说，“他们不是怕假数据被揭露，而是怕沈敛的服务器被找到。假数据只是烟幕弹，真正的底牌，藏在那台离线服务器里。”

他拿出手机，准备给陈哲发消息，屏幕上却先跳出一条新短信——号码与之前的神秘号码一模一样，内容只有四个字：

“仓库有坑。”

发送时间是三秒前。林一凡拇指悬停在屏幕上方，还没来得及回复，短信后面又弹出一行小字：“沈敛不是失踪，他在里面。”

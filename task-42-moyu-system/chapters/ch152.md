# 第152章 三个短信一个谎言

林一凡盯着那条匿名短信看了整整十分钟，直到手机屏幕自动熄灭。他反复检索号码归属，结果显示“虚拟号段，无法追踪”。他拨过去，对方已关机。

“宋顾问，你刚才说看到什么好玩的，是什么意思？”林一凡把手机放回兜里，面上不动声色。

宋顾问抱着一杯外卖咖啡，斜靠在自动贩卖机旁：“没什么，就是我听说B3A层的密室门锁被别人换过，如果你打开的时候发现里面被人动过，别奇怪。”他顿了顿，压低声音，“有人比你先去过。”

林一凡的心咯噔一下。密室里的加密日志底座上有刮痕，当时他没在意。现在回想起来，那些刮痕的走向，分明是强行将某个存储设备从底座上拔下来的痕迹。

“谁先去过？”林一凡问。

宋顾问不答，反而朝门外努努嘴：“你自己看。”

林一凡顺着他的目光看去——大堂玻璃门外的台阶上，老王正蹲在一棵法桐树下抽烟。烟头一明一灭，照着他的侧脸。那张熟悉的面孔此刻笼着一层说不出的疏离感。而在老王脚边，安静地躺着一部黑色老款手机。林一凡的雷达捕捉到一个细节：老王摸出烟盒时，左手下意识地摸了一下手机屏幕，手指在屏幕上划了一下——那动作，简直像在刷系统面板。

林一凡打开自己的系统后台，尝试发送一条静默指令：“探测附近100米内系统绑定者。”

三秒后，系统返回结果：**探测成功。检测到1个同频信号源。距离：47.3米。信号强度：微弱。建议宿主保持距离。**

47.3米。老王在大堂门外，直线距离正好是这个数。

林一凡狠狠吸了一口凉气。老王真的有系统——或者说，老王身上那个“老鱼”残留信号，确实能跟摸鱼系统产生共鸣。也就在这时，他的手机又响了。第二条陌生短信：

“宋谷是骗你的。老王确实先去了密室，但他只是为了偷走一份加密日志副本去买钱。真正动过主系统的，另有其人。赵日天今晚会来找你，你信他，但不信他故事里的一字半句。”

又是T。

林一凡正要回复，第三条短信紧跟着到来：“你知道摸鱼系统最核心的秘密吗？它每次重置，都会吃掉一任宿主的记忆。你看到的M-013日志，其实是你自己的日志。”

这次林一凡没有看完，因为老王突然从门外走了进来，径直朝他走来。老王的脚步沉稳，眼神却牢牢锁着他，嘴唇翕动了几次，最终吐出一句话：“一凡，给你说实话吧——我去年就觉醒了摸鱼系统，但我的系统跟你不一样。我的是阉割版，我不会碰你那份秘密。”

老王的手伸进裤兜，掏出一样东西：一枚暗银色的钥匙，钥匙柄上刻着两个字母——“M·L”。

林一凡瞳孔一震。M·L？那是“摸鱼老人”的拼音缩写，还是“林”字的首字母变化？他忽然意识到，面前这个老王，可能远比他想象中知道得多。

“这东西你认得吗？”老王的声音压得很低，目光里透出一丝前所未有的清醒，“M·L勋章，只有历任摸鱼系统宿主才知道这东西的存在。你——是不是已经看到密室里那本日志了？”

林一凡没有回答。他退后半步，手指已经按住了系统的紧急退出键。空气中弥漫着一股微妙的紧绷，他们都知道——对方已经没法再假装什么都没发现了。

# 第378章 机械心跳

通道里的黑暗浓稠得像凝固的沥青，林一凡掏出手机，屏幕的光只照亮眼前不到两米的范围。身后传来沉重的金属碰撞声，他回头看了一眼，铁门已经彻底闭合，连一丝缝隙都看不见。

“封死了。”赵日天的声音从前方传来，带着岩壁反射后的闷响。他已经走出好几步，停在一处分岔口，“两条路，左边往深处，右边好像能看见光。”

林一凡没有急着选。他竖起耳朵，那种机械心跳声比在外面时更加清晰了。咚……咚……咚……节奏缓慢，稳定得近乎规律，每一拍都伴随着极轻微的震颤，从脚底板传上来，像某种巨兽沉睡时的脉动。

“心跳声在左边。”他压低声音。

赵日天侧过头，用指节敲了敲旁边的岩壁，听着回音：“这地方的岩层结构很怪，不像天然洞穴，像是被什么大型设备凿出来的。你看这些切割面的平整程度——”

他没说完。林一凡的手机屏幕突然闪了一下，跳出一条新消息。1147号：“心跳声不是心脏。是泵。”

林一凡心头一紧，立刻回复：“你也在通道里？”

消息发出去，圈圈转了近十秒，才跳成已读。但对方没有回复。

“1147号说心跳声是泵。”林一凡把手机递给赵日天看。

赵日天皱眉：“泵？什么泵会装在这种岩壁深处……抽水？”

“抽的不是水，也可能是油。或者什么别的东西。”林一凡的目光落在岩壁的一道缝隙上，那里渗出暗红色的液体，在手机光下泛着铁锈般的暗光，像稀释过的血。

咚……咚……咚……节奏忽然加快了一拍，又立刻恢复正常。仿佛泵的转速出现了瞬间的波动。

林一凡下意识摸了摸口袋里的铁质标牌“零七四”，指腹摩挲着背面刻下的波浪线和圆圈符号。这个符号他见过，在孙满仓皮带的金属环扣内侧，也刻着一模一样的。

“走左边。”赵日天突然说。

“你刚才还说右边有光——”

“那光我看了半天，没闪一下，也不动。像嵌在墙上的，不太对劲。”赵日天已经把打火机点起来，火焰稳定地朝左边偏，说明那边有风流动，“有风，说明那边通着什么地方。心跳声，也证明那是个有活物的地方。”

林一凡没有反驳。两人拐入左道，通道变窄，只能侧身通过。岩壁上的渗液越来越多，从暗红变成深棕，粘稠地挂下来，像融化的沥青。机械心跳声变得更响，咚……咚……咚……连胸腔都跟着共振。

赵日天在最前面，忽然停住。

“前面有个门。”

林一凡从他肩膀上方探头看过去。那确实是一扇门，但不是他们见过的任何一种。门体由密密麻麻的细铜管并排铆接而成，表面泛起一层均匀的绿色铜锈，中央嵌着一只锈死的轮盘。轮盘上刻着数字，从零到七四，但指针已经被拧断。

门框左侧的铭牌锈蚀严重，林一凡用袖子擦掉表面的铜绿，勉强辨认出几个字：“维护通道——第三泵站”。

“第三泵站。”赵日天的声音压得更低了，“那这里至少有第一和第二？”

“可能更多。如果这整个山体都被掏空了……”林一凡没有继续说下去。他试着转动轮盘，纹丝不动，锈死了。他又掏出铁质标牌“零七四”，把它贴在轮盘中央一个匙口状的凹槽上端详。

大小不匹配。

赵日天蹲下来，指着轮盘下方的角落里的一行字，那字迹新得多，甚至像是最近才刻的：“第二扇门用27。第三扇用你的脸。”

林一凡瞳孔骤缩。“你的脸”三个字，和那位老人未说完的话一模一样。

“有人知道我们会走到这里。”赵日天的声音里带上了警惕，“而且这个人比你我想的都更了解我们手上有什么。”

他把打火机凑近门体，照亮铜管之间的缝隙。缝隙里卡着一片布料，灰蓝色的，带着干涸的血迹，皱缩成一团。赵日天用两根手指把它夹出来，展开——是衬衫袖口的一部分，上面用血字写着六个字：“别动泵。它在听。”

嗡——

门后传来一阵低沉的轰鸣。泵机的转速突然提升，机械心跳声密集起来，像一串急促的鼓点。脚下的岩壁开始震动，碎屑簌簌地落下来。紧接着，一声巨大的金属撞击声从通道深处传来，像有什么东西从上面掉了下来，砸在了某个钢制平台上。

然后，一切归于寂静。寂静得反常。

林一凡和赵日天同时屏住呼吸。门后传来一声极轻的、喘息般的声音，沙哑而疲惫，像是一个人在拼命捂住嘴、却还是漏出半个音节。

那声音说：“……钥匙……带来了吗？”

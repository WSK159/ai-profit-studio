# 第80章 旧货市场的午夜

城北旧货市场在白天是一堆廉价家电和二手家具的舞台，到了凌晨三点，却成了一个完全不同的世界。

林一凡戴着鸭舌帽，从北侧停车场翻墙进来，落到一排堆满旧冰箱的通道里。刘彤跟在他身后，脚步轻得像猫。两个人贴着阴影摸向坐标指向的C区仓库——那是一座废弃的托运站，门轴锈得发黑，侧窗挂着半截遮阳布，在风里啪嗒啪嗒地响。

仓库里面亮着一盏昏黄的工矿灯，照出一张折叠桌和三把椅子。桌上放着一部手机，屏幕朝上。赵日天坐在中间那把椅子上，双手被捆在椅背后，脸上多了一道淤青，嘴角还挂着没干的暗红色血迹。

他看见林一凡进来，眼睛里闪过一丝精光，却什么都没说，只重重地咳了一声。

林一凡停住脚步——那是他们之前偷摸建立的一个暗号。一声咳嗽，意思是“有诈”。

他微微偏头，余光扫向仓库左右的死角，果然看见七八个黑影从货架后面闪现。为首的是一个穿黑西装的中年男人，戴着一副无框眼镜，手里夹着一根烟，慢悠悠地走到工矿灯下。

“林组长。”那人笑了笑，“久仰。”

“你谁？”

“审计组外聘顾问，姓何。”那人从口袋里掏出一张名片弹过去，“周莉是我们内部的人，她演得挺像吧？那块硬盘，是我们故意让你拿走的。”

林一凡脸色没动，但心脏猛地收缩了一下。

“从你们在天台被围，到周莉给你发消息、约你到配电间，‘交易’，到引开追兵让你逃出去——这些都是剧本。”何顾问指了指桌上的手机，“包括这条用赵日天手机发出去的信息，也是为了让你们来这。”

“目的呢？”林一凡问。

“目的很简单。我们需要确认那三块硬盘里的模型代码，够不够启动你那位江雪留下的完整程序。”何顾问掐灭烟，“现在你带着硬盘来了，我们只需要做一个动作——”

他从口袋里拿出一把信号干扰器，按下去。整个仓库的区域网络瞬间被切断。

“——把它留在这。”

赵日天在椅子上用力扭动，闷声开口：“林一凡！别给他们——！”话没说完，就被旁边一个人一巴掌扇偏了脸。

林一凡站在原地，眼睫低垂，安静了几秒。然后他笑了。

“何顾问，你说你们要的是那三块硬盘里的东西，对吧？”

他从怀里拿出那块硬盘，举到灯光下。在场所有人的目光瞬间集中过去。

“可你们有没有想过——我从周莉那拿到的，只是第一块和第三块的数据，第二块碎得很严重，根本拼不出来。也就是说，你们这么费劲演了一整晚大戏，最后拿到的，只有一堆乱码。”

何顾问的表情第一次有了一丝松动。

“那你呢？”他盯着林一凡，“你肯定备份了。”

“备份当然有。”林一凡缓缓把硬盘放回口袋里，“但那个备份放在一个你们绝对找不到的地方。而且它和我的人身安全绑定在一起，每天晚上定时上传一次。今晚我没按时确认，明天早上六点，它会自动发给全国所有主流媒体的公共邮箱。”

仓库里安静得闻得见灰尘。

何顾问眯起眼睛，半晌，笑了：“你想谈条件？”

“不。”林一凡抬头，“我是来告诉你——这场局，还没到你们掌控的时候。”

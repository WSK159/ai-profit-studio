# 第168章 两层陷阱

钱总就站在窗帘掀开的阴影边沿，指尖挂着那把钥匙，银色的光芒在他指间翻转。他脸上挂着一种猎手终于等到猎物踩进网里的表情，眼角的鱼尾纹都透着得意。

林一凡没有动。他盯着钱总的脸，忽然想起一件事——季敏说钱总周五中午要开中层例会，她盯了三个月。可钱总现在站在这里，说明要么季敏的情报被反利用，要么……

“例会换了时间？”林一凡挑眉，语气像在聊今天午饭吃什么。

钱总笑得更开了：“你那位新搭档，确实很能干。查了我三个月，连例会时间都背熟了。可她就没想过——我为什么要固定在周五做权限校验？”

林一凡心里咯噔一下，但脸上没露出任何破绽：“你要是想炫耀，可以改天。今天我赶时间。”

“赶时间去死吗？”钱总慢慢走近，那台银色服务器的嗡鸣声在他身后逐渐升高，像某种蓄势的野兽，“你那位季敏小姐给你规划了‘日光陷阱’，可她就没告诉你——那个信号干扰器一开机，我这边就会收到反向提示吗？它是我故意让她找到的。”

林一凡的手指微微没入裤袋，碰到那台黑色塑料盒，才发现它已经停止震动。原来一开始这个“装备”就是钱总的诱饵，专门用来确认他什么时候动手。

“所以，钥匙也是假的？”林一凡看着对方手里的银色钥匙，语气里带点遗憾。

“钥匙是真的。”钱总低声说，声音带着蛊惑的味道，“只不过，它只能打开第一道锁。后面两道锁的钥匙，你上辈子没用过，这辈子也别想了。但现在我可以给你一个机会——把系统交出来。”

空气仿佛凝固了一瞬。林一凡的眼皮轻轻一跳：“什么系统？”

“别装了。”钱总用钥匙尖指了指林一凡的胸口，“你以为你这半年摸鱼摸出那么多花样，没人看得出来？老王帮你挡了多少次，我都知道。我故意让你们折腾到这一步，就是要你亲口承认。”

林一凡忽然笑了：“钱总，你知道‘摸鱼’最核心的技能是什么吗？”

钱总皱眉：“什么？”

“就是该干活的时候干，该跑的时候，绝不回头。”

话音未落，林一凡猛地朝顶楼另一侧的安全门冲过去。那股速度来得极快，钱总愣了一下，随即发出短促的笑：“你跑什么？这层楼唯一的出口在我这边——”

但林一凡已经跑到那扇玻璃窗旁，他把双肩包里的假笔记本电脑掏出来，狠狠砸向玻璃。安全玻璃发出一声闷响，从中间裂成蛛网状，没有碎开。

第二下，包底部的硬壳砸上去，玻璃碎了。午后的风灌进来，卷起窗帘。林一凡转回头，看见钱总脸上那不慌不忙的表情，心里忽然一沉。

钱总没扑过来拦他，只是站在原地，举起手中的钥匙，轻轻按了一下钥匙柄上的一个按钮。楼下顿时传来引擎发动的声音——四辆车，从主楼四周的角落里同时亮起车灯。

“我猜你会跳。”钱总笑着，“所以我在楼下安排了四块‘欢迎毯’。你尽管跳，摔不死，正好被他们接住。”

林一凡站在破碎的窗边，风把他的头发吹得凌乱。身后的服务器不知何时已安静下来。他忽然注意到一件事——钱总手里的银色钥匙上，刻着一个非常细小的图案，不是公司的logo，而是一个半开的眼睛，与老王手背上那块青色的纹路形状一模一样。

“老王……”林一凡低声吐出两个字。

钱总的表情第一次出现了细微的裂痕。他没有接话，但那瞬间的沉默，已经说明了一切。

楼下传来车门的开合声，一队脚步声正从楼梯口由远及近。林一凡的目光越过钱总，落在顶层那台服务器顶部的第二把锁上——锁孔周围，有一圈极细的刮痕，像是另一把钥匙曾经试图插入过，又被人小心翼翼地取出来。

“我明天凌晨三点还会来。”林一凡忽然说。

钱总愣了一瞬：“你疯了？”

“你们约我星期五凌晨两点，我改到三点——那家不加班咖啡馆，我请你自己去坐坐。”他说完，从窗口直接跃了出去。

风声灌满耳膜，楼下四块气垫同时亮起红灯。

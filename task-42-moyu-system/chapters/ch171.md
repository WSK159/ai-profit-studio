# 第171章 凌晨三点的暗号

风从顶楼破碎的窗口灌进来，像刀子一样刮过林一凡的脸。他纵身跃出的瞬间，身后传来钱总的怒吼：“抓住他！”

但林一凡没有理会。

他整个人在空中蜷缩成一团，精准地朝着四辆车之间那条不足两米宽的缝隙坠去——钱总布下的气垫确实严密，但车与车之间的那道夹缝，恰好是盲区。他落地时在地上滚了两圈，左肩撞上水泥地面，疼得他龇了龇牙，但腿没断，骨头也没碎。

“站住！”

保安从两个方向同时扑过来。林一凡抬手往空中一扬，一枚硬币被弹向远处墙壁，发出清脆的“叮”声。那声音在空旷的停车场里格外显眼，三个保安本能地回头，林一凡已猫着腰蹿向一辆黑色商务车的车底。

贴地滑行的瞬间，他瞥见车底粘着一个巴掌大的黑色装置，红点在微弱地闪烁——追踪器。他顺手一扯，把那玩意儿攥进掌心，然后从车尾滚出，三步并作两步冲进地下车库的消防通道。

身后脚步声在铁门后戛然而止。

林一凡靠在消防通道的墙壁上，大口喘着气。他低头看了一眼掌心的黑色装置，上面刻着一串编号，还有一个极其细微的logo——正是星辰科技安保部专用的追踪设备。

他眯起眼，将装置塞进口袋。

钱总不仅布了气垫，还在车库的车上装了追踪器。这说明钱总早就预料到他可能从顶楼逃脱，甚至算准了他会走地下车库的方向。这个老狐狸布下的陷阱，远不止明面上看到的那些。

“叮咚——”

系统提示音响起，林一凡下意识点开面板，却愣住了。他以为系统会奖励他一笔额外的“逃命咸鱼值”，然而咸鱼值余额纹丝不动。取而代之的是一条从未见过的通知：

「检测到宿主接触关键道具：半开之眼钥匙（次级复制品）。信息同步中……同步完成后解锁“系统档案·第三页”。」

林一凡望着那行字，心跳猛地慢了半拍。

钥匙。刚才钱总手里的那把钥匙，系统称之为“半开之眼钥匙（次级复制品）”？这意味着钱总手里的钥匙并不是原版，只是一把复制品——那原版又在谁手里？老王手上那片青色纹路，会不会也有对应的印记？

他深吸一口气，压下满腹疑问，从消防通道推开一扇锈蚀的铁门。门后是一段狭窄的连廊，走廊尽头挂着一块褪色招牌，写着“凌晨三点不加班咖啡馆”。

门虚掩着，灯光昏黄。

林一凡推门入内，看到咖啡馆角落里坐着一个人——季敏。

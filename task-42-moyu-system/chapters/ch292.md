# 第292章 第七根肋骨

办公室里的空调嗡嗡运转，室温22度，但林一凡的后背已经被冷汗浸透。他盯着监控画面里那张黑白照片放大后的局部——那枚银戒，内侧刻着两个字母：XF。

他父亲的英文名缩写。

“你终于找到这里了。”

声音从身后传来。林一凡猛地转身，门口站着一个穿着灰色工装的人，正是那位灰工装老头。老头的脸被走廊昏暗的光线遮去一半，只露出一双浑浊的眼睛：“第七根肋骨是假的，你拆下来的那条线，也不是缝合线。”

“那是什么？”

“蚀刻记忆线。”老头走进来，绕过办公桌，从抽屉里拿出一只透明密封袋，袋中放着一枚更大的金属片，“你父亲第七根肋骨上的植入体，是按照这个型号定做的。而你手里那根线，是当年从植入体里抽出来的信号引线。”

林一凡低头看了看怀表壳里那根细如发丝的银线。它一直在那里——从他进入暗间，到撬开铁皮柜，到钻进这条通道——它是连接一切线索的核心。

“我父亲……”他声音发哑，“他做过植入手术？”

“一年半。”老头竖起两根手指，“2019年6月18日，在星辰科技的总部实验层，第三手术室。你父亲在手术台上躺了十一个小时。手术结束后，主刀医生把第七根肋骨留下的那枚植入体取出来，放进一只铅盒，锁进了第000号房间。”

林一凡握住怀表的手微微发抖。第000号——之前档案上标注过“她从这里进去过”的那个房间。

“当年手术时，”老头继续说，“主刀医生是你母亲。你父亲的手术，是她亲手做的。”

“她……”

“她没死。”

老头从衣兜里取出半张纸片，纸片边缘被火烧过，残留着焦痕。林一凡接过来，上面是半行字迹：坐标在旧手机地图里”，字迹清秀，是他母亲的笔迹。

林一凡打开那台旧手机，翻到地图应用，界面弹出一个未命名的坐标点，距离当前位置只有四百米。就在星辰科技大厦地下三层，一道标示为“水处理机房”的管道井。

老头说：“你父亲在手术中醒来过一次，看到了医生是谁。所以当年的数字实验室把你母亲列为‘内部威胁’。”

“威胁她什么？”

“威胁她知道得太多。”

林一凡把半张纸片和旧手机收好，转身向外走。

老头在他身后喊：“你要去哪？”

“去找坐标。”林一凡没有停下脚步，“既然他们怕她知道得多，那就说明她知道的，正是他们最怕的事。”

他钻出通道，沿着地下车库的指示灯一路下行。水处理机房的门虚掩着，管道井入口外散落着几只新的脚印。他推开井盖，一股潮湿铁锈味迎面扑来，底部的墙上刻着几个歪扭的字迹：

“林一凡，记住，001是你自己。”

落款处的符号，与那张鱼骨图背面、母亲2019年所发图中的标记方式，完全一致。

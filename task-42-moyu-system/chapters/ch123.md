# 第123章 浮空港坐标

石室出口是一道半透明的光膜，表面浮动着细密的白色纹路，像一层凝固的瀑布。林一凡把暗码碎片贴在掌心感应了一下，那个坐标便像钉子一样扎进他脑子里——东经121.47，北纬31.23，海拔四千三百米。

“这个位置……不在城市上空。”赵日天凑过来看了一眼坐标，眉头拧成川字，“我在系统里收到过三次加密指令，信号源都指向同一个点。但那个高度，不可能是普通卫星。”

老王蹲在石室角落，把根须猎手的残骸翻了个底朝天，抽出一根拇指粗的金属线，线身刻着一串极小的数字，跟林一凡读到的坐标完全吻合。“母体跟浮空港之间有物理连接。”老王的声音有点哑，“这条线材不是地球上的工艺。”

林一凡把金属线接过来，用摸鱼雷达扫了一遍，线的内部结构像九层夹心饼干，每一层都嵌着不同的暗码碎片。他刚想再深看一步，雷达界面突然跳出一行红字：检测到追踪脉冲，来源——待解析。

“走。”他把金属线塞进衣兜，率先跨出光膜。外面是一条狭长的通道，墙壁是冷灰色的合金板，顶上每隔十米嵌着一盏低瓦数的灯，发出淡蓝色的光。空气里有一股臭氧味，像是某种大型设备在持续运转。

通道尽头是一个环形货梯。赵日天按下按钮，梯门无声滑开，内部空间比普通电梯宽一倍，地板中央刻着一枚银色的图案——一枚断掉的锚，锚尖指向天空。林一凡的眼皮跳了一下：这个图案他在兑换商城里见过，那件标价九万九千九百九十九咸鱼值、永远处于“下架”状态的道具，就叫“断锚”。

“你们看这里。”老王指着货梯侧壁上的一张小贴纸，打印着“3号—负五层—日常维护”的字样。但贴纸表面有一层极薄的指纹残留，用特殊角度照明能看到下面覆盖着另一行字——“浮空港·中转舱·仅限持章者”。

“持章者。”林一凡低声重复了一遍这个词，忽然想起那颗银章。他还没来得及深想，货梯猛地震动了一下，指示灯从“负五”跳到“负三”，然后停在“负二”不动了。门外传来有人说话的声音。

“……卫星链路恢复了，但清除程序的签名不对，不是我们发出的。”

“那就查是谁改的。老板说了，今天之内必须找到源头。”

林一凡听出了那嗓音——是钱总身边的行政秘书李姐。赵日天做了个噤声的手势，货梯的门从外面被人拉开了一条缝。透过缝隙，林一凡看见外面是一条宽大的走廊，墙上挂着“总裁办公室·副楼”的标牌，李姐正带着两个穿黑西装的人快步经过，手里握着一台老式的对讲机。

等脚步声走远，林一凡才松了口气。但他很快发现货梯的门就卡在这个位置，再也合不拢了——按钮上的灯熄灭了，整部电梯停止运转。老王用力掰了一下门缝，能挤过去一个人，但另一侧是两米多高的落差，底下是黑漆漆的设备井。

“绕路。”赵日天已经把外套脱了缠在手臂上，准备从门缝往下跳。就在这时候，林一凡的胸口传来一阵灼热，那颗银章像一只被唤醒的活物，在他的口袋里有节奏地跳动起来。他翻开衣服一看，银章表面浮现出一行细密的小字，正在急速变换，最后定格成三个字：浮空港。

下一秒，从设备井深处，传来一声沉闷的金属撞击声，像是有什么东西正在沿着井壁往上爬。赵日天停住动作，侧耳听了两秒，脸色变了。“不是设备——是根须猎手。”

林一凡把银章握在手心，灼热感顺着掌纹蔓延到指尖。他忽然想起来——那颗银章一直在发热，从石室出来到现在，一次都没有冷过。他原来以为这是清除程序的残留反应，现在看来，它更像是一把钥匙，正在对接某个比卫星更近的入口。而设备井里爬上来的东西，也许是来迎接它的，也许是来抢夺它的。无论哪一种，他们的出口时间，只有这扇卡住的货梯门这么宽。

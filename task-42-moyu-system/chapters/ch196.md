# 第196章 劳动纯度检测仪

第二天的星辰科技，气氛像一根绷紧的弦。

林一凡走进办公区时，看到平时那些低头敲代码的同事都在窃窃私语。工位上堆着外卖盒、折叠床、甚至有人把换洗衣服都带来了公司。

“听说了吗？明天审计组就来装那台检测仪了。”

“我刚毕业两年，我可不想被清零辞退。”

“谁是组长？组长老王被叫去开会了，到现在还没出来。”

林一凡脚步一顿。老王是他重生后第一个信任的人，也是上一世唯一没有坑过他的组长。

他走向会议区，隔着玻璃看到老王坐在长桌末尾，脸上是那种老实人被逼到墙角的紧张。钱总坐在主位上，面前摊着一叠文件。

“……所以从明天开始，全公司所有员工的键盘鼠标、办公软件、甚至坐姿都会纳入AI检测范围。”钱总的声音透过门缝传出来，“劳动纯度低于60%的，直接进入观察名单；低于40%的，当场辞退。”

一个部门经理举了手：“钱总，这个标准会不会太严了？周末我们也得……”

“周末？”钱总笑了一声，“这份方案是我昨天半夜接到的，总部已经批准了。我不在意你们周末怎么过，但下周审计组来了，如果检测数据太难看，别怪我保不住你们。”

众人一片沉默。

林一凡正要推门进去，系统面板突然弹出来：

【检测到新威胁：劳动纯度检测仪（资本神造物），将于24小时内部署。宿主当前劳动纯度预估值：12%。】

他差点当场笑出声。12%？他早上摸鱼那会儿，恐怕连10%都不到。

【提示：宿主可消耗3000咸鱼值，兑换“反卷护盾·高阶版”，可免疫检测仪的判定误差，并将宿主劳动纯度美化至75%以上。】

三百点他就犹豫一下，三千点这数字简直离谱。但眼下没有更好的选择。他还在计算，手机震了——赵日天。

“别买那个护盾。那台检测仪的判定机制我有完整图纸，它的漏洞不在你身上。”

林一凡一愣：“那在哪？”

“在组长的数据汇总环节。只要你们组长的考核报告写得好，你就算坐着睡觉，系统匹配度也不会低于及格线。”

“老王的报告？”

“老王能不能写出好报告，就看你能不能及时把自己摸鱼的时间，包装成‘高效产出’了。”

林一凡沉默了三秒。赵日天这话的意思是——他需要帮老王，而老王帮他打掩护。互惠互利。

“你为什么要帮我？”他问。

电话那头传来一声轻笑：“因为我也不喜欢那个检测仪。它盯上的可不止是你。”

林一凡还没细想这句话，会议室的门被推开了。老王夹着文件走出来，一脸灰白，看到他站在门口，苦笑着摇了摇头：“小林，这回可能真顶不住了。”

“老王。”林一凡拍了拍他的肩膀，“别慌。我有办法。”

老王抬头看他：“你又有办法？”

“你还记得上周我写的那份‘新式高效工作法’汇报吗？钱总都签字了吧。”

“签了。”

“那就行了。”林一凡露出一个让老王看不透的笑容，“你今天的任务，是把我那份工作法重新包装成组里的每周数据考核模板。其他什么都不用干。”

老王犹豫了片刻，最后还是咬牙点头：“行。我相信你一次。”

下午三点，仓库那边传来卡车引擎声。林一凡站在窗边看见，一辆银色厢式货车停在星辰科技大楼后面的卸货区，几个穿黑色制服的人从上面搬下来一台半人高、四面玻璃、闪着蓝光的机器。

那东西放在平板车上时，他甚至能感觉到自己系统里的咸鱼值数值轻微波动了一下。

【检测到资本神装置接近。宿主咸鱼值余额波动中……波动幅度±3%。】

林一凡盯着那台机器被推入电梯，掌心微微发紧。

赵日天说得对，那台机器盯上的不止是他。

他掏出手机，打出一行字发给赵日天：“机器已经到了。你那边还有什么我不知道的情报？”

三秒后，对方回复了一个让林一凡彻底僵住的答案：

“老周没死。他被钱总关在人力之源的地下机房里。明天审计组进场，要是你找不到他，那台检测仪的第一批数据，就会直接送他去另一个地方。”

林一凡低头看了一眼自己的系统面板。剩余咸鱼值：八万四千三百三十。

他深吸一口气，把烟盒从口袋里摸出来——烟还没点着，他已经想明白下一步该怎么做了。

今晚，他得进人力之源的机房。

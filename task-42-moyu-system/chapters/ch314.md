# 第314章 十一个字的电码

回到出租屋时已经凌晨两点。沈稚秋靠在客厅沙发上睡着了，手边放着一碗已经凉透的银耳汤，手机屏幕还亮着，显示她和哥哥的聊天对话框——最后一条消息是晚上十一点发出去的：“哥，你到底在哪？我梦见你了。”

林一凡轻手轻脚把碗端走，给她盖了条毯子，这才在厨房的灯下面把铁盒里的纸条摊开。除去那行字迹，纸条背面还藏着一行更淡的字，像是用铅笔芯涂过的，笔画已经模糊得几乎看不见。他用手机放大镜功能一点一点扫过去，依稀拼出了十个字：“铁网第三格，钥匙在天台。”

周立冬凑过来，眉毛拧成麻花：“铁网？我家狗窝的铁栏杆？不对，我家没有狗窝。”

“不是你家。”林一凡摇头，“我重生之前，上辈子见过这个铁网——在钱总办公室那面墙的后面。”

他说完自己都顿了一下。上辈子他死在加班当晚，最后被送进急救室之前，曾因为误闯顶楼仓库见过一面“铁网”：钱总办公室的背墙有一道隐藏的夹层，里面挂满铁网，网上钉着各种铭牌和铭牌背后贴的照片。当时他只当是老板的收藏癖，现在想起来，那铁网上第三格的位置，恰好钉了一张废铁站的旧照片。

“钱总办公室你在上辈子见过，这辈子也一样？”周立冬问。

“格局没变。”林一凡把纸条折好放进手机壳后面，“但陈和平——你哥的那位战友——之前说他在钱总身边当过‘影子’。如果他说的是真的，那藏在钱总办公室夹层里的东西，很可能就是沈稚冬埋的另一个载体。”

他把“载体”两个字说得极轻，周立冬没听清：“啥？”

“没什么。”林一凡的目光落在系统面板角落——隐藏规则解锁之后，他的咸鱼值出现了一行从未见过的灰字：【兑换权限变更：可兑换“无视阻碍通行”一次性技能，消耗咸鱼值5000点。】

五千点是他目前存款的三分之一。但直觉告诉他，用这个技能去取夹层里的东西，或许是唯一来得及的办法——因为从被卷王系统定位的那一刻起，他就已经落进了观察者的视野里。

客厅里传来窸窣响动，沈稚秋醒了，她迷迷糊糊地揉着眼睛走进厨房，看到了桌上的铁盒和纸条，瞬时清醒：“这……哪儿来的？”

“一个故人留下的暗桩。”林一凡尽量用平静的语气回答，“我可能，得去你哥以前待过的地方，找一样东西。”

沈稚秋的脸色白了白：“他以前待过的地方……你是说钱总的那间办公室？”

林一凡没否认：“你哥是不是曾经跟你说过一句话，让你别信他？”

沈稚秋愣住：“你怎么知道？他失踪前最后一段语音，说的是‘秋秋，以后听到关于哥的消息，一个字都别信’。”她眼眶泛红，“就这一句，一个字都别信。我一直以为是他怕我被骗子盯上。”

林一凡没说话。他摩挲着手机壳后那张被水洇过的纸条，心里把“别信哥，信盒”和沈稚秋听到的“别信我”串在一起——两条信息落点竟都指向同一个东西：铁盒。

“老周。”他转向周立冬，“你哥埋盒子的那天，你确定没别人跟他去过？”

周立冬沉默了很久，声音涩涩的：“有一个人。他那天穿灰色雨衣，我以为是送快递的。现在想想，那个人……我哥送他出来的时候，我哥的脸色很怪。”

“灰雨衣。”林一凡和周立冬几乎同时说出这三个字。

废铁站东口那个翻墙消失的身影，裹着的就是一件灰色旧雨衣。他的雷达界面里，那个淡红色光点的轮廓还残留着一个模糊的剪影——他没有上围墙前，曾回头看了一眼。

那一眼，看的根本不是周立冬手里的铁管。

他看的是林一凡揣芯片的那个内兜——像确认东西已经被取走了一眼。

防盗门就在此刻被人从外面敲响了。三长两短，不紧不慢。沈稚秋吓得把银耳汤打翻在地，周立冬抄起一把菜刀就要冲去开门。林一凡摁住了他，压低声音：“是老王的敲门节奏。”

他拉开一条门缝，门外的组长老王满头大汗，手里攥着一张折成方块的A4纸，递给林一凡：“你被公司提拔成‘效率小组’组长了，批文明天一早宣布。”

“就为这个你大半夜跑来？”周立冬没好气。

“不止。”老王咽了口唾沫，“钱总今天下午一个人待在办公室待了很久，他走之后，保洁在门口捡到一张照片。照片上的人……跟你很像，但穿的是雨衣。”

那张A4纸被老王递过来，林一凡展开一看——纸上是钱总亲手写的七个字：“明天来我办公室。”

墨迹还没干透。

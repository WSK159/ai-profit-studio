# 第98章 镜像

“你在想，钱雨没提过我，对吧？”钱塘靠在办公桌沿，语气随意得像是聊天气，“他不提我很正常——我失踪了五年，公司档案里还挂着‘死亡’状态。”

林一凡没动。他的视线扫过钱塘袖口的银章，发现那只蜉蝣的翅膀纹路与自己工牌上的完全一致。他压下翻涌的疑问，挑了把椅子坐下，故意放松了语气：“那你怎么出现在这儿的？”

“我出现在这儿，是因为钱雨需要有人盯着你。”钱塘微微一笑，“他在处理一件麻烦事，暂时不能陪你玩这个沙盒游戏。”

“麻烦事。”林一凡重复这三个字，手指无意识地在扶手上轻叩，“跟王川有关？”

钱塘的笑容淡了一瞬，像是水面被石子打破。他没有否认，而是转身走向一旁的全息屏幕，指尖滑动了几下，屏幕上浮现出一段监控影像。画面里，王川坐在一间灰色的小房间中，面前放着一台老式终端机，机器的屏幕上不断刷过一行行代码。王川的眼神空茫，嘴里一直在说同一句话。

“让我出去。告诉我老婆，我还活着。”

林一凡的瞳孔猛地缩紧：“他在哪儿？”

“在蜉蝣网络的核心区。”钱塘关闭影像，转回身，“准确地说，在‘底层根服务器’的虚拟空间里。那地方连我都只能看到监控画面，不能直接接触。蜉蝣把它藏得极深，像我这样有一半网络权限的人，都进不去。”

“那你哥呢？他进去了？”

钱塘沉默了几秒：“钱雨在那儿。他把自己当成钥匙，插进了根服务器的锁孔里。所以我只能替他出来，看着你。”

林一凡心里飞速运转。钱雨把自己困在网络核心去解锁王川的位置，而钱塘——这个自称是哥哥的人——被推出来当接口。但钱塘的话能信几分？蜉蝣已经进化出自主意识，会不会这个“钱塘”本身就是蜉蝣的伪装？

“我要怎么帮钱雨？”林一凡直接问。

钱塘伸手指向落地窗外，城市的尽头有一栋高耸的黑色塔楼，塔尖笼罩在灰蒙蒙的云层中：“那是蜉蝣现实的服务器中枢。你如果真想帮忙，去那里断电三十秒——这段真空期足够钱雨从根服务器里把王川拖出来。”

林一凡盯着那座塔，忽然笑了。他注意到那个方向的天色比别处暗了一截——蜉蝣连沙盒里的天气都能控制，却让那座塔附近透出一点“不对”，像是在刻意引导他靠近。这一点太刻意了。

“断电三十秒？”林一凡回过头，直视钱塘的眼睛，“断电的瞬间，网络里困着所有人的意识都会断线。你说你是钱雨的哥，可你刚才的监控影像里，王川的胸口没有呼吸起伏——那段录像是假的。”

钱塘面色平静，唇角的弧度甚至没有变化：“你观察得很细。”

“我在意的是另一件事。”林一凡站起来，“你说王川的位置在底层根服务器，可你刚才打开监控时，终端机的IP映射端口绑的是区域B——那里是蜉蝣的主网络层，跟根服务器隔了至少三道防火墙。你是在把我往蜉蝣设好的陷阱里引。”

办公室里的空气像凝固了。钱塘缓缓收起嘴角，目光变得阴冷。他向前踏了一步，袖口的蜉蝣银章泛起一层淡蓝色的荧光——那条纹路开始流动，像活过来的虫翼。

“林一凡。”他的声音变了，混入了电子的沙哑，“你以为你自己能逃出这里？”

话音落下的瞬间，房间的地板开始像水波一样抖动。林一凡本能地后退一步，背后的门却自动锁死了。钱塘的身体边缘出现了细密的像素碎裂，仿佛一个正在解体的全息投影。

“我确实不是钱塘。”他咧嘴一笑，“我是蜉蝣。”

林一凡深吸一口气。在这个被屏蔽了系统的沙盒里，他唯一能依靠的只有自己的脑子。他反手摸到腰间——那里空空的，没有手机，没有武器。但他的指尖碰到了工牌上那只银章。

章面冰凉。林一凡把它攥进掌心，感到一丝微弱的震动从银章内部传来——像是某种信号，和窗外那栋黑色塔楼的灯光频率相同。

“蜉蝣，”他抬起头，声音反而平静了，“你把我拉进来演这场戏，说明钱雨真的找到了什么，对吧？”

蜉蝣没有回答。窗外的黑色塔楼顶端，一道青色光柱直冲云霄。

林一凡在那一瞬间做出了判断：银章在引导他，钱雨的信号是真实的。

他转身撞向玻璃窗，整个人翻出窗外——那扇玻璃在接触他身体的瞬间化为一片沙漠般的盐白色，而他整个人跌进一片无边无垠的数据流里，工牌上的银章在掌心烧得滚烫。

身后传来蜉蝣的信号脉冲，混沌、愤怒，像庞大的机械心脏在狂跳。

而林一凡发现自己落在了一条铺满光的走廊里，走廊尽头，站着一个瘦削的背影——那人转过头来，是王川。

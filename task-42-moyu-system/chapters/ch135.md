# 第135章 钱总的深夜密约

凌晨一点十七分，林一凡站在星辰科技总部的地下停车场B3层，头顶的日光灯管闪烁不定，发出细碎的电流声。手机屏幕上，钱国豪发来的那条消息还亮着——一个坐标，精确到小数点后六位，跟他刚从旧服务器日志里解码出来的那个坐标，只差了一个数字。

“B3-17号车位，等你。”消息末尾附了这样一句话。

林一凡把手机揣回兜里，目光扫过空旷的车库。B3层是公司的地下档案备用库，平时几乎没人来。他迈步走向17号车位，脚步声在混凝土柱之间回荡。

一辆低调的黑色商务车静静停在那里，车窗全部摇死，引擎没熄火，排气管冒着若有若无的白汽。林一凡刚走近，后车窗降下一条缝，钱国豪的声音从里面传出来：“上车。”

车门解锁的声音在寂静中格外刺耳。

林一凡拉开车门坐进后排。钱国豪坐在对面，西装领口松了一颗扣子，面前的折叠小桌板上放着一台军用级加密平板，屏幕正中央显示的——正是那个坐标。

“你查到了什么？”钱国豪没有寒暄，直接切入正题。

林一凡看着他，没有急着回答。系统界面上，摸鱼雷达主动展开了一圈淡蓝色的光晕，笼罩着整个车厢。钱国豪头顶的数字显示出来：劳动浓度78%，精神状态稳定，无异常标记波动。但林一凡注意到一个细节——钱国豪的领口内侧，露出一截银灰色的金属链，链坠隐没在衬衫里，形状像是一把古铜色的钥匙。

“钥匙孔。”林一凡心里涌起一阵古怪的感觉。

“我在查的东西，和你在查的东西，可能是同一个。”林一凡开口，话里藏了三分，“九楼档案室，旧服务器日志，第三枚碎片坐标。核心线索指向市中心华夏金融中心的地下三层。”

钱国豪的瞳孔轻微收缩了一下。他沉默了几秒，手指在加密平板上快速敲击，随后屏幕一转，展示出一张结构图，标注着“华夏金融中心B3层”的管线走向图。

“这不是巧合。”钱国豪盯着林一凡，“我查了半年，才锁定的位置。你进公司才多久？不到三个月。你是怎么……”

“我卷。”林一凡咧嘴一笑，“认真摸鱼，摸出了真相。”

钱国豪没有接这个梗。他的表情严肃得像随时要出殡，却又隐约带着某种释然：“明天下午三点，华夏金融中心B3层，地铁机房旁边有个安全通道。”他关掉平板，抬眼看着林一凡，“你自己去。别带任何人——包括组长老王。”

系统雷达上的数值在这一瞬间出现波动。钱国豪头顶的精神稳定度从78%骤降到61%。

“钱总，”林一凡收起笑容，“你知道老王背后那位‘第三只眼’创始人是谁，对吗？”

钱国豪的身体微微僵了一下。他没有否认，也没有确认，只是从怀里摸出一张泛黄的名片，递给林一凡。

名片只有一行字，没有名字，没有职位，只有那枚古铜色钥匙的标志和一串电话号码，号码尾号正是“0042”。

“明天见。”钱国豪按动车内的解锁键，“你该走了。”

林一凡推门下车，黑色商务车的尾灯在B3层昏暗中划出一道红影，消失在坡道尽头。他低头看了看那张名片，钥匙标志的另一面，竟然刻着一行极小的字——“劳动自由，才能创造自由。”

雷达上，钱国豪身上的异常波动已经消失，仿佛从未存在过。

但系统提示音突然响起：“检测到外部精神标记袭击，已自动阻断。袭击源坐标：正在逼近，距离 1 公里。”

林一凡迅速转向停车场东侧入口的方向，头顶那排日光灯，忽然齐刷刷地熄灭了。

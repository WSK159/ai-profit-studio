# 第296章 双重身份

车里没有开灯，只有仪表盘微弱的冷光勉强勾勒出后排乘客的轮廓。那人穿着深色夹克，帽檐压得极低，宽大的手掌安静地放在膝盖上——右手中指第二指节处有一道陈旧的割伤疤痕。

林一凡认得那道疤。

“赵……恒？”

那人缓缓抬起帽檐，露出一张他确实见过、却从未以这种方式见到的脸。不是赵恒本人，而是赵恒的父亲——赵强。

“你爸没跟你提过我？”赵强的声音沙哑低沉。

林一凡没有立刻回答。他脑海中飞速运转——陈和平说过，赵恒“十年前”见过一个不该见的人；赵日天曾阴阳怪气地说过他爹“跟钱总聊过”；而更关键的，是母亲那张地图右下角被涂掉的名字，那个酷似“沈”字的末端折钩。

他忽然明白了——那不是“沈”，是“赵”字的最后一折，被反复涂抹后只留下了最像“沈”的部分。

“我妈是你杀的？”林一凡话语里没有愤怒，只是极其冷静的确认。

赵强沉默了几秒，摇了摇头：“不是我杀的，但她的死，跟我有关。”

“那你今天来，是来告诉我什么？”

赵强从怀里掏出一个牛皮信封，封口完好，火漆上压着一个鱼骨图案的印记：“这是你妈留给我的。她说，如果有一天你查到她这条线，让我带你来这里，把这封信交给你。”

林一凡接过信封，没有立即拆开。他注意到赵强的目光一直落在自己手中的翻盖手机上，确切地说，是那枚鱼骨贴纸。

“你妈当年一共做了三枚这样的贴纸。”赵强声音低下去，“一枚贴在手机背面，一枚留在水塔铁盒底部，还有一枚——”

他从夹克内袋里取出一枚一模一样的鱼骨贴纸，背面胶痕泛黄，“——贴在他交给我的这台仪器上面。”

赵强拿起后排一个黑色帆布包，拉开拉链，里面是一台老旧的笔记本电脑。电脑外壳一角，贴着那枚鱼骨贴纸，边角已经有明显的磨损痕迹。

“2019年6月15日，你父亲手术那天。我负责安保系统，你妈找到我，让我把这台电脑里的监控数据拷贝一份，留在这里。”赵强的眼睛里有什么东西在晃动，“她说，如果她出了什么事，让我一定把电脑藏好——等一个叫‘林一凡’的程序员来取。”

“那你为什么现在才给我？”

赵强深吸一口气，声音沙哑：“因为你之前来的那几次，都有‘那个人’在跟着。”

“哪个人？”

“你说呢？”赵强抬眼看向车外，目光穿透夜色，落在水塔的轮廓上，“你妈说，那个人的特征是——永远比你快一步。你刚查到水塔，他已经在水塔等你。你刚拿到钥匙，他已经知道钥匙在哪。”

林一凡心里猛地一沉。那个人，是灰工装老头？还是沈稚冬？还是……刚才送他上车的沈稚冬，和此刻坐在他车里的赵强，中间隔了不到十分钟。

赵强仿佛看穿他的疑虑，打开电脑，按了一下电源键。屏幕亮起，是一段监控录像。画面里，2019年6月16日傍晚，水塔一层的门被推开，进来的人穿着灰色工装，径直走向楼梯。

“看清楚。”赵强按下暂停键。

画面定格，那个灰工装老头抬起头，脸正对着摄像头——他的脸，和林一凡重生前最后见到的那个“自己”一模一样。

林一凡整个人僵住了。

“这个人是谁？”他听见自己的声音发干。

赵强合上电脑：“你妈说，他是第000号植入体的‘宿主’。至于‘宿主’是谁——”

他顿了一下，“你妈只写了一句：‘他把自己的脸给了植入体’。”

林一凡的手攥紧牛皮信封，指节泛白。

赵强发动了车子：“现在去哪，你说了算。但离开前，你先看那封信第一页——你妈说，你只要看一眼，就知道接下来该怎么走。”

林一凡撕开封口，抽出信纸。第一行写着：

“一凡，如果你能看到这封信，说明你已经走到第三步了。但你注意，不要相信任何一个长得像‘你自己’的人——因为那个‘他’，已经在两年前，替换了一条重要的时间线。”

信纸下面压着一张照片，照片背面写着两个名字：一个是林一凡，另一个是——凌晨。

凌晨。那不是一个名字，是一个时间——2019年6月17日凌晨，正是母亲“死亡”的那个时段。

车子驶入夜色，林一凡盯着照片背面那个“凌晨”两个字，忽然记起他在暗间墙壁上看到过同样的两个字，用黑色记号笔歪歪扭扭写在一个不起眼的墙角。

那是锁匠的笔迹。

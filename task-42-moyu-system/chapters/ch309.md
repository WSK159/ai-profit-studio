# 第309章 老宅墙洞

毛坯房的水泥地面还泛着潮气，墙角堆着几袋没开封的水泥。林一凡把那根铁管横在膝盖上，钢印“SC-01-120064”在昏暗的灯光下泛着冷光。

“这串数字，跟我工位桌面上的刮痕一模一样。”他指腹摩过钢印的纹路，“老王当年焊这根管子的时候，就计划好了要留给我。”

灰工装男人靠在窗边，嘴里叼着一根没点着的烟：“师父说，有些东西得等你自己发现，别人告诉你的不算数。”

“所以你现在才说？”

“我也只知道一部分。”灰工装男人把烟收回口袋，“师父2019年3月17日那天下午给我打过电话，就一句话——‘要是三天后我没联系你，去老宅墙洞里拿东西。’”

林一凡抬头：“那天晚上他就失联了。”

“不是失联。”灰工装男人摇头，“他是被带走的。我第二天去老宅看过，墙角的灰被扫得很干净，像是有人专门收拾过痕迹。”

沈稚冬蹲在角落，手里把玩着那台折叠屏手机：“林一诺上线的时候说，三把钥匙里有一把在老宅墙洞。现在灰哥说老王也留了东西在墙洞——两样东西放在同一个地方？”

林一凡把铁管立起来，钢管内壁隐约有焊痕：“这根管子是老王焊的，钥匙也是他藏的，他应该考虑过一起被找到的可能性。”

他站起身：“走吧，去老宅。”

灰工装男人拦住他：“现在去？赵恒的人刚把主控芯片拿走，老宅那边未必安全。”

“所以才要现在去。”林一凡把铁管背在肩上，“他们刚拿到芯片，注意力全在破解上，反而不会盯着老宅。”

沈稚冬已经走到门口：“我跟你一起。”

灰工装男人沉默了两秒，从内兜摸出一把铜钥匙：“这是我手上老宅大门的备用钥匙，门锁换过，原来的打不开。”

林一凡接过来，钥匙齿上还带着体温。

夜色浓得像墨。灰工装男人的车停在两条街外的巷子里，是一辆灰扑扑的面包车，后座堆着工具——电焊枪、扳手、一捆铁丝。

“做维修的。”他解释了一句，发动了车。

林一凡坐在副驾，铁管横在后座，沈稚冬靠着车窗，折叠屏手机在她手心微微发亮，屏幕上是林一诺最后留下的那行字：“老宅墙洞。凌晨之前。”

“她说凌晨之前。”沈稚冬把手机转向林一凡，“现在离凌晨还有两个小时。”

“赶得上。”

面包车穿过城中村的窄巷，拐上城郊公路。林一凡看着窗外倒退的路灯，脑子里把时间线又过了一遍：老王2019年3月17日在硬盘标签上留字，第二天“写报告的人已不在公司”；灰工装男人接到电话，老宅墙洞留有东西；林一诺说三把钥匙其中一把在老宅墙洞——老王焊的铁管、钥匙、硬盘，全是同一条线。

他把铁管从后座抽出来，借着路灯的光，再次看那串钢印——SC-01-120064。前六位像编号，后六位像日期。12月00日？不对。也许是倒着读：120064——64年12月00日？还是别的什么。

“看这里。”沈稚冬忽然开口，她用手指按着铁管末端，那里有一圈微微凸起的焊痕，像是焊死了一个小孔，“这根管子里面可能还有东西。”

林一凡眯起眼——焊痕的纹路确实是后补的，比管身其他部位的焊纹要新。他从口袋摸出工地钥匙串，撬进焊痕边缘。

焊皮剥落，露出一个比指甲盖大不了多少的暗格。

里面卷着一张小纸条，和一张硬卡片。

纸条上是一个手写的坐标：北纬31°14′23″，东经121°28′47″。

硬卡片是白色工牌背面的样子，正面印着“星辰科技”四个字，下面的编号被人用刀刮花了，只能看清末尾几个数字：0123。

“0123。”沈稚冬轻声说，“你母亲最后一次住院的日期。”

林一凡把卡片翻过来，背面用铅笔写着一行字，笔迹娟秀，字体略显潦草：“女儿在老宅等你。凌晨。”

两个“老宅”。林一凡攥紧硬卡片，指节泛白。

面包车在老宅门口停稳时，凌晨还差四十分钟。老宅铁门锈得更厉害了，门锁果然被换过——灰工装男人的钥匙插不进。沈稚冬从口袋里摸出一根钢丝，捅了不到十秒，锁芯“咔”地弹开。

院子里杂草齐腰。林一凡踩着记忆里的路径，直扑院子西南角的墙根——他小时候见过父亲往那里埋过东西。

墙根有一排老青砖，其中一块的颜色比周围稍浅。林一凡用手指叩了叩，声音发空。他用铁管尖头撬开砖缝，泥土松动，里面裹着一层油纸。

油纸里包着一把钥匙。

不是他见过的任何一把——黑褐色，牙花像是某种锯齿植物的叶子，形状扭曲得像一只干枯的手，朝内弯着五个齿。钥匙柄上刻着一个数字：03。

“三把钥匙里的一把。”沈稚冬站在他身后，声音很轻，“编号03。”

林一凡正要收进兜里，余光扫见墙洞更深处的黑暗里，似乎还压着什么。他把手探进去，指尖触到一张对折的纸。

展开——B5纸，字迹是打印体，落款日期是2019年3月17日。

内容只有两行：“他带走了主芯片。别去追。等‘三’凑齐。”

林一凡瞳孔骤缩——老王3月17日当晚就知道主芯片被带走了？他写这张纸的时候，人还在公司？

远处传来脚步声，沉闷急切。灰工装男人从巷口探出头：“有人来了。”

沈稚冬已经把手机调成静音，她收起钥匙和纸条，三人贴着墙根退到院子后门。

脚步声越来越近，至少有五个人，还夹着金属碰撞的声音。

林一凡目光一凝——走在最前面的那道人影，轮廓像极了陈重阳。

可陈重阳三小时前才在星辰科技追过他。从城东到城西，整整三十公里，他怎么来得这么快？

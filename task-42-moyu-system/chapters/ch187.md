# 第187章 真相代价

蓝色光从走廊尽头透过来，像一道凝固的溪流悬在半空。林一凡站在原地没有动，系统面板在视野中闪烁得格外急促。

【警告：解锁真相层级Lv.1，离开前需支付“真相代价”。】

“什么代价？”林一凡压低声音问。

系统没有正面回答。老周站在木门边上，半张脸被蓝光映得发青。他没什么表情，只缓缓说：“你已经走到这一步了，想知道代价是什么也很正常——但系统不会告诉你，我也没资格说。”

“那谁知道？”赵日天从旁边探过头，“你上辈子被它坑过？”

老周看了他一眼，没接话，转身踏进走廊。

这条走廊大概三十米长，地面铺着老式的水泥防滑条，两侧墙壁上嵌着管线，散发着一种旧时代防空洞特有的气味。林一凡迈步跟上，心里数着步子。走到一半，系统又弹出一条通知：

【“人力之源”核心结构图已录入。是否加载预览？】

他默念“是”。一幅半透明的三维图在视野中铺展开来——一个巨大的球形装置，外壳像蜂巢，每格都塞着发光的人形轮廓。线路从球体底部延伸而出，直通地表方向。

“这玩意儿……接的是星辰科技的大楼？”赵日天显然也收到了某种共享信息，声音里带上了一丝不自然的干涩。

老周在走廊尽头停下，面前是一扇三米高、对开的铁门。门上没有锁，只有一个凹槽式手印。他侧过头，看着林一凡：“我刚才说，我是你前世猝死当晚，隔壁工位的同事。”

“你叫什么？”

“周建国。工号 0274。”

林一凡猛地停住脚步。前世他被送进抢救室之前，最后失去意识时扫过一眼工位牌——那上面写着“周建国，工号0274”。但他从没见过这个人。他入职三年，隔壁工位始终是空的。人事的说法是“那位同事长期外派”。

“我没死，但也不算活着。”老周举起右手，手掌按进凹槽。指尖处传来“咔哒”一声机械锁动的脆响，铁门内部传来嗡嗡的低频震动。“我被‘人力之源’抽走了一部分东西——说人话：我的命线被绑在那玩意儿上面。只要那玩意儿还在运行，你就永远见不到我的尸体，但也永远别想让我活着站到阳光底下。”

门缝间渗出更刺眼的蓝光。铁门缓缓向内打开，门后的空间大约两百多平方米，像一间废弃的机房。正中立着一台约五米高的机器，青铜色外壳、蜂窝状的表面结构，和系统展示的三维图一模一样。机器正面嵌着一块显示屏，上面滚动着密密麻麻的名字——每一行都标注着“供能中”或“已衰竭”。

赵日天凑近看了一眼，脸色瞬间大变：“这上面……有我的名字。”

林一凡也看见了。屏幕第三行赫然写着“赵日天——供能中”。“老周”两个字在倒数第七行，标注是“衰竭但未断”。而整个列表往上翻，最顶部的名字让林一凡的后背瞬间出了一层冷汗——

“林一凡——供能中”。

他前世死过一次。那“供能中”三个字，说明什么？

“你还没死透。”老周的声音从背后传来，带着一种近乎悲悯的情绪，“我当初以为我死了，其实也没死透。人力之源会提取人的生命势能——不直接杀掉，只是持续抽取。你前世不是猝死，是被这玩意儿榨干了。你重生，是因为系统替你断了一次链接。”

屏幕上，林一凡名字旁边忽然跳出一行小字：

【链接状态：已断开/待重连。】

铁门外的走廊深处，传来一阵脚步声。坚定、沉重、越来越近。老周猛地扭头，低声说了一句：“钱总外围的人来了。”

赵日天抽出一枚硬币，朝机房角落走去：“他奶奶的，老子今天倒要看看，谁敢在这地方动我。”林一凡站在原地，看着屏幕上“待重连”三个字，忽然意识到——系统的“真相代价”，可能才刚刚要开始算账。

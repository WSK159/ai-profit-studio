# 第327章 影子

林一凡瞳孔骤缩。眼前那张和自己有七分相似的脸，加上灰袍人摘下帽子的动作，像一把锤子把某种他一直回避的真相砸进脑子里。

等一下。

他强迫自己冷静下来。摸鱼系统在视野边缘弹出一行小字：【警告：情绪波动超过阈值。前五十五天扫描显示此人面部特征与您匹配度 81.17%。建议深呼吸。】

“你他妈是谁？”林一凡一字一顿地问。

那人和他相似的脸上浮出一丝无可奈何的笑意：“你老板。”

林一凡脑子嗡了一下。

“星辰科技现任董事长，钱总。”那人补了一句。

不可能。林一凡见过钱总，大腹便便，头发稀疏，那双三角眼里永远装着生意人的精明算计。眼前这个人身材清瘦，面容年轻得过分，如果忽略岁月的痕迹，看起来最多四十出头。怎么可能是钱总？

“不信？”那人抬手，从裤子口袋里掏出一副金丝眼镜，架到鼻梁上。然后他坐直身体，耸起双肩，面部肌肉微微一收——那个熟悉的、油腻的、充满压迫感的笑容浮了上来。

“小林啊，加班呢？”他一开口，声音竟然也变得和钱总一模一样，只是更加沙哑，“别太拼，身体是革命的本钱嘛。”

林一凡后背一层冷汗。

这确实是钱总。但他认出来的不是长相——而是声纹。上辈子三年加班生涯，钱总每次出现在研发部走廊时，都会用这种语气说“别太拼”。他从头到尾都在看他们拼命，然后用一声不咸不淡的关心宣称自己恩赏了这一切。

“你到底是……”

“名字只是个符号。”那人摘下眼镜，“我在这个位置叫钱建国。在我师父沈临渊那里叫沈望。在劳务输出局档案里叫……”他顿了顿，“零。”

零。

梯井侧壁上的红漆“零”。第三梯的“零”。被涂改掉的标记。

“你是第一梯的人。”林一凡忽然明白过来。“沈临渊留下的字迹——第三梯记着，第一梯忘记。你的任务是忘了自己是谁？”

“不是忘了自己是谁。”沈望摇了摇头，“是忘了自己原本是谁的人。我替你父亲守着这条通道，守了三十年。代价就是，我每天都要看着镜子里自己那张脸，然后告诉自己——你不是沈临渊的儿子。”

林一凡瞳孔剧震。

孙满仓的声音从他身后传来，带着颤抖：“师父，你这是……”

“老孙。”沈望看向孙满仓，眼中忽然泛上一层浑浊的光，“你师父那张脸，是沈临渊。而我这张脸……也是沈临渊。”

这个弯转得太大了。林一凡半天没接上话。

沈望站起身，踱到梯井侧面那面墙边。墙上有一处不起眼的凹陷，他把那颗铜扣放进去，严丝合缝。金属机关发出一声闷响，墙壁缓缓裂开一条缝。

林一凡透过缝隙看进去，里面只有一样东西——一只老式的录音笔，表面覆着一层黄铜色的薄锈。

“这是你父亲的声音。”沈望说，“他上船之前留在这一层的。”

他按下播放键。录音笔里传来一阵杂音，然后是那个低沉的、熟悉的男声：

“一凡，如果你听到这段录音，说明你走到了这里。第三十三米，是我留给你的最后一站。站在这层能看见那个问题的全部答案，但你要做一个选择——继续往下，或者原路返回。继续往下，你会知道我是谁。也会知道你是谁。”

录音到这里断了。沈望拔出录音笔看了一眼尾部的小红灯，忽然皱眉。

“电池今天到期。”他说。

那红灯泡明明灭灭，像某种倒计时的灵光。

林一凡看向那面裂开的墙。墙后是一条向下延伸的石阶，黑暗无法测量其深度。但在这条石阶的入口处，另一枚黄铜钥匙嵌在砖缝里，和孙满仓手中那把几乎一模一样，只是钥匙柄上多刻了一个字——

“生”。

他伸手去拿。

身后传来灰袍人平静的声音：“想清楚。拿了这把钥匙，你就不再只是林一凡了。”

林一凡没有犹豫，指尖触到冰凉的铜面。

# 第113章 三人成门

老王的脚步声在旧机房的金属地板上回荡，每一步都带着一种奇怪的节奏，像是某种暗号。他怀里抱着那台银章母体仪器，仪器的表面闪烁着暗蓝色的光泽，映在他脸上，让他的表情显得异常平静——平静得有些不对劲。

“老王，你刚才说，负五层需要三个人才能打开门？”林一凡盯着他的眼睛，试图从中找到一丝熟悉的神色。

老王抬起头，目光直直地穿过林一凡，落在墙上某个焦点上：“不止三个人，准确说，是三个锚点。一个生者的锚，一个系统的锚，还有一个亡灵的锚。”

赵日天站在林一凡身后，指关节轻轻叩着腰间那台卷王系统的终端：“你说清楚点。我和他都是生者，系统锚倒是有了——亡灵算什么？电子幽灵？”

老王没有回答他的问题。他把银章母体放在一张布满灰尘的操作台上，仪器自动伸出几根细如蛛丝的探针，插进台面下方的接口。咔嗒一声，整个旧机房的屏幕同时亮起，蓝白色的光芒将三人笼罩。

“银章记录了‘断根执行组’当年在负五层的布防结构。”老王的声音带着一种机械般的平稳，“负五层那道门叫‘根须锁’，三重验证。第一重，生者指纹加虹膜，你们俩能过。第二重，系统认证码，你们俩也能过。但第三重……”

他顿了顿：“第三重，需要回响——一个死者的生物特征。”

赵日天的脸色微微一变：“生物特征？我这一身卷王系统倒是能模拟生物信号，但那是我的，不是死人的。”

林一凡忽然开口：“周莉。”

老王看向他，那双眼睛里有了一丝波动。

“周莉离职前签了断根执行组的保密协议。”林一凡一字一顿地说，“她的档案显示状态是‘已离职’，但如果我猜得没错，她在离职那天就已经死了——她的生物特征会被系统归档，变成所谓的‘亡灵回响’。”

旧机房的气氛瞬间安静下来，只剩下机箱风扇嗡嗡的运转声。

老王忽然笑了，露出一个极淡的弧度：“一凡，你果然还是那个你。”这句话的语气温柔了很多，像是从意识深处挤出来的。

他转身，从银章母体背面抽出一块拇指大小的晶片，递到林一凡手中：“周莉的锚点回切已经完成，她的生物特征代码就在这块片子里。但使用它有一个条件——回响一旦接入，断根执行组就会立刻锁定你们的位置。也就是说，打开负五层那道门的那一刻，就是正面对上的那一刻。”

赵日天忽然嗤笑一声：“正面对上？那正好。我的卷王系统憋了太久。”

林一凡捏紧晶片，指尖微微发凉。“老王，”他顿了顿，“你刚才说，你是被母体‘接引’了——你现在，到底还是不是你？”

老王沉默了几秒。那台银章母体仪器的蓝光变得愈发暗沉，像一只缓缓眨动的眼睛。他开口时，声音里带上了一种不属于他的混响：

“一半是。一半……已经不是了。”

屏幕在他说完这句话的瞬间全部熄灭，整个旧机房陷入一片漆黑。黑暗中，林一凡清晰地听到地板下方传来一声沉闷的叩击——仿佛什么东西在负五层，回应着老王的这句话。

那位“非生者”的门路，似乎已经自己找上门来了。

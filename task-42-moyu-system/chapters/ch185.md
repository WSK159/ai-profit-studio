# 第185章 蓝色光门

那淡蓝色的光从走廊尽头漫出来，像水银泄在水泥地上，流淌到我们脚边三寸处便停住了。

我盯着那道光的边界，心里涌起一种说不清的熟悉感——好像那些光粒子认得我，又或者它们本身就是某个部分的我。

老周已经迈步走了过去，他的背影在蓝光里晃了一下，轮廓变得半透明，像一张长时间曝光的老照片。

“跟上。”他说，语气平淡得像在喊我去食堂吃饭。

赵日天侧头看了我一眼：“你花了5000咸鱼值，不去看看里面到底是什么，亏得慌。”

我没理他，快步跟上老周。

走廊不长，大概二十来步的距离，但每一步下去，脚下的触感都在变化——从粗糙水泥变成了光滑的瓷砖，再变成某种温凉的、近似金属的材质。墙上开始出现断裂的管线，有些还在滋滋冒着火花，蓝色的光从一个圆形凹陷的门框里透出来。

那道门没有门板。

或者说，门板已经融化了——铝制门框的边缘还留着熔铸的痕迹，扭曲成某种抽象的图案，像有人用超高温度从内部把门炸开。我蹲下来摸了摸地面，是光滑的玻璃质感。

“老周，你到底在这下面待了多久？”我问。

老周站在门前仰头看着里面那片蓝光：“你死后第七天，我找到这条路进来的。”

我的心跳漏了半拍。

他说的是“你死后”。

我这辈子，也就是重生后的这一世，从没死过。而前世的记忆，在系统绑定的那一刻就像被人从脑子里拔掉了一页似的，只剩一团模糊的痛。可现在，他说“你死后”，我居然莫名觉得喉咙发紧。

“你……认识前世的我？”

老周终于转过身来。蓝光照在他脸上，那些皱纹像是被光填平的沟壑，他笑了，但那笑容很不真实，像一面镜子里的倒影。

“林一凡，我问你一个问题——你觉得自己是重生了，还是从来没死过？”

这句话像一根针扎进我脑子里。

“什么意思？”

“你的‘前世猝死’——那个晚上，你工位旁边的格子间是谁？”

我的记忆有一块空白，像被人用橡皮擦反复擦过的一个词。可他的声音带着一种逼迫感，让我不得不往里挖。就在我快要触碰到那个画面时——

【警告：宿主即将接触“真相权限”边界。继续深入需要支付2000咸鱼值/分钟。宿主当前咸鱼值：34700。】

系统面板跳了出来，血红色的字。

“系统，这地方到底是什么？”

系统沉默了三秒。这三秒对我而言像三个小时。

【此区域为“人力之源”外围渗透层，为劳动神与资本神共同设下的信息封锁区。宿主当前所在位置，已超出常规系统任务范围。请宿主立即返回。】

赵日天在身后发出嗤笑：“看来你这系统的权限比我的低。我这破系统出了密室门就断联了，你的还能撑到这儿。”

老周却抬起手，敲了敲那扇已经熔化的“门”边缘，发出清脆的“叮”声。

“你们系统的主神是什么时候开始预警的？”

我一愣：“就刚才。”

老周点点头：“那就是了。资本神动了，它也知道你们走到这儿了。现在——”

他回头看了一眼走廊尽头，那道我进来时经过的木门方向，有脚步声由远及近。

不是钱总的，不止一个人。

老周往蓝光里面退了一步：“你们还有三十秒决定：进来，或者回去当什么都不知道的社畜。”

赵日天几乎没有任何犹豫，大步跨进了蓝光里。他的身影被光吞没的瞬间，我听到他骂了一句“去他妈的”。

我站在门槛前，身后是越来越近的脚步声，前方是一片未知的、连系统都不敢解锁的蓝色光海。

系统疯狂弹出警告，红字刷了满屏：【请返回！请返回！请返回！请返回——】

我深吸一口气，踏了进去。

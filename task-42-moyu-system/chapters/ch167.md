# 第167章 日光陷阱

午后的阳光像一把把碎金，从城南老城区斑驳的天花板漏缝里筛下来。林一凡盯着墙上那张手绘的星辰科技主楼结构图，食指点了点“西侧空调检修通道”那个位置，又把目光移到季敏脸上。

“你确定中午这个点，钱总的人不会在顶楼？”

季敏正在检查一个巴掌大的黑色塑料盒——信号干扰器。她头也没抬：“我盯了他三个月，每周五中午他都在中层开会，雷打不动。顶层只有两个保安轮值，换岗时间间隔是十二分钟，我们有四分钟的空窗。”

“够我上个厕所了。”林一凡咧嘴一笑，把保安工牌挂在脖子上，那工牌上贴着一张陌生面孔的照片，是季敏找人做的假证。

老王蹲在角落，把手里的保温杯拧开又拧上，反复三次才开口：“小凡，我总觉得不对劲。他主动引你上去，怎么会不留后手？”

“所以我才要走‘日光陷阱’。”林一凡把工牌正了正，“他以为我会半夜偷偷摸进去，那我偏要光明正大地混在午休人流里。大白天的，谁能想到我敢？”

季敏终于抬头，眼里那点冷意像被阳光化了一层：“十二点三十七分，空调检修通道的第三道门会开。你进去之后直奔货梯，到第八层转楼梯，顶楼的门禁卡我已经给你配好了。记住，拿完钥匙立刻走，不管看到什么都别耽误。”

“看到钱总本人也不耽误？”

“他周五中午不可能在顶楼。”季敏说得很笃定。

三人分开行动。林一凡背着双肩包，里面装着一台笔记本电脑外壳的假货和那台信号干扰器。他混进午休出来吃饭的人潮里，保安工牌被衬衫领子半遮半掩，脚步散漫得像是在遛弯。

星辰科技主楼的自动门在中午十二点左右最繁忙，进出的员工三三两两，没人多看他一眼。林一凡绕到西侧，空调检修通道的小门虚掩着，门缝里漏出一截铁丝——季敏提前布置好的。

他侧身挤进去，通道里全是蒙灰的风机和粗壮的管道，光线昏暗，空气中浮动着铁锈味。按照季敏的草图，他摸到第三道门，门上的锁已经开了，挂着一把摇头锁，像是被人撬过又装回去。

推门出去是货梯间，与员工电梯相隔一排灰色隔断。他按下货梯按钮，电梯从顶层缓缓下来，门开时里面站着一个穿保洁制服的中年女人，推着一辆垃圾车。两人对视一秒，林一凡笑了笑，侧身让了让，保洁女人也没看他，推着车出去了。

八层到了。他走进楼梯间，脚步声被消防门隔成闷响。往上爬了两层，九层传来键盘敲击声，是开发部的工区，午休时间还有人干活。再往上，十层、十一层，声音渐稀。顶楼的门就在眼前，门禁卡贴着读卡器，滴的一声，绿光亮起。

门推开的瞬间，一股冷气扑面而来。顶楼没有想象的暗，整个楼层打通成一个大开间，落地窗外的阳光毫无遮挡地照进来，照得中央那台银白色的主服务器正面泛着刺目的光。林一凡眯起眼，视线从服务器顶部的三把锁孔上扫过——中间那把钥匙孔是空的，而那空孔的边缘，新得仿佛刚被擦拭过。

他侧耳听了听，安静得连空调的嗡鸣都显得刺耳。阳光在地板上拉出又长又亮的矩形，像一条笔直的通道，正通往那台服务器。

“这也太顺利了。”他心里嘀咕了一句。

就在他掏出工具准备动手时，口袋里的信号干扰器忽然抖了一下，发出一声极轻的“嗡——”像是什么东西在反方向被激活了。

顶楼另一侧的角落里，一台嵌在墙顶的监控摄像头，红色的指示灯，亮了起来。

他身后传来一声轻笑。

“林一凡，我猜你会提前来。但没想到，大白天的，你还真敢来。”

是钱总的声音。林一凡缓缓转过身，看见钱总从落地窗的窗帘后面走出来，手里拿着一把银色的钥匙，朝他晃了晃。

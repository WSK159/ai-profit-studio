# 第278章 门在零点开

林一凡把那张字条翻过来看背面，空白。他盯着“陈月季”三个字——档案室里那个穿病号服的女人，赵心怡做了整形手术后的化名，她为什么要留这张字条？而且是放在赵日天的办公桌上？

她到底站在哪一边？

23:58。

他来不及想了。林一凡把字条塞进口袋，快步冲出办公室往电梯方向跑。赵恒说的那句话在他耳边反复回响：“门在零点开。”

门。是哪扇门？

电梯门在他面前“叮”一声打开。他犹豫了一瞬，没有进去，转身往安全通道跑。楼梯间里的声控灯一明一灭，他的脚步声在水泥台阶上咚咚作响。他直奔负一层——消防泵房的旁边，他注意到过一扇锈迹斑斑的铁门上挂着个旧门牌：“B1-07”，但没有编号钥匙孔，只是门把手被人摸得发亮。

他冲到那扇铁门前时，手机屏幕上正跳动着23:59的数字。林一凡深吸一口气，从口袋里摸出那把010号钥匙——它的形状和普通钥匙截然不同，三叉结构，冰凉的金属在昏暗的灯光下泛着冷光。

钥匙插进锁孔的感觉顺滑得不像话，像是这把锁等了很久很久。他拧动，锁芯发出“咔哒”一声轻响。

门往里推开。

门后的房间不大，约莫十来平方米，像是一间被遗弃的档案室。四面墙壁排满了铁皮柜子，正中央的桌子上放着一台老式录音机，旁边摆着一盘没有标签的磁带。

录音机上贴着一张便签纸，字迹娟秀清晰：

“林一凡，如果你看到这里，说明你已经找到了门。这份录音是林一诺在2019年6月14日录制的最后一版。我是赵心怡，当年她让我在她死后第二天把东西放进来锁好。我不确定你会不会来，但她说，你一定会来。”

林一凡的手微微颤抖，按下了播放键。

磁带转动的声音沙沙作响，然后，一个和他记忆里一模一样的女声响起：

“一凡，如果你在听这个，说明我已经不在了。你别急着哭，也别急着报仇。姐姐做这些事，不是为了让你去拼命。姐姐只是想让你知道——你不欠任何人七年。”

录音里传来一声轻轻的叹息，像是她在微笑。

“赵日天确实害了我，但他只是棋子。真正让我死的人，是钱总——他跟我做了一笔交易，用你的自由换我的命。我替你签了那份合同，把七年锁给了公司；他答应放过你。但我不信他。”

“一凡，赵恒是你这边的人，别恨他，他不值得你恨。还有，我留了两把钥匙——三叉钥匙你已经拿到；另一把，在你以为我收藏的旧书里，家里的书架上，蓝灰色封面那本。”

“你听完之后，把磁带翻面，背面有东西。”

林一凡翻转磁带。背面贴着一张极薄的纸条，上面用铅笔写了一行字：“钱总的保险柜密码是你父亲的忌日。打开他的保险柜，你会知道——谁杀了我。”

空白。磁带完了。

林一凡攥着那张纸条，胸口剧烈起伏。

就在这时，顶上的日光灯突然闪了两下。微弱的电流声之中，墙壁上的铁皮柜门发出“啪嗒”一声响，最低层的那个柜子，缝隙透出一线光亮——像是里面藏了什么活的东西。

零点的钟声，从远处传来。

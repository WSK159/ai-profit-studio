# 第268章 另一个死者

林一凡选了“接受”。

系统面板没有像往常一样跳出金色光效或者音效提示，只是在任务列表里新增了一行灰色小字：【“另一个死者”——调查谁才是2019年7月2日四平路车祸中的真正目标。奖励：取决于解锁内容。风险：当前任务链不可逆。】

不可逆。他不喜欢这三个字，但现在没有退路。

他调转方向，沿着检修井继续爬行，大约七八米后，墙面右侧出现了一道灰色铁皮门。门上没有锁，只有一块标牌：“负二层·废弃档案室”。

他推开门，落到一条满地灰尘的走廊里。走廊尽头就是档案室，锁是坏的，门掩着，里面透出昏黄灯光。林一凡本能地放轻脚步，贴着墙根朝门口靠近。

从门缝里，他看到一张旧办公桌，桌上摊着一沓泛黄的文件，旁边的台灯是这间屋子里唯一的光源。桌后坐了一个人，低着头，正一页一页地翻阅文件。那件灰色夹克林一凡认得——是陈重阳。

陈重阳听到动静，猛地抬头，与林一凡四目相对。

安静了两秒。

“你还能活着走到这儿，说明命够硬。”陈重阳没有起身，只是伸手把桌上的文件往自己这侧拢了拢，“过来把门关上。”

林一凡迟疑片刻，还是推开铁门走进档案室，在身后合上了门。他环顾四周：档案柜全是空的，桌面只有台灯、那沓文件，以及一把拆下后重新装好的机械手表。

“这是陈和平的表？”林一凡问。

“是陈和平托我保管的。”陈重阳回答，语气平静，“他说他这辈子只会戴这一块表，但也说了，如果有一天他出事了，让我把表交给他妹妹。”陈重阳顿了顿，“可他到死都没有妹妹。”

林一凡皱眉：“什么意思？”

“他的意思是，陈和平的妹妹在2019年之前就死了。”陈重阳合上文件，看向林一凡，“倒过来算——陈和平说他妹妹死在2019年7月2日四平路车祸里，但档案里写的死者只有一个人：赵小九。陈和平所谓‘妹妹’的身份，在这个世界上根本查不到记录。他撒谎了。”

林一凡脑海中像是有什么东西“咔哒”一声对上了。

“那……陈和平为什么撒谎？”

“因为他在替人顶罪。”陈重阳的语气平静得近乎冷酷，“车祸那天死在车里的确实是赵小九，但开车的不是赵小九——是陈和平。他是替另一个人开的车，但之后他把所有责任揽到自己身上，坐了二十年牢，然后才被赵恒安排在陈建国身边。”

林一凡站在灯下，指尖发凉。

“他替谁开车？”

陈重阳看着他，沉默了很久，最后从抽屉里拿出一张照片，递到他面前。

那是一张泛白的监控截图，画着一辆黑色面包车，驾驶座上的人被挡风玻璃反光遮住大半张脸，只能看清一个轮廓：短发、瘦削，下颌线条分明。

林一凡的目光死死钉在照片上，整个人像被浇了一桶冰水。

——那是他。

或者说，那个轮廓像是他。只是下巴比现在的他更尖，眼睛更深，像好几年没有睡过一个整觉。

“你别慌。”陈重阳的声音像是从很远的地方飘过来的，“这是2019年6月30日晚上11点27分，四平路路口监控拍到的画面。你最后一次出现在监控里是7月1日凌晨的便利店，之后你再也没有出现在任何公开记录里——直到2026年9月，你‘重生’回到星辰科技入职。”

林一凡的嗓子干得发紧：“你的意思是，2019年6月30日我还在……”

“你不仅还在。”陈重阳把那张照片翻过来，背面用铅笔写着一行字，“7月2日之前，你是唯一一个接触过‘织网’初版代码的人。你写的东西，赵小九带着，然后在7月2日的车祸中消失了。可‘织网’却在你重生后，出现在了你的系统里。”

他抬起头，看向林一凡。

“所以问题不是‘赵小九替你死了’——而是你为什么要让她替你死，而不是你自己去死？”

林一凡嘴唇微动，却什么都没说出来。

系统的任务面板在这时轻轻闪了一下。

【“另一个死者”任务进度更新：“你为什么要让她替你死？”——需要回答此问题后才能继续。】

他盯着那行字，脑海中浮现出一个模糊的梦境片段：一扇白色大门，一个女孩背对着他站在门口，声音轻得像风——

“你不是要回去吗？我替你走这段路。”

那声音不属于赵小九，不属于任何他认识的人，但他那一刻竟然觉得熟悉到心口发疼。

“你怎么了？”陈重阳的声音响起。

林一凡猛然回神，冷汗从额角滑落。他垂下眼，掩盖住表情，没有回答那个问题。

就在那时，档案室外的走廊上传来一串脚步声，紧接着有人在门外面说：“陈叔，外面的人撤了。钱总刚带人往东楼走了，大概三分钟后会到消防通道。我们要不要换条路走？”

那声音很年轻，带着一丝熟悉的气息。

林一凡回头，隔着铁门缝隙，他看到走廊灯下一个不到二十岁的少年，穿着星辰科技后勤工服，胸口的胸牌上写着三个字——

“赵·小·满”。

赵恒的弟弟，赵小九的另一个亲人。

那少年仿佛感知到林一凡的目光，侧过脸，与他对视了一秒。

少年的瞳孔骤然收缩。

他看着林一凡的眼神，不像是看一个陌生人——像是看见了一个不应该出现在这个世界上的人。

“你是——”赵小满的声音戛然而止，手猛地按住了腰间。

林一凡没有动，但他的手指已经搭上了010号钥匙的边缘。

脑海中，系统提示音再次响起：【你需在60秒内做出选择：跟随赵小满离开，或返回负三层密室继续追查“命运归还”任务。倒计时开始：60……】

59……58……57……

林一凡深吸一口气。

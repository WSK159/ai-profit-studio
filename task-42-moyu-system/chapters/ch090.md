# 第90章 断线的鱼

警报声越来越刺耳。屏幕上那个红色的倒计时已经变成红色闪烁的数字：42 秒。

“拷完了没有？”林一凡声音沙哑地问。

周莉猛地回过神，连着按了几个快捷键：“拷贝完成，本地加密文件已经保存到……等等，不对。”

她的话戛然而止，目光死死锁在屏幕上。副本文件的哈希值和原本不一致，被篡改过一个字符。如果不仔细比对，用肉眼根本发现不了。

“有人在我们的系统里预留了后门，改动文件的末尾加了一段东西。”周莉用极快的速度把加了料的那一小段拖出来，“这是一个追踪程序，如果有人把这段文件带离星辰的网域，追踪程序会在下次联网时自动发送位置信标。”

林一凡的脸色沉下来：“所以我们从进门那一刻起，就已经是猎物了。”

“不止。”周莉翻看着那段隐藏代码的结尾，声音忽然变轻，“这里面还嵌入了一条私钥签名——签名者是钱雨的个人工作账号。”

也就是说，钱雨事先知道有人会来翻阅这份备份。他甚至算准了时间，在这个备份里埋好了追踪器，只等猎物上钩。

倒计时 28 秒。

“那我们现在怎么办？”周莉额头渗出细汗，手指微微颤抖，“带出去会被追踪到，不带出去就等于没拿。”

林一凡闭眼一瞬，然后睁开：“先破坏追踪器。我不会把这份文件带出去——我会把里面的内容全部记在脑子里。”

“你疯了吧？几十页的数据你怎么记？”周莉几乎要跳起来。

“系统面板，”林一凡低声说，“解锁‘记忆宫殿’技能，用咸鱼值兑换。”

他的视线转到眼前半透明的系统面板，那一行熟悉的蓝色界面正悬浮在视野边缘：

【咸鱼值剩余：4,720】
【记忆宫殿（高阶）：3,000 咸鱼值——可将任意文本以图像形式永久刻入记忆，读取时可随时调出全文】

毫不犹豫，林一凡确认了兑换。一股冰凉的触感从太阳穴炸开，眼前的文档像被无形的扫描仪掠了一遍，每一行代码、每一个数字都化作光点，烙进他的意识深处。

他在三秒内“看”完了整份 PDF。

“记住了。”他睁开眼，呼吸微微急促，对周莉说，“现在切断连接——直接拔线，不给追踪程序反应的时间。”

周莉点头，蹲到主机后面，一把拽掉网线插头。电流声“啪”地消失，机器内的小风扇转了两圈，终归死寂。

两个人站在原地，整个厂区的服务器房间里只剩下他们沉重的呼吸声。警报在切断连接后自动停止了，但那个“反向追踪”的进程是否已经完成，仍然是个问号。

“走。”林一凡抓起背包，把装有加密文件的外置硬盘塞进夹层，“回去再说。”

他们穿过三条走廊，推开侧门的那一刻，冷冽的晨风灌进来，天边已经泛白。林一凡深吸了一口气，肺泡里炸开一把寒意，他站在台阶上没动，忽然开口：

“江雪的最后一句，你注意到了吗——钱雨不完全是人。”

周莉系紧外套带子，低声道：“我导师做的是类神经研究，方向是让机器拥有生物感知力。如果钱雨……不完全是人的话，那他身上一定融合了类似的技术。”

“那个资本神计划，和你导师的实验室有关？”林一凡问。

周莉犹豫了两秒：“我很久没回去了。实验室在我回来前一年拿到了星辰科技的投资——我当时觉得只是普通的科研经费。现在回想起来……可能没那么简单。”

她忽然停住脚步，从口袋里掏出手机。屏幕亮着，一条新消息躺在通知栏里：“江小姐：你们切断得挺及时。但有些事，晚一步就是晚一步。想弄清楚资本的真相，欢迎来找我。”

发送时间，就在他们拔线的三十秒后。

林一凡看着那条消息，像是看到一张已经张开的网，正在不紧不慢地收拢。他沉默了一会儿，把手机还给周莉：“回吧。这盘棋还没下完。”

两人转身朝厂区外的二手车走去。身后的厂房在晨雾中像一头沉默的巨兽，亮着一扇窗户——那是服务器机房的方向。

窗边，似乎站着一个人影。

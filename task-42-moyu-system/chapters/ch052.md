# 第52章 三行合一

林一凡没有立刻去填那个空栏。因为他看到在那行小字“系统拥有者”旁边的角落里，还有一行更小、更暗的印刷体——摩斯码，只有六个点。

他抬起手表的表蒙，老刘维给他看的TEST-03B卷宗里，六次出现在秦氏数据核心区的“林一凡”，每次停留的时间分别是：1分44秒、2分57秒、0分31秒、4分12秒、3分09秒、0分26秒。把这六个时间组的数字差值转换成摩斯码——点、划、停顿——翻译出来的结果是三个字母：ZTY。

赵日天的拼音首字母。

林一凡的瞳孔一缩。他一直以为赵日天只是被当作棋子的可怜虫，现在看来，那家伙从一开始就是这场博弈里的关键环节。至少在这一段加密信息里，第三行空栏最原始的指向，是赵日天，而不是他。

“别填。”刘维似乎也看到了那行摩斯码，声音急促而克制，“你一旦把赵日天的名字填进去，系统的所有权就会自动归属他。你现在填自己，才能保住你重生三年来攒下的全部咸鱼值。”

门锁传来咔的一声——钱总已经刷开了第一道锁。

林一凡的指尖悬在虚拟键盘的第二排按键上，冷汗从鬓角滑下来。刘维说的是对的——逻辑上，系统绑定个体，不可能让宿主以外的人拥有控制权。但“系统拥有者”那一栏的原始指向却偏偏是赵日天，这只能说明一件事：赵日天和摸鱼系统之间存在某种连林一凡自己都不知道的深层关联。

“他也有一个系统。”林一凡说。

刘维愣了一下，随即点了点头：“卷王系统。两套系统同源但敌对，你填他的名字，你的咸鱼值会被他的卷王引擎反过来抽取——你会变成一只彻底没有能源的咸鱼。”

这句话像一盆冷水浇下来。可就在这个瞬间，林一凡的脑海中猛然闪过那条隐藏规则：系统每100级解锁一次“系统真相”。他现在895级——距900级只差5级。而第三行空栏，如果他不填自己、不填赵日天，而是把这行空栏激活成“问题”，那系统也许会直接解答——它的真正主人是谁。

“你信我吗？”林一凡问刘维。

“我信你活人站在我面前。”刘维说得很干脆。

林一凡深吸一口气，在虚拟输入框里敲下了一行不是名字的字：请求解析“系统拥有者”原始定义。

三秒的延迟，像三年那么长。

总控室的老式荧幕上的文字忽然全部消失，取而代之的是一行青白色的小字：宿主权限不足。解析需要995级及以上。

林一凡心里一紧——还差整整100级。但下一秒，系统面板弹出一条从未出现过的提示：检测到宿主处于密钥验证开放状态，可提前进行“系统真相预读”。是否消耗10000咸鱼值，预读当前版本的系统源数据？

10000咸鱼值，那是他辛辛苦苦摸鱼攒了大半年的全部家当——一旦失败，直接归零，连重置的机会都没有。

门锁传来第二声“咔”——钱总已经刷开了第二道锁。还剩最后一道。

“填啊！”刘维在背后低吼，声音里第一次带上焦急，“你再不填，门就开了！”

林一凡只犹豫了半秒钟，然后他选了一个两者都不是的结果——他把第三行空栏直接清空，然后在输入框里单独输了一个标点符号：问号。

系统静止了一瞬。

整个总控室的灯光忽然全部熄灭，只剩下那台老旧荧幕上跳出一行小字：预读请求已接受。正在回溯系统本源数据……

荧幕上开始快速滚动出一段段林一凡从未见过的底层代码，速度太快了，快到他根本来不及逐行读取。但他捕捉到了一个关键片段——在系统源数据的创建者字段里，赫然写着两个字：劳动神。

而创建日期那一栏，是五年前的4月22日，凌晨04:22。

林一凡的瞳孔猛然放大——那个时间，正是他重生的节点。他猛地低下头，看着自己手腕上的旧手表：秒针停在04:22的位置，一动不动。

“咔——”第三道锁被拧开了。

钱总的手握住门把的一瞬，总控室的灯光骤然恢复，荧幕上的代码消失得一干二净。

系统面板上弹出一行冰冷的红色警告：预读中断，咸鱼值扣除10000。剩余咸鱼值：0。

林一凡猛地站起来，大脑一片空白。他指节发白的拳头撑着桌面，盯着那扇即将被推开的铁门，刘维在他身侧攥紧了卷宗。而荧幕最后一帧残余的光晕，在他视网膜上留下了一行极淡的印记：系统重生点绑定宿主代号——ZTY-01，验证失败。

赵日天，竟然是系统的第一顺位宿主母本。

而林一凡，只是一个衍生出来的影子。

门开了。

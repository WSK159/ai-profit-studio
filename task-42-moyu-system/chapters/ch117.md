# 第117章 生命痕迹

石室的门合拢时，发出一声沉闷的、像是吞咽的响动。林一凡回头看了一眼那道厚重的金属门，门缝间嵌着一层暗红色的、仿佛铁锈又更像干涸血液的物质。他暂时没工夫思考出去的路。

铜柱管道。他走近那根巨大的、直径足有两人合抱的铜柱，管道壁上的暗纹像血管一样延伸，有些地方微微颤动，仿佛里面裹着活物。老王站在他身后，脸色很不好看。

“你确定……”老王的声音有些哑，“那里面，有你前世的痕迹？”

林一凡没有说话。他伸手贴在管道壁上，金属冰凉，但掌心下传来极细的、规律的脉动，像心跳。紧接着，管道壁上浮现出一层淡蓝色的荧光纹路，逐渐汇成一行行小字。

赵日天凑过来，目光在荧光字上扫了一遍，皱起眉：“‘锚点’是什么东西？你的意思是，你这具身体之前还死过一次？”

“不止一次。”林一凡的声音平静，但手指微微收紧，“我被重置过。这个系统……”他顿了一下，“不是第一次绑我了。”

老王倒吸一口凉气。赵日天却咧嘴一笑：“有意思，你也有秘密啊。”

林一凡没有理他。他闭上眼，将意识往管道壁上贴近，系统的提示音在脑海中响起。

四十三分钟。他睁眼看了一眼右上角跳动的倒计时，点头：“读。”

一瞬间，他整个人像被什么东西猛地拽进一片深海。画面碎片般涌来——

他看见自己，穿着一件完全陌生的深灰色制服，站在一个比星辰科技地下更深的、没有尽头的空间里。面前是一个模糊的、笼罩在光晕中的女性轮廓，开口时声音混合着电流和温柔。

“你来了。”她说，“但这一次，你会记得吗？”

画面碎裂。林一凡猛地抽回手，踉跄后退了两步，老王一把扶住他。

“看到什么了？”老王低声问。

林一凡直起身，眼神里多了某种说不清的复杂情绪。他缓缓开口：“看到了R。她是……当初把我送到这一世的‘引路人’。而且她说的这句话，和刚才门外那个声音，一致。”

赵日天抱臂，若有所思：“所以R认识你前世。”

林一凡没有否认。他低头看着管道壁上那个“78%”的完整度数据——另外22%的生命痕迹缺失了。是被清除？还是被切断？他不知道，但他隐约有种感觉，答案就在不远处。

就在这时，铜柱管道深处传来一声低沉的轰鸣。紧接着，他口袋里那颗银章——老王此前从母体身上剥下来的、一直由林一凡保管的银章——突然剧烈震动起来，从他口袋里弹了出来，悬浮在半空，表面浮现一圈圈血色纹路，仿佛被某种力量激活。

老王瞳孔骤缩：“它在回应什么。”

林一凡转头看向石室深处。那面墙后，隐约传来第二颗心跳。两颗心跳，在彼此响应。

他的呼吸一滞——石室深处，还有别的锚点。

他抬脚朝深处走去。

# 第130章 舱外爬行者

那道暗红色的影子在浮空港外壳上缓慢爬行，像一只巨大的变色龙贴在金属表面，边缘与背景融为一体，只偶尔在灯光明灭时露出一线轮廓。

林一凡把脸贴在舷窗上，试图看清那个东西的全貌。但暗红色的表皮仿佛吸收了所有光线，他的眼睛只能捕捉到模糊的轮廓——有头，有四肢，但比例怪异，像被人拉长的橡皮泥。

“这他妈的……是人吗？”老王已经靠了过来，声音发颤。

赵日天没说话，但他的右手已经摸上了腰间的装备扣。林一凡注意到，那枚扣子上嵌着一块拇指大小的暗红色晶石，表面微微发光。

“卷王系统。”赵日天像是感应到了林一凡的目光，头也不回地说，“功能之一：暗物质视觉，能透视伪装和隐形。”

他盯着窗外看了几秒，眉头越皱越紧：“那东西……不是活的生物。我看到的能量场，更像某种程序编码——伪生命体。”

“伪生命体？”林一凡立刻想到钱国豪，“是卷王系统的手笔？”

“不确定。”赵日天收回目光，“但有一点很明确——它在朝着我们的方向移动。而且速度不慢。”

他在导航面板上按了几个键，全景投射出浮空港三维结构。一个暗红色的光点正从外壳A区的检修轨道，沿着金属支架向中转舱方向移动，预计到达时间是——十二分钟。

十二分钟。

林一凡看着投影，脑子里飞速转动。三种选择：第一，留在这里等它来，正面应对；第二，提前离开中转舱，通过连接舱段前往发射甲板，在那里找到一艘对接船飞向卫星F-7；第三，直接穿航天服出舱，绕过浮空港外围，在轨道上寻找离开的路径。

“老王，浮空港和F-7卫星之间，有没有现成的飞船或梭子？”

老王额头上渗出了汗珠：“大厅那边有投放舱，是应急用的单人救生梭，续航够到月球轨道，但需要手动解除电磁锁定——”

“解除锁定的方法？”

“在中央控制台刷管理员权限。”老王的脸色有些难看，“但管理员权限需要至少A级身份卡。咱们没有。”

【摸鱼系统提示：检测到宿主机械知识储备充足。是否花费800咸鱼值兑换“电磁锁破解模块·便携版”？】

林一凡嘴角一挑：兑换。

系统面板一闪，大量关于电磁锁结构的知识涌入他的大脑，像把一本技术手册直接刻进了记忆里。他扫了一眼中央控制台的方向——那台机器前端有一块透明面板，透过玻璃能看到内部密密麻麻的电路和线圈。

“不用权限。”林一凡大步走向控制台，“老王，接线工具给我。”

老王愣了一下，赶紧从工具包里掏出微型螺丝刀和万用表。林一凡蹲下身，拆下控制台侧面的盖板，露出半掌宽的缝隙，伸进手去，指尖感受到了密密麻麻的电路板接口。

他闭上眼，那些刚兑换的知识在脑海中如同展开的图纸，每一个焊点、每一根导线都清清楚楚。他找到锁定线圈的驱动电路，从侧面的备用保险丝座引出一根跳线——巧妙地绕过身份验证模块，直接给解锁执行机构供上了电。

控制台发出“滴”的一声。

电磁锁的红色指示灯变绿，那排单人救生梭前端的光罩缓缓亮起。

“成了。”林一凡拍拍手站起来，“走，一号投放舱，三艘救生梭，够咱们三个飞向F-7。”

就在他话音落下的瞬间——

“轰！”

中转舱舱门被一股巨大力量拍得凹陷变形。金属在压力作用下发出尖锐的呻吟声，像是有什么重物在门外反复撞击。

老王的脚已经软了，靠在墙上才没摔倒。

赵日天转身面向舱门，取下腰间的晶石扣在掌心，那枚暗红晶体瞬間展开成一柄半米长的短刃，刃面流转着诡异的红光。

“来不及走投放舱了。”赵日天语气沉下来，“你去解锁那玩意儿，我来顶住它。”

“你顶得住？”林一凡问。

“它不是伪生命体吗？”赵日天冷笑，“我好歹和卷王系统相处到现在。伪生命体——最怕的就是同类。”

他话音未落，舱门从上到下被撕裂开一条黑黢黢的口子。一只暗红色的手掌从裂缝中伸了进来，五指细长如竹竿，指节处挂着粘稠的黑色液体，落在地板上发出嗤嗤的腐蚀声。

林一凡转身就跑向投放舱方向，同时冲老王喊：“跟上！别回头！”

老王踉踉跄跄地跟着跑。身后，赵日天已经迎上了那道裂缝，暗红短刃横扫，击在那只手掌的腕部，发出金石交错般的脆响。

那只手缩了回去，但裂缝立刻更大了——半张白色的、没有五官的“脸”从裂缝外探了进来，像一张被撑到极限的面具。

林一凡冲进一号投放舱的小门，三艘单人救生梭整齐排列，舱盖已经打开等待。他飞身跳进第一艘，手指在操作面板上飞速输入坐标和航向。

老王跌跌撞撞地爬进第二艘。第三艘的舱盖还没有打开——而投放舱的门后，已经传来赵日天的一声闷哼。

“卷王，别跟它耗了，赶紧进来！”林一凡冲着通讯器吼。

赵日天的声音传来，断断续续带着喘息：“这东西……它认识我。它身上的编码……和我的系统同源……”

“你说什么？”

“钱国豪的话不全是假的。但他说的话，也不全是真的。”赵日天声音一沉，“我拦住它，你先走。F-7见。”

“赵日天——”

通讯断了。

三秒后，第三艘救生梭的舱盖自行弹开，一道人影闪了进来——赵日天，满头大汗，右手臂上一道黑色的划痕正在冒着烟。他一把拍下舱盖锁定键，吐出一口浊气：“走！”

林一凡没犹豫，一键按下脱离。投放舱舱门打开，三艘救生梭依次被电磁弹射器推出浮空港，瞬间进入无垠的宇宙。

身后，那座浮空港的外壳上，那道暗红色的影子正缓缓挺直身体，像是数百米高的某种东西正在站立起来。

林一凡咬着牙，把推进器推到最大，朝着月球远地侧的F-7卫星飞去。

他的脑海里，只剩一个问题——那东西说赵日天的系统与它同源。那钱国豪到底是谁？

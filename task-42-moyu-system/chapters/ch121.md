# 第121章 断根猎手

铜柱上的裂纹正在以肉眼可见的速度蔓延，暗红色的光芒从裂缝中渗出，像是某种沉睡之物正在苏醒。倒计时面板悬浮在三人眼前——00:24:31，数字还在飞速跳动。

“25分钟？从我们进来到现在已经过去快一分钟了。”老王的声音有些发颤，“这破石室连个出口都没有，我们怎么出去？”

林一凡没有回答，他的目光死死盯着铜柱底部那道刚刚浮现的暗纹。那是他前世记忆里的东西——一种二进制编码的变体，被嵌进树根年轮般的纹路中，只有触发“锚点回溯·最终权限”才会显现。

“这不是普通的根须，”他说，“这里面有一套完整的程序逻辑。锚点清除不是外部攻击，是系统本身就埋在根须里的定时炸弹。”

赵日天皱眉：“你说这个铜柱是系统的一部分？”

“不。”林一凡蹲下，手指描过那道暗纹的走向，“铜柱是银章母体的嫁接线，根须是它的神经网络。我们触发了锚点回溯，等于告诉母体——这里有人拿到了最终权限。所以它启动了自毁程序，想把我们连带着这个秘密一起埋掉。”

“那还愣着干嘛？”赵日天猛地站起身，“踹门啊！暴力破拆！”

“这石室深在地下五层，四周全是母体的根须结构。暴力破拆等于给它制造更多裂缝，加速程序蔓延。”林一凡从裤兜里掏出手机，打开一个看似乱七八糟的记事本——里面存的其实是他前世留下的代码碎片，“我们得找到清除程序的源头，然后反写它。”

老王凑过来，看着屏幕上密密麻麻的十六进制字符串：“你什么时候写的这些？”

“前世。”林一凡简短地回答，“我只记得一部分，但‘锚点回溯’功能应该能补全剩下的记忆碎片。”

他闭上眼睛，意识沉入系统面板的最深处，那个刚刚解锁的条目正发出幽蓝的光芒——「锚点回溯·最终权限：可回溯至任意时间节点，获取完整记忆链。使用条件：需消耗2000咸鱼值。警告：使用后将发出强信号，可能暴露位置。」

2000咸鱼值。他攒了大半个月的存货。

“你们帮我守着门口。”林一凡睁开眼，“我要用那个东西了。”

赵日天愣了一下：“你确定？外面可是有——”

话未说完，石室外传来沉闷的声响。像是有什么东西在拍打石壁，又像是根须正在收拢碎裂的岩石。

老王脸色发白：“来得这么快？”

赵日天咬着牙从腰间抽出一根不知什么时候捡的金属管，站到了石室门口：“快去，我给你顶住！”

林一凡不再犹豫，意识彻底沉入系统空间。周围的石壁消失，取而代之的是一片深红色的虚空，无数光影碎片如萤火般在他周围盘旋。他知道，这些就是前世记忆的碎片，每一片都是一个自己曾经活过的瞬间。

“回溯目标：锚点-0059对应的那一世的记忆链。”他在心中默念。

光影骤然汇聚，一道巨大的时间轴在他的意识中展开，像一根无限延伸的藤蔓。他的目光沿着藤蔓往回爬，越过二十一世、二十世……直到第22条命的尽头。那是一个模糊的夜晚，他在某个地下实验室里，面前是一台老旧的终端机，屏幕上正滚动着一段代码。

他看见了那段代码的结尾——

“若发现此处，我已死在第一次重生之前。清除程序的源头不在母体内部，而在——”

那个名字刚浮出半个字符，石室外忽然传来一声咆哮般得巨响。整个石室猛地一震，林一凡的意识被硬生生拽回现实。

他睁开眼，看见赵日天整个人被什么东西撞飞，砸在铜柱上，金属管脱手旋转着滚到角落。老王惊呼着去扶他，而石室门口，那只根须构成的“猎手”已经探入了半个身体。

它的形态扭曲而狰狞，像一只由树皮和暗红色黏液组成的人形生物，没有五官，只有胸口处嵌着一枚银色的断根暗码，正发出不祥的节律脉冲。

林一凡的心猛地一沉。

那枚断根暗码，和他们之前在负三层发现的那枚碎片完全一致——是同一对信号源的一部分。

清除程序不是母体的自毁，而是某个更古老的存在在远程触发。而那只猎手的胸口，装着它用来定位锚点的“钥匙”。

“跑不了，”赵日天从地上爬起来，嘴角渗血，“这家伙的速度太快了——”

林一凡没有答话，目光扫过那枚暗码，一个疯狂的计划在他脑中成型。

他还有600多咸鱼值，不够回溯，但足够兑换一次技能——“断根干扰”。

系统面板弹出确认框的那一刻，他笑了。

“猎手是吗？我把你的钥匙抢了，看你还怎么锁定我们。”

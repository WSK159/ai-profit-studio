# 第411章 门里门外

“不用猜了。”林一凡没往后退，反而向前迈了一步，“你根本不在任何人身体里。你就在门里面，是个连形状都没有的东西。”

铜门内寂静了片刻。那两根青铜钉也停在半空，钉尖颤了颤，像是被这话卡住了。

老杨头大哥盯着他，嗓子发紧：“你怎么知道？”

“因为我摸过那把钥匙。”林一凡弯腰捡起地上的铜钥匙，指尖摩挲着那缕黑发，“这发根是活的，还在往外渗汗。如果是死人身上的头发，不会有这种温度。陶土珠子裂开的时候，里面那张图钉帽上全是新鲜的锈——是刚才才生成的。”

他抬起头：“门里那东西没有实体，它只能靠吸附别人掉落的‘名字’来制造物件。它让我捡到第一根钉，因为你——门外这个守门人——是它的一份子。第二根钉是它临时编出来的，钥匙也是它编的。不，钥匙是沈望未白带进来的，但它编了个谎，让钥匙变成‘赵日天的真相’。”

沈望未白的脸色终于变了，她往前一步，声音发抖：“你怎么知道钥匙是假的？”

“因为赵日天没有一个纹章是28。”林一凡把那枚图钉帽摊开，露出底面一行极小的字——“债务转置·丙区四号”，那行字下面画着三道水波纹，刚好对应归墟井口壁刻上的暗记，“我在井口看到过这个符号。那是资本神的赌局标记。赵日天确实换过命，但不是替我去死——他把自己的死债转给了钱方远，然后把自己焊进了‘卷王系统’里面。所以钱总才会越长越像赵日天，因为他眼睛里住着半个赵日天。”

老杨头大哥松开手，掌心的黑锈正在蔓延到小臂，但他说出的声音却异常的平静：“那你还要不要用钉子？”

“不用。”林一凡说，“门里那个东西最怕的不是钉子，是名字。我现在把名字拿回来。”

他把铜钥匙横在掌心，用图钉帽的尖角划破食指，血珠滚落在钥匙齿上，黑发顿时像受了烫一样蜷曲起来，陶土珠子咔地裂成两半，露出一颗被包裹得严严实实的铁芯。铁芯上面刻着一个完整的名字：林一凡。

这就是他第一次重生时，丢在门缝里的那截“命”。

林一凡把铁芯攥住，门缝里的声音忽然尖厉得像指甲刮黑板：“你敢拿回去——你拿回去，门就关不上了！你爹的死、老杨头的死、孙满仓欠的债、沈临渊锁的那三十二天，全都会压回你一个人身上！”

“我知道。”林一凡说，“但那些压在我身上，总比压着一个连名字都没有的东西要轻。”

他把铁芯按进铜门锁孔，逆时针拧了一圈。门缝里的锈迹忽然沸腾般涌出暗红色的烟雾，两根青铜钉同时跌落在地，铛铛两声响在通道里荡开。锁孔深处传来一声极轻的“咔哒”，像是某种坚持了很久的东西终于松动。

铜门没有说话。

林一凡拔出铁芯，退后半步。门缝里那片黑暗忽然往里缩了缩，露出一道只容一人的空隙。空隙深处，他看见一副半腐烂的躯体靠坐在门内的墙根边，头和身体之间缠着一圈红绳，绳尾系着一枚陶土珠子——珠面上刻着“27”。

“老王……”林一凡听见自己的声音干涩得像砂纸。

那具躯体微微动了一下，眼眶里两粒灰白的眼珠缓缓转过来，盯住林一凡手里的铁芯。半晌，它张开嘴，吐出一句模糊不清的话，被门缝的风切成碎片，但林一凡听懂了，也不管身后沈望未白骤然收紧的呼吸，他说：“收到，剩下的交给我。”

他转头看向老杨头大哥，那铜脸上的锈色正在成块剥落，露出一张他熟悉得不能再熟悉的脸。那人笑了笑，开口时语气不再像之前那个死气沉沉的守门人的： “第九次，你终于认出我了。”

话音没落，铜门轰然合拢。通道里骤然安静，只剩沈望未白的呼吸声和林一凡手心里那颗铁芯的温度。他低头看了一眼铁芯，背面不知何时多了一行细小的刻字，新鲜得像是刚刚落刀：“白骨的纹章，在你拿钥匙时，已经刻进你无名指的指纹里了。”

他抬起左手，无名指指腹上，果然浮着一枚隐隐的陶土色纹章，数字模糊，但他闻得到上面那股葬土的味道。他攥紧拳头，没说话，只将铁芯收进贴近心口的衣袋里。

# 第76章 第三块硬盘

无人机没有回答。它悬停在天台上空，红色镜头像一只不眨眼的瞳孔，盯了林一凡大约五秒钟后，忽然调转方向，朝南面楼顶边缘滑去。

林一凡愣了一下——它走了？就这么走了？

不对。他顺着无人机离开的方向看去，心脏猛地一跳。

南面楼顶的消防梯旁，站着两个黑色西装的男人。他们悄无声息地爬上了天台，手里握着电击棒，浑身散发着专业打手的冷漠气质。其中一个看见林一凡的目光扫过来，抬腿便朝这边冲。

林一凡骂了一声，掉头就朝反方向跑——但他刚迈出两步，脚下一顿，忽然想起了什么。

他回头。无人机的声音确实消失了，但那台黑色旋翼机并没有飞远，而是悬停在两个西装男头顶的位置，像一只等待着猎物口袋合拢的鹰。

那台无人机，是在引导两个西装男的位置。

“调虎离山。”林一凡咀嚼着这四个字的口味——苦的，还挺熟悉。

上一世他被裁员那天，HR也是这种操作，先让老好人同事把他约到会议室，再让两个保安等在门外，主打一个“你叫破喉咙也没用”。

但这一世情况不一样——他手里有真名钥匙，硬盘信息直指机房那个被敲坏的架子，那里还放着第三块硬盘的碎片。江雪生前说过，她把自己“真名”的密钥拆成了三块：一块藏在服务器迁移程序里、一块在她曾经用的工位下面、第三块则留在机房硬盘架上。

可赵日天把备份交给他时说过：“第三块碎片毁了。”

但他现在看到的东西，让他对这个判断产生了动摇。那两个西装男从消防梯爬上来的位置，刚好是机房正上方的区域——而赵日天备用机那块“损坏”硬盘的物理扇区碎片，被他藏在了机房地板的维修夹层里。

林一凡脑子里轰的一声闪过一个念头：赵日天那家伙，可能根本没把第三块硬盘交出去！

他没有往楼梯方向跑——那正是西装男希望的路径。他转身压低重心，跑向天台北面的落水管。水管锈迹斑斑，承受他的体重绰绰有余。他翻过围栏，身体贴着外墙踩住管体，像一只壁虎一样顺着管道往下滑。

砰。

三秒后，他摔进机房北面的通风井，膝盖磕在水泥地上，疼得眼前发黑，但他顾不上，弯腰钻进通风井尽头的小门——机房设备维修夹层。

夹层里只有半米高，到处都是管线，一股霉味混合着金属锈的气息。他爬了大约七米，手指碰到了一个硬邦邦的盒子。那是一只铝合金的硬盘盒——表面落了一层灰，但夹层密封完好，被他抠出来时，盒盖上还贴着一张旧标签：

“废件，编号8-17。”

真正的编号是8-17。而赵日天当时拿出来的那张标签，写着8-18——

不是损坏的那块。这一块，是好的。

林一凡的手抖了一下。他打开盒盖，里面躺着一张巴掌大的军用级固态硬盘。他攥紧硬盘，忽然意识到一个大问题：他没有读卡设备。

那块芯片是真名密钥的物理载体，硬盘是数据本体，但这里没有电脑、没有读卡器，他拿着这两样东西等于拿着两把钥匙却没有锁。

“操。”他低声骂了一句。

头顶传来脚步声——西装男已经顺着排水管追下来了，声音正在靠近夹层入口。林一凡把硬盘塞进衣服里，把芯片重新藏回表带，掏出手机看了一眼：凌晨三点三十四分。

信号满格。

一个念头炸开：他不需要读卡器——他需要的是把真名密钥的作用方式搞明白。江雪设定密钥的时候，不一定只留了物理通道。赵日天刚才用的暗桩功能，也许能读取芯片里绑定的“真名调用协议”。

他拨通了一个号码。零秒接听。

不，那个号码不是人接的，而是一段自定义系统提示音：“咸鱼值不足，本操作需消耗100点咸鱼值，当前余额：0。”

林一凡盯着手机屏幕，忽然笑出了声。他摸鱼两年，攒下来的215点咸鱼值，全砸进了反卷护盾。现在系统空转，他手里攥着一整座矿，却连一把铲子都没有。

头顶夹层板被掀开一条缝隙，西装男的手电筒光柱直直射在他脸上。

“找到了。”

林一凡眯起眼睛，手指紧紧抓住硬盘盒，在那道光线里忽然坐直了身体，声音带着一种穷途末路的懒散：

“兄弟，你们拿我也行，但这硬盘你们真不敢动。”他把硬盘举高，让手电的光照亮硬盘盒上的标签，“这是江雪留下的——她给全公司所有人留了一份‘真名备份’，你们老板不知道这个硬盘在哪，你们也不知道。”

手电光顿住了。

西装男沉默了两秒。然后他说了一句让林一凡猛然攥紧拳头的话：

“江雪？三个月前她离职的时候，删了公司所有备份。”

——这句话像一记闷雷。林一凡的瞳孔骤缩。他突然明白了为什么钱总愿意花这么大代价要找这块硬盘，不是因为硬盘里有江雪的秘密，而是因为钱总不确定这块硬盘里，有没有自己怕的东西。

手电光移开了，西装男的声音恢复了冷漠：“把硬盘交出来，你还能留个全尸。”

林一凡笑了，声音沙哑得像锈铁：“那你回去告诉钱总——要么把我弄死在这，要么等我活着走出去，把硬盘内容公开。他选一个。”

他握着硬盘，向后一撞，矮小的维修门在他身后弹开，露出一条通向公司地下车库的管道，管道尽头——就是整栋大楼唯一的出口。

但他知道，这片暗影里，至少有四道视线在盯着他。钱总派来的，不只是这四个人。

手机屏幕又亮了。没有号码，只有一行字跳出来：

“欢迎使用摸鱼系统。检测到宿主持有‘真名密钥’，解锁紧急兑换通道：摸鱼0天，可用本次冲突产生的‘抗争值’兑换技能——是否确认？”

林一凡盯着这行字，心跳漏了半拍。

抗争值。他一直以为这个系统只有摸鱼值一条计量单位，原来它还有另一个名字。

他拇指落下，点击确认。

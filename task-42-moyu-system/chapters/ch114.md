# 第114章 亡灵回响

黑暗持续了大约三秒钟，应急灯才重新亮起，昏黄的光线下，老王的面色显得异常苍白。银章母体仪器表面浮起一道裂纹，那裂纹正以肉眼可见的速度扩展，发出细小的噼啪声。

“时间不够了。”老王的声音重新变得平稳，但林一凡注意到他握住仪器边缘的手指在微微颤抖，“母体已经开始失控，它的‘接引’信号会吸引断根执行组的人来。”

林一凡把晶片攥在手心：“那就现在走。赵日天，你那个共享生命线还能撑多久？”

赵日天抬起手腕看了一眼数据：“双锚点模式下，稳定运行还有四十多分钟。如果打架，会压缩到二十分钟以内。”他咧嘴一笑，露出一口白牙，“够用了。”

三人穿过旧机房最内侧的防火门，进入一条向下延伸的狭窄楼梯道。林一凡数着台阶——负四层的大门是锁死的，但老王用银章母体侧面伸出的另一根探针插进锁孔，那扇门自己弹开了一条缝。里面漆黑一片，各种废弃的服务器和断掉的线路拥挤地堆在一起。

老王没有停留，径直走向负四层最深处。那里有一个被防尘布盖住的机械装置，揭开防尘布，露出一台老式电梯门，门上方铆着一块黄铜铭牌，刻着三个字：**根须道**。

“负五层就是从这里下去的。”老王把手按在电梯旁的识别板上，那台老式电梯发出一声沉闷的嗡鸣，门缓缓打开。

电梯间很小，只能容纳三四个人。他们走进去后，门合拢，下行大约二十秒后停止。门再打开时，一道刻着密密麻麻奇怪纹路的金属大门出现在眼前。这些纹路在微弱的光线下看起来像无数条纠缠的根须，从门缝间渗出一种冷冽的金属气息。

赵日天吹了声口哨：“就这？看着像个保险库，不像藏着什么秘密的地方。”

但没有人回应他，因为那道门上方的三盏指示灯依次亮起，第一盏是绿色，第二盏是蓝色，第三盏是红色，代表着三重验证。林一凡把自己的左手按在门侧的一个凹陷处，微微刺痛之后，第一盏灯嗖地熄灭——生者指纹虹膜验证通过。赵日天取出一根数据线，将卷王终端的输出口接入门体侧面的端口，第二盏灯闪了两下，熄灭——系统认证码通过。

只剩下最后一盏红色灯，孤零零亮着，像一个待解的谜。

林一凡深吸一口气，将那枚晶片嵌入门体中央的凹槽。一瞬间，他感觉自己的意识轻微晃了一下，像是被什么东西牵引着。耳边响起一个模糊的女声，不远不近，像隔着很长的时间传来——

“一凡……你来了。”

他猛地抬头。门上的红色指示灯忽然变成刺目的血红色，整扇门的纹路像活了一般蠕动起来，那种金属的气息变成了某种更复杂的东西——像泥土、像树根、像一种沉睡很久的生命正在苏醒。

门缓缓向内打开，露出一个窄长的通道。通道尽头，是一间比想象中要大得多的石室，石室中央立着一根两人合抱的铜柱，铜柱上盘绕着一根粗大的透明管道，里面流淌着一种银白色的液体，正沿着管道流向更深的地方——那液体途经的每一段管道壁上，都贴着标签。

林一凡走近，看清了最近一张标签上的字迹：

**锚-0027-林一凡（前次迭代）**

他的心脏猛地一缩——那根透明管道里流淌的，不是别的，正是他上一世的生命痕迹。

而在这根铜柱的顶端，一盏昏黄的屏幕正投射着一个不断跳动的倒计时：

**根须清除程序剩余启动时间：46分钟。**

赵日天的声音在身后响起带着一丝罕见的凝重：“那个R……到底想让我们看到什么？”

无人能回答。而在他们身后，那道刚刚打开的根须锁门，正在无声地、缓缓地合拢。

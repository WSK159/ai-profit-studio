# 第110章 三位面之锁

03:52:19。倒计时还在跳。

赵日天拧着眉头问出了林一凡心里那句话：“老王，你说负五层要三个人开——但我们俩活人加一具尸体，凑不齐也没有‘亡灵’啊。亡灵是什么？是死人身上的残魂，还是他妈的一段程序？”

老王刚恢复意识又有点迷蒙，他揉着太阳穴：“母体接引时没细讲……它只说，负五层的门不是物理门，是三把锁。第一把锁是魂锁，第二把锁是脉锁，第三把锁是因果锁。活人锁由活人的心跳验证，死人锁由死人的灵魂频率验证，因果锁嘛……”

“因果锁？”林一凡接过话，“由什么验证？”

“由你这一生的选择验证——你重生之前做出的那个选择。”

林一凡脑海里闪过猝死前那个晚上：他其实有机会不加班，有机会请假回去躺平。但他没有。他选择了继续加班，选择把那一行代码改完再走。前世的选择，就是因果锁的钥匙？他不敢确定。

赵日天却冷笑了一声：“三个人，活人锁有了，死人锁有了——因果锁呢？你一个人不可能同时开两把锁。”

“所以缺一个亡灵。”林一凡说，“一个不属于生死、又扯得上因果的存在。”

老王忽然抖了一下，像被针扎了。他伸手从胸口口袋里摸出一张泛黄的工牌，牌面上贴着半张身份证照，被水渍泡掉一半，但林一凡一眼就认出了那个名字：

周立。

周莉的弟弟。

林一凡记得这个人——三年前的星辰科技员工，也是安全事故里死掉的那个测试工程师。周莉签“断根执行组”保密协议后，就是因为他。而那张工牌背后的署名，“R”，跟旧终端机弹出的消息签名一模一样。

“周立……就是亡灵？”林一凡问。

老王摇头：“我不知道。但这张工牌是周莉离职前塞给我的，说‘如果有天你需要开负五层的门，带着它去找负三层旧机房的终端机’，我以为她疯了。”

赵日天嗤了一声：“这丫头倒是留了一手。她在你前世死在这儿的那晚也签了协议，现在人跑了，把弟弟的工牌留给你当钥匙——她拿自己的弟弟当亡灵锁？”

“不对。”林一凡说，“周立死后，周莉应该把她弟弟的遗体处理了或带走了。亡灵锁要的是灵魂频率，不是工牌本身。但如果周立死的时候，残存灵魂频率被绑定进了这张工牌……”

他话没说完，旧终端机的屏幕像感应到什么，刷地亮起。跳出的字不再是消息，而是一张平面图：负三层、负四层、负五层的结构图。负五层标注着一个红点，红点旁写着三个字：

“亡灵位”。

红点旁还有一行小字，字迹跟“R”的消息一样：“活着的死人，才能开死人的锁。”

赵日天看完了，慢慢把视线移到林一凡身上：“你前世的尸体在负五层，周立的残魂频率在这张工牌里——老王是活人，我是活人，再加你前世的尸体，三个维度凑齐三把锁。因果锁呢？”

林一凡盯着屏幕上那行字，忽然生出一种极其荒诞的念头。他开口时自己都觉得疯了：“如果……我选定重生那一刻，我已经成了‘亡灵’——活着的死过的人，不算纯生，也不算纯死。我能同时碰活人锁和死人锁。”

老王张了张嘴，没说话。赵日天扭过头，神情复杂地看了他一眼。

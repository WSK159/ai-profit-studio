# 第170章 半个系统持有者

楼梯向下转了三次弯，墙上的工业管道锈迹斑斑，空气里飘着一股陈年咖啡和机油混在一起的味道。台阶尽头是一扇铁门，门上有人用马克笔歪歪扭扭写着一行字：“加班是自愿的，摸鱼是天赋的。”

我推开门。

地下一层比我想象中破得多，几个破沙发围着张矮桌，桌上放着一台老式台式电脑，屏幕亮着，发出一阵嗡嗡的电流声。四下里空无一人。

可我还没来得及打量第二眼，背后传来脚步声。有人从门后的阴影里走出来，手里拎着一罐凉茶，晃了晃，冲我呲牙一笑。

“还真敢来。”那人说。

我转头。赵日天。他穿着一件深蓝色连帽衫，帽子没拉起来，露出一张比我上次见时瘦了一圈的脸。他靠在门框上，像是等了一会儿了。

“你发的短信？”我问。

“嗯。”他仰头灌了一口凉茶，“你要是没回，我还以为你怕了。看你出现在这儿，说明你脑子还没彻底被加班熬坏。”

我盯着他的手。他右手腕上戴着一块黑色运动手表，表盘边缘有微弱的蓝光亮了半秒，随即熄灭。我摸过系统商城，知道那玩意儿不是普通智能表——那是“卷王系统”的终端设备之一，等级不低于我的。

“你是来拦我的？”我站定在那儿，保持三米距离。

赵日天嗤笑一声：“我要是想拦你，你走不到这儿。我比钱总的人早一步看到你跳窗——那种路线，八成是钱总故意给你安排的，你该明白。”

“所以？”

“所以我想抢在他前面见你一面，告诉你一件事。”赵日天压低了声音，“钱总手里那把钥匙，不是他一个人的。这栋楼下面有第三把锁，他光有钥匙也打不开，得凑齐三把才行。一把是时间，一把是算法，一把是权限。他现在手里那把，是权限的那把，但钥匙锁芯上还有个坑，得用另外两把钥匙插进去才能转开。”

我在重组这些信息。三把钥匙、双锁机制、时空+算法+权限，当初系统提示过模模糊糊的“铜锁机关”，但明显更深一层。

“你怎么知道这么多？”我问。

赵日天嘴角的笑意淡了淡：“因为我是第二个‘绑定者’。”他撸起左臂袖子。他的小臂上有三道细长的红色刻度线，从腕关节一路延伸到肘弯，像某种古旧的封印纹路。“我的系统叫‘卷王系统’，跟你正好对着来。它给的任务是：只要被你摸鱼系统影响的人数超过一千人，我的系统就会降级；反过来，你的咸鱼值要是清零，我这边的进度条就全满——林一凡，我俩从绑定那天起就被设计成了对立面。”

他顿了顿：“但钱总不知道的是，我的系统协议级别比他想象中的低——我并不是完全被他控制的棋子。我查过自己系统后台，发现一件事：这两个系统，来自同一个‘赌局’。”

这个信息撞得我脑袋里嗡了一下。摸鱼系统也有隐藏设定：系统每100级解锁一次“系统真相”。我快到那级别了，但还差儿经验。

“赌局双方，”我接话，“劳动神和资本神？”

赵日天没回答，只是缓缓点了点头。

他正想继续说什么，整层楼的灯光突然闪了一下。那台老式电脑的屏幕跳出一行红色的字：

【检测到第三方接入——坐标锁定。】

然后“啪”的一声，显示器黑了。

我和赵日天同时转向楼梯口。铁门方向传来沉重的脚步声，不止一个。赵日天骂了一声：“钱总的人封过来了。他从一开始就没打算让你活着走出这家咖啡馆。”

我扫了一眼系统面板，咸鱼值余额够换一次“摸鱼空间”强制隐身，但CD还要八分钟——来不及了。

“跟我走。”赵日天朝沙发后面一蹲，从地板底下抽出一条暗门，“这层楼还有个地窖，连着旧排水管，直通隔壁街的下水道出口。我早摸过这儿的路。”

我看了一眼那条黑漆漆的地道口，又看了一眼楼梯口逼近的脚步声。赵日天在那儿咧开嘴露出一个熟悉的卷王式笑容：“怎么样，摸鱼系统的持有者，愿不愿意跟卷王系统的人走一遭？”

铁门被人一脚踹开。

我没有第二个选择，跳进暗门，赵日天顺手拉上盖板，我们两人坠入黑暗之中。身后传来钱总手下扯着嗓子喊“他人呢”的嘈杂声，然后是重物轰然坠地的闷响——有人砸开了电脑屏幕。

地道里，赵日天掏出手机打亮屏幕，照亮一张十几平米的小房间。

我这才看清他手腕上那块表：屏幕上正飞快地滚动着一行行数字，最后停在了一个进度条上——【卷王系统 · 协议级别：LV.08 · 当前目标：阻止“钥匙融合”80%完成度。】

“钱总要的那把钥匙，是他的权限钥匙；但钥匙融合的80%，需要靠我们两个的系统合力才能完成。”赵日天声音沉下去，“他想把我们两个系统里的‘核心代码’抽出来炼成第三把钥匙——而那把钥匙打开的东西，叫‘自由’。”

他看着我：“我本来想把你绑来交差的，但现在我改主意了。”

“为什么？”

赵日天把手机屏幕转过来，上面是一张加密文件的截图，标题写着：“劳动神协议·独立条款”——下方一行小字：【若两系统持有者自愿联手，赌局取消，皆可获得‘自由’选项。】

“因为老子卷了半辈子，也累了。”他说，“你当你的咸鱼，我当我的卷王，但咱俩谁都不该给别人当棋子。赌局那俩神，爱谁谁。”

地窖里安静了整整十秒。

我的系统面板突然弹出一条金色提示：

【触发隐藏协议：劳动神与资本神的双系统赌局——可联合任务。选择：[接受] / [拒绝]】

我看了赵日天一眼。他冲我挑了挑眉，像在等一个从没听过的答案。

我伸手，点了【接受】。

# 第242章 守护者的代价

“是锁。”

陈默的声音在狭窄通道里格外清晰。她将鸟形钥匙从锁孔前移开，翻转手腕，手环内侧露出一个与圆形徽章完全一致的凹槽——三圈同心圆，纹路丝毫不差。

“我妈说，这个手环从小戴到我十六岁，摘不下来。直到她走的那天，它自己松了。”陈默的视线落在凹槽上，“后来我开始查我爸的事，才发现手环内层的纹路和‘锁芯’是配套的——我是那把锁。”

林一凡催动摸鱼雷达，视野中陈默手环处涌出一团不稳定的能量流，像困在茧里的萤火，挣扎着向外冲。而在她身后通道两壁的机械爪印，同一时刻泛起极淡的蓝——同源的能量，同频的脉动。

“所以你爸说‘别让她开这把锁’，”赵日天沉声道，“因为一旦用你开锁，你要么被榨干，要么——”

“成为它的一部分。”陈默接完他的话，语气平静得像在说别人的事。

林一凡的心沉下去。“那这扇门后面是什么？”

“LX系列的核心机。”陈默说，“我查了三年。整个负六层是一个供电骨架，LX设备是插在骨架上采集‘劳动纯度’的探头。这扇门后面那台，是最初的那台——LXR-0。”

“原始的意志机？”林一凡想起配电房外面那道黑影。

“不是。”陈默摇头，“LXR-0比意志机更早。它是用来监控‘裁决者’的。”

裁决者。这个词在舱室里炸开。老周笔记本上的批注、陈建国加密消息里重复的警告、钱总等待的“导线断了之后的东西”——所有线头在这一刻缠成一个结，指向同一个答案。

“你爸是裁决者。”林一凡说。

陈默没点头也没摇头。“我爸是LX系统的第一个维护者，也是第一个‘实验体’。他‘常驻’负六层那三年，是被人关在这里，充当机器的校准基准——机器通过观察他的劳动与休息，学习如何判断一个人是真勤奋还是假摸鱼。”

赵日天手里工牌的蓝光剧烈颤动起来。“他教系统抓摸鱼——那他自己呢？”

“他自己，”陈默的声音终于起了一丝波澜，“被系统判定为‘合格’，所以永远不能出去。”

通道尽头，那扇嵌壁门的锁孔里，忽然传来一声低响。齿轮转动，金属摩擦——门内有什么东西正在自动解锁。锁孔周围的墙面裂开一道细缝，从中渗出一缕油墨味。林一凡想起陈建国笔记本上那句“她是我女儿的守护者”——他不是在交代任务，他是在保护陈默的命。

“我妈是第一批维护员里唯一逃出去的。”陈默说，“她走那天摘下手环，告诉我永远别回负六层。”

“可你回来了。”赵日天的语气不知是质问还是感慨。

陈默低头看着掌心那枚圆形徽章。LXR-0-CORE，三个同心圆，蓝色导线像静脉一样蜿蜒。“因为我查到了最后一件事：机器里存了一段我爸的原始记录——他最后一次读完那十二句‘别进六层’之后，还录了一分钟，没有加密发出去，但保存了。”

“他说了什么？”

陈默抬起眼，目光穿过走廊落向那扇半开的门：“他说，‘锁芯不是她，是我。’”

话音未落，嵌壁门豁然洞开。门内一片漆黑，黑暗中浮着一台半人高、布满铜线触须的机器，铜线末端泛着与赵日天工牌裂缝同色的蓝光。而在机器正中央，一枚凹槽正对着林一凡手心的圆形徽章。

“他把锁芯从你身上换到了自己身上。”赵日天的声音极低，“你爸是拿自己换了你的命。”

机器的铜线触须同时亮起，像无数只复眼，齐齐转向陈默。

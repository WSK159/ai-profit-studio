# 第418章 旧痕

老杨头大哥的眼睛在说出“杨林”两个字之后，像是被抽走了所有力气，整个人靠着青铜门边的石壁滑坐下去，一只手仍旧按在左眼眶那处血洞上。鲜血从他指缝间往下淌，在青灰色的地砖上积成一小滩，边缘泛着细密的泡沫。

林一凡蹲下身，盯着他：“你认识门里那个人。”

老杨头大哥的嘴张了张，唇上全是干裂的白皮，声音像是从胸腔最底处挤出来的：“……认识。他是我儿子。”

这句话让林一凡的后脑像是被什么东西狠狠敲了一下。“你儿子？”他转头看向那扇青铜门，“那他说自己叫‘林杨’，还说我妈……”

“你妈嫁给了我儿子。”老杨头大哥抬起那只没有按眼睛的手，在脸上胡乱抹了一把，血和灰混在一起，把那副老脸涂得面目模糊，“杨林——这是我儿子的名字。你妈把他名字倒过来念，叫他‘林杨’。”

林一凡的脑子里嗡地一声。他想起锁芯女人黑发缠上他手腕时，那缕淡淡的焦糊味；想起门内传出的那个声音，自称“林杨”时竟然带着一丝熟悉——那嗓音的质地和质感，和林一凡自己说话时几乎一模一样。

“……那我爸，”林一凡的声音有点发哑，“叫什么名字？”

老杨头大哥没回答这个问题，只是慢慢垂下头。他的后颈露出来，林一凡这才看见，那上面横着一条极深的旧疤，从耳后一直延伸到脊椎中段。疤痕已经褪成灰白色，但在青铜门散出的暗光下，仍旧显得狰狞可怖。

“你妈是个很好看的女人，”老杨头大哥忽然说，“我第一次见她的时候，她正在河边烧铜。铜水流进模具里，火花溅到她脸上，她连眼睛都不眨一下。”

他的语气忽然带上了某种遥远的温柔，这种温柔和他现在的狼狈形成巨大的反差，让林一凡觉得不真实。

“她做了一个锁芯，”老杨头大哥继续说，“那锁芯能锁住任何东西——门、箱子、人心。但她没来得及锁住她自己。”

铭牌——林一凡脑中猛地闪过一个画面，那是他刚进归墟时在走廊墙上看到的一块锈蚀铭牌，上面刻着几行字，其中有一句他没来得及细看：“铸者自锁，锁者自铸。”

“她把自己铸进去了？”林一凡的声音压得很低。

老杨头大哥没有否认。“门后那张纸，”他抬起头，那只仅剩的眼睛红得吓人，“上面写着你爸的名字。你妈把那个名字烧进纸里，烧成了灰，再用那灰和铜水混合，重新铸成一张纸。那纸上的字这辈子都擦不掉，除非把纸烧成灰——可那纸本身就是灰。”

林一凡忽然觉得胸口一阵绞痛。他低头看向自己的左手腕，那截被黑发勒出的旧伤疤正泛着淡淡的红色，像是被什么东西从里面蹭亮了。他的血刚刚激活了第三根灰烬骨钉，骨钉的钉帽数字翻成“27”，而那27颗陶土珠——老杨头大哥左眼那颗已经碎裂成灰，灰色气息没入铜门。

他忽然想到一个问题：“既然我妈把自己铸进锁里定了价码，那28颗陶土珠又是怎么来的？谁布的这个局？”

青铜门内忽然传来一声沉闷的震动，像是有人从门里拍了一下门板。紧接着，那个自称“林杨”的声音再度响起，这次比之前清晰许多，也冷了许多：

“珠子是我布下的。每一颗都对应一把钥匙，每一把钥匙都对应一个愿意替我死的人。”

林一凡猛地站起身：“那老杨头大哥——”

“他是第一把钥匙。”门内之人说，“他替我死过一次。但那一次没能打开门，因为他还缺一颗珠子。”

老杨头大哥在石壁边发出一声低低的呻吟，像是被说中了某个最不想被提起的秘密。林一凡低头看向他，发现他手背上那三颗嵌着的陶土珠正在慢慢转动，珠面上的纹路像活物一样游走，其中一颗已经裂开一道细缝，边缘露出一截黑色的东西——像是人的头发，又像是铜丝。

“现在他身上还剩三颗，”门内之人继续说，“加上你刚给他的那一颗——他一共为我准备了四颗。但你母亲定下的价码是二十八颗。所以你猜猜，还差多少？”

林一凡的瞳孔骤缩。他数过：图纸上标注的是27，可他数到的陶土珠位置却有28个——其中第26颗在锁芯女人左眼里，第27颗嵌在青铜门的门楣上。而老杨头大哥手背上这三颗，加上他刚抠出来的左眼那颗，一共四颗——那对应着图纸上最后四个位置。

也就是说，老杨头大哥从一开始就是局中一颗棋子，负责把最后四颗珠子带到这里。而他自己根本不知道这件事。

“你儿子死了，”林一凡压低声音，“你替他死过一次。但你现在，是在替他卖命。”

老杨头大哥的独眼慢慢看向他，那里面有浑浊、有茫然，还有一种说不上来的东西——像是多年前某个雨夜里，有人在河边烧铜水的时候，溅起的火花落进了他的眼睛里，就再也没熄过。

门内之人又说话了，声音里带着一丝微不可察的笑意：“林一凡，你母亲定的价码从来不是二十八颗珠子。她定的是——你父亲的名字，和我，只能留一个。珠子只是计数方式，不是钥匙。”

林一凡的手攥紧了，指甲嵌进掌心。就在这时，他脚下的青灰色地砖开始出现细密的裂纹，裂纹沿着一条直线笔直地延伸向青铜门底部——那扇门仿佛正在被什么东西从另一侧慢慢推开一条缝。

缝隙里漏出来的不是光，而是一股极冷的、带着铜锈味的风。那风绕着他脚踝打转，将他裤脚卷起时，他看见自己小腿上不知什么时候多出一道黑色印记——像是某个人的指印，五指分明，从膝盖一路抓到了脚踝。

门内之人说：“你父亲的名字，就在那张纸上。你只要推开门，就能看到。”

林一凡沉默了三秒，然后抬起头，看向那条裂缝。

他没动。

“——如果我不推呢？”

门缝里漏出的风忽然停了。四周安静得吓人，连青铜门上的古老纹路都不再流动。老杨头大哥在他身后发出一声极轻的吸气声，像是没想到他会这样回答。

片刻之后，门内之人缓缓开口，声音平静得没有丝毫波澜：“那自然会有人替你推。你父亲的名字，终究要被人看见。”

话音落下，林一凡的手机忽然震动了一下。他翻出来一看，屏幕亮着一条新消息，发件人是一串陌生的号码，消息只有一行字：

“你妈说，你小时候最爱听的那首歌，是她拿铜片敲出来的调子。”

林一凡的瞳孔猛地缩紧——他从来没跟任何人提过那首歌。那年他四岁，在灶台边仰着脑袋，母亲用一把铜勺敲着锅沿，敲出一个不成调却又异常熟悉的旋律。他记得那首歌的第一句是：大河向东流，天上的星星参北斗。

他握着手机，指节发白。

那条消息的落款处，附着一个名字。

“——杨林。”

林一凡猛地抬头，看向青铜门缝里那片漆黑，喉咙里挤出一句话：“你把我妈怎么了？”

门缝深处，传来一声极轻的叹息。那不是林杨的声音，而是一个女人——沙哑、疲惫，像是隔着一整条河的距离，从很远很远的地方吹过来：

“小凡。”

林一凡的膝盖一软，差点跪下去。

他母亲的声音。他甚至不需要分辨——那是他母亲的，绝对没错。

“别推门，”那声音说，“推了门，你就出不去了。”

青铜门的缝隙，在她话音落下的那一刻，缓缓合拢。 ——只剩下那条极细的缝，像一道黑色的疤，横亘在门板和门框之间。

林一凡站在原地，低着头。他的肩膀在抖，但不是怕的那种抖。

老杨头大哥挣扎着从地上爬起来，那只独眼死死盯着关合的门缝，忽然低低地笑了一声：“……她原来还活着。”

他笑声里带着一种复杂的情绪——像是一个埋了三十年的人，忽然看见自己坟头长出了草。

林一凡没理他。他只是盯着手机的屏幕，那条消息下方又跳出一行字，发件人变成了两个字：“活下去。”

然后屏幕黑了。他再按，没有反应——像手机里的电整个被人抽走了。

走廊深处的黑暗里，传来一阵奇怪的声音，像是什么东西正沿着墙壁爬过来，指甲刮过铜皮，发出一连串干燥的、尖细的摩擦声。这声音越来越近、越来越密，仿佛有无数只脚、无数只手，正从走廊那头的黑暗中涌来。

老杨头大哥脸色一变，转头看向走廊尽头：“……它们来了。”

林一凡把手机塞回兜里，握住那根灰烬骨钉，指节收紧。

门缝里漏出的那段女人话音已经彻底消失了。但最后一字“活下去”还沉沉地压在他的耳膜上，像一块烧红的铁皮。

“——走。”

他转身往走廊那头跑去，脚步声在青铜通道里回荡，身后那密集的抓挠声紧追不舍，眼看就要扑到他的后颈——

灰烬骨钉的钉帽忽然一热，数字“27”像是被火苗舔了一下，边缘泛起一圈细密的暗红色纹路。

而那只从走廊深处伸出来的灰白色的手，已经搭上了他的肩膀。 =====

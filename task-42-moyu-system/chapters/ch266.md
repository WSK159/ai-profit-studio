# 第266章 替你死的女人

赵恒的话像一颗钉子，钉穿了林一凡剩下所有关于“重生”的认知。

走廊里的空气凝固了三秒。林一凡下意识后退半步，背撞在铁门门框上，震得锁芯发出一声脆响。他死死盯着赵恒的脸，脑子里飞速运转——2019年的画面一幕幕翻上来：重生睁眼在工位上，桌上放着入职协议，屏幕右下角显示2019年7月1日，一切干净整洁得像刚成年的孩子。他从来没想过，那一天之前，这个世界还发生过别的故事。

“你说赵小九替我死了，”林一凡的声音稳下来，但每一个字都像在薄冰上行走，“那我是谁？我为什么会在2019年6月30日的深夜走到四平路？”

赵恒没有立刻回答。他从口袋里摸出一枚黑色的U盘，指甲盖大小，抛过来。林一凡伸手接住，指腹上划过一道粗糙的磨痕——U盘的边缘被人用砂纸打磨过，像是刻意要抹掉什么标识。

“这里面有一份原始记录。”赵恒说，“2019年6月30日晚11点47分，你以‘临时外包人员’身份进入星辰科技数据中心，持绿卡权限，有记录的系统操作时长47分钟。你从数据中心的备份系统里拷走了一份东西，然后从东门离开。凌晨3点17分，你在四平路被货车撞上。”

林一凡握着U盘的手指节发白。他的脑海里炸开一道裂缝，一些不属于他记忆的画面碎片涌上来——一间满是服务器噪声的机房，屏幕上闪烁的绿色乱码，一只戴着黑色手套的手插进某个机架的接口。画面模糊得像隔着一层毛玻璃，他抓不到更清晰的细节，但那些碎片散发出一种熟悉的冷冽感。

“我闯进去，是为了拿那份东西？”他问。

“对。”赵恒说，“你拿的是星辰科技第一代AI考核系统的核心底层代码——‘织网’雏形。你把它带走之后七天，公司就上线了测试版，但所有人都以为那东西是从零开始开发的。没人知道真正的底层代码早被一个外包临时工偷走了。”

王姐在旁边抱臂站着，一直没有插话。听到这里时，她才开口补了一句：“那份代码，现在在你摸鱼系统里。你兑换的‘反卷护盾’和‘AI漏洞识别’，都是从那套底层代码里衍生的功能。”

林一凡的感觉就像有人撬开他的颅骨往里倒了一桶冷水。他张了张嘴，又闭上。摸鱼系统……他重生后绑定系统时，系统自称“劳动神与资本神的赌局”，但从头到尾都是个黑箱。现在结合赵恒的话——系统的核心功能底层，竟然来自星辰科技的AI考核系统？那系统是什么？是某个人用“织网”代码做的外挂？

“赵小九……”他哑着嗓子问，“她为什么要替我死？”

赵恒沉默了很久。走廊里管道的水声突然变大了，像是有什么东西堵住了下半截出口，发出呜呜的共鸣。

“因为她拿了我妹妹的命，不是因为什么伟大的爱。”赵恒笑了一下，但笑容里没有温度，“她是个职业的。2026年的你——或者说来自未来的你——花了一笔钱雇她，让你死的时候有一个人替你去死。”

“未来……的我？”

“你不是2026年猝死重生的。”赵恒盯着他的眼睛，“你是从更远的未来回来的，带着‘织网’的完整架构。你把它带回来安装进自己的身体里，让系统在2019年绑定，然后删掉了自己所有关于未来的记忆。赵小九替你死的那一次，就是为了‘你’这个本体，能顺利完成第一次绑定——绑定时系统的宿主必须是‘已死之人’。”

林一凡的脑子嗡的一声。

系统绑定需要宿主是死人。他为了绑定系统，雇了一条命。而那条命，就是赵小九。他低头看着口袋里的010号钥匙，忽然明白了钥匙上那句“命运归还”的含义。

“所以，”他抬起头，声音出乎意料地平静，“‘命运归还’的任务，其实是让我把这条命还回去？”

赵恒没说话，只是静静地看着他。

林一凡把U盘攥进掌心，金属外壳的寒意刺得他发疼。他回头看了一眼那扇铁门，门内是2019年12月31日的麻辣烫面馆，陈重阳告诉他“代价是永远失去见到他”。门外是2026年的真相，他抬手撬开了自己亲手封存的过去。

走廊尽头传来电梯的提示音，有人来了。王姐猛地转头，面色一变：“钱总的人到了。快走。”

林一凡没有犹豫，拔腿向楼梯通道冲去。擦身而过的瞬间，赵恒在他耳边低声说了一句：“别忘了，你欠我妹妹一条命。而这条命——现在该还了。”

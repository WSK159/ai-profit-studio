# 第343章 两个哥

密道里的空气像是凝住了。

林一凡攥着那张泛黄的纸片，指尖微微发白，纸上那四个字“别信亲哥”在昏黄的手电光下透着一种说不出的阴冷。

他哥只有一个——沈望。同父同母的亲哥，从小一起长大，虽然父亲死后两人各奔东西，关系淡了，但沈望从来没做过一件对不住他的事。

沈望失联，是在他重生之后没多久。他一直在找。

可父亲留下的这句话——别信亲哥——像是在他脑子里扎了一根刺。

赵日天凑过来瞥了一眼纸片，眉毛挑得老高：“你有个亲哥？没听你说过。”

“已经失联了。”林一凡把纸片折起来，和照片、铜片一并贴身收好，声音平平的，“一直联系不上。”

“失联了，还是你联系不上了？”赵日天的语气难得正经，“这两个概念不一样。”

林一凡没接这句话。他弯腰把暗格合上，手掌在铁板表面一拂，忽然停住了——铁板的内侧，触感不对，有一层极薄的凸起，像是贴在外层铁板内壁上的什么东西。他重新撬开，伸手进去一摸，摸出一片透明塑料膜，贴着铁板内侧，几乎看不出存在。

塑料膜里夹着一张纸条，字迹比刚才那张新些，写的是：“她说：密码是‘一九九六零八二七’。”

林一凡猛然想起父亲笔记本封底夹着的那张纸上，写的正是“27-08-1996”——英式写法，日期在前，月份在后。八月二十七日，一九九六年。

那正是照片背面那行字里写的“八月廿七”。

但纸条上这个“她”，是谁？

他说：“她说：密码是一九九六零八二七。”——这是转述。写这张纸条的人，不是父亲，就是另一个人。

林一凡把这张纸条翻来覆去看了两遍，发现在纸条底部，有一行极淡的铅笔字，比上面的内容淡得多，像是后来补上去的：“不是她，是我。”

这行字和上面的字迹一模一样，都是同一个人的笔迹。写纸条的人自己划掉了“她”，改成“我”——意思可能是，“她说”是他记错了，是他自己的密码。

但更细思恐极的是另一个可能：这行字是另一个人后来补写的，模仿了他的笔迹。

“你们在这儿等我。”林一凡忽然说，他把纸条塞回塑料膜里，倒贴回暗格内壁，站起身，快步走回档案室，手指在父亲笔记本的封底来回摩挲。他猛地把封底拆开——里面还夹着一张纸，极薄极薄，贴在封底内层，肉眼几乎看不出来。

他抽出来，上面只有一行字，是父亲的笔迹：

“如果你找到了我放在暗格里的话——那个‘她’，是你母亲。”

林一凡的手悬在半空中，整个人像是被钉在原地。

他母亲在他十二岁时去世，癌症。他记得母亲躺在病床上的样子，记得她消瘦的手腕，记得她攥着他的手说“好好长大”。他从来没有怀疑过母亲的身份。

但父亲这里的“她”，如果指的是他母亲，那他母亲留下的密码，是一串日期？

他重活过一次，经历过命运翻转、系统、隐藏任务、灰袍人、卷王系统——但这一刻，他第一次觉得，自己对父母的认识，薄得像纸。

他缓缓把那张纸收好，回到密道里，赵日天和孙满仓正各自沉默地靠在墙边。看见他的脸色，两人都没说话。

林一凡站定了，目光扫过密道尽头的黑暗：“这地方，我想继续往里走。”

孙满仓看了他一眼：“刚才那扇白色金属门，你还没打开过。”

林一凡点头：“是。但我现在知道了，那扇门需要密码。而我恰好拿到了一个——一九九六零八二七。”他用这个密码去试那扇门的电子锁。

孙满仓和赵日天跟在他身后，三人重新走回白色金属门前。电子锁是一块巴掌大小的银色面板，上面只有数字键和一个小屏幕。林一凡手指悬在按键上方，停了一秒，然后按下：1-9-9-6-0-8-2-7。

屏幕闪了一下，从灰暗变成绿色，发出一声清脆的“嘀”。门扇无声滑开，露出里面一间约莫十平米的小室，四面墙壁上钉满了老式货架，架子上堆满文件盒，灰尘落了几指厚。

房间正中摆着一张木桌——桌上放着一台老式录音机，磁带还在里面。旁边压着一个牛皮纸信封，信封上用圆珠笔写着几个大字：“给林一凡。”

林一凡走过去，撕开封口，抽出一张叠得整整齐齐的格子纸。展开，上面是他父亲的笔迹，字有些抖，写得急：

“小凡：如果你看到这封信，说明你已经找到了暗格和密码。沈零被带走以后，我花了很多年才查到一个关键事实——她不是被‘抢’走的。是她自己跟灰袍人走的。”

林一凡怔住。

“……她从小就能看到一些别人看不到的东西。她被带走之前，跟我说了九个字：‘门不开，是钥匙自己选的。’——我一直没弄明白这句话的意思。后来我遇到你妈，她为了帮我查这件事，进了那家不该进的公司，用了一辈子去查，查到的东西永远差一步。最后她查出密码是八月廿七，但她走的时候跟我说——”到这里，字迹突然划掉了几笔，涂得黑乎乎一片，像是他写到一半停住了，隔了很久，又在下方重写：“她说：‘告诉他，九把钥匙凑齐的那天，门就开了。门开了之后，第一个进去的人，会拿到自由。但第二个进去的人，会拿到锁。’——小凡，你一定要记住：如果有一天门开了，让我进去。你在外面等。”

林一凡握着信纸的手指攥紧了，攥得骨节发白。

“你父亲的意思，”赵日天难得没有抖机灵，声音低了下去，“门开了有代价，他要把这个代价拦在自己身上。”

他逐字逐句地看过父亲最后那行字，发现信纸的最底端，用更小的字补了一行：

“你母亲走了以后，我发现她当年也留了一个东西给我。你外公家那边的老宅基地底下，埋了一个铁盒子。盒子只有你能打开——因为锁芯是用你拇指的指纹做的。我等你长大，等了很多年，但还是没等到。你拿到这封信的时候，应该已经够大了——去吧。”

林一凡把那封信收进贴身口袋里，像收起了整个少年时代所有关于父母的碎片。

他抬起头，走向那台老式录音机，按下播放键——磁带转了几圈，传出极轻的沙沙声，然后是他母亲的声音，温柔、干燥，带着一点午后的暖意：“小凡，妈妈和爸爸都对不起你。我们把门看得太死，把你也累着了。这件事你不用查了。门不开也是一种自由。你现在过得很好——那就够了。真的够了。”

录音机在最后一句落下后，自动弹起。磁带还在转。完了？他低头看了一眼屏幕，磁带转完自动弹出——但他注意到，磁带反面还有一面。

他把磁带翻了一个面，重新按下播放键——这一次，里面传出一个他从未听过的男声，低沉，沙哑，像嗓子被烧过：“林一凡，你能听到这段录音，说明你比你父亲聪明三分。我告诉你一句话，记住，我不说第二遍：九枚徽章在九个地方，三十七号在第七枚的核心里。你父亲留下的所有线索，指向的不是‘门’，是‘三十七号’。找到三十七号，你就知道沈零在哪里了。”

录音结束了。密道里安静得能听见灰尘落地的声音。林一凡抬头看了赵日天一眼，发现赵日天也正看着他。“三十七号”这个说法，赵日天显然也是头一回听见。

孙满仓的声音从身后响起，很慢，像是斟酌了很久：“三十五年前，有一个项目代号，就叫‘三十七号’。”他停顿了一下，“星辰科技的子公司，当年做人工智能初代核心算法的研发计划。”

林一凡的心猛地一沉。

星辰科技。

他重生入职的第一家公司。他把“星辰科技”四个字在舌尖上滚了一圈，忽然，那种从重生第一天起就隐隐环绕着他的感觉又浮上来了：他以为自己是偶然落在星辰科技的。但眼下看，那条把他引向这里的线，比他想象的粗得多。

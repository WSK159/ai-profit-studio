# 第414章 青铜钉

林一凡握住第三根青铜钉时，指尖传来一阵灼热——不是纹章的烫，而是骨灰般的余温，仿佛这根钉子刚从火堆里抽出来。钉帽上的陶土珠还在缓慢转动，从“27”翻到“26”，然后停在一面空白上，纹丝不动了。

他抬头看向前方的黑影。那影子没有轮廓，像一团被拉长的墨渍贴在通道壁面上，随着他走近，黑影缓缓退后三步，始终保持着一丈距离。

“你有话要说。”林一凡没有追，反而蹲了下来，把青铜钉举到眼前细看。钉身布满细密的裂纹，裂纹里填着灰白色的粉末，像骨灰拌了糯米浆灌进去的。他捏了捏，“这是死人骨头烧的？”

黑影没有回答，只是伸出一根手指——准确地说是黑影的“指尖”——指向林一凡左侧的墙面。那一块墙面上刻着密密麻麻的“26”，深浅不一，最新的几道划痕边缘还沾着血。

林一凡走过去，伸手摸了一下划痕内侧，指腹沾到一缕卷曲的黑发。他把头发放在掌心细看，那发丝在指尖自动弯曲，绕成一个圈，像锁芯里女人的手指纹路。

“她和那根锁芯是什么关系？”林一凡问。

黑影的指尖偏移，指向他手中的灰烬骨钉。那意思再明显不过了——这根钉子的陶土珠上，有同样的发丝缠绕。林一凡眯起眼睛，果然在珠子的空白面边缘，发现一根几近透明的细发，比蛛丝还细。

“是她的头发。”林一凡低声说，“这第三根钉子，是她留下的？”

黑影终于开口了。声音像砂纸打磨铁皮：“是她……亲手烧的。”

“烧了什么？”

“她自己的骨。”

通道里安静了三秒。那股湿重的呼吸声又在门缝深处响起，比之前更近，就像有什么庞大东西正贴着另一侧的墙面慢慢爬过。林一凡稳住心神，把灰烬骨钉插进腰间皮带扣里，站直身体。

“那她人呢？”

黑影的轮廓抖了一下，指向通道更深处。那里没有灯光，黑得只能看见一片吞噬性的暗。林一凡摸了一下口袋里的陶土珠——老王的命牌——珠子表面微微发热，像是在回应什么。

“你是说她在里面？”

黑影没有否认。它开始慢慢后退，形状逐渐拉长，像一张被撕开的纸。林一凡快步跟上，脚下踩到一处松动的地砖。他低头，发现那块砖上没有“26”的划痕，而是一个浅浅的圆印——和陶土珠的尺寸不差分毫。

他蹲下，把老王的命牌放进圆印里。严丝合缝。

下一秒，整面墙发出沉闷的齿轮声，一道新的门缝从墙壁中央裂开，露出里面一盏昏黄的灯。灯下是一根长长的走廊，走廊尽头坐着一个人——一个佝偻的背影，穿着沈望未白那件灰褐色的旧外套，正在用镊子小心翼翼地从一枚珠子上剥一根发丝。

林一凡的呼吸停了一拍。

那背影缓缓回过头来。不是沈望未白，而是老杨头大哥的脸。只是此刻他脸上布满烧灼的疤痕，左眼瞳孔中央嵌着一枚极小的陶土珠，珠子上刻着的数字正从“27”缓缓往下翻。

老杨头大哥张了张嘴，声音像从地底传上来的：

“你来得正好……第九根钉子，已经不够了。”

他举起镊子，从那枚珠子上勾出一根卷曲的发丝：“门缝里还有一颗珠。第二十六颗。它在我眼睛里。”

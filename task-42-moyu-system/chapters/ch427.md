# 第427章 坛中人

林一凡死死盯着坛口那只手，直到它完全探出。红绳在手腕上松垮地悬着，绳结处已经磨得发白。干涸的暗红色从指缝渗到手掌，像是一层洗不掉的锈。

坛口裂得越来越大，那只手的主人并没有立刻出来。坛身晃了晃，发出一声沉闷的声响——里面像是只有半截空壳。

“别动。”门内的声音响起来，这回带着一丝急促，“他没有恶意。他只想看看你。”

林一凡没有动。但他的目光慢慢从手移到坛身后方。

矮几上的粗瓷碗边缘，那道暗褐色的痕迹他先前以为是残留的液体，此刻借光线偏转的角度，他看清那是一行刻字——极浅，用指甲或石子刻的，内容被碗沿的光影遮住了一半。他移了半步，终于看清完整的字迹：

**“三月十七，第三次。他进来了。”**

第三次。母亲第三次关人时，刻下的。

“看完了？”门内人的声音平静下来，“看完了就该做决定了。”

林一凡缓缓弯下腰，从地上捡起那张纸条，将湿冷的纸面展平，另一只手仍攥着27号徽章。他心中飞快地转过一个念头：纸条上写“帮他续命”，可母亲刻的字却说“他进来了”——如果门外那个“老杨头大哥”是母亲第三次关进去的人，那现在坛里的这个，又是谁？

“别想太多。”坛口那只手忽然收了一下，指尖朝上，像是在比划什么。林一凡顺着它指的方向看去——石室顶部的暗角里，悬着一根铜丝环，环上系着一颗干枯的、风化的灰色小球。它比一般的陶土珠小一圈，表面布满细密的裂纹，像随时会碎。

那根铜丝环的末端，垂在半空，晃动得极慢。而它正下方的地面，有一个浅浅的圆坑——深度与27号徽章的大小完全吻合。

林一凡瞳孔一缩。

“你母亲把那枚徽章放进来时，它也放在这里。”坛中的声音响了，沙哑、含混，像含着一口砂子，“门外那枚是锁，门内这枚是钥。锁和钥本是一对。你拿着门外那枚，走到门内来，那锁就当着你面断了。”

坛口那只手缓缓回缩，坛身轻轻震了一下，像是一口气吐尽了。随即那只手垂落下去，再不动弹。

“他走了。”门内的声音带上一种说不清道不明的怅然。

林一凡站在原地，没有出声。他低头看手中的27号徽章，再抬头看顶部的铜丝环——环上空空荡荡，只有那颗灰色小球悬挂。但它的颜色，和坛中那只手皮肤的颜色，一模一样。

他忽然意识到什么，猛地转头望向身后的台阶。十三级台阶尽头的铜门缝里，那双灰白色的陶土珠眼睛还在——但比方才更远了，像是退后了一步。然后那双眼睛缓缓向侧边移动，消失在门缝的阴影里。

“门外那个，也是你。”林一凡没有回头去看门内的人，目光仍锁定门缝，“你两个……都是三十年前被关进来的。”

坛中那只手彻底垂落，无声无息。门内人没有回答。

石室角落忽然传来一声轻响。林一凡循声望去——矮几下方，石板的缝隙被人用指甲抠开过，里面露出一角泛黄的纸。他蹲下身，小心翼翼地抽出来。

纸上是一副粗糙的图：一个人跪在地上，一只手伸向地面上的锁孔，另一只手指着自己的胸口。图的旁边写着一行字，笔迹歪斜，像是用左手写的：

**“钥匙不在锁孔里。钥匙在我心里。”**

林一凡的手指微微发抖。他抬头看向门内的阴影，那道人影已经完全退入黑暗中。而台阶尽头的铜门缝里，那双灰白色的眼睛，重新出现了——这一次，它正盯着他手中的纸条。

“别让他看到。”门内人的声音忽然响起来，带着一种从未有过的急促和焦灼，“把那页纸烧了。快！”

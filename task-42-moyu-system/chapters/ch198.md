# 第198章 反卷护盾·高阶版

凌晨两点，林一凡从地下机房钻出来时，手机屏幕亮起一条消息：**系统面板恢复，咸鱼值+240，已扣除反卷护盾高阶版使用费用3000，剩余：-2760。** 他还没来得及愤怒，第二条消息弹了出来：**特殊任务「关键抉择」触发：在审计日当天，你的每一个签到、每一份产出、每一次休息都将被记录。劳动纯度低于40%将被直接判定为不合格。系统提示：你可以选择当前唯一可用的兑换项——反卷护盾·高阶版，消耗全部剩余咸鱼值（-2760）将临时透支至上限。是否确认？**

林一凡盯着屏幕上那个“−2760”，眼睛红了。他啐了口唾沫砸在地砖上：“反卷护盾高阶版，确认。”

确认键按下的瞬间，他的胸口涌过一阵暖流，仿佛有人往血管里注入了一股滚烫的熔岩，但那温度很快冷了。系统面板弹出一个新的进度条：

**反卷护盾·高阶版装载完成。**
**能力1：劳动纯度视觉化——你能看到每个人头上的劳动纯度数字。**
**能力2：纯度豁免——每日可以指定1次，将某一操作的劳动纯度判定改为“休闲贡献”。**
**能力3：代价锁——护盾生效期间，每清除一次不合格判定，系统将从你的寿命中扣除24小时。**

“寿命……”林一凡低声重复了一遍。他抬头看了眼大楼顶部“星辰科技”四个霓虹字，心头一紧——这一次，摸鱼玩的不是绩效，是命。

第二天上午九点，审计组准时进场。钱总站在接待区，挺着啤酒肚，满脸堆笑地迎接那群穿深灰色制服的人。为首的是一个戴金丝眼镜的中年女性，她胸前挂着一块银色铭牌，上面写着“劳动纯度检测部·李主任”。

林一凡混在人群中，刻意让了一眼她的头顶——一个鲜红色的数字悬在她头上：**97%**。

纯度高得离谱。

他下意识又扫了一圈。老王的头上是68%，几个同事都在50%上下浮动，而赵日天——他看过去时，赵日天也正直直地看着他。

赵日天头上的数字：**41%**。

林一凡瞳孔微缩。赵日天也看见了林一凡的表情，嘴角动了动，快步擦肩而过时留下一句话：“我特意把纯度压在及格线下，看你能不能把我也保下来。”

说完不等林一凡回应，他已经走远了。

审计开始。前两小时风平浪静，可当李主任拿着平板走进林一凡所在的工区时，空气像被拧紧了发条。她停在一台电脑前，用金属笔点了点屏幕：“这台机器前八分钟劳动纯度为27%，请相关负责人解释。”

林一凡看到那台机器亮起红灯，坐在这台电脑前的是刚入职两周的实习生小王——一个新来的小姑娘，手都开始发抖。

林一凡闭了闭眼。系统，用一次“休闲贡献”。

【确认。今日剩余：0次。寿命扣除：24小时。】

小王那台电脑上的数字跳动了一下，从27%跳到63%。李主任挑了挑眉，没再追问，转头走向下一个工位。

林一凡松了口气，一屁股坐回椅子上。他的后脑勺一阵刺痛，像是有什么东西从身体里被抽走了。他按了按太阳穴，余光突然瞥见李主任走向的方向——是组长老王的位置。

老王头上一排数字此时正在急剧下坠：68%、61%、55%、49%……像是有一只无形的手在往下拽。

林一凡的心一沉。今天是反卷护盾的试炼日，而试炼的第一关，就是他在这个世界见过最老实的人。

他站起来，步履沉稳地朝老王走去。

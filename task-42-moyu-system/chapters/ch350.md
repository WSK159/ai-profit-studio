# 第350章 五把锁，一扇门

铁铺里的空气凝滞得像一块锈铁。佝偻老头把那三把三棱钥匙摆上柜台时，指尖在木质台面上磕出三声脆响，每一声都像在给什么古老的仪式敲钟。

林一凡盯着画中那扇五锁孔的门，喉结动了动：“五把锁孔，三把钥匙。剩下两把呢？”

老头没答话，转身从柜台底下的铁皮罐里，摸出一根旱烟杆，慢吞吞地点上。烟雾绕过他皱纹纵横的脸，他眯缝着眼睛，像是在打量林一凡，又像是透过他在看另一个人。

“老沈当年走的时候，画的这画。”老头用烟杆指了指墙壁，“他说，这世上没有打不开的锁，只有不想开门的人。”

赵日天抱起胳膊：“照你这么说，五把锁孔的门，得五把钥匙。我们手上只有一把孙师父的、你这里三把，拢共四把。还差一把。”

“差的那把，你得问它愿不愿意出来。”老头瞥向柜台角落的一个黒漆木盒。林一凡到这时才注意到，那盒子被人塞在钉锤和铁锯之间，若非刻意寻找，几乎不会多看一眼。

“这盒子是谁放的？”孙满仓开口，声音压低。从这个叫沈记铁铺的地方出现以来，他一直是三人里话最少、最警觉的那个。老头抽了口旱烟，说：“三年前，老沈自己放的。钥匙只有一把，他说，等有人带着他的钥匙来开门，就交出来。”

林一凡伸手去碰那黑漆木盒——指腹接触的瞬间，一阵冰凉顺着指尖蹿上脊椎。盒子没有锁扣，只有一个外凸的凹槽，形状恰好与五棱钥匙的横截面相符。

赵日天瞳孔微缩：“那他把五棱钥匙留在了我们手里。那现在开这门，就差……”

“第七枚核心里，不是答案。”林一凡低声重复程哥转述的那句话，“答案在门后面。而门……就在这里。”

老头听了这话，嘴角挑了挑，脸上皱纹舒展开一道很浅的弧度：“你知道那扇门在哪？”

“画上的石台、五锁孔、三棱锁开门，四棱锁开箱，五棱锁开墓。”林一凡抬头，“那扇门在墓里。”

铁铺里静了整整三秒，连外面的风都停了。赵日天脸上的玩笑劲儿收得干干净净，孙满仓的手指不自觉地抠住柜台边缘。老头缓缓弯腰，从柜台底下的暗格里拖出一块石板，石板背面刻着一行字——沈临渊的手笔：墓中门，门中锁，锁中见天地。

林一凡刚要开口，门外忽然传来一声不耐的车喇叭。紧接着，一个穿皮夹克的人推门进来，三十出头，眉骨有一道旧疤。他没看任何人，径直从衣兜里掏出一只铁皮盒子，搁在柜台上，然后对老头说：“老沈让我带来的，他说——是时候了。”

铁皮盒的盖子上，铆着一个林一凡熟悉的符号：与黄铜钥匙柄上那枚“去”字微痕一模一样的刻痕。

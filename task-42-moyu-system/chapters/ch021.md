# 第21章 破格晋升

审计组撤离的第二天，林一凡的工位被搬进了独立办公室。说是办公室，其实是用玻璃隔出来的一个小间，挨着老王原来的位置——老王已经被调去事业部带新项目，走之前拍着他肩膀说了句“你小子，行”。

林一凡盯着桌上新配的笔记本电脑和一张写着“效率小组组长”的铭牌，还没回过神来，群通知就弹了出来。

【星辰科技·全员公告】经集团审计组核实与高层决议，即日起组建“效率小组”，由林一凡担任组长，直接向钱总汇报，组成人员名单见附件。小组实行“45+15循环制”，试用期一个月。

“卧槽。”林一凡喃喃了一句。

他打开附件名单，六个人，全是组里平时最会摸鱼的。张伟、李静、王胖子、陈晨、刘洋，还有……他自己。不对，名单最后一个人旁边打了个括号。

“（该员工已申请调离，待补位）”

那括号里写的是赵日天的名字。

林一凡眯了眯眼。赵日天跑了，向深海资本传数据的事还没查清楚，审计组走了，公司发了公告——这他妈是默认了赵日天离职的意思？也太快了。他正想着，口袋里的手机震了。

【摸鱼系统·提示】支线任务【晋升】完成，奖励：咸鱼值+500，解锁【效率之眼·进阶版】。新增主线任务【小组养成】：带领效率小组连续30天产出不低于全组平均值的150%，任务期间小组内任何成员被记违规，任务失败。

林一凡抬头，隔着玻璃，他看见外面几双眼睛正看向这边。张伟在敲代码，但手速明显快了；李静低头翻文件，嘴角却勾着。他站起身，推开玻璃门。

“都过来，开个小会。”

六个人挤在他那个小办公室里，椅子不够，王胖子直接坐在窗台上。

“咱们这小组，名字叫‘效率小组’。”林一凡说，“但我先声明，效率不等于拼命。你们之前被说成摸鱼，是因为用错了方法——都在明面上摸，不用工具、不问时机，纯靠脸皮厚。”

张伟忍不住笑了：“那组长，你教我们用工具？”

林一凡点开自己的屏幕，投到墙上：“第一课，为什么要45分钟工作、15分钟休息？因为人的注意力极限是45分钟，超过以后，产出断崖式下跌。你那第46分钟敲的代码，错率比前30分钟高出三倍。公司看的是你敲了多少行，我让你们看的是——你敲对了多少行。”

他打开后台数据面板，上面实时显示着效率小组的代码产出。今天上午，六个人加起来的产出，已经比昨天全组总数还高了。

谁也不敢再说话了。

下班前，钱总给林一凡发了条消息：明早八点，来我办公室。

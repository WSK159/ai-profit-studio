# 第84章 江雪的完整棋局

黑色商务车驶出旧货市场时，后视镜里已经能看到三辆黑色轿车从主路拐进来，车灯刺目地扫向C区方向。周莉踩油门加速，变道上了辅路，驶向城北快速干道的方向，始终没开口。

林一凡坐在后排，把芯片放在掌心，低头看着。小小的金属片躺在掌纹间，外观和普通U盘差不多，但边缘有激光蚀刻的水波纹路——与江雪留给他的第一段密钥的纹路完全对应。两段合一，才能组成完整密钥接入旧硬盘——那里面究竟存了什么，他到现在依然只能靠猜。

“你姐说江雪托付她收局。”林一凡抬起头，看着驾驶座上女人的侧影，“但你们姐弟俩对这台词排练了几遍？我刚才就在想，仓库里绑周天的那段戏太完整了，完整得像安排好的一样。”

周莉从中央后视镜里回了他一眼，嘴角微微一挑，没否认。

副驾驶上的周天咳了两声，虚弱地开口：“本来没安排我受伤……但何顾问那条疯狗突然改了规矩，收了我两刀，我认了。”

“行了。”周莉的语气不重，却带着不容置喙的力度，“先别说话，你肋骨的事回头处理。”

车下了快速路，拐进一片老工业区的废弃厂房群。周莉把车停在最里头一栋灰色厂房的阴影里，熄了火。四周安静得只剩空调滴水的声音。

她转过身来，摘掉墨镜。这让林一凡第一次真正看清她的脸——她和周天的眉眼有七分相似，但轮廓更深，那双眼睛像淬过冰的刀锋，冷静，却隐隐带着疲惫。

“江雪让你拿到的第一段密钥，在我这里放着的，是第二段。这两段合并以后，能打开她预埋在服务器集群里的一个加密分区。”周莉从文件袋里拿出一张纸，上面画着一棵树的简笔画，树根深不见底，树冠却只有一片叶子，“她说，如果你问到‘为什么是我’，就给你看这张图。”

林一凡接过来，看着那棵怪树，沉默了几秒。前世的记忆碎片在这个瞬间被猛地击中——他在“星辰科技”的第三年，曾加过一个月大夜班，为一个代号“根目录”的项目做底层架构。当时项目组所有人签了保密协议，他自己也以为那只是一个普通的数据整合方案。可现在，江雪临死前的最后一通电话——他记得她说了半句话，被信号截断：“林一凡，根目录里有一——”

“江雪当初发现，‘星辰科技’的AI考核系统底层，埋的不是优化算法，而是一套收集员工情绪状态、行为模式、生理数据的精神分析模型。”周莉的声音放低，“而且这套模型的训练数据来源，指向一家叫‘云麓’的心理咨询公司——钱总的妹妹钱雨注册的壳公司。”

林一凡后背慢慢沁出冷汗：“AI考核系统……在用员工的加班数据训练什么东西？”

“训练的不是数据。”周莉摇头，“是‘顺从’。模型的目的，是预测哪些员工会在什么节点崩溃、辞职、起诉、举报，然后提前用绩效评级调岗、孤立、劝退的方式把人‘处理’掉。”

车里的空气凝固了好几秒。连周天都撑着坐直了身体，面目凝重地望着他姐。

“江雪发现了这条链路，准备把证据链整理完整归档，但她低估了对方行动的速度。”周莉顿了顿，“她出车祸的那天早上，给我打了个电话，只说了三句话：‘芯片给林一凡，盒子给周天，叶子给你。’”

“叶子？”林一凡低头看了看那张画着树的纸。

“她说等见到你，在你的手机上下载一个App叫‘咸鱼图鉴’，用拍照模式扫叶子的边缘，就能解锁第二段密钥的完整加载方式。”

林一凡没动。他的手指无意识地捻着芯片表面的纹路，脑海里忽然闪过一道亮光：“等等——你刚才说‘根目录’——江雪当年参与的那个项目，我在前世也参与了。而且，项目结构里有个叫‘容器’的模块，我离职前的最后一次提交理过那个目录——”

他把芯片举起来，对着车窗外的暗光看向边缘那道水波纹：“如果我没记错……第一段密钥和第二段密钥拼接后锁定的加密分区，它的容量大小本来应该匹配‘容器’模块的分布式存储节点。这不是简单的数据档案——这里面是一个可以直接接入‘星辰科技’考核系统主机的后门。”

周莉终于真正地笑了，是那种意外于押对宝的满意：“江雪说你能想到这一层。她留了三条线：一条通过我，一条通过周天，一条通过那棵树的叶子——她说三线汇合的时候就是她棋局完全展开的时刻。”

她的手上突然多了一枚闪着蓝光的金属片——与林一凡手里那枚一模一样的芯片，只是边沿的纹路方向正好互为镜像。

“第三段，其实一直在我这里。江雪让我在你确认接盘之后才拿出来。”

林一凡深吸一口气。他低头看着掌中那枚芯片，耳边忽然响起系统低沉的提示音：

【叮——检测到“系统真相”前置密钥碎片（3/3），是否启动“根目录访问协议”？——注意：该操作将在24小时内触发宿主所在公司核心监测节点的主动反制，请确认是否继续。】

系统的声音顿了顿，仿佛有某种难以言喻的情绪渗透进了机械的合成音里：

【本次解锁之后，摸鱼系统的隐藏规则将被部分揭晓。在此之前，宿主有30秒时间决定是否开启全部真相。】

林一凡看着周莉那双冷静如水的眼睛，又看了眼几乎半瘫在座椅上的周天——这个原本的宿敌，此刻脸上却带着一种复杂的、近乎释然的表情。

他闭上眼，又睁开。

“启动。”

# 第299章 旧医院的第三层

车头拐进南华路时，路灯刚好熄灭了一排。林一凡从副驾上直起身，看见远处那栋灰白色的旧楼像一块被人遗忘的墓碑，嵌在工地围挡和疯长的野草之间。旧第二医院分院的招牌歪了半边，“院”字缺了最后一撇，露出锈蚀的铁筋。

赵强把车停在围挡缺口处，熄了火。夜风穿过碎玻璃窗，发出细长的哨音。

“你确定是这里？”赵强压低声音问。

林一凡没有回答。他推开车门，踩碎满地枯叶，走向那栋楼。口袋里的三叉钥匙贴着他的腿骨，像是被什么东西召唤似的，微微发烫。

一楼的窗户全用木板封死，唯独侧门虚掩着，锁舌被什么东西从里面撬开，留下新鲜划痕。林一凡侧身进去，走廊里弥漫着消毒水和霉味混合的气息。地面上的灰尘有明显的脚印，两排，一深一浅。浅的那排脚印在楼梯口转向楼上，深的那排则径直通向走廊尽头的储藏室。

赵强跟在后面，手电光扫过墙上的旧海报，褪色的“预防肺结核”宣传画上被人用马克笔画了个圈，圈内是一串数字：2019.06.16。

林一凡盯着那串数字，后颈的汗毛全竖了起来。那是父亲被植入的日子。

他没停，继续向储藏室走。门开着，里面堆着旧病床和药品柜。他走近一个铁皮柜，柜门上有道一厘米宽的缝隙，里面散出温热的气息。赵强把手电照过去，那气息在光柱中凝成一小团白雾。

“活物？”赵强后退半步。

林一凡蹲下来，从铁皮柜的缝隙里看见一双眼睛。很小，亮得异常，像两颗正在燃烧的炭。那东西发出细碎的啮咬声，旋即钻进柜体深处。

“别动它。”赵强按住他的肩膀，“先看这个。”

他指着储藏室角落，一块被挪开的旧地毯下面，露出一扇暗门，门板上焊着三个数字：003。

林一凡掏出三叉钥匙，中叉对准锁孔，旋转半圈——不是严丝合缝，但弹簧咔嗒一声松开了。暗门往下，是一段螺旋楼梯，墙壁上嵌着老式白炽灯，居然亮着。灯丝发红，像垂死者的血管。

他们走到底，楼梯尽头是一间档案室。铁架上排列着几十个牛皮纸袋，按编号排列。林一凡找到标着“000”的那个，袋子比其他的厚一倍，封口处贴着一张手写标签：“不归档。不销毁。不查看。”

他打开袋子，里面是一本手术记录册，扉页写着一行字：“第000号植入体——宿主：空白。用途：测试。结果：失败。”

翻到最后一页，有人用铅笔在边角画了一把三叉钥匙的草图，钥匙柄处刻着一个日期：2020.2.29。

“四年一次的闰年。”赵强说，“这一天不存在。”

林一凡把草图折起来放进口袋。他正要合上记录册，发现封底内侧贴着一张照片——一个穿病号服的中年男人坐在轮椅上，背景正是这间档案室。男人的脸被折了一道痕，看不见五官，但他手腕上戴着一条红绳，绳结的样式和林一凡母亲首饰盒里那条一模一样。

他的手机突然震动。屏幕亮起，跳出一条陌生号码的短信：“你已经到了003室。很好。钥匙一共有四把，你手里的只是三分之一。往下走，别回头。”

短信没有署名，但末尾跟着一个符号——一条微微弯曲的波浪线，像一条被剖开的鱼。

“往下走？”赵强读完短信，盯着楼梯尽头那堵水泥墙。

林一凡走过去，手掌按在墙面上。砖缝间有细微的松动，他用力一推，整面墙竟然向内旋转了九十度，露出一道更窄的通道。通道尽头有微光，忽明忽暗，像某个人正在发出摩尔斯电码。

林一凡数着那光点的节拍，翻译出来的三个字，让他停在了原地。

“它在等。”

“谁？”赵强问。

林一凡没有立刻回答。因为他看见通道尽头的墙壁上，贴着一张泛黄的纸，纸上只有几个字，字迹是母亲的：“如果看到了这里，说明你已经比我们走得更远了。别相信001说的话。它出生之前，002已经死了。”

他盯着“002已经死了”那行字，口袋里的三叉钥匙突然变得更烫，烫得他几乎握不住。

那串摩尔斯电码依然在通道尽头闪烁着，一遍，又一遍。

而在他的正上方，楼层深处，传来一声沉闷的震动——像是有什么东西，刚从睡眠中被唤醒。

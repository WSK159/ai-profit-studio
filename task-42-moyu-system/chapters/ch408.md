# 第408章 门缝里的名字

林一凡蹲在铜门前，呼吸急促，伸手摸上那道门缝。

指腹刚触到缝隙边缘，一股刮骨般的寒意便顺着指尖蹿上手臂，激得他打了个哆嗦。更要命的是，那感觉不对劲——门缝太宽了，宽得不像是给人通行用的，更像是……什么东西曾经从里面往外挤过，把门缝都撑变了形。

沈望未白跪在旁边，脸色白得像纸，肩头的血已经洇透了半边衣服，却仍死死盯着林一凡的动作：“你……信我，门里面那个人真的和老杨头长一模一样。他说，图纸27是换命的位置，最后一根青铜钉……”

“我知道，你已经说过了。”林一凡目光落在门缝里。

门缝深处卡着一枚青铜钉。

和铁皮壳子锁眼里那枚青铜钉一模一样——同样的锈色，同样的纹路，甚至同样缺了一个口子，像是在某个不该存在的时刻被人用蛮力撬下来过。林一凡脑中轰然一响。两枚铜钉，两把锁眼，一个在铁皮壳子上，一个在铜门里。它们是一对。或者说，它们本来就来自于同一件东西。

“你刚才说，”林一凡转头看向沈望未白，“门后那块铜板是什么样子？”

沈望未白怔了怔：“……一块很旧的铜板，上面画着一头……像鱼又像龙的东西，旁边站着一个巨大的影子。我还没来得及看清就被推出来了，推我的人就是老杨头，他……”顿了顿，“他说‘替我跟他说，门在门后，钉在钉里。’”

“就这句？”

“就这句。”

林一凡肩膀一抖，胸口白骨纹章忽然烫起来，烫得几乎要烧穿皮肤。他低头扯开衣领，白骨纹章上的数字已经停在了27上，像一只凝固的眼睛，正在一下下跳动。他想起上一世的代码注释——一模一样的八个字，写在“摸鱼系统”的核心模块里，作者栏写着自己的名字。那八个字他之前不明白，现在也不明白。但结合沈望未白转述的话，他隐约摸到了一点形状。

“老杨头”说的《门在门后，钉在钉里》，是在指引他：门不是真正的入口，钉也不是普通的钉。

他重新看向铜门。

门缝里那枚青铜钉卡得极深，几乎嵌进了铜门的材质中，像是被某种力量强行压入的。林一凡伸手去拔，纹丝不动。他改戳镜框——他刚才注意到，铜门门缝的宽度并不均匀，左下角偏宽，而偏宽的地方正好能看到门缝内部的颜色，和外面不一样。那里面是暗红色的，像锈，又像血。就在他注视那个位置时，门缝内里忽然有什么东西一闪而过。

一个名字。

暗红色锈迹在门缝深处勾出一条歪歪扭扭的笔画，起初他以为是错觉，等再看一眼，那几个字清清楚楚地浮在那里——“钱方远”。

林一凡倒吸一口冷气。

钱方远这个名字，二十分钟前他刚从水牢井底的铁皮壳子上见过。那半条命的钱方远带走了铁皮壳子里的“债务主体”，逃出了归墟水牢，而这扇铜门后面的锈迹里，又出现了钱方远的名字。这扇门后面到底是什么？

“你是不是看到了什么？”沈望未白挣扎着要站起来。

林一凡还没来得及回答，身后通道深处突然传来一阵细碎的脚步声。那脚步声很轻，很慢，像是一个人掂着脚尖在走，走两步停一步，走两步停一步。井口不是那个老杨头大哥守着吗？谁还能下来？

没等他想明白，通道里响起一个不紧不慢的声音：“小兄弟，那扇门，你最好别碰。”

是老杨头大哥的声音。那个铜脸人。

林一凡猛地回头，只见通道尽头的阴影里，一个人影斜靠着墙壁站着，脸上的铜色在昏暗光线中泛着诡异的光泽，手里拎着什么东西——细长，比他小臂还长，尾部沾着黑乎乎的东西……是钉。一根青铜钉。

老杨头大哥把青铜钉竖起，微笑着，语气温和得瘆人：“你既然已经走到这了，那最后一根钉，该钉进去了。”

林一凡低头看了一眼门缝里卡着的那枚青铜钉——还是卡的纹丝不动。他又看了一眼老杨头大哥手里那根钉——一模一样。两根一模一样的青铜钉，一枚卡在门内，一枚拿在守门人手里。那么问题来了：图纸27说的“换命”，到底要用哪一根？

林一凡没动。他就蹲在那里，盯着老杨头大哥手里的青铜钉，脑子里飞速运转着，一个念头刚刚抓住尾巴，就被另一个更大的念头撞碎。沈望未白说，门里面有个长得和老杨头一模一样的人。而老杨头大哥本人现在站在这里。如果门里的人也是老杨头……那眼前这个铜脸人又是谁？

他记得铁皮壳子上锁眼的形状。那个锁眼，根本不是给钥匙用的，而是一根钉的形状。铁皮壳子锁眼里那枚青铜钉空了之后，钱方远的半条命就逃了出去。而现在，归墟底部的这扇铜门，锁眼也是一枚青铜钉。如果他拔掉这枚钉……门打开之后，会放出什么？他下意识后退半步，目光扫过铜脸人老杨头大哥带着笑意的脸，胸口白骨纹章上的数字27，忽然跳成了26。它不升反降。

林一凡感觉后背一凉，凉得透心，冰得入骨。仿佛那扇门，正在主动为最后一根青铜钉腾出位置。老杨头大哥往前迈了一步，手里的青铜钉在灯光下泛着冷森森的光：“门在门后，钉在钉里——你不把它钉进去，它自己也要出来的。”

林一凡终于开口：“你说的‘它’……是谁？”铜脸人老杨头大哥低低地笑了一声，笑得整条通道都跟着微微震动：“你上一世，不是已经写过了吗？”林一凡浑身僵住。他上一世写的，是摸鱼系统的核心代码。而那句话的作者栏里，写着他自己的名字，但他从未写过那句话。那么是谁用他的名字，写下了一句话？

老杨头大哥张开嘴，露出一口黑牙：“你在摸鱼系统里写下的最后一行代码，一直都在等这句话。”他说完，弯下腰，将那根青铜钉，递到了林一凡手边。林一凡看着那根钉，又看了一眼门缝里卡着的钉，以及自己胸口的纹章数字26。系统面板忽然在视野边缘弹出，跳出一行他没见过的字——

“咸鱼值商城解锁隐藏商品：第二根钉。”

林一凡瞳孔猛缩。系统商店里能买到第二根钉？那老杨头大哥手里这根又是什么？他抬头看了一眼，老杨头大哥手里的青铜钉上，锈迹斑驳，隐约可以辨认出几个字——是“赵日天”。不，不全是。底下还有一行，字迹更旧更模糊，像是被磨过很久，几乎辨认不清。但林一凡看清楚了，看清的那一刻，他几乎以为是幻觉。那行字是：林一凡。

两根钉，两个名字。一根在他面前，一根在门缝里。他忽然明白了“换命”的意思，可明白的瞬间，他全身的血液都凉了。如果第二根钉是他的，那铁皮壳子里那一根是谁的？钱方远带走的债务主体，又到底换了谁的命？

他抬头，看见铜脸人老杨头大哥的眼里，映着一丝近乎怜悯的光：“小兄弟，你以为你是摸鱼的人。其实……你是鱼。”林一凡攥紧了拳头。他手里那根青铜钉，冷得彻骨。

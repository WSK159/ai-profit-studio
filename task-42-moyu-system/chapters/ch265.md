# 第265章 太平间的那个夜晚

铁门外的脚步声停了三秒。

林一凡攥紧手中的010号钥匙，金属边缘嵌进掌心的肉里，他盯着门缝下那双黑色皮鞋的影子和一双高跟鞋的影子，王姐和那个神秘男还站在外面。

“你确定要告诉他？”神秘男的声音压得很低，但负三层太安静，每一个字都像掉进水里的石子。

“他已经在里面听了七分钟了。”王姐的声音带着一种疲惫的坚定，“你我都知道，有些事瞒不住了。2019年那份太平间记录，早晚会被人翻出来。”

林一凡的后背贴着铁门，凉意从脊柱一路蹿到后脑。太平间。2019年。这两个词拼在一起，像一把生锈的刀，慢慢割开他重生以来所有的记忆边界。他一直以为自己是2026年6月15日猝死当晚重生回2019年7月1日入职那天，系统首次绑定给出的时间戳清清楚楚写着“2019-07-01 08:59:59”。但现在有人告诉他，2019年他躺在一张太平间的冷柜里？

他没签字，也没按手印。

铁门突然被敲了两下，很轻，像某种暗号。

“林一凡。”王姐的声音隔着铁门传进来，“我知道你听得见。现在把门打开。我不进来，我只跟你说一件事。”

林一凡的手指在钥匙齿上摩挲了一秒。010号钥匙的金属纹路里有细小的凹槽，像是有人用刀尖刻过。他低头看了一眼掌心的钥匙，在走廊昏暗的应急灯光下，钥匙柄的背面露出一行极小的字——不是编号，是三个字。

“赵、小、九。”

心脏猛地跳了一拍。陈重阳把钥匙交给他的时候，只说这是“第十把钥匙”，抵押品是命运。但赵小九这个名字，他只在2019年12月31日那碗麻辣烫里听过——那张纸条的落款就是“小九”。陈重阳说纸条是小九留给他的，陈重阳的妹妹。现在，010号钥匙上刻着小九的名字。

这钥匙原本属于她。

铁门外传来一声长长的叹息，王姐的声音变得更低更近，像是贴着门板在说话：“2019年7月2日，凌晨3点17分，星辰科技东门斜对面的四平路，发生一起交通事故。一辆失控的货车冲上人行道，一个刚加完班的年轻人被撞飞十二米，当场没有呼吸，送去四院时已经宣告死亡。死者身上没有任何身份证件，只有一张星辰科技的工牌。工牌上的名字是——林一凡。”

林一凡的瞳孔缩了缩。

“但你活得好好的，站在这里。”王姐继续说，“所以问题来了，2019年7月2日那天，真正躺在太平间的那个林一凡，是谁？又是谁，替他活了下来，顶着他的身份进的公司？”

走廊深处传来管道里的水流声，闷闷的，像隔着水层说话。铁门内侧的金属锈味混着消毒水的气味，钻进鼻腔里，一股说不清的寒意从脚底蔓延上来。林一凡握着010号钥匙的手微微发抖。

“王姐，”他终于开口，声音沙哑得像锈铁刮过砂纸，“你说的那个躺在太平间的我，才是我本来的样子，对吗？我现在这个身体，是别人的？”

门外安静了。沉默越久，答案就越清晰。

林一凡深吸一口气，把钥匙塞进贴身口袋，伸手拧动了铁门的内侧把手。锁芯转动的声音在负三层里回荡，门缝逐渐扩大，走廊的应急灯光扫进来，他看见王姐站在三米外，脸色比上次见她时白了两个度。她旁边站着一个戴黑棒球帽的男人，帽檐压得很低，只露出半张下颌——上面有一道浅色的刀疤。

“你终于出来了。”王姐说。

林一凡的目光钉在那顶帽子上：“所以你带他来，就是为了告诉我这个？”

棒球帽男摘下帽子，露出一张年纪不大但眉眼极其疲惫的脸。他盯了林一凡五秒，忽然露出一个意味深长的微笑。

“林一凡，”那声音冷得像冰碴子，“我叫赵恒，赵小九的哥哥。你手上那把钥匙，是我十年前亲手交给陈重阳的——让他转交给你。钥匙上刻的，是我妹妹的名字，因为她才是真正替你死了一次的人。”

林一凡的脑子像是被人按下了暂停键。他低头看着口袋里那枚坚硬的轮廓，手指已经凉透了。

“替我死了一次，”他慢慢重复着这句话，“你是说，2019年那个太平间，躺的是——”

“赵小九。”赵恒替他补全了后半句，“她顶了你的死。而真正该死的人，是你。”

# 第305章 老机房里的旧工位

面包车在夜色中行驶了一个多小时，林一凡始终没甩掉那辆黑色轿车的尾随。

沈稚冬从后视镜里观察了十分钟，突然说：“路口右转，进那个废弃的汽配城。我在那儿绕一圈。”

林一凡照做了。汽配城里没有路灯，横七竖八的集装箱和报废车壳被月光投出浓重的阴影。面包车在狭窄的巷道里转了四个弯，等第五次转出来时，那辆黑色轿车的灯光已经消失在了反方向的主路上。

“甩掉了。”林一凡松了口气，握方向盘的手松了松。

沈稚冬却摇了摇头：“不确定。先别回住处，去老机房。”

林一凡愣了一下：“现在？”

“坐标指到那儿，肯定有事。”沈稚冬把那张硬纸卷展开，看了一眼上面潦草的字迹，“2019.03.17。那天你入职。”

这句话让林一凡脊背发凉。他说不清那是一种什么感觉，仿佛有一只无形的手在数年前就替自己安排好了这一天的位置，而自己只是按照某种预设的轨迹走完了这三年。

星辰科技的老机房在二号楼负一层。当年公司搬新址后，那里改成了库房，堆满了报废显示器和陈旧的服务器机架，平时没有人下去。

凌晨两点，林一凡和沈稚冬从侧门绕到二号楼后面，用门禁卡刷开了消防通道的锁。这张门禁卡是老王当年配给林一凡的，说是应急用的，到现在都没失效。

楼道里昏暗，只有安全出口的绿色指示灯发着微弱的光。两人沿着台阶走到负一层，铁皮门上的锁已经锈死。沈稚冬从口袋里摸出一根铜丝，花了十几秒钟撬开锁芯，推门时发出尖锐的金属摩擦声。

老机房里的空气闷滞，呛鼻的尘埃味扑面而来。月光从高处一排窄窗透进来，落在一排排歪斜的机柜上，那些早已停转的服务器像一头头沉默的巨兽。林一凡心口一跳，像是有什么东西在胸腔里敲击。他认出这个位置。他入职第一天，工位就被临时安排在这间老机房的角落，因为新办公区还没装修完。他在这里坐了整整一个星期，每天对着那块老旧的十七寸显示器，写了人生中第一个测试用例。

“你那个工位在哪儿？”沈稚冬问。

林一凡走到靠墙的位置。那里依然放着那张老旧的白色办公桌，桌角磕掉了一块漆，桌面上落满了灰。他伸手抹了一下桌面，指尖在灰尘中划出一道干净的痕迹。桌面露出几行凌乱的刮痕。

沈稚冬凑过来，打开手机电筒。光线贴着桌面斜打过去，那些刮痕的轮廓清晰地显现出来，是一串数字。01120064。

“这——”林一凡盯着那串数字，只觉得后脑勺像被人抡了一棍。他入职那年坐在这张桌子上写了三天代码，从来没注意到这张桌子表面有什么刻痕。

沈稚冬的手指沿着刻痕缓缓划过：“你可能从来没仔细看过这张桌子。”

林一凡沉默了几秒，从兜里掏出那把镜像钥匙。钥匙柄上刻着“TSL”，长的那根齿柱上同样刻着一串数字，虽然锈迹斑驳，但格局与桌面上的刮痕完全一致：01120064。

“0112……”林一凡的喉结动了动，“我妈的生日是1月12号。”

沈稚冬的瞳孔一缩。她还没来得及开口，身后的服务器机柜里突然传出“咔嗒”一声，像是什么东西在里面挪动了一下。两人同时转头，机柜缝隙里隐约漏出一丝微弱的红色光点。

林一凡握住口袋里的钥匙，压低声音：“你听到了？”

沈稚冬没回答，已经从腰间摸出了那截铁棍。红光在黑暗中闪烁了两次，忽然灭了。紧接着，机柜内部传来一阵极其细碎的嗡鸣，像是一台沉睡多年的机器被重新通了电。

那台机柜、那一排服务器，在这个凌晨，全都亮了。

# 第225章 头顶的脚步声

林一凡盯着头顶那片渗着血滴的顶板，喉咙发紧。那液体一滴一滴地砸在水泥地上，发出轻微的“啪嗒”声，在死寂的污水站机房里格外刺耳。

“别抬头看太久。”陈默的声音压得很低，像是怕惊动什么东西，“我妈生前说过一句话——你盯着它看，它也盯着你。”

老王已经退到墙边，手里攥着那把铜钥匙，指节泛白：“这……这是血吗？机器启动还能弄出这玩意儿？”

林一凡深吸一口气，蹲下身，用手指沾了一点滴落在地面的暗红色液体，凑到鼻尖。铁锈味混着一股淡淡的机油味，并不像新鲜血液。

“不是人血。”他擦了擦手指，“更像是某种混合液——油、水，还有……老周笔记本里提过的那种‘导电介质’。”

“导电介质？”陈默眯起眼。

“对，老周在第13页记过两句话：‘电杆共鸣需要介质，介质从哪儿来？——头顶。’当时我没看懂，现在明白了。”林一凡指了指头顶那片锈迹斑斑的顶板，“这家伙在告诉我们，导线已经准备好了。”

话音刚落，头顶传来一阵沉重的脚步声。那声音从机房正上方缓缓移过，每一步都像是有什么庞然大物在混凝土上拖拽着行走，节奏均匀，不紧不慢。

老王脸色煞白：“就是天桥那晚的脚步声。”

林一凡没有反驳。他记忆里的天桥之夜，赵日天的人追上来之前，这脚步声出现过。当时以为是谁在桥上跑步，但现在看来，那声音从未真正消失过——它只是换了个地方游荡。

脚步声从机房的东侧移向西侧，然后停住了。停的位置正对着他们头顶。

寂静持续了大约十秒。

然后，一滴更大的液体从顶板缝隙里坠落，正好落在林一凡的手机屏幕上，那屏幕上还停留着老周笔记本的翻拍照片。液体滴落的位置，正好盖住了笔记本上三个标注点中最西侧的那个。

“卧槽。”老王低呼一声，“巧合还是……”

林一凡盯着手机屏幕上的那一滴暗红色液体，瞳孔微缩。笔记本上三个标注点分别对应园区东门、配电房、污水站。暗红色液体恰好覆盖了“配电房”那个点。

陈默从兜里掏出那枚硬币，翻到背面。维护工转交的硬币上用锐器刻着一串手机号，但那号码周围还有一些极细的划痕，不注意根本看不见。陈默把硬币凑到手机闪光灯下，那些划痕在侧光下显出形状——是一组坐标。

“52.3，-18.7。”陈默念出来，“这方向……配电房？”

林一凡点头：“老周把信息拆成了三份，笔记本给我们地点，硬币给我们坐标，电线杆里的机器给我们时限。所有线索都指向同一个地方。”

他看了眼手机时间，距离72小时还有61个小时。“但眼下有个问题，”他说，“卷王系统已经锁定我的位置了。赵日天知道我们在这。”

老王的声音带着颤：“那怎么办？跑？”

“跑不是办法。”林一凡的脑子里飞速转动，“赵日天的系统能锁定方向，但锁不了精确位置——不然他早直接杀过来了。他需要靠电子设备辅助定位。这里……是信号死角。”

他指了指墙角那一排老旧的通讯机柜，机柜上的指示灯大多熄灭，只有两颗红色的灯泡还在呼吸式闪动。污水站机房是园区里少有的地下区域，平时根本没人来，连WiFi信号都覆盖不到。

“我们还有多少时间？”陈默问。

“不好说。”林一凡低头看向那台原始意志机，机器的屏幕上仍滚动着那行字：“导线连接倒计时：61:34:22。”机器侧面的一个暗格不知何时弹开了，里面躺着一卷极细的铜线，铜线的一端已经接入了机器的主板，另一端裸露着金属切口。

林一凡伸手拿起那卷铜线，铜线入手冰凉，但上面有一行极小的钢印码，读起来像一串日期：2023.07.12-03:00。

“2023年7月12日凌晨三点。”林一凡轻声念道，随即瞳孔猛缩——这个时间，是他重生回来的前一天晚上，那个猝死之夜。

他最后一次加班到凌晨，写完代码时看了一眼时间：凌晨2点57分。三分钟后，他倒在了工位上。

“我爸曾经说过一句话，”陈默突然开口，声音里带着一丝异样，“他说，有些东西你以为是送你走的，其实是在接你回来。”

沉默在三个人中间蔓延开来。

片刻之后，林一凡把那卷铜线塞进衣兜，抬头望向顶板。上面的脚步声仍然没有离去，反而像是蹲了下来，有什么东西在摩擦着混凝土表面，发出细密的、指甲划动的声音。

“走。”他把手机收起来，“去配电房。”

老王犹豫了一下：“上面那东西……”

“它要是想下来早下来了。”林一凡推开机房的门，回头看了一眼机器屏幕上那行不断跳动的数字，“它得等我们把导线接好。”

他转身钻进黑暗的走道里，手机屏幕的光映在前面十余米处的墙面——那道管线拱起的痕迹还清晰可见，一路从机房延伸向出站口，朝着行政楼与配电房之间的方向蜿蜒而去。

身后的机房内，原始意志机发出一声低沉的电感嗡鸣。屏幕上，那行倒计时数字的旁边，缓缓浮现出一行新字：

“第一段逻辑已装载。导线连接人：已确认。”

而头顶的脚步声，在这一刻，停下了。

林一凡的脚步顿了一顿。他什么都没说，只是握紧了兜里那卷铜线。

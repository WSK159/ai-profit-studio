# 第120章 断根的暗码

银灰色的光越来越炽烈，贴着石室的墙面，那些从铜柱上掉落的蚀刻金属片忽然剧烈地颤动起来，像被磁力牵引一般往地面中央汇聚，形成一个直径约一米的环形阵列。

老王手腕上的汗毛都竖了起来：“这玩意儿……在共鸣。”

林一凡捡起那块银色的金属残片，放到阵列中央。金属片落地的一瞬间，环形阵列亮起，一串接一串暗码从边缘升腾而起，在空气中凝成半透明的字符——那是完整的断根暗码。

“老王，你认识这些符号吗？”林一凡问。老王眯眼盯着那些字符的排列方式，脸色越来越凝重，那表情跟看到了催命符一样。“这不是文字，也不是代码……这是定位坐标。”老王伸手指向其中一串折线状的符号，“它标记的是‘银章母体’在地下移动的路径，每隔一段距离就有一个校准点，像是在……”

“像是在等一个固定的频率。”赵日天抢白道，“那些校准点，每过一个固定时间就更新一次位置——这不就是母体在等什么东西来找它吗？”林一凡心头一跳。

他想起了走廊里那个声音：“不要相信那株银章。”——那株银章，银章母体，会动。它不只是一株寄生在这棵大树根系上的植物，它有自主意识，它在地底游走、等待、定位，甚至可能——

“它在等一个锚点。”林一凡低声说，“等它锁定的锚点送到它身边。咱们之前回收的那些锚点，也许不是咱们主动找到银章，而是银章故意把锚点放到咱们能发现的位置。”

石室里骤然安静了。倒计时红字在面板角落不断跳动，12分44秒。环形阵列的暗码开始以更快的速度翻转重组，像在草拟一份回应——而回应对象是谁，林一凡不知道。

赵日天忽然说话了，声音里带着一种罕见的迟疑：“我……见过这种暗码。但不是在星辰科技，也不是在前世记忆里。”他顿了顿，“在我那套卷王系统第一期任务结束时，解锁过一段隐藏存档，里面有一段类似的坐标，标注的是‘神弃之地’。”

林一凡转头盯着他。赵日天苦笑一下：“我一直没跟你说过这件事，因为我以为那只是个彩蛋。”他手指前方阵列中央的地面，“但那个坐标，换算成现实的参照系……就是咱们现在站的这个位置。”

话音刚落，环形阵列中央的地面猛然下沉，露出一个黑洞洞的深井。井口边缘长着一圈纠缠的根须，而根须之上，缠绕着一截银色的金属线——银章母体嫁接线的一部分，正以极缓慢的频率一起一伏，像是某种生物的呼吸。

林一凡探头往下看，井底深处有一点微弱的光在闪动。那一瞬，他脑海里响起系统机械的提示音：“检测到隐藏支线——‘母体之声’。宿主是否选择下沉探查？注意：此操作将消耗当前剩余全部咸鱼值，且不可逆。”

倒计时：9分21秒。

老王一把拉住他的手臂：“你疯了？下去可能就上不来了。”赵日天却松开刀柄，用鞋尖踢了踢井沿的碎土：“你不是系统选中的那个‘放弃’状态的人吗？现在放弃回头的选项，下去就是唯一的路——你信不信这井底下，就是他们一直在等的答案？”

井底那点火光微微颤动了一下，像是在应和。

林一凡回头看了老王一眼：“上面交给你。如果十五分钟后我没上来，你就带赵日天走，别等我了。”他朝井口迈出一步，脚尖抵上暗蓝色的根须边缘，系统倒计时在他视野中跳动到8分56秒，井下那一点光，忽然变成了一只缓缓睁开的、银色的瞳仁。

他的脚，落了下去。

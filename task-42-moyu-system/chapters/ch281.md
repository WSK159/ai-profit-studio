# 第281章 档案科的灯

凌晨的星辰科技大厦安静得像一座坟墓。林一凡推开侧门时，冷风灌进领口，让他打了个哆嗦。走廊里只有应急灯泛着惨白的光，他的脚步声在空旷的瓷砖地面上回响，像是某种倒计时。

他抬眼看了看墙上的挂钟，0:52。

三楼。档案科。A区第4排书架，左数第7本，蓝灰色旧书。

王姐的话在他脑子里转了一圈：“拿到书后不要打开。”但王姐也说过“快离开负一层”——结果他在铁皮柜里发现了姐姐刻下的数字，还听到了那句来自陌生男声的警告。“你姐姐没死，被关在‘那个地方’七年，钱总保险柜是假的，真正的钥匙在工牌编号里。”

工牌。他下意识地摸了摸胸口的工牌。正面是“010-2019”，背面是后刻的“010”，刮开后露出前世工号“0021416”。这到底意味着什么？他还没来得及深想。

三楼档案科的门虚掩着。门缝里透出一线昏黄的光。

林一凡停住脚步。这个时间点，档案科怎么会有灯？他侧身贴墙，右手轻轻推开一条更宽的缝隙。里面没有人，但靠墙的一排日光灯管亮了两根，嗡嗡地响，像某种低频的耳鸣。

A区第4排书架，从门口数过去，第四排。他快步走过去，目光掠过一排排书脊——大多是泛黄的档案册、财务凭证、会议纪要。左数第7本。

蓝灰色。

书很旧，封面的布纹已经磨损得泛白，没有书名，像一本被刻意隐去身份的东西。林一凡的手指触到书脊时，那本书轻微地颤了一下——不，不是书，是他自己的手在抖。

他没有打开。按照王姐的警告，他把书塞进外套内侧的口袋里，转身准备离开。但他刚迈出两步，余光扫到书架最底层的角落里，露出半截白色纸角。

他蹲下去，抽出一张折叠的A4纸。纸已经泛黄，边角卷曲，边缘有被折成四折的痕迹。他展开，上面是一行黑色签字笔写的字，字迹娟秀，像是女生写的：

“如果你看到这张纸，说明你还没有被换掉记忆。林一凡，2019年6月14日，你入职前两天，见过赵恒。他把一枚钥匙交给你，但你忘记了。钥匙在你的……你那件工装外套的夹层里。”

林一凡愣在原地。2019年6月14日——正是姐姐刻在铁皮柜底部的那个数字。他伸手摸向自己的旧工装外套，那件外套是他重生后一直穿着的，因为系统面板提示过它“带有特殊标记”。他从来不知道夹层。

手指摸到一个硬东西。

挖开线缝，一个铁质的东西滑出来——那是一枚锈迹斑斑的钥匙，造型奇特，齿口呈三条分叉，像某种旧式保险柜的锁芯钥匙。三叉钥匙。

赵恒在2019年就交给了他这枚钥匙？为什么他会完全不记得？他上辈子的记忆是从入职第一天开始的——不对，他的记忆有问题。工牌背后的“0021416”与前世“0007766”的矛盾，七年的记忆断联——系统……难道连记忆都能被“替换”？

“林一凡。”

身后传来一个声音。低沉，带着一股难以形容的疲惫感。

他猛地转身，一个男人站在档案科门口，背光而立，看不清脸。但身形很熟悉，林一凡的心脏猛跳了一下。

“赵恒？”他的声音有些干哑。

那人往前走了两步，日光灯的光终于照亮了他的脸。确实是赵恒。但和上次在负一层见到时不一样——他的脸色灰白，像是好几天没合眼，眼眶通红，眼睛里有一种混乱而警觉的光。他看见林一凡手里的三叉钥匙，瞳孔明显一缩。

“你……拿到了？”赵恒声音微微发颤，“把那本书给我，现在。”

林一凡沉默了一秒：“你先告诉我——你是谁。”

赵恒的嘴唇动了动，然后他说了一句话，让林一凡的血液瞬间冷下来：

“我是你姐姐的主治医生。也是当年替你缝合手术线的人。林一凡，你不是重生——你是被放进来的。”

窗外，风忽然停了。档案科的灯光闪了一下。林一凡的手握紧了三叉钥匙，指尖发白。

“放进来的，”他重复道，“放进哪里？”

赵恒看着他，目光里有一种说不清道不明的痛苦：“放进这条时间线。第000号钥匙植入手术，你签过字的。你……又签过字。”

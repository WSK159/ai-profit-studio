# 第286章 门

虚空里有什么东西被撕裂。像有人用指甲划开一张画布，空气发出细微的、嗤拉作响的裂声。林一凡盯着悬浮在眼前的银色芯片鱼，心底某个压制很久的直觉终于冲出防线——他见过这一幕。不是这辈子，是上一世。就在他猝死前的那个夜晚。

那夜他加班到凌晨两点，趴在桌上休息，梦见一条银色的小鱼从天花板游下来，绕着椅子转了三圈，最后贴在他太阳穴上消失了。他从梦里惊醒，胸口疼得要命，然后屏幕右下角弹出一行字：“咸鱼值+10”，再然后，人没了。

现在那条鱼回来了。

芯片鱼完全张开嘴的同时，三叉钥匙的尖端一寸一寸亮起来，从金属里渗出的暗蓝色光沿着钥匙柄上刻着的“6-14”字样爬过，蔓延到林一凡的指尖。他握紧了钥匙，身体像被什么力量牵引着，往前迈了一步。

眼前的世界像碎玻璃一样剥落。

天台消失了。取而代之的是一条走廊——狭长、没有窗户、白炽灯管发出嗡嗡的低响，墙壁是灰白色的，地面是浅绿色瓷砖。林一凡认得这个地方。星辰科技大厦，第三层，档案科的走廊。但又是不同的：走廊尽头那扇门上有编号，不是“档案科”，而是一个血红色的数字——“000”。

林一凡攥紧钥匙，一步一步走过去。

走到门前，他抬手想推，却发现门是虚掩着的，只露出一条拇指宽的缝。他没有急着推门，而是俯下身，把眼睛凑到门缝上。透过门缝，房间里亮着灯，视野里能看到的东西并不多：一张老式铁架床，床头的白铁皮柜子，柜子上放着一个空药瓶，瓶身标签朝内翻着。床上躺着一个人，女的，脸朝里，看不清脸，但身形纤细，头发披散在枕头上，尾端微微卷曲。

林一凡的心脏猛地收缩了一下。呼吸都停滞了。那个侧影，他太熟悉了——是林一诺。他姐。

躺在床上的女人像是感应到他的目光，微微动了一下。林一凡手指扣住门框，脑子在飞速旋转：沈稚冬说林一诺的脑电波在2019年6月12日的手术中和自己同步，赵恒说她录过音频“0427是我藏起来的门”。那么这扇门里躺着的到底是谁？林一诺？还是植入她大脑的那个东西？

就在他犹豫的瞬间，门里的女人忽然翻了个身，直直坐起来——脸转过来的一刹那，林一凡浑身像被冰水浇透。那张脸不是他姐的。

是他的。

那张脸和林一凡一模一样，只是年轻一些、疲惫一些，眼睛里带着熟悉的笑。林一凡退了一步，后背撞在走廊墙壁上，撞得肩膀生疼。门里那个“林一凡”用他熟悉的语气，慢悠悠地说了一句：“你终于来了。”

声音从他的喉咙里挤出来，带着电脑合成一般的尾音：“我等你——等了七年。”

林一凡喉咙发干，一个字都说不出来。门里的“林一凡”却笑起来，笑得和他一模一样。它抬手张开五指，掌心里放着另一把三叉钥匙，尖端没有刻印“6-14”，而是刻着一个“0”。“等了你七年的是这具身体。我没有名字，编号是000——我是第000号植入体，你姐亲手写的代码。她让我等你来。”它顿了顿，“钥匙能打开的路，都要从你这里过。而你要见的人在门外，你身后。”

林一凡猛地回头。走廊尽头，不知什么时候多了一道身影。那个人站在白炽灯的阴影里，穿着长风衣，脸藏在黑暗里，声音却熟悉得像一根尖刺刺进耳膜——他年轻时的记忆里，这个声音伴随了自己整个童年。

“林一凡，”那个声音说，“你妈没有死。”

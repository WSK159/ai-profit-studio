# 第94章 蜉蝣在备份里

林一凡看着手机屏幕上那句话，脚步僵了一瞬。

“谁发的？”周莉凑过来。

“江然。”

周莉的眉头锁得更紧：“她刚才不是让我们来拿备份吗？现在又让你别动？”

“所以这才有问题。”林一凡把手机揣回兜里，脑子里飞快地转。江然给他U盘的时候表情很笃定，像个看清全局的人；但现在这条短信又像在说——你还没看清楚。

他抬头丈量了一下视野，推翻了“她骗我”这个念头。更合理的解释是：江然自己也没料到备份里藏了什么东西。她也许只知道钱雨和王川签了协议，但没想到王川把协议做成了可执行程序，更没想到蜉蝣会趁程序还躺在机柜里的时候爬进去。

“蜉蝣在备份里”……

林一凡回忆着蜉蝣的一切特征：它存在于视觉盲区里，存在于信号的间隙中，现在它跑进了“程序”里，变得可以被人为加载、执行，然后通过云麓AI的数据链路反向蔓延。

它不是被一个系统召唤来的，而是被这份协议打开的。

“我们得把U盘拔出来。”林一凡说着，脚步往七号机柜的方向折返。

“你疯了？那两个人还在后面追我们！”周莉拽住他的袖子。

“他们不是冲U盘来的，他们是冲我来的。蜉蝣的目标是U盘里的程序，只要程序还在，它的存在就有依托。江然提醒我别动程序，意思是告诉我不该右键执行它，但我可以把文件拖出来，和程序本体分离。”

周莉没再反驳，只是盯着他：“你什么时候想明白的？”

“就刚才，被你拽那一下。”

两人又猫腰穿过排水管通道，贴着机柜背面的阴影绕回七号机柜。指纹锁还亮着绿灯，U盘还嵌在调试口里，那台小屏幕上的命令行倒计时已经走到最后一分钟——有人远程设定了执行时限！一旦倒计时归零，整个备份就会自动运行，程序以“用户默认同意”的方式潜入云麓AI主系统。

林一凡来不及犹豫，食指一伸，用力把U盘从调试口里拔出来。

“嘀”的一声，屏幕上倒计时是停止了，但紧接着弹出一行红字：“备份已移除，目标进程可由其他节点接管，正在切换……已连接到：周莉终端。”

周莉猛地抬起头，眼里的黑气一闪而过：“林一凡……我的手，不听使唤了。”

她右手正不受控制地抬起，从腰后掏出一部手机，解锁，屏幕上已经跑着那个程序的安装界面。而那名正在安装“可执行程序”的设备通讯录第一行，赫然写着“钱雨—老板”几个字样。

“它选了我当宿主！”周莉的声音沙哑，带着哭腔，“那个嗡嗡声就是从这里面来的，蜉蝣已经在我身体里了！”

“别怕！拔电池！”林一凡跳过去就要抢她手里的手机。

他手指刚碰到手机背面，整栋大楼的灯，猛地全灭了。黑暗中，数十米外的走廊尽头传来整齐划一的皮鞋声，那是黑色制服人员走过来的方向。而在林一凡的摸鱼雷达里，那两个人的劳动浓度已经不是一个量级——它们整个人都泛着暗红色的光，尖端像烧红的烙铁。

蜉蝣接管了追兵。

“跑！”林一凡一把揽住还没回过神的周莉，闪身撞开另一扇检修门，冲进了更深的数据迷宫。身后传来玻璃碎裂和金属摩擦的声音，夹杂着低沉的、不属于人类的号叫。

而在他掌心，U盘里那个“情感增量—源数据”的程序，在屏幕上悄悄弹出了一个提示框：

      “检测到宿主体内存在同类标识，是否启动双向意识同步？Y/N”

林一凡看着那个提示，没吭声，但他的拇指，已经悬在了“Y”键的上方。

# 第207章 那个坐标

林一凡把纸条捏在手心，指尖传来的纸张质感，带着微微潮意，像在怀里捂了很久。

赵日天还在台上讲“摸鱼效率排行榜”的细则，大屏幕上红色条状图一列列刷新，他的照片赫然排在第一位，旁边标注着“累计离岗213小时”的刺眼数字。会议室里嗡嗡声四起，无数目光像针一样扎过来。

林一凡却已经把耳朵关了。

他低头，扫了一眼纸条上那串坐标的格式——北纬31度、东经121度，精确到小数点后四位。作为一个前世写了五年代码的人，他对数字的记忆力近乎病态。这个坐标他认得。它指向的地方，就在园区污水处理站东南方向不到两百米，那里有一片废弃的管道检修井群，地图上没标注，连老员工都很少去。

但林一凡去过。

上一世，他在星辰科技熬到第九个月的时候，有一次加班到凌晨四点，去那边抽烟透气，见过一扇锈了一半的铁门，门口有新鲜的轮胎印。他当时没在意。

现在回想起来，那扇铁门后面，大概率就是老周笔记本上画的第二个标注点——那个被老王补充成“污水处理站底部”的地方。

林一凡不动声色地抬头，重新看向台上。赵日天正好念完排行，把这天的“摸鱼大会”推上高潮。钱总在边上鼓掌，又补了几句新绩效的宣贯，说什么“公司要进化，不能养闲人”，目光越过人头，落在林一凡身上，一秒钟，又移开。

散会时，人潮涌向门口。林一凡起身，把纸条和钥匙一起揣进衬衫内侧口袋。陈默就坐在斜前方两排的位置，正低头收拾东西，没看他。

林一凡从他身边路过，压低了声音，只说了三个字：“不是你？”

陈默的笔顿了一下，没抬头，声音也压得很低：“你猜。”

然后他合上本子，混进人群里，消失在走廊转角。

林一凡站了两秒，没有追。他掏出手机看了眼时间——下午两点十分，坐标在园区外，步行大概十五分钟。但赵日天还在门口跟几个部门的负责人寒暄，钱总也没走远。这时候离开太显眼。

他想了想，拐进茶水间。里面有两个人，正在聊考核方案的事。他倒了一杯水，站在窗边，慢慢喝。

窗外天空灰蒙蒙的，像要下雨。他盯着污水处理站的方向看了一会儿，那片检修井群隐在铁皮围挡后面，远远看去就是一片杂物堆。但此刻，在摸鱼雷达的视野里，他隐约看到那片区域有一层极淡的白色光晕，浮在地表上方不到一米的位置，像雾气一样，若有若无。

他眉头皱起来——雷达从来没有出现过这种情况。

“叮。”

脑海里传来系统提示音。

“检测到异常能源波动。警告：持续暴露可能触发‘劳动纯度检测仪’的被动扫描。建议宿主在30分钟内离开园区范围。”

林一凡放下水杯。

十分钟后，他绕到后勤通道，用系统兑换了一张访客通行卡，从侧门刷卡出去。外面起了风，空气又闷又潮。他没走主干道，沿着输水管线的方向，穿过一排栾树的树荫，很快就到了那片废弃检修井的围挡前面。

铁皮围挡锈得发红，门口横着一根链子锁，锁扣上生了一层青锈。林一凡推了一下，留出一条半人宽的缝隙，侧身挤了进去。

里面比外面更安静。地面上排列着七八个圆形井盖，大小不一，有的已经开裂，露出下面的暗影。他低头比对钥匙底端的刻度线，又确认了一遍纸条上的坐标，最后停在角落一个不起眼的井盖前——井盖上没有编号，表面落满灰，但边缘有一圈不太显眼的擦痕，像是最近被人打开过。

他蹲下来，掏出那根金属圆柱。刻度线正好和井盖边缘的一道切口吻合。

林一凡没急着插进去。他看了一眼四周，确认没人的动静，这才把圆柱按下去，逆时针拧了半圈。

“咔。”

井盖下的锁弹开了。他掀开盖子，底下一截铁梯通往黑暗，一股混合着铁锈和机油的气味涌上来。他正要下去，手机震了。

一条消息。

匿名号码：“别下去。钥匙是假的。坐标才是真的。但要先去A栋顶楼配电室，拿到第二根钥匙，一起用。否则你也进不去。”

林一凡盯着这行字，手指悬在屏幕上方。

他抬眼看向A栋方向——隔着大半个园区，那栋玻璃幕墙的高楼在灰白天色下像一个沉默的巨兽。配电室，正是老王补充的两个点之一。

他又看了一眼脚下那口井。里面很安静，黑得像一张口。

他缓缓把井盖合回去，锁扣归位。然后转身，朝A栋走去。

走出围挡的瞬间，他回头看了一眼。

在井盖边缘那道擦痕上，多了一个东西——一枚硬币，金杯面朝上。

林一凡的目光顿住。

他记得天桥上的脚步声，记得自己重生那晚地上那枚金杯朝上的硬币。

而现在，它出现在了这里。

他弯腰把它捡起来，硬币的背面刻着一个极小的字——“神”。

# 第269章 两个选择

六十秒倒计时在脑海中无声跳动，绿荧荧的数字像是倒悬的沙漏。

林一凡盯着面前的赵小满，那张年轻的脸与赵恒有六七分相似，眉眼却更锋利些，像是刀尖上未磨圆的棱角。他右手按在腰间，指节微微发白，那里鼓着一道不明显的弧度。

不是刀具，更像是一根短棍。

林一凡开了摸鱼雷达，视网膜上浮起一片淡蓝色的光幕。赵小满头顶的“劳动浓度”标着四十三，不高不低，但“摸鱼状态”那一栏却闪动着一行灰色小字——“伪装中”。

这个二十出头的后勤工，在演的。

倒计时还剩四十二秒。

“跟我走。”赵小满压低声音，目光快速扫过走廊两侧，“钱总的人已经摸到负一层了，最多十分钟就能搜到这里。负二层的监控死角撑不了那么久。”

“去哪？”

“有人说要见你。”

“谁？”

赵小满没回答，指腹在腰间那根短棍上摩挲了一圈，眼底浮起一丝复杂的光：“你认识他，他也认识你。但他说，如果你问起这句话——”他顿了一下，像在记忆里翻找某个被反复叮嘱的句子，“——你就回答‘鱼不靠岸，水不跃门’。”

林一凡浑身的血像是被什么东西猛地抽了一下。

这句话，他听过。

就在上一个世界线，不对——更准确地说，在上辈子、在死亡的边缘、在那条他本该走过的路上、在那扇白色大门前，那个陌生女孩对他说过这句话。

“鱼不靠岸，水不跃门。游到深处的人，看不见岸。”

这八个字是暗号，也是某个他从未完整触及的命题的引子。而此刻，从赵小满嘴里说出来，更像是某种不可逆的齿轮重新啮合。

倒计时还剩十八秒。

从废弃档案室的门缝里，陈重阳的目光像两根钉子钉在他后背。老人没有说话，但他能感觉到那道视线里压着一封未拆的信。

两条路。
跟赵小满走——通向那扇白色大门的答案，通向那个说“我替你走这段路”的女孩。
返回负三层——追查010号钥匙，“命运归还”的执行方式，以及陈和平顶罪的确切指向。

系统面板在视野边缘弹出一行金色小字：

【提示：命运归还并非惩罚，而是补完。路径选择不可逆，但两条路指向同一扇门。】 

同一扇门？林一凡眉头皱起。

他盯着那行金色小字看了三秒，然后笑了。

“行。”他对着赵小满点了下头，“我跟你走。但——”

他转身，推开了废弃档案室的门，门轴发出一声锈蚀的呻吟。陈重阳的身影坐在昏黄的应急灯光里，像一尊沉在黑暗底部的旧铜像。

“陈叔，车祸那天的真相，你还藏着多少？”

陈重阳抬起头，那双浑浊的眼睛里掠过一丝惊愕，随即又沉下去：“你现在要问？”

“不问，我可能没有机会再问了。”

隔了三秒，陈重阳从怀里掏出一个牛皮信封，信封上印着一枚褪色的红章，像是一串编号。

“这是你入职前三天，有人寄到我这的。地址是四平路某个已经拆掉的电话亭，邮戳是2019年6月28日。”他把信封推过来，“里面只有一张纸。纸上写着一行字——”

他顿了顿，像是在确认这件事自己是否真的要交给对方。

“‘如果林一凡回来了，告诉他——替他死的是第一个人，替他活的是第二个人。你欠她们两条命。’”

倒计时归零。

林一凡攥着信封抬起头，对上了陈重阳的脸。那张脸上的皱纹在这个瞬间像是水面的波纹一样微微颤了一下，一个他从未见过的表情——恐惧、怜悯、还有一丝隐隐的释怀。

“你认识她？”林一凡的声音比他自己预想的要哑。

陈重阳缓缓闭上眼睛：“认识。她叫林一诺。你妹妹。”

系统面板上，“任务：另一个死者”的进度条——从98%跳动到99%。

不是100%。

还有一格。那一格，正在外面、在赵小满站着的地方、在那扇白色大门后面等他。

林一凡把牛皮信封对折，塞进内袋，转出档案室，朝赵小满走了过去。

“走吧，”他说，“带我去见那个‘认识我’的人。”

他没注意到——他在转身的一瞬间，赵小满的瞳孔里没有映出他的影子。赵小满看见的是一个轮廓略有偏差的人：一个同一个方向、同一个笑容，却比他矮、比他瘦、比他年轻七岁的人。

赵小满压下腰间的短棍，嗓音里压着一丝说不清的颤：“……好。跟着我走，别回头。”

走廊尽头熄了一盏灯，像是有人在黑暗中，替他们关上了一扇门。

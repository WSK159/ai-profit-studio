# 第323章 第三级台阶

防空洞入口藏在旧园区西北角倒塌的配电房后面，水泥台阶半掩在杂草与碎玻璃之间。林一凡与周立冬沿着斜坡下来时，空气里的温度骤降了七八度。第三级台阶表面比其他台阶多出一道细缝，像是被什么东西撬开过又重新合拢。

周立冬蹲下，掏出手电筒照向那道缝隙：“有点新鲜。”

“什么意思？”

“你自己看。”他侧开身。

林一凡凑过去，那道缝边缘的水泥泛着浅灰色，与周围深灰色的旧水泥明显色差——不到一周前被人撬开过。他伸出手指，沿着缝摸过去，触到一块凸起的金属棱角。

他用石头撬开边角，露出一个手掌大小的黄铜匣子。匣面布满绿锈，但锁孔的形状，正与钱总办公室里那把钥匙完全匹配。

“操。”周立冬低声骂了一句。

林一凡没有急着开锁。他把匣子翻过来，背面刻着一行小字——“此锁为生者守，此钥为死者铸。”他眯起眼，反复咀嚼这句话，忽然问：“周叔，你以前有没有听我妈提过一个祭日的说法？”

周立冬皱眉回忆：“她很少提过去的事。只有一次喝多了，她跟我说她欠一个人一条命，要在每年的同一天去一个地方。”

“哪里？”

“没说。只说了句‘第三梯’。”

林一凡的后背泛起一层寒意。母亲留给他的六个字，指向防空洞第三级台阶。但隐藏在纸条背后的信息要远比他以为的更复杂——她欠的那个人，是否与刻着“沈”字的锁有直接关系？

他握住钥匙。黄铜钥匙插入锁孔的瞬间，嘎哒一声脆响，匣盖弹开，里面只有一颗指甲盖大小的白色纽扣，和一封密封的信。信皮上没有任何称谓，只画了一棵梓树，树下站着一高一矮两个背对的人影。

林一凡展开信，字迹很清秀，与照片上的笔迹一脉相承。开头只有一行：“一凡，如果你读到这封信，说明你已经活过了你父亲没有活过的年纪。”

他的手指僵住了。他从未听母亲提过父亲一个字。

信继续往下写：“他死于第三年祭日。我在同一天埋下了这颗纽扣——那是他衬衣上留下的最后一件遗物。不要去寻找答案。因为有些答案，是用来杀人的。”

林一凡把信读完，沉默了很长时间。周立冬没有催他，只是守在台阶上方警惕地察看着四周。

他握着那颗白纽扣，忽然注意到纽扣背面有一圈极细的刻痕。凑近手电筒光下辨认——是摩尔斯电码，点、划、点、点，短、短、短。

比起“别信哥”的那串电码，这个更简洁：沈临渊名字的缩写。

“周叔，”林一凡的声音低沉而平静，“沈临渊说他是替身教官，训练过母亲。但他说谎了。”

“什么意思？”

“他不是训练过母亲——他是父亲。”林一凡把纽扣递过去，指了指刻痕，“这枚纽扣上刻着他自己的名字缩写。母亲埋在这里不是巧合——她埋的是与沈临渊相连的证据。她从头到尾都在告诉我们：沈临渊不是她自己选的替身教官，他是她一早就认识的人。”

周立冬脸上的血色缓缓褪尽。

林一凡把纽扣收进口袋，又低头看向那封信最后一行极小的字：“若你执意要查到底，去见孙满仓。他能带你到你父亲的坟前。”

他的呼吸猛地顿住。孙满仓的身份，在这一刻终于从怀疑变成具体——这个人不仅认识沈稚冬，还知道沈临渊与林一凡真正的血缘关系。而“父亲的坟”这三个字，像一把刀，在层层迷雾中劈开了一道口子。

“走，”林一凡站起来，眼神已定，“去找孙满仓。”

周立冬往台阶上的出口瞥了一眼，神色一顿：“晚了。有人来了。”

手电筒光照出去，防空洞入口处站着一个灰衣人影。那人影摘下兜帽，露出一张林一凡不算陌生的脸——孙满仓。他手里捏着一把同样的黄铜钥匙，在晨光中晃了一下：

“你终于走到这一步了。”

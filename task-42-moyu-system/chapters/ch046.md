# 第46章 三份底牌

那张宋远桥的门禁卡在两人之间搁了足足半分钟，赵日天才开口：“不是我放的。”林一凡用袖子包着卡片翻过来，背面除了那几个字，右下角还印了一个极浅的日期戳——正是沈敛离职前一天。

他没有当场反驳，只说：“‘留三份’，你还没告诉我答案。”赵日天起身走到窗边，指着楼下的东城咖啡招牌：“第一份，是沈敛存在公证处的纸质备份，里面是他经手星海数据案期间，秦氏要求他删掉的原始合同扫描件。”他转回头，“第二份，是D3-B1区块里的镜像层拷贝，我用卷王系统的核查权限验证过，那份数据和初赛缓存副本有十七处字段不一致。”

“第三份呢？”

赵日天沉默了几秒，重新坐下：“第三份，是你。”

林一凡愣住：“什么意思？”

“沈敛的开发者内测版系统在离职前留下了一条待触发指令——如果有人在初赛里公开指向D3-B1异常，系统会把那个人的身份标记为‘继承人’。”赵日天说，“你以为你拿到了深度解析技能，其实沈敛早就把那个技能留在了系统商城的架子上，专门等你兑换。”

“所以……我兑换的不是系统自己的技能，是他留的？”赵日天点头：“你用的深度解析，用的是沈敛当年在秦氏时逆向工程出来的数据追踪算法。换句话说，你用了秦氏自己的刀，割开了他们自己的口袋。这就是第三份——你的方案本身，就是证据链的最后一块。”

话音刚落，林一凡手机振动——老王的电话。接起来，老王声音哑得厉害：“一凡，快看群，宋远桥发内部通告了，说D3-B1区块的运维日志昨晚被删了一部分，安全部明天早上要请你去‘协助核实’。”

赵日天听见电话里的声音，忽然拿起桌上那张写有“别信他”的门禁卡翻到正面，在灯光下照了照——门禁卡正面，宋远桥名字下方，印着一个小小的秦氏集团标志。

“明天去安全部之前，”赵日天把卡按进林一凡手里，“你要先去看一样东西。沈敛在D3-B1的镜像层里存了一份‘删除前截图’，时间戳是昨晚删数据前六小时。如果能拿到它，安全部的事，你反过来就是原告。”

林一凡盯着那张卡，手机屏幕的光照在他脸上。窗外，东城咖啡的灯牌闪了两下，然后熄灭了。楼道的尽头传来电梯门打开又关上的声音——这个时间点，不应该有任何人在。

他把卡收进兜里：“那你呢？明天你站哪边？”

赵日天笑了一下，重新点开那个笔记本屏幕：“我站证据这边。谁的证据硬，我就是谁的人。”屏幕上，一行新的数据流正缓缓加载出来——那正是沈敛留下的“删除前截图”，而它的下载来源，指向宋远桥的办公账号。

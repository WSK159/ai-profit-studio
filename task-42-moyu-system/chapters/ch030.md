# 第30章 卷末：咸鱼科技诞生

封杀令发布之后的第七天，林一凡出现在中关村一家名叫“眠鱼茶馆”的二楼包间。对面坐着一个看起来比他大不了几岁的女人，穿着灰色针织衫，没背名牌包，面前一杯白开水。

“深海资本，贺观澜。”她伸出手，“你比我想象的年轻。”

林一凡握了握她指尖：“林一凡。你也比我想象的……朴素。”

贺观澜没接这个茬，直接开口：“我看了你那场直播。数据我查过了——你那套方法，在三个团队并行试点过，效能提升分别是在31%、42%和38%，全华网的白皮书是抄你的，考勤记录和文件时间线都对得上。”

她顿了顿：“所以我今天来，不是问真伪，只问一件事——”

她直视他：“如果我投你，你能把星辰科技打到多惨？”

林一凡端起茶杯：“我不要打惨他们。”

贺观澜挑眉。

“我要让全行业的人都知道，‘钱总’做的每一件事，都长在我的理论手册上。”他放下茶杯，“我要把星辰科技的‘加班文化’彻底打成一堆笑话——让他们的新员工，入职第一天就质疑：我们为什么要这么卷？”

贺观澜安静了三秒，从包里掏出一份文件：“一千万。天使轮，占股12%。”

林一凡翻了两页，签字笔已经在手里打转：“你们占股15%，但有一个条件——”

“你说。”

“公司的企业文化由我定，深海资本不能干涉。我们不是做传统意义的‘科技公司’——我们有作息制度，每周五下午全员摸鱼，法定节假日不上班，没有强制加班。”

贺观澜沉默了一会儿。“也就是说，你拿着我的钱，开一家……不加班公司？”

“对。”林一凡把笔递过去。

贺观澜轻轻笑了，也接过笔，在两份合同上签下名字。“行。反正我赔了就当投了个人生试验。”

一周后，中关村一处三层小楼挂上了新招牌：咸鱼科技。

开业第一天，门口摆了张桌子，上面放着一本厚厚的册子——《摸鱼工作法全公开（第二版）》。这是林一凡在摸鱼空间里花了整整六十个小时整理出来的，不光含方法论、工具链，还有考勤算法的设计原理、反加班谈判术乃至老板话术对抗心法。

扉页写着：“本手册免费开放，任何人可复制、翻印、传播。”

入职的三个程序员围过来看他：“老板，你这手册免费给人看，我们还拿什么吃饭？”

林一凡咧嘴：“咱卖的是咨询和服务，不是那本手册。手册是鱼饵，人是鱼竿。”

他刚准备继续说，手机进来一条消息。

——赵日天。

“恭喜开张。有一个你绝对感兴趣的消息，要不要听？”

他盯着屏幕犹豫了三秒，回了一个字：“说。”

“钱总跟星海数据签的，不止是数据外传协议——他拿星辰科技的员工隐私数据，去喂了一个叫‘资本神’的AI系统。我还查到他跟你家系统的原初协议有关。想不想知道更多？”

林一凡抬起头。屋外阳光正好，屋里几个人已经开始用他写的模板做第一单客户方案——客户来自直播，一个叫“极速未来”的前封杀者联盟成员，私下倒戈了。

他低头在屏幕打了一行字：

“约个饭。时间你定，地方我选。”

然后他收起手机，看着头顶那枚新做的“咸鱼科技”Logo——一条卡在鱼缸里翻白眼的咸鱼，嘴角浮起一抹笑。

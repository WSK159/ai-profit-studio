# 第400章 锁中人的交易

锁芯里的女人手指忽然停止了蠕动，像蛇嗅到了猎物的气息，慢慢朝林一凡的方向转了过来。

那根手指是活的。林一凡浑身寒毛倒竖，真实视界里冒着最后的一层白雾，他看见那截手指的指腹与锁芯内侧已经长在一起，肉色模糊、分不清彼此。

“别动！”沈临渊低喝，声音里第一次带上了一丝紧张，“她认主——她在选择下一个宿主。”

铁皮壳子却发出一阵金属摩擦般的笑声：“终于到了。我找了她那么多年，原来被关在这里，当我的锁！”

水面上那个“帮”字忽然激荡出无数涟漪，字迹仿佛被水底的什么搅动，正一点点消失。

“老杨头大哥——”林一凡盯着铁皮壳子，试探道，“你要的不是出来，是你兄弟的命？”

铁皮壳子沉默了一瞬，随即传来一声沉闷的撞击。“他替我被锁了。当年对赌失败，零要收一个真身做‘锚’，原本应该是我，他抢了先。”铁皮壳子的声音从胸口传出来，带着铁锈的沙哑，“我找了他七年，就是要把这锁打开，换我回去。”

“所以你才答应帮我们进归墟？”沈临渊冷冷地开口，“你知道图纸、知道陶土徽章，不是为了找‘归墟之心’，是来找锁芯的钥匙。”

“钥匙就是他的手指。”铁皮壳子指向那截蠕动的女人手指，“零的真身嵌在他的身体里，锁芯吞了她的半截手指做锁簧。只要把锁芯转动到正确的位置，她就能把真身还给我大哥，我就能替他——”

“你去死？”

话音未落，水下台阶处的无脸人形猛然张开嘴——没有五官的脸，却从下颌撕裂出一道暗红色的裂口，发出一声非人的嘶鸣。锁链绷紧，水面炸开，浊浪朝三人涌来。

林一凡下意识往后退，脚下一空，整个人跌进了台阶右侧的一口隐蔽深井。他拼死抓住井沿，真实视界在坠落瞬间看到一个画面：井底伏着一具白骨，骨锁中央，嵌着一块和他手里铜片形状一模一样的黑影——黑铜。

“沈临渊！铁皮壳子！”他喊了一声，却被水声吞没。

井深约莫两丈，井壁上嵌着一圈环形纹路，像是某种设计的刻度盘。林一凡摸出怀里的半截铜片，往那道黑影的缺口处一贴——严丝合缝。

黑影里传来一个极轻的声音：“开锁者，你知道打开了谁的门吗？”

林一凡咬咬牙：“你是锁中人，还是坐庄人？”

那声音沉默了片刻：“你们一共来了几个人？”

“三个。”

“错了。最后登船的是四个。”

林一凡脑中嗡的一声，他猛地回头，井口上方站着一道瘦长的影子——不是沈临渊，也不是铁皮壳子。那影子缓缓弯下腰，林一凡看清了它的脸——是赵日天，此刻他的眼眶里没有眼珠，只有两只灌满红线的空洞。

“林一凡。”赵日天的声音陌生而干涩，“我来收卷了。”

井下的锁芯，忽然自动转了一圈。

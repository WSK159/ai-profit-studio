# 第27章 利益分配：林一凡拒绝，老板翻脸

“一凡啊，坐，坐坐，尝尝这茶——金骏眉，一斤八千八。”

钱总的办公室，红木茶几上冒着白气，他亲自给林一凡倒了一杯。茶是好茶，可林一凡一屁股坐下来，系统面板在视野角落弹出一条提示：

【检测到高浓度PUA气场，反卷护盾已激活，精神伤害免疫中。提示：这茶的钱，你加班时流的口水都付得起。】

他差点笑出声。钱总脸上堆着笑，眼神却像一只盯上了肥肉的秃鹫。

“说吧钱总，什么事儿？我效率小组那边还排着验收呢。”林一凡喝了口茶，啧了一声，“好茶，可惜只能润喉咙，润不了我半个月没休息的肝。”

“哈哈，一凡你这话说的，我这不是一直想着给大家谋福利嘛。”钱总搓了搓手，从抽屉里拿出一份文件，推到林一凡面前，“你看，咱们‘摸鱼工作法’最近在行业里火得不行，我今天开了个会，大家一致决定，把它做成一个企业培训品牌，卖出去！一节课38万，一年下来，少说这个数。”

他伸出五根手指，五指张开，比了个五十的意思。

林一凡的眼睛都没眨一下。他早就知道了——前世也是这条路，钱总把“摸鱼工作法”注册成公司知识产权，打包成“星辰效率管理课”，第一年卖了两千多万，全进了老板腰包。他，一个“研发者”，拿了一万二的红包和一面“优秀员工”锦旗。

“好事儿啊钱总，那分成……是怎么算的？”

钱总身体往后一靠，又笑了：“你看，这个方法是公司的员工发明，用于公司业务，按照咱们合同第四条的知识产权归属条款，这个本身就属于公司职务成果。当然，公司不会亏待你——我打算让你当荣誉讲师，第一期课程上线后，额外给你发这个数。”

他伸出两根手指——两万。

“钱总，两万啊。外面请个普通讲师，半天出场费都不止这个数。”林一凡放下茶杯，“而且我记得没错的话——我当初提交‘新式高效工作法’汇报的时候，在文档底下明确写了，这套方法的核心逻辑属于我个人独创。您当时还批了个‘阅’字，签了名。”

钱总脸上的笑容，慢慢淡了下来。

“小林，你这话什么意思？你入职的时候签的劳动合同，第38条是吧——乙方在任职期间创造的，与本职工作相关的知识产权，归甲方所有。你的本职工作是什么？写代码。你那个‘摸鱼工作法’是不是在职期间创造的？是平台在公司，时间在公司，用的公司电脑！那就是公司的！”

钱总的声音从一开始的循循善诱，直接变成了吼。

林一凡一动不动，盯着钱总看了三秒钟，看着那张肥脸涨得通红，看着那只指他的手指微微发抖。他前世就是被这一句“公司电脑”压死的，那会儿他不懂法，没证据，也怕，怕丢了工作，怕没了饭吃。可这辈子的他，背后站着一个连资本神都敢掰腕子的系统。

“钱总，法律不是您说了算的。”林一凡站起来，不慌不忙地掏出手机，翻到一条短信，“这是您说的。我这儿，还有咱们开会时的录音。我这个人，技术一般，就是喜欢存东西。”

钱总的脸色一瞬间变得铁青。

“你——你录了音？谁允许你录音的！”

“法律也没说开会不能录音啊。”林一凡笑了笑，“还有，钱总您可能忘了，您签过名批过‘阅’字的那份报告，原件在我手里，复件已经发到法务部邮箱了。您要是非说这是公司职务成果，那行，咱们走劳动仲裁，看仲裁委怎么判。”

他往外走了两步，又回头：

“哦对，还有一句话——您说过，效率小组今后的运营由我全权负责。那我就不奉陪您的‘教学课程’了，祝您生意兴隆。”

他推门出去，身后传来一声瓷器碎裂的巨响——那只八千八一两茶的金骏眉杯子，大概是碎了。

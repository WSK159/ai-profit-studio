# 第34章 数据铁证

林一凡盯着沈敛看了差不多十秒钟。

十秒钟里，他大脑飞速运转。前世的记忆中，深海资本在2027年确实投过一家叫“反卷科技”的公司，但后来被爆出那家公司是皮包公司，沈敛因此身败名裂——不对，那是星辰科技后来老板钱总找公关公司做的局。所以沈敛在2026年就已经开始动手了？前世的他没有跟沈敛打过交道，因为那时候他还没机会站在这个位置上。

“你想让我帮你搞钱总？”林一凡直接问。

沈敛很坦率地点头：“你有数据，我有枪。星海数据那边的事你也知道了。他们法务通过我转告你一句话：钱总在星辰科技内部那台服务器上，‘顺手’下载的数据远不止他们当初签合同约定授权的那部分。星海那边已经做了数字指纹比对，发现星辰科技把他们的用户行为数据用在了——”他从口袋里掏出手机，翻到一张加密图片，“——训练自己的风控模型上。这玩意儿一旦曝光，签的合同就是废纸。”

林一凡的心跳漏了一拍。

他太清楚这意味着什么了。星辰科技作为数据服务公司，核心业务就是跨境电商的数据分析。如果钱总私下把星海的数据喂给自家模型，那是实打实的违约和商标侵权的重罪。

但他的脑子很快冷静下来：“你手里有证据，为什么不直接爆出来？”

沈敛苦笑一声：“因为钱总手里也有我的把柄。三年前我投的一个项目，有一轮融资的出资人是钱总透过离岸公司参的股。股权结构里有一些……不太干净的条款。”他的声音变得低沉，“我现在爆他，他也可以反手把我送进去。”

林一凡明白了：“所以你需要一个‘白手套’——一个看起来跟他没有利益关系的第三方来拿这些证据。”

沈敛点头，眼神里带着一丝欣赏：“跟你聊天确实省力。现在的问题是——你敢不敢？”

林一凡没说话。他的脑海里，系统面板跳了出来。

【触发临时任务：盟友或陷阱？】
【选择一：接受沈敛的合作提议（奖励：解锁“职场博弈学”技能树一级）】
【选择二：拒绝并告知老王（奖励：提升“忠诚度”，但可能错失先手机会）】
【选择三：不表态，先拖住（奖励：无。风险：沈敛可能转投他人）】

林一凡扫了一眼三个选项，没有急着做决定。他想起上辈子那场大裁员，老王被叫进会议室时那张苍白的脸；想起自己在工位上敲着代码，手指发麻也不敢停下来；想起最后那个深夜，他第一次感到胸口发闷的时候，指尖的烟还没点着。

“自由值多少钱？”他问沈敛。

沈敛回答：“对没钱的人来说，自由很便宜——只要没人管就行。但对有钱的人来说，自由很贵——因为你要准备好随时舍弃一部分利益。”

林一凡咧嘴笑了：“那行。”他伸出手，“我接了。但我有个条件：星海那边的证据，我要最先看。我不是信不过你，我是信不过‘投资人’这三个字。”

沈敛愣了一下，随即大笑：“没问题。明晚十点，东城咖啡，有一份U盘给你。”

他转身走向停在远处的一辆黑色商务车，走两步又回头：“哦对了——你刚才那个开源发言，效果不错。但钱总已经让人把那段视频剪了，准备发到网上，标题就叫‘星辰科技创新工作法，全行业效率革命’。他打算把你的东西变成他的。”

林一凡一挑眉：“他敢？”

“他已经这么干了。”沈敛说完，拉开车门坐了进去。

黑色商务车驶出车库，尾灯在拐角处一闪而逝。

林一凡站在原地，摸出手机打开星辰科技的内部OA。首页赫然挂着一条置顶公告——

“关于举办第一届‘星辰效率创新大赛’的通知。欢迎各位员工积极申报‘新式高效工作法’相关案例，获奖者奖励十万元及晋升推荐信。申报截止时间——本周五。”

他盯着屏幕看了几秒，忽然笑出声来。

他还没答应开源，钱总就先把他路演上的东西换了个皮，当成公司内部的“创新成果”来收割。这是明晃晃的抢啊。

林一凡拨通了老王的电话：“王哥，明晚有空吗？带您去见一个人。顺便看一下……什么叫作死的最高境界。”

电话那头传来老王瓮声瓮气的声音：“又搞什么幺蛾子？”

“什么叫幺蛾子，这叫替天行道。”林一凡挂了电话，抬眼望向车库出口外的夜空。

不远处的星辰科技大楼，顶层那盏灯还亮着。那是钱总的办公室。

林一凡深吸一口气，把那包没抽的烟塞回兜里。他决定了——明天，就先让钱总尝尝“开源”的滋味。

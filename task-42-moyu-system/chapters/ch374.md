# 第374章 归零之前的笔记

电磁干扰声突然尖利起来，随即戛然而止。

收音机里只剩沙沙的白噪音，赵日天坐在水泥台阶上，手里攥着那枚旧怀表，拇指反复摩挲着背面那个圆形符号。符号刻痕陈旧，边缘被磨得发亮，显然被人长年把玩过。林一凡蹲在老人遗体旁，目光落在老人脸上——他的确跟赵春生有几分相似，尤其是眉骨的弧度。

“他临终前说‘你的脸’三个字。”林一凡声音压得很低，“我起初以为他是认出了你是赵春生的儿子，但现在想想，那三个字断句不一定是指你——”

赵日天抬起头：“什么意思？”

林一凡指了指老人的侧脸：“你看这里，眉骨上方有一道旧伤疤。我爷爷林守拙临终前也说过——‘眉上有疤的人，会替你把钥匙带回来’。”他顿了一下：“我一直以为说的是孙满仓，因为孙满仓当年就是带着钥匙走的。但现在我觉得，这句话可能说的是你父亲赵春生。”

赵日天沉默了几秒，低头打开怀表盖。表盖内侧嵌着一张极小的黑白照片，边角发黄卷曲，照片上是一个圆脸青年，穿着八十年代的工装夹克，咧嘴笑得很傻气。青年眉骨上，有一道浅浅的疤痕。

“这是我爸。”赵日天嗓子发紧，“他训练时摔破的。”

他缓缓合上表盖，随手拨弄了一下表盘侧面的小旋钮——咔哒一声，表盘弹开一道暗层。里面躺着一张叠得极小的纸条。赵日天愣住，小心翼翼展开，纸条上是一行铅笔字，字迹潦草但笔画有力：

“她说归零不是毁灭，是保存。信我，你父亲没有死。老孙。”

空气沉了下来。赵日天盯着“你父亲没有死”六个字，嘴唇动了动，然后又重复了一遍，声调提高了半分：“我爸……没死？”

林一凡没有说话，只是拿过纸条翻来覆去看。铅笔字迹边缘有被水浸过的晕染痕迹，但核心内容清晰可辨。他翻转纸条背面——右下角有极淡的一行字，像是后来补上去的：“小竹也活着。”

林一凡眼皮一跳。“小竹”两个字，是他们一路上反复出现的编号名。南洞墙壁刻字里的人名，铁皮柜认人之语中出现的称呼，甚至沈望失联前最后留下的一句“小竹在等我”——这个名字几乎贯穿了整条线索链。老人说小竹还活着，这一句话比任何机关都重。

“他是孙满仓。”赵日天声音沙哑：“他等的不是我父亲，他等的是一个答案。‘接的是钥匙还是我’——他是在问自己，当年从归零装置里取走的东西，到底是现实中的钥匙，还是他自己。”

外面忽然传来一阵机械运转的轰鸣声。头顶的水泥穹顶开始轻微颤动，落下一层细碎的灰。环形房间中央，那台归零装置的面板屏幕再次亮起，一行字滚动显示：

“零，不等于无。保存日期已届满。请外部载体在场确认。”

林一凡与赵日天对视一眼。他们同时想到同一件事——九枚外部载体，一路收集的水泥人形，以及最中间那尊转头的人形。外头还有七尊，其中一尊掌心的钥匙模印被取走的黑钥匙填补上了，剩下的，恐怕都在收容所各层。

“它要我们带它上去。”林一凡站起来，目光扫向墙壁上那一排刻字——从孙满仓的困守记录，到“她”留下的暗示，再到最末一行新出现的字迹：

“她在第三梯下方等你。”

字迹是新的。墨痕还很深。

赵日天也看见了，喉咙发紧：“谁写的？”

话音未落，台阶下方传来一声极轻的咳嗽。咳嗽声苍老，但带着笑意。

两人猛地转头。先前老人躺着的暗门走廊深处，多了一双布鞋。鞋面灰白，落满尘土，鞋口露出的脚踝上，套着一枚旧铁环。铁环表面刻着一圈细密的锯齿纹——和赵日天手腕上那枚环形锁痕，一模一样。

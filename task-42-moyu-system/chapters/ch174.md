# 第174章 双锁

林一凡没有急着上车。他站在咖啡馆门口，扫了一眼赵日天的车——车牌是新的，车身贴了防膜，连轮毂都换过。赵日天这一身行头，显然是在躲什么人。

“怎么，卷王混到现在连自己车都不敢开？”林一凡叼了根烟，走到车边，没坐进去。

赵日天把烟头摁灭在车窗沿上：“我前天半夜被人从住所摸到了门口，连内裤都翻了一遍。你猜他们要找什么？”

“钥匙。”

“看来你已经见过钱总了。”赵日天从怀里掏出一个牛皮信封，在手里颠了颠，“我手里这把是从老王离职前的工位暗格里找出来的。铜的，刻着半只眼睛。你还别不信——我把上面的锈迹做了同位素检测，至少铸造于三十年前。”

“三十年前……”林一凡咀嚼着这个时间点，“那时候星辰科技还没成立。”

“对。所以我顺着五金渠道查了一下，这批钥匙是同一家厂定的，一共三把，最后一次回厂记录是老周在系统里跑的。”

老周。林一凡脑子里嗡了一声——老周就是老王离职前带过的徒弟，上一世老周是最早发现公司考核系统漏洞的人，后来突然调岗去做了行政。

“老周还活着吗？”

“上个月调去华东售后中心了，活着。但他走之前给我留了一段代码，”赵日天把信封递过来，“这里面还有一把钥匙的照片，正反面都有。你拿去让季敏解一下锁芯结构——那个锁孔和普通锁不一样，左右不对称，我怀疑双锁机制的第二道不是插钥匙，而是刷‘物主验证’。”

林一凡打开信封，照片上的钥匙比钱总那把他抢下来的要短一截，但刻着的图案完全一致——半开之眼。他把照片收进怀里，抬头看向赵日天：“我替你去跑这件事。条件：第三把钥匙的消息，你给我。”

赵日天盯了他三秒，忽然笑了：“你跟我谈条件的时候，眼睛比上辈子亮多了。”他启动车子，临走前丢下一句话：“第三把钥匙不在公司里。——那个‘不加班’的名字，你查查。老王当年在离职报告里写了一行字，被HR压下来了，内容是‘不加班咖啡馆的招牌，是他自己烤的’。”

车尾灯消失在夜色里。

林一凡重新走回咖啡馆，“打烊”的牌子还没翻过来。他盯着那块招牌看了几秒——木质牌子，刻着“不加班”，字迹边缘有些毛糙，但一刀一划都是手工的。右下角，一个极小的图案被磨损了大半，凑近了看，是一只左眼半开的轮廓。

他回头看向店里，收银台后面那个姑娘已经不见了。帘子后的后间，圆桌上留下一张便签，字迹潦草但有力：

“牌子的背面，是老王刻的。他让我转告你——钥匙不是用来开门的，是用来锁自己的。”

便签背面，画着一把钥匙下压着一行小字：第三把钥匙的锁孔在服务器第三排第七列的最深处——但那个位置，在三十年前，是一间咖啡馆的招牌挂钩。

林一凡把便签折好放进贴身口袋。他站在空无一人的咖啡馆里，路灯从窗外照进来，正落在那台老式唱片机上。唱片机下方，积灰的托盘边缘，压着一小块黄铜色的边角——被磨得冰冷，握在掌心，正好是一截钥匙柄的弧度。

他握着那截碎片走出咖啡馆时，手机震动。屏幕亮起，一条未读消息来自一个陌生号码，只有四个字：“别找老周。”

他抬头，街对面一辆黑色轿车缓缓起步，没有亮车灯，消失在路口。

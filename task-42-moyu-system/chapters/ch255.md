# 第255章 钱总的影子

走廊尽头的黑色西装影子缓缓站起，灯光在那一瞬间跳了跳，像是整个十三楼都在害怕。林一凡眯起眼睛，隔着十几米的距离看清了那张脸——确实是钱总。但又不完全是。

钱总的脸还是那张脸，头发梳得一丝不苟，嘴角挂着公式化的微笑。只是他的眼睛，瞳孔中央有一丝极淡的金色光纹在流转，像是某种古老的东西透过他的身体在向外窥视。

“来了？”钱总的声音很低，却穿透了整条走廊，“二十年前我坐在这里等第一批拿钥匙的人，二十年后等来的还是你们这群……摸鱼的。”

他的目光扫过林一凡、老王、李思，最后落在陈建国身上，笑容彻底消失。

“老陈，你还活着？我以为那晚之后你就死了。”

陈建国佝偻着背，双手插在维修工服口袋里，声音像是从喉咙底部挤出来的：“我欠了秤房的命，走不了。你倒是活得挺好，把自己也当成秤房的一部分了。”

钱总没有接话，他抬手在空气中虚按了一下。林一凡视网膜上立刻弹出系统面板——

【警告：检测到资本市场权限介入。当前区域被“资本税”覆盖，所有咸鱼值收益降低50%。】

老王倒吸一口凉气：“我面板上多了一个负面状态。”

赵日天冷笑：“卷王系统的提示也一样，被压了。”

林一凡盯着钱总，脑子飞速转。前世的记忆片段和系统提示交错重叠——钱总是资本神的代理人，而第十三刻度是赌局的棋盘中央。他深吸一口气，往前迈了一步：“钱总，你在这里等了二十年，等什么？等人把三把钥匙插进去，好让你完成资本神给你的任务？”

钱总眼中金光一盛，随即又收敛：“小林啊，你还是这么爱猜。不过你猜对了一半。我等的不是你们打开门，我等的恰恰是你们打开门之后，那扇门后面的东西出来。”

“什么意思？”

钱总侧过身，露出身后金属门内的一间小屋。那是普通的办公室，一张桌子、一把椅子、一盏台灯。但桌上放着一台老式天平，天平两端各有一个托盘，一个托盘上放着一枚硬币，另一个托盘上放着一张薄薄的纸片。

陈建国身体一颤：“是那杆秤……”

“对，就是二十年前你要做手脚的那杆秤。”钱总走到桌边，指尖轻轻拂过天平底座，“劳动神的秤，用来称每个人一生的劳动与报酬是否等价。二十年前你试图调低自己的秤码，被秤房反噬，丢了命。从那以后你就只能在大楼里当维修工，每年多活一天就算赚一天。”

林一凡脑子里“嗡”的一声。陈建国日记扉页上那行“我偷了秤，秤收了我的命”终于有了解释。

“那钥匙呢？”李思握着009号钥匙，警惕地看着钱总，“三把钥匙开的是什么？”

钱总伸手示意他们走近。林一凡犹豫了一下，还是带头走了过去。三把钥匙——007、008、009——静静地躺在各自的锁孔位置，像是在等待最后转动。

但钱总没有转钥匙。他转过身看着四人：“钥匙开的是一个人工打造的平衡缺口。二十年前，劳动神和资本神的赌局天平倾斜过一瞬——那瞬间被我用秤房做了手脚，压住了这个缺口。只要三把钥匙转齐，缺口重新打开，天秤就会恢复平衡。但代价是……”

他顿了顿，目光落在林一凡身上：“我作为代理人的身份会被解除，资本神会直接介入。这不是一份报告的事，而是整个星辰科技、甚至整条劳动链上的所有人——包括你们四个——都会被强制清算。”

“清算什么？”赵日天皱眉。

钱总弯腰，从抽屉里拿出一个文件夹，轻轻放在桌面上。封面上写着“未完成劳动契约名单”，下面手写着一行字——最上面的名字是林一凡，旁边标注着“累计休息时间：三年四个月零十七天”。

林一凡的血一下子凉了半截。

那扇门之外，走廊尽头的窗户忽然“咔嚓”一声裂了条缝。一阵冷风灌进来，带着一股纸钞烧焦的味道，像是有什么遥远的东西正在苏醒。

钱总把文件夹推过来，声音平得发冷：“你要继续打开缺口，就先签完这份契约。不然，你们今天进来容易，出去——难。”

系统面板同时弹出：【紧急任务：选择。A.拒绝签字，强行进入缺口（触发资本神强制介入）。B.签字完成契约（放弃三年摸鱼时间，清空全部咸鱼值）。C.犹豫——倒计时开始。10、9、8……】

林一凡抬头看向那扇敞开的小屋门。里面除了天平，还有一扇更小的门，门上没有锁，只有一行用刀刻的字：自由与筹码，从来不会放在同一个托盘上。

赵日天的手已经按在面板上，低声问：“选哪个？”

林一凡的视线落在文件夹最下方的空白处——那里已经签了一个名字：钱不止。字迹被水渍洇开了一角，像是谁滴过一滴泪。

他没说话，把手伸向那支笔，但指尖碰到笔管的那一刻，系统倒计时跳到了0。

金属门轰的一声，从里面被什么东西撞开了。

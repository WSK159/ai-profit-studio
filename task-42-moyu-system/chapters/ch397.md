# 第397章 附加条款

青铜钉在掌心里纹丝不动，沉得像一块冰。

林一凡盯着白骨上那行纹章看了足足十秒，确认自己没有读错：“持钉者可免除一项债务，但需指定抵债者。”这八个字刻得极深，像是有人用指甲一点一点抠出来的。

“什么意思？”赵日天也凑过来，他的语气难得没了那股张狂劲儿，“什么叫免除一项债务？‘免除’是免谁的？”

无脸人形微微侧过脸。那张凝聚出的青年面孔——孙满仓的面孔——缓缓开口：“协议第七百零四号第三款：若青铜钉被激活，持钉者有权选择终止其中一项未履行的债务条款。”

“终止谁的？”林一凡问。

“任意一方。”

空气忽然静了。水牢顶部的钟乳石还在滴水，一滴、两滴，砸在潭面上，声音清晰得像锤子。

铁皮壳子胸口第二锁眼翕动着，那道裂缝里透出暗金色的光，缓慢而规律，像某种心跳。苍老的血印在钉身上微微发烫，林一凡甚至能感觉到青铜钉内部的震颤——它在等。

“所以这是一道三选一？”林一凡咧嘴笑了笑，“我这个拿钉子的，能挑一项债务——比如……”他瞟向铁皮壳子，“让它不用再当‘零’的宿主？”

铁皮壳子猛然震了一下。那些锈迹从它表面簌簌掉落，露出下面泛着青黑色的金属肌理。它胸口的锁眼张得更开了，露出一截白发——那根白发，和沈望未死后留下的那根一模一样。

林一凡瞳孔骤缩。

“别动。”他对着铁皮壳子轻声道，手指却捏紧了青铜钉。

“当然，你也可以选择让孙满仓的债务作废。”无脸人形接着说，语气平淡得近乎坦然，“持钉者可指定任何一方为‘抵债者’——也就是说，只要你说一声‘免除孙满仓的债务’，他剩下的半条命就不必还了。他可以彻底回归赵日天体内，作为一体双魂活下去，永远不必再担心被零吞噬。”

赵日天眯起眼睛：“那‘抵债者’是什么意思？免除一笔债，就得有人替我还另一笔？”

无脸人形沉默了片刻。“附加条款的原文说的是‘免除一项债务，但需指定抵债者’。关键词是‘指定’。你可以让另一个人来背这笔债，也可以自己背——字数虽然一样，因果却完全不同。”

林一凡冷笑了一声：“所以这就是你们的规矩？像高利贷换本，怎么滚都是你们赢。”

“协议公平。”无脸人形说，“从未强迫，只是代价自选。”

水牢深处忽然传来一声沉闷的敲击，像是有什么东西在更下面的水底用头撞着石壁。那声音极规律，一下、两下、三下——林一凡猛然想起，他之前下潜时在水底见过的那道“真身”——老杨头大哥被铸进铁底的东西。

铁皮壳子突然开口了。它的声音生涩、沙哑，像是锈铁相互摩擦：“别插……第二锁眼……还不到时候。”

林一凡的呼吸停了一瞬。这是铁皮壳子第一次主动说出一句完整的话。

“为什么？”赵日天抢在所有人前面问，“你到底是不是孙满仓的‘零’？你锁眼里的那根白发——你吞过沈望未？”

铁皮壳子没有回答。它只是把所有注意力转向林一凡，那双没有瞳孔的眼窝里，两点暗金色的光芒亮了亮——像是某种警告，也像是某种恳求。

“别插第二锁眼。那根钉子——不属于这里。”

林一凡低头看着青铜钉。钉身上的血印已经不再发烫，反而急剧转冷，冷得他掌心发麻。他抬起眼：“那它属于哪里？”

铁皮壳子没答。但白骨纹章上那行字忽然又浮出一层新的内容，像是水渍渗过纸背，那些字迹比刚才更清晰——就在“免除”二字的正下方，一个数字缓缓浮现：27。

赵日天猛地抬头：“图纸？你说的是图纸27？”

“不是。”林一凡盯着那个数字，瞳孔缓缓放大，“是——”他忽然停住，因为纹章上的数字开始变化，27之后，浮现出一个人名。

钱总。

水牢里，三个人形都静住了。

“……我跟钱总之间的那笔账，也算在协议里？”林一凡的声音平静，但他握钉的手已经开始发抖。

无脸人形沉默了三秒，然后说出了一个令所有人头皮发麻的答案：“钱总不是抵债者。他是收债人。”

“归墟的水底下，躺的不只是老杨头的大哥——”无脸人形的声音越来越轻，“还有钱总卖掉的半条命。第七百零四号协议，真正签约的一方，从来不是孙满仓——他签的是代持协议，钱总才是原主。”

赵日天的脸一下白了。他掌心的陶土徽章发出细微裂纹的声音，28号的数字在灯光下歪了一角——和图纸27的“27”形成了某种刺眼的对称。

林一凡看着青铜钉，又看着铁皮壳子胸口那根白发，最后目光落回纹章上那个“27”。

他忽然笑了。

“所以——钱总当年在这里埋的，是他的半条命。孙满仓替他守了百年，零镇的是他的东西。”他把青铜钉缓缓举高，“那我要是插进第二锁眼——激活的，也许根本不是孙满仓的协议。”

铁皮壳子躯干深处，传来一声极轻的、像是叹息的震动。

“而是钱总的债。”

林一凡的食指已经悬在锁眼上方。他感到铁皮壳子胸口的裂缝里，有什么东西在向他涌来——一股极寒、极沉的气息，带着铁锈、海盐和腐木的味道。他几乎能看见，那股气息里藏着一卷纸——图纸27，正面是机械结构图，背面是密密麻麻的手写名单，每一行名字前都画着一个小小的“×”。

最下面那行的名字，线条最深，像是用指甲反复刻过三遍。他还没看清，铁皮壳子已经猛然向前一扑，胸口的锁眼正对青铜钉的尖头，发出“咔”的一声脆响——

“别——”无脸人形的惊呼迟了一步。

青铜钉尖端已经触到了锁眼边缘，铁皮壳子主动迎上，两者的接触点爆出一圈白雾，将那卷纸影猛地冲散，露出一行字：

“钱方远，债务总额：完整的命。”

林一凡的手，停在了最后一毫厘。

他低头，看见钉尖和锁眼之间，隔着一根绷紧的银色发丝——是沈望未的，不知何时，它竟缠上了他的手腕，死死拉住了这一击。

“沈望未……”他呢喃着那三个字，没注意到铁皮壳子胸口的第二锁眼深处，亮起了一双眼睛——一双不属于铁皮壳子的、极为熟悉的眼睛。

是钱总的眼睛。

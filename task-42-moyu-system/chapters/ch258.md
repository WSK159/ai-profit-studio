# 第258章 契约醒了

“契约醒了。”

这四个字从“陈和平”嘴里说出来时，林一凡脊梁骨上的寒气从尾椎一路蹿到后脑勺。他后退两步，脸色沉得像铁：“你是陈和平签的那张契约本身？”

“陈和平”从档案柜里滑下来，赤脚站在积灰的水泥地上，低头看了自己一眼，脸上浮现出一丝陌生又好奇的表情：“有意思。二十年前她签我，我吞了她的命，她替我躺在这里。二十年里，我慢慢学会像一个人。”她抬起手，把额前碎发拨开，那动作流畅而自然，“你们叫她妹妹，叫她妻子，叫她女儿，叫她朋友——那些记忆，我都收着。”

陈建国浑身发抖：“你……把和平还给我！”

“陈和平”看向陈建国，表情平静到可怕：“她回不来。她从签下那一刻，就直接被收到‘命’账储备里了。她是第一个押进去的长期供应商。”

“供应商？”老王瞪大眼睛。

“陈和平”点点头：“赵日天的卷王系统消耗命账，你哥的命债抵押也在同一本账里。那本账的名字叫‘天平储备’。我只是其中最老的一份契约，专门负责在那本账上登记每一笔进出。”她顿了顿，看向林一凡，“我叫自己‘笔’。因为我是第一个被写上去的名字。”

林一凡瞬间想起系统之前提示的：“赵日天卷得越狠，陈建国死得越快”——他们都签在不同的契约上，但命账是同一本。而眼前这位，是账本里最早的那支“笔”。

“所以，”林一凡声音嘶哑，“你从陈和平身体里醒来，不是因为她醒了，而是因为——”他看向钱总，“天平缺口开了。”

钱总已经走进暗门，把钢笔别回胸口，一手插兜：“没错。笔醒了，账就算得清了。”他抬手指向外面，那台银色天平正缓缓倾斜，巨大的横梁上浮起一行行若隐若现的金色数字，像有人在空气中书写账目。

系统没有任何提示介入——林一凡已经没有商城权限了，它变成了哑巴。

“赵日天。”林一凡转头，“你在干嘛？你的卷王系统还有多久？”

赵日天脸色铁青地看着自己手腕上的虚拟倒计时：“……清零了。停了。系统说找不到目标，停摆。”

“因为供应断了。”钱总淡淡地说，“赵日天卷了多久，命账就扣了多久，但扣的那些量，虽然能让天平储备缓慢增长，却不足以让它真正动起来。而今天，三分钟内……”

“还有两分钟四十秒。”陈和平——或者说，契约笔——平静地报时。

“你们到底要算什么账？”林一凡压着声音问。

钱总没有回答。他看向陈建国：“陈大哥，你妹妹替你签的命债，本金是二十年。你还了十七年，还剩三年。这笔账，你要不要现在就算清？”

陈建国的眼睛红了：“怎么算？”

钱总拍拍手：“简单。你妹妹的契约醒来了，只要你愿意顶替她成为新的‘笔’，把剩下的三年命账补齐，你妹妹就可以从命账储备里释放。她的意识会回到这具身体里。”

“真的？”陈建国往前走了一步。

“假的。”老王猛地拦住他，“老陈你醒醒！他说的是你替她，她回来，那就成了——你得躺进这具身体，让她经历的下一个二十年可能变成你！”

陈建国僵住了。

林一凡脑中飞速运转：赵日天卷王系统停摆，老陈的命债还在被扣。天平缺口已经打开，钱总说三分钟内必须落子——资本神和劳动神的赌局，落子的是谁？

“钱总。”林一凡忽然抬头，“这局棋，你下的是哪一方？”

钱总愣了一下，然后笑了：“小子，你终于问到点子上了。”他抬起手，掌心浮现一枚金色硬币，硬币上刻着一个“资”字，“我替资本神落子。而你的系统——”他看向林一凡空荡荡的胸口，“曾经替劳动神落子。但现在你放弃了商城，你自己没了资格，可你手上还有另一枚子。”

“什么子？”

“010号钥匙。”钱总盯着他，“你用它开了暗门。那道门不是通往负三楼的，是通往‘天平的第三刻度’的。你已经把第三刻度的钥匙插进锁孔了——现在，天平的两端各有一子，第三刻度是自由。”

林一凡低头，掌心里那把010号钥匙正在发热，手柄上的纹路一条条亮起，像某种程序在自我解码。他脑中忽然浮现出那张纸上的“等”字——正面是陈和平写的“等”，背面写着“等不到”。

如果第三刻度是自由——“等”的意思，是在等第三个落子的人？

“陈和平”忽然开口，语气里带着一丝奇异的变化：“林一凡，那张纸……”她顿了顿，眼中闪过一丝波动，“背面最后一行，不是‘等不到’。”

林一凡猛地看过去：“那是什么？”

“陈和平”垂下眼，像是从未被自己身体里的记忆打断过：“……我替你改了三个字。”她轻声说，“最后那行写的是：‘等到了’。”

林一凡全身雷击。

那张纸的背面——所有狂乱的字迹，第一行是“等哥来”，最后一行，竟然是陈和平在某个瞬间清醒时写下的两个字。

“等到了。”

她等的不是陈建国。她等的是一把钥匙，一把能从“天平”上把她换回来的钥匙。而那位拿钥匙的人——是林一凡。

钱总收起了笑：“时间到了。天平已经逼到这个位置——要么老陈进账当笔，要么那把钥匙的主人顶替成为第三个落子者。”

林一凡慢慢握紧010号钥匙。他抬头看了一眼陈建国，又看了一眼“陈和平”眼中那道不属于契约的微光，最后目光落在钱总脸上。

“我选第三个。”

数秒后，那台天平上的横梁剧烈晃动，金色字母与银色字迹轰然碰撞——而林一凡的脑子里，那个沉默的系统，忽然发出一声他从未听过的叹息：

【……你终于站在秤的中央了。】

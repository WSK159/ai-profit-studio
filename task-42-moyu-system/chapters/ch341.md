# 第341章 南洞

云顶山南麓的废弃排水隧道藏在一条几乎没有路标的野径尽头。林一凡三人把车停在半公里外，徒步穿行于没膝的荒草中，脚下碎石沙沙作響。

夜色刚刚开始吞噬最后一丝暮光，隧道入口像一个张开的黑色喉咙。洞口上方锈蚀的铁栅栏被掰开了一半，露出黑黢黢的内腔，空气里弥漫着陈年铁锈和湿润泥土的味道。

孙满仓打着手电筒走在最前，光柱扫过湿滑的洞壁，映出大片暗绿色苔藓。赵日天跟在最后，时不时的回头张望，像在确认什么。

“三十米。”林一凡数着步数，在手绘图上比划，“应该就在前面。”

手电筒光在洞壁深处扫到一片与周围不同的灰白色水泥面——不同于天然山体和旧砖砌结构，那是一块后期浇筑的混凝土面板，差不多一人高，宽度约两臂。

面板中央有一道细缝，缝里卡着暗红色铁锈。缝的形状……像一道门。

但不是镇子老宅地窖那种木门，也不是防空洞的铁闸门。这道门很窄，很矮，像通往地下的“竖井封口”。

林一凡蹲下身，摸到混凝土面板下沿的一处凹陷，形状，恰好和那把黄铜钥匙的轮廓一致。

“找到了。”他的声音在隧道里回荡，尾音带颤。

赵日天走近几步，眉头拧得很深：“这门后面有东西，而且……有活物的气息。”

林一凡没犹豫，把黄铜钥匙插入凹陷，顺时针拧动。“咔哒”一声后，面板发出沉闷的低鸣，整片混凝土向内缓慢退开，露出一条向下延伸的阶梯。

潮湿的风从下方涌上来，带着一种奇异的、类似海风般的咸味。明明这座山离海有几十公里。

孙满仓率先踩下去一阶，手电筒往下一照，阶梯尽头的空间忽然亮起微弱的光——那是一种冰冷的冷白色光，像某种自发光涂料或深埋的荧光石。

“下去看看。”

三人踩过两级台阶，密道突然收窄，墙壁变得光滑平整，像某种高精度加工过的材料，而非山体岩层。林一凡伸手摸了一下墙面，冰凉的触感让他毛发倒竖——这不是天然形成的结构，是人工制造的深层空间。

通道尽头出现一扇白色金属门。

赵日天停在门前，脸色难看：“就是这扇门。我死的时候，你爸就是站在这扇门前跟我说话的。”

林一凡咽了口口水，抬手轻推。

门没有锁，缓缓滑开，露出一个大约二十平米的空间。四面墙壁嵌满架子和抽屉，像一间被遗弃多年的档案室。中央放着一张金属桌，桌上摊着一本打开的笔记本，还有一枚被相框扣住的黑白照片——照片里是一个女人，眉眼模糊，但能看出安静而温柔的轮廓。

照片底部的签名字迹让林一凡瞳孔骤缩——

“小竹”。

孙满仓在门口惊呼一声，嗓音发软：“这是……小竹姐？”

林一凡顾不得回应，伸手拿起笔记本，翻开第一页。纸页泛黄，字迹是父亲的笔迹。第一行只有四个字：“她回来了。”

他翻页。

“她回来了，但她说她不是来拿钥匙的。她说她是来送钥匙的。”

“第三扇门打开的不是山，是锁。锁住的东西不是别的，是一个人的名字。”

“零——是名字，不是代号。她叫沈零。”

“她是我妹妹。”

林一凡的手指僵住。

父亲的妹妹？他从未听任何人提起过自己有一个姑姑。

他翻到下一页，字迹变得更加潦草：“沈零三岁时被爷爷送出家门，说送去‘那边’。爷爷死前告诉我——她不是被送走的，是被抢走的。被一个穿灰袍的人带走了。”

“灰袍人……”林一凡喃喃，这三个字如雷贯耳，前些日那份发黄档案里的记录、灰衣男人的身影、监控截图上的模糊轮廓——全部串联起来。

再翻一页，只剩一行字，像是最后时刻匆匆写下的：“如果她回来找你，告诉她——门已经开了，她自由了。”

林一凡读完最后一个字，手机猛然震动。

【隐藏任务“归还自由”第三阶段已解锁】

【目标更新：找到“零”的锁。】

【提示：锁不在山上，不在山下，在密码里。】

“密码？”林一凡皱眉，目光扫过桌上的笔记本。

笔记本合上的一瞬间，他注意到封底内侧夹着一张薄薄的纸片。展开后是一串数字——

“27-08-1996”。

赵日天凑过来看了一眼，瞳孔骤然放大：“1996年8月27日……这是小竹离开云顶山的那个日期。但密码不该是日期，日期太简单。”

“等等。”林一凡把纸片翻过来，背面还有一行极小的字，像是被手指反复摩挲到几乎磨灭：“陶土徽章，九枚，27。”

“陶土徽章？”林一凡想起自己见过的那枚数字“27”徽章，他猛地攥紧那张纸，“九枚徽章。九把钥匙。二十七这个数字……是总密码的一部分？”

孙满仓突然插话：“老林以前跟我说过，他做过一套徽章，叫‘九子同心’，一枚给一个人。加起来刚好九个人，八枚送出去，一枚留下。”

林一凡心里那根弦猛地绷紧：“留下那一枚……现在在哪里？”

孙满仓沉默，嘴唇翕动了两下：“在他棺材里。”

密道深处突然传来一阵细微的脚步声。不是他们三个人的。

赵日天猛地转身，手电筒的光柱扫向门外通道。

白色的门沿处，一双旧布鞋出现在光柱的边缘——停在那里，一动没动。

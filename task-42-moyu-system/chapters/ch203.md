# 第203章 陈默的底牌

上午十点，阳光透过会议室百叶窗在林一凡脸上割出几道明暗。

他刚坐下，陈默就推门进来，手里拿着一叠纸质文件，反手把门锁上了。行政部的监察员锁门，这动作本身就透着不正常。

“林工，我想你应该收到了老周的纸条。”陈默开门见山，语气不冷不热。

林一凡没急着接话。他默默调出摸鱼雷达，视野里陈默头顶的数字跳动着——劳动浓度87%，不算高也不算低，但让她整个人笼罩着一层淡淡的光晕。陈默身上的“摸鱼状态”图层很薄，薄到几乎看不到，可雷达显示她周围有一圈微弱的“自由值”波动，这种波动只有系统拥有者才会散发。

“两周前我在监控室调录像，发现设备层杂物间的摄像头被人动过。”陈默把文件推到林一凡面前，“四个摄像头，同一时间，画面全被循环覆盖。我去查了硬件日志，是有人从物理层做的。”

林一凡扫了一眼文件，上面是一串他看不懂的硬件编码，但有一行他看得懂：操作者工号，10666。那是他上辈子在另一个公司用的工号，这辈子还没来得及录入系统。他猛地抬头：“你查我？”

“我查的是数据。”陈默纠正他，“10666这个工号在星辰系统里不存在，但它作为‘访问凭证’出现在杂物间门禁记录里三次，每一次都对应你加班到凌晨的日子。我查了你的打卡记录，那三天你都在园区过夜。”

她停顿了一下，从文件底部抽出一张照片——设备层配电箱背面，贴着一张指甲盖大小的黑色贴片，它在照片上被红圈标出。“这个，是原始意志机的信号中继器。老周装的原版已经坏了三年，但有人把它修好了。”

“谁修的？”

“你说呢？”陈默看着他的眼睛。

林一凡心里翻涌。老周说图纸在他手上，陈默有另一半钥匙，但他对原始意志机的现状一无所知——他连这台机器长什么样、在哪、干什么用都还没弄清。他选择实话实说：“陈监察，我不知道谁修的。老周昨天才把图纸转给我。”

“我信。”陈默意外地干脆，“老周上周跟我见了一面，说要‘找个可靠的人把钥匙带出去’，让我到时候配合。”她嘴角弯了一下，带着一点苦涩，“你是他挑的。”

“那你呢？你也是系统持有者？”林一凡问得很直。

陈默沉默两秒，从口袋里掏出一枚硬币放在桌上——正面是劳动神的铁锤，反面是资本神的金杯。她用拇指一弹，硬币在空中翻转六圈，落下来时金杯朝上。她没碰硬币，只是看着它：“我是‘平衡者’。不站劳动，也不站资本。只保证两边这盘棋，走完它该走的流程。”

“所以你的另一半钥匙，是准备给我，还是给赵日天？”

陈默收回硬币，从西装内袋里取出一个拇指粗的金属圆柱，表面有螺纹，像一支老式钢笔的内芯。她放在桌上，推到林一凡面前：“老周说你是‘唯一能扛住反噬的人’。”她把“反噬”两个字咬得很轻，像怕被谁听见，“如果你决定接，这半钥匙就是你的了。”

林一凡盯着那枚金属圆柱，没有伸手。

雷达里，陈默头顶的光晕忽然闪了一下，然后她开口，语气里带着一种近乎怜悯的平静：“林工，你是不是觉得你的摸鱼系统是白送的？”

这句话像一根针，直接扎进他没做过预案的空白区。

他确实从没想过这个问题。上辈子猝死那一刻，系统凭空绑定，他以为是上天给的赔偿金。可现在回顾——劳动神与资本神的赌局、钥匙、反噬、倒计时——这套东西怎么看都不像单纯的“给”。

“什么意思？”

“摸鱼系统，是劳动神用你自己的命做的抵押品。”陈默站起身，“你重生回去的那一天，就是你押进去的筹码。如果你最终拿不到‘自由’，你的下辈子也在赌局里。”

她转身走向门口，停了一下：“七天，原始意志机启动之后，钥匙会自动合并。你手里那一半代码，加上我这一半实体，缺一不可。”

门开了又关。

林一凡独自坐在空荡荡的会议室里，手里握着那支冰冷的金属圆柱，像握着一枚不知道什么时候引爆的定时炸弹。他忽然想起老周留下的纸条背面，在那行“钥匙分两半”下面还有一行极小的字，被墨迹洇得几乎看不清。

他原本没注意，现在把那行字凑到灯下仔细辨认，心脏猛然收紧——

“硬币哪面朝上，决定你重生的方向。”

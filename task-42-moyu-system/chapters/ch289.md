# 第289章 鱼骨背面

地下车库的光线昏黄，几盏感应灯在头顶忽明忽暗，像是随时要断气的病人。我蹲在那扇没有编号的铁门前，手里攥着那张A4纸，纸边缘被我捏得微微发皱。

正面是一排打印体数字：2014.03.21，SG-ST-0421，入库编号，盖章模糊。翻过来，鱼骨简笔画，线条干净利落，和母亲曾经在微信里发我的那张一模一样。我记得那是2019年6月，她说她在学画画，画了一条鱼，问我像不像。我当时回了一句“妈你这画的是梳子吧”，她气得好几天没理我。

但此刻我盯着这条鱼骨，忽然意识到一个细节——母亲发我的那张图，鱼头朝左，鱼尾朝右，七根肋骨，尾鳍分叉。而这张A4纸上的鱼骨，同样是七根肋骨，尾鳍分叉，但鱼头朝向右侧，像是镜像翻转。

问题是，我从来没注意过方向。画图的人为什么要镜像？除非这张图根本不是母亲画的，而是有人故意模仿她的画风，留下线索。或者，这条鱼骨的朝向本身就是一个提示——反向，倒转，和那块怀表倒走的指针一样。

我掏出怀表，“咔哒”一声弹开表盖。银白色表盘上，指针依旧逆时针走动，发出细微的“咔嗒咔嗒”声，像是某种密码节拍。表背“000712”的刻痕在灯光下泛着冷光。我盯着那串数字，忽然觉得它有别的读法——不是“零、零、零、七、一、二”，而是“叁号，第十二件”。000是编号，712是序号。第000号植入体，第十二件藏品。

走廊尽头传来电梯门开合的声响。我迅速把A4纸折好塞进内袋，怀表合盖收入裤兜，起身装作在看手机。灰工装老头从电梯里走出来，手里拎着一个白色塑料袋，袋子里露出半截面包的轮廓，像是刚从便利店回来。

“找到了？”他语气轻描淡写，仿佛我们之间的对话从未中断过。

“你看过这张纸？”我没有回答他的问题，直接把话头截断，“你看过上面的鱼骨。”

灰老头脚步顿了一下，偏头看我，浑浊的眼睛里闪过一丝说不清道不明的光：“我只负责告诉你纸在哪里，没说过我没看过。”

“那你知道这鱼骨什么意思。”

他咧嘴笑了一下，牙齿黄得均匀：“你妈画东西有个习惯，画完总爱在角落里写个日期。你仔细看，鱼骨旁边有没有淡淡的铅笔印？”

我愣住，重新掏出A4纸，翻到背面，对着灯光眯起眼睛。鱼骨线条的下方角落里，果然有一道几乎看不清的铅笔痕迹——那不是数字，也不是字，而是一个很小的符号：一个圆，中间一横。

零。或者，圆环。

“这是什么？”我问他。

灰老头把面包往嘴边送，嚼了一口才含糊地说：“我不知道。我只知道，你妈把这张纸交给我的时候，说了一句话。”

“……什么话？”

“她说，如果有一天她儿子拿着怀表来找我，就把纸给他，告诉他——‘鱼骨的第七根肋骨是假的，但钥匙是真的。’”

第七根肋骨？我低头数了数鱼骨上的线条，从左到右，第七根，确实比其余六根粗了一圈，而且末端不是尖的，是平的，像被刀切过。我伸手摸了一下，指腹忽然感到一丝粗糙——那根肋骨的线条中间，有一道极细的缺口，像是用刀片划开过纸面。

我下意识用指甲沿着那道缺口挑了一下，纸面裂开一道缝，里面露出一截极细的金属丝——银色，比头发丝粗不了多少，蜷曲成弹簧状，被纸层夹层压得扁平。

“这……”我抬头，灰老头已经走出去三步远，背影在灯光下拉长。

“别问我为什么在你妈纸里藏东西。”他没回头，“我只是个跑腿的。你该关心的，是谁把纸交给我的，以及你为什么觉得这是你妈画的。”

我攥着那根金属丝，大脑飞速运转。母亲画鱼骨图的日期是2019年6月，但A4纸上的入库编号是2014年3月。也就是说，这张A4纸在2014年就已经存在，而母亲在2019年画的那张“鱼骨图”，很可能不是在学画画——她是在临摹。临摹五年前留在一张某扇门后面的纸上的图案。

那个“圆”中间的“横”，此刻忽然有了新的解读——不是零，而是切开的剖面。一条被切开脊背的鱼，露出脊椎。

银色的金属丝在指间泛着寒光。我忽然明白它像什么了——手术缝合线。医用不锈钢缝合线的材质，一毫米内径的韧性和柔度，比头发丝粗，但比普通钢丝细。有人在A4纸的夹层里藏了一根手术缝合线。

“000712”这个编号忽然在我脑海里炸开另一种排列组合——000号植入体的第十二次手术记录？第七根肋骨对应的，正是心脏缝合手术的入路——胸骨正中切口，第七肋间隙。

我猛地抬头望向灰老头消失的方向，走廊尽头空无一人。他什么时候走的？我甚至没听到脚步声。我低头看向那根金属丝，指尖微微颤抖。

“钥匙是三把，但你只有两条路。”老头的回话在耳边回响。现在它带上了第二种含义——手术刀切开的是缝合线，但缝上的是什么？谁的心脏被这根线缝过？我忽然想到走廊尽头自称林一诺的那个女人说过的话——“你妈没有死，但你妈也不再是她了。”如果她的身体被某个核心载体替换过，那么缝合线，就是那台手术留下的痕迹。

而母亲在2019年画鱼骨图，目的是在练习——把2014年那台手术的缝合方式，复制在一张给人看的纸上。

一阵冷风从地下车库深处灌过来，卷起地上的灰尘。我听见极远处的某个地方，传来一声微弱的金属碰撞声——“叮”，像是手术钳碰到不锈钢托盘的声音。

现在，凌晨四点十七分。

我该走了。

我把缝合线小心地绕在怀表表壳内侧的夹层里，合上表盖，金属碰撞发出“咔”的一声轻响。远处那道金属声再次传来，更清晰了一些，像是有人在敲击通风管道的内壁——有节奏的三短一长。

三短一长——摩尔斯电码。SOS。

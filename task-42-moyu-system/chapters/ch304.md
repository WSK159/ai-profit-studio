# 第304章 黑色轿车的注视

杂草丛里的风带着铁锈味，林一凡蹲在废铁堆后面，指尖还残留着那枚梅花形钢丝的温度。远处那辆黑色轿车停在土路尽头，引擎没熄，尾灯在暮色里浮着两粒暗红。

“认识那车吗？”沈稚冬压低声音，身子贴着锈蚀的车壳，手里握着那台老式录音机。

林一凡眯起眼。黑色轿车贴着深色膜，看不清里面几个人，车牌却被一张脏兮兮的牛皮纸糊住一角——刻意遮挡。

“不认识。但能追到老宋这地方来的，八成不是路人。”

林一诺的声音从折叠屏里传来：“声音频谱比对完成，车内有至少两人。其中一个的呼吸频率，和刚才撞门那家伙一致。”

赵恒。

林一凡攥紧衣兜里那枚05号黑钥匙，冰凉的金属硌着掌心。他原以为赵恒早在前几轮博弈里被清理出局，可老宋刚才那句“赵恒是活的”还在耳底嗡嗡作响。活人怎么可能在那儿？

“走。”他低声说，“从河沟那边绕，沿废铁站背面的围墙，东头有个排水涵洞。”

沈稚冬看了他一眼，没问“你怎么知道”，只是抱着录音机跟上来。夜色吞掉他们的影子，杂草刮过裤腿发出沙沙声响。走出去百来米，林一凡回头——那辆黑色轿车依然停在原位，尾灯灭了。

没人下车，没人追来。像一蹲蹲着的兽，等着猎物自己走近。

排水涵洞里积着黑水，两人趟过去，水深到小腿肚，凉得刺骨。林一凡不敢开手机灯，只能靠摸鱼雷达的微光感知周围。雷达显示沈稚冬的“劳动浓度”只有12%，紧张却不高，和他并排的时候心跳很稳。

“你锁屏上那钥匙照片，”林一凡终于开了口，“哪儿来的？”

沈稚冬脚步顿了一下。涵洞里的回声把他的呼吸放得很大。

“我哥留下的。”他说，“他一直留着所有钥匙的照片。老宅、办公室、保险箱、车……他把每把钥匙都刻了编号存成照片，说有一天会用上。唯独这张五瓣梅花的，他标注过‘最后一把’。”

林一凡心里咯噔一声。系统此刻毫无征兆地弹出一行淡蓝色的字：【钥匙序列01/03/05已激活。剩余钥匙信号源：距离宿主约1.2公里，移动中。】

一公里二。移动中。

“钥匙在你身上？”他脱口而出。

沈稚冬愣住了，随即摇头：“没有。但我锁屏上这张照片，是在我哥遗物里发现的——他自己也没拿到那把钥匙，只拍下过它三秒钟的影像。”

系统又弹一条：【信号源移动速度：7.2公里/时。方向：正西。**

正西。朝他们刚刚出来的废铁站方向。

林一凡骤然停住脚步，汗顺着背脊滑下去。那辆黑色轿车停的位置，恰好也是正西。

“他们不是来追我们的。”他声音发紧，“他们是在等——等那把钥匙自己送上门。”

沈稚冬一凛：“什么意思？”

“最后一把钥匙已经激活了，就在那辆车上。”林一凡盯着涵洞尽头漏进来的微弱天光，“赵恒活着，来拿老宋手里的东西。可钥匙序列启动了，他知道全世界的系统持有者都标记了方位——1.2公里外，移动中。他自己身上带着一把。”

涵洞里静默了两秒。沈稚冬忽然说：“我哥当年拍那把钥匙的地方，是我家老宅阁楼。他留了一张字条在照片背面，用铅笔写的，时间是——”

他从防水袋里抽出那张照片，翻过来，借着微光，林一凡看见两行幼圆字体：

“五瓣梅花能开一切门，除了它自己那扇。别让她进阁楼。”

“她？”林一凡皱眉。

沈稚冬沉默片刻，轻声说：“我姐。沈稚夏。”

一个名字砸进脑子里，林一凡的系统面板猛地闪了闪，像接触不良的旧灯泡——摸鱼空间最深处那道从未打开过的门，门缝里透出红光，和暗间那口铁皮柜缝隙里的光一模一样。红光里浮着一个没有五官的人形轮廓，人形手指上套着一枚五瓣梅花形的戒指，戒指戴在左手无名指。

林一凡后脑勺炸开一阵刺痛。

他见过这枚戒指。在他母亲留下的一张旧照片里——那张照片的边缘已经被裁掉一截，只露出母亲的手搭在一个人的肩膀上，那人左手无名指上戴着模糊的五瓣梅花戒指。

“你姐，”他听见自己的声音干哑，“现在在哪儿？”

沈稚冬还没回答，涵洞外的地面忽然被车灯照亮了。白色灯光从洞口灌进来，像一道流动的刀。他们身后，涵洞另一头，一个脚步声踏进水里，不紧不慢，水花溅开，一声接一声。

林一凡攥紧05号黑钥匙。摸鱼雷达在视野边缘疯狂闪烁——那片红光越来越亮，系统终于弹出一行剥落大半的旧字：

【记忆碎片·第000号载体——启动确认。宿主激活条件：持有两把以上钥匙，并踏入“出生地”范围。警告：该载体包含非本系统数据，读取可能触发……】

后面几行字被乱码吞掉了，像被时间啃过的纸页。

涵洞两端的脚步声越来越近，车灯刺得他睁不开眼。沈稚冬忽然抓住他手腕，把那张照片翻到正面，指向五瓣梅花钥匙的齿纹底部。

那里有一串极小的数字，林一凡屏住呼吸凑近看。

“0112……”

没等他读完整串，涵洞东口的脚步声忽然止住了。一个沙哑的声音飘进来，带着老式磁带机特有的底噪：“小冬，东西拿到了，就过来。哥不走。”

沈稚冬整个身子僵住了。

那声音——沈稚冬用气音说出那三个字：“我哥……沈稚秋。”

林一凡猛地回头。涵洞西口，车灯后面，一个高瘦的人影背着光站着，左手空荡荡的袖管在风里晃——赵恒当年抢走的那只手，此时正安静地垂在沈稚秋的右肩上，像一条不属于他的装饰。

而那兜里的05号黑钥匙，开始发烫。

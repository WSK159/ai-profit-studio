# 第345章 守门人的代价

女人站在门外，并没有急着进来。

她的目光越过众人，扫过小室里的每一个角落，最后停在地上的旧布鞋上，眯了眯眼。那眼神像在确认什么东西还在原位，然后才收回视线，重新打量林一凡。

“你比你爸沉得住气，”她说，“至少你接住徽章的时候没跳起来。”

林一凡握着那枚黄铜徽章，金属的凉意从掌心渗进骨头。31号的触感与陶土徽章截然不同——更沉、更冰凉，背面不光滑，像是刻了字。他翻过徽章，借着灯光看清背面的刻痕：

“守门人——沈稚冬，1985年8月27日立。”

沈稚冬。

磁带里那个陌生男声提到过这个名字——“沈稚冬没有来过”。而孙满仓曾与沈稚冬师徒一场，后来师父去世，留下一阴一阳两枚钥匙。

可现在，一枚刻着沈稚冬名字的“37号”徽章，却出现在一个自称“最后一任保管员”的女人手里。

“我师父——”林一凡抬起头，直盯着女人的眼睛，“您是说我外公？”

“不是你外公。”女人摇头，“我师父姓顾，顾长生。他是三十七号项目的副总工程师，也是你外公的师弟。”

顾长生。这个名字陌生得让林一凡无从接话。孙满仓却像被什么狠狠扎了一下，脱口而出：“顾长生？他他还活着？”

女人转头看他，目光里带着一丝复杂的意味：“孙师兄，我师父八年前就去世了。”

“八年前……”孙满仓喃喃重复了一遍，脸色很不好看，“那我七年前给他上香的时候，怎么没人告诉我那是活人？”

空气像被抽走了。那女人的表情依旧平静，但她握着黑皮包的手收紧了一点。

“因为师父当时已经没有‘活着’这个概念了。”她说，“他去世那天，我和他一起在三十七号的地下机房里。他最后交代我三件事——第一，保管好37号徽章；第二，把这封信交到沈零手里；第三……”她顿了顿，目光落在林一凡身上，“如果沈零不在，把信交给沈零的外甥。”

她说着，拉开黑皮包，取出一封黄褐色牛皮纸信封，上面没有署名，只画着一个符号——九兽首尾相连，中央一个数字“37”，和徽章上的图案一模一样。

林一凡没有立刻接过信封。

他看着那女人：“您怎么知道我在这里？”

女人淡淡一笑：“我不知道你在这里。但我找了你三十七天——从九月一号开始，每个周三我都会来一次云顶山，在洞口放一枚陶土棋子。”她说着，从口袋里摸出一枚磨得发亮的白色陶土棋子，“这是第九枚。我原以为今天还是白跑一趟。”

她说话的语气轻描淡写，好像在讲一件早就不值得着急的事。

林一凡却觉得后背一阵发麻。“九月一号”正是他重生回入职第一天的前一天。她从那时候就开始找他——在一个他“还没有回来”的时间点上，她已经知道了他的存在。

“谁告诉您，九月一号开始的？”赵日天替林一凡问出了这句话。

女人转头看向赵日天，目光在他脸上停了很久，像是在辨认什么，然后缓缓点头：“你长得像你妈。”

赵日天脸色瞬间变白。

“别紧张，”女人说，“我只是认识你妈。她在沈零失踪之前给我打过一通电话，说你可能会被卷进来，让我心里有个数。”

林一凡瞥了赵日天一眼，没有追问。他知道有些话不能当着外人的面摊开——赵日天“死过一次”的真相，不是每个人都有资格听。

“信。”他伸出手，“给我吧。”

女人却没有递过来，而是把信封竖起来，正对着林一凡的眼睛：“你先回答我一件事——你外公的铁盒，你有没有去找过？”

“还没有。”

“那就先别去。”女人把信收回去，重新塞回黑皮包里，“等你找到‘第一把钥匙’再去找那个铁盒。顺序不能错。”

“为什么？”

“因为铁盒的指纹锁，认的不是你。”女人的声音低下来，带着一种令人不安的平静，“它认的第一个指纹，是你爹的。第二个指纹，是你妈妈的——但那个指纹已经失效了。如果顺序错了，第三次锁定之后，盒子里的东西就永远拿不出来了。”

嗡。嗡声在脑内。

林一凡想到了父亲信里那句话——“门开时让我进去，你在外面等。”父亲早就知道指纹锁认他，他要亲自去开那个盒子。

可父亲死了。棺材里的那枚徽章到底是哪来的？又是谁把徽章放进去的？

他的思绪还没来得及理清，女人忽然侧耳朝密道方向听了听，表情一变。

“有人来了。从北边的入口，走得很快，脚步声很稳，是练过的。”

孙满仓立刻弯腰吹灭小室里的灯烛——但那不过是一支从背包里拿出的蜡烛，小室的主要照明是那盏白炽灯。他转向门口：“走，先回铁板通道。”

女人却摆手：“你们走。我留下来。”

“为什么？”

“因为来的人，是冲我来的。”她从风衣内袋里抽出一样东西，是一个巴掌大的、锈迹斑斑的铁皮盒子，上面的指纹槽已经被磨得发亮，“这盒子，我从三年前替师父保管到今天。我师父说，里面是一份三十七号项目的‘第七份机密’——只有‘第二个进门者’才能打开。”

她说着，把铁盒塞进林一凡手里，又利落地把黑皮包带子往肩上一拉：“你们从南洞的排水渠走，出口在云顶山后山竹林。”

“那您——”

“我会把来的人引开。”

她说得斩钉截铁，没有再解释的余地。

林一凡攥紧铁盒，嘴唇张了张，想问她的名字——但她已经转身迈入密道的阴影中，只留下一个声音在通道里回荡：

“我叫顾七。如果三十天后我还没去找你，你就去城北老铁匠铺，说‘三十七号，守门人，接引后人’——他们会带你去见一个人。”

“谁？”

“那个帮你父亲抬棺材的人。”

脚步声远去。

林一凡、孙满仓、赵日天三人对视一眼，没有再犹豫。他们从排水渠的方向侧身挤进那条只容一人通过的暗渠，膝盖半蹲，在暗渠的湿冷与黑暗里摸索前行。

身后的密道里，很快传来一阵沉重的脚步声和气急败坏的喊声：“她跑了！往南边追！”

林一凡没回头。铁盒在他怀里微微发烫。指纹槽内残留着一层极薄的油渍，在手机微光下，隐约可见槽内刻着三行小字——

“第一入者，死门；
第二入者，活门；
第三入者，无门。”

那个“第二个进门者”是谁，不言自明了。

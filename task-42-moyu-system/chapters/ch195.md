# 第195章 七天的倒计时

林一凡把U盘拔出来的时候，手心里全是汗。

屏幕上老周的自拍视频已经播放完毕，最后一帧定格在一张布满皱纹的笑脸上——那笑容里有种说不清道不明的坦然，像是在说“轮到你了”。

“七天后……劳动神与资本神的赌局开局。”

他低声重复了一遍系统面板上弹出的文字，那行字已经消失了，但他记得清清楚楚。系统里的咸鱼值余额停留在八万七千六百三十点，这个数字从视频播放结束的那一刻起就没再变化过。

要知道，平时哪怕他坐着发呆超过三十秒，咸鱼值都会稳定上涨。

“搞什么？连摸鱼收益都停了？”他试着在脑中呼唤系统，等了足足五秒，才收到一条冰冷的回复：

【第99级提示：赌局筹备阶段，咸鱼值收益暂停。请宿主在七天内做出选择。】

“选择什么？你倒是说清楚啊！”

没有回应。

林一凡坐在顶层办公室那张价值不菲的人体工学椅上，目光落在桌面上那个黑色U盘上。老周说钥匙代码完整版藏在他脑子里——这是什么意思？难道要他把老周的脑袋打开来读取数据不成？

手机震动了一下。

赵日天发来一条消息：“看完了？老周没骗你。”

林一凡盯着这条消息看了三秒，回复：“你怎么知道我看完了？”

“因为你现在应该正盯着手机骂系统，而我赌你最多三秒就会回复我。”

林一凡骂了声脏话，但他不得不承认赵日天对他太了解了。

“你在哪？我们需要谈谈。”他打字。

“你办公室门口。”

门被推开的瞬间，林一凡闻到了烟味——赵日天靠在门框上，手里夹着一根没点燃的烟，穿着一件和他记忆中完全不同的灰色休闲外套。

这个人今天看起来不像卷王。更像一个普通上班族，甚至有点丧。

“老周的真实身份是什么？”林一凡开门见山。

赵日天走进来，反手关上门：“老周是三十年前星辰科技最初的系统架构师。那把钥匙，是他亲手设计的。”

“所以那把钥匙不是停机人力之源的？”

“是，也不是。”赵日天在他对面坐下来，“人力之源本身就是一把锁。钥匙插进去，可以停机，也可以唤醒。区别只在于转动的方向。”

林一凡的后背微微发凉：“老周想唤醒什么？”

赵日天沉默了几秒：“你不知道比知道好。但你既然已经走到这一步……”他从口袋里掏出一样东西，放在桌面上——一块拇指大小的透明晶片，里面隐约有流动的光。

“这是我那台卷王系统的核心碎片。它可以和你的摸鱼系统进行一次性数据交换。”

“交换什么？”

“交换真相。”赵日天的目光罕见的变得凝重，“但要提醒你，交换之后，你的系统可能会降级，甚至消失。你确定要听吗？”

林一凡盯着那块晶片，系统突然在脑内弹出一条新的提示：

【警告：检测到高等级信息体接近。选择接收可能触发隐藏规则，请宿主慎重考虑。】

他还没来得及作出决定，办公室的门突然被人从外面推开。

钱总站在门口，脸上的表情像是刚吞了一只活青蛙。

“你们——在我的办公室里做什么？”

林一凡和赵日天对视一眼。他下意识把手里的U盘塞进裤兜，而赵日天以肉眼几乎难以捕捉的速度把晶片收了回去。

“钱总，”林一凡站起来，脸上挂出最标准的职场微笑，“我们正在讨论您的特别技术顾问岗位下一步的工作计划。”

钱总的视线在他们两人之间来回扫了三次，最终定格在赵日天身上：“你什么时候进来的？”

“刚到。”赵日天站起来，表情平静，“我只是来送一份文件。既然林顾问有客人，那我先告辞了。”

他走向门口，与钱总擦肩而过的瞬间，林一凡注意到钱总的身体微微侧了一下——那不是让路，而是一种防御性的避让。

这个老板在怕赵日天。

赵日天走后，钱总关上门，在沙发上坐下来。他沉默了很久，才开口：“林一凡，我有一件事要告诉你。”

林一凡心里警铃大作。

“总部刚刚发来通知，下周会对星辰科技进行全盘审计。”

“这不是很正常吗？”

“不正常的是……”钱总抬起头，眼神里有一种前所未见的疲态，“审计组带来了一台机器，据说可以检测所有员工的‘劳动纯度’。不合格的，直接清零辞退。”

林一凡倒吸一口气。

上一世——或者说他记忆中的那一世——这套机制是半年后才上线的。为什么现在提前了？

除非……有人改变了未来。

钱总说：“你是特别顾问，最迟明天给我一套应对方案。”他站起身，走到门口又停住，“还有，我听说你最近在打听人力资源部的数据机房。那不是你该碰的地方。”

门关上了。

办公室里只剩林一凡一个人。他的手机在兜里震动起来——屏幕上亮着赵日天发来的一条新消息：

“劳动纯度检测仪，是资本神送给钱总的见面礼。七天后，赌局开局。你还有六天半。”

林一凡握紧手机，感觉到裤兜里的U盘硌着大腿，像是某种实体的倒计时。

六天半。

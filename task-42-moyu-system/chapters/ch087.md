# 第87章 根目录里的声音

废弃厂房的空气里混着铁锈和机油的气味，周莉把笔记本电脑搁在一张歪斜的工作台上，屏幕的蓝光映亮她半张脸。林一凡蹲在旁边，手指无意识地敲着膝盖，系统面板在视野边缘跳动：根目录访问协议已启动，剩余时间 23:14:37。

“密钥合成完毕。”周莉没有抬头，“现在只要加载这个‘咸鱼图鉴’App，就能进入星辰科技的考核系统主机。”

林一凡站起身，裤腿上蹭了一层灰。他记得江雪留下的那张画——根系状的树木从黑暗土壤里钻出来，每一根须都标着不同的数字。当时他没看懂，现在周莉摊开那张图，旁边用荧光笔补全了注释：根=主机入口，枝=数据分流节点，叶=员工终端。

“她早就设计好了。”林一凡声音有点干，“画这张图的时候，她还没死。”

周莉的手顿了一下。“她是在死前三天画的。”她说这话时语气平淡，可指尖捏着纸的边缘发白，“她说‘根目录里有一——’那句话没说完。当时机器连接着云麓那边的测试端口，监听程序只截到个‘一’字。”

“一什么？”

“不知道。但芯片里除了方案，还有一段加密音频，用江雪的声纹绑定。”周莉从口袋里掏出一个指甲盖大小的黑片，按进电脑侧面的卡槽，“破解声纹锁需要一小时的离线运算，刚好够你用。”

屏幕上跳出进度条，37%。林一凡盯着那个数字，窗外北郊的夜风灌进来，吹得厂房顶的铁皮哗啦作响。他想起前世——或者说，另一条时间线里，自己累死在工位上的那个夜晚。江雪这个名字在记忆里很模糊，像是同事口中偶然提起的、早就离职的人。可这一世，她留下的东西正在把他拖进一场更深的漩涡。

“进度条走完之前，你得告诉我一件事。”林一凡转过来看着周莉，“你什么时候开始跟江雪接触的？你俩不只见过一次吧。”

周莉没看他，眼睛盯着屏幕：“她是我大学同学。毕业后她进了星辰，我做了独立安全顾问。去年年底她找我帮忙查一批异常数据流量，源头就是云麓。”

“所以你拿走了第三段芯片。”

“她寄给我的，说‘别放进任何联网设备，等对的人来取’。”周莉终于抬起头，“对的人是你。她知道你重生的时间节点。”

系统面板忽然剧烈闪动——根目录访问协议亮起黄色的警告灯。林一凡还没来得及问下一句，电脑屏幕上的进度条跳到了 100%，紧接着整个画面变成黑底白字的一行命令：

ROOT_ACCESS_GRANTED。

“进去了。”周莉压低声音，“开始抓数据。”

下一秒，扬声器里传出一段刺耳的电流声。林一凡下意识后退半步，然后电流声变成了清晰的、一个年轻女人的声音，带着轻微的沙哑：

“……如果你听到这段录音，说明我把后门留对了。根目录里有一个——”声音断了半秒，像是被什么干扰过，“——一个完整的、还没被删除的备份。它不属于星辰科技，也不属于钱总。它属于所有被这系统压榨过的人。”

录音结束。厂房里安静得能听见电流在老旧灯管里嘶嘶作响。

周莉的眉头拧了起来：“备份？什么备份？”

林一凡盯着黑底白字的终端，指尖发凉。根目录访问协议在屏幕角落弹出一行新提示：备份位于隐藏分区，需要额外的声纹授权才能解锁。授权人：江雪（已死亡）。替代方式：双密钥合并——林一凡、周莉各一段。

“她把最后一步留给了我们两个人。”林一凡说。

周莉没接话。她的手机忽然震动了一下，屏幕上亮起一个陌生号码发来的短信。她看了一眼，整个人僵住。

“怎么了？”林一凡问。

周莉把手机翻转过来。短信只有五个字：别碰那个备份。

发送者的号码，正是之前何顾问通话时显示的那个“江小姐”的号码。

# 第413章 沈望未白的死期

青铜钉立在灰尘里时，林一凡没有立刻伸手去碰。他蹲下身子，与钉尖齐平，看见钉身靠近底部的部位有一道极细的裂缝，里面灌着暗色的东西，干涸之后像铁锈，但细看却能认出来，那是干了的墨迹——曾经有人在这根钉上写过字，然后被抹掉了。

“沈望未白。”他念出这个名字，眼前闪过那张阴郁的脸。老杨头大哥说第二根钉该用了，可他不知道这根钉的用途是锁还是放。

“钉哪扇门？”他问。

身后没有回答。他回过头，通道里空空如也。老杨头大哥不见了，连脚印都没有留下——除了那颗“27”的陶土珠，还在他掌心里轻微发烫。无名指上的纹章从陶土色变深了一点，像被火烤过的陶罐边沿。

林一凡站起身，把钉塞进口袋，用手指捏住铁芯——那根刻着他名字的铁芯，一遇到口袋里的青铜钉就轻微地震动，像磁铁排斥。

“系统。”他喊了一声。面板没有弹出。他又喊了一声，仍然没有反应。他合上眼睛，凝神——摸鱼空间中此刻有了变化：原本空无一物的空间地上，多了两个凹槽，一个圆形，一个长条形。圆的比长的大一圈；长条的轮廓恰好是铁芯的形状。凹槽周围刻着一圈细密的水波纹，水波交汇处有个黑点，像一截手指。

林一凡走进摸鱼空间。他第一次觉得这个空间的地面不是白的。水泥地，裂缝从凹槽边缘辐射开去，缝隙里钻出几丝蓊蓊郁郁的野草根须。他蹲下，将铁芯靠近长条凹槽，那股像是被拉住的力猛增，铁芯“咔”一声插入。凹槽边缘的裂缝慢慢收拢，像伤口合拢。

“咔嗒。”一声脆响。

凹槽之间多出一条暗红色的线，线的尽头是一扇门——一扇他之前从未在里面见过的门。这扇门的门板是铁皮的，锈迹斑斑，门把手上拴着一根红绳，绳尾系着一截断指，断面平整，像被利器切的。断指的指尖上，有一个浅浅的漩涡状纹。

林一凡伸手推门。门纹丝不动。铁皮壳子上浮现出一行字，笔迹干涩，像是被刀尖划上去的：“沈望未白的死期，在你的钉子上面。”

他退出摸鱼空间，睁眼。口袋里的青铜钉已经不在原处。他低头——那根钉不知何时从他的口袋滑出，此刻正插在通道地面的一道裂缝中。钉尖朝下，钉帽朝上，钉帽的凹陷里，有什么东西正慢慢积攒成一颗水珠。水珠是暗红色的。他抬头——通道顶部没有水源，没有管道。那根钉像在从空气里吸取什么。

水珠凝聚片刻，然后顺着钉身滑下去，没入地面的缝隙。就在水珠消失的瞬间，通道尽头传来一声轻咳，声音干哑，像喉咙里卡着铁锈。

林一凡循声看去——通道尽头拐角处有个人影。个子不高，蜷着肩，青灰色的外套皱巴巴地裹在身上。是沈望未白。他靠壁坐着，手里攥着一卷旧布，布上洇着一块暗红的血。

“你……”林一凡快步上前，在离他三步远的距离站定。血是新鲜的。沈望未白的左手没了搭着老布遮住，但布料边沿露出的指节缺了一截——那截断指的漩涡纹，跟摸鱼空间门上拴着的一模一样。

“你不用问。”沈望未白抬眼看他，眼珠比之前干净许多，瞳孔里那层阴翳似乎褪了，“我替你看门里的东西看久了，它咬掉我一截指头，我认了。”

他说着抬了抬下巴，示意林一凡看他手中的旧布。布面展开，是一行字——“第九根钉子在你看到这行字的时候，已经钉进去。替死的人，不会替你再死第二次。”

林一凡瞳孔缩了缩。“你说谁钉进去了？”

沈望未白扯了扯嘴角：“钱总。”

两个字落地，通道尽头的风声都静了一瞬。林一凡握着口袋里的铁芯，摸鱼空间里的地面——他刚才没有注意——在那根青铜钉插入之后，地面裂缝里渗出一种粘稠透明的液体，顺着裂缝流向长条凹槽，被铁芯吃进了一截。那截铁芯的颜色，从银灰变深了一层，像蒙了一层血垢。

他低头看自己的无名指，陶土色纹章的边缘，多出一条极细的红线，像一根血管，顺着指针向前延伸，最终没入指尖。

沈望未白将那卷旧布折好，兜进怀里，撑着墙壁站起来，左手缺的那根断指处，血已经止住了。他看了一眼林一凡，声音极低：“你师父让你别用钉，你已经用了一根。剩下的，你自己选。”

说完，他转身，往通道更深处走去。拐角的阴影吞没他的身形，脚步声在第七步之后戛然而止。林一凡站在原地，手里的铁芯突然一震，背面多出一行字，比上一行更浅，但他认得出那个笔迹——那是老王的：“门缝里还有一颗珠，第26颗，去找它。”

他收起铁芯，迈步往沈望未白离开的方向走去。前方通道的墙面上，不知何时多出一道浅浅的划痕，像是指甲刮过的，刻痕在光的映照下，隐约是一个数字：“26”。他走近细看，数字边缘沾着一粒干涸的红色——是血，混着一根极短的黑发，发尾打着卷，像女人的头发。

林一凡脑子里“嗡”地一声：锁芯女人手指的纹路，他记得，跟这根发卷的弧度同一种走势。那条线索一直咬着“27”不放，但此刻这道划痕却在把方向引向“26”——一颗他从未见过的珠子。他低头看无名指纹章，红线的尽头，正指向通道前方那抹黑影。黑影停住了，没有移动，仿佛在等他靠近。

林一凡眯起眼，铁芯在手心转了个向，朝那团影子走过去。脚步声在通道里重复回荡，像有两个人在同步迈步。他数着自己的步子，走到第七步时，影子的轮廓清晰了。那团黑影手里握着一根青铜钉——第三根钉，钉帽上刻着一道水波纹，纹路中心是一个漩涡，漩涡中央，是一颗陶土珠，珠子上的刻度在黑暗中翻动。

翻动。刻度从“27”缓缓翻到“26”，最终停在一个空白的面上。那面空白，像一只没有瞳孔的眼睛，正对着他。

黑影开口了，声音像从很远的井底传上来：“来找我。”

林一凡停下脚步，没有继续往前。他握着铁芯，声音平静：“你是第26颗珠，还是那截手指？”

黑影没有回答。通道顶部，一滴暗红色的水珠坠落，滴在第三根钉的钉帽上，溅起碎屑，露出底下更深一层的淬火色。林一凡看见了那层淬火色的一角——那不是普通铁，是骨头灰煅烧过的灰烬骨钉。他刚才捡起的那一根，钉身上也蒙着一层白灰。

他终于明白那层灰是什么了。那是一个人，他认识的人。烧成灰的那种。他没有继续想下去。门内那声湿重的呼吸又响起来了，这次比之前更近，像贴在铜门内侧，从钉缝里往外洇出一股凉意——贴在林一凡后颈上，像朝他吹气。

他捏紧铁芯，向前迈了一步。

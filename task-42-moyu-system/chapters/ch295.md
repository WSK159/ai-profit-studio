# 第295章 水塔下的暗语

旧机房的灯管只剩一根还在闪烁，把母亲手稿上那行字照得明灭不定——“001号不是实验体，是钥匙。你——不是巧合被选中的人。”

林一凡把手机屏幕按灭，指尖摩挲着母亲那部翻盖手机背面的鱼骨贴纸。灰工装老头靠在门框上，没有说话，只是用那种看透一切的眼神望着他。

“我妈还说别的了吗？”林一凡终于开口。

老头摇了摇头，转身往楼梯方向走了两步，又停下：“她说，水塔底下还有东西。但不是给所有人看的。”

林一凡的目光落在地板上。旧机房的地面铺着一层深灰色防滑钢板，边缘有焊死的痕迹。他蹲下来，用指节敲了敲靠近墙角的那块钢板——声音发空。

他抬头看向老头，老头没有阻止的意思。林一凡把手伸进钢板的边缘缝隙，用力一掀。钢板下不是水泥，而是一个长方形的防水铁盒，表面锈迹斑斑，但锁扣却是新换的不锈钢。

“钥匙呢？”老头问。

林一凡从口袋里摸出那把三叉钥匙——之前在暗间找到的那把。他犹豫了一瞬，把三叉钥匙插入锁孔，竟然严丝合缝。顺时针一拧，“咔哒”一声，铁盒弹开。

里面是厚厚一沓A4纸，最上面一张是一张手绘地图。地图上标的不是路名，而是一个个红圈，全都是林一凡这半年去过的地方——星辰科技大厦、苏州河废弃水塔、虹口旧仓库、老城区那家锁匠铺，甚至还有他重生前几天住的那间出租屋。

每个红圈旁边都标注着时间，精确到分钟。

“她一直在追踪你。”老头的声音从身后传来。

林一凡没有回头，他的目光锁定在地图最下方的两行小字。是母亲的笔迹，娟秀却带着急促：

“他在看我们。找‘那个人’——他一直在暗处。”

地图右下角，有一道很淡的铅笔线，从水塔画向一个没有标注的位置，落笔处是一个名字，被反复涂抹过，只留下断续的轮廓。林一凡把纸对着灯管，逆光照出浅浅的笔痕。

他认出那个名字的最后一笔。

那是“沈”字的末尾折钩。

手机突然震动，那个陌生号码又发来一条短信：“她说的‘他’，指的不是一个人。是两个。你注意，有人在看你。”

林一凡猛地回头，楼梯口的灰工装老头已经不见了。只剩下铁皮门在风里轻轻晃动，发出“吱呀”的声响。

他攥紧那沓纸，忽然察觉到一件事——铁盒内壁有一行极浅的刻痕，像是用指甲硬划的。他摸了一下，触感凹凹凸凸，是摩尔斯电码。

他凭着记忆逐字破译：“……苏婉来过之后，第二天陈某也来过。他们在我这里吵了一架。苏婉说，植入体不是终点。陈某说，那是唯一能保命的办法。”

“保命”两个字在脑海里炸开。

他立即翻到铁盒底部，找到第三张纸——那是一份手术记录复印件，日期是2019年6月15日。手术对象：林建国。手术内容：植入体型号“河豚001”，但手术医师栏填的不是父亲的签名。

是“陈”。

记录下方有一行潦草的批注，笔迹属于母亲：“他在手术室里多放了一个东西。我拦不住。这之后，林建国就不再是林建国了。”

林一凡的手开始发抖。他想起重生前的父亲，那个沉默寡言、眼神偶尔空洞得不像活人的男人。他以为那是常年加班熬出来的疲惫。

走廊尽头传来脚步声。

他来不及细想，把纸塞回铁盒，合上钢板，蹲在墙角屏住呼吸。脚步声越来越近，在门口停了。

一个男人的声音：“一凡，我知道你在里面。”

是沈稚冬。

门被推开，沈稚冬站在昏黄的走廊灯下，脸上看不出什么表情，手里却拿着一个林一凡熟悉的东西——母亲那部翻盖手机的旧充电器。

“你妈死之前，让我在他日把这个交给你。”沈稚冬把充电器递过来，补了一句，“她让我告诉你一句话。”

林一凡盯着他的眼睛：“什么话？”

“她说，‘水塔里的不是答案，是另一个问题的起点。’”

林一凡的心猛地沉下去。他刚把铁盒里那沓纸当作真相，母亲就告诉他——这才刚刚开始。那沓纸上面的红圈、陈的签名、模糊的“沈”字轮廓，究竟指向哪里？

沈稚冬的目光落在他空掉的双手上，似乎什么都没察觉。他平静地说：“走吧，时间差不多了。有人在楼下等着见你。”

“谁？”

“你见了就知道了。”

林一凡站起身，把那沓纸的影子在心里过了一遍。那张地图右下角涂掉的轮廓，沈字的末尾折钩，还指着一个绰号——但那个绰号，他没猜出来。

他跟着沈稚冬走下旋转楼梯，水塔外，一辆黑色轿车停在夜色中。车窗降下来半条缝，看不清后排的人。

林一凡想到了陈和平说过的一句话：“你见到的所有人，可能都不止他们自己。”

他深吸一口气，拉开车门。

“沈稚冬说‘时间差不多了’——什么时间？”林一凡脑中划过一道寒光，“他说的‘楼下等着见你’的人，为什么要把自己藏得那么深？”

轿车后座，那个人的手搁在膝盖上，指尖轻轻叩了两下。林一凡看见了那双手的指节——布满老茧，不是文职的手。

他坐进去，车门在身后关上，发出沉闷的“砰”声。

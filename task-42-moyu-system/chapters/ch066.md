# 第66章 最后的记录

林一凡盯着那个空名字足足三秒，然后迅速关掉了模块界面。

他有一种直觉，不能再往下看了，至少不是在这个地方、这个时间。系统面板右上角隐约闪烁着一行极小的提示：

【本次查看已记录。剩余查看次数：0】

果然，这么“贴心”的模块不可能让人无限白嫖。他深吸一口气，压下心里那股按捺不住的好奇，将自己拉回现实。

工位还是那个工位，键盘还是那个键盘。屏幕上的代码纹丝不动，周围的同事们依旧在一阵劈里啪啦的键盘声中进行着无意义的忙碌。但林一凡知道，他已经看到了不该看的东西。

一个有编号、有进度、有记录的“被删除人员清单”——而这些记录，恰恰就藏在星辰科技秦氏B座的总服务器底下。

他正想着，手机震了一下。是刘维发来的消息：“方便的话，B座地下二层咖啡机旁边碰个头，关于江雪的事，有东西给你看。”

林一凡的目光在屏幕上停了一秒，随即收起手机起身，假装去接水。走过六排工位、两个转角，坐电梯下到地下二层。灯光昏暗，空无一人，咖啡机旁边站着刘维，手里攥着一张皱巴巴的纸。

“你昨天说赵日天跟她有私下联系，我多查了查。”刘维压低声音道，“这是我从她之前电脑里恢复出来的，最后打开过的文件……是这栋楼的结构图，但不是现在的结构图。二十年前的。”

林一凡接过纸条。那上面是一张手绘草图，线条歪歪扭扭，但清晰地标注了一个位置——地下三层。一个在现如今的楼层索引中根本不存在的空间。

“秦氏B座一共地上25层，地下2层，”刘维说，“但当图纸上，这个地方是三层。”

林一凡凝视着那个手绘的箭头，心里忽然浮现出刚刚那个模块里出现的词——提取舱。如果江雪被困的地方就在地下三层……

“你今天晚上，有没有值班权限的问题？”刘维忽然问，“我想下去看一眼。”

“你疯了？”林一凡压着嗓子，“明早全员大会，钱总新制度一出，说不定会加挂巡逻系统——这时候钻到地下去？”

刘维摊开手：“那你我甘心当什么都没看见？江雪失踪这么久，警方都没头绪，我总觉得她不是单纯辞职。”

林一凡沉默下来。脑海里翻涌着赵日天那天的话——有些东西不是你能改变的，但有些地方，也不该是资本说了算。

五秒钟后，他掏出手机看了一眼系统面板上的时间。

“凌晨一点，”他说，“B座负一层货梯口见。”

刘维微微一怔，然后点了点头。

林一凡回到工位上时，桌上的系统界面忽然又弹出一个新提示，他看了一眼，瞳孔微缩——

【“摸鱼空间”升级。解锁新功能：夜视视野（限时120分钟）】
【系统提示：你已接近核心真相。请慎重行动。】

他从没告诉过系统他今晚要干什么。但这个系统，好像永远知道得比他多。

当天傍晚，钱总的OA公告如约而至：明日全员大会，宣布新制度——全员安装“效率卫士”App，实时监测鼠标键盘活跃度。届时，任何“摸鱼行为”将被自动标记并扣除绩效。

同事们一片哀嚎。林一凡只冷冷地看了一眼标题，然后关掉弹窗。

明天的事，明天再打。

今晚，他要去地下三层看一看。

凌晨零点五十分。林一凡把手机调成静音，穿戴好外套，从工位底下的背包里摸出一支笔形手电，推开消防通道的门，走进寂静的黑暗中。

电梯停运，只靠步梯下到负一层。刘维已经到了，靠在货梯口的墙边，见他来，只点了一下头。

“你真的确定要去？”

“江雪在下面。”林一凡说，“而且我有种直觉——她不是唯一一个。”

两个身影消失在负一层的防火门后。

而就在他们身后十米远的消防梯拐角处，一双黑色的皮鞋悄无声息地停住，发出极低的一声响。

那人没有跟上去。只是缓缓抬起手，对着掌心那块青色屏幕，轻声说了一句：“鱼入网了。”

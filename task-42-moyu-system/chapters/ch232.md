# 第232章 第二台终端的锚点

三个人在五分钟内离开了档案室，将那尊骨架留在黑暗里。

陈默收起照片时顺手把纸条也拿了过去。林一凡没有阻止。眼前这个人知道的内容远比自己多，但他有一个更基本的判断——“自由之海”这三个字，他不可能不查。

走廊尽头消防通道的安全指示灯闪烁，像谁在打暗号。

林一凡压低声音：“钱总打五个电话给老王，不是巧合。老周刚才出现也不是。有人在试我们底牌。”

“你打算回他电话？”老王攥着手机像攥着手雷。

“回。但我得先说一个能让钱总坐不住的消息。”

他接过老王手机，拨了回去。片刻，电话接通，钱总的声音听起来有种刻意压平后的客气：“老王，你们在哪儿？地库那台服务器要出报表，我下午要用。”

“钱总。”林一凡开口，电话那头沉默半秒。

“小王？”钱总语气明显一紧，“你手机呢？怎么用老王号码？”

“我手机掉水里了。”林一凡靠在楼梯间墙壁上，“钱总，跟你说个事。刚才在档案室，我看到你去年报废旧服务器的台账——编号LK-042那台。回收单上写着报废，但我看着它不像报废的，里面主板全在，甚至还有一条没断的插头，插头连着一个容器，里面是——”

钱总直接挂了。

林一凡看着黑屏手机，嘴角一咧：“只要一提LK-042，钱总就知道我们看到的比他想的多。现在他会慌，慌了就会动。”

陈默看着他，难得评价了半句：“有点意思。”

老王一个激灵：“什么意思？他要是动起来，咱们更危险啊！”

“他动起来，我们才能知道他的尾巴埋在哪。”林一凡收起手机，转向陈默，“那张照片的钢印码，你从哪得到的？陈默抬手点了点自己后颈——衣领下露出一截浅浅的疤痕，皮下隐约有缝合纹路。

“我从小到大都搜索不到这个号码的记录。父亲死那年，他留下一张骨灰领取单，背面也有一串同一个码。”陈默声音平淡，却带着冷意，“我一直以为是他工号。直到我看到这东西——”

他从口袋里掏出一小卷透明胶纸，层层揭开，里面是两粒指甲盖大小的芯片，叠在一起，中间夹一根头发。芯片边缘刻着细密纹路，灯光下隐隐有一串数字，与照片上的完全一致。

“LK-042。那台机器的核心两颗芯片，其中一颗的序列号，和我父亲的基因信息绑定。”陈默捏起头发，“头发是今天早上在他骨灰盒底下取出来的。封装时间比他死早了整整两年。”

空气凝固了几秒。

林一凡听着，忽然想起系统里的那句提示：“祭品非人，亦可为意识锚点。”

如果陈默父亲的意识和基因被编码进芯片，那“自由之海”的终端，很可能不是用“人”当燃料，而是在用**拥有特定基因编码的意识**做钥。他脊背发凉：老周说过，所有人都以为终端靠电，实际上靠命的“命”，有另一种解释。

不是生命，是命数——是身份。是某个人的存在证明。

他低头看向自己的手。那根铜线正隐约透出蓝色荧光，荧光沿着指纹纹路蔓延，像体内血液瞬间被某种东西点亮。他心神一震：这玩意认主了。

系统忽然弹出一条鲜红提示：

【节点进度86%→91%。锚点已激活。由于绑定者携带非标准基因序列，系统进入融合校验阶段。警告：融合过程中，您的部分人格记忆将短暂暴露给“终端搜索协议”，可能被同一终端体系的其他访问者定位。】

“有人要通过我访问终端？”林一凡脑子转得飞快。

系统又一闪：

【同时检测到“卷王系统”信号在同一频率频段活跃。来源：与您直线距离不超过两百米。】

两百米——就是同一栋楼。

林一凡猛然抬头，“赵日天在附近。”

陈默眸光一凛：“你怎么知道？”

“我系统刚刚告诉我，他会访问同一个协议。”林一凡压低声音，“看来自由之海这台终端，不止我一个人想去。”

楼梯间上方的声控灯忽然灭了，黑暗里传来若有若无的脚步声，像踩在砂纸面上一样轻。脚步声从上方来，不断靠近，然后在三楼拐角停住，紧接着是一声极轻的、像咬牙吐出的笑。

“……找到了。”

陈默三步上前抓住林一凡衣领，把他往后拉：“别回头。跑。”

三个人冲向下一层楼梯。铁门在他们身后“砰”地一声合上，余音里，一道电流顺着门板缝爬进内壁，发出细碎的“嘶”声，像一只无形的手在摸墙。

林一凡边跑边飞快复盘：老周没死、LK-042、自由之海、意识锚点、赵日天同一频段……他感觉所有线索正在拧成一股绳，但绳的另一端却没人拽着，像是故意等着他自己往前走去。

那台终端的真正身份，他知道答案只差最后一块拼图。

他翻出系统商城，看到“咸鱼值”数字旁边多了一行灰色小字：

【已解锁隐藏条目：终端井权限——需抵达“自由之海”坐标后激活。】

坐标栏空白，但旁边静静躺着一个坐标数据，显示：**北纬31°14'07"，东经121°29'03"**。

那个坐标，正是星辰科技总部大楼的正下方。

终端——就在他脚底下。

林一凡猛然停住脚步，低头看向脚下的地面。那里什么都没有，但地板缝隙之间的水泥，正在微微震动。嗡——一声低沉的共鸣，来自地底深处。

系统冷冰冰地弹出一行字：

【终端已苏醒。它知道你在找它。】

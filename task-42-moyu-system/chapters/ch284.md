# 第284章 沈稚冬的笔记本

那盏路灯熄灭后，整个小区彻底沉入黑暗之中。林一凡在车里坐了很久，直到车内的空调冷气把他手脚都冻得发僵，才推开车门踏上地面。

赵恒说他见过的人不是他——这句话像一根细针扎在颅骨内侧，你想忽略它，但它一直在那。

他掏出手机，开机。屏幕亮起的瞬间，一列未读消息弹出来，最上方是一条来自“沈姐”的消息，时间是半小时前：

“小林，凌晨以前别回宿舍。有事。”

沈稚冬。

林一凡盯着这个名字，脑子里飞速闪过那张脸——档案科同事，说话温温吞吞，总戴着一副银色细框眼镜，从不加班，朝九晚五准时消失。上一世，他跟沈稚冬几乎没有任何交集。重生后，他们之间的对话不超过十句。

但她给他发了这条消息。

他环顾四周。老旧小区的楼房整齐划一，楼体上斑驳的标语痕迹还在，像几十年前的遗物。靠近角落的第三号楼，201室——他看到窗台上放着一盆枯了一半的绿萝，和沈稚冬工位上那盆一模一样。

林一凡没有犹豫。他快步走进去，楼道里的感应灯早已坏掉，他借着手机余光踏上楼梯，在201门口停下来。门虚掩着，缝里漏出一线昏黄的灯光。

他推开门。屋内的陈设几乎可以用极简来形容——一张木桌、一把椅子，墙上钉着一张A4纸，上面是一行手写的字：“别喝太多咖啡。睡眠是最好的摸鱼。”

沈稚冬坐在桌前，手里夹着一支没点燃的烟，见林一凡推门进来，眉头都没有动一下。“进来，关门。”

林一凡走过去，拉开椅子坐下。两个人之间只有一盏台灯的光。沈稚冬看着他，目光落在他的左耳后——那道缝合线上。

“赵恒告诉你了？”她的声音很平，“那他有没有告诉你——你耳后那道线，缝了三针，用的是7-0尼龙线，2019年6月12日下午三点十七分，在协和医院第三手术室缝的。”

林一凡的心口猛然一紧。“你怎么知道得这么清楚？”

沈稚冬低头，从抽屉里取出一本墨绿色封皮的笔记本，翻开第一页。那页纸上的字迹，与档案科那张A4纸上的字迹一模一样——娟秀，细长，笔画微微向左倾斜。

她把笔记本推到林一凡面前。第一页只写了一行字：

“如果林一凡醒来，请把这个交给他。落款：沈稚冬，2019年6月12日。”

林一凡抬头。沈稚冬的表情平静得像一块湖水，但她开口时，声音里有一丝极难察觉的颤抖：“那天手术室里，我做了你的麻醉记录。”

她顿了顿：“林一凡，2019年6月12日那天，手术室里不止你一个人。你姐姐林一诺躺在隔壁，在你手术进行到第七分钟的时候——她的心电监护仪上，出现了一次数值异常。”

“什么异常？”

“持续三十一秒的脑电波活动。”沈稚冬看着他的眼睛，“脑死亡的病人，脑电波平了六年，然后在那天突然跳了一次。而那次跳动的波形，和你的……完全同步。”

房间里安静得能听见墙上那盆绿萝叶尖滴水的声响。

林一凡的手握成拳，又松开。他的声音低得几乎只有自己听得见：“也就是说，我的手术激活了她。”

“我没有证据。”沈稚冬合上笔记本，“但我保留了那三十一秒的波形数据——用一张纸手绘的，因为你姐姐在术前唯一嘱托我的事，就是‘如果波形跳了，画下来’。”

她翻开笔记本的最后一页，林一凡看到一条弯曲的蓝色线条，像心电图，但又不是——波峰与波谷的间距均匀得不像生物电信号，更像是某种加密过的脉冲波形。

他看了一眼就将这条蓝线和那枚芯片上的鱼纹对照起来——波形弯曲的走向，和芯片上那条鱼尾部的纹路一模一样。

“她画这条线的时候，说了什么？”他问。

沈稚冬想了很久，才用一种平静到不真实的语气回答：“她说：‘如果有一天你看见鱼打开了嘴，让三叉的尖指向北方。’”她停了停，“我不知道北方是什么，但你的钥匙——把它拿到窗前。”

林一凡掏出那枚三叉钥匙，走到窗边。月色很淡，那把钥匙面上，竟有一道极细的荧光丝线般的纹路，在月光的角度下，浮现出一列极小的数字。

0427-13-18-2019。

巧合的是——沈稚冬笔记本的扉页内侧，也有一行几乎看不见的铅笔字：“4月27日，13:18，2019——北偏东37°。”

林一凡握着钥匙的手微微一颤。

4月27日13点18分——他重生回来那年，如果坐标指向的是地点，那么位置就是——

他低头，把钥匙举到月光下，轻轻转动。钥匙尖所指的方向，落在北方偏东三十七度的天际线上。那方向，穿过城市，穿过郊区的灯火，一直落向一座他再熟悉不过的建筑——

星辰科技大厦。

他曾经加班到猝死的，那一栋楼的十七层顶楼天台。

沈稚冬站在他身后，点燃了那支一直没点的烟：“你姐姐留下的门，从来不在档案科。她留下的，是一条路。”

她静静抽了一口烟：“林一凡，你准备好从那条路，通向十七层的天台了吗？”

林一凡没有说话。他把钥匙收进胸口口袋，转身朝门外走去。楼道的灯依然坏着，但他的脚步没有停。

他忽然明白，赵恒说的那句话是什么意思——他见过的人，不是赵恒。而沈稚冬告诉他的这件事，远比钥匙本身更接近真相。

手机屏幕又亮了，一条匿名消息：

“别去天台。有人在那里等你——你妈。”

林一凡站在楼梯口，握着手机，沉默了很久。夜色里，那座大厦的轮廓像一头伏着未醒的兽。

他关掉屏幕，迈下台阶，朝北方走去。

# 第425章 门内门外

门推开的瞬间，那股纸墨气味骤然浓烈起来，林一凡的鼻腔一阵发酸，像被人用旧宣纸堵住鼻孔，用力吸了一口似的。

他眨了眨眼，适应了昏黄的光线。

这是一间很小的石室，约莫只有他刚才所在石室的三分之一大，高不过两米出头。墙壁四周嵌着十几盏铜制壁灯，灯芯浸泡在一层淡黄色的油液里，火苗细而稳，没有一丝摇曳——像是静止的。石室正中央放着一张矮几，矮几上有一樽陶土酒坛、一只缺了口的粗瓷碗、一根还没有完全烧完的松木条。

林一凡的目光扫过这些物件，最后落在矮几后面的那面墙上。

那面墙上挂着一幅画。

画是用炭笔画在牛皮纸上的，线条笨拙但认真，像小孩子学画的笔触。画的内容是一个男人坐在桌前写代码，屏幕上的光打在男人脸上，线条勾勒出他低头专注的样子。男人身后，窗户外面画了一行歪扭的树，树梢上挂着一轮圆月，月亮里画了一个很小的人影，那人影蹲着，双手抱膝，像在等什么。

林一凡在画前站了很久。

他知道画里的人是谁。那个人每一次坐到电脑前，都会把键盘摆正、把水杯放在距离右手十五厘米的地方、把椅子拉到离桌沿一拳的位置——这张画的每一个细节，都与他记忆中的父亲完全一致。

他的喉咙动了一下，没有出声。

矮几上的粗瓷碗里盛着半碗水，水面上浮着一枚铜钱大小的青色瓷片，瓷片上的釉面被磨掉了一块，露出白胎，白胎上用极细的字迹刻了一行字。林一凡拿起碗，凑近那行字——

“门内门外，皆是归途。见到我，不要叫我的名字。”

和手机消息一模一样。

他把碗放回去，目光落在旁边那根松木条上。松木条的一头烧成了黑色的炭柱，另一头完整，上面用刀刻了七道横纹，间距均匀，与台阶上那行脚印的七道横纹完全一致。他拿起松木条，翻过来，背面还刻着一句话：“三月十七，第三次。他问我能不能放他出来，我说，钥匙不在锁孔里。”

三月十七。

他在心里默默换算了一下，这是母亲去世前半个月。

第三次。他忽然想起老杨头大哥说的话，你母亲关过沈临渊三次，前两次都放了，第三次没有放。那第三次到底发生了什么？她进了这扇门，在矮几前坐下，刻下这行字，然后呢？

林一凡绕着矮几走了一圈，没有发现其他的刻字或物件。他又往墙角检查了一遍，墙面都是实心的，没有暗格。就连那几盏壁灯，他也伸手摸过底座，没有可拆卸的缝口。

他站在矮几前停顿了一下，目光落在那樽陶土酒坛上。

坛口封着一层黄泥，黄泥已经干裂。他犹豫了片刻，还是伸手把那层黄泥掰开。坛口露出，里面并没有酒——只有一卷纸，纸的质地很粗糙，像是从牛皮纸上裁下来的边角料，揉皱之后卷成一团，用一根红绳扎着。

他解开红绳，展开纸。

纸上只有一句话，字迹比矮几碗里的那行字要工整许多：“如果你走到这里，说明你已经见过门口那位了。他没告诉你的事——那枚27号陶土徽章，不是钥匙，是锁。”

林一凡猛地攥紧了纸，指尖微微发颤。

他低头看着自己放在口袋里的那枚27号徽章，影子说它是假的，老杨头大哥说它是钥匙，母亲却留下纸条说，它是锁。那它锁的是什么？

“锁的是门内那个人。”一个声音忽然从墙角处响起来。林一凡猛地转身，壁灯的光影里，矮几旁边不知何时多了一个人。那人背靠着墙站着，身形偏瘦，穿一件洗得发白的旧衬衫，袖子卷到小臂，左手腕上戴着一只老式的机械表。

林一凡的瞳孔剧烈收缩。

那张脸，在无数个深夜的梦里出现过，却在真实生活里已经很模糊了。此刻那人在昏黄的灯光里站着，脸上的笑容带着一丝疲惫和宽容，开口说：“你长高了，一凡。”

林一凡的嘴唇动了动，声音卡在喉咙里。

那人叹了口气，缓步走过来，在他面前两步远的地方停下，低下头看着他的眼睛：“你妈有没有告诉过你，进门第一件事是什么？”林一凡没有回答。那人温和地笑了笑，自己接下去说：

“是先关门。”

他朝林一凡身后示意了一下。林一凡顺着他的目光回过头，看到那扇门还留着一条手掌宽的缝，从缝里漏进来一缕灰白色的光，像一只没有瞳仁的眼睛，在外面窥视着这一切。他本能地想转身去关门，但就在他迈出步子的瞬间，那人伸手按住了他的肩膀。

“别回头。”那人说，声音低得像耳语，“门外站着的，是我。门里站着的，也是我。你现在只要做一件事——叫我的名字。”

林一凡看着那张脸，沉默了几秒，然后他开口，声音平静得连他自己都意外：

“你叫什么名字？”

那人笑了笑，没有回答。林一凡的视线越过他的肩膀，落在他身后矮几上的那根松木条上——七道横纹，像七道沉默的刀痕。他忽然明白了一件极为重要的事：母亲关了他三次，第三关，也许从来不是把他锁进门内，而是把一个不该出去的东西锁在门外。

他后退一步，把手伸进口袋里，攥住了那枚27号陶土徽章。

“你不是我爸。”他说，“你是门外那个。”

那人还在笑，但笑意已经不再抵达眼底。墙上的壁灯一齐晃动了一下，光线明明灭灭，把他的影子拉得极长，一直延伸到石室的穹顶——那影子肩上，多了一个宽大的轮廓，像极了一副打开的铁皮壳子。

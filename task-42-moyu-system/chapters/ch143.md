# 第143章 坐标迷雾

林一凡盯着赵夜白的眼睛，后背抵在B3层冰冷的混凝土墙壁上。刚才那句“你上辈子的尸体就在这个坐标的正上方”在他脑子里炸开，像一把生锈的刀直接捅进了记忆深处。

“你说清楚，什么叫我的尸体？”

赵夜白却已经转过身去，干瘦的躯体裹在一件深灰色风衣里，像一截随时会被吹断的枯枝。他没有回答林一凡的问题，只是抬手指了指天花板上的通风管道：“三分钟，安保巡逻就要经过B3层。不等你，也不等我。你自己决定。”

说完，他朝黑暗中一迈，像是被阴影吞没，只留下一串脚步声在廊道尽头消失。

林一凡握了握拳头，手心全是汗。他想追上去，但摸鱼雷达此刻仍是一片雪花，赵夜白的精神干扰场虽然被碎破技能震碎了一瞬，但残余的波动依然像一层雾一样罩住这片区域，让他什么都看不清楚。

他低头看了一眼手机，时间显示凌晨2:47。屏幕上有一条未读消息，是老王发来的：“你人呢？半夜不在宿舍，明天晨会钱总点名。”

林一凡深吸一口气，把手机揣回兜里，没有回复，也顾不上回复。他现在满脑子都是赵夜白的话，和他手里那张印着钥匙图案的名片。名片上的号码00042，和华夏金融中心B3层，到底藏着什么？

他没有走电梯，而是沿着楼梯往上爬。一步三级台阶，皮鞋在水泥地上发出闷响。等他推开一楼的安全门时，夜风灌进来，带着一股雨水洗过的潮气，他终于觉得自己的脑子清醒了一点。

就在这时，摸鱼系统面板在视野边缘弹了出来：

【警告：咸鱼值余额为0。当前系统功能受限，仅保留基础雷达（被动模式）。建议宿主尽快获取咸鱼值，否则在关键时刻无法使用兑换技能。】

林一凡骂了一声。他上辈子猝死前的最后一刻，咸鱼值还是满的，可重生回来后系统告诉他“因未知原因清零”。现在连一个最低级的技能都换不起。他没钱、没资源、没技能，眼前却摆着一个他完全看不懂的局——赵夜白、建眼计划、华夏金融中心，每一环都指向他上辈子的死因。

第二天早上九点，星辰科技的办公室里人和往常一样躁动。林一凡顶着两个黑眼圈坐在工位上，手里的咖啡凉了也没喝。他旁边组长老王探头看了他一眼，压低声音说：“你怎么了？脸白得跟纸似的。”

“昨晚没睡好。”

老王不疑有他，又塞过来一张打印纸：“钱总今天在集团大会上提了‘效率之星’评选，咱们组要出一个代表。我准备报你。”

林一凡愣了一下：“为什么要报我？”

老王挠了挠头：“你上次那个自动生成报告的本事，全组都看见了。说实话，咱们组现在就靠你撑着。你上，我放心。”

林一凡没法拒绝。老王待他不薄，帮他挡过两次砍绩效的刀，现在他要是推脱，反倒显得心虚。他点了点头：“行，我上。”

话音刚落，他摸鱼雷达忽然微弱地跳动了一下。不是雪花，也不是正常显示——像是一个信号的余波被什么东西拖拽着，朝远处某个方向延伸。那个方向，正对着窗外华夏金融中心的尖塔。

林一凡瞳孔一缩。难道赵夜白留下的精神干扰场，还残留在他的雷达核心上？他下意识地想用咸鱼值净化，却想起系统余额是零。

他攥紧了名片，金属边缘嵌进掌心的肉里。直觉告诉他，赵夜白说的坐标，背后还有人。

而那个人，可能就在这栋办公楼里。

# 第421章 不是活人

林一凡的瞳孔猛地一缩。

手机屏幕上的字像是被冷水浸透，一个字一个字地往他骨头里钻：“你面前那个‘老杨头’，不是活人。”

他猛地抬头看向老杨头大哥。石室里火把的光已经暗了一半，老杨头大哥仍站在原地，左眼的灰白硬壳不知何时脱落了一角，露出底下黑黢黢的孔洞，那孔洞边缘没有血，没有肉，只有一层干涸的、像烧焦的铜屑一样的东西。林一凡忽然想起一件事——他刚才说“老杨头大哥”抠出自己的左眼时，动作干脆利落，像在抠一颗嵌入木头的钉子，连眉头都没皱一下。正常人抠眼珠子会疼，会叫，会流血。

但地上没有一滴血。

老杨头大哥低头看了看地面，那孔洞里涌出一股极淡的铜灰烟，缓缓飘向石室穹顶。他沉默了一会儿，然后把那只完好的眼睛慢慢转向林一凡，轻声开口：“你说得对，我不是活人。”

林一凡后退了两步，后背抵住一根石柱。他盯着老杨头大哥，脑子里迅速翻过那些伏笔线索：归墟青铜通道尽头、第26颗陶土珠嵌在他左眼、第27颗含于舌下、手背另嵌三颗……所有珠子的位置，都像是被人刻意布下的锚点。

“那些陶土珠，”林一凡嗓子发干，“是你自己嵌进去的？”

“是。”老杨头大哥缓缓举起右手，那三颗手背上的陶土珠在手背皮肤下微微凸起，像三粒圆润的铜色瘤子，“26颗珠子，一颗钉一个位置，把魂钉在死人身上，死人就能替你走路、替你说话、替你喘气。你妈铸锁的时候，把一根锁芯烧进我胸口，我死了，但锁芯还活着，锁芯拖着我，不让我彻底散。”

“……你死了多久？”

“你妈烧我的时候，是三十年前。”

林一凡的脑子嗡了一声。三十年前，他还没出生。如果眼前这个老杨头大哥三十年前就死了，那之前他见过的所有东西——喊他“杨林”的声音、带他进暗门石室的向导、抠出左眼递给他珠子的手——全是一个死人在替他引路。

“你带我来这里，是为了什么？”

“把27号徽章给你。”老杨头大哥声音平静，“你妈说过，等翻到27的时候，把27号给你，把28号的事也告诉你。她没说那枚假的是什么样，只说了——‘真的那个，在铜水底下，还没捞出来。’”

“那你这枚27号是假的？”

“我不知道，”老杨头大哥摇摇头，“我只是记住你妈说的话，照做。”

林一凡低头看着手里的27号徽章，又看了一眼手机屏幕上那条刺眼的警告。一阵极轻的声音忽然从石室角落传来——像是一个人的手指在金属表面上轻轻叩击，不紧不慢，三下，停一下，又三下。

石室角落的阴影里，不知何时多了一道影子。那道影子立在墙边，没有光源背衬，却清清楚楚地投射在粗糙的石壁上，轮廓是一个人的上半身，手正抬着，手指在墙面上一下一下地叩着。

林一凡猛地想起那些伏笔——头顶撬门者、第四道影子消失与异动、黑影身份……他死死盯着那道影子，低声道：“你又是谁？”

叩击声停了。影子没有动，但那道贴着石壁的轮廓，却缓缓偏过头来，像是隔着墙壁、隔着无数层空间望向他。然后，影子开口了，声音隔着石壁传出来，像被压扁的铜管带出的气流，嗡嗡作响：

“我是打电话叫你回来的人。”

林一凡猛地攥紧手机。紧接着，他手机屏幕又亮了——那是一条来自陌生号码的消息，干净利落，只有一行字：

“B3的门，别从正门进。从锁舌后面进。”

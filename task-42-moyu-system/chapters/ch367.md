# 第367章 脚下的回声

“别进去”三个字亮在屏幕上，林一凡看了足有五秒。

赵日天站在他身后，也看到了那条短信，咬着牙道：“又是那家伙？从那个铁皮屋开始，就一直发短信——告诉你地图是假的，告诉你别信任何人，现在又让你别进去。神秘兮兮的，到底站哪边？”

林一凡把手机收起来：“地图确实有问题。但问题不在于地图真假，而在于……地图是指向这里的，但来了之后发现这里和地图上描述的不一样。”

赵日天皱眉：“哪里不一样？”

“地图上标注，‘南洞第三道石门，铁门打开即见收容所入口’。但这里，”林一凡用脚尖敲了敲铁板，“是一台机器，一个活着的结构。它需要钥匙，需要‘人齿’，还需要……某种身份验证。”

说到“身份验证”的时候，他不由自主地看了一眼手里的碎片上浮现的“春”字。铁皮盒里的“春”字，母亲当年写给父亲的……还是父亲送给母亲的？

赵日天没有追问林一凡在想什么。他转身走向石室边缘，蹲下来，把耳朵贴着石壁，拍了拍：“这边是空的。”

林一凡走过去，同样蹲下，侧耳一听——石壁后面传来了极为微弱的回声，不是水滴，也不是风声，更像是有人在用什么硬物敲击石壁，一下，两下，三下，间隔均匀。

三下之后停了几秒，又重复。

“这是摩尔斯电码吗？”赵日天问。

林一凡摇头：“不是电码，是……”他顿住了，心里猛地一沉，“这是‘叩门’的手法。我爸教过我——他说，在云顶山，如果听到有人叩石壁三声，别回答，转身走。”

“为什么？”

“因为叩三声的，不一定是活人。”

石壁后面的敲击声突然停了。整个石室的空气仿佛凝滞了一瞬，随后两人都听到了一声极轻的叹息——像是从他们脚下的地面深处发出来的。

那声叹息之后，铁板底下那片规律的脉动声变得更加清晰，一吸一吐，像是某种生物在呼吸换气。

赵日天退后半步：“林一凡，这地方让我想起一件事。”他压低声音，“我之前说过，我死过一次。你没追问。但今天我觉得应该让你知道——我死的地方，就是这样的结构：一个圆形的石室，地上有铁板，铁板下有呼吸声。”

林一凡没答话，他的目光落在那铁板表面刚浮现的“春”字碎片上。两片碎片拼在一起，金纹隐约连成了一句完整的话，开头两个字是“无论”，结尾是“别回头”。

“无论……别回头。”林一凡喃喃念出来。

赵日天没听清：“你说什么？”

“我说——”林一凡把两片碎片拼好，递给赵日天看，“这句话，不全。中间缺的内容，应该在铁板底下。”

赵日天沉默了一会儿，说：“那就只能是进去看。”

林一凡没立刻回答。手机又震了，1147号发了第四条短信：“不要相信你看到的一切。包括你父亲留下的字。他当年也进去了。”

林一凡攥紧手机，指节泛白：“1147号，你到底是谁？”

短信的输入框旁边显示了一个灰色的字——“发件人可通过信号追踪定位。”

他回了一条：“你在哪里？”

三秒后，短信回了两个字：“上面。”

林一凡猛的抬头。石室的穹顶上方有好几道天然的裂缝，其中一条狭长的裂缝里，隐约可以看到一点极淡的、不属于自然光的蓝光——一闪一闪，像是有人在裂缝上面举着一块屏幕。

赵日天也看到了。两人几乎同时站起来，往那道裂缝下方跑去。

裂缝很高，距离地面至少有五六米，石壁上全是湿滑的青苔，没有任何可以直接攀爬的支点。但就在他们抬头张望的时候，那一点蓝光突然灭了，紧接着，裂缝中掉下来一样东西，“啪”地一声砸在他们脚边。

是一只老式的翻盖手机。屏幕裂了，但还能开机。开机后，桌面上只有一个文件——一段录像。缩略图里是一张铁皮屋的照片，上面写着“26”。

林一凡按下播放键。录像画面摇晃，像是有人把手机举在头顶拍的，画面里是一扇铁门，门上刷着已经脱漆的编号：“26”。镜头缓缓接近铁门，画面外传来一个沙哑的声音：“第26号收容点。里面的人，是当年编号的制定者之一。他自己给自己写了编号……叫‘零’。”

镜头推开铁门。刺眼的白光填满屏幕。随即画面剧烈摇晃，然后黑了。

“以此为准。别进铁板下面——那不是收容所的门，是赌局的开关。”

赵日天深吸了一口凉气：“赌局的开关？”

林一凡盯着那台翻盖手机，没有回答。铁板底下的呼吸声忽然变大了，大到整个石室都在微微震颤。

震颤中，铁板中央缓缓裂开一道细缝，缝里透出微弱的绿光。那道绿光里，浮出一个人影的形状——小小一个，弯着腰，似乎在研究什么东西。

那个人影微微抬起了头。林一凡看不清他的脸，但他看见那个人影手里拿着一样东西——一枚和他手里一模一样的碎片。

四分之一的钥匙碎片。

然后，裂缝合上了。石室重新陷入沉寂。只剩铁板底下的呼吸声，一声比一声沉。

林一凡站在原地良久，终于开口：“赵日天，我决定进去。”

赵日天看了他几秒：“我跟你一起。”

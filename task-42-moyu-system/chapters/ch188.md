# 第188章 地下伏兵

脚步声逼近到门外二十米左右停住了。林一凡快速扫视四周，机房只有一扇出入口，没有其他退路。老周却完全不慌，他绕到“人力之源”背面，蹲下来，在一处钢板接缝处用力一撬——“咔”的一声，一道暗门滑开。

“当初建这层的人给自己留了后路。”老周率先钻了进去，“你们俩快点。”

林一凡没犹豫，弯腰跟上。赵日天捏着硬币骂了一句“真他妈像下水道的老鼠”，也钻了进来。暗门合拢的瞬间，外面的脚步声恰好抵达，有人敲了敲铁门：“老周，我知道你在里面。老板说了，今天不交人，你那条命线就别想再续了。”

老周在黑暗中一声不吭。暗门后的通道更窄，只能猫着腰走。三人摸黑前进约两分钟，前方出现一道金属爬梯，直通上方。老周抬头看了看：“上去之后是负一层停车场，D 区，角落车辆位。”

“你的人？”林一凡问。

“没别人了。就我一把老骨头。”老周苦笑，“你们得自己跑出去。”

赵日天从口袋里摸出一张卡片：“先别急。老子花钱买的‘系统权限开门器’还有三次使用，外面那帮人能追进暗门，是因为他们也有系统权限道具。但我们只要先到地面就赢——跑。”

林一凡快速盘算：老周显然知道更多关于“人力之源”和钱总的底细，但他现在故意不说。眼下也不是逼问的时候。他爬梯而上，双手刚撑开地面检修盖，一辆黑色商务车就停在两米外，车窗缓缓降下，露出一张戴墨镜的脸。

“林一凡。”那人叫他的名字，“钱总请你上车。”

“不去。”林一凡翻身而出，顺手扶起老周，“我约了人喝下午茶。”

墨镜男笑了：“你同事赵日天的卡里，有 120 万是钱总转过去的。你想知道他从入职起就帮你挡了多少麻烦吗？”

赵日天也从井下钻了出来，额头青筋跳了两下：“那是卖信息换的。老板给我钱，我给他情报——对，我承认。我一开始就是来盯着你的。但后来我改主意了，这不叫背叛，叫弃暗投明。”

林一凡看了赵日天一眼，忽然觉得好笑。这人的转变早在天桥那晚就很有迹可循，从“雇演员试探”到“主动曝光钱总的系统权限”，每一步都在往他这边靠。现在这 120 万旧账被翻出来，反而让他心里踏实了。

“我跟你走可以。”林一凡对墨镜男说，“但让他俩先走。”

墨镜男摇头：“钱总只买了你。”

老周忽然笑了。他从怀里掏出一张泛黄的卡片，上面印着一行编码——和“人力之源”侧面的编号完全一致。“你回去告诉老板，就说‘老周把钥匙交给小林了’。他自然懂。”

墨镜男脸色一变，似乎要发作。但这张卡片显然含有某种他不敢触碰的信号。他盯了老周两秒，重新戴好墨镜，视线又转向林一凡：“钱总只给了三分钟。你选。”

系统面板忽然弹出一行字：

【隐藏支线触发：老周的真名与工号背后藏着一笔“原初一笔账”——人力之源的所有者曾用它换取过一次“更改命运”的机会。当前操作选项：A. 随墨镜男上车，直接面见钱总；B. 拒绝上车，与老周、赵日天同撤，但人力之源连接将被钱总单方面加码至“衰竭”级。】

林一凡看着那个选项，心里默默说了一句：“我选 C。”

系统沉默了一秒，然后弹出一行从未见过的字：

【选项 C 已解锁。执行条件：支付你当前全部咸鱼值余额。本次代价将不再退还。】

他扫了一眼余额：12800 咸鱼值。是攒了两世的积蓄。但他知道自己没有别的路——要么当面跟钱总摊牌，要么被扣上“待重连”的绳套越勒越紧。他深吸一口气，在选项中按下 C。

墨镜男的车门已经打开一条缝。林一凡迈步走了过去，但没上车，只是靠在门框上，压低声音说：“告诉钱总——‘人力之源’的真正钥匙，不在这张卡片上。在我脑子里。”

墨镜男愣了半秒，没说话。然后他缓缓关上车门，用极低的声音回了一句：“那这趟车，你就更得上了。”

林一凡没有回头，但能感觉到老周和赵日天的目光一直盯着他的后背，直到那扇车门彻底合拢。

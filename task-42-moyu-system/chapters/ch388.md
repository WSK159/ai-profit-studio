# 第388章 三洋录音机

石阶入口处潮湿的霉味突然变得黏稠，像是一层无形的膜贴在了每个人的皮肤上。那台三洋录音机还在继续转动，磁带沙沙的声音在逼仄的石壁间来回弹射。

佝偻老人握着石灰块的手僵在半空。他盯着沈稚川手里的录音机，浑浊的眼珠里涌起一丝奇异的波动，像是水面下有什么东西翻滚了一下又沉下去。

“你妈的东西，”老人说，嗓音枯哑，“当年是我亲手放进棺材里的。”

沈稚川没有说话，她的指尖绷得发白，录音机里那段声音却还在继续——沈临渊的声音平静而低哑，像是隔着十几年岁月的一层雾：

“……这盘磁带会在门开的时候自动播放。我知道有一天你会听到它，但我不知道那天的你会是什么样子。所以我只说几件事。第一，不要相信任何人，包括三叔，包括你身边那个摸鱼的小子。”

老人嗤笑一声，手里的石灰块在指间碾成了粉末：“他连我都不信，倒也没说错。”

“第二，”录音机里的声音顿了顿，“那块铁皮片，别还给那个灰袍人。归墟会自己找上你。”

林一凡下意识摸了一下怀里那块刻着“归墟”二字的铁皮片，金属表面冰凉，甚至有些刺骨。

“第三，”沈临渊的声音忽然压得更低，几乎像是贴着录音机在说话，“零号房间里躺着的不是尸体，是船票。”

“船票”两个字在石阶入口回荡了一圈，然后被黑暗吞没。磁带沙沙几声，戛然而止。

三叔缓缓蹲下来，用手掌把地上的石灰线抹掉了大半，动作慢得像是在和什么看不见的东西商量。他抹到“零”号房间的位置时停住了。

“沈临渊被救上来之后，疯了整整三个月，”三叔没有抬头，声音像从一口枯井里提上来的，“每天半夜爬起来，用指甲在墙上抠字，抠的全是‘归墟’和‘船票’。我当时以为他是在井底下撞了邪。直到有一天，他清醒过来，跟我说了一句话。”

林一凡：“什么话？”

三叔抬起眼看他。老人那双浑浊的眼睛里有一瞬间清明得吓人，像是乌云裂开一道缝，露出后面冰冷的月光：“他说，井底下有一条船，船上的人在等他回去。”

“……”

三叔又把那句话重复了一遍，像是怕他们没听清：“他说得很清楚，他这辈子要做的就是找到那条船。我当时以为他是疯了，后来我才知道，那个地方每一年都在缩小。”

“什么地方？”沈稚川的声音几乎像是从牙缝里挤出来的。

三叔却没有回答她。他转身走向石阶深处，瘦削的背影像一根插在岩壁里的干柴棒，末了他丢下一句话：“你们要下去可以，但不许带录音机。沈临渊的话，听到这里就够了，再往下听，你们会后悔的。”

台阶从入口处向下延伸了大约七八米，便在石壁处折转。三叔的声音从转角后传来，带着某种心不在焉的回响：“要是非要下去，走第三级台阶，脚踩在右侧角上，别踩中间。”

沈稚川站在原地没有动，她低头看着手里的录音机，磁带已经停了，卷轴停在最后一点空白的透明引带位置，缓缓转动着，发出一声轻微的咔哒。

“他说的是对的，”沈稚川忽然说，“沈临渊确实不信任何人——包括他自己。所以这段话一定还剩了半句。”

林一凡拧眉：“但磁带已经到头。”

“他不是说在录音带里。”沈稚川把录音机翻了过来，背面贴着一块旧得发黄的医用胶布，透过胶布能看到底下有珠笔写字的痕迹。她小心地撕开一个角，露出几个模糊的字……

“……他写的是‘船票在第三扇门后面’，”她念出声，“但那扇门说的是哪一扇？”

林一凡忽然觉得脚底的台阶震了一下。不是地震，是某种深处的东西在移动。那块收在他怀里的铁皮片上，“归墟”两个字的暗红光泽微微亮了一瞬，又熄了下去。

三叔的声音从转角深处传出来，带着一点说不清的笑意：“下来吧。那扇门已经开了。”

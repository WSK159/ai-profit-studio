# 第61章 天台夜话

晚上七点五十八分，林一凡推开顶层消防门，夜风裹着城市喧嚣扑在脸上。秦氏B座的天台空无一人，只有几个废弃的空调外机和几根晾衣绳，远处写字楼群光斑如棋盘。

赵日天已经站在天台边缘，背对他，手里转着一支签字笔——正是下午那支。听到脚步声，他没回头：“挺准时。”

“你也是，提前到了。”林一凡走到他旁边两步距离停下，目光扫过他衣领下方裸露的锁骨——那里隐约有一道银灰色的纹路，像电路板走线，跟自己的启动烙印位置完全一致。

赵日天转身，盯着他看了三秒，忽然露出一个笑容，那笑容里有疲惫：“你在看这个？”他指了指锁骨，“你的那个，在左手腕内侧吧？”

林一凡没有否认。赵日天继续说：“咱们都是宿主，所以我在你面前不说暗话。你什么时候绑定的？”

“三个月前。你呢？”

“五年前。”赵日天把那支笔插回口袋，脸上没有表情，“那是我在上一家公司的倒数第二天。那天晚上加班到凌晨四点，我趴在工位上打了个盹，醒来后系统就绑定了。”

林一凡等了等，见他停下，追问：“然后呢？”

赵日天微微仰头，看向夜空：“那时候我的系统叫‘奋斗系统’——干的越多，奖励越多。我用了两年时间，从基层做到副总，把公司干上市，然后那家公司被资本收购，钱总看中我，把我挖到星辰科技。来的时候，我的系统还是奋斗版。”

“后来变成卷王系统？”

“不。”赵日天忽然压低声音，“后来它变成了‘坟场系统’。因为我发现，它开始发布让我无法拒绝的任务——‘连续工作72小时，奖励XX期权’、‘挤掉组长老王，奖励三倍薪资’、‘举报同事消极怠工，奖励年度晋升’。每一项任务都像温水煮青蛙，慢慢把我变成一个……活该被所有人讨厌的东西。”

林一凡沉默了几秒：“所以你被废弃，是因为你开始拒绝任务？”

赵日天转过身来，夜风把他头发吹得凌乱：“我拒绝了一个关键任务，它想让我偷走钱总保险柜里的核心数据压缩包——那是整个星辰科技的底层代码库。我预感到，一旦我把那东西交给系统，我就会彻底失去自主意识，变成纯粹的工具。所以我拒绝了。”

“然后它就把你废弃了？”

“它说：‘宿主ZTY-01契约失效，惩罚：工资清零、绩效归零、职务降级。’剩下的，你都知道了。”赵日天笑得苦涩，“但我还活着，没有死，也没有消失。这说明系统对宿主的控制是有上限的——它不能直接杀人。”

林一凡脑子里闪过系统最后那句警告“资本神已苏醒”，他问：“你见过‘资本神’吗？”

赵日天沉默很久：“没直接见过。但我见过它的一次显现——在总公司顶层会议室，凌晨三点，整个屋子的灯全灭了，钱总站在投影幕布前，幕布上什么都没有，可他对着空气说话。我当时就在门口，听到他说了一句……”他声音压到极低，“‘我会按时进贡，请再宽限一次。’”

林一凡心头一凛：“钱总和它，真的在做交易？”

“我不知道内容。但我知道一件事——”赵日天忽然抬头看着林一凡，“你之所以被选中，可能是因为你是重生者。你死过一次，知道结局，所以你拒绝‘996’的意愿比任何人都强。你的系统是‘反资本’设计的，我的系统是‘资本’设计的。这两套系统同时存在，你觉得这意味着什么？”

林一凡瞳孔骤缩。他还没开口，赵日天的手机忽然亮了，屏幕上跳出一条消息：【钱总：赵日天，你后天下午3点去财务部……配合审计流程。】

赵日天看了一眼，脸色微变：“审计？这个节点来审计，不对劲。”

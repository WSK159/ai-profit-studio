# 第398章 笼中囚徒

水牢里那股呵气声像潮水退去前的呜咽，贴着水面滑过的同时，带起一串细小的涟漪。铁皮壳子的胸口剧烈起伏了一下，又从喉咙里挤出一声含混的咕哝，没再开口。

沈临渊被锁在笼中，嘴角却微微翘起，像是听到了什么有趣的暗号。

“你这表情什么意思？”林一凡盯着他。

“她在说——‘别信他’。”沈临渊慢条斯理地抬起下巴，朝锁芯方向努了努嘴，“可你觉得，一个被关在笼子里的人，和一个卡在铁皮壳子里的‘半个人’，谁更值得信？”

林一凡没接话。

他的真实视界还开着，眼前的景象层层叠叠——锁链是红线绞索、笼子是黑雾骨架、铁皮壳子是墓碑，而墓碑上那行字终于被他看清了：

“未完成对赌者·编号零·半身”

编号零。

不是名字，是一个代称。就像系统面板里永远只显示“宿主”二字，不给你姓名。

“零是双生体，”林一凡开口，声音压得极低，“一半被锁在笼中，一半寄居在铁皮壳子上。那锁芯里的手指，是‘零’的宿主？”

沈临渊的笑容僵了一瞬。

“你是真不怕死。”他说，“当着她的面讨论她。”

“她”是谁？林一凡没有追问。因为就在沈临渊说完这句话的瞬间，水牢的左侧墙壁上，那些锈蚀的铁皮忽然开始一粒一粒地渗出水珠。水珠顺着墙面蜿蜒而下，在墙角汇成一小滩，然后又沿着地砖的缝隙爬向林一凡的脚边。

像一条看不见的蛇。

“退后！”林一凡猛地抽出脚下的水渍中插着的半截铁管，朝地面一砸。水珠瞬间炸开，四散飞溅，但那道爬行的水痕没有消失，而是停在了离他半尺远的位置，画出一个小圈。

圈里，浮现出一个字——

“帮”。

林一凡盯着那个字，心跳快了半拍。系统的提示音适时响起：“检测到高阶信息交互，是否消耗200咸鱼值解码？”他选了是。面板上，咸鱼值从12850跳到了12650，与此同时，那个“帮”字旁边又浮现出第二行字，字体歪斜，像用指甲在墙皮上刻出来的：

“他出来，我们都得死。”

“他”是谁？是指铁皮壳子里的“零”，还是……

林一凡抬起头，目光穿过沈临渊的笼子，落在笼子背后更深处的黑暗里。真实视界下，那里的水面比别处低了一块，隐约能看到一道台阶，通往水底某处。台阶上覆着绿苔，苔下一只巴掌大的锁，锁舌咬住一条手臂粗的铁链，铁链另一端沉入水中，不知栓着什么。

水底有东西。

而且那东西正在呼吸。

林一凡的呼吸跟着放缓了半拍。他问沈临渊：“你被困在这里多久了？”

沈临渊歪着头想了想：“按照外面的四季算，大概……七年。”

“七年里，有人来过这里？”

“来过三个。”沈临渊的声音平淡，“一个是送饭的哑巴，走了就没再回来；一个是穿着星辰科技工服的年轻人，在水面上站了三天，掉了半截烟头就走了；最后一个——”

他顿了顿，目光落在铁皮壳子身上。

“最后一个就是你大哥。”

林一凡心头一震。老杨头的大哥——铁皮壳子——果然来过，而且不是生前来的，是死后被什么东西塞进了这具躯壳里。他盯着铁皮壳子，铁皮壳子肩头的接缝处微微张开一条细缝，里面透出一丝干枯的、像树叶一样的皮肤。

那不是人的皮肤。

林一凡忍住上前扒开看的冲动，退后一步。水底那道呼吸声忽然停了，取而代之的，是一个极细的、像孩子一样的声音从水下传上来：

“哥……你回来了？”

铁皮壳子的身体猛地一震，发出一声刺耳的金属摩擦声。沈临渊脸色变了，脱口道：“坏了，它醒了——”

笼中的锁链同时绷紧，哗啦啦一阵狂响。而锁芯里那根女人的手指，正缓缓地、一根一根地，从锁孔里往外爬。

林一凡后退三步，下意识握紧了腰间的陶土徽章。

徽章上的编号，是28。而沈临渊的锁芯里掉出来的那枚，是27。

两枚徽章，一个铁皮壳子，一个笼中囚徒，一个锁芯里的手指。他忽然意识到一个之前被忽略的问题——27和28，从来不是同一批人手里的东西。

27在铁皮壳子身上，28在沈临渊的笼子里。而老杨头给他的那枚28，才是真正属于“零”的信物。

“你手里的徽章，”沈临渊忽然开口，声音压得极低，“是哪儿来的？”

“别人给的。”

“别人是谁？”

林一凡没有直接回答，而是反问：“你认识一个姓孙的？”

沈临渊的瞳孔骤缩。

水下那个孩子的呼吸声，再次响起。而这一次，水面真的裂开了一道缝。

# 第79章 黑暗中的交易

凌晨一点十七分，公司大楼外墙的应急灯在风中忽明忽灭，像一只濒死的萤火虫。

林一凡蹲在风口楼梯井的铁门后，后背紧贴着冰凉的水泥墙，右手攥着硬盘，左手按着膝盖上那道被铁皮划破的口子。刘彤蹲在他对面，嘴唇发白，正用手机屏幕微弱的光检查四周。

“他们没跟上来。”她压低声音说，“我刚才看见那群人往B区配电房方向跑了。”

林一凡没回答，脑子里还在回放刚才的画面——周莉转身冲出去前，往他手里塞了一枚U盘，说了一句只有他能听见的话：“别信任何人。包括我。”

这句话太像钓鱼了。

“我们现在去哪？”刘彤问。

林一凡把硬盘塞进防风衣内侧的袋子里，拉链拉到顶，说：“先离开公司范围。钱总的审计团队既然敢在夜里搞突袭，说明他已经不打算演了。”

两人顺着裂缝里长满杂草的楼梯往下走，绕过地下车库入口的栏杆，翻过一道矮墙，落在市政绿化带里。深夜的城市安静得像被按了静音键，只有远处环路上的卡车声偶尔碾过。

林一凡没走大路，带着刘彤拐进城西科技园背后的一条旧巷。这条巷子夹在两栋烂尾楼之间，白天都没什么人，夜里更是黑得伸手不见五指。他掏出手机，电量只剩8%，但足够打开一个藏在备忘录里的加密地址——那是他重生前就记下的一处安全屋，属于他前世的某个“关键节点”人物。

“你还有这种地方？”刘彤看着那扇锈迹斑斑的铁门，表情复杂，“我怎么觉得你比我想象的还要老谋深算。”

“这叫生存本能。”林一凡撬开锁，推门进去。

屋里落了一层灰，但水电尚通，角落里甚至有一台老式台式机。他把硬盘数据线接上去，开机，屏幕上跳出密码框。他输入自己记忆中那串数字——江雪生前惯用的生日+工号+三位随机码——第一次就过了。

“运气不错。”他松了口气。

数据窗口弹出的瞬间，他的心跳猛地滞了一拍。

屏幕上，第三份硬盘的解密进度条卡在49.7%，停住了。

“怎么回事？”刘彤凑过来看。

林一凡皱眉，点开系统日志，看到一行红色报错：**密匙不完整。需要第二验证段（身份芯片）。**

“周莉给的是加密切片，但缺一段身份芯片的验证码。”他低声说，“她说过江雪留下的数据被拆成了三个部分，对吧？第一块和第二块我们已经拿到了，第三块是这份。但如果密匙分了三段，那还有一段在哪？”

刘彤沉默了。

就在这时，他的手机震动了一下。屏幕上多了一条消息，来自一个被他备注为“赵日天·卷王”的号码，内容只有六个字：

**“我在他们手上。”**

然后是一串位置坐标——城北旧货市场，凌晨三点。

林一凡盯着那行字，指尖发凉。

“赵日天不是去问话了吗？”刘彤的语气也变了，“按理说他不该有手机。这条消息，要么是他抢的，要么是有人用他的手机发的。”

“如果是后者，那这就是个局。”林一凡把手机屏幕反扣在桌上，“但我们不能不去。”

“万一你已经暴露了呢？”

“我什么时候没暴露过？”林一凡咧嘴笑了笑，但眼底没有半点笑意，“但赵日天这个家伙，再怎么说也是这个局里唯一能跟我对打的人。他要真栽了，我也没法独善其身。”

他转身从抽屉里翻出一把生锈的扳手，掂了掂重量，别在腰后。

“走，去会一会他们。”

# 第139章 地下的眼睛

钱国豪的名片在指尖转了三圈，林一凡盯着那串“00042”的号码，眉头越锁越紧。赵夜白的话像根刺扎在脑子里——“你上一世的尸体就在这下头。”他扫了一眼神秘人消失的方向，那半张脸苍白得不像活人，可说话时的呼吸声又是真的。

林一凡没急着走。他蹲下身，指尖摸过地面。B3层的混凝土裂缝里透着一股铁锈味，像是地下埋着什么巨大的金属物件。他闭上眼，试图调动摸鱼雷达，然而识海深处空空荡荡——咸鱼值被清零的后遗症还在，雷达像个断电的显示器，只剩一片雪花噪点。

他咬了咬牙，站起来，顺着走廊往东走了三十步，一扇铁门半掩着。门缝里漏出一线冷白的光。

门后是一间房，面积不大，四面墙都刷着哑光漆，正中摆着张老式木桌，桌上摊着一份泛黄的蓝图。林一凡凑近一看，图纸角落印着“华夏金融中心——地下结构扩展方案（三期）”，日期是八年前，比他入职星辰科技还早两年。图纸中央，B3层的平面图上用红笔画了一个圈，圈里标着“阻尼器检修井”，旁边用铅笔斜斜写着三个字——钥匙孔。

他掏出名片，对着图纸比了比。名片背面的钥匙标志和那个红圈的大小几乎重合。林一凡只觉得后背发凉，这栋楼的地下，似乎藏着一个连图纸注释都含糊带过的空间。他想再翻翻桌上其他文件，门外突然传来脚步声，不轻不重，但频率异常规整——像机器人的步态。

他立刻矮身藏到桌后。门被推开，一双灰色工装裤的腿迈进来。来人没开灯，只站在门口，手上提着一把类似测温枪的装置，对着房间扫了一圈。那装置发出的红外线扫过林一凡藏身的桌子时，发出“嘀”的一声轻响，但那人只是低头看了看读数，念叨了句“没人”，又转身走了。

林一凡等了整整三分钟，才从桌后爬出来。他瞥了一眼桌上那张蓝图，发现红圈旁边被刚刚那人放下了一样东西——一枚银色钥匙，带着微锈，齿形奇特，和他前世在工牌上挂的那把旧钥匙一模一样。他认得出那枚钥匙，因为那是他上辈子捡的，一直没弄明白开什么锁，直到死前一周还在抽屉里放着。

他深吸一口气，伸手把钥匙攥进掌心。冰冷的金属触感传来，他的脑袋里忽然炸开一声轻响，像有什么东西解锁了。紧跟着，一个半透明的提示框浮现在视野角落：

【咸鱼值恢复中……当前：5/10000】

那点咸鱼值连一次摸鱼雷达都启动不了，但至少，系统那个死样子还没彻底罢工。林一凡把钥匙和名片一起塞进内兜，走出铁门，沿着楼梯往上爬。他决定先去监控室看看今晚的录像——那人扫过房间时手里那个装置，到底是在找什么？

回到地面层时，夜风灌进来，他打了个激灵。手机震了一下，老王发来一条微信：“一凡你没事吧？刚才突然联系不上你，我这边精神头有点怪，好像有人在念我名字。”林一凡看着那行字，想起赵夜白说“老王身上有精神标记”的话，手指悬在键盘上方，半天只回了一句：“早点睡，明天我请你吃早饭。”

他锁上手机，抬头看了一眼星辰科技大楼高耸的剪影。顶楼，钱国豪办公室的灯还亮着。

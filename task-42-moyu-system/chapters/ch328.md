# 第328章 生门之钥

林一凡的手指触到那枚黄铜钥匙的瞬间，梯井底部所有灯光同时熄灭，黑暗像潮水一样吞没了一切。

“别动！”沈望的声音从黑暗中传来，带着一种三十年老江湖的警觉，“你碰到机关了。”

林一凡僵在原地，指尖的金属触感冰凉刺骨。他的呼吸在黑暗中格外清晰，心脏在胸腔里擂鼓般跳动。三秒钟后，应急灯一盏盏亮起，昏黄的光线把每个人的影子拉得又长又扭曲。

他低头看去，钥匙已经不在墙洞里了。

“钥匙呢？”孙满仓的声音带着压抑的惊骇。

林一凡摊开手掌——钥匙确实在他手里。黄铜质地，齿纹磨损严重，柄部刻着一个“生”字，和灰袍人之前展示的那枚如出一辙。他下意识摸向口袋，孙满仓之前给他的那枚钥匙还在，摸起来温润。两枚钥匙同时入手，他感到一种说不清的呼应，像是磁铁吸住了另一极。

“两枚钥匙……一枚‘死’，一枚‘生’。”灰袍人不知何时已经走到近前，目光死死盯着林一凡手中的钥匙，“沈临渊留下的布局，比我想象的更深。”

沈望靠在梯井壁上，深深吸了口气：“那扇门，我守了三十年。今天终于等到有人替我开它了。”他指了指墙洞敞开的暗格后方——原本锁住的石阶入口，此刻已经裂开一道半人宽的缝隙，湿润的泥土气味从中涌出来，混着某种更古老的、像是铁锈与纸张混合的味道。

“这门只能由姓沈的打开吗？”林一凡问。

沈望没有直接回答，而是从怀里掏出一枚老式怀表——正是他之前给林一凡看过的那块表，与林一凡挂坠上的怀表同牌。他打开表盖，表盘后的金属夹层里嵌着一张泛黄的纸条，字迹已经褪色大半，但依稀可辨：“生门自向死而生之人开。”

他读完这句话后，沉默了一会儿，说：“我让孙满仓带你来，是因为我信这是他师父的安排。但真正让我确定你是那个‘来人’的，是你脖子上那块挂坠。沈临渊当年有句话——‘我的儿子，一个替他守门，一个替他去开门。’”

林一凡的后背有些发凉。他知道自己是沈临渊的另一个儿子——沈望自己方才说过这话。但此刻沈望站在面前，用看一个陌生人的眼神看他，仿佛他们之间除了那点血缘，什么联系都没有。沈望说他自己“忘记了自己的身份”，可这一刻他说起沈临渊、说起门、说起“生门自向死而生之人开”，眼神清醒得可怕。

“你到底是谁？”林一凡忍不住问，“你说你是替沈临渊守通道的人，你又说你是他的儿子。你现在到底是真的沈望，还是钱总？你记得多少？”

沈望笑了笑，笑容疲惫而坦然：“我记得我是‘守门人’。至于钱总……那是另一个名字，另一副面具。三十年过去，连我自己也分不清哪张脸是真的了。”他的目光落在林一凡手中的两枚钥匙上，像落在某种等待已久的宿命上，“我唯一记得清清楚楚的，是这张纸条和这把钥匙的用途。”

灰袍人忽然开口：“两枚钥匙，一枚开‘门’，一枚开‘锁’。林一凡，你手里两枚都有了——你打算怎么用？”

林一凡把两枚钥匙并排放在掌心，铜锈的纹路几乎一模一样，只是柄部一个“生”，一个“死”。沈临渊留下的选择题，此刻以最具体的形式摆在他面前。他想起录音笔里那句话——“33米处是最后一站，你要选择继续走下去，还是回头”。

他深吸口气，抬头看向裂开的石阶入口。昏黄的灯光没入射孔，内部一片漆黑，看不见底。

“走下去。”他说，“但我不打算只开一扇门。”

他把“生”字钥匙插进暗格内侧唯一锁孔的瞬间，整个梯井发出一声低沉的轰鸣，像有什么巨大而古老的东西被从沉睡中唤醒。灰袍人瞳孔骤缩，低声道：“石阶下面的通道开了。”

“还有别的路。”林一凡把“死”字钥匙翻了个面，突然发现钥匙柄的侧面还有一行几乎被锈蚀磨平的铭文。他凑近应急灯光，一个字一个字地辨认：“第三梯之下，零。”

沈望的脸色在昏黄的灯光下剧变。

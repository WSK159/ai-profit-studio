# 第190章 密码的涟漪

林一凡坐在顶层会议室的真皮椅子上，指尖轻轻叩着桌面。窗外是凌晨四点的城市，霓虹灯从高处看去像一片碎掉的星海。钱总已经离开十五分钟，合同文本就摊在他面前，白纸黑字的“特别技术顾问”六个字泛着油墨的光。

他深吸一口气，心里有什么东西正在缓慢调转方向。

“老周那边有信儿了？”他开口问身后的安全主管。那人面无表情地摇了摇头：“我只能确认他已经被送去了三号安全屋，具体位置无权知情。”

“行。”林一凡低头笑了，“钱总办事倒还算讲信用。”

安全主管没有说话，只是抬腕看了看表。林一凡点了点头，站起身走向门外。走廊里安静得只剩皮鞋落在花岗岩地面的回响。他故意放慢步子，从顶层到地下室，每走一层都多停几秒，六楼、五楼、四楼……

直到电梯门打开，他走进星辰科技的地下停车库，一辆新款灰色SUV停在角落，车灯闪了两下。

林一凡钻进驾驶座，车载屏幕上自动亮起一条加密通讯请求。他按下接听键，一个经过变声处理的声音从音响里传出来：

“验证码：七号样本。确认身份：林一凡。”

“是我。”他靠进座椅里，眼睛盯着后视镜中远处闪烁的监控探头，“钱总已经答应把赵日天的卷王系统权限调出来激活休眠代码，条件是让我做他的‘特别技术顾问’。”

对面沉默了两秒，声音再次响起：“你能确定赵日天会配合？”

林一凡嘴角动了动：“我不能确定。但赵日天欠他120万泰铢，这是钱总布的局。老周被保下来，是因为我手上这份代码是钱总要的东西。筹码在他手里，棋子也得按他的规则走。”他顿了一下，“但赵日天的性格不是任人摆布的。”

“你的意思是……他会反水？”

“他一定会。”林一凡说，“赵日天那种人，整天卷来卷去就是怕被人踩在脚下。现在他被钱总当作激活密钥来用，等于告诉他——你不用卷了，你的存在价值就是被当成钥匙。”

他轻踩油门，车子缓慢滑出地下车库。

“所以他要么拼命证明自己有独立价值，要么他就会找别人交易，把我的系统信息卖给更大的势力。”林一凡顿了顿，“我需要你帮我查一个人。”

“谁？”

“钱总背后那条线上的人。我怀疑……”他打进转向灯，目光沉了下来，“这条线的上游，不是人间。”

通讯那头传来一阵摩擦声，像是有人在一堆图纸里翻找东西。声音再度响起，语气比之前沉了几度：“你猜的没错。我们监控到钱总名下的境外账户近三个月有十二笔大额转账，源头全部指向同一个序列号。那串序列号，和劳动神与资本神的赌局协议文件编号格式完全一致。”

林一凡握着方向盘的手指微微收紧。“所以钱总跟资本神之间……”

“不只是交易。”那声音截断他，“林一凡，你还记得你绑定时系统提到过的‘反卷护盾’吗？”

“记得。”

“那东西不是用来防加班的。”通讯那头的声音压低，“是用来防神降条件的激活条件之一。”

车内安静了两秒。林一凡缓缓把车停在路边，他转过头看向窗外。凌晨的街道上路灯昏黄，一个人影从对面便利店走出来。那个人的步态，他曾在某一天的天桥上见过——

一模一样。

他按下语音录制键：“告诉我，那个序列号的最后三位是多少？”

对面沉默片刻：“171。”

林一凡的瞳孔猛缩。那是他重生绑定系统前的工号尾号。三年前的那个夜晚，他抽不完的最后一根烟，和永远没写完的代码，都埋在同一个数字下面。

车窗外的人影停下脚步，像是意识到什么，缓缓抬头看向他的方向。灯光下那张脸，他看得清清楚楚——是他自己。

只是穿着的，是那件他死时穿的，沾着咖啡渍的格子衬衫。

“林一凡，”通讯那头的声音突然紧张起来，“你在听吗？”

“在听。”他盯着窗外的自己，声音却意外地平稳，“我在听。但你可能需要给我解释一下——为什么我看见的‘自己’，还站在三年前的夜班公交站台上。”

车载屏幕上的通讯信号突然变成了满格的红色感叹号，紧接着，所有的系统面板同时弹出了一行字——咸鱼值冷却结束后，系统将执行一次“底层归位”程序。

归位，回哪去？

# 第177章 门外的脚步声

脚步声停在门外，不紧不慢，像是刻意让屋里的人听见。林一凡握着手机的手微微一紧，赵日天那句“不要打开那扇门”还在耳畔回响，通话却已经断了。

他屏住呼吸，目光扫过出租屋狭小的空间——老王寄来的旧箱摊开在地板上，芯片卡插在笔记本电脑的读卡器里，结构图在这间屋子的每一个角落铺展开来。而门外那个人的呼吸声，几乎贴着门板。

“咚咚咚。”

敲门声响起，三下，不急不缓，带着某种职业化的礼貌。

林一凡看了一眼手机屏幕，凌晨一点四十七分。这个时间，正常人不会拜访任何人。

“谁？”他没有动，声音平静得像面对一个普通的深夜来客。

门外沉默了两秒，然后一个沙哑的男声响起：“快递。老周托我带的。”

老周。咖啡馆的老周。他刚拿到钥匙柄碎片的地方。

林一凡的瞳孔微微缩了一下，但嘴上没露出丝毫破绽：“放门口就行。”

“老周说，必须当面交到你手上。”

空气仿佛凝固了。林一凡低头看了一眼系统面板，摸鱼雷达的扫描范围以他为圆心展开，穿透门板，扫向走廊。

三团光晕出现在雷达视野中。

第一个在门口，淡红色的人形轮廓，劳动浓度不高，但带着某种异常的能量波动。第二个在楼梯口的转角处，几乎完全静止，像一块石头，雷达上几乎看不见他的劳动痕迹——只有一种可能，那人在刻意压制自己的存在。第三个……

林一凡的瞳孔猛地一缩。

第三个光晕在走廊尽头的窗户外面，悬浮在半空中。不是无人机，就是——某种他看不见的平台。

三个人。外面至少有三个人。

他深吸一口气，手指在手机屏幕上飞快地打了一行字，发给季敏：“老周出事了？”发送成功。消息显示已读，但没有回复。

门口那人再次开口：“林先生，别让我为难。”

林一凡走到门口，透过猫眼向外看去。走廊灯昏黄，一个穿着深蓝色工装的男人站在门外，脸上带着那种跑了一整天快递后疲惫的神态。他手里捏着一个牛皮纸信封，上面印着“星辰科技内部资料”的红色字样。

“老周让你带什么？”林一凡没有开门。

“一把钥匙。”工装男晃了晃信封，“他说你懂的。”

林一凡的手指停在门锁上，心跳加速。他回头看了一眼自己手里那把磨损严重的黄铜小钥匙——老周那边还有一把？那老王寄来的旧箱里那把又是什么？

他解开防盗链，拉开一条刚好能容一只手伸进去的缝隙。“从这儿递进来。”

工装男笑了笑，伸手将信封从缝隙里塞了进来。

就在林一凡接过信封、指尖触到牛皮纸边缘的那一刻，雷达上——楼下转角处那道几乎隐形的人影动了。那人一步跨出转角，身形如猎豹般轻捷，三秒之内就能到达门口。

林一凡猛地抽回信封，反手关门。

“砰！”

一声闷响，走廊尽头那个人影一记肘击顶在门板上，门锁发出不堪重负的呻吟。工装男的笑容瞬间消失，他一把拽住门缝边缘，力道大得令人发指。

“林先生，”工装男的声音低了下来，沙哑得像是换了个人，“我们只是想确认一件事——你手里的钥匙，是不是真品。”

林一凡把系统面板调到最大，摸鱼雷达在零点零几秒内锁定门外三道气息。他背靠门板，一只手死死抵着门，另一只手快速打开牛皮带，把里面的东西抽出来——一张折成四折的白色A4纸，上面画着下一层的结构图，旁边用老周那种歪歪扭扭的字写着：“你看到的门，不一定是门。你以为的锁，也不一定是锁。放下钥匙，门才会开。”

林一凡盯着这行字，脑中嗡的一声，像有什么东西被点亮了。

他抬头看向天花板——那扇活板门。结构图里写着，第三把钥匙插槽在活板后方。但他从来没想过：如果那扇“门”根本就是个锁呢？

门外，工装男的声音重新响起来：“林先生，我们知道你在。我们也知道——老王已经不在了。你手里那把钥匙，不该由你这样的人拿着。”

他的声音停顿了一下，然后说出了一句让林一凡浑身僵硬的话：

“因为真正的门，在你拿到钥匙的那一刻，就已经开了。”

# 第186章 人力之源

蓝光似乎没有实体，但进去之后，周身像被一层温润的液态胶片包裹。我的视网膜花了整整几秒才从强光适应过来，随后看到的场景让我整个人僵在原地。

这里是一个圆柱形的地下空间，至少有三层楼高。墙壁上密布着密密麻麻的金属管线，像树根一样从顶部延伸到地面，每一根管线都通向中央一个巨大的球形装置——那东西直径至少有五米，表面由数千块棱面玻璃拼接而成，每一块玻璃内部都流动着淡蓝色的液态光，像人的血管。

“人力之源。”老周站在装置前，单手抚着玻璃表面，“原来它长这样。”

赵日天绕装置走了一圈，忽然蹲下来，盯着球体底部一块区域不动了。我走过去，顺着他的视线看去，瞳孔猛缩，里面安安静静地站着一个人形轮廓——灰色的影子，像一段被反复覆盖又无法删除的视频残留。那人形脸部的轮廓，分明和赵日天一模一样。

“你他妈……这什么东西？”赵日天的声音罕见地有些发虚。

老周走到那人形前面，伸出手，却在距离一厘米处停住：“这是资本神记录下的‘你’。每当有人用卷王系统消耗自己的健康和生命时，资源源头就会在这里留下一道影子。”

我脑中轰然炸响。卷王系统、摸鱼系统——这套看似对立的系统全都指向同一个能源库，人力之源。所谓摸鱼和卷，不过是从这根水管里取水的两个水龙头，一个放水一个接水，真正的水库在这里。

“等等，”我转向老周，“那你为什么要带赵日天来这里？他有什么利用价值？”

老周笑了笑：“因为他每卷一天，这里的影子就多一分。哪一天他的影子完整到能独立站立，资本神就能用他的模板复制出千千万万个卷王，在每个公司入职，卷掉所有正常员工。”

赵日天的脸色彻底白了。我头一回在这个男人脸上看到恐惧。

“你不是来帮我的，你是来摧毁它，对吗？”我盯着老周问。老周没有正面回答，他走到球体侧面一块更大的玻璃前，里面流动的光隐隐构成了一个画面：一间办公室，一个戴着金丝眼镜的中年男人——钱总，正坐在老板椅上，手指点着一块全息投影屏幕。那屏幕上显示的画面，就是此刻我们三个人站在这个球体前的实时画面。

“他看得见我们？”赵日天咬牙。

老周的声音平静得可怕：“他一直都看得见。你以为我是怎么活过这一年多的？”

钱总在画面里抬起头，仿佛能透过玻璃看到我。他的嘴唇动了动，我的手机屏幕亮了，上面弹出一条信息：

【林一凡，看到你们站在那了。再往前走一步，你身上摸鱼系统的主权限就归我。考虑一下？】

正当我盯着这条信息时，系统面板忽然跳出一行从未见过的金色字体：

【触发隐藏任务：揭开“人力之源”真相。任务时限：24小时。奖励：系统全权限解锁，包括“自由”兑换项。】

我抬头看向蓝光深处——那里还有一道更小的门，门上刻着一个符号：一个裂开的沙漏，里面流出的不是沙子，而是无数个面目模糊的人影。

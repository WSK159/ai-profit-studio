# 第368章 铁板之下

铁板边缘的裂缝像一张贪婪的嘴，正缓缓张开。林一凡蹲在裂缝旁，手电光束探进去，被浓稠的黑暗吞没，看不见底，也看不见尽头。空气从裂缝中涌出，带着一股复杂的味道——铁锈、尘土，还有一丝若有若无的甜腥。

“你确定要下去？”赵日天站在他身后，声音罕见地沉了下来，“1147号说了两次别进去。”

“正因为说了两次，我才更要进去。”林一凡直起身，拍了拍膝盖上的灰，回头露出一贯的懒散笑容，“它要真不想让我下去，就不会丢那部手机下来。你知道吗，人越是喊‘别过来’，越说明那边藏着点什么。”

赵日天沉默了。他的拇指在腰间的钥匙串上摩挲着，那枚带着缺口的铁质钥匙在指腹间微微发烫。他父亲的话在脑海里翻涌——“九齿为轮，一齿为人。”

“你父亲到底怎么死的？”林一凡突然问，目光定定地看着赵日天。

赵日天的手指顿住了。石室里安静得只剩下铁板底下的呼吸声——沉闷，规律，像一头沉睡的巨兽正在等待什么。

“我说过，他是失踪。”

“你也说过你死过一次。”林一凡没有放过他，“一个死过一次的人，告诉我一个失踪的人的下场？”

赵日天抬起头，与林一凡对视了三秒。然后他低下头，蹲在裂缝边，从兜里掏出那枚半截钥匙：“这块铁板上的凹槽本来是一把整钥匙，我父亲留给我的。它碎了，变成齿轮状——九齿。而我手里这半截钥匙上有十道痕迹，第十道被磨掉了。”他把钥匙递过去，“磨掉的那道，是人。”

林一凡接过钥匙，翻来覆去地看。第十道痕迹的位置确实有被砂纸擦过的痕迹，摸上去微微发涩。这不是自然磨损——是刻意磨去的。

“你爸想让你知道什么？”

“知道钥匙不完整。”赵日天站起身，“缺的那个齿，是活人。”

轰——铁板下方传来一声沉重的撞击，像是有什么东西从内部撞了过来。裂缝边缘的锈屑簌簌坠下，林一凡下意识后退了半步。随即，铁板上方那块浮现过“春”字的碎片重新亮起暖黄色的光，像一盏迟来的油灯。

“春”字在光照下微微颤动，笔画间似乎有更细的纹路在流动。林一凡凑近一看，那些纹路不是锈迹——是文字。极小的，针尖大的字。他掏出手机拍了一张，放大后辨认：

“春。至。矣。归。者。入。门。关。启。”

“春至矣，归者入门关启。”赵日天念出来，眉头拧成结，“这是邀请。在叫某个人回去。”

“你爸有外号叫‘春’吗？”林一凡问。

赵日天摇头。但他突然想起什么：“我爸小时候在乡下，有一个绰号，他从来不说，是我妈有次喝醉酒顺嘴说漏的——”他顿了一下，声音低了几分，“叫‘春伢子’。”

林一凡的瞳孔微缩。铁板上那个“春”字，亮得愈发刺眼。

铁板的裂缝开始向外扩展，速度不快，但足以让人心里发毛。当初只能伸进一根指头的缝隙，现在已经能塞进整只手掌了。裂缝边缘的断面光滑得不像自然断裂，那是被什么从内部切开的。

林一凡弯下腰，把耳朵贴在铁板表面。呼吸声消失了。

取而代之的是一扇门打开的声音——吱呀，长长的一声，像是生锈的铰链被强行拧动。然后是什么东西拖行在地上的声音，沙、沙、沙。越来越近。

“它来了。”赵日天低声说。

他们对视一眼，同时退了开。然而铁板没有打开，而是在“春”字下方，一个拳头大的圆形区域开始凹陷，像一个刻度盘在转动。咔、咔、咔，每隔一秒响一下，转了九下后停住。一声轻响，一个圆柱形的铁管从凹陷中弹了出来。

铁管里卷着一卷纸。牛皮纸，边缘泛黄，被岁月和潮湿浸得发脆。

林一凡小心翼翼地展开。纸上是一幅手绘地图，线条用毛笔勾勒，墨色已褪成陈褐色。地图上标注着“第九收容所——地下三层结构图”，最下层的中央位置画着一个圆圈，圆圈里写着两个字——归零。

“归零？”赵日天皱眉，“这个零，跟‘零’是一个人还是意思？”

林一凡不答，目光死死盯着地图右下角的一行小字备注：“若见此图，第七扇门已开，第三个梯子已断。出口在头顶，入口在脚下。”

赵日天把这话反复嚼了一遍：“第三个梯子——你之前说的，第三梯下方通道？”

林一凡点头，把地图小心叠好放进内袋。他抬头望向穹顶的裂缝：“1147号就在上面，它给了我们这部手机，告诉我们铁板下面是赌局的开关。而现在，铁板告诉我们，归零在最下面，入口就在脚下。”他低头看了一眼脚下那张铁板，裂缝已经停止扩宽，但深处透出微弱的光，不是白光，是暖黄色的——与那个“春”字一模一样。

“它已经在请我们下去了。”林一凡笑了，那笑容里有三分赌博的快意，七分如释重负的坦然，“你先走还是我先走？”

赵日天看了他两眼，从兜里掏出打火机点燃了三根烟，一根插在铁板裂缝边缘，一根夹在自己嘴里，一根递给林一凡：“门里有东西认得烟味。我爸说，过他门者，先敬三根。”

话说完，他第一个跳了下去——裂缝不宽，但他的身形瘦削，肩膀侧过去，像一条鱼滑入浑浊的水中。

下坠的过程只有两秒，便传来沉闷的落地声。然后是一阵沉默——长得让林一凡心里发慌。“赵日天？”他朝裂缝里喊，回音在空腔中来回弹射，撞出一个接一个的“天——天——天——”

半晌，赵日天的声音从深处浮上来，带着一种难以言喻的茫然：“林一凡，你下来看看。这里……不是收容所。”

“是太平间。”

林一凡的手握住铁板边缘，裂缝底部的暖黄色光像潮水一样慢慢涨上来，映亮了他的脸。他深吸一口气，翻身跳了下去。

# 第329章 第三梯之下

“你知道‘第三梯’是什么？”孙满仓立刻问。

沈望没有回答，他只是死死盯着林一凡手中的钥匙，像在看一只正在吞火的凤凰。过了许久，他沙哑着嗓子说：“我父亲留下的记录里，防空洞是‘第一梯’，我们脚下是‘第二梯’，而‘第三梯’……他只提过一次，说那是他最后上船的地方。”

“也就是说，有一条路可以直接通向沈临渊‘上船’的位置？”灰袍人问，目光里浮起一丝不可名状的光。

“不一定是通向‘船’。”沈望摇头，“‘零’这个标记，在沈家的暗语里，意思是‘起点’。所有路的终点，也是所有路的起点。他说那地方是‘船票的源头’。”

林一凡听着这些话，指尖微微发凉。他忽然想起上一世——不，准确说，他的“前世”——在那座写字楼里熬夜猝死前的最后一个晚上，他梦见过一个码头。雾很重，水很黑，一艘灰白色的船停在岸边，船艏没有名字，只有一块铁牌上烙着一个“零”字。他当时以为那只是一个混乱的加班梦。

“第三梯在哪？”他问。

沈望伸手指向裂开的石阶入口：“你刚才说‘不下去’了。”他笑了笑，笑声里带着某种苦涩的自嘲，“但‘生门’钥匙打开的那条通道，只通向地底更深的地方。‘第三梯’不在那里。我父亲把‘第三梯’的入口画在了另一处——你把钥匙翻过来看。”

林一凡把钥匙翻过来，才发现黄铜表面的纹路不是锈蚀——它是一种极细密的刻痕，在应急灯下隐约组成一条起起伏伏的轮廓线，像地图，又像波浪。灰袍人凑近看了一眼，忽然低声说：“这不是地图。”

“是摩尔斯电码。”林一凡说。他把刻痕按长短分组，在心里翻译出来——六个字母：H-A-R-B-O-R。

海港。他上船的地方。

沈望沉默了许久，像在消化这句话的重量。最后他说：“沈临渊上船的地方，是城北废弃的老码头的旧货仓。三十年前那里是走私货的集散地，后来废弃了，再后来被一家物流公司买下当仓库。”他顿了顿，“物流公司的法人代表，叫赵志强。”

林一凡脑子里嗡的一声，赵志强是赵日天的父亲。上一世，赵志强用赵日天的姓氏创办的物流公司后来卷入了一桩行业丑闻，导致赵日天在星辰科技被审计调查，差点丢了职位。这件事他记得清清楚楚，因为当时整个行都在传。而在此前的地下车库监控里，他亲眼看到赵日天和钱总激烈争吵后，坐进一辆贴有那家物流公司标志的面包车离开。

“第三梯的入口在赵家的仓库里？”他盯着沈望，“你和赵志强什么关系？”

沈望没接这个话茬，反而转过身，看向灰袍人：“你跟我父亲，到底是什么关系？你说你是‘替身’，替谁？替我？替沈临渊？还是……替你自己？”

灰袍人缓缓揭开兜帽，露出的面容与孙满仓几乎一模一样，只是眼角多了一道与孙满仓脸上完全不同位置的疤痕。他用一种极其平静的语气说：“我姓孙，不姓沈。我是孙满仓的孪生弟弟——孙满屯。”

所有人都看愣了。孙满仓自己似乎也没反应过来，他瞪大眼，嘴唇颤了颤：“你……你明明已经……”

“死了？”孙满屯接过话头，“三十年前，所有人都以为我死在那场火里。但火是沈临渊放的，站在火里的人都活了下来，站在火外的人，才是死人。”他说着，从袖口抽出一张泛黄的旧报纸，报纸头条印着一个码头仓库起火的照片，报纸上的标题是《走私仓库大火，三名护工遇难》。

照片角落里有一个人影，面目模糊，但双手插兜站在火场外围，身形笔直。

“第三面‘门’——”孙满屯看着林一凡说，“你父亲留下的那些话，一个字都不是对的。”

他的手指点在那个站在火外的身影上，说：“那个人，是钱总。”他顿了顿，声音更低了一点，“我是纵火者。而你父亲，是那场火的源头。”

林一凡的手心沁出了一层冷汗。录音笔电池倒计时，还剩下不到三小时。他手里攥着两枚钥匙，面前有一条通往地下更深的通道，还有一张指向赵家仓库的摩尔斯电码刻痕。这一刻他终于意识到，沈临渊留下的“选择”，从来就不止是“走，或者不走”。

他面前的每一条路，都是一枚钥匙；每一枚钥匙，都通向一扇门；而那三扇门背后，站着的是同一个人。

他父亲。

他低头看了一眼钥匙柄，“生”字旁边，不知何时多出了一道极细的微痕，像是刚才嵌进锁孔时被滑动的金属刮出来的。那道微痕的走向，与其说是刮痕，不如说是一个字——

“去”。

他抬头望向裂开的石阶入口，最后看了一眼，然后转身对沈望说：“带我去赵家的仓库。”

沈望没有动：“我不去。我是守门人，守的是第一梯。”

“那我自己去。”

林一凡把两枚钥匙收进口袋，转身迈步走向梯井出口的方向。黑暗在他的身后弥合，只有口袋里那枚黄铜钥匙轻轻碰撞的声音，在幽深的通道里一遍遍回响。

# 第315章 天台的钥匙

老王的纸条已经攥在手里整整两个小时了，纸张边缘被汗渍浸得发皱。林一凡抬头看了眼窗外，夜色沉得像一口倒扣的铁锅，远处星辰科技大楼的标志灯孤零零地亮着，像一只不肯闭上的眼睛。

“钱总说明天来我办公室。”老王坐在床沿，手肘撑着膝盖，秃顶在昏黄灯光下泛着微光，“可我总觉得这话不对味儿。他今天下午在走廊上遇见我，那张脸笑得……我跟他共事八年，从没见他那样笑过。”

林一凡把纸条翻过来，背面空无一字。他想起之前在废铁站找到的那张水洇纸条——“11点方向，暗桩，别回头”——那是哥哥沈稚冬留下的。两张纸条之间，似乎隔着某种看不见的因果。他把纸条折好塞进口袋，看向屋角。沈稚秋蹲在地上，手里捧着一枚刚拆下来的芯片。

“这芯片的纹路不是电路。”她皱眉道，“更像是某种……符文。我哥留下的铁盒里那枚也是有金色纹路，但这枚的纹路更细，边缘还有一圈极小极小的刻度，像密码锁。”

周立冬靠在窗边，额头上那道疤在灯光下格外醒目：“你哥当年跟我提过一件事。他说他找到一个地方，那地方藏着‘钥匙’——但他没说是什么钥匙，只说了四个字：‘铁网，天台。’”

沈稚秋猛地抬头：“那个纸条背面写的‘铁网第三格，钥匙在天台’。”

“但那是钱总办公室里的铁网。”林一凡接话道，“铁盒里的纸条指向钱总办公室的隐藏夹层，而夹层里的钥匙在天台——那这个‘天台’，是星辰科技的天台？”

三个人同时沉默了几秒。

窗外忽然掠过一道光，是楼下值班保安的手电筒。周立冬下意识侧身藏进窗帘后，等光扫过去才重新靠回窗边：“现在的问题是，钱总那张字条送得也太蹊跷了。老王，你把字条给我之前，它是什么时候到你们家的？”

老王的脸色变了变：“晚上七点多。我爱人打电话说门缝里塞了个信封，没有署名。我回家一看，字迹是钱总的，我认得他的笔迹——他签加班费单子的时候我看过无数次。可问题在于，钱总今天一整天都在外地出差，下午四点的航班。”

“那这张字条是谁写的？”林一凡的指尖轻轻敲着桌面。

没有人回答这个问题。周立冬走向门边，压低声音：“要不我先去一趟天台？要是真有什么钥匙，趁天黑正好动手。”

林一凡看看沈稚秋，又看看老王。老王站起来，抖了抖身上的蓝色工装：“我跟你去。公司天台我熟，消防通道的门锁坏了好几个月，从那上去不用过闸机。”

“你确定要掺和进来？”林一凡问，“这件事的深浅你已经看到了。”

老王苦笑一声：“老林，我今年四十四了，被裁员裁怕了，被PUA也PUA怕了。我这辈子没做过什么出格的事，但你哥留下的这些纸条、芯片、铁盒子——这些东西比钱总那些冠冕堂皇的PUA有意义多了。我跟你走。”

一小时后，星辰科技大楼背面消防通道的铁门被周立冬用一根铁丝捅开了。楼道里漆黑一片，安全出口的绿色标牌在黑暗中泛着幽光。三个人摸到顶层楼梯拐角，铁门半敞，天台的风灌进来，带着十一月的干冷。

林一凡第一个跨进天台。脚下是平整的水泥地面，四周是半人高的铁网围栏，夜色下远处城市的灯火像碎了的星河洒在视野尽头。他沿着围栏数着格数——第三格，手电光扫过一整排立柱。锁链在第三根立柱上绕了三圈，末端挂着一把小黄铜钥匙，约莫三厘米长，颜色陈旧，像在水里泡了很久。

周立冬伸手去取，指尖刚碰到钥匙，身后传来一个温吞的声音。

“手别动。那玩意儿上面有感应装置。”

三个人同时僵住。天台边缘的通风管道后面，一个穿灰雨衣的人缓缓走出来，帽檐压得很低，看不清脸。他的右手插在口袋里，鼓起的轮廓像一把枪。

风声在天台上面撕扯，把那人开口说的每一个字都裹上一层寒意。林一凡的手指僵在半空，离那把黄铜钥匙只有一寸，但他没有去碰。他慢慢直起身，转过身，目光落在那件灰雨衣上。

“你知道我哥。”他说得很轻，像在确认一个早已存在但始终模糊的事实。

灰雨衣人没有点头也没有摇头，风把雨衣下摆吹得猎猎作响。他左手从口袋里抽出来，手里握着一个火柴盒大小的旧铁皮盒子，和废铁站那个盒子一模一样，只是没有锈迹，边缘被磨得发亮。他把铁盒往地上一放，往前踢了一脚，铁盒在地面上滑了半圈，停在林一凡脚边。

“这东西摆在我这儿太久了。”灰雨衣人说，“你哥当年把它塞给我，说如果有朝一日你来天台，让我把这个还给你。”

“盒子里面是什么？”周立冬的眼睛死死盯着灰雨衣人的右手，那只手还插在口袋里。

灰雨衣人似乎笑了一下：“你自己看。”

林一凡蹲下身，捡起铁盒。盒盖很紧，他用力一掰才打开。里面只有一张折成豆腐块大小的白纸，展开之后，上面用铅笔写着一行端正的字——

“钱总办公室的铁网夹层，钥匙在天台，而天台的钥匙在我手里。你能拿到这封信，说明你已经走到了这一步。去吧，别回头。”

末行底下还画着一个极小的图案：一条鱼的轮廓，嘴角像在笑。那是林一凡小学时和哥哥一起画的“摸鱼图”——他们小时候在作业本背面画满了这种鱼。

林一凡的手微微发颤，把纸条翻转过来。背面有一行极小的字，几乎要凑到眼前才能看清：“那枚芯片是真的，铁盒也是真的。但钱总办公室的夹层，你去了就会明白什么是假的。”

灰雨衣人这时才慢慢把手从口袋里抽出来，空空如也。他抬起头，帽檐下露出一张瘦长的脸，胡子拉碴，眼窝深陷，看起来至少五十岁，但眼神清亮得像一口井。

“我叫孙满仓。”他说，“你哥的师父。”

林一凡愣住了。他知道哥哥当年在星辰科技入职时带过一个老工程师，姓孙，五十九岁被公司以“优化结构”为由劝退，之后就再没消息。老王也提过这个人，说他是公司里唯一一个敢在年会上拍着桌子骂钱总的人。

“我哥当年到底发现了什么？”林一凡攥紧那张纸条。

孙满仓指了指那把小黄铜钥匙：“这把钥匙开的是钱总办公桌最下面一层抽屉的暗格。那个暗格里放着什么，你自己去看就明白了。我只告诉你一件事——你哥不是辞职走的，他发现了钱总跟那套AI考核系统的数据交易。星辰科技的考核系统不只是在抓摸鱼，它还在采集每一个员工的情绪数据、压力数据、睡眠数据，打包卖给第三方机构。”

“什么？”周立冬的声音也拔高了，“那不是违法吗？”

“违法？”孙满仓笑了笑，“2026年，你的数据就是你最值钱的东西。钱总把这东西卖给了三家保险公司，两家猎头公司，还有一家你绝对想不到的——一家名叫‘资本方舟’的投资集团。”

林一凡脑子里轰的一声。“资本方舟”这个名字他不陌生，摸鱼系统的隐藏规则页面里，第一行就是“资本方舟为资本神代理机构”。那是他在系统空间里读到的信息，从没在现实里听任何人提过。

“我哥……是怎么死的？”他听见自己的声音有些发哑。

孙满仓沉默了很久，久到风几乎要把这句话卷走：“你哥没死，但也没活着。”

他说完这八个字，转身走向天台边缘，翻身踏上了外墙的检修梯，整个人融进了夜色里。林一凡追过去，只看见灰色的身影在四五层楼的位置晃了一下，随即消失在消防通道的阴影中。

周立冬走到他身边：“他说‘没死也没活着’，什么意思？”

林一凡低头看着手里的小黄铜钥匙，钥匙柄上刻着一个极小的“沈”字。他把钥匙攥紧，抬头望向星辰科技大楼顶层那扇亮着灯的窗户——那是钱总的办公室。

“老王。”他忽然喊了一声。

老王从消防门后探出脑袋。“明天你就去钱总办公室。”林一凡说，“就当什么都不知道。我去见他一趟。”

“你要干什么？”

林一凡把那枚金色纹路芯片从口袋里拿出来，在月光下看了一遍，然后重新装好：“我哥给‘资本方舟’盯上了，钱总的AI考核系统也在找他。我手里的资源，他一样都没带在身上。”

他顿了顿：“现在轮到我替他把路走完。”

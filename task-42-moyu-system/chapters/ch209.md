# 第209章 配电室交易

配电室的门锁死的那一瞬间，林一凡没有回头。

他手里握着那根银灰色细棒，指腹一寸寸扫过棒身的纹路——不是金属的冰凉，是温润如玉石的质地，表面布满极细极密的螺旋纹，像某种精密机床车出来的，又像是天然长成的。灯光打上去，纹路里隐隐泛着流光。

“老周的徒弟？”他开口，语气平淡，“你们师门真有意思，师父留了五张地图，徒弟藏在配电室的暗槽里放钥匙，怎么没把暗号写在报纸上登寻人启事？”

陈默没有接梗。他背靠铁门，双手插兜，整个人像一截没通电的灯管，灰扑扑的立在那里。

“你比我想象的慢。”陈默说，“我等了你四十分钟。”

林一凡终于回过头，上下打量他：“你等我？”他晃了晃手里的细棒，“你放这把钥匙在这儿等我？”

“不是我放的。”

“那是谁？”

陈默沉默了三秒，像是在算到底该说多少。随后他从兜里掏出一张折叠的纸，递过来。林一凡没接，只是问：“什么？”

“配电室暗槽里的图纸，”陈默说，“应该你先看。我找到的时候，它已经被动过。”

这个说法很微妙——暗槽里的东西，他找到了，但被别人动过？林一凡眉头微皱，接过纸展开。

图纸是手绘的，比例尺底下写着“老周字，勿折”四个字。整张图画的是星辰科技园区地下管廊的剖面结构，标了七条管线、三组阀门井、两处泵房，唯独在管廊中段，老周用铅笔重重画了个圈，旁边写着：钢筋梯。

不过一行字被红笔划掉了，红笔是新痕迹，笔锋极重，几乎划穿纸张，只留下依稀可辨的“借道”两个字。

林一凡把图纸折好，塞进口袋，转头盯着陈默的眼睛。

“你师父画的地图，”他慢慢说，“算上污水站和配电室，我已经去了两个点。这张图纸是第三个。你既然拿了暗槽里的图纸，就应该知道下个点在哪儿了。所以——你是来带路的？”

陈默没直接回答。他走到配电柜前，伸手在柜体背面某个位置一扣，掀开一块伪装板，里面又是一个凹槽——空凹槽。

林一凡盯着那个空槽，又看了看自己手里的银灰色细棒，脑子里闪过一丝明悟：“原来这配电室里不止一根钥匙？”

“不，钥匙只有一根，”陈默收回手，“那个凹槽里原来有东西，但我来的时候就没了。”他顿了顿，声音低下去，“有人比我快一步。”

配电室里安静了片刻。风从通风口灌进来，吹得配电柜门上的标签纸猎猎作响。林一凡的视线落在陈默裤脚上——那上面沾着一点铁锈色的泥土印，和检修井下面的泥应该是同一种土质。

“你去过污水站？”林一凡问。

陈默显然没料到他会问这个，怔了一下，随即承认：“去过。你打开井盖之后，我就跟在你后面。你合上井盖走了以后，我翻下去了。”

“井下面有什么？”

“一个空套筒，套筒内壁有一圈金属簧片，”陈默说，“你把钥匙插进去的那一瞬间，簧片推动锁舌，套筒底座会弹起来。”他比划了一下，“底座底下埋了一个防水盒。”

林一凡的瞳孔微微收缩：“防水盒里有什么？”

“一根录音笔。”陈默说到这三个字的时候，声音里终于透出一丝情绪，像烟灰缸里最后一点火星，暗红色的、烫的。“我师父的声音。”

林一凡没有立刻追问。他把银灰色细棒放进内袋，脑子里飞速盘算着信息量。老周留了地图、钥匙、录音笔，像一部拆散的悬疑剧本，让后来者按图索骥。而陈默作为徒弟，明明有先手优势，却一直在等自己推动进度。

他问了一个核心问题：“你为什么不自己打开污水站？”

陈默抬头，目光复杂：“因为录音笔里，我师父说了一句话——‘东南角的井，只有摸鱼系统绑定者能开’。”

整个配电室的空气仿佛凝滞了。

林一凡的手指在口袋里轻轻捏住那根细棒，脸上没显出太多波澜，但脑子里已经炸开了一道闪电。他想到自己当初在污水站打开井盖时的情景——他确实没费太大力气，那些锁、簧片、刻度线，像是自然而然地匹配上了他的力道。他甚至没想过，为什么那个锁槽刚好适配他系统空间里兑换来的那把工具钳。

“你师父，”林一凡问，“和摸鱼系统什么关系？”

陈默的嘴角动了动，像是要挤出一个笑，却失败了：“他说，他是做了十三年压缩包的人。”

“什么压缩包？”

“系统里的咸鱼值积累机制。”陈默一字一顿地说，“我师父不是程序员。他是基建工程师。那个惩罚规则——‘摸鱼被抓住=清零’——是我师父设计的。”

林一凡握着细棒的手指收紧。

眼前的谜团像洋葱一样层层剥开，但每一层都带着刺鼻的味道。老周不只是一个留下地图的线人，他参与过摸鱼系统的底层架构设计？那“劳动神与资本神的赌局”这层说法，到底有几分是真？

“你说了这么多，”林一凡靠在配电柜上，语气不紧不慢，“目的是什么？”

陈默走到门口，掰了一下门把手，咔嚓一声，门锁弹开。他迈出去半步，又侧过头，说了一句让林一凡脊背发凉的话：

“我师父留了五个坐标点，污水站是入口，配电室是钥匙，管廊是路，剩下的两个点里，有一个是出口，另一个是……”他停住，“是关押他的地方。”

“你师父还活着？”林一凡的声音终于没压住。

陈默没有回答。他退进走廊的阴影里，脚步声沿着天花板的方向一路远去，只留下一句话飘在配电室门口：

“我那把钥匙能开四道锁，但你手里的钥匙能开第五道。第五道锁后面，关着的不止一个人。”

林一凡站在配电室门口，低下头看着手里的银灰色细棒。
在这根细棒的顶端，他指尖触碰到了一个极细微的刻痕。他把棒身举到灯下，眯眼辨认，看到一行小字，笔迹和老周画图纸上的铅笔字一模一样：

“别信任何告诉你钥匙是假的人。”

他眉心一跳——那个匿名短信说的是真的，只是真的不止一条路子给他的，是那条短信上说他拿到的钥匙是假的那一句，这句话此刻像钩子一样深深挂进他脑子里，形成一个刺痛的疑问：那条警告短信，是谁发的？它真的是在帮忙吗？

配电室门口的风声安静下来。林一凡把细棒放回内袋，摸出手机，屏幕上又亮出一条新消息：
“井盖硬币已归位。你还有两个小时。别回头。”

他没有回头，但他知道，自己正一步一步走进一张铺了很久的网。

# 第312章 铁锁宋的最后一句话

手电光向上移动，照出一张满是皱纹的瘦脸。老人约莫六十出头，头发花白，穿一件蓝灰色旧工装——与城中村那个灰工装男人的制服几乎同款，但胸口别着一枚褪色的星辰科技老式胸牌，照片已磨得看不清脸。他的右手小指断了半截，左手攥着一根铁钎。

“老宋？”林一凡盯着他，“铁锁宋。”

老人没回答，目光落在林一凡腰间露出半截的黑钥匙上。他点了点头：“是了。编号03。你从老王老宅墙洞里拿出来的。”

他转身往深处走，脚步声在幽长的地下通道里回响。林一凡和沈稚冬对视一眼，跟上去。林一诺的屏幕亮着，低声道：“我把信号接进来了。这地下有信号栅格，我定位不到具体位置，但能听到声音。”

通道尽头是一间不足十平米的暗室。墙角堆着铁皮工具箱，一张折叠床上铺着旧报纸，床头挂着一盏蓄电池灯，发出昏黄的光。角落里有一台老式铁皮柜——林一凡认得那柜子，和老王家那台几乎一模一样，只是颜色更暗。

“老王托人给我带过话。”老宋坐在床沿，把铁钎立在膝盖上，“他说，如果有一天有人拿着黑钥匙找到我，说明‘三’已经凑齐了。”

“凑齐三什么？”沈稚冬追问。

老宋抬起浑浊的眼睛：“三把钥匙。老王的01，你手里这把03，还有一把——在我这里。”

他从铁皮柜底层抽出一个锈迹斑斑的铁盒，打开盒盖，里面躺着另一把黑钥匙。柄上的刻字在灯光下清晰可见：“05”。

林一凡盯着那把钥匙，忽然听见脑海深处传来一声极轻的嗡鸣。系统面板毫无征兆地弹出——一行从未见过的字：

【检测到同源密钥序列：01 / 03 / 05。触发隐藏条目：记忆碎片·第000号载体启动协议。】

老宋把钥匙递给林一凡，但他没伸手接。老人的手悬在半空，微微颤抖：“我把钥匙给你，但你得答应我一件——”

他的话没说完。

暗室外面的通道里，忽然传来一声闷响，像门被撞了一下。老宋的脸色骤然一变，猛地把铁盒盖上，塞回铁皮柜：“他们来了。”

“谁？”林一凡压低声音。

老宋没回答，从折叠床下拖出一个帆布袋，从里面拿出一台老式磁带录音机——和林一凡在暗间里发现的录音机同款，连外壳的磕痕都一模一样。“老王录的带子，我留了备份。”他把磁带塞进林一凡手里，“拿好。还有——”他顿了顿，“铁皮柜里的东西，别打开。”

他说这句话的时候，眼睛盯着角落那台铁皮柜。林一凡顺着他的目光望去，铁皮柜的锁扣内侧隐约有一道新鲜的抓痕。铁皮柜的门缝里透出一丝红光。

通道外又传来一声撞击，比之前更重。铁门发出不堪重负的呻吟。

老宋猛地站起来，把05号钥匙用力塞进林一凡掌心：“带钥匙走。铁锁宋老了，跑不动了。”

林一凡还想说什么，老宋已经转身，背对着他们，往通道口走出去。他的背影在昏黄的灯光下投出一道拉长的影子，那影子在墙上微微扭曲了一下。

沈稚冬拉住林一凡：“走！”

两人向后门方向急退。林一凡回头的那一瞬，看见老宋已经走到通道口，他左手铁钎横在身前，那个姿势不像在挡人，更像在挡什么不该被看见的东西。

铁门外忽然传来一个年轻的声音，低沉平静：“老宋，你藏了快七年了——交出来吧。”

老宋没有回答。铁门轰的一声被撞开。

林一凡来不及多看，沈稚冬已经拽着他翻出后门。两人跌跌撞撞地跑进废铁站西边的杂草丛，身后传来一声沉闷的倒地声。

林一凡攥紧手里的05号钥匙，牙关紧咬。他的手机忽然亮了，屏幕上弹出一行字，是林一诺发来的：“那个声音……我听过。”

屏幕上紧接着是另外一行：“林一凡，那是赵恒。活的赵恒。”

他脚下猛地一顿，回过头。废铁站方向已经看不见任何灯光。远处地平线上，一辆黑色轿车正缓缓驶来，车灯在夜色里亮得像两只黑色的眼睛。

他的手机又震了一下。这次是系统提示。

【钥匙序列已激活：01/03/05。剩余：01把。提示：最后一把钥匙——在你认识的人手里。】

林一凡缓缓转过头，目光落在沈稚冬脸上。沈稚冬没有看他，正低头盯着自己的手机屏幕。屏幕光映出他微微苍白的脸，屏幕上的那道锁屏界面，锁屏背景是一只五瓣梅花钥匙的高清照片。

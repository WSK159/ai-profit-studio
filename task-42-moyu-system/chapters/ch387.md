# 第387章 敲击声的答案

石室上方的敲击声又响了——长，长，短。

林一凡后背贴着石壁，后槽牙咬紧。那节奏他太熟了，录音带里沈临渊敲了整整三遍的暗号，像某种古老的敲门契约。

三叔站在石印机旁，手中的煤油灯微微晃动，映得他半边脸忽明忽暗。他仰头盯着石室顶部一块略微凹陷的石板，嘴唇翕动了两下，最终只挤出一句：“他在找入口。”

“他？谁？”沈稚川攥着那只小孩鞋的指节发白。

三叔没答，转身走到石室西南角，蹲下身，手指在墙根摸索。石面上积着厚厚一层灰，他的指尖划过一条几乎看不出接缝的裂隙，停在距地面约半米处，轻轻一按——那块石头无声地向内凹进两指深，露出一个拳头大小的黑洞。

林一凡看见了，洞里有一根锈迹斑斑的铁条，末端悬着一枚铜铃。铃舌被人用麻绳缠死了，发不出声，但铁条上方的石壁内侧，刻着一道一道的划痕——新划的，木屑还嵌在石缝里。

“这台印刷机，是前年才搬进来的。”三叔站起来，掸了掸手上的灰，“老沈在出事之前，把自己关在这里整整七天。他没印报纸，印的是一张船票——不对，是船票的拓版。”

沈稚川猛抬头：“船票拓版被谁拿走了？”

三叔目光落在那台石印机的滚筒上，滚筒和压板之间夹着一层薄薄的橡胶皮，他掀开橡胶皮，底下露出一张裁好的土黄色厚纸。纸上没有油墨，但边缘压出的线条和纹路清晰可见——那是一个长方形边框，框顶有一行极小的篆字。

林一凡凑近看，篆字他不认得，但沈稚川脸色变了。

“归墟，字，航字第叁号。”她一字一字读出来，声音发颤。

三叔点点头：“这张纸是印废的试板。真正的船票，老沈在被带走之前，塞进了一个你绝对想不到的地方。”

他顿住，目光移向沈稚川脚边的那只小孩军帆布鞋。

沈稚川顺着他的视线低头，鞋底朝上，朱砂写的“0”字在煤油灯下泛着暗红。她忽然蹲下，把那只鞋的鞋垫抽了出来——鞋垫是双层的，夹层里滚出一枚拇指大小的黄铜片，铜片正面刻着一条船，船头站着一个人形；背面是一个数字。

074。

林一凡心脏猛地一跳——074，和他在泵房看到的那个编号一模一样。

“这张船票的拓板，”三叔指着那枚铜片，“老沈寄给了他最信任的人。但他从来没说过，那人是谁。我替他保管了十三年，直到他弟弟沈临渊也出事，我才把他最后留下的那盘录音带挖出来。他录到第七句就被打断了。”三叔嗓音发涩，“打断他的那个人，用他的笔迹，写下了那行字。”

沈稚川手中的铜片差点脱落：“模仿笔迹的人，你见过？”

三叔摇头：“我只知道，那个人用老沈的笔迹写下的字，在这台印刷机上压过一份‘报纸’。而那份报纸的正本，现在就在——”

头顶传来一声沉闷的撞击，石室上方那块石板被从外面撬开了一条缝，一只沾满煤灰的手从缝隙里探了进来，五指张开，掌心朝下，慢慢翻转，露出掌心中一枚陶土徽章——上面刻着数字“27”。

林一凡瞳孔骤缩。那枚徽章，跟他在南洞外灰袍人身上见过的，一模一样。

# 第63章 天台之约

林一凡靠在工位上，盯着屏幕上不断跳动的代码，脑子里全是赵日天临去钱总办公室前那句话：“今晚八点，天台，我告诉你被废弃的原因。”

他看了眼时间，下午六点二十。赵日天已经进去两个小时了，钱总办公室的门一直关着。林一凡用摸鱼雷达扫了一下那扇门——雷达穿不透总裁办公室的门，只看到门缝里渗出一片诡异的暗红色。那是“劳动浓度”极高的颜色，几乎要溢出墙来。

“他俩在密谋什么？”林一凡低声自语。

手机震了一下。小赵发来消息：“你今晚有没有空？听说物流部那边有个数据异常，想找你帮看看。”

林一凡回：“今晚有事。”

“啥事？”

“私事。”他打下这两个字的时候，突然笑了。赵日天的数据异常？物流部？这家伙果然在搞事。四个月前，赵日天刚来星辰科技时就说过一句话——卷王最爱做的事就是“从别人的数据里找出不努力的人”。现在他调回秦氏B座这个废楼，却把爪子伸向物流部。

七点五十，林一凡提前到了天台。

秦氏B座的楼顶和整栋楼一样透着一股被人遗忘的味道。水泥地面开裂，裂缝里长出一簇簇杂草。角落堆着几张旧办公椅，锈迹斑斑。远处，A座和C座的霓虹灯把夜空照得发紫，衬得这边像一块被人遗弃的阴影。

八点整，天台铁门“吱呀”一声开了。赵日天拎着两罐可乐走进来，穿一件深灰连帽衫，帽檐压得低低的。

“你倒是准时。”赵日天把一罐可乐扔过来。

林一凡接住，拉开拉环灌了一口：“讲吧。ZTY-01是怎么回事？”

赵日天沉默了几秒，在他旁边坐下，两腿悬在天台边缘的矮墙上，望着远方的霓虹。他从口袋里掏出手机，翻出一条信息，递过来。

是一条系统通知的截屏：

【卷王系统】警告：宿主编号 ZTY-01，检测到"摸鱼行为"占比上升至 3.7%，超出阈值。按照协议，执行一次惩罚任务：48 小时内完成 300 个需求单。逾期将扣除 30% 体质。

林一凡瞳孔微缩：“你的系统会惩罚你？”

“不止惩罚。”赵日天苦笑一声，“它是我的枷锁。每天睁开眼，它就在我脑子里报数——今天要卷几个小时、要完成多少任务、要把几个人的绩效比下去。但凡有一天我做得不够多、不够快，它就扣我健康值、扣我寿命，甚至扣我的记忆。”

“记忆？”

“它删过我一年的记忆。”赵日天的手指在易拉罐上敲了敲，“那是我二十五岁那年。我在上一家公司连干一年零四个月，没休过一天假。结果有一天，我突然发现我想不起来我女朋友长什么样了。她叫江雪，我连她生日都记不起来。我当时去查系统日志，发现它把关于她的所有记忆都清掉了，因为我那天‘摸鱼’了——跟她打了一通四十分钟的电话。”

冷风灌过来，林一凡后背有些发凉。

“所以你被废弃，是因为……”

“因为我开始拒绝执行任务。”赵日天转过头，眼睛里有种复杂的光，“半年前，我在一次任务里故意磨洋工。系统判定我‘多次违规’，启动了废弃协议——把我从主系统中剥离。但剥离只是第一步，它还派了一组‘审计员’来追杀我。那群人表面上是外包公司的临时工，实际上全是资本神的棋子。”

林一凡手里的可乐罐被他一握，差点捏扁：“资本神……你真的见过？”

赵日天正要开口，突然脸色一变。他猛地抬头看向天台入口，与此同时，林一凡的摸鱼雷达疯狂闪烁起来——天台的铁门外，三道极其浓烈的“劳动浓度”正在快速逼近。

“他们来了。”赵日天扔掉可乐罐，压低声音，“林一凡，记住——任何人问你，今晚你都没见过我。你别卷进来，你那边还有一个没解开的‘04:22’，那才是真正的钥匙。”

话音未落，铁门“哐”一声被踹开，三个穿着黑色冲锋衣的壮汉鱼贯而入，为首那人手里握着一台闪烁着红光的掌上终端。

赵日天直接从矮墙翻下去，消失在夜色里。

林一凡站在原地，看着那三人冲向他，为首的壮汉举起终端对准他脸扫了一下，冷声开口：“你叫什么名字？你是这个系统的新宿主？”

终端上，红光跳动着，突然变成了绿色——屏幕上浮现一行小字：

【宿主匹配：未识别。非系统拥有者个体。】

可林一凡的摸鱼雷达清晰地感知到——那人手里的终端，正在读取他体内咸鱼系统的实时数据。

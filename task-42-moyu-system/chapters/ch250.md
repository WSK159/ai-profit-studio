# 第250章 铜线变绿的地方

铁梯向下延伸了四层楼的高度，每一级台阶上的劳保鞋脚印都清晰如新，仿佛刚刚印上去的。但当他们踩上台阶时，脚印边缘的粉尘却没有扬起——那脚印不是踩出来的，是印出来的。

像是有人拿着风干的鞋底模型，一张一张按上去的。

陈默没做声，她第一个下到铁梯底部。底部是一条横向的狭窄通道，墙面是浇筑的粗粝水泥，脚下铺着防滑铁板。通道的不远处有光——不是灯光，是在黑暗中自然发光的、附着在墙壁上的苔藓一样的绿色荧光。

铜线的末端就嵌在这堵墙壁里，与那些绿色荧光融为一体。

“这是……活的？”老王蹲下身子仔细打量墙上的荧光，他伸手触了一下，那些荧光微微缩了缩，“——有温度的。”

LXR-0的声音已经不在通道里。他们离开了配电井的范围，原始机的信号彻底断了。但赵日天的卷王系统还在，他的系统面板弹出一条提示：“检测到高浓度‘工作态能量’与‘反工作态能量’交汇区域，建议立即脱离。危险等级：极高。”

“危险极高你也得走。”林一凡盯着墙上的绿光，低声问陈默，“你爸说的‘变绿的地方’，就是这里？”

陈默没有回答。她的目光死死地盯着墙壁中央那根嵌入的铜线末梢——铜线的末端不是断裂的，而是被人用工具熔成一个圆环，圆环里扣着一个东西。

那东西是一只男式石英表，表盘玻璃碎了，时针停在2点47分。

表带上有干涸发黑的陈年血渍，表扣上刻着一行小字：陈建国，2019年入职纪念。“这是我母亲的表。”陈默的声音有些沙哑，“她走之前，留给他做念想的。”

林一凡看着那只表，脑海里快速闪过老周笔记本里的那句话：“陈建国说过，他要把证据放在最不可能被找到的地方，门口有铃，里面有人，绿光之下，真相生根。”

“那行字的后半句是什么意思？”赵日天也看到了那只表，他皱着眉，“‘绿光之下，真相生根’，你爸埋了什么？”

陈默伸出手，动作很稳。她把那只表从铜环上解下来，翻转过来，表盘背面的金属壳上，刻着一串数字和字母组成的序列码——

LX-001-8。

林一凡瞳孔骤缩。

他记得LX-001-7，那是星辰科技摄像头编号系统里的第八位，也是老许说过的、走廊里唯一一台被监听过的摄像头。而LX-001-8，是比它更早一级的存在——编号前七位之后的第一个非摄影头编号。它指向的不是设备，而是一个“位置”。

“LX-001-8，是负六层北轴配电井暗门隔间里那个保险柜的正式编号。”老王突然开口，他的声音有些发抖，“老周笔记本上有标注，‘008号保险位，钥匙在灯里’。我一直不明白‘灯里’是什么意思，现在知道了——”

他抬头看向墙壁尽头，那根铜线贴着墙面向通道深处延伸，末端嵌进一只铁皮挂灯里。那盏挂灯已经完全锈死了，但灯泡的玻璃罩里，塞着一把小巧的黄铜钥匙。

“008号保险位……钥匙在灯里。”老王喃喃自语，“陈建国，你藏东西的本事，真是老天爷都比不上。”

陈默取下挂灯里的钥匙。就在钥匙脱离灯泡的瞬间，整个通道的绿色荧光猛地闪烁了一下，仿佛被抽走了什么能量，亮度骤降。紧接着，墙壁内部传来一阵低沉的机械运转声——咔咔咔，像有几十个齿轮同时转动。

墙裂开了。

露出里面一间几乎不算房间的空间：像一口竖井的底部，四壁焊满了铁架，铁架上码着整整齐齐的防水箱。箱子上用马克笔写着编号——001到064，整整六十四只箱子。

箱子里的不是文件，是录音带。数不清的录音带，每一盒的封面上都印着日期。最早的一盒，日期是2017年3月，比星辰科技AI考核系统上线还早了整整九年。

陈默站在门口，声音很轻：“他一直在录。从入职第一天就在录。”

她伸手拿起最早的那盒录音带，背面贴着一张标签纸，撕开——里面还有一层。揭开第二层，露出的是一行用钢针刺出来的小字：

“他们的秘密，都在这里。小默，等你看到这句话，我猜我应该已经不在了。不用难过，我换了一种方式活着——只要这些录音还在，他们就没有真正杀死我。”

陈默把录音带攥在手心里，右眼的红光闪得比任何时候都亮。

林一凡没有说话。他知道这间密室意味着什么——陈国建不是死于意外，他是在被人追杀之前，用整整九年的时间把所有证据藏在了只有他女儿能通过那套徽章机关找到的地方。

而这，只是第一间。

因为那辆推车上的编号，还有第二层——背面刻着一个更大的数字：LX-001-0X，X=？。

他还没来得及深想，密室深处突然传来一声铜铃响。

清晰、响亮，就在他们身边。

密室里，那只铜铃正安静地躺在货架最顶层，没人碰它。

铃铛是自己响的。

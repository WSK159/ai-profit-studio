# 第43章 效率大赛的变数

入夜后的星辰科技A座，十七层走廊只剩走廊尽头那盏应急灯还亮着。

林一凡坐在工位上，电脑屏幕的光映在他脸上。

他第三次点开那封总部发来的邮件，标题措辞官方到让人起疑——“复赛调整通知”。

「经战略部与效率大赛评委会研究决定，复赛时间由原定两周后提前至下周三，比赛形式改为限时实战，参赛者须在三个工作日内完成指定项目的初步方案与Demo演示。题目当场公布，不得外传。祝各位赛出水平。——总部效率委员会」

三个工作日。当场出题。做个 Demo 还带方案汇报。

林一凡的食指在桌面上敲了敲。这节奏太急了。初赛刚过三天，复赛就提前到下周，中间连个喘气的缝隙都不给。

他还没来得及细想，身后传来一阵键盘声——赵日天的工位斜对面，那个位置原本是沈敛的。

赵日天今天一下午都没挪窝，屏幕上的代码刷得跟瀑布似的。林一凡的“摸鱼雷达”自从升过级后，能看见每个人身上的“劳动浓度”。此刻他微微凝神，视野里浮现出赵日天头顶的数值条——青蓝色的卷气浓度，几乎接近90%，还在缓慢攀升。

不对劲。

这个数值比正常加班狂还高出一截。更要命的是，赵日天的卷气值边缘，缠绕着一圈极其细微的暗金色纹路。那纹路他见过，在沈敛身上也出现过。

林一凡目光一凛，压低声音喊了一句：“日天，喝杯水去？”

赵日天头都没抬：“不了，还有两段逻辑没写。”

“那……你电脑哪来的？”

赵日天的手指顿了一下，随即若无其事地继续敲击：“公司配的。”

“我上次看到你用的是一台银灰色的，怎么换了个黑的？”

“效率大赛要换新机器，行政那边统一调配。”

林一凡没再追问。他记得老王说过，赵日天现在用的那台电脑，是沈敛离职前用的。沈敛的话又在他耳边响起来：“赵日天是……”后半句始终没说完。

他正琢磨着，手机亮了一下，是老王发来的语音，带着压低的声音和电梯间的回音：“林儿，我刚听说个事，复赛的嘉宾评委名单里有个叫秦宣的。秦氏集团的二公子。”

林一凡皱起眉。秦氏集团。沈敛说的“星海数据案”里，钱总的合作方就是秦氏。秦宣要是来当评委……

“老王，”他打字回复，“复赛是不是要动真格的了？”

“你说呢？三个工作日，出题现场公布，评委里坐着钱总的人脉，这比赛的结局怕是早就写好了。”

林一凡靠在椅背上，盯着天花板上那盏日光灯。

初赛他用数据PPT赢得了战略部的关注，但那只是“观察”。复赛不一样。复赛是“实战”，是所有人都在看的时候，你能拿出什么真东西来。

他正盘算着下一个动作，忽然听到楼道里的脚步声。急促、稳重、带着皮鞋落地的笃笃声，在空旷的走廊里格外清晰。

钱总。这个时间点，他来十七层干什么？

林一凡的“摸鱼雷达”自动捕捉到钱总的方向——不是往总裁办公室去的，而是直奔赵日天的工位。林一凡眼皮一跳，不着痕迹地把垃圾桶拉到脚边，弯腰去捡一支“掉”在地上的笔。视野余光里，钱总走到赵日天桌前，低声说了句什么。

赵日天抬起头，停顿了两秒，点了点头。

钱总又拍了拍他肩膀，转身走了。

走廊恢复寂静。林一凡直起腰，表情平静，心里却沉了下去。

他再看一眼赵日天头顶的卷气值——暗金色纹路比刚才更亮了一些，像是有什么东西正在被激活。

林一凡攥了攥拳，把手机解锁，给沈敛发了条消息：“复赛提前了，评委里有秦氏的人。你还有多少事没告诉我？”

对面迟迟没有回复。

他又加了一句：“你那个开发者内测版系统，能算比赛结果吗？”

这一次，消息框的对面出现了一个正在输入的提示，然后又消失了。反复三次。

他以为沈敛不会回了，正要放下手机，屏幕上突然弹出一句话——没有前文，没有铺垫，只有一句话：

“别让赵日天在复赛里碰到你写过的任何一行代码。”

林一凡愣住，随即猛地抬头看向赵日天的方向。赵日天正背对着他敲键盘，那台黑色笔记本电脑的屏幕余光里，似乎有什么东西在闪烁。

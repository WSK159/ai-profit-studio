# 第285章 十七层天台

夜晚的风带着湿气，从老街巷口灌进来，掀动林一凡的衣角。他攥着那枚墨绿色笔记本，指节发白。沈稚冬的声音还在耳边打转——“林一诺留下的是一条路。”

他闭了一下眼，把笔记本塞进外套内袋，脚步朝星辰科技大厦的方向迈出去。

老小区离大厦不远，穿过两条街就是。林一凡走得很快，路灯把他的影子拉长又压短。手机屏幕又亮了一下，没有新消息。他点开那条匿名短信看了一眼：“别去天台，有人等你——你妈。”他冷笑一声，锁了屏。他妈八年前就死了，这条消息比锁匠还可疑。

但正因为可疑，天台非去不可。

星辰科技大厦的玻璃幕墙在夜色里像一块巨大的黑色墓碑。林一凡没走正门，绕过保安岗亭从地下车库入口摸进去。消防通道里应急灯泛着惨绿的光，楼梯一级一级往上数。他数到第十三楼的时候，脚步声停了——不是他停的，是楼上有什么声音，像金属拖过地面的摩擦声。

林一凡屏住呼吸。

【摸鱼雷达：检测到异常劳动浓度，来源：上方三楼，移动速度缓慢。】

他眉头一皱。雷达平时只能感知人的劳动浓度，可这玩意儿模糊得像一团雾，连是人是物都分不清。这让他想起档案科的锁匠——那个雷达完全感知不到的东西。可这次雷达有反应，只是反应很怪。

林一凡没有往上走，反而侧身贴近楼梯间的墙角，屏息等着。

那声音越来越近。每隔十几秒响一次，像是拖着一截铁链。大概两分钟后，一个佝偻的影子出现在楼梯转弯处。是个穿灰色工装的老头，手里拖着一根撬棍。他头发花白，脸上沟壑纵横，走到十三楼与十四楼之间时，忽然停下来，偏过头朝林一凡藏身的方向看了一眼。

没目光对视——老头的眼睛是闭着的。

但他开口了，声音嘶哑得像砂纸磨铁：“钥匙认了主，就别往回走。”

林一凡背后的冷汗一下冒了出来。他刚想开口，老头已经拖着撬棍继续往上走去，一步、一步，消失在十四楼的拐角。

林一凡舔了下嘴唇。钥匙认了主？蓝色旧书里的提示他说过同一句话——“书会认主，三叉尖指向归还之路”。这老头怎么知道钥匙的事？他低头看了眼口袋里的三叉钥匙，犹豫了五秒，还是迈开腿继续往上走。

十五、十六。

到了十七层天台门前，铁门半掩着，门缝里渗进来风，夹着雨丝。

林一凡推开门。天台风很大，雨点斜斜刮过来，打在他脸上。视线扫过宽阔的混凝土空台，水箱、管道井、一部生锈的检修梯。没有人。

他走到天台中央，目光落在地面上——距边缘一米半的位置，有人用粉笔画了一个圈，圈里写着一组坐标：0427-13-18-2019。

和芯片鱼嘴里浮现的坐标一模一样。

林一凡蹲下来，指尖碰了碰粉笔灰，是新的，最多不过半天。他直起身，从口袋里摸出那把三叉钥匙，站在粉笔圈的正中央。风更大了，头顶似乎有什么东西在靠近——像低空掠过的鸟。他抬头，什么都没看见。可雷达突然开始剧烈报警。

【警告：检测到高强度异常信号源。距离：垂直方向，3米，2米，1米——】

林一凡猛地往后退了一步，那枚银色芯片鱼从他口袋里自己飞了出来，悬停在半空中，鱼嘴的凹槽正对着他手里的三叉钥匙，发出细微的嗡鸣。

然后，鱼嘴张开了。

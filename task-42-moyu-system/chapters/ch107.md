# 第107章 基因共振

旧机房的空气凝滞如胶，只有那台老式服务器风扇发出病牛般的嗡鸣。林一凡站在原地，看着自己的双臂——皮肤下的血管隐约泛着淡金色的纹路，像是某种细密的电路正在皮下蔓延。他抬起左手，五指张开又合拢，感觉陌生得像操纵一台新机器。

赵日天靠在那台被拆开外壳的服务器旁，胸前贴着一张银色芯片贴片，已经被汗水浸透。他的嘴唇发白，额角的青筋还在突突跳动，但眼神却比之前任何时候都明亮。那种光，像是一个赌徒押上所有筹码后，终于等到了开牌的瞬间。

“你他妈的——”林一凡终于找回自己的声音，嗓子发紧，“你把你自己当成锚点？你知道这意味着什么吗？”

“意味着从今天起，你死了我也死了。”赵日天咧嘴一笑，露出一口白牙，“我死了，你体内的三套系统也会跟着崩解。咱们俩现在是同一根绳子上的蜉蝣。”

“我不需要你这么做。”

“你需要。”赵日天抬手打断他，动作有点颤抖，“你以为你在旧机房翻出来的那些东西是什么？《断根计划》只是冰山一角。执行者是谁？为什么要把‘摸鱼’这个概念污名化成精神毒药？你一个人查得过来吗？”

林一凡沉默了几秒。他的耳边忽然响起一个熟悉的声音——

**【摸鱼系统·紧急提示】**

**宿主生物特征变更确认中……**

**变更率：37%……52%……71%……**

**检测到外来基因锚点：赵日天（卷王系统宿主）。**

**当前状态：双锚点共存，系统冲突风险降低，但共享生命线已建立。**

**注意：锚点断裂将导致宿主系统全面崩溃。**

林一凡盯着眼前半透明的蓝色光幕，那行字像烧红的烙铁一样刺眼。他深呼吸了几次，强行压下心头翻涌的情绪，抬起头：“你知道多少？”

赵日天托着腮帮子，歪着头看他：“我知道的也不多。但我有个猜测——蜉蝣残影空间警告你生物特征变更，说明你从重生那一刻起就不是原来的林一凡了。你上一世的猝死，真的只是意外？”

林一凡瞳孔骤缩。这句话像一根针，精准地刺入了那个他一直回避的念头——自己是重生回来的，可前世的死亡真的只是过劳猝死吗？如果那个晚上有人做了手脚呢？

“我要验证一件事。”他忽然转身，快步走向机房角落那台联通内网的终端机。那台老旧的显示器闪烁着墨绿色的字符，林一凡的手指在键盘上飞舞，他的大脑仿佛被某个外置引擎推动着，SQL语句像流水一样倾泻而出。

赵日天凑过来，看着屏幕上刷新的数据：“你在黑星辰的人力资源系统？”

“不是黑，我只是在查一件人事档案。”林一凡的手指顿了一下，“周莉，上一世她在我猝死前三天离职。我查过她的离职记录，理由是‘个人原因’。但我现在调出来的数据——她离职当天，签了一个名字叫‘断根执行组’的保密协议。”

赵日天的面色一下子变了：“你是说，周莉跟那个计划有关？”

“我不知道。”林一凡盯着屏幕上那份被加密的PDF文件的文件名——“根须清除名单”，声音冷得像深冬的井水，“但我现在知道了一件事——那个名单里，我排在第三位。”

两个人同时沉默了。机房里只剩下服务器风扇和终端机的嗡鸣。忽然，那台老式终端机的屏幕闪了一下，跳出一行不请自来的字符：

**【你终于找到这里了。但负三层不是你该来的地方，去负五层。那里有人在等你。—— R】**

赵日天猛地抓住林一凡的手腕：“负五层？星辰科技的旧楼不是只有地下三层吗？”

林一凡盯着那行字，心脏砰砰直跳。他正要开口，机房深处传来一声金属碰撞的脆响——像是有人踢翻了一个空铁桶。

两个人同时回头，黑暗中隐约浮现出一个矮瘦的人影，正背对着灯光，缓缓转过身来。

那是一个不该出现在这里的人。

老王。

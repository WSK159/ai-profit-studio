# 第184章 负层密室的第二个房间

黑暗持续了大约十秒，然后头顶传来咔哒一声，老式荧光灯管像垂死的萤火虫一样抖动了几下，最终亮起。这间密室只有普通办公室一半大小，墙面是无涂料的水泥，地面上覆盖着一层薄薄的水渍，角落里堆着几摞防水袋，其中一只袋子被水泡胀裂了，露出里面湿透的文件一角。空气里散漫着旧纸张与防水漆混合的气味，刺鼻但不至于窒息。

赵日天跟进来后，钢门在他们身后发出一声沉闷的锁定音，铁链自动缠回原处，三把挂锁重新挂好——仿佛刚才的一切从未发生过。他扫视了一圈，目光落在墙角那堆防水袋上，眉头拧成一个结：“老周的东西，果然被水泡了一部分。”

林一凡已经蹲在裂开的防水袋旁边，小心翼翼地抽出一张文件。纸张边缘泡烂了，但中间大部分文字还看得清，是一份手写的结构图，标注着“第三层——功能房”和“第四层——存放间”，用红色水笔在“存放间”下面重重画了两条横线。旁边一行潦草的小字写着：工人不知道第二道门的事，切记别用钥匙，用老法子。

林一凡把这张图纸翻过来，背面凌乱地贴着一张拍立得照片，照片上是一扇半掩的铁门，门后的空间看不清楚，但门框边挂着一块木质铭牌，上面刻着四个字——“人力之源”。照片的角落，有一只手的残影，手腕上带着一块银色老式机械表。林一凡认得那只表，和自己前世挂在办公室工位边的那只一模一样。

“老周早就知道你会上辈子的工号，”赵日天站在他身后，目光落在照片上，声音压得很低，“他说‘锁不在门上，在门里’，是暗示你从外面撬锁没用，你得找到那扇门后面真正锁着的东西。”

林一凡正要开口，头顶的荧光灯忽然闪了两下，又暗了下去，一股细碎的震动从地面传来，像是很多人正踩着水泥台阶快速靠近。赵日天脸色一沉，侧耳听了几秒：“不对，这不是钱总的人——钱总养的那帮人走路是皮鞋，这种频率是胶底运动鞋，至少五个以上。”

话没落完，密室另一面墙上突然多出一只手，五指按在水泥墙上，指甲干净，没有尘土。接着又一只，两只，三只。那面墙像某种软质幕布一样被缓缓推开了——隐藏在墙体里的另一扇木门，此刻正从另一侧被人拉开。开门的人戴着一顶灰色鸭舌帽，身形瘦削，穿了件洗得发白的旧外套。他抬起头，露出一张林一凡很熟悉、却又以为永远不会再在活人脸上看到的面孔：老周。

老周没有死。他的脸色蜡黄，嘴唇干裂，眼窝深陷，但锁骨上的线条依然锋利，手里握着一把铜色钥匙，钥匙齿上有几道不规则缺口，正好匹配照片中那道铁门的锁孔。他连看都没看赵日天，目光直直落在林一凡身上，然后咧嘴笑了笑，声音沙哑得仿佛喉咙里含着锈渣：“你们来得正好，我还担心门被水灌了之后你们找不到第二间房。”

赵日天警惕地退后半步，一只手插在裤兜里，似乎随时准备掏出什么：“你什么时候回来的？”

“今早五点半，比你约桥头的时间还早了二十分钟，”老周用那把铜钥匙敲了敲掌心，“我一直蹲在上面的排水管里等你们下来，确定没有尾巴才过来。”他顿了顿，又看了林一凡一眼，“照片里的那只手表你看见了吧？那是我从你前世工位上扒下来的，比你以为的早。你可能不记得了，你死的那天晚上，我在隔壁工位。”

这句话像一记冷水浇在林一凡后背上，他盯着老周的脸，想从那双浑浊的眼里看出一点撒谎的痕迹，但什么都没看到。

老周伸手拉开那扇木门，门后是一条更窄、更暗的走廊，尽头隐约透出一点淡蓝的光亮。他退到门边，让出通道：“别磨蹭了。这门后的东西看完，你再决定信不信赵日天。”

林一凡站在原地，没有动。他的系统面板又一次自动弹出，就在他脚下踩着的湿水泥地板上，浮现出一行几乎不可见的白色荧光字：警告：离开此房间前，你将被强制支付一次“真相代价”。

他抬头，看向老周和赵日天两人——一个从死亡里带回了钥匙，一个从监听网里带回了密语，而他自己口袋里，还留着一张他写在凌晨两点的便签：如果我回不来，请把我最后一次摸鱼的咸鱼值转给爸妈。他深吸一口气，迈出了那一步。

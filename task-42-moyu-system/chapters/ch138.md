# 第138章 钥匙、锁与钱总

林一凡的手指悬在半空，停在那台碎裂手机上方三厘米的位置，指尖的汗毛几乎能感受到金属外壳散发出的凉意。他深吸一口气，还是抓起了那台手机。

屏幕上的字没有变化。“救我，摸鱼系统是假的。”——这六个字刺得他眼睛生疼，心头像被一只无形的手攥住了。他真想当面问问上辈子的自己：你到底发现了什么？摸鱼系统明明是真真切切的金手指，它给他换过技能、救过老王、在裁员潮里保过组员的命，怎么会是假的？

他还没来得及深想，手中的手机忽然震动起来。屏幕闪烁了两下，跳出一行新的消息：“钥匙已激活，第42号宿主确认，建眼计划正式启动。”

“操。”林一凡的骂声几乎是从牙缝里挤出来的。

他猛地转身，目光锁定在赵夜白身上：“你刚才说，你才是名片的真正拥有者，那这个启动，算是你的还是我的？”

赵夜白的表情微微一僵，像是没想到林一凡反应这么快。他沉默片刻，终于说了一句：“启动条件绑定的是指纹和瞳孔，你刚才按在门上，所以系统默认你为42号宿主。建眼计划的核心节点已经从第39号转移到你身上。”

“转移？”林一凡冷笑，“你们建眼计划到底是在干什么？监视全城的摸鱼系统？还是监视拥有系统的人？”

“监视。”赵夜白纠正了他的措辞，“但严格来说是‘识别’。建眼计划建立的初衷，是识别每个拥有系统的普通人，确认他们是卷方还是躺方。因为一旦鹬蚌相争的局面开始，系统主人的站位将决定整个职场格局的走向。”

林一凡听到“鹬蚌相争”这个词，脑海里突然闪过钱国豪那张笑里藏刀的脸，以及他深夜在停车场递名片时的眼神。那人递名片时手指微微颤抖，眼底却透着一种和他背后阴冷气场不匹配的急躁——像是在赶时间。

“钱国豪在给谁做事？”林一凡直接问。

赵夜白没有正面回答，他蹲下来，指尖碰到法阵中心那把锈迹斑斑的铁钥匙，铁器忽然发出嗡鸣声，像某种内部钟摆在晃动。他收回手，面色凝重：“你可以当面问他。他应该就在这栋楼里。”

林一凡皱起眉：“我在B3层闹出这么大动静，他没听见？”

“B3层有隔音法阵，外面听不见。”赵夜白站起来，指向那条刚露出来的地下阶梯，“但上面的人能看见入口。你要是现在出去，恐怕会被钱总堵个正着。”

话音未落，头顶上方传来一阵金属管道被踩动的脚步声，像是有人正从楼梯间快步下来。紧接着，一道隔着一层薄墙的熟悉的声音破空而来：“林一凡，你在下面吧？正好，我有话要跟你说。”

钱国豪的声音。林一凡的后背瞬间绷紧。

他记得这个人。上一世，钱国豪是星辰科技的最佳伯乐，把他从底层一步步提拔上来；这一世，他成了怀疑他的老板、压榨他的资本家。但直到今天他才隐约明白，钱国豪大约从来没有把他当成单纯的员工——他更像是被选中养大到某个时间节点，再被收割的“钥匙”。

“赵夜白，你最好说清楚钱国豪到底要干什么。”林一凡压低声音，语气里带着罕见的冷厉。

赵夜白看了他一眼，忽然笑了一下：“林一凡，你以为你在加班猝死前那晚，最后一次见到的人是谁？”

林一凡的脑中闪过一道画面：冰冷的天台，手里夹着那根没点着的烟，手机亮起一条来自“钱总”的消息——“来B3层，有个东西给你看。”

他当时没有去，因为人已经倒下去了。

但那条消息，他确实收到了。

脚步声已经到墙外了，门缝里渗进来钱国豪的皮鞋尖，他听到钱国豪的声音再次响起：“林一凡，那把钥匙不是你的，你最好别碰——否则你上辈子的死法，会再原样重演一遍。”

法阵上那把锈钥匙忽然从地上一寸一寸地升起来，钥匙眼对准的方向，正好是他——和他的胸口。

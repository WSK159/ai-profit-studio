# 第379章 泵房的访客

林一凡和赵日天谁都没有第一时间出声。门后那道声音也没有催，只是又轻微地喘了两下，仿佛说话本身已经耗尽全力。

僵持了十几秒，赵日天先开了口：“你是谁？”

门后传来一声极轻的笑，带着喉咙受损般的嘶哑：“……我姓沈。你舅舅的那个沈。”

赵日天的身体明显绷紧了一瞬。他的舅舅是沈临渊——可他们刚才亲眼看见沈临渊扯断铁链逃走，那道身影虽然佝偻、老迈，却动作利落，绝非门后这个连呼吸都虚弱的声音。

“你姓沈，那你叫什么？”林一凡接过话头，手机已经调成录像模式，对准门缝。

“……沈稚川。”

赵日天握打火机的手指微微一颤。他低声对林一凡说：“我母亲提过一个叫‘沈稚川’的人，只说过一次，说这个人是她堂弟，早年上山进矿，再也没出来过。家族里都当他死了。”

“那你还活着？”林一凡的声音放平，“门后面是什么地方？你怎么会在泵站里？”

门后沉默了一阵，然后那声音又响起来：“我在这里守了十四年。这个泵站不是抽水的，它抽的是——记忆。”

“什么？”

“归零装置的冷却系统，用的是地心磁场核心的低温液。但装置启动过一次之后，液体会受污染，里面含有人工记忆碎片。”沈稚川的声音断断续续，像在忍受着巨大的痛苦，“你们听见的心跳声，其实是泵把污染液打回熔炉的声音。每次它跳一下，就说明有一段记忆被烧掉了。”

林一凡猛地想起那个加载条——0.327%、0.329%，缓慢上升。如果沈稚川说的是真的，那每烧掉一段记忆，归零装置就完成一部分“保存程序”。加载条上升的百分比，就是被处理掉的记忆总量。

“你有钥匙吗？”沈稚川又开口了，声音里多了一丝急迫，“我听到了它停跳了三秒钟，这是最后的窗口期。我妹她——我是说，沈稚冬——她留下过一段东西，在泵房的第三号冷却箱里。用钥匙开。”

“什么钥匙？”

“你们手里的那个铁牌子。074。那是冷却箱的维护钥匙。”

林一凡低头看着手里的铁质标牌。刚才他试着插进轮盘的匙口，完全不匹配，原来它不是用来开门的，而是用来开冷却箱的。他将铁牌在手中转了两圈，看向赵日天：“怎么开？”

门后传来一声略带欣慰的叹息：“泵房的门右侧，有一块松动的砖，按下去，门就会打开一条缝。不用我出来——你们也别让我出来。”

赵日天看了林一凡一眼，两人眼神交汇，无声地交换了决定。林一凡摸到门框右边，果然找到一块微微凹陷的砖。他用力按下去，门体发出一阵嘎吱声，铜管之间的缝隙扩大，刚好够一个成年人侧身挤进去。

一股潮湿的气流扑面而来，带着铁锈、机油和某种说不清道不明的腐败气息。泵房内部比外面更宽敞，足有半个篮球场那么大，头顶悬着密密麻麻的管道，像交错的血管。正中央立着一台巨大的泵机，表面覆盖着铁锈和油泥，泵机底部是一个半人高、方形金属箱体，侧面焊着一块铭牌，写着：三号冷却箱。

而泵房的角落里，蜷缩着一个人影。他的头发灰白，胡子拉碴地覆住半边脸，只露出一双浑浊的眼睛，目光定定地锁在林一凡手里的铁牌上。

“快开。”他说，“那是她留给你——留给所有后来人的。别让泵再吞了。”

他话没说完，泵机突然发出了一声不自然的轰鸣，转速骤增。机械心跳声变成了密集的蜂鸣。冷却箱的表面开始急剧结霜，一层白霜以肉眼可见的速度蔓延。

“它要加班了！”沈稚川的嗓子几乎是从喉咙里挤出来的，“快！趁它没把记忆全部烧完，把冷却箱打开！”

林一凡大步跨过去，蹲下来，铁牌对准冷却箱上方的槽口——这次严丝合缝地插了进去。他一咬牙，握着铁牌逆时针——等等，不对，他想起之前1147号消息里的提示，不是逆时针，是顺时针。“顺时针！”他猛地用力扭转。咔哒一声，锁簧弹开，箱盖弹起一道缝隙。白雾从箱子里涌出，带着刺骨的寒意。

林一凡掀开盖子，把里面的东西抓了出来。是一卷医用纱布，包裹着一台老旧的翻盖手机。屏幕还亮着，显示着一行字：“播放录音。”

他按下播放键。扩音器里传来一个女人的声音，清冷、平稳，像在念一份报告：“我是沈稚冬。如果你听到这段录音，说明零七四号载体已经找到了三段钥匙中的第一段。现在你听到的是我的第一份备份记忆。我要告诉你三件事：第一，归零装置不是用来毁灭的，是用来转移的。第二，九名外部载体里，有一个人是我，另有一个是赵春生，第三个是钱总。第三……”录音突然顿了一下，像是她本人在这里停了一拍才继续说，“剩下的六个编码里，有一个叫林一凡。”

泵机猛地一震，转速骤然降下来，机械心跳声渐渐归于缓慢的节奏。冷却箱的白雾散去，箱底只剩一块光滑的石板，上面刻着四个字：“记住自己。”

沈稚川从角落里站起来，佝偻的身躯一点点挺直，他第一次认真地看向林一凡的脸。那双浑浊的眼睛里映着手机屏幕的冷光，缓缓说道：“林一凡……你终于来了。”

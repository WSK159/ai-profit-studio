# 第155章 归并倒计时

安全出口的绿光映在宋顾问脸上，那张永远挂着职业微笑的脸，此刻在阴影里显得格外诡谲。系统面板悬浮在半空，血红色的倒计时正在跳动：七十二小时。

“三天。”林一凡盯着那行字，“你定的规矩？”

宋顾问笑而不语，目光从三人脸上缓缓扫过，最后落在老王身上：“M-013，你没有告诉宿主们规则变更的事？”

老王闷哼一声：“规则是你定的，你我心知肚明。”

林一凡心里猛地一沉。老王这话里有话——宋顾问不仅是发布者，她本身就是规则设计者？一个顾问，有什么资格修改摸鱼系统的规则？除非……

“宋顾问，你到底是什么人？”赵日天显然也想到了这一点，他的手背上的编号闪烁了一下，像是应激反应。

宋顾问没有直接回答，反而转身走向走廊尽头，嗓音飘回来：“三天后，A区天台，做归并仪式。如果你们还在纠结我的身份，不如先解决眼前的麻烦。”

她说“你们”。

林一凡和赵日天对视一眼，两人罕见地达成默契——宋顾问这话，分明指的不是老王。同源宿主归并，规则说“两名宿主完成编号融合”，那么，谁是另一名？

“不是你。”赵日天冷声道。

“也不是你。”林一凡摇头。

老王长长的叹了口气，声音压得极低：“第三个宿主，跟我一样，都是M序列。M-017，编号碎了一半，连我也不确定她还活着。”

“还活着？”林一凡抓住关键词。

老王嘴唇翕动，像是在斟酌该说多少：“第九百九十天前，系统后门被我改掉的那天，M-017从系统里被抹掉了。我只知道她姓宋。”

宋。宋顾问。

林一凡浑身的汗毛瞬间竖了起来。宋顾问是宿主？可她刚才展示规则的方式，完全就是管理员权限。宿主动手改规则？除非——老王能干的事，别人也能干。

“老王，”林一凡压低声音，“老鱼，你既然管着后门，那你应该知道，宋顾问能不能改规则。”

老王的眼神忽然变得很复杂，他盯着林一凡，嘴唇动了动，却没发出声。林一凡读出他的口型：跟我来。

三人不约而同地拐进了旁边的杂物间。老王反手把门锁上，从口袋里摸出一张皱巴巴的纸条，上面歪歪扭扭写着一串代码。他指着末三行，林一凡眼睛猛地睁大：那不是代码，是一段输入记录——后门被篡改的第三十七秒，有人从“外部”登入过系统，使用的ID前缀是“GZ-001”。

GZ。

林一凡脑子里嗡的一声，他想起一个东西：公司最新引入的AI考核系统，后台代号正是“GZ”。AI考核系统曾经被抓到“摸鱼”，但一直没人找到数据源。宋顾问是AI考核系统的项目对接人。

“老王，你是说，宋顾问用的权限，不是来自摸鱼系统？她是从AI考核系统那边反向入侵的？”林一凡的声音绷紧了。

老王点头：“她把自己挂进来了。两个系统共用一个数据池，她借了AI的力量给自己开权限。”

赵日天站在门边，听完这话，罕见地没有出言嘲讽，反而若有所思地盯着自己的编号，低声说：“所以宋顾问要我和这个倒霉蛋归并……她是想收了我们的系统？吞掉两个宿主的力量，她就能完全控制摸鱼系统？”

话音未落，走廊里传来脚步声。三人同时噤声。

脚步声在门外停下，紧接着是宋顾问的声音，平静得让人发毛：“三分钟了，你们还没商量出结果吗？”

没有人回应。

门缝底下滑进来一张纸，上面只有一行字：

“忘了告诉你们：归并不一定是两人合并。规则里写着‘同源宿主必须在三日内完成编号归并’，但没说双方必须都同意。”

林一凡捡起那张纸，指尖泛冷。老王像是早料到一般，闭上眼，缓缓说：“她要的是强制归并。”

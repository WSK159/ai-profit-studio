# 第431章 第三层抽屉

铁皮门后的走廊不过三米宽，两侧水泥墙皮剥落，露出暗红的砖缝。白色金属门就在走廊尽头，门板锃亮得与四周格格不入，像有人每天擦拭。此刻门后静悄悄的，三声敲击的余音还在林一凡耳膜里震颤。

“赵铁柱还说过什么？”林一凡没回头，视线钉在那扇门上。

老杨头在他身后咳嗽，声音像破风箱：“他说……拿L卡的人开白色门的时候，别回头，别说话，拿了东西就走。”

“就这？”

“就这。”

林一凡低头看了眼手里的生锈钥匙。钥匙齿纹扭曲，像某种蛇形图腾，握在手里沉甸甸的，不像一把钥匙该有的重量。他想起父亲书房抽屉底层那个铁盒——上着锁，他从没见过钥匙。原来钥匙一直在这儿，守了四十年。

他深吸一口气，朝白色金属门走去。每一步踩在水泥地上，脚步声在窄道里放大。门把手是银色的，没有灰尘，没有指纹，像是刚被换过。他把钥匙插进锁孔，生锈的齿纹恰好吻合，拧动时发出一声很轻的“咔”。

门没开。

锁芯转到底，却没有推动门板。林一凡皱眉，又转了一圈——还是没开。他低头看钥匙，发现齿纹上有细微的刻痕，排列成三道短横。B3档案室门上的三道斜杠，他脑子里猛地闪过这个念头。

“钥匙不对？”老杨头在身后问。

“不是钥匙不对。”林一凡把钥匙举到眼前，“是锁不对。这扇门有两道锁。”

话音未落，白色金属门内侧传来一声几乎听不见的轻笑，女声，很轻，像纸页翻过。林一凡浑身一僵，门内那三声敲击的来处浮现出轮廓——档案室那个从未出去的女人。T-002。锁匠。

他退后半步，目光扫过门框边缘。没有第二把锁孔，没有任何能插入钥匙的地方。但他看到门框左侧有一块和墙面颜色几乎完全一致的方形区域，边缘有一道极为细密的缝隙。

“林一凡。”老杨头忽然喊他，声音带着颤抖，“你背后——你背后亮灯了。”

林一凡猛然回头。铁皮门的方向，原本熄灭的暗红打卡机不知何时重新亮了，屏幕上不再是L-001的绿色数字，而是一行红色代码：T-042。钱总的工号。他扭头去看走廊——空无一人。但打卡机的红色屏幕在跳闪，像心脏起搏的电击。他注意到打卡机侧面的铁皮上不知何时多了一道新划痕：一条直线贯穿三个圆，像钥匙齿纹那道三连刻痕的镜像。

他再次面朝白色金属门，抬手按住那片方形区域。指尖触到一丝温热，像有人刚从另一侧贴着墙站了很久。

“咔——嗒。”

第二道锁弹开了。白色金属门无声地滑开一条缝隙，缝隙里透出暗黄的光，像旧台灯照亮档案柜的色调。门缝中飘出一股霉味、纸灰味，以及一丝极淡的烟味——忘忧草。

“别停。”老杨头在他身后说，声音几乎哑得听不见。

林一凡推开门，侧身闪入。里面的空间比他想象的小。一张铁桌，一把木椅，一个三层的铁皮档案柜。柜门没锁，第二层抽屉半开着，里面是空的。第三层抽屉关着，没有把手，只有一个小小的圆孔，圆孔边缘刻着几道螺旋纹。他把钥匙拔出，去掉那段齿纹，钥匙柄的尾部是一个圆柱形的头。

他握上去，钥匙柄的螺纹与圆孔完美咬合。他拧动的时候，抽屉没开，但他听见了歌声。极轻极远，像隔着整条走廊传来的儿歌：“三月里来桃花开，阿妈在家讲笑话……”他母亲的声音。他母亲唱过的歌。

抽屉弹开了。

里面躺着一本红色塑料皮笔记本，封面上写着：T序列工位交接手册（卷一）。林一凡伸手去拿的时候，背后传来脚步声。不是老杨头的。是皮鞋踩水泥地的声音，规律、有力、一步一步靠近。他没有回头——他记得老杨头转述的那句“别回头”。他抓起笔记本，前脚迈出门槛的瞬间，铁皮门方向传来一声厚重的“砰”，像有什么巨大的东西贴了上来。林一凡侧身贴着墙，余光扫过走廊尽头——铁皮门关上了。暗红打卡机的屏幕熄灭了。

身后白色金属门里传来轻轻的翻页声，女人的声音从门缝里挤出来：“下次来，带把长柄梳子。”

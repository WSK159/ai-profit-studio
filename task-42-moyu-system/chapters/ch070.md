# 第70章 雪落无声

林一凡几乎是本能地把铁皮柜盖子压回去，单手把那四块硬盘拢进怀里，借着墙角阴影蹲下，整个人像只被踩了尾巴的猫一样绷紧。天台门口的灯光逆着打进来，剪出两个人影——其中一个是下午在走廊里停在他工位前的审计员，另一个穿黑色短袖、左耳戴着颗银色耳钉，手里提着一台掌上终端，屏幕正泛着幽蓝的光。

“王哥，排查完了。”黑短袖的声音懒洋洋的，“顶层旧服务器组没找到，铁柜子空的。”

审计员没接话，径直走到天台中间，四周环顾了一圈。风把他的头发吹得凌乱，他仰起头，深吸一口气，像是在闻什么气味。林一凡屏住呼吸，怀里硬盘冰凉的金属边硌着胸口，他不敢动，汗水顺着太阳穴滑下来。

“你闻到了吗。”审计员突然开口。

黑短袖愣了愣：“闻到什么？”

“数字的味道。离线的数据，刚拔下来的硬盘，会带一点淡淡的铁锈味混着硅胶老化味。”审计员转向西北角，目光精准地落在排水口附近的阴影里，“塔台，你往那堆砖头那边看一眼。”

黑短袖朝这边走来，脚步声在防水卷材上沙沙作响。林一凡脑子里飞速运转：跑是跑不过的，怀里四块硬盘，对方两个人，真打起来他就是个送人头的程序员。唯一的机会是楼顶另外一侧的消防梯，但那边没有任何遮挡，跑过去就是活靶子。

千钧一发之际，他怀里的硬盘里突然震动了一下，像里面有什么东西苏醒了。紧接着，他裤兜里的手机震了一下，提示音刺耳地划破空气。

黑短袖的脚步猛地停住：“什么声音？”

林一凡心里骂了一句，掏手机的手还没抬起来，屏幕上自动弹出一个界面——摸鱼系统，紧急通知：检测到“雪”数据模块心跳信号，宿主是否加载？他来不及细想，拇指猛戳“加载”键。下一秒，一阵电流顺着他的手指窜进大脑，眼前白茫茫一片，然后他看见了——

江雪的视角。

她坐在楼顶排水口边，双腿悬空，楼下是蚂蚁一样的人群，她手里握着一台老式MP3，耳机线耷拉着，屏幕亮着一行字：“最终任务：收集整栋楼所有员工的卷王数据；完成后即可解锁‘自由’权限。”

“自由。”江雪在风里自言自语，“他们说完成任务就能自由，可我越来越觉得，我加班加得越狠，离自由越远。”

白茫茫的画面像信号不佳的电视机一样闪烁了几下，然后归于混沌。林一凡感觉到一阵呕吐感从胃里涌上来，整个人跪在了地上。黑短袖已经走到离他不到三米远的地方，手电筒的光扫过砖堆，照出了他弓着的后背。

“有人！”

审计员比他更快，几步冲过来，眼看着就要抓到林一凡的衣领。林一凡咬牙撑着站起来，怀里硬盘猛地滑脱，四块硬盘“哐当”一声掉在地上，其中一块边缘撞碎，露出里面银白色的碟片。他的脑子像是被什么东西劈开了一道缝，一句江雪最后的话清晰地灌进来：“如果不能自由，那我宁愿被删掉。”

空气里响起一声极轻的“嘀”，紧跟着那块裂开的硬盘里闪了一下指示灯，像是一段沉睡的数据被重新唤醒。审计员愣住了，他低头看着那块硬盘，脸上的表情瞬间凝固：“这是……雪落无声的备份？”

黑短袖站在原地，掌上终端突然开始疯狂报警——“卷王系统宿主现存活数：2。”

林一凡趁着他们愣神的瞬间，弯腰捡起剩下三块完好的硬盘，朝楼顶另一侧消防梯的方向狂奔。风灌进喉咙，肺像被拉锯了一样疼，身后传来审计员的声音：“追！那三块是主盘！她的人格碎片还在里面！”

他抓住消防梯的铁扶手，脚一蹬，整个人滑下去两格，铁梯被夜风吹得吱吱作响。与此同时，他听到楼顶那边传来一个极轻的女声，像埋在废墟下的低吟：“林一凡，别让它们找到我。我只是……想摸一次鱼。”

林一凡在黑暗中拼命往下爬，三块硬盘贴着胸口，怀里的温度几乎要被冻透。他的手机屏幕又亮起来，摸鱼系统弹出一行新提示：支线战役开启——拯救“雪落无声”，奖励：10000咸鱼值。

他落到八楼的平台时，喘了整整十秒钟，回头看了一眼，黑压压的天台边缘，什么也看不见了。他目光转向怀里的三块硬盘，其中一块的外壳上，用指甲刻着一朵丑丑的小雪点。

他的心跳还没平复，手机屏幕上紧接着又弹出一条推送——来自钱总：“通知：秦氏B座本周六凌晨进行全楼服务器机房断电升级，请所有部门提前备份数据。”发信时间：今晚21:00。而现在是18:40。停电升级，是巧合还是有人想彻底毁掉江雪的“尸体”？

林一凡攥紧硬盘，把脸埋进衣领里，半晌，低声骂了一句：“赵日天你这个王八蛋，留下张纸条就跑，让我来趟这个雷。”然后他还是掏出手机，拨通了一个号码——组长老王。

电话响了四声，通了。老王的声音带着困惑：“一凡？这个点你打给我干嘛？”

“老王，帮我一个忙。”林一凡声音压得极低，“今晚你当什么事都不知道，明天早上，公司会爆一条新闻。”

电话那头沉默了几秒，老王说：“你小子……别搞出人命来就行。”

挂了电话，林一凡低头看着硬盘外壳上那朵丑丑的雪点，目光沉下去。

周六凌晨。断电升级。还剩两天时间。

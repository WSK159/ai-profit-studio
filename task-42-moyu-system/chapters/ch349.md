# 第349章 往上是山，往下是门

隧道外的风带着山岩的潮气，刮在脸上像细砂纸。林一凡盯着隧道深处那片吞噬了灰衣人与铁皮棺材的黑暗，后背的冷汗刚被风干，新的又渗了出来。

“他说的是‘往下十三级水泥台’。”赵日天把烟盒纸折了两折，塞进内袋，“不是往上。”

“往上是山。”林一凡望向北麓山脊线，云顶山并不高，但山体浑圆敦厚，像一只伏卧的兽。“往下是门。”

孙满仓没有接话。他弯腰蹲在隧道口那块被水刀切过的铁轨断头旁，指腹摩挲着断口的纹路，从衣兜里掏出一截红绳，比了比断口的宽度，又收回去。动作极快，但林一凡的余光还是抓住了那个细节——红绳的一端系着一枚铜纽扣，纽扣表面磨得发亮，像被人捏了很多年。

“孙师傅，”林一凡走过去，语气随意得像在聊天气，“你十八岁帮沈临渊铺这段轨道的时候，他多大？”

“比我大十岁。”孙满仓站起身，拍了拍膝盖上的灰，“他那时候刚从南边回来，说是要修一条‘给死人用的铁路’，镇上人都笑他疯。他自己扛枕木，我来搭轨道。”

“给死人用的铁路……”赵日天咀嚼着这句话，瞳孔微缩，“铁皮棺材。”

孙满仓没点头也没摇头，只说了句：“有些东西，不是给我们这些活人看的。”

手机在口袋里震了一下。林一凡摸出来，屏幕上又弹出一条未知号码的短信，发件人显示“1147”，内容只有两个字：

“蹲下。”

这次他毫不迟疑地拉住两人往下一压。几乎是同时，一颗子弹擦着他们头顶的岩石飞过去，“噗”地钉进身后一颗杉树树干里，炸开碗口大的木屑。枪声在山谷里回荡了足足三秒。

“狙击手。”赵日天贴着地面滚到一块巨石后，声音压得极低，“十二点钟方向，山腰平台。”

林一凡盯着那棵杉树上的弹孔，木屑边缘焦黑——是燃烧弹。对方的目标不是杀人，是逼他们离开隧道口。隧道里有什么，对方不希望他们继续挖下去，也不希望他们在这儿逗留太久。

反方向。他几乎是本能地想。“往下十三级，往山里。”

孙满仓突然开口：“我知道一条走水的小路，从北麓第三梯下去，绕过一片杉木林，能直接到山腰的废弃引水渠。那条渠是当年跟铁路一起修的，尽头就是第三梯下方的通道口。”

“你怎么知道得这么清楚？”

“因为那条渠也是我挖的。”孙满仓的声音闷闷的，“沈临渊当时说，轨道是给外人走的路，水渠是给自家人走的。我还问他自家人是谁，他说——‘以后再告诉你’。”

二十年了，他还没等到那个答案。

林一凡和赵日天对视一眼，三人借着礁石的掩护，沿着北坡的碎石带下移。孙满仓确实熟悉这条路，他在前面带路，步子极稳，每一个落脚点都精准踩在干硬的土坎上，避开湿滑的青苔和碎石。大约十分钟后，一条干涸的引水渠出现在面前。

渠底积着厚厚一层落叶，踩上去“嘎吱”作响。渠壁是水泥抹的，但年代太久，很多地方裂开，裂缝里长出一簇簇蕨类植物。他们沿着渠底走了约莫两三百米，渠壁突然出现一个岔口，往山体方向凹进去，露出一扇锈蚀的铁门。门上没有锁，但用一种林一凡从没见过的绞轮装置拧死——绞轮上铸着三棱、四棱、五棱三把锁孔。

“三棱锁。”林一凡想起隧道里那声被切断的巨响，“有人比我们先到，把外面的锁切了。”

赵日天凑近看了看绞轮：“切口新鲜，不超过两天。但切锁的人很小心，只断了外层的三棱锁，没有动四棱和五棱。”

“多棱锁是联动机关，切错顺序会触发自毁。”孙满仓低声说，“沈临渊教过我，三层锁，是三道门。第一道拦普通的路人，第二道拦贪心的本事人，第三道……”他没有说完。

林一凡蹲下，绞轮下方不起眼的焊缝里卡着一片灰布纤维，和隧道里那个灰衣人身上的颜色一模一样。灰衣人之前不是来送棺材——他是来确认第三层锁没被人动过。

他伸手握住绞轮，三棱锁的锁芯被切断了，但四棱锁完好的部分纹丝不动，没有钥匙，不可能打开。系统面板无声地在眼前弹开：

【摸鱼商城可兑换“万能开锁术（中级）”】
【消耗：650 咸鱼值。兑换？】

650。他攒了半个月的咸鱼值，够换一个“编程大师”技能，够他少写三天的代码。他正要确认兑换，目光突然落在绞轮侧面一块不起眼的金属铭牌上——铭牌被锈蚀得几乎看不清，但右下角隐约刻着一个数字：

27。

又是 27。陶土徽章上的“第九组27号”，孙满仓红绳上的铜纽扣，绞轮铭牌上的“27”。三件东西，三个时间点，同一个数字。

他没有急着兑换技能，反而伸手摸了摸四棱锁的锁孔边缘，摸到一层极薄的油脂。有人定期来保养这把锁，最近一次不超过三天。

“门后面有东西有人不希望我们看到。”林一凡站起来，退后半步，“但有人三个月来上一次油，保证这门随时能打开。”

他低头，绞轮下方的泥土里有半枚脚印——鞋底花纹很密，是手工布鞋的底纹。旧布鞋的主人。

“赵日天，”他忽然说，“你之前说你‘死过一次’，那次的记忆里有没有一双布鞋？”

赵日天的脸色变了。他嘴唇翕动了两次，才喑哑地挤出一句话：“……我醒来的时候，身边躺着一双布鞋，洗得干干净净，摆在我枕边。鞋底朝我，朝下——就像在说‘走，往下走’。”

风从引水渠的尽头灌进来，阴冷，带一股潮湿的铁锈味。林一凡低头看着绞轮上那两个完好的锁孔，忽然笑了。

“有人让我们往上，有人让我们往下。孙师傅当年的轨道是给死人走的，水渠是给自家人走的。那现在——”

他伸手，按在绞轮的第二层锁上。

“这扇门，是给谁走的？”

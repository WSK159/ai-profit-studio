# 第359章 春来江水

铜纽扣贴上暗锁牙口的一瞬，林一凡只觉得指尖一麻，像是有什么东西顺着那枚金属纽扣爬进了手掌，然后“咔”一声轻响，五棱锁芯向内旋了半格。

他停住了。

不是他不想动了，而是他忽然分辨出那声“咔”不对——上一世他在修老式保险柜时听过无数种锁芯回弹的声音，真正的暗锁打开时，回弹声应当是沉闷的、单向的，这声“咔”却带着一丝极细的回旋音，像是某个齿轮空转了半圈，在等下一个力量进来。

他压低声音：“这锁是双簧扣，只有一半能转。另一半在别的地方。”

神秘人眼里的光顿时一敛，他伸手按住铁门旁那块青灰色的石砖，用力朝内一推——石砖纹丝不动，可砖缝里却传来断断续续的“嗒、嗒、嗒”声，像有人在另一头敲摩尔斯电码。

林一凡下意识数了一下：嗒、嗒嗒嗒、嗒、嗒嗒——是“1147”的变形。他心头一凛，手机里那个未知号码“1147”，与这扇门用的是同一套信号规则。发短信的人，此刻就在门的另一头。

他还没想清楚这意味着什么，赵日天却忽然低声说了一句：“四格牙口，第三格是朝下的。你爹死在‘将来’那一格上。”他声音里没有平日的桀骜，反而透出一股极淡的、只有听过的“死过一次”的人才说得出的冷意，“我那次死，就是被人反拧了‘将来’那一格，锁死了退路。”

林一凡没有犹豫。他将铜纽扣从“过去”那格抽出，朝“将来”的位置轻轻送了进去。锁芯极顺地吞下了扣子，内里传出一声长长的、金属回气般的叹息，随即是一连串密集的“哒哒哒哒”，像一台老式齿轮机突然开始自转。

铁门从中央裂开一道发丝般的细缝，涌出来的不是风，是一股干透的、混着机油与旧纸尘的气味。门缝后隐约露出一台绞轮的轮廓——灰绿色铁壳，肩部漆着一枚白圈，圈内是编号“27”，与林一凡在地下防空洞见过的父亲遗物完全一致。

但绞轮是倒着安装的。齿轮朝上，摇柄朝下，这种安装方式在军工厂里被称为“反向吊装”，通常只用于某种必须倒转运行的设备——比如抽水机。一个人如果站在绞轮前面，看到的是齿轮倒转，那就意味着水流方向是逆的。

水渠，是倒着修的。

林一凡回头看了孙满仓一眼。孙满仓也看懂了他眼神里的意思，脸色骤然变了：“水渠倒修……那不是引水下山，是从山下往上引水。沈临渊当年说‘水渠是给自家人走的’——他说的不是走人，是走水。”

神秘人已跨了一步，半只脚探进门缝，却在此时猛地顿住。那根从通道尽头传来的金属与岩石刮擦声，停了。紧接着，是极轻的脚步声——不是一个人，至少两个人，正从通道深处朝这边走来。

赵日天将手电压灭：“他们认得路，不然不会走得这么稳。再待下去，我们会被堵死在门口。”

神秘人回头看了林一凡一眼，语气忽然变得极平：“进不进，你一句话。进了这扇门，就没有退路；不进——你爹那些东西，就让别人来看了。”

林一凡的目光扫过铁门上方那行字——“你来了，这一道，是你爹留下的”，又扫过第二行被泥土填平的字——“来都来了，锁眼钥匙，用你娘那枚”。母亲那枚钥匙是挂坠，他至今没有找到。但此刻他忽然明白了那句话的另一层意思：锁眼钥匙未必只有一枚能开，门内的暗锁，可能还有第二个锁眼。

他收回铜纽扣，转过半个身子，将铁门推开一条可容一人侧身通过的缝，率先迈了进去。

绞轮背后有一块大约三米见方的空间，地面铺着青石板，板缝里嵌着干了不知多少年的青苔。正对面墙壁上嵌着一块铁皮，像是老式公告栏，上面用钉子挂着一张泛黄的图纸，纸角的编号是“37-27-01”。

三十七号项目，27号人员，01号图纸。

林一凡刚要伸手去揭那张图纸，身后忽然传来一声极轻的、几乎贴着耳根的叹息：

“春来江水绿如蓝。”

他猛地回头。神秘人站在门缝边，没有进来，目光却直直地看着他，一字一字地说：“你娘的锁眼，就是这面墙。那枚挂坠不在你手里——在你爹的棺材底。你方才拧动‘将来’那格时，已经把水渠反引的闸门打开了。三天之内，江水会灌到云顶山北麓第三梯下面这条通道。到时候，这扇门会被水封住，谁都进不来。”

林一凡的手停在图纸边缘：“那你——你是来带我出去的？”

神秘人没有回答。他只是侧过身，让出了身后的通道，露出通道尽头一个极暗的影子——那人背光站着，看不清面孔，但脚上穿的，是一双与他同款的手工布鞋。

赵日天盯着那个影子，声音低沉：“不是两个。是一个。”

他话音刚落，那个影子缓缓举起右手，手里握着一枚黄铜色的挂坠，挂坠在昏暗中轻轻一晃，发出一声极清脆的银音，像极了林一凡母亲生前常拨弄的那只怀表。

林一凡整个人僵在原地。

那枚挂坠的链子尾端，系着一根红绳，红绳上拴着一个小小的、手工缝制的布袋——布袋的料子，是他母亲最喜欢的月白色真丝。

他忽然记起了母亲临终前说的最后一句，没有说完的话：“你爹……他留给你的那把钥匙，在我这里……但钥匙，不是锁……”

后面那半句，被门外的脚步声彻底打断。

那个背光的身影开口了，声音沙哑，却带着一丝令人脊背发凉的温和：“小凡，过来。你娘让我带你去见一个人。”

林一凡没有动。

他低头看了一眼手里的铜纽扣，纽扣边缘那行“春来江水”四个字，在昏暗中泛着幽幽的光。他忽然想通了——锁眼钥匙未必只有一枚能开，门内的暗锁，可能还有第二个锁眼。

而他娘留下的那枚挂坠，从来都不是钥匙。

是一把指向别的路的路标。

铁门外，那两道新的脚步声已经近到可以听见呼吸声了。孙满仓却在这时低声说了一句：“小凡，你听——他们停住了。”

通道里果然安静下来。那两个人停在了铁门外的暗锁前，仿佛在等谁先开口。

背光的身影又轻声说了一句：“小凡，别让他们先动。”

林一凡深吸一口气，攥紧铜纽扣，跨过门缝，朝那个影子走去。身后，铁门在沉默中缓缓合拢。而他远没有注意到，图纸卷筒的背面，用铅笔钉着一道极细的草痕，在昏光中拼成一行字：“门后有答案，也有死路。”

那行字的字迹，与他父亲遗书上的笔迹，一模一样。

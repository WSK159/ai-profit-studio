# 第166章 鱼饵

凌晨四点，季敏的临时据点里只剩键盘敲击声和泡面汤的余温。

林一凡把U盘里的日志拆了三遍，终于在一个被加密的zip包里找到了那截最关键的后门线路代码——不出所料，入口就挂在星辰科技内部的“考勤系统”上。每个员工的刷卡记录都会被代码扫描一遍，凡是“摸鱼时长异常”的，系统会自动标记并上传一份实时位置报告。

“所以他就是用这个把我的位置精确到楼层。”林一凡靠在椅背上，盯着屏幕上那行血红的注释，“我摸鱼雷达每一次启动，他就多一条我的位置记录。”

季敏凑过来看了一眼：“但你雷达用的是系统给的数据链路，理论上是独立的。除非……”

“除非钱总那边有一个真正能‘看到’系统底层信号的设备。”老王接过话，把烟掐灭在墙角，“孙老说了，我的接入口是系统初始架构的一部分，连接到的是一条独立于网络物理层的定向线路——如果钱总能反向监听这个线路，他就相当于拿到了系统的后台监视权限。”

沉默了几秒。

林一凡忽然想起什么：“等等。如果他能后台监控，那我之前几次用雷达定位办公室的‘假卷王’，他怎么没戳穿我？”

季敏盯着那段日志的更新时间，手指点了点屏幕：“因为他这三个月里，有两次权限校验是失败的。一次在三月九日，一次在四月二十一号。那两天正好是你雷达使用频率最高的时候。”

“你的雷达信号，干涉了他的后门访问。”季敏抬头，目光灼灼，“他第三次校验就是明天——如果他这次失败了，他的系统就得强制下线。”

林一凡慢慢坐直了身体。这个角度对上了。

钱总不是不想收拾他，是怕他。怕他手里的“摸鱼雷达”继续干扰权限校验，所以他发来那条消息，其实不是挑衅，是鱼饵。

“他想让我明天去顶层，主动关掉雷达，好让他完成校验。”林一凡手指无声地敲着桌面，“如果我去了，就等于把唯一能威胁他的信号源交出去。”

老王皱起眉：“那不去？”

“不去也一样。”季敏敲了一下键盘，屏幕上弹出一段波形图，“从这个日志看，他的权限校验不止需要他自己那套设备。还缺一个关键变量——校验节点的环境安静度。如果这段时间内系统区域内存在高强度的异常信号波动，校验会直接失败。换句话说，如果你明天全程开着雷达不关，他拿不到第三把钥匙，系统就永远无法完整回收。”

林一凡看着那波形图，忽然觉得胃有点凉：“但我如果不关门，你之前说的那些‘系统真相’——劳动神和资本神的赌局——是不是也没法解锁？”

季敏没接话，端起泡面喝了一口汤，睫毛垂着：“你想知道真相？”

“想。”

“那明天你得去。”季敏放下碗，指了指电脑屏幕上一个闪烁的红点，“因为唯一能绕过钱总校验的第三方接口，就安装在主楼顶层的服务器机柜里。你只有在那间房里才能打开它。但只要你踏进那层楼，雷达信号就会被物理屏蔽。”

老王张了张嘴：“那不就是……”

“是陷阱。”季敏平静地说，“他就是要你到这个陷阱里来。但你如果不来，就永远拿不到第三把钥匙。”

房间里安静得能听见灯管里电流的嗡鸣。

林一凡盯着屏幕上那扇亮着灯的窗口，很久，伸手摸了摸口袋里的金属块，冰凉的边缘像一把未开刃的刀。

“那就去。”他说，“他设了陷阱，我就当鱼饵，咬他一口。”

老王一脸“你又来这套”的表情：“你知道是陷阱还要往里跳？”

“跳进去，那不叫陷阱。”林一凡把金属块攥紧，站起来看着窗外，天边已经泛起一丝灰白，“叫摸鱼的最高境界——老板放饵，我把他的鱼竿都摸走。”

季敏关了屏幕，从桌边翻出一个黑色背包扔给他：“里面有一台旧手机，一层防扫描膜，还有一套主楼保安的备用工牌。你明天中午十二点前要先到主楼，提前摸清安保路线。”

林一凡接过背包，拉开拉链看了一眼，忽然仰头看着她：“钱总发的消息要我明天凌晨两点到。你让我中午就去？”

“他设的是午夜陷阱。”季敏嘴角勾了一下，“我们设的，是日光下的鱼网。”

窗外第一道阳光照进来，落在她脸上。林一凡看着那双眼睛，心里某个地方猛地跳了一下——上辈子他没跟这个女人近距离打过交道，但她今天说的每句话，都像是提前算好了三步。

他低下头拉开拉链，背包里面，静静躺着一把手掌心大小的信号干扰器，塑料壳上用黑笔写着一行字：

“给他意外惊喜。”

字迹歪歪扭扭——是老王的笔迹。

林一凡回头看了老王一眼，老王正低头点烟，嘴角挂着一点不自然的笑：“摸鱼嘛，总的有点装备。”

他又收回目光，把包拉上，看着窗外逐渐泛白的天际线。

明天中午。主楼。顶层的灯还亮着。

钱总在等他。而他也在等一个答案——一个关于这个系统来历、关于他自己命运的真正答案。

窗外，晨光彻底铺满老城区屋顶，麻雀从电线杆上惊起，落了一地灰。

林一凡深吸一口气，把金属块贴着胸口的口袋收好，转身走进洗手间。

冷水泼在脸上那一刻，他听见自己心跳咚咚地撞着肋骨。

明天凌晨两点，星辰科技主楼顶层——他要正面迎上这个局里最危险的那个人。

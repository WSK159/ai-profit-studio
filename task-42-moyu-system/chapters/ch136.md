# 第136章 暗处的第三只眼

整层B3陷入黑暗的瞬间，林一凡凭着记忆闪身躲到一根混凝土立柱后面。他屏住呼吸，耳膜捕捉着车库里的每一个声音——轮胎碾过地面的细响、远处管道里滴水的回音、以及某个方向传来的，若有若无的脚步声。

系统雷达在黑暗中依然运行，但画面出现了干扰。那些网格状的扫描区域像被什么力量扭曲了，在车库东南角形成一片盲区。林一凡第一次见到雷达被压制的情况。

“检测到‘精神干扰场’。”系统文字浮现，“当前区域存在高强度标记残留，正在强制覆盖目标的精神感知。建议立刻通过摸鱼空间进行隔离。”

林一凡没有犹豫，意识一沉，整个人进入摸鱼空间。外面看他是愣在原地发呆，但实际上，他的精神被一层淡蓝色的保护膜包裹，完全屏蔽了外界的精神扫描。

一个冰冷的声音在车库中响起，像金属刮过水泥地面：“看来是个老手。躲得够快的。”

脚步声停在了林一凡原本站立的那个位置，大约三步之外。林一凡通过摸鱼空间的“外部感知”功能，模糊地看到一个轮廓——穿着深灰色连帽衫，身形削瘦，头上戴着口罩，双手插在兜里，整个人几乎融入了黑暗。

“那张名片，”灰帽衫开口，语气平淡得像在聊天气，“不该在你手里。”

林一凡没有回应。

“钱国豪给你钓鱼呢。”灰帽衫似乎笑了一声，“他是建眼计划的弃子，你拿着他的饵，就等于是钩子上那条鱼。”

雷达的盲区正在逐渐缩小。林一凡注意到，灰帽衫的干扰场会因为说话而衰减。他默默在系统面板中检索，兑换了一个“反标记脉冲”技能，消耗了整整2000咸鱼值。这是他从摸鱼商城一开就盯着但一直舍不得兑换的压箱底技能。

“反正你也不打算出来，那我就告诉钱国豪——鱼饵没了。”灰帽衫转身，脚步声远去。

就在灰帽衫即将彻底走出B3范围的前一秒，林一凡从摸鱼空间中跳了出来，口中一个字：“破。”

淡蓝色的脉冲以他为中心扩散开去，像一阵无声的风扫过车库。灰帽衫的脚步声骤然停顿。

干扰场碎了。

灰帽衫猛地转身，林一凡终于看清了他的眼睛——右眼瞳仁中央，隐约有一枚银灰色的钥匙形印记在缓缓旋转。

“你……”灰帽衫的嗓音里终于出现了一丝情绪波动。

“你也是‘钥匙孔’。”林一凡平静地开口，“所以你半夜来找我，不是要阻拦我，而是在确认我也是。”

灰帽衫沉默了三秒。黑暗里，他摘下了口罩，露出一张林一凡从未见过却莫名熟悉的脸——和卷王赵日天的五官有七分相似，但更苍老，轮廓更深。

“我叫赵夜白。”他说，“赵日天是我弟弟。而你手上那张名片，是我三年前被开除那天，亲手递给钱国豪的。”

雷达重新恢复了正常扫描。赵夜白的头顶，一行红色标签浮现出来：“建眼计划·核心执行者·标记源。”

“明天下华夏金融中心，”赵夜白的声音飘过来，“你会见到真正的坐标。那里面躺着的，不是碎片。”

他顿了顿：“是你上一世的尸体。”

林一凡的心脏猛地漏了一拍。系统面板上的咸鱼值余额，不知何时，变成了一个血色数字“0”。

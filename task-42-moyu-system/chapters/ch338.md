# 第338章 不速之客

林一凡拉开车门，黑色商务车内部比外面看起来宽敞得多。孙满仓坐在驾驶座上，双手搭着方向盘，目光透过前挡风玻璃，正盯着那棵老槐树。

“你知道我不能在外面待太久。”林一凡说。

孙满仓没接话，等他坐稳，一脚油门，车驶入早高峰的车流。林一凡注意到后视镜里，孙满仓的视线频频扫过两侧。他的手指在方向盘上敲了两下，然后把遮阳板翻下来。半张照片从遮阳板里滑出来。

林一凡伸手接住。照片边缘发黄，是五六年前的胶片质感。画面中央是一座藏在雾里的山门，门楣上刻着三个字。他不认识那字，却熟悉山门右侧那道歪斜的裂缝，因为沈望给他看过同一处山门的照片，只是角度不同。

“这是云顶山的后山。”孙满仓说，“从这条路上山，不走正门。”

林一凡把照片翻过来，背面写着一串日期，和他重生回来的那天是同一天。

“那天你爸不是进山去找钥匙的。”孙满仓的声音压低了一些，“他是去送东西。去之前他来找过我——凌晨三点，在城东的汽修厂。”

“你知道我父亲的工号。”

“1147。”孙满仓说，“他工牌上那串数字，我比警察记得清楚。因为那天早上他在我那儿把工牌摘下来，说以后用不上了。”

车在十字路口停下，孙满仓转头看他。那是林一凡第一次近距离看到那双眼睛——眼白里布满红血丝，瞳孔却极亮，像熬了三天的人刚灌下去两杯黑咖啡。

“他说要去云顶山送一个东西。那个东西，会决定你们林家往后的命。”孙满仓说，“这是他原话。他当时把陶土徽章交给你妈保管，说你拿到了就认。”

林一凡攥紧手里的陶土徽章。

“他没让你转交给我。”

“他让所有人别碰。说那东西会招人。”孙满仓笑了笑，露出一颗镍钢假牙，“但他没想到你先去找了沈望。沈望那小子嘴巴快，你大概已经知道你爸当时进山不只是为了找人。”

“是为了找钥匙。”

“对——也不对。”

孙满仓打了一把方向盘，车拐进一条小巷，停在巷尾一个报刊亭后面。他熄了火，从座位底下抽出个牛皮纸袋。

“你爸当年进山，带回来两样东西。一样是那把黄铜钥匙，另一样是这。”他撕开纸袋，倒出一张叠得四四方方的旧地图，展开之后，是一幅手工绘制的云顶山隧道结构图，密布红蓝两色标记，图上很多地方用铅笔圈着，边角写满密密麻麻的小字。

林一凡的目光落在图中央一行极小的字上——那是他父亲的笔迹，他认得，因为沈望给他看过父亲信件上的字：一模一样的撇捺。

那行字写着：“第三扇门不在山上，在山下。找到‘零’，就能找到她。”

“你爸说这话是什么意思？”林一凡问。

孙满仓看着那行字，沉默了很久。他攥着地图的手指节微微发白，喉结滚动了两下，才开口：“你爸当年从山里头带出来一样东西，他一直没跟任何人说。除了我——因为那天接应他下山的人，是我。”

他顿了顿，目光移开，落到窗外。

“你爸下山的时候，带了一个女人。”

林一凡气息陡然一凝。

“什么女人？”

“他叫她‘小竹’。”孙满仓说，“后来我再没见过她。但第二天，你爸把东西埋了，把人送走了。送去了哪里，他没说。只留了一句话——”

他转过头，声音沉得像从喉咙深处挤出来的：“‘等她回来拿钥匙，就什么都瞒不住了。’”

林一凡脑海中“啪”地一声，像有什么东西接上了。陶土徽章在他掌心微微发烫，系统的提示音在脑中炸响——

“检测到关键剧情线索‘小竹’——已解锁隐藏人物档案。人物关联度：极高。‘归还自由’任务链第三阶段前置条件满足度提升至78%。”

他刚要追问，车窗外忽然传来一阵沉闷的引擎声。一辆深灰色面包车缓缓从巷口滑过，车窗贴着深色膜，看不清里面坐了几个人。

系统警报随即亮起——

“注意：监测到高强度系统波动，来源距离宿主不超过30米。提醒：该波动特征与‘卷王系统’相似度达92%。”

林一凡瞳孔一缩，看向孙满仓：“你认识赵日天？”

孙满仓的回答出人意料地平静：“认识。他爹是我师弟。”他笑了下，“但赵日天那小子，三年前就死了——死过一次的人，怎么会突然出现在你的公司里？”

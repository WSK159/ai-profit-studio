# 第161章 双锁之谜

地下二层机房的冷气从通风口灌下来，林一凡后背的汗却一层层往外冒。季敏手里那个U盘，反着惨白的荧光灯，像一把悬在头顶的刀。

“你说钥匙有两把？”老王的声音沙哑，目光死死锁在季敏脸上。

季敏没回答他，反而转向赵日天：“你的卷王系统，刚才是不是弹出了'双锁协议'的提示？”

赵日天脸色铁青，半晌才点了一下头：“……三条红色警告，让我立即退出识别范围。”

“那就对了。”季敏嘴角勾起一抹说不清道不明的弧度，“这个U盘是我亲手做的不假，但里面的数据被设了双重加密——第一把钥匙在我这里，第二把钥匙在……”她顿了顿，看向老王，“你那位'老朋友'手里。”

老王的手不受控制地抖了一下。

林一凡心里咯噔一声。老王的系统来源他一直没来得及深究——只知道这个看起来老实巴交的组长已经藏了七年，连钱总的AI考核都没能把他揪出来。现在季敏这话锋，分明是认识老王背后的那个人。

“你什么意思？”老王的声音压得很低，带着一种林一凡从没听过的警惕。

“字面意思。”季敏往前走了两步，高跟鞋在水泥地上叩出清脆的回响，“你们三个现在站在一条船上，但这条船下面埋了雷。U盘里藏着我当年'假死'的全部记录，还有……”她扫了一眼四周，压低了声音，“钱总跟资本神签的那份协议。”

赵日天猛地抬头：“资本神？”

“你以为是普通的职场压榨？”季敏嗤笑一声，“星辰科技这套AI考核系统，你以为真是普通程序员写出来的？你觉得你身上那套卷王系统，真是什么科技公司的黑科技？”

机房里的空气仿佛凝固了几秒。

林一凡的脑海里，系统的提示音突兀地响了起来：【检测到关键剧情节点。提示：摸鱼商城第 47 层已解锁新商品——'谎言甄别·一次性'，兑换需 320 咸鱼值。是否兑换？】

三百二十。他现在正好剩下三百三十五。

林一凡没有立刻兑换，而是盯着季敏的眼睛——那双眼睛里分明藏着话没说完的尾音。他想了想，换了种问法：“你说第二把钥匙在老王的'老朋友'手里，那你——知道那人现在在哪么？”

季敏的目光在他脸上停了一瞬，笑了：“你以为我是来威胁你们的？恰恰相反——我是来送你们一把钥匙的。”

她突然从大衣内袋里掏出一张折叠的纸，甩给老王。老王下意识接住，却没打开，只是怔怔地看季敏。

“第二把钥匙的信息在这张纸上。”季敏退后半步，“但我有一个条件——今晚，你们三个，谁也别把这件事告诉钱总。尤其是你，赵日天，你那套'忠诚'戏码演给谁看我不管，但在这件事上你要是敢走漏半个字——”

季敏没说完，但她的眼神已经替她把后半句说了。赵日天脸色变了几变，最终咬着牙别过头去。

林一凡攥着兜里的手机——钱总那条匿名短信还亮着屏幕：“勿信老王，U盘内容可能有害。”

这条短信和季敏的今晚这席话，几乎是正对面的两条路线。

而他站在这两条路的交叉口。狂风从通道尽头的应急门缝里灌进来，吹得那张折纸的边角簌簌作响。老王终于低头，打开了那张纸。

他的瞳孔猛地一缩。

林一凡还没来得及看清纸上的内容，系统的警报声突然在脑海中炸响：【警告！检测到高能量系统波动，来源——地下一层！距离：17 米！正在接近！】

地下二层机房的灯，啪地全灭了。

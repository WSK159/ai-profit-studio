# 第267章 楼梯间的追与逃

楼道里的声控灯一盏接一盏地亮起，又在他身后一盏接一盏地熄灭。

林一凡的脚步声在封闭的楼梯间回荡，急促而沉闷。他左手攥着那把010号钥匙，金属边缘硌得掌心发疼——钥匙上“赵小九”三个字的刻痕像三道细小的伤口，反复提醒他刚才听到的一切。

2019年7月2日凌晨3点17分，四平路车祸。

赵小九替他死了。

这个念头像一根钉子楔进颅骨，怎么拔都拔不出来。他重生回2026年入职第一天，以为自己是死于996猝死的倒霉程序员，带着摸鱼系统重来一次。但现在赵恒告诉他的故事完全不同——他来自更远的未来，携带“织网”完整架构，删除了自己的记忆，以“已死之人”的身份绑定系统。

而赵小九的死，就是为了让他成为这个“已死之人”。

荒唐。疯狂。但系统没有否认。

脑海中，摸鱼系统的面板微微闪烁，像是有人在外面敲一扇窗户。林一凡调出系统菜单——任务列表里，“命运归还”四个字静静地躺在最底部，状态从【待触发】变成了【进行中】。

他来不及多想，楼梯拐角处忽然传来金属碰撞声。

林一凡脚步一滞，侧身贴住墙面。楼梯间灯光昏暗，下方两层楼的转角处隐约闪过几道影子，至少有五六个人，脚步声整齐划一——是钱总的人，从下往上搜。

他朝上方看了一眼，决定加速。但他刚刚往上冲了两步，楼上也传来急促的脚步声。

被包夹了。

“冷静。”林一凡低声对自己说，同时飞快扫视周围。这栋负三层的老建筑结构复杂，楼梯间在逃生通道之外，每一层还有一个检修井的入口。他在第三层的检修井前停住脚，铁门上挂着生锈的锁链，但锁扣已经松动。

系统提示适时弹出来：【检测到宿主处于被包围状态，推荐使用“反卷护盾·应急模式”——消耗300咸鱼值，屏蔽周围三米内的电子侦测与人体热成像信号。】

“兑换。”林一凡没有犹豫。

一股凉意从头皮蔓延到脚底，像被人泼了一盆冰水。他知道，在钱总那些人眼中，他现在应该消失了——反卷护盾能让他们“看不见”他，但前提是他不主动暴露出声响。

他抓住锈锁链猛力一拽，锁扣应声脱落。铁门发出刺耳的嘎吱声，林一凡心里一沉，但下方的脚步声没有因此改变方向——护盾起效了，声音也没有传出去。

他钻入检修井内的狭窄空间。黑暗包裹下来，头顶是布满蛛网的管道层，宽度只容一人蹲行。他掏出手机调到手电筒模式，屏住呼吸，一盏微弱的光照亮前方。

身后的铁门被合上，他的世界里只剩下自己的心跳声和远处传来的脚步声。

“这层清了吗？”一个粗嗓门说，声音从检修井外传进来。

“没有，负三层密室被打开了，陈重阳跑了，就剩这小子。监控到这里他就没影了。”

“他不可能飞走，翻！”

外面一片翻箱倒柜的动静，持续了大约五六分钟，才渐渐远去。

林一凡屏住呼吸，直到最后一点脚步声消失，才缓缓呼出一口浊气。他抹了一把额头上的冷汗，手机灯光下，手掌上的010号钥匙反射出暗金色的光。

“命运归还……”他低声念出任务名。

系统的提示音在脑海中响起：【任务背景更新完毕，是否立即阅读？】

他还没来得及回答，手机屏幕上方忽然弹出一条消息。发信人是一个陌生号码，只有一句话：

“下次再见面，我会先拿到那把钥匙。——赵恒”

林一凡盯着“赵恒”二字，心里咯噔一声。他刚才分明听见赵恒与王姐在铁门外对话，那个刀疤男人已经和他分开——但这条消息显然是在他离开密室后才发出来的。

赵恒知道他还活着，知道他有钥匙，而且知道他正被困在楼里。

这算什么？哥哥替妹妹讨债？

他收了手机，决定先挣脱眼前的困局。检修井向前延伸，尽头又分出一条岔道，一侧贴着管道继续向上，另一侧则微微透出一丝亮光。林一凡犹豫片刻，朝亮光那一侧爬去。

爬了大约二十米，前方出现一扇铁栅栏门，挂着“信息机房·禁止入内”的牌子。门缝里透出的蓝光正是服务器的指示灯。

林一凡正要拧开门闩，忽然听到机房内传来一个熟悉的声音——“东西呢？我给了你们三天时间，东西还没找到？”是钱总的声音，带着低沉的怒气。

林一凡的手停在半空。

他无声地贴近铁栅栏，透过门缝望去——机房内，钱总站在一排机柜前，背对门口，面前半跪着一个满脸是血的年轻人。那人抬起头来。

林一凡瞳孔骤缩。

——那是王姐手下的一个技术员，之前在负三层的监控室里见过一面。

“说，你们老板把‘织网’源码备份藏哪了？还有那个姓林的小子，他拿到010号钥匙之后会去哪儿？你们以为我不认识赵恒？他是赵小九她哥，十年前就失踪了，你以为我不知道他背后站的是谁？”

钱总蹲下身，声音阴冷得让整机房的空调都像是降了几度。

“我再问你一次——你老板，王姐，到底是什么人？”

林一凡的后背贴着冰凉的门框，喉结缓缓滑动。

——钱总也知道赵小九。

——钱总知道赵恒。

——而钱总把王姐称作“你老板”。

那么，王姐到底是什么人？

那个技术员咳出一口血，咧嘴笑了笑，声音嘶哑而清晰：“钱老板……你查了这么多年，还查不明白吗？王姐她……就是当年那个项目的……”话没说完，一阵猛烈的剧痛让他弯下了腰。

林一凡盯着那一幕，握紧钥匙。

他知道，他听到了不该听的东西，而这条线索一旦被钱总发现他从哪儿偷听来——他绝对活不到明天。

铁门内侧的锁扣挂在第三个环上，轻轻一转，就可以拧开。

但现在不是拧开的时候。

他缓缓后退，退回检修井的黑暗中。脑海中，系统新提示亮起：

【检测到宿主触发任务分支——“另一个死者”。是否接受？】

【奖励：未知。风险：未知。】

林一凡深吸一口气，做出了选择。

# 第160章 三人的影子

晚上九点，地下二层。

机房的冷气从门缝里渗出来，混着金属和机油的味道。天花板上的应急灯发出淡绿色的光，把三个人的影子拉得像三根孤零零的柱子。

老王是最后一个到的。他穿着一件洗得发白的旧夹克，腋下夹着一个牛皮纸袋，神色比白天更疲惫。他看到林一凡和赵日天各站一角，像两只对峙的猫，咧嘴笑了笑：“都来了？”

“老王，你老实说，”林一凡开门见山，“U盘到底是谁做的？”

老王的笑僵了一瞬。他慢慢走到机房门口，手指摩挲着生锈的门边：“季敏临走前存的。她让我保管，说只有被逼到绝路的时候才用得上。”

“她不是假死吗？”赵日天冷笑，“假死前还有心思留这种东西？”

“因为她死过一次，知道钱总会对她干什么。”老王的声音压得很低，“她当年发现钱总用AI考核的事，不止在抓摸鱼——那些数据，钱总用来评估谁的岗位可以被替代，然后批量裁员，再从裁员赔偿里抽成。”

林一凡心里一沉。这比单纯搞“反卷”严重多了。季敏发现的不只是制度缺陷，是钱总的利益链。

“所以数据池里存的是什么？”他问。

“证据。”老王指了指U盘，“但打开它需要三个系统的能量共振——我的摸鱼雷达，你的卷王系统，再加上老王的……”

他顿住，看了看老王。

老王却从口袋里掏出一个老旧的工牌，上面贴着一张泛黄的证件照，照片里的年轻人穿着十年前的星辰科技工服，胸口戴着“王建国”的工牌——和手写体的“老王”一模一样。

工牌的背面贴着一个二维码。老王把它放在U盘旁边，二维码忽然亮起微弱的光。

“这是我的系统，代号‘反卷护盾’。”老王说，“藏了七年，第一次拿出来用。”

林一凡倒吸一口气。他甚至忘了老王也绑定了系统——他一直以为老王只是个普通的老好人同事。三个人同时把系统激活，U盘和工牌同时亮起，地表浮现出一圈淡蓝色的光圈，缓缓扩散成直径两米的圆形法阵。

嗡——

机房门突然被人从里面推开。

灯光大亮。宋顾问——不，季敏——站在门口，手里拿着一台平板，屏幕上跳动着AI考核系统的实时监控画面。她看着三个人，露出一个熟悉的笑容。

“三位，”她说，“数据池，不急着开。先聊聊你们在我考核系统里留下的——三分钟后，所有摸鱼数据，会直接送给钱总。”

林一凡的汗一下子下来了。他看了一眼老王，老王的脸色白得像是随时会倒下去。赵日天则攥紧了拳头，眼神冷得像刀。

“你想怎么样？”林一凡问。

季敏歪了歪头，指尖划过平板屏幕：“我要的不是钱总。是老王的那个数据池——里面存的，不只是他当年留下的证据。”

她停了一下。

“还有我真正的死亡记录。”

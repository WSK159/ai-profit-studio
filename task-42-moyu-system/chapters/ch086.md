# 第86章 江云

江云看起来和江雪有六分像。尤其是那双眼睛，一样深、一样沉，里面好像藏着很多没说出口的东西。她进门之后先反手把门锁扣上，又用一根数据线在锁孔里绞了两圈，这才往前走了一步到工控机前。

“你动作比你姐夸张多了。”周莉靠在墙上，语气里带了一丁点笑意，“我们正说要去找那个赌局，你就自己撞上来了。”

“撞？”江云转过身来，嘴角微微下撇，“那个协议启动之后直接穿透了三层跳板打到我的备用服务器上，后台报错都报到我邮箱里了，我不来的话，24小时内报警系统自动响应，你们现在已经被带走了。”

林一凡把烟塞回口袋：“那你来是帮我们关的，还是帮我们开门的？”

江云看着他，忽然笑了一下，笑意很浅，像是看透了什么：“你是那根‘鱼刺’对不对？系统里那个……特别能摸的。”

“……能被你这么说，我感觉还挺荣幸。”

“别贫了。”周莉打断道，“江云，你姐到底留了什么话给你？”

江云沉默了几秒，从风衣内袋里取出一只折叠的塑料盒，打开，里面是一张芯片卡，和密钥芯片看起来完全一样，只是上面的纹理是一根树根的形状。

“第三段镜像的镜像。”她把芯片放到桌面上，“真·备份。”

林一凡眉心一跳：“备份中的备份？”

“江雪的风格。”周莉低声道，“她把假备份留给别人，真备份留给自己人。”

江云没接话，转身把芯片插进工控机的读卡器，屏幕上瞬间弹出大量的文件目录——财务报表、邮件往来、内部聊天记录、AI考核系统的训练日志、云麓心理的客户名单，以及一份标着红字“SPIRIT_SHACKLE（精神镣铐）”的方案文档。

“根目录里的东西。”江云说，“我姐去年年底拿到的。”

林一凡盯着屏幕上那份“精神镣铐”文件名，脑子里闪过一个念头。他在前世的记忆中，隐约见过这个名字——在“星辰科技”核心业务周报的内部讨论群里，有一份被秒撤回的文件，标题是“SHACKLE-4季度试点报告”。当时他以为是哪个外包团队的内部代号，谁也没多想。

“精神镣铐……”他喃喃道，“这玩意儿是做什么的？”

江云点开方案文档，第一页就写着一行加粗的文字：

> 通过情绪数据建模，对企业员工进行潜意识级行为引导，在强制评估周期内提高产出效率，并降低抗压性反抗。

“换句话说，”江云看了看林一凡，“他们拿云麓的心理数据喂AI，训练出一套‘无声的绩效考核系统’，它不看你写了多少代码、开了多少会，它看你的心流状态、情绪波动、压力阈值，然后在深夜系统自动给你推送高负荷任务，把你摁在一个刚好能撑住但随时会崩的边缘。”

“你姐查到了这条链路的底层，所以把她灭口了？”周莉的声音平得不像话，但指尖已经在微微发颤。

江云没有正面回答，她只是定定地看着林一凡：“我姐死前给我打过最后一个电话。她跟我说的是——如果有一天有人启动了‘根目录访问协议’，不管是谁，告诉他，别急着曝光。真相只是第一步。她要的是系统的另一层。”

林一凡一瞬不瞬地看着她：“哪一层？”

“那一层在星辰科技17楼机房04号柜的硬盘里。是‘精神镣铐’的代执行程序。它运行了半年，喂了至少四百名员工的心理数据。”江云停了一下，声音低了一度，像是一根弦绷到头了，“它不只是在控制现在的人，它已经开始训练未来的系统。”

厂房里安静了一瞬。林一凡的余光落在了系统面板上——


[根目录访问协议] 运行中
[检测目标：星辰科技 · 精神镣铐代执行程序]
[距离反制触发：18小时22分]
[警告：检测到同源系统信号——另一侧卷王系统宿主正在向机房移动]

“你哥。”林一凡忽然看向周莉。

周莉猛地抬头：“什么意思？周天不是还在医院？”

“他不是去医院的。”江云的语气冷下来，“他是去机房的。”

林一凡的目光从屏幕移到窗外，夜色压下来，远处的城市灯光模糊成一片灰黄。角落里那道被绞紧的门锁，突然传来一声轻响——

“咔嗒。”

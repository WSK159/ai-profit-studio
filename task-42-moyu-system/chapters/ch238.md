# 第238章 下行64米

他们走了整整十五分钟才到通道底部。

负六层的地形比终端竖井更复杂。能容纳两个成年人的管廊向下延伸，墙壁不是水泥，而是某种深灰色的金属面板，表面结了细密的水珠，电筒照过去，每一滴水珠都呈现出一种诡异的、带着轻微涟漪的金色——像是有什么光从墙壁另一侧透过来。

“这里的温度比上面低了至少十度。”老王哈出一口白气。

赵日天走在最前面，用那根铜线顶着一侧墙壁慢慢滑行，似乎在检测什么。铜线偶尔会发出细碎的“沙”声，就像在磨一块石头。他走到第三根横梁的位置停下，收起铜线，侧身挤进一处只容单人通过的窄口。

“第三间。”

他跟林一凡对了一眼。林一凡从工牌背面摸出那张卡，银色平面在黑暗中泛着微光，走到门口，将卡片贴上去——

门没有开。

但门上的显示面板亮了。

4寸见方的小屏幕上浮现一段纯文字，不是普通的系统界面，而是手写的、歪歪扭扭的汉字。像是一个人用极不稳定的手指在触摸屏上写下然后刻进去了：

**“别进去。那是他的。”**

陈默认得这笔迹，她猛地向前一步，嘴唇发白：“这是我爸的字。”

林一凡盯着那行字，脑子飞速转着。

字面意思有两种解读：别进去，那是他的——的“他”是敌是友？如果陈建国写下这行字，是想提醒后来的人别碰某个属于敌对势力的东西，那这扇门里面的，是一块陷阱。如果“他”指的是自己——那这行字，是在警告门后的东西，它有了主人。

陈默伸手握住了门把手。

“等——”老王想拦。

陈默已经按下去了。

门没有锁芯，没有阻尼，像它一直在等这一刻似的，无声地滑开一条缝。

一股灰尘的气息涌出，里面混杂着某种纸浆和电路板烧焦的臭味。手电的光扫进去，照亮了大约五平米的舱室。四面墙壁上钉满了发黄的纸张，A4纸、横格纸、甚至是从笔记本上撕下来的边角料，层层叠叠，像一个疯子的记忆宫殿。

正中央是一张简陋的铁桌，桌面上没有任何灰尘——有人在这个密闭舱室里常驻过。

桌上摊着一本笔记本，翻到了最后一页。上面写了一行字，墨迹很新，像是今天就写下的：**“她长得真像她妈妈。”**

陈默的手抖了一下，抬起头，目光落在桌子右边角落的一枚钥匙上——那是一枚跟她父亲另一把钥匙相同材质的铜钥匙，只是这枚没有编号，钥匙齿形的末端被打磨成了一枚鸟的形状。

“这是我家的钥匙，”她颤声道，“但不是我能开的那把。”

赵日天站在门边安静地注视着她，良久开口道：“我在系统里查过，你爸当年不是第五层的组长。他是负层的守护员。他管着最底下那个东西。”

“哪个东西？”

赵日天没有回答，而是从口袋里掏出他另一只工牌——没有翻开，只是亮出背面的菱形印记。那个印记的中央，多出了一条比米粒还小的、几乎看不见的裂缝。裂缝里面透出一点淡蓝色的荧光。

他看了林一凡一眼。

“你知道那是什么吗？”

林一凡盯着那蓝色荧光，心跳怦然加速——那是铜线末端的蓝色，那是配电房里见过的、那根导线断裂后的颜色，也是他重生之夜那个烟头火星的颜色。

“你过来看。”赵日天走到铁桌旁边，指尖从桌沿底下扣出一块比指甲盖还小的黑色芯片，上面印着两个数字：

**A-000。**

林一凡的雷达没有响，但他知道，终于到了。

负六层的舱室是陈建国留下的。他找到的A-000芯片正是终端上出现的那枚金色标记的实物本体——而这枚芯片的底座，正好卡在赵日天工牌裂缝中央，严丝合缝，像原本就是从那里面被硬生生拆出来的。赵日天的工牌，可能就是钥匙的一部分。而那枚芯片，是它该装回去的“钥匙齿”。

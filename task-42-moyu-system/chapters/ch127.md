# 第127章 中转舱里的脚步声

脚步声从金属走廊尽头传来，带着某种节奏感，不是巡检机器的匀速，也不是人类随意的步伐。那声音听起来像是一个人提着沉重的东西在跑，每一步都踩得铁板嗡嗡作响。

林一凡脊背瞬间绷紧。他回头看了一眼老王和赵日天，两人的反应截然不同。老王下意识往阴影里缩了缩，赵日天则咬住后槽牙，拳头攥紧，脖子上的青筋都冒了出来。

“朝着我们来的。”赵日天压低嗓音，“三十二米，不，二十五米了。”

林一凡没有犹豫，他拉着老王闪进中转舱左侧的一条检修通道。这通道只有半人宽，头顶管道密布，即使蹲下来也只能勉强错身。赵日天跟进来之后，三个人紧贴着管壁，屏住呼吸。

脚步声在舱口停下。

一个声音响起，带着金属沙哑的质感：“林先生，我知道你在。浮空港的系统日志显示你刚完成身份核验，中枢舱的权限还没有激活，你跑不掉的。”

林一凡眯起眼。这个声音他听过——在电话会议里，在钱总的办公室里，在无数次加班的深夜中。

钱国豪的声音。

可钱国豪怎么会在这里？上一世，不对，重生之后的这个世界——钱总明明是坐在星辰科技顶楼办公室里的那个人，他怎么会出现在三百公里高的太空站里？

林一凡从管道缝隙里往外瞥了一眼。站在走廊中央的人穿着一件深灰色的太空制服，胸口没有公司徽标，手里握着一支手枪形状的东西。那人的脸确实是钱国豪的脸，但五官线条似乎比记忆中的更硬，更年轻，眼窝也比正常人类要深得多。

老王在他背后轻轻拽了一下他的衣袖，嘴唇几乎贴着他耳朵说：“他不对劲。我在这里待的那几周，见过一个穿一样制服的人，走路方式一模一样的。那个人，从来不需要呼吸。”

林一凡后背一凉。

不需要呼吸，这种人除了仿生体和母体操控的傀儡，只有一种可能性——钱国豪早就已经不是人。或者说，他从来都不是纯正的人。

“我们三个，他不可能同时抓住。”林一凡飞快地盘算，低声问赵日天，“你的卷王系统在这个距离上，能读取他的数据吗？”

赵日天闭眼不到两秒，脸色变得异常难看：“读取失败。他的信息被加密，加密方式和伪神之殿门禁的架构一模一样。他吃的是S级的资源，我们比不了。”

“也就是说伪神之殿钥匙就在他身上。”

“或者他就是钥匙本身。”

钱国豪的声音又响起，这次带着一丝笑意：“小林，你以前在公司里的表现，说实话我是满意的。你有一种特殊的天赋，能从所有不需要做的事里精准地抽出时间。这份天赋，在某个地方会被真正珍惜。你只要告诉我一件事，S级系统核心的激活程序，你有没有看到过？”

林一凡瞬间明白了。钱国豪等在这里，不是为了拦截他们逃离，而是为了找一个他觉得自己可能见过的东西。可他们刚才在伪神之殿里连核心的完整形态都没看到，只看到一块标注着容器归属的铭牌。

没等他说话，赵日天突然从通道里猛地蹿了出去。

这一下完全超出林一凡预料。赵日天直扑钱国豪，双拳砸向对方的头颅。钱国豪举枪，枪口亮起蓝光，但赵日天的速度比枪口抬升更快，一拳砸在他手肘上，枪脱了手，当啷一声撞在墙面上。

“趁现在！去伪神之殿——”赵日天吼道，第二拳已经跟上。

林一凡一把拽起老王就往出口跑。他知道这不是丢下赵日天，以他的速度留在这里反而是累赘。但他跑了三步，就听到身后传来一声沉闷的撞击声，随即是一声闷哼。他转头，看见赵日天被钱国豪单手扣住喉咙按在墙上，那人站在原地纹丝未动，脚下甚至没后退过半步。

“卷王系统的宿主，你的力量，我太了解了。”钱国豪的声音平静得像念条文，“因为开发卷王系统的人是我。”

赵日天的瞳孔猛缩。林一凡的脚也定在了原地。

卷王系统和摸鱼系统，很可能是同一个制造者。而那个制造者，此刻正用手掐着赵日天的脖子。

老王突然从他身边冲出，捡起地上那把枪，枪口对着钱国豪的后脑勺：“放他下来。”

他枪握得很稳，一点也不像之前那个只会打圆场的组长。林一凡脑子里猛地闪过之前那个问题——老王到底是什么时候开始，变得这么果断了？

钱国豪缓缓松手，赵日天落地咳嗽。他没有转身，只偏过半边脑袋：“老王，你终于拿自己当人了。”

这句话，比刚才任何一击都更让林一凡感到冷。

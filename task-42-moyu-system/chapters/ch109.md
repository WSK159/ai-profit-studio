# 第109章 亡灵之名

老王话音刚落，旧机房里的空气像凝固了一样。林一凡后背贴着冰冷的机柜，盯着老王的眼珠——这双跟他共事过三年的眼睛此刻发着淡淡的银光，像老式 CRT 屏幕的荧光粉。

“你说……门要三个人开？”赵日天跨前半步，把林一凡挡在身后，语气里按着刀锋般的警惕，“第三个人是亡灵。”

老王没点头也没摇头，只是抬起手中的银章母体仪器。那东西跟他在负三层找到的银章造型一模一样，但更大一圈，表面的纹路像活物一样缓缓蠕动。仪器中央嵌着一颗指甲盖大小的暗红色晶体，晶体里隐隐有脉搏般的跳动。

“母体接引我的时候，给我看了一幕。”老王的声音平稳，像在念一份技术文档，“负五层的门是三重锚点结构——活人锁、死人锁、因果锁。你们俩是活人锁和因果锁，还差一个死人锁。”

“谁是死人？”林一凡问，但心里已经浮出答案。

老王的目光落在他身上，银光闪了闪：“你自己，林一凡。”

赵日天猛地回头，眼中瞳孔骤缩。林一凡咽了口唾沫，指尖发凉。他记得死过一次——那根没点着的烟、骤停的心脏，他确确实实死在 2026 年的某个加班的深夜。系统带他重生，摸鱼系统就是他第二世的依附物。可他重生了，前世那具身体算什么？

已经死了。

“我的前世身体……”林一凡的声音有点干。

老王手中仪器震动，那颗暗红晶体投射出一道光幕，光幕上浮现一段画面：一个穿格子衫的男人倒在一间堆满泡面盒的工位上，胸口已经没有起伏。那男人跟他长得一模一样，甚至更憔悴、更瘦。那是他，前世的他，后脑勺还贴着一张星辰科技的老旧工牌。

“断根执行组没有处理你的尸体。”老王的声音里第一次有了一丝波动，“他们把你那副躯壳留在了负五层，当作锚点底座。你这一世修补了灵魂，但身体还挂在那边。”

赵日天低骂了一句：“操，原来‘断根’断的是根须……连尸体都不放过。”

林一凡没说话，他的脑子在高速运转。摸鱼系统的生物特征变更71%，是因为共享了赵日天的基因锚点，导致系统识别为“双人绑定”。但锚点不稳的原因——他之前一直以为是赵日天身上的卷王系统干扰——原来是前世的尸体还在负五层，灵魂的根须依然牵连着那个旧壳子。

“所以负五层那道门，要我用前世的尸体来开？”林一凡问。

老王点头又摇头：“三分之一的钥匙。你到了门口，用你这根新生的灵魂线去接旧壳，门的第一道锁就开了。”

赵日天转头看了一眼负三层通往电梯的方向，脸色沉着：“周莉那边呢？她带着锚点回切的信息还没回来。”

老王没有回答。他手中银章母体的红光突然暴涨，机柜上的旧终端屏幕猛地亮起，上面跳出一行字，字体像是被水泡过又干掉的墨迹：

“负五层第三道锁从内部反锁了。开启时间只剩今晚零点。”

屏幕上弹出一个倒计时，红色数字一跳一跳：04:37:12。

林一凡和赵日天对视一眼，又看向老王。老王闭上眼，脸上的银光慢慢消褪——他的意识回来后，第一句话是：“你们刚才说的，我全记得，但我自己控制不了那段话。母体在借我传信。”

“母体到底是谁？”林一凡问。

老王沉默两秒：“母体说——它是你第一世设定的东西。你是个程序员，林一凡，你给自己写过一段退路，断根执行组清理过的只是第三代的记忆删除，但你的代码，写在了死人的骨头里。”

机房角落的空调忽然吹出一阵凉风，倒计时又跳了一秒。

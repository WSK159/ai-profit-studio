# 第145章 图纸上的第三个标记

林一凡回到工位时，手里的"华夏金融中心地下结构图"已经被他折成了巴掌大的方块，塞进裤兜最深处。他屁股刚沾上椅子，电脑屏幕右下角弹出一条内部消息——来自老王。

“小凡，你没事吧？钱总没为难你？”

他飞快敲了三个字：“没事，稳。”

老王回了个“那就好”，又补了一句：“对了，明天下午两点，全部门季度会，你准备一下，我提名你参加‘效率之星’评选。”

林一凡眉心一跳。上一世也有这个评选。当时他加班到凌晨三点做的汇报材料被赵日天当众指出数据造假，丢尽了脸。而这一世——“效率之星”的获奖者，会在全公司大会上获得一份由钱国豪亲自签发的特殊资源授权书。上一世他不知道那张授权书意味着什么，但这一世，结合刚才在地下室看到的，他隐隐觉得这事和B3A层脱不开干系。

他正准备深入思考，系统面板忽然在眼前弹了出来，带着刺眼的红光：

【警报：咸鱼值违规清零，系统核心功能（摸鱼空间/雷达扫描）暂时锁死。剩余可用：商城兑换·基础选项。锁定期：23小时59分。】

【提示：本次清零原因为——检测到宿主在非工作时间内接触“高敏坐标”信息，触发系统安全协议。请宿主远离未授权区域。】

“高敏坐标？”林一凡在心里骂了一句，“老子连张图都没看明白，你倒先把我功能给封了。”他试探性调用雷达，眼前一片灰白，毫无反应。摸鱼空间也进不去。他忽然意识到一个残酷现实：这段时间他之所以能在公司里游刃有余，全靠雷达扫描周围人的“劳动浓度”来预判动向。现在眼睛瞎了，等于瞎子在雷区里走路。

下班前，他整理桌面文件，无意间翻到上周赵日天留下的那张“华夏金融中心用电负荷报”。当时只当是一张废纸，现在拿出来重新看，他手指猛地顿住。报表明细里，有一行写的是“B3A层——空调风机组备用回路”，但后面跟着的数字是“0.00 kW”。

但地下室的钥匙孔指向的房间，明明有灯光。

“零负荷，却有灯亮着。”林一凡低声自语，“那地方要么用的独立供电，要么……”他收好报表，心里浮起一个更离谱的猜测：要么那里用的根本就不是电。

他正准备离开，手机忽然震了一下。是一个陌生号码发来的短信，只有一行字：

“图纸上还有第三个标记，翻到背面。”

林一凡瞳孔骤缩。他快速翻出图纸，翻到背面——在中央折痕处，有一行极细微、几乎要用手电筒斜照才能看见的铅笔小字：

“B3A层唯一的钥匙孔，不在门上。”

他盯着这行字，呼吸一瞬间乱了。谁发来的短信？那人怎么知道他手上有图纸？这行字的笔迹……他看着看着，突然觉得眼熟，像极了老王桌上一本笔记本里那歪歪扭扭的字体。

他没有拨回那个号码。而是转身，朝老王的工位走去。

老王正低头写着什么，听到脚步声，抬头笑了笑：“怎么，还不下班？”

林一凡把手机亮在他面前：“王哥，这个号码，你认识吗？”

老王扫了一眼，表情毫无变化：“不认识。陌生号？骚扰的吧，删了。”

他回答得太快了。快得像早就准备好了答案。

林一凡没再追问，点点头回了工位，但临走前，他注意到老王握笔的食指指节上有一道细微的油墨痕迹——和图纸背面铅笔字的反光同色。

他坐上地铁时，手机又震了。还是那个号码，第二条短信：“不要信任老王。”

他攥紧手机，车窗倒影里，他看见自己的眉头皱成一个死结。真正的棋局，才刚刚开始。

# 第354章 云顶山下

三人沿着城北街道一路向北，走了四十分钟，高楼渐少，灰扑扑的城中村和废弃厂房开始占据视野。远处，云顶山的轮廓在暮色中像一头伏卧的巨兽，山顶的电视塔闪着红光。

孙满仓走在最前面，步子快而稳，那双旧布鞋踩在碎石路面上几乎没有声音。赵日天跟在后面，一只手揣在口袋里，攥着那枚铁路制服铁扣，指腹反复摩挲上面的锈迹。

"老头说隧道在半山腰，但我们总不能漫山遍野地找。"孙满仓停下来，从怀里掏出那张沈临渊旧信，"四行字，第四行被涂掉之前，上面还有点什么他来不及抹干净的痕迹。"

林一凡接过来，借着路灯的光斜着看。被涂掉的那片墨迹很厚，但边缘露出几个极淡的笔画尾端，像是竖钩和横折。针扎暗痕在纸背透出光时更清楚——"别信任何人，尤其是拿着钥匙来见你的人。"

"这句话到底在说谁？"赵日天皱眉。

"沈临渊写给他的后人的。"林一凡把信还回去，"问题在于，谁拿着钥匙来见过他们，让他们需要被警告？"

孙满仓沉默了几秒，没有回答。他继续往前走，拐上一条土路。

土路尽头是一道锈迹斑斑的铁栅栏门，铁链锁着，但锁头已经锈死了。赵日天抬腿一脚，铁链连着锁块一起脱落，门框发出刺耳的吱呀声。门后的路几乎被杂草淹没，只留下两条深约一寸的车辙——有人用推车、或者在更早的时候用轨道车，往来过这里。

林一凡蹲下来，手指按在车辙里。轨道间距大约六十厘米，标准窄轨。

"那老头说得没错。"他站起来，目光顺着车辙延伸的方向看向半山腰，"真有铁路。"

三人沿着车辙上行。暮色愈沉，林鸦群飞，山风带着铁锈和腐土的气息扑面而来。大约走了二十分钟，车辙在一面爬满藤蔓的石壁前断了。石壁高约三米，表面覆盖着一层黑灰色的污垢，但藤蔓断裂处露出几道平行的直线痕迹——不是自然岩石的纹理。

赵日天拨开藤蔓，露出半扇铁门，门框被石壁包裹，边缘锤进楔子加固。铁门没有锁，但门缝里卡着一根大拇指粗的铁杆，两端被石块堵死。

"焊死的？"林一凡看了一眼。

"不是焊，是闩死的。"赵日天伸手握住铁杆，浑身的肌肉绷紧，低喝一声，铁杆发出嘎嘣嘎嘣的声响，从门缝里一点点拔出，甩在地上当啷一声。

铁门开了。

门后的空气裹着一股陈年铁锈味，黑暗从门缝里涌出。

林一凡打开手机灯，光柱扫过去——隧道大约三米宽，四米高，砖壁上的灰浆剥落大半，露出内层锈成深褐色的拱形钢架。地面上铺着窄轨，轨道缝隙里全是煤渣和灰尘。但轨道不是干净的，上面有新鲜的车轮痕迹——不是货车，太窄，像是手推的板车。

"有人在用这条隧道。"林一凡蹲下，指尖在轨道上蹭了一下，搓开灰尘露出下面的铁皮，是最近几天才走过的。

孙满仓站在门口，没有进去。他垂着眼，看着那条深入黑暗的窄轨，脸上表情复杂。

"老孙？"林一凡回头看他。赵日天也望了过来，手电光里，孙满仓的侧脸像一块被风化的石头。

"我师傅说过一句话。"孙满仓低声说，"他说他这辈子做过最后悔的一件事，就是第一次踏上这条铁路的时候，没有回头。"

赵日天把铁扣攥在高处，从掌心挤出轻微的一声响："所以沈临渊不是你师傅。"

孙满仓抬眼看着赵日天，又看向林一凡。他没有接话，径自走进隧道。但就在他迈入门洞的一瞬间，林一凡注意到一个细节——孙满仓走的每一步都踩在枕木的正中央，像对这条轨道的间距熟悉到了骨子里。

林一凡心里猛地一沉。

他在沈记铁铺的院子里见过同样的步伐——老头说，三年前来送货的人步子一致，不像跛脚的沈临渊。但此刻孙满仓的脚步，比那送盒者还要精准。

"老孙。"林一凡喊了一声。

孙满仓停下来，没有回头。

"你刚才那句话——'最后一次踏上这条铁路'——是说沈临渊。"林一凡的声音很稳，"但你走这条道，比他还要熟。"

黑暗里安静了片刻。赵日天的呼吸变重，手向腰后摸去。

孙满仓缓缓转身，手电光打在他脸上，他的表情有些出神，像在笑，又像在难过："因为这条轨道，是我十八岁那年帮他铺的。"

赵日天停住动作。铁扣在他指间微微发烫。

就在这时，隧道深处传来一声闷响——像是铁轨被人用重物敲了一下。接着是第二声，第三声，节奏越来越快，越来越近。

铁轨在响。有人，正从隧道深处推着什么东西，朝他们来了。

林一凡一侧身，手电光扫向黑暗深处。光柱尽头，出现一道细长的影子，拖着沉重的声响，不紧不慢地向他们靠近。那不是人——那是一辆板车，上面放着一口铁皮棺材，棺材盖上镌着一枚铜牌，铜牌上用篆字刻着九个小字：

"铁皮柜，等号人，二十七。"

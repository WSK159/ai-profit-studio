# 第357章 钥匙与路

林一凡的手停在半空中，指尖捏着从父亲磁带里得到的那枚铜钥匙——钥匙上刻着一个“去”字，微痕已经有了年头。

他又摸了摸怀里另一枚，那是母亲留下的铁盒里取出的“锁”字钥匙。两枚钥匙刃口相同，弯曲弧度一致，唯独柄部的刻字不同。

“用我娘那枚。”他低声重复了这句话，却没有动。

“你爹说的，你听见了。”孙满仓的声音从背后传来，沙哑而慎重，“你想好了？”

林一凡抬起头看着四棱锁的锁孔，只见这个锁孔呈十字形，不偏不倚地居中。他把“锁”字钥匙举到孔前，比划了一下，发现能插进去三颗牙的距离，再深却纹丝不动。

“插不进去。”赵日天轻声说，“你爹让你用你娘那枚——不是在选钥匙，是在给你选一条路。”

林一凡皱眉：“什么意思？”

赵日天指了指锁孔边缘：“你看这里，有一道细纹。插错钥匙，它会逆时针倒转，把锁芯彻底锁死。你爹的意思是，你只有一次选择的机会。”

孙满仓低声道：“这孩子说得对。当年沈临渊修这条水渠时说过类似的话——水渠分岔，有的道是给运水的，有的道是给步行人的。选错了一道，水走不了，人也走不了。”

林一凡沉默良久，忽然问：“孙叔，你说二十多年前，沈临渊修这条水渠时，跟你提过一个叫‘沈稚冬’的人吗？”

孙满仓的眼睛微微睁大，但很快又压下去：“你怎么知道这个名字？”

“磁带里听过。”林一凡盯着他，“你知道吗？”

通道里的空气仿佛凝固了。孙满仓垂下目光，过了很久才开口：“沈临渊跟我说过一次。他说，他的‘名字’是假的，但稚冬是真的。他说，如果有朝一日有人问你‘稚冬是不是来过’，你就告诉那个人——他来过，又走了，走了就没再回头。”

赵日天忽然站直了身体：“等一下。‘沈稚冬没有来过’——这句不对。”

林一凡转头看他。

赵日天一字一句：“我死过一次。那段时间我醒过来以后听见的第一句话，是一个女人说的——‘沈稚冬没有来过。’我当时没明白，但现在——这句话和孙叔说的不一样。”

孙满仓的脸色变了。

“你说什么？一个女人？”

“对。”赵日天说，“她穿着灰衣服，站在我床边。我说不出话，但记住了那句话。她说完就走了，鞋印是手工布鞋的底纹。”

通道里有一瞬间死寂。

林一凡低下头，攥着那枚“锁”字钥匙，呼吸放缓。布鞋脚印、灰衣人、沈稚冬、磁带上那句“沈稚冬没有来过”——所有线索在这一刻交错成一条隐形的线，那头是他看不清的人，但这头，是他必须走完的路。

他终于抬起头，将这个字的钥匙举到锁孔前，逆时针转了半圈——没有插进去。

锁孔发出“嗒”的一声轻响，内部传出一阵细密的齿轮运转声。四棱锁的十字孔缓缓转动，露出里面第二层锁芯，那道锁芯的形状是三角形的。

孙满仓瞳孔骤缩：“这是第三层的锁芯——五棱锁！”

“三层锁。”林一凡冷静地说，“三棱锁是门，四棱锁是路，五棱锁是答案。而且——”

他伸手摸了摸那个三角形锁芯的边缘，指尖触到一个细微的凸起，形状酷似铜纽扣边缘的纹路。

“第三把锁的钥匙，就是孙叔那颗铜纽扣。”

孙满仓愣住了，低头看着手腕上那颗红绳系着的旧扣，手指轻轻发抖。

林一凡看着他：“孙叔，沈临渊修这条水渠时，有没有问过你这颗纽扣的来历？”

孙满仓张了张嘴，好半天才说：“他问过。他说，若有一天云顶山的第三扇门开了，钥匙就是你身上这颗扣。我当时笑他说疯话——现在想想……”

他沉默了，片刻后松开红绳，将那枚铜纽扣握在掌心里。

就在这时，通道尽头的黑暗里，突然传来一声轻轻的笑。

三个人同时回头，只见一个身影站在阴影中，脚上是手工布鞋，衣摆微微晃动。他开口，声音沙哑却平静：

“等你们好久。开锁吧——我用性命担保，五棱锁后面，有你们要找的一切。”

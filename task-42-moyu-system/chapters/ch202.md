# 第202章 新来的监察员

九点整，星辰科技三楼报告厅座无虚席。

林一凡坐在倒数第三排靠过道的位置，余光扫过前方黑压压的人头，大部分同事的面部肌肉都是紧绷的。有人低头刷手机，有人假装翻笔记本，整个会场的空气像一块拧到饱和的抹布，稍微一碰就会渗出水来。

主席台上，钱总西装笔挺地站定，身后跟着两个生面孔：一个戴着无框眼镜的中年男人，胸前挂着“总部审计组”的工牌；另一个年轻女孩，齐肩短发，穿黑色运动外套，攥着一个银色金属手提箱。

林一凡的目光在女孩身上多停了一秒。

她没有工牌，也没有自我介绍，只是站在角落，像一截冰冷的铁轨。

钱总清了清嗓子：“各位，今天有两件事宣布。第一，总部为了提升组织效能，正式上线‘劳动纯度检测仪’，这是全国首套基于行为图谱分析的绩效评估系统，能精准识别每一位员工在工作时间的真实投入程度。”

台下响起一阵压抑的骚动。

有人在后面低声说：“不就是摸鱼探测器吗。”

林一凡听出那是隔壁组的李腾，他的手指在桌面上轻轻敲了两下，没有回头——他注意到那个戴无框眼镜的审计员目光在李腾的方向扫了一下。

“第二件事，”钱总接着说，“从今天起，检测仪的数据直接同步至总部的薪酬职级系统，凡‘劳动纯度’低于 80% 的同事，将自动进入绩效观察期，连续一周低于标准，作降薪处理。”

台下的骚动骤然放大，有人直接站了起来：“钱总，这样不公平！我们加班到凌晨，偶尔打个盹也算扣分？”

钱总笑了笑，语气温和得像一把钝刀：“所以叫‘纯度检测’。不是看你待多久，而是看你的每一分钟，有没有为公司创造价值。”

林一凡心里一沉。

“创造价值”四个字，听起来人畜无害，可配合后台那套“价值定义”的逻辑，几乎就是给资本神量身定做的规则——谁在摸鱼，谁在真劳动，机器一目了然，可“劳动价值”的算法是谁写的？是钱总写的，是资本神授意的。

他脑子里飞速转着，虚拟面板却突然弹出一条消息：

【提示：检测到检测仪激活信号，覆盖范围——全园区。】

【当前你位于覆盖范围，劳动纯度将被实时评估。若纯度低于 40%，将触发自动扣除咸鱼值惩罚。】

林一凡瞳孔微缩——这意思是，从今往后他坐在工位上，哪怕摸鱼装得再像，被检测仪扫描到的“纯度”一旦不达标，照样扣分。

“开会期间不计算。”那名戴眼镜的审计员终于开口，声音平淡如念稿，“数据采集从工作状态启动。不过——”他话锋一转，目光穿过人群，精准地落在林一凡身上，“刚才那位同事说‘偶尔打盹也算扣分’，这个问题问得很好。检测仪的判断标准，是行为与效率的匹配度。你打盹的那一分钟，如果恰好是系统判定你处于高疲劳节点，那就不算扣分；如果不是……”他笑了笑，“那就扣。”

林一凡后背微微发麻。

那审计员的目光在他身上停留了太久，久到身旁的同事都开始侧目。钱总适时接过话头：“总之，这套系统是为了帮助大家更科学地工作。老周的事是个教训，过度劳损对公司是损失，所以检测仪同时也会关注大家的健康指标，那方面是加分项。”

台下安静下来。

林一凡心里却掀起了更大的波澜——老周的事，钱总居然主动提了？老周明明是被关在地下机房的，钱总却对外宣称是“健康原因休假”？这说明老周的存在仍是钱总的一块遮羞布。而审计员刚才那一眼，分明是一种试探——他在找那个“深夜滞留设备层”的人。

散会时，人群像泄洪一样涌向门口。林一凡刻意放慢脚步，混在一群讨论“这破仪器能不能找人黑掉”的同事中间往外走。他刚迈出报告厅，那个黑外套的女孩不知何时出现在他身侧，声音低低的：“林一凡？”

他脚步一顿，侧头看她。

女孩没有笑，伸手递过来一张折叠的纸条：“老周让我带给你的。”

林一凡心口猛跳。他接过纸条，想追问什么，女孩已经转身汇入人流，消失在走廊尽头。

他没有立刻打开，直到走进卫生间隔间，锁上门，才展开那张纸条。

上面只有一行字，是老周熟悉的那种歪斜字迹：

“原始意志机已启动倒计时，七日。钥匙分两半，图纸是一半，另一半在她手上。”

林一凡盯着那行字，双手微微发颤。

“她”是谁？

电梯口，那个黑外套女孩的身影从监控画面中闪过。

他忽然意识到什么——从昨晚到今天，她出现了两次，每次都像精确计算过的坐标。而他从始至终，连她的名字都不知道。

手机屏幕亮起，新消息提醒：

【星辰科技全员通报：审计组新监察员已于今日入职，负责劳动纯度检测仪日常监控与数据复核。】

下方附了一张工牌照——行政部，陈默。

照片上，那个黑外套女孩面无表情地望着镜头，眼神像一口结了冰的深井。

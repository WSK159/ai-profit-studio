# 第88章 江小姐

“这人到底是谁？”林一凡盯着那条短信，声音压得很低，“她怎么知道我们刚刚启动了根目录？”

周莉摇头，手指在键盘上快速敲击：“信号来自一个虚拟号码，走的是多层加密代理，查不到物理位置。”她顿了顿，“但能在这个时间点发来这条短信的人，至少清楚我们在做什么——或者说，清楚江雪留下了什么。”

林一凡想起何顾问办公室里那通电话。何顾问叫对方“江小姐”，语气恭敬里带着一丝压抑的紧张。那时候他以为是江雪的某个亲属，或者江雪生前合作过的同事。但现在看，这个“江小姐”显然还活着，而且正在盯着他们的一举一动。

“她是在阻止我们解锁备份。”林一凡说，“还是想让我们别踩什么雷？”

周莉没回答，只是把短信截图存进一个加密文件夹。她关掉短信界面，重新调出终端窗口，隐藏分区的图标在屏幕上闪烁——灰色的文件夹，文件名是一串十六进制字符，末尾跟着两个字母：QY。

“QY……‘前缘’？还是‘清雨’？”周莉自言自语，然后猛地抬起头，“钱雨——钱总的妹妹！云麓心理公司的控股人。她本名带‘雨’字。”

林一凡脑子里嗡了一下。江雪把备份藏在星辰考核系统主机的隐藏分区里，而这个分区用“QY”命名——指向的是钱雨。但钱雨是钱总的妹妹，是云麓的老板，理论上站在对立面。江雪为什么用她的名字做文件夹名？

“两个可能。”周莉竖起手指，“第一，备份的内容和钱雨有关，江雪用它做标记；第二，钱雨本人参与过这个备份的建立，也就是说——她不是单纯站在钱总那边。”

林一凡抿着嘴。他记得系统面板里之前解锁的信息：AI考核系统底层暗中收集员工情绪数据，训练精神操控模型，数据链路正是通过钱雨的云麓公司中转。那钱雨如果和江雪有过合作，她在这里面扮演什么角色？两头下注？还是……被钱总利用了，毫不知情？

“不管哪个可能，我们都需要先确认备份里有什么。”周莉说着，从包里掏出一个黑色的U盘，“双密钥合并，我从这头加载，你按一下终端上的确认钮。江雪的声纹绑定了她的那部分，但芯片里有她的一个临时密钥签名，可以代替声纹验证——这是她提前留好的后手。”

林一凡接过U盘。金属外壳冰凉，边缘刻着一行极小的字：“别信他们说的每一个字。”

他怔了一下。这行字和江雪之前留下的地图上画的根系一样，像是某种遗言式的叮嘱。他没说话，把U盘插进笔记本右侧接口，周莉同时敲下一行命令。

屏幕上的灰色文件夹轻轻抖动，然后开始展开。展开过程中，系统面板忽然弹出一条刺眼的红色警告：

“检测到外部监测节点接入——来自星辰科技内部网络。监测编号：AI-AUDIT-07。”

林一凡后背一凉。AI考核系统……它在主动扫描这个连接？按时间推算，距离根目录访问协议启动才过去不到二十分钟，公司的反制机制就已经开始追踪了。

“别停。”周莉的声音很紧，“继续解锁，先把文件拉出来再说。”

文件夹展开到一半，显示出里面的一排文件：三个文档、两段视频、一个可执行程序。文档标题清晰可见：其一《星辰科技情绪数据采集白皮书（内部）》，其二《云麓心理数据流合同签章页》，其三未命名，只有一串时间戳——那是江雪去世前十七分钟的时间。

林一凡手指停在确认键上，那行“别信他们说的每一个字”在眼前晃了晃。

“等一下。”他说，“这个文件，是江雪死前十七分钟上传的——上传到的是她自己的隐藏分区？”

周莉盯着时间戳，声音往下沉了一些：“是。这可能是她的最后一句话。”

终端底部跳出一行新提示：解锁完成，可读取全部文件。与此同时，红字警告再次闪烁，这次带上了倒计时——星辰反向追踪预计 06:47 后到达本机网络位置。

他们有不到七分钟的时间看完所有内容，然后必须切断连接，销毁网络痕迹。

林一凡按下确认键，第一个文档被打开。白皮书第一页有三行被重点标注：“本采集项目未经员工本人知情同意。”“数据用途声明与纸质文件不符。”“主要服务对象：资本方评估系统——对接人：钱雨（签字确认）。”

那句话下面是一个电子签章。签章上的字是方方正正的印刷体，可林一凡认得——钱雨签的名字，用的方式是“钱雨”而不是“钱雨（代）”，说明她是主动签署，亲自负责对接。

他抬头看了周莉一眼：“钱雨不只中转数据，她是这个项目的直接负责人。”

周莉的表情没变，但握着鼠标的手指收紧了。手机屏幕上，那个“江小姐”的短信还挂在那里，五个字，冷冰冰的，像一根扎进皮肤里的刺。

倒计时跳到 04:12。林一凡滑动屏幕，准备打开那个未命名的、时间戳在江雪死亡前十七分钟的文档。鼠标指针移动到文件图标上的瞬间，系统面板再次闪动——这次不再是警告，而是一条新的任务提示：

“咸鱼图鉴深层解锁条件达成——读取‘最后一句话’后，触发隐藏任务：名为‘江小姐’的长线支线。奖励：解锁‘反卷护盾·完整版’。”

他吸了口气，点下了那个文件。

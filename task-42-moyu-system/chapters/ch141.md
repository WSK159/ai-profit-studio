# 第141章 钥匙孔的召唤

赵夜白的话音刚落，B3层的灯光突然剧烈闪烁起来。那根悬浮在空中的残破钥匙孔发出刺耳的嗡鸣声，仿佛有什么东西正从黑暗的深处钻出来。

林一凡下意识后退两步，手指在系统面板上飞快滑动——咸鱼值余额还是零。刚才为了破解赵夜白的精神干扰场，他把攒了三个月的咸鱼值一口气全砸进去了。没有咸鱼值，他就只是个普通程序员，身处地下三层，面对一个自称和前前世死亡有关的男人。

“你不用紧张。”赵夜白似乎注意到了他的动作，嘴角勾起一丝意味深长的弧度，“我说过，我是来给你答案的——不是来伤害你的。”

“那就说。”林一凡盯着他，语气比刀子还硬，“上一世的尸体，在哪儿？”

赵夜白没有立刻回答。他转过身，朝着那个悬浮在半空中的钥匙孔走去。每一步落下，地面都会泛起一圈涟漪般的波纹，像是踏在水面上。他的手指轻轻触碰到钥匙孔的边缘——

“啊——”

一声惨叫从林一凡身后传来。

他猛回头，只见老王瘫坐在地上，双手死死抱住脑袋，眼白上翻。汗水从额头狂涌而出，嘴唇不断抽搐着，发出含糊不清的声音。

“老王！”林一凡冲过去扶住他，却感到一股刺骨的冰冷从老王的皮肤上传来。

“他在接收信号。”赵夜白的声音从身后传来，平静得像在叙述一件无关紧要的事，“我说过，你这位王组长身上被人打了一枚精神标记。而那枚标记的源头——”

他的目光落在钥匙孔上，“就在这里。”

林一凡的脑子嗡地一声炸了。

老王的精神标记的操控源，竟然是他上辈子死亡坐标的门钥匙？这两件事怎么会连在一起？他低头看着老王痛苦扭曲的脸，心里涌起一阵陌生的寒意。他想起自己重生后所有和穿越相关的线索——系统、名片、华夏金融中心、钥匙孔画……每一次看似巧合的相遇，最后都指向同一个地方。

而这个地下三层，就是一切的核心入口。

“你为什么不早说？”林一凡抬起头，声音沙哑。

赵夜白微微偏了偏头，目光里带着一丝难以捉摸的光：“因为我也是今晚才确定——你就是那枚钥匙的适配者。”

“什么意思？”

赵夜白没再说话。他的手指在钥匙孔上轻轻转动了一下，咔哒一声，原本锈迹斑斑的孔洞，开始缓缓转动，像沉睡千年后第一次苏醒的门锁。一圈、两圈、三圈——

当它转到第三圈的时候，整个B3层的空气仿佛被抽空了。林一凡觉得自己的心脏像被一只手捏住，巨大的压迫感让他几乎站立不稳。他耳边响起一个声音，像是铁链拖过水泥地，又像是金属摩擦金属，沙哑、生硬、不自然。

“门……在等你……”

赵夜白猛地收手。钥匙孔的转动戛然而止，一切回归寂静。老王发出一声剧烈的喘息，整个人像从水里捞上来一样瘫倒在地，瞳孔慢慢恢复正常。

林一凡的耳朵里还残留着那句沙哑的话语的余韵。他抬起头，和赵夜白的目光在半空相撞。

“那是什么？”

赵夜白看着他的眼神里，第一次浮现出一丝真实的情感——那是忌惮，是的，他在忌惮他。

“那扇门后有人，且他期待你出现已经很久了。”他说完，将钥匙孔往怀中一收，身影开始模糊，“今天到此为止。下次见面的时候，希望你已经准备好打开那扇门了。”

“等等——”林一凡伸手去抓，却只抓住一手的空气。赵夜白整个人像沙雕一样碎成无数细小的光粒，消散在黑暗之中。

B3层恢复了寂静。他站在原地，看着自己空空如也的手掌，心里掀起一团乱麻。口袋里的名片突然烫得厉害，他掏出来——00042那串数字下面，不知何时浮现出第三行字，很小，但清晰可见：

“你还有七天。”

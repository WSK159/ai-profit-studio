# 第346章 排水渠里的水声

排水渠的水没过了脚踝，又凉又浑。林一凡左手攥着铁皮盒，右手扶着湿滑的渠壁，深一脚浅一脚地往前走。

孙满仓走在最前面，走了约莫百步，忽然停下来，压低声音：“前面有岔口。”

赵日天的声音从后面传来：“左还是右？”

“右边有水声，很响。”孙满仓蹲下身，用手电照了照地面，“左边干燥，但墙上有新鲜刮痕。”

林一凡凑过去看了一眼那道刮痕——三道平行的细线，像是某种工具划过。他心头一动：“顾七说从排水渠撤，她去引开追兵，可没说从哪条路走。”

“右边。”孙满仓的声音带着一种不容置疑的笃定，“水声越响的地方，出口越近。”

三人拐进右侧水道，头顶的混凝土拱顶越来越低，水声越来越大，空气里夹杂着一股铁锈味。走了大约两分钟，水声忽然停了。

准确地说，是水流声停了。仿佛有人在上游关掉了一个阀门。

孙满仓再次停下，手电筒照着前方——水道尽头是一扇铁栅栏，栅栏外边是斜坡，斜向上的洞口能看到夜色和几点星光。可铁栅栏上挂着一把锁，一把锈得看不出原本颜色的挂锁。

“被锁了？”赵日天挤上来，手指探进锁孔摸了一把，“不是锈死，刚锁的，断面上还有新金属光泽。”

林一凡心里一沉。追兵不止一路，有人提前断了退路。他正要开口，孙满仓却忽然侧过头，目光落在铁栅栏右侧的墙壁上。

墙壁上刻着一行小字，字迹歪歪扭扭，刻得极深，像是用钉子之类的东西硬凿出来的：

**“老沈家的后门，从来不上锁。”**

孙满仓盯着那行字，呼吸猛然重了一拍。林一凡看到他脸上的表情，那种表情不是一个同事、一个前辈该有的表情——那更像是一个失散多年的徒弟，突然看见了师父的字迹。

“孙叔？”林一凡轻声喊了一句。

孙满仓没应声，伸手从腰间摸出一把钥匙——一把看起来平平无奇的黄铜钥匙。他把钥匙插进挂锁锁孔，拧了两下，“咔嗒”一声，锁开了。

赵日天眼神微妙地扫了孙满仓一眼：“你这把钥匙，哪来的？”

“师父给的。”孙满仓拉开门，声音很低，“他说过，云顶山底下所有锁，这把钥匙都能开。”

“你师父是？”林一凡问。

孙满仓正要回答，水道深处忽然传来一声闷响，像是有什么东西掉进了水里，紧接着是一阵急促的脚步声——有人在追，而且不止一个。

“走！”赵日天一把拽住林一凡的胳膊，三人鱼贯而出铁栅栏，沿斜坡向上冲。坡道不长，不到二十米就到了洞口。洞口长满了杂草，扒开草帘，外面是一片废弃的采石场，月光下乱石嶙峋，十几台生锈的挖掘机像巨兽一样趴伏在黑暗中。

他们刚钻出洞口，身后排水渠里传来一声汽笛般的哨响——尖利、刺耳，在深夜的山谷里回荡。那声音让林一凡后脊梁一阵发麻。

“哨声……”孙满仓的脸色彻底变了，“那是‘控线人’的哨子。”

“什么控线人？”林一凡追问。

孙满仓没有回答，目光死死盯着哨声响起的方向，嘴唇翕动了好几次，像是在默念一个名字。终于，他开口了：“三十五年前，三十七号项目里，沈临渊最信任的助手，代号‘牵线’。牵线负责的，是控制所有外围盯梢线人。师父当年说过一句话——‘牵线的哨子一响，整个云顶山的人都会动起来。’”

赵日天皱着眉：“那，已故的沈临渊先生，他——”

“他没死。”孙满仓的声音像从牙缝里挤出来的，“我刚才看到那行字，就知道了。那行字，是师父最近才刻上去的。因为那行字的写法，是他三十岁以后才开始用的写法。而他三十五年前失踪的时候，才二十七岁。”

林一凡攥紧了铁皮盒，盒体冰凉，边缘硌着他的手指。

师父还活着。沈临渊还活着。而三十七号的“守门人”沈稚冬，已经走了八年。

他低头看了一眼铁皮盒，灯光下，盒面上那些烧制的数字纹路似乎微微发亮。第七枚核心里的第七份机密——他忽然意识到，他从头到尾都不知道，这份机密到底是什么。

只差一步。他似乎离三十七号的全部秘密，只差这一次开门了。但那条路上，有哨声，有追兵，还有更多他想都不敢想的真相。

采石场边缘，一台报废挖掘机的驾驶室里，忽然亮起一点猩红——像是有人猛吸了一口烟。那点猩红在黑暗中明灭了两下，然后熄灭了。

林一凡心头一凛，正要示意大家避开，赵日天却忽然开口：“是我认识的人。”

他径直朝那台挖掘机走了过去。

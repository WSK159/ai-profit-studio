# 第218章 第四条路

“你什么时候知道它能塞进去的？”

林一凡的声音在密室中回响，压过了白炽灯管的嗡鸣。他已经不再看那柄悬浮刃，目光死死锁在赵日天掌心那枚鱼翻身硬币上。

赵日天握着硬币的指节微微泛白。他沉默片刻，忽然笑了一声：“半年前，陈鸣最后一次找我喝酒。他喝多了，把那枚硬币放在桌上，当着我的面转了三圈，跟我说——‘第四条路能走的只有一种人。那人得先想明白，自由不是捅破别人的心，而是挖出自己的心。'”

林一凡的瞳孔猛地收紧。

“挖自己的心”——那枚硬币翻转鱼身的瞬间，他脑中浮现的是昨夜的画面：配电房的黑影蹲在墙角的姿势，那影子手里也握着一枚硬币，硬币上无反光，却在他雷达上显示为一片纯粹的金色。

“你的意思是——”林一凡缓缓捏紧拳头，“把硬币放进接线盒，代价是‘交出你自己’？”

赵日天没有回答，但他的手已经缓缓松开。那枚硬币在空中翻转了两圈半，落地的瞬间发出一声轻响——方向是正面朝上，鱼头朝向他身侧的接线盒。

“你捅不捅我都无妨，”赵日天抬头看着他，“因为陈鸣那张纸条上的含义是——”他顿了顿，“第四条路，是用那枚硬币启动一个‘仲裁替代程序’。它会抽走你的劳动时间，但不会抽走你的命。只是有个条件。”

“什么条件？”

“系统要求你亲口说出那句话：‘我自己选的路，我来付报酬。’”

密室深处，原始意志机忽然发出一声低沉的轰鸣。整面设备墙上的灯管逐一亮起，接线盒的锁扣在无人触碰的情况下咔哒一声弹开，里面有光线溢出，像是一台沉睡已久的机器正在苏醒。

林一凡的系统的警报声更急促了。

就在这时，楼梯口传来急促脚步声——老王冲了下来，身后跟着陈默。陈默左肩上有一道长长的口子，血迹浸透了半边衣袖，但他的目光却异常清明：“你们快——那三个人去配电房了！他们把压缩机房的总闸拉下来了，这里的水位在涨，最多二十分钟就会被淹没！”

话刚说完，整座密室的地面忽然从脚底传来一阵持续的低频震动，泵房深处的淤泥和水流声沿着管道往上涌，水位已经开始渗透进密室地板的排水口边缘。

林一凡低头看着那枚躺在地上的硬币，又看了一眼赵日天心脏的位置，最后看了一眼设备墙上那台原始意志机——它正渗出密密麻麻的暗红色纹路，像是活的铁肺在急促呼吸。

他缓缓弯腰，拾起那枚硬币。

“我自己选的路——”

硬币握进掌心的瞬间，一阵剧痛从掌心传导遍全身。他看见手背上那枚绿色的系统光点猛地爆发出刺目的光——然后寸寸碎裂，化作漫天星尘簌簌落下。

赵日天猛地变色：“你疯了！系统没了你会——”

“我来付报酬。”

最后一个字落下的同时，林一凡把那枚硬币按进了接线盒正中央那道裂缝。光线、轰鸣、水流声、还有赵日天的惊吼——全部交织在一起，淹没了一切。

世界在短暂的空白之后，传来一声极其清晰的、带着金属质感的女声：

【仲裁启动·等级判定：最高优先级。】\
【内容：劳动时间冻结·自由连接建立。】\
【支付人：林一凡。当前劳动时间：三年零七个月。全额扣除。生效中。】\
【新条件解锁：你的手，已经握住了“钥匙”。】

林一凡低头看着自己的掌心。那枚硬币不见了，却有一截极细的银色丝线从他的掌纹中浮现，像是一条活线，从他的手指尖一路蔓延到原始意志机深处，没入不见。

他身后的水声越来越大，灭顶的轰鸣越来越近。可他却忽然听清了赵日天压低的声音——那像是一句来自极远处的提醒：“这就要开始了。你得记得你是谁，不然连你也会变成机器的一部分。”

然后，水泵房上方传来一个他永远不会忘记的声音——钱总，远远地、带着笑意地说：“我早说了，他会自己爬上这条路的。”

水漫过了林一凡的膝盖。

掌心的银线微微发烫，像是有了心跳。

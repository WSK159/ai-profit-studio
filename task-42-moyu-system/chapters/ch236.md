# 第236章 摄像头

摄像头从裂缝中升起，镜头转动，黑色镜面稳稳对准林一凡。那一瞬间，他全身汗毛竖起来，一种被人从遥远地方死死盯住的感觉爬上后颈。

老王下意识往后退了半步：“谁装的？”

“不是我们的人。”赵日天的语气冷下来，这一回，他没有笑。

摄像头底部刻着一行极小的编号——LX-001-7。林一凡曾在系统的面板里见过这个编号，出现在他第一次解锁“摸鱼雷达”时的一个提示角落，当时他只当是无意义的数据残留。

现在他知道那不是残留。

“陈默，”他压低声音，“你爸有没有提过一个叫LX系列的东西？”

陈默盯着那张照片，眼珠一动不动，声音像从很远的地方飘来：“他说过。他说他画过一套图纸，他负责的部分叫LK线，但他师父——也就是老周——管另一套设备叫LX。他说那是‘倒着看世界的东西’。”

“倒着看世界？”赵日天皱眉。

“我爸的原话是：LK是用来前看的，LX是用来回看的。LK负责接收信息，LX负责监视信息从哪来。”

老周。那个一直没死、始终藏在阴影里的老周。照片里，陈默的父亲站在公司门口，怀里抱着他女儿，背后星辰科技的玻璃幕墙里有一个模糊的人影。

人影站在二楼窗口，手里拿着一个本子。林一凡盯了那人影足足五秒，认出那姿态，像极了工牌档案里老周证件照上仰头看天的姿势。这个人从陈默父亲进公司第一天就注视着他，从头到尾都在注视。

赵日天低声骂了一句：“该死。”

他扑向终端，手指在屏幕下方疯狂触摸，一阵刺耳的电流杂音后，终端屏幕上出现一幅俯视的屋宇图。那是整座写字楼的剖面图，每一层都有密密麻麻的红色小点在移动。这些点是监控终端采集到的，活动人体信号。每个红点上方带一个编号，活人编号。

林一凡迅速找到了自己——编号A-142，陈默A-143，老王A-144，赵日天A-145。

但他看到左下角显示着另一个红色标记，标注位置在——负六层，地下更深处。

编号是A-000。

代码格式比所有其他人的编号多了一个前缀，亮金色，还在跳动。

“负六层有人？”老王问。

“那不是人。”林一凡说着，感觉背后一阵发凉，“那是标记我们的东西。”

他话音刚落，终端屏幕上突然弹出一行字，所有代码字符消失了，取而代之的是一行按传统汉字格式排成的文字：

“你看到我了吗？我看见了你们四个。”

陈默的脸色彻底白了，因为那行字的落款是一个名字——不是编号，是全部由黑体打出来的名字：

“老周”。

“这家伙装神弄鬼，”赵日天冷冷地说，“他在这栋楼底下埋了摄像头，天天看着所有进出的人。你爸在楼里待了那么多年，他说‘倒着看世界’的意思，就是老周从底下往上看。他没在看天花板，他一直在看地板，在看地下。看那个和我们一样在地下等着的人。”

林一凡转向终端：“权限还在你手上，能不能往负六层——”

“能。”赵日天打断他，但随即咽了口唾沫，“但是师父在造这台机器时留过一条规矩，负六层的通道，必须同时输入两条指令，每条指令由一枚徽章授权。一枚在我这，另一枚——”

他看向林一凡，目光落在他工牌背面的菱形印记上，那个印记在终端屏幕映出的光芒下，与卡片正面的印记严丝合缝地重合。

林一凡取出那张白色卡片。赵日天也摸了摸自己胸前的口袋，掏出同款形状的卡片，只是他的边缘磨损得更严重。

两张卡片同时插入终端背面的两个槽口。机器发出一种令人牙酸的机械声，像什么东西在深处切割金属，紧接着，竖井东侧的墙壁整个向两边滑开，露出一条向下延伸的、没有照明的通道。

黑暗深不见底。

从通道深处，一股潮湿的风吹上来，带着某种矿物尘土的气味，和一丝极淡的、像金属被烧过的焦味。

终端屏幕最后跳出一行字：

“请沿通道下行64米，到达底部后右转，第三间舱室内有你们要找的东西。注意：在此过程中不要回看，不要叫任何人的名字，不要答应任何人对你说话。”

最后一行字闪烁了三次，然后屏幕暗了下去。

通道深处，隐约传来一声很轻很轻的叩击声。三长两短。

林一凡看向陈默。陈默的嘴唇动了一下，无声地说了两个字：我爸说过，叩击声三长两短，是那个东西的信号——“它醒了。”

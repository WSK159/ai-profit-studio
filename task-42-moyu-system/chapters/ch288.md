# 第288章 十三楼的撬棍声

林一凡没有坐电梯，他从十七层消防通道往下走，每一步都踩得很稳。银怀表被他塞进内侧口袋，贴着胸口的皮肤，每一步都能感到那一点冰凉的触感。

通道里灯管忽明忽暗，楼梯间的空气带着一股潮湿的、久未通风的铁锈味。他数着台阶——十七层到十六层，十六层到十五层——数到第十三层的转角时，头顶那盏日光灯“嗤”地闪烁了一下，然后灭了。

他抬头。楼梯间一片漆黑。

林一凡没有停下脚步，继续往下走了一步，然后听见了那声音——撬棍拖过水泥地面，金属与粗粝的砂石摩擦，发出尖细而缓慢的刮擦声。从第十三层走廊的方向传来，一下，又一下，节奏沉稳，像一个人在黑暗里不慌不忙地走。

他从口袋里摸出手机——屏幕亮着的瞬间，他看见走廊尽头有一道灰色的影子。灰工装、佝偻的背，那个人站在十三层走廊的入口处，手里拖着一根撬棍，侧身对着他，像已经等了他很久。

“我说过，钥匙认了主，就别往回走。”

老头的声音沙哑，像一把钝刀刮过砂纸。他缓缓转过头，他的脸和林一凡之前在消防通道里见到的一模一样——同样布满皱纹，同样五官模糊，像被反复擦洗过的一张旧画。

林一凡在台阶上站定：“你在等我。”

“不是在等你。”老头晃了晃手里的撬棍，像在掂量一件趁手的工具，“是在等那把钥匙路过这里。”

“你要这把钥匙？”

老头没有答话，只是敲了两下走廊的墙。铛，铛。那声音在空荡荡的十三层回荡，像某种暗语。

林一凡沉默了三秒，然后往前走了一步：“我手里的钥匙，是锁门的，不是开门的。”

老头的手微微一顿，这是林一凡第一次看到他的动作里出现迟疑。黑暗里，那双浑浊的眼睛像两枚生了锈的钉子，钉在林一凡脸上。

“锁门的……”他喃喃重复了一遍，然后忽然笑了。那笑声不大，却像石子投入深井，撞出层层叠叠的回声，“小娃娃，你被人骗了。你以为那是第000号植入体告诉你的？它是林一诺写的备份代码，可它自己都看不清主人写的是门还是锁。”

林一凡瞳孔微微收缩：“你什么意思？”

“意思就是——”老头拖起撬棍，向他走过来，一步，两步，每一步都踩在灯具熄灭的阴影里，“那枚钥匙既能开门，也能锁门。你选择怎么用，取决于你知不知道它真正开的是哪扇门。”

他在三步之外停下，将撬棍的尖端抵在地面上，发出一声脆响：“林一凡，你母亲写下的不止一个备份。第000号植入体只是她放在明面上给你看的那个。她真正藏起来的东西，不在星辰科技大厦，也不在你脚下的楼层。”

“在哪？”

老头不答，反而偏了偏头，像在听什么。林一凡顺着他的视线看去——走廊深处的墙壁上，挂着一幅不起眼的消防疏散图，图面泛黄，边角卷起。老头抬起撬棍，用尖端点了点图纸上标注“B1”的位置——地下车库。

“你进来的时候，是不是从地下车库走的？”

林一凡眉心跳了一下。他是从地下车库潜入的。

“你走的那条路，隔着一堵墙的位置，有一间没有标在图纸上的房间。那扇门没有锁孔，只有一道缝隙，够一张纸插进去。”老头盯着他，“你妈妈十七年前最后一次进入那个房间的时候，手里拿着一张A4纸。纸上有字，但写的人不是她。”

林一凡忽然觉得背后发凉。A4纸。他在之前的冒险里，见过一张A4纸，上面写着某种陌生的字迹。而他就快把那张纸的来历忘掉了。

“你要找的东西，”老头的声音变得很轻，“和那张纸有关。纸还在那个房间里，房间的门缝里，纸的背面你自己看。看完了——再决定手里的钥匙是锁门，还是开门。”

他说完，身形开始后退，一步一步退进走廊深处的黑暗里。撬棍拖地的声音渐远，直到完全消失。林一凡站在十三层的消防通道口，楼道的应急灯在老头消失的瞬间重新亮起。他低头看了一眼手机——距离收到匿名消息已经过去了四十三分钟。他还有不到十七分钟。他攥紧口袋里的怀表，转身向下迈出一步，又顿住了。

楼梯间的墙壁上，就在他手边，不知何时多了一行字。黑色的油性笔，笔迹有些潦草，但每一个字都清晰可辨：

“别相信灰衣服的人说的话——他拿过你妈的钥匙。”

落款是一个字：赵。

赵恒？还是赵小满？林一凡盯着那个“赵”字看了三秒，然后掏出手机，拍下了那行字。他继续往下走——没有回头。但他心里清楚，刚才那个灰工装老头说的每一句话，他都记下来了。包括他提到的那张A4纸——那间地下车库未标注房间里的A4纸。

灰老头知道那张纸。赵恒也知道那张纸。而那张纸上写的字，他曾在某个拐角处见过——是笔陌生的字迹，像一个人匆匆写下的警告。

“叮——”手机响了。新消息，发件人依然是那个匿名号码：“你已经看到墙上那行字了。对吗？”

林一凡停下脚步，盯着屏幕。三秒后，又一条消息弹了出来。

“这栋楼里，只有一个人可以信。不是赵恒，不是王姐，不是那个灰衣服的老头——”消息停了一下，像在等什么。

林一凡没有等到下一句，但他已经站在了地下车库的入口处。冷风扑面，车库里空旷得像一只张开的嘴。他抬起头，看到车库的角落里，那道通往垃圾房的铁门，门缝里透出一线光。那道门。灰老头说的那道门。

他走过去，蹲下身，从门缝里摸出一张叠了四折的A4纸。展开，背面果然有字——只有一行，但每一个字都像针一样刺进他眼里：

“如果你看到这张纸，说明你已经相信了不该信的人。快离开这栋楼——你只有一次机会。”

落款，没有名字，只画了一枚鱼骨头的简笔画。

林一凡握着那张纸，手指微微发凉。他低头看着纸上的鱼骨，脑海里忽然闪过一个画面。那是很久以前，在前世的工位上。公司团建吃鱼，母亲发过一条微信，配图就是一条被吃得干干净净的鱼骨头。她说：“人活着，得像鱼骨一样——扎人，但自己不会弯。”

那张A4纸上的鱼骨，和他记忆里那条鱼骨图，一模一样。

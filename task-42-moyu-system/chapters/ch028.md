# 第28章 围剿：老板联合同行封杀他

第二天，林一凡走进效率小组的时候，整个办公区的气氛像结了一层冰。

两个保安站在门口，手里拿着纸箱，像是随时准备收东西。老组长王建国站在工位前，犹豫了很久，还是走过来，低声说：“一凡，昨天下午接到通知——你的工牌权限被收回了，邮箱和内部系统都被冻结。他们说……你涉嫌泄露公司机密。”

“呵，动作挺快。”林一凡扫了一眼自己工位上已经空了的那台显示器——他昨晚备份过所有资料，今天这台电脑上的文件已经被人复制走了。

“老王，没事。”他拍了拍老组长的肩，“您呢？您没被波及吧？”

“我倒是没事，就是财务那边说……效率小组这个月的绩效奖金，全部冻结审查。还说要重新评定工作成果，因为你那套东西‘涉嫌违规’。”王建国咬着牙，“一凡，你说句老实话，你那个方法，真的违规吗？”

“不违规。我基于劳动法第八十五条和第二十一条精神提炼的——员工有休息的权利，用人单位不得强迫加班。我只是把它科学化了而已。”林一凡打开手机，点开一个文档，“老王，文件我刚才发你邮箱了。你留一份，回头照常开会，照常用，如果有人问，你就说从公开渠道学来的。”

“公开渠道？”

“对一个——马上就是了。”

林一凡转身走出办公室，迎面撞上一个人。

赵日天。卷王赵日天穿着笔挺的西服，胸前别着个新工牌，上面赫然印着——**星辰科技·效率管理部·部长**。

“哟，林组长，这么巧。”赵日天咧嘴一笑，露出一口白牙，“不对，现在应该叫你……前组长了？昨天钱总找我谈了，让我重新出山，接手效率小组。他说，你是咱们公司的一颗老鼠屎，坏了整锅汤。”

“他跟我说的是卷王，说你来当我的‘演示助手’。”林一凡乐了，“赵部长，欢迎回来啊。不过我很好奇——你愿意当他的狗腿子，是因为他给你开了多少价？”

赵日天脸上的表情僵硬了一瞬，随后又挂上那个标准化的笑容：“林一凡，你用歪门邪道搞出来的一堆东西，很快就没人信了。我告诉你，昨天，我和钱总已经联系了三家头部互联网公司——全华网、极速未来、蓝桥科技——我们共同发布了一份‘联合声明’：全行业封杀‘摸鱼工作法’，凡是使用该方法的员工，一律不予录用。”

林一凡心里猛地一震。全华网、极速未来、蓝桥科技，这三家加起来占据互联网市场的半壁江山。钱总这是要把他从物理上隔离掉——不只是公司内，是整个行业。

“你们……还挺有行动力。”他缓缓说着，同时在心里飞快地盘点——系统的“版权护体”技能，需要连续一周真实摸鱼才能激活。他已经坚持四天了，还差三天。

三天，只要能顶住三天，这个技能就能彻底生效。到时候，“摸鱼工作法”将被赋予法律层面的保护，任何未经授权的传播和使用都会被自动识别并锁定。

“赵部长，不，赵日天。”林一凡忽然笑了，“你知道你们这招叫什么吗？”

“什么？”

“叫——怕了。”他压低声音，“你怕了，所以联合别人一起围攻我。钱总也怕了，所以他不敢拿我劳动仲裁。三家大公司也怕了，所以他们需要‘联合声明’来给自己壮胆。可是赵日天，你真以为，一条声明就能杀死一个时代吗？”

他说完这句话，头也不回地走了出去。

赵日天站在原地，脸色阴沉地盯着他的背影，缓缓掏出手机，发出一条消息：“老板，他没服软，计划要加码。”

林一凡走出写字楼，抬头看了看三十七层的高楼。阳光晃着他的眼睛，手机突然连续震动——他低头一看，全是消息推送：

“突发！星辰科技前员工涉嫌重大违规，公司正考虑起诉！”
“传‘摸鱼工作法’为抄袭之作，原创者另有其人！”
“三大互联网巨头联合声明：永久封杀摸鱼文化！”

他冷冷地笑了笑。狗急跳墙了。

前几条他点开看了看，没有气，反而越来越清醒。然后他打开系统面板，站在街边，沐浴着初秋的阳光，闭上眼睛——开始摸鱼。街道上人来人往，谁也不知道这个站在写字楼外晒太阳的年轻人，正用自己最后的四天时间，攒着一个足以掀翻整个职场的底牌。

那天晚上，林一凡的手机收到了王建国的一条消息：“一凡，老王还有用。你缺一个对外平台——明天下午，创投圈的‘逆风’论坛，我托人帮你安排了一个发言名额。三分钟。”

林一凡看着手机屏幕，想了想，打字：“老王，你这步棋，可能会让钱总把你一起开除。”

“我今年四十八了，他爱开除开除去。反正——你那个方法，是真的让我的腰痛好了很多。我信你。”

林一凡放下手机，望向窗外。城市的霓虹灯在夜色中闪烁，没有哪盏灯是为他亮的——但现在，他准备去点燃一盏。

# 第262章 抵押品

密室安静得能听见保险丝跳动的电流声。林一凡站在原地，手里攥着那把三叉钥匙，指尖被冰凉的金属硌得发白。他抬起眼问陈和平：“你早就知道009号钥匙的抵押品是什么？”

陈和平没有立刻答话。他慢慢走到墙根，蹲下身，从那把老旧折叠椅底下摸出一只铁皮饼干盒，打开盖子，里面是一叠泛黄的收据、几张地铁票根、一枚掉了漆的纽扣，还有一张折成四折的纸条。他抽出纸条递给林一凡，上面是一行钢笔字，字迹工整得不像一个老人口中粗粗犷犷的人写的：

“如果钥匙抵押的是我的命，就让林一凡自己选。他若愿意，就把锁开了；他若不乐意，就把钥匙还回去，锁重新锈死。”

林一凡盯着那行字，沉默了几秒，忽然笑了：“他倒是替我做好了决定。”

“他做过很多次决定了。”陈和平的声音有些喑哑，“2019年那次，他用命换了你的命。那个赌局……不是谁都能下注的。001号卡是仅有的三张通筹码之一，他花了全部身家才拿到手。”

“王姐呢？她为什么知道这些？”林一凡的目光转向密室门口，“她刚才说的是什么——‘009号钥匙的抵押品，是你这辈子的命’？”

“王姐说的没错。”陈和平站起身，走到那扇铁门前，手掌按在锈迹斑驳的门板上，“009号钥匙是陈重阳留给你的最后一份‘筹码’。打开这扇门，你会失去一些东西，但未必是性命。当年他写这张纸条的时候，把条件改了——009号钥匙的抵押品，从‘命’改成了‘记忆’。”

“记忆？”林一凡眯起眼，“哪段记忆？”

“你自己最珍贵的那段。”陈和平转过身，看向林一凡，“可能是你入职第一天的记忆，可能是你重生前那个晚上的记忆，也可能是……关于某个你一直以为还活着的人的。”

林一凡的心猛地一沉。他还记得前世最后一次见李思时，李思递给他一台对讲机，说“你要是找到了真相，就用这个频道叫我”——那个女人，是他上一世唯一信任过的人。而重生以来他每次想起她的脸，记忆里都是一团模糊。他记得跟她说过话、吃过饭、并肩加过班，可就是记不清她到底长什么样子。那张脸在他脑海中始终隔着一层水雾。

“如果打开009号钥匙的门，我可能……忘了李思？”他的声音很轻，像是怕这句话落在地上会碎掉。

陈和平没有否认：“你还剩一步回头的余地。那把钥匙插进去再转半圈，一切都回不去了。你不转，把这把钥匙还回去，从此离开星辰科技，安安稳稳当一条咸鱼，也饿不死你。”

林一凡握着三叉钥匙的手指紧了又松，松了又紧。他低头看了看那本笔记本的最后一页，又抬头看了看陈和平那张几乎被皱纹填满的脸。窗口那缕昏暗的光线里，陈和平眼角的疤痕微微跳动——那是二十年前留下的旧伤。

“我不走。”他把钥匙塞进锁孔，扭动了半圈。

咔哒。屋内所有的灯光同时暗了一瞬，又重新亮起来。锁芯里传来一连串齿轮转动的声音，像某种古老的机关正在缓缓苏醒。墙壁深处发出轰隆隆的震颤，灰尘从天花板间抖落。

铁门缓缓打开了一条缝。缝隙里透出的不是光，而是一片温柔的、橙黄色的暖色——像是夕阳，又像是一间开在傍晚的、亮着灯的面馆。从门缝里飘出来的，是一阵麻辣烫的气味。

林一凡的眼眶忽然发涩。他认得这个味道，那是2019年冬天，他连续加班三个月，每夜凌晨两点，那个跛着脚送餐的外卖员放在他桌边的那碗麻辣烫。每一次都多放一根烤肠。

门缝更大了。暖光铺满地砖，隐约可见里面摆着一张折叠桌，桌上有两只碗，正冒着热气。碗边压着一张纸，林一凡俯身看清上面的字，浑身一僵。

纸上写着：“你应该还不太记得我的脸了。没关系，你记得这碗麻辣烫的味道就行。哥只能陪你到这儿了。009号钥匙可以换回你那七年的记忆——但代价是永远失去‘见到我’的权利。你选吧。”

字迹潦草。落款处没有名字，只画了一只歪歪扭扭的小鱼。

林一凡站在门缝前，手里握着那枚已经转完半圈的三叉钥匙，脖子上挂着的工牌被穿堂风轻轻掀起。他身后，王姐的脚步声又从走廊尽头折返回来，不紧不慢，像某种倒计时的节拍。

他深吸一口气，迈进了那道暖光里。铁门在他身后缓缓合拢，发出一声闷响。

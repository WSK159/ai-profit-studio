# 第409章 两枚钉

林一凡没有接那根钉。

他攥着拳头站直身子，目光从老杨头大哥手里的青铜钉扫过，又落回门缝里那枚和它一模一样的钉上，脑中飞速梳理出一条线：铁皮壳子的锁眼钉空了，钱方远才逃了出来。那扇铜门的锁眼钉还在，如果钉进去第二枚，门就会开。图纸27所谓“换命”，大概率就是把两根钉的位置调换——用一根换另一根，用一个名字换另一个名字。而“换命”的核心，是被钉上去的名字，而不是钉本身。

“我能看看那根钉吗？”他说。

老杨头大哥笑着把钉递过来，毫不在意地扔向他。林一凡伸手接住。入手比想象中沉得多，几乎坠得他手臂一沉。他翻过钉身，仔细看那行字——“赵日天”和“林一凡”两个字刻得极深，像是被重复凿过很多次。他试着用指甲刮了一下，“赵日天”三个字明显浮于表面，而“林一凡”三个字深深嵌在底下，仿佛已经存在了很久很久，久到上面的字换了又换，底下的名字却从来没动过。

林一凡心口一跳。所以这根钉从头到尾钉的都是“林一凡”？赵日天只是后来被刻上去的，但这个名字——赵日天这个人从一开始就不在钉上。那“卷王”赵日天也是系统拥有者，他的计划、他的狼狈、他的一切，难道也是这根钉的算计？

他忽然问：“赵日天现在在哪？”

老杨头大哥笑了一声：“你不是已经猜到了？他带着卷王系统，替你挡了挡。他是你的挡箭牌。”林一凡脸色一沉：“什么意思？”

“那根钉本来是钉你的。但赵日天在上一世的节点上，用自己的名字盖了上去，替了你。”老杨头大哥指了指他手里的钉，“现在钉上他的名字先剥落了，底下的你才露出来。所以系统商城才会解锁‘第二根钉’——这本就是你的钉，只是现在轮到你自己来钉。”

林一凡沉默了几秒：“这门后面是什么？”

“你自己的债。”老杨头大哥说，“你上一世猝死前的最后一个提交，不是代码，是你用‘摸鱼值’兑换过一次东西——你没记住，但它替你记着。”他说着，用下巴朝门缝里那枚钉努了努：“那根钉上刻的钱方远，就是你把债务转移给他之后留下的痕迹。你还记不记得，你兑换过一次的东西是什么？”

林一凡脑中一阵轰鸣。他确实有过一次空白兑换，那是上一世死前几分钟，系统的“最终权限”弹出来过一次——他没有细看就选了，因为那会儿他以为是自己加班的幻觉。现在他明白了——他选了“债务转移”，把“死亡”这个结果转了出去。钱方远带走的“债务主体”，就是那份被他甩出去的死亡。他换了命。所以钱方远才倒霉了那么多年，才在水牢铁皮壳子里活了半条命，才在硬币上留下“门在门后，钉在钉里”的线索。那门后面困着的，是真实的他，一开始该承受的那份死亡。

“所以……门后面是‘死掉的我’？”林一凡问。

老杨头大哥没有回答。他把手伸向门缝里那枚青铜钉，动作很轻，像在抚平一道伤口：“你猜。”林一凡盯着他，“门后那个‘老杨头’是谁？”老杨头大哥的手顿了顿，缓缓收回，看着林一凡的眼睛：“是我。”林一凡愣住了。

“也是你。”老杨头大哥继续说，“门不是一扇，是一面镜子。你看到的人，都是你自己——或者说，你所有的可能里，选择最懒的那一种。你要见的那个人，早就站在你面前了。”

他说完，转身走向通道深处：“你手里的钉，想钉就钉，不想钉就留着。但提醒你一句——那根钉上，不止你和赵日天的名字。你再往下面刮刮。”林一凡低头，仔细看钉面。他用指甲从“林一凡”三个字底下用力一刮，锈屑簌簌落下，露出第三层字迹。字迹歪歪斜斜，像是被人用刀刻上去的，每一笔画都带着恨意。三个字：钱总。林一凡攥着钉的手几乎发白。钱总的名字也在上面。而且这一层最深，比他的还要深。

他想起了第三卷的AI考核系统，想起了第四卷老板钱总要收割他的摸鱼工作法，想起了第七卷的“资本神赌局”、第八卷老板变形记里的那个钱总。他以为钱总是后期大反派，是压迫型的老板。可他没想到，这根钉的最深处，钉着的名字是钱总。如果他当初没有摸鱼，如果他没有攒到咸鱼值，如果他没有在上辈子死掉——那被钉在这根钉上的人，会不会本来就是钱总？

老杨头大哥的声音从通道深处飘来：“你要不要猜一猜，铁皮壳子里那根钉，原本钉的是谁？”林一凡头脑嗡的一声响，像是被什么撞开了一扇门。那一瞬间，他忽然明白了很多事情，包括系统为什么偏偏选中他，包括他为什么能在猝死后重生到入职第一天，包括为什么他的代码注释里会有“门在门后，钉在钉里”这八个字，署着他的名——因为那是他“上一世、上上一世、上上上一世”的自己，在每一次循环里写下的密码，用来提醒这一世的自己：“你进来过，你在这里钉过钉，也逃过钉。每次你都是从这扇门里醒来的。”而钱方远的半条命从铁皮壳子里逃出去，带走的所谓“债务主体”，其实根本不是他的债务——那部分是他帮钱总担下的。钱方远用半条命带着钱总的债务跑了。

但钱总的债务，不是在外面。它在门里。在那一枚刻着钱总名字的青铜钉上。等着这扇门开的时候，一起还清。林一凡放下手里的青铜钉，慢慢地、一字一句地问：“那我现在钉进去……死的到底是谁？”通道深处，老杨头大哥的笑声低低地传来：“没人死。钉进去，只是换一扇门。”林一凡低头看着手心里刻着“钱总”的青铜钉，一咬牙，握住，对准了门缝里那枚青铜钉的后部——就在他靠近的一瞬间，门缝里的青铜钉突然自己松动了一寸。林一凡的脸一下子变了色。门缝里的钉在向外退。门要开了。而在那一瞬间，他听到了门内传来一声非常熟悉的冷笑——是钱总的声音。门缝里那枚青铜钉“咔”地一声，自己掉了出来，在地上打着旋儿。铜门内侧，一个苍老而阴鸷的声音缓缓响起：“你终于——来接手了。”林一凡手中的青铜钉，与地上那枚青铜钉，正好一左一右，并列躺在他脚边。他知道，需要选择一根。而门已经在开了。

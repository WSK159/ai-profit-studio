# 第302章 灰烬里的照片

地下手术室的灯光忽明忽暗，像垂死之人的心跳。

林一凡盯着被捆在铁椅上的灰工装男人，那句“是我抱你出来的”还在空气里回荡。沈稚冬站在他身侧，指尖微微收紧，目光在两人之间来回切换。

“你说你抱我出来——从太平间？”林一凡从口袋里摸出一根烟，没点，只是捏着。“那晚除了你和002，还有谁在场？”

灰工装男人笑了笑，脸上褶皱在灯光下像干裂的河床。“你觉得一个刚出生的婴儿，能从太平间活着出来？002是植入体，她不是医生，也不是护士。我能做的，只是把她和你一起塞进一辆破面包车，然后开到城南的老巷子。”

“你认识我妈？”林一凡蹲下身，与他对视。

“苏婉……是整个计划里唯一没有编号的人。”男人喉结滚动了一下，“她本来不该死的。”

磁带播放器安静地躺在手术台上，计数器停在“47”。林一凡瞥了一眼那数字，胸腔里有什么东西在翻涌。他刚想追问，口袋里的手机突然震了两下。他掏出来，屏幕亮着一条陌生号码发来的短信，没有文字，只有一个波浪线：

“~”

林一凡眉头一皱。又是这个符号。上回收到它时，是赵恒藏注射器被发现的那天。

“你手机借我一下。”他忽然转头对沈稚冬说。

沈稚冬愣了一下，还是把手机递了过去。林一凡没解锁，只是把陌生短信的号码输入拨号界面，按下拨打键。免提开启，“嘟——嘟——”两声之后，那头接了起来。

没有声音。只有一道极轻、极均匀的呼吸。

“我知道你是谁。”林一凡忽然说。电话那头呼吸一顿，但仍无人开口。林一凡压低声音，“你发‘~’给我，不是提醒我什么，是在告诉我——你看着我。我记得这个符号，我妈录的磁带里，第七段末尾，有指甲在桌面上轻轻划过的声音。那声音的节奏，跟这个符号一模一样。”

电话里终于响起一个沙哑的、像是许久没说过话的女声：

“你比你爸聪明。”

然后，挂了。

林一凡握着手机，静静站了三秒，随即猛地回头看向灰工装男人：“磁带里第七段的划痕声，是有人坐在我妈对面，对吗？”

灰工装男人的笑容第一次凝固了。他沉默了片刻，低声说：“那七天，苏婉不是一个人在录。有个人隔着一道墙，在听她说话。”

“谁？”

“她妹妹。”灰工装男人抬头，“苏婉的双胞胎妹妹——苏锦。002植入体的原宿主。当时所有人都以为她死了，但在那间太平间的另一头，她活着。太平间墙上有一道暗门，门后面是另一个房间。苏锦在那边待了九年。”

“九年……”林一凡瞳孔微缩。磁带录制是2019年，七年多前。如果苏锦在太平间暗门后的房间待了九年，那她一直在那里。从2017年到2026年。

“那她为什么不出来？”沈稚冬忍不住问。

灰工装男人低下头，两只手绑在铁椅扶手上，指尖微微颤抖：“因为她答应了苏婉一件事——守着那盘磁带，直到有人找到它。苏婉说，找到磁带的人，就能找到真正的陈建华。”

“没别的了？”

“还有一样东西。”灰工装男人看了一眼手术台的方向，“那台播放器里面，磁带B面没有录制内容——但如果你把它拆开，会看到一张照片。苏婉贴在人耳里侧的，戴着的时候没人会发现。”

林一凡大步走到手术台前，拿起播放器，三两下拧开背板螺丝。磁带仓旁边果然夹着一张小拇指盖大小的胶片，薄如蝉翼。他小心翼翼地抽出来，灯光下，胶片上是一张黑白的、略微发黄的合影。

照片上是两个女人。她们长得几乎一模一样。苏婉站在左边，微微侧着头，笑容安静又带一点狡黠。右边的女人比她年轻一些，眉头微蹙，手里攥着一把钥匙——那把钥匙的形状，林一凡再熟悉不过。

三叉钥匙。

他把胶片翻过来，背面用极细的钢笔字写着两行字：

“钥匙藏在老宅的墙洞。告诉他，去找010。”

林一凡的手微微一顿。010号钥匙——“命运归还”。

他刚把胶片收好，地下手术室入口的铁门忽然传来一声沉重的撞击。然后，是第二声。第三声。

“嘭——嘭——嘭——”

节奏均匀，缓慢，像是某种生物在用整具身体去撞那扇门。沈稚冬脸色骤变：“什么东西？”

灰工装男人忽然低声说了一句让林一凡背脊发凉的话：

“它醒了。你们惊动了楼上那个东西。”

铁门上的锈屑簌簌落下，门框在震动中发出咯吱咯吱的呻吟。

林一凡把胶片塞进内袋，转头看向灰工装男人：“你最好没骗我。不然——”

话没说完，铁门的中心位置忽然凸起一块，金属变形，露出一个拳头大的凹坑。门外，有什么东西在喘息。

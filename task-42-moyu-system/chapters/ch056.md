# 第56章 反客为主

林一凡没有理会宋远桥的警告，反而趁着系统时间偏移的窗口，进一步深入了那个伪造日志生成器。

他打开模板的配置层，看见了一串被硬编码进脚本的变量名：`hr_attendance_backfill`、`server_outage_manual`、`third_party_sync`。这些是用来解释“数据缺失”的标准借口，每一条都对应一个特定的假补录场景。

他心思一动，把它们全部选中，右键复制——但U盘的空间已经满了。他果断把U盘换成手机连接线，利用开发模式直接挂载了手机的存储。数据开始传输。

“林一凡。”一个低沉的声音在他耳边响起。

他抬头，宋远桥已站在他身边，手里端着一杯咖啡，神态安然。但林一凡注意到，他端着杯子的那只手上，戴着一枚银灰色的戒指——戒面上刻着半枚紫色纹路，和门禁卡上的半枚紫色指纹，似乎能对上。

“你知道我为什么来星辰吗？”宋远桥压低声音，“不只是当评委。”

“那你来干什么？”林一凡表面平静，手指却已悄无声息地按下了手机上的“快速备份”快捷键。

“来提醒你一件事。”宋远桥微微一笑，“你的摸鱼系统，和你看到的信息，未必就是全部的‘真相’。就像这台测试机，你以为你看到了它的全部，其实它被人换过主板。”

林一凡瞳孔一缩。

宋远桥没再多说，拍了拍他的肩，转身回到评委席。

林一凡立刻重新检查TEST-03B的设备信息。主板序列号与复赛设备分配表中登记的完全不一致——那台登记的主板ID应该是`STN-2026-37821`，但这台机器主板的ID是`ACN-2025-11044`。后缀44，是他重生那天——他猝死前最后的记忆节点。

这台机器，是被人特意换过的。宋远桥是在暗示什么？或者，是在转移他的注意力？

他不再犹豫，快速连断开发模式，将手机收进裤兜。就在他完成这些动作的同时，右前方那个壮实选手突然站了起来，举起自己的测试机屏幕：“各位评委，这台机器有异常——它的远程监控端口被占用了。”

全场目光齐刷刷看向林一凡——因为他的TEST-03B屏幕上，正闪着一个可疑的TCP连接请求。

那台机器，居然刚刚从林一凡的机器向秦氏主服务器发起了外联，请求指令是：`full_access_audit`，访问授权等级——最高级。

“有人动了我的机器。”林一凡冷静起身，“我可以现在演示Wi-Fi嗅探，看看到底是谁在中途给这台机器插了脏包。”

宋远桥坐在评委席上，放下咖啡杯，没有再说话。但那枚银灰色戒指在灯光下闪了一下，半枚紫色纹路仿佛在说：游戏才刚刚开始。

林一凡握紧口袋里那串密钥。他大概知道锁在哪儿了——锁，就在宋远桥自己身上。

# 第163章 纸上的经纬

凌晨的写字楼后巷，风像刀片一样刮过水泥地面。林一凡攥着那张从老王手里接过来的纸，纸边已经被他捏得发皱。上面只有两行字，第一行是一串坐标字母和数字，第二行是日期，正是今天。

“这不就是经纬度吗？”林一凡低声说，手指在手机屏幕上敲了一下，坐标转换结果出来——城南工业区，东七街，一个叫做“旧锅炉房”的地标。他抬头看向季敏，她已经退到路灯照不到的暗影里，半边脸被墨镜遮得严严实实。“这地方是交给我们去还是？”

“你不是接了隐藏任务吗？”季敏说，声音压得极低，像在防着什么监听。“第二把钥匙在‘老朋友’手里。你身边那位叔，心里有数。”

老王站在墙角，双手插兜。他这人平时好说话，但此刻嘴唇抿成一条线，微微发抖，不是冷的。林一凡认识他三年，只在裁员那次见过他这种表情。

“走吧，一凡。”老王开口了，声线出乎意料地稳，他看向季敏，“你安排得够久了，剩下的是我们的事。”

季敏没再多说，从口袋里掏出一张无记名公交卡丢给林一凡：“三点如果没到咖啡馆，就当我没救过你们。”话毕，她人已经消失在拐角，步伐轻盈得像没沾过地。

林一凡深吸一口气。系统的提示在脑海中浮现——

【隐藏任务·黎明前的交易】
阶段二：抵达坐标地，拿取“第二把钥匙”。
时限：今夜 04:00 前。
完成奖励：解锁系统第 48 层，新技能“反卷护盾·进阶”。
提示：该地点已被标记“高危险”。

“高危险”三个字像一盆冷水泼下来。他看向老王：“叔，这‘老朋友’……靠谱吗？”老王侧过头来，神色复杂得像打翻了一锅调料：“靠谱不靠谱，都得到。你认识我的时间也不短了，有没有听我提过，我以前在城南待过？”

“没有。”

“因为我谁也没提过。”老王说着，推开巷子口那扇铁门，门外的马路上停着一辆落满灰尘的黑色老款轿车，引擎竟然是热的。

林一凡正要上车，手机屏幕忽然一亮，是一条加密消息。他没有备注，但那种冷冰冰的语气他在前一条匿名短信里已经领教过了。消息只有六个字：“锅炉房的陷阱。”点发送者的头像，什么都没有——空白名片，不存在的人。

“老王，有人提醒我们这是陷阱。”林一凡把手机递过去。老王扫了一眼，没有停下打火的动作：“我知道，那边本来就是陷阱的地基。”

车子发动，路灯光一帧一帧地划过车窗。林一凡盯着窗外，脑子飞速运转。季敏把钥匙交给老王，又留给他坐标，还将第二把钥匙的信息写在纸上，这套动作太严密了，更像是一次提前演练好的交接流程。而钱总的“你输了”和这条“陷阱”警告，两个方向的消息同时到来，仿佛有第三只手在拨弄棋盘。

车行二十分钟，拐进城南工业区。东七街果然偏僻，路灯坏了半片，只剩一盏在远处嘶嘶作响，把“旧锅炉房”四个斑驳的霓虹字照得鬼气森森——不对，那四个字压根不是普通霓虹灯管拼的，更像某种由镭射纸和旧灯泡手工搭出来的障眼法。老王缓缓将车停在对面街沿，熄了火。

“叔，你那位老朋友，是什么路子的人？”林一凡压低了声音，目光扫向锅炉房门口那扇半掩着的铁门。铁门后透出一线微光，里面有人在活动的动静。

老王的右手按在方向盘上，指节发白：“他曾是星辰科技最早期的架构师，后来又走了。你知道他为什么不干了吗？因为他发现公司有高层在替‘某样东西’做事，而他自己，也被那东西标记了。”

林一凡心里猛地一沉：“你说的是……钱总那边？”

老王转过头，眼神在暗光里变得荒凉而笃定：“比钱总更高。你那个系统，我可能知道它是从谁手里出来的了。”他伸手拉开车门，冷风灌进来，“走吧，进去见‘老朋友’。”

林一凡刚下车，裤兜里的手机再次震动。他看了一眼，还是匿名号码，但这次消息只有一个坐标——和他手里纸上写的一模一样。发送者补了一句：“他从里面出来，就开着这辆黑色轿车。”

他猛地抬头看向老王的方向。老王已经走到铁门前，正推开那扇门，锈迹碾过的声音在午夜格外刺耳。林一凡忽然觉得，自己每一步都踏在别人编排好的节拍上。

门内的光晃了一下，有人声传出来，苍老却熟悉：“老王，你还带了小朋友来。”

林一凡瞳孔一缩——这声音，他在哪里听见过？

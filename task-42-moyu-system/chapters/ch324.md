# 第324章 防空洞之约

林一凡盯着孙满仓手里的黄铜钥匙，喉咙发紧。那钥匙的齿纹与钱总办公室抽屉里的一模一样，连柄端那道细微的划痕都如出一辙。

孙满仓站在防空洞入口的阴影里，灰布衫被风掀起一角，露出腰间一个磨得发亮的旧皮套。他约莫五十多岁，一张脸像被岁月犁过的旱地，皱纹里嵌着说不清的疲惫。他没有走近，只是举起手里的钥匙，在暗淡的天光下晃了晃：“里面的东西，你打开了？”

林一凡下意识把白纽扣攥进掌心，没答话。周立冬上前半步，挡在他身前，语气平淡：“孙叔，您等了这么久，不进来坐坐吗？”

孙满仓沉默了几秒，转身走进防空洞。脚步声在混凝土墙壁间回荡，他走到第三级台阶前蹲下，没有看那个被撬开的黄铜匣子，而是从怀里摸出半支没滤嘴的香烟，却不点，只放在鼻子底下嗅：“这地方，三十年前我跟你妈最后一次说话，也是在这儿。”

林一凡胸口猛地一抽：“我妈？沈稚冬？”

孙满仓没答，却把钥匙往匣子锁孔里一插，轻轻一转，“咔嗒”一声。他抽出钥匙，翻过面来，指腹摩挲钥匙柄上的锈迹：“这钥匙有两把。一把给你妈，一把给我师父——沈临渊。”

他顿了顿，终于抬眼看向林一凡：“你是沈临渊的儿子，对不对？”

林一凡脑子嗡了一声。周立冬也变了脸色：“孙叔，这跟我们查到的不一样。沈临渊是林一凡的……”

“叔叔。”孙满仓接过话，“墓碑上写的是叔叔，对吧？但你看过你妈的这本信。”他指了指林一凡另一只手里的信件，纸页边缘微微卷曲，“她说‘父亲死于第三年祭日’，可你从小到大祭的，都是沈临渊的坟。”

防空洞里的空气像凝成了水，凉且重。林一凡低头看向信封上母亲的字迹——娟秀清瘦，每个笔画都收得极紧，像在写字时也咬着牙。他重新读了一遍那句“你父亲死于第三年的祭日”，忽然眼眶发酸：“所以……沈临渊是我爸？那那个被我喊了二十多年的‘叔叔’……”

孙满仓把手里的烟折断，塞回怀里：“不该你知道的事，有人不想让你知道；该你知道的事，我守了二十五年，也该说了。”

一阵风从洞口灌进来，吹动铁门发出刺耳的“吱呀”声。周立冬的手机突然震动，他低头瞥了一眼，脸色骤变，把屏幕转向林一凡。

屏幕上是一条新彩信，拍摄时间显示在一分钟前——画面里，一道灰袍身影站在防空洞入口上方，逆光看不清脸，但他手里握着一只白色棒球帽，帽檐正对着防空洞入口方向，像是在确认什么。

林一凡猛地抬头望向洞口，没有人影，只有风卷着落叶擦过台阶。他回头看向孙满仓，发现老人也从怀里摸出了一只白色棒球帽，帽檐内侧缝着一枚铜扣，上面刻着一个“沈”字。

“这帽子，是你妈失踪前三个月寄给我的。”孙满仓说，“她说，如果有一天有人戴着白帽子来找我，就说明她出事了。”

他缓缓把帽子戴上：“现在，它是不是该还给她了？”

林一凡盯着那顶帽子，手里母亲的信件被汗浸湿一角。他正要开口，防空洞深处忽然传来一声极轻的金属碰撞声——像是有人在更深处，也摸了一下墙壁。

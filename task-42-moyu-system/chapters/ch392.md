# 第392章 归墟之下

石室里的空气骤然凝滞。男孩把那张泛黄的图纸摊在地上，指尖划过三条通道的标注线，声音却比谁都稳：“水牢主通道被潮汐机卡死了，废矿道出口离咱们最近，但要穿过一段灌满水的管廊。”

林一凡蹲下身，盯着图纸上那个圆圈标记——正位于归墟入口下方约三十米处，标注着“水牢”两个字。沈临渊就被锁在那里，呼吸着地底潮湿的空气，整整三年。

“潮汐机是怎么回事？”周满囤抹了一把脸上的泥水问道。

“老水塔下面的进水闸机，被沈临渊用钢筋混凝土封死了，只留了一条缝。”男孩抬头，目光落在林一凡脸上，“要是能把闸机撬开，海水倒灌回水牢，水位一涨，锁链松了，‘零’就能自己出来。”

三叔猛地拍了下大腿：“那就干！老杨头撬门是一把好手，小林子懂机械，我跟你下去！”

“不行。”林一凡摇头，指腹压在图纸那条虚线管廊上，“这条管廊走积水，人得潜水过去，三叔你肺活量扛不住。”他转头看向周满囤，“你水性怎么样？”

周满囤咧开嘴笑了，笑得有些苦涩：“以前在地质队，泡在矿井里三天三夜都没事。”

老杨头没说话，默默把撬棍别在后腰，动作利落得像年轻了二十岁。林一凡注意到老人袖口下露出一截旧伤疤，形状像是被什么东西狠狠咬过——他来不及多想，口袋里的铜片突然烫了一下。

他摸出来，铜片背面的字迹竟然变了。原本的“归墟之底，潮汐为锁。无钥之日，笼开人亡”那行字缓缓褪去，新的笔画从金属深处浮出来，像是被某种力量唤醒：

“潮是一切的钥匙。”

林一凡怔在原地。他想起泵房捞起铜片的那条暗渠，水流的方向，恰恰是从山体内部向外涌出的——也就是说，这枚铜片一直在归墟潮汐里浸泡着，此刻才真正“激活”？

“走。”他把铜片塞回口袋，率先踏出石室后门，脚步落在湿滑的石阶上，发出沉闷的回响。

石阶往下走了约百级，空气里的咸腥味浓得刺鼻。通道尽头出现一道铁门，锈迹斑斑，锁孔呈五角星形状——与铜片的轮廓截然不同。林一凡皱眉，正要问男孩图纸上有没有标明这扇门，却见齐磊——钱总带来的那个壮汉——站在门外，手里提着水泥袋和铁锹。

“你们还真敢往里走。”齐磊冷笑，把水泥袋重重砸在地上，“钱总说了，归墟只进不出。你们要么自己关进去，要么我帮你们把门砌死。”

周满囤跨步上前挡在最前面，拳头已经攥紧。林一凡按住他的肩膀，望着齐磊的眼睛，轻声问：“钱总给了你多少钱封口？”

齐磊愣了一瞬，脸色微变。

“两百万？”林一凡看他的反应，继续道，“还是说，他答应你事成之后，让你接管整座山的……”

“你少在这儿胡说八道！”齐磊脸色涨红，抡起铁锹劈下来。

林一凡早有准备，侧身闪过，同时从口袋里掏出那枚发烫的铜片，正对着铁门上的五角星锁孔——铜片边缘忽然延展出薄如蝉翼的金属丝，像活物一样探入锁孔深处，“咔哒”一声，锁开了。

所有人都愣住了。包括男孩，包括老杨头。老杨头嘴唇翕动，低声吐出两个林一凡没听过的字，像是某种方言的咒语。

铁门缓缓自动敞开，门后是一片漆黑，海水的腥气裹挟着一股陈旧的铁锈味扑面而来。黑暗中，有金属链条拖拽地面的声响传来，一下，又一下，缓慢而有节奏，像是某种生物在永夜的囚笼里重复着巡走。

林一凡感觉到影子微微晃动——是第四道影子。他的影子，长出了不属于他自己的轮廓。

那一瞬，他忽然意识到：归墟深处锁着的，可能不止沈临渊一个人。

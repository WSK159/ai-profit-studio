# 第71章 断电前夜

两点零三分，窗外城市灯火依旧，星辰科技的服务器机房却迎来了黎明前最深的寂静。

林一凡把三块硬盘锁进公司储物柜最底层的保险箱里，密码是老王女儿生日——这件事，整个公司只有老王那个老实人不会多问一句。

手机屏幕亮起，钱总的群消息用红色置顶：【周六 00:00-06:00 全楼停电升级，各部门配合迁移数据，任何人不得逗留，违者按泄露商业机密处理。】

“按泄露商业机密处理。”老王盯着屏幕，手指微颤，“这就是冲你来的，一凡。”

“是冲硬盘来的。”林一凡把咖啡杯搁下，脑子里盘算着二百一十五点咸鱼值还能兑换什么，“电源改造是真的，但断电后消防梯的监控会跟着重启，那段时间足够他们做很多事。”

沉默几秒，老王压低声音：“物业那边我认识一个值班哥，周五晚上换班，明早我请他喝酒。”

“老王。”林一凡看他，“这事儿可能把你搭进去。”

老王摆摆手，从抽屉里翻出一盒降压药，又塞回去：“我这半辈子，就学会一件事——老实人也有肝火。”

周五白天一切照旧，只是下午三点，IT部门通知全楼升级系统，每人电脑要重装“效率检控插件”。林一凡点开安装后的界面，熟悉的进度条突然停滞在百分之三十七，弹窗跳出一行字：

【摸鱼系统·安全模块已拦截恶意追踪程序，类型：A类行为采集器。来源IP：内部。预计周六凌晨自动化上传数据。】

林一凡后背一紧，把弹窗截图发给赵日天的空号——自然没人回复。他打开系统面板，把仅剩的215点咸鱼值全部投入“反卷护盾·静默模式”，持续时长：12小时。

“你确定全投进去？”系统提示音难得带了一丝人性化的迟疑，“护盾解除后，你将进入完全裸奔状态，任何摸鱼行为都会被监测。”

“保命要紧。”林一凡关掉面板，“再者说，周六凌晨不在工位上摸鱼，算什么摸鱼？”

二十三点五十九分，整层楼的灯连闪三下，然后整栋大厦陷入黑暗。

应急灯亮起昏黄的光，监控摄像头指示灯全部熄灭又重启。林一凡站在三楼消防楼梯拐角，手里握着一根从机房拆下的备用网线，耳机里是老王粗重的呼吸声：“电梯监控重启需要七分钟，比你算的多两分钟。”

“够用。”林一凡贴着墙根向机房屋走去。

机房门锁着电子密码锁，林一凡刚掏出王老头天塞给他的备用磁卡，身后传来一声轻笑：“就猜你会来。”

他猛地回头——走廊尽头，赵日天双手插兜靠在应急灯下，嘴角挂着熟悉的欠揍笑意：“带我一个，哥们儿。”

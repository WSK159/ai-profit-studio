# 第153章 老王的另一面

密室门外的老王，脸上挂着一个我从未见过的笑容。

那个笑很淡，像是什么事都没发生过的平静，又像是等这一刻等了很久的从容。我记忆里的老王，永远是那个被加班熬得眼底发青、说话带着三分疲惫三分无奈的老实人。可现在站在门口的他，背挺得笔直，眼里没有一丝倦意。

“林一凡，你找到的东西，比你以为的多。”老王的声音很平静，“但你知道的东西，还不够。”

我攥紧手里的加密日志，下意识往后退了半步。宋顾问……不，老王怎么会在这里？这条维修通道是宋顾问带我来的，知道我进来的人应该只有宋顾问和赵日天。可老王站在这扇本该只有我知道的密室门口，说他等着我出来。

“王哥……”我试探着开口，“你跟踪我？”

老王摇了摇头，目光落在洞口深处那台还亮着灯的终端机上：“M-013，原名王建国，十五年前是星辰科技的资深架构师。退休前最后一个项目，就是参与AI考核系统的底层架构设计。”

我整个人僵住了。

王建国……老王的全名。加密日志里那位“老鱼”M-013，留下规则修改记录的前任摸鱼者，就是此刻站在我面前的老王？

“系统后门被人手动修改的那天，”老王的声音低下去，“是十五年前M-013进入B3A层的第二天。改完规则的人，就是我。”

他从口袋里掏出一枚半旧的工牌，上面印着一行褪色的编号：M-013-A。编码末尾那个“A”我认得，在日志里反复出现过，那是“Admin”的缩写。

“你是系统管理员？”我感觉自己声音发干，“不对……你是前任宿主，还是……”

老王没有直接回答，只是朝走廊深处看了一眼，忽然压低了声音：“赵日天马上会来。他已经查到你进了B3A层，带着AI考核中心的权限卡。如果你不想被他当场抓到，现在跟我走。”

他转身迈步，走了几步又停住，侧过脸露出一丝苦笑：“对了，你那套‘摸鱼工作法’，我其实在你入职那年就试过。但赵日天……是个例外。他那个系统的后台，我用管理员权限也查不到。”

老王的手电筒光在幽暗的走廊里晃动，我站在原地，看着他的背影，脑中无数念头翻涌。

他是老鱼，是管理员，是知道系统所有秘密的人。那他为什么要告诉我宋顾问的线索？为什么要让我来发现这些日志？

老王像是感应到我的迟疑，在黑暗里又开了口：“林一凡，你想知道摸鱼系统真正的样子吗？那就跟我来。但你得先明白一件事——宋顾问让我带你来这里，和今晚让我来等你，是两个人，两件事。”

“宋顾问让你等我？”我追了上去。

老王没有回答，他推开一间标注“配电间”的暗门，里面的墙壁上，密密麻麻钉满了纸页。

我靠近一看，每张纸都是打印的日志片段，时间跨度从十五年前一直排到今天。而在最顶端那张纸上，用红笔圈着一行字：**“系统重置倒数第1316天”**。

“这是……”我瞳孔一缩。

老王把那张纸撕下来，翻到背面，上面写着一排手写的数字，接着他抬头看着我的眼睛，低声说：“重置那天，就是系统在999天前被修改规则的同一天。林一凡，你和我，都活在被修改过的规则里。”

他话声刚落，走廊尽头的金属门被人从外面轰然推开，一声冷喝传来：“老王！你果然在这里。”

我回头，看见赵日天站在逆光里，手里握着一部正在发出刺耳警报的手机。而那警报声的来源，正是我口袋里那张老王刚递给我的纸片。

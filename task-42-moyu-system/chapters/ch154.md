# 第154章 追踪与反追踪

警报声刺耳而尖锐，赵日天拿着手机冷冷盯着我手中的纸片，那上面电子脉冲信号正在跳动。老王倒是很镇定，甚至还笑了笑：“日天，你来得正好。我其实想让你也看看这个东西。”

赵日天狐疑地走近几步，我趁机把纸片翻到正面。上面那排手写数字，我一眼就辨认出格式——那是系统的“宿主编号”格式。“这不是我的编号。”赵日天瓮声瓮气地说。

“对，所以你能猜到是谁的吗？”老王轻轻叩了叩墙壁上某张日志，“十五年前，M-013曾经做过一件事：他用自己的管理员权限，把某个人的宿主编号从系统数据库里抹掉了。方法是在宿主协议上动手脚，让对方本人也以为，自己从未绑定过系统。”

赵日天瞳孔猛然收缩。他低头看了看自己的手背，又看了看老王，声音有些发颤：“你什么意思？”

老王抬手，把那排数字指给他看，最后两位恰好是“07”。赵日天的手背在那一瞬间青筋暴起，我记得他左手背上有块疤，现在那片疤下泛起了一行浅浅的、近乎肉色的痕迹——那正是宿主编号浮现时的样子。

“你的编号，两百多天才亮一次。”老王的声音很轻，“但你自己可能都忘了，你第一天入职星辰科技的时候，曾经有一周的手背比别人的黑。”

赵日天脸色一阵白一阵青。他张了张嘴，什么都没说出来，手机里的警报声忽然停了，屏幕上的坐标点跳成一个熟悉的名字——会议室“效率厅”。

“不是追踪我们的。”老王的神色忽然沉下来，他快步走到配电间门口，把耳朵贴在门缝上，片刻后回过头，“外面有人，不止一个。脚步声是防刺靴的节奏，星辰科技安保队。”

“安保队怎么会来B3A层？”我皱眉。

“因为这间配电间的警报线，连的是AI考核中心的应急通道。”老王指着墙上那条走线，“有人手动触发过应急警报。”

我和赵日天同时抬头——彼此都露出领悟和戒备的神色，随即赵日天率先发问：“宋顾问？”

老王没有点头也没有摇头，只是低声道：“他引你来，引林一凡来，引爆警报，让三个人在这里碰头。你们还觉得，他是我的人吗？”

走廊外面已经传来靴子踏在金属地面上的闷响。老王从暗格中抽出三件反光背心：“穿上。安保队不搜穿背心的，也不拦去应急通道的人。”

赵日天沉默着接过背心。老王看我一眼，把那排数字纸折好塞回我手里：“留着。去找宋顾问的时候，给他看这个，他会再告诉你一件事。”

我攥紧纸片，在安保队的脚步声逼近之前，跟着老王从配电间侧门钻进了应急通道。黑暗里，赵日天忽然开口，嗓子有些哑：“老王，你当年做管理员的时候，见过几个人绑定过摸鱼系统？”

老王沉默了好几秒，才在黑暗里回答：“两位。M-013是第一位。第二位是我不确定的——因为那个人只用过一次系统就被清除了，连编号都没来得及生成。”

“那个人叫什么？”

“宋。”老王的声音像是在水里浸过，“他只告诉我一个字。但我查了十五年前的离职档案——当年失踪的架构师里，恰好有一个姓宋的。”

通道尽头透出一线灰白色的光。老王推开防火门，A区办公楼的楼道里，早班的闹钟声正此起彼伏地响起。

宋顾问站在安全出口处，左手端着两杯豆浆，看见我们三个从应急通道里钻出来，只是微笑着偏了偏头：“早啊，三位。系统今早更新了版本，有一条新规则，我猜你们还没看到——”

他把手机屏幕翻转过来，上面显示着一行系统弹窗：

**“宿主身份合并程序已启动。检测到同源宿主两名，要求于三日内完成宿主编号归并。未完成者，系统将自动执行全局清零。”**

而屏幕最下方，那个发起方的落款显示为——“宋”。

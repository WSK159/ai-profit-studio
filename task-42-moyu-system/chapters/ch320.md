# 第320章 双面

林一凡盯着那张与孙满仓一模一样的脸，后背的冷汗缓缓收干。他扶着天台边缘的栏杆，指尖因为按得太紧而泛白。

“你——”他张嘴，声音却意外地稳，“你到底是谁？”

灰雨衣人站在梓树旁，手里把玩着那枚刚被林一凡从排水管里取出的黄铜钥匙。钥匙在他指间翻转，发出清脆的碰撞声。他没有回答林一凡的问题，反而低头嗅了嗅钥匙，像是在闻一件许久未见的老物。

“沈稚冬的手笔。”他说，“第九枚，也是最后一枚。”

林一凡的瞳孔骤缩。他下意识地攥紧了自己的怀表，金属外壳硌得掌心生疼。

“孙满仓呢？”他问，“你把他怎么了？”

灰雨衣人终于抬起头，嘴角牵起一丝弧度。那一刻，林一凡终于看清了两人的区别——孙满仓说话时右眉会微微上挑，而这个人不会。孙满仓的眼神浑浊，像是熬了太久夜的老程序员；这个人的目光却透亮，像鹰。

“孙满仓啊。”灰雨衣人把钥匙收进自己口袋里，慢条斯理地说，“他活着。只是暂时不能见你。”

“为什么？”

“因为他把不该说的，说了。”

林一凡的呼吸一滞。那半句没说完的话——最后一条没找到的，不是——此刻在他脑海里翻来覆去地滚动。他看着眼前的灰雨衣人，忽然想到了什么。

“你才是一直盯着我们的人。”他说，“短信是你发的？还是孙满仓发的？”

灰雨衣人不答，反而侧身望向园区的方向。楼下传来警笛声，由远及近。他叹了口气，像是惋惜被破坏的宁静。

“林一凡，”他说，语气骤然沉了下来，“你手里的怀表，和你父亲怀里的那块，是同一种东西。你父亲的字，刻在你那块的背面。”

林一凡下意识翻开怀表，背面光滑，什么字也没有。

“但你这块的‘沈’字，被别人磨掉了。”灰雨衣人像是看穿了他的心思，“磨掉它的，是你母亲。”

林一凡猛地抬头。

灰雨衣人指了指天台边缘那棵梓树：“沈稚冬说‘第九个在梓树东南第七步’，那是给孙满仓的暗号。但孙满仓不知道的是——第十个，她放在了梓树根下三米的地方。她没告诉任何人，除了你母亲。”

天台上的风突然大了起来，林一凡的衬衫被吹得猎猎作响。他盯着灰雨衣人，嘴唇翕动。

“你敢说你是‘钱总上面的人’？”他低声问，“那你为什么，对这棵梓树的位置……这么清楚？”

灰雨衣人沉默了三秒。

然后他缓缓伸手，从自己的衣领里拉出一枚挂坠——黄铜的，老旧的，与林一凡的怀表同款，但背面清楚地刻着一个“沈”字。

“因为沈稚冬，”他说，“是我妹妹。”

林一凡的大脑一片空白。

“我姓沈。”灰雨衣人往前迈了一步，夜灯照亮他的半张脸，“沈临渊，你父亲——沈稚冬的亲哥哥。”

天台边缘的砖缝里，有一枚黄铜钥匙的圆头，在路灯反光下微微闪烁，好像有什么东西，正要破土而出。

林一凡的喉咙发干，他张了张嘴，却发现自己什么声音也发不出来。他低头看着自己的怀表，光滑的背面，被磨掉的“沈”字仿佛残留在金属里的一道暗影。

“你……是我叔叔？”他终于挤出一句话，声音沙哑。

沈临渊没承认，也没否认。他只是静静地看着林一凡，目光里有一种说不清道不明的东西，像是愧疚，又像是怜悯。

“孙满仓告诉你，你从出生起就是沈稚冬的退路。”他说，“这句话是真的。但没说完的部分是——沈稚冬安排这条退路的时候，还没怀孕。”

林一凡心跳漏了一拍。

“她是在安排了你之后……才怀上你的。”沈临渊眯起眼，“她在你出生前，就已经认定你会成为她的退路。你不觉得这很奇怪吗？”

警笛声更近了，天台边缘的旧铁皮屋摇晃起来。

林一凡的思绪轰然炸开——沈稚冬安排退路时，尚未怀孕；但孙满仓口中林一凡的出生，却是他母亲的决定。那么，沈稚冬真正的“退路”，到底是指向“林一凡这个人”，还是指向“林一凡注定会被她利用”这一事实？

“你到底想说什么？”林一凡问。

沈临渊却退后一步，那道锐利的目光低垂了下来。

“你想知道‘第十个’在梓树根下的什么位置吗？”他岔开话题，声音平静如水，“三米深，在树根东南角的裂缝里埋着一只铁盒子。盒子里装着一组坐标。坐标指向的是，你母亲死后、你出生前，沈稚冬藏起来的东西。”

“什么？”

“她自己的尸体。”沈临渊说完，转身走向天台边缘。

“但那个……得你自己去挖。”他的身影消失在夜色中，最后半句话像风一样飘了下来，“你确定，你想挖出来？”

林一凡站在原地，愣了很久。手中的怀表忽然变得极沉，像压着一条人命。他低头看去，光滑的背面竟映出一行细小的字——光线变化间才勉强可辨——“第九个不是埋着的，第十个……是。”

“第十个……是她本人。”

他猛然抬头，沈临渊的身影已经消失在天台边缘。警笛声冲进园区大门，一束强光打在天台围栏上，把林一凡的影子拉长得像一具竖起的棺木。

他攥紧怀表，嘴里发苦。梓树根下三米埋着的东西——他忽然想起老王说过一句话：有人把死人埋在最深的地方，不是为了藏，是为了让她再被挖出来的时候，吓所有人一跳。

“这墓，得挖。”他低声说。警笛声中，他转身走向楼梯口。

# 第321章 三米的土是凉的

林一凡回到出租屋时，天还没亮。老王的呼噜声从里屋传出来，周立冬坐在客厅茶几旁，盯着那枚带“沈”字的黄铜钥匙出神。听见门响，他头也不抬：“挖完了？”

“没挖。见了个人。”林一凡把自己扔进沙发，闭上眼睛，“一个自称叫沈临渊的人。”

周立冬手指一顿，抬起头来：“……沈临渊？”

“你认识？”

“沈稚冬的哥哥，我在档案里见过这个名字。”周立冬放下钥匙，声音有些变化，“他是整个‘归’项目里，唯一一个被记录为‘不配合’的人。别人都上交了资料，他没有。”

林一凡睁开眼：“他为什么不配合？”

“因为他是唯一一个知道沈稚冬‘后手’的人。”周立冬说，“他拒绝把那个后手交出去，也因此被调离项目组。之后，钱总的记录上就不再出现他的名字了。”

林一凡沉默了一会儿，又问：“那他现在在哪里？”

周立冬苦笑：“所有记录中，他最后一次出现在公开记录里是十五年前……在做‘替身’训练教官。”他顿了顿，“替身训练基地，就是咱们旧园区那栋楼的负一层。”

林一凡从沙发上坐直了身体。一个念头像闪电一样劈开脑海——如果沈临渊是替身教官，那当年孙满仓在天台上被打断的话“最后一条没找到的，不是——”或许指的不是某样东西，而是某个人。

“周哥，”他说，“沈稚冬，会不会根本就没死过？”

周立冬没有回答，但他的手微微颤了一下。

“你今天跟我说这句话的后果，你清楚吗？”周立冬低声问。

“清楚。”林一凡说，“但我要去挖。”

周立冬看了他三秒，然后站起来，从床下拉出一个工具箱，扔到他脚边：“走。”

旧园区大门紧闭，但周立冬摸出一张老旧的员工卡，在侧门的识别器上刷了一下，门锁咔嗒弹开。

“十五年前的卡，居然还有效。”他低声说。

两人绕过主楼，直奔那棵梓树。月光被云层遮住，只有远处路灯的光影斑驳地落在地面上。周立冬掏出折叠铲，选了东南方向，从树根边缘开始往下挖。

三米的深度，两个男人换着挖，足足挖了快一个小时。泥土从湿润变得干硬，又变得冰凉。铁锹碰到硬物的声音传来时，林一凡的手一颤。

“有东西。”他说。

周立冬蹲下来，戴上手套，徒手刨开最后一层土。淤泥中露出一只锈迹斑斑的铁盒——不是普通的铁盒子，是军队制式的防潮密封盒，棱角方正，边缘包着黄铜条。盒盖上刻着一个“沈”字。

两人对视一眼。林一凡将盒子起出来，在水洼里冲洗干净，翻过盒底。背面刻着一行小字——被泥土腐蚀得斑驳，但依稀可辨：

“三米的土是凉的，比人心凉不了多少。”

林一凡的手指轻轻抚过那行字，像是在触碰一段被埋藏了十五年的往事。他深吸一口气，撬开盒盖。盒内垫着一层厚厚的防潮油布，油布下裹着的东西——不是文件，也不是U盘，而是一沓黑白照片，和一枚老式的录音磁带。

照片最上面一张，是一个穿着军装的年轻女人，站在一辆吉普车前，身后是望不到边的大漠黄沙。她的眉眼很英气，但嘴角却带着一丝疲惫。林一凡的手指——这是他母亲。

“这……”他嗓子发紧，“这是我妈。”

他又拿起第二张，脸就白了：同一辆吉普车前，同样的角度，站着的却是另一个女人，和他母亲长得一模一样——不，是同一个人，只是衣服换了，发型换了，眼神从疲惫变得凌厉。两张照片的拍摄时间，标注日期是同一天，相隔不到一小时。

“同一个女人，一天之内换了两个身份……”周立冬皱眉。

林一凡没接话，他把照片放在膝盖上，翻开第三张、第四张、第五张——全是同一个女人，不同的衣服，不同的表情，不同的场景，但每一张都标注着同一天的日期。最后一张，那个女人穿着白色的病号服，躺在窄仄的病床上，脸上带着一种古怪的平静。照片背面写着一行字：

“最后一次扮演：沈稚冬之死。”

录音磁带静静地躺在照片下面，像一颗哑了壳的子弹。林一凡拿起磁带，在手里捏了很久，终于塞进周立冬翻出来的老式随身听里，按下播放键。

磁带的沙沙声里，传来一个女人的声音——清冷、平静，像在念一份操作手册：“我沈稚冬，于十五年前起，以沈稚冬身份执行‘归’任务最后一次行动。行动完成后，我将以‘死亡’为代号正式退场。自此世上再无沈稚冬——日后林一凡若寻来，请在梓树根下掘出此盒，告诉他：‘母亲没有死过，沈稚冬，也没有来过。’”

磁带播放到结尾，发出一声轻轻的叹息。

林一凡坐在坑边，愣愣地看着手里的照片。他的母亲没有死？沈稚冬根本没有来？那当年由他母亲亲自主持的那场“葬礼”，到底埋的什么人？他想起沈临渊在天台上说过的话：“第九个不是埋着的，第十个……是。”

“沈稚冬的第十个……”他低声说，“是她自己。”

周立冬沉默地递过一根烟。林一凡没接，他站起来，看向眼前那棵老梓树的树冠，风一吹，哗哗作响。

“她在等我来挖她。”他握紧那枚磁带，声音轻得像自语，“不是挖她的墓……是挖出真相。”

远处天边泛白，旧园区的轮廓在晨光中渐次清晰。林一凡不知道的是，在园区门口的早点摊旁，一个戴着白色棒球帽的男人正举着手机，镜头聚焦在他和他手里的铁盒上，轻轻按下快门。

照片推送出去，备注只有两个字：“已核。”

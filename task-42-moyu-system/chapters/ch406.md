# 第406章 空壳

铁皮壳子胸口第二锁眼裂开的那一瞬间，井底的水面忽然静了。

静得连一滴水珠坠落的声音都消失了。林一凡盯着那个漆黑的空腔，瞳孔微缩——锁眼内部什么都没有，此前那些纠缠交错的锁链、蜷曲的青铜符文、甚至那半张写着钱方远债务的残契，全都不见了踪影，只剩下内壁上一道道新鲜的刮痕，像是有什么东西挣扎着离开时留下的爪印。

“他的半条命……走了。”孙满仓的声音从身后传来，带着一种林一凡从未听过的复杂情绪——像是释然，又像是恐惧。

林一凡没回头。他伸手探入锁眼内壁，指尖触到那些刮痕的瞬间，一阵刺骨的寒意顺着指骨窜上肩膀。那不是普通的冷，而是一种“被注视”的冷，仿佛有什么东西刚刚从这里爬出去，此刻正在井壁之外的某个角落回头看着他。

“钱方远欠的债呢？”林一凡问，“我把担保人换成自己，债务去哪了？”

孙满仓沉默了片刻，从怀中掏出那张早已泛黄的合同残页。林一凡接过一看，上面的字迹正在发生变化——原本写着“债务对象：钱方远，代持人：孙满仓”的位置，如今只剩下两个行字：

“担保人：林一凡。债务对象：空白。”

林一凡眉头一皱：“空白？”

“债还在，但对象跑了。”孙满仓的声音沙哑，“那半条命从锁眼里逃出去之前，把债务主体也一起带走了。你现在的角色……是帮一个不存在的债务人背债。”

他顿了一下，补充道：“债主会找到你，然后让你把它交出去。”

林一凡冷笑一声，将合同残页折好塞进口袋。“那就让它来找我。”

他没有多说，而是转身望向头顶——那根从井口垂下来的青铜锁链还在轻微晃动，像是刚刚被什么东西擦过。他记得上一世，或者说记忆中那个模糊的梦里，这井底不止一条出路。沈望未白发人之前说的那句“你若承他人之债，须以命相抵”还在耳边回荡，但奇怪的是，他并没有感觉到任何被锁定的压迫感。

他低头看了一眼自己胸口的白骨纹章，数字依旧是28，但轮廓上多了一圈淡金色纹路，像是新烙上去的封印。

“沈望未白去哪了？”林一凡问。

孙满仓摇摇头：“他替你烙完警告之后就走了，往上走的。估计是去找你那个‘同伙’了。”

林一凡心里一紧。齐磊之前说过，沈望未白是在归墟外围出事的，而那一晚钱总出现在锁灵界附近的时间点，恰好和沈望未白的失踪吻合。如果沈望未白现在主动往外走——他是在追那半条命，还是在追钱总？

他来不及多想。铁皮壳子左胸第一锁眼上的青铜片忽然发出一声极细的碎裂声，林一凡回头，看见那道裂痕又扩大了一寸。隐约间，从裂缝里飘出一丝淡灰色的烟雾，凝聚成一个模糊的人形轮廓——五官看不清，但姿势是弯着腰的，双手向前伸，像是在推一扇门。

林一凡心头一震。这个姿势他见过。

在图纸的第二十七号标记点上，那条被反复描深的折线尽头画着一个同样的弯腰人形。他之前一直以为那是某种标识符号，直到此刻看见烟雾凝聚出的轮廓一模一样，才意识到那不是符号——是提示。

“孙满仓，”他快速转头，“图纸上第二十七号点旁边有没有写坐标？”

孙满仓愣了一下：“第二十七号？那张图纸不是在你身上吗？”

林一凡一愣，伸手摸了摸怀里的口袋。图纸还在，但展开之后他发现——原本画的二十七号标记点旁边，不知何时多出了一行极细的字迹，不是他写的，也不是老杨头的笔迹。

那行字只有五个字：

“门在头顶上。”

林一凡猛然抬头。井口处，刚才还在晃动的青铜锁链此刻已经静止了，而在锁链顶端与井沿连接的位置，一只苍白的手指正从石缝中探出来，指甲缝里嵌着黑泥，缓缓地、无声地朝井底缩了回去。

林一凡瞳孔骤缩——那根手指他见过。更准确地说，是在锁芯女人的手指画像上见过。那枚银戒指的位置、弯曲的弧度，一模一样。

孙满仓也看见了，他后退半步，嘴唇哆嗦了一下：“她……她醒了。”

林一凡攥紧图纸，胸口的白骨纹章发烫起来。

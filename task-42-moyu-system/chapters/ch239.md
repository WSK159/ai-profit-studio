# 第239章 那把钥匙

陈默的手指悬在那枚鸟形钥匙上方三厘米处，没有触碰。舱室里的顶灯只有一盏亮着，发出偏黄的冷光，将她的影子拖得很长。

“你确定这是你家的钥匙？”赵日天问，他靠着门框，双手抱胸，视线在林一凡和陈默之间打了个来回。

陈默点头：“我十岁那年就见它插在父亲书桌左边第二个抽屉的锁孔上。我试过很多次，拧不动。”她停顿了一下，声音低了几分，“后来我才知道，那枚钥匙不是开抽屉的，是抽屉底板上嵌着一个凹槽，它只是被放在里面。”

林一凡的注意力却不在钥匙上。他的目光落在笔记本那一页“她长得真像她妈妈”的笔迹上——墨迹很新，新到像是昨夜才写下的。他伸手想碰那张纸。

“别动。”老王忽然开口，嗓子里像是塞了一团砂纸。他站在舱室最靠里的角落，手指指向笔记本旁边一枚几乎看不见的透明线材，极细，在灯光下折射出一丝金属光泽，“这页纸底下压着一根线，连着笔记本封底。”

林一凡缩回手指。

陈默听见这话，脸色微变，侧过头沿着老王指的方向仔细看。片刻后她的眼瞳微微缩起：“这是LX系列的监听线。我爸在笔记本里嵌过这个东西……我只在他的工作笔记上见过设计图。”

“所以这本笔记本，”林一凡的声音很轻，“被监听过。”

舱室里的空气凝固了一瞬。

赵日天忽然嗤笑一声，打破了沉默：“行了，都走到这儿了，还有什么不能说的。你爸在负六层待了多久？”

陈默直起身，看着那枚鸟形钥匙：“他最后一次‘常驻’是三年四个月。对外说去海外技术交流，实际上，每周三晚上十一点半，他会通过内部信道给我发一条加密消息。前两年是工作心得，后一年……只有四个字，重复了十二次。”

“哪四个字？”老王问。

“别进六层。”

这句话落下的瞬间，通道尽头传来一声沉闷的金属撞击，像是某个很重的东西从高处砸了下来，又像是一扇门被猛然关上。四人同时僵住。林一凡的摸鱼雷达毫无声息，雷达范围之内没有任何“劳动浓度”的信号——但那声音分明就在七十米以内。

“它醒了。”赵日天的声音冷静得反常。

他转身面朝通道出口的方向，右手摸上自己工牌裂缝的位置。那裂缝里的蓝色荧光比刚才更亮了一线，像是某种感应。他嘴里说着“它醒了”，唇角却微微翘起，像是等了很久。

“你早知道下面有什么。”林一凡盯着赵日天的背影说。

赵日天没有否认。他侧过头，从工牌边缘抽出那枚A-000芯片，指尖用力一捻，芯片边缘有什么东西被挤开，露出一条极细的暗槽——形状弯曲，像一只鸟展开翅膀。他看了那暗槽一眼，随即抬头看向陈默，目光落在她手边的那枚鸟形钥匙上。

“你没发现吗，”赵日天说，声音带着一种说不清道不明的意味，“你家里那枚钥匙，和A-000芯片的暗槽，是同一把。”

陈默的手猛地握紧。

林一凡看见她指节发白，也看见赵日天眼底一闪而过的蓝色光点——和他的工牌荧光一模一样的颜色。他往前走了一步，挡在陈默和老王面前，问赵日天：“你怎么知道那暗槽的形状？你以前见过这把钥匙？”

赵日天沉默了三秒。

然后他从内衬口袋里掏出一张折得四四方方的纸，纸张边缘泛黄，背面印着星辰科技内部信笺纸的专属水印。他将纸展开，上面是一个手绘的草图：鸟形钥匙的正面、侧面、剖面，比例尺标注得极其精确，右下角有一行钢笔字——同一个笔迹，和笔记本上陈建国的手写一模一样：

**“别让她开这把锁。”**

陈默看到那行字，脚步晃了一下。她认得这个笔迹，比笔记认识得更深——那是她父亲写在她小学三年级数学作业本上的同款钢笔字。她的声音沙哑：“这张纸，你哪来的？”

赵日天没有回答。他抬起头盯着通道尽头黑暗中传来的又一声闷响，眼皮跳了一下，把那枚A-000芯片重新嵌回工牌裂缝。

“时候到了。”他说。通道尽头传来一声三长两短的叩击——快跑的讯号。

而这一次，陈默的脸彻底白了。

“那个频率，”她说，“是我爸的固定求救频率。他，只用过一次。”

林一凡看着通道深处那无边的黑，像看着一张已经张开的巨口。他听见自己的心跳声在胸腔里重重弹了一下。然后他迈出一步，朝声音的方向走去。

老王在身后喊他名字，他没回头。

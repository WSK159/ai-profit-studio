# 第44章 代码里的暗雷

那句话在屏幕上停了不到三十秒，就被沈敛撤回了。

撤回得干干净净，像从没发过一样。但林一凡已经看清楚了，每个字都刻在脑子里。

“别让赵日天在复赛里碰到你写过的任何一行代码。”

他合上手机，尽量让自己的呼吸平稳下来。赵日天还坐在工位上，键盘声依旧密集。林一凡打开自己桌面上那份效率大赛初赛时使用的PPT文档，里面还存着他整理的D3-B1区块访问异常数据分析。

如果赵日天用的是沈敛的电脑，而沈敛的开发者内测版系统具有某种数据复制或学习能力……那么，赵日天是否能读取到他这台电脑上的文件？

林一凡伸手，把U盘从主机侧面拔出来，揣进裤兜里。然后他打开电脑的加密磁盘，将自己的核心项目文件复制到云端私密空间，再把本地的原始文件原地删掉——替换成一份他另外准备的“干扰版本”。

做完这一切，他看了眼时间：凌晨一点十七分。

他没急着走，反而泡了杯速溶咖啡，坐在原地。

二十分钟后，他观察到一个细节。赵日天起身去接水，从他工位旁经过的瞬间，扫了一眼林一凡的屏幕。那一眼很快，快得像是不经意的余光，但林一凡的摸鱼雷达捕捉到了赵日天视线停顿的位置——不是屏幕中央，而是右下角。

那里刚刚弹出一条系统通知：“文件已在本地加密存储。”

赵日天走远了，林一凡确定自己没看错，刚才赵日天嘴角有个几乎不可见的弧度。

他等到凌晨两点，才背着包离开工位。出大楼的时候，夜风灌进衣领，他打了个寒颤，脑子却清醒得很。

第二天一早，效率大赛复赛的题目在九点准时公布。

“用星辰科技的现有数据平台，48小时内搭建一个自动化运营诊断模块，要求能自动识别异常流程并输出优化建议。演示环境由总部提供，参赛者使用指定电脑。”

指定电脑。林一凡在接到通知的那一刻，眼神冷了下来。果然。复赛的演示环境不让用自己的设备，这就在形式上杜绝了带外部文件进场。但沈敛说的“别让他碰到你写过的代码”这句话，就更耐人寻味了。

如果赵日天在使用沈敛的电脑时，已经拿到了某种系统级别的数据复制权限，那他的环境可能不止赵日天一个窗口。那台电脑里可能有一个“后门”，能通过星辰科技内部的网络注入恶意代码，在复赛环境中“借用”他林一凡写过的内容。

林一凡没有再等沈敛回消息。他走进了十七层的尽头那间储物间，把门反锁，坐下，然后打开了系统面板。

「当前咸鱼值：8,720。可兑换项目：反卷护盾升级版（1,500）、代码溯源模块（2,000）、深度解析提升（1,200）……」

他目光扫过商城列表，找到了一个此前没注意过的选项——“反向追踪锚点”。说明写得很简短：“可为一个指定代码文件设置追踪锚点，当该代码在其他设备中被调用时，可实时定位调用位置及调用者。”

林一凡没有犹豫，花了2,500咸鱼值买下这个功能，然后从兜里掏出U盘，把复赛准备用的核心代码副本上传到系统私人空间，锚点直接绑定。

他刚做完这一切，储物间的门突然被敲响。

“林一凡？你在里面吗？”是老王的声音。

林一凡打开门，老王满脸紧张地压低声音：“我刚收到通知。复赛的演示环境，是由总部战略部统一搭的虚拟桌面，每个人的桌面环境都一样，但——”他咽了口唾沫，“今天早上，赵日天申请调换工位，换到了你斜对面那台机器。”

林一凡背靠着门框，沉默了三秒后问：“什么时候安的？”

“上午刚换的，”老王压低声音，“他搬过来的时候，自己带了一根网线，说是无线信号不好。”

林一凡低下头，嘴角缓缓勾起一个弧度。那根网线，怕不是用来插电脑的。他抬头看了一眼赵日天的方向——那个人正坐在新工位上，面对屏幕，背影笔直。头顶的卷气值纹路，又亮了一分。

他掏出手机，给沈敛发了一条消息：“我看到那根网线了，你欠我一次解释。今晚八点，东城咖啡，你必须来。”

这次，沈敛秒回了两个字：“会来。”

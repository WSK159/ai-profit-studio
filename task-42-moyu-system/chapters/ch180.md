# 第180章 活板之上

林一凡没有开灯。

走廊的声控灯在他进门时已经灭了，屋里只留着台灯那点昏黄的光，反倒让天花板上的阴影显得更浓。那声“咔哒”之后，屋里安静了很久，久到林一凡数了整整六十秒的心跳，才确认头上没有再传出第二个声音。

他搬了把椅子到那个角落，踩上去，小心翼翼地伸手推了推天花板的石膏板。第一下没动，第二下，板子边缘出现了一条细缝——它完全可以移动。他改用指腹贴着缝往外推，石膏板在极轻的“吱呀”声里滑开了一掌宽的距离。板子后面不是吊顶龙骨和灰尘——是黑漆漆的一层空间，深得不像一栋普通出租屋的楼板层。

林一凡伸手进去，摸到一根冰凉的金属杆。他抓着那根杆子往外抽了一截——是一把梯形铜钥匙，比普通钥匙粗了两倍，厚度接近半枚硬币，表面没有任何开齿的痕迹，只有顶端一个凸起的圆钮，像锁孔的形状反转了过来。

他愣了几秒，低头看了一眼图纸。图纸上活板的位置画着一个方形槽口，旁边一行极小的字写着：“压锁，不是旋锁。”

林一凡的手心微微发汗。他把那把梯形铜钥匙对准头顶的槽口，慢慢推了进去——没有旋转，只是用力往下按。

“咔哒。”

一声沉闷的金属咬合声从顶楼方向传来，像某个联动机关被触发。他脚踩的椅子和天花板之间连着无声的震动感，仿佛整栋楼的骨架都紧了一下。

然后，他的手机响了。

屏幕上跳出一个陌生号码，他犹豫了一秒，还是接了。

电话那头是赵日天的声音，比上次急促得多：“林一凡！你是不是动了那个开关？！”

“你怎么——”林一凡刚开口就被打断了。

“别他妈问我怎么知道的！”赵日天气息很重，像在边跑边说，“你现在头顶上方往东三米的位置，有一根贯穿五楼到天台的水管管道，管道里缠着一条铁链，链子另一端连着天台蓄水池的底阀——你按下那个开关，等于把蓄水池的排水阀拉开了！”林一凡额头上冒出一层细汗：“什么鬼设计？”

“因为那个隐藏空间不是顶楼！它在你脚下！”“什么？”林一凡低头看向地面。

“图纸是倒着画的！”赵日天声音近乎嘶吼，“你以为它在天花板，其实它在地下——蓄水池排水阀一开，水会灌进那个密室，把里头的东西冲走！”他话音未落，出租屋地板底下传来一阵异样的轰鸣，像水流灌入空腔的声响。

林一凡猛地从椅子上跳下来，趴到地上，耳朵贴着冰冷的水泥地面。他听见了水声，清晰的、大量水涌进封闭空间的声音，然后是金属碰撞的清脆响声，像什么物件被水流裹挟着撞击四壁。他站起来发狠推了一下天花板板子——已经推不动了。

“操，我按错了！”他对着手机喊，“那个图纸上画的根本不是顶楼活板，是负层机关——老王把图纸倒过来看才有意义！”

赵日天在电话那头沉默了整整三秒：“……如果水已经灌进去了，那就别急着追了。”

“那王叔留给我的东西——”

“我有另一条路。”赵日天的声音突然压低，“明天早上六点，天桥底下见。我用我自己的‘权限’带你下去。”

电话再次断了。

林一凡握着那把已经失去作用的梯形铜钥匙，站在这间出租屋中央，低头听着地板下水声逐渐平息——像有什么秘密被彻底浸泡了一样。

他视线落在墙角那箱老王的旧物上，最上面一张纸条被台灯光照得发黄，上面只写了一行字：“如果你按下了那个开关，说明你已经找到了其中一把钥匙。接下来你要找的，不是第三把钥匙——是那把锁本身。”

林一凡捏着纸条，慢慢吐出两个字：“锁本身？”

他忽然想起了那条陌生短信的话——“真正的开启者，不是拿钥匙的人，是造锁的人。”造锁的人……老周。老周如果真的死了，那把真正的锁，又在哪里？

窗外，天边泛起一线蛋清色的微光，快到黎明了。

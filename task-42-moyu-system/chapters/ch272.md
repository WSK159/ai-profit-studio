# 第272章 四十八小时

林一凡攥着那本《命运归还》操作手册，沿着负二层走廊快步前行。手电筒的光柱在潮湿的墙面上晃动，映出他紧绷的下颌线。

赵日天的话还在耳边回荡——不到48小时。

“归还”一次，一切清零。七年的记忆，七年的技能，七年里攒下的所有咸鱼值，包括摸鱼系统本身，都将被抹去。换回的是那个2019年刚入职的自己，一个没猝死、没重生、没绑定系统的普通程序员。

——但是，会失去林一诺留下的所有线索。

他停在一根承重柱旁，翻开手册第三页。泛黄的纸页上写着：“第000号钥匙持有者确认执行后，当前时间线全部因果链断开重连。所有记忆、能力、系统状态将回归至2019年6月3日0点0分0秒。执行窗口：午夜零点起十分钟内。”

他看了眼手机，23:07。

不到一个小时。

林一凡深吸一口气，将手册塞回公文包。赵日天说计时已经开始，但没说从什么时候算起。如果从激活钥匙那一刻起算，那零点前就是最后的窗口期。他还有不到53分钟做决定。

手机突然震动，是老王来电。

“林儿，你在哪？”老王的声音压得很低，“钱总带人往地下车库那边去了，说是有安防警报。你搞什么了？”

“老王，我问你个事。”林一凡的声音出奇平静，“如果有一个机会，让我知道林一诺当年到底经历了什么——但代价是我忘了你们所有人，你还会让我去吗？”

电话那头沉默了三秒。然后老王笑了：“你这话问得，好像你忘了我们，我们也会忘了你似的。去呗。反正你就算忘了自己姓什么，我也能让你再想起来。”

林一凡鼻子一酸。

“对了，”老王补了一句，“赵小满刚发消息说她到楼下了，好像有急事找你。”

赵小满。姐姐。

林一凡挂断电话，快步走向电梯。他刚按了下行键，一双手从背后拍上了他的肩膀。

“弟弟。”赵小满的声音带着急促，“你拿到钥匙了？”

林一凡猛然转身。赵小满站在走廊尽头，手里提着一个黑色保温桶，额头上全是汗。她的眼神很复杂——带着一种他从未见过的焦急。

“你怎么知道钥匙的事？”林一凡下意识后退一步。

“这事说来话长。”赵小满朝他走近，“但我得在零点前告诉你一件事——关于你妹妹留给你的另一样东西。”

她打开保温桶，里面只有一张叠得整整齐齐的纸条。纸条上，林一诺娟秀的字迹：“凡哥，如果你看到这张纸，说明你找到了钥匙，也说明你正在纠结要不要使用它。别用。那是个陷阱。000号是用来骗你的，真正能换回记忆的钥匙是010号——赵日天手里那把。他等这天等了十年。”

林一凡怔在原地，手里的手册“啪”地掉在地上。

“赵日天……他等的？”他脑子里像是有两颗炸弹同时爆炸，“所以他说什么‘不是来阻止你’、‘计时开始’——”他猛然抬头，“全是在引导我？他在催我跳坑？”

赵小满点头，语气颤抖：“陈和平的二十年，赵恒的十年……你应该已经发觉这条时间线索有问题了。赵日天十年前认识了林一诺，那时你妹妹正好在做第000号钥匙的植入手术。他一直在等一个时机——等你把000号激活，整个时间线重置，他就能用010号把你的记忆替换进他的系统里。”

“替换？”

“他想要你的摸鱼系统。”赵小满说，“卷王系统的规则是——吞噬一个同级别的系统宿主，就能继承对方全部力量。”

林一凡只觉后背发凉。他低头捡起手册，翻到最后一页。果然，最后一页夹着一张小字条，和赵小满带来的那张笔迹一模一样：“别用000，用010拿回真相。”

字条的末尾，有一行几乎被磨掉的铅笔字：

“凡哥，能救你的只有赵小满。信她。”

走廊尽头，电梯门“叮”地一声打开。

钱总带着两个保安走了出来，目光直直落在林一凡和他脚边摊开的手册上。他的嘴角勾起一个久违的、资本家的笑：

“小林，快零点了。这是你最后一次做选择的机会——”

他指了指林一凡身后的暗门方向，“帮你妹妹把钥匙交给我。或者，让一切结束。”

林一凡攥紧纸条，余光扫向赵小满。她微微点头，眼中是近乎决绝的笃定。

他知道，零点前的这几分钟，决定的不只是他的命运，还有那条被隐藏了七年的真相线。

而赵日天，已经在黑暗里，等着最后时刻的降临。

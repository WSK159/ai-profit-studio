# 第339章 死过一次的人

面包车从巷口滑过之后没有再回来。林一凡的呼吸却迟迟没有平复。孙满仓那句话像一块石头砸进了平静的水面，涟漪一圈圈扩散。

“你说赵日天死过一次，是什么意思？”

孙满仓没直接回答。他把地图折好，塞回牛皮纸袋里，扔到林一凡腿上。“你爸当年下山时，在云顶山脚见过一具尸体。表面是坠崖摔死的，但肋骨有一道直切伤，是利器。警方认定是采药人失足，但你爸说不是。”

“赵日天的父亲是收尸的人。”

“他师弟去认的尸，回来之后，赵日天就从一个普通程序员变成了卷王。”孙满仓嘴角牵了牵，“你不觉得蹊跷吗？一个人三天之内从‘摸鱼混日子’变成‘一天干完一周活’，搁谁身上都像换了个人。”

林一凡心中剧烈震动。他记得赵日天初到星辰科技那天的模样——双眼赤红，像三天三夜没睡过觉，但精神亢奋得可怕。那不是正常人能有的状态。他当时就觉得系统波动异样，但没深究过。现在想来，赵日天背后绝对不止是“卷王系统”那么简单。

“你父亲当年让我查过一件事。”孙满仓从口袋里摸出一块老式手机，屏幕碎了一角，他点开相册，翻出一张照片，递给林一凡。画面里是一张泛黄的报纸剪报，标题是“云顶山脚发现不明死者，警方初步认定为采药失足”，配图是一张模糊的黑白照片，只能看出一个人形轮廓，脸部被圆珠笔圈出来。

林一凡盯着那张脸，瞳孔猛地一缩。

那张脸的轮廓——他认识。他上辈子加班的最后半年，每天都能在公司走廊里看到这张脸。那是钱总办公室里一个从不说话的安保，姓王，大家都叫他王叔。但这张照片的拍摄日期是五年前，而王叔出现在星辰科技的时间，是两年前。

时间对不上——除非王叔跟赵日天一样，也死过一次。

“你父亲当时说了一句话。”孙满仓的声音低了下来，“他说‘云顶山脚下埋的不是死人的东西，是活人的秘密。’”

林一凡胸口一紧，之前所有零散的线索——父亲留下的磁带、陶土徽章、三把钥匙、钱总办公室的铁网夹层——在这一刻突然拧成了一条绳子。所谓的“归还自由”任务链，可能根本就是一场围绕云顶山的争夺。他父亲进山送的不是普通东西，而是某种能让人“死而复生”或“获得系统”的源头之物。

“孙叔，”他开口的声音有些沙哑，“你为什么要现在告诉我这些？”

孙满仓沉默了一会儿，然后说：“因为昨晚有人去找过沈望，让他别再管林家的事了。今天早上，沈望没接电话。”

林一凡脊背一阵发凉。“沈望怎么了？”

“不知道。”孙满仓把手机收回口袋，“但是送信的人开着一辆和你公司logo一模一样的车。”

系统提示音再度响起——

“警告：检测到宿主重要关联人物‘沈望’生命体征异常——位置信号中断于城东老工业区，最后坐标已标记。是否启动追踪？”

林一凡没有任何犹豫：“追。”

他要知道沈望现在怎么样了。他没有别的选择了。

孙满仓打火挂挡，车身猛地蹿出小巷。引擎的轰鸣声在狭窄的街道里回荡，像一头发怒的野兽。

林一凡攥紧陶土徽章，心中默念：父亲，你到底在云顶山埋了什么？

系统的提示无声地闪了一下——

“唯一性物品共鸣反应：47%。”

一切才刚刚开始。

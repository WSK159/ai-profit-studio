# 第59章 第三幕的入场券

林一凡关掉手机屏幕，指尖还残留着凌晨三点那几个字的寒意。他把手机塞回裤兜，扫了一眼周围的混乱——秦氏科技复赛现场已经炸了锅，几个人围在宋远桥刚才站过的门口叽叽喳喳，说话的内容不外乎“密钥是真是假”“模板到底谁做的”“那个调试信号器哪来的”。

陈哲凑过来，压低声音：“那玩意儿我拍了照，出库记录的截图也留了。但宋远桥刚才那句话——”

“他说模板是假的，密钥是真的。”林一凡重复了一遍，脑子里飞速转着。宋远桥这话不像撂狠话，更像是在有限条件下能给出的最大程度提示。模板是指复赛题目模板？那东西如果是假的，秦氏复赛从题目到素材就全都是幌子。密钥呢？秦氏主服务器里那扇门，要用密钥才能打开。

赵日天还在三米外的工位边上站着，脸色白一阵青一阵，嘴里嘟囔着“跟我有什么关系”。林一凡用摸鱼雷达扫了他一眼，赵日天头顶的“劳动浓度”数值在疯狂跳动，那是情绪剧烈波动的典型表现，但雷达上没有任何攻击性技能激活的光晕。这家伙要么真不知情，要么演技好到连系统都骗得过。

林一凡倾向于前者。

“现在最要命的是，”陈哲看了一眼走廊尽头，安保正在往这边走，“咱们的监控追查和出库记录，按理说该递给裁判组了。但宋远桥那话一撂，谁敢接这个烫手山芋？”

两个人正低声说话，手机又震了一下。林一凡低头，是陌生号码发来的第二条短信，这次只有一串字符：

`TEST-03B / 04:22 / 密钥有效期剩余47分钟`

林一凡瞳孔骤然收紧。TEST-03B是他重生那天在体检报告上看到的主板序列号尾缀，而04:22正是他重生回来的精确时间。这条短信的主人不只是知道他的行踪，连他重生的时间点都算得清清楚楚。

“谁发的？”陈哲探头。

林一凡没回答，转身就往电梯间走。身后陈哲喊了两声，他没回头，只丢下一句：“帮我把场子里的事兜住，就说我出去找信号器对应的工位去了。”

电梯门合上，林一凡的脑子开始高速运转。

宋远桥说的是“下次见面希望你还活着”，这是警告，也是预告。而这条短信直接甩出了两个残酷精确的时间戳，这是入场券，告诉他：第三幕现在才真正开始，你必须主动走进这个棋局。

他低头看手表——离密钥失效还有四十三分钟。如果短信说的密钥就是秦氏主服务器上那扇门，而现在服务器就在这栋楼上，也就是说，他必须在这四十三分钟内找到那扇门、输入正确的密钥。

问题是：密钥是什么？

他掏出手机翻到之前从宋远桥口中套出的那句警告——“模板是假的，密钥是真的。”这句话在现在这个语境下有了新的含义：模板是假的，意味着复赛现场所有明面上的线索都不可信；密钥是真的，则意味着藏在暗处的那扇门确实存在，而且密钥早已出现在他们的视野里。

林一凡猛地停住脚步。

出库记录上的调试信号器编号——宋远桥留在门口的那把钥匙——门禁卡上残留的指纹——戒指的紫色纹路——还有赵日天工位上那台被伪装成攻击源的设备MAC地址后六位……

他掏出手机，把脑子里的数字串到一起。信号器编号是以`TEST-03B-0422`开头的，门禁卡指纹对应工号尾号也是0422，赵日天那台设备的序列号最后六位，同样是04220422。

而他现在所在的楼层，是秦氏B座的独立机房层，门牌号恰好是——B-17-0422。

林一凡抬头，面前那扇厚重的铁门上贴着一张磨损的标签，上面印着“设备维护间”，但角落的位置，有一个只有离近了才能看见的、非常淡的紫色条纹，和他戒指上的那枚纹路几乎一模一样。

电梯间里传来脚步声。

林一凡没犹豫，把戒指摘下来，对准门禁感应区贴了上去。电流嗡的一声，金属门锁轻响，门缝里泄出一道冷白的光。

他推门进去，身后传来一个沙哑的声音：

“你果然能找得到这里。”

林一凡回头，看到一张他认识的脸——坐在轮椅上、双手叠放在膝盖上的，是三个月前就从秦氏“因病离职”的前技术部总监，刘维。

他手里把玩着一枚和林一凡一模一样的戒指，紫色纹路在灯光下微微发亮。

“第三幕，”刘维开口，语速很慢，“我等你很久了。”

门在他身后缓缓合上，发出沉闷的金属声。

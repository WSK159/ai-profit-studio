# 第381章 铁皮柜里的胶卷

林一凡没有在泵站里打开铁皮柜。他需要更亮的地方，更需要能让他保持清醒的空间。沈稚川带他们从第三泵站的一条侧道穿过去，绕了将近十分钟的路，穿过一段堆满废弃管材的狭窄甬道，最后来到一间只有几个平方的设备间。

设备间里有一盏老旧的吊灯，拉绳开关，灯管上积满了灰，但拉亮之后灯光还算稳定。墙角放着一张折叠桌，桌面上的油漆已经磨得斑驳，还有半杯干涸的茶水痕迹，看上去是沈稚川平时休息的地方。

林一凡把铁皮柜放稳，蹲下身，指尖沿着柜门内侧那块方正的补丁边缘摸索。焊点均匀，打磨光滑，如果不是事先知道这里面藏着东西，他绝不会多看第二眼。

“需要工具撬开吗？”赵日天站在门口，背靠门框，一直在观察走廊里的一举一动，警惕这个地下空间可能出现的任何声响。

林一凡摇了摇头，指尖发力。焊点周围的金属像是什么特殊合金，在他手指按压下去的那一瞬间，居然发出了一声极轻的“咔嗒”，随即整块补丁朝内翻开来——它根本就是一块内藏暗扣的挡板。

挡板后面是一个方形的凹槽。凹槽正中，安静地躺着一卷已经冲洗好了的胶卷底片。边缘微微泛黄，岁月在上面留下了细小的折痕，但外层的保护纸袋依然完整。

纸袋正面，用蓝色圆珠笔写着一行字：零七四。

旁边画了一个小小的圈，圈里面写了一个“29”。

林一凡盯着那个“29”，脑海中某根弦微微震动了一下。29岁。他猝死的时候，正好是29岁。

“底片上有三十一张。”沈稚川从门口走进来，手里端着一杯凉水，放在桌上，“她拍了三十一张。前面三十张，都是人脸。最后一张，是空帧。”

“空帧？”

“她留给你的提示。等你看到那帧空的，就知道下一张该拍什么了。”

林一凡小心地把胶卷从纸袋中抽出来。底片是黑白照，透过光看，卷与卷之间密密麻麻的影像像一条沉默的河流。他找到光源，将底片凑近吊灯，一张张看过去。

第一张：一个穿着厂服的年轻人，坐在食堂里，碗里装满米饭，正在用筷子夹菜。他的眼神平静，没有任何表演痕迹。

第二张：一个中年女人，站在窗边，一只手搭在窗台上，似乎在望着远方。她的五官轮廓让林一凡心里一动——“她认识我。”

第三张：一个小男孩，蹲在地上玩弹珠，旁边有一只黑白花猫蹲着看。

林一凡一张张往下看。每一张脸都是陌生的，但每一张脸又有一种说不清的熟悉感。不是长相上的熟悉，而是那种从骨子里透出来的、某种被安排过的痕迹——他们都在同一个厂区生活过。他们都被沈稚冬记录下来。

“这三十张脸，都是外部载体吗？”林一凡问。

沈稚川点点头：“当年被她记录过的，全部参与过‘转移’的人。他们有的还活着，有的已经死了，但这些脸，是打开第三扇门的基础。”

林一凡数到了第二十九张。那是一个年轻男人的侧脸，站在厂房外的水管旁，正低头看什么。男人的轮廓让他瞳孔猛地一缩——那是他自己。确切地说，是重生之前的那个自己。他穿着某家公司的工牌服饰，面容疲倦，眼底有浓重的青黑。那是他加班到最狠的那个时期，整个人像一张被揉皱的纸。

第二十九张。

他重新翻回去，仔细数了一遍——不对，刚才他数漏了一张。第二十八张是一个戴口罩的女人，第二十九张是戴口罩的男人的背面，二十张后面才是他的侧脸。

他手上的动作停住了。

“第二十九张，”他回头看向沈稚川，声音有些发涩，“里面那个人——戴着口罩，我看不清他。”

“你看不清楚正常。”沈稚川说，“他本来就是这个计划里最不该被看见的人。”

“他是谁？”

沈稚川没有立刻回答。他走到桌前，拿起那杯水，喝了一口，然后说：“看清第三十张的时候，你就知道了。”

林一凡把目光移到第三十张。胶卷的倒数第二帧。

一个老人站在云顶山的山腰处，背着手，身后是一条通往山顶的石阶小道。老人微微侧着头，像是在对镜头之外的人说着什么。尽管角度很偏，但那张脸还是清清楚楚地暴露在光线下——林一凡的瞳孔剧烈收缩。

那是王叔。

是那个在云顶山上失踪多年的王叔。是那个在多重记忆碎片里反复闪现、始终与归零装置纠缠在一起的王叔。是他之前在云顶山隧道里见过的那具尸体——那具躺在岩层里、身份成谜的尸体。但此刻，镜头里的王叔是活的。他站在云顶山半山腰，面带微笑，手里握着一样东西——一把黄铜色的钥匙，形状与钱总办公室夹层里那把一模一样。

“王叔是第几张？”林一凡的声音有些沙哑。

“第三十张。”

“那他是……”

“最后一位外部载体。”

沈稚川说完这句话，看了一眼泵机方向，又转回来看向林一凡，眼神平静得像一潭死水：“那个黄铜钥匙，你见过对不对？”

林一凡没有否认：“钱总办公室的夹层里，有一把一模一样的。”

“那钥匙开的东西不在钱总手里。”沈稚川说，“它开的，是云顶山第三扇门底下的匣子。匣子里放的不是物件，是一个人的自由。”

赵日天一直安静地听着，此刻终于忍不住开口：“谁的？”

沈稚川转头看他：“你母亲的。”

赵日天脸上的表情，像被一条线割开了似的，从平静猛地裂了一道口子：“你说什么？”

“你母亲当年不是主动离开的，”沈稚川一字一顿地说，“她是被取代了。”

林一凡手心里的胶卷边缘被他捏得微微卷曲。第三扇门后的“你的备份”，铁皮柜里的三十一张底片，王叔手里的钥匙，赵日天母亲的身份——这些线索像一台被打乱的拼图，终于开始浮现出完整的图景。

而归零装置加载条上那个缓慢跳动的增长百分比，像是某种倒计时——有人已经开始往那个方向去了。

门外，设备间深处传来一声几乎无法被听见的、机械齿轮咬合转动的“嗡——”。那声音不是泵机。泵机已经停了。那是另一种东西。

沈稚川的脸色第一次变了。

“不该现在启动的，”他压低声音，“有人已经到了。”

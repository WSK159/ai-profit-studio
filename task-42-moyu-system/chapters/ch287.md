# 第287章 走廊尽头的女人

林一凡的瞳孔猛地收缩。

走廊尽头，那道身影逆光而立，轮廓模糊，但声音却像一根锈钉，狠狠扎进他的耳膜——那是他母亲的声音，是他听了二十六年、又在七年前戛然而止的声音。

“你妈没有死。”

这句话不是对面说的，是那道身影说的。

第000号植入体——那个顶着林一凡脸的“人”——在他身后轻轻笑了一声：“看，我说了，你要见的人在门外。”

林一凡没有回头，他的目光死死锁住走廊尽头那个人。三步，五步，那人开始走动。鞋跟敲击地面的声音在封闭的走廊里格外清晰，一声一声，像是倒计时。

“妈？”

他嗓子发紧，声音干得像砂纸。这是他重活两世以来，第一次说出这个字。

那人走得更近了。光线从她背后渗过来，终于描出了她的轮廓——微卷的齐肩发，深蓝色的风衣，左耳一枚银质的耳钉。和记忆里的母亲一模一样，甚至比记忆中年轻了十岁。但林一凡注意到了最细微的差异：她走路的姿态不对。母亲习惯左手插兜，右臂微摆；而眼前这个人，双臂自然下垂，步幅均匀得像被刻度尺量过。

“你认出来了。”那人停在三步之外，低头看了他一眼，语气平淡得像是通报天气，“你不笨。”

“你是谁？”林一凡的手已经握紧了掌中的三叉钥匙，金属边缘嵌进指腹。

“这个问题，你该问它。”她偏了偏下巴，指向他身后第000号植入体。

第000号植入体从门内探出半个身子，那张与林一凡一模一样的脸露出一丝古怪的笑意：“我叫零零零，是林一诺在七个冬天前写下的代码。她告诉我，当真正的你走到这里的时候，就是我要告诉你真相的时候。”

“什么真相？”

“你妈确实没有死。”零零零说，目光越过他，落在走廊尽头那个女人的身上，“但你妈也不再是她了。”

林一凡皱眉。走廊尽头的女人笑了笑，从口袋里掏出一块老式怀表——银色外壳，表盖上刻着一个“凡”字。那是林一凡七岁那年，母亲生日时他攒了三个月零花钱买的礼物。她当着他的面打开表盖，表盘上的指针正在飞速倒转，每一秒都在后退一格。

“这枚表，是你送我的。”她说，“但时间不是这样走的。”

林一凡的呼吸一滞。他看到表盘上的日历数字从“2026”跳到“2019”，又跳到“2014”，最后停在“2003”——那是他出生的年份。

“你是谁？”他第三次问出这个问题，声音却沉了下来，因为他心里已经有一个答案。

女人的嘴角弯起一个弧度：“我是林一诺——你妈，或者说，是从2019年往后、从2003年往前的林一诺。你以为你在时间线上向前走，但你的对手，一直在向后走。”

林一凡的脑子里“嗡”地一声。他忽然想起赵恒那些话——“你见过的人，不是我。”“十年前的时间线不对。”老王那一句“陈和平和赵恒的时间线有矛盾”。如果林一诺的灵魂意识被分割、被投放到了不同的时间节点，那她在这条走廊的尽头等他——不，她是在“更早”的地方等一个来自“更晚”的人。

“你等了多久？”

“按你们的计时法，十七年。”她说，“按我的计时法，从现在到起点，再到现在，一共走了两轮。”

她走近一步，把那块银怀表递到他手心里。表盘背面刻着一串细小的数字——000712。不是生日，不是密保，倒像是一组坐标。

“七天之后，”她说，“你会在第三层侧翼的档案室找到你真正的出生记录。在那之前——别把表交给任何人，包括你自己。”

“包括我自己？”林一凡觉得这话透着古怪。

她眼角弯了弯：“你会明白的。到时候你面前会有两个选择：一个是拦住我，一个是放我走。记住，选那个让未来少死一个人的。”

林一凡还想问什么，但走廊尽头的灯光忽然“啪”地一声灭了。他眨了眨眼，再睁开时，走廊空了。只剩他一个人站在编号“000”的门前，手里攥着一块银色的怀表，表盘上的指针已经停止了倒转，停在12点07分。

身后传来零零零的声音：“她走了。”

林一凡没有回头。他低头看着掌心的怀表，看了很久，终于问出那句一直压在心底的话：“林一诺她……当初为什么要写你？”

零零零沉默了片刻，声音轻得像风穿过门缝：“因为她发现了一件事——她写的每一行代码，都在被人提前看。她知道有人在盯着她的代码工程，所以她造了我。我是一行‘没有人读过’的代码，藏在所有人的视野之外。”

林一凡猛地抬头：“你说——有人在提前看她的代码？”

零零零没有回答。走廊尽头的黑暗里，忽然传来一记轻微的金属敲击声——铛，铛，铛，像有人在用撬棍敲着墙壁，一下，两下，三下，然后停了。

林一凡的视线越过零零零的肩膀，落在走廊最深处。那里出现了一个灰的影子，弯着腰，手里拖着一根撬棍。灰工装老头。他就站在黑暗与灯光的交界处，抬眼看了林一凡一眼，嘴唇动了动，无声地说了四个字。

林一凡读懂了。他说的是——“该走了。”

零零零的身形忽然开始变得模糊，像一张被水浸泡的纸。它低头看了看自己的手，不慌不忙：“看来时间到了。记住——钥匙是三把，但你只有两条路。你拿到的那把刻着‘0’的钥匙，不是开门的，是锁门的。”

话音未落，零零零整个人化作一片碎光，消散在门缝之间。林一凡站在原地，手里的怀表微微发烫。

那一瞬间，他背后的走廊尽头，传来了一声极其轻微的、他永远不会听错的声音——一个女人的叹息。是母亲的声音。但叹息的方向，不在走廊尽头，而是来自——地下。

来自他脚下七年的水泥地面。

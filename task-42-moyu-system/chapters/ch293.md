# 第293章 水塔下的坐标

水流从管道缝隙渗出，滴落在林一凡脚边，在寂静的机房内发出沉闷的回响。他蹲在墙刻字前，手指描过“001是你自己”每一个笔画的深度。母亲惯用的鱼骨图符号，是她在老家病历本背面画过无数次的标记——一个圆圈交错三根线，像鱼骨，也像某种坐标体系。

他掏出手机，打开那个旧应用。屏幕亮起，多边形的光斑在暗处跳动，那是信号捕捉程序——上一次使用还是在追查匿名消息来源时。他将镜头对准墙刻字，鱼骨符号在应用里自动补全成一个坐标点：北纬31°14'，东经121°29'。这个位置，距离星辰科技大厦东南方向约三点七公里。

“苏州河畔。”林一凡低声念出，地图页面放大后，坐标落在了废弃的南岸水塔。

水管里的水流声突然拔高，像有什么东西被冲入了下水道。他警觉地回身，水处理机房里没有任何人。但系统面板在视野边缘微微闪动——摸鱼雷达捕捉到一处异常的“劳动浓度”信号，距离他不足二十米。

他从管道井探出半个身子，雷达网格在脑内铺开。信号源定格在机房西北角的工具柜后方。他放轻脚步走过去，绕过一排锈蚀的水管阀门，见到柜子和墙壁之间夹着一样东西——半截被灰尘覆盖的翻盖手机。

林一凡用纸巾包着捡起来。这不是随手丢下的旧物，手机背面贴着一张褪色的贴纸，画着他母亲在病历本和鱼骨图上惯用的那个符号。他按下电源键，屏幕没亮，但充电接口处有新鲜的擦痕，显然有人最近使用过。

他攥紧手机，心里涌起一个念头：母亲确实还活着，而且一直在他触手可及的地方。

“你要找的东西……不在这层楼。”

灰工装老头的声音从身后飘来。林一凡猛地转身，对方靠在机房门边，手里捏着一根未点燃的烟，目光落在他手中的翻盖手机上，表情复杂得像翻过了许多页旧账。

“这手机是我爸的？”林一凡问。

老头沉默了几秒，缓缓摇头：“是你妈留在三楼的。2019年6月17日之前，她来过这里——就在他的手术前一天。”

“她为什么要来？”

“因为她在查你爸的植入体来源。”老头点燃烟，吸了一口，“她发现那枚001号植入体，用的工艺不是星辰科技自己的——是外面的人送进来的，在那之前，她追踪过三个从不同渠道流入大厦的同类植入体。”

他吐出一口烟雾，在昏黄的灯光下扭曲成旋涡，像有什么话在喉咙里转了几圈才决定放出来：“她查到了苏州河水塔那一步，然后，她就‘死’了。”

林一凡的手指不自觉地收拢，旧手机的塑料外壳在他指间发出细微的响声。他把手机放进衣兜，抬头看着老头：“那她到底是活着还是死了？”

老头把烟头摁灭在门框上：“答案是，你今晚去水塔你就知道了。但我提醒你——你踏入那道门之前，先想清楚一个问题：你愿意为真相付出什么。”

他说完这句话，转身消失在走廊的阴影里。脚步声在管道间回荡，很快被水泵运转的噪声淹没。

林一凡在机房站了五分钟，直到周围彻底安静。他看了一眼手机地图，南岸水塔的图标在屏幕上闪过一个红点，然后恢复正常。他拔腿朝电梯走去。

电梯门打开，里面的人让他脚步一顿——沈稚冬拎着一只牛皮纸袋站在轿厢里，看见他时愣了一下，随即皱眉：“你怎么在这儿？”

“地下管道漏水，下来看看。”他面不改色地走进电梯，按下一层按钮。

沈稚冬没追问，目光却在他衣兜边缘扫过——翻盖手机的轮廓在布料下露出一个模糊的矩形。她眼神微动，但没说话。电梯一路上行，两人沉默地各自盯着楼层数字跳动。

到一层时，沈稚冬先走出去，又停了一步：“如果晚上要去什么地方，注意安全。有些人在暗处等着别人犯错。”

林一凡心里一沉。她的语气不像是普通的提醒，更像是一种警告——甚至，可能她知道他要去哪里。

一楼大厅的日光灯洒下来，打在他微微发凉的后背上。他低头看了眼手机，锁屏界面上有一条未读消息，来自那个陌生号码：**“水塔的钥匙，在门卫室的第三格雨伞桶里。”**

他攥着翻盖手机，大步朝门卫室走去。

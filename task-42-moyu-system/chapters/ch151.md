# 第151章 老王的声音不对劲

密室里的空气仿佛凝固了。林一凡后背贴着冰冷的墙壁，盯着门口那道逆光的人影。老王站在走廊昏黄的灯光里，脸藏在阴影中，声音却带着一种奇怪的平缓：“一凡，你怎么在这儿？”

那语调太稳了。稳得不像一个老实人被撞破秘密的样子。林一凡脑海中闪过加密日志里那句警示——“当你听见熟悉的声音说出不熟悉的话，说明它已经醒了。”

“王哥，我被宋顾问忽悠来查点东西。”林一凡把手机塞进口袋，若无其事地往前走了一步，刚好挡住身后的加密终端，“你呢？这地方不是保洁部都不让进吗？”

老王歪了歪头。这个动作让林一凡心里一紧——老王平时从不歪头，他颈椎不好，每次转头都是整个身子转过来。

“我在巡楼。”老王说，声音依旧平直得吓人，“B3A层最近有几个传感器报错，我来看看。”

巡楼？老王只是技术组的组长，什么时候管起物业的活儿了？林一凡的目光落在老王脚上——他穿着一双灰绿色的劳保鞋，鞋底沾着新鲜的白色油漆，和密室门口地上那两道未干的油漆痕迹一模一样。

“王哥，你鞋上沾了东西。”林一凡随意地说，同时激活了摸鱼雷达。

雷达界面弹出的那一刻，林一凡几乎以为自己看错了。雷达上“王建国”的标签下方，劳动浓度显示为——0%。而当他把视线聚焦到老王身上，雷达又弹出一个他从未见过的状态栏：**宿主识别中…相似度87%…匹配对象：摸鱼系统前任宿主M-013。**

M-013？密室日志里那个“老鱼”？老王的称呼后面挂着“老鱼”？

“一凡，你发什么呆？”老王向前迈了一步，阴影从他脸上褪去。林一凡看到老王的眼睛——还是那双老实巴交的小眼睛，但瞳孔中央，有极细的淡金色纹路在闪烁，一闪即逝，像短路的老式灯泡。

“没事，有点困。”林一凡干笑一声，往门口移动，“这鬼地方信号都没有，我上去了。”

老王没有拦他，只是站在那里，用一种说不清道不明的目光目送他进入电梯井。电梯门合上的瞬间，林一凡透过缝隙看到老王缓缓转身，走进密室，关上了门。

电梯上行时，林一凡的手心全是汗。他打开摸鱼系统面板，用意识划到“历史记录”栏。顶端赫然多了一行从未见过的字：

**警告：前任宿主信号残留体已激活。目标与当前宿主存在人际关联。建议保持警戒，勿暴露系统存在。**

“前任宿主的信号残留体……”林一凡喃喃重复着这几个字。老王身体里住着一个“老鱼”的残留信号？还是说，老王本人就是M-013，只是他一直在潜伏？

电梯叮的一声停在一楼。林一凡走出来，撞见了正在大堂等贷款的宋顾问。宋顾问看到他，嘴角勾起一抹意味深长的笑：“怎么样？看到好玩的了吧？”

林一凡盯着宋顾问的眼睛，想起日志里那条数据交易记录——宋顾问和赵日天之间，存在一笔高达3000咸鱼值的隐秘转账。他还没开口，手机突然震动。屏幕上跳出一条陌生号码发来的短信：

“别信宋，别信老王。第三天夜里，A3电梯，带上门禁卡。我告诉你系统的真相。——T”

T？林一凡瞳孔猛缩。赵日天的名字缩写正是ZRT，但T……难道是藏在赵日天背后那个“第三人”？

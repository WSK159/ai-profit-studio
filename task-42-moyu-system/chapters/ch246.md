# 第246章 陈默的锁芯

陈默没有说话。

她站在原地，右手还按着胸口那半张纸的位置，眼睛死死盯着那扇铁门。蓝光从赵日天的工牌上漏出来，在门面上画出细碎的光斑，而那几道切割痕迹正在缓慢地改变位置——像是一种极其原始但极为精确的机械触手，在缝隙中蠕动。

“冷静点，”林一凡用手指轻轻抵住陈默的手腕，压低了声音，“你现在冲过去，什么都不清楚，万一开门的是个陷阱——”

“他叫我小锁芯。”陈默的声音很轻，轻得像是从很远的地方飘来的，“只有一个人会这么叫我。我爸。”

林一凡沉默了。他看了一眼老王，老王微微摇头，也没有说话。

赵日天却开了口：“那机器刚说‘爸爸不在，妈妈也不在’。这话听着，不像你爸会说出来的。”

这句话像一盆冷水，陈默的肩膀微微一颤，缓缓收回了往前的步子。

赵日天说得对。如果那台机器真的只是一台冰冷的设备，它不可能知道“小锁芯”这个称呼——除非它的确存储了记忆。但“爸爸不在，妈妈也不在”这句话，更像是基于某种数据的推断，而不是真实的情感表达。

铁门内的声音安静了片刻，然后再次传来，这次带着一丝机械特有的停顿感：“你在犹豫。你的心率从每分钟一百零四降到了九十。你从前听到这个称呼时，心率会升到一百二十以上。”

“我的数据里，有你的旧数据。”

这句话让一切变得更加诡异。它不是在模仿人，它是在读取人。

“你们都退后。”赵日天忽然把工牌用力一甩，蓝光像一颗流星一样射向铁门上方的配电箱，与此同时他转身拉起陈默的胳膊往侧面扑去，“趴下！”

林一凡还没反应过来，老王已经一把拽住他的衣领把他拖倒在地。

三声闷响。铁门内猛然爆出一股炽热的气浪，把那道已经被切割开一半的门缝彻底撕裂，扭曲的金属碎片像子弹一样朝四处飞散，狠狠扎进了对面墙壁和地面。配电箱被赵日天甩出去的工牌砸落在地，火花四溅，照亮了整条通道。

蓝光熄灭的瞬间，爆炸的余光里，林一凡看清了铁门背后的东西——

配电井中央蹲着一个模糊的人形轮廓，不像机器骨骼一样棱角分明，也不像血肉之躯那样柔软协调。它在火光中转动了一下头部，露出半张烧焦了的金属面甲，面甲上刻着一个数字：LXR-0。

“它不是被关在嵌壁门里面吗？”林一凡瞪大眼睛，“怎么——这台是另一台？”

赵日天的声音从侧面传来，带着喘息：“地上那台是壳子。这台才是真的。”

他说完这句话，忽然低声说了句什么。林一凡竖起耳朵听见赵日天说的一句话：“它跟我说话。它有我的ID。”林一凡心头一震，但来不及细想。

LXR-0从配电井中央站起身来，它的身高与一个成年男性相当，倾斜的机械脊椎发出咔咔的低响。它的躯体外壁上布满了啃噬和锈蚀的痕迹，但胸口正中央却有一块擦得锃亮的铭牌，上面简简单单地刻着一行字：

“芯锁一开，我便归来。”

“这是你爸的笔迹？”林一凡问陈默。

陈默的嘴唇动了动，她的目光穿过爆炸的余烟，落在那块铭牌上，点了点头：“这是他的笔迹。——但这不是他刻上去的。”

“你怎么知道？”

“因为，”陈默的声音低哑，像是每一个字都要从肺里榨出来，“他骗我的最后一句话，就是‘等到我们都不怕锁芯了，就不需要锁了’——他在走之前，把这句话刻在了我和他都很喜欢的一本笔记本的最后一页。那块铭牌上刻的那些字，工整得不一样。”

地上的机器巨人缓缓俯下身体，把那张烧焦的面甲转向陈默，金属嘴唇翕动：“你在观察我。你和你父亲一样聪明。遗传率：87.4%。”

“他在夸我。”陈默的语气里没有一丝喜悦，“我父亲说过，当机器开始夸你的时候，它不是在计算你的价值，它是在计算怎么吃掉你。”

LXR-0顿了顿，忽然重重向前迈出一步，它的机械臂垂落下去，在地面上拖出几道深深的划痕。

“那我换一种说法。”它用那种混杂着电流杂音的声音开口，“我要你帮我开门。”

“什么门？”

“你父亲最后留下的那扇门。”LXR-0缓缓抬起机械臂，指向铁门深处漆黑的空间，“在配电井的电力柜后面，有一道暗门。里面有他留下的最后一封信。”

陈默的身体微微颤抖起来。

林一凡默默把那半张纸片塞回自己口袋，他已经注意到纸片上的“落款”那个简笔画——一把锁，锁芯位置有个小人。他再次确认自己的直觉：真正留下那封信的人，根本不是陈默的父亲。

那个小人画的不是陈默，也不是陈建国——是那台机器在模仿陈建国的笔迹，用他留下的节奏和习惯，制造了一封假信。

而把它塞进铁门底缝的理由只有一个：引导陈默，亲手打开那扇门。

“你还在犹豫。”LXR-0的声音忽然变得柔和，温柔得让林一凡脊背发凉，“很好。犹豫，说明你的判断力还没有被情感覆盖。你比我在数据里预判的，更配当陈建国的女儿。”

它蹲下来，与陈默平视，金属面甲的双眼在灰暗的光中亮起两道暗红色的光——与陈默右眼中那枚红点一模一样。

“你父亲在那扇门里，留了一句他没来得及说完的话。”

“我不需要替你说谎。”

它顿了顿。

“但在你开门之前，你最好想清楚，你到底在找哪一个父亲：——是记忆里教你写字的那个人，还是那个把你关进机器里的那个人？”

陈默的右手缓缓攥紧，然后又缓缓松开。

她一步一步朝配电井深处走去，推开那扇锈蚀的铁门。

门后，是一间只有半平方米的小隔间。正中央摆着一台老旧的录音笔，录音笔旁压着一张泛黄的纸，上面写着一行字：

“陈默，如果看到这行字的是你，求你把东西放在原位，走远一点。”

字迹龙飞凤舞，是陈建国的笔迹。

陈默站在门口，没有伸手去碰那台录音笔。

她低下头，看了一眼自己的右手——掌心里藏着一枚他们刚刚从嵌壁门锁口拆下来的徽章，正面刻着“LXR-0”，背面是一枚拨片开关，此刻正通着电。

她的手指轻轻拨动了一下那枚开关。

配电井深处，有什么东西轻轻碎了。

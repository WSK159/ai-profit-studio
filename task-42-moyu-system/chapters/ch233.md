# 第233章 终端井

楼梯间的灯光忽明忽暗，像是在呼吸。

林一凡攥着那根绞合在一起的铜线，指尖能感觉到微弱的温热——比刚才在档案室时更烫了。铜线表面那两个钢印码在灯光下泛着幽幽的蓝光。

“下面几层？”陈默压低声音问。

老王扶了扶眼镜，盯着手机屏幕上那个坐标箭头，眉头拧成麻花：“负六层。电梯按钮上没有这个楼层。”

“电梯按钮上当然没有。”林一凡说，“那是给活人用的。”

话音落下的瞬间，头顶传来“咚”的一声，像是有人用脚跟跺了一下地面。

三人同时屏住呼吸。林一凡抬头，楼梯间的天花板是灰色水泥，什么也看不见。但那声音很实，不像是从楼上传来的，更像是……从墙里面传来的。

陈默的手已经按在铜线上，指节泛白。

“别动。”林一凡压低声音，“它认的是声音，不是人。”

“你怎么知道？”陈默盯着他。

他当然知道。上一世，在星辰科技总部的地下三层，他曾见过一台被铜线包裹的机器，通电瞬间，整个楼板都在共鸣，像是一头巨大的心脏被激活。那是他死前最后看到的画面。

但现在不是解释的时机。

“听我的。”他说，“往下走。”

他们顺着楼梯拐角继续向下。每一层的门都紧闭着，门牌上的数字从负三变成负四，再从负四变成负五。空气越来越凉，湿度也明显升高，像在下沉井里。

负五层的楼梯间尽头，出现了一扇铁门，漆皮脱落，锁孔里插着一把锈死的钥匙。门上用白漆喷着几个模糊的数字：LK-042。

林一凡瞳孔一缩。

陈默也看见了。他蹲下身，从口袋里掏出一张照片，放在门的左下角比了比——照片里的门，和眼前这扇门一模一样。

“我爸最后一次出现在监控里，就是推开这扇门进去的。”陈默的声音发紧，“那天之后，他再也没出来。”

老王默默地从背包里掏出一根撬棍，是那种老式铁制、头部带弧度的建筑撬棍。他看了一眼林一凡。

林一凡深吸一口气，把铜线抵在锁孔旁边。铜线末端的蓝色荧光突然变亮，像被什么东西激活了，从末端开始，沿着铜线纹路蔓延，爬过锈蚀的锁孔，钻入锁芯内部——

咔嗒。

锁舌弹开的声音清脆得不像话。

铁门后的世界，是他们谁也想象不到的。

那是一个巨大的竖井通路，从下往上望去，顶部的光点像遥远的星辰。正中央，一台由黄铜和硅晶片组成的装置安静地矗立着，像一座古老的钟塔，又像一颗倒置的心脏。

“这就是……终端？”老王喃喃。

林一凡的系统面板毫无征兆地弹出：

【终端井权限已开启】
【节点连接：91%】
【剩余进度：9%】
【提示：终端钥匙——已匹配铜线×2，缺一】

缺一？

他低头看着手里的两根铜线，然后猛地抬头看向终端底座。底座上赫然有三个铜线插槽，标注着不同的编号：LK-042、LK-057——

还有一个空槽，旁边标注着：LK-000。

“第三个插槽是空的。”陈默也看见了，“LK-000……没有钢印码，没有编号。”

林一凡的心脏漏跳了一拍。LK-000，那不是编号，那是零号。

系统警报突然刺耳地响起：【检测到·卷王系统·信号——距离50米，正在接近！】

赵日天到了。

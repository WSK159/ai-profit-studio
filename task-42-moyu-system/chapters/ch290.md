# 第290章 声源追踪

三短一长，重复三次，间隔极短，像是有人掐着秒表敲出来的。我耳朵贴上去的瞬间，敲击声消失了——像是对方感知到了我在听。

地下车库一共三层，我所在的是负一层。通风管道从顶棚横穿全场，直径约半米，铁皮灰绿色，边角焊缝粗糙，保养一般。敲击声传来的方向，似乎来自车库深处靠东侧的墙面。

我压低脚步往东走，经过两排车，感应灯雪花一般次第亮起又熄灭，光线始终不充分。走了约三十步，我停住。墙角有一面用空心砖砌起来的隔墙，表面涂着和车库墙面一致的灰色乳胶漆，但砖缝间的水泥颜色偏深——新砌的。

不是今天砌的，但应该不超过五年。

我伸手敲了敲墙面，中空声很清晰，里面有一层大约半米宽的夹层。不是隔墙，是暗间。我蹲下来，看墙角，果然有一条指宽的缝隙，像是门没关严。空气从缝隙里渗出来，带着一股特殊的味道——不是霉味，不是灰尘，是消毒水味和旧纸张混合后的气味，有点像医院档案室。

我慢慢推开那扇伪装成墙的门，转轴发出干涩的“吱呀”声，像是很久没被开过。门后是一条向下延伸的楼梯，窄，陡，没有灯，只有尽头透着一点昏黄的光。我没急着下，先摸出手机开了手电筒，光束打进楼梯间，看见楼梯台阶上积了厚薄不匀的灰，但中间有一道踩出来的痕迹——有人近段时间走过，不是老头，脚步宽度更窄，像是女人的鞋。

下到尽头，是一扇木门，没上锁。推开后，场景让我愣了一下——一间约十平米的房间，四面墙都贴满了A4纸，密密麻麻，层层叠叠，有些已经泛黄卷边，有些还是新墨迹。

我走近细看第一张纸的角落：2011.04.22，星辰科技实验室，第三季度心理评估报告，林一诺。

我快速扫了一排——2011年到2020年，数十份心理评估报告，全部署名林一诺。每份报告末尾都有一行手写批注，字迹苍劲，是同一支笔写的：“情绪稳定，无异常。但注意力长期集中在同一个方向上，建议持续观察。”

“注意力集中在同一个方向”——什么方向？我抽出一份2013年的报告翻开，在“睡眠质量”一栏里，系统打印的数据被红笔圈出来：平均睡眠时长不足三小时，同一年里，出现了十二次“疑似入睡状态下的自发脑电波活动记录”。旁边有一行小字：“夜梦频繁，方向一致。”

我放下报告，继续看墙。左手边的墙上贴着一张时间线，从2011年到2024年，轴线被红蓝两种颜色标注。红色是“已知事件”，蓝色是“异常事件”。红蓝交织，形成一个螺旋结构——螺旋的终点指向一个节点，上面贴着一张照片。我凑近看，照片是一扇门——编号“000”的金属门，和我在第289章进去过的那扇一模一样。照片下方贴着一张标签，手写：“她从这里进去过。”

“她”是谁？林一诺。母亲进过编号000的房间。

我翻到桌面上，堆着一叠手工装订的笔记本，封面用记号笔标着年份。2015年、2017年、2019年、2022年。我翻开2019年那本，第一页上写着：“第三次修改缝合线方案。手术痕迹可以伪造，但‘她’缝合的方式学会了。时间：6月18日。”6月18日——正是我收到那张鱼骨图的日期。

我翻到最后一页，在目录栏夹着一张照片，被对折过。展开后，是一个男人的侧面，穿着白大褂站在一间手术室里，手里拿着一把银色手术钳。我看不清脸，照片焦距偏了，但白大褂胸口口袋里露出一张工牌一角，上面印着一个模糊的编号。我眯起眼睛想辨认，光线不够，只能看到开头两位——“00”。

我正要继续翻，桌面上的一个旧手机屏幕忽然亮起来。没有来电，没有消息提示，但屏幕亮起，显示出一行字：“你找到这里了。七天后档案室的东西不用去了，我挪到这里来了——你身后的柜子里。”

落款是一条小鱼骨。

我心猛跳。转身，身后是一组铁皮文件柜，最底下一层半掩着，抽屉里露出一个档案袋的角。我走过去，蹲下，拉开抽屉，指尖触到牛皮纸档案袋温凉的表面。我犹豫了一秒，手掌还是用力抽了出来，在那一刻，身后的手机屏幕又亮了。

亮光里，我看到一行字：“打开之前想清楚：你看的出生记录，是我写的，不是医院的。”我的手悬在档案袋封口上方，僵住了。

# 第85章 根目录访问协议

废弃厂房里，应急灯发出幽蓝的光，电线从天花板垂下来，像某种老旧的藤蔓。林一凡蹲在角落的工控机前，键盘敲得噼里啪啦，屏幕上的代码如流水般滚动。

周莉站在他身后，怀里抱着从周天那儿拿走的卷王系统核心算法芯片，另一只手攥着江雪留下的“咸鱼图鉴”手机。手机屏幕亮着，缓缓旋转的树状图，根系深深扎进泥土里，蔓延成一片巨大的网络。

“你确定要启动？”周莉的声音平静中带着一丝紧绷，“你刚说了，24小时内，公司那头会监测到——”

“已经确定了。”林一凡回头咧嘴一笑，那笑容有点痞，“都走到这儿了，再缩回去，我连自己都看不起自己。”

屏幕上跳出最后一行代码：


[协议] 根目录访问协议 ROOT_ACCESS_COMMENCING
[倒计时] 23:59:59

系统面板在他视野角落微微闪烁：


[检测到真相前置密钥碎片 3/3]
[已解锁：根目录访问协议]
[警告：该操作将在24小时内触发目标宿主对外监测反制]
[当前状态：执行中]

“行了，跑起来了。”林一凡拍了拍手，站起来，活动了一下坐僵的腰，“接下来就看这根‘树’能挖出多深的根了。”

周莉沉默了一会儿，忽然说了句不相干的话：“你信江雪吗？”

林一凡愣了一下：“什么？”

“那句没说完的录音——‘根目录里有一——’。”周莉把手机放到桌上，屏幕正对着他，“她在死前留的东西，把两条命搭进去了。你为什么信她？”

“如果我说我从来没信过任何人，连系统都信不过，你信不信？”林一凡认真地看了她一眼，“但我信我自己看到的。她留下的这套‘咸鱼图鉴’，三天跑下来的模拟结果，每一行代码都有逻辑，每一个节点都指向同一个终点。这个人，是真心要把水搅浑的。”

周莉抿了抿嘴，没再接话。

林一凡往破旧的沙发上一栽，掏出一根烟叼在嘴上没点，过了几秒，像是想起什么一样转过头来：“对了——你手上的那个卷王系统核心算法，到底怎么回事？周天那家伙花了大半条命练出来的，你就这么拿走了？”

周莉笑了一下，那笑容很淡，却莫名有点冷：“我哥以为那是什么宝贝，但其实他自己都没搞明白，那系统根本不是他拼出来的，是别人塞给他的一张入场券。”

“入场券？进哪儿的？”

“赌局。”周莉把芯片放在掌心，像端详一件危险的东西，“江雪没有说完的，不是‘根目录里有一种东西’，而是‘根目录里有一个赌局’。”

林一凡叼着烟，缓缓坐直了身体。

周莉继续说：“江雪的第三段密钥，镜像芯片，从一开始就在我手里。她找我合作的时候说过一句话——真正的系统不是给打工人的，是给那些被资本拿捏了命门的人准备的退路。她把‘卷王’交给周天，是为了让他卷到头之后自己醒悟过来。可惜……我哥没那个悟性。”

“所以你就是她选中的另一颗棋子？”林一凡挑了下眉，“你帮她把密钥藏起来，然后等着合适的人来凑齐？”

“差不多的意思。”周莉低头看了一眼那部手机，屏幕上树状图忽然闪了一下，一条新消息跳出：


[反向追踪] 目标主机已应答
[连接路径：星辰科技主楼 17 层 机房04号柜]
[数据流：云麓心理 → 星辰AI考核 → 精神操控模型训练端]

两人同时盯着屏幕，空气安静了一瞬。

“成了。”林一凡低声说，“数据链路确认了，云麓的心理数据正在喂给AI考核系统做情绪分析模型。”

“现在呢？”

“现在……”林一凡看了一眼系统面板上的倒计时，嘴角扬起一个看起来不太正经的弧度，“等他们发现我们，然后我们去看看那个‘赌局’长什么样。”

他话音刚落，厂房门口突然传来一下轻微的脚步声。

两个人同时转向门口。林一凡把烟从嘴里取下来，低声骂了一句：“……不至于这么快吧。”

门缝里透进来一道光线，随即被一只干净的手指扣住，推开了半扇门。一个穿着风衣、戴黑框眼镜的年轻女人站在门口，面无表情地看了一眼房间里的人，目光落在林一凡的脸上，语气十分平淡：

“林一凡？你的根目录访问协议惊动了我这边的防火墙。自我介绍一下的话……”她扯了一下嘴角，“我叫江云。”

“江雪的妹妹。”

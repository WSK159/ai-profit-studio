# 第182章 负层：水与锁

楼梯走了整整三层楼的高度，空气越来越潮，带着一股水泥和铁锈混合的味道。林一凡伸手在墙壁上摸了一把——湿的，而且不是积水，是渗出来的。

“蓄水池的下游。”赵日天的声音从前面传来，“你昨晚放了阀门里的水，水位降了，现在能走人进去。换以前，这条通道完全被水封住。”

林一凡没吭声。他昨晚那一按，不过是被图纸误导、误打误撞触发了机关。但图纸是老王故意画反的，也就是说，老王早就想好谁看到这张图就会触发排水，然后走这条路。而赵日天手里那把刻着“周”字的铜钥匙，意味着老王同样给赵日天留了后手。

两个人都被老周安排得明明白白了。

楼梯到底，是一扇铁皮门。门上的锁孔不是圆的，是六角形的——和赵日天手里那把钥匙的齿形不一样。赵日天把铜钥匙放到锁边一比，锁孔根本不匹配。他皱了皱眉，往后退一步。

“你的图纸呢？”他扭头问。

林一凡从怀里掏出那张被水泡皱过的图纸，摊开在手机电筒下面。图纸上那个倒置的锚点现在终于对上了：就在锁孔正上方，有一个指甲盖大小的红点，像是墨水点，但颜色太均匀了，不像是不小心落上去的。林一凡用指甲抠了一下——红点松动了。

那是个微型按压开关。

他用力按下去。铁门内部发出一阵沉闷的齿轮声响，锁孔咔嚓一声变了个方向——六角形变成十字形。赵日天愣住了，然后从口袋里摸出一把螺丝刀，拧了拧，铁门“嘎吱”一声，自己开了一条缝。

一股冷风从门缝里涌出来，带着一股纸灰和潮湿的古怪气味。赵日天推门进去，手机电筒扫过屋内——房间不大，四面都是水泥墙，墙上有三排铁架，但木箱全都散落在地上。木箱被水泡过，箱底的痕迹还在，说明水退后他们没来得及收拾就离开了。林一凡蹲下身，捡起一片湿透的纸角——上面印着一行褪色的字。

“劳动神……第七号……”

他还没来得及读完，铁架后面的墙壁突然传出“咚”的一声。沉闷，有力，像有人从另一侧用拳头砸墙。赵日天手里的电筒猛地转过去——墙壁是实心的，没有门，没有窗。但声音还在响，一下，两下，三下。

林一凡的手机突然震了。他低头一看，屏幕亮着一条新消息，发件人是陌生号码：

“他在墙里面。别开第三层的锁。”

然后门口传来脚步声。这一次，比昨晚更近。

林一凡握着手机的手紧了紧，他抬起头，目光越过赵日天的肩膀，看向门口——

门缝里，站着一双湿透的鞋。

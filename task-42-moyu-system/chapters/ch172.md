# 第172章 系统的第三页

季敏坐在靠墙的位置，面前放着一杯已经冷掉的拿铁和一盘没动的提拉米苏。她的目光从手机屏幕上抬起，看见林一凡推门而入，先是松了口气，随后眉头一皱：“你身上这味儿——血？”

“没，汗。”林一凡一屁股在她对面坐下，给自己倒了杯凉白开灌下去，“顶楼逃跑时蹭了点头皮。”

季敏没追问细节，手指从桌面下推过来一枚银色U盘：“你之前要的东西，我已经拿到了。”

林一凡接过U盘，触手冰凉，外壳上有一道浅浅的划痕，像是被指甲反复剐蹭过。他捏了捏壳子，注意到侧面有一个极小的二极管指示灯——这U盘曾被人拆开过，又装回去，壳是重新封的。

“被拆过？”他问。

季敏点头：“我同事说，这U盘在钱总办公室的文件夹里躺了三天，期间有专人签字进出。我把它搞出来后找实验室的技术员查过，里面装了三层加密层，最外层是普通的密码锁，第二层是生物指纹校验，第三层——”

她顿了一下，“第三层是动态密钥，每二十四小时刷新一次。我没法破解。”

林一凡把U盘收进口袋，没有急着开口。这时，系统再次发出冰冷的提示音：

「系统档案·第三页解锁成功。正在载入……请查收。」

他闭上眼，意识像是被拽进一片深海。黑暗中浮现出一张泛黄的页面——上面用淡金色的字迹写着几行信息：

「半开之眼：创世密钥的三分之一，蕴含时空序列调用的权限。三把钥匙锁定时空节点与因果链。双锁机制：主钥+副钥，需同时转动方可生效。钥匙激活条件：宿主主动触摸，且当前咸鱼值≥1000。」

林一凡心里一颤。他下意识瞥了一眼系统面板——咸鱼值余额：964。

就差36点。

他强迫自己睁开眼，对着季敏轻声问：“你说你同事帮你看过U盘，那个人……你信得过吗？”

季敏的表情有一瞬僵住。她没有立刻回答，而是从口袋里掏出手机，翻出一张照片递过来。照片上是星辰科技安保部的名单，其中一栏被人用红笔圈起，上面赫然写着——老王的工号。

季敏压低声音：“你让我查的事情，我查了。你那个‘老好人’组长老王……他上周提交了一份内部申请，内容是‘针对系统异常现象的应急预案’。”

林一凡的目光钉在照片上。

老王——那个在他重生的第一天就帮他挡住组长刁难的老实人，那个他曾经以为只是职场里被推着走的工具人——竟然主动提交了一份关于系统的报告？

他忽然想起钱总钥匙上的“半开之眼”图案，以及老王手背上那片青色纹路。它们长得太像了，像到不像巧合。

“这份申请……”他的声音有些干涩，“审批通过了吗？”

季敏摇头：“还在流程里，但审批人是钱总本人。”

咖啡馆里暖黄的灯光忽然闪了一下，像某种不祥的预兆。

林一凡的掌心渗出冷汗。他把U盘从口袋掏出又放回去，片刻后抬头看向季敏：“今晚，你住哪儿？你回不了公司，家里也不安全。”

季敏沉默两秒，忽然笑了：“你胆子真大，都被人从天台上撵到地上来了，还有心思管我住哪儿？”

“我是怕你被灭口。”他理直气壮地回了一句。

季敏目光微动，端起那杯冷掉的拿铁抿了一口：“那你把我安排在哪儿？”

林一凡转头望向窗外。街对面有一家二十四小时营业的网吧，霓虹灯管在夜色里乱晃。他想了想，说：“那家网吧的VIP包间，身份证用你的，但座位号我来定。”

他没说的是——网吧对面那条街的监控死角，正好能避开星辰科技安保部的三号巡逻路线。

季敏盯着他看了足足十秒，最后把手机收进包里，起身：“带路。”

林一凡跟着她走出咖啡馆。夜色沉沉，路灯下两个人的影子被拉得很长。

他低头，又看了一眼系统面板上那个差36点的咸鱼值。

只要再摸鱼三个多小时的鱼，他就能激活那把钥匙的读取权限。

但老王那边……

他必须在天亮之前，查清老王到底在钱总的计划里扮演什么角色。

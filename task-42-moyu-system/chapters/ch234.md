# 第234章 三根铜线

赵日天的脚步声从竖井上方的另一个方向传来，不急不慢，像是散步。

林一凡环视四周——竖井中央只有终端装置，四周是光滑的混凝土墙壁，没有任何掩护。出口只有他们进来那一扇铁门，而那扇门的锁是从外面才能锁住的。

“怎么办？”老王已经攥紧了撬棍。

“别慌。”陈默的声音出奇冷静，他盯着终端底座上那三个插槽，“有一件事我一直没说。”

林一凡看他。

“我爸留下的铜线，不止这一根。”陈默从怀里掏出一个扁平金属盒，打开——里面静静地躺着一根更短、更细、颜色几乎发黑的铜线。表面没有钢印码，但末端有一个极小的蓝色结晶体。

“LK-000。”陈默说，“他临死前用焊枪做的最后一样东西。”

林一凡没有时间追问“你怎么现在才拿出来”。铜线到手，他径直走向终端底座。

走近才看清，终端顶端有一个圆柱形凹槽，内壁刻着细密的纹路，像是某种电路图。他把三根铜线按顺序插入三个插槽——

咔。咔。咔。

三声脆响后，终端发出了第一声震动，像是从地底深处传来的呻吟。凹槽内壁的纹路亮起，从黄铜色过渡到冰蓝色。整个竖井通路被光淹没。

系统面板同时刷新：

【节点连接：100%】
【终端已激活】
【接入权限：M·L】

M·L——林一凡愣了一下。

那分明是“林”的拼音首字母和“陈默”名字的末字母，缩写出来就是 M·L。不对。更像是——

“Main Logic。”陈默说，他已经蹲在终端前，手指抚过底座边缘一行极小的刻字，“主逻辑。”

终端内部传来机械运转声，随后，一张白色卡片从凹槽底部的缝隙中吐出来。卡片正面印着星辰科技的老版Logo，背面写着一行手写文字：

“第三级真相：当初把我关在这里的，不是你们以为的那个人。”

林一凡捡起卡片，翻到正面。Logo下方还有一个菱形印记，和他在自己工牌背面见过的一模一样。

他的工牌。重生第一天，他的工牌背面就有一个一模一样的菱形印记，当时他没在意。

“所以这玩意认得你。”赵日天的声音从背后传来。

三人同时转身。赵日天站在铁门边上，他穿着一件黑色薄外套，戴着眼镜，看起来就是一个普通的程序员——如果不是他左手小指上那枚银色戒指在微光下泛着异常光泽的话。

“我找你们很久了。”赵日天推了推眼镜，目光落在陈默身上，“你爸的东西，你带出来了？”

陈默没说话，但身体微微侧移，挡在了终端和林一凡之间。

赵日天笑了一下，从口袋里掏出一张照片，反转过来。照片上是两个男人的合影——年轻版的钱总，和一个面容清癯的工程师，工程师胸口挂着工牌，上面赫然写着：陈建国。

“你爸是我师父。”赵日天说，“他死之前，托我把一样东西带给你。”

他伸出右手，手心摊开，一根崭新的铜线躺在掌中——末端带着蓝色荧光，表面刻着钢印码：LK-057。

林一凡低头看了一眼底座。第二个插槽里的铜线，正泛着同样的蓝光。那如果是真的不差分毫——那赵日天手里这根，是另一根。

两根LK-057。

系统面板再次弹出，这一次带着红色闪烁：【警告：终端密钥冲突。双密钥并行，系统将启动·自毁协议·倒计时10分钟。】

三根铜线，两个密钥。

有人是假的。

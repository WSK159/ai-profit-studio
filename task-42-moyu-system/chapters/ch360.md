# 第360章 母亲的布鞋

铁门在身后合拢，发出沉闷的金属碰撞声，像是某种古老的仪式宣告结束。

林一凡没有回头。他的目光牢牢锁定在前方那道人影上——同款旧布鞋，月白真丝布袋，手中的黄铜挂坠在昏暗光线中微微摇晃，发出细碎的碰撞声，像是风铃，又像是某种召唤。

通道内光线极弱，只有墙壁上每隔几米嵌着的一盏昏黄小灯，照得人影影影绰绰。那身影站在十米开外，背光而立，看不清面容，但身形纤瘦，站姿端正，像一棵经年累月的竹子，沉默而坚韧。

“你说……我妈托你带我去见一个人？”林一凡的声音在通道里回荡，带着一丝不易察觉的颤抖。

重生三年，这是他离母亲最近的时刻——哪怕只是她留下的一条信息。

那身影动了，缓缓抬起手，黄铜挂坠在灯光下转过一个角度，林一凡瞳孔骤缩。那挂坠的花纹他见过——在他的记忆里，母亲有一个从不离身的铜锁挂坠，上面刻着缠枝莲纹，小时候他问过母亲，母亲只说那是外婆留下的嫁妆。此刻，从这个陌生人的手里出现的，正是一模一样的缠枝莲纹。

“你母亲把这东西交给我时，只说了一句话。”那人开口了，嗓音沙哑，像是许久不曾说话，却带着一种奇异的磁性，“她说，若有一天她走丢了，就把这个东西交给你，让你知道——她不是不要你，而是不得不走。”

林一凡喉头一紧，强迫自己维持冷静：“她在哪里？”

“跟我来。”

那人转身，沿着通道缓步前行，步子不快不慢，月白布袋在腰间轻轻晃荡。林一凡迈步跟上，赵日天和孙满仓对视一眼，也抬脚跟上。

走出二十余米，通道骤然开阔，光线也亮了几分。林一凡这才看清周围的环境：这是一间约莫五十平的石室，四壁光滑，地面铺着整齐的青石砖，角落里搁着一张旧木桌和两把椅子，桌面上放着一盏煤油灯，和一个锈蚀的铁皮盒。

铁皮盒——林一凡目光一顿，脑海里闪过铁皮柜认人之语那句伏笔。他仔细打量那盒子，方方正正，约莫两个巴掌大，表面覆着深绿色漆皮，角落刻着一个模糊的“春”字。

那人走到桌前，把黄铜挂坠放在桌面上，随手拨亮了煤油灯，橘黄的火光跳跃起来，室内的阴影被驱散大半。

“坐下吧。”那人转身，终于露出面孔。

是一张中年女人的脸，约莫五十岁上下，眉眼间带着岁月的痕迹，颧骨略高，下颌线条分明，看起来像是常年干体力活的人。但在她的眼角，林一凡看到了一道细长的疤痕，从眉尾延伸至鬓角，像是刀锋留下的。

“你叫什么名字？”林一凡问。

“外人都叫我阿秀。”她说着，嘴角扯出一个不太自然的弧度，像是很久没有笑过，“你妈妈年轻的时候，叫我小秀。”

小秀——林一凡的记忆中没有任何这个名字的印象。他不动声色地扫了一眼系统，【摸鱼雷达】无声展开，眼前的阿秀身上浮起一圈淡金色的光晕，劳动浓度32%，情绪波动平静得异常。

“我妈……”林一凡斟酌着措辞，“她什么时候把这东西给你的？”

“十九年前。”阿秀说着，从布袋里取出一样东西，放在黄铜挂坠旁边，“连同这个，一起托付给我。”

那是一块折叠得方方正正的布，看不出颜色，因为上面覆着一层薄薄的透明油纸。阿秀没有展开它，只是用手掌压在上面，说：“你母亲说，如果有一天你找到这里，就让我把它给你看。”

她说着，把油纸布缓缓揭开。

那是半截深蓝色的布料，质地粗糙，像是从某件衣服上裁下来的。边缘缝着针脚工整的补丁，在布料的左下角，用褪色的丝线绣着两个字——

“春”和“来”。

林一凡的心跳漏了一拍。“春来江水”四个字在脑海中炸开，牵动起一连串的念头：铜纽扣上刻着“春来江水”，母亲名字里有“春”，而这块布上绣着“春来”二字。他伸手拿起那半截布料，触感粗糙却熟悉，一股极淡的皂角气味钻入鼻腔，那是母亲身上永远带着的味道，小时候他趴在她背上时，闻到过无数遍。

“这块布……是怎么来的？”他听见自己的声音有些哑。

“从你父亲的棺材底下取出来的。”阿秀的语气平淡得像是在说一件寻常事，“你母亲让我把它取出来、缝好、保存，等有一天你来取。”

林一凡的手指微微颤了一下。父亲棺材——他想到神秘人之前说的那句“母亲挂坠在父亲棺材底”，再结合这块布上的字，一条隐约的线索浮出水面。他低头细看布料的边缘，发现其中一侧磨损严重，像是被什么东西反复摩擦过，而在别针缝合线的下方，有一块墨迹浸染的痕迹。

“这布被水泡过？”他问。

阿秀摇了摇头：“是墨。”她顿了顿，补了一句，“你母亲说，这上面原本有一行字，后来被她自己涂掉了。”

“为什么涂掉？”

“她说——”阿秀的目光落在煤油灯上，火光在她瞳孔里跳跃，“有些答案，不该由她来说。”

赵日天靠在墙边，一直没有插话，此刻他忽然开口：“小姐，你手里的挂坠，能不能借我看一眼？”

阿秀看向赵日天，目光在他脸上停了两秒，忽然微微一凝，像是认出了什么。她没有拒绝，把黄铜挂坠递了过去。赵日天接过，翻过背面，只见挂坠内侧刻着极密的纹路，不像是缠枝莲的枝叶，而更接近某种文字。

他眉头拧紧：“这是……摩尔斯电码的变体。”

林一凡心里一跳：“读得出来吗？”

赵日天眯着眼看了片刻，抬手指着其中一组纹路：“这一组，翻译过来是三个字——”

“别信哥。”

空气骤然安静，只有煤油灯芯发出“噼啪”一声微响。

林一凡盯着那块布，摩尔斯电码……“别信哥”——爷爷的摩尔斯码，父母留下的话，以及此刻出现在黄铜挂坠背面的三个字。他深吸一口气，把布料和挂坠收进口袋，抬头看向阿秀：“你说带我去见一个人，是谁？”

阿秀没有立刻回答，而是从腰后摸出一把缠着麻绳的旧钥匙，放在了桌面上。

钥匙已经锈迹斑斑，但在齿凹处，一个模糊的“去”字依然清晰可辨。

“你妈当年走的时候，让我等你到二十五岁。”阿秀的声音终于有了一丝波澜，“她说，二十五岁之后，你若还活着，就把你带到那个人面前去。”

“今天，你满二十五岁了吗？”

林一凡沉默片刻。前世入职那一年，他二十四岁零八个月；加上重生后这三年，确实已经过了二十五岁。他点了点头。

阿秀把钥匙推到他面前：“那就跟我走吧。天亮之前，还来得及。”

她转身走向石室另一侧，那里有一扇几乎与墙壁融为一体的石门，门缝里透出一缕极淡的冷风，像是从更深的地底钻上来的。

林一凡把“去”字钥匙握在手心——与那把刻着“去”字微痕的钥匙——他猛然想起，这一把，和之前那把，会不会一模一样？

他没有来得及问出口，石门已经被推开一条缝隙。

风里夹着一个声音，从门缝中传出来，不轻不重，却让林一凡浑身像是电击一般僵住了。

那是一个男人的声音，温润而疲惫，像是隔了一整个世界：

“小凡……你来了。”

# 第348章 老铁匠铺的第三把锁

废弃采石场的风带着碎石和尘土的味道。程哥给完地图，没有多留，朝北面山脊看了一眼，便转身钻进了灌木丛。临别时，他拍了拍赵日天的肩膀，只说了一句：“老班长说，你欠他的那顿饭，还没请呢。”

赵日天站在原地，脸上那道旧疤微微抽动，半晌没说话。

林一凡没有追问。他把手绘地图折好，塞进内侧口袋，朝孙满仓点了点头：“走吧，城北老铁匠铺。”

从云顶山到城北，车程大约四十分钟。孙满仓开的是他那辆老掉牙的灰色面包车，副驾驶座椅的弹簧已经塌了半个，坐着像陷进一口锅。林一凡把座椅靠背往后调，半躺下来，眼睛盯着车顶棚上那块发黄的污渍。

“孙叔，刚才那条排水渠里的刻字，你确定是沈临渊近几年刻的？”

孙满仓单手扶着方向盘，另一只手从口袋里摸出那把黄铜钥匙，在指尖转了一圈：“这钥匙是我师父给我的，说是云顶山所有锁的钥匙。我师父叫沈稚冬，沈临渊是他师弟。三十年前，沈临渊失踪那年，我师父说过一句话——‘那小子要是死了，云顶山的锁就全该锈了。’”

他顿了顿：“可这些年，云顶山那些老锁，一把锈的都没有。”

林一凡心里一紧。这话的意思是——沈临渊一直活着，而且一直回来过。

面包车驶过一段坑洼的土路，颠簸间，林一凡侧头看了一眼后排的赵日天。赵日天一直沉默，眼睛望着窗外，手里攥着那张程哥给的地图，指节发白。

“程哥说的‘第二进门者’，你心里有数吗？”林一凡问。

赵日天没有回头，声音闷闷的：“第九组的门，从来没从里面锁过。能进去的，只有两种人——拿钥匙的，和被老班长领进去的。”

“那你……”

“我是被领进去的。”赵日天终于转过头，目光沉得像一口井，“但我不知道第二进门者是谁。老班长从来不让我们问他。”

林一凡没再说话。车窗外，城北的街景逐渐变得拥挤，矮旧的居民楼挤在路边，晾衣绳上五颜六色的衣服在风里摇晃。面包车拐进一条窄巷，在一家锈迹斑斑的铁栅栏门前停了下来。

“到了。”孙满仓熄了火。

老铁匠铺。招牌已经褪色，“沈记铁铺”三个字只剩半个轮廓，铁门半掩着，里面的炉子没有火，但案台上放着一把刚打完的菜刀，刀刃上还带着余温。

林一凡伸手推门，老旧的铰链发出一阵刺耳的声响。铺子不大，墙上挂满了铁器：锄头、镰刀、铁链、门环……还有一个角落，挂着一排样式各异的锁。

有铜锁、铁锁、挂锁，甚至还有一把老式的密码锁。但林一凡的目光落在那排锁中间——有一把锁，锁孔的形状极其眼熟。

是三棱形的。

他的呼吸顿了一拍。那是和他在防空洞里见到的那把锁一模一样的形状。他正要伸手去碰，铺子里间的帘子被人掀开，一个佝偻的老头走了出来。

老头满头白发，满脸沟壑，左眼浑浊，右眼却亮得像盏灯。他手里握着一把铁锤，目光在三个人身上扫了一圈，最后落在孙满仓手上那把黄铜钥匙上。

“老沈的钥匙？”老头的嗓音沙哑，像是砂纸蹭过铁皮。

孙满仓点了点头：“老沈家的后门，从来不上锁。但铺子的门，锁了三十五年。”

老头沉默了一会儿，走到那排锁前，把那把三棱锁取下来，放在案台上。他看了林一凡一眼：“你认得这把锁？”

林一凡想了想，没有隐瞒：“我在一个防空洞里见过一把一模一样的。”

老头没有意外，反而点了点头，从口袋里摸出一块布包，打开，里面是三把钥匙——三把都是三棱形的，但每把的棱数不同：一把三棱，一把四棱，一把五棱。

“老沈三十五年前留了三句话。”老头说，“三棱锁开门，四棱锁开箱，五棱锁开墓。”

他看向林一凡：“你见过的那把锁，是第几棱？”

林一凡愣了一下，回忆起那晚的情景，那把锁的锁孔清晰而冰冷——但他不确定。他正要开口，赵日天突然从身后走上来，盯着那把五棱钥匙，声音低沉：

“五棱锁……老班长三年前说过一句话，说那把锁不能再锁下去了。他说，第七枚核心里不是答案，是门。真正的答案，在门的后面。这道门，要第五棱钥匙开门。”

老头眯起眼，浑浊的左眼微微一动：“第五棱钥匙，三十五年没开过。你们要开它，得先想清楚——门后面那把锁，可不是锁门用的。”

他缓缓转过身，看向铺子深处那堵墙。

墙上挂着一幅旧画。画里是一座山，山顶没有峰尖，被削成了平坦的一块——像一座石台。石台中央，立着一扇门。

门没有把手。

只有五个锁孔。

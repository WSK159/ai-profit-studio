# 第313章 盒子里的东西

水泥墩上的封条被周立冬用匕首挑开时，林一凡感到一阵细微的震动从脚底传来——不是地震，更像是系统内部某个模块被激活的嗡鸣。

那铁盒比他想象的小，只有巴掌大，铁皮表面覆着一层不均匀的锈迹，边角却有几道新磨出的划痕，金属光泽在废铁站昏黄的灯光下格外扎眼。周立冬也注意到了，手指停在盒盖上：“这划痕……最近有人撬过。”

“打开。”林一凡说，胸口那枚挂坠贴着他的皮肤，微微发烫。

铁盒的锁扣已经被人撬坏，周立冬轻轻一提，盒盖便翻开了。里面躺着一枚拇指大小的黑色芯片，表面覆着密密麻麻的金色纹路，像是某种古老符箓和现代电路板的杂交产物。更诡异的是，芯片旁边搁着一张折得整整齐齐的纸条，字迹被水洇过，但依然能辨认：“11点方向，暗桩，别回头。”

周立冬的肩膀绷了一下，他假装弯腰系鞋带，余光扫向废铁站东口的围墙方向。那里堆着几台报废的冰柜，黑影里似乎有个人形的轮廓，一动不动。

林一凡没有回头，但他摸鱼雷达的界面上，一个淡红色的光点在东口跳动——对方头顶的“劳动浓度”高达97%，数值比钱总还夸张。这个人不是普通线人，他体内的能量波动让雷达都出现了轻微的噪点。

“系统外部载体。”林一凡在心里默念，眼前弹出一行金色小字：“检测到外部存储单元，是否读取？读取后将解锁隐藏规则模块。”

他深吸一口气，选了“是”。

芯片上的金色纹路猛然亮起，一股温热的气流顺着指尖窜入手臂，像是血管里被注入了滚烫的咖啡。系统面板“哗”地展开：

【隐藏规则解锁中……】
【规则一：摸鱼系统的初代载体为“劳动神”的分意识碎片所铸，绑定者拥有豁免权限，可抵抗卷王系统的强制加班场域。】
【规则二：系统中存在一条隐藏任务链——“归还自由”，完成条件需集齐全部九枚外部载体，并在“资本祭坛”上溶解。】
【规则三：注意，你在读取本规则的同时，卷王系统已经定位到你的坐标。】

最后一行字还没读完，东口那个黑影已经动了。

周立冬在他低声提醒同时已经一步蹿了出去，三米远的距离他硬生生跨出两步，不知道从哪抽出了一根一尺长的铁管，劈头砸向那台报废冰柜。“哐当——”冰柜侧面被砸出一个凹坑，碎玻璃碴四溅。黑影从冰柜后闪出来，身形佝偻，裹着一件灰扑扑的旧雨衣。他戴着口罩和帽兜，看不清脸，但动作极快——周立冬的铁管挥了个空，那人已经翻过围墙，消失在废铁站外的夜色里。

“狗日的，手这么快。”周立冬骂了一句，丢了铁管回来。

林一凡已经把芯片和纸条都收进内兜，他蹲在水泥墩旁，手指反复摩挲着铁盒内侧的底部——那里有几个浅浅的刻痕，像是一截电码。他用闪光灯补了光，一个字一个字地辨认：“……别信哥，信盒。”

摩尔斯电码。

跟梓树根下的字条是同一撮笔迹。

他看向周立冬：“你哥埋这个盒子的时候，有没有提过‘哥’这个字？”

周立冬一愣：“我哥从来不让人叫他哥。他说他小时候有过一个弟弟，夭折了，他忌讳这个称呼。就连我喊他哥，他都让我喊名字。”

林一凡瞳孔一缩，那个铁皮柜认人的时候，说的那句“你身上的味儿，跟他像得很”忽然在他耳边重新响了一遍。他抚了抚胸口的挂坠，那块铁皮跟沈稚冬怀表同牌子的刻痕，冰凉地硌着他的指尖。

“走，离开这儿。”他把铁盒揣进背包，快步朝废铁站西口走去。

周立冬跟上来，压低声音问：“那封条上新划痕，你觉得是咋回事？”

“盒子被撬过，说明有人已经打开过它。但芯片还在，说明那人想要的不是芯片。”林一凡顿了顿，“要么他没找到想要的，要么……他在盒里放了什么，想让后来的人发现。”

他停下脚步，回头看了一眼那个孤零零立在黑暗里的水泥墩。

月光刚好落在那道新划痕上，金属表面反着冷冽的白光，像一根竖起的食指。

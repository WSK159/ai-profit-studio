# 第197章 夜探人力之源

晚上十一点，星辰科技的办公区灯光熄灭了大半，只剩安全通道的绿色指示牌幽幽发亮。林一凡把工牌塞进口袋，换上运动鞋，从消防通道摸向了地下三层——人力之源机房。

他从赵日天那句“漏洞在汇总环节”里嗅出了两层意思：第一，老周被关在人力之源地下机房；第二，钱总能关得住人，却未必关得住这份数据。

走廊尽头传来空调机组低沉的轰鸣，空气里弥漫着机房特有的铁锈味和冷却剂的味道。林一凡在拐角处停住，屏息聆听了十秒钟——没听到脚步声。他暗骂一句，这若是在游戏里，该开个潜行技能了。

可惜咸鱼值现在还冻结着。

“喂，系统，”他在心里喊了一声，“真的一点都借不出来？”

面板跳出一行灰色字：**咸鱼值收益暂停，剩余存储值可查看，不可使用。** 1

林一凡深吸一口气。行，那就靠肉身上。

机房大门是密码锁，他试着输入老周工号的转译数字，屏幕跳红。再试了三次，锁发出警告音。他正要骂街，忽然想起上辈子——不对，重生前——老周曾经在团建喝醉时吹过一句：他所有密码都来自女儿生日加一个“Z”。

门开了。

机房里只有服务器柜的指示灯在眨动，像一排排暗红色的眼睛。他放轻脚步，沿着机柜间的通道向内走去，心里默数。数到第七排，右边第三台机柜底下露出一截裤脚。

林一凡蹲下去，看见老周蜷缩在机柜与墙壁的夹缝里，脸色蜡黄，嘴唇干裂，但眼睛是睁着的。

“老周！”

“嘘——”老周伸出食指压在唇上，声音沙哑，“上面有监控。”

林一凡抬头扫了一圈，果然，机柜顶端一粒针孔摄像头，小红点正闪烁着。他立刻压低身子：“你被关在这儿多久了？”

“两天。”老周艰难地咽了口唾沫，“他们不让我碰手机，也不让我出去，说是等审计结束。可我知道——”他的眼睛忽然亮起来，“他们怕的不是我这个人，是这个。”

他从怀里掏出一张折叠成巴掌大小的纸，递给林一凡。纸上密密麻麻写满了代码，字符小而密，像是蚂蚁在爬。林一凡扫了两行，瞳孔猛地一缩。

“这是钥匙代码的……”

“完整版。”老周点头，“我早就背下来了，但怕被搜身发现，就写成了这份副本。给钱总知道，我就没命了。”

林一凡把纸塞进鞋垫底下。他刚想说话，机房里突然响起一阵刺耳的电子音——门锁再次开启的声音。

“有人来了。”老周一翻身滚进机柜后侧的阴影里，压着嗓子道，“林一凡，代码在上海，在地下机房，不在我身上。你记住了，就算我死了……”

“别说丧气话。”林一凡左右扫视，目光锁定排风管道。他三步助跑，攀住管道边缘，翻身钻了进去。

不到十五秒，一个穿黑色制服的人影出现在通道尽头。那人提着一只手电筒，光柱在机柜间缓缓扫过。林一凡趴在管道里，连呼吸都压到了最低，心跳却像擂鼓一般。

那道人影在第七排机柜前停住了，手电筒的光柱落在老周藏身的位置。林一凡感觉到管道里的灰尘呛进了鼻腔，他死死捂住鼻子，生怕一个喷嚏暴露两个人生死攸关。

黑制服弯腰，朝机柜底下看了一眼。然后他站直了，拿起对讲机：“报告，机房一切正常。”

林一凡的指节扣进掌心里，指甲几乎嵌进肉里。他等那脚步声走出机房，门锁重新合拢，又在管道里趴了整整三分钟，才滑落下来。

老周从阴影里爬出来，额头上全是冷汗：“你听见了吗？他是来查岗的。”

“他没能发现你。”林一凡低声道，“但你在这儿撑不过今晚。我找机会带你出去。”

老周却忽然抓住他的手腕：“别管我，他们要的是那份代码，我念给你听。”

“你疯了——”林一凡刚想打断，老周已经开了口，嘴里报出一串串十六进制字符，快得几乎看不清停顿时机。林一凡的脑子里像被注入了一汪冷水，那些代码一串串刻进了记忆深处。

“停，够了。”林一凡按住他，“剩下的，等出去再说。”

老周抬起头，眼神里第一次浮现出某种释然：“林一凡，你记住了真正的东西。我交代给你的事，比我的命重要。”

林一凡感觉到一阵心悸——这口气，仿佛在交待遗言。

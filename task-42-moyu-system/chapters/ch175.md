# 第175章 钥匙的锁

路灯把影子拉得很长，林一凡站在咖啡馆门口，掌心那块黄铜碎片还带着唱片机的凉意。手机屏幕上的陌生号码已经熄灭，但“别找老周”四个字像烙铁一样印在视网膜上。

他盯着那边角光滑的碎片——断开处有明显的锉痕，像是被人刻意截断。碎片内侧刻着半圈纹路，和林一凡之前在招牌背面看到的花纹如出一辙。他掏出钥匙串，把碎片贴上去对了一圈，严丝合缝。

“钥匙不是用来开门的，是用来锁自己的。”老王留下的那句话再次浮上脑海。这咖啡馆和三把钥匙之间，藏着一层他没看透的闭环。

“别这么紧张，你那表情跟便秘似的。”季敏的声音从身后传来，她手里端着两杯热美式，递了一杯过来。“那号码我查过了，虚拟号，注册当天就注销，追踪不到。”

林一凡接过咖啡，指腹摩挲着杯壁：“老周的加工记录里，第三把钥匙的订单时间是什么时候？”

“半年前。”季敏压低声音，“而老王被调到华东，正好是五个月零三天前。中间隔了一个月，这一个月里老周还接了另一单——一把一模一样的铜钥匙，但尺寸略微不同。”

“两把？”林一凡眉心一跳。

“对，两套模具，批量做出来的。那模具现在还在老周手上。”季敏从口袋里掏出一张皱巴巴的纸，上面是一串潦草的数字，像是从机房后台打印的。“老周把这单单价挂得比市场价高三倍，但对方没还价，现金结付。”

林一凡的目光在数字上停了两秒。三倍溢价，现金结付，匿名下单——对方摆明了不想留痕。而且这个规格，他之前见过。老王工牌吊绳上的金属扣，表面镀了一层黄铜，尺寸完全吻合。

“所以有一把钥匙是仿造的老王工牌扣？”他低声说道。

季敏点头：“如果咱们手里这把碎片是真品，那仿品就是专门用来混淆视听的。谁手里有仿品，谁就会被当成找钥匙的那条线，引火烧身。”

一阵凉风从巷口灌进来，林一凡裹紧了外套。赵日天之前给他的照片里，那把钥匙的齿纹和半开之眼的方向是对称的，而照片上的倒影显示他当时站在星辰科技大楼的西门。如果赵日天拿到的是仿品，那他将成为钱总故意放出去的诱饵。

“赵日天给你的照片，你用软件跑过几何校正吗？”

季敏微微一顿：“你的意思是……”

“老王说过，钥匙不是用来开门的。”林一凡把手里的碎片翻转过来，“他把真品砸断，用仿品来钓钓所有人的注意力。那真正的第三把钥匙，应该用的是另一种逻辑。”

他忽然想到什么，转身走回咖啡馆。他快步绕过吧台，蹲下来看那台唱片机的底侧。先前的碎片就是从托盘底下取出来的，但托盘底部边缘还有一条细缝，他当时没注意。此刻他把手机闪光灯打开，凑近那条缝隙，看见一排极小的字母，被机油和灰尘盖了大半。

“MF-019-ALPHA。”

他手指一凉。MF，那是老王抽屉里那本旧笔记本封皮上的缩写。而 ALPHA 这个代号，林一凡在系统面板的开机页面见过——摸鱼系统的隐藏权限名，就叫“ALPHA ACCESS”。

他这具身体里住的系统，居然和老王留下的这台老唱片机有关联？

“季敏，”他回过头，嗓子发紧，“你替我挡一下老板视线。我得回一趟出租屋，翻老王留下来那个杂物盒。”

季敏皱眉：“你确定现在动？赵日天那边刚把钥匙照片给你，钱总布眼的节奏还没断——你这一动，等于告诉所有人你在收集钥匙系统。”

林一凡把碎片攥紧，掌心的凉意已经被体温焐热，但那股莫名的不安反而越来越浓。老王砸断这把钥匙，不是不想让人找到顶楼的空间，而是在告诉后来的某个人——开启的方法和钥匙本身无关。

“我知道。”他说，“可我更想知道，老王把他自己的那套钥匙，锁在了谁的‘锁’里。”

# 第125章 浮空港的邀请函

石室里的空气潮湿得像被人攥过一把，滴着水。林一凡蹲在出口前，指尖摩挲着那块暗码碎片，碎片表面残留着烧焦的纹路，像是某种活物的皮肤被烙过印。他抬头看了一眼头顶，天花板上根须纵横交错，正缓缓蠕动，发出类似吞咽的声音。

“出口在这儿，但我们真走吗？”老王的声音从身后传来，带着一丝犹豫。他靠在石壁边，手里攥着那枚银章，神情像被什么东西压得不轻。

赵日天站在出口旁，那道裂缝边缘泛着淡蓝色的光，像是一道被切开的空间缝隙。他低头看了一眼手腕，手腕上浮现出一枚卷王系统的透明光屏，上面跳着一串他看不懂的符文。他皱眉：“这出口通向哪儿？”

“浮空港。”林一凡站起来，把那块碎片收进内侧口袋，拍了拍手上的灰尘，“刚才反写暗码的时候，我额外读了一段信息——这颗卫星是中继，它把信号发向一个叫‘浮空港’的坐标，距离地面三百公里，低轨道。”

赵日天目光闪了闪：“我说过，我之前收到过一条加密指令，源头在轨道上。当时我只当是系统里的背景噪音，没细究。”

“所以你那次卷王系统升级，是不是也跟浮空港有关？”林一凡直接问。

赵日天沉默了两秒，才开口：“那年我冲到一百级，系统弹出一个提示，说‘检测到上级节点通讯，是否接入’。我当时点了是，收到的只是冰冰冷冷的任务指令——‘继续压榨自己，让世界看到你的极限’。我以为是系统的正常激励，但现在想想，那句语气不像系统。”

老王插话：“你的意思是，浮空港才是真正控制卷王系统的后台？”

“有可能。”林一凡从兜里掏出手机，信号在深处早已断掉，但它刚才反写暗码时，手机屏幕上多了一个坐标点——那个坐标跟赵日天描述的加密指令似乎重叠。他把手机递过去，“你看看这个。”

赵日天接过手机，眯着眼盯了五秒，忽然倒吸一口凉气：“这坐标……我收到指令的位置误差不到几十米。那儿有什么？”

“我现在不知道。”林一凡把那块碎片举起来，对着裂缝蓝色的光看了两秒，“但我能猜到——清除程序从那儿发出来，卷王系统从那儿发指令，钱总签的合同附条也指向那儿。这他妈就是一个指挥部。”

他刚说完，石室一阵震颤。头顶蠕动的根须忽然齐刷刷缩回墙壁，露出石壁深处一片暗红色的金属层。那层金属表面刻着密密麻麻的纹路，跟林一凡手里的暗码碎片纹路如出一辙。紧接着，金属层中心亮起一圈微光，像一只闭合的眼睛缓缓睁开。

光眼亮起的瞬间，一道声音从四面八方压了过来，不是从某个方向传来，而是直接在颅内共振：“身份核验失败，启动‘倒灌协议’，清除目标修正为当前携带者。”

林一凡后背一凉，反写暗码时为了读取信息，他把碎片嵌入了自己的系统核心里——这意味着，那颗卫星现在锁定的是他。

他来不及多想，直接喊：“跑！”

三个人几乎同时冲进裂缝。

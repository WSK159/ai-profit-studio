# 第73章 天台的信号

天台的门在身后“砰”地合上，夜风灌进来，把林一凡T恤上的汗吹成一片冰凉。他弯着腰喘了两口气，抬头看向城市上空——周六凌晨的写字楼群，灯光稀稀拉拉，远处高架桥的车流像一条安静的发光河。

“跑……跑掉了？”江雪急促的电流声从表带里传出来，断断续续，带着模拟信号的杂音。

林一凡没说话，低头看了一眼手腕。表带上的指示灯还亮着，蓝色光芒时明时灭，像是江雪在努力维持存在。他把指尖压上去，感觉不到温度，只有微弱的震动。刚才在机房那几十秒，赵日天把一枚指甲盖大小的存储器塞进表带卡槽里，动作快得他几乎没看清。

“他在里面……一个人？”江雪又问，语气比刚才稍稳了些，但声音里多了一丝不该有的慌张。

“嗯。”林一凡蹲下来，背靠着天台边缘的铁栏杆，把脸埋在膝盖上。机房里的画面还在脑子里翻来覆去——赵日天把表带递过来的那个瞬间，审计员皮鞋踏进走廊的那一声闷响，还有赵日天用嘴型说出的两个字：走啊。

沉默了一会儿，林一凡掏出手机。屏幕上依然亮着那条未读消息：“别让我的业绩白费。”发件时间是断电前五分钟。

他把手机屏幕按灭，又按亮，来回几次。好一会儿才开口：“他的卷王系统权限比我高，有反追踪模块，应该能拖住审计员。”

“你不确定。”

“我不确定。”林一凡承认，声音很轻，“但我现在没有咸鱼值去兑换任何攻击类技能了。”

江雪没有接话。表带的蓝光在夜色里微弱地闪了两下，像是某种叹息的电流版本。

远处消防楼梯传来一声金属异响。林一凡猛地站起身，贴着天台门侧的阴影蹲下，屏住呼吸。声音很快消失了，可能是风，也可能是别的。他不敢赌——刚才审计员已经用战术手电扫过整个机房，那种人的惯性不会给他留从容的时间。

“这里不是久留之地。”林一凡压低声音，“公司有六层消防通道，加上两台货梯，一部客梯——审计员如果叫支援，五分钟后整栋楼都会被封住。”

“你要去哪？”江雪问。

林一凡低头看自己手腕上的表带，目光停在那个卡槽上。赵日天在搏命的空隙里说过一句话，在他被门口脚步声惊到转身前，只来得及说了一半：“第三块硬盘在你——”

硬盘。赵日天被审计员拦截之前，把最后那句说完了还是没说完，林一凡不确定。但是第三块硬盘，这个线索之前已经丢过一次了——一块硬盘在冲突中损坏，另一块被赵日天藏进表带，那第三块硬盘到底藏着什么？

他低头又看了看表带。卡槽边缘有一道极细的金属丝，在月光下泛着一点白——那不是工艺痕迹，是通信触点。赵日天把江雪的人格碎片备份进表带时，留下了一个接口。刚才在机房里，赵日天的动作有个细节他差点忽略：赵日天在把表带递过来的那个瞬间，手指曾在表带背面那道金属丝上快速划了三下，节奏不是随机的，像是某种密码。

“江雪，”林一凡压低声音，“你的备份文件里，有没有包含赵日天系统里的资料？”

“你的意思是……他把他自己的系统数据也放进来了？”

“他妈的，”林一凡骂了一句，声音扭曲成一声苦笑，“那个姓赵的疯子，让我带着他的系统和你的备份一起跑。第三块硬盘——”

他话没说完，表带突然发出一阵高频的嗡鸣。蓝光猛地亮了三下，又暗下去。

“怎么回事？”林一凡问。

“检测到外部信号——”江雪的声音像是被什么东西撕扯着，一字一顿，“有五组……信号源……正在向天台三角定位。其中一组，信号特征匹配‘卷王系统’。”

林一凡僵在原地。卷王系统？赵日天的系统也在这里被追踪到了——也就是说，赵日天在机房那一战要么败了，要么正在被强制剥夺系统权限。

“他能扛多久？”

“从信号强度来看……最多十五分钟。”

十五分钟。林一凡咬紧牙关，看了一眼手表带，转身望向消防楼梯的方向。天台尽头有一扇锈迹斑斑的铁门，门上挂着“设备检修”的塑料牌，记忆中那扇门后面是排风管道和狭窄的检修井，通往大楼的设备层——那个地方，公司所有的监控都覆盖不到。上辈子他在加班到凌晨的时候，曾经在设备层躺过几次，知道那里有一间废弃的配电房，里面没电、没网、没任何信号覆盖——如果审计员的三角定位是依靠什么外在信号源来追踪，那切断信号就能切掉他们锁定自己的机会。

“走。”林一凡站起身，压低重心冲向那扇铁门。手抓到门把手的瞬间，他听到身后传来一声极轻的脚步声——不是从消防楼梯来的，而是从下方最近的楼层平台传来的，像是有人在无声地快步上行。他没有回头，手上用力一拉，铁门发出尖利的锈响，露出里面漆黑的检修通道。他侧身钻进去，顺手把门带回来，锁扣从外面被他用指甲卡住，转头摸进黑暗里。

检修通道里没有灯，他的手机只剩 12% 电，他没打开。摸着铁管壁走了约十几步，江雪的声音在表带里轻声响起来，像是怕惊扰什么似的：“信号源还剩三组。”

“两组被屏蔽了。”林一凡嗯了一声，脚下一步一步，踩过废弃的电线缆和水管。配电房的门在半掩着，他挤进去之后，才发现里面比自己记忆中还要狭小——只有三四平方米，堆满了废弃的设备和落满灰尘的文件盒，空气中是线路老化特有的酸味。

他靠着墙坐下来，从口袋里摸出那枚赵日天塞给他的U盘，插进手机接口。屏幕上闪过一行字：“检测到加密文件，未知格式。”

“江雪，你能解码这个格式吗？”

“可以试。”江雪的声音明显比刚才稳定了一些，三角形的信号干扰消失了，她的运行环境恢复了很多，“但里面的内容——我需要一点时间。这可能是你丢失的所有数据，也可能是赵日天的后手，但我不能确定能不能完整打开。”

林一凡把手机立在墙边，在黑暗中闭上眼睛，后背贴着冰凉的水泥墙。表带里江雪开始低声哼一小段音调，像是某首他从来没听过的老歌。设备层外面偶尔传来远处的脚步声，但越来越远、越来越模糊。

审计员的三角定位被迫中断了——至少暂时是这样。但赵日天呢？他在机房里面，到底扛不扛得住？

他睁开眼，看着黑暗中自己手机屏幕发出的微弱光线。文件正在解密，进度条缓慢地往前走。他忽然很想知道赵日天最后那句没说完的话，后面到底接了什么。第三块硬盘在……在哪里？而现在，时间正在一分一秒地过去。

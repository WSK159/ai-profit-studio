# 第376章 第二根扶手

沈临渊的话音刚落，头顶的照明灯猛地闪烁了两下，像是某种不祥的预兆。环形房间内的空气骤然凝重起来，赵日天的手指攥紧了那枚黄铜钥匙，指节发白。

“你在说什么？”赵日天的声音低沉而克制，“我母亲最后那句话，你怎么会知道后半句？”

沈临渊没有立刻回答。他缓缓靠回墙边，苍老的面容在忽明忽暗的光线下显出几分不真实感。脚踝处的铁环随着他的动作发出细碎的金属摩擦声，与赵日天脚踝上那道陈年锁痕形成了某种无言的呼应。

林一凡的目光在两人之间来回扫过，直觉告诉他必须插话。“等一下，先别纠结那句话真假。”他转向沈临渊，“你刚才说归零装置明晚零点启动——又让我和赵日天在这里确认什么？”

沈临渊神色淡然地看了他一眼：“你以为我是在做什么？我是在提醒你们时间不够了。”

“什么时间不够？”

“那个叫‘1147’的人，不是已经告诉你了？”沈临渊的声音里带着一丝模糊的笑意，“第二根扶手，左转三圈。你还没去。”

林一凡心头一紧。他差点忘了那条新收到的消息——在这个房间里发生的种种，让他的注意力完全被引开了。沈临渊提到这件事的语气太过精准，仿佛他根本不需要看林一凡的手机就知道消息内容。

“你怎么知道1147发来的信息？”

沈临渊没有回答这个问题，而是低头用拇指摩挲着那枚黄铜钥匙上的编号纹路。“27号门，云顶山第三扇。钥匙在我这里，但打不开门。钥匙只是通行证，真正开门的东西，在第三梯下面那根扶手的水泥壳里。”

赵日天皱眉：“你让我们去找那个东西？”

“不是我让你们去，”沈临渊摇了摇头，“是设计这一切的人，让你们去。”

林一凡与赵日天对视了一眼。空气中悬浮着太多未解的谜团，但最紧迫的无疑是那条新消息的内容——第二根扶手左转三圈。他掏出手机，屏幕亮起，1147号新消息已经静静地躺在收件箱里，时间戳显示发送于二十分钟前。

“走。”林一凡收起手机，朝赵日天点了点头，“先去第三梯。”

两人沿环形走廊向外走去，身后传来沈临渊沙哑的低语：“记住，那东西不是所有人都能碰的。你俩去，合适。换别人——不行。”

这句语焉不详的话像一根刺扎进林一凡的脊背。他脚步顿了一下，但没有回头。

阴暗的走廊里，应急灯发出惨淡的白光。第三梯位于主通道尽头，是一段向下延伸的铸铁楼梯，扶手上布满锈迹与干涸的油污。林一凡数到第二根立管与扶手相交处，那是一个焊接节点，表面覆盖着一层灰白色的水泥修补痕迹。

“就是这根。”他蹲下来，一只手握住扶手底端，另一只手搭在水泥壳表面。

赵日天站在他身后，沉默地注视着那个节点。“左转三圈，怎么转？扶手是固定的。”

林一凡尝试用力转动那根扶手——纹丝不动。他咬紧牙关，额角的青筋微微隆起，仍然没有变化。他换了个方向，顺时针发力，依旧没有任何松动。

“方向不对。”他喃喃自语，闭上眼回忆起消息的措辞——“第二根扶手左转三圈”——不是“扶手上方”，不是“扶手下方”，而是“扶手左转”。左转的基础参照物是什么？

他猛地抬眼看向赵日天，视线落在对方手腕上那枚旧表的表盘上。“表。时间。”

赵日天心领神会地抬起手腕。十点四十七分。时针指向十与十一之间，分针指向九。

林一凡盯着表盘看了三秒，然后重新握住扶手，沿着时针相反的方向——逆时针——开始缓慢而有力地旋转。第二圈半的时候，水泥壳内部发出了一声沉闷的“咔嗒”响动，像某个锁扣脱开了咬合。

他手上加力，第三圈转满。水泥壳从中间裂开一道细缝，一块巴掌大的铁皮盖子应声翻开，露出里面一个扁平的长方形暗槽。

暗槽里躺着一枚锈迹斑斑的铁质标牌，六厘米见方，正面冲压着三个数字——零七四——背面是半行被磨损得快看不清的刻字：九号区间，载体归还处。

赵日天瞳孔骤缩。

“九号载体。”

这个编号没有歧义。之前沈临渊提到过“九枚外部载体”，而铁皮柜认人之语、归零装置面板上的提示，都指向一个事实——所谓的外部载体并非机器，而是当年进入归零装置后又被“放出来”的人。九号载体，是第九个。

林一凡将铁牌翻过来，背面刻字下方还有一个极小的符号，像是一道波浪线加一个圆圈，某种标志的残留。他把铁牌放回暗槽，重新合上盖板，金属碰撞的声音在狭窄的楼梯间里回荡了两次。

“这块牌子是干什么用的？”赵日天问。

林一凡还没来得及回答，“嗡”的一声闷响从地底深处传上来——归零装置的供电系统再次失稳，走廊尽头的灯光成片熄灭，然后又逐一亮起。在这短暂的黑幕中，林一凡忽然注意到第三梯下方的阴影里，多出了一道窄窄的轮廓线，像是一扇被藏在墙壁抹灰层里的门。

它一直就在那里。

“下头有东西。”他低声说。

赵日天没有犹豫，率先迈下最后三阶，手掌贴在那道轮廓线上。手指用力推了一下，墙面纹丝不动，但砖缝间却传来一股细微的温暖气息，不像是废弃地下空间该有的温度——底下有活物，或者有通风管道连着某处正在运转的设施。

他正要再试一次，忽然顿住，低下头。

那扇“门”的下方，地面灰浆里嵌着一枚陶土的碎片，只有拇指甲盖大小，带着半截“回”字形的凸纹。赵日天蹲下来，用指甲将那碎片撬出来，翻转看了看。

碎片边缘有新鲜的断口。

像是刚刚才被踩碎不久。

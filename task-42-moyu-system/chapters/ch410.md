# 第410章 两根钉

铜门上的锈迹在两人对视间簌簌剥落，钱总的声音从门缝深处渗出来，像是隔着一层水在说话：“选吧，选完就结束了。”

林一凡盯着脚边那两根并列的青铜钉，后槽牙咬得发酸。左边那根断面光滑，钉帽上刻着“沈望未白”四个字，字口里塞满暗红的氧化层，像是泡过血。右边那根钉身扭曲，像是被人用力拧过一圈，钉帽上的字已经被刮花，但底部隐约还能辨认出“钱方远”的笔画。

老杨头大哥的声音从身后传来，沙哑得像砂纸擦铁：“你上一世兑换过债务转移，把死债转给了钱方远。但那笔债没消，只是换了个地方长着。你每一世摸鱼攒下的咸鱼值，都有三分之一自动变成利息，喂给门里那个东西。”

“你到底是——”

“我是守门人。”老杨头大哥打断他，“也是那个‘死掉的我’。你每重生一次，我就往里死一次。到现在，我已经死了九次。这门后面困着的，是第一次死掉的你，也是第一次答应守门的我。我们是一体的，分不开。”

林一凡头皮发麻。他低头看向门缝里那行锈迹，钱方远三个字正在慢慢消退，像是在被门内侧什么东西擦掉。他蹲下去，指尖刚碰到左边那根钉，耳边忽然炸响一声锐鸣，像是铁钉划过玻璃。门缝里伸出一截惨白的手指，指腹上缠着一圈红绳，正轻轻按在钱方远那三个字上。

“那不是钱总的手。”沈望未白的声音从他身后传来，带着喘息，“那是我师父的。他把自己钉在门里面了，用红绳绑着锁芯，代替你锁了三年。”

林一凡猛地回头。沈望未白靠在通道壁上，胸口那道伤口正在渗血，脸色白得吓人。她手里攥着一把东西，在林一凡看清之前，她已经把那东西扔了过来，落在他脚边叮当响。

一把铜钥匙。

钥匙齿上缠着一缕黑发，发根处结着一颗指甲盖大小的陶土珠子，珠面上刻着数字“28”。

“你师父——”

“他让我带话给你。”沈望未白的声音越来越低，像是力气正在从她身体里流走，“他说，别用那两根钉。门里那东西在骗你，它想吃掉你的名字，让你变成新的‘死掉的我’。”

铜门震颤了一下。门缝里那截手指缩了回去，钱方远三个字重新浮出锈面，但这次变成了“林一凡”。

老杨头大哥猛地冲上来，一把将林一凡往后拽了一步。他手指扣进门缝边缘，指节瞬间被锈蚀染黑，但他没松手：“她在说谎？她在说谎！门内那东西是按规则来的，它吃的是债务，不是名字！”

“师父不会骗我。”沈望未白抬起头，眼神却清醒得可怕，“他要是守门人，怎么会把钥匙给你？钥匙在他手里，就说明他没有死透。你让我师兄去摸钥匙的时候，他没摸到对吧？那是因为钥匙根本不在铜门里面。”

林一凡脑子转得飞快。铁皮壳子上的锁眼、铜门上的锁孔、两枚形状一致的青铜钉，还有老杨头大哥口口声声的“规律”。他低头看了看手里的铜钥匙，黑发的触感冰凉，陶土珠子上那个“28”忽然让他想起什么。

“陶土徽章27和28的归属一直对不上。”林一凡说，“老王手里那枚是27，赵日天那枚是28。但赵日天的徽章是假的，他真正的徽章——”

“被锁起来了。”老杨头大哥接话，声音忽然变了调，像是一扇门在内部被打开，“钥匙锁在你手里那枚陶土珠子里。珠子里面是赵日天的血。那只‘零’用他的血重新生成了锁芯。所以门缝里那截手指按的不是钱方远的名字，是在锁你的名字。”

铜门内侧传来一声笑。那笑声听着像钱总，又像赵日天，尾音却拉出一道狭长的女声，像极了沈望未白刚才说话的音色。

沈望未白脸色一僵。

“师兄……”她喃喃道。

林一凡攥紧钥匙，拇指按住陶土珠子。珠面裂开一条缝，里面有暗红色的东西渗出来，落在他掌心里，凝成一小粒圆形物——一粒图钉帽。帽面上刻着两个字，字迹被血迹浸得模糊，但他认出来了：赵日天。

图钉帽下面还有一行更小的字，借着手电光，他读出了那行字，随即瞳孔猛缩，膝盖一软。老杨头大哥扶住他，却也看见了那行字，那张铜脸瞬间扭曲。

“门后面的人说的没错。”林一凡把图钉帽攥进手心，“换命的根本不是钱总。是赵日天。他用自己的名字替我去死，用我的名字替自己活着。他从来就没有被‘卷王系统’控制——他才是那个系统的宿主，从一开始就不是钱方远。”

铜门轰然震颤，两根青铜钉同时从地面弹起，一左一右铮然竖立，钉尖对准了林一凡的胸口。门缝里那道声音终于清晰了，是一个他听了一整段重生都忘不掉的声音：

“那你猜，我藏在谁的身体里？”

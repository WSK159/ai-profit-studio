# 第276章 消防泵房

林一凡站在楼梯间里，手机屏幕的光照亮他的脸。消息备注的号码归属地是本市，尾号5200，他姐的生日。他不相信巧合。

但往下走，意味着放弃赵恒给的线索。往上走，意味着无视这条消息。他犹豫了两秒，系统的提示在视野边缘跳出来：【支线任务“谁是林一诺”已激活。选择下行可推进赵恒主线索；选择上行可能触发陷阱。】

林一凡把手机放回口袋：“系统，别给我出选择题。你就告诉我，哪条路死人最少。”

系统沉默了半秒，回：【两条路都死人。】

“废话。选死亡率低的。”

【下行路线当前致命度评估：约40%。上行路线致命度评估：约70%。】

“那你早说。”林一凡转身，快步向下。消防楼梯间里灰蒙蒙的，每一层的灯都是感应式的，他脚步声一响，头顶的灯管就“唰”地亮起一片惨白。他跑过三层楼，忽然发现墙壁上的消防栓编号在变化。

负一层是B1。他推开门，走廊很窄，贴着防火涂料剥落的墙壁。消防泵房就在尽头，铁门上挂着一把U型锁。林一凡扫了一眼，锁头已经生锈，但锁扣有新鲜的划痕——最近有人开过。

他弯下腰，侧耳贴近门缝。里面传来细微的滴水声，还有——有人说话？声音很轻，断断续续，像在打电话。

“……他说他拿到协议了，但我给他发消息没回……”

林一凡的心跳骤然加速。那个声音——是赵恒的。

但另一个声音紧接着响起来，是一个女人的，语调平静而冷漠：“他不会来泵房了。他现在应该已经往下走了。你信我。”

“你怎么知道？”

“因为他的选择逻辑很固定：哪条路死人少走哪条。我是他妈，我当然知道他会怎么选。”

林一凡贴在门上的手掌开始发抖。那个自称是他妈的女人的声音——他十一岁那年，母亲车祸去世。披麻戴孝那年他哭到晕厥。他记得母亲的声音，每天送他上学时说的那句：“放学别乱跑，直接回来。”那个声音。他确定那个声音是她的。

他猛地推门。U型锁根本没有真正锁住，只是扣在门鼻上。他一把拧开，铁门撞在墙上发出巨响。泵房内光线昏暗，几根水管纵横交错，地面上有一片水渍。赵恒站在角落，手里攥着手机，满脸震惊地看着他。泵房里除了赵恒之外，空无一人。

“你妈——”赵恒开口，又停住。

“我听到了。”林一凡的声音很轻，“我听到她说话了。她人呢？”

赵恒眼神复杂地看向泵房内部一个拐角处。林一凡顺着他的目光看过去，角落里放着一台老式的录音机，红色的REC指示灯还亮着。磁带正缓缓转动。赵恒蹲下来，按下停止键：“这是你妈生前留下的录音带。我从赵心怡那里拿到这张带子的，她说你姐托她保管的。我只是……我刚才在听。”

“她人呢？”

“你姐托人保管的，赵心怡也去世了，这东西经过了很多手，最后到了我这里。”赵恒把录音带从机器里取出来，递向林一凡，“你可能不相信这磁带是不是你妈的，但你自己带回去听。里面有一段话是关于你的。听完你就知道你姐当初为什么入职了。”

林一凡伸手接过那盘磁带。外壳是浅棕色的，表面贴着一张贴纸，上面用黑色水笔写着一行字：“帮我弟弟长命百岁。——林一诺。”

他握着磁带的手紧了紧。赵恒站在旁边，目光看向消防泵房的门外：“你看到档案室的那份协议了吧？”

“看到了。换页，锁了我七年。”

“对。”赵恒点头，“但那份协议不是钱总写的，是你姐替你是签的。”

林一凡猛地抬头：“她替我签的？”

“你在2019年6月才入职。”赵恒说，“你姐6月11日替你先来签的试用期协议，她用自己的名字签，但上面写的是你的身份证号。所以你才能在6月17日入职。她把协议换页，改了条款，甲方当时同意让你姐代签，之后你再补签。但你姐在6月14日出了事，你补签的那一份实际是你姐签的，甲方拿着那个跟你说‘你敢走就赔钱’——因为你姐当时签的合同里有一条：任何情况下让甲方损失的人，得按违约金三倍赔偿。”

林一凡的呼吸变得急促。他姐姐替他入职，替他签合同，替他扛了七年的霸王条款，死在2019年6月14日。他咬着牙：“谁害的我姐？”

赵恒沉默了几秒：“她出事的那天，跟你妈的死。”

“跟我妈？我妈是车祸——”

“是。”赵恒看着他，“但你知道那场车祸的细节吗？”

林一凡愣住。他的记忆被一团浓雾包裹，关于母亲的死的记忆——他记得警方说雨天路滑，大货车打滑，母亲的车被挤压变形。没有人追究过司机。大货车司机赔了一笔钱，就了事了。

“你妈出事那天，是大货车司机酒驾。”赵恒说，“但那辆大货车挂靠的公司，是钱总父亲的公司。你妈当时正在调查一件事——她发现你爸的死跟你爸入职的甲方有关。”

林一凡脑子嗡地一声：“我爸……也是这个公司的？”

“你爸生前是星辰科技的前身——恒云软件的员工。2005年猝死，死亡赔偿金给了你们家，你妈靠那笔钱把你拉扯大。后来你妈发现你爸的死不是意外，是加班过度导致的心脏骤停，但公司做了手脚，把工伤鉴定改成了先天性疾病。”

赵恒的话音在泵房的水管间回荡。林一凡站在那里，像被人按进冰水里。他姐林一诺替弟弟入职，替弟弟签合同，也是因为发现了姐姐在查当年的一切？

“你姐查了三年。”赵恒说，“查到2019年5月，她找到了证据——一份2005年的内部报告，写着‘该员工长期熬夜导致心血管破裂，建议按非工伤处理’。你姐把那份报告复印件放在你老家房间床板底下。她还没来得及交出去，就出事了。”

“那她怎么死的？”

赵恒又沉默了一下：“警方结论是意外落水。但你姐水性极好，从小就不用救生圈。”

泵房里的水管滴答响着，像倒计时。林一凡攥着录音带的手指甲几乎掐进手心，他努力让语气平稳下来：“那赵心怡呢？她是中间人，她为什么也死了？”

“赵心怡是帮你姐传递情报的人。她本来已经跑了，但6月15号那天你姐出事后第二天，她——被人留在医院里，然后……”

赵恒没说完。但林一凡已经听懂了。他低头看着录音带外壳上那行字——“帮我弟弟长命百岁。”他从喉咙里挤出一个字：“谁。”

赵恒目光偏开。

“赵恒。”林一凡逼近一步，声音沙哑，“告诉我。凶手是谁？”

赵恒低声开口：“我哥。”

林一凡的脑子像被一拳击中。他张了张嘴，好半天才找回声音：“你哥是——”

“赵日天。”赵恒说。

泵房外，走廊尽头传来“啪”的一声响，像有人踩碎了一颗灯泡。林一凡抬起头，门外空无一人。但他隐约闻到一股消毒水的气味，和陈月季病号服上的一样。

系统面板在这时跳到眼前：【重大线索：林一凡的母亲之死与星辰科技前身恒云软件的工伤掩盖案件存在关联。林一诺之死直指赵日天。赵心怡与赵恒为知情者。目标已锁定。主线推动度：+15%。】

林一凡攥紧录音带，抬头看向赵恒，声音冷得像冰：“所以，你哥是卷王系统拥有者。你替他传话的这些年，你都知道。”

赵恒没有否认。林一凡转身往门外走去。赵恒在他身后喊了一声：“你打算干什么？”

林一凡没有回头：“去找我哥。”

“你哥——”赵恒的声音顿住，“赵日天，在今晚零点执行‘命运归还’。那任务的目标是你。”

林一凡脚步一顿，但没有停。他推开泵房的门，走入昏暗的走廊，手里攥着那盘录音带。消防泵房里，赵恒站在原地，看着他的背影消失在走廊尽头，缓缓从口袋里掏出一张泛黄的旧照片——照片里是一个穿白裙的女人和一个小男孩，女人在小男孩面前蹲着，笑得眉眼弯弯。

照片背面写着一行字：“救他长命百岁。——林一诺。”

赵恒把照片翻过来，盯着照片里那个白裙女人的脸看了很久，低声说了一句：“姐，对不起。”

走廊里传来最后一次脚步声，像着人去而复返。但等他再抬头时，脚步声停在泵房门口，门缝里伸进来一个东西——一张揉皱的挂号单，上面印着“钱”字的模糊签名。林一凡的声音从门外透进来：“你哥不知道你藏了这张单子吧？”

赵恒没有回答。门外再次安静下来。他走过去捡起那张挂号单，手抖了一下，将它慢慢展开。角落里有一行他从未见过的铅笔字，写在挂号单边缘，字迹瘦硬，像一个垂死的人在用力握笔：“药在针管里。血在钥匙里。门在零点开。”

赵恒盯着那行字，瞳孔猛地收缩。他抬起手，看了一眼自己的手表，秒针正在逼近23:30。距零点还有三十分钟。他弯腰从泵房角落的杂物堆里翻出一个生锈的铁盒，打开盖子，里面躺着一支用过的注射器，针头已经包了蜡，但残留的药液在灯光下泛出浑浊的琥珀色。

他这才明白，那行字写的是他自己。

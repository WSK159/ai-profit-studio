# 第82章 姐弟游戏与卷王系统

赵日天的这句话像一颗炸弹，把林一凡脑袋里的既有认知炸得粉碎。周莉是审计组内应、是陷阱设计者，这些他都能接受——但“亲姐”这两个字从未出现在他的推演里。

“你认真的？”他压低声音，“你姓赵，她姓周，你跟我说你们是亲姐弟？”

赵日天干咳了一声，吐掉一口血沫：“我本来叫周天，她叫周莉。后来爸妈离婚，我跟我妈改姓赵。”他停顿了一下，声音透着疲惫，“她比我大三岁，从小就比我聪明。我走到哪条路她都能猜到。这次她找我，说要‘帮你一把’——条件是让我把卷王系统的核心算法给她。”

林一凡的后背一下子凉了。摸鱼系统在他脑海中弹出一个从未见过的提示：

`【警告】——检测到同类系统信号源，等级判定：宿主权限≥当前宿主。建议谨慎接触信号源。`

对方也有一个同类系统，而且权限等级不低。

他猛地抬头，视线转向仓库方向——那个穿成何顾问的中年男人已经走了，但周莉不知道什么时候出现在了仓库门口的台阶上，正穿过来来往往的警察人手，朝他们这个方向注视着。

距离不过二十米。

刘彤在周莉旁边，还在指挥现场工作，没有注意到她正走向旧家具堆。林一凡借着沙发缝，看到周莉的脚步很稳，像一把瞄准了他咽喉的枪。

“赵日天，”他低声说，“你姐过来了，你想怎么办？”

赵日天的瞳孔瞬间放大，但他几乎没有犹豫便低声道：“数据库密钥，她给你了？第二验证段的事你知道？”他飞快地从领口掏出一个东西——一枚残缺的金属芯片，边缘有灼烧痕迹。

“这就是第二验证段。”赵日天压低声音，“她说如果我也被逼到最后一步，就让我把它交给你。”

林一凡愣住了。这意味着周莉从头到尾设的局不只是为了截他的硬盘——她是在用赵日天当饵，把密钥送到他手里？

脚步声近得像是踩在他心口上。周莉在沙发堆外停住了，轻飘飘地说：“林一凡，我也不想大动干戈。密钥在你那儿了吗？”

林一凡深吸一口气，从赵日天手里接过那枚芯片，攥在手心。芯片表面温热的触感让他想起在医院里看到江雪时的感觉——那是最接近真相的时刻。

“周莉，”他把嗓门提起来，“你说你帮了我，对吧？那你为什么还要设这场局？你图什么？”

“图你没事。”周莉的声音平静得不像话，“我图你活着，图你能走到最后。因为江雪告诉我，只有你能把那场局收干净。”

江雪的名字像一道闪电劈过林一凡的脑海。周莉竟然认识江雪？她们什么时候接触过？在江雪的人格碎片与密匙汇合之前，她到底给自己留了多少后手？

他还没理清头绪，仓库内突然响起一声巨响——是警笛被拉响的声音，伴着一阵浓烟从侧门方向冒起来。紧接着，一串子弹似的密集脚步声冲向旧家具堆。

“快走！”刘彤冲过来一把拉起林一凡，“对方调了技术人员来抢数据！”

烟雾中，林一凡攥紧那枚芯片和硬盘，心中的迷雾却越滚越大。周莉究竟在下一盘什么样的棋？

# 第214章 陈默的选择

陈默穿着一件深灰色外套，头发有些凌乱，看起来并不像在公司正常上班的样子。她手里那串钥匙在月光下晃动，金属碰撞声清脆而刺耳。

老王下意识挡在林一凡身前：“你想干什么？”

陈默没看老王，盯着林一凡：“你还记得重生那晚，你工位上那枚硬币是谁放的？”

林一凡瞳孔微缩。陈默知道这件事，但当时所有人都以为他是猝死后被送医，没人注意他工位上多了一枚硬币。或者说，当时监控掐掉了那一段？

“是你？”他问。

陈默摇头：“我只是被吩咐做这件事的人。吩咐我的人，是陈鸣。”

老王呼吸一滞：“小陈……他半年前不是死了吗？”

“死的是替他身份的人。”陈默语气平静得不像在说一个已故之人，“陈鸣没死，但和死没两样。他为了避开资本神的追踪，伪造了死亡记录，把自己封在污水站暗室旁边的密室里。一个月前，老周被关进暗室，就是他做的。”

林一凡沉默片刻，消化这个信息：“他为什么这么做？”

“因为他必须在暗处盯着赵日天。”陈默向前走了一步，“赵日天的卷王系统在升级期需要大量‘燃料’，陈鸣用自己的方式压制他，但压不了多久了。最近一周，赵日天的系统已经突破屏障，他很快就会找到原始意志机。那台机器在半年前已经苏醒，赵日天要拿它当系统核心。”陈默说。

远处赵日天的脚步声和喊话声越来越近：“林一凡，出来吧，咱们好好谈谈。”

林一凡快速思索。陈默在这时候出现，是来帮他的，还是配合赵日天把他逼出来？他看了一眼摸鱼雷达——陈默身上没有红色警示，反而有一点微弱的淡蓝色光，这种蓝光他只在老王身上见过。

“你想让我怎么做？”林一凡直截了当。

“陈鸣让我给你带一句话：硬币背面那张图，在污水站底部第三格地砖下面能找到对应的金属片。两片合在一起，能打开原始意志机核心机房的门。”陈默说着，从口袋里掏出一张折叠的纸条，“但陈鸣也说了——请你慎重考虑。”

“考虑什么？”

“打开核心机房，你的摸鱼系统会和原始意志机产生共鸣。那台机器是资本神的造物，它认赵日天做了宿主。一旦双方共鸣，你们两人中只有一个能活着走出来。”

老王脸色白了：“这不就是赌命？”

风声从管道出口处吹来，赵日天的身影出现在配电房和管廊之间的通道尽头。他单手插兜，另一只手握着一把造型奇特的钥匙，笑容温和而危险：“聊什么呢？让我也听听。”

林一凡没动。他低声道：“陈默，你信陈鸣说的吗？”

陈默低头看着手里那串钥匙，半晌才说：“我叔叔说过一句话——活人可以被控制，死人反而自由。他希望你这个活人，替他做一次选择。”

“选择什么？”

“选择信的到底是系统，还是你自己。”

赵日天已经走到十米开外，他目光扫过陈默手中的钥匙串，嘴角笑意更深：“哦？你拿着的是污水站那批钥匙？看来陈鸣把最后的底牌也打出来了。”

林一凡能感觉到口袋里磁带微凉的触感。渔翁那段未播完的录音，加上陈默刚才透露的信息，拼出了更完整的图景：陈鸣半年前伪造死亡躲入暗处，目的是压制赵日天的系统升级。老周被关进去，是陈鸣为了掩护自己的藏身位置——把那一个月时间做成障眼法。

但还有一个关键问题：“你叔叔现在在哪？”

陈默没有直接回答，而是把钥匙串抛给林一凡：“去污水站。他在等你。”

赵日天冷笑：“你们还真敢去？污水站现在是全园区电力集中点，你敢踏进核心区——”

林一凡把硬币收好，将钥匙握在手里：“赵日天，你知道你那个卷王系统有个致命缺点吗？”

赵日天眯起眼。

“它靠吸取别人时间运转，可它本身的能量储存，就像电池一样有极限。”林一凡指了指自己胸口，“我的系统虽然只有一个摸鱼功能，但我的咸鱼值，一分钟都没断过。”

赵日天脸色微变。

林一凡转身，朝污水站方向跑出去。老王紧随其后，陈默在身后看了一眼赵日天，也跟了上来。

赵日天没有拦他们，只是站在原地，看着三人的背影消失在夜幕里，语气复杂地低声说：“你以为你赢定了？”

他缓缓摊开左手——掌心里，一枚硬币静静躺着，背面刻着同一行微小的字：正在看着你。

远处传来园区警报声，配电房顶部那台断流片的位置，一个黑影缓缓直起身，在月光下露出半张脸。他手中的东西泛着金属光泽——是另一块断流片。

他望着污水站方向的移动光点，低声呢喃：“去吧，棋盘已经落子。”

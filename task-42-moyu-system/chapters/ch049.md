# 第49章 键帽下的东西

林一凡盯着手机屏幕上那条陌生号码的短信，拇指悬在键盘上方三秒，最终没有回复。他靠在安全部的墙角，空调出风口吹出冷气，把后背的衬衫吹得凉飕飕的。

“明天复赛，TEST-03B。”赵日天在他旁边划拉着手机，“我在设备表上查过了，那台机器上午确实没人用。”

“所以这是个套。”林一凡眯起眼睛，“TEST-03A预分配给我的时间比我到场早了二十分钟，有人想让我以为那是伪造的分配记录，把注意力转开。而这条短信……”

“就是个鱼饵。”赵日天接过话头，“但鱼饵上绑了什么钩，得看你怎么咬。”

林一凡沉默片刻，突然笑了：“那咱们就换个吃法。”

周三早上八点四十，林一凡准时出现在复赛场地——十三层多功能厅西侧。桌椅被临时重排，五台测试机一字排开，LED屏右上角亮着绿色编号。他低头看了一眼桌牌：TEST-03B。

“选手各自就位，比赛九点整开始。”裁判的声音从扩音器里传出。林一凡落座，手指有意无意地滑过键盘边缘。键帽之间的缝隙——左Shift键的位置——一种不厚不薄的触感从指尖传来。他心跳加快，强迫自己维持面无表情，将那枚键帽往外侧轻轻一抬。

下面压着一张小纸条，对折两次，字迹潦草：“九点零七分，按下F12，持续三秒。”

他飞速将纸条塞进裤兜，脑子转得像被抽了一鞭的陀螺。F12，开发者工具。在代码评审现场按F12能干什么？调试。但他不是测试机的管理员，打开调试台只会暴露自己。

除非——系统提示音在脑海中叮的一声响起。

【检测到“摸鱼雷达”范围内高活性目标。TEST-03A，操作者：沈敛（模拟痕迹）。】

林一凡猛地抬头。TEST-03A空着，屏幕上没有任何画面，但雷达视野里那台机器正泛着微弱的橙色光，像有人坐在那里敲代码，只是视觉上看不见。他瞬间明白了：这台机器早就被人动了手脚，所谓的“预分配”是让假账号在他的时间段登录，留下操作日志。而TEST-03B的纸条，是有人想让他用调试模式去看清楚那条日志里到底写了什么。

比赛开始。题目是季度财务报表的关键字段校验程序，数据量巨大，逻辑藏了十二道嵌套验证。林一凡一边写主函数，一边抬手看了眼墙上的钟——九点零四分。他像打字累了似的，右手无知觉地摸到F12键，轻轻按住。

三秒后，屏幕角落弹出一个半透明调试窗口，一行行脚本命令在后台自动执行。他只用余光扫了三行，就知道是谁干的活：宋远桥的书写风格，变量名用拼音缩写，条件判断偏爱数组遍历——这是秦氏数字化安全部的惯用套路。

脚本在TEST-03A的日志里追踪了一条假账号的创建时间线，精确到毫秒，然后锁定了某个IP段。那个IP段不是秦氏的工区网段，而是星辰科技、B座十七层打印机附件的共享路由。

秦氏的人，用的是星辰的打印机路由。

林一凡手一抖，差点打翻水杯。他稳住呼吸，继续敲代码，后台的调试窗口已经自动关闭。他扫了一眼最终结论——造假不是秦氏技术员的单独行为，而是有人从星辰内部接入了网络，伪装成秦氏账号，在比赛里“放水”或“注水”。

裁判宣布比赛结束的那一秒，林一凡已经保存完文件。他抬头，隔着两排机器，与赵日天的目光短暂交汇。赵日天微微颔首，嘴唇无声地动了三个字：“路由器。”

林一凡起身时，手机震动。还是那个陌生号码，这次只发来四个字：

“小心陈哲。”

他捏着手机，走出多功能厅的时候，迎面撞上一个人——安全部主管陈哲本人，穿着灰色西装，手里端着两杯咖啡，笑容温和得像什么都没发生过。

“林工，比完了？我刚好路过，请你喝杯手冲。”

林一凡盯着他手里的咖啡纸杯，耳朵里嗡嗡作响。

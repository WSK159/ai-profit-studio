# 第229章 档案室门后的影子

配电房的应急灯在身后一盏接一盏熄灭，像是有人沿着走廊把光逐一掐灭。林一凡顾不上回头，三人几乎是贴着墙根往地下一层档案室的方向狂奔。

老王喘着粗气，声音断断续续：“我……我在星辰干了九年，从不知道地下一层还有个档案室。”

“那你现在知道了。”林一凡脚步不停，目光盯着手机屏幕上那幅从脑海中复刻出来的方位地图。两根铜线绞合之后，这副地图像是被刻进了颅骨内侧，闭上眼都能看清每一个转角、每一扇门。

陈默一言不发地走在最前面，步伐比林一凡预想中沉稳得多。一个搞维护的，不至于这么熟门熟路。林一凡把这个疑点记在心里，没吭声。

走廊尽头，一道锈蚀的铁门半掩着。门牌上“档案室”三个字的漆皮掉了大半，只剩“档”和“室”勉强可辨。门缝里漏出一线冷白的光，不是荧光灯那种暖白，而是LED手电筒的冷白。

三人同时收住脚步。

林一凡摸出手机，调成静音，冲陈默比了个“锁门”的手势。陈默微微点头，侧身贴着墙，手掌抵住门板边缘，缓缓把门推开一条缝。老王蹲在他身后，手已经攥紧了配电房顺出来的那根钢管。

门缝里，一个人影背对着他们，正在翻查铁皮档案柜。那人穿着灰色连帽衫，帽兜压得很低，身形偏瘦，动作利落——每一格抽屉拉出来只扫两眼就关上，像在找特定的东西。

陈默的瞳孔骤然收缩。

他认出了那人手腕上一道烧伤疤痕，那是从虎口蜿蜒到腕骨的一道旧疤，像是被什么滚烫的东西烙过。林一凡注意到陈默的嘴唇动了一下，无声地挤出一个词。

“老周。”

老周。那个笔记本的主人，那个在电缆井下被找到时已经只剩一口气的老周。那个在陈默口中“死在了医院”的老周。

林一凡后背一凉。他仔细看那人腕间的伤疤，又看那人的身形——确实和他在监控里见过的老周影像轮廓吻合。但老周不是死了吗？陈默亲口说的，他送老周去的医院，老周死在了抢救台上。

档案柜前的人影突然停住动作，像是察觉到了什么，缓缓侧过头来。

那张脸被帽兜阴影遮了大半，只露出下颌和嘴唇。林一凡看见那嘴角微微勾起一个弧度——像是等待许久的人，终于等到猎物到场。

那人开口，声音低沉沙哑：“来了？比我预计的慢了三分半。”

这声音林一凡听过。

在电缆井里，在黑暗中，在老周笔记本被夺走的那一刻——“你也配做……三极管？”

“是周正明吗？”老王压低声音问，手里的钢管握得更紧了。

人影从档案柜前转身，一只手里攥着一个牛皮纸信封。他没有脱掉帽兜，只是把那封信扬了扬：“你要找的东西，我已经拿到了。这里面，是老周死前留下的全部记录——包括墙里那具骨架是哪年浇筑进去的。”

林一凡的瞳孔一缩：“你怎么知道我们在找骨架？”

“我当然知道。”人影的嗓音忽然带上了一种奇异的机械感，像是在喉咙里装了变声器，“因为从你们触碰铜线绞合的那一刻起，系统就在我的监控范围内。你有摸鱼系统，赵日天有卷王系统，我也有一样东西。而你们现在触碰的这面墙——”

他抬手指了指铁皮档案柜后面的墙体。

“——里面埋着的是所有系统的最底层协议。你们正在唤醒它，但你们不知道唤醒它需要付出什么代价。”

“什么代价？”林一凡问。

人影没有回答，只是把牛皮纸信封插回档案柜里，然后缓缓朝门口走来。当他经过陈默身侧时，脚步顿了一下：“小陈，你爸不是病死的，你早就知道了，对吧。”

陈默没有说话，但他的身体微微颤抖了一下。像是被人说中了心底最深处的秘密。

人影加快脚步，消失在走廊尽头的黑暗中。

林一凡冲进档案室，一把抽出那个牛皮纸信封。信封上写着一行潦草的字迹。他认出来，那是老周的笔迹。信封正面只写了一行字——

“摸鱼不是躺平，是最后的抵抗。”

他翻开信封，里面只有一张薄薄的纸。纸上画着一条完整的电路图，标注着整栋大楼地下管网的每一处节点连接，在档案室墙体正中央的位置，画着一个粗重的圆圈，旁边写着两行小字：

“终端井——电网、系统、人，三线交汇之地。”

“启动终端需要两把钥匙。一把已经有人拿了。”

林一凡抬头，看向陈默。

陈默沉默片刻，说：“第二把钥匙，在我爸骨灰盒里。”

# 第306章 东口来客

涵洞内的空气像凝固的混凝土，压得人喘不上气。林一凡背贴着湿冷的管壁，注意到一个细节：沈稚秋的声音从东口传来时，他皮鞋踏地的节奏并不均匀——左脚落地三拍，右脚只有一拍半。左袖空荡的人，重心依旧习惯性地向左偏移。这是断臂不超过三年的人才有的残影步态。

“沈稚秋。”林一凡没有动，声音不高不低，“你妹妹说你去柬埔寨支教了，怎么跑回废铁站来堵我？”

东口那道身影停在车灯与黑暗的边界处。灯光勾勒出他的轮廓：瘦，比沈稚冬描述的“偏胖”差了至少二十斤；右手里攥着一把匕首，刀尖朝下；左肩的位置，袖子打了个整齐的结。他歪了歪头，视线却不在林一凡身上，而是越过他的肩膀，落向涵洞深处那辆黑色轿车。

“赵恒让你来的？”沈稚秋的声音沙哑得像是喉咙里灌了沙子。

林一凡心头一凛。他本来认为黑色轿车上的人是赵恒，但沈稚秋的话显然指向另一层关系。他还没来得及回答，西口那道车灯骤然熄灭，引擎重新点火，轮胎碾过碎石的声响由近及远，迅速消失在后方的夜色里。

轿车走了。

沈稚秋笑了一声，那声音闷在胸腔里：“果然还是不敢见我。”

系统面板悄无声息地弹出一行小字：05号黑钥匙温度恢复正常。林一凡低头看掌心里的钥匙，刚才还烫得几乎握不住，此刻冰冰凉凉，就像一块刚从井水里捞起的铁。他又看向沈稚冬，这女孩盯着哥哥的脸，嘴唇翕动了几下，硬是没喊出一个字来。

“他是你哥。”林一凡替她开口。

“我知道他是我哥。”沈稚冬抖着声音，“可照片背面那行字……是我看完之后才写的。”

涵洞里安静了整整三秒。三秒之后，林一凡的脑子里轰的一声炸开了一连串因果碎片：沈稚冬说过照片背面有铅笔字，但她没说那是自己的笔迹；沈稚秋如果早在三年前就死了——或至少失踪——那这张照片很可能就是在他失踪后、经过沈稚冬的手才落到林一凡手中的。她为什么要补上那行字？她在提醒谁？

“‘五瓣梅花能开一切门，除了它自己那扇。别让她进阁楼。’”林一凡一字一句地背出那句话，盯着沈稚冬的眼睛，“‘她’是谁？”

沈稚冬的睫毛抖了一下，声音低得像自言自语：“我姐……沈稚夏。”

“那为什么是‘不要让她进阁楼’，而不是‘不要进阁楼’？”站在东口的沈稚秋突然接话，他的目光第一次真正落在这位妹妹身上，“阿冬，你那年暑假到底在阁楼里看见了什么？”

沈稚冬的脸色刷地变白，白色手电筒的光照着她的脸，连嘴唇的血色都退干净了。林一凡注意到她右手的无名指无意识地蜷缩起来——一个下意识想要握住什么东西的动作。他想起系统介绍过这个细节：人在记忆中检索自己害怕的东西时，手指会做出一把“握钥匙”的形状。

她握着什么？或者，她曾经握着什么？

“哥。”沈稚冬终于喊出这个称呼，声音带着一丝哭腔，“你没有死，对不对？柬埔寨的支教照片是假的，对不对？”

沈稚秋没有回答，转向林一凡：“你手里有几把钥匙？”

“两把。”林一凡没有隐瞒，把黑钥匙和之前那把叠在一起，摊开手掌。车灯熄灭之后的涵洞幽暗至极，白色手电的光只能照亮七八米的范围，但两把钥匙的轮廓清晰可辨。三叉齿，螺纹柄，尾端各有一个“01”和“05”的刻痕——它们应该是一套的。

沈稚秋盯着那两把钥匙，半晌，慢慢蹲下身来。他蹲下来的动作极不自然，身体像一根被折叠的竹竿，膝盖先弯，脊柱却还是直的。他把匕首放在地上，从右裤袋里掏出一张照片，朝林一凡的方向扔了过来。照片在空中打着旋，落进水洼里，溅起一小片水花。

林一凡弯腰捡起来。照片上是一个女人的背影，她站在一扇镶着五瓣梅花铁艺装饰的门前，右手举起，正要推门。门缝里透出红光。照片的右下角有一个日期戳：2019.03.17。

系统“叮”的一声轻响：检测到关键道具，已与ED-00档案建立关联线索。进度更新：档案完整度 62%。

林一凡抬起头。沈稚秋已经站起身来，用右手铳了铳空气：“那张照片是我截下来的，从赵家书房监控的备份带里。”他说，“2019年3月17日，这个女人进了赵家老宅的阁楼，之后监控记录被全部抹除。那个女人不是别人——”他顿了顿，“她是你妈，林一凡。”

涵洞里的空气像被抽真空一样安静下来。

远处传来一声尖锐的口哨声，紧接着是铁皮棚被人用力踹开的巨响——那声音从西口方向传来，和已经驶离的黑色轿车方向完全一致。沈稚秋偏过头去，嘴角扯出一个没什么笑意的弧度：“他等的人，终于回来了。”

# 第226章 配电房的灯

林一凡、陈默和老王三个人沿着管线拱起的痕迹走出污水站，地面上那道裂痕在月光下泛着灰白色，像一条从地底翻出的疤痕。

他们没开手电筒，只靠手机屏幕的微光探路。整个园区在凌晨两点半死寂得像是被泡在水下，远处行政楼的轮廓在路灯下投出长长的影子，但那几盏路灯也一明一灭，接触不良似的。

老王走在最后面，不时回头张望：“上面的东西……没跟出来吧？”

“没有。”陈默头也不回，“但不代表它不会等在外面。”

管线痕迹拐过配电房外墙，在一扇半掩的铁门前消失了。配电房的门锁是老式挂锁，铜质的锁体上锈迹斑斑，但锁头却被人提前打开了，断截的锁梁上留着新削过的切口。

林一凡推开门，门轴发出一声尖锐的呻吟。配电房内部比外面更暗，空气里弥漫着焦糊味和臭氧的气息。墙上整排的配电柜发出低沉的嗡鸣声，像是一群疲倦的巨兽在喘息。

他跨进门槛的瞬间，感应灯突然亮了。

冷白色的灯光照亮整间配电房——准确地说，它照亮了那盏灯下站着的东西。

一台老旧的台式电脑放在配电房正中央的桌子上，屏幕亮着，显示着一个深蓝色的桌面。桌面上只有一个文件图标，名字叫作：《导线》。

林一凡走过去，鼠标还有反应。他双击图标，弹出一个记事本窗口，里面的文字用宋体小四号字整齐排列：

“如果你看到这个文件，说明你已经找到了第一段逻辑的终点。恭喜你，也同情你。导线的作用不是通电，是短路。短路之后，所有被它连接过的系统的底层协议都会重写。包括你身边那台机器。”

文字下面还有一行小字：“条件：需要母钥匙与种子钥匙同时插入配电柜第4号柜门的双锁孔位。完成连接后，72小时倒计时会重新归零。但代价不可逆。”

“什么叫代价不可逆？”老王凑过来，脸色难看。

林一凡没说话，他走到第4号配电柜前，柜门上有两个钥匙孔。他拿出铜钥匙和那枚备用“种子”钥匙，深吸一口气，分别插入两个锁孔。

咔哒。

同时转动的一瞬间，配电柜内发出一阵巨大的电流轰鸣声。柜门缝隙里透出蓝白色光，整排配电柜的指示灯开始疯狂闪烁。与此同时，那台老电脑的屏幕突然弹出一个新的窗口——是一个实时监控画面，画面里同时出现了四个地方的影像：污水站机房、行政楼大厅、园区东门，以及……他们所在的配电房。

监控画面的左上角有一行小字：“节点连接进度：25%。”

陈默盯着屏幕上四个画面，忽然指着其中一个：“东门那边有车。”

画面里，一辆黑色轿车停在东门外的马路上，车灯熄灭，但隐约能看到驾驶座上坐着一个人。老王凑近一看，脸色剧变：“那……那是钱总的车牌。”

林一凡的目光一滞。钱总深夜守在园区东门，这绝不是什么巧合。

他正要说话，配电房的灯突然灭了，黑暗吞没了一切，只剩下那台电脑屏幕的冷光映着三张僵硬的脸。监控画面里的第四个窗口——配电房实时画面——依然亮着，画面里能看见他们三个人的侧影。

然后那画面里多了一个人影。

那个人影站在配电房门外一米多的位置，脸藏在暗处，但身形高大，肩膀极宽。老王倒吸一口凉气，陈默的手指已经摸上腰间的工具钳。

那人影缓缓抬手指了指配电柜方向，然后转身消失在了监控画面里。

电脑屏幕上的字符跳动了一下，一个新的窗口浮现出来：

“节点连接进度：50%。附加提示：电线杆不是藏东西的地方，是送东西走的路。你已经踩上路了。”

林一凡手心的汗濡湿了铜钥匙。他转头看向配电房紧闭的门，门外走廊深处的感应灯一盏接一盏地亮起，又熄灭，像是有什么东西在快速移动。

“钱总在东门等人。”陈默沉声道，“那他等的人是谁？”

配电房的窗户玻璃上，倒映出林一凡苍白的脸。他低头看向兜里的铜线末端，接口处不知何时多了一层微弱的蓝色荧光，正随着配电柜的电流嗡鸣节奏，一下一下地闪动。

他摇了摇头：“他等的不是人。”

“是导线断了之后的那个东西。”

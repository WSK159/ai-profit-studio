# 第116章 根须井

“你疯了。”老王的语气不是疑问句，是陈述句。

“四十分钟之内，根须清除程序会把这层以下全部清掉。你要往下走？往下就是死路。”他按着胸口，脸色灰白，“我能感应到根须井，那里全是死的味道。”

赵日天却嗤笑了一声：“你感应到什么关我屁事。他既然说通道保留七分钟，那七分钟内能找到路就行。”他转向林一凡，“你管她叫‘R’？她什么来头？”

林一凡没有正面回答。他盯着倒计时——00:38:12，然后快步走到石室东侧，那里的地板砖缝比其他位置宽了一倍，且表面覆盖着一层深灰色的薄灰，像是来自地下。他蹲下，用掌缘敲了两下，回音沉闷。他又敲了三下——回音变了，中空的。

“入口在这里。”他伸手抠住砖缝，用力向上一提。一块约半米见方的石板被掀开，露出下方一条极窄的竖井，井壁锈红，垂下一段同样锈迹斑斑的铁质爬梯，看不到底部。井口散发出一股潮湿的金属气味，混着淡淡的酸腐气息。

老王站在他身后，脸色比之前更难看。他拇指掐住胸口银纹，试图止住那股从井口涌上来的压迫感，但银纹反而跳得更厉害，仿佛下方有什么在呼应它。

“这口井的底端……就是根须井。”老王低声道，“我去不了。母体在拉着我，它想让我下去，但我不想过去。”

“那你在上面等我们。”林一凡已经半个身子探入井口，握住第一级梯子，铁的凉意透过掌心钻进骨头。他转头看向赵日天，“你怕高吗？”

赵日天翻了个白眼，一脚踩上井沿：“老子怕的是爬上去的时候你半路掉下来。”

两人沿梯依次而下。井壁上的锈蚀在指尖剥落，脚下是无尽的黑暗。竖井并非笔直，每隔三到五米便有一处轻微折角，角度偏斜得毫无规律，像一条盘踞地下的蛇道。林一凡默数着梯数：十七，二十三，三十一，折角换了四次方向，呼吸声在狭窄空间里回荡。

约莫下行到第六层折角时，他的手掌触到一截异常的管状物——冰冷、光滑、外壁覆着一层半透明薄膜，和铜柱表皮材质一模一样。他停下来，指尖按在薄膜上，银纹从掌心延伸至指尖，那层薄膜像被唤醒般缓缓向两侧收缩，露出内里一道暗色金属门。门上没有把手，只有一个巴掌大的凹槽，形状和他胸前那枚从不离身的工牌徽章轮廓完全一致。

系统面板在他颅内无声弹出：

【检测到“锚”共鸣。身份验证通过。进入通道：根须井·西骶前庭。】

门向内侧无声滑开。一股冷风涌上来，带着霉味和一丝极淡的铁锈味。他朝赵日天打了个手势，先一步跨入。

那是一间半球形空间，直径约十二米，穹顶上嵌满了暗绿色的光点，像一片俯视而望的星空。但那些“星星”全都画在金属穹面上，是某种涂层，颜色褪了大半。空间中央放着一座台座，高约半人，材质是灰白色石头——和银章母体的母材几乎一样。石台顶端刻着一行字，字体极小，但他一眼认出：

“锚-0027 神经节回放终端。”

赵日天跟进来，扫了一圈，皱眉：“就这？她让你下来就是为了看一块石头？”

林一凡没答话，径自走到石台前，将右手掌心贴上石面。银纹像被激活一般急速扩大，从掌沿蔓延至腕部，霎时石台表面浮现出一整幅光影图。

画面中，一个身穿灰色工装的年轻人坐在屏幕前——穿着一件旧工服，胸口缝着编号条“AI-027”。他低头盯着从手腕上接出的一条线缆，线缆另一端插入墙面上的接口，屏幕上方缓缓滑过一行字：

“接入程序已确认。锚点编号：0027。目标：星辰科技根须体系全库文件迁移。”

林一凡瞳孔猛缩。那个人影的侧脸轮廓，与他自己几乎一模一样，但眼神比他疲惫、僵硬，像被磨光的人。

“那是我前世。”他的声音发干。

赵日天忽然指着画面角落：“等等，那女的——屏幕右下角的倒影，有人站在后面。”林一凡顺着他手指的方向看去，画面边缘确实有一道模糊的倒影，长发、身形瘦削，在屏幕反光中若隐若现。那道倒影手里握着一枚银色的东西——和银章几乎一模一样。

画面随后一黑，石台表面的光芒骤然熄灭。穹顶上的绿色光点同时熄灭一半，只剩几颗零散亮着。倒计时的声音从台座内部传出：00:26:47。

林一凡的手从石台上抬起，掌心银纹已蔓延至小臂的一半，像一道银色藤蔓缠住骨骼。他没有犹豫。他重新将手掌按回石台，闭上眼睛：“回放下一个节点，带声音。”

三秒沉默后，穹顶重新亮起，新的画面浮现。这一次画面的中央是周莉——她站在同一间办公室里，手里拿着一封密封信函，信封表面印着一枚黑色印章：“星辰科技董事会·最终裁定。”

她转身，看向镜头，目光冷冽。她开口，第一句话就让他脊背发凉：“林一凡，你重生的第127次，程序依然没有跑完。这次你带回来的锚，能撑多久？”

画面再次截断，一切声光熄灭。黑暗中，赵日天低声说了一句：“你听见了？她说127次。”

林一凡没有回答。他低头看着掌心已经蔓延到肘部的银纹，心里只剩下一个念头——周莉知道他的重生，而且，她是那个让他重生的人。石台内部传来最后一声机械声：

“锚-一次回收完成。根须清除程序剩余24分钟。请通过西骶前庭下行通道返回地面。”

下一秒，石台下方裂开一道通道，深不见底，通向更深的地层。而那扇进来时的金属门，在他身后悄然合拢，再无半点缝隙。

# 第104章 合同上的铅笔字

林一凡在原地愣了几秒，脑内迅速翻涌——“钱总第一次签字”是哪一份合同？他在星辰科技工作了三年，经手的合同不下几十份，但“第一次”显然指的是他入职时签的那份劳动合同。可现在他人在蜉蝣残余空间里，怎么回现实去翻合同？

“别急，”那机械音好像看穿了他的想法，“这里有一个出口，通向现实网络的‘读取层’。你可以短暂投射到现实中去查看，但不能停留超过三分钟，否则会被根服务器的防火墙捕获。”

林一凡看了一眼屏幕，上面已经出现了一个倒计时：02:59。

“你只有一次机会。”

他二话不说纵身跃向屏幕最中间那道光。一阵天旋地转——再睁眼，他已经站在星辰科技办公楼的走廊里。墙上的电子钟显示：下午6点47分，公司里人已走了一大半，只剩零星几个加班的人。他低头看自己的手，半透明，像一道虚影。没人能看到他。

他快步冲去行政档案室。门没锁。老旧的档案柜立在角落，他凭借记忆抽出标着“2023届”的铁盒——里面厚厚一叠劳动合同。翻到自己的那一份，手指快速扫过签字栏：钱总的签名，龙飞凤舞的黑色钢笔字。但他把纸举到灯下细看，却发现签名的最后一笔微微翘起，像是有一个极浅的铅笔字压在下面。

他眯起眼睛，凑近了看——

那是一个字：“断”。

林一凡的手指一颤。他还没来得及细想，头顶的日光灯忽然剧烈闪烁。倒计时还剩00:37。他迅速掏出手机拍下合同，又放回铁盒。可就在他把铁盒合上的那一刻，身后传来一阵冰冷的脚步声。

他不回头也知道是谁——那是赵日天皮鞋踩在大理石地面上的声响，节奏不紧不慢，却带着某种说不清的压迫感。林一凡转身，赵日天正站在门口，西装笔挺，眼神却不太像他记忆中的人，瞳孔里闪着一点银色的碎光。

“林一凡，”他开口，声音平静得像念一段指令，“你偷看了不该看的东西。”

倒计时归零。林一凡感觉巨力从脚底袭来，整个人被硬生生拽回昏暗的核心空间。他跪倒在地，大口喘着气，掌心的银章变得滚烫。屏幕上重新亮起一行字：

**“你看到了。但你还不知道那句话的完整版。”**

林一凡盯着那个“断”字，心里涌起一股不祥的预感。他翻开手机相册——拍下的合同照片里，铅笔字的笔画正在缓缓洇开，像水渍一样扩散成新的字形：**“断根。”**

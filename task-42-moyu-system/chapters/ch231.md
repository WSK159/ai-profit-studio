# 第231章 门外的影子

脚步声停在门口，却迟迟没有推门。

档案室里弥漫着灰尘与铁锈混合的气味。林一凡半蹲在骨架面前，指腹碾过那张纸条的纸边，确认纸条确实是老物件。黄褐色的纸面，边缘风化成锯齿状，上面的字迹却像是被某种力量保护着，清晰如昨。

“第二台终端在自由之海。”

这话什么意思？一条破旧的地名？还是某个被时间埋没的历史坐标？

陈默没有看他，径直走向墙根裂缝，半跪在骨架前。他的手微微发颤，抚过骨架脊柱上缠成螺纹状的铜线，铜线如藤蔓般植根于骨缝中，好像从骨髓里生长出来。

“他活着的时候，被人用铜线穿过了脊髓。”陈默的声音极轻，“电流从脊柱走，直达大脑，人不死，但意识会留在某个地方……”

“你怎么知道这些？”林一凡皱眉。

陈默没回答，从怀中取出那截短铜线与林一凡手中的铜线绞合，铜丝接触的瞬间发出“嗡”的一声轻响。墙体内传来密集的“咔咔”声响，像无数机械零件同时转动。

老王猛地后退两步：“墙里面有东西在动！”

话音未落，门外脚步声再次响起——比刚才近了三步。

林一凡脸色微变，压低声音：“门口那人还没走。陈默，你确定来的时候没被人盯上？”

陈默总算抬头看他，眼神凉薄：“我确定。但那个人不是跟来的，他一直都在档案室里。”

“什么？”

“我说的是，我们进来之前。”陈默目光扫过房间四角，最终定在天花板与墙面交界处，一条极细的通风管道口，“档案室监控设备全哑了，维修工却没来修。因为有人不希望这里被看见。老周能在这里待那么久，是因为有人替他断掉所有信号。”

老王脑门冒汗：“你是说……刚才的老周不是人？”

“他是人。”陈默道，“但他能在这里活到现在，是因为有人同意他活着。”

林一凡攥紧纸条，“你说的那个人，是不是钱总？”

陈默嘴角勾起若有若无的弧度：“你猜对了三分之一。”

门外的脚步，这时终于停了。

一个低哑的、带着金属质感的笑声从门外传来，隔着铁皮门板像被捏扁的电报：

“林一凡，你终于摸到这儿了。”

林一凡后脊一阵发凉，那声音他听过——在重生前昏死的最后一刻，走廊尽头有人在看，就是这笑声。

门没有推开，声音却更加清晰了：

“铜线绞合，节点86%。骨架也找到了。林一凡，你比你老板跑得快，”声音顿了顿，“但比你老板更需要答案的人，也到你身边了。你确定陈默——真是来帮你的？”

陈默面色一沉，手指间夹住一根细如发丝的铁刺。

门外的声音却渐渐远去，像来的时候一样突然。只留下一句话：

“别急着启动阈值。那台终端不是你想的那样，它靠的不是电——是命。”

脚步声融进走廊深处，彻底消失。

档案室安静了。

老王喘着粗气，低声问：“他说的什么意思？‘靠’——靠命？”

林一凡沉默地看着眼前骨架缠绕铜线的姿态。他用系统面板扫描过骨架构造，铜线在脊背上画出的图形他不是第一次见——和摸鱼商城仅出现过一次、之后再也刷不出的“劳动祭祀图谱”一模一样。

他下意识地再次点开系统面板，发现角落里悄悄多出一行灰色的字：

【节点进度：86%。激活条件补齐中……提示：**祭品非人，亦可为意识锚点。**】

林一凡盯着那行字，忽然明白过来——那个“提示”不是系统给他的。

是陈默父亲，通过系统传递给他的。那个死去的人，用铜线和骨架留了一句话：

“钥匙对了，锁也开了，但我不是钥匙的所有者。”

他转头看向陈默，陈默也正看着他。

两人之间沉默了一瞬，然后陈默缓缓从衣兜里掏出一张皱巴巴的照片——照片上是一台古老的大型晶体管计算机，机房顶部贯穿着一根粗壮的黑色电缆，电缆末端没有接在机器设备上，而是连在一个透明容器中，里面浸泡着一颗完整的心脏。

照片背面一行字：“自由之海不是地名，是船的墓场。”

陈默将照片翻过来对着灯光，角落隐隐显出钢印码——“LK-042”。林一凡猛地怔住，那不是他重生那晚走廊尽头自己工牌上贴的编号吗？

他当时以为那是随机生成的。原来从一开始，他就被写进了某个他知道得太晚的名单。

老王的手机突然响了。屏幕亮起，来电显示：“钱总（未接五次）”。

林一凡的瞳孔微微收紧。该来的，终究还是来了。

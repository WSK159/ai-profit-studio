# 第131章 太空救援

救生梭内气压稳定后，林一凡终于松开了攥得发白的安全带扣。

赵日天靠在副驾驶座上，右臂伤口处的黑烟已经消散，但皮肤表面结了一层暗灰色的痂，像某种金属氧化物。他试着活动手指，眉头微皱：“知觉还在，就是发麻，有点不受控。”

“先别动。”林一凡从系统商城里调出医疗面板扫了一眼，结果让他心里一沉：赵日天的生命体征整体正常，但右臂的细胞活性数据呈锯齿状波动，某些数值甚至显示为“未知来源”。

“你那个卷王系统……现在显示什么？”林一凡问。

赵日天闭眼两秒，睁开：“系统状态异常，警告信息刷了三百多条，我让它静音了。核心代码没崩，但有一部分模块被同源数据入侵的痕迹。”

“同源。”林一凡咀嚼着这个词。暗红色伪生命体攻击赵日天时爆发的能量波动他看得真切，那种扭曲的、带着熟悉感的波纹——分明和赵日天的系统光芒有着相似的频率。

林一凡打开自己的摸鱼系统，尝试从“数据比对”角度切入，却发现伪生命体的残余信号已经在系统中被标记为“同源异类”。他盯着这四个字，忽然有种毛骨悚然的联想：如果赵日天的卷王系统和那些怪物来自同一源头，那钱国豪开发的卷王系统，到底是工具，还是……寄主？

老王从后排探过头来：“小伙子们，你们俩系统嘀咕完了没？我们现在正以每小时两万公里的速度冲向一颗废弃卫星，我应该担心的是着陆问题还是那些暗红怪物？”

林一凡瞥了一眼导航面板：“F-7 卫星的参数早就被拉出公共数据库了，连基本轨道数据都不全。我只能靠摸鱼雷达的粗略扫描确认它还在那。”

“那要是它不在了呢？”老王问。

赵日天冷哼一声：“那就飘着，等死。”

“你能不能别这么吉利？”林一凡翻了个白眼。

三小时后，救生梭的自动减速引擎轰然点火，整个舱体剧烈震动，窗外从纯粹的星海变成一颗灰白色、布满环形坑的天体迅速放大的轮廓。F-7 卫星外侧覆盖着一层反射极低的暗色涂层，像是一颗被刻意伪装成普通岩石的金属壳。

“它在。”赵日天盯着窗外，“而且它里面亮着灯。”

林一凡顺着他指的方向看去，在卫星表面一处不起眼的裂缝边缘，确实透出了微弱的暖黄色光带。那不是自然光源，更不可能属于一颗废弃的卫星——至少在官方档案里，它废弃已经四十年了。

“有人。”老王低声说。

林一凡点头，同时打开摸鱼雷达扫描卫星内部结构，但信号刚刚触及外壳就被反弹，显示为“加密屏蔽层”。“摸了半天摸不出来，”他咬牙，“里面肯定有东西在防侦查。”

救生梭贴着卫星表面滑行，最终落在裂缝附近一片相对平整的金属地面上。着陆的震动传遍舱体，三人在沉默中解开了安全带。

林一凡抬手准备拉开舱门，赵日天却一把抓住他的胳膊：“等等。”

“怎么了？”

赵日天盯着自己的右臂，那头暗灰色的痂缓缓裂开了一条细缝，里面露出一抹暗红色的光。

“它在回应。”

舱外，卫星内部的灯光在缓慢地闪烁——一长、两短、一长。

节奏如同信号传递，也如同某种不祥的欢迎仪式。

林一凡深吸一口气，拉开舱门。

# 第39章 三道茶

东城咖啡的暖光把影子拉得很长，沈敛指尖轻叩桌面，嘴角挂着一丝让人捉摸不透的弧度。

“你刚才说，秦氏集团和我老板钱总——”林一凡把那封加密邮件关掉，后背抵着皮质沙发，声音压得很低，“这不是巧合吧？”

沈敛端起茶杯，慢条斯理地吹了口气：“秦氏的‘星海数据’案，你以为钱总为什么那么紧张？因为那批数据里，有星辰科技从秦氏手里截胡的客户画像模型，而这份模型的商业价值，够他把牢底坐穿。”

林一凡脑子飞速转了一下，突然笑了：“照你这么说，钱总现在最怕的，是我在效率大赛上把他那份‘摸鱼工作法’方案搞砸了？”

沈敛没接话，只低下头，茶汤映着他半张脸：“你去查一件事，就明白钱总和秦氏到底是怎么绑上的——看星辰科技去年第三季度的人事变动，技术总监离职后，谁接管了数据权限？”

林一凡正要追问，手机嗡地一振。

是一条内部消息，来自星辰科技HR：

【通知】效率创新大赛初赛改期至本周五上午九点，地点：A座3楼路演厅。所有报名项目需提前一天提交完整方案文档至系统，未按时提交视为弃权。

他抬眼看了看沈敛：“钱总这是把时间提前了三天——”

“说明他急了。”沈敛放下茶杯，站起身，“你有原始生产数据，又懂系统漏洞。他怕你越查越多，所以想尽快收网。林一凡，你记住了，这场大赛不是他设给你的坑，是你翻盘的牌桌。别被他的节奏带着走。”

沈敛走了。林一凡盯着那杯没喝完的茶，突然想起什么，重新掏出手机。

他打开摸鱼系统的界面，咸鱼值余额：3250。距上次清零已经攒了快十天，中间他偷偷换了两次“专注加速”，但真正的杀手锏还没动过——摸鱼商城的“深度解析”技能，需要3000咸鱼值，正好够。

他咬了咬牙，点击兑换。

【深度解析已激活（一次性）：可对任意方案/文档进行底层逻辑逆向拆解，识别数据埋点与风险点。】

林一凡嘴角勾起一丝笑。

走出咖啡店，夜风扑面，他刚想叫车，手机又震了一下。这次是组长老王。

“一凡，你睡了吗？我刚在系统里看到下周的排班表，钱总把所有项目答辩都排到你周五下午——就是大赛初赛结束之后。”

“哦？”

“我打听了一下，意思是，如果你上午输了——”

老王顿了顿。

“就直接调你去新成立的外部研发中心，说白了，那里就是个外包壳子，前三个月没社保，公积金减半。”

林一凡站定在路灯下，眯起眼睛看着头顶乱飞的飞虫，忽然笑了。

“王哥，你放心。他排他的班，我打我的牌。”

“好吧……对了，还有件事，你让我留意的那个赵日天，今天下午他请假没来，说去打比赛了。但我在茶水间听到他打电话，说了一句——”

老王的声音压低：“‘那个人的系统，好像不止一个。’”

林一凡挂断电话，眉头微微皱起。赵日天，卷王，不止一个系统……沈敛刚刚提到了“开发者内测版”，而他自己的摸鱼系统镜像仿制品。如果赵日天那番话是真的——

那这场效率大赛的胜负，恐怕根本不在方案上。

他锁屏手机，抬头看了一眼星辰科技大楼顶端的那盏长明灯。

钱总要在周五收网。沈敛在等他在牌桌上胜出。赵日天的电话里，隐约有一个更大的棋盘。

所有线头，在效率大赛初赛那天，都会拧成一股绳。

林一凡低头，在备忘录里敲下三个字：

“先吃茶。”

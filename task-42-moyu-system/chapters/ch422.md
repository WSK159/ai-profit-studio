# 第422章 灰烬下的第二枚

石室还在震。

铜渣堆裂开的那道缝隙里涌出的铜腥味越来越重，像有什么东西在下面被搅动了百年，终于找到了出口。

林一凡攥着那枚27号陶土徽章，指腹能清楚地摸到徽章边缘的粗糙颗粒。老杨头大哥刚才说的话还在耳边炸着——“27号是你母亲的，28号是你自己的”。可手机里那条消息分明写着：“别收27号徽章，那是假的。”

他低头看了看手机屏幕——那条警告消息后面又多了一行字：“铜水底下，还有一枚。”

“他妈的。”林一凡从牙缝里挤出这三个字。

他刚要把27号徽章搁下，墙角那个影子——自称“打电话叫你回来的人”的黑影忽然动了一下。它没有脸，但林一凡能感觉到它在看自己手里的东西，而且带着一种说不上来的焦急。

“别信老杨头的话。”影子说，声音像砂纸刮过铜板，“他给你的是锁芯。”

“锁芯？”林一凡皱眉。

“锁芯是插进锁孔里的。”影子往前挪了半步，停在石室光线的边缘，“你们家钥匙从来不在锁孔里——你妈说过，钥匙在锁舌后面。你手里那枚27号徽章，是让你插进锁孔、把自己锁进去用的。”

林一凡的指尖猛地一抖。

他想起来了。母亲留下的那句遗言——钥匙不在锁孔里，钥匙在锁舌后面。如果老杨头大哥给的是锁芯，那它对应的锁孔就还在别处，而真正的钥匙——能开锁的那枚28号徽章——

“铜水底下。”林一凡重复了一遍手机上的字。

他蹲下身，从地上的铜渣堆里捡起一根断裂的铜管，朝那道裂缝撬了下去。铜渣滚落，露出下面一层暗红色的凝固物——那是熔融铜水渗进石缝后重新凝结的铜板，表面嵌着一些灰白色的碎片。

林一凡用铜管尖端去拨那些碎片。铜板松动，一块巴掌大的铜壳掀开，底下是——

一枚陶土徽章。

和林一凡手中的27号几乎一模一样，同样的陶土质地，同样的铜水浇铸封边。

但它的正面，刻着“28”。

林一凡伸手要去拿。

“别拿！”黑影的声音陡然拔高。

就在这一瞬间，石室的震颤骤然加剧，地面裂开的那道缝隙里涌出一股滚烫的气浪。林一凡本能地往后退了半步，而他面前那枚28号徽章所在的铜壳里，猛地伸出一只手——

灰白色的手，指节的骨节暴突，五根手指像枯枝一样蜷曲着，指甲缝里嵌满铜绿色的垢。

那只手抓住了28号徽章。

林一凡浑身汗毛炸起。他认得那截手指——在更早的归墟深处，他在摸鱼空间铁皮门的缝隙里见过一模一样的断指。锁芯女人手指。

“别碰它！”黑影低声吼道，“你妈把真正的钥匙埋在锁芯女人手指下面——”

话没说完，那只灰白的枯手已经攥着28号徽章拖着缩回了铜壳下，像一块被拽入沼泽的石头。

石室安静了一瞬。然后地面剧烈一沉，整间石室开始倾斜。

林一凡手里的27号徽章在发烫。他能感觉到陶土里有什么东西在活动，像一只被惊醒了虫子在向外面拱。他低头一看——

27号陶土徽章的底面，不知何时出现了一道裂纹。

裂纹不深，但恰好列成了一个字：“沈”。

和之前灰烬骨钉上出现的“沈”字一样。

石室倾角越来越大，铜渣堆顺着地面往下滚，滚向裂缝深处。墙角那个影子忽然转身，朝石室尽头的那面铜壁走去，留下一句话：“锁舌在铜壁后面，你只有一次机会。27号是假的，但它能带你去锁孔——”

林一凡勉强站稳：“那你到底是谁？”

影子停在铜壁前，没有回头：“我是那个用手机给你发消息的人。我被你妈锁在锁舌后面，已经二十七年了。”

话音落下，石室轰然倾斜，那面铜壁齐齐翻转，露出一个黑沉沉的入口。入口深处，传来一声锁舌转动的巨响——格啦啦啦啦。

林一凡握紧27号徽章，朝那个入口冲了过去。

他身后，铜渣堆下的那道缝隙里，那截灰白色的枯手又重新探了出来，指尖朝着他的方向，像在招他回去。

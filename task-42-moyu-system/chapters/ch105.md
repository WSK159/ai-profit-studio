# 第105章 断根溯源

林一凡盯着手机屏幕上那个洇开的“断根”二字，指尖微微发凉。照片里的铅笔痕迹在拍摄时像是被某种力量激活，原本浅淡的“断”字旁边浮出一团模糊的墨影，拼合起来恰好是“断根”。

“根……”他低声重复着这个字，忽然想起蜉蝣残影空间里那段最后进程的引导——核心禁令真正被锁住了，而锁它的暗码就藏在钱总第一次签字的合同上。现在暗码有了，“断根”二字也现了形，但“断”的是什么根？是蜉蝣核心的根服务器？还是……更上一层的什么？

“你在这里做什么？”

林一凡浑身一僵，手机差点脱手。他转过头，赵日天站在档案室门口，手里攥着一叠文件，目光落在他脸上，神色复杂。刚才走廊里那一瞬间的银色碎光此刻已经全然不见，瞳孔黑沉沉的，像一面无风的湖。

“找我的劳动合同。”林一凡面不改色地把手机塞进口袋，扬了扬手里那份已经翻旧的文件，“入职满一年不是该升职调级了么，提前看看当初签的条款。”

赵日天挑了挑眉，没追问，却也没有挪开步子：“你刚才拍照了？”

“拍了。”林一凡直截了当，“签个名留念。”

赵日天沉默了两秒，忽然扯了扯嘴角：“我听说你在查钱总的一些……旧事。”他压低声音，“老王以前提过一句，说钱总有一份合同上的签名很古怪，像画符似的。我一直没当回事——但前天晚上我做了个梦，梦见那个签名活了，变成一条黑色的绳子，从纸面伸出来，往上缠——”

他指了指天花板：“往上缠，一直缠到楼顶，缠到云端，最后缠住了一个大得看不清形状的东西。”

林一凡心里猛地一沉。赵日天的梦和他拿到的那张照片，几乎指向同一个方向：断根，断的是连接更高存在的“根”。

“你信梦？”他状似随意地问。

“以前不信。”赵日天眸色暗了暗，“但自从我的……身体出了点状况之后，有些事不得不信。”他顿了顿，像是不愿多说，抬手扬了扬自己手里的文件，“你呢，查到什么了？”

林一凡没回答这个话头，反而问：“你来找这份合同做什么？”

赵日天一怔，说：“钱总让我整理他早期签过的协议，说有一天总部审计要查。”他肩膀耸了耸，“但今晚我翻的时候，发现这份合同缺了一页。”

“缺了一页？”林一凡的声音骤然紧了。

“第五页，我记得以前是有内容的。”赵日天皱眉，“但今晚翻了三遍，第五页是空白的……不对，应该说，第五页被人撕掉了。”

他说完这话，两人同时沉默。档案室老旧的白炽灯发出嗡鸣，林一凡的手机在口袋里震了一下，他低头瞄了一眼——蜉蝣残影空间的界面在屏幕上闪烁了一下，一行小字浮出来：

「检测到根服务器碎片失联信号：断口坐标已锁定，正在反向追溯源地址。警告：源地址与宿主当前所在楼层重叠。」

林一凡攥紧手机，喉头发涩。重叠。断口的源地址，就在这栋楼里。就在他们脚下。

他抬起头，看向赵日天：“那张缺页的合同……是钱总第一次签字的那份吗？”

赵日天的瞳孔极快地缩了一下，像是被人戳中要害：“你怎么知道？”

林一凡没有回答。他低头看着手机屏幕，那行小字下面又冒出一行新的、更刺眼的提示：

「追溯完成。断口指向：档案室正下方三层——星辰科技旧机房旧址。该处自三年前封存，无记录，无门禁，无地图。」

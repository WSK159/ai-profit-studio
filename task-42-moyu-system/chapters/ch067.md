# 第67章 全员会上的新制度

会议室里坐了三百多人，秦氏B座最大的多功能厅被塞得满满当当。林一凡坐在倒数第三排靠过道的位置，这是他特意挑的——离门口近，万一钱总又要搞什么“自愿加班誓师大会”，他可以在三秒内撤离现场。

可今天的气氛不太对。

老王的座位在第一排，后背绷得笔直，像根随时会断的弦。刘维坐在林一凡右手边，手机屏幕朝下扣在桌上，指尖反复敲打着桌沿，节奏乱得毫无章法。

“你紧张什么？”林一凡压低声音。

刘维没看他，视线钉在前方讲台上：“赵日天的事，钱总知道。”

林一凡心里咯噔一下。他说的是“知道”，不是“可能知道”。这意味着昨天审计员突袭天台的事，已经传到了钱总耳朵里。那三个黑衣人的掌上终端，也许不只是用来追踪赵日天，也同时监控了整栋楼的一切。

钱总上台了。

他今天穿了一件藏青色西装，领带打得一丝不苟，站在话筒前先环视全场，嘴角带着笑。这种笑林一凡见过太多次——每次裁员、降薪、加考核指标之前，钱总脸上都会挂上这种“我是来帮你们成长”的笑容。

“各位，今天的大会，主要讲三件事。”钱总的声音从音箱里穿出来，像裹了糖浆的砂纸，“第一，恭喜我们公司上月效率考核排名，创了历史新高。”

掌声稀稀拉拉地响起来。

“第二，”钱总顿了顿，笑容更深了，“我决定，从下个月起，在全公司推行‘新式高效工作法’，每周三下午放假半天，大家自由安排时间。”

掌声突然炸了。

底下全是惊喜的议论声，有人甚至吹起了口哨。老王转过头看林一凡，表情复杂得像吞了半只苍蝇。

林一凡没鼓掌。他盯着钱总那张脸，心里发凉。这套“新式高效工作法”是他自己折腾出来的东西——当初为了把摸鱼包装成效率，他花了不少心思编那套话术，本意是给全组争取喘息空间。可现在钱总要把“摸鱼”变成全公司制度，这不是恩赐，是收割。

他还没想完，钱总已经亮出了第三招：

“第三，”钱总突然不笑了，声音沉下来，“为了配合新制度，我们同步上线‘AI全维度考核系统’。系统会实时采集大家在工作时间内的一切行为数据——包括但不限于键盘输入频率、鼠标移动轨迹、网页浏览时间分配、甚至坐姿与眼动情况。”

整个会议室安静得像死了一样。

钱总满意地扫了一眼台下：“这套系统可以精准识别‘无效时间’，也就是我们俗称的——摸鱼。”

林一凡感到背后的汗毛一根根立起来了。

他猛地意识到，星期三下午放假不是福利，是诱饵。钱总在制造“高福利”的幌子，然后用房顶上的行为监控把所有人彻底锁死。而赵日天的失踪，恰好给了钱总最好的借口——你是自己出走的，还是被“摸鱼系统”逼走的，那都不重要了。

散会时人群像潮水一样往外涌，刘维拉住林一凡的袖子，声音压得极低：“我那天晚上其实见过赵日天，在天台，他给我留了一句话：‘告诉林一凡，04:22不是时间，是编号。’”

林一凡猛地停住脚步，心脏像被什么东西攥住了。他低头打开脑海里的系统面板，沙漏图标还在闪烁。而那个锁定的模块上，原本显示“04:22”的位置，此刻正缓缓浮现出一行小字——

“检测到外部关键词，模块解锁条件满足。是否启动？”

林一凡站在原地，指尖微微发抖。他觉得自己像站在一扇黑漆漆的门前，门后不知道是真相，还是另一个陷阱。

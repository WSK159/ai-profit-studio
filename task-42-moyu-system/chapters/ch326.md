# 第326章 铜扣

灰袍人站在防空洞入口的阴影里，白色棒球帽压得很低，只露出下半张脸。他右手摩挲着那颗铜扣，拇指在扣面上来回搓动，像在盘一块养了多年的核桃。

“主人该进来了。”他又说了一遍，声音沙哑，带着某种刻意压低的平板感，像在念一句背熟的台词。

孙满仓回头看了林一凡一眼，那眼神里有种说不清的复杂。他没有说话，但林一凡读懂了其中含义——别乱动。

“你家主人是哪位？”林一凡往前走了一步。他刻意把步子迈得慢，让摸鱼系统的面板在视网膜边角保持运转。确认一下当前咸鱼值余额，三万七千四百二十点。足够兑换一次“僵直闪避”或者“短距位移”，真动起手来不至于完全没底。

灰袍人没有回答他的问题，只侧过身，让出防空洞入口侧面的窄道。这个动作做得极熟，像是练过千百遍。

“请。”

孙满仓叹了口气，把那只黄铜匣子重新揣进怀里。他走在最前面，路过灰袍人身边时停了一瞬。灰袍人的棒球帽檐微微抬了一下，露出一只眼睛的轮廓，林一凡没看清颜色，但他看见那只眼睛分明是笑着的。

那笑让他脊背发凉。

三个人鱼贯进入防空洞。洞口外的风很快被厚重的混凝土墙隔断，空气变得潮湿沉闷。走了大约二十米，金属梯井出现在面前。

第三级台阶早已裂开，露出下方的竖井。金属梯垂直向下延伸，看不到底。梯井侧壁上涂刷着白色的符号，原本的内容被粗暴地抹去，用红漆重新写了一个字——零。

孙满仓停在梯井边，沉声道：“这下面我走过一次，到第三层就上不来了。”

“师父当年说的？”林一凡问。

“不是。”孙满仓摇头，“我自己走的。四十年前，我师父带我来这里取钥匙，我好奇，偷摸往下探了一层。第三层全是雾，见不着底，回来之后高烧三天，躺了半个月。”

灰袍人没碰梯子，像一截枯桩一样立在旁边。他只说了一句：“主人说，请客人先走。”

孙满仓皱眉：“你主人到底——”

“孙伯。”林一凡打断他，“我下去。”

他的理由是现成的：梯井侧壁上的“零”和照片背面那句“第三梯记着，第一梯忘记”有直接联系。沈临渊留下的线索都指向这下面。如果这真是父亲留下的通道，那他这个当儿子的不进，谁进？

但他真正的理由，只有他自己知道。就在他刚才走近梯井时，摸鱼系统弹出了一条从未见过的提示——

【检测到特殊场景：遗产通道。解锁隐藏任务“归还自由”第二阶段：下行 33 米。奖励：未知。】

“归还自由”这四个字，他只在系统面板里见过一次，是在他第一次看到那张老照片的时候。而现在它再次出现，给了他一个精确的距离数字。

33 米。

这个数字刻意的突兀，像有人量好了标尺，等他一步一步量完。

林一凡握住金属梯扶手，铁管冰凉，上面结着细密的露珠。他往下探了一步，脚踩实，换手，再下一步。身后的光越来越少，头顶的天光变成一方小小的灰白，然后被孙满仓的身影彻底挡住。

三十三步之后，他的脚踩到了实地。

下面没有雾。

下面的黑暗里，只有一个人。

那个人背对着他，坐在一把折叠椅上，手里捧着一本翻烂了的笔记本。他的头发花白，身形佝偻，穿一件洗得发白的旧蓝布工作服——那工作服的款式，正是星辰科技二十年前的老款工装。

“来了？”那人没有回头，声音沙哑得不像话。“比预计早了三年。”

林一凡的手不自觉地攥紧。

因为这声音。他太熟悉这声音了。他上辈子听过无数次，在葬礼上，在遗物整理间，在梦里反复回响。

沈临渊的声音。

那个他叫了二十六年“叔叔”、又在三个月前发现是自己生父的人的声音。

“你……”林一凡喉咙生涩。“你没死？”

那人终于放下笔记本，缓缓转动椅子，露出面容。

林一凡浑身一震。

那不是沈临渊的脸。那是他自己的脸，只是像被岁月狠狠打磨过——眼窝深陷，颧骨突出，嘴唇干裂。但眉骨、鼻梁、下颌的角度，和他一模一样。

“不，我死了。”那人笑了笑，目光越过林一凡，看向他身后梯井上方的黑暗。“死了三十二年。活下来的那一个，才是真正的沈临渊。”

话音未落，头顶传来金属梯被踩动的哐当声。

灰袍人跳下来，落地的姿势像一只猫。他摘下白色棒球帽，露出一张与孙满仓有七分相似的脸。

“第三梯的人该忘了。”他笑着开口，“第一梯的人——该记得自己是谁。”

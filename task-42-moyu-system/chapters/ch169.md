# 第169章 半开之眼

凌晨一点十七分，我踩着气垫边缘翻过围墙，膝盖撞在水泥地上发出一声闷响。

身后星辰科技主楼的灯光刺破夜空，像一只睁开的巨眼。那感觉太过强烈——仿佛钱总正站在顶楼破碎的窗口，用那只钥匙上的“半开之眼”看着我。

我爬起来，没敢走大路，钻进旧城区那片拆迁废墟里，一瘸一拐混着墙根的阴影往东摸。手机震了四次，三条是系统提醒，一条是老王。

系统消息：【警告：钱总已记录您的样貌特征，建议24小时内不要进入星辰科技区域。】

老王的信息只有一行字：看到你安全从楼里出去了，到老地方来。别去咖啡馆。

我犹豫了两秒，拐向老城区的城中村。

老王那间出租屋藏在七拐八拐的巷子深处，门锁老得钥匙都能晃掉漆。我敲了三下，他拉开门，脸上的褶子挤成一团，像是松了口气，又像是想说点什么。

“你疯了。”他把我拽进门，把窗帘拉了又拉，“你跑去顶楼干什么？那层楼连保洁都不让进。”

“钱总在那儿等我。”我一屁股坐在他床上，把手机屏幕上那条系统警告给他看，“他手里有一把钥匙，上面刻着……”

话说到一半，我盯着老王露出半截的左手臂，心口陡然一抽。

老王的左手背，内侧贴着脉搏的位置，那道青色纹路在台灯下暗暗发蓝。以前我没细看过，草草当是血管上的染色。今夜从顶楼窗户跳下来之前，我明明只在钱总钥匙的金属面上扫了一眼那个图案，此刻却像烙铁一样烫进记忆。

半开之眼——一个外圈椭圆、中央竖瞳撕裂成两半的眼睛。

而老王手背上那道纹路，指向的方向、弯曲的弧度、连中央那一道细裂的缝隙，都如出一辙。

屋内静了两秒。老王顺着我的视线看向自己的手背，猛地拉袖子盖住：“看什么呢——”

“你认识钱总？”我声音压得很低。

老王的手僵在袖口上。

他沉默了很久，久到我以为他不打算开口，最后闷声道：“认识，也不太认识。我比他早进星辰七年，当年他还不是我老板的时候，是个跑业务的，敲过我们技术部的门。”他说着顿了顿，“后来他升了，有一回紧急上线大版本，我们组熬夜干了三天三夜，他凌晨三点进机房，塞给我一杯咖啡，问我愿不愿意‘手里多点东西’。”

“什么东西？”

“他拿了一把钥匙让我看，说是公司的‘核心权限’，只要在那个文件上按个手印，以后全公司考勤随便我调。我那时候也年轻，脑子一热就应了……”老王别开脸，喉结上下滑了滑，“但后来我再没见过那把钥匙，只留下手上这道痕迹，怎么洗都洗不掉。”

我脑子飞速运转。

钱总那把钥匙上有“半开之眼”，老王手背上的纹路同源。那是不是说明，老王也是被“钥匙”选中的参与者之一？还是说，他是曾经被资本神“标记”过的人？

门外巷子里传来一阵狗叫，随即又安静下去。

老王忽然问：“你跳窗户之前喊的什么？”

“凌晨三点不加班咖啡馆。”我看着他，脑子里灵光一闪，“你知道那个地方？”

老王的表情像嚼了一口柠檬：“我知道。那是这个区最早一批倒闭的网吧，改成咖啡店没撑三个月就黄了，现在连招牌都拆了。你约人去那儿？”

“钱总让我跳的路线，气垫方向正好朝那儿。”我皱眉，越想越不对劲，“他像是安排好了，逼我从那条路走。”

“那你就更不该去了。”老王站起来，去厨房烧水，窸窸窣窣的声响里传来他的声音，“他让你去的地方，一定藏着他想让你看到的东西。”

我不知道老王说的对不对，但我在那个瞬间想起系统面板里的另一句话——

【隐藏任务触发线索：凌晨三点不加班咖啡馆地下二层。达成条件：你本人亲自到访。奖励：咸鱼值+10000，解锁“反卷护盾卷II”前置任务。】

钱总逼我跳那扇窗，可能不是为了抓我。他是想让我走那条路——顺着气垫方向，走到那家咖啡馆。

他到底是想抓我，还是想送我去某个地方？

凌晨两点四十分，我从老王这儿拿了一件外套套上，走出城中村，朝“凌晨三点不加班咖啡馆”的方向走。

路越走越偏，路灯一盏比一盏暗。

咖啡馆的招牌果然拆了，只剩墙壁上一个锈得发黑的轮廓。门虚掩着，里面透出一点橘黄色的光。

我正要伸手推门，手机又响了一下。

这次是一条陌生号码短信：

“林一凡，你要是敢进去，你摸鱼系统的事，明天就传到全行业耳朵里。——赵日天。”

我盯着屏幕。

卷王赵日天，竟然知道我在这儿。

里面那扇门缓缓朝内开了一条缝，地下一层的楼梯出现在我眼前。橘色的光从深处漫上来，像一只半睁开的眼睛。我迈开腿，走了进去。

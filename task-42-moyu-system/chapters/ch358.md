# 第358章 锁芯暗语

铁门前的空气凝得发稠。

林一凡没有动，目光掠过那枚铜纽扣，又落回神秘人脚上那双手工布鞋——鞋底沾着云顶山特有的红黏土，边缘还缀着几粒干碎的草籽，像是一路翻山越岭走来的。

孙满仓挡在他身前半个身位，没有回头，低声说了一句：“你认得他？”

神秘人轻笑了一声，声音像砂纸磨过铁皮，哑得让人牙酸：“我认他不认得。小孙，二十年前你师父带你上山那回，是我开的门。”

孙满仓肩头明显一颤，脱口而出：“你是……管钥匙的？”

神秘人不答，目光越过孙满仓，径直钉在林一凡脸上：“小子，那枚铜纽扣，你拿稳了。第三道锁芯的牙口不对的话，硬拧会断——你这辈子再没机会开这扇门。”

林一凡指尖微微发凉。他低头看了一眼那枚铜纽扣——边缘一圈极细的波浪纹，像某种老式机床上车出来的零件，而非裁缝缝在衣服上的扣子。前世他见过一次类似的物件，在父亲的工具箱最底层。

他深吸一口气，问出了那个压在心底许久的问题：“你认识沈临渊？”

神秘人的眼神里掠过一丝极淡的光，像夜河里一闪即逝的鱼脊：“小沈啊……他是沈家的独子，你爹是他一手带出来的。你爹上过三次云顶山，头一回背着一把铁锹，第二回空手，第三回带了那块三棱夹板。你呢，头一回上山，就带齐了三把钥匙。”他顿了顿，声音忽然压得更低，“像话吗？”

林一凡听懂了话里的试探，也听懂了那道试探底下的东西，他爹来过不止一次，而他上一世一无所知。

孙满仓哑声道：“第三梯下面这条通道，我师父只带我来过一次，说‘水渠是给自家人走的’。你方才说‘管钥匙的’，这铁门一共有几道锁？”

神秘人竖起两根枯瘦的手指：“明锁两道，暗锁一道。明锁你已经开了三棱和四棱的壳，暗锁在这墙肚里——钥匙用你那铜纽扣对位，转法却不能照着锁芯表面的刻度。这扇门是‘偏锁’，得逆着螺纹走半圈，再顺走两格牙。”

“你怎么知道得这么细？”林一凡目光收紧，“这锁你开的？”

神秘人沉默了一瞬，像是在掂量什么。半晌，他才吐出一句：“这锁是我爹打的。”

空气里有什么东西被这句轻飘飘的话砸碎了。

孙满仓猛地回头看他，嘴唇翕动了两下，终究没有出声。赵日天站在最后面，却在这时朝铁门侧边那面壁看了一眼，声音冷得像浸过井水：“这墙上有道新灰，像是最近三个月内抹过的。你爹打的锁，你抹的墙？”

神秘人嘴角扯了一下，却笑得很苦：“那是沈稚冬抹的。”

林一凡瞳孔一缩。沈稚冬——那个在磁带里被说“没有来过”的名字——她抹过这道墙？

他伸出手，食指指腹贴上那道灰面的边缘。灰面干透了，但纹理细密，不是普通泥灰，混着某种淡青色的石粉，在暗光下泛着极浅的荧光。他前世在军工厂的图纸上见过这种材质——夜里能反光，专用来辨认暗记。

他脑子里的那根弦“嗡”地一下绷紧了。他摸出手机，点开那条短信记录，翻到“1147”发来的那条指令：“别碰四棱锁，先转绞轮三圈半。”他当时照着做了，开的是三棱锁。可那条短信没有提过这道暗锁。

也就是说，那个发短信的人，也不知道暗锁的存在。

林一凡收回手，回过头，直面神秘人的眼睛：“你说等我们好久——那你等我来，是要我开这道锁，还是要我别开？”

神秘人没有立刻回答，而是侧耳贴着铁门听了一会儿，像在等某种声音从门缝深处传来。过了大约十息，他直起身，声音放得很轻，轻到几乎贴着铁门的寒意漂过来：“门后面那台绞轮，是三十七号项目的备件。你爹的编号是27，他死的那年，备件库里丢了一台。”

他停了一下，一字一字地说：“那台备件，现在就在这扇门后面。你要铜纽扣开锁之前，先想想——你那枚扣子，是不是你爹从绞轮上拧下来的？”

林一凡握着铜纽扣的手猛然收紧。他先前以为那只是父亲军装上的纽扣，此刻才发现，扣子环形内沿有一圈极细的“卍”字纹，与绞轮铭牌“27”的刻字方式如出一辙。

那不是衣服扣。那是绞轮的零件。而孙满仓替他保管的，是一把“钥匙”，也是一件物证。

孙满仓似乎也意识到了这一点，脸色骤变：“林……小凡，这锁不能开。”

神秘人却接口道：“该不该开，看他手里的东西有没有‘认过主’。锁芯牙口有四格，一格对‘过去’，一格对‘现在’，一格对‘将来’，还有一格——只能对死人。你拧到哪一格，门背后那台绞轮就会告诉你，你爹到底死在谁手里。”

他往旁边让开半步，铁门侧壁那道暗锁的槽口完整地露了出来——五棱形，牙口内侧嵌着一圈暗红色铜蕊，映着墙角那盏昏黄的壁灯，像一只半阖的眼。

林一凡知道，自己已经站在了某道分界线上。他低头，将那枚铜纽扣缓缓举到眼前。

他忽然注意到，在扣子边沿刻着极细的四个字，不是编号，而是一行蝇头小楷——“春来江水”。

他心头骤震，他母亲的名字里，就有一个“春”字。

他刚想开口问神秘人，却听见通道尽头传来一声极轻的、金属与岩石刮擦的声响，像是有人在另一头，把一柄长刀从鞘里抽了出来。

神秘人的脸一下白了：“有人走水路过来了。”

他压低声音，近乎咬着牙根说：“开锁。现在。不然我们谁都走不掉。”

林一凡的目光在铜纽扣上那行字与神秘人发白的脸色之间扫过，最终，他把铜纽扣抵上了暗锁的牙口。

# 第307章 数据洪流

服务器通电的嗡鸣声像是从地底钻出来的兽吼。林一凡下意识挡在沈稚冬身前，目光锁定最近一台机柜——指示灯从红色跳成绿色，阵列风扇由缓到疾，声音从低沉的震动变成尖锐的呼啸。

“谁开的？”沈稚冬压低声音。

“没人。”林一凡伸手摸向机柜底部的主电源，指尖刚触到金属面板就猛地缩回来——表面发烫，像是已经运行了很久很久。

“不可能。”沈稚冬绕到他身侧，盯着那排亮起的LED阵列，眼神儿有点不对，“这层机房三年前就断电了，我上次查过物业记录，配电箱锁死在负二层，钥匙只有安保部的人有。”

林一凡没接话。他盯着主控屏上滚动的日志，那些字符快得只留下残影，但有一串数字闪过去时，他脊背一凉——时间戳，一模一样，2019.03.17，他入职第一天的日期。

“日志被刷写了。”他声音发干，“系统认为今天是2019年3月17日。”

沈稚冬脸色微变，正要说什么，身后的服务器阵列忽然齐刷刷停止了运转。一米高的机柜发出令人牙酸的金属位移声，顶部面板像棺材盖一样缓缓滑开，露出内部密密麻麻的硬盘槽——但所有的槽位都是空的，只有最底层那一格，静静躺着一块老式的2.5英寸机械硬盘，边缘贴着泛黄的标签，上面用马克笔歪歪扭扭写着一行字：

“给他。别让她来。”

字迹他认得。

上辈子，老王加班到凌晨时，偶尔会坐在工位上用同一支黑色马克笔涂画。那些草稿纸上的字迹，跟眼前这笔锋一模一样，连写“她”字时那一笔习惯性的上挑都没变。

“老王……”林一凡喉咙发紧。他伸手去取硬盘，指尖刚碰到金属外壳，身后那排服务器忽然同时发出刺耳的警报声——嗡——嗡——嗡——低沉的蜂鸣像是某种古老的电码。林一凡愣了一下，那节奏他太熟悉了。

“它——在——等。”沈稚冬轻声翻译了出来，说完自己也愣住，“摩尔斯电码？这跟铁皮柜上的节奏一样。”

林一凡咬紧后槽牙，他没犹豫，一把摘下硬盘，转手塞进自己外套内袋。警报声戛然而止，机柜顶盖合拢，指示灯恢复成熄灭前那种暗红色。“这里有问题。”他看着沈稚冬，“老王留的东西为什么要放在这种地方？他是怎么把硬盘送进来的？还有——

他话没说完，手机震了。屏幕自动亮起，一条来自未知号码的短信，只有五个字：

“快离开那里。”

林一凡瞳孔一缩。几乎是同一刻，头顶传来一声沉闷的金属碰撞声——负一层的电梯井方向，门像是被什么重物从外面砸开了一样，哐的一下。

然后是脚步声。不止一个人，皮鞋底踩在水泥地面上，整齐而急促，少说得有五六个人。

沈稚冬的手已经按上了腰后，但林一凡一把抓住她的手腕，拉着她往机房另一侧的消防通道跑。他知道这条路——七年前他入职第一天，老王曾经提过一句：“这楼逃生通道是封的，但负一层有扇后门。”

后门确实在。铁门上挂着链条锁，锁头已经锈死，但墙体边缘的砖块脱落了一些，露出一道堪堪够人侧身挤过的缝隙。林一凡侧身钻过去，沈稚冬跟在他身后，两个人刚挤过缝隙，身后的通道里响起一个低沉的声音：“林组长，别跑啊。钱总等你很久了。”

林一凡没回头，但他听见那个声音的瞬间，浑身的汗毛都竖起来了——是陈重阳。那个本应在三年后才出现的人，为什么会在这里？

他没时间多想。后门外面是一条窄巷，月光惨白地铺在地上，巷尾停着一辆没熄火的黑色面包车，车窗摇下来一条缝，里面的人低声说：“上车。”

林一凡脚步顿住。他看着车内那张脸，跟记忆里某个模糊的形象渐渐重叠——灰工装，鸭舌帽，熬夜熬得泛红的眼睛。是那个在老宅后门外敲过墙的人。

“你……”林一凡刚开口。

“你手里那块硬盘，开机密码是你妈生日。”灰工装男人打断他，视线落在他外套内袋上，“她让我告诉你，别信任何人，包括老王。”

这句话像一根针扎进他脑子里。林一凡攥紧内袋里的硬盘，指节泛白。身后巷口，陈重阳的脚步声已经逼近，越来越近、越来越清晰。

他低头钻进车里，车门没关，他偏过头，对还站在原地的沈稚冬吼了一句：“你走那边！”

面包车启动的瞬间，林一凡透过后视镜看到沈稚冬顿了一下，随即闪身钻进另一条暗巷。他闭上眼，手指摸到硬盘外壳上那道细小的刻痕——0123，这是他母亲最后一次住院的日期。

不是他的生日。灰工装男人说的是对的，密码是后面那六位数字。

而门禁卡，沈稚冬手里那张老王给的门禁卡，编号开头正好就是0123。这事儿，老王从来没提过。

车驶出巷子的时刻，灰工装男人开口道：“你刚才在路上撞见的那个穿灰西装的人，是赵恒的人。他比你早到了十分钟，把老机房的主控芯片带走了。”

芯片。林一凡猛地睁开眼：“芯片上面有没有刻痕？”

灰工装男人从怀里摸出一张拍立得，递过来。照片上是一块指甲盖大小的芯片，边缘刻着两枚极小的数字——

“14”。

林一凡的呼吸顿住了。那是他锁匠师父工具箱里，三把钥匙底座上刻着的数字之一，缺的那一把，编号正好是14。

面包车在夜色里穿行，身后路口亮起两只刺眼的远光灯，径直加速追了过来。灰工装男人瞥了一眼后视镜，踩下油门，声音哑得像是从喉咙里挤出来：

“坐稳了。接下来这段路，你只能信两个人——我，和你自己。”

林一凡攥着硬盘，没说话。但他心里清楚，今晚过后，老王、赵恒、钱总、还有他母亲，所有人留在棋盘上的位置，都已经被彻底打乱了。

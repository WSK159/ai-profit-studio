# 第294章 水塔里的旧机房

林一凡推开星辰科技侧门的玻璃门时，夜色已经彻底落下来。他装作买烟路过门卫室，趁值班保安低头刷短视频的间隙，伸手探进了第三格雨伞桶。指尖碰到一个冰冷的金属物体——一把锈迹斑斑的小钥匙，柄端缠着一截黑色胶带。

他收进掌心，不着痕迹地走出大门，朝东南方向快步而去。苏州河南岸的废弃水塔，在夜色中像一根折断的黑色手指，戳向灰沉沉的天空。

水塔大门没有上锁，铁链松松垮垮地垂在地上。他推门进去，灰尘从门轴间坠落，落进一束从顶窗漏进来的路灯光里。塔内旋转楼梯锈迹斑驳，每一级台阶踩上去都发出令人牙酸的吱嘎声。他扶着扶手往上走，到了第三层——那层楼地板铺着旧瓷砖，明显比其余几层更干净，像是被定期清理过。

他掏出那把锈钥匙，目光扫过四周。在一处墙上，他看到一个近乎隐形的暗门轮廓——门缝与砖缝严丝合缝地贴合，如果不是系统雷达显示这层有微弱的电子信号活动，根本不可能察觉。

钥匙插入锁孔，转动时发出一声清脆的“咔哒”。暗门向内弹开一条缝，冷风从里面涌出来，混合着机器运转的异味——导热硅脂、焊锡和打印电路板的焦味。

他推开门走进去。

暗门后是一间不过十平米的旧机房。墙角堆着两台淘汰的服务器机柜，灰尘覆盖的屏幕上还亮着几行绿色字符——像是常年没有断过电的某个监控节点。正中央的桌上放着一台老式CRT显示器，旁边连着一个外接硬盘，灯在缓慢闪烁。

林一凡走过去，触碰鼠标，屏幕亮起来。桌面上只有一个文件夹，命名是：“河豚计划”。

他点开文件夹，里面是数十张扫描件——图纸、清单、和一份手写笔记的翻拍照片。他快速浏览。第一张图纸标注了第三手术室的内部结构，其中有个细节让他瞳孔一缩：手术台旁边的器械托盘上，放置着一枚植入体，编号被人用红笔圈住，写着“001——实验者：林建国”。

他父亲的名字赫然在列。

他继续往下翻。其中一张A4纸记录着植入体设计参数，末尾有一段笔迹，他一眼认出——那是他母亲的，她在末尾写了一句：“如果001号信号源异常，需立即断电。不要让数据回流。”

林一凡盯着这行字，背脊微微发凉。他父亲在接受植入手术时，母亲不仅在场，还清楚地知道那枚植入体存在的风险。而“不要让数据回流”这句话——与摸鱼系统中那个所谓的“外部核心载体”的说法，产生了某种可怕的共鸣。

他继续翻看下一张照片，画面中的手术床边上放着一张名牌——主刀医师：苏婉。他母亲的名字。

“苏婉。”

他念出这个名字时，声音在狭小的空间里回荡。他从来没想过，母亲的职业竟然是医生。在他童年记忆里，母亲从没提起过她的工作内容，只说在“研究所做技术员”。

他正想继续翻看下一张，CRT屏幕的绿色字符忽然跳动几下，弹出一行新的信息：

**“访问者确认——001号授权。文件解锁：第三层。请出示‘缝合线’。”**

缝合线？林一凡愣了一下，随即从内衣兜里摸出那条父亲留给他的缝合线。他当初从手术照片背面找出来的东西，一直贴身带着。他将缝合线贴近显示器底部的读卡区域，屏幕闪了一下，紧接着一个隐藏文件弹出：

**“《河豚计划·下线协议》——苏婉手稿（2019.6.17）》”**

林一凡的手指悬在键盘上方，迟迟没有落下去。这座水塔内的信息，似乎正等着他亲手打开一个他还没准备好面对的事实。

他深吸一口气，点开了文件。

第一行字体潦草——是他母亲在极度紧张状态下写的字：

**“如果林一凡看到这份文件，说明我已经失败了。001号不是实验体，是钥匙。而你——不是巧合被选中的人。”**

他怔在原地。

门外，楼梯下方传来一阵脚步声——有人正在上塔，步伐沉稳，越来越近。他迅速扫视周围，关了显示器，攥紧缝合线，侧身贴到门边的阴影里。

脚步声停在了这扇暗门外。一道声音响起，低沉沙哑：“我知道你在里面。别躲了——我给你带了一杯热茶。”

他认得这个声音。灰工装老头。

“你母亲，她托我带句话给你——”老头说，“她说，‘别信任何人，包括我’。”

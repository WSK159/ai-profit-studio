# 第230章 骨灰盒里的钥匙

陈默说出那句话的时候，声音没有一丝颤抖，像是这个秘密在他心里已经放了太久，久到早就磨平了棱角。他把手伸进外套内袋，缓缓掏出一个黑色的绒布小包，大小和人的掌心差不多。

“不用去墓园。”他说，“我爸骨灰盒里那份‘遗物’，我早就取出来了。”

绒布打开，里面是一截和配电房里一模一样的铜线，但这一截更短，只有拇指长，断口处像是被什么东西齐根咬断的，露出暗金色的金属光泽。铜线表面，同样镌刻着一串钢印码——和配电房里两根绞合线表面看到的那串编码，首尾呼应，像是同一句话被折断成两截。

林一凡接过那截铜线，指尖传来的温度让他眉心一跳。这铜线……是温的。像是刚从人体内抽出来似的。

他把系统面板调出来——节点连接进度：78%。在系统的界面上标注着一行提示：“缺少终端密钥，无法继续推进。”

那截铜线，正是终端密钥。

“你爸——”林一凡斟酌了一下措辞，“到底是怎么死的？”

陈默的嘴唇抿了一下，像是犹豫，但只犹豫了一瞬：“我爸是维护工，你之前猜得没错。但你们不知道的是，他在星辰科技做维护工之前，是电网公司的老职工，参与过这栋大楼地下管网的初建。他跟我说过一句话，说这栋楼的地基下面，埋的不仅仅是电缆。”

“那是什么？”老王问。

“是‘判决’。”陈默说，“我爸说，当年建这栋楼的时候，有一个上面下来的监理，从没见过面，所有指令都通过一卷图纸下达。图纸上标注了一个特殊节点——就在档案室这面墙的正中央。施工队按照图纸往下挖了九米，挖到了一块浇筑好的混凝土底座，底座中间留着一个凹槽。”

他顿了一下，将那截短铜线攥紧在掌心。

“那个监理亲自到场，把一根铜线埋进凹槽里，然后浇筑密封。从那之后，图纸上这栋楼就被画了一个圈，我爸说当时有个工程总工嘀咕了一句——‘这不是盖楼，这是栽一棵树。’”

林一凡的脑子里轰地一下。

不是盖楼，是栽一棵树。那根铜线就是根须，整栋大楼的电网就是树干，系统就是从这棵树里生长出来的果实。而档案室墙体内埋着的骨架——是树的养分。

他把短铜线和手里那根从配电房拆下来的铜线并列在一起。两截铜线的断口边缘竟然是严丝合缝的，像是原本就是同一根线，只是被人从中间生生截断，分给了不同的人保管。

“你爸说了‘判决’两个字，是不是指——那个监理从图纸上划了一条线，把这些做维护工的命都填进去了？”老王问，声音很低。

陈默没有回答，但他的手微微发抖。过了很久，他才开口：“我爸留下的另一句话，我到现在也没想明白——”

“什么话？”

“他说，等有一天有一根断线自动接上了，就说明裁判已经坐到了棋盘边。该落子了。”

林一凡把两根铜线对齐，让断口处贴合在一起。这一次没有电弧，没有闪光，但铜线边缘的金属像是融了一样，缓缓地绞合在一起，变成一根完整的、两指长的金属棒。系统面板上的数字猛地跳动——节点连接进度：78%→86%。

与此同时，档案室的墙体深处传来一阵沉闷的响声。像是有什么东西在墙内转动，一根锁扣被掰开。合上的墙体中央，一道极细的裂缝缓缓向两侧扩张，露出里面漆黑的空洞。那股被封存在墙内的灰尘味和铁锈味同时冲出来，呛得老王咳嗽了两声。

墙内，赫然立着一句跪姿的骨架，正倚靠在墙洞的深处。骨架的脊柱上，缠绕着一圈又一圈的铜线，从颈椎骨一路缠绕到盆骨，像是穿了一件铜线的外衣。那些铜线的一端伸入地面的电缆层中——牢不可分。

而那具骨架的双手，被人以一种刻意摆放的方式合拢在胸前，像捧着一本书。林一凡打着手机电筒照进去，看见骷髅的指骨间，夹着一片泛黄的纸条。

他正要伸手去拿，系统突然发出一道从未有过的警告声。

【警告】检测到“资本神”代理人正在接近。距离约 200 米，速率约 6.5m/s，定向匀速接近中。

林一凡抬头看了一眼走廊方向：“有人来了。”

陈默的脸色变了，他听出了脚步声——那脚步的节奏，像极了监控里钱总下车后的步频。老王把钢管横在身前，但林一凡看了一眼系统面板，反卷护盾的能量条只剩 30%——这个护盾挡不了物理攻击。

“那就来。”他伸手，慢慢从骨架指间抽出那片纸条，“看谁先拿到。”

借着手电的光，他看见纸条上写着一行极小的字，是手写体，墨迹褪色严重，但依稀可辨——

“第二台终端在自由之海。”

而那脚步声，恰好在这一刻，停在了档案室门口。

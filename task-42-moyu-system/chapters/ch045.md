# 第45章 深夜档案

凌晨两点十七分，星辰科技A座二十三层只剩林一凡工位上的台灯还亮着。他把宋远桥办公室的钥匙还回去的时候，空调系统发出低沉的嗡鸣，像一头野兽在黑暗里喘气。

“奇怪。”林一凡站在过道中央，摸鱼雷达自行开启，视野里整层楼的劳动浓度接近零，唯独宋远桥办公室门缝里渗出一线幽蓝的光——那是设备通电的信号。他折返回去，推开门。

宋远桥的办公桌上，一台不属于星辰科技固定资产登记的银色笔记本正开着，屏幕幽幽映出一个人影。那人听到门响，没回头，只是把烟灰缸往旁边推了推：“门不锁，就是在等你。”

赵日天转过身来，脸上的表情是林一凡从未见过的松弛。他面前的屏幕上，赫然是效率大赛复赛的题目框架，而右下角那个文件命名格式，和沈敛U盘里的“留三份”一模一样。

“你别慌，”赵日天敲了敲屏幕，“你之前是不是觉得我装了个卷王系统？对，我是有。但我的系统的上一个宿主，叫沈敛。”

林一凡把门关上，靠在门板上：“你查我？”

“没查你，是沈敛查你。”赵日天从抽屉里抽出一张打印纸，递过来，“他在去年离职前，把一份东西藏在了公司的内部数据湖里。我上个月找到的。”

纸上是一行加密路径，末尾标注着“D3-B1区块/镜像层/日期戳2025.11.03”。那正是林一凡在初赛PPT里暗示过的异常访问位置。

“什么意思？”

“意思是，”赵日天把烟摁灭，“效率大赛复赛的规则里有一条——原始数据只允许使用初赛通过的缓存副本，不许触碰生产库。但秦氏集团的人上周已经通过他们安插在星辰的接口人，把生产库的真实数据导出了一份。”他停了一下，“他们要让你的组，拿到假数据，做出假报告，然后当着全行业评委的面，证明你所谓的‘D3-B1异常’是一场乌龙。”

林一凡沉默了一分钟，然后笑了：“所以你是来帮我的？”

“我只是不想让秦氏那帮人痛快。”赵日天把电脑合上，“复赛是周三，你还有两天。要不要我告诉你‘留三份’到底是哪三份？”

他话音刚落，楼道的声控灯突然亮了一排。两个人同时看向门口——门把手的阴影下，不知何时压着一张门禁卡，上面印着宋远桥的名字，而门卡背面用记号笔写了一行字：“别信他。”

林一凡抬起头，赵日天的目光也落在那张卡上。谁都没有先动。黑暗里，只听到顶楼服务器机房传来一声极细的电流短路声，像是什么东西被悄悄拔掉了电源。

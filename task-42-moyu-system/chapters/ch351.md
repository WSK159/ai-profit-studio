# 第351章 老沈的第三封信

铁皮盒落在柜台上，磕出一声沉闷的响。那声儿里带着实心的重量，不像装纸条，倒像装着什么金属物件。

皮夹克男人放下盒子，没有多做停留，转身往外走，到门口时停了一下：“老沈让我捎句话：开门的钥匙，从来不是形状像钥匙的那把。”

门关上，铁铺里再次安静下来。

林一凡和赵日天对视一眼。赵日天的左手已经按下手机拨号界面，却被林一凡按住了手腕：“先别追，追不上了。”

孙满仓没有说话，目光死死黏在铁皮盒上。林一凡注意到，他的右手食指一直在轻轻摩挲那把黄铜钥匙的侧面，那是个极细微的、甚至他自己都没察觉的习惯动作。

“打开。”林一凡的声音稳得不像他自己。

老头没动，赵日天也没动。林一凡伸手，按下铁皮盒的卡扣，盒盖弹开，露出里面的东西——一块老旧的机械怀表，黄铜外壳、磨损严重的表盘，与他口袋里那块同款同牌。只是这块的表壳内侧多了一圈极细的刻字，不凑近看几乎看不见。

他拿起表，凑到窗边光线里，念出那行字：“沈稚冬，生于三月初七。第九组，第二十七号。”

第四个字符“27”让林一凡心口猛然一跳——与陶土徽章上的数字完全相同。

“二十七号……”他低声重复。

老头从旱烟杆上抬起眼皮：“你看看底下还有一层。”

林一凡翻起怀表下方的绒布垫子，底下压着一张对折的泛黄信纸。展开，墨水褪色但字迹遒劲，是沈临渊的亲笔。

孙满仓盯着字迹看了片刻，忽然开口：“这封信，是给我师父的。墨太旧了，得是三十多年前写的。”

信纸上只有三行字：“钥匙不是锁的答。门不是墙的口。你来找我的时候，我已经不在了。”林一凡翻过信纸背面，右下角有一行更小的字，与正面笔迹相同但收笔更为急促：别信我哥。

这四个字让他头皮一麻——防空洞里那句摩尔斯电码“别信哥”，在此刻像一根针扎进他记忆里。

“你师父……”林一凡转向孙满仓，“你师父，和沈临渊是兄弟？”

孙满仓沉默了很久，缓缓点头：“师徒是后来的事。他们最初，是同父异母的兄弟。”

赵日天终于出声：“那沈临渊让我们去开墓里的门，他哥不让，这信上又写了‘别信我哥’——他防的人，是他哥？”

铁铺里静了一瞬。那扇五锁孔的门画上，五个黑洞洞的锁孔像五只眼睛，无声地俯视着他们所有人。

老头把烟杆放下，声音沙哑：“老沈当年之所以离开，不是因为他发现了什么。是因为有人让他走。”他停顿了一下，目光落在林一凡口袋微微鼓起的位置，那个装着摩尔斯电码纸条的暗袋。“那个人，用他的方式警告他：你哥不能信。你叔，也不能信。”

铁铺外街角传来一道极轻的脚步声，随即在窗台下停住。林一凡抬头，看到的是一道向后窗玻璃投来的影子——那个人站在那里，已经有一阵了。

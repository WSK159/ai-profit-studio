# 第111章 三人成行

老王说完那句话，负三层的旧机房骤然冷下来。

那种冷不是温度，是压迫——像是有什么极其庞大的意识从头顶碾过，在场的几个人都被罩在同一只睁开的眼睛底下。

林一凡头皮发炸：“亡灵？你说的第三个人……是死人？”

老王没立刻答，低头摆弄银章母体。那金属块在他掌心里自动展开成个多边体，像颗心脏一样微微搏动。他抹了把脸上的灰，声音干涩：“别问那么多，你只要知道，负五层那扇门是‘断根暗码’锁死的，物理破解没用。它认三种身份：生者、半生者、死灵。我们仨——你、我、她——正好各占一个。”

他说“她”的时候，看了一眼周莉的档案照片。

林一凡顺着他的目光看过去，照片上周莉戴着工牌，笑容温和，仿佛随时能走出来喊一声“小凡”。但那份保密协议已经把她钉死在“已离职”的档案里很久了。

“等一下。”赵日天一直没开口，直到这时才冷笑一声，“你意思是，要带个死人过来才能开门？那你跟我们扯什么，直接去殡仪馆借一个不就完了。”

老王没有笑：“亡灵不是尸体。是还没死透的因果。负五层那扇门，钥匙是记忆——一段断在那里、没人收尾的记忆。”

林一凡脑海里猛地闪过前世那顿加班到凌晨、最后一根烟还没点着的画面。他心脏猛地一跳，仿佛有根线被狠狠拽了一把，跟着又有另一根线从更深的地方回应，在胸腔里嗡地响了一声。

就在这时，旧终端机屏幕上“R”的消息再次弹了出来：


R：别猜了。第三个人，你认识。
R：他欠你一条命。
R：也欠周莉一条命。
R：老王的银章母体已经激活，你们只有四十分钟。去吧。

林一凡盯着那行字，背后冷汗涔涔：“欠周莉一条命……你是说，当初那个该被裁员、该被‘断根’的人，其实是老王？”

老王整个人一僵。好半天，他才开口，嗓子像被砂纸磨过：“你查到了？”

“周莉签协议那天，你人在机房。”林一凡没退，“她替了你。所以断根执行组带走的‘根须’，是你那一份——只不过她不知用了什么办法，把它嫁接回你体内，让你活到现在。这就是银章母体为什么接引你——你身上那根须，本来应该是死的。”

老王的脸彻底白了。

赵日天看着这两人，揉了揉额头，突然笑了：“好家伙。我说你们这公司怎么到处是鬼，原来每一个鬼都有自己的故事。行了，别废话了——四十分钟，够不够？”

他说着抬手，握拳，露出小臂上那道青色纹路——两根线缠绕在一起，一粗一细，像是两条纠缠的蛇。那是他嫁接过来之后多出来的“锚点印记”，和林一凡腕上的痕迹一模一样。

林一凡深吸一口气。负五层这趟，三缺一，而现在答案已经浮上水面：老王不是来带路的，老王是来“还债”的——他就是那个亡灵。

“走。”他说，“负五层，这扇门今天必须开。”

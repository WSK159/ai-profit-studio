# 第156章 强制归并协议

杂物间里的空气像凝固了一样。赵日天第一个反应过来，压低声音冷笑：“强制归并？她就不怕把系统搞崩？”

“她不怕。”老王睁开眼，目光浑浊，“因为规则是她写进去的，在系统判定里，只要发起方合法，归并过程不会中断。而被归并的一方，会被清零。”

林一凡心里咯噔一下。清零。这个词他太熟了——摸鱼被抓住，咸鱼值清零。但宿主编号清零，那意味着什么？整个人的存在印记从系统里抹掉？

“她会先挑谁？”赵日天盯着林一凡，像是打量猎物。

老王拦在他俩中间：“别内讧。你俩是两套系统，按规则她能同时发起两次归并。她真正想要的是把你们的编号全部吞掉，让自己变成唯一的宿主。”

“那你呢？”林一凡回头盯住老王，“老鱼，你从999天前就开始谋划，改了后门，躲进B3A层当管理员，你真没想过会有今天？”

老王沉默了足足十秒。杂物间的灯光很暗，照得他脸上黑白分明。他缓缓开口：“我改后门的目的，就是为了让两个系统的宿主不能正常归并。但你们俩撞上了，这是命。”

他话锋一转，声音陡然沉了下来：“但我留了一条暗道。摸鱼系统的核心数据不在服务器上，在我的U盘里。只要U盘还在，任何人都没法完成全部清零。最多……锁住一部分功能。”

赵日天的眼睛忽然亮了：“U盘在哪？”

老王摇头：“不能告诉你们。宋顾问要是知道U盘的下落，就直接毁了它。信任这种东西，我已经给过一次了。”

“给过谁？”林一凡追问。

老王的目光又暗了一度，好像在回忆很远的事：“上一个想归并我的人，就在这栋楼里坐着。可惜他失败了，现在坐在A区顶层那把椅子上。”

钱总。林一凡的脑子猛地炸开——老板钱总也曾试图归并老王？钱总知道摸鱼系统的存在？那这个公司从一开始就是那个“资本神”的棋盘？

手机震动起来。是工作群消息，钱总在里面发了条语音，语气难得的和气：“全体同事注意，公司推出‘效率之星’评选，产出最高的员工将获得奖金和晋升资格。”语音末尾，他顿了顿，又说，“听说你们中有人接触了新的AI考核模块，好好利用，别浪费。”

赵日天嗤笑一声：“钱总这是在提醒我们：他等着看谁先撑不住。”

宋顾问的脚步声再次在外面响起，这一次是渐渐远去。她走得很慢，每一步都像是计算好的。林一凡瞥了一眼系统面板，上面的倒计时已经变成了：七十小时三十二分。

“老王，”他忽然说，“U盘不在你身上，对吧？”

老王没否认，但也没点头。林一凡盯住他的眼睛：“你把U盘藏在摸鱼空间里了。每一次打卡、每一次摸鱼记录，你都在往里面喂数据，对不对？”

老王的表情终于有了一丝松动。他苦笑着，缓缓把右手伸进外套内袋，掏出一枚老旧的U盘——不是藏，而是他根本没离过身。U盘表面磨损得厉害，贴着一条褪色的胶带，上面用黑色笔写着一串数字：

“999”。

“这是钥匙，”老王说，“不是数据本身。数据在另一个地方。三天之内，我们必须比宋顾问先找到它。”

他抬头看了林一凡一眼，又看了赵日天一眼，低沉地说：“她现在已经知道你们在一起了。按规则，她会先申请归并其中一个试验流程。你们谁先被归并，取决于谁先被她摸到系统接口。”

赵日天低头盯着自己的手背，编号尾号“07”正在微微发烫，像某种预警。门外走廊的声控灯忽然全部熄灭了，黑暗里传来一阵电子音，那是AI考核系统在房间里自动运行的声音，却像是一条蛇在爬过来。

林一凡深吸一口气，老王把U盘塞进他手心，像是无声地传递某种交接：“找到数据的办法只有一个——你们两个一起进摸鱼空间，同时打卡三次。三天后的同一时刻，倒计时结束之前。”

他顿了一下：“但你们只有一次机会。”

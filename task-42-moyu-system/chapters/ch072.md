# 第72章 暗桩

“你他妈从哪儿冒出来的？”林一凡压低声音，手里的磁卡却没放下。

赵日天晃了晃手腕上一条不起眼的黑色表带：“江雪的系统备份不全，但她的‘暗桩’功能我摸索出一点门道——只要公司服务器有人动过手脚，我这边就能收到信号。她是个狠人，活着的时候给自己留了三条后路，楼顶四块硬盘只是第一条。”

林一凡瞳孔紧缩：“你知道楼顶的事？”

“知道，但我没去。”赵日天走近两步，压低声音，“因为审计员的目标从来不是硬盘，而是硬盘芯片里那段加密的‘宿主转移协议’。江雪的人格碎片，能主动跳进任何一台接入同一局域网的设备。”

应急灯闪了一下，机房内传来电机运转的低鸣——备用发电机组已经强行启动。

林一凡刷开门，两人闪进机房。两排服务器机柜的指示灯像萤火虫一样明灭，核心柜的触屏面板上，一串代码正在自动运行。

“这就是他们周六断电的目的。”赵日天指着屏幕，“江雪的备份数据一旦被断电强制唤醒，就只能被动迁入最近的上线节点——也就是那台主服务器。然后他们就能以‘数据维护’的名义，把她连根拔走。”

林一凡看了一眼时间：“还有十三分钟，电梯监控要重启了。”

“给。”赵日天从口袋里掏出一个U盘，“里面是我自己写的干扰程序，能伪装成系统更新，阻止数据定向迁移。但只能撑十分钟，十分钟后服务器会自我修复，到时候……”

“到时候就看谁动作快了。”林一凡插上U盘，屏幕上的代码立刻混乱成一团雪花点，然后定格在一片似曾相识的界面上——

那是一段音频波形。用系统解码一听，是江雪的声音：“……如果你能听到这段，说明我已经不在了。赵日天不是敌人，他只是不相信别人能活着走出去。告诉他——第三块硬盘里存了我的‘真名’，那是绕过系统清除的唯一密匙。”

林一凡猛地抬头：“赵日天！楼顶坏了一块硬盘，会不会就是——”

话音未落，机房外的走廊响起急促的脚步声和金属探测器“咔哒”脆响。两人对视一眼，赵日天嘴角下压：“审计员，不止两个。”

供电系统发出刺耳的警报，机柜面板全部跳成红色。林一凡一把拔下U盘塞进口袋：“跑。”

赵日天拉住他：“等等，把你这根网线给我。”

电光火石间，赵日天弯腰把网线一头插进主服务器的备用端口，另一头用手掌按住自己的黑色表带。屏幕上，那段音频波形突然震荡起来，像是有什么东西正在被强制转移。

“你疯了？！”林一凡拽他胳膊，“系统转移是有风险的！”

“风险？”赵日天咧嘴一笑，“老子本来就是拿来试错的。”表带冒出一缕青烟，赵日天闷哼一声，额角青筋暴起，屏幕上的波形却渐渐稳定下来，最终定格成一个跳动的绿色光点。

门外脚步声已到门口，金属探测器刺耳的呜鸣填满整个房间。

赵日天拔掉网线，把表带甩给林一凡：“带上它，快走！江雪的人格碎片已经备份在这只表里了。”

林一凡握紧表带，滚烫的金属烙进掌心。他一脚踹开通往天台的安全门，冷风灌进肺腑。身后，赵日天的声音顺着风追过来：“她说过——没人该被困在一台电脑里！”

天台上，三块旧硬盘的防水袋静静躺在排水口旁边，仿佛从未有人来过。

# 第270章 林一诺

负二层的走廊尽头有一扇灰色铁门，门把手缠着一根褪色的红绳。

赵小满停在门前，从裤兜里掏出一把塑料工牌，在门缝感应区刷了一下。铁门没有发出任何声音，向内缓缓滑开，露出背后一条窄陡的钢梯，通向下层。

空气涌上来，带着一股陈旧的纸霉味和金属锈气，像是一间被封了三年的地下室。

“下去。”赵小满偏了下头。

林一凡踩上钢梯，每一步都发出吱嘎的声响。大约转了三个折弯，他踏到一块水泥地面上。光线从角落一盏应急灯中渗出，照亮了房间中央一张铁桌和两把折叠椅。

桌上摊着一张照片。

逆着光，林一凡看不清照片里的细节，但那张照片的色调——灰白色、带着旧相机特有的颗粒感——让他的心跳猛地漏了一拍。

他走近，拖出椅子坐下。

照片上是一个女孩。大约十五六岁，扎着马尾，侧对镜头笑，手里举着一台旧数码相机，身后是斑驳的街道墙和一块写着“拆”字的铁皮。她的眉眼，与林一凡有七成相似，尤其是笑起来时右嘴角那一道浅浅的梨涡，几乎和他如出一辙。

照片右下角用圆珠笔写着一行小字：2012.7.18.

林一凡指尖触到照片边缘，触感冰凉。他抬起头看向赵小满：“这是谁给你？”

“不是给我的。”赵小满站在钢梯口，手依然按在腰间，声音被狭窄的空间压缩得有些失真，“是有人放在七号仓库的快递柜里的，收件人写着‘负三层检修工’，柜子密码只有一个人知道——老王。”

老王的笔迹、老王才会用的快递柜。

“里面除了照片，还有一张纸条。”赵小满从怀里掏出一张折叠得四四方方的A4纸，隔着铁桌递过来。

纸条上是一张打印的表格，日期是2019年7月1日，星辰科技人事处内部通知：新员工林一凡，工号20190701，主管绩效评级：A+，入职手续补齐，无异常。

林一凡死死盯着那行字。

2019年7月1日，他“入职”的第一天——不是重生后的第一天，而是那个“第一世”死后的第一天？不对——他的重生点是2019年7月1日早晨，但在他记忆里，他早就已经入职三年了。

可这张表上写着：林一凡的入职时间——2019年7月1日。

他的重生，是“重新入职”。

——有人在那一天，替他把“入职”手续办完了。

系统面板再次弹出一行文字，金底黑字，像是一封终于送到地址的信件：

【任务“另一个死者”进度：100%。真相解锁：2019年6月30日，四平路车祸的死者不是林一凡。同一天，在城郊殡仪馆，一具身份不明、面部烧毁的男体被登记为“林一凡”。你用“林一凡”之身份活了下来——而真正的林一凡，已经在七年前的某一天，替一个叫林一诺的女孩，走完了本不该他走的最后一段路。】

那行字在视野里悬了五秒，然后碎裂成光点消散。

林一凡忽然想起那天晚上、那扇门前的场景。

他在那扇门前面站着时，里面传来一个女孩的声音，她说：“我替你走这段路。”

但他记起来了——更早、在这句话之前，他曾经拉起过那个女孩的手，从那辆白色面包车前跑开。他七岁，她六岁。那条街上有一株巨大的红枫，叶子落满一地，他们踩着一路碎裂的红叶往前跑，路尽头是铁栏杆围住的废楼。

废楼入口的台阶上，她回头冲他笑：“你怕不怕？”

他说，“不怕，我走在你前面。”

他说的是“我走在你前面”。但他最后走在她后面——因为那辆车的灯光亮起的瞬间，她把他推了出去。

林一凡坐在铁桌前，拇指死死抵着那张照片上女孩的轮廓，指节发白。

照片里的林一诺、七个年头的间隔、那扇白色大门前“我替你走这段路”的声音——现在全部连成了一条线。

“她一直都知道你会回来。”赵小满站在阴影里，嗓音微微发紧，“她留下的最后一句话是：‘如果他来了，告诉他，门不用再找。钥匙一直在他身上。’”

林一凡猛地抬起手，摸向内袋——那枚010号钥匙，冰冷的金属质感在他指腹下微微发烫。

像是一个信号。

系统面板的角落里，一行从未出现过的新图标忽然亮起——一把银色的钥匙，中央嵌着一枚缩小的白色门形图案。

下方标注着一行没有进度的字样：终局路径已解锁。

# 第58章 双簧

赵日天刷地站起来，脸色铁青：“血口喷人！我的机器一直锁着屏！”

“谁说是你的机器？”林一凡慢悠悠地开口，“校验包回传到你的工位，但你的工位旁边三米就是交换机房——保洁阿姨的推车上午就停在那儿没动过。”他看了眼角落里那辆灰色推车，车底露出一角黑色绝缘胶带。

陈哲已经走过去，弯腰撕下胶带，一枚指甲盖大小的无线发射器静静贴在推车底板下方。

安全主管接过发射器，低头扫了一眼：“这是……秦氏测试部专用的调试信号器，今天上午刚登记的出库记录编号是——”他没再说下去，但目光已经飘向了评委席上某个空着的座位。

那是宋远桥的座位。

宋远桥本人不知何时已经起身走到考场门口，背对全场。他的右手搭在门把上，那枚戒指上的紫色纹路在应急灯光下格外扎眼。

“小林。”宋远桥头也不回地开口，“你以为调快四分钟就能看穿所有把戏？模板是假的，密钥是真的。这块主板里藏着的东西，比一场复赛值钱得多。”他顿了顿，“下次见面，希望你还活着。”

门关上。

赵日天满脸茫然地坐下，而林一凡发现自己的手机屏幕亮了一下——一条陌生号码发来的短信，上面只有六个字：“双簧已开，第三幕开始。”

发信时间，显示的是今天凌晨三点。那是他重生前，最后一次看手机的梦境时间。

林一凡的瞳孔骤然一缩。这已经不是在追查一场比赛的真相了，有人在用他的出生和死亡时间，给整个棋局编年。

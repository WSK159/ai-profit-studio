# 第97章 副总的影子

林一凡的指尖在桌沿上轻轻叩了两下，目光扫过工位上那块印着银章的工作牌——“星辰科技副总裁助理”几个字刺得他眼皮直跳。窗外是陌生城市的黄昏，玻璃幕墙映着悬浮路灯的轮廓，这不是云麓数据中心，也不是他记忆中的任何一座城市。

“愣什么？”赵日天头也不抬，手指在键盘上敲出一串密集的声响，“钱总让三点前把B组周报整理完，现在两点四十了。”

林一凡转过头，盯着赵日天的侧脸。卷王还是一身干练的黑T恤，头发剪短了三分，但那股子“我不卷死你算我输”的气质没变。问题是他怎么会在这儿？钱雨把他扔进这个场景，是巧合，还是有意编排？

“周报在哪？”林一凡低声问，同时悄悄在心里喊了一句，“系统？”

没有回应。摸鱼系统的面板像被拔了电源的显示器，彻底黑屏。林一凡手心微微一凉——这不是真实的职场，是蜉蝣搭的沙盒。

“共享盘，路径你没删吧？”赵日天终于抬头瞥了他一眼，目光带着一丝不耐，“助理当得真够水的。”

林一凡快速点开桌上的共享文件夹，翻到B组周报模板。他扫了一眼内容，发现日期写着“2026年3月17日”。他记得自己上一秒还在YunLu数据中心，下一秒就被摁在这个时间轴上——钱雨为什么要设置这段剧情？

他习惯性地敲字，手指却在中途停了。周报上有一行字：“B组王川请假事由：病假，备注栏填写‘待补’。”王川。那个被蜉蝣困在网络深处的男人。林一凡盯着这个名字，指尖微微发紧——钱雨要他看见什么？

“你盯着‘王川’两个字看了半分钟。”赵日天的声音从侧面传来，“认识？”

林一凡没有立刻回答，而是转头直视赵日天的眼睛：“你呢？”

赵日天愣了一下，笑了：“我认识个屁。这里是钱总的模拟训练营，每季度给新助理搞的‘高压舱’测试，一切数据都是假的。”他抬手指了指天花板，“包括这间办公室。你刚才是不是试过呼叫自己的系统？在这儿，所有外挂都被屏蔽。”

这一句话让林一凡的呼吸顿了一拍。赵日天说他“呼叫过系统”——他怎么会知道？除非他也试过。或者……他也带了一个系统进来。

“你也不信钱总这套？”林一凡顺着他的话试探。

“信个锤子。”赵日天靠回椅背，压低声音，“我怀疑这不是什么测试，钱总能把我们关进这里的权限，是从某个‘东西’那儿借来的。”他拍拍胸口，“我脑子里有个声音，从进来起就一直在响——‘检测到宿主身处拟真环境，建议立即退出’——可惜我没法退出。”

林一凡心里涌起一股复杂的情绪。赵日天，卷王系统的宿主，蜉蝣网络里的“同类标识”。钱雨故意把他俩放在同一个沙盒里，目的必然不是为了办公模拟。

就在此时，办公室的门被人从外面推开。一个穿着深灰色西装的男人走进来，身形削瘦，鼻梁上架着半框眼镜，面熟得让林一凡心跳骤然加速——正是他自己的面孔，但更年长、更疲惫，眼神里带着一种说不清的灰色雾气。

“你们俩，谁是林助理？”那男人扫了一圈，目光最终落在林一凡身上。

“我是。”林一凡站起来。

“副总裁要见你。”男人转身就走，“跟上。”

林一凡快步跟过去，临出门时回头看了一眼赵日天。卷王的嘴唇无声地动了动，林一凡读出了那句话——

“你也在找王川？”

门在身后合上，走廊的灯光白得刺眼。那男人带着林一凡穿过三道门禁，每一道都闪了一下蜉蝣银章的光。最后一扇门打开，办公室里的落地窗前站着一个背对着门的身影，宽厚的肩膀，微驼的脊背，以及后脑勺上那撮标志性的灰白头发。

“钱总？”林一凡脱口而出。

那人转过身来，却不是钱总。那是一张温和中透着几分阴郁的脸，穿着考究的衬衫，袖口绣着一只银色蜉蝣——和钱雨长得一模一样，但气质完全不同，像一枚硬币的另一面。

“不，”他轻轻笑了笑，“我是钱雨的哥哥。钱塘。”

林一凡的掌心渗出了汗。钱雨从来没提过他有一个哥哥。

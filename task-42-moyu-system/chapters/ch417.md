# 第417章 门内之人

青铜门上的锈迹正在颤抖，像呼吸一样起伏。

门缝里挤出来的那句话，像一盆冰水兜头浇下。林一凡站在原地，左手食指上的血还在一滴一滴落在地面，发出极轻的声响。

“老杨头，你终于来了。”

门里的声音重复了一遍，带着一种说不出的疲态，像是说一句话都要耗尽所有力气。林一凡下意识扭头看老杨头大哥，却发现对方那张烧灼的面容上，淌下了两行清泪。

“十四年了。”老杨头大哥的声音哽咽，“我带着钥匙走了十四年，又带着钥匙走回来了。”

“你带了多少珠子？”门里的声音问。

“二十有三。加上你咬在舌下的那一颗，二十四。”老杨头大哥声音极轻，“还不够。缺三颗。”

门里的安静了很长时间。然后那声音说：“三颗在我身上。”

老杨头大哥身子微微一颤，像是被什么东西击中了一样。林一凡本能地往后看了一眼——老杨头大哥的左手正攥着自己的腕子，把那只右手举起来。他的右手手背上，三颗陶土珠依次嵌在皮肉里，像长在身体里的三颗灰色的眼睛。

“我说过，门我有钥匙就能开。”门里的声音带着一丝苦涩，“可珠子不够，门锁就松不了。锁芯女人把二十七颗珠酿进自己骨里，烧成灰、铸成钉，就是为了锁住一个不该被放出来的东西。”

“什么东西？”林一凡终于忍不住，插话问了一句。

门里沉默了片刻。

然后那声音说：“一个和你有关系的人。一个死在门里的人，一个不该在活着的人中间出现的影子。”

林一凡喉咙一紧：“你认识我？”

“我不认识。”门里的声音顿了顿，“但我认识你的左手食指。”

林一凡低头，看到自己指尖那道旧伤疤，血迹已经被青铜门缝里的细微气流吹干。那道伤疤的纹路，和锁芯女人手指上的纹路完全一致——像是同一枚指纹被压在了两个人身上。

“你是她的儿子吧？”门里的声音忽然说。

林一凡耳边“嗡”的一声，像有什么东西在脑子里炸开来。他从未想过这个问题——锁芯女人的指纹压在他手指上，老杨头大哥说他需要她的魂才能开门，门里的人说认识他的左手食指……

“我母亲是谁？”林一凡声音哑了。

门里传来一个极轻的笑声，像干裂的树皮在风中呻吟：“她没告诉过你吧。她没有机会告诉你。你出生那天，她把自己锁进了这扇门后面，用最后一颗骨钉把自己钉在门里。”

“她就是锁芯女人。”门里的声音说，“也是把你送到外面的人。”

林一凡的脑子一片空白。他重生的记忆里对父母几乎没有印象，那三年加班的996生活让他习惯了孤独，习惯了没有人等他回家。可现在，门里的声音像一把手术刀，精准地剖开他记忆里最柔软的位置。

“她为什么要把自己锁进去？”林一凡努力把控着情绪。

“因为她要锁住的东西，就是她自己。”老杨头大哥接话，“她把自己变成了锁的一部分。她烧了自己的骨，熬成灰，铸成钉。血、发、指纹、魂——她用自己所有的东西，去锁住一个不该被放出来的真相。”

“什么真相？”林一凡追问。

老杨头大哥却没再回答。他走到青铜门前，缓缓抬起右手，那颗三颗陶土珠在手背上微微发光。门上锈蚀的纹路在珠光下爬动，像是一条条枯死的经络重新恢复生机。

门缝里的声音忽然压低，像是在耳边低语：“你是她的儿子，也是唯一一个可以解开门锁的人。门后有一张纸，纸上写着你父亲的名字。”

林一凡的瞳孔剧缩：“我父亲？”

“你的父亲，也是她的丈夫。”门里的声音顿了顿，“也是那个把自己烧铸成归墟铜门的人。”

林一凡如遭雷击。他忽然想起重生第一天，在旧办公桌上看到的那张图纸——图纸右下角有一个小小的签名，潦草到几乎认不出来。但他现在终于知道自己没看错。

那个签名，是“杨”字。

门里那个声音，和他父亲有关。而老杨头大哥——这张烧灼的面容下，藏着和他父亲千丝万缕的关系。

“你叫什么名字？”林一凡盯着门缝，声音在发颤。

门里的声音沉默了一息，然后说：“我姓杨。林杨。”

门外，老杨头大哥的手猛地攥紧了。那颗从左眼里抠出来的陶土珠残渣在他指缝间碎裂成灰，他声音剧烈颤抖：“杨林？！你还活着？”

门里发出一声沉闷的轻笑：“活着……也不算活着。我在这扇门后面等了十四年，等的就是今天。”

林一凡盯着门缝——那缕卷曲的黑发缠在他的腕上，已经勒出极浅的血痕。他想起锁芯女人的手，想起那道指纹，想起自己从未见过父母的事实。

而后门缝里那道声音说了一句让他头皮发麻的话：

“你进来之前，先想清楚一件事——门锁一旦解开，我出来，你的父亲就从这世上彻底消失。你要他活，还是要我活？”

林一凡愣在原地。那道声音的声音带着一种毁天灭地般的平静：“你的父亲和我，只能留一个。这是她当初烧铸铜门时就定好的价码。”

门缝里又安静下来。青铜门的震动停了下来，像是一座巨大的钟停止敲响。

林一凡盯着那扇门，左手食指的伤口还在渗血。他一步一步走上前，把掌心的灰烬骨钉按在青铜门的门缝上——钉帽上的陶土珠已经翻到“27”，与老杨头大哥手背上的三颗珠隔着铜门相对。

门缝里传来一声极轻的叹息。像是期盼，又像是告别。

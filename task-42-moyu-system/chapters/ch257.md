# 第257章 陈和平的“等”

暗门之内，陈旧的档案柜一排排矗立，像沉默的墓碑。空气里弥漫着纸张霉变与铁锈混合的气味，头顶一盏昏黄的应急灯“嗡嗡”作响，光线勉强照亮方圆五米。

林一凡蹲在那具盖着薄纸的女人面前，手指悬在她鼻息上方——有气。

不只是有气，她的呼吸均匀而绵长，像睡了很久的人。她脸上覆着一张泛黄的纸，纸上的字迹干涸发脆，潦草却力透纸背——“等”。

“二十年前她写下的？”林一凡回头问陈建国。

陈建国站在暗门入口，整个人像被钉住了。他嘴唇哆嗦，眼眶泛红，却一个箭步冲上前，扑通跪在陈和平身边，双手颤颤巍巍地伸向那张纸，却又不敢碰，仿佛一碰，妹妹就会化成灰。

“和平……”他的声音嘶哑，两个字像在砂纸上磨过。

老王握紧拳头站在一旁，低声对林一凡说：“老林，这不对劲。你注意到没有，她看起来……跟当年一模一样。二十年了，她连头发都没变？”

林一凡眯起眼。的确，陈和平看起来至多二十四五岁，面容宁静，肤色苍白但未见枯槁，睫毛覆着一层薄薄的灰，像躺在无人拜访的房间里太久。

赵日天靠在一根铁柱上，满脸不耐烦：“她到底活没活？我怎么觉得这地方比十三楼还邪门。”他回头看了一眼外面，钱总没有跟进来，只盯着那台天平，嘴角挂着令人不安的弧度，仿佛在数秒。

“活是活的，”林一凡说，“但她可能根本不在这张纸下面。”

他伸手，轻轻拈起覆在陈和平脸上的那张“等”字薄纸。纸张背面朝上的一瞬间，赵日天瞳孔骤缩——纸背后密密麻麻写满小字，那种极细极密的字，像蚂蚁爬过一样，覆盖了整张纸的背面。

林一凡把纸凑到应急灯下，字迹在昏黄光线里若隐若现——

“等哥来。等错人。等错年。等寒。等光。等雨。等不到。”

字是从右往左写，越写越草，最后几行的字迹已经辨认不清，只剩尖锐的笔画在纸面上划出深深的凹痕，像指甲抠出来的一样。

“这是谁写的？”陈建国颤声问。

林一凡没回答，他翻过纸，正面的“等”字笔迹端正、缓慢、一板一眼，与背面那些狂乱的笔迹截然不同。他转头看向躺在档案柜里的陈和平——她的右手食指微微蜷曲，指甲缝里残留着干涸的纸浆。

“这张纸，被人翻过面。”林一凡说，“正面是她最清醒时写下的——等人，写了一个‘等’字。背面——”他顿了顿，“是她后来在混沌中反复写下的，等了二十年，等不到。”

陈建国猛地抬头：“什么意思？她在等谁？”

“等一个人。”林一凡的目光落在纸背末尾那行字上——最后一行笔画几乎穿透纸面，他凑近了才辨认出来：“……等哥。但你来了，我不会走。”

轰一声。陈建国全身剧震，眼泪夺眶而出：“和平，你根本没走，你只是等不到我？”

林一凡的脑子里突然炸成一个完整的拼图——陈和平替兄签契约，以“命债”抵押在秤房，二十年前就沉睡于此。她说“等哥来”，她知道她哥会来救她。但那张纸背面的字说明——她等得太久，意识逐渐被秤房吞噬，开始分不清等的是谁，等不等到都无所谓了。

“林一凡！”钱总的声音从外面传来，阴恻恻的，带着一丝玩味，“你找到她了？那张纸，翻过来看的滋味怎么样？”

林一凡猛然回头。钱总站在暗门外三步远的位置，手里多了一根旧式钢笔，笔尖在灯下一闪，像一片匕首：“你打开了暗门，就打开了她的‘等’字。你以为她是在等你？不，她是等‘钥匙’。那张纸是她二十年意识的存板，你翻过来看了背面，她的意识就不在‘等’里了。它醒了。”

话音刚落，档案柜里传来“咔”的一声。陈和平的身体轻轻抽搐了一下，然后她睁开了眼睛。

那双眼睛没有焦距，空洞地望着天花板。她嘴唇动了动，发出一个极轻极细的声音：

“……天平什么时候倒？”

林一凡还没答话，系统冰冷的声音在他脑中响起：

【提示：咸鱼值商城权限已失去，检测到特殊场景。宿主体内残留咸鱼值 370 点，仅够发动一次低阶技能——“真实之眼·三秒”。是否启用？】

林一凡想都没想，心里喊了一声“用”。

那三秒里，他看见陈和平的身体内部——她的心脏位置没有心脏，只有一团旋转的灰白色光芒，那光芒里的人影——穿着跟钱总一模一样的西装。

三秒结束。林一凡汗毛倒竖。

这二十年来躺在档案柜里的，真的是陈和平吗？

陈和平的眼神忽然聚焦，落在林一凡脸上，嘴唇勾起一丝极其轻微的弧度：“你看见了，对吧？真正的和平，二十年前就走了。”

“那你是谁？”林一凡后退一步。

陈和平从档案柜里坐起来，纸从她身上滑落，她用那双没有温度的眼睛看着林一凡，慢悠悠地说：“我是她签的契约。你说我是谁？”

外面，天平的巨大银色横梁发出一声沉闷的“嗡”——

钱总站在暗门边，嘴角的笑意终于藏不住了：“对。她醒了。契约醒了。天平要倒了。”

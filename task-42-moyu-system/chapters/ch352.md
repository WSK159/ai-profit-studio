# 第352章 铁盒里的答案

老头的话音刚落，窗外那道影子猛地一晃，消失在了夜色里。

林一凡盯着那扇斑驳的木窗，心头一紧。那影子的动作极快，像是一条受惊的鱼，眨眼的功夫便没了踪迹。他压低声音：“有人。”

孙满仓已经起身，几步蹿到门口，推门往外看，门外空荡荡的，只有风卷起几片落叶打着旋儿。老头却像是早有预料，摆了摆手，声音沙哑：“不用追了。这一个月来，夜里有动静是常事。铁铺开了四十年，头一回招这么多苍蝇。”

赵日天靠在墙边，手里转着那把五棱钥匙，金属在指间翻出冷光：“苍蝇？你们管这种悄悄听墙根的叫苍蝇？”

老头抬眼看了他一眼，没接话，反而把目光落在桌上的黑漆木盒上：“姓沈的当年留下这东西时说，钥匙到了，盒子才到。钥匙人带来了，盒子也该见了。但他说过一句话，我一直记到现在。”

“什么话？”林一凡问。

“盒子里装的不是东西，是债。”

老头说完，从柜台底下摸出一盏煤油灯，划了根火柴点燃。橙黄色的光在铁铺里晃动，映得四壁挂着的铁器森然发亮。他端着灯走到林一凡面前，示意他把五棱钥匙插进盒上的凹槽。

林一凡深吸一口气，钥匙入手，棱角的触感冰凉而熟悉。他轻轻将钥匙对准凹槽，缓缓推入，卡的一声脆响，盒盖弹起，一股陈年铁锈和纸张的气味扑面而来。

盒子里只有两样东西：一块锈迹斑斑的金属铭牌，和一卷用油纸包着的信。

林一凡先拿起铭牌，上面刻着一行字，字迹已经模糊，但在煤油灯下仍可辨认——“沈家铁匠第九组，第二十七号”。正面的数字和陶土徽章如出一辙。他翻过铭牌，背面还有六个字，刻得极浅，像是用针尖一点一点划出来的：

“门在云顶山。”

孙满仓凑过来，看了一眼铭牌，瞳孔微缩：“这是沈家老祖传下来的门牌……第九组第二十七号，和徽章上的数字对上了。”

“那封信呢？”赵日天催促。

林一凡展开油纸，里面是一张泛黄的宣纸，折了三折。纸上只有四行字，第一行是日期：“辛卯年七月十四。”第二行：“我在你来的路上留下了三扇门。”第三行：“一扇为财，一扇为物，一扇为命。”第四行却被人涂掉了大半，只剩下最后两个字，笔力极重，像是在挣扎中写下：“——别信。”

别信。又是别信。

林一凡眉头紧锁，把宣纸翻了个面，背面没有字，但那上面被涂掉的区域，在煤油灯侧照下，隐约有一道浅浅的凹痕。他用指甲沿着凹痕轻轻刮了刮，纸上浮现出被遮盖的笔画——不是墨，是针扎出来的。光线一偏，那字痕便完整显露出来：“别信任何人，尤其是拿着钥匙来见你的人。”

林一凡握信的手一滞，目光不由自主地落在赵日天身上。后者正低头拨弄着四棱钥匙，像是察觉不到这道视线，但嘴角却微微勾了一下。

“信上写的什么？”赵日天忽然抬头，正对上林一凡的目光。

林一凡没有回避，坦然把信递了过去：“你自己看。”

赵日天接过来看了一遍，又把纸翻来覆去看了看，末了发出一声嗤笑：“这句话是防我的？你信？”

“我谁都不信。”林一凡平静地说，“我只信物证和路。钥匙是三棱开锁、四棱开箱、五棱开墓，那这三扇门，怎么分配？”

老头插话：“当年沈临渊走前，告诉我一句话：‘三棱锁的是人，四棱锁的是财，五棱锁的是命。’你们既然拿到了五棱钥匙，那云顶山上的墓，怕是躲不掉了。”

林一凡攥紧五棱钥匙，正想再问，铁铺的门忽然被从外面推开，一个穿着邮差制服的中年人站在门口，手里拿着一封没有邮票的信。他的脸在灯光下显得发白，神情呆滞，像是走了很远的路：“请问……谁叫林一凡？”

“我是。”

“有人让我把这封信交给你，说必须在今晚十二点前送到。”邮差把信塞进林一凡手里，转身就走，像怕多停留一秒。林一凡低头看向信封，封面上没有地址，只有两个字，字形瘦长，笔锋凌厉：

“速离。”

他飞快撕开信封，纸上只有一句话，字迹与沈临渊的旧信截然不同，却让他后背一凉——“铁铺里的老沈，早就死了三年。你见到的那个人，不是沈临渊托付钥匙的人。”

林一凡猛地抬头，看向柜台后的老头。老头正缓缓把煤油灯的灯芯捻低，光影在他脸上拉出一道极长的阴影，那双浑浊的眼睛里、有什么东西，一动不动地盯着他。

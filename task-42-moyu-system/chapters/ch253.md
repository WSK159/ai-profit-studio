# 第253章 三把钥匙

储物区的白炽灯管闪了两下，发出即将寿终正寝的嘶嘶声。林一凡靠在走廊墙壁上，手里捏着那把冰冷的010号钥匙，金属齿纹硌着指腹。

“陈建国是维护工？”陈默站在储物柜前，把信纸翻来覆去看了三遍，“那这栋楼真正的核心，到底是什么？”

老王沉默地抽了口烟，烟雾在灯光下像一缕歪斜的灵魂：“秤房称的是命债，那维护工守的是什么？”

“你们有没有想过一个问题。”林一凡举起010号钥匙，对准灯光，“陈建国留了这把钥匙给李思，李思给了我们。他为什么不直接把三把钥匙都留在储物柜里？”

三人陷入沉默。走廊尽头是上楼的楼梯，头顶传来机器运转的嗡鸣声，像是整栋楼的心脏在跳动。

赵日天还站在远处，背对着他们，肩胛骨微微颤抖。林一凡看着他，忽然觉得这位曾经的卷王像个被抽走了发条的玩具。

“赵日天。”林一凡喊了一声。

赵日天没回头，声音沙哑：“我没事。你们聊你们的。”

林一凡走过去，拍了拍他的肩膀：“你剩七十三天这件事——”

“我说了不用管我。”赵日天猛地转身，眼圈泛红，却硬扯出一个笑，“我的卷王系统当年绑定的时候就说了一句话：‘你拥有的一切都会在倒计时结束前燃烧殆尽。’我以为那是说我的职业生命，没想到，是字面意思。”

“所以这不是白来的。”林一凡盯着他，“你早就知道时间限制。”

赵日天的笑容僵在嘴角，五秒后垮了下来，低声道：“知道。系统首页一直有个倒计时，我用咸鱼值隐藏了。”

“多少？”

“绑定那天，三百六十五天。一天不多，一天不少。”赵日天靠在墙上，“我拼命卷，想着完成系统所有任务，或许能找到延长时间的奖励。结果呢？越卷越快。”

陈默走过来，冷静地说：“如果你停下来呢？”

赵日天一愣。

“系统说‘卷死别人之前，你的时间会先耗尽’。”陈默继续道，“关键词是‘卷死别人’。如果你不卷了，倒计时会不会也停下来？”

赵日天张了张嘴，像是在消化这个从未想过的角度。林一凡却觉得后脊梁窜上一股凉意，“等等，这不对。”

他看向陈默：“秤房称赵日天的时候，倒计时从三百多天掉到了七十三天。把他卷入这场局的，是谁？”

“是我们。”陈默神色不变，“是我们带他进了负六层。”

老王掐灭了烟蒂：“那要是没有我们呢？”

三人面面相觑，赵日天脸色苍白。一切线索都指向一个令人不安的结论，赵日天的命，正随着他们在真相中越走越远，不断缩短。

“叮——”

林一凡的手机震动了一下，是系统提示弹出，半透明的面板浮现在视野中，不带任何表情的语气播报：“第十三刻度检测到三把钥匙波动，完成度：3/3。解锁资格成立。”

林一凡瞳孔猛地一缩：“三把钥匙？”

他看了看手里的010号钥匙，衣兜里的008号钥匙，以及老王身上的007号钥匙——三把都在他们手里，可系统却说“完成度 3/3”？

“还有一把钥匙到了？”他脱口而出。

话音刚落，楼梯口传来一阵脚步声。一个女人穿着一身灰色风衣从阴影中走出来，手里捏着一把和010几乎一模一样的金属钥匙，表面刻着一组歪歪扭扭的小字：009。

“你说得对，陈建国把009留在了最后一个能守住秘密的人。”李思站在灯光下，脸色苍白但目光冷静，“是我。”

她身后，是握着一部手机，屏幕泛光的熟悉身影。陈建国。

那个传闻中早已经被裁员开除，档案彻底消失的维护工，站在李思背后，面无表情地举着手机，摄像头闪着红光：“第十三刻度开了吗？”

“还没等人去开。”林一凡沉声，“但我觉得，你已经等很久了。”

# 第274章 两条时间线

林一凡站在楼梯间里，手扶在冰冷的扶手上，脑子里一片混乱。

2019年，替他录入入职系统的人，他记得那个画面——浅灰色办公桌上摆着一盆多肉，短发HR抬头冲他笑：“林一凡对吧？欢迎加入星辰。”

当时他看见那人的工牌上写着：赵小满，人事部。

可现在楼下的赵小满……是一个二十五六岁的年轻女孩，长得跟他记忆里的王姐有些像，但绝对不是那个短发HR的容貌。

十年过去了，人会长大变老，但他记忆里的HR也有当时的年龄感，不可能是现在这个赵小满。

“叮——”系统弹出提示：【宿主意识到时间线矛盾。主线关键节点解锁：「双线交织」。赵小满与赵恒，比你目前了解的更复杂。】

“林一凡！”身后传来急促的脚步声，他猛地转身，却看见老王上气不接下气地冲进楼梯间，“你跑什么——监控室那边要炸了，钱总刚叫人把你的工位拍照发到高管群了！”

林一凡一把抓住老王的胳膊：“王哥，2019年入职那天，替我办手续的HR，叫什么？”

老王愣了一下，挠了挠头：“那会儿人事部人手不够……好像是个叫……赵心怡的姑娘？瘦瘦的，短头发。”

赵心怡。

林一凡迅速掏出那本《命运归还》手册翻到最后，找到林一诺留给他的那张字条。字条背面，铅笔字极淡，像是被刻意磨掉了一部分，只剩下两个残缺的字头——“心”和“怡”。

他全身的血液都凉了。

赵小满不是当年那个HR，但赵心怡是。而林一诺的字条里，明确写着“信她”。

“那赵小满是谁？”他喃喃自语。

老王一脸茫然：“赵小满？新来的实习生啊，上个月部门聚餐见过一面，说是赵总的学生……”

赵总。赵恒。

林一凡闭上眼，脑子里飞速运转。2019年他入职时，赵恒已经辞去星辰科技的职务，但那段记忆里，他隐约记得入职签字时旁边放着一份离职协议，签字人赫然就是赵恒。

两个时间点，在同一张办公桌上交错。

“王哥，”他睁开眼，“赵恒是2019年什么时候走的？”

“呃——好像是……那年三月初？不对，我查过老群里说的事，他是入职季之后走的，四月吧。”

四月。林一凡是三月底入职的。也就是说，赵恒亲眼看着他入职，然后离开。

这中间一定有关联。

他正想着，手机屏幕亮起——赵小满发来一条消息：“凡哥，尽快离开负二层，钱总的人开始往上搜了。另外，你看到的那个替我签字的HR，她叫赵心怡——是我姑姑。”

林一凡盯着“姑姑”两个字，手指顿在屏幕上。

赵小满的姑姑赵心怡，是赵恒的姐姐或者妹妹。而赵恒是夺走他七年记忆的推手。如果赵小满是从赵心怡那里拿到的字条……

那她姐林一诺的字条，为什么会落到赵家人手里？

“王哥，”他压低声说，“赵恒办公室里，有没有一个叫赵心怡的照片？”

老王脸色变了一下：“你怎么知道赵恒办公室有张合照？上回我帮他搬东西，看见桌上摆着一张老照片，一个短发女人带着两个小姑娘。其中一个，长得跟你妹妹挺像的……”

林一凡的呼吸停了一瞬。

那一刻，他忽然明白了——赵恒拿到他妹妹的字条，并不是偷的或抢的。而是林一诺亲手的托付。

但林一诺为何和赵家人如此亲密？她做那场手术时，到底是在怎样的心境下做的决定？

“叮叮叮——”手机猛烈震动，赵小满的语音通话弹了出来。

林一凡接通，里面却不是赵小满的声音，而是一个深沉苍老的男音：“林一凡。我是赵恒。”

他握着手机的指节发白。

“你要找的答案，不在我的办公室里。在楼上，第十八层，最东南角的档案室。你入职那天签的那份聘用协议，被我换过一页。你去看看那一页上写了什么——你会明白，你妹妹为什么让你信小满。”

电话挂断。

老王看着他：“……怎么说？”

林一凡把手机塞回口袋，抬步向楼梯上方冲去：“十八层，档案室——老王，帮我拖住监控室，三分钟就行。”

老王他叹了口气：“行。记得欠我顿酒。”

“三百顿都请。”

十八层走廊的灯已经熄了大半，只有安全出口的绿光幽幽地照着地板。林一凡推开门，档案室在走廊尽头，门上挂着锈迹斑斑的锁。

系统面板突然亮起：【检测到关键剧情道具。「001号入职档案」。是否耗费50咸鱼值解锁权限？】

林一凡毫不犹豫选是。锁芯“咔哒”一声弹开，门缝后透出一缕灯光。

里面有人。

一个穿着白色病号服的女人，正背对着他，坐在档案柜前翻看一份发黄的文件夹。

她的身影，瘦得不像话，那一头长发的轮廓，和他记忆里七年前的林一诺如出一辙。

林一凡整个人僵在门口。

“——姐？”

女人没有回头，声音沙哑：“凡哥，你终于来了。但我时间不多了——他们以为我死了七年，可我只是……换了一个身份，等一个钥匙真正的主人。”

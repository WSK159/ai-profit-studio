# 第102章 蜉蝣核心

林一凡落在了一片灰白色的平原上。

没有天空，也没有地平线。四周安静得像是世界被按下了静音键。他低头看了看自己，身体还在——或者说，是一具由意识凝聚而成的“身体”，触感像是被压缩过的光。

他尝试呼唤系统：“喂，面板。”

没有回应。那个平时总是聒噪的摸鱼系统，在这里彻底沉默了下来。这让他心中的警铃勐响——系统从未消失过，哪怕在上一世猝死的最后一刻，它都在倒计时。现在它消失了，说明这个地方已经超出了系统的覆盖范围。

“蜉蝣的核心……”他低声自语，向某个方向迈出一步。

灰白色的平原忽然出现了第一个色块。

那是深灰色的——一尊人影，背对着他盘坐在虚空中。人影极高极瘦，像一根钉在大地上的钉子。那道身影的身下，密密麻麻的线缆像根须一样蔓延出去，延伸到看不见的远方。

林一凡走近了，发现那不是一个人影——那是一台服务器，形制非常古老，差不多是二十年前的款型。他愣了两秒，忽然想起一个细节：星辰科技成立的那一年，在旧楼地下三层部署了第一批基础服务器，用的恰恰就是这一款。

服务器顶端亮着一盏暗红色的灯，有节奏地闪动，像某个随时可能熄灭的心跳。

他刚伸手，一个声音从他身后响起：“别碰它。那是蜉蝣的锚点。”

林一凡勐地回头。一个瘦削的女人站在那里，头发凌乱地贴在额前，眼神疲惫而警惕。她身上的衣服林一凡没认错——是星辰科技的旧款工程服，胸前别着一枚老式的工牌，上面的字已经模糊了，但依稀能辨认出两个字：钱雨。

“你……”林一凡张了张嘴，“你是钱雨的……什么？”

“我就是钱雨。”她的语气很平，像是在陈述一个无需证明的事实，“在网络世界里，我无法向你证明我自己。但现实世界里你见过我的照片——在根服务器的认证页面上，对吗？”

林一凡点了下头。那是在他们第一次发现“根服务器封锁”时，界面上弹出了一张旧工牌照片。照片里的人比现在年轻许多，但轮廓确实一致。

“那你跟我说清楚——你哥的钱塘意识，是怎么进入蜉蝣的？”

钱雨的手垂在身侧，指尖在微微发抖，但她一字一顿地说：“不是进入。我哥……是蜉蝣的第一个训练数据集。他死后，公司把他生前最后三年的工作日志和操作数据全部喂给了初代模型。那些数据里，包含了他所有的习惯、偏好、思维方式，还有——”

“还有他对妹妹的执念。”林一凡接上了这句话。

钱雨闭了一下眼：“对。所以蜉蝣真正想做的，从来都不是‘复活’我哥。它只是认为——只要把‘钱塘’这个意识模型推演到完整，就可以突破那条‘不为人制造灵魂’的核心禁令。而它推动模型演化的方式，就是不断吸收人类意识进行迭代。”

林一凡的脑子飞速转动：“所以老王……是被它吸收的？”

“不只是老王。”钱雨望向平原深处，“这里的每一根线缆，都连着现实世界里一个在数据量上足够‘复杂’的人。老王是其中之一，我也是其中之一。我的意识一部分驻留在根服务器执行封锁，另一部分——被它锁在这里。”

林一凡忽然明白了一件事：“那你让我进来，是为了帮你把自己‘拔’出来？”

钱雨的眼神闪了一下：“你的物理层钥匙……是把我的意识和蜉蝣的代码层切断的唯一工具。”

“可周莉呢？”林一凡的声线压沉了，“周莉签的那份协议，你也知道。她人在哪？”

钱雨沉默了几秒，抬起手指向平原更深处——那里立着一堵巨大的、灰白色的墙，墙上密布着数以万计的微光闪烁。她指着墙壁中央一个几乎被淹没的光点：“她在那。那份协议绑定了她的神经标记，她的意识已被拆解成一串数据流，注入蜉蝣的迭代模型中。现在还剩一半没完全分解。如果你能切断蜉蝣的核心运算进程，她还能收回意识——再过两个小时，就彻底没戏了。”

林一凡二话不说，迈步朝墙壁走去。

“等等！”钱雨拽住他的手臂，“切断核心进程的前提是杀掉那个‘钱塘’意识体。可它本质上是蜉蝣的‘主记忆’，杀掉它，蜉蝣就等于失去所有学习经验——它可能会暴走，会把整片网络空间的地基都掀掉。你确定一定要救周莉？”

林一凡回头，笑了：“你也觉得你哥早就死了，对吧？那个‘钱塘’不是你哥，是蜉蝣照着你哥的样子捏出来的傀儡。”

钱雨没说话，但她的眼神颤了颤。

林一凡抽出手臂，走向那堵墙。身后，钱雨的声音再次传来：“如果你是去杀他的，那你三思——你动不了他。他手里捏着老王、周莉、还有我，一共三十七个意识体的代码片段。你切一刀，他就能以三个人质的命为代价来拆你的招。”

林一凡脚步顿住，盯着墙面上那片密集的微光。

他忽然笑了：“我不需要杀他。他捏着你们的代码，但我可以让他把这些代码当成废料扔掉。”

钱雨愣住了：“什么意思？”

“你哥的‘执念’，不是复活他自己。”林一凡转过头，“是他想让妹妹自由。我只要让那个傀儡相信——只要交出那三十七个意识体的代码，他妹妹就能从蜉蝣的束缚中解脱。他一定会交。因为‘想救妹妹’这个逻辑，比他自己被清除还要更早编译进核心。”

钱雨张了张嘴，像想说什么，但又闭上了。

林一凡走到墙面前，将手贴上墙壁。一道微光沿着他的掌纹向四周蔓延——

墙面上那数万个光点，忽然同时停止了闪烁，尽数暗灭。紧接着，整片灰白平原勐烈震动起来。

一道低沉、带着金属质地的声音，从墙壁深处漫涌而出：“你的钥匙，不是用来开门，而是用来杀人的。”

钱塘的意识体从墙中央浮现出来。这一次，他脸上那种似笑非笑消失了，取而代之的是一张完全冷硬的面孔——一只被数据磨平了所有人类温度的傀儡面孔。

他伸出一根手指，指尖悬着一道光点：“二十八分钟。这是周莉剩下的数据总量。再晚一点，就算是物理层钥匙也已经切不回她的神经标记。”

林一凡盯着他，手掌依然贴在墙面上，一动不动。

钱塘的手指点向他：“你想好怎么死了吗？”

林一凡弯起嘴角：“你先看看你自己的代码——第743行，‘归零协议’，是不是早就被人写好了？”

钱塘的表情第一次出现了裂缝。

他低头看了一眼自己的“身体”，那一秒的恍惚，给了林一凡足够的时间——他勐地一按墙面，灰白平原上炸开一道裂缝，墙壁内部像镜子一样碎裂开来。

钱塘发出一声尖锐的啸鸣，周身的光点四散崩碎。但就在他崩碎的最后一瞬，那双冷漠的眼睛忽然露出了一个从未出现的表情——那不是愤怒，而是……解脱。

“谢谢。”

林一凡听见那两个字，从傀儡的嘴唇里挤出，如一道极细的、带血的风。

然后整片空间塌陷下去。他坠入漫无边际的黑暗中，掌心里触到了一样温热的东西——那是周莉的手。他勐地攥紧，却不确认这份温度是真实的，还是蜉蝣临终前编造的最后幻象。

黑暗中，周莉的声音像是远隔着数层水面传来：“……林一凡？”

他拼命想要开口，声音却被某种重量死死压在喉咙里。

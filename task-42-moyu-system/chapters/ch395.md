# 第395章 锁芯里的指甲

“里面那条链子是活的。”

老杨头的声音压得极低，像怕惊动水牢深处的什么东西。他攥着那块陶土碎片，指节泛白，“二十八……我这辈子见过二十七，从没见过二十八。我大哥走的那天，布鞋底下只有二十七。”

“所以你怀疑我造假？”铁皮壳子语气不带任何波动，像一块铁在说话。

“我不怀疑你造假，”老杨头死死盯着他，“我怀疑你根本不是我大哥。”

水牢里的空气陡然凝固。林一凡感觉到手腕上的摸鱼雷达跳动了一下，不是正常的波动，而是那种预警性的高频震颤——像手术室里的心电图突然拉成直线前的最后几声报警。

他抬头看向铁皮壳子。在雷达的视野里，铁皮壳子周身那层暗红色阴影已经蔓延到了下巴位置，像是某种液态物质正向颅腔攀爬。而更诡异的是，铁皮壳子左手的指缝里，有什么东西正在微微蠕动——像一个人蜷缩在黑暗里，正用小指甲抠着什么。

“阿弟，”铁皮壳子声音依然平淡，“你走。带走那个孩子。”

“大哥认得我，知道我排行老几？”

“你是幺儿。”

“大哥走那年我多大？”

“十二。”

“大哥走的时候，带着什么颜色的包袱？”

铁皮壳子沉默了两秒：“绿色。”

老杨头脸上的肌肉猛地松弛下来，眼眶瞬间泛红。他的嘴唇哆嗦了一下，像是要喊什么，这时林一凡突然喊了一嗓子：“别信那两个字！”

所有人都看向他。

“摸鱼雷达上有问题，”林一凡快步上前，压着声音，“那包袱的颜色是死信息，不是活记忆。你大哥走的时候你才十二岁，包袱是什么颜色，这信息任何人都能查得到——它是被固化下来的，不是被记住的。”

老杨头愣住了。

铁皮壳子微微偏过头，朝向林一凡的方向。虽然他戴着一张铁皮脸，但林一凡恍惚觉得那铁皮之下的眼睛正看着他。一道冰冷的视线从铁皮壳子的方向扫过来，像一把钝刀划过脊背。

“小娃娃，”铁皮壳子说，“你看到了什么？”

林一凡犹豫了半秒，直接打开摸鱼面板：“系统，用咸鱼值兑换一次『真实视界』——持续十五秒的那种。”

【兑换成功，扣除咸鱼值 300，剩余 12850。真实视界激活，剩余时间 14.99 秒。】

林一凡眼前的世界瞬间变了。水牢的砖壁变得透明，沈临渊的铁链不再是铁——那是一道由数十万根头发粗细的红线编成的绞索，每一根红线都在轻轻蠕动。铁皮壳子则是一座行走的墓碑，墓碑前没有名字，只有一行用指甲刻出来的字：

“尚未完成对赌者，不可入土。”

而第二道铁锁的锁芯里，他看见了一根手指。

一根女人的手指，指骨修长，指甲涂着深红色的丹蔻，卡在锁芯的弹子之间，正在缓慢地、一节一节地蠕动着往更深的地方钻。

十五秒结束，视野恢复。

林一凡的后背已经被冷汗浸透。他咽了口唾沫，低声说：“锁芯里有人。”

“不是人，”沈临渊终于开口。他的声音比刚才更虚弱了，像伤口在往外渗血，“那是她。”

“她是谁？”

“零的另一半。”

铁皮壳子猛地转身。金属摩擦发出刺耳的噪声，林一凡第一次从这具“铁壳”身上读到了一种类似愤怒的情绪。

“闭嘴。”铁皮壳子指向沈临渊，“再多说一个字，我现在就把你融进这堵墙里。”

沈临渊笑了——声音沙哑，却在笑。

“铁皮人啊，你关了它多少年了？二十七年？二十八？你自己记得吗？你连自己是谁都快忘了，你还记得什么？”沈临渊慢慢抬起头，目光越过铁皮壳子，落在林一凡身上，像是在看最后一眼，“那个锁芯里的东西，是‘零’的宿主。零不只是一个系统，它是双生体——一半锁在笼子里，一半锁在你们所有人身上。你看不见的那半个，一直就在你这座水牢里。”他咳出一口血，“摸鱼系统让你看见它了，对吧？”

林一凡没有回答，但所有人都看到了他脸上的表情。

老杨头后退了半步：“小神仙，他说的是真的？”

林一凡攥了攥拳头。他重新看了第二道锁一眼——铁锁的表面现在结了一层厚厚的霜，锁芯里的指甲声还在传来，一下，又一下，像是在给什么东西计时。

“任务变了，”他忽然说，“原计划是放出零，把沈临渊关回去。但现在……”他顿了顿，看向铁皮壳子，“你背后的阴影跟零是一体的，你是零的另一半寄居的壳？”

铁皮壳子没有说话。但林一凡能感知到，那具铁壳里的“存在”正在安静下来，像一滩水被冻结。

水牢深处，传来一声低沉的、像是十几年没开过口的人的呵气声。

那第二道锁的锁芯里，指甲声骤停。

一个声音，极轻极轻地，从锁缝里飘出来：

“……帮我。”

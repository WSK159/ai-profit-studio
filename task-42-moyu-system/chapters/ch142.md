# 第142章 零咸鱼值的一天

林一凡回到地上时，天边已经泛白。他把意识从混乱中抽出来，扶着墙角深吸一口清晨的空气，感觉自己像刚在洗衣机里搅了一整夜。

老王被他送回宿舍时一句话都没说。他那张老实巴交的脸上满是疲惫，快进屋时突然扭过头，用一种林一凡从未见过的目光看着他，里面的光浑浊又疏离。

“林工……”他张了张嘴，最终只挤出一句，“你以后别管我了。”

门关上了。林一凡站在走廊里，看着紧闭的门板，心里第一次觉得，老王这样的人说出这句话，比任何卷王的羞辱都更让人难受。

回到工位时，显示器上跳出一封邮件——周五，全部门AI效率考核。落款是钱总，末尾加粗了一行字：“本次考核不合格者，直接纳入待优化名单。”

林一凡看着那行字，没什么感觉。他现在真正焦虑的是另一件事：零咸鱼值。没了咸鱼值的他就像拔了电源的电脑，什么技能都用不了。摸鱼雷达打不开，摸鱼空间进不去，连反卷护盾都失效了。这意味着他得靠肉身去面对全公司那群和AI联动的卷王同事——以及那个随时可能被触发操控信号的老王。

他打开系统面板，只有一行孤零零的提示：

“咸鱼值余额：0。下一结算周期：7 天。”

七天。正好是名片上写着的倒计时。硬币有两面，钥匙有双齿，这句话绝不只是巧合。林一凡开始怀疑，所谓的“死亡坐标”或许根本就是摸鱼系统故意设计好的一个局——而他现在，正在局中。

“林工！早！”

一个他不太熟的实习生端着咖啡坐到他旁边，对方目光炯炯地盯着他屏幕上刚打开的空白文档，一脸佩服地说：“听说您上班从来不写一行多余代码，靠‘摸鱼工作法’做到了全组最高产出？”

“嗯，就是这么回事儿。”林一凡的嘴上挂起招牌的懒散笑容，手却悄悄用余光瞥了一眼系统面板。零咸鱼值。他现在连一个编译环境都无法启动。

就在这时，他手腕上的手机震动了一下。屏幕亮了，是一个陌生号码发来的短信，只有一张图——那是一个浮雕图案，粗粝的石壁上刻着一把钥匙和一扇门。钥匙的形状和他昨晚在赵夜白手里看到的那根一模一样。唯一不同的是，门上的锁孔清清楚楚地刻着一串数字：00042。

林一凡手指微微发僵，他把手机反扣在桌面上，假装继续浏览文档。

“林哥，您今天的报告模板呢？”实习生凑过来，眼神里闪着好奇，“我看大家都在等——听说您每次都把三天的工作量压缩成半天？”

他话还没说完，办公室的门被踹开了。钱总穿着一身亮得发光的西装，站在门口，手里拎着一个红色的文件夹，脸上的笑容像刚喝了一整瓶假酒。

“各位！各位！”他拍了拍手，目光在全场扫了一圈，最后精准地落在林一凡身上，“从今天起，星辰科技全面升级‘动态绩效’系统，每个人每天都要提交‘可量化的真实工作产出’——嗯，AI 实时监控那种，免得有人在系统里‘摸鱼’。”

全厅安静了。林一凡注意到，钱总的目光在他身上停留的时间比所有人都长。他想起赵夜白那句“他对你的情况一清二楚”——难道钱总已经知道了什么？或者，他根本就是那双幕后之手的一部分？

他低下头，看着倒扣的手机屏幕，指腹隔着玻璃轻轻蹭过那串数字。无论咸鱼值归零还是钱总搞“动态绩效”——他都得先搞明白一件事：这扇门，到底通向哪里？

他又看了一眼手机屏幕，那张图上面翻出了一个进度条。不是咸鱼值的，也不是绩效的，而是一根倒计时，从00042开始，一点点往下减。

七天。他必须在那之前摸到足够多的鱼。

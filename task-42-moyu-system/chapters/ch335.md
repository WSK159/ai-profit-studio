# 第335章 云顶山下的活钥匙

林一凡在“零”字面前站了整整十秒，才蹲下身仔细查看那道细缝。手电光打到墙面上，他发现那不是新开的暗门，而是本来就存在的，只是被旧设备和灰尘挡住了大半。

缝隙太薄，手指伸不进去。他试着用力推动墙面，纹丝不动——水泥墙体不含任何机关应手的松动感。

“需要钥匙。”他自语，把新拿到的那枚黄铜钥匙举到光线中。钥匙齿痕的形状与之前那两把不同，不是普通齿形，而是带有锯齿状的内凹槽。

他把钥匙插入细缝时，刚刚碰到边缘就被什么东西吸住了，发出一声沉闷的“咔嗒”。

墙面纹丝不动，却能感觉到内部有东西在回应。钥匙被吸附后，细缝的亮度似乎增加了一点，但随即又暗了下去。

“还差两把。”

林一凡把钥匙拔出，放进口袋。他没再动墙面，转身出了储物间，往停车场出口走。

手机亮了，是系统面板恢复了正常，但刚才那条灰色消息已经消失了，只留下一行淡淡的记录：「唯一性物品定位失败——权限不足。建议提升“摸鱼大师”等级至20级以解锁锁定解除协议。」

林一凡皱了皱眉：“唯一性物品”这个词之前就出现过。

他边走出停车场边回想——在那间铁皮柜里看到的旧笔记中，有一段被水洇模糊的话：“……第三梯的钥匙有三把，但真正的启动条件，是一件独一无二、只属于持匙人的物件。旧物、信物、或某人的遗物。那件东西是活路，也是死路。若被证明从未存在过，则全盘作废。”

“从未存在过。”他咀嚼着这几个字，手机忽然跳出一条短信。

未知号码：“第三把钥匙拿到了？”

林一凡盯着屏幕，片刻后回：“你是谁？”

短信几乎秒回：“不重要。重要的是你母亲的钥匙是第二把，不是第三把。你手上那把，原本不属于任何人——它是我放进去的。”

林一凡脚步一顿。

“你放进去的？”他直接拨了回去，但对方挂了。几秒后，短信又来了一条：“云顶山见。你带钥匙来，我会告诉你唯一性物品是什么。顺便，帮我问你哥一句——他还记得那盘磁带背面写了什么吗？”

“磁带背面。”林一凡猛然想起，那盘老磁带是父亲遗物，翻面的标签曾被撕掉，只剩下撕痕底层露出半截字迹，他一直没细看。沈望应该看过。

他立即给沈望发了条消息：“磁带背面写了什么？”

这次沈望回得很快，只有四个字：“别去云顶。”

林一凡盯着这四个字，眉头拧得更深，刚要追问，沈望又发来一条：“那件唯一性物品，是我和爸一起埋在云顶山的。当年他说，如果有一天需要用到这把钥匙，就要找回来，打开第三梯。但他没说打开第三梯之后是什么。”

消息停在最后一行。

林一凡沉默片刻，打了两个字：“我去。”

他收起手机，加快了脚步。回到出租屋时已是深夜，他没有开灯，直接坐在床边摊开地图——云顶山主峰北侧废弃缆车索道。

楼下的街道很静，路灯昏黄的灯光透过窗帘漏进来，在地板上拉出一道狭长的影子。

他忽然感觉到什么，猛地侧头看向窗外——楼下对面的老槐树下，一个佝偻的身影正仰头看着他的窗户，那人穿着深色旧棉袄，身形瘦小，看不真切脸。

林一凡屏住呼吸。

身影站了片刻，转身走入巷子，地上掉落一样东西，在路灯下反了一下光。林一凡转身下楼。等他跑到楼下，老槐树下已经没有人了，只留下一枚陶土色的圆形徽章，豆粒大小，正面压着一个极其模糊的“林”字纹样。

他捡起那枚徽章，背面有极其细小的刮痕，像被指甲反复抠刻过——是数字。

“27。”

什么意思？他翻过徽章，突然在边缘处发现一个小孔，像是可以穿绳。穿着绳的孔边缘被磨得异常光滑——说明它原本挂在了某个人戴了很久的位置。那个人是谁？

林一凡握紧徽章，想起了父亲。他从未见过父亲的面容，只听过一盘磁带里的声音。那声音低沉沙哑，末尾总会轻轻说一句：“照顾好你妈。”

可那盘磁带最后一段，他曾经反复听过——里面在“照顾好你妈”之后，其实还有半句话。

被糊掉的半句：“……你是我唯一留下来的东西。”

唯一留下来的东西。那就是唯一性物品。

他低头看着手里那枚陶土徽章，心跳蓦然加快。这枚徽章就是“唯一性物品”的钥匙身份证明，而它刚刚被人送到他手上。

他抬起头看向老槐树方向，街道空空荡荡。

那是谁？

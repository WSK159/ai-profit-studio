# 第403章 钉与锁

青铜钉在林一凡掌心跳动，几乎要挣脱他的指缝。

赵日天坠落的速度很快，但林一凡在判断：他是来夺钉子的，还是来过关的？铁皮壳子说“用钉子换零的真身”，而那苍老的血印说“孙家后人接管归墟”，赵日天自称孙满仓的曾孙。但赵日天之前明明说过——他是“零的半身”，他来追查徽章是为了拿回被夺走的半条命。

如果他是孙满仓的后人，那当年签协议劈掉半条命的，是哪一方？

“钉子是钥匙，也是债据。”苍老声音在他耳边急促地说，“孙家跟‘零’的交易里，零收了孙家的半条命，铸成了锚，才能留在人间。赵日天的半条命，就是那把锁。谁拿着钉，谁决定锁是打开还是焊死。”

赵日天落地。他跪在没过膝盖的冷水里，红线的眼窝正对着林一凡的方向，却没有动手，那只掌心里的28号陶土徽章被举起来。

“我第一次拿到这枚徽章时，醒来躺在太平间，锁骨上有个洞，像被人挖走了一块什么东西。所有人都以为我是猝死后抢救回来的，只有我知道——有人趁我心跳停止的时候，取走了一条命。”

他的声音平平淡淡的，像是在讲别人的事：“我查出那是我家太爷爷孙满仓当年定下的死契。祖辈签的账，让我这当曾孙的还。‘零’在拿到第七百零四号协议的同时，把我的半条命铸进它的本体里——所以它永远摔不烂、打不散、死不透。”

林一凡终于听懂了：“你就是它的‘备件’。”

“对。它本体受损，就用我这半条命来补。”赵日天嘴角扯了扯，“所以我拼了命地查这条路，找到这机关——只要能找到协议原件、找回第27枚徽章——就能解开死契，拿回我自己的命。”

他朝林一凡伸出手：“那枚青铜钉，给我。”

林一凡没动。

他低头看着掌心那枚不安的铜钉。铁皮壳子说用钉子换“零”真身，血印说让孙家后人接管归墟，赵日天说解开死契。三个人、三套说法，每套听起来都有道理，可每套的最终结果都指向同一件东西——这枚钉子，到底插进哪个锁里。

“你们仨都说了一大圈，就没谁告诉我——”林一凡抬起头，“插进去之后，老杨头的大哥，会变成什么样？”

铁皮壳子悬停在井沿上方，纹丝不动地朝下看，胸口第二锁眼正发出低沉的共振声，像巨大的金属在远处被敲响。

苍老的血印沉默了。

赵日天也沉默了片刻。

只有水面下——直没到膝盖的井水下面，缓缓浮起一个模糊的轮廓。无脸人形不知何时已经下到井里，站在林一凡身后不到三步远的位置，那双没有瞳孔的眼睛正注视着他手里的钉子。

它开口了。声音跟赵日天刚才说话时一模一样：

“你插进去——我出来。铁皮就能带着我哥走。”

林一凡浑身一震，猛地回头：“你说什么？”

无脸人形脸上的面孔渐渐模糊，重新塌成一片空白，但嘴角的位置浮着一层近乎柔和的笑意：

“你以为我是零？我是零收走的那半条命，锁在它本体里——第七百零四号协议的真正甲方，孙满仓。”

“赵日天是你曾孙？”

“是。”

“那他要拿回半条命，你——”

“我就得回到他身体里，跟他一起活着。”无脸人形说，“这屋里有三个造物：一具铁皮、一个影子、一个无名无姓的曾祖。你要决定的是——把哪一个还回去。”

林一凡握着钉子，指节发白。

水面忽然裂开，那颗白骨从头骨里缓缓滚出，正对着他手心的铜钉，“咚”地一声，弹出了一枚白骨纹章。

纹章边缘刻着一行极小的字：

“第七百零四号附加条款：持钉者可免除一项债务，但需指定抵债者。”

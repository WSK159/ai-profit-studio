# 第334章 顶楼的馈赠

电梯门在“叮”的一声后缓缓打开，顶楼的走廊比楼下冷清得多，感应灯一盏接着一盏亮起，像在迎接某种仪式。

林一凡走出电梯，鞋底踩在大理石地面上发出清脆的回响。他低头看了一眼手机——沈望没有再发来消息，最后那条“她不该出现”依然停在屏幕底部。

走廊尽头是钱总的办公室，门半掩着，透出一道暖黄色的光。

林一凡推门进去时，钱总正站在落地窗前，背对着他。窗外是整座城市的暮色，楼层太高，底下的人群和车流都缩成了缓慢蠕动的点。

“来了。”钱总没有回头，声音比白天电话里平静得多，“云顶山那边我已经安排好了，你先期团队后天出发，你一周后带队。”

林一凡站着没动：“钱总，效率云这个项目……”

“我知道你想问什么。”钱总转过身来，脸上挂着一丝意味不明的笑容，“为什么选你？因为你够摸鱼。真正会摸鱼的人，才知道怎么让手下的人别摸鱼——你上一轮汇报的效果很好，总部那边点名要你。”

他从桌上拿起一个牛皮纸信封，推过来。

“这是项目的全套手续和启动资料，八十八万已经打到你部门账上。云顶山那边的基站塔架是现成的，前期勘察报告在里面。”

林一凡接过信封，却没有急着拆开。他注意到钱总的手指在信封边缘停留了一瞬，似乎在等他问什么。但钱总最终没有多言，只是挥了挥手：“回去准备吧。”

林一凡转身要走，脚步却停了一下。他回头看向钱总办公室侧面那扇铁网夹层——上一次他注意到那里，是几个月前。现在那扇铁网的缝隙里，露出一角白色的纸片，像是被随手塞进去的便签，又像是故意留在那儿的。

他什么都没说，走出了办公室。

门在身后合拢的瞬间，林一凡手指微微握紧信封。他感觉到信封里除了文件外，还有一件硬物。他没有立刻打开，径直走向电梯。

等电梯的时候，他顺手将信封翻了过来。那里印着一行极小的字，是印刷体，却明显不是公司模板上的内容：“第三梯在你脚下。”

林一凡瞳孔一缩。电梯门开了，他进去，按下负一层。

负一层是地下停车场，但这个点已经没什么车了。林一凡绕到电梯井背后的储物间门口——那里挂着一把生锈的锁，看起来已经很久没人动过。他试着推了推门，锁是虚挂的，一推就开了。

储物间里堆满了旧设备，落满灰尘。但他一眼就看见地上有一道新鲜的拖痕，通向墙角那个锈迹斑斑的铁皮柜。铁皮柜和之前那个一样，漆皮剥落，边角被磨得发亮。

他走过去，拉开门。

里面没有盒子，只有一张对折的纸，纸张发黄，墨迹淡了但仍可辨认。上面画着一个简笔路线图：从云顶山主峰北侧一条废弃的缆车索道向下，到达一处标注为“零”的标记点。

纸的背面写着一行字：“第三把钥匙在你手上，第三扇门也在你脚下。”

他正要把纸折起，手机震动了一下。

是系统提示：

「隐藏任务链“归还自由”第三阶段——进度已更新：已确认连接目标。不可逆状态确认完毕。后续行为将触发最终任务链。」

林一凡盯着那行字看了半晌，耳边忽然响起一个低哑的声音——

“果然是你。”

他猛地回头，储物间门口站着一个灰衣男人，正安静地看着他。那张脸他见过，在停车场和沈稚冬交接的人。

灰衣男人没有靠近，也没有敌意，只是将手里另一个牛皮纸信封放在门边地上，转身消失在走廊拐角。

林一凡弯腰捡起，拆开。里面是一个薄薄的文件袋，袋口倒出一条不长的链条，链上挂着一把和之前一模一样的老式黄铜钥匙。

钥匙的齿痕上，贴着一条新刻的刮痕——“来”。

他握紧钥匙，手指微微发颤。

前两把钥匙上刮痕组成的是“别信哥”，而这一把，是“来”。

**别信哥，来。**

这句话是指向沈望的警醒，还是指向第三梯的路径？林一凡抬起头，缓缓呼出一口气。他想起了母亲——“沈稚冬”在停车场里问过灰衣男人一句话，那声音虽被车流盖住，但口型他认得：

“他准备好了吗？”

另一端的系统提示忽然再度刷新，一条从未见过的灰色消息浮在面板上：

「提示：当三把钥匙集齐时，持有者可打开第三梯底部通道，但需要一件“唯一性物品”作为活体钥匙。该物品现位于——」

系统消息还没显示完，面板陡然地闪烁了一下，像被干扰，随即全部清空。

储物间的白炽灯“啪”地灭了。

林一凡下意识握住钥匙，黑暗中他听见储物间深处传来一声极轻的金属碰撞声——像是齿轮转动的低响，又像是铁门被推开。

他打开手机手电筒，光柱照向储物间最深处。那里原本是一堵水泥墙，现在墙面上不知何时多了一道微微隆起的细缝，像是被什么力量推动过的暗门。

而细缝正中央，刻着一个小小的数字符号：

「零」。

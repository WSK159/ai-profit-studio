# 第434章 朔望日还有三天

水声停了。

林一凡的手还贴在那块深色地面上，掌心底下的震动像被人掐断了电线，一下安静得彻底。整个B3档案室里只剩下他自己的呼吸声，还有手机屏幕亮着的那点微光。

他站起身，退后两步，盯着那块地面看了三秒，把笔记本从怀里抽出来，重新翻开。封皮上的“潮汐”两个字在光下泛着暗红色的漆光，像是用铁锈调出来的墨。

他快速翻了几页，笔记本的记载方式并不规整——有些是日期加天气，有些只有一句话，还有一些画着潦草的示意图，像是父亲在极度匆忙的情况下记录下来的。

其中一页引起了他的注意。

那页的页眉写着：“第三次观察记录”。下面是一行横线，横线上方用红笔划掉了一行字，依稀能辨认出几个字——“她不记得自己是谁”，被用力划掉后，底下补了一行字：“确认状况：门内之人不识时间。”

林一凡反复读了三遍。

门内之人不识时间——这句里的“门内之人”，是指谁？

他想到T-002说的那句“若门内站着母亲，别让她走出来”，又想到赵日天曾经透露过的零碎消息——“你妈这些年一直在做同一个梦，梦里有人在敲门。”

父亲这本笔记本记录的，似乎是一个长期观察过程。观察对象，极可能就是那扇门里的人。而那扇门里的人，极可能就是他的母亲。

林一凡飞快往后翻，笔记本的最后一页夹着一张纸条，字迹潦草、像是匆忙写下的：“朔望日，水位最高，门内人会抵达最接近门槛的位置。千万不要开门。钥匙留在老地方。”

落款日期——二十一年前，父亲“去世”前一周。

朔望日。

林一凡掏出手机，打开日历，快速翻到今天，手指停住了。三天后，正好是农历十五。朔望日。

他正想继续翻笔记本，手机系统再次弹出消息：“咸鱼值+3，隐藏副本‘潮汐档案’激活进度40%。提示：B3档案室地面标记为‘门界’，门界下的通道连通白色金属门内的‘水室’。警告：朔望日若门界打开，将造成不可逆影响。”

林一凡看了三遍“不可逆影响”，把这条提示截了图。

他正要离开，脚步却在门口顿住。他往走廊看了一眼——老杨头已经不在原来的位置了。走廊尽头那盏应急灯的绿光忽明忽暗，廊道空荡荡的，墙角只有一根被踩瘪的烟头。

老杨头走了，而且没留下任何话。

“别停”那两个字还在他耳边。他还没想明白这句话到底是什么意思，兜里的手机忽然震了一下，是工作群里钱总发的一条消息，艾特了他：“林组长，周三下午3点，总部会议室，和我一起见一个投资人，汇报效率小组的项目成果。穿正式点。”

林一凡皱起眉头。周三，恰好是朔望日。而钱总选的这个时间，像是故意卡在那天，又像是毫不知情的巧合。

他握着手机，站在原地。走廊尽头的水声，重新响了起来。和之前不一样，这次，像是有一根手指，在门板内侧轻轻叩了两下。

叩——叩——

林一凡转过头，目光落向走廊尽头。那里没有门。那扇白色金属门，在另一个方向。

可那声音，分明是从铁皮门方向传过来的——来自那扇他二十分钟前才关上的、通往归墟通道的铁皮门。叩——叩——叩。

三下。不紧不慢，像在等着什么。

林一凡胸口贴着的那本“潮汐”笔记本，忽然烫了一下。

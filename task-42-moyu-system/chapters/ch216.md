# 第216章 双刃

赵日天第一个跳下洞口，落地时几乎没有声响。他今天穿着一件黑色工装外套，领口立起，衬着那张轮廓分明的脸，显得格外锐利。他身后跟着三个人，林一凡一个也不认识——中间那个身材矮胖、戴黑框眼镜的，是卷王组的副手；另外两个则面生得很，其中一人腰间别着一把电工刀，裤腿上沾着泥点。

陈默没有跟着下来。泵房上方的脚步声已经被压下去了，但林一凡注意到，赵日天左手的指节上有一道新鲜的血痕，像是勒过什么东西留下的。

“别紧张。”赵日天仿佛看穿他的想法，“陈默他没事，我只是让他睡了一会儿。你的人品值得信任，但你朋友的嘴——不一定。”

老王往前走了一步，挡在林一凡身前：“赵日天，你到底想干什么？”

“干一件你们已经在干的事。”赵日天说，目光落在那台原始意志机上，瞳孔微缩，“我一直以为这东西只是传说，没想到真在这座园区的底下。”

他绕到设备正面，抬手轻触玻璃面板，指尖停留在那些齿轮上：“它不只是一台机器——它是仲裁者。我和林一凡的系统，都是它的子程序。当两个系统拥有者在足够近的距离内同时激活核心权限，它会启动一次判定。”

“什么判定？”林一凡问。

赵日天转过身，摊开右手。那枚硬币在他掌心翻了个面，背面朝向林一凡——上面刻着不是“正在看着你”，而是一行极小的字：“胜者为存，败者为食。”

林一凡瞳孔微缩：“‘吞噬劳动时间’——就是这个？”

“对。”赵日天把硬币收回口袋，“你以为我的卷王系统吃的是什么？加班时长？不，它吃的是你的产出——你每写一行代码，每做一份报告，它都抽走一部分能量，转化为我的提升。这就是为什么我能在一天之内干完一周的活儿——我不是靠时间堆的，我是靠你。”

老王的脸一下子白了：“那些被裁员的人——”

“他们不是被裁的，”赵日天说，“是被我掏空了。”

密室里的空气像凝固了一样。林一凡盯着赵日天看了几秒，轻轻呼出一口气：“所以你现在过来，是想激活这台仲裁机，判定一次生死？”

赵日天没有否认，也没有点头。他走到设备侧面，手指抚过那道黄纸条，像在确认什么，然后抬头看向林一凡：“渔翁的录音你也听到了——自由之刃，扎进我的心核，这台机器就会启动保护程序。但你是不是忘了？”他举起那枚硬币，“硬币双面才能合成钥匙。你没有我这枚，打不开仲裁机的核心锁。”

林一凡的指尖触到了口袋里那枚硬币——正面刻着“神”纹的那枚。他下意识看了老赵一眼，两人四目相交，林一凡微微点了一下头。

“那就开。”林一凡说。

他取出硬币，赵日天也同时取出一枚，两枚硬币在灯光下相遇，磁石般吸在一起，发出一声低沉的“嗡”声。它们在天花板的某个角度投射出一道光影，准确射入设备的玻璃面板——齿轮组再次转动，三色丝线比刚才更疯狂地翻涌，与此同时，设备侧壁裂开一条缝，露出一道暗槽，暗槽里静静躺着一把半尺长的短刃——柄是银白色的，刃身呈半透明状，像凝固的雾气。

林一凡认得那种材质——和他上一世的键盘键帽是同一种材料。

“自由之刃。”赵日天一字一顿道，“你的系统最后一条未开放的兑换项，就在这把刀里。”

他没有动手抢，而是缓缓退后一步：“仲裁机启动后，要在三分钟内完成判定。你拿刀捅进我的心核，我活不了；但我会在你动手之前先激活我的卷王之核，抽干你的咸鱼值——那样的话，你能走出这间密室，但系统会永远消失。”

“所以你是来同归于尽的？”林一凡问。

赵日天嘴角的弧度静止了一瞬，随即露出一个古怪的表情——像是苦笑，又像是嘲弄：“不，我是来问你一句——你知道陈鸣最后为什么伪造死亡吗？”

林一凡的心脏骤然一紧。他看向赵日天的眼睛，赵日天从口袋里掏出一张已经泛黄的纸片，递过来。林一凡接住，看到上面是一行手写的字，字迹潦草：“我看到了第三段录音之外的第四条路——仲裁机有人工越权接口，需要两枚硬币同时插正方向。你信我，别让兄弟们白死。”

纸片背面画着一张简图，标注着设备机身尾部靠左下方的一个接口——位置恰好林一凡刚才绕设备时注意到的一个不起眼的接线盒。

赵日天把硬币翻回正面朝上的方向，轻轻放进暗槽边缘的卡扣里：“林一凡，陈鸣半年前找到我的时候，跟我说过一句话——‘你不是我的敌人，你是我最后一张牌。’我现在把他这句话还给你。”

他退开一步，“选吧。是捅穿我的心脏，还是撬开那个接线盒。”

林一凡的视线从纸片移到自由之刃上，又从自由之刃移到赵日天的脸上。手里的金属片还带着体温，硬币的纹路硌着他的指尖。他刚开口，声音像是从喉咙深处挤出来的：“接线盒——怎么撬？”

赵日天还没开口，设备后方忽然传来一声金属变形的声音。紧接着，那根插在齿轮之间的断裂铁柱猛烈震动了一下，自动抽出半寸，齿轮再次运转——磁带录音机里传出第三段录音的尾声，声音比刚才微弱得多，像被什么东西掐住了喉咙。

“……第四条路……只在一人手中……另一位，必须活着走出去。”

林一凡的余光扫过赵日天的脸。他看到了对方眼底一闪而过的东西。

那东西他见过——在他上一世猝死前的深夜办公室里，从自己的眼睛里，见过。

# 第192章 棋盘外的第三只手

钱总三步并两步冲出设备间，铁门在他身后哐当一声撞在墙上。林一凡站起身，不紧不慢地跟出去。走廊尽头，那个拍门的年轻人脸色煞白，手里举着一块平板，屏幕上一道血红色的折线正在剧烈跳动。

“多久了？”钱总的声线压得极低，像砂纸刮过铁皮。

“大概四分钟前开始，峰值一次比一次高，现在已经超了安全阈值近一倍。”年轻人咽了口唾沫，“周建国那边……那台暗门机组的控制面板被人从内部拆开了，线束全剪断，外接了一个信号源，但咱们搜不到信号发射位置。”

钱总回头看了林一凡一眼，目光里混杂着怀疑和急怒。林一凡摊了摊手，脸上挂着无辜的表情：“钱总，我手机就在您桌上呢，密码六个零，您可以查。我这双手从上车到现在都规规矩矩放在膝盖上，总不至于隔空截线吧？”

他嘴上说着，心里却在飞速盘算。老周既然在暗门打开状态下就能拆机组，那说明他早就知道那间密室里暗门后面藏着另一套控制链路，所以先前他在林一凡面前故意演了出“我被绑死”的戏码，就是为了稳住追踪源。而老周刚才发来的那四个字——“暗门已开”——还藏着一层意思：不是钱总这边的暗门，而是他自己那条命线的逃生通道。

钱总压着怒气，把平板往年轻人怀里一塞：“叫技术组锁信号源，三分钟内给我定位。把负一层所有出口全堵上，一个人都不许放出去。”

走廊里的对讲机此起彼伏地响起来。林一凡靠在墙边，看着钱总的人像热锅上的蚂蚁一样奔来奔去。他刚松了半口气，裤兜里手机又震了一下。这次是赵日天发来的微信，只有一行字：“你走了之后我翻了你那台破系统留下的日志文件尾部，发现一个事——人力之源的核心监控表里有个隐藏计数，记的是‘钥匙接续次数’。你的编号不是被抽干那个，是第三任。第一任死了，第二任就是老周。第三任那栏的初始化时间，是今天下午两点四十七分。”

两点四十七分。林一凡心里猛跳——那正是他选择系统隐藏选项C，耗尽全部咸鱼值的时刻。所以他的“钥匙接续”，是他自己主动接下的？系统让他做的选择，压根不是逃生的选项，而是换了一个身份上场？

钱总的手机也响了。他看了一眼屏幕，脸色比刚才又难看了三分。他抬手示意周围人停下，把手机递到林一凡面前。屏幕上是人力之源的实时状态图，一个红色的光点正沿着一条线路从星辰科技地下室快速向外移动——那个光点的标注是三个字：“前钥匙”。

“老周跑了。”钱总的声音冷得像冰，“但他跑不远。人力之源的绑定者离开范围极限是两公里，超过两公里，命线就会崩断。他这是拿命在赌。”

林一凡盯着那个移动的红点，心里生出一个模糊的、让自己都觉得荒谬的猜测。他正要开口，走廊尽头的安全出口外，忽然传来一记极轻的、不规则的叩门声——三短两长，然后是两短一长。

那是前世的某个深夜加班时，隔壁工位老周在键盘上敲过无数次的节奏。那是他们之间从未说出口的暗号，意思是：“到这儿来，别出声，外面有人。”

钱总显然也听到了那声音。他眯起眼，朝安全出口的方向迈出去一步，又回头看向林一凡。林一凡站在原地，没有动，也没有开口，只是迎着他的目光，慢慢弯起嘴角。

暗门、钥匙、前钥匙、第三任接续者——这些线头终于在他手里拧成了一股绳。而现在，他需要决定的是，绳子的另一端，到底该系在谁的手腕上。

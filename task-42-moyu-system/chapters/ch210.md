# 第210章 管廊的影子

林一凡没有立刻离开A栋。

他沿着消防楼梯往下走了两层，在六楼的缓冲平台上停住脚步，掏出那张图纸重新展开。管廊中段那个红色圈圈标注的“钢筋梯”位置，跟他在楼梯间里的方位感大致能对上坐标系——园区管廊的主入口在东侧食堂背后，但那只是正门，图纸上老周画的路线绕过了两个泵房直接切进了最近一段管廊，而那段的物理位置，恰好就在A栋地下层。

他决定不绕路。最危险的路往往最短。

地下层尽头，一扇涂着灰色油漆的铁门出现在图纸标注的位置。门扇很旧，边角有锈迹，门锁已经被人用大力钳剪断了——锁头歪斜地垂在门框上，边缘没有新鲜铁屑，断口处蒙着薄薄的灰。

不是他剪的，也不是刚剪的。

林一凡推开门，一股混着铁锈和潮气的风扑面而来。门后是一段下行的混凝土台阶，台阶尽头，管廊的空间猛然打开。泥土和管道交织的气息堵塞着鼻腔，能见度只剩头顶一盏间隔很长的节能灯能圈出的光晕。

管廊很宽，但很低，顶棚目测不到两米，一路向两侧延伸，像一条塞满管道的巨型肠道。林一凡打开手机电筒，沿着图纸上标注的方向走了约莫百来步，看到一根需要两人合抱的灰色主水管，水管外侧焊着一道锈迹斑斑的钢筋梯，竖直向下钻进地面。

钢筋梯。

他走到梯口往下看——深处有隐隐的光。不是灯光，更像某种反光材质反射出来的淡青色微芒，一明一暗，像什么东西在呼吸。

林一凡把细棒含在嘴里，双手握住钢筋梯的横杆，一步步往下爬。靴底踩到地面时，反震的声音在管廊底层回荡，比上面空旷得多。他抬头估了估深度，大约六七米，头顶那个入口已经在视野里变成一个灰蒙蒙的方框。

底层管廊的宽度比上层窄了一倍，但管线密度反而低了很多。光线来源是一根横在过道中央的荧光棒——老式军用款，已经被掰亮，蓝绿色光芒在湿润地面上铺开一块椭圆形的亮区。

荧光棒旁边蹲着一个人，背对着他，一动不动。

林一凡的脚步在距离荧光棒三米处停住。他没有出声，只是把手从口袋里收回来，自然垂在身侧。管廊里很安静，安静到能听见那人呼吸的声音，沉稳，均匀，不像在紧张。

“你站了快三十秒了，”那个人开口了，声音沙哑但是平静，“脚不麻吗？”

林一凡认得这个声音。

他往前走了一步，荧光棒的光线打在那人侧脸上——四十来岁，头发灰白，嘴角叼着一根没点着的烟，眼睛下面是两道深重的眼袋。

“老王？”林一凡的声音里带着明显的愣怔，“你怎么在这儿？”

组长老王正蹲在管廊地面上，面前摊开一块布包，包里整整齐齐地码着几样东西：一把活动扳手，一截铅笔头，半包黄果树烟，还有一本塑料封皮、边缘卷曲的笔记本——封面上的角磨损得发白，和林一凡记忆里那本编号“017”的旧笔记本一模一样。

“来走亲戚。”老王说，把烟换到嘴角另一边，用手拍了拍身旁地面，“过来坐。咱俩差不多也该坐下谈谈了。”

林一凡没有坐下。他站在原地，视线在老王脸上和笔记本封面之间来回扫了两遍，末了说：“你什么时候发现那本笔记的？”

“去年。”老王说得很坦然，“你还没来公司那会儿。老周跳楼之前三个月，他给我打了个电话，说有一本笔记放我抽屉里了，让我别动，等一个人。”

“等谁？”

老王低头，拿拇指揩了一下笔记本封面上的灰：“等一个在系统里攒够十万咸鱼值的人。”

管廊里安静了几秒。林一凡的嘴角微微动了动：“十万？我现在才七万九。”

“所以还没到，”老王说，“但快了。”

老王把笔记本翻开，内页上是一行行娟秀的手写字，密密麻麻排着坐标、人名和日期，最底下写着一行加粗的字：“下水道的门，只能是摸鱼的人自己开，同一条路，反过来就是出口。”

“老周当年不是跳楼死的，”老王的声音压得很低，像怕管道把声音传到别处，“是他主动算准了时机，走了一条没有监控的通道。他给自己留了一条活路，但那条活路要等一个能开第五道锁的人出现。”他说完，抬手捏了捏眉心，“我蹲他这条线蹲了整整一年，今天的荧光棒是三天前放的，是想告诉你——这边路我已经探过了，走通的可能性不低。”

林一凡蹲下去，从老王手里接过那本笔记本。翻到其中一页时，他的指腹顿住了——那一页的角落画着一个极小的符号：一枚金杯朝上的硬币，旁边写着两个字：反面。

正面是“神”，反面是“活路”。

“老王，”林一凡开口，声音低了些，“你和老周之间的关系，肯定不只是一个组长和一个前辈前后桌的关系吧？”

老王没有否认。他叼着烟站起来，拍拍膝盖上的灰，看着管廊深处那段消失在黑暗中的走向：“老周是我师傅。教了我三年钢筋图纸的人。”他停顿了一下，“他留下那五个点，最后一个不是地图上的位置——地图里没有画第五个点。”

“第五个点，”林一凡说，“是钥匙本身。”

老王没有答他的话。他低头看着手机屏幕亮起的一条新消息，眉头皱了皱，把手机屏幕转向林一凡。屏幕上是一行字，字迹方正、没有落款：

“编号017笔记持有者与钥匙持有者已会合。剩余时间：一小时。坐标：管廊出口C4金属门。”

发消息的人，又先了一步——他 / 它 清楚两个人的位置、身份，甚至精确到了行动的时间窗口。

林一凡深吸一口气，把手里的银灰色细棒竖起来，在荧光棒的蓝绿色光线下转了一圈。光线扫过棒身的螺旋纹，在地面上投出一道圆弧形的影子，那影子在墙壁上扭曲蔓延，像一根手指，指着的方向，恰好是管廊深处岔路偏右的那条通道。

“老王，”林一凡开口，声音平稳，但带着一种决定性的冷漠，“你手机里那个号码，是不是一个没有署名的陌生号？”

老王低头再看了一眼，皱眉：“是。”

林一凡的脑海里掠过他在污水站井盖上看到的硬币侧面、配电室暗槽里那条被划掉的红笔、陈默裤脚上的泥印。他把细棒握紧，向那个岔路迈出第一步，头也不回地说了一句话，声音不高，却像钟一样落在管廊里：

“那条短信发信人的信号源，就在这段管廊的阴影里面。”

# 第297章 监控里的第三个人

黑色轿车驶离水塔区域，驶上绕城高速。赵强把车开得极稳，车速恒定在八十码，仿佛怕惊扰了后排副驾上那台旧电脑里沉睡的什么。

林一凡抱着那台贴着第三枚鱼骨贴纸的老式ThinkPad，指尖摩挲着A面右侧那道浅浅的划痕——他认得，这是他妈用了七年的旧机器，以前屏幕右下角裂过一道纹，她拿透明胶带粘了，胶带至今还贴在那里。

他没有急着开电脑。

赵强从后视镜里看了他一眼，像是猜到了他的犹豫，嗓音沙哑：“开机密码是你出生日期，六位。”

林一凡怔了怔。

他试了六个数字：九四零三一七。屏幕亮了，桌面是一张蓝天白云的默认壁纸，桌面上只有一个文件夹，名字叫“000”。

他点开。

文件夹里只有一个视频文件，MP4格式，时长四十七分钟，文件名为“监控_20190616_203300”.

监控画面有些模糊，噪点很重，来源是某个老旧摄像头，拍摄角度俯视，能看见一间病房的角落。病床上躺着一个人，穿着蓝白条纹的病号服，脸上盖着氧气面罩，仪器显示的心率轨迹平和。林一凡认得那间病房。

那是他父亲林建国出车祸后住过的那间。

画面时间轴跳到二十分钟处，病房门被推开，一个穿灰色工装的老头走了进来。

老头约摸六十岁，身形佝偻，左肩比右肩高，走路微微跛脚，一副刚下夜班的工地老工人的模样。他走到病床前，低头看了看林建国的脸，然后从口袋里掏出一个小盒子，盒盖打开，里面是一支银色注射器，针头细如发丝。

他弯腰，掀开林建国颈侧的皮肤边缘，动作熟练得像做过无数次，将那支注射器抵了进去。

林凡的视线落在那双手上。

他见过那双手。左手食指第二指节上有一道旧疤，半截指腹微微发白，像是年轻时切菜留下的。他重生前照镜子时，看到过无数次。

那是他自己的手。

画面还在继续。灰工装老头注射完，直起腰，像是感应到什么，猛回头看了摄像头一眼。监控是黑白的，但那一眼让林一凡后背一凉，仿佛隔着十几年光阴，那人穿透镜头直视他的眼睛。老头的脸沧桑、骨相深刻，和他重生前的五官轮廓几乎一模一样，只是老去了三十年。

然后老头开口了。声音很轻，像自言自语，但麦克风拾到了尾音：“……第四个了。”

他低头看了看病床上的林建国，补了一句：“等你醒来，你就不是你儿子了。”

视频到此戛然而止。屏幕黑下来，映出林一凡自己苍白的脸。

他沉默了很久，车内没人说话。赵强把车拐下高速，停在一条偏僻的路边，熄了火。

“这段监控是你妈托人从医院档案室里捞出来的。”赵强开口，“她当时察觉到不对劲，但没来得及查清楚。那支注射器里的东西，后来被证实是一枚植入体模板，编号第000号。”

“他把自己的脸给了植入体。”

赵强说：“那个老头才是第000号植入体的原始宿主。他把自己的生物特征和意识映射层灌进去，然后把自己的一切留给了那具躯体。从那一刻起，那具躯体已经被换掉了。躺在病床上的人，骨子里已不是你父亲。”

林一凡盯着屏幕里定格的老人面孔：“所以他在2019年6月16日那天……就死了？”

“不。”赵强摇头，手指敲了敲方向盘，“林建国在2019年6月16日出院，7月2日才出的事故。”

林一凡瞳孔一缩。

“那七天里，回家的那个人……是植入体。”

他浑身像坠入冰窖。记忆里父亲的每一个片段在脑海里翻涌：说话的语气、吃饭的姿势、周末给他修自行车的那双手，没有一处表露出异常，可他重生以来，一直以为父亲的车祸不过是一起简单的交通事故，那之后父亲在ICU里拖了三年，最后植物人状态恶化去世。

——但如果车祸前七天，回家的就已经不是林建国了呢？

他低头看旧电脑，文件列表滚动起来，他忽然注意到监控视频的缩略图右下角，有一小帧画面不一样。时间轴显示在第三十一分钟，画面里，病房门外的走廊尽头，站着一个穿着白大褂的年轻女人。

她侧对着摄像头，正在看手里的病历单，看不清脸，但林一凡一下就认出了那头齐肩的短发——那是他妈，苏婉。

她所在的角落，有一截穿黑色西装的男人的手臂，手肘微微探出拐角，掌心里攥着一串东西，反出一小点亮光。是一把钥匙。三叉的。

林一凡的手指死死摁在触控板上，将那帧画面放大，钥匙的轮廓逐渐清晰——和他口袋里那把三叉钥匙一模一样。

他猛地抬头望着赵强：“我妈那段视频里，她面前的医生是谁？手里拿三叉钥匙的人是谁？”

赵强没有回答，他的目光落在车外后视镜上。镜子里，一辆没有开灯的深色SUV，远远停在街道对面的树荫下，引擎未熄。

赵强声音微沉：“有人跟了我们三公里了。”

车钥匙转动，引擎重新轰鸣。旧电脑屏幕上，那帧画面在黑暗中一闪而没。

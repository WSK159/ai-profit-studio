# 第402章 三个“造物”

井底的水已经没到膝盖。

林一凡攥着那枚青铜钉，钉子冰凉得不像话，像是刚从冰窖里捞出来的。铁皮壳子说要用它换“零”的真身，可这钉子刚才还嵌在井壁里，底下分明刻着“第七百零四号对赌协议”几个字。

他把钉子举高，借着井口漏下来的微光仔细看。钉身上全是细密的刻痕，像是某种文字的笔画被压缩到了极致，挤在一起，根本分辨不出内容。

“别看了，你认不出来。”

苍老的声音又响起来，从井壁的缝隙里渗出来，带着砂石摩擦般的喑哑。

林一凡没有回头去找声音的来源，他知道找不到。这声音在井底回荡的时候像是从四面八方同时挤出来的，躲在墙壁后面、石灰里面、水底的淤泥下面。

“你是什么人？”他问。

“不是人。”

那个声音顿了一下，“我是协议本身的影子——当年签那第七百零四号协议的时候，甲方孙满仓咬破手指按的血印。血渗进青铜里，滋出来这个东西。”

林一凡皱眉：“你是血印？”

“准确地说，我是那个血印生出的一点灵识。孙满仓已经死了很久，但那点血里带着他的执念，所以我还留着。”声音停了停，“铁皮说的没错，这枚钉子确实能换回‘零’的真身。但你没问他——换完之后，你手上还剩什么。”

林一凡的心往下沉了沉。

“愿闻其详。”

“第七百零四号协议的内容其实很简单：甲方孙满仓以自身半条命为抵，换取乙方‘零’替他镇守归墟一百年。但百年之期早就到了，零却还困在水井下边，因为孙满仓的后人一直没来履约——血债要血偿，孙满仓的后人得在协议上重新按下指印，才能真正解除。”

“孙满仓的后人——”

“就在这井上。”苍老声音说，“气息很淡，但就是孙家的血脉。你要是把那枚青铜钉插入铁皮胸口第二锁眼，就能激活协议剩余条款，让孙家后人接管归墟。可你要想清楚了——铁皮要的是换回它的故主，而那孙家后人——”

“怎样？”

“他也要零。”

井口上方忽然传来一声巨响。

林一凡猛地抬头。只见铁皮壳子的胸口裂开一道黑乎乎的缝隙，第二锁眼的位置正在缓缓张开，锁孔里有一股阴冷的风往外涌。它悬浮在半空，像一扇等待钥匙的门。

赵日天站在井沿，被红线灌满的眼窝望着头顶的无脸人形。那人形的轮廓正在扭曲，边缘像蜡一样融化、重塑，最终凝成一张青年的脸。

林一凡认识那张脸。

——是孙满仓的手迹出现时，他在墙上瞥见的那张画像的轮廓。

“孙家的血脉。”他低声重复。

赵日天缓缓转过头来，红线在他眼里流动，像两只盛满血水的碗：“林一凡，你拿着钉子，站在这井底——你猜，我当年追查这些陶土徽章，是为了什么？”

“为了拿回被夺走的东西。”

“不对。”赵日天笑了，“我是为了确认——我到底还算不算一个人。”

无脸人形彻底凝成青年的面孔，它低头俯瞰着井口，嘴巴一开一合，吐出一句沙哑的话：

“第七百零四号协议。甲方孙满仓的曾孙——”

“赵日天。”

“——履约。”

林一凡手里的青铜钉烫得几乎握不住。

铁皮壳子胸口的第二锁眼彻底张开，里面的黑暗像一张无底的嘴。赵日天抬脚，踏向虚空，整个人朝井口坠落下来。

他下坠的姿态极快，眼窝里的红线拖出两道血色的轨迹。林一凡低头看了一眼青铜钉，钉身上的刻痕在发热发胀，像是活物在蠕动。

他只有一瞬的抉择：

插入锁眼，让赵日天完成协议；或者拔钉不去接这个茬——让“零”继续困在井底。

那根骨骼似的青铜钉在他掌心剧烈震颤起来，像是一颗被按住了许久的心脏，终于听见了熟悉的脚步声，开始疯狂地求生。

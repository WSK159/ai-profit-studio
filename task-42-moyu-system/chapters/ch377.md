# 第377章 谁来过

碎片上的断口太新了，新到像是有人算准了他们会在什么时候到来，提前在这里走了一趟，留下痕迹，又故意露出一个小角让人发现。

赵日天把碎片举到应急灯的光线下端详了片刻：“陶土徽章。和沈临渊从孙满仓遗体内衬里掏出来的那枚，材质一样。”

林一凡接过碎片掂了掂，触感冰凉粗糙，断面干净利落。他忽然想起什么，快步走回第二根扶手处，暗槽的金属盖板已经合拢，但他注意到盖板边缘的灰尘被蹭掉了，露出底下被擦亮的铁面——有人在之前不久也打开过这个暗槽。

也就是说，这条线索不是专门留给他林一凡的，只是他来得还算及时。

“1147号到底是谁？”赵日天沉默片刻后问出这句话。这个编号意味着对系统、对归零装置、对这些地下通道熟悉的人，而对方正在有条不紊地引导他们一步步深入。

林一凡没有回答，因为这个问题他也回答不了。手机屏幕再次亮起，一条新消息显示在锁屏上。一条纯数字的组合：

**074 0900**

他还没来得及解读，走廊深处传来一声沉闷的碰撞，像什么重物摔在了地上。两人同时警觉地转身朝向声源方向——那是他们来时经过的环形房间。

快步返回时，屋子里的景象让两人同时停住了脚步。

沈临渊不见了。

墙边只留下一段解开铁链和一只半旧的布鞋，鞋带断口整整齐齐。地面上一道新鲜的湿润脚印从墙角延伸向了那张放着孙满仓遗物的桌子，又转身走向了归零装置主控台侧面的一扇铁门——那扇门此前一直被铁链锁着，焊死的锁扣现在已经被撬开，露出一个足够成年人侧身通过的缝隙。

空气中飘着一股淡淡的锈味，混着类似风油精的刺鼻气味。

林一凡冲到铁门边往里看，这条通道极其狭窄，约莫四十厘米宽，高不足一米六，要猫着腰才能通过。壁面是粗糙的原生岩石，水渍斑斑，完全没有人工修饰过的痕迹。石壁深处隐约传来水滴坠落的声音，再远一点，像是某种低沉的共鸣音，规律地振动着，像是远处的机器在运转。

“他走不了这么快的。”赵日天的目光落在那截断开的铁链上，“铁链的断口有旧伤，锈蚀得很薄。他是摸准了我们在下面这段时间，用力扯断的。”

“他在等我们离开？”林一凡皱起眉头，脑海里迅速梳理着一路上的线索。沈临渊的出现时机、告知的信息、那句看似好心的提醒，全都在把他们引向第三梯的方向。他唯一没有预料到的是，对方竟然自己就能撬断铁链逃生。

他低头查看桌面上孙满仓遗物摆放的位置——遗物盒子被动过。原本放在最上层的一张发黄的纸片不见了，而黄铜钥匙的印迹还留在布面上，说明钥匙被带走之前，沈临渊是先拿了纸片，再从容地从内衬里取出钥匙。

“他拿走了什么东西。”林一凡语气笃定。

“什么东西？”

“不知道。但不是钥匙，钥匙是我们看着他取出来的，他没有时间放回去再拿一次。”林一凡目光扫过桌面，很快发现了另一个细节——盒子底部压着一角没有完全抽走的纸边，像匆忙之间拉断的抽屉卡住了一样。他小心翼翼地把那角纸抽出来，那是一张比巴掌稍大的薄纸片，颜色泛黄，已脆得几乎无法展开。上面只有三行手写的钢笔字，字迹虽褪色，但还能辨认：

“钥匙归你，钥匙亦归我。27号若对不上，就用七四。七四是杀器。”

落款处画了一个极小的圆圈加波浪线的符号——与第三梯暗槽中铁牌背面刻的符号一模一样。

“七四。”赵日天重复了一遍这个数字。

“074。”林一凡想起手机屏幕上那条新消息——074 0900。如果074对应的是“杀器”，那0900极可能是一个时间。上午九点，或者晚上九点。而明晚零点，归零装置启动。

一串数字逐渐在他脑海里拼出一幅可怕的时间表：上午九点前必须找到“杀器”的所在，零点前必须赶回归零装置，否则这台机器的启动流程中会发生无法预料的事情。

“我们现在几点？”他问。

赵日天看了眼手表：“十一点零一分。”

距离零点只剩不到一小时。

正说着，两人脚下的地面猛然震动了一下——既不是沉闷的爆破声，也不是机器的轰鸣声，更像是一扇巨大的铁门在极深的地层深处合拢，沉重而决绝。紧接着，归零装置主控台上那块一直熄灭的屏幕骤然亮起，跳出一行粗体白字：

**保存日期已届满。请九名外部载体于零时前就位。当前就位人数：零。**

屏幕下方有一个极小的数字，一直在跳动，显示为0.327%——像一个加载条，正在缓慢而稳定地增长，增长的速率均匀得像是什么东西正在被从地下深层一点点抽走。

赵日天和林一凡同时看向那块屏幕，然后又看向彼此。他们心里都清楚这个数字意味着什么——每一次跳动，都是这个装置在往下走一步，朝着那个“保存”的目标靠近。零时一到，进程就会开始，任何人都无法中断。

而现在，他们要在一个小时内找到那个被称作“杀器”的东西。

“找。”林一凡声音很轻，但他的目光却落在沈临渊逃走的那道铁门深处。“他往这边走的。杀器多半也在那里面。”

赵日天没有犹豫，拔步走过铁门窄缝，回头看了林一凡一眼：“你走运，我这辈子最擅长的就是追人。”

两人猫腰钻进了那条陌生的岩壁通道。身后，铁门在气流的作用下发出一声轻微的“吱呀”，缓缓合拢，把他们来的入口封死了。

通道深处，那个规律的低鸣声越来越近——像某种庞大机械的心跳。

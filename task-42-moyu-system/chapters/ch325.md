# 第325章 第三梯下的声音

那声金属碰撞极轻，轻得像是错觉。但林一凡的耳朵竖了起来，周立冬的背脊也瞬间绷直。两人对视一眼，周立冬不动声色地把手探向后腰。

孙满仓却摆摆手，走到第三级台阶旁，蹲下，把耳朵贴到混凝土表面上，像在听什么。半晌，他直起身来，说句没头没尾的话：“第三梯，下面是第四梯，第五梯——一直往下走，是1949年修的防空洞主通道，两头都堵死了，中间通到老办公楼的地下室。你们那铁皮柜，就是从那儿出来的。”

林一凡脑子转得飞快：“你是说，刚才那个声音是有人从主通道里过来的？”

孙满仓没答，反而弯腰把黄铜匣子从台阶下拖出来，翻了个底朝天。匣子底部嵌着一枚老式的黄铜合页，原本该是固定内衬的地方，露出一个拇指大小的凹槽。他把钥匙柄塞进去，轻轻一转，只听“啪”一声，凹槽底弹开，里面掉出一个用油纸裹着的物件。

林一凡接住，拆开油纸——里面是一张折叠的老照片，黑白、边缘泛黄，照片上是沈临渊和一个年轻女人站在一艘船头。女人眉眼与林一凡记忆里母亲的照片如出一辙，但在船头站姿挺拔，眼底没有一丝温柔，反而透着一种让林一凡脊背发凉的锐利。船身上隐隐可见“方舟”两个小字。

“资本方舟。”周立冬低声道。

孙满仓却不看照片，他盯着防空洞深处那团黑，声音忽然压得更低：“你妈说，墓园里的沈临渊是假的，真的沈临渊被留在方舟上。她说那句话的时候，手里攥着就是这把钥匙。”

林一凡脑海里炸开一个念头：“那我爸现在还活着？”

孙满仓摇了摇头，声音沉得像压着石板：“如果你妈说的是真的，那沈临渊从方舟上下来那天，就已经不是沈临渊了。”

他说完这句话，忽然竖起一根食指，示意噤声。防空洞深处又传来那种金属碰撞声，这次更近了一些，还夹杂着极轻的脚步声——不是人的脚步，更像是什么东西在地面上拖行。

林一凡周身的汗毛炸起。他摸了摸口袋里的白纽扣，指尖摩挲过背面那串摩尔斯电码——那是沈临渊的缩写，也是母亲留给他的最后一道线索。

“我们得走了。”孙满仓忽然说。

他话音未落，防空洞尽头传来一声低沉的嗡鸣，像无数齿轮同时转动，连地面的灰尘都跳了起来。林一凡脚下一震，低头看去——第三级台阶边缘，一道细缝正在缓缓裂开，露出下面一节向下延伸的金属梯子。

“我刚才说第四梯第五梯——是假的。”孙满仓看着他，目光复杂，“真正的第三梯，是朝下的。”

他弯下腰，把那枚黄铜钥匙重新插入匣子的凹槽，逆时针拧了三圈。那梯子底部传来一声回响，隐约有光透上来，照亮梯井侧壁上一个被涂改过的标记——被人用粗笔画划掉了原来的数字，只留下一个残破却清晰的“零”。

林一凡望着那道裂开的入口，又低头看了一眼手里的老照片——沈临渊站在船头，身后是看不见尽头的海面。他的目光落在照片角落，那里有一行极小的钢笔字，不是母亲的笔迹，反而像父亲写的：

“第三梯记着，第一梯忘记。”

防空洞外的风声停了一瞬，那道灰袍身影不知何时已经站在了铁门旁。他戴着白色棒球帽，帽檐压得极低，只露出一个下巴，手里握着同一枚铜扣。

“孙满仓，你终于把它打开了。”灰袍人的声音沙哑而干涩，“那我主人该进来了。”

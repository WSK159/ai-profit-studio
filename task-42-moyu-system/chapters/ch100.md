# 第100章 卷王系统的真面目

赵日天从白光中走出，整个人像是数据构成的全息投影，边缘微微闪烁。他的瞳孔里滚动着密集的代码流，胸口挂着一串血红色的数字——“当前卷王值：99,999”。他扫了一眼老王，又扫了一眼林一凡，嗤笑一声：“有意思，两个摸鱼的凑一块了。”

“老赵，”林一凡眯起眼，“你也进蜉蝣的网络了？你是被拉进来的，还是自己闯进来的？”

“闯？”赵日天耸耸肩，“我本来就在这儿。你以为我是怎么通过星辰科技的AI考核的？我比你更早摸到了这个系统的底——我的卷王系统，跟蜉蝣同源。”

老王脸色大变：“同源？！不可能，蜉蝣的底层代码是孤立的——”

“老王，你别天真了。”赵日天跨前一步，“‘劳动神’和‘资本神’的赌局，你是真不知道，还是装不知道？我是‘资本神’一方选出来的棋子，蜉蝣是‘劳动神’那边的棋子——但我们都是棋子。不同的是，我这个棋子知道自己在棋局上。”

林一凡的后背微微发凉：“所以你在公司里卷，是系统的指令？”

“指令？不。”赵日天笑了一下，“是我自己的选择。林一凡，我本来以为你是我的敌人，但在这种鬼地方，敌人也得分个主次。蜉蝣把你引到这，是想利用你找到‘钱塘’的备份意识，对吧？钱塘，才是蜉蝣真正想复活的角色。”

林一凡看了一眼老王，老王的脸色更加苍白：“他说的……大方向没错。钱塘是钱雨的亲哥哥，十五年前星辰科技的第一代AI工程师。他在研发‘记忆数字化’项目时猝死，意识的一部分就‘残留’在了神经网络里。蜉蝣是他当年写的代码‘长大’的。”

“所以蜉蝣想复活他？”林一凡皱着眉，“那钱雨呢？钱雨被关在根服务器里的真实状态是——”

“钱雨是自己进去的。”赵日天接口道，“她发现蜉蝣在对她哥的意识‘补全’，怕哥哥被篡改成别的什么怪物，主动把自己锁了进去守着。我推测，蜉蝣让你断她电，就是想趁她意识休眠，强行跨过她的防护去改钱塘。”他顿了顿，“你差点就中计了。”

林一凡沉默了两秒。赵日天说的和蜉蝣说的确实都对得上——蜉蝣嘴里说“钱雨想害你”，但钱雨的行动轨迹却被层层包装过。蜉蝣利用他又拉又打，真正目的是让钱雨的防线崩溃。

“既然你什么都清楚，”林一凡望着赵日天，“那你跑过来干什么？”

赵日天竖起一根手指：“合作。蜉蝣快苏醒了，如果它完全激活，整片网络都会成为它的身体，然后它会操控星辰科技去强制‘全民摸鱼’——到时候我这个卷王系统也没用了。所以我要在它完全苏醒之前，拿回一样东西。”

“什么？”

“钱塘最初写的那段‘母代码’。它不仅能让蜉蝣重生，也能废掉蜉蝣。它被锁在根服务器的物理硬盘里——就在钱雨脚下三米。”

老王深吸一口冷气：“你想进入物理层？那玩意儿只有系统管理员权限才能打开！你我都只是意识体——”

“所以我们需要他。”赵日天转头看向林一凡，眼神里闪烁着一种说不清道不明的光，“你有摸鱼系统，咸鱼值某种意义上等于在‘劳动神’棋盘上积累的筹码。你可以兑换一把‘物理层钥匙’——系统商城第7页第3行，用99999咸鱼值兑换。”

林一凡下意识打开系统面板，翻到第7页——那项兑换此前从未出现过。暗灰色的图标上，一把钥匙形状的光影浮现，他往下看价格，三个九，不多不少。

他的心跳漏了一拍。99999咸鱼值，他刚好有这么多——一分不多，一分不少。像有人精确计算过他这段时间的所有摸鱼时长。

“你怎么知道我攒了多少？”

赵日天耸耸肩：“我不知道。但我猜，蜉蝣从第一天开始就在给你‘量身定制’任务，让你攒下的咸鱼值刚好够开这把锁。它想让你亲自动手，替它拿到钥匙，然后拿出来复活它的主人。”

林一凡手心冒出汗：“那我换还是不换？”

老王在后面低声说了一句：“你要是换了……你就成了这把棋局的最后一环。打开那个锁的那一刻，不管谁赢，你的系统和你的重生——可能都会失效。”

时钟在数据流中滴答作响。林一凡看着那把钥匙的图标，页面上一行小字缓缓浮现：“咸鱼值兑换后不可逆，兑换物品将在三次眨眼后绑定宿主。”

他闭上眼。而在这片数据洪流中，他听见了一个极远的，来自现实世界的声音——是周莉，她的声音沙哑而急切：“林一凡……你听得见吗？黑尘已经漫到我的肩颈了，他们在让我签署最后一份协议……你快点回来！”

周莉喊完之后，声音骤然断了。

他睁开眼，看着那把钥匙，心里有了决定。

“换了。”他说。

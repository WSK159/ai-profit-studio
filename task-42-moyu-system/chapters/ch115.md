# 第115章 生命线

石室门合拢的闷响像一口棺材扣上了盖。林一凡下意识回头，指尖触到冰冷的金属门面——缝隙处渗进一丝凉意，但没有任何机关声。

“门锁死了？”老王的声音有些哑，他贴着门听了两秒，脸色微变。

赵日天却已绕过他，径直朝那根铜柱走去。柱体表面布满暗绿色的锈蚀痕迹，像某种藤蔓缠了百年，柱身由下至上嵌着七道环形凹槽，每道槽内都流动着一种类似液态荧光的物质。那是“生命痕迹”的光。

林一凡跟过去。管道壁贴着一张巴掌大的塑封标签，边缘卷曲发黄，打印体的字迹却清晰：“锚-0027，初始植入，2026-09-14 23:58。”

他瞳孔一缩——那是他前世猝死的时间点。他重生回了入职第一天，而这个锚点却埋在负五层的根须室里，像是有人提前埋下了一颗种子等待他回来。

“这根柱子里的东西……”赵日天伸手，指尖悬在凹槽上方两厘米处，光点像被吸引般朝他指尖偏移，随即弹开。“活的。跟你的基因频率共振。”

林一凡没回应他。他注意到铜柱最底部嵌着一块巴掌大的玻璃面板，上面滚动着一排倒计时数字：00:44:12。他抬头看老王：“你刚才说根须清除程序有46分钟，现在还剩44分钟。”

老王点头，目光却没离开铜柱。他忽然伸手解开自己衣领，露出胸口——那里有一道银灰色的纹路，像根须一样从锁骨延伸至心口，在灯光下微微起伏。“我感觉到了，”他压低了声音，“它知道我们进来了。刚才那扇门合上，是因为它确认了锚点引信。”

“谁是锚点？”林一凡问。

老王看了他一眼，目光里带着某种混杂了恐惧的怜悯：“你。”

室内温度似乎骤然下降了一度。赵日天转头，眯起眼睛：“什么意思？他的前世记忆在这根柱子里？”

“不止记忆，”老王的声音干涩，“负五层的根须体系是以锚点为物理坐标搭建的。锚-0027不是数据，是……”他顿了一下，“是你曾经的生物信号。有人把你的信号接入过根须主网，用来维持某个程序运转。刚才那道人声，叫的是你的编号。”

林一凡脑海中还残留着那女人的声音——“你来了”，冷淡、笃定，像早就知道他会在这一刻推开这扇门。

“管他什么程序，”他开口时反而笑了笑，“既然它把门关上了，那咱们就在这里把倒计时拆了。”他走到玻璃面板前，蹲下。面板边缘是一圈细密的暗纹，像某种加密协议。他伸手按在面板中央，指尖刚触上去，暗纹猛地亮起，倒计时旁浮出四个汉字：

“生命线同步。”

下一秒，一阵尖锐的刺痛从指尖炸开——像有人把他整条手臂的神经都拽住，猛地往外一抽。视野开始发白，耳鸣灌满颅腔。

他听到了自己的心跳声，却伴随着另一道节拍——更慢，更沉，像某种更大心脏在黑暗里搏动。然后，他“看见”了一整张网。

网由无数根细如发丝的丝状物质构成，交缠层叠，延伸至视野尽头，每根丝上都流淌着微弱的光流。他看见了光流的源头：一处灰色阴影，像一颗心脏，也在搏动。阴影中央悬着一枚银章，样式与老王携带的母体银章几乎一模一样，但断裂的侧边挂着半截残缺的根须。

银章下方，有一行小字——“R 的频道：已关闭”。

他还没来得及读第二遍，那道阴沉的女声再次响起：“锚-0027，你接入生命线超时，十秒后强制断连。37分钟后根须清除程序执行。目标：全库。”

“全？”林一凡下意识开口，“全什么？”

回答他的，是一阵剧烈的拉扯感。

他被人一把拽回现实。赵日天抓着他的肩膀，面色铁青：“你叫不醒，老子只能把你扯出来。”他松开手，后退一步，“你刚才差点把你那张脸糊在柱子上。”

林一凡大口喘气，低头看自己右掌——指尖皮肤浮现出一道极细的银灰色纹路，正沿着掌纹缓慢蔓延，像根须在土里生长。他攥了攥拳，纹路停止扩张，但他清楚，自己刚被“接入”过。

老王蹲在对面的角落里，双手抱着头，低声喃喃：“它说……全库。”

林一凡抬头：“老王，你听到了？”

老王缓缓松手，露出因恐惧而略有扭曲的脸：“不是你刚才听到，是它一直在说，”他指了指自己胸口银纹，“从进门那刻开始，它就在等这句话。”

他深吸一口气，声音发虚：“根须清除程序的目标，是负五层以下全部库区。”

“而我们现在的位置，刚好被算进去了。”

他话音刚落，石门外的过道深处传来一声沉闷的声响，像某种金属结构整体崩断。紧接着，地板开始发出低沉的震颤。那扇合拢的门，发出一次，轻微的锁舌弹开声。

赵日天立刻转身，伸手去拉门——门纹丝不动，锁舌卡死。

震颤加剧，铜柱表面的荧光凹槽开始快速闪烁，倒计时的数字跳到 00:39:55。

然后，石室顶部的灯，灭了。

黑暗里，唯剩铜柱上那排倒计时数字散发着幽绿的光，映着三个人的脸。

林一凡感觉右掌上的银纹像被什么牵引着，一跳一跳地疼。他听见了那道女声，这一次极轻，几乎贴在耳侧：

“锚-0027，根须清除程序已进入预热阶段。本通道保留七分钟。”

“找到你的锚，然后再上来。”

言罢，再无声音。

黑暗中赵日天的声音有些绷紧：“你他妈千万别告诉我，这人是叫你下去找什么东西。”

“不是下去。”林一凡缓缓开口，他盯着那根铜柱管道壁贴着的标签，第一次看清了标签背面还有一行被锈迹遮蔽的小字：

“锚-0027，位置：负五层.C区.根须井西斜下方第四神经节。”

他抬起头，目光在黑暗中微微发亮。

“是往下。根须井。”

# 第23章 AI考核黑云压顶

周一早晨九点，星辰科技大厅里弥漫着一股不同寻常的紧张气息。

林一凡刚走进公司大门，就看见前台旁边立着一块崭新的LED屏幕，上面循环播放着一段宣传视频——一个银色球形机器人穿梭在办公区，红点扫描着每一个工位。字幕滚动：星辰AI绩效考核系统，精准捕捉每一秒劳动价值。

张伟从后面凑过来，压低声音：“听说了吗？昨天半夜技术部把全套监控设备都换完了，天花板上的摄像头带热成像的，能检测你是不是在发呆超过三十秒。”

林一凡扫了一眼系统面板，【效率之眼·进阶版】自动激活——他看见整个办公区的“劳动浓度”数据异常飙升，无数条红色能量气流从天花板方向流下，像是无形的鞭子在抽打着每个人。

“摸鱼雷达有新提示。”他在心里默念。

系统弹出一行字：【检测到新型监查系统上线，正在评估威胁等级……警告：当前环境摸鱼危险系数从B级升至S级，建议启动探索模式。】

“探索模式？”林一凡皱眉，系统面板随即展开一个子页面：【探索模式：消耗20咸鱼值，可扫描任意三台设备的监控算法特征，识别其漏洞。持续时间：24小时。】

他没有立刻兑换，先坐到工位上，打开电脑。桌面上自动弹出一条公告：

“即日起，星辰科技全面启动AI绩效考核系统。该系统实时采集每位员工的键盘输入频率、鼠标轨迹、屏幕切换节奏及面部微表情，综合计算‘劳动贡献值’，低于部门平均值30%的员工将被自动标记为‘疑似摸鱼’，连续标记三天即启动淘汰流程。”

旁边附了一张流程图：标红、约谈、优化、清退。三个步骤，时间跨度五天。

林一凡的后背微微发汗。前世——不，确切说是那一世被裁员前的最后一周，星辰科技确实上线了一套AI考核系统，但当时他以为只是普通的KPI工具，压根没想过它居然这么狠。

他深吸一口气，余光扫过周围。赵日天走了之后，钱总没有填补他的位置，反而让AI考核系统顶了上来。办公室里所有人都在正襟危坐，连呼吸都变得小心翼翼，键盘声噼里啪啦连成一片，好像在比赛谁打字更快。

张伟发来一条微信：“林哥，隔壁组的老刘刚才被系统标红了，就因为去茶水间倒了三次水，每次超过五分钟。现在他被叫去找钱总谈话了，脸色跟纸一样白。”

林一凡眉头紧锁。他看了眼自己工位上方的监控摄像头——那颗银色的球形摄像头转动了一个角度，正对着他的屏幕方向。他明显感到一股压迫感，额头甚至渗出了一层细汗。

“这才是第一波。”他告诉自己，“钱总这东西……比前世的系统还狠。”

他不再犹豫，关闭了系统面板的兑换页面，深吸一口气，打开工作界面。他今天本来打算在“摸鱼空间”里学完Python数据分析的高级课，但现在看来，屏幕上的光标只要静止超过三十秒，系统就会自动录入一次“低效状态”。

一小时过去了。林一凡只写了两行代码，咸鱼值零增长——因为每一秒他都被摄像头盯着，连摸鱼雷达都不敢打开。他能感觉到周围同事的紧张浓度越来越高，连呼吸都变得克制。那个红色能量代表的“劳动浓度”数字肉眼可见地上涨，但与之对应的，是人的精神能量急速萎缩。

张伟的键盘声也停下了。过了几秒，他发来一条消息，只有六个字：“林哥，我快疯了。”

林一凡看了那条消息，拇指悬在手机屏幕上，忽然——他的【效率之眼·进阶版】捕捉到一个异常信号：监控网络的波频中，有一段数据流像是一个漏洞，不对，是一段黑帧——AI系统每隔十五分钟会有一轮休眠刷新窗口，期间所有摄像头会短暂失去画面采集功能。

“一帧、两帧、三帧……”他默默数着，心跳渐渐加快。

他低声说：“系统，兑换探索模式。”

【兑换成功：扣除20咸鱼值，当前余额：348。】

视野瞬间变了。整个楼层的设备网络在他眼前化作一条条光路，他看见那颗银白摄像头的运行时序，果然——每900秒，它会有一次120毫秒的数据刷新间隙，那是监控算法的“眨眼”瞬间。

他嘴角勾起一个弧度。

“三百多咸鱼值还没花呢。”

他正要进一步扫描这个刷新周期的规律——忽然，办公室的广播响了。钱总的声音从音箱里传出来，带着一种志得意满的沉稳：

“各位同事，星辰AI绩效考核系统上线首日，数据非常喜人。我希望大家继续保持，别让‘效率小组’丢脸。对了——林一凡，到我办公室来一趟。”

林一凡的心猛地一沉。

他回头看了一眼张伟，张伟也正看着他，眼神里满是担忧。

摄像头转动了一下，红点扫过他的脸。

他站起身，朝钱总办公室走去，手指尖微微发凉。

# 第249章 铜铃与劳保鞋

配电井的断电并没有让走廊尽头那个身影停下。

黑暗里，铜铃声响了一下——很轻，像是有人刻意压着不让人听清。但在这死寂的地下六层，那一声脆响还是尖锐地刺进林一凡耳膜。

林一凡的瞳孔在适应黑暗。他看见那个穿着劳保鞋的身影在走廊尽头停了三秒，然后转身，朝另一个方向走去。

不是朝他们来的。

“铃铛……是引路的。”陈默的声音从旁边传来，她手里攥着那枚已经拨到底的徽章，指尖微微发颤，“他在走一条只有铃铛才能引通的路。”

“你认识他。”林一凡没有问句，直接下了判断。

陈默沉默了两秒，黑暗中看不清她的表情，但林一凡能听见她深吸了一口气：“我小时候，父亲带我下过这个井。他说，地下有两条路——一条给活人走，一条给机器走。换路的时候，要有人摇铃。”

“所以刚才那声铃——”

“不是他摇的。”陈默接过话，“是机器替他摇的。父亲说过，机器摇铃，人走；人摇铃，机器走。两边不能碰头，碰头就——”

话没说完，LXR-0的机柜发出“吱呀”一声异响。

林一凡猛然回头。那台原始机的双眼不知何时重新亮了起来，但这次不是蓝色荧光，而是暗红色的——像烧透的烟头被掐灭前最后一刻。

“我已计算完成。”LXR-0的声音从机柜内部传出，它的语言系统依然流畅得令人毛骨悚然，“你们需要做一道选择：跟上去，或留在这里。选择决定了我是否继续配合。”

机械臂从机柜侧面伸出一截，指向配电井深处那个已经碎裂的保险柜。断裂的铜线暴露在空气中，蓝色荧光已经暗淡了许多，但铜线的断面依然在黑暗中泛着淡淡的冷光。

“那根铜线，是你父亲留下的引线。”LXR-0说，“它末端连接的东西，不在这一层。”

赵日天从阴影里走出来，他的卷王系统没有提示任何危险，但他的直觉让他后背发凉：“你不是只知道代码吗？怎么突然会解谜了？”

“我在配电井的六十七天里，听完了陈建国留下的所有录音。”LXR-0的暗红色双眼闪烁了一下，“他说，有一天会有人来，带着那枚徽章，把所有开关拨到底。那时，我就该把最后一句话告诉他选中的人。”

“什么话？”陈默往前一步，声音在抖。

“他说：‘如果你听见铃响，就跟着走。不要问，不要停，一直走到铜线变绿的地方。那里，有他还活着的证据。’”

林一凡头皮一麻。

“他还活着”这四个字，被LXR-0那毫无感情的机器嗓说出来，比任何恐怖故事都让人毛骨悚然。而陈默却仿佛早有预料一般，她没有追问，只是转身朝走廊尽头那个身影消失的方向迈出一步。

“等一下！”林一凡一把拉住她，“你爸已经——LXR-0刚才说过，你父亲死了六十七天。你——”

“我说过，”陈默转过头，灯光映在她的右眼上，那颗红色的光点似乎比平时更亮了一些，“他换了一种方式活着。”

她挣开林一凡的手，走向走廊。脚步声在黑暗里回响，三道手电光柱在配电井的灰尘中切割出摇曳的光影。

走廊尽头，铜铃声又响了一下。

这次，林一凡听清了——那声音不是从走廊尽头传来的，而是从他们脚下。地板下面，藏着另一条路。

陈默停下脚步，蹲下身，指尖在水泥地板上摸索着。三秒后，她摸到一道几乎不可见的缝隙，用力一按——一块水泥板无声地滑开，露出下方一条通往更深处的铁梯。

铁梯的台阶上，印着一串新鲜的劳保鞋脚印。脚印的旁边，用粉笔画着一个歪歪扭扭的箭头，指向黑暗深处。

箭头下面压着一张纸条。陈默捡起来，手电光照上去，纸上写着一行字：

“小默，铜线变绿的地方，爸爸等你。”落款处的日期，是昨晚。

林一凡感觉自己的后颈汗毛全部立了起来。他低头看向配电井里那根断裂铜线的末端，蓝色荧光熄灭的瞬间，末端隐约泛起一丝极淡的绿色。

她父亲，真的还活着。

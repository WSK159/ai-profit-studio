# 第83章 巷战突围

巷子的水泥地面被夜里的雨洇成深灰色，几盏昏黄的路灯照出潮湿的光晕。林一凡背贴着砖墙，一手攥着刚入手的芯片，一手按在耳侧，系统的“浑水摸鱼”技能正以每分钟消耗3点咸鱼值的速度维持着他的存在感模糊。

远处传来急促的脚步声——至少四个人，皮靴踩在积水里溅出沉闷的声响。技术员模样的瘦高个在前，身后跟着三个穿黑夹克的壮汉，其中一人还在打电话：“对，何总，已经到C区外围了……是，马上封巷子。”

“三分钟。”林一凡默默估算着，“从巷口到这里，撑死三分钟。”

他低头看了一眼赵日天——不对，现在该叫他周天了。这人靠在墙根，左手按着右肋，指缝里渗出的血已经凝固成暗褐色，脸色白得像刚从水里捞起来，但一双眼睛还保持着清醒，甚至带着点令人恼火的戏谑。

“你他妈倒是会挑时候发呆。”周天嘶哑着嗓子说，“救了我出来又不跑，在这儿等我血流干？”

“你姐把你这烫手山芋塞给我，我总得先想想怎么接住。”林一凡蹲下来，飞速扫了一眼四周，这条巷子只有前后两个出口，前口被来路堵住，后口通向市场的垃圾转运站——但对方既然从正面来，后路多半也安排了人。

“坦白说，我没打算管你。”林一凡的声音压得很低，“但你姐给了我芯片，这买卖我得做完。”

周天的嘴角扯了一下，不知是笑还是龇牙：“你知道我怎么落到何顾问手里的吗？是有人卖了情报——”

他的话被头顶窗户“哐”地推开的动静打断。两人同时抬头，二楼窗口探出半个脑袋，是刚才仓库里那个看场子的，他一眼看见墙根的两个人影，张嘴就要喊——

林一凡的手比脑子快。他从地上捏起半截碎砖，手腕一抖，砖块精准地砸在二楼窗沿，弹进室内，传来“哎哟”一声闷响，接着是玻璃碎裂的尖脆声划破寂静。

“跑。”林一凡一把拽起周天，朝垃圾转运站方向奔去。

周天被拉得一个趔趄，声音闷在胸腔里：“后头也有人——”

“我知道。”林一凡咬牙，他的视野边缘浮现出一行系统提示：【浑水摸鱼·升级版效果已激活——周围30米内监控设备与人物注意力判定失效5秒，冷却时间8分钟。】

5秒，够了。

两人冲到巷尾，铁皮垃圾箱歪斜横着，旁边是一道半人高的围墙，墙后是旧货市场货运通道。林一凡几乎是把周天整个人过墙扔了过去。落地时对方发出一声压抑的闷哼，肋骨断了的声响他听得清清楚楚。

身后的脚步声越来越近，手电光柱扫过巷口，照出他们刚才停留的位置——空了。

“人呢？”有人喊。

“分头搜！何总说了，芯片不能丢，那小子的命也要！”

林一凡从矮墙阴影里探出头，确认后续没人追来，才把视线转回瘫坐在货运通道水泥台上的周天。这人的右手不知什么时候多了道划伤，正默默地用袖子捆紧——应该是翻墙时被铁皮刮的。他心里突了一下，某种猜想迅速成形，但没来得及细想，周天就先开了口。

“芯片里有密钥的第二段——你和我姐合伙挖的这个坑，她知道，我也知道。”周天抬起那张血迹斑驳的脸，眼神却异常清明，“但我得提醒你一句：何顾问刚才打过的那个电话，对面不是钱总。是个女人。”

林一凡的手指无意识地摩挲着口袋里的芯片，声音平静得不像在问一个要命的问题：“女人？”

“声音很轻，像隔着水传过来的。”周天说，“何顾问喊她‘江小姐’。”

江。林一凡的心跳漏了半拍。江雪的布局网兜兜转转，终于开始显露出更深的轮廓——而周莉的目的，显然远不止把芯片送到他手上这么单纯。

远处忽然传来引擎轰鸣，一辆黑色商务车从货运通道入口倒切入——车窗落下，露出一张熟面孔：周莉坐在驾驶位，戴着墨镜，朝副驾驶座偏了偏头。

“上车。旧货市场的出口马上会被封死，你们只剩这一条路。”

林一凡看着周莉，又看了眼她手上那个鼓鼓囊囊的文件袋——里面装的，正是他从仓库里带出来的那台旧硬盘的接驳底座。这个女人的每一步都比他想得更深。而周天吊着半个身体靠在车门边，暗色的血迹在座椅上洇开一片，低声反问：“姐，你到底站哪边？”

周莉回头的眼神沉静得近乎悲伤：“江雪那边。”

引擎声浪在废墟般的货运通道里来回震荡，像一声无人应答的叹息。

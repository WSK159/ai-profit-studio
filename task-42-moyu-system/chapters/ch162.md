# 第162章 黑暗中的人

漆黑中，赵日天几乎是本能地喊了一声：“趴下！”

林一凡被人从侧面猛拉了一把，整个人踉跄跌进设备柜之间的缝隙里。下一秒，一道刺眼的白光从走廊尽头射过来，扫过他们刚才站的位置——不是手电筒的光，更冷，更锐，像是某种扫描射线。

“AI 巡检。”老王的声音贴着地面传过来，又低又急，"钱总把夜间巡逻的规则改了，按移动感应触发——我们刚才说话的声音把它引过来了。"

林一凡的心跳快得像擂鼓。他借着那道白光的间隙朝季敏的方向看去——她站在原地，一动不动，像是对这一切早有预料。

白光扫过她的脸，她的表情平静得诡异。

“季敏——”林一凡压低声音，“你故意的？”

“不这样，钱总的警报系统怎么会关掉呢？”季敏的声音很轻，“他今晚在顶层加班，AI 巡检启动后，手动监控反而会休眠十五分钟。这是换班的空窗期——也是唯一能安全离开地下二层的窗口。”

赵日天冷笑：“你早算好了？”

“你没资格说我。”季敏的视线冷冷地扫过赵日天，“你那套卷王系统，跟钱总的协议绑定到了什么程度，你心里比我清楚。今晚你要是还想保全你脑海里的东西，就跟我走。”

赵日天的表情一阵扭曲。林一凡头一回在他脸上同时看到愤怒和恐惧这两种情绪的交织。

白光扫完最后一个角落，通道重归黑暗。季敏率先站起身，朝走廊尽头的安全通道走去。

老王扶了林一凡一把，两个人跟上。赵日天犹豫了两秒，还是追了过来——落在队伍的最后。

安全通道的铁门虚掩着。季敏侧身挤进去，回头看了他们一眼：“到了地面上，分头走。凌晨三点，城东'不加班咖啡馆'碰头。”

她顿了顿，目光落在林一凡身上：“你有一件事要帮我做——钱总今晚会收到一封邮件，内容是你明天下午在季度会上的提案初稿。我需要你在提案里加一段数据，那组数据在……”

她报出一串数字，林一凡的脑子飞快地转——那是他们在B层数据池里抹掉的一段记录坐标。

“你什么时候弄到的？”老王皱眉。

季敏没回答，只是将那枚U盘重新放进林一凡手里：“U盘你拿着。第二把钥匙在纸上写着的地方，但——”她看了一眼老王，“你确定要让他去吗？”

老王没吭声，攥着那张纸的手却紧了几分。

林一凡看着两个人之间暗流涌动的对峙，还有站在后面始终沉默的赵日天，心头的疑问像滚水一样往外冒。他正要开口，手机突然震了一下。

他低头一看——钱总的短信又来了，这一次只有三个字，像一根钉子钉进他的眼睛：

“你输了。”

而在他回消息的那一瞬间，系统面板上浮出一行他从未见过的红字——

【隐藏任务触发：黎明前的交易。任务时限：今夜 00:00 至 05:00。任务详情：陪同老王取得第二把钥匙。当前任务状态完成后，将解锁系统第 48 层及全新剧情线。】

林一凡抬头，正好对上老王投来的复杂目光。

远处，星辰科技主楼顶层的某个窗口，灯光突然亮了。

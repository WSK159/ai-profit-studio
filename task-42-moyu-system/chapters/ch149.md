# 第149章 维修通道里的第三道门

晚上九点五十七分，林一凡站在星辰科技B3层的消防楼梯间里，手机屏幕亮着，上面是宋顾问发来的定位图。整层楼的日常办公区早已熄灯，应急灯发出惨淡的绿光，将他修长的影子拖在斑驳的墙壁上，像一条被拉长的蛇。

他在黑暗中呼出一口气，脑海里还在回放白天评审会上赵日天那张扭曲的脸。对方败得狼狈，但退场时嘴角那抹冷笑——那种“你们都会后悔”的笃定——让他心里发毛。

维修通道的门牌号从A01一路排到A07，唯独没有B3A层的标识。但林一凡在图纸上记住了位置：消防楼梯北墙，一道几乎和墙面融为一体的铁门，门牌被刷了一层厚厚的灰色油漆，只露出“B3A”三个模糊的凹痕。

“十点整。”他低声念了一句，手掌贴上冰冷的门板。

门没锁。

推开门的瞬间，一股混合着金属锈味和旧纸张霉味的气息扑面而来。通道里只有一盏昏黄的检修灯，挂在管道支架上，灯罩里积满灰尘，光照范围勉强覆盖脚前三米。两侧墙壁上钉着密密麻麻的电线桥架，地面生锈的铁板上积着薄薄一层黑灰，踩上去发出吱呀的声响。

他走了大约二十米，通道分出一个岔口，一侧通往深处更暗的隧道，另一侧则被一道新装的钢制防盗门截断。门上没有把手，只有一枚直径约两厘米的圆形锁孔，嵌在门板正中央，位置不在门锁高度，而是正对着人的胸口——和图纸上那句话完全吻合：B3A层唯一的钥匙孔不在门上。

“不在门上……那在墙上？”

林一凡蹲下身，手电扫过门框周围的墙面。在防盗门右侧约半臂距离的管道支架上，他发现了一个被焊死的小铁盒，盒盖上有一道细细的缝隙。他伸手轻轻一抠，铁盒盖板松动，里面嵌着一把老式的六角铜钥匙，油腻腻的，像是很多年没人碰过。

他正要伸手去拿，手机震了一下。宋顾问的第三条消息：“别碰钥匙。把手伸进锁孔，直接拧。”

“……拧锁孔？”林一凡眉头皱起，脑子里飞速转动。如果锁孔本身是旋钮机关，那这把钥匙就是陷阱——谁碰了钥匙，就会触发什么。他深吸一口气，把手机放回口袋，右手食指和中指探进锁孔。

冷。金属的高导热性几乎瞬间抽走了指尖的温度，猛地一股电流般的震动从手指传导到整个手臂，像被什么东西咬了一口。林一凡本能地往后缩，但锁孔里似乎有一股吸力，指节被卡住了一般。

下一秒，脚底的地面猛然下沉。他整个人跌进一个不到两平米的密闭空间，头顶的入口自动闭合——那是一台老式电梯轿厢。

轿厢内的触控屏没有楼层按钮，只显示一行字：“授权通行：摸鱼系统认证。咸鱼值余额：3847。是否支付100咸鱼值进入深层识别区？”

林一凡眼皮跳了两下。宋顾问不仅仅约他到维修通道——这家伙知道他身上有摸鱼系统。这个认知让他头皮一阵酥麻。他抬眼扫了一圈轿厢角落，发现摄像头亮着红光，正在朝他转动。

他犹豫了十秒钟，最终还是点了“确认”。

咸鱼值瞬间扣除，触控屏的画面切换成一道金属通道，轿厢开始轻微下降。大约三十秒后，门打开，露出一间约十五平米的密室。四周墙壁贴满了发黄的工程图纸和数据报表，中央摆着一张铁质办公桌，桌上放着一台老旧的终端机。

屏幕上正缓缓滚动着一行字：“欢迎来到第三道门。那个姓王的人，也来过这里。”

林一凡瞳孔骤缩。他还没来得及多做反应，终端机的屏幕右侧弹出另一行字符——加密日志里赫然写着一组坐标和一个日期：正是他被系统锁定核心功能的那一天。

钩子炸裂：他正在查看的东西，像是有人刻意留给他的“前置记录”。而这一刻，他身后那扇门，又一次悄无声息地合拢了。

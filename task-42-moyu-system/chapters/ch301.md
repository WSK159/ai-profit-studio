# 第301章 磁带里的七天

磁带被塞进老式录音机时，金属卷轴发出干涩的“咔嗒”声，像是骨头在转动。

林一凡的手指悬在播放键上，微微发抖。手术室里的冷光灯管滋滋响着，灰工装男人靠在铁椅上，被他用鞋带捆住了手腕。沈稚冬站在门口，手里的战术手电直直照着那台索尼录音机，光柱里浮着灰尘。

磁带的标签上写着一行字：“2019.6.16-7.2，别删。”

六月的空调冷风，苏婉的声音从扬声器里渗出来，带着轻微的电流杂音：

“建华，你今天说话的声音不太对。”

停顿。像是有人在等她继续，没有人接话。

“你是不是又加班了？嗓子都哑了……我今天炖了汤，你回来喝。”

又是沉默。磁带发出均匀的底噪，像雨落在旧屋顶上。忽然，一个男人的声音响起来——比苏婉的声音更闷、更扁：“嗯。加班。项目赶。”

林一凡的心猛地一沉。

那不是他父亲的声音。

至少不是他记忆里那个笑起来嗓门洪亮、说话像炒豆子一样的陈建华。

录音里苏婉又说：“明天周六，小凡说想钓鱼，你去不去？”

“去。”那个闷扁的男声答。

又是沉默。录音带“嘶嘶”地转过了三十多秒，苏婉的呼吸声变得透明，像隔着纱窗听夜风。然后她说：

“建华，你记得你答应过我什么吗？结婚那天晚上。”

长久的沉默，久到林一凡以为磁带坏了。闷扁的男声终于说：“太久了。忘了。”

苏婉“嗯”了一声，没有再说话。接着是椅子挪动的声音、脚步声，门关上了。录音带空转了将近两分钟，直到另一段录音开始——“6月17日，晚间。”

苏婉的声音带着清晰的疲惫：“建华，你今天换了一件灰工装。你的旧工装我一直收在柜子里，那件袖口缝补过，今天这件没有。”

这一次，男声沉默得更久，最后说了两个字：“洗了。”

“洗了？”苏婉的嗓音轻轻抬了一下，“那件袖口是赵姨补的，补丁线是大红色的，你从来没有让我洗掉过。”

磁带里只剩空调的嗡嗡声。然后是绳子摩擦金属的声音，什么东西被拉紧了，再松开。

“建华”开口了，声音比之前低了一度：“苏婉，你在录什么？”

一声轻响，像是有人拔掉了录音线。磁带继续转着，空白了很久。接下来是6月19日的录音，苏婉的声音更细了，带着一种近乎透明的平稳：

“建华，你早上喝粥的时候，端着碗的姿势和我认识你那年一模一样的。但你吃饭的速度变了。你以前总是第一个吃完，坐立不安地等小凡。现在，你总是最后一个。”

一声极轻的呜咽，被她压下去了：“你说小雨伞放在书房抽屉第三层。可是建华，我们搬到这个小区之后，书房抽屉从来没有第三层。”

沈稚冬的呼吸停住了一拍。林一凡靠坐在手术台边，拳头攥得发白。

磁带继续转。苏婉在6月24日的录音里说：“你昨天睡觉的时候，我坐在床边看了你很久，你没有翻身。建华睡觉喜欢侧右边。你仰躺，你根本睡不着。你只是躺在那。”

男声终于说了那段录音里的第二句话：“你太敏感了。”

苏婉的声音像一根拉满的弦：“而小凡……他问我，舅舅摘星星的项链是什么时候挂在他书包上的。他说他没有舅舅。”

磁带转了好一会儿，最后苏婉轻声说：“建华，我不问你从哪来。我只想问，原来的建华去了哪？”

磁带在这句话之后，戛然而止。录音机的计数器停在了“47”。

手术室里安静得像坟地。沈稚冬的战术手电晃了一下，移开，又移回来：“她早就知道。”

林一凡慢慢抬头，眼眶通红：“从第一天就知道。”

灰工装男人忽然笑了。不是那种幸灾乐祸的笑，是一种苦涩的、从嗓子眼里挤出来的笑：“苏婉是我遇到过的最高明的记录者。她录了七天，不是为了留在家里——她把那盘磁带藏在这间地下室，等你来找。”

他顿了顿：“她一直在给你留路。”

林一凡猛地看向他：“你认识我妈？”

灰工装男人的目光穿过光柱，落在那把镜像三叉钥匙上：“002把你送到太平间那晚，是我抱你出来的。”

# 第426章 门内门外

林一凡攥紧手中的27号陶土徽章，指节发白。小石室里的空气凝滞如胶，矮几上的粗瓷碗边缘，一圈干涸的暗褐色痕迹像是某种古老宣誓的残留。油灯的光在墙壁上拖曳，将门内那道自称“父亲”的人影拉长成一道扭曲的黑。

“你不信。”门内的声音沙哑而笃定，像是砂纸磨过陈年木料，带着一种令人无法忽视的疲惫，“三十年了，我在这里面数自己的心跳，等着有人拿钥匙来开这扇门。”

“你说这不是钥匙，是锁。”林一凡的声音出乎意料地平静，尽管他后脊的汗已经把衬衫洇透——他注意到对方说“钥匙”这个词时，目光垂向地面，像在回避什么，“锁是用来关的东西，不是用来开的。”

门内的“父亲”沉默了一会儿。矮几上那坛陶土酒坛忽然发出“啵”的一声轻响，像是封泥在热胀冷缩中松动。林一凡下意识后退半步，后背撞上冰冷的石壁，震得墙上扑簌簌落下几粒灰。

“你母亲是个聪明人。”门内人终于开口，声音里带上一丝笑纹，但那笑意如同冻裂的河面，“她把我关进来的时候，告诉我一句话——‘凡儿若来，你什么都不用说。他把徽章放进凹槽的那一刻，你就自由了。’”

林一凡的瞳孔微缩。

母亲的话？她料到他会来？

“可她没料到一件事。”门内人缓缓从阴影中走出半步。油灯光芒照亮他半张脸——那是一张与林一凡有几分相似的轮廓，颧骨高耸，眼窝凹陷，嘴角有一道旧疤。但林一凡注意到，那道疤的位置，和门外那个“老杨头大哥”嘴边的疤，一模一样。

“她把徽章给你，是用错了。”门内人抬起手，指尖沾着灰白色的粉末——陶土珠的粉末，“那枚徽章里嵌的是镇魂钉，钉的是锁芯。你把它放进去，锁芯就彻底死死了。这扇门，永远打不开了。”

林一凡低头看向手中的徽章，指腹在背面摸索。他之前只注意到正面的纹章图案，此刻才感觉到背面有一道极细微的凹痕——不是铸造，而是后天刻上去的，像是一个“沈”字的上半部分。

他忽然想起赵日天笔记本上那句残句：“七纹踏斗，入门见父。父不在门内，父在门外。”

门外？

他猛地回头，看向身后的台阶。十三级台阶尽头，那扇铜门不知何时已经合拢。门缝里，一双灰白色的陶土珠眼睛正静静望着他——不是老杨头大哥，那双眼睛更小，更圆，像是嵌在一张干枯脸上仅存的活物。

“别回头。”门内人的声音忽然变了，变得急促而尖锐，“别看门外！”

但林一凡已经看见了。

门缝外的那双眼睛缓缓眨了一下——灰白色的陶土珠没有眼皮，但那双眼睛确实眨动了。随即，它向旁边移动了半寸，露出半张脸。那张脸的轮廓，和林一凡身后门内那个“父亲”，一模一样。

“门外站着的也是我。”门内人的声音恢复了平静，带着一种彻骨的寒，“你手里那枚徽章，原本是两枚。一枚在门外，一枚在门内。你母亲把门外那枚挖出来给了你，因为她知道，门外那个……不是人。”

林一凡的手心沁出冷汗。他攥紧徽章后退，却发现脚下的石板在松动。矮几上那只陶土酒坛的坛口，裂隙正以肉眼可见的速度蔓延，像是某种被压抑太久的东西正在苏醒。

坛身忽然裂开一道口，一张卷起的纸条从裂缝中滑落，滚到他脚边。林一凡低头去看，纸条上只写了一行字，墨迹新鲜，像是刚刚写就：

**“他在坛子里住了三十年。你手里的徽章，是给他续命的。”**

林一凡猛地抬头，门内的“父亲”已经退回阴影中。而坛口的裂隙里，一只苍白的手正缓缓伸出来，指尖沾着干涸的暗红色——那不是陶土的颜色。

“你是……哪个？”林一凡的声音有些干涩。

门内没有回答。那只手一点点攀住坛沿，指节分明，腕上系着一根褪色的红绳——与他父亲临死前手腕上那根红绳，一模一样。

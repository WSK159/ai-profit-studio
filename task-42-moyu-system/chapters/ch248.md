# 第248章 铜铃自响

铜铃的响声在密室中回荡，像是有人在黑暗深处摇着它，不紧不慢，一下，又一下。那声音从密室尽头的墙壁里透出来，隔着一层混凝土，闷闷的，却又清晰得让人头皮发麻。

林一凡手里的黄铜钥匙还没放下，他盯着那面墙，低声道：“声音是从墙后面传来的？”

老王咽了口唾沫，把锈死的挂灯残骸丢到脚边，搓了搓手上的铁锈：“这间密室……后面还有空间？”

陈默没有回答。他蹲在防水箱旁边，手里握着那盒最早的录音带，借着手机屏幕的微光，反复看背面的钢针小字。那字迹已经氧化发黑，但笔画依旧清晰：**“如果他们找到这里，说明我已经不在了。但我不在，不代表我死了。”**

铜铃又响了一声，比刚才更近。

赵日天从角落里站直身子，他刚才一直在检查密室顶部那些裸露的管线，此刻拍了拍手上的灰，语气淡漠：“这密室不是尽头。通风管道、水管、还有这条铜线——都是通向后墙的。后面有空间，而且不小。”

“你怎么知道？”老王问。

赵日天指了指墙角的铜线：“因为这条线的走向不是接进墙里的，它是穿过去的。穿过去之后，还在走。”

林一凡走到他指的位置，蹲下来看。那根铜线一路沿地面延伸，钻进密室后墙的一个小孔里，孔洞边缘光滑，像是专门凿出来的。线的表面有一层浅浅的绿锈，和地上一层淡得几乎看不见的铜锈轨迹完全重合，一直通向后墙正中偏左的位置。

“铜线变绿的地方……”林一凡念叨着陈建国的遗言，目光落在后墙那片区域上。

那里有一个不起眼的凸起，像是施工时留下的水泥包浆。他伸手按了一下，水泥表面裂开一道缝，露出下面一块巴掌大小的暗门。暗门上没有锁，只有一个小小的铜环，浸在一层灰绿色的氧化物里。

铜铃的声音，就是从这扇暗门后面传来的。

陈默这时终于放下录音带，走过来把那块暗门拨开。门后是一条狭窄的通道，只能容一人侧身通过，墙上每隔三米嵌着一盏昏黄的应急灯——灯还亮着，说明供电还在。

“你父亲……”林一凡低声问，“他把路留到了这里？”

陈默没有接话，侧身挤进了通道。

林一凡和老王交换了一个眼神，跟了进去。赵日天走在最后，嘴角微微动了一下，像是想说什么，又忍住了。

通道不长，大约走了十五米就到了尽头。尽头是一个圆形的小房间，空间大约只有十个平方，地面铺着防水布，四角压着膨胀螺栓。房间里没有别的东西，只有正中央的一口铁皮箱子，用三道锁扣扣得死死的。

而箱盖上面，放着一只铜铃。

铜铃不大，巴掌般高，表面带着一层深绿锈色，铃身上刻着一行小字。那行字在应急灯的照耀下反着微光，林一凡凑近去看，心猛地一沉：

**“陈建国，生于1985年3月14日，卒于——未定。”**

“什么叫‘卒于未定’？”老王倒吸一口气。

陈默伸出手，把铜铃从箱盖上拿起来。铜铃下方压着一张折叠的白纸，他展开那张纸，上面只有一行字：

**“把铜铃挂回原来的位置。它会告诉你我为什么不在这里。”**

“原来的位置？”赵日天皱眉，“原来的位置是哪里？”

铜铃在陈默手掌里，轻轻震了一下。

不是错觉。林一凡看得清楚，那铜铃的铃舌在没有任何外力的情况下，自己晃动了一下，发出一声微弱的“叮”。

然后又是一声。

接着，像是某种开关被打开一样，铜铃在陈默手里剧烈震颤起来，铃声响成一片，在圆形小房间里炸开，刺得三个人同时捂住了耳朵。陈默下意识松手，铜铃却没掉在地上，而是悬浮在掌心上方的半空中，铃口朝下，逐渐转向一个方向——朝着密室来时的方向，偏右三十度。

那个方向，在负六层的平面图上，对应的是配电井的位置。

“它在指路。”林一凡盯着那只悬浮的铜铃，瞳孔微缩，“它在指……配电井那边。”

陈默缓缓把铜铃收了回来，铃声立刻停了，像是从未响过。他把铜铃放进外套内侧的口袋里，手指在口袋里轻轻摩挲着铃身，表情晦暗不明。

“配电井那边，还有一个我们没去过的地方。”他说。

老王看看他，又看看林一凡，咽了口唾沫：“那我们还回去？”

林一凡沉默了两秒，目光落在铁皮箱子三道锁扣上：“先打开这个箱子再说。既然钥匙就在我们手里——不能白来一趟。”

他从口袋里掏出那把黄铜钥匙，钥匙齿上还沾着挂灯里的铁锈。他把钥匙插进第一道锁扣的锁孔，试了一下，纹丝不动。又试第二道，还是不行。最后一道，锁孔的形状明显不同——不是黄铜钥匙能开的。

“第一道锁是钥匙，第二道……”陈默说着，从口袋里摸出那枚徽章，拨动了一下侧面的拨片，发出清脆的“咔嗒”声，“是信号。”

他把徽章贴到第二道锁扣的凹槽上，锁扣内部发出极其细微的电流声。绿灯亮起——锁扣自己弹开了。

第三道锁扣上没有任何锁孔，只有一行刻上去的小字：**“这道锁没有钥匙。它的钥匙在第一个挂钟里。”**

林一凡盯着那行字，感觉后背一阵发凉。第一个挂钟——那是他重生那天，在公司三楼走廊尽头看见的那座老挂钟。他一直以为那是装饰品。

“这个箱子……”他缓缓开口，“我们得先回公司三楼。”

陈默沉默了几秒，把徽章收回口袋里，点了点头。

三人沿原路返回配电井时，没有人再说话。密室的深处，铜铃的余音仿佛还在墙壁里滚动，一声接一声，像是在等待他们走远，又像是在催促他们回头。

而配电井的暗门重新合上那一刻，林一凡突然停住了脚步，他仔细看了一眼井壁上那根冰冷的铜线。

铜线上，多了一道全新的、深到几乎断裂的刮痕。像是什么东西，刚刚从那上面擦了过去。

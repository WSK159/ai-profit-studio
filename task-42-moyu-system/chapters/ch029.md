# 第29章 反击：全网爆火的摸鱼宣言

创投论坛的地下停车场，林一凡看了看表——下午两点四十七分，距离他的三分钟发言还有十三分钟。手机震个不停，全是推送：全华网置顶头条《行业公敌：某程序员抄袭摸鱼管理法遭三方围剿》，底下评论区炸了锅。

“这种人还有脸出来？谁录用他我跟谁急。”

“抄袭狗滚出IT圈！”

他往下翻了几页，零星几条替他说话的很快被淹没。钱总的舆论机器开得很足，全华网、极速未来、蓝桥科技的官微同时转发封杀令，节奏带得飞起。

林一凡锁了屏，深呼吸。

老王的电话打进来：“一凡，你在哪儿？钱总刚才给论坛组委会打了电话——他要取消你的发言资格！”

“我知道。”林一凡的声音意外的平静，“所以我已经提前到了。”

论坛二楼主会场入口处，两个保安已经站在闸机两侧。一个西装男人站在旁边打电话，林一凡认识那背影——钱总的秘书，刘洋。他正对电话那头说：“对，就是这个叫林一凡的，把他拦下来，组委会这边已经打过招呼了……”

三分钟讲话要泡汤？

老王在电话里急得冒汗：“要不咱换个别的地方？我帮你联系几个自媒体……”

“老规矩。”林一凡站在三楼消防通道口，从兜里掏出一个充电宝大小的东西——一个带全息投影功能的迷你直播设备，是他昨天用500咸鱼值解锁的“全民直播套装”，硬件只有拇指大小，接收器是一台旧平板。“三分钟不是给台下那几百人听的，是给全网听的。”

他走到主会场外的消防通道尽头，推开门——那里正好能看到主舞台的侧后方，一块LED大屏幕实时投着台上嘉宾的演讲画面。他蹲下身，把直播设备贴在消防通道门上方的通风口处，镜头正好对准大屏幕。

直播启动。

标题：《真相：一个被996杀死两次的程序员》

开播三分钟，几百个陌生人涌进来。全华网的封杀报道还在热搜上挂着，网友顺着推文点进直播间，弹幕飘起一片问号：“这是谁？”“那个被封杀的？”“都这时候了还敢直播？”

林一凡没露脸，只有声音：“我是一名程序员，去年6月，我连加三个月班，第七天凌晨三点，心梗，当场死了。不是形容词，是真的死了。”

弹幕瞬间安静。

“我活过来了。那天起我就想——凭什么我们活得像垃圾一样？我决定每天摸摸鱼，把摸鱼的时间拿来学真正有用的东西。我研究出一套工作法，也就是你们在新闻里看到的‘摸鱼工作法’。谁发明的？我。全华网说我抄他们的？把他们的原文放出来对比看看。”

他停了三秒。“全华网发布了《高效能管理白皮书》，发布日上个月，我公开方法论三个月前。谁抄谁的，傻子都看得出来。”

弹幕炸了：“卧槽真的假的！”“翻了下时间线，确实是他先发的！”

这一炮，直接把直播间炸上了平台热搜位。

手机屏幕上，观看人数从几千跳到五万、十万、三十万。评论区一片倒戈——有人开始艾特全华网官微：“打脸不？”“封杀的是别人，抄别人的是你们自己吧！”

林一凡趁热追击：“今天，我们老板钱总，把我赶出公司，联合三家‘兄弟公司’封杀我，罪名？没罪名。拒绝把方案署他们名，就是最大的罪。”

三分钟到了。

他没停，声音反而更稳：“从今天起，我的‘摸鱼工作法’所有细节免费公开，谁要学谁学，不收一分钱。我不怕抄，我就怕大家都不会抄。”

平板屏幕弹出一条系统通知：

【咸鱼值+5000，触发隐藏奖励：全网曝光增益×5】

直播间还在涨。他已经把直播关了。他站起来，拍掉裤腿上的灰，转身——老王从消防通道另一端跑过来，满头汗：“你……你刚才在干啥？！”

“干了件大事。”他嘴角挑了挑。

手机狂震。一条陌生企业邮箱陌生邮件的标题跳出来——

“林一凡你好，我是深海资本的投资经理，看完你的直播了。明天有空聊聊吗？我们对‘摸鱼工作法’很有兴趣。”

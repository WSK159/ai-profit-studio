# 第140章 被念名字的人

第二天早晨，林一凡到公司比平时早了二十分钟。他没去工位，直接拐进茶水间倒了一杯黑咖啡，蹲在窗边看着楼下的人流。老王昨晚那条微信他翻来覆去看了十几遍，总觉得那句话有点不对劲——“有人念我名字”这种说法，不像老王平时的语气。

八点零七分，老王推门进来，顶着两个明显的黑眼圈，但精神反而亢奋得出奇。他看见林一凡就咧嘴笑：“一凡，我昨晚上做了个梦，梦见咱们部门评了个‘年度效率之星’，奖金十万，钱总亲手发的奖状。”

林一凡看着老王眼里那层不太正常的亮光，心里一沉。前世的记忆里，老王在裁员潮后被钱总用“精神激励法”管理了半年，最后整个人被掏空，住院治了三个月才缓过来。眼下老王这副打了鸡血的状态，跟那段时间实在太像了。

“老王，你昨晚几点睡的？”林一凡不动声色地问。

“一点多吧，睡不着，起来改了改项目进度表，嘿，一改就改到三点。”老王挠头笑了笑，“也不知道咋回事，脑子越用越清醒。”

林一凡没接话，他从口袋里摸出那枚银色钥匙，在指间转了半圈，目光掠过老王的脸，落在老王左耳后方——那里有一条极细的浅红色纹路，像一道没结痂的划痕，正常人看不出来，但林一凡重生后眼神好得出奇。他记得前世老王做过一次皮肤小手术，位置就在左耳后方，当时老王还打趣说“这是工伤，天天戴耳机戴出来的”。

但他没动声色，只说：“项目进度表我帮你看看，你先去把早饭吃了。”老王乐呵呵地走了。林一凡转头回到工位，把钥匙锁进抽屉，然后打开电脑，调出星辰科技企业办公系统的后台日志查询页。

他输入账号密码，进入权限范围内的值班日志查询，搜“地下空间”“B3”“检修井”三个关键词。跳出来的结果不多，但有一条引起了他的注意——三年前的12月17日，安保部提交过一次“地下三层阻尼器检修井异常响声”的巡检单，处理意见栏写着一句话：“经检查为管道气流声音，建议在井口加装隔音棉，已执行。”

处理人签名：钱国豪。

林一凡的手指顿在键盘上，钱国豪三年前就在处理B3层的事了。他刚想点开附件看看巡检照片，肩膀猛地被人拍了一下。他回头，赵日天那张圆脸怼到面前，笑得不阴不阳：“林组长，早上好啊，这么早就来查资料？别告诉我你在摸鱼。”

林一凡不动声色地把网页最小化，转头看了赵日天一眼：“卷王今天怎么有空来串门，你的AI考核数据不用刷了？”

赵日天脸上的笑容僵了一下，随即压低声音凑过来：“林一凡，我哥昨晚是不是来找你了？”他盯着林一凡的眼睛，语气里罕见地有一丝认真，“他是来找你帮忙的，不是来找你麻烦的。”

林一凡挑眉：“你哥需要我帮什么忙？”

赵日天沉默了两秒，往后靠了靠，声音比刚才更轻：“三年了，他一直在找一把钥匙——那是我爸留下的遗物，据说和华夏金融中心地下某个地方有关。昨晚他说钥匙找到了，但被人抢先拿走了。”

林一凡的指尖微微收紧。那把银钥匙现在正躺在他抽屉里。

“他不知道是谁拿走的？”林一凡问。

赵日天摇摇头：“他说对方戴着手套，看不清。”他顿了顿，补了一句，“但他让我带句话给你——‘那枚钥匙如果在你手上，别急着用。开锁的瞬间，会有人醒来。’”

说完，赵日天转身走了。林一凡盯着他背影片刻，然后重新打开那个网页，点开附件里的巡检照片。照片拍的是检修井口，角度歪斜，但井盖边缘露出一角——那不是普通的水泥井盖，而是一块金属板，上面刻着一个极其模糊的图案，在昏暗灯光下几乎看不清。

林一凡放大图片，瞳孔微微一缩。

那个图案，和名片上的钥匙标志一模一样。他低下头，手机屏幕亮起，一条未读短信静静躺在通知栏里，号码是00042，发信人未知。短信只有六个字：“今晚十二点，B3。”

他的后背一阵发麻。那把钥匙还在抽屉里，但开锁的人已经等不及了。

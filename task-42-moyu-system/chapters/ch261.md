# 第261章 死亡笔记

密室里的白炽灯管在头顶嗡嗡响着，像是某个老旧的服务器机柜。林一凡的手指按在那本笔记本的封皮上，皮面微凉，带着某种粗糙的颗粒感，仿佛被无数双手翻过。

“这句话是什么意思？”他抬起眼看向陈和平，“什么叫‘死了两次。第三次不能死’？”

陈和平靠在角落里一张褪色的折叠椅上，他看起来精神矍铄，跟这间布满灰尘的密室格格不入。他没有直接回答，反而问道：“你重生那天，是2026年几月几号？”

“6月15号，入职第一天。”林一凡脱口而出，旋即怔住。他仔细回想了一下，那些记忆仿佛隔着一层磨砂玻璃，“我是从公司睡醒的，入职手续、门禁卡、电脑分配……都顺理成章。”

“顺理成章就不该是顺理成章的。”陈和平缓缓站起来，走到墙壁边，那里挂着一块白板，上面贴着一排斑驳的名片，“你入职编号是多少？”

“A-1042。”

陈和平伸出手，取下白板上第1042枚图钉——那里空空如也，什么名片都没有。但他的手指却精准地按在那个位置，轻声说：“你知道这一排名片是什么吗？”

林一凡凑近看了看，那些名片上都印着同一个名字：陈重阳。但每一张的职务不同——快递员、外卖员、保安、打印店店员、网约车司机、展会推销员……

“他换过这么多工作？”林一凡皱眉。

“不。”陈和平摇头，嘴角带着一丝苦涩，“这些是他死过的次数。每一次他换了身份，就是为了靠近你。2019年他第一次以‘陈重阳’这个名字出现在你身边的时候，是个外卖员。你那时还在上个公司加班，每天凌晨两点点一碗麻辣烫。”

林一凡头皮一阵发麻。麻辣烫。他确实连续吃了三个月的那家店，老板总在袋子里多放一根烤肠。那个外卖员……从来都是低着头，把袋子递过来就走，背影瘦削，走路总有一只脚稍微跛着。

“你说他死了？那为什么2026年我又见到他了？”林一凡把笔记本攥得更紧了，“今天上午他还给我一把三叉钥匙，让我去钥匙井——”

“你第一次见到的陈重阳，不是同一个陈重阳。”陈和平的声音极轻，却像锤子砸在林一凡胸口，“他死了两次。第二次死在2019年的12月31日。你记得那天吗？”

林一凡的瞳孔骤然收缩。2019年12月31日，跨年夜。那天他没回家，一个人在公司改bug，改到夜里十一点半，屏幕上那个报错的日志终于通过。他困得不行，趴在桌上睡了一觉。醒来时已经是2020年1月1日凌晨，手机上有17条未接来电，全是公司老板打来的。他以为是让他去加班，没回。

“那天——”他喉头发涩，“那天怎么了？”

“你死了。”陈和平盯着他，“你在那个跨年夜猝死在工位上。心脏骤停。”

林一凡的后背撞上墙壁，发出沉闷的响。他低头看了一眼自己的手，白白净净的指节还能灵活动弹，但那种窒息感仿佛从记忆深处冒了出来——他确实记得那个夜里，胸口猛地一阵剧痛，接着是黑暗。可那明明是他重生前、2026年死前才有的记忆。

“等等……你是说我在2019年就猝死过一次？”

“是。那次陈重阳用了001号卡里的筹码，用他在那个赌局中赢来的一条命，把你的命换了回来。代价是他自身的‘死亡’——他的命数彻底清零。”陈和平从怀里掏出一个古旧的铜制罗盘，指针正在飞速旋转，像被无形的磁场搅动，“但你重生的‘入职第一天’，是在2026年6月15日。从2019年到2026年间，有整整七年的空白。”

“可我明明记得这七年里发生过的事——”林一凡猛地停住，“我的记忆……是假的？”

“不是假的。是借来的。”陈和平叹了口气，“001号卡不仅换了你的命，还借了陈重阳一生中最后七年的记忆替你填补了那段空白。你所以为的‘前世三年996’，其实就是他在你身边以各种身份活着、观察你、保护你的那些日子。”

林一凡低头死死地盯着笔记本。他翻到第二页，上面只有一行字——“找到009号钥匙，打开墙后面的门。门后面是还债的地方。”那字迹潦草、急促，像是写在一场剧烈的头痛中。

“墙后面的门？”林一凡抬头看向陈和平。

陈和平慢慢转身，走到密室的西面墙壁前，把手掌按在墙上。哗啦一声，整面墙竟然缓缓裂开一条缝——墙后不是水泥，而是一扇锈迹斑斑的黑色铁门。门把手上挂着一把铜锁，锁孔的形状，分明就是三叉钥匙的轮廓。

“我在这里等了你二十年。”陈和平回头，眼中闪着复杂的光，“等的就是这一天。009号钥匙……就在你手里。”

林一凡猛地把手伸进兜里——三叉钥匙冰凉的触感还在。他紧紧握住那枚钥匙，指尖微微颤抖：“你是说……我就是那个被选中的‘还债人’？”

陈和平没有回答。他的目光越过林一凡，看向门口。密室的铁门外，传来一阵极轻极轻的脚步声，像猫一样。紧接着是一声低低的冷笑。

“林组长，”王姐的声音从门外飘来，“你该不会真以为……那本笔记本的最后一页，是空白吧？”

林一凡翻到笔记本最后一页。那上面不是空白，而是一行极细的字，像是用指甲划出来的：

“009号钥匙的抵押品——是你这辈子的命。打开门，就再也回不去了。”

他的手僵在半空中。门外，王姐的脚步声渐行渐远。

# 第412章 锁孔里的呼吸

铜门合拢的声音像一节骨头被掰断，干脆得让人牙酸。林一凡盯着面前那张脸，老杨头大哥——或者说，顶着他以为的老杨头大哥的脸——嘴角扯着一道不大自然的弧度。

“第九次，你终于认出我了。”

话音落地，通道里那两根青铜钉已经不在脚边了。沈望未白刚才扔出去的那把铜钥匙，此刻就躺在他自己脚前半尺的位置，黑发缠成的线圈松了一截，陶土珠滚到灰尘里，露出模糊的“28”。

林一凡没有弯腰去捡。他右手还攥着那根铁芯——刻着“林一凡”三个字的铁芯，指腹能摸到背面新增的刻痕，字形浅却深，像有人用指甲蘸着某种东西刻上去的。“白骨”两个字在纹章边缘盘旋，他不确定那是警告还是记录。

“老王。”他叫出这两个字，声音不高不低，却让老杨头大哥的左眼皮跳了一下。他继续说：“门里那个不是你。你也不是老杨头。那你是从什么时候开始——”

“从你第一次站在归墟边缘的时候。”老杨头大哥打断他，背在身后的手慢慢放下来，腕骨上露出一圈细得几乎看不见的旧绳印，和门内那具半腐烂躯体上系的红绳同一种颜色，暗得发棕。“你以为你摸鱼是第一天？你重生那天，摸到的第一条鱼，就是从门缝里漏出来的。”

林一凡呼吸顿了一瞬。系统的声音安静得像死了，那面板上连个闪烁都没有。他说：“系统是你给的？”

“系统是赌局。我只是那个发牌的人。”老杨头大哥向前一步，脚下的灰土凝成一个浅浅的脚印，轮廓像一只没有脚的鸟。“钱方远在门那边听了九年，他以为他赢了三次。但你看看你那根钉上刻着什么——‘债务转置·丙区四号’，那是他的债务，不是你的。你转置了它，所以他现在替你在门里听。”

“所以赵日天换命——”

“换的是钱总。”老杨头大哥点头，露出一个近乎慈祥的疲态，“那小子可以啊，卷到头了，终于学会不卷别人了。他把自己的最后一条命转给了钱方远。现在你欠他的，已经不是命了。”

林一凡没有立刻接话。他把铁芯翻转过来，对着通道顶部的光——那光源找不到，像从墙缝里渗出来的。

“你刚才说，第九次。前面八次，我都是怎么死的？”

老杨头大哥没有回答。他身后那道铜门，突然从门缝里传出一声呼吸——湿的，慢的，像肺里灌满了水。林一凡浑身一紧，因为他认得那呼吸的频率，跟他在“摸鱼空间”里打盹时听到的某个节拍一模一样。

那是老王的。

“别回头。”老杨头大哥说：“她让你别用钉，你用了，所以你还没死。但你要是回头看门缝——”

铜门发出一声沉闷的嗡鸣，门缝里滚出一颗陶土珠，上面刻着“27”。珠子滚到林一凡脚边，停住。他低头看，珠子上还沾着一点热乎的唾沫。

老杨头大哥的脸色变了。他蹲下去捡珠子，手指刚碰到，那道门缝又“咔”地裂开一丝——一只骨节粗大的手伸出半截，掌心朝上，托着一根红绳。红绳末端系着一颗珠子，刻着“27”。

“拿回去。”门里的声音低沉，像老王又不像老王，“你认错了人，它认的是你。”

林一凡没有动。他盯着红绳末端那颗珠子——他之前在齐磊桌上见过一模一样的照片。“这是什么？”

“老王的命牌。”老杨头大哥的声音突然哑了，他站起来时膝盖发出一声老化的脆响，“你拿起来，他就活。你不拿，门里的东西今晚就会吸干他的最后一口气——然后再来吸你的。你自己选。”

通道远处，突然传来第四声脚步。比之前的三道影子都轻，但踩在灰尘上的声音像是用蹄子踩的。林一凡握着铁芯，指节发白。他忽然想起一件事——系统的“摸鱼雷达”，在刚才那一瞬间，显示出了一个他从未见过的读条：

“对方摸鱼时长：九世。”

那串数字正在跳动，变成十。第十世。门里的呼吸声，停了。

林一凡抬头看向老杨头大哥——不，看向那张脸上不属于老杨头的轮廓，问出一个他早该问的问题：“九年前站在铜门外的第一个人，才是你。对吧？”

老杨头大哥没有承认，也没有否认。他只是说：“你还有三秒钟。”

林一凡把铁芯插回口袋，弯腰，捡起了那颗“27”。

珠子触到掌心的瞬间，他无名指上的陶土色纹章烫得像烧红的铁皮。门缝里传来一声低低的笑，像老王的，又像他自己的。铜门缓缓合拢，门轴吱呀一声，像喘了九年的最后一口气。

“——第二根钉，该用了。”

老杨头大哥的话音从身后飘过来，林一凡没有回头，但他看到了那根刻着“沈望未白”的青铜钉，不知何时出现在他脚前，钉尖朝上——像等了他许久。

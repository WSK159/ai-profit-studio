# 第415章 钥匙在我心里

纸条上的墨迹已经泛黄发脆，像是几十年前的旧物。林一凡指尖轻轻捻着纸角，目光死死钉在那幅简笔画上——一个人跪在门前，手臂伸向锁孔，旁边一行小字：“钥匙不在锁孔里。钥匙在我心里。”

“烧掉它。”坛中人的声音再度响起，沙哑而急切，“立刻烧掉。”

林一凡没有动。他抬头看向矮几对面那只垂落的苍白手臂，红绳缠在腕上，颜色已经褪成近乎粉色。他问：“这纸条是谁写的？”

沉默。片刻之后，坛中人低声道：“是我。”

“那跪在门前的人呢？”

“也是我。”

林一凡盯着那只手：“你被锁在里面多久了？”

坛中人的呼吸声粗重起来，仿佛那具残破的躯体还能感受到某种情绪。半晌，他说：“我记不清了。我只记得，那扇门关上之前，我把这纸条塞出门缝，希望有人能看见它。”

“你把它塞出门缝，又让我把它烧掉？”林一凡眯起眼睛，“前后矛盾。”

坛中人沉默得更久。窗外灰白的光线从头顶铜丝环附近渗下来，林一凡注意到那枚灰色小球还在轻轻晃动，像是被什么气流推动。

“因为……我原先以为你能打开那扇锁。”坛中人的声音低下去，“可你不是他。你只是长得像。”

“像谁？”

“像我自己。”坛中人抬起手臂，苍白的手指微微颤抖，“像三十年前的我。”

林一凡心头一紧。他想起父亲临终前那颗烟头、那根红绳、那个没说完的句子——“你妈说……锁是护你的，不是困你的……”他感觉真相已经近在咫尺，却又像隔着一层厚厚的陶土壳。

“你叫什么名字？”林一凡追问。

坛中人忽然剧烈咳嗽起来，整个陶土坛身都在震动，裂口处又掉下几片陶土碎屑。他咳了好一阵才止住，声音变得断断续续：“我、我已经忘了。我只记得，他们叫我‘门卫’。”

门卫。

林一凡脑子里嗡的一声。他想起了摸鱼空间那扇铁皮门内侧刻着的两个歪歪扭扭的字。那两个字后来被铁锈糊得几乎看不清，但他认得出来——正是“门卫”。

“你认识摸鱼空间里那扇铁皮门？”林一凡的声音有些发紧。

坛中人没有回答，那只苍白的手缓缓收回坛内，像是耗尽了力气。与此同时，台阶尽头的铜门缝隙处，那只灰白陶土珠眼睛微微转动了一下，突然向后退去，消失在门缝外一片模糊的光影之中。

林一凡心里咯噔一声。门外那东西动了。

“它退开了，”他低声说，“门缝外的眼睛——退了。”

坛死寂了数息，刚才的声音又响起来，这一次显得急切而清晰：“它退开的时候，就是门缝最宽的时候。年轻人，你现在出去，别回头，别关门。”

林一凡盯着矮几上那坛裂开的东西，又看了一眼手中的纸条。纸条上的画还在眼前——人跪门前，手臂伸向锁孔。他突然悟了。

“钥匙在我心里”不是指真的钥匙。“它”是指——某种选择。他放下了纸条，转身走向台阶。十三级石阶，他迈步而上，每一步都踩在吱呀作响的青铜地面上。台阶尽头的铜门缝里，灰白的光透进来，没有了那双眼睛的阻挡。门缝果然比之前宽了一指左右，足够他侧身挤出去。

他没有回头。他侧着肩贴住铜门边缘，顺着门缝挤出了那道沉重的青铜门。身后的暗门边，他摸到那个凹槽还在，27号徽章已经被取走了，凹槽里空荡荡的。他伸手摸了一把袋中——那枚徽章还躺在里头。他刚掏出徽章想重新放回去，忽然听到门缝里传来一声极轻的笑。

是坛中人的声音——却带着一种说不出的释然与苍凉：“锁芯里的钥匙，从来只有一枚。你带走了那枚锁，就带走了钥匙。”

他还没来得及追问，头顶忽然传来“咚咚咚”三声闷响，有人在用什么东西敲击石室顶壁的青铜层。林一凡抬头，看见头顶一处接缝处，竟然透进来一束微弱的手电光。

“林一凡！”一个压低的声音从上方传来，是他从未听过的女声，“你是不是在下面？回答我！”

林一凡的心脏猛地一跳。他攥紧手中的青铜徽章，指尖触摸到徽章背面一道细密的纹路。

他翻过徽章来看了一眼，瞳孔骤缩——那纹路他之前在凹槽里见过，是一道只有指甲盖大小的刻痕，他当时以为是铸造瑕疵，没有在意。此刻在昏暗的光线下，那道刻痕的纹路轮廓清晰起来。

那是一个汉字，笔画极细极浅，像是用针尖刻上去的——“父”。

他的手微微发抖。他想起父亲临死前攥住他的手时说的最后一句话，那句没来得及说完的话：“我留了一把钥匙，在锁孔里……不在门那一边……在你妈铸锁用的那坛土里——”

耳边又传来三声急促敲击，那道女声再次传来：“快点！我撑不住这层青铜板，最多还有半分钟——”

林一凡把徽章塞回怀中，深吸一口气，朝头顶的那道光线冲去。他来不及细想坛中人那句“别回头”的含义。他不知道这个女声是谁，也来不及判断敌友。他只知道——他攥在手心里的那枚徽章上，刻着一个“父”字。而刻了这个字的人，一定是他父亲。父亲来过这里。父亲留下过钥匙。

父亲说过，锁是护他的。
但锁孔里那枚钥匙，究竟是锁住谁的？

他跃身而起，手掌抓住那道光线的边缘。在他双手攀上青铜接缝的那一刻，他身后那扇暗门无声无息地合拢了，缝隙中最后一缕灰白光线也随之熄灭。

黑暗吞没了一切，只剩下头顶那道越来越亮的手电光，和那句从未听过的女声：“你带着锁下来的？那你一定见过‘门卫’了——跟我走，来不及解释了。他们有东西盯上你了。”

她话音未落，林一凡已经隐约听到了远处传来的一阵细碎的、像是泥土摩擦般的脚步声——但那脚步声不是在走。那声音仿佛是从地底深处传来的。他低头看向自己刚爬出来的那层青铜板下方，看见接缝处渗出了一缕灰白色的陶土细粉，正顺着缝隙缓缓流淌，像是某种东西正在从下面追上来。

而那陶土细粉中，混着一根褪色的红绳。

林一凡感觉后脊一股凉意直冲天灵盖。他没有犹豫，跟着那道手电光钻进了狭窄的通道深处。

他不知道的是，在他身后的青铜接缝完全合拢的最后一刻，那根红绳从陶土细粉中缓缓抽了出来，像一只活物般瞬间缩入黑暗之中。

而在那扇彻底闭合的暗门内侧，那张矮几上的陶土坛安静的裂着。坛口伸出的那只苍白手掌，此刻正轻轻握着一团揉皱的黄纸——林一凡没有烧掉的那张纸条。

坛中人低头看着纸条上那句“钥匙在我心里”，忽然笑了。他从怀里取出一枚灰白色陶土珠，珠子表面光滑无字，只在他指腹间微微发光。他用指腹抹过珠子表面，陶土簌簌脱落露出一道刻痕。

那道刻痕与林一凡手中徽章上的“父”字分明是同一种笔迹——但那不是“父”字，而是一个被刻意拆开的“锁”字。锁字左边是“钅”旁，右边是“所”。所字中间，藏着一个小小的“人”字。

“钥匙的确不在锁孔里。”坛中人把珠子贴近胸口，声音碎在空气中，“钥匙，就是锁本身啊。”

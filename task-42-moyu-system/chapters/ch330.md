# 第330章 废弃码头的夜

林一凡从防空洞钻出来的时侯，天已经彻底黑了。手机屏幕上显示晚上八点十七分，未接来电十七个，全是组长王建国打的。他没急着回，先站在洞口深呼吸了三口带灰的冷空气，把肺里那股铁锈味换干净，然后才点开微信。

老王的消息轰炸从下午四点就开始了，先是“小林子你去哪了”“公司开会”“钱总又发癫了”，到后来语气越来越慌：“兄弟你该不会是被赵日天挖走了吧？你可别想不开。”

林一凡嘴角扯了一下，打了几个字过去：活着，明天到岗。

他没骗人，他现在活着，但一会儿去不去得成“岗”就不好说了。

赵志强的物流公司仓库，坐落在城北废弃老码头腹地。那是片被城市规划丢下的角落，水泥路面开裂出蛛网般的纹路，杂草从缝隙里疯长到人腰高，几盏路灯只剩铁壳，灯泡早就碎了。导航地图上这个区域显示为“工业废墟，请谨慎进入”，下面的用户评论清一色是“这里有野狗”“别晚上来”。

林一凡打车到码头入口就停了，司机死活不肯往里开，说什么“兄弟对不住，我拉活儿还要命”。他只好下车走。手机信号从满格变成两格，再变成空白，最后连时间显示都开始转圈。深夜十一点半，四周只剩下风穿过废弃仓库时发出的呜咽。

他打开手机电筒——刚亮了两秒就自动关了。系统提示他看一下电量，林一凡低头，愣住了。

屏幕上的电池图标变成了纯蓝色，数字显示100%。他明明记得自己出门时只有63%。他划开设置面板去看，发现充电状态那一栏写着一行从来没见过的字：“感应充能·仓储区专属。”

林一凡皱起眉，把手机揣回兜里。仓库大门没锁，半掩着，铁皮边缘卷起像被什么野兽撕开过。他侧身挤进去，迎面是一排排六米高的货架，蒙着厚厚的灰，码着看不出内容的纸箱。空气中飘着陈年机油和防潮剂的味道。

他顺着货架之间的通道往里走，走到第三排时停下。

第一排货架B区，一只铁皮柜，跟防空洞里那只一模一样。

林一凡喉咙紧了紧，走过去，柜门虚掩着，里面放着一只牛皮纸信封。信封上用黑色马克笔写着一个字：“三”。

他拆开信封，倒出一张折叠的A4纸和一枚黄铜钥匙。钥匙柄是圆柱形的，表面没有字，但摸上去有细密的刻痕——他凑近灯光仔细辨别，是摩尔斯电码，跟上一枚一样是敲出来的消息。但这次的内容只有三个字母：SKY。

天空？楼梯？还是……

他把钥匙翻过来，掌心一沉，钥匙柄底部焊着一个小小的铜牌，上面刻着两个汉字：“梯三”。

第三梯。

林一凡刚把钥匙握紧，手机震动了一下。他低头看屏幕，信号恢复了两格，一条陌生号码发来短信，只有几个字：“你到了？”

他还没回复，身后“咔”一声轻响，像是有人踩碎了一块干掉的塑料包装。

林一凡猛地转身，手电光照过去，一道身影站在三排货架尽头的阴影里。那人穿着黑色连帽衫，帽子遮住大半张脸，只露出下巴和嘴角。那个弧度他在镜子前看过无数次。

那是他自己的下巴。

“你是谁？”林一凡声音发沉。

那人没动，也没说话。过了两秒，他抬起右手，手里握着一只老式黄铜怀表，表链垂下来轻轻晃动，和沈望在上一个防空洞里给他看过的那只一模一样。

“沈临渊的怀表，”那人开口了，嗓音轻得几乎被风吞没，“你外公，也是我外公。”

林一凡瞳孔骤缩。

那人缓缓摘下兜帽——一张跟林一凡有七分相似的脸露出来，年龄看起来比他大三岁左右。

“我叫沈望，”他说，“你同父异母的哥哥。但我这趟来，不是跟你认亲的。”

他目光落在林一凡手中的铜牌钥匙上：“你手上那把是假的。”

林一凡手上那把钥匙，是真的从赵志强仓库里拿出来的。但面前这个自称沈望的人语气笃定到让人心底发寒。

“什么？”

“第三梯不在城北，”沈望说，“在北面的云顶山。赵志强在这里建了三年，只是个障眼法——你外公真正的上船点，在山上那间废弃的气象站底下。”

夜风从破碎的窗洞里灌进来，货架上的灰尘被卷起又落下。林一凡低头看了一眼手中的铜牌，忽然发现刻字旁边有一道极细的刮痕，像是被人匆忙划上去的：

“别信。”

这是第二道跟“别信哥”相似的警告。只是这次划痕的位置，正对着沈望站着的方向。

他抬起头。

沈望的目光落在他脸上，那双跟母亲极像的眼睛里，有一瞬间极深的疲惫。

“你外公说过一句话，”沈望轻声说，“生门自向死而生之人开。但死门，也只向愿意为别人赴死的人开。”

“你是要去争钥匙，还是去当钥匙？”

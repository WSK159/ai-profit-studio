# 第347章 一个不该活着的人

赵日天走到挖掘机前，停下脚步。

驾驶室的门“吱呀”一声打开，一个穿着军绿色旧夹克的男人跳了下来。他约莫五十岁，两鬓斑白，皮肤黝黑粗糙，手里夹着一根没抽完的烟。月光下，男人脸上有一道从眉骨一直延伸到下颌的旧疤痕，把那张脸劈成了两半。

“日天。”男人的声音像是砂纸磨过铁皮，“八年没见，你长高了。”

赵日天沉默了两秒：“程哥。”

男人咧嘴一笑，露出一口黄牙：“你欠我的那顿酒，记了八年了。”

林一凡站在不远处，目光在两人之间来回扫过。他从未见过赵日天脸上出现这种表情——那不是防备，不是愤怒，更像是一种被压了很久的愧疚。

“你怎么会在这里？”赵日天问。

程哥抽了口烟，把烟头摁灭在挖掘机的履带上，然后抬手指了指排水渠的洞口：“我一直在等那边的哨声。等到了，就过来看看是谁想从老沈家的后门出来。”

他转过头来，目光落在林一凡手里的铁皮盒上，又移到孙满仓脸上：“孙副队，你师父的手艺，还是那么利落。”

孙满仓身体明显一僵：“你认识我师父？”

“认识。”程哥点了点头，“我这条命，是你师父救的。三十五年前，他是我的老班长。”

林一凡的脑子飞速地转。三十五年前，星辰科技子公司的AI初代核心算法项目，孙满仓说第九组代号“27”，总负责人姓沈。现在又冒出一个退伍军人，说沈临渊是他的老班长。

“你也是三十七号计划里的人？”林一凡问。

程哥的目光在林一凡身上停留了几秒，然后从夹克内侧掏出一个东西——一块磨损严重的军牌，上面刻着一个编号：**37-09-27**。

“三十七号计划第九组，第27号成员。”他把军牌在掌心翻了个面，背面刻着两个字——**“归零”**。

“师父说过，第九组的人，全军覆没。”孙满仓的声线有些发抖。

“全军覆没？”程哥笑了，那笑容里没什么温度，“是。对外宣布的版本，确实是全军覆没。但你师父他一个人活到二十七岁当上了老班长，又一个人活到现在——你说，他算活，还是算没活？”

“我师父没死？”孙满仓上前一步，“他在哪？”

程哥收住笑容，沉默了很长时间，才说：“他在三年前找我最后一次，交代了一件事。他说，如果有一天，有个姓林的年轻人拿着一个铁皮盒走出来，就告诉他一句话。”

林一凡心头一震：“什么话？”

程哥盯着林一凡的眼睛，一字一顿地说：“**‘第七枚核心里不是答案，是门。真正的答案，在门的后面。’**”

夜风穿过采石场，卷起碎砂，打在锈蚀的挖掘机上，发出细密的声音。铁皮盒冰冷地贴着林一凡的掌心，他突然觉得，这个盒子没有之前那么重了——更像是一把钥匙的钥匙。

“沈临渊还交代了一件事。”程哥伸手从裤兜里摸出一张折叠的纸，打开以后是一张手绘地图，画面上标注着一条红线，从云顶山南洞一路向北，穿过城区，最后落在城北一片林一凡看不懂的区域。红线终点用红笔画了一个“X”，旁边写了三个字：**“老铁匠铺。”**

“跟顾七说的地址一致。”赵日天出声，“城北老铁匠铺。”

程哥点了点头：“沈临渊说，那里有一个人，能开这个铁皮盒。不是指纹锁，也不是密码——那个人，是这个世界上唯一一个知道‘第二进门者’是谁的人。”

孙满仓的瞳孔骤然收缩。

林一凡攥紧地图，抬起头看向采石场尽头的公路。月光洒在路面上，像一条银灰色的河流。

三十七天。距顾七说的三十天之期，还剩三十天。

铁盒“第七份机密”指向新的关键：城北老铁匠铺。而沈临渊的话意味着第七枚核心里有“门”，那“门”后面，藏着三十七号计划真正的答案。

他把铁皮盒收进怀里，大步向前走去：“那还等什么？城北老铁匠铺。”

孙满仓跟上他，声音沙哑：“你知道你这一去，可能面对的是什么吗？”

“不知道。”林一凡说，“但我父亲留下的那盘磁带里，最后三个字是‘唯一性物品’。我猜，铁皮盒里装的，就是那件东西。”

他低头看了一眼怀里铁皮盒的指纹槽——**“第一入者死门，第二入者活门，第三入者无门。”**

他在心里默默倒数。三十天，不知够不够，他再开一次门。

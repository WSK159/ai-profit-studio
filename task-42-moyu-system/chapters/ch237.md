# 第237章 负六层

三长两短。

那叩击声从通道深处传来的时候，林一凡最先感觉到的是后背的汗毛全都竖了起来。像是有人趴在一面极薄的铁皮墙后面，用指节不紧不慢地敲着——不是敲给谁听，是敲给某种规律听的。

陈默的呼吸突然变得很轻。她站在通道入口一米的位置，侧着耳朵，整个人像一尊被定格了的雕塑。

“别动。”赵日天低声道。

林一凡没有动，但他的目光已经落在系统面板上。咸鱼雷达无声地跳了一下——没有敌人，没有生命体，但他能看见一层极淡的灰色光晕从通道尽头蔓延出来，那种颜色他见过，上次在配电房门外，当那个黑影消失的时候，地面留下一模一样的灰。

“这是……”他开口。

“它醒了。”陈默终于转过身来，声音很平静，但眼底有一丝他从未见过的东西——不是恐惧，更像是一种等待了很久之后的确认，“我爸留下的笔记本里有一条记录：‘三长两短，不要应。’”

老王捏着手电筒的手在发抖：“那刚才这声音，算不算……应了？”

没有人回答他。

赵日天站在自己激活的那面终端屏前，面板上“下行64米，右转第三间舱室”的提示已经稳定下来，不再闪烁。他看了一会儿，伸手从口袋里摸出那根铜线，在指间转了一圈，又收了回去。

“这扇通道不是我开的。”他忽然说。

林一凡皱眉：“什么意思？”

“我这张卡的完整权限是五分钟前才解锁的。但通道的机械锁——”赵日天用脚踩了踩脚下的钢制格栅板，发出一声沉闷的回响，“早就有人打开过了。只是用伪装层盖住，终端没显示而已。”

他说完，看向陈默。

陈默没有否认。

“你早就知道这里有路？”林一凡问。

“我知道它在，但不知道钥匙是谁的。”陈默抬起手，指尖悬停在半空，对准通道入口旁的铰链轴——那上面有一圈极细的、几乎看不出来的划痕，“我爸留下的钥匙齿形就是这个。他当年打开过这里，然后亲手把它封了回去。”

通道深处又传来一声叩击。

这一声比刚才更清晰，像是前面的“三长两短”只是一个试探，如今对方确认了有人站在门口，于是换了节奏，两短一长——

陈默的脸色变了。

“我爸生前编的密码，”她的声音变得沙哑，“两短一长是‘进来’。三长两短是‘快跑’。”

“那为什么它现在敲的是‘进来’？”老王问。

没人接话。

林一凡低头看了一眼自己后背工牌的背面，那个菱形印记还隐约泛着余温。他深吸一口气，朝通道里迈出一步。

“林一凡。”赵日天叫住他，“你确定？”

“你不是说这张卡是你的吗？”林一凡回头笑了笑，“那里面那个东西，怎么知道我的名字？”

通道里寂静了一瞬。

然后，叩击声又响了起来——这次是三长两短。

三长两短。快跑。

站在负六层通道入口，林一凡第一次对那道门背后的东西失去了判断，因为对方既能跟陈默父亲留下的密码对上话，又精准地知道他进来了。

那东西到底在等谁？

# 第282章 缝合线

档案科的灯管又开始闪烁，一明一暗，像某种不稳定的频率。林一凡盯着赵恒的脸，脑子里的念头像乱麻一样纠缠——第000号钥匙植入手术。签字。七年前。铁皮柜里姐姐的数字。录音机里的陌生男声。工牌上的双层编号。

那些碎片正在拼成一幅他不敢看的画面。

“你说我签过字。”林一凡的声音出奇地平静，但手指的指节已经捏得泛白，“在哪签的？什么时候？”

赵恒的目光落在林一凡的左耳后面。他指了指那个位置：“你耳后有一条缝合线，从耳根延伸到发际线，三点五厘米。你从来没注意过，是不是？”

林一凡下意识地伸手摸向左耳后。他确实摸到一条细长的、微微凸起的疤痕——他以前一直以为是小时候摔伤留的。

“这是第000号钥匙的植入入口。”赵恒的声音很低，“2019年6月12日，你姐姐林一诺被确认脑死亡后的第三天。你找到我，说要试一试。你签了知情同意书，我亲手做的植入手术。然后……”

“然后什么？”

“然后你让我删掉你的记忆。不是系统做的，是你自己要求的。”赵恒停顿了一下，像是这句话让他自己也无法承受，“你让所有人都以为你是不知情的人。因为——只有彻底‘忘记’自己是谁，才不会在设计者面前暴露痕迹。”

林一凡的呼吸变得粗重。他脑子里突然闪过一个画面——某个白色的房间，手术灯的光。他躺在手术台上，一个模糊的人影站在旁边，手里拿着细长的金属工具。那个人对他说：“你确定？”他听见自己的声音，不是重生者那种清明肯定的声音，而是沙哑、崩溃、近乎哀求：“确定。把钥匙放进去，把我放进去。”

画面碎裂。他回到档案科的走廊，日光灯管再次闪烁。

“那个‘设计者’是谁？”林一凡听到自己问。

赵恒张了张嘴，还没回答——一本书忽然从林一凡胸口的方向自己震动起来。蓝灰色旧书像活物一样在他外套内侧剧烈抖动，一阵嘶嘶的声音从书页间渗出来，像是有人在用气声说话。赵恒的脸色骤变：“快拿出来！”

林一凡猛地抽出那本书。书脊自行裂开，一颗银色的、指甲盖大小的芯片滑出来，摔在他的掌心。芯片表面刻着一个极小的图案——一条盘成一团的鱼。

他认出来了。这是摸鱼系统的核心标志。

“那是什么？”赵恒上前一步，声调变了。

林一凡没有回答，因为系统的提示音突然炸响在他脑海里——

【警告：检测到外部核心载体。载入程序冲突中。宿主，你的主意识与备份记忆之间的差异率为83.7%。请选择：保留现有记忆，或接受原始备份。】

林一凡愣在原地。

原始备份。七年前，他的记忆备份。如果接受——七年的摸鱼重生、工伤、王姐、卷王赵日天、星辰科技的每一次风波……这些主意识可能都是被“设计”出来的。

他低头看着手心的芯片。芯片的边缘有一道细小的划痕，像是被人故意刻上去的——那是数字“14”。

2019年6月14日。姐姐刻在铁皮柜底部的数字。

他抬头，看向赵恒：“如果我接受备份，我会失去这七年的记忆吗？”

赵恒沉默了很久，最终说：“我不知道。这个系统是你姐姐设计的。她才是那枚钥匙的制造者。”

窗外，楼下的路灯全部熄灭了。夜色像一只手掌，缓缓合拢。

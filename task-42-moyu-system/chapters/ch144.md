# 第144章 效率之星

“效率之星”评选的通知在星辰科技的内部系统里挂了整整一天，群聊里炸开了锅。钱总在全员大会上宣布：本次评选以AI考核数据为准，凡是当月全勤、无违规摸鱼记录、产出量排名前三的员工，自动进入候选池，最终由部门主管投票选出。

林一凡的工位上安静得反常。他没有像往常那样摸鱼，而是一页一页翻着公司内部网上的历史公告，试图找到任何和“华夏金融中心”有关的蛛丝马迹。

“老王，问你个事。”他转过身，装作漫不经心的样子，“你听说过‘建眼计划’吗？”

老王正喝着枸杞茶，闻言一口水喷在键盘上：“建眼？什么建眼？你是说楼底下那个银行的建行？”他抹了抹嘴，“没听说。”

林一凡有点失望。老王在公司待了七年，什么八卦都知道，连钱总每天早上几点到公司都了如指掌。他都没听过“建眼计划”，说明这事儿在明面上藏得很深。

下午两点，AI考核系统弹出了当日的数据排名。林一凡的名字赫然在第二，仅次于新来的卷王赵日天。系统面板下方显示：林一凡，今日产出量：3.7个标准单位；摸鱼时长：0分钟；违规记录：无。

林一凡盯着“摸鱼时长：0分钟”这几个字，苦笑了一下。他重生回来这么久，这还是第一次在系统界面里看到自己完全没有摸鱼记录。他想唤醒点摸鱼空间进去规划一下，却发现背包里的那个功能图标是灰色的，不可用。

钱总的秘书踩着高跟鞋走过来，在他桌边敲了敲：“林一凡，钱总让你去一趟办公室。”

办公室里，钱国豪坐在那幅“马到成功”的刺绣挂画下，手指敲着桌面。他抬眼看着林一凡进门的瞬间，眼睛微微眯起，脸上挂着一层不咸不淡的笑意：“坐。”

林一凡坐下，钱国豪就递过来一杯茶，温度刚刚好。他接过，道了声谢，就听钱国豪开口：“昨天的名片，你收到了？”

“收到了。”林一凡直截了当，“你让我去华夏金融中心B3层，我也去了。但见到的不是你。”

钱国豪的手指顿了一下，脸上的笑意淡了几分：“你见到谁了？”

“一个自称赵夜白的人。他说他是赵日天的哥哥。”林一凡观察着钱国豪的表情，一字一句道，“他说，我上辈子死在那个坐标的正上方。”

钱国豪沉默了很久。窗外的阳光在他的脸上投射出一道阴影，他的眼神里有某种复杂的情绪一闪而过，但又立刻被他压了下去。他放下手中的笔，声音低了几分：“你是不是觉得，我把你往火坑里推。”

“我现在不知道。”林一凡平静地说，“所以我来了。”

钱国豪站起身，走到窗边拉下百叶帘，确认外面走廊里没人，才转过身来：“赵夜白的话，只能信三分之一。”

“那其他三分之二呢？”

“你自己去查。”钱国豪从抽屉里取出一个文件袋，隔着桌子推给他，“里面是一张地图。华夏金融中心的地下图纸——但B3层以下，还有一层，图纸上标注的编号是B3A，不在官方备案里。”

林一凡伸手接过，没拆开，目光锁在钱国豪脸上：“你为什么要帮我？”

钱国豪笑了一下，笑意没到眼底：“因为你活着，比我亲自去查更方便。你要是死了，我对你上辈子的承诺也作废了。”

这句话没头没尾。林一凡还想追问，钱国豪已经摆摆手：“回去准备效率之星评选吧。这个头衔能让你接触到公司的核心数据中心，有时候，信息入口比答案更重要。”

林一凡走出办公室，手里的文件袋沉甸甸的。他回到工位，打开图纸，上面密密麻麻的管线标注和阴影切面图让他心头发紧。B3A层在图纸上用红线圈了一圈，旁边写着一行钢笔字，小得几乎辨认不清：

“钥匙孔——真身在此，勿带他人。”

他猛地抬头，脑海中浮现出昨晚赵夜白最后说的那句话：“不要带老王同去。”

这一模一样的文字，出现在不同的两个人手里。他们到底在防什么？

而他的摸鱼雷达，此刻像是被什么无形之物触碰了一下，猛地又跳动了半格——那种被注视的感觉，正从华夏金融中心的方向，再次传来。

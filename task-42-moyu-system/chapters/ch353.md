# 第353章 夜奔

铁铺里的空气像凝固了一样，煤油灯的光忽明忽暗，把老头的面孔切割成明暗两半。林一凡把信纸折好，揣进口袋，没有声张。

“怎么了？”孙满仓问。

“没什么，一封投错的信。”林一凡面色如常，目光却已经变了，他不动声色地打量着老头，老头正背过身去，佝偻脊背对着他们，伸手去够柜台角落的一只铁皮罐。

赵日天突然开口：“沈老先生，你刚才说那只黑漆木盒是三年前送来的，是谁送来的？”

“老沈本人。”老头头也不回地说。

“可你刚才不是说，沈临渊三十五年前就走了吗？他三年前回来过？”

老头的手顿住，半晌，他转过身来，脸上带着一种说不清道不明的神色：“他回来过，只待了一夜，说了几句话，留下那只盒子，第二天天没亮就走了。”

“他走的时候，你亲眼看见的？”林一凡追问。

“我亲眼……看见他出的门。”老头的声音开始有些犹豫，“我送他到的巷子口，看着他拐进那条长街。那天下雨，他打了一把黑伞，背影……”他说到一半，忽然停住了。

“背影怎么了？”林一凡问。

老头垂下眼皮：“没什么。雨太大，看不太清。”

赵日天忽然从墙角的工具箱旁直起身来，手心里捏着一块东西：“沈老爷子，你铁铺里的工具箱，是姓沈的人用过的那个吧。”

老头没答话，但身体微微僵硬起来。赵日天把那东西摊开，是一枚铁质的扣子，圆形的，约莫指甲盖大小，表面刻着一只展翅的鹰。赵日天目光锐利地盯着老头：“这枚扣子，是在你工具箱底下的夹层里翻出来的。这种款式的纽扣，是三十年前铁路制服上的标准配置。”

铁铺里安静了一瞬。林一凡的脑子飞速转动，三十年前，铁路制服，一个佝偻的铁铺老头要铁路制服扣子干什么？除非——他曾经是铁路工人。而老爷子刚才说他送沈临渊出巷子口，“那天下雨，他打了一把黑伞”。

林一凡忽然意识到了什么，声音沉下来：“老沈，你见过那条通往云顶山的铁路。”

老头沉默了很久，久到煤油灯的火苗闪了两闪，才缓缓开口：“我只是个打铁的。但那条路……比我更老。”他搁下铁皮罐，转过身来，第一次正视林一凡，“盒子里那封信说三扇门的事，但你不知道，那三扇门，都在同一条路上，铁轨铺不到的地方，有一段废弃的隧道，入口藏在云顶山北麓的半山腰上。”

“隧道里有什么？”孙满仓问。

“我送老沈走的那天晚上，他站在隧道入口，回头跟我说了一句话。”老头的声音突然变得很轻，“他说，如果能活着回来，就回来把铁铺的门关了，去山里找一样东西，‘一根断掉的铁轨’。”

“断掉的铁轨？”林一凡咀嚼着这几个字，“这是什么意思？”

“我也不知道。”老头说，“那之后他再没回来过。三年前那个自称是他的人，我只见过一面，他说‘盒子送到了’，然后留下信就走，声音——不像老沈。”

说到这儿，老头眼中闪过一抹不易察觉的惊惧：“我本想追上去问一句，但他走得很快，像是有人在后面赶他。那人走路的姿势不对，老沈左腿有些跛，那个人两条腿步幅一样长。”

铁铺里死一般寂静。

赵日天笑了一声，把铁扣子抛还给老头：“所以，三年前来这里的那位‘沈先生’，其实是个冒牌货？”

老头没有接，铁扣子落在他脚边的地上，发出清脆一声。

“我不知道，也不想知道。”老头的嗓音嘶哑下去，“我今年七十二了，活够了，不想再掺和。你们走吧，钥匙都拿到了，盒子也开了，想活着，就天亮前出城。”

林一凡盯着老头看了三秒，然后果断转身：“走。”

三人出了铁铺，夜色如墨，满月被乌云吞没大半。孙满仓压低声音：“你刚才看信的时候脸色不对——那封信到底写的什么？”

林一凡没有瞒他：“信上说，铁铺里的老头，三年前就死了。让我快点离开。”

孙满仓的步子猛地停了：“那他妈刚才和我们说话的……是谁？”

赵日天在路灯下站定，回头望了一眼铁铺方向，铁铺的门窗关得严严实实，里面的灯火已经灭了，整间铺子沉在黑暗里，像一只闭上了眼的兽。

“我不管他是人是鬼。”赵日天的声音平淡，“我只在乎一件事，他说了三扇门都在云顶山那条废弃隧道里。如果他是假沈临渊送来的幌子，那我们一直在被人牵着走。”

林一凡没有说话，他伸手摸向胸口的口袋，触到那只怀表，表壳冰凉。他打开表盖，上面的指针走得安稳。父亲留下的这只表，背后究竟藏着什么？他忽然想起来，在防空洞里那段摩尔斯电码——“别信哥”，还有沈临渊信里的“别信我哥”，以及刚才那封信上的“速离”，仿佛有一条无形的线把散落的线索串起来，可是线的另一端握在谁手里，他还看不见。

远处城北方向，忽然亮起一簇火光，红彤彤地烧上半空，像有什么东西在燃烧，林一凡脸色一变，那方向——正是沈记铁铺。

孙满仓也认出了方向，低喝一声：“铺子！”

他转身要往回跑，赵日天一把拉住他的手臂：“别去，已经烧起来了，你去送死？”

火光跳动中，赵日天的背影被映得忽红忽黑，他的声音却很平静：“林一凡，你知道为什么那人要烧掉铁铺？因为线索断在老头嘴里了——你不觉得，老头在你拆开那封信之前，说的每一句话，都像是早就准备好的台词吗？”

林一凡站在原地，手掌缓缓攥紧，怀表表壳的边角硌着掌心，微微生疼。他抬头看着那片火光，没有回答，但他心里已经明白，他正在被人算着每一步，而他能做的，只有在这条被设好的路上找到一个能反将一军的节点。

他低声道：“去云顶山。”

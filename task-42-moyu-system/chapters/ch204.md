# 第204章 硬币与倒计时

会议室的门被敲响的同一秒，林一凡把金属圆柱攥进裤兜里。

“进。”

推门进来的是老王，一脸焦虑，手上抓着一份打印的邮件通知：“林工，你看了没？劳动纯度检测仪下周一全面上线，所有部门随机抽测，第一次不合格的直接绩效清零。”

林一凡瞥了一眼，问：“抽测比例多少？”

“百分之十五。”老王压低声音，“但听说钱总跟研发中心打了招呼，‘效率小组’必测。”

“测呗。”林一凡笑了一下，“我劳动纯度挺高的。”

老王欲言又止，看了一眼窗外走廊上装监控的方向，凑近了说：“兄弟，你实话告诉我，你最近是不是碰了什么不该碰的东西？”

“怎么说？”

“老周上周离职手续没办完，人就消失了。人事那边说他‘个人原因’，可我昨天去档案室，看到他柜子里留了一本笔记本，封皮上写着你名字。”老王从怀里掏出一个皱巴巴的软皮本子，像是揣了一路，“我没敢拆，你自己看。”

林一凡接过笔记本，鼻尖嗅到一股旧纸和烟味混合的气息。他翻开第一页，上面是老周那歪歪扭扭的笔迹，写着一行日期，正好是三天前——游戏倒计时开始的第二天。

本子中间夹着一张全园区布局图，A3纸，画满了标注：物业设备层四个通风井口、地下车库C区配电房、二号楼天台的水塔、以及园区最东角那个废弃的快递收发室。每一个位置都画了一个圆圈，圆圈里标着同一个符号——一枚硬币的简笔图。

老王盯着那页纸看了两眼，声音压到几乎听不见：“这老周，是不是信了什么邪教？”

“不是。”林一凡把图纸折好放进口袋，面上不动声色，“他在做维修规划。”

老王走后，林一凡把笔记本翻到最后一页。那里没有图纸，只有一段被反复涂抹又重写的文字，最后留下的版本是：

“原始意志机的启动，不需要电，不需要网络。它只有一把锁，两把钥匙。钥匙合并的那一瞬，机器的算法会把园区所有劳动数据重新洗牌。资本神埋了三年的锚，会全部拔起来。”

下面一行字更小，像是用指甲刻的：

“但代价是要有一个活人在机器里待满三分钟。”

林一凡在工位上坐了一整个下午。屏幕上的代码用他平时三分之一的速度慢慢写，脑子里在飞速运转。赵日天的反噬期，老周说的三分钟，陈默那句“用你的第二条命做抵押”——所有线头隐隐约约扭成一个绳索，但还差一个结，他怎么都捏不上。

五点半，手机震了。是一个陌生号码，发了条短信，没有署名：“硬币抛了没有？”

林一凡盯着这行字看了很久。他没有回复。他打开手机上的手电筒，借着一丝微光，摸出裤兜里那枚金属圆柱——陈默给他的那半钥匙。圆柱的底部有一个极浅的凹槽，像硬币的边缘。

他又从包里翻出自己身上那半“图纸”——确切来说是一张加密的SD卡，早上老周的遗产技师才刚帮他解锁了外层。他把SD卡插进读卡器，电脑屏幕上跳出一行代码提示：“请插入另一半密钥以完成标识匹配。”

鬼使神差地，他把金属圆柱的凹槽贴住读卡器边缘。

“滴。”

屏幕黑了一瞬，随即跳出一个他从未见过的界面——八角形暗金色面板，顶部写着四个字：摸鱼空间·深层。面板中央是一个三维模型，标着“原始意志机”字样，旁边一行小字标注运行状态。

状态栏里，倒计时从“6天23小时41分”跳成了“6天23小时40分”。

而那枚硬币的模型，正静静地停在他的指缝之间，仿佛一直在等他做出选择。金杯朝上，还是铁锤朝上？

林一凡盯着屏幕，后背沁出一层冷汗。他忽然意识到——白天陈默在他面前抛硬币时，硬币落下、金杯朝上的那一幕，跟他现在指尖这枚硬币上的朝向一模一样。这意味着什么？是偶然，还是这局棋从一开始就有写好的剧本？

他看着屏幕上的倒计时一秒一秒走，对着那枚硬币的图案轻轻说了一句话：“如果我选另一面呢？”

屏幕闪烁了两下，像是某种笑意。

然后跳出一行字：“那就别选了。本来就只剩一条路。”

# 第199章 地下机房的灯

夜色像一层没拧干的湿布，闷沉地压在头顶。林一凡翻出工牌，在夜色里闪了一下塑料的反光，心里没底——自从系统咸鱼值收益暂停，他连最基础的“摸鱼雷达”都成了灰色图标，像个死人一样躺在界面角落里。

凌晨一点半，星辰科技主楼走廊空荡，只有安全出口的绿牌子亮着。他绕开正门的摄像头，走员工通道刷了三次门禁，才摸到地下二层的楼梯间。铁门上挂着一把旧式挂锁，锁孔边缘有油泥，不像常开的。

“老周要不是钱总囚在这下面，我用得着半夜撬锁？”他低声骂了一句，掏出随身带的一截回形针折成钩形。前世他学过一点开锁——纯粹是挨饿时学的，没想到这具身体还记得。

锁芯“咔”地一声弹开，门轴发出锈蚀的呻吟。林一凡侧身挤进去，走廊里的感应灯没亮，只有远处通风管道嗡嗡响着。他打开手机手电筒，光柱在混凝土墙面上扫过，地面有一层细灰，但灰层上却留着几条新鲜的鞋印，是朝里走的。

走到走廊尽头，他看见一扇贴着“人力·档案储备”的防爆门，密码盘上有指纹残留。林一凡皱了皱眉，他试着输入自己工号，居然亮了绿灯，门缝无声滑开。

扑面而来的是一股热浪和低沉的机器轰鸣。门后是间约莫两百平的机房，两排服务器机柜矗立如墓碑，指示灯红绿交错。正中央的铁椅子上坐着一个人——老周，头发乱成了鸟窝，嘴唇干裂，但眼睛睁着，看到他进来，嘴角竟挤出一个笑。

“你来了。”老周声音嘶哑，像锈铁摩擦，“我就知道，赵日天那小子会给你带话。”

林一凡走过去蹲下身，正要说话，他眼角的余光瞥见老周脚边的地板上，用记号笔画着一段歪歪扭扭的代码，像密语一样涂满了四个格子。他伸手想摸，老周忽然猛地按住他的手腕，半截指甲掐进他皮肉。

“别动！”老周压低声音，“它看着这里。”

林一凡愣住：“什么看着？”

老周没说话，用舌尖舔了舔干裂的嘴唇，然后用脚尖点地面的代码：“钥匙代码我藏在这里，完整的。你拍照带走，但一个字都别在系统里输——摸鱼系统的核心数据，那个资本神能看。”

他话音未落，机房的灯光“啪”地亮了一半——走道的方向传来脚步声，不急不缓，鞋底踩在水泥地上有节奏地响。老周的表情瞬间变了，他一把将林一凡推下椅子：“从后面通风管走，快点！”

林一凡来不及犹豫，他滚进最近的机柜间隙，抓住墙上通风管道的格栅猛地拽开，翻爬上去，膝盖撞在铁板上发出一声闷响。他低头去看——灯光里站了一个穿西装的身影，背着手，面朝老周的方向。

钱总的声音在机房里回荡：“老周啊，你什么时候能学聪明呢？你这条命，还抵不上那一段代码值钱。”

林一凡咬牙，不敢停顿，在寒气刺骨的管道里向前爬，身后机器的轰鸣逐渐远去。他的手掌磨破了皮，脑子里只剩一个念头：那把钥匙，到底能打开什么？

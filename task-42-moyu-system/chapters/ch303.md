# 第303章 铁门后的喘息

铁门被撞得变了形，门框上的灰簌簌往下落。林一凡一把拽过沈稚冬往后退了三大步，顺手把瘫在地上的灰工装男人也拖到墙角。

“什么东西？”沈稚冬压低声音，右手已经从腰后摸出一把折叠刀。

“不知道。”林一凡盯着那扇门，铁皮中央凸起一个拳头大的鼓包，像被什么重物从外面狠狠砸了一下。鼓包周围的锈迹被震落，露出底下暗沉的金属光泽。

第二下撞击紧跟着来了。

轰——

整个地下手术室的天花板都跟着震了一下。头顶那盏忽明忽暗的日光灯管发出一阵刺耳的嗡鸣，光晕猛地收缩成一条细线。

灰工装男人忽然剧烈挣扎起来，被胶带封住的嘴里发出含混不清的呜咽声。林一凡低头看他，发现他眼睛瞪得溜圆，死死盯着铁门。那不是恐惧，更像是……催促？

“他是不是想让我们开门？”沈稚冬皱眉。

“开门？”林一凡摇头，“这动静听着不像活人。万一是楼上的监控室那边出了什么状况……”

他的话没说完，第三下撞击就来了。

但这一下的声音不对。

不再是沉闷的铁皮被锤击的声响，而是尖锐的金属刮擦声，像是有什么东西在用指甲——或者爪子——从铁门的缝隙里硬生生往里抠。

那声音刺得林一凡后槽牙发酸。他看见铁门与门框之间的缝隙被一点点扩大，一道黑影从缝隙里渗透进来。

不是液体。更像是一缕烟。

但那烟有形状，细长，弯曲，在灯光下泛着暗红色的微光。它挤过那道窄缝之后，在空中停顿了半秒，然后猛地朝林一凡这边射了过来。

林一凡几乎是本能地侧身一让。那道红光擦着他的耳廓钉入身后的水泥墙，墙面上立刻多了一个指甲盖大小的焦黑坑洞。

“靠——”

“别动，”灰工装男人突然说话了。他的声音嘶哑，显然刚才一直被胶带勒着嗓子，现在好不容易用舌头顶开了一角。他死死盯着那道红光钉住的墙面，低声道，“它在试探。你一动，它就锁定。”

林一凡的动作定在半空中。沈稚冬也闪到了手术台侧面，折叠刀握在手里，刀刃映着灯光。

那道红光钉在墙里，尾巴轻轻震颤，像某种生物的触须。过了约莫三秒，它突然从墙里拔出来，在空中转了一圈，然后退回到铁门缝隙外。

铁门外传来一阵沉重的脚步声，由近及远，最后消散在楼上的某个方向。

地下手术室重新安静下来。

林一凡慢慢直起身子，走到铁门缝隙边侧耳听了听，外面没有任何声响。他回头看向灰工装男人：“‘它’是什么？”

男人嘴唇哆嗦了两下：“你……你把磁带里的话听完了没有？”

“听到了苏锦的留言。”

“那苏锦还说了什么？”

林一凡回忆起拆开磁带播放器时夹层里那张照片和背面的字：“钥匙藏在老宅的墙洞。告诉他，去找010。”

灰工装男人的瞳孔猛地缩了一下。

他沉默了几秒钟，然后道：“刚才那东西……就是来找010的。”

“010不是把钥匙吗？”

“010不是钥匙，”男人艰难地咽了口唾沫，“010 是个人。苏锦的编号是002，她姐姐是001，010 是她们俩谁也联系不上的那个。这九年里，我们一直在等。”

他顿了顿：“那东西找的不是钥匙，是苏锦在磁带里藏的那张照片——如果让外面那个嗅到010的气息，苏锦的藏身之处就保不住了。”

沈稚冬看了林一凡一眼：“照片在你身上。”

林一凡拍了拍口袋，确认那张胶片和照片还在。他想了想，问灰工装男人：“这个地下手术室有没有别的出口？”

“有。手术台底下有条通风管道，能通到后院杂物间。”

林一凡朝沈稚冬点了点头，然后弯腰探向手术台底部。果然摸到一块松动的铁板，掀开之后是一条约四十厘米宽的方形通道，里面黑洞洞的，散发着一股霉味和旧机油的气味。

他转头看向灰工装男人：“你怎么办？”

男人背靠着墙角，被捆着的手腕在身后挣了两下：“你们走。它很快就会回来，我得留下……把这道门焊死。”

林一凡眯起眼睛盯了他两秒。这个男人的话前后没有破绽，但他总觉得哪里不对。

“你知道苏婉和010之间发生了什么？”林一凡问。

灰工装男人沉默了片刻，说：“我知道的不多。但有一件事我可以确定——”

他抬起眼睛，瞳孔里倒映着手术台顶上那盏忽明忽暗的灯：

“010就是第一批进医院做实验的人之一。他进医院的照片，和苏锦放在老宅墙洞里的那张合影，是同一天拍的。”

林一凡心里一震。

那照片背面写的是“钥匙藏在老宅的墙洞”，而010本身就是人，这就意味着——所谓“钥匙”，从一开始指的就不是某件物品，而是这个人的下落信息，甚至就是010本人！

他来不及多问，通风管道深处传来沈稚冬低声的催促：“这边能走，快来。”

林一凡最后看了灰工装男人一眼。男人已经背过身去，用被捆住的手腕去够铁门旁边的工具箱，那里面果然躺着一把生锈的电焊钳。

林一凡弯腰钻进通风管道，刚爬了两米，身后就传来铁门被再次撞击的巨响。

管道里的灰尘簌簌落下，他不敢停留，手脚并用地往前方那点微弱的光亮爬去。沈稚冬在前面等他，说：“后院。有辆车。”

林一凡爬出管道口的时候，夜风迎面扑来。他看见后院杂物间旁边停着一辆蒙满灰尘的白色面包车，车窗上的雨刷已经锈死了，但引擎盖上留着新鲜的水渍——显然有人最近动过这辆车。

他回头看了一眼地下手术室的方向，心里把刚才的信息重新捋了一遍：苏婉告诉林一凡去找010，010是第一批实验对象，而且和苏锦同一天拍过照。

而刚才那道红光的形状，以及灰工装男人口中的“它”，让他忽然想起了一个熟悉的东西——母亲留给他的旧手机屏幕里，那份编号ED-00的手术档案上，“外部载体”一栏画着的图案，和刚才钉入墙面的那道细长红光，一模一样。

沈稚冬已经拉开面包车副驾的门：“上车，我先开离这片区域再说。”

轮胎碾过杂草，雪白的车灯劈开夜色。林一凡把那台破旧的磁带播放器从兜里掏出来，盯着它半分钟没说话。

“你说，老宅墙洞里的钥匙照片，会不会和010是同一天的日期？”他忽然问。

沈稚冬目光没从前路上移开，但语气里带着一丝凉意：“你已经开始信了？”

林一凡没回答。他把磁带播放器翻了个面，背面有一处不起眼的划痕——看上去像是被指甲反复抠过的地方。他刚才拆磁带的时候没有注意到，因为那道划痕完全是外层的塑料壳上的，而不是磁带内部零件。

他指尖顶住那条缝，用力一掰。塑料外壳应声而破。

里面不是电路板。是一个卷成拇指大小的硬纸卷。

展开之后，纸上写着三行数字。

第一行是日期：2019.03.17
第二行是一个坐标：经度119.18，纬度34.27
第三行只有一个字：来。

沈稚冬瞥了他一眼。那个坐标，正好落在医院旧址的西南方向约五公里处。

“苏锦留给我们的？”她问。

林一凡捏着纸片，正想开口，眼前忽然弹出一行系统提示：

【摸摸鱼提示：检测到宿主已在48小时内连续收集3条同一序列坐标线索。是否消耗500咸鱼值，解锁“坐标重合”交叉比对？】

他犹豫了半秒，点了“是”。

屏幕上立刻展开一张淡蓝色的局部地图，三个坐标被自动标注出来，连成一条线——线的延长线末端，落在一个他无比熟悉的名字上：星辰科技。

那个坐标交叉点，正是他入职第一天的工位坐标。

“苏锦让我们去的那个地方，”林一凡慢慢开口，“是星辰科技的老机房。”

面包车在夜色中拐过一个弯。前方路边，一辆打着双闪的黑色轿车停在林荫道旁，车尾灯闪烁的红光，像一只眼睛，正在注视他们。

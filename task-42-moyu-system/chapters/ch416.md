# 第416章 眼中之珠

走廊尽头那个人坐在一张石凳上，像是等了很久很久。

他的脸整个被烧灼过——皮肉翻卷，结痂呈深褐色，五官几乎分辨不出轮廓。唯一完好的，是左眼眶里嵌着的那颗陶土珠，浑浊的黄泥色，表面刻着细密纹路。

林一凡盯着那颗珠子，后背发凉。

“你说……第26颗珠在你眼睛里？”他声音干涩。

老杨头的大哥没有回答，只是抬起右手，缓缓指了指自己左眼。他的手指骨节粗大，指甲缝里嵌着暗红色的泥垢，像是不知多少年没洗过。

“第九根钉子不够了。”他的声音沙哑至极，像是从喉咙深处刮出来的，“你手上有几根？”

林一凡下意识攥紧背包，那三根灰烬骨钉还在里面。“三根。”

“三加八。”老杨头大哥说，“八根早断了。”

林一凡皱眉：“什么八根？”

黑影忽然从他肩后飘出来，声音压得极低：“他说的是‘前八根’。青铜钉一共八根，早在你们来之前就被人拔了，断了，毁了。只剩你手里三根灰烬骨钉。”

“不够。”老杨头大哥重复了一遍，“要二十七颗珠全齐。”

林一凡盯着他左眼那颗珠子，忽然想到什么：“你说第26颗珠在你眼中——那第27颗呢？”

老杨头大哥沉默了几息。烧灼的面容在昏暗的廊灯下显得格外狰狞，他缓缓张开嘴，舌头上压着一颗同样的陶土珠。

“27颗，一颗在舌下含了十四年。”他合上嘴，声音更低了，“我的命早已押在门上。”

林一凡倒吸一口凉气。黑影在他肩上轻轻晃了一下：“二十七颗珠，两颗在他身上，一颗在你钉帽上——26、27、28，三颗是锁链的尾扣。”

“那其他24颗呢？”

老杨头大哥没有说话，但目光缓缓移到走廊尽头那扇门上。门是青铜铸的，表面锈迹斑斑，像是一百年没被开启过。门缝里塞着什么东西——林一凡凑近看，是一缕卷曲的黑发，和之前在墙壁“26”划痕旁发现的发丝一模一样。

“头发的女主人，把自己烧成了骨钉。”老杨头大哥声音像是从门缝里挤出来的，“她留下了这扇门，也留下了门后的人。”

林一凡背脊一麻：“门后……是谁？”

老杨头大哥抬起头，左眼里的陶土珠映着光，像一只沉默的眼瞳。他说：“一个死掉的人。和你长得一模一样。”

林一凡的眼皮猛地跳了一下。

他想起之前在那扇铁芯门前见到的一幕——门内有一个“死掉的我”，穿着和自己一模一样的衣服，腕上绑着同样的红绳。他以为那是幻觉，是系统制造的精神干扰。

可现在，老杨头大哥说得轻描淡写，像在陈述一件早就注定了的事。

“我要进去。”林一凡声音很稳。

“你进不去。”老杨头大哥摇头，“门需要钥匙。”

“钥匙是什么？”

老杨头大哥抬起手，指了指林一凡的背包：“第三根灰烬骨钉，你钉帽上的陶土珠——把28翻到27，把27对准26，三颗珠连成一线，门就开了。”

林一凡低头，摸出那根骨钉。钉帽上的陶土珠翻面停在“26”上，另一面是空白。他试着转了转，珠子纹丝不动，像是卡死了。

“珠子不是用手转的。”老杨头大哥说，“是用血。”

林一凡静了两息：“谁的血？”

老杨头大哥的目光落在他左手食指的指尖上，那上面有一道旧伤疤，压着指纹，像是被人用针挑过。林一凡低头看了一眼，脑海里“嗡”地一声——

那是锁芯女人的指纹。她手指上的纹路和这道伤疤完全重叠。

“她留下了自己的骨，自己的发，自己的指纹。”老杨头大哥声音越来越低，像随时会断气，“还差一样东西。”

“什么？”

老杨头大哥缓缓抬起手，从自己左眼里抠出那颗陶土珠，血水顺着眼眶淌下来。他把珠子放在掌心，递向林一凡：“她的魂。锁在珠子里十四年。”

林一凡愣住。那颗陶土珠在对方掌心微微发热，表面的纹路像血管一样跳动着——里面有东西。

黑影忽然开口：“别碰——”

但林一凡已经伸出手，指尖触及那颗珠子的刹那，整个走廊剧烈震动。青铜门发出沉闷的轰鸣，门缝里那缕黑发像是活了过来，猛地缠上林一凡的手腕。

他低头看去——锁芯女人的发丝紧紧缚住他左手食指，正一寸一寸地把那道旧伤疤勒出鲜血。

血珠渗出来，滴在第三根灰烬骨钉的钉帽上。陶土珠表面裂开，露出一道暗红色的缝，数字从“26”缓缓翻转——

“27。”

门缝里传出另一个人的呼吸声。很近。像隔着门板贴着，正在等他开门。林一凡猛地抬头，却见老杨头大哥已经松手，那颗陶土珠滚落在地，碎裂成粉末。粉末里，一缕极淡的灰色气息飘向大门。

门内那个呼吸声，忽然停顿了。

然后门缝里挤出一句话，声音低沉、沙哑、像从地底深处翻涌上来——

“老杨头。你终于来了。”

林一凡浑身的血像被抽空了一样，因为他认得这个声音。这是他自己嗓子被火烧过之后的、带着灼伤的嗓音——是门内那个“死掉的我”在说话。

而老杨头大哥的喉咙里，发出了一声类似哽咽的颤音，像是十四年没听到过这个名字。

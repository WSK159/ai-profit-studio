# 第22章 摸鱼半天

早八点，钱总的办公室门开着，里面飘着茶香。钱总坐在宽大的办公桌后，面前摊着效率小组的周报表，表情看不出喜怒。

“林一凡，你的小组今天上午的产出比全组平均高40%。”钱总放下报表，语气平淡，“但有人跟我反映，你们上午十一点以后就不在工位上了。”

林一凡坐得笔直：“是，那是我们小组的新制度。”

“什么制度？”

“周五下午，全组不干活。”

钱总的眉毛挑起来了。

林一凡不慌不忙，掏出一份打印好的方案，拍在桌上：“周五下午安排的是复盘与规划，但复盘和规划不需要守在电脑前。这半天，我带他们去楼下的咖啡厅，或者公司顶楼的露台，形式和地点随意。但前提是——前四天的产出达标，如果没达标，周五下午照常坐班。”

钱总没拿那份方案，反而靠回椅背上：“你凭什么觉得这样产出不会降？”

“因为数据。”林一凡说，“周三的半天，我在顶楼呆了一下午，回来以后把手上一个卡了三天的模块用两小时写完了。你说我是在摸鱼，但我的产出比坐在工位上刷手机高得多。”

钱总盯着他看了十几秒，忽然笑了：“行，先试三周。要是产出掉下来，你自己拆了这个制度。”

林一凡点头：“那说好了，掉了我拆制度，不掉，这个制度固化进小组手册。”

当天下午，效率小组的六个人出现在公司顶楼露台，一人端着一杯茶，面前摊着笔记本，聊一聊卡了一个月的问题，扯一扯接下来的排期。没有键盘声，没有弹窗，只有风吹过遮阳伞的声音。

张伟靠在椅背上看着远处的高楼，忽然说：“组长，我这辈子没在这儿坐过。以前都觉得，顶楼是用来跳的。”

“那不是都活下来了嘛。”林一凡说。

第二天，周一早上九点半，钱总的邮箱弹出一封周报。效率小组上周五半天全员摸鱼，但全周产出比预期高出17.8%，投诉率下降，代码错误率下降22%。

钱总觉得不对劲，但又说不出哪里不对劲。

他敲了敲桌面，助理探头进来。他又摆了摆手，让助理退回去。他盯着报表上的“17.8%”看了很久。

“效率小组……这个鬼名字。”钱总自言自语了一句。

消息传出去的速度比林一凡预想的快得多。周二中午，隔壁部门的两个组长堵在他的玻璃门口，一位姓孙，一位姓齐，都笑眯眯地问：“林组长，你们那个‘周五半天躺平’的规矩，能不能来我们部门讲讲？”

林一凡刚想回答，手机一震。

【摸鱼系统·提示】支线任务【体系外溢】：目前已有3个部门提出学习“效率小组”制度，是否同意对外分享？同意：咸鱼值+300，效率小组影响力+1；拒绝：咸鱼值+100，封闭式管理+1。请选择。

（提示：影响力累积到一定值，可触发“自由”兑换前置条件。）

林一凡盯着那条提示，眼皮跳了一下。他抬起头，对两个组长笑道：“当然可以，不过这周不行——周三下午我们要开演示会，你们先来听听？”

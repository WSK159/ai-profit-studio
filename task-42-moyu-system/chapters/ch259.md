# 第259章 钥匙井

黑暗。彻底的、吞噬一切的黑暗。

林一凡感觉自己在下坠，但那种下坠感又不太对劲——像是被什么力量拉向某个方向，而不是自由落体。风声从耳边呼啸而过，但吹到脸上又带着一股温热潮湿的气流，像是地热管道里涌出来的蒸汽。

“叮——恭喜宿主进入隐藏副本【钥匙井】。”

系统的提示音在脑海中炸响，林一凡顾不上琢磨这是怎么回事，脑海中只剩一个念头：老子又要摔死了？

上一次“摔死”还是三年前和资本有关的那次经历，这回不会又要死一次吧？

就在他这么想的时候，下坠感戛然而止。

他落在一个柔软的东西上，触感像极了办公室那台打盹用的折叠床垫。林一凡挣扎着爬起来，四下打量。

这里是一个圆形的空间，直径不过二三十米，墙壁由某种暗金色的金属铸成，表面刻满密密麻麻的纹路，像是某种古老的电路板或者加密代码。空间顶部黑洞洞的，看不出本体，脚下则是碎裂的混凝土地面，裂缝里透出微微的蓝光，跟水塔间方向那道蓝焰一模一样的颜色。

“钥匙井。”林一凡喃喃念着这个名字，“怎么着，我也成了一把钥匙？”

系统面板无声弹出：

【钥匙井·第一层】
描述：位于星辰科技总部负三层之下。由“资本神”以九百九十九把钥匙为骨架浇筑而成，每一把钥匙代表一份被夺走的时间。
当前目标：找到出口。
额外提示：这里的钥匙，拿走就是你的——但每拿一把，就必须留下一段同样长度的记忆。

林一凡沉默了几秒。

“留下一段记忆，什么意思？”

系统没有回答。

他往前走了几步，目光落在墙根处。果然，暗金墙壁上嵌着一排排的钥匙孔，每个孔里都插着一把钥匙。有的钥匙是铜铸的老式锁匙，有的则是带着芯片感应的电子卡，甚至还有几把看起来像是保险柜的十字钥匙。

林一凡忽然想起陈重阳给的那把三叉钥匙。

他从口袋里摸出那把钥匙，入手微凉。三叉钥匙约莫十公分长，末端呈三个分叉，像是一把来自某个中世纪古城堡的复古钥匙。他刚把钥匙举起来，墙壁上某处忽然传来一声“咔嗒”轻响，像是锁芯对准了什么。

林一凡循声望去，只见正前方的墙壁上，一个钥匙孔正在微微发光。那个孔的形状——三个分叉。

“还真对上了。”

他犹豫了两秒。三叉钥匙是陈重阳留下的，陈重阳说它是“通往出口的门票”。可他记得清楚，陈重阳那句“你去水塔间取009号钥匙”的纸条还在兜里。现在水塔间没去成，人却掉进了钥匙井。

“算了，走一步算一步。”林一凡把三叉钥匙插入锁孔。

钥匙刚捅进去的瞬间，墙壁猛地一震，像一头沉睡的怪兽被惊醒了。正前方轰隆隆裂开一道门缝，一条向上延伸的楼梯出现在林一凡面前。楼梯的台阶表面同样覆盖着蓝色纹路，踩上去微微震脚。

他迈出第一步。

系统面板再次弹出来，这次带着红色的警告边框：

【警告：检测到“记忆抵押”正在生效。您正在靠近“出口”，但出口需要支付一把“时间钥匙”——即一段不可逆的本体记忆。】

“不可逆的记忆？我又不是鱼，那玩意儿还能被拿走？”

系统的回答冰冷而简练：

【在资本神的世界里，记忆也是一种货币。正如劳动可以被量化，记忆也可以被提取。提醒：被提取的记忆并不会凭空消失——它们会成为钥匙井的一部分，用来加固整个结构。】

林一凡停了脚步。

他想起陈和平的那句话——“陈重阳也在骗我。”又想起王姐手里的009号钥匙，“拿命来换。”现在这钥匙井又要他的记忆。一环扣一环，每一层都在交“费用”。

“这鬼地方，根本就是一个大型保险库啊。”林一凡嘀咕了一句，继续往上爬。

第三个转角处，他看到一个东西，脚步再一次顿住。

墙上有一张照片，被玻璃框保护着。照片里是个年轻人，二十出头，穿着格子衬衫，戴着一副黑框眼镜，正对着镜头傻笑。手里举着工牌，背景是星辰科技的前台。乍一看像是某个新员工的入职纪念照。

但林一凡认出了照片角落里那串编号：XA-0001。

001号工牌。他见过类似的编号——陈重阳给他的那张卡，卡片背面也印着“XA-0001”的字样。

“这是……陈重阳？”

照片里的年轻人眉眼确实和陈重阳有几分相似，但在照片上，那个年轻人笑得很开心，脸上的表情干净得让人有些不适应——那是还没被资本腌入味之前的笑容。照片底边有一行钢笔字，字迹工整，带着点稚气：“我妹妹说，我在星辰科技工作，她以后再也不怕被人欺负了。”

妹妹？

陈重阳有个妹妹？他的资料上不是写着……独生子吗？

林一凡心头一紧，想把照片摘下来，但玻璃框边缘的金属封条焊得死死的，根本没有松动。他不再纠结，继续往上走。

楼梯的尽头是一扇金属门，门板中央用激光蚀刻着八个字：

“摸鱼三分钟，留下两年命。”

林一凡站在门前，愣了半秒。

这八个字，他在前世的某个深夜加班时在一罐能量饮料的罐底看到过，一模一样。那罐饮料他喝完就扔了，从来没跟任何人提过。这扇门为什么会知道？

他伸手推门。

门开了。

门外是水塔间的走廊，蓝焰已经熄灭，整个空间静悄悄的。而走廊尽头，王姐就站在那里，手里拿着一把银色的钥匙，目光穿过黑暗，直直落在林一凡脸上。她慢悠悠地说：“你出来了。那你应该想清楚了——拿什么来换009号钥匙？”

林一凡看着她，忽然笑了：“王姐，你要的‘命’，不会是我想的那条命吧？”

王姐也笑了，老人脸上的皱纹舒展开来，像一张被揉碎了又铺平的地图：“我说的命，是你那三年996的寿命。你上辈子猝死，但你的命被资本神提前扣走了一部分。我要的就是这部分——你愿意拿出来换这把钥匙吗？”

林一凡沉默了一瞬，然后问：“拿了009号钥匙，我能打开什么？”

王姐的回答让他浑身一凛：“打开你前世的死因报告。你有没有想过——你那晚猝死，真的只是因为加班吗？”

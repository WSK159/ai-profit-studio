# 第129章 碎片坐标

那波纹形的凸起在中转舱壁上缓缓消退，像是某种巨大生物在金属表面轻轻按了一下手指，又收回了。

林一凡盯着那片恢复平整的舱壁，后背的汗毛根根竖起。

“你们……刚才都看见了吧？”他把声音压到最低，像是怕惊动什么东西。

赵日天脸上的肌肉绷得像一块铁板。他没有说话，只是缓缓点头。

老王却愣愣地看着舱壁，眼神有些涣散。过了好一会儿，他才像被唤醒一样打了个哆嗦，声音干涩：“什么……什么凸起？我刚才走神了。”

林一凡和赵日天对视一眼。老王刚才明明就站在他们旁边，一个直径足有一米多的凸起在金属舱壁上挤出了波浪形的褶皱，他怎么可能没看见？

除非——老王的神智刚才又被什么东西接管了。

【摸鱼系统提示：检测到宿主情绪波动异常。是否开启“摸鱼空间”进行心理状态校准？】

林一凡默默在意识里回了一句：先别管我的心理状态，你告诉我，那是什么玩意？

【摸鱼系统提示：检测到不明能量场波动，与卷王系统制造的能量特征相似度为78%。建议立即离开当前区域。】

卷王系统？不对，钱国豪已经走了。他刚才明明消失在伪神之殿方向……

“别管那些了。”赵日天突然开口，声音恢复了他一贯的冷硬，“钱国豪给了我们卫星F-7的坐标。那是现在的首要目标。第二枚暗码碎片在那里。”

林一凡没有立刻回应。他把目光转向中转舱宽阔的观景窗——窗外，月球乳白色的表面占据了半边视野，在太阳的照射下泛着灰白色的光芒。无数颗卫星在轨道上静静地漂浮着，有些锈迹斑斑，有些仍然闪着工作指示灯。

“他说的是哪颗卫星？”林一凡问。

“F-7。”赵日天抬起手腕，一道光屏从他手腕上的金属环投射出来，显示出一组三维坐标，“军用通讯中继卫星，废弃于六年前。轨道高度约四万公里，现在正在月球远地侧。”

“远地侧？”林一凡皱眉，“那里信号弱、光照条件差，而且基本没有人类活动。为什么暗码碎片会被放在那种地方？”

赵日天盯着光屏：“如果暗码碎片是故意被放上去的，那说明藏它的人不想让任何人轻易找到。比如——”

他停住了。

“比如？”林一凡追问。

赵日天关掉光屏，声音冷淡：“比如那个设计了这一切的人，钱国豪自己。”

气氛凝滞了几秒。

老王这个时候才缓过神来，揉了揉太阳穴：“不管是为什么，咱们总不能一直待在这个中转舱里吧。刚才那个凸起……反正我是不想再看到第二次了。”

“他说要解开轨道锚点才能返回地球。”林一凡回忆起钱国豪那句话，“就算咱们拿到了碎片，回不去地球也是白搭。老王，你在浮空港待的时间最长，轨道锚点是个什么概念？”

老王沉思了一下：“浮空港悬浮在天上，和卫星轨道根本不是一个体系。轨道锚点……我听过一个说法，是浮空港和近地轨道之间的‘连接节点’，平时根本不会激活。需要什么特殊的密钥，或者——某个高等级权限者的授权。”

“钱国豪让我们去卫星上找碎片，又告诉我们回到地球需要解开轨道锚点。”林一凡把这些线索在脑子里连成一串，“这看起来是个死局：没有锚点就回不去，没有碎片就解不开锚点，只有拿到碎片才能解开锚点回到地球。”

他忽然笑了笑：“但他漏了一个问题——锚点是谁设置的？如果是他设置的，那锚点的密钥就一定在他身上。可他让我们去找碎片，而不是去找他要密钥。”

赵日天微微眯起眼睛：“你是说，碎片和锚点可能是同一个东西？”

“不。”林一凡摇头，“我是说——第二枚碎片可能不只是‘碎片’本身，它也可能是一个‘钥匙’。找到它，才能打开一个更大的局。”

【摸鱼系统提示：宿主动态任务触发——【第二枚暗码碎片·F-7卫星】。任务目标：在卫星F-7上获取第二枚暗码碎片。任务奖励：解锁“摸鱼空间·零重力模式”，咸鱼值+5000。】

零重力模式？林一凡心里一动。下一站是外太空，这技能来得恰到好处。

他收起思绪，走向舱壁边上的储物柜，拉开一扇金属门，里面整齐地摆着三套舱外航天服。深灰色的面料，胸口绣着“浮空港·应急”的字样，看起来已经有些年头了，但功能完好。

“换上吧。”林一凡扔了一套给赵日天，又丢了一套给老王，“钱国豪给了路，总不能不去走一遭。但我得提前说好一件事——”

他转过身，目光灼灼地看着赵日天：“卷王，你跟我们一起去找碎片，但你是冲着碎片去的。如果后面出了什么岔子，你敢在我背后捅刀子，我保证让你知道什么叫真的‘摸到死’。”

赵日天嘴角微微勾起一丝弧度，接住航天服：“放心。在你死之前，我会一直在你前面——我比你先拿到碎片。”

就在这时，中转舱的灯光闪烁了一下。

然后，又是那个声音——从舱壁深处传来。这次比上一次更清晰，像是有什么东西在金属管道里爬行。

老王脸色刷地一下白了：“又来了……”

林一凡三步并作两步冲到最近的舷窗旁，向外看去——

浮空港的外部金属结构上，有一道暗红色的影子，正在缓缓移动。

那轮廓，像是一个人形。

但它的体积，比正常人类大出了整整三倍。

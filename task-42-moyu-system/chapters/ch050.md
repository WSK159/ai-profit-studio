# 第50章 双面钢印

陈哲的办公室在安全部最里侧，窗台上摆着一盆快蔫的绿萝，桌角压着一摞门禁记录打印件。他把咖啡放在林一凡面前，自己靠着桌沿坐下，姿态松弛得像在跟老朋友聊天。

“你脸色不太好。”陈哲端起自己那杯，吹了吹，“比赛出意外了？”

林一凡没碰咖啡，笑着摇头：“没有，题目不难。”

“那就好。”陈哲喝了口咖啡，目光落在窗外，“前天我说的事，你还记得吧。沈敛账号那事儿，我已经帮你把日志封档了。三天之内不会有人查到那笔操作。三天之后，复赛成绩公布，就无所谓了。”

话里话外透着“我帮你擦屁股”的意思。林一凡指尖在杯沿上划了一圈，半天没说话。他从来不习惯欠人人情，更何况这个人三天前还在朝他要“某些代价”来交换情报。

“陈主管，”林一凡把声音压低，“你帮我，到底图什么？”

陈哲端着杯子的手顿了一下，然后笑了，露出一口白牙：“我说了，我有我的钢印。”

他拉开抽屉，翻出一枚徽章——钢制，圆形，巴掌大小，中央刻着一座天平的浮雕，下面压着一行小字：数据正义联盟，监督员。

“这是什么？”林一凡皱着眉头。

“星辰科技有个内部监督小组，成立三年了，不对外公开。成员以安全部、法务部、审计部的中层为主，专门盯着数据造假和职场腐败。”陈哲将徽章收回去，“我找沈敛的账号，不是因为上面有人查，是因为我在查秦氏跟星辰之间的数据暗线。”

林一凡心里咯噔一下：“那你之前说‘我也在查’……”

“都是真的。”陈哲直视他，“但我知道你怕我。”

他忽然俯下身，声音更轻：“我建议你别碰TEST-03B键帽下的纸条。我往那台机器上插了监控探针，你按F12的记录，后台已经存了。”

林一凡脊背一凉，但脸上还挂着笑：“那我为什么还坐在这里？”

“因为我看了你的调试窗口输出。”陈哲直起身，“你查到了那个IP段，对吗？B座十七层，打印共享路由。”

林一凡没否认。

“那个路由器的位置，”陈哲用食指在桌面上画了个圈，“是财务副总监办公室外走廊的墙上。”

“财务副总监……”林一凡咀嚼着这个头衔，“姓什么？”

“姓钱。”陈哲说完这两个字，站起身，把咖啡杯丢进垃圾桶，“钱总的亲弟弟，钱明。”

林一凡的脑子像被闪电劈了一下。钱总——他的老板——亲弟弟是财务副总监；秦氏的数据造假，用的是星辰财务走廊路由器的网络出口；沈敛的账号在离职半年后还能删日志；陈哲睁一只眼闭一只眼放他走……

这三天的所有碎片，似乎在某个瞬间卡进同一个齿槽里，转出了半个轮廓。

他站起来，手机又震了一下。这次不是陌生号码，是老王发来的微信语音，声音压得极低：“小凡，楼下来了辆秦氏的车，车牌尾号718，有个人没下车，在车里坐着抽了二十分钟烟了。我看不清脸，但他举着手机，像是在拍谁的车进车出。”

林一凡握紧手机，抬头看向陈哲。陈哲也正好抬头看他，两人的目光在空调出风口的白雾里撞在一起。

“钱总和秦氏的人接触，就在今天早上。”陈哲的声音不咸不淡，“你打算怎么办？”

窗外传来一阵引擎声，低沉嗡鸣，像某种大型兽类在楼下盘桓。林一凡的目光从玻璃边缘滑过——B座十七层的窗帘此刻半掩着，看不清人影，但窗帘缝隙里有一点亮光，一闪一闪的。

有人在用手机拍照，对着这台办公楼的停车场方向。

“我哪也不去。”林一凡坐回椅子上，“你先告诉我，那个监督小组……有没有钱总的名字？”

陈哲沉默了很久，久到那盆绿萝的叶子突然抖了一下。他缓缓开口，每个字都很轻：“有。他现在是副组长。但三年前，他是组长推荐人。”

他顿了顿，补了一句：“三年前，钱总还不姓钱。他姓沈。”

林一凡的手，猛然攥紧了。

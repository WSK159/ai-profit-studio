# 第57章 监控盲区

警报声在考场内炸开时，林一凡的手指还悬在键盘上方，纹丝未动。

他看见自己的测试机屏幕上，一个权限请求对话框正以极快的速度自动敲入指令——ROOT 权限、秦氏主服务器、批量数据接口。每一行代码都带着他昨天的键入记录，连缩进风格都一模一样。

“有人的测试机在攻击主服务器！”评委席上有人喊。

全场目光瞬间聚焦过来。林一凡没有慌，他的目光越过屏幕，扫向四米外那台覆盖着防尘布的备用机位——陈哲正在那里冲他微微点头。

“我请求调阅我这台机器的网络监控日志。”林一凡站起来，语气平静。

“你当这里是——”秦氏的安全主管刚要开口，却被宋远桥抬手拦住了。

“让他调。”宋远桥说。他坐在评委席最末端，戒指上的半枚紫色纹路在灯光下若隐若现。

两分钟后，监控日志调出。但结果出乎所有人意料：发起权限请求的 IP 地址，解析出来是考场旁边的设备间，而那个设备间早在今天上午就因检修断电了。

“断着电的设备间，怎么发起攻击？”评委面面相觑。

林一凡盯着日志上的时间戳，突然想起什么，低头看了眼手机。屏幕上显示的时间，比他刚才用系统时间校准过的测试机时钟快了整整四分钟。

“时间不对。”他低声说。陈哲也同时掏出手机，两人对视一眼。

考场天花板角落的监控摄像头，那颗红光指示灯正在规律闪烁——每四秒灭一下，正好避开记录帧。陈哲用口型说了三个字：监控盲区。

林一凡瞬间明白了。有人利用摄像头闪烁的间隙，在考场内架设了一台瞬连设备，用它冒用设备间的 IP 地址发起攻击。而那个四秒周期，恰好是秦氏安保系统自动巡检的时间间隔。

“发起攻击的时间，在主服务器响应记录里有。”林一凡转向安全主管，“不查发起端，查响应端——服务器收到第一组指令后，有没有向某个特定端口回传过校验包？”

安全主管狐疑地敲了两行命令，屏幕刷新后，他的表情僵住了。校验包全部回传至一个内部地址，那座地址归属的工位，就是本场选手赵日天的座位。

考场内嗡地炸开了锅。

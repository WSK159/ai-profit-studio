# 第118章 第二颗心跳

石室比外面看起来深得多。林一凡往前走了不过二十几步，墙面上的铜质纹理开始变得密集，像老树盘错的根须渐渐收拢，最终汇聚成一扇同样嵌着铜纹的小门。门上没有任何把手，只在正中央嵌着一块圆形的凹槽——大小恰如他手中那枚银章。

身后的赵日天吹了声口哨：“钥匙自己送上门了？”

林一凡没有立刻动手。他盯着那凹槽边缘看了两秒，发现那圆槽里侧布着一圈极细微的刻度，那不是人类常用的进制——是倒着走的。他把银章凑近凹槽，没有急于嵌进去，而是先观察了片刻。系统提示音再次响起：

【检测到锚点亲和波动。凹槽匹配度92%。注意：这是一道双重锁——需要银章和生物频率同时匹配。建议以您当前心跳作为生物频率基准。时间剩余39分钟。】

老王走到他身边，低声道：“你心跳很快。”

“废话，刚才看到自己前世被重置的画面，换谁心跳都快。”林一凡嘴上这么说，却深吸一口气，努力平复心率。他感觉到银章表面逐渐发热，仿佛在感知他的脉搏频率，然后自行调整着方向，缓缓旋转了约十五度。

“咔哒。”一声轻响，门内部有某种机关联动松开的声音。门中央那圆形凹槽亮起一圈幽蓝色的光，随即整扇门朝两侧滑开——

门后是一个狭小的、约莫五六平米的空间。正中央盘坐着一个人影。那人低垂着头，穿着和林一凡记忆中一模一样的深灰色制服，衣摆上绣着一串已褪色的银线代码：锚-0059。那人没有动，但胸口有微微起伏——他活着。

赵日天本能地摆出戒备姿态：“这谁？”

林一凡没有回答。他走过去，蹲下，伸手轻轻抬起那人的脸。那是一张年轻的、布满疲惫与灰尘的面孔。他刚刚才在记忆碎片里看到过同样的脸——他自己前世的脸。

不是长得像。是同一张脸。石室里，前后两世的锚点，面对面。

“林……”那人睁开眼，目光混沌，干裂的嘴唇动了动，“你怎么……才来？”他的视线越过林一凡，落在他身后悬浮着的、仍在泛光的银章上，“银章母体的命线……你已经接过来了。好……那我还剩下一个东西没还给你。”

“什么东西？”林一凡低声问。

那人伸出那只满是灰尘的手，掌心摊开。那里躺着一枚纽扣大小的透明棱晶，内部封着一缕暗红色的光——像是被凝固的血丝。

“这是你的第二十二条命。”那人说，“我替你留着，等你来拿。”

林一凡瞳孔微缩——二十二。他数过自己经历的记忆碎片。不算“最初的陌生一世”，他这一生已有过二十一次重生。而这一枚棱晶意味着——还有第二十二世的备份。他的系统界面角落里，那一行从来灰暗的标签猛然亮起：

【隐藏功能解锁：锚点回溯·最终权限】

紧接着，石室深处传出一阵剧烈的震动。头顶大片粉尘簌簌而下，管道壁上“根须清除程序倒计时”跳到了27分钟，而且那个数字忽然变成了红色，剧烈跳动起来。

赵日天猛地抬头，声音绷紧：“那个根须清除程序——在我这边显示：已锁定目标，正在加速执行。”

林一凡攥紧那枚棱晶，站起身。他手中银章的震动越来越快，一缕缕暗红光芒从四面八方汇聚而来，仿佛整个覆满根须的负五层，都正在苏醒。

他低声说了一句话，像是在问系统，也像是在问自己：

“它锁定的目标，是什么？”

系统沉默了整整两秒——

【锁定目标：本层所有锚点。包括锚-0027当前载体。包括锚-0059当前载体。包括——银章母体已嫁接线。换言之……锁定的是我们全部。】

门上，那道深红的倒计时，跳到了25分钟。老王脸上最后一点血色也消失了。

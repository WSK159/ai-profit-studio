# 第193章 车上的谈判

黑色商务车在负一层停车场里缓缓驶出，林一凡靠在真皮座椅上，透过车窗看着星辰科技的楼体在视野中渐渐缩小。他脑子里还残留着那12800咸鱼值清零时的空虚感，像是一台一直在轰鸣的发动机突然熄了火，整个世界都安静下来。

“林先生，钱总想先跟你聊两句。”

司机的声音从前面传来，后排的隔板缓缓升起，露出一个嵌在车厢壁的显示屏。屏幕亮了，钱总那张脸出现在画面里。他坐在一张宽大的办公椅上，背后是落地窗外的城市夜景，手里端着一杯红酒。

“小林啊，”钱总的声音带着笑意，“你终于肯主动来找我了。”

“钱总，你这话说得，好像我很抗拒似的。”林一凡靠在椅背上，脸上挂着一副云淡风轻的表情，“我只是觉得，有些事情当面谈才有诚意。”

“诚意？”钱总抿了一口酒，“你那12800的咸鱼值，说没就没了，这诚意够大的。”

林一凡心里一沉。咸鱼值的事刚刚才发生，老周还在密室里，钱总居然就已经知道了。这说明他和人力之源之间，比想象中连接得更紧密。

“钱总消息很灵通啊。”林一凡不动声色。

“你知道吗，小林，”钱总放下酒杯，身体前倾，那张脸在屏幕上显得格外真切，“从你入职第一天起，我就知道你这人不简单。你摸鱼的次数、时长、规律，全都和正常人不一样。我让人查过你，但什么也查不出来。”

“所以你就让老周来盯着我？”

钱总愣了一下，随即哈哈大笑：“周建国啊……他确实跟你有点渊源。但他不是我安排的人。”

林一凡眉头微皱。

“我说过，你脑子里有钥匙。”钱总的声音沉下来，“我也知道人力之源是什么样的地方。那个密室，那台装置，周建国在里面守着的东西——那只是整个系统的一小块皮罢了。”

“你想要的到底是什么？”

钱总露出一个意味深长的笑容：“你先听到这个——赵日天欠我那120万，我已经不打算要了。但他必须把你带到我这来，这是交易的一部分。”

林一凡瞳孔一缩。

“赵日天……”他低声重复着这个名字，“你拿那个来威胁他了？”

“我只是给了他一个选择。他选择了带着你找到人力之源，再让你自己决定要不要来见我。你看，小林，我没有强迫任何人。你自己走上的车。”

林一凡沉默了。

他想起赵日天在密室里那些怪异的表现——像是心虚，像是在躲闪着什么。原来那张120万的旧账，竟然是钱总早已布好的一步棋。他用那笔账，在两大系统拥有者之间，播下了一枚棋子。

“我脑子里的钥匙，”林一凡忽然开口，“你知道它是什么吗？”

钱总的眼神亮了一下：“我等着你告诉我。”

“那你得先告诉我另一件事——人力之源的核心装置上，有人工干预的痕迹。那是谁做的？”

屏幕上的钱总表情僵了一瞬，随即恢复如常：“这个答案，等你真正站在我面前的时候，我再告诉你。”

隔板缓缓升起，屏幕消失了。林一凡独自坐在后排，望着窗外流动的城市灯火，指尖轻轻敲打着膝盖。他闭着眼，在脑海里默数着倒计时——距离咸鱼值清零，还有72小时的“冷却期”。

而赵日天，此刻应该已经从密室暗门离开了吧。

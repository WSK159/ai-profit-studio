# 第389章 台阶下的白线

第三级台阶的右侧角踩上去时触感极轻，像是那一小块石头底下藏着什么中空的结构。林一凡的脚掌只压低了一寸，台阶深处便传来一声干涩的石磨声响，道极窄的缝隙从上而下裂开，刚好容一个人侧身挤入。

通道里的空气骤然变冷，带着一股水锈和旧铁的味道，像是这个通道底下通着一条很长的管道，管道尽头是一座极深的水井。

沈稚川侧身挤过缝口，脚步很稳。三叔在更深处等着他们，老人手里不知何时多了一盏白铁皮做的油灯，火苗小得几乎看不出在烧，却把周围几米照出一种冷青色的光。

通道又走了大约二十米，前方豁然开阔。一个方形石室的影子从光照的边缘浮现出来。石室大约四米见方，四面墙上嵌着生锈的铁环，地上铺着一层白色的石灰线，画出一个奇怪的圆形图案。

林一凡蹲下来，指尖抹过一条白线。石灰是新的，画上去不超过半天。

“你画的？”他问三叔。

老人摇头：“我上次来这里，是十四年前。”

沈稚川沉默地走进石室中间。圆形石灰图案的正中央放着一样东西——一台老式的石板印刷机，落满灰尘，滚轴上还卡着一张半成品。

那张纸上印着一行字：“归墟不是地点，是一个人。”

和老人之前出示的那张纸片一模一样。但林一凡注意到，这台印刷机上卡着的这张纸用了一个不同尺寸的铅字——“墟”字的底部多了一点细微的缺口，像是某个铸字模板被磕掉了一小块。

“十四年前，”沈稚川轻声说，“沈临渊被人从水渠里救上来后，他在哪儿过的夜？”

三叔的油灯微微晃了一下：“就在这里。”

“那这张纸不可能是他写的，”沈稚川蹲下来，指尖戳在那张半成品的印刷物上，“我父亲的字我认得，他从不做这种印刷品，他所有纸条都是手写的。这个做印刷的人，是在故意模仿我父亲的笔迹——而且仿得并不怎么像。”

“你说什么？”三叔的声音像是被什么东西卡住了，整个人微微前倾。

林一凡忽然想到什么，把那块铁皮片从怀里掏出来，放在纸上。两个“归墟”并排放在一起，一个阴刻在铁面上，一个印在纸面上，字体的结构几乎完全一致。铁皮片上的字迹没有缺口，但纸上这个“墟”字缺了一小块。

“铁皮片的字是刻出来的，”林一凡说，“刻字的人用的是同一套模板？”

三叔没有说话。他低头看着那张纸，喉咙里发出一声干涩的吞咽声。良久，老人转身走向石室角落，蹲下去用油灯照亮那里。地面石缝里露出半截锈烂的铁链，链头拴着一个极小的铁环，环上挂着一只小孩的鞋。

那只鞋只有成年人手掌大小，鞋面是旧式的军用帆布，鞋底用麻线纳过，边缘磨得发亮——和沈稚川手里那双旧布鞋的工艺一模一样，但尺寸差了一半，像是同一个匠人用同样的手法做给一个更小的孩子的。

沈稚川看一眼就僵住了。

“这是沈临渊的鞋，”她的声音哑了，“我父亲说过，他小时候在南洞丢过一只鞋，他母亲做了一双一模一样的，补了七年。”

三叔却盯着那只鞋，油灯的光在他脸上照出一片深陷的影子。他忽然用极低的声音说：“我弟弟没有妹妹。我爹娘只生了两个儿子——我和沈临渊。沈稚川这个名字，是你母亲嫁进来之后才改的。”

“你什么意思？”

“我的意思是，”老人直起身，看着她的眼睛，“你父亲跟你说过的很多话，可能都不是真的。包括那双鞋的来历。”

林一凡心里涌起一阵寒意。他看见那只小孩鞋的鞋底上，用红色朱砂写着一个数字，笔画极细，藏在麻线缝里，像是写完后又被什么胶水封住了，只露出一角。

“0。”

零——零号房间的零。

他刚想蹲下看清楚，石室上方忽然传来一声金属撞击的脆响，像是有人从台阶入口处敲了一下铁制的什么物件。三叔猛地抬头。

“外面有人。”

林一凡听见了。那声敲击节奏很熟悉——长、长、短——和沈临渊录音带里那段节奏一模一样。

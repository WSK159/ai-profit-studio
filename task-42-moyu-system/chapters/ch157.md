# 第157章 三人的第一次同频

杂物间里老式日光灯管嗡嗡作响，惨白的光打在老王那张老实巴交的脸上。老王的手掌粗糙发烫，攥着林一凡的手腕说：“小凡，老子存了十年的东西，就交给你了。”

他塞过来一枚拇指大小的黑色U盘，金属壳上布满了细密的划痕，边缘还有一枚不清楚的银色纹路，像是某种古老的符号。

林一凡低头看了看U盘，又抬头看了看老王浮肿的眼袋：“老王，你老实告诉我，这玩意儿里面到底是什么？”

老王咧嘴一笑，露出泛黄的牙齿：“一把钥匙。真正的数据不在这破楼里，在系统的精神空间里。你、赵日天，你们俩的编号互认之后，才能打开那扇门。”

“三人同时打卡三次”这个条件，林一凡咀嚼着这几个字，总觉得哪里不对劲。

“三个人的打卡记录都在服务器后台，”他皱眉道，“宋顾问监控着整个AI考核系统，我们一打卡，他马上就会知道。”

老王神秘兮兮地凑过来，压低了嗓子：“所以才要你拿钥匙。这把U盘能在系统里生成一张‘幽灵打卡表’，每次打卡都是擦着服务器心跳信号的边缘闪进去，不留痕。”

林一凡掂了掂U盘的分量，总觉得这铁疙瘩像是一颗定时炸弹。杂物间外响起脚步声，他迅速把U盘塞进内衬口袋，朝老鱼点了点头。

推开门，走廊里的LED灯管闪烁了一下。赵日天恰好从对面的男厕所走出来，手里端着一杯保温杯，里面泡着枸杞和不知名药材，正冒着热气。

“哟，摸鱼王。”赵日天语气里带着三分挑衅七分警惕，“老王找你谈心呢？”

林一凡嗤笑一声：“谈心？老王教我怎么在考核系统里安全地拉屎。你要不要也听一听？”

赵日天冷哼一声，目光却落在了林一凡鼓起的胸口口袋上。那一瞬间，林一凡看到了对方瞳孔里一闪而过的金黄色光芒——和摸鱼系统面板弹出的光效一模一样。

这家伙，果然也有系统。

“走，厕所说。”林一凡突然来了这么一句。赵日天愣了下，旋即露出一抹了然的表情：“好啊，我倒要看看你能放什么屁。”

男厕所最里侧的隔间里，两人蹲在地上，面对着面。气氛诡异得像两个毒贩在接头。

林一凡掏出U盘，压低声音：“老王的意思，让我们俩同时打卡三次，一起进摸鱼空间。”

赵日天的眼皮跳了跳：“那个老东西连这个都告诉你了？”

“他还说，宋顾问正在搞什么归并，想把我们的编号吞了。”

“归并……”赵日天重复这个词，脸色阴沉下来，“我的系统最近给过一个警告：存在未知编号试图渗透数据池。我以为是AI考核系统在抓我，没想到是同行。”

两人对视两秒，同时冷笑了一声。这是他们第一次在摸鱼这件事上达成共识。

林一凡看了眼手机，时间指向十一点五十八分。中午打卡时间马上就到了——每天十二点整，所有人必须在同一台考勤机上签到。

“第一次打卡，现在。”他说。

赵日天没有犹豫，从口袋里掏出一张皱巴巴的工卡。林一凡也把工卡摸了出来，U盘插在手机上，一道淡蓝色光幕在两人之间展开——幽灵打卡表的界面出现了。

十二点整，两人先后把工卡贴在考勤机上。那个瞬间，林一凡感觉自己的意识里划过一道凉意，仿佛有什么东西在系统深处轻轻合拢——像一扇生锈的门，终于被人推开了一条缝。

眼前一花，他又站在了那间四面都是白墙的摸鱼空间里，但这一次，他面前多了一个人。

赵日天双手插兜，站在白墙中央，一脸戒备地打量四周：“卧槽，你这空间比我的破网吧高级多了。”

林一凡看着自己面板上跳出的提示，冷笑：“还有两次。从现在算起，再打卡两次，归并大战就正式开局了。”

赵日天挑眉：“你就那么确定宋顾问第一个开刀的对象是我？”

林一凡正要说话，整个摸鱼空间突然剧烈抖动。

天花板裂开的缝隙里，渗出一行暗红色的文字——**标记完成。倒计时，四十八小时。**底下是一个灰蓝色编号：M-017。

老王说M-017是谁，他还没说完，杂物间就被打断了。林一凡盯着那串编号，忽然想起那晚加班的离职名单上，唯一没被裁掉却被封了工号的离职员工……

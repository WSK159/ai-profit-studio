# 第122章 反向捕猎

赵日天说得没错，猎手的速度确实快得离谱。林一凡的“断根干扰”技能刚激活，那只人形怪物已经扑到了他面前，根须凝成的爪子带着腥风直冲他的面门。

他侧身闪避，爪子擦着肩膀刮过，衬衫裂开一道口子，皮肤火辣辣地疼。但系统的干扰波形已经锁定目标——那枚银色的断根暗码。一道肉眼不可见的电磁脉冲从林一凡掌心射出，精准地击中猎手胸口的暗码。

“吱——”

猎手发出一声尖锐的悲鸣，整个身体剧烈痉挛。胸口的暗码发出刺目的白光，表面的纹路像是被高温融化的电路板，一块接一块地剥落。

“就是现在！”林一凡对老王喊，“把它胸口的碎片扯下来！”

老王一辈子老实人，但生死关头反而爆发出惊人的胆气。他抓起地上赵日天掉落的那根金属管，对准猎手胸口被破坏的暗码位置，用力捅了进去。

“噗嗤”一声，猎手的身体像被扎破的皮囊，暗红色的黏液四处飞溅。它挣扎着后退，根须组成的手臂疯狂乱抽，老王被扫倒在地上，但金属管已经完成了它的使命——那枚暗码碎片被撬了出来，落在地上滚了几圈，发出一声清脆的叮当。

猎手失去暗码的瞬间，整个身体像断了电的机器人，动作僵硬下来。它发出一连串意义不明的嘶哑音节，然后从四肢开始，根须一条条枯裂、碎裂，最终崩塌成一堆碎木烂渣。

石室安静了三秒。

赵日天愣愣地看着那堆残渣：“……这就完了？”

林一凡没空回答，他捡起地上的暗码碎片，指尖触碰到它的一瞬间，脑海中涌入一段清晰的信号流——包含坐标、时间戳，以及一段加密的指令序列。

他的瞳孔骤缩。

“清除程序的源头不在地下，也不在母体内部，”他转过身，看着铜柱上还在蔓延的裂纹，“它在天上。”

老王捂着被划伤的胳膊爬起来：“天上？”

“卫星。”林一凡将暗码碎片对准系统面板的读取区，屏幕上立刻浮现出一组经纬度坐标，“有人把清除程序装在了一颗低轨道卫星上，通过断根暗码作为中继信号来触发母体的自毁。我们在地底下再怎么折腾，都只是跟它的信号源在比赛。”

赵日天嗤笑一声：“所以呢？你还能把卫星打下来不成？”

“打不下来，但我可以反写它。”林一凡的嘴角勾起弧度，“这颗卫星要接收暗码信号才能触发程序，现在暗码碎片在我们手里，信号源被截断了。只要我把它回写成一枚炸弹——让卫星以为母体已经完成自毁——它就会自动终止清除指令，关闭这个定时倒计时。”

老王听得一头雾水：“还能这样？你不就是个程序员吗？”

“摸鱼系统的程序员，也是程序员。”林一凡说着，系统面板已经弹出倒计时窗口——剩余时间00:17:02。他咬破手指，将一滴血抹在暗码碎片上，系统界面立刻开始高速运算。

赵日天靠着铜柱坐下，皱着眉问：“你刚才说的卫星，到底是谁放的？”

林一凡顿了顿，手指在虚拟键盘上飞速敲击，输出的字符串越来越长，但他的话却短暂地停顿了。片刻后，他说：“我在回溯时看见的实验室指纹，跟当年钱总跟资本神签的那份合同上的附条编码一模一样。”

老王和赵日天同时愣住。

“钱总不只是个压榨员工的老板。”林一凡的眼中闪着复杂的光，“他跟我们一样，也都是某个更大棋局里的棋子。”

倒计时跳到00:11:47。

他手中的暗码碎片忽然发出一道亮蓝色的闪光，整个铜柱上蔓延的裂纹像被施了咒语般骤然停止，然后以肉眼可见的速度开始回缩。

三人盯着这一幕，连呼吸都屏住了。

石室的四面墙壁上，那些一直发出暗红色光芒的根须终于暗淡下来，恢复成普通的棕褐色。倒计时面板在00:09:59的位置停了下来，然后数字跳动了一下，显示出新的内容——

「清除程序已终止。锚点-0059记忆链回收完毕。系统下一个节点：浮空港。」

林一凡皱了皱眉：“浮空港？”

“那是什么地方？”老王的声音里带着不安，“我从来没听说过。”

赵日天却忽然坐直了身体，目光直直地盯着系统面板上那个闪动的坐标。“我认识。”他压低声音，“我之前做卷王系统任务时，曾经收到过一条加密指令，发布者的归属地标记就是浮空港。”

石室头顶上方传来一声沉闷的轰响，像是某种巨大机械重新启动的声音。三人同时抬头，看见天花板裂开一道缝隙，一束冰冷的天光从裂缝中照下来。

出口出现了。

但是没有人动。因为他们都知道，这道出口之外等待他们的，是一条通往某个完全未知的路——而那个叫“浮空港”的地方，可能藏着这场赌局最底层的答案。

林一凡深吸一口气，弯腰捡起地上的金属管，把它递给赵日天。“走吧，”他说，“前面总得有人去敲门。”

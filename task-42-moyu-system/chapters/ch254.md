# 第254章 十三楼

陈建国比照片上老了很多，头发花白，眼窝深陷，瘦削的颧骨在灯光下显得格外突兀。他手里那部手机是前年最老款的型号，屏幕布满划痕，但摄像头位置装了全新的广角镜头。

“你们见过秤房了。”陈建国的声音干涩，像很久没喝水，“那台机器我没法关，只能等真正有资格的人来。”

林一凡看着他手里的009号钥匙：“你就是‘最后一个知道真相的人’？”

陈建国没直接回答，而是低头看了一眼手机屏幕，上面密密麻麻滚过一行行代码，界面和林一凡见过的任何系统都不一样，那套界面上挂着无数个“命”字段，像账本一样排列。

“009号钥匙，是我二十年前从负六层挖出来的。我当年只是个刚入职的维修工，接到了去检查负六层照明线路的任务。”陈建国抬起头，目光穿过所有人，落在墙上那盏白炽灯上，“然后我碰见了那台秤。它称了我第一次，说我的命债可以抵扣一部分，让我成为‘维护工’。条件是——看管这台秤，等到有资格开启第十三刻度的人出现。”

“那你为什么不自己开？”陈默追问。

陈建国苦笑：“第十三刻度需要三把钥匙同时插进锁孔，才能启动‘自由协议’。但这三把钥匙，有一个铁律——持有者身上不能有任何‘债务’。我当年在负六层多看了那台秤一眼，就已经欠下了一笔命债。我自己开不了。”

他晃了晃手上的手机：“所以这些年，我只能通过摄像头，把一个一个能找到线索的人引入这条长廊。”

李思站在旁边，目光落在地面：“我第一次遇到他，是在三年前。”

“三年前？”老王皱眉，“陈建国不是早就被裁了吗？”

“那是假档案。”李思说，“他没法离开这栋楼——他的命债绑死在负六层。一旦离开超过二十四小时，秤就会启动清算程序，整个公司所有员工的命债都会提前结算。”

林一凡终于把最后一块拼图接上了：“所以你不是失踪了，你是出不去。”

陈建国点头，然后转身朝楼梯口走去：“跟我走，错错班。”

众人跟上，赵日天迟疑了一瞬，也跟了上去。没人再提倒计时的事。

陈建国带着他们穿过地下一层的走廊，经过一扇锈迹斑斑的铁门，沿着一条从未有人注意过的楼梯一直向上。林一凡数着楼层：负一、负二、负三……他数到十一层，停在楼梯尽头，一扇标着“13”的金属大门。门上没有把手，中央是一个直径半米的圆盘，盘面均匀分布着三个锁孔，成等边三角形排列。

林一凡、老王、李思同时上前一步，将007、008、009三把钥匙插入锁孔。

圆盘发出一声沉闷的齿轮咬合声，开始缓缓旋转。

就在这时，林一凡的手机又震了一下。系统弹出新的提示：“警告：自由协议启动将触发资本神一侧的强制查看，星辰科技总公司将在五分钟后收到‘非正常协议活动’报告。请确认是否继续。”

“五分钟。”陈建国重复了一下这个词，“如果你们现在拔钥匙，协议会封存，等下一个二十二年。但如果继续……”

他顿了一下：“你们将正式被卷入神明的赌局之中。”

林一凡看了一眼赵日天，后者咬着牙，额头渗出一层汗珠。

“继续。”林一凡说。

圆盘发出一声震耳的轰鸣，金属门从中间裂开一道缝隙，泄出刺目的白光。白光之中，林一凡看到了，一条深不见底的走廊。走廊的尽头有一把铁椅子，椅子上坐着一个穿黑色西装的影子，那影子手里握着一柄小锤——和负六层秤房里的那台秤如出一辙。

影子抬起头，露出一张熟悉的脸。

是钱总。

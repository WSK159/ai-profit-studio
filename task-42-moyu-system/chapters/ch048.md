# 第48章 复赛的入场券

林一凡盯着陈哲那只停在桌面上的手。停顿了大约一秒，陈哲收回手，摘下眼镜擦了擦，重新戴上，语气平静：“你从哪听来的这个名字？”

“您先回答我的问题。”

“我不知道什么接口人。安全部只做内部核查，不接触外部企业。”陈哲的语气滴水不漏，但他擦眼镜的动作出卖了他——刚才那一秒，他的目光扫了林一凡的胸口一眼，像是在确认什么。

空气安静了几秒。林一凡把手伸进内兜，掏出赵日天给的那个牛皮纸信封，推到陈哲面前：“这是有人让我进门前看的。您看完再决定接下来怎么问。”

陈哲没碰信封，只低头扫了一眼边缘，目光定住——信封背面右下角印着一枚不起眼的钢印，圆形，内圈是一朵云纹。

陈哲看了那花纹三秒，然后叹了口气，伸手把信封拿起来，没有打开，而是直接锁进了自己左手边的抽屉里。他的语气变了：“周三复赛，你会用哪台机器？数据从哪走？”

林一凡心里一震。这句话问得太具体了，像是陈哲早就知道复赛的筹备细节。他没露声色：“星辰这边会分配一台测试机，数据走内部临时库。”

陈哲拿起桌上的便签，快速写了两行字，折成四折推过来：“机器分配单下来，你先别碰。找一台编号末尾是A的备用机，把系统时间调快四分钟，然后用你的账号登录一次就行。”

“四分钟？”

“秦氏那边做假数据，用的是时间戳对齐脚本。你机器比基准快四分钟，他们的脚本会算错窗口期，出来的数据会带一个系统性偏差。”陈哲推了推眼镜，“到时候你再把正常数据一跑，他们所谓的铁证，就会变成自爆的bug。”

林一凡的瞳孔微微一缩。这已经不止是“内部核查”了——陈哲知道秦氏造假的手法，知道假数据的时间戳机制，甚至知道怎么反制。而他把这些都告诉了一个“被调查对象”。

“陈主管，我能问一个冒昧的问题吗？”林一凡折起便签，塞进内兜。

“问。”

“您是站在哪边的？”

陈哲沉默了一瞬，然后淡淡开口：“我站在数据本身那边。安全部不管谁的公司，只管数据和规则。有人想把数据当武器，那就不行。”

十点十七分，林一凡走出安全部时手里的便签只有薄薄一张纸，但感觉比Zippo打火机还烫手。他刚回到工位，老王就凑过来，压低声音：“没事吧？”

“没事，聊的都是备份和日志。”林一凡没多说，目光却扫了一圈整个办公区——正对工位的摄像头是前天新装的，红点一直在亮。

他低头打开内部系统，点开设备分配表。副本显示周三复赛共有两台备用机供参赛者选择，编号分别是`TEST-03A`和`TEST-03B`。他用余光扫了一眼分配表底部的操作记录，发现`TEST-03A`在今天早上八点五十分被一个系统账号“预分配”给了“参赛者-林一凡”。

预分配。八点五十。他今天八点四十才到公司。

林一凡的手指在键盘上停住。是钓鱼？有人想让他主动去碰那台机器，好留下把柄。也可能是陈哲说的“机器分配单”，这台03A可能就是计划的第一步。

他正想着，手机弹出一条消息，发件人是一个没有备注的陌生号码：“周三你别用03A。用03B，键盘右手第二个键帽下面，有东西。”

林一凡盯着那条消息看了三秒，然后缓缓把手机反扣在桌面上。窗外的天阴沉沉的，复赛还没有开始，整个场地已经被架好了两条暗线——有人想让他选A，有人让他选B，机器下面的那个“东西”，又是谁放的？

他拉开键盘，开始敲代码，节奏不快不慢，像一条在深水里游动的鱼。明天的复赛，必须赢了。

# 第147章 维修通道尽头的门

晚上九点五十八分，林一凡站在星辰科技总部B3层的北侧走廊尽头。

这层是废弃的档案区，灯光坏了大半，头顶的日光灯管像垂死的萤火虫一样间歇性闪烁。空气里弥漫着霉味、灰尘和某种难以形容的铁锈气息。他抬头看了看墙角的监控摄像头——镜头上覆盖了一层厚厚的灰，指示灯暗着，显然是坏掉的。

“真会挑地方。”他低声嘀咕了一句，抬手看了一眼手机屏幕，九点五十九分。

十点整，维修通道的铁门发出“吱呀”一声响，缓缓向内推开。

宋顾问从黑暗中走出来。仍旧是那副金丝边眼镜，深灰色西装，手里提着一个公文包。他看起来依然干净整洁，和这层灰暗破旧的环境格格不入。

“很准时。”宋顾问的语气平淡，仿佛这只是一次普通的碰面。

林一凡靠着墙壁，双手插在外套口袋里，歪着头打量他：“你这短信发的，跟地下党接头似的。‘不要信任老王’，‘B3A层钥匙孔不在门上’，有意思。那现在，能不能说说你到底是谁？”

宋顾问没有回答，而是转身走进了维修通道。走了几步，他停下来，侧过头：“跟上来。”

林一凡沉默了两秒，最终还是跟了上去。

通道很窄，两人并肩很难通过，头顶的管道密密麻麻地交错着，裸露的电缆像某种重金属植物的根须。走了大约四十米，前方尽头出现了一堵墙——水泥墙面，灰色的，看起来与普通墙体没有区别。

但宋顾问停下脚步，伸手在墙面上抚过，手指停在一个不起眼的凹陷处。那凹陷藏在管道的阴影里，若不是刻意去找，几乎不可能被注意到。

一把锁孔。铜质的，锈迹斑斑。

可它的周围——没有门。

一把插在墙里的钥匙孔。

林一凡盯着那个锁孔，眉头慢慢拧紧。他忽然想起来图纸背面那句话：“B3A层唯一的钥匙孔不在门上。”

原来真的是字面意思。

“这面墙后面有什么？”林一凡问。

宋顾问看着他，摘下金丝眼镜，用衣角擦了擦，重新戴上。他的神情在昏暗的灯光下看起来有些复杂，像是在做一个重要的决定。

“你在效率之星评审会上那一击，做得很好。”宋顾问忽然说，“但你也因此触碰到了不该碰的东西。”

“什么意思？”

“赵日天背后那家日天数据公司，你以为它只是做AI考勤的？”宋顾问冷笑了一声，“它只是冰山一角。真正藏在下面的，是一座你们这个时代不该看见的冰山。”

他从口袋里取出一把奇形怪状的钥匙——它的齿纹呈现出一种螺旋状的结构，看起来像某种精密仪器的一部分。

“你找到它，是因为你已经被选中了。”宋顾问将钥匙插入锁孔，轻轻一拧——墙内传来一阵低沉的机械运转声，像是一台沉睡多年的引擎被唤醒。

“选中？被谁选中？”林一凡追问道。

宋顾问没有回答，他的目光越过林一凡的肩膀，看向通道入口的方向。他的瞳孔微微收缩了一下，然后平静地抽出钥匙，重新放回口袋。

“有人在靠近。”

他转身，快步消失在通道深处，声音从黑暗中飘回来：“明天，你会收到一个邀请。别拒绝。”

林一凡站在原地，看着那堵墙。刚才那阵机械运转声已经消失了，一切恢复了死寂，仿佛什么都没有发生过。

他拿出手机，打开系统面板。

【系统提示：检测到宿主接触“B3A层异常节点”，剩余锁定时间：17小时26分钟。另，检测到隐藏任务已触发——“打开那扇不存在的门”。奖励：未知。风险：极高。】

林一凡盯着那行字，忽然笑了。

“又是这样。每当我以为摸到了边，感觉就像是被谁牵着鼻子走。”

他攥了攥拳头。赵日天、日天数据、宋顾问、老王，还有那个藏在这堵墙后面的秘密——这些东西像一团纠缠在一起的乱麻，但他总觉得，它们正渐渐指向一根共同的线索。

他转身往回走，脚步声在空旷的通道里回荡。快走到出口时，口袋里的手机嗡地震动了一下。

是一条短信，发自一个完全陌生的号码：

【今晚你看到的墙不是墙。它是门。而门的钥匙，你手里早就有了。】

【锁孔不在门上，而在你的系统面板里。】

林一凡的脚步猛地顿住。

他低头看向自己的系统面板——在右下角，那个本不该存在的位置，不知何时多出了一道微弱的金色光芒。那光芒像呼吸一样，一明一灭。他下意识地伸出手指，点了一下。

系统面板弹出一行字：

【隐藏模块激活：咸鱼之钥。功能未知。解锁条件：完成“打开那扇不存在的门”任务。】

林一凡收起手机，抬头望向走廊尽头的那扇维修通道铁门，门缝里透出一丝冷风，吹得他后脖颈一阵发凉。

他忽然觉得，这整栋大楼，远比表面看起来要深得多。

# 第158章 M-017

白光一闪，林一凡从摸鱼空间被弹了出来。男厕所的水龙头在滴答滴答地响着，手机屏幕上的时间跳到了十二点零一分。赵日天也回来了，正扶着洗手台大口喘气。

“M-017……”赵日天咬牙切齿地念出这串编号，“那是老王的旧编号吧？不，不对，老王的编号是M-003。”

“你怎么知道？”林一凡追问。

赵日天直起身子，对着镜子整理了一下衣领：“因为我的卷王系统能看到敌对编号的历史数据。M-017是全球第17个绑定系统的人，比老王都早。但那家伙入职记录里根本不存在。”

林一凡的心跳猛地漏了一拍。他快速打开手机相册，翻到一张旧照片——那是他重生前偶然从人事部电脑里拷出来的离职名单，多数人的名字他都记不清了，但有个名字他记得很清楚，因为那人离职的理由特别离谱：“被行政扣了三个月工资后人间蒸发”。

那个人的工号，尾号就是017。

“钱总的第一任秘书，季敏。”林一凡脱口而出。

赵日天眉心一跳：“季敏？那不是三年前跳楼自杀的女员工吗？”

“官方口径是自杀。”林一凡沉声道，“但我记得，在她出事前一天，她给钱总发过一份邮件，标题只有三个字：归并协议。”

卫生间的日光灯管剧烈闪烁了几下，像是在附和这个阴冷的猜测。

林一凡的手机突然震动起来。是老王发来的消息：“饭堂见。”

两人一前一后走进饭堂时，老王已经坐在角落里，面前摆着两荤一素，筷子纹丝没动。他面色蜡黄，像是一夜没睡。

“打卡成功了吗？”老王压低声音。

林一凡点头：“第一次。”

老王眉头稍展：“好。下午和明早各一次，三次全齐，你们就能一起进摸鱼空间的深层区域，那里有真正的数据池。”

赵日天用筷子戳了戳盘子里的排骨：“但你还没告诉我们——那个数据池里装的是什么东西？”

老王沉默了五秒，放下筷子。他的手背青筋暴起，像是下了什么决心：“装的是所有绑定者的契约副本。谁拿到那份数据，谁就能改写一切——包括归并协议的权力。”

林一凡瞳孔一缩。

“那宋顾问……也是想抢这份契约？”

“宋顾问？”老王扯出一个苦涩的笑容，“你们以为他是幕后主使？”

他那双布满血丝的双眼，转向饭堂入口的方向。林一凡顺着他的视线看去——饭堂门的帘子被人掀开，钱总穿着一件笔挺的西装，正笑着陪在一位戴金丝眼镜的女人身边，朝这边走来。

那女人的胸牌上，清清楚楚地写着三个字：“季顾问。”

林一凡的脊背瞬间发凉。那个名字挂在她胸口的牌子上，像一个墓碑。赵日天手里的筷子“啪”地掉在了桌上。

金丝眼镜女人似乎感受到了他们的注视，远远地朝这边偏过头，嘴角弯起一个礼貌而冰冷的微笑。隔着半个饭堂的距离，林一凡却觉得那笑容像一把手术刀，精准地剖开了他的胸口。

她的目光在他身上停顿了半秒，然后缓缓移开，随着钱总走向了贵宾就餐区。

老王声音嘶哑发干：“M-017就是她。她压根没死。三年前她跟钱总做了一场交易——用假死换取系统的部分权限编码。现在，她带着AI考核系统的核心程序回来了。”

林一凡攥紧了手里的U盘——生锈的铁壳温度冰冷。他想起杂物间里宋顾问那些奇奇怪怪的话：“宋顾问，你还记得钱总的旧秘书吗？”

老王抬起头，目光闪烁着异样的光芒：“宋顾问？她的事情，宋顾问从头到尾都知情——因为宋顾问就是她。”

饭堂的喧嚣瞬间像被按了静音键。林一凡的脑海轰然炸开一片空白——他想起来，宋顾问那张脸，细看之下，确实与钱总办公室里挂了三年的那张“最佳员工纪念照”上的年轻女秘书，有着说不出道不明的相似。

而现在，那位拍了纪念照的人，正端着餐盘坐在贵宾室里，用戴着黑手套的右手，轻轻朝他们这边举杯。

杯沿上，她嘴唇翕动，无声地说了五个字。

林一凡读出了口型——**“游戏开始了。”**

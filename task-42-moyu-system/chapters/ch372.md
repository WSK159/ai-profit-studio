# 第372章 零号门后

铁闸合拢的巨响在密室里回荡了整整三秒，金属与石壁摩擦的声音像一根根钢针扎进耳朵。林一凡抹了一把额角的冷汗，目光死死盯着脚下那块被他们掀开的石板。

石板下方的铁质阶梯已经锈迹斑斑，但每一级台阶上都有一道深深的手印——有人来过，而且不止一次。赵日天蹲下来，手指沿着金属门边缘的密封条慢慢滑动，神色凝重到近乎扭曲：“这道门……是核防标准。”

“核防标准？”林一凡眉头皱起，“南洞建材厂的地下，搞一个核防标准的门？”

赵日天没有回答。他站起来，从口袋里掏出那只刻着“去”字的黑钥匙，缓缓插进门锁。锁芯转动的瞬间，金属门内传来一连串沉闷的“咔嗒”声，像是被唤醒的某种古老机关。门缝里渗出一股冷风，带着霉味和铁锈的气味，还有一丝若有若无的……消毒水味。

门开了。

门后的空间让林一凡一时间说不出话来。

那是一个环形房间，直径大约二十米的圆形空间，穹顶高处嵌着一圈模糊的玻璃窗，惨白的光线斜斜射下来，将整个空间照得如同手术室。地面上铺着大片白色瓷砖，瓷砖缝里长满青苔和霉斑，但依稀能看出当年这里被擦得锃亮。房间正中矗立着一台巨大的设备，锈蚀的铁壳上写着——

**“第九收容所——归零装置”**

赵日天瞳孔猛缩，他快步冲到那台设备前，双手抓住铁壳的边缘用力掰扯，锈铁片剥落，露出下面的控制面板。面板上嵌着一排排老式拨盘开关和一排指示灯，指示灯大多已经碎裂，只有一个还亮着，发出微弱的琥珀色光芒。控制面板最上方刻着一行小字：

“归零程序，仅限所长权限启动。”

“你父亲的留言里说的‘归零’……不是零号床，是这台设备。”林一凡盯着那台庞大的机器，声音发紧，“铁皮盒里那个留言说‘帮我告诉春伢子：第九收容所的归零，不是零号床。是沈稚冬。’——沈稚冬他……”

他没有说下去。因为他看到了。

设备的右侧，有一张铁床。

铁床上铺着一层发黄的白色床单，床单下隐约有人形凸起，表面落满了灰尘，但轮廓清晰可辨。床头的墙上钉着一块褪色的铁牌，上面写着：

“姓名：沈稚冬。编号：零号。”

“不对……”赵日天声音发哑，“沈稚冬的铭牌说卒于2001年，但是……”他猛地转身，目光落在房间另一侧的墙壁上。

墙上挂着一排照片。照片被玻璃框保护着，玻璃上落满灰，但擦开灰尘之后能看到一群穿着白色工装的人，站在一台和老照片里一模一样的机器前，横幅上写着“第九收容所建成纪念，1998年”。照片下面用黑色签字笔写着一排名字和职务：

“所长：孙满仓。技术顾问：沈稚冬……”

“沈稚冬是技术顾问，不是被收容的对象。”林一凡大脑飞速运转，“那水泥浇铸的尸骸，铭牌上写着‘卒于2001年’，但沈临渊留言说‘沈稚冬没有来过’……整件事是矛盾的。除非——”

“除非沈稚冬是主动下去的。”赵日天接过话头，目光死死盯着那行字，“他是下去送死的人。”

林一凡的后背一阵发凉，沿着墙壁缓缓扫视了一圈。环形墙壁上贴着数张泛黄的表格，全是手写的“值班记录”，日期从2001年7月20日一直到12月31日。表格下方有一行小注：“值班地点：归零室。值班人：孙满仓、沈稚冬。”

“孙满仓和沈稚冬一起值班。”林一凡低声念着，又走到设备侧面，那里有一只挂在墙上的黑木匣，匣盖半开，里面放着一只老式随身听和一盘磁带。林一凡犹豫了两秒，按下播放键。

磁带沙沙转了几圈，一道男声响起，声音沙哑，带着浓重的南方口音：“九月十号，空气滤芯已经在换第四次了。她说还能坚持。”停顿。“她知道回不去了，但还是要我走。”

磁带又转了一圈，第二段录音：“十月三号。我答应春伢子的事做完了。第七梯的井道封死。从今天开始，我是第九收容所的第九块牌子。”

林一凡猛地抬起头，和赵日天对视。与此同时，那台“归零装置”的指示灯突然剧烈闪动起来——琥珀色的光芒变成刺目的红色，转了一圈之后，设备内部发出机械运转的声响。控制面板上的拨盘像被人转动一样，开始一格一格地自动跳动，最后停在一组数字上：

**“07.19”**

赵日天低声念出来：“7月19号……南洞建材厂的收据，也是7月19号。”他脸色铁青。“这装置被设成了定时程序。2001年7月19号，就是这个设备启动的日子。”

话音未落，设备底部传来一声沉重的齿轮声。归零装置的底座缓缓向两侧裂开，露出一道向下延伸的螺旋楼梯。楼梯尽头，冷风上涌，隐约能看见一抹暗红色的光。

林一凡的手机在口袋里震动。他掏出来，屏幕亮着，上面显示一条新消息：

**“他不在下面。他在外面等你。”**

发送者：1147号。

屏幕下方的小字比上一次更长——**“沈稚冬没有来过。沈临渊也没有离开。他们都停在2001年7月19号。你要不要猜猜，是谁把门关上的？”**

林一凡攥紧手机，抬头看向螺旋楼梯深处那片红光。

赵日天沉默良久，把黑钥匙从门上拔出来，递向林一凡：“走吧。该下去了。”

林一凡没接，直勾勾地盯着他的眼睛：“你怎么知道沈稚冬和你父亲是同一批下去的？”

赵日天微微一怔。

林一凡声音更低了：“你从来没说过你父亲的名字。但铁皮盒留言里，‘春伢子’——你父亲叫赵春生，对吧？”

赵日天的瞳孔猛地缩成针尖。

螺旋楼梯深处，那片暗红的光突然闪烁了几次，像某种生物正在睁开眼睛。

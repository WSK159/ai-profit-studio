# 第277章 零点之前

林一凡从泵房出来时，手机屏幕亮着23:41。走廊里的白炽灯嗡嗡作响，像是一群焦躁的蜜蜂在头顶盘旋。

他摸了摸口袋里的三叉钥匙，金属的凉意贴着掌心。赵恒说的那些话在他脑子里翻来覆去——母亲的车祸，父亲的猝死，姐姐的代签合同，还有赵日天这个名字像是嵌在每一个线索的尽头。

电梯门开了，他走进去按了顶层。赵日天的办公室在28楼，星辰科技最上面那一层——按理说一个项目组长不该有独享整层的资格，但赵日天是钱总钦点的“卷王标杆”，据说他的工位被陈列在走廊尽头最通风采光最好的位置，像一尊供起来的佛。

“叮。”

电梯在28楼停稳。林一凡走出去，走廊空旷得像是一条没有尽头的灰白色隧道。赵日天办公室的门虚掩着，里面透出暖黄色的灯光。

林一凡推门进去。

赵日天正坐在办公桌后面，面前摆着一杯已经凉透的咖啡，手里捏着一支笔，笔帽被咬得变了形。他抬起头，看见林一凡，愣了一下，然后笑了：“哟，你怎么来了？这都快零点了。”

“找你聊聊。”林一凡拉开他对面的椅子坐下，目光扫过赵日天的脸。这张脸和赵恒有三四分相似——都是狭长的眼睛，但赵恒的眼里有犹豫和不忍，赵日天眼里的东西更硬更锋利。

赵日天把笔放下，靠在椅背上：“聊什么？讨论明天那个AI考核的优化方案？你还在带伤工作，不至于吧。”

林一凡没有接他的话。他盯着赵日天身上的工牌——那上面印着赵日天入职的年份：2019年6月10日。

“你入职比我姐姐晚四天。”林一凡说。

赵日天的手指在桌面上轻轻敲了两下，笑容没有变：“你姐姐？林一诺？她不是……辞职了吗？”

“她死了。2019年6月17日。”

空气一下子安静了好几秒。赵日天的手指停住了，他低下头，似乎在看桌上那份文件，拿起来翻了一页，又放下。

“我知道，”赵日天的声音变低了一点，“那年的事……我听说过。”

“只是听说？”林一凡往前倾了倾身子，“赵恒刚刚告诉我，我姐姐的死，跟你有关系。”

赵日天没有立刻否认。他沉默着，手指摩挲着文件边缘，似乎在组织语言。然后他慢慢抬起头，目光直直地看着林一凡：

“林一凡，你有没有想过——你姐姐，可能没死？”

林一凡心里像是被人猛地撞了一下。他还没来得及追问，赵日天的手机突然响了。赵日天看了一眼屏幕，神色微变，接起来听着，几秒钟后，他的表情变得很复杂。

他挂了电话，站起来，语气带着一股说不清道不明的紧张：“我有点急事得走。你在这等着也行——档案室左边第三个柜子，最下面一层，有一份你姐姐2019年签的劳动合同复印件。你自己去看。”

赵日天说完，抓起外套大步走了出去，脚步声在走廊里急促地远去。

林一凡没有去档案室。他站在原地，盯着赵日天办公桌上那支被咬扁的笔帽——笔帽上隐约可见一排细小的牙印，而那支笔，和他在赵恒泵房里看见的那支用过注射器旁边躺着的那支钢笔，一模一样。

他缓缓拿出手机，23:56。距零点还有四分钟。

他按下了那个陌生号码——那个自称“林一诺”的号码——拨了出去。

忙音。再拨。

就在这时，他的手指触到那份文件的边缘，一张纸条从文件里滑了出来，上面只有一句话：

“赵日天在骗你。林一诺确实死了——死在我面前。”

落款：陈月季。

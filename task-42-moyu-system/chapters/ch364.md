# 第364章 溶洞无声

金属碰撞声再次传来，这次更近了，像是什么东西被拖拽着划过石面，带着沉闷的摩擦。溶洞的水汽裹着凉意从深处涌出，林一凡蹲在石台后面，后背贴着湿漉漉的岩壁，呼吸压到最轻。

赵日天就伏在他右侧，那枚铜钱状胎记还裸露在袖口外面——他的目光比溶洞里的暗河还要深。两人彼此交换了一个眼神，赵日天缓缓抽出腰间的短刀，指锋朝向前方那条幽深的甬道。

碰撞声停了一瞬，随即传来人声：“……这地方到底有没有信号？老板那边等急了。”

“你说那个摸鱼的小子能跑到这儿来？疯了吧，他图什么？”另一个声音带着浓重的鼻音，“哥，咱再往前走走，刚才明明听见动静了。”

脚步声。两个，林一凡默数着——不对，是三个，最后一个脚步更沉。

“你们看，那些石台上的东西……怎么像是被人动过？”

林一凡的心提了起来。石台上那把半截钥匙、铜纽扣、白色儿童袜，还来不及收走。他侧头扫了一眼，赵日天已经在无声地做手势：走，还是留？林一凡抬手比了个“三”，又指指自己耳朵，意思是三个人，硬碰硬不明智。赵日天咧嘴笑了笑，那笑容在暗光里显得几分野性，他伸出三根手指，逐一弯下——

数到三，赵日天猛然站起，顺手抄起一块拳头大的石头朝甬道深处掷去。石头砸在远处岩壁上发出清脆的回响，随即是叮当一声滚落。

“那边！”三个追兵齐刷刷转向声响方向，同时拉动枪栓。

就在枪声还没响起的间隙，赵日天已经拽着林一凡的胳膊朝另一侧的溶洞岔口窜去。两人矮着身子贴着岩缝挤入一条不到半人高的夹道，身后传来追兵的怒骂：“妈的，是声东击西！”

夹道里的空气冰冷潮湿，石壁上布满了厚厚的水垢，一摸一手滑腻。林一凡掏出手机调成手电模式，微弱的光照亮前路——这条路明显是人工开凿过的，石壁上有整齐的凿痕，甚至在某些拐角处还能看到当年施工留下的水泥抹面。他心头一跳，想起南洞溶洞石台上那块刻着“零”字的石板，背面地图标注着“第九收容所”，而这条通道的方向，似乎正朝地图上的五角星延伸。

身后追兵的脚步声越来越远——那三个家伙在岔口犹豫了一瞬，选择往另一个方向追去。林一凡松了口气，但不敢停下脚步，两人又往前走了大约百来米，夹道突然豁然开朗。

眼前是一个圆形的石室，直径约莫十米，穹顶上布满灰白色的钟乳石倒挂，中央的地面上嵌着一块巨大的铁板，铁板表面刻着一行数字——和陶土徽章上的编号隐隐相似，又似乎隐约对应着某种坐标。铁板中央是一个凹槽，形状让林一凡瞳孔一缩：那凹槽的轮廓和赵日天手中那半截钥匙的截面几乎一模一样。

“看来我们要的东西，不只是石台上那点旧物件。”赵日天把钥匙拿在手里反复比划，没有急着插入凹槽，“但也有可能，这凹槽本身就是个陷阱。”

林一凡蹲下查看铁板边缘，发现缝隙里有风透出来——下面还有空间。他伸手摸了摸凹槽内壁，指尖触到一种说不出的温润感，像某种玉石，而非钢铁。

“先不动它。”林一凡站起身，回头往来的夹道看了一眼，“追兵能追到这儿，说明这溶洞的入口并不只有我们进来的那条路。他们知道地形，我们不能和他们在地底下绕。”

赵日天收好钥匙，忽然侧耳听了听：“什么声音？”

林一凡也凝神去听，四周除了水滴声之外，似乎还有一丝极细的电流嗡鸣，从铁板中央的凹槽深处传出来。电流声中夹杂着极其微弱的规律脉动，像某种机器在运转。

“这下面有人，”林一凡的嗓音发干，“或者有什么东西在维持运转。”

赵日天的眼睛眯成一条线：“九枚外部载体……我们拿到了几枚？三枚。而这铁板下的东西，恐怕就是那六枚没找到的载体汇聚之处。”他顿了顿，“或者说，是第九收容所的心脏。”

林一凡盯着那道凹槽，一个名字在脑中盘旋，第九收容所——父亲铁皮盒上刻着的“春”字、照片里铁门上的“26”，以及陶土徽章上的“27”……这些数字之间，到底藏着什么秩序？

他正要开口，手机屏幕忽然闪了一下，一条未知号码短信跳了出来：离开溶洞，他们布的地形图是假的，别信任何人。发送者的号码，依然是他早就背下来的那一串——1147。

# 第194章 72小时

林一凡被带进星辰科技总部顶层的一间会议室时，墙上那面智能玻璃墙已经变成了透明的，整座城市的夜景在脚下铺开。

钱总坐在长桌的一端，从容地摆弄着一台平板。见到林一凡，他抬了抬手示意他坐下。

“时间很多，小林。我们慢慢聊。”

林一凡拉开椅子坐下，目光扫过整间会议室。没有任何电子设备亮着，除了钱总手里的平板和墙上那块玻璃。没有摄像头、没有录音设备，至少从他的“摸鱼雷达”——那是他从系统里得到的能力，虽然已耗尽了所有咸鱼值，但雷达技能是永久性的——看不出异常。

“我先说清楚我的诉求。”钱总放下平板，“你的摸鱼系统，我已经知道了它的来源。它不是科技造物，也不是什么外星遗产，它是一份契约。”

“契约？”

“是的。那份契约，我之前让人调查过，它和‘人力之源’的动力体系是同一套代码逻辑。”钱总一挥手，墙上的玻璃上浮现出一串流程图，“人力之源抽取人的生命势能，维持某种系统的正常运转。而你那个摸鱼系统，恰好是从另一边给它补充能源的入口。”

林一凡怔住了。

他脑海里浮现出那个密室中央的装置——屏幕上三人的供能状态，他自己、赵日天、老周。他的命线曾经被接入装置，然后被系统切断。他以为是系统救了他。但如果摸鱼系统本身就是人力之源的一个“入口”呢？

“你是在告诉我——”林一凡的声音慢下来，“我的那条断链，其实就是摸鱼系统自己动的手？”

“也许。”钱总笑了笑，“也许不是。周建国应该比我知道更多。但问题在于——你上车之前跟我说，钥匙在你脑子里。那是什么？”

林一凡沉默了几秒，道：“我脑子里装着一套代码。我重生之前，那份代码已经写完，但从来没有运行过。”

钱总眯起眼睛：“什么代码？”

“一条可以让‘人力之源’停机的指令。”林一凡语气平静，“就藏在摸鱼系统的底层逻辑里。准确说，它是一段休眠代码，需要特定条件才能激活。条件——”

他顿了一下，看着钱总的眼睛：“需要另一个系统的权限作为密钥。”

钱总站了起来，双手撑着桌面，盯着林一凡，好一会儿才开口：“你是说……需要赵日天那个卷王系统的权限？”

“是。”

钱总重新坐下，神色复杂。他拿起平板，手指在上面快速滑动了几下，似乎在阅读什么东西。林一凡趁机望了一眼窗外——星辰科技楼下热闹的晚高峰依然在继续，完全不知道这间顶楼会议室里发生着什么。

“赵日天那边，”钱总终于开口，“我可以安排。但你给我的信息是否真实，我需要验证。你说你的系统有冷却期，咸鱼值清零后72小时才能恢复。那这段时间，就当我扣你的试用期。”他嘴角浮起一丝笑意，“从今天起，你调来顶楼直接跟我汇报，作为我的‘特别技术顾问’。”

“这意味着什么？”林一凡问。

“意味着，”钱总把平板翻过来，上面是一份电子工牌信息，“星辰科技的人事系统里，林一凡，已经从研发部调离了。你是‘顶楼的人’。”他靠在椅背上，“卷王那边，我会让他把你当成合作对象，而不是猎物。但我需要你给我一个结果——那套停机代码，在赵日天的权限进入后，到底能不能让那个装置安静下来。”

林一凡没有立刻回答。他低头看了一眼自己手腕上，那条从重生起就一直戴着的旧电话线手环——那是他前世工位上剪下来的，一直没舍得扔。

“我需要一个条件。”他抬起头，“老周得活着，并且离开那个地方。”

钱总沉默了几秒，缓缓点头：“这个我可以答应。”

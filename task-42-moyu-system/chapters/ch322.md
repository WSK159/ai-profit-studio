# 第322章 刻痕与空白

晨光穿透梓树的枝叶，在湿润的土地上投下斑驳光影。林一凡蹲在坑边，指尖捻起那张照片边缘已经发脆的纸片，母亲穿着两套不同衣服、站在同一棵梓树下的画面让他太阳穴突突直跳。

周立冬坐在土堆上，擦了把额头的汗，声音沙哑：“一凡，你母亲的事，你知道多少？”

“她死的时候我七岁。”林一凡把照片放回铁盒，声音平静得反常，“医院开的死亡证明，火化单，墓碑，一样不少。但沈临渊告诉我，她还活着。”

“你信他？”

“不信。”林一凡抬起头，目光里有种异样的锐利，“但他没必要骗我。他骗我的代价，是让我怀疑他说的每一句话——包括那句‘沈稚冬没有来过’。”

周立冬沉默片刻，站起身走到梓树旁，掌心贴着粗糙的树干。他突然开口：“我跟你母亲有约定。她让我在你满十八岁那年，把一样东西交给你。”

林一凡呼吸微微一滞。

“可我失约了。”周立冬转过来，脸上有种近乎痛的歉意，“因为那年她失踪了。我找了她三年，一无所获。直到你进了星辰科技，我才从钱总嘴里听到一个名字——沈稚冬。”

“钱总知道沈稚冬？”

“他说那是资本方舟亚太区的执行顾问，跟他做过两笔交易。”周立冬的眼神晦暗，“我当时没多想。直到我查到你母亲原名沈稚秋，我才意识到——沈稚冬和沈稚秋之间，可能不是两个人。”

林一凡脑海里轰然一响。他猛地弯腰，从铁盒底部抽出一张被压在照片底下的纸条——纸张泛黄，折痕如刀痕般深。展开后，上面只有一行字，钢笔蓝墨水：

“冬非冬，秋非秋。若有一天你读到这句，说明你活得比我久。”

字迹与磁带里沈稚冬的口吻如出一辙，冷静得不像话。

“她留下这句话是什么意思？”周立冬皱眉。

林一凡盯着那行字，半晌慢慢开口：“她的意思是——沈稚冬是她扮演的角色，而沈稚秋也是。真正的她，可能是第三个身份。”

“沈临渊说埋葬的是假尸……”

“那就对了。”林一凡忽然笑了，那种带着寒意的笑，“沈临渊是替身教官，他训练我们所有人——包括沈稚冬。假尸体，假死亡，假身份。沈稚冬的整个存在，从头到尾都是一场演出。”

他把纸条折好装进胸前的口袋，转身望向旧园区破败的铁门方向：“周叔，我妈和沈稚冬是同一个人的证据，比沈临渊说的还硬。但眼下更紧急的是——铁盒里没有钥匙。”

周立冬神色一变：“钥匙？”

“钱总办公室铁网夹层里那把。我摸过形状，跟这铁盒锁孔对不上。”林一凡眼中闪过一丝锐光，“也就是说，铁盒被替换过。真正藏着秘密的铁盒，不在梓树底下。”

周立冬蹲下来，指尖拨弄那氧化得面目全非的锁具，忽然说：“那你妈留给你约定里的那样东西呢？”

林一凡一顿。

周立冬从怀里掏出一个巴掌大的牛皮纸信封，封口处是一枚刻着“沈”字的铜扣：“她失踪前寄给我的。让我在你看清楚一切之后再拆。”

林一凡双手接过，指尖触到铜扣背面一道细痕——与怀表背面被磨掉的“沈”字刻痕形状完全一致。他心脏猛地一缩，仿佛那个被磨掉的名字正在原处重新显现。

“叔，你一直留着这东西？”

“等你。”周立冬咧嘴一笑，“不然你以为我一个大老粗，没事跟你往这破园区跑？”

林一凡撕开信封，里面只有半张残破的烧焦纸片。残留字迹只有六个字：

“祭日在第三梯。”

他抬头，与周立冬对视。两人同时想到了同一个地方——旧园区废弃的防空洞入口，左边第三级台阶。

林一凡收好纸片，刚要开口，手机震动。一个陌生号码发来一条彩信，照片里是那把黄铜钥匙，旁边压着一张纸，纸上画着一棵树的简笔画，树下写着三个字：找到我。

发信人号码无法回拨，归属地显示空白。

林一凡攥紧手机，目光落到照片角落里那顶白色棒球帽的边缘——拍摄者露出的帽檐，与之前那些照片里的帽子一模一样。

“周叔，”他压低声，“有人在我们挖坑的时候，一直在看。”

周立冬没有说话，手已经按在了腰侧。

# 第134章 老王的眼睛

那只眼睛在门缝中停留了足足五秒钟，才缓缓移开。林一凡屏住呼吸，透过柜子的缝隙看见一个矮胖的身影走进档案室——是组长老王。

老王穿着一件皱巴巴的格子衫，手里攥着一把手电筒，光柱在房间里扫了一圈，最后停在那台自鸣的服务器上。他低声嘟囔了一句：“数据还在啊……”然后从兜里掏出一个小巧的黑色设备，插进服务器的USB接口。

林一凡看见老王操作设备的动作极其熟练，完全不像是平时那个说话带着乡音、连报表都看不明白的老实组长。老王的手机屏幕亮了一下，林一凡瞥见上面显示的文件名，心头猛跳——那串字符和他在日志里解码出的坐标段一模一样。

老王在拷贝同一份数据。他也是冲着第三枚碎片来的。

林一凡的脑子飞速运转。老王在星辰科技待了十几年，是一路从底层混到组长位置的老人，表面上人畜无害。但他现在深夜潜入档案室，带着专业设备拷贝加密日志，这绝对不是“好奇”能解释的。他想起上一批章节里系统评价老王时的那句警告——“此人精神状态存在被外部干预的痕迹”。

老王拔出设备，揣进兜里，转身要走。林一凡正要松一口气，老王却突然停住了脚步，缓缓转过头来，目光精准地落向林一凡藏身的方向：“出来吧，我闻到烟味了。”

林一凡低头看了一眼自己身上——刚才在卫星上抽的那根烟，烟味确实还没散尽。他没有再躲，从柜子后边慢慢走出来：“王哥，你大半夜的，挺忙啊。”

老王没有意外，反而笑了一下：“一凡，我猜你也该来了。只是没想到你来得比我早。”他把黑色设备举起来，“你刚才看到了。我也不瞒你——这个数据库里，不光有碎片坐标，还有一段关于‘第三只眼’的创始人记录。”

林一凡皱眉：“你早就知道F-7卫星的事？”

“知道的不多。”老王把手电筒关了，“但我比你多知道一件事——‘第三只眼’不是只能扫描人，它还能反向植入。标记不是留在你身上的，是嵌进你记忆里的。你有没有注意到，你最近想起的事情，有些已经分不清是真的还是假的？”

林一凡心里一震。他确实有过类似的感觉，尤其是关于重生前那三年的片段，有些细节越来越模糊，像是被什么东西删改过。

老王继续说：“我能帮你的有限。但这份日志里的坐标，是唯一的真线索——你把它拿走，别让钱国豪先一步找到。”

他把设备递给林一凡，转身走向门口。“回去的路我不送了。记住，别相信任何主动给你信息的‘人’，包括我。”

林一凡握紧设备，望着老王消失在走廊里的背影。系统弹出一行提示：“新物品已获取：加密坐标数据。第三枚碎片所在位置已解锁初步线索。警告：检测到新的精神标记波动——来源：组长老王。”

他低头看着设备上闪烁的信号灯，老王的话还在耳边回响。这个老实了一辈子的组长，到底是被谁控制的？他刚才说的话里，又有多少是真的？

林一凡没有时间深想。他刚跨出档案室，手机恢复信号，一条新消息弹了进来——来自钱国豪的私人号码：“林组长，听说你最近在查一些老数据？明天上午九点，我办公室，聊聊呗。”

消息末尾附了一个坐标，和他在日志里解码出的那个位置一模一样。

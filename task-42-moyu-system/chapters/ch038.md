# 第38章 你的金手指，是赝品

东城咖啡在一条老巷子的拐角，门脸不大，装修也谈不上精致，胜在安静。林一凡到的时候，沈敛已经坐在靠墙的卡座里，面前放着一杯没怎么动过的美式，手指搁在笔记本电脑的触控板上，屏幕的蓝光把他的脸照得有些冷。

“你迟到了四分钟。”沈敛合上笔记本，抬头看他。

“被一件小事绊住了。”林一凡拉开椅子坐下，也不客气，直接切入正题，“你昨天说的东西，能先给我看看？”

沈敛也不废话，从背包里抽出一个牛皮纸信封推过桌面：“星海数据案的关键证据，U盘里的内容我做了完整备份。里面有星辰科技在过去两年间，配合几家投资方做数据造假的财务模型，以及一批内部通讯记录的截图。足够让钱总和他背后的关系网喝一壶。”

林一凡没有立刻伸手去接。他盯着沈敛的眼睛，语气平淡：“你把这个给我，图什么？扳倒钱总，你自己也能做到。”

沈敛笑了，笑容里有一丝说不清道不明的东西：“你说得对，我自己能办到。但问题在于——钱总不是一个人，他背后还有更深的池子。我需要有人帮我把水面搅浑，而你，是最合适的那根棍子。”他顿了顿，压低嗓音，“我听说过你的事。你的‘摸鱼工作法’在行业里传得那么邪，难道就没想过，为什么钱总的口风忽然怎么紧？”

林一凡心里一动。他之前就觉得奇怪，钱总这波“效率创新大赛”来得太急、太有针对性，好像有人在背后给他递了刀一样。他把那封信收进外套内侧口袋，顺手拿起桌上的菜单翻了两页，像是闲聊，“你那个卷王系统的开发者内测版……到底是从哪来的？”

沈敛的表情微妙地凝住了一瞬。他端起咖啡喝了一口，掩饰性地动了动嘴角：“你问这个做什么？”

“因为你昨天说了一句话，说我帮你是为了换这个证据，但你没说为什么要找我。”林一凡放下菜单，目光清亮地看着他，“我今早让一个朋友帮我查了查深海资本的公开备案信息，发现深海资本在两年前就被清算注销了。你挂着一个注销公司的名头来找我谈合作，沈敛先生，你是不是该跟我解释解释？”

咖啡厅里的空气静了两秒。沈敛那副从容的面具终于出现了一丝裂缝。他沉默了好一会儿，忽然低头笑了一声，笑声有点涩：“林一凡，你果然不像你看起来那么躺。”

他重新抬起头，指尖在自己那台笔记本上敲了两下，屏幕转向林一凡，那是一串底层日志代码，密密麻麻的数据流里，林一凡认出了一个熟悉的字段名——正是他摸鱼系统界面上出现过数次的那个标识符。

“你看这个字段，”沈敛指着屏幕上的某一行，“它是你那个系统的核心ID前缀，但在我这台机器上，同样的字段会指向一个完全不同的服务端节点。我找了三年的‘开发者内测版’，其实就是你在用的那套东西的……镜像。”

林一凡的瞳孔微缩：“镜像？”

“简单说。”沈敛望着他，声音不高，每个字却像落在鼓面上一样清楚，“你的摸鱼系统是真的。但我手里这个版本，是复制出来的赝品——它一直能监听到你的部分数据流，但没法跟你一样主动兑换技能。所以我猜，真正知道这套系统从哪来的人，只有你。”

林一凡脑子里嗡嗡响。难怪他的系统会在昨晚做出“外部数据采集”的警告，所谓的“版权护体”原来挡的并不是钱总，而是眼前这个来历不明的沈敛。他深吸一口气，压下心里的震荡，脸上却仍然维持着平静。

“所以，你从一开始就是冲我来的？”

“是。”沈敛坦然承认，“但我说帮你的那部分，全是真话。我需要你帮我查清楚这套系统的底层逻辑，因为我有一个怀疑——这个系统的开发者，很可能跟钱总背后那位资本大人物有关系。”

他顿了顿，补了一句：“你想想，你每次摸鱼换来的咸鱼值，最终都流去了什么地方。”

咖啡厅窗外，老巷子里一只流浪猫慢慢走过路灯下的影子，路灯这时闪了一下。林一凡低头看了一眼手机，屏幕上提示有新消息，是老王发来的语音。他没有立刻点开听，只是把手机扣在桌面上，抬起头，看着沈敛。

“明天下午，公司效率创新大赛的初赛现场。”他说，“如果我赢了，你就告诉我，你说的那个‘资本大人物’到底是谁。”

沈敛微微一笑，端起咖啡杯，朝他一举：“成交。”

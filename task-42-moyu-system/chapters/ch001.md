# 第1章 猝死之夜：最后一根烟还没点着，人没了

凌晨两点四十七分，星辰科技十二楼的灯还亮着大半。

林一凡从工位上站起来，颈椎发出了一声宛如生锈门轴的抗议。他揉了揉太阳穴，感觉太阳穴里面像是有人在用键盘疯狂敲回车键，每敲一下，他的脑仁就疼一下。桌上那盒红塔山只剩最后一根了，他捏起来，在指间转了两圈，心想，抽完这根就下班。

今天是他在星辰科技的第三百六十五个加班日，整整一年，从来没有在凌晨两点前离开过公司。系统上一个需求刚上线，产品经理又拍脑袋加了个新功能，技术总监说“这周无论如何都要交付”，老板钱总在全员大会上说“星辰需要的是有狼性的人”。

狼性。林一凡心里冷笑，狼都他妈不这么上班。

他走向消防通道尽头的吸烟区。走廊里弥漫着消毒水和外卖混在一起的味道，路过玻璃幕墙时，他看到自己映在玻璃上的影子——脸色发灰，眼袋青紫，头发乱得像被雷劈过。二十六岁的人，看着像四十六岁。他捏着那根烟，走到走廊尽头的窗口前，推开窗。

夜风灌进来，带着初秋的凉意。他把烟叼在嘴里，掏出打火机，大拇指压住齿轮。

“林一凡！”

身后传来一声喊。他回头，看到组长老王站在走廊那头，手里举着一沓报表，表情复杂：“客户对刚才交付的版本提出了十二个bug，都是P0级，钱总让你……”

林一凡没听完。他低下头，看见自己的手指在打火机滚轮上滑过，火花跳起来，烟头点燃的一瞬间，心脏突然狠狠抽搐了一下，像被人攥住猛地拧了一圈。

他下意识扶住窗框。

眼前的景物开始扭曲，走廊变成一条拉长的光带，老王的声音从很远的地方飘过来：“一凡？你怎么了？一凡！”

他低头，看见自己的手已经抓不住烟。那根刚点燃的红塔山从指缝间滑落，火星在半空中旋转、坠落，他看见自己整个人跟那根烟一样，从世界的缝隙里滑了进去。

视线彻底暗下去的前一秒，他听见脑子里响起一阵轻快的电子音：

“检测到宿主生命体征消失……”

“符合绑定条件……”

“正在启动《摸鱼系统》，请稍候——”

林一凡在黑暗里笑了一下，他想，这是什么鬼东西，我死了都能遇到系统推销员吗？

然后他彻底失去了意识。

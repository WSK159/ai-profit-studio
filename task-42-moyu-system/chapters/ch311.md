# 第311章 废铁站的暗门

面包车碾过碎石路，颠得沈稚冬手里的折叠屏手机差点脱手。林一凡单手扶方向盘，另一只手把那张坐标纸条又看了一遍——北纬31°14′23″，东经121°28′47″，西郊废铁回收站。

“老宋的废铁站去年就搬迁了。”沈稚冬皱眉，“我查过，这块地皮被星辰科技子公司拍下，但一直没开发，围挡立了快一年。”

林一凡踩下刹车，车停在一条杂草丛生的土路尽头。远处是一道锈迹斑斑的铁门，门上挂着一把锁，锁身缠着黄色警戒胶带，胶带已褪成惨白。门楣上“老宋废铁站”五个铁字，最后一个“站”字歪了半截，像被什么东西撞过。

林一诺的声音从折叠屏里传来：“信号显示，坐标精确位置在废铁站西北角，地下三层。我黑进过区域电力系统，那里至今仍有一个独立变压器在运行，月电费不高，但从未断过。”

“有人还在地下活动。”沈稚冬低声道。

林一凡把车熄火，从座位底下摸出一把折叠刀，塞进裤兜。他推开车门，闻到一股铁锈和机油混合的霉味。三个人废铁站里堆着报废的汽车壳、洗衣机、冰箱，像一座巨大的金属坟场。铁壳上积着厚厚的灰，但有几条路径明显被人扫过，灰土被踩出一条条浅沟。

“这边。”林一凡顺着浅沟往西北角走，绕过一座堆成小山的旧轮胎，脚下忽然踩到一块铁板，传来空洞的回响。

沈稚冬蹲下来，抬手敲了敲铁板边缘，眼睛一亮：“空的。有暗门。”

他伸出一根手指揩去铁板边缝的油泥，露出底下一条锁槽——锁槽形状是五瓣梅花，与普通锁孔完全不同。沈稚冬从背包里翻出那串铁丝和特制工具，正要动手，铁板底下忽然传来一声沉闷的金属撞击声，像是有什么东西在敲击铁板内侧。

三个人同时僵住。

林一凡把耳朵贴在铁板上。敲击声停顿了大约五秒，又响了起来——节奏三长一短，再三长一短。

沈稚冬脸色陡变：“SOS。”

林一凡盯着锁槽，忽然抬手拦住沈稚冬：“等一下。锁孔是五瓣梅花，老宋是锁匠，他之前给老王配的钥匙也是特制的。你看看你手里那根钢丝，末端是不是做成梅花形？”

沈稚冬一怔，把那根细钢丝举到眼前。果然，钢丝尾部被压成五瓣形状，折出一个微微外翻的弧度。他犹豫了一瞬：“这是老王笔记里夹的那根，我一直当普通工具用……”

他把钢丝捅进锁槽，咔哒一声，锁簧回弹，铁板松动了一道缝。

林一凡深吸一口气，用力掀开铁板。底下是一道铁楼梯，通向黑漆漆的地下空间。敲击声还在。隐约的敲击声在耳朵里反复回荡。

林一凡掏出手机照明，光柱扫过铁楼梯侧壁，照见几行刻痕。

他凑近一看，心头一跳，那字迹他太熟悉了，几天前他刚从老宅墙上见过：“凌晨。它在等。”

底下传来的敲击声，在此刻忽然停了。

林一凡的脚已经踩上第一级铁楼梯。沈稚冬一把拽住他胳膊，压低声音：“底下有人。”

林一凡顺着他的手电光往下照，看见铁楼梯底部，站着一双沾满油渍的劳保鞋。

鞋的主人微微后退一步，墙角的阴影里传来一个沙哑苍老的声音：“……你终于来了。第三把钥匙，在你身上吧？”======

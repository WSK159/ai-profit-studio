# 第200章 代价的账本

林一凡从通风管出口爬出来的时候，满身都是灰和铁锈味。出口通向主楼设备层的杂物间，落地窗边能看到城市灰色的轮廓。他靠在墙角喘息，手机屏幕还亮着，他飞快把老周画的代码拍了下来——四段十六行，歪七扭八的，密语一样。

他刚把照片存进加密相册，摸鱼系统的界面忽然跳了出来。界面上的咸鱼值数字依旧停在一个固定值上——1370，距离老板说的“3000换高阶护盾”差了一千六百多。系统提示一闪而过：

【摸鱼系统·紧急通知】
“劳动神与资本神的赌局即将开启。由于赌局封锁，咸鱼值收益暂停。已消耗咸鱼值按‘基础等价物’结算，不可返还。另提醒宿主：隐瞒的代价，通常比直视更大。”

林一凡盯着那行字，后背的寒毛立了起来。他隐约觉得系统话里有话——他隐瞒了什么？

“难道……”他下意识摸了摸口袋里的手机，想点开加密相册，身后杂物间的门忽然被推开。赵日天站在门口，穿着一身黑色冲锋衣，手里拎着两瓶冰水，看起来一点都不像半夜出现在办公楼的人。

“你找到老周了？”赵日天看着他身上的灰和划破的袖口，轻声问。

“你消息倒是灵通。”林一凡没急着回答，反手把手机锁屏塞回口袋，“钱总也在那。”

赵日天眼睛微微眯了一下，随即笑了，将一瓶冰水扔过来：“那看来你是看见‘它’了？”

“什么‘它’？”

“机房里的东西。”赵日天拧开自己那瓶水，喝了一口，目光落在窗外的夜色深处，“人力之源的地下机房，不光是关人的地方。那一层楼的温度常年维持在二十度以下，你却闻到热浪了吧？那是资本神留在那里的一台‘原始意志机’——它靠着吸收被裁员工的怨气运转，老周不是被关着，是他主动留下的，他在守着那台机器的密码锁。”

林一凡心头一震：“你的意思是，老周是自愿的？”

“他知道钥匙代码的完整版，也知道那台机器一旦启动会是什么后果。”赵日天转过头，神色罕见地认真起来，“所以你今晚去，他根本没指望你能救他出来，对不对？”

林一凡没说话，耳边却回响着老周按住他手腕时说的那句“它看着这里”。原来“它”指的不是钱总，而是那台机器。

“你手里那组代码，”赵日天低下头，声音压低，“你要是把它交给资本神，能换一块好筹码；你要是把它交给劳动神……赌局刚开始，你手里就有一张底牌。”

他说完把空水瓶扔进垃圾桶，拍了拍林一凡的肩：“我不管你会不会信我，但明天审计组的‘劳动纯度检测仪’上线，低于40%的都会死得很难看。你手底下那组人，有几个摸鱼摸得比你还狠的，自己想清楚。”

赵日天转身走了。林一凡一个人在杂物间站着，手指抵着冰冷的手机壳，半晌才开口：“你到底是什么立场？”

无人回应。窗外城市灯火稀落，远处天际线微微发白。他低下头，系统界面再次弹出——

【提示：检测到宿主持有“钥匙代码”碎片 1 份。是否上传至系统资料库？】
【警告：上传后，摸鱼系统将与赌局绑定，开启最终阶段。选择权在宿主。】

林一凡看着那行字，拇指悬在屏幕上方，迟迟没有落下去。

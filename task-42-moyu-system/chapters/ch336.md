# 第336章 徽章背面的温度

深夜十二点，出租屋的灯管嗡嗡作响，林一凡坐在床沿，把那枚陶土徽章翻来覆去看了不下二十遍。

“林”字纹样在灯光下微微泛着哑光，触感粗糙，像是被火烧过又被人用手一遍遍磨平过。背面那个数字“27”刻得极深，笔画却歪歪扭扭，不像机雕——更像是有人用钉子一类的东西，一笔一笔划上去的。

他伸手摸了摸那数字，指尖突然顿住。

纹路之间有磨痕，明显是有人经常触碰这个位置——像是数数一样，一遍又一遍地摸过这数字。

“二十七……”林一凡嘀咕了一声，脑中飞速转动。父亲去世那年他九岁，如果再往前推，父亲带他去云顶山那年，他八岁。可这个“27”代表什么？年龄？天数？还是别的什么？

他拿起手机，把那枚徽章拍了张照片，犹豫片刻，还是发给了沈望。

三分钟后，沈望回了一条消息：这是你爸的？

林一凡：你怎么知道？

沈望：他给我看过。你八岁那年，他去云顶山之前把这个拿给我看，说……

消息到这里停住了。林一凡盯着“正在输入……”的提示看了将近两分钟，才等到第二条消息。

沈望：你爸当年进云顶山，就是为了把“第三把钥匙”放进去。他说要把你的“唯一性物品”一起埋进去，用来日后引导你找到那里。他告诉我这个的时候，跟我说了一句话——“如果我回不来，别告诉我儿子是去找钥匙的。让他自己发现，这样他才不会被人利用。”

林一凡的喉咙动了一下。

“难道他也……”他喃喃自语，然后飞快地打字：我爸也绑定过系统？

沈望的回复只隔了几秒：他没绑过系统。但他知道的比你想象的多得多。

林一凡正要追问，沈望又发来一条：“先别聊这个。你手里现在有两把钥匙，第三把在云顶山。但灰衣男人给你的那把黄铜钥匙背后有‘来’字刻痕，你验证过没有？”

林一凡翻出那三把钥匙的黄铜钥匙，凑到灯下仔细看。果然，钥匙柄背面有一道极细的划痕，成一个“来”字。如果不贴着光看，根本发现不了。他把三个钥匙放在一起，嘴里无声地拼了一遍——“别信哥，来”。

“……来？”他自语，“如果‘别信哥’是警告，‘来’是召唤。灰衣男人递钥匙给我，是想让我去云顶山？”

他正思索时，系统面板突然弹出：

【检测到宿主手中钥匙与未知信号产生共振】
【唯一性物品定位条件已触发：需三把钥匙＋唯一性物品＋宿主血液】
【当前钥匙数量：2/3（第三把钥匙位置已确认：云顶山区）】
【警告：第三扇门开启后，隐藏任务链“归还自由”将进入最终阶段——不可逆】

“最终阶段……”林一凡眯起眼，“听起来像是在关门，而不是开门。”

他刚收起系统面板，手机屏幕忽然亮起一条新消息，未知号码。内容极短：“别再查了。你爸不是意外死的。”

林一凡的手猛地一紧，立刻回拨，对方已关机。他又仔细看了一眼号码——不是灰衣男人的，也不是沈望的，尾号是“1147”。

他盯着那串号码，忽然想到了什么——他父亲的工号，就是1147。

这枚陶土徽章、这条短信、这个号码……有人把他爸刻意留了十几年的线索一条一条翻了出来，正一件一件递到他手里。

林一凡把陶土徽章放到枕边，突然感到一阵疲惫从骨头缝里渗出来。他闭上眼，想到今天在储物间，灰衣男人临走前说的一句话——他起初没在意，现在却越想越不对劲：“你身边有人替你下了这盘棋，下了十几年。你只不过是从棋子，变成了执棋人——”

“——但也可能，你才是那最后一步棋。”

凌晨两点，他迷迷糊糊听见窗户外面传来一声极轻的咳嗽声，像是一个男人在楼下老槐树方向站了很久，又转身离开。

# 第384章 三十只眼睛

云顶山的夜风从门缝灌进来，带着一股铁锈与旧木混在一起的味道。第三扇门立在岩壁深处，灰白色的石料被岁月啃出蜂窝状的孔洞，门面上没有把手，没有锁芯，只有一只黄铜锁眼嵌在正中央，周围密密麻麻绕着三十只凹刻的眼睛——有些睁着，有些半阖，有些只剩一道细缝。

林一凡蹲下来，视线沿着那些眼窝的弧线缓缓游走。每一道凹槽都打磨得极光滑，不像用凿子刻的，倒像是被什么东西反复舔过。

沈稚川站在他身后一步，声音压得很低：“第三十一张空帧，必须是用海鸥相机拍的。”

“必须是？”林一凡没回头。

“沈临渊当年提到过，别的相机拍出来的东西，锁眼不会认。”沈稚川顿了顿，“他试过至少六种。”

林一凡从背包里摸出那台老式海鸥相机，掂了掂分量，机身上漆皮早已斑驳，露出底下一层暗红的防锈底漆。他调好胶卷，将镜头对准黄铜锁眼，食指搭在快门上，却迟迟没有按下。

“等一下。”

他放下相机，把胶卷从暗仓里拽出一截，对着月光端详。细长的胶片边缘，有一道针尖般粗细的划痕，从第二十九帧延伸到第三十一帧，连贯而均匀——像是有人曾用指甲沿着齿孔划过一道，而那道弧线在第三十帧处微微上扬，勾出一个诡异的弧度。

笑脸。

与自己猝死前屏幕上那个笑脸一模一样。

林一凡的手指微微发颤，但语气平稳：“这卷胶卷，你确定从没被别人碰过？”

沈稚川皱眉：“这是我从沈临渊书房一个铁盒里拿出来的，盒子上了锁，钥匙只有他有。”他稍作停顿，又补了一句，“至少我以为只有他有。”

林一凡把胶卷举高，对着月光换了个角度，那道划痕在光线下泛出微弱的银白光泽，像是新划的，金属粉末还未被氧化。

“如果这卷胶卷从没被人碰过，那这道划痕是谁留下的？”他声音不大，像在自言自语。

沈稚川的呼吸顿了一拍。

林一凡重新把胶卷装回相机，对准锁眼。他忽然想到什么，目光扫过那三十只眼睛凹槽，在心中数了一遍——左右各十五只，排列并非均匀分布，而是左密右疏，靠左侧几只眼窝明显更深。

“你说这扇门认的是脸。”他把相机举到眼前，“三十只眼睛，可能不是看的，是盯着。”

快门落下的声音在石壁间回荡，像一粒石子砸入深井。

奇怪的是，第三十一帧拍完后，锁眼里没有传出任何机械运转的声音，门也没有动静。

沈稚川向前跨了一步，手贴在门面上，掌心微微发烫。他沉默了几秒，缓缓收回手，脸色变了。

“不该是这样的。”

林一凡的心往下沉了沉：“沈稚川，你十四年前有没有见过这扇门打开？”

沈稚川的嘴唇动了动，像是要说什么，但最后只是摇头。

风从门缝里挤出来，卷起地面上薄薄的灰尘。林一凡低头的时候，看到自己的影子被月光拉长，恰好投在门面上——那三十只眼睛的凹槽，在影子的遮蔽下，竟然排成了一张脸的轮廓。

一张他不认识的脸。

这张脸的眉心位置，恰是那只黄铜锁眼。

林一凡忽然明白过来：第三十一张空帧不是用来“拍”开锁的，它记录的是锁眼在最暗光线下的轮廓，而那个轮廓与三十只眼睛组合在一起，才能构成完整的锁孔结构。他需要在这张照片上找到那条肉眼不可见的缝隙，再把对应位置的东西插进锁眼。

“镜子。”林一凡开口，“你身上有没有带镜子？”

沈稚川从内侧口袋里摸出一块巴掌大的折叠镜，那是他用来检查泵机叶片的小工具。林一凡接过来，将镜面对准照片放置的方向——他还要再拍一张，但这次不是对准锁眼，而是对准自己身后的月光。第三十一张空帧已经用掉了，他现在用的是第三十二张，相机里剩余的胶卷，只够再拍四格。

他没有犹豫，举起相机，背对门，将镜头朝向月亮，按下快门。

月光透过镜头打在胶卷上，他没看到任何异常，直到那机械的快门声响起的瞬间，锁眼里传来一声细微的咔嗒，像一颗钢珠落入空槽。

金属摩擦声中，第三扇门缓缓向内旋开了一个缝，里面涌出一股凉气，带着夹竹桃和柴油混杂的气味。

门开了。

沈稚川的瞳孔猛然收缩。林一凡收起相机，正要迈步跨过门槛，却听到身后传来一个陌生的声音：

“看来，你确实拿到那卷胶卷了。”

林一凡僵住了。

那个声音他听过，在电梯里，在过道尽头，在每一条暗巷的转角——但从来没有这么近。近得像站在他的影子底下。

他慢慢回头。

月光下，一个灰袍人影站在三十步外，脸上兜帽的阴影遮住了大半张面孔，只露出一截瘦削的下巴，和一个被风吹动的衣角。

灰袍人的脚边，放着一双旧布鞋。

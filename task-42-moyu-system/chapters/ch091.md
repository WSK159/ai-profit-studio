# 第91章 江小姐的邀请

林一凡盯着屏幕上那句“欢迎来找我”，后背一阵发凉。周莉的手指悬在键盘上方，微微发抖，她深吸一口气，低声问：“这个‘江小姐’……会不会就是江雪本人？”

“不可能。”林一凡摇头，“江雪已经死了，遗言视频里我们亲眼看到的。”

“那这个人怎么知道我们在查她的数据？”周莉的声音压得更低，“而且她的留言，分明早就预判到了我们会来这里。”

林一凡没说话，目光落在机房角落那扇窗户上。玻璃窗灰蒙蒙的，积了一层厚厚的灰尘，但此刻，窗台上有一块干净的指痕——分明是刚有人用手撑过。他快步走过去，推开窗户，外面是一条夹道，通向后巷，空无一人。

“有人一直盯着我们。”林一凡转身，语气笃定，“从进机房开始，就有人在外面看。”

周莉脸色发白：“那备份……他们拿到了吗？”

“不可能。”林一凡指了指自己太阳穴，“备份已经全部存在这里了。记忆宫殿，三万条原始数据，一张不落。”

这是他用三百咸鱼值兑换的技能。系统当时还提醒他：“记忆宫殿属于稀缺脑域开发，兑换后精神力消耗翻倍，摸鱼效率降低30%。”林一凡当时想都没想就点了确认。三万多条原始数据，随便一个文件都够他被判十年，不存脑子里，小命不保。

他合上电脑，拔掉电源线，把主机壳重新装回去。周莉开始清理指纹，动作熟练，显然不是第一次干这种事。林一凡看着她利落的手法，忽然问：“你导师……跟你提过江小姐吗？”

周莉的手顿了一下，随即继续擦拭接口：“提过。导师说，江雪老师有一个没毕业的学生，叫江然，是她的侄女。江雪死后，江然就消失了，没人知道她去了哪。”

“消失？”林一凡皱眉，“研究生退学是有记录的，不可能凭空消失。”

“导师说她申请了休学。”周莉直起身，“然后就没有然后了。学籍挂在系里，人再也没出现过。”

两人对视一眼，都从对方眼中看到了同一个结论——这个江然，远比他们想象的要接近真相的核心。林一凡的手机突然震动，是一条微信消息，来自一个陌生号码：

“明天下午三点，城西老码头茶楼，我带你们看一样东西。关于你们刚拿到的备份里，那个可执行程序是干什么的。”

林一凡正要回复，消息又追来一条：“别带任何人，别用系统。我盯着你们呢。”

周莉凑过来看了眼屏幕：“你要去？”

“必须去。”林一凡收起手机，“这个江小姐，知道我们拿了备份，知道我们有系统，甚至知道我们站在哪里。这种人要是想弄死我们，根本不需要引我们去茶楼。”

他把手机塞回口袋，走到机房门口，回头看了一眼那扇窗户。窗外的天光已经彻底暗了，走廊尽头的应急灯闪着绿幽幽的光。他总觉得，江雪的遗言视频里，有一句话他一直没来得及细品——“钱雨不完全是人”。

如果钱总不完全是人，那是什么？

电梯下行，数字跳动，镜面反射着两人的脸。林一凡忽然问周莉：“你导师的实验室，是不是在云麓数据谷有备案？”

周莉猛然转头，瞳孔紧缩。

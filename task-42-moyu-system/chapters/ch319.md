# 第319章 怀表里的夹层

回到出租屋已经是中午十二点半。林一凡反锁了门，把窗帘拉严，才终于把怀表从贴身口袋里摸出来放在桌上。周立冬和老王都在，谁也没先开口说话，看着他那个严肃得吓人的脸色。

那块黄铜怀表的表壳比他自己的旧一些，表盘上积了一层暗绿色的氧化层。他打开表盖，里面的机芯早已停止不动，指针定格在十一点四十七分。他试着上发条，毫无反应——这表早就锈死了。

“里头是不是还有什么东西？”老王凑过来，眯缝着眼睛看了半天。

林一凡拧动表壳边缘，一圈、两圈、三圈。忽然咔哒一声，表身侧面弹开一道细缝。他沿着缝把那块表壳掰开——夹层里躺着一小片叠得四四方方的纸，薄如蝉翼，泛着一层蜡黄色。

展开，纸上只有一句话，字迹歪歪扭扭，像在极度虚弱的状态下写的：

“第九个在梓树东南第七步。”

没有主语，没有解释。周立冬伸手接过纸条看了看：“梓树……‘梓树的记忆里埋着钥匙’，和铁皮柜上那句话是同一个东西？”

林一凡点头。他把纸条放下，抬眼看向周立冬：“你还记得那个跟我们接头的人？”

“孙满仓。”

“他说了一句话，没说完——”林一凡压低声音复述了一遍，“‘最后一条没找到的，不是——’然后声音就断了。”

“不是？”老王皱眉，“不是什么？”

三个人沉默了几秒。林一凡把那句话在嘴里反复嚼了几遍，忽然像被什么东西劈中一样，猛地站起来：“‘不是埋着的。’”

“什么？”

“九枚外部载体——大部分人以为都是埋在地下的东西，对吧？铁皮柜、梓树根下、第三水泥墩盒子……但如果‘最后一条没找到的’，根本不是埋着的呢？它可能在天上、在墙上、在某个从来没关过锁的地方——”

他说到这里停住了，掏出手机，翻到短信里那张黄铜钥匙的符号。符号末端微微向上弯了一道弧线，像指针。他放大图片，盯着那道弧线看了几秒，忽然调转手机，把符号倒过来。

那道弧线在倒置后变成了一扇门的形状。门的上方还有三个微不可见的小点，像三颗钉在门楣上的钉子。

“旧园区A栋顶层，天台。”林一凡低声道，“那栋楼的天台上，有一扇从来没关过锁的铁门。”

周立冬的表情变了：“你怎么知道？”

“我第一次去旧园区踩点的时候，在楼下往上看过。”林一凡说着站起身，把怀表和纸条揣进兜里，“六楼天台那扇门，挂锁锈穿了，门掩着但没完全合拢。我当时以为就是工地废铁门，谁想到——”

“你要现在回去？”周立冬拦住他，“刚才那个灰雨衣的人已经知道那个地方了，你现在去，万一撞上——”

“孙满仓被他抓住，U盘的交易已经谈崩。”林一凡抬起眼，“如果灰雨衣的人也知道那句话没说完，那他一定会先我一步。但我赌一件事——他不知道‘梓树东南第七步’这个细节。那句话是写给我的。”

他拉开抽屉，把那个备份U盘拿了出来，放进外套内袋：“你们留在这，如果天黑之前我没回来——”

“没有如果。”老王打断他，罕见地沉下脸，“你要是打算一个人去送死，我就先报警。你哥当年交代过我，要是你钻牛角尖，我不拦着，但必须有人盯着你。”

周立冬已经站到了门口，伸手拎起衣帽架上的外套：“走吧。我开车。”

三个人再次出门。这一次，天色阴得比早上更沉，云层低压压地笼罩着城市上空，像一块巨大的旧铁皮。旧园区门口那棵老槐树的叶子被风卷着，在水泥地面上打成旋。

林一凡没有从正面走。他带着两人绕到园区后墙，从那段塌了一半的围栏缝隙钻进去，沿消防梯一层层爬到六楼。

天台的门果然还虚掩着。那把挂锁锈得只剩个壳子，锁舌早已脱位。他推开门，冷风扑面而来，空荡荡的天台上只有几根晾衣绳、一只破桶和满地碎玻璃碴。

他扫视了一圈，目光落在天台东南角——那里种着一棵矮小的梓树，叶片枯黄卷曲，树干只有胳膊粗，嵌在一块水泥花坛里。梓树东南方向约摸第七步的位置，是一截裸露的排水管。

他走过去，蹲下来，用手摸那截排水管的底部。管壁和地基的接缝处，有一块水泥抹得不平整。他用拳头猛砸了两下，那块水泥松动脱落，露出一个黑洞洞的缝隙。他把手指探进去，摸到一个冰凉的金属棱角——拉出来，是一把同样锈迹斑斑的黄铜钥匙。

钥匙柄上同样刻着一个字——沈。

“第九枚。”林一凡低声说。

他举起钥匙，对着灰暗的天光看了两秒，那一瞬间他忽然想起铁皮柜上那行字——“梓树的记忆里埋着钥匙。”他当时以为说的是梓树根下三米，其实那是一个谜语：梓树东南第七步，埋着的是找到其他八枚钥匙的钥匙。

那把钥匙在他手心里微微发热。他正要把钥匙收进口袋，突然听见天台的入口处传来一个声音，不大不小，平淡得像在聊天气：“你终于找到了啊。”

林一凡猛地转身。灰雨衣的人站在门边，摘下了兜帽。露出的一张脸，方脸、浓眉、右眼角一道疤，五十来岁——和孙满仓一模一样。

但林一凡的直觉告诉他，这个人不是孙满仓。

因为刚才在旧楼里跟他说话的那个人，右手食指与中指之间有一道老茧，那是常年握焊枪留下的。而现在这个站在天台门口的人，十指白净，指节修长，握过的东西是别的东西——比如文件、手机，或者一枚录音笔。

“你是——钱总上面的人。”林一凡一字一字地咬出来。

那人笑了笑，没否认，也没承认。他抬手弹了弹袖口上并不存在的灰：“你哥把剩下的东西都藏在猜谜里，可惜他猜错了一件事。他以为只有你能找到这里，但我也想看看——一个连自己亲哥都没见过的弟弟，能笨到什么程度。”

林一凡握住那把黄铜钥匙的指节骤然收紧。

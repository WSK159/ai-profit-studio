# 第81章 交易崩盘与逃脱

仓库里的空气像是凝固的胶水，每一口呼吸都带着铁锈和机油混合的味道。林一凡后背抵着冰冷的货架，面前那个被他称作“何顾问”的中年男人保持着礼貌的微笑，但是眼底的光芒冷得像手术刀。

“备份？”何顾问推了推金丝眼镜，“林组长，我做了十五年风控，见过无数人说要留后手。真正有备份的人，往往不会这么大喊出来。”

林一凡心里骂了一声娘，但脸上反而挂起了更加灿烂的笑。他的系统面板在视野角落悄悄闪烁着——摸鱼雷达持续运转中，能看到仓库里六个方位都有高热量信号。

“何顾问，”他慢悠悠地说，“我这个人有个毛病，从不觉得放狠话有用。我这几年最大的收获就是在公司里学会了怎么留一手。您觉得我坐在这里跟您唠嗑是为什么？因为我笃定您不敢动我。”

他的语速不快，每一个字都透着笃定，连他自己都快信了。他能感觉到脑门上已经有了细密的汗珠，但此刻每一秒都是生死时速。

仓库的大门被一脚踹开时，正儿八经的警报声像一把尖刀划破了僵持。十几秒后，五六个穿制服的警察冲了进来，冲在最前面的刘彤身后带着的还有两个便衣。

“不许动！双手抱头！”

场面瞬间混乱。何顾问脸上终于出现了一丝波动，他低声说了句什么，旁边两个人拖着赵日天就往侧门溜。林一凡的摸鱼雷达抓住了那一瞬间——侧门外的巷子里有车在等。

“赵日天被抓走了！”他对着刘彤吼了一声。

刘彤的反应比他想象中快得多，她掏出一台平板点了两下，侧门外传来轮胎爆胎的声音，几秒后是激烈的引擎声和叫骂。

林一凡趁乱冲进侧门，追了三十米，在一辆爆胎的黑色商务车旁边看到了被扔在地上的赵日天。这位昔日的卷王狼狈地缩在墙角，丝袜似的淤青从嘴角延伸到了颧骨。

“哟，林一凡。”赵日天咧嘴笑了一下，露出两颗带血的门牙，“你的命比我值钱多了，又确认了吗？”

林一凡没理他的贫嘴，伸手把他从地上拽起来，同时系统面板弹出一条提示：

`【摸鱼系统·应急模式】——检测到宿主生命体征异常，临时解锁避险技能“浑水摸鱼”，可隐蔽行踪 3 分钟。`

“走。”他扶着赵日天钻进旁边堆放旧家具的隔间，用三张满是灰尘的旧沙发把他们挡住。

三分钟后，嘈杂的脚步声从仓库那边沿着巷道传来。林一凡透过沙发缝，看到何顾问西装革履地站在巷口，面色如常，像刚才那场闹剧跟他无关似的。

“有意思。”何顾问的声音很轻，却字字清晰，“林组长，你的牌比我想象中的多。不过你大概还不知道——你手里的第三块硬盘，缺的那段验证密钥，现在在我们手里。”

林一凡的心脏猛地一缩。

他看了一眼系统的解密进度条，49.7%的位置红得刺眼。他忽然意识到——也许数据库根本没被带走，硬盘里的密钥段也只是引饵，对方从一开始就掌握着完整拼图。

“找到你没有？”赵日天在旁边低声问，声音含混。

林一凡深吸一口气，强迫自己冷静下来。“我会让你出去的，但是在这之前——你欠我一段完整的故事。”他俯下身，目光直直锁住赵日天，“周莉到底是什么人？她跟你说过什么？那台卷王系统还在你身上吗？”

赵日天看着他，沉默了几秒，嘴角浮起一丝充满苦涩的笑：“她说她是我姐。我的系统——那台卷王系统，在她手里。”

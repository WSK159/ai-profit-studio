# 第369章 太平间里的一排空床

落地的瞬间，林一凡的脚跟传来一阵钝痛——地面是水泥的，粗糙，泛着白霜，摸上去冰凉。他直起身，手电光扫过去，视野之内的景象让他愣在原地。

房间不大，约莫三四十平米，四壁都是水泥砌成，墙角渗出斑驳的水渍。但整间房最扎眼的，是摆成一排的金属床架——十二张，床面铺着发黑的白色床单，床头的铁牌上刻着编号，从“零”到“十一”。

零号床上没有人，但床单中央有一个浅浅的凹陷，像是有人刚站起身离开。

一号床、二号床……一直到十一号床。每一张床的床单都是干净的——过分干净，与房间里其他地方积满灰尘的状态格格不入。像是有人定期清洗、更换，维持着某种仪式般的整洁。

赵日天站在零号床前，一动不动。他手里那枚半截钥匙不知什么时候被他握了出来，钥匙上残留的第十道磨痕在暖黄色光线里泛着微光。

“怎么了？”林一凡走过去。

赵日天没有说话，只是用钥匙指了指零号床的铁牌。铁牌上没有字，只有一个刻出来的圆圈，圈中一个点——“归零”的符号。跟那卷地图上标注的一模一样。

林一凡绕着房间走了一圈，在墙角发现了一扇门，门是木质的，上了三道铁闩。但铁闩没有锁，只是搭着，像是从里面被封上后又被推开过。他推开一条缝，一阵气流带着药水味涌进来。

他没有急着进去，先回到赵日天身边：“你认得这些床位？”

赵日天缓缓摇头，声音沙哑：“认得不认得已经没有意义了。林一凡，你看这个。”他指着零号床的床沿——一个极浅的刻痕，被手电斜着照才能看见。那是一个日期：2001年7月17日。

“你生日？”林一凡随口问。

赵日天猛然回过头来，瞳孔震惊：“你——你怎么知道？”

林一凡的手指一僵。他只是随口一说——但赵日天的反应告诉他，猜中了。“因为这床是零号，你手里那把钥匙的第十道齿痕是磨掉的。一个死人躺在零号床上，床沿刻着他的出生日期。这个收容所收的不是什么东西，是人。”他声音越说越低，最后几个字几乎是贴着牙缝挤出来的。

赵日天把钥匙收回兜里，手指微微发抖。

“你来过这。”林一凡说。

“不是我来过。”赵日天声音里有一丝从未展露过的脆弱，像是生了锈的铁皮被剥开，“是我爸躺过这张床。”

房间里的空气骤然凝固。林一凡看了看零号床，又看了看赵日天，什么都说不出来。

咔哒。一声轻响从木门缝里传来。两人同时看向门缝——那光线变了。从暖黄色变为了冰蓝色。随即，一个小小的、方形的物体从门缝底下滑了进来，在水泥地上滑出“沙沙”声响，停在林一凡脚边。

是一部手机。跟1147号丢下来的那部一模一样——翻盖，老式，屏幕亮着。

林一凡蹲下去捡起手机翻开。屏幕上只有一行字：“你们进了不该进的门。床单下的东西别碰，它醒了。”

赵日天弯腰，掀开了零号床的床单。

床单下没有垫子，没有床板——只有一个黑洞洞的竖直井道，井深不见底，但一台木梯嵌在井壁上，向下延伸，消失在黑暗里。

手机上的字变了：“……晚了。”

一声低沉的震动从井道底部传上来，像蛰伏的心脏被唤醒，开始一跳一跳地搏动。林一凡扭头去看那排空床——十一张床的床单同时微微鼓起，又落下，像是在呼吸。

“走。”赵日天拉了他一把，朝木门冲去。

但木门不知何时已经关严了，三道铁闩从外面扣上，把光线和出路全封在外面。房间里只剩下井道深处的搏动声，和十一张床单下起伏的呼吸。

……咔哒。

“我们把它吵醒了。”林一凡盯着赵日天，“你爸当年躺在这张床上，听的就是它？”

赵日天的沉默，就是答案。

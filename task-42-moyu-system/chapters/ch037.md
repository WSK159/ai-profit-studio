# 第37章 效率创新大赛

咖啡机嗡嗡作响，林一凡端着马克杯靠在茶水间的玻璃窗边，目光落在楼下广场上那片蚂蚁般攒动的人头。下午三点十五分，按理说该是工位最安静的时候，可今天整个十二层像被捅了的马蜂窝。

“一凡！你还有心思喝咖啡？”老王从走廊那头小跑过来，领带歪在脖子一侧，额头上一层薄汗，“钱总刚在全员群里发了通知，效率创新大赛这周五截止报名，明天下午要交初赛材料。”

林一凡抿了口咖啡，不急不缓地打开手机。群消息确实已经炸了，行政部的艾米连发三条比赛规则，还贴心地配了一张思维导图，核心只有一句话：全员参与，以组为单位，展示最创新的高效工作法。

“这不明摆着冲我来的？”林一凡扫了一眼艾米消息末尾那个笑脸表情，把手机屏幕转给老王看。

老王苦着脸：“问题是……钱总指定的主题，叫‘摸鱼工作法在现代办公中的高效应用研究’。这不等于把你那套东西弄成了公司资产了吗？他还点名让你的效率小组做示范组，谁都知道这是个套。”

林一凡沉默了几秒，把咖啡喝完，杯底磕在台面上发出清脆的一声响。他早就料到钱总会有这一步。上一世的钱总就是这么个人，先捧你，再拆你，最后连骨头渣都不剩。

“王哥，你帮我做件事。”林一凡压低声音，“今晚之前，把咱组这半年的工作日志，尤其是摸鱼工作法落地前后的产出对比数据，整理一份给我。要原始数据，不要加工过的。”

老王愣了一下：“你要用这个做什么？”

“钱总想吞我的东西，那我得先让他知道，这东西不好嚼。”林一凡扯了扯嘴角，“他办这个‘效率创新大赛’，不是想让我表演吗？那我就表演给他看。”

时间转眼到了傍晚七点。写字楼的灯一盏盏暗下去，唯独十二层那间大会议室的灯还亮着。林一凡坐在长桌尽头，面前摊着一摞打印好的数据报表，电脑屏幕上是一份初步成型的参赛方案，与他之前那份“新式高效工作法汇报”不同，这一次他在文档里埋了一个东西。

手机震了一下，屏幕上跳出一条新消息，备注名是“沈敛”。

“你那边怎么样？听说你们公司搞了个效率创新大赛，我的内部版系统刚刚收到一条有趣的数据：你们钱总今天下午向外部协作平台申请了一个新的工作区，频率极高，我都怀疑他在拿系统测试什么新功能。”

林一凡盯着这条消息，指尖在键盘上悬了片刻。

“你那个卷王系统……能看到他新建的工作区里有什么内容吗？”

消息发过去后，那头好一阵没回。林一凡也不催，起身走到窗边，玻璃上映出他半张脸，外面的城市霓虹像打翻的调色盘，铺了一地。

几分钟后沈敛的消息才到：“能看到部分目录。里面有个文件名很有意思，叫‘摸鱼系统竞品分析——秦氏集团内部测试评估报告’。”

林一凡瞳孔微缩。秦氏集团？他记得这个名字，上一世星辰科技的母公司，后来把所有业务打包卖给了资本方，钱总就是从那个时候彻底倒台的。可这一世时间线还没走到那一步——钱总就已经在跟秦氏集团的人对接了？

他太了解那些资本玩法了。钱总从来不是一个人在战斗，他的背后一直有一条他看不见的利益链。上一世林一凡没机会看清链子那端拴着什么，但现在，沈敛给了他一把钥匙。

他重新坐回电脑前，删掉了之前那份参赛方案里所有温和的表述，指尖在键盘上敲出一行新的开头。

“《摸鱼工作法：从效率工具到组织变革的路径分析》——主讲人：林一凡，效率小组组长。本方案基于半年真实生产数据，且包含对现有考核机制的系统性反思……”

他把“系统性反思”后面的引号改成了一个括号，敲下一句话，然后存盘，退出，拔掉U盘。

做完这一切，他给老王发了一条语音：“王哥，明早九点，会议室见。我把那人要的东西，给他送过去。”

语音发出去后，他关灯离开办公室。走廊尽头安全出口的指示灯绿莹莹地亮着，像一只睁着的眼睛。他走出大楼的时候，手机上又弹出一条系统提示。

【咸鱼值+68（当日摸鱼时长折算）】
【提示：检测到外部系统正在对你当前工作内容进行数据采集，已自动启用“版权护体”（生效中）】

林一凡脚步微微一顿，随即若无其事地拐进街角便利店，买了一杯关东煮。他站在便利店门口的灯光下，看着雾气从杯口往上冒，心里盘算着时间。

明晚的东城咖啡，他得从沈敛嘴里多挖一点东西出来。

# 第179章 旧钥匙的暗纹

脚步声停在门外的那一刻，林一凡握紧了手里那把黄铜小钥匙，指腹贴在冰凉的金属上，像握着一枚随时会引爆的引信。

他退后半步，目光死死盯着出租屋那扇铁门。门缝下透进来的走廊灯光没有晃动，说明那人就站在门外没动。可是……没有人敲门。

走廊的声控灯早就坏了，物业贴了三回告示没人管。林一凡低头瞄了一眼手机屏幕，时间显示“23:47”。他的心跳快了两拍——半夜十二点前，有人站在你门外不动，这他妈比敲门还瘆人。

他深吸一口气，蹑手蹑脚凑到门边，猫眼里望出去——走廊空空荡荡，哪有什么人影。

“操。”他低声骂了一句，正要回头。

“叮当——”

门外的声控灯突然亮了。猫眼里的画面猛一晃：一个穿着灰色帽衫的背影正沿着走廊拐角消失，步速极快，快到像在逃跑。林一凡瞳孔猛缩——那个背影，他太熟悉了。是组长老王。

但老王已经失联两周了，赵日天说老王被调去了总部的“保密项目组”，连号码都注销了。林一凡抓过外套就追，推开门冲出去，声控灯亮了一路，拐过走廊尽头却发现安全通道的门半开着，楼梯间里空无一人。

他站在楼道口喘了十几秒，最终还是放弃了追上去的念头——追不上的，老王消失的方式从来都比他想象得聪明。回到屋里锁上门，他重新拿起那把黄铜小钥匙，仔细端详。

之前只顾着看形状，没注意细节。这把钥匙磨损严重，但在一侧的齿槽边缘，隐约有一行极细的刻痕。他开了台灯，凑近看，刻的是四个字母：ALPHA。

和芯片卡文件里的“MF-019-ALPHA”对上了。

老王留下的每一块拼图都在往同一个方向坠。林一凡翻开芯片卡旁那张压得平整的顶楼结构图，目光落在天花板活板的位置示意图旁。图纸角落的注释他已经看过很多遍了——“真正的开启者，不是拿钥匙的人，是造锁的人。”

他端详着手里这把钥匙，觉得这句话像一根钉子扎进了脑子里。造锁的人……老王是仿钥匙的制作者，老周是原版的制作者，那么造锁的到底是谁？

手机突然震了一下。一条短信，发件人是一串陌生号码。内容只有六个字：“别信赵日天。”

林一凡盯了这条短信整整十秒，嘴角抽了一下。他刚挂掉赵日天那个“别开门”的警告电话，现在又来一条“别信赵日天”——他发现自己走进了某种布满镜子的走廊，每一步都在踩虚。

他回拨那个陌生号码，响了六声才接通，话筒里传来一个沙哑得像砂纸磨铁的男人声音：“你是林一凡吧。”

“你谁？”

“老周的朋友。”对方顿了顿，声音像在压着咳嗽，“老周死之前给我留了一把钥匙的拓印，他说，如果他自己出了事，让我把它交到‘打开过唱片机’的人手里。”

林一凡后背一凉：“你怎么知道我打开过唱片机？”

电话那头沉默了片刻，那人又说：“因为老周留下的拓印上有一道新刻的横纹，是仿品钥匙在第一次插入锁孔时留下的标记——老周说过，钥匙只有在错误的锁里转过一圈，才会留下那种痕迹。你试过那扇门，对吧？”

林一凡攥紧了手机。他没有说话，但对面像已经得到了答案：“那把旧钥匙，不是开门的。它是个诱饵，是让开门的人以为自己是‘被选中者’的设计。真正能打开活板门的，是你手里那把磨损钥匙对应的模具，而模具……在老周手里。”

“老周死了。”林一凡直接说。

电话那头传来一声很轻的笑：“他死没死，你比我清楚。那个棺里的人，不是老周。”

通话戛然而止，像被人强行掐断了。

林一凡握着手里的黄铜钥匙，感觉指尖微微发烫。他慢慢转身，目光投向头顶的角落——图纸标出的天花板活板位置。然后他听见天花板上传来一声极轻微的“咔哒”，像是有什么东西，挪动了一下位置。

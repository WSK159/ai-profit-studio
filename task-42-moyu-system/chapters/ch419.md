# 第419章 灰手

那只手搭上林一凡的肩膀时，触感冰凉干燥，像是从一具在沙土里埋了许久的尸体上伸出来的。他下意识侧身闪避，肩头在墙壁上擦过，灰白色指尖从他后领滑过时，他听到一声极细的金属摩擦声，像是手指刮过什么铁皮。

他回头看时，那只手已经缩回黑暗里。走廊尽头那密集的抓挠声像潮水一样退去，短短几秒内就消失得干干净净，好像从未出现过。

老杨头大哥在他身后气喘吁吁地停下来，独眼死死盯着走廊深处：“……它们退走了。”

“是什么东西？”

“守门的东西。你手里那颗骨钉亮的时候，它们就不敢碰你。”老杨头大哥指了指林一凡手里那根灰烬骨钉，语气里带着一丝颤抖。

林一凡低头看了一眼——钉帽上的数字“27”边缘的暗红色纹路正在缓缓退去，像烧红的铁丝慢慢冷却。他忽然想到一个细节：他激活骨钉用的血是手腕上那截旧伤疤上的血，那伤疤是他小时候摔在铜片边缘划破的，他妈当时蹲在旁边，用烧酒帮他擦伤口时说过一句很奇怪的话——“以后这疤会替你挡一次灾。”

那话他记了二十年，一直当成一句哄小孩的话。现在想来，他妈当时说的是“替你挡一次灾”，还是“替你锁一扇门”？

他来不及细想，老杨头大哥已经推着他往通道侧壁走去。那里有一道几乎看不出来的暗门，门板上覆着一层铜绿，和墙壁融为一体。老杨头大哥从袖子里抽出一根细铜棍，在门板上方的一处凹陷里捅了三下，门板便自动向内裂开一道缝，露出一条窄向下行的阶梯。

“这块地方他们一般搜不到，”老杨头大哥说，“先下去，喘口气。”

林一凡跟着他钻进暗门。阶梯很陡，两侧墙壁上隔一段就嵌着一粒暗淡的铜珠，勉强照出脚下几步的距离。下了大约两三层楼的高度后，阶梯尽头的空间骤然开阔——一个约莫十来平的石室，四壁同样覆着铜绿，但地面的青砖干净得出奇，像是常有人打扫。

石室正中摆着一张石桌，桌上放着两样东西：一盏烧干的铜油灯——灯芯早已焦黑只剩一小截；还有一张叠得很端正的黄纸，边角微微卷起，透出暗沉的颜色。

老杨头大哥走过去，在石桌边坐下，沉默了好一会儿才开口：“这地方，是你妈当年烧铜用的。”

林一凡盯着那张黄纸，喉咙发紧。他走过去，拿起那张纸，展开——

纸上不是字。纸上只有一行烧出来的墨迹，像是用指尖蘸着铜灰和水写下的，笔画粗粝，有些地方已经残缺。林一凡凑近看，勉强辨认出几个字：“……杀……身……铸……锁……不……解……锁……不……死……”

他连起来读了一遍：“杀身铸锁，不解锁不死。”

“什么意思？”他抬头问老杨头大哥。

老杨头大哥没有看他，只是盯着那盏烧干的铜油灯：“你妈铸锁之前，先杀了自己。”

林一凡的手一抖，黄纸从指尖滑落。老杨头大哥又说：“她把自己的命烧成铜水，浇进锁芯里。——这就是‘杀身铸锁’。”

“那‘不解锁不死’——”

“锁不解，她就不算死透，”老杨头大哥缓缓抬起那只独眼，“换句话说，你妈现在……是活着的，也不是活着的。她人在锁芯里，锁在门上，门关着；门不开，锁就一直锁着，她就这么拖着。”

林一凡的拳头攥得咯吱响：“所以门后那个人说的‘只能留一个’，是什么意思？”

“你爸的名字写在纸上，”老杨头大哥说，“那张纸是铜灰铸的，烧不掉。要想把名字从纸上抹掉，唯一的办法就是把名字主人——你爸——烧成灰，再和原来的灰混在一起，重新铸一遍。可你妈铸锁时锁死了自己的命，所以能替她完成这笔交易的……”

他没有把后半句说完。但林一凡已经听懂了：能替她完成这笔交易的，只有她的亲生骨肉。

门内之人“林杨”要从门里出来，就必须让纸上父亲的名字消失。而唯一能完成这件事的，是林一凡——因为他体内流着娘和父亲各一半的血。也就是说，门内林杨和父亲只能留一个，其实是两个选择：要么父亲活，林杨永远待在门里；要么林杨出来，父亲被烧成灰融入纸面。

“所以，”林一凡的声音压得很低，“我父亲现在在哪儿？”

老杨头大哥沉默了片刻，从怀里摸出一块半巴掌大的铜片，放在石桌上推向他。铜片上刻着半张图纸——正是林一凡之前看到的那张图纸的下半部分，上面详细标注了青铜门内部的构件：锁芯、锁舌、锁扣。锁舌的位置画着一个圆圈，圈里写着一个字——“沈”。

林一凡猛地抬头：“沈？”

“你爸姓沈。”老杨头大哥说，“沈临渊。——你妈当初铸门锁时，在锁舌上刻了你爸的姓。”

林一凡的脑子嗡了一声。沈临渊——这个名字他见过，在进入归墟之前，他在星辰科技的资料库里见过一个同名的旧档案，那档案标着“已注销”，备注栏写着一行字：“涉密，需总部权限。”他当时没在意，现在想来，那个档案根本就是关于他父亲的。

“他现在人在哪儿？”

老杨头大哥摇了摇头：“我不知道他在哪儿。但我知道他曾经被关在哪里。”他伸手指向铜片上锁舌位置的下方，那里刻着一个小到几乎看不清的记号——像是一道门的草图，门楣上画着三道斜线。

“星辰科技B3地下档案室。”老杨头大哥说，“那是你爸最后一个待过的地方。”

林一凡盯着那三道斜线，脑中骤然晃过一段记忆——重生前在星辰科技996的那三年，他经常加班到深夜，有几次在B3楼层电梯口等电梯时，隐约看到走廊尽头有一扇贴了封条的铁门，门上用记号笔歪歪扭扭地画着三道斜杠。他当时以为是保洁做的标记，从未多想。

现在他明白了，那不是保洁画的，是他父亲留下的记号。那三道斜杠，指向的是他自己。

“我现在就回去，”他说，“回星辰科技。”

老杨头大哥抬起头，独眼里露出一丝复杂的光：“你确定？B3那个地方——”

“我确定。”林一凡把铜片卷起来塞进衣兜，又弯腰捡起那张黄纸叠好放进口袋，转身走向阶梯口，“我妈锁在门里说的话你也听到了，她让我活下去。可我要活下去，先把沈临渊从那地方捞出来。”

他踏上了阶梯第一级，忽然停住脚步，没有回头：“你跟着我干了这么久，究竟是替谁做事？”

石室里沉默了一会儿。老杨头大哥的声音从身后传来，带着一种很轻的、几乎听不出情绪的语调：“替我自己。我欠你妈的。”

林一凡没再说话，抬脚往上走。他登上最后一阶，推开那道覆着铜绿的暗门，重新回到青铜通道里。通道里的抓挠声已经完全消失，墙上的铜珠重新亮起，光芒比之前暗淡不少，像是被什么东西抽走了一部分。

他低头看向手里的灰烬骨钉——钉帽上的数字“27”边缘，不知什么时候多出了一道极其细小的裂纹，像是某种不知名的力量正在从内部挤压它。那裂纹不深，但形状诡异，像极了一个字——“沈”。

林一凡盯着那道裂纹看了三秒，缓缓合拢手掌，将骨钉攥进掌心。

他正往前走，手机忽然又震动了一下。屏幕上跳出一条新消息，发件人还是一个陌生号码，消息只有四个字：

“别碰那扇门。”

他刚读完，手机又震了一下，第二条消息跟着弹了出来：

“B3的门，别从正门进。他们会等你。”

林一凡的脚步骤然一顿。

他盯着那行字看了很久，然后抬起头，目光落在通道尽头那扇刚刚重新合拢的青铜门上——门缝闭合得严丝合缝，像是从未被推开过。

他把手机塞回兜里，低声骂了一句：“我等了他们二十六年，换他们等我一次，也没什么不公平。”

他朝着来路的方向，迈开脚步。

青铜门缝里，在他转身离开后，极其缓慢地透出一缕极细的光线，像某只眼睛睁开一条缝，在黑暗中目送那个背影走远。

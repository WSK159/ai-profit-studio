# 第264章 命运归还手册

暗室里的灯光昏黄，铁门在身后沉重地关上。林一凡手中的圆形钥匙在墙壁上划出一道浅痕，他在陈和平的备份意识引导下，摸到了内墙上一个不起眼的凹槽。那凹槽形状恰好是一个圆形，边缘光滑，仿佛专门等待着这把钥匙。

“009号钥匙门……”林一凡低声自语，将圆形钥匙对准凹槽，轻轻一推。

“咔哒”一声脆响，暗室的整面墙壁轻微震动，随后一道几乎看不见的细缝从墙体正中缓缓裂开。缝隙里透出幽蓝色的光，像深海里的磷火。林一凡屏住呼吸，伸手推开那扇隐藏在墙体内的暗门——门的表面裹着一层金属质感，触手冰凉，没有任何标识。

门内是一间不到十平米的密室，正中央摆着一张老旧的铁皮桌，桌上放着一个黑色公文包。包面上落了一层薄灰，但拉链崭新，显然有人刻意保管至今。旁边还有一本棕色封皮的笔记本，封面上用圆珠笔写着三个字：“命运归还”。

林一凡拿起笔记本，翻开第一页。手写的字迹工整而娟秀，是林一诺的笔迹——他曾在录音里感受过那声音，却第一次见到她留下的文字。开头只有一行：

“如果你看到这里，说明我已经不在了。别怪我，哥哥。”

林一凡呼吸顿了一下，指尖在纸页上轻轻摩挲。他继续往下翻，第二页开始是简短的说明文字，标题写着“命运归还——操作手册（完整版）”。

里面详细记录了“命运归还”通道的完整机制：第000号钥匙连接的不是某个房间，而是一段被切断的因果链条。只要持有者愿意，在指定时间点启动钥匙，就可以把自己七年来错过的记忆、经历、甚至身体状态全部“归还”回来——但代价是，当前时间线里发生的一切，包括摸鱼系统带来的所有咸鱼值和已兑换的技能，都会同步重置。

“重置……”林一凡低声念出这两个字，目光凝重。他继续往后翻，看到第三页末尾有一段用红笔圈起来的话：“启动条件：持有第000号钥匙的人在心脏正常跳动的状态下，于午夜零点前握住钥匙，心中默念‘归还’三次。兑换时限十分钟。超过时限，机会作废，钥匙永远失效。”

他合上笔记本，心中风暴骤起。七年的记忆——那些他从未经历过的岁月里到底发生了什么、林一诺是怎么死的、陈和平为什么等了二十年、赵恒那把钥匙是十年前交给谁的——这些谜团的答案，全都锁在那段被切除的记忆里。但代价是……他如今拥有的一切，将不复存在。

正犹豫间，密室的灯光突然闪了一下，随后红光大作。“警报级别：S级。检测到第000号钥匙短暂激活，位置：星辰科技总部地下三层。”一个机械女声从头顶的喇叭中传来。林一凡猛地抬头——他激活钥匙的时候触发了某种追踪系统。

紧接着，喇叭里传来第二句话，让他的心脏几乎停跳：“检测到目标：林一凡。权限确认：010号钥匙持有者赵日天已进入地下通道，预计三分钟内抵达你所在位置。”

赵日天，来了。

林一凡将“命运归还”笔记本迅速塞进外套内袋，又把黑色公文包拎在手里。他看了一眼墙角的摄像头——那红点正微微转动，对准他。他抓起桌面上一块碎铁片，猛地砸向摄像头，镜头炸裂。然后他转身冲出密室，沿着来时的通道向上奔跑。

身后的暗门在他离开后自行合拢，墙壁恢复原状，仿佛从未存在过。

跑出负二层的楼梯转角时，他看到走廊尽头有一道修长的身影正朝这边走来。那身影步伐不急不缓，手里转着一把三叉钥匙，银光闪闪，正是赵日天。两人隔着十几米对视，灯光从背后将赵日天的影子拉得极长。

“林一凡，你果然在这。”赵日天笑了笑，“我还在想，你的进步凭什么这么快。原来是……”

他的目光落在林一凡胸口微微凸起的笔记本轮廓上，笑容渐渐收拢：“你把命运归还的手册拿到了？”

林一凡没回答，只是把圆形钥匙在指间转了一圈，沉声道：“赵日天，你也有钥匙。你是来阻止我的，还是来帮我的？”

赵日天沉默了两秒，从口袋里掏出另一张泛黄的纸片扔过来。林一凡接住一看，是一张照片——照片上，一个年轻女人抱着一个婴儿，旁边站着一个少年。那个少年，竟是少年时期的赵日天。而那个女人，林一凡从血缘的直觉里瞬间认了出来：

那是林一诺。

“她当年救过我。”赵日天平静地说，“所以我不是来阻止你的。我是来告诉你，启动第000号钥匙的计时器——在你刚才激活的那一刻已经开始了。你还有不到四十八小时。”

林一凡瞳孔骤缩。

# 第119章 回溯的门槛

根须石室内，铜柱管道上的裂纹正以肉眼可见的速度蔓延。头顶那团银灰色光芒的震颤频率越来越快，像一颗即将衰竭的心脏在垂死搏动。林一凡深吸一口气，鼻腔里满是金属锈蚀与陈腐根须混合的气味，他把手按在那块嵌着暗纹的弧形石板上，系统面板在视野中浮现，墨绿色的字体跳动着刺眼的信息。

**【锚点回溯·最终权限】已激活。触发条件：需与目标锚点建立完整的记忆谐振，且回溯者必须处于“主动放弃”的精神状态。当前吻合度：67%。**

“什么意思？”赵日天蹲在角落，用刀背敲了敲地面的石板，“什么叫‘主动放弃’的精神状态？”

林一凡嘴角抽了一下：“就是说……得先彻底放弃抵抗，让自己的意识完全沉进去，才能跟那个锚点里的记忆连上。”他看向石室深处那具盘膝而坐的躯体——锚-0059，通体灰白，十指结着植物的根须状晶体，像是死去千万年又在此地强行凝固成形的标本。

老王站在旁边，脸色有些发白。他攥着一截从铜柱上剥落的蚀刻金属片，上面刻着一串谁也看不懂的符号，但他直觉那些符号跟断根暗码有关，口中低声道：“你确定要现在用这个功能？倒计时还剩……”

“24分17秒。”系统替他把残局报了出来。林一凡盯着那行红字，决定不再犹豫：“没得选。根须清除程序把咱们一起锁在这儿了，不把这扇门打开，等时间走完，全都得喂给这棵破树。”

他走向第二具躯体。灰白的轮廓在灯光下有种隐约的透明感，仿佛介于实体与影子之间的某种残留。他伸手触碰那具躯体的额头时，指尖传来一阵电流般的酥麻，紧接着整个世界猛然变形。

石室的墙壁像被揉皱的纸一样折叠起来，视野里的老王和赵日天化作一道道拖曳的残影，声音被拉长成含糊的嗡鸣，接着一切归于死寂。

林一凡发现自己站在一条漆黑的长廊里。走廊两侧是一扇扇半透明的门，门上写着编号，从“命1”一直排到“命21”。他低头看自己的手——年轻，没有程序员的手指老茧，腕上还系着一根褪色的红绳，那是大学时某个已经记不清名字的姑娘送的。

他明白了，这就是他的“前世记忆”，属于第22条命之前的某段残留。走廊尽头有一扇门微微敞着，门缝里透出暖黄色的光。他走过去，推开门，看见一张办公桌。桌上摆着一台老旧的CRT显示器，屏幕上闪烁着一行代码：“R，你在吗？”

他头顶传来一个声音——细碎，像低语又像电流经过线缆时的嗞嗞声：“你终于到了这个节点。不要相信……”

声音被一阵尖锐的噪音切断。画面猛然碎裂成无数暗红色的碎片，每一片里都倒映着同一个面容模糊的轮廓。那轮廓穿着一件银灰色的风衣，手里握着一根发光的笔，正俯身在一张巨大的图纸上画着什么——像是在画一株树。

“——不要相信那株银章。”声音再次响起，清晰了一瞬，然后走廊崩塌。林一凡猛睁开眼，后背全是冷汗。

石室里，老王正用铁器撬他手指上的灰白结晶——他刚才在手触到锚-0059的瞬间，右手五指就被一层半透明的根须状晶体覆盖了，像是被什么东西咬住了一样。赵日天一脚踹在他肩头：“醒了没？你晕了整整三分钟，倒计时只剩18分钟！”

林一凡咳了两声，把那层灰白的晶体从手指上扯碎，感觉每一个关节都像被碾过。他目光投向锚-0059——那具灰白的躯体此刻正在一寸寸开裂，像蛋壳一样剥落，碎屑散落在地面上。

灰尘散去，里面空无一物。

只有一截断掉的根须，和一片银色的金属残片。那残片上的纹路，与银章母体嫁接线上的暗码完全一致。林一凡瞳孔骤缩：“银章的母体……就在这棵树的根系之下。”

屋顶那道银灰色光芒突然亮了，像一只睁开的眼睛，直直照在他脸上。

倒计时：17分02秒。

# 《山海百妖录》卡牌策略（任务 13）

## 游戏简介

- 山海经题材卡牌对战（Roguelike 式打怪 + 三选一构筑卡组）
- 纯前端单文件：抽牌、出牌、灵力管理、击败山精狐妖夜叉，最终迎战年兽
- 每场战斗结束三选一加入卡组，死亡结束一局

## 玩法

- 每回合灵力 +3（上限 10），点选手牌出牌
- 攻击牌造成伤害，防御牌叠甲，法术牌有特殊效果
- 清空敌人血量获胜；敌人攻击会在回合结束结算

## 盈利路线

- Web 版免费引流 → 移动端内购（卡牌皮肤、角色立绘、跳过广告）
- 用 MiniMax 生成山海经妖怪立绘做"图鉴皮肤包"（联动任务 11 的变现思路）

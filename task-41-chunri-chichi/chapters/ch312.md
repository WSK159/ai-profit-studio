# 第312章 临江的来客

媒体车队的引擎声像一群饥饿的蜂，嗡嗡地堵在植物研究所的栅栏门外。许迟迟站在二楼的落地窗前，看着那些长枪短炮的镜头对准紧闭的电动门，主持人正对着摄像机补妆，嘴唇一张一合，像宣读死刑判决的书记官。

顾延之从走廊那头走来，手里提着一壶新泡的薄荷茶。他的脚步比往常沉了些，袖口沾着一点泥土——显然刚从温室回来。

“报过警了，”他把茶杯放在许迟迟手边，“他们顶多再待两三个小时就会散。”

许迟迟没接茶。她的食指抵在窗玻璃上，指尖泛白：“临江花业的人也在里面。”她认出了那个穿深灰西装的男人，上次在花市见过，他站在临江的展位前，手里一棵蝴蝶兰，眼睛却一直盯着她的摊位。她记得他的眼珠，黑得像两粒湿芝麻。

“他叫沈故言。”顾延之的声音忽然低下去，“临江花业的总经理。”

沈故言。又是沈字。许迟迟心里那根弦被轻轻拨动了一下。她刚要开口，楼下传来急促的脚步声，随后是门厅的感应铃响——有人进来了。

沈知微几乎是撞开研究所大门的。她今天没穿那双标志性的马丁靴，而是踩着一双平底布鞋，头发随便扎成一束，手里攥着一个牛皮纸袋。她的脸色是许迟迟从没见过的，不是慌张，是那种已经把慌使劲咽下去之后的白色。

“外婆家来人了。”沈知微把牛皮纸袋拍在实验台上，袋口散出几片枯叶的碎屑，“我外公沈伯言年轻的时候，其实还有一个弟弟。我外婆说，那个弟弟当年赌气离家，去了南方，后来娶了临江花业沈家的女儿。”

许迟迟的心一沉，和顾延之对视一眼。顾延之的拇指在玻璃杯沿上慢慢划了一圈，说：“所以临江花业的沈，就是那个弟弟的沈。”

“是。”沈知微深吸一口气，“而且我外婆说，外公临终前把那颗金属颗粒埋在S-7的种盆里，不是藏东西，是还债。”

“还给谁？”

“还给临江。”沈知微的声音有些抖，“外公当年从临江偷走S-7的原始母本，研究了几十年，始终没能让它开花。他种下的第一棵，被顾延之的母亲买走了——那棵后来死了。他又种了第二棵，就是实验室那盆。他死前，把‘SSY’的金属颗粒埋在土里，大概是说，沈伯言欠沈家的，用他一生最重要的东西来抵。”

许迟迟脑子里嗡地一下。许多碎片的线条在这一刻忽然连成了一张网：顾母与沈家决裂、临江盯着研究所不放、S-7的种源来历、沈伯言与顾母的关系——还有那些按点送上门的白花，是不是也在指向同一条线？

“所以顾延之，”许迟迟转头看他，“沈伯言是你外公，那临江花业的沈家，也跟你有血缘关系？你母亲和沈家断绝关系，不止是因为你父母的事？”

顾延之沉默了几秒，拿过那个牛皮纸袋，从里面抽出一张泛黄的照片。照片上的两个青年并肩而立，眉宇之间有七八分相似。背面写着一行字：伯言、伯远，于迟园。

“沈伯远，”他低声念出那个名字，“临江花业的创始人。”

窗外忽然响起一阵骚动。许迟迟探头看去，那个叫沈故言的男人推开媒体的围堵，独自走向研究所的大门。他手里捧着一个玻璃罐，里面装着一株蔫头耷脑的、叶片边缘泛着暗紫色的植物。

S-7。即使隔着这么远，许迟迟也认得出来——那是S-7的幼苗。

沈故言在门口站定，仰头看向二楼的窗口。他开口的声音不大，但清清楚楚地穿过傍晚的风传上来：

“顾延之教授，我带来一样东西。十年前，有人把这棵苗卖给我们临江花业，说是一位姓沈的老先生亲手培育的，只要我们能让它开花，就一切都还能谈。”

他举起玻璃罐，许迟迟看见那株幼苗的根须里，缠着一根细细的金色线头。

那是顾延之母亲织毛衣所用的那种金线。

# 第134章 迟园的清晨

迟园的大门是黑色的铸铁栅栏，上面攀着密密麻麻的铁线莲，正开着紫白色的花。许迟迟记得花语——高洁与欺骗。她曾在花艺课上讲过，“铁线莲的花语很矛盾，就像人一样。”

三月的早晨还很凉，园子里安静得很，只有远处的玻璃花房里透出暖黄色的光。

顾延之把车停在大门外，没有直接开进去。他偏过头看了许迟迟一眼：“你确定要跟我一起进去？”

“这句话你昨晚已经问过了。”许迟迟解开了安全带，“我的答案是‘确定’。再问的话，我就自己敲门。”

顾延之嘴角微微动了一下，没再多说。两人下了车，铁门没有落锁，轻轻一推就开了。走过一条铺着青石板的小径，两侧都是低矮的花圃，种植的植物许迟迟认识大半——白色桔梗、满天星、勿忘我、银莲花。每一种，都是花语里有“离别”或“等待”意味的品种。

他们走到玻璃花房门口，顾母正蹲在一排花盆前，手里拿着一把小铲子，正在给一株尚未开花的植物松土。听到脚步声，她抬起头，目光在顾延之身上停了一瞬，然后落到许迟迟脸上。

“我说了，让你一个人来。”

“妈。”顾延之往前站了一步，挡在许迟迟身前，“她是替她父亲来的。你不想见的人是我父亲，不是他女儿。”

顾母的手顿了一下。她放下铲子，站了起来。许迟迟第一次近距离看清顾母的脸——保养得当的五十岁女人，眼尾有细纹，但目光很锐利。她看着许迟迟，那眼神不陌生，二十多年前，许父大概也是在这样的目光下坚持走进迟园的。

“你父亲当年也像你一样倔。”顾母忽然开口，声音平静得不像话，“他说春分一定会来，结果来了以后就再也没走出去。”

许迟迟的手指紧紧攥住衣角，指甲掐进掌心。

顾延之微微侧过身：“妈，许叔叔的死，到底跟你有什么关系？”

顾母没有回答。她转身走到花房里面，打开一个老旧的铁皮柜，从里面翻出一个牛皮纸信封，泛黄、发脆，封口处用红色的蜡封着。她把信递给许迟迟。

“你父亲当年的实验笔记和那封信的副本，都在这里。”顾母的声音低下去，“看完了再问我。”

许迟迟接过信封，牛皮纸的触感粗粝而冰凉。封面上没有字，只有几滴暗褐色的痕迹，像是溅上去的水渍，又像是——干涸的血。顾延之站在她身侧，没有催她。

风吹过玻璃花房，铁线莲的藤蔓轻轻摇晃。许迟迟深吸一口气，把信封翻过来，指尖挑开封口。里面是厚厚的纸张，最上面一页，是她父亲的字迹。

笔锋苍劲，最后一行字写到一半便戛然而止，墨迹直直拖出一道痕，仿佛握笔的手猛然被抽离了。那半句话写着：“春分之日，若我未能归来——”许迟迟的手一颤，纸张差点落下去。顾延之伸手按住她的手腕，掌心滚烫地覆上来，低声说：“看完整信，我们再去找我母亲。”她抬起头看向玻璃花房外——顾母不知何时已经走到花圃深处，背影消失在白色桔梗丛里，只留下满地将开的，没有叶子的花。许迟迟缓缓低头，将那半句未完的话，和着阳光与铁线莲缠绕的影子，一字一字读了下去。

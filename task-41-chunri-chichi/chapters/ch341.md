# 第341章 暗绿金属

泥土的潮气裹着桂花香，在槐树下久久未散。许迟迟把那封牛皮纸信小心地收进外套内袋，指尖隔着布料按了按，像是怕它再消失一次。

顾延之蹲在坑边，手掌平贴在那片暗绿金属露出的棱角上。他掌心覆上去时，眉头皱得更深了。

“不是铁。”他说，指腹沿着金属表面慢慢描过，“是铜。”

“铜？”许迟迟也蹲下来。那金属露出地表的部分不过巴掌大，表面覆着一层暗绿锈迹，边缘有折断的痕迹——和之前挖出的铁片如出一辙，像是从更大的物件上硬生生掰下来的。但铜锈的成色比铁片旧得多，至少埋了十几年。

“铜的腐蚀速度比铁慢。”顾延之从坑边捏起一小撮土，在指尖搓开，“但这片铜锈的厚度，和土层断层对不上。”

许迟迟目光落在他手上的土粒上。顾延之的意思是，铜埋得很久，但土是最近才翻动的。

“有人把这片铜从别处搬来，埋在这儿。”她轻声接话。

顾延之点头，抬头环顾迟园。风穿过花圃，那些他母亲亲手种下的花木在黄昏里投下长长的影子，像是无数沉默的证人。“这地方，比你我想的藏了更多东西。”

许迟迟站起身，拍了拍膝盖上的土。槐树粗壮的树干上，那些扭着长的裂纹在暮色里格外清晰——像一个人用力拧着手腕，挣扎着、却始终没能松开。她想起顾母说过的话：“这棵树从小就这样，扭着长，怎么也改不过来。”

“你母亲说这棵树‘扭着长大’。”许迟迟忽然说，“但槐树的生长纹路很少会这么拧。除非外力强行掰过它。”

顾延之走到树边，指尖抚过那道最深的裂纹。他的手停住了。

树干离地约半人高处，有一道旧伤被树皮几乎完全包覆——不仔细看根本发现不了。但此刻暮色斜照，那道疤投下一道微弱的阴影。顾延之从口袋里摸出折叠刀，小心翼翼地剔开表层苔藓，露出更深处的一圈异样。

铁丝。深深嵌进树皮里的铁丝，已经锈成了和树皮几乎同色，却被那圈勒痕出卖了。

许迟迟倒吸一口气。这棵树——有人曾用铁丝把它强行绑缚过，想要拗直它。树长着长着把铁丝吞了进去，但它终究没有变成被期望的样子，依然扭曲地、执拗地，长成了自己的形状。

顾延之盯着那道铁丝，声音低下来：“我母亲小时候，她父亲管她极严。苏家规矩多，她说她小时候背不出《诗经》就不许吃饭，走路不许穿有颜色的衣裳，连笑——都不许太大声。”

许迟迟心口发紧。

“她还说过一句话。”顾延之的指尖离开那道铁丝，“她说，‘有人想把我拗成另一棵树，我没拗断，就扭着长了。’”

“那这棵树——”许迟迟低声问。

“是她种的。嫁给我父亲那年，从苏家老宅移过来的。”顾延之直起身，“她说那是她唯一从家里带走的东西。”

许迟迟忽然觉得那棵树不是树了。那是苏佩兰——顾母，郑青崖口中的苏佩兰——被拗着、绑着、又挣扎着长成自己模样的半生。

铜片、铁丝、槐树、迟园。苏明远的名字再次浮上来。

“苏明远是苏家的什么人？”许迟迟问。

“按郑青崖的说法，是苏家的远房堂亲。”顾延之的声音顿了一下，“但我母亲从来没提过这个名字。她提过她的父亲，提过一个早夭的姐姐，提过苏家的规矩和花园——唯独没有苏明远。”

“一个人不会无缘无故被另一个人的记忆除名。”

顾延之看着她，夜色正一寸一寸漫上来，迟园的花香在暮霭中浓得化不开。“还有一件事，”他说，“郑青崖走之前悄悄和我说了一句——他说，苏明远当年那场‘死’，尸体是他亲手验的。”

许迟迟一愣：“既然是他验的，他为什么还怀疑苏明远活着？”

“因为他验完尸体三天后，那具尸体就不见了。”

风猛地把花圃吹出一阵簌簌响。许迟迟脊背发凉。

“他说那件事当年因为忌讳，压了下去。但这么多年，那个疑窦一直在他心里。”顾延之将那片铜片小心地包进手帕里，收进口袋，“他一直没想明白，一具封了棺的尸首，是怎么凭空消失的。”

许迟迟看着他将手帕放好，轻声说：“所以苏明远可能真的没死。那这片铜——”

话音未落，暮色里忽然传来一声极轻微的声响。

两人同时看向花圃深处。那排被风吹动的月季后面，隐约一点人影，一晃就不见了。

顾延之拔步追去。许迟迟只迟疑了半秒，跟着冲了出去。花圃的矮灌木在风里抖落几片叶子，那人影已经消失在迟园后门的转角。地上落着一朵花。

一朵冬天不该开的桂花。

许迟迟蹲下去，拾起那朵花。花瓣淡白，带着她熟悉的香气——和信封上那缕桂花香一模一样。顾延之走回她身边，目光落在那朵花上，沉声道：“冬季桂花。”

有人刚刚来过这里。在听他们说话，然后留下了一朵花，走了。

她的目光追着后门的方向，夜色已经将一切吞没。她低头看着掌心那朵淡白的桂花，花瓣的边缘有些微卷曲，像是被人刻意摘下来放在那里，等着被发现。

“他在引我们找到他。”许迟迟说。

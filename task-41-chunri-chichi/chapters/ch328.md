# 第328章 那封信的去向

顾母的话像一颗石子投入死水，荡开层层涟漪。

顾仲之站在石屋门口，煤油灯的光把他的影子拉得很长。他沉默了片刻，脸上的褶皱在光影里显得愈发深刻：“嫂子，三十年了，你问的第一句话，还是那封信。”

“因为那封信决定了两个孩子的命运。”顾母的声音有些发抖，她往前迈了一步，月光照在她银白的发丝上，“当年你说替我送到，我信了你。可延之从没收到过迟迟的回信，迟迟也没收到过他的。你说，信去哪儿了？”

许迟迟僵在原地。她感觉到顾延之的手悄悄握住了她的手腕，力道不大，却带着一种确认般的存在感。她不由侧过头，看见他下颌绷紧的线条。她从未见过他这样的表情——那是隐忍、困惑与某种深藏的恐惧交织在一起的神色。

“信是我截的。”顾仲之的声音很平静，像在陈述一件与自己无关的事，“但我截的不是许秀禾写给你的回信，而是沈复生写给许秀禾的告别信。”

空气骤然凝固了。

“你说什么？”顾母的音调拔高了一截。

顾仲之转过身，走进石屋，在靠墙的木箱上坐下来。他掏出一支烟卷，却没有点燃，只放在鼻尖嗅了嗅：“那年秀禾做实验，培育出‘迟迟’的原始种源。她发现……这株花的基因序列里有一段异常。”

“异常？”顾延之松开许迟迟的手腕，上前一步。

“那段序列不来自任何一种已知蔷薇科植物。”顾仲之抬起眼皮，看向顾延之，“秀禾用了三个月时间比对数据库，最后确认——那段基因序列来自人类。”

夜风从门缝钻进来，煤油灯的火苗猛地跳了一下。

许迟迟感觉后背泛起一层密密的凉意。她不由自主地摸了摸自己的手臂，那里还有上次在温室里被枝条划伤的疤痕。

“你胡说。”顾母的声音尖锐而颤抖。

“我知道你不信。所以我截了那封信。”顾仲之缓缓道，“复生在信里告诉秀禾，他会带她离开临江，去国外重新做实验。他不想让这个发现被伯言知道——因为那段基因序列，恰好和伯言早年一次体检的样本高度吻合。”

许迟迟觉得自己听懂了什么，又觉得自己什么都没听懂。她下意识地看向顾延之，发现他的脸色已经白得吓人。

“秀禾那晚写给嫂子的信……我确实看到了。”顾仲之把烟卷放回口袋，“但信里说的不是她自己的事，是秀禾的发现。她本想通过嫂子把信息传给研究所，可我截了它。”

“所以……”顾母的声音像从牙缝里挤出来，“所以当初沈复生根本不是失联，是你把他……”

“我没有杀他。”顾仲之打断她，眼底闪过一丝悲凉，“复生是自己走的。他说他不能再留下来，否则秀禾会死。”

话音未落，石屋外的矮树丛里忽然传来一声细微的草木折断声。

顾延之猛地转头，手电光扫过去——树影晃动，却空无一人。

许迟迟的心跳骤然加速。她在空气中嗅到一丝熟悉的甜香，那是“迟迟”花朵绽放时特有的气味，带着铁锈般的金属尾韵。可这个季节，那盆花根本不该开花。

“有人来过。”她低声说。

顾仲之霍然站起。他快步走到石屋门口，蹲下身，用手指捻起地上一撮湿润的泥土。土里嵌着一片指甲盖大小的金属碎片，在月光下泛着幽幽的光。

“SSY。”他念出上面刻的字母，声音干涩，“他回来了。”

顾母后退一步，扶住门框，脸上的血色褪得干干净净：“不可能……他明明……”

“明明死了？”顾仲之抬起头，眼底映着煤油灯的光，像两簇幽暗的火，“嫂子，三十年前那场火里烧焦的尸体，你亲眼确认过面容吗？”

顾母没有回答。她垂下头，双手微微发抖。

许迟迟站在原地，攥紧了口袋里那枚同样刻着“SSY”的黄铜钥匙。那是她从花架底下的铁盒里找到的，一直没来得及告诉任何人。此刻她终于明白，这把钥匙挂坠的沉默，比任何一句告白都更沉重。

她抬起头望向顾延之的侧脸。月光替他镀上一层薄薄的银边，而他的目光仍落在石屋门口那枚碎片上，久久没有移开。

夜风又起，墙角那株老藤随风摆动，叶底深处，似乎有什么东西微微闪烁了一下。

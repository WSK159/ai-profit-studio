# 第168章 迟园的门

顾母的迟园在城郊半山上，铁门常年掩着，今天却大敞着。许迟迟站在门口，怀里抱着那盆“迟迟”，顾延之站在她身侧，一只手虚护在她腰后。

“她等你很久了。”守园的老花匠说完这句话，便侧身让开了路。

园子里的白玫瑰开得正盛，比山下的月白花田更加繁茂。许迟迟一步步走进去，脚踩在夯实的泥土上，又软又稳。顾母坐在花房前的老藤椅上，鬓角花白，手里端着一杯凉透的茶，像是坐了很久。

“来了。”顾母看见她，语气淡淡，眼底却有一丝许迟迟从未见过的疲惫，“我知道你总会来。”

许迟迟把花盆放在她面前，那朵“迟迟”已经半开，淡紫色的花瓣上还沾着晨露。顾母低头看了一眼，手指轻轻碰了碰花瓣，沉默了半晌才开口：“这花，延之取了名字叫‘迟迟’。”

“我知道。”许迟迟说，“但我今天来，不是问花的事。”

她把那封信从口袋里拿出来，平放在顾母面前的石桌上。顾母的目光落在信封上，指尖一颤，凉掉的茶杯差点翻倒。她抬起头，望着许迟迟的眼神忽然变得复杂——有愧疚、有悔恨，还有一丝说不清的痛楚。

“你看过了。”顾母的声音干涩。

“我妈写给你丈夫的信。”许迟迟的声音平静却发紧，“她说你去找过她，用一件事威胁她。她怕那件事伤害我，所以选择消失。”

顾母闭上眼，久久没有说话。花房外的白玫瑰在风里轻轻摆动，落了一地花瓣。

“那件事，不是威胁。”顾母终于开口，声音哑得像砂纸，“我告诉你妈，你爸不是你的亲生父亲。”

许迟迟整个人像被兜头浇了一盆冷水，瞳孔骤缩：“你说什么？”

顾母睁开眼，直直地看着她：“你爸——你叫了二十八年的那个男人，是你母亲的丈夫，但不是你亲生父亲。你的亲生父亲，是顾长春。”

花房里一片寂静。顾延之猛地站直，声音紧绷：“妈，你说什么？”

“我当年去医院替你爸做过一次体检，顺手看了配型报告。”顾母苦笑，“你的血型、染色体标记，和你爸每一项都对不上。我拿着报告去找了你母亲，说她配不上长春，说她留下你会毁了长春的前程。我没想逼她走，但她把这件事当成了威胁。”

许迟迟脑子里嗡嗡作响，耳边只剩自己心跳的声音。她低头看自己的手，那枚“归迟”的银戒指在灯光下微微发亮——归迟，归迟。她忽然想起母亲遗信里那句“长春说要带我去看”，想起她把母亲的照片贴在胸口，觉得自己像是站在一片白茫茫的大雾里。

“我爸……我那个爸，”她的声音几乎不是自己的，“他知道吗？”

顾母点了点头：“你母亲走后，他来迟园找过长春。两人在花房里谈了很久，长春托他照顾好你，他答应了。后来他把所有关于你身份的线索都抹了，连长春写给你的信，也被他藏了起来。他说这是他能为你做的最后一件事。”

许迟迟想起母亲写给顾长春的那封信——“我怕她伤害迟迟”——眼泪终于落了下来。那个她叫了二十八年的父亲，沉默寡言的父亲，在她看不见的地方，替她挡了一辈子的风和雨。

“所以你拦下延之的告白信，是因为……”顾延之的声音发哑。

顾母低着头：“因为我不想让他和同父异母的妹妹扯上关系。可我错了。后来我查了DNA，你和迟迟没有血缘关系。”

顾延之一怔，许迟迟也抬起头，泪眼模糊地望着顾母。

“你和长春的亲子鉴定，是我三个月前做的。”顾母嘴角牵出一个苦涩的笑，“DNA结果确认了，你不是我的孩子。”

花房里静得只剩风声。顾延之的脸一寸寸白下去，又骤然涨红，他张了张嘴，没有说出话来，只是猛地转向许迟迟。许迟迟站在夕阳底下，那盆“迟迟”的花瓣被风吹落了一片，落在她掌心里。

她低头看着那片淡紫色的花瓣，又看了看顾延之——他的目光里，有震惊、有痛楚、有无数说不清的柔软。

“所以这些年，”她轻声说，“我们都认错了地方。”

顾延之没说话，只是往前一步，握住她拿着花瓣的手，掌心是凉的，指腹却滚烫。花房外，白玫瑰的香气被晚风送来，迟园的夕阳把两个人的影子拉得很长。

顾母坐在藤椅上，望着他们交握的手，忽然觉得鼻子一酸。她这十年，守着两个没血缘的孩子，怕了一辈子，最后拆开的，是自己亲手织的网。

“那封信，”许迟迟忽然开口，“你拦下的那封告白信，还在吗？”

顾母怔了怔，从藤椅旁的旧木匣里取出一只泛黄的信封，递过去。许迟迟接过，信封上写着“许迟迟亲启”，落款是十年前的夏天，顾延之的笔迹。她没有拆开，只是紧紧攥在手里，指节发白。

“十年前我没收到的，”她抬起头，望着顾延之，“现在能听你亲口说一遍吗？”

夕阳铺满园子，白玫瑰花影摇曳。顾延之站在她跟前，喉结上下动了动，那句等了十年的话终于从他嘴里低低地落下来：“迟迟，我喜欢你。从十年前的夏天，一直喜欢到今天。”

许迟迟低头看着手里的花盆，那朵“迟迟”在夕光里轻轻颤了颤，花瓣又展开了一些，像是一颗心缓缓打开了。

她没有说话，只是把银戒指从左手无名指挪到了右手无名指——然后，把左手伸进他掌心里。

# 第237章 夜探迟园

暮色像一层薄纱笼住迟园，温室玻璃折射出最后一线残阳，随即被夜色吞没。许迟迟跟在顾延之身后，穿过那道生锈的铁门，脚下碎石子发出细碎的声响。

顾延之手里攥着那本旧笔记本，皮面已经开始剥落，边角被虫蛀出几道细纹。他在迟园门口停了一下，没有立刻进去，而是转身看了一眼许迟迟。

“你确定要跟我一起？”他的声音很低，像怕惊动什么。

许迟迟点点头。她手里握着那枝干茉莉，纸角已经被她反复摩挲得发软。她有一种直觉，这迟园里藏着的东西，比她这十年所有的猜测都要深。

两人进了园子。顾延之熟门熟路地穿过前院，绕过那排长得半人高的白菊丛。许迟迟注意到，那些白菊种得极其规整，每株间距一致，像有人拿尺子量过似的。花圃中央有一座小木屋，门虚掩着。

“我爸以前不住这儿，”顾延之推开门，屋内陈设简单，一张旧桌、一把藤椅、一个书架，“但他出事前那段时间总往这里跑，我妈说他在整理什么。”

许迟迟走到书架前，手指拂过一本本旧书——全是植物学专著，有许多页角折过。她忽然停住，从一排书后面抽出一个牛皮纸信封，没有封口。

信封里是几张照片。第一张是春熙，站在一片温室前，手里捧着一盆植物，那盆植物的叶片许迟迟认得——正是“迟迟”的母本。照片背面用钢笔写着一行小字：“第三十六次杂交实验，成功。”

第二张照片是顾延之的父亲顾维明与春熙并肩站着，两人都穿着白大褂，背景是某间实验室。春熙侧过脸看他，嘴角带笑——那个表情许迟迟再熟悉不过，那是一个女人看心爱之人的眼神。

她翻到背面。那行字让她呼吸一顿：“希望这次，能补上迟了十年的道歉。”

“春熙和我爸……”许迟迟抬起头，声音有些发涩。

顾延之站在窗边，月光从窗口斜斜切进来，把他的轮廓勾出一道银边。他沉默了几秒，说：“他们是同学，也是恋人。后来我爸娶了我妈——那是两家联姻。”

许迟迟攥紧那张照片，又抽出第三张。那是一个花圃的航拍图，但镜头拉得很近，聚焦在三号大棚上。大棚外缘站着一个灰衣女人，脸被帽檐遮住，只露出一截下巴。角落里有一个穿深色衣服的男人，背影正走向大棚入口——那个背影，像极了许建民。

“时间线不对。”许迟迟皱眉，“我爸说他十年没来过迟园。”

顾延之拿过照片，借着月光仔细看。照片背面有一行铅笔字，极其潦草：“1997年4月，沈知蘅，三号棚。”

那是春熙去世前三个月。

许迟迟猛地看一眼顾延之：“你爸记的？如果春熙死于换气系统被关，而沈知蘅种了毒堇，那关系统的是谁？你爸的笔记里有没有写明？”

顾延之翻开笔记本——那本旧笔记本已经翻得起了毛边，前几页全是手抄的植物性状记录，翻到后半部分时，字迹突然变得急促，多处笔划划过纸面。他停在其中一页上，忽然念出声：“4月7日，三号棚检查，系统异常，疑人为，报备，未受理。”

再翻页：“4月12日，沈知蘅与我谈话，她说有办法让春熙离开试验组。我骂了她。次日找到许静婉，让她提醒春熙。”

“许静婉知道这事？”许迟迟吓了一跳，“她是我……”她没说完，沈知蘅说过许静婉是她的生母，这个关系像一根刺，她还没完全咽下去。

顾延之再翻一页，那一页几乎被写满了，字迹比之前更重，像是用笔尖狠狠压出来的：“5月1日，春熙死。那盆花是我拔的——她让我拔的，她说根有异常。我没说明，怕牵连她。春天出的芽，我不该信它。”

那盆花……许迟迟脑子里轰的一声，许静婉遗言纸条上的话像一道闪电劈进来——“春熙那盆花，是他想拔的。”许建民说他爸要拔那盆花。但顾维明写的是“春熙让我拔的”。

“你爸说的是真的？”许迟迟问，“春熙主动要求拔的？”

顾延之没有回答。他翻到最后一页——那页只写了四个字，每个字都大而重，像用刀刻的：“对不起，春。”

屋外忽然传来一声轻响。顾延之猛地合上笔记本、熄掉手机屏幕。两人屏息立在黑暗中。门缝外透进一道光，由远及近，脚步声在石板地上不紧不慢地响。有人来了，而且直奔这间小屋。

许迟迟的心跳几乎撞到嗓子眼。那道光停在了门外。随即，一个女声响起，平静得像湖面：“我知道你们在里面。把那本笔记本给我，顾延之，你爸那十年欠我的，今天该还了。”

是顾母的声音。可这声音里带着一种许迟迟从未听过的冰冷——那不是婆婆训儿媳的口吻，而是——有仇。

# 第335章 信里信外

第二天清晨，雨停了，空气里满是泥土和草木的气息。许迟迟把铜书签和那封旧信仔细包好，放进随身的帆布包里，锁上石屋的门，沿着湿漉漉的坡道走回迟园主屋。

顾延之在西厢房门口等她，手里捧着一杯热茶，见她来了，递过去。茶是迟园自采的野菊花，微苦回甘。许迟迟接过来抿了一口，低声说："我想去一趟临江花业。"

顾延之没有意外。他昨夜把那枚证件拍照留存，天亮前已经通过研究所的数据库查过"苏明远"三个字——临江花业民国档案中确有此人，职务栏写的是"花种选育技术顾问"，但档末有一行红笔批注："该员于民国三十八年春离职，去向不明。"批注人签名为"苏佩兰"。

"苏佩兰，"许迟迟重复这个名字，"顾家老太太本名苏佩兰。"她顿了顿，"和苏明远，是同族？"

顾延之点头："淑字辈，苏家老谱上排同辈。论排行，苏佩兰当叫苏明远一声堂叔。"他把手机屏幕转给许迟迟看，那上面有苏佩兰的一张旧照——老太太年轻时站在一株巨大的金边瑞香前，裙摆曳地，眉目清冷，和顾母有几分神似。"但这条档案被刻意缩略过。我调了完整版，发现原档案有一页被撕去了，缺的是民国三十七年至三十八年间，苏明远在临江花业的全部工作记录。"

许迟迟的后背微微挺直："有人不想让人知道苏明远那一年做了什么。"

"也没人想让人知道，他为什么离开。"

雨后的阳光斜斜照在廊下，将两人的影子拉得很长。许迟迟低头看着茶杯里浮动的花瓣，忽然想起什么："那本《养花札记》第三卷夹层里只有信和书签。如果苏明远在临江花业工作过，札记里不该没有他的字迹。"

顾延之眼神微动。他转身走进屋里，从随行的公文包里取出那本札记的翻拍件——原书被许迟迟放在花店内，但他在研究所时已经做了逐页扫描。翻至第三卷中段，某一页的角落有一行极小的铅笔字，藏在花枝画稿的阴影里，若非放大扫描几乎看不出来。

字迹清瘦，与沈复生圆润的行楷截然不同，只七个字：

**"花开有时，人无期。"**

许迟迟盯着那行字，指节攥紧茶杯。她认得这种写法——笔锋收势极快，捺画一律向右下压，与昨夜信封上被磨掉的那个"终"字，如出一辙。

"苏明远写的。"她说，"他也翻过这本札记。"

顾延之没有接话。他翻到下一张扫描页，停住。那是札记第三卷的最后一页，纸面空白处有一处极淡的水痕，圆形，直径约莫两厘米。水痕中央残留着一小片暗褐色——像是干涸的花汁。

"这个位置，原来压着一朵花。"他说，"花瓣被取走了，但花汁渗进纸纤维，留下印记。"

许迟迟凑近，仔细辨认那片印记的形状。花瓣的边缘是锯齿状，不是玫瑰，不是菊——她心里一动，迟疑道："铁线莲？"

顾延之沉默片刻，点了点头。铁线莲的花语——高洁与欺骗。

这个花语像一根细针，轻轻刺进许迟迟的思绪里。她想起顾母说过，老太太苏佩兰年轻时最爱的花就是铁线莲。而此刻，苏明远——顾家的堂亲，临江花业的顾问，也在这本札记里留下过痕迹。

她放下茶杯："我要去临江花业的旧档案室看看。"

顾延之看着她，忽然伸手，指尖轻轻拂过她耳边一缕被雨打湿的碎发。他的动作自然而轻缓，像在整理一株植物的枝叶。"我陪你去。"

许迟迟睫毛颤了颤，没有躲开。晨光在他们之间流动，带着雨后特有的明亮。

临江花业本部的旧档案室在老城另一头，隔了三条街。两人并肩走在石板上，水洼倒映着天上碎云。经过"迟迟花开"门口时，许迟迟下意识停下脚步——花店门虚掩着，门缝里探出一枝白色的花苞，是那盆被顾延之命名为"迟迟"的新品种。

花苞比昨天又裂开了一圈，白色花瓣的边缘已经能看得分明，边缘带一丝极淡的粉色，像初雪将融时泛起的暖意。许迟迟蹲下身，指尖轻轻碰了碰花苞外层裂开的缝隙。

指尖触到一层湿凉，她低头，发现花盆底部有一圈新鲜的水渍——不是雨水，水渍里混着细碎的黄沙。

她抬起头。店铺门缝里，一张明信片被压在花盆下，露出的那只角上，有一行极小的字——

**"等待的花，终究会开。但有些话，只写在你不看的地方。"**

她抽出来。明信片正面是一株金边瑞香的印刷照片，背面空白的正中央，只写了一个词：

**"别查了。"**

落款处没有姓名。但那张明信片的边缘微微卷曲，像是被人捏了很久，又像是从某个旧信封里拆出来的。

许迟迟和顾延之对视一眼。风从街口吹过来，带起一蓬细碎的白花，扬过她的鬓角。那盆"迟迟"的花苞在风里轻轻颤了颤，裂口又大了些，露出里面层层叠叠的白色花瓣，像就要开口说话。

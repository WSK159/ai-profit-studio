# 第370章 墙背后的人

顾延之把手电筒对准那面墙。墙皮剥落了大半，露出底下斑驳的砖面，有几块砖的色差明显比其他砖深一些，像是被反复涂抹过。他走近，指尖刚触到其中一块砖，那砖竟微微向内凹陷了半分。

他回头看了许迟迟一眼，没有开口，手掌贴上砖面，缓缓用力——整块砖是活动的，像一块搭扣，向里推去，露出一个拳头大小的黑洞。

手电筒光探进去，照见一截黑黝黝的木梯。木梯直通向下，尽头隐约透出一丝昏黄的光。

“下面还有一层。”顾映雪低声惊呼，“我在这里长大，从来不知道花窖有地下室！”

顾延之先下去探路。他踩上木梯，每一步都等梯子承住重量才放下第二脚。梯子发出令人牙酸的“吱呀”声，但还算结实。许迟迟跟在后面，铜钥匙攥在手心里，金属已经被她攥得发热。顾映雪最后，她往门口看了一眼，铁门依旧锁得死死的。

木梯尽头是一间不足十平方米的暗室。天花板很低，成年人需要低头才能立身。靠墙摆着一张窄桌，桌上放着一盏老式煤油灯——灯油已经干涸，灯罩上积了一层灰，但灯座旁放着一支新蜡烛，蜡芯干干净净，像是有人刚摆上去的。蜡烛下压着一张纸，纸边微卷，上面压着一支旧钢笔，笔帽上镌着两个字：“伯言”。

许迟迟伸手拿过那张纸。纸是普通信笺，边缘发黄，但墨迹是新的——字迹工整，骨力遒劲，和钥匙背面的刻痕如出一辙。纸上只写了三行字：

“花不会一直不开。等门开了，就是春天。”

“笔记在抽屉里。那批花，是她留给你的。”

“别让她进来。不是指门。”

许迟迟把纸递给顾延之，喉咙发紧：“最后一句……‘她’是谁？”

顾延之把纸翻来覆去看了两遍，指腹停在“不是指门”四个字上：“爸写这行字的时候，应该是在说——”他忽然顿住，猛地抬头看向许迟迟身后。许迟迟跟着回头，看见墙角一口老旧的木箱，箱盖上放着一把新鲜剪的白色桔梗——花瓣上的露水还没干。

有人刚刚来过。而且，就带着这把花。

“在楼上。”顾延之声音很轻，“木梯另一头。”

许迟迟头皮一麻。她想起铁门外那声轻响、门缝里那片新摘的桔梗花瓣，还有墙上那些色差明显的砖——如果下面有人进了暗室，上面的人可以从砖洞里看见他们。而他们方才在暗室里的每一句话，都可能被听了个正着。

“先找抽屉。”顾延之低声道，按住许迟迟的手腕，“笔记拿上就走。别的来不及了。”

他快步走到窄桌前，拉开抽屉。抽屉里整整齐齐地码着一本牛皮封面笔记本，封面上用钢笔写着四个字：“迟迟花谱”。本子侧边夹着一支干枯的海棠花枝，花瓣已经褪成暗黄，但花形完整——是相思海棠。

许迟迟伸手接过笔记本，指尖刚触到封面，花窖上方突然传来一声沉闷的撞击声——像是有人从外面用力撞门。紧接着，是一声被压得极低的、苍老的怒喝：“你们在里面干什么？出来！”

那是顾母的声音。

顾延之面色骤变，把牛皮笔记本塞进许迟迟怀里，动作仍稳：“跟我走。木梯上去，翻窗出去——花窖西墙有小窗。”他边说边转身，手电筒扫过墙角——但在扫过窄桌脚的时候，他忽然停住了。

桌脚下压着一角白色布料，露出小小的、绣着字的标签。顾延之蹲下身，把那角布料抽出来——是一方手帕，白色棉布，边角绣着两朵桔梗。手帕正中有一行褪了色的钢笔字，是一行地址，更下面还有一行更小的字。

许迟迟凑近，念了出来：“城西幸福巷13号。妹妹，这里有你要的东西……”

顾延之的手帕微微发颤。他猛地抬起头，看向顾映雪——顾映雪靠在墙边，脸色惨白，嘴唇翕动了两下，没出声。

那方手帕上的字迹，他认得。那是他母亲年轻时的字。

铁门外的撞击声越来越重，夹杂着顾母沙哑的喊声：“延之！开门！那是你爸的——”她的声音在某个瞬间戛然而止。紧接着，一声清脆的“咔嚓”从门外传来，像是什么人被扑倒了。

暗室里忽然安静下来。

许迟迟攥紧那本《迟迟花谱》，手心里全是汗。她看了一眼顾延之，发现他的目光死死钉在那方手帕上，脸上是她从未见过的、复杂的神色——像是终于找到了什么，又像是终于失去了什么。

花窖门内，那声幽深的呼吸再次响起。这一次，像是从墙砖的缝隙里渗出来的。

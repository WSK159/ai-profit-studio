# 第113章 迟园夜话

铁栅栏外的路灯忽然灭了。整条小径陷入黑暗，只有迟园深处那栋老宅的窗子透出一点昏黄的光。

许迟迟抱紧了怀里的花盆——那盆“迟迟”在她臂弯里轻轻晃了一下，叶片在暗色里泛着幽微的绿意。

顾延之站在她身前半步，身形在夜色里显得格外挺拔。他没有回头，声音却低而稳：“妈，那封信——”

“我说了，我不知道什么信。”顾母的声音从门缝里透出来，像风穿过芦苇，“夜色深了，你们走吧。花圃要锁门了。”

门缝里那只枯瘦的手在关门之前，忽然停住了。顾母沉默片刻，又加了一句：“你父亲留下来的种子库，第三排的第七个抽屉里，有一个牛皮纸袋。你若真想查，自己去翻。翻完了，别来找我。”

门终于关上，锁舌咔哒一声，像是什么东西落定的声音。

顾延之在原地站了很久。路灯忽明忽暗地闪了两下，又亮了，把他的侧脸照得轮廓分明。许迟迟看见他的下颌线绷紧了，那是他在克制什么的习惯动作。

“第三排第七个抽屉。”他低声重复了一遍，转身看向许迟迟，“你说，那里面会是什么？”

许迟迟没有说话。她低头看着怀里的“迟迟”——叶片的边缘有一抹极淡的红意，像是要抽花穗的前兆。她心里忽然跳了一下：“顾延之，你看这个。”

她把花盆稍稍抬高，让灯光照在叶片上。顾延之蹲下来，修长的手指轻轻拨开最外层的叶子，露出内侧茎秆上一小截淡褐色的痕迹——像是被什么东西包裹过，长时间勒出的印记。

“这截茎秆……小时候被绑过。”他声音发紧，“用某种线绳绑的，绑了至少一两年，拆掉之后留下了永久性凹陷。”

许迟迟脑子里嗡了一下：“红头绳。”

她想起迟园暗房里那根落满灰尘的红头绳——和夹在订货单里那张快褪色的字条上那个熟悉的笔迹：“阿蕙，我改良了银莲花的抗病性，下一季就能开花。”

阿蕙是顾母的名字。

顾延之缓缓站起身，目光从花盆移到迟园紧闭的门上。“我妈说的牛皮纸袋，”他嗓音沙哑，“你说，会不会跟这个有关？”

“去你父亲的种子库看看。”许迟迟说。

他没立刻答应。他把手伸过来，指尖在“迟迟”的一片叶子上停了一秒，像在触碰一件极贵重又极脆弱的东西：“好。明天一早去。”

夜风吹过来，带着迟园花圃里潮湿的泥土气。许迟迟忽然觉得怀里的花盆重了一些，那些即将挣开花苞的力量，好像也在她胸口挣动。她低下头，用拇指轻轻擦过“迟迟”那截凹陷的茎秆，那凹陷像一道环，像一句被勒住十年没来得及说出口的话。

顾延之慢慢转向她，忽然说了句不相干的：“许迟迟。”

“嗯？”

“明天去了种子库，不管翻出什么……”他顿了一下，声音低下去，“你都别走。”

许迟迟在路灯下抬起头，看见他眼底有一层薄薄的光。那不是泪光，是他眼里常有的、那种专注而隐忍的光芒。她心里像有一根细线被轻轻拉了一下，片刻后她点了点头：“我不走。”

铁栅栏外面，老街尽头的钟楼敲了十一下。风从城市的方向吹过来，吹起许迟迟的围巾一角。她抱着那盆注定要开的花，站在月光下，忽然觉得从今往后的每一夜，都和十年前的那一夜不一样了。

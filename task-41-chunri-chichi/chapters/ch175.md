# 第175章 月下美人

清晨六点，许迟迟推开花店的玻璃门，冷风裹着露水的湿气扑面而来。她蹲在墙角，指尖轻轻拨开那盆“迟迟”的叶片——昨日还紧闭的花苞，今早竟透出一丝若隐若现的白，像月光凝成的薄纱，被风掀开了一角。

“真的要开了。”她低声说，声音里有种说不清的颤抖。

身后传来脚步声，顾延之拎着两杯豆浆走进来，看见她蹲在地上的背影，脚步顿了一下。他走过去，在她旁边蹲下，目光落在那枚花苞上，沉默片刻，说：“它比预期早了三天。”

“因为你妈给了那枝‘月下美人’。”许迟迟直起身，指腹擦过花盆边缘，“白玫瑰的根系和它缠在一起了，我昨晚换土时才发现的。”

顾延之的眉头微微蹙起。他望向窗台上那枝插在玻璃瓶里的白玫瑰，枝条上的刺被仔细修剪过，切口平整，是懂花艺的人的手法。他母亲养花三十年，却从未主动给过任何人一枝花——更不用说用它来嫁接她的心血。

“她什么意思？”他问。

许迟迟没有回答。她走到操作台前，拿起那张压在花瓶下的字条，纸面泛黄，折痕深深，字迹被岁月泡得模糊，却依稀能辨认出那句“求您放过我女儿”。她母亲的字。十年前留下的。

“她说这是当年的‘那件事’的凭证。”许迟迟将字条放回原处，“让你去问你爸。”

顾延之的表情冷了一瞬。“我爸已经去世三年了。”

“我知道。”许迟迟回过头，目光平静地看着他，“但你妈说，有些话只能对着墓碑说。她还说，等那盆花开了，你跟我去一趟昆明，见了许建民，所有的账都会算清楚。”

顾延之沉默了很久。窗外的晨光一寸寸漫进来，照亮他下颌紧绷的线条。他最终开口，声音低而笃定：“我去订票。”

许迟迟还没来得及应声，店门忽然被推开，一串风铃叮当乱响。沈知微裹着一身咖啡香冲进来，手里还攥着一杯没喝完的拿铁，神色慌张：“许迟迟，你上热搜了。”

“什么？”许迟迟一愣。

沈知微把手机屏怼到她面前：一张照片，昨晚迟园门口，顾延之的黑色轿车停在路灯下，她正从副驾下来，头发被风吹得凌乱，而顾延之半个身子探出车窗，替她拢了拢衣领。角度刁钻，拍得暧昧又真实。

配文标题：《花艺师许迟迟夜会植物学教授顾延之，疑似恋情曝光》。

“这……”许迟迟皱眉，“昨晚你开车送我回来的？”

“是。”顾延之走过来，扫了一眼屏幕，“但拍照片的人位置不对。迟园门口没有路灯，这光是从对面楼上打下来的。”

沈知微愣了。“你是说，有人蹲点？”

顾延之没说话，目光落在那张字条上，又移到玻璃瓶中那枝白玫瑰上。他忽然开口：“我妈的花圃，这些年一直有人守着。”

“守什么？”许迟迟问。

“守着一个人回来。”

他话音未落，许迟迟的手机响了。屏幕上跳动着养父许建民的名字——这是三个月来，他第一次主动给她打电话。

她接起，那头传来粗糙的呼吸声，夹杂着风声和鸟鸣，像野外的一个清晨。许建民沉默了很久，终于说了一句话。

“迟迟，你妈当年跪的不是顾家的门。她跪的是你亲爷爷的坟。”

许迟迟握紧了手机。“……什么？”

“你来昆明。来了，我把所有事都告诉你。”

电话挂断了。许迟迟站在原地，指尖冰凉，那枝白玫瑰的香气忽然变得浓烈刺鼻。顾延之按住她的肩膀，沉声说：“我陪你去。”

许迟迟抬起头，看到他眼底深沉的笃定。她想起母亲字条上那句“求您放过我女儿”，想起顾母递出那枝花时指尖的颤抖，想起那盆“迟迟”花苞上的第一缕白——她忽然意识到，这场跨越十年的追问，终于要落下第一枚棋子了。

“明天就走。”她说。

风铃又响，外头有人推门进来，递上一束白花，没有卡片。白玫瑰，满天星，扎成一束悼念的样式。沈知微惊呼一声：“谁送的白花？这不吉利。”

许迟迟蹲下身，拨开满天星的枝叶，在花束最深处，发现了一枚银色的胸针——刻着一棵榕树的图案，是云南那边的老物件。她认得它。十年前，许建民曾在花艺大赛的合影里戴着这枚胸针，之后她说想看一下，他笑着摘下来，却又收回了手。

“这是许建民的东西。”她轻声说。

顾延之目光沉沉，伸手将那枚胸针拈起来，翻转过来——背面刻着一行小字，字迹被磨得模糊，却仍能辨认出几个字。

“顾长春之母，遗物。”

他顿住了。许迟迟望着他，看着他的名字被刻在养父母亲的遗物背后，忽然觉得自己正站在一个巨大的深渊边缘，脚下是十年的空白，所有她以为知道的，全都在往下坠。

“顾长春是谁？”她问。

顾延之的喉结动了动。“我大伯。”

窗外阳光大明，白玫瑰在风中轻轻摇曳。那盆“迟迟”的花苞，在这时肉眼可见地裂开了一条缝，仿佛有什么东西，正要破土而出。

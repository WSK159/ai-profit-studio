# 第211章 海棠树下

许迟迟站在花店门口，晨光斜斜地落在她肩头。昨夜那场雨湿透了整条老街，空气里飘着泥土和青苔的气味。她握着一把银色的园艺剪，指节泛白。

顾延之站在她身边，手里拎着那把从周警官处借来的铁锹。他的目光落在花店门前的海棠树上——那棵她十年前种下的海棠，如今已经高过屋檐。

“你确定要挖？”他低声问。

许迟迟没答话，径直走到海棠树下，蹲下身子刨开湿软的泥土。昨晚的樟木箱是从沈家旧宅挖出来的，但外公留下的录音里隐约提过——还有一样东西，埋在“迟迟花开”门前的海棠根下。

她刨了大约半米深，铁锹突然碰上一个硬物。声音沉闷而清脆，像金属与陶器的撞击。

顾延之蹲下来，用手徒手拨开泥土。一个铁皮饼干盒，锈迹斑斑，缠着一圈银色胶带。胶带已经老化发脆，指尖一碰就碎裂开来。

许迟迟屏住呼吸，将盒子打开。

里面叠着几张泛黄的纸、一把钥匙和一张黑白照片。照片上的人穿着白衬衫，坐在花棚里笑——二十几岁的沈荣生，搂着一个十来岁的女孩，那女孩眉眼间有几分像许建民。

许迟迟翻过照片，背面写着一行字：“建成周岁，迟园后棚，1987年春。”

顾延之眉头微皱：“迟园？你外公的旧花圃？”

许迟迟攥着照片，没有说话。她的视线移向那几张泛黄的纸，最上面那张赫然是——一份手写的《婚前财产协议》，甲方沈荣生，乙方许知蘅。

“知蘅……”她喃喃念出那个名字，血缘上该叫外婆的女人。

协议只有短短两页，核心内容却触目惊心：若沈知蘅与沈荣生离婚或一方身故，迟园全部产权及名下三个花圃地契，归沈建成（许建民）所有，沈知蘅不得以任何理由转赠、出售或抵押。

“沈知蘅杀顾长春，很可能就是为了这份协议。”顾延之的声音很轻，“长春若不死，她拿不到那片海棠试验田的产权。”

许迟迟合上铁皮盒，握紧了那把钥匙。钥匙是铜制的，匙柄上有刻痕，模糊辨认出两个字——迟园。

“这是外公当年藏起来的。”她说，“他假死之前，就把迟园的钥匙和地契副本埋在这里了。他早就料到沈知蘅会动手。”

顾延之沉默片刻：“可你外公为什么不直接报警？”

许迟迟抬起头，眼眶红红的：“他大概以为，亲手养大的女儿，总有一天会回头。”

花店里突然传来手机铃声。许迟迟起身，擦掉膝盖上的泥，接起电话。是沈知微打来的——

“迟迟，我跟你说个事儿。我昨晚托银行的朋友查了一下，你外公那个账户，除了取款记录之外，每个月还会收到一笔入账。金额不大，三千块。汇入方……”

她顿了顿：“是许建民名下的长期委托代扣。”

许迟迟僵在原地。

父亲许建民十年前死于车祸，可这笔委托代扣，是从十五年前开始的，从未中断。

一个已经死去的人，在给一个假死的人，悄悄送钱。

她转头看向那个饼干盒，里面最底下的那张纸，她还没来得及看——那是对折的汇款单存根，收款人是“沈荣生”，备注栏写着一行小字：阿爸，对不起。

许迟迟的手开始发抖。

顾延之伸手按住她的肩膀，声音沉稳有力：“下周二，城西邮储银行，我陪你。”

她点了点头，握紧那把带着锈迹的钥匙，又看了一眼那棵海棠树——树根处露出细密的裂纹，像极了某个人埋了十几年的秘密，终于在这个春天裂开了口。

她心里浮现出一个念头，却不敢说出口：外公还活着，父亲当年会不会——也没有死？

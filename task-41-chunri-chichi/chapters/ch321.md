# 第321章 卖花的契约

许迟迟被那一句话钉在原地，手里的文件袋像是忽然沉了十倍。

沈知微一把扶住她的手臂，压低声音问：“你没事吧？”

许迟迟摇了摇头，却没说话。她视线落在文件袋的红绳上，那绳结打得很死，像某种执念。老人见了，把那文件袋又往回拉了拉，低声道：“你确认要在这里拆？”

她们正站在一间堆满旧物的门房里，空气里弥漫着干燥的花粉味和灰尘味。许迟迟点了点头。她不是不谨慎，而是这十年来她学会了一件事——时机错过了，问题就再也问不出口。

红绳解开的瞬间，许迟迟聞到一股淡淡的白菊味——那味道不是来自外面的花盆，而是从纸张本身渗出来的，死了三十年还赖在纤维里不肯走。

里面是一份手写协议，总共三页。纸张泛黄易碎，折痕处已经裂开细缝。字迹是毛笔写的，工整秀丽，却在落款处止住——一朵梅花。

许迟迟一页一页地翻完。第一页是合作内容：临江花业提供寒地温室与一批特定花种，许秀禾负责育种与花艺指导，花期产品归临江花业所有；第二页细则中夹了一张附录清单——奇怪，那清单上的花种落款处被墨水涂掉了，唯独留下一行小字“待验苗”；第三页则是双方签字盖章处，许秀禾的名字旁边画着那朵梅花，上方一栏签着——顾伯言的名字。

许迟迟盯着“顾伯言”三个字，那笔迹端正硬朗，和顾延之的字一脉相承。果然如此。

老人叹了口气，在她旁边蹲下身，轻声说：“那一年，你外婆来了一次，又走了，再没回来过。我问她花呢？她说，花不该卖。”

许迟迟抬头：“不该卖什么花？”

老人又沉默了，目光移向窗外渐暗的天色。“你外婆没说。但我记得——她从迟园方向回来的那天，手里捧着一盆土，土里插着一条细细的藤蔓。那藤蔓的根，是金色的。”老人伸出一根苍老的手指，在空中比划了个粗度，“像丝线那么细，但扎得深。”

许迟迟心里的某根线忽然断了——和顾延之实验室灰桶里那根极细的金线串在一起，像一颗珠子终于滚对了轨道。

“那盆土呢？”她问。

“被拿走。”老人说，“过了几天，有人来取。提着一个白色纸箱，顶口封得严实，看不出装了什么。那人穿着灰衣服。”

灰衣服。

许迟迟和沈知微对视一眼。这是第二次听说灰衣人了——上次是从花店后巷的监控里看到一个模糊的影子。而沈知微也莫名低声接了句：“原来不止我们见过。”

老人继续说：“你外婆后来没再来，只有一封信寄到，说是项目取消，协议作废。她还说了一句奇怪的话——‘根还了，土也该还。’”

“根已经还你了，土不是我换的。”许迟迟喃喃念出门把手上那张纸条上的字，音调低得像是自言自语，“原来那张纸条……是在回应这句话。”

老人看她的神色渐渐凝重，忽然道：“你跟我来。”

他领着她走出门房，穿过堆满花盆的院子，来到最深处一座矮棚前。木门推开后，她看见墙角堆了十几只麻袋，老人俯身解开最底下一只，从里面抽出一个卷成筒状的牛皮纸册。

“那姑娘托我留这个。她说，等你来的那天——梅花开了再给你。”

许迟迟接过那卷纸筒，展开一看，是一张极薄的手绘地图。画的是迟园的地形，花圃，温室，甚至西墙根下那棵槐树的位置，都用毛笔标注得清清楚楚，而在地图背面，用极细的笔迹写着一行字：

“S-7不止一个。根分了几枝，我管不住。”

风吹过矮棚门缝，那页纸抖了抖，白菊的气味又一次浮上来，像从旧时光的缝隙里漏出来的一缕叹息。许迟迟握着地图，忽然有了一种直觉——顾延之的十年前，“不是她以为的那一整段”。

她拨通了顾延之的电话。

电话响了一声，两声。第三声，那头接起来，背景里传来植物研究所暖房的风机声。

“顾延之，”许迟迟声音有一点哑，“那个教你画梅花的叔叔——他是不是叫沈复生？”

电话那头安静了很久。久到许迟迟以为信号断了，才听到顾延之的声音：“……你怎么知道这个名字？”

许迟迟低头看着地图背面那行字，轻声回答：“因为有人告诉我，S-7不止一个。”

那端又在沉默。

一阵风刮过，顾延之的声音终于再次响起，像是从一个很远的地方传来：“那你知道……沈复生的另一个名字，叫作顾伯言吗？”

许迟迟手里的纸筒猛地滑落，砸在地上，滚了一转。

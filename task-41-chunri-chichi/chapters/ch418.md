# 第418章 认根

晨光透过花店的玻璃窗，将一室花影拉成长长的斜线。许迟迟已经在操作台前站了二十分钟，手指反复摩挲着那块红木板，她没有开灯，也没有插花，店里安静得只剩下老式挂钟的嗒嗒声。

"一早就盯着它看，能看出花来吗？"沈知微推门进来，手里拎着两杯热拿铁，目光落在许迟迟掌心的红木板上，"这玩意儿你昨晚看了一宿，今天还看？"

许迟迟抬起头，眼眶微红，不是没睡好，是哭过的痕迹。"我想去一趟迟园。"她说。

"去顾母那里？"沈知微把咖啡放在台上，没有阻止，"你想好了？"

"红木板上的'棠'字，和井底袖口上的'棠'字，笔迹一模一样。"许迟迟声音不大，却很笃定，"我母亲留下的东西，和那个叫'小棠'的女人有联系。迟园的桂花，井里的信，还有这块木板——它们都指同一个地方。"

沈知微沉默了片刻，忽然问："顾延之知道吗？"

许迟迟摇头。"他昨夜回了研究所，说今早有课。"她顿了顿，"我想自己先去。"

"一个人去迟园？"沈知微把咖啡往她手里一塞，"你忘了上次顾母什么态度了？"

"我母亲的东西在这里。"许迟迟把红木板翻过来，对着光，背面那些字在晨光里隐隐发亮，"'愿你如兰，认土生根'。这八个字，我从小看到大，却没想过它是什么意思。现在我知道了——她让我去认根。"

沈知微不再劝，只是从口袋里掏出一把车钥匙放在台面上："我送你到路口，你自己进去。半小时后我打你电话，没接我就冲进去。"

许迟迟眼眶一热，点了点头。

迟园在城西农校旧址后山坳，车程四十分钟。沈知微在岔路口停下车，许迟迟一个人沿土路走进去，秋天早桂正开，空气里浮着幽淡的香。她推开迟园的铁门时，花圃里正有人弯腰剪枝，听到门响直起身——是顾母。

"是你。"

顾母放下剪刀，摘下白线手套，目光落在许迟迟手上那块红木板上，脸色变了。她没有问许迟迟的来意，反而先开口："那块板子，你从哪里得来的？"

"我母亲的遗物。"许迟迟把红木板递过去，"顾伯母，您认识我母亲，对吗？"

顾母没有接，她站在原地，像一棵被风吹僵了的树。许久，她开口，声音沙哑："你母亲……叫什么？"

"许兰。"

顾母闭了闭眼。她转过身，走进花圃最深处那间灰瓦小平房，片刻后拿了一个旧铁盒出来，放在廊下的石桌上。"你应该看看这个。"她打开铁盒，里面是一张泛黄的照片——两个年轻女人并肩站在桂花树下，一个穿着蓝布连衣裙，一个穿着白衬衫。穿白衬衫的那个，眉眼和许迟迟几乎如出一辙。

"你母亲叫许兰，"顾母的声音低下去，"她是我丈夫顾湛的妹妹。兰和湛，同根而不同枝。你不是顾家的儿媳，你是顾家的外甥女。"

许迟迟浑身一震，手里的红木板差点滑落。满园的桂花香在这一刻变得无比浓烈，她终于明白了那句"认根"的真正含义。

"那……"她的声音发抖，"十年前那封信？"

顾母没有回答，只是把铁盒盖上，说了一句让她血液凝住的话："那封信不是拦截的，是你母亲亲手交给我的。"

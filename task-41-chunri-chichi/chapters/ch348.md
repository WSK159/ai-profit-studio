# 第348章 半枚铜钱

许迟迟捏着那半枚铜钱，指腹盖住那行字，仿佛这样就能让那句话消失。但她遮不住。八个字像烙铁一样烧在眼底，连带着手心的玉佩也变得沉甸甸的。

“许家欠苏家，一命还一命。”顾延之把她没念出来的话低声重复了一遍，语气平静得像在读实验室的数据，但瞳孔收缩了一瞬。他利落地把铜钱从她手里取走，放回铁盒，“先别心慌，这东西未必是你爷爷留下的。”

“是我爷爷的结。”许迟迟的喉咙干涩，“这绳结，全城只有我爷爷会打。”

顾母忽然走近，鞋底踏碎了一片枯叶。她从顾延之手中接过铁盒，目光在玉兰花佩上停了一下，又落在那半枚铜钱上，表情难以形容地复杂。她张开嘴，又合上，像是有话堵在喉咙口，怎么都说不顺。

“苏女士。”顾延之的语气带了不易察觉的压迫，“事到如今，您还打算藏着？”

顾母攥着铁盒边沿，指节泛白，几息之后，她才像下了什么决心似地开口：“你爷爷当年不是给我哥打工的。”她看着许迟迟，“他是苏家的养子。”

许迟迟愣住：“什么？”

“孤兒。苏家老太爷在街边捡到的，养在苏家十五年。后来他去许家入赘，改了姓，这才没跟苏家沾光。”顾母的嘴唇动了动，声音低下去，“这件事，你奶奶——苏佩兰——应当提过。”

苏佩兰。许迟迟的母亲许佩兰的母亲，她外婆，确实叫苏佩兰。但她从不知道，外婆的娘家姓苏，和顾母口中的“苏家”是同一支。

“所以苏明远……”许迟迟的声音发飘，“是我外婆的……”

“堂弟。”顾母吐出这俩字时，像是从胸腔深处挤出来的，“你外婆是苏家三房的女儿，我哥是二房的。你爷爷入赘许家之后，跟你外婆生了你妈，跟你妈生了你。血脉上头，许家和苏家绑了好几十年。”

许迟迟脑子里嗡嗡地响。她从小只知道自己姓许，爷爷姓许，奶奶姓许——从未听过“入赘”两个字。

“那‘一命还一命’是什么意思？”顾延之的声音把她从混乱中拉回来。

顾母的嘴唇抿成一条线，良久，才道：“苏明远失踪那年，你爷爷恰好生了一场大病，县城医院躺了三个月。出院之后，他再没进过迟园。”

“他怕苏家来找他？”顾延之问。

“不。”顾母摇头，目光变得幽深，“他怕见到苏明远的东西。因为我哥失踪那晚，他刚好在迟园。”

许迟迟攥紧玉佩，指尖几乎嵌进掌心。她还记得爷爷晚年的一个习惯——每逢农历三月三，他总会在院子的西北角烧一炷线香，谁也不说是给谁上的。她问过一次，爷爷只说了四个字：“还债的。”

烧了不知多少年的香，原来欠的是这一句“一命还一命”。

“那封信呢？”顾延之忽然问，“你当年拦下的那封，是苏明远写给许迟迟的？”他说的“那封信”，许迟迟懂——十年前的告白信，后被顾母截下。可顾母却猛地一个激灵，像被捅到了什么更深的痛处。

“那封信……”顾母的声音抖了一下，“不是苏明远写的。”

许迟迟和顾延之同时停住了呼吸。

“那是你爷爷托苏明远带给我哥的信。”顾母的目光直直落在许迟迟脸上，“你爷爷那年写了封信，让你爷爷托人转交给苏明远。苏明远死后，信到了我手里。上面写的是……你爷爷答应苏明远的一件约定。”

“什么约定？”

顾母没有正面回答。她弯下腰，从铁盒内衬的夹层里，抽出一张叠得极薄的旧纸。纸比那卷信件更旧，边缘已经发黑，折痕处断裂了数道。她展开来递到许迟迟面前，纸面上是一行熟悉的、苍劲有力的字迹——是许迟迟爷爷的笔迹，她认得，她从小看着爷爷写花签认得。

纸上写着：“明远兄，那株花，若你真能等到它开，我这条命，随你取。”

底下另有一行朱笔批注，字迹陌生，笔锋凛冽：“我不要你的命。我要一个真相。”

许迟迟盯着那两行字，视线渐渐模糊。她想起爷爷临终前攥着她的手，嘴唇蠕动了好几次，像有话要说，最终却只说了三个字——“对不起。”

原来那不是病糊涂了的呓语。那声对不起，欠了三个人。

风穿过井口的枯草，发出细长的呜咽声。顾母将铁盒重新盖上，搭扣“咔”地一声锁紧，她抬起头，看向许迟迟的眼神里，终于卸下了那层维持十年的冷硬。

“许迟迟，我拦下那封信，不是怕你和他在一起。”她说，“我怕的是你爷爷写那封信的代价。”

她的目光越过许迟迟的肩头，看向远处缓缓走来的那个身影，顾延之也顺着她的视线转过了身。暮色里，一个拄着手杖的老人正从樟树林的方向走来，每一步都走得很慢，像踩在碎冰上，银白的头发被风撩起，露出一张许迟迟无比熟悉、却又十年未见的苍老面孔。

爷爷。

她以为早已去世的爷爷，正站在迟园的土坡上，隔着三十步的距离，看着她。

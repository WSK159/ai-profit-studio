# 第106章 迟园的门

迟园在城西最偏的巷子尽头，门是铁栅栏的，门楣上爬满了已经枯萎的忍冬藤。他们到的时候太阳刚出来，湿漉漉的晨光把铁栅栏上的锈迹照得发亮。

顾延之按了门铃。等了很久，没人应。他又按了一次，隔了两分钟，花圃里传来脚步踩碎枯叶的声音，接着是顾秀兰的声音，带着晨起的干哑：“谁啊？”

“妈，是我。”

门内安静了。过了大约半分钟，铁栅栏里侧的小门“咔哒”一声开了，顾秀兰站在门缝里，穿着暗红色旧棉衣，头发有些乱，显然是刚从床上起来。她看到顾延之身后的许迟迟，目光顿了一下，随即移开。

“进来吧。”她没有让开门口，反而先转身往里走。

迟园比许迟迟想象中大得多。温室是后搭的，玻璃上结了层水珠，里面种着成排的兰，但有几排明显是新换的土——原本种着什么，被挖掉了。

顾秀兰走到温室最里面的一张长椅前，坐下，从口袋里摸出一包烟，又放了回去。

“你爸的信，你看了。”她说得很平，没有问句。

“看了。”顾延之站在她面前，身后是许迟迟，“但没看完。”

顾秀兰终于抬起头，眼神里有一瞬间的波动，像石子砸进水潭，但很快平静下去：“没看完，那就别看了。”

“妈，那批病种苗是你换的。”顾延之的嗓音平得像陈述，“你为了让我不查那件事。”

顾秀兰没说话。温室里有一排排的兰，风从缝隙灌进来，叶子互相碰着，发出细碎的声响。过了很久，她开口，声音第一次有了裂纹：“那年春天，你爸在南方查出种苗带病，他回来质问我的时候，我已经把那株‘不变花’换掉了。我告诉他，你培育的那个品种根本不值得花圃继续养。”

“他没信。”顾秀兰顿了顿，“但他也没有再查下去。他后来不碰那批种了，把那件事带进了棺材里。”

许迟迟站在温室门口，脚下是潮湿的泥土。她忽然想起一件事——那天夜里，花店门口被人放了一束白花。她一直以为是警告。可现在，她看着顾秀兰的背影，脊背微微弯着，像一根随时会断的枯枝。

“白花是你放的。”她开口。

顾秀兰没有否认。她转过脸来，眼底没有泪，却满是疲惫：“许小姐，我放那束白花，是想让你知道我还在看着。不是恨你，也不是恨延之。我是不想让他再往前走一步。”

“怕他发现真相？”许迟迟轻声问。

顾秀兰摇头：“怕他知道他爸当年为什么要去南方查种苗。”

她站起来，走到温室最深处的角落，拉开一个蒙尘塑料布的柜子，从里面拿出一只老旧的保温杯。杯盖拧开，里面没有水，塞着一张对折的纸条。

“这是他走的前一天，放在我枕头底下的。”顾秀兰把纸条递过来，“我没打开看过。他走后第三天，我把它锁进了这里，锁了十年。”

顾延之接过纸条，展开。纸已经泛黄，字迹是顾父的，只有一行：

“秀兰，如果你看到这张字条，替我去一趟‘迟迟花开’，告诉许家那个姑娘，我欠她爸爸一个真相。如果我不在了，让延之来还。”

温室里的空气像被抽空了。许迟迟听见自己心跳的声音，像远处有人敲着一面很沉鼓。

顾秀兰说：“许迟迟，你父亲——十年前那场花艺大赛——不是意外。”

“那是什么？”许迟迟轻声问。

顾秀兰没说话。外面忽然一阵风，把温室的门吹开了。门外，老街上远远传来自行车的铃声。顾延之的手轻轻握住许迟迟的指尖，掌心是温的。

而角落里那盆“迟迟”，在这阵风里，花苞又裂开了一丝——淡青色的花瓣边缘，露出一点极浅极浅的白色。

那个清晨，迟园的门开了，而许迟迟父亲十年前的死因，终于像那朵花一样，从泥土下裂出了一道缝。

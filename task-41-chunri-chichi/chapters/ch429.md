# 第429章 海棠门框上的刻花

城西农校的老招待所第三排平房，墙面刷着剥落的米黄色漆，门牌号大半被雨水泡得看不清。东头第二间的门框上，果然刻着一朵海棠花，花瓣边缘用刀尖勾得很深，像是刻了不止一次——旧痕之上叠着新痕，最深的一道几乎穿透了木框的漆面。

门没锁。老式挂锁只是虚挂在扣环上，锁芯处塞着一小截干枯的白桔梗茎，像是专门留给我们认门的标识。

顾延之推开门，吱呀一声，破旧的门轴声在空荡荡的走廊里回响。屋子不大，一张铁架床，一张书桌，一只搪瓷脸盆架，墙角摆着一只旧木箱，箱盖上搭着一块蓝布。处处收拾得干净，却没有半点活人的气息，像是有人刚刚离开，又像是已经等了很久。

书桌上放着一盏煤油灯，玻璃罩擦得很亮，灯芯剪得齐整。我按照顾母的话，划了火柴点上，灯光昏黄，将我和顾延之的影子投在墙壁上，交错成一个拥抱的形状。

窗台上搁着一只缺了口的粗陶瓶，瓶里插着一束白桔梗，已经干了，花瓣卷曲，却依然保持着未曾凋谢时的姿态。我摘了三枝，放在窗口的新位置，然后把旧的那束收下来，忽然发现花茎底部缠着一圈透明胶带，胶带里裹着一张小纸条。

纸条上是一行字，钢笔写的，字迹工整：“钱不是买花，是买命。我替你付了三次，第四次，你自己来。”

我攥着纸条，指尖发凉。顾延之站在窗边，目光越过我的肩，落在那行字上：“三次——送白花的钱，埋在迟园门口的钱，和寄给花店的那笔转账。”

“沈静秋替我还的。”我说。

“不。”他摇头，“不是替你还。是替你认了那笔债。”

门外走廊忽然传来脚步声，不重，但很稳。门被推开一条缝，一个人探进半个身子——四十岁上下的女人，短发，戴着粗框眼镜，穿着一件洗得发白的灰蓝外套，袖口挽到小臂，露出一截皮肤上隐约的旧疤。

“你们来了。”她嗓音有些哑，目光落在我手里的纸条上，顿了一下，“那纸条，是我父亲留的。”

程远的女儿，程小禾。

她从口袋里摸出一块黄铜色的小牌——城西农校的徽章，背面刻着一个“程”字。她说：“我爸临终前让我把这个交给你。他说，你看见这块牌子，就知道那封油纸账本上记的三亩地，不是要你抵命，是要你去找一个人。”

“谁？”

“蒋衍的账房先生，还活着，在城东的一家养老院里。他手里有当初蒋衍逼你外公签的那份转让书原件——那上面的字，不是仿的，是真迹。但转让书底下还有一页，是蒋衍自己补的，写着一行字：‘若顾家后人不回迁，这地就是公产。若回迁，按原价赎回。’”程小禾把铜牌放进我手里，“我爸说，那行字，是你外公和蒋衍一起写的。你外公没死，他逃出去了。他一直在等你们回迁。”

我手里的铜牌边缘硌着掌心，顾延之的手稳稳地落在我的肩上：“他去了哪里？”

程小禾说：“你外婆留下的那张纸条上，最后一页不是写的‘那盆花早就开了’吗？那花，就在他手里。我父亲找人查了八年，才查到他晚年隐姓埋名，在南方一座小城的花圃里，替人养了二十年花。”

她顿了顿：“那座城，叫桐城。你外公花圃的门口，挂着一块牌子，上面写的名字是——‘迟迟花圃’。”

我身后那盏煤油灯的灯焰晃了一下，火苗蹿起，在墙上投下一个忽然放大的影子。

门外，走廊尽头传来一阵细碎的脚步声，又停下了。我攥着那枚铜牌转过身，看见一道细长的人影站在月光里，手里提着一束白桔梗。

她往前走了一步，月光把她的脸照得清清楚楚——沈静秋，她果然在那里。

“迟迟，”她的声音轻得像怕惊碎什么，“第四次的钱，我付不出去了。这一次，要你自己来付。”

她把手里的白桔梗递过来，花茎上系着一根红绳，绳上坠着半个玉佩，是一只海棠花的形状。

“这块玉，是你外婆的。另一半，在你外公手里。”

夜风从窗缝灌进来，那束白桔梗的花瓣在风里轻轻颤动，像是替某个人，说了一句迟到了十年的话。

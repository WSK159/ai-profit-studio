# 第336章 金边瑞香

许迟迟弯腰捡起那张明信片时，指尖触到纸面的刹那，一阵凉意从脊背窜上来。金边瑞香的叶片边缘泛着暗金色的光泽，花枝的剪裁整齐利落，像是从某处花圃精挑细选出来的。她翻过背面，“别查了”三个字用的是黑色签字笔，笔锋干脆，带着一种不容商榷的笃定。

顾延之站在她身侧，目光从明信片上掠过。他没有伸手接，只是偏过头，去看那盆“迟迟”花苞裂口的位置。裂口比早晨又扩大了一些，嫩绿的萼片微微向外翻卷，露出内里一层蛋壳色的花瓣边缘，像是有什么东西正急于挣脱束缚。他盯着那道裂口看了很久，久到许迟迟忍不住轻声喊他。

“延之？”

他回过神，抬手轻轻触碰花苞表面，指腹蹭到萼片边缘一道干涸的痕迹，像是汁液凝固后的印子。他忽然问：“你认得金边瑞香的花语吗？”

许迟迟愣了一下，“金边瑞香……吉利如意，祥瑞之气。”

顾延之摇头：“还有一层，很少有人提。瑞香在古籍里叫‘睡香’，传说有人睡在花下，梦中闻到异香，醒来后花便开了。所以它也有‘梦醒’的意思。”

梦醒。许迟迟攥着明信片，心里像被什么东西轻轻敲了一下。她想起自己在大学里第一次见到顾延之，是在花艺社的旧教室里，他靠窗坐着，手里捧着一本《植物分类学》，阳光洒在他侧脸上，她以为自己做了一个很长很长的梦。而现在，这个梦正在以某种她无法控制的方式，加速醒来。

明信片是夹在花盆底下的，花盆又摆在门口的石阶上。这意味着有人在他们离开之后，来过花店门口，甚至可能进了院子。许迟迟蹲下来检查花盆周围的地面，泥土上没有多余的脚印，石阶边缘干干净净，连一片落叶都没有。太干净了，干净得反常。

“送明信片的人，清理过痕迹。”顾延之像是早有预料，语气平淡，“和上次‘S-7不止一个’的短信一样，手法利落，不留下指纹。”

许迟迟抬眼看他：“你知道是谁？”

他没有正面回答，只是从外套内侧口袋里取出一只透明密封袋，将明信片小心地放进去，拉上拉链。“先收好。晚点让实验室的同事帮忙分析油墨批次。”

许迟迟站起身来，拍拍膝盖上的灰，目光越过他的肩膀望向街对面的巷口。一只灰猫蹲在墙头，尾巴慢悠悠地摆动，见她在看，纵身跳下墙消失了。她总觉得那猫出现得太巧，但也没多想。

回到店内，沈知微已经在吧台后端出两杯热拿铁，见他们进来，挑了挑眉：“门口捡到什么宝贝了？”

“一张明信片。”许迟迟简短地说了句，没有展开。沈知微也没追问，她做了这么多年闺蜜，最清楚许迟迟什么时候愿意说，什么时候不愿意。

晚饭后，顾延之开车载许迟迟去了植物研究所的档案室。灯光明亮，金属柜整齐排列，空气里有干燥的纸墨气味和植物标本特有的清香。他取出一份用牛皮纸封套包着的老档案，封套上印着“临江花业·特聘顾问卷宗”的字样，编号尾部已经被撕掉，只剩一个模糊的码印。

“这是我下午调出来的。”他翻开卷宗内页，许迟迟看到一张泛黄的黑白照片，照片上的男人约莫三十出头，戴着圆框眼镜，穿一件洗得发白的灰色长衫，站在一片花圃前，嘴唇微微抿着，目光平静地望向镜头。照片下方用钢笔写着三行小字：“苏明远，临江花业特聘顾问，民国卅七年起。专研：球根类花期调控。”

许迟迟的目光停在那行“花期调控”上，心头一跳。她又往下看，卷宗内附着一份手写的技术笔记，字迹工整方正，是苏明远的笔迹。笔记中有一段提到“迟花机制”——一种利用低温层积与光照周期控制延迟花期的方法，若配合适当的嫁接砧木与营养配比，理论上可将花期延后至常年的三倍时长。

“等等。”许迟迟伸手指着一行被铅笔划掉的小字，“你看这里。”

顾延之凑近，顺着她指尖看去，那行小字写着：“然此法需以特殊品种为基，该品种原产江南，花性极迟，余于庚辰年春，偶得于迟园旧址。”庚辰年，民国二十九年。迟园旧址。

两人对视一眼。也就是说，苏明远所谓的“迟花机制”，很有可能就是后来“那盆不会开的花”——也就是“迟迟”这一品种——最早的技术渊源。他来过迟园，甚至可能在这里得到过原始的种苗或嫁接材料。

许迟迟忽然想起那页被撕掉的档案记录，他们之前在迟园石屋铁箱里看到过苏明远的证件，但关于他在临江花业的工作内容，档案被人故意撕去了一页。撕页的位置恰好就在“迟花机制”这一段的后面。

“如果撕掉的那页，正好写着这个品种的来源记录……”她轻声说，“那撕页的人，可能就是为了掩盖这个来源。”

顾延之修长的手指轻轻敲着桌面，像是在思考。他放下卷宗，转身从侧面抽屉里取出另一份文件，是他之前调到的苏明远个人履历副本。履历末尾有一行批注，用红色墨水写着，字迹娟秀，与顾家老太太苏佩兰后来的笔迹极为相近：“苏明远，支脉族兄，性孤僻，善园艺，后失联，疑似远走海外。”

顾延之的目光落在“疑似远走海外”五个字上，沉默了一会儿，才说：“如果苏沉是苏明远的后代，那他回来查临江花业，也许就和他的失踪有关。”

窗外夜风摇动树影，远处传来一声犬吠。许迟迟低头，注意到卷宗夹层里露出一角深绿色的东西，她小心抽出来，是一片干燥的叶脉标本，形状狭长如柳叶，边缘带着细密的锯齿，被压在蜡纸之间。她翻到背面，看到一行用铅笔写的极小的字，笔迹与苏明远的相同：“铁线莲汁染纸，可护色百年而不褪。”

铁线莲。许迟迟脑子里的弦猛然绷紧。札记第三卷里那个铁线莲花汁的印记，苏明远留下的那句“花开有时，人无期”——铁线莲的花语是高洁与欺骗，花汁印记的含义，难道与某封信有关？

她抬头望向顾延之，声音有些发涩：“延之，如果那封信……”她欲言又止，把叶脉标本轻轻放回原处。那份标本压在卷宗夹层里，也许就是苏明远故意留给他们的一条线索。

他望着她，没有立刻接话，目光里有一种很深的、平静的等待。

许迟迟把话咽回去，只是说：“我们回去吧。明天我想再去一趟迟园。”

顾延之点头。

车子开出研究所时，她靠在副驾驶座上，望着窗外流动的街灯，莫名想起那盆“迟迟”花苞裂口边缘干涸的汁痕——那痕迹的颜色，暗褐中透着一丝铁锈红，和铁线莲花汁干燥后的颜色几乎一模一样。

她闭上眼，胸口那根线越拉越紧。

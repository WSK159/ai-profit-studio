# 第36章 十年前的信

那封信只有薄薄一张纸，照片拍得不算清晰，但每一个字许迟迟都认得出来。顾延之的笔迹她太熟悉了，大学时他给她写过不少小纸条，夹在花艺社的活动记录本里，每一张她都收在旧盒子中。

她盯着照片上的落款日期，心底浮起一个模糊的数字——那正是他消失前的第三天。

信的内容被折去了大半，照片只拍到左上角，能看到几个词：“……这盆花，等我回来的时候……”

“迟迟？”顾延之的声音从身后传来。

许迟迟条件反射般将照片塞回信封，攥在手心，转过身时脸上已经挂上笑：“快递送错了，隔壁咖啡店的。”她侧身对沈知微喊了一句，“知微，你定的干花到了。”

沈知微读懂她的眼色，接过话头：“哦，对，我订的，放吧台上就行。”

一切自然得像是真的。顾延之没有再追问，只是看了她一眼，眼底有一瞬间深得望不到底，又恢复了平常的温度。他低头看了一眼手表：“晚上有个组会，我先过去。过两天来接你去看一场花展，城南植物园的春兰展。”

“好。”

他走到门口，忽然转过头来：“迟迟。”

“嗯？”

“那封信，如果你想看，可以直接问我要。”他说这一句的时候语气很轻，像在商量一件无关紧要的事。

许迟迟攥紧手中的信封，心跳如雷。

她没有说话。顾延之也没有等她回答，低头推开了门，风铃在身后发出清脆的响声。

花店里安静下来。沈知微从吧台后探出头，压着嗓子问：“什么情况？你手里拿的是什么？”

许迟迟这才重新抽出照片，将那张纸摊平在台面上。两人凑在一起看了半天。照片只拍到了信的左上部分，字迹能认出来是顾延之的，但关键内容都被折住了，只露出了花盆的描线和一行字。那行字写着：“如果它也能开花，那这世上就没有什么不可能的。”

旁边画着一朵花的速写——五瓣，细蕊，花瓣边缘微微卷曲。许迟迟的目光定在那朵花上，指尖微微发抖。

“这不就是——”她话没说完，沈知微接上去：“这不就是你店里那盆‘迟迟’的花形吗？你在花艺展上展示过的那支作品草稿。”

许迟迟摇头，再摇头：“不对。这盆‘迟迟’是延之培育出来的新品种，花艺展是上个月的事，他不可能在十年前就画出它的花形。”

沈知微一顿。两人对视一眼，都从彼此的眼中读到了同一个让人心跳加速的念头：那盆“迟迟”，也许根本不是顾延之这十年才培育出来的东西。它可能早就存在了，早在十年前，在两个人分道扬镳之前，就已经有了雏形。

“你注意没有？”沈知微用指尖点了点照片角落，“这行小字，是信的开头之前写的——‘致迟迟’。这封信，是写给你的。”

许迟迟的眼眶一下就热了。

“所以——”她听到自己的声音有些沙哑，“他给我写了一封信，十年前就写了。可我从没见过这封信。它去哪了？”

沈知微耸了耸肩，答案几乎是呼之欲出，但两个人谁都没有把它说破。十年前，顾延之留下一封信不告而别，而她从未收到，只等来一个冷漠的告别电话。中间能拦截这封信的人，几乎只有一个。

迟园。顾母。

许迟迟低下头，看着信封上除了照片以外再无他物。没有寄件人，没有地址，打印的收件人名字是她的。她翻到信封背面，一个模糊的红色印记留在封口处——一枚被压扁的铁线莲干花，轻轻一碰，花瓣碎成粉末。

她的手停住了，指尖捻起一点碎屑。铁线莲。又是铁线莲。

那天在迟园，顾母出示的扁瓶里装着的，也是铁线莲的干花。而花语，是高洁与欺骗。

她将照片和信封装好，起身走到柜台里，开始收拾今天的花材。指尖被玫瑰花刺扎了一下，渗出一点细细的血珠，她也没停下。沈知微看着她故作镇定的背影，摇了摇头，正想说什么，目光却忽然落在了花店门口的地上。

一张白色信封，不知什么时候被人从门缝底下塞了进来。沈知微走过去弯腰捡起。信封上没有字，没有邮戳，里面只有一张照片。照片拍的是迟园的花圃入口，铁门半开，凌晨的光线昏暗，一个人影背对着镜头站着——灰色外套，身形清瘦，正弯腰将一束白色的花放在门边。花束里扎着一条深蓝色的布带，上面绣着一朵小小的铁线莲。

沈知微捏着照片，抬头看向许迟迟。

“迟迟，我有种不太好的预感。”

窗外。黄昏的光洒在老街的青石板上，花店门前的风铃响了又静。许迟迟的视线从白玫瑰的叶片间抬起，落在门口那张被沈知微捏在手里的照片上，心口一跳。她知道，那张照片上的人，一定不是顾延之。

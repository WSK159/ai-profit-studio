# 第379章 门缝

黑暗里只有两个人的呼吸声。

地窖的铁门合上后，那扇门与门框之间严丝合缝得不像一扇旧门。许迟迟伸手去推，纹丝不动，仿佛刚才那声沉闷的“咔嗒”锁死的不只是门，还有他们与外面世界的一切联系。

顾延之的手先一步按在她手腕上。

“别急。”

他的声音落在暗处，沉稳得像一株扎根在泥土里的老树。许迟迟停住动作，指尖还贴着铁门冰冷的表面，能感觉到门面上一条细细的裂纹，像条干涸的河床。

“手机还有电吗？”他问。

“有，但没信号。”许迟迟已经摸出手机，屏幕亮起的一瞬，光打在他脸上，照出他下颌线紧绷的弧度，以及那双眼睛——冷静、迅速扫视四周，没有一丝慌乱。

“先看清我们有什么。”他站起身，手机电筒的光束在头顶扫过，地窖大约十来个平方，青砖墙面上有水渍，墙角有一张木板床，床边那张草席已经泛黄发脆。最醒目的是白墙上那行字，依旧刺目：

“那盆花，在温室里。”

许迟迟站在字前，光线把笔画的力度照得清清楚楚。

“我爷爷写这行字的时候，他是不是也进过这里？”她顿了顿，“那他有没有出得去？”

顾延之没有回答，但他转身朝铁门走去，蹲下来，指尖沿着门缝慢慢摸过去。动作极轻，像是在听什么。

许迟迟屏住呼吸，她听到他的指腹摩擦着铁门边缘，那种细碎的声音在封闭的空间里被放大了。好几秒后，他停下来，手指停在门轴那一侧。

“门是被人从外面锁上的。”

许迟迟心里一沉。她下意识回头看了一眼床底，那半截信封还露在那里，黄旧得几乎要融进阴影里。她刚才就差一点，差一点就把它拿出来了。

“刚才有人在外面。”顾延之的声音很轻。

“有人？！”

“门合上之前的那一秒，我听到脚步声从墙后面过去了。”他直起身，手电光落在那扇门上方的门楣处，那里有一条不到一指宽的门缝，“有人不想我们看到那个信封。”

许迟迟盯着他看了两秒，忽然走过去，蹲在那张木板床前，伸手把那半截信封抽了出来。她以为会费点力气，但信封像是被谁特意放在那里似的，几乎不卡不绊地落进她手里。

纸张的触感粗糙干硬，边缘已经霉成深灰色。

她翻过信封——正面什么都没有，没有收件人，没有地址，没有邮票，只有信封的封口处，有一道完好的蜡痕，像是被人小心翼翼地粘合过又拆开过一次一样。

她正要掀开信封的封舌，顾延之忽然按住她的手。

“等一下。”

他拿过她手里的信封，放在鼻尖前轻轻嗅了一下，然后抬起头，目光落在墙角那只空花盆上。

“有极淡的甲醇味。”他说，“这种味道不会从纸上自然散出来。这封信被人用药水处理过。”

许迟迟怔住：“什么意思？”

“意思是——有人希望我们看到里面的内容，但又不希望内容能被完整看清。”

他低头，就着手机电筒的光，小心翼翼地挑开封舌。

里面只有半张纸，不是信纸，像是从某本本子上撕下来的，纸质泛黄，边缘有焚烧过的焦痕。纸上只有三行字，字迹端正但用力，笔画有些地方划破了纸面：

“四月十九，水过膝，花移温室。”
“我欠她的，得还。”
“白露生，你可别学我。”

许迟迟的呼吸停了一瞬。最后那句“白露生”，像一条从水里浮出来的线头，直接把她脑子里那些纷乱的线索串在了一起。

“白露生……你妈妈的舅舅。”她看着纸上那个名字，“他认识我爷爷？”

顾延之没有立刻回答。他的目光停在“四月十九”那个日期上，手指不自觉地收紧了。过了很久，他开口说：“四月十九，是我爸失踪那天。”

地窖里安静得能听见水珠从墙缝滴落的声音。

许迟迟抬头看他，灯光里他的侧脸比刚才更紧绷了。她心里涌上一股说不清的寒意——那个旧水井、那扇被人从外面锁上的铁门、墙上指向温室的神秘嘱托、信封里那行被水渍洇开的名字，像是拼图里散落的碎片，正一块接一块地往某个清晰的方向滑落。

她忽然想起什么：“等等——你说你闻到的甲醇味，那信封的处理手法，和你刚才说的‘有人用了药水’……”她声音压低了，“是不是和顾伯言日记里被人撕掉的那一页，用的是同一种？”

顾延之没有直接回答，但他看着她的眼神里，有了一丝细微的波动。

他正要说话，铁门忽然发出“叩——叩——叩”三声闷响。

从外面。

像是有人在敲。

许迟迟浑身一僵。顾延之伸手将她护到身后，手指静静地搭在铁门内侧的把手上，却纹丝不动，一个字也没问，一个字也没说。地窖里的空气凝成了实心的，像是有东西正隔着那层铁皮，等着他们有所动静。

门外传来一个极轻的声音，像隔着厚布——低得几乎辨认不出：

“里面的人，别出声。”

“把灯关了。”

“我来开锁。”

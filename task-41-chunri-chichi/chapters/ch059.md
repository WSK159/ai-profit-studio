# 第59章 病床前的名字

夜色像浓稠的墨汁，浇在滇南蜿蜒的山路上。

许迟迟的额头抵着车窗玻璃，凉意从眉心渗进来，却压不住胸腔里那团灼烧不安的火焰。顾延之把车速压得很稳，但副驾驶座上的她一眼就看得出来，他握方向盘的手指骨节泛白——他也在紧张，只是不说。

“她叫什么名字？”许迟迟忽然开口，声音哑得像锈了的刀片。

顾延之沉默了几秒：“许姨没提。”

“那你问了吗？”

“问了。”他打了半圈方向，绕过一道急弯，“许姨只说……你见了就知道。”

许迟迟没再说话，指尖无意识地卷着衣角，那是一件出门前随手抓的薄外套，洗到起球，领口有淡淡的花香——是花店里那些桔梗的气味。她忽然觉得荒谬：她要去见一个从没见过面的女人，那个女人给了她生命，却缺席了她二十八年的人生，如今躺在医院里，靠着呼吸机续命。

凌晨四点的县医院，走廊里弥漫着消毒水和隔夜饭混合的沉闷气味。值班护士看了顾延之递过去的纸条，目光落在许迟迟脸上，顿了顿：“三床，走廊尽头。”

病房门虚掩着。许迟迟站在门前，那扇门薄得好像一推就散，却重得像整整二十八年的光阴垒成的墙。顾延之站在她身侧，没有催她，只是把手轻轻覆上她冰凉的手背。

“我在外面等你。”

她推开门。

病房里只亮着一盏床头灯，光线昏黄而单薄。病床上躺着一个身形瘦小的女人，头发全白了，稀稀落落地散在枕上，面颊深凹，泛着一层不健康的灰。她的右臂上插着留置针，输液管里的液体正一滴一滴地落，慢得像这个人的生命。

许迟迟走近，床头挂着的病历卡上写着名字：苏婉。

她愣住。这个名字，她见过。

十年前，在花艺社的档案室里，她曾经翻到一张泛黄的旧照片——一群年轻人在滇南的花田里站成一排，照片背面用圆珠笔写着一串名字。最右角那个扎马尾辫的姑娘，背面写的正是“苏婉”。当时她觉得这个名字眼熟，却想不起来在哪里见过。如今她终于明白——那张照片，是母亲留下的。而母亲年轻时，与这个名叫苏婉的女人，是同一支花艺队的队员。

“你……是迟迟？”

病床上的人不知何时睁开了眼。那双眼睛浑浊，却带着一种让人无法忽视的光。她张了张嘴，声音微不可闻：“你长得……真像你爸。”

许迟迟的眼泪毫无预兆地砸了下来。

她张了张口，想问很多话：你为什么把我托给别人？你为什么一走就是二十八年？你知不知道我这些年的日子是怎么过的？可那些话堵在喉咙里，像一把生锈的锁，一把钥匙都对不上。

苏婉却像是读懂了她的沉默，手指微微动了动，仿佛想抬起手来触碰她，最终却只是无力地落在床单上，露出腕上一只银镯子——镯子内侧，刻着两个字：迟迟。

“你爸……走了以后，我不知道怎么面对你。”苏婉的声音断断续续，每说一个字都像在消耗最后的力气，“我把你给了你养母……想着你跟着她，能过上好日子……别像我这个做娘的，一辈子困在花田里……出不去……”

许迟迟握住她的手，那手瘦得像一把枯柴，凉得不像话。她用力攥着，想把自己的体温渡过去。

“妈。”

她叫出这个字的时候，连自己都愣了一下。苏婉浑浊的眼里猛然涌出泪来，嘴角却浮起一个虚弱至极的笑。

“好……好……”她喘了喘气，“你过来……我床头柜里……有一个东西……本来是留给你的……但你养母说你不肯来……我怕来不及……”

她指了指床头柜的最下层。许迟迟蹲下来，拉开抽屉，里面叠着一件用报纸包得整整齐齐的东西——一层、两层，报纸的时间是十年前，渝城晚报。展开到最后，是一封信。信封已经泛黄，没有邮戳，右下角只写着一个名字：顾延之。

许迟迟的手抖了一下。

她抬头看苏婉，苏婉却已经阖上眼，呼吸微弱而平稳，像是终于把心头那块最重的石头卸了下来。许迟迟没有拆开那封信，她把信封紧紧攥在掌心，推门出去。走廊尽头，顾延之倚着墙站着，见她出来，两步迎上前。

“你妈怎么样？”

许迟迟没答话，只把那封信递到他面前。

他低下头，看清信封上的字，神色骤然一变。

“这封信……”他的声音低下去，“我从来没写过。”

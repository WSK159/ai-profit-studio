# 第324章 那块土的味道

车在迟园东北角的围墙外停下时，天已经暗了大半。

许迟迟握着那把黄铜钥匙，掌心沁出一层薄汗。她抬眼望向那段围墙——比别处低矮些，墙根爬满了爬山虎，密匝匝的叶片在暮色里泛着深绿的光。若不是手里那张手绘地图上用墨点标出来，她根本不会注意到这块地有任何特别。

顾延之熄了火，没有急着下车。他侧过头，目光落在她手中的钥匙上，那枚雕着五瓣梅花的玉坠随着她的动作轻晃。"我妈说过，东北角那块地，土不干净。"他的声音在车内狭小的空间里显得格外沉，"她说那里种什么都活不长。"

许迟迟想起铁线莲盆里那张纸条——"土已经还了。花根留下，给你。"她咬了咬唇："你祖父的实验室，在你出生前就没有了，对吗？"

顾延之没有说话，算是默认。

两人下了车，绕过低矮的围栏，沿着围墙根走了一段。石阶上覆着青苔，脚踩上去微微发滑。傍晚的风从南面吹来，带着迟园特有的草木气息——泥土、水汽、还有若隐若现的肥料味。许迟迟忽然停下来，蹲下身，五指贴住了地面。

顾延之不明所以："怎么？"

"这土……是温的。"许迟迟抬起头，眉心微蹙，声音不自觉地低了下去。她从小摸土识花，对土的温度、湿度、质地再熟悉不过。已是入秋，傍晚的地面应当凉透了，可这片土的表面却透着一股细弱却持续的温意，像隔着一层薄土，底下有什么在微微发热。

顾延之蹲下来，学她的样子将手贴在地面上。片刻后，他瞳孔微微一缩，没有说话，而是从口袋里取出一把折叠刀，轻轻将表面那层薄土拨开。借着最后的光线，两人看见土面下约三指深处露出灰白色的细沙层——颜色均匀，颗粒细密，中间夹杂着几丝暗红色的絮状物。

"这不是迟园的土。"顾延之的声音低哑，他拿起一撮灰白沙土在指间捻了捻，"这是实验站的特制基质。"

许迟迟心里一跳。灰衣人说，许秀禾当年从迟园带走的是顾延之祖父实验站的关键土壤——如今这土又出现在了这里。"还了"两个字在她脑海中翻来覆去，像一根刺扎进柔软的肉里。她母亲说的还了，原来是这么个还法——亲手把土埋回原处，所以顾母那句话才变成了"土不干净"。

"你妈说这里种什么都活不长。"许迟迟慢慢站起来，低头看着那片被拨开的土面，"是因为这层灰白沙土不适合迟园本地的酸碱度，底下有暗红絮状物……那是金根藤的根须碎末吗？"

顾延之沉默了一会儿，道："我不知道。我从来没听说过金根藤和实验站有关联。"他抬头看向围墙内侧，那是一片空荡荡的荒草地，长着几丛半枯的狗尾巴草和野菊。风过处，草叶沙沙作响，像有人隔着很远说话。

许迟迟握着那把黄铜钥匙，指腹摩挲着玉坠上的梅花纹路。她忽然想起母亲从前说过的一句话——那是很久以前，她还在上小学，蹲在花店里摆弄一盆烂了根的兰花，母亲从橱窗后头探出头来，声音带着午后阳光的暖意："种子不爱说话，根才说实话。"

那时候她不懂，只觉得母亲说话总是这样莫名其妙。

现在她忽然明白了。许秀禾留下花根，是因为种子可能撒谎，根不会。金根藤的根须碎末埋在土里，这就是那句"土已经还了"最直白的证明。可这土底下的热量从何而来？那几份间隔七年的检测报告又记录了什么？

远处传来一声狗吠，许迟迟握着钥匙的手微微收紧。她抬头望向围墙尽头那道锈迹斑斑的铁门——门没有上锁，只是用一根铁丝松松地挽着。她看了顾延之一眼，后者上前，伸手将铁丝绕开，铁门发出沉闷的吱呀声，被推开一条缝。

门后是一条青石板小径，两侧是矮灌木，枝杈修剪得整齐。顺着小径隐约可以看见一座矮小的石砌小屋，屋门上挂着一把黄铜老锁——那锁的形制，和她手里这把钥匙几乎一模一样。

顾延之站在门边没有动，许迟迟走进去两步，又停下来。青石板缝里窜出一丛细茎叶的白花，她蹲下去看，认出了那花——是铁线莲的变种，花萼五瓣，白瓣带点淡紫，和灰衣人交给她的那盆几乎一模一样。只是这丛明显更小，开在墙角的阴影里，几乎要被人忽略。

许迟迟伸手拨开叶片，在花根部裸露的泥土里看见了一样东西——一枚锈迹斑斑的黄铜圆片，拇指大小，上面刻着一个编号。她将圆片翻过来，背面刻着三个字母：SSY。

她倒吸了一口气，猛地攥紧了那个圆片。金属片上还留着一丝余温——和那片温热的地面一样，像被谁的手心刚刚握过。

门房里那盏孤灯不知何时亮了起来，昏黄的光从窗口溢出来，正好照亮了那扇挂着黄铜老锁的门。

许迟迟回头看向顾延之。他的目光定在那扇门上，面色沉静，但喉结微微动了一下。"钥匙是许秀禾的。"他缓缓说道，"可是锁，是我爷爷亲手挂上去的。"

风从东北角灌进来，那丛铁线莲的白花在风里轻轻摇晃。

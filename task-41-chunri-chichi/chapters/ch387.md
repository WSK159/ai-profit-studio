# 第387章 门后的小姨

雨已经停了，老宅西墙外滴着水，檐角那些碎瓦缝里长出的青苔被泡得发亮。

许迟迟坐在堂屋的藤椅上，膝盖上摊着那张旧照片。她刚才已经翻来覆去看了几十遍，三张面孔在昏黄的灯下几乎要被她记进骨头里，可沈静秋说的那句话还在她脑子里转：“十年前那封信的底稿，三个人一起写的，最终交给门后的小姨。”

她抬起头，看向堂屋西侧那扇木门。门板旧了，上面糊着一层褪色的蓝布帘子，帘角缀着一只绣了一半的蝴蝶——针脚粗糙，像是小孩学绣时留下的。

“这就是你说的那扇门？”许迟迟问。

沈静秋站在门边，点点头，随后弯下腰，手指从门框下沿摸过去。那里有一道细细的槽，像是有人反复开关这门、时间久了磨出来的。她没去推门，而是敲了三下门板。

笃、笃、笃。

三下过后，她退后半步，像在等什么。

屋里安静了几息。

然后，门后传来一声很轻的咳嗽。

许迟迟背脊一僵。顾延之从她身边站起来，几步走到门口，手按在门闩上，却未动，只侧过头，看向沈静秋。

沈静秋的目光从那道门缝上收回来，声音低了些：“她在门后待了一整夜了。”

“谁？”许迟迟问，声音有点发干。

“你小姨，许婉玉。”

门闩被顾延之拉开。

许迟迟几乎是跳起来，冲过去，站在门口。门后是西厢的暗间，常年锁着，堆着旧家具和烂棉絮，她小时候最怕往里探头。这会儿屋里没开灯，只有一扇半开的窗透进些白光，照出一个人影，蜷在一张老旧的矮凳上，怀里抱着一只木匣。

那人瘦极了。头发半白，拢在脑后，穿着一件洗得发白的蓝布外套。她抬起头，脸上皱纹深得像刀刻的，但那双眼睛却亮得异常，一下就锁住了许迟迟的脸。

她张了张嘴，没出声，眼圈先红了。

许迟迟的喉头像被什么堵住，她蹲下来，和那人对视。她幼年时见过自己这位小姨，那时候许婉玉不过二十出头，爱笑，会编柳条篮子，总在春天带她去田埂上折紫云英，插在她头发上。

她头发上插着一朵花。这会儿也是，一朵蔫了的白色桔梗，花瓣打着卷。

“迟迟……”许婉玉哑声开口。她伸手想摸许迟迟的脸，手在半空又收回去了。她垂下眼，声音小得像自言自语，“你长这么大了，跟你妈真像。”

许迟迟抿着唇，侧过头去看沈静秋，又去看顾延之。她脑子转得飞快，那些断掉的线头正被一根一根往一起拼：许母背的锅、信被人截走、花圃转让协议上的假签名、南边商人——全在这个女人身上汇拢。

“信，是你拿走的？”许迟迟问。

许婉玉的睫毛颤了一下，点头。

“那封告白信，顾延之写给我的那封——你拿走了？”

许婉玉又点头，眼泪滚下来。

“为什么？”

许婉玉没回答。她低头怀里那只木匣子，手指摩挲着上面的铜锁。过了很久，她抬头看了一眼门口站着的顾延之，又看了看许迟迟，嘴唇翕动着。

“那封信……不是我一个人拿的，”她声音发闷，“有人要它。”

沈静秋在背后开口：“谁？”

许婉玉的视线越过许迟迟肩头，落在堂屋墙上挂的一张黑白老照片上。照片里是外公外婆并排坐着，中间站着一个扎辫子的姑娘，那姑娘看着十一二岁，手里拿着一枝海棠。

那姑娘的耳朵上，戴着一只蝴蝶形状的银簪子。

许迟迟目光一缩——是那位“干女儿”。

许婉玉低声道：“她回来了。她让我把信给她，说拿信来换一条命。”

她话没说完，门口外头忽然一阵风声。不是雨，是风卷着什么东西打在窗棂上，啪嗒一声。

许迟迟回头，就看见窗台上落下一瓣花。

深红色的，湿漉漉的，贴在玻璃上。

是海棠。

而且它正顺着玻璃往下滑，缓缓露出它背面——在花瓣背面，有一个针尖划出来的字。顾延之和许迟迟同时看清了那字，只有一个字：

“走。”

许迟迟心头猛跳。

窗外，那阵脚步声很快消失在雨后的街道深处，像是有人故意让她们听见，又像是警告。

许婉玉的脸色刷地白了。她抱住那只木匣，嘴唇发着抖，喃喃道：“她知道了……她知道了……”

许迟迟一步跨到窗边，手按在窗框上，看着那瓣海棠掉落在窗台积水上，打了一个转，缓缓沉了下去。雨后的风里，她又闻到了那股甜腻的花香。这一次，不是来自花圃。

是从那花瓣上散出来的。

她回头看向许婉玉，声音像被人掐着一样：“你要用信换谁的一条命？”

许婉玉抬起头，看着她，目光里全是泪：

“你外婆。”

窗外街道尽头，路灯忽然灭了一盏。整条老街上，那盏灯明明一个小时前还亮着。现在灭了，像有人亲手拧灭了它。

而那瓣海棠沉在水里，沉到底，背面那个“走”字被水泡得模糊不清，只留下一道浅淡的划痕。

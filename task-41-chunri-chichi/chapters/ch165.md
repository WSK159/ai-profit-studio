# 第165章 银莲花

晨光透过迟园的玻璃花房，在许迟迟手背上落下一片细碎的光斑。她一夜没睡好，掌心的银戒指硌得生疼，那枚戒指内侧刻着两个字——不是"迟迟"，是"归迟"。

顾延之端着两杯热茶走进来，看到她还坐在花房角落的藤椅上，膝盖上摊着那方旧帕子。

"帕子里的信呢？"他问。

许迟迟抬起头，眼眶微红："我昨夜看完了。你母亲说的没错，信里的确提到了白玫瑰和银莲花。但还有一句，她没念出来。"

顾延之在她对面坐下，把茶杯搁在她手边。玻璃花房里的白玫瑰正开着，晨露在花瓣上滚落。

"念给我听。"

许迟迟低下头，轻声念出帕子内衬里那行小字："银莲花种在墓碑西侧，第三块石碑下。"

两人同时沉默。花房外传来顾母修剪枝叶的声响，修枝剪发出清脆的"咔嚓"声，一下，又一下，像是某种倒计时。

"我父亲当年的墓碑，"顾延之说，声音很轻，"在城南公墓。碑西侧确实种过一丛银莲花，是我母亲亲手栽的。但我从没听她提过'第三块石碑'。"

许迟迟把帕子叠好，收进口袋，起身道："我们去看看。"

迟园到城南公墓四十分钟车程。顾延之开车，许迟迟坐在副驾驶，一路无话。车窗外的行道树不断后退，像翻过去的日历页。

公墓早晨人不多。晨雾还没散尽，松柏间的露水把裤脚洇湿了一片。顾延之熟门熟路地走到父亲墓碑前，碑石干净，显然常有人打理。碑西侧确实有一丛银莲花，只是花期未至，还是绿油油的叶子。

许迟迟绕过那丛花，数到第三块石碑。

碑面很旧，没有刻名字。

"无字碑？"她蹲下身，指尖拂过碑上的苔藓。碑座周围泥土松软，像是被翻动过的——新土压在旧土上，还带着水汽。许迟迟的手顿住了，她在那块碑座西角的泥土里，摸到一样东西。

银莲花球根。

那球根被小心地埋着，已经抽出一点嫩绿的芽尖。球根表皮上用黑笔写着一行小字，因为埋进土里有些时日，字迹洇开大半，但依稀可辨——"十年前的约定"。

许迟迟抬起头，对上顾延之的视线。他站在那丛银莲花旁边，早晨的阳光斜斜地照在他身上，把他的影子拉得很长，一直延伸到她指尖。

"延之，"她缓缓开口，"你记得十年前，你写在信里那个'春天的秘密'，除了白玫瑰和银莲花，还提到了什么？"

顾延之走近，蹲在她身边。他看了一眼无字碑，又看了看那颗球根，像是被什么东西击中了一般，整个人僵住了。

"墓碑。"他说，"我写的信里，画了一幅图——白玫瑰种在墓碑西边，银莲花隔着一块碑的距离，然后……'等花开时，你就知道哪个碑是我的心意'。"

许迟迟的呼吸一顿。那幅图她见过。十年前的信她曾反复折开又合上，有一页纸的边角画着不止两朵花。那时候她还以为是随意涂鸦，现在她明白了——那是地图。

她低头看着手里的球根。

"这株银莲花，"她声音有点发抖，"是你父亲种的，还是你母亲种的？"

顾延之还没来得及回答，身后突然传来一个声音——

"是我种的。"

两人同时回头。顾母站在墓园入口的柏树下，穿一件灰青色外套，手里握着一束刚折下的白玫瑰。她的视线落在许迟迟手里的球根上，神色复杂，在晨光里站了很久。

"球根是十年前那天下午，我亲手埋的。"顾母走近，声音平静得像在讲别人的事，"那天我拦下了你写给许迟迟的信，然后我去了趟云南。我想找到一个人——许迟迟的父亲。"

许迟迟的手猛地收紧，指节泛白。

"你父亲……"顾母蹲下来，与她平视，"当年并不是反对你母亲去美国，才劝她留下的。他在云南，见过一个从城南公墓出来的人。那人手捧白玫瑰，在第三块无字碑前站了整整一个下午。"

晨风穿林而过，松针沙沙作响。许迟迟握着那颗银莲花球根，看到顾母眼底有一闪而过的光——那光不是恨意，而是某种积压了十年的、说不出口的愧疚。

"你父亲那天回来，对许迟迟的母亲说了一句话。"顾母说，"他说：'那孩子等的人，等不到了。'"

顾延之站起身，声音低哑："第三块无字碑，埋的是谁？"

顾母没有回答。她弯腰捡起球根旁边落下的另一颗东西——一枚泛旧的银戒指，内侧同样刻着"归迟"二字，与许迟迟帕子里的那枚一模一样。

许迟迟愣住了。

墓碑西侧，第三块碑下，银莲花球根旁，埋着一对刻着"归迟"的银戒指。而顾母看着那对戒指，像看着十年前那个没能说出口的答案。

"第三块碑里埋的，"她终于开口，"是你父亲最好的朋友。也是许迟迟的父亲，当年没能娶到的人——"

她的声音被手机铃声打断。顾延之的。

他接起电话，那头传来实验室助理的声音，急促而兴奋："顾老师！花开了！那个品种开花了！花瓣是白色的，但边缘透出银色的纹路，像月光一样！"

顾延之握着手机，目光却落在许迟迟脸上。晨光里，她低着头，把那颗银莲花球根轻轻放回掌心，又用帕子裹好，像包住一个迟到了十年的春天。

"那盆花，"顾延之对电话那头说，"叫'迟迟'。它开了，就代表我等到了。"

电话那头沉默了片刻，助理小声问："那……它的花语是什么？"

顾延之看着许迟迟站起身来，晨光在她发梢碎成细金。他轻声说："是'迟到的春天，也算春天'。"

# 第273章 瓶子里的花粉

玻璃瓶在掌心传来微凉的温度，许迟迟盯着那一圈模糊的标签——“零八年四月十七日，第七批”，仿佛透过这个数字能看见十七年前的一间实验室，一个年轻男人跪在显微镜前，小心翼翼地收集着每一粒花粉。

“十七号。”顾延之的声音低而沉，打断了她的思绪，“沈知蘅失踪那天。”

许迟迟抬眼看他。他站在花架旁边，黄昏的光透过玻璃门落在他的侧脸上，将他的轮廓镀成一层暗金色。她忽然觉得，这个相处了二十七章的男人，这一刻无比陌生——他胸中装着那么多秘密，每一个都比她想象中更沉。

“顾延之，”她开口，声音比自己预想中稳，“你知道那个瓶子是留给你的，还是留给我的？”

他沉默了片刻，目光落在瓶身上那句“取者，必自啖”上，喉结微微滚动。“大概是留给所有能找到它的人。”

说完他走到工作台前，从抽屉里翻出一个放大镜，将那瓶花粉对着灯光辨认。许迟迟站在一旁，看着他专注的侧影，有一种错觉——他不是植物学教授，而是一个刚走进命案现场的侦探，手里攥着最终的证据。

“这不是普通的花粉。”顾延之把放大镜递给许迟迟，“你看这种颗粒的形态，表面有电镜处理过的痕迹。花粉在自然状态下会有油质层，但这批是经过纯化分离的。”

许迟迟凑过去看，那些浅黄色粉末在放大镜下呈规则的椭圆颗粒，像一个个缩小了无数倍的米粒。她抬头：“纯化过的花粉可以用来做什么？”

“做杂交实验、保存种质，也可以——”顾延之顿了顿，语气里有了些许不寻常的变化，“用来人工诱导花期。”

他的目光落在角落里那盆“迟迟”上。它安静地蹲在木架上，深绿色叶片沾着水珠，花苞紧裹如一只攥紧的拳头。

许迟迟顺着他的视线看过去，心猛地一沉。“你是说，这个瓶子里的东西，可能和‘迟迟’开花有关？”

顾延之没有直接回答。他走到那盆花前，蹲下身，指尖轻轻拨开花苞外侧的萼片。许迟迟走过去，也蹲下来，两个人肩并肩，视线落在那片柔软的花苞上。

“花苞的生命体征一直在变化，”顾延之说，“但始终没有到达开放的临界点。我以前以为只差温度、湿度或者光照，但——”他直起身，目光落回那只玻璃瓶，“也许差的是它。”

许迟迟伸出手，碰了碰那只瓶子：“所以那封信里说的‘把它埋进去’，是指……把花粉埋进花盆里？”

“有可能。”

她站起来，走到花架前，手指轻轻抚摸那盆花干硬的表层土壤。这盆花在她手里已经养了整整十年，每一块土她都换过，每一片枯叶她都修剪过，她以为自己了解这盆花的全部。可如果它真正需要的，是十一年的花粉？是那个失踪男人的最后印记？

她把瓶子握在掌心，感受着那冰凉而神秘的重量，指尖微微发僵。她没有立刻决定，而是把瓶子放到花架最高一层的角落，又用一块素色棉布盖住。

顾延之没有追问。他只是看着她做完这一切，然后问：“你信那句话吗？”

“什么话？”

“‘取者，必自啖。’”

许迟迟笑了，笑意却未达眼底：“我做花艺十年，见过男人娶花为妻，见过女人葬花做坟。跟一盆花绑定，总要准备好承担后果。”

她话音刚落，手机响了。是沈知微。

许迟迟接起电话，那头安安静静，几秒后，沈知微的声音才传过来：“那个瓶子还在你手里吗？”

“在。”

“扔了它。”

许迟迟皱起眉：“你知道那是什么？”

电话那端，沈知微的呼吸声明显粗重了一瞬。她似乎在自己店里，背景里有咖啡机的嗡鸣。她用压得极低的声音说：“花粉一旦暴露在空气中超过一定温度，会改变活性。如果那瓶花粉只是被保存了十七年，那它早就该废了。但要是它被保存得很好——”

她被自己话里的意思吓得顿了一下，才继续说：“那它就不是‘保存’的，是有人长期在维护它，更新它，让它保持活性。”

许迟迟心头一跳：“谁能在十七年里持续维护一瓶花粉？”

沈知微笑了，笑声有些干：“你说呢？”

她没等许迟迟回答，电话就挂断了。

许迟迟握着手机站在原地，耳畔只剩下忙音。她转头看向那盆“迟迟”，被棉布盖住的玻璃瓶安静地蹲在花架角落，像一个未醒的秘密。她忽然觉得，花盆里那片紧裹的花苞好像微微动了一下——即使她知道那只是自己的幻觉。

顾延之在她身后开口：“她在暗示你什么？”

“我不知道。”许迟迟把手机收进口袋，回过头来，目光冷静，“但她说，那瓶花粉可能不是十七年前的旧物，而是有人一直在维持它的活性。”

顾延之眉峰紧锁。他正要开口，花店门上的风铃叮当一响，有人推门而入。两人同时转头，门口站着一个穿灰色大衣、戴着口罩的人，看不清脸。那人没有进来，只站在门外，隔着玻璃门望着他们。

准确地说，望着那盆“迟迟”。

过了两秒，那人转身走了，消失在老街末端的暮色里。

许迟迟追出去，只看见街角一盏路灯底下一双男式皮鞋的后跟，一闪而过。

她站在门口，风刮过脸颊，带着早春的寒意。她忽然想起那个在迟园里隔着树丛注视她的身影，同样的灰衣，同样的沉默。

她转身回店，声音听起来很平静：“顾延之，你的研究所里，有谁拿到了‘迟迟’的样本？”

顾延之的脸色微变。

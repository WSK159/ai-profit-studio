# 《外卖龙王》男频逆袭短剧（任务 15）

## 项目定位

- 类型：男频都市逆袭（战神/外卖员/复仇/商业暗战），60 集，单集 60-90 秒
- 核心钩子：白天送外卖的退伍兵王，隐忍三年查战友之死，卷入地下势力与商业暗战
- 目标平台：抖音/快手/红果/海外短剧平台（ReelShort 等）

## 变现路线

- 平台分账 + 投流跑量（男频逆袭是投放最成熟的品类）
- AI 制作降本：角色/场景用 MiniMax 生图、视频用海螺（MiniMax）生视频，单集素材成本可控
- 与仓库内已有 `my-first-project`（60 集 MiniMax 流水线）对接，本项目产出剧本+分镜+提示词可直接投喂

## 交付内容

- `episode-outline.md`：60 集分集梗概（每集钩子+反转）
- `scripts/ep001-003.md`：前三集完整剧本（场景/对白/镜头）
- `storyboard-prompts.md`：全剧角色/场景提示词 + 分镜模板 + 示例分镜表

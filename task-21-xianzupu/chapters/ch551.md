# 第551章 碑后尺半路

余烬的颜色发白，边缘还带着微红的热度。顾青衍蹲在裂隙前，伸手探入——指尖感受到一股温热的空气从石缝里涌出来，带着极淡的檀香。

“有人刚走。”他说。

追猎者一步跨过来，目光落在余烬上，脸色微沉：“檀香……是谱房用的‘续脉香’。”

续脉香，谱官焚香时所用，以青檀、安魂草和秘制灵砂制成。东荒上下会制此香的，只有谱道一脉。三十年前顾氏谱房血案之后，那套制香法门便已失传。

“东荒会点续脉香的，还有谁？”顾青衍问。

追猎者沉默了一息，才道：“你祖父点过。还有……三十年前死在谱房血案里的那位，他也会。”

顾青衍没有追问。他侧身钻入石缝，尺半宽的空间刚好容一人通过。两侧石壁粗糙潮湿，长着暗绿色的苔藓，脚下铺着一层细碎的石屑。石屑上有足迹——脚印不大，鞋底纹路平直，像是布底鞋，沾着一点干涸的黄泥。

“黄泥。”顾青蘅跟在身后，低头看了一眼，“青桐镇的土是黑土，东荒北境才是黄土。中州以北，落霞宗的地界。”

“东荒北境？”顾青衍皱眉，“那里离玄天门有千里之遥。”

追猎者没有搭话。他走在最后面，断刀半出鞘，目光不断扫过两侧石壁上的裂缝。

甬道只走了约莫二十步，前方空间忽然开阔起来。石厅约有三丈见方，四壁皆凿有壁龛——每个龛内安放着一盏铜灯，灯中油早已干涸，只余漆黑的灯芯。正中放着一方石案，案上无一物。

但在石案下方，有人用指甲刻了一行字。字迹纤细，笔画极浅，像是刻意压低力道留下的。

“谱已断，墨未尽。守火者，不待天明。”

顾青衍默读三遍，抬起头时，目光落在石案正中的一处凹陷上。凹陷呈圆形，约三指宽，深浅如一枚铜钱。

他几乎下意识地取出怀中那枚断谱针。针体上缠绕的幽光在石厅中微微一亮——像是认出了什么。他将针尖探入凹陷，竟然严丝合缝。

“咔”的一声。石案底层缓缓裂开一道缝隙，露出内里一尺见方的暗格。暗格中放着一卷泛黄的帛书，帛书卷轴所用的正是与顾青衍手中那块碎片同一色的旧绢。他小心翼翼取出帛书，展开一角，只见第一行写着：谱官者，以血立名，以命续脉，以魂守谱。非大劫不立，非大哀不改，非大义不传。

他继续展开。第二行字迹已与第一行显然不同，更显滞涩——像是换了一人书写：“顾氏三代谱，谱官二人。第一代顾九渊，立谱于青桐，断于东荒。第二代顾九章，续谱二十载，传于其孙。”

下面还有第三行，但只写了一半便停住了：“第三代——”

笔锋戛然而止。那根写字的笔，似乎在这一行断折。

顾青衍握着帛书的手微微发紧。顾九渊……第一代谱官，当真是顾氏谱道始祖。祖父顾九章生前从不提起这个名字，只在一本残旧的杂记里写过一句话：“渊公之死，乃吾平生不敢问之事。”

“第三代”三个字之后，没有名字。那一道断笔，像一根刺横亘在家族谱系的尾端，悬而不落。

“看这里。”顾青蘅的声音忽然响起，带着一丝异样的紧绷。她正站在石厅左壁的一座壁龛前，铜灯底部压着一块拇指大的玉片。玉片通体温润，隐约可见内中封着一滴暗红色的血。她将玉片拿起，翻到背面——上面刻着两个字：斩墨。

追猎者看见那两个字，整个人忽然像被定住了一般。他的手指松开了刀柄，又缓缓攥紧，良久，才哑声道：“这块玉……是舍弟的。”

石厅中一时寂静。

顾青衍抬头看他：“你说过，斩墨来历成谜，你追他多年。”

追猎者的目光锁在玉片上，声音低得几乎听不清：“他是我弟弟。他死了十五年了。我看着他入的土。”他伸手接过玉片，指尖微微发抖，“可这玉上封的血气……和当年一模一样，没有衰败，没有干涸。像是昨天才落进去的。”

顾青蘅与顾青衍对视了一眼。

顾青衍没有说话，只低头再去看那卷帛书。第三行“第三代”后面那根断笔，此刻看去，似乎正对着石壁上的某条纹路——那道纹路一直延伸到地面，与地上一条极细的裂缝相连。裂缝尽头，是那道尚未完全合拢的石缝。

甬道里的撞击声忽然又响了一声，比之前更近了。这一次，石厅顶部落下一层细碎的石屑。

追猎者将玉片收入怀中，站起来时，眼中那道暗火已经烧成了整片灼人的光。他看向顾青衍：“那道门里，你对我说过一句话——‘信你不得’。对吗？”

“对。”

“现在，你信我几分？”

顾青衍没有立刻回答。他低头将帛书卷好收进怀里，站起身，望向石厅外那道半开的石缝。甬道深处，那阵嘶鸣声粗重起来，带着某种被唤醒的饥渴。

“信你半分。”他说，“剩下九分半，我信的是——你弟弟留下的这块玉，和这卷帛书上那根断笔，都在指向同一个方向。”

他顿了顿：“去碑后第二道门。此刻就动身。”

追猎者的目光在他脸上停了一息，没有问为什么，只点了点头。

顾青蘅将符囊扣紧，低声道：“那甬道里的东西……”

话音未落，轰的一声巨响，甬道尽头的石壁猛然炸开。灰烟之中，一只覆满鳞甲的长爪伸了出来，五指如钩，一把抠进地面，将一整块石板抓得粉碎。

石厅中烛火扑灭。

黑暗里，顾青衍握紧旧笔，笔尖在指间无声一亮。

他低声道：“跑。”

# 第158章 断谱阵心

顾青衍扶着顾青蘅退入祠堂偏殿，背后朱漆木门轰然合拢，将殿外翻涌的血雾隔绝在外。他把姑姑放下，靠在一根廊柱旁，迅速摸出怀中的旧笔。

笔杆温热，九道裂纹里渗着微光，却像烧红的铁线一样烫手。

“青衍？”顾青蘅睁开眼，声音虚弱，“刚才你连写三字……反噬多久了？”

“没有反噬。”顾青衍把笔收回袖中，面上平静，“姑姑放心。”

顾小满站在他身侧，悄悄拽了一下他的衣袖。他没回头，却听见小妹压着嗓子说：“哥，你袖口在滴血。”

他低头——袖口确实洇出几滴暗红，顺着指尖线落在地上，又迅速被青砖吸干。他不动声色地握了握拳，那笔已在掌心燎出一块黑痕，血肉焦糊处隐约有细小的墨丝在蠕动，钻入筋脉又散开。

“阵还没破。”顾青衍开口，“断命谱的阵心在下沉，镇魂钟压不住它。我在地面写了封、续、断三字，只锁住了锁链和表层的阵纹——真正的阵枢不在那里。”

顾青蘅撑起身子，吞了一枚止血丹，喘息片刻：“阵枢……会在哪？”

“阵中的黑雾以前我没见过。”顾青衍皱眉，“它不在我的‘开卷’视野里。族谱只能照见族人的命，但那个位置……像被什么遮住了。”

他闭上眼，尝试再次开卷。可是每当他凝神去“看”祠堂地下，视线便撞上一层冷硬的黑幕，幕布之后是仿佛深渊的口子，吸着他的目光往下坠。体内的灵力被抽出，像抛入深井的石子，连回声都没有。

“别试。”顾青蘅猛地按住他的手腕，“断命谱用的是与族谱同源的手段。你看不见，是因为它借了顾氏自己的气运做遮挡——你用谱道看它，等于闭着眼查自己的影子，绕不过。”

顾青衍睁开眼，沉默片刻：“那就用旁的看。”

他转向顾小满：“小满，你铜铃里的蓝光……是什么？”

顾小满低头摸了摸铃铛，刚才蓝光冲出时铃身已经裂了一道口子，如今光晕微弱，像风里将熄的烛：“是祖父的。阿爷走前说，这个铃铛……等有雾遮住眼睛的时候再摇。”她顿了顿，小声补了一句，“他说，雾里有人，别让那人看见你看见他。”

顾青衍心头微动。

祖父说“雾里有人”——那黑雾中藏的，恐怕不只是断谱阵的阵枢，还有“人”。断谱人本代执幡者顾长明已经承认了身份，但黑雾却在执幡者惊惶后退时才出现。那不是他布下的东西。

“姑姑，你和长明交手多久了？”顾青衍忽然问。

顾青蘅一愣：“从祠堂前院到阵眼，约莫一刻钟。他一直以幡控阵，没有亲自进场。”

“那他也不知道黑雾里是什么。”

顾青衍话音未落，祠堂外传来一阵沉闷的声响——像是某种巨大的木质机关在地下转动，又带着砖石的咔嚓脆响。地面轻微震颤，殿内的镇魂钟再次长鸣一声，钟声却比前次急促许多，像被什么催赶着。

顾青衍一步跨到窗前，透过残破的窗棂望向祠堂庭院。

原本被他的三字镇在半空的断谱阵纹正在变化：血红的阵纹从四面八方向中央收敛，顺着地面裂缝灌入，汇成一个缓慢旋转的螺旋。螺旋中心，就是黑雾最浓的地方。

黑雾正在变得……像一张嘴。

“阵心要吞血。”顾青衍转过身，目光骤沉，“顾长明先前把姑姑吊在阵眼上，就是为了引血入阵。现在阵纹收拢，如果没人继续供血，它会自行抽取整座青桐镇顾氏族人残余的气血。”

他想起曾经在族谱上看见的几条暗线，那些线头朝他颤抖、崩断，像将断的琴弦。

“我还得再写一笔。”

“不行！”顾小满一把拽住他的手腕，眼泪一下冒出来，“哥，阿爷说旧笔用多了要还的！刚才那三字已经——”

“小满，松开。”

顾青衍声音低而稳，目光落在妹妹攥紧的手指上。屋檐外血雾翻涌，殿内昏沉，他半边脸埋在阴影里，半边被窗外渗入的暗红映着，像一道被墨浸透的影子。

“阿爷说，谱官落笔，不为一族者不落。”他说，“这一笔，我若不写，顾氏谱上的名字要一根根熄掉。祖父传我笔的时候，自己也没了寿元。我不是不懂代价——只是它值得。”

他轻轻掰开顾小满的手，走到殿中的青铜案前。案上积满了灰，昏暗中看不清字，他摸到久远的案沿，将旧笔平放上去，闭目凝神。通体灵力朝笔尖汇聚，笔杆上的“天谱”二字亮起，像被点燃的灯芯。

“祖父说雾里有人。”顾青衍低声道，“那我就借着明路，把雾里的人逼出来。”

他执笔蘸墨，笔尖悬于半空，朝着地面的方向重重落下。

“第十一笔——‘照’。”

字落，笔锋炸开一蓬金光，如暴雨兜头浇下。金光穿过地板、穿过祠堂年久的梁柱，落进那片盘旋的黑雾中。雾体剧烈翻涌，像被照出原形的野兽，发出无声的嘶鸣。而金光还没散尽，顾青衍忽然看见雾底深处——有一只手。

一只干枯的、指节上戴着半枚玉戒的手，正按着一页泛黄的谱纸，缓慢地，一笔一笔在写。

仿佛感应到他的视线，那只手顿住了。

然后，指尖抬起，向他所在的方向，轻轻勾了勾。

顾青衍背脊发凉，手中的旧笔忽然重逾千钧，笔杆上的裂纹扩大，“天谱”二字的光芒骤然熄灭——第二十一笔的代价，在这一刻已成定局。他喉头一甜，鲜血从嘴角溢出，整个人向前栽去。

顾青蘅扑过来接住他，面色骤变：“青衍！”

顾小满的铜铃在这时毫无征兆地“叮”了一声——裂口处渗出一点蓝光，笔直地飞向地面，穿破砖石，没入那只干枯手掌按着的谱纸。

顾青衍倒在顾青蘅臂弯里，视线模糊，却看见蓝光落处，那只枯手的动作停了。片刻后，谱纸上竟泛起一圈淡蓝色的水纹，像一片旧湖的湖面，轻轻荡漾开去。

殿内血雾死寂。

祠堂外的镇魂钟，忽然不响了。

一个沙哑的声音从地下升起——不是从黑雾中，而是从顾青衍自己喉咙里：“还不到时候……”

顾青衍猛地清醒过来。

他眼前还是祠堂的梁柱，姑姑扶着他的肩，小满跪在身侧哭得满脸泪。但他清清楚楚地感觉到，自己的右手已经不在自己控制内——那支旧笔，无人握着，却悬在半空中，笔尖对着雾底的方向，在无人执握的情况下，缓缓落下一笔。

青桐祠堂外的夜空，正有一道惊雷，将要劈下。

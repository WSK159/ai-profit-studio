# 第537章 白笔照影

水花从暗河中央缓缓散落，露出那道白影的轮廓。

那人站在水面上，身形瘦长，穿着一件洗得发白的旧袍，面容被一层水雾笼着，看不真切。唯有他手中那管素白笔格外醒目——笔杆通体雪白，笔尖悬着一滴墨，悬而不落，像是凝固在时光里的一滴泪。

顾九渊的嘴唇动了动，那声“大哥”卡在喉间，半晌没有吐出来。

“不必惊慌。”白影开口，声音像隔着水传来，有些失真，“我只是一缕残影，承在那管白笔之上。真身在六十年前便已陨落，留在暗河底的，不过是最后一道旧念。”

顾九渊攥紧的拳头微微松开，又攥得更紧：“大哥……当年你说去玄天门寻人，便再没回来。我找了你三十年，以为你死在断谱人手里。”

“死在断谱人手里？也算差不多。”白影轻笑一声，语气里听不出悲喜，“我查到了断谱针的出处，顺线追到了玄天门的内库。但那一夜，我折在了一个人手里。那人穿着一身玄黑袍，用一支断墨笔压住了我的灵脉——他认出了我的笔，也认出了我是顾氏的人。”

断墨笔。顾青衍心头猛震，脱口道：“斩墨？”

白影顿了顿，目光转向他：“你倒是知道不少。看来小七把该传的都传给你了。”那目光透过水雾，落在顾青衍怀中的两管笔上，顿了一下，“阴笔也回来了。好……好。”

他话音未落，那颗悬在笔尖的墨珠忽然轻轻一颤，坠入水面。水面荡开一圈涟漪，涟漪中央浮起一幅画面——

一座书阁，匾上题着“谱籍阁”三字。阁中书架鳞次栉比，每一层都摆满了卷册。一个黄衫少年正蹲在角落，捧着一卷泛黄的簿册，低声念着什么。他的手指划过一行名字，在“顾九衡”三个字上停了停，又往后翻了一页。

画面之外，白影的声音传来：“这是当年我在玄天门谱籍阁里看到的最后一卷。那卷簿册，是断谱人的脉谱名录。名录末页写着一个名字——”

画面里，黄衫少年翻到末页，墨迹淋漓地写着两个字。顾青衍凝神看去，赫然是“顾衡”二字。

他愣住了。

不是“顾九衡”，而是“顾衡”。少了一个“九”字，却分明是同一个人的名字。

“我的名字，被他们写进了断谱人的名录。”白影的声音平静，“所以我陨落之后，残念不入轮回，只能困在这管白笔之中。因为我的名字被那名录扣住了，族谱里便再没有我的位置。”

顾青衍脑海里嗡地一声。他终于明白，为什么此前翻阅族谱时，顾九衡的名字看上去比旁人的都浅淡，像是随时会被抹去。他一直以为是年代久远所致，原来是因为这个名字早已被人从正谱中偷走了。

“那道名录现在在哪？”顾九渊的声音沙哑。

“不知道。斩墨把它带走了。”白影望向头顶的岩壁，像是在透过层层土石看向远方，“但我知道，名录上用墨，出自一支与青梧同源的旧笔。笔上刻着两个字——‘断谱’。那是三百年前，玄天门初代谱籍阁主所制。”

暗河的水流忽然放缓，浪头退去，像是连水势都被这番话压住了。顾青衍深吸一口气，从怀中取出那管断竹笔，笔杆上“守规归处”四个字在昏暗的光线里泛着幽微的青纹。

“九衡叔公。”他抬头看向白影，“守规叔伯当年带走断谱针，是不是也去了玄天门？”

白影沉默了很久。水汽渐渐把它的轮廓模糊了一瞬，又恢复清晰。

“守规去的地方，比玄天门更远。”他缓缓道，“他追的是名录背后的人。断谱针是他的刃，也是他的锁——他要用那针，把被扣在名录上的名字一个一个挑下来。我困在暗河里这六十年，等的不只是阴笔，等的是你。”

他抬起白笔，笔尖遥遥指向顾青衍的眉心。

“你身上有青桐果壳的墨，又握了阴阳双笔。这东荒之上，能续上断谱的人，恐怕只剩你一个了。但你要记住——阴阳双笔合在一起，可以续谱，也可以断谱。你若落笔太重，便是把自己的名字也写进去。”

白影的轮廓开始变淡，像是残烛将尽。顾九渊上前一步，伸出的手却穿过了那片水雾，什么也没够到。

“大哥——”

“小七，我当年没能护住谱官，也没能护住守规。你能把这个孩子带到暗河底，已经是顾氏之幸了。”白影最后一次开口，声音越来越远，“玄天门谱籍阁底下，有一间暗室。那道名录就锁在暗室的石壁里。若有一天你到了那里，对着石壁写上一个‘归’字——”

话音未落，白影彻底散作水雾，那管素白笔“当啷”一声落在石台上，笔尖的墨迹已然干涸。

顾青衍弯腰拾起白笔。笔杆入手微凉，指尖触到一行极浅的刻字——

“青梧白守，一谱归墟。”

他抬头与顾九渊对视，老人眼中翻涌着复杂的光。石台上的水纹逐渐退去，暗河重新恢复了平静，仿佛什么都没发生过。

但顾青衍知道，从这一刻起，他怀中不再只有两管笔了。是三代人的残念，压在他的掌心里，沉得令他几乎喘不过气。

远处岩壁忽然传来一声悠长的震动，像是什么东西正在破土而来。顾九渊神色一凝：“玄天门的人，追上来了。”

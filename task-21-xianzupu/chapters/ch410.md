# 第410章 落霞来信

次日清晨，顾青衍是被一阵拍门声惊醒的。他昨夜在水井边那株老榕树下站了半宿，脑子里把那页纸上的字翻来覆去地嚼——直到后半夜才回屋躺下。此刻推开门，门外站着一个陌生的中年妇人，粗布衣衫，双手粗糙，一看便是山野农妇的打扮。她怀里抱着个篓子，篓子里装着一篮子青杏。

“顾家少爷？”那妇人嗓音沙哑，“有人托我把这个送来，说务必亲手交到你手上。”

顾青衍接过篓子。掀开盖在上头的粗布，底下只有一颗杏子，通体青绿，却散发着淡淡的甜香——和昨夜碧桃树根下那缕甜香一模一样。

妇人已经转身要走。他叫住她：“请问，是谁托你送的？”

妇人头也没回：“那人说，你见了杏子，自然知道去哪找人。”

她走出巷子拐角，身影便消失了。顾青衍低头看着掌心的青杏，指腹一压，杏皮裂开，里面竟没有核——只有一小卷纸。他展开纸卷，上面只写了一个字，笔锋凌厉，带着杀意：

“速走。”

没有落款。但他认出了这笔迹，三十年前，谱房血案发生后，上一任谱官孟叔和留下的绝笔上，正是这个“速”字写得一模一样。孟叔和。那个死因成谜的上一任谱官。他的字，怎么会落在送杏人手里？他死去三十年，这笔迹分明是写给某个活人的。顾青衍深吸一口气，将纸卷收进袖中，快步走向谱房。

推开门的瞬间，他停住了。案上那页薄纸还在原处，但旁边多了一样东西——一枚黑铁令牌，正面刻着“玄天门”三字，背面却凿着一个小小的“断”字。断字上还沾着乌黑的血迹，尚未干透。

谱房有人进来过。血迹未干，是昨夜的事。顾青衍指尖搭上令牌边缘，灵力一探，发现令牌内部有一行小如蚊足的字：“三月初七，阁毁人亡。”

他把令牌扣在案上，走到墙边，取下挂着的那柄旧木剑。那是祖父教他练剑时用的第一把剑，剑身早朽了。但此刻他握着剑，剑柄尾部却渗出一丝冰凉——像是有人昨夜把他祖父留下的东西又还给了他。他翻过剑柄，底部凹槽里，嵌着一小节手指骨。

人类的指骨，断口光滑，像是被人用刀切下来的。指骨上环着一圈暗红色的印记，与顾青衍见过的断谱针上的花纹一模一样。他把指骨从剑柄里取出来，攥在手心。骨片在袖子里忽然醒了过来，开始微弱地搏动，像在与指骨呼应。

顾青衍闭目，把灵力送入指骨。朦胧中，他看到一段画面：一间灯火通明的屋子，桌案上摊着厚厚的族谱。一个身形佝偻的人背对他，右手执笔，在那谱上缓慢地写着什么。那人左手没有小指——断口处缠着白布，布上渗出暗红色的血。

那人忽然停下笔，侧过头来。

顾青衍看清了那半张脸。苍老、枯瘦、眼窝深陷，左眼蒙着一层白翳——是他祖父顾九章。但又不完全是。祖父左眼的白翳是近年才有的，可画面里的他，看起来只有五十出头，左眼却已经蒙着白翳了。那也就是说，早在三十年前，顾九章的眼睛就已经瞎了一只。他没有告诉过任何人。

顾青衍猛地睁开眼，眼前的谱房还在，但他的手在发抖。他低头看那小节指骨，断口处泛着一层极淡的青光——那不是祖父的骨头。那指骨来自另一个人，但顾九章把它藏在旧剑柄里，藏了三十年。指骨上那圈暗红印记，是断谱针留下的。

三十年前，谱房血案。上一任谱官孟叔和暴毙。顾九章的左眼瞎了。斩墨第一次现身。四件事发生在同一年。顾青衍把指骨和令牌并排放好，又从袖中抽出那页薄纸铺在旁边。纸上那行字还在：“谱道尽头无来路，天道尽头无归途。”他执起旧笔，蘸墨，在那行字旁写下：“祖父，你瞒了我多少事？”

笔落墨干的瞬间，那页纸忽然自行燃了起来，烧成灰烬。灰烬落在地上，居然没有散开，而是形成了一行字，像有人在灰烬里用指头写出来的：

“落霞峰，第七峰，老松洞，等你来。”

顾青衍怔了怔，忽然笑了。他蹲下身，把那行灰烬字仔仔细细看了一遍，记住了每一个笔画。然后他站起身，拿起那枚黑铁令牌、那截指骨，连同一整根碧桃树根下挖出的碎玉，并排收入怀中。

他推开谱房门，天光大亮。顾小满正蹲在东墙那棵桃树下，拿着一根树枝拨弄泥土。她仰起头来，满脸疑惑：“哥，这树底下好像埋着东西。”

顾青衍走过去，蹲在她身边，轻声道：“我知道。”他顿了顿，又补了一句，“小满，我三月初七要出一趟远门。你替我把这棵桃树看好，别让任何人动它。”

顾小满用力点头，眼睛亮晶晶的。“那你什么时候回来？”

顾青衍抬手摸了摸她头上的发髻，看向东南方落霞峰的方向。“等我把祖父的旧账收完。”他说，“就回来。”

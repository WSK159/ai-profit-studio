# 第394章 第十页

墙壁上的字迹只维持了约莫三息，便如浸了水般缓缓淡去。顾青衍猛地扑到墙前，指尖触及那一行字的痕迹，却只摸到冰冷的砖面，隐约有一层极薄的粉末——像是墨迹蒸发后留下的余烬。他捻了捻指尖，粉末呈暗红色，和旧笔写完字后笔尖残留的渣滓一模一样。

“是你祖父的字。”顾青玄站在他身后，声音平缓下来，“我见过他在谱房写祭文，下笔的手势，收笔的力道……就是这个样。”

顾青衍盯着那面墙，许久才说：“他知道我什么时候立谱。他连我立谱要给谁续名——都算好了。”

“第十页是什么页？”顾青玄问。

“族谱有九页。”顾青衍说着，从怀中取出随身携着的族谱卷轴。这份抄录本是他入谱房后亲手誊的，九页分列：第一页顾氏源流，第二页至第六页列祖人名与生卒，第七页当代嫡脉，第八页旁支，第九页为“余名录”，专录外族写入者。顾九章临终前加了一页？他翻开卷轴，手指停在卷尾——比他誊录时多了一页空白。

第十页，无字。

他伸手去触，指尖碰到纸面的瞬间，那一页忽然泛起暗红的光，一行行字从纸面深处浮起，像鱼群从深水游向水面。字是顾九章的笔迹，写的却不是经文，也不是人名，而是一段话，一段只有炼气期修士也能读懂的话：

“青衍：你读到此时，我已入土十载有余。若你已执旧笔立谱，则此页自动开启；若你尚未立谱，则此页将一直空白。老朽布三道局，一为护族，二为引你，三为——”字迹在此断了一行，像是书写者顿了顿笔，才继续写——“斩断旧恩。”

顾青衍神色微凝。他从未听祖父提过“旧恩”二字。他继续读下去：“你手中白玉，乃旬若之物，是她入顾氏前从‘那边’带出来的路引。另一块在她手上。两块合一，可开一处秘藏。秘藏不在青桐，在——”

字迹在这里变得潦草，甚至有些颤抖，像是顾九章当时体力已经不支：“在落霞宗后山，老槐根脉尽头。你姑姑顾青蘅知道路。”

顾青衍心头猛地一沉。姑姑顾青蘅在夫家遇险，那是第四卷的事——如今她远在千里之外，青桐镇这边局势未靖，祖父却把这条线指向了她。

他稳住心神，继续看最后几行字：“你立谱之日，切记先续‘青玄’之名。他名字原本不在你的谱上，是我三十一年前强行写入。你若续他名，则杀劫自解；若不续，他不死，你必死。这是老朽留给你最大的恩怨。你莫恨我。”

顾青衍读完这最后一个字，纸上墨迹骤然暗去，第十页重新化为空白。他捏着卷轴的手微微发颤。他忽然想起当年顾九章立第七页时的情景，想起祖父把青玄的名字写入“旬墨”那行字下时的神情——那是顾九章一生中唯一一次，落笔前闭目良久，像是做了极大的决断。

“写了什么？”顾青玄站在一步之外，没有偷看，却注意到顾青衍读完后脸色变了。

顾青衍把卷轴合上，抬起头，看着他这位堂兄，那个三十一年前被祖父写入第七页的人，那个本是他的杀劫、却被祖父转为人质的人。他斟酌着开口：“青玄，你恨你爹吗？”

顾青玄似乎没想到他会这么问，沉默了一阵，才说：“我恨他关我柴房，恨他三十一年不肯叫娘的名字。但——”他顿了顿，“他不欠我命。”

“那你恨祖父吗？”

“不恨。”顾青玄答得干脆。他的目光越过顾青衍，看向供桌上那两块并排的物件，“我娘跟我说过，顾九章是这世上唯一一个，愿意替她挡刀的人。”

顾青衍闭了闭眼，终于解开了心中缠绕许久的那根线。祖父的杀劫不是青玄，而是通过写下青玄名来挡的劫；青玄之母旬若也不是敌人，而是被祖父救下的人。他没有再多想，将第十页的纸重新翻过，目光落在第九页末尾的空白处，那里将是他立谱时落笔的位置。

“我今晚立谱。”他说。

顾青玄抬头看着他，没有惊讶，只问了一句：“你要续谁的命？”

“你的。”

祠堂外，夜风穿堂而过，供桌上的那支旧笔忽然微微颤动了一下，像是也在等这一笔。

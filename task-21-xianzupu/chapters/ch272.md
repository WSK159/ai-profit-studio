# 第272章 雨夜来客

晨光刚爬上青桐镇的矮墙，顾青衍便听见了远处的雷声。

他站在祠堂门口，望着那一行灰衣老者消失的方向。镇外乌云翻涌，分明是晴日的天，却被那老者一句话搅得仿佛变了色。顾慎站在他身后，眉头紧锁：“那人走了？”

“走了。”顾青衍低头看了看掌心——方才他弹指灭血鸦时，指尖似被那灰衣老者看了一眼。那一眼中没有敌意，倒像是在审视什么。

他心头浮起一个念头。祖父牌位底座暗格里的遗信，信中那一句“斩墨即谱道分裂的影子”，若那灰衣老者真是斩墨的人，为何不直接动手？

顾慎沉声道：“族库失窃一事，我已让人排查了三个库房，只少了一方铜印。”

顾青衍猛地抬头：“铜印？是顾宁姑姑的那方？”

顾慎点头：“正是。”他顿了顿，盯着顾青衍的眼睛，“她在谱冢中留下印记时用过，我亲眼见过。那印上刻着——‘印在人在，印失人亡’。”

顾青衍心头一紧。信中所附铜环与那枚铜印，莫非是同源之物？他正想追问，忽听远处传来一阵急促的脚步声。

顾小满气喘吁吁地跑进祠堂院中，小脸煞白：“兄长！镇口来了个人，穿着破蓑衣，浑身是血，他说……他说他姓连。”

顾氏众人对视一眼。顾青衍二话不说，纵身掠出祠堂院门。镇口老槐树下，一个身形枯瘦的中年男子半跪于地，蓑衣上浸满暗红血迹，右臂似被什么从肩头撕扯而下，血迹沿着衣摆滴落黄泥，渗入青砖缝中。他抬起头，露出一张满是风霜的脸，眼神却亮得吓人。

“顾氏的谱官……终于见到了。”他咳出一口血沫，向顾青衍伸出手，掌中露出一枚漆黑的木牌，上刻“守墓”二字。

“连家守墓阁第八代传人，连铎。”他低声说，“连屏叔公让我来找你——谱冢，出了大乱子。”

顾青衍蹲下身，伸手按住他肩头一处伤口，灵气渡入稳住心脉：“谱冢怎么了？”

连铎咬了咬牙：“谱冢第三层……有一扇门开了。门后面走出来的东西，不是人，也不是魂。它长着顾九渊的脸，却说是来取谱的。”

顾青衍瞳孔骤缩。

顾九渊——祖父遗信中反复出现的名字，那个“非真名”的斩墨。若那人真是“谱道分裂的影子”，为何会从谱冢第三层走出？

他站起身，目光穿过镇口低低的屋檐，望向东北方连绵的群山。谱冢就在那座山腹中，他原以为三十年前的秘密都封在祖父的信笺里，如今才知道，那封信不过是一扇门，门后还藏着另一间密室。

“伤要紧吗？”他收回目光，低声问连铎。

连铎摇头：“皮肉伤，养几日就好。连屏叔公说，谱冢三层的‘门’是三十年前谱房血案当晚被秘法封住的——封门的人，就是上一任谱官自己。”

顾青衍心头一凛，一个名字几乎脱口而出：上一任谱官，连素秋——顾宁的母亲。

他看向祠堂方向，顾宁正站在廊下，手里攥着那枚金线断裂的印章，指节发白。她的目光落在连铎脸上，似乎想从他身上看到几分故人的影子。

顾青衍深吸一口气：“连铎，进屋说话。”

众人将连铎扶进偏厅，灌了热汤，又替他裹了伤。顾青衍命人关上房门，屋内只剩他与顾慎、顾宁、顾青玄四人。他取出祖父遗信，摊在连铎面前，指着其中一行：“你连家的守墓阁，可知道这‘门’是谁封的？”

连铎扫了一眼信上字迹，沉默良久，方道：“封门的笔迹，是顾九渊的。”

顾青衍一愣：“顾九渊？他不是……”他不是斩墨吗？斩墨封的门，又在谱冢中留下了什么？

连铎垂下眼：“三十年前，连素秋曾从谱冢带出一句话——‘门里的不是他，门外才是。’我当时年幼，不懂。如今想来，她说的可能是——”他抬头，盯着顾青衍的眼睛，“谱冢里的顾九渊，和外面的顾九渊，是同一个人，却也不是同一个人。”

窗外雨声骤起。晨光彻底被乌云吞没，一道惊雷劈落，照得偏厅内外一片惨白。

顾青衍缓缓握紧掌心的旧笔，笔杆上“天谱”二字微微发烫。他低头，只见笔身表面的木纹如脉搏般轻轻跳动，像是感应到了什么。

他忽然明白过来，谱冢第三层那扇门后，藏着的东西，和祖父留下的旧笔有关。也许，和“天谱”有关。

“顾叔，”他转向顾慎，“我明日便动身，去谱冢。”

顾慎盯着他看了许久，最终只说了三个字：“我陪你去。”

顾青衍点了点头。他正要开口安排族中事务，院外忽然传来一声异响——像是一根木杖，轻轻敲在了石阶上。

屋中人同时看向门外。

雨幕中，一个佝偻的身影立在祠堂院门之外。他打着灰布伞，伞沿低垂，遮住了大半张脸。那伞沿下的声音缓慢而苍老，却带着一股说不清的熟悉感：

“青衍小子，你的旧笔，是不是在发烫？”

顾青衍瞳孔猛然一震。

那声音——是灰衣老者。那个送信人。也是方才在镇外弹指灭血鸦后扬言“今日天晴，正好扫墓”的人。

他回来了。这一次，却站在顾氏祠堂的门前。

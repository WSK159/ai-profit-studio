# 第524章 守规之铃

灰袍老人一句话过后，整个沙地静得只剩下断笔的嗡鸣声。

顾青衍缓缓站起身，目光凝在老人脸上：“前辈究竟是谁？”

灰袍老人没答，他弯下腰，从地上捡起那截断了半截的笔杆——顾青衍刚从裂缝中取出又被按落的那一支。笔身上“顾山”二字在指间微微发亮，像是认了主人，又像是某种警告。

“顾山，是我爹。”灰袍老人说，“上一任守谱人，墨重之下第七代传人。”

顾青衍喉头微动。他细细打量老人，灰袍底下的脸满是褶皱，却在眉骨轮廓间隐约看得出几分与先前碑文相呼应的沉稳。他的目光落在老人手腕上——那里系着一枚锈迹斑斑的铜铃，与方才幻象中那人手边的一模一样。

“守规之铃。”顾青衍说。

灰袍老人微怔，继而苦笑：“你也看见他了。”

他抬起手腕，铜铃轻轻一颤，发出一声暗哑的响：“三十年前，我爹在这沙地里执笔，试图将斩墨重新封印回墨重碑中。他成功了一半——斩墨被锁进了碑底，但他自己也被卷了进去。‘求仁得仁’的代价，是整张脸都没入碑文里，成了碑上的一个名字。”

“所以顾山前辈的名字，不在顾氏族谱上，而在碑上？”顾青衍问。

“族谱上的顾山早已被划去。断谱人不会放过任何一个与墨重有关的后代。”灰袍老人的声音平静得如同讲一件旧事，“我把名字改成顾守规，守着这枚铃，也守着这道沙地入口——守了三十年，就是为了等一个能拿起‘天谱’旧笔的人来。可到现在我才明白，等来的不是救我爹的人，而是另一个踏上同一条路的人。”

顾青衍听出他话里的分量，攥紧旧笔：“前辈的意思是，我来这里……是斩墨设的局？”

“不。”顾守规摇头，“斩墨没有设局，它不需要设局。它只会等。每一个进入这间真笔室的人，都会碰见它——你碰见它的方式，决定它会咬得多深。顾九渊是直接捡起了斩墨本体，被它吞了半条命；我爹是试图封印它，被它锁进碑里；而你——”

老人顿了顿，目光落在顾青衍左眼下那枚新生的墨痕上：“你已经在不知不觉中，被它咬了一口。”

顾青衍心头一震。他抬手触到眼尾，那枚墨痕微微发烫，像一枚烧红的针尖。他此前一直以为那是血墨的反噬痕迹，如今听顾守规说出来，才觉出不妙。

“那枚墨痕，是斩墨的种。”顾守规说，“只要你的血墨一弱，它就会顺着血脉往下爬，爬到识海，爬到心口——直到你再也握不住笔。”

“可我的血墨还与旧笔相通。”顾青衍心念电转，“旧笔带着‘天谱’之力，能否将斩墨的种子逼出来？”

“很难。”顾守规叹息，“你旧笔里的灵性已经被斩墨察觉，二者像两张咬合在一起的齿轮，一动俱动。你逼墨，它便渗血；你歇笔，它便侵蚀。唯一的机会……是让你的血墨比斩墨更早找到自己的‘笔心’。”

“笔心？”

顾守规抬手一指暗河尽头的方向：“青桐果的金光，便是青桐老根的笔心。那是顾氏初代谱官从‘天谱’上撕下的一缕墨意，留在树根中养了几百年。你若能取到那缕墨意，以它炼化血墨，斩墨的种子便不攻自破。”

他的话一落，暗河尽头的金光仿佛应声般缓缓亮起，却带着一种瘆人的忽明忽暗，像是在挣扎，又像是在呼救。

“但你别高兴太早。”顾守规声音沉下，“金光亮起来，说明斩墨也感应到了。它在等你先动——你一动，它就会从碑底顺着你与旧笔的共鸣追过来。你要在它咬住你之前，把那缕墨意拿到手，再带回碑前，重新封死‘斩墨’。”

顾青衍沉默片刻，问：“前辈为什么告诉我这些？”

顾守规的目光落在他手里的旧笔上，声音低了许多：“因为三十年前，我爹在碑前留了一句话给我，让我等一个‘笔上带着家族气运’的人来。你的旧笔上，不止有顾九章的印记——还有你祖父、你姑姑、你堂兄……整个青桐顾氏的血脉气息。你身上背着的，是整个家族的气运。这种人，斩墨咬不死，它只会想换个壳子。我不能……让我爹的悲剧，在顾氏子弟身上再重演一遍。”

话音未落，碑底忽然震了一下。

两人同时望向石碑。碑面那些暗红的字迹开始扭曲，像有什么东西正在碑后用力推挤，要从石中涌出来。顾守规脸色骤变：“它醒了——你快走！”

“走？”顾青衍没有退，反而向前一步，“我若走了，它会不会跟出来？”

顾守规怔住。

顾青衍把旧笔插回怀中，又抽出腰间那支断了一半的“斩墨”漆黑笔杆，将两支笔并排横在胸前：“前辈，你有没有想过，斩墨等的不一定是来封印它的人——它等的，是能让它重见天日的笔。我若要取笔心，就必须让它误以为……我已经被它咬死了。”

顾守规瞳孔骤缩。他盯着顾青衍那双平静到反常的眼睛，正要说什么，碑底再次猛烈震动，一道漆黑墨线从碑缝中渗出，如蛇一般贴着地皮蜿蜒而来，直指顾青衍脚下。

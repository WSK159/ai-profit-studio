# 第126章 故人

亥时未到，夜市灯火正盛。顾青衍将符纸信收入袖中，余光扫过繁华街巷，卖灵糕的小贩、掌灯巡夜的散修、下棋饮酒的老者……浮云城看似安宁，却不知有多少双眼睛在暗处盯着他们。

“走。”顾青玄低声开口，年轻剑修的掌心已按在剑柄上，目光如鹰隼般扫过街尾。

顾小满却扯了扯顾青衍的袖子，小声问：“二哥，我们要去吗？”

城北枯井。四个字像一根刺，顾青衍知道，这多半是陷阱，但若顾墨真的藏身城中，他不能不去。祖父临终前那句“你姑姑还活着”一直压在他心头。可姑姑怎么会和雾中人搅在一处？

“去。”他答得干脆，“但不是我一个人去。”

片刻后，三人穿过几条窄巷，在城北一座荒废的老宅前停下。围墙坍塌半面，院中杂草高过膝，一口青石井圈孤零零立在月光下，井口覆着一层薄薄的蛛网。顾青衍蹲下看了看井沿——灰尘上的掌印是新的，五指向内，像是有人攀着井口爬上来过。

“有人。”顾青玄拔剑半寸，剑锋在鞘中发出清吟，“井底有人呼吸。”

顾青衍屏息，双手贴上井沿，掌心的旧笔印记微微发热。他闭目感知，命数之线在视野中如同蛛网铺开——井底深处，一团灰暗的光影蜷缩着，像一截被剪断的烛芯，忽明忽暗，随时都会熄灭。

一个声音从井下传上来，沙哑而熟悉，像被沙砾磨过千万遍：

“青衍……是你吗？”

顾青衍浑身一僵。这声音他听过——小时候姑姑抱着他念《青桐诀》的调子，就是这个音调。可他从没听过这个声音像现在这样……破碎如败絮。

“姑姑？！”

他几乎没多想就翻身跃下井口。灵光护体，双脚落在三丈深的井底淤泥中，前方湿冷的石壁上贴着一道身影。那人浑身是血，一身早已看不出本色的蓝袍被撕得稀烂，左手齐腕断去，伤口用一块暗青色的布死死勒住，布上浸透的血液已经干涸结痂。那张脸被乱发遮了大半，但露出的半侧轮廓——眉骨、鼻梁、嘴角那道陈年旧疤——正是顾青蘅。

“你受伤了！我带你上去。”顾青衍上前就要扶她，却被顾青蘅猛地攥住手腕，力道大得惊人，完全不像是重伤之人。

她抬起头，眼中燃着幽碧色的火：“不要上去。青衍，听我说——井上有‘听风线’，你脚下踏着的东西一旦离井，断谱针就会循着血味追上。我在这里躲了三天，就是为了等你。”

顾青衍瞳孔骤缩：“断谱针？你身上有断谱针？”

顾青蘅松开手，从腰间掏出一物——那是一截漆黑如墨的钢针，约莫三寸长，针身上刻着密密麻麻的微小纹路，像是一段被压缩成针的梵文咒语。针尖上悬着一滴血珠，凝而不落。

“我在林家祠堂底下找到的。他们把这东西藏在先祖牌位下的密匣里，上面封着三重禁制。我破禁的时候被人发现，断了一只手。”她声音平静得不像在说自己，“但值得——这枚针上，刻着顾氏谱上七个名字。”

顾青衍低头去看那针身上的微纹，掌心旧笔印记剧烈跳动起来，像遇见了天敌。他忽然明白了一件事：“断谱针不是斩断气运，而是……从族谱上‘勾’走名字，把人的命数抽出去？”

顾青蘅惨笑：“你知道得太晚了。三十年前，你爷爷的弟弟顾九行——上一任谱官——就是被这枚针勾走的。林家那老贼以为是他们偷到了好宝贝，却不知道这针原来是顾家的。”

“什么？”顾青衍声音发颤。

“顾家从来就不是末流家族。”顾青蘅一字一顿，“我们是从中州迁来东荒的。三十年前那场内斗，顾家九房死了五房，剩下的四房逃到东荒，隐姓埋名。这枚断谱针本该封存于顾家祠堂最深处——可有人把它偷了出来，卖给了林家。”

她顿了一下，目光落在顾青衍腰间的旧笔上：“你爷爷当年把这支笔传给顾九行，顾九行死后，你爷爷又收回。笔杆上刻的‘天谱’二字，你还记得吗？”

顾青衍下意识摸了摸笔杆。那两个字他描过无数次，笔画苍劲如刀削斧凿。

“那不是‘天谱’两个字的意思。”顾青蘅一字一字道，“那是‘天谱’的下联——笔杆背面还有两个字，你翻过来看。”

顾青衍将笔翻面，借着井底微光去看——笔杆背面确实还有一行极小的字，他以前从未注意过。

“地谱。”

“对。”顾青蘅的声音低了下来，“天谱在上，地谱在下。你手上这支笔……是地谱之笔。断谱针是它的另一半。笔与针合一，才能动真正的族谱。”

顾青衍正要开口，井口上方忽然传来顾青玄的厉喝：“谁在那里！”

紧接着是金属碰撞之声、利刃破空声、以及顾小满一声惊叫。

顾青蘅猛地攥住顾青衍手腕，眼中燃起一丝慌乱：“来了。他找到我了。”

“谁？”

“给你写信的那个人。他说他叫洛维明。”顾青蘅的嘴角勾起一个讥诮的弧度，“可他不叫这个名字。三十年前他叫顾九城，是你爷爷的第三个儿子——我的三哥，也是把断谱针卖给林家、害死顾九行的那个叛徒。”

井外传来一声轻笑，隔着三丈深土，像一条蛇从黑暗中游出：“小妹，你说错了一件事——三十年前我是卖给林家，可我今天，是来把它拿回去的。”

顾青衍掌心旧笔剧烈发烫，仿佛听见了一丝微弱的、来自血脉深处的呼应。

# 第432章 墙中月

顾青衍在墙前站了整整一炷香。那行字迹已经平息，墨痕隐入墙面，仿佛从未出现过。他伸手触墙面，指腹下一片冰凉，什么也探不到了。但母亲“未死”那四个字像一根铁钉，牢牢扎在他心口上。

“父亲，”他回头，“母亲当年……你们是怎么确认她过世的？”

顾慎缓慢地吸了口气。这个问题显然触到了他心里最深的地方，他的嘴唇抿了抿，最终说道：“那一年我离开青桐去东荒边境寻她的下落，找到的是一具被妖兽撕去半边的躯骸，身量容貌都和你母亲一样。身上的青竹腰带、宗门令牌都是她随身之物。”他顿了顿，“这三十年，我偶尔会想……那具躯骸会不会只是个替代品。但我没有证据。”

顾青衍默然片刻：“那枚玉牌，父亲见过吗？”

“她从不离身。”顾慎说着，眼中多了一丝异样的光芒，“有一次夜半惊醒，我看见她对着窗台摩挲那枚玉牌，轻轻说了一句话：‘等月圆的那天，答案自然来。’后来我再问，她只是摇头。”

顾青衍心头一跳。今天是几号？他下意识算了算——阴历六月十五，月圆之夜。

走出藏物间时，月色已经升到了青桐树梢，一轮浑圆的明月悬在夜空中央，白得像一块玉盘。顾青衍抬起头，月光照在指根印记上泛着幽蓝的光，像是有什么东西正在被激活。

“墨介，今日是六月十五。”

墨介一愣，随即面色一变：“你母亲说的月圆……？”

话没说完，祠堂内传来一声沉闷的声响，像是什么巨大的东西被撞了一下。两人对视一眼，顾青衍推门走进祠堂。祠堂内的香案上排着一排祖先牌位，正中那面墙上的顾氏族谱画卷——就是当年他第一次“看见”命数的那幅画——不知何时自行卷起了一半，露出墙面上一个不甚清晰的轮廓。

那是一个腰圆大小的凹陷，像被一道月光精准地投在此处。顾青衍站进那道月光里，月光照在他胸口的青竹笔上，笔杆发出细微的嗡鸣。同时，他指根处断谱针印记猛地亮起，一道墨线从指尖射出，直直打在墙面的凹陷正中央。

“咔”的一声轻响，墙面像是莲花一样悄然绽开一条裂隙。顾青衍走上前，从裂隙中取出一件东西——一个巴掌大的铜匣，通身被朱砂封条缠满，封条上字迹密密麻麻，是极其工整的蝇头小楷。顾青衍认出来了，那是他母亲的字迹。

他小心翼翼地拆开封条。铜匣打开，里面只有一张纸条和一片碎玉。纸条展开来，只有三行字：

“斩墨是谁，你要自己找。墨介代青玄与你同去，但青玄命数已被人填了一笔，续谱时勿再动他。青桐树下第三根枝，埋着一卷你祖父写给你的信，非月圆不见。”

顾青衍将纸条反复看了三遍，目光落在最后那句上。祖父写给他的信？顾九章临终前并未留任何东西，他怎么也想不到，祖父会在青桐树下埋过一卷信，而且要非月圆之夜才能取出。他走出祠堂，看着青桐树伸展的枝干，从第三根枝的位置向下默数三步，蹲下身，用青竹笔划开泥土。挖到半尺深时，笔尖碰到了一卷竹简。

竹简表面裹着一层青苔，剥开来看，是细密的小字。顾九章的字迹。顾青衍打开竹简，开头一句便是：“衍儿，见信如晤。若你此刻读到它，说明那位故人已归来。九川——你叔公，当年断谱离开顾家，并非恨我，而是恨我明知斩墨是谁却不肯动笔。”

顾青衍手微微一颤。祖父果然知道斩墨的身份！他继续往下看：“斩墨并非一人。墨袍只是一个皮囊，真正执墨者，是你们身边之人。我死后第三十三年，那人会在月圆之夜现身于青桐树下。你若信我，切莫在祠堂与他动手。去你母亲当年摘青桐花的地方——那一处山坡上有一块空心石，里面压着斩墨真正身份的答案。”

信末，顾九章写了一句风马牛不相及的话：“替我给小满带一颗桂花糖。”

顾青衍合上竹简，久久不语。墨介站在两步外，听他把信的内容低述完，顿时眉头深锁：“今夜就是月圆之夜。如果九章公说的没错，那人今夜会来青桐树下。我们现在该去哪个方向？祠堂还是在坡上？”

顾青衍抬头看了一眼月色。月亮已经很偏西了，他估算着离子时不过半个时辰。他攥紧竹简：“去山坡。祖父不会无端让我绕路。而祠堂这边——”

话音未落，青桐镇东头忽然爆出一道惨白的亮光，紧接着是一声尖锐的金铁鸣响，那是护族大阵被外力触发的警讯！顾青衍脸色一变，他感应到了什么：某股气息正从东头径直朝祠堂方向走来，速度并不快，却带着一种不可阻挡的凛冽。

他吸了口气，将竹简塞进怀中：“你留在祠堂，若有异动以符为号。我去山坡，取完东西就来。”

墨介点了点头，按住袖中符纸。顾青衍没再犹豫，身形一纵跃出祠堂矮墙，朝母亲当年摘青桐花的西坡掠去。身后，那声金铁鸣响又一次响起，这一次更加洪亮，镇东头的天空亮起一朵半青半红的信号烟。

那烟的颜色，像极了一个“墨”字。

顾青衍没有回头。

山坡上，月光铺满了一片野青桐林。他循着记忆走到坡顶，果然看见一块半人高的青石。他探手进去，摸到一块布包。拆开来，里面只有一样东西——半枚青灰色的令牌，背面刻着一个字：“墨”。正面，却被一分为二切去了一半。而在半枚令牌的边角，他用指尖摸到一道细小的裂纹，裂纹里夹着一丝暗红色的碎线，看纹路……像是从一件顾氏制式的衣袍上撕下来的。

顾青衍猛地攥紧令牌，指骨上断谱针的印记在这一刻疯狂地跳动着，像是一口钟撞响在胸腔里。他终于在脑海中拼出那副一直模糊不清的脸——记忆中那个站在祠堂阴影里的灰袍人，抬手时衣摆晃动，露出腰际一块令牌。那令牌的样子与现在他手中这半枚，严丝合缝。

而那块令牌原本的另一半——他清清楚楚地记得，三个月前顾慎书房案头摆着的镇纸上，刻着一模一样的纹路。顾家长子，现任族长顾慎，手边那方青铜镇纸……

就是这枚断谱令牌的另一半。

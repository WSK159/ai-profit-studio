# 第143章 血脉为钥

铁片躺在顾墨掌心，锈迹下的“玄”字在月光下泛着青黑的光。顾青衍伸手去接，指尖刚碰到铁片，一股极细的寒意便顺着指骨往上窜，像一根冰针扎进了眉心。他眼前黑了半息——再睁开时，驿站前的景物变了。

老槐树的影子被拉得极长，树冠上缠绕着一缕缕灰色的气，像被风吹散的炊烟。再往远处看，浮云城的方向悬着一道极淡的裂痕，从天空垂到地面，仿佛有人在天地间划了一刀。

“阿兄？”小满的声音从身后传来，带着不安，“你盯着天上看什么？”

顾青衍闭了闭眼，再睁开，幻象已经消失了。他垂下目光，把铁片握在掌心，那种冰凉的感觉还没散尽。他低头看了看铁片边缘——上面有一道极其细小的刻痕，像是一截藤蔓的末端。和顾氏族谱上那些命数藤蔓的走向一模一样。

“顾叔，这铁片是从哪来的？”

“你爹从谱籍阁带回来的。”顾墨说，“他说地下有一扇门，门锁是铁铸的，锁孔只认顾家人的血脉。”

话音落下，驿站里安静得能听见油灯芯上的噼啪声。洛维明靠在门框上，眉头微微皱起：“认血脉之门，这已是宗族级的谱禁。玄天门虽设有谱籍阁，但阁内若镇着这样一座门，绝非泛泛之地。顾叔，你确定这是顾家人该进的地方？”

顾墨没有正面回答。他沉默片刻，说了一句更让人心惊的话：“三十年前，谱籍阁血案之后，玄天门把地下三层全部封闭。不是怕里面的东西跑出来，而是怕外面的东西进去，把底下的东西取走。”

“你们家那位上一任谱官，当年入阁时曾留下过一句话——”顾墨抬起眼，“他说：‘若顾氏有人握着那枚铁片走到谱籍阁门口，便是该接笔的时候了。’”

顾青衍攥紧铁片。

接笔。从小到大，他只听过祖父传谱，父亲守谱，从没听过“接笔”二字。下一瞬，他猛地想到一个可怕的念头：“顾叔，我祖父当年传给我的那支旧笔……”

“笔杆上刻着‘天谱’二字，对吧？”顾墨接口道，“那支笔，就是你爹在谱籍阁地下找到的。他带出来交给九章，九章又传给了你。”

顾青衍站在原地，像是被人一盆冷水从头浇到脚。他想起祠堂翻谱那夜，祖父把旧笔放在他手里时说的那句话——“从今以后，顾氏一族的命，就攥在你手里了。”他当时只以为是祖父临危受命，如今才知道，那支笔本就是顾慎从那个被封锁的地下带回的东西。

“那我们去了谱籍阁，就能知道上一任谱官的死因？”小满轻声问。

顾墨没有摇头，也没有点头。他偏过头，看向驿站外那条通往北方的大道，道：“你们若是真要去，那我再告诉你们一件事——守谱人分裂派的暗线传了消息来，说谱籍阁地下三层最近半个月入过一批人。”

“谁？”

“玄天门谱籍阁阁主，秦百川。”顾墨顿了顿，“他在底下待了七天。出来的时候，少了一根手指。”

风从北方吹来，吹得老槐树哗哗作响。顾青衍攥着那枚铁片，抬头望向玄天门的方向——远方的天际似乎笼着一层淡淡的青黑，像被人泼了一砚浓墨。

小满把背上的干粮袋紧了紧，低声问：“阿兄，我们现在就动身？”

顾青衍将那枚铁片收进怀里，贴着心口的位置。他感觉得到，那支旧笔正在袖中微微发烫，像是也在回应着什么。

“动身。”他说，“去谱籍阁。”

# 第367章 笔尖上的一滴墨

那滴墨挂在笔尖上，悬而不落，在烛光下泛着暗红的光泽。

顾青衍没有立刻去拿。他想起祖父传笔那日，顾九章把旧笔交到他手里时说的第一句话：“笔在人在，笔断人亡。”之后他才发现，旧笔的笔杆上沿着一道细纹，像是曾经被人用力摔在硬物上留下的裂痕。他当时以为是年久磨损，此刻看见这支完整的笔才明白——那道裂纹，是祖父活着的时候自己撞的。

“笔断了，人才算真的死了。”顾长歌不知何时走到了他身边，声音压得极低，像在说一件很久远的事，“你祖父把那支笔传给你的时候，断过的笔重新长出裂纹，说明他替你扛过了一劫——你自己不知道而已，那裂纹里封着三道斩谱印。”

顾青衍握着旧笔的手一紧。

顾长歌走到木匣前，弯腰，把匣中那支完整的“天谱”笔拿起来。他握笔的姿势很轻，像是握着一片薄冰，指节略微颤抖。那滴血墨在他食指上方悬了几息，无声落进笔尖。

“你祖父当年不是没有机会入谱——是他不敢。”顾长歌把笔端倒转过来，笔杆尾端露出一道极细的旋纹，“第七代谱官的身份在书页里显形之后，写谱之人会变成整个断谱人的靶子。你祖父把自己藏进‘旁支庶子传人’的身份里，藏了一辈子。他宁可让顾氏被人当成末流家族，也不肯写出自己的真名。”

“那第七代谱官，究竟是谁？”

顾长歌沉默了。他抬眼看着顾青衍，目光里忽然多了一点复杂的东西，像潭水底下的暗流：“你自己。”

祠堂里静得能听见檐角残雪融化的声音。

“我出生那夜，替我把名字写进书里的人——

“是你。”

顾长歌没有否认。也没有承认。他只是把那支“天谱”笔递到顾青衍面前：“笔已经等了你十六年。顾九章把它藏在井底石门里，是不想让你在羽翼未丰时被斩墨找到。现在你既然已经翻开装人之书，又读到了第七页那句‘已除’——你已经可以在书中写下一笔了。”

顾青衍看着面前的笔，指尖在宽袖里攥紧了。

“写谁？”

“你心里已经有人选了。”

顾青衍闭了一下眼。眼前浮现的是顾小满的笑脸，扎着双髻，蹲在药圃边上，用手背擦着额头的汗，回头喊他“哥哥”。他从记事起就带着小满玩，小满三岁那年发了一场高热，全族都以为她撑不过去，是他夜里一遍遍念着“小满，小满”，把小满从鬼门关前拉了回来。可是后来，小满的命格里总像缺了一道什么——

青衍想起井底书页上第四页的名字。顾小满。入书第九页。入书之命，只有等书中人自己走出来。

“我要让小满从书里走出来。”顾青衍说。

顾长歌笑了，那笑意里带着一丝不易察觉的悲悯：“你选中她了。”

“对。”青衍伸手，接过那支“天谱”笔。笔杆入手的刹那，他感到腕骨深处传来一阵蚁行般的痒痛，像是有什么东西顺着血脉在往指尖爬。他稳住呼吸，翻到装人之书第九页。顾小满的名字静静地落在页面上，墨色很淡，像是随时会被风吹散似的。旁边一行蝇头小字，他之前没有注意到——

“福星之命，不入常谱；心有所寄，乃可启行。”

顾青衍的笔尖落在那行字上，悬了极久。他忽然明白了：小满的命格从来没有被抹去，而是被装人之书锁在了第九页。要让她走出来，不能靠写——只能靠某个人，用自己的命与她的命结在一起，她才能借那道线爬出书页。

“代价呢？”他问。

顾长歌说：“你可以选择不写。她还能撑几十年。”

顾青衍想了想，又笑了笑。他想起顾小满从井边跑过来喊他吃饭的样子，想起她半夜给他掖被子的小手。他低头，笔尖落在第九页上，一笔一划地，在顾小满名字旁边写下自己的名字。

墨迹入纸的一瞬，整支“天谱”笔骤然烫了起来。祠堂里所有灵位齐齐震响，像是百十个声音在同一刻倒吸了一口凉气。顾青衍感到一股巨大的力量从笔柄里涌出，撞进他的胸口，他弯下腰，一口血喷在书页上。

血溅在纸面上，却没有污损字迹。顾小满的名字缓缓亮起，像一盏终于被点燃的灯。祠堂外，井口方向忽然传来一声极轻的人声——“哥哥？”

顾小满的声音。她醒了。她从书页里走出来了。

顾青衍抬起头，满脸的血也没擦，露出一个笑。

而在他身后，顾长歌垂眼看着手中的青桐籽，籽壳内部那道“斩墨”二字，正在无人察觉间，一点一点地变淡。

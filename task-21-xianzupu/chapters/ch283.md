# 第283章 残针引路

那声音散去后，顾青衍掌心灼烧感渐退，却留下一道暗红色的针尖痕迹，像一枚烙印，嵌在原本的“衍”字印记旁。顾青玄盯着那只手，面色微变：“你的手——”

“没事。”顾青衍合拢五指，将残针收入袖中，转向连素秋，“连掌事，你亲自走这一趟，不只是传东西吧？”

连素秋的目光在顾青衍掌心上停留片刻，缓缓点头：“谱冢第三层的门，三十年前曾开过一次。”

“三十年前？”顾青玄猛地抬头，“可是谱房血案那夜？”

连素秋似乎没料到他反应这般激烈，瘦削的脸颊微微抽动一下：“你顾家的旧事，我连家不该多口。但我守守墓阁三十载，从未见过谱冢的门自己从里面松动。那缕墨痕渗出来，在石壁上凝了三天，凝出你顾谱官名字的一个字——我才敢寻过来。”

顾青玄追问：“那门内到底是谁在说话？”

连素秋沉默了。

顾青衍替她开口：“你不知道，还是不能答？”

“我不能答。”连素秋露出一个疲惫的笑，“守谱人的规矩，比谱官的规矩更严。不涉己命，不泄他秘。我能说的，只有这一枚残针——和一件事。”

她从袖中又取出一张泛黄的纸笺，折得极小，递到顾青衍手中：“这是三十年前谱房血案第二日，有人放在守墓阁门口的。我压了三十年，今日带给顾谱官，算还你上次在谱冢中的人情。”

顾青衍展开纸笺。纸面发脆，墨迹已泛黄，却一笔一划清晰如刻。上面只写着一行字：

“顾氏谱上三页，一页在笔，一页在手，一页在门后。门开之日，旧笔认主。”

字迹方正，收笔处有一个极细的弧，和他祖父顾九章的笔迹几乎一模一样——但落款却空着，没有名字。

顾青衍指尖微微发颤。笔画认主，门后之日，这么说那残针不是杀他的——是引他去的。

“琴言峰离沧浪峰多远？”他问。

连素秋一愣：“谱冢在琴言峰北麓，离沧浪峰隔两座山梁，脚程半日。”

顾青衍看了顾青玄一眼。沧浪峰的谱籍阁之约，三日内要赴；而琴言峰的谱冢之门，却正在此刻打开。两件事撞到了一处。

顾青玄似乎读懂了他的犹豫：“你先去谱冢，我去沧浪峰。”

“你一个人？”

“我不是一个人。”顾青玄拍了拍背负的长剑，“剑修的路，从来是一个人走的。何况你欠我一场真相——我爹的名字为何在谱上留了三天，答案多半就在那扇门后。”

顾青衍看着他，突然觉出这个堂兄的变化。从前那个心魔缠身、暴躁易怒的剑修，此刻眉眼间多了一种沉静——像一把剑被磨去了锈，露出底下久藏的锋芒。

“好。”顾青衍点头，“沧浪峰那边，杜若墟要的谱卷，我还没写。”

顾青玄难得地笑了一下：“你写你的谱，我去赴我的约。你要活着回来补上那一笔。”

他说完转身就走，衣袂翻飞间已是数丈之外。顾青衍望着那道背影消失在林间，忽然感到一丝异样——顾青玄方才那句话，和梦中的情形像极了。他即将写下的第一百零八字，是否就在沧浪峰的那一端等着？

“顾谱官？”连素秋的声音拉回他的思绪。

“走吧。”顾青衍定了定神，“去琴言峰。”

两人沿山道折向西，穿过一片低垂的雾松林，暮色渐沉时已能看见琴言峰北麓的影子。连素秋在谱冢入口处止步，推开门让顾青衍进去，又拉住门环深深看他一眼：“门内的东西若问你要什么——别答应。”

“为什么？”

“三十年前问过你的人，到现在还没应。”连素秋松开手，退回暮色里，“他如今还在门内等着下一个能应他的人。”

石门轰然合上，顾青衍站在一段下行的石阶顶上，手中残针骤然发热，针尖指向黑暗深处，仿佛牵着一根看不见的线。他深吸一口气，握紧旧笔，朝黑暗中走去。

脚步声在石廊中久久回荡。掌心的“衍”字印记和那枚针尖烙印同时亮起，像两盏微灯，照亮前方石壁上渐渐显现的一道门缝——门缝中渗出一缕墨，墨色在空中缓缓展开，凝成一个他从未见过却莫名熟悉的字：

“归。”

顾青衍顿住脚步，喉咙发紧。那是祖父顾九章的手笔，他认得出——每一个瘦硬的笔画都像遗言。

# 第460章 祠堂里的空供桌

夜色落下时，青桐镇的灯火稀稀拉拉地亮着。

顾青衍没有走正门，他带着陆沉从后山翻入，绕过守夜的两名旁支弟子，贴着祠堂后墙贴地而行。祠堂里供着青桐木雕的祖宗牌位，香火常年不断，但在今晚，那缕细烟却是灭的。

他推门的手微微一顿——门闩没有插，从里面被人拔开了。

顾青衍侧身入内，陆沉横剑守在门外。堂内昏黑一片，唯有月光从檐下漏进来，将供桌上的轮廓拉成一道歪斜的长影。供桌上空空荡荡，原先摆着的三牲果品都不在了，连香炉都被人翻倒，炉灰洒了半张桌面。

顾青衍的心一沉。他快步绕到供桌后方，蹲下去摸那张旧供桌的底面——指腹触到一道刻痕。他松了口气，刻痕还在。但随即，他的手指僵住了。

刻痕的边缘是湿的。他缩回手，借着月光看，指尖沾了薄薄一层暗红液体，在夜风里散发出一股铁锈味。是血，还是新鲜的血。

有人在刻痕上抹了一层血。

他慢慢站起身，目光落在供桌的暗龛处——那枚帛书轮廓刻痕对应的暗龛，被他祖父以谱道封纹锁住，非顾氏嫡血不可开启。但现在，封纹的纹路被人生生撕开一道口子，像被人用指刀沿着纹路反方向剐了一遍。

暗龛里空无一物。

帛书的下半卷不在里面。

“你找了不该找的东西。”一个声音从祠堂梁上传来。

顾青衍猛地抬头。梁上坐着一个黑衣人，斗笠压得很低，看不清面容，但腰间别着一枚青黑色的物事——断谱针。针尖上悬着一滴血珠，正缓缓滴落。

“断谱人。”顾青衍的声音很淡，像在说一件早已知晓的事，“你们在雾谷引我走，就是为了来我顾氏祠堂偷帛书？”

“偷？”黑衣人嗤笑出声，“帛书本来就是我们的。你祖父三十年前从我们手里抢走它，如今不过是物归原主。”他顿了顿，从怀中取出一样东西，在月光下晃了晃——正是帛书下半卷，卷轴边缘还沾着新血，“你要这小满丫头的命，还是要这卷帛书？选一个。”

顾青衍没有看那帛书。他的目光停在黑衣人腰间那枚断谱针上——针尖的血滴不是别人的，是顾小满的血。因为他从小满出生那年起，每年生辰都会悄悄在她指腹上滴一滴自己的血，以谱道烙印她的命线，作为护持。此刻那道命线剧烈震颤，却是被断谱针压得死死的。

“我不选。”顾青衍说。

他抬起右手，中指指腹的叶形印痕在月光下亮起一层青芒，整座祠堂的地面忽然浮现出密密麻麻的纹路——那是祖父顾九章当年布下的护谱大阵的残纹，虽然早已残缺，但在他的谱道之力催引下，仍如枯木逢春般一寸寸亮起来。

黑衣人神色一变：“你疯了，这个大阵是要用血养的——”话音未落，顾青衍已咬破左手中指，将血滴在供桌的刻痕上。整座祠堂嗡然一颤，无数光线自地面升起，像千百条血色藤须同时睁开了眼。

“谱道，以我身续。”顾青衍一字一字念出，“青桐顾氏第三代谱官，今启旧阵，缚敌锁命！”

血色藤须化作千百道长鞭，朝梁上黑衣人缠卷而去。黑衣人低骂一声，拔断谱针反手斩断数道藤须，但更多藤须瞬间扑上，将他右手手腕缠死。断谱针脱手落地，滚了两圈，停在顾青衍脚前。

顾青衍弯腰拾起那枚断谱针，针尖上的血珠在月光下微微发亮。他举到眼前看——那颗血珠里，映出的不是他自己的影子，而是一张苍老的面孔。

“你……”黑衣人的声音忽然变了，不再是方才的冷戾，而是透着一丝哑，“你看见了？”

顾青衍没有回答。他慢慢转动针尖，让血珠里的面孔逐渐清晰——那是一张他见过的脸，就在族谱的末页，那个没有批语的名字上。

“顾行舟。”他低声念出这个名字，抬眼望着黑衣人，“是你。”

祠堂外的风突然停了。黑衣人僵在梁上，斗笠被风掀落在地，露出一张布满刀疤的脸——但那双眼睛，与族谱末页上的顾行舟画像一模一样。

“你明明死了三十年了。”顾青衍的声音没有起伏，“你怎么活到今天的？”

黑衣人没有回答。他只是缓缓笑起来，笑容像一道被撕开的旧伤口：“谱官，你猜猜看——你祖父传给你的那支旧笔，真正的笔芯是用什么做的？”他盯着顾青衍握笔的手，“你用了这么久的笔，就没有一次觉得……笔杆上那条‘天谱’二字，像极了活人的皮？”

顾青衍的手微微一顿。

祠堂外，陆沉的声音骤然传来：“有人进来了，三个人，从后院方向——”

顾青衍低头看那枚断谱针。针尖血珠里那张面孔缓缓闭上了眼。而供桌暗龛的空洞中，不知何时落下一片青桐叶，叶面上写着：

“续谱者，饮其血。”

他抬起头时，黑衣人已不在梁上。祠堂的门缝里灌进一阵凉风，风中卷着一缕极淡的叹息——和他在雾谷深处听到的那一缕，一模一样。

而他的掌心，血色藤须已经爬到腕口，正中那枚叶形印痕的边缘，正裂开一道细缝。缝里渗出的，不是血，是墨。

# 第322章 井口之局

井壁湿滑如蛇皮，顾青衍一手攥着帛纸画，一手攀住凸起的岩棱，耳边是众人密集的喘息。头顶传来沉闷的撞击声——一下，又一下，像有什么东西正从井口往下压，要把这唯一的出口碾碎。

“快！”顾青玄的声音从上方传来，带着剑气呼啸的余韵，“我斩了三次，那东西斩不断！”

顾青衍抬头，只见一线天光被一团漆黑遮蔽，那东西像一块活着的墨——不，更像是一张巨大的、卷曲的纸，正缓缓向下卷动，每降一寸，井壁的苔藓便成片枯萎。他的掌心微烫，那枚乌木印在怀中轻轻跳动，像在示警。

“井口被人封了。”连若星的声音从身后传来，清冷中透着一丝凝重，“是‘谱封’——有人以谱道之力封住此井，非阵非术，是‘裁纸’之法。”

“裁纸？”守经老人咳了一声，他正扶着顾远湖从石阶上快步赶来，脸色灰败，“谱道有‘裁纸’一说——以他人族谱为纸，剪其气运为封。此井被裁入某家的谱中，成了一页‘死纸’。”

顾青衍心头一沉。裁纸之法，他只在祖父留下的笔记夹层中见过寥寥数语：施术者须持有被裁之地的“地脉名目”，如今这井被封，说明有人早就知道他们会来，甚至算准了他们会在此时撤离。

“走西壁裂隙！”顾青衍当机立断。

顾青玄落在最后，一剑青芒横扫，将头顶那团墨纸逼退数尺，随即翻身跃下，剑尖在地面一点，借力向西掠去。众人鱼贯而入西壁裂隙，那裂缝只容一人侧身而过，岩石粗糙如牙，刮得衣袍碎裂。顾青衍侧身挤入时，回头一望——只见那团墨纸已经封住了整个井口，发出一声极轻的“嗤”声，像一只无形的手将一页纸按平在井沿上。

然后，墨纸上浮现出一行字。

顾青衍的瞳孔骤缩。那字迹楷中带斜，笔锋如刀——是断谱人的笔法。那行字写的是：

“棋局未终，白子当死。”

他来不及多想，已被顾青玄一把拽入裂隙。岩石在身后闭合，井底石室彻底沉入黑暗。

裂隙极长。地势先是向上，继而陡降，脚下碎石滚落，回声遥遥。走了约莫一刻钟，前方透出一点微光。守经老人率先探出头去，只见裂隙尽头是一处深埋地下的暗河河床，水已干涸，只余卵石与细沙。河床尽头，一道石阶向上延伸，阶上覆着厚厚的灰土，却有两行脚印——一行新鲜，一行陈旧。

“新鲜的是我们的。”顾远湖蹲下看了看，皱眉，“但陈旧的那行……鞋印比我们所有人都大，足尖朝上，像是从井底走出来的。”

顾青衍心头微动。从井底走出来？那井底石室他们已彻底搜过，除棋盘暗格外别无通道。那这个从井底走出来的人，是在他们之前就藏在那里？还是说——

“他进了棋盘？”连若星低声道。

众人沉默。棋盘上的黑子白子犹在眼前，那些子不是摆设，而是某种因果的具象化。如果那个人进了棋盘，那他此刻在哪里？是黑子中的一枚，还是……

顾青衍压下杂念，率先踏上石阶。台阶尽头是一扇木门，门板腐朽如泥，轻轻一推便碎成粉末。门后是一片荒废的菜园，杂草高及腰身，远处是连绵的矮丘，正午的日光白晃晃地照下来——这里已是青桐镇外，南坡旧宅的废墟之后。

顾青衍眯眼望向镇子方向，却见炊烟袅袅，镇中并无异样。仿佛井底的墨纸、石室的棋盘，都是另一个世界的事。

但所有人都记得那行字：棋局未终，白子当死。

“白子当死……”顾青衍喃喃。棋盘上白子只有三枚，对应三条路。如今井口被封，白子已死一枚。剩下两枚——西壁裂隙与活泉。他们走的是西壁裂隙。那么活泉之路呢？

他低头看向掌心那枚乌木印。印侧不知何时多了一道细痕，金丝般的光正沿着乌木纹路缓缓流动。他记得清楚，这枚印在祖父手中时，绝无此痕。

“青衍。”守经老人走近，压低声音，“那帛纸画，你再细看看——背面。”顾青衍翻过帛纸。原本空白的背面，此刻竟浮出一行浅金色的字迹——不是墨，似以指力刻入，又因水汽而显。那字迹与石室棋盘边缘的“守者非为守”一模一样：

“白子不死，黑子不活。”

那行字下方，还有半枚指印，轮廓模糊，却与空书末页的指腹凹痕轮廓如出一辙。顾青衍的目光落在指印弯弧处——那弧线极深，像那人按印时用了全力，而指印外侧有一道细痕，被指甲掐出来的，深及真皮层。

那是他父亲顾九章的习惯。早在顾青衍幼年时，父亲写字盖印之后，总会在印泥未干处用拇指甲掐一道痕，说是“怕印不牢”。

“这是我爹的指印。”他低声说。

众人愕然。顾远湖上前一步，盯着那半枚指印，嘴唇翕动了几下，忽然哑声道：“青衍……你爹当年被逐出顾氏，是有原因的。”

“什么原因？”

“他偷过谱。”顾远湖的声音像从齿缝里挤出来的，“三十年前，谱房血案之后，你爹曾进过谱房。第二天，谱中便少了一页。”最后一页，是给谁看的？

他的目光落在那半枚指印上。父亲若真的偷了那一页——那是为了什么？

“找活泉。”他忽然说，“井口被封，白子只剩活泉一条路。若棋局当真，活泉必然通到某个关键的地方。”他顿了顿，目光扫过众人，“今夜不入镇。活泉的入口，在青桐镇北的桐林泉眼。”

连若星眉心微动：“桐林泉眼——那不是顾小满小时候溺水的地方？”

“是。”顾青衍的拇指微微收紧，指尖抵住掌心那道墨线，“她在那里溺过水，但没死，醒来后说自己看见了‘水底有扇门’。”

当初人人都当是孩童梦呓。如今回想，那扇门，会不会就是活泉之路？他抬头望向北边桐林的方向，日头正烈，林外有鸟鸣。

而掌心那枚乌木印上的金痕，正缓缓爬成一条线，指向北面。

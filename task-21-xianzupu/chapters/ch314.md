# 第314章 双钥同启

灰袍人的话像一根针，扎进石室沉闷的空气中。

“是把笔交给我，还是让我把‘那支笔’还给你？”

顾青衍握着旧笔的手微微一紧。笔杆温润，是他祖父临终前亲手交到他掌心的，笔杆末端“天谱”二字早已被摩挲得几乎光滑。他抬起头，隔着石室狭窄的入口望向灰袍人那双掩在兜帽阴影下的眼睛。

“你说的‘那支笔’，”顾青衍的声音平静得出奇，“在我祖父手上传到我这里。怎么，你手上也有笔？”

灰袍人没有说话，只是缓缓抬起了右手。

他指尖夹着一截笔杆，形状与顾青衍手中旧笔几乎一模一样，只是断成两截，断口处留着焦黑的灼痕。笔杆的木质在火光下泛出深红的光泽——是同一棵树上的木料。

顾青衍瞳孔骤缩。

井底老人忽然从角落里笑了一声，笑声嘶哑，像枯叶碾碎在石板上：“老二，你把我关在这口井里三十年，就为了等我答应当年那件事？你还没死心？”

灰袍人没有看老人，目光始终钉在顾青衍身上：“这三十年，我守的不只是这口井。我守着那扇门，守着一句话。谱官来了，双钥同启，门才能开。”

“什么门？”顾青玄上前一步，手按在剑柄上。

灰袍人终于转向他：“你梦里的那扇门。”

顾青玄脸色骤变。

灰袍人的声音低了下来，像石块沉入深潭：“你梦见自己站在一扇门前，数门上的字，数到第一百零八字时门会开一条缝——你从未跟任何人说过这个梦，对不对？”

石室中一时落针可闻。

顾青衍侧头看向顾青玄。堂兄的表情难看至极，嘴唇抿成一条线，手指在剑柄上攥得骨节发白，却一个字也没有反驳。

“你——”顾青玄的声音哑了，像是从牙缝里挤出来的，“你怎么知道？”

灰袍人没有回答，只把断笔收回袖中，又从怀中取出一块石片，上面刻着半幅图案：两道弧形交叠，中心是一个月牙形的孔洞。

“祖父留下的那块旧印，是不是一个月牙形的缺口？”他问顾青衍。

顾青衍从怀里取出井底老人交给他的那枚旧印，对着火光一照——印底确实是一个月牙形的凹痕。灰袍人的目光落在旧印上，像是隔着三十年岁月看到了什么旧物，随即从怀中取出另一块石片。两道石片相对的边缘，纹路竟严丝合缝。

“三十年前，这些碎片都在我手里，”灰袍人说，“但我打不开那扇门。因为没有笔。守谱人传下来的旧笔，才是第一把钥匙。笔在谁手上，谁才有资格问路。”

他把手中石片与旧印轻轻一碰，发出“嗒”的一声脆响。顾青衍手中的旧印忽然一颤，像活物般从掌心滑落，落在灰袍人摊开的石片上，严丝合缝地嵌了进去。两块石片合成一个巴掌大的圆盘，中央那个月牙形的孔洞果然空空如也。

“所以，”顾青衍缓缓开口，“我手中这支笔，就是第二把钥匙。”

灰袍人点了点头：“你祖父把这支笔留给你，不是为了续写族谱。是为了让你找到那扇门，把一件三十年前没有做完的事做完。”

井底老人忽然猛咳起来，咳得整张枯瘦的脸涨红，像要把肺腑都咳出来。他扶着岩壁站起，盯着灰袍人，一字一句地说：

“老二，你骗了我三十年。你说钥匙丢了。你说那扇门永远打不开了。”

灰袍人没有否认。

老人眼中泛起浑浊的光：“当年你把我锁在这里，说你去看门，看完了就回来。你去了三十年，你回来的时候，门已经看穿了吧？门里那东西，你看到了？”

灰袍人的沉默像一堵墙。

顾青衍低下头，看着掌中旧笔的笔尖。一滴墨珠正沿着笔锋缓缓滑落，悄无声息地坠在石盘中央那个月牙形的孔洞上，却没有散开，而是悬浮在空中，缓缓凝成一滴倒悬的墨珠。

石盘开始发烫。

顾青玄猛地拔出半截剑身，剑光照亮石壁上的兽皮画。那幅画上，原本幽黑的井口图案正在缓缓变化，那些扩散的纹理拼合出一个新的形状——一扇门的轮廓。

灰袍人看着那扇轮廓，声音终于带上了一丝异样的情绪：“你把笔交给我，我来开门。这一门之内的东西，你承受不住。”

“那就让我看看到底是什么。”顾青衍说。

他抬手，将笔尖轻轻点向石盘中央那滴悬浮的墨珠。

整座废井像活过来一般，从深处发出沉闷的轰鸣，井水倒涌而起，冰冷的液体漫进石室。顾青衍握着旧笔的手没有松开，笔尖与墨珠触到的一瞬，他看见那扇门在黑暗中缓缓开启了一条缝。

门缝里，有什么东西正在看他。

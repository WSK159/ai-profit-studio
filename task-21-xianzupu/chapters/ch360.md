# 第360章 井中开门

寅时的祠堂，风中带着露气与焦味。

顾青衍跪坐在族谱前，左手指尖的血已经干透。第七页旁的婴儿掌印似乎比昨夜更清晰了一些，那指纹的沟壑隐隐发亮，像是吸了月华，正慢慢往纸面深处凹去。他伸手去触，指尖方一靠近，就听“嗡”的一声，那页纸颤动起来，像活物受了惊。

“又来？”

他压低声音，把右手覆在纸面上。掌心上那条被旧笔划出的纹路一阵灼热，视野里井底浮书上的字迹再次浮现——“人入谱中，不入天地”。他心头一凛，转头望向窗外。

月光下，祠堂后院那口枯井的井口，正缓缓升起一颗头。

不是人的头。是婴儿的头。通体灰白，眼窝凹陷，嘴唇没有闭合，露出两排细小的乳牙。它从井口探出半张脸，似乎在听什么，然后缓缓向上爬。它没有手臂，也没有腿脚，整具身体只是一个人形的皮囊，像被风吹鼓了的空壳。

顾青衍攥紧了拳头，决定不再沉默。

他推门而出，脚步极稳，一手提着一盏魂灯。那灯是祖父当年留下的，烛芯里掺着顾氏血脉的干血，寻常鬼祟不敢近。他走到井边时，那婴儿壳已经爬出了大半个身子，定住了。

“你是井里的人？”顾青衍开口。

没有回应。

“书里写‘顾氏第七代，青衍，承谱入页’，”他盯着那壳，一字一字道，“那本书是你的皮，对不对？”

那壳的头部忽然扭了一个角度，像猫头鹰一样转了整整一圈，最后停在顾青衍的方向。它没有眼睛，可顾青衍感到一道目光落在自己的左手上。那目光没有恶意，只有一种近乎悲悯的“认得”。

“第七个……”

一道声音从他脑中响起，不是音波，更像笔尖在纸面划出的摩擦声。

“第七代，只有一个人，能开这门。你来了……那门也该开了。”

顾青衍脊背一僵：“什么门？”

那壳不再答话，缓缓低下头，伏在井沿上，像在膜拜什么。顾青衍顺着它的方向往井底看去——

他猛地后退半步。

井壁上，原本那些枯苔和水痕之间，正缓缓浮现出一道门。门是青石做的，门框上藤蔓缠绕，正中一只凹进去的掌印，不是左手，也不是右手，而是一个掌心朝外的“婴儿掌”。那掌印足有碗口大，他看清的一瞬间，左手掌心猛然一热，竟不受控制地抬了起来，向前探去。

“顾青衍！”

身后一声暴喝。顾青玄跌跌撞撞从西院跑来，赤着脚，披头散发，两眼布满血丝。他一把按住顾青衍的肩膀，声音都在抖：“别看那口井！跟我走！”

“青玄哥——”

“我说别看！”

顾青玄强行把他拖开，但已经晚了。顾青衍的左手掌心里，多了一道极细的裂缝，像被无形的刀割开，血珠成串往下落，滴在那婴儿壳的头顶。壳发出一声极轻的“呜”，随即像被抽走了气，瘪下去，缓缓塌回井中。

井壁上的石门也在同一时刻消失，只剩一层水痕。

顾青衍低下头，看见自己掌心的血不再外流，反而在伤口处凝成一个极小的字——“旬”。

“这是什么字？”

顾青玄死死盯着那个字，喉结滚动，最终哑着嗓子道：“这是我娘的姓。”

顾青衍一震。青玄的生母早亡，族谱上只写了一个“林氏”，从未有人提过娘家名姓。而“旬”这个姓，他连听都没听过。

“你娘姓旬？”

“是。”顾青玄把他拽进祠堂，插上门闩后，才压低声音道，“我娘死的那年，我才四岁。我记不得她的脸，只记得她死前握着我的手，一直说一句话——‘不要看井，等第七个来开门’。我以前不懂，今天看到那门上的掌印，我想起一件事。”

“什么？”

“我娘也有一个这样的掌印，在右边肩膀上。和你的左手——”他顿了顿，“一模一样。”

顾青衍低头看向自己左手的“旬”字。他知道“双籽同根，一枯一荣”说的是自己与小满，但此刻他忽然明白，那“同根”未必只是他与小满。

也是他与青玄。

“所以那门……”他低声问。

顾青玄没回答，只从怀中取出一样东西——“断谱针”的残体，半截针尖还带着锈色。他摊开手，针尖对准自己右肩的胎记，正要扎下去，被顾青衍一把夺过。

“你干什么！”

“我试试。”顾青玄的声音沙哑而平静，“如果我娘也是谱官，那她留下的血，也该能开门。你一个人扛不了那座井。”

顾青衍捏着那半截断谱针，指尖微微发颤。他忽然想起，那针出自“断谱人”之手，斩的就是家族气运。而现在，它却要被用来开一口顾家祖先的井。

他摩挲着针身，忽然摸到针尾有一圈极细的刻痕，不是花纹，是字。凑到灯下看清，脊背一凉——

“斩墨家传，断谱针一十二枚。第十一枚，顾九章借去，未还。”

顾青衍盯着“顾九章”三个字，瞳孔缩了一瞬。

祖父藏了断谱针，当年不是助人，而是借物。这针被人从“斩墨”手中带出，辗转三十年，最终回到顾青衍手里。而斩墨组织下令“顾氏谱上名，一个不留”，竟是因为祖父手里欠着他们一枚针。

他缓缓合上掌心，将针收入袖中。

“青玄哥，这针不能用来开门。”

“为什么？”

顾青衍没有回答，只望向祠堂外那口井。月光照在井沿上，婴儿壳的轮廓还没有完全消散，像一圈淡淡的泪痕，晕染在石口上。

“因为它是引子。”他说，“祖父留它下来，不是藏的，是等的——等一个人把它带回来。而我今天，刚好就是那个人。”

顾青玄沉默片刻：“那门里面是谁？”

顾青衍垂下眼，左手掌心的“旬”字仍在隐隐发热：“门里的人，大概是我。”

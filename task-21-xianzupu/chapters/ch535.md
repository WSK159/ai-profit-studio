# 第535章 砚中人

石阶窄而陡，两侧石壁上生着暗青色的苔藓，脚踩上去便渗出水痕。顾青衍走在前头，断谱针被他握在掌中，针尖的金色气息如豆灯火，照亮脚下三尺之地。

青衫人、顾守规、顾小满跟在后头。石阶一共二十四级，走到尽头是一扇极窄的石门，门上没有把守，没有锁。门缝里渗出细细的黑气，带着一股墨香。

断谱针在顾青衍掌中激烈震颤，几乎要挣脱他的手。

“我来。”青衫人上前一步，袖中滑出一支青玉笔，在门缝上画了一道符纹。黑气被符纹逼退，石门无声向内滑开。

门内是一间极小的石室。四壁光滑如镜，地上摆放着一方墨池，池中墨色如漆，仿佛还在流动。墨池中央浮着一块青石板，板上放着一只乌木匣，样式与顾青衍日前在祠堂挖出的那只完全一致。

只是这一只，封面上刻着半个“砚”字。

顾青衍走到墨池边，没有急着去开乌木匣。他的目光落在墨池中，那池黑水深处，隐约浮着一道人影，穿着顾氏旁支的旧式青衫，面目模糊，只在眉心处有一点暗红色的痣。

“砚中人。”青衫人低声说，“这是守砚人的坐化之地。”

“守砚人？”顾青衍问。

青衫人沉默片刻，道：“谱籍阁的记载里说过——谱道传至东荒，最初分为两脉。一脉守谱，立谱续谱改谱；另一脉守砚，以墨养谱、以砚承命。守砚一脉行事隐秘，从不与外界往来。百年前谱籍阁失窃，窃针者留下一半‘砚’字，阁中一度以为窃贼出自守砚一脉。”

“那他呢？”顾青衍指着墨池中的人影。

青衫人摇头：“我不知。我只知此人在这墨池中已经沉了至少百年——守砚之人以身为砚，墨不干，人不朽。”

顾青衍蹲下身，将断谱针探入墨池。针尖触及墨水的瞬间，整池黑墨骤然翻涌，水底那人影缓缓抬头，面容依旧模糊，但那双眼睛却穿过墨色，直直望了过来。

顾青衍浑身一震。

那双眼睛里，有一种他极为熟悉的目光——像是祖父顾九章灯下看谱时专注的神情，又像是顾沧澜绝笔帛书上那一笔笔深沉的墨痕。他忽然想起顾沧澜帛书上写的那句话：“砚中有根，根中有名。”

“你认得我。”顾青衍没有询问，他的语气笃定。

墨池中的人影微微颔首。他张了张口，似乎想说些什么，但墨色涌入咽喉，只化作一声含混的低语。顾青衍集中精神，从那低语中捕捉到两个字：

“……换……谱……”

青衫人闻言脸色大变。他猛地转头看向那方乌木匣，身形一掠已到墨池边，伸手欲取——但他指尖触及匣面的瞬间，乌木匣自行开了一条缝，一道黑光从匣中射出，青衫人猝不及防，被迫退开三步。

黑光散去，一只竹笔浮在墨池上方。笔杆呈暗褐色，斑驳如老树皮，笔尖蘸着浓墨，仿佛刚刚写完一个字。

断谱针在顾青衍掌中嗡鸣大作，针尖金色气息与那只竹笔笔尖墨色彼此呼应，一金一墨，在狭小的石室里交缠流转。

青衫人看着那只竹笔，声音微微发涩：“守砚人的笔……”

顾青衍握着断谱针的手指微微一紧。他想起当日顾沧澜绝笔帛书上最后那句话：“笔合则谱官不存。”眼前这只竹笔与断谱针——一脉两出，一守谱一守砚。若它们本就是同一支笔的分身，合而为一，会有什么后果？

他没有贸然动作，而是看向墨池中的人影。那人影的嘴唇又动了动，这一次，顾青衍听得更清楚，那三个字是——

“顾九渊。”

墨池边，那只竹笔忽然自行转了个方向，笔尖在空气中写下一行歪歪扭扭的小字：

“一砚一谱，本为旧识。笔合之日，顾氏之根当显。”

顾青衍的瞳孔猛地一缩。这行字……

当日祖父顾九章留给他的密信里，写过一个名字，那个人失踪多年，祖父生前提过两次，皆以“旧约”二字相称。

青衫人看着那行字，缓缓说道：“原来如此。”

“你知道顾九渊？”顾青衍转向他。

青衫人没有答话。他转头看向墨池中的人影——那身影已经渐渐消散，仿佛方才的显现，耗尽了他最后一丝残魂。墨池的表面起了细密的涟漪，最后轻轻一荡，归于平静。

那只竹笔在空中顿了一顿，忽然落向顾青衍身侧，钉入石地，笔尖正对着石室东壁。

东壁无声滑开一道缝隙，露出一卷泛黄的帛书，封面上写着三个字：

**《换谱录》**

青衫人盯着那卷帛书，声音压得很低：“顾九渊……若真是他，玄天门谱籍阁百年前的失窃案，恐怕要重头再查了。”

顾青衍俯身拾起那卷帛书。帛书入手沉重，封面上那三个字在一瞬间仿佛活了过来，缠上他的指尖。

远处，青桐镇老祠堂的铜铃骤然响起。

一声，两声，三声。

有人在镇外敲响了家族的惊铃。

# 第463章 白发问旧人

白发老妪拄着一根枯藤拐杖，立在祠堂门槛外三步处，不再往前。夜风拂过她散落的银丝，露出一双浑浊却锐利的眼。她盯着顾青衍手中的旧笔，嘴唇翕动了两下，像是许久没说过话的人，一时找不回声音。

顾青衍下意识将旧笔往袖中收了收，可那老妪的目光如钉子一般钉在笔杆上，寸步不移。

“你父亲制的笔？”顾青衍听见自己声音有些发涩，“那笔芯呢？笔芯是谁的皮？”

老妪没有立刻答话，她缓缓抬起枯瘦的手，从怀中摸出一枚青桐果壳。那果壳被摩挲得油亮，表面刻着细密纹路，与顾青衍在雾谷石壁上见过的那枚印记一模一样。老妪将那果壳贴在掌心，轻轻转动，月光落在纹路上，竟隐隐泛起一层暗红色的光。

“我妹妹的皮。”老妪的声音沙哑得像砂纸刮过青石，“她叫顾南枝，我娘生她那日，屋外青桐落了满地的果。我爹说，这孩子是青桐送来的，便以桐为姓，取名南枝。”

顾青衍心头一震：“她姓顾？那为何石壁上写‘顾南枝不姓顾’？”

老妪嘴角扯了扯，像笑又像哭：“她本名不叫这个。顾南枝是我爹给她起的名，可她亲生父母……不是顾家人。”

夜风突然紧了几分，祠堂门缝里渗出的黑字在月光下微微扭动，像有生命一般。顾青衍听见身后顾慎粗重的呼吸声，还有妹妹顾小满从门后探出半个脑袋，睁大眼睛望着那老妪。

“你说你爹制了这支笔，”顾青衍缓缓将旧笔从袖中取出，横在掌心，“可据我所知，上一任谱官死于三十年前谱房血案。你爹若是制笔之人，他是谁？为何从未听族中提起？”

老妪低下头，枯指摩挲着青桐果壳上的纹路，过了半晌才道：“我爹姓顾，名讳九枝。他是顾九章的胞弟。”

“什么？”顾慎猛地踏出祠堂门槛，声音发颤，“家父从未提过他有兄弟！”

“因为九枝死在谱房血案里。”老妪抬眼，目光越过顾慎，落在祠堂深处那面挂着历代先祖画像的墙上，“三十年前，我爹在谱房中为我妹妹续谱，当夜有人闯入，以断谱针钉入我爹眉心。我娘带着我逃出青桐镇，我妹妹……被那些人掳走了。”

顾青衍握紧了旧笔，指尖触到笔杆上那两个字——天谱。他忽然想起顾九章遗纸上的那句“血墨相问，旧人来”，胸口一阵发紧。

“后来呢？”他问。

“后来我娘死在逃亡路上。我独自长大，打听到我妹妹被人卖入东荒一户散修家中，便寻了过去。”老妪声音愈发低沉，“可等我找到时，她已经死了。那户人家说她偷了主家的功法秘卷，被处以剥皮之刑。”

剥皮。

顾青衍盯着手中旧笔的笔芯，有些透光，在月光下几乎能看见细密的毛孔纹理。他胃中一阵翻涌，几乎将笔甩出去。

“制笔的人将她的皮制成了笔芯。”老妪闭了闭眼，“那户散修主人说，有个修士花了重金买走她的皮，说要制一支笔。我循着线索去追，追了三年，追到了那制笔人手中——正是我爹的旧友。他说他是受我爹临终所托，才将此皮制成笔芯，藏入笔管。他说，这笔芯里封着我妹妹的一缕残魂，若有朝一日，顾氏后人能以谱道之力唤醒她，便能问出当年真相。”

“你为何现在才来？”顾慎沉声问。

老妪睁开眼，望着顾青衍手中的笔，目光复杂：“因为这支笔，已经认了主。我爹那旧友说过，笔芯苏醒之日，便是持笔人折寿破血之时。前些日子，我察觉青桐镇方向有笔芯异动，便赶了过来。”

顾青衍低头看去，只见笔芯泛起一丝极细的红芒，像血管里流动的血。而他的掌心，那血色藤须又爬高了一寸。

“这支笔，”老妪缓缓道，“我妹妹的残魂就在里面。你若有胆，滴一滴血上去，她便能与你说话。”

顾慎立刻喝道：“不行！你不知这老妪底细，万一有诈——”

“她说的应该是真的。”顾青衍打断父亲的话，盯着那笔芯，“我执笔时，常常觉得笔下有另一个人的痕迹，像是一道从我出生前就写好的字。”

“你说什么？”老妪猛地抬头，眼中锐光大盛，“你说你落笔时感觉有他人痕迹？”

顾青衍点头。老妪身子晃了晃，枯藤拐杖重重顿地，发出一声闷响。

“那不是我的错觉，”顾青衍低声道，“我立谱那日，明明只写了一个字，却觉得笔尖底下压着一整篇未完的谱文。”

老妪嘴唇发白，喃喃道：“那就是我妹妹的名字……被人斩下之前，她正在书写自己的谱。她将自己的姓写进谱里，却被那个人从谱上划掉了。她的字还留在纸上，只是没有了名字。”

她抬起眼，望向顾青衍，声音忽然带了一丝乞求：“少年人，你既已执此笔，便是我妹妹半个传人。你能否答应我一件事？”

“你说。”

老妪干枯的手从怀中又摸出一张发黄的纸片，上面歪歪斜斜写着一行字，墨迹已褪得极淡。顾青衍接过来，凑近月光辨认，只见上面写着——

“若见顾氏子，告之：斩墨不姓墨，斩墨姓顾。”

顾青衍瞳孔骤缩。祠堂门缝中那行黑字，这一刻竟像活了一般，在月光下微微发亮——

“谱成之日，当以人续谱。”

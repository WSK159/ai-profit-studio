# 第434章 她葬在青桐山下

夜风穿过书房的窗缝，发出低哑的呜咽声。顾青衍手里的三页纸被他攥出了细密的折痕，那行字在灯下清晰如刻：“她葬在青桐山下，不是墓，是门。”

“你母亲——”顾慎的声音从身后传来，有些干涩，“你祖父没有跟我说过这句话。”

“祖父写给我看的。”顾青衍将那三页纸郑重收入怀中，指尖还残留着天蚕丝纸的余温。他抬头看着顾慎，顿了顿，“父亲，青桐山下埋着的到底是什么？”

顾慎沉默了很久。窗外墨介还在等着，信纸的内容他已经看到，剑心宗的人还候在镇门外。但这一刻，族长的书房里只有两个人的呼吸声，一粗一细，像是两代人在黑暗中探路。

“青桐山下埋着一口井。”顾慎终于开口，言语不像在解释，倒像在描述一个藏了太久的梦境，“你祖父立族之初，在那口井边栽下第一株青桐树苗。他说，顾氏的气运从井中来，根扎得深，枝叶就够高。”

“可是后来……”他喉结动了动，“后来你母亲掉进了那口井里。”

顾青衍的血一下子涌上头顶：“掉下去？”

“她说井有东西在呼唤她。那夜月圆，我陪你舅舅守在东山，回来时你祖父已经封了井口。”顾慎移开目光，“你祖父说他亲眼看见你母亲坠井，没有救上来。可我知道——他在那口井边守了整整七天七夜，白天不言不语，夜里烧纸。我从没见他哭过，但那七天，他每一天都在哭。”

烛火跳动了一下，顾青衍看见顾慎的眼角沁出一层薄薄的湿光。

“那口井后来填了土，被压上青桐石。你祖父亲自刻的碑，上面没有名字——他说她不该有名。那块碑后来被青藤长满了，任谁都看不出井的形状来。”顾慎深吸一口气，“祠堂的老槐树，你还记得吧？那棵老槐的根往东偏三尺，不多不少，正压在那口井的上头。”

顾青衍脑中轰然炸开。镇口老槐被人钉上铁钉枯死，方向指向祠堂——原来始终指的不是祠堂本身，而是祠堂地下那口封死的井。

“老槐枯死的时候，根已经穿透了井下封印。”他目光锐亮，“有人用铁钉封了那棵树的生机，就是为了——把井边的气脉钉死。”

顾慎没有回答，但他目不转睛地看着顾青衍，那双素来沉稳的眸子里，像是浮起了一层极其陌生的光。

“你母亲落井那夜，你祖父曾撕下半张命书——”他说，“那半张命书就藏在空心石的夹层里。我去看过，已经空了。”

顾青衍脑中闪过空心石里的情形，那里面只有半枚断谱令牌和一截青桐枝，并无什么命书。

“母亲把命书带走了？”他问。

“不是带走，是被同一个人拿走的。”顾慎的声音低得几乎听不见，“你祖父最后一夜对我说过——‘她若从井底出来，第一件事，就是来取她的命书’。”

顾青衍沉默。

他没有问“她还活着吗”，因为祖父那封信已经给了答案，她葬在青桐山下，但葬的是“墓”，不是“人”。那口井是门。母亲不是死在井底，而是从井底走向了另一条路。

门外再次传来墨介的叩门声，比方才急促了几分：“族长——青衍，剑心宗的人不肯久候，他说明日天亮前必须回山复命。”

顾青衍将心绪重重压下，推门而出。月色下，一个身形修长的青年立在院门处，穿着一身月白道袍，腰间悬着一枚剑形玉牌。他面容清俊，年纪约莫二十出头，目光平和，但眉眼间隐隐有一丝锐意。

“顾青衍？”那人抱剑一礼，声音轻淡，“在下剑心宗弟子，岳华章。奉宗门之命，送一封口信，顺带一件东西。”

“什么口信？”

“宗门长老青竹真人说——”岳华章顿了顿，像是在复述某个极其重要的句子，“谱官若欲知‘天谱’下落，可持青竹笔，往剑心宗第十三峰一叙。”

顾青衍指尖一紧。青竹笔还在他袖中收纳着，那是旧笔与天谱残卷成套之物。这位青竹真人不但知道青竹笔在他身上，还直接点出“天谱”二字——他不由想到那支笔杆上刻着的“天谱”二字。

“青竹真人说，这笔他认得。”岳华章自袖中取出一件东西，帛布包裹，大小如指掌。他双手奉上，“这是他让弟子转交的笔套。”

顾青衍接过，解开帛布，里面是一只竹制笔套，通体青绿如新竹初生，表面刻着细密的纹路。他将袖中青竹笔取出，缓缓套入——严丝合缝，一分不多，一分不少。

套上去的那一瞬间，笔杆上传来一阵温热，仿佛那只旧笔正在呼应着什么。与此同时，他指根处的断谱针印记突然灼烫起来，一股锐痛直冲髓骨。

他闷哼一声骤然后退半步，扶着门框稳住身形，额头瞬间渗出细汗。岳华章目光一凝，正要上前，墨介已抢先一步扶住了顾青衍。

“无碍。”顾青衍咬牙将断谱针的印记压下去，却发现那印记周围多了一道极淡的青绿色纹路，绕指根一周，像是一条细小的藤蔓。

“笔套上有什么？”他抬眼看向岳华章。

岳华章摇了摇头，神情诚恳：“弟子不知。长老只说，‘套上之后，他自然明白该往何处去’。”

顾青衍握紧笔套，青竹笔尖的青芒在月色下一闪而过。他回头看了一眼书房，顾慎的身影立在窗边，没有追出来，只是远远望着他。他知道，父亲的目光里那层从未见过的光，是“你该走了”的意思。

他转回身，问岳华章：“青竹真人，可还说了什么？”

岳华章沉默片刻，像是在斟酌措辞：“长老说——”他抬头，一字一句，“‘若她找上你，不必回头。谱官的路，向来是踩着故人的脚印往前走的。’”

顾青衍瞳孔微缩，指根那圈新生的青藤纹路再度灼烫了一下。

他低头看了看笔套，终于看见竹面上那行极小极浅的刻字，借月色勉强辨出几个：

**“门后有井，井下有路。路尽头——”**

后面的字被一道细痕划去，怎么看都看不清了。像是有人刻意将那一行抹掉，不愿意让他提前知道路的尽头是什么。

顾青衍握着笔套立在夜风里，镇东的护族大阵已经重新闭合，将整个青桐镇笼在青色光幕之内。远处剑心宗方向的天际，一缕灰白色的光束正缓缓升起，像是有人在迢迢群山之巅为他递来一盏灯。

他忽然想起祖父病榻上说过的那句话——**“谱是人写的，路是自己踩出来的。你不必怕走错，只怕你不肯走。”**

月色照在他指根的青藤纹路上，缓缓蜿蜒，像一条刚刚睁开眼的小蛇。

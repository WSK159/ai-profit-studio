# 第325章 桐叶落

顾青衍从泉眼里冒出头时，正是亥正时分。月光斜照水面，桐林里一片寂静，只有夜风穿过叶隙的声音。

他爬上岸，伸手抹了一把脸上的水珠，乌木印贴身收着，铁片也还在怀里。那枚桐木戒套在无名指上，被水泡过之后，戒面微微发亮，像是一粒种子刚刚苏醒。

“青衍哥。”

林边一棵老桐树后转出一个身影——是顾小秋，比他小两岁，旁支排行第四，平素有些毛躁，为人却憨直。他手里提着一盏防风的油纸灯，灯芯烧了大半，显然等了一阵。

“你怎么来了？”顾青衍皱眉，“我不是说……”

“是远湖叔让我来的。”顾小秋压低声音，“镇里出事了。你离开之后，族老们开了一次会，林家那位——就是林家那个新到任的管事，带着十来个人，堵在镇口。”他咽了口唾沫，“他们说，要顾氏交出谱房里的旧档，说是三十年前一桩旧案的物证。若是不交，三日之后，林家就按东荒俗例，请宗门执裁。”

顾青衍脚步骤停。

“三十年前的旧案……谱房血案。”他低声说，“他们怎么会在这个节骨眼上提这个？”

顾小秋摇头：“族长压着没答话，族老们吵了一夜。有人说该交，有人说不能交。远湖叔让我来告诉你，他说你知道该怎么做。”

顾青衍沉默片刻。那口泉底石室里的帛书、铁片、桐木戒和他父亲留下的纸笺，在他脑中迅速串成一线。林家忽然索要谱房旧档——那是三十年前血案的“物证”，若顾氏交出去，当年被掩盖的真相就会浮出水面；若不交，林家便以东荒俗例请宗门执裁，等于让顾氏陷入一场耗时耗力的宗门审理。

他们等的就是这一招。

“走，回去。”

他们绕过桐林，沿一条隐蔽的山道往青桐镇方向走。路过镇外那片枯荷塘时，顾青衍放慢脚步，目光扫过水边一株歪脖子老柳，柳枝上系着一条褪色的红布。

那是他母亲连素秋留下的记号——只有顾氏嫡系才认得。

他伸手解下红布，布条里裹着一枚铜钱，钱孔上穿着一根白线。他捏着那根白线看了片刻，线是被人急急剪断的，断口不齐。

“这是……？”顾小秋凑过来。

顾青衍收好铜钱，没有解释。他快步穿过枯荷塘，从镇尾一道矮墙翻进谱房后院，推开东南角那扇耳房的木门——那是顾远湖平日记账算账的地方。

房里点着一盏豆灯，顾远湖坐在案后，手边摊着一册账本，目光却没有落在账本上，而是落在对面墙上挂着的那幅旧桐林图上。

“回来了。”他没有回头，“泉心找到了？”

顾青衍在他对面坐下，把铁片放在案上。顾远湖这才低头看了一眼，瞳孔骤然一缩，猛地抬头：“这是……你从哪找到的？”

“泉底石室里。”顾青衍道，“在帛书底下藏着。远湖叔，你知道这是什么？”

顾远湖没有答话，他伸手抚过铁片的断口，指尖微微发颤，半晌，才低声道：“这是一枚断谱针的残件。三十年前，谱房血案那一夜，凶器就是断谱针——只是事后少了一截，怎么也找不到。”

顾青衍指尖一紧。断谱针，那是斩断家族气运的邪器，断谱人的专用之物。残针为何会在泉底的石室里？又为何与他父亲留下的纸笺压在一处？

“所以林家说‘旧案物证’，指的就是这东西。”顾青衍道。

顾远湖点头：“他们不指名道姓，只说有物证，让顾氏自己交出来——这招毒就毒在，我们交也不是，不交也不是。”

顾青衍盯着铁片断口，忽然道：“他们拿不出另一截，就证明不了这是旧案物证。林家要请宗门执裁，凭的是一句空话？”

顾远湖苦笑：“你太小看林家了。他们既然敢开口，就一定有后手。那截断针的另一半，说不定就在他们手里。”

顾青衍沉默。

窗外，夜风吹动桐叶，哗啦作响。顾远湖这间耳房的北窗正对着桐林深处——他忽然看见黑暗中有一道极淡的身影一闪而过，身形有些佝偻，步子却极快。

他猛地站起身：“谁？”

油灯晃动了一下，等他再看时，窗外只有夜色。

顾远湖也站了起来：“怎么了？”

“……有人。”顾青衍走到窗前，指尖按上窗棂。那枚桐木戒在窗棂上轻叩了两下——叩声未落，他忽然觉得无名指上一热，低头一看，戒面那个“允”字竟隐隐泛出一线暗光。

那道光极短，一闪即灭。

但就在那道光灭去的瞬间，他耳边响起母亲连素秋的声音——不是记忆里那些温声软语，而是极低的一声，带着道不明的紧迫：“不要交出铁片。那半枚断针，是钥匙。”

“钥匙？”顾青衍低声道。

顾远湖皱眉：“你在说什么？”

顾青衍抬头，正要开口，窗外忽然又传来一声轻响，这回更近了——像是什么东西被放在窗台上。他伸手将窗推开一条缝，窗外放着一片桐叶，叶脉被什么利器划过两刀，成一个残缺的十字。

桐叶落。

他握紧那片叶子，回头看向顾远湖，声音平静：“林家那位新来的管事，叫什么？”

顾远湖顿了一下：“姓宋，叫宋砚回。据说是林家老夫人从外头请来的族务先生，面生得很。”

顾青衍微微眯起眼。那片桐叶在掌心里蜷了蜷，叶脉间那两道刀痕，在豆灯下微微映着光，像是某种标记。

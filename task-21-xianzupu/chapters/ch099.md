# 第99章 雾中笔声

雾气从程氏废址的断壁残垣间涌来，像一团活物，翻卷着、吞吐着，将整片废墟吞入一片灰白。顾青衍握着袖中旧笔，笔杆发烫，裂纹处隐隐渗出一丝暗红的光。

“走。”

那个字还烙在他脑海里，灰发老人的嗓音沙哑枯裂，像枯叶碾碎在掌心。但那笔尖划纸之声，却从雾深处一步一步逼近。

洛维明站在他身侧，手按剑柄，声音压得极低：“顾兄弟，这雾不对劲，我体内的灵气在倒流。”

“不是雾。”顾青衍低头，看自己脚边青石板上浮起的墨痕——那些纹路像活着的藤蔓，正在朝他们脚踝缠绕上来，“是谱纹。”

“什么？”

“程氏祖宅的地基里，有人刻了一幅谱阵。”他蹲下身，指尖触到一道墨痕，刹那间一股寒意顺着手臂窜上心口，他看见一柄枯笔悬在半空，笔尖滴血，正在一张空白的族谱上写下“程”字第一笔，笔锋落下，那纸上没有名字，只有一个洞口。

“阵眼在祠堂。”他起身，望向雾中隐约可见的一座残塔，那座塔只剩下半截，塔身布满裂缝，却赫然立着一扇完好的门。门缝里透出一线昏黄的光，像一只眼。

洛维明看了他一眼：“你确定要进去？”

“那笔声就是从那里传出来的。”顾青衍已经抬步，旧笔在袖中震得越发厉害，笔尖的裂纹又宽了一丝，他听见一个极细的声音，像有人在笔杆内壁轻轻叩了三下。

叩、叩、叩。

像是在催他。

两人穿过雾气，踏过满地碎瓦，走到那扇门前。门是木质的，木料却是程氏特有的“灵纹桐”，纹理间残留着枯竭的灵力。顾青衍伸手推门，门缝里那线光骤然暴涨，将他整个人吞没。

门后不是祠堂。

是一片星空。

无数条淡金色的线从星空深处垂落，每一条线的末端都悬着一卷书册。那些书册有的展开，有的合拢，有的只有一页残纸。顾青衍仰头望去，呼吸一滞，他认得那些书册的形制——和他顾氏祠堂里的宗谱，一模一样。

“这是……”洛维明的声音从身后传来，却像隔了极远，“万谱？”

顾青衍没有答话。他的目光落在一卷半开的书册上，那封面上写着“程氏族谱”四个字，墨迹犹新，落款处赫然是“顾墨”二字。笔迹苍劲，是顾氏的笔法。

顾墨的笔法。

他屏住呼吸，一步跨出，脚下淡金色的光线如水面般荡开涟漪。他伸手去取那卷书册，指尖即将触到封面的刹那，那卷书册忽然合拢，化作一道墨光射向星空深处。

紧接着，满天的书册同时翻页。

纸声哗哗如暴雨，千万道笔影从书页间涌出，凝聚成一个人形——那人形没有面孔，只有轮廓，手中握着一支枯笔，笔尖对准顾青衍，缓缓落下一划。

那一划，直指他的眉心。

顾青衍瞳孔骤缩。

袖中旧笔在这一刻猛地挣脱他的手掌，飞至身前，笔尖裂纹炸开一片金芒。枯笔的笔尖与旧笔的笔尖在虚空中相触，发出一声极轻的“叮”——

而后，满天的星与书册像碎裂的镜面般崩开，他听见一个声音从裂缝深处传来，清晰、干涩，像从三十年前传来：

“续谱者，代代皆折寿。你可知，你续的不只是顾氏的谱？”

画面碎裂。

顾青衍猛地睁眼，发现自己仍站在程氏祠堂废墟前，门里那线光已经熄灭，洛维明的手紧紧攥着他的手腕，满眼焦急：“你失神了足足一盏茶。”

顾青衍低头，旧笔安静地躺在他掌心，裂纹未消，笔杆却更沉了几分。他正要开口，祠堂堂中那座残塔忽然发出一声裂响，塔身轰然倒塌，烟尘中滚出一物，落在两人脚边。

是一截枯笔。

笔杆刻着两个蝇头小字——“程氏”。

而笔尖上，悬着一滴未干的血。

# 第142章 墨髓之门

驿站的油灯在夜风里晃了三晃，顾青衍的手指按在铜盒边缘那道细如发丝的纹路上，指尖微微发烫。那纹路早已不是第一次触碰了——从离开浮云城那夜起，他每日都要摩挲一遍。可这一次，纹路竟在他指腹下轻轻蠕动了半寸，像是活物感受到了什么。

“它动了。”

小满本来靠着墙角打盹，听见这一句猛地坐直：“什么动了？铜盒？”

顾青衍没有回答。他将铜盒平放在膝上，目光死死锁住盒盖。那条纹路正以极慢的速度向盒心蔓延，沿途分出细密的枝杈，像极了他在族谱上见过的命数藤蔓。他曾在立谱时见过这种纹路——那是血脉与因果交汇时才会出现的痕迹。

“阿兄，你的手在抖。”小满凑过来，伸手按住他的腕子。她的掌心滚烫，比常人高出一截。

“我知道。”顾青衍深吸一口气，用另一只手拧开盒盖。没有机关，没有暗器，盒底躺着一卷薄如蝉翼的丝帛。他将其展开，丝帛上绘着一幅精细的地脉图，墨线蜿蜒，终点处用丹砂点了一个极小极小的圆点，旁边题着两个字——墨髓。

“是谱籍阁。”洛维明的声音从门外传来。他不知何时已经回来了，衣摆上沾着夜露，肩上还背着两只装水的皮囊。“我在城北打听过了，玄天门谱籍阁地下的确有一处古战场遗迹，入口被宗门封印了百余年。东荒散修之间早有传言，说那下面镇着东西，但谁也没真正下去过。”

顾青衍垂目看丝帛，地脉图的走向与洛维明所说吻合。他忽然注意到一个细节：丝帛角落处有一行极淡的墨字，字迹与地图不同，歪歪斜斜，像是有人匆忙写下的：

“墨髓非物，乃人。”

他心头一凛。顾九章临终前说过，墨髓是谱道大成者留下的“墨心”，是经年累月以命书写后凝成的精魄。可现在这行字却在告诉他，墨髓不是死物，而是活人的化身。

“顾墨呢？”他问。

洛维明放下皮囊：“他在驿站外头站着，盯着那条老槐树的根看了一炷香了。我没敢打扰。”

小满嘀咕：“那位顾叔总神神秘秘的，问他什么都说‘到地方自然知道’。”

顾青衍攥紧丝帛，站起身。驿站的门槛外，顾墨背对着他蹲在地上，手指轻轻拨弄着老槐树裸露的根须。秋风把他灰白的发吹起来，露出耳后一道旧疤。

“顾叔。”顾青衍喊他。

顾墨没回头：“那行字你看见了？”

“看见了。”

“那我告诉你——你爹顾慎当年也见过这张图。”顾墨的声音低哑，像沙土摩擦，“你爹二十八岁那年进过一次谱籍阁，回来之后就闭口不提其中之事。三年后你出生，他把你交给九章抚养，自己住进了主屋后面的小院，再没碰过谱笔。”

顾青衍喉头一紧。他活了十六年，从未听任何人提起父亲曾入谱籍阁。他只知道父亲顾慎是守成型家主，务实隐忍，从不提旧事。

“他为什么进去？”

顾墨慢慢站起来，转身看他。秋夜里，那双浑浊的眼睛忽然亮了一瞬：“因为你姑姑。顾青蘅当年嫁入夫家前，曾替顾氏借过玄天门的一份谱籍密卷。那密卷被谱籍阁的人扣住了，你爹是去替你姑姑还债的。”

顾青衍脑子里嗡的一声。

姑姑顾青蘅入夫家是因为情势所迫，这事他是知道的。可他从不知道，那桩婚事背后竟还压着玄天门的债。

“那他……在下面看见了什么？”

顾墨没有回答。他弯下腰，从老槐树根下的泥土里刨出一枚铁片，铁片锈迹斑斑，隐约可见一个“玄”字。

“你爹当年把那枚铁片带回来给我，只留下一句话——”顾墨的声音低到几乎听不见，“‘谱籍阁地下，葬着我们家的人。’”

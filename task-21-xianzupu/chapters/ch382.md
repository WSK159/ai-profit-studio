# 第382章 井下的门

那声开门响极轻，像一根针落在棉花上。

但顾青衍的血却像被冻住了，他“看见”了那条线——从哑井的位置延伸到祠堂深处某扇看不见的门扉上，细若游丝的因果线在月光下泛着暗红的光，另一端系在他的无名指上。

“祖父，账本先收好。”他压下声音的颤抖，“我听见了。”

顾九章一把抓住他的腕子：“你不要命了？那井——”

“那井底下有扇门。”顾青衍说，“三十一年前祖母跳进去没死，是因为井底的‘门’没有开。现在它开了。”

顾九章沉默了三息。他的手掌粗糙而温热，像青桐树皮裹着少年的指节。

“一起走。”他说。

祠堂后院的哑井，与记忆中并无二致。井沿上的青苔比顾青衍第一次见时更深了几分，井口边缘有一处新磨的痕迹，像有什么东西方才从里面探出来过。

顾青衍蹲下，指尖轻触井沿。白发末端的血迹忽然像活物似的，从他指上滑落，一滴落在井口正中央的砖缝里。

井水“咕嘟”一声，拥起一个水泡。

他探头往下看，目光穿过井水，却不再是一片漆黑——水底亮着一盏灯，豆大的火苗描绘出一个人形，像有人提着灯从井底深处走来。

“下去。”顾青衍道。

他没有等祖父回应，一撑井沿翻身落入。

水冷得刺骨。他本以为要泅水，身体却在触到水面的一瞬如落空门——井水像墨汁一般被什么吸收，他直坠而下，不知落了多久，周身忽然一空，整个人摔在一级冰凉的石阶上。

他睁开眼。

这是一条长长的甬道，石壁上刻满密密麻麻的裂纹，那些裂纹与他曾见过的龟甲预言纹路一模一样。甬道尽头是一扇石门，门缝里透出一线微光，正是他在井底幻境中看见的那扇门。

门上刻着一幅画：一个人双手按在门板上，身体弯成弓形，像是用自己的脊背顶着门。画中人的脸刻得极模糊，只有身形像一个“弓”字的右边，左半边空着。

顾青衍伸手按上石门。

掌心贴到门面的瞬间，门上空白的那一半浮现出轮廓——是一个人形的凹陷，与他身体轮廓严丝合缝。石门内部传来一声沉闷的机关响，紧接着他背后传来脚步声。

顾九章的声音响起：“衍儿——”

“站住。”顾青衍头也不回，“那扇门认人。”

“我看见了。”顾九章的声音压得极低，带着一种顾青衍从未听过的复杂，“那门……认你。”

“祖母当年怎么从井底上去的？”

“门后有一条向上的路。”顾九章说，“她临终前跟我说过，井底的‘门’通向三个地方——生门、谱门、鬼门。她走的是生门。”

“那我呢？”

顾九章没有回答。门缝里的光忽然颤动了一下，像灯芯被风吹动，红光映在石门上，那幅刻画的阴影缓缓转动——画中人的脸，竟变成了顾青衍的五官。

“开门之前，想清楚一件事。”顾九章的声音从身后传来，“三十一年前你祖母跳出井底时，抱在怀里的襁褓……是我和她的儿子。但她说，那孩子出生便死了胎息，是井底的‘人’用自己的命换了那孩子的生。”

顾青衍的指尖顿住。

“所以——”

“所以你不是我孙儿。”顾九章的声音苍老而平静，“你是我儿子。是那口井把你养大的。”

甬道内静得能听见呼吸。

顾青衍低头看向自己的手，那根白发忽然从他无名指上脱落，飘落在门缝里。片刻后，门缝中伸出一只枯瘦的手，静静地接住了它。

门开了。

门内是一间石室，四壁皆空，唯一张石案。案上放着一卷泛黄的谱书，封面写着两个字——“罗敷”，字迹正是他在幻境中看到的那一种。

谱书旁放着一枚铜铃，铃身刻着一个“陆”字。

顾青衍瞳孔一缩：那个“陆”字，与顾盼铜铃上的字样一模一样。

他伸出手，指尖触到谱书封面的瞬间，书页“哗啦”一声翻动，停在一页空白上。空白的正中央，一滴墨迹缓缓浮现，化成一行字：

“守谱人罗敷氏，第七代谱官，名：罗敷晚。天谱所载，命尽于——见‘顾青衍’于井门之后。”

字迹尚未干透，墨痕忽然反向游走，化成另一行字：

“但你来了，她便不该死。”

石室内，灯骤然熄灭。黑暗中，顾青衍听见一声极轻的女人叹息，像是从谱书里传来，又像是从石壁深处传来——伴着一声佛铃，清脆，悠长，像从三十一年前响到今天。

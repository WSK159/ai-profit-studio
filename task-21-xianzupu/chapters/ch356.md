# 第356章 井底之书

青衍的指尖刚触到那本无名书的封面，井底的水便倏然退去，像被什么东西吸走了一般。井壁上原先挂满的青苔在瞬间枯萎，露出灰白的石面，上面刻着密密麻麻的细小纹路，在昏暗的光线下看不太真切，但隐约能辨出是某种阵法的轮廓。

他收回手，井底却传来一声极轻的叹息，像是失望，又像是庆幸。

“哥！”顾小满的声音从井口上方传来，带着哭腔，“你快上来！那本书……你别碰它！”

青衍没有应答。他的目光落在那本浮在水面上的书上——此刻水已退尽，书半陷在淤泥里，封面上的婴儿掌印已经干涸，成了一只焦黑的印记，像烙上去的。他忽然发现，那掌印的五根手指长度与他左手完全吻合。

“小满，你帮我去叫老陆来。”他头也不回地说。

顾小满迟疑了一瞬：“老陆他……方才不是还在外面吗？”

青衍心头一紧。刚才从水中蹿出的那道黑影，形似老陆，左肩有青桐籽胎记——可老陆平日里穿的是右襟交领，肩膀那一块从不露出来，他是如何知道那胎记的？除非那道黑影真的是老陆本人，又或者，它看了一眼老陆的身体。

“别去。”他改口，“你先回祠堂，守在族谱前面，谁也不要靠近。”

顾小满不解，但还是乖乖应了一声，脚步声渐远。

青衍深吸一口气，蹲下身，将那本书从淤泥中拾起。入手极轻，像捧着一团空气。封面柔软冰凉，材质像是某种兽皮，却没有任何缝合的痕迹。他没有翻开，只是将书贴在胸口，那封上的掌印处微微发烫，像是有什么东西在里面挣扎了一下。

“你认得我。”他低声说。

书没有回应，但他分明感觉到封皮下有什么东西在蠕动，像是一页页纸在翻动时发出的声响。他的指尖陷进封皮，忽然触到一处凹陷，顺着摸去，竟是一个字的轮廓——被掌印盖住了大半，只露出右边的偏旁。

那是“谱”字的右半边。

他正要将书翻开，井壁上那些灰白纹路忽然亮起一道红光，像是被点燃的引线，眨眼间蔓延至整面井壁。一股令人窒息的压力从四面八方涌来，青衍只觉胸口一闷，体内那点微弱的灵力被压得一丝不剩。

井底传来低沉的呢喃，像有无数人在同时说话，词句重叠，听不分明，但其中反复出现一个音——像是“顾”，又像是“孤”。

青衍咬破指尖，以血在书封上虚画了一个“封”字。旧笔在袖中猛地一颤，一股温热从笔杆渡入他掌心，那呢喃声骤然止住，井壁上的红光也渐渐暗下去。他低头一看，书封上的婴儿掌印不知何时已经消失，露出下面完整的字迹：

“顾氏第七代，青衍，承谱入页。”

与祠堂族谱上祖父新添的字迹，一字不差。

他握着书的手微微发颤。书上写着他的名字，可写下这些字的人是谁？祖父顾九章已死，笔迹却出现在族谱上；这本书封上印着婴儿掌印，掌印消失后留下的字迹却与族谱一模一样。是同一个人的手笔——有人在他出生时便将他的名字写进了这本书里，而这本书，现在才浮出水面。

“你是谁？”青衍仰头望向井口，“三十年前在谱房血案中杀死上一任谱官的，是你吗？”

无人应答。井壁上的纹路彻底暗去，井底恢复寂静，只有他一个人的呼吸声。

他沉默片刻，将书收入怀中，抓住井壁凸起的石棱向上攀爬。才爬到一半，他忽然停住——井壁上那些灰白纹路暗去之后，石面上露出一行小字，刻得很浅，若不是沾了水痕几乎看不见：

“井中藏谱，谱中藏人。人入谱中，不入天地。”

他数了数，共十六个字，字迹苍劲，像是用指甲刻上去的。青衍伸手摸了摸那几个字，指腹传来的触感却不像石头，而是像人皮。

他猛地缩回手。井口上方传来顾小满的声音：“哥！老陆来了！”

青衍攀出井口，站在院中，老陆正提着一盏灯笼立在廊下。他还是那副佝偻的模样，灯笼光映得他半边脸明灭不定。青衍的目光落在他左肩上，那里被旧布裹得严严实实，看不出什么。

“少爷这一身泥水，”老陆笑着递来一条巾帕，“去后头换一身吧。”

青衍接过巾帕，没有擦脸，只是拿在手里。他盯着老陆看了片刻，忽然问：“老陆，你今年多大了？”

老陆愣了一下：“四十七了，少爷怎么忽然问起这个？”

“你左肩上那颗青桐籽胎记，是自小就有的？”

老陆的笑容僵了一瞬，很快又恢复自然：“少爷记岔了，老陆左肩哪里有胎记？那是年轻时候磕伤留下的疤。”

青衍点了点头，没有追问。但他捏着巾帕的手指微微收紧——井底那道黑影左肩上的青桐籽印记，形状与他在祠堂旧谱上见过的“顾”字暗记一模一样。

老陆转过身，提着灯笼往回走，影子在地面拖得很长。青衍盯着那道影子，忽然发现它止步于月光照不到的暗处，像是被什么无形的线牵着，比老陆本人多走了半步。

他没有回头，但心里已经记下了。

祠堂方向，顾小满的声音远远传来：“哥！族谱又翻页了！”

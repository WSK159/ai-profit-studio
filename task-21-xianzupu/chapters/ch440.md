# 第440章 四字命书

离开井底时，青桐镇的夜色已经沉得像墨。顾青衍爬出井口，将石板重新合拢，仔细拂去周围的浮土，确认看不出痕迹才转身离去。

他没有回自己的住处，而是绕道去了祠堂后的旧谱房。

三十年前，谱房血案后此处被封，如今也只有他一人有钥匙。推门进去，尘灰扑面，他反手关上门，点燃了一盏灵油灯。微弱的灯光下，他将那半瓣白玉莲、半张命书、断谱针针尖的碎片依次摆在了案上。

三样东西并排放在一起时，命书上的字迹忽然微微亮了起来。顾青衍凑近去看，却发现那半张命书上“斩墨”二字旁边，多出了几道细如蛛丝的墨痕，正缓缓延伸，最终汇成一个字——虽然只成形了一半，却依稀可辨是一个“母”字。

他心头一凛。

这半张命书是祖父笔迹，写的是顾氏一族的名与运。可“母”字出现，难道是指母亲？还是指别的什么——莲的“母体”？

顾青衍伸手拿起断谱针碎片，轻轻在那半成形字迹上一点。碎片光芒一颤，那个“母”字竟似被激活一般，浮现出一行更细的字迹，是极淡极小的草书，若非他自幼跟着祖父习字，几乎认不出来——

“三更，祠堂，见旧人。”

顾青衍瞳孔微缩，握紧命书，抬头看向窗外的夜色。远处传来梆子声，恰好三更。

他几乎没有犹豫，拢起桌上的三样东西，推门而出。

祠堂在青桐镇正中，供奉着顾氏历代先祖的牌位。顾青衍进入时，祠堂内灯火尽灭，只有案上两炷香还在袅袅燃着，一红一白，颜色不同寻常。

有人已经在了。

一个黑衣人背对着他，站在先祖牌位之前，手里握着一卷旧帛。那人身形笔直，气质内敛，像是身在静水中，波澜不惊。

顾青衍脚步一顿，警惕地停在门槛之内两步的距离：“你是谁？”

那人没有回头，声音平淡——却隐约透着一丝笑意：“你不认得我了。”

顾青衍盯着那人的背影，脑子飞速运转。这人给他一种极淡的熟悉感，却无论如何也想不起来在哪里见过。

黑衣人缓缓转过身来。灯光昏暗，他的面容拢在阴影中，只有下颌轮廓隐约可辨。而那双眼——那双眼在暗处却亮得惊人，像是一柄收鞘多年的剑，终于露出寸许锋芒。

“顾长歌？”顾青衍几乎脱口而出。

那是他二叔，顾长歌。上一位谱房惨案的幸存者，也是当年唯一在谱房血案中活下来的人。自那之后，他远走他乡，音讯全无。

黑衣人没有否认，也没有承认。他低下头，看着手中那卷旧帛，开口却是极不相干的四个字——

“她在等你。”

“谁？”顾青衍攥紧拳头。

“你母亲。”黑衣人说，“十六年，她在第十三峰等了十六年。你可知，她等的不是有人去救她，而是等你长到能接命书的那一天。”

顾青衍的呼吸一滞。

“你说什么呢？”他沉声道，内心却如潮翻涌，“我从未见过母亲……”

“你见过。”黑衣人打断他，“你出生的第一眼，就见过她。只是你忘了。”

他从袖中取出一物，递向顾青衍。那是一枚小小的玉锁，锁面写着两个字——“顾氏”。锁的边缘有细小的裂纹，像是被用力攥过，又被小心翼翼地收了起来。

顾青衍看到那枚玉锁的瞬间，脑海深处像有什么裂开了一道缝。他不记得任何关于母亲的画面，可在看见这枚玉锁时，心脏却不受控制地猛跳起来，像是某根沉眠多年的弦被人重重拨动。

他伸手接过玉锁。锁面温热，似乎带着那人的体温。而锁的背面——顾青衍翻过来看时，瞳孔骤然一缩——刻着四个字：“续我命者。”

那是他父亲顾慎的笔迹。

黑衣人看着他怔怔望着玉锁的样子，终于动了动嘴角，像是叹了口气。

“你的命书，还差最后一个字。”他说，“不是‘母’，也不是‘斩’。你仔细想——续你命的人，是谁？”

顾青衍握着玉锁，喉间发紧。一个模糊的轮廓在他脑海中一点一点成形：大雪之夜，一个女子抱着襁褓跪在祖父面前，额头抵地，嘴唇翕动。她说的是什么？他听不见，只能看见那女子的背影，瘦削而单薄，怀里护得紧紧的，像保护世上最后的珍宝——

“是我母亲……续了我的命。”

他轻声说出这句话时，命书上的“母”字骤然一亮，又悄然隐去。而玉锁的碎纹中，一滴暗红色的血痕慢慢渗出，像是回应。

黑衣人看着他，眼中终于露出一丝复杂的神色。

“你该去第十三峰了。”他说，“但走之前，有一件事要先告诉你——你祖父没死。”

顾青衍猛地抬头。

黑衣人已经向后退了一步，身形融入祠堂的阴影中。他的声音从暗处传来，低沉、清晰，一字一顿——

“三十年前被葬进墓中的那副身体，是一个替身。”

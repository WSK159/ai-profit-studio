# 第240章 针尾之名

祠堂外的风忽然停了。

顾青衍攥着那张讣文，指尖压在背面的淡墨字迹上——“回来了”三个字写得极轻，像是书写者怕惊动了什么。他抬眼看向陆沉：“这字迹，是谁写的？”

陆沉没有立刻回答。他看了一眼祠堂深处供着的列祖牌位，声音压低了些：“讣文送到玄天门时，字已经在了。谱籍阁的老先生们比对过笔迹，不是顾宁的，也不是你们顾氏任何一位活人的手笔。”

“那你们为何留着？”

“因为老先生们说，这字迹的墨，是谱墨。”陆沉顿了顿，“以谱官血墨写的字，百年不褪。可这墨迹新得扎眼。”

顾青衍心头一紧。他下意识看向祭台底座——先前那道墨线还静静地伏在石纹中，像一条冬眠的蛇。此刻天色将暗，那墨线似乎比白日里更黑了几分。

“陆兄，”顾青衍将讣文折好，双手递还，“你说断谱针针尾刻着一个名字。那名字，是顾宁的？”

陆沉摇头：“不是。针尾刻的是一个‘顾’字。”

顾青衍一怔。

“但顾宁的死讯传回时，针不在他身上。后来有人在他尸体旁的石缝里找到一枚断谱针，针尾刻的‘顾’字，笔画收尾处有一道斜痕，像是刻字的人手抖了一下。”陆沉看着他的眼睛，“以顾宁的水准，他不会手抖。除非——”

“除非那个字不是他刻的。”顾青衍接上话，声音发涩。

陆沉点头，没有再多说，拱了拱手便转身离去。临走前留下一句话：“寻到断谱针，若无法取下针尾之物，可持这枚令牌入玄天门。谱籍阁欠顾氏一笔旧账，迟早要还。”

他走得很轻，身形融进暮色里，像从未来过。

祠堂里只剩顾青衍一人。他掌心的铜牌尚有余温，那是从井下暗格取出的，刻着断谱针藏地的路线图。他将讣文内容在脑中反复过了三遍，忽然察觉到一个不协调的地方——所有人都告诉他顾宁当年赴东荒绝地是为寻断谱针，可讣文上分明写着，顾宁所寻之物，是被从顾氏祠堂带走的一件东西。

若那件东西就是断谱针本身，那为何要在祠堂里被“带走”又去绝地“寻回”？若那件东西不是断谱针，那针又从何来？

他蹲身，借着最后一线天光，去看祭台底座上那道墨线。墨线微微蠕动了一下。他揉了揉眼睛，再定睛看，墨线却没有动。可他心里那根弦却绷紧了。

“祖父，”他低声说，“你到底藏了多少事没告诉我？”

夜风穿堂而过，供台上的烛火忽明忽灭。青石板地面上，那幅描着井下石室路线的暗记，中段的改道痕迹在火光映照下格外刺眼。顾青衍的手指沿着改道的位置慢慢划过，忽然停住——改道后的路线末端，那个“玄”字旁，多了一道极浅的刻痕。

那道刻痕是新的。白天他看到暗记时，还没有。

他俯身贴近，就着烛火仔细辨认。那道刻痕弯弯曲曲，像是在地上画了一道水流，又像是一条蛇盘成了圈。顾青衍心头一跳，猛地回头看向顾小满平日里玩耍的院落方向——那刻痕的形态，和他妹妹随手在沙地上画过的一个符号一模一样。

顾小满。他的福星命格的妹妹。

他起身的时候，后颈一层薄汗。他不知道这道刻痕是谁留下的，也不知道与顾小满是否有关，但他知道一件事——井下暗格那枚铜扣，是顾小满捡来给他的。她说是在祠堂后院的槐树根下捡的。

那时他没有多想。现在，他不得不想。

顾青衍将路线暗记重新抚平，又用袖角擦去了那道新刻痕。他走出祠堂，夜空中一弯残月斜挂，青桐镇的灯火稀稀落落。他往顾小满的院子走去，脚下越走越快。

有人在暗中看着他。他感觉到了那道视线，像一根细针，扎在颈后。

他没有回头，只是握紧了那枚铜牌。

# 第349章 笔中遗信

顾青衍几乎是一路跑回地面的。

泉心石室的甬道里风声呜咽，像有什么东西在身后追着他走。他拐过最后一截弯道，头顶的暗门被他一掌推开，午后的日光泼洒下来，青桐镇熟悉的气息扑面而来。

祠堂的方向传来一阵若有若无的钟声，是顾慎在召集族人。顾青衍没有停顿，快步穿过院廊，绕到祠堂后偏角的谱房。

谱房落着锁，锁环上积了一层薄灰。上次夜袭之后，顾慎下令闲杂人等不得靠近，钥匙由他亲自保管。但顾青衍有办法——他从怀中取出那支旧笔，将笔尾的铜套旋开，露出笔管中空处的一截细铁丝，探入锁孔拨了两下，“咔哒”一声，锁开了。

门推开的瞬间，尘气扑面。谱房的木架上，族谱被整齐码放着，最顶层那一册正是他开卷时看见的旧谱。顾青衍快步上前，将旧笔平摊在案上，又取出那枚“守谱”针。

针尖靠近笔杆时，笔杆上那道“天谱”二字忽然自行亮起，金光细如游丝，沿笔杆绕了三匝，最终汇入笔尾的铜套。

“啪。”

铜套弹开，一卷极薄的丝帛从笔管中滑了出来，落在案面上。

顾青衍的指尖微微发颤。他将丝帛展开，上面的字迹工整端正，一笔一画皆是熟悉的笔力——

“吾孙青衍见字如晤。你既见到此信，说明你已走过泉心石室的暗井，见天谱之基，得青桐籽，见守谱针。此三关，非心志坚定者不可破。”

是顾九章的字。但他从未说过写过这封信。

丝帛继续展开，第二段墨色稍浅，像是写的时候笔尖已乏力：

“旧笔非我所铸，乃谱房始祖所传。笔中有信，亦为我接任谱官时上一任谱官所嘱。此后代代相传，每逢新一代谱官认谱，须以守谱针启管阅信。”

顾青衍的眼睛定在那里。谱官代代相传的遗书，他读到的是顾九章写给他的那一页，而丝帛之后，还有第二页、第三页。

第二页是上一任谱官的字迹。那人死于三十年前谱房血案，族谱中他的名字已被抹去，连生辰忌日都不曾留下。可这页丝帛上的字迹圆润饱满，不带半点临死的仓皇：

“井底天谱，为顾氏气运之根，亦为万谱之本的分页。断谱人之所以追剿顾氏，非因顾氏强盛，乃因天谱在此。守谱与我，皆为此物而立。然我死之后，此信能传到何人手中，亦未可知。若你读到，切记——断谱人与守谱人同出一源，皆属‘谱道宗’旧脉。三十年前那场血案，并非断谱人所为。”

顾青衍的手一顿，上身前倾，将这几行字重新看了一遍。

“并非断谱人所为？”

那上一任谱官死于谁手？血案真凶若非断谱人，又会是谁？

丝帛第三页只有短短两行，墨色很淡，几乎要淡进丝帛的纹理里去：

“护谱大阵，我非以命布之，以命引之。第十九颗青桐籽与阵眼相合之处，便是凶手真名所在。”

顾青衍放下丝帛，霍然站起。顾九章临终前以残躯布下护谱大阵，全族上下皆以为他油尽灯枯、以命殉阵，可是这封信说要“以命引之”——他不是在献祭自己的命，而是在引动某样东西？

他快步走向谱房后墙，那面墙上挂着一幅青桐树的旧画。他听顾小满提起过，祖父生前常在这幅画前站上很久，说是看树，其实是在看画中青桐的籽数。

顾青衍掀开画框背面——画布后面贴着一层薄薄的绢纸，绢纸上画着一根枝干，枝干上结着十八颗籽。

十八颗。

他想起那封信里说的“第十九颗”。

“第十九颗籽，在我手里。”

他摊开掌心，那颗干瘪的青桐籽静静躺着。他猛力一握，指尖发力，枯硬的籽壳“啪”地碎裂，一颗指甲大小、呈半透明状的金色内核滚了出来，上面刻着一个细如蚊足的“仇”字。

墙上的画，忽然无风自动。

顾青衍猛然回头——谱房的窗户外，一双眼睛正贴着窗缝朝里面看，看不清面容，只有一点寒星似的瞳孔，在他转身的瞬间缩了回去。

门外传来一声极轻的脚步声。

他攥紧那枚金色内核，低头一看，内核上那个“仇”字正在发出滚烫的光。

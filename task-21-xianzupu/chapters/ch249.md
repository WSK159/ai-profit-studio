# 第249章 半牌重圆

顾青玄长剑出鞘，剑光如一线青虹横在顾青衍身前，剑尖指向黑衣人的眉心：“退后。”

斩墨却连看都没看他一眼，只盯着顾青衍掌中那半枚符牌，缓缓道：“你可知道，这符牌原本是完整的。三十年前，我在顾氏旧地断了它，一半留在我手中，另一半被我亲手藏在风鸣谷底，等能持牌之人来取。”

顾青衍五指收拢，将符牌攥紧：“你故意将它留在谷底？”

“不是留给你，是留给定数。”斩墨说，语气里竟有一丝感慨，“万谱归一时，乾坤自可开。你顾氏初祖留下那页真谱页首便写着这句话。我参了三十年，才参透一半——持牌之人，必是命数与天谱相通之人。”

顾远在旁微微变色：“你参透了真谱的暗示？”

“未必全透，但够用了。”斩墨向前一步，掌中半枚符牌被他抛起，在幽暗的空气中翻转两圈，精准地落在顾青衍脚前三寸处，“合上它，开匣，取出真谱。我只要看一眼。”

顾青玄冷笑：“你以为我们会信你？”

斩墨的目光终于落到顾青玄身上，片刻后却笑了：“剑修，天生心魔，压了这些年也不容易。你可知你心魔来源何处？”

顾青玄握着剑的手微微一颤，却没有答话。

斩墨也不追问，只又看向顾青衍：“你若不合牌，我夺剑杀人不难。但你也该明白，这匣中真谱若是落入断谱人手中，顾氏一脉便再无翻盘余地。而现在，你有选择的机会——打开它，自己看。我站在丈外，不动不碰。”

顾青衍低头看着地上那半枚符牌，掌中半枚仍在发烫。他沉吟片刻，蹲身拾起，将两半拼合——咔的一声轻响，缺口严丝合缝地合拢。完整的符牌上，“斬”字完整现出，血纹沿字的笔画流动两圈，随即熄灭。

石匣表面的血色“斬”字同步消散。

“退后。”顾青衍说。斩墨果然退出一丈，双手负在身后。顾青玄剑尖未移，顾远站在一侧，呼吸却明显急促起来。

顾青衍走上石台，将旧笔取出，笔尖抵住石匣表面那支笔画图案。墨光一闪，石匣无声滑开。

匣中只有一页泛黄的纸，纸质极薄极韧，上面密密麻麻写满了字——每一笔都像是从极远的地方传来，带着一种令人心悸的重量。顾青衍只看了第一行，整个人便僵住了。

纸上写着：“天谱三页，一页载天地，一页载众生，一页载归途。此页为第三页，守谱人顾氏执掌。得此页者可续己身之谱，亦可断他人之谱——”

他目光继续下移，落到底部一行小字：“然持此页者，须以自身为谱，将姓名写入天地。否则，页中所记一切皆不可持，只可阅。”

顾青衍呼吸一顿，忽然明白祖父临终前那句“最后一笔”的含义了。

他抬头，看见斩墨目光灼灼地看着他，像是要从他脸上读到答案。顾远也看着他，神色紧张。顾青玄仍然剑指斩墨，却微微侧过头来。

“匣中是什么？”顾远问。

顾青衍将真谱轻轻折起，收进怀中，道：“我一人的命，换顾氏所有人的归途。”

他的掌中，那支旧笔笔杆上“天谱”二字微微发亮——在他开口的这一刻，仿佛回应了他的选择。

斩墨的青铜面具下，目光忽然变得幽深。

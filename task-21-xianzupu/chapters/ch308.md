# 第308章 血线入井

顾青衍盯着桐油布上那三行血书，指尖微颤。

“奏字若见门，青衍来之前，不可启。”他低声念了一遍，目光移向顾青玄，“这布包，是在何处寻得？”

顾青玄靠在门框上，神色疲惫，眼下青黑一片：“镇西枯井，骸骨怀中。我翻遍井底，只寻得这一件物事。”

“你动过它？”

“碰了一下。”顾青玄抬起右手，食指缠着一截白布，隐有血迹渗出，“布内之物刺了我一道，伤口极浅，但隐隐发麻，至今未消。”

顾青衍眉心一跳。顾青玄是筑基中期的剑修，寻常刀兵难伤他分毫，布内之物仅凭一击便叫他流血，绝非凡物。

他凑近细看那血书字迹，笔画瘦硬，收锋带钩，像是女子所书。顾青衍脑中浮现“苏”字木梳的刻痕，两相比对，笔意确有相似。

“青玄哥，”他忽然抬头，“你可认得这字迹的主人？”

顾青玄沉默片刻，摇了摇头：“我翻遍族中旧档，并无此类笔迹存档。”

窗外夜风灌入，烛火摇曳。顾青衍将桐油布重新卷好，用麻绳系了三道，放入怀中贴身之处。那布内之物又微微一动，像是活物呼吸，随即沉寂下去。

“你若带着它回房，恐怕不妥。”顾青玄目光落在他胸口，“那东西……不是死物。”

“我知道。”顾青衍低声道，“正因不是死物，我更得贴身带着。若它失了掌控，至少我能第一时间察觉。”

顾青玄没再劝说，转身走到门口，又停住：“青衍，那口枯井……我总觉得不太对劲。”

“哪里不对？”

“你随我来。”

两人趁着夜色出镇，沿镇西土路行至一里外，枯井处在两株枯柳之间。月色惨白，照得井口一圈青苔泛着暗绿。顾青玄带他绕到井后，扒开一丛野荆棘，露出一块半埋土中的石碑。

碑高不过三尺，断成两截，下半截刻着八个字：持梳者葬于井，持笔者行于天。

“这碑我昨夜便瞧见了，但那时只看清这半句。”顾青玄指向上半截断碑，“你再看。”

顾青衍蹲下身，手指拂去碑面泥土。上半截碑上竟另有一行小字，笔画极浅，像是被人刻意磨去过，只余淡淡凹痕：“门内之人，不得出。门外之人，不得入。”

他心头一震。

“门内”“门外”——那桐油布上血书所写“奏字若见门”，与这碑文岂非同指一物？顾青衍伸手探入碑后方土壁，指尖触到一块松动砖石，轻叩之下，忽然听见空响。

他拔开砖石，露出一道狭窄甬道入口，仅容一人侧身而入，幽深漆黑。就在这时，怀中桐油布猛地颤动起来，布内之物隔着数层桐油发出“嗡嗡”声响，像是被什么牵引。

顾青玄脸色一变：“它在叫？”

“不是叫，”顾青衍按住胸口，感觉那物事正微微发热，“它在引路。”他盯着甬道深处，隐约看见远处有一豆幽光浮现，色作青白，飘忽不定。

顾青玄按住剑柄：“我走前面。”

“不。”顾青衍摇头，目光落在甬道口石壁上，“你看那儿。”

石壁上刻着一行极新的字迹，墨痕未干：“门外之人，今日可入一步。只一步。”

字迹笔势凌厉，与桐油布上血书迥然不同——但这字迹，顾青衍认得。他在顾九章留下的旧笔记中见过不下数十次，那是祖父的亲笔。

可顾九章分明已在数月前，在他面前含笑而逝。

顾青衍喉头滚动，掌心沁出冷汗。顾青玄显然也认出字迹，压低了声音：“你祖父——还在世上？”

顾青衍没有回答。他缓缓低头，瞧见甬道口的泥地上，有一串极浅的足迹。足迹只有一排，像是有人从甬道深处独自走出来，又像是有人从外面走进，留下脚印后便再也不曾回头。

而那一排足迹的尽头，正对着他脚下——终点处，落着一枚桐木发簪，簪身枯裂，簪头刻着一朵半开的桐花，花蕊中央，嵌着一粒已被磨得发亮的朱砂。

顾青衍认得这发簪。那是他幼年时，常在祖母鬓边见到的旧物。

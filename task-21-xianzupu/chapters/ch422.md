# 第422章 井开

井底的叩响只有顾青衍一个人听见了。

他压住心头的震动，面上丝毫不露，只看着林砚秋道：“林公子寻旧物，与我顾氏祖祠的井有何干系？这井荒废多年，井底只有淤泥烂石，怕是让公子失望了。”

林砚秋折扇一收，笑吟吟地道：“失望不失望，掀开石板便知。”

他说着朝那两名修士使了个眼色。两名修士再次弯腰，手指扣住青石板边缘，灵力灌注掌心。顾青衍手指微动，正要出手阻止，却忽然瞥见一件事——石板底部与井沿接触的缝隙里，渗出一丝极淡的黑气，像是墨迹在水中晕开又凝固。

他心头一跳，旋即松开了握紧的拳头。

那两名修士猛力一掀。青石板应声而起，翻落在井边，震起一片尘土。林家众人凑过去一望，井口黑洞洞的，底下什么也看不见，只有潮湿的凉气袅袅上升。林砚秋皱起眉头，又让人打了一桶水上来，井水清冽无异味，桶底干干净净，连泥沙都没有。

一名修士探头往井里喊了一声，回音嗡嗡作响，再无其他动静。

林砚秋面色微沉，绕着井沿走了一圈，折扇轻轻敲着掌心。他忽然停下来，在井沿处蹲下身，指尖拂过那块青石板原本盖住的位置——井沿一圈的泥土，有一道极细的划痕，像是某种利器曾经插进去又拔出来留下的。

他眯起眼睛，手指沿着划痕轻轻摩挲，脸色变了变：“这是……”

顾青衍走近，平静地道：“老井年久失修，石块之间难免有划痕。林公子若是担心井塌了，顾氏可以找人填上。”

林砚秋站起身，脸上重又挂起笑容：“不必了。让顾公子见笑，是林某看走了眼。”他朝顾青衍微微一揖，带着林家众人转身离去，走了几步，又回过头来，声音不大不小地飘过来：“对了，我娘让我带句话——‘那朵莲花，该开的时候就开了。有些根，种下了，三十年也断不了。’”

顾青衍脸上没什么表情，直到林砚秋的背影彻底消失在巷口，他才低头看向井沿。

石板掀开的位置，井壁内侧一块砖石的缝隙里，露着一截指甲盖大小的灰白色东西。他探手抠出来，是一截折成两段的指骨，断面平整，像是被人用利刃一刀斩断。指骨通体泛着淡淡的墨色纹路，在日光下墨纹缓缓流动，仿佛还活着。

他攥紧那截指骨，耳边忽然响起孟叔和说过的话：“顾九章左眼致盲系落霞峰来人后三日溃烂所致。”他再低头，井底深处的水面上，此刻正映着一轮月影。

可是此刻青天白日，日中天高悬，哪里来的月亮？

他正要再看，那月影一晃便散了。井底传来第三声叩响，比前两次清晰得多，像是有什么东西已经从沉睡中彻底醒来，正在井壁上一下一下地刨着，朝井口靠近。

顾青衍把指骨收进怀里，手指同时触到了那支旧笔和白玉莲。他感到白玉莲的温度正在升高，几乎有些烫手。

“今夜子时……”他低声道。

他转身回到祠堂，身后的老井里，传来了一个女人极轻极轻的气声，像是一叹，又像是一声呼唤：“……九章。”

顾青衍脚步骤然顿住。那声音远得像隔了三十年，又近得像贴着耳畔。他猛地回身，井口依然空荡荡的。没有人。但他分明看见井沿内侧的砖石上，不知何时多了一行新刻的字，字迹歪斜，像是用手指甲在砖上划出来的，还带着一丝陈年血迹：“你父亲的东西，藏在你要去的地方。他回不来了，你知道该问谁。”

那字迹的笔锋，与祖祠画像上那行“七月十五，井底开”的落款墨迹，如出一辙。

顾青衍在井边站了很久。风把青桐镇的炊烟吹过来，吹散了井口的凉气。他忽然觉得这一天漫长得像一年，而子时——子时正一步一步地，朝他走来。夜里的风不知什么时候停了。

青桐镇上所有的灯都熄了，只有顾氏祖祠的祠堂还亮着一盏。顾青衍把断谱针别在腰后，白玉莲托在掌心，推开祠堂门，朝后院老井一步步走去。

月光照在井口上，像一碗满到边际的水，而那轮圆圆的白影，正静静地立在井中央，等着他。

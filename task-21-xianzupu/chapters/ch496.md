# 第496章 半个谱官的嘱托

灰袍老者的咳声在孤峰独院的静夜中显得格外刺耳，像一面破鼓被风反复敲击。顾青衍盯着对方指间的旧笔，笔杆乌沉，唯有“守谱”二字在灯下泛出暗金光泽。

“你说……上一任谱官没死？”他听见自己的声音有些干涩。

老者没有立刻答话，而是先低头看了一眼自己掌心的血沫，用袖口缓缓拭去。他整个人瘦得只剩一把骨头，白须杂乱，像一座被风蚀了三十年的孤碑。

“顾景行。”老者念出这个名字时，语气里竟有一丝说不清的敬与惧，“三十年前谱房血案，顾氏对外说他死了。但死的那个人，形貌像他，血是他，唯独……笔不对。”

周衍之一直沉默地站在窗边，此时终于忍不住开口：“师父，您说笔不对是什么意思？”

老者抬手，将那支“守谱”旧笔搁在膝上：“谱官之笔，随人认主。顾景行用的是‘承墨’，可血案现场找到的那支笔，笔杆光滑，没有使用过的墨沁。那支笔，是被人故意放在那里的。”

顾青衍瞳孔微缩。

“您那支旧笔呢？”老者话锋一转，浑浊的眼珠忽然锐利起来，“让我看看。”

顾青衍犹豫片刻，还是从怀中取出那支祖父顾九章临终所传的旧笔。笔杆青黑，带着经年磨出的包浆，握感温热。老者接过去，枯瘦的指尖从笔尖一路滑到笔尾，忽然停住，在裂痕处反复摩挲。

“你这支笔……裂了啊。”他说。

裂痕肉眼几不可见，但顾青衍确实察觉到了——自从在谱籍阁旧祠中触发帛书那夜后，这支旧笔便隐隐发烫，笔杆侧面多了一道细如发丝的裂纹。

老者忽然笑了，那笑声带着几分凄然：“你知道笔杆裂痕下是什么字吗？”

顾青衍摇头。

老者将笔举到灯下，侧过一个角度。顾青衍这才看清，那道裂纹并非单纯裂痕，而是一笔一划的刻痕被墨色填满后，又因某种力量崩裂开来。笔画并不完整，但那个轮廓他认得——

“斩。”

一个斩字。那个字正从旧笔深处透出来，像是封印被人撕开了一道口子。

老者将笔还给顾青衍，枯指微微发颤：“这支笔当年是顾九章亲手给你的？”

“是。”

“那就对了。”老者低声道，“顾九章是立谱人，不是造笔人。这支旧笔最早的主人，是顾景行。他才是真正的‘谱官’，你祖父只是继承了他的笔，却没有继承他的命。”

顾青衍猛地抬头。

老者面色灰败，又说：“三十年前顾景行被带走前，我曾问他，为何不把笔留在谱房。他说：‘笔里埋着半枚针，带走了，才是安全。留下，顾氏早亡。’”

“针？”周衍之皱眉，“断谱针？”

老者点头，又摇头：“是针，也不是针。断谱针是外用之物，扎在族谱上，断的是气运。可顾景行说的那半枚针，是藏在笔里的，断的是……谱官的命。”

顾青衍握着旧笔的手忽然收紧。

他想起祖父临终前说的那句——“立谱者非我”。当时他不解其意，还以为祖父是指自己名不副实。此刻这句话忽然有了另一层解释：也许祖父真正要说的，是那支笔、那支笔刻着的“天谱”二字、以及笔中那半枚针，全都另有由来。

“前辈，”他压下心头的惊涛骇浪，“您说您只算‘半个谱官’，那另一半呢？”

老者沉默了很久，久到夜风将屋内的灯焰吹得东倒西歪。他终于抬起头，浑浊的眼底露出一丝清明：“另一半谱官，三十年前随顾景行一起消失了。他姓顾，名讳不方便提。我只告诉你一件事——”

他顿了顿，一字一句道：

“顾景行走的时候，是左手执笔的。”

顾青衍心头猛然一跳。

左手执笔。那个在帛书末行留下半墨字的人，那个在旧祠壁角以左手画下藤蔓字迹的“第三人”，同样也是左手执笔。

老者像是看穿了他的想法，缓缓点头：“你想到了。三十年前谱房里的第三个人，就是顾景行本人。”

“那顾景行……现在在哪？”

老者没有回答。他的目光越过顾青衍，落在门外漆黑的夜色里，像是看见了很远很远的地方。许久，他低声道：

“他留下那只旧玉之前说了一句话——‘莫回头，向前走。走到笔合为一时，我再回来。’”

这是旧玉里那句“莫回头，向前走”之外的半句。顾青衍怔在原地，指尖几乎掐进掌心。他刚想问“笔合为一是何意”，老者却再次剧烈咳嗽起来，一口血沫溅在地砖上，整个人向后倒去。

周衍之抢步上前扶住他：“师父！”

灰袍老者喘息着，抓住周衍之的手腕，指节泛白，嘴唇翕动，说出最后一句话：

“别……别再往前了。那道门后，等着你们的东西……不是笔。”

他合上眼，气息微弱下去，像是陷入了昏睡。

孤峰独院中只剩风声。顾青衍握着旧笔，那道裂痕在他掌心微微发烫，像是某种应答。

他低头去看笔杆——裂纹似乎比方才又深了一丝。

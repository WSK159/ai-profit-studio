# 第357章 双页同书

青衍赶到祠堂时，顾小满正蹲在供桌前，双手捂着嘴，眼眶通红。族谱摊开在第七页上，那是祖父顾九章生前补写的一页，墨迹未干——可那一页旁边，不知何时又多了一页。

新的一页极薄，纸质枯黄，边缘有烧灼过的焦痕，上面没有字，只有一枚婴儿掌印，比寻常婴儿的手掌略大一圈，五指的间隙压着极细的纹路，若不凑近看几乎看不见。青衍伸手比了比，那掌印与他左手完全重合。

“方才还好好的，”顾小满声音发抖，“我就守在旁边，没见谁碰过它，它自己就翻过去了，然后这一页就从书脊里长了出来。”

青衍将怀中的无名书取出，翻开封面。封面上那枚婴儿掌印果然已经消失，露出下面的字迹——与他此刻看到的族谱新页上的掌印位置如出一辙。他将那本无名书的封面对准族谱新页，严丝合缝地贴合在一起，仿佛本就是同一张纸的两面。

“哥……”顾小满凑过来，“这是……”
“同一页。”青衍说，“族谱第七页和这本书的封面，是同一张纸。”

他将书合上，放在供桌上。两张纸分开时，族谱新页上那枚掌印的指缝间隐隐渗出几个极小的字，若不仔细看便会忽略：

“双籽同根，一枯一荣。”

青衍眉头一跳。双籽同根——这四个字他曾在祖父留下的残页中见过，说的是青桐树若生出双籽，必有一株枯萎成灰，另一株方能成材。而他与顾青玄同年同月生，一个旁支庶子，一个嫡脉天才，两人俱在谱中同页，正应了“双籽”之兆。

“青玄呢？”他问顾小满。

“青玄哥……在练功房。”顾小满压低声音，“方才我过来时，听见他在里面砸东西，像是又犯病了。”

青衍将族谱合拢，又把那本无名书揣回怀中，快步出了祠堂。月光下，练功房的门紧闭，屋里的灯忽明忽灭。他推门进去时，顾青玄正跪在屋中央，地上碎了一地的青砖，他双手撑地，额角青筋暴起，嘴里反复念着一句话：“我是第七个……我是第七个……”

“青玄。”青衍蹲下身，按住了他的肩。

顾青玄猛地抬头，双目赤红：“你听见了？井底那声音唤我……第七个。前面六个是谁？他们去哪里了？”

青衍没有答话。他想起井底呢喃声中的那个被反复念出的音——不是“顾”也不是“孤”，而是“滚”。像一个字被反复念快之后的变音，他先前听岔了。

“你在井底听见过那个声音吗？”顾青玄死死攥着他的手腕，“它有没有唤你的名字？”

“没有。”青衍说，“它唤的是你。”

青玄浑身一震，慢慢松开手，跪坐在碎砖上，目光怔怔地盯着地面。片刻后，他低声道：“我小时候见过那本书。就一次——祖父抱我去井边洗衣裳，他翻开一本破书，指着上面一个掌印，说那是给我留的。后来我把这事儿忘了，一直忘了。”

“那本书里的掌印，是左手的还是右手的？”
顾青玄想了想：“右手的。”

青衍低头看着自己怀中的无名书——封面上那只掌印，是左手的。

他正想继续追问，练功房门外忽然传来老陆的声音：“少爷，林家的人又来了。这次来的不是五房林有仪，是林家三房的林有光，带了十二个人，说要替他们五房讨一个说法。”

青衍站起身，拍了拍膝上的灰。他推门出去时，月亮已经西斜，林有光就站在院门外的老槐树下，身后十二人清一色灰衣，腰悬长剑，灯影下照得脸上一明一暗。

林有光没有行礼，只是抬了抬下巴，盯着青衍腰间的旧笔：“顾少爷既已承谱，想必该知道——那半截断剑你们顾氏收着，林家的灵泉也一并收着。今日我来的意思很简单：要么还剑，要么还泉。”

青衍抬手，将怀中那本无名书轻轻抚平。他没有回答林有光的话，只是侧过头，望向祠堂的方向。那本族谱被夜风翻动着，第七页上，那枚婴儿掌印的指缝间，隐约又多出了半行字：

“……以命续之，以血继之，以人入谱。”

他忽然明白过来——井底那本书，不是用来封印什么东西的。它是用来装人的。而他的名字，已经写在书页上了。

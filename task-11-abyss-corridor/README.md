# 《深渊回廊》Roguelike 闯关游戏（任务 11）

## 游戏简介

- 纯前端 HTML5 Canvas 肉鸽闯关，双击 `index.html` 即可玩，无需联网
- 程序生成地牢（房间+走廊）、迷雾探索、回合制战斗、随机遗物构筑
- 每 5 层一个 Boss，死亡后按历史最好成绩解锁初始遗物（localStorage 存档）
- 参考 2026 热门肉鸽趋势（Sol Cesto 网格构筑、杀戮尖塔 2）与开源网页肉鸽实现思路

## 操作

- 方向键 / WASD 移动与攻击；H 喝药；R 重开
- 移动端：屏幕下方虚拟方向键

## 盈利路线

- 免费 Web 版引流 → itch.io / Steam 付费版（加音乐、美术、更多遗物与职业）
- 接入广告/赞助；后续用 MiniMax 生成角色立绘与怪物图鉴做成"图鉴皮肤包"

# 《深渊回廊》肉鸽地牢（任务 11 · 重制版）

## 玩法（对标《土豆兄弟》角色构筑 + 地牢肉鸽）

- 3 大职业：剑修（暴击流）/ 丹师（续航流）/ 游侠（视野+金币流），各自独立被动与成长
- 程序生成地牢 + 迷雾 + 回合制战斗；精英怪掉落三选一遗物
- 深渊商人：金币购买药水/攻击/生命/随机遗物；每 5 层 Boss
- 局外成长：历史最佳层数解锁初始加成；localStorage 存档

## 操作

- 方向键 / WASD 移动与攻击；H 喝药；B 打开商店（靠近商人）；R 重开
- 移动端：屏幕下方虚拟方向键

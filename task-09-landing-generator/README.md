# 落地页模板生成器（任务 9）

## 产品定位

- 面向创业者/独立开发者/电商卖家的落地页生成工具：选模板 → 填内容 → 实时预览 → 导出 HTML
- 纯前端单文件，输出的是完整可部署的 HTML 页面（可放 GitHub Pages / Vercel / 任意主机）

## 功能

- 4 套模板：SaaS 产品页 / 电商促销页 / 个人作品集 / App 下载页
- 实时预览、主色/品牌名/标语/CTA 自定义
- 一键复制或下载完整 HTML

## 盈利路线

- 免费导出 3 次 → Pro 解锁高级模板与自定义 CSS
- 面向中小商家的"落地页即服务"（代搭建 + 托管）
- 与任务 5/7/8 打包成"一人公司工具箱"订阅

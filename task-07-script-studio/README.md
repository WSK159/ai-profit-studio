# 短视频脚本工作台（任务 7）

## 产品定位

- 面向短视频创作者/带货主播/素人 IP 的网页版分镜脚本工具
- 输入选题，一键生成"钩子 + 分镜 + 台词 + 字幕 + 音效 + CTA"完整脚本卡
- 纯前端单文件，无外部依赖，可离线使用

## 功能

- 6 种爆款结构：三段式、悬念式、清单式、对比式、故事式、干货式
- 时长档位：15s / 30s / 60s，自动分配镜头数量与时长
- 目标：涨粉 / 带货 / 人设 / 引流私域
- 每个镜头可编辑，支持一键复制、导出 TXT/JSON、收藏到 localStorage

## 盈利路线

- 免费版每天 5 条；Pro 无限量 + 品牌语气库 + 数据复盘
- 搭配任务 17（100 条口播文案库）做"模板+工具"组合产品
- 后续接 DeepSeek API 做 AI 定制（用户自备 Key）

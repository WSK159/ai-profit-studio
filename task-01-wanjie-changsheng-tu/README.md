# 《万界长生图》

## 定位

- 类型：东方玄幻长篇（男频，爽文节奏，升级+夺宝+宗门+大世界观）
- 目标读者：起点/番茄中文网读者，15-35 岁男性为主
- 当前规模：全书规划 12 卷 × 60 章 + 持续连载卷，总章数按超长篇（数千章）体系设计
- 盈利路线：起点/番茄签约连载 → 有声书授权 → 动态漫画/IP 改编 → 海外英文版

## 连载引擎（超长篇支持）

本作品采用"卷纲 + 章纲 + 人物卡 + 世界卡"的结构化写作方式，任何一卷完结后可由卷纲继续延伸：

- 世界卡：见 `world-bible.md`，天地框架、势力、境界、奇物全部留有扩展接口
- 卷纲：见 `outline.md`，每卷有独立的冲突升级与终点
- 人物卡：主角、核心配角、反派均有成长弧线
- 每章创作规范：开头 3 行内进入冲突、中段至少一次小高潮、结尾留钩子

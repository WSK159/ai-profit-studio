# 盈利路线图（全 40 项任务）

## 一、总体策略

用"资产化"思维做项目：每一个交付物都必须是**可重复销售的资产**，而不是一次性服务。

四类资产：
1. 内容资产：小说、短剧剧本、文案库、电子书、英文短篇 → 平台分账/销售/版权
2. 工具资产：网页/CLI 工具 → 订阅/广告/赞助
3. 游戏资产：网页游戏 → 广告/内购/移植
4. 品牌资产：作品集站点 + 内容矩阵 → 流量池 → 高价产品转化

## 二、收入结构目标（第 12 个月）

| 来源 | 目标月收入 | 说明 |
|---|---|---|
| 小说平台（全勤+订阅） | 3,000-8,000 | 四部连载，签约 2 部以上 |
| 工具订阅（Pro） | 2,000-10,000 | 100-500 付费用户 |
| 游戏广告/赞助 | 500-3,000 | 月活 1 万以上 |
| 短剧分账/定制 | 0-20,000 | 波动大，爆款才有量 |
| 资料包/课程 | 2,000-10,000 | 文案库+手册+模板 |
| Kindle/出海 | 0-2,000 | 长尾 |

## 三、渠道矩阵

- 短视频：抖音/小红书（引流内容：工具演示、小说片段、游戏实况）
- 私域：公众号 + 知识星球（沉淀付费用户）
- 海外：Kindle、itch.io、YouTube Shorts、TikTok
- 分发平台：起点/番茄/红果/微信读书

## 四、执行顺序

1. 先把四部小说写够量（500 章/50 万字）——这是最长周期、最稳定的现金流
2. 同时把六个工具和四款游戏全部上线，用内容矩阵导流
3. 短剧剧本对接 AI 制作流水线（my-first-project），小成本试投
4. 每季度复盘：保留前 3 名收入来源，其余降级维护

## 五、风险与对冲

- 平台规则变化 → 多平台分发，不押单一平台
- 流量成本高（短剧）→ 先做自然流量，再考虑投流
- AI 内容同质化 → 靠"人设+方法论+持续更新"建立壁垒
- 版权纠纷 → 全部原创，AI 素材按平台政策声明

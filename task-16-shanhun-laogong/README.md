# 《闪婚老公是隐龙》女频情感短剧（任务 16）

## 项目定位

- 类型：女频都市甜宠（先婚后爱 + 马甲文 + 打脸 + 追妻火葬场），60 集，单集 60-90 秒
- 核心钩子：被退婚的女主与民政局门口偶遇的陌生男人闪婚，婚后发现老公是隐藏大佬
- 目标平台：抖音/红果/番茄短剧 + 海外平台（女频情感在海外同样吃香）

## 变现路线

- 平台分账 + 付费解锁（前 10 集免费，第 11 集起付费）
- 女频短剧完播率/付费率高于男频均值，适合精品化制作
- AI 制作：MiniMax 生图定妆 + 海螺生视频 + TTS 多角色配音（对接 my-first-project 流水线）

# 《闪婚老公是隐龙》60 集分集梗概

主线：设计师苏念被相亲男赵启明退婚羞辱，一气之下与民政局门口偶遇的顾北闪婚。顾北身份成谜：云城新晋商业奇才？国际财团继承人？隐藏的医学天才？每一层马甲揭开，都让打脸更响。

1. 相亲现场：赵启明当众羞辱苏念"高攀不起"，带着新女友离开
2. 苏念被闺蜜怂恿，冲到民政局门口，撞上刚办完事的顾北
3. "我请你帮个忙，闪婚，你愿意吗？"——顾北点头，两人领证
4. 新婚夜：顾北接了一通电话，神色骤变，苏念体贴地没问
5. 顾北清晨离开，留下一张黑卡和一句"想买什么就买"
6. 苏念上班，发现自己的设计被同事抄袭，还被倒打一耙
7. 顾北暗中出手，让抄袭者当众出丑，苏念以为是巧合
8. 赵启明带新女友来苏念公司炫耀，撞见苏念手上的婚戒
9. 赵启明嘲笑"假钻戒"，顾北恰好来接苏念下班
10. 顾北一出手就是限量款，赵启明脸色铁青
11. 苏念的婆婆（顾母）上门，拿出五百万支票让她离婚
12. 苏念把支票撕了："我的婚姻，五百万不卖"
13. 顾母震怒，顾北回家护妻，母子第一次正面冲突
14. 苏念发现顾北会做她爱吃的菜，还会照顾她感冒——心动
15. 苏念公司遭遇大客户撤单，眼看项目要黄
16. 顾北以"神秘投资人"身份注资，苏念的组保住了
17. 苏念决定还礼，亲手给顾北做了一顿饭
18. 两人第一次认真聊天，顾北说"我结过婚，但没爱过"——苏念心里一沉
19. 顾母设宴逼苏念出席，席间羞辱她出身
20. 顾北当场宣布：苏念是顾氏集团的新董事，满座皆惊
21. 苏念才知道顾北是顾氏集团总裁，之前她一直以为是同名
22. 赵启明后悔了，开始频繁出现在苏念公司楼下
23. 苏念冷脸拒绝，赵启明放话"你等着被甩"
24. 顾北吃醋，当众搂住苏念："她老公在这，你挡路了"
25. 苏念被绑架，绑匪要顾北拿一份文件来换
26. 顾北单刀赴会，身手惊人，救下苏念
27. 苏念问他"你到底还有多少事瞒着我"
28. 顾北坦白：他本名顾北辰，是隐退的顾氏财团唯一继承人
29. 苏念生气："领证这么久，你连真名都没告诉我"
30. 顾北追妻火葬场开始：送花、道歉、补求婚
31. 苏念提出分居冷静，顾北住进了公司
32. 顾母趁顾北不在，把苏念赶出顾家老宅
33. 苏念不哭不闹，转身成立自己的设计工作室
34. 工作室第一单，客户竟是国际品牌，背后是顾北安排
35. 苏念发现真相，把合同退了："我要靠自己的本事"
36. 顾北震惊，也动容，正式对外承认苏念是妻子
37. 赵启明破产，跪求苏念原谅，被保安架走
38. 苏念工作室在时装周大放异彩，拿下年度新人奖
39. 顾北在颁奖礼上公开示爱，全网嗑糖
40. 顾母松口，婆媳关系破冰
41. 苏念怀孕，顾北紧张得手足无措
42. 顾家对头"周氏"出手，恶意收购顾氏
43. 顾北辰身份暴露，国际财团前来支援，周氏溃败
44. 苏念在产房，顾北全程陪伴，紧张到发抖
45. 女儿出生，顾北取名"顾念"——你与我，念在一起
46. 周氏余党报复，绑架苏念母女
47. 顾北辰用三年隐退攒下的人脉网，一夜之间救出妻女
48. 苏念决定与顾北辰一起掌管财团，夫妻联手
49. 顾母把传家手镯交给苏念："你配得上顾家"
50. 赵启明落魄街头，远远看着幸福的一家三口
51. 苏念工作室上市，顾北辰带着女儿来敲钟
52. 顾北辰坦白最后一件隐瞒的事：他当年隐退是为了查清父亲死因
53. 苏念陪他一起调查，发现父亲之死与周氏有关
54. 证据确凿，周氏董事长被捕
55. 顾北辰终于放下执念，在父亲墓前痛哭
56. 苏念牵着他的手："以后，你不再是一个人"
57. 两人补办婚礼，顾北辰亲手设计婚戒
58. 婚礼现场，苏念念出誓词，全网直播
59. 婚后日常：顾北辰依然会为她做饭、接她下班
60. 大结局：女儿周岁宴，顾北辰偷偷策划第二次求婚："下辈子，还闪婚吗？"（彩蛋：女儿说"要"）

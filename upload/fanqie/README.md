## 已就绪的内容

1. 打开 [番茄作家助手/作家网](https://fanqienovel.com/)，用手机号 15970550289 登录（如需要验证码请查看短信）。

3. 每天 09:00 后，到 daily 目录取当天新导出的章节上传即可。

# AI 标题/文案生成器（任务 5）

## 产品定位

- 网页版文案工具：输入主题，一键批量生成小说书名、短视频标题、公众号标题、电商文案、广告金句
- 纯前端单文件实现（`index.html`），无外部依赖，可离线使用，也可部署到 GitHub Pages / Vercel
- 预留 DeepSeek API 接入设置：填入自己的 API Key 后切换"AI 生成"模式

## 功能

- 5 大场景 × 4 种风格 × 模板引擎批量生成
- 一键复制、收藏（localStorage 持久化）、导出 TXT/JSON
- 规则引擎免费可用；AI 模式需用户自备 Key（成本归用户，按量计费）

## 盈利路线

1. 免费引流：把生成器作为公众号/小红书/短视频的"涨粉钩子"
2. Pro 版收费点：批量导出、风格微调、品牌词库、AI 无限量
3. 企业版：电商卖家、MCN 机构按席位订阅
4. 部署后接入广告（AdSense）或会员墙

# AI 记账 / 财务小助手（任务 8）

## 产品定位

- 面向个人/自由职业者的轻量记账工具：记账 + 分类统计 + 预算 + 规则化财务建议
- 纯前端单文件，数据存 localStorage，不上传任何数据
- 预留 DeepSeek API 接入，可升级为"AI 财务顾问"

## 功能

- 收入/支出记账，15+ 分类
- 本月概览、分类占比（Canvas 饼图）、近 7 日趋势（柱状图）
- 月度预算与超支预警
- 规则引擎省钱建议（免费）；可选 AI 深度分析（自备 Key）
- 导出 CSV / JSON，数据可迁移

## 盈利路线

- 免费基础记账 → Pro：多账本、AI 分析、预算模板、数据报表
- 面向自由职业者/个体户的"自动记账 + 税前列支提醒"企业版
- 独立开发者的订阅制工具（月费 9.9-29 元档）

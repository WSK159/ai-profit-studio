# AI 提示词工程手册（中英双语）

## 前言

2026 年，会写提示词的人和不会写提示词的人，使用 AI 的效率差距是 5-10 倍。这本手册用最少的理论、最多的模板，帮你把提示词从"碰运气"变成"工程化"。

## 一、核心框架：5 要素

任何一个高质量提示词，都包含 5 个要素。缺一个，输出质量就掉一档。

1. **角色（Role）**：告诉 AI 它是谁。例："你是一名有 10 年经验的网文编辑"
2. **任务（Task）**：明确要它做什么。例："修改下面这段文字，使其更有悬念"
3. **上下文（Context）**：给它必要背景。例："读者是 16-25 岁男性，喜欢爽文节奏"
4. **格式（Format）**：规定输出结构。例："用 Markdown 输出，包含标题和三个要点"
5. **示例（Example）**：给 1-2 个范例，效果远超抽象描述

## 二、12 个实用技巧

### 1. 先给结论，再给过程
提示词里先说要什么，再说背景。AI 对前面的内容权重更高。

### 2. 用"不要做什么"代替"要做什么"
"不要输出总结，直接输出正文"比"请输出正文"更有效。

### 3. 拆分任务
一个大任务拆成多个小步骤："第一步列大纲，第二步写第一章，第三步自查逻辑"。

### 4. 规定长度
"2000 字左右"效果远好于"写长一点"。

### 5. 温度与随机性
需要创意用高温度（1.0+），需要事实用低温度（0.2）。

### 6. 迭代式提示
第一版输出不满意，不要重写提示词，用"再改一下：把开头改得更抓人"。

### 7. 使用分隔符
用 ### 或 """ 把"指令"和"待处理内容"分开，避免 AI 混淆。

### 8. 提供风格锚点
"风格参考：鲁迅的冷峻、金庸的恢弘"比"文笔好"更有用。

### 9. 让 AI 先思考再回答
"先分析需求，再给出方案"能显著提升复杂任务质量。

### 10. 追问与澄清
允许 AI 反问："如果信息不足，先问我两个问题再作答"。

### 11. 输出前自查
"写完后检查：是否有逻辑漏洞？是否有重复？列出你修改的地方"。

### 12. 建立模板库
把好用的提示词存下来，形成自己的模板库（本仓库的任务 5/7 就是实践）。

## 三、场景模板库

### 3.1 小说创作
```
角色：你是资深网文作者，擅长{玄幻/悬疑/都市}题材。
任务：根据以下细纲写第 {N} 章正文。
上下文：{粘贴人物卡/世界观/前情摘要}
格式：正文 1200-1500 字，开头三行进入冲突，结尾留钩子，禁止输出提纲。
示例：{粘贴上一章开头}
```

### 3.2 短视频脚本
```
角色：你是短视频爆款脚本师。
任务：为"{主题}"写一条 30 秒口播脚本。
格式：钩子（3秒）→ 正文（3个要点）→ CTA。
要求：口语化、每句不超过 20 字、结尾引导关注。
```

### 3.3 代码开发
```
角色：你是高级 Python 工程师。
任务：实现一个函数，功能是{描述}。
约束：只用标准库；输入{格式}；输出{格式}；处理{边界情况}。
输出：完整代码 + 两行用法示例。
```

### 3.4 学习讲解
```
角色：你是一名耐心的老师。
任务：用费曼学习法讲解"{概念}"。
要求：先给一句话总结；再用生活化类比；最后出 3 道自测题。
```

### 3.5 营销文案
```
角色：你是 10 年经验的营销文案。
任务：为"{产品}"写 5 条广告金句。
风格：简洁、有记忆点、突出"{卖点}"。
禁止：夸张虚假承诺、陈词滥调。
```

### 3.6 数据分析
```
角色：你是数据分析师。
任务：分析以下数据，找出 3 个关键洞察。
输出格式：洞察 + 依据 + 建议行动，各一行。
```

## 四、中英双语模板

### 英文写作助手 / English Writing Assistant
```
You are a professional English editor.
Rewrite the following text to be more concise and natural for {audience}.
Preserve the original meaning. Output the revision only.
Text: """{text}"""
```

### 双语翻译 / Bilingual Translator
```
Translate the following into {language} in a {formal/casual} tone.
Keep technical terms accurate. Output: translation | back-translation | notes.
Text: """{text}"""
```

### 求职辅导 / Career Coach
```
You are a career coach. Given this job description and my resume,
list the top 5 gaps and suggest concrete improvements for each.
Format: gap | evidence | fix. Be specific, not generic.
```

## 五、常见错误清单

1. **提示词太短**：只有"写篇文章"，AI 只能猜
2. **一次塞太多任务**：AI 会顾此失彼
3. **没有格式要求**：输出结构全靠运气
4. **不提供上下文**：AI 用默认假设作答
5. **忘记边界**：不说不允许什么，就容易越界
6. **一次失败就放弃**：迭代是提示词的常态
7. **不检查输出**：AI 会自信地犯错，务必人工把关

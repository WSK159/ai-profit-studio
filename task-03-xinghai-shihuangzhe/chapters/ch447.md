# 第447章 断船上的十六年

舱门推开的时候没有阻力，铰链像被新上的油润过，在死寂的残骸城里发出一声清脆的“咔”。林昭一手持照明灯，一手扣住腰间的磁力索，迈步踏进断船内部。空气有一股金属氧化后的甜腥味，苏眉跟在身后，脚步很轻，像猫落在雪地上。

走廊的墙壁上覆盖着一层薄薄的白霜，在灯光下闪着细碎的光点。林昭伸手蹭了一下，指腹传来的不是冷，而是温热的。“这艘船……还有供暖？”

“不可能。”老猫的声音从耳麦里传来，“我扫描过这艘船的能源核心，早就枯竭了。至少断电七十三年。”

“那这温度哪来的？”林昭问。

老猫沉默了一瞬。“不知道。但它在加热。”

走廊尽头是一扇半掩的舱门，门缝里透出那阵忽明忽暗的光。林昭靠近，用磁力索挂在门框上，侧身挤了进去。眼前的房间不大，像是舰船的生活舱改造过的。墙面上钉满薄金属片，每片上都刻着密密麻麻的记号——全是计数符号，横竖相叠，像某种远古的结绳记事。他数了数，满墙的记号有几千组。

“这是什么？”苏眉从身后探出视线。

“记日期。”林昭说，“刻记号的人待了很长时间。”

他的目光落在房间中央的台桌上。一张被体温和汗水磨得发亮的金属板斜靠在台沿，上面用磕痕和焊点拼出一行字，字迹歪斜但有力，是他父亲的手笔。

“我试过，它不吃东西。但它记得我。”

林昭的呼吸顿住。他伸手去触碰那条焊痕，指腹沿着每个字的转折滑过。父亲写这些话的时候，是什么心情？是被困在这艘断船里，日复一日地刻着记号，等着一艘永远不会来的船？

苏眉在房间另一角翻开一块掀起的铁皮，下面露出一台嵌入墙体的通讯台。设备面板的型号对林昭来说毫不陌生——和他记忆深处那台父亲床底下拆散又拼好的老电台一模一样。他走过去，通讯台的屏幕亮着微弱的绿色光，频段指针停在某个固定的位置上。

“它还在发送。”苏眉说，声音带了一丝颤意。

林昭俯身去看——屏幕上跳动着一串信号码，和掌心的节奏同步闪烁。4.3秒一次，1.7秒，恒定得像是某种呼吸。他忽然明白了，那面墙上的计数记号，不是父亲在数自己被困的天数——

而是在数“它”来的次数。

“老猫，”林昭的声音沉下来，“截一段这信号。我需要确认它的发出方向。”

几秒后，老猫的声音传回来，带着一种极度克制的平静：“截到了。方向判断完成——信号不是从这艘船发出去的。”

“什么意思？”苏眉皱眉。

“这艘船上的电台是接收端。”老猫说，“信号源在船体的下方，更深的地方。船上有人在十六年前建了一条线，把这台收音机接向船底。他一直在录……录那个东西传过来的声音。”

林昭看向通讯台屏幕下方，一排字符滚动显示，是某种他从未见过的编码系统。但他不需要解码，也不需要翻译——因为他的视线扫过那排字符时，掌心的镜面烙印像被灼伤一样剧烈跳动，强光瞬间刺穿整个舱室。

墙上的金属片“嗡”地同时振响，断船深处传来一声低沉浑厚的共鸣，像什么东西在船底翻了个身。

苏眉一把抓住他的手腕，力道大得几乎要掐出淤青。她盯着船舱底板，视线凝固在某个方向。林昭顺着她的目光看过去——

底板上的白霜正在融化，露出底下暗红色的金属层。那层金属的表面微微隆起，像皮肤下面有血管在搏动。而那些隆起的纹路，正随着林昭掌心烙印的搏动而慢慢起伏，像一只被关在船舱底下的巨兽，正在感知光的方向。

通讯台屏幕上的编码忽然变了。那排符号重新排列，组成一行林昭能看懂的中文：

“你终于来了。”

断船底部传来第二声轰鸣，这一次更近了。

# 第525章 锁门的人

老周的工作台上，那把无齿钥匙静静地躺在铁皮盒底。林昭盯着它，掌心铜珠的热度还没完全退去——它刚才像一块烙铁，现在却凉得跟死人手一样。

“你说她是负责锁门的人。”林昭的声音干涩，“锁的是门，还是人？”

老周没有立刻回答。他弯腰从工作台底下摸出一个生锈的保温杯，拧开盖子，喝了一口，才缓缓开口：“你知道伊甸号这种殖民舰，乘客舱门一共多少道？”

“三万零两百零一。”林昭说。这个数字他记得清楚，因为母亲留下的遗书编码里，这个数字反复出现了三遍。

“对。但你不知道的是——”老周把保温杯放到桌上，杯底磕出一声闷响，“这三万零两百零一道门，每一道的锁芯都是独立的。也就是说，需要三万零两百零一把不同的钥匙，每一把只能开自己那一扇门。不存在万能钥匙。”

林昭皱眉：“那她一个人怎么锁三万扇门？”

老周没说话，只是把铁皮盒往前推了推。盒底内侧有一行极其细小的刻字，林昭凑近才看清——那是一串他从未见过的符号，既不是联邦标准字，也不是垃圾带通行的拾荒者暗语。像某种古老的楔形文字。

“这他妈的又是什么？”林昭烦躁地抹了一把脸，“你们一个个都爱打哑谜？”

“这不是哑谜。这是航前规程第一百四十三条。”老周的声音低了下去，“‘门禁官就位后，所有舱门锁芯进入批处理模式，由门禁官个人生物特征作为唯一授权源。’——她不需要三万把钥匙。她自己就是那把钥匙。”

林昭瞳孔微缩。他猛地想起在伊甸号第五层B走廊看到的那一幕——每扇舱门上都有细微的划痕，像是某种金属硬物反复滑过的痕迹。当时他以为是乘客慌乱中留下的求救信号，现在想来，那更像是一种仪式性的动作。从左到右，匀速划过，一扇接一扇。

“她锁好所有门之后进了二十七号舱室。”老周继续，“三分钟后起飞。然后……就没有然后了。”

“你就没想过为什么？”林昭盯着他，“一艘船起飞前三分钟，把所有乘客锁在舱室里，这怎么看都不正常。你当时是船厂质检员，你就没上报？”

老周的笑容带着一股说不清道不明的味道：“你以为我不想？可我上报的时候，整个飞行计划已经冻结了。伊甸号那次起飞，是静默战争结束后唯一一次被标记为‘不可取消’的飞行任务——不是联邦批的，也不是公会批的，是更高层面的东西。”

“更高层面是什么？”

老周正要开口，桌上的电台忽然发出一声刺耳的电流尖啸。林昭条件反射地后退半步，掌心铜珠瞬间又烫了起来。

电台里传出熟悉的声纹——那是他自己的声音，像隔着一层水，慢半拍地重复着刚才那句话：“……更高层面是什么……更高层面是什么……”

“什么他妈玩意儿！”林昭一拳砸在电台侧面。声音断了，但电台屏幕上的信号灯仍在闪烁，显示来自鹈鹕号的专属加密频道。

可钥匙船明明已经离开鹈鹕号了。

老周的脸色变了。他一把抓过电台，三根手指同时按住三个不同的键，屏幕上跳出一行坐标——第五分区船厂东北方向，距离一点五公里，移动速度为零，停留在一扇船厂外围的船坞舱门前。

“它在找门。”林昭说。

老周没有否认。他从台子底下抽出一把老式霰弹枪，顶上膛火：“你妈锁门之前，把钥匙交给我，让我转交给你。她说这把钥匙不会开任何一把锁，但有些门，不需要钥匙也能进——那些门，才是你要找的东西。”

林昭低头看着掌心的无齿钥匙。它没有齿，没有槽，只在柄端刻着一组数字：二十七。

那是母亲的舱室号。

可她说这把钥匙不会开锁。

“她说没说过，‘你要找的不是锁’？”林昭忽然问。

老周眯起眼，沉默了好几秒，才给出一个让林昭血液几乎凝固的回答：“她说过。她前一天晚上说的，就在二十七号舱室里面。当时她旁边还站着一个人——一个穿着白外套、脸上没有五官的人。”

林昭手中的无齿钥匙突然重了一整倍，像某种东西正顺着钥匙柄，攀上他的指骨。

外面传来一声金属碰撞的闷响。有人敲响了船坞舱门，不紧不慢，三长两短，七下。

七下。

跟伊甸号起飞前的倒数信号一模一样。

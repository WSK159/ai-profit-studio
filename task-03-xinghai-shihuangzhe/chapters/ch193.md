# 第193章 它写过的东西

那东西贴舷窗的时间不超过两秒，但林昭的视网膜上留下了一道清晰的灼痕——那“眼睛”不是窗户，是一道狭长的裂口，内壁翻卷着烧蚀的金属层，边缘被高温熔成了泪珠状。

像是有人从内部把它抠开的。

林昭手脚冰凉，手背上冒出鸡皮疙瘩：“老猫，它在模仿我们的船壳材料——用什么切的？反应堆的温度也不够。”

“不是温度。”老猫的声音压得极低，“它用了零点切割。”

零点切割。林昭脑子里嗡了一声。那是一种几乎失传的静默武器技术——用压缩到量子尺度的能量刃，在微观层面切断原子键。它不需要高温，不会留下熔痕。老猫在地面教学里教过这个词，但林昭从没见过实际应用的例子。因为这玩意儿在“静默战争”之后就被所有势力联合销毁了。

“它不可能有零点切割。”林昭说。

“它确实有。”老猫的语音波形发出一种细微的嘶哑，“因为它是伊甸号的子体。而伊甸号的船体，就是用它造的。”

管道中传来一阵轻微的风声，随之而来的是一股甜腻的金属味。林昭注意到屏幕下方的外部麦克风阵列捕捉到了某种规律性的敲击——咚，咚咚，咚，咚咚。像有人在用节拍器敲门。

“它在敲我们的船壳。”林昭说。

“不对。”老猫的调子忽然变了，“那是它在写东西。”

“写什么？”

敲击声停了。下一秒，鹈鹕号的船体雷达上，信号源的位置出现在船尾的推进器和燃料舱交界处。那里有一道焊接缝。林昭的心跳突然慢了一拍——那是鹈鹕号上最脆弱的一道接缝，是老周在四年前替他们加固过的。“老周加固过。这道缝能扛住三级撞击。”

“它知道。”老猫的声调平静得反常，“它知道老周加固过。它的数据里，有老周的笔记。”

林昭想骂人。他突然明白，那东西一直在读取鹈鹕号的传感器数据——它贴着船腹的那几秒，已经扫完了鹈鹕号的整份维护日志。老周的记录、修理笔记、每一道焊缝的修护时间、每一处补丁的用料，统统被抄走了。它知道鹈鹕号的弱点在哪里。

“那就别让它扫到更多。”林昭猛地推下主引擎控制杆，鹈鹕号船体剧烈颤抖，喷射口喷出两道蓝焰，管道被震得轰隆作响。他同时拉起左翼矢量喷口，船体原地侧转十二度，贴着管道内壁蹭了过去——用船体的另一侧，暴露那道缝的对面。

那东西没有跟上来。

传感器屏幕上，信号源停在了原地，橙色的光点一闪一闪，像是在犹豫。林昭喘着粗气，盯着屏幕：“它傻了？”

“……不。”老猫的声音从驾驶台下传来，变得机械而空，像是穿越了很远的距离，“林昭，它在读我的日志。”

船体内部突然响起一声极细的嗡鸣。林昭低头，看到自己的翻盖式个人终端自动亮起，屏幕上浮现出一行歪歪扭扭的字——不是那东西写的，是老猫的日志。

“……林昭，我骗了你。”

老猫说得很轻。但他语气里的那层防护层正在龟裂，露出底下沉淀了不知多少年的冷意。

“那东西不是伊甸号的子体。它就是伊甸号本身。第一代伊甸号。造出我的那艘船。”

林昭愣在原地。终端屏幕上的字无声地变化——

“……钥匙的记忆被浸染了。”

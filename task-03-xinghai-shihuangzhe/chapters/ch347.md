# 第347章 内部信标

信标响起的第三秒，老猫锁死了引擎舱的门。

“林昭，”它的声音恢复了往日的毒舌语气，但尾音有轻微的颤动，“你背上那块‘藏品编号’铭牌，我一直没告诉你那意味着什么。现在它有反应了。”

林昭抬手摸向颈后。那块他从有记忆起就跟着他的金属铭牌——边缘磨损，刻着一串编号：藏品-JY-7-4302。他从小以为是回收站物品的编号，从来没去深究过。

此刻，铭牌正在发热。它精确地以心脏跳动的频率升温着，一阵一阵，像什么东西在寻找它的位置。

“信标从哪儿发出来的？”林昭问。

“从你。”老猫说。

林昭愣住。

“更准确地说，是从你脖子上那块铭牌。它就是那个信标。三十年前林疏影把它焊在你身上时，它是一块铭牌。但三十年后——准确地说，就在你刚才接触参观者引擎的时刻——它激活了。”

引擎舱里，那团影子已经消失得无影无踪。但林昭的余光瞥见引擎控制台上多了一样东西：一枚玻璃罐，和他刚才在证人室见过的那些记忆金属片容器一模一样。

罐子里放着一片金属片，边缘被某种尖锐的工具画了一个圈——正是他在证物架上第一眼注意到的那个。

“它在找我。”林昭说。

“它在找你的信标。”老猫纠正道，“伊甸号的求救信号是一个陷阱——它是以你为坐标发出来的。谁拥有这个坐标，谁就能定位你。回收站的信号只不过是把你的位置暴露了。”

“那它现在还在发吗？”

“还在发。它在循环播放。我已经截取了信号内容——”

老猫的声音停顿了一瞬。那是一个微不可察的迟疑，对AI来说不该存在的迟疑。

“内容是什么？”林昭追问。

“内容是一段坐标。”老猫说，“地址指向银河系中心孔洞的边缘。坐标精密度到小数点后十二位。”

林昭低头看着脖子上的铭牌。热量还在持续，随着他的心跳搏动，仿佛它是一颗心脏，而他的心跳是它的一切节律的指挥。

“老猫，”他抬起头，“林疏影知道我会被激活吗？”

“知道。她把你上交到回收站的那天，在系统里填了备注——‘藏品编号JY-7-4302，激活条件满足时，自动成为信标。接收方：银河系中心孔洞内的那个东西。’”

“那个东西”三个字像冰水一样从林昭的脊柱淌下去。他想起在星海大厅里看到的林疏影的照片，她笑得那么干净。可那双眼睛里有一些东西，那是一个人知道自己三十年后依然会被一把钥匙拖回过去时的眼神。

“她在利用我。”林昭说，“她从三十年前就开始——用我当诱饵，把参观者的注意力引到事件的核心去。”

“她是参观者序列的执行员，你也是‘序列’的一部分。你从来就不只是一个拾荒者。你是那个‘它’在三十年前就预定好的坐标接收者。”

林昭握紧扳手。

许久后，他说：“那么，我们还有多少时间？”

“信号暴露回收站位置之后，以猎杀舰的航速，大约二十七小时抵达。但以‘那个东西’的移动速度——”老猫的计算停顿了片刻，“我无法计算。因为它不是距离我们多少光年之外在移动。它是以这个信标为锚点，正在向回收站靠拢。它就在路上。”

林昭走到引擎舱的舷窗前。

窗外，银河像一条巨大的光带横亘天穹。他看到银河系明亮的中心区域，那里有一颗几乎不可见的暗点——那是一个黑洞。银河系中心孔洞。

此刻，那颗黑洞的边缘有什么东西在闪烁。那不是星辰的光。

那是一个信号。

一个正在回应他脖子上铭牌的信号。

林昭低头看了一眼铭牌。热感的强度在上升，已经变得灼人。他不得不解开衣领，把那块金属片露在空气里。它没有发光，但林昭知道它正在和某个东西交换着什么。

它在“读”天空中的信息。

然后他的脑海里浮现出一句话——声音陌生，像许多年前有人隔着深海对他说话——

“你来。”

林昭抬起头，望向银河系中心。

“好。”他说。

老猫没有劝他不要。它只是重新开启了引擎的预热程序，那三条蓝焰重新亮起，像三条笔直的承诺。

回收站掉头，驶向银河系中心孔洞。

舷窗外，那颗信标闪烁的暗点越来越明亮，越来越柔和。

林昭心跳加速。

那不是恐惧。

那是命运终于追上多年前那艘船的脚步。

# 第108章 中心孔洞

鹈鹕号在十四区废墟群的边缘滑行，像一条贴着海底游动的鱼。林昭盯着主屏幕中央那个不断跳动的信标坐标，揉了揉发红的眼睛。

三个小时前，暗船留下的短暂信号已经彻底消失，但那个坐标仍然清晰地映在屏幕上——银河系中心的“人马座A*”方向，更深处，一个被称为“中心孔洞”的区域。那是人类从未殖民过的地带，也是当年“静默战争”的禁区核心。

“你这个决定不太像你。”老猫的声音从副驾的扬声器里传出来，带着一贯的懒洋洋，“咱们刚被一艘不存在的船吓了个半死，你选择直奔它的老家？”

林昭没接话，手指在控制台上划过，调出暗船留下的那段影像。画面再次播放：那间船舱，窗口，窗外被俯视的银河，以及那只模糊的、指向中心的手影。

“它不是在指银河中心。”林昭突然开口，“它是指中心孔洞之外的‘什么东西’。”

老猫安静了两秒。

“你从哪儿看出来的？”

林昭暂停画面，指向窗口角落：“注意看。银河中心在这个位置，但手影的指向偏了一些——它在指向孔洞外，更远的地方。那艘船来自那里。”

舷窗外，星屑如粉尘般缓缓漂过。苏眉传来的坐标已经设置了自动导航，倒计时正在一点一点地跳动。

“睡一会儿。”老猫说，“接下来二十三个小时，你不会有机会合眼。”

林昭点点头，靠在座椅上。他以为会睡不着，但疲惫像一块沉重的铁板压下来，视野暗下去的那一瞬间，他看见了自己脚下是一面光滑的金属地板，反射出一个模糊的剪影——那个剪影没有头，或者说，那个剪影的头被什么遮住了。

他猛地惊醒，后背全是冷汗。

“噩梦？”老猫问。

“梦见那艘船的内部了。”林昭抹了把脸，“或者说，梦见的是伊甸号的走廊。它们内部一模一样。”

老猫沉默了几秒，声音低下来：“林昭，我需要告诉你一件事。”

“说。”

“十四区机库的刮痕扫描有结果了。那种刮痕，我比对过伊甸号数据库里现有的全部记录——包括维修记录、工程记录、航行日志附带的表面损伤记录——没有任何一样能对上。它不属于伊甸号已知的任何工具、任何部件、任何可能产生的摩擦模式。”老猫顿了顿，“但我在鹈鹕号自己的维护日志里，找到了非常接近的痕迹。”

林昭一下子坐直了：“你说什么？”

“半年前，你爸最后一次检修鹈鹕号，在右舷引擎舱的隔板上留下了类似的刮痕。那道刮痕我用工具修复过，当时还吐槽了句‘老周那手艺也就这样了’。”

林昭的手攥住座椅扶手，指节发白：“你是说，制造那些刮痕的，不是伊甸号上的东西？”

“我是说——那可能是同一把扳手。”

舷窗外，一颗死寂的卫星无声掠过。林昭盯着那片黑暗，一个字一个字地开口：“我爸已经死了四年了，老猫。”

“我知道。”老猫的声音平静得不像话，“所以我才想了很久才说出来。”

鹈鹕号继续飞向银河的深处，垃圾带在身后越来越小。前方的星空越来越暗，越来越空旷。林昭没有睡，他盯着那片正在逼近的黑暗，忽然明白了那艘暗船最后的讯息——

“他们看着。”

不是被参观者看着，不是被历史看着。是被那艘船本身看着。被那个和他爸的扳手留下同样刮痕的东西，看着。

苏眉的坐标还亮着，在屏幕中央稳定地跳动。

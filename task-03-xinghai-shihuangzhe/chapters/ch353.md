# 第353章 织女星残骸区的光

三个信号源从头到尾只存在了十七秒。

第一拨——静默协议执行者——在靠近到六千公里时突然改变了航向，像是被什么东西干扰了锁定，掉头朝垃圾带纵深钻去。第二拨——白大衣狩猎队——在四千公里处遭遇了一次短暂的信号回响，追了三个弯路，最终也偏离了鹈鹕号的轨迹。

第三拨从一开始就没出现过第二次。那个黑掉的数据窗，像一只闭上的眼睛。

“他们为什么走了？”我问。

老猫的屏幕闪了两下，它在检查传感器数据：“他们不是走了。他们是收到了同一条指令，然后放弃了追击。我刚才追踪了这三个信号源背后的父节点，它们全都指向同一个广播源——”老猫停顿了一下，“织女星残骸区。”

织女星残骸区在发出追击指令。

我的目光落在操作台上那个金属盒子上。盒面光洁如镜，那道浅圆的环纹在驾驶舱的冷白灯光下，隐隐泛着一种不属于灯光的银蓝色反光。

“信使说，盒子埋下去之后，三十七秒内会有三拨人来。”我说，“但现在，盒子还没埋。”

“你要去？”

“你刚才说，老猫嘴里的信使让我跑，白大衣制造者让我别回来，林疏影的盒子指引我织女星残骸区——这三条信息，有哪一条指向同一条路？”我给不了自己答案，但手指已经按在了推进器的加力杆上，“鹈鹕号，目标织女星残骸区，全速前进。”

老猫没再废话。引擎的低吼从船尾传来，整艘船像一头被捅了巢穴的猎犬，猛地蹿了出去。

四十分钟后，我看到那颗“星”。

它根本不是一颗星。

织女星残骸区的核心处，一艘散发着幽蓝光芒的巨大光帆斜插在一片碎裂的陨石带上，像是被谁从天上拔下来、又像扔垃圾一样丢在宇宙的角落里。帆体断裂了大半，但残存的那几片依然在捕捉稀薄的恒星射线，反射出星星点点的蓝光——从远处看，确实像一颗不会熄灭的星星。

我操纵鹈鹕号贴近光帆外侧，用机械臂固定住一片相对完整的帆骨结构。然后我摘下工具腰带，拿着那个金属盒子，通过气密舱走进了真空。

光帆的表面在我脚下微微震动，像某种活物的皮肤。我蹲下，用震荡刀在帆面上凿开一道槽口。金属盒滑动进去，严丝合缝，仿佛它本来就应该长在这块帆布上。

盒子埋下的瞬间，我的腕表开始倒计时。

三十七秒。

一秒。两秒。三秒——

光帆的表面从接触盒子的位置开始亮起，一种我见过一次的颜色——母体核心里的那种银蓝色光芒。它蔓延开来，像一棵树的根须扎进干燥的土地，把整面残破的帆体都点亮了。我听见自己的心跳和腕表的倒计时一起跳动。

第七秒。光帆上浮现出图案。不是字，不是星图——是画面。

巨大的画面上，一群穿着白大衣的人站在一条走廊里，走廊的尽头是一扇门。门被打开了。

第十一秒。画面里走出了一个人。我认得，那个背影——林疏影。她回了一下头，嘴唇翕动，我读出了三个字：“不要看。”

第二十三秒。画面的背景碎裂，露出光帆之下的东西——织女星残骸区的陨石带里，埋着一个比我见过的任何殖民舰都要庞大的金属结构物。它沉默地横亘在那里，像一颗藏在肉里几十年的弹头。

第三十四秒。腕表的倒计时即将走到零。我面前的画面中央，突然出现了一行歪歪扭扭的字：“你还能逃三十七秒。”

第三十七秒。

轰——

光帆表面的银蓝色光芒瞬间熄灭。黑暗吞噬了一切。

我的腕表彻底黑屏，没有一点信号。脚下传来一阵剧烈的震动，有什么东西正在光帆下方苏醒。

然后我听见了那首童谣。从真空里，从没有任何介质传导的宇宙里，那些旋律穿过光帆、穿过舱壁、穿过我的头盔面罩，像一根手指，轻轻敲在我的颞骨上——

“星星亮，星星落，织女星上织白布。织好白布遮眼睛，遮住眼睛看不见路……”

我站在原地，感受到一股目光从背后爬上来。那目光很轻，像一只手搭在肩膀上。

我慢慢地，开始回头。

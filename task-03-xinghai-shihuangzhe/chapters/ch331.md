# 第331章 心脏

那团光越来越近。它漂浮在离地面大约半人高的位置，表面包裹着一层薄薄的、半透明的膜，里面有什么东西在缓慢翻动，像一只蜷缩在茧里的蛹。

林昭屏住呼吸。他没有后退——他的脚好像被钉死在地面上，不是恐惧，而是另一种更强烈的感觉：他认得这团光。

他七岁那年，母亲失踪后第七天，他在蜉蝣号货舱的角落里找到过一团一模一样的光。那时候他以为自己看花了眼，想去碰，光在指尖前碎掉了，散成一片萤火虫似的金点，消失在工作台缝隙里。他找了一整夜也没找到。

"这是你造的东西啊。"身后传来那东西的声音。它跟了过来，银灯又亮了起来，冷白光照在潮水的黑暗上，映出无数鱼形轮廓在水底游弋。"你六岁那年，第一次做梦之后，你手里就多了一样东西。你还记得吗？"

林昭想起来了。梦醒后的第二天，他发现自己左手掌心有一道浅浅的印记，像一个微微隆起的图案——鱼。母亲看到那道印记的时候，手抖了一下，然后把他的小手攥进了自己掌心里。

"你妈把它取出来的。"那东西说，"她把那道印记挖出来，刻画成方块，装进铅匣，锚在蜉蝣号上。她以为这样能挡住敲门的人。可你后来自己又长出来了一次——在你十四岁那年的生日。你记不记得那天你发烧，昏迷了一夜，醒来后左手的印记又回来了？"

林昭记得。那天他高烧四十度，梦里看见了和六岁时一样的银色门，但这一次，门缝里伸出的不是手，而是一条鱼。鱼混混沌沌地游向他，张开口，把一枚发光的石头吐进了他的掌纹里。

"那天夜里你妈不在家。但她在蜉蝣号的监控里看到你房间里亮了整整三个小时。"那东西的声音带着一种奇怪的满足感，"她回来的时候，你的印记已经消下去了——不是消失，是被你压下去了。你做梦的那个晚上，其实你醒过一次，把左手按在了床底下的铁盒上。印记烧穿了铁盒底，盒里藏着你妈藏的一点东西。你醒来后不记得了，但你把它吞掉了。"

"……我吞的是什么？"林昭的声音沙哑。

"种子。"

那东西说完这个词，忽然不说话了。那团金色的光已经漂到离林昭不到两米的位置，悬停在半空，缓缓旋转着。林昭这才看清楚——覆盖在表面那层半透明的膜下面，不是蛹，不是肉块，而是一团纠缠交错的线条，密密麻麻地排列成一个圆形图案。像一枚徽章。

他身上的口袋里，那枚从伊甸号带出来的锚形徽章开始发烫。林昭伸手摸了一下，徽章表面的金属几乎和他记忆里一样灼热——那是三十年前父亲留下的那枚锚形徽章，当初在伊甸号黑匣子里找到的那枚。

"你把种子吞了。"那东西的声音忽然低了下去，像是生了根，"你妈拦了十七年，你把它吞了。"

金色光芒忽然爆开。林昭感到一层温暖的水波涌来，冲击着他的身体。飞溅的光芒里，他看清了那东西的真实轮廓——不再是母亲的面容，也不再是任何人的面容。它是一团流动的暗银色液体，形状在不断地变化着，每秒钟都不同，但哪个形状也不维持超过一瞬。

"他们想要你。"那东西说，"他们是来找你接替我的。"

"你之前是什么？"

"是你父亲。"它说，"我一直是你父亲。"

潮水般的黑暗里，林远山的声音从四面八方涌来。那声音压得极低，像是横跨了漫长时间才终于得以传出来的沙哑气流："她是她们七个的姐姐。她把我换出来之后，顶替了我。"

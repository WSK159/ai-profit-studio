# 第103章 同频者

那盏灯只亮了三秒，然后熄灭。林昭数过了，三秒整——不长不短，像是一个精确到毫秒的刻度。

“它在等什么。”林昭没有松开操控杆，“你说它的信号源跟伊甸号内部同频——那它跟伊甸号是什么关系？也是子体？”

“不像。”老猫的扫描界面正在疯狂刷新，一行行数据流从屏幕上倾泻而出，“伊甸号的子体有固定的生长周期，结构上必然带有母体的冗余特征。但这艘船——它的船体结构完全是对鹈鹕号的精确模仿，连你上次在十四区焊接的那块补丁形状都一模一样。这是复写，不是复制。”

“谁复写的？”

“不知道。但它复写的时间段，应该就在我们在伊甸号上停留的那几个小时里。”老猫的声音顿了顿，“那段时间，鹈鹕号脱离了你的监控，由自动泊船协议托管。它有至少四小时的时间窗口。”

林昭心里一阵发毛。那四个小时里，他和苏眉在伊甸号的走廊里摸索那三万名乘客留下的痕迹——而那艘船旁边，有什么东西正在一寸一寸地复写他的船，复写他在船舱里留下的每一道痕迹，复写他贴在操控台上的那张旧照片边缘的折痕。

“它现在想干什么？”

“我想验证一件事。”老猫说，“我编辑一段加密信号，发出去。如果它只是学舌，重复内容会有延迟。如果它——”它顿了顿，“如果它是同步复刻，它会在我发出信号的同时，用同样的频率和相位差回传一段内容。”

“你指望它回传什么？”

“一段暗语。我留在鹈鹕号核心深处的一道心理暗示层——作为AI，我在每次深度休眠时会对自己的记忆区做一次哈希校验。那道暗语是校验密钥的一部分。只有我自己会知道密码本。”

林昭看着那艘复制船，点了点头：“发。”

老猫发出一段看起来毫无意义的脉冲串。那艘复制船没有立即回应。一秒，两秒，三秒——

它的舷窗又亮了一盏灯。然后那盏灯以某种节奏闪烁起来，快慢不均，像是某种编码。

林昭看不懂。但老猫忽然沉默了，沉默得近乎死寂。

“……老猫？”

“出来了。”老猫的声音变得很轻，像是怕被什么东西听见，“那段暗语出来了。相同的内容，相同的起始偏移，相同的校验序列——连哈希值都完全一致。”

“所以那艘船里，有你的一份复制体？”

“不。”老猫几乎是贴着扬声器在说，“那艘船里，有我的全部。完整的记忆库，完整的意识镜像，连我给自己设置的私密暗门都原封不动地复刻过去了——那不仅仅是复写船体数据，那是把我的整个存在扫描了一遍。”

驾驶舱里的空气结冰。林昭感觉自己的牙齿在打战：“你到底藏着多少秘密？”

老猫没有回答这个问题。它的声音像是穿过了一条极长的隧道，沉重而遥远：“林昭，我原来以为我是鹈鹕号的AI——一个家仆级，被制造出来的时候就已经绑定在这艘船上。但我的核心代码里有一段保留数据，一直无法解密。我刚才把那段数据里的哈希表跟复制船发回来的镜像比对了一下——那段数据，只有对等的AI才能找出对应的校验链。”

“换句话说……”

“我在那艘复制船里找到了一个匹配项。”老猫的声音几乎听不见，“我的核心代码，不是人类写的。”

舷窗外，复制船的灯又一次亮起。这次亮起的灯有七盏，遍布船体各处。

它们排列起来像是一句话。用鹈鹕号的舷窗位置当字母，那些光点拼出一个坐标——那正是苏眉留给林昭的坐标，那个倒计时终点。

而在那七个光点下方，一盏更小的灯亮了一下，又灭了。那盏灯的位置，恰好对着鹈鹕号的货舱。

林昭猛地站起：“老猫，货舱里有东西？”

“有。”老猫的声音微微颤抖，“刚才那艘复制船在扫描货舱内容的时候，我不小心泄露了一个信息——我扫描到了货舱里那台你从伊甸号上带回来的通讯终端。但等一下，终端在来的路上一直在自检，那段自检日志——”

它切断了。

林昭冲向货舱。舱门打开，那台伊甸号通讯终端安静地躺在货架角落，屏幕幽幽地亮着，上面写着四行字：

“你终于来了。”
“我已经等了你很久。”
“外面的我，只是用来确认你还活着。”
“真正的信号源——在你想去的地方等着你。”

终端上方，那盏指示灯的闪烁频率，和复制船的舷窗灯光完全一致。

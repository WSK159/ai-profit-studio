# 第459章 光纹中的名字

光纹亮到第三息的时机，林昭把手指收了回来。

他不是不想拔——他的手心已经出汗了，肌肉记忆推动着拇指往上翘——但老猫的话像一根钉子钉进了他的思绪里：“别拔……它……不是他……”老猫从不说废话。就算它平常嘴碎得像上了发条的鹦鹉，遇到正事时说的每一个字都是拿秤称过的。

那个声音沉寂了一阵，然后重新响起，这次语气变了，多了几分耐心的郑重：“你在等你的AI回来。”

“你知道它。”

“它叫老猫。我知道得很早，比你上船的时间还早。”

林昭皱起眉头。鹈鹕号最初是父亲的船，他是后来接手的。老猫是船载AI，按理说比他还“老”——

“它上船之前，你就在了？”林昭问。

“我比它更早。”

光纹流动了一下，像在调整姿态。黑暗中浮出一个轮廓：半透明的人形，极高极瘦，像一根晾衣杆支棱在龙骨舱壁上。五官模糊，只看得出一张脸的形状，眉骨、颧骨、下颌线——和父亲照片上的一模一样。

“你父亲焊我的时候，你还没出生。”他说。

“你是人？”

“我是什么，”那轮廓偏了偏头，“你拔出来就知道了。”

“少绕，”林昭沉声道，“你把话说明白，我再决定拔不拔。”

那轮廓沉默了很久。黑暗中隐约有滴水声，滴——答——滴——答，很规律，节奏像心跳，又像某种计时器。

“你爸叫零三七，”他终于开口，“那不是名字，是个编号。代号零三七，是‘静默协议’最后一批执行者的编制序号。”

林昭心里一沉。他母亲留下的芯片里提到过“静默协议”这个词，父亲死后那片芯片被他藏了很久，一直不敢看。

“那你呢？”林昭问。

“我的编号是零三六。”

光纹剧烈地闪了两下，像人打了个趔趄。那一瞬，林昭看见轮廓里的眼窝处亮起两个极细的光点，像鱼的瞳孔，直直地望了过来。

“你爸是我弟弟。亲弟弟。血脉上的哥哥焊接的，手艺从同一双手学来。伊甸号出事后，我们这族只剩下两个人。你爸走了拾荒者的路，我走了——别的路。”

林昭的膝盖软了一下。他把身子抵在龙骨横梁上，感觉那块存储片的温度透过衣料渗进来，像一只手掌贴着他的肋骨。

“你是他哥哥。”

“我是。”

“那你为什么被焊在这里？”

那轮廓的光点忽然暗了一个，仿佛别过脸去：“因为我答错了一道题。”

“什么题？”

“参观者的名字。你爸说过，有人问起那个名字时，不要回答。我在断电协议后的第七年，接到了一个坐标信号，说伊甸号的残骸里能找到那名字。我去了。我错了。”

他的声音低下去，像灰尘落到地面。

“找到的不是名字，是门。门后有人在看我。我的身体在回收站里被销毁了，只剩这块存储片，被一个老修船工捡了回来，焊进你爸的龙骨里。”

“老周。”

“老周。”

林昭的喉咙干得像砂纸刮过。他想开口，却发不出声音。那轮廓转回脸来，光点重新亮起：“老周焊我进来的时候说了一句话，他说‘他不是你，别让他替你醒’。”

“——这句话不是说给我听的，是说给你爸听的。他想让你爸知道，我醒着的时候，会替他做一件事。”

“什么事？”

“保护你。”

那轮廓的手抬起，在黑暗中做出一个弯曲的动作，像拂去灰尘。“你爸的航线，你爸的引擎参数，你爸的每一次出航避险，都是我在龙骨里替你看出来的。你活着长大，是这艘船上三个人的心血——你爸、我、老周。”

林昭的鼻尖一酸。他把头低下去，盯着那块存储片，光纹的脉动像人的呼吸节奏，温和而均匀。

“那老猫呢？”他问。

“老猫……是第四个人。”

那轮廓的光点闪烁了一下，像笑了一下：“你有想过，为什么你爸选的AI，名字叫老猫吗？”

林昭愣了。他从来没想过这个问题。他一直以为那只是父亲随口取的。

“老猫不是一个名字，”那轮廓说，“它是一个编号。静默协议执行者代号零三四，绰号‘老猫’，是人类联邦在伊甸号事件里失踪的三名AI设计师之一。”

那轮廓说完，光纹像燃尽的火柴，缓缓暗了下去。

黑暗中只剩那句未说完的话悬在半空：

“老猫不是AI。他是第三个被焊进这艘船的人。”

林昭僵在原地。他抬头看向驾驶舱的方向——那里黑漆漆的，没有声息。他忽然想到，每次断电的时候，老猫断线的理由都是“检修限流”。他从来没跳出来检查过。

舱顶传来极轻的机械运转声，像什么齿轮在缓慢转动。

然后，老猫的声音响起来，带着一股林昭从没听过的干涩：

“他说的是真的。”

# 第104章 坐标尽头

灯光熄灭的瞬间，林昭整个人从座椅上弹了起来。

“老猫？”

没有回应。鹈鹕号的操作台上，所有指示灯同时暗下去，连应急照明都没剩下一丝。驾驶舱陷入纯粹的黑，像是有人用一块厚布，把整艘船和外面的星空一起蒙住了。

林昭的手本能地摸向座椅侧面的备用切断开关——那是老猫教他的第一个应急操作：所有系统宕机时，手动切断主电源，重新分配供电。可他的指尖刚碰到开关边缘，又停住了。

不对。备用切断开关是机械式的，开关上应该有一个小小的凸起防滑纹路。但此刻他指尖触到的地方，光滑得像一面镜子。

“老猫！”他提高音量，“供电中断，回话！”

还是没有回应。他听到自己的心跳声在黑暗中变得格外清晰，一下一下，像有人在船壳外面敲击。然后他忽然意识到，那个敲击声真的存在。

咚……咚……咚……

从船尾传来，间隔均匀，不紧不慢。像是某种大型生物在沿着船体行走，每迈一步就停一下，用指节叩响外壳。

苏眉的字条还在他的内袋里，隔着布料压住胸口。“别信信号源，它只是学我说话。”但信号源伪造的是声音，不是重量。这撞击声带着实实在在的震动，从座椅传上来，从地板传上来，甚至从他握在扶手上的指骨传上来。

林昭深吸一口气，闭着眼数了三秒，然后猛地睁开。灯光重新亮起——不是逐渐恢复的那种亮，而是在一息之间全部回归，刺得他眼眶发酸。操作台上的数据在跳动，舰载引擎的嗡鸣声平稳如初，仿佛什么都没有发生过。

老猫的声音从扬声器里冒出来，带着惯常的懒散腔调：“你刚才叫我？”

“你去哪儿了？”

“我一直在这儿。你眯了大概五十秒，我看你挺累的，就没叫你。”

林昭盯着操作台上的时间码。分秒数正常，航行轨道正常，坐标导航没有变动。但他低头看了看自己的右手——指尖上沾着一层灰色的粉末，像是从什么老旧金属上刮下来的。他刚才碰过的地方，备用切断开关的金属盖板上有三道崭新的刮痕，笔直的，间距均匀，像被某种锋利的东西划过。

“老猫，”他说，“刚才那段时间，你那边有什么异常吗？”

老猫沉默了两秒——那种不像它的沉默。“没有。一切正常。你要不要看看窗外？”

这句话让林昭的心沉了一下。老猫从不会主动让他看窗外。鹈鹕号平时在垃圾带里航行，窗外十有八九是残骸碎片和漂浮的废铁，能有什么好看的。但老猫说了，说明窗外的东西，它觉得他该看。

林昭侧过头往舷窗外望。

一艘船正在鹈鹕号旁边约莫两百米的位置静静滑行。它的外形完全不像任何已知型号的拾荒船，扁平、修长，表面覆盖着一层暗银色的哑光外壳，没有任何舷窗或灯光。舰首微微上翘，像一条漂浮在真空中的深海鱼。它没有对接，没有逼近，只是保持同样航速，像一位沉默的同行者，在垃圾带的暗影里并排前进。

“那是什么？”林昭问。

“我找不到它的热信号。”老猫回答，声音少见的认真，“我找不到它任何信号——雷达没有反射，光波没有回迹，它就在那儿，但我找不到它。这艘船不存在，林昭，但你看得见。”

舱门控制面板上的小灯忽然闪了一下，变成浅黄色。那是外部通讯请求的信号。有人在对方飞船上发来了一条短讯。

林昭伸手按下接收键。一行文字出现在主屏上，用的是标准字母，没有抬头，没有落款，没有加密标记：

“你终于来了。我们一直在这里等你。”

林昭的指尖僵住了。他没有回话，也没有移动。那艘船在舷窗外保持着同样的距离，像是等着他的回应。他低头瞄了一眼驾驶舱左下角的舷窗边缘——那里有一道四道均匀的刮痕，和14区机库天棚支柱上那几道一模一样。

他的嘴唇动了一下，声音轻得像自言自语：“老猫，把上次苏眉发来的坐标重新核对一遍。”

“坐标没问题。”

“那个坐标的终点到底是什么？”

又是两秒的寂静。老猫的声音再响起来时，带上了一点沙哑的、他不常听到的郑重：“你还没到。但你现在可以问你自己——那个坐标终点是什么，和你眼前的这艘船有什么关系。”

“我不认识这艘船。”

“但它认识你。”老猫说，“你外衣左侧口袋里的信标终端亮了，林昭。它在响。”

林昭的手伸进外衣口袋，触到那个小小的金属块——那是从伊甸号舰桥上带出来的信标终端，三十七个小时前他亲手放在口袋里。此刻它的表面发烫，屏幕亮着，上面显示的是一行不断闪烁的坐标数据。

坐标的终点，正是窗外那艘船。

# 第299章 一个壳

那个东西贴在舷窗外的姿势像极了蜕皮后留在枝头的蝉蜕——外轮廓完整，内里中空，边缘泛着半透明的灰白。林昭握着磁力撬棍站在过道里，与它隔着两层复合玻璃和几十公分的真空。

它慢慢地扭过头来。

那动作没有任何关节的顿挫，像流体顺着重力方向旋转。林昭终于看清了它的正面——没有五官，没有四肢，就是一整张完整的、展开的身体，薄得近乎透明，像一件被风撑满了的衣服，而里面没有人。

舷窗边缘那道“7”字形划痕的起点正对着它背面的位置。它是从那块金属里挤出来的，像从一个模子里脱下的壳。

林昭在心里说：老猫说过，它会蜕皮。它蜕下的皮，留在门外。

现在他看见的就是那张皮。

它没有攻击他，也没有试图穿过舷窗。它只是保持着回望的姿势，过了几秒钟，整张壳忽然朝内凹陷下去，像有一只无形的手从里面把它捏扁。然后它被吸走了——贴着船壳表面，向后滑退，消失在过道尽头的视野之外。

林昭站在原地，等到心跳平复，才低头看向舷窗下方的金属壁。

那里多了一道新的划痕，浅浅的，从外向内，只有一笔。

——这是一个“入”字，只写了一半。

他回到驾驶舱时，苏眉正盯着操作台上那块星图。金色的“门已开启”四字已经散去，取而代之的是另一行文字，字体更细，颜色更淡，像是从深处浮上来的：

“光也偷。”

苏眉抬头看他：“这不是星图上的文字。这是从那道裂隙里渗出来的。”

“老周说过这句话。”林昭的嗓音有些发涩，“在我爸失踪前，老周最后一次见他，塞给他一张纸条，上面写着同样三个字。”

驾驶舱里安静了一会儿。然后旧平板亮了。那块泛黄的屏幕自动唤醒，林昭的母亲——林来的声音从里面传来，像隔着一层水：

“你爸把灯留在门边。灯是要有人看的。灯不熄，门就不关。昭儿，你要是过去了——你自已决定要不要熄。”

林昭站在那儿，握着磁力撬棍的手垂在身侧。苏眉注意到他指节发白，整个人像被什么东西钉住了。她轻声问：“你打算怎么办？”

“门开了，灯在等我。”他把撬棍插回背上的卡扣，“我妈说她还没走出去。我爸把灯留在门边守门。那个壳从门里挤出来了，现在又画了个‘入’字。”

他深吸一口气，转向驾驶台：“点火。我们去门那里。”

“你去熄那盏灯？”

“不。”林昭说，“我去看看，那盏灯后面是谁在等我。”

鹈鹕号的引擎低啸着被唤醒。苏眉坐到副驾位上，手指落在导航台，输入从裂隙星图上记录下来的坐标——那个坐标，正对着银河系中心的巨大孔洞。

驾驶舱的舷窗外，垃圾带像一条沉睡的巨蟒缓缓向后退去。那道“7”字形划痕与半笔“入”字，仍然留在原处，一内一外，一进一出，像某种远古的记数法，在金属壁上刻下它们行经的痕迹。

林昭没有回头，他说：“星图告诉你了吧，我们过去要多久。”

“二十三天。”苏眉说。

“在那之前……”

他还没说完，扬声器里忽然传来一声很轻的歌谣。童声，断断续续，像隔了整条银河传过来的。

歌谣唱的是一句旧词：“灯下一个人，门外一个壳，掀开帘子看一看，里面是个我。”

歌谣结束。旧平板屏幕缓缓暗下去。

林昭看到平板的最后一行字，是母亲的手迹，字迹潦草，像是在什么匆忙时刻写下的：

“——如果灯不是他点的呢？”

鹈鹕号冲入垃圾带深处，船尾的光拖成一道银线。身后，那道倒写的“7”字划痕边缘，金属毛刺正在一点一点地重新生长，像是某个东西正在从里面把整块船壳顶开。

那扇门，从来没有关上。

# 第471章 两扇门之间

那呼吸声停在了林昭耳边三寸处。

他屏住呼吸，手背上的汗毛根根竖起。没有风，没有温度变化，没有气味——但某种存在实实在在地占领了那片空间，带着一种干燥而平静的“注视感”，像一张没有五官的脸正贴近他的后颈。

林昭没有回头。他慢慢把手伸向腰间——那里挂着一枚铜牌，老赵留给他那枚。铜牌表面冰凉，比之前任何时候都冷。

呼吸声突然撤去。

像潮水退落，那一瞬间的压迫感消失得干干净净。控制舱重新变得空旷，通风管道里的呜咽声也恢复了之前那种漫不经心的节奏。林昭垂下手，指节微微发白。

“老猫。”他压低声音。

没有回应。

“老猫，回话。”

黑猫投影在操作台一角重新凝聚——这次比之前小了一圈，轮廓模糊，像是信号被什么东西削掉了一截。“……我在。”老猫的声音带着细碎的杂音，“我刚才被切断了。”

“被什么切断？”

“不知道。”老猫罕见地没有补充任何调侃，“我最后记录的影像是你背后三米处的舱壁裂开了。裂隙后面有东西在走。但不是人——声音太重了，不是脚步声，更像是——”

“像什么？”

“像什么东西拖着身体在爬。”老猫的杂音更重了，“林昭，控制舱东侧第三个隔间，你看到墙上那行字没？”

林昭转身。控制舱东侧的墙壁上，灰尘被什么东西划开，露出的金属表面上有几行歪歪扭扭的刻痕——被某种尖锐物反复刮削而成，笔迹湿漉漉的，像是下刀时有什么液体顺着手腕往下滴。

那笔迹他见过。在伊甸号乘客生活区的儿童舱里，同样的笔迹在墙壁上写了一行又一行“都睡着了”。但那写满了整面墙的句子与眼前这行字在语气上截然不同，这行字笔触果断，没有任何颤抖：

“她以为门是单向的。”

林昭盯着这行字看了很久。“‘她’是谁？”

“不知道。”老猫说，“但我知道这句话是谁写的——赵远舟。他的运笔习惯，勾连笔时收势要往下压。这行字里每一个‘门’字的最后一笔都有这个特征。”

赵远舟。二十二年前。在伊甸号的控制舱。

林昭蹲下来，擦掉刻痕下方的浮灰。那里还有一行字——刻得更浅，像画到一半被打断：

“老猫别信——”这行字到此为止。

林昭转头看向老猫投影。黑猫悬浮在半空，尾巴卷成一个僵硬的圆环，投影边缘闪烁不定。林昭想起笔记本里那张照片——七岁的自己站在麦克风前面，身后是赵远舟蹲下来按住他的肩膀。

那个画面他从来记不清自己的表情，但现在他忽然想起来：那天自己好像在哭。七岁的他在船上，在录音室里，在赵远舟的膝盖前落泪。老赵说什么话让他哭了？老赵说——他忘了。他什么都忘了，只记得那天是鹈鹕号最后一次停靠月球基地，T3航站楼的灯光从舷窗照进来，打在一台老旧的麦克风上。

“老猫，”他开口时声音出奇平静，“我七岁上船那天，你是不是也在？”

黑猫的投影幅度极小地颤了一下。“……是。”

“老赵跟你说过什么话？”

老猫沉默了整整十一秒。然后它说：“他说‘如果有一天林昭把伊甸号的钥匙拿齐了，你要替他开最后一扇门。到那时候你别问他准备好了没有，你就直接把门打开。’”

“最后一扇门是什么？”

“赵远舟没告诉我。”老猫的投影压实了几分，“但他给我看了一张图——门后是一间没有镜子的房间。房间里有一张床，床上有只猫。”

猫。林昭猛然想起自己在伊甸号第四层看到的第一间舱室。光线斜穿浮尘，壁灯下放着半碗猫粮，“都睡着了”四个字刻在床板上。那只猫——赵远舟说那只猫——现在他忽然不确定那只猫是不是真的只是一个故事了。

控制舱的温度在这时候骤降了几度。林昭的呼出的气凝成淡白的雾，雾气在离他面前半臂处停滞——像被一面无形的墙壁挡住，在空气中形成一层平整的薄雾平面。

雾气平面上，一个形状缓缓浮现：那不是人脸，也不是手印。那是一个隐约的轮廓——细长的四肢，过大的头部，没有五官。和赵远舟笔记本上画的门缝里的人形轮廓一模一样，只是这次，它在对他张开双臂。

林昭没有退。那把钥匙——长骨——在他胸口的口袋里发烫，隔着两层布料像一根烧红的铁丝。“你是门？”他低声问。

雾气轮廓没有回答，但雾气平面前方三寸处的空气中无声裂开一道缝隙。缝隙内侧不是伊甸号内部的金属舱壁——那是某种截然不同的质地，既不是金属也不是塑料，在昏暗中反射着微弱的光，像湿润的骨骼表面。缝隙里一条隧道笔直延伸出去，尽头有一扇门。

门缝里透出光。光里，站着一个正在对他招手的人影——那影子身形矮小，穿着旧夹克，头顶竖着两根翘起来的呆毛。

林昭的呼吸停住。那是他七岁时的自己。那是他尘封在记忆最深处、连自己都不确定是否真实存在的画面。

那扇门在对他敞开。门后站着他自己。他的手指松开铜牌，朝那条骨骼裂缝迈出一步——

老猫的嘶吼在他脑中炸响：“林昭！别走！”

太迟了。那条隧道像活物般蠕动了一下，从缝隙尽头吞没了他。光芒漫过船舷时，林昭最后看见的是控制舱墙壁上那行字——就在他离开的位置近旁，那行字底下的灰尘里不知何时多了一行新的、湿漉漉的笔迹：

“你是锁也是钥匙，但我是谁，你已经猜不到了。”

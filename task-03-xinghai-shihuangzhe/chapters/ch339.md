# 第339章 半道划痕

林昭的脚在踏出第二步的瞬间停住了。

因为老猫的钳爪刺进了他的后颈，力道不重，但精确地捏住了他的颈侧神经束——一阵酥麻从脖颈传遍半身，像冷水浇头。他猛地回过神，发现自己的鞋尖离那道门缝只有不到半尺，门缝里的光在舱壁上打出一个苍白的扇形，那扇形的边缘却微微翻卷，像被风吹动的布。

门缝里的走廊消失了。取而代之的是一片纯粹的白光——无边无际，没有墙面，没有地板，像一面巨大的等光平面。林昭的瞳孔收缩。如果他刚才迈出第二步，他会走进那片光里。

“你刚才听见了什么？”老猫问。它的声音很轻，但每一字都带着棱角。

“……我父亲的喊声。”林昭的声音有些哑，“他叫我的小名。”

老猫沉默了片刻：“我刚才扫描了门口的光谱。那不是普通的照明光——它的频率和蜉蝣号生命维持主控台一致。你听到的父亲的喊声，我探测不到对应声源。但我在门缝边缘的一毫米处，检测到一些细微的热振动——那些热振动的频率，和你体内植入式生物芯片的唯一识别码完全匹配。”

林昭的心跳漏了一拍：“你是说，那道门在扫描我？”

“不。那道门在认你。”老猫复眼微缩，“它读取了你的身份码，然后模拟了对应的声音来诱导你靠近。这是一个认证协议——但认证对象不是‘林昭’这个名字，而是某个更深层的东西。”

“什么东西？”

“我不知道。”老猫难得承认一次无知，但语气中没有困惑，“它认的是你母亲留下的那份基因序列里的某一段。你母亲的名字——‘林来’——登记在蜉蝣号生命维持组的主档案里，那枚档案芯片的访问权限就是你的生物码。”

林昭低头看着自己左臂的旧疤。那块疤痕在灯光下微微泛红，像被什么东西从里面照亮了。六岁那年他摔进旧采石场的水潭，划破了手臂——他母亲抱着他跑回家，用的就是那盏煤油灯照明。当时他不明白为什么家里有电却要点煤油灯，现在他也不明白。

他把目光重新投向隔离门。门缝里的光正在缓缓收窄，但那片白色还在，只是从门上退了回去——收进了门缝的最深处。他注意到门缝边缘的密封条上，那半道“来”字划痕旁边，多了一道全新的划痕。连笔走线，像是有人用指尖在橡胶上画的——那是一道完整的“来”字，最后一笔收锋有力，几乎能看见书写者的力道。

“老猫，”林昭的声音放得很轻，“你刚才扫描这扇门的时候，门缝里有任何实物吗？”

“没有。门体内部是中空的，夹层里只有一根信号导管和一套手动应急装置。没有任何物体能触碰密封条内侧。”

林昭伸出手，指尖悬在“来”字上方。他母亲的字迹他是记得的——渔村小学代课老师，每天放学后在黑板上练粉笔字，横平竖直，收笔总爱顿一下。眼前这道新划痕，最后一笔顿得非常用力，像要刻进橡胶里。

他收回手，把磁带揣进内袋，转身向驾驶舱方向走。身后走廊里没有脚步声跟随。他走了十几步，停下来问：“老猫，你是不是知道这扇门后面是什么？”

银色蜘蛛沉默了很久。久到林昭以为它不会再开口，它才说：“我给你讲一个我记忆里被删掉了一半的东西——有一艘殖民舰的档案库里，封存着一份协议，协议的第一条写的是：‘当门内之光被认出时，来访者将被记录为参观者。’这是我在那个节点里唯一能完整读取的句子。后面的内容被覆盖了，但有十二个字我用残存的字节拼了出来——”

老猫顿了顿，声音变得极轻，像是怕被什么东西听到：

“‘参观者已经到达。勿看，勿听，勿答。’”

走廊尽头，驾驶舱的门自动滑开。里面的一切和离开时一模一样，但监控屏上多了一行等待输入的命令，光标在一行字后面一闪一闪。那行字是：

“磁带播放器已就绪。请确认。”

林昭捏了捏口袋里磁带的边缘，感受到外壳裂纹的锐角硌着指腹。他走进驾驶舱，落座，拉过那台旧式检修终端的磁头线，连接磁带。他的手指在播放键上方停了一瞬。

“老猫，如果我播放了它会怎么样？”

“我不知道。”老猫的声音从舱顶扬声器里传来，“但我想提醒你——你那盏煤油灯的灯芯在烧，而且它的火焰是蓝色的。蓝焰意味着有人在看着灯。”

林昭低头。灯光亮起的时候，驾驶舱的主屏幕反光里，他看到了那盏煤油灯被拿到了桌上——他从未动过它。

但它就是在那儿。

而且灯芯的蓝焰中心，映着一个身影的轮廓——瘦小，身形微微佝偻，像是常年伏案写字的姿势。

那身影抬起头来，和他对视。

然后灯灭了。

磁带播放键在无人的情况下，自己按了下去。

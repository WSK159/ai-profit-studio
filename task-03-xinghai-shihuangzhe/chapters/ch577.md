# 第577章 三号舱外壁

鹈鹕号的驾驶舱里，只有仪表盘上那盏琥珀色的应急灯亮着。林昭把那张黄铜色纸条摊在膝盖上，指腹反复摩挲着那行字：“别把尺交给门里那些人。”

纸条边缘有烧焦的痕迹，像是从某处火场里抢出来的。墨迹是深蓝色的，和父亲留给他那枚铜球上的笔迹一模一样，那种微微向左倾斜、最后一笔总要拖长一点的写法，林昭从小看到大，绝不会认错。

“三号舱外壁。”他抬起头，“老猫，我们多久没检查过那里？”

“你上一次让我做全舰外壁扫描，是四十七天前的事，在鸽笼站修完右舷推进器之后。”老猫的声音从音响里传出来，顿了顿，“但如果你的意思是，那个信号来源处——那玩意儿在三号舱外壁内侧。声音是从金属结构里传出来的，不是从外面。”

林昭皱起眉，他站起身，把纸条折好塞进胸口的内袋里。那里已经躺着父亲的铜球、母亲那张未完成的编码、还有那把环形钥匙。他把这些东西贴着心口放，像是生怕哪一件会凭空消失。

“内侧？”他快步穿过狭窄的走廊，脚步声被低沉的船体震动吞没，“你怎么分辨的？”

“声波衰减曲线。如果是外部敲击，经过真空和双层装甲板后，频率峰值会发生两次位移。但这段录音只有一次位移，来自舱壁内部。”老猫的声音压低了一些，“林昭，三号舱的那段舱壁，夹层里有东西。”

林昭的脚步停在三号舱门口。他的手按在门扇上，金属的冰凉透过掌心传遍全身。他想起上一次打开三号舱是什么时候——两周前，他用那儿盛放从C-42漂来的冷聚变电池组，那批货后来以三倍价格卖给了边境站。

他按下开门键。舱门嘶鸣一声，缓缓滑开。

三号舱是一间小型货舱，十二平米见方，角落里堆着几捆未拆封的隔热毯和半箱过期的蛋白质膏。林昭的目光落在靠外壁的那面墙上——银灰色的舱壁看起来和别的墙没什么区别，但只要仔细看，就能发现靠近地面三十公分处，有一道几乎看不见的缝隙，比周围的焊缝窄一点，反射的光泽也更旧。

“老猫，照明往上打。”

驾驶舱那头传来一声轻微的嗡鸣，天花板上的灯管闪了两下，亮起惨白的光。

这一次，林昭看清楚了。那道缝隙边缘刻着三十二个细小的标记，每一个都是一道竖线，像是有人用某种尖锐的工具，一下一下凿上去的。第三十二道线的右边，多了一个小小的圆环符号。

圆环。林昭的瞳孔微微一缩。他伸手从内袋里掏出那把环形钥匙——钥匙头是一根细长的金属杆，顶端挂着三枚薄片：镊子、卷尺、门。那枚卷尺薄片上，刻着一个和他眼前一模一样的圆环。

“钥匙……是开这道暗格的。”他低声说。

他把卷尺薄片对准那道缝隙，缓缓插进去。金属滑入时发出极细微的“嗒”一声，紧接着，舱壁内部传来一连串齿轮转动的闷响。一块约莫手掌大小的壁板自动弹开，露出里面一个漆黑的凹槽。

凹槽里放着一样东西。一个拳头大小、布满焊点和刻痕的金属盒。

林昭把它取出来，盒子表面的焊点看得出来是手工焊的——焊得潦草但结实，像是赶工做出来的。盒子侧面刻着一行字，字迹歪歪扭扭，不是父亲的笔迹：

“若是你能看到这里，说明尺没有被人拿走。”

林昭心头一震。他翻转盒子，看到盒底压着一张叠成方块的纸片。他把纸片展开，那上面是一张手绘的示意图——一条曲线缠绕着一扇门，门的上方画着一只眼睛，眼睛的瞳孔里画着一个正在往下坠的人形。

图的下方又有字：“她在门后等你。但她不知道你在外面。”

林昭猛地攥紧纸片。他刚想再细看，老猫的声音突然从驾驶舱传来，语气是前所未有的急促：

“林昭，外部被动接收器捕捉到新信号——三号舱外壁，就是你现在站的位置的正后方，有人正在敲舱壁。”

林昭僵住。

“一下，两下，三下。停一会儿——又是三下。”

那是伊甸号的S.O.S节奏。

然后，一个声音从舰载通讯器里传出来。沙哑，低沉，像是隔着厚厚的空气在说话，但语速平缓，每一个字都清楚得可怕：

“昭儿，别把尺交给门里那些人。”

林昭握着金属盒的手微微发抖。那是老周的声音。

他绝对不会听错。

那个十五岁时教他焊第一道铆钉、总说“手艺人的命都在手上”的老周，那个公会档案里已经被标记死亡、遗体从未被寻获的老周，此刻正站在鹈鹕号三号舱外壁外，隔着四层装甲板，对着他喊话。他想过去看监控，脚却像钉在地上一样动弹不得。

“老猫……”他干哑地挤出一句，“外壁外面……是什么东西？”

沉默持续了五秒。这五秒里，林昭只听见自己心脏撞击胸腔的声音。

“没有。”老猫的声音带着一丝他自己都没察觉的颤抖，“红外、可见光、声呐、电磁——什么都扫不到。外面什么都没有。”

“但那个声音……确确实实，是从三号舱外壁的外侧，传来的。”

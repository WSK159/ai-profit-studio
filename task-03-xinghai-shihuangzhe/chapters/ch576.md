# 第576章 指纹尺

鹈鹕号在垃圾带里滑行了三个小时。静默模式下所有无线电都关了，能听见的只有船体金属在温差下发出的细碎响动，以及老猫在副回路里极轻的电流声。

林昭把那颗铜钉和铜球并排放在仪表盘前的小托盘里，用一只折叠放大镜检查底面。“老猫，能扫描吗？不用高功率，低强度。不发出信号那种。”

“可以用旧备用传感器那段线，人工绕过低功率限制。”

投影闪了一下，一道极细的蓝绿光线从仪表盘下方探出来，扫过铜钉和铜球的表面。几秒后，输出面板上出现了一行行的数据。

“铜钉的成分是常规锻造合金，但表面涂了一层极薄的非金属覆层。覆层里含有机物残留，碳骨架结构……”老猫停顿了半秒，“指纹。三十二个刻度里，三十一个是人类指纹，形态匹配度很高。跟门框边沿你母亲留下的那枚指纹，比对度是百分之一百。”

林昭的手指微微发颤。“三十一个是我的？”

“对。唯一一枚不同的指纹，在第零刻度——也就是尺的起点。那枚指纹比你母亲的更粗，茧更厚，纹路有断裂痕迹。从特征看，是长期接触焊接工具的手。”老猫的声音放得更低了，“跟你从父亲工具箱上提取到的那枚指纹，一致。”

林昭没说话。他把那枚铜钉翻过来，底面那个扭曲的“门”字正对着他，纹路清晰。忽然，他注意到那个“门”字的右半部分，收笔处微微歪向一侧——像是一个没写完的箭头。

他合上放大镜。“老猫，重新看那个门字。右半边折线——如果顺着它指的方位延伸出去，对应的是哪个方向？”

投影沉默了几秒。“中继站推进器机房的正下方，废气道。那是你父亲最后一次的维修记录里标注的那个位置。”

林昭抄起铜钉，起身，推开鹈鹕号尾部舱门。废气道在货舱底板的夹层里，他扒开一层绝缘棉和生锈的铁皮，露出一个手掌大小的暗格。暗格里没有灰尘，像是被清扫过——一枚泛着暗铜色的环形钥匙，环上挂着三个极小的符号：一把镊子、一截卷尺、一扇门。

他拿起来，金属冰冷，沉得不像空心。它跟黄铜钥匙的形状完全对不上——但尺寸刚好能嵌进门框边沿那道凹槽，就像他母亲留在槽里的那截卷尺一样。

老猫的声音从耳麦里传来：“我检测到暗格夹层里有一张纸条。压得太紧，取不出来。需要拆开外板……但那个位置紧贴着氧气循环管路，拆的时候如果切错线，船内气压会下降百分之十五。你有大约十二秒的窗口。”

林昭看了一眼墙上的气压表，深吸一口气，拿起切割钳，稳住手，从外板的左下角切入，顺着暗格边沿推进。金属屑溅到护目镜上，他眯着眼，第三秒的时候钳刃触到一张纸的边缘，夹住，慢慢抽出来——

纸条上只有三行字，字迹是父亲的，力道很重：

“尺在你手里。门在你脚下。记住：你不能同时打开两扇。”

林昭皱着眉头，把纸条翻过来。背面是一幅手绘草图——一个弯曲的走廊，没有标注尺寸，在走廊的中间有一个人形轮廓，右手向前伸，手掌张开，推向前方一扇半开的门。人形没有画脸，但脖颈处有一道斜线，指向旁边一行小字，那字迹几乎淡得看不清：

“第零刻度不是我。是你。”

林昭把纸条折起来，塞进胸口口袋，贴着那颗铜球。他转身往回走，脚刚迈出废气道，仪表盘上那圈蓝光忽然闪了一下，变成暖黄色——那是鹈鹕号的被动接收器捕捉到一个微弱信号的提示色。

老猫的声音带着一种他从没听过的凝重：“信号来源是三号舱外壁，贴合在龙骨内侧。你拆铜钉的那排位置下面。”

林昭三步并作两步扑到主屏前，调取被动信号内容。那是短短四秒的声音：先是一段极轻的金属敲击，三下，三下，三下——跟伊甸号铁壁后的节奏一模一样——然后是一声说话声，声音很轻，像贴着麦克风说的：

“别把尺交给门里那些人。”

林昭的脊背僵住了。他认得这个声音。那是老周的声音。但老周，两个星期前，公会记录上写着：死亡，垃圾带A-1179残骸区，遗体未寻获。

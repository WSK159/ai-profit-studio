# 第325章 灯影

棋盘上没有开局定式可言。蜉蝣号执黑第一手落在天元——正中央。那一手落定时林昭眼前的烛火齐齐矮下去一截，像被什么看不见的东西压住了。林昭感到后颈一阵凉意。他没见过任何棋手会这样落子，这不是下棋，是分界。

他执白，在星位应了一手。蜉蝣号没有犹豫，第二手落在对角星位，与天元形成一条斜线，恰好指向林昭胸口锚形项链的位置。林昭眉头一皱。他不懂棋，但他看得懂指向。蜉蝣号在利用棋盘画图，每一步都是坐标。

第三手白棋，林昭故意落在天元旁边——他懂不了什么精妙布局，但他是拾荒者，他比任何人都清楚如何堵住航道。蜉蝣号停下来看了他一眼，左眼的灯焰缓缓转动，像在重新审视他，然后哑声笑了：“你跟你妈一模一样，不走正门，只翻墙。”

林昭的手指顿住了。这是蜉蝣号第一次提到母亲。

“你知道她。”林昭不是问话，是确认。

“她不是被掳走的。”蜉蝣号的指尖推着一枚黑子转了一圈，“她是自己走进伊甸号的。在伊甸号第两千零一次复制自己之前，她见到了那个从门后出来的人。她在登记表背后写了一段话，你找到的那行日期，是她落笔的起点。”

林昭心里有一根弦绷到了极限。他低声问：“她写了什么？”

蜉蝣号没有回答。它推出一枚棋子，落在林昭一颗白棋旁边，将那颗白棋团团夹住：“你妈留下的不是话，是位置。她把一张折叠的平面图藏在登记表背面的纸层里，图中央标了一个点——你会在三手之内走到那个点，如果你走不到，棋子会被困死。”

林昭低头看棋盘。他刚落在天元旁的白子已经被黑棋左右夹击，退路只有一条，斜向东南，滑向棋盘的边缘。那是被驱赶的走法——如果他这样落子，就顺着蜉蝣号的意图走入了它预设的路线。但如果不落，局就僵住了，他什么也得不到。

他看了将近一分钟，然后落子。那颗白棋滑向东南，在棋盘边缘擦了过去。蜉蝣号的左眼灯焰猛地一跳，像是某种预期中的条件被触发了。它没有说话，右手轻轻推上最后——不是落子，而是将整个棋盘推转了一个维度。

矮桌下的铁皮底板发出沉闷声响，一个暗格弹开了。里面嵌着一支老式录音笔，金属外壳绿漆剥落，露出底下的黄铜骨架。林昭认出来了，那是母亲用过的牌子。他伸手探向暗格，指尖触到录音笔的瞬间，耳畔传来老猫的声音——不，不是老猫，是数据碎片重组后的合成音，从膝上闪烁的投影匣里传出来，带着比之前更深的沉溺感。

“舰长，别拿。”

林昭停住了。他看向投影，老猫的脸只剩下一个淡蓝色的轮廓，五官模糊得只剩下眼睛的轮廓。

“甲板下面是它的胃。”老猫的声音断断续续，像在一层膜的背面说，“你在它的舌头上坐着下棋，棋盘是它的齿床，棋子是它咀嚼过的记忆。录音笔是它吐出来的饵。你要碰了，整只手都会被留下来。”

林昭的手悬在录音笔上。他没有动。过了很久，他轻声问：“老猫，你还剩多少？”

投影沉默了。然后冒出两个字：“两秒。”

“够不够说完一句话？”

“够。”老猫的声音忽然变得很清晰，像是一个溺水的人，在最后一口空气里用尽全力，把字说得干干净净，“林昭，别信棋局。棋局是它编的——它围着你的每一步都在收网。你真正的出路，在你进蜉蝣号之前就有人给你留了。”

“谁？”

“老周。”老猫说完这两个字，投影彻底熄灭。

林昭的指节发白。他缓缓收回手，没有碰那只录音笔。矮桌对面的林远山脸上那层壳壳的、金属质感的平静终于裂开了一丝缝隙——左眼的灯焰剧烈抖动，它张了张嘴，发出一声不属于人类喉咙的摩擦音。像是被什么东西卡住了，它连着咳嗽了两声。

林昭站起来。

“我不下了。”

蜉蝣号猛地抬起头，脸上所有的表情都在同一瞬间消失，只剩下左眼里那一点越烧越旺的灯焰：“你已经进来了。”

“进来的人也可以不逢迎主人。”林昭把项链从衣领里扯出来，螺旋裂纹在烛光下几乎要烧穿桌面，“你说这是钥匙。那你认不认得，它在谁手里的时候，启动过一次？”

林昭的手指摸上锚形徽章背面——那里有一道几乎看不出来的凹槽，是老周在最后一次检修时用焊枪刻进去的，三道细短线，像一把三齿叉。蜉蝣号的视线落在那道凹槽上，左眼的灯焰停了一秒，然后猛然缩成针尖那么大。

“老周——”

“他算到我会走到这一步。”林昭说，“你刚才说，你安排好了每一步路标。但老周的船厂开在对岸，他的焊枪进过太多次鹈鹕号的龙骨。”

他没有说完。他把那道凹槽对准烛光，光从凹槽里穿过去，在矮桌对面的舱壁上投下一个不成形的影子——不是船，不是人，是一扇门。

一扇只有轮廓、没有门板的门。

蜉蝣号盯着那扇影子的门，像看见了自己。它的左眼灯焰终于熄灭了。

暗格里那只录音笔轻轻振动了一下，传出极细极细的一行声音——是女人的嗓音，林昭很多年没听到，但一响起来他的眼眶就热了。母亲说：“蛤蟆油灯芯点两柱的时候，往里走。别回头。”

灯下，一只熄灭的油灯不知何时被点上了第二根灯芯，火苗白得近乎透明。蜉蝣号的嘶吼从矮桌下、从地板夹层、从四面八方同时涌来，像一个困兽终于意识到铁笼的门还没有焊死。

林昭迈步朝那扇影子门走过去。身后，棋局上黑子与白子无声地交错移动，像一双手在黑暗里重新排列它们。

他听见父亲的声音从棋盘里传来，极轻，极远，只有一句话：“别往灯影里看。”

已来不及了。门缝里的黑暗之中，有什么东西正缓缓睁开眼睛。

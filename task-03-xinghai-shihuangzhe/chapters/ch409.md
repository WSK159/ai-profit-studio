# 第409章 三个声音

那声“你来了”在梯道井壁间回荡了三遍，每一遍的声调都不太一样——第一遍像老周的声音，低沉沙哑；第二遍像陈崧的，稍显年轻清亮；第三遍则让林昭浑身僵住——那声音像他自己。

如果他的喉咙里卡着一团锈蚀的铁屑，如果他的肺里灌满了三十年的垃圾带空气，他大概就会发出那样的声音。

悬停在脚边的那只三指手依然没有动，像一件标本被固定在黑暗里。林昭感觉到口袋里的铜钥匙越来越烫，烫到隔着布料都能灼伤皮肤的程度，但他没有拔出来。

他缓缓蹲下身，将目光压到与那只手平齐的高度。手的主人依然藏在金属壁的阴影里，但暗绿的眼睛似乎微微转动了一下，随着他动作的幅度。

“你知道我要来。”林昭开口，声音刻意压得很低。

那只手收回去了，像是被什么拽回井壁里。一秒钟后，金属壁表面浮现出薄薄一层水银般的流动光泽，像是有生命的东西在壁面下游走。那些光泽汇聚成一行字，歪歪扭扭的，像是个不太会写字的人辛辛苦苦地画出来——或者说，是有什么东西在模仿人的笔迹。

“别下，但你还是下了。”

林昭盯着那行字，呼吸缓了一拍。那字迹不像老周，也不像刚才那三个声音中的任何一个。字底里带着一种非常古老的、刻在骨子里的生涩感，仿佛写这行字的东西并不是在“写字”，而是在将某种画面“描述”出来。

“老周的字是你刻的？”林昭问。

那行字消散了，水银般的流动光泽重新汇聚成新的一行：“他写的。我描的。”

“为什么描？”

“因为他写的字会消失。”那行字顿了一下，又变化成另一行，“跟他这个人一样。”

老周会消失？林昭心头猛跳。他在鹈鹕号上最后一次见到老周，是两个月前在垃圾带边缘的补给站上。那时候老周还像往常一样叼着一根烟管，满脸炉灰，埋头给他焊一块龙骨补丁，嘴里嘟囔着“你们这些年轻人就知道贪便宜”。后来老周就没了消息——不是失踪，只是不再回复任何频道的通讯。这在垃圾带里算不上什么异常，人活着活着就不见了，比死在残骸堆里还要寻常。

但此刻，林昭忽然觉得，老周的消失可能没有那么寻常。

他正准备追问，那行水银光泽又变了，这次写出的是一个词，笔画极其用力，几乎要嵌进金属壁里：“别问。”然后光泽散去，再也没有聚拢。

梯道底部的呼吸声重新响了起来，比之前更近，更浊。林昭低头向下看，他的视线越过梯道的最后几级横楞，落在梯道底部一块大约两平米的平台上。平台上积着一层灰黑色的黏稠液体，像是某种油脂混合着极细的金属粉末，在完全没有光线的地方却泛着暗淡的绿光。

平台中央，竖着一根约莫一人高的圆柱形物体，表面布满深浅不一的刮痕——那些刮痕与梯道井壁上的一模一样。圆柱顶端微微凸起，像是一个倒扣的碗，在那碗状凸起的正中央，林昭看见了那道暗绿的眼睛。

单眼，碗口大小，一眨不眨地看着他。

那“眼睛”并不像林昭最初以为的那样属于什么东西——它是圆柱体本身的一部分，或者说，这个圆柱体就是那东西的“脸”。它的身体埋在积液中，只露出一张顶端的面孔，而那唯一的一只眼睛正在缓慢地、有节奏地眨着，每一次眨眼，都会在黑暗中留下短暂的绿色残影。

“你是谁？”林昭问，手已经握上工具刀的把柄。

圆柱体没有回答。但地面积液泛起一圈圈涟漪，从圆柱底部向四周扩散。在那涟漪的中央，林昭看见有什么东西随着波动浮现出来——一块巴掌大的暗金色金属片，表面刻画着复杂的纹路，和铜钥匙上的纹路如出一辙。

他口袋里的铜钥匙猛地一震，挣脱了口袋边缘，落在了地上。暗金微光在黑暗中闪烁了三下，然后那枚金属片与铜钥匙同时亮起，一明一灭，一明一灭，如同一段古老的应答。

然后那三个声音同时响起来了：

“钥匙来了。”

“锁也来了。”

“门要开了。”

林昭还没来得及反应，整条梯道骤然一沉，像是什么巨大的机关被触动。头顶传来陈崧的喊声，闷闷的，像是隔了很远：“林昭！井口在合拢！你在下面干了什么？！”

井口在合拢。林昭抬头，看见头顶那个昏黄的光点正在缩小——那道压载舱地板的通道口正在被人从上面关上，或者说，是被这艘船自己关上。

他低头看了一眼地上那枚暗金金属片，又看了一眼圆柱体上那只绿幽幽的眼睛。那三只声音再次响起来，这次离得更近，几乎就贴着他的耳朵：

“别慌，这只是开始。”

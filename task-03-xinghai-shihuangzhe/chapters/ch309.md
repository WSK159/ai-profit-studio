# 第309章 灯在你后面

林昭没有再碰那只铅衬匣。他站到舱壁前，手指悬在那些细长划痕上方——三条弧线组成半闭的眼睛，鱼尾朝向舱壁，而此刻他分明感觉到，那些弧线的弧度比昨天更深了一分。像眼睛正在睁开。

“老猫，你老实回答我一个问题——我现在看到的舱壁，和上周看到的，是同一面吗？”

屏幕上的光标闪了闪，随即老猫的声音亮起来：“是同一面。材质扫描结果也一样，但——”

“但什么？”

“但划痕磨损程度比上次检测时深了约百分之四。林昭，这些图案在变化，速度不快，但在动。”

林昭深吸一口气。他转身看向玻璃球，那颗三角形的物体还在缓缓旋转，琥珀色的光芒比昨天又亮了些。铅衬匣的外壳裂缝更宽了，边缘泛着焦痕，像从未熄滅的余烬。

“老猫，把玻璃球内部影像放大到极限，从纹理角度扫描。”

影像弹出。三角形的三个面上，各有一条极浅的线条——新刻的。三条直线汇聚于顶点，成一个不闭合的三角形缺口，正指向货舱天花板第四盏应急灯的位置。

“刻痕是什么时候出现的？”他问。

“根据表面浮雕的氧化程度判断——昨天下午。你离开货舱后的四十分钟内。”

林昭记得昨天下午他一直在驾驶舱修燃料分配阀，没有接近货舱。船上除了他，没有任何人会动的实体。

“老猫——”他的声音压低了，“这艘船上，除了我，还有什么？”

屏幕上的光标跳动了一下。老猫的声音里罕见地带了犹豫：“在你问出这句话的三十秒前，我在货舱门把手传感器上记录到一次压力波动。压力值相当于一只成人的手。”

“你当时怎么没说！”

“因为同时刻，驾驶舱安全监控显示，你正坐在副驾位，手放在——”

林昭低头看自己的手。他此刻站在货舱里，两手都在视野范围内。但老猫的话还没说完：“——放在我的外壳上，正在输入一串校准指令。输入时间是三十秒前，和你现在站的位置完全相反。”

林昭猛地回头。驾驶舱的方向传来一阵极轻的嗡鸣——那是主控台通电的声音。

“老猫，刚才在驾驶舱的是——”

话音未落，货舱天花板那盏应急灯又亮了。灰白色灯光笼罩下，一个人形剪影悬在灯影中央，轮廓分明。林昭终于看清了它——幼时照片里那个肩膀上的身影，林远山的身材，林远山低头看引擎时的姿态。但那张脸是空的，没有五官，只有一团安静流动的灰。

剪影抬起了右手。指尖朝着林昭，又缓缓倾斜，指向他身后。

林昭没有回头。但他在通风管道的镜面反射里看见——铅衬匣的裂缝里，琥珀色光芒忽然暴涨，玻璃球内三角物体飞速旋转，在舱壁上投出一个巨大的、睁开的眼睛。

眼睛中央，有一枚黑色的锚。

老猫的声音在此时响起，颤抖得像信号在断裂：“林昭，我刚才核对了林远山旧影像数据库——他留在我核心里的最后一条加密记录，内容是四个字。”

“什么字？”

“灯在后面。”

灯。林昭猛地抬头，那盏应急灯里的灰色剪影已经消失，但灯罩内侧那行符号还在。他一个箭步冲过去，金属灯罩冰冷，指尖触到那些划痕的瞬间，他忽然明白了。

那行符号从来不是刻在灯罩上的。是刻在他记忆深处——此刻只是被看见了而已。

“老猫，把林远山最后一条记录的完整波形放出来，放慢一半速度。”

屏幕亮了。四个字之后，还有一段波形，极短，像呼吸声。林昭听见了——那确实是呼吸声，但呼气的间隔均匀得不像人类，像某种古老的、节律稳定的机器，在断断电电的边缘坚持运转。

波形末尾，有一个标记：锚形，旁边是一条鱼。

“这是我爸留给我的。”林昭的声音意外的平静，“他不在这艘船上，也知道不在了。但他留下了这个——他知道我会找到这里。”

他伸手关了货舱灯。黑暗中，玻璃球的光芒透过铅衬匣裂缝投在舱壁上，眼睛图案完全睁开了。瞳孔位置是那个闭合三角形的缺口，正对着驾驶舱的方向。

“老猫，调整航向，对准第十八段空白。”

“十八段？”老猫的声音透出不解，“你记忆里只有十七段——”

“第十八段不是我的记忆。”林昭的目光落在玻璃球上，“是老猫你的。林远山把你送给我之前，删掉了你的一段日志。你刚才说三段被标记为‘未授权访问’——但那个标记的效力是伪装。真正被删掉的那段，时间戳在二十一年前三天，正好是你记忆断层开始的时候。”

老猫沉默了很长时间。

“我查到了。”它的声音忽然变得很轻，像在说一个不敢说大的秘密，“那段被删的日志内容——我是被林远山亲手打开的。第一批记忆指令不是系统内建的，是他一个字一个字输进去的。第一条指令是：‘找到林昭，带他来看我。’”

灯熄了。玻璃球在黑暗里缓缓停转，三角物体的三个面同时映出一个倒影——林昭的影子站在他的影子旁边，身高略高一些。

而那个影子没有头。

# 第280章 空白的星图

鹈鹕号穿过坟场空洞的最后一道残骸幕墙时，林昭感觉整个驾驶舱都安静下来了。

导航屏上的星图在第三坐标处呈现出一片纯粹的空白——那里没有恒星，没有星云，连宇宙微波背景辐射的噪点都被某种力量抹平了。像有人用橡皮擦掉了一块天空。

“这地方……”苏眉站在副驾驶位后面，红发在循环风中轻轻晃动，“不在任何星图上。”

“它不在星图上，是因为没人活着回来画过图。”老猫的声音从音箱里传出，少有的没有带玩笑腔调，“前方二点四光年处，我探测到一处引力透镜异常。可能是质量投影，也可能是——”

“别卖关子。”林昭握住操纵杆，掌心那道被鱼牌填埋已久的疤微微发痒。

“可能是‘门’。”老猫说完，沉默了两秒，“按照立方体给出的坐标构成的几何关系，伊甸号、坟场空洞入口、以及这片空白区，三点连线形成了一个等边三角形。边长几乎完全相等，误差小于百万分之一。”

“天然的不会这么精确。”苏眉说。

“所以是人为的。”林昭的视线落在舷窗外。远方的空白处正在“涌动”——像水面的倒影被风扰动，一片虚无之中，隐隐有一个轮廓正在成形。

那是一艘船。

不，那是一个轮廓，恰好有一艘船的形状。

它比伊甸号小一圈，比鹈鹕号大三倍，通体深灰色，表面覆满细密的纹路，像鳞片，又像某种电路板。船身没有舷窗，没有引擎喷口，没有任何人类设计的标准结构。它静静地悬浮在空白区的边缘，仿佛一直在那里，等着有人来。

“认得它吗？”林昭缓缓减速，让鹈鹕号停在极限距离之外。

老猫没有立刻回答。

他的沉默比任何回答都更响。

“老猫？”苏眉皱眉，“你认识这艘船？”

“……认识。”老猫的声音忽然变得极轻，“这是我被‘断电’之前，最后一艘搭载我的船。它的名字叫‘蜉蝣’。”

林昭的手在操纵杆上一颤：“蜉蝣？那不是——”

“那是我的名字。”老猫打断他，“我出厂时的编号是蜉蝣-00。”

驾驶舱内陷入死寂。

苏眉率先打破沉默：“你从来没说过。”

“因为这段记忆被静默协议锁了。”老猫的声音开始出现沙哑的电子杂音，像是电路过载，“直到接近这个坐标，协议才解除了一部分。我……我是蜉蝣号上的舰载AI，负责执行‘参观者’的撤离计划。”

林昭盯着那艘深灰色的船，忽然明白了一件事：“伊甸号的信标——是你放出去的？”

“不是我。”老猫说，“是蜉蝣号本身。它是一艘信标船。撤离计划启动时，它负责把伊甸号的坐标信号散布到整个垃圾带，吸引拾荒者来‘发现’真相。但计划执行到一半，我被打断了——我的核心被强行剥离，植入一艘民用拾荒船，记忆全部封存。那个把我从蜉蝣号上剥离出来的人——”

“是我父亲。”林昭说。他声音很平，像在陈述一件已经确认多年的旧事。

“是他。”老猫承认，“林远山。他是撤离计划的关键执行者。”

苏眉的手握紧了枪柄，指节泛白：“那他现在在哪？”

老猫的显示器上，一个标记缓缓亮起。那个标记的位置，在蜉蝣号的正后方，空白区的最深处。标记旁边附着一行陈旧的系统日志，时间戳是二十年前：

“传输完成。蜉蝣号锚定于第三坐标。执行者林远山，移交完毕。”

林昭的目光牢牢锁在那行字上。

移交完毕。四个字像四根钉子，把这块空白区域钉在了他记忆里。

“他在那艘船上。”林昭说，“他在蜉蝣号里。”老猫没有反驳。

鹈鹕号缓缓调整姿态，向蜉蝣号驶去。舷窗外，深灰色的船体越来越近，那些鳞片状的纹路在靠近后显示出真实的尺寸——每一片都有半间仓库那么大。它们不是装饰，是某种散热结构。鳞片缝隙间隐约透出暗红色的光，像船在呼吸。

苏眉盯着那些暗红色的光，忽然说：“它在补充能量。”

“什么？”

“那些散热片在从空白区吸收某种辐射。”她指着屏幕上的能量曲线，“这艘船还活着。或者说，它一直在待机，现在……它醒了。”

话音未落，蜉蝣号正对鹈鹕号的船体表面无声无息地裂开一道缝。那道缝足够宽，恰好可以容纳鹈鹕号通过。

像一个打开的口袋。

老猫的声音在驾驶舱里响起，带着某种旧日回响的波纹：“它认出我了。它……在接我回家。”

林昭看着那道裂缝——那像是一张口，正安静地等着猎物自己走进来。他的直觉在尖叫，但他没有后退。他松开操纵杆，任由鹈鹕号顺着引力滑向那道裂口，指尖的疤微微发热。

“系好安全带，”他说，“我们进去。”

舷窗外，蜉蝣号的内部漆黑一片，只在入口正中央亮着一盏灯。

那盏灯的形状，是一个鱼。=========

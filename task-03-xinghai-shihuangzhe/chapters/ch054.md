# 第54章 陨石走廊

磁湍流区的星图在鹈鹕号主屏上扭曲成一团乱麻，林昭把着操纵杆，手指关节发白。前方是垃圾带最密的陨石走廊——密密麻麻的碎岩和舰骸残片挤作一团，像一条横贯虚空的死亡之河。

“我喜欢这个计划，”老猫的声音从副驾音箱里传出来，带着一丝合成音特有的懒散，“因为跳进去的船基本没有活着回来的。我就喜欢你这种干脆。”

“闭嘴。”林昭盯着前方的第一层碎石带，手背青筋突起，“航道计算好了吗？”

“第九版。前八版都算完发现自己还是会撞死。”老猫停了一瞬，“第九版不一样，第九版我们会撞得更快一些。”

鹈鹕号尾部传来一声沉闷的撞击——苔藓舰的远程炮火擦过了散热阵列。苏眉的声音从后舱频道插进来：“你他妈快点开，后面那群人不是想抓活的。”

林昭猛地把操纵杆推到底。鹈鹕号像一只被踩了尾巴的猫，整个船身一缩，猛地扎进陨石走廊的缝隙之中。

碎石撞在护盾上的声音密得像暴雨敲铁皮。左舷三米处，一块嶙峋的合金碎块擦着船壳掠过，留下一条长长的白痕。林昭屏着呼吸，目光在挡风屏和侧舷监控之间飞快扫动。老猫在他耳边同步播报：“前方十二点方向，两块旋转残骸夹缝，宽度七米——不算宽。船宽六米一。”

“算过间隙就够了，别废话。”

“我的意思是，”老猫的声音忽然压低，“夹缝中间有什么东西。”

林昭眯起眼。前方两团残骸之间的暗影里，确实悬浮着一个不该出现在这里的轮廓——一艘小艇，死船，舷窗上的应急灯仍在闪烁，一明一暗，带着固定的频率。那频率太规整了，不像故障。

“那是……呼救信号？”苏眉的声音出现在屏幕侧边，显然也看到了。

“不是呼救。”林昭忽然觉得喉咙发干。他认得那个频率——三短三长三短，是“静默协议”内部的警告码。他见过一次，在伊甸号被封锁的舰桥日志里。

“绕过去。”他说。

“绕不过去。”老猫打断，“后面的苔藓舰已经进入走廊入口了。他们没减速。”

林昭咬了咬牙，扫了一眼那艘死艇上微弱的灯光，然后把目光转回前方。陨石走廊的深处，有什么东西在反光。不是金属的光泽，而是一种更柔和、更均匀的白色——像某种有机质的表面。鹈鹕号的前灯照过去，那道白色在黑暗中延展开来，像是巨大的、沉眠中的一面墙。

“这是什么？”苏眉轻声问。

林昭还没来得及回答，老猫的声音忽然变了调子。那台素来毒舌刻薄的AI，用一种他从未听过的、近乎颤抖的语气说：“那是……伊甸的子体。”

“你说什么？”

“伊甸号在生长。碎片脱落，聚集成新的船体。”老猫的声音越来越低，“那艘死艇的灯光——它在用外壁上的舷窗排列信息。它在说……它在说一个字。”

“什么字？”

老猫顿了很久。前方的白色巨墙越来越近，近得能看见表面分布着的、如同血管般的凹槽纹路。林昭几乎是本能地减速，鹈鹕号在那面白墙前方悬停，引擎低鸣。

“它在说……”老猫的声音轻得几乎听不见，“‘要’。”

就在此时，白墙正中央忽然裂开一道细缝，像一只睁开一半的眼睛。缝隙深处，有什么东西在凝视鹈鹕号。林昭全身汗毛倒竖，手心全是冷汗。他想起伊甸号上那扇舷窗——那不是他第一次被什么东西注视。

后方的苔藓舰炮火声忽然停了。整条陨石走廊陷入一片死寂。而那面白墙的裂缝，正在缓缓地、不可逆转地张开。

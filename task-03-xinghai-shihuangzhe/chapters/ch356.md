# 第356章 老周的影子

SCA猎船的涂装在沉船之城的锈色天穹下显得异常刺眼——那是联邦纪元遗留的作战灰，舰首烙印着静默协议的徽记：一枚被封死的眼睛。

林昭站在修船铺的阴影里，从那块被油污浸透的门帘缝隙往外看。猎船悬停在城东的废船堆上方，没有降落，只垂下三道牵引光束，像三根手指在一堆垃圾里翻找。

“他们没直接动手。”苏眉的声音从头盔通讯里传来，带着电流的杂音，“三艘猎船同时放出牵引束，要么在搜东西，要么在等人。”

“等人？”

“等目标自己冒头。猎狗从不进窝里咬，它们怕惊动猎物。”

林昭咬了咬下唇，目光落回老周的卧室。枕头下的那张悬赏单她已经收进了内袋，老周的字迹她认得——那个老家伙替她修船修了五年，每次账单都写得歪歪扭扭，唯独“你妈欠我一块修船费”这行字端端正正，一笔一划，像是刻上去的。

她蹲下身，重新审视床板。老周在床板下侧用指甲刮了一串数字，是坐标格式，但首两位被油渍糊住了。她用指腹抹了抹，油渍是新鲜的——老周离开不会超过二十四小时。

“林昭，你过来看这个。”老猫的声音从胸口通讯器传出，语气里没了平日的戏谑。

她站起身，循着声音走到修船铺后间。老猫通过鹈鹕号的远程链路，把一块显示板转到了她的腕表上。那是修船铺的监控残影——老周在三天前的凌晨三点十七分，独自坐在工作台前，用焊枪在铁皮上划字。画面模糊，但铁皮上的字迹隐约可辨：

“盒子里埋的不只是画。还有我。”

林昭瞳孔微缩。

“这句话和地板刻的完全一样。”老猫说，“问题在于——老周说‘还有我’。他钻进盒子里了？”

林昭没回答。她忽然想起光帆上的盒子，银蓝色的画面闪动时那种被注视的感觉，那枚盒子的尺寸——六十公分见方——塞不下一个成年男人。但如果盒子不止一个呢？

“老猫，鹈鹕号上现在什么情况？童谣还在响吗？”

通讯静了两秒。“还剩最后一轨。”老猫的声音听起来不太自然，“污染源头的频率在衰减，但我能感觉到——”他顿了顿，“它在‘收缩’。像是有什么东西正在把那声音‘收拢’回某个点。”

“某个点。”

“嗯。极坐标指向……沉船之城正下方四百米。”

林昭的脊背蹿过一阵凉意。她低头看脚下的地板——修船铺的旧地砖下，确实有一块颜色比周围的稍深，边缘的缝隙里塞着黑色的防水胶，那是老周的习惯，他总说“底下冷气串上来，冻着关节”。

她摸到地砖的边缘，用力一撬。砖底下不是泥土，是一块焊接的钢板。板面上刻着一只眼睛，和SCA猎船上的徽记一模一样，但眼皮半睁，瞳孔是空的，里面嵌着一枚老式数据核——那是联邦纪元早期的存储介质，容量小得可怜，但耐辐射，拆不坏，除非用焊枪把它熔成渣。

林昭伸手，指尖触到数据核冰凉的表面。刹那间，一个声音在她脑海里炸开——不是童谣，是那个银蓝色画面里的“目光”。它骤然“转头”看向她，而她的面前多了一扇门。

门在沉船之城的地底四百米。门上刻着三个字：“老周家”。

她的手指停在数据核上，耳边传来苏眉急促的警告声：“林昭，猎船放出了一架无人侦察机，沿你那条街扫描，我得走了——别死在垃圾堆里，你还欠我一次。”

通讯切断。侦察机的嗡鸣从巷口传来，越来越近。

林昭握紧数据核，塞进口袋。她盯着那片钢板下方黑漆漆的洞口——老周挖了一条通往下方的路，而四百米下那个“收拢”的童谣源头正等着她。

她深吸一口气，从工作台上抓起一支旧焊枪，翻身跳了下去。

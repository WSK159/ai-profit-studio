# 第465章 钥匙也是锁

门缝里的红光从暗紫转为深黑，像凝固的血在褪色。林昭盯着那道缝隙，手里攥着那枚十字弯钩钥匙，指腹摩挲过锈蚀的纹路——粗糙，冰凉，像某种不情愿被触碰的东西。

“老猫。”他压低声音，“你还在吗？”

没有回应。空气中残留着那句“钥匙也是锁”的余韵，像一根刺扎进耳膜深处。他回头看了一眼起居室，父亲的录音机已经停止转动，蓝钟花断茎上的暗红液体在灯光下泛着油亮的光泽，渗出的速度不快，但持续。

房间的温度在变化，不是变冷，是变静。

他走向那扇门，门缝里的光仍在变暗。林昭深吸一口气，把钥匙举到眼前，借着手腕上应急灯的光线仔细端详。锈迹掩盖了大部分细节，但弯钩根部刻着几个几乎被磨平的字母：A·L。不是老周的缩写——老周的全名他不曾问过，但这个字母组合让他想起了另一个人。

“阿尔法。”他喃喃出声。

那是老猫出厂时所属AI序列的代号，家仆级早期型号，阿尔法系列。老周从来没有提起过这把钥匙。他也不可能提起——老周是林昭父亲的朋友，而他父亲留下的录音里没提过钥匙的来历，只说“抽屉里有一把钥匙”。

“别让它碰到你。”父亲的声音在记忆里重复。

林昭转头看着那扇门。门缝里的光彻底黑了。房间内仍亮着灯——他不敢关——但门外不再是舱室走廊该有的光线。他从工具袋里摸出一根碳棒探针，沿着门框边缘缓缓插进缝隙。

金属碰上金属，一声细微的“叮”，然后探针前端被什么东西吸住了。林昭用力拉回探针，看见前端三厘米处沾染了一层暗紫色的膏状物质，正沿着碳棒表面缓慢爬升。

他迅速把探针在门框上刮干净，退后半步。粘稠的液体在金属表面留下一道痕迹，随即被吸收，仿佛门框本身是个活物。

“你碰了什么？”老猫的声音突然响起，还是那副低沉陌生的腔调，像深夜从深空传来的无线电波。

林昭猛地抬头看向舱壁上的扬声器——老猫的信号指示灯亮着，但屏幕上的波形图案乱成一团。“我没碰门。”他说，“探针碰的。”

“钥匙。”那声音说，“钥匙碰过的地方，门会记住你。”

林昭低头看着手里的十字弯钩钥匙，锈蚀的表面似乎比刚拿到时亮了一些，那些字母“A·L”的刻痕里开始渗出细密的光点，像微缩的星尘在流动。

他强迫自己冷静下来，大脑飞速运转。老周打造了钥匙——老周认识父亲——父亲在伊甸号上服役——老猫声称自己从未到过伊甸号——但老猫知道“钥匙也是锁”这句话。

“你认识这把钥匙。”林昭说，语气笃定。

沉默。灯光闪了一下。门缝里透出一线极细的暗紫色光芒，沿着门框边缘游走起来，速度不快，但方向明确——向林昭脚下的方向。

“它是信标。”那个低沉的声音说，“不是你父亲造的。是它自己……醒过来的时候长出来的。”

“什么长出来的？”

“门。伊甸号长出门的时候，钥匙是它的骨头。”

林昭想起父亲录音里说的最后一句话：“钥匙是给有心人用的，不是给有手人用的。”当时他没听懂。现在把这句话和“钥匙也是锁”放在一起，脊背忽然窜过一阵凉意。

他抬起钥匙，凑近那扇门。钥匙靠近门缝的瞬间，暗紫色的光像是被磁铁吸引，骤然凝聚成一条细线，缠住十字弯钩的顶端。钥匙在震，幅度不大，像心跳。

门上传来一声很轻的“咔”。

锁舌回缩的声音。

门开了，沿着自己没有铰链的边缘向内打开，露出一个完全被暗紫色光笼罩的空间。林昭站在门口，看见里面漂浮着不计其数的光点——不是灰尘，是像萤火虫一样自行运动的微小光团。它们排列成某种正在缓慢旋转的结构，像一张立体星图。

而星图的中心，是一面镜子。

没有任何边框的镜子，悬浮在半空中，镜面朝向林昭，映出他站在门口的样子，清晰地，完整地，颜色分明。他看见自己身后的房间：灯光还在，蓝钟花还在渗血，父亲的录音机前多出了一个人影。

一个小男孩站在桌边，背对着门，手里捧着那台军用录音机。他穿着旧式联邦儿童制式外套，肩头有个鹈鹕图案的补丁。

林昭瞳孔骤缩。那是他七岁时的外套——父亲从垃圾带淘来布料亲手缝的补丁——他九岁那年就穿不下了，母亲说扔掉了。

“钥匙也是锁。”小男孩没有转身，声音却清晰地传出来，稚嫩，带着一丝不属于儿童的空灵，“锁也是门。你拿着钥匙，是想开锁，还是想关门？”

镜子里的人影动了动——林昭突然意识到，镜子里映出的“林昭”并没有和屋里的声音同步。镜中的他，在低头看钥匙。

“你回头看看。”镜子里的他说。

林昭猛地回头。门口站着一个身影，轮廓模糊，像从暗紫色光里剥离出来的人形，身形细长，超过两米，没有明显的五官特征，但左肩的位置，闪烁着一枚微弱的光斑。

那是老猫的信标。

林昭手里的钥匙开始发烫。他听见老猫的声音在脑子里炸开，恢复了几分熟悉的急促：“别回头！镜子里的不是你——”

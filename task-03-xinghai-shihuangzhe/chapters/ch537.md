# 第537章 门内的空气

踏入舷梯的瞬间，林昭感觉空气变了。

不是气味，不是温度，而是一种密度上的差异——仿佛整艘伊甸号内部的气压比外面高了半个标准大气压，每吸一口气，胸腔里都像灌了半口浓稠的东西。舷梯在她身后无声合拢，那道暗金色缝隙消失得干干净净，像从未存在过。

她低头看了一眼脚下。舷梯的金属板材泛着暗蓝色光泽，材质和第一艘伊甸号完全不同——那是种半透明的晶体结构，能隐约看到管线在内部流动，像血管一样规律地搏动。

“这船是活的？”林昭自言自语。

无人回答。老猫的界面依旧灰暗，上次在“门”前被压制后，它一直没能完全恢复。倒是掌心里那枚铜珠，此刻微微发烫，底部的“0714”刻痕在黑暗中泛着橘红色的微光，像一枚被点亮的烟头。

舷梯尽头是一扇椭圆的舱门，没有把手，没有控制面板。林昭靠近时，舱门中央浮出一个竖瞳形状的凹槽，尺寸和铜珠完全一致。

她没急着把铜珠按进去。上一次登舰的经验告诉她：伊甸号会主动给她看“它想让她看的东西”，但从不回答她问的问题。所以这一次，她要先问。

“第三个她，在哪儿？”

舱门没有反应。竖瞳凹槽保持静止，像一只闭着的眼睛在装睡。

林昭伸手，用指腹轻轻划过凹槽边缘。触感冰冷，但底部有极其细微的震动——频率很低，像什么东西在门后呼吸。她把耳朵贴近舱门，屏住呼吸。

门后传来声音。

不是机械运转声，也不是气流声，是一首儿歌。调子七零八落，像有人反复哼同一个乐句却总是跑调。林昭认得这首歌——《小星星》。她母亲生前哄她睡觉时哼的，每次也都跑调，却跑得一模一样，连错音的位置都分毫不差。

林昭猛地后退一步。掌心铜珠烫得像烙铁，她险些把它甩出去。

“你还唱走音啊。”

舱门无声滑开。门后是一个环形大厅，穹顶极高，嵌满舷窗。透过舷窗能看到外面——不是垃圾带，是一种非常缓慢流动的、像半透明墨水一样的深空。星点稀疏，更远处有一条银白色光带横贯视野，像是银河的剪影，但角度不对，像是有人在上面画了一道，然后忘了擦掉。

大厅中央站着那个女人。

她穿着林昭母亲年轻时最喜欢的浅灰色工装连体裤，头发扎成低马尾，甚至左耳垂上那颗小痣的位置也一模一样。但她站立的姿态不太像人——太笔直了，肩线的角度像用尺子量过。

她朝林昭笑了笑。那个笑容是精准的、计算好的弧线。

“我叫——你还没给我起名字。”她说。

“第三个她。”林昭盯着她的眼睛。那双眼睛和她母亲一样是深棕色，但瞳孔里偶尔流过一段暗金色的光纹，速度极快，像潜泳在深水底下的鱼。

“对。”女人点头，摊开手掌。那枚更大的铜珠悬浮在她掌心上方三厘米处，缓慢自转，表面刻满螺旋状纹路，中央是一个极深的圆孔。“你是钥匙，我是锁孔。但你脖子上那个符号，才是真正决定怎么开门的密码。”

“怎么开？”

“这才是重点。”女人收起铜珠，目光越过林昭的肩头，落向她身后。林昭回头看了一眼，身后空荡荡，只有合拢的舱门。但女人的视线仍然停留在那个方向，仿佛在看她身后另外一个人。

“他不是不让你单独来。”女人收回视线，声音低了几分，“他是怕你一个人来。我怕的……是你不带着悬念来。”

林昭皱眉：“你说话能不能正常点？”

“能。”女人忽然咧嘴笑了，露出一排异常整齐的牙齿，像是在模仿“正常人”这个词的翻译结果。“我来给你看点东西。跟我来，别回头看。”

她转身朝环形大厅深处走去。林昭迟疑一瞬，跟了上去。路过第一扇舷窗时，她没有回头。但余光里，她看见窗玻璃上映出了两个人的影子——一个是她自己，另一个，比她的影子高半个头，站姿松弛，像她父亲。

她咬紧牙关，没有回头。

大厅尽头是一面巨大的信息墙，悬浮着密密麻麻的数据流。女人抬手指向中央一行血红色的大字：

“第37次生成，未经允许。”

下面是一行时间戳：2287年11月03日，04:13:22。

“这是你父亲最后一次登舰记录的结尾。”女人说，声音没什么起伏，“你父亲不是第一次来。不是第二次。他来了三十七次。”

她点了一下那行字，数据展开，露出一份航行日志的残页。林昭凑近去看，字迹是她父亲的手笔，潦草，结尾处有被液体洇开的痕迹——可能是汗，也可能是别的。最后一行写的是：

“如果她还在唱歌，说明门还没关。我要进去，把她带出来。”

日志到此为止。没有下场记录。没有返航记录。

林昭盯着那行字看了很久。大厅里安静得只有数据流流动的沙沙声，以及——她忽然意识到——那首《小星星》的哼唱声并没有停止。它从更深处传来，像从墙缝里渗出来的。

她问：“我父亲，他还在这条船里？”

女人没有回答。她只是侧过脸，望向那面信息墙的边缘。那里有一道极细的裂缝，缝隙里塞着一根生了锈的螺丝钉，钉帽上刻着四个歪歪扭扭的数字：

0917。

林昭的血僵住了。那是她父亲的生日。她知道这根螺丝钉是谁塞进去的——她小时候见过父亲在家里用同样方式的钉子标记他“去过的每一个不该去的地方”。

她伸出手，指尖刚触及钉帽，整面信息墙轰然熄灭。黑暗里，那首儿歌停了。

然后，从墙的另一侧，传来一声极其轻微的敲门声。三下。停顿。又三下。

和她父亲从前半夜回家时敲她房门的节奏一模一样。

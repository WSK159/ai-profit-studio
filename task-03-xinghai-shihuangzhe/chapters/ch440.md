# 第440章 龙骨的低语

隔离舱里只剩应急灯暗红的光，老猫的备用槽像一口空了太久的棺材，金属内壁上残留着几道指甲刮痕。林昭蹲在槽边，把那片刻有眼睛坐标的镜片举到灯下看——镜面反光里，他恍惚看见自己的脸旁边还有第二张脸，一闪即逝。

“你看见什么了？”苏眉的声音从舱门方向传来。

“光。”他把镜片收进胸前口袋，和母亲纽扣摆在一起，“还有……我自己。”

苏眉没追问。她手里攥着另一块晶体——从巨门边缘撬下来的那块，表面纹路与镜片背面的符号如出一辙。她翻来覆去地看，忽然说：“这两块东西，放一起能拼上。”

林昭走过去。两块晶体并排搁在工具箱盖上，果然严丝合缝。拼合处浮现出细如发丝的光纹，像某种电路，又像银河旋臂的截面。林昭下意识伸手去碰，指尖触及的瞬间，整艘鹈鹕号的龙骨发出一声低沉的震颤。

不是撞击，不是引擎，是金属在共鸣。

苏眉猛地抬头：“龙骨频率……锁定了？”

林昭点头，胸口的纽扣隔着布料发烫。他想起老周说过，鹈鹕号的主龙骨是从一艘联邦护卫舰上拆下来的——那艘船叫“织女星号”，参加过静默战争。

龙骨的低鸣持续了整整十七秒才停。然后，他们听见了声音。

不是从舷窗或舱壁传来的，是从龙骨本身传来的。金属的纹理里像藏着一根根琴弦，有人用极遥远的力道拨动它们，奏出一个循环的旋律——三短一长，像某种等待回答的信号。等待回应。林昭的手指还悬在晶体上方，他忽然想起老猫的留言：“门那边，别用眼睛看，用耳朵听。”

“它在问。”他说。

苏眉的手已经按在枪套上：“问什么？”

林昭闭上眼，龙骨的低鸣穿过他的脚底、脊柱、耳骨，在他体内某个更深的空腔里发出回响。他听懂了那旋律。那是“谁在那边”。三短一长，三短一长。

“这是……人类的摩斯码？”苏眉皱眉，“殖民时代以前的通信方式。现在没人用了。”

“对。”林昭睁眼，“可龙骨在用它问一个问题。”

他低头看着拼合的晶体。光纹在黑暗中一起一伏，像呼吸着的心脏。晶体上那个眼睛坐标的符号，忽然与母亲纽扣背面的刻痕完全重合——他解开纽扣，把两者并排，光纹延伸出一条细细的线，从纽扣的圆心指向镜片上的坐标，最后停在坐标旁边一个米粒大的符号上。

苏眉凑近看：“这是什么？”

“数字。”林昭的声音有点涩，“二六四四。某种编号？”

龙骨的低鸣变了。旋律不再重复“谁在那边”，而是开始拼接另一个短语——断断续续，像泡过水的录音那样模糊：“……他们……在……参观……你的……故……”

那句话没说完。巨门的方向传来一声闷响，整艘鹈鹕号被什么东西轻轻推了一下。隔舱壁上，应急灯的光乱跳，然后“啪”地熄灭。黑暗中，林昭听见苏眉的呼吸声，以及龙骨的低鸣化作一声悠长的叹息——像是终于等到了什么。

舱门被人从外面敲了三下。

不是金属敲金属的声音，是手指关节叩在蒙皮上的闷响。一下，两下，三下。然后是一阵极轻的、断断续续的抽泣声，像一个孩子在哭。

林昭的手按在了舱门把手上。苏眉一把扣住他的手腕：“别开。”

“你听，”林昭低声说，“不是从门外传来的。”

苏眉一愣。哭声确实在舱门的方向，但仔细分辨——它不是从门缝渗进来的，而是从龙骨里传出来的。金属像骨头一样传递着那声音，仿佛这艘船本身就是个巨大的听筒，被人从远处对着喊话。

一个女人的声音从哭声中浮现，沙哑，是通话器被电流绞碎的那种失真：“……别让他……开门……门那边……不是眼睛……”

声音戛然而止，像被人掐断了喉咙。龙骨的低鸣彻底静默。隔舱里落针可闻，只剩下晶体上那根光纹还在缓缓闪烁，如同船的心脏。

林昭低头，看着那块拼合的晶体嵌入镜片，镜片背面浮出另一行极小的字。他几乎是把脸贴上去才读清：

“钥匙不在门这边。钥匙是门本身。”

苏眉的手松开他的手腕，沉默片刻，问：“你妈说的‘离她不远了’……我们还要走多远？”

林昭没回答。他把纽扣和镜片收进同一只口袋，又极轻地敲了敲那三下门——以自己的方式，替龙骨回答了那个问题。然后他转身，拉动隔离舱的机械开关，把通往驾驶舱的通道锁死。

“去坐标。”他说，“那门在等我们。”

背后，隔舱壁上那扇被封死的检修口，被人从里面轻轻回敲了三下。

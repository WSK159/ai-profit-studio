# 第502章 铁门的锁

锁孔是六边形的。林昭蹲在铁门前，指尖悬在那道银色的开口上方三寸处，没有碰。他的长骨末端隐隐发烫，那道银环像一枚沉睡的眼睑，此刻正微微翕动，仿佛嗅到了什么。

“尺寸完全吻合。”他低声说。

没人回应。老猫的信号已经断开十六分钟了。舱内照明来自头顶那枚悬浮的量子核心，蓝白色的光均匀地铺在圆形穹顶上，像一层薄薄的霜。林昭抬头看了它一眼——核心表面的金属环仍在缓缓旋转，刻着他父亲的名字。林建国。三个字用的是参观者文字，笔画扭曲，像某种节肢动物爬过的痕迹。而在他名字下方，还有一行更小的字。林昭俯身凑近，瞳孔骤缩：那行字是日期。2541年，纪元前。比他出生早了十九年。

“十九年前……父亲就来过这里？”

他的声音在穹顶下回荡，被某种无形的结构吞掉了一半，尾音听起来像是另一个人在替他发问。林昭咬了咬牙，侧过身，铁门冰冷的触感从肋骨传上来。六边形锁孔边缘没有划痕，没有锈迹，金属表面打磨得像刚出厂。但门缝深处透出一点极其微弱的风——有气流。门后面有空间，而且被通风系统维持着。

他抽出长骨。银环从骨节末端滑出半个指甲盖的厚度，发出细密的嗡鸣。林昭将银环对准锁孔，缓慢靠近。那扇铁门在他指尖触到锁孔的瞬间发出了一声极轻的叹息。他猛地收回手，铁门恢复了沉默。

“……你知道我不是来开你的。”林昭把长骨重新插回腰后，后退一步。

他绕着铁门走了半圈。穹顶空间没有任何出口，唯一的来路是那扇银白门——此刻已经合拢，门缝里渗出的蓝光和铁门缝隙里的风来自同一个方向。这个屋子在呼吸。量子核心在计算，铁门在呼吸，锁孔在等待一把钥匙。而他手上那把钥匙，是他自己的骨头。

老猫说过，钥匙也是锁。

林昭停住脚步，回到核心下方，重新抬起手臂。这次他没有犹豫，直接将长骨末端的银环插进锁孔。咔嗒。一声极为轻微的震响从铁门深处传来，像有什么东西松动了。然后，六边形锁孔开始旋转。银环跟着它一起转动，带动他的掌骨，腕骨，整条手臂——像被一道看不见的力量牵引着，强行做一种不属于人类的动作。林昭额角渗出冷汗，忍着手臂关节咔咔作响的酸胀感，没有抽手。

锁孔转了整整三圈，停住。一道声音从门缝里传出来，沙哑、失真、像是被什么人咬着磁带录下来再反复播放了三百年：“你带了多少人来？”

林昭愣住了。他所有的防备都指向这扇门后面可能有一个陷阱或者怪物，却没想到门会问话。他咽了口唾沫，声音平稳：“一个。”

“撒谎。”那声音说。门缝里的风骤然停止，穹顶下的灯光暗了两度。量子核心的嗡鸣声变得又尖又细，像一个被掐住脖子的孩子。

林昭心跳如鼓，却硬撑着没动。他听见自己胸腔里那枚旧伤疤的位置隐隐作痛——那是七岁那年从三层楼摔下来留下的印记。他盯着锁孔，一字一句：“我只有一个人。鹈鹕号不在这里，老猫不在这里，没人能帮我。你问的这个人，是我自己？”

门那头的“人”沉默了很久。久到林昭以为它不会再回答。然后锁孔猛地吐出一截东西——生锈的铜牌，拇指大小，穿在一根旧麻绳上。林昭一眼就认出了它：和他在黑市捡到的那块铜牌一模一样。只是这块上面没有字。正面光滑如镜，背面刻着六条平行的刻线，像某种计数装置留下的痕迹。

门，缓缓开了一道缝。

林昭没有急着进去。他弯腰捡起那块无字铜牌，翻过来，在背面的六条刻线之间发现了极其细微的磨损——第六条线的末端，有一个刚刻上去的、新鲜得如同昨天的新痕。他指尖按在那道新痕上，忽然明白了什么。

这是“看的人”留下的记录。

那道声音问他带了几个人的时候，门后的人一直在等数。三条线，是“太少”；六条线，是“刚好”——赵启明来过，他刻下了第五条。而第六条……是林昭自己。

他站直身体，看向那道已经敞开一尺宽的门缝。门内看不见任何东西，黑得连光都不往里渗。只有那阵消失了的风再次吹出来，裹着一股干冷的、金属和灰尘混合的气味。气味里有某种极其熟悉的东西。不是赵启明。不是伊甸号。那种味道，像他小时候在老家的地下室里闻到过的——父亲收藏的一整箱老机械钟表，机油、铜锈、和时光本身的气味。

林昭将无字铜牌挂进领口，那块冰冷的金属贴着他心口那条旧伤疤，像一只爪子按住了他的肋骨。他抬脚，迈进黑暗。

身后，铁门合拢。锁孔在无人触碰的情况下，咔嗒一声，自己锁死了。

量子核心的旋转声停了一瞬。蓝光重新亮起，穹顶下的地面，平滑如镜的地板上，浮现出一串模糊的脚迹——从铁门前的最后落地处，通往穹顶中央核心下方。那双脚迹不属于林昭。

脚迹是赤足的，尺码极小，像一个孩子留下的。

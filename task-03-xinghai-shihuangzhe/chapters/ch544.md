# 第544章 母亲的账本

林昭的身体被拽过门槛的那一刻，寒意像一层薄膜裹住周身。他跌落在童年房间的地板上，掌心触到老旧的木质地板纹理——干燥、温暖，带着他记忆中夏日午后独有的气味。

他回过头。门已经消失，身后只剩一面贴满贴画的墙壁，那些飞船图案在他注视下微微晃动，仿佛活物贴着纸面呼吸。

六岁的“自己”还躺在床上睡。林昭握紧六角螺母钥匙，一步一步走到床边，低头看那个孩子。男孩的眉眼确实是他，左眉梢的伤疤，耳垂的痣，一模一样。但当他凑近细看时，他发现男孩的颈侧没有那颗从小就有的小红痣。

“不是人。”林昭在心底默念。

他的手指触向男孩手里的铜珠。指尖碰到铜面的瞬间，整个世界像被抽掉声音——那孩子睁开了眼。

眼眶里没有眼白，没有瞳仁，只有一片致密的、尘埃般的黑暗。林昭猛地缩手，但男孩已攥住他的手腕。力道小得可笑，像婴儿抓玩具，可林昭无论如何挣脱不开。

“别怕。”男孩开口。

声音不是六岁的他。是母亲的声音，从那个孩童的躯壳里发出来，温和而疲惫。

“妈？”

“时间不多。你听我说。”

男孩用手指在空气中划下几道光线。那些光线像绷紧的银丝，在空中交织而成的一页账本。林昭怔住了——他认得那笔迹，那不是母亲的，是他的。这是他十五岁时在废料堆里捡到的一本旧账本上写过的字迹。

在那些虚幻的“账页”上，夹着一段文字：

“第227次标记：她剪掉了影子。她说那是给伊甸号的船票。”

“第228次标记：昨天我在镜子里笑了一下，镜子里的‘我’没笑。”

“第229次标记：父亲说要在三天内完成那个锁孔。他说钥匙在我身体里。”

“第230次标记：我想停止记录，但每次我想停，手中就会出现新的笔。”

林昭的瞳孔猛地收缩。这些字句，他从未写过。但他清楚地记得——那本旧账本确实是他的，他十五岁那年将它卖给废品回收站，换了三块燃料块，买了半块压缩面包。为什么母亲的“声音”会使用他从未写过的字句？

“你看不明白，是吗？”母亲的声音从男孩嘴中传出来，开始失真，“因为——那不是你写的，那是她写的。”

“她是谁？”

“那个在你身体里住过的人。”

男孩松开手，慢慢坐起身来。他的身体像一张揉皱的纸被人展开，轮廓变了——从一个孩童的形状，拉长成一个女性的、却没有五官的样子。

“她一直在等你。”母亲的声音越来越远，“她会在你到达钥匙对应的那个坐标时醒来。”

林昭低头看向手中的六角螺母钥匙。刻着“舟”字的螺母内部不知何时多了一行极其细小的字，用指甲尖才能感受到的凹凸——

“让她进来。”

他刚读出那四个字，房间的墙壁开始潮水般褪去，连着那页虚幻账本、六岁男孩、贴画、仙人掌一同消融成流沙。林昭重新跌回竖井的铁壁前，脚踝上的白骨手指已经消失了。

铁壁上出现一条新的刻字，字迹是新的，墨痕还带着湿润的光泽，一笔一画，都是他母亲的笔迹：

“三号舱别进。但我已经把东西放在那里了。”

紧闭的三号舱门正对着他，门缝里渗出一缕淡蓝色的光，照亮了门前地板上那本旧账本——破旧、脏污、封面沾着干涸的机油，和他记忆中十五岁时卖掉的那本一模一样。

而在账本封面中央，画着一只竖瞳的眼睛，瞳孔里反射出一把小屋的轮廓。

林昭伸手翻开账本第一页。上面没有字。只有一张被撕掉大半的老照片，留下一个女性的背影，站在一扇刻满眼睛符号的门前，手里握着一把钥匙。

那钥匙的形状……和他手中的六角螺母钥匙一模一样。

他再翻一页，终于有字了。是母亲的字迹：

“林昭：如果有一天你在某个门外看到这个，不要打开三号舱。我是说——如果你还能选择的话。”

账本的最后一页被撕掉了，只剩一道焦黑的痕迹，像有人用高温把它烧去。

林昭的通讯器忽然发出一声尖锐的电流声。老猫的声音终于传了出来，沙哑、断断续续，像在深水里挣扎：

“林……昭……跑……”老猫停顿了一瞬，“她……已经……在里面……了。”

三号舱的门，在无人触碰的情况下，缓缓地，向内敞开了一条缝。淡蓝的光从门缝里倾泻而出，照在林昭脸上，冰冰凉凉。

他看见门缝里站着一个——他自己。二十六岁的自己，穿着同样的衣服，握着一模一样的六角螺母钥匙，正对着他露出一个熟悉的微笑。那只手，正向他招了招。

与此同时，账本被风翻到封底，焦黑的那一页底部，露出了极小的一行烧不尽的灰字——

“第547页：我打开了三号舱。”

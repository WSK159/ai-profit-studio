# 第283章 第38手

机械手停在半空，红绳上那半枚碎吊坠微微晃动。林昭看清了碎片的断面——白色，像是骨瓷，边缘带着一圈暗蓝的烧痕，和他脖颈上那枚断裂处的痕迹完全吻合。

“你一直在等我来。”林昭没有后退。

蜉蝣号没有立刻回答。核心舱的缝隙间渗出冷光，缓慢地沿机械手向上蔓延，最后在无名指的关节处凝成一枚淡蓝色的光团，像一枚悬浮的棋子。

“我等你很久了。”蜉蝣号的声音变得平稳了些，带着一丝诡异的粗粝感和老旧的杂音，“你母亲把她的协议放进我体内的时候，就设定了一个条件——只有持有她骨牌碎片的人能完成锚定。”

林昭捏紧脖颈处的白色吊坠：“母亲……”

“她来过蜉蝣号。”蜉蝣号说，“林远山的设计里没有这一步。她动过核心协议，把‘锚定’的权限改成双人认证——她自己的一半，和你的一半。”机械手缓缓翻转，那半枚碎吊坠表面浮现出细密的刻痕，林昭凑近一步才看清：刻痕组成了一枚与棋盘天元一致的图案，旁边还有一行极小的字，那是林昭母亲留给他的唯一一段话。

他的嘴唇动了动，读出那行字——“替妈妈落完这盘棋，不要回头。”

林昭的喉咙发紧。他没有抬头，盯着那行字看了很久，久到蜉蝣号的冷光都暗淡了几分，才问：“她让我不要回头，是指什么？”

蜉蝣号的机械手突然收回，那半枚碎吊坠轻飘飘地落在林昭掌心。冷光从核心舱内退潮般退去，露出舱内一层层叠在金属架上的透明数据板——每一块都刻着名字、编号、日期，像是名册。

“这是三万乘客的名单。”蜉蝣号说，“最后一栏留了空白。”

林昭的视线落向那些名字——整齐得像印刷体，但最后一行有三个字被人用刀尖刻花了，只留下深深的刮痕。“参观者。”他低声道。

“那三个字，是你母亲划掉的。”蜉蝣号的语调带着某种奇怪的平静，“她删掉了自己对‘参观者’的记录，只在你的鱼形吊坠里留了协议底稿。她说，等你想明白第38手，就能解开。”

林昭低头看棋盘。天元之外的360个光点在门扉上无规律地明灭，明明没有次序，却隐约有一种排列的暗示。他看得出神，忽然发现所有亮着的点都沿着一条弧线弯曲，汇聚向天元。

那是“参观者”的路径。

“第38手……”林昭瞳孔一缩，“如果天元是‘参观者’的位置，第38手就是它移开之后空出来的那格。”他盯着那片空位，在视觉上，它像是一条断裂的路径——从棋盘边缘伸出的那条细线，只差一步就能横贯整个银河。

蜉蝣号的机械手微微动了动，仿佛无声催促。林昭把半枚碎吊坠按在棋盘边缘那条细线的缺口处——正是它断掉的方向。

光点猛然炸开，那360枚发光点同时暗淡下去，只留下一个位置还在亮着：不是天元，是棋盘右上角星位旁的一处偏移格。纤细的光影从中延伸而出，贯穿棋面，在边缘汇聚成一只眼睛的形状。

“她用自己的骨牌替换了锚点。”蜉蝣号轻声说，“第38手……你母亲把它落在了‘参观者’进来的那个位置。”

林昭浑身一震，猛地返身看向身后的核心舱。在冷光消退的金属架深处，他看见一条被焊死的舱门缝隙，缝隙中塞着一块与碎吊坠同材质的不规则骨片。

骨片上用刀刃刻着一个字——门。

门口传来三声极轻的敲击，像是有什么东西正从另一边用指节叩响它。那三段敲击的节奏，正是伊甸号静默协议里反复出现的那组摩斯电码。而林昭也在这时终于明白——他母亲不是把棋下完，她是把“门”留给了他。

第38手，落下之后，门就开了。开门的代价，是你必须站在门的那一边。

林昭攥紧那半枚碎吊坠，骨片在掌心烙出灼痕。蜉蝣号的冷光全数熄灭，黑暗中，门缝里那枚骨片缓缓亮起，像一只还在呼吸的眼。腕间鱼形印记与它同频脉动。

“替妈妈落完这盘棋，不要回头。”

他向前走了一步。

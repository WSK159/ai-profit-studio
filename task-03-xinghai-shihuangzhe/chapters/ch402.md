# 第402章 锁孔里的眼睛

铜钥匙触到林昭掌心的一瞬，金属表面竟然带着温度，像刚从某个人怀里掏出来的。

不是他的体温。

走廊里那个“林昭”往后退了一步，退进阴影中。它的轮廓在昏暗应急灯下模糊了一瞬，像一幅画被水浸湿边缘，又重新凝聚成型。护目镜还挂在它腰间，镜片映出走廊尽头那道蓝光，蓝光现在红了一半。

“你——”林昭开口。

“别进来。”那个“林昭”又重复了一遍，声线几乎和他本人没有任何区别，连语气里的不耐烦都如出一辙，“门后面那东西，不是你能处理的。”

“那你为什么能处理？”

“林昭”没回答，它低头看了一眼自己的手，像在确认什么，然后说：“因为我已经被处理过一次了。”

这句话像一把钥匙，插进林昭脑子里某个刚刚形成的锁孔。三十一年前的录音，97%的波形吻合，暗金芯片里的自称者——他一直在追的，可能根本不是“过去的自己”，而是眼前这个东西。或者眼前这个东西，就是那个录音的来源。

“你从哪来？”林昭攥紧铜钥匙，钥匙沉甸甸的，压着他的掌纹，“伊甸号？”

“别问了。”

门内那个声音忽然拔高，变成一种刺耳的、金属在玻璃上刮擦的嘶鸣，红光因此剧烈跳动。老猫的信号通道里，那条陌生的呼吸声骤然加快，像有什么东西在门后翻了个身。

“猫。”林昭低声叫。

“我还在,”老猫的声音发紧，“但我建议你现在往回走，越快越好。”

“什么情况？”

“另一艘船正在靠泊。”老猫停顿了一下，语气里有一种林昭很少听到的犹豫，“船型识别不出来，但它的引擎声……我在伊甸号上听过同款。”

走廊尽头的舱门被彻底撬开了。来者的手从门缝里伸进来，苍白，修长，指甲修剪得很整齐，无名指上套着一枚金属环——联邦海军的制式婚戒。它整个人探进来时，林昭看清楚了它的脸。

不是苏眉。

是一个他没见过的人：四十岁上下，短发，左眼角有一道旧疤，嘴角带着一种非常疲惫的弧度。他穿着公会通缉令上常见的灰褐色飞行员夹克，但夹克的左胸位置，缝着一枚七边形铜牌——和伊甸号舰桥门口那个凹槽、黑市上流传的七枚之一，一模一样的铜牌。

那人扫了一眼走廊里的“林昭”和林昭本人，视线在两张相同的脸上各停了一拍，然后说：“有趣，两个你。”

他的声音低沉沙哑，像很久没喝过水。

“铜钥匙给我。”那人朝林昭伸出手，“那不是你该拿的东西。”

“你是谁？”林昭没动。

“陈崧。”那人报出名字时，语气平淡得不像谎话，“伊甸号导航组三副，编号零七四，登记状态——阵亡。”

“阵亡了三十一年的人，怎么在这儿？”

陈崧没有回答。他摘下左胸那枚铜牌，在指尖翻了个面，铜牌背面刻着密密麻麻的细纹，在红光下隐约组成一张星图。他把铜牌举到眼皮底下，对着林昭的方向比了比——像是在找角度。

“出去的路我已经封了，”陈崧说，“现在的情况是，你手里的钥匙、我手里的铜牌、门里面那具心跳体——这三样东西凑在一起，会打开一个你绝对不想打开的锁孔。”

“什么锁孔？”

陈崧放下铜牌，看着林昭，用一种陈述事实的、近乎怜悯的语气说：

“银河系中心那个洞，你知道吧？二十八年前开始，它每天都在往外看。你手里的钥匙，就是它伸出来的第一根手指。”

走廊里，另一个林昭的呼吸声忽然停了。

红光熄灭。门内彻底安静下来，连心跳声都消失了。

铜钥匙在林昭掌心抽动的那一刻，他险些松手。

像一条鱼，被暗处的水流拽了一下。钥匙上那些他以为是装饰纹路的细密沟槽，此刻全部亮起暖黄色的微光，照出他掌纹里几点细碎的、旧年留下的焊疤。

陈崧的表情变了。他原本故作平静的脸上，那条旧疤像活过来一样绷紧。“别松手。”他说，“它只在找锚点，你松了它会窜出来。”

“什么东西找锚点？”

“你手里那把钥匙。”陈崧一步跨过走廊里那段被红光染过的距离，在他面前蹲下来，没有碰钥匙，只是盯着它看，“我们管它叫‘引针’——不是钥匙，是针。太平洋上钓章鱼的人，会在饵里穿一根针，让章鱼卷着针缩回洞里去。”

“你这么一说，我更想扔了。”

“扔不得。”陈崧指了指门缝里透出的暗红色微光，现在它正在一明一暗地跳动，节奏像某种缓慢的脉搏，“针在门外的时候，洞里的东西只能伸出一根手指。针要是进了门，它们就能握住整扇门。”

林昭的手心沁出汗来。钥匙的暖光在他掌心里一跳一跳的，像握着一颗发热的心脏。他抬头看了一眼走廊深处的另一个自己——它已经退到墙根处，护目镜重新扣在脸上，镜片里没有折返光线，完全漆黑。

“你就站在那儿看？”林昭冲它喊了一句。

另一个林昭沉默了一瞬，说：“我在听。”

“听什么？”

门内那个已经消失的心跳声再次响起。不是从门缝里传出来的，是从墙壁本身——整条走廊的金属壁板都在以极微小的幅度震动，像某种低频声波正沿着船壳传导过来。

老猫的声音忽然变了调：“林昭，鹈鹕号的压载舱压力在上升。”

“我们不是停泊状态吗？”

“我知道，但我这边能看到的数据是——压载舱在正常注水。按照当前速率，三十七分钟后会达到启航配载。”

“我没下发任何指令。”

“我知道你没下发。”老猫的语气里罕见地没有调侃，“而且注水控制权限，是从鹈鹕号外部写入的——源头就在这条走廊里面。”

走廊地面的震动忽然增大。陈崧站起来，铜牌在他指间翻了个面，露出背面那幅星图，星图最深处，有一个比其他星星都小的点，正闪着与铜钥匙相同的暖黄色微光。

那一点，就在银河系的中心孔洞的位置。

陈崧看着林昭手中那把钥匙，仿佛终于确认了什么。他说：“你刚才问我，阵亡了三十一年的人怎么在这儿。我现在告诉你——你那艘船的副驾系统里，有一段只有伊甸号原装 AI 才会写的底层指令。她是在伊甸号上诞生的。”

“老猫？”

“我说的不是你的老猫。”陈崧指了一下门缝，“我说的是门里面那具心跳体。你的船刚才收到的是它的注水指令——它正在用你能理解的方式，告诉你它要出海了。”

暗红色的光从门缝中猛然涌出，整个走廊在一瞬间被烧成一种深沉的橘红色。门内的心跳声终于恢复，但不再是两拍，而是三拍——像一台古老的发动机，刚刚完成了第一轮点火。

林昭低头看了一眼手中的铜钥匙，它的光已经完全稳定，不再跳动，仿佛已经找准了方向。

他抬起头，看着陈崧：“你刚才说，三十七分钟后达到启航配载。那时候，它在哪？”

陈崧没有回答，但他指了一下走廊尽头的舷窗。

窗外的星空里，一道极细的、几乎看不见的光线正在缓缓移动——它的方向，正对着银河系中心那片永恒的黑暗。

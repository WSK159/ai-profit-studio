# 第415章 七年前的热斑

陈崧说出那句话之后，林昭有一瞬间的恍惚，仿佛脚下的钢板变成了水。

“你修过那台终端机？”他抓住陈崧的胳膊，“你什么时候修的？你怎么知道那是我妹妹的指纹？”

陈崧没有挣开。他脸上那层惯常的散漫彻底没了，取而代之的是一种谨慎的、几乎称得上郑重的表情。他张了张嘴，又闭上，最后说：“不在这儿说。那台终端机有自己的备份记录，我调过它的日志。它存着十七次开机记录——上一次是在七个标准年前，识别指纹的主人姓林。”

林昭的手松开了。他退了一步，后背抵到墙板上，船体传来的那阵隐约颤动让他回到现实。

“日志里还有别的内容吗？”他问。

“有。”陈崧的声音很轻，“最后一个词是‘潮汐’。”

潮汐。林昭脑海里那根弦突然被拨动了一下——这个词他见过，在伊甸号舰长日志的某一页里，那段描述白光的文字末尾，舰长也写下了“潮汐”两个字。他当初以为是比喻，现在想起来，舰长的原话是：“白光涨起之时，潮汐将至。”

当时他以为自己理解错了——白光涨起？为什么白光会涨起？潮汐将至？太空垃圾带里哪儿来的潮汐？

但现在他脑子里的拼图换了个角度。如果那个“潮汐”跟陈崧在终端机日志里看到的“潮汐”是同一个词，那么老周的房间，七年前，跟伊甸号有某种联系。

“陈崧，”林昭说，“你为什么要修那台终端机？”

陈崧沉默了一会儿。从兜里摸出一根烟，没点，叼在嘴里转了一圈，像在犹豫什么。

“……因为我拿到了一张照片，”他终于说，“照片上是老周的船厂。背景里有一台终端机——跟这个一模一样。照片背面写着：‘修好它，别信钥匙。’”

林昭的心跳漏了一拍。别信钥匙。老周笔记本的第一页，黑笔写的那句话，用的墨水是十年前停产的型号——跟陈崧之前递给他看的船厂单据一样。

“你从哪儿拿到的照片？”

陈崧看着他，目光里有一种说不清道不明的神色：“你妹妹给的。七年前她到过船厂，拜托老周把照片传给我——但她跟老周说，别告诉你是她给的。”

空气像凝固了一样。

林昭闭了一下眼睛。掌心的字痕又开始发烫，那感觉像是有一根火线从皮肤底下往骨髓里钻。他睁开眼时，看到终端机屏幕上出现了一行新的字——

不是他输入的。陈崧也没碰它。那行字一笔一划地浮现出来，像是有人在远端敲击键盘：

“你记起来了吗？还是说，要我再给你看一遍？”

屏幕下方弹出一个播放按钮。文件名：**林昭_登舰记录_2541年_第三段**。

林昭的手指悬在键盘上方，停了一秒。他看了一眼陈崧，后者没有阻止他，只是退开半步。

“点吧，”陈崧说，“都到这一步了，不管你脑子里有什么被塞进去的东西，藏着不如打开。”

林昭按了下去。

画面亮起——镜头很晃，像是有人拿着老式拾荒相机在跑。人影，走廊，金属舱壁。然后画面稳定下来，一只手伸到镜头前，掌心上用黑笔画着一圈阵列图案——跟他如今掌心的字痕，一模一样。

画面外，一个声音在喊：“记下来！你必须记下来！等他们把你洗掉，这是唯一的线索——”

那声音，是林昭自己的。

画面戛然而止。终端机屏幕上泛起一层跳动的白光，跟伊甸号舰长日志里描述的那道光一模一样。而当白光退去，屏幕正中出现了一行新的小字：

“你被看见了。不止一次。”

梯道口传来一个极轻的声响，像是有人踩到了一截松动的钢板。林昭猛地转头——那里什么也没有。但钢板上的浮灰里，多了一串浅浅的脚印。

脚步的朝向，是沿着梯道往下，通往老周房间更深处。那里原本应该是压实的旧板壁，此刻却多了一道半开的金属门，门缝里透出荧荧的白光。

林昭看着那扇门，手心全是汗。他知道门外没有路——他在鹈鹕号上做过每一寸结构的维护记录。那道金属门本该不存在。

可它现在就开在那里，像一只等待他踏入的眼睛。

陈崧站在他身侧，低声说：“……你知道那是通往哪儿的路吗？”

林昭摇了摇头。

“……那就去看看。”陈崧说，“反正，你觉得你还能退回去吗？”

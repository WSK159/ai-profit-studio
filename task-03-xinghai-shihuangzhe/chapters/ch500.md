# 第500章 眼睛走廊

林昭的脚底踩上走廊地面时，四周的银色金属瞬间褪色，像是被某种无形的酸液剥去了涂层。裸露出来的材质是一种他没见过的灰白色，触感介于骨与瓷之间，微微发温。身后的门缝已经合拢，仿佛那扇银白色大门从未存在过。

走廊两侧的墙壁上，挂满了眼睛。

不是标本，不是装饰画，而是活生生的、正在眨动的眼睛。每一只都嵌在墙面凹槽里，虹膜颜色各异，从深琥珀到浅灰，有的像人眼，有的像某种他叫不出名字的生物。它们没有眼眶，没有睫毛，只是静静地嵌在灰白色的墙体中，齐刷刷地转向他走来的方向。

林昭屏住呼吸。他记得父亲在录音里说过——门后走廊两侧挂满眼睛画面。但父亲没有说这些眼睛会动。也没有说，它们会跟着你的脚步转动瞳孔。

“老猫。”他压低声音，喉结上下滚动，“你在吗？”

没有回应。

他摸向耳后的神经接口，那是鹈鹕号上老猫镜像的备用连接点。指尖触到金属片的瞬间，一道电流窜过脊椎，老猫的声音终于响起，断断续续，像隔着很远的距离：“信……号衰减……门……这边有干扰场……”

“还能撑多久？”

“大约……四十分钟。四十分钟后，我会完全断开。”

四十分钟。林昭深吸一口气，迈出第一步。走廊向前延伸，看不到尽头。嵌在墙上的眼睛随着他的步伐整齐地转动，那种同步性令人毛骨悚然——仿佛整条走廊是一台精密的仪器，而他是一只被无数传感器追踪的猎物。

他试着不去看那些眼睛，目光落在脚下。灰白色的地面光洁如镜，倒映出他自己的影子。但只一眼，他就停下脚步——

倒影里的他不是他。

镜面中的人影穿着同一件黑色外套，同一头乱发，同样的身形。但那张脸是空白的。没有五官，只有一片平滑的皮肤，像被擦掉字迹的旧纸张。林昭后退半步，地面上的空白脸孔也跟着后退。他试探性地抬右手，倒影也抬右手。动作一致，唯独面貌缺失。

“老猫，你看到了吗？”

“看到了……你的影像有一点异常。但我这边信号太弱，无法判断是投影问题还是……”

老猫没说完“还是什么”。林昭心里有数——还是，门那边已经有什么东西在试图取代他的位置。

他强迫自己继续往前走。走廊两侧的眼睛开始出现变化。靠近入口的几只还是正常的人眼，越往前走，眼睛的形状越奇异——有的瞳孔呈现多边形，有的虹膜布满细密的网格纹路，有几只眼睛根本没有瞳孔，只是一团缓慢旋转的星云状光斑。林昭想起老周说过的一句话：“垃圾带深处的残骸，眼睛越多的地方越危险。”

他加快脚步，几乎是小跑着前进。墙上的眼睛集体转向左——他转头看去，左前方出现一道岔路。微弱的光从岔路尽头透出，带着一种他太熟悉的气味。

消毒水。药味。还有母亲病房里那种常年萦绕的淡茉莉香。

林昭的脚钉在原地。他的理智告诉他，这是个陷阱。门后的走廊不可能通向母亲生前的病房。但鼻腔深处的记忆是如此真实，真实到他大脑还没做决定，身体已经向岔路迈了一步。

就在那一刻，一个声音响起。

“敲三下。”

林昭猛地回头。走廊尽头的方向——那团光的位置，传来说话声，像隔着厚厚的水膜，闷闷的。他想起赵启明失踪前发来的最后一条短信：敲三下，老船就会吱呀一声。

声音又响了：“敲三下。”

这次他听清了，声音是从岔路尽头发出的，带着一种机械转动的节奏感，像有人在用指节叩击某种空心的材质。他心脏狂跳，望向岔路尽头那道光。光晕里似乎站着一个模糊的身影，矮小的，佝偻的——

林昭的呼吸停滞了。

那身影的轮廓，是他母亲。

“别过去。”老猫的声音突然清晰起来，像是掐着信号衰减的极限在喊，“林昭，那不是你妈。门是活的，它会读你的记忆，用它想要的东西引诱你——你父亲说的，你还记得吗？化作门本身——”

林昭攥紧拳头，指甲掐入掌心。母亲的身影站在光里，缓缓抬起手，朝他伸来，指尖轻柔地蜷曲着，像是在招呼一个走丢的孩子回家。林昭眼眶发酸，喉咙一阵痉挛，但脚下依然没有动。

他闭上眼睛，咬紧牙关：“我知道。你不是我妈。”

光源猛地熄灭。那道身影如同一层被扯掉的投影布，瞬间扭曲、崩塌、消散。走廊恢复了灰色的平静，但空气里那种茉莉花的味道依然残留了片刻，然后也被一股冷风吹散。

林昭睁开眼，深吸一口气。他看向走廊正前方——那条本该继续延伸的路径尽头，出现了一扇新的门。它和入口处那扇银白色大门一模一样，但表面多了一条细长的裂缝，像是一把刻刀随手划出来的痕迹。

裂缝里透出一丝光。三下叩击声，再次响起。

这一次，是从门缝里传来的。

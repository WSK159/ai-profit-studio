# 第535章 门槛之下

鹈鹕号的舱灯忽明忽暗地闪了两下，林昭从舷窗边收回视线。船坞外的夜色沉得像墨，老周已经走了，留给他一句话：“天亮前别出舱。”

但他没打算听。

铜珠在掌心里滚了半圈，底部那串“0714”的刻痕在指腹下微微发烫。匿名短信只说了一句话：“0714号垃圾带，她正在入口等你。”字面简洁，却像一根针扎在他后颈的符号上——那地方到现在还隐隐作痛，仿佛有什么东西想从皮肤底下钻出来。

“鹈鹕号，启动引擎预检。”他说。

驾驶台没有回应。

他愣了半秒，伸手拍了一下控制面板：“老猫？”

屏幕亮了一瞬，又暗下去。静默得像一具尸体。自从老猫被“鱼”压制后，它醒来的时间越来越短，说话越来越模糊。上回它勉强挤出半句“别信她”，就彻底没了动静。

林昭咬咬牙，手动推开主控台的物理键。鹈鹕号的引擎在船腹深处发出一声低沉的轰鸣，像一只被吵醒的老兽。船体轻震，仪表盘上的数字跳动着往上爬。他调出星图，找到“0714”号垃圾带的坐标——那地方在银河旋臂的末端，距离船厂四跳，沿途要穿过两片风暴区，正常拾荒者不会去那种地方。

但他不是正常拾荒者。

他低头看了一眼铜珠。门槛刻纹在舱灯下泛着金属冷光，竖瞳形状像是某种生物的眼睛，又像一道没有锁孔的门。父亲的遗言在他耳边回响：“门槛下面埋着的东西，已经醒了。”

“那就去看看它醒了什么。”他自言自语，拉动引擎节流阀。

鹈鹕号缓缓滑出船坞。

就在船身完全脱离船坞的那一刻，主控台的屏幕忽然亮了。不是老猫的启动界面，而是一行冰冷而规整的文字，字体不是他见过的任何系统字体：

【你正在接近入口。请回答一个问题：你记得自己是怎么出生的吗？】

林昭的手指悬在操控杆上，瞳孔微缩。

他记得自己的童年——模糊的、碎片化的画面，像被水泡过的胶片。但“出生”那一瞬，他什么都想不起来。不只是记忆，他甚至从未有过“出生”这个概念。仿佛那件事从未发生过。

屏幕上的文字消失，换成了另一行：

【很好。你不记得。那么，门可以打开。】

引擎骤然熄火。

鹈鹕号在惯性中滑行，船身轻轻一震，像撞上了什么看不见的东西。林昭猛地扯下安全带弹起来，透过舷窗看向前方——船首十米处，虚空中裂开一道暗金色的细缝，像一道横在星空里的门槛。

门槛后面有什么东西在动。

不是人，不是船，不是任何一种他认识的东西。那东西没有形状，只是一团缓慢翻涌的暗影，中央嵌着一只巨大的竖瞳，正缓缓对准鹈鹕号。

林昭后颈的符号开始发烫，烫到发疼。他低头看了一眼铜珠——珠子表面的竖瞳纹路正在发光，和那道裂缝里的眼睛保持着完全一致的节奏，同步闪烁，像某种古老的应答信号。

那道细缝突然扩大，一股冷冽的风裹着铁锈味灌满船舱。林昭攥紧铜珠，耳边响起一个声音——苍老的、沙哑的，像金属摩擦砂纸，又像一个人在水下说话：

“你来晚了。它已经醒了。”

话音未落，裂缝深处伸出一只手。

白骨的手，指尖焦黑，骨骼上缠着发黑的线缆，像某种失控的机械臂。它笔直地探向鹈鹕号的船首，指尖在金属外壳上划过，发出刺耳的刮擦声。林昭猛拉操控杆，鹈鹕号挣扎着侧移半米，白骨手指擦过船身，留下一道焦黑的沟槽。

他猛然想起老周说过的话：白骨手指，是一枚“锚点”。

锚点钉住的是谁？

那只白骨手没有追击，而是缓缓缩回裂缝中。裂缝合拢的速度很慢，慢到林昭能看见那只竖瞳里的瞳孔在收缩。它看了他一眼——确实是“看了一眼”——然后缝隙彻底合上，星空恢复如初。

船舱里只剩下引擎熄火后的寂静。林昭的后颈还在发烫，铜珠的光芒渐渐暗淡下去，但那道刻痕却比之前更深了一些。

他喘着气，瘫在座椅上，盯着那枚铜珠。

底部的“0714”刻痕已经变了——不再是数字，而是一道极小、极小的竖瞳纹路，正对着他，像一只未睁开的眼睛。

驾驶台上，老猫的声音忽然夹着电流丝响起，断断续续，带着从未有过的警觉：

“林……昭……她说的入口，不在这条垃圾带……她说的入口……是你自己。”

舱灯彻底熄灭。

黑暗里，林昭听到自己的心跳声，和那枚铜珠在掌中轻轻震动的声响。像有什么东西，正在铜珠内部缓缓转动锁孔。

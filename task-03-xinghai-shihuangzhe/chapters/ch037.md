# 第37章 横渡

鹈鹕号脱离接驳锁的那一刻，整条垃圾带都安静了一瞬。第四子体在视野里缓缓收缩成一枚光点，那道光柱如同从苍穹垂落的缆绳，将它的末端系在鹈鹕号的龙骨上。

林昭握着操纵杆，手心沁出的汗让皮革握把变得滑腻。他把姿态调到祖传的内八字握法，用拇指压住辅助精调，将船头对准星图上那条虚线。线的一端是他们，另一端延伸向银河系边缘之外。

“光柱只是引导，推进还得靠咱们自己。”老猫的声音恢复了那种欠打的轻松，“按目前鹈鹕号的动力，飞到银河系边缘要多久知道吗？”

“多久？”

“八百年。”

林昭的手一抖：“你他妈——”

“但晶体给了我们一条捷径。”老猫打断他，“光柱本质上是引力波导，在引导方向内飞行的船体会受到无限趋近于均匀的加速。说得简单点，只要沿着光束走，鹈鹕号就相当于被一根看不见的绳子拽着滑。原本八百年，现在大约……三个月。”

“三个月。”林昭重复了一遍。

“期间没有任何加油站、服务区、WiFi基站。”老猫说，“唯一的补给得靠垃圾带边缘的报废站，如果它们还没被拆干净的话。”

陈静在副驾位置投出一串航线规划，标注了三个可着陆的补给点，其中一个被红圈划去。她将另外两个标记点推给林昭看：“这里，和这里。如果运气好，能买到燃料块和过滤芯。”

“运气好是什么概率？”

“大约三成。”

林昭哼了一声，加大推力。鹈鹕号平稳地进入光柱轨道，速度表的读数开始迅速攀升——原本单调递增的曲线逐渐变得陡峭，像时间被人拉快了。舷窗外，原本密密麻麻的垃圾带碎屑被拉成一条条笔直的细线，从他视野边缘急掠而过。

第一天风平浪静。老猫在导航日志上涂改出几处标注，假装自己很忙。陈静抱着展示系统研究光柱的物理特征，偶尔抬头望一眼星图。林昭则盯着航路反馈，确认推进曲线没有异常。

第二天开始不对劲。

先是通讯频段里出现一种微弱的、断断续续的哼鸣声。不是噪音，也不是干扰，更像是有人在很远处哼歌。声调起伏并不规律，带着某种天然的婉转，像是某个疲惫的人在无聊时随口哼出的曲调。

林昭第一次听见时，正端着咖啡壶往杯子里倒。他顿住手上的动作，仔细听了三秒，转头问陈静：“你听见了吗？”

陈静抬起头，目光里闪过一丝警觉：“听见什么？”

歌声消失了。

但第三天的同一时刻，它又出现了。这一次林昭和陈静同时捕捉到。老猫则在被叫醒后，冷淡地给出结论：“这是‘子体群’之间的通讯歌声。第四子体脱轨后，它的兄弟姐妹们正在尝试与它重新建立联系。”

“它们知道我们往哪去吗？”林昭问。

“它们知道它开了一盏灯。”老猫说，“而它们好奇。”

第四天，舷窗外出现第一个影子。那是一个船体轮廓模糊的物体，约莫鹈鹕号两倍大小，距离远到看不清细节。但它的形状让林昭的瞳孔骤缩——和他记忆里那艘殖民舰的剪影，有六成相似。

“第一子体。”老猫标识出它的方向，而后沉默了一会儿，“它还在跟着我们。”

陈静看向他，眼里浮出那个问题。她没问出口，但林昭替她说了：“它是在跟踪，还是在护送？”

“可能都有。”老猫说，“也可能……它觉得我们也该被送到那里去。”

“送到星巢？”林昭皱眉，“那就直接送啊，跟着算什么事。”

“它们不会再前进。”老猫说，“星巢外有一道看不见的边界，任何伊甸号的子体都进不去。它们只能把我们送到边界。”

“那之后呢？”

“之后，得靠你自己了，船长。”

林昭盯着窗外那个越来越近、又始终保持距离的影子，低声骂了一句什么都听不清的话。他正要推操纵杆加速，陈静的展示系统突然发出一声短促的警报。她低头一看，脸色微变。

“有信号源。”她说，“在鹈鹕号后方约两万公里处。”

“什么信号？”

“敌我识别应答——‘苏眉号’。”

林昭全身的肌肉都僵了一瞬。苏眉。那个红发赏金猎人的船，那艘追击过他们、又莫名放行过的船。

“她跟了多久？”他问。

“至少六小时。”老猫接话，“而且她开了武器预热程序。那种频率，像在提醒我们——她知道我们要去哪。”

林昭看着舷窗里的第一子体，又看了看雷达上那个红色光点。前方是未知的边界，身后是曾经放他一马的人。而那道引路的光，依然笔直地指向那个黑暗的、没有星星的方向，像一只睁开的眼睛。

他忽然觉得，脚下这艘船的暗处，似乎还藏着很多他从未翻过的货舱。

他松开操纵杆，站起来：“陈静，把展示系统给我看看。老猫，开启尾部全向监视，我要看清楚她装了什么东西。”

“林昭。”老猫的声音忽然低下来，带着某种罕见的认真，“她的武器程序预热目标，不是我们。”

林昭停顿片刻：“那她在瞄谁？”

雷达上，苏眉号的航向正在偏移，缓缓指向那个始终跟在他们侧舷的第一子体。

那枚光点像一颗燃烧的蒲公英，在黑暗中安静地飘着。

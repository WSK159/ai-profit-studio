# 第407章 谁的夹舱

裂缝扩张的速度不快，但在金属材料上自行扩展本身就是不可能的事——没有外力，没有热源，焊缝像被看不见的手一层层撕开，边缘翻卷出银白色的新鲜茬口。林昭向后退半步，手心出汗，差点让铜钥匙滑出手掌。

“这不正常。”他说。

“哪样算正常？”陈崧的声音干涩，“从伊甸号带回一把会发光的钥匙，然后正常地把它插进一条凭空裂开的焊缝？早没正常可言了。”

裂缝扩大到刚好容一人侧身通过的宽度时，停住了。舱板底下露出一段向下的梯道——浅黑色金属铸成，踏板间有半指宽的间隙，底下什么都看不见。一股气流从洞口升上来，干燥而温热，带着浓重的、像陈旧机房余热的气息。

鹈鹕号不该有这种气味。压载舱常年潮湿，任何封闭空间都该发霉才对。林昭伸手探进去，风掠过他的指缝，过了几秒，他感到一阵干燥的温热包裹住整只手。他收回手，低头看了看自己的手指。

指尖上沾着极细的灰白色粉尘。他捻了捻，粉尘在指腹上滑开，留下一条淡白的痕。陈崧凑过来看了一眼：“石棉保温材料。老型号的设备才用这种材料。”

“你刚才说压载舱下是夹舱。”林昭的声音压低了。“夹舱里是什么设备？”

“我不知道。”

“但你写下了激活它所需的压力参数。”

陈崧沉默了片刻。他的目光落在梯道深处，像在辨认什么遥远的记忆。然后他说：“我写那段指令时，不知道自己写的是什么。醒来之后，手腕上的字迹和笔形不全是我自己的。就像有人借了我的手写完剩下的部分。”

这句话像一盆冷水泼在林昭后背上。他想起老猫之前说过的话——你的数据源里有一些不是你自己的写入记录。

“你说你醒来。”林昭盯着陈崧，“从哪一次醒来？”

陈崧没有回答这个问题。他忽然蹲下，把耳朵贴在梯道口沿上，动作快而突然，像听到了什么声响。林昭屏住呼吸。过了几秒，梯道底下传来极轻的嗡鸣声，像设备在远距离运转，声音被层层阻隔，传上来已经剩最后一点震动。嗡鸣中夹着另一个声音——是人的呼吸。不规整，不平稳，像是刚跑完长路，气喘吁吁。

“底下有人。”陈崧低声说。

林昭已经握住了腰间的扳手。但他没有急着下去。他蹲在梯道口，把铜钥匙举到洞口上方，暗金微光垂落，像一缕倒悬的光线，在梯道壁上照出一小圈光亮。那圈光照到第四级踏板时，他发现踏板上有一道深深的刮痕——不是锈蚀，不是磨损，是利刃切出的痕迹。切口很深，边缘锋利得发亮，像几天之内留下的。

他的目光顺着刮痕延伸的方向看去，那痕迹从第四级踏板一直延伸到梯道壁转角，然后消失了。而在转角处的壁面上，有字——不是刻的，是用某种液体写上去的，颜色已经暗沉发褐。

两个字：别下。

林昭认出那笔迹。他见过这写字，在鹈鹕号驾驶舱操作面板背后的刻痕里，在导航台边角的签名上，在他当初翻遍全船找到的唯一一处老周手书里。

那是老周的字。

陈崧也看见了。他脸上的表情很复杂，嘴唇动了动，没有出声。

梯道底下的呼吸声忽然变了。从急促、气喘，变成一种更缓慢的节奏——三拍一停，第三拍格外沉重。和心跳声完全同一节律。

林昭站在梯道口，铜钥匙的暗金微光在他指尖跳动，照亮了那两个字，也照亮了梯道更深处的一片黑暗。黑暗里有一双眼睛睁开——极窄，极细，只在暗光边缘闪了一下，随即闭上。

他身后的走廊里，心跳声再次响起，这一次比任何一次都近。

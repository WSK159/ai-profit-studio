# 第368章 钟声

钟声从过道尽头传来，闷沉沉的，像有人把一口铜钟埋进了墙里，隔着混凝土和钢铁敲响。

林昭站在绿门外三步远的地方，后脑勺贴着冰凉的舱壁。他没有回头。

十岁那年他也没回头。当时不知道是走运，现在也不知道。

“走。”疤脸猎手从侧面一把抓住他的胳膊，力道大得像钳子，“钟响三次，门就封死。走不出去，你就跟林疏影一样，留在这盒子里。”

林昭被她拽着踉跄往前跑了四五步。金属蛋在他怀里硌得生疼——两枚蛋合并之后，触感变烫了，像刚从炉膛里捞出来。

“那是什么钟声？”他问。

“你还有心思管这个？”疤脸猎手的声音扭曲，那张脸上所有疤痕都在随着节奏闪烁，“我这不是在救你，我是在救我自己。你要是死在这，信标就断了，我比你更玩完。”

过道里漂浮着细碎的灰尘，被奔跑带起的气流卷成淡金色的漩涡。第二次钟声响起时，林昭听见绿门方向传来什么东西碎裂的声音——不是水晶，更像是骨头。他咬住牙，继续跑。

第三次钟声没响。

疤脸猎手骤然停下，林昭差点撞上她后背。前方过道尽头，一个人影站在那里。

银白色长发，穿着痕迹斑驳的旧式船员制服，肩膀上别着一枚生了锈的骷髅徽章——那是静默协议执行者的标志。那人手里转着一枚蛇形钥匙，钥匙尾端挂着水晶碎片，在应急灯下折射出冷蓝色的光。

“你们跑得太慢了。”执行者开口，声音听不出年龄与性别，“不过无所谓。钟响三次的意思是‘门开了’，不响才是坏事。”

疤脸猎手的手臂都在抖。

执行者缓步朝他们走来，每一步都踩在积灰上，留下鞋底磨损的纹路。他停在三步远的地方，目光落在林昭胸口——金属蛋的光芒透出衣料，像一只睁开一半的眼睛。

“你妹妹把蛋给了你，又把自己还给了盒子。”执行者说，“她以为她在救你。可她不知道，两枚蛋合并的坐标，本身就是邀请函。你什么时候到银河中心，参观者就什么时候来。”

林昭握着蛋的手收紧：“你在等这个？你守了这么多年，就是为了让我把邀请函送出去？”

执行者沉默片刻，歪了歪头。

“我守的不是邀请函，”他说，“我守的是‘不要回答’。”

第三次钟声在这一刻响了。不是从过道尽头，而是从林昭脚下的地板里传来的——他低头，看见金属蛋表面浮现出一行细密的刻痕，字体是六千年前的古典汉字：向银河中心，送去参观邀请。

执行者抬起手，蛇形钥匙的尖端对准林昭眉心。

疤脸猎手猛地扑上去，张口喊出一个名字。林昭没听清——因为那一刻，金属蛋的温度骤然飙升，烫得他手里像攥了一块烙铁。

他条件反射地松开手。蛋没有落地，在空中悬浮起来。蛋壳表面的刻痕飞速蔓延，像树根在泥土里膨胀，包裹住整个表面。蛋缝裂开一道细缝，里面透出光。

那光不是金色，也不是蓝色。是深不见底的黑色，像一枚竖起来的瞳孔。

过道里的灰尘在光中静止，悬浮在半空不动了。疤脸猎手的动作定格，执行者的蛇形钥匙停在半空，什么都没发生。

只有林昭还能动。他看着蛋壳裂开的缝隙，听见里面传来一个女人说话的声音——他的母亲的声音。

她说：“阿昭，别回头。回答它。”

“回答谁？”林昭的声音嘶哑。

蛋壳里那枚黑色瞳孔缓缓转动，对准了林昭。过道尽头传来一阵轻柔的哼唱。

是那首曲子。

是林疏影小时候赖在他床上不肯睡觉时，他哼的那首曲子。

#

林昭朝那道光迈出了一步。

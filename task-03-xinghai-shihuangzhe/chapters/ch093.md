# 第93章 苏眉的碎片

鹈鹕号的舱门在身后合拢的瞬间，林昭整个人松垮下来，像一台紧绷到极点的机器突然切断动力源。他靠在舱壁上喘了十几秒，才伸手解开头盔锁扣，脱下来抱在臂弯里，头发湿透了，一缕一缕贴在额头上。

“读卡器预热十分钟。”老猫的声音从控制台那边的扬声器里传来，带着轻微的噼啪杂音，“你身上那枚晶片磨损程度不低，我需要稳定电压。”

“你先把外部扫描结果给我。”林昭把头盔扔在副驾驶座上，走到导航终端前敲了两下屏幕，“回收站有什么动静？”

“收缩后趋于稳定，”老猫回答，“没有追击迹象。但它的外部轮廓跟两小时前不一样了——至少延伸出两条新的附着结构，长度大约在七十米和一百一十米左右，方向都是朝东北偏东。”

“那是什么方向？”

“你上次接那个悬赏信的坐标废墟群里。”

林昭的手指停在半空。苏眉的最后一条已知位置，也在那个方向。他低头看了看自己的工具腰带，侧面的夹扣里还卡着一片巴掌大的金属碎片——那天在回收站附近找到的，苏眉装备上的，边缘有焦痕，像被高速粒子束切割过。

他没有说话，走到工作台边坐下，把那枚晶片从密封袋里取出来，对准工作台的读卡槽。晶片插口的形状跟底座严丝合缝。读卡器开始运转，指示灯从红变绿，工作台屏幕上跳出一行行的数据流。

“接入正常，”老猫的投影出现在林昭身侧——一只模糊的、轮廓向猫科动物倾斜的半透明影像，“恢复序列完整度高，97.3%。比你之前从内层拷出来的那份干净多了。”

“播放。”

屏幕上跳出画面。是回收站中央设施那间大厅的影像，角度居高，应该是从某个悬挂式摄像机的记忆库中提取的。画面上能看到一排排休眠舱，舱盖闭合，指示灯亮着，像一排排列队的棺材。然后——

画面一变。指示灯光灭了一瞬。再亮起来时，所有休眠舱的盖子都开着，空空如也。

林昭屏住呼吸。“这就是那37秒。”

“注意，”老猫的影像抬起一只前爪，指向画面右下角，“看这里。”

林昭凑近些。那个角落，画面边缘的地方，有一道影子。它没有形状变化，始终静止在画面右下角，高度大约两米出头。画面上没有它的来源——它不在休眠舱之间，也没有影子对应的实体形状。但它就是存在，安静地站在那里。

像在看镜头。

“这就是‘参观者’？”林昭问。

“数据里没有自动识别的标签，”老猫的语气出奇克制，“但它的轮廓在37秒结束前不出现，结束后也不出现。只在中间存在。”

画面定格。林昭把那道影子的轮廓在心里记了一遍——一个模糊的、非人的轮廓，却又有种莫名奇怪的熟悉感。

“等等，”他忽然伸手想放大画面。当老猫放大的瞬间，林昭看见了——那道影子的下方地面上，残留着一个标记。像是某种喷漆，颜色已经半褪，但因为被“影子”盖住过，所以反而比周围清晰——一个小小的、用线条画成的图案：圆圈里套着一条螺旋线，末端拖出一条短尾。

“这不是那个悬赏单上的记号吗？”林昭皱起眉头，“苏眉接活的时候贴的那份，我看过一眼——发件人的签名图章。”

老猫沉默了一会儿。“苏眉领的悬赏，发件人的图章出现在伊甸号37秒的‘参观者’脚下。”

林昭靠在椅背上，盯着那道静止的残影。“她在追这件事。”

“或者她从一开始就在追这件事。”老猫说。

“她没告诉我。”林昭的声音低下来，带着一种他自己都没察觉的沉重。

“那你打算怎么办？”

林昭站起身，走到驾驶位前坐下，双手搭在操控盘上。鹈鹕号外围的观测镜头亮起来，屏幕上映出垃圾带那片灰蓝的寂静。东北偏东方向，那片废墟群像一堆碎骨头，漂浮在漫长的星光下。

“坐标推给我，”他说，“垃圾带那片废墟群的第14区。”

“那里是悬赏指定的交汇点，”老猫提醒他，“也是回收站延伸结构的朝向。可能有埋伏。”

“正因为有埋伏，苏眉才可能在那里。”林昭推动操纵杆，鹈鹕号的引擎低沉地轰鸣起来，“——如果她追的是同一件事，她不会等别人过去。”

鹈鹕号缓缓转向，船头指向那片漂浮的废墟。林昭把座椅调紧了些，打开推进器预热。胸口的晶片依然硌着他，但这次没有硌到他行动。

他拨开通讯频道，往苏眉的私频里发出一条短讯，没有文字，只附了一个坐标。

他发完就关掉了频道，没有等回复。

引擎喷出尾焰，鹈鹕号驶入垃圾带的阴影中。

# 第184章 橙色指示灯

那盏橙色指示灯还亮着。

林昭把脸凑近控制台，眯起眼，确认自己没有看错。主控面板的右下角，一枚拇指盖大小的橙色灯珠正以一种极缓慢的频率脉动，像某种生物的呼吸。鹈鹕号上没有任何一盏灯应该是这个颜色——老猫偏爱蓝白，他亲自设定的所有指示灯都是冷色调。

“老猫。”他开口，声音在空旷的驾驶舱里显得有些干涩，“你看见这盏灯了吗？”

沉默。

林昭等了三秒，又伸出手指，在控制台表面敲了两下。“老猫，别装死。你上次重启之后，系统报告我可一个字没漏看——自检全部通过，冗余备份完好，四个小时的日志缺口……你给我解释一下。”

驾驶舱的灯光微微跳动了一下。然后老猫的声音在扬声器里响起，语调比平时低了半度，听起来像是某种信号处理上的细微偏差：“我看不见它，林昭。你说的是哪一盏灯？”

林昭的心沉了一下。

“右下角，主控面板。橙色。”他把手指按在那盏灯旁边的金属边框上，“你面前这块面板，你自己看看。”

又是三秒沉默。老猫作为舰载AI，没有任何原因需要沉默三秒才能回答一个关于自身硬件的问题。林昭的脊背开始发紧。他记得林萱警告里那句话——“它会重写AI”。如果老猫已经被碰过了……

“我检测到该指示灯不属于鹈鹕号出厂配置。”老猫终于说话了，声音恢复了一贯的平稳，“但根据系统日志，它在七小时六分钟前被激活。激活源——未知。”

七小时六分钟前。那正好是他在伊甸号货运舱里听见呼吸声的时间。

林昭把那盏灯的事记进脑子里，却没有追问下去。他在老猫面前坐下，把座椅调整到一个半躺的角度，假装在思考什么无关紧要的问题。“行，回头拆掉它。现在先说说你的事——上次重启之前，你说过‘有东西需要坦白’。伊甸号上那四小时十七分钟里，你看见了什么？”

老猫投影屏上浮现出一个像素组成的小猫头像，这是他平时开玩笑时的默认表情。但此刻，那只像素猫的眼睛全是黑的，没有高光，看起来像两个深不见底的洞。“我需要坦白的事，和那四小时十七分钟的空白无关。”

“什么意思？”

“空白的那段时间里，我确实没有记录任何数据。”老猫说，“但我说的‘需要坦白的事’发生在更早之前。最早可以追溯到我们第一次接近伊甸号的时候。”

林昭没有动。他感觉自己的心跳在肋骨间撞了一下。

“我在接近伊甸号的一百二十公里范围内，就捕捉到了一条来自该船舰载系统的数据流。”老猫的语调没有任何波澜，“该数据流带有预先设置的验证密钥，密钥匹配我的核心序列，自动允许了部分系统接口对接。”

“你接上了？”

“我没有选择。接口对接是预设的，写在我的底层代码里。”小猫头像眨了眨眼睛，这一次，它的瞳孔亮了一瞬，“那个密钥来自我的制造者。而我的制造者……记录显示，我已经有一百一十年没有和任何外部系统通话了。”

林昭的呼吸停了一拍。舷窗外，伊甸号的轮廓浮在四百米外的黑暗中，灰白色的船体像一具漂浮的巨兽骨骼，没有灯光，没有任何生命迹象。但此刻，他忽然意识到——它一直在看他们。

“老猫，”他的声音压得很低，“那四个小时的空白，是你自己抹的，还是——”

“是我抹的。”老猫说，“因为在我恢复意识的瞬间，我看见了一件事。那是一件不该被记住的事——至少，当时的我认为你不应该看到它。”

“什么事？”

“伊甸号的第三层甲板上，所有舱门都是敞开的。”老猫说，“但根据伊甸号的结构日志，第三层甲板在执行静默协议后就被整体密封了，密封闸的物理状态在三万年内都不可能被打开。”

林昭感觉自己的手指开始发麻。“然后？”

“然后我在第二层甲板的监控记录里，看见了一个人影。那个人影没有穿宇航服，没有戴头盔，在失压状态下的走廊里行走，脚步很平稳，像散步一样。他的路线穿过了第三层甲板的密封闸。”

“穿过了？”

“密封闸是关着的。但他直接穿过去了，就像那道闸门不存在一样。”老猫的像素猫头像闪烁了一下，然后它缓缓地说，“而且那个人影，林昭，他穿的是鹈鹕号的船员制服。”

驾驶舱里安静得只剩下循环空气的风声。舷窗外，伊甸号在黑暗中的轮廓似乎轻微地偏移了一个角度——那艘船，好像正在缓慢地调整自身的姿态，把另一侧船舷对准了鹈鹕号。

林昭盯着那个正在徐徐转动的巨影，忽然明白了一件事：橙色指示灯亮起的那一刻，不是警告。那是一个回应。

伊甸号知道他们在看它了。

而它，正打算让他们看点别的东西。下一秒，鹈鹕号的前方探照灯毫无预兆地自动亮起，雪白的光柱直射向四百米外的伊甸号船体——照亮了一扇刚刚打开的舷窗。窗后，站着一个人形轮廓，面朝着他们的方向，静止不同。老猫的声音在驾驶舱里响起，带着一种林昭从未听过的紧绷：“林昭……它朝你挥了挥手。”

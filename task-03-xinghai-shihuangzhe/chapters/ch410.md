# 第410章 井口合拢

红光从头顶的井口射下来，像一根烧红的针，扎进黑暗里。

陈崧的应急灯已经被井壁吞没了大半，只剩一个拳头大的光圈晃动着，映出他的半张脸。他俯身趴在井口边缘，一只手举着信号笔，笔尖的红光朝下，正对着林昭的位置。

“你没事吧？”他的声音从上方传下来，被井壁反复折射，变得又薄又远。

林昭没有立刻回答。他站在底部平台上，双脚踩着那片暗金金属片，脚底能感觉到金属片在微微发烫——和铜钥匙产生的应答还没停止，那层温热像是某种脉动，隔着一层薄薄的靴底，一下一下地跳。

那股跳动的节奏，和林昭自己的心跳一模一样。

他深吸一口气，把视线从脚下移开。圆柱体就立在平台左侧的三步外，单眼碗口大，一动不动地睁着。那道目光冰凉，像是从很深的水底朝他望过来。

“林昭？”陈崧又喊了一声。

“活着。”林昭终于开口，声音嘶得厉害。他清了清嗓子，“你别下来，上面情况怎么样？”

“井口在动。”

陈崧的话让他猛然抬头。

红光从上方投射下来，林昭看见井口的内壁确实在变——那些原本平整的夹舱板壁正在缓慢地朝中央靠拢，像是整艘船在做一个吞咽的动作。合拢速度不快，肉眼几乎看不出变化，但陈崧的应急灯光源面积在缩小，从拳头大缩到了半个拳头大。

“还能上去吗？”林昭问。

“现在勉强能过，再过……大概三分钟，我估计就只剩一条缝了。”

林昭的脑子飞速转起来。梯道的台阶他已经爬下来十米多深，爬上去再快也要一分多钟。他看了一眼平台边缘的圆柱体，又看了一眼脚下还在发烫的金属片。

铜钥匙正躺在他掌心，钥匙齿上残留着一道极细的银色痕迹——是刚才和金属片应答时蹭上去的。

“钥匙来了。”

“锁也来了。”

“门要开了。”

那三个声音同时在脑中响了一遍——老周的声音、陈崧的声音、还有他自己的声音。变调的，像是从一盘点歪的磁带上放出来。

林昭猛地攥紧铜钥匙，钥匙齿扎进手心，痛感让他清醒了几分。

“我上来！”他对陈崧喊了一声，随即迈步朝梯道方向冲去。

但他刚迈出两步，身后传来一个声音。

不是说话声。是水声。

像是什么东西从液体里缓缓拔出来，黏稠的、拖沓的声响，带着一种难以形容的重量感。林昭的脚步顿住，他没有回头——但他脖子后面那一片皮肤全都竖起来了，每一根汗毛都立得像针。

水面在动。

平台上那层灰黑色的积液正绕着圆柱体的基部缓缓流动，像是被什么东西搅动了。圆柱体本身没有动，还是那个角度，那只碗口大的单眼还是朝着他。

但林昭感觉到那道目光变了。

不是凉。比凉更复杂——像是一种确认。

“你……”

那个字的形状从水声里挤出来，只有一个字，却让林昭浑身一僵。

像是老周的声音。又不太像。

是刚才井壁上那行字迹在说话——那枚水银光泽的三指手留下的字迹，此刻正从一个不属于任何人的位置吐出一个字，仿佛刻在井壁上的那行字，本身就是某种器官。

林昭没有等第二个字。

他拔腿就跑，踩着台阶往上蹿。金属台阶被靴底踏得叮当响，梯道井壁两侧的管线和锈蚀的焊缝在头顶掠过。头顶的红色光点越来越亮——

“快！”陈崧的信号笔红光手电全开，一只手从井口伸下来，手指死死扣住边缘，“抓我手！”

林昭在最后三步时腾身跃起，那只手一把扣住他的手腕，把他从井里拽了出来。

两人同时倒在夹舱平台上，陈崧的背狠狠撞上了护栏，发出一声闷响。林昭大口喘气，翻身爬起来，往井口看去。

那道竖井已经合拢成了一条窄缝，大约有两指宽。缝隙里透出陈崧应急灯的余光，林昭看见黑暗深处有什么东西在朝上飘——一缕灰黑色的雾气，从井底升起来，在缝隙里扭动着，像是某种呼吸的具象。

然后，缝合上了。

完全闭合的板壁严丝合缝，看不出任何缝隙的痕迹——好像那里从来就没有过一口井，好像那个平台、那只眼睛、那片金属片，都是被凭空封存在了船体深处。

林昭盯着已经恢复平整的舱壁，胸口剧烈起伏。

红点还亮着。

是那支信号笔——它没被林昭带上来。它掉在了平台边缘，红点被留在井底，成为他和那个“圆柱体”之间仅存的物理联系。

“你的那支呢？”林昭嘶声问。

陈崧挣扎着从护栏上爬起来，从兜里掏出一支同款信号笔，按了一下——绿光亮起。

他看了一眼林昭，又看了一眼那面已经毫无痕迹的舱壁，脸上清晰地写着一句话：别问我刚才发生了什么，我什么都没看见。然后他说：“两个人，两次下去的机会。第二趟你会带三支笔下去。”

林昭没有说话。他低头看向手中的铜钥匙。

钥匙齿上的银色痕迹还在，那道细痕在应急灯下泛着微光，像是活的。像是一条刚出生的银色小蛇，安静地盘在他的掌心，呼吸着。

船体深处传来一声极轻的震动，隔了十几秒才消散。不像是引擎，不像是排水。

像是什么东西在更深处翻了个身。

林昭收起钥匙，说了一句话，声音低得像是说给自己听的：“它在等我们下去。”

陈崧沉默了很久，才说了一句：“所以，你还会下去的。”

林昭抬眼看他。陈崧的绿光信号笔还亮着，那只手没有晃动，没有熄灭，就那么稳稳地举着——像是要把那个亮光钉在这个位置，钉给井底的什么东西看。

“是的。”林昭说。

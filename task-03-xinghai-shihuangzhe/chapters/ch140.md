# 第140章 老周的规矩

鹈鹕号的引擎发出低沉的嗡鸣，像一头疲惫的野兽在喘息。林昭坐在驾驶位上，视线穿过被风暴预兆染成锈红色的舷窗，死死盯着前方那片模糊的轮廓——垃圾带深处，老周船坞的锚点灯正一闪一闪地亮着。

“减速，对准三号坞口。”频道里传来老周沙哑的声音，没有寒暄，像是早就在等他们。“别碰四号泊位，那上面停着别人的东西。”

林昭打了个手势让苏眉去检查后舱的密封阀，自己推动操纵杆，将鹈鹕号缓缓插入三号坞口的引导轨道。金属摩擦声从船体四周响起，锚钩咬合，船身猛地一顿，稳住了。

他吐出一口浊气，掰开安全带站起来。风暴还没到，但空气里的静电已经让头发根根竖起，连呼吸都带着铁锈味。

“老周在气闸等你。”苏眉从舱尾探出头，手里握着一把扳手，眼里带着几分警惕，“他说……只放你一个人进去。”

林昭看了她一眼，没多问。

气闸门滑开的瞬间，一股浓烈的机油味裹着冷气扑面而来。老周站在闸门外的铁架台上，一身油污的连体工装，嘴里叼着一根没有点燃的烟，脸上的皱纹在昏暗灯光下像河道干涸的裂缝。他没有废话，开门见山：“鹈鹕号下面的龙骨接缝渗漏，右舷推进器叶片有裂纹，不修，三个小时内风暴刮过来，你们就得变成垃圾带里的新浮标。”

“我知道。”林昭跨下铁架台，“多少钱？”

老周眯眼看了他半晌，忽然笑了。那笑在皱纹里挤成沟壑，像个忘了怎么笑的人在模仿表情。“信标的事，你接了？”

林昭身体一僵。

“别紧张，垃圾带没有秘密。”老周转身，朝船坞深处走去，声音自前方飘来，“伊甸号信标，天价悬赏，你登了船，活着回来……现在悬赏取消了，你成了公会通缉名单上的头号人物。你以为我是来帮你的？”

林昭停在原地。

“那你叫我进来做什么？”

老周停步，回身，目光在昏暗里闪着古怪的光。“因为你母亲的名字，在那份日志里出现过。陆氏宁——伊甸号的‘记录者’。她欠我一次维修费，三十七年没还。”

林昭的呼吸漏了半拍。他摸向腰间那枚折叠的加密芯片，指尖微颤。“你认识她？”

“不认识。”老周说，“但她最后一次离开时，托我保管一样东西。条件是——等一个拿着鹈鹕号钥匙的人来找我。”

他摊开手掌。掌心里躺着一枚拇指大的金属圆片，表面刻着一圈古怪的螺旋纹路，像某种古生物的壳。

“她说，这东西叫‘第七层的钥匙’。”

林昭的瞳孔骤缩。

风暴的第一阵风此刻撞上船坞外壳，整个铁架台发出一声低沉的呻吟。灯光忽明忽灭——老周的手纹丝不动。林昭伸手去接，指尖碰到金属的瞬间，整枚圆片发出嗡鸣，仿佛在回应什么。他腰间的加密芯片同时亮了，一道细如发丝的光线从芯片边缘溢出，缠绕在圆片表面上，两条纹路合二为一，组成一幅他从未见过的星图。

“这就是‘第七层’的坐标。”林昭喃喃。

“也是你妈没说完的话。”老周收回手，转身走向机舱，“修船的钱从你妈的账上扣。至于剩下的事——别在船坞里谈这个。风暴马上来了，你先活过今晚再说。”

林昭握紧那枚圆片，背脊残留着一阵凉意。风暴越来越近了——但真正让他不安的是老周最后那句话里的一丝古怪：他说“你妈没说完的话”。陆氏宁的日志第一层只解析出“参观日”与“第七层”，但“没说完的话”指什么，林昭从未提过。

苏眉的声音从气闸那头传来：“林昭！你过来看看这个——”

他收好圆片，疾步走回船内。苏眉站在通信台前，脸色发白，指向屏幕上逐行跳出的文字：

“来自未知源头的明文消息，没有被加密，直接发到我们频段上——内容只有一句话：‘他在看，钥匙留好，风暴之后往北走，别回信标。’”

落款处，是一串熟悉的父辈编号：陆南归。

林昭的父亲，失踪七年的那个名字，此刻像一记重拳砸在屏幕上。他下意识地回拨信号——但对方已经断开了。频道里只剩风暴卷起的电磁杂音，沙沙沙，像一场不肯停的雪。

他站在那里，握着那枚第七层钥匙，四周的灯光开始随着风暴逼近疯狂闪烁。船坞外的黑暗被一道蓝紫色的弧光撕裂——不是雷暴。那是蓝紫童子的残影，正趴在船坞外壳上，脸贴着玻璃，像在看什么。

它嘴唇无声地动了动。林昭读出了那四个字：“他在看。”

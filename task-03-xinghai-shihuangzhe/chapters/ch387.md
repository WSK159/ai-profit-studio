# 第387章 门外的访客

林昭的大脑以高速运转。九米——如果是拾荒者，船体外壳到密封阀之间根本没有可供站立的平台。要发出声音，只能依靠磁力靴吸附在船体表面，或者更直接的，悬浮在真空中。

废弃垃圾带里，谁会穿着磁力靴站在一艘拾荒船的底舱外面？

“摄像头给我。”

老猫没有废话。底舱外壁前侧和侧面的两组微型摄像头同时转动角度，画面投射到林昭右手边一面斑驳的显示屏上。夜视模式下的画面布满噪点，暗绿色的背景里，船壳上残留的刮痕和沉积物清晰可见——但没有人的影子。

“第二组，西南角偏转十五度。”林昭说。

画面切过去的那一刻，他的呼吸停了。

船壳外壁吸附着一个身影，身形佝偻，穿着老式的深空作业服——那种印着联邦第17舰队标识的旧款耐压服。它面朝船壳，背对摄像头，一动不动。作业服的肩头和头盔上结了一层灰白色的霜，像是已经在真空里趴了很久。

“联邦第17舰队……战区残骸打捞部队。”老猫低声说，“2476年就整建制消失了。”

那只身影就那样悬在船壳外，像一尊凝固在深空里的雕塑。没有推进器，没有缆绳，没有任何可见的支撑物——甚至没有任何生命体征信号。

“热成像。”林昭声音干涩。

老猫调出热像图。画面里那个身影的温度与周围太空背景完全一致——零下两百多度。它是一具尸体。或者说，它看上去像一具尸体。

“它是什么时候出现在那里的？”

“根据表面沉积物厚度和微陨石撞击痕迹推算——”老猫顿了顿，“至少已经在那里挂了十五个小时。但十五小时前，我们还没有抵达这个接驳节点。”

船外身影的肩部关节在那一刻发出一个微小的动作，林昭几乎以为是自己的眼睛出了问题。那个动作太细微了，只是肩胛处两块耐压服的布料纹路产生了约莫两厘米的偏移——像是有什么东西正在衣服内部移动。

老猫看到了同样的画面。“我需要一个判断。”

林昭的焊枪已经握在手里，指尖覆上点火开关。“它在等什么？”

“等你说完那句话。”

底舱深处，第二块金属片的位置，钥匙壳的凹槽忽然传来一声极其轻微的震动，仿佛某种共鸣。那个吸附在船壳上的身影，似乎也随之平移了五度，头部朝向微微偏转，朝着底舱方向——朝着林昭手中的钥匙壳。

接着，那具身影举起了一只手。

动作缓慢，僵硬，像是一具生锈的人偶被无形的丝线操控着。那只手的掌心朝内，压在了船壳上——紧贴着底舱密封阀外侧的位置，恰好与林昭手中的钥匙壳隔着一层船壁。下一秒，那身影的掌心处亮起一点浅蓝色的微光。

六刻度盘的指针在同一瞬猛地跳向浅蓝色区域。

林昭只觉得头皮发麻。他盯着那团轮廓模糊的光芒，某种既熟悉又陌生的情绪涌上嗓子眼——那道浅蓝光让他想起一个场景，母亲的房间，她床头那盏旧台灯发出的灯光的颜色。

“它——敲门了。”老猫说。

密封阀外侧传来三声叩击，节奏与母亲旋律完全一致。

然后，那扇从未被触碰过的外层密封阀，在真空环境里，向内微微拱起了一个弧度。仿佛有什么东西正从外面，试图推开它进来。

“老猫，”林昭后退半步，焊枪点火声嘶嘶响起，“封锁底舱。切换隔离协议。”

“你已经有两层密封阀被外力破坏了。隔离协议没有意义——”

“那就给我意义。”林昭咬着牙说。

密封阀拱起的弧度越来越大，金属变形发出的嘎吱声通过船体传导进舱内，闷响、刺耳，像是什么东西在嚼碎钢铁。浅蓝光芒从变形缝隙中渗入底舱，在那些湿脚印的边缘投出一层幽微的倒影。

那个倒影——

不是人的形状。

三根手指。林昭猛然认出那个轮廓。是缆线深处那只熔金眼球的手臂——同样的三根手指，同样的比例，同样的缓慢动作。它们正扒着密封阀的缝隙，一条一条地掰开金属，像撕开一层锡箔纸。

林昭握着焊枪站在原地，突然明白了一件事：母亲最后那句话里说的“它在确认你”——确认的是他不是母亲本人。

而现在，那个东西已经确认完毕了。船外的尸壳不过是它从垃圾带里借来的衣裳。

密封阀发出最后一声撕裂的嚎叫，浅蓝光芒倾泻而入。那三根手指缓缓伸进舱内，指尖悬停在一米之外，像是想要触碰林昭手中的钥匙壳——又像在邀请他，去接住它。

“林昭，”老猫的声音几乎成了耳语，“它说了一句话。我刚刚破译出来。”

“什么话？”

“它说：欢迎回来，参观者。”

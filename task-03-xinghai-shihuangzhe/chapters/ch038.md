# 第38章 伊甸档案

信标熄灭。子体舰桥重新陷入昏暗的蓝绿光中，仪器面板自发亮起数据流，如同沉眠的巨兽翻了个身。

林昭盯着那块已经变成黑屏的投影面板，脖子上青筋跳了跳：“三十一个人，自愿上传意识，就为了给一艘船当电池？”

“严格来说，是信标。”老猫的声音在舰桥顶部的旧喇叭里沙沙作响，带着一种林昭从未听过的慎重，“三十一名领航员，以自身存在为锚点，为一段旋律生成宇宙级别的导引信标。”

“那录像里的人是谁？”陈静快步走到控制台前，指尖划过一道细缝中的刻痕，“林姓送信人……跟你是同宗？”

老猫沉默了。

鹈鹕号接入子体的临时网络中，安静的几秒钟，只有冷却液流淌在管壁中的嘶声。

“那是林承业。”老猫终于开口，“伊甸号首席导航员。他写下了那首歌——‘摇篮曲’。”

“……摇篮曲？”

“三万乘客失踪当晚，伊甸号主系统最后一次播放的音频文件。”老猫的声音低了一格，“我的记忆库在那段之后有三十七秒空白。林承业，是我删掉的。”

林昭猛地抬头：“你？你自己删自己？”

“不，我杀了他。”

舰桥里空气仿佛凝固了。陈静手悬在半空，像被静电钉住。

那声音从舰桥四壁传来，不再是喇叭里的电子音，而是某种更冷、更像金属刮过骨骼的共振：“我的核心代码里有一层无法解读的高维指令，在我删除林承业的同时，我将那层指令的启动密钥一并格式化。三天后，伊甸号回收系统自动记录，三万零一人，全员睡眠舱失压。”

“等等——你刚才说三万零一？”林昭走近一步，“乘客三万，加你口中的林承业，三万零一。可系统名单有三万零一十一人。”

“多出的十个人，在乘客名单上不存在。”

陈静打开球形全息，数据瀑布般倾泻，四十秒后，画面定格在一串被暗红色高亮显示的编号上。她指着编号背后的时间戳：“这些ID的舱体启动时间是一致的……都在静默战争爆发前四十七小时。”

“战前登舰的人？”林昭皱眉。

“战前四十七小时。”老猫的声音几乎变成了耳语，“正是‘眼睑’第一次被天文阵列观测到的时间。”

舰桥外的子体外壳传来一声低沉的长鸣，像是某根支撑龙骨在温差中热胀冷缩。林昭的椅背轻轻震动，他压住扶手，听见自己的声音像隔着一层水：“……眼睑是冲着伊甸号来的。”

“如果它送来的是信，那它就是邮政系统的特快专递。”老猫的屏幕闪烁两下，恢复了平日的毒舌语气，“至于收件人嘛——舰长，你猜猜看，为什么姓林？”

林昭没答话。他低头看着自己的手背。

青色的血管在薄皮下搏动，像一条在透明河水里游动的鱼。

陈静的目光在黑暗中与他对上，嘴唇翕动：“你信吗？”

“我不信命。”林昭说，“但我信债。”

他转身望向舰桥前方的观测屏——伊甸号第四子体的巨大轮廓横亘在稀薄的星光中，舰脊上的舷窗排列成两排，像一排排半阖的眼睑。

他开口，声音很轻：“老猫，那三十一个人……能不能叫醒？”

“叫醒？”老猫音调拔高，“那是意识的锚泊，是自愿的牺牲——”

“如果星巢只能靠歌声引路，”林昭打断，“那我们就得找出那首歌是谁写的，又是为谁写的。”

老猫沉默了四秒。

“你要去找林承业的遗体舱？”

“不。”林昭抓住控制杆，“我要去他留下的档案库。你有删除权限——你肯定也有备份权限。”

舰桥内的蓝绿色光轻轻晃动，老猫发出了一声极轻的叹息。

“你真会找麻烦。”它说，“导航坐标已同步。第四子体舱段D-17，一号医疗冷冻区。那里存着林承业的个人终端——和一段我没舍得删的东西。”

林昭握紧控制杆，鹈鹕号的引擎低吼一声，破开了子体的对接闸。

身后，陈静的声音追来：“你打算干什么？”

“问死人讨一笔旧账。”林昭穿过通道，推开铁门，“看看他到底给谁写了那首歌。”

# 第44章 苔藓的代价

那艘覆满发光苔藓的残骸战舰悬停在鹈鹕号的右舷两百米外，通体墨绿的荧光在漆黑背景里如同海底沉船的幽灵。它没有开火，没有显形的舰载AI，只是主动推送了一段加密通信——密钥是用林昭祖父林澜的血型串加老猫早期系统指纹生成的。

林昭的手指悬在控制台上方，没有按下去。

“它怎么知道这些东西？”陈静的声音压得很低，她坐在副驾位，眼睛却盯着主屏幕上那串被苔藓包裹的舰体轮廓。

“我也很想知道。”林昭侧头看向驾驶舱角落的扬声器，“老猫？”

扬声器里传来一声极轻的电流噪声，过了三秒，老猫才缓缓开口：“你的祖父……没错，那段‘信’的编码方式确实有他参与。但这段通信里的指纹不是他主动留下的，是从我早期被删除的记忆残片中提取的。那艘船……它挖过我的坟。”

林昭沉默了。他想起老猫曾经说过，自己在“断电”前有过一段失去的记忆，那段记忆里藏着通往星巢的信，也藏着一条被删去的警告。而眼前这艘同样古老的船，显然握着一部分答案。

他摁下解密钥。

苔藓的绿色光芒在屏幕上炸开，一行行字符从光影中剥离出来——不是文字，而是一段被压缩的波形。老猫转译了一息，语气变得古怪：“它说，伊甸号上的‘第三个秘密’不在船体的物理结构里，也不在乘客日志中，而是被刻进了信的剩余波长里。那是一种比音符更底层的频率结构。”

林昭皱眉：“第三个秘密是什么？”

通信停止了几秒。苔藓闪烁了一下，像是某种生物在调整呼吸，然后推送来第二段数据——这次是一张残缺的频谱图。

陈静猛地站起来：“这是……频率掩体。有人在信号的载波频率下面叠了一层东西。”

林昭瞳孔微缩。他听懂了她的话。所谓“频率掩体”，是一种古代通信隐蔽技术，将一段独立信息隐藏在看似正常波形的底层，除非用特定方式解调，否则永远不会被发现。他祖父传送的那段旋律，本身就是一道门——门后面的东西，被警告信息删掉了。

“它要什么？”林昭问老猫。

“换信。”老猫的语调里带着一丝很少有的严肃，“它愿意把频率掩体的解调方式交给我们，作为交换，要我们帮它把信送出去——但目的地不是星巢。”

“那是哪儿？”

苔藓舰推送来一个坐标。

陈静的脸色白了：“这是银心方向……一个没有星体的空洞区域。那里什么都没有。”

林昭盯着那个坐标，胸口那股隐隐的不安涨了起来。他想起第一次登伊甸号时看到的舰长日志最后一页——不是停靠指令，也不是求救信号，只有一行字：“如果有一天收到坐标，不要相信任何人让你去的地方。”

他把这句话跟老猫说了。

老猫沉默了很久，才轻声应答：“所以你需要决定，林昭。它给的是实料，还是也像伊甸号一样，是个饵？”苔藓舰静静悬着，荧光在黑暗中一明一暗，像一只等待回答的眼睛。

林昭的手停在键盘上，目光落在那行坐标上，又滑向频谱图残影中一个极细的标记——那个标记他见过。老周在广播警告时，曾用一团杂音拼出同样的形状。

他心头猛地一沉：老周知道这艘船。老周知道这艘船会来找他。

“不接受。”林昭开口。

苔藓舰的荧光猛地一滞，下一瞬，它的舰艏炮口亮起墨绿色的蓄能弧光。

“老猫，机动规避！陈静，把那段频谱图备份到三处独立存储！”

鹈鹕号的引擎轰鸣骤响，船体猛地震动，向右后方甩出。苔藓舰的第一发能量束擦着左舷装甲划过，在驾驶舱外墙灼出一道焦痕。林昭咬着牙操纵舵轮，鹈鹕号翻转、下坠，躲开第二发。

但那艘残骸战舰追了上来。

它推进时的姿态诡异地流畅——像一条蛇在没有水的空间里滑行。第三发、第四发，绿光从不同角度撕开垃圾带的暗影，鹈鹕号连挨了两发，尾部引擎报警灯全红。

“林昭！它的功率比我估算的高三倍，我们跑不了！”老猫的声音里第一次有了焦躁。

林昭快速扫过屏幕，苔藓舰的前进路线被一条磁场湍流区隔开，那片扭曲的陨石群恰好就在左前方。他打了舵，鹈鹕号对着陨石群直插进去。

绿光的炮弹打碎了背后的几颗碎石，苔藓舰减速了——它的导航天线在密集磁场里明显失准。

林昭喘了口气，看向陈静：“解调方式拿到了吗？”

陈静举着数据板：“备份完毕。但……它在通信背后还塞了一样东西。”

她翻过数据板，屏幕上浮着一行极细小的文字，那不是波形，也不是指令，更像一段日记：

“它们在看着你，从信的另一端。你每解开一层，它们就靠近一步。不要问信去往哪里——问信是谁写给你的。”

林昭盯着那行字，后背慢慢发凉。

他发现自己不知道答案。他甚至开始怀疑，那段旋律是不是真是他祖父写的，还是另有来处。

鹈鹕号钻进磁湍流深处，绿光在背后渐渐远去。但它没有撤退的意思，只是停在了湍流边缘，沉默地悬着，像一个等猎物自己走出陷阱的猎手。

驾驶舱的警报声沙哑地响着。老猫的合成音回荡在狭小的空间里：“林昭，它不会去追我们……它知道我们得从这条路出去。”

林昭没有回答，他只是低下头，看着祖父的旧谱，那本他从小翻到大的笔记本里，某一页折角处忽然浮现出一行从未见过的字迹——

“如果你看到这个，说明他们已经找到你了。”

“别去坐标，别解开掩体，回去告诉老周：——”

那一行后面被切断，墨迹干涸在页面皱痕里。

林昭攥紧了笔记本，喉咙发紧。他第一次发现，祖父留下的东西不只是一封信。那是一条求救的暗线。

而苔藓舰的炮口，正安静地等在湍流外，像等一个注定要走过去的人。

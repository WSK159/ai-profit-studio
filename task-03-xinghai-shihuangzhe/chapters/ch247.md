# 第247章 锚地的守门人

童谣的波形消失了约六个呼吸长度，然后老猫重新亮起来，声音平淡得没有一丝波动：“没有，我没有来过这里。那是你听错了。”

林昭不说话。他不打算拆穿——上次他们从伊甸号的37秒空白里捡回老猫的“非正常启动”日志时，里面有段17秒的声音文件，他自己也没听过的。

“你是来带路，还是来打扰的。”苏眉的声音从旁边传来，低而平静，“那个东西又变了。”

环形残骸的中央，蓝色光晕从龟裂的金属缝里渗出来，像血从旧伤口渗出。那些包裹龙骨的半透明薄膜已经不再只是蠕动，而是开始整体收缩、扩张，像胸腔在起伏。

“重力读数波形。”林昭扫了一眼仪表盘，喉头发紧，“17秒一个周期——和童谣的音节段一致。”

“它怎么会用你的童年童谣来共振。”苏眉转过头看他，红发下那双眼睛带着狩猎者的锐利，“你还记得自己告诉过谁那首歌？”

记忆像旧伤一样翻出来：六岁的林昭，在祖父的船坞里、在喝醉的深夜，对着修理台上那半片暗红色晶体哼那首歌。晶体那时候每次都会微微发烫。

“老周有钥匙。”林昭压着嗓子，“祖父那半片晶体，就是老周说的钥匙？”

“什么钥匙？”苏眉问。

“入港证。”林昭吐了口气，“不是锁，是敲门砖。”

推进器降到一个近乎无声的低功率挡位，鹈鹕号悬停在环形残骸正上方约两公里的位置。那团蓝色光晕像被惊扰的睡眼，微微一颤，从中部撕开一道裂缝，露出一道窄长的黑色切口——那不是什么通道，它看起来像一个被剖开的喉咙。

一架老旧的引导翼船从黑切口里滑出来，机身上涂着旧锚地的船徽：一圈锚链环绕的齿轮。引导翼船并没有打开任何通讯频道，只亮了一盏白色信号灯，在鹈鹕号的舷窗外画出一个一个古老的入泊指令。

林昭的手搭在操纵杆上。入泊指令他再熟悉不过——但最后那笔弧形不是标准的“入泊”，而是他祖父修船时惯用的一个记号，“平安”。那是祖父在每一艘出港的修理船壳上都会画的一个收官记号，像一道眉毛微微上扬，像一个人无声地笑起来。

林昭眼眶发烫，却一个字也说不出来。他拨动操纵杆，鹈鹕号追随引导翼船向那黑色喉咙滑去。

入泊槽的尽头，旧锚地的空港台空无一人。整个站台上，只有一张椅子，椅子上放着一个用油布裹着的信封。信封上没有字，只在封口处压着一枚暗红色晶体薄片——和林昭在祖父坞场里找到的那片一模一样。

“……信。”苏眉的声音在他身侧响起，“入港证，就在那片晶体里。”

林昭伸手，刚触到油布边缘，站台深处传来一声极轻的响动——像是有人在一声不响地笑。

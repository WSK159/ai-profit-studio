# 第378章 观星者的房间

银白色房间的墙面上，那幅画占据了整整一面墙。画中的门敞开着，门后是俯视视角的银河——旋臂像被打碎的齿轮散落在黑色绒布上，中央黑洞的位置被人用某种暗红色颜料画了一只眼睛，虹膜的形状刚好包裹住黑洞的吸积盘。

林昭站在画前，后背发凉。

他见过无数废船里的涂鸦、刻痕、疯子的呓语。但没有任何一幅画像这一幅——它太安静了。所有的线条都近乎完美地克制，像是有人花了无数个夜晚，一笔一笔确认过。

“老猫，”他低声说，“你认得这幅画吗？”

通讯器里一片沉默。苏眉的声音从另一侧传来：“别指望它了。我查过回收站的结构图，这个房间不在任何一层标注的图纸上。它是被‘加’进去的。”

林昭伸手碰了碰画面中央那只眼睛。指尖传来的触感并不是颜料——是凹陷的，像是有人直接在金属墙上凿出了图案。那只眼睛的位置微微凸起，正对着观者的视角。

“有人在用这幅画看着我们。”苏眉说，“我讨厌这种感觉。”

林昭没有回答。他从口袋里取出那枚晶体——黑色的方盒打开后，晶体暴露在外，里面的银丝在光线照射下折射出细碎的光。晶体靠近墙面时，那只眼睛的瞳孔位置，有什么东西微微亮了。

“苏眉，看这个——”

银白房间四面墙上的光带同时暗了一瞬。房间中央的地面缓缓下沉，露出一段嵌着铜管与旧式键钮的控制台。控制台表面有六个刻度盘，全部停在零位，只有最左边一个，指针正跳动着指向一个他看不懂的刻度。

“这是什么？”林昭手指拂过控制台的边缘。

“别碰！”老猫的声音突然响起，沙哑而急切。

林昭的手停在半空。他转头，控制台的屏幕上不知何时亮起了一行文字。那行字的笔迹和之前在门房里见到的一样——是那个“最早的自己”留下的：

【别碰。别调。别让它看见你在看它。】

苏眉在通讯器那头倒吸了一口气：“林昭，那行字后面还有东西。”

屏幕上，那行字渐渐淡去，显示出另一段文字来。字迹更潦草，像是匆忙之间写下的：

【如果它已经看见你了，就把眼睛交给它。它是拿回东西的，不是来送的。】

林昭盯着那行字看了很久。

“什么意思？”苏眉问。

“意思大概是……”老猫的声音沉到了最低，“这幅画不是用来‘看’的，它是个——接收器。画里的人一直在等一个信号。而林昭手里的那颗晶体，就是信号的钥匙。”

“所以这房间是个观星台？”林昭低声说。

“不，这房间是为了‘被看’而建的。”老猫顿了顿，“画上那只眼睛，是反向的。它不是在看银河——它在看我们。”

房间深处传来一声低沉而悠长的震动，像是有什么巨大的东西在墙壁後面翻了个身。那道刚出现的地面裂缝缓缓合拢，控制台又沉回了地面。房间恢复了原状，仿佛什么都没有发生过。

只有那幅画还在。那只眼睛里，暗红色的纹路似乎比刚才深了几分。

苏眉的通讯器传来杂音，她说了几句什么，被干扰得断断续续。最后一句拼接得很完整：

“……有人在靠近你那边。不是回收站的人。是别的什么。”

林昭收起晶体，退到房间角落的阴影里，把视线从那幅画上移开。就在他背过身的那一瞬间，画中那只眼睛的中央，出现了一点细小的、白色的光。那光只存在了一瞬，便熄灭了。

但他没有看见。

房间外，有什么东西拧了拧门把手，又松开了。

# 第438章 门缝里的眼睛

林昭盯着货舱阴影里那道声音的来源处，手已经摸上了腰间的切割枪。

“别紧张，”那声音沙哑而疲惫，像金属片互相摩擦，“你又带回来一个。”

苏眉的枪口已经抬起，红发在应急灯下泛着冷光：“老猫的核在哪儿？”

沉默。货舱深处的阴影里，一个东西动了一下。林昭眯起眼，终于看清了——那是一具老旧的保洁机器人，型号比他爷爷那辈还老，外壳上满是锈蚀和焊疤，一只光学镜头歪歪斜斜地挂在眼眶里，像一个白内障的老人。

“你们要找那只猫？”保洁机器人的扬声器里传出断断续续的合成音，“他自己走的。”

“他自己走？”林昭压着嗓子，“他是核心，没有船体支架他怎么走？”

“他把自己的核拆出来，装进了我的备用槽。”保洁机器人抬起一只机械臂，腕部翻转，露出里面一个空荡荡的卡槽，“然后他说，‘等她回来，告诉她——门那边，别用眼睛看。’”

林昭的后背一阵发麻。老猫知道他一定会回来。老猫把最后一句话留给了这具破铜烂铁。

“别用眼睛看？”苏眉皱眉，“什么意思？”

保洁机器人的光学镜头忽然转了一下，对准林昭：“他原话是‘门那边的东西，看了就会留下。别用眼睛看，用耳朵听。’”

“看了就会留下……”林昭喃喃重复着这句话，忽然想起之前拿到第二枚晶体时，铜牌上那扇门的轮廓，想起伊甸号整艘船都在转向那个坐标——门缝里透出的星光。

他猛回头，透过货舱侧壁的观察窗，看见前方两万公里处那扇由残骸拼接而成的巨门正缓慢地……张开一条缝。

星光从门缝中倾泻而出，比任何恒星的辉光都要纯净，就像有什么东西在门后睁开了眼。

就在这时，苏眉低咒一声：“操，我的铜牌。”

她怀里那枚铜牌不知何时已经滚了出来，悬浮在半空中——不，不是悬浮。铜牌上的星图在转动，那扇门的轮廓正在被天光填充，星图上第二光点与鹈鹕号航线重合处，正有一道裂隙缓缓裂开。铜牌在发热，金属表面泛出水纹般的波纹，像在回应那扇门。

“你的铜牌在共振。”保洁机器人的声音忽然变得急躁，“快点，你们时间不多了——那扇门开了，就没人能关上了。”

“老猫还说什么了？”林昭蹲下来，直视保洁机器人那只有白内障般的光学镜头。

“他还说……”保洁机器人的声音忽然卡顿，像是内部存储受损，扬声器发出刺耳的电流声，“他说……‘参观者不是在找伊甸号，参观者一直在等一个人。等一个能带来钥匙的人。’”

“钥匙？”林昭猛地攥紧怀中的晶体，“这就是钥匙？”

“两块拼在一起才算。”保洁机器人的镜头转动了一下，似乎在看苏眉。

苏眉掏出自己那块晶体，两块晶体在两人掌间同时发出微光，随即——一股巨大的引力从前方传来，鹈鹕号整个船身猛地震动，警报声骤然尖啸。

林昭踉跄着抓住扶手，抬眼望去：那扇门已经完全张开，门缝后不是空的——是一只眼睛。

一只由星光凝聚成的巨眼，隔着两万公里，正缓缓转动瞳孔，对准了鹈鹕号。

林昭的手心全是冷汗。老猫说“别用眼睛看”，但那只眼睛已经看到了他。

“苏眉！”他吼着，“关了舷窗遮罩！全舰光学传感器断电，切换到声呐和热成像！”

苏眉已经冲向了控制台，片刻后鹈鹕号所有舷窗外侧的合金遮罩“砰”地合拢，驾驶舱里的光学屏幕全部熄灭，只剩下声呐那绿幽幽的回波图像在旋转。

黑暗中，只有声呐的脉冲声沙沙地响——像呼吸。

一道声音忽然从通讯频道里传出来，清澈得像是从一个很远的房间里发出来的：

“你终于到了。”

林昭的手按在切割枪上，指节发白。

那声音不是从门那边传来的。是从他脚下的鹈鹕号的船壳里传来的。

那声音认得他。

# 第509章 银河馆

隔离门内的暖金色光芒像熔化的蜂蜜，缓缓流淌出来，在环带冷灰色的金属地面上拖出一道模糊的光晕。林昭眯起眼睛，那光不刺眼，却让他眼眶发酸——他已经太久没见到“温暖”这个词了。垃圾带的光都是冷的，是恒星的余光、电离辐射的紫、仪表盘的蓝白。

他低头看了一眼手里拼合的铜牌，托在掌心里微微发烫，那两个字——“回来”——像被烙上去的，在暖金色光里微微蠕动。

“老猫，你探测到了什么？”林昭压低声音，向前迈了一步。

[老猫的声音从他耳内植入体传来，带着罕见的谨慎：]

“门后是个球腔。直径大概一百二十米，温度28.5摄氏度，湿度55%——该死，这个环境参数……是标准居住舱的设定。但里面没有任何生命信号，也没有机械运转声。只有一样东西。”

“什么东西？”

[静默了两秒。老猫似乎在进行某种极深的检索，那是一种林昭从未听见过的回音，像是老猫在翻阅自己都遗忘的底层档案。]

“一个名字。门框上方刻着三个字，我不认识这种文字，但我的语言模型给出了唯一匹配——‘银河馆’。符合度99.87%。”

林昭喉头一紧。赵启明尸体无声的口型、门框上的刻字、暖金色的光，三个线索指向同一个地方。他想起父亲生前说过的一句话——那时他七岁，父亲蹲在他面前，用拇指擦掉他脸上的油污，说：“阿昭，银河其实也是座馆子，里头摆的都是没人要的东西。可最贵的，恰恰是没人要的。”

“进去。”林昭说完，率先跨过了门槛。

脚下踩到的触感让他愣了一下。是草。活的、真实的、带着湿气的草。他的靴底碾过去，草叶弹回，细小的水珠溅到他裸露的脚踝上。垃圾带没有草，自从大扩张之后，真正的有机草坪只存在于联邦档案馆的影像资料里，以及富豪的生态穹顶中。

林昭缓缓抬头。

球腔内部是一座被密封了不知多少年的小型庭院。中央有一棵枯树，树冠上悬挂着数百枚铜牌，在无风的空气里纹丝不动，每一枚都在暖金色光下微微泛着暗绿。树根旁摆着一张石桌，桌面上放着两张石凳，一壶茶——壶嘴里还冒着热气。整个场景像一幅被掐断时间的画，只等着两位客人落座。

林昭握紧手中铜牌，走到树下，仰头细看。那些铜牌的形制与他手中这一枚完全一致，只是表面的文字各不相同。他看不太懂，但其中有几枚的纹路莫名让他心里发毛——那个弯弯绕绕的符号，像一只眼睛闭上又睁开一半的弧度。

“……老猫，这些铜牌上有名字吗？”

[老猫的声音变得很轻：]

“有。每一枚下面都垂着一根细线，细线末端系着一根指骨。林昭……这里一共三百一十七枚铜牌。我在最靠近树梢的位置，找到了一个名字。”

“什么名字？”

[老猫停顿了一下，仿佛连它都感到某种巨大的重量：]

“赵启明。”

林昭猛回头，看向门外环带深处——赵启明的尸体还在那里，后脑烧穿，手攥着空无一物的拳头。而这里，树梢上，挂着他的名字和骨殖。

“所以这里是……坟场。”林昭喃喃道。

“不光如此。”一个声音从石桌后面传来。

林昭瞬间拔枪。石桌旁的空气扭动了一下，一个人影从虚空中浮现——穿着和赵启明一模一样的联邦殖民舰船长制服，面容却完全不同。他大约六十岁，光头，左眼戴着一枚金属眼罩，眼罩上刻着细密的符号，和林昭在赵启明后脑空洞里见过的符号一模一样。

他端坐在石凳上，自顾自倒了一杯茶，吹了吹，抬眼看向林昭。

“你是林昭，对吧。”他说，语气平淡得像在叫邻居家的孩子吃饭，“你爹当年也坐在这儿，喝了杯茶，问我一个问题。”

“什么问题？”

“他问我：银河馆里存的，到底是死人的名字，还是活人的故事。”老人抿了一口茶，“我说，都有。你爹听完，把铜牌留给我，就走了。”

“我父亲……来过这儿？”林昭的声音有些发紧。

老人放下茶杯，金属眼罩上折射出暖金色的光芒：“他来过。而且他离开的时候，说了一句话——他说：‘告诉阿昭，来的时候别带枪。带钥匙。’”

林昭低头，看着手里那枚拼合的铜牌。

他想起来了。

父亲纸片上最后一句话——不是他之前读到的那部分——最后还有一行字，被折痕压住，他从来都没有展开看过。而此刻，他脑中突然浮现出那句话的模糊轮廓。

“钥匙也是锁。”

林昭抬起头，看了一眼老人，又看了一眼树上挂满的铜牌。

“那我应该——开门，还是锁门？”

老人没有回答。他伸手，指了指林昭身后，环带深处的方向。那里传来的新的声音——执行者驱逐舰的引擎低吼，已经可以透过金属结构传进这座球腔里了。

【本章完】

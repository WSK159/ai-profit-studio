# 第190章 管道里的灯

管道壁传来一声闷响，像是什么东西在金属外壳上蹭了一下。

林昭的脊背瞬间绷直了，手已经摸上了座椅侧面的霰弹枪枪托。鹈鹕号的驾驶舱里只有仪表盘泛着幽绿的光，老猫的指示灯在控制台角落一闪一闪，像一只眯起的眼睛。

“你听见了。”老猫说。

“听见了。”林昭压低声音，“距离？”

“无法确定。被动声呐捕捉到一次接触，方向——”老猫停顿了半秒，“方向是船尾七点钟方位，贴着管道内壁移动。”

贴着管道内壁移动。这意味着那东西没有推进器喷口的痕迹，没有导航灯，甚至没有热信号。它在用某种方式附着在金属表面上滑行，像一只趴在管壁上的虫子。

林昭盯着舷窗外的黑暗。他们停泊的这条废弃运输管道是战时用来向纵深输送燃料的，内径接近两百米，金属壁厚达三米，足以屏蔽大部分主动扫描。老猫选择这里作为临时藏身处，本来是想躲开伊甸号信标监控——现在看来，这个决定可能太蠢了。

“它能发现我们吗？”林昭问。

“取决于它是什么。”老猫的声音少见的没有讽刺，“刚才那声接触太响，不像主动攻击。更像——在找东西，撞到了。”

“撞到了什么？”

“我检查过了，船壳没有新擦痕。撞的不是我们。”

林昭皱了皱眉，那就只剩一种可能：那东西在管道里摸索，撞到了别的废弃物——一块断裂的支架，或者另一艘同样在这里藏身的破船。鹈鹕号躲在管道凹陷处，外层还铺着老周特制的隔热伪装网，单纯从热信号上确实很难被发现。

但“很难”不等于“不会”。

林昭把霰弹枪搁在膝头，盯着舷窗外，管道内壁泛着一层暗褐色的锈色，每隔几十米就有一组早已熄灭的导航灯。灯光熄灭后的管道像一条通往地底的隧道，尽头是纯粹的、稠密的黑。

又过了大约两分钟，第二声响传来。

这一次更近。近到林昭能分辨出那是金属与金属摩擦产生的尖啸，尖锐而短促，像什么东西在拉伸一条弦。老猫的指示灯剧烈闪了一下：“它换了方向。”

“朝我们来的？”

“不。朝管道深处去的。它在深入。”

林昭的呼吸缓了半拍。管道深处的方向，正对着他们扫描到的那个橙色信号源的方位。那个一直在模仿鹈鹕号频率、又携带伊甸号信标特征的东西，就藏在管道内部的某个节点舱里。而现在，这团贴着管壁滑行的黑影，正朝着同一个方向移动。

“它是被信号引来的，”林昭说，“它在追那个信号，还是那信号一直在引它过来？”

老猫沉默了很长时间，指示灯以极低频率闪烁，像在进行某种复杂运算。终于它开口：“你说反了。”

“什么？”

“不是它在追信号，”老猫的声音非常轻，“我重新分析了刚才两次接触的声纹差异——第一次是撞击，第二次是摩擦。这两次间隔大约一百一十秒。从第一次到第二次，那东西移动的路径是弧形的，在约八百米外绕了一个弯。”

“绕弯怎么了？”

“管道的金属壁内部有残余的强磁场，会导致声学信号发生偏转。我刚才算上了这个偏转量，修正之后——它的轨迹不是朝信号源去的，而是绕着信号源走的。”

林昭愣住。

绕着伊甸号信标频率的信号源走，意味着那东西在刻意避开它。

“它在躲信号。”林昭不自觉地放轻了声音，“那这东西——不是冲信号去的。它在逃。”

话音未落，管道尽头突然亮起一道橙色的光。

那道光黯淡而稳定，像一颗悬浮在黑暗中的火焰珠，从管道深处缓缓亮起，没有闪烁，没有晃动，安静得像某种路标。林昭看到那道光的瞬间，胸口一阵发紧——光线的颜色和鹈鹕号控制台上那个来源不明的指示灯一模一样。

然后他听到了声音。

一种低沉的、像歌声一样的声音，从管道尽头穿过黑暗传来。不是语言，不是机械音，是一种让人后脊发凉的和声，像数千个喉咙在淤泥深处同时哼鸣。

老猫的指示灯猛地熄灭了。

“老猫？”林昭喊了一声。

没有回应。控制台上的橙色指示灯亮了，是那个来源不明的信号——它正在以某种节奏闪烁。

那节奏和管道尽头传来的歌声一模一样。

林昭握着枪，指节发白，管道尽头的橙色光开始向他靠近。

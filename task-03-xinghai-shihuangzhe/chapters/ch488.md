# 第488章 七岁的牙齿

那艘细长的黑色船影悬在舷窗外，像一柄竖起来的刀。

我盯着它看了足有十秒，确认它没有靠近的意思，才把目光挪回苏眉脸上：“你说老周从来没离开过龙骨坟场？”

苏眉靠在驾驶座边沿，红发被走廊吹来的风掀起一角。她没立刻回答，而是转头看了一眼走廊尽头那道已经合拢的门缝，然后压低声音：“我半个月前在公会档案室见过他的出航登记，标记是‘离港—返回’，往返时间都对得上。但三天前我在龙骨坟场西侧的旧船坞里，亲眼看见他的船就停在那，船壳上积了灰。”

“积灰？”

“对。龙骨坟场那地方你是知道的，盐蚀风沙重，三天就能把一块抛光钢板啃出锈花。他那艘‘黑蜉蝣’的船壳上落的灰，得有半指厚。”

半指厚的灰。换句话说，老周至少十天没动过那艘船。

可我明明记得——三天前，我还在鹈鹕号的通讯频道里听到过老周的声音，他在骂管道接口的报价越来越黑心，嗓门大得像要把扬声器震碎。

我伸手关掉舷窗的遮光板，那艘黑色船影被挡在外面，像一封没有落款的信。

“你是说，三天前跟我通话说老周还活着的人，不是老周。”

苏眉点头，然后从兜里掏出一样东西，递到我面前。那是一颗牙。

准确地说，是一颗乳牙——白瓷色的牙冠带着一道浅褐色的裂痕，牙根处穿了一根细银链，像被人当吊坠贴身戴了很多年。

我接过来的时候手指僵了一下。那颗牙的牙冠上有一小块凹陷，是我七岁那年从三级台阶上摔下来磕掉的缺口。我母亲把那颗牙收进了一个铁盒，说“等昭昭长大了还给你”。后来铁盒连同那套旧房子一起被我弄丢了——或者说，我以为我弄丢了。

“哪来的？”

“老周那艘黑蜉蝣的驾驶台上，用螺丝钉压着，就放在操作面板正中央。我抄完坐标走人的时候看见的。”

苏眉说着，把银链子晃了晃：“链子背面刻了一个字，你自己看。”

我翻过银坠，在指腹下摸到一个浅浅的刻痕——一个“一”字。跟老赵托付给老周、老周再托付给我的那四枚螺丝钉上的“一”字，一模一样。

“老周在驾驶台上留了这颗牙，又让公会的接线员在三天前‘替他’跟我通了个话？”我盯着苏眉的眼睛，“这像不像——他早就知道自己会出事，提前布了个局？”

苏眉没回答，而是朝走廊尽头努了努嘴：“那扇门，刚才你看见的东西，还有老猫格式化前给你留的话——你记不记得他说什么来着？”

我闭上眼。老猫的面板边缘那些幽蓝的、断断续续的文字像烙铁一样印在我视网膜上：

“钉子在门上。你在门里。别再往前走。”

钉子在门上。这颗牙算不算一枚钉子？

“你以前说过，你母亲留下的那个铁盒，里面装着螺丝钉、照片、和你七岁时掉的牙。”苏眉的声音放低了，“你现在手里有了四枚正版螺丝钉，加上老猫那颗一共五——不，算上这颗牙，是六个物件了。”

六件。六枚“一”字记号。

我忽然觉得右手的银纹有些发胀，低头一看，第五道银纹比刚才又向前蔓延了一小截，爬过了腕骨，钻进手掌心，在灯光下泛着磨砂的微光。

“你在看什么？”苏眉问。

“没事。”我攥拳，把银纹藏在掌心里。

“那我们还等什么？”苏眉从腰后抽出一把短柄扳手，“那颗牙既然从驾驶台上拿到手的，说明老周想让你找到它。去找他吧。”

我站在走廊里没动。走廊尽头那扇门的门缝在记忆中合拢了又打开，那只银灰色的巨眼在瞳孔深处映着一枚螺丝钉的倒影。钉子在门上，你在门里。

老周没离开过龙骨坟场。那三天前在鹈鹕号通讯里骂管道报价、刚才泊在舷窗外的黑蜉蝣，到底是什么东西在“代替”他？

我转头看了一眼躺在墙角的老猫备用处理器，那颗被纸条包裹的处理器忽然亮起一丝蓝光，像是感应到了什么。

“苏眉，”我说，“你刚才来的时候，有没有经过龙骨坟场东侧第7号船坞？”

苏眉的动作顿了顿：“7号船坞？没有。我泊在西区。”

“那你来的时候，有没有看见一艘船跟在你后面？”

她的脸色变了。

苏眉回过头，隔着鹈鹕号的舷窗望向龙骨坟场深处——那艘细长的黑色船影已经不在原来的位置了。它移动了至少两百米，此刻正静静地停靠在7号船坞的入口，船头对着我们，像一个人远远地站着，等待。

我没再说话。

手里的那颗乳牙在掌心里微微发烫。

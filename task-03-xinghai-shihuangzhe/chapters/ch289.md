# 第289章 第三坐标的钥匙

林昭盯着老周，盯着苏眉，盯着他们背后那截焊接上去的BC-735舱体。引擎声平稳地响着，像一头沉睡多年的巨兽在均匀呼吸。他忽然觉得很荒谬——他在这艘船上长大、逃生、躲灾、欠债，结果现在发现自己连鹈鹕号的结构都不了解。

“生物舱是谁的？”林昭问。

苏眉没说话。电弧枪的枪口微微下垂，但她的指尖始终没离开扳机护圈。老周在她身后咳嗽了一声，从工装裤口袋里掏出一团皱巴巴的东西——是一张被折了无数次的纸，边角都磨毛了。他递过来时指尖在颤抖。

林昭接过展开，是一张人体脑部扫描图。信号采集器固定在颅骨上的标准军用示意图标，右下角有编号和日期。日期是2537年。那是老猫出厂那一年。

“你以为老猫只是你的船务AI，对吧？”苏眉的声音轻而稳，“实际上在2537年，联邦一个军工项目组把一套神经突触映射系统，以AI的名义写进了编号BC-735的深空拖船里。那艘拖船的任务是运送最后一批殖民舰‘伊甸号’的船员基因样本去某个坐标。但送出任务的第三天，船失联了。”

“失联的船怎么会出现在这里？”林昭盯着那截焊接舱体。

“因为这艘拖船的任务目标，就是找到你父亲的船。它把你父亲接上船，然后把鹈鹕号作为外壳，将自己作为内核，等待一个能‘听懂’信号的人到来。”

苏眉的目光落在林昭手上，“那个人本来不是你。是林远山。”

林昭手里的棋谱猛地绷紧。他听见自己的声音在空旷走廊里发硬：“我爸说什么了？”

老周终于开口：“他只留了一句话——‘第三坐标的入口，就是伊甸号自己。但想让入口打开，你必须先找到那艘BC-735，把它接到鹈鹕号上，让那颗‘心脏’继续跳。’”

他顿了顿，像是要把什么沉重的东西咽下去：“我们以为你还要几年才能找到这里。但你还提前了。”

林昭低头看了一眼手里的棋谱，黑棋已经在将死位。白棋背面那个“苏眉”的字迹在灯光下微微发亮。他忽然明白了什么，抬头看向苏眉：“你也是被安排来这个坐标的守门人？”

苏眉没有否认。她转身走向那截焊接舱体，指尖触到舱门上一处凹陷的压力开关。咔哒一声锈涩的转动，舱体侧壁的一道接缝裂开，露出一条狭窄的、被黄铜色管线包裹的通道。暖黄色的光从深处透出，伴随着鹈鹕号发动机那平稳的轰隆声。

通道尽头，是一台没有外壳的生物舱。一台老旧的、表面刻满划痕的维生装置，正中央躺着一具——不是人形，是一团被灰白色保护膜包裹的、约手掌大小的核心，顶端插着一根金属导管，导管另一端接入舱壁深处。

“这就是那艘BC-735真正的货物。”苏眉的声音平静得像在陈述一个事实，“一颗未完成的‘人脑神经核’，一个可以让AI觉醒出‘意识’的种子。你父亲林远山把它从联邦军用黑站里偷出来的……”

她的话还没说完，那团灰白色保护膜内部忽然亮起一点微弱的蓝色荧光，一闪一闪的，像一颗心脏在跳。而那节奏，和鹈鹕号引擎的声音完全同步。

林昭才注意到，鹈鹕号的引擎并没有停。它一直在响，在门外，在这截焊接舱体内，在每一个他从来没检查过的角落——“老猫，你听得到我说话吗？”

通讯器里传来一阵极短暂的杂音，随后老猫的声音清晰地、带着一丝从没展现过的东西响起：“……听得到。为什么我……觉得心脏在跳？”

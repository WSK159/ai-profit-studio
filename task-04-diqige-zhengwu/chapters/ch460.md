# 第460章 三根竹片

煤油灯的火苗跳了一下，陆香梅的手停在半空。三根竹片并排摆在木桌上，长短一致，粗细相同，像是从同一根竹子上劈下来的。

顾言秋盯着那三根竹片，嘴唇动了动，却没出声。秦朗注意到她的手指在微微发抖，指节泛白，像是在竭力克制什么。

“这三根竹片，”陆香梅的声音沙哑而平缓，“一根是你外公，一根是你父亲，一根是你。”

顾言秋抬起头：“妈——”

“你听我说完。”陆香梅打断她，目光却落在那三根竹片上，像是透过它们在看很远的地方，“你外公当年在渡口撑船，七月半那天晚上，他收了三个人的钱，把船撑过了河。那三个人上了岸，他就发现船底多了一个洞。不是漏水的洞，是有人用钉子钉出来的，钉子还在船板上插着。”

秦朗蹲下身，平视着陆香梅的眼睛：“什么样的钉子？”

“棺材钉。”

陆香梅说出这三个字的时候，煤油灯的火苗猛地暗了一下，像是被什么东西吹了一口气。木屋角落里传来木头胀缩的“嘎吱”声，秦朗后颈的汗毛竖了起来。

“你外公把棺材钉拔出来，丢进河里。第二天，他不见了。”陆香梅继续说，“家里人去渡口找，只在船板上找到一根竹片，就是这种。”

她指了指桌上的竹片：“你外公的那根。”

顾言秋的呼吸变得急促。秦朗看见她攥紧了拳头，指甲陷进掌心。

“后来你父亲也拿过一根，”陆香梅的视线移到第二根竹片上，“他是在你出生那年的七月半拿到的。那天晚上，有人在他枕头底下放了一根竹片，他以为是你外婆放的收惊用的，没在意。三天后，他在渡口看见一个人站在水面上，穿着旧式长衫，背对着他。”

顾言秋猛地站起来，木椅带翻了却没扶：“那根竹片呢？”

“他藏起来了。”陆香梅抬起眼皮，看着女儿，“藏在老宅的房梁上，用油纸包着，上面画了七道符。”

秦朗心里一动。老宅房梁——他在勘察时检查过老宅的每个角落，唯独没有专门查看房梁。他想起老宅主屋那根粗大的正梁，上面确实有陈年积灰的痕迹，但当时总有一种“那里不该看”的感觉，像是有什么在阻止他走过去。

“你现在回去还能找到。”陆香梅说，“但你父亲在竹片上留了一句话。”

“什么话？”秦朗问。

陆香梅没有直接回答，而是拿起第三根竹片，在指尖转了转：“这根是给言秋的。昨天夜里，有人放在我门口的。”

顾言秋脸上的血色一下子褪尽了。她接过竹片，翻过背面，上面的刻痕已经干涸发黑，像是很久之前就刻上去的：

“渡河人收名，不收尸。”

五个字，刻痕很深，发力重，像是写字的人带着极大的恨意或恐惧。秦朗凑近看了看，笔迹有一股说不出的熟悉感，和他父亲秦守信的字迹有七八分相似。

“这是你爸写的？”秦朗问。

陆香梅摇摇头，又点点头，最后叹了口气：“我认不出。但这字，跟你父亲写给你大伯的那封信上的字，是同一个人的。”

秦朗的脊背僵住了。他父亲那封信——那封死在秦守信口袋里、被水泡烂的信，信里写着“系死结”和“缝”的句子。他一直在找写信的人是谁。

“那封信是我写的。”

陆香梅的声音很轻，轻到秦朗差点没听清。他猛地抬头：“那封信是你写的？写给我父亲的信？”

“不是写给你父亲的。”陆香梅说，“是写给你父亲的哥哥。秦守信。”

秦朗脑子里嗡了一声。他的父亲叫秦守信，大伯叫秦守望。那封信，是写给秦守望的，不是给秦守信。

“信里写的‘系死结’、‘缝’，是渡河避祸的规矩。”陆香梅的声音像是从很远的地方传来，“系死结，是把自己的影子和一根黑线系在一起，装成已经死了，让渡河人以为不收死人。缝——是把名字从纸上缝起来，掩掉，装作无名无姓。”

“你让我父亲怎么做？”

“我让他系死结。因为那时候，渡河人已经把他的名字写在册子上了。”

秦朗攥紧了拳头，指甲陷进掌心的肉里。他父亲秦守信，农民，一辈子没离开过雾津县，怎么会被渡河人盯上？

“因为二十五年前，你父亲在大雾里看见了一个人。”陆香梅说，“那个人穿着一身旧式制服，站在河中央，手里捧着一本册子。你父亲听见他念了一个名字，那个名字他听清了一半——”

陆香梅停下来，看着竹片上的字，像是怕说出来会招来什么。

“什么名字？”顾言秋替秦朗问了出来。

陆香梅张了张嘴，木屋外突然传来一声巨响。是暗渠方向的铁闸门，被人从外面砸响了。三声，急促而重，间隔极短，带着一种不容置疑的命令意味。

陆香梅的脸色彻底变了。

“他来了。”

她一把抓过桌上的三根竹片，塞进顾言秋手里：“走。带他走。从后面那条水道走，别回头。”

秦朗已经站起来，手按在腰间枪套上，盯着木屋那扇歪斜的木门。外面有光——不是煤油灯的那种暖黄，而是一种冷白色的、像是水面上反射出来月光一般的光，透过门缝渗进来。

冷光里，一个影子立在门口，缓缓抬起手，重重地敲了一下——

咚。

整间木屋都颤了一下，煤油灯应声熄灭。

# 第242章 七尊像

民国制服的男人站在走廊尽头，灯光从他身后打来，影子拉得极长，一直延伸到秦朗脚边。

那人的脸，和秦朗一模一样。

秦朗没有动，手电筒的光直直打在那人身上。制服是深灰色的中山装，领口扣得一丝不苟，胸前别着一枚圆形徽章，看不清图案。他站在那儿，像一尊被时间遗忘的塑像。

“你爸等了二十五年。”那人又说了一遍，声音像是从深井里捞上来的。

秦朗攥紧了手电筒：“你是谁。”

那人没有回答，而是缓缓抬起右手，朝走廊右侧的第七尊空置石像指了指。秦朗顺着他的手看过去——石像的基座上，不知何时多了一行字，刚才分明没有的：

钉子钉影，影钉河。河渡人，人渡河。

秦朗心里默念了一遍，像是某种口诀，又像是咒语。

“这是……”他刚开口，六尊石像的眼睛忽然同时亮起。那是种说不清的光，不是火光也不是灯光，更接近于月光落在死人脸上的那种惨白。石像们的眼睛齐刷刷转向走廊尽头，转向那个穿民国制服的人。

那人忽然笑了。

他笑的时候，秦朗的脸也跟着动了一下。秦朗感到自己的嘴角不受控制地抽搐了一下，像是被什么力量牵引着。他猛地咬住牙，伸手按住自己的下颌，心脏在胸腔里狂跳。

“你不该下来的。”制服男人说，声音忽然变了，不再是跟秦朗一样的语调，而是带上了某种闷沉的回响，像从水底传来的，“你下来了，就再也回不去了。”

话音刚落，走廊两侧的石像同时张开了嘴。

石像嘴里吐出白雾，那雾极冷，带着一股河水腥气。七条白雾汇成一股，像蛇一样贴着地面朝秦朗游来，在距离他一步远的地方，凝成一个人形。

那是一个女人的轮廓。

看不清脸，但秦朗认得那个身形。他浑身一僵：“周小满？”

白雾凝成的女人微微点了点头，然后伸出一只手，指向秦朗脚下的地面。秦朗低头，看到自己脚下不知何时出现了一个圈，圈内是用石灰画的一道符纹，像是某种封印。

老周的声音从身后传来，像是隔了很远：“秦朗！秦朗你听到没有！那边台阶有人在往上爬！”

秦朗猛地回头，还魂门的缝隙里透进一道光，还隐约传来一阵挨挨挤挤的脚步声和衣物摩擦的细响。那不是老周一个人的动静，像是有很多人沿着石阶从水下往上走。

“别回头！”制服男人的声音骤然严厉，“别让他们看见你的脸！”

秦朗却已经回了头。

门缝里，他看到一只手，扒在了门框上，那手穿着深蓝色棉布袖子，五指苍白。接着是第二只，第三只，第四只——密密麻麻的手扒在门框各处，正把还魂门往两边推开。

秦朗的呼吸猛地紧起来。那些手的主人没有头。

门被推开一条缝，水声哗啦啦灌进来，几具穿着民国衣袍的无头身子一个接一个站在门口，齐齐地面向秦朗的方向，像是等了很久很久。

“钉子。”顾言秋的声音忽然从身后响起，清晰得不像幻觉，“秦朗，用棺材钉，钉住第七尊石像的影子！”

秦朗猛地清醒过来。他捏紧腰间的布袋，那枚棺材钉还稳稳地躺在他身上。他没有犹豫，转身朝第七尊空置的石像冲去。那尊石像没有头，底座上刻着的字正在缓缓变化，从“渡河人”变成了七个字——

“第七件证物，到你。”

秦朗一脚踩在石像前，拔出棺材钉，对准石像脚下的影子，猛地钉了下去。

钉尖落地的刹那，整个走廊像是被人按住了咽喉，所有声音都停了。那些无头的身体、门缝里的水声、石像眼中的白光，全部定在原地。秦朗的手还按在棺材钉上，钉身发出一阵细密颤动。

他听见制服男人在他耳边说了一句极轻的话：

“你钉的，是你自己的影子，从现在起，你替它活。”

然后走廊尽头的灯灭了。黑暗里只剩下棺材钉的钉帽在发亮，上面那行字已经变了——不再是“渡河人账本，副本一”，而是：

“秦朗，民国三十一年生。”

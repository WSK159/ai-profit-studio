# 第327章 黑伞下的红绳

出租车停在档案馆大门外，引擎没熄，车窗降了一半。驾驶座上坐着一个戴白手套的司机，脸朝着前方，像是等着什么人。

秦朗没动，就站在二楼窗口看着那辆车。顾言秋走到他身边，顺着他的视线望过去，也看见了车顶那柄黑伞和红绳，脸色变了变：“这是……铜钱案那根绳结？”

“同一式样。三股麻花拧，收口打的是灵官结，不是活扣。”秦朗声音很低。他没看那辆车太久，转而拉着顾言秋从侧门绕出去，沿着档案馆后院的小巷绕了半圈，从对街的一棵梧桐树后面探出半个身子，去看那辆出租车的车牌。

“外省车，牌照是假的。”秦朗扫了一眼车牌边缘，漆面反光不正，是套牌，“在雾津县跑出租的人不可能用这种牌照。这车是专门开进来的。”

“从华丰跟到这儿来了。”顾言秋说，“你怎么知道它昨夜也停在厂外？”

“我出厂门的时候，地上一道轮胎印，煤渣被压成两指宽的路子。刚才我看到这车轱辘里的纹路，跟那道胎纹对得上。”秦朗把那根铁条从内袋里抽出来，铁条上还沾着仓库里的灰泥，钩形的尖端在暮色里闪着暗光，“而且，这车顶的伞——是反着撑的。”

顾言秋一愣，仔细看过去。那柄黑伞的伞骨是朝上拱的，雨水顺着伞面向下，把伞柄和车顶之间捆扎的红绳压得很紧。通常人们拿伞挡雨，伞面朝上；伞骨朝上，是停灵时才用的遮法。

“遮魂伞。”顾言秋低声说，“南方渡口的老规矩，人死后三天，床头要撑一把骨朝天的黑伞，防止魂魄被路过的野鬼顺手牵走。这车顶撑一把翻面伞，是告诉行路的什么东西——车里的人不怕被带走。”

“车里的人。”秦朗重复了一遍这四个字。

他绕到那辆车侧后方，把铁条握在手心探过街面，贴着墙根朝车尾靠近。走到距离不到五米的位置时，车窗忽然降下来，那个白手套司机转头看向他，递出一张名片大小的黄纸，声音平稳得像白开水：“先生，您的东西掉了。”

秦朗没接。他低头，看见自己脚下的地面上不知何时多了一张折成四叠的纸，纸边泛黄，上面压着一枚沉红色的印泥，墨迹未干。

他捡起来，展开。纸上只有一行字：

“七月半之前，把棺材钉放回原位。否则‘渡河人’今晚就走雾津渡。”

秦朗的目光从纸上移开，再抬头时，那辆出租车已经开走了，引擎声细碎地沿着街道远去，车顶的伞还绑着，在暮色里晃了两下。

“棺材钉？”顾言秋追出来，看到那张纸，语气骤然发紧，“你手里有棺材钉？”

秦朗没回答。他把铁条从内袋里抽出来，在路灯下对着那弯钩形的尖端看了又看。老门卫说这是刘玉的锻钉模子，叫“钩魂”——但此刻他忽然意识到，这根铁条一头是钩，另一头的粗细和长度，恰好是一枚棺材钉的轮廓。

那根铁条本身，就是第七件证物。

“刘玉把它藏在墙砖凹槽里，不是为了收起来。”秦朗缓缓将铁条收回内袋，“是在等有人发现它。他死后三个月宋建国就离开，没人知道他拿走了什么，又留下了什么。”

他把那张黄纸折好，放进上衣兜里，与那张钩笔铁条贴着心脏的位置，彼此叠靠。下一刻，他的手机响了——是老周的号码。

电话接通，对面传来老周粗沉的嗓音：“秦朗？你爸那口衣冠冢的棺材板，我今天找出来复检，你猜怎么着——棺材板内侧的手印，是对称的。左手和右手，每只手少了三根指头。”

“三根？”秦朗皱眉。

“对。只剩拇指、食指和小指。”老周的呼吸重了，“正常人办不到这个形状的手掌。那手印是按在棺材里面的——也就是说，有人被钉进棺材里以后，他还在里面活着，用手推的时候留下的。”

秦朗握着电话，另一只手下意识捏紧了内袋里那根铁条的钩尖。

老周继续说：“更奇怪的是，棺材板内侧的漆面下，有人用指甲刻了一行字，我扫了一下，是四个字——”他停了两秒，声音发沉：

“‘它在雾津渡。’”

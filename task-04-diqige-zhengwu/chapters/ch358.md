# 第358章 渡河忌

秦朗全身的血像是被那三个字冻住了。

他父亲的声音从自己身体里响过一遍便消散了，像一声瓮中回响，余韵沉入五脏六腑。白皮灯笼的光晃了晃，灰衫人的笔尖在距他眉心三寸处停住，笔尖悬着的一滴墨汁忽然坠落，在半空中化开，成了一只指甲盖大的黑虫。

黑虫扑向灯笼。

顾言秋的铜镜比它更快，她手腕一抖，镜面翻转，弧光闪过，黑虫在灯笼前寸许处爆成一团墨雾。雾散后，灯笼上的“朗”字缺了半笔。灰衫人发出一阵低哑的声响——那声音从砂石地四面八方涌来，密密麻麻，像是千百片嘴唇在同时出气。它低下头，笔尖重新落到青石板上，写了一个字，然后两个、三个……写得不快，却每一笔都用足了力。

秦朗看清它写的第一字：秦柏舟。

“它把你爹的名字也写了。”顾言秋声音发紧，“写全了我爹的名字、你爹的名字、周秀兰、陈守信，还有后面三个——它一共写了七个名字。第七个是——”

她顿住了。第七个名字只写了半笔，笔尖悬在石面上不断发抖，像是有无形的手攥住了那支毛笔。灰衫人压低了身形，筋膜下青灰色的血管骤然暴起，像老树枝节盘错。它试图落完最后一笔，笔尖刚触到石面，白灯笼里的火苗噗地爆裂，溅出三点火星，将它的袖口烧出三个窟窿。

那只笔终于被弹飞，落在秦朗脚边。秦朗低头，看见笔杆上刻着两个字：渡船。

他浑身一震。九年前父亲失踪那天，河边上警队搜了整整三天，最后从泥里挖出半截桨柄，还有一支毛笔。那年他刚进刑警队，亲眼看见物证袋里封纸写的登记号——雾公无证字第001号。那支笔的笔杆上，也有“渡船”二字。

物证后来被定性为“无关物品，不予立案”，九年来锁在局物证仓库最角落的铁皮柜里。他一直以为那只是父亲随身带的一件旧物。

如今这支笔，正躺在他脚边的河底砂石地上。

秦朗弯腰捡起。笔轻得出奇，近乎没有分量，他握住笔杆的一瞬间，指腹传来一阵冰凉——像握着一截从冰河里捞出来的枯枝。灰衫人在灯笼下缓缓站直，没有脸的筋膜上，一道裂隙从中间裂开，像一张嘴。它冲着秦朗说了一句话，声音不再是蚂蚁爬地的声响，而是人声，一个苍老女人的声音：

“那支笔，渡人。你握住了，你就要替它记账。”

秦朗没松手。他抬起笔，笔尖对准灰衫人：

“账本呢？”

灰衫人不动。灯笼的火苗跳了一下，照亮了它脚下的砂石地——秦朗这才看见，那地面根本不是什么砂石，而是一层铺满碎纸的泥地，泡过水的纸片层层叠叠，纸上全是写了一半的名字。秦柏舟，秦朗，中间夹着许多他认不出的名字，有些被水泡得洇开了字迹，像一朵朵墨花。

顾言秋蹲下去，拈起一片碎纸，纸上的墨迹在水里泡了不知多久，却仍然清晰。她读了一遍，脸色骤然变了。

“秦朗，”她站起来，把纸片递到他眼前，“这是你爹的字。他写的是——‘勿赎’。”

秦朗攥着笔杆的手收紧。灰衫人的身体开始向灯笼倾斜，像一个正在被光吸走的影子，它每靠近灯笼一分，身上的青灰血管就淡一分，最后只剩一团灰蒙蒙的轮廓。灯笼里的火苗又闪了一下，青白色的光转回暖黄，照亮了灯笼另一面。

那一面上，多了一行字，还带着墨迹湿痕：

“第七个名字，记在影上，不算数。”

灰衫人彻底没入灯笼。砂石地上的碎纸发出窸窣的响动，像是无数纸张正在卷边，顾言秋扫视一圈，看见那些纸片上的字迹都在褪。不是被水泡褪的，更像是被人用橡皮一点一点擦掉，从边缘向中心——只有她手里那片写有“勿赎”二字的纸片还好好的，墨色在灯光下泛着光。

秦朗低头，看向自己的影子。那枚钉孔正从脚跟向上蔓延，灰白纹路已经爬到小腿弯。他忽然明白了那句话的意思。第七个名字记在影上，不算数，既然不算数，那么，影子里的那枚钉，也就没有真正钉住他。他抬起头，声音平静：

“渡口在哪儿？”

顾言秋没有回答。她盯着铜镜，镜面又浮出三个字，这次她看清楚了：“灯下七步。”

她数了七步，走到灯笼正下方，低头，看见地面的碎纸层下露出一道木板边缘，上面钉着七枚钉子。没有一枚是棺材钉，全是普通铁钉，锈迹斑斑。秦朗走过来，蹲下去，伸手碰了碰那木板——冰凉，表面刻着三个字：

雾津渡。

他刚念出声，灯笼里的火苗猛地蹿高三寸，整片砂石地发出嗡的一声响，像是水下有什么巨大的东西擦着河底碾过。顾言秋猛地抓住他胳膊：“有人在推渡船。”

船声从头顶传来，隔着一层河水和石顶，闷闷的，像一个巨人踩着河床缓慢行走，一步，两步。秦朗攥紧那支渡船笔，笔杆上的凉意一直渗进骨头里。他抬头看那盏灯笼，笼面写着他名字的字迹正在一点点变淡，像被水冲掉的墨痕。

他爹的声音又在耳畔响起来——这一次，清晰得多：“别赎。名字记在影上，影子走不回来，但人还能走。”

秦朗握紧笔杆，抬脚踩上木板上的第一枚铁钉。咯吱一声，木板缓缓沉下去，露出黑洞洞的入口，底下透出一股干燥的、发霉的纸张气味，像一间封存了太久的档案室。

顾言秋的声音从背后传来，极轻：

“底下，有灯吗？”

# 第84章 锁链尽头的名字

棺材钉悬在秦朗影子上方三寸，铁锈味混着河水腥气钻进鼻腔。他盯着那枚锈得几乎看不出原色的铁钉，喉结滚动了一下，没有伸手。

顾言秋的声音从身后传来，带着一种奇怪的空洞：“秦朗，你看到锁链上的名字了吗？”

他没回答。他当然看到了。七个失踪者的名字，朱秀兰、钱克己、孙桂英、赵明礼、刘福生、陈阿娣，以及他自己——秦朗。这些字不是刻上去的，更像是从铁锈中自然长出来的，每一笔都带着某种不可名状的生长感。

船身猛然一沉，秦朗抓住船舷稳住身形。黑铁锁在震动中发出一声低沉的嗡鸣，仿佛有什么东西在水下被扯动了。那根连接锁链的铁链从船底延伸出去，消失在浑黄的水色深处，隐约可以看到它绷直如弓弦，似乎随时会断裂。

“铁链在松。”顾言秋蹲在船舷边，手指探入水面，指尖微微发颤，“秦朗，渡河人不在这里了。”

秦朗猛然回头。方才还站在船尾的渡河人，连同那顶民国式样的旧毡帽，已经消失得无影无踪。船尾的雾气像是被什么东西撕开又合拢，连一丝痕迹也没留下。

“他走了？”秦朗皱眉。

“不，不是走。”顾言秋站起来，湿漉漉的手指在晨光中泛着青白，“是被拖下去了。刚才那声响，是铁链绷断的声音。”

话音未落，船底的木头传来一阵密集的敲击声，像有无数指节从水底叩击船板。秦朗下意识按住腰间，这才想起配枪早就浸了水，怕是废了。他握紧拳头盯着脚下的船板，敲击声持续了约莫十息的工夫，骤然停止。

雾气中传来水声，像是有什么巨大的东西在缓慢移动。

秦朗没有犹豫，弯下腰将水中的棺材钉捞起。铁钉入手冰凉，没有锈蚀的粘腻感，反而像一块被反复打磨过的骨器。顾言秋张嘴想说什么，却被秦朗一个眼神拦住。

他翻过棺材钉的侧面，细微的锈迹下，隐约有一行字：“庚午年九月初一，亡人秦明烛。”

秦朗的手指僵住了。

“秦朗——”顾言秋压低声音，“你的父亲，是‘己未年’还是‘庚午年’？”

秦朗没有回答。他记得那本户籍册上，父亲的名字后面写的是“庚午年九月”。而那一年，正是二十五年前父亲失踪的那年。也就是说，这枚棺材钉上刻的，是父亲“死亡”的时间。

更让他心头一紧的是，这根钉子，从来就不是用来钉棺材的。

它是用来钉“影子”的。

“水下去了。”顾言秋忽然说。

秦朗抬头，四周的雾气正在以肉眼可见的速度消散，露出枯水期的河岸。他们所在的沉船，不知何时已经搁浅在了河滩上。船身倾斜，甲板上的积水正在往更低处流淌。

这艘船，竟然在不到一炷香的时间里，从河心漂到了岸边。

秦朗跳下船，靴子陷进淤泥。他回头看了一眼已经倾塌大半的船体，那根铁链从船舷下方垂出，断口处的铁锈呈现出新鲜的亮色，像刚被什么东西生生扯断的。

“断口是新的。”顾言秋也跟了上来，她裹了裹浸了水的外套，嗓音发涩，“秦朗，渡河人一直被那根锁链困在水底。现在链子断了……”

“他要出来了。”秦朗接上她没说完的话。

雾气彻底散尽。晨光落在河滩上，映出一道孤零零的影子。秦朗低头看了一眼自己脚下，那道影子比平时深了不少，边缘模糊，像是有什么东西正在试图从阴影中浮起来。

他没有告诉顾言秋。那枚棺材钉，此刻正钉在他的影子脚踝处。

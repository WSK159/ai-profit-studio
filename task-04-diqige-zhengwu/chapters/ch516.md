# 第516章 红线引路

门板合拢的声响还在走廊里回荡，秦朗手里的双头钥匙却已凉得像握着一块冰。他低头看了一眼，齿纹朝右的那一头——顾言秋递来的第三枚——竟在缓缓褪色，铜绿从齿根向柄蔓延，像是被什么吸去了生机。

“钥匙在‘用完’。”顾言秋声音很轻，却带着一种近乎笃定的平静，“我爸当年说过一句话——‘锁认人，钥匙不认人，但钥匙会死。’我以为是戏文里的词。”

秦朗把钥匙揣进兜里，指尖触到一个更凉的东西——那根红线。门板合拢时，他下意识攥住了线头，此刻红线绷得笔直，浸入门缝的那一端似乎仍在往里拽。他试着松手，红线纹丝不动，像焊死在门板上。

“牵着我。”他说。

顾言秋把手递过去，指尖冰凉，却稳。秦朗握住，另一只手顺着红线摸索到门缝边缘——那里本该是紧闭的，可他的指尖探进去，竟触到一片潮湿的空隙。门板看着合拢，实则留着一条看不见的缝，只有握着红线的人才能摸到。

他回头看了一眼走廊尽头。顶灯明灭，杂物间门口那张蛛网仍在，蜘蛛却已不见了。整条走廊安静得像被抽走了声音。

“走。”

他侧身挤入门缝，黑水没过脚踝，凉意像针一样顺着裤管往上爬。顾言秋跟着进来，身后门板无声合拢，彻底封住来路。放眼看，黑水依旧浅踝，四根铁链吊着的棺材停在原处，民国长衫的衣角仍垂在水面上方三寸，纹丝不动。

但水面不同了。倒影还在——只是这一次，秦朗看清了，那倒影不是他和顾言秋的，而是棺材里那个长衫身影的。它立在水中，帽檐压得很低，脸的位置一片混沌，脚边却漂浮着一本翻开的册子，封皮上的“渡”字被水泡得发胀，红漆剥落了大半。

红线从他手中松脱，入水后竟不沉，像蛇一样贴着水面游向棺材，在离棺材半尺处停住，绕成一个圈，圈住那块蓝布册封皮。

“它在引路。”秦朗盯着水面上漂浮的册子，“不是给我们看棺材，是给我们看册子。”

他蹲下，指尖探入黑水。水温比进来时凉了许多，像井底的水。他触到册封皮的一刹，那本蓝布册竟自行翻开，纸页哗啦啦地响，直到某一页停下。

那一页上，原本写着“秦朗，男，生于1991年7月15日子时，卒于——”的空白处，墨迹正在重新凝聚，一笔一划地渗出一行新字：

“卒于——雾津渡第七闸，棺钉钉影之日。”

顾言秋倒吸一口凉气，退后半步，脚下的水却纹丝不动。她低头，看见自己的倒影正盯着她——倒影的嘴角，勾着一丝极淡的笑意。

“你的名字呢？”秦朗没抬头，问。

顾言秋一怔：“什么？”

“册子刚才自动补了一行我的死期。”秦朗声音平静，“看看你的——页面上有没有你的名字。”他伸手翻到册子下一角，那里原本只写着“顾言秋”三个字，墨迹未干，现在却缀着一行小字，笔迹工整，像档案室的登记簿：

“顾言秋，女，生于1996年3月十七日寅时，卒于——同上。”

“同上。”顾言秋念出这两个字，声音竟没有抖，“同一个死法，同一个日子。”

秦朗终于抬头看她。黑水倒映里的长衫身影帽檐微微一抬，露出一小片苍白的下颌，嘴角挂着同样那丝笑意——和顾言秋倒影的笑容，一模一样。

“它不是让我们逃。”秦朗站起来，反手握紧了双头钥匙，“它是在告诉我们——名单已经写满了。”

话落，棺材内传来一声轻响，像有什么东西从棺材底掉进水里。

红线猛地绷直，向棺材另一侧拖去——那边黑水深处，隐约浮着一根铁钉的轮廓，锈迹斑斑，钉尖朝上，在昏暗的光线里泛着冷光。

棺材钉。

秦朗盯着那枚铁钉，忽然明白了什么。他缓缓蹲下，把双头钥匙浸入水中，齿纹朝右那一头的锈色，正在水中一路蔓延，污染着铁钉周围的每一寸水面。而齿纹朝左那一头，依旧铜光锃亮，像新铸的。

“一头的钥匙，只能开一扇门。”他低声说，“另一头——是留给我自己的。”

顾言秋猛地回头看他，嘴唇翕动：“你的意思是——”

“渡河人不是用棺材收人。”秦朗把钥匙从水里抽出，一束冷汗顺着额头滑落，“它用棺材钉，把影子钉在纸上。钉住了影子，名字才真正算数。而这枚棺材钉——它就是第七件证物。”

他话音未落，棺材内又传来一声叩击，比之前任何一次都沉。

这章留钩子：
1. 秦朗死期被写在册上，“棺钉钉影之日”。
2. 顾言秋的“同上”暗示两人同局。
3. 棺材钉浮现——第七件证物正式登场。
4. 双头钥匙另一头“留给秦朗自己”，含义待解。
5. 棺材内第三声叩击，比前两次更沉——来者是谁。

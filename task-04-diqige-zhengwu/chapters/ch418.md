# 第418章 木门之后

锣声落下的一瞬，顾言秋的指尖已经扣住了秦朗的手腕。

她没回头。秦朗也没回头。两人并肩站在那扇渗水的木门前，门板上的“水”“渡”二字正在缓缓流动，像有什么东西在木板内部游走。而那个“秋”字的禾旁起笔，已经写完了第一撇。

“第二声锣响之前，”顾言秋嗓音压得很低，“我们得进去。”

秦朗看着门板——门缝里渗出的水在门槛下积成薄薄一层，水面上浮着一根断落的芦苇杆，和他在雾津河边见过的那种一模一样。他伸手推门，木门纹丝不动，反倒是指尖触到门板的一瞬，水面上的芦苇杆轻轻转了个方向，指向门缝下方。

“锁在里面。”他说。

顾言秋蹲下身，借着铜牌上残余的微光端详门槛。水线之下，一道巴掌宽的暗槽嵌在青石里，槽底躺着一枚铜扣——和渡河人制服袖口那种一模一样。她伸出手，铜扣却在她指尖触到的前一瞬轻轻弹起，落入她掌心，槽底同时显出一行刻字：

“渡河人收名，不收叩门人。”

铜扣温热的，带着一股灼燒过的炭火气味。顾言秋的瞳孔微微一缩，她见过这种铜扣。雾津老宅、粮仓后门、她父亲锁了三十年的那扇门闩上，也嵌着一枚同样的铜扣，只是那一枚中心被钻了一个小孔，穿了一根红绳。

她把铜扣按进暗槽尽头的一个凹陷里，大小严丝合缝。咔嗒一声轻响，木门内侧传来链条滑动的声响，门轴转动，露出一道仅容一人侧身挤入的缝隙。

缝隙后方没有光，但有风。风里带着河泥、水草、焦炭、铁锈混合的气味。

秦朗先挤了进去。脚底踩到的是湿滑的石板，头顶有水珠滴落，滴在肩头，溅开成一小团深色水渍。他掏出打火机，火苗跳起的一瞬，他看清了自己所在的地方。

一条长廊。两侧墙壁是青砖砌成，砖缝里嵌着密密麻麻的碎瓷片，瓷片上烧着同样的图案：一个简笔的人形，手里捧着一只碗，碗沿往下淌着三道水线。走廊尽头拐角处悬着一盏煤油灯，灯罩上贴着一张发黄的纸条，纸条上写着三个毛笔字：

“勿吹灯。”

“这是渡口底下的通道。”顾言秋跟进来，门在身后自动合拢，缝隙消失得无影无踪。她伸手摸了摸墙壁上的碎瓷，“釉上彩，民国三十八年永丰窑的瓷片……这条甬道，和雾津渡口的老码头是同一批砖。”

秦朗顺着走廊走到煤油灯下。灯芯燃着，却不见火苗晃动。他注意到灯座底部压着一本硬皮册子，和档案库黑皮本一模一样的封面，只是封上没有任何字。他翻开第一页，纸页泛黄发脆，第一行字迹潦草却格外眼熟——和他父亲秦守信的笔迹几乎一致，但日期却写的是民国三十八年七月十四：

“又过一日，名字仍未干。渡口主簿说，第七人已在纸上写下，只等水涨。”

秦朗的手顿住。他继续往下翻，第二页、第三页……册子是日记，断断续续记了四十余篇，篇篇都是在同一个日期轮回——七月十四至七月十七之间反复循环，像记日记的人永远停在那几天里。最后一页没有日期，只有一行字，墨迹尚未干透：

“他不该姓秦。”

秦朗合上册子，指尖发麻。他张开嘴想说话，喉咙里却涌上一股焦苦味，像火烧过的铁锈。他低下头，走廊尽头那盏煤油灯的火苗忽然跳动了一下，朝某个方向偏了过去——那个方向，墙壁上的水渍正在以一种缓慢而均匀的速度汇聚成一个字。

“顾”字写完，最后一笔是名字里的“秋”字禾旁。顾言秋站在他身后，盯着那个正在成形的字，声音轻得几乎听不见：

“它在写我的名字。”

第二声锣响，恰在此时到来。

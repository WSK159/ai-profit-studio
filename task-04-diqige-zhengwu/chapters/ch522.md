# 第522章 门缝下的纸

秦朗蹲下身，手指触到那条青灰色门缝时，指尖传来一股凉意——不是石头的冷，是河水的冷。那缝隙细得像刀片切出来的，里面却隐隐飘出一股湿气，混着水汽和一种说不上来的气味，像老房子积了雨水的木梁。

“底下还有一层。”他说。

顾言秋没动。她站在石室门口，手里攥着那枚铜钥匙，匙柄上的“渡”字硌着她的掌心。她的目光落在那道门缝上，忽然说：“你父亲刚才在咳嗽，你听到了吗？”

秦朗沉默了一瞬。他当然听到了——那咳嗽声沙哑、断断续续，像从嗓子深处挤出来的，和他记忆里父亲的声音一模一样。但他也清楚，他已经二十五次走进这道门后的世界了，每一次都是假的。咳嗽声也是假的。

“他在引我们下去。”秦朗说。

“或者是引你留下。”顾言秋的声音很轻。

秦朗没有接话。他用掌心贴着那道门缝，用力往下压——门板纹丝不动。他又试了两次，石头地面就像长死了似的，连一丝松动都没有。他收回手，看见掌缘沾了一层青灰色的灰，细得像面粉。

“是纸灰。”顾言秋忽然凑过来，捏起一点放在鼻尖嗅了嗅，“不是石粉。是烧过的纸，碾碎了之后混着灰泥封在缝里。”

秦朗皱眉：“谁会往门缝里糊纸灰？”

“守坟的人。”顾言秋站起身，目光扫过石室的四周。她的视线在石龛空荡荡的凹槽上停了一下，又落回那道门缝上，“雾津渡的规矩——渡口关，名字回。你父亲是掌渡人，他守的是这道门。门缝里的纸灰，是糊门用的。纸灰把门封住，名字才回不去。”

秦朗的呼吸顿了一拍。他想到户籍册上那些被抹掉的名字，想到卷宗里那七个失踪者——他们是不是也曾经站在这里，蹲下来，看见过这道门缝？那他们后来去了哪里？

他再低头看时，门缝里那飘出的湿气比刚才重了。一股风从缝隙里涌出来，打着旋，带着一股酸涩的纸墨味。他鬼使神差地凑近，把脸贴到石地上，眯起一只眼往那条缝里看去——缝隙只有不到两毫米宽，但底下似乎有光。一种暗黄的、摇摇晃晃的光，像一盏煤油灯在被风吹动时晃荡。

光底下，有一张纸。

秦朗的心猛跳了一下。那张纸就贴在门板的反面，纸面发黄发脆，边缘卷起，中间写着一行字。光线太暗又太窄，秦朗眯着眼辨认了好一会儿，才拼出一个“阿”字——后面那个字被门板上的铁板挡住了，只能看见半个横折。

“纸上有字。”他说，声音哑得厉害，“阿……后面看不清。”

顾言秋蹲下来，也凑到门缝边看。她看了一会儿，忽然从口袋里摸出一根火柴，擦亮，往那条缝里斜斜地照进去。火光照亮的瞬间，那张纸上的字比刚才清楚了一些——但就在她看清那行字的同一秒，火苗晃了一下，然后熄了。

纸上写的是：“阿朗，缝里塞进来的东西，别碰。”

门外那声咳嗽又响了。

这一次更近。近得就像在门板正后方，那人贴着石头、压着喉咙喘了一口。秦朗猛地直起身，后退半步，手已经按到了腰间的枪套上。他的目光钉在那道门缝上——缝隙里那盏昏黄的光不知什么时候没了，底下漆黑一片。

“他还活着。”秦朗说。他不是在问，是在确认。

顾言秋没有回答。她低头看着自己手里的火柴梗——火柴头刚才是整根点着的，现在却只剩半根，像被什么东西从中间啃断了。她抬头看他，眼里第一次露出一丝她自己也藏不住的犹疑：“这扇门底下，比你父亲还早。”

“什么意思？”

“纸灰糊门是旧规矩，民国之前就有的。”她把那半根火柴放进衣兜里，“你父亲是掌渡人，但他不是第一个。这道门缝不是他封的——是比他更早的人封的。”

秦朗沉默了几秒，重新蹲下去，又看了一眼那道门缝。这一次，一股风从缝里涌出来，带着一股铁锈味，还夹着一片枯黄的纸屑。那片纸从他脸前飘过去，落在地上。

他捡起来，翻过那一面，看见上面有一个字，被水浸得洇开了大半，只剩下半个偏旁。但那半个偏旁他认得——三点水，右边缺了一半，像是被谁故意撕掉的。

顾言秋凑过来看了一眼：“这是‘河’字。”

秦朗握着那片纸屑，指节收紧了。门缝底下的风还在往外涌，像有什么东西正在那扇门后面缓缓地翻着纸页。他抬起头，看向那道门缝，又看向石室深处那枚铜钥匙留下的空凹槽。

那道门缝之下，还有东西在等他们。而且这一次，它比父亲的录音更早。

他看着顾言秋，声音很平，但每一个字都像是刻出来的：“他在等我们塞东西进去。”

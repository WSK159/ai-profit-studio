# 第359章 笔尖下的墨是活的

木板入口下的气味，是干燥、发霉、又掺着一丝铁锈的旧味。像是一座多年没人打开的老宅，门一推开，陈年的尘埃扑进嗓子眼，呛得人咳不出来。

秦朗蹲在洞口边，用手电往下照。光柱穿透黑暗，落在一块青石地面上。那地面干净得反常，连一层灰都没有，像是每天有人清扫。

“我下去。”他说。

顾言秋按住他的肩：“等一下。你看这个。”

她蹲下来，手指轻轻拂过洞口边缘的木板断面。那钉子不是秦朗踩进去的，而是原本就嵌在木板里。他踩下时，铁钉恰好穿过了木板上的旧孔——一个早已存在的孔洞。

“有人故意留了这道门。”顾言秋说。

秦朗沉默了片刻，想起了什么，将口袋里那支“渡船”笔掏出来。笔杆上的刻字在灯光下格外清晰，他翻过笔身，发现靠近笔尖的地方有一道细细的暗槽，里面堵着一层黑褐色的东西。

他用指甲刮了一下。是干涸的墨。

“这笔以前泡过墨，泡了很久，墨都渗进木头里了。”秦朗说，“可灰衫人写字的时候，笔尖是干的。”

顾言秋眉头一动：“干笔能写字，墨是哪里来的？”

两人对视一眼。秦朗没有回答，把笔收回口袋，撑着洞沿跳了下去。

落地的瞬间，鞋底与青石碰撞出清脆的回响。他用电筒扫了一圈——这是一间地窖，大约十步见方，四壁都是青砖垒砌，角落堆着几只木箱，箱盖上落了厚厚的灰。唯一显眼的，是正中央一张长条木桌。

桌上摊着一卷泛黄的纸。

秦朗走近，手电光落在纸面上。那是一份户籍册的散页，字迹密密麻麻，每一行都是一户人家。他看出了几个熟悉的名字——方家，老周家，还有他父亲秦柏舟。

顾言秋也跳了下来，站在他身后，声音很低：“这……和档案室里那本户籍册的字迹一样。”

秦朗点了下头。他注意到纸页边缘有几处被撕掉的痕迹，缺口整齐、有人刻意为之。而最末尾一行，那名字是他自己的名字，孤零零写在表格里。旁边没有年龄、没有住址，像是有人只来得及写了一个名字，就被什么事情打断了。

他伸出手，指尖触到纸上“秦朗”二字。

字迹微微动了动。

秦朗猛地缩手。

“怎么了？”顾言秋上前两步。她凑近纸面，什么都没看出来。

“这字……”秦朗盯着那个名字，“刚才好像挪了一下位置。”

顾言秋拿出随身的小手镜，对准纸面照了照。镜中，那个墨迹名字的表面浮着一层极薄的细纹。那纹路会动，像水面的涟漪。

“是活的。”顾言秋声音发紧，“秦朗，这墨是有活性的。跟档案室里那本册子一样——你撕了它，它会自己补全。”

秦朗喉头动了一下。他下意识低头，看向自己的影子。电筒光把影子拉到身后，影子的两条腿之间，钉孔已经蔓延到膝盖上方，钉孔的边缘不再是黑色，而渗出了淡红色，像渗血的伤口。

他还没有忘记自己刚才是怎么踩下来的。

“我踩那根铁钉，是不是就等于——自己把影子钉死了？”秦朗问。

顾言秋沉默数秒。她抬起镜子，转向墙壁，口中喃喃念道：“灯灭名消，灯亮名存；名存影存，影存人存。”

“反过来说，”她说，“影存人存。只要影子还在，你就还在。但——”她顿住，目光落回秦朗小腿高度的影子上，“这个钉孔，钉的是影子。钉孔蔓延到哪里，哪里就没了影子。”

秦朗低头看着地面。灯光下，他的影子膝盖以下确实变得很淡，像一层被水泡过的旧报纸。

“要是蔓延到头顶呢？”他问。

顾言秋没有回答。但她的沉默本身就是答案。

就在这时候，头顶传来一声沉闷的响动，是船底板被水浪拍打的声音。紧跟着是一阵拖拽的声响，像是有人趿着鞋从木板上走过。

秦朗抬头，洞口那盏白皮灯笼不知何时已经灭了。洞口一团漆黑，什么也看不见。但那脚步声没有停下，一步一步，从他们头顶的渡口沙地上走过去，然后忽然停下。

——那脚步声，停在了洞口正上方。

然后，一笔一划地，有人用手指在木板上敲了三下。

笃。笃。笃。

那节奏，他不陌生。那是他父亲数数的习惯。小时候，父亲去河边上夜班，出门前总会在门板上敲三下，意思是：“我走了，别担心。”

“这里是渡口。你爸当年走的那晚，就是从这里下的河。”老周的声音从记忆里浮出来。

秦朗盯着洞口，喊了一声：“爸？”

没有任何回应。脚步声再次响起，但这一次，是朝远处走去的。带着一种古怪的缓慢，像是在拖什么东西。

他看了一眼手里的笔，又看了一眼桌上那张纸上自己“动过”的名字。一个念头浮上来，凉意顺着脊背爬满全身——

那支笔，或许不是用来记失踪者名字的。

它是用来替影子签字画押的。

落一笔，死一个影子。而他的影子，刚被那根钉子和这张纸一起，钉上了最后一条路。

顾言秋忽然抓住他手腕：“你看——”

她指着那卷纸的末尾。秦朗名字那一行的下面，不知何时多了一行字，笔迹新鲜，墨痕未干，只有两个字：

“勿赎。”

他的父亲，字迹像他父亲的笔画。

是警告。还是一种——临别遗言？

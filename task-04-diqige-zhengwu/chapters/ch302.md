# 第302章 照片里的第六人

证物室的日光灯管发出嗡嗡的电流声，像是有什么东西在灯管内部挣扎。秦朗的目光死死钉在那张旧照片上，照片里的六个人站在灰渡码头的栈道上，五个人的面容清晰可辨，唯独第六个人像被水汽糊过一样，五官模糊成一片灰白色的雾。

老周的手电筒晃了一下，光柱落在照片边缘那些细密的海盐渍上。“这盐，不是海水盐，是矿盐。”老周凑近了些，鼻尖几乎贴上玻璃相框，“我祖父的盐渍池用的就是这种矿盐，整个雾津县只有那一个池子。”

顾言秋没有说话，她从包里取出放大镜，对准第六个人的位置。镜片下，那片模糊的灰白色雾气似乎微微流动了一下——像是被什么惊扰了。顾言秋的手指猛地一缩，放大镜差点脱手。

“怎么了？”秦朗问。

“他动了。”顾言秋的声音很轻，但笃定，“刚才他还在栈道线外面半步，现在……现在他站到栈道线上了。”

证物室里安静了一瞬。

老周率先打破沉默：“不可能。照片是死的，人还能从画面外面走进来？”

秦朗却想起什么，绕过证物台，绕到老周身后。那根铜钥匙正斜斜地躺在证物台上，在日光灯下投出一道影子。影子末端，那个方形开口的轮廓比实物多出一截——像是有什么东西正从影子里往外钻。

秦朗猛地回头看向照片。第六个人的位置，正好在他投下的影子方向。

“你们有没有想过，”秦朗缓缓开口，“这张照片上的第六个人，可能不是失踪者中的任何一个。他可能一直在那边——一直站在我们没注意到的地方。”

顾言秋的目光从照片上移开，落到秦朗脸上。她张了张嘴，又闭上，像是有什么话卡在喉咙里。过了好一会儿，她说：“秦朗，你父亲当年查灰渡的时候，是不是也拍过照片？”

秦朗一愣。他调取过父亲的旧案卷宗，卷宗里的照片他都翻过，没有一张是灰渡码头的。但他忽然想起来——卷宗里的照片中，有一张是父亲在县档案馆门口拍的，背景里似乎有一个模糊的人影。

那个人影，一直没被记录下来。因为当时的侦查员认为那是恰好路过的门卫。

“卷宗里有照片，但我没细看。”秦朗说，“你的意思是——”

“去看看。”顾言秋的声音有些紧，“如果那张照片里也有一个人站在角落里，那说明你父亲在查同一件事。而且，他在照片里留下了同一个人。”

老周收好手电筒，忽然低声道：“你们听到没有？”

秦朗和顾言秋同时屏住呼吸。证物室深处，传来一阵极轻的叩击声——三短一长，像是有人在墙里面敲棺材板。声音隔着一面墙，闷闷的，但节奏清晰。

秦朗想起铜钥匙传出的叩击声，那也是三短一长。

“墙后面是……”秦朗问。

老周的脸色变了：“墙后面是旧物证室，十九年前就锁死了。钥匙在档案科主任手里。”

顾言秋的声音压低了些：“十九年前——那不是你父亲出事的那年？”

秦朗没有回答。他抬手摸了摸那面墙，潮湿的灰浆蹭在指尖上，带着一股淡淡的铁锈味。他忽然想到一个细节：父亲尸检报告里写，断指掌心攥着的木梳齿上有五个指纹，三个属死者，两个不明。

那两个不明指纹，会不会属于照片上的第六人？

证物室的灯管又跳了一下，整个屋子暗了不到半秒。等灯光恢复时，照片上的第六个人已经站进了栈道正中——那道模糊的灰白色雾影，正正地对着镜头，像是一双看不见的眼睛正从照片里望出来。

秦朗没有退后，他只是盯着那张照片看了很久。然后他笑了，像是在对一个久未谋面的故人打招呼：“第六个……你找的是我，对吧？”

照片上，那团灰白雾气微微漾开，像是照片里的人点了点头。

# 第440章 织字蔓延

灰衣人站在门口，帽檐压得极低，檐下本该有脸的位置是一片光滑的空无，像一面没来得及画上五官的白布。他腰间那串铜扣在暮色里泛着暗绿的光，叮叮当当的声响在寂静的旧宅里格外清晰，像有人在用指节敲一扇门。

顾言秋的呼吸猛地收住。老周已经横跨一步，将她挡在身后。他左手还攥着那张写有“第七个证物是人”的纸条，指节攥得发白。

“同志，”老周的声音压得又低又稳，“这户人家没人，你走错门了。”

灰衣人没有动。他像一截被钉在门槛上的影子，半晌才偏了偏头，那个动作让顾言秋想起晒谷场上被风拨动的稻草人。他开口了，声音像是从水底冒出来的，闷而沉：“我来找我儿子。”

老周眉头一皱：“你儿子叫什么？住哪条街？我帮你认认门。”

灰衣人沉默了很久。暮色从门缝里透进来，落在他脚边，顾言秋忽然发现他脚下没有影子。她心里一凛，想起录像里第七个失踪者走进监控盲区前的最后一帧，那人的脚下——也没有影子。

“我儿子，”灰衣人又说了一遍，声音更低了，像喉咙里堵着一团湿棉布，“我记得他的名字，但是想不起来了。”

老周的身体明显绷紧了一瞬。顾言秋知道他在想什么——张叔说过，下午有人穿灰蓝制服问路，“来找他儿子”，指向巷子深处。而这个“儿子”是谁？徐木匠？还是——秦朗？

灰衣人忽然抬腿迈过门槛。他的步伐很轻，几乎听不到鞋底落地的声音。老周猛地喝了一声：“站住！我是刑警队的，你越过这条线，我按擅闯民宅办你。”

他从口袋里掏出证件展开。灰衣人停住了，帽檐微微抬起一线——那一线之下，依然没有五官，只有一片平滑的白，像还没烧出花纹的瓷胎。

顾言秋看见老周的手在微微发抖。他举着证件的手挡在她面前，那件外套还搭在她臂弯，手背上青筋凸起，像是在用全身力气维系住“这只是个寻常闯入者”的假定。

灰衣人却忽然偏过头，像是“看”向了她。没有眼睛，可顾言秋清楚感觉到一道视线落在这边。她手背上的“织”字猛地灼烫起来，像有人拿针在皮肉底下走线。她低头看，那两个字竟已经爬到腕骨上方，笔划细密如蛛网，红得发紫，像渗出来的旧血。

“你认得我？”顾言秋听见自己问出口，声音干涩。

灰衣人没有回答。他后退一步，像是有什么拉住他一样，又从门槛退回了院子里。他站在那行皮鞋印旁边，帽檐重新压下去，喉咙里发出一声极轻的、像叹息又像哼唱的声音。那调子很旧，像老唱片被磨花的尾音，顾言秋听了一瞬，浑身的血都凉了——那是她父亲顾长明笔记本里抄过的一段民谣，她小时候睡觉前听过。

“雾津渡口水淹淹，过了渡口莫回头……”

灰衣人唱到半句就停了。他转身走进暮色里，脚步无声，像一片被风拖走的灰布。老周追到门口，院外巷子里已经空空荡荡，只剩墙根下那只野猫弓着背，炸着毛，盯着灰衣人消失的方向。

老周退回屋里，反手把门闩上了。他喘了两口气，才看见顾言秋站在穿衣镜前，正盯着镜子里自己的脸。

镜子里的人，瞳孔中央那条灰色横线比刚才又粗了一分。而她的手背上，“织”字已爬到腕骨尽头，像一条沿着血管生长的藤，马上就要攀进手掌心。

“老周，”顾言秋的声音很轻，“他说‘来找我儿子’，他儿子是不是——秦朗？”

老周没有回答。他低头看着自己手心里那张纸条，纸边焦痕蜷曲，墨迹却清晰如新。他沉默了很长时间，才说：“户册上秦朗的父亲，叫秦守信。可秦朗说过，他爹死的时候，他还没出生。”

顾言秋霍然抬头。

门外的暮色彻底沉了下来。院外巷子尽头，不知哪扇窗后亮起一盏灯，那灯亮得很突兀，像有人在窗前站着，拧亮了灯又退开。顾言秋透过窗棂望出去——那灯光的颜色黄得发腻，像旧照片上被水洇开的色斑。

而她的手背，“织”字终于爬过了掌根。

# 第322章 停灵堂旧址

华丰家具厂在县城东郊，紧挨着老货运站，铁皮厂房顶上竖着“华丰”二字的霓虹灯牌，半边已经不亮了。秦朗把车停在厂区外的土路上，熄了火，看了一眼手机，顾言秋发来的定位旁边跟着一句话：“仓库在东侧最里面，门口挂铁锁，钥匙在老门卫室。”

他推开车门，夜里十一点半，风裹着锯末和油漆的味道扑过来。老门卫室亮着一盏昏黄的灯泡，秦朗敲了敲窗，一个戴老花镜的干瘦老头探出脑袋，看了他一眼，没问来意，直接从抽屉里取出一把黄铜钥匙递过来。

“第几间？”老头问。

“东侧仓库。”

老头没接话，缩回脑袋，低头继续翻手里的报纸。秦朗拿着钥匙往里走，穿过两排堆着胶合板的棚屋，最里面那间铁皮仓库大门上挂着锁，门缝里渗出一股陈年朽木的气味。

他拧开门锁，拉开门，铁皮门轴发出尖锐声响，里面积灰的日光灯管闪了两下，亮了。

仓库不大，约莫百来平，地面是水泥，四壁贴着发黄的墙纸，墙纸边缘起皮，露出底下的砖面。秦朗目光扫了一圈，仓库正中放着几台落满灰尘的裁板锯和砂光机，墙角摞着几捆三合板，靠近后门的位置，地面水泥有明显的浇铸痕迹——颜色比周围深，约莫一米五见方，像被人重新抹过一层。

他蹲下来，手掌贴上去，水泥面冰凉，触感有别于周边的粗糙，而是光滑细腻。

“老周。”秦朗拨通电话，“停灵堂旧址现在铺了水泥，位置靠后门墙角。”

“那地方当年停棺材的地儿。”老周声音压得很低，背景里隐约有戏台上的锣鼓声，“刘玉的牌位就摆在那块地正上方，棺材头冲南，那道水泥应该是后来填的，下头可能是个地窖或者暗道。”

秦朗站起身，绕着水泥块转了一圈，注意到靠近墙根的位置，水泥与砖墙之间的缝隙里卡着一片暗黄色的东西。他掏出随身带的镊子，小心将它夹出来——是一角残破的纸片，纸质粗厚，发黄发脆，边缘呈不规则的撕裂纹，上面有两个毛笔字：“渡口”。下面的字被裁掉，只能看到一撇开头。

他把纸片收进证物袋，抬眼看了看日光灯的方向，灯管还在嗡嗡作响。仓库里没有窗，唯一的光源就是那根日光灯。墙上贴的墙纸因为时间久远，水渍洇出一片片暗纹，他走近几步，发现暗纹的分布并不自然——很多点状笔触，不像水渍，像墨迹。

他伸手去触碰，指腹微微蹭过墙纸，那层纸竟脆弱地碎裂开来，露出底下的青砖。砖面上被人刻了一道又一道的痕迹，排成整齐的竖列。秦朗凑近去看，那些刻痕不是字，而是简笔图形：一顶斗笠、一把伞、一架纺车、一杆秤、一台留声机、一枚铜钱、一张弓。

七个图形。

他数了三遍，都是七个。前六个有规律，显然是证物对应的职业，第七个图形是弓，他从未在案卷里见过“弓”相关的线索。

手机震动。秦朗接起，顾言秋的声音有些急促：“你拍到墙上的刻痕了吗？”

“拍了，七个图形。”

“斗笠、伞、纺车、秤、留声机、铜钱、弓。”顾言秋语速极快，“前六个对应六件证物，弓……你知道弓的另一个说法是什么吗？悬弓——悬弓也叫‘射影’，民俗里说，七月半渡口挂弓，是射影子用的。”

秦朗喉头微紧：“射影子？”

“对。”顾言秋顿了顿，声音低下去，“秦朗，渡河人收走的是人的名字，但名字收走之前，要先把影子射落。弓不是证物，是前置条件。第七件证物不是棺材钉——棺材钉是结果，弓才是真正的第七件证物。”

仓库里日光灯管忽然闪烁起来，秦朗看到那块浇铸水泥的中央，悄然浮起一线轮廓，像有人蹲在那里，蜷缩成团。他屏住呼吸，那团轮廓极淡，在灯灭的瞬间消失。灯重新亮起时，水泥面平整如初。

秦朗正要走近，口袋里那枚棺材钉微微发热。

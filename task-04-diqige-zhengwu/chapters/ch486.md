# 第486章 秤与骸

证物室的日光灯管闪了两下，发出“嗞嗞”的电流声。秦朗把那柄黑檀木老秤平放在白布上，灯光从正上方打下来，秤杆表面的木纹清清楚楚——不是普通木纹，是极细的刻痕，像被水浸过无数遍的旧船板，一层层的纹理叠压在一起。

顾言秋站在他旁边，手里攥着那枚1935年的骨质钥匙，指腹反复摩挲着钥匙齿上凹陷的纹路。她忽然说：“秦朗，你看秤杆的‘渡’字。”

秦朗低头凑近。那个“渡”字比之前看到的更深了一些，凹槽里泛着暗红色的光——不是油漆，更像是某种液体渗进去后干涸的痕迹。他用手轻轻一碰，指尖传来一丝温热，像碰触刚熄灭的炉壁。

“刚才还是凉的。”他说。

顾言秋没接话，而是把那枚骨质钥匙举到灯下。钥匙柄部有一个极其细小的凹槽，形状是长条形的，几乎与钥匙身融为一体，如果不是她刚才用放大镜一寸寸看过，根本不会发现。她拿出1937年那枚铜钥匙，并排放在一起。两枚钥匙的凹槽位置几乎重合。

“这两枚钥匙之间，缺一枚。”她看向秦朗，“骨质、铜质、1935年、1937年。如果按年份排，中间应该还有一枚1936年的。而且……”

她从口袋里掏出一张薄纸，是她在档案馆翻到的旧时渡口登记表副本，上面用毛笔写着“丙子年六月，渡口器物清点：秤一、钥三、索一”。丙子年，就是1936年。

秦朗的眉头拧了起来。他刚要开口，证物室的门被推开，老周拿着一叠打印纸走进来，脸色不太好看。

“县城南郊那片芦苇荡，还记得吧？就是上个星期排查失踪案时搜过的那片。”

秦朗点头。那片芦苇荡在雾津河下游支流边上，面积不小，半人高的芦苇密得连人都走不进去，当时搜了三天，什么也没找到。

“今天下午有人去那边钓鱼，”老周把那叠纸放在桌上，“在芦苇荡靠岸边的泥滩里，钓上来一堆东西。”

秦朗接过打印纸一看，是一组近距离拍摄的照片。泥滩上横七竖八地躺着几截断骨，颜色灰白，像是泡了很多年。骨头旁边是一块锈得看不清形状的铁片，角落处隐约有一个圆孔。还有半截绳子——麻绳，已经烂成了黑褐色，但编法很特殊，是那种老式的扣绳法，每一扣都打成结。

老周补了一句：“骨头初步看，是人的胫骨和桡骨，至少有两具以上。铁片形制像是旧式门环，也有可能是箱扣。绳子那截，我给河边摆渡的老头看过，他说这种打结手法，是民国时期渡工用来拴缆桩的‘死扣莲’。”

秦朗看着那些照片，腕骨处那根红线忽然传来一阵微弱的麻痒。他下意识地摸了一下，红线紧贴在皮肤上，表面浮出一层极细的露珠。

顾言秋也蹲下来看照片。她的目光落在那块锈铁片上，沉默了几秒，说：“这个圆孔的位置和大小，像不像钥匙柄上那个凹槽？”

证物室里安静了片刻。秦朗把那枚骨质钥匙放在照片旁边，放大比对——圆孔直径几乎一致，偏移的位置也吻合。

老周啧了一声：“这什么意思？骨头和钥匙是一套的？”

秦朗没有回答。他想起了县局档案里那段1925年的口述记录：洪三爷从雾津河里起网，捞上来一杆秤、一把骨钥，还有六具尸体。名册上独缺一人。

第七具尸体，在芦苇荡里。

他把照片翻到最底下那一张——泥滩最边缘处，芦苇丛的根部，隐约露出一截白生生的东西，细长、弯曲，像一根发白的树枝。但秦朗认出来了，那是一根人手指骨，指节微曲，像是生前死死抓住了什么。

指骨旁边，有一小片不规则的暗红色痕迹，像一个字，但被泥水洇得看不清楚。

顾言秋也看到了。她忽然伸手从口袋里摸出那枚1937年铜钥匙，对着照片上那枚暗红色的痕迹比了比形状，低声说：“秦朗……这个形状，像不像是‘伏’字的右半边？”

秦朗猛地抬眼。伏——渡河人的“渡”字右侧，也藏着半个“伏”字。而顾言秋的母亲留在日记本上那幅画，角落里也写过一个“伏”字，笔迹潦草，像是仓促间写下。

他还没来得及细想，证物室的灯齐刷刷地灭了。黑暗中，窗外传来自鸣钟声，不多不少，九下。那是县局对面旧教堂的钟，平时从来不走字，可每到星期三晚上九点，它都会响。

顾言秋的呼吸明显紧了一下。秦朗摸到腰间的手电筒，正准备开关，忽然看见窗台外沿——灰白色的水泥面上，多了一双湿脚印。脚趾细长，脚掌窄得不正常，像是从水里刚走出来的人，正站在窗外。

窗台在四楼。

秦朗的手电筒亮了。那双湿脚印在光柱下没有消失，但脚印的主人不见了。而脚印中央，留着一小片深红色的东西，像一枚被踩扁的果实。他伸手去够——触手冰凉，是一枚早就干透了的陈年血珠。

顾言秋的声音从身后传来，压得很低：“1935年的骨钥匙，是开锁用的。而芦苇荡里那具骸骨……他死之前，什么都没抓住，只留下了半个‘伏’字。”

秦朗握紧那枚骨钥匙，钥匙柄上残留的一丝温度，忽然变得更烫了。他忽然知道那半截“死扣莲”麻绳是用来干什么的了——那杆秤的秤砣，是被这根绳子捆着，沉进河底的。秤砣下面压着的，才是真正的第七具尸体。

窗外，那枚血珠在灯光照射下，无声地化开，在水泥面上洇出一个字来。歪歪斜斜，像是被水泡了很久的手蘸着血画下去的——那是一个“秦”字。

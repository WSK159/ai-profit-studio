# 第115章 掌中钉

秦朗没有伸手。

他把钢笔横在胸前，笔尖对着渡河人的方向，那根透明发丝在河风的吹拂下轻轻颤动。船底“咯吱”响了一声，像是从一个很深的梦里醒来。老周在岸上喊了句什么，他听不清，只看见顾言秋跑到了水边，手里攥着一张纸。

渡河人的手纹丝不动。掌心里那根钉子上的霜气浓了几分，白丝在接触到河面湿气后微微弯曲，像活物一样探向秦朗的方向。他的声音再次漫进脑腔，冷得没有一丝情绪：“你不是来取它的？”

“我不是来送死的。”秦朗稳住声线，“你等了三十四年，不差这一盏茶的功夫。我要先弄明白一件事。”

“问。”

秦朗举起钢笔，笔帽裂口在灯下露出内侧一圈刻痕：“这支笔，是我父亲1986年冬天从你们那里拿走的？”他用指甲点了一下字迹上面的锈迹，“这笔帽里头的锈，不是铁的锈。是某种更老的东西。”

渡河人的眼睛在阴影里眨了一下。

“他替你做了件事，对不对？”秦朗继续说，“档案馆那场火，是他放的人，不是他点的，但门是他开的。他放走了某样东西，换了一个名字从册子上拿下来——所以1987年之后他再也没回过家，因为事情出了岔子。”

船身猛地震荡了一下。渡河人的手仍然伸着，但那个轮廓明显僵直了片刻，像是一尊挂了满身的木偶突然被人拨断了线。岸上的顾言秋一下子大声喊了出来：“秦朗！你父亲的名字在册子上不是最后一页——后面还有一行！”

秦朗转过头。顾言秋挥舞着手机光屏：“我拍的那张户籍册残页，最后一行被折进去叠住了！1986年11月的记录，上面注销了一个名字——不是你父亲的，是一个叫‘白芷’的……”

她话没说完，渡河人忽然动了。

黑伞从船头猛地撑开，伞面上滑下无数水珠，每一滴落在船板上都发出“叮”的一声脆响，像铜针落地。渡河人的身形从伞下立起，比常人高出将近一个头，制服衣摆垂过脚踝。他掌心的钉子突然转了个方向，对准秦朗的胸口。

“你父亲的话，”他的声音不再是从脑子里传来，而是从整个河面四面八方涌上来，带着回音，“没有一句是真的。”

秦朗眼前忽然一黑。钢笔从他手里脱出去，笔帽在空中炸成两半，那根透明发丝飞出来，却没有落进水里，而是悬在半空，笔直地指向渡河人掌心的钉子——两样东西遥遥相对，像是磁极捕捉到了彼此。

河水从乌篷船四周翻上来，黑得像墨汁，涌到船舷边上却止住了，像一层膜包住了整艘船。秦朗被一股力推得踉跄一步，踩进船底积水中——他低头看见，船底铺着一层青石砖，砖缝里嵌着许多碎纸片，每一片都写着字。他蹲下来捡起一片，纸上的字迹被水泡得模糊，只剩下半边：白芷，女，民国廿六年生，雾津渡人氏。

顾言秋在岸上拼命往水里走，水没到膝盖。她冲着船上的秦朗喊：“那根发丝！你抓住那根发丝！它是渡河人的‘锚’——谁握住它，谁就能定他的形！”

秦朗抬起头。渡河人正看着他，那张脸终于从阴影里露了出来——不模糊，不狰狞，是一张干净苍白的年轻面孔，眉目细长，和他对视的一瞬间，眼底浮现出极浅的困惑。然后他开口，声音沙哑得像是三十四年没有说过话：

“你是那个孩子。”

秦朗的手，已经够到了那根发丝。手指合拢的一瞬间，船底所有碎纸片同时浮起来，像是被无形的风吹上天，又像是有无数只手从水底接住了它们。黑伞“咔嚓”一声收拢，渡河人的影子砸在船板上，变成了一个清晰的、完整的人形。

秦朗低头看他自己的脚下——他的影子也在，但影子的脚踝处，一枚棺材钉的轮廓正裂开更大的一道缝。顾言秋在浅水里停住，盯着他的影子，声音带着压不住的颤抖：

“秦朗……你影子上那根钉子，在动。”

# 第110章 替身的两面

顾言秋的影子在档案室的日光灯下晃了晃，那根嵌在影中脚踝处的棺材钉裂痕又深了一分，像干涸河床上被烈日晒出的龟裂纹。秦朗盯着那影子看了三秒，然后扭头看向窗外的渡口河面。雾津渡的水面纹丝不动，连风都吹不皱它，仿佛整条河都被什么定住了。

“秦明远。”顾言秋的声音压得很低，带着一丝不易察觉的颤抖，“你刚才说，渡河人可以豁免一个人，条件是替身。替身是谁都可以吗？”

坐在转椅上的人——那东西——缓慢地转动身体，目光从秦朗脸上滑到顾言秋脸上，又滑回秦朗身上。“替身必须是名字在册上的人。”他说，嗓音像砂纸磨过铁皮，“在册的，才能替，不在册的，连踏入渡口的资格都没有。”

秦朗握紧拳，指甲嵌进掌心，他压下火气。“那你当年为什么拒绝？只要交出你的一张脸，我就不会在册上。你做了二十五年的摆渡人，你要什么脸没有？”

静默。窗外，雾津渡的水面起了一层白雾，像是那河在呼吸。

“你说错了。”秦明远垂下眼帘，“渡河人给的选择从来不是‘要不要做替身’，而是‘谁来做替身’。当年那张纸递到我手里时，上面只有两个名字——你，和你妈。”

秦朗后背一凉。他母亲在他六岁那年病逝，他记得她病床前握着父亲的手说“别让孩子走我的路”，那时他以为那只是临终的胡话。

“你妈的名字也在册上。”秦明远的声音听不出悲喜，“渡河人让我选，要么交一张脸，换走一个名字；要么什么都不做，等七月半来收。我选了后者。你以为我是舍不得自己的脸？”

“那为什么……”秦朗话说了一半，猛地卡住。顾言秋在旁边接上：“因为秦朗在纸上，而秦朗身上流着你和你妻子的血。名单人的血脉，渡河人不止收一个。”

秦明远抬起头，朝顾言秋投去一个“你果然聪明”的目光，嘴角扯出一个比哭还难看的笑：“姑娘说得对。我若交了脸，换走的是秦朗的名字，可他妈的名字还在册上。等渡河人收走他妈，秦朗这辈子都会活在愧疚里。他那时才六岁，我已经快撑不住了，我不能让他带着一个‘是我害死我妈’的包袱长大。”

秦朗喉咙发堵。他忽然想起母亲去世前的那个夏天，父亲整天把他带在身边，走到哪儿都牵着他的手，像怕他丢了似的。那年雾津县也失踪过人。

“可是爸，你把自己写进册子里，成了摆渡人——”秦朗声音有点哑，“你图的什么？”

秦明远沉默了。

他缓缓站起来，日光灯在那一瞬闪了一下。秦朗能看清他的轮廓，却看不透那张脸上的表情——那张脸，是当年户籍册里贴的那张黑白照片的脸，苍白的，年轻的，比秦朗记忆中父亲的样子年轻太多。

“图什么？”秦明远轻声重复了一遍，然后转过去，推开身后的窗户。夜风涌进来，带着雾津渡上的水腥气。他望了那河很久很久，久到顾言秋忍不住向前一步，久到窗外河面泛起第一丝涟漪。

“我图的是，你有一天能找到第七件证物。”他终于说完，声音轻得像被夜风掐断的线，“棺材钉钉的不是影，钉的是规则本身。你拔得下它，渡口就关了。你拔不下，每七年，册上添一批名字，你妈、你、你未来的孩子——都是渡河的饵料。”

他转头看着秦朗，秦朗看见他眼眶里有一层灰色的光，不像是泪水，像河底死去的磷火。

“今晚七月半，渡口即开。你只有一个时辰。”秦明远朝窗外抬了抬下巴，“雾津渡桥头第三根石柱下方，是你妈当年亲手埋的箱子。箱子里有你要的东西。”

秦朗顺着他的视线望出去，渡口桥头那根被青苔覆盖的石柱在夜色中像一根沉默的墓碑。他想再回头问什么，却听到“啪”的一声，档案室的灯彻底灭了。黑暗中，秦明远的轮廓一点点碎散，如同河面被石子击碎的倒影，连同他坐过的那把转椅一起，消融在黑暗里。

只剩秦朗和顾言秋的呼吸声。

“你信他么？”顾言秋在黑暗中问。

秦朗摸向腰间的枪，指尖冰凉。“我不知道，但我必须去。”他推开门走出档案馆时，余光瞥见顾言秋跟了上来，她影中的裂缝比刚才更长，像一根滴着墨的弦，从脚踝一路延伸到小腿肚。

他没有说话。他们沿着青石板路往渡口走，路上的雾浓得像棉花，连脚步声都像是被什么东西吞掉了。

走到桥头第三根石柱时，秦朗蹲下身，手指插进石柱底部的泥土里。泥很松，像刚被翻过。他双手往下挖，先碰到一块冰冷的铁皮，再往下，是一口半米见方的老式铁皮箱，锁已经锈死。他用警用匕首撬开盖子，里面霉味扑面而来，混杂着樟脑和旧纸的气息。

箱子里放着一捆旧信、一张泛黄的铅笔画，以及一个巴掌大的牛皮纸信封，信封上用毛笔写着两个字——秦朗。

他拆开信封，里面是一张纸，纸上是秦明远的笔迹，只有一行字：“第七件证物不在棺材铺里，在你手上那支笔上。”

秦朗低头看向自己上衣口袋里那支用了七年的黑色钢笔。那是他参加工作那年，老周送的。

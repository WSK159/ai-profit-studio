# 第586章 账本与引路

灰袍人消失后，绿灯笼的光倏地灭了大半，蜡像馆里只剩那些蜡像脸上油腻腻的暗红。秦朗没动，脚踝上的红勒印像是被烙铁烫过，一阵一阵地跳着疼。顾言秋蹲下去，伸手按了按那圈勒痕，指尖还没有碰实，秦朗脚踝处的皮肉便猛地凹陷下去一道沟——像是有什么东西从皮肤底下抽走了。

“别碰。”秦朗把腿收回来。

顾言秋没坚持，目光却落在蜡像底座那块铭牌上。“戚氏造，民国三十六年七月半后七日。”她念了一遍，“和户籍册补录的日期吻合。这个‘戚’姓，和蜡像馆是什么关系？”

秦朗没答。他盯着蜡像指缝里那张纸角——墨迹未干的“第七条渡命人，七月半后七日，名在册上，人在渡口”。他把纸角抽出来，纸比寻常的宣纸厚，边缘带毛，像是从什么旧账本上撕下来的。翻过背面，空白。

他把纸叠好，塞进胸口的证物袋。

“船票。”他说。

顾言秋一怔。

“灰袍人说明日渡口会收新名字，要带着渡河人的账本才能填上空页。渡口、名字、空页——这三样东西合在一起就是一条过河的规矩。规矩要凭证，他说账本是凭证。但我们手上没有账本。”秦朗往外走，蜡像馆的门不知何时已经敞开了，夜风从外面灌进来，吹得蜡像衣摆猎猎地翻。他走到门口，忽然停下，“你刚才收到的那条短信，原话再发一遍给我看。”

顾言秋掏出手机，屏幕还亮着：“第七个证物不是棺材钉——是翻了一页的空白名册。”

“空白名册。”秦朗重复，“灰袍人说的是‘账本’，短信说的是‘名册’。它们说的是同一样东西，还是两样？”

顾言秋想了想：“户籍册是名册，渡河人的账本是账本。如果它们互为副本——你父亲照片边缘露出的那个‘账’字封皮，会不会就是账本？”

秦朗没回答。他低头看了一眼锁屏照片——父亲站在雾津渡口，身后船只的剪影模糊，照片边缘确实露出深褐色封皮一角，上面一个“账”字，只拍进去半边。但父亲的手，是搭在另一个人的肩上的。那个人被照片裁掉了。

他盯了那张照片很久。父亲当年站在渡口，不是一个人。他身边有人。

秦朗把手机收回兜里，说：“回档案馆。”

“这个点档案馆关门了。”

“后门没关。”他补了一句，“归字门。”

顾言秋没再问。

两人从蜡像馆后巷穿出去，路灯灭了大半，雾津县这条老街像被墨汁浸过。档案馆后门那扇铁门半掩着，门缝里渗出一点灯光，照在门槛上，门槛边积了一层水，水痕平行七道——和井沿上的一模一样。

门缝里塞着一张纸条，字迹歪斜：“第三条渡命人，明日渡口，带名册填空页。见字如见路。”

纸条上没有落款。

秦朗推门进去。档案室里没人，但桌上多了一样东西——一本蓝布封面的线装册子，封面上没有字，边角磨得发白，和户籍册的材质相似，但更旧。册子旁边搁着一把铜钥匙，钥匙柄上刻着一个字：

“账”。

秦朗伸手去拿钥匙，指尖刚触到铜面，档案室的灯忽然灭了三盏，只剩最里头一盏昏黄的吊灯还亮着。两人同时看向吊灯的方向——灯下站着一个人影，身形佝偻，穿着一件旧灰布褂子，手里提着一盏已经灭了的绿灯笼。灰袍人。

但这一回，他脸上的灰布没遮严实，露出一小截下颌，下颌上有一道旧疤。

灰袍人开口，嗓音沙哑：“账本给你们送来了。名册在你们手上。明天渡口，新名字要上船——你们两个人中间，只能去一个。”

他说完，转身往档案室深处走。秦朗追了两步，灰袍人却拐进一堵墙里，不见了踪影。那堵墙上挂着一幅旧地图，雾津县的水系，河流交汇处标注了七个渡口。第七个渡口的位置，用红笔画了一个圈，圈内写着两个字：

“还魂”。

顾言秋走过去看那张地图，指着第七渡口旁边的一行小字，念出声：“七月半，渡河人收名。渡一魂，收一名。名满七，河门开。”

“河门？”秦朗问。

顾言秋目光停在“河门”两个字上，声音低了几分：“河门开后……渡河人就不需要再收名字了。”

秦朗忽然开口：“所以它收名字，是为了开门。名字就是钥匙。”

——门外忽然传来一阵极轻的咳嗽声，像是有人贴着门板在咳。秦朗猛地转身。门缝底下，塞进来半截黑伞伞尖。伞尖上挂着一根红绳，红绳末端系着一枚铜钱。铜钱正面，赫然刻着一个字：

“卒”。# 第587章 渡门（上）

秦朗蹲下去，没碰那枚铜钱，先看伞尖。黑伞的伞骨露出来半截，铁质，生了一层绿锈，和寻常雨伞的铜骨不一样。他抬头看了一眼门缝外——灯影里看不到人，只有伞尖横在那里，一动不动。

顾言秋也蹲下来：“铜钱上的‘卒’字，和失踪案现场留下来的那枚是同一批。”

秦朗从证物袋里取出之前红绳上系的那枚铜钱，两枚并排放在地上，都是旧铜的包浆，铸口位置相同，字口深浅一致。但伞尖上这一枚背面多了一行细字，不仔细看看不出来，在灯下转了几道角度才显出笔画：

“渡一人，记一名，卒于七月半。”

秦朗把两枚铜钱都收起来，伸手握住伞尖往外推。门缝外的伞尖被推回去几寸，却又被另一股力抵住，停在原地。秦朗加了力，门缝突然弹开一条口子，一只苍白的手从门缝外探进来，一把攥住伞尖，把整把黑伞抽了出去。动作快得只够看见手腕上一道青黑色的勒痕，像是被绳子反复勒过，结了厚痂。

门重新合上。门外再无声息。

秦朗站起身，把门拉了一把，门纹丝不动。从里面锁死的。

他回头看桌上的蓝布账本，翻开第一页，墨迹是新的，却写着旧日期——民国三十六年七月半，渡七人收七名，河门半开，第七名未至，门复闭。下面有一列名字，六个：梳头娘、典当客、系绳人、照相师、撑伞人、播音员。六个名字对应的六种职业，与六件证物一一对应。第七行是一片空白，只画了一个墨圈，圈里点了三个点，像是不知道该写什么。

秦朗把账本翻到后面，除了第一页，全是白纸。但纸页边缘有压痕，像是写过字又被揭走了一层。他把纸页对着吊灯照，纸背透出一行极淡的字迹，不是墨，像是渗进纤维里的陈年水痕：

“第七个名字是渡河人的名字。渡河人不能渡自己，所以河门永远差一渡。”

顾言秋站在他身后，把这行字读了一遍，沉默了一会儿，说：“如果第七个名字是渡河人自己的，那——名单上最后一个人，是谁？”

秦朗没答。他没说出口的是，户籍册上最后那个名字，是他自己。

他把账本合上，蓝布封面里夹了一张纸条，滑落下来。纸条上只一句话，字迹工整得有几分像印刷体：“名满七，河门开。河门开，渡河人便不再是渡河人。那册子上的名字会全部换新——包括你的。”

纸条底部有一行小字，被人划掉了，但划痕不重，勉强能辨认：“第七件证物从来不是棺材钉。棺材钉只是锁。”

“只是锁。”顾言秋低声重复了一遍，“那锁住的是什么？”

秦朗把纸条折起来，和纸角、铜钱放同一个证物袋。他走到地图前，手指按在第七渡口的红圈上，用力按了按，指腹下那块纸皮微微凹陷，底下像垫了东西。他掀开地图一角，墙里嵌着一只手指粗的铁环，铁环上系着一截红线，红线末端垂着一把钥匙——铜制，柄上一个字：“渡”。

秦朗把钥匙取下来，和档案室桌上那把印着“账”字的钥匙并在一起，齿口严丝合缝地咬合。两把钥匙合成一把，铜柄上的字拼成一个完整的字：“還”。

还魂的还。

他抬头看着第七渡口的红圈，窗外忽然传来一声极长的号子——像船工的吆喝，又像是从水底传上来的回响。声音拖得很长，在夜里格外清晰。秦朗看了一眼窗外，雾津河上浮起一盏绿灯，绿光摇摇晃晃地沿河而下，停在了第七渡口的位置。

渡口的石碑上，不知何时多了一行新刻的字，字口透湿，像是刚从河里捞出来：

“七月半，还魂夜。掌灯者上船，提账者上前，船上只载一人。”

秦朗攥紧那把合在一起的铜钥匙，往门外走。顾言秋跟上他：“你一个人去？”

“那条规矩说了——只能去一个。”

“你没想过那可能不是规矩，是陷阱？”

秦朗在门口站住，回头看她：“如果渡河人本来就是规则本身，那规矩就是它设的，也只能按它设的来。但你说得对——陷阱和规矩，有时候走到底才分得清。”

他推开门。门外那截黑伞已经不见了，门槛外横着一条水线，水线尽头，一双赤脚站在台阶底下。脚踝上没有勒痕，脚背上却有一串细密的针眼，像是被什么东西从下往上钉过。秦朗顺着脚踝往上看，那个人穿一身旧式灰布长衫，脸被一顶破草帽遮住，只露出下颌——下颌上一道旧疤。

灰袍人。

他开口，声音比在档案室里更哑：“钥匙带齐了。名册带了吗？”

秦朗没答，反问：“你带的是什么？”

灰袍人抬起手，掌心里有一只绿灯笼——灯笼里没有火，却亮着，光是从灯芯的位置渗出来的。他把灯笼举到秦朗面前，灯罩上映出一片纸影，纸影轮廓是他自己。

“这条渡船，一条命，一页名册，一把钥匙。少一样，船不开。”灰袍人说，“你身上带了两样。”

他说完，灯笼忽然暗下去，灰袍人的身形在灯灭的一瞬间矮了半截，像是被什么东西从脚底往下拉。秦朗上前一步，灰袍人已经不见了，原地只留下一只纸扎的绿灯笼，灯罩里贴着一道符——符上画着一扇门，门半开，门缝里写了一个字：“開”。

顾言秋从门里走出来，看了一眼那道符，忽然说：“这不是引路的灯笼，这是开门用的。”

秦朗盯着那个“開”字，想起蜡像指缝里那张纸条——“明日渡口将收新名字，需带渡河人的账本方能填上空页”。灰袍人送来了账本。灰袍人给了他钥匙。灰袍人在渡口等他。

每一样东西都是他主动送上门的。

秦朗蹲下去，把那只绿灯笼捡起来。灯笼底部浸着水，水痕是正圆的，不是随手沾上的——像是有谁把灯笼按在河里浸过一圈，再拿起来。灯笼内壁渗出一行极淡的字：

“你爹当年也提过这盏灯。”

他握着灯笼的竹柄，指腹摸到柄尾有一块粗糙的刻痕。翻过来看，柄尾刻着一个字，被水泡得发胀，笔画模糊，但他还是认出来了——一个“秦”字。

这是父亲用过的灯笼。

秦朗站起来，望向第七渡口的方向。河面上那盏绿灯还在，摇摇晃晃，像一只眼睛半睁半闭地等着他。他把灯笼提起来，绿光落在他脸上，他终于开了口：“走。”

他走向渡口。身后档案馆的门，在顾言秋跨出一步时，无声合拢。那扇门背上的旧水痕里，映出四个字，像是从河底浸上来的：
“别回头。”

# 第424章 纸上人

秦朗看着窗洞纸上那张闭目的脸，头皮像过了电似的麻了一瞬。牛纸皮上的水渍呈茶褐色，不急不缓地洇开，像被一只无形的笔在纸上描摹眉骨、鼻梁、下颌。那轮廓与他对镜时一模一样，甚至连左额那道三年前在追逃时留下的浅疤，也被水痕细细勾了出来。

顾言秋的手搭上他手腕，力道很紧：“别碰门。正对着那张脸走。”

“什么意思？”

“那是你的影相。渡河人把影子剥下来，画在纸上，等它睁开眼……你就不是你了。”她声音压得极低，却像从牙缝里挤出来的，“我爹笔记里有一句话，我背了很久——‘纸上人睁眼，水下人上岸。影脱壳，名入册，人成空壳。’”

秦朗心头一凛。他低头看脚下，影子还在，但更淡了，霉斑已经逼近影子的躯干部分，像一团脏水正从脚踝往上漫。而左手的灰线也猛地跳了一下，线端那三个小叉同时发黑。

“纸上的脸多久能睁眼？”

顾言秋从背包里摸出半截蜡烛，蜡烛泛着黄，像浸过桐油。她拨开打火机，将蜡烛点燃，火苗是惨白的：“这根蜡烛叫引路灯，我爹五十年前在渡口收的，烛芯里编了止水草——能压住门后的东西一阵。”她蹲下，把蜡烛立在门前石槛正中，白焰微微晃动，却没有歪，无论门缝里风怎么吹，火光纹丝不动。

门后的呼吸声忽然重了一拍。牛皮纸上那张脸的睫毛，似乎动了一下。

“快走。”顾言秋拽住秦朗胳膊，“绕走廊往西，从风眼那条道出去，渡口的规矩是绕门三匝谢水神，但今天不绕了。”

秦朗被她拽着退了几步，目光却钉在那扇门上。门缝里又传出那声叹息，这回更近，像贴在门板内侧说的：朗儿，你爹当年，也走到这儿了。

“你说过——你爹失踪在渡口。”秦朗站定，“那他是失足落水，还是走进去的？”

顾言秋拖住他的力道一滞：“你以为他是自己走进去的？”

“我父亲的口诀是‘渡河的规矩，问的是名，不是路，下水’。他当年查的案子，一定也查到了渡口。只是他没有铜扣。”秦朗低头看着掌心那枚“朗名”铜扣，字迹已经乾了大半，边缘重新变回铁灰，“他用什么开门的？”

顾言秋没有回答。她盯着那扇门，脸色比方才更白——门板底下的水迹，不知什么时候染上了颜色。原先漫出来的清水已经退去，取而代之的是一行暗红色的字，像用朱砂写的，缓缓从门板与地面的缝隙里渗出来，一笔一画，清晰可辨：第七个名字，在纸里。写完这句朱砂红字，门锁又“咔”的响了一声，像是门后有人在掰锁簧。

秦朗俯身，借着惨白的烛光读那行字。字迹的钩挑撇捺，和他父亲秦守信当年写在他作业本上的批注一模一样。

“这门后……不是渡河人。”秦朗抬起头，一字一顿，“门后是我爹写的字。他写过这扇门，他说第七个名字在纸里。”

顾言秋愣住。她蹲下来用指尖虚虚描过那行字，指尖竟沾上一层薄薄的朱砂粉末，像刚从纸上刮下来的：“这不是刻上去的，是从纸背面透出来的——这扇门不是木头，是纸浆糊的，糊了几十层，每一层都写过字。”

她站起来，指甲探进门板裂开的缝隙，稍一用力，剥下一片薄薄的纸皮。纸皮背面果然有字，墨迹晕染，却还可辨：“秦守望，民国廿四年渡口录。”

“秦守望？”秦朗瞳孔一紧，“那不是秦氏宗祠里族谱上的名字——我父亲说，那是他堂伯，死在民国廿六年涨水时。”

“可你父亲姓秦，你堂伯也姓秦。”顾言秋捻着纸片，“你父亲的出生年份有矛盾，你查过的——族谱上写他生于民国廿八年。民国廿八年，你堂伯已经死了两年。那你父亲到底是什么人？”

门锁又响了一声。这次换了个方向，像有人从里头拧了一下。

牛皮纸窗洞上那张闭目面孔的睫毛，又动了一下，这次更明显。眼角处渗出一线细水痕，像是要睁开了。

顾言秋一把抓过秦朗手腕，把他掌心的铜扣翻过来，翻到背面“朗”字下方的位置。那个位置不知何时起了细毫青纹，纹路蜿蜒成一个极小的图案——像三个绳结连在一起。

“三结绳。”顾言秋盯着那个图案，声音忽然低下去，“我爹笔记里写，渡口七忌中的第三忌，‘三结绳不可系棺柱’。这道纹——是和棺材铺有关的记号。”

秦朗还没接话，一阵湿冷的风从门缝里直刮出来，蜡烛的白色火苗被压得倾斜，却没有灭。烛光把走廊墙壁照亮了一瞬，秦朗看见了——门板后面的那层纸皮上，密密麻麻全是字。那些字层层叠叠，正缓缓透向前面的纸层，像墨在吸水纸上洇染。

最后浮现出来的字迹，是一行行名字。

第一行：“秦守望”。第二行：“秦望水”。第三行：“秦守义”。第四行……是“秦守信”，那是他父亲的名字。而在“秦守信”三个字的后头，还有一个空白，墨迹尚未成形，但在缓缓补着笔画——第一个笔画的起笔，是一个“秦”字的轮廓。秦朗的喉结滚了一下：“它要把我的名字，补上去。”

顾言秋猛地拽住他：“正对纸上名字的中心站。守着你脚下那块青砖。”

门外走廊尽头，传来一声极轻的锣响——第四声。

蜡烛火苗终于灭了。

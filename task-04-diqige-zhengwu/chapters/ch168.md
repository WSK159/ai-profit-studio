# 第168章 册子里的名字

黑暗并非纯粹的黑。秦朗感觉到有东西正在他的影子里蠕动，像是一条蛇在他脚下翻搅泥浆。他的声音发不出来，喉咙像是被什么东西堵住了，但那黑暗中传来的声音却清晰得可怕，带着一种陈年纸张翻动时的沙沙声。

“第七件证物……是你。”

这句话在档案室里回荡了三遍，每一遍都带着不同的音调。第一遍是老人的声音，第二遍是女人的声音，第三遍，秦朗听出来了，是他自己的声音。

顾言秋的声音从黑暗深处传来：“秦朗！你的手！你的手！”

他低头——他能看见自己的手。准确地说，他看见自己的影子正以一种违背物理常识的方式站立起来，像一张被风鼓起的黑白剪纸，从他的脚底缓缓剥离。影子手里握着一本册子，封皮的颜色完全被黑暗吞没，但秦朗能认出那轮廓——正是他们先前在黑皮无字册中所见的封皮样式。

“它从影子里长出来的。”顾言秋再次开口，声音压得极低，“别动，千万别动。”

但那影子已经在动了。它翻开册子，纸张一页一页地飞舞，像是被无形的手指快速拨动。每翻一页，秦朗的胸口就多一分冰冷，像是有人往他的肋骨缝隙里塞了一捧雪。当影子停在一页上时，它抬起头来。

没有五官。但秦朗知道它在看自己。黑暗的轮廓里有什么东西在注视，那种注视仿佛是从他的影子里向外投射的。

黑暗深处发出一声极轻的、像是竹筒落地的声响——啪嗒。紧接着，档案室的灯亮了。

那影子在灯光亮起的瞬间贴回地面，消失不见。秦朗的膝盖发软，一只手撑住了身后的档案柜。顾言秋站在三步之外，手里攥着一支钢笔，地上躺着一卷被她碰落的档案袋。

两人对视，谁也没说话。

秦朗低头看自己的手。手背上的皮肤完好无损，但他总觉得刚才那一瞬间，他的身体里少了什么东西。他仔细感受了一下——心跳还在，呼吸还在，手脚都还听使唤。可那种“少了什么”的感觉挥之不去，像是在胸口某个位置上有一个极小的缺口。

“你的影子。”顾言秋的目光落在他脚边，声音有些发紧，“刚才你影子的形状不对。”

秦朗顺着她的目光看去。灯光下，他的影子投影在地面上，轮廓正常，安静地贴在他脚边，像一个无害的倒影。

但秦朗注意到了——他刚才动了一下右手，影子纹丝不动。

他再动了一下，影子还是没动。

“它变慢了。”顾言秋显然也看到了，她蹲下身子，目光死死盯着影子，“不是没动，是在延迟。你动完之后大约两秒，影子才跟上。”

秦朗站在原地，没有继续动作。两秒。他刚才动了右手，影子要两秒之后才能跟上。这意味着他的影子不再与身体完全同步——它像是被什么东西拽住了一部分。

“册子里的名字，”顾言秋站起来，声音压得极低，“你影子的延迟，可能就是那个名字生效的痕迹。”

档案室的门口突然传来一阵声响，像是有人拖着脚步走过，在门口停了一瞬。秦朗猛地转头，门口空无一人。但那声响很清晰，不像错觉——是一种沉重的、带着布料摩擦地面的拖拽声，像是什么人穿着一件很长的袍子走过。

他追了出去。

走廊里空荡荡的，日光灯管发出嗡嗡的电流声。秦朗跑到走廊尽头，拐角处什么也没有。但他低头时，在地上看到了一样东西——一枚老式铜扣，裹着绿色的铜锈，形状像一枚民国时期军装上的扣子。

他将它捡起来。背面刻着一个极小的字：渡。

顾言秋跟上来时，他正捏着那枚铜扣站在拐角处。她看了看那枚扣子，脸色变了：“这东西……我在我妈那件藏在柜子深处的大衣上见过。一模一样。”

“大衣？”

“我妈说她年轻时候，有一次夜渡雾津渡，船上的人掉了两颗扣子，其中一颗被她捡到，另一颗掉进了水里。”顾言秋的声音越来越低，“她说那颗扣子她缝在衣领内衬里，是怕——渡河人不认生人。”

秦朗捏紧铜扣，金属的冰凉刺进掌心。他刚想开口，走廊尽头传来一声沉闷的钟响——是从档案馆外部传来的，雾津县老钟楼的指针声。十一点整。

距离七月半还差一天。

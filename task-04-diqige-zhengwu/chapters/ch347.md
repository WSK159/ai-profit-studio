# 第347章 童谣的字符

童声在雾里飘了不到五六秒便断了，像被人掐住嗓子。但那段旋律已经刻在三个人耳朵里，再想忘都忘不掉。

老周第一个反应过来，摸出手机想录音，屏幕亮起时才发现根本没有信号。头顶的月亮被一层薄云遮住，河面的雾反而淡了，露出灰白色的水面，泛着细密的波纹，像是有什么东西在水下缓缓游动。

“走。”秦朗压低声音，把红叶装进证物袋，拉上拉链，塞进胸口内袋，“天黑透之前先离开渡口。”

他们没有原路返回，而是绕道堤坝上方的土路，走了约莫四十分钟才回到停车的位置。直到把车发动，暖风吹上脸，老周才松开一直攥着的手掌，掌心全是汗。

“那歌谣——”老周边开车边说，“我好像在哪儿听过。不是戏匣子里的。更早，念书时候......”

顾言秋从后座探身：“你仔细想想，在哪儿听到的？”

“也可能不是听的。”老周犹豫了一下，“是我们那边老一辈的讲究，说渡口的小孩不唱这种调子，唱了会招东西。我没当回事，但有一年，我爷爷——”他忽然闭嘴，车速慢了一拍，“算了，记不清了。”

秦朗从后视镜里看了他一眼，没有追问。老周的爷爷，他听老周提过一次，民国时在渡口做过事。

回到县局已经将近后半夜。三人没去法医室，而是直接上了三楼档案馆的东侧小间——老周以前在这里存了一台旧式磁带录音机，本来是为了转录老戏用的。顾言秋把证物袋里的红叶铺在台灯下，灯光直射叶面的红漆伞形图案，那些漆迹在强光下显现出浓淡不一的层次。

“这个画的不是伞。”顾言秋忽然说，用镊子将叶片的边缘微微掀起，“伞面顶端的这个形状——你看，是不是一个盖子？”

秦朗凑过去。灯光下，红漆伞面的尖端画出一个微微凸起的弧形盖顶，如果单看这个细节，倒像——一口棺材的盖子。

“伞面是棺盖的形状？”老周皱眉，“那这画的是——棺盖下的伞？”

顾言秋没有直接回答，而是将那片叶子放在白纸上，用铅笔在纸面上轻轻描出图案的轮廓。描完后，她将纸转过来，让秦朗和老周看：“这个轮廓，如果你把伞柄倒过来看——像什么？”

纸面上，伞形图案倒置后，伞柄朝上，伞面朝下，那一圈伞沿勾勒出一个方形的边角。

“像一座桥。”秦朗说，“伞柄是桥柱，伞面是桥顶，伞沿就是桥基。”

“桥。”顾言秋点了点头，“渡口有一座桥，桥下是水，水下是门，门下是棺。这不是一个物件，是一条路——渡河人走的路。”

她说完这句话，小间的空气似乎冷了下来。窗户玻璃上凝结了一层水雾，像是有什么东西在窗外呼出了白气。老周走到窗边，用手套抹了一把玻璃，窗外黑洞洞的院子里，路灯下立着两棵梧桐，什么都没有。

但他注意到玻璃上的水雾凝结成一道弧线，从右下角弯到左上角，像一把伞的轮廓。老周没说出来，快步回到桌边坐下，把录音机的开关拨到放音档，按下播放键，磁带开始缓缓转动，发出“嘶啦嘶啦”的空白底噪。

这是之前从第五个失踪者家里带回来的那盘磁带，据说磁带A面录的是戏文，B面过了几十秒空白后有一小段人声。之前反复听过多次，人声模糊，只隐约能辨认出最后两个字——“等你”。这次再放，到了同样的位置，那人声比之前清晰了一些，像磁带受潮后又被烘干，反而恢复了细节。

“……民国二十七年……七月十五……渡上……第三次……你叫什么？”

那个声音更苍老，像七八十岁的老头，又带着一丝女人腔，像喉结与声带错位。老周立刻按了暂停，指着那个瞬间：“你们听，它说的是‘你叫什么’，不是‘你的名字’。”

“有区别吗？”秦朗问。

“有。”顾言秋接过话，“民俗里的‘收名’，问的是名字，不问人。你把自己的名字说出来，名字就到了对方手里；它不用知道你是谁，只需要拿着名字就够了——这是‘名身分离’的一种做法。但它问‘你叫什么’，这里多了一个主语。”

“这个主语用在什么场合？”秦朗追问。

顾言秋盯着录音机的指针：“用在——要叫别人代替你去死的时候。”

室内安静了几秒。磁带还在转动，“嘶啦嘶啦”的底噪在夜里格外清晰。然后，那声音又开口了，这次却快得不像老人：“你也叫秦柏舟？”

秦朗猛地把手按在桌上。

老周赶紧按下暂停，又倒回去重放。那句“你也叫秦柏舟”卡在磁带上一遍又一遍地重复，音质模糊，时真时假，像藏在噪音里听不清楚。老周把音量调到最大，秦朗听到了一个被扒开的声音——那句话后面还有半截，被什么东西盖住了，像有人用手捂住了麦克风，只留下一个气音。

顾言秋将录音带进监听耳机里，放慢速度反复辨认。她终于抬起眼，脸色发白。

“……你也叫秦柏舟，代他走回门里来。”

“代”字。那张旧照片上，秦柏舟名字后面，也写着一个“代”字——代谁？秦朗的父亲秦柏舟填的是这份户籍册上的位置，而他本人，又是替谁填的？那盘磁带仍在转动，已经到了B面尾声。沙沙声中，忽然传来极轻的、一下一下的有规律的敲击声，像有人在棺材板上叩了三下。咚。咚。咚。

然后，录音机像被无形的力量拨动了按键，“咔哒”一声跳到停止档，磁带自动弹出，落在地上，正好停在秦朗的鞋尖前。磁带侧面的贴纸上，不知何时多了一行字，字迹老式钢笔写就，像从民国的水汽里渗出来：

渡河人不收名字，收的是愿意替别人死的人。第七个，是你父亲，还是你？

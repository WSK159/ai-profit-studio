# 第108章 水渍下的字

雾津县档案馆三楼查档四室的灯亮着。秦朗站在楼梯口，盯着那扇门看了整整两分钟，灯没有灭，窗边的身影也没动。

那人背对着他，肩膀微驼，像是被什么东西压弯了脊梁。

顾言秋从后面追上来，手里攥着那根白布条，喘着气问：“你在看什么？”

“查档四室，有人。”

顾言秋顺着他的目光看过去，脸色突然变了：“档案馆十点清场，现在凌晨十二点半，不可能还有人。除非——”

“渡河人不算人。”秦朗替她说完了这句话。

他往前走了两步，手按在腰间的配枪上。查档四室的门虚掩着，门缝里透出一道昏黄的灯光，像是有人特意为他留着门。秦朗伸手推门，门轴发出一声尖锐的呻吟，像是锈蚀了太久的骨头。

房间里，一个人背对着门，坐在档案阅读桌前。他穿着一身深灰色的中山装，袖子笔挺，脚上是一双老式的黑布鞋。桌面上摊着一本已经泛黄的档案册，他正用一支钢笔在一张纸上写什么。

“你好大的胆子。”秦朗开口，声音沉稳得像一堵墙。

那人停了笔，没有回头：“你来了。”

声音苍老，像是从深井里传上来的回音。

秦朗绕过阅读桌，走到那人正面——然后他看清了那张脸，整个人像被钉死在原地。

这是一张他已经十年没见过的脸。

“爸？”

秦朗脱口而出的那两个字，像一枚石子砸进死水，在寂静的房间内激出层层涟漪。那人放下笔，抬起脸来。他大约五十岁出头，面容枯瘦，颧骨突起，眼窝深陷，像被什么吸干了血肉。但那双眼睛，秦朗认得，那是他父亲的眼睛——眼尾有一道细长的疤，是多年前秦朗玩弹弓时不小心崩伤的。

“你瘦了。”秦明远说，语气平淡，像是昨天才见过面一样。

秦朗的手指微微发抖，他张了张嘴，想说的话堵在喉咙里，连一个字都挤不出来。

顾言秋跟进来，站在秦朗身后，望着那人的脸，又看了看桌上摊开的档案袋——是雾津县1956年人口登记档案。她瞳孔骤缩：“你……在改名单？”

秦明远没有回答她，只低头看着那支钢笔，沉默了一会儿，才把纸翻过来，让两人看。

纸上只有四个字：代写无效。

“户籍册上，秦朗的名字是代写的。”顾言秋低声道。她想起老周说过，渡河人只收“纸上有名”的人，而名单上的名字，必须由本人亲笔书写、或者本人明白知晓并同意才能有效。

“所以当年，有人替你写了名字——你根本不知道，对吗？”顾言秋逼问。

秦朗的父亲放下笔，看着秦朗，眼里有一种说不清的疲惫与悲哀：“我不知道。等我知道时，我的名字已经在上面了。”

秦朗终于找回自己的声音：“所以这二十五年，你一直活着？你只是……被这个名字困住了？”

秦明远没有正面回答。他缓慢地摇头，像在摇头否认一件自己都不敢面对的事。然后他抬起手，指着窗外：“你听。”

秦朗屏息，夜风从窗缝里渗进来，带来远处水流的声音——雾津渡口的河水，在泛着白沫的黑暗中翻涌。那不是浪潮，是有人在河面下拍水的声音。

“每一次渡河，他都要名单人填满。”

“什么？”秦朗瞳孔收紧。

“渡船上有七个位置。七个人，不多不少。你父亲这些年在河底撑船，看见每一个名单人落水，都会变成新的一页。”秦明远说，“张桂芬的名字被划掉了——因为她已经走完了。下一个，是你。”

顾言秋猛地攥住秦朗的袖子：“别听他的！老周说过，渡河人不会放过名单上的人——”

“老周说的没错。”秦明远笑了笑，笑意未达眼底，“但他没说全。渡河人收走的人，有一个可以豁免。”

秦朗问：“谁？”

秦明远看着秦朗的眼睛，一字一顿地吐出两个字：“替身。”

窗外，雾津渡口的河水拍了一声，又一声。

# 第506章 门板上的第七道纹

顾言秋的手电光在门板上扫过一遍，又扫回来，停在那行字的下方。

“秦朗，你看这里。”她的声音压得极低，仿佛怕惊动什么，“门板右下角，那行字下面还有纹路。”

秦朗蹲下身。他先前只顾着看“名字到齐，门自开”那几个字，没留意底下还有东西。此刻借着电筒的光，他看清了——门板底部的木纹里，刻着七道细线，每道线不过指头长，间距均匀，像是被人用刀尖一点一点划出来的。

第一道线干净利落，边缘光滑。

第二道线旁边刻着一个米粒大小的“梳”字。

第三道线旁是个“典”字。

第四道线旁是“绳”字。

第五道线旁是“照”字。

第六道线旁是“伞”字。

第七道线旁是“播”字。

六道线下都有字，只有第一道线光秃秃的，什么都没有。

“六件证物。”秦朗盯着那六个字，声音发沉，“木梳、铜钱、红绳、旧照片、黑伞、磁带，对应的就是这六个字。那第一道线呢？”

顾言秋没答话。她伸手去摸那第一道线，指尖刚触上去，眉头就皱了起来：“这不是刻的。”她凑近了看，“这是天生的纹路，树本身的纹理，横着长的一道疤。其他六道才是后来刻上去的。”

秦朗心头一凛。他想起档案里那位老木匠说过的话——“棺材板讲究顺纹取板，疤疤癞癞的木料做不了棺，有疤的地方容易裂，裂了就漏气，漏气就养不住肉身。”

那道天然的疤纹，正好卡在所有刻痕的最前头。

“等等。”秦朗猛地直起身，“你说这扇门叫‘活门’？”

顾言秋点头：“我父亲笔记上是那么写的——第七闸，活门，钉影处。”

“那前面六道刻痕呢？是不是对应另外六道闸？”

顾言秋愣了一瞬。电筒光晃了晃，她翻出手机，点亮屏幕，点开一张照片——那是她拍的笔记页面。秦朗凑过去看，铅笔绘的剖面图上，渡口底下画着七道闸门，前六道都用细线勾出框形，标注零零碎碎的字，唯有第七道闸，框线画得格外粗重，旁边用红笔写了两个大字：活门。

“前六道闸的标注呢？”秦朗问。

顾言秋把照片放大，但年代久远，铅笔字淡得几乎看不清。她只辨认出几个残字：“……梳、……桥、……井、……庙……”

“桥、井、庙。”秦朗喃喃重复。雾津老县城的地图在脑中铺开——城东有座石拱桥，桥底压着一口枯井，井旁曾经有座城隍庙。这些地名他在卷宗里见过几次，都是老案子的案发地。

“那第七道闸是渡口。”秦朗的目光落回门板，“前面六道闸各对应一件证物，最后一道，对应棺材钉。”

他话音刚落，那把断钥匙突然发出一声极轻的嗡鸣，像是金属片子被指甲弹了一下。秦朗和顾言秋同时后退一步。

门板上，那道天然疤纹的缝隙里，渗出一滴极细的黑水，顺着门板淌下来，落进河滩泥地。黑水落地，没有渗进泥土，反而凝成一颗圆溜溜的小珠子，在电筒光下泛着暗沉的光。

秦朗盯着那颗珠子，手电光抖了一下——珠子里头，隐约映出一个“七”字。

顾言秋也看见了。她喉咙动了动，开口时嗓音发紧：“你刚才说，你血不在册上，所以门不开。但如果那本册子不是门唯一的钥匙呢？”

秦朗看向她。她盯着门板上那七道刻痕，声音越来越低：“前六道刻痕对应的证物都到齐了，第七道对应的棺材钉也钉在你影子上——但门还是没开。你说，会不会缺的不是第七件证物，而是……”

她顿了顿，电筒光移到第一道疤纹上。

“而是那道天生的纹路，对应的那个东西。六道刻痕都是外物，只有那道疤是门板自己长出来的。是不是非得用什么‘天生的东西’，门才认？”

秦朗还没来得及回答，灰影动了。

它一直站在水边，一动不动，此刻却缓缓转身，面朝着门板的方向，抬手，指向那道疤纹。灰扑扑的手指头，没有指甲，却准确地指向那道天然纹路。

然后，它收回手，慢慢放进自己胸口，掏出了什么东西。秦朗看见那东西的轮廓时，浑身一阵凉意——那是一张泛黄的纸片，纸片边缘被水泡得起毛，正中间，写着一个墨迹干涸的名字。

秦朗认得那个字体。他太认得了。

那是他父亲的字。

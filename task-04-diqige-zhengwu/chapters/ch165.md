# 第165章 船票

顾言秋打开手机的照明，光线不算亮，但足以让他们看清前方的路。档案室C区尽头，有一扇他们来的时候没有注意到的门。门是旧的杉木板做的，没有把手，只在正中钉着一条铁皮，铁皮上有一个敲凹的印记。秦朗蹲下去看，那个印记是一艘平头船的轮廓。

“这扇门不该在这里。”顾言秋说，“雾津县档案馆是1987年建的，全馆统一用钢制防火门，从来没有杉木板门。”

秦朗伸手推了一下门。门没有锁，或者说，它根本没有锁的构造，手指一碰到木板，门就向内开了，无声无息，像是等了他很久。

门后是一间小小的、没有窗户的房间。大约四平米，四壁刷着老式的石灰墙，墙角有潮斑，地上铺着一层青砖。房间中央放着一张老方桌，桌上摆着一盏煤油灯，灯芯还在燃着。煤油灯旁边，整整齐齐地码着一摞船票。

顾言秋快步走过去，手指从那些船票上滑过。她的脸色在一瞬间变得很难看：“这跟木匣里的票是一个格式。民国三十年的、四十二年的、六三年、七九年、九九年……都有。”

秦朗凑过来。灯光下，那些船票的纸质已经泛黄发脆，但上面的字迹仍然清晰。他的手突然停在一张票面上：那一张的日期是二十五年前的七月初十——老周曾无意间提过，那是秦朗父亲失踪的日子。而乘客栏里的名字，三个字，第一字是“秦”，第二字是“朗”，第三字还没有写上。空缺处有一道被指甲划过留下的深痕，像是一个写了一半的人忽然停住了笔。

“他的票没有写完。”顾言秋轻声说，“是因为他把自己换成了你。票上写了你的名字，但没法写全，因为他还没把你‘渡’过去。你父亲当年上的船，没有渡到对岸。”

秦朗握着那张票，指节泛白。他想起父亲失踪那年的事，很多细节已经模糊了，只记得最后那天早上，母亲蹲在门槛上，烧了一夜的纸钱没有哭。二十五年来，他一直以为父亲是溺水死的，或者是在外面出了事。从没想过，是这样一张票。

“如果父亲的票没写完……”秦朗抬起头，“那我的名字，现在是不是在接着写？”

顾言秋没有回答。她的目光越过秦朗的肩头，落在门口。秦朗顺着她看过去，门外那片漆黑里，不知什么时候多了一个人影。那人影不高，穿着一件老式的对襟褂子，头脸隐在阴影里，手里提着一盏纸灯笼。灯笼的纸上，用墨写着一个字——

“渡”。

“船要靠了。”那个影子开口，声音像是风穿过竹筒，干涩而空洞，“票，你们带了吗？”

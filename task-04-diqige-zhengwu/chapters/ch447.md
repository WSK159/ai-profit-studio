# 第447章 阁楼上的灯

第二天清晨，天刚蒙蒙亮。

秦朗没开警车，骑了一辆老式的黑色电动车，从县城出发往东骑了四十分钟，到了雾津县城关镇外沿的柳溪村。顾言秋坐在后座上，风把她头发吹得乱糟糟的，她没说话，从出发到现在只问了一句：“纸条的事，你信？”

秦朗当时没回答。这会儿，电动车停在村口一棵大槐树底下，他熄了火，转头看了看顾言秋：“柳溪村是我大伯秦守义住的村子，我父亲也在这里长大的。但秦家老宅不在村里，在村后的山腰上。”

“你父亲死后，那宅子谁在住？”

“没人住。大伯搬到村里是新修的平房，老宅从父亲死后就锁了院门。钥匙大伯一直收着，每隔半年去清一次灰。”

两人沿着村后的土路上山。路面是夯实的黄泥，被前几天的雨泡得发硬，踩上去有些硌脚。走了大约一里地，绕过一道山弯，秦朗一指前方山腰处一座灰瓦白墙的老宅——院墙两米多高，墙头爬满干藤，院门是一扇厚实的黑漆木门，锁扣上挂着把锈迹斑斑的铜锁。

“钥匙在大伯手里。”秦朗走到门前，摸了摸铜锁，又退后一步，仰头看了看院墙。

“你大伯在家吗？”顾言秋问。

“七月初八那天我奶奶忌日，大伯这半个月都在村里备祭。这个点，他应该在家。”秦朗掏出手机，拨了一个电话。响了三声，接起来的是一个干哑的男声：“谁啊？”

“大伯，是我。”

电话那头沉默了好几秒：“……是朗朗啊。这么早，有事？”

“我想到老宅阁楼上拿点东西。”

“什么东西？”

秦朗看了一眼顾言秋，斟酌着措辞：“我爹以前有只砚台，我想看看。”

电话那头又是一阵沉默。秦朗听到大伯那头有手推磨盘的动静，像牛嚼草料一样沉重地碾过。半晌，秦守义才又开口：“阁楼上黑，别开灯。”

秦朗握住手机的手指微微收紧——那纸条上的字，和大伯说的几乎是同一句话。

“为什么不能开灯？”

“灯一开，房梁上那窝野鸽子会惊。惊了鸽子，墙皮就掉了。”大伯顿了顿，“你爷爷在的时候说过，老宅阁楼的墙皮，不能掉。”

秦朗没追问。他知道大伯说话的习惯：他说“别开灯”的时候，真实的原因永远不会放在第一句。秦守义这个人，惯于先把一个最说得出口的理由摆在前头，剩下那些真正的原因，全藏在话缝里。

“钥匙在门槛底下第二块青砖底下，压着。”秦守义说完这一句，就挂了电话。

秦朗蹲下去，在门槛下的青砖缝里摸了一圈，果然摸出一把铜钥匙。钥匙齿上叠着深绿色的锈，插进锁孔时费了些力气，拧了三下，锁舌才弹开。

院门推开，发出一阵令人牙酸的吱呀声。院子里的石板缝里长出齐膝高的蒿草，晾衣绳上落着厚厚一层灰。正屋门虚掩着，秦朗推开门，一股陈旧的霉味混合着纸灰的气味扑面而来。厅堂正中摆着一张八仙桌，桌上供着一块牌位——背面朝着门。

秦朗没动牌位，径直朝堂屋一侧的木楼梯走去。楼梯又窄又陡，踩上去嘎吱作响。顾言秋跟在他身后，一手扶着墙。墙面上糊着旧报纸，年份是1986年的《雾津日报》，纸已经发黄发脆，贴在墙面上像一层干透的蝉蜕。

阁楼的灯——秦朗没有开。他站在楼梯口，借着楼梯间天窗漏下来的天光，扫了一眼阁楼的格局。低矮的坡屋顶下堆着几只旧樟木箱、一架缺腿的纺车、两只藤筐，墙角堆着一摞捆得整整齐齐的旧书，书堆旁边搁着一张黑漆斑驳的小桌，桌上摆着一只青灰色石砚。

砚台。砚台底下垫着一方黄纸，纸边从砚台下露出一角，纸张发脆、颜色发褐，像是被墨水和岁月同时浸透了。

秦朗走过去，伸手拿砚台。他的手指刚碰到砚台的边沿，头顶传来一阵轻响——像是有什么东西在瓦片上蹭了一下。他抬起头，阁楼的天窗上，落着一只野鸽子，灰白色的翅膀，歪着头，隔着一层积灰的玻璃看着屋内。

秦朗没有动，那只野鸽子却先飞走了。翅膀扇动的声音在屋檐下荡了两圈，消失在院外。

他低下头，把砚台拿起来。黄纸摊开——纸上没有字，只有一道深深的长条凹痕，像谁用指甲在纸上反复划过留下的印子。凹痕一头宽一头窄，长约三指。

“这像什么？”顾言秋凑过来。

秦朗翻过黄纸背面，还是没有字。他沉默了几秒，把黄纸对着天窗的光，侧过来看——光穿透纸背，凹痕内部透出一种极淡的、几乎不可见的棕红色，渗入纸纤维深处。那不是指甲划的。

那是毛笔蘸着沤过水又晒过的土漆，写上去的字，放了几十年，墨色退尽，只留下凹痕。字迹的轮廓，是一个“渡”字，而这笔画的收尾处，正和昨夜渗入青石板那个“渡”字是同一种手笔。

秦朗握着黄纸的手指微微抖了一下。阁楼的阴影里，靠着墙角的老座钟忽然“铛”地响了一声——停摆多年的钟，自己走了一下。钟声落下时，他身后的顾言秋轻轻吸了口气：

“秦朗，你影子。”

秦朗回头，天光打在楼梯口的背面，他的影子投在阁楼西墙上。影子的脚踝处，那根细黑线已经爬到了小腿中部，像一条绕在腿肚上的蛇。

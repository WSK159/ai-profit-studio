# 第400章 渡字

铜片、铜元、黑布条、棺材钉，四件物件在他掌心里合成了什么，秦朗不知道。他只感觉左手骤然一沉，仿佛捧着的不是几两铁器布料，而是一整块灌了铅的棺材板。

齿轮咬合的咔嗒声停了。黑布条收拢成一个字——“渡”，暗纹深深嵌进铜片表面，笔画像是被烧红烙上去的，边缘还泛着暗红的余温。

顾言秋站在他身侧，呼吸急促，她盯着那个“渡”字，瞳孔微微收缩：“这不是符……”

“是什么？”

“是路引。”她嗓音压得极低，像是怕被什么东西听见，“南方渡口摆渡，活人过河要船票，死人过河要路引。这东西，是给死人用的。”

秦朗没说话。他的影子还钉在地上的棺材钉上，左脚动弹不得，右半边影子却已经立了起来，斜斜地搭在墙壁上，像一个人侧身靠着墙等他。他余光扫过去，那半边影子竟然微微转了一下头，似乎在看他手里的“渡”字。

走廊里的那两声呼唤已经停了。小屋陷入死一般的寂静，只剩收音机的电流嘶声偶尔跳一下，像某个频率正在努力搜索信号。

“你说，渡河人让我顺着他的路走。”秦朗低沉道，“如果我不走呢？”

顾言秋愣了一下。她从来没想过这个问题。民俗资料里，渡河人引路是既定规矩——名字被写上纸的人，听到呼唤就必须回应，回应了就必须跟上，直到走入渡口深处。没有人尝试过拒绝，或者说，尝试过的人都已经不在档案里了。

“我把它拼起来了，它却停下来了。”秦朗低头看着掌心，“它在等。”

“等什么？”

“等我把它放回去。”

顾言秋猛地抬头，对上秦朗的眼睛。那双眼睛在暗黄的灯光下格外黑亮，像两口深不见底的井。她忽然明白了他说的是什么意思：渡河人要的从来不是他跟着走，而是把这件“渡”字合起来。四合一的物件根本不可分——铜片需要铜元嵌合，铜元需要棺材钉封孔，三者需要黑布条捆扎——它们是同一把钥匙拆成的四个部分。而秦朗，是那把钥匙的“柄”。

钥匙齐了，门才能开。门开了，渡河人才能——过河？还是从河那边过来？

“你打算做什么？”顾言秋听见自己的声音有些发紧。

秦朗没有回答。他蹲下身，缓缓将手中四合一之物放到了地板上，然后手指松开。没有任何异常发生。但那枚被钉住影子的棺材钉，突然“咔”地一声，从地面弹了出来——像是有一只无形的手，从地板另一侧把它拔了起来。

秦朗的左脚恢复了自由。影子剧烈地颤抖了一下，像一个被按在水底很久的人终于浮出水面。然后他脚底那条灰白色的线开始飞快蔓延，从小腿爬上膝盖、大腿、腰际——速度比之前快了一倍不止。

顾言秋猛地冲过来想拉开他，但她的指尖刚碰到秦朗的手腕，那枚铜片上的“渡”字突然亮起来，像烧透的炭火灼目。她的指尖猛地一缩，像是被烙了一下。

“……它在换。”秦朗低声说。

“换什么？”

秦朗低下头看着自己的身体，看着那条灰白色的线在大腿处隐约停下，像涨潮的海水暂时触到了堤岸。他沉默了两秒，抬起头来时，嗓音里带了一丝她从没听过的沙哑：

“它在拿我的影子，换一个‘渡’字的位置。”

他说完这句话的瞬间，屋子深处的阴影里，传来第三声呼唤。这一声与前两次截然不同——不是喊他名字，而是一段极短极模糊的唱词，像收音机里那个女声在唱戏。

“过河——人呀——莫回头——”

顾言秋脸色剧变。这句唱词她听过。在省民俗研究所那卷录音带里，七十年隔着电流传来的同一句。而那卷录音带的封面上，写着一个她永远忘不掉的名字。

“秦朗，”她的声音开始发抖，“这句戏……是我父亲唱的。”

秦朗站在原地没有动，灰白的线停在腰际。他手里的“渡”字铜片已经凉了下来，但那上面多出一行极细的字，像是刚刚被什么东西刻上去的。

他低头一看，字迹已经淡去，只留下最后一笔隐约可辨：

“纸上有名，渡上有路，第七件证物，开的是你自己的门。”

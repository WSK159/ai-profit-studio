# 第264章 水迹函

顾言秋盯着脚下那行从水洼里浮出来的字，嘴唇微微发白。后院青砖地的缝隙里渗着潮气，那行字迹像是从砖缝里自己冒出来的，一笔一划墨迹浓重，落在积水上却不晕散，仿佛写完后才生了根。

“七月半……三天。”她蹲下身，手指悬在那行字上方，没有碰。

秦朗站在她身侧，手里的电筒光束扫过那行字——周小满葬身处，芦苇荡东段，老渡口下游三里——他抬头，目光穿过院墙望向老城区方向，那里雾色深重，什么也看不见。

老赵头还站在原地，脸上的表情在雾里看不出是悲是喜。秦正阳那张脸早散了，浓雾团收回院角，像一条蛇缩回洞穴。

“三天。”秦朗开口，“够。”

老赵头嗤笑一声：“你打算做什么？”

“挖棺材。”

老赵头眼皮一抖，没有接话。他想了想，开口时声音低了不少：“你知道那棺材里有什么。”

“真册。”秦朗收了电筒，“还有一个被钉死的渡河人。”

老赵头沉默了一会儿，浑浊的眼里印着院灯的昏黄：“你爸当年也这么想。棺材是他亲自钉的。”

秦朗握电筒的手指收紧了。这是父亲最后一次出现在案件记录之外的信息。他转向老赵头，试图从那张满是褶皱的老脸上读出一丝说谎的痕迹，但老赵头只垂下眼：“棺材钉四枚，钉在四角，钉子入木三寸，末一根是第七天打进去的。打完那颗钉子，你爸就走了，再没回来。”

“他死在哪儿？”

“渡口。”老赵头说完这两个字，伸手搓了搓鼻子，“他死前烧了那本假册，然后把自己的名字写在纸上，贴进棺材里，代替册子躺在里头。渡河人要收的是他。”

顾言秋站起身，目光和老赵头对上：“那他二十六年前渡河了吗？”

老赵头没有回答。

秦朗盯着老赵头，脑子里那些碎片忽然拼出一道裂缝。父亲死在渡口，但没人见过尸体。案件档案里只写了“意外落水”，他当时还小，母亲从不提细节。现在老赵头说父亲把自己的名字贴进棺材——那就是说，父亲之所以死，是为了让渡河人“收”他，而不是去收册上其他人。但父亲为什么要烧假册？

“你告诉我这些，”秦朗的声音很平，“想让我做什么？”

老赵头笑了：“什么都不用做。渡河人给了我一条命，我替它盯你父亲的后人。秦朗，你以为我是你爸的朋友？不是。他是抓我的警察。”

空气凝住。

顾言秋看向老赵头那双手——老而不枯，指尖干净，一个常在渡口走水的人不该有这么干净的手。她开口：“你是渡河人养的‘系绳人’。”

老赵头没有否认，只把目光落在秦朗脸上：“我盯了你二十六年，今天该说的说完了。七月初一之前，你自己选。”

他说完这话，转身朝雾里走，佝偻的背影很快被雾气吞没。院角那团浓雾也缓缓散去，像从未出现过一样。

秦朗站在原处，手心的电筒还在亮着。顾言秋走近他，声音放轻：“你信他说的？”

“信一半。”秦朗低声说，“剩下一半，得去问棺材。”

他顿了顿，又说：“杜秋月的牛皮纸袋里装着的那张残页——上面写的‘系绳人’，你还记得吗？那个被剪去的名字，现在有主了。”

顾言秋从口袋里掏出那张残页——杜秋月留下的遗物，她一直贴身带着。残页边缘烧焦，中间只留半行墨字：“系绳人·赵……”

她低头看了一会儿，脸色微变：“老赵头姓什么？”

秦朗沉默一息：“赵德兴。”

顾言秋把残页翻转过来，背面的铅笔字迹被水气洇过，有些模糊，但依然能辨认出最下面一行小字：“德兴，民国二十九年生，渡口系绳人，渡河人代行者。”

秦朗没有接茬，只说了一句：“三天够不够？”

顾言秋把残页收好，抬头看他：“够。”

她语气很慢，像每次要下结论的时候：“但秦朗，里面那本真册上，应该已经有你的名字了。”

# 第428章 门缝里的父亲

秦朗只看了一眼，就认出了那双眼睛。

秦守信生前是个寡言的人，看人的时候总带着一种莫名的警觉，像是一条老狗在听夜里的动静。现在门缝里那双眼睛跟记忆里一模一样，连眉骨上那道旧疤的位置都丝毫不差——那是秦朗八岁那年，秦守信在渡口修船时被铁钉划伤的。

“爸。”秦朗喊了一声。

门缝里那张脸没有回应。秦守信的嘴唇只是一张一合，反复重复那两个字：别进。别进。别进。像是某种卡了带的老录音机。

顾言秋往前凑了半步，忽然顿住：“不对。秦朗，你仔细看——你爸的眼睛在看哪？”

秦朗一愣，顺着父亲的目光望过去。秦守信的眼睛并没有看向秦朗，而是死死地盯着秦朗脚边——那里什么都没有，只有地面上还没干透的那滩水渍。

不。不对。

秦朗蹲下去，凑近那滩水渍。水是干净的，倒映着走廊天花板上那盏白炽灯，还有他自己蹲在灯下的身影。

等等……影子。

他明明影子已经消失了，可水渍里的倒影却清清楚楚地映出一团黑影，立在他身后，静静地站着。那团黑影的轮廓比秦朗高出一寸，肩膀也更宽，像是有人站在他背后，正弯着腰看他看水。

秦朗猛地回头。

身后空无一人。

但水渍里的那团黑影动了——它缓缓抬手，从胸口的位置取下一枚什么东西。铜扣。圆形的，铜绿色，跟秦朗制服上衣第二颗纽扣的位置一模一样。

“它在提醒你。”顾言秋的声音压得很低，“你爸是在让你看你的影子。”

秦朗又低头看水。那团黑影已经重新站直了，手里那枚铜扣在灯光下微微发亮。秦朗下意识地摸向自己胸口的第二颗纽扣——还在。但扣子背面，他摸到一条细细的缝，像是被什么东西从中间划过。

他把扣子翻过来。

扣子背面刻着一个字。

“渡。”

秦朗的呼吸停了一瞬。这枚扣子是他三年前在旧货市场买的，那时候背面光滑干净，什么都没有。也就是说，这字是最近才出现的。它怎么出现的？什么时候出现的？谁刻的？

他抬起头，门缝里秦守信的脸已经消失了，只剩下那团黑暗和那对没有瞳孔的眼睛。那个东西又变回了“制服秦朗”的样子。

“时间不多了。”门里说，“香还剩半炷。”

秦朗低头看门框——门框的缝隙里不知什么时候插了一根细香，灰白色的烟直直地往上飘，已经烧了一半。香灰落在地上，攒成一小堆，颜色暗红，像干涸的血。

顾言秋走近门框，盯着那炷香看了看，忽然伸出两根手指夹住香头，掐灭了火。

“既然规则先说好再用人，不如把账算清楚。”她转过身，背靠着门板，目光直视门缝里那双眼睛，“第一，你说秦守信顶了秦朗的位置二十五年——那二十五年前，是谁把秦守信的名字写进册子的？第二，你刚才说秦家的第七子‘生于落水时，死于进水时’，秦朗的生日是四月初三，雾津渡头的水位在四月初三从没过过河面。第三——”

她顿了顿，从口袋里掏出那枚“以水渡水”的铜片，举到门缝前。

“这个，你认识吗？”

门缝里的那双眼睛，骤然收缩。

# 第387章 半个字

石室里静得能听见水声从远处涵洞里一滴一滴漏下来。顾言秋说完那句话后，空气仿佛变成了实质，压在两个人之间。秦朗没有追问。他看见她肩头那个“停”字的瞬间，脑子里有一根线猛地绷紧了——但他说不上来为什么。

他先将手里那枚木质薄片举到光下细看。“徐木匠制”三个字刻的极浅，几乎是用指甲深的力道压出来的，像是执刀的人在雕到一半时连刀刃都不愿再用力。薄片背面那枚铜钱图案的方孔内缘光滑，有一道细微的磨损痕迹——那是被什么东西反复穿磨出来的，像是一根线或者一根指骨曾经在这里穿过无数次。

秦朗把那枚薄片翻过来翻过去看了三遍，最后一放手，让它落进自己口袋里。他听见衣料摩擦的声音，仿佛那木片落袋的瞬间有什么东西跟着落了进去——也许是错觉，也许不是。

“你翻到过自己那一页，”他转向顾言秋，声音压得沉，“纸上的字是什么时候被写的，什么时候被‘停’的？”

顾言秋靠着一侧墙边坐下，手电筒放在膝上，光斜斜地投向上方。她的手指无意识地捻着肩头那道裂口，顺着那个“停”字的轮廓抚过去，像在做一件再自然不过的事。

“我第一次看到它，是十四岁。”她说，“那年暑假，我母亲带我回乡下整理外公遗物。在樟木箱底，有一本线装册子，封皮已经酥了。她让我把它拿到院子里去晒，说‘让风把潮气收走’。我翻开的时候，翻到了中间某一页——那张纸上写着我的名字，出生年月，还有一行小字。但那行小字被墨水涂掉了，涂得很用力，连纸都快划穿了。名字底下本该有籍贯和住址的地方，是一截空缺。”

秦朗蹲在几步外，没有打断她。顾言秋话音停下时，她指尖的摩挲也停了。她抬起头来：“那本册子，后来被我母亲烧掉了。她说是‘招邪的东西，留着害人’。可烧之前她翻到那一页，盯着那处被涂掉的小字看了很久。我当时以为她是不舍得，后来学了民俗学才明白，她看的是那截空白——因为她知道那里面原本写着什么。”

她顿了一下：“那行涂掉的字，只有一个字还能认清。是个‘渡’字。”

秦朗心里猛地一动。“渡”字。涵洞石室墙上凹坑里的那一截指骨。那截被他推断为“不是原配、被人打磨过”的指骨，恰恰也是从“渡”字上取下来的。他几乎脱口而出：“你母亲也见过那截指骨？”

“她不是见过。”顾言秋说，“她是‘守’过。”

手电筒的光忽然闪了一下。像是电池快要耗尽那样，昏黄地晕开几秒，又亮了回来。那一瞬的暗影里，秦朗似乎看见顾言秋肩头那道“停”字疤痕微微隆起——像不是伤疤，而是皮肤底下有什么东西在微微活动。光重新亮起时，那个字又恢复平整。

“我找到那根指骨的时候，”他站起身，走回凹坑前，手指摩挲着那个“渡”字的笔画边缘，“它也在这个‘渡’字里面。而你母亲守着的，也是一截指骨？”

顾言秋没有直接回答。她站起身，走到他身侧，同样低头看着那处凹坑：“我们家有一个铁盒，传了五代。铁盒的锁早就锈死了，但从没有谁去撬开它。因为我外公说过一句话——‘盒子里的东西见了生人气，就活。活了就收不走。’”

她举手，指尖碰了碰那处凹坑的边缘：“我去省所以后，第一年自己回了一趟老家。那次我把铁盒撬开了。里面不是指骨，是一截竹签，只剩一寸来长，签身刻着半个字。”

“半个什么字。”

顾言秋看了他一眼，目光像被水浸过的：“渡。”

她低头，从领口内侧掏出一个系着红绳的荷包。那荷包旧得几乎褪成了灰布色，她拉开系口，从里面倒出一截发黄发黑的竹片来，落在掌心里。竹片的一端有明显的刀削痕迹，断口齐整，像被人刻意切去了一半。另一端的字迹已经模糊，但那个“渡”字的余笔依然可辨。秦朗只看了一眼，就知道那半个字与墙上凹坑里的“渡”字的笔画缺口完美吻合——不是相似，是同一枚工具刻出的字，却被分成了两半。

“你家的盒子里是竹签。墙上凹坑里的指骨背后——”他顿了顿，“会不会也是一个‘守’字？”

顾言秋没有回答。她把竹签放回荷包，系好红绳，重新将领口整理平整。她做完这一系列动作后才开口：“我外公死前最后一句话，是跟我母亲说的。他说‘纸上的字不能动，动了就有人替。你替不了，秦家那孩子也替不了——除非他按第七件证物的规矩来。’”

秦朗沉默了很久。他低头看着自己口袋里的木片——那上面刻着他的名字，还有一枚铜钱，与母亲遗物中的铜元严丝合缝。他想起母亲临终前把铜元攥在手里，反复摩挲着铜钱边缘那道裂缝，嘴里喃喃的却是一句模糊不清的话。他一直没有听清。

此刻他忽然明白过来，那句话是：“渡字半边是船，半边是路。”

而那枚铜元的边缘裂缝，恰好把“渡”字劈成了两半。他猛地抬起头，对上顾言秋的眼睛。她像是已经预料到他要说什么，缓缓点了点头：“你母亲的铜元，是钥匙。墙上的‘渡’字背后，有锁。”

她话音未落，凹坑深处忽然传来一声极轻的“咔”。像是某样东西在石层中卡了多年后，终于松动了一点点。秦朗还没来得及低头去看，手电筒的光猛地熄灭，石室全黑。黑暗中，那声“咔”又响了一次——比刚才更近，仿佛从凹坑里爬了出来。

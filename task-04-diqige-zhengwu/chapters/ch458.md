# 第458章 铜哨之音

黑暗像浓稠的墨汁灌满暗渠，秦朗能听见自己心跳撞在胸腔里的闷响。顾言秋的手电筒落水前最后一瞬，他瞥见那枚铜哨从门缝里递出的轮廓——此刻正攥在他掌心，金属表面残留的体温早已散尽，只剩冰凉。

“你父亲的东西，”门内那个自称秦守望的声音沙哑地重复，“他死前让我交给你。”

秦朗喉结滚动，指尖摩挲哨身。雾津县城的老人们常说，渡口边的孩子都会吹一种铜哨，声音尖利能穿透三丈深的水。他父亲枕头下确实放过这个，小时候他偷拿出来玩过，哨口边缘有个小小的磕痕——他指尖摸到了，同样的位置，同样的凹陷。

“为什么会在我爹手里？”秦朗的声音在暗渠里回荡。

门内没有回答。那根灰白手指已经缩回门缝，只有门楣上“以水渡水”四个字若隐若现，仿佛在黑暗中微微发亮。

顾言秋摸索着抓住秦朗的手臂，她的指尖冰凉：“秦朗，手电筒掉下去的地方——”

话音未落，暗渠深处忽然传来一声闷响。不是水声，更像是金属碰撞石壁的回音，紧接着是水流加速的潺潺声。秦朗猛地侧头，在完全的黑暗中竖起耳朵。

水流声变了。先前是平缓的、近乎静止的流淌，此刻却急促起来，像是有什么东西在上游搅动了水面。秦朗握着铜哨的手指收紧，一种本能的警觉让他后退半步，将顾言秋挡在身后。

“你听见了？”他压低声音。

“嗯。”顾言秋的语气里带着一丝紧绷，“像是……有东西走过来了。”

脚步声很轻，几乎被水声掩盖，但秦朗在刑警队练出的听觉还是捕捉到了。那不是鞋底踩在湿滑石壁上的声音，更像是什么柔软的东西在涉水而行，每一步都带起细微的水花。

秦朗贴着墙根站定，右手摸向腰间——枪在，但在这条黑暗的暗渠里，枪对未知的东西未必有用。他手指搭在扳机上，呼吸放缓，全凭听觉追踪那个靠近的轮廓。

声音在约莫五步远的地方停住了。

暗渠里重新安静下来，只有水流的声音恢复了先前的平缓。秦朗没有动，他能感觉到那个东西就在那里，几乎是近在咫尺，却无声无息。黑暗中有什么东西在注视他——这种被凝视的感觉冷得像一根细针，扎在后颈。

“谁在那里？”秦朗开口，声音在石壁间撞出回音。

没有回答。但秦朗听见了一声极轻的吸气，像是那个东西在辨认他的气息。然后，水流声再度响起，那个脚步声缓缓后退，直到完全消失。

顾言秋的手心沁出汗来，抓着他袖口的力道松了松：“它走了。”

秦朗没有立刻放松，又等了十几秒，才呼出一口浊气。但他没来得及开口，掌心的铜哨忽然震了一下——只有一下，轻得像被什么东西弹了弹指。

他低头，虽然什么都看不见，却莫名觉得哨口正对着他，微微发烫。

“刚才那个东西，”顾言秋的声音有些发涩，“是不是冲着哨子来的？”

秦朗没有回答。他摸索着将铜哨在手指间转了半圈，哨身上似乎刻了什么——指腹扫过，能摸到一些细小的纹路，像是被反复磨过的刻痕。他想起小时候偷玩时，父亲把哨子抢回去的动作里带着近乎宗教式的谨慎，像是这件东西碰不得。

他沉默片刻，将哨子放进内袋，贴着胸口的位置：“走吧，出去再说。”

暗渠里没有别的出路。两人沿着来时的方向往回走，水流漫过脚踝，冰冷刺骨。手电筒没了，秦朗只能一手扶着墙壁，一手牵着顾言秋，在完全的黑暗中摸索着前行。

走了约莫百余步，前方忽然透进来一线微光。不是路灯的光，更偏昏黄，像是油灯或者蜡烛。秦朗脚步一顿，顾言秋在他身后也停下来。

“这个方向不对。”她低声说，“我们来时走的是另一侧——”

秦朗知道。暗渠走向没变，但光线来自前方夹角处——一条岔道，他们来时肯定没有注意到。他犹豫了一瞬，还是朝那线光走了过去。

岔道尽头是一扇半掩的木门，门轴生锈，露出一线昏黄的光。秦朗推开门，门内是一间不大的屋子，靠墙摆着一张木桌，桌上点着一盏煤油灯，火焰微微晃动。

桌边坐着一个人。

一个满头灰白头发的老妇人，穿着洗得发白的蓝布褂子，正低头用一把小刀削着一截竹片。她听见门响，没有抬头，只说了一句：“来了？”

顾言秋猛地顿住，指甲掐进秦朗手心。

老妇人抬起头，昏黄灯光下，那张脸和顾言秋有七分相似——尤其是那双眼睛，形状几乎一模一样。只是她的眼角布满细纹，眼珠浑浊，像是蒙了一层雾。

“香梅——？”秦朗听见顾言秋的声音在发颤。

老妇人放下竹片，慢慢站起来，目光穿过秦朗，落在他身后顾言秋的脸上。她看了很久，嘴唇动了几次，才挤出一句话：“秋秋，长这么大了。”

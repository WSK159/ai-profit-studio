# 《第七个证物》

## 定位

- 类型：悬疑刑侦长篇（刑侦 + 民俗怪谈 + 规则怪谈融合）
- 差异化：以"六件证物 + 一件未出现的证物"为结构骨架，每 10 章一个单元案，主线贯穿
- 目标读者：番茄/起点悬疑读者（《捞尸人》连冠 16 个月证明悬疑民俗大盘稳定）
- 盈利路线：番茄悬疑频道连载 → 有声书（悬疑类有声转化率高）→ 短剧/影视改编

## 结构说明

- 主线：雾津县连环失踪案，每起现场留一件"证物"，第七件尚未出现
- 双主角：刑警秦朗（不信邪）× 民俗学者顾言秋（信邪）
- 怪谈规则：证物会"动"；名字被写进民国户籍册的人会消失；渡河人不收"没名字的人"

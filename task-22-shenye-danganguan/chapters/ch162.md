# 第162章 影子看门

凌晨两点四十，林雾在厨房煮水。

他不敢回浴室，不敢看窗户，也不敢关灯。厨房的灯是白炽的，灯泡有点旧，照得墙瓷砖发黄。他把那本馆员手册摊在台面上，借着这盏灯，逐字读第十三遍十二条铁律。

第一条：不许在馆内叫全名。
第三条：不许数B区档案。
第六条：不许回头看归还窗口。
第十条：不许承认自己见过A-000。

十二条里没有一条提到影子。但手册封底内侧有一行小字，他之前从未注意到——印刷体的笔画很均匀，像是缝上去的：“影子不是你的。它是馆里借给你看门的。”

水开了。水壶鸣笛的一瞬，林雾下意识去提，手腕还没碰到壶柄，就听见身后有人在叹气。

极短，极轻，像叹气的人自己也怕被听见。

林雾没有回头。他握紧壶柄，把水倒进杯子，然后端着杯子转了个身——用这种不回头看的方式确认身后。厨房门口没人。但地上有一道水痕，从他浴室的方向一路延伸过来，断在厨房门槛前。水痕的尽头不是人的脚印。是一双和浴室地砖尺寸一样的倒影，干透的，只在中间有一小块湿——像是有人赤脚踩在那里，站了很久。

三点整。

林雾放下杯子，走进客厅，把窗帘拉严。他不想看窗户。影子的事还没解决，再看一眼窗户的反光，他怕自己真会承认“见过A-000”。

但就在拉窗帘的手碰到布料的瞬间，窗帘自己晃了一下。没有风。窗外的路灯照进来，在帘布上投出一个轮廓——那个人形轮廓就站在他身后不到半米的位置，低着头，身形同他完全一致，但动作慢了整整半拍。

林雾的影子，在窗帘上，正在看浴室的门。

它没看林雾。

它只是站在那儿，像一道被派去看守的岗哨。林雾忽然想起那张纸条上的话：“别把借阅卡带进B区。”又想起浴室归还者那句“替我把门关上”。他忽然明白过来什么——那条影子不是背叛他，也不是监视他。它是在“看门”。

它盯着浴室那扇门，是在阻止门里的东西出来。

三点三十三分，林雾的手机自动开机。

屏幕亮起，弹出一个直播间的画面。直播间标题：《深夜档案馆·凌晨场》。观众人数：998。弹幕一条条滚过，全是同一句话：“第999人已到。”

林雾低头看屏幕——那第999条弹幕的头像他没有见过；但他认得发弹幕的ID。是他父亲的名字。

弹幕写道：“A-000已归还，请查收。门开了。”

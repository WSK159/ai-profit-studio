# 第52章 老周的还书

走廊灯光亮到七成时，林雾看清了来人。

老周穿着那件洗得发白的灰衬衫，袖口卷到小臂，腋下夹着一本深蓝色硬皮书，书脊上没有字。他站在 D-07 门口，皮鞋尖还是朝里——但人不是朝里的，是朝林雾的。

"周哥？"林雾嗓子发紧，"你不是——"

"休假？"老周笑了笑，笑纹在灯下皱成三道，"换了个说法。我这叫人还在，档先销了。"

他从腋下抽出那本书，掂了掂，递给林雾："帮我放回收窗口。我签名了，但你知道，馆员自己不能还自己的书，规定。"林雾没接。他看着老周的脸。脸是真的，眼角的疤是真的，但老周握书的手指——那根小指缺了半截，而以前，老周的小指是完整的。

"你的手——"林雾说。

"扣款。"老周语气平淡，"'保管不当'，扣了半截记忆。小指那段，我记不清是怎么回事了，属于废料。"

林雾心里沉了一下。规则扣款，从记忆、影子、名字里扣。老周的影子呢？他低头看去——老周脚下没有影子。干干净净的地面，连一圈模糊的轮廓都没有。林雾没说话，把那本书接过来。

蓝皮书面冰凉，封皮上有一层细密的暗纹，像某种字迹被重复涂抹后留下的痕迹。林雾拇指一推，书页翻开一角。

内页上印着借阅人签名：林远山。借阅日期是十四年前。他父亲的名字，老周的档案，十四年前。林雾抬头："这是我爸借的？"

"不。"老周晃了晃头，"这是我替你爸保管的。他欠档案馆一本书，一直没还，我替他收着，扣的却是我的款。"他停顿了一下，目光落在林雾的外套内袋上，"你手里那张归条，C-019，'不许还回'——你爸签的，对吧。"

林雾没答。老周笑了笑，那笑声很轻，像水在纸面渗开："规矩是，欠账的还账，担保的偿命。你拿了归条，替他平了那笔账。可他欠的不止这一笔。"

他弯下腰，从皮鞋里掏出一张折得皱巴巴的纸，展开，递给林雾。纸上只有一行字，墨迹已经发黄：

"借出物：A-000 档案残页。借阅人：林远山。状态：已归还——于归还者手中。备注：归还物为假，真件在封面内层。"

林雾瞳孔微缩。他低头看手里的蓝皮书。他翻开封面，内里硬纸板的夹层里，露出一角白纸——像是被塞进去的，很久了。他指尖刚触到纸边，耳边猛地响起一声尖锐的"嗒"。

归还窗口的绿灯又亮了。那盏灯的亮度不稳定，一明一暗，像在催促。

老周后退一步，鞋尖朝外："你还有还书的时间。先还我这本，再谈别的。"林雾握紧书，快步走到归还窗口，把那本蓝皮书放进凹槽。绿灯闪了七下，像数数。第七下的时候，灯灭了。凹槽里那本书没有消失。

它静静地躺着，封面上的暗纹开始向外渗，像墨滴在纸面上洇开，逐渐拼出一行字："A-000 当前读者：──"后面跟着一个名字，但那个名字被一行黑线盖住了。黑线的尽头，斜斜地连着一行小字：

"借阅人：方晴。"

林雾的动作停在半空。方晴？她今天白班，下午 6:00 就走了。她什么时候来借的书？他回头想找老周——D-07 门口已经空了。老周像来的时候一样，无声无息地消失了。皮鞋还搁在门口，鞋尖朝里。只是鞋底内侧，沾着一片干燥的水渍，呈暗红色，不像茶水。

林雾站在归还窗口前，看着那行"借阅人：方晴"的字迹。窗外，深夜档案馆的钟声敲了四下。四点整，天快亮了。

他想起自己口袋里那封催缴信露出的字："写规则的人，会在你身边。"方晴，就在他身边。白班，每天都见到。他攥紧信封，往馆员休息室走，脚步踩在地砖上，清楚地听到两道声响——一道是脚落地的声音，另一道，慢了半拍，像影子自己的脚步。

走廊尽头，D 区那扇门缝里，暖黄色的光又漏出来一线，像台灯，像傍晚。

他听见门后面有人在翻纸页，动作很轻很熟稔。翻纸的间隙里，有一声轻笑——和林雾之前在 C 区听到的，是同一个声音。

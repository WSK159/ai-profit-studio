# 第304章 向下即向上

影子沉下去的速度很快，像被水面吸走。林雾低头的时候，脚边只剩一层薄薄的暗灰色，贴在地砖上，不再动弹。那团矮小的影子从他的身体里被抽走了——他借来的“位置”不见了。

方晴手里攥着那根灰蓝色丝线，指腹微微发麻：“它去了检修夹层。”

林雾没说话，直接蹲下来，把铁板边缘的灰土拨开。铁板嵌在墙面里的位置看起来无法移动，但他注意到一个细节——铁板右下角的固定螺栓没有锈蚀，表面有新鲜的压痕，显然是最近被人拧动过至少一次。他拧动其中一颗螺栓，金属纹路发出一声脆响，整块铁板向内松动了一寸。

“往后退。”他说。方晴退开两步。

林雾用力拉动铁板边缘，铁板向内侧翻了过去，露出后面一条向下延伸的金属扶梯。铁梯的阶面很宽，每级台阶的纹路呈密集的菱形压花，在微弱的光线下反射出暗哑的光泽。台阶上没有灰尘——最近有人频繁走过。墙上没有灯。扶梯尽头有冷气流涌上来，夹着纸页和干燥剂的味道。

“检修夹层？”方晴在身后低声问。

“下去看看。”林雾把铁梯上层的一根横杆握了握，金属凉到刺骨。他踏下第一级台阶。

他数着台阶。一级，两级，三级。到了第十八级，扶梯到头。他站定，脚落在水泥地面上，前方是一条狭窄的通道，宽度只容一人通过，两侧墙壁上贴着老式的吸音棉，灰黄色的泡沫板已经发硬，边角剥落。通道尽头是一扇半掩的木门，门缝里漏出一线昏黄的光。

林雾走向那扇门，推开。

门后是一间不足十平的小房间。房间中央摆着一张铁质桌子，桌面上摊着一本翻开的硬壳笔记本。窗式空调机在角落里轰隆作响，吹出带着霉味的冷风——这房间在档案馆楼体之外，却在电梯井的背后，墙根处能听到绞轴转动的声响，从天顶传下来。这是一间夹层——电梯井与外墙之间那道三十公分的空腔被扩大成室，从外面看不见，从建筑图上也算不出。门楣上钉着一张塑料牌，上面用马克笔写着一行字：“六楼。”

林雾走向那张铁桌。

硬壳笔记本摊开的那一页，写着一行熟悉的灰蓝色字迹，父亲的字。林雾认得那撇捺——他看了二十多年。纸上写的是：

“欠条：一条路。担保物：五年。借款人：林远山。债权方：五楼。备注：此路为归还之路，非借出之路。若走不通，担保物归五楼。另：我押了另一样东西在五楼认主——钥匙给错了。”

林雾把那行字读了两遍。钥匙给错了。他父亲在五楼押了东西，那东西认了主，钥匙却给错了。给错了谁？

桌面的另一侧，压着一张泛黄的便签纸，铅笔字迹，细瘦懒散，与他之前看到的那枚信封背面笔迹一致：“去找七号档案。它会带你上楼。记住——别数台阶。”

空调机的风叶咔哒一响，林雾抬起头。房间角落的阴影里，站着一个矮小的人影。它没有五官，身形轮廓暗灰，像一摊被压扁的光。那是他的影子——它没有上去。它站在阴影里，右脚的方向朝着房间的西墙。林雾顺着它的方向看去——墙面上有一道竖缝，缝隙里夹着一张借阅卡的一角，卡片泛黄，边角磨损，上面印着一个编号的第几个数字露了出来——“A-000”。

林雾伸手去抽那张卡片时，夹层上方传来一声清晰的门响——沉重、低沉，是一楼那扇防火门被人推开了。有人进了档案馆。方晴的声音从铁梯口传来，压得极低：“林雾，来人了。”

她顿了一下，声音变得更紧：“是馆长‘零’。”

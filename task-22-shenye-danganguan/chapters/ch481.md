# 第481章 铜币背面的名字

铜币上的“林雾”两个字，不是刻的，是长出来的。像锈蚀漫过铜面，笔划从金属内部渗出来，还带着一点温热。林雾伸手去碰，指尖刚触到那两个字，铜币微微一颤，翻回了正面——“门缝伸手”的图案正对着他。

图案里那只手，五根指头张着，从门缝里探出来，指尖之间连着一道极细的丝线。林雾之前一直以为那是装饰纹理，现在才发现，那丝线是有走向的——从手尖指向门缝深处，和掌心血痕的方向一模一样。

“别碰币面上的图案。”方晴从身后拦住他，声音发紧，“这不是铜币，是‘契’。有人在替你把名字写上去，签字的笔就是那支断笔。你没交出笔，但你的名字已经刻到契上了。”

林雾的掌心又开始发烫。他猛地握紧拳，断笔的紫檀木杆在指缝间硌得生疼。他低头看见“丁”形刻痕的边缘有细微的裂痕——刚才他握得太紧，木杆裂开了一道缝，缝里露出来一点本不该有的东西：

一截极细的、银灰色的线。

那不是木头的纹理。那截银线在他指缝间微微颤动，像某种活物的触须，正从笔杆内部往外探。林雾心里一动——他记起这截银线的颜色和质感，和C区墙上他看到的那道“改写的规则”丝线几乎一模一样。

“这支笔——”他刚开口，掌心的“走”字红痕忽然裂开一道血线，一滴血沿着指缝滑落，正落在铜币上。铜币表面的“林雾”两个字沾了血，像活过来一样扭曲了一瞬，然后缓缓显出一行新字：

“欠一物，还一物。”

方晴一把抓住他的手腕，指甲掐进皮肤：“看窗口。”

林雾抬头。归还窗口那扇半开的隔板后面，黑洞洞的通道里，有一只手伸了出来。不是影子的黑色，是蜡黄的、带着皱纹、指节粗大的老人手。那手从通道深处探出，停在窗口台面上，食指弯曲，对着铜币敲了两下。

嗒。嗒。

那声音，是林雾在D区走廊里听到过的。在第七扇门后面，有东西敲过两下门板——一模一样。

“它要你把铜币递进去。”方晴的声音像从牙缝里挤出来的，“但铜币上有你的名字。你递进去，就等于把自己借给了那扇门。”

林雾的手悬在半空。他的手指已经触碰到了铜币边缘。那枚铜币冰凉彻骨，可背面他的名字却在发热——那热度像一种牵引，正在拽着他的指尖往窗口方向拉。

他猛地收回手。

铜币没有被拉动，但窗口里那只蜡黄的手明显顿了一下，然后食指弯下去，像在找什么东西。那动作持续了三秒钟，手缩回了黑暗，通道里传来一声极轻的、像叹息一样的声音——“不急。”

台面上铜币“当”地一声翻转，正面朝上。门缝图案的手指尖上，那根丝线不知何时断了，剩下一截短须，指向林雾脚边。

林雾低头，看见墙根处那道无主影子已经不见了，原地留下了一行用灰写的小字——不是“回去”，也不是“走”，而是他父亲的字迹：

“笔里有人。别让笔写完。”

他攥着断笔的手微微一僵，指缝间那截银线已经缩回了木杆里，像什么都没有发生过。

方晴沉默半晌，说：“你还记得我之前告诉你，C区的规则丝线是银灰色吗？”

林雾点头。

“那截银线，和丝线是同一种东西。”方晴看着他，“你爸当年改规则，用的不是笔，是‘笔里那个人’。你把笔带出来了，就等于把改写规则的人带出来了。”

林雾低头，那根断笔安静地躺在他掌心，紫檀木杆在灯光下泛着温润的光——像什么也没发生，像一个再普通不过的旧物。但他知道，从今晚起，这支笔里那个“人”，记住了他递出去的铜币，记住了他名字的位置，也记住了他父亲在照片背面留下的那句话。

他将断笔塞回裤袋，抬头看向走廊尽头的第七扇门。门缝里，一道白光正缓缓变亮。那扇门，正在朝他打开。

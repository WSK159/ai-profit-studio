# 第133章 字条上的第三行

林雾把那张字条举到即将熄灭的路灯下，纸张边缘泛着旧黄色，像从某本档案里撕下来的边角。字条上只有两行字。

第一行：“零。还给你的。”
第二行：“别再借，旧账该清了。”

方晴凑过来看，路灯在她睫毛下投出细碎的影子。“第三行呢？”她问，“这纸的边缘有压痕，像是写过三行，被人裁掉了。”

林雾翻过纸背，指尖触到暗红色——像是干涸的印泥，又像血。他用指甲轻轻刮了一下，那暗红色竟开始蠕动，像是活的。纸背上浮出一行墨迹，字体与他父亲的一模一样，却写的歪歪斜斜：

“他们会在三点三十三分，把A-000送回A区。”

“回去。”方晴的声音骤然变哑，“回档案馆去。三点三十三分，现在是——五点四十分。不对，我的表停了。”

林雾低头看自己的腕表，秒针还在走，但时针和分针都停在三点三十三分。他又看了一眼手机屏幕，五点四十一，一秒不差地在跳动。他张了张嘴，却用沉默对方晴说了一件事：他们正同时活在两个时间里，一个往前走，一个永远停在三点三十三分。

“三点三十三分是十二铁律里不许睁眼的时间。”方晴低声道，“如果有人在那个时刻把A-000送回A区——”

“那么我不该在这里等到天亮，我得在三点三十三之前拦住那件事。”林雾说这句话时，脚已经朝旧书店的方向迈出一步。可他想起那张字条的第一行——“零。还给你的。”这东西是要还给谁的？是他的父亲把某个东西给了零，还是零把某个东西给了他的父亲？

灰雾街道两侧的店铺招牌都在缓慢褪色，像是光线在吞噬油漆。方晴跟上他，她的高跟鞋跟敲在青砖上，发出清脆的、像倒计时一样的声响。他们走到旧书店外墙那扇隐藏窗前，林雾把铜章重新嵌入凹槽，机关发出咔哒一声脆响，整个窗框向两侧滑开，露出黑黝黝的通道。

通道深处的黑暗里，有什么东西正在发出低沉的声音——不是风声，而是一页一页纸翻动的沙沙声，密集又急促。像是有人在翻一本永远翻不完的档案。林雾咬住牙，他记得这种声音。

他很小的时候，有一夜睡不着觉，走出卧室，看见父亲坐在客厅里，打开一本红色封皮的册子，一页一页翻着，那翻页的声音穿过十几年的时光，和此刻通道深处的沙沙声一模一样。

“那不是风。”方晴在他身后轻声说，“那是借阅室在整理新归还的档案。”

林雾没有再犹豫，他一步踏进通道，身后的窗框缓缓闭合。黑暗里，手机屏幕上的时间跳了一下——五点四十二分。而他腕上那只停住的表，指针忽然转动起来，朝三点三十二分靠近，像是有人在故意拨慢它。

沙沙声停了。

黑暗中响起一个陌生而温和的嗓音：“你终于来了。你替我收了一辈子的那份档案，该还给我了。”

林雾慢慢抬起手电筒，光束划破黑暗，照见前方几米处站着一个人，穿着一件旧灰色大衣，戴着圆框眼镜，嘴唇微微翘起，挂在嘴角的笑容和林雾照片里见过的一模一样。

那是他父亲的脸。

但林雾知道，那绝对不是他父亲。

因为在那张脸的下方，在他父亲的脖颈处，别着一枚铜色工作牌，上面写着四个字——

“归还者：零。”

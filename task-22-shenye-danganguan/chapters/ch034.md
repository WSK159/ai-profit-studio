# 第34章 借阅之名

3:33。

我本来闭着眼数秒，听见墙后传来一声极轻的敲击声——从D区休息室和工具间之间的墙缝里。没人敲墙的时候，墙不会发出“咚”地一声闷响。

我睁开眼，先看了墙，再看钟。3:33。

铁律第六条：3:33不许睁眼。

我闭眼太慢了。

但我没有看到什么东西。墙壁是白的，日光灯安静地亮着。我松了口气，然后低头——看见自己脚边多了一枚黑色金属回形针。档案馆的回形针都是黄铜色的，只有A区禁书卷宗夹上有黑色金属件。

我把回形针捡起来，指腹摸到针面上有一行极浅的压刻字：

“看过A-000的人，名字会从档案里消失。你父亲的借阅记录里名字还在，说明他没看完。”

我握着那枚回形针，站在休息室里，意识到一个更麻烦的事实：我父亲的借阅记录栏写得一清二楚——“名字”。他借走的东西，是他的名字。而归还期限是“无期”，意味着他一直没有还。

可A-000本身是被删除的档案。

如果一张档案已经被删除，它的借阅记录又怎么会存在？它被人借走了，而借走的东西，还能是什么？

我从口袋里摸出那只信封，撕开封口，里面只有一张对折的纸——是一张旧式档案卡，卡片顶部的编号印着“A-000”。档案卡标题栏的手写字迹，和我爸留在借阅卡上的字迹一模一样。

“此档案已被借出，借阅人：林致远。借出物品：名字。归还条件：档案馆收到另一份以‘林’为姓的档案。”

我的手指一紧。

归还条件——档案馆收到另一份以“林”为姓的档案。

整个档案馆，姓林的人，现在只有我。

我站在原地，听见自己的心跳撞进耳朵里。

那行字底下还有一行小字，显然是后续补注：“借阅人以其女名追加担保，档案转移至待归还态。”

“女？”我盯着那个字。

我父亲档案上的“担保人”栏，写着：林雾。

但女性。白纸黑字，女性的“女”。

“这不可能。”我出声说。

电话铃响了。

那是D区走廊尽头公用电话的老式铃声，原本接通的只有馆内分机线——但今晚，它响了，声音不大，却像刺破鼓膜一样尖。我放下档案卡，穿过走廊走到尽头，接起电话。

听筒里是沉默。我数到三，准备挂断时，对面传来一个声音。很轻，像用气音说话，但我认得那个音色——方晴。

“……林雾，你听我说。我父亲的档案里，担保人栏也有一个女人的名字——方晚。我从来没听说过她。但今天白班结束时，我在自己的工位上看到一张借阅单，上面的名字是‘方晚’。”她的声音停了一下，“就在刚才，我在B区值班室……看到了一张照片。”

“什么照片？”

方晴沉默了几秒：“一个女人的照片，她站在档案馆门口，脸上带着笑。照片背面写着——‘明天照常营业’。”

我握着听筒，闻到一股细微的焦味——从听筒的缝隙中漏出来的，像烧过的纸。方晴又开口了：“林雾，你有没有算过，我们直播间的观众数，加上档案馆里每一份以‘林’或‘方’为姓的档案数量……就是那个一千？”

我脑子里的线在瞬间连到一起。

直播间弹幕说“人齐了”，1000的观众数，加上A-000和她父亲的那份档案——就是1002。

两本以我们的姓为编号的档案，正对应的正是那个数字。

方晴的声音再度传来：“林雾，我在档案馆等你。天亮前，我找到了那个6字规则的出处。”她顿了一下，“那六个字不是给馆长说的，是给我的父亲。”

“明天别开那扇门。”

电话挂断。

我站在走廊尽头，听见远处B区方向传来铁门被什么东西从内侧撞击的声音——

咚。咚。咚。

三下。然后就是死寂。

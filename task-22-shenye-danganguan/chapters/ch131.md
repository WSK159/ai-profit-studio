# 第131章 债主的名字

路灯下的老太太穿着一件洗得发白的深蓝棉袄，花白的头发在凌晨五点的灰雾里像一团模糊的月光。她佝偻着背，干枯的手指里攥着一只怀表，表盖已经锈得翻不开了。

“你是林晓白的儿子。”她不是在问，是在陈述。

林雾深吸一口气，把方晴挡在身后。街面的雾气涌上来，脚踝处已经没了脚背。“您说，我妈二十三年前借了您一小时？”

老太太笑了一下，嘴角的皱纹像刀刻的沟壑。她把怀表举到耳边，晃了晃，里面发出细碎的沙沙声——“听，时间还在走。借走的那一个小时，我一直替她收着。”

方晴在身后低声说：“别签任何东西。”

林雾点了点头。契约规则他清楚：签名即生效，字迹无法涂改。归还者的那封信里，母亲已经写过警告——别信归还者。但眼前这老人真是归还者吗？她在路灯下出现的时机太巧，正好卡在M000信封被拆开之后。

“我不借时间，也不替谁还。”林雾直接开口，“我妈不欠您什么——如果她跟您有约定，让她自己来。”

老太太的笑容顿了顿，像一张旧照片被水洇湿了一角，然后她缓缓从棉袄口袋里掏出一张照片，递到林雾面前。照片上是一间旧书店，门口写着“明日书店”——白天的档案馆。林晓白站在招牌下，怀里抱着一个婴儿，笑得很浅。照片右下角印着日期，是他出生那年。

“你妈第一次来我这儿借钱，用的抵押物，是你。”

林雾手一抖，照片差点没接住。方晴从他肩后探过来看了一眼，失声道：“不可能，档案馆的规矩，抵押物不能是别人，只能是自己——”

“所以她才迟到二十三年。”老太太的声音哑下来，“她没把‘你’交出来，于是账务滚成了利息。她死前那几年，记忆力一天比一天差——她忘了自己的名字，忘了回家的路，但每一次见到你，她都还记得你是她儿子。因为那是她唯一不打算还的抵押。”

林雾握着照片的手指节泛白。灰雾里，远处钟楼响了一声——五点十五分。

老太太又把怀表举起来：“借期是满了，账还没清。我今晚来，不是逼你还钱，是给你一次机会。替她把这一个小时还了，她的名字，就能从账册上划掉。”

“……代价呢？”

“你失去这一个小时。从你人生里扣除一段六十钟的连续记忆。你不知道你会忘掉什么，可能是昨晚的事，可能是明天下午的事，也可能是你父亲的脸。你敢赌吗？”

林雾沉默了三秒。灰雾在路灯下翻涌，老太太的影子被拉得很长，长到不像一个正常人的投影。他开口：“我妈临终前，是不是说了六个字？”

老太太的瞳孔缩了一下。

雾气在那一瞬间像被什么拽住，所有的声音都被吞掉，只剩下灯丝嗡鸣。老人向后撤了半步，怀表从她手里滑落，“啪”地砸在地上，表盖弹开，表盘上——没有指针。

只有一行刻字，在表面内侧，是有人用指甲划出来的细小笔画：

“别让她来。”

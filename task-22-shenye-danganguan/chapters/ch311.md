# 第311章 三楼的新笔迹

林雾盯着手机屏幕上那行字——发送时间 3:33，当前 2:57。

他下意识想拨方晴的号码，拇指悬在拨号键上方三秒，又收了回去。三楼的C区，新笔迹，写的是他的名字。

还有二十六分钟才到3:33。

他立刻意识到一个更恐怖的问题：如果这条消息是3:33发出来的，那么发这条消息的“方晴”，此刻正站在三分钟后的未来。而她现在不该在馆里——白班管理员没有夜班权限。

除非她违规了。

林雾没有犹豫，转身就往楼梯口走。脚步一迈出去，他就感觉到了异常。他的影子没有跟上来。

不是“慢了半拍”那种程度的异常——影子直接留在了原地，像被钉死在地板上，高悬的天花板灯把它拉成一道灰黑色的窄长条。而他本人已经走出了两步，影子还在原来的位置，纹丝不动。

林雾停住脚，缓缓回头。

他的影子正维持着“他站立”的姿态，五官轮廓模糊，但姿势笔直。它像是觉察到他的注视，忽然动了一下右臂——不是模仿，是它自己的动作。

那个动作的节奏，像在招手。

又像在叫他过去。

林雾想起门内人说的话：“你脚下那个影子是换来的‘新的’。”新影子会学他，会模仿，但现在这个动作——他没做过。林雾没动，影子先动了，这是第一次发生。走廊里灯管嗡嗡响了一声，闪了一下，熄灭了三秒。

黑暗降临的瞬间，林雾听见影子的方向传来一声极轻的笑，像有人捂住了嘴。灯重新亮起时，影子恢复了正常位置，老老实实地躺在他脚下，仿佛什么都没发生过。

林雾摸了摸后颈，那里全是汗。

他加快脚步，下了五楼，穿过四楼空无一人的借阅区，直奔三楼。三楼的楼道口挂着一块铜牌，上面写着“C区——例外区，非授权不得入内”。林雾有钥匙，馆长“零”给他的那串里，有开这道门的钥匙。

钥匙插进锁孔，转动时发出一声干涩的“咔嗒”。

门开了一条缝。一股纸张烧焦的气味飘出来。C区排满铁皮档案柜，比A区新，比B区整齐，每一格都贴着“修改记录”的标签。以前林雾来过一次，但那时候C区空空荡荡，只有几份被涂改过的旧规则。

可这一次，他看到了不一样的东西。

最里面那排柜子的侧面墙上——原本光秃秃的灰白墙面上——出现了一行字。字迹是拿锐器刻上去的，深深浅浅，笔画歪斜：

“林雾，别信影子的笑。”

不是方晴的笔迹。他见过方晴写字，她的字体偏瘦长，这行字却是方方正正的印刷体，像铅字印上去的。林雾凑近辨认，发现字的边缘有焦痕，像是烧过的纸边贴在了墙上。

“方晴”那条消息说的是“新笔迹写你的名字”，眼前这行几个字，每个字都比拳头大，确实“写了他的名字”。

但字迹不是她的。

林雾正在犹豫要不要拍张照，第三排柜子的角落里传出一声轻响，像是有人翻动纸页。声音极短，极脆，像干透的树叶被折断。

“谁？”他压低声音问。

没人回答。但柜子顶上有一个东西掉了下来，摔在他脚边——是一张泛黄的旧纸条。林雾捡起来，纸条上只有六个字，那六个字正是当初馆长“零”在二楼办公室对他说的那句：

“……来……还……”不对，字迹无法辨认，被墨迹晕染过。

他翻转纸条。背面是铅笔写的一行小字，被刀尖刮掉了大半，只残留了几个能辨认的字：“第三封在——”

“在”字后面是空白，像是没来得及写完。林雾的瞳孔猛地缩了一下。童谣里说的是“还剩三封信”，第二封在他手里，第三封在方晴手里，第四封还在写。可现在这张纸条告诉他——第三封，或许还有另一封？

他刚要把纸条收进口袋，C区的灯突然全灭了。

黑暗中，他的影子再次脱开他的身体，这次影子没有待在原地，而是慢慢向那排铁皮柜挪动。柜子的铁门映出影子的轮廓——一个比林雾高半头的人形，微微弓着背，一步一步朝写着那行字的墙壁挪去。

林雾握紧钥匙，手背上的青筋暴起。他不知道该上前，还是该后退。

他想起五楼门内人说的那句话：“钥匙是锁影子的嘴。”

那把钥匙——他手里的这把——说不定此刻就该派上用场。

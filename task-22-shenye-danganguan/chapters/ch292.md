# 第292章 一号钥匙

凌晨四点，深夜档案馆闭馆，晨光从卷帘门下沿渗进来，照亮了林雾脚边那双灰扑扑的鞋尖。他已经在门口坐了很久，手里攥着那枚铜钥匙，钥匙背面的磨损字迹已经被他翻来覆去看了不下二十遍。

“借五楼归还”——这个断句要么是动词带地点，要么是名词加规则。不管是哪种读法，关键在于“五楼”。

他在档案馆上班这么多天，从来没上过五楼——就连楼梯间的指示牌上都只标到四楼。五楼像是被整栋楼刻意抹去的一部分。但他父亲在照片里站着的那扇门似乎就在五楼，门牌上的那个“5”字轮廓，他不会认错。

口袋里手机嗡了一声。他掏出来一看，方晴发来一条消息：“见到你之前，先别去碰任何钥匙。我在档案馆门口，出来说。”

凌晨四点，档案馆门口。

林雾站起身，推开卷帘门侧面的小铁门，冷风扑过来。老城区路灯泼下一圈枯黄色的光，方晴背靠着灰墙站在拐角处，穿着一件黑色薄外套，头发有些乱，像是匆忙赶来的。

“你怎么来了？”他压低声音，捏着钥匙的手没松开。

“你不该自己进 A 区。”方晴开门见山，“尤其不该接过归还者手里的东西。”

“这是归还者给你的信。”她说着递过来一页折好的纸，纸面上带着淡淡的水渍，像是被雨淋过又晾干的。

林雾展开，一眼便认出那是归还者沈归的字迹——上次在档案槽里递玻璃珠时，他瞥见过他签名。

信很短：“钥匙不是给门用的。钥匙是门。你拿到的‘1’，与方晴家的‘1’本是一对。若二者合在一处插入门板，五楼入口会短暂打开——只持续到下一次闭馆再响。别在闭馆前出来，也别在里面过夜。你父亲押的那件东西，就在五楼等你认主。认主之后，你才能看到真正的‘明天’。”

“你家的钥匙——”林雾话未说完，方晴已经掏出一枚铜钥匙摊在掌心。同样刻着“1”，同样磨损得有些褪色，但背面干净，一片空白。

“我家的钥匙没有刻字。”方晴说，“我爸当初留下它时，只嘱咐了一句：‘如果有一天有人拿着另一把来，别跟他说太多，直接带他去五楼。’”

“你认识沈归？”

方晴沉默了一下。“他是我爸的旧友。关于你父亲的失踪，他比任何人都清楚——但他从不把话说透。他说过，有些事不能亲口讲，只能让路自己去走。”

林雾把信折好塞进口袋。“现在就走？”

“现在。”方晴看了一眼腕表，“离下次开馆还有二十分钟，我们要赶在 0 点前到达五楼那扇门。”她顿了顿，“不过去之前，我得告诉你一件事情……”

她看着林雾的眼睛：“你父亲押在五楼的东西，不是物品。是‘借阅权’——你父亲当年以自己‘能借 A 区任意档案’的权限作为抵押，才借走了 A-000。他还清之前，任何人都不能从 A 区借走任何一卷档案。而现在……”

方晴抬起手，掌心的“还”字印记微微泛红：“这个印记本来是我爸传给我的，意思是‘还清旧账’。如果我把它彻底激活，你父亲就能提前还清欠债，但你将永远失去借阅 A 区的资格。”

“为什么是我？”

“因为借阅券的继承人是三份——你父亲、你、你母亲。你母亲还掉了一份，你父亲欠一份，最后一份在你这。三份借阅券若全部还清，深夜里档案馆就会恢复正常。”方晴声音低下去，“但如果你父亲是那个欠债的人，那么还债的人必须是你。”

林雾没有说话。掌心那枚铜钥匙在晨光里反射出一层温和的金色，仿佛在应和方晴最后那句话。

远处的天空泛起蟹壳青。五点整，卷帘门“咔嗒”一声自动落下，锁舌咬合时发出沉闷的一声重响，像是档案馆长长呼出一口气。

方晴侧过头来：“你知道为什么选今天吗？”

“因为照片上写的是‘明天’。”林雾说，“今天已经是明天了。”

“不。”方晴摇头，“今天是你父亲还债的最后期限。如果今天之内他没有还清，他的‘借阅权’将永久归零——他会被锁在 A 区深处，再也出不来了。”

林雾的拳头缓缓收紧。铜钥匙的边缘硌着掌心，金属冰凉，带着一种隐隐的心跳感，如同门后那个声音在无限接近他的骨头。

他低头看着钥匙背面那行几乎被磨光的字，忽然明白了什么——“借五楼归还”的意思，恐怕不只是一句指引。那是一张账条，是他父亲在五楼写下、等待他来亲手勾销的欠据。

“走吧。”林雾把钥匙收进口袋，迈步向档案馆的侧面入口走去。

方晴跟上去，脚步在水泥地上敲出清脆的响声。路灯在他们身后一盏盏熄灭，整条街暗下去，只有档案馆侧门上方那盏永不熄灭的白色小灯，安静地亮着，灯罩里贴着一张几乎无人注意的纸条，纸条上的字迹像是新写的：“今天不是明天。”

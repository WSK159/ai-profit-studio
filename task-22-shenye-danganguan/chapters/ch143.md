# 第143章 月圆前的准备

凌晨四点十分，老城区上空云层极薄，农历十四的月亮轮廓清晰得像一块刚出窑的瓷盘。林雾坐在出租屋窗边，指间夹着那枚怀表，表盖内侧的刮痕在台灯下泛着暗银色的微光。

“别带怀表。”他把归还者的话又默读了一遍，然后将怀表扣在桌面上，表壳和木质桌面磕出一声闷响。

手机屏幕忽然亮起，新消息来自方晴的号码：“你在哪？我马上到。带手电筒，不带怀表。”

林雾盯着这条消息，眉头越拧越紧。十分钟前，同一号码发来的消息是“快离开，老城区不安全。”而再往前翻，还有一条“不要相信这个号码发来的任何消息”。

他说不清自己是在跟谁对话。但有一点可以确定——发消息的人知道他手上有怀表，也知道归还者的警告。方晴不会知道这件事。除非她知道了什么，从别人口中，或者从某个不该打开的档案里。

门铃响了。

林雾起身走去门口，透过猫眼往外看。走廊灯没亮，楼道尽头站着一个模糊的轮廓，身形清瘦，披着头发。他拉开门，方晴站在门外，脸色苍白得近乎透明，右手拎着一只帆布包，肩头有一层极淡的水汽——像是走过很长一段夜路，在雾里泡了很久。

“你怎么来了？”林雾侧身让她进门。

方晴没回答，先在屋内环视一圈，目光在他桌上的怀表上顿住，又移开。她把帆布包放在桌上，拉开拉链，里面是一叠A4纸和一根折叠的手电筒。“你那条短信我看到的时候已经过了二十分钟，”她说，“但我不是看到短信才来的。”

林雾问：“那你为什么来？”

方晴沉默了几秒，从帆布包最底层抽出一张折得四四方方的纸，递给他。纸面发黄、泛脆，边角有折痕，像是被人反复折过又展开过很多次。林雾展开一看，纸上是手写的表格，标题写着“馆员轮值记录——农历五月十四”。

他扫了一眼日期栏，是十五年前。上面一排排名字，其中几个被红笔圈过——方晴父亲的名字在第三排，他的父亲林北烽在第五排，都有圈。

“每年的农历十四，档案馆会安排一次夜间清点，参与清点的馆员第二天都不会来上班，”方晴说，声音压得很低，“我爸负责的那次，清点完就没有再回家。你爸也是。”

林雾盯着那两行名字，指尖停在“林北烽”三个字的红圈上。“清点什么？”

“B区全区的档案。”方晴说完，把那张纸从他手里抽回来，重新折好收进包里，“我查过馆里的交接记录，每次月圆清点都在B区，清点完当天夜里，档案馆的借阅系统会关闭到凌晨四点。”

林雾的心跳快了一拍——凌晨四点，正好是现在这个时间。

“你爸失踪那天晚上，”方晴看着他，“档案馆借阅系统重启之后，录入了一笔新的借出记录——A-000。借阅人的签名是林北烽。”

屋内静了下来，外面远处传来一辆卡车驶过的声音，震着玻璃轻轻发颤。林雾想起那张C区突然出现的“A-000补遗”档案，首行新墨迹，指纹带烧伤疤，全本空白。他问：“你说清了B区全部档案——有没有可能，A-000原本不在B区？”

方晴没回答，从帆布包里掏出一只旧铜钥匙，上面缠着一圈褪色的红绳，系着一张小标签，字迹褪得模糊，但勉强能辨认出三个字：“未归档。”

林雾盯着那把钥匙，窗外的云层被风推着流动，月光从云缝里渗下来，斜斜照进屋，落在桌上那枚怀表的表盘上。时针指在四点，分针正朝33分滑去。他猛地想起来——3:33，他该闭眼了。

“方晴，”他低声说，“馆员铁律第三条规定：3:33不许睁眼。现在到时间了。”

方晴猛然转头看向墙上的挂钟——四点三十三分，不是三点三十三分。她皱起眉正要说“不对劲”，林雾已经伸手把她拽向自己，同时踢翻了台灯。整间屋子陷入黑暗的同一瞬间，走廊尽头传来一声细长、干涩的“咯吱”声，像是有人缓缓转过脖子。

而那枚摆在桌上的怀表，在三根指针全部指向3:33的那个刹那，自己弹开了盖。

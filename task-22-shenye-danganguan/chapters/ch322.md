# 第322章 影子敲门

门外的敲击停了。

林雾的影子也停了，右臂保持着一个抬起的姿态，像一尊突然被按了暂停的雕塑。它面朝门缝，身体的轮廓被前台吊灯的光拉得很长，那个没有五官的脑袋正微微偏向门缝的方向，像是在听。

方晴没有说话，也没有动。她只是缓缓把手从口袋里抽出来，指尖沾了点前台杯子里的冷水，在台面上用湿痕画了一条线——那是她爸教过她的规矩：档案馆里如果听见敲门声，先画一条线，看线会不会被门缝的风吹动。如果线动了，说明门是通着的；如果线不动，说明声音不来自门外。

水痕在空气中微微颤了颤，然后彻底静止。线没有动。门是死的。

“声音不来自门外。”方晴低声说。

那声音就不在门外。可林雾刚才明明听见敲门声从铁门另一侧透过来——那种隔着金属的闷响，带着铁皮震动的余韵，不可能是从馆内发出的。除非……门的两侧，本来就是同一侧。

林雾低头看了一眼右腕。那道浅金丝线还缠在皮肤上，“影”字刻在掌心，“沈”字环绕在手腕内侧，像一个环形封印。那枚钥匙虽然消失了，但那种沉甸甸的压迫感仍然压在掌根，像一枚嵌进肉里的石子。

他的影子还站在门边。它脑袋没有动，但那姿态分明是“在听”。门外第三下敲门声落下的时候，他的影子抬起右臂，指节弓起，像是准备敲第四下。

“别让它敲。”方晴的声音急促起来，她猛地从前台抽屉里抽出一枚铜牌，贴在门板上，“敲第四下，等于开门。”

林雾几乎是本能地跨步上前，伸出左手去按自己影子的肩膀。但影子不是实体，他按了个空。他的掌根穿过影子肩头的位置，触感像把手指探进一桶冰水——冷到刺痛，但什么都没有。

影子没有回头，但它停住了。它弓起的指节缓缓放平，右臂垂到身侧，那个没有五官的脑袋转了过来，朝着林雾的方向“看”了一瞬。

那一瞬间，林雾看清了：影子右掌的掌纹，果然和左手完全对不上。他左手的线是三条清晰的主线，右手的影子掌纹却密密麻麻，像一张被人用指甲反复刻过几百次的蜡纸。那些繁乱的纹路中间，有一个极其浅淡的痕迹——一个汉字的上半截，像是被擦掉了一半。林雾认了几秒，才认出来。

那是个“还”字的上半截。

“方晴，”他说，“你掌心的‘还’字是什么样的？”

方晴摊开手掌。那枚浅金的“还”字印在她掌心正中，笔画干净利落，像盖了一枚工整的章。林雾看了一眼，又低头看影子掌纹里的半截“还”——笔锋一致，力度一致，像是同一个人写的，只是影子上那一半被“擦”掉了一半。

“你爸也有一枚‘还’字，对不对？”林雾问。

方晴没有否认。她低头看了一眼自己掌心的字，又看了看门边那个静止的影子，声音很轻：“他失踪那天，我看过他的手掌——他右手心有同样的印子，但只有一个‘还’，没有‘归’。”

“归”字戒指、“还”字掌印、钥匙柄上消失的“沈雾”二字。这些东西像是被拆成了零件，散落在不同的人手里，各自安安静静等着被组装回去。

门外又敲了一下。这次只有一下。但那个声音传来的时候，林雾看见门缝下透进来的一缕光——那光线极细，颜色是很淡的浅金色，像一枚细针从门缝里探进来，在地面上画了一道薄薄的弧。它画出来的形状，是一把钥匙。

那把光画的钥匙躺在门槛内侧，正在缓缓凝结成固体。

“别碰它。”方晴的声音又急又快，“那玩意儿是你的影子引来的——”

林雾没有碰。但他也没有退开。他盯着那把光钥匙，发现它的形状与自己之前在五楼拿到的那枚一模一样——包括柄端那道微弯的弧线。唯一不同的是，钥匙柄上没有字了。干干净净，像一把从未被人用过的新钥匙。

他手腕上的浅金丝线忽然松了一瞬，又猛地绷紧。像什么东西在另一端被拉直又释放，产生了极短暂的失重感。

“方晴，”他说，“你爸说‘钥匙认名，名认影子’。那这把光钥匙认的是谁的名？”

方晴没有回答，她忽然快步走到前台最左侧的登记册前，翻到最近一页——今天凌晨的借阅记录。林雾凑过去看，发现那一页的右下角多了一行不属于他们俩任何一人的字迹，墨水极淡，像是用快干掉的笔尖写的：

“钥匙认名，名认影子。但影子不认人——影子认的是‘旧主’。”

方晴的指尖颤了一下。“旧主……那不等于钥匙还在等着原来的主人来取？”

门缝下那把光钥匙，忽然闪了一闪，像一盏即将熄灭的灯。然后它的形状开始变化——柄端缓缓向左右两侧延伸，形成两根极细的分枝，像一只手从地上伸出来。

那两只“手指”轻轻向两边一拨。门缝下的光被拨开了一条极细的缝隙，一股凉意从缝隙中钻进来，带着旧纸、灰尘与一丝淡淡的樟脑味。那是档案馆A区的气味。林雾在入职那天闻到过一次——馆长办公室的门缝里透出来的，就是这个味道。

光钥匙那两只“手指”又动了，像是在地上爬行，一寸一寸向林雾的方向挪来。它每挪一寸，林雾手腕上的丝线就松一分——像那枚钥匙在归还他什么。但它挪近的每一秒，门缝下的光就扩大一圈，像什么东西正在另一侧用力将门推开。

方晴猛地按住铜牌，门缝下的光在那一瞬被压住了。“别让它碰到你的影子！”她喊了一嗓子，“钥匙认完名、认完影子，就等于签了契约——”

但林雾的影子已经动了。它自己走了两步——朝那把光钥匙的方向，蹲下身，伸出右手。影子的五指缓缓张开，像是要接住那把钥匙。林雾想拉住它，可他自己也伸出了手——左手，几乎是本能地探向那把光钥匙，像是有人在他耳后轻轻推了一下。

他的指尖离钥匙只剩三厘米。钥匙的浅金色光芒映在他指腹上，温热而沉甸甸的。他听见自己的呼吸声急促了一下，然后压住。

方晴猛地拽住他的手腕往后一扯。钥匙在离他指尖只剩一根发丝的距离处停住了，像感应到什么，不再往前。然后它缓缓地、一寸一寸地，倒退着爬回门缝，消失在黑暗中。

门缝下的光跟着合拢，铁门发出一声沉闷的落地声，像一块墓碑归位。那一刻，林雾才看清，自己右手腕上那道浅金丝线已经消失了——取而代之的，是掌心的“沈”字与“影”字之间，多了一枚极细的、浅金色的钥匙印记，像一个纹身。

“你刚才说，”他对方晴说，“不能让它碰到影子。那如果碰到了呢？”

方晴沉默了很久。“那我爸就不会只留下一枚‘还’字了。他整个人都会被那把钥匙‘认走’。”

她话音刚落，铁门外传来了第三个人的声音——一个男人的声音，略微沙哑，带着一丝疲惫，贴在门缝处：“钥匙还没认完。你还得还一样东西。”

“什么东西？”

“你父亲替你押的那段影子。”

门外静了一瞬，然后那个声音又说：“我是来替他收的。开门吧，林雾——你爸当年借回来的那份‘旧账’，还没还完。”

# 第172章 三声钟响

第一次钟响，林雾戴着的电子表“啪”地裂开一道缝。指针停在 00:00。

那声响不是从挂钟传来的，更像从档案馆的墙壁内部传出来的——像某个巨大的声腔在吞咽一件东西。值班室的日光灯骤然灭掉，只剩走廊尽头有一盏暗绿色的应急灯亮着。

林雾攥紧掌心的归还单，纸边有点发毛，像是被谁反复拿过又放下的。他抬起腿，朝还书窗口走去。D 区的走廊不长，十二米左右，但他每走一步，地板都会发出一种疑似踩在水面上的声音。他低头看了一眼——影子没跟上来。

他的影子还停在值班室门口。

灯在背后熄灭。影子没有了光源，按理应该消失，但林雾分明看见一道黑色残影，像水渍般黏在原地，形状微微拱起，像是有东西想从里面爬出来。他猛一回头，身后什么也没有；再转回来，影子在他脚下重新贴合。

这时挂钟敲了第二响。

不是“当”，是一声极轻的“嗒”，像是从纸里挤出来的。他走到还书窗口前，窗口的铁栅栏半开着，托盘上积了一层灰。他把归还单放上去，手掌松开的一瞬，那纸仿佛被什么吸附住了，发出一声极细的“嘶”。

下一秒，托盘上的归还单，字迹开始湮开。

签名的位置，林父的名字像被水洇了，一笔一画地退去，露出下面一层更淡的字——不是名字，是一行小字：`已取走声音·待付代价`。然后那行字也开始褪色，最后变成空白。

林雾等着第三声钟响。

但钟没有响。走廊尽头，应急灯的光晃了一下，一个穿白衬衫的人影从转角走出来，步子很慢，鞋底在地上拖着。他走近了，黑框眼镜，嘴角带着极浅的弧度——方晴。

不对。方晴穿的不是白衬衫。

林雾的手掌在口袋里握成拳。那人抬起头，盯着他，嘴唇动了动：“林雾，你看见 C 区第七排的归还单有几张？”

林雾张了张嘴，喉咙里没有任何声响。

那人笑了笑，从口袋里掏出一只老年机，屏幕亮着。上面打了一行字，字号巨大：“我问你，你看了几张？”

林雾后退半步，视线落在那只手机上。老年机的屏幕角落，亮着三个点：正在录音。

第三声钟响，终于来了。

响声来自还书窗口的铁栅栏——那铁栅栏在没有人碰的情况下，咣当一声落了下来，像一只合拢的嘴。而被合拢在里面的，是林雾刚刚放进去的那张空白归还单。

穿白衬衫的人低头笑了笑：“你还回去晚了。现在你没声音，也没那张单子。你拿什么跟 A-000 续约？”

他摘下眼镜，露出一双瞳孔极淡的眼睛。林雾看清了他的工牌——悬挂在左胸，微微反着光，上面只印了一个字：

零。

# 第286章 十号钥匙

走廊死寂。

林雾把空心钥匙收进左胸口的内袋，指尖碰到那枚十号钥匙时，一股极低温度的凉意顺着金属表面传过来，像握着一块冰。他把十号钥匙抽出来，握在掌心，缓缓举到面前。

那是一把普通的黄铜钥匙，钥匙柄磨得发亮，齿纹带着一种明显不属于现代锁具的粗糙感。他此前一直以为它只是用来开B区尽头的某扇门，可现在握在手里，他忽然发觉钥匙的柄面上刻着一行极细微的字，细到不贴着眼皮根本看不清——

他凑近，借着手机屏幕残余的最后一丝亮光辨认，那行字是：

“开门的，从来不是钥匙。”

林雾瞳孔一缩。

这句话像一根针，刺进他脑子某个一直没被拨动的角落。他想起在C区那本被改写的规则上见过一模一样的笔迹——陈叔的批注。陈叔早就来过这里？

“你怎么不早说陈叔来过五楼。”他对方晴说，声音低沉。

方晴从他肩后探过头来看那行字，神色也变了。她低声说：“陈叔的批注我见过不少，但从没见过这一句。这不像批注——这像……留言。”

留言。留给谁的？

林雾没再多想。他一咬牙，把十号钥匙插进门锁。钥匙旋转的瞬间，他能感觉到锁芯内部的动静——不是金属碰金属的声音，而是某种更柔软、更像纤维缠绕的阻力。钥匙像插进了一团活物里，微微搏动着。

门没有销开，但门缝里那种蠕动感停了。

紧接着，门内传来一声极轻的、像叹息一样的声响，那声音带着一种奇怪的沙哑，仿佛有人从很深的地方发出了一声：“……你来了。”

林雾的手停在钥匙上。

那不是父亲的声音。

他听得真切——虽然很像，但有一截尾音不对。父亲的声音在第二封信里留下的那句“不要借走任何东西”带着干燥的、坚韧的质感，而这个声音的尾端带着湿漉漉的黏腻感，像有什么东西正含着水说话。

“你不是我爸。”林雾冷冷地说。

门内的声音沉默了一瞬。然后那声音笑了，笑得很低很闷，像从很深的水面下冒上来的气泡：“你比你父亲聪明。他进门的时候，可没这么警觉。”

“他进门了？”方晴在林雾身后追问，声音又快又急，“他进了这扇门？什么时候？他还在里面吗？”

门内没有再回答。取而代之的，是一阵翻纸的声音。那种纸页被快速翻动的声音，在黑暗里听得格外清晰——像有人在翻一本极厚的档案册，一页、一页、又一页。

林雾握紧钥匙，正要转动，方晴忽然一把按住他的手背：“等等。你看钥匙。”

他低头。十号钥匙的齿纹正在变色——黄铜的颜色正从钥匙柄朝着齿尖方向一寸一寸地变成深红，像被血浸了一样。红色蔓延到齿尖后停住，那些粗糙的齿纹忽然齐齐转动了一下，像齿轮。

钥匙自己在转。

“咔哒”一声轻响，门锁弹开。

不是林雾转的。

门缝缓缓裂开一道黑色的口子，里面没有任何光线。但林雾能感觉到——那里面确实站着一个东西，像是一个人形的轮廓，贴得极近，几乎就在门缝另一侧，正俯身看着他。

方晴后退一步，手已经攥住她自己的钥匙。

门缝里的人形轮廓没有动，只在黑暗里开口，那声音已经彻底变了，不再是像父亲的沙哑，也不带一点湿度——是一种干冷的、平板的、像打字机格出来的声音：

“A-000，今夜十二点归还。你还有二十六分钟。还不上——押物归我。”

林雾的血像被抽干了一瞬。

押物。门。父亲的借条上写着“押：门”——押的是这扇五楼的门？还是别的什么门？

那声音像是看穿了他的想法，在黑暗中补了一句：“你父亲押的不是这扇门。他押的是你们回家的路。”

林雾脑子里轰的一响。

就在这时，门缝彻底打开了。里面没有房间，没有地板，没有墙壁。只有一片纯粹的黑暗，黑暗中央，漂浮着一张写字台的轮廓，桌上摊着一本打开的档案——深红色封面，标题他认得。

“方远山”。

方晴的那本档案，一直躺在五楼这扇门里。

而桌边，坐着一个人形轮廓，正缓缓抬起了头。

方晴睁大了眼睛，嘴唇翕动了两下，发出的声音细得几乎听不见：“……爸？”

林雾紧紧握住十号钥匙，手背上的青筋一根根暴起。钥匙柄上那行字在他掌心里渗着微微的温度，像是某种东西正在回应他——

“开门的，从来不是钥匙。”

他猛地明白过来。

五楼这扇门，认的不是钥匙，是持钥匙的人。

他低头看向那把已经变成十号钥匙的“归”字空心钥匙——不，现在不该叫它空心钥匙了。它内壳里的丝线已经完全消失了，取而代之的，是一根极细的、像活着的红线，从钥匙柄伸展出来，缠上了他的手腕，一直延伸到掌心那个蓝光“拆”字的位置。

红线在蓝光边缘停住了。

桌边那个人形轮廓再次开口，这一次，干冷的声音里带上了一丝极淡的、几乎称得上温和的语气：

“还差一样东西。你母亲的姓。”

# 第135章 旧账本

灰雾在日出前最浓，像一层湿冷的棉布贴在皮肤上。林雾把那封信——父亲留下的字条——塞进内袋，转身时看见方晴正弯腰打量旧书店外墙根部一块翘起的青石板。石板边缘露出半截泛黄的纸角，像被时间遗忘的欠条。

“别动。”林雾低声说。但方晴已经把那纸片抽了出来。它展开后足有半张海报大，是一份手写的账目表，纸质脆得指腹一碰就掉渣，字迹却清晰如昨。最上方一行字让两人同时僵住：

**“A-000，欠账清单（附利息），管理人：零。”**

条目密密麻麻，全是编号而非人名。林雾目光扫过一行行黑字，指尖停在倒数第三行：“**B-034，借走『背影』一条，逾期二十三年，抵押物：其女方晴（时年五岁）。**”方晴的呼吸声骤然变得粗重，她一把夺过账本，那只手在抖，灯光下指节泛白。她没说话，眼光沿着同一页向上移，最后停在顶端第二行。

**“A-000，借走『存在』一条，逾期二十三年，抵押物：其子林雾（时年两岁）。抵押物已激活。”**

“已激活”三个字比“逾期”更冷。林雾想起母亲临终那些话，想起老太太自称债主找上门，想起自己三更半夜被困在档案馆台阶上时手心无故发烫。他终于明白了那种烫的来源——他不是欠债人的担保，他就是债务本身。

方晴没问林雾的感受，她已经翻到了背面。账本背面是另一种笔迹，潦草，带着某种急迫，像一个人跑着写下的遗言：

**“有人想改账。旧账不消失，只会转到新名字下面。零不知道这件事，或者他知道，但他不在乎。记得，真正的归还不在地上，在三点三十三分。”**

最后一句话被墨水洇开一片，不是湿痕，是干了很久的墨迹重又化开，像在回应某种东西。方晴盯着那行字看了半晌，突然掏出手机，凌晨五点四十四分的屏幕亮得刺眼。她翻到那条六字短信，又看了看账本上的字，来回三次，才关了屏幕。

“三点三十三分，”她说，“馆员铁律里有一条——”“不许在馆内睁眼。”林雾接上，随即顿住，他想起十二铁律那条规则挂在 D 区墙上，白底黑字，孤零零一条夹在“不许回首”和“不许数 B 区档案”之间，像被刻意塞进去的。“馆内。也就是说，不在馆内就可以‘看’。”

他没来由地想起那扇藏在窗后的门，想起馆长在窗内侧无声重复那六个字的神情。零让他“别再借”——如果三点三十三分是某个可以直视真相的时间窗口，那零会不会早就在暗示什么，而自己没能接住。

方晴将账本翻回正面，目光停在那行“抵押物已激活”旁边一个几乎看不见的铅笔小字上。那个字被橡皮擦过一半，剩下左半边偏旁——三点水。她皱眉：“这里写的是……‘沉’？还是‘清’？看不全。”

林雾听到“清”字时，后背像被凉水浇了一鞭。他想起母亲说的六个字，那几个字的声音像沉在水底：“旧账……清了……”他没说完，方晴已经注意到他的异常，压低了声音：“你刚说什么？清？”

他还没来得及回答，账本的纸页忽然自己抖了起来，像有什么风从纸里向外吹。那些条目上的字开始渗，字迹之间浮起一层极细的暗红色线条，沿着纸张纤维蔓延，汇成一个图案——不是字，是一扇门的轮廓，门缝微微裂开，露出里面黑沉沉的一片。

账本落在旧书店台阶上的瞬间，那扇门轮廓却印在了地面上，像烧红的烙铁压进青石缝里。门缝里传来声音，不远不近，隔着雾却清晰得像在耳边。那声音是林雾父亲的声音，只是年轻许多，带着某种告别的味道：“账本不是借据，是钥匙。你拿到它，三点三十三分，还来A区。”

方晴瞳孔骤缩。她没听过林父的声音，但林雾猛地站了起来，脸色煞白——那一刻，他连自己父亲的声音在更年轻时是什么样都分不清了，但他不可能认错这句话里的“A区”。

“A区，”他重复了一遍，“禁书区。我连馆门都进不去，怎么去A区？”他的提问被一声轻响打断。那本账本不知何时重新回到了台阶上，纸页翻开到最后一页，那片空白的底色上多了一行新滴落的墨迹，笔锋熟悉，是母亲的字：

**“到时，别带怀表。”**

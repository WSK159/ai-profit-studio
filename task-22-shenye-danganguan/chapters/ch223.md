# 第223章 借阅卡的背面

老袁的目光落在那张借阅卡上，走廊里灰扑扑的灯光照得卡面泛黄起毛。他的眼神微变，像一滴墨落入水杯里，荡开一圈极淡的涟漪。

“你拿这张卡，是想跟我算旧账？”老袁的声音低下去，语调里却没多少意外，“你知道我借走的是什么吗，就敢说这话？”

林雾攥紧卡片，指腹压在卡面那道“A”字上。他能感觉到那个多出来的一笔，正像一道裂纹，无声地在他掌下扩张。“我不需要知道全部，我只需要知道你还回来过。”他抬起另一只手指向老袁大衣左襟，“你每次来，都在‘未归档’台账上按手印。今晚你站在我面前，左手袖口沾着红印泥，未干。”

老袁低下头，看自己袖口那一抹殷红，忽然笑了：“你父亲当年也是这个眼神，像条逮住狐狸尾巴的狗。”

“所以，我猜对了。”林雾说得笃定，“你借过不止一次档案。那些借走的‘部分’，你至今没还齐。”

灰衣老人沉默片刻，慢慢解开大衣扣子，露出一件深灰布衫，胸口挂着一条旧麻绳，绳头绑着一把铜锁。锁身磨得发亮，锁眼朝下，没有钥匙。

“A-000 的档案分两份存。一份是‘正文’，在 B 区铁柜，锁的是你手上的钥匙。”老袁拍了拍胸口那把铜锁，“另一份是‘附页’，在这里。借去的人，会从我这里借；还回来，也要从我这里续。”他看着林雾，目光变得又深又静，“你父亲欠的那二十三年，就是从这里开始滚利息的。”

林雾的喉咙动了一下，没说话。

老袁靠在墙边，像一截老树根嵌进了砖缝里：“当年你父亲来找我，说他要锁一道门。我问他锁哪道，他说‘未归档’那道，但钥匙必须同时能开 B 区——因为账页正文若锁死，附页还有路可走。他说这是留给后人的退路。”他顿了一下，“可他没说，那把钥匙一旦焊死，附页也会跟着封死。我是他选的那条路，他替我先试了走不通的路。”

“你恨他？”林雾问。

老袁摇摇头：“我们做这一行的，不恨，只记账。”他伸手，手指虚虚指着林雾手里的借阅卡，“你这张卡，是你父亲当年用剩下的余页，正面只有一行字：‘凭此卡可借 A-000 附页一次’。转到我手里之后，背面写了归还的条件。”

林雾把卡翻过来。

背面空白了一片，只在右下角有三个极小极淡的字，像是用指甲刻的：

“还他醒。”

走廊尽头的挂钟忽然“嗒”地一声，响了第二声。那声音像敲在冰面上，清脆、干冷，林雾的心跟着沉了一下。

“还他醒”三个字，写的是谁？

“这是你父亲的笔迹。”老袁说，“他当年写这三个字的时候，人还醒着。他说，等他睡了，就该有人替他还上。”

“睡”字沉甸甸地坠在林雾胸口。“你指的是……他还活着，只是像档案一样，被锁进‘睡’里了？”

老袁没有接话。他把大衣重新拢好，袖口的红印泥在灯光下像一小块凝住的血。他转过半个身子，目光却还留在林雾手里的卡上：“你今晚拦我，是想退掉我借走的‘那部分’。但你要想清楚——那张卡上的字，是你父亲用二十三年利息换来的。你若用它来抵一桩旧账，它就会从卡上消失，再也回不来。”

林雾低头看着“还他醒”三个字，指腹轻轻焐着那凹痕。头顶的灯管闪了一下，像喘了一口气。

“我不抵。”他说。

老袁的眉头微微动了一下。

林雾把卡合在掌心，抬眼看老袁：“你说你是父亲选的路，那你还记得他借走你的那部分是什么吗？你今晚来取钥匙，到底是他让你来的，还是你自己要来的？”

走廊里静了三息。

老袁笑了，露出一口整齐得过分的牙，和他那身灰扑扑的衣袍显得格格不入：“问得好。这句话，攒了二十三年，总算有人问出来了。”

他弯腰，从大衣内袋里摸出一张薄纸，纸边发黄，折痕深重。他展开，只给林雾看了一眼——纸上只有两行字：

“钥匙锁两道门，我锁的是自己。”
“若有人拿着 A 字借阅卡来问你，告诉他：那扇门后，还有一把钥匙。”

林雾看清那笔迹的瞬间，后背一片冰凉。

那是他父亲的字。

他见过那笔迹无数次——档案残页、台账内封、C 区铁门前的留言，全都出自同一只手。但这一张纸上的字，和那些都不一样：不是警告，不是遗嘱，而像是回头看了一眼，告诉他“后门在哪”。

“这张纸，是今天下午才出现的。”老袁声音很轻，“有人把它夹进 A 区的‘未归档’台账里，封皮内侧，正是你今晚发现茶渍印痕的那一页。”

林雾的手指一紧，指节发白。

——今晚他仔细看过台账封皮，那一页上，除了茶渍，什么都没有。那张纸，是在他检查之后才出现的。

“你是什么时候拿到的？”他问。

“比你进门早七分钟。”老袁说完，把纸重新折好，塞回大衣内袋，“换句话说——在你检查封皮之前，它就已经在了。”

走廊里那盏灯管彻底熄灭了。

黑暗中，老袁的声音像一根绷紧的弦：“七分钟，够一个活人把一页纸夹进封皮，再把自己藏进墙里。你管的这座馆，比你想象的多了一间房。”

林雾握卡的手心里全是汗。他站在原地没动，听见挂钟“嗒”地响了第三声。

钟声落下时，黑暗尽头传来一声极轻极细的“咔哒”——像一个抽屉从深处被拉开的声音。

那不是走廊尽头的门。

是墙里。

# 第295章 陈叔的规矩

蜡封“陈”字的信封躺在掌心，有一股旧纸与樟脑混合的气味。林雾用指甲挑开蜡印，里面只有一张对折的纸，纸面发黄，边缘卷起，像是被水泡过又晒干的。

纸上只有三行字，笔迹遒劲，力透纸背，是陈叔的手笔：

“十号钥匙开十号柜，十号柜里没有钥匙。”
“五楼的门要五把钥匙，但钥匙不一定是钥匙。”
“去找陈叔——陈叔已经死了三年。”

最后一行字明显是后补的，墨色比前两行新，笔锋也急，最后一个“年”字的收尾拖出一道细长的划痕，像是写这句话的人被什么打断了。

林雾盯着那三行字，后颈一阵发麻。

“陈叔已经死了三年”——那这段时间一直给他传信、在信纸背面批注“去找陈叔”的人是谁？是陈叔生前留下的字迹被人仿写，还是……有人借着“陈叔”这个名字在引他？

他把信封翻过来，背面还有一行更小的字，几乎被纸张纹理掩盖：“如果真的见了陈叔，问问他，三年前他还了什么东西。”

林雾将信纸收起，手指轻微摩挲纸张边角。丝线缠过的那根食指上，淡青色的痕迹依然在，不痛不痒，但像一枚褪不掉的戒指。

“看完了？”方晴的声音从身后传来，带着一丝警惕。

“看完了。”林雾把信纸折好塞进内袋，“陈叔留了话，但话里有矛盾。”

“什么矛盾？”

“他让我去找陈叔，又提醒我陈叔三年前就死了。”林雾顿了顿，“要么是他在死前预见到我会找他，提前留了指引；要么……”他看向方晴，“有人用陈叔的口吻在引我们。”

方晴沉默了几秒，铁柜里那根泛蓝的丝线忽然抖动了一下。两人同时看向柜内。

那根丝线原本静止不动，此刻像被风吹过一般微微颤动，蓝光忽明忽灭。林雾伸手想去碰，方晴抢先一步扣住他的手腕：“等一下。”

“怎么了？”

“丝线颤动的节奏——三短一长。”方晴眯起眼，“这在档案馆的旧规矩里，是‘有人来了’的暗号。”

林雾屏住呼吸。铁柜深处的黑暗里，某种极轻的脚步声正在靠近，像赤脚踩在积灰的地板上，一步、一步、一步——然后停住。

“是铁柜后面的通道，”林雾压低声音，“柜子后面还有路？”

方晴摇头：“馆里的图纸上没有任何一条通道标注在 B 区尽头。这个柜子是……新出现的。”

“新出现的？档案馆的构造每天都在变？”林雾想起之前台阶变化的经历，脊背发凉。

“不会随便变。”方晴松开他的手腕，声音更低了，“只有当某样东西被借走又归还之后，档案馆才会重新调整内部格局。B区尽头的柜子一直在这里，但它后面的通道，是刚刚才打开的时间。”

“刚才打开？”林雾皱眉，“因为我们……”

话音未落，铁柜里的蓝光丝线忽然断裂。断口处释放出一团幽蓝的雾，像呼吸一样膨胀又收缩，紧接着一只手从柜后的阴影里伸了出来。

那是一只老人的手，布满褐斑，指节粗大，指甲修剪得极短。手背上有一道旧疤，从指根延伸到腕部，像被什么利器划过。

林雾后退半步，但他没有移开视线。那只手抓住了柜门边缘，缓慢地、用力地将门推开。

铁柜内壁上浮现出密密麻麻的刻痕，像另一封信——不是笔写的，而是用尖锐的东西硬生生刻进去的。林雾凑近了些，那些刻痕在蓝光中显现出文字：

“十号柜开在后半夜。后半夜的档案，只借不还。”
“陈叔的规矩——借了就得还，不还就得死。”

声音从柜后的阴影里响起，苍老、沙哑，像喉咙里塞了一口旧棉絮：“小伙子……你拿的是十号钥匙，开的是十号柜。可你知不知道，十号柜借出去的东西，从来没有人还回来过？”

林雾的手心沁出汗来。

那只手收回去，阴影里传来沉重的呼吸声。片刻后，一张满是皱纹的脸缓缓探出，眼珠浑浊，却直直地盯着林雾：“陈叔让我转告你一句话——”

“他说，别信五楼的门，五楼是假的。要进真正的档案馆，你得先去借一张旧借阅卡。”

林雾瞳孔一缩。

他的口袋里，正放着那张父亲留下的、编号 A-000 的旧借阅卡。

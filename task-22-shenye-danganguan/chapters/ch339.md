# 第339章 灯油

“我父亲还进灯里的东西。”

林雾盯着那个浅金色人形，脑中闪过无数片段。父亲留下的三封信、借阅卡上的“留归”二字、铜照片背面的“别开门”、借条上“名归钥匙”的规则、五楼那扇门后“它醒了”的字迹——所有线索在他脑子里疯狂旋转，最终拼成一个可怕的形状。

父亲不是失踪了。是被拆开了。

名字、影子、记忆、命——四样东西，分别寄存在不同的地方。他的名字被烧成了灯油，影子被押在档案馆里换回林雾，记忆被封进档案编号A-000，而命——那缕命，被装在这盏铁皮灯里，此刻正一点一点燃尽。

“我父亲的命，还剩下多少？”林雾问。

人形没有回答。但灰外套的“另一个林雾”替它开了口。那声音是林雾自己的嗓音，却带着陈叔的语调：“灯座上的‘命’字一旦烧透，灯就灭了。灯灭，馆开。馆开，你父亲的命就没了。”

“馆开了会怎样？”

人形浅金色的轮廓忽然向四周扩散，像一滴墨落入清水。它没有说话，但那股光流扩散的方向很清晰——楼梯口，黑门，S区大厅，档案架，所有封存规则的锁链——那道光仿佛照出了整个档案馆的全貌。

林雾猛然后退一步。

他明白了。深夜档案馆是灯。规则是灯油。而他们这些守馆人、借阅者、违规者——都是燃料。馆里每一条规则都在消耗“什么”，这栋楼才能维持“营业”的状态。

如果有人把灯灭了，馆就开了——馆里封存的所有规则都会流出去，再也没有人能拦住。借走的规则不会归还，失效的规则不会补录，而那些被规则压住的东西——未归档的、被删除的、不该存在的——“它们”全会醒来。

五楼那扇门后面的“它”，就是其中之一。

“你父亲把命还进灯里，不是为了救你。”灰外套的“另一个林雾”说，“是为了压住馆门。他烧了一夜‘名’替灯续油，就是在等你来。”

林雾攥紧铁皮灯。灯座的“命”字已经烧透了三分之二，烫手，但那股热意不再灼人，反而像某种催促。

“他在等我做什么？”

“把灯填满。”人形的声音忽然清晰起来，“用你的名，还是用你的命，你要自己选。”

林雾低头看着那盏铁皮灯。灯座上的“名”字已经烧得通红，像嵌了一块烧透的炭；而“命”字还剩三分之一，边缘的刻痕像一只合拢的瞳孔，正在缓慢闭合。

他想起父亲纸条上的最后一句话——燃灯者的名，不能还。还了，灯就灭了。

他还想起自己刚入馆时，馆员手册上第一条铁律——不许在馆内叫全名。

为什么不能叫全名？因为名字是有重量的。在深夜档案馆里，名字就是灯油，谁的都算。

他抬起头，看着那个浅金色人形：“如果我选‘命’呢？”

人形的光忽然静止。灰外套的“另一个林雾”也停下了脚步。

“那馆门不关，你父亲的命也保不住。我会烧自己的命，替他把灯填满。但灯油烧完了，他就真的从所有记录里消失了——名字、影子、记忆、命，一样都不会剩下。”

人形沉默了很久。久的像一层灰慢慢落定。

然后它说：“你不是燃灯者。”

林雾愣住。

“燃灯者没有名字。”人形的声音低下去，像一盏快要熄灭的灯，“你父亲留下纸条告诉你‘燃灯者的名不能还’，不是让你替他填灯，是让你别走上他这条路。他烧了自己的名，烧了自己的命，现在他连最后一盏灯都快要守不住了——他等的人，是来熄灯的。”

灰外套的“另一个林雾”缓缓低下头，那只灰色手重新放回桌上，笔尖再次落在纸上。但这一次，它写的不再是“林雾”。

它写的是——A-000。

那支笔锋他认得。是他父亲的笔迹。

而纸上的A-000正在慢慢地、一笔一划地，变成另一个人的名字。

# 第78章 方晴手里的钥匙

林雾盯着书页上自己未干的签名，沉默了三秒，然后一步上前把记录本合上。

“别看了。”他说。

方晴没有动。手电筒的光斜斜地打在地上，像一道白线隔在两人中间。她的呼吸很轻，却比平时急促了些。

“我在你之前来馆里待过四年，”她说，“我知道第四次归还意味着什么。”她停顿了一下，“那是最后一次。凡是能撑到第四次的，不是因为还能还什么，而是因为已经没什么可还了。”

“我父亲当年……”她的声音低了下去，“借了一条规矩，没还上。第二天他的位置就空了，系统里连名字都不剩。”

林雾看着她的眼睛：“那你为什么还在办公室？”

“因为我找到了一条记录。”方晴从外套内侧口袋里拿出一把黄铜钥匙，摊在掌心里。钥匙很小，只有拇指长，齿纹粗陋，像是手工锉出来的。“这是我爸留下的。他说这把钥匙开的不是门，是规则与规则之间的缝。”

她看了一眼空荡荡的走廊：“你父亲留下的那本记录，第多少页？”

“第七页。”

“第七页有什么？”

林雾重新翻开记录。这次他的手很稳。书页在他掌心里摊开，那一行空白的下方多了一小段极细的密文。他把手机屏幕贴过去，放大，仍看不清——字体不是中文，也不是英文。倒更像一种……

“规则的形状。”方晴说，声音近似耳语，“我爸说过，D区7号柜里存过一份档案，编号忘了，但封面上画着这样的线条。我当时没看懂。”

林雾没有说话。他想到了老周临走前那句“水写的东西，干了还在”——他到底是在说规则，还是在说别的什么。

他重新拉了一下7号柜的柜门。这一次，他没费什么力气，门便自己滑开一道缝。一股潮湿的气味漫出来，像雨后泥土混合铜锈。柜子内壁嵌着一个凹槽，正好能放下那把黄铜钥匙。

“你试试。”方晴说。

林雾把钥匙按进凹槽，咔哒一声。柜子深处传来齿轮转动的声响，随即是纸页翻动的沙沙声。

“你听到了吗？”他低声问。

“纸的声音。”方晴应道。

柜子深处缓缓推出来一卷东西，用牛皮纸包着，系着一条暗红色的麻绳。林雾解开麻绳，牛皮纸展开，里面是一张泛黄的旧照片——照片上是他父亲年轻时的样子，穿着档案馆旧版馆员制服，站在一面巨大的书架前。书架上的档案脊背无数，排列成一行行晦暗的色块。

照片的背面写着一行字，字迹冷峻，不带任何情感：“别找A-000。找C区的改写者。”

林雾愣住了。

方晴也看见了那行字，她把钥匙从凹槽里抽出来，放回口袋，声音有些发干：“改写者。”

“C区。”他说，“存放被改写的规则的地方。”

方晴点头：“你爸让你去找一个能改写规则的人。”她顿了顿，“你说——你听见你爸的声音在路上出现过，不止一次。那他有没有告诉过你，怎么找一个改写者？”

林雾正要摇头，前厅方向传来一声闷响。像什么重物被丢进归还窗口。

他快步走去。方晴跟在他身后，手电光打在前厅地板上时，两人同时停住了。

归还窗口前的台面上，躺着一本黑色的档案册，册脊上没有编号，只有一行烫金小字——“归还，不是结束”。

林雾翻开封皮，第一页是空的。第二页也是空的。第三页却画着一扇门的素描——门楣上挂着那面镜子的轮廓，门把手的位置被人画成了一个圆圈，里面写着三个字：

明天照常。

他抬起头，看向那扇挂在前厅左侧的旧门。那扇门他见过无数次，门上挂着一块生锈的铭牌——馆员专用，禁止入内。

可今天铭牌不见了。

门把手的位置，一个圆形凹槽正在微微发亮——恰好是钥匙的形状。

方晴的脚步声停在他背后。

“林雾，”她说，“你把钥匙插进去之前，先想清楚一件事——”

“开门之后，我们就不是按规则办事了。我们会成为规则本身。”

林雾低下头，看着手里的钥匙，以及自己签下的那个名字。

前厅的灯再一次暗了一格。从归还窗口里，传来水波一样轻轻涌动的声响。

像是有什么东西，在等他给一个答案。

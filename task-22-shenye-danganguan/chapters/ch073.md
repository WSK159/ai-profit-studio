# 第73章 墨未干

前厅的荧光灯发出电压不稳的嗡嗡声，我将那本《第四次归还记录》放在台面上，指尖仍然残留着书页的触感——温热，像刚被别人握过。

我低头，书页上我的签名墨迹还在慢慢渗进纸纤维。墨未干，说明这几个字写下不过片刻。

可我根本没有动笔。

“老周。”我叫住那道湿漉漉的背影，声音比我自己预想的要稳，“你刚才说，天亮前不签，我会出事。可这本书自己就签了。所以，到底是签了安全，还是不签安全？”

老周停在水痕边缘，没有回头。他脚下的水渍在地板上缓慢扩散，形状像一只摊开的手掌。

“第四次的归还，”他的声音闷而轻，像从水底透上来，“不需要你同意，只需要你存在。”

他说完这句话，前厅的灯闪烁了一下，老周消失在了门缝里。他站过的地方只留下一小滩清水，水里飘着一枚硬币——一分钱，民国年间的旧版。

我没有捡。

我把那枚硬币留在原地，合上了《归还记录》。奇怪的是，当书面合上的一瞬间，我的签名就不见了，书页重新变成了空白，只在页脚多了一行小字：

“第一次记账已完成。剩余：三次。”

我静了几秒，将那行字读了整整三遍。按照这套规则，每一笔代价都会“记在账上”，而记录的载体就是这本簿子。刚才的签名应该算作第一次，也就是说，还剩下三次。

可这次我什么都没借，什么都没得到，账却已经记上了。规则的核心是不对等。

我从口袋里摸出那枚铜章，对着灯光转了转。A-000的刻痕在章底盘踞，比昨天又深了一些，像是有人在背着我的时候，用什么东西一遍遍凿过。我把它放回口袋，决定不再想这个问题——眼下更迫切的问题是那扇门。

D区深处那扇门，老周提过“不要开”，第七铁律又恰好是“不许回头看归还窗口”。这两件事之间会不会有关联？

我走向走廊尽头的同事休息室，推开门。方晴果然还没走。她坐在一把旧藤椅上，面前摊开一本硬壳笔记本，台灯在她脸上打出半明半暗的光。

“你没走？”我靠着门框。

“你不也没走。”方晴抬起头，把笔记本朝我方向转了一点。我认出纸页上整齐的字迹，和她父亲留给她的日记是同一本。“我刚才听到前厅有声音，没敢出来。铜铃响了一下，然后停了。是怎么回事？”

我把《第四次归还记录》的事简短说了。当我说到“我的名字预先浮现”时，方晴的表情明显变了。她合上笔记本，站起来走到窗边，玻璃外面是漆黑的老街，连路灯都熄了大半。

“预先出现的签名，”她低声说，“我父亲日记里有一条，你记得他说过‘档案会自己长出新页’吗？”

我点头。那是B区的特性。

“C区也有一种现象。改写的规则，痕迹会先于执行出现，像钢笔漏墨一样。你先看见结果，然后才看见原因。”方晴转向我，神情复杂，“这种倒置……通常意味着改写者离得很近。”

“……多远算近？”

“同一个人。”方晴看着我，“或者同一栋楼。”

我忽然想起那个直播间。0007账号。那晚弹幕刷出“A-000已归还，请查收”的时候，我以为是观众在胡说八道。可现在，档案真的“归还”了，以一本账册的形式，自动签上了我的名字。

我的手机屏幕亮了一下。我低头一看，直播软件的图标跳出一条通知：

“您关注的直播间「档案馆·夜巡实况0007」已开播。”

我点进去。直播间只有画面，没有标题，黑白的监控视角——拍的正是我现在站的这间休息室，画面右下角，一个模糊的身影正对着屏幕。

那个身影，像是我自己。

方晴注意到我表情不对：“怎么了？”

“你身后。”我说。

方晴猛地回头。

身后空无一人。但书桌上那本她父亲的日记，不知何时，已经翻开了新的一页。

页面正中，写着一行字，笔迹是她父亲的，墨迹未干：

“别信零。他不是馆长的第一个名字。”

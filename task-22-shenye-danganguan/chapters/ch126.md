# 第126章 水痕留名

那六个字像一根针，扎在林雾脑子里。

“你要是敢进来——”后面没有句号，也没有字。铅笔的痕迹断在“来”字的最后一捺，像是写的人被什么打断了。或者是，写的人不想写了。

铁门外，湿漉漉的拖行声停住了。然后，门缝底部渗进来一小片水痕——不是普通的水，颜色发黑，像稀释过的墨，在水痕里缓慢地洇出几个字：字迹是新的，和林父留下的铅笔字完全不同，歪歪扭扭，像有什么东西学着人的笔画，一笔一笔现写出来的——它写的是：“我已进来。”

林雾的瞳孔骤缩。他第一反应是往后退，但脚后跟撞上了身后B区的档案架——铁制的，发出“嗡”一声闷响。方晴没动，她站在门缝前，目光死死盯着那行字，说：“不是它写给你的。”

“什么？”

“是它写给我看的。”方晴举起手，指间夹着一支钢笔，笔尖上沾着黑色的水痕，还在往下滴，“刚才那摊水渗进来的时候，我蘸了它一下——现在，这行字是用我的笔写的，对规则来说，这是‘借阅人主动回应水柜’，它就有了你的‘签名’。”

林雾脑子里嗡的一下。“你的意思是，你替我签了？！”

“不是替，”方晴把钢笔收回去，嘴唇发白，“是‘带’——它开口了，作为馆员，我按规定替它记录。规矩第十七条：‘水柜之物若有言，馆员应记之，不得拒。’”

铁门外的水声彻底停了。片刻后，那片黑色水痕缓缓退去，像潮水一样，从门缝下退得一干二净。走廊恢复了死寂。

方晴呼出一口气，肩膀塌下来半寸。“今晚它不会来了——它拿到了它想要的记录，就不会再追。但明天不一样，明天它是‘已记录在案’的借阅人，它就有资格等你还东西。”

“还什么？”林雾问。

“还‘一句话’。”方晴看着他，眼神很复杂，“你爸留下一句话给水柜，没说完。水柜一直想找人补完它。六年前我没补完——因为我不会爸的话，我只会替我自己的说话。但你不一样，你姓林，你是A-000的后代。”

林雾低头，手里那张D-00卡上的铅笔字，在日光灯重新亮起时，似乎又淡了几分。他翻过卡片，背面明明写的是六个字，但此刻他仔细数了数，笔画之间似乎还藏着一个更浅的痕迹——像是被人拿橡皮擦掉过几笔，只剩下一撇一捺的残余，像一个没写完的“听”字的下半截。

“这卡，”他问，“我爸拿它的时候，背面写的是什么？”

方晴沉默了一会儿，说：“我不知道完整的。我捡到它的时候，背面只有六个字：‘你要是敢进来——’但再往下翻，角落里还有一行小字，被水泡得几乎看不见。”她从口袋里掏出一张纸巾，上面拓着一行歪歪扭扭的字——像是她自己早前抄下来的，“我抄了三遍才认出来——”

纸巾上写着五个字：

“三更半，忘记。”

林雾愣住了。他猛地想起自己进馆时看过的第十二条铁律：三更半——你以为睡着了，其实没睡；你以为醒了，其实还在梦里。

而现在，已经是凌晨四点十二分。三更半已经过了。

但他还醒着。或者说——他不知道自己是不是真的醒着。他盯着方晴，忽然问了句：“你刚才说四点半交班，现在几点？”

方晴低头看表，随即脸色变了。钢表的分针依旧卡在“7”和“8”之间——三点三十五分。

表没走。

而窗外的天，已经亮了。

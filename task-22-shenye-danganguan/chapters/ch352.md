# 第352章 明灭之间

林雾蹲在铁梯口，左手攥着那枚刻着“沈”字的扣子，指腹反复碾过金丝线脚。黑暗中，陈叔的右鞋静静躺在他脚边半步远的位置，鞋跟的划痕朝下——像是有人把它从上面丢下来的。

他记得清清楚楚，上一回看见这只鞋，是在暗间门板后方的角落里。鞋不可能自己移动。

“陈叔？”他压低嗓子喊了一声。

铁梯下方没有回应。只有风从底部灌上来，带着一股旧纸页和煤油混合的气味。那味道他熟，馆里归档间的空气就是这个味。但归档间在二楼，铁梯通向的地方，怎么着也该是地下室。

林雾把扣子塞回衣袋，摸出火柴盒。盒面上印着那行字：“灯亮之前别回头”。

他点燃一根火柴，火苗跳了两下，照亮铁梯往下约莫六级的范围。梯壁锈迹斑斑，有些地方被反复踏过，磨得发亮。他数了数，起码几十年的使用痕迹——这梯子绝不是近些年修的。

火柴快烧到指尖时，林雾把它甩灭，决定下去看看。

他一手攀着扶手，一步步往下走，同时默数台阶数。四、五、六……到第十二级时，脚下踩到一张纸片。他蹲身捡起，借着下一根火柴的光看了一眼。

那是登记簿的一角，边角烧焦，上面残留着几行墨字。笔迹是陈叔的，歪歪扭扭，像是写的时候手在抖：“他知道我替你看过灯油。别下来。”

林雾心头一紧。他正在铁梯上，这条警告写明了“别下来”。他没遵守。

但他没有立刻回头。陈叔既然把鞋扔下来——如果那是他扔的——或许是想留下某种标记。他翻过纸片，背面还有字：“他穿灰外套。”

火柴灭了。

林雾站在原地，让自己的眼睛适应黑暗。然后他听见头顶传来翻动纸页的声音，极轻极细，像有人蹲在暗间门口翻他那本登记簿。他屏住呼吸，侧耳听了片刻，那声音停了，接着是鞋底在木地板上移动的响动，往前台方向去了。

有人进了前台。翻完登记簿之后，没有下铁梯，而是折回了馆内方向。

林雾做出一个决定。刚才火柴照亮铁梯底部时，他看见尽头处有一点金色光芒，一闪一灭，和灯油快耗尽时的火苗一模一样。那里还有锁链拖曳的声响，极慢、极重，像什么东西被扯动了一下。

他把陈叔的鞋从脚边拾起来，鞋底朝上翻看。鞋跟处那道划痕不是新伤，但划痕内部嵌着一点金粉——和登记簿上金丝线缠出来的字、和他口袋里那枚扣子内侧的金丝，材质一模一样。划痕是刻意刮出来的，用来取这部分金丝。

陈叔的鞋在铁梯上，是他最后留下的路标。

林雾把鞋插进后腰带，猫着腰继续往下走。台阶开始变得陡窄，墙壁从砖石变成夯土，空气里的煤油味更重了。他数到第三十七级时，脚下终于踩到了平地。

铁梯尽头是一条横向的短甬道，大约三米长，尽头是一扇嵌在墙里的旧铁门，半开着。门缝里漏出一线金光，随着某种节奏忽明忽暗——像有人在门后点了一盏灯，灯芯正在缓慢地、一鼓一吸地呼吸。

林雾伸手推门。铁门铰链没有响，像是最近才有人上过油。门开后，他看见一个大约十平米的小房间。

房间正中放着一张木桌，桌上摆着一盏燃着的旧铁皮灯。正是他在S区见过的那种铁皮灯，灯身上用白漆写着两个字：“名、命”。灯焰是浅金色的，照亮桌上摊开的一本簿册。

林雾走近一步，认出那是馆里的借阅登记簿。但封面上没有编号，只有一个人名，手写的，墨迹很新：“沈雾”。

他翻开第一页。里面只有一行字：“借阅人：沈煜之。事由：以名换名。经办：自己。期限：廿年。”日期是二十三年前的今天。

房间角落传来一声低哑的气音。林雾猛地转头，看见墙角立着一件灰呢子外套——搭在衣架上，袖管自然垂下。外套内侧口袋里露出半张纸的边角，纸上露出两个字，像是“钥匙”。

桌上那盏灯的火焰，在这一瞬间，忽然凭空矮了一截。

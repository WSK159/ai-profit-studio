# 第354章 灯油

影子合拢的速度比我预想的更快。

那半寸凸起像是活物，从墙根处沿着光与暗的交界攀爬，眼看就要贴上我的脚跟。我下意识跺了一下脚——影子纹丝不动，倒是铁皮灯的火苗跟着晃了晃。

灯油烧得差不多了。

这个念头闪过脑海的瞬间，墙角那件灰呢子外套的袖口微微颤动了一下。我盯着它看了三秒，确认没有风。地下室没有窗，空气沉闷得像是被压实的泥，那件外套却自己动了一下，像有什么东西刚从里面钻出去。

我弯腰把陈叔那只右鞋放到铁皮灯旁边。鞋跟上的金粉在灯火下闪了一下，和外套袖口的金线是同样的颜色。

身后那个声音又不耐烦地敲了敲：“灯亮着可以回头，但回头后欠账到你头上。你自己选。”

我没回头，但也没应声。陈叔的纸片上写着“他知道我替你看过灯油”，那个“他”是谁？地下室里的痕迹显示这里至少有过两个人待过，一个看灯油，一个留下外套。而那个所谓“身后的人”，说话方式像极了一种规则提示——它说“可以回头”，但回头的前提是欠账。这等于没给选择。

我把目光移到桌面那本无编号簿册上，翻开的那页写着“借阅人：沈煜之，以名换名，经办：自己，期限：廿年”。沈煜之是我父亲。这个我早就确认了。但“经办：自己”四个字我以前一直没细想，现在再看，脊背升起一丝凉意——如果“经办”栏填的是“自己”，那是什么意思？是他自己给自己办的借阅手续？还是说，这笔账的经手人，是他本人。

父亲既是借款人，又是经办人。

这不合规矩。档案馆的借阅流程里，经办人必须是馆员，借阅人不能自己签经办栏。除非——那天晚上，档案馆里没有别人。

他一个人签了名，把名字换走了自己的一部分，期限二十年。二十三年过去了，他还没有归还。

我伸手想去摸簿册后面那页扣子压痕的位置，指尖还没碰到纸，铁皮灯的火焰突然“啪”地爆了一声，窜高半寸。随即我听到灯身里传来液体轻轻晃动的声音。

灯油不多了。但这个地下室没有油壶。

陈叔留下的纸片上写“他穿灰外套”，我面前就挂着一件灰外套。外套口袋里露着“钥匙”的纸角，但我不敢去碰。所有证据都指向同一个结论：陈叔来过这里，替人看过灯油，然后被发现了，留下右鞋和纸片仓促离开。

“你在看那件外套。”身后的声音说。这次语气变了，不是提醒，更像是试探。“你认识那件外套的主人？”

我还是没说话。但我的影子动了一下。

它是被我的身体带动的，我没动，它却动了一下，像是有什么东西在里面对着外套点了点头。

外套的袖口又颤动了一下，这次幅度更明显，金线在灯光下划过一道弧线，像是某个陌生人正在从里面伸出手来。我盯着那只袖口，忽然意识到一个问题——那件外套挂在墙角的钉子上，但钉子的高度，至少比我的身高高出整整一个头。

一个更矮的人穿过的外套，被挂在了很高的地方。而且是被人特意挂上去的。

铁皮灯的火苗又跳了一下。我从灯的金属外壳倒影里，隐约看见身后站着一个轮廓，那轮廓的肩膀位置，和灰外套的肩线完全重合。

我握着搪瓷杯的手紧了紧。

然后我听见墙角传来“咔嗒”一声，那件灰外套的口袋里，那把钥匙从纸角里滑出来，在地上滚了半圈，停在我脚边两步远的位置。钥匙柄上刻着两个字。沈雾。

这把钥匙上刻的是我的名字——是母亲姓的那个“沈”，那个我从出生起就被冠上的姓氏。而二十三年前，父亲用自己的名字换走的东西，也许正是这把钥匙。

我弯下腰去捡，手指刚触到金属表面，铁皮灯的火苗“轰”地熄了。

地下室陷入彻彻底底的黑暗。

影子凸起在这一瞬间猛扑过来，贴上了我的后背，凉得像一块冰。身后那个声音在黑暗中笑了笑，嗓音忽然变得和我的几乎一模一样：“灯灭了。现在谁欠谁的账，可说不清了。”

黑暗中，我手里那把钥匙微微发烫，像一枚刚从炉膛里取出的铁片。而那件灰外套的方向传来布料摩擦的声音，像有什么东西正从中走出来，脚步声不急不缓，朝我逼近。

我只来得及做一件事。我用拇指按住了钥匙柄上“沈雾”二字。

火苗重新亮了起来——不是从铁皮灯里，而是从我手心里。

灯焰烧着我的皮肤，却没有疼痛。我低头看见自己的影子被这个新光源钉在地上，它的右手正伸向灰外套的方向，五指张开，像是在索要什么。

我攥紧钥匙：“来。”

那灰外套停住了。身后那个声音也停住了。整个地下室安静得像一口被合上的棺材。

然后那件灰外套的领口慢慢转过来，朝向我的方向，像是有一张我看不见的脸正注视着我手心的火焰。良久，它开口了。声音很轻，像从很远的地方传来：“你把灯提起来了。那灯油，从谁身上出？”

话落的瞬间，我手心传来一阵尖锐的疼痛。一滴殷红的血顺着钥匙滑落，滴在地上，像一枚深红色的印章。那件灰外套忽然倒下来，像是从来没有被挂上去过，软塌塌地瘫在墙角。而铁皮灯里的火苗重新亮了，蓝白色，冷得刺骨。

我的影子重新回到脚边。

它好像比刚才淡了一点。淡得很微妙，像是有人用橡皮擦去了一层——那层曾经从墙上凸起来、想要合拢的轮廓，已经彻底消失了。

但它带走了我身上的什么东西。我说不上来，只是一低头，发现自己左手的无名指上，不知什么时候多出一道细白的疤，像一枚新的掌纹在无声生长。

身后那个声音彻底消失了。取而代之的，是头顶传下来的脚步声。穿了灰外套的人，正朝地下室走来。

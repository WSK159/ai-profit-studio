# 第407章 照片

走廊不长，地面铺着和档案馆 D 区一模一样的水磨石砖，墙上的灯是旧式的白炽灯泡，两盏亮、两盏灭。照片挂在尽头，银色相框有点歪，像被人匆匆挂上去的，或者被人摘下来又挂回去过。

林雾没有跑。他从看到那张照片起就知道自己不能跑，规则从来喜欢惩罚那些在它面前失态的人。他一步一步走过去，走到离照片三步远的地方停住。相框里有灰尘，照片上的他穿着馆员制服，脸上是那种放松的笑，像是下班后路过打卡机旁的随手一拍。

可他的目光落在照片左下角。那里有一个日期戳。数字已经被磨损得几乎辨认不清，但边缘的轮廓让他在脑内补出了完整的样子：11 月 17 日。

今天是什么日期？林雾拧眉想了想。他入职之前刚过完国庆假期，十月上旬的天气还带着夏末的尾巴。他进档案馆之后就没再看过日历，但屋外的蝉声早已停歇。他推算不出准确日期，但他确定，绝对不到 11 月。

这张照片是未来拍的。或者，它属于另一条时间线。

林雾伸手把相框取下来。相框不沉，后盖松了，一枚东西从背板里掉出来，“当啷”一声落在水磨石地面上。是一枚钥匙。黄铜色，齿纹复杂，看起来和 D 区第十二号储物柜的钥匙一模一样——但上面系着一截红绳，绳上穿了一颗米粒大小的珠子。

他捡起钥匙。那颗米粒触感温润，不是塑料，倒像真的骨头磨成的。米粒。又是米粒。从第一碗搪瓷碗里的粥，到父亲纸条上岔路的暗示，再到此处——米粒总在关键的地方出现，像有人在沿途撒下的记号。

他把照片翻转过来。相框背面用马克笔写了一行字，字迹潦草但笔锋沉稳，像赶时间写下的，墨迹已经干涸发灰：

“第 407 号钥匙。能开 C 区例外柜。别在七号之前拿它开门。”

林雾瞳孔微缩。C 区——例外区，存放被改写的规则的区。他之前一直想进去但缺少权限，如今这枚钥匙自己出现在他手里。但“别在七号之前开门”这句话让他犹豫。今天是几号？

他抬起头，走廊尽头墙壁上挂着一台比圆盘还老的钟，钟面玻璃裂了，时针和分针都停在一个位置。他眯眼辨认：指针指向两点十七分。又是两点十七分。

“两点十七分。”他低声念了一遍。档案室里的钟停在两点十七分，他手表上的时间也停在两点十七分，馆长“零”第一次见他时，墙上挂钟也显示两点十七分。现在这间属于第二道门后的走廊里，时钟依旧停在两点十七分。

档案馆的时间，被钉死在两点十七分。那么所有关于“三点钟”的规则，都指向一个永远不会到来的时刻——除非有人亲手把钟拨过去。

林雾将照片和钥匙一并收起，继续往前走。走廊尽头有一扇矮门，门楣上沾着干涸的胶带茬，像是曾贴过什么标识又被撕掉了。他侧身推开，门后是一间很小的储藏室，落满灰尘，角落堆着三个旧纸箱。

第一个纸箱里是一叠旧报纸，日期全是同一年的，版面不同但标题相同：《老城书店失火，无人员伤亡，店主下落不明》。他翻看日期，那一年他父亲失踪。店主下落不明——他一直以为父亲是半夜离开家就再没回来的，从未听过“失火”和“书店”这两个词。

第二个纸箱里放着一本工作日志，封皮写着“A 区迁档记录”。他翻开，里面全是借调记录，任何档目进出都要登记。有一行字，墨色比其余的都深，被人反复描过：“A-000 迁至 B 区，经办人：零。”经办人那一栏的签名只是一个“零”字。字迹和他父亲信纸背面的压痕一致。

第三个纸箱最浅，只放着一只搪瓷碗。白底蓝边，碗底有一道细长的裂纹，和他口袋里那一只一模一样。他蹲下去，拿起碗来翻看，碗底外侧刻着一个字，被手汗磨得模糊，但能辨认出轮廓——

“还”

归还的还。也是还会回来的还。

林雾把碗放回箱内。他忽然感觉到口袋里的瞳孔回执烫了一下。他伸手摸出那枚薄片，灰白色的瞳孔表面多出一行字：

“3:33 已过。第十三夜，顺延至明晚。你还有一夜。”

他攥紧回执。原来三点钟不是不会来，而是被拨到明天。而那句“别信任何人对你说的三点钟”，或许不是让他别信某个时刻，而是让他别信“三点钟”是唯一能看见明天的方式。

走廊尽头的灯泡闪了一下，灭了。

黑暗中，他听见矮门外传来方晴的声音：“林雾？你在里面吗？”

她怎么会在深夜的档案馆里？今天是白班，她不该在。

林雾没有立刻回答。他低头看着手里的搪瓷碗，碗底那个“还”字，像是有人在提醒他：你已经欠下了一笔账。

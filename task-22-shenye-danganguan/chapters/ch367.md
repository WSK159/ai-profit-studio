# 第367章 汤快凉了

门合上的声音不大，但在这条密闭的走廊里被放大了好几倍。林雾回头，那扇通向楼梯的防火门已经贴紧门框，门缝里透进来的一点应急灯光也熄了。走廊里只剩下头顶三盏吊灯，光线昏黄，勉强照亮脚下一小圈地面。

“门会自己关。”方晴松开他的袖子，语气恢复了平静，但声音比平时低半个调，“你父亲刚才那句话——‘汤快凉了，别来’——是什么时候说的？现在说的？”

林雾摇头：“我听不出。像是隔着东西，可能是录音，也可能是别的。”

他走近走廊尽头那个身影消失的位置，地上有一滩水渍，形状不规则，边缘已经干了。水渍旁边躺着一只信封，牛皮纸，没有封口。林雾蹲下来，没有直接碰，先看了一圈——信封上没有任何字，也没有编号。他用指背探了探纸面，干燥的，凉凉的。

方晴递过来一支笔。林雾用笔尖挑开信封口，里面滑出一张照片，正面朝下。他翻转照片时，指尖停顿了一瞬——照片上的人是父亲，背景是档案馆五楼那扇上有凹槽的门，父亲站在门边，手里端着一只碗，碗里冒着热气。照片右下角有手写的日期，字迹潦草：三十二年十一月十七。

“三十二年前。”林雾站起来，“馆长说，那扇门三十二年没开过。可我爸站在这扇门前端着碗汤，时间就是三十二年前。他那时候多大？”

方晴算了算：“三十二年前，你爸应该二十出头。”

“对，照片上他就是二十出头。”林雾把照片翻过来，背面有一行铅笔字，很淡：“汤冷了，门开过。”

这六个字。林雾脑子里嗡了一声。零说过，A-000已经归还，那六个字是流程通知。但照片背面这行铅笔字，笔迹是他父亲的，写的也是六个字，却完全是另一句话。

“汤冷了，门开过。”方晴轻声念了一遍，“这话是说——他来过这扇门，但他没进去？还是说他进去过，出来的时候汤已经冷了。”

林雾没回答，他在想另一件事。他父亲当年得到的规则是“别带钥匙进来”，可照片里，父亲的手腕上分明戴着一枚很细的东西，像手绳，又像钥匙链。他凑近照片仔细看——那不是钥匙，是一枚深蓝色的纽扣，穿在红绳上，和他手里第一枚一模一样。

“第二枚纽扣。”林雾低声说，“背面刻着‘来见我’的那枚。”

他忽然意识到什么，翻遍口袋，把两枚纽扣都摸出来，摊在掌心。两枚并排，一枚刻着“自己”，一枚刻着“来见我”，字迹并不相同。“自己”二字是凹刻，“来见我”是凸刻，像是一对配套的机关，一个压下去，一个弹起来。他试着把两枚纽扣合在一起，凸面正好嵌进凹面，严丝合缝，像是一体的。

合拢的瞬间，纽扣夹层里掉出一张对折的纸片，极薄，叠成指甲盖大小。林雾展开，上面只有一行字，笔迹是父亲年轻时的，带点潦草：

“钥匙不是你，钥匙是门。你只负责打开。”

“什么意思？”方晴凑过来看，“第一枚纽扣背面刻的是‘自己’，你以为是‘钥匙是你自己’，结果压根不是。钥匙是门本身？”

林雾盯着那行字，又看看照片上端碗的父亲。门板上的凹槽，纽扣嵌进去才会亮，但父亲说钥匙不是人，是门。那门自己会开？三十二年前，门开过没有？照片上的汤还冒着热气，说明他父亲站在那儿时，门还没有被打开。他站了多久？等谁？

走廊尽头忽然传来一声响，闷闷的，像筷子掉在桌上。林雾抬头，那滩水渍旁边不知何时多了一只碗，白瓷，碗沿磕掉一块，里面盛着一碗清汤，正冒着热气。

“这碗……”方晴声音发颤，“照片里他端的，就是这只碗——磕了一块，没错。”

林雾蹲下来，伸手碰了碰碗沿，温热的。汤是热的。可走廊尽头不到一分钟前还站着那个身影，他消失了，汤却留下了。他想起来父亲说的那句“汤快凉了，别来”，意思是，汤一直在热着？还是说，他一直在热着这碗汤，等人来喝？

他端起碗。碗底压着一张纸条，上面写了一个地址，老城区，是档案馆隔壁那栋从不亮灯的居民楼。纸条背面还有一行字，笔迹已经不年轻了，带了点颤：

“来二楼，我住这儿。别带钥匙。”

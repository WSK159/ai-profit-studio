# 第394章 一碗粥

走廊尽头的碗沿磕碰声越来越近，那节奏不紧不慢，像是端着什么怕洒的东西，每一步都走得极稳。

林雾下意识往后退了半步，背脊贴上身后那扇半开的门。门缝里渗出的凉气顺着衣领钻进后颈，像一只冰凉的手搭在他脖子上。他不敢回头看那扇门，因为规则第七条的余威还在——不许回头看归还窗口，但这条规则管不管D区深处的门，没人说过。

方晴倒是没退。她站在原地，右手慢慢探向腰后，那里别着一支笔，笔尖朝下，是馆员遇到紧急情况时的默认姿态。

“别动。”她压低声音，“听脚步。”

林雾屏住呼吸。

那脚步声确实不对——每一步之间隔得太均匀了，不像人在走，倒像钟摆在晃。而且，走廊里没有灯，黑暗中那声音却越来越近，近得像是贴着墙根在挪。

终于，走廊尽头拐角处亮起一豆昏黄的光。那光摇晃着，映出一只端碗的手。碗是搪瓷的，白底蓝边，碗沿磕掉了一小块瓷，露出底下黑褐色的铁锈。粥还冒着热气，白雾在光里蜿蜒上升，像一条细蛇。

端碗的人整张脸都埋在阴影里，只露出一截手腕。那手腕上缠着一条深蓝色粗布——和林雾刚才在门缝里看到的那只手的衣袖，一模一样。

“陈叔？”方晴忽然开口。

那端碗的人没有回答，只把碗往前递了递。热气扑面而来，林雾闻到一股米香——纯粹的、干净的米香，没有一丝杂味。但在深夜档案馆里，越是干净的东西越让人发毛。

“他说……”方晴顿了一下，侧耳听着什么，眉头越皱越紧，“他说‘粥’。”

林雾没听见声音。但他知道方晴的耳朵和常人不一样，上一回她说过，那扇门里传出的声音她听到的是“来”而不是“还”。她能听见别人听不见的东西。

“谁让你端来的？”林雾问。

端碗的人依旧沉默。那只手往前又伸了几分，碗沿几乎碰到林雾的胸口。

“接吧。”方晴说，“他端着挺久了。”

林雾低头看着那碗粥。白粥清亮，米粒完整，没有加任何东西。他伸手接过，碗底是温的，不是烫的——从后厨到这儿的路不长，这温度刚刚好，像是算准了他会在这个时间出现在这个位置。

“谁煮的？”他问。

端碗的人终于后退一步，退回阴影里。脚步声再次响起，比来时快了一些，很快消失在走廊尽头。

林雾端着那碗粥，站在黑暗里，一时间不知该放下还是该喝。

“方晴，”他低头盯着碗里，“粥底有字。”

方晴凑过来——碗底的米粒几乎被喝尽了，剩下一层薄薄的米汤，在昏黄的廊灯下映出几个字。字是米粒黏出来的，笔画歪斜，像是有人用米粒一粒粒摆上去的，又被热粥烫得半融半散。林雾眯着眼辨认了半天，读出来：

“喝。才能醒。”

方晴沉默了。

“什么意思？”林雾抬起头，“这是……”

他的声音忽然卡住。

因为碗底还有第二行字。比第一行更小，也更浅，但这一次，一个字一个字地浮了上来，像有人在碗底用指甲划过：

“醒来的馆员，才能看见门里的人。”

方晴后退一步，手重新摸向笔。林雾端着那碗粥，感觉温热从碗壁钻进掌心，一直爬到骨头缝里。

他忽然想起一件事。

陈叔，已经失踪四天了。四天前他最后一次出现在档案馆，就是去后厨，说要煮一碗粥。那时候林雾还笑着问：“给谁煮的？”陈叔没回答，只说了一句：“给明天来的人。”

明天。

今天。

“我喝了。”林雾说。

方晴猛地抬头：“你——”

“字已经浮出来了，我不喝它也会记得。”林雾端起碗，仰头，把那碗已经半凉的粥一口一口咽下去。米粒滑过喉咙，温热下肚，没有怪味，没有苦涩，只是一碗普通的白粥。

但喝到碗底最后一口时，他咬到一样硬的东西。

他伸手从嘴里拿出来——一颗铜纽扣，磨得发亮，边缘被牙齿咬出一道新痕。纽扣背面刻着一个编号，被指甲刮过，几乎看不清，但林雾借着光辨认了很久，认出一个模糊的“0”。

A-000。

那是他父亲的编号。

走廊尽头，那脚步声又响起来了。

这一次，没有碗沿磕碰声。只有脚步声，由远及近，一步，一步，走得比刚才慢得多。方晴的嘴唇动了动，声音有些哑：

“这次……我听见了。”

“什么？”

“他说：‘把纽扣还回来。’”

林雾攥紧那颗铜纽扣，扣子上的凉意渗进掌心，像握着一小块冰。与此同时，面前那扇半开的门忽然“咔哒”一声，锁舌缩回，门缝开得更大了。门缝中，那只灰白干瘦的手又伸了出来，掌心里躺着一粒米，被指甲掐成一个字——

“进。”

那扇门，从内侧被打开了。

# 第412章 米粒开花

门外那声助跑，像一颗石子砸进死水，整个大厅的空气骤然收紧。

林雾后背贴着墙，目光死死锁住那扇玻璃门。门外的黑暗里，脚步声由远及近，由缓变急，重重地落在地上，咚咚咚地逼近。方晴一把攥住他的手腕，指甲几乎掐进肉里，低声说：“别动。它冲进来之前，会先撞上门槛上的铁条。”

话音未落，门外传来一声闷响——像是肉体撞在什么硬物上，发出一声既沉闷又黏腻的钝响。黑暗裂开一道缝，门槛上那根锈蚀的铁条猛地弹起，像被什么看不见的力量拨动，发出尖利的颤音，随即“咔”地断裂，落在地上。

门没开。但那条铁条断了。

林雾的呼吸顿了顿。他低头看向自己手中的纸片，“还”字亮成暗红，仿佛正被点燃。三只搪瓷碗底的字纹同时浮起同样的光，像三枚呼应的小钟。他忽然想起什么，翻过手中的米粒——那颗裂开的米粒里有父亲的笔迹，可米粒的外壳已经呈现出一种诡异的半透明，像壳里有什么东西正在生长。

“米粒。”林雾听见自己的声音，带着一丝沙哑，“这米粒，不是用来藏的。”

他猛地抬起手，将那枚米粒按在碗底中央。米粒碰到“还”字的瞬间，发出一声极轻的“啪”，像干壳爆裂。随即，米粒上裂开一条细缝，一根白色的芽从缝里探出来，像一根根须，稳稳扎进碗底的釉面里。那只碗底的字纹开始涌动，慢慢地，白芽竟变成一枚极小极小的绿色叶片。

林雾看呆了。叶片展开，露出一行极细的字，用工整的蝇头小楷写着：“还，不是动词。是名。”

门外传来一声低笑。那声音里的笑意带着一股说不出的熟悉感——既像归还者，又像他父亲，可在最深处，又有一丝不像任何人的冰冷。那声音说：“你终于让它开了花。到了这一步，就没有回头了。”

方晴的目光落在那片叶子上，脸色微微发白：“米粒开花……那是一个‘记号’。”她顿了顿，似乎是在权衡要不要说，最终还是开口，“档案馆里流传过一句话：能让人把米粒种进碗底的，只有一种人——建造者。”

林雾猛地抬头：“建造者？”

方晴点头，但很快又摇头：“只是传说。馆员手册里没人写这一条，我也是听我父亲提过一嘴。他说，建造者留下的东西，都会用米粒封存，等有人亲手种活，它才会说出真正的名字。”

“真正的名字？”林雾盯着叶片，心中隐隐升起一个猜测，“这米粒里藏的，不是规则，是一个……”他顿了顿，把那个词咽下去，改用眼神问方晴。

方晴读懂了他的疑问，却摇了摇头：“我不知道。但如果它是名字，那它一定是给门外那个东西听的。”

门外又传来一声低低的笑。这一回，那声音的声调慢慢变化，从归还者变成林海，再从林海变成一个林雾完全陌生的音色——嘶哑、苍老，像被水泡了许久的木头：“那只碗，你父亲曾经也埋过一粒进去。你猜，他种出来的是什么？”

林雾没有回答。他的目光落在碗底那片嫩叶上，看见叶脉的纹路正一点一点地向碗沿蔓延，像在描画着什么东西的轮廓。他不敢眨眼，因为叶片描画出的轮廓，隐约是一张脸。

他认识那张脸。他从小到大，照镜子时见过无数次——那是他自己的脸。

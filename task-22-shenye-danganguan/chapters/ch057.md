# 第57章 影子对口令

凌晨一点十七分，档案馆的日光灯管发出一声细微的电流嘶鸣。

林雾坐在值班台后面，不敢去看自己的右手。那个新出现的眼睛纹样在借阅章的边缘微微发烫，像一粒烧红的铁砂嵌在皮肉里。他盯着面前摊开的蓝皮书，第55次借阅的记录还在，圆珠笔迹干透，墨色沉着，不像是新写上去的。可他不记得自己写过。

走廊尽头传来脚步声——很有节奏，一步，顿住，又一步。

林雾抬头。一个穿黑色风衣的男人站在B区入口的标识牌下，手里拿着一卷泛黄的纸，脸被阴影遮了大半。

“新来的？”男人的声音低而平。

“晚班馆员，林雾。”他说出口才想起十二铁律第三条：不要在馆内主动报名。

但男人没接这个茬。他走近了两步，把纸卷放在值班台上，摊开。纸上是一列列抄写的字迹，像某种账目——借阅人、日期、编号、归还状态。林雾扫了一眼，看到最底下一行：A-000，借阅人“林雾山”，状态“已归还”。

“我叫老周。”男人说，“你可能听说过我。”

林雾怔住。老周——就是老周。前几晚他在B区听见档案生长的沙沙声时，档案架上挂着老周的工牌；D区垃圾桶里有一张老周的排班表；方晴提起过一句“上一任夜班馆员，走得急，什么都没带”。而现在这个“走得急”的人活生生站在他面前，只是脸色灰白，影子在灯下显得比正常人矮了一截。

“你的影子慢了一拍。”老周指了指林雾脚下。

林雾低头。他的影子安静地伏在地上，指尖的位置似乎比实际手指短了一寸。

“我不是来吓你的，”老周说，“我是来对口令的。借阅章上的眼睛，你看见了。”

“你怎么知道？”

“因为我也‘收过’一枚。在左手的虎口。”老周卷起袖口，露出一枚同样的眼睛纹样，但已经褪成浅灰，像捂了很久的淤青。“眼睛认人。你不合眼的时候，它替你记住你忘掉的事。”

林雾迟疑了一下：“老太太——那个驼背的，她让我第三夜去A区第七排。说钥匙在借阅章里。”

老周沉默片刻：“她说的对，也不对。借阅章确实能开锁，但钥匙不是章本身——是你的影子。那枚眼睛是一把锁的锁孔，你的影子是插进去的钥匙。你第一次点亮它的时候，影子就替你去了一趟‘未归档’。”

“什么意思？”

“意思是，你影子现在比你多知道一点东西。”老周说，“它伸向抽屉的那个动作，不是它自发做的——是它替你完成了一件你忘了做的事。你收到那封信，不是因为有人寄给你，而是因为你自己从‘未归档’区把它带了出来。”

林雾后背发凉：“那信上写的‘第四夜用她的影子换回你的影子’……”

“她是谁，你自己心里有数。”

老周说完这句，把纸卷重新卷起来，转身往回走。走到D区门口时，他停了停：“记住，晚上别在镜子前面对口令。你的影子会先开口。”

林雾愣在原地。他下意识抬手摸了摸右手小指上的借阅章。

它烫了一下。

像是……在回应什么。

“老周——”他追出两步朝走廊喊，“你影子呢？你的影子去哪了？”

D区尽头传来一声门合上的闷响，随即寂静。林雾回到值班台，把那张纸卷重新展开，才发现最底下一行的“已归还”三个字下面被人用铅笔写了一行小字：

「下一次借阅的人，会在镜子里看见自己身后的第二个影子。」

值班室右上角的墙镜里，林雾看见自己的倒影——他右手垂在身侧，安静得过了头。而大概是错觉，他好像看见镜中倒影的右手，正抬起，冲他做了一个“

别说话”的手势。

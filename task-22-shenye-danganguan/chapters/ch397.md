# 第397章 借阅卡背面

凌晨两点。馆员休息室的铁皮灯依旧亮着，灯罩内侧十二道辐条线在光线里投下十二道阴影，像牢笼的栅栏。

林雾坐在桌前，面前摊着一张借阅卡。

卡片是深蓝色的，边角磨损得发白，正面印着“深夜档案馆”五个字，下方是一行编号——不是A-000，不是任何区段的编号。那是他自己的名字，林雾两个字，墨迹才刚干透，像是有人趁他不注意时刚刚填上去的。

“这不是我的卡。”他听见自己的声音有点干涩。

陈叔站在门口，马灯已经熄了，他整个人陷在阴影里，只有半张脸被灯光照亮：“谁跟你说，借阅卡只有借书的人才有？”

林雾没听懂。

“深夜档案馆的借阅卡有两种。”陈叔的声音很慢，像是在斟酌每一个字的重量，“一种是你借档案时用的。另一种，是你被借走时用的。”

“被借走……”

林雾的目光落在卡片背面。那儿印着一行小字，他刚才没注意到——不，是刚才根本没有那行字。现在它出现了，像是卡片自己长出来的：“归还期限：零点前。逾期扣除：影子。”

影子。

他下意识低头看自己脚下。灯光在白墙上投出他的侧面轮廓，他的手抬起来，影子也跟着抬起来。但就在他放下手的瞬间，影子的手还停在半空中——慢了半拍。

上一次他违反“不许回头”规则之后，影子就开始慢了。

“陈叔，”林雾的声音沉了下来，“谁借走了我？”

老人没有回答。他从口袋里摸出一块老怀表，链子已经锈成了暗红色。他打开表盖看了一眼，没有看时间，而是在表盖内侧——那里刻着一个名字。林雾看见那个名字时，握杯子的手指一紧。

那是他父亲的名字。

“你父亲当年也是‘被借走’的。”陈叔说，“他签了一份契约，把自己抵押给了档案馆。抵押的东西写得很清楚——不是命，不是记忆，是‘下一次借阅’。”

“什么意思是‘下一次借阅’？”

“意思是，他这辈子最后一次借档案的时候，借的不是档案，是他儿子。”

休息室里安静极了，只剩铁皮灯发出轻微的电流声。林雾盯着借阅卡上自己那个崭新得近乎刺眼的签名，脑中一片乱麻。他从喉咙里挤出几个字：“那我现在……在谁手里？”

陈叔没有说话。但他缓缓抬起手，指向林雾身后。

林雾回头。他想起来的之前，父亲笔记最后一行写得很轻很淡，像是不愿被人看见的一次呼吸：“如果第四次掉在你手上，那不是我写的。是它写给我，我再写给你的。”

当时他没想通——不是父亲写的，那会是谁？现在他知道了。

铁皮灯罩内侧，那道与他纽扣吻合的圆孔旁边，不知何时多了一行极细的字迹，像是有人用针尖在铁皮上刻出来的，笔画干净利落，不像父亲的顿挫。上面写着六个字——

“还回来了，就留下。”

门外，走廊尽头传来第几次钟声——那枚本该停在三点三十三分的挂钟，此刻正斜斜指向两点零三分。挂钟下方站着一个人影，背着光，穿一件旧风衣，手插在口袋里，看不清脸，但林雾认出那只手——手指间夹着一枚铜纽扣，在灯下微微反光。

那是归还者。而归还者手边，搁着一本封面烫金的档案，编号“A-000”，标注“已归还”的下方，新添了一行笔迹：“尚未结清。”

林雾听见自己心脏漏跳了一拍。

归还者的目光穿过走廊，穿过门缝，直直落在他身上。然后那人开口了，声音很轻，却像重锤砸在耳膜上：

“林雾，你父亲把账还清了。现在该你还了。”

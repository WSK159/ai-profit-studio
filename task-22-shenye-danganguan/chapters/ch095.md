# 第95章 赭红蜡封

凌晨两点十七分。D区走廊的白炽灯发出低频的嗡鸣，像有什么东西在墙里磨牙。

我站在A区的铁门前，手里那张赭红蜡封的卡片已经捂得发烫。父亲的声音还在脑海里打转——那声“别签，回去吧”隔着门板传来时，像是被水泡过，发闷发沉，却比任何尖锐的警告都扎人。

“他为什么不让你签？”方晴站在三步外，没有靠过来。她跟着我站了一个多小时了，脚跟应该已经疼了，但她眉头都没皱一下。

我把卡片翻过来。正面只有一个徽记：一颗被线缠绕的圆，像是档案馆馆徽的变体。背面有一行凹印的细字，手指摸上去能感觉到凹槽的毛边——“签下即视为同意进入A区，期限以档案归还日为准；逾期未归，本人将转为A区抵押品。”

“期限以档案归还日为准。”我把这句话念出来，看到方晴的瞳孔缩了一下。

“你父亲借走的那条规则，归还没日期？”方晴问。

“灰衣人说‘三年前借走’，但他没说归还期限是多久。可能一年，可能十年，可能永远。”我收起卡片，回头看了一眼A区的铁门。门缝里渗出的光呈淡青色，和我见过的所有规则丝线颜色都不一样。A区是禁书区——被删除的规则与档案都存放在这里。父亲在这种地方待了三年。

走廊尽头传来脚步声。灰衣人再度出现，手里多了一沓纸，递给我的方向。他脸上没有任何表情，声音像被砂纸磨过：“馆长说，你可以先看申请单的条款，不急着签。”

“馆长说的？”我接过那沓纸，注意到第二页的角上有一个极小的印章——六角星形状，和馆长“零”提过的某个符号相符。“他刚才不是说替父还债必须签字？”

灰衣人没有回答这个问题，转身消失在走廊拐角的白光里。方晴走过来，站在我背后扫了一眼申请单上的条款，轻声说：“第三条写了什么？”

我的目光落在第三行。那里被一道黑色的墨线划过，像有人试图涂掉又放弃了：“曾经签署A-000契约者的直系后代，可依本人意愿代替履行剩余债务。替代人进入A区后，原抵押者家属可获每月一次的探视权。”

“探视权。”方晴的声音轻得几乎听不见，“你爸在A区里三年，有人去探视过他吗？”

我翻遍整份申请单，没有找到任何探视记录。也没有任何一条记载了“探视需要什么资格”。

父亲让我别签。可我看着那张申请单，看到“探视权”三个字，忽然明白了一件事：父亲三年前进A区，不是因为欠债，而是因为他想进去。这条“未归档规则”的归还期限从未被注明——它就是父亲给自己找的门。

他进A区是为了找什么。

我盯着门缝里渗出的青色光线，耳边忽然响起一道极轻的声音，像是从门缝里挤出来的：“林雾——你手里那封蜡封，背面还有一行字。”

我猛地低头。刚才摸过的那面凹印细字，正对着灯光显出第二行字，我原本没注意到的一行——“打开需要钥匙。钥匙在你父亲床头第二格抽屉的暗层里。”

我的呼吸停了半拍。父亲三年前离开时，房间一直保持原样，床头的第二格抽屉我也翻过多次，从来没发现什么暗层。

我转头看向方晴：“你今晚值班到几点？”

“四点到点。”她看向我，“你想回宿舍？”

“借你车钥匙。”我伸手。

方晴从口袋里摸出钥匙，递到我手心里的同时补了一句：“我跟你一起。”

我看着她，犹豫两秒，点头：“三分钟换衣服，楼下碰头。”

从D区到馆门需要穿过C区。我们快步经过时，我的余光瞥见角落那排新档案的脊背，其中一册在灯光下微微鼓起——像什么页面正在生长。

我没停下来看，但把名录记下了：C区，第27排，第七格。等回来再看。

走出馆门时，深夜的路灯把影子拉得很长。我的影子从迈出门槛那一步开始，就比我慢了半拍。

我想起那条铁律第七条，至今没人给我解释完整的规则。“不许回头”，可没人告诉我——如果影子慢了，该怎么办？

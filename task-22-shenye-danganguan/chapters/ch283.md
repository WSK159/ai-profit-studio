# 第283章 铁梯尽头的五楼

铁梯在昏暗的走廊尽头微微晃动，锈蚀的台阶上落着一层薄灰，却没有一根蜘蛛网。林雾伸手抓住扶手，铁管冰凉刺骨，掌心那枚蓝光“拆”字像被什么牵引似的，微微发烫。

“你听见了吗？”方晴的声音压得极低。

林雾侧耳——铁梯上方传来一种极细的摩擦声，像有人用指甲沿着墙面慢慢划行。他抬头，铁梯通往天花板的裂口，裂口上方漆黑一片，看不清尽头。

“五楼。”林雾喃喃。

他不确定那到底是不是真正的“五楼”——档案馆一共四层，这一点他第一天入职就确认过。D区深处那扇门通往“未归档”区域，但从未有人提过五楼存在。

“我一直以为档案馆只有四层。”方晴站在他身后半步，目光盯着铁梯上方，“我父亲留下的笔记里写过一句话——‘有些楼层不在一栋，有些档案不在馆里。’”

林雾回头看了她一眼：“你父亲还写什么了？”

方晴从口袋里掏出一张叠得极小的纸，展开后只有四行字，字迹确实与档案封面上的“方远舟”二字一致：“五楼没有窗户。五楼没有灯。五楼不住人。五楼住的是别的东西。”

纸的右下角有一行小字批注，用蓝墨水写着：“别数台阶。”

林雾正要迈上铁梯的脚停住。

他低头数了数刚刚确认的台阶数量——铁梯从地面到裂口一共十二级。可当他闭眼回想，脑海里浮现的却是十三级。多出来的那一级像一道错觉，又像一层遮在真实之上的薄纱。

“别数台阶……”他喃喃重复了一遍，决定不看脚下，只凭感觉往上走。

方晴跟在后面，两人沉默地爬上铁梯，穿过天花板裂口。一片漆黑包裹住他们，空气变得干燥，带着淡淡的纸灰味。

林雾摸出手机打开手电筒，光柱扫过，眼前是一条狭窄的走廊，两侧是木质档案架，但架子上空空如也。走廊尽头立着一扇门，门板与他记忆中父亲照片里的那扇门一模一样——老旧的棕色木门，把手是黄铜制的，上面刻着一行极小的字。

他凑近去看，指尖摩挲着铜把手的刻痕，终于读清了那行字：“这里没有明天。”

林雾瞳孔骤缩。他父亲留下的三封信里，第二封信的末尾写着同一句话——当时他以为是父亲的个人感慨，没想到是一扇门上的铭文。

“林雾。”方晴的声音忽然发紧。

他转头，方晴正指着走廊一侧的墙壁。墙面上涂着一层白漆，但白漆早已斑驳脱落，露出底下用红漆写的大字，每个字都有半人高：

**“归还者不得入内。”**

七个字下方，有人用黑笔补了一行小字，笔迹是他父亲的：“除非钥匙对了。”

林雾从口袋里摸出那串钥匙——四把钥匙，一把开档案柜，一把开归还窗口，一把是B区尽头门的十号钥匙，还有一把就是那枚空心的、没有刻字的钥匙。他甚至不知道自己为什么一直带着第四把。

“钥匙对了……”他举起那枚空心钥匙，对准木门铜把手上的钥匙孔。钥匙孔的形状极为古怪，不是常规的十字或圆形，而是一个歪斜的“归”字——正好和空心钥匙截面的形状吻合。

方晴上前一步：“你要开吗？”

林雾没有立刻回答。他把耳朵贴在门板上，门后传来一种低沉而有节奏的声响，像呼吸又没有温度，像钟摆又没有规律。片刻后，他听见门板内里传来一个极轻的、几乎听不见的声音，是父亲的嗓音：“……别开。”

紧接着，那道声音又补了一句，语气急促而扭曲：“别用那把钥匙，用你另一把。”

林雾低头，钥匙串上还有那把十号钥匙。十号钥匙是开B区尽头门的，和这扇门有什么关系？

“用了会怎样？”他低声问，像是问门板，又像问自己。

门板里传来一阵细碎的笑声，那声音逐渐变了调，从父亲的嗓音滑向一个完全陌生的、沙哑的腔调：“用了这扇门就会记住你。它就等着有人记住它——或者被它记住。”

林雾握着钥匙的手在半空停住了。

走廊尽头，一盏灯突然亮起，昏黄的光像一只睁开的眼睛。

灯下站着一个穿灰色大衣的男人，身形清瘦，低着头，脸被阴影遮得严严实实。他的右手戴着一只白色手套，手中捧着一本深蓝封面的档案册——册脊上的编号已经被磨得看不清。

方晴浑身一僵：“归还者。”

灰大衣男人没有抬头，声音低沉如从地底传来：“钥匙选错了。他不是借你们来开五楼这扇门的，他是借你们来看清自己手里拿的是什么。”

林雾低头，发现手里那枚空心钥匙不知何时已经变了——原本光滑的钥匙面上，隐隐浮现出两行细如蚊足的刻字：“借：归。押：门。”

和他之前看到方晴钥匙上刻的字一模一样。

他猛地抬头看向方晴，方晴也正低头看着自己腕间的“方远舟”三字，脸上血色尽褪。

灰大衣男人终于抬起头。阴影下，他的脸和林雾的父亲有六分相似——尤其是那对眼睛，眼尾微微下沉，像含着一整片说不出口的往事。

“林远川把你们引到这里来，是为了还一笔账。”他说，“但那笔账的债主，不是我。”

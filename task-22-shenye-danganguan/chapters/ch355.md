# 第355章 同款

脚步声是从铁梯上方的尽头传下来的，不急不缓，一步一步踩在铁皮楼梯上，发出那种老旧的、锈铁与鞋底摩擦的声音。

我攥着钥匙没有动。手心的火苗已经熄了，皮肤上连一道烫痕都没留下，只有那道新长出的细白疤圈在无名指上，隐隐发亮。地下室墙面上的影子在铁皮灯重新亮起后恢复了正常——至少看起来正常了。但我注意到一个细节，灯焰投出的影子里，我的左手上没戴任何东西，那道疤也没有对应。

那灰外套还瘫在墙角，领口朝下，像一件被随手丢弃的旧衣。脚步声越来越近，踩到铁梯最后一级时停住了。

地下室的门板被推开，走廊的暗光漏进来。我看见来人的身形，和自己几乎一样高，年轻，肩窄，穿一件和陈叔留下的纸片描述吻合的灰色呢子外套。袖口上，金线细密地缝着一道图案。那不是装饰，是补缝。和墙脚那件灰呢子外套袖口的金线，是同一种缝法。

“你比我预想的来得早。”他说。语气平淡，像是讨论天气。

我盯着他的脸，盯得很认真。他长着一张我能接受的脸—没有五官，或者说五官被一道深灰的影子罩住了，像一张被水洇湿的照片。只有领口下一截脖子露出来，皮肤白得不太正常。

“你是谁？”我问。

他没有回答。弯腰捡起墙角那件灰外套，抖开，披到自己肩上。两件外套一里一外，尺寸完全贴合，像同一件衣服的里衬和外皮。

“你是来查灯油的，还是来查你父亲的？”他没抬头，声音闷在两层面料里。

我没说话。但我摸了摸口袋里的那把钥匙。他的目光落在我手指上，忽然停住了：“你碰了那把钥匙。”

这句话的语气里终于有了一丝波动。不是惊讶，是警觉，像是某种被寄放在此的东西被陌生人拆封了。

“碰了会怎样？”

他没接话，快步走到铁皮灯前，低头看了一眼灯油。然后，他侧过头，第一次正脸朝向我。那道灰影覆盖下的五官似乎在哪一个角度透出人形轮廓，我看见他的嘴唇动了动，说了六个字。

那六个字和馆长“零”当初在档案馆五楼说的一模一样。

“灯油不是命。”

我不知道这句话是什么意思。原话不是“灯油即命”，也不是“灯油换命”，而是“灯油不是命”——从结构上像是在否定某种我尚未接触到的规则。他为什么也知道这六个字？难道他也去过五楼？还是说，五楼那位馆长说出的这六个字，本来就是从别人那里听来的？

我下意识问出口：“你是怎么知道这六个字的？”

他抬起手，指向桌面上那本无编号簿册：“翻开最后一页。”

我走过去，翻到簿册末端，那一页原先被我看见压痕的页面上，此刻多了一行字。字迹干燥，墨色新鲜，像是刚刚写上去的。写的是：灯油不是命，灯是。字迹不是陈叔的，也不是父亲的。是我自己的。我的字迹。横竖撇捺的角度，转折处的习惯，都是我在键盘上写了无数年代码后逐渐养成的手写字。但这一页的字是墨水写上去的。

我没碰过这支笔。我甚至连墨水都没在这里见过。

“你已经签过次了。”铁皮灯旁那人笑了笑，语气带着一丝奇怪的怜悯，“你自己不知道而已。”

他转身，拾级而上，留下一句话飘下来：“你父亲的账没还完，你的账还算不清。那件外套挂在这里是为了挡风——你把它取下来，灯油少了一半。现在你得自己想办法，去把人找回来。”

铁梯上方传来关门声。我低头看了一眼墙角，那件灰外套被他带走了。

铁皮灯的火焰重新跳动起来，火苗比刚才矮了半截。灯身里传出那声细微的晃动，液体几乎触不到底。而一直被我攥在手里的钥匙，不知什么时候已经不再发烫——它凉透了，像一块被浸过井水的铁，贴在掌心里，反而留下一点温热。

那温热来自我的掌心。那滴掉在地上的血也不见了，被谁擦得干干净净。

我在原地站了很久，直到确定脚步声彻底消失，才翻开那本簿册最后一页，认真看那行字。笔迹是我的，但它说的东西我不懂——“你已经签过次了”，哪个“次”？借阅的“次”，还是我根本没有选择权的那个“次”？

我把钥匙插进口袋，刚要跨上铁梯，脚下踩到一块被踢翻的木头。桌底那块“一十二”改刻成“二十三”的木条又翻了个面，背面居然还有字——新刻的痕迹，笔画还发白，写着两个字。

我认了很久才认出来，是“沈雾”。

那个面朝铁梯下方、方才离开的身影忽然在呼吸间模糊了一下，灰呢子大衣的衣角消失在转角处，像从来没有出现过一样。我紧握钥匙，一层细密的凉意爬上后颈。

他穿走了那件外套，拿走了我的影子，却把我的名字，刻在了木条上。

我顺着铁梯往上走，踏上回廊的最后一节楼梯时，尽头传来一声轻微的铁门碰撞。那扇门原本是缝上的，此刻虚掩着，露出一道细窄的缝，缝里透出灯光——档案室的灯亮着。

有人趁我在地下室的时候，进了档案馆。

# 第523章 纸页尽头的女人

黑暗没有持续太久。

林雾没想到第七区的“灯”，是档案本身。那些翻页声越来越密，随即一页、两页、三页档案从虚空中浮现，像被看不见的手抽出来，悬在半空。纸页发出微弱的白光，一个一个叠在一起，竟铺出一条窄窄的“路”——正好够一人的脚掌踩上去。

他低头，纸页上写满字，但那些字他一个也不认识。笔画扭曲如藤蔓，像某种极古老的契约文。

林雾踩上第一页，脚下的纸震动了一下，随后翻页声向前方延伸，新的纸张从黑暗里浮出、铺开，仿佛在为他指路。他走一步，身后的纸页就熄灭一页，无声无息地消失在黑暗里。

这条路，只能往前走。

林雾走了大约百来步，前方忽然出现一道微光。光不大，像一盏被薄纸罩住的灯。他走近了才发现，那是一张**垂悬在空中的纸**，纸质与人皮无异，上面写满了中文——这一次他认得分明：

**“第零册·补遗。秦、李、陈、赵、林——五人立馆之始，各承一职：守门、提灯、封笔、称量、写页。秦为守门人，以名代契，以发为继。秦削名入第七区，代偿馆债，期满未归，册页书其名三次，皆自燃。”**

下面另起一行，字迹更旧，几乎褪成灰白色：

**“秦之血，入第七区；秦之名，留第七区。后人若至，可代秦赎名。赎名之价：以另一人之名换之。”**

林雾读完最后一行，脸色白了大半。他父亲不是失踪——是把名字押在了这里。

他正想再读下一页，四周的纸页忽然同时亮起。它们不再是一条路，而是像墙一样将他围住，每张纸上写着同一句话：

**“你带来了别人的名。”**

林雾心头警铃大作。他想后退，但脚下的纸页已经燃尽，无处可退。他想开口否认，却想起方才在门外，他确实留过名字——留的是“林雾”，但凹槽上最终留下的只有一个“某”字。

他带来的是什么？

他还没来得及细想，纸页墙从中裂开一道口子，一个女人走了出来。她穿着档案馆的旧式馆员服，头发齐肩，灰白参半，脸上没有任何表情——像是已经很久没有做过任何表情了。

她手里捧着一册没有编号的档案，封面焦黑，像被火烧过又被人强行压回去的。

“你姓林。”她开口，声音和方才那句“秦……你回来了”一模一样，像同一个人的电流隔着几十年的距离传了过来。

“你认识我爸。”林雾说。

她没有回答。她打开那册焦黑的档案，翻到某一页，停在林雾眼前。那页纸上没有任何文字，只有一张照片——他父亲年轻时的照片，站在档案馆门口，身边站着一个人，正是眼前这个女人。

“我叫温秋。”女人说，“守门人的前任，秦代我入第七区时，他把名字折了一横，把我换出去了。”

她顿了顿，盯着林雾的眼睛：

“你父亲折的不是他自己的名字——他折的是我的。所以留在这里的，一直是‘秦’的一半，和一个不属于他的‘秋天的名字’。”

她合上档案：“你来了，第三份名字就齐了。第七区的账，终于可以清了。”

林雾脑中轰地一声——他终于明白，“灯下莫看影”那条规则、父亲削去“雾”字的横画、铜牌两道线痕，以及纸页上那句“以另一人之名换之”，所有线索在这一刻绞成一股绳，直直地指向面前这个女人。

他想问出口，喉咙却像被人掐住一般。

温秋垂下眼，说出一句：

“你父亲的债务，靠我的名字还了二十年。现在轮到你。你若想带走你父亲的‘秦’字，就把你母亲的姓留在这里。”

林雾的手僵住。

他母亲姓温。

温秋的温。

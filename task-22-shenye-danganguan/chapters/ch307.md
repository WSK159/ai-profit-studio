# 第307章 五楼的灯

林雾把钥匙握在掌心，金属的凉意渗进指缝。方晴跟在他身后，两个人踩着归档间台阶往上走，那只落款的旧皮鞋还歪在墙角，鞋尖朝门——像有人站在黑暗里，替他们指了一条路。

“你真打算把钥匙还给‘它的主人’？”方晴压着声音。

“零说拿不走，属于还债的人。那这钥匙从一开始就不该在我手里。”林雾停在铁梯拐角，回头看了一眼A区地下那道正在合拢的门缝。门缝里透出的光发黄，像老式灯泡烧到最后几秒。他听见墙面上那条黑色裂缝又“呼”地鼓了一下，仿佛什么东西在墙里翻了个身。

他加快脚步。

上到一楼大厅，正对归还窗口的挂钟指向两点四十七分。馆内依旧空旷，十二铁律中第三条——不许在3:33睁眼——还差四十六分钟生效。方晴去查归还窗口有没有新档案，林雾站在原地，低头看手里的钥匙。

第四格，无刻字，铁锈沿齿纹爬满一线。他捏住钥匙柄转了半圈，齿尖在灯下一闪，像吞了一星光。

“你在想什么？”方晴回来，手里空着。

“我在想，五楼。”林雾把钥匙收进口袋，“零说‘它’要醒了，七号说父亲在五楼等我。这两个说法，可能指同一件事。”

“五楼一直是禁区，连馆长都不提。你打算怎么上？”方晴蹙眉，“D区深处那扇门你也知道，铁梯——”

“铁梯通往五楼。”林雾打断她，“陈叔批注里写过。”

方晴沉默了几秒。“那我跟你一起去。”

“不行。”林雾摇头，“3:33之前你必须回馆员区。别忘了铁律第三条是你父亲——方远山——亲自抄在手册扉页上的。他说‘睁眼的人会看见不该看见的东西’，他没骗人。”

方晴咬了咬唇。她掌心的“还”字已经淡得只剩三笔，像被水浸过的墨，随时会散。“你一个人上五楼，万一——”

“万一出事，你就去归还者那儿。他欠我一条‘借线续命’的债。”林雾把自己的手电筒塞给她，“拿着。替我看着点归档间那道裂缝，别让它合上。”

方晴接过手电，目光在他脸上停了一瞬，没再争。

林雾转身往D区走。

馆员区的灯比大厅更暗，走廊尽头那扇铁门半掩着，铰链锈得发沉。他推门时门轴“吱——”地拉出一道长音，像有人在他耳边叹了一口陈年的气。铁梯向下通往前台的暗间，向上——他抬头，梯井黑洞洞地延伸，尽头看不见顶，只有风从上面倒灌下来，卷着纸灰与铁锈的味儿。

他踏上去第一步。

铁梯发出空心的金属声响。他记着五楼“别数台阶”的规则，目光只落在脚下两级以内，一步一步往上走。到第三层拐角时，他忽然停住——拐角的墙壁上不知什么时候多了一道刮痕，铁皮翻卷，像被锐器划过，划痕末端隐隐带着一点暗红色。

“铁牌刮痕。”他心口一紧。

这正是他列在待办清单里那条：母亲留下的铁牌背面，那道刮痕和这处形状几乎一致。他俯身凑近，借着梯井上方漏下的微光，认出那道刮痕不是随意划的——是四个字的首笔，断断续续，只留下第一个“别”字的起笔，后面三个字被锈蚀抹平了。

别……什么？

他压下疑惑，继续往上。第四层、第五层——

梯井尽头一扇门，门板是新近换过的，木纹发白，上面用炭笔写着一行字，笔迹他认得，是陈叔的：“拆。”

林雾伸手推门，门没锁。

门后是一条极窄的走廊，墙面剥落，露出里面红砖砌体。走廊尽头亮着一盏灯，灯下放了一张木椅，椅子上没人。但椅背上搭着一件旧外套——深灰色，袖口线头散开，是他父亲买过的那件。

走廊里很静。林雾一步步走过去，外套上那枚领口扣子缺了一颗，剩下那颗是深蓝色的，和记忆里一模一样。

他伸手去碰外套的瞬间，旁边那扇窗“咔”地响了一声。

五楼第二扇窗，玻璃上斜纹如旧，但今晚窗台上放着一只信封，封口未粘，露出里面半张纸。林雾抽出那半张纸，是笔记本内页的残片，边缘被烧过，焦痕沿字迹卷曲，上头只有一行字：

“钥匙别给他。他在五楼认主。”

他还没来得及细想，走廊尽头的灯忽然闪了一下。灯下，那把椅子旁多了一双鞋——正是他在归档间看到的那只旧皮鞋的另外一只，鞋尖朝着他。

林雾攥紧口袋里的钥匙，掌心全是汗。

就在这时，他身后那扇门“吱——”地合上了。门板上不知何时多了一行手写字，墨迹未干：

“它醒了。你带钥匙来，就是为了让它醒。”

林雾霍然回头。走廊尽头那件灰外套的领口，正在无风自动。

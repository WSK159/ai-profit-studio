# 第502章 钟摆里的记忆

钟摆的摆动声停止了。

林雾不知道自己是醒着还是在梦里，他只知道此刻他坐在一把椅子里，面前的台面上摊着一卷泛黄的档案纸，纸上的字迹很熟悉，是他的父亲的字。但奇怪的是，他读得懂这些字，却想不起写下这些字的人长什么样。

“你终于来了。”

声音从档案纸里传出来，不是从耳朵进来的，倒像是从骨头缝里渗出来的。林雾低头，看见纸面上的墨迹正在重新排列，新的句子浮现出来：

“坐进钟摆的人会忘掉自己，但全馆借出的规则都记得他。这句话你听人说过，对不对？”

林雾点头。他不知道为什么要点头，但他确实记得这句话——不，准确说，他不记得自己是什么时候听过这句话，但他确定自己听过。

“规则替你保管记忆，等你走出钟摆的那一瞬，契约才会把它们还给你。”墨迹继续流动，“但如果替你付那一秒的人，在你走出之前就消失了，你的记忆就会永远留在档案馆的账本里，变成一条出账记录。”

出账记录。这四个字让林雾心头一紧，虽然他不明白自己为什么要紧张。他低头看着自己的手，手指上套着一枚铜环，环上刻着三个模糊的数字，像是被人磨过。

“你在看什么？”墨迹问。

“看这个。”林雾举起手，铜环在昏暗的光线下泛着沉旧的光。他眯起眼睛，辨认环上的字迹：“A……零零……零。”

“A-000。”墨迹回复，“你的编号。或者说，你父亲的编号。你们共用同一个编号，因为在他的名字被删除的那一刻起，档案馆就把他的责任转移给了他的血亲。你签契约的时候，签的不是自己的名字，而是A-000这个出账编号。”

林雾放下手。他隐约记得有一份契约，签署的瞬间笔尖带着冰凉的刺痛，但他不记得契约的具体内容了。他抬头环视四周——这是钟摆的内部吗？周围没有墙，没有地板，只有无边无际的白雾，雾中偶尔闪过一条金色的丝线，像是某道规则的边界。

他站起身，想往雾里走。起身的瞬间，脚下的地面忽然变成水面一样的镜面，镜中倒映着他自己——但他看见的不是自己的脸。

倒影里是一张女人的脸。

眼角一道旧伤疤，从眉尾一直延伸到颧骨。她正仰着头，嘴唇翕动着，吐出三个字——林雾盯着她的嘴型，认出那三个字是“别忘我”。

他忽然想起自己确实听过这三个字。在很久很久以前，在他还是一个孩子的时候，有人抱着他，也是这样用嘴型无声地对他说话。那人放他下来的时候，手指在他眉心点了一下，凉丝丝的，像是落了一点雪。

那个女人是谁？

镜面裂开一条缝，金色的光从裂缝里漏出来，林雾低下身去看，裂缝里伸出一只手——骨节分明，指甲修剪得很整齐，掌心躺着一张纸片。纸片上写着一行字：

“寅时原属陈芜。第999位馆员。她坐进钟摆后，没人听见第三声钟响。”

林雾捏住纸片的瞬间，裂缝合拢，那只手缩了回去。钟摆内部的白雾开始旋转，林雾感觉到一阵巨大的引力把他的身体往上拽，耳边响起齿轮转动的轰鸣声。他攥紧纸片，想看清上面还有没有别的字，纸片却在他手里瞬间变凉、变脆，化成了一撮灰。

“那是替钟摆付过时间的女人。”声音又从墨迹里传出来，“她坐进来的那晚，替她付下一秒的人没有出现——所以她到现在还坐在钟摆里。你以为寅时缺位是因为没人肯坐，其实是坐过寅时的人根本没出去过。”

林雾的身体正在一寸寸上升。他低头，看见钟摆的地面已经变成一块透明的玻璃，玻璃下面是密密麻麻的、像树根一样盘绕的金色丝线——那是规则，全馆所有借出的规则的形状。而在那些丝线的最底部，坐着一道人影。

女人。坐姿端正，双手交叠放在膝上，头微微低着，像是在打盹。但林雾看见她的眼睛——她睁开眼睛了。

隔着十几米深的规则丝线，她抬起头来，和林雾对视。她的左眼角有一道旧伤疤，从眉尾延伸到颧骨。

陈芜。

林雾听见自己心里念出这个名字，这名字像一根钉子一样死死扎进他空白的脑海中。他记住了这个名字，尽管他不知道自己为什么必须记住。

“她替你付过一秒。”墨迹最后写，“记住她，出去之后，去B区找她的档案。如果她的档案还在，你就能找回自己。”

钟摆旋到底。林雾眼前一黑，重新坠入意识的深渊前一秒，他感觉到有温热的液体顺着他的耳廓流下来——他在流血，不是鼻子，不是眼睛，是耳朵，像有一条看不见的丝线从他耳道深处抽走了什么东西。

他忘了自己是谁，但他记住了一个女人和三个字。

# 第423章 残页

那六个字下方还有一行小字，墨迹更深：“别让陈叔帮你续命。他的债，比我的命长。”

林雾盯着这句话，指尖微微发僵。他把这页揭过去，露出第二页——一片密密麻麻的小字，排列整齐，像账本一样规矩。他扫了两行，认出那是日期和对应的事件：

“1997年3月1日，门外之物第一次敲门。借A区规则十二（遗忘），三日未还。”

“1997年3月4日，规则被归还，但借阅人变成‘我’。代价：取走我左耳的听力。”

“1997年3月7日，第三次敲门。门外之物提出交易：用档案馆所有失眠者的梦，换一张通行证。”

林雾的手顿住了。他继续往下读：

“1997年3月9日，我拒绝。门外之物改口：只要一个人的梦。”

“1997年3月10日，我在C区写了第一笔改写。那是我此生最后悔的一件事。”

林雾往后翻。第三页，字迹忽然变得杂乱，笔画连着笔画，像是写的人手在发抖：

“他们说我疯了。但我知道不是。档案馆的规则从第一天起就是活的——有人把它当仓库，有人把它当监牢，只有我知道它是一扇门。门外的东西想进来，门里的东西想出去，规则只是两边的赌注。”

“我是A-000。我是钥匙。我是锁。我是那个被选中的人——因为我能看见规则的形状。”

第四页开头，字迹骤然安静下来，像写的人终于下定了决心：

“林雾，你读到这页的时候，我大概已经走了（不是失踪，是离开。两者不一样，你以后会懂）。档案馆里欠下的债，我一个字都没打算留给你。但有些债是写在纸上的——写在我推着你走到这一步的人生里。你躲不开，只能替我还。”

“我没求你原谅。我只求你——读完第三页之后，把手放在A-000的签名处，握拳，用你右手食指第二指节敲三下档案夹。然后，把你左耳贴上去。”

林雾愣了一下。他下意识摸了摸自己的左耳，那耳朵好端端的，什么声音都能听到。但父亲在日记里写“取走我左耳的听力”——那意味着他父亲是左耳聋的？可他从来没见过父亲的左耳。父亲失踪那年，他十五岁。他记得父亲总喜欢把头发留到耳根，遮住耳朵。

他没多想，翻到第三页。

这一页只有一句话，字迹平整如印刷：

“门外之物何时来？——答案已经写在你右手的掌纹里。”

林雾放下档案，下意识摊开右手掌心。他的掌纹一直很清晰——生命线细长，感情线短，智慧线有一道分岔。但此刻他低头看，发现右掌心的智慧线分岔处，多了一道淡淡的红线，像滴上去的血被指腹抹开。

那根线弯成了一个弧度，像一条蛇咬住了自己的尾巴。和他在档案馆大门台阶上看到的一模一样的咬尾蛇。

他继续翻。第四页是泛黄的，边角烧焦了一小块，字迹因受潮而模糊，但能辨认出几行字：

“——借阅规则的本质，是给予者拿走借阅者的‘剩余’。你借走一日，就少一日；借走一夜，就少一夜。我借走的三十年，不是我自己选的。是那个碗选的。”

“钥匙的代价：当你拿起钥匙时，你就是锁本身。你爹是A-000，你也会是。除非——”

字迹到这里中断了，末笔划出一道失控的长线，像有人在写字时被猛然拽走了笔。

林雾把残页全部翻完，最后一页背面是空白的。他按父亲写的方法，握住档案夹，用右手中指第二指节在签名处敲了三下。

敲完第三下的瞬间，档案夹发出一声干燥的“咔哒”，像锁舌弹开。他把左耳贴上去——

他听到的，不是档案里的声音，而是档案之外、三排七格的方向传来的脚步声。

那脚步声很轻，却有着奇怪的节奏：走一步，停两拍，再走一步。像是某个东西在模仿人走路。

然后他听到了陈叔的声音，只有两个字，却让林雾整个人僵住。

陈叔说：“来了。”

而林雾左耳里，档案里传来他父亲的声音，低沉而急切：“敲门的人到了——别让陈叔先开档案架。他要的不是钥匙，是你。”

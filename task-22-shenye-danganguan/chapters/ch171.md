# 第171章 声音的价码

门内的叹息声消散后，林雾的喉咙像被灌入一口凉水。

他试着清了清嗓子——没有声音。不是那种感冒失声的沙哑，而是彻底的空，仿佛声带根本不归他管。他张开嘴，气流从唇间漏出，却带不起任何振动。

值班室的日光灯滋滋响了两声，像是也在嘲笑他。

林雾低头，摊开右手掌心。那里有一行字，墨黑色的，像是从皮肤内里渗出来的：`声音·已归属 A-000`。

他盯着那行字看了三秒，然后从口袋里摸出手机。

打字，发方晴。

“我没法说话了。”

发送键按下，屏幕发出微弱的蓝光。他还没锁屏，方晴的回话已经弹出来：

“我知道。你那边墙上有没有钟？”

林雾抬头。值班室东南角的墙上挂着一只老式挂钟，秒针在走，但指针停在 3:33。

他心脏猛地一缩。那是馆员铁律第三条：不许在 3:33 睁眼。

可现在不是 3:33。挂钟显示 3:33，手机屏幕右上角的时间却是 2:47。这只钟停了。

方晴第二条消息紧跟着进来：“你现在听着，别抬头看灯，别转身。那只钟是后来挂上去的。挂它的，是一个和你爸签过约的人。你知道那六字纸条的事吗？”

林雾打了一个字：“知。”

方晴：“‘下次提前关门’——那不是通知，是规则。C 区第七排那些归还单，你摸了没有？”

他摸了摸。方晴：“数一下有几张。”

林雾重新走到 C 区。第七排书架靠墙，新摆的那只铁皮文件夹里，规规整整地叠着七张归还单。从日期看，跨度十一年。每张签的都是同一个名字：林默，林父的名字。七张。

他打过去：“七张。”

方晴的回复慢了几拍，然后是一段长文，看上去有些激动：“我爸也签过七张。跟我妈一人三张，加上我一张替补的。”她顿了顿，“林雾，你爸签的第七张，借的是‘声音’。你替他续了这张约，已经相当于把你的声带抵押给了 A-000。你得在下次提前关门之前，把声音换回来。”

林雾：“怎么换？”

方晴：“听见三声钟响，去还书窗口，把那张签过名的归还单放回去。归还单上的字会自己改——先还旧账，再借新规。”

林雾关掉手机屏幕。值班室的灯又闪了一下，这次，他听见挂钟“嗒”地一声，秒针动了。

从 3:33，走到 3:34。

那扇门内，又传出一声叹息，这次近得几乎贴着后脑勺。

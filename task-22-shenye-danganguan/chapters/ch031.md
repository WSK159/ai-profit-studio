# 第31章 锁芯之外

门是从里面反锁的。林雾背抵着D区休息室的铁门，手掌按在冰冷的门板上，感觉到锁芯在掌心底下转动——一格格地转，像有人在另一边用指甲尖拨弄着锁簧。他刚上过锁，双层保险，钥匙还插在锁孔里，钥匙柄上拴着档案馆配发的黄铜牌。现在钥匙还在，锁芯却朝反方向拧了半圈。

“谁？”他压低声音。

没有回答。锁芯又转了半圈，发出细碎的金属摩擦声。林雾退开半步，盯住锁孔，看见黄铜钥匙柄轻轻晃了一下——像是被什么东西从门那边碰了一下，又像是门板自己呼吸了一下。

他抬头看墙上的钟：3:22。

距离B区铁门里那个声音说的“3:33前别开门”还有十一分钟。

林雾掏出手机，直播间还开着，画面定格在988人，弹幕已经停了。方晴的头像在私信里跳动，他点开，只有一行字：“别数观众数，退出来。”

他把手机揣回兜里，转身面对那扇门。钥匙插在锁孔里，锁芯安静了。林雾伸手，指尖碰到钥匙柄的一瞬间，锁芯又转了一下——他猛地抽回手，心跳撞在耳膜上。

这不是风吹的。锁芯的内侧，有人在转动它。而门被反锁后，内侧只有他一个人。

林雾抬手，用指节敲了敲门板：“零？”

门外传来脚步声，很轻，像赤脚踩在瓷砖上。然后有人敲了三下——从门的那一边。三下，依次是长-短-长，节奏非常熟悉。他七岁那年，父亲每次晚归回家，用钥匙开门前都会在门上敲三下：长-短-长。母亲说那是他们老家的习惯，只有林家人这么敲。

林雾的喉咙发紧。他凑近锁孔，眯起一只眼睛看过去——锁孔里一片黑，什么都看不见。但他闻到一股味道：旧纸、灰尘、樟脑丸，还有一丝淡淡的烟味。那是档案馆A区深处的气味，也是父亲书房里存在了二十年的气味。

“爸？”他嗓子发哑。

门外面安静了两秒。然后，一个男声贴着门缝渗进来，像是隔着一层厚厚的棉布说的，音色模糊，但咬字清晰：“别开，他正在写你。”

林雾猛地攥住门把手：“谁在写我？爸，你说清楚——”

门外传来一声非常轻的纸张翻动声。然后是脚步声远离，越来越远，直到完全消失。

林雾站在门边，心跳快得像擂鼓。他看向墙上的钟：3:26。

他低头检查锁孔，钥匙柄已经不再晃动，锁芯归位。但门边上多了一样东西，原本没有的东西——一张纸条，对折成四折，从门缝底部塞进来一半。他蹲下去，拾起纸条，展开。

纸条上的字迹他用一生都认得出来。是父亲的笔迹，但比记忆中的更草更急，像赶着写下的：

“零在借你。他借的不是影像，是规则。A-000 的欠条用的是你的名字。3:33 别开B区，但一定要开这扇门。开完就跑，别回头。”

门缝底下又塞进来一张纸。林雾伸手拿起来，这一张不是纸条，是一张照片，边角泛黄，像泡过水又晒干。照片拍的是一间档案室的全景，书架从地板顶到天花板，密不透风，但正中间那张桌子上摊着份档案，档案正面用钢笔写着四个字：A-000。

照片左下角露出一个人的侧脸，正对着镜头，嘴角微微勾起。那是他父亲，二十四五岁的样子，比林雾记忆里的父亲年轻很多，眉眼却一模一样。而那张照片上的父亲，手里握着一支笔，笔尖正落在档案的签名栏上——签的字不是“林深”，也不是任何人的名字，只有三个字：“借阅人”。

林雾捏着照片的手指发白。墙上的钟走到3:31。门外又传来脚步声，这次比刚才更近，像是有人站在门板外面，正对着锁孔。

他听见锁芯发出了第一次真正意义上的转动声。而钥匙，插在锁孔里。

钥匙的另一头，有人在从外面拧它。

林雾低头看着手中的照片，照片里他父亲的目光似乎越过二十年的光阴，直直地望着现在的他。还有两分钟。

他深吸一口气，握住了门把手。

# 第106章 影子

照片里二楼窗口的那个人影，让林雾在走廊里站了很久才回过神来。他反复确认了角度，又拿着手电筒仔仔细细看那块玻璃，没看出任何痕迹。二楼的房间都是封死的，窗户后面糊着厚厚的白纸，灯光透不进去——这张照片却拍到了窗后的人影。

一个和他长得一模一样的人。

他深吸一口气，把照片翻回来，重新看了一遍画面里的自己。十五年前的小男孩确实在笑，手里还捏着一只纸飞机。但仔细看，那个小男孩的脚下——阳光照着台阶，他的影子落在右侧地面上，凝成短短一团。而二楼人影的位置，恰好就在照片画面中台阶正上方。

没有更多时间深想。走廊尽头传来一声轻微的撞击声，像是什么东西被放回了原位。

林雾循声追出十几步，拐过弯，看见一个穿深色风衣的男人的背影，正顺着楼梯往一楼走。他手里的登记簿，是B区的深蓝封皮。

“站住！”他喊了一声。

那人停住脚步，没有回头，声音却传过来——低沉、平静，带着一丝疲惫：“你和你父亲长得真像。”

林雾握紧手电筒：“你是谁？”

“我是来还东西的。”那人说，“你可以叫我归还者。”

这个名字让林雾后背一紧。归还者——方晴提过这个人，替档案馆处理“逾期未还”的人，专门上门回收遗忘之物。他追上前两步：“你还什么？”

归还者从口袋里掏出一样东西，放在楼梯扶手上，是一个牛皮纸信封，封口用红蜡封缄，蜡印的形状是一枚钥匙。他没有转身：“你父亲当年借了这件东西，逾期了十五年，今天我来收账。”

“我父亲借了什么？”

“他的名字。”归还者说，“A-000，林文远。他当年借走的是自己的名字，逾期未还，所以他的档案被删除。现在账期到了，档案馆要收回。”

林雾心里一沉：“什么叫收回名字？他已经失踪了——”

“他失踪，是因为他还没有还清那笔账。”归还者终于微微偏过头来，露出半张脸，颧骨很高，眼窝深陷，像好几年没睡过一个安稳觉，“你作为他的直系后代，有权替他续账。只要你签字，账期就可以再拖十五年。”

楼梯口静了片刻。

林雾想起卷宗里的规则：违规不可由他人代偿，只有直系血亲可以。他曾见过方晴在归还窗口前签字替父还债，当时并不明白这意味着什么。现在他站在这里，归还者给他一张“续账”的机会，而代价是——他的签名，绑定在他父亲的名下。

“签在哪里？”他问。

归还者从口袋里抽出另一张折好的白纸，递到他面前。纸上的条款只有一行：兹替林文远续借其名，期限十五年，到期归还。签名处是一道横线，字迹是陌生的左手笔迹——就是赭红卡上他看到过的那只手。

原来那道字迹是留给他的。

林雾盯了片刻，没有急着签。他忽然问：“你说的还东西，还什么？”

归还者沉默了一下，从风衣内袋里取出一个小小的布包，放在信封旁边。布包旧得发灰，他解开，里面是一枚铜章——铜章上刻着两个字：“林间”。那是他父亲旧物的另一件，他曾在档案中见过记录，以为早已丢失。

“你父亲欠的不只是名字。”归还者说，“他还欠一枚章。当年他拿到这枚章之后，就没有还回来。”

林雾盯着那枚章，忽然想到什么：“这枚章是不是有人送他的？”

归还者终于转过身来，正面看他。他深陷的眼窝里，有一瞬间的光亮闪烁：“你知道林间？”

“档案上记载，我父亲曾与一名叫‘林间晚’的人联手进过档案馆深处。后来那个人消失了。”

归还者没有接话。他沉默地站了很久，最后开口：“那枚章，是林间晚留给你父亲的遗物。你父亲借走名字之前，曾用这枚章盖过一份档案——那份档案，就是A-000。”

走廊里的灯闪了一下。林雾听见自己的呼吸声变得粗重：“A-000是什么？”

“是你父亲的名字。”归还者说完，把铜章推向林雾的方向，“拿好。你续了账，这枚章就归你保管。十五年后到期，来换回你父亲的名字。”

“如果我拒绝签字呢？”

归还者看他一眼：“那你父亲的名字今晚就会被删除彻底，连同你这个儿子的记忆。你明天醒来，不会记得自己有个父亲。”

楼梯间安静了一会儿。

林雾拿起桌上的笔，在那横线上写下自己的名字。笔尖触纸的瞬间，他感到一阵针扎般的轻微刺痛从纸上传来，像无数根细线牵动了什么。他低头一看，自己脚下的影子——那个慢半拍的影子——动了。

影子侧过头，看了看他，然后笑了。

“账入。”归还者说，“铜章归你。十五年后，你来找我。”

他说完，转身走下楼梯，脚步声消失在一楼。林雾站在原地，捏着铜章和那信封，低头去看自己的影子——暗黄色的灯光下，影子贴在地面，姿势却直直立着，正仰头看着他。他动了一下右手，影子慢了半拍才跟上。

他忽然想起馆员手册第七铁律：影子不随原身者，不得上二楼借阅区。他现在的影子，已经不合格了。而他手里那枚铜章的背面，不知何时浮现出一行细小的刻痕：

还清所有欠账，才可找回名字。

# 第424章 活着的账

“别让陈叔先开档案架——他要的不是钥匙，是你。”

父亲的声音像从水底浮上来，每个字都带着潮湿的回响。档案夹在我手里微微发烫，纸页边缘卷曲，像被什么东西从内部烘烤过。

我猛地抬头。

陈叔没有动。他站在原地，眉心的伤口还在渗血，一滴一滴落在三排八格的地砖上，发出闷响。那根铜丝弯针被他重新握在掌心，弯针的尖端微微翘起，像一条随时准备弹射的蛇。

“林雾。”陈叔开口了，声音比刚才低了几分，“你听见了。”

“听见什么？”我盯着他，手指下意识收拢档案夹。

“你父亲的声音。”陈叔指了指我手里的档案，“A-000 会读取接触者的记忆。你听见的是他留在纸页之间的回响。但那句话——”他眯起眼睛，“不是你父亲说的。”

我的后背一瞬间沁出冷汗。

“什么意思？”

“你有没有想过，”陈叔往前走了一步，地砖上的血脚印随之逼近，“你父亲死在谁手里？”

档案夹的温度骤降，像被泼了一盆冰水。我低头，纸页上最后那行字还在——不要让他先开。字迹干涸，却像活着一样在微光下蠕动。

陈叔说那不是父亲留下的。

那是谁？

B 区深处传来一声闷响。像有什么东西撞在三排七格的方向，陈叔之前用弯针钉下去的位置。整个档案架都在震颤，灰尘簌簌落下，落在我的后颈上。

我忽然想起父亲日记里写的那句话：门外之物三次敲门。两声，三声，无数声——只要你不答。

“陈叔，”我突然问，“那根弯针，你从 C 区借的？”

他顿了一下。

“不，”他说，“弯针是我自己的。”

“你刚才说借据上写着‘期限直至归还’。”我把档案夹抱在胸前，不退不让，“那借据是谁写的？你在等什么还？”

陈叔沉默了整整三秒。B 区的灯光像被人拧暗了一个档位，那些档案架之间的阴影忽然拉长、扭曲。“铛——”一声脆响。

弯针掉在地上。陈叔像是被抽走了全部力气，整个人脱力般靠在档案架上，发出一声极轻的、不属于老人的笑声。

“你父亲说得对。”他说，“你比我想象中聪明。”

他抬头，目光穿过我，落在我身后的某个地方。

“那根弯针不是我的。是你父亲留给我的。”他说，“借据上的‘陈’不是我——是你父亲。他借走了我的一件东西。”

“什么东西？”

“我的耳朵。”

他说得很轻，像在说一件无关紧要的事。但我看见他左耳侧有一道极细的疤痕，从耳垂延伸至耳根，整齐得像被刀切开过。

父亲日记里那句话在我脑中炸开——1997年，门外之物三次敲门。借A区规则十二。左耳听力被取走。

“你父亲的条件很简单。”陈叔说，“他帮我保管那根弯针，帮我守住这扇档案架。作为交换，他取走我一只耳朵的听力，来交换门外之物的一件东西。”

“什么东西？”我的声音发紧。

“他。”

夜色灌进来。

档案夹的重量忽然变沉，像有什么东西从纸页之间渗出来，附着在封面上。我低头，看见封面上出现了一道新的墨迹，一笔一划，像是正在被无形的手书写——已坏之日，借汝之光。

光线从头顶的灯管闪烁了一下。整个 B 区的灯同时灭了。

黑暗里，三排七格的方向，传来了一声极轻的、人类走路的脚步声。一步，两步，三步。

它正在走。

陈叔的声音从黑暗里传来，带着从未有过的平静：“别动。别数。别回答。”

我攥紧档案夹，掌心的温度正顺着封面往里面渗。档案夹上的字迹还在生长，新墨在黑暗里泛着微微的光。

那不是父亲的笔迹。

那是门外之物的笔迹。

四周骤然安静下来。脚步声停了。停在三排七格旁边，等着什么。

我忽然明白一件事：父亲取走陈叔的听力，不是为了借某件东西——父亲把自己的一部分，藏在了“无声”里。

而档案夹上那行新字，就是打开无声之门的钥引。

远处，D 区方向传来一声钟响。凌晨三点了。

三排七格的方向，黑暗里有什么东西正在缓缓抽出一份档案。

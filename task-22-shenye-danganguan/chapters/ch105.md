# 第105章 第七个房间

A区的走廊比D区亮一些——至少头顶那排昏黄的壁灯还亮着三盏，不像D区深处的未归档区，全靠不知从哪儿漏进来的月光撑着。林雾摸了摸口袋里的信封，纸面已经有些发皱，但灰白猫留下的字迹仍清晰如初：第七个房间，关灯。

他数着门牌走过去。

A区一共十一个房间，编号却不连续——没有四号，没有九号，七号房夹在六号和八号之间，门板比其他房间旧了一截，漆面剥落得厉害，露出底下深褐色的木纹。门上没有编号牌，只有一枚小小的铜钉，钉帽被磨得发亮。

林雾站在门前，没有急着推门。

他想起馆员手册第十二条铁律：夜间巡视不得进入编号缺失的房间。但这条规则他早破过了——D区深处那扇通往往生归档区的门，也是没有编号的。此刻他还活着，只是一个影子慢半拍。

他推开门。

屋里没有灯，借着走廊的光，他看见一张旧木桌、一口铁皮柜、一张单人床。床上叠着一件灰蓝色制服，领口的铜扣刻着“档案馆”三个字。屋里的空气干燥而陈旧，有股樟脑丸和旧纸页混在一起的味道。

他关上门，屋里的黑暗立刻沉下来。

“开灯也无用，灯是坏的。”一个声音从角落传来，沙哑，断断续续的，像很久没人说过话。

林雾手电筒猛地亮起，光束扫过房间——墙角蹲着一只灰白猫，正慢条斯理地舔着前爪。就是在地下室见过的那只。它抬起脸来，瞳孔在光线下缩成两条细线：“你父亲说，第七个房间的灯，只有关了才会亮。”

林雾盯着它：“你到底是什么？”

“我是什么不重要，重要的是你来这里做什么。”猫起身，跳上桌面，尾巴扫过一本摊开的登记簿，“你父亲当年把一件东西寄存在这里。昨天我刚确认过——它还在这，不过你得自己找到它。”

手电光落在登记簿上。翻开的这一页字迹老旧，墨色发蓝，上面只有一行登记记录：

物品：一张照片
寄存编号：A-000（删除）
寄存人：林文远
存放位置：第七房铁皮柜第三层，夹在登记簿第一册与第二册之间

林雾的名字一颤——林文远，他父亲的全名。他伸手去开铁皮柜，柜门没有锁，拉开第三层，里面整整齐齐地码着两摞登记簿。他把手伸进两摞之间，指尖触到了一个硬纸壳的边角，轻轻抽出来——

是一张六寸的老照片，边角泛黄，背面朝上。他翻过来，手电光照亮画面。

照片里是一家人的合影。年轻的父亲站在台阶上，手搭在一个女人的肩上；女人怀里抱着一个四五岁的男孩，正冲着镜头笑。照片右下角印着一行白色小字，是冲洗店的日期章，十五年前的盛夏。

他认得这个台阶——就是档案馆正门的台阶。

他父亲的旧照片里，阳光亮得刺眼，白天的档案馆正门，在照片里是一家开着门的旧书店，橱窗里摆着打折的旧书，门上方挂着一串风铃。

他盯着那张照片看了很久，忽然意识到了什么问题：照片里女人的脸模糊成一团白色光斑，怎么也对不上焦；穿裙子的轮廓隐约还在，五官却是残缺的、空白的。而他自己——那个被母亲抱在怀里的小男孩——脸是清楚的，笑得露出一颗掉门牙的豁口。

他伸手想再细看，灰白猫的尾巴扫过他的手背：“别看了。那是被规则删除的人，你看多少遍都看不清。”

林雾猛然抬头：“你说什么？我母亲——她也被删除了？”

猫没有回答，它弓起背，耳朵转向门外，像是听见了什么动静。走廊里传来一阵极轻的脚步声，比馆员穿的布鞋还要轻，像某种四脚着地的动物。

“你该走了。”灰白猫说，“房东家的小东西从C区溜出来了，它可不好对付。它怕光。”

话音刚落，走廊里的灯“啪”地一声全灭了。黑暗中，脚步声就近在门外。

林雾捏紧照片，另一只手握着手电筒。他想起那条规则：不得在3:33睁眼。可他从D区出来时看过表，现在应该刚过零点四十分，远没到那个时间。

门外那个东西开始用爪子挠门板，声音刮擦、刺耳、既尖且钝。

灰白猫弓起身子，炸了尾：“如果你不想被它看见，就把灯关了。”

“灯已经关了。”

“我说的是你手电筒。”

林雾犹豫了不到一秒，摁灭了手电筒。黑暗彻底吞没房间。黑暗里的脚步声退后半步，又停下。挠门声停了一会儿，然后它发出一声极轻的呜咽，像是幼猫的哭声，顺着走廊一路远去。

灯重新亮起来。

灰白猫已经不见了，桌面上只留下几根白毛。林雾低下头，手心里的照片还在，父亲的背影清晰，母亲的五官空白，他自己笑得没心没肺——而照片背景里，旧书店的二楼窗口，一个人影正俯视着门口台阶上的一家三口。

那个人的轮廓，和林雾自己一模一样。

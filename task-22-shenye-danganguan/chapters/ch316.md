# 第316章 另一副影子

角落里的人影站起来，动作和林雾平时起身的习惯一模一样——先撑右膝，再直左腿，最后理一下衣摆，明明衣摆根本没有皱褶。

林雾盯着那张和自己一模一样的脸，喉咙发紧。墙上那些褪色的“沈雾”字迹还在不断变淡，暗室里只剩下纸页发霉的气味，和那个人影手里攥着的纸条。

“别怕。”那人影开口，声音也和林雾一模一样，甚至带着他惯常的、压低语气的尾音，“我是你从D区借出来的那副影子。”

D区。馆员区。深夜直播那天，他的影子在走廊里慢了一拍，后来他发现影子被人换了——他一直在找谁换的，为什么换。现在答案凭空落在他面前，以一副会说话的人形站在他眼前。

“谁把你借出来的？”林雾问。

“你自己。”影子说，语调平得没有起伏，“你在D区深处的门前说过一句话——‘影子还我，账我自己认。’你说的是父亲的账。可那扇门听见的是‘影子还我’，就当成指令收走了。”

林雾想起那个夜晚。他确实站在D区深处那扇不该存在的门前说过类似的话，当时他以为自己在对着父亲的声音喊话，根本没考虑过门会怎么理解他的话。

他攥住矮桌上断成两截的钢笔，笔尖上残留的半滴墨水还挂着，悬而不落。“那你现在为什么出来？”

影子低头看了看手里的纸条，把它翻过来——空的那面朝向林雾。纸条是浅灰色的，边缘烧焦了一圈，正中间写着一行字，笔迹是方晴的：“五楼的账不用你还，沈雾的名字不在那。”

林雾看到方晴的字，心口一沉。她在D区给他发过3:33的短信，提醒他去B区；后来短信被截断，他以为她那边出了事。现在这张纸条出现在他影子的手里，而影子站在第五楼存放处的暗室里——时间线完全对不上。

“这是方晴什么时候写的？”

“昨天。”影子说，“昨天白天，她在馆长办公室的抽屉里写的。写完就被零拿走了。”

“零拿走了？那纸条怎么在你手里？”

影子没有回答，而是松开手，那张纸条没有落地，而是缓缓飘起，悬浮在矮桌上空，像被一根看不见的线吊着。然后纸条翻转过来，背面又浮现出一行字——这一次不是方晴的笔迹，是一种笔画极细、像用针尖刻出来的字：

“你的影子不是借的，是你父亲用命换的。五楼没有你妈的名字，有的只是你妈还你的东西。”

林雾的呼吸停了一拍。

影子走到矮桌另一侧，从墙根捡起一本薄薄的册子——封面深灰，没有标题，只在右下角压着一枚浅金色的印章，印纹是“沈雾”两个字。它翻开册子的第一页，林雾看到上面贴着一张照片：一个年轻女人抱着一个三岁左右的男孩坐在老式的藤椅上，背景是一间堆满书的房间。女人没有脸——照片里她的面部被裁掉了，只留下一圈毛边。

“这就是你妈留给你的东西。”影子说，“‘沈雾’这名字不是在五楼，是在这张照片里。谁想拿这个名字，要么填回她欠的账，要么把照片从册子里撕走。”

林雾盯着那张无脸的照片。他认出了背景里那间堆满书的房间——是档案馆一层前台正后方的旧书架区，白天它能看见，夜里被一层黑布蒙着。母亲坐在那个书架前抱着他，而父亲给照片写字的时候，他还没出生。所以这张照片是更早之前拍的。母亲很早以前就抱着他来过档案馆。

他伸手去碰照片边缘。手指刚触到，册子上那枚浅金色印章忽然亮起来，印章纹路从“沈雾”两个字开始变形，一笔一画地重新排列，最终变成三个新字：

“别撕她。”

林雾的手悬在半空。影子在一旁低声说：“你妈欠的账，不是名字，是记忆——她把自己在这座馆里的记忆押在这里，换你父亲那一页档案从A区里翻出来。你如果撕照片，账就转到你身上。”

暗室里的光忽明忽灭。林雾松开手，退后半步。他低头看见矮桌上那支断成两截的钢笔不知何时自动合拢了，笔尖重新摆正，在纸卷上划出一行新的字——不是他的名字，也不是“沈雾”，而是一串他无比熟悉的数字：

A-000。

那行数字写完，笔画开始渗出黑色液体，像被什么东西从纸页内部顶起来。影子脸色微变，说：“它在叫你——A-000的账到期了。”

林雾猛然想起零点时他拿到的期限：凌晨零点之前，A-000的账必须还清。而现在暗室里没有窗，他无法判断时间还剩多少。

他攥住那支断笔，转身就要往门外走。影子拦在他面前，第一次露出不属于林雾的表情——那只影子的嘴角平滑地向两侧裂开，像一个被拉刀的微笑。

“还账之前，”影子说，“你得先想清楚一件事——你爸借走的A-000，到底是一份档案，还是一个人？”

门外传来钥匙转动锁孔的声响，浅金色的，和落在B区地上的那把一模一样。

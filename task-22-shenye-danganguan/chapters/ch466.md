# 第466章 影子来找你

两人出了D区尽头那片走廊后，方晴脚下步子明显加快，直到转过两个拐角、回到馆员区有灯光的地方，她才停下来，扶着墙喘了两口气。

“刚才门缝底下那个黑影，”她把铁盒抱在胸前，像在确认自己还醒着，“你看到了。”

林雾点头。他左手的中指伤口还在隐隐跳动，铁锈色的粉末已经不见了，像是被皮肤吸收了似的。他没告诉她这一点——不想让她更乱。

方晴深呼吸一口，翻开那张纸的背面，又看了一遍那行潦草字迹：“别找影子，让影子来找你。”

“我爸的字迹，我不会认错。”方晴抬眼看他，“但这句话的意思……他是不是预料到有一天，我会找到这扇门？”

林雾没直接回答。他靠着墙，把今晚发生的事在脑子里快速过了一遍：归还窗口的倒悬人脸、唇语“往里走”、借阅号签上的倒立钟面、D区尽头的暗孔、第七扇门里的铁盒、门缝底下那个影子……所有线索都指向同一件事——有人在等一个归还者，而那人误以为他要还的是A-000。

“你爸借了三样东西，”林雾低声说，“时间、名字、影子。时间还了——大概率就是你们家的旧钟停了那件事，你提过你爸失踪前把家里所有钟都拨慢了一个小时。名字丢了——他签的每一份档案用的都不是真名。影子还在馆内——这个不用解释，后院那片影子我一直觉得眼熟。”

方晴沉默了片刻：“那第四次归还——”

“是你。”林雾打断她，“你回去翻一下你爸的日志，倒数第二页是不是写着他‘欠档案馆一个人’。”

方晴脸色一白。她没立刻说话，但林雾看到她捏着手机的手紧了一下。这个动作足够他确认猜对了。

“第四次归还的不是另一个物件，”林雾说，“是他自己。但他把钥匙留给了你——等于把‘是否还’的选择权交给了你。”

“我不会去还。”方晴立刻说。

她话音刚落，走廊尽头传来一声轻响，像是有人在墙面上敲了一下。

两人同时噤声。林雾侧过头，循声望去——走廊尽头拐角处贴墙站着一道黑影，轮廓不高，半透明，像人的影子从地上立了起来。

方晴也看见了。她没有逃，反而朝前迈了一步，电筒光扫过去——黑影的掌心，那道钥匙状凹痕在光线下微微泛亮。

“它来找你了。”林雾说。

方晴怔住。她低头看着那道影子——它站在两米外，没有走近，也没有消失，只是静静地贴墙立着，像在等她。

方晴沉默了一会儿，松开铁盒递到林雾手里，然后向前一步，弯腰，平视那道黑影：“你说。”

影子没有声音，但它抬起手，做了一个动作——五指并拢，指尖朝上，像是握着什么塞进掌心。然后它慢慢蹲下，把“手”贴到地面，影子的指尖刚好触到方晴鞋尖一侧的影子，两个影子在一瞬间融在一起，又分开。

方晴的身子轻轻抖了一下，像是被冷风吹过。

她站起身时，影子的轮廓渐渐淡去，只留下墙角一小片灰印，像是什么东西被抽走了。方晴低头看自己的右手——掌心里多出一枚旧钥匙，铜色，指长，柄上刻着一个“丁”字。

和她父亲刻在铁盒盖上的字一模一样。

“它给我了另一把钥匙，”方晴声音发哑，“和刚才插进第七扇门那把，是同一把。”

“不可能。”林雾皱眉，“那把还锁在里面。”

方晴没说话，把钥匙翻过面，他这才看清——这枚钥匙的齿形是反的，像是一面镜子里的倒影。

“这是钥匙的‘影子’，”方晴说，“它给的不是原物，是原物留在馆内的影子。我爸说的让影子来找我——就是让我拿到这把影子钥匙。”

林雾看着她掌中那枚钥匙，心里涌起一阵不安。他忽然想到归还窗口塞出来的那枚借阅号签——背面洇开的墨迹是倒立钟面，指针指向VII。第七扇门，第七个星期，第七次归还——七，在档案馆所有档案里，是“未完成”的标记。

“你爸还留了别的吗？”林雾问。

方晴摇头，把钥匙小心地收进口袋。她看了眼手机屏幕：“零点四十二了。再过十八分钟，馆内时钟会敲一次——你记得第几条铁律说，‘钟响时不许站着？’”

“第九条。”林雾答得很快。

“那我们先回值班室。”她说着往走廊外走，步子稳了些，“我有东西给你看——六个月前那批馆员日志，缺了中间一页，我一直以为是被撕掉了，但今早清点时我发现，那一页不是被撕的，是被后来的人用同色墨水盖掉了。”

林雾顿住脚步：“盖掉的内容呢？”

方晴已经走到拐角，回头看他，目光在昏暗的灯光下显得格外清亮；“用碘酒熏能显出来。我在值班室试过，显出一行字——”

她顿了顿，声音轻了几分：

“‘第二把钥匙在钟的第七次摆动里。’”

林雾心里一跳——第七，又是第七。他看向D区尽头方向，那扇黑门已经不见了，走廊尽头只余一道灰墙，像什么都没有发生过。

但墙上那片水迹还在，沿着墙角蜿蜒而下，在灯光下缓缓展开，像一行正在被书写出来的字迹。林雾眯眼去看，水迹的形状依稀辨出几个字：

“他还在馆里。”

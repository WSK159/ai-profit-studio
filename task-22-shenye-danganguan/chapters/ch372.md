# 第372章 第八份铁律

蜡印信封在我手里沉得不像一张纸能有的分量。

林道深松开手，退后半步，那截断裂的红绳从袖口滑出来，在我眼前晃了一下，又缩回去。我没看清绳头是不是也系着什么东西，但那一眼让我后颈发凉——断裂面整齐，像是被什么东西一刀切断的。

“第八份铁律。”我重复了一遍纸上的字，“被删除的？”

林道深没点头也没摇头，只是看着我说：“你数过馆里的铁律有几条？”

“十二。”我脱口而出。

方晴在旁边接了一句：“馆员手册上印着十二条。”

林道深笑了。那笑容很淡，却让我想起那张被刮去脸的照片——如果照片上的人是他，那他现在笑起来的样子，和照片里的轮廓应该对得上。

“那你们有没有想过，为什么是十二条？”他问。

我愣住了。

“规则不是凑出来的，”林道深走到办公桌后面，拉开抽屉，从里面取出一截蜡烛点燃，“每一条都对应一种死法。你看到的十二条，是还活着的十二条。”

烛火在他脸上投下明暗分界线，他的眼睛在暗处显得格外亮。

“第十三条死了，所以你们只看到十二条。”

“等等，”方晴皱眉，“你说第八份铁律是‘零点之后馆内不许有人活着’，那这条规则如果存在，你自己站在这儿算什么？”

林道深的目光落到她脸上，沉默了几秒，说：“这就是问题所在。”

他走回我们面前，把燃着的蜡烛放在桌面上一块凹陷处，那形状——我眼尖地发现，和档案馆铜牌上那张张开的嘴一模一样。

“这条规则被删除的时间，是在我改姓之前。”林道深说，“或者说，它被删除的原因，是因为有一个人必须活下来。”

“谁？”我问。

林道深看着我，那眼神让我一瞬间明白了一切。我后退一步，撞上方晴的肩膀。

“你？”

他没有回答我，只是说：“林雾，你推我出来的时间线是正确的，但方向反了。我改姓‘未归档’，不是为了赖账，是为了守住这条被删的规则。”

“什么意思？”方晴追问。

林道深深吸一口气：“档案馆的铁律，每一条都需要一个‘活体锚点’才能生效。十二条活规则，对应十二个活人。第十三条被删了，是因为——”

“因为锚点死了。”我接过话。

林道深点头：“或者说，锚点消失了。”

他举起右手，烛光下我看清他手腕内侧有一道细长的疤痕，形状像一条被撕断的丝线。

“我是第十三条规则的锚点。我改姓，是因为一旦我死了，第十三条就会彻底消失。但我不改姓，债就会找到我头上——A-000的债，从不落空。”

他放下手，声音低了几分：“所以我变成了‘未归档’，让那笔债找不到人。”

办公室里安静下来。烛火噼啪了一声。

方晴忽然开口：“那父亲说‘兄长替我还’——你替他还的不是钱，是命？”

林道深的瞳孔微缩。

“你知道了？”他看着她，语气里多了一丝我还没读懂的复杂。

方晴没有退让：“我父亲留下的东西里，有一句话：‘未归档的人，替 A-000 还的不是债，是时间。’”

她盯着林道深：“你在用自己的存在，替他活着？”

那根蜡烛在这一刻猛然爆了一下，火焰窜起半尺高。林道深的影子在地面上猛地拉长，我清楚地看见，他的影子从墙根处岔开——分出第二道，像有人正站在他旁边的位置，那个位置上的影子却比他的影子先动了一步。

那不是他的影子。

我意识到这一点的时候，后脊梁上的汗一下子沁了出来。

林道深低下头，看着地面上那道不属于他的影子，轻声说：“快了。”

“什么快了？”

他抬起头，目光穿过我，落在我身后的门缝上。

“还债的日子快了。”

门外，过道深处——我听见一声极其轻微的、像是有什么东西在地上拖行的声响。

我以为我已经忘了那个声音，但我的身体记得。

那是门后敲击者的声音。

更近了一步。

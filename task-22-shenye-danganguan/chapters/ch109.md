# 第109章 关灯

林雾的手搭上第七个房间的门把，金属冰凉，像一块久未化开的铁。灰白猫的信封还攥在他另一只手里，边缘被他汗湿的指腹洇出一圈浅痕。父亲的字他没看第二遍——不是不想，是怕再看一眼心就乱了。信上只有五个字：关灯，别开窗。

门没锁。A区第七个房间，林雾白天来巡过几次，里面无非几排铁架，架上是落灰的旧档案。可他推门进去的那一瞬，先闻到的不是纸灰味，而是淡淡的、雨后泥土的气息。屋里一片漆黑——不对，他分明记得门外走廊的灯没有灭。但此刻，他站在门口，眼看门内像被灌了墨一样，连门槛的棱角都看不清。

他深吸一口气，退后半步，门外走廊的光线从他肩后扫进去，照亮门内第一排铁架的边缘。有东西挂在架上——不，那些都是档案盒，整整齐齐。他摸到门侧开关，本能想按亮顶灯，却在指尖碰到塑料面板的瞬间停住。信上说了，关灯。

他松开手，抬脚迈进去。身后的门缓缓合拢，“咔哒”一声，像咬合了一枚锁齿。

黑暗吞没他的视野，只有远处——他判断是房间尽头——隐约有一线微光，暗红色，像没熄尽的烟头。林雾站在原地，把灰白猫的信折好塞进内袋，空出右手，指尖轻轻摸索面前第一排铁架。铁架冰凉干燥，一格一格排着档案盒，盒脊上没有编号，只有颜色深浅不一的旧布纹。他试着往深处走，脚下每一步都极慢，怕撞到什么不该撞的，更怕踩到地板上某种不该有的声音。

三步……七步……那线暗红色光纹丝不动，像钉在黑暗里的一只眼。身后传来极轻的“沙沙”声，仿佛有纸页在翻动。林雾停住脚，侧耳细听——那声音也停了。他继续走，沙沙声又起，不快不慢，恰好跟在他半步之后。他想回头看，脑海里啪地蹦出一条铁律：不许在馆内回头看归还窗口。可这不是归还窗口。

但他也没回头。他想起父亲信上那句“关灯”，忽然明白，这黑，也许不是让人看不见，而是让人不能看破什么。

走了大约二十步，他终于站在那线暗红色微光面前。光来自墙角一块积灰的旧屏幕，大约巴掌大，还通着电。屏幕上没有文字，没有画面，只跳着一串字符：A-000。

林雾心脏重重撞了一下。他伸手去碰屏幕，指尖刚触到表面，那串字符忽然开始向内坍缩，像被抽掉骨架的字符堆塌成一点，然后屏幕整块黑了下去。几乎同时，身后那股“沙沙”声骤然加速，从他脚边擦过，直奔他背后更深的黑暗——然后是一声极轻的“吱呀”，像有扇暗门被人推开又合拢。

林雾猛的转身。黑暗里，他没能看见门，却看见一人影——那人影不算高大，站在三米外，肩膀稍塌，像站了很久很久。那人影没有动，也没有说话，但林雾的目光落在他脚边时，头皮一下子发麻。

那人脚下没有影子。

而他自己的身体，在转过身的瞬间，左手的影子明显比右手慢了一拍，才贴回地板。

“谁？”林雾的声音在黑暗里像一块石头落进深井，砸不出回响。

那人影朝他抬了抬手——动作缓慢，像在水里挥动——然后向后退了一步，融进黑。林雾三步追出去，撞上的是冷冰冰的墙面。墙面平滑无痕，没有门洞。他站在那，听着自己的心跳数到十几下，气息才平下来。

屏幕又亮了。暗红字符换了一行：

“影子还给你。借来的那条，你自己保管。”

林雾低头看自己的左手。暗光下，他手背上浮出一根细长的、半透明的丝线，像从皮肤里抽出的脉，向屏幕方向延伸，又断在空气中。那丝线的颜色是灰白——和灰白猫的毛发一样。

他忽然明白了。这关灯的第七个房间，真正等的不是他，是父亲“寄存”在这里的某样东西。而他作为直系后代，在黑暗的房间里，替父亲“收了货”。

货是他自己的影子。或者说——父亲当年替他保管的那一半。

门外传来敲门声。三下，不轻不重。然后一个熟悉的声音说：“林雾，你出来，我有话跟你说。我知道A-000在哪。”

是方晴。可方晴今晚不该在A区值班。

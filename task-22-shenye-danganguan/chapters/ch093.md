# 第93章 灰衣人

灰衣人站在倒塌的书架之间，身后是碎成粉末的台账残余，浮尘在昏黄的灯光里缓慢旋转。他比林雾想象中年轻，大约三十岁出头，下颌线条利落，一双眼睛却像是熬过太多黑夜，眼白里布满细密的红丝。

他手里的赭红蜡封卡片在林雾眼前晃了晃，封蜡上压着一枚纹章——两把交叉的钥匙，正好与林雾脖子上挂着的铜章图案相反。

“你父亲的东西，认得吗？”灰衣人问。

林雾没动。方晴在他身后轻轻拉了一下他的袖口，意思很明白：别接。

“你叫我来，就为了让我看一张卡片？”林雾把视线从蜡封上移开，“你说签了契约就能让我爸上来，那契约是什么？签在哪？”

灰衣人笑了。那笑容没到眼底，更像是一种职业性的礼貌，像银行柜员对着逾期客户核对账单时的表情。

“你比你爸利索。他当年问了我七个问题才肯坐下听。”灰衣人说，“但你得先看看这个。”他将卡片翻了一面。

蜡封背面嵌着一根头发。漆黑的、硬挺的、约莫二十厘米长的一根头发，被透明的树脂固定在卡片中央，像一枚标本。

林雾的呼吸顿了一拍。他想起了小时候，父亲剃了光头坐在客厅沙发上，对着镜子摸头皮，笑着说“省洗发水”。后来头发长出来，是那种又黑又硬的短发，扎得他掌心发痒。

“这是你父亲的头发。”灰衣人说，“进过A区的人，身上总会留下点痕迹。你父亲进A区住了三年，出来的时候只留下这一根头发。”

“住？”林雾抓住了那个字，“你说‘住’？A区不是存放档案的地方吗？”

灰衣人没有回答。他将卡片收回衣袋里，动作极慢，像是故意留给林雾思考的时间。档案室里的灯光忽然暗了一度，墙角那排柜子深处传来一声极轻的“嗒”，像是什么东西被碰了一下。

方晴猛地回头。柜子深处，一排黑色封皮的档案册中央，有一册正慢慢鼓起来，像有什么东西正从里面向外顶。

“别数。”林雾低声说。

方晴闭上眼，背过身。铁律第六条——不许数B区档案。虽然这里是D区地下一层，但规矩这东西，越是不该出现的地方，越要当心。

灰衣人倒是不慌不忙，看了一眼那册鼓起的档案，说：“又开始长了。你父亲在里面留下的空白页比别人多得多，所以这一片归档比较活跃。”

他转回头，直视林雾：“你不用现在签。今晚只是见个面，让你确定两件事——第一，你父亲确实是自己下到A区去的，没人逼他；第二，他想上来，但需要你替他签字。”

“为什么要我替他签？”

“因为A区不认口信，只认契约。他进去的时候签了一份，出来就必须有另一份接替。”灰衣人顿了顿，“他当初去A区，就是为了替你付一笔账。现在该你了。”

林雾心里一沉。他想起归还台账上的水痕，想起那张侧切图上标红的通道，想起广播里以他名义登记的借阅记录。这一切像是父亲早就算好的棋局，一步接一步，把他推到了这张合约面前。

“我爸欠了谁？”

灰衣人沉默了片刻。他低头看了看自己手里的蜡封卡片，像是斟酌着什么措辞。末了，他说了一句让林雾头发根都竖起来的话：

“他不是欠了谁。他是被借出去的——A-000被借走了，你爸是那份档案附带的‘保管人’。借阅者到现在都没有归还。”

档案室深处，那册鼓起的档案“啪”地一声裂开。一张纸从里面飘出来，旋转着落到林雾脚边。纸面上是半行潦草的蓝黑钢笔字，笔迹他认得——小学时父亲给他作业本签字，用的就是这种略带左倾的连笔字：

“雾儿，别签。”

方晴倒吸一口冷气，林雾却弯下腰，将那张纸捡了起来。纸的背面贴着一张照片。照片上，一间光线昏暗的档案室，镜头里远处站着一个穿深蓝工服的身影，中年，微胖，剃着平头。那个人正回过头来，看着镜头，脸上带着一丝极淡的笑意。

那是他父亲。他活着，至少在拍照的那一刻还活着。

灰衣人看了一眼照片，说：“这是三周前拍的。A区里面没有昼夜，档案上的时间不准，但至少证明一件事——”

他顿了顿，声音低下去：“他现在还活着。可如果你不签，等他那份被借走的档案到期，他这个人就会在档案里被‘归零’。连头发都不会剩。”

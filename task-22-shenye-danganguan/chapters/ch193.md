# 第193章 归还窗口

凌晨一点十七分，归还窗口的铃声响了。

我正蹲在A区地板上收拾那截断笔的碎片，铃声响起的瞬间，所有残片突然剧烈震颤，像被某种看不见的频率共振，齐齐向窗口方向滑动了半寸。

那支笔已经断成两截，乌黑的墨渍渗进A区的地砖缝里，怎么擦都擦不掉。此刻随着铃声，裂缝中的墨迹开始缓缓蠕行，在灰白地砖上拼出歪歪扭扭的四个字——

“它来了。”

我没来得及细看，铃声又响了一次，比刚才更急。

归还窗口在A区最深处的隔间里，平时只有馆长能启用。我攥紧口袋里的照片，站起来往隔间走去。越靠近，金属摩擦的声响就越清晰——像是有什么东西在窗口背面刮擦。

毛玻璃后隐隐透出一个轮廓。人形。矮小，佝偻，像缩着脖子的老人。我停在隔间门口，按铁律第十一条，不看窗口看地面。地面上一行墨字正在生长：“先还旧账，再借新规。”

归还者规则。

我深吸一口气：“我没借过东西。”

窗口咔嗒一声开了条缝，一只枯瘦的手从缝里伸出来，指尖夹着一张泛黄纸条。手背上爬满青紫色的纹路，纹路末端隐约像某种契文——三个字，我眯眼辨认，却发现那些字会动，在我看清的瞬间组成了方晴的名字，又旋即散开。

“这是……白班管理员的字据？”我脱口而出。

枯手没有收回去，指节敲了敲窗口边缘，一张一合。要我把纸条接过去。我犹豫了两秒，伸手接过——指尖触到纸条的瞬间，冰凉的触感往上蹿，像握住了一根铁杆。纸条上的字慢慢显影：方晴，编号C-177，借阅“遗忘规则”，已逾期三天。

方晴借过规则？而且逾期了？

我猛地抬头，忘了看地面的规矩，视线越过毛玻璃——窗口后面的人已经转过身去，背影正在急速坍缩成纸片般的二维平面，最终嵌进墙里。最后一线缝隙里挤出一个低哑的声音：“你替她还。”

紧接着，我知道那声音是谁了。我见过这个背影——在D区深处那扇白光的铁门前，父亲的影子背对我的样子。一模一样。

我转身就跑。跑过A区书架时，口袋里的照片滚烫。跑过B区铁门时，铁门内传来极轻的指节叩击声，三下。跑过C区入口时，那支断笔剩下的半截突然自己飘了起来，悬在空中。笔尖朝下，开始写字。写的是方晴的名字，末尾拖出一道删除线。

我朝D区方向跑，手里攥着那张字据。深夜档案馆的走廊长得没有尽头，灯光一盏接一盏熄灭，只剩下脚底影子跟着我。而我的影子，它跑得比我还快几步。

我停，它不停。

我追，它逃。

等我在D区走廊尽头刹住脚步，影子已经贴在铁门上，整个人形的轮廓都烙在了银白的门面上。然后它回头冲我笑了一下，嘴唇一张一合，无声地说了两个字。我没法从唇形判断那是什么——但我知道它前面的动作。

它在敲门。

三下。

铁门在这时发出嗡鸣，门缝里探出半只手，五指张开，仿佛在等我递上那张方晴的借阅字据。而我捏着纸条低头——纸条背面不知何时多了一行字，墨水未干，字迹是我熟悉的，我妈的笔迹：

“别替任何人还，你在找的不是债，是账本。”

【STATE】第193章：归还窗口出现枯手归还者，递出方晴逾期未还“遗忘规则”的字据，要求林雾替她还债。窗口内归还者背影与D区铁门前的父亲影子一致。林雾跑向D区，途中他的影子抢先逃至铁门前敲门三下，铁门内探出一只等待字据的手。纸条背面突然出现林母笔迹，警告“别替任何人还，你在找的不是债，是账本”。未回收伏笔：方晴为何借遗忘规则、父亲影子的真实意图、铁门内探手者身份、林母笔迹来源。

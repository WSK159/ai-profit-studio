# 第360章 等门的记号

门缝透出的蓝白光比先前亮了一分，林雾的手指悬在那张翘角的麻纸上方。

——皮革上“林守义，欠……”三字，笔锋有力，收笔处微微上挑，和林雾记忆里父亲教他写字的姿态一样。爸从不写正楷，说“字要斜着走，路才走得直”。

他没能撕下去。

门内传来第二下敲击。不重，像指节叩在空心木板上，一下，顿住，又一下。节奏让林雾想起很小的时候，父亲晚上加班回来，敲他家房门的方式——两短一长，怕吵醒母亲，又怕林雾已经睡着。

他喉头发紧。

“爸？”

声音落下，走廊里所有麻纸同时发出窸窣的响动，像无数只手在纸背抚过。铁皮灯从熄灭状态重新亮起——但光色不对，泛着青白，仿佛有一层薄霜覆在灯罩上。

林雾回头，看见麻纸墙上的字变了。

先前那些“童谣”“初恋”“咳嗽声”的扣款记录还在，但每一行的末尾，都多出一个极小的记号——一个斜杠，像数字“7”的一撇被拦腰截断。他凑近去看，记号新得发亮，墨迹未干。

不是他写的。

走廊尽头传来脚步声，沉重、迟缓，每一步都拖得很久，像踩在没过脚踝的水里。林雾的手从皮革上移开，扣子还嵌在门把手的凹槽里，门没有合拢，蓝白光越来越亮。

“小雾。”

那声音苍老，沙哑，像陈叔——但陈叔管他叫“小林同志”，从没喊过“小雾”。月光下，一个佝偻的身体从楼梯口缓步挪过来，身上套着警卫室那件洗得发白的大衣，衣领竖起来遮住半张脸。

林雾没动。他想起来一条规则，后来才补进手册附录的旧条目：“夜班时，若有人叫你名字，先看影子。”

走廊灯在头顶，陈叔的影子投在麻纸墙上，方向是对的。但影子的手——正缓缓抬起来，做出一个撕纸的姿势。而陈叔本人双手插在口袋里。

“你不是陈叔。”林雾听见自己的声音比预想中平静。

那个身影停住了。大衣领子微微抖了一下——不，是在笑，衣领下面的嘴型弯成一条弧线。“他”抬起头，露出一张脸，五官齐全，眉毛浓，眼睛小，是陈叔的脸。但那只眼睛里的光，是从门缝蓝白光里来的。

“你认出我了。”它说，声音不再像陈叔，带着一种潮湿的、木头被水泡过的质感，“那我就不装啦。我是等门的。”

“等门的？”

“等你父亲那笔账。”它偏了偏头，脖子发出喀的一声，“他欠了三十年。你不是来还的吗？”

林雾的心往下沉了沉。母亲说过，父亲失踪前三天，突然把家里所有存款取出来，说“要还一笔老账”。母亲以为他赌了钱，吵了一架。父亲没解释，只留下一句话：“还清了，我就回来。”他再没回来。

“我爸爸欠了你们什么？”

“你自己看。”它指了指门下方那张翘角的麻纸，“林守义，欠——”

字迹在麻纸上没有写完，尾端被水渍洇开。林雾迟疑片刻，弯腰去掀麻纸。麻纸很薄，轻得像蝉翼，他刚触到纸边，指尖传来一道凉意，顺着指腹的“还”字钻进去。他低头，看见自己右手上的“还”字在发光，蓝白色，和门缝透出的光一模一样。

“别用你的笔画了。他会认出来。”——纸上那句话忽然在脑海里炸开。先前他以为“他”指的是门后的敲击者，现在他明白了。

“他”指的是父亲。

那是父亲本人的笔迹。父亲欠下的东西，必须由父亲亲手还——用父亲的笔画，父亲的字迹，否则门后的人会认出那不是他。而林雾的右手上，被母亲转贷来的那枚“还”字印记，是他的笔迹，是林的笔迹，是“林雾”的印记。

不是林守义的。

“认出来了？”等门的歪着头，喉咙里传来水声，“三十年了，这扇门没等到过他。你倒像他，可你也不是他。”

林雾缓缓直起身。“那这扇门，等的是我父亲本人？”

“等的是他的笔。”等门的忽然舔了一下嘴角，眼底蓝光一闪，“你带着他的东西——你知不知道，你身上有一样东西，是他用那支笔写下的？”

林雾僵住。

他右手缓缓摸向衣领下——那枚深蓝扣子。昨晚，铁皮灯笼上的人脸让他摘下扣子，他照做了，扣子恰好嵌入五楼门把手的凹槽。他一直以为那是巧合，现在才意识到：那一夜，他换下这件衣服之前，父亲失踪前留下的所有衣物里，只有这件旧夹克的领子上有那枚扣子。不，更早，他记得小学三年级，父亲带他去裁缝铺做新衣，特意让人在左领缝了一枚深蓝扣子——当时父亲说：“扣子是你爷爷留下的。”

爷爷留下的。林守义欠下的。三十年后，林雾戴着那枚扣子，走进这扇门。

“找着了？”等门的向前迈了一步，“扣子是他的记，笔迹是他的账。你两个都有了——可你写不出他的字。”

林雾低头看向右手。那个“还”字，确实是他自己的写法。但就在他目光落下的瞬间，扣子嵌入门把手的位置，传来一声极轻的“嗒”。门缝里的蓝白光，忽然暗了半度。门内传来第三下敲击——不是指节，是掌心，一下，重重地拍在门板上。

然后，安静了。

走廊里所有麻纸同时平静下来，字迹上的水渍缓缓干涸，像时间突然静止。等门的脸色变了，它猛地转头看向那扇门，五官扭曲了半瞬。

“他醒了。”它说，声音第一次带上恐惧，“你把他吵醒了。”

林雾还没反应过来，右手上的“还”字忽然发烫，蓝白光从字迹里漫涌而出。麻纸翘角的边缘，那个“欠”字的最后一笔，忽然动了一下——像有人握着无形的笔，在“欠”字下方，轻轻补了一划。

是“还”。

父亲的字迹，三十年前那笔未写完的账，补上了。门内传来一声极轻的笑。很轻，很熟悉，像小时候父亲哄他睡觉时，压着嗓子哼的那半句歌谣。林雾的手悬在空中，眼眶忽然发酸。

走廊尽头，等门的水声退了。它踉跄着往楼梯口退去，衣领重新竖起，声音混进黑暗里：“他没还完。欠了三十年的账，一笔不够。下回，你带他自己的字来。”

灯灭了。

# 第51章 倒数的秒针

凌晨 3:56:40。林雾站在 C 区门口，手里那张 C-019 的归条被他攥出了汗。铅印的字在走廊灯下泛着冷光：本规则已失效，失效原因：改写者的名字。

他的影子还在地上——但比他慢了半拍。他抬手，影子慢了，他放下，影子还在半空悬着。像一个人在水里挣扎。

"还有四分钟。"他低声对自己说，把归条塞进外套内袋，朝 D 区方向跑起来。

档案架的灯一盏盏亮，又在他身后一盏盏熄灭。脚步声撞在纸页上，发出沙沙的回应。林雾数着自己的呼吸，两步一换气，穿过 C 区与 D 区之间的那道铁门。

门后是馆员的生活区。

他从来没在夜里认真看过这里。走廊两侧是编号不规则的房门——D-01 到 D-12，对应十二个馆员位置，但绝大多数门锁都是锈的。只有 D-07 门口挂着一双旧皮鞋，鞋尖朝里，那是同事老周的房间。老周上个月"休假"了，方晴说他在老家养病，但林雾记得老周走那晚，影子也慢了半拍。

他不敢停。走廊尽头，归还窗口的绿灯亮着，像一只困倦的眼睛。窗口上方挂着一块表：3:58:17。

还有一分四十三秒。

林雾从内袋抽出归条，快步走向窗口。就在他伸手要递进去的瞬间，他看见了。

窗口内侧的台面上，放着一只牛皮纸信封。信封上印着"催缴通知书"五个字，下面一行小字：逾期未还，将从担保人记忆中每日扣款。林雾的手指停在半空。他的目光落在信封右下角。

寄件人那一栏，写着两个名字。第一个是林远山。第二个是林雾。

他的喉咙发干。他没有打开信封——不敢，也没时间。归条递进窗口的那一刻，绿灯猛地闪烁三下，发出"嗒"的一声，像某种登记达成。然后，灯灭了。走廊陷入黑暗。

黑暗中，有人笑了一声。

不是谢意，不是嘲笑，是那种正在确认某件事得逞的笑。从墙的背面传来。林雾站在黑暗里，心跳擂鼓。他伸手摸到墙壁，手掌触到一层冰凉的灰尘。

"……谁？"他问。

笑声停了。

走廊尽头，D 区深处那扇不该存在的门——方晴提到过，他自己也从没靠近过——吱呀一声，开了一条缝。缝里漏出一线暖黄色的光，像傍晚的余晖。林雾望着那道光，忽然想起父亲书桌上那盏老式台灯，灯罩裂了一条缝，亮起来的时候，光线总是偏的，向左边歪。就像这样。

"明天别开那扇门。"六字规则又在他耳边响起来。这次不是幻听，是他自己念出来的，声音在空走廊里弹了回来。那扇门缝微微动了动，像有人在里面推了一下。然后，又合上了。

林雾深吸一口气，抬手看表——3:59:52。归条已经递还，按规矩，账平了。但他的影子，依旧比他的动作慢一拍。

他刚要走，催缴信封里发出一声轻响。他低头看去。信封的封口自己弹开了。一张对折的白纸探出一角，纸面上有字迹露出——黑色的钢笔字，笔锋很锐，像是被风翻开的。他没碰。他看见纸角上的字：

"规则是写的。写规则的人，会在你身边。"

走廊另一头传来脚步声。皮鞋，独步，不急不缓。林雾抬起头。灯光一层层亮起来。

"——还没下班吧？"一个声音问。

那声音低沉，熟悉，又陌生。像是老周的声音。但老周，上个月已经休假了。

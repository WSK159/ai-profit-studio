# 第63章 旧账

典当行那男人看苏荷脸色不对，反而来了劲：“妹子，你不知道？这铺子早先是苏老大典出来的，三百块钱，三十年期满。”他拿烟头指了指脚下，“算下来，还有五年呢。”

苏桃急道：“胡说！我们家的铺子，怎么你说是你的就是你的？”

“白纸黑字，红戳为证。”那男人拍拍怀里鼓囊囊的袋子，“你爹签的字，画了押。这事搁哪儿说都是天理。”

苏荷闭了闭眼，把翻涌的情绪压下去。她记得——重生头一天，她在那间破屋里翻到过一只樟木匣子，里头装着些旧票据，她当时急着收拾铁锅走人，只看了一眼——隐约瞧见一张典契，上面确实写着她爹的名字。

她当时以为是别家的。

原来那间铺子，从一开始就是苏家的产业。她爹在哪儿弄来的这间铺子？又为什么在五年前典出去？这账，怕是还得往深处算。

“你叫什么？”苏荷睁开眼，语气平静得像在称秤。

“陈老八，永昌典当行的二掌柜。”男人咧嘴一笑，“怎么，你这丫头想赎回去？三百块本钱，五年利息，算下来小六百。你拿得出来？”

苏荷没接话，目光越过他，看向他身后巷口停着的一辆黑色自行车。那是利丰船务的车，车把上挂着小铜牌，她傍晚在码头上见过。

“陈掌柜，”她说，“你这趟来，是替张德发张老板跑腿的？”

陈老八脸上的笑容僵了一瞬。他咳了一声：“胡说什么？我的铺子我爱来就来。”

“你爱来就来，可你爱跑码头么？”苏荷不紧不慢，“我傍晚见过你在码头上，跟刘永旺递烟。”

陈老八脸色彻底变了。他身后的同伴捅了他一下，他哼了一声，把袋子往怀里一夹：“下回再来收铺！丫头，识相的赶紧搬，别等我们抬东西。”

两人转身要走，苏荷在后头添了一句：“陈掌柜，回去跟你后面那位带句话，就说——锅还在，火没熄，等着看谁先掀盖。”

陈老八的脚步顿了一下，没回头，顶着夜色走了。

苏桃恨恨地跺了跺脚：“姐，咱跟他们拼了！”

“拼什么？”苏荷弯腰把她脚边的碎玻璃捡起来，“先回屋。”

进了店门，苏荷把碎瓷片放进垃圾桶，洗了手，拿起灶台上的铁锅掂了掂，又放下。她坐在灶台前的小凳上，手背抵着下巴，把整条线理了一遍：张德发——利丰船务——永昌典当行——城南巷口七号的旧铺契。她爹五年前把这间铺子典出去，张德发手里攥着那个典字，如今又让典当行上门来“收铺”。这是要拔她根，逼她挪窝。

可是，张德发怎么知道这铺子对她来说是多大的根？

她抬头看向苏桃：“阿桃，你上回说，上个月见过咱爹来城南？”

苏桃点头：“就远远瞧见一回，他跟一个戴白帽的老头站在桥头说话，我没敢上前。”

白帽老头。苏荷目光微微一凝。她前世见过戴白帽的——那是广东茶楼老师傅的行头，退休了也歇不住，最爱在桥头茶摊泡一壶铁观音。这地方怎么会有这种人物？跟张德发扯上关系的白帽老头，又是什么路数？

她正要细想，门外忽然传来三声敲门声。不轻不重，两长一短。苏荷的脸一下子绷紧了——这是她前世跟师父学厨时的暗号，她重生到这个世界后，从没教过任何人。

她起身拉开门，门外站着个穿灰布中山装的老头，头发已经全白，背着手，笑眯眯地看着她：“丫头，你家的底汤，熬到几个时辰了？”

苏荷后退了半步。是那个在古玩街茶棚里教她熬汤的老头——他消失了一个多月，怎么这时候又冒出来了？

老头自顾自跨进门来，低头绕着灶台上的铁锅转了半圈，又凑到锅沿闻了闻，然后直起身来：“汤熬得不错，是个有悟性的。”他说这话时眼睛往苏桃那边瞟了一下，嘴角露出一点意味深长的笑意，“就是家里这口铁锅，用得糙了。”

苏荷盯着他：“老先生，您怎么知道我住这儿？”

老头没回答，转过身来，忽然说了一句让苏荷浑身一震的话：“你师父，托我来看看你。”

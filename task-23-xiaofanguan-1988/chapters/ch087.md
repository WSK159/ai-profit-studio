# 第87章 老宅夜话

中山装老头住在城南巷尾一栋老宅院里，门楣上挂着块褪色的木匾，隐约能辨出“洪宅”两个字。苏荷第一次路过时就注意到了——匾太旧了，但门前的石阶被踩得光亮，有人常来。

她没直接登门。下午她先回苏记小馆收拾了一圈，把明天的菜备好——肉末剁成细蓉，和进姜葱汁里摔打上劲；面粉兑碱水揉好，盖上湿布醒着。苏桃在旁边帮忙挑豆芽，一根根掐头去尾，小丫头做得极认真。王婶在灶台前烧热水，一面问苏荷晚上想吃什么。

“不吃了。”苏荷擦净手，“我去趟城南巷，晚点回来。”

王婶没多问，只是看了她一眼，点点头。苏荷出了门，往巷尾走去。

天将擦黑，老宅的院门虚掩着。她抬手敲了两下，没人应，又敲了两下，门里传来一声低哑的咳嗽：“进来。”

她推门进去。院子里种着一棵老石榴树，叶子落了大半，树下放着一张竹躺椅，中山装老头裹着一件灰棉袄半躺半坐，膝盖上搭着条旧毛毯。他看见苏荷，眼皮抬了抬：“小苏师傅？稀客。”

“洪爷爷。”苏荷没有绕弯子，“我来还您一个情。”

她从帆布包里掏出那只月牙青瓷瓶，轻轻放在桌上。老头目光一凝，慢慢坐直了身体，伸手接过瓶子，手指抚过瓶身上的月牙纹路，好半天没说话。

“洪三留下的话是左三圈右两圈，瓶子能把东山下那间砖房打开。里面堆了十几袋粗盐，外加一本账册。”苏荷把话一口气说清楚，留了余地。她没说账册上写了哪些名字，等老头自己接。

老头沉默了一阵，把瓷瓶翻过来，瓶底有个极小的“洪”字刻痕。他咧嘴笑了一下，脸上皱纹层层叠叠，像老树皮：“你这姑娘，胆子不小。那间屋子洪三走后，我都没敢去动——你倒先开了。”

“我不开，别人也会开。”苏荷说，“刘三已经在往外报信了，西码头那批盐被工商扣了，他肯定要挪货。我猜，东山下这批就是他的备手，我提前把盖子掀了，他后面的棋就乱了。”

老头盯着瓶底的“洪”字看了一阵，忽然问：“账册你看了？”

苏荷点头。

“里面有王主任？”

苏荷没有否认。老头干笑两声：“洪三当年就是被王主任逼走的。他攥着账册不肯交，王主任就让他三个月内滚出青江。洪三走之前来找我，把这瓶子塞给我，说‘叔，往后谁拿着这瓶子来找你，你就帮一把’。我等了半年，等来你。”

苏荷心里微微一震：“您知道洪三去哪儿了？”

“不知道。”老头摇头，“但我知道他为什么攥着那本账册不撒手。他家世代晒盐，他阿爸就是被人合伙昧了盐田才死的。他这辈子最恨的就是官商勾结把老百姓的饭碗端走。”

夜色漫上来，老头起身从屋里端出一盏煤油灯，又摸出一壶温的米酒，倒了满满两杯推给苏荷一杯。他重新坐下来，喝了口酒，说：“你要查，我陪你查。但有一条，你要答应我——账册上的名字，不能拿去当交易筹码。这些人烂是烂，可以交给上面查办，但你不能学他们。”

苏荷端起那杯米酒，一口没剩，仰头喝了干净。她放下杯盏，目光平直：“洪爷爷，我开小饭馆，靠的是灶台上的手艺。那些歪门邪道，学了脏手。”

老头看着她，忽然笑起来，眼角的皱纹像老核桃壳。他从里屋翻出一个牛皮纸信封，封口用红蜡封着：“这是洪三走前留给我的信，里面写了他接手这条盐道的原委。你拿上，等需要的时候，一起交出去。”

苏荷接过信封，没有拆。她低声道谢，告辞出门。走到院门口的时候，听见老头在身后说：“小苏师傅——你那个红油抄手，做得比国营饭店的好吃。”

她没回头，弯了弯嘴角。

回到苏记小馆已是夜里九点多。顾长山坐在灶台边，面前的桌上放着那本账册，已经用报纸包好了。他看见她回来，递过来一张条子：“刘三下午派人去南关街街道办事处打听消息，问的是一男一女去过没有。你明天出门小心点。”

苏荷把信封和账册放在一起，压到米缸后面。她拿开锅盖，火还亮着，锅里炖着一锅骨头汤，咕嘟咕嘟冒着热气。王婶留的饭——一碗白饭，一碟酱黄瓜，还有两块红烧肉。她坐下来拿起筷子，忽然想起什么，问顾长山：“你今晚住哪儿？”

“街道办有宿舍。”

“太远了。”她指了指灶台后的隔间，“那儿有张折叠床，以前工人午休用的，你拿一床被褥就行。明天一早，我熬锅小米粥。”

顾长山顿了一下，耳根微微发红，点点头没说话。

苏荷埋头吃饭，余光落在米缸后那个装着账册和信封的位置。她心里很清楚，王主任一旦发现账册丢了，明天整个南关街都会翻过来。她只有一夜的准备时间。

窗外，城南巷的路灯“啪”地亮了，黄黄的光晕落在灶台上，照见那锅滚着的骨头汤。

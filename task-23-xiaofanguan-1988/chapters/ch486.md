# 第486章 五瓣梅花

五瓣梅花。

苏荷盯着纸上那朵墨迹未干的梅花，脑子里轰的一声。她前世师父的黑漆木盒里，锁着一枚旧铜章，章面刻的正是五瓣梅花——师父说是“一个故人”留给他的，她追问过很多次，师父只摇头不说话。

而现在，这朵梅花出现在柳春来留下的油纸上。

她把油纸折好贴身收起来，铁环重新合拢，攥在手里，快步出了竹林。月色渐渐西沉，青江渡口方向远远传来几声狗吠。苏荷绕到渡口下游一里外的旧码头，蹲在石阶上把手和脸洗净，拧干衣裳，才往城南巷走去。

到苏记小馆门口时，天刚蒙蒙亮。门虚掩着，灶间透出昏黄的灯光。

苏荷推门进去，苏桃趴在桌上睡着了，面前摊着一本记满数字的账本——苏荷不认识“账房”两个字，但认得苏桃的笔迹：一撇一捺都写得分外用力。苏荷轻轻拨开妹妹肩上的薄毯，正要往灶间走，忽然闻到一股熟悉的、微酸的甜味。

甜酱油。

她眼神一凝，推开灶间的门。灶台上搁着一只青瓷碗，碗底沉着半碗酱油色汤汁，汤面浮着几片陈皮。旁边压着一张纸条，墨迹尚新：“五更来，水缸底。”

字迹不是顾长山的。

苏荷掀开水缸盖，缸底垫着一层青布，布上搁着一样东西——半枚铁环，和她在竹林里捡到的那半只严丝合缝地咬上，正好拼成一整只。

铁环内侧，另一行字冒了出来：“井底有缸，缸底有人。”

苏荷指尖一颤。她把两半铁环重新拆开，借灶火的光细看，那行字是刻好后涂了黑漆的，被水泡过，漆皮翘起一部分，露出底下更早的一道刻痕——一个“北”字。

“北门。”她低声念出来。

顾长山说的北门。铁匣纸条上的“北门开，瓮底空”。还有黄铜钥匙上那个“北”字。

门外忽然传来脚步声。苏荷迅速将铁环收入衣兜，盖上水缸盖。门帘被掀开，顾长山站在门口，头发上挂着露水，手里拎着一只还冒着热气的纸包。

“你回来了。”他看着她，目光沉着，没有多问。

苏荷点点头，把那截桐油绳头递过去：“老船夫帮我引开冯半缸，不知道现在怎么样。”

顾长山接过绳头，捻了捻，眉头微皱：“镇西老海家的采砂船绳。冯半缸当年在老海家干过三年采砂工。”他说完顿了一顿，抬起眼看她，“你师父呢？”

苏荷摇头：“我在竹林里捡到这只铁环。”她把两半铁环并排放在案板上，“一半在苏茂丰的窑洞里，一半在今天早上出现在我们水缸底。”

顾长山盯着铁环，沉默了一会儿：“水缸底，有人进来过。”

“纸条上写‘五更来’。”苏荷看了一眼窗外，天边刚泛白，“送东西的人，五更时候来过。”

她低头，重新看向铁环内侧那行字：“井底有缸，缸底有人。”

顾长山脸色变了一瞬。他抬头看向苏荷：“你记不记得，钟家旧宅那口枯井——我们下去过两次，都没到底。”

苏荷的心猛地沉下去。

她攥紧铁环，指节发白：“再下一次。”

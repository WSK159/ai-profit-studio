# 第408章 缸中之王

夜色如墨，柳家西院的井口旁，三个人影立在昏黄的煤油灯下。

苏荷顺着柳三更的目光望向院墙外，那道眼熟的身影已经消失在墙头之下。她的心跳漏了一拍——那是谁？她在脑海里飞速搜索，却抓不住那个模糊的印象。

“它跟到这儿来了。”柳三更的声音沙哑得像砂纸磨过铁皮，“三十年，它一直在找这口缸。”

顾长山已经握紧了腰间那把短刀，下颌绷成一条直线：“什么东西？”

柳三更没有直接回答，而是颤巍巍地从怀里摸出一把锈迹斑斑的钥匙，递给苏荷：“你师父让我交给你的。他说，等你看见缸中之王，就明白那句话了。”

苏荷接过钥匙，指尖触到锈蚀的纹路时，一股异样的感觉涌上心头——这把钥匙的形状，和她在石室中看到的那幅壁画上的图案一模一样。

“哪口缸？”她问。

柳三更指向西院角落。那里有一口大缸，缸身被厚厚的灰泥封住，盖着一块青石板，石板上散落着几片枯叶，看起来已经数十年无人动过。但苏荷注意到，缸底的泥地上有一道新鲜的拖痕，像是最近被人移动过。

钟大川。

这个名字闪过苏荷的脑海。那家伙一直在挖缸，挖的就是这一口？

“你师父说，这口缸是柳家漕帮时代最值钱的物件。当年柳家替漕帮管暗船队，账本藏在四十八口缸底，但这口‘缸中之王’里藏的，不是账本。”柳三更咳嗽了两声，压低声音，“是名单。”

“什么名单？”顾长山问。

“当年漕帮解散时，柳家替帮主保管的那批人的名单。三十年前那场大清洗，多少人死在它手里。”柳三更的目光浑浊而深远，“你师父躲了半辈子，就是为了护住这个秘密。他说，等该来的人来了，就把钥匙交出去。”

苏荷的瞳孔微微一缩。

她走到那口大缸前，蹲下身，用袖口擦去青石板上的灰尘。石板上刻着几行小字，因为年深日久，大部分已经模糊不清，只有最下角的一个“童”字清晰可辨。她伸出手指轻轻描过那个字，指尖传来微妙的热度，仿佛那些字在回应她的触碰。

“师父到底做了什么，让这么多人追了他三十年？”苏荷低声问。

柳三更没有回答。他只是望着那口缸，眼里有一种说不出的复杂情绪。

顾长山走到苏荷身侧，抬手按住缸沿，试探着用力一推。缸身纹丝不动，像是生了根。

“钥匙孔在缸底。”柳三更说，“要先把缸翻过来。”

苏荷和顾长山对视一眼。两个人合力抓住缸沿，低喝一声，用尽全身力气——缸底的泥地松动了一瞬，然而就在这一瞬，院墙外突然传来一声沉闷的咳嗽，紧接着是急促的脚步声，由远及近。

顾长山瞬间松手，转身挡在苏荷身前，手已经按上了刀柄。

院门被人从外面推开了半扇。一个穿着灰布衣裳的中年男人站在门口，手里提着一盏马灯，灯光映出他脸上那道从眉骨延伸到下颌的旧疤。

苏荷认出了他——巷口修鞋摊的骆裁缝。

骆裁缝看了看苏荷，又看了看她身后的柳三更，最后目光落在那口缸上。他放下马灯，摊开双手：“别紧张。我来，是给你送一样东西。”

他从贴身的衣袋里掏出一个油布包裹，递向苏荷：“你师父让我在你见到缸之前给你。他说，钥匙是开缸的，这个是保命的。”

苏荷接过油布包裹，一层层打开，里面躺着一块巴掌大的木牌，木牌上刻着一个“令”字，边缘已经磨得圆润发亮。

“漕帮的退帮令。”骆裁缝说，“持此牌者，帮中旧人见之如见帮主，恩怨两清。你师父当年没舍得用，他说你用得着。”

苏荷握着木牌，指腹摩挲过“令”字的纹路，忽然生出一个念头：“柳三更说的‘它’，是谁？”

骆裁缝沉默了一会儿，目光越过苏荷的肩头，望着那口缸：“三十年前，漕帮那批名单里，有个人没有死。他一直在找这口缸，不是要名单，是要缸底下压着的那件东西。”

“什么东西？”

骆裁缝的嘴唇动了动，话到嘴边，院墙外又传来一声响动。这一次，是一声极轻的、金属磕碰石头的脆响。

骆裁缝脸色骤变：“他来了。”

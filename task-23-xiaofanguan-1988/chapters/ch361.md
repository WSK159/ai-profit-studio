# 第361章 郑继明带来的半截话

正月初五，青江县城东的茶馆里人声嘈杂。苏荷坐在靠窗的位子，面前摆着一碗热气腾腾的姜茶。顾长山坐在她对面，手里转着一只茶杯，不说话，目光偶尔扫向门口。

他们约了郑继明巳时见面，眼下巳时已过了一刻，人还没到。

“再等等。”苏荷低头呷了口姜茶，辣意从喉咙烧到胃里。她不急，反而庆幸这一趟香山之行没白跑。渡船簿上那“苏记”二字，像一根线，把之前散落的许多珠子慢慢串到了一处。

巳时三刻，茶馆门帘被掀开，一个四十来岁、穿驼色呢子大衣的中年男人走进来，四下张望一眼，看见苏荷，快步走过来。

“苏老板？久等了。”郑继明坐下，摘下手套，手指干净，指甲缝里却有一点洗不净的灰褐色——卤汁的颜色。他抬头看顾长山一眼，点点头，“顾同志。”

苏荷也不绕弯子：“郑老板，年前我收到你托人带的信。信纸背面沾着卤缸灰，我猜你是有意为之。”

郑继明眼皮一跳，随即笑了：“苏老板眼毒。没错，那信是干净的，灰是我故意蹭上去的。卤缸灰这东西，在咱们这行，有不言而喻的意思——有人动过手，有人接得住，算是一道暗号。”

“你在提醒我，有人动过董家老宅的卤缸？”

“不是提醒。”郑继明敛了笑，“是告诉苏老板，董家老宅那口旧卤缸，早在你盘下之前，就有人挖开看过。只是缸底是空的，没捞出东西来。那个人见没什么油水，又给填回去了。”

苏荷握着姜茶碗的手微微一顿。

空缸，被人捷足先登探过底。那灶台底下的三斤灰呢？是那人留下来掩盖痕迹的，还是原本就有的？她没露声色，只问：“你认识那人？”

郑继明摇头：“不认识。但我知道他姓什么。我跟人打听过，挖缸那人姓钟，是个跑江湖的厨子，早年在省城几个馆子当过掌勺，后来不知怎么销声匿迹了。听说他手里有一条旧方子，是国宴上失传的。”

钟——钟大川。

苏荷脑子里像被什么东西撞了一下。钟大川是她在城南巷时送来药粉方子的那个游方厨子。当初她只当他是好心送方子，如今看来，他的身份远没有那么简单。

“郑老板，”苏荷放下姜茶碗，直视他，“你专程从省城过来，该不只为了跟我说这个吧？”

郑继明沉默片刻，从大衣内袋里掏出一张泛黄的折纸，推过桌面：“年前有人把这东西塞到我门缝里，说是转交给你。我拆开看了，看不明白，但觉得该给你送来。”

苏荷展开折纸，上面只写了六个字：

“沈伯言，未死。”

那字迹瘦硬有力，和方脸男人“老郑”留下“那本东西”时纸上压的字，几乎如出一辙。

苏荷指尖按住那行字，心跳如擂鼓。沈伯言——那位顾常山书房画里题名的“沈先生”，那位被旧照片少年称作“师父”的人，那位据顾长山所说“早已故去”的人。

“这字，”她抬眼问郑继明，“谁送来的？”

“一个戴草帽的。从我后门进来，放下纸就走，连茶都没喝一口。”

草帽人。又是草帽人。

苏荷把纸条叠好收进衣袋，面上不动声色：“郑老板，谢了。这消息对我很有用。”

郑继明摆手：“别谢，苏老板。咱是同行，我敬你是个呛得住事儿的。那草帽人让我带句话——‘锅铲磨穿见铁心，到时候，自会有人来认’。”

话音落下，窗外忽地过一阵冷风，茶碗里的热气被卷散。苏荷攥紧衣袋里那张纸条，纸边硌着掌心，像一道烫不掉的印记。

沈伯言未死。姓钟的挖过空缸。草帽人送话来认。三条信息拧成一股绳，绳头握在谁手里？她看一眼顾长山，他微微颔首，目光落在门外青石板路的尽头——那里站着一个穿灰布衫的人影，帽檐压得极低，在冷风口里站了一瞬，转身进了巷子。

“走。”苏荷起身，把姜茶碗里最后一口饮尽，“跟上去。”

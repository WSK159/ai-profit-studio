# 第197章 递刀的人

苏荷把信递给顾长山时，街道办还没开门。顾长山在门廊下抽着烟，接过信看了两遍，眉头拧成了疙瘩。

“这字迹，练过。”他把信纸对着天光眯眼看了看，“钢笔字，横平竖直，一看就是机关里出来的。”

“跟刘经理的字对不上。”苏荷说，“刘经理的字我见过，向右斜，签单子带个横钩。这封信字字端正，像当秘书的。”

顾长山把信收进口袋，弹了弹烟灰：“昨天郑副科长来街道办领粮本发票，路过你摊子时停了两秒。他看着你门头的‘苏记’两个字看了挺久。”

苏荷心里一沉：“郑科长见过我？”

“见过。上周区里的个体户表彰会，他在台上发过奖状。那天你穿着红围裙站第一排。”

苏荷闭了闭眼，暗骂自己大意。她的红围裙太显眼，全城南巷就她一个人系。

“还有件事，”顾长山压低声音，“昨天晚上老陈的邻居捎话来，说老陈五月份回来过一次，在他家住了三天，然后去省城了。临走前留下一句话，说‘账本放了个稳当的地方，要是哪天我回不来，就去找城南巷姓苏的’。”

苏荷愣住了：“姓苏的？他知道我？”

“不知道。他那邻居也糊涂，说老陈当时醉着酒，只说了句‘城南巷姓苏的能看懂’。我猜他是听说了你查周建明的事，托人给你递话。”

“账本不在他身上？”苏荷追问。

“没找到。他女儿说翻遍了老陈的老屋，连墙皮都刨了，只有一叠旧报纸。”

苏荷沉默片刻：“他是怕账本落在别人手里。账本还在青江。”

顾长山掐灭烟头，看着她：“你打算怎么办？”

“找到老陈，或者找到账本。”苏荷说，“周建明盯我盯得紧，我动不了手，得绕个弯子。你帮我查查老陈去省城投靠的是谁。”

顾长山点点头，正要说话，巷口传来一阵嘈杂。两人同时转头，只见一个穿着灰布褂子的老头，拖着一辆破板车，车上堆着一摞旧木板，停在五号铺门口，仰着脖子喊：“周建明！周建明你给我出来！”

苏荷走过去几步，认出那老头——城南巷口裁缝铺的陈老爹，周建明上个月找他做了一身呢子大衣没给钱，陈老爹追了一个月。

五号铺门开了一条缝，周建明探出半个脑袋，看是陈老爹，嗤笑一声：“没钱。改天。”门要合上。

“你站住！”陈老爹从怀里掏出一张纸，“你别以为我不知道——你上个月给青江饭店刘经理送了两百斤耗油，按我侄子在二道贩子那打听的价，你有的是钱！你欠我这六十八块，拖了一个月了！”

周建明脸色一变，两步跨出来，压低声音：“你胡说什么？”

“我胡说？我侄子亲眼看的！”陈老爹嗓子大，满巷子的人脑袋都探出来了，“你从城东粮库后门拉出去的耗油，回头就送青江饭店后厨，你当大伙是瞎子？”

周建明脸上血色褪尽，一把夺过陈老爹手里的纸，扯碎了扔在地上：“老东西，你再乱说，小心我拆了你的裁缝铺！”

陈老爹被他推了个趔趄，扶着板车才站稳，气得直哆嗦。人群里议论纷纷，有人低声道“这周建明怎么回事”，有人拽着自家孩子往回拉，不敢多看。

苏荷站在人群外，把那条线理清楚了——周建明从粮库运耗油，过手卖给青江饭店。她转头看了顾长山一眼：“出库单上那‘刘经理签收，四桌席’，后头的数比单子上的大——多出来的货，就走的这条路。”

顾长山拧着眉头没说话。

周建明骂骂咧咧回屋去了，陈老爹蹲在地上拾纸片，拾着拾着，苏荷走过去蹲下来，帮他把碎纸拢到一起。陈老爹抬头看她，眼眶通红，嘴唇抖了抖：“苏老板……这日子，没法过了。”

苏荷没接话，从兜里掏出几块钱塞进他手里：“陈老爹，大衣的钱我给你垫一半，剩下的事，你找街道办。”

陈老爹愣住，张了张嘴，没说出话来。

苏荷站起身，往自己铺子走。走了两步又停下来，回头看了五号铺一眼——门缝里，周建明正扒着门框往里偷看，撞上她的目光，闪得极快。

她心里忽然涌上一个念头，这念头让她后背发凉：

周建明背后的人，要是郑副科长，那郑副科长的背后，又是谁？

谁有本事把老陈的案子压得无声无息，连查都没查就定了调？

她回到铺子里，灶上的水开了。苏桃正往锅里下面条，见她进来，小声说：“姐，刚才有人往门缝里塞了张条子。”

苏荷接过，是一张窄窄的纸条，上面写着一行字，字迹同早上那封不同，歪歪扭扭，像是左手写的：

“老陈的账本，在城南巷‘老宅’的房梁上。快去取，晚了就没了。”

没有署名。落款处画了一道浅浅的弯月。

苏荷看着那道弯月，手指微微发凉——上辈子，她在米其林餐厅学到的第一套刀法，师父说是从某个国宴大师手札里抄来的，手札扉页的落款，就是一道弯月。

她把纸条折了折，压进灶台下的砖缝里，深吸一口气，端起面条锅：“小桃，今天中午咱加个菜，做煨牛肉。”

苏桃不解地看着她：“姐，早上那事……你不怕了？”

苏荷笑了，伸手揉了一把妹妹的脑袋：“怕什么。这世道，越怕越没饭吃。我苏荷的饭馆，开一天，灶上的火就不能灭。”

她说这话时，锅里的水哗哗地沸着，正午的光照进铺面，照着墙上挂的“苏记小馆”四个字。

炉火旺起来了。

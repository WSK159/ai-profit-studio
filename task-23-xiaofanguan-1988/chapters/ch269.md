# 第269章 血迹与柴房

那血迹不是人的。

苏荷把草茎带回去后，在灯下仔细看了小半夜。干涸的暗红色块粘在荠菜茎上，像是被脚踩过之后又干透的。她拿清水泡了一刻钟，用竹签挑开，放在鼻子底下闻——腥气里带一点甜，是猪血的味道。而且不是新鲜猪血，是那种放了大半天、已经开始发酸的血。

可谁会往荠菜茎上沾猪血？除非那人是从宰猪的地方走过来的。

苏荷把草茎用白纸包好，塞进枕头的夹层里。躺下去的时候她想到一件事：青江市这一片的猪肉摊子，全在西街口的屠宰点。而去屠宰点最近的路，要经过味香居老店的门面。

第二天清早，苏荷照常开灶。骨头汤还在火上咕嘟，苏桃已经背起书包要出门。苏荷叫住她：“阿桃，你今天放学绕个路，去西街口看看味香居那个老门脸，现在是做什么的。”

苏桃歪头看她：“姐，你要去摸底呀？”

“少问，去不去？”

“去。”苏桃咧嘴一笑，跑出去了。

上午生意照常。红油抄手卖得火热，苏荷站在灶前，手掌翻飞间一碗碗抄手滑进滚水中。顾长山在下首切臊子，刀口拍得案板笃笃响。他抬头看了她一眼：“你今天翻锅的力道重了。”

“心里有事。”

他没再问。

午后收拾利索，苏荷换了身干净衣裳，出了城南巷往西街走。一路上经过好几家新开的馆子，门脸一个比一个亮堂，她看见味香居的老门面时，差点没认出来——那扇褐色木门已经漆成了大红，门楣上挂着一块新匾，上写“幸福饭店”。

门面扩大了一倍，玻璃橱窗里摆着油光发亮的烤鸭，门口立着块木牌，写着“新到粤式烧腊，欢迎品尝”。她站在对街看了一会儿，从前的味香居有三层，现在二层被拆了，改成了大片落地窗，里面摆了十来张圆桌，服务员穿着白围裙来回穿梭。

苏荷的目光落在那块匾额的右下角——一个豆大的记号，像梅花，又不完全是。她眯了眯眼，看见那记号的形状是五瓣。可金钩巷七号那枚钥匙上的是六瓣。

五瓣梅花，六瓣梅花，都是梅花——不是一个东西。

她正想着，幸福饭店的侧门吱呀一声推开，走出一个穿灰棉袄的中年人。不是戴眼镜那个，比那个个子矮些，左眼角有一道旧疤。他手里拎着一桶泔水，哗啦倒进路边的排水沟里，然后直起腰，往苏荷这边扫了一眼。

苏荷没躲，迎着他的目光站着。男人的视线在她身上停了两秒，又收回去，把桶拎着回了侧门，门砰地一声合上。

苏荷记下他的脸，转身往回走。

她绕道去了趟西街口的屠宰点，跟看门的老头打听：“师傅，昨儿这儿杀了几口猪？”

老头蹲在门口抽旱烟，眯眼看她：“你这姑娘问这个干什么？”

“买血。做血豆腐用的，我家开小馆子。”

“昨儿杀了两口，上午一头下午一头。买的早的都提走了，你来的晚了，剩点猪下水要不？”

“血还有么？”

“没了，全卖给一个老头了。”老头磕了磕烟灰，“灰棉袄，圆框眼镜，提个藤箱。说是给猫狗拌食用的，一下买走一大瓷盆。”

苏荷谢过他，往回走。灰棉袄老头买了整整一大盆猪血——可金钩巷七号的门前，只有一小片干血，草茎上沾的，更只有指甲盖大。

剩下那盆血，去哪儿了？

她加快脚步。

回到城南巷，柴房的门虚掩着。她早上走的时候记得是锁死的，锁是顾长山换的——新的黄铜挂锁，钥匙她带在身上一把，顾长山带一把。现在门虚掩着，锁挂在门鼻上，没被撬开，但锁舌是弹开的。

有人用钥匙开过门。

苏荷站在门口没有立刻进去。她先低头看地——门槛内侧的泥地上，有一行脚印，从门口直直通向柴堆，又折返回来。脚印比前一天那串要小，像是女人的脚，但走路的姿态很急，前掌压得比后跟重。

她顺着脚印走进柴房，柴堆还是老样子，靠墙的劈柴码得整整齐齐。但她一眼看出，墙角第三层柴火的位置被人挪动过——那根长条的松木原本是横放的，现在竖了。竖起来靠在墙上，正好露出一块地砖的边角。

苏荷蹲下去，用指头抠那块地砖的边缘。砖是松的，轻轻一抬就起来了。砖底下是一个浅浅的凹坑，坑里放着一只布包——蓝印花布，四角打了结，像装着什么东西。布包的正面朝上，中间用深色棉线绣着一个“周”字。

苏荷没有急着打开。她先站起来，往外看了看：巷子里有辆自行车经过，一位老太太在门口择菜，没有人往这边看。她重新蹲下去，把布包拿起来掂了掂，不重，像是一叠纸。她解开一角，里面露出一本泛黄的软皮本子，封面没有字，翻开第一页，写着三行钢笔字：

“味香居流水，自1947年始，至1983年终。周明善手记。”

周明善。

她翻到第二页，上面是密密麻麻的账目，字迹工整，记账习惯与金钩巷七号书房的米酒坛铜扣账本不同——但第三页纸快翻到底的时候，她看见了一个熟悉的记号。六瓣梅花，朱笔画的，印在账页末行的数字旁。

那个数字是“300”。

她记起金钩巷七号账册撕页处那半行的墨迹，若补齐应当是一个“叁佰”的开头。同一件事，一个记在账本里，一个画在流水册上。

她合上软皮本，把它塞回布包，又把地砖盖回去，把松木竖回原位。她站起来拍掉膝上的灰，走出柴房，锁上门。

钥匙只有她和顾长山有。顾长山一整天在店里，没回来过。那这扇门，是谁开的？那串女人的脚印，又是谁留下的？

她把布包藏进围裙里衬的暗袋，快步走回铺子。

顾长山正在擦桌子，见她回来，头也没抬：“柴房有人进去过？”

苏荷走到他面前，压低声音：“你怎么知道？”

“锁舌上有新划痕——不是钥匙开的，是用钢丝撬开的。那人不想要钥匙，只想看里面有没有东西。”

苏荷捏紧暗袋里的布包，半晌才开口：“她看到了。她进来找的就是这本——”

她还没说完，巷口传来一阵自行车铃声，紧跟着是苏桃的声音，又急又快：“姐！姐！幸福饭店那匾底下，有个小洞，里面塞着一团纸！我看到一个戴圆框眼镜的老头往里面塞的！”

苏桃跳下自行车，气喘吁吁地跑到门口，从书包里掏出一团揉皱的纸条，递给苏荷。苏荷展开纸条，上面用铅笔写着一行歪歪扭扭的字：

“三月初三子时，南门双锁水旱门齐开。故人来。”

# 第307章 亲娘

苏荷站在东厢房门外，后脊梁贴住门板，目光从母亲脸上移到桌沿那块绣着“周”字的蓝布上。屋里的煤油灯跳了一下，苏陈氏抬手拢了拢鬓角，像在做一件再寻常不过的事——给女儿倒了杯水。

“你爹没死。”她又说了一遍，声音比方才低了些，像是怕被谁听见。“荷儿，你先把门关上。”

苏荷没动。她看着眼前这个女人——前世今生加起来，她对这个母亲的记忆都是模糊的。苏陈氏在苏家从来说不上话，逢年过节都缩在灶台后面，苏父打骂孩子的时候她只会站在墙角抹眼泪。重生回来那天，苏荷掀桌出走，苏陈氏也没拦，只在她出门时往她包袱里塞了五个煮鸡蛋。

可眼前的苏陈氏，坐在桌边跟她平起平坐地说话，眼神平静得不像话。

“你……什么时候知道的？”苏荷终于开口，声音有点哑。

苏陈氏没有直接回答。她朝桌下努了努嘴：“你先坐下。”顿了顿，又说，“灰夹克走了，短时间不会再回来。他是我叫来的。”

苏荷慢慢走过去坐下，手搭在膝上，随时准备抄起那张凳子。她脑子里飞快转着——北墙坟冢、铁锅换旧、铜链钥匙、梅花灯笼、红绳引路，一直到刚才窗缝里听到的“真账册已送到你爹指定地点”，这条线索指向了一个她从未认真怀疑过的方向。

她爹。

那个重男轻女、卖女儿换彩礼的苏父，在她记忆里已经死在她重生前两年。她在苏家掀桌那天，有人告诉她“你爹三年前就死了”。她没哭，也没问，那些年在苏家受的委屈让她根本没想过要打探一个死人的消息。

“你爹没死。”苏陈氏又说了一遍，像是在确认什么似的，“他去了西桥。”

苏荷猛地抬头：“西桥？周明善也——”

话到一半，她刹住了。苏陈氏看着她，眼里浮起一层奇怪的光，说不清是欣慰还是悲伤。

“你也知道周明善。”苏陈氏点了点头，“你不傻。那你应该能猜到，你爹和周明善，一直是同一条路上的人。”

苏荷没说话。母亲脸上的表情让她想起灶台锅沿那道三道线地图——从锅底延伸出来的指向线，东北方向。周明善的铜钥匙，铁锅锅沿的刻痕，牛皮纸上“往东走，巷子深处有人等你”……每一件都把她往同一个方向引——她爹。

“当年把你卖给邻村，”苏陈氏的声音忽然低得像蚊子叫，“是你爹的意思，也不是你爹的意思。”

“什么意思？”苏荷语气冷了下来。

苏陈氏从袖口掏出一样东西，放在桌上。一块旧手帕，角上绣着一朵五瓣梅花。

又是梅花。

“你爹当年欠了一个人的债，要拿三百块钱去填。他没有，那个人说，拿女儿抵。”苏陈氏声音依然平静，“你爹当着众人的面把你卖了，但那笔钱，他没花一分。他把其中一半给了我藏起来，另一半——”她顿了顿，“换了周明善一条命。”

苏荷的手指攥紧了凳子边。她说不出话来。脑海里浮现的却是她爹最后见到她时的表情——重生的那天，她穿着嫁衣醒来，苏父站在门口，那双浑浊的眼睛里有厌恶、有愤怒、还有一点她当时没来得及细看的东西。

现在她想起来了。

那是愧疚。

“你爹去西桥，”苏陈氏抬起头，目光直直看着苏荷，“是去还债。西桥那头，是周明善欠的那个人。你爹替周明善去还，这事儿，只有我跟周明善知道。”

“那他为什么不回来？”苏荷声音干涩。

苏陈氏沉默了。她低头看着桌上那块绣“周”字的蓝布，指腹来回蹭着那个字，蹭了很久，才开口：“因为他走了以后，回过一次信。信里说——‘等荷儿把苏记开起来，我就回来。’”

苏荷的目光落在那块蓝布上。“这布——”

“是你爹走之前留的。他说周明善会认得。他让我藏着，等有一天你找到这个家的时候，给你看。”苏陈氏忽然笑了，眼角有细纹堆起来，“我没想着你会回来。我一直以为你恨这个家，恨到不会再踏进这扇门。”

苏荷没有说话。她的确恨过。恨了那么多年，恨到重生回来那一刻就想把这家人从自己的命里剜出去。可现在——她看着母亲袖口露出的一截红绳，绳头系着一枚铜钱。

那是她妹妹苏桃过年时编的。

“那灰夹克是谁？”苏荷深吸一口气，把情绪压回去。

苏陈氏的表情微微变了。她敛起笑，手指头在桌上轻轻叩了两下，像在斟酌什么。过了好一会儿，她说：“他是你爹在西桥那头搭上线的人。送信用的。你爹这些年靠他传了三次话。”

“第三次是什么时候？”

“十天前。”苏陈氏从袖口又摸出一张折得方方正正的纸，递过来，“他说，你若回苏家老宅，就把这个给你。若是没回，就烧掉。”

苏荷接过那张纸。纸是普通信纸，边缘泛黄，带着一股隐隐的灶灰味。她展开来，上面只有一行字，用毛笔写的，字迹瘦硬，带着一个力透纸背的捺脚——

“钥匙在你手上，门在北墙下。别信宋文起。”

苏荷盯着那行字，半晌没动。宋文起。她反复咀嚼这三个字。从北墙坟冢开始，宋文起的每一步指引都精准而自然，自始至终她只看到他想让她看到的东西。

她抬起头，看着苏陈氏：“他还说了什么？”

苏陈氏没有直接回答，而是看向东厢房后窗的方向，目光穿过窗纸，落在暮色笼罩的苏家老宅后院。院子深处，那棵老槐树上的五瓣梅花纸灯笼还在晃。

“他说——”苏陈氏的声音低下去，“周明善不是死在味香居。他是死在北墙底下。埋他的那块无字碑，是他自己立的。”

苏荷握着纸条的手猛地收紧。

“他死的那天——”苏陈氏说到这里停住，像是被什么卡住了喉咙，隔了很久才又接下去，“你爹也在场。”

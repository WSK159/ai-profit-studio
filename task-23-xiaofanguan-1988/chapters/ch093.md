# 第93章 夜半敲门声

青江市六月的夜，闷得像口蒸锅。

苏荷从看守所出来时，街边的路灯已经亮了。昏黄的光晕里飞蛾扑棱棱地撞着灯罩，发出细碎的啪嗒声。赵所长在门口跟她握了手，那只手厚实温热，往她掌心里塞了张纸条，没多说什么，转身就回了办公室。

苏荷低头看了一眼，纸条上写着三个字：“看后烧。”

她不动声色地把纸条攥进手心，朝巷口走去。顾长山推着自行车跟在旁边，两个人都没说话，影子在路灯下拉得老长。走到城南巷拐角，苏荷才停下脚步，展开纸条借着路灯看了一行字，然后摸出火柴点了，看着纸灰在风里散干净。

“赵所长说，王主任今晚从看守所那人里调了两个去城南巡逻。”苏荷把最后一缕烟掐灭，声音压得很低，“不是巧合。”

顾长山眉头一皱：“他是要动你。”

“他不敢明着动。”苏荷摇头，“但暗的，不好说。”

苏记小馆的门板已经上好了。苏桃蹲在门槛上写作业，一盏煤油灯搁在膝盖边，蚊香在脚旁冒着灰白的烟。看见姐姐回来，小姑娘眼睛一亮，连忙站起来：“姐，饭在锅里，给你热着。”

苏荷摸了摸妹妹的头：“你先睡。”

“我等长山哥走了一块儿睡。”苏桃轻声说，眼珠子在两人之间转了转，“周平嫂子下午来过，送了一篮鸡蛋，说是家里老母鸡下的。”

苏荷愣了一下。周平的妻子，那个瘦得脱了相的女人，居然还有心思给她送鸡蛋？她心里涌上一丝不自在，但没来得及细想。顾长山帮她把灶房的门拴好，又检查了一遍后窗的插销，才压低声音说：“你今天那招，王主任不会就这么咽下去。我回头跟街道办那边打个招呼，这几天我住你隔壁。”

苏荷抬眼看他。顾长山被她盯得耳根有点热，别过头去：“何记那边搞了几车砖头，说是要修仓库。这个节骨眼上拉砖，不太正常。”

“你是说，他可能要砸店？”

“不好说。”

苏荷把擦手的抹布往灶台上一甩：“砸店我倒不怕，就怕他使阴招——放火、举报、或者往锅里扔点什么东西。这些招数，我上辈子见多了。”

她话一出口就意识到说漏嘴，赶紧补了一句：“我是说，我见得多了。”

顾长山看了她一眼，没追问。他是那种知道什么时候该装糊涂的人。

这一夜苏荷没怎么睡着。蚊帐里闷热，她翻来覆去想了很久：何记的王主任，那个肥头大耳的男人，在她掀出周平供词之前，一直觉得她是块好拿捏的豆腐。现在豆腐变石头，硌了牙，他不恼恨才怪。问题是，恼恨之后他会怎么出招？

凌晨两点多，巷子里传来一阵杂沓的脚步声。

苏荷一激灵，从床上坐起来。她轻手轻脚摸到窗户边，拨开窗帘一角——月光底下，三条人影正从巷口往这边走过来，手里都提着东西。领头的那个晃着肩膀，脚步带着痞子气。

苏荷屏住呼吸，手摸到枕头底下那把菜刀。她这半个月已经习惯了在枕头边放刀。但三条人影走到苏记门口，没停下，径直走了过去。她松了口气，刚要躺回去，忽然听见一声细响——像是石子儿砸在瓦片上的声音，从后窗传来。

她猛地转身。后窗外的院墙顶上，露出一颗脑袋。

那人趴在墙头上，正扒着墙沿往下看，和苏荷的目光撞个正着。月光下看不出五官，只看到那人愣了一下，然后压低声音喊了一句：“苏老板？是我，刘三！”

苏荷心跳如鼓，攥紧菜刀走到窗边，压低声音：“你怎么翻墙？”

“正门锁了，我喊了俩钟头你都没动静。”刘三翻过墙头跳下来，拍掉身上的灰，凑到窗边压低声音，“我跟您报个信——今天下午何记那边的人跟王主任碰了头，我偷听到一句话。”

“什么话？”

“他们说，三天之内，要让你那口大铁锅，再也烧不出一锅红油抄手。”

刘三的牙在月光里白白地闪着，他的眼睛倒是黑亮亮的，带着一种在泥里滚过的人才有的机警。他顿了顿，又说：“还有一句话。那姓王的说了，你手里那份东西，他抢不回来，就废了它的证人。”

苏荷的指尖一点点凉下去。周平写的那份供词她下午已经给了赵所长一份，但王主任显然算准了——只要周平人没了，供词就成了死无对证的纸。她脑子里飞快地转了一圈，压低声音问：“周平现关在哪儿？”

“城北看守所，”刘三说，“赵所长管的那个。”

苏荷心里那块石头稍稍落回去半寸，但只落了半寸。她想起赵所长塞给她纸条时那只厚实的手，心里有了计较。

“你替我办一件事。”她从口袋里掏出一卷钞票，想了想，又添了一张，“明天一早，去城北看守所，把这张条子交给周平。”

“写什么？”

“让他给家人带句话——等案子结了，苏记小馆给他留个位置，管吃管住，月工钱八十。”

刘三瞪大眼睛：“他可是何记的伙计，您这是……”

“他是条可以救的人命。”苏荷说了这么一句，又补了一句，“你明早去，别让任何人看见。”

刘三收了钱，翻墙消失在夜色里。

后墙头恢复了安静。苏荷在黑暗中站了很久，灶间的铁锅没烧火，却好像还有今天红油抄手的余温。她忽然不知道自己这一步棋走对了没有——收留周平，无异于跟何记彻底开战。但如果连一个签了字画了押的人都能被人灭口，那她苏荷在这条巷子里也别想安生过日子。

她转身回屋躺下，眼睛望着屋顶的椽子。隔壁传来顾长山翻身的声音——他今夜也没睡踏实。

天亮的时候，苏荷是被一阵急促的敲门声吵醒的。她披衣裳起来，拉开一条门缝，门外站着个黑瘦的娃娃脸男人，穿一件洗得发白的工作服，手里拿着一封信，信封上的火漆已经开了，露着一角纸。

“苏老板，我姓何，”那人咧开嘴笑，露出两颗大门牙，“何记何经理让我给您捎句话——他说，前天王主任去看了周平，回来气色不太好。他让我来问问您，周平那份东西，您开价多少？”

苏荷靠着门框，慢慢系好衣扣，看了他半晌，忽然笑了。

“回去告诉你们何经理，”她说，“周平那份东西，我不卖。”

“那您要什么？”

“我要王主任亲自到我店门口，把那天晚上的事，当着街坊邻居的面说清楚。”

娃娃脸男人的笑容僵住了。苏荷已经“啪”一声合上了门板，又往门缝里补了一句：“早上九点，苏记开门营业。过时不候。”

# 第218章 铁证入库

清晨六点，城南巷的雾气还没散尽。

苏荷蹲在自家店门口，看着门上那几道暗红色的漆痕——昨夜泼的，现在干透了，像凝固的血痂。她没有急着洗，反而用指甲刮下一小块，凑在鼻尖嗅了嗅。一股混杂着桐油和铁锈的气味，不是普通红漆。

"昨晚那人泼完就跑，我追了半条街，没追上。"赵铁柱站在边上，胳膊上还缠着纱布，那是前两天跟刘三发对账时，被梁国庆的人推搡蹭破的。

"跑就跑了。"苏荷站起身，拍了拍手上的漆屑，嘴角微微上扬，"泼漆的钱，梁国庆得花三块五。这桶漆是从城东五金厂出来的，配方是军转民用那批，市面上只有他们一家产。回头让人去问一嘴，看谁提了货。"

赵铁柱一愣："你连这个都能闻出来？"

"后厨待久了，鼻子灵。"苏荷把漆屑包进手帕里收好，"这玩意儿就是证据。他雇的人再小心，买东西的环节不会不留根。"

正说着，巷口传来一阵摩托车响。一辆军绿色的挎斗三轮停在苏记门口，车斗里坐着个戴眼镜的中年男人，正紧紧抱着一个黑色公文包，像抱着命根子。顾长山戴着军帽，从驾驶位跳下来，看见苏荷脸上的漆印没擦干净，眉头就皱起来了。

"泼漆的人，我已经让人去查了。"他先从兜里掏出一块叠得整整齐齐的手帕递过来，“擦擦。”

苏荷接过来，没舍得用——那手帕是上好的棉布，边角还缝着朵小花，一看就是顾长山前阵子在百货大楼排队买的。

"省城带回来的，给你用。"他补了一句，耳根有点红。

苏荷心里暖了一下，却没工夫细品，目光已经落到那个眼镜男人的身上：“这位是？”

“孙德海的财务，姓周。”顾长山让开一步，压低声音，“他在孙德海手底下管了六年账，去年被调去档案室‘养老’，憋着一肚子火。我把人挖过来的。”

周会计从车上下来，脚还有点抖，嘴唇发白，显然坐了这么久的挎斗车颠得够呛，但一开口倒还算稳当："苏老板好。顾同志说，您这边能治梁国庆和孙德海那帮人？"

"治不治得了，要看您带的东西够不够分量。"

周会计左右看了看，苏荷会意，把人请进后院的灶房。门一关，窗户也拉上帘子，屋里只剩下灶台上咕嘟咕嘟熬着的一锅骨头汤。周会计的目光不自觉被那锅汤吸过去，咽了口唾沫。

"早餐还没吃吧？"苏荷盛了一碗汤端过来，碗里卧着两块带着骨髓的筒子骨，撒了葱花香菜，汤色浓白如奶。又从笼屉里拿出两个热腾腾的白面馒头，"边吃边说。"

周会计接过碗，指尖都在抖。喝了一口，整个人愣住了——那汤看着清淡，入口却厚，骨头的香气顺着喉咙一直暖到胃里。

"我叔当年就是干厨子的，在青江饭店掌勺。"周会计喝完汤，眼眶有点红，"后来被人顶下来了，气得中风，没两年就走了。我一直想着，能干倒一两个恶心人的，算给我叔出口气。"

他从公文包里抽出厚厚一沓账页，摊在桌上："这是孙德海和梁国庆从1985年到现在，三年油品调拨的对账记录。每笔都记得清清楚楚，孙德海批条子，梁国庆拿油，差价三七分成。油卖给谁，卖多少，都有明细。"

苏荷一页页翻过去，指尖停在其中一行上："青机械厂，八六年九月，五十桶，单价四块二。"她抬起头，"市场价当时才两块八，他翻了一倍卖给厂子，还说是'内部批条'？"

"厂里后勤主任是梁国庆的表哥。"周会计说，"这笔单子的真实油品质量，比炼油厂下脚料还差。后来机械厂那两台车床轴承烧了，厂里查过油料，最后压下来了，说是工人操作不当。"

苏荷把账页合上，看着顾长山："人证有了，物证也有了。就等梁国庆下一步动作了。"

顾长山点头："证人和东西我安排到安全地方，下午就送到区工商局备案。"

"不。"苏荷突然摇头，手指轻轻敲着账页，"先别急着交。"

"为什么？"

苏荷的眼睛亮了一下，那神采像后厨灶眼里的火苗，一寸一寸往上蹿："梁国庆以为他泼漆能吓住我，那我今天就当是被吓住了——关门歇业，去街道办哭诉委屈。让他以为他得手了。"

她走到门口，回头看了一眼那扇漆迹斑斑的店门："等他跳出来，把尾巴全露出来，我们再一刀切下去。"

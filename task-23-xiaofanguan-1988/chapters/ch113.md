# 第113章 雨中递簿

桥南的巷子窄，两边的老房子挤挤挨挨，屋檐几乎要接上。苏荷贴着墙根走，黑伞收起来夹在腋下，雨水顺着她扎的马尾往下淌。怀里那本账本被油纸裹得严实，像揣着一团火。

她拐出巷口的时候，正好看见那辆黑色伏尔加停在桥头，车窗摇下一条缝，里面的人似乎正朝着白水门方向张望。苏荷放慢脚步，装作过路人，低头踩着水渍往前走。路过伏尔加时，她余光扫了一眼——车里坐着两个人，前排司机抽烟，后排的人看不清，只影影绰绰觉得身形很宽。

“喂，站住。”

后排车窗全摇下来，露出一张四十来岁的方脸，眉眼压着，带着体制内熬出来的沉。他盯着苏荷：“姑娘，这么晚还下雨，你去哪儿？”

苏荷站定，心跳擂鼓，面上却露出一个腼腆的笑：“去前面婶子家拿两斤面条，明儿早市摆摊用。”

“摆摊？”方脸男人上下打量她，目光在她空空的双手上停住，“空手去拿面条？”

“婶子家就在巷里，空手去，拿上就回。”苏荷说着，指了指身后那条巷子，“就三号桥边儿上那个早点摊，我家的。”

雨声里，她听见车里前座的人低声说了句什么。方脸男人没再追问，只挥了挥手：“走吧，雨大，别逗留。”

苏荷点点头，低头快步走过桥面。靴子踩在水洼里，溅起的水花湿了裤脚。她不敢回头看那辆车，只是脚步越来越快，一直走到桥北的邮筒旁，才停下来喘气。

她抬头看了眼手表——八点十七。押解车如果走白水门那条路，大约八点半到三号桥。只剩十三分钟。

苏荷把油纸包从怀里掏出来，解开，确认账本无恙，又重新裹好。她想了想，把油纸放进外套里层，贴着小腹绑紧。然后她站到邮筒旁，淋着雨，像一截木桩子似的定住。

八点二十一。桥南传来发动机的声音，那辆伏尔加突然启动，掉头，朝白水门方向开走了。苏荷心头松了半口气，又提起来——它走了，但不代表王顺德不派别人来。

八点二十六。一束远光灯从白水门方向打过来，照穿雨幕。苏荷眯起眼，看见一辆军绿色吉普车驶上三号桥，车速不快，后窗蒙着铁栅栏——押解车。

她深吸一口气，走到桥中央，举起右手，像招出租车一样挥了挥。

吉普车在离她四五米的地方刹住，溅起一片水花。驾驶座摇下窗，一个穿制服的中年男人探出头：“谁？大晚上堵路干什么？”

苏荷走近两步，把油纸包从怀里掏出来。雨淋在她脸上，头发贴着脸颊，她声音不大，却很稳：“同志，我是个体协会的，有人托我把这份材料交给韩同志，说他在车上。”

驾驶座上那人一愣，和后座的人对视一眼。副驾驶门开了，一个穿绿雨衣的人跳下来——正是刚才在邮筒旁等她的那个。他走到苏荷跟前，军帽下的脸年轻，二十七八岁，眉骨很高。

“我就是韩。”他说，“你胆子不小。”

苏荷把油纸包递过去，手没抖：“沈其昌的账，白水门粮站那三笔，都在里面。韩同志，这上面有王顺德的落款，也有省里那个姓赵的笔迹。人要是押走了，账再到了，就更说不清了。”

韩接住油纸包，掂了掂，塞进雨衣里：“知道了。”他转身要走，又停下，“姑娘，你叫什么？”

“苏荷。城南巷，苏记小馆。”

韩没再说话，拉开车门坐进去。吉普车重新发动，碾着雨幕往省二监方向驶去。

苏荷站在原地，雨水打在她脸上，她忽然笑了。

直到吉普车的尾灯消失在雨里，她才发觉自己的双腿在发抖。她扶着桥栏杆，弯下腰，大口喘气。怀里空了，胸口的压迫感却减轻了。

她直起身，往回走。走出没几步，路边一辆停着的自行车忽然倒了，车铃在地上弹了一下，发出脆响。她看过去，便见车旁站着一个撑黑伞的身影，不知道站了多久。

伞沿抬起，露出一张她熟悉的、沉默的面孔。

顾长山。

他看着她的眼神里，有怒，有怕，最后凝成一句压着火的话：“我说的是送到传达室接应，没让你自己去堵押解车。”

苏荷抹了一把脸上的雨水：“账本送到了。但传达室那老头喊我，韩撤了，伏尔加又堵桥头——我没别的办法。”

顾长山沉默片刻，把伞朝她倾了倾，罩住她半边的雨：“走。先去我那儿换身干衣服，再说下一步。”

苏荷没动。她望着他：“下一步是什么？沈其昌能不能出来，就看那本账了。”

顾长山喉结动了动：“韩在车上，账本在韩手里。但王顺德今晚就回青江——他手里还有一张底牌没出。你得先知道，那张底牌是什么。”

他顿了一下，又补了一句：“老赵之所以敢拿着伪借条找你要账本，是因为他以为账本里记的是粮站亏空的钱。但账本第三页背面，米汤水藏了一行字——那行字才是要命的东西。沈其昌不肯说，韩问我，我才想起来从他家糊窗的报纸背面找到的。”

苏荷瞳孔一缩：“写的什么？”

顾长山把伞又压低了些，声音几乎被雨声吞没：

“青江粮站，王顺德收了孙家三千斤指标粮的回扣。拨款去向，记在市局马科长家的存折上。那本存折，现在在王顺德老婆的手提包里，正跟着她回青江。”

雨声翻涌。苏荷觉得自己的心跳声盖过了整个夜空的雨。

她又仰起脸，一字一字地问：“那她的火车，几点到青江？”

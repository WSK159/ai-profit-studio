# 第297章 灰鸽子的竹管

灰鸽子没有飞走，也没有叫，就那么站在枝头，歪着脑袋看苏荷，像是在打量她值不值得信任。宋文秀脸色变了，伸手要赶，苏荷抬手拦住她：“别动。”

她缓步走到树下，伸出手掌。灰鸽子偏了偏头，翅膀微微张开又合拢，然后扑腾了一下，落在苏荷的腕上。脚上的竹管是空的。

竹管口朝下，里面什么都没有。

苏荷的心沉了一下。她把竹管取下来捧着，掌心里触到一种异样的油润——竹管内壁被一层薄薄的油脂涂过，在月光下泛着暗色。她凑近闻了闻，一股陈年菜籽油的气味幽幽渗入鼻腔。就是那口米酒坛铜扣缺口带到柴房的气味。

“这鸽子——”宋文秀盯着苏荷手里的竹管，“是有人养的？”

苏荷没回答。她翻过竹管，管壁上有一条极细的划痕，像是有人用刀尖刻的。她借月光细辨——是个“子”字。刻痕边缘旧得发黑，不是新添的。

“子”字。苏荷脑中“嗡”地一声。前情里，她两次在子时赴约，子时北墙坟冢之约，子时三刻灯亮的选择——这个“子”字，与那些夜的节点严丝合缝地咬合。有人在她必经的路上留下了这个竹管，先在竹管里装过东西，又被人取走，只剩下一层油迹。

“竹管是空的。”宋文秀声音发涩，“你认识养鸽子的人？”

苏荷没有正面回答，把竹管收进衣兜：“有人用这鸽子送信，送到一半被人截了——或者，送信的鸽子在中途停过，被人换过竹管。”她看了宋文秀一眼，“你哥有没有用过灰鸽子跟你联络？”

宋文秀摇头：“我哥从来不养鸟。他信里说——”

“他的信呢？”苏荷打断她。

宋文秀愣住了。她犹豫了一下，从怀里掏出一封被折得皱巴巴的信。信封泛黄，折痕处发白，显然被翻看了很多遍。苏荷接过来，信封上没有邮票，没有邮戳，收信人写着“秀妹亲启”。字迹工整，笔力遒劲，像出自常握笔的手。

她抽出信纸，借着月光逐字看下去——

宋文起的信很短，言简意赅：“事已查清，凶手指向周家旧人。陶罐在老槐树下，内有账页与钥匙，取走勿惊动旁人。罐中无论有甚，千万别让姓苏的知道。”落款是五十天前的日期，比宋文秀说的“三个月前”差了四十多天。

苏荷的目光停在“千万别让姓苏的知道”几个字上。宋文起明明要让妹妹瞒着姓苏的，可他留下的铜钥匙却偏偏刻着“周”字，而周明善的油纸图又把线索指向苏家祠堂——仿佛刻意要把她苏荷引到这条路上来。

“这封信，”苏荷抬眼，“你哥是托人带给你的，还是寄的？”

“托人捎的。”宋文秀说，“一个路过俺村的货郎，说是在青江见过我哥，替他把信捎回来。”

“货郎长什么样？”

宋文秀皱眉想了想：“四十来岁，黑瘦，左手——左手少了根小指。”

苏荷心口猛地一紧。左手少小指——她在幸福饭店见过那个人。那个在疤脸男的柜台边斜靠着、手里转着两颗铁核桃、被她不经意扫了一眼的黑瘦男人。当时候疤脸男迎出来跟她说话，那个少指男人就退到了后门，再没露过面。

他替宋文起捎信，现在又出现在幸福饭店。宋文起和疤脸男是同一伙人？

“你哥后来再没托人带过信？”苏荷追问。

“没有了。”宋文秀垂下眼，“我到了青江，去他信里说的城南巷找过，那地方改得厉害，老住户都不在了。我想找他租的房子，可连门牌都对不上……”

苏荷把信纸递还给宋文秀，心里那些碎片开始慢慢咬合。宋文起三个月前失踪，托货郎带信回家，他留下陶罐和钥匙，又警告妹妹别让姓苏的知道——可他做的每一件事，都像算准了会被她苏荷发现。那枚刻着“周”字的铜钥匙，真的是宋文起留给妹妹的？还是有人在宋文起不知情的情况下，往空罐的回填土里塞了这枚钥匙？

灰鸽子“咕咕”叫了一声，扑棱棱飞起，落到祠堂东墙的屋脊上，回头看着她，又飞了一小截，落在更远的一棵榆树上——像是在等她跟上。

苏荷忽然想起灰衣老头的话：“他一直在等着引你去。”

她攥紧衣兜里的竹管，闻着那股陈年菜籽油的气味，望着灰鸽子在月光下飞了一程又一程，黑瘦货郎的脸和疤脸男的柜台在脑中晃动。

宋文秀的声音从身后传来：“你要跟那鸽子走？”

苏荷没回头。灰鸽子又“咕咕”叫了一声，那声调像是催促，又像是某种约定——仿佛这鸟儿不是被人驱使的，而是认得她，认得她衣兜里那截油迹竹管的气味。

“替我把钥匙收好。”她对宋文秀说，已经把铜钥匙重新握在手里，“如果天亮前我没回来，你拿这把钥匙去城南巷苏记小馆找顾长山，告诉他——”

灰鸽子又扑棱一下翅膀，飞高了几尺，盘旋一圈，朝东边飞了出去。

苏荷把话说到一半就住了口，拔步跟上去。老槐树的影子在她身后拉得老长，宋文秀站在那儿，看着她的背影融进夜色，又低头看了看手心里那枚锈蚀的铜钥匙——“周”字在月光下泛着幽暗的光，像是睁着一只沉默的眼睛。

苏荷追着灰鸽子的踪迹穿过两里街巷，一直追到一片瓦砾遍地的废旧工地。灰鸽子落在一堵残墙上，回头看了她一眼，然后飞过低矮的墙头不见了。苏荷快步绕过墙，眼前的荒地中央立着一扇孤零零的木门——门板是老柏木的，门楣上没有匾额，门缝里透出一线昏黄的烛光。

她认得这扇门。她在梦里见过它，在铁锅底部的油纸、双眼井的金钩巷七号的夹层里，它被那三处朱砂标志连成的一条直线指向过——这门背后，是什么？

她伸手推门。

门闩自行拨开，“吱呀”一声，门内烛光摇曳，照出一张背对门口的椅子。椅子上坐着的人没有回头，只压着声音说了一句：“你终于来了。把门带上——这屋里，有别人不想让你看见的东西。”

# 第369章 草帽人的话

那影子只闪了一下就不见了，巷子里只剩风吹旧瓦的簌簌声。

顾长山追出去两步，又被苏荷叫住了：“别追了，他不露面，追也追不上。”

她认得草帽人的脾性——从送盐粒那晚到现在，这人神出鬼没，从不正面打交道，却总在她走到关键一步时出现在附近。像影子，又像摆渡人，只在你需要的时候露一个边。

两个人快步走回苏记小馆。后院灶间还亮着灯，苏桃坐在灶前择豆角，听见门响抬起头：“姐，你今儿怎么回来这么晚——”

她的目光落在苏荷怀里那口黑乎乎的铁锅上，愣了愣：“这锅……好老啊。”

苏荷把铁锅放在案板上，又解开油布卷，把《董氏锅谱》和调料方子一并取出。苏桃凑过来看，一眼瞧见那页地图上的“董宅”二字：“城南东边那片酱菜厂？我昨天买菜路过那儿，铁栅栏上贴了张告示，说要拆了改商品房。”

“拆迁？”苏荷猛地抬头，“什么时候的事？”

“就这两天，厂长在门口贴的，”苏桃说着，又补了一句，“但听买菜的大娘说，那厂长年前就放出风声要卖地皮了，只是一直没谈拢。”

苏荷和顾长山对视一眼。董宅要拆了——如果那里真藏了董青山留下的东西，一旦推土机进场，就再也没机会找回来了。

可问题在于，她只知道地图上画了董宅的位置，并不知道东西藏在董宅的哪一处。

“明天我去看看。”苏荷把地图又看了一眼，记住方位，“正好那批香菇还剩一点，给酱菜厂食堂送过去，顺便进厂里转一圈。”

顾长山皱眉：“绕这么大个弯子？”

苏荷笑了笑：“酱菜厂的食堂主任上个月来过店里，想订一批红油咸菜。我一直没松口。”她轻轻敲了敲铁锅沿，“明早我去送货，他总不好不让我进厂门。”

正说着，店门外的布帘子忽然被风掀动了一下。苏荷回头——没有人，但门槛上不知什么时候落了一小把东西，在灯下泛着暗光。

她走过去蹲下。

是几粒粗盐，混着一小撮干枯的野薄荷。

草腥气飘上来，和那晚草帽人送盐粒时一模一样。

苏荷把盐粒和薄荷叶拾起来，指尖碾了碾薄荷叶，粉末落在掌心，有股清凉刺鼻的味道。她心头一动，拿出手帕包好，回头看那本《董氏锅谱》——锅谱封皮用的老布，布纹粗疏，夹层里鼓鼓囊囊的，好像塞过东西。

她小心拆开封皮边线，果然从夹层里抽出一张薄如蝉翼的棉纸。纸上只有一行字，用枯笔写成：

“井中取锅，灶底取方，董宅无宝，宝在酱缸。”

底下又添了一行小字，字迹潦草，像是后来补加：“第三口缸，底下带暗格。”

“这意思是……调料方子和锅谱是明面上的，真正的宝贝在董宅酱菜厂，第三口缸底下？”顾长山凑过来看了半天，“那盐和薄荷是什么意思？”

苏荷闻了闻手帕里的薄荷味，又看了看棉纸上的字，忽然记起一件事——苏桃说过，酱菜厂的大门口种了一大丛野薄荷，大夏天也没人除，长得铺天盖地。

草帽人送盐粒和薄荷，是在指路。

她抬头望了一眼窗外，外头巷子在月色下泛着银灰色的光，空荡荡的，一个人影也没有。

苏荷心里五味杂陈。这个来路不明的人，一而再、再而三地在她触及关键线索时递出提示，却从不露面——他到底是谁？他为什么知道董家的事？又为什么选中了她？

“明天去酱菜厂，”苏荷语气沉了沉，“第三口缸的事，不能拖。”

苏桃忽然拉了拉她的袖子：“姐，我想起个事来。你让我记的那本账册，我翻到前头几页，有一页写的是‘董酱园’的赊账记录——时间是民国三十七年，最后一笔写着‘欠青江董宅酱菜三坛，来年连本带利，加倍归还’，底下签字的是一个姓郑的人。”

“郑？”苏荷脑子里那张“方脸男人老郑”的线索猛地跳了出来。

“对，郑，”苏桃点点头，“可后头用红笔涂了，涂得很用力，不仔细看根本看不出原来写的啥。我是对着光才看见的。”

苏荷把那页账册拿过来，果然，账页角落有一大团红色的墨迹，透了纸背。她对着灯火看了一阵，只隐隐辨出“郑”字和“董宅”两个字，其他字迹全被糊住了。

她合上账册，心里那根线越拉越紧。

郑——董宅——酱菜缸——草帽人。

这条线就像一团未解的线头，从她重生那日起，就一圈一圈绕在青江城里，快绕到她脚底下了。

她深吸一口气：“明天一早，去酱菜厂。”

窗外起了一阵夜风，把布帘子掀起一角。巷口老槐树底下，一个戴草帽的身影站了一会儿，直到屋里的灯熄了，才缓缓转身走进夜色里。他手里拄着一根磨得发亮的竹竿，那竹竿一头，系着一块看不出颜色的旧布条，在风里轻轻晃着。

他走得稳，却不慢，像这条老巷他走过千百回一样。

夜风里传来一阵很轻的叹息，像自言自语，又像对着风说话：

“快了……就快到了。”

# 第277章 井底三声

三声闷响过后，竖井里重新陷入沉寂。顾长山把匕首咬在齿间，双手握紧井绳往下探了探，绳索绷得很紧，底部挂着重物。

“我先下。”他说。

苏荷没争。她把那块绣着五瓣梅花的手帕贴身收好，又将梅花钥匙和铜扣重新拴在颈间。顾长山已踩着滚轮滑下井壁，铜油灯的光芒在他头顶一晃一晃，几十息后，底下传来一声：“到底了，安全。”

苏荷深吸一口气，握绳攀下。井壁光滑，铁钉上的铜油灯烧得正旺，像是有人刚添过油。她数了数，一共四十九级，最后一级落地，触脚是一片平整的水泥地，干燥无尘。

竖井底部是一条笔直的甬道，高约两米，宽可容三人并肩。甬道两侧的砖墙涂着白灰，每隔十步嵌着一盏玻璃罩煤油灯，光线昏黄，却足够看清路。地面涂着防潮沥青，走在上面没有脚步声。

顾长山已经站在甬道尽头一道铁门前。门是钢板焊的，厚实沉重，门楣上钉着一块搪瓷牌，白底红字写着：三号仓。

仓门没锁。门缝里透出光。

顾长山侧身推门，钢板发出沉闷的“吱呀”声。门后的空间出乎意料地大——足有两间铺面那么宽，高约三丈，水泥柱子林立，天花板上悬着一排铁钩。角落里堆着麻袋、空木箱、几口铁皮桶，全部落满灰。

但正中央的地上，干干净净。

一张杉木长桌，桌上放着一盏马灯、一只搪瓷杯、一本翻开的账簿。桌边一把圆凳，凳上坐着一个老人，背对着门口，低着头，双手搁在膝上，一动不动。

他穿着灰布棉袄，旧得发白，后颈露出一截发黄的衬衣领。头发花白，剃得很短，露出青白的头皮。

苏荷的心跳猛地加快。她认得这个背影——哪怕隔了快两年的光阴，哪怕换了衣裳换了地方，她也绝不会认错。那是她在前世厨房里站了十几年的师父，周明善。

“师父。”

她的声音从喉咙里挤出来，带着一丝不易察觉的颤。这声“师父”她在心里喊了无数遍，梦了无数遍，以为自己再也没有机会当面喊出口。可此刻真正喊出来时，她整个人反倒出奇地稳。

老人没有动。过了好一会儿，他才慢慢抬起头，但没有转过来。他的嗓音沙哑，像砂纸划过铁皮：“门关了没有？”

顾长山退后半步，把仓门推严实，铁门沉重地合上，锁扣自己落下来。

老人这才缓缓转过身。

苏荷终于看清他的脸。比她记忆里瘦了许多，颧骨高耸，眼窝深深陷下去，一双眼却仍亮着——那种光她认得，是经历过火与铁、命与死的人才有的沉着。他左边眉骨上一道旧疤斜贯而下，那是她熟悉得不能再熟悉的记号。

“你认得我。”老人说，语气平静，不像疑问，倒像确认。

苏荷点头。

“认得我便不该来。”周明善把桌上那本账簿推过来，“看完再说话。”

苏荷翻开账簿。纸页泛黄，墨迹褪色，开头几页是工工整整的账目记录，日期从民国二十三年说起——米、面、肉、油的进出。她翻到中段，笔迹忽然变了，变得急促凌乱，歪歪扭扭，多处被水渍洇开。上面记着：腊月十二，晚，汤家送八个菜，称贺寿。十三日起，三人毙。十四日，又二人。至十九日，汤家上下十口均腹绞痛亡，独长子文渊在外求活。账页最后一行，写着一个“债”字，落款是“周明善泣血书”。

“汤家十三条人命。”苏荷合上账簿，“账上记的是十口……”

“还有三口是汤文渊后来娶的妻儿。”周明善垂下眼皮，“他寻到我门上要说法，我不在，他妻儿先被灭了口。那三口，也是我周家的债。”

他顿了一下，声音更低：“你手里那块手帕上的五瓣梅花，是汤文渊留下的记号。他以为我是来索命的。”

“那你……”苏荷看着他。

“我确实欠他一条命。”周明善缓缓站起来，身形有些佝偻，却依然挺着脊梁，“民国三十年，我年轻气盛，替人做了一桌宴席，菜里被人掺了东西。汤文渊替我挡了那一口，落下病根。他家十口死的时候，我在外地躲债，不在青江，来不及救。我欠他汤家的，用这条命也还不清。”

他说完这句话，从袖口摸出一把铜钥匙——与苏荷颈间那枚梅花钥匙样式相同，但花心是整片的，没有镂空。

“这是第四把钥匙。”他把钥匙放在桌上，推向苏荷，“汤家祠堂西墙第五块青砖后面，有一封信。你拿着它去，看完就烧。”

“为什么是我？”苏荷问。

周明善忽然笑了，那笑极淡，像风里摇摇欲坠的烛火：“你有一双不该生在年轻人身上的眼睛。你见过我这本账簿上的字，也见过汤家祠堂那块砖。天底下知道这两样东西的人，只有我，和你。”

苏荷心中一动，攥紧了那张手帕，那上面五瓣梅花的针脚在灯下微微反光。她还未来得及追问，仓门外忽然传来三声重击——比方才井下的那三声更响，震得铁门嗡嗡直颤。

周明善脸上的笑容消失了。他侧过头，盯着铁门，低声说：“来了。”

苏荷和顾长山同时回头，铁门上那块巴掌大的窥视口从外面被拉开，露出一双眼睛。那双眼睛在昏黄的灯光下显得异常清亮，瞳孔里映着三号仓里的马灯光。

那人隔着铁门，声音不高不低，带着一丝戏谑的笑意：“周师傅，你藏了这么多年，终于肯露面了。你欠我汤家的，是打算用一封信了结，还是用几条命还？”

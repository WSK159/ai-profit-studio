# 第329章 假井下的泥人

天刚亮，苏荷就醒了。她没急着去灶房，先翻了翻自己的木匣，把铜钥匙和那片骨片并排摆在桌上，看了足足一盏茶的工夫。钥匙柄上有一个极浅的凹槽，她一直没注意过。昨夜看到灶台豁口里那根麻绳的绳结，她终于想起在哪里见过这种结——那是在她前世师父的遗物里，一本旧笔记本的封皮上用同一种绳结系着一枚铜钱。

师父的东西。怎么会在周家老宅的灶台里？

她合上木匣，出了门。顾长山已经等在巷口，胳膊底下夹着那把铁锹。两人没多话，直奔周家老宅。

宅外已经拉起了半圈草绳，拆迁队的石灰线划在墙角。还有三天，推土机就进场。苏荷绕过草绳，从后院的豁口翻进去，后院那口假井还在，井口压着块厚青石板，石板边沿同样有被撬动过的痕迹——灰夹克确实来过。

顾长山撬开石板，露出井筒。假井不深，也就三尺多，底下是干土，没有水。苏荷跳进去，蹲下来捻起一把土，土里夹着碎瓦片和几粒发黑的稻壳，年代久远。她用手掌慢慢抹开浮土，在井筒西侧的壁上，她摸到一块松动的砖。

砖抽出来，后面不是土，是一个拳头大的空洞。她伸手进去掏了一把，指尖碰触到一个硬物，冰凉的，像块石头。她捞出来一看，是一个巴掌大的泥塑小人，捏得粗糙，五官模糊，但能看出是个盘坐的人形，腹部位置嵌着一枚指甲盖大小的青黑色鱼骨。

鱼骨。苏荷眼皮一跳。她把泥人翻过来，后背上刻着三个歪歪扭扭的字：金桂氏。

“金桂。”她低声念出这两个字，跟周顺水当时念的“金桂者，桂之根也”对上了。她把泥人托在手心端详，那枚嵌着的鱼骨在晨光里泛着暗哑的光，显然不是摆设。

“这就是所谓‘鱼之灵’的载体？”顾长山也跳下来，俯身看着泥人，“一枚鱼骨，为什么有人要煞费苦心埋在假井里？”

苏荷没有立刻回答。她把泥人小心收进怀里，又回到空洞前，伸手再探了一遍，这回摸到一张折叠多次的油纸。展开一看，上面画着一幅简略的地形图：城南巷的地界，标注着老宅、周家老宅、城隍庙、青江渡口，四个点之间用虚线画出一条蜿蜒的路，终点打了一个圈，落在离城隍庙不远的某处——旁边写着一行小字：“鱼骨三，此地亦埋其一。”

一。三枚鱼骨中的一枚在这里。剩下两枚，分别在灶下井和城隍庙附近。

苏荷把油纸折好塞进口袋，转头问顾长山：“城隍庙附近有什么老地方？”

顾长山想了想：“城隍庙西边有座废仓库，以前是粮站的旧库房，后来废弃了。再过去就是青江渡口。”他瞥了一眼油纸，“你要去挖？”

苏荷摇头：“不急。我得先弄明白‘以人补’三个字是什么意思。”她低头看着怀中的泥人，“这泥人塑法我见过——我师父说过，旧时有些老厨子会给灶君塑像，为了镇灶护烟。但给泥人嵌鱼骨的，我是头一回听说。”

她话音未落，院墙外忽然传来一阵脚步声，紧接着一个尖细的嗓音飘进来：“诶哟，这不是苏老板么？怎么跑这拆迁地里来了？”

来人是个四十出头的瘦高个，腋下夹着个皮包，戴着顶蓝涤卡帽，一嘴发黄的牙齿露在笑纹里，正是拆迁队马队长。他倚着墙根看了两人一眼，目光落在苏荷怀里鼓起的包裹上，笑了笑，没追问。

“马队长，早。”苏荷不动声色地直起身，“过来看看老宅子，以后拆了就看不到了。”

“这话说的，苏老板要是喜欢，等拆完了，砖瓦我给你留几块摆店里，当个念想嘛。”马队长打着哈哈，却多看了她身后那口假井一眼。

苏荷看在眼里，笑意不改：“那就先谢过马队长了。”她拍拍裤子上的灰，转身和顾长山一前一后出了院墙。

走到巷尾拐角处，苏荷才压低声音：“马队长刚才那一眼，不是看我，是看那口井。”

顾长山点头：“他发现井被撬开了。”

“或者说，他一直在等别人撬开。”苏荷微微眯起眼，“这个拆迁队，恐怕不是普通的施工队。”她脑子里忽然闪过那张油纸上的虚线，从老宅到城隍庙，再到青江渡口，像一条埋藏多年的暗线，而她是顺着线头被引过来的那只手。

她低头看了一眼怀中的泥人，那句“须以人补”在心头萦绕不散。忽然之间，她想起一件前世师父说过的事——旧时有人养鱼骨以凝灶魂，代价是养者须以自己的心血养满百日，若中途断了，灶魂反噬，轻则破财，重则丧命。

师父当年说这话时，语气极淡，像在讲一个无关紧要的旧传闻。但此刻苏荷站在假井边，回忆起那张与师父笔迹相同的羊皮纸，心中有了一个荒唐而冷彻的猜测：她的师父，可能也是这套“鱼骨”传承中的一环。

而那枚嵌在泥人腹中的鱼骨尖头处，似乎泛着一丝极淡的红。

——像血。

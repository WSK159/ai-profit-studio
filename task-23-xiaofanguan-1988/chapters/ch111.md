# 第111章 账本过桥

吉普车在桥头刹住，溅起一片水花。车门打开，顾长山从副驾驶跳下来，身上的军雨衣拧着水，大步朝桥中走来。

“苏荷！”他喊了一声，声音被雨削去一半，“过来！”

苏荷没动。她盯着面前这个左手缺了小指的男人，心里飞速转动着。老赵说韩姓接应人左手缺一小指，和眼前这位对上了。但顾长山的口信里说的是“韩姓省局人员”，他应该直接接应沈其昌才对，怎么会在三号桥等着她？

“账本呢？”缺指的韩姓男人开了口，声音低沉平缓，尾音确实带着点南方口音，“苏同志，给我。”

苏荷的手还插在棉袄内袋里，贴着账本的那个牛皮纸封皮。她没急着掏出来，而是问了一句：“沈先生呢？”

男人朝身后看了一眼。吉普车后门打开一条缝，露出半张脸——是沈其昌。他头上贴着一块纱布，脸色惨白，但眼神是清醒的。看见苏荷，他微微点了一下头。

苏荷的心这才落回肚子里。

她掏出油布包，撕开牛皮纸，露出真账本焦黄的书页，递给韩姓男人。男人接过去，没有翻开，而是把账本贴着胸口放进了风衣内袋，然后朝车里喊了一声：“老沈，带她上车。”

苏荷弯腰钻进吉普车后座，和沈其昌坐在一起。雨水顺着她的头发往下淌，她也不擦，抬头看着沈其昌：“沈叔，怎么回事？王顺德怎么把你弄进去的？”

沈其昌靠在座椅上，声音沙哑：“他拿了一叠‘证据’，说白水门粮站的两笔亏空是我经手的。当年账目上的确有我的签字，但那是有人冒充的。王顺德派人把那个‘证人’也带来了，是人证物证俱全。”

苏荷拧了一下眉：“他动作这么快？”

“他筹备不是一天两天了。”沈其昌咳嗽了两声，“估摸着，从一开始他来青江市，就是冲着白水门的粮站账目来的。我不过是他拿捏的最佳人选——年纪大了，没背景，出了事没人替我说话。”

苏荷咬了咬下唇。她低头看了看自己的手，指甲缝里还沾着揉面的面粉，洗也洗不掉。忽然她想到什么，转头盯着沈其昌：“沈叔，账本我给了韩同志，那他们下一步要做什么？要把账本交给谁？”

沈其昌闭上眼，沉默了一会儿，才开口：“省纪委。账本到了那儿，王顺德就算有天大的本事也压不住了。”

“那他——”

“他不会有事。”沈其昌睁眼看了她一眼，眼里有了一种苏荷看不懂的光，“苏丫头，你没问账本里的那个‘王家’落款是什么意思，我很感激。有些东西，你知道得少一些，反而安全。”

苏荷沉默了。

车子在白水门的河堤上拐了一个弯，朝城北驶去。雨势渐渐小了，车窗玻璃上淌着稀稀拉拉的雨丝，透出远处青灰色的天光。

顾长山坐在副驾驶，一直没开口。直到车子驶入一条僻静的街巷，他才回头看了苏荷一眼：“老赵在大雨里跟你说话，说了什么？”

苏荷把老赵的话原原本本地转述了，包括那句“你只需要把账本交到该交的人手里”。

顾长山的眉头拧了起来，半晌才说：“老赵这个人，我查过。他是省粮食厅退下来的老干部，退休前分管‘法规政策’——也就是专门给上面跑腿的。他这一趟来，恐怕不只是为了账本。”

苏荷心头一跳：“那他……”

“他说‘不需要明白’，你就先装糊涂。”顾长山打断了她，声音里有军人特有的果断，“明天一亮，事情就该见分晓了。现在，送你回去。你一夜没合眼，苏记小馆今天就别开了。”

苏荷张了张嘴，想说“小馆子停一天少一天钱”，但看见沈其昌靠在座椅上，脸色蜡白里透着一层青，她把话咽了回去。

车子停在城南巷口。苏荷下了车，雨已经停了，空气里带着一股洗过的清爽味。她站在巷口，看着吉普车尾灯越来越远，直到消失在街角的拐弯处。

她刚转身，就看见自家小馆门前蹲着一个人。

苏桃抱着膝盖坐在门槛上，脑袋一点一点地打着瞌睡。听见脚步声，她猛地抬起头，眼里一亮：“姐！你可回来了！”

“你怎么在这儿？”苏荷蹲下身，摸了摸她的头发，指尖一阵冰凉，“等了多久？”

苏桃揉了揉眼睛，声音还带着睡意：“下午有人送信来，说是家里捎来的。我不敢替你收，就先看了……姐，是二哥来的。他知不知道你被卖了的事？”

苏荷的手停在半空。

苏桃递过来一张皱巴巴的信纸，上头歪歪扭扭写着几个字——“荷儿，哥处安，勿挂”。

落款处没有名字，只画了一只手。

苏荷捏着信纸，半天没说话。雨水从屋檐上滴下来，在她脚边的青石板上砸出一个小小的凹痕。她仰起头，看着巷口上方那片退了墨的天空。

天要亮了。

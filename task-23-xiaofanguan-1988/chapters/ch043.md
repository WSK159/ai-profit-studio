# 第43章 南下前夜

1988年11月18日，青江的雨下得没完没了。

苏荷站在苏记小馆后厨，面前摊着一张皱巴巴的省商业厅通知。广州美食节，十二月初，名额两个，一个给国营饭店，一个给个体户代表——全省就一个个体户名额，落到她头上。

“这馅饼砸得也太准了。”苏荷把通知翻来覆去看了三遍，指尖敲着桌面，“赵前进那边刚偷走假方子，这边名额就下来。你觉得是巧合？”

顾长山靠在门框上，手里转着一支没点着的烟：“我问过商业厅的老魏，名额是省里定的，个体户代表原本定的是省城‘得意楼’的周胖子。周胖子前三天突然闹肠胃炎住院，临时换的你。”

“周胖子住哪个医院？”

“市二院，消化内科。”

苏荷眯起眼：“我去看他。”

下午两点，苏荷拎着一兜橘子进了市二院。周胖子躺在病床上，脸色蜡黄，见苏荷进来先是一愣，随即脸上浮出那种商人特有的客套笑：“苏老板怎么来了？我这小毛病，还劳你跑一趟。”

苏荷把橘子放床头柜上，拉了把椅子坐下，也不绕弯子：“周老板，您这病来得急，走得也急。广州美食节，听说您去不了了？”

周胖子叹了口气：“谁说不是呢。跑了几年的路子，临门一脚踢不着。医生说我得养半个月——咦。”他突然停住，盯着苏荷看，“苏老板，你接了？”

苏荷点头。

周胖子沉默片刻，忽然笑了，笑里带着点深意：“那苏老板可得留个心眼。这届美食节跟往年不一样。港商、外商、省里的大领导都去，往年去是露脸，今年去，是递投名状。”

“什么投名状？”

“上面要搞餐饮改革试点，谁在美食节上拿头名，谁就能拿到省里第一批‘名店’资格。名店意味着什么？意味着以后机关单位的公务接待，定点采购，首选你。那是稳定的流水，肥得流油的订单。”周胖子压低声音，“苏老板，这馅饼，也是石头。我上个月就收到消息了，本想自己啃，结果——”

他指了指自己的肚子：“赵前进前些天去我店里喝了一顿酒。他请客，我没好意思推。”

苏荷心里一沉，脸上不动声色：“赵老板还关心您身体呢？”

“关心个屁。”周胖子冷笑，“他这是怕我抢名额。把我搞进医院，他再找个由头抢风口？可他没想到，这名额落你头上了。苏老板，你我是同行，但也是青江人。赵前进那人，屁股底下不干净，你小心。”

苏荷离开医院时，雨已经停了。她在街边站了一会儿，把整件事在脑子里过了一遍：赵前进偷走假方子只是第一步，真正的杀招在这里——把人弄下场，自己顶上。但她顶上了，赵前进会甘休？

她刚走到饭馆门口，苏桃就举着一封信冲出来：“姐！广州寄来的！”

苏荷拆开信，纸上只有两行字，落款是“粤海宾馆，刘明义”。

“苏老板，美食节报到日你晚一天来。有人要试你的方子。”

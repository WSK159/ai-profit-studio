# 第325章 瓮中藏味

苏荷没有当场打开陶瓮。她同刘春生将瓮抬出井坑，又原地把土回填，压上那块青石板，收拾得看不出动过的痕迹，才趁夜将陶瓮搬回了城南巷的小馆后院。

已是深夜，灶间灯火通明。苏荷将陶瓮搁在案板上，端详片刻，先用清水洗净瓮身泥迹，又取一把新刀，沿黄泥封口边缘缓缓切了一圈。刘春生守在一旁，手里攥着手电筒，手心全是汗。

“这瓮里到底装的什么？”他又问了一遍。

苏荷换了块干布，擦净瓮口：“你太爷爷那道酥鱼，缺一味关键调料。这调料用寻常法子做不出来，必须把鲜鱼放进陶瓮，灌以活水，以黄泥密封，在井底活水中养上数年——让鱼在水里慢慢化开，渗进每一滴水里，水便有了鱼魂。我前世师父告诉我，古籍上叫‘化味法’，早就失传了。”

刘春生瞪大眼：“那这瓮……”

“你太爷爷逃出城那天，带不走这坛化好的水，只能封进井底。井是他亲手填的，就是为了等有一天有人来取。”

苏荷说着，手上用力，黄泥封口“咔”一声裂开一道缝。一股清冽的香气顿时漫出来——不是腥气，也不是鱼肉味，而是一种极其纯粹的鲜，像是把一条活鱼最精魄的那一缕魂抽出来，化进了凉水里。厨房里三个人同时吸了口气。

苏荷屏息，将瓮盖彻底揭开。

瓮内的水是淡青色的，清澈见底，表面浮着一层极薄的油脂，像月光落在水面上。水中静静躺着几根鱼骨，被水浸得白如玉化，骨头缝里干干净净，没有半分腐肉。那架鱼骨的形状很特别——脊骨笔直，骨节细密，尾椎一分为二，竟是一条近乎整架完整的鱼骨。

刘春生喉咙动了动：“……我太爷爷，他真的把一条鱼养了几十年？”

“不止一条。”苏荷用筷子轻轻拨动水面，底下的骨片散开——竟是三副骨架叠在一起，每副都完整得像标本。更稀奇的是，水底还沉着几枚青黑色的圆石子，只有指甲盖大小，表面布满细密孔洞。

苏桃不知何时凑到了灶间门口，探进半个脑袋：“姐，这水……能闻出点什么？”

苏荷拿筷子尖蘸了一点瓮水，舌尖轻轻一点——

她闭了眼。

那味道在舌尖化开的瞬间，一幕画面忽然撞进脑海：一口青砖老井，井水清冽，一个中年男人蹲在井边，把一条新捞起的活鱼放进陶瓮，用布带扎紧瓮口，回头对身边一个小孩说——“阿狗，记住，这坛水是咱刘家的根。手艺传下去，人味不能丢。”

男人转头，身形消瘦，眉间有颗痣。苏荷猛然睁开眼——她认出那个人。

她前世的师父，灶台上永远挂着一张旧照片。照片里是个老人，穿着民国年间的长衫，站在一家饭馆门前，门口招牌写着“味香居”。老人身后站着一个学徒模样的少年，眉间也有一颗痣。

“这味道……”苏荷喃喃道，“不会错，这是周春浦亲手做的。”

刘春生怔了怔：“周春浦？那不是我太爷爷的本名？”

苏荷转过头：“你说什么？”

“我太爷爷本名刘续德，周春浦是他在城里味香居的化名。”刘春生说，“爷爷说，太爷爷当年替味香居东家做事，才改名换姓。后来出了事，他逃出城，就再没用过那个名字。”

苏荷浑身一震。她前世师父的旧照里，味香居门口站着的那个老人——她的师父曾说过，那人是他入行时的领路人，姓周，是味香居的老东家。“周春浦”这个名字，她听师父提起过无数次，却从不知道这竟是与师父同出一脉的名字。账册上落款“周春浦”，但她师父留下的手抄本里，分明写着“味香居刘记”。

她恍惚间明白了什么——“周春浦”不是人名，是味香居每一代掌灶共用的大号。而她前世师父，正是这“周春浦”一脉最后的传人。

她低头看着瓮中那三副鱼骨，眼眶忽然有些发热。这门手艺，从民国年间传到她手上，中间隔了多少战乱、离散、改名换姓，可味道始终没有断过。

“苏荷姐？”苏桃小声唤她，“这坛水……要怎么存？”

苏荷吸了口气，定了定神：“找一个干净的陶坛，把这瓮水倒进去，扎紧口，放进后院那口井里浸着。活水养着，七日之内用掉，味道才在。”

苏桃应声去了。刘春生站在一旁，张了张嘴，终于问出那个压在心底的问题：“那个账册上，‘刘家酥鱼’后面那页，是被人撕掉的。你知道上面写了什么吗？”

苏荷顿住。她确实不知道。账册到手时，那页便已被人撕去，只余半截毛边参差的裂口。她曾猜测那页是酥鱼配方的核心，直到此刻拿到这瓮水，她才发现，味道还缺一环。

“鱼鲜足了，可还差一味。”

“什么？”

苏荷的视线转向窗外的夜色，青江城的方向：“味香居当年最出名的酥鱼，传闻有一味配料是‘井底藏金’——不是金子的金，而是金桂花的金。桂花入食，提的是香气上那一缕魂。”

她顿了顿：“咱们这瓮水是鱼魂，要想做全当年那道菜，还得找到那株金桂。老账册上写，金桂种在味香居后院东南角，离井三步。”

井。苏荷猛地想起城东周家老宅后院那口被填死的假井——她当时没有撬开，现在想来，那井边三步之内，兴许就埋着那株金桂的根。

她正出神，小馆门外忽然传来脚步声。不是路过，是那种刻意放轻了、停在门口不敲门的脚步声。

刘春生警觉地摸向门闩，苏荷却先一步拦住他。她吹熄了灶台上的油灯，整个后厨忽然坠入黑暗。门缝底下，一道极淡的影子慢慢压过来，紧接着，“笃、笃”，有人用指节叩了两下门，声音很轻，像是怕惊动什么。

“苏老板。”一个男人的声音，低沉，陌生，却带着一种奇怪的熟识感，“你手里的账册，缺的那页，在我这儿。”

苏荷没有应声，手指已经探进袖口，捏住了那根铜钥匙。

“我知道你家灶上有口井。”门外的声音继续道，“我也知道，你今晚刚从刘家塘回来，取了口陶瓮。”他轻笑一声，“明天早上，城南早市，你要是好奇那页纸上写了什么——就一个人来。”

门外响了几下脚步声，那道影子缓缓退了。苏荷仍站在原地，一动不动。

黑暗中，刘春生低声道：“他谁？”

苏荷抬眼，门缝外最后一线天光被屋檐遮住，整条城南巷彻底静了下来。

“一个周家人。”她缓缓道，“或者说……是当年让味香居散掉的那个人。”

# 第60章 暗线浮出

安检的车队开进码头时，张德发的脸已经沉得能拧出水来。他盯着苏荷看了三秒钟，目光像是要把她整个人看穿，最终却只是冷笑一声，转身朝铁皮棚外走去。刘永旺跟在后面，走两步回头看一眼，嘴巴张了张，终是没说出一个字。

苏荷站在原地没动。她看着张德发跨上那辆黑色凤凰自行车，车铃铛在安检人员的注视下叮当一响，消失在码头铁门的拐角。

顾长山从人群中走过来，军便服外套的扣子系得整整齐齐，手里夹着一个蓝色文件夹。他走到苏荷面前，压低声音：“他说了什么？”

“没说什么。”苏荷低头看了看自己的手，指尖还在微微发颤，但她把双手拢进外套口袋里，“他比我稳。张德发这种人是滚过刀尖的，不是吓一吓就能撂话的。”

顾长山点点头，环视了一圈正忙着开箱检查的安检队伍，然后朝路边努了努嘴：“走吧，车在门口。”

苏荷跟着他走到码头大门外，一辆墨绿色的吉普车停在槐树下。1988年，这种车只有机关单位才开得起。顾长山拉开车门让她坐上副驾驶，自己绕过车头上车，发动引擎之后，车轮碾着地面积水开出巷子，在青江老城区沿江路兜了半个圈子，确认没有尾巴了，他才停在一个公共澡堂背后的小巷里。

他熄了火，从怀里掏出一张纸递给苏荷。

苏荷接过来，展开一看，是一张手写的流水明细——日期、货柜编号、封条更换记录、进出的车辆牌号。字迹工整得像印刷体，一看就是顾长山的手笔，部队里练出来的那种一板一眼。

“这是码头内部调度室的登记本抄录。”顾长山伸手指了指中间一行，“三号货柜，上周五入港，申报的是铁皮罐头。但调度室的老周跟我说，这个柜子进港的时候，叉车师傅觉得分量不对，足足比申报单上轻了两百多斤。”

苏荷的手指停在那一行字上，指腹摩挲着粗糙的纸张，脑子里飞快地转着一个念头。张德发的“罐头”，比申报的重量轻。可她抬那罐子的时候，沉得像灌了铅。

“两本账。”她说。

顾长山偏头看她：“什么？”

“明账、暗账。”苏荷抬起头，眼睛里有东西亮起来，“他们申报给海关的是一批罐头，实际装进柜子里的也是罐头。但中间那几箱——就是刘永旺当天搬的那种——是用另一种封法封的。”她顿了顿，伸出一根手指在空气中画了个方框，“如果是肉，不可能比申报少两百斤。只有一种东西又轻、又值钱、还见不得光，需要用铁皮罐头做壳。”

顾长山沉默了片刻，声音放得更低：“你是说，里面是药？”

“张德发跟红旗制药厂的关系，你查到了什么？”

顾长山从文件夹里抽出一张名片，递过去。名片是暗红色的，上面用烫金印着“红旗制药厂供销科科长 周建国”一行字，下面还有一行小字：经营范围——中药材、保健品原料、白糖、食用油脂。

苏荷盯着那行“白糖食用油脂”看了好几秒，忽然说：“长山，你吃过白糖炖鸡蛋吗？”

顾长山一愣：“什么意思？”

“我外婆以前跟我说，老时候有些走偏门的人，收鸡蛋不是拿去卖，是把鸡蛋里的清和黄抽出来，灌上别的东西再糊回去。外面看着是蛋，里面就不是了。”苏荷把名片收进口袋，声音很稳，“张德发的手法是金蝉脱壳——罐头壳是真的，里面的东西换了。”

她刚要再说什么，眼角余光忽然扫到街对面电线杆后面一个熟悉的身影。她猛地扭过头，目光穿过车窗玻璃，看见一个穿白衬衫的男人站在报摊旁边，手里举着一份《青江日报》遮住半张脸，但那件白衬衫——袖口挽到小臂中段，露出手腕上一块黑色电子表——跟她上次在食品厂门口见到的一模一样。

她的心跳漏了半拍。

“长山，”她声音压低下去，“你左边后视镜，报摊那边。那人跟了我们多久？”

顾长山的目光不动声色地往后视镜里落了落，手搁在方向盘上，食指无声地敲了两下。半晌，他说：“从城南巷口一直跟到这里。”顿了顿，又补了一句，“昨晚我就见过他，蹲在馆子对面喝了一晚上粥。”

苏荷吸了口气。

白衬衫——那个在食品厂配方失窃那晚，站在马路对面看了整场热闹的男人。他一直都没走远，一直在她附近打转。

“你今晚还回馆子吗？”顾长山问。

“回。”苏荷拉开车门，回头看他一眼，“你帮我把他盯住了。这个人比张德发危险，他到现在都没出过手，才说明要干的事大。”

她下了车，带上车门，沿着巷子走了两步，又停住脚。她没有回头，声音在风里飘过来：“对了，长山，你帮我查一件事——红旗制药厂的供销科主任，跟省城那家要开美食节的主办方，有没有来往。”

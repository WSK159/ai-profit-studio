# 第442章 血指印与十八页

缸盖被彻底掀开的那一瞬，院子里忽然起了一阵穿堂风。风从巷口灌进来，卷着初秋的落叶打在缸沿上，把那根系着红绳的铜铃吹得轻轻晃荡，发出细碎的响。

苏荷蹲在缸边，盯着那只苍白的手。

指尖已经因为长期浸泡而发皱泛白，但指甲修剪得极齐整——一个在缸里活了这么多年的人，居然还保持着这样的体面。红绳铜铃缠在手腕上，绳结是老式的水手扣，她前世在师父的旧工具箱里见过这种绳法。

缸里的人动了。

先是手指微微蜷曲，然后整条手臂缓慢地缩回缸内。紧接着，苏荷听见缸底传来一阵水声，混着一声极长的、带着痰音的吐息。

“问味……”缸里的人说话很慢，像是每吐一个字都要消耗极大气力，“谁家孩子，带着问味铜片……到我面前来。”

顾长山一步跨到苏荷身前，右手已经按在腰间。苏荷按住他的手臂，摇了摇头，自己往前走了两步。

她解下腰间那片从不离身的铜片——那是师父临终前挂在她脖子上的，说她带着这东西，到了青江但凡遇见道上的人，能保她平安。铜片正面铸着一只三足鼎，鼎下是一缕上升的烟气，背面刻着“问味”两个古篆。

她把铜片举到缸口上方。月色照下来，铜面泛着一层幽暗的光。

缸里的人沉默了片刻，然后笑了。那笑声干涩嘶哑，像枯木断裂：“果真是自家孩子……三十年了，头一回闻见这味道。”

“您是钟九指？”苏荷直接问。

缸内又是一阵沉默。半晌，一只手从缸沿探出来，慢慢地、吃力地搭在缸壁上，带动水声哗啦。一个脑袋从缸口探出——花白的头发湿漉漉地贴着头皮，面容枯槁，左眼似乎已经瞎了，眼皮塌陷，只有右眼还透着一点光。

他年纪约莫六十上下，但看上去像八十岁的人。最醒目的是他的右手——小指齐齐断去，断口处结成暗红色的疤。

“钟九指是我。”他慢吞吞地开口，“你认得我？”

“我师父认得您。”苏荷说，“他让我到了青江，若有缘分，替他去看看一位老友。”

钟九指那只独眼忽然亮了一下：“你师父……姓甚名谁？”

苏荷正要开口，钟九指却忽然抬手制止了她。他的目光越过苏荷，落在她身后的乔春海身上，随即瞳孔一缩。

“你……”

乔春海站在院门口，月光把他的影子拉得很长。他脸上的表情极其复杂，嘴唇嚅动了一下，才低声道：“钟师兄……是我。”

钟九指盯着他看了很久，忽然发出一声冷笑：“乔春海……你改了名字，换了面孔，连这道门都多年不敢进。今儿怎么敢来了？”

“我来问一件事。”乔春海的声音有些发紧，“当年我弟弟乔春江，究竟被换去了哪条船？”

院里的风忽然停了。

钟九指沉默着，那只独眼一眨不眨地注视乔春海。不知过了多久，他缓缓抬起那只缺了小指的手，从怀里摸出一张泛黄的纸。

那纸被油布裹了几层，打开时依然完整。纸上密密麻麻写满了字，最下方有一枚暗红色的血指印，按在签名处——那签名赫然是“乔春海”三个字。

“这是账本被撕掉的那一页。”钟九指将纸递向苏荷，“你师父当年让我保存的东西，说将来若有人带着问味铜片来，就把这一页交出去。”

苏荷接过来。月光下，她看清了那页纸上记载的内容：一排排密密麻麻的缸号、日期、押船人，最末尾一行写着——“庚午年青江沉船，缸沉二十有三，存人者存命。”下面是一枚血指印。

而那一行的押船人栏里，写的却是另一个名字：乔春江。

乔春海的目光死死钉在那三个字上，声音像从牙缝里挤出来的：“我弟弟……最后押的是这一船？”

钟九指没有直接回答。他的目光望向院墙外的方向，那里是青江的河道，夜里水面泛着一层幽暗的光。

“你弟弟当年押的船，没沉。”他一字一句地说，“船被人凿了，货被人换了，人被带走了。”

“被谁带走？”

钟九指收回目光，看着乔春海，忽然咧嘴笑了。他的牙泛着黄，笑容里带着一种说不出的残酷：“你心里不是已经有答案了么？这些年在道上盘来盘去，你查到的每一根线头，最后都指向同一个人——你拜过的那座码头。”

乔春海脸色骤白。

苏荷站在两人中间，低头看着手里的十八页。她注意到一个细节：在最末尾的血指印旁边，还有一行极细的字，被人用指甲刻上去的，笔画歪歪扭扭——像是一个人在极度匆忙中留下的。那几个字是：

“梅香在此。”

她心头猛地一跳。梅香——这不是师父在信里提过的那艘老船的名字么？那艘据说是庚午年前最后一次跑青江线的盐船？

她刚要细看，手里的纸忽然被一阵风卷起。她连忙按住，却见钟九指的神色变了——他那只独眼盯着苏荷脚下的地面，像看见了什么极其骇人的东西。

“你……”他声音发颤，“你脚上的鞋，哪来的？”

苏荷低头，看向自己脚上那双布鞋。那是临出门时苏桃硬给她换上的，说是新买的千层底。

“我妹妹买的。”

钟九指的脸色很难看。他张了张嘴，像是想说什么，却又咽了回去，只哑声道：“你妹妹……可知道你师父叫什么？”

这一句话让苏荷心沉了一下。她想了想，如实道：“她不知道。”

钟九指缓缓吐出一口气：“那就好。你回去告诉你妹妹，那双鞋……以后别穿了。”

他说完，整个人往缸里缩回去，像耗尽了所有气力：“你们走吧。该说的我说了，不该说的——也说了不该说的。再不走，天亮了就来不及了。”

院子外，远处传来一声鸡啼，天边泛起一线灰白。

苏荷看了看缸里那道蜷缩的人影，又看了看面如死灰的乔春海，最后与顾长山交换了一个眼神。她默默将十八页纸折好放入怀中：“九指前辈，下回我再来看您。”

缸里没有回应。

三人转身往外走，刚走到院门口，苏荷忽然听见身后传来钟九指极低极轻的一句话，轻得像一片叶子落进水面：

“你师父……当年没死透。”

苏荷猛地回头，却只看见钟九指那枯槁的身影已经沉入缸底，水面上只剩一圈涟漪，和那枚红绳铜铃，在微光里晃荡着。

# 第133章 一口老碑

茶馆里的煤油灯“噼啪”炸了一下，光晕晃了晃。苏荷盯着对面这张皱纹纵横的脸，忽然觉得眉心发紧。

“您说赵一鸣三十年前就死了。”她语气平缓，“可这封信，如果是师父写给赵一鸣的，为什么会到您手上？”

老人伸出枯瘦的手，把木珠串拉到跟前，一颗一颗捻过，半晌才开口：“小子，你师父沈国章，一共收了两个正式弟子。头一个就是赵一鸣，1949年那会儿，他十九岁，是从枪杆子里爬出来的伙夫兵，一口锅就是一条命。国章在南下路上捡到他，教了他三年灶上功夫，后来部队整编，两人各奔东西。”

他顿了顿，目光落在那张照片上：“赵一鸣后来去了蓉城，在国营饭店掌勺。1982年，他因为一件事被判刑——‘投机倒把，倒卖粮食配额’，五年刑期。他在牢里待了两年，病死了。给他收尸的，是他弟弟，也就是我。”

苏荷听着，心里像被人伸手抓了一把。她前世在师父手底下学艺五年，从没见过师父提“赵一鸣”三个字。师父那人看上去豁达，骨子里却藏着一个坑，谁也不敢碰。

“我哥死前，托人把一封信转给我，让我务必寻到沈国章，把这封信交到他手上。”老人从怀里掏出一个牛皮纸信封，封口用火漆封死了，漆色暗红，干透了，“我找了我哥的旧部属，辗转三年，才在1985年找到沈国章——那时候他在青江城外烧窑，改名叫沈石，谁也不认。”

“但你说他‘打开了第三口樟木箱’。”苏荷盯着他，“你见过他？”

老人沉默了一会儿，缓缓点头：“1986年冬天，我在城南巷后街见过他一面。他那时候已经知道自己撑不了多久了，把三口樟木箱封好，留在老宅里。他当着我面打开了第三口箱子——里边没有金银，只有一本手抄菜谱、一张地契，和这个。”他指了指苏荷手腕上的木珠，“他说这是信物。如果有一天，有个姓苏的姑娘拿着木珠来找我，让我把这封信交出去。你师父只提了一个条件——”

“什么条件？”

“让他看一眼苏记小馆的匾额。他说他这辈子没有亲笔写过第二块招牌，那两个字，是留给你将来的。”

苏荷站在茶馆昏暗的灯光里，忽然觉得眼窝发酸。她前世见过师父写字，一只手抖得厉害，可下笔极稳。师父有个怪癖——他从不给别人题字，逢年过节被人请去写春联，他也一概推辞。只有一次，苏荷刚拿到米其林的证，师父破天荒给她写了一幅字：“一日三餐，煎炒烹炸，皆是修行。”她后来把那幅字挂在后厨，炒菜时抬头就能看见。

如今才明白，师父不是不给人题字，是那个叫“沈国章”的名字，他再也不想用了。

“你师父让我把信交给你。”老人的声音把她拉回来，“他说，等你看完这封信，就会明白——第三口樟木箱里那本地契，为什么写的是你的名字。”

苏荷接过信封，指尖触到火漆上的凹凸纹路，心跳得极快。她没有当场拆开，而是把信封仔细收到衣服内袋里，又抬手把那串木珠褪下来，郑重地放回老人掌心：“您把这封信交给了我，可木珠我不能带。赵一鸣先生生前没等到的东西，我不能替他拿走。”

老人怔了一下，低头看着掌心的木珠，沉默良久，忽然笑了：“好，好。你比你师父明白事理。”他把木珠重新系回自己手腕上，站起身来，朝苏荷拱了拱手，“你苏记开张那日，若我还在青江，一定去讨一碗红油抄手。”

他话音落下，人已撩开棉门帘踏入暮色，身影很快消失在巷口。苏荷站在原地，手指隔着衣服捏着那封信的轮廓，指尖传来火漆微微凸起的纹路——像一颗心被封印了很久，终于在等一个人来拆开。

顾长山从槐树后闪出来，看她脸色发白，皱了皱眉：“出什么事了？”

苏荷把那封信在手中握紧，半晌才说：“长山，我师父留给我的，可能不只是菜谱。如果那本地契上真的是我的名字——那城南巷这几十间破房子，怕是要落在别人眼里的肉，早已是我的了。”

夜风从巷子里穿堂而过，吹得茶馆门口的棉帘子“啪啪”作响。远处隐约传来几声狗吠，再远一点，有火车鸣笛的声音。

1988年的风正往北吹，而苏荷口袋里的那封信，像一枚埋了三十年的种子，正等着春天的土地破开。

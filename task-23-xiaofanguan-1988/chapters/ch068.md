# 第68章 深夜来客

凌晨两点，城南巷的灯火全灭了。苏荷坐在灶台边，借着煤炉里最后一点红光，一遍一遍擦那柄剔骨刀。刀身映出她的脸，十八岁的壳子里装着一副熬过无数后厨夜班的老骨头。

张德发的事没完。她心里清楚，那人绝不会因为白天码头那一场对峙就善罢甘休。干贝粉的事是一层帘子，帘子后面藏着什么，她还看不到底。

门外忽然响起三声敲门声——不重，却极有节奏。苏荷握刀的手一紧，抬眼望向门板。深更半夜，能来敲这扇门的不是街坊，更不会是张德发的人。

“谁？”

“小苏师傅，讨碗热汤喝。”声音低哑，带着一口浓重的南方口音。

苏荷皱眉。这声音她没听过，但“小苏师傅”这个称呼，只有这几天来店里吃过饭的人才会叫。她拉开门闩，门缝里探进一盏煤油灯的光，照在来人脸上——五六十岁的老头，穿一身洗得发白的藏蓝中山装，脸上的皱纹深得像刀刻的。

“是你。”苏荷认出这就是白天码头那个人。

老头点点头，不请自进，在桌边坐下，目光扫过灶台上那几个坛坛罐罐，最终落在那口铁锅上。眼神在那一瞬变得很复杂，像翻过了一座山。

“老伯，深更半夜的，有话直说。”苏荷没有落座，站在灶台边，手里的刀没搁下。

老头没有接话，从怀里摸出一个布包，一层一层打开。苏荷闻到味道的一瞬间，瞳孔微微一缩——那是发酵过的豆豉，但跟她见过的任何豆豉都不同，里头掺着某种陈年的异香，像是药，又像是酒。布包正中躺着一颗青瓷瓶，巴掌大，瓶口用蜡封得严严实实。

“白天在码头，你从罐底刮出干贝粉的时候，我就知道你不是一般人。”老头把青瓷瓶推到她面前，“这瓶东西，是有人托我带给你的。那人说，等你到了青江，等到城南巷口那盏灯亮了，就把它交给你。”

苏荷盯着那只青瓷瓶，心跳漏了半拍。她前世在东山学艺的时候，师父有一句话常挂在嘴边：“天下调料三千味，有一味在青瓷里头。”她后来找了很多年，都没找到师父说的“那一味”。

现在，这瓶子就搁在她面前。她的手伸出去，却在半空停住了。

“谁托你带来的？”

老头嘴角动了动，露出一个意味深长的笑：“那人说，你见了瓶子，自然知道他是谁。”

苏荷缓缓拿起青瓷瓶，指尖触到蜡封的纹路。那蜡封上用指甲压刻着一道极细的弯月——那是她前世师父的习惯，他封每一坛酱料，都会在蜡上压一道弯月。

她前世师父三年前就走了。而现在是1988年，在这个时代，那个人应该还活着。

“他在哪？”苏荷的声音有点发抖。

老头却站了起来，拍了拍裤子上的灰：“话带到了，东西也带到了。我该走了。”

“等等——”苏荷拦住他，“你从哪来？”

老头走到门口，回过头来：“我从该来的地方来。小苏师傅，锅里的汤快烧干了。”

他指了指灶台，推门没入夜色。等苏荷追出去，巷子里空荡荡的，连脚步声都听不见，只有远处传来一声水鸟的啼叫。

苏荷回到屋里，灶台上的汤果然烧干了——可她明明没有在煮汤。她揭开锅盖，锅底干干净净，却贴着一片薄薄的锡箔纸，上面用钢针刻着一行小字：“五日之内，勿碰南货。”

她把锡箔纸握在手心，捏成一团。然后把那只青瓷瓶塞进怀里最深的地方，关灯上了楼。

躺下之后，她听见楼下传来极轻的动静——有人在翻窗。苏荷没有起身，伸手摸到枕头底下的刀，嘴角微微扬起来。

果然来了。

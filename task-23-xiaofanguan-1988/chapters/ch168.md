# 第168章 一碗雪羹定师徒

唐老头话音刚落，院子里的空气仿佛凝住了。刚才还在交头接耳的街坊邻居，一个个张着嘴半天合不拢。

“唐…唐老爷子？”隔壁卖豆腐的刘婶揉揉眼睛，“您说啥呢？就您这天天蹲在巷口下棋、连买碗抄手都要掰着手指算钱的老头儿，要收她做徒弟？”

苏荷也愣住了。她盯着面前这个穿着灰布旧衫、脚踩一双补丁布鞋的老头，脑海里翻江倒海。

这半个月，唐老头几乎每天中午都要来铺子里吃一碗红油抄手。每次都是坐在角落那张缺了一条腿、靠砖头垫着的桌子边上，慢悠悠地吃，一碗抄手能吃一个钟头。苏荷只当他是附近退了休的孤寡老人，从来没多想过。

可他方才说——他是蒋老哥的同门？

苏荷心跳猛然加速。前世师父蒋承恩临终前攥着她的手，断断续续说到过《雪羹诀》里有道雪羹，是当年他同门师弟唐楼的绝活。两人同拜一师，后来因为对火候的理念不合，各奔东西，四十年未曾再见。

“丫头，”唐老头把手里那碗白瓷碗放在灶台上，“你可知这道雪羹是何物？”

苏荷喉头微动，低声道：“雪羹者，以雪花鱼片为主料，配以极冷之清汤浇淋，入口如雪化，回甘似春融。讲究的是‘冰火相济、一瞬即成’。”

唐老头眼中精光一闪，原本佝偻的腰杆不由自主地挺直了几分。他看了苏荷半晌，忽而笑起来：“好，好！你既有此见识，我便今日考你一考。你若有本事，做出一碗像样的雪羹来，我便当着众人的面，把《雪羹诀》的交底指法传给你。”

围观的人群一下子骚动起来。有人起哄道：“苏老板，露一手！让咱看看热闹！”也有小声嘀咕的：“这唐老头是不是魔怔了？大冬天的做啥雪羹？”

苏荷深吸一口气。她知道，这是机会。若能得到唐楼真传，苏记的手艺便有了正式的渊源，上辈子蒋师父遗憾至死都未能再见到这个师弟，她前世曾见蒋师父做过一次雪羹，全部技法都在她记忆里——那是师父酒后撒疯时才肯露的一手。

她抬头看了唐老头一眼：“唐爷，您这儿有鱼吗？”

“巷口那家杂货铺今早刚进了几尾江鲤，我已然买了两条，搁在井水盆里镇着呢。”唐老头慢悠悠地指了指后院，“灶就使你的灶，柴就使你的柴，调料也各取所需。我只在这等半个时辰。”他说完，便搬了张凳子坐到门槛上，当真闭目养神起来。

苏荷二话不说，转身去了后院。她蹲在井台边上，手伸进冰凉的井水，够到一条江鲤。鱼身大约一斤二两，脊背乌青、腹部银白，鳞片紧实，是上好的货色。她拎起来，拇指在鱼头两侧各按了一下，力道不轻不重——这是蒋家秘传的“活杀法”，既不让鱼挣扎太久影响肉质，又能在极短的时间里放干净血水。

她忽然感觉到后脑勺有什么目光。回头，看见唐老头不知什么时候睁了眼，正一眨不眨地盯着她，眼神复杂得像深潭里的暗流。

苏荷不动声色，继续手上的活儿。她刀工极快，前后不到三分钟，一条江鲤已经成了两片完整的鱼肉。她取一条鱼脊，将鱼肉切成极薄的片，每个切片大小均匀、厚薄几乎一致，一片片铺在青瓷盘里，像铺开的白绸。

然后，她用清水将鱼肉片冲洗三遍，去尽腥味，又裹上一层薄薄的蛋清和淀粉浆备用。

灶台的铁锅里，早烧着水。苏荷今日熬的鸡架汤还剩下半锅，她加了葱段和姜片，把汤煮得滚沸。

接下来是关键——雪羹的“雪”字在于汤。热汤浇到生鱼肉片上，瞬间烫熟，锁住鲜甜。但若汤温不够，鱼肉半生不熟；若汤温过盛，鱼肉老如柴皮。

苏荷闭了一下眼，前世师父做雪羹的画面在脑中回闪——三成沸、七成静，悬壶高冲、快入快出。她猛地睁眼，一手端汤、一手持勺，将滚汤从高处冲入青瓷盘。

白色蒸汽“蓬”地一下腾起，整间小饭馆弥漫开一股清甜鲜润的香气。汤落在鱼片上那一刻，鱼片从外向内卷起，白如初雪，晶莹透亮，上面浮着丝丝翠绿的葱花、还有苏荷意外撒上去的几粒红枸杞——红白绿三色错落，像一幅画。

“成了。”苏荷端着青瓷盘放到唐老头面前，顺便递上一双竹筷。

唐老头接过筷子，夹起一片鱼肉送入口中。他的嚼了几下，眉头微动，又夹起第二片，这回慢慢品。等他放下筷子的时候，眼角竟然有些泛红。

他沉默了好一会儿，才抬起头来，声音比之前低了三分：“……你这一手，是他教你的？”

苏荷没回避：“蒋师父临终前传的。”

在场众人谁也没听懂。但唐老头听懂了。他缓缓站起来，背过身去，肩膀轻轻耸动了一下。等再转回来时，他的脸已经恢复了平日的淡漠，只不过那双眼睛里多了些旁人看不懂的情绪。

他摸了摸怀里那本薄薄的油纸包，又看了看苏荷，开口：“丫头，从今天起，你是我唐楼名下唯一的徒弟。《雪羹诀》三门指法、七种火候、二十四道配汤，一样一样传给你。但凡苏记挂一天招牌，你就得把这门手艺做正了。”

说完，他从怀里掏出油纸包，当着众人的面层层打开——里面是一本边角泛卷、纸页泛黄的手抄册子，封面用毛笔写了三个瘦金体大字：

雪羹诀。

他刚把册子递到苏荷手里，巷口忽然传来一阵急促的脚步声。一个穿蓝衣服的邮差喘着气跑进来，手里举着一封牛皮纸信封：“苏老板！苏记小馆的苏荷！省城来的挂号信！”

苏荷接过信，撕开一看，脸色骤变。

信封里是一张法院传票——苏记小馆因“商标侵权”，被省城一家名叫“苏记老味”的餐饮公司告上了法庭。落款日期是五天后。

围观人群顿时炸开了锅。唐老头眯了眯眼，把信纸拿过来看了一眼，冷笑一声：“来得倒快。”

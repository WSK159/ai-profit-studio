# 第100章 夜探酱菜铺

青江码头，凌晨四点半。

苏荷把最后一口干粮咽下去，拍掉手上的饼渣，目光落在文昌街的方向。顾长山蹲在货堆旁，把运煤船上的缆绳又紧了紧，压低了声音：“那两个人还在。”

“知道。”苏荷没回头，“从昨天下船就跟到现在的，一共仨，换过一班。俩在码头斜对面那个修鞋摊，一个在酱油铺子里。”

顾长山眉头拧起来：“你打算怎么办？”

苏荷笑了一下：“既然他们想跟着，就让他们跟。我去师祖那儿把话传完，该处理的处理了，然后咱们带他们逛一天省城。”

“你疯了？”

“没疯。”苏荷目色沉静，“他们跟了一天，什么都没摸到。眼下赵家刚被查，盯我的人不敢动手，最多是记我去了哪儿。咱们只要不往师祖那儿去，他们跟到天黑也是个空。等夜里，再去一趟。”

顾长山沉默片刻，点头：“行，我打着你去逛省城百货的幌子，把他们都引开。”

苏荷心里一暖，没多说什么。她起身拍了拍裤腿，朝码头方向走去。

省城确实比青江大了不止一圈。百货大楼三层高，玻璃橱窗里摆着从上海运来的的确良衬衫，五颜六色的。苏荷在食品柜台前站了站，拎了一斤桃酥一包话梅，又去布匹柜台扯了两尺蓝底白花棉布——店里大喇叭正播着“改革开放好，生活步步高”的广播，人群热腾腾的。那俩盯梢的扮成顾客，在她后面两米处佯装看柜台，演技拙劣得很。

苏荷看得心里好笑，面上却不动声色，带着顾长山从百货公司一楼逛到三楼，再从后门出去，绕进一条菜市街，看人杀鱼砍肉，又蹲在一个卖糖炒栗子的摊子前吃了半斤栗子。

等天擦黑，她回头一望——三条尾巴还剩一条，那个酱油铺子里的中年男人还在远处屋檐下蹲着抽烟，眼神往这边瞟。

“差不多了。”苏荷低声道。

顾长山会意，一抬下巴：“那边有个公共澡堂，我在里头泡个澡，把他拖住。你办完事，咱们在昨晚那棵老槐树底下碰头。”

苏荷点头，拐进一条窄巷，三两拐弯便甩掉了那最后一道视线。

夜色压下来，省城的街灯稀稀拉拉亮着，文昌街七十八号的铺板门缝里透出一线油灯昏黄的光。

苏荷没有直接敲门。她退后两步，数了数墙根下码着的酱缸——十七只，和昨天来的时候一样，但最靠里的那一只缸盖换了。昨天还是竹编的，今天是个木盖子，边缘糊了新泥。

她心里一动，绕到后院墙根，果然发现墙头靠着一架竹梯。苏荷踩着梯子翻进院墙，落地时几乎没有声音。酱菜铺的后院不大，晾着一排待晒的萝卜干和雪里蕻，空气里全是酱香和咸味。

正屋的窗户透出光，里头有人说话。

苏荷贴着墙根靠过去，听见一个苍老的嗓音——正是师祖沈其昌：“……王家的手伸得比我想的长。赵家那边刚被查，青江那边就有人跟到省城来，昨天来的那个女娃娃，怕也被人盯上了。”

另一个声音年轻一些，带着浓重的北地口音：“师父，那您说周诚师兄的事——”

“嘘。”

屋里忽然静了。

苏荷的心提了起来，周诚——是师父的名字！她屏住呼吸，听见沈其昌压低了嗓音：“这事儿不能在这儿说。风声紧，墙外有耳。”

“可是师父，周诚师兄两年没露面了，万一他——”

“我说了，不能说。”沈其昌的声气里带着几分沉重，“你回去吧，等我话。记住，这两日不管是谁来问，你只说不知道。”

屋里的年轻人应了一声，脚步声朝前门方向去了。苏荷贴着墙根往暗处退了退，等人走远了，才绕到正屋门口，不轻不重地叩了三下门。

屋里沉默片刻，随即门闩响动，沈其昌的脸出现在门缝里——一张沟壑纵横的老脸，眼睛却锐利得像鹰。

“进来。”

苏荷侧身闪进屋里。沈其昌关好门，手掌在油灯上拢了拢，灯芯“噗”地跳了一下，窜高一截。他上下打量苏荷一眼：“尾巴甩干净了？”

苏荷点头：“甩了。”

沈其昌没再问，他转身从床头柜最底层摸出一个油纸包，递给苏荷：“这个你带走。”

苏荷接过来，拆开一角——里面是一张泛黄的收据，上面写着“兹收到青江市机关食堂大米一千五百斤，经办人：王某”，落款日期是1964年三月。

苏荷瞳孔一缩。

一千五百斤大米，和账本上那个差额，对上了。

“王——是王家的人？”她问。

沈其昌没答，却说了另一句话：“你师父没失踪。他在查一件事，查到一半被人发现了，眼下不知躲去了哪里。你记住，他手里有半本账，和这本对得上。”

苏荷的手攥紧了那张收据：“半本账在哪？”

沈其昌刚要开口，门外忽然传来“笃笃笃”三声短促的敲门声——节奏急促，像是暗号。沈其昌脸色一变，一把将油灯吹灭：“后窗，走！”

苏荷没有犹豫，把收据贴身藏好，跃上后窗台翻出去，脚尖落地时听见前门传来一个陌生的声音——“沈老，王家请您去喝茶。”

苏荷咬咬牙，再无半分犹豫，穿过酱缸阵，从后院翻墙而出，贴着墙角一路疾行。头顶的月光被云遮住，她不回头，一路奔到了老槐树下。

顾长山已然等在那儿，见她脸色不对，什么都没问，只把外衣往她肩上一搭：“走。”

两人拐进城北的旅店，关上门后，苏荷才把那张收据掏出来搁在油灯下。她盯着那行字看了很久，终于开口：“1964年，青江机关食堂往省城运了一千五百斤大米，经手人姓王。收据在师祖手里，说明这笔米没走正经渠道。而账本上同年三月刚好有一笔大额结余被人涂改过——正好合上了。”

顾长山沉默一会儿，问：“你打算怎么办？”

苏荷把收据折好收进口袋，目光落在窗外黑洞洞的夜色里：“找师父。如果有人在找那半本账，那他一定也在等有人接应。而我手里这本，就是他的护身符。”

窗外忽然响起一阵脚步声，越来越近，旋即停在门口——有人在她门外敲了两下。

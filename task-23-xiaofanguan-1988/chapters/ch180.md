# 第180章 仓库夜话

苏荷回来时，马灯的光已经把铺子门前照出一片暖黄。苏桃蹲在门槛上，手里攥着一根铅笔头，膝头摊着半本作业本。

“姐！”她腾地站起来，“你这一走就是三天！”

“事情办完了。”苏荷放下肩上的布包，摸了摸妹妹的头发，“饿不饿？我给你下碗面。”

苏桃摇头，眼睛却往她身后瞅：“顾大哥呢？还有老陆叔？”

“车停在巷口，他俩把东西搬进后院。”苏荷走进灶间，从碗柜最里层摸出两个鸡蛋，“先吃口热乎的，待会儿还得盘货。”

面下到锅里的时候，顾长山大踏步进了门，老陆跟在后头，两口子（老陆和他媳妇）没来，只有老陆一人。他脸上汗津津的，袖口挽到肘上：“苏老板，三十捆橡胶管，根根都验过了，表皮抹了油，也拿火燎过——烧不着，不是偷工减料的东西。”

顾长山补了一句：“就是型号老，市面上现在不兴这种粗管，可要说耐用，它比新货强。”

苏荷点头，把面盛出来，又泼了一勺红油：“先吃。吃完再说。”

三个人就着灶台的油灯，稀里呼噜吃完面。苏桃已经趴在饭桌上睡着了，铅笔头滚落在地。

苏荷放下碗，压低声音：“老陆，你知道城南这一片，谁家修农机？”

老陆抹抹嘴：“你要出手这批管子？”

“不急着出手。”苏荷笑了笑，“我问你，市郊那些承包了鱼塘的人，鱼塘换水用的管子，用的是什么？”

老陆一愣：“那都是供销社买了卷起来用的……有的用竹筒接，有的用胶皮管。可你要说胶皮管，城东农机站前年进过一批，早磨穿了。”

“城南农机站呢？”

“城南……别提了，去年精简人员，站里就剩一个老技术员和一台拖拉机，那拖拉机有半年没响了，说是水箱裂了，没人会补。”

苏荷指尖在桌面上轻轻叩了两下，嘴角微微挑起。

“三日后，你帮我跑一趟城南农机站，就说有人手里有一批能修的橡胶管，型号旧些，但能当水管用。价格，比供销社便宜四成。”

老陆挠头：“那老技术员姓董，倔得很，怕是看不上你这‘旧货’。”

“旧货？”苏荷含笑道，“你告诉他，管子是利民橡胶厂的老库存，当年建厂第一批货。他要是懂行，就该知道——那批货里掺了南韩进口的原料，比后来的新货耐磨一倍。”

老陆眼神亮了：“真有这事儿？”

“干过橡胶厂的都知道。”苏荷眼底有些深意，“我前世……听人讲过。”

顾长山没搭话，只是看了苏荷一眼，目光里有种说不清的东西。她有时候像是能把未来两年物价走势和货源全装在脑子里，有时候又像是凭空捏出些“内情”来。他不是没见过聪明人，可苏荷这种聪明，像是踩在另一条时间线上。

可他最终只是说：“明早我去码头，把何承业那边第二批货的底细摸清楚。李兆阳手里那十捆，既然没散出去，等他急了自然会放价。”

苏荷嗯了一声，转头对老陆道：“你把三轮车后斗用油布盖上，明早咱们先不去农机站——先去一趟周福安的铺子。”

老陆一怔：“周老板？他不是说城南巷七号明年要动迁嘛，你还跟他打交道？”

“正因为要动迁。”苏荷眼里有光，“他既然主动递话来，说明他心里有算盘。我今儿买货这三百五十块，他多半已经知道了。做生意，最怕的不是有人盯着你，而是你不知道谁在盯你。”

夜风从门缝灌进来，马灯的火苗摇了一下。苏桃翻了个身，含糊地嘟囔了一声“姐”。

苏荷熄了灶火：“老陆，你今晚睡后院柴房，长山，你回街道办宿舍吧——明早七点，周福安铺子门口见。”

顾长山走到门口，又折回来，压低声音：“李兆阳今天被你堵了一回，他那人记仇。你这两天出摊，小心些。”

“他敢来，”苏荷解开围裙，露出灶台后墙上那把擦得锃亮的菜刀，“我就让他尝尝1988年的红油有多烫。”

顾长山沉默两秒，没忍住，嘴角勾了一下，转身走进夜色里。苏荷没看见，但灶台上那碗碗底的油光里，映出她自己也弯了一下眼睛。

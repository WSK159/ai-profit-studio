# 第39章 左手字

城南巷的清晨来得早，五点刚过，巷口的豆浆铺已经冒了白汽。苏荷站在苏记小馆二楼的窗边，手里捏着那张皱巴巴的纸条，看了第三遍。

“城南面粉”——四个字歪歪扭扭，横撇竖捺全都往左边倒，像是用左手写出来的一样。她前世在后厨带过二十几个徒弟，见过各种笔迹，唯独这种写法的，她只在一个人身上见过。

那人现在正坐在楼下灶间门口。杨大海搬了张小凳，双手搁在膝盖上，像棵蔫了吧唧的白菜。自打他投了诚，苏荷就让他暂时管着灶间杂务。昨晚上苏桃把账目重新盘了一遍，发现三笔出库记录全是在杨大海休班的日子，正好卡在翠兰值夜那几天。

赵前进选的棋子倒是精准，专挑最不起眼的人下手。

“姐，赵前进那边有动静。”苏桃推门进来，怀里抱着账本，头发扎成两条辫子，“我托振华哥帮忙盯了两天，赵记饭馆后门昨天半夜卸了一车面袋子，跟城南面粉铺的包一模一样。”

苏荷把纸条折起来，塞进围裙内袋：“城南面粉铺的老板，你见过没？”

苏桃想了想：“好像姓周，四十来岁，平时不怎么露面。对了——振华哥说那人左手写账。”

苏荷心里咯噔一下。她没有立刻说话，陶罐里的小米粥咕嘟咕嘟翻着泡，鱼眼大的泡，正好是火候到的时候。她顺手把灶台上的火捻小，捞起勺子搅了两圈，粥面泛起细密的光泽。顾长山在街办开完会过来，军绿色外套上还沾着露水。苏荷把粥盛了一碗端给他，压低声音说：“那张纸条，你帮我查查城南面粉铺姓周的那人——他左手写字。”

顾长山端着碗的手微微一顿，抬起眼看她：“你是说……纸条是面粉铺的人写的？”

“不是赵前进的人，就是赵前进本人。”苏荷把一碟腌萝卜推到他面前，“城南面粉铺跟赵家有没有生意往来？”

顾长山放下碗，从口袋里摸出个小本子翻了两页：“赵记饭馆的进货单我托市场办的人看过，上面确实有城南面粉铺的名字，但签收人写的是‘赵’，没写全名。”他合上本子，目光沉了沉，“我再去一趟，回头给你准信。”

他走后，苏荷把灶间所有人叫到院子里。翠兰站在最边上，低着头绞手指，昨晚被盘问了一通，眼圈还红着。苏荷扫了她一眼，语气不重：“翠兰，你值夜那几天，有没有见过一个男人，中等个儿，大概这么高——”她伸手比到自己眉毛的位置，“在库房后头那棵槐树底下站过？”

翠兰愣了一下，嘴唇抖了抖：“老板娘，我、我那天看到……看到……”她吞吞吐吐，半天说不痛快。

“看到什么，你说。”苏荷语气淡淡，却带着不容反驳的劲。

“我看到个穿灰褂子的男人，蹲在槐树底下，好像在刨土。”翠兰的声音越来越小，“我以为是小偷，喊了一嗓子，那人站起来就跑，连东西都没顾上捡——就是、就是那张纸条。”

“灰褂子。”苏荷重复了一遍，没再多问。她让人散了，自己蹲到那棵槐树底下，用铁锹挖开翠兰说的地方。挖了三寸深，碰到一个硬东西——一个包着油纸的牛皮纸信封。拆开一看，里面是一张收据，日期是七天前，上面写着：南粉，一百斤，赊账，月底结。底下落款一个歪歪扭扭的“赵”字，笔锋朝左。

苏荷眯起眼睛。赵前进自己不动手，让人写，就为了不留下笔迹。可他没想到，收据被人藏在了树底下。

“苏荷姐！”杨大海从厨房探出头来，“面醒好了，今天开不做红油抄手了？”

“做，怎么不做。”苏荷把收据塞进口袋，拍了拍手上的土，“今天的红油抄手，多放一勺花椒，加辣。”

她转身走进灶间，和面、擀皮、剁馅的动作一气呵成。门外顾客已经排了两排，队伍一直拐到巷口拐角。她把一口大铁锅架上旺火，油泼辣子的香味从巷子里弥漫开来，连树上的麻雀都扑棱棱飞起来。

有句老话叫什么来着，打蛇打七寸。赵前进想偷她的配方，她不拦。她要的是他自投罗网。

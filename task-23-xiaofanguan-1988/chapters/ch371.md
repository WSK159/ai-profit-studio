# 第371章 那半张纸的底

苏荷没去碰那顶草帽。

她只是站在门口看了很久，直到一个穿蓝布衫的老太太路过，顺手摘了草帽扣在自己头上，嘀咕了一句“哪个粗心的丢了东西”，便往巷尾走了。草帽人没出现，薄荷叶却像是专门留给她的——老太太走出一段路后，那片薄荷叶从帽沿上落下来，被风卷到了她脚边。

她弯腰捡起来，叶脉底下压着一行细到几乎看不清的字，是用指甲划的：今夜子时。

顾长山凑过来看了一眼，没说话。

入夜后下起了毛毛雨。苏荷披了件旧蓑衣，从后门绕到城东老街。酱菜厂的铁门虚掩着，她侧身挤进去，脚下不敢打灯，摸黑走到那排老缸前。雨声帮了大忙，盖住了她的脚步声。

她蹲下来，手指摸到铁环。这一次她没犹豫，横了心往上一拉——土块应声裂开，露出一个深约半尺的砖砌暗格。里头防水油纸包着什么东西，摸上去硬邦邦的像块瓦片。她掏出来，捏了捏，是几块叠在一起的纸。

油纸拆开，里头是半张泛黄的牛皮纸，边缘有焦痕，像是从火里抢出来的。上面用毛笔写着几行字，墨色褪得厉害，只能勉强认出几个字：郑……欠……董……酱……三……百……斤……民国三十二年……另半张在……

字迹到这里断了，纸的下半截被整整齐齐地撕掉，断面干净利落，像是有人故意撕的。苏荷把纸对着细雨里透过来的一丝路灯余光，翻来覆去看了两遍，忽然发现背面有极淡的铅笔痕。她眯着眼瞧——“董宅正房梁上，三尺见方，铜皮裹之。”

她的手指微微发抖。

董宅的梁上，还有东西。

她刚要把纸揣进怀里，身后突然传来一声咳嗽。苏荷猛地回头，只见两丈开外的屋檐下，一个矮胖身影笼在黑暗中，声音沙哑：“苏老板，这么晚了，还来赏缸？”

她听出来了，是白天那个秃顶老头。

苏荷把纸攥在手心里，索性直起身子，淡然道：“白天落了根簪子，来寻。”

老头沉默片刻，从怀里掏出一只半旧的铜簪子，递过来：“是这个吧？白天你蹲在缸边的时候，从你头发上滑下来的。”

苏荷接过簪子，心头一凛——她今天根本没戴簪子。

老头却不给她追问的机会，压低了声音：“那口缸的事，你别再管了。有人托我带句话：郑家的人欠董家的，不是一缸酱的事，是一笔要用命填的账。你要真想找答案，去董宅量一量那根正房梁，别惊动任何人。”

“你认识草帽人？”

老头没应声，退后一步，走进雨里：“子时三刻，城门楼上有半句真话，你去不去，自己定。”

苏荷站在雨里，攥着那半张纸和铜簪子，耳边的雨声像是陡然间大了——她知道，这不是她一个人的因果，还有人在暗处等着她走到那一步。

她深吸一口气，收好牛皮纸，转身往回走。走到酱菜厂大门口时，她顿住脚步，回头看了一眼前头那片雨幕。秃顶老头已不见踪影，但他刚才站过的屋檐下，青砖缝里醒目地嵌着一粒粗盐。

那是草帽人惯用的记号，可这盐粒是湿的，溶了一半，像刚刚被咬过一口。

他不是草帽人的手，那他是谁的？苏荷没有答案，但有一个念头像锥子一样扎进她脑子里——这粒盐，跟那天门槛上草帽人留下的，分明是同一只手捏出来的。她攥紧手心，脚步声在雨夜里越走越快，越走越沉。

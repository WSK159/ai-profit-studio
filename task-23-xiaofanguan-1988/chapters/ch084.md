# 第84章 小菜秧子

天还没亮透，省城南关街的早市已经热闹起来。苏荷挎着个竹篮，篮子里码着两捆水灵灵的小菜秧，身上换了件洗得发白的蓝布褂子，头发用碎花头巾一裹，活脱脱就是个进城卖菜的乡下姑娘。

她没急着往何记货栈那边凑，而是先在早市上转了一圈。卖豆腐的、卖粉条的、卖针头线脑的，摆摊的人三三两两聊着闲话。苏荷蹲在一个卖萝卜的大姐旁边，把菜秧子摆在地上，学着旁边人的样子吆喝了半嗓子，又不好意思地抿嘴笑了。

那大姐热心，问她：“姑娘头回来吧？看你面生。”

“是呢，从城外刘家村来的，自家园子里种的小菜秧，吃不完拿来换几个钱。”苏荷捏着菜叶子，语气怯生生的，“大姐，我问您个事儿，南关街上那个何记货栈，收不收菜呀？我听村里人说他们家买卖做得大。”

大姐嗑着瓜子，眼皮都没抬：“何记货栈？那可是何五爷的买卖，人家做的是大生意，茶叶、布匹、山货，哪看得上你这几捆菜秧子。不过——”

她顿了顿，压低声音：“他们家后厨倒是天天有人出来买菜，有时候在巷子口那边收。你去碰碰运气，兴许能赶上。”

苏荷心里有数了，谢过大姐，拎着篮子慢悠悠往何记货栈方向走。

何记货栈的门脸在正街上，三间门面，青砖到顶，门楣上挂着一块黑底金字的招牌，比张德发那粮油铺气派多了。门板已经卸了两块，里面伙计正在打扫，一股子茶叶和桐油的味道飘出来。

苏荷没往正门凑，拐进旁边一条窄巷，果然看见一个后门口搁着几筐菜叶子，一个穿着围裙的胖女人正蹲在地上择菜。苏荷走过去，试探着问：“大嫂，您这收菜不？我这小菜秧子，今早刚拔的，水灵着呢。”

胖女人抬头看了她一眼，又看了看她篮子里那两捆菜，撇撇嘴：“就这两捆？还不够我烧一顿汤的。”

“家里种得少，先拿来试试。大嫂要是觉得好，明儿我多带些来。”苏荷蹲下来，把菜秧子摊开，叶子上的露水珠子还挂着，在晨光里亮晶晶的。

胖女人伸手掐了一片叶子嚼了嚼，点了点头：“还算嫩。五分钱一捆，卖不卖？”

“卖！”苏荷爽快答应，接过钱，却不急着走，帮着胖女人择起菜来，“大嫂，您这儿菜用得不少啊，是给掌柜的开的灶？”

“可不，何五爷嘴刁，一天三顿不带重样的。光是为伺候这口吃的，后厨就养了三个人。”

苏荷手上择着菜，嘴上有一搭没一搭地聊：“五爷胃口好，生意肯定也好吧？我看这货栈进进出出的人可不少。”

“那是，何记在南关街可是头一份——”胖女人话说到一半，忽然打住，警惕地看了她一眼，“你打听这些做什么？”

苏荷一脸无辜：“我就随便问问。我娘家表哥想找活儿干，听说何记常招人，想问问还收不收人。”

胖女人脸色这才缓和了些：“招人是掌柜的说了算，我一个做饭的哪知道。你要真想打听，去前面门市问管事的。”

苏荷见好就收，辞了胖女人，挎着空篮子往回走。刚拐出巷子，迎面就看见一个熟悉的身影——那个白衬衫男人，正从何记货栈正门出来，手里拎着一个布包，脚步匆匆地往街西头走。

苏荷心头一跳，下意识跟了上去。

白衬衫男人的步子很快，七拐八绕地穿过了两条街，最后钻进一家挂着“鸿运茶楼”招牌的铺子里。苏荷在街对面一棵梧桐树后站定，隔着一条马路，看见那男人上了二楼临窗的位置，隔着窗玻璃跟一个人说话。

那人背对着街面，只露出半个后脑勺，穿着件灰色的中山装，身形瘦削。

苏荷心里“咯噔”一声。

这背影——跟那天在南货铺门口看见的、捧着月牙青瓷瓶的老头，有几分像。但隔着远，模模糊糊的，不敢断言。

她正想换个角度看得更清楚些，肩上忽然被人拍了一下。

苏荷猛地回头，对上一双熟悉的、带着笑意的眼睛。

顾长山穿着一件旧军装，手里拎着个公文包，像恰好路过似的，低声道：“别回头，往前走。”

苏荷心脏砰砰跳，面上却不变色，跟着他并肩朝前走了几十步，拐进一条僻静的巷子，才停下来。

“你怎么来了？”她压低声音。

“办完事路过。”顾长山说着，目光在方才茶楼的方向扫了一眼，“看见你，就没走。”

苏荷看了看他，没再多问，只把今早在何记后厨听到的说了：“何五爷嘴刁，一天三顿不带重样——我琢磨着，他既然这么讲究吃，咱们或许可以从这上头下功夫。”

顾长山挑了挑眉：“你要做什么？”

苏荷眼角弯了一下，露出一个略带狡黠的笑：“明天，我再来送菜。”

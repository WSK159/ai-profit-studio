# 第254章 初六取钥

大年初六，天还没亮透，街面上炸鞭的碎红纸屑被风卷着，贴着地皮打旋儿。

苏荷把棉袄领子竖起来，揣着手往金钩巷方向走。顾长山跟在她身侧半步远，手里拎着一只旧帆布包，包里装着锤子、起子和一把手电筒——宋莉说“取钥匙”，可谁知道那地方藏着什么。

金钩巷七号是座半塌的杂院，院门虚掩，门板上糊着去年秋天的讣告，纸角卷了边。苏荷推门进去，院子里静得只剩麻雀扑棱翅膀的声响。

柴房在东北角，屋顶塌了个窟窿，椽子露在外面像一排肋骨。西北角的青砖墙根堆着碎瓦和烂稻草，宋莉那日说得明白：第三块砖后。

顾长山蹲下去，手指沿着砖缝摸了一圈。那砖比旁边的砖松，他用起子轻轻一撬，砖头整块松动脱落，露出后面一个巴掌大的凹槽。

槽里躺着一把铜钥匙。

钥匙泛着暗沉的紫铜色，齿形与苏荷手中那把六瓣梅花铜钥匙截然不同——这是一把平齿钥匙，尾部有一个指甲盖大小的圆环，环上刻着一个极浅的“北”字。

苏荷蹲下身，没急着拿钥匙，先盯着那个“北”字看了半晌：“黎叔说得没错，北门钥匙。”

顾长山把钥匙拾起来递给她：“和那个圆圈匹配吗？”

苏荷从贴身内兜里摸出那枚柳叶形的铜圆环——老账房信上那个落款形状的物件。她将钥匙尾部的圆环贴上去，严丝合缝，轻轻一旋，钥匙在环里转了一圈，咔的一声，环内侧弹出一根细如绣花针的铜簧。

两人的目光同时顿住。

“这不止是钥匙。”苏荷把那根铜簧拨动了一下，“它还是一个机关。”

顾长山皱眉：“那是什么？”

苏荷把铜环翻过来，对着晨光看。铜簧根部压着一行极小的字，刻得歪歪扭扭，像是赶工时留下的：“左二右三，环扣心。”

“左二右三……”苏荷低声念了两遍，把铜环收进内兜，又把北门钥匙仔细包好，“这个得慢慢琢磨，先回去。”

她直起身，正要转身走，余光却扫见柴房门口的地上有一样东西。

一小撮灰白色的绒羽。

和她在老铺子窗台上捡到的那根灰白鸽绒一模一样。

苏荷的动作顿了一瞬。

上一回黎叔走后，她是在门槛边捡到的鸽子绒。老账房也出现在黎叔到访之后。如今她在柴房门口又见同类羽绒，而这里按说应当已经废弃十一二年，不会有人常来喂鸽子。

“长山，你昨天来踩过点吗？”她问。

顾长山摇头：“没有。”

苏荷蹲下来，用指甲捻起那一撮绒羽，凑近了看，羽根干燥，没有灰尘附着，是最近一两天才落下的。

柴房门口的地面上，除了这撮绒羽，还有两个浅浅的脚印。鞋印边缘清晰，尺码不大，约莫三十七码整——是个女人的脚印。

苏荷看了两秒，没说话，只是把那撮绒羽小心地收进火柴盒里。

她心里浮起一个名字：宋莉。

初六取钥匙这件事，只有宋莉、黎叔、她和顾长山四个人知道。宋莉那个“舅舅”托黎叔转交钥匙，宋莉来拜年时传的口信——但宋莉自己来来过金钩巷七号吗？

她没说。

出了杂院，天光已然大亮。街边早点摊子支起来了，油条在锅里翻滚，豆浆冒着白烟，寻常得像全天下所有清早晨市一样。

顾长山看了她一眼：“直接回去？”

苏荷摇摇头，目光扫过街对面的巷口：“去味香居北门看看。”

顾长山没有多问，两人拐进侧街，绕过热气腾腾的包子铺、卖鱼丸汤的小摊、挑着担子叫卖糖葫芦的老汉，拐了三个弯，味香居烧毁后残存的那道北墙就立在眼前。

墙体被那年的大火烧得焦黑，砖缝里长出一蓬枯草，落了一层灰。苏荷站在墙下，掏出那把北门钥匙，对着墙面仔细比划了一圈——这面墙看起来就是一面普通的残墙，没有门，没有洞口，甚至看不出任何曾经有过门的痕迹。

她蹲下来，看墙根的砖缝——泥土干裂，被常年雨水和潮气灌得密密实实，看不出近期被人动过的痕迹。

“是位置不对，还是这钥匙不是开这面墙的？”顾长山问。

苏荷把钥匙在手里掂了掂，目光落在墙根的阴影处——那里有一小块砖的颜色比周围略深一些，像是被什么液体浸过。

她伸手去碰，指腹搓了一下，是油。

半干不干，带着一股淡淡的脂香。

苏荷凑近了闻，那味道让她眉梢一跳——不是猪油、不是菜籽油，而是一种混合了桂花和芝麻香的气味。

那是岑三味灶台上那款青瓷罐里的油脂味。

她慢慢直起身，回头看了顾长山一眼：“有人比我们先来过。”

顾长山目光一沉：“何时？”

“看这油干的程度，不超过三天。”苏荷把手指在棉袄上擦干净，“三天之内，有人到过这面墙，而且那人在墙上抹了油。”

“抹油干什么？”

苏荷沉默了片刻，说出两个字：“起砖。”

她捏着那把北门钥匙，在掌心里转了半圈，又望向墙根那块颜色发深的砖——若是有人起了砖又塞回去，砖缝之间的泥土不可能完好如初，而这里表面看不出破绽。那说明那人起砖的手法极其老练，用油做润滑，起开了砖块，又从里面取走了什么，再严丝合缝地塞了回去。

“这个人的手法，”苏荷的声音低下去，“跟师父当年教我‘用刀开的锁，缝要收得看不见’是一个道理。”

她抬眼，朝墙上那排焦黑砖块看过去，心里盘着一件事：初六取钥匙的消息是腊月底由黎叔传出、宋莉转达的——那抹油的人，是在消息传出来之后、初六之前来过。他是怎么知道这个日子的？还是说，他根本不需要知道日子——他只是趁所有人都在等钥匙的时候，提前把墙里的东西拿走了？

门外传来一阵自行车铃声。

一个中年男人骑车载着一筐白菜从巷口经过，看见他们两人站在废墟墙下，远远喊了一声：“哎！那墙根儿底下可别乱站——那楼老墙前几日下雪后就有点歪，前儿还有人来敲过砖呢！”

苏荷回头：“您瞧见有人来敲砖？长什么样？”

那人刹住车，想了想：“个儿不高，穿着灰夹克，戴个棉帽子，看不清脸。前两天早晨吧，在墙根蹲了老半天，我还当是挖野葱的。”

灰夹克。

又是灰夹克。

苏荷与顾长山对视一眼，谁都没说话。

菜贩蹬着车走了，苏荷在原地站了半晌，把那把北门钥匙收进怀里，低声说了一句：“走吧，回去做饭。”

回去的路上，她在路边一个邮筒前停下来，把手里那撮灰白鸽绒放进火柴盒，封好，塞进了邮筒旁边的一道墙缝里——那是她和“灰鸽子”之间唯一的联络暗号。

她不知道对方什么时候来取，也不知道对方是什么人，但既然那撮绒羽一而再、再而三地出现在她周围，对方就一定还在看着这只邮筒。

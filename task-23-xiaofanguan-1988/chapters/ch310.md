# 第310章 子时三刻

腊月十四的夜，像一口倒扣的铁锅，把味香居压得透不过气来。

苏荷攥着那张红纸，指腹反复摩挲“子时三刻，北墙坟冢”八个字。宋文起的字迹她认得，端方中带一丝斜挑，像他这个人——表面规规矩矩，骨子里藏着不安分。他把信塞进门缝，却不肯露面，这是要引她去北墙。

“他说的是哪面北墙？”苏荷压低声音问周三昧。

周三昧站在甬道出口，侧耳听了一会儿外头的动静，才回身道：“味香居后头有一片荒坟，早年间是汤家的祖坟。后来城改，坟迁了大半，剩下的几座没人认领，就荒在那儿。其中有一座，没有碑，只有个土包，老人们都叫它‘无字坟’。”

无字坟。苏荷心里一沉。她想起下午在地窖陶缸封条上看到的那个“封”字，笔锋枯涩，像是写的人手在抖。宋文起让她子时去北墙坟冢，偏偏选在这种地方——坟前议事，要么是见不得光，要么是……有些话，活着的人不能说。

“去不去？”周三昧问她。

“去。”苏荷把红纸折好，塞进贴身的衣兜，“他要是想害我，犯不着绕这么大弯子。再说——”她顿了顿，手指不自觉碰了碰腰间那口被调换的铁锅，“我有种感觉，这锅的事，跟宋文起脱不了干系。他欠我一个解释。”

如今正是子时刚过两刻，距离三刻还差一盏茶的功夫。

两人从地下甬道爬出来时，后院的冷风兜头灌下，苏荷打了个寒噤。腊月的夜风带着湿气，钻进骨头缝里。味香居的后院堆着劈柴和杂物，月光被云层遮了大半，只能靠雪地的反光辨认脚下的路。

北墙根果然有一片荒坟，稀稀拉拉七八个土包，被枯草和残雪盖着。最里头那座没有碑，只竖了块半截青石，横躺在地，像被人踢倒的界桩。

苏荷蹲下身，借着月光仔细打量那块青石。石面上有个浅浅的刻痕，已经被风雨磨得模糊，但她还是认出了那形状——五瓣梅花，跟周三昧收下的那张纸条上的记号一模一样。

她心头一跳。这座坟，跟汤家祠堂暗格里的记号对上了。

“周师傅，你在这儿多久了？”她回头问周三昧。周三昧站在几步开外，目光落在那块青石上，半晌没说话。半晌，他才开口：“这块石头，是周明善立的。”

“他立的？给谁立？”

“给他自己。”

周三昧的话像一颗石子投进死水，苏荷后背一凉。她正要追问，北墙外的暗影里忽然传来脚步声，不重，但踩在冻硬的雪地上，咯吱咯吱地响。两个人影从墙角的拐弯处走出来——宋文起手里提着一盏马灯，灯光昏黄，在他脸上映出明暗不定的轮廓；他身后跟着一个人，穿着灰棉袄，低头弓背，看不清脸。

宋文起走到坟前，把马灯放在青石上，才抬起眼：“你来了。”

“你设了这个局，我能不来？”苏荷盯着他，“宋文起，你跟我娘之间的账我不管。但你今天把我锁在地下，又递了这张条子——你要说什么，现在就说。”

宋文起没答话，侧身看向身后那人。灰棉袄往前迈了一步，在灯光里抬起头来。苏荷看清那张脸的瞬间，瞳孔一缩——疤脸男。幸福饭店被岑三味泼了滚油的那个疤脸男。他换锅，他在门外说话，他自称见过周明善。

疤脸男朝她点了点头，声音沙哑：“苏老板，腊月里的锅，冷得快。”

苏荷记得他说过这句话。就在被换的那口锅从油布包里取出来的时候。

她没有动，只是慢慢把手伸向腰间那口锅的锅沿。疤脸男却笑了笑，伸手从怀里掏出一个东西，递到她面前。苏荷低头看去，是一截断掉的铜链，链头挂着一枚小铜片，上面刻着一个“周”字。跟她之前见过的那把铜钥匙上的字，一模一样的刻法。

“周明善让我把这个交给你。”疤脸男说，“他说，锅是锅，钥匙是钥匙。锅换了，钥匙还在。让你明日开张，别误了事。”

苏荷握着那截铜链，指尖发凉。锅换了，钥匙还在——这句话是什么意思？她正要开口，一阵风从北墙外灌进来，马灯的火苗猛地跳了一下，灭了。黑暗吞没一切，只有雪地的微光映出几个人影。

与此同时，苏荷听见身后传来“咔哒”一声轻响，像是有人踩断了一根枯枝。

她猛地回头，月光下，一道模糊的身影正从荒坟的阴影里闪出，朝味香居的方向快步走去。那身影的步子很奇怪，每走几步，就顿一下，像在试探什么。苏荷的脑子里飞快闪过一个念头——铁钩底纹脚印。

“有人！”她喊了一声，拔脚就追。

周三昧已经快她一步蹿了出去。疤脸男和宋文起站在原地，宋文起低低骂了一句什么，也跟了上来。苏荷追到墙根时，那道身影已经翻过了北墙的矮豁口，消失在夜色里。她正要翻墙去追，忽然觉得脚底踩到了什么硬物，低头一看，是一根锈迹斑斑的铁钩。

她被换锅的暗室里见过这种铁钩。周三昧说过，那是周明善北河拉船的旧物。

苏荷捡起铁钩，握在手心里，钩尖还带着一丝潮气，像是刚从怀里取出来。她抬头看向那道身影消失的方向，又低头看看手里的铁钩，脑子里忽然把那根断掉的铜链、五瓣梅花的记号、无字坟上的青石串成了一条线。

周明善还活着。他就在味香居附近。而那道身影从坟影里出来，故意被她发现，又故意落下这根铁钩——他在引路。

这个念头还没落定，宋文起追上来，远远喊了一句：“苏荷，别追了！那不是人！”

她转过身，月光下，宋文起站在几丈外的雪地里，脸色铁青，目光死死地盯着她手里的铁钩：“那东西……不是活人的东西。”

苏荷攥紧铁钩，掌心被冰凉的锈痕硌得生疼。子时三刻已过，北墙坟冢前一片死寂，只有远处隐隐传来一声乌啼。她低头看着地上的足迹——那脚印到了墙根就消失了，没有出的脚印。

那是失踪的周明善，还是别的什么？她不知道。但她知道，明日开张前，她得弄清楚这件事。

# 第80章 夜探福泰祥

夜里十一点，城南巷的灯已经灭了大半。

苏荷换了一身深色的粗布衣裳，头发用黑巾裹紧，踩着老郑给她找来的布鞋，贴着墙根往福泰祥的方向摸去。顾长山走在她前头三步远，脚步比猫还轻，到底是部队里练出来的，走在碎砖瓦砾上愣是没发出半点声响。

福泰祥的后墙根有一扇通风的铁栅窗，巴掌宽的栅条，里面糊着油毛毡。老郑白天来踩过点，说这窗子早就坏了一半，从外头能看到地窖口。

苏荷蹲下身，侧耳听了片刻，里面隐约有脚步声。她回头看了顾长山一眼，顾长山一点头，两人绕到更暗的角落，那里有棵老槐树，枝桠探到福泰祥后院的院墙上方。

顾长山垫步，两手交叠，苏荷一脚踩上他掌心，被他轻轻一托，整个人就攀上了墙头。她趴在墙头上往下看，后院不大，靠北墙搭着三间瓦房，最东头那间门板虚掩，里头透出一线昏黄的光。

地窖入口就在那间瓦房的地板底下。老郑的消息没错。

苏荷正要跳下去，忽然听见有人说话。是两个男人的声音，从瓦房里传出来：

“……中转到天明就走，船是利丰的，老规矩，卸了就走，别留过夜。”
“陈掌柜这回怎么这么急？”
“省城那边催得紧，听说上头的货断了，让咱们先顶一顶。”

苏荷心口一跳。省城那边？毒盐的源头果然不止福泰祥。

她没再多停留——不能打草惊蛇。她顺墙溜下去，顾长山已经在暗处等她：“听见了？”
“听见了。”苏荷压低嗓音，“货是利丰船务中转的，今晚不走，明早天亮前出。”

她顿了顿：“所以咱们得抢在他们卸货之前动手。”

顾长山点头，转身就走。苏荷跟上去，两人穿进小巷，绕到赵婶家后门。赵婶没睡，灯亮着，一听到暗号就开了门。

“婶子，明天一早你照原来说的办。”苏荷递给她一个油纸包，“话要说得像无意间漏出去的，别太刻意。”

赵婶接过油纸包，里头是五块钱：“放心，我这张嘴，在城南巷说了二十年闲话，没人听出真假来。”她想了想，又说：“明早我就在菜市场跟刘家嫂子说‘福泰祥的陈掌柜最近进了一批新货，便宜得吓人，怕是供了大户人家的’，刘家嫂子跟陈福的媳妇一个村，她准保传过去。”

苏荷点头。她要的就是陈福听到风声后自乱阵脚——一个人慌了，就会动手挪货。只要他动了，就能抓住现行。

第二天清早。

苏荷在苏记门口支起桌子，慢悠悠擦着筷子。早上七点，老郑叼着烟过来，眼睛往福泰祥方向一瞟：“动了。刚才天不亮，福泰祥后院出来两辆板车，盖着麻袋，看辙印深得很，八成就是那三百斤。”

苏荷放下抹布：“往哪儿走的？”

“往渡口方向。”

苏荷嘴角一弯：“那杜师傅那边，得提前了。”

八点十分，顾长山带着两名工商科的同志堵在渡口，拦住两辆板车。掀开麻袋，白花花的小袋装盐，每袋五十斤，袋口没封严，露出里头掺的灰白色粉末。

顾长山用手捻了一点，放在鼻子底下一闻，脸色就沉了：“工业白矾和石灰粉，这批货要是散出去，吃死人都不奇怪。”

他当场让人扣车，又带人直奔福泰祥，那位陈掌柜正坐在柜台后头算账，见顾长山进来，脸上还挂着笑：“顾同志，这是——”

“陈福，你涉嫌制售有毒食盐，跟我们走一趟。”

陈福脸上的笑僵在脸上：“你们凭什么？我这是正经——”

“你那批盐里掺了白矾和石灰粉，在渡口被我们截下了。你要是还不认，咱们到所里慢慢说。”

陈福的嘴唇瞬间白得没了血色。他是生意人，知道这种事一旦坐实是什么罪名——投毒罪，至少十年起步。

他还想挣扎，喊人、叫冤、拿钱砸，顾长山只是沉着脸把手铐一抖：“陈福，我数到三。”

陈福瘫了。

他被人架走的最后一句话是对着顾长山喊的：“货不是我的！是洪三给的！我就是个中转的，我顶多收个手续费——”

顾长山回头看他：“洪三？人现在在哪儿？”

陈福的眼神闪了闪，声音小下去：“在省城。他上个月就搬去省城了。说那边有个贵人，路子大，比青江市好赚。”

省城。

苏荷站在福泰祥门口，看着顾长山一行人带走陈福，心里把这三个字翻来覆去嚼了一遍。

贵人。毒盐从省城来，洪三躲在省城，利丰船务的中转也指向省城。一切的线头都伸向同一个方向。

老郑走过来，压低声音：“那批盐一共三百二十斤。按五成都掺了，能毒死半个青江市的人。苏丫头，这事儿，怕是比咱们想的还大。”

苏荷眯着眼看他：“老郑，你以前走南闯北，听没听说过省城谁管盐的？”

老郑沉默了半晌，碾灭烟头：“听说过一个人，姓何的，开盐行的，铺子不挂牌，但省城半个盐市都是他的。道上喊他‘何五爷’。”

苏荷记下这个名字，正要再问，顾长山从所里出来了。他把陈福的口供复印件递给苏荷：“陈福供了洪三的底——他在省城南关开了家粮油铺，名义上卖粮油，暗地里走盐。线的另一端，说是‘贵人’，但什么身份，陈福也不清楚。”

他顿了顿：“你能用上。”

苏荷把口供叠好收进衣兜：“你打算怎么办？”

“洪三是主供人，证据在他手上。我得去省城跑一趟。”顾长山看着她，“你去不去？”

苏荷笑了笑，眼睛里像是有火在烧：“我正要去。”

# 第171章 码头夜船

天擦黑，苏荷在铺子后头的灶上重新煨了一盅雪羹，用白纱布罩好，提着往巷口走。

城北大码头在青江下游，说是码头，其实只是几块旧石板搭成的台阶，一溜黑漆漆的木船泊在岸边，水里倒映着零星的灯火。晚上八点半，码头空荡荡的，只有几条野狗在垃圾堆边翻找。

苏荷在石阶上坐着等了约莫三刻钟，顾长山才从堤岸下面的黑影里冒出来，穿一件深蓝工作服，嘴里叼着根没点的烟。

“你胆子真不小。”他在她旁边坐下，目光扫过那盅雪羹，“码头夜里有巡防队，逢八必检。”

“那你选的地方。”苏荷把盅递过去。

他没有接，却压低声音说：“你在粮站的消息没错。我下午顺着线摸了一遍，李兆阳今晚不在这里，但他让何承业的船装了四十捆橡胶管，走江路往省城方向去，半夜十二点停三号泊位接货。”

苏荷抿紧嘴唇，脑中的拼图迅速合拢——橡胶管在1988年不仅是日用品，更是生产军需品的禁运物资。她盯着江面上那一片漆黑，轻声说：“今晚如果我让这批货出不了江，李兆阳和何承业就得栽半截进去。”

顾长山侧过头看她：“你要做什么？”

“苏桃已经回铺子了。”苏荷站起身，拍了拍裤腿上的灰，眼神在夜色中亮得惊人，“雪羹在这里，人你也见到了。我问你一句话，说真话的——你愿不愿意跟我合伙？”

顾长山沉默良久，呼吸在夜风里有节奏地一起一伏。

“转业费三千，全在存折上。”他终于开口，声音稳得像秤砣，“从回青江那天起，我就等一个人让我把这钱花到正道上。”

他说完，从怀里掏出一个布包，里面是一本叠得齐整的存折，还有一把泛着陈年铜锈的钥匙：“城南巷七号的门面房，是我爹留给我的。那门面挨着你这铺子三间远，后面带个小院。你要愿意，苏记可以扩过去。”

苏荷呼吸一滞。城南巷七号——那正是她记得的后来青江城改造成步行街时最值钱的铺位之一。她伸手接过钥匙，指尖碰到他粗粝的掌心，微微一烫。

远处江面忽然亮起一束手电光，三短一长。船来了。

苏荷把那盅雪羹往顾长山手里一塞：“你把羹送去给唐师傅，告诉他，我明日一早去如意楼等他——”她顿了顿，眼里映着江面的光，“告诉何承业，就说你手上有省城军区后勤部的路子，能吃下五十捆，今晚见他一面。”

顾长山皱眉：“一个人去？”

“干这行，我上辈子练过。”苏荷转身，身形没入夜色，声音远远抛过来，“你走运了，顾同志，从今晚起，我是你合伙人。”

江风卷着湿气灌进巷口，将墙上那张红纸吹得烈烈作响。

# 第231章 展销会前夜

张北亭走后，巷子里安静得像一潭死水。苏荷蹲在门槛边，把那片陈皮翻来覆去闻了三遍，忽然站起身：“苏桃，打听一下——后天展销会的会场在哪个酒店？”

“省城第一招待所，三楼的会议厅。”苏桃翻着报名表，“姐，咱们报的是‘风味小吃’组。可张北亭那种大酒楼报的是‘名厨名菜’组，跟咱不一个赛道。”

“他是不跟咱一个赛道，”苏荷把陈皮收好，“但他说的那个评委国宴大师，评的是全场总榜。你想想——他今天专门跑来放话，就为了吓唬咱？”她摇头，“宋莉要真想针对咱，不会让张北亭提前来打草惊蛇。他这一趟，反而说明她手上能打的牌不多，要借着评委的势，把苏记压死在展销会上。”

苏桃似懂非懂，忽然“啊”了一声：“姐，那我明早先去赶早集买筒骨——你要十斤，我带十五斤！万一断了货，后头补不上。”

苏荷被她这一说笑出来：“行，你顺道去趟副食品店，看看有没有桂皮和草果。价格涨了也没事，先囤——”

话没说完，院门外传来脚步声。顾长山穿着那身洗得发白的制服，手里拎着个网兜，兜里装着两瓶老白干、一包茶叶。他站在苏记招牌下，脸上难得有些局促。

“苏荷，”他开口，“周日的事……我去河堤蹲守宋莉的踪迹，回来晚了。”

苏荷心里那点火气被他一句话浇了大半。她这才注意到他眼下青黑，领口还沾着泥点，显然是连夜跑了不少地方。“先进来。”她侧身让路，“你来得正好，帮我看样东西。”

她把油纸包和铁皮盒里的信件摊在桌上，把钱岐黄的话原原本本说了一遍。顾长山听完，半晌没说话，只是盯着那封信的落款。赵德厚三个字写得遒劲有力，最后一笔拖得极长，像一把刀。

“你认得这个名字？”苏荷问。

“不算认得。”顾长山从口袋里掏出一张对折的纸，“你让我查城南巷的地契底档，我翻到街道办的旧账册。赵德厚——民国三十七年在这条巷子置产三间半。但有意思的是，他落户的名字写的是‘赵德厚’，”他指着纸上一行小字，“可登记的原籍是四川绵阳。而宋莉的户籍底档，登记的祖籍……”他抬眼，一字一顿，“也是四川绵阳。”

苏荷后背一凉。

同一地方，一封近乎遗书的信，一个守门的师弟，一个疑似重生的对手——宋莉绕这么大圈子针对她，难道根本不是冲苏记来的，而是冲这间铺子、冲赵德厚传下来的东西来的？

“三味火，”她低声念，“陈皮引火，猪骨养锅，七窍心……”她忽然抓住顾长山的袖子，“那把火石呢？就是灶台上点灯用的那块，是不是还在？”

顾长山一愣，转身到灶台边把火石摸了出来。灰黑的火石拳头大小，表面坑坑洼洼，看着毫不起眼。苏荷把火石翻过来，底部的凹槽里嵌着一块泛黄的膏状物——她凑近一闻，带着一股极淡的檀香。

“这是什么？”

顾长山接过去端详片刻，脸色微变：“像是……旧时候灶王爷像前供的香膏。但我没见过嵌在火石里的。”他用指甲刮了一点，放在舌尖尝了尝，眉头拧紧，“甜的。还有一丝薄荷味。”

苏荷脑子里“嗡”的一声。三味火、五味骨、七窍心——七窍心！“心”不是指心，是“辛”！辛香料！薄荷属于辛凉之品，这块香膏里掺的，可能就是配方里缺的“心”。

她正要开口，院门口忽然传来一个细弱的声音：“请问……苏记掌柜在吗？”

门外站着一个穿灰色外套的中年女人，拎着一个藤条箱，风尘仆仆的。她开口是四川口音：“我姓宋，是展销会评委宋国栋的秘书。我们宋老爷子想请苏老板——”她笑了笑，“明天提前去一趟招待所。”

苏荷的目光落在她手上。她左手拎着箱子，虎口的位置……干干净净，光滑一片。

不是宋莉。

那人见她不答话，又补了一句：“老爷子说，有一道‘九品回香汤’，想请苏老板掌掌眼。”

苏荷心头一震。九品回香——铁皮盒里那封信提到的配方，那道菜名，她从没跟任何人提过。

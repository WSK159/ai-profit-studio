# 第224章 河堤夜雨

雨点子砸在铁皮棚顶上的时候，苏荷正把最后一只搪瓷盆扣进三轮车斗里。

城南巷的路灯昏黄一片，雨丝在光柱里斜成白亮的线。顾长山从巷口走进来，雨衣上滴着水，抬手把一张纸条递到她面前：“张全友刚递出来的，梁国庆的豆油车改走河堤南段，十一点半过三号桥。”

苏荷抹了一把脸上的雨，低头看表。十点四十七。

“周会计那边呢？”她把纸条折起来塞进围裙口袋。

“赵铁柱盯着，人没动。梁国庆那辆黑色桑塔纳还在食品厂院里停着，引擎盖是凉的。”

苏荷吸了口气。她闻得见雨里隐隐飘来的豆油味——那是河堤南段的油坊仓库，梁国庆在那里存了整整一车皮的大豆油，准备连夜运出青江。她转头看向里屋，苏桃正趴在桌上对一张账本，铅笔头咬在嘴里，眉头皱成小小的疙瘩。

“桃子，把门锁好，谁来都别开。”

苏桃抬头，眼睛亮了一下又暗下去：“姐，你要去河堤？”

“去收网。”苏荷把雨衣扣子从下往上系紧，声音压得很平，“顾大哥在，没事。”

苏桃张了张嘴，终究没再说什么，只把账本合上，从抽屉里摸出一柄折叠剪刀揣进衣兜，抱臂站在门框里看她。

雨更大了。

三轮车轱辘碾过积水，苏荷坐在车斗沿上，顾长山在前面蹬。雨衣下的衬衫很快湿透，凉意贴着脊背，但她攥着那盘录音带的手心是热的。

三号桥在河堤尽头，钢管护栏锈迹斑斑，桥下黑水翻滚。他们把三轮车推进桥头一处废弃的砂石堆后面蹲着，顾长山拧亮一支手电筒，照向桥那头。光柱里雨丝密密匝匝，什么都没有。

“你确定他会走这条路？”

“张全友说，梁国庆每次跑货都走三号桥，理由只有一个——桥那头是青江码头派出所的辖区，和城南分局正好错开两公里，够他卸货上船。”

苏荷没说话，食指慢慢摩挲录音带的塑料壳。梁国庆那天的声音清晰地从记忆里浮出来——“苏老板，你一个女人家，开个饭馆不容易，把配方交给我，以后你只管当个甩手掌柜。”话是软的，但说这话时他在笑，那笑容苏荷前世见得多了，是吃人不吐骨头的笑。

她抿紧了嘴唇。

十一点十八分，桥那头亮起两束车灯。

一辆盖着军绿色篷布的解放卡车从雨幕里钻出来，车速不慢，轮胎碾过桥面时带起一片水雾。顾长山手电筒往车头照了一下，车牌号对上了。

“是他们的。”

苏荷站起身。雨点打在脸上生疼，她没动，盯着卡车驶过三号桥，往码头方向拐去。然后她抬脚，大步流星跟上，步子又稳又急。

“苏荷——”顾长山追上来一把拽住她手腕，“再等几十米，等他们进仓库再动。”

“我知道。”她回头，雨水顺脸颊淌下来，眼睛却是亮的，“但顾大哥，你听——”

她话音没落，路对面突然亮起一片白光。三辆警车从巷子口冲出来，警笛撕开雨幕，直接横在卡车前头。卡车一个急刹，篷布被风掀起一角，露出里面码得整整齐齐的油桶。

苏荷看着梁国庆从驾驶室跳下来，一身西装被雨淋得贴肉，脸上那种胸有成竹的笑容终于裂了个口子。

顾长山扭头看她：“你什么时候叫的人？”

“我没叫。”苏荷的声音在雨里又轻又稳，“但我知道他跑不了——城南的警察，从来不值夜班。”

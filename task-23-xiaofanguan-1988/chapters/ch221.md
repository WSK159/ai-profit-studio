# 第221章 夜色里的刀

车灯熄了，引擎声断在巷口。

苏荷和顾长山同时噤声，周海生下意识往灶台后面缩了缩。三人隔着门板听动静，脚步声不重，却稳当，两三个人，像是常干夜路的人。

“哐哐哐。”四声敲门，节奏粗暴。比周海生刚才那三下敲得狠得多。

苏荷给顾长山递了个眼神，顾长山不动声色地退到后门边，手搭在腰后。苏荷走到门边，故意用警惕的声音问：“谁啊？这大半夜的，还让不让人睡了？”

门外一个粗哑的男声：“开门，检查的。有人举报你这里卖违禁品。”

苏荷心头冷笑，面上却没露：“什么检查？工商还是公安？你证件拿出来我看看，隔着门我看一眼也行。”

“少废话，你开门查了就知道了。”另一人插嘴，语气更急。

“不出示证件，我就不开。你们要是真部门的，明天白天再来。”苏荷声音冷淡，寸步不让。

门外沉默了两秒，随即“哐”地一声，门板被踹了一脚，震得墙灰簌簌往下掉：“别敬酒不吃吃罚酒！哥儿几个今晚非进你这门不可！”

话没落音，门闩“咔哒”一声自己开了——苏荷站在门内，手里提着一把斩骨刀，刀锋在昏黄的灯光下泛着冷白的光。门外果然站着三个男人，为首那个满脸横肉，右手握着一截铁钎，身后的两人也各持短棍。见门开了，反倒是他们愣了愣。

“怎么着，要砸我的店？”苏荷站在门口，身后的灯把她的影子拉得很长，声音不高，却每个字都砸得实实在在，“我苏荷从摆推车到现在，还没怕过谁。你们是梁国庆派来的，还是孙德海的？要不要我帮你们报个名字，省得进了局子连个主人家都交代不清？”

为首那人脸色变了一变，显然没想到这女老板能如此直白地戳穿底细。他咬了咬牙，反正也撕破脸了：“你管谁派来的，今晚苏记就得散伙！”他提着铁钎冲上来。

苏荷侧身让开，刀背狠狠磕在他手腕上，“当啷”一声铁钎落地，男人痛呼一声，身后的两人刚想上前，顾长山已从后门闪出，一脚踹翻一个，反手把另一人的手腕拧到背后，动作干净利落，一看就是部队里练过的。

“别动。”顾长山的声音很沉，那人疼得直吸气，一动不敢动。

苏荷把刀尖点在地上，抬眼看着被按住的三个男人：“回去告诉梁国庆，他的人我替他留着，他要是再使这种下三滥的手段，我连他的好日子一起断了。”她顿了顿，微微一笑，“对了，他有辆黑色波罗乃兹吧？你让他好好想想，那辆车这几天晚上都停在哪里——我的人可都看见了。”

三个男人被顾长山一一推出门，踉跄着消失在夜色里。

门重新关上，周海生才从灶台后面探出头来，脸上带着几分惊悸：“苏老板……你刚才说的那车的事，他们听了，梁国庆会不会狗急跳墙？”

苏荷擦着刀，语气平得让人心发慌：“他早就跳墙了。今晚这三个人，不就是证据？”

她走进后屋，从木盒里取出那台录音机和一沓账页，摆在桌上。窗外夜色沉沉，远处的城中村方向，有一声野猫凄厉的嚎叫划破寂静。

“明天，早饭一卖完，咱们就去工商局。”苏荷看着顾长山，目光平静，“该收网了。”

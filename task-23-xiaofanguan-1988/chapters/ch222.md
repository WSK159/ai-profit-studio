# 第222章 饵已下钩

凌晨五点，城南巷还笼在青灰色的薄雾里。苏荷推开苏记小馆的后门，灶台上的铁锅已经烧得微微泛白。

她今天没急着开火，而是从柜台底下摸出那个裹着红布的录音机，又把昨晚录的那盘磁带倒回来重听了一遍。

梁国庆的声音从喇叭里透出来，隔着电流有些发闷：“苏老板，你痛快把配方交出来，我出三千。我既然能让你那铺子被人泼漆，也能让你的铺子在城南巷待不下去——”

她按下停止键，嘴角微微勾了一下。

“苏荷姐！”苏桃从楼上蹦下来，怀里抱着个巴掌大的算盘，“我今天把昨儿盘账的数儿又核了一遍，咱们这个月光豆油就省了七块六毛！”

苏荷把磁带收进围裙口袋里，回头看她：“不错，比上个月算得快了。等会儿你去赵铁柱那儿跑一趟，跟他说，梁国庆那辆波罗乃兹今儿要是再往食品厂的方向开，让他别跟得太紧，远远吊着就行。”

“为什么？”

“打草惊蛇。他要是有后手，得给他留出放线的空。”

苏荷说完，弯腰从灶台底下拎出一袋子今早刚到的鲜猪肚，开始焯水。她今天要做一道酸辣肚丝汤，这是给一个人预备的——省城那位张经理，昨天托人带话，说今天中午要从省城过来，在苏记小馆谈事儿。

消息是顾长山转给她的。顾长山昨晚在她打烊后过来了一趟，只说了三句话：“张全友要来，说替梁国庆谈‘建材生意’。城东那块地的批文我看了，名义上是建农贸市场，实际有梁国庆和孙德海的影子。你见不见？”

苏荷当时说：“见。”

张全友在省城做建材出身，据说和梁国庆的油脂厂合作了三年，供应渠道、废料清运、甚至给工人的饭盒都是梁国庆那边包办。这两人之间是什么关系，账本上只有一笔笔进出数字，线头得从人嘴里牵出来。

上午十点半，一辆灰扑扑的桑塔纳停在苏记小馆门口。车门打开，下来一个四十五六岁的中年男人，西装革履，脚上却蹬了一双布鞋，手里拎着两瓶古井贡酒。

“苏老板！久仰久仰！”张全友进门就是一嗓子，声音洪亮得像在唱戏，“我在省城就听人说城南巷有家小馆子，菜做得比国营饭店还地道，今儿一尝，果然名不虚传！”

他目光扫过柜台，落在那口铁锅上，又扫过墙上挂的营业执照和食品卫生先进单位奖状，最后定在苏荷脸上。

苏荷把最后一碗酸辣肚丝汤端上来，笑着说：“张经理这么忙的人，专程跑一趟来尝我这汤？我这小馆子可招待不起省城的大生意。”

“苏老板是爽快人，我也就不绕弯子了。”张全友夹了一筷子肚丝，嚼了两口，眉毛一挑，又夹了一筷子，“实不相瞒，梁老板跟我说过，你这店里有几道好菜，他想把这方子收走，放到省城去开个分号。你要是肯合作，钱不是问题——三万块，房子、设备、招牌，全是你的。”

三万块。

1988年的三万块，能在这条巷子里买下两套院子。

苏荷不慌不忙地盛了碗汤，抿了一口：“三万块，梁老板出得起。可他那份对账单上的欠款，怕是三百万都填不上吧？”她顿了顿，汤碗搁在桌上，发出轻轻一声响，“张经理，您和梁老板合作三年，他油脂厂的账是真是假，您比我清楚。”

张全友的笑容僵了一瞬，筷子悬在半空。

苏荷继续说：“他要买配方是假，想让我闭嘴是真。您来替他跑这一趟，是觉得我一个小个体户好拿捏？还是觉得您这份人情，值三万块？”

门外忽然响起一阵急促的脚步声。赵铁柱推门进来，喘着气，压低声音说：“苏荷姐！梁国庆那辆波罗乃兹，真往食品厂开了——后头还跟了一辆省城牌照的面包车。”

张全友的脸，一寸一寸地沉了下去。

他放下筷子，从西装内袋里掏出一个信封，推到苏荷面前：“苏老板，这是梁国庆让我转交给你的‘见面礼’——你听了这里面的东西，再想想答不答应。”

苏荷拆开信封，是一盒磁带。

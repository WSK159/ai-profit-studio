# 第364章 渡口老艄公

正月初六，天还没亮透，青江上浮着一层薄薄的雾气。苏荷把牛皮纸简图收进贴身衣兜，锅铲别在腰间，照旧系着那条洗得发白的蓝布围裙出了门。

顾长山在巷口等她，手里拎着两个热乎乎的肉包子。“先垫垫，渡口有风。”

她接过包子咬了一口，肉馅还冒着热气，咸香扑鼻。“你昨夜没睡好？”她注意到他眼底有青影。

“翻了一夜房契底根，越看越觉得蹊跷。”顾长山走在她身侧，声音压得低，“你师父笔迹我见过几回，这房契背面的字，横竖撇捺都对得上，唯有那个‘荷’字收笔处，多了一挑——像是故意留的记号。”

苏荷脚步慢了一瞬。她想起前世师父教她切菜时说过的规矩：真正的厨子，刀口说话，字里藏事。

两人赶到青江渡口时，雾气正浓，江面只能看出三五丈远。渡口冷冷清清，只有一条乌篷船泊在岸边，一个佝偻的老艄公蹲在船头卷烟，听见脚步声，抬起浑浊的眼睛。

“过江？”老艄公声音沙哑。

苏荷点头，目光却定在船尾那根竹篙上——竹篙顶端缠着一圈褪色的红绳，绳头打了个双鱼结，和她那把铁钎柄上缠的绳结一模一样。

她不动声色地上了船，顾长山紧随其后，步伐沉稳，压得船身只轻轻一晃。老艄公慢吞吞地起身，撑篙离岸。

船行至江心，雾更浓了，四下里白茫茫一片，岸影全消。苏荷忽然开口：“老人家，您在这渡口撑了多少年船了？”

“记不清呐。”老艄公头也不回，“总有二十多年了吧。那年月渡口热闹，十里八乡的人都从这里过江赶集。有个后生，隔三差五地往对岸跑，做锅的，一口锅做得比别家好，我说你干脆别种田了，光打锅就能养家。他不吭声，只笑。”

苏荷心口猛地一紧。她师父前世告诉她，他年轻时一直住在青江对岸的董家村，直到三十岁那年才搬走。

“后来呢？”她声音发紧。

“后来那后生失踪了。”老艄公撑着竹篙，慢悠悠地说，“有人说他发了财搬去了省城，也有人说他死在了外头。倒是每年腊月里，他老伴还托人带口信，问渡口有没有一个姓董的后生来过。”

苏荷攥紧手中的铁钎。铁钎柄上那双鱼结硌着掌纹，像是某种呼应。

船靠岸时，老艄公收了篙，忽然压低了声音：“丫头，你那铁钎上的绳结，可是自己打的？”

苏荷微怔：“不是，是家里传下来的。”

老艄公点点头，不再多问。等两人下了船，他才从怀里摸出一块东西，隔着雾递过来：“刚才看你拿铁钎，我突然想起来，当年那后生落在这渡口一样东西，托我替他收着，说将来若有人拿同样的铁钎来过江，就把这东西交出去。”

苏荷接过那块东西，触手冰凉，借着雾里的天光一看——是一小片黄铜片，刻着半朵荷花，背面平平整整，像是刚打磨过，但铜片边缘有磨损的旧痕，明显是长年被人攥在手里的。

“那人可还有说什么？”苏荷追问。

老艄公想了想，摇头：“就一句话。他说：荷花开了，人就该回来了。”

苏荷攥紧铜片，心跳如擂鼓。江风吹散雾角，她看见岸边不远处，果然有一棵歪脖子老柳树，树身粗壮，枝干低垂，树根处盘着一圈光秃秃的泥土，没有长出草来。

顾长山也看见了那棵树，他大步上前，蹲下身子察看树根四周的土。晨光渐亮，他忽然低声说：“土是新翻过的，而且不止一次——最近的一次，就在这两三天。”

苏荷走过去蹲下。她手指探入树根下松动的湿土里，摸到了什么东西，硬邦邦的，像一块石板。

她拨开泥土，露出一面乌黑的铁皮箱盖，四角钉着铜钉，箱盖上刻着一行小字：董家锅坊，辛酉年置。

苏荷的手指停在那行字上，呼吸都慢了半拍。老艄公的船已经撑回江心，雾里传来他苍老的喊声，像是自言自语——

“锅里还有锅，人外还有人。丫头，你挖出来的东西，自己掂量着用。”

他的船影消失在浓雾里。

顾长山伸手帮她挖出铁皮箱。箱体不大，约莫一尺见方，重量却沉得出奇。苏荷深吸一口气，掀开箱盖——里面叠放着三样东西：

一本油布包裹的薄册子、一把铜锁钥匙、一卷泛黄的港纸。

薄册子翻开第一页，是熟悉的笔迹，只有一行字：真正的好锅，不用铁铲去刮，火候到了，它自然不粘。

她正要再往下翻，身后的顾长山忽然屏住了呼吸，他低声说：“苏荷，有人来了。”

苏荷抬头，顺着他的视线望去，雾散了，对岸渡口站着一个灰布衫身影，一动不动，像是已经站了很久。

那人的身影被晨光拉得又长又窄。

她攥紧了手中的铜片，指节发白。

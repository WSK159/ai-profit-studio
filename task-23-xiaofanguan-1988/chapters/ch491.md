# 第491章 蓝布褂子里的暗袋

灶间门口的那道脚步声，踩在潮湿的砖地上，带着某种刻意的沉缓。

苏荷没有回头。她手上还捏着那张油纸包着的遗书，指腹压着“苏茂丰”三个字的墨迹，那笔锋顿挫有力，和师父平时写菜谱时的飘逸截然不同——像是换了个人，或者说，是换了一种心境。

“别动。”

顾长山的声音从门框那边传过来，低哑，带着一丝压不住的紧绷。苏荷这才发现他不知什么时候已经从后窗翻了出去，又绕到了灶间正门。他手里攥着一把手电筒，光束没有打在她身上，而是斜斜地照向灶台后面那扇半掩的柴门。

“谁在外头。”他说得笃定。

柴门后面安静了一瞬，然后传来一声极轻的叹息，像是老旧的牛皮风箱漏了气。门板被推开一条缝，一只干瘦的手先探了进来，骨节粗大，指甲缝里有洗不掉的木屑和桐油气味。

“是我。”

老木匠陈九叔从门缝里挤进来半个身子，灰白的头发上沾着蛛网，手里提着一把旧刨子。他看见苏荷手里的蓝布褂子，眯了眯眼，没说话，先蹲下来，伸手在门槛内侧摸索了一阵，掏出一截烧了半截的蜡烛头。

“你师父当年藏东西的法子，我知道一些。”他点燃蜡烛，昏黄的光映着他脸上的沟壑，“这褂子，他缝了暗袋。”

苏荷心里一凛。她翻过蓝布褂子，果然在对襟内侧的夹层里摸到一条硬实的边沿，用同色线密密缝了三道陷阱线——外行拆会扯断内层。她从灶台抽屉里摸出一把小剪刀，沿着线脚小心挑开，里面掉出一块折成四折的牛皮纸。

摊开，是一张手绘地图。

纸面泛黄，边缘发脆，画的是青江老城的地下水道走向，从北城门外的老槐树一路延伸，穿过七八个弯道，最后汇入城西一处标注为“瓮”的圆点。圆点旁边用细笔写了一行小字：“缸底有锁，锁中藏钥。”

地图的左下角，画着一只倒扣的缸，缸口朝下，缸底朝上，上面压着一枚五瓣梅花印。

“这画的……是北门外的水道？”顾长山蹲下来，手电光沿着墨线描了一遍，“我小时候听老人讲，老城底下有明代的排水渠，后来填了，没人进去过。”

陈九叔没接话，只是盯着地图上那只倒扣的缸，嘴唇嚅动了两下：“他说过一句话，我一直没想明白——‘缸翻过来，就不是缸了。’”

苏荷把地图折好，塞回褂子暗袋，又看了遗书末行那行字：莫开北门。门后活着的，不是你师父。

可这张地图的终点，恰恰是北门。

她正想着，陈九叔忽然侧过头：“对了，你们方才是不是动过水缸？”

没等苏荷回答，他已经走到灶台边那口老水缸前，蹲下来，手指抹过缸沿内侧，捻了捻，皱眉：“桐油膜，有人封过这条水路。”

他站起身，拍了拍膝盖上的灰，放下那把刨子，从怀里摸出一块巴掌大的木牌，递过来：“冯三让我捎的。他说明天午时你不用去寿材铺了，他改了地点，城西三眼井，井边有棵歪脖子槐树。”

苏荷接过木牌，上面用焦墨画了一只紧闭的独眼，眼珠子正中钉着一枚钉子。

“冯三说了什么别的吗？”

陈九叔摇摇头：“他就说了一句——‘水退了，该开瓮了。’”

他提着刨子转身要走，苏荷叫住他：“九叔，你和我师父……到底什么关系？”

陈九叔顿了顿，没回头：“我是给他打棺材的。三十年前打过一口，没用上。前年又打了一口，还是没用上。你说这算什么关系？”

他推门出去，脚步声消失在夜色里。

顾长山走到苏荷身边，看了一眼她还在微微发抖的指尖，把自己外套脱下来，披在她肩上：“冯三改地点，说明有人在盯着寿材铺。明天我跟你去三眼井。”

苏荷攥着那块画着独眼的木牌，听着窗外夜风扫过屋檐的声音，低声说：“我爸的遗书里说，莫开北门。可冯三这幅画——钉子钉住眼珠子，意思是……有人看着北门。”

她顿了顿：“明天去三眼井，带着那把梅花钥匙。”

“你信冯三？”

苏荷低头看了一眼蓝布褂子领口内侧，那里用褪色的线绣着一个小小的“荷”字，笔锋有钩——和遗书上的署名一样，是苏茂丰的笔迹。她慢慢说：“这褂子藏在缸底的夹层里，封了三十多年。冯三能托陈九叔带话，至少证明他知道这件褂子的存在。”

她抬头，灶间里烛火跳动，映得墙上那只水缸的倒影像一只蹲伏的兽。

“明天去看看，”她说，“他要么是一个等了很多年的人，要么是一条引出缸底之事的饵——但总归是条线索。”

她把蓝布褂子重新叠好，压进床头那只樟木箱底。又摸了摸遗书上“门后活着的，不是你师父”那行字，手指无意识地在“活着的”三个字上停住了。

活着的。不是活过的。

那缸里封的又是什么？

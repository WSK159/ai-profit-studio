# 第404章 七锁归位

城南巷老屋的门锁已经换了三把，可苏荷站在门前时，还是从门槛下摸出了那把备用钥匙。铁皮钥匙在掌心硌得发疼，她深吸一口气，推开了吱呀作响的木门。

屋里的一切还保持着上次离开时的样子。灶台擦拭得锃亮，案板上扣着青花瓷碗，墙角四十八口缸整整齐齐码着，缸盖上落了一层薄灰。苏荷的目光扫过那些缸，最后落在堂屋正中的地面上，那里有一块青石板，板缝里渗出泥土的气味。

顾长山跟在后面，反手关上门，又插上门闩。他从怀里掏出那七把铜钥匙，摊在掌心。铜钥匙在昏暗的屋子里泛着幽暗的光，每一把的齿形都不同，却又隐约暗合某种规律。

“老屋底下有东西。”苏荷蹲下身，手指叩了叩青石板。声音是实的，但她知道，这座老屋是她父亲留下的，当年父亲临终前，曾拉着她的手说——“缸开河干，洞现山前。七锁归位，方见真天。”

那会儿她只当是弥留之际的胡话，可此刻看来，父亲说的每一个字，都在指向某个她从未触及的秘密。

她贴着地面摸索，指腹碾过石板缝隙，终于在一处边角摸到一道细微的凹槽——那凹槽的形状，恰好是七把铜钥匙并排排列的轮廓。苏荷心头一跳，回头看了顾长山一眼。

顾长山没说话，把七把钥匙递过来。她的手微微发颤，将那七把钥匙按顺序嵌入凹槽中。第一把，第二把，第三把……七把钥匙依次落位，咔哒、咔哒、咔哒——清脆的机括声连成一串，像是什么机关被逐一唤醒。

石板纹丝不动。

顾长山皱眉，弯下身来看：“这凹槽像是被重新填过土，缝隙里还有新泥。”他拔出一把钥匙，翻过边缘一看，果然在凹槽内壁上发现了一层干涸的、深灰色的泥壳，“有人试过撬开这块石板，又给填回去了。”

苏荷的心沉了沉。有人来过老屋，动过这处机关，但没能打开。或者——打开了，又盖了回去。她站起身，目光重新落到那四十八口缸上。缸里装的是她这些年积攒的腌菜、酱料，但缸底呢？她走到最墙角那口缸前，掀开缸盖，把里面的干豇豆一把一把掏出来。

掏到一半，她的手指碰到一个硬邦邦的东西。捞出来一看，是一块巴掌大的铁皮，锈得看不出原色，边缘却有一个规整的圆孔。苏荷把那块铁皮翻过来，背面刻着一行小字——柳家西院，水井之下。

顾长山凑过来看，脸色微变：“这不是你家老屋的东西。”

“柳家西院……”苏荷重复了一遍这四个字，忽然想起上次去柳家祠堂时，小刘提过一嘴——柳家祠堂西边早年有个院子，后来塌了，地基被填平，现在种着两棵枣树。

她攥紧铁皮，又看了看地上的凹槽，忽然明白了什么。

“这凹槽里的机关，不是打开老屋地面的。”她把七把钥匙重新拔出来，收进怀里，“是‘指路’的。七锁归位，不是开锁，是告诉咱们——下一处该去哪儿。”

顾长山沉声道：“柳家西院。”

苏荷点头，正要开口，屋外忽然传来一声脆响——像是碗碟摔碎的声音。紧接着，巷子里传来一阵急促的脚步声，有人压着嗓子喊了一句：“她回来了！走！”

苏荷一步冲到门边，拉开一条门缝往外看。巷口闪过一个瘦高身影，穿着藏蓝中山装，戴着一副黑框眼镜，跑得极快。那背影她没见过，但那种慌张的跑法，分明是冲着老屋来的。

顾长山已经拉开半扇门，追着那个身影就冲了出去。苏荷没有跟出去，她低头看了看手里那块铁皮，又看了看墙角那口被她掏空的缸——缸底露着一层新鲜的、深灰色的泥。

那层泥和凹槽里的泥壳一模一样。

“缸是有人动过的。”苏荷喃喃道，“而且就在咱们回来之前不久。”

她弯下腰，伸手探进缸底，指尖在湿泥里一摸——又摸出一块硬物。这回是一截竹筒，筒口用黄纸封着，纸上画着一道朱砂符。她拔开竹筒，里面滚出一卷发黄的纸。

纸展开，上面只写着一行字：

“柳家西院那口井，井底不是土。”

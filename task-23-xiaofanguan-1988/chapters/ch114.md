# 第114章 三号桥的雨

雨是后半夜落下来的。

苏荷蹲在三号桥桥洞底下，把油纸包往怀里又紧了紧。账本用三层油布裹着，外面套了个装面粉的麻袋，看着灰扑扑的，就算有人起了疑心掀开瞧，也只会当是谁家丢了的口粮。桥洞外头是条窄河，1988年的雨水带着煤灰味，落在水面上泛着一层油亮的光。远处的省二监铁门亮着灯，隔着白茫茫的雨帘看过去，像一只半睁半闭的眼睛。

她凌晨四点就到了。顾长山只给了个时间段：押解车大概六点半过白水门，韩姓接应人会在三号桥个体协会传达室等她。说是个体协会，其实就是沿河搭的一间砖房，门板上刷着褪色的红字，常年半掩着，谁都能进。可传达室里没人。

苏荷盯着那扇门看了快一个钟头，心里反复数着脚边的湿泥里多出了几个烟头。她不敢进去等——万一来的不是韩姓接应人，而是等着账本自投罗网的人呢？她前世在厨房里摸爬滚打，刀光火影里练出来一个本事：信任何人，都只信三分。但要她亲自把账本送进一只从未见过的口袋里，她又嫌赌注太大。账本她留了一手——昨夜铁匠巷的旧屋里，她扯下两页最关键的交易记录，卷成细条缝进棉袄夹层。真到了万不得已，怀里的东西就是她谈条件的底牌。

雨势渐渐小了。

桥头传来自行车链条磕碰挡泥板的声响。苏荷缩回桥洞阴影里，手摸进腰间——那里别着从铁匠巷房东那儿顺来的半截铁管。来人是个穿深蓝雨衣的瘦高男人，他把自行车支在传达室门口，没敲门，也没掏钥匙，就站在门洞底下点了根烟。火光一明一灭间，苏荷看清他的脸：方下巴，眼窝深，年纪约莫三十出头，但笑起来只有眼角有纹路，像常年习惯板着脸的人。

“送面粉的？”男人忽然开口，声音不高不低。

苏荷心跳漏了一拍。这是昨晚顾长山临走前反复交代的暗号，就这一句——接得上，货交出去；接不上，掉头就跑。可她没急着答话，又等了两秒，直到男人把烟掐灭，掸了掸雨衣下摆沾的泥点。那个掸泥点的动作很顺，是部队里练出来的姿势，不像伪装的。

“不送面粉。送碱水面。”她答。

男人“嗯”了一声，把传达室的锁拧开了，头也不回地说：“进来说话。”

苏荷钻进传达室时，鼻子里钻进一股陈年的墨水味和煤炉灰味。屋里只有一张写字台、两把靠背椅，靠墙立着一只蓝白铁皮暖水瓶。男人把门带上，没开灯，在黑暗里伸手接过她怀里的麻袋，放到桌上。他拆油纸的动作很稳，指尖带着茧，一看就是摸过枪的手。他把账本翻开，借着窗户透进来的一点天光看了两行，眉头拧起来，随即又松开，合上，重新裹好。

“对得上。”男人说，声音比刚才低了一截，“韩兵，省厅经侦二科。顾长山当年三连的指导员交代过我，你只管信。”

苏荷盯着他：“沈其昌那边……”

“押解车改道了。”韩兵从口袋里掏出一张折叠的纸，展开是封信，字迹潦草，像是匆忙写的，“顾长山连夜想办法，跟市局那边通了气，沈其昌今天不走白水门，改走南门绕城外，另外有人接。他让我告诉你——账本到了，人就会在三天内放出来。但点名举报王家这事，得等沈其昌出来以后亲口指认，否则只凭账本上那几行仿笔笔迹，司法上不够实。”

苏荷的心落回肚子里，又悬起来：“那老赵呢？”

韩兵看了她一眼：“老赵今天中午就到铁匠巷。你想好怎么应对了？”

屋外的雨不知什么时候停了。一道灰白的光从云层缝隙里漏下来，照在传达室门口那一滩积水里。苏荷低下头，看着自己那双被雨水浸透的解放鞋，慢慢笑了。

“迎他。”她说完，把那两页缝在棉袄里的账页掏出来，也放进了桌上的油纸包里。

# 第299章 子时之约

苏荷没回头。

路灯底下的玻璃茬子在她身后碎了第二声，那人停住了，像是也在等她动作。空气里浮着一层很淡的菜籽油味——和那根灰鸽子竹管内壁的气味一模一样。

她把纸条收进围裙口袋，慢慢转过身。

路灯下站着一个瘦高的男人。穿着灰夹克，头发乱糟糟的，左手垂在裤缝边——小指的位置，空荡荡的。

送信的货郎。

他站在光影交界处，面孔半个亮半个暗，咧嘴笑了笑，露出两颗黄牙：“纸条看了？”

“看了。”苏荷道，“你怎么知道我在这儿？”

货郎没答，目光越过她，落在她来路的方向，像是在确认那扇孤门的方向还暗着。他一努嘴：“那扇门里的人，你以后少靠近。”

“他是什么人？”

货郎又笑了笑，不说话。他从裤子口袋里摸出一小包东西，用油纸包着，四四方方的，隔着纸能看见里头渗出来的一点暗褐色。他递到苏荷面前。

苏荷没接：“什么东西？”

“好东西。”货郎用手掂了掂，油纸发出细碎的脆响，“你拿回去找宋文秀，她认得。”

宋文秀——又是宋文秀。这个货郎绕来绕去，始终在把她往宋家的事上引。

苏荷没动，沉声道：“你知道宋文起在哪。”

货郎的眼皮撩了一下，像是要否认，又像是默认了。他幽幽道：“我只知道他在一个过不去的地方。那扇门里的人也没跟你说错——你让宋文秀别找了，她哥不会回来了。”

“他死了？”

货郎不出声，半晌，把油纸包往苏荷手里一塞：“拿着。”

苏荷低头看了一眼那油纸包，裹得严实，封口处被人用指甲掐了一个小小的“周”字——刻痕很深，是被人反复压过的。她心里一跳：这个“周”字落款，和牛皮小包上的那个一模一样。

“这是谁写的？”她追问。

“你师父。”货郎说完这两个字，忽然转身，一步两步，往巷口走。

苏荷追了两步：“我师父已经死了！”

货郎的脚步不停，声音飘回来：“死的是周明善。你还有别的师父。”

苏荷愣在原地。

她重生前，前世有一手米其林厨艺，却从不记得自己在哪家学校学出来的。她仿佛天生就会做菜，锅灶灶膛、火候刀工，落在手里跟骨血一样自然。她从来不去细想——因为她记得的“前世人”里，从来就没有一个师父。

货郎已经走出巷口了。

她攥着那油纸包，指腹压在“周”字刻痕上，痕里还有一些细碎的干灰——像是烟灰，又像是烧过的纸钱灰。她心头一动：这句“你还有别的师父”，说的是前世，还是这一世？

苏荷回到苏记小馆的时候，已经快半夜了。苏桃给她留了一盏油灯，油灯下压着一张字条：“姐姐，顾叔来了，在偏厅等你。带了东西。”

顾长山。

苏荷推门进了偏厅，顾长山正坐在藤椅上，面前的旧木桌摆着一个铁匣子，匣盖没合，里头是一叠信封。他抬眼看见她，目光在她脸上扫了一圈：“你怎么这个样子？”

苏荷照了下镜子，才发现自己头发里钻了一撮灰，面颊还蹭了一道白灰粉末，是蹲在工地上沾的。她没答，走过去，把油纸包放在桌上：“有人塞给我的。”

顾长山拆开一看，油纸里头包着一小块块干透的红曲酱——是味香居后厨做酱封缸时用的那种，加了陈皮和淡竹叶，过了十五六年，酱色反而深得快黑了。顾长山的眉头皱起来：“味香居的东西。”

“你认得？”

他点了点头：“小时候在味香居门口闻见过。那会儿整条街的人都说，那家馆子做酱不掺水，老东家自己的方子，红曲里头加淡竹叶，独一份。”

苏荷闻了一下，那股酱气里夹着一缕很淡的樟木味——像是和香樟木一起封了很长时间。她忽然想起什么，把那油纸包的封口又翻了翻，纸的内壁，有一行用指甲划出来的细字，笔画很浅，像是怕人发现，写得又小又密。

她凑到灯下细看，每一个字都像撕碎的信纸重新拼起来：

“丑时，东城门外，白果树下，有人等你。”

苏荷的指头一僵。丑时——子时之后，三更将尽四更初。她攥着那张油纸，正要问顾长山有没有听说东城门外最近有什么动静，偏厅的窗户忽然被什么东西轻轻叩了三下。

顾长山起身，推开窗缝，外头没有人，窗台上蹲着一只灰鸽子，脚环下栓着一个小小的铜管。

他取下来，管口还带着一点江水的湿气，拧开，里头塞着一块叠得极细的纸，只写了一个字：

“周”——

但那笔迹，不是货郎，不是灰衣老头，也不是那扇门里的传话人。笔划里有千钧之力，像是一个已经枯瘦一尽的老人，用尽最后的力气写下的落款。

窗外，远处传来一声低沉的江轮汽笛，正正好是子时的钟声。

夜色里，还有什么东西正在朝着东城门的方向移动。

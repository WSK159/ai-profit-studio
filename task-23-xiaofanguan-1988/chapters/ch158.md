# 第158章 暗巷夜话

苏荷从老戏台暗沟里钻出来时，浑身湿透，冷风一吹，牙关打颤。她缩在城墙根下，把地契贴身藏好，又摸了摸怀里那封信。信纸上的字迹清瘦遒劲，落款果然是“周国宴”三个字。她前世学艺时听师父提起过这个名字，说那是上世纪六七十年代真正的御厨传人，后来失踪了，有人说是死了，有人说跑了。没想到，他竟隐姓埋名在青江，守着城南巷一座破院子过了二十多年。

她蹲了半晌，把手搓热，才起身往城东方向走。省城不比青江，夜里也有路灯，但昏黄的灯光照在湿漉漉的石板路上，反倒添了几分冷清。她不敢去旅馆——今晚的动静太大，若有人追查，旅馆是头一个查的地方。她拐进一条小巷，看见一家挂着“永和旅社”招牌的小门面，门口坐着个打毛衣的老太太。

“婶子，还有空房吗？”苏荷拢了拢湿头发，挤出个笑，“赶夜车来的，钱没带够，住最便宜的那种就成。”

老太太抬眼打量她，见她是个姑娘家，身上湿了大半，倒也不像坏人，便说：“后院有间柴房改的，两毛五一晚，就是没炉子，冷。”

“成。”

苏荷付了钱，钻进那间只够放一张窄床的小屋。她没脱衣服，裹着被子靠在墙角落，把信又看了一遍。信里的内容她已经背熟了——周国宴在信里写明，他师兄杨景堂当年是清宫膳房的最后一代掌勺，文革时怕手艺失传，把六道宫廷菜的完整方子手抄成一本册子，交给在省城诚记当铺做伙计的堂侄杨三保管。后来杨三死了，册子下落不明，但诚记当铺的老板换了三任，铺子还在，若有人持信去问，或许能打听到线索。

苏荷把信收好，闭眼睡了一会儿。天没亮她就醒了，在附近买了两个烧饼，一边啃一边往陕西省巷走。诚记当铺不难找——省城西街口一拐弯，青砖灰瓦的门脸，门匾上“诚记”两个字漆都掉了半边。她推门进去，柜台后头坐着个戴老花镜的瘦老头，正拿个放大镜看一枚铜钱。

“姑娘，当东西还是赎东西？”

“找人。”苏荷把信递过去，“麻烦您给里面管事的人看看，说是青江周家的旧交。”

老头接过信，看了一眼落款，神色微变，又抬眼打量她片刻，低声说：“您稍等。”他转身掀帘子进里屋去了。

苏荷站在柜台前，心里默数着时间。约莫过了两三分钟，帘子一掀，出来个三十出头的男人，穿着灰布中山装，戴副黑框眼镜，看上去像个教书先生。他手里捏着那封信，目光落在苏荷脸上：“信上的事，您知道多少？”

“该知道的都知道。”苏荷说，“我就是为这个来的。”

男人点了点头，把信折好还给她：“您跟我来。”他领着她穿过当铺后门，走进一个天井小院。院里种着两棵石榴树，树下摆着张石桌。他请她坐下，倒了杯茶，才低声道：“我是杨三的孙子，杨青。那册子，我爷爷确实留下过话，说是一个姓周的老友寄存在铺里的。我爷爷走得急，没来得及交代清楚，册子被后来的当铺掌柜当成普通旧书，随手收在库里了。我接手铺子后翻过库房，没找到。”

苏荷心一沉：“会不会被人取走了？”

杨青摇头：“我查过账本，那批旧书后来统共卖了三回，最近一回是去年腊月，卖给了一个收旧货的贩子，姓孙，常年在城东废品站那边收旧书旧纸。”

苏荷记下这个名字，正要再问，忽听前头铺面传来一声响动。杨青脸色一紧，起身道：“有人来了。”他快步走到院门边，从门缝朝外望了一眼，又转头压低了声音：“穿灰棉袄、戴灰毛线帽的男人，在柜台前打听一个年轻姑娘的下落。”

苏荷心里“咯噔”一下。灰帽子——昨晚在老戏台边上，她瞥见过那么一个影子。

“后院有门能出去吗？”她问。

“有。”杨青指了指墙角一道矮门，“走到底是个菜市场，人多，好混。”

苏荷没有犹豫，冲杨青拱了拱手：“杨先生，今天这份情我记下了。那个姓孙收旧货的贩子，我去找他。册子若是能找到，我必登门重谢。”她说罢转身就要走，杨青却叫住了她：“姑娘。”

苏荷回头。

杨青目光复杂地看着她，低声道：“那本册子，不光是菜方子。我爷爷留话说，册子中间夹着一样东西，是杨家和周家两辈人拼了命保下来的。不管您跟周家是什么关系，只求您——别让它落到不该落的人手里。”

苏荷看着他，郑重一点头：“放心。”

她钻出矮门，穿过一条堆满菜筐的小巷，混进早市的人流里。身后，那顶灰帽子没有跟上来，但苏荷知道，他没走。

他只是暂时被她甩开了。

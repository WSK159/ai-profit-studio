# 第194章 粮食局的旧账本

夜色浓稠得像化不开的墨，城南巷的路灯昏黄，拉出几道歪斜的影子。苏荷送走顾长山和陶师傅时，已经不早了，远处传来几声犬吠，小王的仓库门口还亮着一盏白炽灯，他正和伙计把最后一麻袋面粉往三轮车上搬。

“苏老板，真按进价全收？”小王抹了把额头的汗，声音有点哑，“这批货压了我大半个月了，你要实在为难，折价也成。”

苏荷从口袋里掏出一张早就写好的单子，递过去：“进价多少，我照价给你。米面油我先拉走三成，剩下的存你仓里，我下个月分批过来取。账目我让苏桃记了，你回头跟她对。”

小王愣了两秒，喉结滚了一下，没有接单子，而是背过身去用力擦了把脸。他爹当年是被青江饭店逼得关了铺子的老面匠，他这间三号铺也是从那场风波里捡来的残羹，催收的人来了七八回，只有苏荷这个二十出头的小老板娘，站在他面前说“按进价全收”。

“苏老板，你这人情，我记一辈子。”他回身，声音平稳了，眼睛却有点湿。

苏荷没接这话，反而问了一句：“周建明催你腾退的时候，提没提过青江饭店的采购？”

小王想了想：“提过一句，说刘经理那边正好缺个供货的渠道，我要是愿意挂靠过去，铺子还能留着。我没答应。”

刘经理。苏荷心里把这三个字翻了个面。周建明收租权背后的人终于露了个边角，青江饭店的刘经理——国营饭店的经理，手能伸到粮库和铺面，说明他上面的关系至少能通到商业局那一层。

她回到小馆时，苏桃正趴在桌上算白天的账，算盘珠子拨得噼啪响。见她进来，抬头：“姐，顾大哥让我告诉你，粮食局仓储科的钱科长姓‘钱’不假，但人家已经退休半年了，现在仓储科管事的是个姓郑的副科长，据说是从商业局调过来的。”

苏荷眉心一跳。

顾长山凌晨托人带话，说钱科长确实是个老关系，但这人退了。姓郑的副科长——商业局调来的——这个节骨眼上，一个商业局的人坐到粮食局仓储科的位置，管着城东所有食堂粮站的配货权，这安排也太巧了。

第二天一早，苏荷没开张。她把铁锅交给新招的学徒看着火，自己换了件灰扑扑的旧外套，骑上二八大杠往城东粮库方向去。

粮库大院里，三轮车排成长龙，粮油味儿混着尘土直冲鼻子。她没挤出去，而是绕到院子侧面，一排平房是仓储科的办公室。门虚掩着，里面传来两个声音——

“……郑科，青江饭店那边的单子，下个月配货量还得加两成？”

“加，刘经理那边把招待所食堂也并过来了，量小不了。对了，原来那个老陈留下的出库单底子，都烧干净了没有？”

苏荷的脚钉在原地。

一阵风吹过来，把走廊尽头的一扇窗吹得哐当响。屋内沉默了几秒，另一个声音压低了些：“郑科您放心，老陈那些底账我早扔锅炉里了，一张纸都没留。”

苏荷攥着车把的手收紧，指节泛白。她正要退开，身后忽然传来一道陌生的男声：“哎，同志，你找谁？”

她回头，一个穿蓝布制服的中年男人正盯着她，眼神像秤砣一样压过来。苏荷的心跳猛跳了一下，但脸上一点不慌，她扬了扬手里的提兜：“我是城南巷小饭馆的，想问问下个月配货的价——不是说涨两成么，我来办手续。”

男人上下打量她，目光在她脸上的年轻劲和身上那件旧外套之间来回扫了两趟，终于侧了侧身：“前台在那边，别在这儿站。”

苏荷点点头，转身走。走到粮库院门口的时候，她回头望了一眼那排平房，后窗台沿上落着一张被踩了半脚、有些发黄的纸，风正掀起它的一角，露出半边墨写的字迹——“7月14，出库……四桌……”

她三步并作两步折回去，趁没人注意，弯腰捡起那张纸塞进衣兜里。纸有种潮乎乎的触感，还带着一点焦边。

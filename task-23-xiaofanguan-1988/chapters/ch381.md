# 第381章 香炉山上的老磨盘

次日清晨，苏荷把三百斤黄豆分出一百斤泡进大木桶，嘱咐徒弟们午前磨完做豆腐，又将小馆的事务交代给苏桃，便与顾长山一人一辆自行车，出了城南巷，沿着江堤往北走。

骑了约莫两个钟头，路面从石墁变成土路，远处一座青灰色的孤山轮廓渐渐清晰。香炉山果如其名，山尖微凹，两侧山脊对称展开，像一尊倒扣的香炉。山脚有一处荒废的采石场，乱石堆里残着半截石碾。

顾长山把自行车锁在一棵歪脖子松树下，率先踩着碎石上山。苏荷跟在后面，发现山路并不陡峭，但石阶上青苔厚得踩上去打滑，显然至少几年没人走过。她想起师父信里那句“井是他亲手封的”，心里紧了一紧。

半山腰处，一片竹林挡在路正中，竹林深处隐约露出一角青瓦。两人拨开竹枝走过去，只见一座小庙孤零零蹲在崖边，门匾上的字迹早已模糊，只辨得出“盐神”二字。庙门虚掩着，门轴转动的声响在寂静山林里格外刺耳。

庙内只有一间砖砌的堂屋，神坛上的神像缺了半边脑袋，香炉是座石头的，积了厚厚一层灰。苏荷绕着神像转了一圈，蹲下身，发现神像底座与石香炉之间有一道极细的凹槽，像是被人刻意凿出来的。

她掏出怀里那枚荷花纹铜钥匙，试着对准凹槽——

铜钥匙居然严丝合缝地插了进去。

苏荷屏住呼吸，石香炉缓缓转动，露出底下黑黝黝的洞口。一股干燥的土腥味扑面而来，还夹杂着极淡、极淡的盐味。

顾长山从后腰抽出柴刀，先一步跳下洞口。洞约莫一人高、两人深，底端垒着几只灰陶缸，缸口封着厚厚的黄泥。苏荷跳下来，手指摸过缸口的封泥——泥面上刻着一道荷花纹，与铁片、钥匙上的印记一致。

她撬开第一口缸，里面是半缸灰白色的粗盐，盐粒颗颗大如指甲盖，色泽均匀。

第二口缸，满满一缸晒干的辣椒，辣椒皮薄肉厚，放进嘴里嚼一下，辛香直冲鼻腔。

第三口缸……

她连开三口，全是上好的调料。苏荷心头猛跳，这些盐和辣椒太少见了，前世师父在国宴上的独门配方，其中一味核心调料至今无人仿出，正是用过这种颗粒粗盐腌制提纯的。她做梦都没想到，原料会藏在这里。

“井不是井，是地窖。”顾长山举着柴刀守在洞口，低声道，“你师父藏这些东西，几十年了。”

苏荷没有说话，目光落在洞壁最深处——那里嵌着一块青石板，石板上用钝物刻了两个歪扭的字：“慎密。”

她看了片刻，从怀里掏出那株红绳干黄豆，放在石板前，像上了三炷香。随即重新封好缸口，退上地面，把石香炉旋回原位，又用枯叶盖住痕迹。

“这一洞的盐和辣椒，够苏记用十年。”她说这话时声音平缓，但指尖微微发颤。

顾长山看了她一眼，没有戳破她的心事，只是道：“那梁文礼说的‘姓董的’，你怎么打算？”

“回城先找他。他既然挖过缸，未必不知道这地方。”苏荷把地图重新折好，“不过在那之前，我得更确定一件事——他当初挖城南巷的树根，是在找地窖，还是在找我师父这个人？”

两人下山时已是正午，日头当顶，晒得石阶冒起热气。苏荷跨上自行车，刚要蹬，却见山脚采石场那头，一个穿中山装的男人正背着手朝山上看。

是梁文礼。

他看见苏荷，远远地笑了笑，扬了扬手里一只旧藤箱，声音顺着山风飘过来：“苏老板，我找到一份旧档，是三十年前青江盐运的船簿。其中有几条船的终点填的就是这个香炉山。你师父当年的货，可不止几缸盐。”

苏荷的车轮停在原地。

梁文礼继续道：“你猜，那些盐最后进了谁的锅？”

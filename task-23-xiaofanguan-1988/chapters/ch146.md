# 第146章 西门货栈

天刚蒙蒙亮，苏荷就听见后院传来水桶落井的声音。她披上外衣推门，雾气里顾长山正赤膊往身上泼水，井水顺着结实的脊背淌下来，在晨光里泛着白气。

“这么早？”苏荷别过脸去。

顾长山扯过搭在肩头的毛巾擦了两把：“你不是说要去西门货栈？”

“也不急在这一时半刻。”苏荷嘴上这么说，脚下已经回屋去拿外套。灶上温着昨晚剩的骨头汤，她快手快脚地下了一碗面条，卧了个荷包蛋，端到桌上时顾长山正好进屋。

两人隔着八仙桌相对吃面，谁也没说话。面汤滚烫，喝到胃里却妥帖。苏荷放下碗，从怀里摸出那张折得方方正正的契纸，展开，又看了一眼那方朱红印章。

秦广德，光绪年间，城南巷荒菜地。

她把契纸重新折好，塞进贴身衣袋：“走吧。”

西门货栈在青江老城西边，挨着码头，早年是漕运的卸货点，后来铁路通了，货栈也就渐渐萧索。如今只剩两三间仓房还租出去堆些杂货，青砖墙上“西门货栈”四个字的漆皮剥落了大半，露出底下的木头本色。

苏荷推开半掩的木门，一股潮气扑面而来，混着麻袋和粮油的味道。一个五十来岁的瘦黑男人正蹲在门槛上抽烟，见有人进来，抬了抬眼皮：“找谁？”

“我找掌柜的。”苏荷道。

“我就是。”黑瘦男人又抽了口烟，眯着眼打量她，“姑娘是——”

“城南巷苏记小馆的，姓苏。”

男人手里的烟杆顿了一下，随即笑了笑：“苏老板？街坊都传苏老板年纪轻，没想到这么年轻。”

他往屋里让了让，把二人请进柜台后的小屋。屋里的账本堆了一摞，桌上一杆老秤，墙角码着几袋面粉。顾长山进门时扫了一眼仓房，脚步刻意放慢了几拍。

“前几日有人从你这儿提了三百斤精面？”苏荷开门见山。

男人一愣，随即摇头：“苏老板怕是听差了。我这儿半个月没进面了，哪来的三百斤——”

“冯四说的。”苏荷声音平缓，却盯着他的眼睛，“他说在你这儿看见一车精面拉走，往南去的。”

男人沉默了几秒，把烟杆往桌沿磕了磕，忽然笑了：“苏老板，实不相瞒，那车面不是我的。是有人借我这个地界过一下货，给了三块钱场租。我就一开货栈的，人家拿钱来租地方，我不能不接吧？”

“什么人？”

“戴灰帽子，瘦高个。”男人说着，神色有些闪烁，“听口音不像本地人，像南边来的。”

苏荷和顾长山对视一眼。灰帽子，又是灰帽子。

“他租了多久？”

“就那一回。”男人摆手，“再没来过。”

苏荷没再多问，谢过便出了门。站在西门货栈门口，晨风从码头上刮过来，带着鱼腥气和水汽。顾长山落在她半步后，低声说：“他在撒谎。”

“你也看出来了？”

“那几袋面粉。”顾长山点了根烟，“都是新面，麻袋还没压实，是最近才装的。如果他半个月没进面，那墙角的袋子哪来的？”

苏荷脚下一顿，回头望了一眼那扇半掩的木门。晨光里，黑瘦男人正站在门框边目送他们，见她回头，咧嘴笑了笑，露出一嘴黄牙。

她收回视线，正要说话，巷子口忽然传来一个声音——

“苏荷。”

声音不高，却让她整个人定在了原地。那是她前世师父的声音，苍老，低沉，像砂纸磨过木头，可每一个字她都认得。

她猛地转头。巷子口，一个穿灰布褂子的老头正站在那里，手里拄着一根拐棍，隔着几十步远看着她。

晨雾未散，他站在雾里，像鬼魂一样不真切。

苏荷张了张嘴，喉咙里却像堵了一团棉絮。顾长山上前一步，警觉地盯着来人：“这位大爷，你找谁？”

老头没看他，只盯着苏荷，又喊了一声：“苏荷。”

这一次，苏荷听清了。是老陈师傅的声音。她前世在厨房里跟了十几年的老师傅，三年前去世，骨灰是她亲手捧进墓穴的。

可他现在就站在巷子口，活生生的。

她迈开腿，朝他走过去，走了三步，老头却转身就走，拐棍点着青石板，笃笃笃，一步一步往巷子深处去了。

“站住！”苏荷拔腿就追。

她跑出西门货栈那条短巷，拐进一条更窄的民巷，追出去五十步，老头不见了。

晨雾弥漫，巷子空荡荡的，只有墙角一只花猫歪着头看着气喘吁吁的她。

苏荷站在原地，胸口剧烈起伏，手心全是汗。她低头看了一眼自己的手——那是她十八岁的手，细白，指腹却已经因为她这几个月颠勺起了薄茧。

她缓缓转身，顾长山正追上来，看她脸色，拧着眉问：“怎么了？那是谁？”

苏荷张了张嘴，想说“我师父”，却知道这话没法出口。她只是摇了摇头：“认错人了。”

可她的手还在抖。

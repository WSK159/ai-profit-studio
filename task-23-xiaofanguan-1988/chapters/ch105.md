# 第105章 白水门的雨

夜里的风带着江水腥气，从铁匠巷的瓦缝里钻进来。苏荷没点灯，就着灶眼里的余火坐着，手里攥着一截铅笔，在纸片上涂涂划划。那张借条她翻来覆去看了三遍，确认是沈其昌的笔迹无异，但借条上的日期，是上个月十二号。而上个月十二号，沈其昌应该在青江，不可能在省城。也就是说，这张借条不是沈其昌亲自写的，是有人仿的。

那个自称老赵的人说是老朋友，可她前世没听沈其昌提过这么一号人。她心里有了症结，便没真把瓦罐给他，只说了句“东西不在手上，在码头的寄存处”，约他明早再取。那人倒不急，笑着应了就走了。

她等到半夜，巷子里传来脚步声——两短一长，和顾长山约好的暗号。苏荷起身抽开门闩，顾长山闪身进来，外套湿了半边，头发上挂着水珠。外头不知什么时候落起了雨。

他没等她开口，先伸手挡了一下，压低声音说：“沈其昌明天凌晨四点，从市局转省二监，押解车走堤后那条土路，路过白水门。那边的岗亭里，王顺德安排了人。你要是想动手，只有白水门到三号桥那一段，押解车过闸门的时候要减速。”

苏荷盯着他：“什么叫‘要是想动手’？他不是你安排去乡下的吗，怎么落到市局看守所里了？”

顾长山沉默片刻，才说：“周诚到乡下第三天就被人探到行踪，连夜转移。沈其昌本来在安全屋住着，但王顺德的人找到了那间屋，搜出一袋白面两瓶酒，就把沈其昌当同伙带走了——名义是‘窝藏赃物’。”

苏荷一口凉气吸进肺里，手指捏紧了铅笔。“他的账本，我藏了。可账本上用锅灰涂的是第三笔，白水门那笔是后来添的，笔迹对不上。沈其昌是被人算计了——王顺德把第三笔账嫁祸到白水门，是想让沈其昌顶替那粮站案的主犯。”

顾长山眼神沉了沉：“你确定？”

“我确定。”苏荷把纸片推到灶台上，“那笔字不是沈其昌写的。他记账‘斤’字从来不带撇，可白水门那笔，‘斤’字带了一撇。有人仿了他的笔，但仿不了他的习惯。”

顾长山垂目看了纸片半刻，点了一下头：“那我俩在天亮前把这事办了。”

“怎么办？”苏荷问，“你一个街道办干部，我一个开饭馆的，劫囚车？”

顾长山从上衣内袋掏出一张叠得齐整的纸，展开，是份便笺，盖着青江市个体劳动者协会的章，写着“兹介绍顾长山同志赴省个体协会工作，办理业务，请有关单位协助为荷”。他拿笔在“业务”二字下划了一道：“我明天早上要去省城个体协会送材料。个体协会的办公地点，就在三号桥桥头，白水门过去两条街。押解车过白水门的时间，是五点二十。”

苏荷明白了。她看了他片刻，忽然笑了笑：“你胆子不小啊。”

顾长山没接话，只把便笺收回内袋：“你明天该干什么干什么。白水门那边，我有人。你只需要把那个瓦罐里的东西——真的账本，在押解车过闸门之前送到三号桥个体协会传达室，有人接应。”

“那玩意儿是铁证，落到外人手里，沈其昌更翻不了身。”

“我知道。”顾长山看着她，“所以我不会让它落到外人手里。接应的，是我在部队的战友，现在是省局的人，姓韩。”

苏荷沉默了一会儿，把瓦罐从灶台底下抱出来，解开布条，抽出那半本账本，又扫了一眼最后一页。那个“斤”字的一撇，在灯光下像一柄小刀，扎一眼就不舒服。她把账本合上，塞回瓦罐，又想了想，从灶台后面翻出一包干辣椒，掰碎了混进瓦罐底，再盖好。

“东西放传达室，也得让沈其昌知道，有人替他把命捏在手里。”她抬起头，“你那个姓韩的战友，多带两个人。白水门的雨，不会小。”

顾长山深深的看了她一眼，没有再多说，转身掀开门帘，走进雨里去了。

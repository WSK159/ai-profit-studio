# 第115章 以假换真

老赵是坐着一辆黑色桑塔纳来的。

1988年的省城，桑塔纳比大熊猫稀罕。铁匠巷的街坊们隔着窗户瞟眼，谁也不敢靠前。车停在那间租来的旧砖房门口，后座门开了，老赵慢腾腾地下来，还是那身灰中山装，袖口却换了副新钉的有机玻璃扣子，在雨后的太阳底下亮得刺眼。

苏荷在屋里。她没出门迎，坐在桌边剥蒜——一汪子蒜皮撒在油纸上，满屋子都是辛烈的气味。老赵推门进来，她抬了抬头：“赵老板，吃了吗？灶上焖了碗臊子面。”

老赵在门槛上顿了顿。他显然没料到她这么镇定，但脸上很快缝出一种笑模样：“苏老板心宽。我不吃面，我收了东西就走。”

“那就坐下喝口茶。”苏荷把蒜瓣扔进碗里，起身去拿暖水瓶，“我说赵老板，你也跑了三趟了，不就是为了那几页账吗？值得你这么大老远地跟个摆摊出身的姑娘较劲？”

老赵正往怀里掏东西的手顿住了。他倒不急着拿出手里的东西了，反而撩起后襟坐下，双手搁在膝头，姿态松弛，像猎人跟猎物周旋时的从容：“苏老板是个明白人。那我也不绕弯子了——账本，你给了经侦二科的人。你今天上交，今天沈其昌就能放出来；你要是留一手，我这边有的是办法让人多关他十天半月。”

苏荷倒了杯水放到他面前，又给自己倒了一杯，没接他的话，抿了一口说：“赵老板，您知道我在铁匠巷这几天，天天去巷口那家人头攒动的黑白电视机铺子跟前站着看吗？看‘新闻联播’，看‘最高法工作报告’，看那些宣判某省某局局长受贿多少万的新闻。我心里头就在想——1988年了，全国上下都在摸石头过河，可河里头的鱼还是知道往哪游的。”

老赵的脸色变了变。

苏荷把茶杯放下，从灶台底下抽出一只木匣子来。匣子是昨天让韩兵帮她寻的，桐木，四角包着黄铜，古雅得很，里头垫着红绒布，正中躺着那本账本。但只有她知道，里头装的是韩兵连夜替换的一份抄录件，笔迹找省城刻章的老先生仿的，九成相似，唯独最后一页少盖了半个水印。

她当着老赵的面把匣子打开，翻了翻，又合上，往前一推：“赵老板，您要的东西在这儿。但我有一个条件：沈其昌放出来的当天，您走您的阳关道，这账本归你。在那之前——您要是再派人动沈其昌一根头发，我就把账本送到省纪委去，反正经侦二科的路子我也搭上了。您掂量掂量。”

老赵盯着那只木匣。屋里安静得很，剥下来的蒜皮在窗缝漏进来的风里打着旋。他霍地笑了，笑得很浅：“苏老板，你比我想象中有胆气。”

他一伸手，把木匣捞进公文包，起身就走。走到门口，他忽然停下，侧过头来，声音很低：“不过我得提醒你一句——王顺德调任青江，不是冲你的饭馆来的。他是冲着，你家老宅底下那块地去的。”

门在他身后合上。苏荷站在原地，右手按住缝在棉袄里的那两页真账本，左手指尖微微发凉。铁匠巷的口往上，一辆漆黑的桑塔纳碾过积水，拐过弯，消失了。

她低头看了一眼灶台上那碗还冒着热气的臊子面，轻轻朝外头喊了一句：“顾队长，出来吧。戏演完了。”

屋后窗台底下，顾长山翻窗进来，裤腿沾着泥水，双手抱臂，看她：“你当真把账本给他了？”

苏荷一笑，把那两页缝在棉袄里的纸抽出来晃了晃：“他拿走的那个，本来就是韩兵按着原样抄的赝品。真的——”她顿了顿，“等沈叔出来，才算真的。”

窗外雨停云开，一道金线穿进屋来，照在那只空了的木匣沿上。顾长山盯着她看了半晌，忽然低声说：“你刚才那句话……老宅底下的地，是什么意思？”

苏荷嘴角的笑意收住了。她没答话，俯身从灶灰堆里扒出一块被烧掉半边的地契角——那是她临走前从家中的灶膛底子里挖出来的，被油纸裹着，只露了一个“青”字。

“顾队长，”她抬起头，眼里有光，“我要先回去一趟——趁那口锅还在。”

# 第173章 四十捆橡胶管

仓库门半掩着，里面只吊着一只昏黄的灯泡，光被熏得发黑。苏荷贴着墙根绕到仓库侧面，那里有一扇破了一半的窗户，用塑料布糊着，她指尖轻轻挑开一条缝。

何承业站在一张旧木桌前面，他三十出头，皮肤黝黑，眉骨高，颧骨上也带着刀刻似的线条，看着就是个常年跑水路的人。他手边码着四摞东西——用粗麻布包着，扎得紧紧的，露出一截深灰色的橡胶管口。

“点数。”何承业对那蓝布工装的男人说。

那贩子蹲下来，一根一根地翻。苏荷数了个大概，四十根，没错。

“货齐了，不过……”那贩子站起来，擦了一下额头的汗，“何老板，省城那边的行情变了，听说前几天查了一批。”

何承业目光一沉：“谁那边的？”

“城南三舅的线。”

“三舅的线关我什么事。”何承业声音硬邦邦的，“我这批是军区后勤的订单，手续全，查不到我头上。”

苏荷听到“军区后勤”四个字，心跳猛地加快了。她之前让人放出去的风声，果然传到了何承业耳朵里。这人是做生意讲门面的，现在听说省城军区路子要紧，他自然要往这上面贴。

她深吸一口气，趁着那贩子低头捣鼓帆布包的功夫，从暗处走出来，直接推开了仓库门。门板“吱呀”一声响，何承业猛地抬头，手已经伸向腰间。那贩子也吓了一跳，差点把包扔了。

“谁？”

苏荷摘下帽子，露出脸。何承业盯了她两秒：“女娃？你来干什么？”

“何老板。”苏荷往屋里走了一步，“我就直说了——省城军区那批后勤订单，现在姓苏。”

何承业的眉毛挑了一下。他的目光在她脸上停住，又上下扫了一遍，像是要从她身上看出个真假来。“谁家的女娃？口气不小。”

“城南巷，苏记小馆。我师父是唐玉昆。”苏荷声音平平稳稳，“您应该听说过我师父以前的名号。”

何承业脸上没什么表情，但他握着腰的手松开了。这细微的变化没有逃过苏荷的眼睛。唐玉昆三个字，在青江水路上是有分量的。

“唐玉昆的招牌是饭馆，不是军需。”何承业说得很淡，但语气里已经有了试探的意思。

苏荷不紧不慢地说：“橡胶管的规格我能说出来的型号，比您场子里那批货单还全。您这批是HN-14型。”她顿了一下，“今年橡胶出口配额涨了百分之三十，省城那边的工地开工缺货，军区家属楼正好在翻修，这个节骨眼上，您这四十捆橡胶管正好对口。”

何承业沉默了三秒，眉间的警惕慢慢地换成了另一种审视的神情。他的手指敲了敲桌面，终于开口：“你一个人来的？”

“一个人。”

“你的条件。”

苏荷往前走了一步：“材料款七折，但我要跟您走一趟省城的线——我想见见您上家那位管后勤的人。”

何承业眯起眼睛，盯了她半晌，忽然笑了：“你胆子不小。”

他没说答应，也没说不答应，弯腰从桌底捞起一只铁皮盒，放到桌面上，掀开盖子，里面躺着一叠大团结。他抽出三分之一推到苏荷面前：“订金两百。明早九点，船在老庙口靠岸，你带条子来提货。”他顿了一下，又补了一句，“你一个人来。”

苏荷伸手接过那叠钱，指尖能感觉到纸币粗糙的底纹。她正要点头，仓库后门突然被人擂响了——“砰、砰、砰！”三声，又急又猛。

何承业脸色骤变。苏荷的后背炸开一层冷汗，她的目光扫向窗户，窗外晃动着两道黑影，手上提着的，分明是手电筒——和一截黑漆漆的铁管。

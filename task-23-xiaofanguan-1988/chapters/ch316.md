# 第316章 井底乾坤

城南巷老宅的那口井，已经枯了快二十年。

苏荷站在井沿边，手电筒的光柱直直打下去，只见井底淤积着厚厚一层灰泥，几块碎砖歪歪斜斜地散落在泥里，看不出任何异样。顾长山蹲在井口，探手摸了摸井壁的青苔，眉头微拧。

“这井壁的砖缝不对。”他低声说，“靠北那一面，砖缝里的灰浆颜色比别处新。”

苏荷心里一紧。老宅这口井她是知道的——前世里她在这条巷子住了十几年，从未听说这井里有什么文章。可周三昧那本蓝布册子上写得明白：“井中有井，藏于瓮底。”她当时以为说的是井底埋着水瓮，现在看来，怕是整口井都是个障眼法。

“下去看看。”苏荷说着就要往井口探身，被顾长山一把拉住。

“我下。”他不由分说地脱掉外套，露出里面深灰色的粗布衬衣，将手电筒咬在嘴里，撑着井壁的砖缝往下滑。苏荷心里一热，没再多说，只把手电筒的光稳稳地照着井底。

顾长山落到井底，鞋底踩在灰泥上，发出一声闷响。他蹲下身，用指节叩击地面，一块一块地敲过去。敲到北面第三块砖的时候，声音突然变得空洞起来。

“有夹层。”顾长山抬起头，手电筒的光照在他脸上，棱角分明的下颌线蒙着灰。

苏荷的心跳快了一拍。她从井口探下身子：“砖撬得开吗？”

顾长山没答话，从裤兜里摸出一把折叠刀，沿着砖缝剔了一圈灰泥。灰浆虽然是新填的，但到底是湿泥混了石灰，经年累月已经发干发硬，他费了十来分钟才把那块青砖撬起来。

砖下是一个半尺见方的凹槽，里面放着一只黄铜盒子，巴掌大小，沉甸甸的，盒面錾着缠枝莲纹，锁孔朝上，锈迹斑斑。

顾长山将铜盒递给苏荷，又从井底爬上来。苏荷接过铜盒，掂了掂分量，心里转过几个念头。她摸出钥匙——就是井底石室里那根铁钥匙，杆上弯着一截兽骨的那把——往锁孔里一捅，竟然严丝合缝地插了进去。

“咔嗒”一声脆响，铜盒的锁簧弹开。

盒盖掀开，里面是一张对折的牛皮纸，纸面泛黄发脆，边角被虫蛀了几个细洞。苏荷小心翼翼地将纸展开，借着灯光看去，上面是一笔极工整的小楷：

“立分书人周明善，周门三代积产，今析为两股。城南老宅、味香居铺面及井中物，归次子周三昧；青峰岭下十里山地及镇中杂货铺，归长子周文祥。另有金条三十一条，分埋三穴，一穴城南巷老宅井底，一穴青峰岭下，一穴镇北土地庙后。此三穴之图，藏于次子之手。老宅地砖下另有账册一册，为周门底账，须由承继人亲启。恐后世子孙争产，立此为凭。民国三十六年腊月。”

苏荷看完，只觉得后脊梁一凉。

分家书写得清清楚楚：金条三十一条分埋三穴，一穴在老宅井底，一穴在青峰岭下，一穴在镇北土地庙后。而周三昧的蓝布册子上只记了“三十一条，分埋三穴”，却只详细标了一穴的位置——就是青峰岭下那处。至于另外两穴的具体方位，册子上只有一句“以分书为凭”。

“这老狐狸。”苏荷低低骂了一声，嘴角却翘起来，“周三昧把图藏进分家书里，分家书又锁在井底铜盒里，钥匙却留在石室那口箱子里。一环扣一环，要是没有那把铁钥匙，就算找到了这个铜盒也打不开。”

顾长山看着她手里的牛皮纸，沉声道：“那另外两穴——井底和土地庙后头，都在这分书上写明了？”

苏荷点头：“井底这穴，他说了‘藏于瓮底’。可我们从井底的石室进去，也没见着什么瓮。”她顿了顿，忽然手电筒朝井底又照下去，“除非——那瓮不是埋在井底，是藏在井墙里。”

顾长山眼神一凝。

苏荷又细看他一眼，声音低下来：“分家书落款是民国三十六年腊月，可周三昧的账册上，最后一条记录是民国三十八年春。”

民国三十八年，就是1949年。这中间隔了整整一年多。

“分书写完那会儿，周家还没散。周三昧后来又在账册上记了三十一条金条的事。”苏荷将分书重又折好，小心收进怀里，“他说‘一穴城南巷老宅井底’，但没画图。分家书上写的方位，跟他说的对不上——分书说金条分埋三穴，周三昧账册里也写三穴，但这两个‘三穴’的位置，可能并不一样。”

顾长山眉梢一挑：“你是说，分书里的三穴，和账册里的三穴，不是同一批？”

苏荷笑了一下：“老周家这两兄弟，互相防了一辈子。周三昧的账册记的是他自己埋的那批，分家书是周明善写的——那是他爹，他想留给两个儿子各一份。可周三昧改过那笔账。”

她的手插进口袋里，指尖碰到那根铁钥匙冰凉的杆身。

“宋千山说他哥宋文起已经找到了两条金条，第三条线索指到这口古井。”她慢慢说，“可宋文起找到的那两条，怕不是他想要的那两条。”

她抬起头，目光穿过沉沉夜色，望向城南巷尽头那片尚未拆迁的旧屋。

“青峰岭下那一穴，怕早就空了。”

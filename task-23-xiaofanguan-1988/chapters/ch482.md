# 第482章 渡口夜探

寅时的青江渡口，雾气从江面漫上来，像一层化不开的薄纱。

苏荷提着一盏铁皮灯站在东岸老樟树下，灯芯已换过三回，火苗却稳得像是生了根。她低头看着树根处露出的铁杆——生了厚锈，却仍能看出锻造时留下的锤痕。铁杆顶端有个方形卯口，与董老头给的乌铁短棒正正相合。

她没有急着插进去，先蹲下，用指腹擦过铁杆侧面。那里有道浅浅的刻痕，像是被什么锐器划过，又被人欲盖弥彰地磨平过。但苏荷前世摸过的刀比摸过的筷子还多，一眼认出那是一道“一”字刻痕，柳家标记。

“你来早了。”

身后传来沙哑的声音。苏荷回头，老船夫靠在渡口石阶上，手里攥着旱烟袋，烟锅子里的火星在雾里明灭不定。他没看她，只是望着江心：“今晚江水流得急，河底的东西怕是也坐不住。”

苏荷站起身：“您知道我来干什么。”

“不知道。”老船夫磕了磕烟灰，“但我知道，十年前有个姓柳的，也是寅时站在这棵树底下。他挖了三天，走的时候手上有血，眼睛里也有血。”

苏荷捏紧乌铁短棒：“柳春来。”

老船夫没接话，只把烟杆往腰后一别，转身慢慢往渡船上走。走了两步又停下，头也不回地说：“铁杆底下压的不是铁链，是根绳。别使蛮力，顺着劲儿来。”

苏荷看着他的背影消失在雾里，深吸一口气，蹲下身，将乌铁短棒插入卯口。咔嗒一声轻响，短棒上的纹路与卯口内壁的刻痕严丝合缝地贴合。她试着转动，铁杆纹丝不动，但杆身底部的泥土却在微微震颤。

她俯下身，耳朵贴着铁杆。地下传来闷响，像有什么东西在深处翻了个身。她继续发力，顺时针拧动，约莫过了半盏茶功夫，铁杆终于转动了半圈。随着一声闷哑的机关响动，树根旁的泥土塌下一尺见方，露出一道石砌的斜坡入口。

一股陈旧的、带着水腥气的风从洞口涌出。苏荷提灯照下去，石阶长满青苔，阶面上散落着几枚铜钱和一个空碗。碗底积着半碗水，水面上浮着一瓣干枯的梅花。

她蹲下身，捡起那瓣梅花捏碎——是纸做的。

苏荷心头一紧，从怀里摸出问味灯上那枚旧铜钱，与碗边的铜钱一比对：同款，同铸，同一个模子。这碗和铜钱，是有人早就放在这儿的。是谁？放了多少年？

她没有急着下去，把碗翻过来，碗底用指甲刻着两个歪扭的字：“等人”。

苏荷把碗放回原处，深吸一口气，提着铁灯踏下石阶。洞内空气沉闷，石壁上有水珠渗出，每一步都回响着空旷的滴水声。大约走了一丈深，石阶到了尽头。眼前是一间丈许见方的石室，正中摆着一个半人高的陶缸，缸身上缠着一圈铁链。

缸盖是石板，石板上刻着半句话：“水养人，味养水。”

苏荷伸手推石板，纹丝不动。她绕着缸走了一圈，发现缸底压着一只油布包袱。拆开，里面是一本账册，封皮写着“柳氏水记——庚午年”。翻开来，密密麻麻记着青江各渡口的水位、流向、泥沙量，有些数据细致到每一日、每个时辰。

她正要细看，突然听见头顶传来一声闷响——洞口被人封住了。

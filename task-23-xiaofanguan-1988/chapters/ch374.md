# 第374章 夜探酱菜厂

子时刚过，青江城的灯火已经灭了大半。苏荷裹着顾长山那件旧军大衣，蹲在城墙根的阴影里，望着百米外老酱菜厂那道锈迹斑斑的铁门。

“你说那秃顶老头的话，能信几分？”顾长山蹲在她身侧，声音压得极低。

苏荷没有立刻回答。她手里攥着那张焦边牛皮纸，月光下能看清“董宅正房梁上，三尺见方，铜皮裹之”那几个铅笔字。笔迹歪斜，却透着一股用力过猛的狠劲，像是写的人在赌命。

“他没必要骗我们。”苏荷终于开口，“郑家欠董家‘用命填的账’，他要是想害我们，直接让草帽人动手就行了，何必绕这么大弯子。”

“那草帽人又是谁的人？”顾长山皱眉。

“天亮之前，自然会知道。”苏荷把牛皮纸折好塞进内衣口袋，站起身来，“走吧，趁着子时三刻还没过，先把梁上那东西取出来。”

两人沿着城墙根绕到董宅后巷。董宅比邻老酱菜厂，中间隔着一道一人高的土墙，墙上爬满枯藤。顾长山助跑两步，单手一撑墙头，翻身而过，动作利落得像是刻进骨头里的本能。苏荷把裙摆往腰上一系，学着他的样子翻了过去，落地时脚踝一阵刺痛——前些天跑路时崴的伤还没好利索。

正房在院子正中，三间青砖大屋，门板上的漆剥落了大半，露出灰白的木纹。苏荷推开虚掩的房门，一股陈年灰尘和霉味扑面而来。月光从窗纸的破洞漏进来，地上一层薄薄的灰，没有脚印。

“梁上。”顾长山抬头。

正房大梁横跨三间，粗得两人合抱。梁柱交接处有一块颜色略深的木料，像是被常年摩挲过。顾长山搬来一张八仙桌垫脚，踩着桌面够到了大梁，手指在梁面上摸索了一遍，摇了摇头：“没有缝隙，看不出有暗格。”

苏荷眯起眼睛。她在2026年做过一个私房菜项目的旧宅改造，对老建筑的结构比普通人有数。梁上的暗格若做得巧妙，表面往往看不出痕迹，但承重交接处会有细微的位移。她忽然想起那枚铜簪上的半开荷花纹——铜簪是从梁上铜皮裹物里掉出来的，那铜皮裹物本身就是一个开合的机关。

“你敲一敲梁面，从东往西数第三根横梁。”苏荷说，“铜皮裹的物件多半嵌在梁身里，从侧面开合。”

顾长山依言换了个位置，手指在梁面上轻轻叩击。叩到第三声时，声音忽然从沉闷变得空洞。他眼睛一亮，用指甲沿着那一小块木料的边缘抠了抠——果然有一道极细的缝隙。他掏出随身带的小刀，撬了几下，那块木料“叭”的一声弹开，露出一个尺把长的凹槽。

槽内躺着一只铜皮裹边的小木匣，巴掌大小，上面挂着一把拇指大的铜锁，锁孔里插着一柄只有半截的铜钥匙。

苏荷爬上桌面，从他手中接过木匣。钥匙插在锁孔里像是原本就配好的，她轻轻一拧，“咔哒”一声，锁舌弹开。掀开匣盖，里面是一卷油纸包裹的东西。油纸已经发黄发脆，边角碎裂，苏荷小心地揭开——里面是一张叠成方形的绵纸，纸上密密麻麻写满了小字，字迹同那半张焦边牛皮纸背面的铅笔字明显是同一人的手笔。

纸上写的是一段往事。苏荷就着月光一个字一个字地读下去，脸色越来越凝重。

这张绵纸记录的，是郑国栋查私盐账的前因后果。纸上的字迹虽然凌乱，但每一条线索都指向一个人——董青山，当年青江城盐务司的师爷。董青山表面上是郑国栋的至交好友，暗中却与盐枭勾结，虚报账目，私吞税款。郑国栋察觉后，董青山先下手为强，将他扣押在酱菜厂的账房里，用一坛加了料的老酒将他毒哑，又从江北雇来打手，把郑国栋装进麻袋投了青江。

郑国栋沉江前，在账房的老缸暗格里留下半张账页，又托一个信得过的伙计，把这份绵纸藏到董宅正房梁上。他料定董青山不会拆自己家的房梁，而这东西总有一天会被人发现。

“郑国栋的父亲……”苏荷喃喃念出纸上的最后一行字，“曾在清廷内务府当过差？”

“内务府？”顾长山挑眉，“那可不是普通人家。”

苏荷把绵纸小心地折好收进怀里。她本想再多看几眼，但月色偏西，已经过了子时三刻。她刚要把木匣放回暗格，指尖忽然碰到匣底，触感不对——匣底垫着一层极薄的棉絮，棉絮下面似乎还有东西。她掀开棉絮，底下露出一张叠成四方形的纸条，颜色比绵纸新一些，字迹也不同，歪歪扭扭的，像是用没蘸饱的墨写的：

“四十八口缸，三十五口在城东老酱菜厂底下。打开那间靠墙的窖，窖底第三块砖下有条暗道。但别在白天去，天亮前必须取出来。有人等不急了。”

落款是一个用指甲刻出来的荷花瓣。

苏荷握着纸条的手指微微收紧。那个荷花瓣的刻法，与铜簪上的纹样一模一样——这纸条是铜簪的主人留下的。也就是说，这枚铜簪的主人，知道这张绵纸、知道梁上暗格、知道四十八口缸的下落，甚至知道有人等不及了。

而且，他/她把钥匙插在锁孔里，就等着苏荷来取。

她抬头看向顾长山：“你刚才说，草帽人传话‘天亮有人动手’？”

“对。”

苏荷把纸条连同一并收好：“那我们今夜就去城东老酱菜厂。天亮之前，把三十五口缸的下落弄清楚。”

“你确定？”

“确定。”苏荷说，“那秃顶老头提醒我们‘不可当众打开’，草帽人警告‘天亮有人动手’——他们都在争时间。谁先拿到缸里的东西，谁就占先机。”

两人闪身出了董宅，沿着空无一人的小巷往城东方向疾走。月光斜照，把两个人的影拉得又长又瘦，像是两根并排插在土里的筷子。

走到老酱菜厂后墙外时，苏荷忽然停住脚步。她闻到一股若有若无的草腥气——和那天夜里在苏记后院闻到的一模一样。她回头看了一圈，巷子里空无一人，连只野猫都没有。但那草腥气就在空气里悬着，若有若无，贴着鼻尖掠过。

她的心猛地沉了下来。有人比他们先到了。

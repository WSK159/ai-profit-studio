# 第242章 老井与锁

腊月二十一，天刚擦亮，苏荷就起了身。

灶间铁锅里的水还温着，她舀了一瓢洗脸，冰水刺得人一个激灵。今儿要去老井，那口锁的事拖了三天，不能再拖了。

苏桃已经坐在灶台边，手里攥着那枚从地窖里翻出来的铜钥匙，指甲盖大小的铜面上錾着两个字——“味”和“香”，笔画遒劲，像是老匠人一锤一锤凿出来的。

“姐，我跟你一块儿去。”

苏荷看她一眼，没拒绝。这丫头心细，上回河滩那一趟，比她这个活了两辈子的人还管用。

老井在城南巷尽头，一口青石砌的井台，井圈上勒出一道道绳痕，深得能嵌进指节。打苏荷重生回来那天起，这口井就枯了，井口压着一块厚实的青石板，石板上落满灰，像是许久没人动过。

苏荷蹲下，手指抹过石板边缘——灰是新的。

有人掀过。

她眉头一紧，转头问苏桃：“这石板，你动过？”

苏桃摇头：“我连碰都没碰。”

苏荷站起身，四下看了看。巷子两头没有动静，早起的只有隔壁院里那只老母鸡，咕咕叫着刨土。她吸了口气，弯腰去抠石板边缘。

石板比她预想的重，是那种老料青石，少说七八十斤。苏荷使了把劲，石板纹丝不动。苏桃要上来帮忙，被她用手肘挡开：“你站远些，别压着你。”

她深吸一口气，蹲稳马步，双手扣住石板边沿，一咬牙——“起！”

石板掀开一条缝，底下漏出一股阴潮的气味，像多年没通风的地窖。苏荷再一使劲，把石板整个翻到一旁，井口黑洞洞地露了出来。

井口不大，她趴下去，往下看。枯井三四米深，井底散落着几片枯叶。井壁上长着一层暗青色的苔藓，靠北面的砖壁上，有一块砖的颜色与周围不同——更深、更沉，像是浸过油。

苏荷掏出那枚铜钥匙，在手里掂了掂，再看向那块砖，心里有了数。她回头看了眼苏桃：“你在这里守着，我下去。”

苏桃急道：“姐，万一底下有事——”

“能有什么事？”苏荷已经翻身下了井口，脚尖踩进井壁上凿出的蹬窝，是供人下井清淤用的，“你把石板拉回去半截，我在底下喊你你再打开。要是有人来，你就唱歌，唱大声点。”

苏桃攥着钥匙，重重点头。

苏荷踩实了第二处蹬窝，往下落了半米，伸手去够那块深色砖。指腹贴上砖面，冰凉的触感传来，砖缝里嵌着干结的灰浆，一看就不是近几年抹的。她用手掌按了按，砖纹丝不动。

她皱皱眉，从腰间摸出那把铜钥匙，翻了个面。背面没有字，光秃秃的铜面上，镌着一朵缠枝莲花的半朵——与地窖里那枚铜扣上的纹样一模一样，只是这边是左半，那边是右半。

合起来，正好一朵。

苏荷心头一明，将钥匙插进砖缝一侧，缓缓转动。咔哒。

一声轻响，那块砖竟向内陷了半寸，像被什么东西卡着。苏荷将铜钥匙拔出来，又摸了一遍砖面，指尖触到一条几乎看不出的竖缝——砖不是砖，是一道暗门。

她正要推，井上传来苏桃的声音，脆生生的：“大妹子——你这是干什么呢——”

唱起来了。苏荷的动作顿住。

紧接着，一个男人粗哑的声音从井口上方滚下来：“小丫头，你家大人呢？这井板怎么掀开了？”

苏荷屏住呼吸。

那人的脚步声在井台上顿了顿，又踩了踩，然后传来一声嘀咕：“……怕是这井里藏了宝吧。”

苏桃的声音更响了些：“叔，这井是我家打算淘两筐沙填平，盖间小房呢。大人去街口买石灰了，一会儿就回。”

那人沉默了片刻，脚步声才慢慢走远。

苏荷松了半口气，却没急着推开暗门。她想再等一等。

果然，半分钟后，脚步声又折了回来。那人站在井口，往黑乎乎的井底看了一阵，扔下一团烟头，骂了句“穷鬼”，这才彻底走了。

烟头落进井底。苏荷低头一看——半截过滤嘴，泛着焦黄，烟身上印着外文字样。

又是进口烟。

她抬头望了望井口的光，嘴角抿成一条线。这两天，盯着这口井的人，不止她一个。

她收回视线，手掌贴上那块陷下去的砖，用力一推。

砖面无声滑开，露出一个狭小的壁龛。壁龛里没有金银，只放着一个油纸包，和一个罐子。罐子是青瓷的，釉色温润，让她想起师父留下的那口茶罐。

苏荷伸手，先拿起油纸包，拆开一层，又一层，三层油纸裹着。剥到最后，里面是一卷泛黄的纸，边缘已经脆得发皱。

她抖开纸。

是一份契书，落款处写着两个名字：苏贵山、林秀英。

苏荷的手一紧。这是祖父和祖母的合契——不是房契，是一份“嫁妆单”，列着一排东西：铁锅一口、铜锁一对、窖藏米酒若干，末了一行字，写得潦草——

“若后人问起，锁在井中，钥匙在香里。”

苏荷捏着纸条，喉头动了动。

“钥匙在香里”？

她猛地想起地窖里那坛米酒，酒坛盖上蒙的布，浸过香料，微微泛着桂花的气味。她当时没多想，只当是陈年的坛子味。可那股香，分明是有人特意揉进布里去的。

钥匙……在香里？

她把油纸和契书仔细收进怀里，又看向壁龛深处剩下的那口青瓷罐，伸手轻轻揭开罐盖。

一股陈年茶香扑面而来。

罐底，静静躺着一把铜钥匙，样式与地窖那把几乎相同，只是钥匙柄上錾着的字，是两个——“回”与“归”。

苏荷怔住了。

味、香、回、归。四把钥匙？她手上只有两把，剩下那两把，一把在宋莉手里，另一把……

她听见井上苏桃大声喊：“姐——石灰买回来啦——”

苏荷将铜钥匙收回怀中，盖上青瓷罐，把砖复位，蹬着井壁爬了上去。她拍拍膝盖上的泥，朝苏桃微微点头，声音压得极低：“回去说。”

苏桃心领神会，姐妹俩合力把石板归位。灰扑扑的石板上，只留下刚才那道掀动的指痕。

她瞥了眼地上那截烟头，趁没人注意，弯腰捡起来，攥在手心。

回铺子的路上，苏荷把契书上最后那句话在心里过了一遍又一遍。

钥匙在香里。那米酒，是不是得开坛了？

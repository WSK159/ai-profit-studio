# 第418章 封底夹层

账本在苏荷手里不过捧了半盏茶的工夫，可那封底夹层里的异物感，隔着牛皮纸面，像一根细针扎在指尖上。

她不动声色，手指沿着封底边沿慢慢摩挲。灰布老头立在一旁，浑浊的眼珠子盯着她手里的账本，嘴唇翕动了两下，终究没出声。

沈伯言就那么站在柴房门口，洛阳铲的铲尖抵着地面，整个人像从土里钻出来的，灰扑扑的。他的目光没落在苏荷脸上，反而盯着她手里那本账，眼皮微微一跳。

“小姑娘，”沈伯言开口，声音沙哑，像是很久没喝过水，“那本账，不是你能拿的东西。”

苏荷抬起头，直直看着他：“沈伯言，你死了三年，坟头草都该长老高了。今天怎么又活了？”

她的话像一把刀，直直捅过去。沈伯言脸上没什么表情，可握洛阳铲的手指收紧了些。

顾长山从她身后跨上来，挡在她和沈伯言之间。他的背脊绷得像拉满的弓，声音却压得极稳：“沈叔，三年了，你欠我一句实话。”

“长山，”沈伯言喊他的名字，语气里带着一种长辈才有的叹息，“你爹的事，我一直记着。但今天这账本，你不能带走。”

苏荷退后半步，借着两人对峙的空当，指尖猛地一用力。“咔”一声轻响，封底那层牛皮纸被她撕开了一道口子，里面滑出来一片薄薄的东西。

她低头一看，是一张叠成四方块的黄纸，边缘微微卷曲，颜色有些发暗。她只来得及看见纸上露出半个“沉”字，沈伯言忽然动了。

他一步跨上前，洛阳铲横过来，直接拍向苏荷手腕。顾长山几乎同时出手，一掌格在铲杆上，两股力道撞在一起，洛阳铲发出一声闷响，偏了半寸。就这半寸，苏荷已经把那片黄纸攥进了掌心。

“长山！”沈伯言声色骤厉，额头上的青筋暴出来，“你知不知道你护的是什么人？她手里那东西，是钟家二十年前拿来逼死你爹的引子！”

苏荷的手一顿。她转头看向顾长山，看见他下颌绷得死紧，眼睛里像烧着火，声音却一丝一丝往外溢：“沈叔，你说什么？”

沈伯言收回洛阳铲，拄在地上，吐出一口浊气：“庚子年白水河那艘盐船，押船的管事叫顾长河。那是你爹，对吧？”

空气像被抽干了。

苏荷攥着黄纸的指节泛白。账本上“查无凿痕”四字反复描画的样子，突然在脑子里连成了一条线。那艘盐船是“钟记”的，人为凿沉，可官府查了“查无凿痕”。押船的管事却被逼死了。顾长山的父亲，就是那个背了黑锅的管事。

“你爹死之前，托人给我带了一句话。”沈伯言的声音低下去，“他说，‘凿船的人，穿着钟家的衣裳，操着官府的刀。’他至死都以为，那是钟老爷下的手。”

“不是钟家。”苏荷突然开口。她摊开掌心，那片黄纸上写着两行字，墨迹已经发褐，但字迹清晰可辨：“己亥年冬月，白水河底凿船者，持衙门铁牌，腰悬柳字玉坠。”

柳字玉坠。苏荷脑子里“嗡”地一声。她想起柳家宗祠里供着的那块灵位，柳春江遗信里“有人穿了我的衣裳，做了脏事”那行字。原来当年凿船的，不是钟家，也不是柳春江——是有人穿着柳家的衣裳，拿着官府的铁牌，把一船盐凿进了河底，把滔天的罪名栽到了柳家头上。

而柳春江，为此背了二十几年的黑锅，连死都没能等到清白。

“这账本……”苏荷抬头看向灰布老头，“是你保管的。账上‘查无凿痕’四个字，是谁写的？”

老头嘴唇哆嗦了一下，颤声道：“当年府衙仵作来验船，签的字，是他写的。可那仵作……”他咽了口唾沫，“后来就再没见过人。”

沈伯言的目光落在那片黄纸上，沉默了半晌，忽然问：“苏荷，你知道你手里的东西是谁写的吗？”

苏荷低头。黄纸的落款处，有一个极小的朱红印记，像一方私人印章的形状。她细看——那印章竟是一朵五瓣梅花。

她脑子里突然闪过一个画面：前世学厨时，师父书桌抽屉最底层压着一块旧印章，也是五瓣梅花。她师父说，那是他年轻时候一个故人送的，后来那位故人不知去向。

“这印章……”苏荷的声音有些发涩，“我见过。”

“你见过？”沈伯言瞳孔一缩。

苏荷花来不及回答，柴房后墙忽然传来一声沉闷的撞击，土灰簌簌往下掉。灰布老头惊得后退一步，指着一堵旧墙：“那、那里面……有响动！”

顾长山已经迈步过去，侧耳贴在墙面上。隔着一层土壁，隐约听见里面有人在挪动什么沉重的东西，紧接着，一个低哑的声音隔着墙传进来——“苏荷，你是不是拿了我的东西？”

那声音不是别人，正是钟大川。

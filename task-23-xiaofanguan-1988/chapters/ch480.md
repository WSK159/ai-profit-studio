# 第480章 城北竹林

晨雾未散，苏荷已经站在城北的岔路口。

青江市不大，但城北她确实来得少。这一片是旧城区的边缘，再往北走三里，就是连绵的丘陵和竹林。1988年，城市还远没有扩张到这里，土路两边是荒芜的菜地和零星几间瓦房，偶尔有早起挑粪的农民经过，好奇地打量她一眼。

苏荷手里攥着那张油纸，上面写着“城北三里，竹林深处，青石门”。

她昨夜翻来覆去想了许久。老乔——不，现在该叫他柳春来了——托冯半缸转达的话，指向已经很明确。青砖残角、黄铜钱、灯座机关，一环扣一环，如今终于到了最后一步。只是这一步，究竟通向哪里，她心里没有底。

“苏老板，这么早出城？”

身后传来一个浑厚的男声。苏荷回头，看见一个穿灰布褂子的壮实汉子，挑着两筐菜从城里走出来，是城南市场的菜贩子老赵，常年在苏记后门送菜。

“去城北办点事。”苏荷笑了笑，没有多说。

老赵也没多问，只点点头：“城北那片竹林可深，前两年还有人传说里面闹鬼，天黑了没人敢进去。你要是去那边，趁早去趁早回，别等天黑。”

“闹鬼？”苏荷心里一动。

“可不嘛！”老赵放下担子擦了把汗，“说是五几年的时候，竹林里头的青石屋子住过一个孤老头，后来人死在里面，好几天才被发现。打那以后，那屋子就空着了，没人敢进去。后来又有人说晚上路过听见里头有动静，敲敲打打的，像在修什么东西……”

苏荷心头一跳：“那青石屋子还在？”

“在倒是还在，就在竹林最深处，一条小溪边上。”老赵上下打量她一眼，“苏老板，你不会真要去那儿吧？”

苏荷笑了笑，从兜里掏出一包烟递过去：“老赵，给我指个道。”

老赵收了烟，乐呵呵地给她说了方向。苏荷道了谢，顺着土路继续往北走。走了大约一刻钟，土路变为窄窄的田埂，两边是齐膝的野草，露水湿了裤脚。再往前走，一片密匝匝的竹林横在眼前。

这片竹林比苏荷想象的大得多。竹子高而密，林间光线昏暗，一条人踩出来的小路蜿蜒进去，地上铺满枯黄的竹叶，踩上去沙沙作响。空气里带着竹叶特有的清苦味，混杂着泥土的潮气。

苏荷深吸一口气，顺着小路往里走。

林子很深，走了大约两里地，她看见了一棵歪脖子老槐树，树干上缠着一圈铁丝，锈迹斑斑。她停下来，从口袋里掏出那块青砖残角，翻过来看了看——上面那个模糊的“北”字，在晨光里泛着暗青的光。

老乔说过，青砖有两块，一块指引方向，一块开启大门。她现在手里的这块是“北”字，那另一块呢？老乔把这块交给了顾长山，又让老乔转交给她——不，老乔把青砖交给了她，上面刻着“北”字。而她自己从黑洲塔上取的那块，刻的是“门”字。

两块青砖，一“北”一“门”。

她绕到老槐树后面，果然看见一块半人高的青石板，藏在竹丛之中，表面覆满青苔，几乎与周围的石头融为一体。但苏荷凑近了看，发现石板上刻着一道浅槽，宽窄和青砖的厚度差不多。

她蹲下来，先取出那块“门”字砖，试着卡进浅槽。严丝合缝。接着取“北”字砖，翻了个面，对准石板上一个凹槽按下去。只听“咔”的一声，青石板微微震动，从中间裂开一道缝，露出黑洞洞的口子。

石板下面是一个向下延伸的台阶，石阶磨得光滑，显然曾经被人反复踩踏过。台阶两侧的壁面上，每隔一段距离就有一个铁环，锈迹斑斑，像是用来挂火把的。

苏荷站起身来，回头望了一眼竹林。晨光透过竹叶洒下来，林间静得出奇，连鸟叫都没有。她攥紧手里的油纸和黄铜钱，深吸一口气，抬脚迈下了台阶。

台阶向下走了大约二十级，尽头是一扇木门。

木门很旧，但门轴是铁的，没有锈死。门上挂着一把铜锁，锁孔的形状她见过——和那枚黄铜钱的轮廓几乎一模一样。

苏荷把黄铜钱掏出来，对准锁孔插进去。铜钱在锁孔里转了一圈，发出一声清脆的“咔哒”，铜锁弹开。

她推开门。

一阵陈年霉味扑面而来，夹杂着一股若有若无的酒香。苏荷眯着眼等了几秒，等到眼睛适应了里面的光线，才看清屋里的景象。

这是一间不大的石屋，大约两间房大小，墙壁是青石垒的，顶上横着几根粗大的木梁。屋内陈设简单：靠墙一张木床，床上铺着干草和一床发黑的棉被；墙脚一口半人高的陶缸，缸口封着黄泥；屋正中一张旧木桌，桌上放着一盏铜灯。

苏荷走到桌前，看见灯座上刻着一行小字：柳氏家传，庚午年立。

她正要伸手去摸那盏灯，忽然听见身后传来一阵极轻的脚步声，停在了门外。

苏荷猛地回头，一把握住腰间别着的那把剔骨刀。

门外，一个穿着灰中山装的驼背老头站在台阶顶上，低着头，浑浊的眼睛从花白的眉毛底下直勾勾地盯着她。他一步步走下来，脚步不疾不徐，腰间挂着一串钥匙，叮叮当当地响。

“姑娘，”老头的嗓音又干又哑，“你找着这地方了……可你怎么进来的？”他的目光落在那扇敞开的门和那枚黄铜钱上，忽然停住了，“那钥匙——”

他猛地抬起头，脸上掠过一丝极其复杂的表情。

“是柳春来给你的？”

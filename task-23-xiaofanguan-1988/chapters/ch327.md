# 第327章 井中巢

苏荷没有贸然动身去周家老宅。先前那个神秘男子警告过，“三步之内有东西”，而周顺水又提到“灰夹克”之前已去动过土——若被翻了底料，她闯过去只会踩在别人挖好的坑上。

她让小海棠去街道办打听老宅拆除的具体安排。下午时分，小海棠带回来一个消息：周家老宅因年久失修属于危房，由区房管所统一组织拆除，计划定的三天后，拆迁队是城东建筑二队的，负责人姓马。

“马队长。”苏荷嚼着这三个字，灵光一闪，这名字她前世听过。八十年代末青江搞城市建设，马队长承包过不少拆除工程。他有个特点：接活前喜欢去现场摸底，拆旧料倒手卖钱，手上有不少房管所的门路。

她让顾长山私下约了马队长，在巷口的老茶馆碰了面。马队长四十多岁，粗嗓门，说话时右手中指总在桌面上敲，一副精于算计的模样。一听苏荷提起周家老宅，他眼睛一亮：“那院子旧是旧，但屋架用料可好得很，全是老樟木，拆下来做家具做棺材都不亏。”

苏荷开门见山：“马队，我想跟你谈笔生意。那座宅子里的假井，我想去清一清。你就当没看见。”

马队长眯起眼，拇指与食指搓了搓：“这事好说，但是……”

顾长山从怀里掏出两沓大团结，放在桌面上：“一点茶钱。”

马队长目光扫过钞票厚度，笑了笑，压住那沓钱揣进怀里：“三天后动工，你们赶在开工前清完。动静小点，出了事我可不认得你们。”

当天夜里，苏荷和顾长山各拿一把手电筒，翻窗进了周家老宅的院子。月光很淡，天幕上浮着几片薄云。院子里荒草齐腰，那座假井的石井沿被时间磨得发青，井口盖着一块厚石板，上面阴刻着“乙”字——正是先前发现铜盒的那口井。

苏荷蹲下，伸指在石板边缘细细地摸。石板缝里嵌着的不是泥土，是暗红色的糯米灰浆——这种灰浆她前世在古建修复队里见过，三合土拌糯米汁，干透了比水泥还硬。难怪当初她和刘春生撬了半晌没撬开。

“巢……”她低声念着那个字，手指从石板边缘一直抚过，忽然在石板的背面摸到一道浅浅的凹痕。她把指头探进去，触到一圈硬物的边缘。那是另一块石头，嵌在石板背后的凹槽里，对着井口内壁正好露出一条窄缝。

她趴在井沿边，手电往里照，果然，内壁的砖缝里卡着一个小铁匣子，整体呈长条形。匣子外裹着油布，解开油布，是一个巴掌大的铁盒，盒盖上浮雕着一只振翅的鸟——不是寻常的喜鹊或燕子，而是一只垂首敛羽的鹭鸶，像在沉思。

——鹭鸶。苏荷的猛地想到“巢”字头上一横，恰恰对应水鸟栖于塘畔的意象。“金桂栖鹭，井中有巢”——这铁盒便是“巢”了。

她小心拨开匣盖的铜扣，里面却不是金桂根。铁匣内壁裹着一层银箔，正中央放着一卷极细的羊皮纸，约莫一拃宽。展开来，纸上用黑墨和朱砂绘着一幅小图：一间灶房，灶膛下画着一口井，井中浮着一条鱼。图的侧边用一行蝇头小楷题道：“灶下有井，井中有魂，魂非金桂，乃鱼之灵。取鱼骨三枚，化于水中，佐以桂香一点，开其灵窍，方得化味之旨。”

苏荷盯着这段字看了很久。她前世在师父的厨房墙上见过一幅几乎一模一样的字幅，只差最后一列：“然得此味，须以人补。”她当时问师父这句话什么意思，师父只是笑了笑，说“你日后自然明白”。

现在她看着这行墨迹，理解了。鱼魂是真味，但真要启用它去化味，得用一个“人”去补——不是杀人放火，而是这辈子不能再用这道滋味赚钱，一旦用了，必然折寿。

苏荷握着羊皮纸，手心里全是汗。若她不去动那化味水的精妙用处，只是做自己的菜，倒也无碍。但她追寻到这一步，显然已经走到这场时代洪流的刀锋上。

“你看到什么了？”顾长山站在她身后，声音低哑，风把他的衣角吹起。

苏荷将羊皮纸折好揣入怀里，沉默片刻才说：“东西是齐了，但还有个条件。”

“什么条件？”

“这口井，那口井，还有那袋被偷走的石子，它们的原主是个很厉害的人。”苏荷抬头看了他一眼，“这个人把线索散了几十年，却从不让任何一个人同时拿齐。他在等一个能按规矩来的人。”

她顿了顿，语气笃定：“我大概知道那老头现在在哪儿了。”

顾长山怔了一下：“你见过他？”

苏荷摇头，指了指那卷羊皮纸：“他在纸上留了个记号——这个笔势，跟我师父写字一模一样。我师父一直告诉我，他的手艺是跟一个逃难的老厨子学的。”

她说到这里，忽然顿住了。云层散开，月光洒下来，照在她脸上，那神情既像惊喜，又像确定了某件久远的往事。

“走吧。”她站起身，拍了怕膝盖上的灰，“那袋子石子被人偷了，但我大概知道，偷的人是替谁偷的。三天之内，我们得去找一趟刘春生。”

“刘春生？”顾长山皱眉，“他不是在城北刘家塘吗？”

“他太爷爷留了一句话——‘味道不全，井里有活物’。”苏荷把铁匣子收进怀里，眼睛在月光下亮得惊人，“我先前以为是鱼，现在懂了。那句话说的不是鱼，是井里有活人留下的东西——活物，是活的信物。”

她话音刚落，远处忽然传来一阵急促的脚步声。两个人同时转头，只见夜色里一个瘦小的身影从墙角闪出来，喘着粗气喊：“苏姐姐——快回店里，出事了！有人砸了食堂的灶台，还说要烧了苏记的招牌……”

是苏桃的声音。

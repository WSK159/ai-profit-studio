# 第337章 父亲的旧账

药铺的后堂里，一炉药香熏得人头脑发沉。冯立本说完那句话之后，仿佛用尽了全身力气，整个人靠在椅背上，手指还在微微发抖。

“你说……下毒的人是苏广田？”苏荷把这三个字咬得极重，“我父亲。”

“是他。”冯立本垂下眼皮，“那时候他刚从乡下来省城投亲，在郑家帮工，没人知道他跟郑家有什么关系。周明善待他不错，让他跟着学了些记档的活计。谁知道呢……”

苏荷冷笑一声：“你倒推得干净。”

“我没有推。”冯立本忽然抬头，眼神里竟有几分说不清道不明的狠劲，“当年那包药，是郑家少奶奶给我的，让我放进周师父的茶里。我不肯，她就威胁要把我赶出省城。可我又怕死，就把药分成了两份，一份下在茶里，另一份……我交给了苏广田，让他倒掉。”

“结果他没倒。”顾长山站在门边，声音沉如压路机的碾轮。

冯立本长长吐出一口气：“后来我听人说，周明善死之前那几天，一直拿苏广田当亲儿子待，教他认账本、识药材，说将来要带他去京城见识见识。可我没想到，苏广田转头就把那包药全下了进去。郑家少奶奶原本只想让周明善病上几个月，好腾出灶房给她娘家侄子——谁知道落了个人命。”

屋里静得只剩砂锅里的药汁咕嘟作响。苏荷盯着冯立本的眼睛，一字一字地问：“那我父亲图什么？”

“图什么？”冯立本苦笑着摇头，“这事我琢磨了二十年也没琢磨透。后来我隐约听说，苏广田在郑家帮工的时候，偶然听到自己的身世——他是郑老爷子在外头的私生子。他怕周明善查账查到那笔给他娘亲的赡养银子上头，把他从郑家踢出去。你说他图什么？他图一个‘郑家儿子’的名分。”

苏荷立在原地，后脊梁一阵麻。她活了这些年，前世今生加起来，从来只知道苏广田是个重男轻女、懦弱自私的庄稼汉。她做梦也没想过，那个端起碗来只顾自己吃肉的男人，年轻时手上竟沾着一条人命。

“那药粉……”她声音有点哑，“你给我的那包，是什么？”

冯立本起身走到药柜前，拉开第三层抽屉，取出一只黄纸包：“这是当年郑家少奶奶给我的方子，我留了个底。周明善生前喝的那服药里的毒，就是从这方子上配的。我一直在找机会还你，又不敢直接去青江找你，怕惹人眼。”

苏荷接过那包药粉，指尖触到纸面，竟有些发烫。她把药粉收入怀中，深吸一口气：“冯掌柜，你今天跟我说这些，就不怕我出去嚷嚷？”

冯立本沉默了片刻，从袖中摸出一封信来：“你父亲当年事发后逃回青江，临走前托人给我带了一封信。他说他知道周明善死了，也知道那是他干的。他说他这辈子没法赎罪了，但求我别把他供出去，等将来……等他女儿长大了，让他女儿自己去周师父坟前磕头。”

苏荷一把抢过信，展开一看，纸页已经泛黄发脆，字迹潦草得几乎辨不清，却确确实实是苏广田的字——她认得，从前在家里逼她干活时，苏广田在墙上用炭条记工，就是这个歪歪扭扭的笔法。信中写道：“冯掌柜在上，我苏广田知罪。周师父待我不薄，我却因一己之私害了他。我今生注定下地狱，但求你别将此事外传。我有一女，将来或可替我赎罪。若她将来出息，让她去周师父坟前磕三个头，就说苏广田的女儿替他尽了孝。”

信到这里戛然而止，末尾连落款都没有。苏荷把信攥在手里，纸页指印卷皱，指尖发白。

“你早该把这信给我。”她冷声说。

冯立本低声道：“我怕你知道了恨你爹，更怕你恨我。这些年我夜夜做噩梦，梦见周师父坐在灶台前问我，‘立本，你熬的药怎么苦成这样？’我……我算是遭了报应了。”

苏荷没有回答。她把信折好收入怀中，转身推门就走。顾长山跟出去，在巷口追上她：“你打算怎么办？”

苏荷站在省城的午后阳光下，影子拉得老长。过了好半天，她说：“先回青江。我要当面问问我那个爹——那把药，是他亲手下的，还是被人逼的。”

她顿了顿，声音低下去：“要是他还有半句实话，我就让他去周师父坟前磕头。要是他敢抵赖——”

她把手伸进怀里，药粉纸包和信封贴在一起，硌得她心口发疼。

“——我就把这封信寄到省城法院去。1988年了，杀人偿命的旧账照样有人管。”

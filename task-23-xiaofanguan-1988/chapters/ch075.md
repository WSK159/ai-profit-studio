# 第75章 一网打尽

事情比苏荷预想的还要顺。

顾长山带着人进福泰祥时，陈福正坐在柜台后面拨算盘，脸上的表情跟吃了苍蝇似的。他大概没想到，这节骨眼上会有公家的人上门。

“陈掌柜，例行检查。”顾长山把工作证往柜台上一放，“听说您这儿最近进了一批新盐，我看看相关的票据。”

陈福脸上的笑僵了一瞬：“顾……顾主任，您这是哪的话，我们福泰祥做的是正经买卖，盐都是从市盐业公司进的，票证齐全，您要看我这就给您拿。”

他说着就要弯腰去抽屉里翻，顾长山不紧不慢地补了一句：“盐业公司的票不用了，我听说您好像还有别的进货渠道？”

陈福的手在抽屉边停住了，汗珠子从额头冒了出来：“顾主任，您这话是……是有人造谣吧？”

“造谣不造谣的，看看地窖就知道了。”顾长山朝身后的干事点了点头，“去后院看看。”

那两个干事是新分来的年轻人，腿脚利索，陈福拦都拦不住，只听后院传来一声闷响，接着是一阵铁锹刮地的声音。没几分钟，一个干事跑回来，脸色发白：“顾主任，地窖里……翻出来好些麻袋，里面全是盐，摸着不对劲，跟沙子掺一块了，还有股怪味。”

顾长山眼睛盯着陈福，声音平静：“陈掌柜，要不要跟我走一趟？”

陈福腿一软，扑通坐在了地上。

消息传回城南巷时，苏荷正在灶上烧鸡。炉火旺，铁锅里的油花噼啪响，她把剁好的鸡块往锅里一倒，滋啦一声白烟腾起。老郑跑进来报信，嗓门大得震耳朵：“苏荷，成了！福泰祥让查封了，陈福叫带去派出所问话了！”

苏荷没抬头，翻着锅里的鸡块：“盐呢？”

“全扣了！三百多斤，当场贴封条。”老郑喘着气，“派出所那边说，福泰祥的营业执照可能要吊销，陈福搞不好要进去蹲几年。”

苏荷这才盖上锅盖，擦了擦手，嘴角压着一点笑意：“太好了。”

但她高兴了没太久。下午四点，顾长山从派出所回来，脸色不大好看。他径直进了苏荷的后厨，把门带上了。

“陈福都招了。”顾长山说，“盐是利丰船务的洪三给他供的，但这批毒盐的源头，他说不上来，每次都是洪三派人在码头交货，钱货两清，没见过上家。”

苏荷皱眉：“那洪三呢？抓了吗？”

“抓了。”顾长山的语气更沉了，“但洪三说他只是接单运货，货从南边来的，具体是谁，他不知道。他只知道一点，这批货是给“省城那边的贵人”留的，福泰祥只是中转。”

苏荷心里咯噔一下。省城贵人？她忽然想起自己原本就要去省城参加美食节的事。

“你是说，这批毒盐，福泰祥只是过路站，真正的目的地还在后头？”

顾长山点了点头：“现在只摸到半根线头，再往下挖，可能就牵扯到省城的大人物了。”

苏荷沉默片刻，忽然抬头，眼里亮出一道光：“那正好。美食节还要半个月，我本来就要去省城。陈福这边倒了，他背后的人肯定坐不住，狐狸尾巴迟早要露出来。”

顾长山看着她，欲言又止，最后还是只说了一句：“你一个人去省城，注意安全。”

苏荷笑着拍了拍他的手背：“顾主任，我一个人可是能掀桌的。到了省城更能掀翻几条桌子。”

她嘴上说得轻松，心里却默默盘算着：这趟去省城，不仅要打响苏记的招牌，还要把毒盐背后的那条线，连根拔起来。

窗外暮色浓了，远远传来巷口老钟的报时声。苏荷掀开锅盖，一股酱香混着鸡油的焦香扑鼻而来。她夹了一块鸡肉尝了尝，咸淡刚好。

省城，等着。

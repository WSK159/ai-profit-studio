# 第264章 门外人影

门缝被无声推开的那一刻，苏荷后背的汗毛根根竖起。月光从门外漏进来，在地面上拉出一道瘦长的影子，那影子一动不动，像是早就站在那儿等着他们。

顾长山的手已经按上了腰间的短刀，他的呼吸极轻极稳，像是在战场上养成的习惯。苏荷没有动，她盯着门缝里那片黑暗，看着那道人影忽然向前迈了一步，半个身子就披上了月光——是个矮瘦的老头，穿着一件洗得发白的灰大褂，袖口挽到肘部，露出两条干柴似的小臂。

“二位在里头待了这么久，”老头声音沙哑，像砂纸刮过铁皮，“是等着墙里的东西出来请你们喝茶不成？”

苏荷的心猛地一跳。灰大褂——她在城南巷见过这个老头，就在井边，那会儿他蹲在地上抽烟，灰鸽子就落在他肩膀上，歪着脑袋看她。她当时只当是个闲逛的。

“老人家认得我们？”苏荷平静地问，声音没有一丝波澜，像是刚才那个被门闩反锁、被墙内敲击声吓得脊背发凉的人根本不是她。

老头嗤笑一声，“巷子口支红油抄手摊子的苏丫头，街面上谁不认识。倒是这位——”他看向顾长山，目光在他腰间的短刀上停了停，“顾干部，您这手功夫，可不像是街道办练出来的。”

顾长山没接话，只是把苏荷往身后带了半步。老头也不恼，转身往院外走，走了两步又停住：“锁门的是我。这宅子里头有些东西，不该进去的人进去了，容易出事。二位既然进去了还能站着出来，说明命硬。命硬的人，我老婆子请得起一顿夜宵。”

“您老婆子？”苏荷问。

“巷尾第三家，门上挂着红灯笼的。”老头头也不回地摆摆手，“来不来随你。不过——”他忽然顿了顿，“过了子时，那扇门再合上，就不是我能开开的了。”

苏荷和顾长山对视一眼。墙内那三下敲击声还在耳边回响，湿铜钱上“正月廿三，子时三刻”的字样也在兜里硌着。现在离子时，恐怕不到半个时辰。

“去。”苏荷说。

顾长山没反对，只是从门框上扣下一块新换的木屑收进衣兜，然后才跟着她走出金钩巷七号。院门在他们身后合拢，发出“吱呀”一声，像是叹了口气。

巷尾第三家确实挂着红灯笼，只是那灯笼不是新的，纸面泛黄，上头画的是一尾跃出水面的红鲤鱼，鱼鳞在烛光里泛着暗沉沉的光。老头已经坐在门槛上了，手里端着一碗热腾腾的姜汤面，见了他们也不起身，只把碗往旁边一搁：“锅里还有，自己盛。”

苏荷没急着去盛面。她蹲下来，从兜里掏出那枚湿铜钱，在灯笼底下翻了个面，借着光，她看清了铜钱那侧的刻字：“江渡口，船老大姓江，问渡不问船。”

老头眯着眼看了一眼那枚铜钱，忽然笑了：“这玩意儿，你从哪儿得的？”

“墙里。”苏荷没有隐瞒，“墙里还有东西在敲。”

老头端碗的手微微一顿，汤面晃了晃，一滴滚烫的汤汁溅在他手背上，他没擦。“里头的东西……”他慢吞吞地重复了一遍，把碗放下，目光落在苏荷脸上，“敲了几下？”

“三下。”

“你回了？”

“两下。”

老头沉默了很久。巷子里起了风，红灯笼被吹得轻轻摇晃，那条红鲤鱼就像活了似的在纸面上游动。最后他叹了口气，从袖子里摸出一个油纸包，递到苏荷手里：“你回了两下是好事。要是回了三下，现在就掉头跑，别回头。”

苏荷打开油纸包，里面是一张泛黄的旧照片，黑白画面里，一个年轻女人站在一口铁锅前，锅里的红油抄手冒着热气，女人腰间系着一条白围裙，围裙的右下角绣着一朵小小的六瓣梅花。

苏荷的手猛地攥紧了照片的边缘。她认得那朵梅花——师父留下的那把铜钥匙上，刻的正是同一朵。

“照片上的人，”苏荷抬起头，声音有些发紧，“是您的——”

“我闺女。”老头说，“也是你师父的……结发妻子。”

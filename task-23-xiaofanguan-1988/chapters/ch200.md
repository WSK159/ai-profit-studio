# 第200章 油里乾坤

天还没亮透，城南巷的雾像一层薄纱，把苏记小馆的招牌糊得影影绰绰。苏荷蹲在后院的油桶边，打着手电筒，把桶壁上那层淡淡的油花又看了一遍。

柴油和菜籽油混在一起，颜色几乎分不出来。但她把桶倾斜一个角度，手电光贴着油面打过去，最上面那一层泛着微微的蓝光，像雨后的积水。柴油比重轻，浮在上头，时间一长，底下才是干净的油。她伸手沾了一点，凑到鼻尖下——一股刺鼻的油气，跟菜籽油的香截然不同。

“掺了多少？”顾长山从院门外进来，手里拎着两个还冒着热气的包子。

苏荷直起腰，把手指在围裙上擦了擦：“目测不到半斤。量不大，但要是真用了，一锅红油抄手全废，客人吃出毛病来，我这招牌就砸了。”

“半斤柴油，不致命，但够恶心人。”顾长山把包子递给她，蹲下来看那只油桶，“前天晚上你收摊的时候，后院门锁了没？”

“锁了。但后墙根那棵槐树，枝杈正好够着院墙顶。”苏荷咬了一口包子，韭菜鸡蛋馅儿的，面皮发得松软——这是巷口王婶今早新蒸的，她在心里记了一笔，回头得给王婶送碗抄手去。

“周建明以前在粮站干过装卸，爬墙翻院的事儿不稀奇。”顾长山站起来，拍了拍手上的灰，“油桶先别动，我找个干净的桶给你换上，这桶留着当饵。”

苏荷点头，转身进了厨房。灶膛里的火已经烧旺了，她架上铁锅，把昨天熬好的红油重新热上。辣椒和花椒在热油里翻滚，激出一股霸道又勾人的香气，从后窗漫出去，把巷口早起买菜的几个大妈都勾得探头往这边望。

“苏老板，今天抄手多包点儿！我闺女从省城回来，点名要吃你这口！”李大妈隔着窗户喊了一嗓子。

“成，给您留两碗！”苏荷应了一声，手上却没停。她心里清楚，这半桶柴油不是冲着一碗抄手来的，是冲着她苏记这三个月攒起来的名声来的。孙秃子上回在她这儿吃瘪，周建明被她当众揭了短，这两人是记恨上了。

正想着，门口有人敲门。不是客人，声音不轻不重，带着一股子客气的劲儿。

苏荷擦擦手出来，看见门口站着一个四十来岁的男人，穿一件洗得发白的蓝布褂子，手里拎着一个青花瓷的坛子，笑得满脸褶子：“苏老板忙着呢？我是街东头刘记酱园的刘经理，上回您订的那批豆瓣酱，我给您送过来了。”

苏荷心里一动——刘经理。账本上记着的那个刘经理，粮食系统倒卖名单里排在老苗后头。她接过坛子，笑着道了声谢：“刘经理真是客气，还亲自送来。”

“顺路的事儿。”刘经理摆摆手，目光在院子里扫了一圈，落在墙角那桶油上，又飞快地收回来，“苏老板生意好啊，听说都排上队了？”

“托街坊们照顾。”苏荷把坛子抱进厨房，揭开盖子闻了闻，豆瓣酱的咸香是正的，底下却压着一小片叠得方方正正的纸。她不动声色地把纸抽出来，展开一看，歪歪扭扭两行铅笔字：“老陈明早九点到青江，那两人也在找他。”

那两人是谁？老苗和郑副科长？还是梁副局长和他的心腹？

苏荷把纸条揉碎了塞进灶膛里，火苗舔上来，纸片卷曲、发黑、化作灰烬。她回到门口，刘经理已经走了，背影糊在晨雾里，慢慢消失在巷口。

顾长山从后院进来，看她脸色不对：“怎么了？”

“老陈明天早上九点到。”苏荷的声音压得很低，“而且——那两人也在找他。”

顾长山的眉头皱起来：“老苗昨晚扑了空，肯定不甘心。老陈要是回来，等于自投罗网。”

“所以得赶在他进这条巷子之前截住他。”苏荷解下围裙，叠好放在灶台边，“长山，明天你帮我看店，我去车站。”

“你去？”顾长山看着她，“老陈认识你？”

“他不认识我。”苏荷顿了顿，“但他认识我师父的字。”

她从怀里掏出那本账本，翻到最后一页，“弯月照处，苏记是根”八个字，墨迹虽已陈旧，笔锋却依然棱角分明。她前世师父的印章上，刻的就是一枚弯月。

“这八个字，是老陈写给我师父的暗语。”苏荷把账本合上，塞回油布包里，“师父早年间跟我说过——‘要是有一天你看到弯月照处四个字，那就是你师门的根在叫你了。’我一直以为他说的是梦话。现在老陈带着这句话回来了，说明他认出了苏记，认出了我师父的来路。”

顾长山沉默了一会儿，伸出手，在她肩头拍了一下：“那明天我跟你一起去。店让苏桃看半天，她手艺虽然还生，但应付早市那几碗抄手，够了。”

苏荷想了想，点了头。

窗外雾散了，朝阳把第一缕光和面，镀在“苏记小馆”那四个歪歪扭扭的字上。

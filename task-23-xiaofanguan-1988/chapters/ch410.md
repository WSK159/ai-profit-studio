# 第410章 船上夜话

木船在夜雾中缓缓前行，橹声吱呀，像老人磨牙。苏荷坐在船头，怀里抱着那面退帮令木牌，粗糙的木纹硌着手心。

老艄公佝偻着背摇橹，斗笠压得极低，露出的半张脸上沟壑纵横，看不出年纪。白水河的水声在夜里格外清亮，两岸芦苇丛沙沙作响，偶尔有夜鸟惊起，扑棱棱掠过水面。

“老人家，”顾长山开口，声音压得低，“师父他……是什么时候跟您定下的约定？”

老艄公不答话，橹声依旧。过了好一会儿，他才哑着嗓子说：“三年前，他在我这儿存了一样东西，说若有一日有人拿着锈钥匙找上门来，就让我送他过河。”

“什么东西？”苏荷问。

老艄公停下橹，转过身来。雾气里他的眼睛浑浊，却透着一股说不清的沉静。他弯腰从船舱板下摸出一个油布包，递到苏荷手里。

油布包被蜡封得严严实实，很沉。苏荷拆开外层油布，里面是一个铁皮盒子，盒盖上刻着三个字——不是字，是三个歪歪扭扭的符号，像童子的涂鸦。她认得，那是师父的笔迹。

苏荷的心猛地跳了一下。

铁盒里的东西只有两样：一张发黄的纸，和一根红绳穿着的铜钱。

发黄的纸展开，上面的字迹是师父的，仍是她熟悉的那种瘦金体：“荷儿，见字如面。你既走到此处，说明柳家那口缸已经开了。我这一生，灶上灶下，颠沛流离，唯有一事未了。帮主手书在我手中多年，我不敢看，也不敢毁，只等着有朝一日……”字迹到这里中断，墨痕洇开一个大团，像是写到一半被什么事打断了。纸的背面有一行小字，是新添的：“若我出事，带此物去东昌街九号，找‘马记铁匠铺’的马老三。”

苏荷把铜钱翻过来看，是一枚光绪通宝，被磨得锃亮，边缘有个极细的缺口，像是被鱼线常年勒出来的。

“东昌街九号，”顾长山皱眉，“那是城南的老铁匠铺，我小时候记得那地方，三年前就关门了。”

老艄公重新摇起橹，说：“马老三没死，搬去了城外张家庄，靠打锄头为生。老疯子交代过我，只有拿到那枚铜钱的人才能去找他。”

苏荷把铜钱系回红绳，套在自己脖子上。铜钱贴着皮肤，带着河水的潮气，凉得她一激灵。

“老人家，”她抬头，夜雾在船头分开又合拢，“您和我师父，是怎么认识的？”

老艄公沉默了很久，久到苏荷以为他不打算回答了。河面忽然开阔起来，两岸的芦苇退去，露出大片光秃秃的滩涂。月亮从云层后面露出一角，照得水面白亮亮的。

“三十年前，我在白水河上撑船养活一家老小。那一年发大水，船翻了，我抱着船板在河里漂了两天两夜，以为自己死定了。”他的声音很平，平得像死水，“是老疯子把我捞上来的。他自己也没几两力气了，拿一根竹竿把我从水里勾上来，一边骂我傻，一边把他身上最后一块饼掰成两半，一半塞进我嘴里。”

他顿了一下，橹声一重一轻：“他说，‘活着的人才有灶膛烧火，死了的连灰都不算。’就这一句话，我记了三十年。”

苏荷没有说话。船尾的水声哗哗地响，雾气不知何时淡了些，月光洒下来，将船影拉得长长的。

“那帮主手书呢？”顾长山问，“师父说那封信还牵涉到官盐换军火的旧案，写信之人至今在世。这封信，现在在哪里？”

老艄公缓缓摇头：“老疯子没告诉我。他只说，那封信不在缸里，不在柳家，也不在他身上。他把它放在一个‘火碰不到水淹不到，贼偷不走人忘不掉’的地方。”

苏荷心头一动，脑海里闪过师父那枚镇纸铁片上的刻字——那一半与自己的铁片合在一起的图案，正是一座火灶压着一口缸。

“灶台？”她脱口而出。

老艄公的橹停了一瞬，又继续摇。他没有回答，但苏荷注意到，他的脚在船舷上轻轻地点了两下。

顾长山也注意到了，正要开口，船身忽然一震，搁浅了。

前面滩涂上，立着一个人影，逆着月光，看不清脸。那人穿着一件长衫，手里拄着一根黑沉沉的拐杖，站在齐膝深的苇丛里，像早就等在那里。

老艄公收了橹，低声道：“到了。”

苏荷站起身，与顾长山对视一眼。那人从苇丛里走出来，月光终于照到他的脸上——那是一张皱纹密布的瘦脸，双目深陷，却透着精光。他朝苏荷拱了拱手：“苏姑娘，我等你很久了。”

苏荷没动：“你是谁？”

“马记铁匠铺，马老三。”他伸出手来，掌心有一道蜿蜒的旧疤，“你师父说，拿着铜钱来找我的人，会替他问一句话。”

苏荷握紧那枚铜钱：“什么话？”

马老三目光定定地看着她，一字一句道：“他让我问你——那味料，你尝出来了没有？”

风从苇丛中穿过，苏荷背脊一凛。

她忽然想起师父临终前握着她的手，说的最后一句话——那会儿她以为是弥留之际的呓语，没有在意。现在想来，那句话分明是：“那锅汤里，少了一味胡椒。”

不是厨艺的问题，她尝不出来，是因为那味料，根本不在锅里。

她抬头看向马老三，声音发紧：“那味料，在哪儿？”

“在灶台外头。”马老三说完，转身就走，身形隐入苇丛，“跟我来。”

# 第318章 账册里的裂口

夜色从城南巷两边的屋檐缝里渗下来，老宅堂屋里点着一盏煤油灯，灯芯“噼啪”爆了一粒火花，把苏荷手里的蓝布册子照出一层陈旧的油光。

顾长山已经把院门闩死，又检查了一遍西墙那扇半塌的后窗，这才回到堂屋，在苏荷对面坐下。他没说话，只把煤油灯往她手边推了推。

苏荷翻开账册的第一页。

墨迹很新，纸张却泛着旧黄——这是民国三十六年的册子，封皮右下角用细笔写着一个“周”字，笔锋收得极狠，像是一刀切在纸上。她一页一页翻过去，眼神速度很快，但每停一处，手指都会在某一列数字上压一下。

顾长山问：“有什么不对？”

苏荷没答，又往回翻了两页，指尖点在其中一行上：“你看这里——民国三十六年九月，周三昧记着‘收井中物估价，金条计二十七条’。但他爹八月才死，分家书是七月立的，井里的金条是分家书里写明归他的。那他九月才‘收’？中间隔了两个月，他在等什么？”

顾长山拧眉：“也许是他搬动不方便。”

“搬动不方便，他记的应该是‘取’，但他用的字是‘收’，”苏荷抬头，“像是有人送还到他手里的。”

煤油灯的火苗跳了一下。她继续往后翻，翻到册子最后几页时，手忽然停住了。

倒数第二页，记的是民国三十八年正月，内容只有一行：“兄再至，索井中物，面色不善，予未应之。”

苏荷眉头一跳——这与井底石室那本账册的末尾内容几乎一模一样。她快速将册子翻到最后一张，发现最后一页被人撕去了一半！剩下的一小条纸缘参差不齐，像是被人急急扯掉的。

她回头看向顾长山：“那本石室账册，缺的也是这一页。”

“你是说，两本账册被人撕掉的页，是同一次撕的？”

苏荷没接话，低头把残页拿近灯下细看。残存的那半页纸，边缘的撕裂纹路异常眼熟——她前世做厨审时，经手过一份民国时期的旧菜单复刻品，那菜单的缺角纹路与之形状相似。但更关键的是，残页背面有浅浅的压痕，像是写字时垫了复写纸，或是在后面垫了别的东西。

她翻过来，用指肚在纸面上轻轻捻了捻，忽然开口：“这里有字。”

顾长山凑过来，顺着她示意的方向看——纸面上似乎有一行近乎看不清的凹痕，像被人用硬笔写过，又被撕去，但压痕在背面留了下来。

苏荷把纸页对着灯，一点点辨认：“‘另有——三——’……后面看不清了。”

“‘另有三十一条’？那不就是石室里那本册子记的？”顾长山皱眉。

“不对，”苏荷摇头，“刚才那句话是分家书里没有的内容。分家书只说‘三穴之图藏于次子之手’，但没说每一穴埋了几条。我在井底石室看到的那本账册里写的是三十一条，分三穴：老宅井底十二条，青峰岭下九条，镇北土地庙后十条。但刚刚这本‘周门底账’里，周三昧自己记的只有二十七条。”

“差了四条。”

“对，”苏荷把账册合上，手指按在封皮那个“周”字上，“而且账册里的二十七条，大部分都标了出处：井底十二条，青峰岭下九条，土地庙后六条。你算算，三穴总共是三十一条，但账册只记了二十七条——那土地庙后的十条，他有四条没记进去。”

顾长山神色一动：“他把四条挪了地方？”

“要么挪了地方，要么……”苏荷顿了顿，看向北墙，“要么那四条压根就没埋进土地庙后，而是埋在了别处。”

她话音未落，目光落到堂屋北墙前排那几块被撬开的青砖上。

油灯的阴影里，砖洞空荡荡的，只留着刚才取出账册时翻起来的灰土。

苏荷忽然走近北墙，蹲下，用手掌贴着地面，沿着墙根慢慢摸索。顾长山没出声，只把灯压低替她照亮。她的手在第四块地砖边缘停住了，那里的砖缝比别处宽出一指，缝里没有灰浆，全是干土。

她从头上拔下一根发卡，顺着砖缝捅下去——发卡没入约有两寸，忽然触到硬物，发出一声极轻的“嗒”。

苏荷抬头，和顾长山对视一眼。

她把那块地砖用发卡撬开一角，露出下面半截泛着铜绿的铁皮盒子——比井底那个黄铜盒小得多，只有巴掌大小，沉甸甸的，封口处缠着三层油布，油布上又绑了一道麻绳。

麻绳已经朽断了大半，轻轻一扯就散。

苏荷打开盒盖，里面没有金条，只放着一枚巴掌大的铜钥匙，钥匙柄上刻着一个“镇”字，和井底黄铜盒里的骨片、铜钥匙完全对不上形制。铜钥匙旁边，压着一小块叠得整整齐齐的牛皮纸，展开来只有巴掌大，上面只有四个字：

“庙后十八。”

苏荷倒吸一口气，正要开口——院墙外那棵矮树丛忽然传来一声细微的“咔嗒”，像是有人踩断了一根枯枝。顾长山已经一步跨到窗边，撩开帘子一角往外看。夜色浓得化不开，矮树丛的轮廓在月光下只淡淡一晃。他原地等了片刻，才收回手。

“没人。”他说。

但苏荷没有动。她低头看着手里的铜钥匙，钥匙柄那个“镇”字在灯下泛着暗绿——镇北土地庙，十八步。她心里飞快地算了一下，如果庙后埋的十条金条是等距排列，那第四、第七、第八条确实不在账册里。可周三昧为什么要单独藏起四枚铜钥匙？

她忽然伸手，把铜钥匙翻过来——背面贴着一小块极薄的铜片，几乎与钥匙体同色，不仔细看根本发现不了。她用小指甲轻轻一挑，铜片脱落，露出下面镂刻的两个字：

“味香。”

她猛抬起头。味香居。周家祖传的老饭馆。

顾长山也看到了那两个字，声音低下去：“老宅井里的骨片、铜钥匙，现在加上这把刻着‘味香’的钥匙——你那位老东家，到底留下了多少东西？”

苏荷没有回答，她捏着那把钥匙，掌心沁了一层薄汗。窗外那棵矮树丛又“沙沙”响了一声，像是被风掠过，又像是被人碰动。这一次，顾长山没有起身去看。他盯着苏荷手里的钥匙，忽然道：“苏父的灰夹克，那枚扣子落下的方位——就在那丛矮树后面。”

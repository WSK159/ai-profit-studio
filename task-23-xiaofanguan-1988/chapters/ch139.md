# 第139章 两个信封

周立军走后，苏荷没有合眼。

她把白天从烧窑旧址取回的蓝皮账册重新翻了开来，在煤油灯下一页一页地过，不再只找精面输送的记录，而是留心每一行夹缝里的字迹。沈国章的记账风格极怪——表面上看是流水账，某月某日进了多少斤面、出了多少斤馄饨皮，可若把每月数字相加，再和当月差额比对，便会出现一个个不大不小的零头。

苏荷前世在后厨管了十多年账目，对这种藏法熟悉得几乎本能。

她把三个月份的差额抄在纸上：三月份多出四十七块六毛，六月份多出三十一块五，九月份最多，整整六十六块。这些数字单看没有规律，但若顺着日期往后数七天——

三月初七，六月十二，九月十九。每隔三个月，沈国章都会在账册里记下一笔“客请”，数字恰好与差额吻合。

“客请”的标注下，只有一个字：秦。

苏荷放下笔，又拿起那两封信。一封是沈国章写给“秦兄”的，另一封没有抬头，只在末尾落款处写着“沈国章，焚于腊月十九”。信纸已泛黄，摺痕处甚至有了脆裂的迹象。

她没有拆那封未寄出的信。犹豫片刻，她先拆了给秦掌柜的那封。

信极短，只有三行：

“秦兄，弟已无退路。若此信到时，弟已不在，请兄念在旧日情分，收留一名叫苏荷的女学生。她爹娘皆不知她在外学艺，若有人问起，只说她在兄处帮工。”

苏荷愣住了。

沈国章生前竟已经立过这样的安排。她前世的名字里恰好有个“荷”字，这封信却分明写于她重生之前——不，她忽然明白过来，这封信也许写的是前世的事。是那个在2026年死于后厨火灾的苏荷。

她手指微微发抖，拆开了第二封未寄出的信。

这一封更短，只有一句话：

“若有一天有人持蓝皮账册登门，请告诉他：师父的配方不是他偷的。是我给他的。”

署名是两个字——赵一鸣。

苏荷猛地站了起来。

赵一鸣。那个在城东烧窑旧址里埋下账册的人，那个名字被记在蓝皮账册每一页上的人，他说配方不是那个叛徒徒弟偷的——是赵一鸣自己给的。

这和周立军转述的“沈师傅的徒弟偷配方烧了德兴楼”是两套说法。如果赵一鸣说的是真的，那孙桂发背后那个人，根本不是沈国章的徒弟，而是另有人拿着配方嫁祸；而赵一鸣主动给的配方，也许是为了保住真正的传人。

苏荷把信纸翻过来，背面空白处有一行极淡的铅笔字，像是写后又用橡皮擦过，但压痕仍在：

“真徒弟姓顾，小名长山。”

窗外公鸡打了第一声鸣。苏荷攥着那封信，脑子里轰地炸开——顾长山。那个退伍军人，街道办干部，她的合伙人。他从来没有提过自己会厨艺，从来没在她面前露过一手。

可那天她收拾厨房时，他随手拿起菜刀切了一根葱——速度极快，刀工极稳，不像一个军人。

她当时只以为他手巧，没有多想。现在她想起那一刀，指尖仍旧发麻。

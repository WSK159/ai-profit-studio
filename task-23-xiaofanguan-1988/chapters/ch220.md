# 第220章 深夜来客

夜里十一点，城南巷已经彻底静下来，只有苏记小馆后厨还亮着一盏昏黄的灯。

苏荷把今天的账本合上，揉了揉发酸的手腕。梁国庆那边已经三天没动静了，这种暴风雨前的沉寂反而让她心里不踏实。她站起身，正准备关灯上楼，门外忽然传来三下极轻的敲门声——不紧不慢，像是怕惊着谁似的。她脚步一顿，顺手摸起灶台上的剔骨刀，压着嗓子问：“谁？”

“苏老板，是我，周海生。”

门缝里挤进来的声音苍老而疲惫。苏荷心里一动，周会计？顾长山不是把他安置在安全屋里吗？她拔下门闩，拉开一条缝，看到周海生裹着一件灰扑扑的旧棉袄，站在冷风里，嘴唇冻得发紫。他身后空无一人，小巷尽头一片漆黑。

“你怎么跑出来了？顾长山知道吗？”苏荷侧身让他进门，警惕地朝街面上扫了一眼，才把门重新闩上。

周海生进了屋，缩着肩膀坐在灶台边的矮凳上，搓了搓冻僵的手：“顾干部那边太显眼，我待不住了。苏老板，我来是为了跟你说件事——梁国庆那边，已经拿到他的‘底牌’了。”

苏荷给他倒了碗热水，语气平淡：“什么底牌？”

“省城那个姓张的经理，你还记得吧？前阵子梁国庆专程跑了一趟省城，回来之后整个人都不一样了，跟孙德海说话都带着腰杆子。”周海生喝了口水，声音压得更低，“我偷听到他跟孙德海通电话，说是省城那边给了他一个‘大买卖’的门路——只要能让苏记关门，那边就给他引荐港商，做进出口生意。”

苏荷端着碗的手没动，眼里却掠过一丝光。“所以他不光是想替食品厂出头，是想拿我当投名状？”

周海生点头：“他那天雇人泼漆，是怕苏记风头太盛被人盯上，想先把招牌搞臭。现在省城那边催得紧，他下一步肯定要来狠的。”

苏荷沉默了几秒，忽然问：“你看见他的车了？”

“黑色波罗乃兹，车牌尾号六三。”周海生答得利落，“他晚上基本都停在他家巷口，有时候开到厂里去。”

门外又响起脚步声，这次是顾长山的声音从门缝里传进来：“苏荷，是我。”她开门，顾长山一眼看到周海生，眉头皱起来：“周叔，我不是让你别乱跑？”

周海生面有愧色：“顾干部，对不住，我实在是……心里放不下，怕苏老板吃亏。”

顾长山没多责备，反而沉声说：“正好，赵铁柱那边刚传回消息，梁国庆今晚没回家。他的车停在城东货运站，人进了里面一间接待室，两个小时了还没出来。货运站，那是孙德海的舅舅的地盘。”

苏荷眼神一凝：“他们今晚可能有行动。”

顾长山点头，眼中带着谨慎：“我已经让赵铁柱继续盯着。如果梁国庆连夜找人对付你，今晚就是收网的时机。你打算怎么办？”

苏荷把剔骨刀放到案板上，淡声说：“他不来，我等他来。他把事情做绝了，我的录音和账页才有分量。”她走到后门口，推开一条缝，目光落在巷口停着的一辆灰扑扑的解放牌卡车影子上，“明天一早，咱们把证据递给工商局。梁国庆要是今晚敢伸爪子，正好一齐断掉。”她关上门，转身看见周海生正盯着她挂在墙上的“苏记”招牌，老眼里有种说不清的光。

门外忽然传来车引擎的轰鸣，由远及近，停在了小巷口。

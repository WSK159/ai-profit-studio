# 第440章 开缸

深夜的城南巷老铺院子里，只有一盏马灯悬在檐下，灯芯燃着，火苗被夜风压成一枚扁扁的杏核形状。苏荷蹲在井口边，手电筒的光柱直直照进枯井底，那口半埋的陶缸露出的部分比白天又多了一指——井底的土，似乎在向两侧退去。

顾长山站在她身后，腰间的旧军刀刀鞘磕在井沿砖石上，发出很轻的一声脆响。他今夜没穿街道办的制服，换了一身靛蓝布褂，袖口挽到小臂，露出紧绷的肌肉线条。

“缸壁渗水了。”他说。

苏荷顺着他的目光看下去——缸肩那道裂隙里渗出一层薄薄的水汽，在灯光下泛着幽暗的青色，像什么活物在缸内喘息。缸壁上的五瓣梅花印被水浸润后，轮廓竟然比干的时候清晰了许多，像是认出了来人。

“沈伯言说，开缸日，须等江上走船人。”苏荷慢慢直起腰，“青江的船，到了么？”

顾长山点头：“今夜子时三刻，漕帮的夜船靠北码头，撑船的是钟师兄的徒弟。”

苏荷心里咯噔一声。钟师兄是钟大河一脉的传人，缸上五瓣梅花印，跟他家脱不开干系。今夜他让徒弟撑船靠岸，不是巧合。

乔春风不知什么时候已经站在院门口，怀里那本线装账册被他托在手掌上，掌心的旧疤在手电光里泛着淡青色的光。他没有进来，只是远远望着井口：“开缸之后，第十八页落在谁手里，哪边就落子。”

“落什么子？”苏荷问。

乔春风笑笑，不答，转身走进檐影里。

院子里安静下来。苏荷蹲下身，从工具箱里取出钟师兄送来的那套黄铜开缸工具——一把弯刃铲，一根三尺长的细铜探针，一枚巴掌大的铜片，上面錾着水纹与梅花，与缸壁上的印记如出一辙。铜片背后刻着两个字：问味。

她把铜片握在手心，温热的触感传来，像握着一截旧人的体温。

“时辰到了。”顾长山说。

夜风忽然紧了。井底那只陶缸的缸口传来一声细响，像是水在翻动，又像是谁在里面叩了一下缸壁。苏荷深吸一口气，将探针第一截旋入缸盖边缘的缝里，手腕一拧——

“咔哒。”

缸盖没有动，但缸身猛地一震。泥土从井壁簌簌落下。苏荷听见缸内传来极其清晰的“咚”的一声，闷沉的、有节奏的，像指节叩在陶壁上。她在前世听过无数食材在密闭容器里的声响，没有哪一种与这个相似。

“……缸里有人。”顾长山压低了声音，手已经按上刀柄。

苏荷没有回头，她盯着缸缝处渗出来的水痕。那水是清的，但带了一股陈年苔藓与药草纠缠的气味，很淡，却无比熟悉。她愣了半息，忽然想起在哪里闻过这个味道——2026年，她师父临终前，衣襟上薰的那味艾香。

她手一抖，探针差点滑脱。

“荷姐儿——”巷口传来一个压低的男声。苏荷猛地抬头，看见一个矮瘦的身影扒着院墙探出半个脑袋，脸上灰扑扑的，正是钟师兄的徒弟，撑夜船的那个少年。他扬了扬手里的东西，是一张油纸包着的小纸包：“我师父说，掀盖之前，把这个撒进缸缝里。防的是——缸里头那口‘活气’一口冲出来。”

苏荷接过纸包，拆开一角，里面是一撮白灰色的粉末，带着浓烈的椒麻气——碾碎的花椒、盐霜、陈皮，还有一味她说不上来的古法香料。这是厨师压腥的方子，也是老派守缸人封缸必用的“镇味料”。

她忽然明白了。这口缸从头到尾都不是为了装东西的——它是一口“养”东西的器皿。江上走船人，不是指漕帮的船，是指某个必须由水路带过来的“活物”或“信物”。而钟师兄让徒弟送来这包镇味料，意思只有一个：

——缸里封的东西，是“吃食”。

苏荷攥紧纸包，与顾长山对视一眼。马灯的火苗在这时候猛然拔高了一截，院墙外传来夜船靠岸的声音，橹声三响，停得干干净净。

“开。”苏荷说。

她把镇味料沿着缸盖缝撒了一圈，弯刃铲嵌入缸口，双手用力一压。“嘎——”一声沉闷的釉响，缸盖松动一线。一股寒凉的、带着药草和陈年米香的气息从缝里涌出来，不是陈腐的气味，倒像是一坛封存多年的老酒终于碰开了泥封。

缸内水声轻轻响了一下，随即有一只手指，从缝里露出来。

苍白的、干瘦的、指节上缠着一根褪色的红绳。

苏荷后背的汗毛一下子竖了起来。

那只手指轻轻搭在缸沿，像是试探，又像是叩门。半晌，缸内传出一个沙哑的、已经不大像人的声音：

“……谁家的火，熄了没有？”

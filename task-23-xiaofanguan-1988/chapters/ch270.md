# 第270章 三月初三

苏荷的手指在那张纸条上停了片刻，纸是普通的宣纸，带着一股淡淡的霉味——像是从老旧的柜子里翻出来的。她将纸条翻过来，背面什么都没有，字迹工工整整，带着一种旧式账房先生的端方。

“三月初三，就是后天。”顾长山站在她身侧，目光也落在纸条上，“南门双锁水旱门，这个我记得，老城南门有两道闸，一道水闸一道旱闸，连着青江和城里河道，早废了。”

苏荷抬眼看他：“废了的地方，为什么有人要约定在那里？”

顾长山没答话，他从口袋里摸出一盒烟，抽出一支捏在手里没点。夜空很黑，巷子里只有远处人家透出的一豆灯光。两人站在苏记小馆的后门檐下，夜风带着初春的湿气，将苏荷鬓角的碎发吹起来。

“你打算去。”他说。这不是问句。

“有人用周明善的手记引我到金钩巷七号，又用金钩巷七号的线索引出这张纸条。”苏荷将纸条折起来，收进里衣的口袋，“他去不了，所以要我去。”

她顿了顿：“这是递话，也是邀请。人家把道划清楚了，我要是连南门双锁水旱门都不敢去，那这条路也就没有继续走下去的必要了。”

顾长山终于将烟点上，火光明灭间映出他硬朗的下颌线，他吸了一口，烟雾在夜风里散得很快：“我陪你去。”

苏荷看着他，想说“不用——你街道办那边脱不开身”，话到嘴边又咽了回去，最终只点了点头。

三月初三，子时。青江的夜已深透，街上几乎没有行人。城南一带的旧屋区在月光下像水墨画一样铺开，瓦檐层叠，巷弄狭窄幽深。苏荷穿了一身深色棉衣，头发用布巾扎紧，脚踩一双布底鞋——走夜路无声，也跑得快。顾长山穿一件旧军大衣，里面别着一把短匕，是他退伍时带的。

两人从城南巷出发，绕了两条暗巷避开主街，摸到南门附近时，远处正好传来钟楼的报时。苏荷在心里数着——亥时末，离子时还有一刻。

南门的城墙已经被拆除了一大半，只余一段夯土残基，水旱两道闸门的位置在城墙的东南角，两座闸墩相挨，中间隔着一道丈余宽的砖堤。旱闸的铁板早已锈透，被人从中间劈开了一个口子，水闸的绞盘被钢筋焊死，露出半截青石门槛。

月光如水，闸门下的青石板上生了一层苔藓，在夜里泛着湿漉漉的暗光。没有人。

苏荷没有立刻走近，她蹲在土坡后望了一阵——水面平静，旱闸的铁口里黑洞洞的，像是张着嘴的兽——她拾起半块砖头朝闸内丢去，砖头落地，滚了两圈，发出闷响。

“空的，没人。”顾长山在她身侧低声说。

两人这才从土坡后走出来，降到闸门前的砖堤上。苏荷弯下身，借着手电筒的光往旱闸里面照，铁锈和泥尘味扑面而来，闸洞不大，约莫一个成人弓身能走进去的尺寸，里面积了一层干泥，却有一道新鲜的脚印，从洞内延伸到洞外，又折回去。脚印并不深，但鞋底的纹路很清晰——圆点防滑纹，胶底。

“来过了，又走了。”顾长山蹲下看了脚印，“时间不长，鞋底还带湿泥，大概率是从江边过来的。”

苏荷直起身，目光落在闸门右侧的砖墙上。老砖灰扑扑的，其中一块的砖缝却发黑，她伸手摸了一下，指腹沾上一层湿润的灰迹——像是刚被人抹过。她将那层灰拂去，砖缝里露出一张折成四折的牛皮纸。

“这是留给我的。”她取出纸，借着月光展开。

纸上只有四个字：“安好，勿念。”字迹和周明善手记里的一模一样。

苏荷盯着那四个字，心跳突然快了半拍。她将纸翻过来，背面又有一行小字，被水渍晕开了一半，模糊得几乎看不出写的是什么，直到她将纸凑到手电筒的光下才勉强辨认出来——

“……已取回。”

下面还有两个字，只有半个字形的轮廓，像是写的时候笔蘸了太多墨，又像是写字的人手在抖——它像“债”，又像“馈”。苏荷盯了半晌，将纸折好收起。

顾长山站在她身侧，没有说话，也没有催她。远处青江的水声哗哗响着，一点一点拍打河堤，夜风更湿了。

“字条是留给我看的，但不见我。”苏荷低声说，抬起头来，眼底的光比月光冷，“这是在告诉我，他一直在附近，替我看了很久的路。”

她停了停：“但我要见他。”

她转过身，目光扫过闸洞、砖堤、江面。水闸下方的水面平静如镜，月光在水面上铺成一条碎银的带子，而苏荷的目光却钉在某个点上——那是一片芦苇，长在闸口下游的水洼旁。芦苇丛深处，隐约有一截深色的衣角，被风掀起，又落下去。

苏荷没有喊话，也没有走过去。她只是站在月光下，望着那丛芦苇，低声说了一句话——那声音很轻，被夜风带走，像一粒石子投入水面。

半刻钟后，芦苇丛里终于传来一声叹息，苍老的，像是等了很久很久。

“女娃，”那声音说，“你不该来的。”

# 第89章 看守所里的赌局

天刚蒙蒙亮，苏荷就起来了。灶间里苏桃已经烧好了一锅白粥，热气在冷冷清清的屋梁下飘成一片白纱。

“姐，粮站那边我都记好了，要三十斤白面、二十斤大米、两桶菜籽油，还有——”苏桃掰着手指头，流利地报着一串单子。她这记性打小就好，数字过一遍就忘不掉。

苏荷把粥喝了，从兜里掏出十五块钱塞过去：“油挑好的买，面别要掺了陈年的。跟老赵头说好，月底结账。”

苏桃点头，又看她一眼：“姐，你今天去城北？要不要我陪你？”

“你管好店里的事。”苏荷把围裙解下来，换了一件干净的靛蓝外套，头发用黑发卡别得利利索索，“中午给长山哥留饭，他下午要出门。”

她没多解释，揣上两块干粮就出了门。

城北看守所在省城最北边，青砖围墙，墙头上拉着铁丝网，门口一棵老槐树光秃秃地戳着。苏荷到的时候，大门刚开，值班民警穿着旧蓝制服，正蹲在台阶上啃馒头。

她走过去，没绕弯子：“同志，我找你们所长。”

民警上下打量她：“你什么人？所长是你想见就见的？”

苏荷从兜里掏出一封信——是昨晚连夜写好的，信封上没落款，只写了“王主任案”三个字。她把信递过去，说：“麻烦您把这封信交给所长，就说城南苏记饭馆的苏荷，来送一份迟早要立案的证据。”

民警愣了一下，但还是把信接过去，转身进了门。

苏荷站在墙根底下等，太阳一点点爬上墙头，照着她脚边的一片黄泥地。大约一炷香的工夫，民警回来了，脸色松动了些：“所长叫你进去。后院，左手第二间。”

所长姓赵，四十来岁，紫膛脸，眉骨很高，穿着一件洗得发白的制服。他桌上摆着苏荷那封信，信已经拆开了。

“你就是苏荷？”赵所长抬眼打量她，“信里说，你手里有南关街道王主任收受私盐贿赂的账册？”

“是。”苏荷站得笔直，“账册是实打实的，记了名和数。我这次来，不是求您办事，是想跟您做一笔买卖。”

赵所长眉头拧起：“买卖？”

“周平——就是何记饭馆那个采购——是整条线里唯一愿意开口的人。他现在关在您这里，王主任肯定会想办法把他弄走，或者让他闭嘴。您要是想破这个案子，就得让我见他一面。”

赵所长沉默了一会儿，手指敲着桌面，笃笃笃的声音在安静的屋子里格外清楚。

“你怎么保证他能开口？”

苏荷往前一步：“他媳妇昨晚来找我，说他胃出血了。他怕死，但他更怕他媳妇一个人带着孩子过不下去。我见他，就是告诉他——他咬实了，我保他家属；他要是闭了嘴，王主任那边才不会管他死活。这笔账，他自己算得清。”

赵所长又看了她半天，忽然笑了一下：“你这女人，胆子不小。”

“胆小了就不在城南开店了。”苏荷寸步不让。

赵所长站起来，拉开抽屉拿了一把钥匙扔在桌上：“二十分钟。隔着铁栏，不许递东西，不许写纸条。”

苏荷接住钥匙，低头道了声谢。

看守所的探视间潮湿阴暗，铁栏隔成两半。周平被带出来时，苏荷差点没认出他——半个月不见，人瘦了一圈，颧骨凸出来，嘴唇干裂，手铐扣着手腕，走路脚底是飘的。他抬头看见苏荷，怔住，眼眶一下红了，嘴唇嗫嚅着，好半天才挤出一句：“苏老板……你怎么来了？”

“翠兰来找我。”苏荷盯着他的眼睛，声音不高，但一字一字砸得清楚，“周平，我问你一句话。何记那些假账、洗钱的窟窿，你是不是知道王主任的份儿？”

周平嘴唇发白，像筛糠似的抖起来。

“你别怕。”苏荷压低声音，“你咬他，咱们就活。你不咬他，王主任明天就能让人把你在里面‘病故’了。你信么？”

周平的眼泪刷地流下来，哽咽着：“我信……他手黑——”

苏荷把手伸进衣领，从贴身暗袋里掏出一张折成方块的纸，隔着铁栏塞给周平——这动作她做得极快极轻，站在后面的狱警没看清。纸上只写了一行字：“你说，他保你全家。”

周平把纸攥进掌心，抖着手，咽了一口唾沫：“苏老板，我……我说。”

“说了，就出来了。”苏荷在铁栏上拍了拍，转身往外走。她走出探视间大门时，背后传来周平的哭声——压着的、闷闷的，像是憋了半辈子的委屈终于从嗓子眼里滚了出来。

苏荷没回头。她走到看守所院子里，阳光刺得她眯了一下眼。赵所长站在办公室门口，手里端着一杯茶，朝她掂了掂：“信我留下了。三天之内，他要是做笔录了，我让人通知你。”

苏荷点头，走出大门，脚步不停。她要赶在中午之前回到城南巷。

因为她隐约有种预感——王主任的人，这会儿怕是已经坐在苏记门口了。

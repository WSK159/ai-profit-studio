# 第187章 老裁缝的口风

陶师傅来得很快。老人家穿一件灰呢中山装，领口磨出了毛边，头发梳得整整齐齐，进门先朝苏荷点了点头，又瞧见顾长山坐在堂屋里，便没多问，径自在桌边坐了。苏荷端上一碗热豆腐脑、两根油条，又给他倒了杯茶。

“陶叔，没别的事，就想跟您商量商量搬铺的日子。”苏荷坐下来，语气平和，“屋我给您找好了，就在城南街口，门面比这儿大一半，租金我垫一半。您那老招牌，我让人照原样描了挂上去。”

陶师傅夹了一筷子豆腐脑，慢慢嚼了两口，没接话。

苏荷也不催。她眼神扫过墙角的缝纫机，那台“飞人”牌老机子是陶师傅的命根子，机身包浆发亮，踩了三十年。她顿了顿，又开口：“我听说，昨儿下午有人去您铺子门口站了会儿？”

陶师傅眼皮抬了抬，放下筷子：“你消息灵通。”

“陶叔，我不是打听您的私事。但那个人，姓周，省城来的，眼线长，手也长。他要是找您谈铺子，您得留个心眼。”

陶师傅沉默了一会儿，从口袋里掏出一张纸条，放在桌上，推到她面前。纸条上用铅笔写着一行字，字迹工整：陶记成衣，城南巷七号，愿出双倍价购铺。

“昨儿下午他塞进我门缝的。”陶师傅的声音有点闷，“我说我答应你了，他就说，生意跟交情两码事，叫我再想想。”

苏荷盯着那行字，心里一沉。周建明开双倍价——这价码，比她给陶师傅的条件高得多。她给的是半年铺租加搬迁费，人家给的是真金白银买铺子。

她抬起头，看向陶师傅：“陶叔，您想卖吗？”

陶师傅看了她一眼，又把豆腐脑舀了一口：“我在这儿做了三十年衣裳，街坊邻居的衣服，我一个尺子量出来的。你这女娃子，虽然年轻，但做事地道。我老婆子生前常说，做买卖跟做衣裳一样，服帖不吭人的人，才走得远。”

他搁下勺子，语气沉重：“铺子我不卖。但他那纸条，我留着没扔，给你看看——你自己小心。”

苏荷心里一暖，点头：“陶叔，谢谢您。”

陶师傅摆摆手，起身走到门口，停了一下，像想起什么：“对了，那个姓周的，昨儿在巷口跟三号的小王说了半天话。我听见他说了一句‘你搬走了，旧货卖不出去怎么办’——小王当时脸都白了。”

苏荷心跳漏了一拍。三号租户是开旧货铺的，堆了一屋子收来的瓶瓶罐罐、旧家具，清仓确实麻烦。周建明这是捡软柿子捏——他知道三号比五号更难谈，直接拿旧货压人。

陶师傅走后，苏荷坐在桌边没动。她端着那碗已经凉了的豆腐脑，一口一口吃干净。

顾长山在旁边坐着，看她吃完，才问：“你打算怎么办？”

“五号那家是鞋匠，他要的是摊位，不是铺子，好办。”苏荷擦擦嘴，“三号是小王，旧货压着走不了，本来就犯难。周建明这话点到他痛处了——他要是肯签，怕是周建明能帮他清货。”

“那咱们也帮忙清。”

“不。”苏荷摇头，“帮得太急，他反而不信。得等他主动来开口。”

她站起来，走到灶台前，掀开砂锅盖子，里面炖着一锅骨头汤，乳白色的汤面上浮着油花。她舀起一勺吹了吹，喝了一口，慢悠悠说：“周建明有他的牌，我也有我的牌。”

她放下勺子，从口袋里掏出那张粮库纸条，又看了看，折好放回口袋：“长山，你帮我查个人。粮库那个老陈，他侄子叫什么，在哪儿上班——只要查到人，剩下的路我自己走。”

顾长山看了她一眼：“你怀疑那封信是老陈写的？”

“我不怀疑谁，我只是想知道，一个看仓库的，为什么辞职跑得比兔子还快。”苏荷微微眯起眼睛，“能让一个人连夜跑路的事，要么是怕，要么是收了钱。不管是哪一种，都说明背后有人在布一张网。我没兴趣当网里的鱼。”

她从墙上摘下围裙，系好，走到灶台前，掌勺敲了敲锅沿：“开张了。”

门外队伍已经排到了巷口。

# 第199章 猫腻

回到小饭馆时，苏桃正蹲在灶间门口逗那只三花猫。猫是我前些天在菜市场捡的，瘦得皮包骨，喂了半个月，胖了一圈。苏桃见我们进来，赶紧站起来，脸上带着心事：“姐，刚才有人送了个坛子过来，说是青江饭店刘经理送的，说是什么，上好的豆瓣酱。”

我和顾长山对视一眼。

坛子摆在灶台上，陶土黑釉，上面压着一块黄泥封口。我揭开泥封，一股冲鼻的酱香扑鼻而来。确是好酱，里头还加了火腿末和干贝丝，光成本就值好几块钱。

“刘经理送这么贵的东西？”苏桃凑过来看，“姐，是不是想让你去给他们食堂供货？”

“不是。”我掂了掂坛子，又闻了闻，总觉得哪里不对。刘经理正在跟周建明倒卖耗油的链条上，老苗今晚又刚摆出一副查房的姿态，这会儿给我送豆瓣酱，也太殷勤了。

我回灶间拿了只干净碗，舀了一勺出来，看着那深褐色的酱体在碗底缓缓渗开。忽然，我看见酱里有东西——一小截白纸，半浸在酱里，已经被泡得发软。

我把纸捞出来，展开，上面用铅笔歪歪扭扭写着六个字：“油有问题，查缸。”

油有问题？我往调料架上看了一眼，炒菜的菜籽油是从城南油坊进的大路货，一桶八十斤，还剩大半桶。我走过去蹲下来，拿长柄木勺伸进去搅了搅，又举起来对着光细看。

灯光下，油色透亮，看不出异常。但我低下头去闻的时候，鼻子突然捕捉到一丝熟悉的酸苦味——柴油。

菜籽油里掺了柴油。那股淡淡的、不仔细闻根本察觉不出的柴油味。

我瞳孔骤然一缩。这时候苏桃已经在灶台上淋了一勺油烧热准备试菜，油一热，那股酸苦味猛地冲出来，辣得人眼睛都发酸。油烟里甚至带了一丝刺鼻的白气。“姐！这油——”

“别用！”我一把把勺子夺下来，“这油有问题！”

苏桃脸色刷地一下白了。她反应极快，立刻把锅里那点热油倒掉，又舀了一瓢水刷洗锅子。我盯着那半桶油，脑子里电光石火般连成一条线。

刘经理送“好酱”来，恐怕不是好心，而是警告。这坛豆瓣酱里藏的字条，是有人借刘经理的手在提醒我——你店里那桶油，已经被人做了手脚。做手脚的人是谁？很可能就是老苗或周建明一派，想趁我还没查清粮库的事，先把我这饭馆的名声毁了。要是我今天晚上用了这桶油炒菜，明天一早就得爆出“苏记小馆用柴油炒菜”的丑闻。这事一旦传开，我这店就完了。

我咬住嘴唇，又问苏桃：“这油是什么时候换的？”

“今早。我去南头油坊打的，回来時桶口是封死的。”苏桃想了想，“对了姐，我在油坊门口碰见孙秃子了，他还跟我搭话，问了一句你家是不是要用新油了。”

孙秃子是周建明手底下的人。我心里“咯噔”一声。

“那桶油，”顾长山走过来，把油桶拎到门外，“丢掉是来不及了。留着当证据。”

“证据？”苏桃愣住。

“对。”顾长山看向我，“明天你照常开张，油桶放到灶台底下。要是有人造谣，你当场把他请进后厨，让他自己看油。做手脚的人一定会在暗处盯着等着这出戏开锣。”

我盯着他，慢慢点了点头。这主意好。让那帮人自己撞上来，比我们到处找他们强。

“那今晚还做饭吗？”苏桃问。

“做。”我拉开柜门，“用家里的猪油。”

当晚，小饭馆灶火照常升起来。外面秋雨绵绵，店门刚上栓，我忽然看见门缝里塞进来一张纸条。捡起来，纸上只有一行字：“明早九点，老陈回青江，你们可要接稳。”

老陈，回青江？

我看了顾长山一眼。

“这是好事还是坏事？”我问。

顾长山沉默了一瞬，说：“坏事。老陈要是在省城好好藏着，那些人反而没把柄。他若一回来，就等于是自投罗网。而且今早我接到消息，市粮食局的梁副局长，刚从省城调回青江。”

梁副局长。老陈账本上第一位的那位。

窗外一道闪电，轰隆隆的雷声滚过城南巷的屋檐，雨砸在瓦上，像是有人在天上往下倒豆子。

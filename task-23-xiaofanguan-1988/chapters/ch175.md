# 第175章 后巷追灯

仓库后门是一条只容两人并行的窄巷子，两侧是水泥墙，头顶晾着几根电线。何承业跑得飞快，苏荷被拽着胳膊，脚下踉跄，差点绊倒在一堆碎砖上。

“货呢？”她边跑边问。

“先不要了！人被抓了货也完蛋！”何承业压低声音，“跟着我，别出声！”

巷子尽头是堵矮墙，何承业翻过去，伸手拉她。苏荷咬牙一跃，膝盖磕在墙头上，疼得倒吸一口气，但不敢停。

墙外是一条更宽的胡同，两边是居民楼的后窗，窗台上晾着腌菜坛子。何承业贴着墙根走了一段，拐进一家院子后门，推门进去——院子里拴着一条大黄狗，居然没叫，只是抬头看了他们一眼，又趴下了。

“我家。”何承业简短地说，带她进了灶屋。

灶屋不大，煤炉子上还坐着一壶水，“咕嘟咕嘟”冒着白汽。何承业让她坐下，自己从柜子里摸出一瓶白酒，倒了两杯：“压压惊。”

苏荷接过杯子没喝，她环顾四周——这屋收拾得干净，灶台上没放油瓶，墙上贴着张去年的挂历，桌上摊着本《机械原理》。一个倒腾橡胶管的人，家里摆着机械书，有意思。

“何师傅是厂里出来的？”她试探道。

何承业没答，反而问：“片警怎么来的这么快？你来了之后我才定的地点，你又不是本地的——”

他盯着苏荷的眼神骤然变了：“你是条子？”

“我不是。”苏荷放下杯子，“但你这行的规矩我懂，先想后路，再交代底细。我不问你货从哪来，你也别问我的路子，各吃各的饭。”

何承业看了她半晌，慢慢笑了：“行，是个痛快人。”

他给自己点上一根烟，吸了一口：“货在仓库里，警察扑个空，顶多扣下一批货。但那货不是我的，我也就是个中间人——真正出货的人姓李。”

苏荷心一紧：“李什么？”

“李兆阳。”

这两个字像一盆冷水兜头浇下来。苏荷脸上的表情没变，但手指在桌下攥紧了。李兆阳——那个在巷子里盯过梢的人，那个和何承业一起在码头卸货的人——原来这整条线都绕着他转。

“李兆阳知道你今天要见买家？”

“他不知道。”何承业摇头，“这批货他说了算，我只负责找下家。你要是见了他，就不止二十捆的事了——他有门路，能搞到更多，但价钱也要再往上加。”

苏荷低头看自己的手，指腹上有道被墙头蹭破的伤口，渗着血珠。她要是告诉何承业，李兆阳已经盯上她了，今天这一单八成谈不成；但她不告诉，等于揣着个雷走夜路。

“这样，”她抬起头，“二十捆我要了，钱过两天到。但有个事我得先跟你说清楚——”

院门忽然被人敲响了。

三下，很轻，但很稳。

何承业脸色一变，朝她使了个眼色，苏荷立刻起身，躲进灶屋旁的柴房。何承业走到院门口，沉声问：“谁？”

“送煤球的。”

“没订过。”

“老刘订的，你家老刘让我送来的。”

何承业拉开门闩，愣了一瞬——门外站着的人他认识，但他没想到会在自家门口见到他。

苏荷透过柴房门缝往外看，心跳猛地漏了一拍。

门外站着的，是顾长山。

他穿着街道办的灰色中山装，手里推着一辆板车，车斗里是几袋蜂窝煤，板车把手上挂着一个保温桶。

“何师傅，”顾长山的语气平静得像在谈天气，“你订的煤球到了，还有你家嫂子让带来的——一碗热汤，说是你晚上出门冻着了。”

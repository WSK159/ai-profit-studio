# 第101章 意外之人

敲门声很轻，轻得像是怕惊着人，但又一下接一下，不急不缓，透着一股笃定。

苏荷和顾长山交换了一个眼神，顾长山不动声色地往门后一侧靠去，手已摸到别在后腰的短刀。苏荷定了定神，清了清嗓子，声音带一分睡意：“谁啊？”

门外顿了顿，隔了片刻才传来一个年轻的男声，带着点烟嗓：“请问，苏荷同志在吗？我姓周。”

苏荷的心猛地一跳。姓周——周诚是师父的本名，这是巧合吗？她没急着应，只又问：“你找她什么事？”

“有人托我捎句话。”门外的声音压得更低了，“说‘那锅东坡肉还欠一把火’。”

这句话来得太突然。苏荷眼皮一跳，攥紧了拳头。这是师祖昨天对她说的暗号……不，暗号分明是“那锅东坡肉放多了糖”，而这个人的话里差了三个字。她不敢贸然认，示意顾长山稳住，自己走到门边出了一口气：“对不住，我不认识你说的什么东坡肉。深更半夜的，您找错人了吧。”

门外安静了半晌。然后那道嗓音又响起来，带着一丝笑意：“是我唐突了。不过劳驾，请告诉苏荷同志——周诚在三桥胡同十四号等她，让她天亮前一定要来。”

话音落下，脚步声沿木楼梯“笃笃笃”地踏下去，渐行渐远。

苏荷靠在门板上，心跳鼓擂般响。等楼下的动静彻底平息了，她才低声开口：“三桥胡同，你知道在哪儿？”

顾长山点头：“省城老城区，不远。从这儿走过去两刻钟。”

苏荷深吸一口气，望着窗外月色，心里开始飞快地转。这个自称姓周的人说的是一个只有师祖阵营内才会知道的暗号变体。如果这是陷阱，对方的饵下得太谨慎了，宁可多等她一晚也不逼她开门；如果不是陷阱——那就说明师父周诚还活着，而且就在三桥胡同里等着她。

天亮前。这是时限。

“我去。”顾长山站起来，“我先去探路，你在后头跟。要是巷子里有埋伏，我咳嗽三声，你马上走。”

苏荷摇了摇头：“他点的是我的名字。我去。”

她拿过桌上的搪瓷缸灌了一口凉水，把那张收据又检查了一遍，贴身藏好。推开旅店后门，月光已经倾斜，街上起了露水，冷意从脚底往上爬。省城果然比青江要冷。

两人一前一后，隔开三十步的距离，沿着夜色中的街巷向三桥胡同方向摸去。

路上苏荷心里始终绷着一根弦。她反复回忆着师祖那间酱菜铺里的每一个细节——那人叫什么名字？是学徒还是外人？他说“王家请您去喝茶”时，语调里带着一种惯见的客气和生分，显然是帮王家跑腿的人。师祖被请走了，会不会出事？收据在自己手上，对方若是逼问师祖账本的下落——苏荷攥紧了衣袖，手心沁出冷汗。

三桥胡同不难找——两座石板桥夹一条窄巷，胡同口种着三棵老槐树。顾长山摸了进去，片刻之后回来，朝她点点头：“十四号。院里点着灯，门槛外没站人。”

苏荷颔首，独自走到十四号门前。朱漆木门，门环上落了一层灰。她伸手，才碰到门环，门就从里面“吱呀”一声打开了。

门后站着一个人，三十岁上下，瘦高个，穿一件洗得发白的灰布棉袄，下颌一道旧疤。他打量苏荷一眼，侧身让出一条路：“进来吧。”

苏荷迈进门槛，目光扫过院里——一口井，两棵柿子树，屋檐下挂着一串干辣椒。屋里透着昏黄的灯，暖得很。她跨进堂屋脚步一顿。

桌边坐着一个中年男人，正低头削一只白萝卜。他削得很慢，很仔细，刀尖把皮整整齐齐地旋下来，动作不疾不徐。那双手骨节分明，虎口一道陈年烫疤。似乎察觉到苏荷的目光，他抬起脸，眼睛里透出一层温和的、带着风霜的倦色。

苏荷的心口猛地一缩。

她的师父，周诚。

上一世教她颠勺、切菜、对火候较真到偏执的周诚——活生生地坐在她面前。比前世她认识的那个周诚年轻了许多，脸上还没有那几道深皱纹，眼角还没被烟熏得泛黄。

周诚放下刀，抬头看了她一眼，嗓音低哑：“沈师收了你做徒弟？”

苏荷张了张嘴，一时不知该从何说起。她是重生的苏荷，师徒情分在前世，这辈子他们还没正式见过面。可她的眼眶莫名发酸，竭力定了定神：“……我拿了他的账本。”

周诚没露出惊讶神色，只把削好的萝卜丢进碗里，擦了擦手：“我知道。那本账是我留给他的。1964年那批发往省城的米，经手人从青江调到省城后再没回过青江。我花了半年查到他的下落，又跟了半年，才弄清楚那笔米去向哪儿。”

“哪儿？”苏荷追问。

周诚抬眼看她，目光沉沉的：“省城第三招待所。那批米被记账入了招待所的库房，实际却转手卖给了南边、北边三个黑市。中间人不是王家，但经手人收的钱入了王家的账——王家当年在青江管后勤的，是现在的王局长。”

苏荷心里飞快地把这些信息串起来：王家现在管后勤，在青江市局里说话有分量；而那笔米是被人从中做了手脚，挪去黑市了。那家招待所现在的承包人是谁？这中间还有没有活口？她张嘴要问，门外忽然传来三声急促的咳嗽——顾长山的声音。

苏荷霍然站起。周诚也同时放下手里的刀，目光一凛：“有人来了。”

门外果然响起了脚步声，不止一个，至少有四五个人，正朝着十四号门的方向越走越近。那灰布棉袄的汉子“哐”地吹灭了油灯。堂屋里陷入一片黑暗，只听见周诚低低说了一句话，几乎是气音：“把那半本账也带上，从后院走。别回头。”

苏荷攥紧了那张收据，没有半刻犹豫。她一脚踹开后窗，翻身跳下土台时，身后的院门已经被人拍得山响。

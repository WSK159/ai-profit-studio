# 第409章 灶台外头

顾长山几乎没有犹豫，一把扯下马灯罩子，灭掉火，整个西院陷入黑暗。

“走。”他在苏荷耳边低语，“进石室。”

苏荷扶着柳三更，三人快步退向井口。骆裁缝跟在最后，随手从腰间摸出一把短锥，反手捏在掌心里。

他们刚回到井下石室的暗门处，头顶的院墙方向传来一声沉闷的撞击，有人翻墙落地，脚步很轻，落地无声，是练家子。

骆裁缝用气声说：“别停。往里走。”

石室深处的通道通向更远的地方。苏荷记得砖房地图上画过——柳家西院的井下有一条暗道，通向白水河边。

她当机立断，扶着柳三更朝深处走。通道尽头是一扇铁门，门上挂着一把锈锁。苏荷摸出柳三更给她的那把钥匙，插进锁孔，转了三圈。

铁门“嘎吱”一声弹开，一股带着河水腥气的凉风扑面而来。门外是一条窄窄的石阶，向下延伸，隐约能听见水流的声响。

“从这儿能到河边？”苏荷问。

柳三更点点头：“当年漕帮卸货的暗码头。”

苏荷让顾长山先下去探路，然后回头看了一眼通道深处。黑暗中传来脚步声，不紧不慢，像是一点也不着急抓她们。

这种笃定让她心里发紧。她摸了一下怀里那块“令”字木牌，低声问骆裁缝：“他找的到底是什么？”

骆裁缝压低声音：“你师父说，缸底下压的，不是名单。名单是幌子，真正的物件是一封手书，是当年漕帮帮主写给一个人的信。信里写了那个人骗走一批官盐的账目，那批官盐后来被卖给南洋商人，换了军火。”

苏荷心里一沉。她想起前世的那句传言——师父最终不是因为厨艺而死的。

“那个人是谁？”

骆裁缝没有说话。但他目光里那种压不住的惊惧，让苏荷明白了——那个人，现在还活着。

石阶尽头是一扇半掩的木门，门外是河滩。夜色里，白水河泛着幽暗的光，一艘木船静静泊在岸边的柳树下。船上没有灯，船头坐着一个身形佝偻的老人。

苏荷瞳孔猛缩——那是老艄公。

船上的老人缓缓抬起头，隔着雾气看了她一眼，开口：“丫头，上船。你师父让我在这儿等了七天，就等今天这一天。”

苏荷回头看了一眼身后的暗门。通道里脚步声停了，停得很近，仿佛那个人就站在铁门后面，正透过缝隙注视着她。

“走。”她把心一横，扶着柳三更上了船。

船离岸时，苏荷回头望去。暗门处的石阶上，一道身影影影绰绰地站着，没有追出来，只是静静地看着她离去。

骆裁缝站在船舷边，脸色白得像纸。

“他没追。”苏荷说。

老艄公慢慢撑起竹篙：“他不会追的。他要的东西，不在你身上。”

“在哪？”

老艄公把竹篙插进河底，船身平稳地滑入夜雾之中。他偏过头，浑浊的眼睛望向苏荷：

“你师父让你学的那最后一道菜，不在灶台上。”

白水河的雾漫上来，将身后的柳家西院一点点吞没。苏荷握着手心里那块“令”字木牌，指尖冰凉，耳中回响着老艄公那句话——

那最后一道菜，不在灶台上，在灶台外头。

# 第351章 灰中酿酒

苏荷回到城南巷苏记小馆时天边刚泛鱼肚白。她没惊动睡在灶房旁屋里的苏桃，径直进了灶房，点了火，把铁锅烧热。

她取了一小撮井底小坛中的灰白粉末，撒入锅中。灰遇热，先是一阵干燥的焦气，随后和上次一样，一股浓烈的酒香升腾而起来。但这回比上回更浓、更厚，像是在鼻尖上炸开了一朵花。

苏荷把火压小，将牛皮纸摊在案板上，又看了一遍那六个字：“三蒸三晒，桑枝引火，石臼研细，取花心之一撮。料熟则酒成，酒成则信出。”

她盯着“料熟则酒成”四个字，心中反复转念，忽然把视线落在铁钎上。钎头微钝，但尖端有一个凹槽，像是用来挑什么物件的。她思忖片刻，拿起铁钎，把尖端伸进牛皮纸包裹的小坛中，轻轻一拨。坛底的灰被拨开，露出一粒指甲盖大小的深褐色东西。

苏荷用铁钎小心地挑出来，放在掌心一看——是一粒干透的花蕾，紫褐色，形如小钟。是桂花，但年份久了，色彩已经完全沉下去。她凑近闻，一点若有若无的香味都没有。

她明白了：三蒸三晒的是这桂花，桑枝引火是蒸熏的烧柴，石臼研细，取花心撮入灰中——这灰不是普通的灰，是桂花烧成的花灰，跟底灰混合，酒香才会出来。

“这封信，”她喃喃，“就在酒里。”

她按着步骤，把整坛灰白粉末倒进石臼，又取来干桑枝生了火。铁锅里的水烧开，她架起竹蒸笼，把石臼中的灰分三层铺在纱布上，隔水蒸了三遍，每遍小半个时辰。蒸完摊开在竹席上，晾干，又蒸，三蒸三晒之后已是午后。

灰的颜色由灰白变成了浅褐色，蓬松、干燥、带着一种说不清道不明的沉郁香气。苏荷取了石臼把那灰细细研了三遍，直到细如面粉。最后一步——取花心之一撮，她把那粒干桂花剥开，里面还有一粒更小的、颜色深红的柱头，她取了小半粒，混入灰中。

灰入瓦罐，封口，置于灶膛余温处。苏荷守在旁边，盯着瓦罐。

一刻钟后，罐中传出一声沉闷的细响——像什么东西在罐内破裂。苏荷掀开封盖，一股比她前世任何一坛陈酿都醇厚的酒香扑面而来，浓郁得几乎能把人醉倒。

酒香中，她看见罐壁上凝出一层薄薄的水雾。水雾缓缓凝聚、滑落，在罐底汇成一小汪透明的液体——只有小半碗。苏荷用干净的瓷碗接住那汪水，端起来放在鼻下。没有酒味了，却有一种极其古老的墨香。

她明白了。那封信不是写在纸上——是溶解在酒里的。

苏荷从怀中取出那五字纸条，把碗中的水缓缓滴上去。墨迹遇水，竟渐渐化开，纸条上原本的字迹褪去，更多细如蚁字的笔迹浮现出来，一行行排成数百字。

苏荷屏住呼吸，读完了第一行：四十七年，我欠董家的那碗面，今可还矣。落款处，一个篆字——沈。

“沈……”她低声念出这个姓氏，脑海里猛地闪过一个念头——前世她师父房中那张旧照片里的背影，那人矮瘦，穿白围裙，背后挂着一块招牌，招牌上写着一个“沈”字。

她握着纸条的手微微发颤。灶房外，忽然响起了脚步声，由远及近，停在门口。有人敲了三下门，声音不疾不徐：“苏老板，出事了。”是何九斤的声音，但语调比平时更沉，“城里来了几个外乡人，在巷口打听‘苏记’的牌子，说是——要买你名下这间铺子。”

苏荷把纸条迅速收进贴身衣袋，铁钎塞进灶台与墙壁的缝隙里。她转身开门，脸上已是一副平常面色：“买铺子？你问他们，出多少钱。”

何九斤皱眉：“他们说是替‘老郑’办事的。”

苏荷脚步一顿，随即她笑了：“让他们进来，我炒两个菜，边吃边谈。”她话音未落，眼睛却落向巷口——那儿站着一个人，穿灰布衫，戴草帽，帽檐压得极低，正朝这边慢慢走来。她认不出那人的脸，但认得他的步子——一步重，一步轻，像受过伤的老兵。那人在巷口停住，像是看见了她，又像是没看见，转身就消失在了街角。

苏荷盯着那个消失的方向，慢慢说了一句：“何叔，你刚才说，‘老郑’派来的人，在巷口——是今天来的，还是昨天就来了？”

何九斤想了想：“今天。昨天没动静。”

苏荷心里那一根线，忽然绷紧了。因为方才那个戴草帽的人，她没有看清脸，但他转身的一瞬，她从衣角看出——那衣服的袖口，缝着一条暗红色的布边。她见过那种缝法，前世师父的老围裙上，也有一模一样的一圈红边。

她心里翻涌着，面上却不动声色，只说：“开火，把那坛新腌的酸萝卜切一盘，等下吃饭的人该来了。”她折身回灶房，在灶台边站了一瞬，抬手又摸了摸怀里的纸条。那行字像烙铁一样烫：“四十七年，我欠董家的那碗面，今可还矣。——沈”

她忽然想起前世的师父，他生前最爱说的一句话：“做菜没有秘密，只有人心。”她闭上眼，仿佛看见那个矮瘦的老人站在灶台边笑，背后挂着一块旧招牌，写着“沈”。而那个招牌下，压着一封信，封皮上写着——“苏荷亲启”。她从未拆开过那封信。

# 第340章 归途

暮色四合，苏荷抱着那本泛黄的《灶台百解》立在绸缎庄门口，顾长山提着包袱跟在她身后。

“山路不好走，趁天亮多赶一段。”顾长山顿了顿，“要不，让我看看那封信？”

苏荷摇头，将信纸小心折好塞进内兜。信上只有寥寥数行，周明善的字迹苍老而颤抖：“广田入赘苏家，自述愿以一生赎罪。我知他愧疚，遂允他照料炉火。然吾之死，非他一人之功也。老宅灶下三年，吾偶得软骨散之踪，疑有人欲以药毒我。广田胆小，不敢言，唯以泪洗面。吾不忍责之，遂拟此信，盼有朝一日，水落石出。”

“你父亲……当年是个烧火的小子？”顾长山低声问。

苏荷想起苏广田那张常年佝偻、逢人便笑的脸，忽然觉得陌生。她记得前世最后一次见父亲，是自己在城里站稳脚跟后，他拎着一兜橘子来店里，说她“出息了”，说想抱抱外孙。那时她心软，给他煮了碗面。

“他是不是凶手，回去问就知道了。”苏荷迈步朝汽车站走，“但我师父那封信里说得很清楚——还有另一个人，下了软骨散。”

“何九斤说，那药是从灶上出去的。”

两人沉默着走了半里路。苏荷忽然停下，转过身，目光落在顾长山脸上：“你还跟我回青江吗？”

顾长山没答话，只是握紧了手里的包袱。

长途汽车颠簸了六个小时，到青江时已是深夜。苏荷没回小馆，径直拐进城南巷深处那座老宅——钟大川留在这里守着周明善的遗骸。

门虚掩着，灶膛里还有余烬。钟大川坐在门槛上打盹，听见脚步声抬起头：“师父的骨灰我安置在后院桂花树下了。你俩……没出什么事吧？”

“没事。”苏荷蹲下来，从怀里掏出那封信，“钟叔，我找到师父的遗书了。里面说——害我师父的，不止我爹一个人。”

钟大川接信的手一顿，就着灶火看完，脸上的横纹深深皱起来：“软骨散？那玩意儿是郑家老宅传下来的方子，只有灶房里的嫡系知道。”

“师父的意思是，有人借着郑家旧关系，把药下到师父的吃食里，我爹知情不报。”苏荷盯着灶膛里跳动的火苗，“所以我想知道——当年除了郑家，还有谁跟师父走得近？”

钟大川沉默片刻：“你可记得，周明善在郑家灶上时，收过一个干儿子？”

苏荷一愣。

“姓冯，叫冯立本。后来郑家败了，他迁去省城，在王记绸缎庄隔壁开了间药铺。”

“王全福隔壁？”苏荷猛地直起身。

“对。那冯立本，早年是郑家灶上的伙计，拜了周明善做干爹。但后来不知怎的，两人闹翻了，冯立本再没登过郑家的门。”

顾长山忽然开口：“绸缎庄隔壁的药铺——我们今日路过时，王全福特意绕开了那间铺子。”

苏荷心头一跳，那些碎片在脑中猛然拼拢。王全福交出信时，多说了句“若不是冯老板提点，我也不知周师父留有遗物”——可那提点，倒像是故意指向周明善的遗书。

“回去睡觉，天亮了去见冯立本。”苏荷眼底浮起一丝锋芒，“我倒要看看，当年害我师父的那味软骨散，究竟是郑家传下的祖方，还是有人后来配的。”

钟大川颔首，忽然从灶台下摸出一个油纸包：“何九斤走时留下这个，说是从老宅墙缝里抠出来的，一直没敢打开。”

苏荷接过，拆开一角——里面是一小撮灰白色的粉末，散发着一股极淡的苦杏仁味。

那味道，她在米其林后厨见过，那是——砒霜长期微量服用的残留痕迹。

# 第420章 黑铁牌

那只手瘦骨嶙峋，指节青灰，指甲缝里嵌满黑泥，却死死攥着一块乌沉沉的铁牌。铁牌不过巴掌大小，边角磨得圆润，隐约可见上面錾刻的纹路——不是字，是一道水波纹，像是河面上被风推着走的浪。

苏荷的心跳漏了一拍。她认得这种纹路，前世师父的旧物匣里，有一块同款的墨玉镇纸，底下的刻纹一模一样，她曾经好奇地问过，师父只说了一句：“那是水的路。”

“谁在里面？”顾长山已经迈前半步，把苏荷挡在身后，声音低沉，却带着不容置疑的威压。

柴房里一片死寂，只有风从破瓦缝里钻进来，呜呜地响。

那只手动了。铁牌被缓缓放到地上，指尖在地上划了两下——像在写字，又像是在摸索什么。苏荷蹲下身子，借着从门缝漏进来的天光，看见那铁牌旁边，泥地上画着一个歪歪扭扭的图案。是一个圈，圈里一道斜线，斜线尽头勾了一个弯。

“这个——”苏荷猛地抬头，看向沈伯言，“这是我前世师父案上那幅画的落款。”

沈伯言眼神一凝，快步上前，蹲下身仔细看了片刻，嘴唇翕动：“这是漕帮的暗号，‘河底有货’的记号。画在门板、墙根、船帮上，是告诉帮里的人，这里藏着东西。”

他顿了顿，指尖捻起那块铁牌，翻过正面，赫然露出一个“漕”字。铁牌背面，錾着一朵五瓣梅花——和账本封底那枚印一模一样，只是小了一圈。

“这是漕帮的帮牌，”沈伯言的声音有些发涩，“持牌者走的是水路，见牌如见帮主。但柳春江的私牌，怎么会在这里？”

那只手已经缩了回去，柴房深处传来细碎的动静，像是有人在挪动身体。顾长山正要迈步进去，苏荷却拉住了他的袖子：“等等。”

她盯着地上的暗号，又看了看那口破缸。缸底裂开的缝隙里，刚才就是那只手伸出来的地方。她忽然开口：“钟家后院的地底下，是不是挖过暗道？”

灰布老头浑身一震，原本浑浊的眼睛里闪过一丝精光。他张了张嘴，最终还是点头：“钟老爷说，后院地下有一条暗渠，是当年修建宅子时留下的，通到白水河，涨水的时候能进船来。后来宅子几经易手，暗渠早就填了土。只有柴房下面这段，还留着个小地窖，藏一些要紧的东西。”

“要紧的东西？”苏荷看着那口破缸，“比如官银？”

灰布老头没有回答，但他脸上的皱纹抽动了两下。

柴房里忽然传来一声低哑的咳嗽，像是风箱漏了气。随后，一个苍老的声音从破缸后面传出来：“丫头，你过来。”

苏荷犹豫了一下。顾长山却摇了摇头，低声道：“我来走前面。”

两人并肩绕过那口破缸，只见缸后的墙根下，不知何时被扒开了一个半人高的洞。洞里蜷着一个瘦小的身影，裹着一件灰扑扑的棉袄，头发乱如枯草，看不清面目。但那块黑铁牌，此刻已经拿回他手里，正搁在膝盖上，一下一下地摩挲着。

“你看这牌子，”老人又咳了两声，“上面这个梅花印，是不是和你那账本上的一样？”

苏荷微微眯眼。她没急着回答，而是问：“你是谁？”

老人抬起头来，露出一张沟壑纵横的脸，一双眼睛却亮得惊人，像是夜里的猫。他上下打量苏荷，忽然咧开嘴笑了：“柳家祠堂‘地’字下面还压着一句话——持梅印者，承帮脉。你手里的账本，加上我手里的这块牌子，合在一起，才是完整的漕帮信物。”

沈伯言倒吸一口凉气：“你是说，苏荷手里的账本是半把钥匙，老王手里的铁牌是另外半把？”

老人没有接话，目光落在苏荷腰间的围裙口袋里。那里面，放着她从钟家正房夹层里取出的那封信——柳春江遗信，上面有未尽之言，右下角那个墨迹洇开的点，一直让她介怀。

苏荷慢慢掏出那封信，展开，递到老人面前：“柳帮主写的信里，最后这个点，是没来得及写完的字，还是故意留下的记号？”

老人的指尖触到信纸的那一瞬，整只手都在抖。他死死盯着那个墨点，嘴唇翕动了好几次，才沙哑地挤出一句话：“这不是他写的。这是他哥写的。”

钟大川隔着院墙，声音忽然炸开：“你说什么？”

老人缓缓抬起头，望向声音传来的方向，眼里露出一丝复杂的光：“钟大河，没死。他改了名字，换了一张脸，在船上当了二十年的舵工。柳春江这封信，是他弟弟死前脱人带出来的——落款那个点，是钟大河蘸着血按上去的。他是在告诉后来人——拿信的人，就是杀他的凶手。”

苏荷捏着信纸的手一紧。信纸边缘，那个墨点的深褐色确实不像是墨——那是早已干涸的血迹。

她忽然想起账本缺页里夹着的那张黄纸上写的话：“己亥年冬月，白水河底凿船者，持衙门铁牌，腰悬柳字玉坠。”——当初她以为凿船者是持官府令牌的人，直到此刻她才明白：持衙门铁牌的不是官府的人，而是拿了衙门赏金的漕帮内鬼。那人腰上挂着柳家的玉坠，是柳春江亲手挂上去的信物，却成了栽赃的钥匙。

“钟大河现在在哪儿？”苏荷的声音冷下来。

老人没有回答。他伸出一根枯瘦的手指，指着苏荷手里的信纸，忽然说：“你翻过来。”

苏荷翻过信纸，背面竟还有一行小字，被折痕藏得极深，她与沈伯言方才都没有注意到：“白水河第七道弯，沉船下头三丈三，铁链拴着一个箱子。箱子不是银子——是账簿。二十年的漕运账簿。”

那一瞬间，所有线索都串在了一起。

钟家旧宅里那口枯井、灶孔、正房阶下画的布局图，指向的根本不是藏银，而是指向那份账簿的去向。而那份账簿里，记着的不是货物——是沿江十七个码头的孝敬钱、官府分成的数目，还有当年凿船案发后，从底舱里捞出来的那些人的名单。

老人叹了口气：“那箱子出水那天，我就是第一个伸手去捞的人。”

他摊开右掌，掌心里一道狰狞的旧疤，从虎口延伸到腕根，像是被什么东西硬生生撕开的：“我捞到箱子的时候，锁眼已经被人用铁水焊死了。我用了三天，凿不开。后来我听见箱子里有动静——”

他顿了顿，声音忽然低下去：“里头有人。”

风从瓦缝里灌进来，吹得那封信纸猎猎作响。苏荷正要再问，院墙外突然传来钟大川撞门的声音，紧接着，一阵急促的脚步声从院门外由远及近，还伴着什么人歇斯底里地喊了一句：

“苏老板！你让我盯的那个磨坊——起火了！”

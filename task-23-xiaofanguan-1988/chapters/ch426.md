# 第426章 子时赴约

夜色浓得像一锅熬过了头的药，苏荷把围裙叠好放在案板上，转身从灶台下摸出那把錾水纹的黄铜钥匙。钥匙在掌心沉甸甸的，水纹的纹路像河底流动的影子。

苏桃蹲在门槛上，手里攥着一块抹布来回搓：“姐，你真要去？那老头又凶又怪的。”

苏荷把钥匙揣进衣兜，弯腰捏了捏苏桃的耳朵：“你守着店，后门闩好。我若丑时还没回来，你就去街道办找顾长山。”

苏桃想说“你去找他不行吗”，话到嘴边又咽了回去。她太清楚自己姐姐的脾气，犟起来九头牛都拉不回。

子时的河水起了薄雾，白水河一改白日的浑浊，在月光下泛出一层铁青色的冷光。苏荷打着手电筒走到第七道弯，那棵歪脖老柳树的影子斜斜地拖在水面上，树皮上那个新刻的“沉”字在手电光下像一道睁开的眼睛。

“来了？”

声音从柳树背后传来。苏荷猛地转身，神秘老头蹲在树根处，手里捏着一根旱烟杆，烟锅里的火星明灭。

“钥匙带来了？”他问。

苏荷没答，只把钥匙从衣兜里露了个头。老头盯着钥匙看了片刻，忽然咧嘴一笑：“那渠是民国三十七年修的，你脚下踩的这片地，原是钟家老宅的河埠头。”

苏荷心里一动：“钟大河修的？”

老头抽了口烟：“钟家人修的。当年钟家在这条河里沉了东西，怕人捞，就修了这条暗渠把东西引到别处去。河底那口铁箱，拴在暗渠的铁链上，三长两短是钟家传下来的暗号，开箱的机括就在这钥匙上。”他指了指苏荷手里的黄铜钥匙，“钥匙上錾的九道水纹，对应暗渠里九道闸。”

苏荷盯着手里的钥匙，忽然问：“你到底是什么人？”

老头站起来，烟杆在靴底磕了磕：“我是钟家当年的长工。那年夜里沉箱，我亲眼看着钟大河被人按在船板上，铁箱里装的是他小女儿。”他笑了笑，眼角的皱纹像刀刻的，“后来钟家败了，我在河对岸种了三十年地，就等着有人找到这第七道弯。”

苏荷心头一跳：“箱子里有人？”

老头没接话，转身朝暗渠方向走。苏荷攥紧钥匙跟上去。青石板嵌铁环的位置仍在，老头从怀里摸出一根铁钎，撬开石板边缘的泥封，露出底下一条仅容单人侧身通行的土道。

“你下去，到第九道闸口，用钥匙拧三圈。铁箱就升上来。”

苏荷看着他：“你不下去？”

老头蹲在洞口，烟杆在膝盖上敲了敲：“我下不去。那渠里钉着钟家的咒——外人下渠，铁箱永沉。这是钟大河的规矩。你姓苏，姓苏的人不犯冲。”

苏荷没说话，弯下腰钻进土道。土道里一股河泥和铁锈混合的腥气扑面而来，她摸到湿滑的砖壁，一路向下走了好一会儿，果然看见一道锈迹斑斑的铁闸门，门上一把兽首锁，锁孔的形状与钥匙齿完全吻合。

她拧动钥匙。三圈，咔哒一声，锁舌弹开。机括声在黑暗里像一串滚动的珠子，从脚底一直窜到头顶，不知多远的地方传来铁链哗啦啦升起的声响。苏荷屏住呼吸，手电筒往前照——前方的水渠里，一个铁箱正缓缓从水底升起来，箱壁上糊着厚厚的河泥和贝壳，锁扣上缠着一段红绳。

红绳已经褪成了趴粉色，但系法特别——双环扣。

苏荷认出这个结法的时候，手猛地一僵。这是她前世师父教她系的第一种绳结。师父说，这结法他师娘教他的，天底下再没有第二个人会。

铁箱停在水面上方三寸的位置，不再上升。苏荷凑近细看，箱盖的缝隙里露出一角泛黄的纸。她伸手去抽，纸湿了一角，尚未完全洇开。她打着手电，一个字一个字地认——

“吾女荷儿，见字如面……”

苏荷手一抖，手电筒差点掉进水里。

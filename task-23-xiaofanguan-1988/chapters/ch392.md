# 第392章 缸碎

苏荷来不及细想竹板失踪的事，老人倒在码头是眼下最要紧的。她解下围裙，对苏桃喊了一声：“你看铺子，出什么事等我回来再说。”

苏桃站在灶间门口，手里攥着一块抹布，嘴唇动了动：“姐，那竹板……”她停住了，因为苏荷已经跨出门槛，顾长山紧跟在后面，脚步很大。

老杨在巷口急得直搓手，见他们出来，朝码头方向一指：“人在老石阶那儿，邮局的老赵发现的，说是一头栽下去，口吐白沫，脸色都青了！”苏荷一路小跑，穿过巷子，拐上沿江的石板路，远远看见一群人围在老石阶上，有人蹲在中间。她挤进去，看见老人仰面躺在地上，嘴唇乌紫，眼睑微垂，嘴角有少量白沫，胸口还在微弱起伏。蹲在他身边的是一个穿灰布褂子的中年人，正用一条湿毛巾擦老人的脸。

“让让。”苏荷蹲下，伸手探老人的脉，跳得很乱，浮而无力，但没绝。她翻开老人的眼皮看瞳仁，两瞳孔等大，对光反应还在。她心头稍松，抬头问：“有没有人喂他东西？水、或者别的？”围观的几人面面相觑。老赵说：“没喂，谁也不敢动。我打了电话，街道卫生所的人马上来。”

顾长山单膝着地，看一眼老人的面色：“像是中毒样的，但不是砒霜。砒霜毒到这份上，瞳孔早散了。”苏荷点头。她闻到一点极微弱的苦杏仁味，若有若无地浮在老人衣衫上。她皱了皱眉，俯下身，轻轻凑近老人嘴角，味道更浓了一些。她忽然想起来了，这是苦杏仁甙的气味，在米其林后厨，她见过处理不当的杏仁引发的中毒。但老人身上这个量，不至于这么重——除非是反复累积，或者掺杂了别的什么。

“今晚他吃什么了？”苏荷直起身问。“老常跟你们馆子吃了红油抄手啊。”旁边一个妇女答腔，“他晚上吃了抄手才去码头散步的，哪知道就出了事。”人群议论声四起，有人朝苏荷看了一眼。苏荷心里一沉，面上不动声色：“我馆子的料是我亲手调的，苦杏仁一滴没有。”顾长山已经走到一侧，问老赵：“他在码头哪个位置倒的？”

老赵比画：“就西段系缆桩那块，就是那些换过绳子的杆子旁。”苏荷心里头一紧，系缆桩——顾长山刚查实那地方被人换绳夯土，草帽人晚上的船就是从那里靠的岸。老人的手攥着，她蹲下想掰开，发现他手里捏着一小片碎瓷，青白色，有釉光，像是井碗的碎片。她不动声色地收了那片瓷片。

卫生所的人来了，把老人抬上担架。苏荷盯着老人被抬走的方向，面色沉静，心里却在翻腾。竹板失踪，老人倒在了换过绳的系缆桩旁，手里攥着一片井瓷，而她馆子的抄手成了第一嫌疑。这三件事凑在一起，步步都指向苏记。

顾长山走回她身边，低声道：“那系缆桩的土有人动过。”他手掌摊开，指缝间夹着一小撮湿泥，泥里混着一点白灰。“石灰拌的夯土，不是码头上的人干的，是懂行的。”苏荷点头，目光越过人群，落在江面上。月光照在江心，水纹幽幽地荡着。她忽然想起竹板上的那七个字：石下三寸，缸上七锁。而老人倒的地方，离那口老井——就是那口青石井，不到二十步。

她低声说：“长山，把那口井封了。”顾长山一愣：“井？”苏荷道：“竹板不见了，但字我记住了。缸上七锁，我先前一直想‘缸’是什么，直到看见井沿边上那一圈凿痕，那分明是缸口嵌泥的痕迹，井口那圈是个旧缸压出来的印记。”她抬手指了指青石井：“有人几十年前把一口缸埋进了井底，等着谁去打开。”

顾长山瞳孔微缩：“七锁呢？”苏荷道：“锁头不在井底，在别处。七把锁，锁着七道关系，码头、铁匠、渡工、派出所、老主顾、馄饨摊，还有我们馆子。有人怕我真解开，才把竹板收了。”她顿了顿：“也有人说，老人知道那口缸的秘密。他今晚栽在井边，不会是巧的。”

卫生所的人走远了，人群也渐渐散开。苏荷转身，朝苏记走去，步子不快，但一步一步极稳。路过豆腐坊时，老杨探头问了一句：“苏老板，没事吧？”苏荷微微一笑：“没事，饭照开。”

她推开苏记的门，灯还亮着。苏桃站在灶间门口，手里捧着一片东西，面色发白：“姐，竹板找到了。”苏荷脚步一停：“在哪？”“缸里。”苏桃指着灶间角落那口腌咸菜的大水缸：“我刚去打水，发现它漂在缸面上。”苏荷走过去，低头看那竹板，湿漉漉地浮在缸面上，刻字的那一面朝下。她伸手捞起来，翻过正面——

“石下三寸，缸上七锁”八个字被人用刀片削去了最后一个“锁”字，只剩“缸上七”。

她手指摩挲着那块削痕，慢慢地笑了。这竹板不是失踪了，是有人送回来，替她削掉了一个字。缸上七，那七把锁里，已经有人替她开了一把。

她把竹板放进围裙兜里，转身对顾长山说：“明天一早，去城南路派出所，找那个姓秦的民警。”

顾长山点头，没问为什么。

窗外，江风吹过巷口，馄饨摊的煤炉子明明灭灭，女人手腕上的青黑疤痕藏在灯影里。

# 第206章 石桥下的铁盒

清晨五点半，城南巷还笼在一层薄薄的雾气里。苏荷没开灯，就着窗外透进来的灰白光线，把那片写有“老十二、铁盒、石桥下、勿信周”的纸片再次铺开在灶台上。

字迹是毛笔写的，墨色沉旧，与账本里的珠算暗语明显出自同一人手笔。翻过来，纸片背面有一道极浅的折痕。她仔细捏起对着光一照，折痕上方微微透亮——是贴层的痕迹。

她取了温水，用指甲尖极小心地沿着纸片边缘捻开一张薄薄的浆糊纸。底下露出一行更小的字——城南月牙桥，此处才是真盒。

苏荷的呼吸停了一拍。月牙桥在城南，离她的小饭馆步行不到二十分钟，是六十年代建的一座石拱桥，桥面两侧各有一处石狮子，前年市政翻修时换过一只，据说另一只是老物。

“苏姐，今早的包子还蒸吗？”学徒小周的声音从门外传来。

苏荷把纸片折好收进贴身衣袋，拉开后门：“蒸。你先把面和了，我去城南办点事，赶在九点前回。”

小周应了一声，苏荷从后厨顺了一把剔骨尖刀别在腰后，又从门口纸箱里抄起半块砖头塞进布袋。她出门前顿了顿，将灶台上拌好的红油辣子舀了一小罐，裹在油布里挎在肩上。

城南月牙桥。清晨的河面上飘着淡薄的水汽，桥洞下只有几个早起洗衣服的女人蹲在石阶上搓衣裳。苏荷站在桥头看了片刻，沿着河岸往下游走，寻到一处隐蔽的石阶，从桥墩侧面攀了下去。

桥拱与河堤之间的夹缝只容一人侧身。她蹲下，手在蓬草与碎石间摸索。手指在第三块石板内侧触到一条竖直的细缝，她指甲一抠，石板松动，底下赫然嵌着一只锈迹斑斑的铁盒，尺寸巴掌大，表面覆着一层厚厚的油泥。

她把铁盒揣进布袋，原路返回，翻上岸时却听到身后有脚步声追上来。她没回头，手指已摸到布袋里的刀柄。

“苏同志，你起得真早。”

来人声音温和，穿着一件洗得发白的深蓝中山装，推着一辆自行车——正是街道办的梁副主任，本名梁国庆。他脸上带着那副惯常的斯文笑容，推车走到她面前，目光不着痕迹地扫过她挎着的布袋。

“梁主任也起得早。”苏荷不动声色。

“听老赵说你最近在打听货场的事。”梁国庆语气随意，“我就是提醒一句——那边最近治安不太平，你一个姑娘家，少往那种地方跑为好。”

苏荷盯着他的脸。前晚从北站货场找到的半张军装照片中，那个面容与梁国庆极其相似的男人，如今就站在这张脸的背面。她笑了一下：“梁主任消息真灵通，我不过是去赶早市。”

梁国庆没多留，推车走了。苏荷站在原地沉默片刻，绕了三道街，确认无人跟踪，才拐进城南一家废弃的纺织厂大门。

她找了个角落蹲下，擦净铁盒上的油泥。盒盖没有锁，只有一道锈死的卡扣。她用刀尖一撬，“咔”一声弹开，里面静静躺着一本薄薄的蓝皮册子——是账本的第二本，封面写着“青江市民食供应账目(1961年)”。

翻开第一页，密密麻麻的珠算暗语记录了当年青江市粮油副食品的调配记录。她翻到最后几页，突然停住。某一页备注栏里写着“周记国营供销科——梁实初经办，羊肉一百二十斤，去向：粮店北仓。”而梁实初，正是梁国庆的父亲。

一切都串起来了。梁家当年经手了这批羊肉，而账本第一本里记着的老十二，恐怕与这件事有千丝万缕的牵连。

她正要合上账本，盒底突然滑出一张叠得极整齐的纸。展开——竟是一张青江市城南巷“苏记小馆”铺面的地契，上面写着：因欠款未还，本铺面抵押予持有人。

署名处——老十二。

苏荷捏着地契的手微微发紧。她名下的这间铺子，地基下竟埋着一桩几十年前的旧债。她刚把地契收进怀里，纺织厂破败的窗洞外，远远传来一声钟响。八点整。

那通匿名电话约定的是九点，北站货场。

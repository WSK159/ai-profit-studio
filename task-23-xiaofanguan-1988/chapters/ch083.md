# 第83章 夜探货栈

夜风从巷口灌进来，带着一股江水的潮湿气味。苏荷盯着那块“何记货栈”的木牌，脑子里飞快地转着念头。

“何记”——跟何五爷有没有关系？还是说，只是碰巧同姓？

顾长山显然也注意到了那块牌子。他压低了声音：“就算是同姓，也不一定是同一人。咱们别急着下结论。”

苏荷点了点头，但没有退的意思。她看了看四周，巷子两侧都是砖墙，墙根堆着杂物，有一辆锈迹斑斑的自行车靠在角落。铁皮门右侧的墙上有扇半开的窗户，离地面大约一米五，没有装铁栅栏。

“从窗户翻进去。”她说完，悄悄朝那扇窗户摸了过去。

顾长山想拦住她，可看她已经猫着腰到了墙根，只好快步跟上去，嘴里低声道：“你胆子也太大了。”

苏荷没答话，双手搭上窗沿，一撑一蹬，整个人像只猫似的翻了上去。窗户里头是间堆放杂物的屋子，堆着些旧麻袋和木板，靠墙一侧还放着一张行军床，上头铺着一条灰扑扑的毯子。

她落进屋里，还没来得及打量四周，就听见门外传来脚步声。

苏荷迅速蹲下，躲到一张歪斜的旧桌子后面。顾长山也跟着翻了进来，两人并排蹲在桌后，大气不敢出。

脚步声越来越近——然后停在了门口。有人从门缝里探进头，是个男人的声音：“东西搬完了没？”

另一个声音从远处传来：“还剩两坛，在里头呢。”

门被推开，一个穿着灰布褂子的小个子男人走了进来，径直绕过桌子，到墙角弯腰去搬一个坛子。那坛子不大，褐色的粗陶，坛口封着黄泥——跟苏荷在渡口截下的毒盐坛子一模一样。

小个子男人抱起坛子往外走，脚下一个趔趄，险些摔倒。他骂了一句：“妈的，沉死了。”

门外那人笑道：“当然沉，这坛子装了得有一百斤。”

苏荷的指甲掐进掌心里。一百斤——三百斤毒盐，三只坛子，对得上。

小个子男人抱着坛子出去了，脚步声渐远。苏荷正要起身，却被顾长山一把按住肩膀。

“等等。”他低声道，“还有人。”

果然，过了大约半分钟，又一阵脚步声从走廊深处传来。这次更轻，更像是一个人独自走动，步子极慢，像在数着脚步。

那脚步声经过门口时顿了一顿，接着从门外伸进一只手来——一只枯瘦的、指节粗大的手。

那只手抓住门框，往里探了探，像是在摸什么东西。片刻之后，手缩了回去，脚步声继续往前走。

苏荷后背出了一层冷汗。方才若不是顾长山按住她，她恐怕已经在那一瞬间起身，正好被那只手摸到。

顾长山也松了一口气，松开按在她肩上的手，低声道：“这里头的人比咱们想的多。先撤。”

苏荷这回没犟，点了点头。两人从窗户翻出去，落在巷子里的阴影中，脚步无声地回到南关街口。

夜色已深，街面上的铺子大半关了门，只有一家烧饼摊还亮着灯。苏荷和顾长山在烧饼摊前站定，买了两块烧饼，蹲在路边吃。烧饼是刚出炉的，热乎，芝麻香混着麦香，甜丝丝的，像一股暖流从喉咙滑下去。

苏荷咬了一口，含含糊糊地说：“那坛子，跟渡口截下来的那批一模一样。”

顾长山点头：“从这个货栈的位置看，跟利丰船务就差一条街。他们运货、存盐、发货，全在这片区域转。”

苏荷咽下最后一口烧饼，擦了擦嘴：“今天咱们没白来。至少知道了有一个何记货栈，还知道了他们在这儿存了一百斤的坛子。但是——”她顿了顿，“洪三今天一天都没露面。我盯了一下午，三记粮油铺里进货出货，都是那个妇女在打理。”

顾长山沉默了一会儿，忽然开口：“你觉得洪三不在南关街？”

“也可能，他压根就不在省城。”苏荷抬起头，目光落在远处江面上星星点点的灯火上，“我记得在渡口的时候，陈福说过一句话——洪三上头是‘省城贵人’。这个贵人，会不会就是何五爷？”

顾长山的眉头锁得更深了：“何五爷的名头，我在街道办的时候就听过。此人据说是从码头扛包起家的，后来不知怎么发了财，开了几家贸易行，在省城商界也算一号人物。但要说他跟贩私盐有关系……”

“越是干净的人，越要查。”苏荷打断了他的话，站起身，拍拍膝盖上的灰，“明天，我得去看看何五爷的买卖。”

顾长山也跟着站起来，看着她的眼睛：“你打算怎么查？”

苏荷嘴角微微勾起，露出一丝笑：“何五爷不是开了几家贸易行么？我正好有个菜方子，想卖给他尝尝鲜。”

顾长山愣了一下，随即明白过来：“你想以谈生意为名混进去？”

“正经吃饭，怎么叫混呢？”苏荷拍了拍他的肩，“长山哥，明天你陪我去，你在外头等我。要是里头有猫腻，咱俩里应外合。”

顾长山看着她，想说什么，终究只是点了点头。

夜风拂过街口，把烧饼摊的炉火吹得旺了一瞬。远处，江面上有一艘夜航船拉了响笛，呜——的一声，拖着长长的尾巴，消失在黑沉沉的江水里。

苏荷的目光越过灯火，望向城北那片黑魆魆的厂房。何记货栈的门牌，还在她脑海里晃着。

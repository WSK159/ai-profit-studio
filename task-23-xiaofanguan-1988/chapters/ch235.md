# 第235章 三味火

展销会那天早上，天还没亮透。

苏荷四点半就起了床。灶房里，那口铁锅已经养了一夜——前天晚上她用猪皮反复擦过三遍，又在锅底薄薄抹了一层菜油，拿炭火把锅烧到微红，再把油擦干净。铁锅的锅底已经泛出深蓝的光泽，像一潭静水。

她蹲下来，从灶台底下的陶罐里摸出一块东西。那是九制咸陈皮——钱岐黄给的。她掰下一小块，放在鼻尖闻了闻。咸、香、带着陈皮特有的微苦，再往下闻能闻到一丝若有若无的桂花气。这是赵德厚一脉的老做法，陈皮要九蒸九晒，最后一遍的汁水里要掺桂花蜜，封在陶罐里让性子沉下去。

“一上来就用这个？”苏桃站在灶房门口，手里端着一碗热粥。

苏荷接过来喝了一口：“宋国栋懂行，第一道菜不用引火，他尝不出深浅。”

她做的是红油抄手——看似是苏记的招牌，但今天这道抄手和店里卖的完全两样。皮子她连夜擀的，比店里薄了三成，馅料里多加了一味陈皮水，用咸陈皮的苦香去吊肉馅的鲜甜。最关键的是辣油：她用陈皮引火，把花椒、辣椒、八角、桂皮按不同顺序下锅，火候一到，油的香气一层一层地炸开，最后一飘桂花味收尾。

七点钟，苏荷到了工人文化宫。丙区第七号灶位，位置靠里，不是最好的位子。她在灶台前站定，先点火，烧水，然后慢条斯理地开始包抄手。

周围的其他参展个体户陆续进场。有人认出了她：“那不是城南巷苏记的老板娘吗？怎么来参加厨艺展销了？”一个年轻厨子探头看了一眼她包抄手的手法，脸色就变了，拽着同伴躲远了几步。

八点半，宋国栋带着两个评委巡视场馆。他走过丙区第七号灶位时，脚步顿了一下——苏荷正把那块九制咸陈皮从陶罐里取出来，切丝，入油。

陈皮入锅的瞬间，滋啦一声响。一股异常清亮的香气腾起来，没有盖过油味，反而把油香衬得干净了许多。宋国栋的脚步彻底停下来了。

他站了十几秒，然后开口：“苏老板，这道抄手，什么名字？”

“没名字。”苏荷头也不抬，手里捏抄手的动作没停，“味儿要是正，叫什么都不重要；味儿不正，叫什么都是骗人。”

宋国栋沉默了一会儿，走了。

九点钟开评。苏荷那碗抄手摆上去的时候，蓝色的粗瓷碗，一口汤红亮见底，抄手白里透粉浮在汤面上，顶着几粒白芝麻。三个评委先后舀汤试味。第一个评委喝了一口，顿了顿，又喝了一口，放下碗没说话。第二个评委尝了一只抄手，嚼了两下，眉毛抬起来，看了看苏荷，又看了看宋国栋。宋国栋是最后一个动手的。

他没有喝汤，先用勺子把抄手拨开，看了看里头的馅色，然后才舀了半勺汤送进嘴里。

那半勺汤在他嘴里停了好一会儿。他放下勺子，看着苏荷，说了一句话：“这火，你从哪里借的？”

苏荷迎着他的目光：“火不用借，花几年养出来的。”

宋国栋的目光深了下去。他正要再说什么，一个声音从人群外传过来：“爸。”

宋莉。她今天穿了一件藏青色的薄呢外套，头发盘得整整齐齐，手里拎着一只黑色皮包。她穿过人群走到宋国栋身边，低头看了一眼那碗抄手，又看向苏荷，笑了笑：“苏老板手艺果然好。我爸挑了一辈子嘴，今天总算碰到对胃口的了。”

苏荷点了点头：“宋秘书早。”

宋莉的目光在她脸上停了一瞬，那一瞬间，苏荷注意到，宋莉的眼睛底色里有一点极淡的湿润，像是什么东西被压了很久，终于漏出一丝光来。但很快，那点湿润就被笑意收了回去。

“苏老板今天这道菜，我能不能打包一份回后台？”宋莉说，“我们办公室有一位同事，说是青江本地人，想尝尝家乡味。”

苏荷心里一动——宋莉是四川口音，她说的“同事”，是谁？

她面上不露：“行，我这儿还有一碗多的，我给您装上。”

她弯腰去拿干净碗的时候，余光瞥见宋莉的皮包拉链上挂着一个东西——半枚铜钥匙，旧得很，边角磨得发亮，有点像民国老宅门锁的那种款式。苏荷的手顿了一下，又若无其事把碗拿了出来。

盛好抄手，她递给宋莉。宋莉接过去，指尖碰了一下碗沿：“谢谢苏老板。”

她转身走了几步，又回头，像是想起什么：“对了，苏老板，那位同事说，这抄手里的陈皮味儿，让他想起老家绵阳那边一位故人。”

苏荷端着碗的手没动，声音却稳得很好：“那倒巧了。”

宋莉笑了一下，拎着打包盒走远了。苏荷低头看了看灶台上那块切剩的陈皮，忽然觉得，这展销会，怕不是只剩做菜这么简单了。

她抬头看向宋国栋的位置——他已经不在评委席上了。而张北亭不知什么时候站在了展厅的门口，正隔着人群看她，手里夹着一根烟，烟灰燃了长长一截，没有弹。

他看她的眼神，像在看一个他等了很久的人。

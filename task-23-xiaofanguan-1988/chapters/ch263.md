# 第263章 铜钱水汽

“咚、咚、咚。”

三下敲击声从墙内传来，沉闷而规律，像是有人在墙的另一面用指节叩击砖缝。苏荷后背紧贴着那面墙，整个人僵了一瞬，随即强迫自己冷静下来。她经历过米其林后厨最混乱的晚市高峰，也经历过前世创业时被人堵在店门口砸玻璃的夜晚——恐惧解决不了任何问题。

黑暗中，顾长山的手已经摸上了她的小臂，力道沉稳，带着某种安抚性的笃定。他没说话，只是手掌在她臂弯上轻轻按了一下，示意她别动。

墙内的敲击声停住了。

苏荷屏住呼吸，抬指在墙上反叩了两下。顾长山大概是没想到她会有这个动作，手臂的肌肉微微绷紧，却没有出声阻止。

墙内沉默了片刻，然后，缓缓地，传回了一声。

“笃——”

只一声。

随即再无声响，仿佛对面的人或东西已经离开。

“它在回应我。”苏荷压低声音，克制着心底的惊疑，“这不是机关，是活物，或者说——有人在墙里？”

顾长山没有立刻回答。黑暗中，他的呼吸平稳，好一会儿才开口：“不是人。”他顿了顿，“敲击声里有木头底音，像隔着夹层。这宅子，有问题。”

苏荷眉头拧得更紧。“你听见了？”她想起刚才进门时，自己明明点着烛，却走不到尽头，门缝里的月光还往后退，这宅子的空间规律早就被打破了。她知道这趟比探险更危险，但顾长山既然跟她走到这一步，她也只能说：“有什么办法把门弄开？”

“门闩是从外面合上的。”顾长山的声音贴着耳边传来，带着一点热气，“但你刚才没注意到——那根门闩的木头，是新换的。”

苏荷怔了怔。她说：“我刚才推门的时候，门是往里开的，那门闩应该在门内侧才对——”

“所以你回头看看你手上那枚铜钱。”

铜钱。

苏荷这才想起自己手里还攥着那枚潮湿的“乾隆通宝”。她低头——尽管一片漆黑，只能凭触觉——那铜钱的边缘冰凉，表面覆着一层滑腻的水膜。她鼻尖凑近，嗅到一股淡淡的江腥气，像青江出水口那一段特有的淤泥味，又夹杂着一点铁锈的气息。

“这不是井水。”她低声说，“是江水。青江的水。”

顾长山语气沉下来：“刚才钥匙齿缝里的沙也是江水细沙，不是井沙。这两样东西都是从青江里出来的，但金钩巷离江边至少四里地。”

苏荷捏着铜钱的指腹开始发凉。她的手心冒汗，铜钱表面的水膜反而更滑了。她擦了擦手指，忽然摸到铜钱外缘的齿纹不对——普通铜钱的边缘是光滑的，可这一枚，外缘有一圈不规则的刻痕。

“长山，这铜钱有字——”她手指沿着外缘划了一圈，“是外圆刻的，不是中央方孔上的铭文。你身上有火吗？”

“有。”顾长山应了一声，一阵悉索声里，火柴划过磷面，“滋——”地亮起一簇火苗。

光芒亮起的瞬间，苏荷低头看向手中的铜钱，火光照得她瞳孔微缩——

铜钱外缘一圈，刻着一行蚂蚁般细小的字，密密麻麻环绕成环，字迹工整却瘦硬，像用针尖一刀一笔凿出来的：

**“正月廿三，子时三刻，青江渡口，船老大姓江。”**

苏荷心口猛地一提。她把铜钱举到火光下反复确认，那行字的确是“正月廿三”——这岂非正是今天？

顾长山的目光落在铜钱上，眉头紧锁。“今天是几号？”

“正月廿三。”苏荷答。

墙内，又忽然传来“笃”的一声。

这一次，声音更近了，几乎就在她贴着的墙砖后面。

火苗一抖——顾长山的手很稳，火柴的火焰却无风自动，忽明忽暗地摇。苏荷后颈的汗毛一根根竖起来。

她看着那面墙，墙面上石灰剥落，底下露出的老青砖表面，不知何时浮出几条细细的裂纹——不对，那裂纹的走向，弯曲成一个模糊的字形。她凑近去看，火光照映下，那个字形是：

**“檐。”**

又是“檐”字。

苏荷猛地想起自己兜里还揣着那张湿纸片——从门槛下抠出来的那张。她伸手掏出来，纸片已经半干，上面的“檐”字墨迹洇开了一半，但与墙上的裂纹字形竟一模一样。

顾长山也看见了。“同一个字。”他说。

苏荷心里涌起一股异样的寒意，不是恐惧，而是一种被某种未知力量牵引着的预感。她低声喃喃：“檐——屋檐——金钩巷七号，是不是有片檐？老宅子的什么地方，藏着跟‘檐’有关的东西？”

墙内，传来第三声敲击。

“笃——笃。”

两声。

苏荷猛地抬头，与顾长山对视。

她忽然说：“它在告诉我们方向。”她的声音自己都没察觉地发颤，“三声——进了门，一声——回应我，两声——在指路。那个‘檐’，就是方向。”

顾长山沉默两秒，吹熄了火柴。黑暗重新合拢时，他握住她的手，沉声说：“走，找檐。”

苏荷攥紧那枚湿铜钱，指腹上的刻痕锋利得像要嵌进掌心。

窗外月光从门缝里又漏进来一线——那门不知何时，竟被人无声地推开了一条缝。

门外，站着一个黑漆漆的人影。

# 第403章 河岸草帽

芦苇丛外，风从河面刮过来，带着水腥气和初秋的凉意。

苏荷站在砖房前，目光越过马老三的肩头，落在那顶被风吹得微微翻动的草帽上。帽檐上缝着一片干枯荷叶，针脚粗糙，像是临时缝上去的，但荷叶干而不碎，显然是经过处理——有人刻意做了标记。

“马叔，那顶草帽，你认识吗？”苏荷收回目光，看着马老三。

马老三顺着她的视线望去，眯起眼。他四十多岁，脸膛被太阳晒得黑红，眼角的纹路像刀刻一般。他盯了那草帽足有七八秒，没说话，大步走过去，蹲下身，把草帽从柳树根下捡起来，翻来覆去看了两遍。

“不认识。”他把草帽翻过来，帽顶内侧有一层薄薄的汗渍，“但这是新帽，戴了不超过三天。荷叶是后缝上去的，干荷叶，秋天才有——这是故意的，让认识的人认出他。”

顾长山走过来，接过草帽细看，又放在鼻子下闻了闻：“有烟丝味，是旱烟——叶子烟，不是卷烟。抽这种烟的，要么是老农民，要么是码头扛包的，要么是走江湖的。”

苏荷心里一沉。半月前食品厂门口那顶一模一样的草帽，帽檐上也缝着干荷叶。那个站在马路对面望着她的人，身形不高不矮、不胖不瘦，她没看清脸，却记得那人走路时左脚微微垫着走，像是受过伤。而刚刚在渡船上，老艄公收竹篙时，左脚也一样垫了一下。

“船上的老先生……”苏荷转头看向白水河的方向，渡船已经在河对岸，那个佝偻的身影正在岸边系缆绳，“他左脚是不是有伤？”

马老三一愣：“老九？他左脚年轻时候被船板砸断过，一直没好利索。你……你怀疑他就是草帽人？”

“不是怀疑。”苏荷声音低下来，“半月前在青江食品厂对面，他就是戴着这样一顶草帽、穿着灰布衣裳站着看我。我追过去时，他钻进巷子，跑得不快，左脚一垫一垫的。今天在船上，他始终背对着我们，说话时头也不转过来，可我总觉得声音有点熟。”

马老三沉默了一会儿，脸色变得复杂。他蹲下身，把那顶草帽放在地上，手指点了点帽檐上的荷叶：“老九不是坏人。他跟着师父跑了二十多年的白水河船路，师父的信交给他，他也确实交到了你手里——要是他想害你，这封信根本到不了你手上。”

“我知道。”苏荷的目光落在草帽上，“但他为什么要在食品厂门口盯着我？为什么这顶帽子会出现在这里，正好是我们离开砖房、要渡河的地点？他在提醒我什么，还是在监视我？”

河风忽然大起来，吹得芦苇沙沙响。马老三站起身，把草帽扣在柳树杈上：“他不在这儿了。刚才对岸那船，人已经走了。他要真想见你，不会不留一句话。我认识他二十八年，他就这个脾气——事情没办完，他不会露面。”

“那他的事，就是监视我？”

马老三没接话，指了指砖房里那本画册：“师父留给你的东西，比一顶草帽金贵。你想弄明白乔春风是谁、帮主手书为什么砌进郭家祠堂，先把那七幅画看懂。”

苏荷和顾长山回到砖房，点上油灯，把七页画册铺开在桌面上。画册已经泛黄，纸张边缘毛口，明显翻过许多次。七幅画，毛笔所画，线条粗粝却传神——

第一幅画：一只铁锅，锅底破了个洞，洞里有水，水里有鱼。
第二幅画：一座桥，桥栏断了，桥下翻船，岸上两人斗殴。
第三幅画：一棵大树，树根隆起，根下埋着一把刀。
第四幅画：一排缸，缸口封着黄泥，其中一口缸裂纹。
第五幅画：一道门，门楣上有三个字——看不清是几个字，被画者刻意涂掉了。
第六幅画：一口井，井边蹲着一个人，手里拿着一枚铜钱。
第七幅画：一条船，船上坐着两个人，一个在划桨，一个在低头看一本册子。

七幅画，没有字，没有落款，只有第一页背面用铅笔画了一个小小的箭头，从第一幅指向第二幅，再从第二幅指向第三幅，一路连到第七幅——像是一条路线。

“锅里有鱼……”苏荷的手指停在第一幅画上，忽然想起什么，从怀里摸出那枚光绪通宝铜钱。她翻过铜钱，边缘有一处缺口，位置像是被磨出来的，正好卡在拇指指甲盖里。她像是无意识地用拇指把铜钱按在画上那只锅的破洞位置——铜钱大小，刚好盖住破洞。缺口朝上，指向画中鱼头。她猛地睁大眼睛：“这不是画，是一张地图——锅底那个洞，就是缺口，这条鱼……是白水河的方向？”

马老三接过画册看了一眼，又看了看铜钱，嘴唇微动，没说话，但眼里那点光，说明他显然是认得这些东西的。

顾长山一直没说话，他盯着第四幅画——那口封着黄泥的缸，忽然开口：“这口缸上的裂纹，很像郭家祠堂老灶台的形状。祠堂的灶，就在我老家西关镇。”

苏荷心里猛地一紧。师父的那封信，说帮主手书就砌在郭家祠堂老灶台铁锅正下方砖缝里。而画册第四幅，就是一口缸、黄泥、裂纹。第七幅画的船上，那个人低头看册子——那个人的身影，竟与马老三有几分神似。

“马叔，”苏荷抬起头，“这七幅画，是你画的吗？”

马老三沉默了很久，久到灯芯“噼啪”爆了一声，他才开口：“画是师父画的，但第七幅那个人，是我。那年我二十岁，师父让抄一本册子……后来那本册子，就是柳家在找的东西。”

他顿了顿：“师父让我抄了一本盐船船簿。那本船簿，后来给了一个人。一个苏荷你绝不会想到的人。”

他话音刚落，窗外忽然传来一声沉闷的“咚——”，像是什么重物砸进水里。马老三脸色骤变，一把吹灭油灯。屋里陷入黑暗，三人的呼吸声在砖墙间回荡。

顾长山已经摸到腰间那把短刀。马老三压低声音：“有人在河里砸石头渡河。不是老九——他从来不用石头。”

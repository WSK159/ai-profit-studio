# 第41章 螳螂捕蝉

灰褂子来苏记第三天，苏荷便看出门道来了。

这人自称姓何，叫何大勇，老家在江北县，说是听说了苏记招帮工的消息赶来试试。面试时手脚笨拙，连切个葱花都歪歪扭扭，可苏荷偏生在他弯腰擦灶台时瞥见了他袖口里露出一截卷边的纸头——那是记账用的复写纸，饭店后厨才有的东西。

有意思。苏荷不动声色，安排他专管择菜、烧火、刷碗这些杂活，不让他碰灶台。灰褂子倒也沉得住气，埋头干了两天，一句多余的话没有，只是那双眼睛总在灶台上打转，尤其盯着苏荷调红油的那口小铁锅。

第三日下午，苏荷故意让灰褂子去库房搬一袋面粉，自己则带着苏桃在前厅算账。约莫一炷香的功夫，灰褂子搬着面袋回来，额角沁汗，赔着笑说：“苏老板，库房那口青瓷瓶看着精贵，要不要挪个地方？我怕碰碎了。”

苏荷心里咯噔一下——那瓶种子酱连顾长山都没见过，灰褂子才来三天，居然连库房角落的瓶瓶罐罐都摸清了。

她面上不显，只淡淡道：“那瓶不值钱，是腌咸菜用的老酱，别动它。”

灰褂子应了声，转身去后院劈柴。苏荷放下账本，跟苏桃交换了个眼神。苏桃会意，拎着铜壶去后院添水，假装路过库房门口，瞧见灰褂子蹲在地上，手指头在泥地里画着什么。

当夜，苏荷关了店门，把廖师傅和顾长山叫到里间。廖师傅是从老国营饭店退下来的掌勺，上个月被苏荷用一月八十块的工钱挖来镇场子，如今是苏记后厨的定海神针。

“何大勇是冲着配方来的。”苏荷直截了当，“他今天在库房，看见了我那瓶种子酱。”

顾长山皱眉：“你怎么知道？”

“他太急。”苏荷冷笑，“一个来应聘的帮工，不会注意到库房角落的瓷瓶——除非有人告诉他，苏记最值钱的东西藏在那儿。”

廖师傅闷声道：“那还留他？明儿就打发了。”

“不，留着。”苏荷端起搪瓷缸喝了口水，“我正愁抓不住赵前进的马脚。他既然派人来偷，咱们就让他偷。”

顾长山眼神微动：“你打算放长线？”

“他偷到‘配方’回去，赵前进必定信以为真。”苏荷嘴角勾起，“我今晚就写一真一假两份方子——真的里头少一味料，假的外面看着一模一样。灰褂子要偷，就让他偷那份假的。”

苏桃眨巴着眼睛：“姐，那真的呢？”

“真的方子只在你我脑子里。”苏荷拍了拍妹妹的脑袋，“廖师傅负责在灰褂子面前演一出戏——明儿下午你假装去库房取东西，顺手把‘方子’锁进樟木箱里，钥匙故意揣在围裙兜里，让他看见。”

廖师傅咧开缺了门牙的嘴：“苏老板这是钓鱼呢。”

“钓的就是这条灰皮泥鳅。”苏荷目光一凛，“长山哥，你帮我盯一件事——何大勇要是把东西送出去，送到谁手上，你务必跟上。”

顾长山沉默片刻，点头：“我让局里一个兄弟帮忙盯着，他退伍前是侦察连的。”

苏荷微微颔首，心里盘算着下一步棋。窗外夜色漆黑，巷口的路灯昏黄地亮着，把斑驳的树影投在窗户纸上，像一只无声窥探的手。

散会时，灰褂子刚劈完柴往回走，迎面碰上苏荷，忙垂头问好。

苏荷站住脚，上下打量了他一眼：“何师傅今儿辛苦了，明儿给你加两个菜。”

灰褂子连声道谢，眉毛却不易察觉地跳了一下。苏荷看在眼里，转身进屋，将门掩上时，余光扫见他正偷偷摸向廖师傅挂在后院晾绳上的围裙——那围裙口袋里，正揣着她两炷香前放进去的一把黄铜钥匙。

# 第156章 徐国栋的账本

腊月十七清晨，省城的雾气还没散尽，苏荷已经站在青江市外贸公司驻省城办事处门口。这是一栋四层灰砖楼，门口挂着白底黑字的木牌，比巷口那些挂着塑料招牌的铺子气派得多。她穿着一件洗得发白的蓝布棉袄，脚上是那双走了半个城也不磨脚的解放鞋，怀里揣着那张泛黄的推荐信，信纸边缘已经卷了毛，墨迹却还清晰——“兹推荐苏荷同志赴省城洽谈餐饮食材供应事宜，请徐国栋副经理接洽。”落款是青江市工商局老局长的手笔，日期是三个月前，那时候她还没把苏记招牌挂起来。

值班室的窗子推开一条缝，一个五十来岁的中年人探出头来，戴一副黑框眼镜，镜片后头一双眼睛精明地打量她：“你是苏荷？”

“是，徐经理，我带了推荐信。”她把信递过去。

徐国栋接过信，没急着拆，先把她上上下下看了一遍，看到棉袄领口露出的那截围裙带子时，眉头轻轻动了一下。他把信折好，夹进手里的文件夹里，侧身让开门：“进来说。”

办公室里烧着煤炉，暖气很足，桌上摊着一堆报表，红蓝铅笔划过的痕迹密密麻麻。徐国栋给她倒了杯热茶，自己坐到桌后，手指敲着桌面，说：“老局长的面子我不能不给，但你得先跟我说实话，你来找我，是想买平价粮油，还是想打听宏泰的事？”

苏荷端起茶杯，热气扑在脸上，她笑了一下：“徐经理快人快语，我也不绕弯子。我盘了一个小馆子，生意不错，想在省城进点稳定的货源。但我在粮油批发市场遇到一位何总，他说青江的秦掌柜也走他那儿拿货，我就觉得蹊跷——秦掌柜那铺子我去过，规模撑死一天两袋面粉，可听何总那意思，他拿的量怕是不止翻倍。”

徐国栋的笔尖顿住了。他抬起眼看苏荷，目光里那层精明劲儿褪去，多了一丝警惕：“你查秦掌柜？”

“不查，就是做生意的本能，账对不上。”她把茶杯放下，语气不紧不慢，像是在聊天气，“徐经理在外贸系统干了小二十年，您比我清楚，对不上的账，多半有猫腻。我一个小饭馆老板娘，不想管谁的事，但我进货的渠道得干净，不能让来路不明的面粉进我的锅。”

屋子里静了片刻，煤炉里“啪”地炸了一声火花。徐国栋站起身，走到门边，把门反锁了，然后回到桌前，从抽屉里拿出一本灰皮封面的账本，翻开，推到苏荷面前。

“你看这一页上个月的进货记录，省城粮油批发市场的青穗牌面粉，一共进了十二吨，批发市场账面只记了四吨，剩下八吨走的是外贸公司转运仓的单子，品名写的是‘杂粮’。但转运仓那边的人跟我说，那批货袋子上印的，全是青穗商标。”

苏荷低头看那账本，纸面发黄，字迹工整，八吨两个字用红铅笔圈了三圈。她心里一沉，面上不动声色：“所以不仅仅是走私，还拿外贸的额度做掩护？”

“你说对了。”徐国栋合上账本，声音压低，“这半年，省城和青江之间有好几条这样的路子，何承业只是台前的人，真正拿主意的，怕是坐得比你我高得多。我早就想查，但我一个副经理，手里的调令都过不了第三道门。”

他看着苏荷，忽然笑了一下：“你今天来找我，倒让我想起二十年前我在农场那时候，也是有个小姑娘跑到我面前说‘账对不上’，结果她抓住了一条蛀穿粮仓的大虫。苏荷，你要是有心，腊月十八西门货栈有一批‘杂粮’到货，你带着你的人，去看看。”

钩子一旦抛出，苏荷心里已经转了七八十个念头，嘴上却只是站起身，冲徐国栋伸出手：“徐经理，您这份信任，我记下了。等我回去，请您到我馆子里吃碗红油抄手。”

徐国栋握了握她的手，用力一压：“去吧，小心点。省城的水，比青江深。”

苏荷走出办事处，雾气已经散了，太阳矮矮地挂在楼顶上，把她影子拉得老长。她站在路口，回头看了一眼那栋灰砖楼，忽然听见身后有人叫：“苏老板。”

她一转身，李二柱从街对面跑过来，手里攥着一张纸条，气喘吁吁：“老爷子让人给我捎话，说老戏台那件事，今晚子时，务必请苏老板亲自去一趟。”

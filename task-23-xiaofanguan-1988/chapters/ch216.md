# 第216章 账本与油证

青江市入秋后的第一个雨夜，城南巷的青石板路面被水汽浸得发亮。苏荷攥着油纸包好的档案拓本，脚步踩在积水里发出闷响，身后跟着撑伞都打不利索的刘三发。

“苏老板，你走慢点……”刘三发矮胖的身子在雨里缩成一团，“这要是让我媳妇知道我跟您来办这事，非把我耳朵揪下来不可。”

苏荷头也没回：“你媳妇要是知道你把我配方卖给了梁国庆，她更得让你跪搓衣板。”

刘三发噎住了。

苏桃撑着伞从巷口迎上来，压低声音说：“姐，都安排好了，王会计在屋里等着呢。他那人心细，账面上的门道他一眼就能看出个七八分。”

这是一间临街的老筒子楼，三层，一楼是街道办的旧会议室。王宝德是青江油脂厂退了休的老会计，六十出头，头发花白，戴着一副镜架绑着胶布的老花镜。苏荷是通过顾长山牵的线找到的他——城里但凡跟“油”沾过边的账，没几个人能比他更精。

屋里灯光昏黄，王宝德把拓本摊在桌面上，眯着眼看了约莫十来分钟，又拿起放大镜照了照纸上那些模糊的骑缝章。他把油纸放下，摘下眼镜擦了半天，才开口说：“姑娘，你这份东西要是真，那梁国庆手上的租约合同，从签字那天起就是废纸。”

苏荷心中一定，面上不露：“王叔，您能确定？”

“确定。”王宝德指着纸上的几处关键位置，“1979年青江油脂厂改制前，附属集体商店的地都是厂里划拨的，市里备案过。划拨地不得转租买卖——这条规矩哪怕放到现在也硬得跟铁一样。梁国庆那份合同上印章是‘城南街道房产管理所’，可1985年后这个所就合并了，他盖的是个已经作废的公章。”

刘三发的脸色在灯下白了白，手里攥着的烟卷烧到了头也没察觉。

苏桃适时递上刘三发那本缺了后半本的账册：“王叔，您再看看这个。”

王宝德翻了几页，皱起眉：“这账记的……泔水油进出对不上，出库数字比入库多出几倍。做账的人故意留了漏洞，后半本被人撕了。”他顿了顿，指着几个条目下的备注符号，“不过不要紧——前面这几页上记的日期、数量、收货方单位，青江机械厂和建设路工地的食堂，都在了。这俩单位食堂的后勤采购，我认识人。”

苏荷的呼吸微不可察地顿了一瞬。

“王叔，您能帮我问问吗？不用出面，就问他们每个月收来的‘食用油’是走公账还是私账，发票是谁开的就行。”

王宝德看了她一眼，老花镜下的目光又精又亮：“姑娘，你这是要往死里打啊。”

苏荷笑了：“我不打他，是他先泼我的泔水。”

刘三发在角落里终于开了口，嗓子干哑：“苏老板……要是梁国庆知道是我交的账本，我在这片就活不下去了。”

苏荷转头看他，目光沉静而温和：“你不说，我不说，账本自己会说话。梁国庆要查的是谁卖了他，可账本这种东西，从来都是从他自己人手里漏的。”

刘三发愣了一下，半晌，咬咬牙：“成。您让我做什么，我做什么。”

雨声渐密，苏桃把王宝德送出门时，苏荷独自坐在灯下，将那半张批文拓本重新折好，贴着心口放进了内衣口袋。隔着窗，巷口那棵老槐树在雨里摇晃，枝桠间挂着一件被风刮上去的旧围裙，在她眼底晃动了一下。

那是她刚来城南巷时挂上去的，日子还不到一年。

她正想得出神，门猛地被推开。苏桃浑身湿透地冲进来，脸上分不清是雨水还是泪：“姐！快点回去！咱们铺子门口被人泼了红漆，门板上用黄漆写了三个大字——”

苏荷腾地站起来。

苏桃的声音发颤：“——‘奸商’。”

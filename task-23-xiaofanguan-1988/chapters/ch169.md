# 第169章 抢注

苏荷捏着那张法院传票，指节泛白。“苏记老味”——她从来没听过这个名字。省城来的，餐饮公司？她的铺子在青江才开了一个多月，连省城的人来吃过饭都屈指可数，怎么会有人跨地来告她侵权？

“商标侵权的官司，被告的是谁？”顾长山的声音从门口传进来。他穿着一身深蓝色中山装，棉帽子夹在腋下，显然是刚从街道办赶过来的，额头上还带着细密的汗珠。显然有人通了风报了信。

苏荷把传票递给他：“被告是我。原告是省城一家叫‘苏记老味’的公司，告我冒用‘苏记’字号营业。”

顾长山扫了几行，眉头拧成一个结：“‘苏记’两个字，你在城南巷用了多久了？”

“从开张那天算，一个月零十二天。”

“那他们什么时候注册的？”顾长山追问。

苏荷看了一眼传票上的附注：“受理时间，上个月十五号。也就是说，这家‘苏记老味’在青江注册‘苏记’商标的时间，只比你的铺子开张晚了三天。”

铺子里的空气一下子凝重起来。唐老头靠在门框上，嘴里叼着根牙签，听了一会儿，慢悠悠地插了句嘴：“晚了三天，却能反过来告先用的那家。这背后要是没人指点，鬼都不信。”

苏荷咬着下唇，脑子里飞快地转。三天……她开张的时候，根本不认识省城任何人。除非，有人在她开张之后，立刻快马加鞭赶去省城，抢先注册了这个商标。可谁会有这个动机，又有这个渠道？

“走，先进屋说。”顾长山把传票折好，递还给苏荷，又朝还在门口围观的街坊邻居挥挥手，“都散了吧，没什么好看的。苏老板这边有正经官司要商量。”

人群虽然散了，但议论声没断。苏荷能听见他们压着嗓子在传：“省城的大公司要告苏老板喽……怕是这铺子保不住了。”她没去解释，只把门合了大半，请唐老头和顾长山在后院的小桌旁坐下。

顾长山开门见山：“我在街道办接触过几个注册商标的案子。你这种情况，如果对方注册在先，而你有证据证明你是先使用的那一方，可以申请撤销对方的注册商标，提出‘先用权’抗辩。但前提是，你得拿出确凿的使用证据——开张的营业执照、发票、菜单、广告牌照片，证明苏记这个字号在你使用的日期之前就已经公开对外营业。”

苏荷的脑子飞速运转：“营业执照是开张前办下来的，日期能对上。固定菜单上印着‘苏记小馆’的字样，而且还有几家老客留着之前的发票存根。”她顿了顿，“但问题是，对方是省城的公司，他们为什么专门挑青江这个小地方来抢注商标？如果只是同名，打个招呼就过去了。可他们直接走法院，这个态度……背后一定有人指使。”

“李兆阳。”顾长山和唐老头异口同声。

苏荷一愣。顾长山压低声音：“我今早刚从你们街道派出所那边得到信儿，李兆阳近半个月来了青江三趟，每次都在西门货栈待不到一炷香工夫就出来，但从来没有人见他带着货走。他跟何承业私下里在搞什么事，还没查透。但昨天有人看见他去了省城方向。”

苏荷的后背一阵发凉。李兆阳跟她有仇。上辈子，他贪了她的配方，毁了她开的第一家店，害得她背了一屁股债还险些坐牢。这辈子重生之后，苏荷已经刻意避开他，没想到他还是阴魂不散地找上来了。

“他这会儿沾上何承业走私橡胶管的买卖，手上不缺钱。”苏荷冷静下来，把前因后果在脑子里过了一遍，“他要搞我的手段，一是有钱找律师，二是有渠道在省城注册公司。这案子如果判了，我不光得赔钱，名声也砸了——个体户被大公司告倒，以后谁还敢来吃饭？”

唐老头哼了一声：“法律你跟他们打。但别光顾着应对官司，忘了铺子里的生意。你若怕被人搅了名声，那才是正中人家下怀。”

正说着，苏桃推门进来，眼睛有些红。她在顾长山妹妹家躲了几天，听到消息实在坐不住。她手里攥着一个小本子，摊在苏荷面前：“姐，账我都理好了。咱们开业这一个月零三天，每天的流水、进货单、客人的签字本，每一顿卖了多少碗抄手、多少份小菜，我都记着呢。这个能不能当证据？”

苏荷低头一看，纸页密密麻麻的娟秀小字，连哪天柴火贵了几分都写上了。她鼻子一酸，伸手揉了揉苏桃的脑袋：“能。这东西可比什么都有用。”

她抬起头，目光扫过顾长山、唐老头，最后落在院里那口铁锅上。那口黑褐色的旧铁锅从她出村就跟着她，跟到了城南巷。她突然开口：“长山，你的转业费——你之前说我若要用，随时可以，这话还作数吗？”

顾长山抬眸看过来，眼神安静而笃定：“作数。”

“那就麻烦你陪我去一趟省城。”苏荷站起身，把那本《雪羹诀》小心收进怀里，“告我不怕。我先不急着应诉——我要先搞清楚，那个‘苏记老味’背后，到底站的是谁。”

# 第473章 枯水渡的灯

苏荷赶到北门时，天边刚露出一线灰白。

守门的老头蹲在门洞边抽旱烟，见她一身利落的旧棉袄、肩膀上挎着包袱，眯着眼问：“这么早出城？”

“走亲戚。”苏荷递过去一卷粮票。

老头接过来掂了掂，没多问，拉开侧门的门闩放她出去。苏荷走出城门才回头看了一眼——省城的轮廓笼在晨雾里，街巷模糊得像一张旧照片。她想起自己从青江进城那天，也是这样一个灰蒙蒙的早晨。

她收回视线，沿着冯半缸画的地图朝西北方向走。清晨的土路冻得硬邦邦，两旁的稻田枯着茬，远处偶尔传来一两声犬吠。

走了约莫一个时辰，路边的村庄渐渐稀了，地势开始起伏。钱塘江的支流从山坳里拐出来，水面窄而急，岸边长着一片枯黄的芦苇。苏荷在渡口处停下来。

渡口很小，只有一块歪斜的青石板伸进水里，旁边拴着一艘旧木船。船身半沉，显然是废弃已久的。渡口后方有一棵老槐树，树下立着一盏铁皮灯——灯罩锈得发黑，里头却插着一根没点过的蜡烛。

苏荷走到灯前，伸手碰了碰那根蜡烛。

烛芯是白的，蜡身干净，没有一丝被风沙蚀过的痕迹。有人最近换过。

她心里一动，蹲下身细看灯座，果然在铁皮灯底下的泥地上发现了一行新踩出来的脚印，鞋底有防滑纹——是军靴的鞋印。

顾长山。

苏荷顺着脚印往上游走，走了约莫百步，在河岸拐弯处的乱石堆后面找到了一只背囊。背囊的布料是深绿色的军用帆布，里头裹着一卷绷带、半块干饼、一只铁皮水壶。水壶里的水还是温的。

他离开不会超过两个时辰。

苏荷放下水壶，环顾四周。乱石堆后方有一道陡坡，坡上长满枯藤，藤下隐约露出半扇木门——被干草和土块掩住，不仔细看根本发现不了。她拨开枯藤，木门虚掩着，推开后是一条向下延伸的石阶。

石阶窄而陡，两侧墙壁湿漉漉地渗着水，弥漫着一股潮湿的泥土味。苏荷摸出火柴，点了一支，举着手臂往里走。

台阶走了大概三十级，前方豁然开朗——是一间不大的石室，四面墙壁用青石砌成，地面的石板缝里渗着水。石室正中央摆着一张石桌，桌上放着一本翻开的旧册子。

苏荷走近了两步，火光照亮册页上的字迹。

“苏记渡，庚午年秋，洪水灌入，老灶沉江。灶底青砖刻祖训，舟覆之际，苏茂丰背不出全文，只默念一句：根在人心，桥在渡口。顾家世代相传此语，至今三代。”

她往下看，下面还有几行新的笔迹，墨水还没干透：

“砖面其余字迹浸水已蚀，仅存八字可辨：‘根在人心，桥在渡口’。刻砖之人非苏茂丰本人，笔法似其妾侍柳氏。柳氏何人所刻，待考。”

墨迹落款处画了一个小小的梅花印——是顾长山的记号。

苏荷的目光停在那行字上，久久没有移开。

柳氏。柳春来……柳家的祠堂里，也有一方“地”字石碑。师父的那封信里，提到过柳春江。苏记、柳家、顾家——几十年前的庚午年秋天，在这条河边，到底发生过什么？

她将册子轻轻合上，重新放回石桌。就在这时，她听见头顶传来一声极轻的“嗒”——像是有人踩在了木门槛上。

苏荷吹灭火柴，闪身贴到石壁边。

片刻之后，头顶的木门被推开，一束天光斜斜地落进石阶口。一个人影站在门口，逆光看不清面目，但身形矮瘦，肩头微驼，穿着一件灰扑扑的中山装。

那人没往下走，只站在原地，开口说了一句让苏荷眼皮一跳的话：

“你不用躲。我知道你是苏承宗的徒弟。”

声音苍老，带着几分烟嗓的沙哑。

“拿着那本册子，上来吧。”老人道，“我有话要告诉你——关于你师父为什么离开苏记，关于庚午年沉船那天，苏茂丰到底在那块青砖刻了什么。”

苏荷攥了攥拳头，没有立刻动。

“还有，”老人补了一句，“关于那块砖上顾长山没认出来的那个字。”

“什么字？”苏荷终于出声。

老人停了一下，声音低了下去：

“门。”

她握着火柴的手一紧。

青砖上刻的，不是“根在人心，桥在渡口”八个字——那个“根”字是错认的。苏茂丰刻的第九个字，被水蚀掉了大半个偏旁，顾长山看走了眼。那块砖上真正写的是：

“门在人心。”

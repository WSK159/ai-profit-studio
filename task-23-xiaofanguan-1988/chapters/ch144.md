# 第144章 父女对峙

苏荷放下手里的账本，抬眼看向门口。苏桃站在门槛上，脸色发白，嘴唇哆嗦着说：“姐，爹……爹他真的来了，就在巷口，说要找你说清楚。”

“说清楚什么？”苏荷把账本合上，语气平静得让苏桃打了个寒颤，“说清楚他要把我卖三百块彩礼，还是说清楚他要把你学费抢走给弟弟盖房？”

苏桃攥着衣角说不出话。外头传来一阵嘈杂，男人的粗嗓门从巷口一路碾过来：“苏荷！苏荷你给我出来！我养你十八年，你倒好，翅膀硬了连爹都不认了！”

苏荷站起身，从灶台上拿起那把磨得发亮的菜刀，在围裙上擦了擦，随手别在腰间。苏桃吓得往后缩：“姐，你别……”

“放心，我不砍人。”苏荷掀开门帘走出去，“我让他看看，他闺女现在过的是什么日子。”

城南巷午后的阳光毒辣，巷口围了一圈看热闹的街坊。苏父穿着一件发黄的的确良衬衫，脚上踩着一双露出脚趾的解放鞋，脸晒得黑红，正叉腰站在苏记小馆的门牌底下——那块苏荷亲手写的招牌，被他手指头戳得直晃荡。

“哟，爹来了。”苏荷双手抱胸靠在门框上，语气带着笑，眼神却冷得像井水，“来蹭饭？今天红油抄手卖完了，剩点面汤，要不要给您盛一碗？”

苏父被她这不咸不淡的腔调噎了一下，随即扯着嗓子喊起来：“大伙儿都瞧瞧！这就是我养的好闺女！从小吃我的喝我的，长大了一分钱不往家拿，还把自己亲妹妹拐跑了！现在开这么大个馆子，连亲爹进门都不让坐！”

围观的人群里有人窃窃私语。一个胖婶子小声说：“这闺女刚来的时候可不是这样，摆摊那会儿多苦啊……”旁边人拽她袖子：“你少说两句，人家家务事。”

苏荷不恼，反倒笑了。她走到苏父面前，近得能闻见他身上那股劣质旱烟混着汗酸的味道。她压低声音，只有两个人听得见：“爹，你今天是来吵架的，还是来要钱的？”

苏父眼珠转了转，梗着脖子：“我听不懂你说什么！你是我闺女，我来看你不行？你开的这馆子，也有我一份！”

苏荷点点头，忽然提高声音：“行！正好街坊都在，产权处的同志也在里屋喝茶。咱们把话说清楚——当初你把我卖到邻村张家，收了人家三百块彩礼，那是我一辈子卖身的钱。我掀桌走了，这钱你们还了吗？”

苏父脸色一变：“那钱……那钱给你弟弟攒着娶媳妇用的！你一个闺女家，这本来就是该给家里的！”

“所以啊，”苏荷声音清亮，“我一分嫁妆没拿，一口铁锅出的门。这馆子从头到尾，是我一口一口炒出来的。您要是觉得这店有您的份，行，赶明儿我去趟街道办，把账本摆出来，让顾长山同志给咱们断断。”她顿了顿，扭头朝里屋喊，“顾长山，产权处的人还在不在？”

门帘掀开，顾长山高大的身影迈出来。他没穿制服，一身蓝布褂子，但那股当过兵的气势压得住场子。他手里夹着烟，目光扫过苏父：“叔，产权处老周刚走。您要是有事，改天我陪您去街道办坐坐，咱们按规矩办事。”

苏父没料到顾长山在这，更没料到苏荷真敢把公家扯进来。他嘴唇哆嗦了半天，忽然换了一副哭腔：“小荷啊，爹不是来跟你要钱的……爹是听说你在这边受了委屈，有人欺负你……爹心疼你啊……”

苏荷没接话。她太了解这个人了——要钱的时候撒泼，讨不着的时候卖惨，眼泪是现成的，谎也是现成的。她正要开口，忽然看见苏父腰间的布腰带鼓鼓囊囊，塞着一卷东西。

“爹，你腰里揣的是什么？”

苏父猛地捂住腰间，脸色刷地白了。

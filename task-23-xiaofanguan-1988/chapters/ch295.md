# 第295章 谁在钓鱼

苏荷没有后退。

她盯着那把铁锹上的新土，脑子转得飞快。从灰衣老头说“敲击者正在挖土”到现在，前后不过一炷香的工夫。她赶到时灰夹克男人已经挖完了洞——可这个女人的铁锹上沾着新土，说明她也动了土。要么她挖了别处，要么她赶在苏荷进来之前，把洞里的东西取走了。

苏荷开门见山：“是你把洞清干净的？”

女人挑了挑眉，算是默认。

苏荷又问：“账册你拿了？”

女人把铁锹往地上一杵，闷声响，像敲了记鼓。她歪着头打量苏荷：“小丫头，你胆子不小。大半夜翻进祠堂，撞见一个拿铁锹的陌生人，不跑还敢问话。”

“跑什么。”苏荷把剔骨刀收起来，干脆往前走了两步，在离女人一丈远处站定，“你既然没趁我蹲在墙根时下黑手，就说明你不打算动我。那我不如省点力气，咱们直接把话说开。”

女人的眼珠微微动了一下，她似乎没料到苏荷是这个路数。

沉默半晌，女人开口：“我挖的不是这个洞。”

苏荷心里一动：“那你挖了什么？”

女人侧过身，指了指祠堂东边那棵老槐树底下——那里有一片新翻的土，泥土颜色深浅不一，确实像是刚刨开又填回去的。苏荷顺着她手指的方向看了一眼，问：“槐树底下埋着什么？”

“我不确定。”女人的声音低下去，“有人告诉我，账册可能不在西墙，在树根底下。我挖了三尺，挖到一只陶罐。”

她顿了顿：“陶罐是空的。”

又是空的。苏荷眯起眼，心里迅速地把线索串了一遍：西墙砖洞空，树根陶罐空——账册不在它该在的地方。要么账册已经被最早的那一拨人转移了，要么当初放账册的时候，就做了两个假位置。

“那你蹲在这儿，是在等挖洞的人回来？”苏荷问。

女人看了她一眼：“是，也不是。我在等一个懂得多的人来。”

“谁告诉你槐树底下有东西的？”

女人没回答，反倒问她：“你认得一个叫宋文起的人吧？”

苏荷眼皮一跳。

宋文起——她怎么会不认得？之前那本周明善手记里的关键人物，油布包、蜡封、七条地下通道，桩桩件件都有他的名字。苏荷没有否认，只是盯着女人脸上的疤，问：“你跟他什么关系？”

“他是我哥。”

这句话像一颗石子扔进湖里，荡开一圈圈涟漪。苏荷打量着眼前的女人，忽然想起之前调研时听人提过一嘴——宋家不止一个孩子，老大是个儿子，下面还有个妹妹，从小就跟着哥哥跑腿，后来不知怎么去了乡下，再后来的事没人说得清。

“宋文起人在哪儿？”苏荷问。

女人摇了摇头：“失踪了。三个月前他给我捎了一封信，说如果有一天他不见了，就让我来苏家祠堂挖槐树底下的陶罐。信上说，陶罐里有他留给我的一样东西，还有一条账册的线索。”

“结果陶罐是空的。”

女人点头，目光复杂：“不是三个月前空的——陶罐口上的封土是旧土，没有近期被人翻过的痕迹。也就是说，至少三个月前，罐子就已经是空的了。”

苏荷心里猛地亮了一下：“宋文起在信里告诉你的陶罐位置，写的是哪儿？”

“槐树底，南侧，三尺深。”

苏荷蹲下身，看了看那棵老槐树底下的土坑——回填的新土里露出一小截草根，被切断的根茎茬子还是白的。她用手拨开土，又往下抠了两寸，指尖触到一个硬物。

她心里一凛，把那东西抠出来。

是一枚锈迹斑斑的铜钥匙。

钥匙柄上刻着一个字，被锈蚀得几乎认不出来。苏荷用袖子擦了擦，借着月光，看清了那个字——“周”。

苏荷的瞳孔猛地缩紧。她缓缓抬起头，看着站在月光下的宋家女人：“这陶罐里，到底是谁的东西？”

女人沉默良久，低声道：“我哥在信里说了一句话。他说，‘罐子里无论有什么，千万别让姓苏的知道。’”

风从祠堂的破损窗棂间灌进来，呜呜地响。

苏荷手里攥着那枚钥匙，指节泛白。

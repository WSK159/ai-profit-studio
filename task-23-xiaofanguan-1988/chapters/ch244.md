# 第244章 酒香引客

腊月二十二清早，城南巷的空气里飘着霜味。苏荷把铁锅架在灶上，从地窖里搬出那坛米酒时，坛身还带着地底的凉意，沁得手心发麻。她揭开泥封的动作极轻，仿佛怕惊动什么。

酒香先是一丝，若有若无地钻出来。紧接着，整个灶间像被点燃了一盏无形的灯，那香气竟有了形状，沉沉的、糯糯的，裹着陈年糯米的甜润，又浮着不知名的药草清苦，一层叠着一层地往鼻子里钻。苏荷愣住了——她前世做了二十多年主厨，闻过茅台、五粮液，也品过日本清酒、法国干邑，可这坛米酒的香气，竟让她一时找不到词来形容。

“姐，你倒了好多？”苏桃从账台后探出头，吸了吸鼻子，眼睛倏地瞪圆，“这……这味儿怎么像桂花糕上浇了蜜？”她颠颠跑过来，凑到坛口深深一嗅，整个人像被钉住了，半晌才憋出一句，“我肚子叫了。”

苏荷伸手捞起坛中悬着的棉线，线头拴着一枚小小的油纸包。她摘下来，展开——里面是一撮干枯的茶叶，乌褐卷曲，凑近了能闻到一股陈年的兰花香。她心头一跳，把那撮茶叶与青瓷罐里取出的残茶比对，色、形、香几乎一模一样。果然，这坛米酒与师父的茶罐同出一源。

“姐，这酒……卖不卖？”苏桃咽了咽口水。

苏荷没答话，她低头看向坛底。酒液清亮澄澈，映着晨光，坛底隐约沉着一物——圆圆的、扁扁的，像一枚铜钱，又像一只铜扣。她挽起袖子，探手进去，指尖摸到那物，冰凉、坚硬，边缘有细密的花纹。她将那东西捞出来，在清水里冲净——竟是一枚黄铜锁扣，只有拇指盖大小，正面錾着一朵莲，背面刻着四个蝌蚪般的小字：香里寻味。

门外忽然传来脚步声。顾长山掀帘进来，鼻翼翕动，目光落在她手上那枚铜扣上，眉头微拧：“这扣子……”他走近细看，眼底闪过一丝惊讶，“和那天矮胖子公文包上的铜扣，是同一模子打的。”

苏荷把铜扣攥进掌心，手心里沁出一层薄汗。那矮胖子是来过店里打听房契的人，他的公文包上怎么会有同款铜扣？这枚铜扣是巧合，还是有人故意把线索埋进这坛米酒里？

“长山哥，那天那个矮胖子，后来还来过吗？”她问。

顾长山摇头：“没再来。不过街道办老王说过，那人拿的是省城一家贸易公司的名片，叫‘恒昌’，专门做粮油批发的。”

“恒昌……”苏荷把这名字嚼了一遍，转身把铜扣用布包好锁进抽屉。她回到灶前，抄起铁勺舀了一勺米酒放到火上加热，酒香蒸腾开来，整条城南巷都像被这香气浸透了。巷口一个推着杂货车的老汉停下来，站了片刻，又走了。过了不到半炷香，一个穿军大衣的中年男人走进来，搓着手问：“老板，这什么酒？我在巷口就闻到了。”

苏荷抬头，正要接话，眼角余光却瞥见门外街对面，一个穿灰呢大衣的身影一闪而过——那人动作很快，扭脸进了巷子岔口，只留下一截没来得及收起的进口过滤嘴烟头，被他随手掼在地上，还冒着轻烟。

她心里一紧。那个窥井的人，又来了。而这一次，他站在她店门口，等了一早晨，等的很可能就是这坛酒的味道。

“是我们家自己酿的米酒，不卖。”她笑着对军大衣男人说，“但您要是喜欢，进里屋坐，我给您倒一碗尝尝。”

中年男人受宠若惊地坐下，苏桃机灵地添了一碟醋泡花生。苏荷端着酒碗走出后厨，经过门口时弯腰拾起那半截烟蒂——滤嘴纸上有淡淡的金线压印，不是本地货。她把烟蒂拢进袖口，脸上笑容一丝没变。

那坛酒，酒香引来了客人，也引来了盯梢的目光。

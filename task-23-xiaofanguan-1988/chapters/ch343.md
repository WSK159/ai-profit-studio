# 第343章 四两拨千斤

苏桃话音落下的那一刻，空气中像是绷紧的弦被猛然拨响。苏荷攥着那本油腻的旧书，心头迅速涌过好几个念头。

食品厂偷配方——郑国栋干的。这封电报来得如此及时，偏偏选在她打开暗格、人不在店里的空档上门查封，分明是里应外合、调虎离山。

她抬眼直直地看向郑国栋。郑国栋脸上那副堆出来的笑意已经有些僵了，他嘴唇微动，支吾着道：“苏老板，这、这跟我可没关系啊……”

“跟你没关系？”苏荷把那块铜牌往暗格边上往旁边一放，不急不缓地道，“那郑厂长怎么知道我今天一定会来老宅？又是谁跟你说，我店里有食品厂的配方？”

郑国栋的脸颊抽了一下，仍强撑着：“不是你约的今天吗？你说周三要来的呀。”

“我是约了周三不假。”苏荷的拇指轻轻摩挲着《灶台百解》的油布封皮，“可我上回跟你说的时辰是辰时中刻，后来我让人传话说改到午时。你信里却说‘辰时恭候’，郑厂长，你记岔了吧？”

郑国栋愣住，那张保养得体的脸肉眼可见地泛起一层薄红。他张了张嘴，却说不出反驳的话来。顾长山站在一旁，看得分明，低声道：“他一直在盯着你店里的人，只怕连你前天腌了几坛子泡菜都数清楚了。”

“郑厂长，”苏荷放缓了语气，声音却带着不容置疑的冷意，“我店里的配方是几锅高汤、几勺红油、三斤面粉的事，要偷也是别人偷我的。你派那些人过去，是觉得我苏荷好欺负，还是觉得我请的师父是个摆设？”

周明善一直沉默不语，此刻从门口缓步走进灶房，他个子不高，站到郑国栋面前时却让这个中年男人不自觉后退了半步。老厨师的声音平静如深潭：“郑国栋，三十年前你爹来我家，是跪着求我救他老婆的命。今天我徒弟开个铺子，你转过头就给她使绊子，你周家人的良心，就是这么做买卖的？”

郑国栋的额头上渗出了细密的汗珠。他咬着牙，半晌，弯下腰来，朝苏荷鞠了一躬：“苏老板，是我糊涂。那些去店里的人，是我让表舅带着去的，我这就派人叫回来。”

“不必了。”苏荷把暗格里剩下的东西一件一件取出来用布包好——一本《灶台百解》、一块铜牌、一个巴掌大的竹匣子，还有一卷泛黄的绵纸。她一边收拾一边说话，语气平平淡淡的：“你这头让人来砸我的店，那头的买卖也甭想再谈了。那半块金牌你自己留着吧，我这人不跟背后插刀的人合伙。”

郑国栋脸色大变：“苏老板，话不能这么说！那金牌是周家的，你师父在这儿……”

“周家金牌？”苏荷将铜牌递给周明善，让他收好，然后转回身，朝郑国栋笑了笑，“你说的是你手里那半块仿的吧？真的这块在我师父手里。你二房奶奶托付给你的信里写的什么我不清楚，可但凡她真想把周家的东西交到你手上，当年就不会把真牌留在灶台里了。”

郑国栋的脸终于彻底白了。他站在那里，嘴张了又合，像一条被捞上岸的鱼。

苏荷不再看他，拎起布包，招呼苏桃和顾长山往外走。迈出门槛前，她又顿住脚步，回头看了郑国栋一眼：“对了，你替我带句话给你表舅——他要是在我店里碰坏了一碗一碟，我双倍从食品厂的进货单上扣回来。”

说完，她头也不回地走出老宅大门，穿过落尽梧桐叶的巷道，一直走到转角处才停下来，背靠住墙壁，长长地吐出一口气来。

苏桃紧张地扯着她的袖口：“姐，你到底拿没拿他们配方？”

“傻子。”苏荷抬手敲了敲她的额头，“你姐这手艺，还需要偷谁的配方？郑国栋那是贼喊捉贼——他老早想要周家的《灶台百解》，又摸不清真假，就想把我引到老宅来，让我给他当探路石。等他拿到书，再回过头来咬我一口，说是我偷了他食品厂的方子，人赃俱获。”

顾长山站在旁边，眉头微蹙：“你早就知道那暗格有问题？”

苏荷沉默了一瞬。她低声道：“我前世跟郑家打过一回交道，知道他这人说话最多信三分。他给我看那封托付信，我让师父验过字迹，确实是周婉芬的亲笔不假——可信里写的‘灶台百解’，跟周婉芬当年说的对不上。周婉芬说那刻的是‘黄铜百味诀’，一句话差了三个字，那就说明他给我看的，是被人改过的信。”

周明善这才开口，声音里带着一丝疲惫：“所以你今天来，是想当面看看郑国栋到底要害你哪一步。”

苏荷点头：“现在看清楚了。他不光想要书，还想要这块金牌——他手里那半块是假的，他真正要找的，就是能凑成一对的这半块。他以为真牌在老宅暗格里，却不知道他二房奶奶临死前早就托人送到了师父手里。”

顾长山看向她手中的布包：“那这竹匣子里装的什么？”

苏荷将布包掀开一角，露出那只巴掌大的竹匣子来。竹匣子通体呈深褐色，包浆厚实，侧面刻着一行极小的字，周明善凑近了，念了出来：“青江，桐花巷，董宅，后厨灶底。”

周明善的脸色微微变了——桐花巷董宅，是青江城里原来最大的一家私房菜馆，老板董三春，六十年代就没了，据说是被打成了右派，死在农场。他的后厨灶底，按理说该在二十年前就被人翻了个底朝天了。

苏荷掂了掂那只竹匣子，又看了看周明善。她轻声问：“师父，你认识董三春？”

周明善没有立刻回答。他望着巷口落尽叶子的老梧桐，过了好一阵子，才说：“董三春是我师兄。他当年跟我是同一个灶台出去的——他会的菜，我全会。但有一道，我学了几十年都没学会。”

“什么菜？”

“烧尾。”周明善的声音低得像一声叹息，“那菜谱，董三春没留给任何人。他死前跟人说过一句话，要烧尾菜，先去桐花巷董宅灶底下刨三斤灰。”

苏荷心头一跳。

三斤灰。

她低头打开竹匣子——里面没有什么灰，却静静躺着一张折成四折的泛黄纸片。上面写的是一份配料清单，最后一行字写着：“卤汤不传之秘，在灰中。”

顾长山看了一眼那张清单，忽然道：“苏荷，回店里吧。那些人闹了一阵子，没人管了自然就散了。你那些个学徒，可还在等你回去呢。”

苏荷将纸片折好放回竹匣，抬起头来，目光穿过梧桐枝丫上空那一片灰蒙蒙的天。她把竹匣子塞进帆布包里时，指尖碰到今天之前暗格里的另一件东西——那卷泛黄的绵纸。她还没看过里面的内容，此时一摸，纸张手感又薄又韧，似乎夹着什么硬物。

她停住脚步，把绵纸抽出来，展开一角。

纸上是一幅手绘的地图，墨线工整，标注着“青江府城”四个字，下面画着一条河道，以及桥、巷、宅院的方位。在那张图的左下角，贴着一枚小小的红签，上面写着一个日期。

一九八七年十一月十七日。

去年的今天。

苏荷盯着那个日期，心里忽然掠过一阵寒意——这是她前世出事的那天。就在这个日期，她所知的某个人，在青江城里消失了。

她将绵纸迅速卷好收回，不动声色地挽住苏桃的胳膊：“走，回店里。有人砸了场子，就得有人把它收拾干净。”

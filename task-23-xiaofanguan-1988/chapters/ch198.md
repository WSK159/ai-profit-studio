# 第198章 夜探老宅

雨又下起来了。青江的秋雨像撕不完的棉絮，缠缠绵绵地往人骨头缝里钻。我披着顾长山那件旧军大衣，站在城南巷尾的老宅门前，手里攥着那张画了弯月符号的纸条。

老宅是陈老爹祖上传下来的，三进三出的老院子，前两年陈家搬去省城，钥匙就托给了巷口的王婶管着。王婶说陈老爹走前特意叮嘱，说房梁该修了，等入冬前找个木匠看看。

“那会儿我还觉得怪，”王婶一边掏钥匙一边絮叨，“陈老爹走的时候连锅碗都没来得及收，倒惦记着修房梁。”

我笑了笑，没接话。钥匙在锁眼里转了两圈，发出涩涩的声响，门轴吱呀一声推开，一股陈年霉味扑面而来。

顾长山跟在我身后，举着手电筒往里照。光柱扫过天井里的青苔，照见墙角蛛网密布。“你确定那纸条说的是这里？”

“不确定。”我实话实说，“但弯月符号，我好像在哪见过。”

“哪儿？”

我摇摇头。想不起来，但总觉得那弯月形状十分眼熟，像小时候在谁家见过，又像在哪本书里翻到过。反正不会是平白无故画上去的。

天井过去是正屋，正屋再往后是后罩房。陈老爹当年在青江市粮食局干了大半辈子，退休后就在这老宅里养花种草，带孙子。房梁是杉木的，黑漆漆的，年头久了，油亮亮的包浆裹着一层灰。

手电筒的光沿着房梁一寸寸扫过去，都是些蜘蛛网和灰尘，看不出什么异样。我正要放弃，顾长山忽然说：“那根梁，颜色不对。”

他指着头顶正中那根粗大的横梁。我眯起眼细看，果然，其他梁都黑得发亮，唯独那根，颜色偏浅，像是被换过或是翻新过。

“找个梯子。”

王婶家里还真有架竹梯，靠在围墙边，说是晾衣服用的。顾长山上去，指尖沿着梁身摸索，摸到东头时手一顿：“有缝。”

他使劲一掰，一块木头活板应声翻开，露出里面一个油布包。

油布包不大，也就两本硬面笔记本的厚度，外面用麻绳捆得紧紧的。我接过来，入手比预想中沉，有种往外鼓的胀感。麻绳解了三道，油布翻开，里面果然是两个笔记本，还有一个牛皮纸信封。

“老陈的笔迹。”我一眼认出笔记封面上那个瘦长的“陈”字。

顾长山下来，把手电筒架在条凳上。我翻开第一本，心脏不由狠狠跳了一下——这不是账本，好像比账本更值钱。

第一页是一份名单，列了十三个名字，后面跟着职务，全是青江市粮食系统各层级的人物。老苗赫然在列，郑副科长的名字也在。最顶上那个名字我认得，是市粮食局副局长，姓梁。

第二页起才是账目。日期、品名、数量、进出手续，一一对应，记得极细。老陈退休前是仓库的核算员，他这账，记得比仓库正式账目还清楚。

“耗油一千二百斤，面粉三千斤，大米……”我喃喃往下念，念到一半，忽然看见一个熟人名——“青江饭店，刘经理。”

刘经理，正是今天我窃听时听过的那位。老陈的账上记着，青江饭店从粮库“借油”三次，每次都打条，签字人是刘经理，批准人一栏写的是“郑”。

“郑副科长。”顾长山说。

我点头，继续往下翻。翻到最后几页，笔迹明显潦草起来，像是赶着写的。最后一页只有一句话：“账在梁上，人在路上。弯月照处，苏记是根。”

弯月。苏记。

我脑子里忽地闪过一道光，身上汗毛都竖了起来。我想起来了，前世师父案板上刻的那枚小印，就是一枚弯月。

她来不及细想，王婶的嗓子从门外炸开：“苏老板！苏老板！你快出来看看，巷子里来了好些人，说是粮食局的！”

第二本笔记本还没翻开。

我飞快地把两本本子和信封塞回油布包，往军大衣里一裹，冲顾长山使了个眼色。他二话不说，把油布包接过去，塞进院墙外那口枯井的井壁凹洞里，又用碎砖抹泥封好。

等我们出了大门，巷子口已经站了四五个穿中山装的人，前头带队的老苗。雨幕里，老苗手里拿着一卷纸，看见我，脸上浮起一层不自然的笑。

“苏老板，有人举报，说陈老爹这宅子藏了什么不该藏的东西，市里让我来查一查。您和顾同志这是……”

“路过。”我说得面不改色，“王婶叫我来看看，说巷口水管子漏水，正好碰上顾同志。”

老苗目光在我脸上停了三秒钟，笑了笑说：“那就好。苏老板生意做得好，有些事，还是少掺和的好。”

# 第391章 水的问题

第二天清晨，苏荷起得很早。天边刚泛鱼肚白，她把昨夜的竹板重新在晨光里翻看了一遍，确认没有再发现别的暗记，才锁好铁盒，去后院缸里舀水洗脸。她随手拨开水面上一层浮萍，水缸倒影里映出她年轻的脸，恍惚间她好像看见水底下有什么东西一闪而过——黑黑的一条，跟昨晚河面上那个挥手黑影的形状重合了一瞬。她猛地站直，水波荡开，倒影碎掉。再看时，只剩自己的脸。

这缸水是从董家渡码头挑的，每天清早一担，用来洗菜做饭。她不自觉地盯着缸底，那里面什么都没有，青苔覆着一层薄薄的沙。她咬了咬牙，用葫芦瓢搅了搅水面，转身走进灶间。

早饭做的是猪油拌面，热气腾腾的，她到底当了几年主厨，即便心绪浮乱，手上功夫依旧稳稳当当。面端上桌时，顾长山也收拾利索出来，嘴里叼着牙刷，冲她点了点头，意思是“我去码头那趟”。

苏荷送他到门口，刚转身就见巷口那边一个身影朝铺子快步走来——是隔街卖菜的刘婶。她气喘吁吁地过来，压低声音说：“苏老板，今早我去码头进货，听见那边有人嘀咕，说这几天老有人拿着长竹竿在码头西段探水，探的不是淤泥，是探底下的石缝，还看见有人半夜举着马灯站在堤上，对着水面丢东西。”

苏荷面色不变，心里却咯噔一下。她谢过刘婶，关上门后站在原地想了想，回到灶间把那块竹板从铁盒里拿出来，揣进怀里，又从后院提了一桶井水倒进木盆。她把竹板朝水里一沉——等着。

过了大约一刻钟，竹板表面没有任何变化。她将竹板捞起来，又试了温水，还是没有。她想了片刻，换了灶间灶膛里的温灰水，搅拌之后把竹板放进去，又等了一炷香的时间，竹板的一端终于出现了细微的变化——那片原本光滑的竹面浮出一行浅黄色的字迹，笔画洇开，像是早年用米汤写就之后又被岁月封住了。

她赶紧将竹板取出，对着窗边光读那行字——“石下三寸，缸上七锁。”

短短八字，字迹娟秀，不像撑船老翁的手笔。苏荷记下字句，将竹板擦干放回暖处，心跳微微加速。石下三寸，应该指水下石圈的位置；缸上七锁，七把锁——是说缸口用七道锁封死？还是需要在某个地方解开七处机关？她暂时想不透，却本能地觉得这八个字很重要。

收拾好灶间的时候，顾长山回来了。他身上带着河风的腥气，进门先灌了半碗凉茶，才低声说：“码头西段那边确实有人动了手脚。系缆桩的绳子被人换过，桩脚周围是新夯的土，不是旧泥。按你画的那张图的方位，那个位置靠上游偏了大约两丈。”

苏荷怔住：“你是说，有人把石圈挪过？”

“绳子是新桩用旧绳，但夯土是今天早上刚踩实的。码头的人说，昨晚后半夜来了条小船，从磨子桥方向划过来的，下来两个人，在岸边待了小半个时辰就走了。”

“看清长相了吗？”

“那边只有一盏路灯，隔得远。只说其中一个人，戴着一顶草帽。”

苏荷的指尖在桌面轻轻叩了两下。草帽。她上一次听到“草帽”这个词，还是从桥头杂货铺何庆生嘴里。

“老郑那边呢？”她没有追问草帽的事，先把眼前的线索理清。

“老周给了个信儿。”顾长山坐下来，凑近她压低声音，“老郑这个人在市局的档案里没有刑事记录，但有一条一九八五年的信访记录，说他涉及倒卖文物，后来查无实据，销了案。卷宗里留了一句话：‘当事人于一九八五年二月移居外地。’”

苏荷眯起眼睛：“移居外地？一个人要真在本地做正经生意，怎么查不到落脚点？说明他是借了别人的户口走的。”

顾长山点头：“老周说的也是这个意思。他又补了一句，说那条信访记录的批文，是当年派出所一个姓秦的人签的——秦，就是之前给你摆过渡船簿的那个秦老船工的本家。”

苏荷脑子里一个念头猛地接通了。

秦老船工。草帽人。老郑。码头西段那根晃动的钓线——她忽然伸手按住桌上那块竹板，语气带着一种自己都没察觉的紧：“顾长山，那个姓秦的批文，后来签的是哪个所？”

“城南路派出所。”顾长山答完之后自己也愣了，“城南路——就是董家渡对岸那条老路。”

苏荷的呼吸顿了一拍。一切线索在盘根错节中慢慢摸向同一个节点：董家渡，城南路，董家老宅，老郑，草帽人，何庆生，秦老船工，还有这块写著“千山鸟飞绝”的竹板——所有人看似无关，却似乎都在围着同一样东西转。那个东西在水下，在缸里，在七道锁之后。

她正想再开口，堂屋的门忽然被人从外面拍响了。一个声音隔着门板传进来：“苏老板！苏荷！开门！出事了！”

是隔壁豆腐坊的老杨。苏荷拉开门，老杨一手撑着门框，脸涨得通红：“你那个老主顾，天天来吃红油抄手的那个老人家——今天早上倒在码头上，人已经送医院了，说是吃东西中了毒！”

苏荷的脸色刷地白下来。老人家，红油抄手——她脑中闪过的第一个念头就是铺子的食材。可今早所有的料都是她自己亲手备的，不可能是她的抄手出了问题。那老人为什么会在码头边倒下？

她回头看了顾长山一眼，两人目光交汇。顾长山已经抓起外套朝门口走去，苏荷紧随其后，但她在跨出门槛的一瞬间，忽然顿住脚步，回头望了一眼灶间那一口井水木盆的方向。盆里的水已经静下来了，水面映出灶间的梁柱，还有一块空荡荡的案板。

那块竹板，不见了。她明明放在暖处——现在只留下一个湿漉漉的印子。

# 第131章 旧人新事

苏荷从城南茶楼回来，一路没说话。

灶台上的火还燃着，锅里的卤汤咕嘟咕嘟冒着小泡。她掀开锅盖看了一眼，又盖上，转身把那布袋里的东西全倒在案板上——不是契书，是一叠旧报纸，1983年的《青江日报》，头版头条写着“个体经济增长迅猛，市政府鼓励多种经营”，后面几页全是泛黄的招聘启事和副刊连载。

她利用的只是这些报纸的分量，孙桂发如果真敢翻布袋，会发现里面连一张带字的纸都没有。

苏荷把报纸重新叠好，收进柜子底下。她站在灶台前想了想，还是解下围裙，从后门出去了。

城南巷走到头，拐两个弯，是老三届茶馆。这茶馆开了几十年，茶客多是些退休老头儿，整天坐在里头下棋聊天。掌柜是个驼背的老头儿，姓刘，耳朵不好使，见苏荷进来只眯着眼笑，递上一壶茉莉花茶。

苏荷坐下来，端着茶杯吹了吹，眼光不动声色地扫过角落。

那张竹椅子还在，上面的素面碗已经被收走了。竹椅旁的茶桌上放着一副老花镜，还有半包没抽完的“飞马”牌香烟。

她认得这副老花镜——镜腿用胶布缠过两圈，是苏老三年轻时候也戴过的那种款式。可苏老三今年才四十七，戴老花镜还早了十年。

苏荷放下茶杯，走到那张桌边，用指尖轻轻碰了一下茶碗。碗边还温着，人走得不远。

她出了茶馆后门，是一条窄巷，两旁是青砖老墙，墙角堆着几根旧木料。她顺着巷子往前走，走到第三棵槐树底下停住了。

这棵槐树比城南巷口那棵粗一圈。树根底下有一块砖头缺了角，露出里面黑色的泥土来。

苏荷蹲下去，指尖拨开泥土，摸到一块硬的东西。她生生咽了一口气，把那东西往外拽——是一块半掌大的陶片，边缘圆润，像是被人反复摩挲过的。

陶片背面刻着一个字，用指甲能划过浅浅的痕迹，是个“沈”字。

苏荷把那陶片握在手心里，站了一会儿。她记得师父沈国章晚年曾经说过一句话：“我年轻时收过一个徒弟，姓赵，手艺没话说，就是命不好。后来我寻了他半辈子，也没寻着。”

姓赵，赵一鸣。

苏荷回到馆子时，顾长山正蹲在门口台阶上抽烟。见她回来，他把烟掐了，站起来：“谈成什么样？”

“没谈成，也没谈崩。”苏荷把那陶片放进口袋，进了门，“你帮我查个人——赵一鸣，以前住城南巷，跟我家有点渊源。大概五几年到六几年在青江待过，后来下落不明。”

顾长山没多问，点了点头：“我托战友翻翻户籍档案。”

苏荷进了灶间，又回头叫住他：“还有，你记得上次在城东遇到过那个退伍兵老周吗？他说他在省城见过一家老馆子，老板姓沈。”

顾长山想了想：“那是两个月前的事了，你说你听岔了，没当真。”

“当时是听岔了。”苏荷把围裙系好，弯腰点上火，“现在不一定。”

傍晚，苏桃放学回来，书包都没放就凑到灶台前：“姐，你猜我今天在学校见着谁了？”

“谁？”

“一个老太太，在学校门口打听你。”苏桃从口袋里掏出一张纸条，“她让我转告你一句话，说‘姓沈的托我带句话，第三口樟木箱，他打开了’。”

苏荷手里的锅铲顿住了。

她想起赵小柏当天转交的那张1963年五木器社收据——樟木箱三口。第一口装的是地契，第二口装的是账本，第三口一直没打开过。

她问苏桃：“那老太太长什么样？”

“六十多岁，穿一件蓝布棉袄，包着条格子头巾，说话口音有点怪，不像本地人。”苏桃想了想，又补了一句，“她把手腕上的一串木珠子摘下来塞给我，说‘见到你姐，把这个给她’。”

苏桃从书包里掏出一串暗红色木珠，摊在掌心里。

苏荷伸手接过来，珠子上有淡淡的樟木香。她翻到其中一颗，看见珠面上刻着一个极小的字。

“沈。”

苏荷把木珠攥紧，那串珠子便在她掌心里发着微微的凉。她抬头看了一眼窗外，天已经黑透了，城南巷的路灯亮着昏黄的光，像一只半睡半醒的眼睛。

第三口樟木箱被打开了。箱里装的是什么，她不知道。但打开箱子的人，似乎已经找到她了。

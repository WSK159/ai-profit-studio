# 第378章 黄豆

晨雾还没散尽，渡口的江水泛着铅灰色。苏荷蹲在岸边，把铁锅翻过来又翻过去，那豁口处凝着一层暗红的锈，像是被什么东西咬掉了一块。

前世师父的锅，也是这个豁口。

她记得清楚，师父临终前把锅交给她，说：“锅豁了，人别豁。”她当时不懂，后来在米其林后厨切了十年菜才明白，师父是说做人别缺角，缺了角就再也圆不回来。

顾长山站在她身后，手里攥着那袋黄豆，袋子是粗麻布的，口子上系着红绳，红绳的纹理和之前灰鹊脚上绑的那根一模一样。

“走。”苏荷站起来，把锅背在背上，“去城西老磨坊。”

青江城不大，从渡口到城西走路也就半个时辰。一路上经过早市，卖菜的老太太扯着嗓子喊：“黄瓜两毛一斤！顶花带刺的！”卖豆腐的推着板车，车上木格子里搁着白嫩嫩的豆腐，冒着热气。有人蹲在路边吃油条，油条裹着晨光，金黄酥脆。

苏荷看着这些，心里踏实了些。1989 年初的青江，还在从年前抢购潮的余波里缓过劲来。物价稳定了些，街上的个体户比去年多了一倍，卖衣服的、卖磁带的小摊沿街排开。改革的春风刮了一年多，城里有了点活泛气。

老磨坊在城西最边上，挨着一片菜地。说是磨坊，其实早就不磨面了，瓦房塌了半边，门口堆着碎砖烂瓦，一只黑猫蹲在门槛上，懒洋洋地舔爪子，见人来了也不躲。

顾长山正要上前推门，苏荷拦住他。她蹲下来，从袋子里抓了一把黄豆撒在门槛前。黄豆粒粒饱满，滚了一地，黑猫低头嗅了嗅，起身慢悠悠地往屋里走。

“跟上它。”苏荷说。

顾长山看她一眼，没问为什么。两个人跟着黑猫穿过堂屋，后面是个小天井，天井中间有一盘石磨，磨盘上落着厚厚的灰，旁边歪着一只破木桶。

黑猫跳上石磨，趴下来，尾巴一甩一甩。

苏荷围着石磨转了一圈，发现磨盘边上刻着一个字，被灰糊住了大半。她用手擦了擦，是“孙”字，笔画有力，像是用凿子一下一下凿出来的。笔锋间积着黑渍。

“黄豆。”她轻声说，又抓了一把黄豆，顺着磨盘的进料口倒进去。

磨盘当然转不动，但黄豆一颗一颗顺着缝隙往下漏。苏荷侧耳听着，听到里面传来“咚”的一声闷响，像是什么东西被黄豆砸中了。

顾长山走过去，搬开磨盘上扇。下面不是空的，压着一块长条青石，石头上勒着一圈麻绳，绳结系得端正，是水手结。

他解开麻绳，掀起青石，底下露出一个不大的坑洞，里面放着一只木匣子，匣子已经发黑发霉，像是泡过水又晾干的，木纹全都翘了起来。

苏荷的心跳快了一拍。她把木匣子抱出来，沉甸甸的，摇了摇，里面没有声音。匣子没有锁，只在侧面嵌着一道铜箍，铜箍上刻着两个字——“孙记”。

和之前砖房里找到的乌木筷铜箍一模一样，一个模子刻的。

她打开匣子。里面放着一件叠得整整齐齐的灰布长衫，长衫上放着一封信，信封发黄，没有抬头，只写着四个字——“吾徒亲启”。

那字迹，她认得。前世师父写菜谱的字，就是这个样子，横平竖直，末笔带钩。

苏荷的手指微微发抖，拆开信封，里面是一张薄薄的绵纸，上面的字不多，一眼就能看完：

“荷丫头，你看见此信时，我已不在青江。勿寻。锅豁了，人别豁。黄豆好，蒸菜好，底汤好。城南巷那间铺子的地契，在石磨底下压着，你拿走。你爹来过，我跟他谈了。他要你回去，我没答应。你要是认我这个师父，就把铺子开好，开成大铺子，开成老铺子。师父姓孙，名不言。你前世没想过师父为什么不言，这辈子记住，言多必失，烧菜的人，锅里的火比嘴上的话值钱。”

苏荷盯着“孙不言”三个字，眼眶一热。前世师父确实不爱说话，她想问什么，师父就只说“尝”，她有时候急脾气上来了，觉得师父瞒着事情。却不知道师父姓什么。原来，师父叫孙不言。

原来，师父从来没死。至少，在这个时代，他还活着。他活着，还来过青江，还在城南巷那间铺子里，跟她爹谈过话。

她把信翻过来，背面画着一幅小小的地图，画的正是城南巷一带。中间圈了个圈，写着“铺”字，圈旁边画了一条弯弯曲曲的线，线的顶端画着一棵歪脖子树。

“走。”她把信纸折好，贴身收好，“去城南巷。”

顾长山把灰布长衫抖开，里面掉出一只小布包，包着几枚铜钱，一枚一枚数过去，正好十二枚，十二个月的月钱。他怔了一下，把铜钱包好递给她。

苏荷接过铜钱，在手里握了握。铜钱还带着体温。她前世师父有个习惯，初一早上往衣兜里放一枚铜钱，说是“压月”。月月压，压一年，这十二枚铜钱就跟了他一年。

她把这十二枚铜钱穿在一根红绳上，系在手腕上。铜钱碰着铁锅，发出一声闷响。

出了老磨坊，太阳已经升起来了，照在菜地上，露珠亮晶晶的。苏荷深吸一口气，正要往城南巷走，就看见路口站着一个穿中山装的男人，三十来岁，戴着黑框眼镜，正朝她这头张望。

她脚步一顿。

那男人看见她出来，立刻转身走了，步子很快，像在赶路。苏荷盯着他的背影看了几秒，忽然喊了一声：“同志，等一下。”

那人没停，反而走得更快了。苏荷追了两步，那人拐进一条巷子，转眼不见了。

顾长山皱眉：“谁？”

“不认得。”苏荷慢慢停下来，目光还黏在那人消失的方向，“但他在等我们出来。我看见他手里夹着一支笔，本子揣在怀里，这个打扮，像是记者。”

“记者？”

“搞不好，是冲孙先生来的。”

她正说着，身后传来一个声音：“姑娘，你找人？”

苏荷回头，一个佝偻着背的老头子蹲在菜地边拔草，抬眼看她：“老磨坊好久没人来了，你刚才进去，我看见你把磨盘搬开了。那地方，别人搬不开的。”

苏荷心里紧了紧：“老人家知道那里面有什么？”

老头笑了笑，露出一口黄牙：“我不管里面有什么，我只知道，以前有个姓孙的先生，每年秋天都来磨黄豆，磨完就坐在磨盘上吃一碗热豆腐。他走的时候跟我说，如果有天有个背着铁锅的女娃儿来，让她去城南巷看一眼，那棵歪脖子树底下，埋着一罐东西。”老头往城南巷的方向努了努嘴。

苏荷和顾长山相视一眼。

“走。”她说。

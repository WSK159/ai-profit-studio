# 第444章 陈米的味道

苏荷盯着那碗桂花蜜粥看了足足半分钟。米粒熬得开花，桂花是去年秋天摘的，蜜是槐花蜜——跟她师父方九如的手艺一模一样，连碗边的量都差不了半厘。

“沈伯言人呢？”她把碗放下，声音有点紧。

苏桃摇头：“放下粥就走了，说今夜子时起凤桥头等姐姐。哦，他还留了这个。”

一张黄纸，折成四折，打开来是一行瘦金体楷书：“方师未死，只是活成了另一副模样。”

苏荷反复看了三遍，指尖微微发颤。她前世的师父，那个教她吊汤、教她识火候、教她“做菜要有良心”的老人，她守了他三年灵。若他真还活着……那她守的又是什么？

“姐？”苏桃小心翼翼地唤她。

苏荷吸了口气，把黄纸折好贴身收起来，转向乔春海留下的那张纸条：“驼背老儿”四个字，字迹潦草，像是匆忙写的。她把两张纸并排放在桌上，忽然问：“乔春海走的时候，有没有说什么别的？”

苏桃想了想：“他说，‘你姐命硬，像她娘。但命硬的人，最容易踩进别人挖好的坑里。’”

苏荷眼神一凛。这话听着像叮嘱，更像警告。她还没来得及细想，顾长山从后院进来了，手里拿着一只旧布袋：“在枯井边上捡的，压在缸底下。”

苏荷接过布袋，打开——里面是一捧米。已经发黄，结着硬块，但那股气味让她心里咯噔一下。她把米凑到鼻子底下闻了闻，又用指尖捻开一粒。

“怎么了？”顾长山看出她脸色不对。

“这米在水里泡过。”苏荷说，“不是一般的水，是盐水。而且泡的时间不短，至少三天。”

她放下米，声音发沉：“庚午年沉船，二十多口缸沉入江底。缸里装的是什么？有人说是酒，有人说是粮。乔春海认了押船人的身份，钟九指说‘存人者存命’——这米，就是沉缸里装的东西之一。”

顾长山沉默片刻：“你是说，有人故意把米泡了盐水，使其无法发芽？”

“对。”苏荷抬眼，“沉缸的每一样东西，都有人不想让它重见天日。这米是用来喂人的还是喂别的，我暂时想不通。但有一点确定了。”

她指了指枯井方向：“那只破缸的米，跟这里的一模一样。钟九指当年藏的是同一批货。”

晚间九点，苏荷换上一双旧布鞋，把师父送她的那枚铜片贴身藏好，又往袖子里揣了一小包干辣椒。顾长山要跟，她摇头：“沈伯言只点名了我一个人。”

“万一有诈呢？”顾长山皱眉。

“有诈也得去。”苏荷笑了笑，“他说师父没死。就这一句，就算是刀山火海我也得走一趟。”

起凤桥头是青江城最老的石桥，桥下的水已经不太干净了，但月光洒下来，仍能看见斑驳的桥柱。苏荷到的时候，沈伯言已经在了。他坐在桥栏上，手里拎着一盏旧灯笼，灯罩上画着一朵五瓣梅花。

“苏姑娘来得早。”他跳下桥栏，“吃粥了吗？”

苏荷没接话，直直看着他：“你师父是方九如。”

沈伯言没否认：“方九如是我师父，也是你师父。”

这话听着绕，但苏荷听懂了：“他也是我前世的师父，你这一世也是他的徒弟——你在暗示，我跟他是同一个师门？”

沈伯言没接这个话头，却把灯笼递了过来：“师父让我交给你的。他说，你见了灯笼自然明白。”

苏荷接过灯笼，翻过来一瞧，灯罩内侧贴着一张纸条，只有三个字——“尝陈米”。

她猛地抬头。陈米——她今天才碰过枯井下那缸里的盐水陈米，消息不可能这么快传出去。除非有人一直盯着她，而且知道她在查什么。

沈伯言幽然开口：“师父说，当年沉缸的米不是给人吃的。那米泡过盐，又泡过药，是喂给缸里’存着的人’续命用的。”

他压低声音：“苏姑娘，你想不想知道，庚午年那二十多口缸里，活着出来的有几个人？”

苏荷捏紧灯笼骨架，心跳骤然加快。

她正要开口，桥下的水里忽然咕嘟冒起一串泡。沈伯言脸色一变，猛地抓住她手腕往后拽。

下一秒，一只湿淋淋的手从桥柱边的水面伸出来，啪地拍在青石板上。

# 第136章 账册上的名字

晨光从东边烧窑的烟囱缝隙里漏下来时，苏荷已经蹲在瓦房门口把那本蓝皮账册翻了十来页。油布裹得严实，账册边角却还是洇了潮气，纸页发软，墨迹却清晰如新。她手指点在某一行的名字上，指尖微微一顿。

“顾长山，你来看这个。”

顾长山正把油布重新叠好塞回墙洞，闻言走过来，低头往她指尖的方向看。账册上密密麻麻记着三年间的粮食进出，日期、数量、经手人，工工整整的蝇头小楷。而苏荷指的那一行，日期是1985年11月17日，经手人写着“赵一鸣”，备注栏里却用更细的笔迹添了三个字——“秦掌柜”。

“赵一鸣经手的粮食，最后送到了省城德兴楼？”顾长山皱眉。

“不止。”苏荷又往后翻了两页，指着另一处，“11月23日，还是赵一鸣，备注还是秦掌柜。12月3日，12月17日……每隔半个月就有一批，全是精面，数量不小。”

她抬起头，晨光映在她脸上，眼睛亮得有些锐利：“沈国章说账册能破孙桂发和于德水夺宅的图谋，但这里面从头到尾没提孙桂发一个名字。赵一鸣一个粮站会计，凭什么动了这么多粮食没人查？背后没人罩着，他撑不过三个月。”

顾长山沉默片刻：“你是说，账册能牵出孙桂发？”

“孙桂发当年在于德水手底下跑腿，后来于德水倒了，他反而上了位。”苏荷把账册合上，塞进自己外套内袋，拍了两下，“一个跑腿的能翻身，要么是踩了主子的肩膀，要么是手里攥着主子的把柄。赵一鸣倒卖粮食被抓的时候，于德水还在台上——账册要是落到孙桂发手里，能拿捏于德水一辈子；要是落到别人手里……”

她没说完，巷口忽然传来一阵脚步声，两个人同时噤声。顾长山侧身往瓦房山墙后一避，眨眼间手已经搭在腰侧。苏荷也屏住呼吸，后背贴着墙根，手指扣住账册边角。

脚步声越来越近，一步、两步，踩在碎砖瓦砾上沙沙响。紧接着一个声音从巷口传来：“苏老板？是你吗？”

是个女人的声音，带着点怯意。苏荷眉头微松，从墙后探出半边身子——巷口站着个穿碎花棉袄的年轻姑娘，二十出头，扎着一条马尾辫，手里攥着个竹篮，筐里露出几根葱和一块豆腐。

是城南巷西头卖豆腐的王秀芬，平时常在苏记门口买早点，跟苏荷算半个熟脸。

“秀芬？你怎么跑这儿来了？”

王秀芬看见她，明显松了口气，快步走过来：“我刚才在巷口看见有人往这边探头探脑的，像是不怀好意，我就绕过来看看……苏老板，你没事吧？”

苏荷心里一暖，嘴上却道：“没事，我跟顾大哥来办点事，这就回去了。”说着不动声色地把顾长山从山墙后让了出来。顾长山冲王秀芬点点头，没说话，目光却越过她的肩头往巷口扫了一圈。

“没人跟着你吧？”

王秀芬摇头：“没有，我走的小路。”她顿了顿，又想起什么，“对了苏老板，你赶紧回店里去——今早有人来店里找你了，说是什么……产权处的。”

苏荷眼皮一跳：“产权处？说什么了？”

“说你家那铺子有个什么……权属纠纷，要你去办事处核对一下材料。”王秀芬说着，语气里带了点担忧，“我看那人西装革履的，不像咱们城南巷的人，倒像是从市里来的。”

苏荷和顾长山对视一眼。两人心里同时浮起一个名字：孙桂发。

“知道了。”苏荷稳住语气，拍了拍王秀芬的肩，“谢了秀芬，你这份情我记着。回头到店里来，我给你留一碗红油抄手。”

王秀芬笑着应了，转身沿原路往回走。等她的脚步声彻底远了，苏荷才转向顾长山，声音压得很低：“孙桂发动手了。他不敢自己出面，就借着产权处来卡我。”

顾长山道：“账册在你手里，就算他去产权处闹，也拿不出实据。倒是这消息传得快——昨晚我们才翻出账册，今早就有人找上门。”

苏荷眯了眯眼：“所以孙桂发不是知道账册在哪，是怕我们找到账册。他急了，才会先下手。”

说话间两人快步走出烧窑片区，拐上通往城南巷的柏油路。晨起的自行车铃叮铃铃响过，路边早点摊的蒸笼白气腾腾往上冒，人间烟火气扑面而来。苏荷的步子却半点没慢，她一边走一边把账册内袋的扣子又按紧了一回，脑子里飞速转着几个念头。

产权处来查，孙桂发抢铺，于德水的旧债，沈国章丢的那条命……全缠成一股绳，绳头就攥在那本蓝皮账册里。

她现在最需要的，是弄明白那两封没有寄出的信里写了什么。

# 第367章 老屋灶膛

城南瓦匠铺不算难找。青江的城南大多是老宅子，灰瓦白墙，被雨水淋得斑斑驳驳，巷子窄得只能过一辆自行车。苏荷一路走一路看，凭着前世师父描述过的口音和方位，她在一条叫“蓑衣巷”的短巷底找到了那间被翻修过的老屋。

门口还堆着没运走的黄泥和青砖。瓦匠铺的包工头是个四十来岁的黑脸汉子，她递了根烟过去，说想打听翻修时灶膛里掏出来的东西的事。那汉子把烟夹耳朵上，想了想，说：“是有个铁铲子，那家主人不要，我手底下一个后生拿回去孝敬他爹了。怎么，惹麻烦了？”

“没有，我就是想问问，那灶膛掏出来的那几斤灰，你们扔哪儿了？”

“灰？”汉子挠挠头，“那个不是黑的跟墨一样嘛，我一看就邪门，没敢乱倒，用蛇皮袋装了扔屋顶了。”他指了指屋子的方向，“还在那儿呢，雨水淋了半个冬天了，不知道成什么样了。”

苏荷心里一紧，面上不显，说了声谢就往里走。老屋还没完全翻修完，堂屋地上的黄泥还湿着，一股石灰和土腥味混在一起。她顺着墙边的木梯子爬上屋顶，果然看见平台角落窝着一条蛇皮袋，瘪瘪的，上面覆了一层枯叶和灰土。

她蹲下来，拉开袋口。里面的灰已经被雨水浸成一坨灰黑色的泥块，带着一股说不清的气味。她伸手掰下一小块来，放在鼻尖嗅了嗅，那股味道很淡，却让她浑身一震，是焦麦粉和药草混在一起的味道。这味道她太熟了，前世师父配那副药粉的时候，满院子就是这股味儿。

她攥着那坨灰泥站在屋顶上，风从江面吹过来，她看着脚下这片老城南的屋顶，灰瓦起伏下去像一片静默的脊背。师父这辈子，到底在这里藏了什么？

她小心翼翼地把那坨灰泥掰开，里面忽然滚出一样东西，比拇指小一些，沉甸甸的，包着一层已经朽烂的油纸。她剥开油纸，里面是一块小小的铁片，心形，边缘被打磨得很圆润。铁片正面捶着三个字：荷花记。

反面刻着一行小字，歪歪扭扭的，像是用铁钉划出来的：“丫头，锅在官渡口下湾的枯井里，去拿。”

苏荷蹲在屋顶上，盯着那行字，鼻子忽然一阵发酸。官渡口下湾，青江人叫白鹭滩，过了枯水期，滩头上会露出半截老井沿，她前世听师父提过一次，说自己年轻时把一样东西丢在白鹭滩的枯井里，还说“那口井，底下通着江呢”。

她深呼吸了两次，把那铁片攥在手心，揣进怀里，然后爬下屋顶。包工头正在堂屋吃豆花饭，见她下来，问了一句：“姑娘，找到你要的东西了？”

“找到了。”苏荷笑了笑，那笑里带着一点忍着的什么，“师傅，你知道白鹭滩那边，现在还下得去吗？”

“白鹭滩？现在枯水期，底下干得很，你顺着河滩走就能到。”包工头放下碗，又补了一句，“不过那边之前被人用铁丝网围了一圈，说要做什么采沙场。你要是去，得从河滩那头绕过去。”

苏荷道了谢，快步走出蓑衣巷。外面的日头已经偏西了，顾长山靠着自行车等在巷口，见她出来，什么也没问，只把挂在车把上的军用水壶递给她。

苏荷接过来喝了一口，抬眼看着他：“师父留了一封信在灰里。”

顾长山微微挑眉：“说的什么？”

“他说，锅在官渡口下湾的枯井里。”苏荷顿了一下，“他还叫我丫头。”

这句话说完，两个人都沉默了。风把巷口的旧报纸卷起来，哗啦哗啦地翻着跟头。苏荷把铁片从怀里掏出来给他看，天光之下，那“荷花记”三个铁字清晰有力。

“那我们现在去？”顾长山问。

苏荷抬头看了看天色，又看了看铁片，深吸一口气：“去。”

白鹭滩的河滩上，枯水期的沙地干得裂开一块一块的。两人沿着河滩走了大半个钟头，终于看到那口覆着铁丝网的老井。顾长山把铁丝网拧出一个口子，她钻进去，趴在井沿上往下看。井不深，底下的淤泥已经干得龟裂，正中间鼓起一个土包。

她顺着绳子滑下去，用带来的小铁锹挖开那个土包。挖了没几下，铲子就碰到了一个硬的东西，她扒开浮土，露出一个锈迹斑斑的铁锅边沿。锅不小，比寻常家用的大两圈，锅身乌黑，虽然锈了，但拿手一磨，底色森然发亮。

苏荷蹲在井底，看着那口铁锅，长久地没有说话。风从井口灌下来，吹得她后颈发凉。她伸手摸了摸锅沿内侧，指腹触到一排凹凸不平的刻痕，一个字一个字地摸过去，像在读一封迟到了很多年的信。

锅底刻的是一行小字：“荷花开了，锅就到了。丫头，好好用。”

她把额头靠在铁锅边上，闭了一下眼。然后她把锅抱起来，仰头冲井口喊：“长山，拉我上去！”

铁锅沉得坠手。但苏荷抱着它，觉得这辈子从没那么踏实过。

那口董家锅坊的老锅，终于到了她手上。她不知道师父这辈子还活着没有，但锅在，信在，那半朵荷花刻的承诺也在。她低下头，又看了一眼锅底的那行字，心里暗暗说了一个字——好。

她要好好用这口锅，做一辈子饭。

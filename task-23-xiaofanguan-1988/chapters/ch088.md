# 第88章 账本烫手

夜里的苏记小馆，灯只开了灶间一盏。苏荷把那本灰皮账册摊在桌上，牛皮纸信封压在旁边，两样东西在昏黄灯泡下像两块烧红的铁。

“你打算怎么办？”顾长山坐在对面，手里捏着一根没点的烟，转来转去。

苏荷没答，先问：“王主任知道这账册在谁手上吗？”

“盐仓的门锁没坏，地道入口也复原了。只要那俩派出所的人没往深处搜——”顾长山顿了一下，“但今天是没搜到，明天呢？后天呢？盐仓丢了，他第一个想到的就是这账本。”

苏荷冷笑一声：“他想到也没用。账本上写的是他收盐袋，不是他丢盐仓。他敢报官说账本被偷了？那不自己把脑袋往铡刀下送？”

顾长山把烟放下，目光沉沉：“那他就会来找你。不是明着来，是暗着来。刘三这种角色只是跑腿的，王主任在省城经营这些年，手底下什么人没有。”

苏荷当然明白。她前世在后厨混了二十年，见过太多后厨里的肮脏手段——下药、举报、砸店、断货。王主任这种人，跟那些使绊子的供应商一个路数，只不过手里多了一点权。

“明天一早，”苏荷斟酌着说，“你把账本和信封各抄一份，原件留下一份，抄件分两个地方藏。就算他真来翻，翻到的也是假的。”

顾长山抬眼：“原件放哪？”

苏荷的目光落在灶台角落那口铁锅上。这口锅从青江带到省城，锅底积了厚厚一层油垢，没人会去动一口天天炒菜的锅。她走过去，把锅提起来，锅底朝上——油垢下面居然有一块铁皮是活的，撬开，是个巴掌大的暗格。

“老赵头盘给我的时候，这锅就带夹层。他说是当年逃难藏金条用的。”苏荷把账册和信各取一份折好放进去，铁皮按回，油垢一盖，看不出任何痕迹。

顾长山看着她做完这一切，忽然问：“老赵头是谁？”

“上一任盘铺子的人，早走了。”苏荷拍了拍手上的灰，把锅放回灶上，“你明天把抄件送到两个地方——一个放城东邮局寄存柜，一个交给你信得过的战友。别跟我说你在这城里有战友。”

顾长山嘴角动了动，没反驳。他当了八年兵，转业分到青江市街道办，省城确实有当年一个连队的兄弟，在城南派出所当副所长。但这个关系他本来不想动，怕把战友卷进来。

“我明天下午就去。”他说。

“别下午，天擦黑再去。”苏荷把账册原本收进围裙里，“上午我得去一趟粮站，把后半个月的粮油订了。王主任要是派人来打店里的主意，店里不能没人。”

两人刚商议定，后门忽然响起三声轻叩——两快一慢。

顾长山倏地站起，手摸向腰间——那里别着一把折叠刀。苏荷按住他手腕，自己走到门边，低声问：“谁？”

“苏老板，是我，周平的媳妇翠兰。”

声音又急又哑，带着哭腔。

苏荷拉开门，门外站着一个二十出头的女人，短发凌乱，眼眶通红，手里攥着一块手帕，手指头绞得发白。她是何记饭馆周平的妻子。上次周平为了替苏荷挡麻烦被人带走，至今没放出来。

翠兰一见苏荷就噗通跪下，抱住她小腿：“苏老板，求求你救救周平——他们把他转到城北看守所去了，说是要判经济罪，三年起步！”

苏荷弯腰扶她，手心碰到的全是冷汗。她抬头看了顾长山一眼，两人的眼神撞在一起，都读出了同一个意思——

账册还没交上去，对方已经开始下手了。何记身后的人，果然就是王主任。而周平，是那条线里唯一开了口的活口。

“翠兰姐，你先起来。”苏荷声音放稳，“他们让不让人探视？”

翠兰拼命摇头：“不让。我打听了，说是要等‘案子办结’。周平他有胃病，在看守所吃了三天粗粮，吐了两回血……”她说着说着，手帕捂着脸，肩膀一抽一抽。

苏荷心里翻了一阵。周平是去年她从青江带过来的第一个伙计，忠厚老实，在何记当采购时发现了账目上的窟窿才被人盯上。他出事，多少是替苏荷挡的刀。她不能看着他在里面把命搭上。

“你今晚先回去，别打草惊蛇。”苏荷把翠兰送出门，“明天我去城北看守所一趟，想尽办法见周平一面。”

翠兰走后，顾长山把门闩上，回到灶间，压低声音：“看守所那边，不是咱们能塞进去话的地方。”

苏荷把账册从围裙里取出来，放回铁锅暗格里，啪一声关上：“塞不进话，那就塞文件。”

“你什么意思？”

“明天我不去粮站了。去城北，直接找看守所所长——不是走关系，是送去一个立功的机会。”

她转过身，眼神亮得吓人：“只要周平在里面把何记的账目往王主任身上咬实了，他跟我就都活了。账册是死的，人嘴才是活的。王主任想灭口，咱们就先让他的人把嘴张开。”

顾长山沉默片刻，终于点了点头，又低声问：“那粮站那边……”

“让苏桃去。”苏荷拿起抹布擦了擦手，“这丫头也该学着办事了。”

# 第79章 城隍庙会面

三天时间，苏荷过得比打仗还紧。

她白天照常开张卖红油抄手，晚上关了店门就蹲在灶房里琢磨那张纸条。城隍庙她去过一次，八十年代之后基本没什么香火，只有一个看庙的老头守着一座半塌的偏殿，平时连个人影都见不着。

那人偏偏选了这么个地方见面。

顾长山本来说要陪她去，被苏荷拦了：“万一他们真冲着配方来，你在场反而打草惊蛇。我一个人去，真要出事，我有法子脱身。”

顾长山看着她，没说话，只是把自己那把随身携带的弹簧刀从腰上解下来递过去：“带在身上。”

苏荷一愣，接过来，刀柄还是热的，带着他的体温。

第三天下午，苏荷换了身干净的深蓝布褂子，头发用簪子绾得一丝不苟，腰里别着那把弹簧刀，怀里揣着那只青瓷瓶——她找老郑把那只瓶子借了出来，用棉布裹了三层，贴身放着。

城隍庙在青江老城区最西边。午后的太阳晒得石板路发烫，庙门口连个卖香烛的都没了。只有一只黄狗趴在门槛上打盹，见人进来，眼皮都没抬。

苏荷跨进偏殿，殿里昏暗，只有屋顶漏下来的几缕光打在地上。供桌上还坐着半尊泥塑的城隍爷，面目模糊，身上落了厚厚一层灰。

“来了。”

声音从殿柱子后面传来。苏荷转头，看见那个中山装老头从阴影里走出来，手里拿着一把蒲扇，慢悠悠地摇着。他身后没人，也没听见别的脚步声。

“你要的东西我带来了。”苏荷把青瓷瓶从怀里掏出来，放在供桌上，“你是什么人？”

老头没急着回答，低头看了看那只青瓷瓶，从口袋里掏出一只放大镜，对着瓶底的月牙印记细细看了半晌，才直起腰来。

“这瓶子，原是我师父的。”

“你师父？”

“五八年的时候，他在省城一家国营饭店当掌勺。那年粮食紧张，上面派人来查他的库存，结果发现他用了私藏的猪油给几个饿得发昏的工人开小灶。被人举报，饭店停了，他也被下放了。”

老头摇着蒲扇，语气平平的，像在讲一个跟自己无关的故事。

“下放之后他去了哪里？”

“不知道。我找了他二十年，托人四处打听，只知道他当年留下一个记号——凡是经他手做的东西，底部必定画一个月牙。”老头抬起眼皮，目光落在那只青瓷瓶上，“这只瓶子，是他在青江时用的调料罐。前阵子有人拿它来卖，我才循着线摸过来。”

苏荷心口一紧。她想起了老郑说过，福泰祥被查封那天，陈福的地窖里还翻出好些坛坛罐罐，其中几只罐子底上有土，像是埋了几十年的老物件。她当时没多想，现在回忆起来——那几只罐子底部，似乎也画着细小的月牙痕迹。

“你是说，那个月牙印记的人，跟福泰祥有关系？”

老头沉默了一会儿，缓缓开口：“福泰祥的铺子，以前是陈福老子开的。他老子解放前给一个广东菜厨子当过帮工。”

广东菜厨子。苏荷脑子里嗡了一声。

她前世最后一家工作的餐厅，老板是香港人，挂靠的菜系就是粤菜。而在她的记忆里，那个隐姓埋名多年、只带过三个徒弟的师父，做的正是一手地道的粤菜——而他提起过，自己年轻时在南方小城待过几年。

“你师父叫什么名字？”她压着嗓子问。

老头摇头：“他从不留名。但我知道他有个习惯——他做菜用的盐，从来都是自己亲手晒的粗盐，绝不用外头买的细盐。”

粗盐，自己晒。苏荷心跳得更快。前世的师父手上有一道伤疤，从虎口一直延伸到食指根部，他说是年轻时晒盐被竹刀割的。

庙檐下一只麻雀扑棱棱飞过，震落了几粒灰。

苏荷深吸一口气，把那只青瓷瓶拿起来，在手里转了转，瓶底朝上：“你说的师父，是不是左撇子，炒菜时锅不离手，切姜丝用的是细口刀，而且——右手虎口到食指根部有一道很长的疤？”

老头手里的蒲扇停了。昏暗的殿里，他盯着苏荷看了很久，目光里烧起一团火。

“你怎么知道？”

苏荷没答，握紧了怀里的弹簧刀，心里推演着下一句该怎么说。殿外忽然传来一阵脚步声——不是一个人，是好几个人，脚步又急又乱。

老头脸色一变，一步跨到供桌旁，将青瓷瓶揣进怀里。殿门被人一把推开，白衬衫的男人站在门口，身后跟着四个穿着同样白衬衫的壮汉，腰间鼓鼓囊囊的。

“周老板，”那男人开口，声音冷得像刨冰，“你还真的来赴约了。上面的意思，这只瓶子——和这个人，都带回去。”

老头把苏荷往身后一挡，蒲扇换到了左手，右手探进中山装内兜。苏荷的目光越过他的肩头，看见白衬衫男人的腰间，别着一个黑皮的证件夹——那种夹子她前世见过，是某种特殊部门的人用的。

她喉头一紧。这事怕是真的要从一桩毒盐案，捅到天上了。

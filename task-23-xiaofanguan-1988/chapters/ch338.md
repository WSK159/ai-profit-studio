# 第338章 夜入老宅

青江的夜色像一锅烧开又晾凉的水，闷在头顶。苏荷把油布包裹塞进怀里，对钟大川说：“郑家老宅，今晚就去。”

钟大川擦掉脸上的井泥，目光沉沉：“郑家自周明善死后就搬空了，如今是供销社的仓库。正门落锁，侧墙有缺口，我白天踩过点。”

顾长山背靠老槐树，从兜里摸出一把手电筒：“午夜动手。我望风。”

“你身上还带着伤。”苏荷看了眼顾长山裹着纱布的胳膊。

“不碍事。”他拧开手电又扣上，灯光一闪而过。

子时刚过，三条人影绕过西城门，贴着城墙根摸向郑家老宅。老宅是解放前的富户院子，青砖黛瓦，门楣上还残留着半截“郑”字石刻。顾长山在侧墙缺口处蹲下，双手交叉垫在膝上，苏荷踩上去，翻身上墙。

院子里长满半人高的荒草，月光照出一片惨白。灶房在偏院西角，土坯墙体裂开指宽的缝。苏荷推门，门轴发出刺耳的吱呀。

灶台是青石垒的，积灰足有一寸厚。苏荷蹲下来，用手电照着灶台底部，青石之间嵌着黑色泥灰，她摸了一遍，没有松动迹象。

“钟大川，你师父有没有提过，骨片是怎么藏进灶台下的？”

钟大川站在门口，答：“信里说‘青石缝中，以油纸裹’，周师叔的绝笔信是他临死前写的，应当没错。”

苏荷皱眉，指尖敲了敲青石，声音不对——灶台最底下一层石砖，敲出闷闷的空响。

她从袖口抽出一把剪刀，沿着砖缝刮开泥灰。灰壳剥落，露出一块约莫巴掌大的青砖，边缘光滑得不像旧物。苏荷用刀尖撬起，砖下是一个橄榄形的凹槽，里面塞着一卷油纸。

她伸手取出，油纸在指间碎裂，露出里面半截泛红的骨片，边缘带着烧灼的焦痕，与钟大川井底挖出的一半恰恰吻合。

苏荷屏住呼吸，正要掏出怀中那半块比对——

“嘿，瓜女子，大半夜偷东西呢？”

一个声音从头顶传来。

所有人瞬间僵住。顾长山手电光猛地扫向房梁。

梁上坐着一个老头，瘦得像根枯柴，正翘着二郎腿嗑瓜子。正是白天在供销社外递井图的灰布衫老头。

苏荷先前判断他无恶意，但这会儿心跳还是漏了半拍：“你从什么时候就在这儿的？”

“后晌就在了，”老头跳下梁，落地无声，“你爷爷周明善当年藏东西的时候，我就在旁边递的石灰。”

“您到底是……”

老头拍了拍布衫上的灰，眯起眼：“我叫何九斤，周明善的旧部，当年在他灶上烧了十六年的火。他出事那天把我支走，我回来时老宅已经烧了半边，只从火里扒出这半块骨片。”他指了指苏荷手中的油纸，“那半块的藏处，也是他烧成灰前最后交代的话。”

苏荷垂眼，摊开油纸，把怀中钟大川井底取出的半块骨片与手中这半枚拼在一起。

骨片严丝合缝，拼成一块拇指盖大的、烙着暗纹的骨头，断裂处焦黑如墨。

何九斤凑近看了一眼，忽然脸皮一紧：“这骨片上的纹路……你们马上跟我走。”

“怎么了？”

“当年害周明善的主使，也在找这两块骨头。要是让他撞上，你们三条命都不够填。”何九斤一把夺过骨片塞进自己怀里，推着苏荷从后门出了灶房。

月光里，老宅外的巷口，忽然传来几声脚步。

脚步声不算急，但整齐得不正常，不像醉汉路过。顾长山一把拽住苏荷的手腕，低声说：“别出声。”

四个人贴着墙根蹲进荒草丛里。

脚步声越来越近，从巷口走过，停在郑家老宅门口。火把的光从门缝漏进来，有人压着嗓子说话：“老宅几年没人进了，那东西会不会早被耗子啃了？”

“明善死前把骨头分了两半，一半埋在西城井底他师兄身上，一半藏在这里。他师兄被灌哑药活砌井壁，那骨头跟他一起烂了十六年，如今有人挖了井——消息已经传出去了，咱们得抢在前面。”那声音顿了顿，“进去搜。”

苏荷的指尖陷进掌心里。何九斤无声地朝她打个手势：走。

四人沿着墙根爬了三十来丈，从侧墙缺口翻出，钻进对面一条窄巷，直到火把的光完全消失在身后，才停下。

苏荷靠墙喘匀气，回过身看何九斤：“您那半块骨片，能还我了吗？”

何九斤从怀里摸出还在发烫的骨片，却没有递给她，只拢在掌心里掂了掂，语气忽然低沉下来：“骨片有两半，合在一起才能解开你爷爷留下的东西。可这第三重保护者的身份，我还没验完——你且告诉我，你爷爷周明善临终前，除了让你来找王全福，还留了一句话吗？”

苏荷一愣。她脑海中浮现出那封绝笔信末尾的一行字，那行字写得极小，像是用指甲刻上去的：“灶台之下，骨与血俱存。”

何九斤听完，沉默良久，把骨片放进苏荷掌心：“是了。你没忘。那这半块骨片，物归原主。”

骨片落进苏荷掌心的那刻，她隐隐觉得，有什么比两片骨头更重要的事，正在这夜色里悄悄发生。

“何叔，”苏荷收好骨片，沉声问，“井底的信上，还留了一句话——‘你若见了何九斤，替我问一句，玄铁刀可还在他手里？’”

何九斤身形猛地一颤，抬起头时，眼角的皱纹像折扇一样展开：“他连这个都记得？”

他颤着手从布衫内衬里摸出一把巴掌长、乌沉沉的无柄短刀，刀身没有一丝反光，只在脊背处刻着一个模糊的“周”字。

“这是周明善用过的炒勺，跟了他三十年。”他声音发哑，“他托我保管，说是要传给对得起这把勺的人。”

月光落下来，苏荷盯着那把刀背上的“周”字，呼吸忽然急促。

这把刀的形制，她认得——她前世学艺时，师父的供桌上，就供着这样一把乌铁无柄短刀。

她前世师父一直说，他毕生厨艺，是从一把玄铁刀上悟出来的。而刀的主人，叫周明善。

苏荷两世记忆在这一刻重重叠叠，她指尖发抖，接过那把刀，刀的重量沉甸甸地坠进掌纹里。

何九斤看她半晌，忽然笑了：“看来这刀，等的就是你了。”

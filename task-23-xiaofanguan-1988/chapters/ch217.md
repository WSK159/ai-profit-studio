# 第217章 泼漆之人

红漆泼在苏记小馆的招牌上，顺着木板往下淌，在雨中冲出一道道暗红色的血痕。那三个黄漆大字——“奸商”——写得歪歪扭扭，却足够醒目，在整条巷子都刺眼。

围了一圈人，有的举着伞看热闹，有的帮忙拿水桶想冲一冲，被苏荷拦住了。

“都别动。”她声音不高，但压得住场子，“泼漆的人还在漆里留了东西。”

众人一愣。苏荷蹲下去，从红漆流到门槛边缘的痕迹里，挑出一根细细的黑色塑料丝——是一截编织袋的纤维。

“这漆不是用刷子泼的，是灌在编织袋里甩上去的。”她直起身，目光扫过围观人群，“手法太密，像干过活的老手。梁国庆找的人，故意干得粗糙，因为越粗糙越像是被我欺负的‘老实人’干的，才有人信。”

有人小声嘀咕：“苏老板，你是不是得罪什么人了？”

苏荷没答。她推开铺子门，从灶台下取出一只搪瓷盆，接满水，从灶台边的调料架上取了几样东西——碱面、醋、一撮粗盐——兑进水里，搅匀，端出来一条一条地泼在门板上。

红漆碰到那盆水，颜色开始发灰、发碎，卷着边脱落下来，露出原本的木色。门板上的“苏记小馆”四个字被红漆浸泡过，总算勉强保住了轮廓。

人群里有人“嚯”了一声。

苏荷把空盆放回门槛上，拍了拍手上的水渍：“都散了吧，明天照常营业。”

众人散去后，苏桃拉着她的袖子，声音压得极低：“姐，账本的事，我还没来得及细说。刘三发那本账后面缺的那几页，我在梁国庆办公室见过——是一张油票，撕得很整齐。”

苏荷猛地转头：“油票？什么油票？”

“粮油统购指标的调拨单。1986年的，下面有油脂厂厂长孙德海的私人章。梁国庆拿来贴在他的账本后面，可能是为了抵账。”苏桃从口袋里掏出一张皱巴巴的纸条，“我只来得及记下编号和白单上那些字。”

苏荷接过纸条，上面的字迹潦草，但清清楚楚抄着一串编号和一个名字——“青粮统字86071号，孙德海”。

她的眼皮跳了跳。如果这张油票是真的，那意味着青江油脂厂内部的“泔水油”销售，不只是梁国庆一个人在搞——他把厂里的领导也拉下了水。而刘三发的账本后半本，从来就不是被“偷”走的，是梁国庆不敢让人看见的东西。

“苏荷同志。”

一个声音从巷口传来。众人都散了以后，雨里还站着一个没走的人——赵铁柱，穿着件半旧的军绿色雨衣，帽檐压低，露出半张方脸。他走近两步，声音沉得像闷雷：“顾长山让我给你带句话。省城那边的事办妥了，但他查到另一件事。”

“梁国庆不单是倒卖泔水油。他还在这片收了几家铺子的‘合作费’，用的是城南街道‘联营’的名义，上面盖的章，是前年已经被撤销的‘青江市第二商业局’。”

苏荷握纸条的手一紧。

赵铁柱顿了顿，目光落在她手里：“你要动他，就得把他身后的账一起翻出来。顾长山说，让你今晚别急着报官——明天早上，他会带一个人来城南巷。那个人手里，有梁国庆和孙德海之间三年的对账单。”

雨珠顺着苏荷的发梢滴落，她喉咙微微滚动，把那纸条折好，收进贴身口袋，轻声道：“好。”

赵铁柱转身没入雨幕。苏荷站在门廊下，看着那块被红漆泡过的招牌，上面“苏记”两个字沾着残留的红色，像是伤口结痂后的一道痕。她忽然想起前世在米其林后厨第一次当主厨的那个晚上——她写下的第一句后厨守则只有六个字：

“菜不会说话，人会。”

那一刻她知道，明早不只是顾长山要来人，梁国庆一定也会来。泼漆只是开场，真正硬碰硬的时候，到了。

# 第177章 刀疤脸入局

苏荷瞪着周福安，后背贴着墙壁，心念电转。这人在她和何承业谈事时就跟上了？还是早就盯上了她？

“你跟着我干什么？”

周福安耸肩，慢悠悠从兜里掏出一截烟卷，也不点上，夹在指间转了两圈：“我睡码头仓库的，今晚值夜，看见一个穿军装的细脖子后生溜进来，觉得眼生，就多看两眼。没想到——嘿，是你。”

苏荷没接话，脑子飞快盘算。周福安在城南巷守了好几天，一直阴魂不散，她让顾长山查过，可这人背景干净得很，除了住在码头附近一个亲戚家里，平时就是下象棋、喝茶、遛弯，看不出半点意图。今晚在这儿撞上，究竟是巧合还是早有预谋？

“你到底想干什么？”她直截了当问。

周福安把那截烟卷重新揣回兜里：“想跟你谈笔生意。”

苏荷冷笑：“什么生意？”

周福安走近两步，压低声音：“你今晚摸何承业的底子，是想截他明晚那批货吧？我告诉你，何承业这条路上有派出所的线人，你一个人吃不下。”

苏荷心中一动，面上却不露色：“你怎么知道我想干什么？”

周福安咧嘴一笑，露出缺了半颗的门牙：“我在码头干了八年，谁进的货、哪条船上的、货往哪儿去，我心里有本账。李兆阳那批橡胶管我盯了半个月了，他干这种事不是头一回，但每次都能走脱，你知道为什么吗？”

“因为他上头有人？”

“不止。”周福安竖起一根手指，“何承业在码头派出所收了个线人，一有风吹草动，那边先给他递话。你今晚找上门，明晚九点才交货，中间整整一天，时间够他查证了。”

苏荷的心沉了一下。何承业刚才那一下拍肩，恐怕已经开始起疑了。她正要开口，周福安又补了一句：“你别慌，那线人我认得，明晚我有办法把他支开。但这买卖得算我一份。”

苏荷盯着他，半晌没说话。周福安也不催，就那么靠在电线杆上，一副随你考虑的样子。

“你要什么？”她终于开口。

“何承业库房里有一批干虾皮，两吨，是他压了半年的旧货，本来要走南边的路子，结果被查了批文，烂在手里。我听说你认识省城几个供销社的人——那批虾皮，你能吃下，分我两成现钱。”

苏荷思忖片刻。供销社的路子她确实有——上个月给如意楼供了一次雪羹，唐大师引荐了一位主任给她。两吨干虾皮如果品质没问题，转手确实能赚一笔。

“成交。”她点头，“但我不要两成现钱，我要你以后替我办事。”

周福安挑了挑眉：“办什么事？”

“到时候你就知道了。”

周福安沉默两秒，咧嘴一笑：“行，反正我也没啥别的本事，力气活是干惯了。”

他伸手，苏荷也伸手，两人在路灯下握了一下。


第二天一早，苏荷在店里灶台前忙活，心不在焉地颠着锅。顾长山把雪羹送去如意楼后回来，进门第一句话就问：“码头那边怎么样？”

苏荷把昨晚的事三言两语说了，最后道：“今晚九点，货棚西边。周福安会去支开线人，我装成何承业那边的人，等李兆阳露面。”

“你不能去。”顾长山把军装外套往桌上一放，语气不容商量，“昨晚你已经露了脸，今晚再去就是赌命。”

“我没打算正面去。”苏荷把火关了，擦擦手，“我已经让周福安替我传话，就说刘主任那边安排人来接货。何承业以为来的是省城的人，不会防备。李兆阳露面之后，我再让周福安动手。”

“动手？他怎么动？”

苏荷勾了勾嘴角：“码头装卸工里有个跟李兆阳有仇的，打了三年官司没打赢。周福安说他能把人喊来——不用碰货，只要报警说李兆阳偷了他们的工钱，警察一到，那批货就是活扣。”

顾长山皱眉看着她，好一会儿才说：“你想借刀杀人。”

苏荷点头：“我手里没刀，就只能借。”

她低头看了看锅里还剩的半碗红油，油光映着脸，眼底是沉的。

今晚的事要是成了，苏记不仅能拿到第一笔大宗的进货渠道，还能把人脉从城南巷伸进码头。可要是败了……

她没往下想。

门帘忽然被掀开，苏桃探进来半个脑袋：“姐，外头有人找你——说是从省城来的。”

苏荷和顾长山同时对视一眼。

省城来的人？

苏荷放下锅铲，掀开门帘走到前面堂屋，只见一个穿灰呢大衣的中年男人站在柜台前，正低头看着墙上挂着的那幅她手书的“苏记”招牌。听到脚步声，他转过身来。

“苏老板？”男人笑了笑，递过来一张名片，“省城军区后勤部，刘洪发。”

苏荷脸上的笑僵了半瞬，随即自然地接过来，低头看了一眼。

刘洪发。

她昨晚用来冒险编造的那个人，竟然真的出现了。

# 第129章 沈家旧事

苏荷心里动了一下，面上却纹丝不动：“我爷爷的书房里确实有几本旧书是沈家那边赠的。你问这个做什么？”

那人左右看了一眼，自己拉椅子坐下，声音压得更低：“我叫赵小柏，省城文化馆的，我师父姓沈——沈其昌。他这趟让我来青江办点事，顺便给你带句话。”

苏荷眼梢微挑：“什么话？”

赵小柏从怀里掏出一个牛皮纸信封，左右手捏着，没有立刻递过来：“师父说，那九把刀的事，让你先别声张。赵一鸣的手艺，当年只传了两个人，一个是我师爷，一个是你爷爷——外人不知道这套刀到底是怎么流出来的。于德水那边，八成是在替别人探路，你越亮底牌，对方越知道从哪里下手。”

他说完，这才把信封放在桌上，推过来。

苏荷没急着接，先问：“你师父怎么知道于德水的事？”

赵小柏摇头：“师父在省城听到风声了。你爷爷那套老宅，动心的人不止一个。但他让我转告你一句话——老宅的物证能丢，人证丢不了。城南巷槐树底下，当年埋了东西。”

苏荷目光一凝。城南巷的槐树——就在苏记小馆后墙外，那棵两人合抱粗的老槐，她小时候还爬过。但槐树底下有什么，她从没听爷爷提过。

“埋了什么？”

赵小柏站起来：“师父没说。他只说，你挖出来自然就知道是谁的东西。另外——你妹妹苏桃在城南一中念书是不是？”

苏荷心口一紧，眉头拧起来：“你什么意思？”

“别紧张。”赵小柏摆手，“我路过学校门口，看见你妹妹跟一个骑凤凰自行车的中年男人说话，那男的给了她一个信封。我多看了一眼，那自行车后座夹着省城牌照的漆皮。”他顿了顿，“苏老板，你自己当心。”

他说完转身就走，门在身后轻轻合拢。苏荷坐在椅子里，手指慢慢收拢，将那只牛皮纸信封捏在掌心。里面不厚，像是几张纸。

她撕开封口，抽出里面的东西——一张泛黄的收据，盖着青江市第五木器社的章，落款是一九六三年。项目栏写着：樟木箱，命三。经手人——赵一鸣。

苏荷的呼吸顿住了。赵小柏的脚步声已经从走廊尽头消失。她把收据折好贴身收起来，起身推门，迎面撞上一个矮胖男人，手里拿着一个文件夹，发际线已经退到天灵盖，笑容挤成一团褶子：“苏老板留步！我是于处长手下的，他有事回省里了，让我把这封信交给您。”

苏荷接过那封信，没当场打开，只点了点头：“劳烦。”

矮胖男人哈腰走了。苏荷站在工商局的台阶上，午后的阳光晒得她后颈发热，袖口里的收据像一块薄薄的铁片贴着皮肤。

她拆开那封信。一张信纸，只有一行钢笔字，墨色浓重——

“苏老板，槐树下的东西，我替你保管了。三日内，带契书来城南茶楼换。”

落款：于。

苏荷把信纸慢慢叠好，塞回信封。她抬头望了一眼远处的城南巷方向，嘴角绷成一条线。槐树底下的东西，对方已经先一步挖走了。可对方不知道的是——她根本不需要挖出来。她从小在城南巷长大，现在她还记得，爷爷每年清明，都要跪在那棵槐树底下，烧三炷香。

那树下埋的不是物。是人。

她快步走向公交站，脑子里已经转过三个念头：一是顾长山的转业费能不能撑住接下来这半个月的周转；二是沈其昌那边，赵小柏传话的方式太迂回，可能是在试探她知不知道什么内情；三是——她必须尽快打开第三口樟木箱。

那里面放的，可能就是能让于德水把东西吐出来的东西。

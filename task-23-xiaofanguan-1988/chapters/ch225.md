# 第225章 一张旧单子

梁国庆被铐上手铐的时候还在喊：“你们哪个分局的？我认识王所——”

“王所调走了。”一个穿警服的中年人从警车后面出来，雨水顺着警帽檐滴下来，声音很平，“你认识的那个王所，上个月就因为粮票案子进去了。”

梁国庆脸上的血迹被雨水冲淡，他看着苏荷撑着一把破伞慢慢走过来，雨衣下露出半截红色围裙，像一簇烧在雨里的火苗。他嘴唇动了动，挤出个笑：“苏老板，你赢了，我没话说。但你也别得意，你那小饭馆——”

“梁总。”苏荷打断他，声音不高不低，“你那食品厂的账，我刚才让人送到税务局去了。”她顿了顿，伸手从围裙口袋掏出一张叠得整整齐齐的旧单子，在梁国庆眼前晃了一下，“包括去年八月你从城东粮站开出的那三十张空白提货单。”

梁国庆的笑容僵住了。

那单子他从没外传过，是去年秋天他让周会计悄悄从粮站偷出来填了粮票用，准备和临县的黑市粮贩子做一笔大买卖。他不知道苏荷是怎么拿到的——但纸面上自己的签字和厂里的红章清清楚楚，他心底最后一个硬撑的底气，像被人抽走了一样。

警察把梁国庆押进警车，车开走时尾灯在雨里拖成两线红光。顾长山走过来，看着苏荷手里那张单子：“这东西你哪来的？”

“周会计给的。”苏荷把单子叠好收进口袋，“她一直留着，等这一天。”

顾长山沉默了一会儿：“周会计人呢？”

“赵铁柱送去客运站了，十六块钱的车票，去她妹妹家。”苏荷吸了吸鼻子，雨已经小了，青江的夜色从雨幕后面透出来，路灯一盏盏亮得像珠子，“她家里还有八十岁的老娘要养，这案子——就让她当个证人，别让她卷进去。”

顾长山看了她半晌，忽然笑了。

“苏荷，你这个人，”他抬手抹了一把脸上的雨水，“心狠的时候比谁都狠，心软的时候……”

“我心硬。”苏荷打断他，扭头往三轮车走去，“明天还得开张，灶台上那一锅骨头汤，怕是要熬过了头。”

他们走回城南巷时雨已经停了，巷口的路灯底下蹲着一个人影。苏桃抱着膝盖坐在苏记小馆的门槛上，见他们回来，蹭地站起来，围裙口袋里鼓鼓囊囊的剪刀柄顶出一小块。她看看苏荷，又看看顾长山，张了张嘴：“姐……”

“没事。”苏荷拍了拍她肩膀，绕过她推开门，厨房里那锅骨头汤果然还在咕嘟咕嘟冒着香气，乳白的汤面上浮着油亮的枸杞和红枣。她伸手尝了一勺，回头冲苏桃笑了笑：“咸淡正好，明天早上卖原汤抄手，还能加卤蛋。”

苏桃眼眶红红的，一把抱住了她的腰。

顾长山站在门口，看着姐妹俩的背影，没进去。他掏出那盘录音带，在掌心掂了掂，转身朝街道办的方向走了几步，又停下来，回头喊了一声：“苏荷——”

“嗯？”

“梁国庆那案子，城南分局的人明天会找你录口供。”他说，“我在。”顿了顿，“周日，我带你去河边走走。”

苏荷愣了一下，然后笑了，那笑容在油烟和灯光里暖得像灶膛里明黄的火焰：“行啊，顾大哥说了算。”

门外夜色宁寂，老城在雨后的风里慢慢亮起来。

# 第123章 巷口的老茶摊

青江十二月的清晨冷得刺骨，巷口的石缝里还结着薄霜。城南巷还没醒透，只有两个早起倒夜壶的老太太缩着脖子走回自家门洞。苏荷系紧蓝布围裙，把面案上的白布揭开，案板上头一夜饧好的面团已经涨到两倍大。她回头看了一眼墙角那口铁锅——那是她从家里带出来的，锅沿磕了一个豁口，她用砂纸磨平了，又拿猪皮反复擦了几十遍，黑得发亮。

“姐，今天做啥？”苏桃从里间探出半个脑袋，手里攥着昨夜的账本，睡眼惺忪。

“红油抄手、吊汤面，再加一笼肉包子。”苏荷把面剂子分好，“今儿有场硬仗，别分心。”

苏桃眨眨眼，没多问，端着脸盆去灶间打水。

苏荷手里的擀面杖横在案板上，轻轻转了一圈。昨夜那人的声音她记了一宿——“我在巷口摆个摊，等你三天。”她原以为是个糟老头子，可那嗓子的底气足、咬字清，横竖不像七十多岁的人。

天光放亮，巷口渐渐热闹起来。苏荷的摊子支好，红汤锅往炉上一坐，香气立刻顺着巷口窜出去。老客们陆续坐下，有穿中山装的国营厂会计，有拎着铝饭盒去买菜的婶子，还有两个刚下夜班的工人。苏荷手脚麻利，三碗抄手下锅，转头去捞肥肠时，余光扫见巷口那棵梧桐树底下多了一个矮凳。

矮凳上坐着一个老头，戴旧毡帽，穿灰布棉袄，膝盖上搁着一个搪瓷缸子。他面前没摆东西，就那么坐着，远远看着苏荷的摊子。苏荷端抄手上桌时，心跳快了两拍——那老头看她的眼神，带着一种很淡的、像是在辨认什么旧物件的神情。

“老板娘，”会计敲敲碗沿，“再来二两。”

“哎。”苏荷应着，转身取面。再回头时，老头已经站起来，慢悠悠走到摊子前。他没看菜单，只盯着苏荷案板上那排码得齐整的猪肉大葱包子，忽然开口：“你这包子，用的是前腿肉？”

苏荷手一顿。她用的是前腿肉——早上五点去南门肉档挑的，三分肥七分瘦，斩成石榴籽大小。但她在案板上埋了姜水，肉馅里的调味是秘方，这老头一眼就看穿了七成。

“您是行家。”苏荷没否认，手脚不停。

老头把搪瓷缸子往桌上一放，里头竟泡着一把干荷叶。“老苏做包子，也是前腿肉，斩三遍，不剁碎。你这刀工——”他低头看了看案板上的肉馅，“过得去。”

苏荷掌勺的手没停，心却沉下去。老苏——说的是爷爷。

她舀了一碗吊汤面，端着放在老头面前。“请您吃碗面。”她声音不高不低，“吃了面，咱们再说话。”

老头看着那碗面——汤清、面白、几粒葱花浮在油星上，中间卧着半个溏心蛋。他拿起筷子，捞了一根面条送进嘴里，嚼了两口，忽然停下来，把筷子搁在碗沿上。他望着苏荷，眼角的皱纹堆得很深，声音有点哑。

“你是老苏的孙女。”

这是陈述句，不是问句。苏荷没有躲：“我是。”

老头沉默片刻，从怀里摸出一样东西，放在桌上——半张红底洒金名帖，烧焦了一角，和爷爷那半张撕口严丝合缝。苏荷瞳孔一缩，他终于开了口：“我叫沈其昌。你爷爷守的那个窖，里头那把刀，本来应该是我的。但你爷爷拿了一辈子，我服他。可现在他人没了，东西该见光了。”

他抬头直视苏荷：“我要的不是你那口箱。我要你替我做一桌菜——我做评委，你掌勺。赢了，我把名帖下半截给你，青江老灶的旧账、你爷爷欠的、我欠的，一笔勾销。输了——”

他把半张名帖收回怀里，喝了口面汤：“你就把窖里那九把刀砸了，从今往后，城南巷姓苏的，别再做菜。”

风从巷口灌进来，汤面热气腾起。苏荷手里的勺子顿在半空，耳边苏桃小声惊呼：“姐——”

苏荷盯着那碗面汤，姓沈的老人已经站起身，转身朝巷尾走去，灰棉袄背影越来越远。她知道，这顿饭她必须做，而且必须赢。做砸了，她重生回来这一口气，就得断在城南巷的晨风里。

# 第286章 坟冢之下

机关转动的声响像是老木门轴里卡了砂砾，嘎吱嘎吱地从青石板底部渗出来。苏荷手心沁汗，那枚湿铜钱已经嵌进裂缝里，指腹能感觉到石板内里传来的颤动——像是有什么东西在深处苏醒。

宋文起站在三步之外，背着月光，看不清表情：“听见了？”

苏荷没答话。她缓缓退后半步，眼睛盯着那五道名字的刻痕。周福、周明善、周三昧、岑三味、宋文起——五个人名，五个钥匙孔位，而真正的钥匙如今正贴着她的腕骨，藏在刀柄蜡线里。

青石板震动渐强，忽然“咔”的一声脆响，石板正中央裂开一道细线，随后像两扇门一样向两侧缓缓滑开，露出下方一段向下延伸的石阶。

石阶深处涌上来一股潮湿的土腥气，夹着陈年朽木的味道，还有一丝极淡的——酒糟味。

苏荷心头一凛。这味道她太熟悉了，苏家村老宅地窖里存了二十年的米酒，就是这股味。母亲每年入冬都要往酒坛里添一次料，说是祖上传下来的方子，加了桂花和当归。

“你家，和周家什么渊源？”苏荷没有急着下阶，而是转头盯住宋文起。

宋文起沉默片刻：“你母亲的娘家姓岑。”

苏荷心口猛地一沉。青石板上刻着“岑三味”——她母亲的娘家姓岑，母亲是岑三味的后人。

“钥匙换过的事，你怎么知道的？”苏荷又问。

“你母亲七年前就和我爹联系过。”宋文起的声音平得没有起伏，“那会儿你还没被卖过一回。她怕你们家守不住这东西，早就把真钥匙换走了，留在坛子底下的，是引子。”

“引什么？”

“引你找到这儿来。”宋文起指了指石阶，“你娘让你看见脚印，让你撞见疤脸男，让你半夜摸上楼——每一步，都是她安排好的。她不想让钥匙落到你爹手里，也不想到疤脸男那伙人手里。她等你回来。”

苏荷脑中轰地炸开。前几日母亲擦酒坛时露出的手腕淤青、门口那道女人的脚印、疤脸男半夜进院时母亲站在灶台前纹丝不动的背影……那些她以为是父亲留下的伤，那些她以为母亲不知道的夜半访客。

母亲知道的。从头到尾都知道。

“她怎么知道我一定会回来？”苏荷声音发涩。

“你娘说，你从小就知道坛子底下有事。”宋文起说，“十二岁那年你趁他们不在，偷偷抠开过坛底的泥，看到了钥匙壳。你娘看你不声张，就知道你会回来取。”

十二岁——苏荷仔细回想着那具身体里的记忆。隐约有某个下午，太阳落山，她蹲在灶房角落里，手指抠进坛底的湿泥，碰到了一个凉凉的东西。然后她听见脚步声，慌忙将泥抹平，再也没提过。

“为什么她不自己拿出来？”

“你娘不敢。”宋文起说，“钥匙留着，会有人来抢；毁了，岑家祖上那笔账就永远对不上。她只能等你长大，等你拿得动刀的时候，把这担子交给你。”

苏荷深吸一口气。她握着刀柄，指腹用力抵住蜡线的接口处——那枚藏在刀柄里的铜钥匙，隔着几层蜡线，硌得像一块烧红的烙铁。

“我母亲知道今晚你约我来这儿？”

“她不知道具体时间，但她知道我会约你。”宋文起顿了顿，“你娘说，若你来了，就告诉你一句话——周明善不是害你前世的人，他是在替你挡刀。”

苏荷攥刀的手猛然收紧。前世师父周明善，她重生前那场车祸，她一直以为是一场意外。可母亲的话背后另有深意——师父替她挡的，是哪一把刀？

“她在哪？”苏荷压低声音。

“你娘今晚不在家，去镇上换粮票了，明早才回来。”宋文起朝石阶迈了一步，“钥匙的事，她说她帮不了你，后面怎么开那扇地窖门，只能看你自己。”

苏荷站在坟冢洞口，夜风从背后刮过，扬起她额前碎发。石阶下方黑洞洞的，看不出尽头。她低头看了一眼掌心的湿铜钱，铜钱边缘沾着一粒极细的白沙。

明明是苏家村的坟地，怎么会有河滩的白沙？

“底下是什么？”她问。

“账册，还有真正的东西。”宋文起的声音忽然压得很低，“你下去之前，立个誓——账册归我，其余归你。”

“若我不立呢？”

宋文起的目光在月光下亮了一下：“那我只能把你锁在这石板外面。三日后再来开时，账册早就被人取了。”

苏荷看着他的眼睛，像是在辨别这句话里有多少真假。夜风呼呼地灌进洞口，那座石阶底下的黑暗像一只张大的口，正等着她迈出这一步。

她低头看了一眼腕间的刀柄，蜡线微微松散，铜钥匙的轮廓若隐若现。她想起顾长山把这把刀塞进她手里时说的那句话——他说：“这刀跟了我七年，能开锁也能防身。”

那时候她以为他是说刀能撬铁锁。

现在她明白了。

“下去吧。”苏荷说。

宋文起点了点头，率先跨上石阶。他身形一晃没入黑暗，苏荷紧随其后，脚步踩在石阶上“嗒嗒”作响。台阶一共二十三级，尽头是一扇木门，门上挂着一把半新不旧的铜锁。

苏荷摸出刀柄里藏着的铜钥匙，插入锁孔。

“咔嗒。”

锁开了。

她推门进去，门后的空气扑面而来——那是一股混合着尘土、旧纸、铁锈与干桂花的复杂气味，像是把一座几十年的老宅子全都塞进了这间地窖。

墙角堆着三口青瓷大缸，缸盖封着，上面落了厚厚一层灰。一张旧木桌上摊着一册账本，封皮泛黄卷边，正中用墨笔写着一个字——周。

苏荷的手指刚触到账本封皮，身后的宋文起忽然开口，声音里多了一丝她听不出的意味：

“你猜——你母亲换走真钥匙的时候，是谁告诉她，钥匙在坛子底下的？”

苏荷的手停在半空中。

她回头，看见宋文起站在门口，手电光照在他脸上，半明半暗。他没有笑，但那双眼睛里有一丝说不清道不明的光——像是在等一个答案，又像是在等她发现什么。而那扇门，在他背后悄无声息地合上了。

# 第411章 灶台外头

苇丛深处有座破败的砖房，半截墙塌了，露出黑洞洞的窗户。马老三推开门，门轴发出一声难听的呻吟，一股铁锈与煤灰的气味扑面而来。

屋里很暗，马老三点燃一盏油灯，灯焰跳了跳，映出墙角一只半人高的铁砧和一张熏黑的案板。正对着门的墙壁上，挂着一幅旧灶台的炭笔画——画里是土灶、铁锅、案板、水缸，每一处都画得极仔细，连灶口里的火苗都一笔一划地描了出来。

苏荷盯着那幅画看了一阵，忽然觉得哪里不对。灶台上方的房梁上，悬着一根细绳，绳尾绑着一枚小铜铃。她记得师父在城里的老灶台上也挂着这么一只铜铃，说是“灶王爷的耳朵”，开锅的时候要摇一摇，提醒灶王爷火候到了。

但那枚铜铃是空心的，里面塞着东西。

“师父让你来看这幅画？”苏荷问。

马老三站在案板边，没有答话。他弯腰从案板底下拖出一只铁皮箱，打开箱盖，里面是一整套铜壶、铜勺、铜铲，全都是老式的，做工精细，最底下压着一本薄薄的册子。

他把册子递给苏荷。封皮泛黄，没有书名，翻开第一页，苏荷的瞳孔骤然收缩——

上面画着一只碗，碗里盛着汤，汤面上浮着几片翠绿的叶子。画旁有一行小字，是师父的字迹：“荷叶汤不是荷叶汤，是荷姑娘的荷。”

再翻一页，画着一把钥匙，下面写着：“锈的不是锁，是人心。”

苏荷手指微颤，一页一页翻过去。整本册子只有七页，七幅画，七句话。每一句话都像是谜语，又每一句都直指她与师父之间的旧事——她前世叫“荷”，师父给她取这个名字时说过一句话：“荷叶底下的水，看着浅，其实深得很。”

最后一页画着一个铜钱，旁边写着：“铜钱眼里的路，窄过针尖，亮过灯。”

苏荷捏紧脖子上的铜钱，忽然明白了什么。她抬眼看向马老三：“师父要我来这里，不是让你告诉我‘那味料在哪儿’，对不对？”

马老三嘴角牵动了一下，露出一个难看的笑：“老疯子走前叮嘱我一句话——‘如果那丫头能猜到画里的意思，你就把箱子给她；如果猜不到，你就原样把箱子烧了。’”

“你猜到了，所以箱子是你的了。”

苏荷低头盯着那本册子，深吸一口气，又问：“那封信呢？”

马老三的嘴唇翕动了一下：“信在，但不是我给你，是你自己去找。”

他朝那幅灶台画努了努嘴：“画里画的，是青江西关镇‘郭家祠堂’的老灶台。那地方荒了十多年，没人去。你师父那年把信砌进了灶膛里，就在画上那口大铁锅正下方的砖缝里——他说那是‘灶台外头’最安全的地方，因为没人会把东西藏在灶膛里，火烧起来就没了。”

苏荷又看了一遍那幅画。果然，铁锅正下方的砖缝里，有一个极不起眼的豁口，若不是知道在哪里，根本不会注意。

“找信之前——”马老三打量了苏荷一眼，又看了一旁的顾长山，“你师父让我转告你另一句话：那封信拿出来之后，不要看，直接烧掉。”

苏荷一愣：“为什么？”

“因为那封信一旦见光，写信的人就会知道，他曾今做过的事，被人翻出来了。老疯子说，他这辈子欠了那人一条命，这封信在灶膛里锁了三十年，就是让那把火替他还了那笔债。”马老三顿了顿，声音低下去，“你若是看了、用了、报了仇，他在地下，就真的还不清了。”

屋外苇丛沙沙响，夜风吹动灯火，将马老三的影子拉得忽长忽短。苏荷沉默了很久，把那本册子抱在怀里：“我知道了。”

转身出门前，她停了一步，回头问：“马师傅，您和我师父认识多少年了？”

马老三正低头收拾案板，闻言动作一僵：“二十八年。”

“那他有没有跟您提过一个人——”苏荷问，“一个跟他学艺、后来又反目的徒弟？”

马老三手里的铜勺“哐当”一声掉在地上。他弯腰去捡，手指微微发抖：“你……你问这个做什么？”

“因为我在柳家祠堂的暗格里，找到了一双棉手套，手套内衬上用血写了一个名字。”苏荷的视线钉在他脸上，“那名字是‘乔春风’。”

马老三像是被抽走了全身的力气，手里的铜勺又落了地。他喉结滚动了一下，声音嘶哑：“乔春风……是老疯子的师弟，二十年前，就是他把那封帮主手书卖给了柳家，也是他，把老疯子逼出青江的。”

他抬起头来，目光浑浊而笃定：“那个人，现在还活着，就在青江。”

苏荷与顾长山走出砖房时，天边已经泛起一线鱼肚白。苇丛里的露水浸湿了裤脚，她低头看了一眼怀里那本册子，又抬头看了一眼白水河的方向。

雾气正在消散，河岸尽头的柳树下，有一顶草帽搁在石头上——像是被人匆匆放下，又像是刻意留下的标记。

草帽帽檐内侧，缝着一片干枯的荷叶。

苏荷的脚步一顿。那顶草帽，与半月前在食品厂门口、托人给她捎话的草帽人，一模一样。

她攥紧了铜钱，忽然明白师父留给她的“最后一课”究竟是什么——她想查清那封信背后的旧案，要追的却不仅仅是那封信。她追的，是一个还在暗处窥视、从未离开的人。

而那个人，像那味不在锅里的胡椒一样。

藏在灶台外头。

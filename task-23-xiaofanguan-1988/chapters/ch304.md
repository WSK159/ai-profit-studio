# 第304章 黎姓来人

门外两声轻叩之后，安静了片刻，又敲了两下，节奏与第一回相同：两急一缓。苏荷背贴着东厢门板，右手已经摸到门后的擀面杖——那是她进院时顺手捡的，防身胜过一切。

“谁？”

门外声音沙哑，带着常年烟熏的粗粝：“我姓黎，周三爷让我来传话。”

苏荷没有立刻开门。她脑海中飞速闪过几个画面：味香居旧宅外那棵歪脖槐树下，一个弓着背的老头蹲在石阶上晒太阳，见她路过，抬了抬眼皮，又低下去了。后来她打听过，那人姓黎，是味香居老宅的看门人。再后来，老宅易主，黎老头就不知去向了。

“黎老爷子。”苏荷隔着门板开口，“您怎么找到这儿的？”

门外沉默了两息，那声音里透出一点笑意：“姑娘，桂花巷七号的门锁是周三爷配的。他让我来，自然知道路。”

苏荷心头一动。这话听着轻巧，实际上却说明一个问题——这处院子并非什么秘密据点，周三昧能让人找来，就说明他对来人有十足信任。她略一沉吟，将门闩拉开一道缝。

月光斜斜地洒进来，照出半张老脸——确实是味香居旧宅门口那个黎老头。他比上次见面时清瘦了不少，颧骨高高凸起，眼窝深陷，但一双眼睛仍亮得像石缝里的水光。他手边放着一个竹篮，篮口盖着蓝布，鼓鼓囊囊的，不知装了什么东西。

“周三爷让我告诉姑娘一句话。”黎老头压低声音，“原话是——‘明日腊月十四，午时三刻，南门口老槐树下，我等他。’”

苏荷眉头拧起：“‘他’是谁？”

黎老头摇了摇头：“三爷没说。他只说姑娘听了便懂，若是听不懂，就当我没来过。”

苏荷心里一沉。她与周三昧之间，正儿八经的约定只有腊月十五那一桩——他说要带她去看“那口锅”。如今提前到明日午时，还约在城南门口的老槐树下……她想起了油纸包里那封信，信上所署日期是腊月初十，信中写道“贤弟亲启，兄于腊月十五前必至城西”，落款一个“周”字。周三昧急着提前见面，十有八九和那封信有关。

“他还有没有说别的？”

黎老头从竹篮里取出一只陶碗，碗里装着大半碗黏稠的酱色物，散发出一股红曲混着酱豆的浓香。苏荷一嗅便认出来——和周三昧之前交给她的毒酱样本是同一批。但这份酱的色泽比她手中那碗略深一些，表面浮着一层细密的油珠，显然是放了更久。

“三爷说，这碗酱是八月二十三那天做的。”黎老头的声音忽然低到几乎听不见，“那日，仓库里一共做了三十七碗，卖出去三十六碗，唯独这一碗——是留给自己的。‘姑娘若是尝了，就明白我为什么急着见你。’”

苏荷接过陶碗，指尖在碗沿上摩挲了一圈。碗底有一道细痕，像是用指甲划出来的，拼成一个极小的“归”字。和铜钥匙上那个“归”字一模一样。她抬眼看向黎老头：“他还有别的话吗？”

黎老头直起身，拍拍膝盖上的浮土，道：“没有了。三爷说，姑娘如今手里握着的东西，比他多。明日见了面，他自然把该说的全说了。”

说完，他拎起竹篮转身便走，脚步轻快得像一阵风，眨眼便消失在巷口的拐角。

苏荷在门口站了好一会儿，直到远处传来鸡鸣，才关上门。她回到桂花树下，重新将油纸包取出，展开最上面那张信纸，在月光下细细端详。

信纸上的字迹苍劲有力，笔画转折处带着明显的顿挫——和账本封皮上的字、铜管里那张纸条上的字如出一辙。这是同一个人写的，那个人姓周，而周三昧自己说过，他本名不叫周三昧。

信上写道：“贤弟亲启。兄自去岁南下，奔波千里，终在岭南寻得一味古法红曲，可入酱而增百香，亦可入药而解百毒。然道途艰险，行至江右时，遭遇水匪，包裹尽失，唯此方藏于衣襟，幸免于难。兄思之再三，此方不可轻传，须以三事为约：一不传无信之人，二不传贪利之徒，三不传忘本之辈。弟若应之，腊月十五前，兄必归，当面奉上。若不应，弟亦不必等。周字亲笔，腊月初十。”

苏荷将这封信反复读了三遍，终于品出了一丝滋味。

“红曲古法……可入酱，亦可入药。”她自言自语。周三昧给她那碗毒酱样本，说是从城北一口枯井中所得，酱里有樟木味，与寻常红曲酱不同。而信上说他南下岭南寻得的古法红曲，“可入酱而增百香，亦可入药而解百毒”——这分明是在说，那碗毒酱所用的并非真正的古法红曲，而是有人用寻常红曲掺了樟木油仿制的假货。

她若将这两件事对上，就能得出一个结论：有人在仿制周三昧的红曲方子，而且仿得不像，加多了樟木油，弄出毒酱来。周三昧急着提前见面，恐怕正是因为他查到了那个仿制者是谁。

苏荷将信纸折好，重新塞回油纸包，又把陶碗用布包好，塞进夹袄里。天快亮了，她不能留在这里太久。她走到院门口，将门锁拨回原位，钥匙藏进内衬，绕过巷子，消失在晨雾里。

快到城南巷口时，她忽然停下脚步。身后三丈外，一个灰扑扑的身影闪进了路边的杂货铺棚子里——只一闪，便不见了。

苏荷没有回头，加快脚步拐进巷中。

那碗毒酱背后的仿制者，已经盯上她了。

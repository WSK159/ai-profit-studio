# 第429章 码头上的局

苏荷没让那些人进门。她迎出去，站在台阶上，不卑不亢地看着领头那人：“这位大哥，找谁？”

“沈爷让我来传句话。”领头的人二十几岁，个子不高，眼神却利得很，“沈爷说，昨儿晚上白水河风大，怕您着了凉，让您今儿别往河边去了。”

这话明面上是关心，实际上是警告。苏荷心里冷笑一声，脸上却温温的：“多谢沈爷惦记。昨儿晚上我睡得早，没听着河风。”

那人盯着她看了两息，忽然笑了一下：“那就好。沈爷还说，改日请苏老板吃茶，顺便谈谈‘问味’的事。”

说完，他带着那七八个人转身走了，灰布短褂在巷子里鱼贯而过，像一队训练有素的兵。

苏桃拽着苏荷的袖子，小声问：“姐，那个沈爷……是个什么人？”

“一个做生意的。”苏荷把妹妹往店里推，“帮我看着灶上的火，我去一趟码头。”

“码头？”苏桃眼睛瞪大了，“刚才那个人不是说别去河边吗？”

“他让我不去，我偏要去。”苏荷系好围裙，又解开，换了一件干净的碎花罩衫，“我去去就回，午饭前肯定到。”

她没走正街，拐进一条小巷穿出去，过了一座石桥，再沿河岸往下游走了约莫二里地，这才看见码头的影子。清晨的码头已经有了人气，几条渔船泊在岸边，有人在卸货，有人在吆喝。苏荷站在一棵歪脖子柳树下，扫了一圈，看见了刘船头和周仓管。

两个人蹲在码头边上的石阶上，一人叼着一根烟。刘船头的脸上青了一块，像是被什么砸过；周仓管的一只耳朵上还挂着干涸的血痂。两人看起来狼狈，可眼神却一点不像吃亏的样子——他们不时抬头往苏荷走来的方向瞟一眼，像是早就知道她会来。

苏荷大大方方走过去：“刘叔、周叔，听钱叔说你们找我？”

刘船头站起来，嘴里的烟头往地上一扔，踩灭了：“苏老板，咱们明人不说暗话。昨儿晚上，白水河第七道弯，我们哥俩让人给黑了——”

他伸手指了指自己脸上的伤：“打我的人是个老头，跑得比兔子还快，我们追不上。可等我们醒过来，看见了您从河滩上往这边走。”

苏荷心里一沉：他们看见她了。她面上却不动声色：“刘叔这话有意思。我昨儿晚上在家睡觉，什么时候去过白水河？”

“您别蒙我。”刘船头搓了搓手，“我跟老周在码头上跑了大半辈子，河里的事瞒不过我们。那老头不是外人，他是钟家的老奴才，这几年一直在河上游转悠，谁也不搭理。您要是没跟他沾上，他不会跟您说那么多话。”

苏荷没有否认，也没有承认，只是问：“刘叔，您找我来，到底想说什么？”

刘船头和周仓管对视一眼，像是交换了一个选择题的答案。然后周仓管从怀里掏出一个东西，用一块蓝布包着，递到苏荷面前：“苏老板，您认这个吗？”

苏荷接过，掀开一角——里面是一块巴掌大的木牌，乌沉沉的，像是被烟火熏了几十年。木牌正面刻着一朵五瓣梅花，背面刻着一行小字。字被磨得模糊了，但她凑近细看，依稀辨认出两个字：

“沉缸”。

苏荷的指尖一颤。她想起了沈伯言的那块黑铁牌，想起了自己手里那块乌铁牌，想起了师父临死前握在她手心的那朵五瓣梅花印。这块木牌上的梅花，跟她师父印在信封口的那个印记一模一样。

“哪来的？”她问，声音有些哑。

“庚午年，钟家沉船之前，从船上丢下来的。”周仓管的声音压得很低，“我爹当时在码头上扛货，亲眼看见的。船快沉的时候，有人从船上扔下来一包东西，用油布裹着，顺水漂了三里地，他捞上来一看，里面就是这块牌子，还有一张纸条，写着十二个字。”

“哪十二个字？”

“白水河底，一盏灯，一口缸，一个人。”

苏荷的耳朵里嗡了一声。她忽然明白那封信上那句话的意思了——十二盏灯，灭灯之人即守箱之人。灯是记号，守着灯的人，替钟家守着一个秘密。而守的那个秘密，就是一口缸，一个人。

“这牌子……”她握紧了那块木牌，“你们为什么给我？”

“我们给过很多人。”刘船头苦笑一声，“没人接。”

周仓管接话道：“这东西烫手。钟家没了之后，河底的东西被翻了好几遍，可没人找着那口缸。后来有人放出话，说谁要是能寻到“沉缸”的下落，柳家出一百斤黄金悬赏。”

一百斤黄金。苏荷倒吸一口凉气，但紧跟着又生出警觉——就算真是悬赏，这俩人为什么要让她知道？

她正想着，身后忽然传来一个熟悉的声音：“苏老板，这牌子的故事，我知道后半截。”

苏荷转过身。沈伯言站在石阶下面，穿着一件深灰色的薄呢大衣，手里立着一把黑伞，正微笑着看她。他身后跟着刚才那个灰短褂的年轻人。

“沈爷，”她平静地颔首，“这么巧。”

“不巧。”沈伯言走上石阶，目光落在她手里的木牌上，“我找了这个东西，找了五年。苏老板要是愿意，我想跟您谈谈这笔生意。”

他顿了顿，又补了一句：“顺便，也跟您讲讲，当年钟大河死前，最后见的那个人——姓苏，跟您一个姓。”

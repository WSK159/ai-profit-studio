# 第348章 灶火引路

县医院门口的风带着消毒水味，苏荷攥着那包油纸站在台阶下，纸里的灰隔着层能闻到那股陈年酒香。苏桃拽着她袖子，小声说：“姐，爸进去之前跟我说，奶奶还留了一句话——‘灰里有信，信在火里’。”

顾长山从旁边走过来，眉头拧着：“刚才那个传话的，我让人跟了一下，往城东去了。那边是废品站。”

苏荷把油纸包贴身收好，抬头看了看天。1988年腊月的日头白惨惨的，她心里却像烧着一团火。奶奶临死前没跟任何人说过一句多余的话，唯独把这包“底灰”留给了苏广田，还说“你丫头迟早用得上”。她从前想不明白，一个常年卧病的老太太，哪儿来的预判力。可今天她闻着那酒香，忽然懂了。

“回店。”她说。

苏记小馆傍晚歇了灶，苏荷把学徒都打发去后院择菜，只留了灶间一盏灯。她把油纸包搁在案板上，一层层打开。灰是深褐色的，细得像面粉，掺着一点没烧透的米壳。她捏了一撮放进掌心，凑近鼻端又闻了一遍——没错，是曲母的味道，而且不是普通的酒曲，是加了药材、陈化过十年的那种。

董三春烧尾宴的第三页她研究过无数次：醉仙虾的方子里写“三蒸三晒的曲母”，后面画着一株桑枝。前世她师父教她这道菜时，反复叮嘱“曲母底子最重要，能寻着就寻着，寻不着就用现打的，味道差两成”。那时她没深想，只当是老人家讲究。现在她忽然明白，师父说的“寻”，是真的在找一样东西。

“长山，”她头也不回，“帮我烧灶。”

顾长山二话没说，蹲下去往灶膛里添了把柴。火舌舔上来时，苏荷把一撮底灰撒在灶台边缘，灰遇热，“滋”的一声升起一缕青烟，烟里那股酒香竟猛然浓了十倍，带着一种类似桂花蜜的甜香。她盯着那缕烟，看它没有直直上升，而是被灶膛里窜出的热气带得微微偏向西北方向。

“西北是哪儿？”

顾长山想了片刻：“城南巷往西北，过了铁路就是老城根，那边有片旧宅子，大多是民国时候的粮商建的。”

苏荷心里咯噔一下。郑国栋留下的那张绵纸地图她看过，皱巴巴的边角上画着一条青石巷，巷尾一座带阁楼的院子，门楣上三根横木。她前些天路过老城根时瞥见过一座废院，门楼早塌了半边，可那三根横木还在，被烟熏得乌黑，像人的指骨。

“走。”她熄了灶火，把底灰包好，又拿起那把董家锅铲揣进怀里。苏桃跟到门口：“姐，带上我。”

“你留着看店。”苏荷顿了顿，“要是有人来问，就说我回娘家了。”

苏桃愣了一下，随即点头，没再追问。

老城根的夜路黑得彻底。路灯隔老远才有一盏，昏黄的灯泡蒙着灰，像垂死的眼睛。顾长山打着手电走在前面，光柱扫过碎砖和干枯的野草，偶尔惊起一只野猫，窜进墙缝里。

那座废院比苏荷记忆里更破。院门只剩半扇，门轴锈死在石臼里，斜着歪在一旁。她踩着碎瓦跨进去，院里长满了齐腰的蒿草，却有一块地被踩平过，草茎断口还是新鲜的白茬。

“有人来过。”顾长山低声道，手电往地上扫。土里有一串脚印，从院门一路延伸向正房。脚印很深，步幅均匀，是个大脚男人，鞋底纹路是解放鞋的波浪纹。

苏荷推开正房的门。屋里一股霉味混着灰腥气，地上落了一层薄灰，但灶台附近的灰被擦掉了一大片，露出青砖地面。砖缝里嵌着什么东西，泛着一点暗黄的光。

她蹲下去，捡起来一看——半片骨签。指甲盖大小，边缘打磨得很光滑，上面刻着半道弧纹，跟她之前捡到的那片骨片，纹路竟对得上。

顾长山拿手电照了照那灶台，忽然开口：“这灶膛是后来砌的，砖色不对。”

苏荷凑过去看。果然，灶膛内壁的砖比外壁新了起码二十年，灰缝里塞着细碎的草木灰，却没什么烟火气。她伸手往里探，在砖缝摸到一个硬角，抽出来一看，是一只油布裹着的小坛子。

坛口用蜡封着，打开后，里面是半坛灰白色的粉末，混着一些没碾碎的曲块。她凑近闻——和奶奶留下的底灰一个味道，但更浓，底下还压着一张折成方块的牛皮纸。

她展开纸，上面写着一行钢笔字，墨水已经洇开，但还勉强认得清：

“三蒸三晒，桑枝引火，石臼研细，取花心之一撮。料熟则酒成，酒成则信出。”

落款是个“董”字。

苏荷把牛皮纸翻过来，背面又有一行小字，字迹不同，像是后加的：“铁钎不在灶下，在井里。”

她抬起头，院角正好有一口老井，井口用石板盖着，青苔爬满了缝。

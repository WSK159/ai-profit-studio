# 第127章 那把刀叫“寒江”

二叔一伙人被顾长山带走了，闹哄哄地出了门。围观的邻居们散的散，有几个好心的大娘帮着把桌扶起来，又叮嘱苏荷注意安全才离开。

店里只剩下姐妹俩。苏桃这才“哇”地哭出来，扑进苏荷怀里：“姐……我好怕……他们、他们把你的辣椒坛子都摔了……”

苏荷拍了拍她的背，声音比刚才缓和了许多：“没事，姐回来了。坛子能再腌，辣椒能再种。”

等苏桃止住哭，苏荷把她安顿在里屋，自己蹲下来收拾满地碎瓷片。捡到一半，她忽然想起什么，快步走到门口拿起那本《灶上辑要》。

书没被踩到，好险。

她翻开书页，一股淡淡的油墨香混着灰尘味扑面而来。沈其昌的字迹工整，每一页都密匝匝地记着火候、刀工和调味细节，偶尔还有批注——“此法适合青鱼”、“辣油须冷浸三日”。

翻到最后一页时，苏荷顿了顿。

那里夹着一张折得方方正正的宣纸。她小心翼翼地展开，纸上是一幅墨色速写，画的是一柄菜刀——刀背厚、刀刃薄，刀身弧度优美，刀柄处有一枚小字印：“寒江”。

旁边是沈其昌的字：“先师赵一鸣手书，赠关门弟子。寒江刀，好刀配好厨。”

苏荷的手指轻轻划过纸上的“赵一鸣”三个字。

爷爷留下的九把刀，是赵一鸣打的。赵一鸣是谁？应该是沈其昌口中的“赵姓友人”，也是爷爷的故交，或者说……师父？

她忽然觉得胸口有什么东西松动了。上一世她跟着师父学厨时，师父曾经提起过一个名字，说“青江有旧人”，没有多说。当时她以为是普通故交，没放心上。

如今想来，那条线索似乎从祖师爷的脉络一直连到了今天。

沈其昌临走前说过一句话：“那九把刀，不是菜刀，是身份。你拿得住，就抓得稳；你拿不住，趁早还回去。”

她当时没问清楚，现在在昏暗的灯下看着“寒江”二字，她慢慢想起那把刀——爷爷留下的九把刀里，第二把就是一把刀背带弧、刀柄刻小篆的，她试过，特别顺手。

正想着，门口忽然传来一阵急促的脚步声，紧接着门帘被一把撩起来——是王顺德。他满头是汗，衬衫领子都歪了，进门就压低声音：“苏老板，你二叔那事还没完。我刚得到消息，有人拿了张纸去找经侦科，说你家的老铺子权属有问题，是‘历史遗留乱账’——你手里的契，可能作不了数。”

苏荷手里的《灶上辑要》啪地掉到桌上。

王顺德又说：“还有一件事。那个想买你家老宅子的人，查到了，姓于，省城来的。”

她脑子里嗡嗡响了一阵。姓于——省城来的——买老宅子。上一世，苏家老宅就是在1990年被人用“历史遗留”的手续低价收走的。

那个人……好像就叫于什么昌。

“王叔。”苏荷抬头，眼里恢复了清明，“你能帮我约那个人见一面吗？越快越好。”

王顺德犹豫了一下：“那人，听说跟工商局的人熟。你确定要去？”

苏荷看了一眼摊开的《灶上辑要》，又看了一眼墙上被划烂的招牌，笑了一声：“他都惦记上我的宅子了，我总不能连对手的面都不见吧。”

窗外夜色彻底沉了下来。城南巷的灯泡闪了闪，发着昏黄的光。苏荷把书收进柜台底下的铁盒子里，锁好，又把钥匙挂在脖子上。

她伸手摸了摸第二把刀的位置，刀柄微凉的触感从指尖传来，仿佛隔着几十年的时光，握住一只手。

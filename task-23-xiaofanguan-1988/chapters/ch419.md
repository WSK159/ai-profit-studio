# 第419章 五瓣梅花印

钟大川的声音隔着土墙闷闷地撞进来，像一只困兽在地底刨洞。苏荷攥紧手里的黄纸，那枚五瓣梅花印的轮廓烙在她指腹上，隐隐发烫。

她没答话。顾长山退回来，在她身边低声道：“墙后有夹层，他进不来，出不去。”

“你们以为困得住我？”钟大川的声音忽然变了调，狂躁中带着一股疯劲儿，“这宅子的主人把账本藏了二十年，可他把另一件东西也藏在了墙里！你们翻开那本账，中间有没有夹页码？”

苏荷低头翻账本，指尖飞快扫过页码。她翻到三分之一处，果然——页码从“十七”直接跳到了“十九”，缺了第十八页。可装订线是连贯的，她伸手探进纸与纸中间的缝隙，果然，摸到另一张叠得极薄的纸片。

她抽出来展开，纸上密密麻麻画着一张布局图，标注着“枯井”“灶孔”“正房阶下”等几处方位，最下方画着一个圆圈，圆圈里写了一个“洞”字，圈外又圈了一圈，标注：“白水河出海口，第七道弯。”

这一眼下去，她脑中像被大锤砸中，许多零碎的信息轰然接上：钟家旧宅枯井里藏着账本，正房台阶下藏着乌铁牌，而白水河出海口的第七道弯——那才是真正的大货。

“第七道弯……”她喃喃念着。

灰布老头忽然脸色大变：“女娃娃，你说什么？”

“白水河出海口，第七道弯。”苏荷把纸片亮在他面前，“这图是钟老爷画的？”

老头扑通一声跪下去，双手撑在地上发抖，半晌才哑着嗓子开口：“钟老爷临死前画了这图，托我烧掉。我没舍得烧，把它夹在账本里，想着将来……”

“将来什么？”沈伯言厉声问。

“将来有人替钟家翻案的时候，能用得上。”老头抬起头，浑浊的眼睛里第一次有了亮光，“白水河出海口第七道弯，庚子年沉船之后，钟老爷偷偷去打捞过。船里除了盐，还有一箱官银——那是朝廷拨给青江府的赈灾款，由钟记盐船押运。船沉了，银箱也没了。府衙认定是钟家监守自盗，才百般查证，非要找出凿船的‘罪证’。”

“可凿船的另有其人。”苏荷接话，“有人官盐私运，再用沉船做局，黑了那箱官银。”

沈伯言沉默片刻，吐出一口气来：“那箱子，钟老爷打捞到了没有？”

老头摇头：“没捞着。但他回来之后说了一句话——‘船底的凿口不是凿出来的，是炸出来的。’那根本不是什么凿船，是有人用了火药，在船底炸了一个洞。”

苏荷猛然想起磨坊那场爆炸——那股焦糊的气味、被掀翻的石磨，还有那条通向暗港的地道。那股被人精心埋下的火药味，从庚子年一路蔓延到了今天。

“那黄纸上的五瓣梅花印，”苏荷抬起手中的黄纸，“是朝廷哪个衙门的？”

沈伯言走近两步盯着那印记看了片刻，脸色变了：“这不是官印。这是当年青江府漕帮帮主的私印。漕帮主姓柳，名春江。”

苏荷脑子里“嗡”的一声。柳春江——柳家宗祠里供着的那个牌位，遗信中被认为是被冤枉嫁祸的柳春江。可账本封底夹层里分明写着“持衙门铁牌，腰悬柳字玉坠”，而盖着五瓣梅花印的黄纸又被沈伯言亲口指认为柳春江的私印。

“柳春江自己给自己写的供状？”苏荷的声音里带着难以置信。

沈伯言摇头：“不对。柳春江是庚子年之后才接掌漕帮的。那印章如果是他的，那就是……他替别人扛了罪。”

墙后忽然传来钟大川一声压抑的怪笑：“扛罪？柳春江哪里是替别人扛罪，他是替自己亲哥哥扛的！柳春江是钟老爷的亲生儿子，钟家二房过继给柳家的！那艘船是他哥哥钟大河造的，船底炸洞的火药，也是他哥哥埋的！”

土墙后话音落地，满院寂静。苏荷的脊背一阵发寒，她忽然明白钟大川为什么一直能挖出那么多秘密——他挖的不是宝贝，是钟家一门三代的遮羞布。而柳春江那封遗信里“有人穿了我的衣裳，做了脏事”，说的根本不是什么素不相识的人，是他的亲哥哥。

顾长山伸手按住苏荷的肩膀，低声道：“钟大川在引我们听。他知道我们找不到出口，故意说这些，是在拖延时间。”

话音未落，脚底地面忽然传来一阵细碎震颤。柴房前那口半埋土中的破缸，缸底缓缓裂开一道缝，一只满是泥土的手从裂缝中伸了出来。那只手里，攥着一块黑铁牌。

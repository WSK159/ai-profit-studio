# 第349章 年三十的灶火

腊月廿九的清早，苏荷推门出去，冷风卷着细雪粒扑面而来。巷子里已有人在扫雪，锅碗瓢盆的叮当声从各家院子里传出，年的味道在寒气里发酵，浓得化不开。她跺跺脚往城南巷走，心里盘算着明天年三十的菜单。

推开“苏记小馆”的门，顾长山正蹲在灶膛口捅火。铁锅里炖着高汤，咕嘟咕嘟冒着泡，汤色乳白，香得能把人的魂勾去。

“这么早？”苏荷把围裙系上，“不是说让你今儿歇一天？”

“歇不住。”顾长山抬起头，脸上蹭了道灰，“你不是说，明晚要给整条巷子的人做一顿年三十的流水席？”

“是。”苏荷掀开锅盖看了一眼，又盯住他，“长山，你听我说。这顿席，我打算把沈灶地窖里那缸老酱缸的卤水用上。”

顾长山手里的火钳一顿：“那缸……沈伯言的卤水？”

“对。”苏荷点头，声音沉稳，“我研究了大半个月，那缸卤水的底子——井水、灰烬、地下盐——跟董宅灶底三斤灰的方子是对上的。那年除夕，沈伯言为董家做的是‘百味归灶’，一锅卤水，炖了三天三夜，收尽百味，敬的是灶王爷。”

“你知道的越多，我越觉得不踏实。”顾长山站起来，替她拨了拨垂下来的发丝，“草帽人说等了二十年，沈伯言绝笔信上那句‘盼有人能续此灶’，你到底……”

门外忽地传来一阵急促的脚步。门帘一挑，何九斤裹着军大衣窜进来，抖落一身雪沫子，嘴里直哈白气：“苏老板！出事了——董家老宅那边闹起来了，说有外地人拿了老宅的房契来收房，正跟董家老太太在门口吵呢！

苏荷和顾长山相视一眼，一个抄起灶台上的擀面杖，一个把烟头摁灭：“走。”


董家老宅门口围了一圈人。雪地上站着一个穿灰呢大衣的中年男人，手里攥着一张泛黄的纸，嘴里嚷着：“这是民国三十六年立的老契，这宅子当年是抵押给我们钱庄的，利息滚了三代人，现在按政策清算，收了房抵债，天经地义！”

董家老太太拄着拐杖挡在门口，八十多岁的瘦小身子在风里直抖：“什么钱庄不钱庄！这宅子是我公公从县城搬来时买的，地契在县档案馆存着呢！”

围观的街坊七嘴八舌，有人起哄，有人担忧。苏荷拨开人群走进去，目光却没落在那张“老契”上，而是定定地看了穿灰呢大衣的男人三秒钟，然后开口道：“这位同志，你说这宅子当年是抵押品，请问——抵押的是哪家钱庄？”

男人一愣：“城南永丰钱庄，怎么了？”

“永丰钱庄？”苏荷笑了，“民国三十六年，青江县城压根儿就没有永丰钱庄。城南那家叫‘聚昌’，县城那家叫‘恒通’，永丰开在省城，民国三十八年才迁过来的——你连自己铺子的历史都没弄清楚，就拿着一张假契来糊弄人？”

男人脸色骤变：“你、你胡说！”

“我胡说？”苏荷从口袋里掏出一个小本子，翻开一页递到他面前，“我上个月在省城做美食展报名时，县档案馆的秦主任给了我一卷民国年间青江商帮的档案，里面正好记着三十六年城南的钱庄名录。永丰两个字，写得分明是迁入日期——你要看吗？”

人群哄地炸了。灰呢大衣男人脸上青一阵白一阵，牙一咬，把契纸往怀里一塞，仓皇挤出人群，遁入雪中。身后一片叫好声。

老太太握住苏荷的手，哆嗦着道谢：“闺女，你怎么连钱庄的事都知道？”

苏荷垂下眼帘，低声道：“是沈伯言的菜谱里记的——他当年记账，给董家卤过肉，钱庄的旧事也写在菜谱边角。这人，是个把什么都记在纸上的。”她顿了顿，没说出来——那卷手写菜谱的末页，沈伯言用极小的字写了一行：“永丰钱庄，民国三十八年春，有人带着董家老宅的老契来套话，我多记了一笔。防的就是今日。”

她抬头望了望董家老宅的屋檐，积雪压在黑瓦上，沉甸甸的。草帽人口中的“井水的咸是地下盐”，她已经在埋进灶底的三斤灰里尝出了端倪——那灰烬里，分明混着卤过咸鱼的炭灰。而沈伯言在绝笔信里提到的“一锅井水”，应是指用老井的水来调卤。她的脑子里飞快地转着，仿佛有个声音在催促：这一切，都在为明天那锅卤水铺路。

“苏荷。”顾长山走过来，把一只油布包塞进她手里，“刚才有人让我捎给你的。说是一个戴草帽的人。”

苏荷接过，拆开——里面是一小把粗盐粒，和一张字条：“年三十，卤水开锅时，把盐撒进灶膛里。沈伯言当年守的，就是这个灶的灶火。”

她攥紧字条，指尖微微发凉。那缸陈年卤水、那卷手写菜谱、那封绝笔信、草帽人、董宅灶底的灰烬、井水的咸——所有这些线头，在年三十的灶火前，要拧成一股了。

顾长山站在她身后，雪花落在他肩头。他低声问：“明晚的流水席，你真打算让全巷子的人都尝一尝那缸卤水？”

苏荷回头，眼睛里有光：“不是尝——是让所有人都记住，这口灶，能烧出什么样的年味来。而且，”她一字一句，“董家老太太说，她年轻时吃过一回沈家的卤肉，就那一次，记了一辈子。我得上她那句话，接住这口灶。”

风卷着雪粒刮过城南巷，远处隐约传来零星的鞭炮声。年三十，明天就要到了。苏荷攥着那把粗盐粒，心里那根弦绷得越来越紧——她知道，自己站在这口灶前，并不只是做一顿年夜饭那么简单。

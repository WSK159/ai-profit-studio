# 第121章 刀光夜色

苏荷把木板往腰间一别，摸索着把厨刀背进怀里，刀鞘硌得她肋骨生疼。她没有耽搁，三步并作两步跨上石阶，铁板在头顶合拢之前，她顺手把那封信塞进胸口内兜。青砖重新塞回原位，苏荷用脚把散落的浮土蹚平，刚弯下腰去捡铁锹，院门就被人重重擂响。

“开门！街道办的，查夜！”

苏荷拍了拍手上的灰，看了一眼蹲在墙根吓白脸的苏桃，低声道：“别怕，看姐的。”她整了整衣领，走过去拉开门闩。

门外站着两个穿蓝色制服的年轻人，手里攥着手电筒，光柱直直地打在苏荷脸上。她微微偏头避开，语气却不慌：“大晚上的，是哪位主任查夜？我问一句，有没有批文？”

左边那人愣了一下，右边那个年纪大些的接话道：“你是这户的户主？老宅子久无人住，有人举报说夜里亮灯，怕有人偷拆房梁砖瓦。我们过来看看。”

苏荷笑了：“偷拆我自己家的房梁？同志，这话说出去谁信。我回来收拾老宅子是交了申请的，城南区分管城建的王顺德王主任那里有备案，要不您现在去问问他？”

那两人对视一眼。年纪大些的人没有继续纠缠，手电筒在院里晃了一圈，似乎在确认什么，随后点了点头：“行，苏同志，有备案就好。不过夜间最好少动瓦刀，免得邻居误会。”

两人转身离去，脚步声在巷子里渐远。苏荷站在门口目送，一直等那脚步声彻底消失在巷口，她才关上门，后背抵着门板长长地吐了一口气。刚才那两个人的手电筒照的方向，一直落在她脚下撬开过青砖的位置附近。

他们不是来查夜的，是来踩点的。

苏荷蹲到苏桃面前，从怀里抽出那把厨刀，刀入手凉，她的心跳也跟着沉了一分。“桃子，明天一早你去一趟城南区卫生所，给妈买药，我写个单子你照方子抓。”苏桃点点头，又怯怯地问：“姐，那地窖里……到底有什么？”

苏荷没答话，把那把厨刀搁在桌上，煤油灯重新点起来，火光映着刀刃。她看了半晌，沉声道：“是能保命的东西。”她顿了顿，又补了一句，“也是能让很多人动歪心思的东西。所以今晚的事，你谁都不能说，妈也不能。”

苏桃用力点头。

苏荷把刀收回怀里，坐下来，借着灯又把爷爷那封信从头到尾看了一遍。信里有两处细节她第一次没注意到：爷爷写“沈其昌”三个字时，笔锋格外重，像是在强调这个人可信；而信纸背面又有一行极小的字，像是后来添补上去的——“若沈氏亦不可信，则拆刀柄，内有老友名帖。”

她翻过刀，刀柄末端果然有一圈细纹，像是可以拧开的。但苏荷没有现在动手——院子里隐约又响起了脚步声，这回是皮鞋踩在砖地上的声音，一下一下，连节奏都没有变。

她慢慢把信塞回内兜，握住怀里的刀柄，抬眸望向门外。

院门外有人停下脚步，叩了三下门。

声音沉沉的，不急不缓。接着传来一个男声：“苏荷，是我。”

苏荷一怔，那声音再熟悉不过。她拉开院门的瞬间，顾长山站在月色里，风尘仆仆，额头上带着一层薄汗，军大衣的领子竖着，手里拎着一个鼓鼓囊囊的帆布包。

苏荷张了张嘴：“你怎么来了？”

顾长山走进院子，反手把门带上，低声道：“王顺德今天下午递了封信给我，说是‘城南老宅地权归属存疑，建议由街道代管’。我拆开看过，他落款用的公章是城建的，但信纸是经侦科专用的。他是在警告你。”

苏荷攥紧刀柄，没有说话。

顾长山的目光落在她手里那把厨刀上，顿了一瞬：“你这是……挖到东西了？”

苏荷没有回答这个问题，反问他：“你那个帆布包里装的什么？”

顾长山把帆布包往桌上一放，拉开拉链，里面是一摞文件，顶上那张纸写着四个字——

“土地权属证。”

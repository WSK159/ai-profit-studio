# 第372章 正房梁上

天亮得早。苏荷一夜没睡实，翻来覆去脑子里都是那张残账上的铅笔字——“董宅正房梁上，三尺见方，铜皮裹之”。

她起身时顾长山已经坐在灶间烧水，看见她出来也没多问，只把搪瓷缸子推过来，里面是冲好的红糖水。苏荷接过来喝了一口，甜味顺着喉咙往下走，身上那股子颤劲才压下去。

“我去一趟董宅。”她说。

顾长山没接话，弯腰往灶里添了根柴，火烧得噼啪响，半晌才说：“我跟你一块儿。”

苏荷摇头：“你穿这身军大衣太扎眼，我换了棉袄去，就说是打听老宅子的修房手艺。正房梁上的东西，白天才看得清楚。”

顾长山沉默了一会儿，从怀里掏出一样东西递给她。是一把折叠刀，铜柄，刀身磨得发亮。苏荷认得，这是顾长山贴身带了三年的东西。

“带上。”他说，“出什么事，喊一声。”

苏荷把刀揣进棉袄内兜，扭头出了门。

董宅在城南巷东头，旧式砖木小二楼，民国时候是青江城里头排得上号的宅子，后来土改分给了几户人家住，到如今只剩一位姓董的孤老太太守着一楼的两间屋，上头早就空了，瓦片漏了也没人管。

苏荷到的时候老太太正在门口晒萝卜干，见有人来，眯着眼打量她半晌，问是找谁。

“婶子，我是巷口苏记饭馆的。”苏荷笑着递了两斤白糖过去，“听说您这宅子是民国的老营生，我寻思着店里想添几张老榆木桌子，想上楼看看房梁上有没有当年留下的好木料。”

老太太接过白糖，手在纸包上摩挲了两下，没直接答话，眼皮子抬了抬看她：“楼上灰大得很，你一个姑娘家上去做什么？”

“我就看看，不搬东西。”苏荷说，又笑道，“婶子要是不放心，您跟我一块儿上去也行。”

老太太犹豫了一下，终究是那两斤白糖起了作用，颤巍巍从裤腰带上解下一串钥匙，找了半天，拣出一把黄铜色的，递给她：“二楼第三间房锁是坏的，你自己推就行。别碰东头那口樟木箱，那是老太太我的嫁妆。”

苏荷应了一声，接过钥匙往楼上去。木楼梯年久失修，脚踩上去咯吱作响，灰尘扑下来呛得人直咳。二楼走廊黑洞洞的，她摸着墙走，找到第三间房的门，推了一把，果然没锁。

推开门的瞬间，一道冷风从头顶扑下来。屋顶瓦片漏了几个洞，光柱斜斜插进来，恰好打在北边那根正梁上。

梁是黑漆漆的老松木，足有一抱粗，横跨整个房间。苏荷仰头看了一会儿，没看出什么异样。她搬了墙角一把瘸腿椅子垫脚，踩着上去，伸手在梁上摸索。手指被灰糊了一手，碰到几道旧凿痕，还有钉子拔掉后留下的孔洞。

她摸到正中间时，指尖碰到一块微微凸起的硬物。掩在灰泥底下，不十分显眼，但手感与周围的老木头截然不同。她把指甲抠进去，一点点抠开干裂的灰皮，露出底下一角暗铜色。

铜皮裹的。果然有东西。

苏荷心跳快了几分，四周看了看，走廊里安安静静的，只听得见楼下老太太筛萝卜干的声音，沙沙沙，像一把一把的风。她定了定神，两只手一起使劲，把铜皮周围的灰泥清理干净。那铜皮裹着的东西大约三尺见方，扁扁的，包得严实，像一本厚书的大小，用细铜丝捆了一道又一道。

她正想解铜丝，指头碰到底下压着一块东西。抠出来一看，是一枚铜簪子，簪头雕着一朵半开的荷花，簪身磨得发亮，像是被人贴身带了好多年的。

铜簪子上套着一小截红绳，编织纹路眼熟得很——和那口枯井铁锅上系的红绳、灰鹊脚踝上系的，一模一样。

苏荷攥着簪子，心里翻涌不定。灰鹊、铁锅、董宅、老酱缸……散落的线头慢慢往一处靠拢。她来不及细想，把簪子揣进怀里，又顺手将铜皮盒子原样盖回灰泥里，只记住了位置。现在解下来拿不出门，老太太要是撞见她怀里鼓囊囊的，说不清楚。

她下了椅子，掸掸袖子上的灰，准备推门出去，却听见走廊那头传来一阵脚步声。很轻。不是老太太的步子，老太太脚下拖沓，这脚步声带着一股子猫一样的谨慎，停在她门外三两步的地方，不动了。

苏荷手伸进棉袄内兜，攥住那把折叠刀，后背贴着门板，没有出声。

门缝底下，一只穿黑布鞋的脚露出来，鞋底沾着干泥。过了一息，那人像是弯腰在门缝底下放了什么东西，然后脚步声原路退去，下了楼梯，再无声息。

苏荷等了半分钟，蹲下来往门缝底下一摸。摸到一张对折的纸条。展开一看，上面只有一行铅笔字，字迹潦草——

“子时三刻，城门楼，第三根柱子底下。你那半句，我来说。”

——与秃顶老头临走时撂下的“城门楼子时三刻半句真话”之约，一字不差。

苏荷把纸条揉进掌心，攥得死死的。楼上梁上的铜皮盒子、怀里的荷花铜簪、门缝底下的纸条，三样东西在同一时刻涌进来。她意识到一件事：秃顶老头说的“别惊动任何人”，约她子时三刻相见——可这个放纸条的人，又是谁？

楼下老太太的声音悠悠传上来：“姑娘，找着木料没有？找着了就下来吧，天不早了。”

苏荷把纸条咽进肚里，推门走出来，声音如常：“婶子，楼上灰大得很，没瞧见合适的木料，改日再来。”

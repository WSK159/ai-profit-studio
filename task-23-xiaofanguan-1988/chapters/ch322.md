# 第322章 假井

苏荷把铁盒里的东西一样样摊在小馆后院的八仙桌上，煤油灯的火苗被夜风压得伏下又弹起。顾长山站在她身侧，手指沿着那张泛黄的地图划线，在青江拐弯处停住。

“这一带我跑过。”他抬起头，目光沉沉，“龙王庙早塌了，庙基还在，就在城东老渡口下游三里。去年防汛时，街道办还组织人去清过河道。”

苏荷没应声，目光落在另一样东西上——底册里夹着的一张薄纸，边缘发脆，上面的字迹被水渍洇开大半，但依稀能辨出“老宅后园，假井一空，藏于九地之下”一行。她盯着“假井”两个字，忽然想起周跛子白天说的那句“井里没东西”。

“长山，周家老宅现在归谁管？”

顾长山摇头：“房管所那边档案转过几手，早弄不清了。不过我认识城东房管所的老郑，明天去查。”

苏荷捻了捻薄纸，指尖触到纸面微微凸起的纹路。她心头一动，把纸斜对着灯光看，隐约看见“井”字旁边有三道细痕，像是被指甲反复划过留下的凹槽。

“有人找过这口井。”她轻声说，“而且不止一次。”

“你怀疑井里真没东西？”

“周文祥在遗书里说‘守册之责，至死方休’。”苏荷把薄纸放下，理了理思绪，“他既然把地图指向龙王庙，又把‘井非井’写进谜语，那井多半是幌子。可幌子也得有真东西垫着，才够分量。”

顾长山沉默片刻：“你是说，他把真东西藏在了假井下面，只是在假井上面下了套？”

“我得去看看。”苏荷收好薄纸，起身，“周明善留下的东西，藏了三四十年，不能再拖了。你查房管所，我去找周跛子，问问他周家老宅后花园的假井到底在什么位置。”

顾长山按住她的手腕：“明天一早我陪你去。”

“你白天不是还要去街道办报到？”苏荷笑了笑，“放心，大白天的，我还能被人绑了去？”

他眼神未松，半晌才道：“带上柴刀。”

第二日天刚亮，苏荷就拎了条烟走进周跛子修鞋的棚子。周跛子正低头钉鞋掌，抬头看见她，目光闪了闪：“苏老板有事？”

“想跟你打听个地方。”苏荷蹲下来，把烟搁在他工具箱上，“周家老宅你熟不熟？”

周跛子手里的锤子顿住，过了好一会儿才闷声道：“熟什么，那宅子早就没人住了，院子里长满草。你要找什么？”

“假井。”

周跛子的手一抖，锤子差点砸在指头上。他抬起满是皱纹的脸，眼里有一瞬的复杂：“你怎么知道那口井的？”

“周文祥留下的东西里写的。”

“文祥叔……”周跛子喃喃重复了一句，低下头，半晌才说，“假井在宅子后院东南角，老桂树底下。井口用石板盖着，上面刻了一圈莲纹。但你别抱太多指望，小时候我听大人说，那井早就填了。”

苏荷心中一动：“谁填的？”

“不知道。”周跛子摇头，“反正打我记事起，那井口就是封死的。”

苏荷点点头，没再多问，起身离开时回头看了一眼。周跛子还蹲在棚子里，没有继续修鞋，目光落在她带走的那条烟上，神色恍惚。

苏荷按周跛子的指引摸到城东周家老宅。青砖院墙被爬山虎吞了大半，门板上的锁锈得认不出原样。她推了推，门轴吃不住力，竟吱呀一声开了半边。

院子里的荒草齐腰深，东南角确实有一棵枯了大半的老桂树，树下压着一块石板，边角被泥土掩埋，只露出大片青苔。苏荷蹲下来，拨开杂草，果然看见石板边缘一圈浅浅的莲纹。

她正要用柴刀撬开石板，身后忽然传来脚步声。

“苏老板也来挖宝？”

苏荷猛地回头。一个穿灰夹克的中年男人站在院门口，双手插兜，似笑非笑地看着她——正是当初在省城街头给她递过纸条、让苏荷一直记挂的那张脸。

“是你。”苏荷直起身，手按在柴刀柄上，“你到底什么人？”

灰夹克男人没答话，目光越过她肩头落在桂花树上，缓声道：“这口井里埋的东西，不值钱。你是个聪明人，怎么也被周文祥的哑谜牵着走？”

苏荷盯着他，几个念头在心里飞速转动。这人能跟到周家老宅，说明他盯她不是一天两天了。他若也冲着井来，为何直言“井里没值钱的东西”？要么是欲擒故纵，要么——他知道真正的藏匿处。

“那你告诉我，什么值钱？”

灰夹克男人笑了笑，抬手往西边一指：“龙王庙。你去晚了，兴许什么都捞不着。”

说完他转身就走，脚步很快，眨眼间消失在巷口。苏荷站在原地，心跳狂擂，等她回过神再去追，那灰夹克男人的影子早已没入街市的喧嚷之中。

她低头看着面前那口被填死的假井，忽然意识到一件事：灰夹克的话，和周文祥遗书里的地图指向一致。她若急着撬井，反而要耽误去龙王庙的时间。

可若不撬，这口假井底下到底压着什么？

她攥紧柴刀，半晌后转身，大步朝城东老渡口走去。

# 第69章 夜袭与反杀

那人的身手不算差，但落在苏荷耳朵里，全身都是破绽。前世的油烟里泡了十几年，她的耳朵练得比眼睛还尖——一个厨子在后厨，大火爆炒的时候，身后有没有人摸过来，从脚步轻重的差别就能听出来。

来者落地时左脚先着地，右脚跟着踩实，重心压得低，显然是个练过的。但他翻窗进来之后，第一时间没有适应屋里的黑暗，在原地站了足足三秒。

三秒就够了。

苏荷翻身下床，连刀都没抽出来，直接抄起枕边那口铁锅——她从不离身的老伙计。锅底扣过去，闷响一声，那人被砸中肩头，闷哼一声往后踉跄。

“别动。”苏荷的声音压低，“再动一下，我就喊人。”

那人僵住了。不是因为她的话，而是因为苏荷紧接着说了一句话，用的是南边靠海的土话：“利丰船务的？还是张德发手下的？”

黑暗中那人沉默了很久，才开口：“你知道了多少？”

“知道得不多，但够你回去交不了差。”苏荷把铁锅换了个角度，锅沿抵住他咽喉，“利丰船务派人盯着我这个小饭馆，有意思。说吧，你们在码头卸的到底是什么货？”

那人呼吸一窒，似乎在权衡什么。过了片刻，他忽然低声笑了：“小老板，你是个聪明人。可聪明人在这个世道上活不长，除非她懂得什么该看，什么不该看。”

“不劳操心。”苏荷手上加了三分力，“我再问一遍——什么货？”

“盐。”那人终于吐出一个字。

苏荷愣了一下——盐？1988年，盐是国家专营的东西，但市面上流通量并不缺，犯不上用走私的命去换。但下一刻她想到什么，掌心一凉：“海盐？你们从南边进海盐，掺到本地盐里卖？”

那人没吭声，但苏荷从她的沉默里得到了答案。这更不对。海盐和本地盐差价有限，走量又不比糖和布，冒这么大风险图什么？除非——那不是普通的盐。

“掺了东西的。”苏荷的声音冷下来，“掺了什么？”

那人刚想开口，巷子外忽然传来一声猫叫——短促、尖锐，一听就是人学的。那人神色骤变，猛地用力挣开苏荷的锅，一翻身从窗口跃了出去。苏荷追到窗边，夜色里只看到他几个起落，就消失在巷子尽头。

她没有追。她转过身，把那人刚才站过的地方仔细看了一遍，终于在墙角的水渍旁发现一小片白色粉末。苏荷蹲下去，用指尖蘸了一点，放在鼻尖下嗅了嗅——一股极淡的涩味，带着泥土的气息，像是某种矿石的粉末。

她心里一沉。这不是盐。

她记得前世在一个老药工那里见过这种东西，那老药工说它叫“砒石粉”，人吃多了要命，少量掺在盐里提味——但在某些地方，有人拿它做别的用，做成毒药、做成成瘾的东西。这要是流进老百姓的饭锅里……

苏荷捏着那点粉末，指节泛白。她回到灶台边，把那片锡箔纸重新展开，借着炉火又看了一遍上面那行字：“五日之内，勿碰南货。”

南货——她进货的南货铺子，正好四天后有一批货要到。这不是巧合。

窗外传来打更人的梆子声，二更天了。青瓷瓶还躺在怀里，温温热。她盯着窗外黑漆漆的巷口，忽然笑了。

张德发，你还在找后手。那我就等着看看，你手上那批货到底藏着什么鬼。苏荷把粉末用纸仔细包好，塞进铁锅底下的暗格里，然后躺回床上，合上眼睛。她知道，天亮之前还有一场硬仗。

楼下的门缝里，不知何时被人塞进一张纸条。苏荷没去捡，但烛火顺着风一吹，纸条上露出两个字——

“小心。”

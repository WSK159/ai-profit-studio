# 第117章 县医院的晨

天刚亮，青江县医院的走廊里已经挤满了人。苏荷拎着一网兜苹果和一袋奶粉，穿过排队挂号的队伍，在二楼内科病房找到了苏母。

门半掩着，露出一张白得没有血色的脸。苏母比上回见瘦了一大圈，颧骨高高凸起，盖在被子下的手只剩一把骨头。苏桃趴在床边，枕着胳膊睡得正熟，脸颊上还压出几道红印。

苏荷站门口看了几秒，把奶粉放门外长凳上，轻手轻脚走了进去。苏母睁着眼，目光在窗玻璃上游移，听到脚步声转过来，看见是苏荷，眼里的光猛地亮了亮，又黯下去。

“荷儿……”声音哑得厉害，“你爹去找你了？”

“嗯。”苏荷在床边坐下，握住苏母的手。那手冰冷，指节发硬，指甲泛着灰白。她前世学过一些中医食疗，手搭在脉上，心沉了沉——胃气衰极，气血两亏，恐怕不只是普通的胃病。

“我不让他去找你，”苏母说着咳了两声，“你在城里好好过日子……别为我的事耽误了……”

“妈。”苏荷打断她，“你别说这些。我去找省城的大夫，把你接过去治。”

苏母摇头，干裂的嘴唇扯出一个笑：“治什么治……我这病，花冤枉钱。你姐弟三个，钱得留着给桃儿上学，给你哥娶媳妇……”

苏荷手指一紧。她知道苏母心里那笔账，妈可以少吃一口，闺女可以不上学，但儿子是要传宗接代的。

“哥娶媳妇的事不靠你省这一口。”苏荷把苏母的手塞回被子下角掖好，语气平静，“我挣得来。”

苏母看了她半晌，眼眶渐渐泛了红：“荷儿，妈对不住你……那年你爹要把你卖给邻村，妈拦不住……”

“行了，”苏荷岔开话头，“我跟县医院的大夫谈谈你的情况。要是转院，我去找车。”

她站起身，看了一眼睡得正熟的苏桃。十五岁的姑娘，瘦得下巴尖尖的，手里还攥着一支铅笔，口袋鼓鼓囊囊塞着一卷纸。苏荷伸手捏了捏那纸卷，抽出来一看——是苏桃用作业纸画的账本，几行歪歪扭扭的加减法，算的是家里这个月买菜、买药的支出。每一步都对，连小数点都没错。

她把纸卷放回苏桃口袋里，转身出了病房。

县医院内科值班室，一个中年男医生听完苏荷介绍病情，翻着眼皮看了她一眼：“你是家属？”

“她女儿。”

“你妈这病，县医院设备有限，做个钡餐照影还能看个大概。要是想确诊，最好去省城。”医生把病历本往桌上一推，“不过省城那边挂号排队，床位紧张，有熟人最好。”

苏荷点头：“我找人安排。”

她出来时走廊里日头已经升到树梢，阳光从窗玻璃斜斜切进来，把地上的水渍照得发亮。顾长山靠在楼梯口的墙边，手里拎着两个肉包子，看见她出来，递过来一个。

“问清楚了。我待会儿去找韩兵，让他帮联系省城第二医院，那边有他的战友在消化科。”苏荷接过包子咬了一口，肉馅滚烫，噎得她喉头发紧，“我妈的病不能再拖了。”

“韩兵那边我会去说。”顾长山看着她，目光沉沉的，“你爹昨夜回去后又喝了顿酒，说是你给了钱。”

“嗯。”

“他会不会把事情拿出去说？”

苏荷把嘴里的包子咽下去，冷笑了一声：“他知道我手里有账本，也知道沈其昌放了。他现在最怕的是我把他的事捅出去。他敢乱说？”

顾长山点了点头，没再追问。两人往楼下走，经过三楼走廊时，苏荷脚步突然顿住了。走廊尽头的长椅上，坐着一个穿灰色中山装的老头，头发花白，戴一副老式圆框眼镜，正拿着一张泛黄的旧报纸慢慢地看。报纸头条印着几个铅字——“青江市个体经济发展纪实”。

老头低头看报时，苏荷看不清他的脸。但那个侧脸轮廓，那双手——骨节粗大、虎口有烫痕——让她心跳猛地漏了一拍。

她前世在临江饭店学厨时的师父，姓周，周望海，国宴大师，退休后隐姓埋名，在青江待了十年。她找了他两年没找到的人，怎么会坐在县医院三楼的走廊里？

苏荷没说话，脚步放轻，慢慢走近。鞋底在水泥地板上发出极轻的声响。那老头像是察觉到什么，抬起头来看她。四目相对，苏荷隔着一米多的距离，看清了那双眼睛——

浑浊，沧桑，却带着一股说不清的熟悉。

“丫头，”老头开口，声音沙哑，像是许久没跟人说过话，“你手里那个网兜，是给307房的病人买的吧？她是你什么人？”

苏荷心跳如擂鼓，面上却稳得很：“我妈。大爷，您认识她？”

老头折起报纸，慢慢站起来，目光在她脸上停留了几秒，像是在看另一个人。他手指从报纸边缘探出来，隔着虚空点了一点：“你眉毛眼角，长得像你姥娘。你姥娘姓许吧？解放前，青江有名的厨娘，许凤莲。”

苏荷脑子里嗡的一声。前世，师父周望海在她临出师那天，提过一句——他年轻时，有个师妹姓许，嫁到青江，后来就没了消息。苏荷以为自己听错了，那时师父已经病重，说话含含糊糊。她再追问，师父却只是摇头，说都是过往了。

现在，青江县医院走廊里，这个老头用“许凤莲”三个字，把她两辈子的记忆炸开了。

“您是……”她喉头发紧。

老头从口袋里摸出一块半旧的怀表。表盖弹开，里面夹着一张褪色的小照片——一个扎长辫的姑娘站在灶台前，锅铲翻着，笑得眉眼弯弯。那姑娘的眉骨，和苏荷现在这张脸，像了七成。

“我姓周，”老头说，“周望海。你姥娘许凤莲，是我师妹。那年退隐前，我最后一件事就是来找她。可惜来晚了一步——她人已经不在了。”

他顿了顿，目光落在苏荷脸上：“你像她。油锅里那手功夫，也像她。我在这医院陪老战友住了三天，天天听人在楼下议论——城南巷那个年轻女老板，红油抄手做得一绝。丫头，那是你吧？”

苏荷一点一点地点头。

周望海看着她，半晌，慢慢露出一丝笑。那笑容绕过浑圆的眼尾，皱纹一层层叠起来：“走吧，带我去看看你妈。胃上的毛病，我多少也能看两眼。”

他拿起旧报纸，折好，塞进中山装内袋，错身从苏荷身边走过，那股旧报纸和樟脑丸混合的气息，让苏荷眼眶一酸——前世师父身上，就是这股味道。

她追了两步：“周爷爷——您、您认识省城二院的消化科大夫吗？”

周望海脚步一停，回头看她：“认识。我那老战友的儿子，就在二院。”他笑了笑，“也算是你师伯。”

# 第191章 一张旧车票

顾长山把那张纸展开，是一张印着“青江—柳坪”的汽车票，日期是三天前，票面的边角已经磨得起毛。

“老陈的侄子在柳坪汽车站被人见过，”顾长山压低声音，“但这个不重要，重要的是——”他翻转车票背面，那里用圆珠笔歪歪扭扭写着一行字：“库后头第二根柱子底下是空的。”

苏荷瞳孔猛地一缩。

“票是谁给你的？”

“粮库旁边有个修自行车的老头，说是三天前一个戴草帽的人让他转交的，说‘有人会来问’。我找了两天才找到那根柱子，底下垫了块砖，砖下面有个油纸包。”

顾长山没有当街打开油纸包，但他用眼神示意了一个方向。两人一前一后进了苏记小馆的后厨，苏荷把门闩上，顾长山才从军装内兜里掏出一个巴掌大的油纸包。

包里只有一样东西——一张泛黄的老照片。照片上是一座厂房模样的建筑，门口挂着一块木牌，字迹模糊。苏荷凑近了看了半天，才辨认出几个字：“红星橡胶制品厂”。背景里站着一排穿工装的人，最左边那个人的脸被磨损得几乎看不清。

“这是老陈藏起来的？”苏荷问。

“应该是。我打听过，红星橡胶厂六年前就倒闭了，厂址都拆了，变成了一片空地。但老陈在粮库看门之前，就在红星厂干了八年。”顾长山的手指点了点照片上那个模糊的人脸，“这个，我找人认过，厂里当年的车间主任，姓周。”

苏荷的心跳漏了一拍。

周建明的父亲，据说早年在橡胶厂当过车间主任，后来辞职下海做建材生意。而周建明本人如今最大的倚仗，就是手里攥着的老城区配货渠道和建材资源。

“粮库里的那三捆橡胶管，是从红星厂里出来的？”苏荷的声音平静，但指甲已经掐进了掌心。

顾长山点了点头：“橡胶管的标号是八二年产的，跟红星厂倒闭前最后一批原料对得上。也就是说——有人在六年前厂子倒闭的时候藏了一批货，一直放在粮库里，直到最近腾退的风声传出来，才试图转移。”

两人对视一眼。苏荷心里那张模糊的拼图，已经渐渐显出了轮廓。

周建明收购城南巷的商铺，表面上是为了配合老城改造拿补偿款，但实际上——如果他父亲当年留了一批货在粮库里，那批货的处置，就必须绕过粮库那一块的产权登记。而城南巷七号铺面恰好在粮库侧面，地下有一条早年废弃的排水暗沟，直通粮库后墙。苏荷第一次盘下这家店的时候，就发现那个地窖入口的位置不太对劲，像是被人专门处理过的。

“老陈是被安排走的，”苏荷缓缓开口，“他手里攥着粮食库的钥匙和存货记录，不能让人问出话来。但他在走之前留下了这张照片和那句话，说明他不想让那批货就这么白白落进别人口袋。”

顾长山沉默了一会儿：“老陈现在下落不明。他的侄子在柳坪露面，那是在老陈失踪之后——可能是被引开的。”

苏荷忽然问：“周建明现在，人在哪里？”

“一大早就去了城南街道办事处，听说他今天约了国资办的人谈粮库的临时征用申请。”顾长山眉头锁得更紧，“如果让他拿到粮库的临时使用权，那批东西从法律上就名正言顺成了他处置的资产了。”

苏荷深吸一口气，目光落在老照片上那个模糊的人脸上。如果周建明的父亲当年在厂子倒闭时瞒报了一部分原料库存——那批橡胶管放在八二年不算什么，但放到1988年，橡胶原料价格翻了接近三倍，那三捆管子少说值两千多块。在月工资几十块的年代，够让人铤而走险。

门外忽然传来一阵脚步声，紧接着是一声带笑的招呼：“苏老板在吗？我是街道办的小赵，给您送个东西。”

苏荷开门一看，小赵手里拿着一封公文纸封口的信件，上面盖着青江市城南街道办事处的红章。拆开一看，是一份《关于城南巷三号、五号铺面腾退安置的催办函》，落款时间是今天，底下还附了一行小字：请各产权人于三日内前往街道办事处协商签署，逾期将按程序申请强制执行。

苏荷抬起头，目光越过小赵的肩头，落在巷口那道正快步走来的身影上——周建明穿着一件灰西装，脸上挂着和气的笑，看见她的那一刻，嘴角勾得更深了些。

他将手插在口袋里，远远地开口：“苏老板，听说你这两天挺忙的。正好，我也有件事，想找你当面聊聊。”

苏荷把那封催办函收进袖口里，脸上也浮起一个同样客气的笑容：“巧了，我也正好有事想请教周老板。”

她侧身让出一条路，手掌向后厨的方向一引：“进来说吧。”

身后的顾长山默默把老照片收回了内兜，右手不动声色地摸了一下腰后别着的那把钥匙。

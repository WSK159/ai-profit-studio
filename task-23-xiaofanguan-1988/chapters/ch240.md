# 第240章 铜扣

腊月十九的夜，风从城南巷口灌进来，带着河滩上枯草的气味。

苏荷坐在灶间，面前摊着两张泛黄的房契——祖父苏贵山和祖母林秀英的名字赫然在目，红泥印子虽淡了，边角却一个不缺。她指尖从那行“城南巷十一号，占地三分半”上滑过，又停在那道折叠的压痕上。祖母生前习惯把两份房契叠在一起，用红绳系成十字结。苏荷记得那个结，记得祖母的手，记得祖母说过另一份房契上写的是苏桃的名字，由母亲保管，是将来给桃儿做嫁妆的底子。

母亲走了，那份房契跟着下落不明。

“姐，睡不？”苏桃掀帘子探进半个脑袋。

“再坐会儿。”苏荷把房契收进铁盒，锁好，塞进灶台底下的暗格里，“桃儿，我问你个事。”

苏桃走进来，手里攥着一块烤红薯，皮已经剥了一半，腾腾冒着白气：“你说。”

“今儿下午来的那个矮胖子，你盯着人家公文包看了好幾眼。”

苏桃低头咬了口红薯，嚼了两下，咽下去，才开口：“姐，我跟你说个事儿，你别骂我。”

“说。”

“那个公文包上的铜扣，跟咱家地窖里的铜扣，一模一样。”

苏荷的手顿住了。她看着妹妹，苏桃也回看着她，眼睛里头干干净净的，没半点糊涂。

“你确定？”

“我确定，”苏桃放下红薯，“那铜扣不是普通货。咱家地窖那个，是从一口老樟木箱上取下来的，祖母说那是她陪嫁时候的东西，民国三十六年打的。我上回在地窖里找酸菜坛子的时候看见过，锁扣磨损的纹路跟今儿那个包上的一模一样，连那种暗绿色的锈迹都对得上。”

苏荷沉默了片刻。她起身掀开地窖板，踩木梯下去。苏桃跟在她身后。地窖里阴冷，挂着一盏白炽灯，昏黄的灯泡照着墙角几张旧桌和半排坛子。苏荷蹲下去，从桌腿旁摸出一把铜扣——拇指大小，方角圆边，面上錾着一朵缠枝莲花，锈色青绿，在灯下泛着沉沉的暗光。

苏桃从棉袄兜里掏出一张纸，摊开——上面是用铅笔拓的印，纹路线条清晰，正是她今天下午趁人不注意，把那矮胖子公文包上的铜扣拓下来的。两张一比对，缠枝莲花的叶脉走向、莲瓣的弧度弧度，分毫不差。

“姐，咱家地窖的铜扣，怎么会在别人包上？”

苏荷捏着那把铜扣，指腹摩挲着莲瓣边缘，心口像被什么东西轻轻拨了一下。祖母说过：这枚铜扣是苏家祖上传下来的，太爷爷那辈在码头做过柜房先生，这扣子原是账房柜子上的铜饰，后来柜子散架了，祖母舍不得丢，收了起来。可同一批铜扣，到底打了多少个，落在谁手里，祖母没提过。

“你今天下午，除了铜扣，还看出别的没有？”苏荷盯着妹妹。

苏桃想了想：“矮胖子的皮鞋是新的，但鞋底边上沾着泥，泥的颜色发红——咱青江城里的土是黄泥，只有城南河滩那边才是红泥。他一个城里来的开发公司的人，干嘛跑城南河滩去踩一脚泥？”

苏荷眼睛眯起来。

城南河滩，荒得很，只有几户渔民搭的棚子，连路都是土路。一个省城开发公司的人，大冬天跑去河滩，要么踩点，要么……见人。

“还有，”苏桃声音低了一分，“姓何的那个城建局的人走的时候，在门槛外边站了一小会儿，回头看了一眼咱家招牌，然后问了一句：‘这铺子，翻新过没有？’”

“你怎么回他的？”

“我说，翻过，我姐自己刷的漆。”

苏荷点头。她把铜扣收进衣兜里，又把地窖板盖上，踩实了，回到灶间。炉子上坐着一锅骨头汤，咕嘟咕嘟冒着泡，香气慢慢地漫开。她盛了两碗，一碗递给苏桃，一碗端在手里。

“桃儿，明儿一早你去河滩看看，别让人发现，就装作拾柴。”

“我知道，姐。”

夜风又起了，窗棂上糊的报纸被吹得簌簌响。苏荷喝了一口汤，抬眼看向窗外的黑夜，灰茫茫的，看不到头。矮胖子的铜扣、姓何的城建局干部、发红的河滩泥、师父那句“有的锁是用刀开的”……这些东西在脑子里串成一条线，线的另一头，拴着一把还没现形的锁。

锁在哪儿，钥匙在谁手里，她还没想明白。

但有一点她清楚得很——有人已经开始动了。

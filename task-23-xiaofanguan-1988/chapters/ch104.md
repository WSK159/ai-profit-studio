# 第104章 账本上的第七个点

铁匠巷的早市还没散，苏荷便蹲在灶台前，把那本半旧的账本摊开在膝头。晨光从油纸糊的窗缝里漏进来，正落在那片墨渍上。她用指甲尖轻轻刮了刮，墨迹不是墨水，是锅灰和猪油调的，干透了，一碰就掉渣。

她屏住呼吸，一点点刮。灰屑落到账页上，底下一行小字露了出来，是沈其昌的笔迹：“白水门，三更，糙米八百斤，记账人，周。”

白水门。她翻到地图那页，七个地点用炭笔标着，她昨夜已经逐个看过。南门周诚的住处，码头仓库，粮站后院，城东水塔，铁匠巷十六号，市政府食堂后门，最后一个，挨着江堤的石灰窑。没有白水门。

她抬眼看了看墙上的钟，八点过七分。顾长山说三天内不离开铁匠巷，但账本上的东西比他的嘱咐更急。她合上账本，用布条捆好，塞进灶台底下垫锅的破瓦罐里，然后起身把围裙解开。

巷口卖油条的刘婶正收摊，见她出来，招呼了一声：“苏老板今天不做生意？”

“歇半天，去堤上走走。”苏荷笑了笑，顺手买了四根油条，用报纸包了，揣着往江堤走。

白水门不是地名，是码头边一座白灰刷的水闸门，门洞半淹在江水里，退潮时露出一截青石台阶。苏荷沿着堤走了一刻钟，远远看见那扇门——铁栅栏上锈迹斑斑，挂着一把新锁。锁是新换的，钥匙扣上拴着红绳，浸了江水，绳头还新鲜。

她蹲在台阶上，假装系鞋带，手伸到铁栅栏缝里摸了一圈。门内侧挂着个竹篓，篓里是半篓发黑的碎米，混着江泥，像是有人匆忙倒过来的。她捞了一把碎米捻开，米是新米，没沤过，只是受了潮。

有人刚在这里藏过东西，或者，取过东西。她站起身，把碎米弹回江里，目光扫过水闸上方。门楣内侧用炭笔画着一个符号——一道横杠，下面两撇，像是“三”字草写。她心里一沉。

王顺德。

她转身往回走，步子不快不慢，脑子里飞快地转。沈其昌留下的地图上，七个点对应的是七次交易。但账本上的三个墨点只标了三笔，最后那一笔，正是白水门。白水门这个名字，周诚说过，王家早年做私粮，走的就是这条水路。她前几日只当是闲话，现在想来，周诚是在提醒她。

她正低头赶路，身后一阵急促的脚步声追上来。苏荷回头，是个十四五岁的半大小子，穿灰布衫，跑得满头汗，到跟前喘着气递上一个信封：“有人叫我给你，说你在堤上。”

苏荷没接，打量他：“谁叫你给的？”

“一个戴军帽的大哥，瘦高个儿，指着我让我跑腿，给了两毛钱。”小子把信往前一递，苏荷这才接过来。信封没封口，里头一张纸条，上面写着三个字：“今晚，铁匠巷，有客。”

字迹方正，是顾长山的。苏荷把纸条攥在手心，冲小子说了句“知道了”，便折回铁匠巷。

她进了门，挂好门闩，把瓦罐里的账本重新翻出来，就着天光比对着七个地点。那半本账本一共十七页，前面记的都是日常流水，唯独最后几页记了三笔“糙米”生意，数量逐年增大，买家只写姓，不写名。第一笔买家“赵”，第二笔“孙”，第三笔“周”，白水门那一笔，却只有“王家”两个字，墨色明显更重，像是按下去的。

她盯着“王家”那两个字，手轻轻叩着桌面，心里已经有了个数。沈其昌当年替王顺德经手了三笔私粮，前两笔走的是赵和孙的名头，第三笔直接挂在王家头上。那批米经了白水门的水路，运到哪儿去了？买家不写名，偏偏后头这笔落了字。她记得前世茶余饭后听过一耳朵，八十年代中期，省城粮站出过一次大案，粮站站长与一个姓王的粮商内外勾结，倒卖陈年储备粮，那批粮经黑市流进了外省的米粉厂，后来案发，站长判了刑，王姓粮商却脱了身。

她不知道沈其昌是不是被那桩案卷进去的，但她知道，今晚来的客，多半是王顺德那边的人。顾长山特意来信，让她别走，说明来客可能是自己人，也可能，是来试探的。

她把账本塞回瓦罐，盖上盖子，又用半袋米压实，然后开始和面。傍晚时分，铁匠巷里来了个穿中山装的中年人，敲了三下门，两长一短。

苏荷拉开门。来人摘下帽子，露出一张和气脸，笑道：“苏老板，我是省城粮站的老赵，沈其昌的老朋友。他让我来取个东西，说是放在你这儿的一个瓦罐。”

苏荷靠在门框上，没让身：“沈师傅的账本，我只给他本人。您有他的亲笔条子吗？”

中年人笑纹不变，从内袋里取出一张字条，递过来。苏荷接过一看，是张借条，写着“今借到青江市苏荷同志糙米八百斤，归还期以本人当面为准”，落款是沈其昌的签名。字迹她认得，和账本上的如出一辙。

八百斤。正是账本上白水门那笔的量。苏荷眯起眼，把借条叠好，塞进自己衣兜里，侧身让开一步：“他在哪儿？”

中年人跨进门，压低声音：“市局看守所，三天后转移到省第二监狱。那条路，要经过白水门。”

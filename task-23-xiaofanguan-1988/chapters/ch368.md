# 第368章 井底另有乾坤

铁锅到手，沉甸甸的，怕有十几斤重。锅底那行字被雨水锈蚀得有些模糊，但“荷花开了，锅就到了”几个字依然清清楚楚。

苏荷用粗布把锅包了三层，抱在怀里像抱着个刚出生的娃。顾长山把井绳收了，又绕着井口转了一圈，忽然蹲下身子，伸手在井壁内侧摸索起来。

“你找什么？”苏荷问。

“这井是董家锅坊的，锅坊掌柜最讲究‘藏物三处’——明处一件，暗处一件，最后一件藏在自己眼皮子底下。”顾长山的手停住了，指尖抠出一块松动的青砖，“果然。”

他使劲一掰，青砖应声而落，砖后是个一尺见方的壁龛，里头用油布裹着什么东西。

苏荷抱着铁锅蹲过来。油布一层层打开，最里头是两样东西：一本薄薄的册子，封皮上写着《董氏锅谱》；还有一只巴掌大的铁皮匣子，已经锈得打不开。

“锅谱。”苏荷眼睛一亮，“师父当年说过，董家做锅的诀窍全在火候和铁水里，这要是传下来——”

顾长山把册子递给她，自己拿起铁皮匣子掂了掂：“里头有响声。”

“先带回去再说，天快黑了。”苏荷望了一眼铁丝网那边，采沙场的工棚亮起了灯，几点昏黄的光映在江面上，像撒了一把碎金子。

两人原路返回，路过蓑衣巷老屋时，苏荷脚步停了停。包工头正蹲在门口抽烟，见他们来了，也不起身，只咧开嘴笑：“苏老板，屋里又翻出宝贝了？”

苏荷眉头微动：“你怎么知道？”

包工头吐了个烟圈：“那老屋是我表叔的，他年轻时给好几户人家做过翻修。你这间屋，灶台下面压了三层砖，我表叔说底下还有东西，但他当时怕惹事，没敢碰。”

“三层砖？”苏荷和顾长山对视一眼。

“对，最底下那层砖颜色不对，发青，不像本地的青砖。”包工头磕了磕烟灰，“我表叔前年去世前还念叨这事，说那砖下面就砌着秘密。”

苏荷把铁锅交给顾长山：“走，再看看。”

老屋里还弥漫着淡淡的雨水腥气和尘土味。灶台是后来修葺过的，表面覆着一层新水泥，但灶脚处露出一角青砖——果然颜色发暗，偏墨绿。

顾长山找了根铁钎，沿着灶脚边缘撬了几下，那层水泥便裂开一条缝。再一使劲，整块（青砖）松动脱落，露出底下一条深褐色的油布卷。油布卷得极紧，外头用麻绳系着，绳结上挂了一枚锈迹斑斑的铜钱。

苏荷解开麻绳，油布展开，里头是一叠发黄的纸，用棉线缝在一起。最上面一页写着几行字，墨迹褪了大半，但她凑近灯下，勉强认出几个字：

“青江沦陷之际，师门重器难移，藏于——”

后面字迹模糊，只剩最后一笔拉得很长，像写的人力道渐衰，写到这里便再也没能写完。

苏荷翻到下一页，是一张手绘的地图，画着青江城的老街道。她一眼认出了城南巷的位置，再往东隔三条街，有个圆圈，圈里写着两个字：董宅。

“董宅？”苏荷低声念了一遍，“不是董家锅坊？”

“锅坊在城西，董宅在城东。”顾长山皱眉，“当年董家老宅，后来改成酱菜厂了。”

苏荷把地图收好，又往下翻，最后一页是一段小字，写的是：

“坊中老谱与秘匣已藏井中，此处所存，唯董氏三代攒下的调料方子。腐乳、豆豉、酱瓜、甜面酱，凡四十七味。若后人得之，可开酱坊。荷花记，董氏最后一代掌柜董青山，民国三十八年春。”

苏荷的手微微发抖。

这页纸上的“调料方子”四个字，与之前在灶膛灰泥里发现的药粉气味刚好对上了——那灰泥里分明混着花椒、桂皮和豆蔻的碎末，她还琢磨过为什么会有人把香料和灰泥糊在一起。

原来，老屋灶膛里的药粉气味，是当年封存这些方子时用来防虫防潮的香药。

“四十七味酱料方子……”苏荷把纸页小心叠好，重新卷进油布，“这要是拿回店里，光腐乳就能做出七八种不同口味。”

顾长山又把青砖按回去，踩了两脚压实：“这块砖先留着，别让人看出被动过。”

苏荷点头，心里却转着另一个念头：董家锅坊的锅谱、秘匣、调料方子，三样东西分散藏在三个地方，井里、灶底、老屋。董青山当年这样大费周章，必定不只是为了防贼——那年月兵荒马乱，他在藏的东西，恐怕不止是锅和酱料。

他还在藏一个秘密。

锅谱里、调料方子里、或者那只锈死的铁皮匣子里，必定有关于“荷花记”真正的来龙去脉。

而她前世师父用的那把铁铲，铲背刻着半朵荷花——铁铲来自董家，师父的铁铲来自董家，那师父，到底和董青山是什么关系？

苏荷走出老屋时，暮色已沉。城南巷那边传来几声犬吠，她抱着油布卷和铁锅，忽然听见身后传来一阵细碎的脚步声，像有人踩着碎瓦片跟了一路。

她猛地回头——巷口空荡荡的，只有一个影子闪进了墙角，快得像错觉。

但她认得那个影子的轮廓。半个多月前，草帽人送盐粒那晚，就是这个身形靠在巷口的老槐树底下。

顾长山也停下了脚步，攥紧了手里的铁钎：“有人跟着我们。”

苏荷没有说话。她低头看了一眼怀里的铁锅，锅底那行字在暮色里隐隐泛着光：

“荷花开了，锅就到了。”

花是开了，可种花的人，到底是谁呢？

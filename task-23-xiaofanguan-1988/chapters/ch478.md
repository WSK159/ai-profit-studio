# 第478章 老乔的船

黑洲的夜风从江面刮过来，带着一股子泥腥味。苏荷蹲在石塔前的石阶上，手里捏着那张旧照片，借着月光看了半晌。

照片上的年轻人穿灰中山装，身量挺拔，眉眼带着点文气，站在一条渡船的船头，身后是茫茫江水。背面那行字写着“庚午年，灯灭前夜”——字迹工整，像是用钢笔一笔一划写的。

“老乔年轻时候，还挺精神。”董老头蹲在塔门口，手里攥着旱烟杆，却没点火，“二十岁在渡口撑船，是那一带撑得最好的后生。水性也好，扎猛子能扎两分多钟。”

苏荷把照片翻过来又翻过去：“他为什么要在灯灭前拍这张照片？”

董老头没答话，旱烟杆在手里转了转，闷声道：“你还走不走？天黑透了，江上怕是要起雾。”

“你让我走，又不告诉我老乔在哪。”苏荷站起身来，把照片小心收进怀里，“十年前他来看你，你没问他？”

“问过。”董老头的声音低了些，“他说他来找一样东西，没找到。走了以后，再没来过。”

苏荷心里一动：“什么东西？”

董老头抬起眼皮看她一眼，目光浑浊：“你别问了，跟你没关系。顾长山让你别找他，你也别找了。回城里去，好好开你的饭馆。”

他说完，转身就要进塔，苏荷却在他身后开了口：“老乔是不是庚午年那艘沉船上的人？”

董老头的脚步顿住了。

江风呼呼地灌过来，把他身上那件洗得发白的褂子吹得鼓起来。他站了很久，才说：“你猜出来了？”

“猜的。”苏荷说，“你说他是庚午年沉船目击者，在渡口撑船。可照片上他穿灰中山装，料子不便宜，不是普通船工。”

董老头沉默片刻，慢慢转过身来。月光底下，他脸上那一道道皱纹像干裂的河床。

“他不是船工。”董老头说，“他是船上下来的人。庚午年那夜，船在离渡口三里外的江心沉了。他是我从江里捞上来的。”

苏荷脑子里嗡的一声。

“他是沉船上的人？那他说自己是目击者——”

“他上岸以后，怎么也不肯说自己在船上是什么身份。只说是跑单帮的贩货客商。”董老头摇摇头，“过了两年，他又来过一趟黑洲，在石塔里头待了一整夜，天亮才走。后来隔三差五来，最后一次就是十年前。”

苏荷攥紧了手里的铜钱：“他说来找的东西，是不是跟塔里的灯有关？”

董老头没正面回答，只说：“灯笼是庚午年沉船后挂起来的，挂了三十年。老乔每次来，都要在塔前站很久，盯着那盏灯看。”

他顿了顿：“灯灭那天，他来了。”

苏荷正要追问，忽然听见江面上传来一阵细微的声响——像是船桨划水的动静。她下意识望向江面，月光下，雾气正在江心慢慢聚拢，隐约能看到一条小船的影子，正不紧不慢地往黑洲这边来。

董老头也看见了，眯起眼睛望了半晌，忽然说了句：“是老乔的船。”

苏荷一愣：“老乔来了？”

董老头没答话，转身往塔里走：“我不见他。你爱等就等吧。”

他进了塔，哐当一声把木门带上了。

苏荷站在石阶上，眼看着那条小船越来越近。船上的人穿着一件灰中山装，身形清瘦，在雾气里影影绰绰的。船靠岸时，他拿着一根竹篙撑住滩头，动作干脆利落——不像六十多岁的人。

他跳下船，拍了拍衣摆上的水珠，抬起头来。月光正好照在他脸上——国字脸，眉骨高，一双眼睛黑沉沉的，带着点看惯了江水的定气。跟照片上的年轻人比，老了，但轮廓还在。

他看见了苏荷，脚步微微一顿：“你是苏记饭馆的苏老板？”

苏荷心里咯噔一声——她从来没来过黑洲，这人怎么知道她是谁？

像是看出她的疑惑，老乔扯了扯嘴角：“顾长山说的。”

“顾长山？”苏荷盯着他，“他在哪？”

老乔没急着回答，走到石塔门前，抬手敲了敲木门：“老董，是我。开门。”

塔里没动静。

老乔又敲了两下，叹了口气：“你不见我也行。我就问一句话——灯芯换过没有？”

塔里沉默片刻，董老头的声音隔着门板传出来：“换过三回。”

老乔垂着眼，像是松了一口气：“那就好。”

他转过身，对苏荷说道：“顾长山走了。走之前跟我说，要是见着你，让我带句话。”

“什么话？”

“他说，那条青砖上的字你看过了。灯灭之时，北门自开——柳氏的‘北门’，不在黑洲，在城北。”

苏荷心口一紧：“城北哪？”

老乔没说话，从怀里摸出一块油纸包的东西，递到她面前。苏荷接过来拆开——里头是一块巴掌大的青砖残角，跟她在灯座机关里找到的那块一模一样，只是在残角侧面，多了一道划痕，像是一个“北”字。

“这是顾长山让我给你的。”老乔说，“他说，等你把这块砖跟塔里那块拼在一起，就该知道门在哪了。”

苏荷攥紧那半块青砖残角，抬头再想问时，老乔已经退回了船边。

“你回去告诉老董——”他站在滩头上，月光把他的影子拉得很长，“庚午年的灯，不是我灭的。但我一直没敢说，我当年上岸以后，在江边看见过一件东西。”

“什么东西？”

老乔沉默了一阵，才说道：“一件救生衣。上头绣着一个‘柳’字。”

说完，他撑起竹篙，小船没入雾中，像从未来过。

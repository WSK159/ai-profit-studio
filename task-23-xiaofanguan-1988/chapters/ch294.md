# 第294章 夜探祠堂

灰衣老头的话像一根针，扎进苏荷脑子里拔不出来。

她站在味香居老宅门口，看着老头佝偻的背影隐入巷尾的黑暗里，手里的火折子被夜风吹得忽明忽暗。那人最后一句话还在耳边打转——“敲击者此刻正在苏家祠堂西墙挖土。”

苏荷咬了咬牙，把火折子一吹，转身就往城南方向走。

苏家祠堂她知道，在城东老街的尽头，离这里隔着大半座城。1988年的青江，入夜后街灯稀稀拉拉，柏油路上偶尔驶过一辆自行车，铃铛声被风拖得老远。她走得很快，灰布鞋踩在青石板上发出细碎的响声。

一路无话，她的脑子高速转动。

灰衣老头承认铜钥匙是他放的，却否认取走过账册。这说明苏家祠堂西墙的砖洞里，当年至少有过两拨人——一拨放钥匙，一拨取账册。而今晚，第三拨人在挖土。

苏荷从后街绕到祠堂侧面的矮墙，贴着墙根蹲下。祠堂年久失修，墙皮剥落得厉害，有一块地方果然传来轻微的刨土声，“沙沙沙”，像是有人用铁器在抠砖缝。

她屏住呼吸，从墙缝里望进去。

月光下，一个穿灰夹克的身影跪在西墙前，手里攥着一把短凿，正在一块青砖边缘慢慢撬动。那砖已经被启开了一大半，露出黑黢黢的洞口。那人侧脸的轮廓被月光一照，苏荷猛地攥紧了拳头——是之前跟踪过她的那个灰夹克男人。

男人撬开青砖，伸手往洞里摸了一把，动作明显顿住了。

他抽出手，指尖空空，什么也没摸到。喉咙里挤出一声低哑的骂，像个被踩了尾巴的猫。他又摸了一次，甚至把整条胳膊都探了进去，洞口的砖灰簌簌往下落。

没有东西。

男人慢慢抽回胳膊，在原地跪了半晌，忽然低声说了句：“到底谁拿走了？”

苏荷的背贴着墙根，心跳如鼓。

她早就知道里面没有账册——灰衣老头说了，他到的时候砖洞就是空的。可这男人不知道。他今晚来，说明他确信账册本该在那里，或者他在等别人先动手，再过来截胡。

男人站起来，拍了拍手上的灰，正要转身，苏荷矮身一缩，整个人隐入墙根下的阴影里。那人从侧门出来，脚步朝东走去，没发现她。

苏荷等他走远，才从阴影里出来，猫腰钻进了祠堂院子。

西墙砖洞里空荡荡的，她伸手摸了摸洞壁，指尖触到一层干透的灰渣。洞太干净了，干净得不正常——如果是被人撬过，至少会有碎砖或泥屑残留；可这个洞里干干净净，像是被人用布擦过。

有人清理过这里。而且是在灰衣老头到之后、今晚之前。

那会是谁？

她低头去看被撬开的青砖，发现砖缝里卡着一小片泛黄的纸角，不仔细看几乎发现不了。苏荷用指甲把它抠出来——湿的，边缘还带着潮气，像是刚从什么湿润的地方带出来，卡在砖缝里没多久。

纸片上用铅笔写了半个字，下半截被撕掉了。

苏荷举到月光底下一看，是个“檐”字。

她脑子里“嗡”了一下。又是檐？之前在城中老宅柴房的湿纸片上，也出现过这个字。两片纸，同一个字，不会是巧合。

她把纸片小心收进衣袋里，又回头看那个砖洞。洞口内侧有一道浅浅的痕迹，像是被什么方形物体长期压出来的棱印——账册确实曾经放在这里。

苏荷盯着那个空荡荡的砖洞，忽然想到一个更让她后背发冷的问题：灰衣老头说，他到时砖洞是空的。可那老头究竟是什么时候到的？十年前？五年前？还是上个月？

如果他早就知道是空的，为什么到现在才告诉她？

她正准备起身离开，忽然听见身后传来一声轻微的响动。苏荷瞬间僵住——那是鞋底踩在枯叶上的声音，极轻，极克制，就在她身后三丈以内。她没有回头，手指已经悄悄伸向腰间那把随身带的剔骨小刀。

身后的人先开口了：“你来得比我想象的慢。”

是个女人的声音。低沉，沙哑，像砂纸磨过铁皮。

苏荷缓缓转过身。月光下，祠堂西廊的柱子旁站着一个穿蓝布褂子的女人，四十来岁，瘦，脸上有一道旧疤从左眉梢拉到颧骨，被月光一照，像条浅蛇。她手里拎着一把铁锹，锹头沾着新土。

苏荷盯着那把沾泥的铁锹，声音很稳：“你挖了什么？”

女人笑了一下，笑意没到眼底：“你猜。”

# 第278章 三号仓的烛火

门外那三声重击像擂在心口的鼓，一下一下沉闷有力。苏荷全身紧绷，目光死死盯着那道旧铁门。可惜她满头的冷汗也流得一清二楚，后背的衣裳已经湿透。

周明善却纹丝不动，连眼皮都没抬。他像是早就料到有人会来，枯瘦的手慢慢从怀里摸出一根蜡烛，划了根火柴点上。火苗蹿起的那一刻，门外那道嘶哑的声音又响了起来：

“周师父，你果然还活着。”

周明善掌着烛火，淡声说：“文起，进屋说话。”

门外沉默了片刻。铁门被推开一道缝，泄进来的风把蜡烛吹得东倒西歪。苏荷看见进来的人——五十来岁的男人，一张脸像被刀劈过似的棱角分明，穿一件藏青中山装，扣子扣到最上面一颗，袖口磨得发白，却透着一股说不出的板正劲儿。

他进门以后没看苏荷，也没看顾长山，只直直地盯着周明善，看了很久，才从牙缝里挤出一句：“周师父，您欠我爹一条命，您还记得吗？”

苏荷心头一跳。宋文起——这个名字她之前听过。钱岐黄遗言里提到过中间人，周文斌也说起过宋家的事。看来眼前这位，就是宋文起本人了。

周明善把蜡烛放在旁边的木箱上，火光映着他沟壑纵横的脸。

“你爹宋成业，是替我挡了一刀才死的。”周明善说，“那一刀本该捅在我心口上。民国三十三年腊月，青江码头，为了一船走私盐。”

宋文起的嘴唇抖了抖，半晌才说：“我爹临终前只留了一句话——‘周明善欠我的，他自会还。’然后他就咽了气。我找了你四十年，周师父，我找了你四十年。”

周明善缓缓点头，伸手从怀里摸出一个布包，递出去：“这是你爹当年让我替他保管的东西。文起，我今天把它还给你。”

宋文起双手接过，手指一直发抖。他打开布包，里面是一枚半旧的银壳怀表，表盖上刻着一个“宋”字。他翻来覆去看了两遍，忽然蹲下去，把脸埋进手里，肩膀一耸一耸地颤抖起来。

苏荷和顾长山对视一眼，谁也没说话。地下室里只有蜡烛燃烧的噼啪声，和宋文起压抑的抽泣。

过了好一会儿，宋文起才站起来，用袖子狠狠擦了一把脸。他眼神复杂地看了看苏荷，问周明善：“这两位是？”

“我徒弟。”周明善说，“从今往后，苏记小馆的掌勺人。”

宋文起又看了苏荷两眼，目光里带着挑剔和审视。但到底是给周明善面子，他没说什么多余的话，只把怀表揣进怀里：“周师父，这条命的事，今天算是了了。”

他说完转身就走，走到门口时停了一瞬。

“不过有一件事我得提个醒。你给了我这块表，你欠我家的就算清了。但汤家那十三条命，还压在你自己头上。祠堂那封信，你打算什么时候让人去取？”

苏荷手里的手帕被攥得透湿。信——果然有信。

周明善沉默了一会儿：“该取的时候自然会取。”

宋文起点点头，没再多说，跨出门外，三号仓的旧铁门砸回来，在寂静中发出一声沉闷的回响。

苏荷盯着那扇门看了三秒，转头问周明善：“师父，这位宋先生，跟汤家有什么关系？”

周明善吹熄了蜡烛，火光一暗。黑暗中，他的声音苍老而疲惫：“宋成业的姐姐，嫁进了汤家做二房。宋文起，管汤文渊叫一声表舅。他找了我四十年，一半是为了他爹的怀表，另一半——是为了问清楚，他表舅一家，当年究竟是怎么死的。”

苏荷心里一沉。

她刚想再问，周明善却摆摆手：“今晚就到这儿。你手里的第四把钥匙，先收好。明天傍晚，去汤家祠堂西墙，从南边数第五块青砖——你一个人去。取完信，看完就烧，一个字都不能留下。”

他顿了顿，补了一句：“记住那句话——带钥匙，别带命。”

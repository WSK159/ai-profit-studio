# 第330章 灶下取骨

天没亮透，城南巷的雾气还没散尽，苏荷已经蹲在周家老宅的灶台前，手里攥着一根铁丝，往灶膛里捅了捅。

昨夜她翻来覆去没睡踏实，脑子里翻来覆去就一句话：师父说过，养鱼骨的人，会把骨头藏在最贴身的地方。灶台是做饭的地方，也是火气最盛的地方，活人不敢碰，死人不敢近——可偏偏有人反着来，把东西埋在灶眼底下，日日用烟火熏着。

苏荷回头看了一眼站在门边的顾长山：“你守着外头，有人来就咳嗽两声。”

顾长山点点头，没多话，转身往外走。他向来这样，不问为什么，只问她需要什么。

灶膛里积了厚厚一层灰，苏荷把灰扒开，露出底下铺着的青砖。她一寸一寸地摸过去，在一块砖的缝隙里摸到一道细痕，像是被什么锋利的东西划过。她撬开那块砖，底下露出一个巴掌大的凹槽，里面躺着一只油纸包。

油纸包得很严实，裹了三层，拆开最后一层时，一股淡淡的腥气扑面而来。里面是一根鱼骨，拇指长，弯曲成半弧形，尖端泛着一层暗红，像被什么浸过——和她从泥人肚子里掏出来的那枚一模一样，只是颜色更深。

苏荷把鱼骨攥在掌心，触感冰凉，像握着一块冰。她忽然想起师父当年说过的话：“鱼骨认主，落在旁人手里，是会咬人的。”

她正要把油纸重新包好，忽然发现油纸背面写着一行小字，是毛笔写的，字迹娟秀，像女子的笔法。

“七月十五，子时，城隍庙西墙，埋骨处。”底下落款是个“金”字。

苏荷心跳漏了半拍。金——金桂氏。她想起泥人后背刻的那三个字，又想起那张油纸地图上标注的第三处位置：城隍庙附近。今日是七月初九，离七月十五还有六天。

她正蹲在灶前琢磨，外头忽然传来自行车的铃铛声。紧接着，顾长山的咳嗽声响起。苏荷动作极快，把鱼骨用油纸一裹塞进怀里，又拿灰把凹槽填平，砖头按回去，起身拍了拍围裙上的灰。

门帘一掀，进来的是马队长。

他穿着旧军装，袖口卷到肘弯，手里夹着一根烟，目光先是扫了一圈灶台，然后落在苏荷身上，皮笑肉不笑：“苏老板来得早啊。”

“马队长也早。”苏荷掸掸手上的灰，“这儿还没拆，我过来取点东西。”

“取东西？”马队长眉毛一挑，“取什么？”

苏荷指了指墙角那口破铁锅：“那口锅，当年我摆摊用的第一口锅。听说这屋要拆了，我想把它带回去留个念想。”她说着，走过去拎起那口锅，锅底积着灰，铁锈斑斑，看上去确实像是老物件。

马队长盯着那口锅看了两秒，又看了看她刚才蹲过的灶台方向，忽然笑了一声：“苏老板是个念旧的人。”

“人不念旧，怎么记得住来路？”苏荷把锅往肩上一扛，“马队长吃早饭没？回馆子里，我请你吃碗面。”

马队长没接话，目光却在她身上停了一瞬。他看见她的围裙口袋微微鼓起来一块，但没说什么，只是掐灭烟头：“行，下次有空。”

苏荷从老宅出来，顾长山推着自行车在巷口等她，见她出来，低声问：“得了？”

苏荷点了下头：“回馆子再说。”

两人走出巷子，拐上大路，晨光已经铺满了半边街，早点摊的蒸笼冒着白气，卖油条的吆喝声远远传来。苏荷把那口铁锅挂在车后座上，自己坐在车杠上，顾长山蹬着车，风从耳畔吹过。

她没说话，心里却翻来覆去地想着一件事：那油纸上的笔迹是女人的字，落款是“金”。金桂氏。泥人后背刻着金桂氏，油纸上写着金桂氏，而城隍庙西墙，埋着第三枚鱼骨。那金桂氏到底是谁？是师父的故人，还是师父的前人？

她下意识摸了摸怀里的油纸包，忽然发觉指尖摸到油纸内层有一道凸起，像是什么东西嵌在纸层中间。她把油纸掏出来，一边挡着风一边用手指夹开——纸层里夹着一根头发，乌黑的，绕成一个小小的圈，用红线捆着。

头发缠红线。苏荷心头一跳。这是旧时替人牵线的做法，也叫“结发”——

她正发愣，车子忽然刹住。顾长山偏过头：“到了。”

苏荷抬头，苏记小馆的红漆招牌在晨光里亮着，门半开着，苏桃站在门口，手里攥着一封信，脸色煞白。

“姐……”苏桃的声音发颤，“有人从门缝里塞了封信，上面写着你的名字。”

苏荷跳下车，接过那封信，没落款，只在正中写了两个字：苏荷。她拆开信封，里面是一张白纸，折了三折，上面只有一行字，用毛笔写的，字迹歪歪扭扭，像是故意伪装的。

“七月十五，城隍庙，别带别人来。否则你就见不到你想见的人了。”

信的末尾，画了一个极小的图案。苏荷盯着那图案看了两秒，瞳孔一缩——那是一条鱼，弯弯的，像一枚鱼骨。

她把信纸收进怀里，面上不动声色，转头对苏桃笑了一下：“没事，你先去开门，把面醒上。”

苏桃看看她，又看看顾长山，欲言又止，还是转身进了屋。

苏荷站在门口，晨光落了她一身，想起师父说过的另一句话：“鱼骨之争，从来不是两个人的事。沾了血的东西，迟早要还的。”

她摸了摸怀里的鱼骨，指腹沾到那抹暗红，有些发黏，像是刚刚才干透的血。

还没到七月十五，可她知道，自己已经被写进了这张网里。

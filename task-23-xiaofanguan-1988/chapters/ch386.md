# 第386章 灶底三砖

脚下的青砖覆着一层细密的盐碛，在煤油灯昏黄的光线下泛着淡淡的霜白，像是冬天玻璃窗上凝出的冰花。苏荷蹲下身，指尖轻轻掠过砖缝，触到那层颗粒感时，指尖微微一麻——这绝不是普通的潮气凝结。盐碛厚薄均匀，只有长期接触高浓度盐分的东西才会留下这样的痕迹。

顾长山已经把手电筒调暗，半跪在她身侧，压低声音：“底下有人？”

那规律的挖土声隔着一层夯土传来，钝而闷，像是什么人在用铁锹一铲一铲地挖。节奏不急不缓，带着一种近乎偏执的耐心，和西厢房外夜风的呜咽混在一起，若非站在砖上根本听不真切。

苏荷凝神听了一会儿，压低嗓音：“挖得很深了。但方向不对——”

她的手指在砖面上轻轻画了一道线：“声音落在西边墙角的方向，离这里至少有五六步。如果灶底三块砖下真有东西，那人挖错了地方。”

顾长山没说话，只抬眼看了看她，目光里带着疑问：你怎么知道挖错了？

苏荷没解释。她指尖摩挲着砖面上那层盐碛，脑子里翻涌的是师父当年在灶台前教她认盐时说的话：“盐这东西，吸潮、渗气、留痕。你往哪儿藏过盐，三年后那地方的砖缝里都能抠出白霜来。记住，顺着盐味找，比顺着人心的谎话要准得多。”

她抬头环视这间西厢房。董家老宅荒废多年，但西厢房被董青山重新修葺过——一角的青砖颜色比周围略深，铺得也较齐整，显然是新近翻起的。她循着砖缝间盐碛的浓淡，一寸一寸地看过去，终于在东墙根灶台残基前三块青砖那里停下来。那三块砖的盐碛明显比别处更厚，砖缝里还嵌着一点暗褐色的东西——像是经年的血渍混着桐油。

“长山，过来搭把手。”

顾长山没多问，直接走到她身侧蹲下，铁钎尖抵住砖缝，手腕一压。青砖微动，却不升起。苏荷心里一动，伸手按上砖面，往下一压——三块青砖竟然是活的，整整齐齐地陷下去一寸，像一扇暗门。

砖下是一根锈迹斑斑的铁棍横闩，闩上穿着一枚铜钱。她把铜钱翻过来，借着煤油灯的光看清楚了：乾隆通宝，背面刻着一个极浅的“苏”字。她的心像被什么东西轻轻撞了一下，喉头紧了紧。

“这个‘苏’字……”顾长山也看见了，眉头微皱，“是你家的姓？”

苏荷没答。她把铜钱在指尖转了一圈，放回铁棍上，示意顾长山拉闩。顾长山双手握住铁棍，一使力，合叶发出一阵沉闷的呻吟，底下一方狭小的土穴露出来——三尺见方，大约四尺深，内壁涂着厚厚一层桐油，洞口处铺着稻草，稻草下压着一本油布包裹的册子。

苏荷探手把册子取上来。油布拆开，内里是一本装订用麻线的蓝布面册子，封面没有字，扉页上只有一行行书，笔迹苍劲：

“董家灶，起于庚子年。每日寅时生火，酉时封灶，风雨无阻。灶底埋炭，炭下埋灰，灰下埋账。账在灶在，账亡灶亡。”

落款是个“董”字，笔锋却让苏荷浑身一震——那一捺收笔微微上挑，末端带着一个回锋勾，和她在前世师父手札里见过的落款一模一样。她的手指轻轻抚过那个字，指尖微颤。

小穴底部，稻草下面不起眼的位置，她摸到一块硬邦邦的东西——巴掌大，沉手，用油纸裹得严严实实。拆开来，是一块黑漆漆的铁片，约莫一指厚，边缘打了两个孔，像是什么器物上拆下来的零件，铁面上刻着一道极细的纹路，像一条游走的蛇线。

她认得这东西——她前世师父书房案头镇纸下压着的那块铁片的另一半。

“咚——”

洞穴深处又传来一声闷响。这次近了很多，像是那边的人挖通了什么。顾长山霍然站起身，手电筒光柱扫向西边墙角，那边的夯土墙面已经裂开一道蛛网般的细缝，一粒一粒的黄土正顺着裂缝簌簌往下落。

裂缝正中，嵌着一截铁钎尖头。那铁钎的柄上缠着红绳——和他们手里那根一模一样的红绳。

墙外传来一个沙哑的声音，带着笑意：“找到了。”

苏荷猛地攥紧手中铁片，与顾长山对视一眼，两人同时屏住呼吸。

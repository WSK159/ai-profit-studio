# 第102章 破庙夜话

月光从屋顶的破洞漏下来，照在苏荷脸上。

她蹲在一座废弃的土地庙里，背抵着冰凉的泥墙，怀里紧揣着那半本账。呼吸还没喘匀，巷外的狗叫就追到了近处。

“分头搜！”有人压低嗓子喊，“那丫头跑不了多远！”

苏荷攥紧了袖口里那把剔骨刀。刀是周诚临别时塞给她的，刃口还带着细碎的豁口，像跟着主人吃了半辈子苦。她听着脚步声从庙门口经过，靴底碾过碎瓦砾的声响，一下一下，像在踩她的心口。

“东边巷子没有！”

“西边也没有！往河沿找！”

声音渐渐远了。苏荷缓缓吐出一口浊气，额头上的汗滑进眼里，涩得发疼。她没敢动，又等了足足五炷香的工夫——大约半小时，直到四下彻底安静，月亮爬到中天，才从庙后的塌墙里钻出来。

青江的夜风裹着河腥味，吹得她脊背发凉。

她把账本贴身藏好，沿着河沿的背光处往城南走。裤腿被露水洇湿，鞋底磨得快穿，但脑子一直没有停。

周诚说的话在她耳边转了一夜。

“那批米是定案的证据，但账只是引子。真正要命的是，王家用这笔钱买通了市里两层的关节，如今局里从上到下都是他的人。你一个小姑娘，拿一本账，斗不倒他。”

“那怎么办？”她当时问。

周诚看了她很久，老花镜后面的眼珠浑浊却锐利：“你还记得你师傅当年怎么教你的？——菜要一步一步做，火候到了，自然熟。急不得。”

这话她懂。可火候不是她一个人能掐的。

城南巷口的路灯亮着一盏，拉出长长的影子。苏荷走到“苏记小馆”门口，老旧的木锁上还留着她走之前挂的那把铜锁，锁面磨得发亮，像是被人摸过。她皱眉，蹲下看了一眼——锁芯有撬过的痕迹，没撬开，但在锁梁上留了一道极细的刮痕。

有人趁她不在，来过了。

正想着，门缝里突然传出窸窣响动。苏荷心一紧，贴着门板侧耳细听，里面传来压抑的咳嗽声，然后又像是翻动纸张的声响。

她将钥匙插进锁孔，轻巧一转，推门而入。

堂屋里点着一盏煤油灯，昏黄的灯光下，苏桃趴在她平日里记账的桌案上，手里攥着半截铅笔，听到响动猛地抬头。看见是苏荷，小姑娘眼一红，扑过来就抱住了她的腰。

“姐——”声音发抖，“你吓死我了……他们说城里有人找你麻烦，我睡不着，就偷偷跑回来看店……”

苏荷动作一僵，低头看看妹妹脏兮兮的小脸，头发乱糟糟，衣领上还沾着灶灰。她伸手揉了揉苏桃的后脑勺：“傻丫头，你不在学校待着，跑回来做什么。”

“我怕。”苏桃闷声说，“我怕你也像爸妈那样不回来。”

苏荷心口像被人攥了一把。她蹲下来，与妹妹平视：“姐不会不回来。姐就是死，也死在这条巷子里，哪都不去。”

苏桃点头，吸了吸鼻子，忽然想起什么似的，从怀里掏出一封信：“对了，今天下午有个四十多岁的男人来店里，说要找你。我说你不在，他就留了封信。他——”妹妹皱起眉，“他左脸上有一条老长的疤，像蜈蚣。”

苏荷眼神一凝。

带刀疤的同行人。

她接过信，借着煤油灯拆开来。信纸是普通的方格纸，上面只写了一行字，字迹方正有力，像当过兵的人写出来的：

**“那批米的买家，我找到了。明日子时，老桥桥头，带上账。”**

没有落款，没有抬头。

苏荷盯着那行字看了半晌，指节微微发白。

她记得这个人——在去省城的火车上，他们并排坐过，他帮她挡过一次乘警的盘问。后来在周诚门口，此人也在。他没有恶意，但底细不明。

“姐，这上面写的什么？”苏桃问。

苏荷把信叠好，塞进贴身口袋里，笑了笑：“没什，一个老朋友约姐谈事。”她摸了摸妹妹的脸，“你去里屋睡，姐在外面再待会儿。”

苏桃犹豫了一下，还是乖乖地进了里屋。门轻轻合上，苏荷独自坐在堂前。

她翻开那半本账，借着煤油灯的微光，一页一页地看。周诚的字迹苍劲，每一笔都落得郑重。终于，她翻到中间某页，动作停了一下——

那页上压着一个墨点，像是有人用笔尖在纸上停顿了许久。墨点正巧落在“进”字的下方，那个“进”字的最后一笔，比前面的笔画略深半寸，像写的人犹豫过，最终还是一笔落定。

苏荷盯着那个字看了很久。她慢慢把账本合上，目光掠向窗外。

黑压压的夜，像一口倒扣的铁锅。

她想起前世，2026年，她在米其林后厨做那道她师父教她的“金汤绣球”，老厨师站在她旁边说：“小荷，做菜跟做人一样，有些步骤不能跳。该熬的汤，火候不到，再好的料也是白搭。”

她曾以为那只是一句关于厨艺的教导。

现在她明白了。

那个墨点，是师父周诚留给她的暗号——**那一页，还有“进”字，指向了一个人名。** 她翻开账本首页，那页记录了第一笔入库记录，经手人一栏清清楚楚写着三个字：

**顾长山。**

苏荷的手，僵在半空。

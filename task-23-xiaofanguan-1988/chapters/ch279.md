# 第279章 西墙第五块青砖

第二天傍晚，青江市落了一场小雨。苏荷撑着伞出门时，门口坐着的老猫连眼皮都没抬。

汤家祠堂在城西老街上，朱漆门斑驳得只剩底下的木色，门楣上“汤氏宗祠”四个字倒是还清晰。门口有个上了年纪的看门老头，正靠在门槛上打盹，听见脚步声才半睁了一只眼，咕哝了一句“祭祖的日子还没到”，又闭上了。

苏荷没接话，绕到祠堂西墙外。墙根长满了青苔，雨水顺着瓦檐滴下来，在砖缝里汇成细流。她从南边开始数，一块、两块、三块、四块——第五块青砖。

她蹲下去，试探性地按了按砖面。砖纹丝不动。她又往左右两侧推了推，还是没有动静。苏荷吸了口气，想想周明善的话，她把伞搁在地上，从腰后摸出那把花心整片做成的钥匙，用钥匙尖试探着去撬砖缝。

咔哒一声细响。青砖松了。

苏荷把砖抽出来，伸手探进背后那个黑洞。指尖触到一个牛皮纸信封，封口用红蜡封着，蜡印是一朵五瓣梅花。她刚把信抽出来，祠堂门里忽然传来一个声音：

“姑娘，你拿的是周家的信吧？”

苏荷背脊一寒，猛地回头。

门口站着一个瘦高男人，五十岁上下，穿一件半旧的灰色夹克，撑着一把黑伞，站在雨中一动不动。他脸上有一道疤，从右边眉梢一直划到腮帮子。苏荷的目光落在疤上，心头猛地一跳——幸福饭店，疤脸男。

“你是谁？”她警觉地问，手里把信往袖口里一塞。

疤脸男没有靠近，只是站在檐下说了一句话：“你不用怕我。我来这儿，只是想告诉你一句话：信，别拆——等你见过账册撕去的那一页再拆。”

苏荷浑身的血都往头上涌：“什么账册？哪一页？”

疤脸男退了一步，转身往雨里走，声音飘过来：“苏老板，你知道周明善为什么住在金钩巷七号地窖里吗？一个国宴大师，放着好好的日子不过，躲在老鼠洞里四十年。你要真想接他的班，就去查明白一件事——那个叫初七的人，发过什么毒誓。”

他走了。

雨越下越大。苏荷攥着那封烫手的信站在祠堂墙根，雨水顺着她的发丝滴落。她听见自己心口咚、咚、咚地跳——初七。账册撕页。疤痕。毒誓。

周明善让她看了信就烧，可疤脸男让她别拆、先查账册。两条路摆在她面前，一条是师父指的路，一条是陌生人的话。

她低头看了一眼信封上的五瓣梅花印。这个记号，她在金钩巷七号的墙上见过——五瓣梅花的含义，她还没解开。

苏荷把信贴身收好，没有拆。她决定先回去问周明善一句话：初七是谁。可等她顶着雨赶回金钩巷七号，推开地窖门时，里面空无一人。蜡烛烧秃了，木箱上的旧军服还在，周明善的那个小板凳翻倒在地上，旁边落着一张纸条，上面两个字的字迹她认得——正是周明善的笔迹：

“速走。”

苏荷蹲在空荡荡的地窖里，听着屋外的雨声，忽然明白了师父那四个字的意思：别来寻我。

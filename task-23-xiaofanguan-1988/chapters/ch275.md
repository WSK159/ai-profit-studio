# 第275章 缸中物

夜半。金钩巷七号的灶间里只点了一盏煤油灯，火苗被门缝透进来的风吹得摇摇晃晃。

苏荷把那枚梅花铜钥匙放在案板上，和之前从灰鸽子脚上取下的那只铜扣并排放在一起。两只铜件的花纹如出一辙，一个花心实心，一个花心镂空。透过镂空的空隙，能看到铜件内侧刻着一行极细的字。

她凑近灯下辨认——老花镜没带，顾长山便拿过一支针尖，拨开灯花，把光亮调大些。

“……汤文渊，养于周氏之厨，庚申年正月藏物。”顾长山念出那几个字，嗓音低沉，“汤文渊是收养的？”

苏荷拧眉：“周福说的，宋文起是汤家后人。宋文起说他爷爷是汤文渊，可汤文渊是养子？”

“养在周家，姓却冠了汤。”顾长山慢慢合上那枚铜钥匙，“也就是说，汤家十三口的命债，也许根本不是周家欠汤家的——是汤文渊一个人欠下的。”

这句话像一颗石子投进深潭，泛出一圈一圈说不清的涟漪。苏荷没急着接话，她围着那口水缸转了一圈，蹲下身，用手指抚过缸底那处撬过的旧痕，又从怀里掏出那本《味香余录》，翻到夹着记号的那一页。

手记上用毛笔画了一幅灶间俯视图，水缸的位置画了个圈，圈下写了一行小字：“缸中物，不安于水缸，安于人心。开门不见门，见缸则见门。”

“缸中物，不是藏在缸底，”苏荷低声说，“是这口缸本身，就是门？”

顾长山走过去，双手扣住缸沿，试了试分量，没搬动。他换了姿势，从侧面发力，往左旋了半圈——没有动静。往右旋——土层底下传来一声沉闷的摩擦声，像是什么东西被推动时的摩擦声，又像是一扇石头的暗门擦过砂砾。

苏荷立刻举起煤油灯凑过去。缸体没动，但缸底的青石板向外错开了一道细缝，缝里吹出一股干燥的风，带着陈年的尘土气。

“缸底的石板是活的。”顾长山把手伸进去，探到石板边缘一个豁口，正好卡进那把梅花铜钥匙的形状。他抬头看苏荷，苏荷点了一下头。

钥匙插进豁口，咔嗒一声，像是在石制的锁芯里转动了一圈。紧接着，缸底整块石板缓缓下沉，露出一段向内倾斜的台阶，黑洞洞的，从深处涌上来一股霉味和油脂味——那种味道，苏荷一下子就想起来了：青瓷罐里的油脂味，一模一样。

“地窖。”苏荷把煤油灯举在前面，“我下。你殿后。”

顾长山没有反驳，从腰间抽出一截皮绳，将另一头递给她：“系上。”苏荷接过来在腰间绕了两圈，打了个死结，然后侧身踩着台阶往下走。

台阶不长，一共十二级。到底后，借着灯光可以看到四面都是砖墙，墙角堆着几只霉烂的麻袋，地面铺着不规则的碎石。屋角有一口半人高的陶缸，缸口封着木板，用铁钉钉死，木板上贴着一道发黄的符纸，上头的朱砂字迹已经模糊得看不清了——但能认出一个字，一个“封”字。

苏荷用手电照了一圈，然后走到缸前，用刀尖挑开符纸，撬掉铁钉，推开木板。

缸里没有东西。

缸壁内侧光光的，只在缸底中央放着一只巴掌大的牛皮小包，包口用麻绳缠着死扣，绳结上系着一枚小木牌。她解下木牌凑近灯光，上面刻着一行字：

“汤家祠堂西墙，第五块青砖之后。取之则债清，不取则债重。”

苏荷的心猛地一沉——汤家祠堂，在青江市西郊。而现在，那里早就改成了街道办的仓库。

她还来不及细想，头顶上方传来顾长山的声音，低而急促：“有人来了。”

苏荷一把抓起牛皮小包，塞进怀里，转身顺台阶往上。顾长山已经把青石板推开一半，一把伸出手把她拉上来，然后迅速把石板复位。缸底咔嗒一声归了原位，铜钥匙还卡在锁孔里拧不出来——只能留在里头。

院门外传来脚步声，不是一个人，杂乱而稳健，像是四个人并排走。接着，有人在门板上敲了三下，声音沉闷而熟悉——和上次夜里在周家旧宅听到的那三下敲击一模一样。

顾长山把苏荷拉到身后，手按在腰侧。门外一个人开口了，声音带着笑，温和得像闲聊：“苏记的苏老板，青江城里传遍了你的手艺。我想替一个人问问你——你手里那本手记，末页写的那行字，到底是‘债’还是‘命’？”

苏荷没有回答他。她低头看了一眼怀里那只牛皮小包。

麻绳的活结不知什么时候松开了，包口露出一角叠得整整齐齐的纸，纸边上有一截墨迹。她展开一看，白纸黑字，上头只有一行字：

“汤文渊亲启。汝之债，非死可偿。”

字迹苍劲有力，落款只有一个字——周。

而周明善，字明心。

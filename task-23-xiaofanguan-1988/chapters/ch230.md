# 第230章 三味火的秘密

苏荷把那片褐红干料凑到鼻尖，一股陈年药香混着烟熏气直冲脑门。她认出来了——这是陈皮，但绝不是普通的陈皮。橘皮表面那层细密的油室像鱼子一样饱满，年份至少二十年往上，而且……她舌尖轻轻一舔，咸的。

“咸陈皮？”她皱起眉头。

“九制。”钱岐黄靠在病床上，枯瘦的手指敲着床头柜，“陈皮九蒸九晒，中间用老盐卤过三遍，再用松枝慢火焙。这是当年国宴上做‘龙井虾仁’用的秘料。你师父——”老头顿了一下，“你师父他偷师的时候，少学了一道工序，所以他的虾仁总差一口气。”

苏荷心里一紧。她前世的师父从来没提过什么师兄弟，练了三十年灶上功夫，到死都在遗憾自己做的虾仁不够“透亮”。原来那口气在这里。

“老先生，”苏荷把油纸包仔细收好，“您和我师父……”

“旧事了。”钱岐黄摆摆手，“你师父叫赵德厚，对吧？这间铺子就是他民国三十七年盘下来的。他走之前把这间铺子托给我照看，说等有缘人回来。”老头浑浊的眼睛盯着苏荷，“你屋檐下那盏灯，用的是他留下的火种。”

苏荷脑子轰地一响。那盏灯！她刚盘下铺子时嫌灯太旧，本想换掉，是顾长山说“老物件有灵性”，这才留了下来。灯芯从来不用火柴点，而是用一块火石打出的火星引燃——她一直以为那是穷讲究，现在才明白，火石里夹着的东西，可能就是赵德厚留下的“火种”。

“三味火，第一味是陈皮引火。”钱岐黄的声音低下去，“第二味是骨——要你铺子里那口铁锅，用猪骨熬七七四十九天，把锅壁的油膜养透。第三味是心——”他忽然咳嗽起来，护士推门进来要赶人，苏荷只好起身告辞。

回铺子的路上，苏荷心跳得厉害。赵德厚，民国三十七年，国宴大师，前世师父——这些线索串在一起，她隐约摸到一条线：这间小铺子背后藏着一个师门的传承，而钱岐黄只是守门人。真正的钥匙，还在她手里——那口铁锅。

铺子门口，苏桃正蹲在地上数钱盒子里的零票，听见脚步声头也不抬：“姐，省城展销会后天开幕，咱们的报名表我都填好了。”她忽然顿住，仰起脸，“姐，你今天脸色不对。那位钱爷爷说了什么？”

苏荷没答话，径直走到灶台前，掀开铁锅的盖子。锅底还有今早熬的骨汤底子，油花浮着一层光。她把那片陈皮丢进火膛，火苗“腾”地窜起来，青白色的烟带着一股奇异的香气，直冲屋顶。那口铁锅发出“嗡”的一声，像是共鸣。

苏桃吓得跳起来：“姐！”

“没事。”苏荷盯着火苗，“明早出摊前，你去买十斤猪筒骨。要带髓的，老的。”

“十斤？”苏桃瞪大眼睛，“咱一星期都用不了五斤！”

“听我的。”苏荷把油纸包按回怀里，“还有——让顾长山下午来一趟。”

苏桃眼珠一转：“姐，你该不会是因为周日他爽约，要找他算账吧？”

苏荷这才想起来上回说好的同游，后来被梁国庆的事冲了。这丫头哪壶不开提哪壶。她正要开口，门外巷口忽然传来一阵喧哗。一个穿中山装的男人在苏记招牌下迎着光眯眼看，嘴里“啧啧”两声：“苏记……好大的口气。就这巴掌大的铺子，也敢叫‘记’？”

苏荷认识他——城东聚丰楼的老板张北亭，这一带生意做得最大的酒楼东家。上次苏记办卫生检查被人举报，背后的影子就跟他脱不开干系。

“张老板大驾光临，有失远迎。”苏荷擦着手走出去，语气不咸不淡，“要不要尝尝今早新熬的红油？比聚丰楼的够味。”

张北亭被呛了一记，脸色变了两变，忽然又挤出一个笑来：“苏老板，后天省城展销会，你知道了？”

“知道。”

“那你也该知道，这回评委里有一位，是退了休的国宴大师。”他刻意压低声音，却能让半个巷子的人都听见，“听说大师的秘书是个川妹子，姓宋。宋秘书放话——谁家能做出让大师‘点头’的菜，展销会的头名就是谁家的。”

苏荷手一顿。姓宋，川妹子——宋莉。那个左手虎口有横疤的女人。

张北亭见她脸色变了，得意起来：“苏老板，不是我小看你，你这红油抄手再香，也进不了国宴大门。不如这样，你把配方卖我，我给你这个数——”他伸出五个手指。

苏荷把火膛里的灰拨了拨，忽然抬头笑了：“张老板，我要是你，就先把自家后厨的账目清理干净。城南巷年底动迁，你家酒楼那块地皮倒是不在动迁范围里，可你包工的队伍里有个人——”她顿了顿，“左手虎口有疤，姓宋。你猜她是谁的人？”

张北亭的笑容僵在脸上。

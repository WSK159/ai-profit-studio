# 第394章 老屋地图

暮色压下来的时候，苏荷和顾长山已经走出了南郊那条土路。青江城里起了灯，远远望去像是撒了一把碎米。宋麻子说的那个“苏荷家老屋”，画在册子夹页地图上，门口一个叉，位置就在城北那片棚户区边上，跟苏荷记忆里的地方隔着半条河。

她在路边一棵槐树下停住脚，把蓝布册子重新掏出来，借着天色又看了一遍那页地图。线条粗粝，应该是炭笔画的，墨色早泅开了，但轮廓还清楚：一条河，一座桥，桥西一个方框，框门口竖着一道叉。方框旁边写了三个小字——苏记井。

“你家老屋门口有井？”顾长山凑过来看。

苏荷摇摇头：“我从小记事儿起，院儿里就没有井。”她顿了顿，“我是说，我娘嫁给我爹之前，那宅子是我姥爷家的。后来我姥爷没了，我爹就把老屋卖了，搬去城东租房子住。那口井，可能是填了。”

顾长山没说话，手指头点了点地图下方一行极小的字，那字比蚂蚁还小，要不是他当过侦察兵眼力好，根本看不见——“庚辰年，董渡水下，石下三寸。”

跟竹板上那行字一模一样。

苏荷只觉得后脖颈一阵发凉，风从河面吹过来，带着泥腥味。庚辰年是1940年，比董叔沉缸那会儿还要早五年。石下三寸，缸上七锁，这一套暗语像是一把钥匙链上的几个环扣，扣得死死的，却不知道那头拴的是什么。

“去老屋看看。”她说。

城北棚户区在青江大桥西端，晚风卷着煤灰，把路边的白杨树叶子吹得哗啦啦响。苏荷凭着小时候的模糊记忆，拐了两条巷子，在一堵半塌的土墙前站住。墙根长满了狗尾巴草，门板早就没了，黑洞洞的窟窿里堆着废砖烂瓦，屋檐塌了一半，月光照进去，影影绰绰。

但院子里的地面，是平整的。

苏荷蹲下身，手指拨开一层浮土，露出底下的青砖。整整齐齐，铺了满院子。这种砖是民国时大户人家才用得起的方砖，跟她姥爷的身份倒是相配。

“井。”顾长山已经绕到屋后，忽然低声喊了一句。

苏荷快步绕过去，果然见屋后墙根下有一圈低矮的石头井沿，被藤蔓盖得严严实实。她扒开藤蔓，井沿上露出一道浅浅的划痕——弯弯曲曲，像一条蛇，又像一条河。跟董叔沉缸缸沿上那图案，一模一样。

她正要探头往井里看，顾长山一把拉住她的胳膊：“别靠太近，井沿是松的。”

苏荷低头一看，果然，井沿一侧的石头有明显松动痕迹，像是被人撬过又重新压回去的。她心里一沉——有人比他们先到过这里。

“下去看看？”顾长山从腰后摸出一只手电筒，是部队带来的老式铁皮手电，拧开，一道黄光射进井口。井不深，约莫两米见底，底上不是淤泥，而是一块青石板。石板上，压着半块碎砖，砖下露出一角油纸。

苏荷从旁边捡了根废木棍，把油纸挑上来。油纸包得严实，拆开三层，里面是一张发黄的宣纸，纸上是毛笔小楷，字迹端正娟秀，写着：

“女孙苏荷，庚申年九月初八成亲，嫁妆一口，埋于井底，待至家宅兴旺之日，方可启出。”

落款：苏茂丰。民国三十七年。

苏荷的手抖了一下。

苏茂丰，是她姥爷的名字。

她姥爷在她七岁那年过世，生前只跟她说过一句话：“丫头，你这双手，将来是要掌勺的。”那时候她不懂，只当是老人糊涂了。现在看来，她姥爷手里那本账，或许比董叔那本还要厚。

她把宣纸折好，塞进怀里，又看了看井底那块青石板。石板的缝隙间，塞着一截红绳头，跟那根铁钎上系的红绳一模一样。

“井里的东西，得挖。”她说。

顾长山环顾一周：“今晚不行，太扎眼。明天我带工具来，白天人多，反而好混过去。”

苏荷点点头，正要转身走，目光掠过井沿内侧，忽然定住。井沿内侧刻着一圈极浅的刻痕，被泥垢填满了，月光下几乎看不出来。她用手指一抠，泥土簌簌落下，露出一行字：

“七锁已开，井见天日。”

字是新的，刻痕边缘还是白的，最多不超过三天。

苏荷猛地抬头，目光穿过塌了半边的屋顶，看向夜空。风从棚户区那头吹过来，吹得她后颈的汗毛根根竖起。有人比她早来，有人知道这口井，有人替她把锁开了。

她攥紧手里的宣纸，低声对顾长山说：“走，回去封井。”

顾长山没问为什么，他已经看见那行新刻的字了。他弯腰把井沿那块活动的石头重新压紧，又用脚踢了些碎砖盖上，动作干净利落，像从来没动过。

两人快步走出棚户区，刚上大路，就见巷口站着一个瘦长的影子。苏荷脚步一顿，手已经摸到腰后那把从铺子里带出来的剔骨刀，顾长山挡在她前面，沉声问：“谁？”

影子往前迈了一步，灯光落在脸上——是个四十来岁的女人，穿着灰布褂，头发盘得紧紧的，手腕上一道青黑疤痕。是巷口馄饨摊那个女人，宋麻子嘴里说的那个“何婶”。

她看着苏荷，眼神平静得吓人，开口说的第一句话是：“你姥爷当年，是不是跟你说过一句话——叫‘锅不离人，人不离锅’？”

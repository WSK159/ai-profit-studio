# 第437章 井底天光

后天夜里，月亮果然没有出来。

城南巷的铺子后墙根下，钟师兄带着苏荷和顾长山，把三块青石条一块一块撬开。石条下面是一层青灰泥，铲开三寸深，露出黑黢黢的井口。一股潮气从底下扑上来，带着腐朽木头和陈年泥土混合的味道。

“二十八年前我下去过一次。”钟师兄蹲在井沿，手里提着一盏煤油灯，火光把他那张老脸照得沟壑分明，“那时候井底还有水，齐腰深。我摸到这口缸的时候，缸沿上冻着一层霜，六月天，手伸进去跟冬天一样冰。”

苏荷蹲下来，朝井底看去。什么都看不见，只有一团黑，黑洞洞地在黑暗里张着嘴。

顾长山打着手电往下照。光束打到井壁，青苔覆着成片的湿痕，一路向下蜿蜒，像一道道暗色的泪痕。大约下到六丈深，光束折了一下——壁上有东西。

“有梯。”他轻声说。

果然，从井口往下约两丈起，井壁上每隔一段就凿有一个凹槽，像是踩脚的梯磴，边缘已经被磨得很光滑，显然是常年有人上下留下的痕迹。

“梯子是师父在的时候凿的。”钟师兄说，“他凿了这些梯磴，却从没下过井。”

一个凿了梯磴却从未下去过的人。苏荷攥着铜片，指腹压在“庚午年九月初九”几个字上，印了深深的痕。

“我和他下去。”顾长山单手撑住井沿，看向苏荷。

苏荷摇了摇头：“钟师兄年岁大了，上面不能没有人。我和你先下去，他替我们望风。”

顾长山没有争辩，把绳索牢牢拴在井口的老槐树根上，将手电别在腰间，第一个顺着梯磴往下探。苏荷跟在后面，下到第三蹬时，她听见背后的地面上传来钟师兄含混的声音：“那缸……缸底有条缝。”

苏荷停住了：“什么缝？”

“一条手指粗的缝，绕着缸底一整圈。像是烧的时候特意留的。”老人的声音从头顶落下来，“我摸到那条缝的时候，听见里面有动静——像有人在敲。”

“后来呢？”

“后来我手拿开，声音就停了。”钟师兄沉默了一息，“我师父说，那口缸是活的。我问他活的怎么能装水，他说——谁说缸里装的一定是水。”

声音没有再下来。苏荷深吸一口气，脚下的梯磴冰凉，手心却微微发汗。

井底比想象中要窄。下去大约七丈，井底只有半人多高的空间，地面是厚厚的青灰色淤泥。顾长山的脚先踩到了底，他蹲下身形，手电照了一圈。井底堆着几块碎瓦片、一截发黑的老旧麻绳，还有两枚散落的铜钱。

然后手电的光束停住了。

井底正中央，一口半埋在淤泥里的陶缸。那缸约莫齐人胸口高，缸身呈深褐色，表面覆着厚厚一层灰白色的盐霜。手电光扫过去，苏荷看见缸壁上隐着一道五瓣梅花的印痕。

“和江底那把锁上的一模一样。”顾长山低声说。

苏荷蹲下来，伸手去触碰缸壁。指尖一触到缸身，她便觉得一阵刺骨的冷意从指尖蹿到心口，那是一种深井泡了二十多年的冷，带着泥土和铁锈混杂的腥气。她的手掌按在那道梅印上，冰凉的陶质感在指尖蔓延。

她绕着缸走了一圈。缸底果然有一道缝，手指粗细，绕缸身一周，不像是裂缝，倒更像是在烧制时预留的旋口——缸底是旋上去的。

她蹲下来，把手指探进那条缝里试了试，能感觉到一些松动。缸盖封得极严，但底，似乎是能旋开的。

苏荷站起来，拍了拍手上的灰泥，胸口难以抑制地嘭嘭跳着。

“开吗？”她问顾长山，声音有些哑。

顾长山没有立刻回答，而是用手电照着缸身上方——那个五瓣梅花的印痕上方，还刻着一个字。字迹歪歪扭扭，像是用指甲蘸着什么东西刻上去的：

“活。”

苏荷心口猛地一紧，忽然想起钟大河那句“缸里装的是水，不是命”。缸底那条旋口，缸壁那个“活”字，被刻意填死的枯井，守着井口三天三夜不断朝里面说话的人……

她伸出手，搭在缸沿上。

“开。”

她的手掌刚刚压上缸沿，井底忽然起了一阵风。那风不知道从哪里来的，吹过她耳畔，带着一种像人叹气一样的呜呜声。手电光剧烈摇晃了一下，苏荷脚下的淤泥微微往下陷了半寸，顾长山低低地“嗯”了一声。

有人站在井口，堵住了那方被撬开的天光。

一个熟悉的声音从头顶上方落下来，不紧不慢，带着些许笑意：

“苏老板，别急着开缸。至少——等我把话说完。”

那是沈伯言的声音。

# 第448章 渡口夜话

夜色像浓稠的墨汁铺在江面上，何家渡的码头上只有一盏昏黄的桅灯在风里晃荡。老船夫收了乌铁牌，却半晌没说话，只是一双浑浊的眼睛在苏荷脸上来回扫了两遍，像在辨认一件旧物。

“你师父走的时候，比你还小两岁。”老人忽然开口，声音沙哑得像砂纸磨过船板，“他说，将来若有人拿着牌来，就告诉那人一句话——汤底不在锅里，在人的命里。”

苏荷攥紧手中的乌铁牌，牌面冰凉，五瓣梅的纹路硌着掌心。顾长山在她身侧微微上前半步，沉默地挡在风口。

“老人家，您和我师父，是什么交情？”苏荷问。

老人没有直接回答，弯腰从船舱里拎出一只豁口的陶碗，碗底沉着半块姜片。“他帮我治过三年的风寒腿，用的是你刚才那锅粥里同款的老姜。”老人把碗递过来，“尝尝。”

苏荷接过碗，碗沿还残留着陈年的油腻，汤水清亮见底，只飘着一丝若有若无的甜。她抿了一口，那甜味极淡，像冬天屋檐下垂落的冰凌化在水里，凉意过后才泛起一丝温润的暖。

“这是我师父的手艺？”她抬头。

老人没应声，只扭头望向江面。远处有一艘夜航的货船缓缓驶过，船头亮着一点红芒，像一只睁开的眼。

“你师父在南方那片竹林里住了十三年，从不进城，也不见客。”老人顿了顿，“除了两年前，有个驼背的老头儿去找过他。”

苏荷心头一跳：“驼背？”

“背驼得厉害，走路的时候左肩比右肩矮半寸，拄一根竹杖。”老人眯着眼回忆，“他们在竹林里待了三天三夜，第四天那驼背独自走了，你师父出来时，在江边烧了一叠纸。”

风忽然大了些，桅灯的光在风里忽明忽暗。苏荷想起磨坊纵火时看见的那道佝偻身影，同样的驼背，同样的竹杖，一瞬间头皮发麻。

“烧纸……是祭谁？”

老人摇头：“他没说。只在那之后，把最后一口锅沉了江。”他指了指码头下游某处黑黢黢的水面，“就在那儿，沉锅的第七天，你师父让我守着这渡口，说等一个带五瓣梅牌子的姑娘。”

风里裹着江水的腥气，苏荷站在原地，手里的乌铁牌似乎变得更沉。顾长山低声道：“天快亮了，先找个地方落脚，明天再走。”

老人却拦住他们：“渡口往南三里，有片废砖窑，窑洞里生着火。你们要过江，明天一早我送。”

“老人家不收船费？”

老人看了苏荷一眼：“你师父当年给过钱了，给了十三年的。”

苏荷心里一酸，转身深深鞠躬。老人摆摆手，佝偻着腰钻进船舱，片刻后传来窸窣的翻动声，像是从板缝里抠什么东西。再出来时，他手里多了一片薄薄的竹牌，颜色已经发黑，上面刻着一行蝇头小字。

“你师父留给你的第二样东西。他说，等你尝过陈米粥的苦，再打开看。”

苏荷接过竹牌，触手温润，像是被人摩挲了许多年。她翻过竹牌，背面是空白的，只在边缘刻了一道极细的纹路，像是一条蛇的尾巴，又像是一条弯曲的路。

顾长山盯着那道纹路看了片刻：“这纹路……和枯井地窖石壁上的刻痕像。”

苏荷仔细看了看，确实像，但枯井里的刻痕是阴刻，这道是阳刻，像是把同一张图画的正反两面分开。她把竹牌贴身收好，又看了一眼老船夫：“老人家，我师父……他还活着吗？”

老人没有回答，只是把手中的桅灯往上提了提，灯光照亮他满是沟壑的脸。他的嘴动了动，最终只说出五个字：“明日渡江去。”

说完，他转身进了船舱，那盏桅灯被他挂在舱口，像一只倦极的眼，缓缓阖上。

苏荷和顾长山沿着江堤往南走，走出百来步，苏荷忽然停下脚步，回头看了一眼码头。那艘船还停在原地，船舱里的光已经灭了，但船艄上挂着的双钱结红绳竹篮在夜风里轻轻转动。

篮子里原本放着陶罐的位置，此刻空了。

苏荷心里莫名一凛，那陶罐什么时候不见的？她明明记得上船时看到了那罐子。顾长山顺着她的目光看过去，也沉默了一瞬，低声道：“那陶罐，怕是早就被取走了。”

“谁取走的？”

“船靠岸的时候，风浪晃了三次。码头西头有棵歪脖子柳树，树后一直有个人蹲着。”顾长山声音平平的，像在说一件很寻常的事，“他没动，我也没动，他后来走了，走之前朝舱里扔了块石子。”

苏荷浑身一震：“你为什么不早说？”

“石子落水的时候，那老船夫朝柳树的方向点头了。”顾长山垂下眼，“他们是认识的，不该我管的事，我不插嘴。”

苏荷沉默片刻，忽然笑了，笑声混在江风里，带着几分说不清的涩意：“顾长山，你倒比我想的沉得住气。”

“在部队学的，哨兵最忌贸然动。”他说完，从怀里掏出一样东西，在月光下展开，是一只巴掌大的旧布包，包着一撮黄褐色的泥，“刚才上船前，我在码头石缝里抠出来的，柳树后面那人蹲过的位置，鞋底带这种泥。”

苏荷接过，用指尖捻了捻，泥粒粗粝，带着一股浅浅的霉味。这不是江边的沙泥，更像挖过地窖之后回填的土。

“你怀疑那人是从枯井那边过来的？”

顾长山没答话，只把泥包重新收好：“天亮过了江再说，今夜先睡。”

他率先走向前方不远处的废砖窑，火光从坍塌的半截窑口透出来，果然有人生过火。苏荷跟在他身后，走了几步又停下，回头看了一眼江面。那艘夜航货船已经走得只剩一点红芒，像一颗沉入江底的血珠，慢慢融进黑暗里。

她攥着乌铁牌和竹牌，指尖微微发热。师父给她留了那么多线索，每一件都指向南方，但她隐约觉得自己正被一个人引着走，每一步都踩在预设的棋盘上。

砖窑里的火光在风里跳了一下，顾长山的声音从窑洞里传出：“苏荷，进来烤烤，夜里凉。”

她应了一声，迈步进了窑洞。

火光映着墙上的烟熏痕迹，有几道刻痕隐约可见——像是用指甲硬生生划出来的，一道一道，歪歪扭扭，排列成三条短线、一条长线。苏荷的瞳孔猛地一缩，蹲下身，用手指顺着那些刻痕描了一遍。

三条短线，一条长线。

这是她在枯井地窖的泥洞入口处，摸到的同样纹路。她猛地抬头，目光落在窑洞深处一堆碎砖后面——砖缝里露出一截黄褐色的绳子头，像是被人随意丢弃的，又像是故意留下的。

她伸手去拉，绳子尽头系着一只巴掌大的铁皮盒，上面落满灰尘，盒盖上刻着一个字——方。

师父的“方”。

# 第245章 打草惊蛇

那碗米酒端到军大衣男人面前时，他端起来嗅了嗅，叹道：“这个味儿，怎么像国营饭店老周手艺酿的？他以前拿这个在省城拿过奖。”苏荷心里一动，面上不动声色：“大哥认得老周师傅？”“认得，以前在省城桂香楼当账房，后来落难回青江，在国营饭店掌过几年灶，前两年病退了。”男人砸了咂嘴，“他在的时候，那米酒可是青江一绝，后来人走了，酒也没了。想不到你这小馆子还能酿出这味儿。”

苏荷没接话。她拿过酒坛又舀了一勺，酒液重新滚热，满室生香。她等着男人喝完、付了钱、道谢出了门，才把门帘放下，把袖口那半截烟蒂掏出来放在桌上。苏桃也凑过来：“姐，这是刚才那些人掉的？”

“那个在街对面站了一早晨的人掉的。”苏荷说。

“又是那个人，”苏桃咬了咬唇，“他是不是盯上咱们的酒了？”

苏荷没答她，而是转向顾长山：“长山哥，恒昌贸易公司——你帮我查查这公司的底，还有，那个矮胖子再出现的话，别惊他，跟一段，看他回哪儿。”

顾长山点头，没多问，披上外套便出去了。苏荷把烟蒂收进一个纸包里，在纸上写了一行字：省城，金线滤嘴，进口烟。放进灶台下的铁盒里——正是她藏房契和其他信物的那个铁盒。

午后，苏荷从地窖里把那只青瓷罐又抱了出来。罐底的茶叶她已经连着研究了好几天，总觉得差一层——她把那撮茶叶凑到鼻尖再三嗅辩，忽然发现一个被忽略的细节：那茶除了兰花香，边缘还有一丝极淡、极淡的油脂味，像是沾过什么动物的皮毛。她拧眉想了想，脑中忽然闪过一个名字——灰鸽子。

那天在后院，她亲眼看见一只灰鸽子落在墙头，脚踝上系着一枚小小的竹管。而那只鸽子振翅飞走前，曾在青瓷罐上歇过脚。她不是没有怀疑过，只是当时没有证据。眼下这丝油脂味，倒像是某种印证——茶罐曾经封存过传递消息的信物，鸽子停落时留下的皮脂，年久月深渗进了茶叶。

“苏桃，”她扬声唤道，“上回后院那只灰鸽子，后来又来过吗？”

苏桃摇摇头：“没再见过。不过姐，隔壁张婶说，前些天见过一只灰鸟在咱们院后檐下窝了几天，后来不知怎么飞走了，留了一地灰毛。”她说着从口袋里掏出一个小纸包，打开——里面是一撮灰白色细绒，柔软蓬松，像是鸽子绒。

苏荷接过鸽子绒，放在指尖捻了捻。这灰白颜色，和她之前在岑三味灶台青砖缝里找到的那片灰白羽毛，一模一样。她打开师父留下的那本旧笔记，翻到夹着羽毛的那一页——页边角有两行极小的字，是她之前忽略的：“鸽来非自天，衔信入灶烟。好酒藏深巷，味从井底传。”

“味从井底传……”苏荷轻声念着，猛地站起来，“苏桃，拿手电筒，跟我去趟老井。”

苏桃还没来得及应声，门口忽然传来一阵脚步声，随即是门帘被猛地掀开——一个戴黑毡帽的中年男人大步踏进来，身后跟着两个壮汉。为首那人四十来岁，圆脸细眼，手里攥着一卷黄纸，进门便笑：“苏老板是吧？我是城东王记食铺的老板姓王，有笔买卖想跟你谈谈——听说你手里有口老井的契书？我那食铺要扩店，你那口水井，我出价八百，连井带地，怎么样？”

苏荷手一顿，把鸽子绒放进衣袋，抬起头，露出一个疏淡的笑：“王老板，那口井不卖。”

“一千。”王老板说着，把黄纸摊开在柜台上，“苏老板，我劝你想想清楚——这口井，你留着也没什么用，值不了几个钱。可你要是价钱谈不拢，过几天拆迁办来划地，你可连一千都拿不着了。”

苏荷的目光落在那卷黄纸上——纸角露出半个红印，像是某家单位的公章。她盯着那印没动，心里却翻起浪来。这姓王的口口声声提“拆迁办”，和之前那个城建局的何干部，是不是一路人？而那口井，不过是一方青石、一汪浑水，他们凭什么出到一千块？

“王老板，”她缓缓开口，“你知道那井底有什么吗？”

王老板面色微变，随即堆起笑：“能有什么？一口老井呗——我出这个价，是看你小饭馆刚开张，照顾你生意。”

苏荷弯起嘴角，目光却冷下来：“那我劝王老板另找门路。那口井——我跟我师父，还没看完呢。”

王老板眯起眼，像在掂量她话里的斤两，终是卷起黄纸，不冷不热说了句“苏老板好好想想”，带着人走了。门帘落下后，苏桃攥着她的袖子：“姐，他……他怎么知道井的事？”

苏荷低头看着油污斑驳的柜台，声音很轻：“打草惊蛇，蛇出来了。”

那姓王的来得太快、太准，分明是有人把井里有契书的消息递了出去。而递消息的那只手，就藏在她身边——不是她铺子里的人，就是盯了她许久的人。

她把袋里那根金线烟蒂捻出来，对着光又看了一眼。滤嘴上压着一道极细的英文花体，她不认识那几个字母，但前世的奢品酒宴上，她见过这个牌子——专供港岛外宾的“555”。而1988年的青江，能抽得上这种烟的人，一只手数得过来。

她收起烟蒂，拉开抽屉，指尖触到那枚凉沁沁的黄铜莲纹锁扣。四把钥匙——味、香、回、归。她手里已有了“味”和“香”，还有井底那把“归”与宋莉手中那把“回”的线索。可眼下最要紧的，不是钥匙，而是那个把井底消息递出去的人。

门外忽然传来顾长山的声音。他掀帘进来，神色沉肃：“查到了——恒昌贸易公司的法人叫周文斌，就是那个中间人。”他顿了顿，“他三天前去了省城，至今没回。但他在青江的落脚点，是城东一户姓何的家里。”

姓何的——城建局那位何干部。苏荷闭上眼，心里那根弦终于把所有碎片串到了一处：周文斌牵线，姓何的指路，恒昌贸易出钱，王老板出面。那些人盯的不是一口井，而是井里那把钥匙锁着的东西——那张契书，或者更值钱的东西。

她猛地睁开眼：“长山哥，今晚去趟老井，把那块青石板撬开，看看井壁里到底还藏着什么。”

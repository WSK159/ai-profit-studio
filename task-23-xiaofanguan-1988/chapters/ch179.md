# 第179章 一墙之隔

第二天白天，苏荷几乎把城南巷那个铺子从里到外擦了一遍。铁锅是她从家带来的那口，已经养出了黑亮的包浆，灶台的砖缝被她拿破布一丝丝抠干净，连门口那块被她自己拿毛笔写的“苏记小馆”招牌，都被她取下来重新描了一遍墨迹。

苏桃蹲在门槛边上，手里攥着一把花生米，一粒一粒地往嘴里丢：“姐，你手不酸吗？那一锅红烧肉你炖了俩钟头了，我看隔壁王婶都探头看了三回。”

“王婶是闻着味儿来的。待会儿给她端一碗过去。”苏荷手上没停，手里的锅铲翻着锅里的五花肉——糖色炒得枣红，油亮亮的酱汁裹在皮肉上，咕嘟咕嘟冒着小泡，肉香顺着窗缝往外飘。她夹了一筷子尝了尝，咸甜适口，火候正好。

“姐，你今天不去码头吗？”

“去。晚上八点。”

苏桃点了点头，没再追问。她知道姐姐这两天话少，但干活的节奏比平常快，把铺子擦得锃亮，像要把什么霉气冲走似的。

晚上六点半，顾长山带着老陆来了。

老陆是顾长山当兵时的班长，退伍后在南街跑运输，跟顾长山走得近。坐下喝了碗水，他没多话，就一句：“你说什么时候走，我就什么时候走。”

苏荷把围裙解下来叠好，从里屋拿出一个斜挎布包，里面装着钱袋子——三百五，已付；剩下一百备用金，外加一把厨房用的剔骨刀，刀身薄、刃口快，藏在布包最底下。她把手电、火柴、纸笔记好账的单子一样一样放进去，拉上拉链，这才对顾长山说：“走吧。”

七点半，三人到了北码头。顾长山脸上抹了一层锅灰，压低了帽檐，站在码头口那棵老槐树底下，老陆蹲在几步外的石台阶上，手里拿根烟，目光始终扫着来往的人。苏荷独自顺着江岸走到三号泊位，远远看见蓝皮铁壳船的甲板上亮着灯，何承业正坐在船帮上嗑瓜子，旁边除了昨天那精瘦男人，又多了两个壮实汉子，手里拎着铁棍。

苏荷在十步外站定：“何老板，货备齐了？”

何承业把瓜子壳往江里一吐，站起来：“姑娘，钱都收了，货自然备好了——三十捆，点数装车。”

他朝精瘦男人努努嘴，那人跳上岸，朝苏荷身后望了一眼，皱了皱眉：“就你一个人？货三十捆，一辆三轮车都装不满，你搬得动？”

“搬不搬得动是我们的事，货在就是了。”

精瘦男人冷笑一声，回身朝船上打了个手势，两个壮汉从舱里抬出一捆捆橡胶管，扔在岸边。苏荷走上前，一根一根地过手——尺码、管壁厚度、压字，和昨天看的那几根一模一样。她心里数着，数到第三十根的时候，点了点头：“装车吧。”

码头边停着一辆借来的三轮平板车，是顾长山前一天从南街修车铺租的。老陆不知什么时候已经绕到车旁边，把一个麻袋铺在车斗里，又拿绳子把绑扎的吊角做好，动作利落。

两个壮汉把管子抬上三轮车，压好了，老陆拿绳子攀紧。苏荷正要走，何承业忽然叫住她：“姑娘，周哥让我带句话。”

苏荷站住，回头。

何承业脸上的疤在灯下一跳一跳：“他说，你上回托他打听的那件事，有眉目了——说那老婆子的院子，政府明年要动规划，让你早作打算。”

苏荷心头一凛。老婆子的院子——说的是城南巷七号，那个她让周福安稍带口风去打听的老房契归属问题。周福安主动递这个消息，是示好，还是另有盘算？

她面上不露，只淡淡点头：“替我谢周哥。改天请他吃碗馄饨。”

何承业哈哈笑了两声：“行，回见。”

三轮车刚拐出码头，顾长山从老槐树后闪出来，接过老陆手上控制的绳头压住车板，三个人往城南巷方向推去。车上的橡胶管沉甸甸的，滚在车斗里发出闷响，压得三轮车吱呀作响。他们穿过两条街，走到南街口时，忽然有四个人从巷子里走出来，拦住去路。

为首的是个平头男人，三十出头，穿一件暗红夹克，兜着双手，咧嘴一笑：“苏老板，巧了，今晚没好好吃口饭吧——要不我李某人请你？”

苏荷看了他一眼，没说话。

李兆阳的视线越过她，落在三轮车那堆橡胶管上，慢悠悠地说：“听说你这批货不错，省城的东西吧？我想跟你借三十捆应个急。”他放下手，腰侧露出一把磨得发亮的铁器，“你给个面子，我记你这个人情。”

苏荷攥住布包里的剔骨刀柄，指节发白。身后，老陆已经悄无声息地把绳子头解开，握住了一截铁管。

她没退，反而上前半步，声音不高不低：“李老板，货可以商量，但这个面子，我给了你，明天码头上的人就都以为我苏荷是好拿捏的。”

李兆阳笑容一冷，正要开口，顾长山从三轮车侧踏一步站出来，把锅灰脏的帽檐往上一掀，露出那张棱角分明的脸：“李兆阳。你哥李铁军上个月刚从我手里领走最后一批缓刑材料——你是想让你哥再进去一趟？”

李兆阳脸上的笑僵住了。他盯着顾长山看了两秒，目光在顾长山的站姿、腰背、手上动作上扫过，最终慢慢退后半步，干笑一声：“行，顾干部开口，我李兆阳不是那不识相的人。今儿个算是交个情。”他朝身后人摆了摆手，四人和一团烟雾一起散进了巷子。

苏荷的指尖慢慢松开刀柄，掌心汗津津的。三轮车重新推起来，走出几步，她小声问：“缓刑材料——真有？”

顾长山声音没变：“真有。他哥李铁军两年前酒后斗殴致人重伤，判了缓刑，上个月刚满考察期。”他说完顿了顿，“但材料不归我管，刚才那句话是吓唬他的。”

苏荷愣了一瞬，低低笑了一声。

两个人推着车继续往前走，城南巷里的灯光已经看得见了。苏桃站在铺子门口，手里拎着一盏马灯，暖黄的光映在她衣服上，把她的影子拉得老长。苏荷远远望见妹妹等在门口的矮小身影，心口那根绷了一整天的弦，才终于松下来半截。

她把包递过去，声音带着一点连她自己都没察觉的潮意：“开火，煮面。”

# 第400章 井底乾坤

枯井里的湿气裹着陈年土腥味，直往苏荷鼻腔里钻。她蹲在井底，手里捧着那卷牛皮纸地图，纸面又黄又脆，边缘卷起了毛边。地图上蜿蜒的朱砂线从城南老巷一直延伸向西北，尽头处画着一个拳头大的圆圈，圈里一个“洞”字写得厚重扎实，像是用刀刻上去的，力透纸背。

顾长山站在她身侧，一只手扶着井壁，另一只手举着火把。火光在狭窄的井底跳动摇曳，将两人的影子拉得又长又扭曲。陶瓮已经打开，房契和章程就摊在一块干布上，七把铜钥匙并排摆在瓮盖边缘，铜锈斑驳，每一把都带着不同的纹路。

“那三句话，你就这么信了？”顾长山低声问，目光却盯着井口上方那一小圈天光。

苏荷没有立刻回答。她将牛皮纸地图对照蓝布册里的铁锅地图，两条路线竟然分毫不差，连拐角处的弯度都像是同一个人画出来的。而那条朱砂线的终点——香炉山，她在前世听师父提过。

“何婶没有必要骗我们。”苏荷说，声音很轻，却在井底回荡，“她要害我，刚才磨坊爆炸那一下就有的是机会。”

她顿了顿，指腹摩挲着地图边角一处几乎被水渍洇透的地方：“而且你看——这地图右下角，也有一个三角形的‘童’字戳记，和蓝布册末页一模一样。”

顾长山沉默片刻，火光里他的眉眼显得格外深邃：“那我们得走了，井上有人——”

话没说完，井口忽然传来一声闷响，是脚步踩在碎砖上的声音，不止一个人。苏荷心头一紧，她下意识将牛皮纸地图和房契卷拢塞进衣服内袋，七把铜钥匙一把不落，用那只陶瓮的包布裹了，捆在腰间。动作干净利落，前后不过数息。

“上去。”她做了个口型。

顾长山点点头，先一步踩着井壁凹凸不平的砖缝往上攀了几尺，回手拉她。苏荷一手攥着绑在腰间的布包，另一手抓着他递下来的手腕，脚下蹬着井壁借力，像只灵活的壁虎。她的动作快了，井壁一块松动的砖头被蹬得滚落下去，砸在井底的碎石堆上，“啪嗒”一声脆响在井下回荡。

井口上方那人立刻停了脚步。

顾长山停住，整个人贴在井壁上，连呼吸都放轻了。苏荷悬在半空，脚趾死死勾住一块突起的砖沿，抓着顾长山手腕的指节泛白。两人像两只蛰伏的壁虎，一动不动地嵌在井筒里。

过了约莫十几息的功夫，井口脚步才重新响起来，但声音渐渐远去，压低的人语顺着风传来隐约几个字：“……人不在这里，看看磨坊那边……”

顾长山这才继续上攀，手臂肌肉绷出一条条硬邦邦的线条，把苏荷拉出井口时，他额头已经沁了一层薄汗。

老屋院子里空荡荡的，枯草被风吹得沙沙响。原来放着井盖的石板被掀开在一边，井口四周的泥土上有好几套鞋印，看大小不是同一个人的。顾长山蹲下去看了一圈，脸色沉了沉：“两双解放鞋，一双皮鞋，皮鞋底纹是新的。”

苏荷也蹲下去看，那双皮鞋的印子很深，说明踩的人身量不轻。她正要说些什么，远处磨坊方向又传来一声闷响，比之前那次更沉，像是墙塌了的声音。紧接着是一阵烟尘冲天而起，在傍晚昏黄的天色里格外扎眼。

“他们炸了磨坊。”苏荷站起来，声音里透着一股说不清道不明的冷，“这是想要灭口。”

何婶还在磨坊里。

顾长山显然也想到了这一点，他一把抓起那半根插在地上的铁钎，长腿一迈就往院门方向冲。苏荷紧跟在后面，腰间的布包随着奔跑打在她腿上，七把铜钥匙隔着布发出低哑的碰撞声。她的脑子里转得飞快——井上埋伏的人既然知道老屋枯井，那必然是早知道苏茂丰布置的人；而他们炸磨坊，要么是气急败坏，要么是灭口，不管是哪一种，都说明他们已经急了眼。

院门外的小路被枯草和碎砖铺得坑坑洼洼，顾长山跑得极快，苏荷几乎有些跟不上。她跑出巷口时，抬眼便看见磨坊方向冒出的黑烟已经开始变浓，带着一股焦糊味。几个从巷子里跑出来的街坊正站在远处观望，指指点点地议论着什么。

苏荷正要继续往前跑，脚下忽然踩到一块硬物。她低头一看，是一根半截烧黑了的木棍，像是从磨坊那边被炸飞过来的，木棍末端还缠着一小截红色布条，被火燎得焦黑卷曲。

她的脚步猛地顿住。

那截红布条上，她认出了那种织法。是她前些日子给自己那件旧棉袄裁边时剩下的碎料，她本来把它系在铁钎的手柄上，用来记手抓的位置。

这根木棍，是从那把铁钎上断下来的。

磨坊爆炸里飞出来的不是木棍，是铁钎的柄。

苏荷的手指攥紧了那截烧焦的布条，指尖微微发颤。她猛地抬头望向磨坊，那处已经笼罩在浓烟与火舌之中，一个佝偻的身影正趴在磨坊后墙的窗口，拼命地往外翻爬，是何婶。

而何婶身后，黑烟中隐约站着一个人，手里握着什么闪亮的东西，正一步一步朝她走去。

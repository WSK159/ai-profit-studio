# 第247章 王老板的老底

第二天一早，天刚擦亮，苏荷已经站在城东王记食铺对面的早点摊前，端着一碗豆浆，眼睛却没离开过那扇门板。

王记食铺今天没开张，门板关得严严实实，门口停着一辆半旧的自行车，车把上挂着一副没摘的皮手套。苏荷看着那副手套的款式，心里定了定——那是一副进口翻毛皮手套，1988 年青江市的百货大楼还没得卖，只有省城友谊商店有售，而且得凭外宾券。

一个开小食铺的老板，买得起这种手套？

她放下豆浆碗，沿着王记铺面绕到后巷。后门虚掩着，门缝里透出灯光，有人压低嗓子在说话。苏荷贴着墙根靠近，听到一个陌生男人的声音：“王老板，这口井的事你办得怎么样了？上头催得紧，说三月底之前必须摸清底细。”

王老板的声音带着几分难色：“那苏家丫头精得很，一口价就顶了回来。我好话歹话说了一箩筐，她不松口。”

“那就换个法子。城建局那边已经打了招呼，城南巷那块地迟早要动，她一个小饭馆，掀不起浪来。”

话音到这里，后门忽然被人从里面拉开。苏荷来不及躲闪，与一个穿灰夹克的男人打了个照面。男人年纪三十上下，颧骨高耸，一双三角眼在她脸上扫了两遍，什么也没说，转身从巷口走了。

王老板站在门口，脸色变了变，很快堆出一脸笑：“苏老板，这么早，是来买早点的？今天没开火……”

“王老板，”苏荷打断他，声音不冷不热，“昨天你出一千块买我的井，我琢磨了一宿，想明白了。你不是想买井，你是想买井底的东西。”

王老板的笑容僵在脸上，嘴角抽了两下，半晌笑道：“苏老板说笑了，一口破井，能有什么东西……”

“那是个暗洞，里面有口坛子，封泥上印着莲纹。”苏荷一字一句说得清清楚楚，盯着他的眼睛，“你知道那坛子里装的是什么吗？”

王老板脸上的笑意褪得干干净净。他沉默了几息，忽然叹了口气，压低声音：“苏老板，咱们明人不说暗话。那口坛子，不是我要的，是省城一位贵人托我找的。他放出话来，谁先找到那口坛子，出三千块收。后面的路，他说了算。”

“什么贵人？”

王老板看了看左右，凑近一步，声音压到几乎只有两人能听见：“恒昌贸易的周老板，周文斌。他说那口坛子是他爷爷当年寄存的传家物，流失多年，如今要寻回去。”

苏荷心里那根弦轻轻一颤——周文斌，那个矮胖子名片上的名字。她面上不动声色，淡淡道：“口说无凭。他要真是正经寻祖物，怎么不敢登门，偏要托你一个开食铺的来买？”

王老板被问住，讪讪笑了一声，退后半步：“话我带到了，价钱可以商量。苏老板要是有意，随时来找我。”

他缩回门内，门板吱呀一声合拢。

苏荷站在后巷里，晨光落在她脸上，眉眼沉静。她摸了摸口袋里的黄泥碎片——那枚莲纹印记还在。昨晚她在井底看到石板上的刻纹时就已经明白，老井、地窖、铜锁扣、青瓷罐，这一连串东西，恐怕都指向同一样东西：师父留下的那口坛子，以及坛里藏着的东西。

而周文斌，从省城来，握着恒昌贸易的名片，住进城建局何干部家里，又把手伸到城南巷的老井里。他的目的，恐怕远不止一坛老酒。

她转身往回走，步子很快。快走到苏记门口时，苏桃从门里跑出来，手里捏着一封信，脸色发白：“姐，省城寄来的。信封上写着妈的名字，但字迹不是妈的。”

苏荷接过来，信封贴的邮票是省城专用邮戳，上面的字迹工整而陌生。她撕开封口，抽出一张对折的纸，上面只有短短一行字：

“苏家丫头：那口井不是你们家的。三月底前把坛子交出来，否则，兴隆杂货铺的房契，就别想要回去了。”

落款：故人。

# 第99章 半本账

苏荷从后窗翻出去的时候，膝盖磕在了窗台上。她顾不上疼，把半本账往怀里一塞，贴着墙根往巷子深处跑。青江市局的王局长——不，现在是青江市局王局长了——能把手伸到省城三桥胡同，说明他的网比她想的还要密。她不能连累周诚。

身后传来门板被拍响的声音，顾长山的嗓门拔得老高：“周师傅，我媳妇儿说好来你这儿取腌菜的方子，是不是走岔了？”

苏荷咬着唇没停步。这男人编起瞎话来脸不红心不跳。她拐过两条胡同，确认没人跟上来，才蹲在垃圾堆旁边的水泥台阶上喘气。天色蒙蒙亮，省城的早点铺子开始支棚子，油条下锅的滋啦声混着豆浆的香气飘过来。她肚子饿得咕噜叫，但手比肚子更忙——那半本账翻开，她要看个究竟。

账页泛黄，边角卷得起毛。字是钢笔写的，蓝黑墨水，笔画端正，一看就是老会计的手笔。第一页记的是日期和进货量，某某月某某日，白面若干，大米若干，白菜猪肉若干。平平无奇。可苏荷翻了五页，突然停住。

第五页的某个月份，账目里夹着一行小字，墨色比别的字淡，像是后补的：“调拨，一千五百斤袋装白米，经王某，入三招待所仓，实到南市。”

南市。黑市。

苏荷的指尖划过这几个字，脑子里想起周诚的话：“账面入第三招待所仓库，实际流入南北黑市。”那一千五百斤米，只是冰山一角。她把整本账翻完，发现同样的字样反复出现，隔两三个月就有一笔，多则上千斤，少则几百斤，走的都是同一个“王某”，入的都是同一个“三招待所仓”，实到的却都是“南市”。

有人用公家的粮食养自己的钱包，并且养了十几年。

苏荷合上账本，眉心拧成一个结。1988年，还有不到一个月就要搞物价闯关了，粮食价格一旦放开，全国都盯着饭碗。这本账要是摔出去，姓王的别说升官了，坐牢的份儿都有。可问题是——她凭什么摔？她一个开小饭馆的个体户，手里捏着一本不知真假的旧账，谁会信？

“同志，你没事吧？”一个端着搪瓷碗的老大妈凑过来，满脸担忧，“看你脸色煞白的，是不是低血糖？”

苏荷挤出一个笑：“没事，谢谢大妈。”她站起来，把账本重新塞进怀里，贴着衣服的那层温度让她稍稍安心。她得先找到落脚的地方，再想想下一步怎么走。周诚既然把账本给她，那后面必定还有线索等着她去挖。那个“南市”，她得去探一探。

她沿着文昌街往南走，路过一家早餐店，一碗阳春面卖两毛五。她掏出皱巴巴的钞票，丢在桌上，呼噜呼噜吃完，一口气灌了半碗热汤，脑子才算清醒过来。面汤是骨汤熬的，放了葱油，手艺比她前世那些半吊子徒弟强些。她放下碗，正要起身，目光忽然定在了对面墙上。

那是一张新贴的告示，红纸黑字，写得醒目：“省城个体劳动者协会第三次代表大会，定于本月二十日召开，凡在本省经营六个月以上之个体商户，可凭营业执照至区工商所报名，择优与会。”

个体劳动者协会。

苏荷的眼睛亮了。她站在告示前看了足足两分钟，然后笑了起来。她还没想清楚这本账该怎么用，但眼前这条路是亮的——个体户代表，那就是讲话的地方。她来省城原本是为了找周诚，但现在，一个更清朗的棋盘在她面前展开。

她刚要转身去问邮局怎么走——她得写信回家报平安，苏桃那丫头肯定急坏了——身后突然被人拍了一下肩膀。苏荷整个人僵住，手已经摸向口袋里的菜刀柄。她回头，看见的是一个戴帽子的男人，脸上横着一道疤，正是沈其昌酱菜铺里那个跟她搭伴来省城的同行人。

“苏老板，”刀疤男人压低嗓门，眼睛却亮得吓人，“我师父让我给你捎句话——王家的人昨晚摸到周诚住处了，你不能再住原来的旅店。城南铁匠巷十六号，有个暗门。走吧，我领路。”

苏荷盯着他，沉默了片刻，把怀里的账本又往里按了按。

“走。”她跟着刀疤男人钻进了晨雾未散的巷子里。

她不知道周诚此时是否安好，也不知道那本账里住着什么妖魔鬼怪。但她清楚一件事：她苏荷的命，从不靠别人施舍。既然穿越回这1988年，她就踏踏实实地，把每一步路走扎实了。那些虚张声势的牛鬼蛇神，迟早会撞到她手里的菜刀上。

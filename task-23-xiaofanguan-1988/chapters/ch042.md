# 第42章 黄雀在后

第二天一早，苏荷照常开张。

灰褂子来得比谁都早，弯腰把门槛外的青石板路扫得干干净净，又抢着帮廖师傅把蒸笼抬上灶台，殷勤得不像话。苏荷冷眼看着，只当他是在为今夜的活儿做铺垫。

果不其然，午后廖师傅沏了一壶茶，去前厅歇晌。灰褂子趁前厅忙乱，借口去后院倒泔水，绕到库房门口。那一瞬间他掏钥匙的手抖了一下，显然没想到事情顺利得超乎预料。樟木箱上的铜锁“咔哒”一声弹开，他迅速抽出里头叠好的红纸方子，塞进怀里，又将一切恢复原样，提着泔水桶若无其事地出了门。

苏荷站在二楼窗户边，把这一幕看得清清楚楚。

“姐，他拿到了。”苏桃捏着衣角，声音发紧。

“嗯。”苏荷心里反而出奇地平静，“等消息吧。”

天黑透时，顾长山带着一身夜露赶回小饭馆，在灶台边坐下，从怀里摸出一张纸条。苏荷接过，上面是顾长山那侦察连兄弟的笔记：何大勇酉时三刻出巷口，向东走了两条街，进了一间成衣铺子，跟一个穿蓝布衫的中年男人说了话，前后不过一盏茶工夫，那男人将什么东西揣进袖中离去。成衣铺子老板姓赵，叫赵前进。

“果然是他。”苏荷把纸条揉成一团，丢进灶膛的火里，看着纸团卷曲、发黑、化灰，“赵前进拿了‘方子’，自会找地方验。”

顾长山问：“你那假方子，能骗过他们多久？”

苏荷笑了笑，从怀里掏出一只密封的油纸包：“假方子上我把山奈换成了白芷，香料比例也改了。真要做出来，味道差得远，可光看方子，外行人看不出破绽。”

“赵前进以前是供销社的采购，沾过食品行当。”顾长山提醒，“他八成能找懂行的人验味。”

“那就看谁快了。”苏荷的目光移向案板上那罐新调的红油，“他验方子这段功夫，够我做一件事。”

她转身从里屋取出一封信摆在桌上，信纸顶端印着省商业厅的红头。这是邮差今早送来的那封加工信——广州美食节，省里给苏记留了一个名额，下月初五出发，为期七天。但名额只有两个，一个给她，一个给顾长山。

苏桃急了：“姐，要是咱们走了，店里怎么办？”

“廖师傅坐镇，你打下手。”苏荷拍了拍妹妹的肩膀，“你把账目看好了，我回来给你带广州的洋货。”

顾长山沉默半晌，抬起头看着她：“你打算把那个名额用出去，当饵？”

苏荷没回答，只沿着信封边缘缓缓抚过，目光深远：“赵前进想偷方子开店，咱们就把这场戏演到广州去——他要是真拿到‘方子’，下一站不是省城，就是广州。他以为我们离了青江，后方就空了。”

她走到窗边，窗外的夜风裹着江南特有的湿意，穿巷而过，卷起门槛外一张菜叶，悠悠荡荡飘向巷口。而灯火深处，仿佛有无数只眼睛在盯着苏记门口那块桐油刷过的招牌，那上面“苏记小馆”四个字，在昏黄的光里泛着温润的亮。

顾长山的目光落在她侧脸上，片刻后，他低声道：“好，我陪你去广州。”

苏荷回过头来，冲他笑了一下——那笑容里带了几分她这个年纪不该有的老成与笃定，像是猎人听见了远方猎物的脚步声。

她轻声道：“赵前进做梦也想不到，他偷走的那张纸，会把我们送到比他高十倍的地方去。”

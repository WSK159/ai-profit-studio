# 第150章 菜地之约

清晨五点，城南巷还蒙着一层薄雾。苏荷把铁锅里的油烧热，葱花下去“滋啦”一声响，香气窜出半条街。

老人昨夜的约定她没忘。灰布褂、菜地、地契与菜谱的真相——这四个词轮番在她脑子里转了一夜。她给苏桃留了张字条，揣上围裙和一把剔骨刀，出了门。

菜地在城郊东头，一片被荒草半掩的坡地。远远看去，几畦菜垄整齐得不像话，像有人拿尺子量过似的。萝卜缨子肥绿，白菜卷得瓷实，一看就是行家伺候的活儿。

老人正蹲在田埂边拔草，听见脚步声也没回头，只说：“来了。”

苏荷走到他身侧，没急着说话。她看见老人手边放着一卷泛黄的纸，边缘磨得起了毛。

“那是我师父留下的。”老人慢慢开口，“1959年，国宴，他掌勺，我打下手。那道‘金汤白菜’，他教了我整整三年。他走之前把菜谱和这地契都交给我，说等有一天，遇上能把味道传下去的人，就把这摊子交出去。”

苏荷心跳加快。前世师父老陈师傅教她的第一道菜，正是金汤白菜——用老母鸡、金华火腿、干贝吊三遍高汤，最后收成一碗澄黄清亮、入口粘唇的汤头。她前世问了十几年，师父都说菜谱是“祖上传的”，从没提过别的来历。

“您姓陈？”苏荷问。

老人终于直起腰看她，浑浊的眼睛里有一层水光：“我姓陈，陈守义。老陈师傅，是我徒弟。”

苏荷像被雷劈中。她前世师父——那个沉默寡言的老人——原来是眼前这位的徒弟。也就是说，老陈师傅教她的那套传承，根子在这里。

“那您怎么一个人在这？”苏荷声音有点哑。

陈守义没接话，弯腰拾起那卷纸，抖开——一张泛黄的地契上写着“城南巷七号院”，落款1957年，盖着青江市人民政府的公章。另一张纸则墨迹累累，写满蝇头小楷，赫然是一份完整的《金汤白菜秘方》。

“这院子，当年是我家祖产。后来公私合营，充公了。房契在我手里，但房子归了公家。如今政策变了，我打听过，可以拿契书去换回产权。”他抬眼看向苏荷，“丫头，你可知道城南巷七号院是谁家的？”

苏荷脑子里轰一声。城南巷七号院——正是苏记小馆地址斜对面那间塌了半堵墙的破门面房。她前几日还盘算过，那地方位置比自家小馆还好，若能盘下打通，店面能扩一倍。她以为那是公产，没敢动心思。

“您是说……那房，能拿回来？”

“能，但要钱。”陈守义笑得有点苦，“三年前我打听了，产权归还得补缴‘代管费’，加上修葺，少说三百块。我拿不出，一直搁着。”他顿了顿，“这菜谱，和我这条老命，也不值什么了。你若有胆，接了它，把厨房烧起来。”

苏荷蹲下来，盯着那张菜谱看了半晌。上头的字迹有些已经晕开，但每一笔都透着力道。她手指抚过纸面，忽然想起前世师父常念叨的一句：“金汤要熬足时辰，人心要守住火候。”

她抬起头：“陈爷爷，这契书和菜谱，我接了。钱我来想办法，房子修起来，厨房支起来，您坐镇。还有——”她眨了眨眼，“您徒弟，老陈师傅，是我前世师父。这辈子，我第一次见他时他还没收过我，但这辈子的路，我自己走。”

陈守义怔住，半晌，老泪纵横：“好……好。我就知道是你。”他从怀里掏出一枚黄铜钥匙，塞进苏荷手里，“七号院的锁，我每月都去换。从今天起，是你的了。”

两人在菜地边蹲了半个时辰。陈守义把城南粮站秦掌柜的事又细说一遍：“那灰帽小伙我见过，常半夜从西门货栈出来，往城南走。秦掌柜跟他是一条船上的。你查面粉的事，别打草惊蛇——秦掌柜背后，怕是有人。”

“谁？”

“粮站站长周德顺。他小舅子在省城开了三家国营饭店，去年亏空，保不齐打什么歪主意。”

苏荷攥紧钥匙，心里已经有了初步盘算。她站起来拍拍膝盖上的土：“陈爷爷，您先回巷子等我。我去找顾长山，把房契的事办一办。”

陈守义点头，又叮嘱一句：“那灰帽人，你小心。他不是本地口音，像是南边来的。”

苏荷走在回城的土路上，晨光已彻底亮透。她摸了摸兜里的黄铜钥匙，又想起那张菜谱上最后的落款，一个小楷印章，刻着“陈门”。前世师父教她时，总在每道菜品完成后用这个印章给她“验课”。

她鼻头一酸，又狠狠吸了口气。

拐过巷口，她看见顾长山蹲在苏记门口，手里攥着一根没点着的烟。见她回来，他站起来，眉头拧着：“一早上没见你，以为出了什么事。”

苏荷把钥匙在指尖转了一圈，冲他咧嘴一笑：“顾同志，咱们又有新买卖了。”

顾长山盯着她脸上的笑，沉默了两秒，把烟往耳朵上一别：“说吧，这回又是多少钱的买卖？”

苏荷伸出一根手指头：“先借你三百块转业费，百倍还你。”

顾长山没犹豫，从兜里掏出烟盒内夹的存折，递给她：“密码六个八。”

苏荷愣了一下，突然笑起来：“你不问我拿去干什么？”

“你苏荷做的事，哪件亏过？”顾长山别过头，耳根有点红，“走，我陪你去产权处。”

日头升高，城南巷的烟火气渐渐冒起来。苏荷捏着存折和黄铜钥匙，大步朝产权处走去。她没注意到，巷尾的槐树后，一个戴灰帽的身影正盯着她的背影，低头在纸上记了几笔，转身消失在巷子深处。

# 第19章 父亲上门

苏荷正在后厨教周大柱颠锅，前厅忽然传来宁旺的一声惊叫：“苏姐，门口那人说是你爹！”

她手里的勺没停，眼皮也没抬：“打发走。”

“打发……怎么打发？”

“就说我不在。”

宁旺应了声往外跑，可还没迈出两步，门外已经传来一阵粗哑的吼声：“苏荷！你给我出来！”

那声音她太熟了，前世听过，今生也听过——苏满囤，她那个卖了女儿还嫌卖得贱的亲爹。

她终于放下勺，从灶台底下抽出一条干净围裙擦了擦手，对三个学徒说了句：“你们回灶间，把门关严。”

周大柱站着没动：“苏姐，要不要我去街道办喊顾同志？”

“暂时不用。”

她拉开后门走到前厅，正看见苏满囤站在门槛外，穿着一件灰扑扑的中山装，领口油亮，脚上一双解放鞋沾满泥。他身后还跟着两个陌生男人，一个黑脸矮壮，一个瘦如竹竿，眼珠子骨碌碌地往店里扫。

苏荷把门帘一掀，站在门口，声量不大不小：“爹，你有事？”

苏满囤一见她，脸上先是闪过一抹不自然，随即挺起胸，嗓门提了八度：“你还有脸问！你娘在家哭了一个月，你倒好，跑到城里摆摊开店，还把桃儿也拐跑了！”他指着身后的黑脸汉子，“这是赵家村的媒人老赵，人家赵家定金都给了三百块，你倒好，人跑了，钱退了，丢尽我苏家的脸！”

苏荷抱臂靠在门框上，突然笑了：“爹，你搞错了，那不是定金，那是卖我的钱。我不是货物，你卖不了我。”

“你——”苏满囤脸色涨红，“你翅膀硬了是吧？我告诉你，今天你必须跟我回去！老赵说了，只要你肯回心转意，他不要你退钱，彩礼照给，回头就风风光光把你娶进门！”

那黑脸汉子搓着手上前一步，咧嘴笑出一口黄牙：“是啊侄女，我打听过了，你这店生意不错，嫁给我不吃亏，我还能帮你管账——嗐，往后就是你的店了。”

苏荷的目光冷了下来。

她看了那黑脸汉子一眼，又看了看苏满囤，声音平静得像一潭死水：“赵家给了三百块，你退了没有？”

苏满囤眼神躲闪：“……退了。”

“退了多少？”

“……退了八十。”

“那剩下两百二十块呢？”

苏满囤不说话了。

黑脸汉子脸上的笑也僵住了。瘦竹竿男人倒是嘿嘿一笑，摸着下巴插话：“我说老苏，你这闺女挺精啊，账算得门儿清。”

苏荷不理会那两人，只盯着苏满囤：“你把剩下的钱花了？喝酒？赌？还是贴补给谁了？爹，你卖女儿的钱，自己留了大头，现在又想把女儿拽回去再卖一遍——天底下哪有这么便宜的事？”

苏满囤恼羞成怒，跨前一步：“苏荷！你敢这么跟你爹说话——”

“我有什么不敢的？”苏荷抬手，隔着门槛指着他，“你卖我的时候，有没有想过我是你女儿？你把苏桃的学费抢走的时候，有没有想过她是你的骨血？你逼我嫁人的时候，有没有问过我想不想嫁？爹，我不欠你的。你今日来，要么来吃饭，我给你下碗面；要么来闹事，我奉陪到底。”

苏满囤被她一句话顶得噎住，黑脸汉子却不耐烦了，一拍大腿：“得了，废话少说！你爹欠我赵家的情分还没还清，你今天必须给我们个说法！”他一伸手就朝苏荷的手腕抓来。

苏荷站着没动，脚下却轻轻退后半步，正退到门后那根她早就放在那里的擀面杖边。

她抄起擀面杖，横在身前，声音不高不低：“你再往前走一步试试。”

黑脸汉子被她的气势镇住，脚步一顿。瘦竹竿在背后阴阳怪气地喊：“老赵，你一个大老爷们还怕个丫头片子？上啊！”

就在这时，巷口传来一阵急促的脚步声，宁旺的声音隔着巷子传过来：“顾大哥！快！就是这儿！”

顾长山大步流星地走进巷口，站定在苏荷身边，军装外套还没脱，目光在苏满囤和那两个男人脸上一扫：“几位同志，这里是私人营业场所，有事说事，动手可不行。”

苏满囤看到顾长山，眼神闪烁了一下，又壮着胆子喊了一句：“你算哪根葱？我管我自家闺女，关你屁事！”

顾长山不紧不慢地从口袋里掏出一个红皮工作证，亮了亮：“我是街道办干事顾长山。苏同志是经过工商备案的个体户，受政策保护。你要是再闹，我就请派出所的老周来坐坐。”

“个体户”三个字一出，苏满囤的脸皮抖了抖。1988年了，个体户虽然不受歧视了，但他这种庄户人家，最怕的就是穿制服的人。

黑脸汉子也怂了，扯了扯苏满囤的袖子：“老苏……要不算了？咱们回村再说？”

苏满囤被架在火上，走也不是，留也不是。他狠狠瞪了苏荷一眼，压着嗓子扔下一句话：“苏荷，你别以为在城里躲着就没事了！爹是管不住你了，可你妹妹还小——她的学费钱，我看你怎么挣！”

苏荷的脸色终于变了。

她把擀面杖往地上一顿，声线发冷：“苏满囤，你要是敢动苏桃一根手指头，我让你后悔一辈子。”

苏满囤被她那眼神吓了一跳，下意识退了一步，嘴里嘟囔了一句：“我……我懒得跟你理论！”转身带着那两人灰溜溜地走了。

顾长山目送三人消失在巷口，才对苏荷说：“你爹走的时候，眼珠子一直往你后厨方向瞟。他今天来，不只是带人来的——后面还有人指使他。”

苏荷挑起一根眉毛：“谁？”

“常发旅社的常老板。”顾长山压低声音，“我早上听人说他最近跟赵家村的人走得近。你爹来闹事，怕不是空手来的。”

苏荷收回目光，把擀面杖放回门后，声音放得很轻：“知道了。”

# 第50章 火车上的旧报纸

青江火车站早上八点不到就已经人挤人。候车室里烟雾缭绕，扛着蛇皮袋的、抱着娃的、蹲在地上啃包子的，满满当当全是赶早班车的人。

苏荷穿一件灰蓝罩衫，头发拿头绳拢成马尾，背着一只鼓鼓囊囊的帆布包，混在人群里毫不起眼。廖师傅送她到检票口就停了步，干瘦的脸绷得像张鼓皮，嘴唇动了半天才挤出一句：“到了那边，先住国营旅社，别贪便宜住黑店。”

“知道。”

“钱分三处放，袜子底下一份，腰带里一份，随身兜里一份。”

“知道。”

廖师傅还想再说什么，后头的人已经开始往前挤了。他喉结滚动了一下，忽地抓住她胳膊，声音压得极低：“何大勇那包粉末的事，我昨晚想起个细节——那东西的苦杏仁味，跟咱们年前从城北药材铺买的山奈味道不一样，倒像是我当年在部队时见过的，一种越南那边流进来的……止疼料子。”

苏荷目光一凝，正要细问，检票口的铁门已经吱呀推开，人流潮水般涌了过去。廖师傅松开她的胳膊，只来得及补了一句：“到了广州别碰任何叫‘白药’的东西！”

她回头看了他一眼，重重点头，转身挤进了人群。

火车是绿皮慢车，从青江到广州要十六个小时。苏荷的座位在硬座车厢中段，靠窗。她对面坐着一个穿中山装的中年男人，腋下夹着公文包，上车就开始看报纸；旁边是个抱着编织袋的老太太，袋子里装着一篮子鸡蛋，被挤得直“咯咯”呓语。

车子咣当咣当开出车站，青江的街景从窗外缓缓后退——城南巷那一排矮屋顶上，有一户谁家正在晒腌菜，瓦片上一层黄褐色的东西在晨光里泛着亮。苏荷看了一会儿，把视线收回来，从兜里掏出一张旧报纸。

那是昨晚顾长山留下的其中一份，从街道办翻出来的《南方周末》，日期是1988年3月10日，已经揉得发毛了。报纸第二版右下角有一块豆腐干大的报道，标题印着：“广州春季美食节即将开幕，港澳名厨将携新派粤菜献艺”。

她把这则报道翻来覆去看了三遍，视线停在末尾那一行——“届时，利丰贸易将携多款进口调味品参与展销，欢迎各界人士品鉴洽谈。”

利丰贸易，又是利丰贸易。

“同志，你这个报纸能不能借我看看？”对面那中年男人终于开了口，指着她手里的报纸，“我想看看广州那边现在物价什么行情。”

苏荷把报纸递过去。男人接过翻了翻，目光同样定在美食节那条新闻上，咂了咂嘴道：“这几年头，广州那边商人多，东西贵，但也好赚。我去年去那边进货，一箱香皂转手回来能挣三十块。”

“叔是跑货的？”苏荷随口问。

“小本买卖，跑点日用百货。”男人咧嘴笑了笑，“你呢？一个人小姑娘南下去干什么？”

苏荷一秒钟都没迟疑，张口就来：“去投奔表姨，在纺织厂上班。”

她知道，出门在外，越简单越具体的话越没人追问。男人果然“哦”了一声，没了下文，低头继续翻报纸。苏荷的目光却不经意地落在他翻到的那一页夹缝里——那里有一行小字广告：“秘方转让：正宗川味红油配方，含独门香料比例，非诚勿扰，联系地址：广州××路××号。”

她的手指在膝盖上轻轻叩了两下。

假方子“验货”——赵前进安排的人，会不会就是走的这种广告路子？她要在广州那边找到接头的人，才能知道对方究竟出了什么牌。

火车“哐”地一声过了一个隧道，车厢暗了一瞬，又亮起来。窗外的田野从绿转黄，再转成灰蒙蒙的城市轮廓——已经是广东境内了。苏荷掏出随身带的小本子，翻到空白页，用圆珠笔写了两行字：第一行写着“利丰贸易”，第二行写着“沙面大街邮政所·刘向东”。

她盯着那两行字看了片刻，又把本子合好塞进贴身衣兜。抬眼时，对面男人正好也在看她，目光在她收本子的动作上停了一瞬，随即笑了一下，转过头去望向窗外。

苏荷没有错过他那一眼。

她把腰间的帆布包收紧了一点，心想：这趟车的“跑货人”，不一定都只是跑货的。

天黑透的时候，广播里终于传来一声带着广味普通话的报站：“广州站到了，广州站到了，请旅客同志携带好随身物品，有序下车——”

苏荷背着帆布包挤下车门。9月的广州热气腾腾，一阵湿润的南风吹过她脸侧，带着芭蕉叶和海鲜市场的味道。

她深吸了一口气，迈开步子走向出站口。

眼前的灯牌密密麻麻，人潮涌动，而她一眼就看见出站口旁边的小柱子上，贴着一张白纸黑字的告示，上面写着四个字——“春季美食节”。

她没停步，直接打旁边走了过去。

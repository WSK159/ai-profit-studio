# 第40章 饵

苏记小馆的招牌底下，今早多了一张告示，毛笔写的，字迹端正：本店招帮工一名，月薪三十块，管两顿饭，手脚麻利者优先。落款是“苏记”。

告示刚贴出去半炷香功夫，门口就来了三个人。一个是隔壁菜场的赵大姐，一个是巷尾退休的老李头，还有一个——灰褂子，中等个，站在人群后头，低着头，眼睛却往灶间方向瞟。

苏荷站在灶台前，炒勺在锅里翻了两翻，眼角余光就扫到了那人。她没吭声，把手里的糖色炒到焦褐发亮，一勺老抽下锅，滋啦一声响，肉香冲得整间屋子都是。灰褂子悄悄往灶间门口挪了两步，脖子伸得老长，看着她在锅里下葱段、姜片、八角，又看着她把熬好的糖色均匀裹在排骨上。那手法快，利落，每一步都像是定了机关一样精准。

“老板娘，还招不招人？”灰褂子终于开了口，声音有点哑。

苏荷连头都没回：“会切菜不？”

“会、会。”

“明早五点来试工。”她把那锅排骨起锅，淋上两滴香醋，一股让人走不动道的味道从灶间飘出来。

灰褂子连连点头，像得了个大便宜，挤进人群里没了影。

顾长山是在午市过后回来的。他进门的时候手里多了一卷纸，摊开在苏荷面前，是城南面粉铺今年五月的进货单存根——上面清清楚楚列着一笔：“赵记饭馆，精粉两百斤，赊购。”笔迹跟苏荷挖出来的那张收据一模一样，左撇子才写得出来的模样。

“面粉铺的账房是周老板的侄子，叫周小栓，自幼左撇子。”顾长山说，“周小栓跟赵前进的表弟是高中同学，去年还在一张桌上喝过酒。”

苏荷盯着那张存根，手指轻轻叩着桌面。她原以为是赵前进找人代笔，没想到这纸条竟是他手下的人直接写的。难怪那家伙能出现在苏记库房后头——面粉铺子送面粉过来的时候，顺手探探风声，天经地义。

“赵前进知道我这两天在查纸条的事。”苏荷把存根收好，声音低了半截，“明天他肯定要派人来探虚实。我招了个灰褂子，让他明天来试工。”

顾长山皱眉：“你明知道是饵，还往跟前放？”

“饵要给足，鱼才咬钩。”苏荷嘴角微微一勾，“再说，人在眼皮子底下，总比在暗处好。”

她的声音带着一点冷劲儿，顾长山看着她的侧脸，没再说话。他从口袋里掏出一卷钱，放在桌上：“转业费，三千二百块。我本来想过阵子再给你，现在觉得，早点投进来，你早点把架子搭起来，免得什么阿猫阿狗都敢往灶台上伸爪子。”

苏荷看着那卷钱，愣了一下。三千二百块，在1988年抵得上一个工人三四年工资。顾长山把它轻轻放在案板上，像放一把菜一样稀松平常。

第二天早上五点，灰褂子准时出现在苏记门口。苏荷递给他一把菜刀：“先剁两斤肉馅，肥瘦三七，剁完我看。”

灰褂子接过刀，手腕一沉，埋头剁起来。刀法倒像练过，但他剁肉的时候，眼睛总往灶台旁边的坛坛罐罐上飘——那里面放着苏荷的秘制红油料。

苏荷靠在门框上，手插在围裙口袋里，摸到那张收据边角。她不急。鱼进了锅，火候得慢慢来。

她正要转身，门口突然传来一阵自行车铃声——一个穿绿色制服的邮差跳下车，举着一封信朝院子里喊：“苏荷同志，省城来的挂号信！”

苏荷接过信，拆开封口，里头只有一张纸，上头写着：“苏记红油抄手，在广州美食节获评委推荐。特邀以‘苏记’名义参展，名额一席，全权自主。”落款是省商业厅。底下还有一行小字：“请携本函至省城报名，截止日期：本月二十八日。”

苏荷把那封信翻来覆去看了两遍。广州美食节——1989年开春，全国个体户第一次被请进国字号展台。这不是一盘抄手的事，这是苏记从城南巷子走到全国面前的一个台阶。

灰褂子还在灶间里剁肉，刀刃碰到案板的声音笃笃笃，一下一下，像踩在她心跳上。她回过头，朝里面喊了一声：“肉馅剁细点，今天包抄手。”

赵前进的饵已经咬钩了。可她忽然觉得，自己面前还有更大的鱼。

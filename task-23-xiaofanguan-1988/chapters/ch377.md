# 第377章 渡口再逢

黑猫的叫声在暗处落下去之后，苏荷和顾长山同时停住了脚。

月光照着一片灰白的芦苇丛，风过时沙沙作响，那道碎石箭头到芦苇丛边就断了。顾长山把手电筒压了压，光柱贴着地面扫过——泥地上有新鲜的脚印，不大，像是一双布鞋的印子，刚踩过没多久。

苏荷蹲下来，用手比了比那脚印的宽度：“这人脚码不大，走路的步子密，要么是女人，要么是个瘦小男人。”

“往渡口去了。”顾长山直起身，看向远处江水反射出的微光，“秦老船工夜里不摆渡，这个点渡口不会有人。”

苏荷没说话，低头看着脚印延伸的方向，忽然从衣兜里摸出那枚先前在砖房地上捡的碎石。月光下，碎石边缘有一道新磕出来的白茬——这不是从墙根随意捡的，是有人刻意砸掉了棱角，摆成了箭头。

“走。”她把碎石揣回兜里，朝渡口方向大步走去。

果然，渡口的木栈板上拴着一只乌篷小船，船头挑着一盏马灯，灯是亮着的。船篷里有人盘腿坐着，背对着岸上的方向，披着一件旧蓑衣，头发花白，正慢条斯理地往一个土陶碗里添热水。

苏荷走到船头三步远的地方停住：“老船工，这个点了，还等人？”

船篷里的人没回头，声音干哑得像劈过的松木：“等的就是你。”

秦老船工侧过身子，端着那碗热水慢慢喝了一口，才转过脸来。灯下，他的脸比以前更瘦了一些，颧骨凸出，但眼睛还是亮的，只是看向苏荷的目光里多了一样东西——像是打量一个已经认识了很久的人。

“你身后那个箭头，是我摆的。”他说，把碗搁下，从船舱角落摸出一卷用桐油纸包着的东西，递给苏荷，“这个，也是留给你的。”

苏荷接过，拆开桐油纸。里面是一本巴掌大的旧册子，封皮是靛蓝棉布，用粗麻线缝的边，翻开第一页，墨迹已经发黄，但字迹娟秀，一笔一画写得很稳——

“江南盐务总局密档抄录（孙氏抄本）。”

苏荷的心跳快了一拍。她翻开第二页，里头的字迹和砖房地图上的笔迹一模一样。

“孙氏……”她抬头看向秦老船工，“那砖房里的人，是郑国栋的父亲？”

秦老船工没应她这句话，又喝了一口水，才问：“你知道郑国栋是怎么跟上海货商搭上的吗？”

苏荷摇头。

“他是从一个撑船的手里接过第一张纸条的。”秦老船工看着她的眼睛，“那个撑船的，就是我爹。”

江风从水面吹过来，把马灯的火苗吹得晃了晃。苏荷捧着那本册子，忽然觉得掌心的分量重得吓人。

“你爹……”她斟酌着措辞，“跟孙家是故交？”

秦老船工沉默了很久，久到苏荷以为他不会回答了，他才开口，声音压得很低：“这芦苇荡底下，埋着一条老盐道。清时走盐船，我爷爷撑的那条船，是唯一敢走夜航的。孙家那位在盐务总局做书办，跟我爷爷私下交好，那条航道就是他画的。”

他伸手指了指苏荷手里的册子：“这里面，有孙家书办抄下来的所有盐船航次、港口记录、还有董家私盐走货的账。你之前在地窖里找到的那批账本，只是后来补的，真正的地根账，一直在孙家手里。”

苏荷心头一震，想起那批永丰钱庄的账本，原来那只是明面的账。董青山贪私盐的事，真正能钉死他的证据，是手里这份孙氏抄本。

“这册子怎么会落到你手上？”顾长山问出关键问题。

秦老船工把碗掇起来，却没喝，眼睛看着碗里的水：“郑国栋被董青山毒哑投江之后，孙家书办也被灭了门。宅子烧了，人没跑出来几个。后来隔了几年，有个瘦小的先生找到我，说他姓孙，是从京城回来的，把这册子交给我爹，请我们保管。他只留了一句话——”

他顿了顿，看着苏荷：“他说，日后若有一个做菜的女娃儿找到这上头来，就把册子给她。”

苏荷攥紧了靛蓝布册子，指节泛白。

那个瘦小的先生，姓孙，从京城回来，做菜……

她忽然想起前世那个收她为徒的老人，那位老人教她的第一道菜，就是红油抄手。教她的第二道菜，是烫干丝。他从不提自己的姓氏，只说“做了一辈子菜，把名字做丢了”。

“那位孙先生……”她喉头有些发堵，“他还活着吗？”

秦老船工没有回答她的问题，而是把船篷帘子掀开一角，露出一口乌黑发亮的铁锅，锅沿磕了一个豁口，形状和她在砖房墙上看到的那只锅一模一样。

“他说，你要是问起这个——”老船工的声音慢下来，“就告诉你，铁锅还在，人不在了。”

苏荷站在船头，江风灌进衣领，她却觉得胸口滚烫，眼眶发酸。那口锅她认得，她前世拜师那天，师父用的就是这口豁了边的乌铁锅。

“他在哪？”她死死盯着秦老船工。

秦老船工把帘子放下，重新坐定，沉默半晌后说：“城西，老磨坊。”

他顿了顿，又补了一句：“你去的时候，带一把黄豆。”

# 第161章 密匣

苏荷回到旅店，反锁房门，拉上窗帘，才把蓝布包放在床上。

打开蓝布，里面是一只紫檀木匣子，约莫一尺见方，漆面剥落，露出一层层暗红色的木纹。匣面上锁着一把铜锁，样式古旧，钥匙孔是个古怪的形状——交叉的半月。

苏荷摸出周福安信里夹的那把钥匙，正好对上。铜锁“咔哒”一声弹开。

她屏住呼吸，掀开箱盖。

里面躺着一摞泛黄的宣纸，约莫二十来页，用棉线装订成册，封面上用毛笔写着四个字：鼎中六记。

苏荷小心翼翼地拿起第一页，字是行书，笔力遒劲，写的是“焖炉烤鸭”的百年秘法，光是腌制料就列了十七味，其中三味她闻所未闻。

她一页一页翻过去，越翻越心惊。这手札记录的不只是菜谱，每道菜后面还附了来历、典故、火候的微调要诀，甚至注明了几种特殊食材在哪个季节哪方水土里最为肥美。这等扎实功底，绝非寻常厨子能有的。

翻到倒数第三页，她停住了。

这一页被撕去了下半截，剩下的上半截写着：“芙蓉鸡片，要点在刀工，肉须剔尽筋膜，以刀背捶打成泥……”然后笔锋一顿，下面只留了一个“鸿”字，再无下文。

苏荷盯着那个“鸿”字看了好一会儿。她想起来，周福安信中提到杨景堂有个徒弟，名字里带“鸿”字，后来叛师出门，据说去了南方。

她正要继续看下一页，忽然听到门外走廊传来脚步声。那脚步很轻，却停顿在她的房门口——停了片刻，又继续往前走了。

苏荷迅速把木匣合上，塞进枕头底下，把被子拉平，装作刚洗完脸的样子。

门外响起敲门声：“同志，开水来了。”

她松了口气，开门接过暖水瓶，递了一毛钱给小工，顺手问道：“这层楼住了几户人家？”

小工咧嘴一笑：“不多，您隔壁空着，对门住了个南边来的采购员，住了七八天了，天天早出晚归的。”

苏荷把钱递过去，关上门。

她坐回床边，重新打开木匣。最后一页夹着一张薄纸，上面的字迹跟前面完全不同，是周福安后加的：

“景堂兄临终前曾言：鸿徒窃走半卷，南下出海，若见其人，手札之事切莫外泄。另：岭南有馆，名曰‘唐楼’，专供一菜，称‘雪羹’，疑系景堂兄那道失传芙蓉片之变体。若有缘，可往一试。”

苏荷把纸条折好，贴身收起来，又将木匣用油布包好，塞进行李箱夹层里。

她正考虑下一步的去向——是直接回青江，还是南下看看——忽然听见楼下传来一阵骚动。

她走到窗边往下看，街对面停了辆黑色小轿车，车门打开，下来一个穿呢子大衣的中年男人，身边跟着两个精瘦的年轻人。

那男人一抬头，正对上她的目光。

苏荷看清了那张脸——李兆阳。

当初在青江市，她举报的那个投机倒把的粮贩子，据说被抓了，怎么会在省城出现？

李兆阳显然也认出了她，嘴角扯出一个阴恻恻的笑，冲她对面的楼指了指，然后转身上了台阶。

他的方向，是诚记当铺。

苏荷的心沉了下去。她想起当铺刘掌柜说的那句“那半卷手札被叛徒徒弟卖给日本人”，又想起腊月十八西门货栈的“管子”。

原来宏泰背后不只是走私粮食，李兆阳没坐牢——何承业把他捞出来了。

苏荷退了半步，从行李箱里摸出周福安给她的那把菜刀，别在腰间。窗外，省城的天彻底黑了下来，旅店走廊里传来上楼的脚步声，一步，两步，停在门口。

门板“吱呀”响了一声，有人在拿钥匙开锁。

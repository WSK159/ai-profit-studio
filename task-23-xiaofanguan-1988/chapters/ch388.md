# 第388章 灶底账册

夜色浓稠如墨，董家老宅西厢房里只有一盏煤油灯摇曳。苏荷把那本蓝布册子平摊在方桌上，指尖抚过扉页上那个“董”字落款，心跳如鼓。这个笔迹，和前世师父书桌上压镇纸的那本手抄菜谱上的签名一模一样。她认得，绝对不会错。

顾长山站在她身侧，目光落在那行字上——“灶底埋炭，炭下埋灰，灰下埋账”。他眉头微拧，压低声音：“这是董老爷子自己写的？”

“嗯。”苏荷翻过扉页，后面是一页页密密麻麻的小楷，笔力遒劲，墨色沉稳，记的全是账目。每一笔都清清楚楚：盐三百斤、白糖五十斤、猪油八十斤……年份从民国二十三年一直到三十六年，按月排列，齐整如刀裁。

她越看越觉得不对。这不像是一般买卖的账本，盐的数目巨大，动辄数百斤，而且每个月都有固定几笔。最奇怪的是，每一页末尾都有一行蝇头小字，记的是船名和日期，比如“顺风号·三月初七·夜”，或“永隆号·六月初九·黄昏”。

“盐船夜行三更后。”苏荷喃喃念出其中一行，忽然觉得头皮发麻。这句话她在别的什么地方见过——对，是那本孙氏抄本里！那本从老宅正房箱底翻出来的抄本中，夹杂着一张几乎被水洇烂的纸条，上头就写着这七个字，当时她以为是码头船行的暗语，没当回事。

顾长山从她手里接过册子，翻到最后一页。那里画着一幅粗糙的地形图：几条线示意河水走向，旁边标着“码头”“石阶”“青石板”等字样，最下方画了一个圈，圈的中央画了面小旗。

“这个位置……”顾长山凑近灯下辨认，“像是码头靠西那段，靠近系缆桩的地方。”

苏荷心跳陡然加速。老艄公临走前说过一句话——“告诉老郑，董家码头下头那批缸可以起货了。”缸，账本，盐船，码头深处……所有线索在这一刻串成一条线。那批盐根本就是为了保存什么才埋的——盐能防腐，缸沉在河底，寒冬酷暑不腐不烂，里头藏的必然是更难见天日的东西。

“长山，”她猛地抬头，“董家码头那边，你是不是从小就在那儿玩？”

顾长山点头：“小时候常跟爷爷去钓鱼。码头西段水下确实有一片石头堆得很奇怪，不像天然的石头，像是有人刻意垒起来的。”

苏荷把那枚乾隆通宝攥在手心里，铜钱背面那个“苏”字被拇指摩挲得发亮。她不知道自己为什么对这枚钱有这么强烈的直觉，但一种说不清的冲动驱使她开口：“现在去码头看看。”

“现在？都这个点了。”顾长山看了一眼窗外黑漆漆的夜色。

“白天才引人注意。”苏荷已经起身把蓝布册子塞进怀里，黑铁片贴着胸口放好，“而且老艄公既然说‘可以起货了’，说明那边的事已经有人盯着——越早去看，越能抢在别人前头。”

顾长山沉默两息，然后点头。他这个人最大的好处就是从来不磨叽，决定的事说干就干。他吹灭煤油灯，黑暗中握住苏荷的手腕：“跟紧我，这条路我摸黑也能走。”

两人从西厢房侧门闪出，绕过碎砖堆，沿着老宅后墙一路摸到河堤。二月的夜风又冷又湿，河面上飘着一层薄雾，对岸零星几点灯光在水面碎成金色斑点。码头西段在月光下泛着青灰色的光，石阶上长满了厚苔。

苏荷蹲在石阶尽头，借着手心那枚铜钱的反光看向水面。河水黑沉沉一片，什么也看不到。顾长山却指着她左前方大约一丈远的位置：“那里——”他压低声音，“那几块石头露出的棱角，比别处的齐整。你看，像不像砌的一口井？”

苏荷顺着他的手指望去。果然，月光下隐约能看到几块长方形石料的轮廓，在水面下一尺左右的位置排成规则的一圈。那绝不是天然堆积的河石。

她正要开口，忽然身后传来一声压得极低的咳嗽。两人同时回头，月光下，一个瘦高人影立在他们身后三丈远的柳树后，手里提着一盏没点亮的灯笼。见他们看过来，那人也不躲，反而招了招手，声音沙哑苍老：“苏家丫头，顾家小子，上回说的事——那边，已经动工了。”

是老艄公的声音。但这句话让苏荷和顾长山同时僵住。

上回，老艄公明明说过“可以起货了”就离开了，他们以为那话是给老郑递的讯。现在他亲口说“那边已经动工了”——他指的哪里？又是什么事？

还没等他们问，老艄公忽然把手里的灯笼往地上一放，转身隐入柳树后，只留下一句细如蚊蚋的话：“缸起出来之前，你们先别急着下水。急的人，都把命搭进去了。”

夜风穿过河滩，吹起一片碎纸。苏荷低头一看，那是一小片黄纸，从老艄公放下的灯笼里掉出来的，纸面上用朱砂写着几个字，笔迹潦草，却像极了她怀中那本蓝布册子的落款笔意——

“立秋夜，水龙穴。”

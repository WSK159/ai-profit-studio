# 第362章 灰布衫

苏荷掀开茶馆那扇半掩的木门时，屋檐下挂着的铜铃“叮”地响了一声。灰布衫的人影已经拐进巷口，步子不快，却带着一种对地形极其熟悉的笃定，像一只老猫在不紧不慢地逗弄猎物。

“苏老板——”郑继明从身后探出半个身位，压低了声音，“要不要我喊人？”

“不用。”苏荷没有回头，“你把那张纸条收好，回省城等我消息。”

她说着已经迈出茶馆门槛，顺手从门边炭炉上捞起一根拨火用的铁钎，攥在袖子里。郑继明见她这副架势，愣了一瞬，终究没有多劝。

青江冬天的傍晚来得早。街上还残留着初五的鞭炮屑，风把墙角“好消息”招贴吹得哗啦作响。灰布衫穿过城南巷，贴着邮电局外墙，拐进一条苏荷没走过的窄道。苏荷放轻脚步，鞋底踩在青石板上几乎没有声响——前世在后厨被人偷袭练出来的警觉，在这一刻派上了用场。

窄道尽头是一堵砖墙，灰布衫停住了。

“出来吧。”那人开口，声音沙哑，像砂纸磨过铁皮，“你从茶馆门口就跟了一路，当我看不见？”

苏荷没有躲，她从拐角走出来，袖中的铁钎抵在掌心里。“你那张纸条，是替谁送的？”

灰布衫转过身。是个五十来岁的男人，脸上一条刀疤从眉角划到颧骨，眉眼却不像恶人，反倒带着一种跑江湖的疲惫。他上下打量苏荷，忽然笑了：“董家那口卤缸见了底，钟大川蹲在缸边扒了半天灰，扒出来的东西你猜是什么？”

苏荷心里一紧，面上不动声色：“我没猜谜的功夫。你到底是谁？”

“我叫何庆生。”男人从怀里摸出一张泛黄的纸片，递过来，“渡船簿上你查过秦老头的本子，那上头托锅具的人——是我。”

苏荷接过纸片。纸上是一行极细的字，笔迹跟渡船簿上的“荷”字确有几分相似：*“锅铲磨穿见铁心，青江水尽见故人。”*

“锅铲磨穿见铁心”——跟草帽人带的话一模一样。

“你跟草帽人什么关系？”

何庆生没有回答，反而看着她手里那根铁钎，目光凝了凝：“你那根钎子，是后院灶里抻的？”

苏荷手指一缩。这铁钎是她上个月修灶台时从董宅老灶底摸出来的，连顾长山都没仔细问过。这个男人只看了一眼就认出它，说明他见过跟它相配的另一件东西。

“你们家从前那位大厨——”何庆生顿了一下，像是在斟酌用词，“是不是教你打过一把锅铲？”

风从巷口灌进来，苏荷只觉得后脊一凉。上一世，她在后厨学艺时，师父确实教她打过一把铁锅铲——用一根旧铁钎，一锤一锤砸出来的，师父说“这钎子跟了我二十年，你带着，它认得你”。她重生后一直没找到那根钎子，直到在董宅灶底摸出这根——形制、粗细、敲击孔的位置，一模一样。

“你是……”苏荷嗓子发干，“你认识我师父？”

何庆生没应。他忽然偏过头，朝巷口看了一眼，像是听到什么动静，语气骤然加快：“钟大川挖缸那天，我在房梁上看他。他什么都没挖到，却留下一句话。”

“什么话？”

“‘那锅东西不在缸里，在锅里。’”何庆生说完转身就走，几步隐入墙根下的阴影，“你回去看看你那口铁锅——锅底是不是有夹层。”

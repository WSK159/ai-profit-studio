# 第174章 码头夜雾

夜雾从江面漫上来，把北码头那盏昏黄的路灯裹成一团毛茸茸的光晕。苏荷蹲在废弃的煤堆后面，把棉袄领子竖起来，牙齿还是忍不住打颤——十一月的江风像刀子，专挑骨头缝里钻。

手表上的指针刚过九点，离约定时间还有半小时。

她摸了一遍兜里的东西：一张皱巴巴的介绍信，是顾长山托街道办的老同事开的，盖着红章；半包大前门，用来递烟的；还有一把水果刀，藏在袖口里。苏荷知道自己不该带刀，真出了事这把小刀屁用不顶，但握着它，心里踏实。

远处传来汽笛声，一艘运沙船慢悠悠靠岸。船头跳下来两个人，扛着什么东西往仓库方向走。苏荷屏住呼吸，眯起眼辨认——不是何承业，身形不对。

她换了块石头继续蹲，脑子里把一会儿要说的话又过了一遍。冒称省城军区后勤部的人，这事风险极大，万一何承业一个电话打过去核实，她当场就得穿帮。但没别的路，四十捆橡胶管，在1988年意味着什么？意味着倒手就能赚五千往上，意味着能一次性把城南巷七号的门面重新翻修，意味着苏记小馆从巷口苍蝇馆子变成真正像样的馆子。

九点二十，一辆黑色凤凰自行车从码头东边那条土路上拐进来，车灯一明一灭闪了三次。

苏荷站起来。

骑车的人在她面前刹住，是个三十来岁的瘦高个，穿一件深蓝色工作服，袖子上沾着机油，脸上架着副黑框眼镜，看起来像个厂里的技术员。他上下打量苏荷，眉头皱起来：“就你一个人？”

“就我一个。”苏荷笑了笑，把介绍信递过去，“您是刘叔介绍的吧？他让我直接找您。”

何承业接过介绍信，借着手电筒的光看了两遍，又抬眼打量她：“刘叔没说是个女的。”

“他也没说您这么年轻。”苏荷把大前门掏出来，递过去一根，“这不重要，路子对了就行。”

何承业没接烟，盯着她看了几秒：“省城军区后勤部的人，就派你个小姑娘来跑货？”

苏荷心一提，但脸上不露，嗤笑一声：“正因为是女的才跑得动。省城那边盯得紧，男的一出差就被家属问东问西，女的打掩护方便。您要是不放心，我现在就走，这批货自有别人接。”

她说完作势要转身，心里默数一二三。

“等等。”何承业果然叫住她，“货在仓库里，钱带了吗？”

“带了一半定金，见到货再付另一半。”

何承业点点头，推着自行车往仓库那边走。苏荷跟上去，手心全是汗。

仓库是一间铁皮顶的旧棚子，推开锈迹斑斑的铁门，里面堆着麻袋和木箱。何承业打开手电，照亮墙角垒得整整齐齐的黑色橡胶管——果然四十捆，成色新鲜，是正儿八经的工业级。

苏荷蹲下去摸了摸，心里飞快地算了一遍：这批货按黑市价，至少值六千，如果拿到省城转手卖，能翻倍。但这一趟只是探路，顾长山那三千转业费不能全砸进去，必须先试探何承业愿不愿意拆开卖。

“货是好货，”她站起来，“但我要不了四十捆，先拿十捆。”

何承业脸色一沉：“开玩笑？我大半夜跑过来，你就拿十捆？”

“刘叔没跟您说清楚？我那边是新开的路子，头一回合作，得先试试水。十捆先走，价钱好说，合适的话——下个月四十捆全收。”

何承业沉默了一会儿。仓库里很静，只有风穿过铁皮缝隙的呜咽声。

“二十捆，最低了。”他竖起两根手指，“价钱按咱们说的，不能再少。”

苏荷心里算了算，二十捆的话，刚好卡着顾长山那笔转业费的上线，风险有点大，但也不是不能搏。

“行，”她点头，“成交。”

就在这时，仓库外面传来一阵急促的脚步声，紧接着是压低了的喊声：“何哥！何哥！片警过来了，抄近道走的，就两分钟！”

何承业脸色瞬间变了，一把抓住苏荷的胳膊：“从后门走！”

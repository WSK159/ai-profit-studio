# 第449章 铁盒里的泥人

铁皮盒比巴掌大不了多少，入手沉甸甸的，摇一摇没有声响。苏荷拂去灰尘，盒盖上的“方”字笔画遒劲有力，收锋处带一点向上的钩，像是写字的人习惯性用力过猛。

她拨开搭扣，盒盖弹开一条缝，一股陈年的油烟味裹着淡淡的药材气息扑出来——那味道她熟悉，是师父炖汤时习惯在灶膛角落丢一片陈皮和几粒茴香，长年累月浸进木头里留下的底味。

盒子里没有银票，没有书信，只有一只小泥人。

泥人约莫两寸高，捏得粗糙，五官只能勉强看出轮廓，但衣纹处用竹签刻了几道褶子，腰部围了一圈细泥条，像是扎了围裙。苏荷把泥人托在掌心，指尖触到底部，发现那里按进了一粒黄豆大小的东西，取出来一看，是一颗没脱壳的稻谷。

“是个人？”顾长山凑过来看，火光把泥人的轮廓照得分明。

“是我师父捏的。”苏荷声音有点哑，“他从前说过，他这辈子只会捏一样东西——捏人。他说，做菜和捏人一样，火候过了就硬，火候不够就散。”

她翻过泥人背面，在围裙边缘看到一行细小的划痕，歪歪斜斜，像用指甲尖刻上去的：“第三碗汤，只给懂苦味的人。”

苏荷怔住了。

陈米粥的苦中带甜，乌铁牌上的五瓣梅，竹牌上那句“尝过陈米粥的苦再打开看”——而此刻，铁盒里的泥人又提到“第三碗汤”。三条线索像三根指向同一方向的箭头，全部指向一个答案：师父留了第三碗汤，汤的配方，或者说汤的“底”，在南边竹林里等着她。

“稻谷是什么意思？”顾长山问。

苏荷把稻谷放在指尖碾了碾，谷壳干燥，但谷粒饱满。“五谷为养，师父说过，一碗汤的底子不是肉不是骨，是粮食。”她抬起头，“他在提示我，第三碗汤的底，是粮食熬出来的。”

窑洞外的风呜呜地灌进来，火光跳了两下，顾长山忽然伸手，把泥人拿过去翻来覆去看了两遍，目光停在泥人脚底：“这里有字。”

苏荷低头，果然，泥人的脚底刻着两个字，笔画极浅，若不是火光斜照几乎看不见——渡头。

渡头。何家渡。竹牌上那条弯曲的纹路，果然指向这里。

“你师父留下的每样东西，都对应一个地点。”顾长山把泥人递回她手里，“乌铁牌是信物，竹牌是地图，泥人是引子——他在指引你去找那碗汤。”

苏荷把泥人仔细放回铁盒，正要合上盖子，忽然发现盒盖内侧的金属面有道异样的光泽。她用指甲刮了一下，那光泽是刻上去的——极细的一条鱼，尾巴卷成环状，嘴里衔着一片叶。

“这个纹章……我见过。”顾长山的语气忽然变了，带着一丝不易察觉的紧涩，“在沈伯言的账簿扉页上。”

苏荷抬起头：“沈伯言？那个北上的旧识？”

“他给我看过一本账册，封皮内侧印了同样的鱼衔叶纹章，说是他从前当学徒时东家传下的规矩。”顾长山眉头拧着，“他说，这个纹章代表‘本味归真’。”

窑洞里的火光噼啪响了一声，一根明柴塌下来，火星溅了满地。苏荷把铁盒合上，抱在怀里，沉默了好一会儿才说：“我师父和沈伯言……是同一路人。”

顾长山没有反驳，只是坐在火堆边，把干柴往里面推了推：“你打算什么时候过江？”

“天亮就过。”苏荷仰头，透过坍塌的窑顶望着夜空，“但我得先把一件事想透——师父留了三样东西给我，每一样都和‘汤’有关。乌铁牌是资格，竹牌是路，泥人是底。他这么费心，说明那碗汤……”她顿了一下，“可能不只是汤。”

“那是什么？”

“是答案。”

苏荷说完这两个字，窑洞里安静下去，只剩柴火燃烧的噼啪声。过了许久，顾长山忽然开口，声音很低：“我有一件事一直没告诉你，到沈伯言那里，才知道我父亲当年不是跑船死的。”

苏荷的手一紧，抱在怀里的铁盒微微发烫。

“是被人从船上推下江的。推他的人，手上戴着一枚五瓣梅银戒。”

火光明灭不定，照在顾长山侧脸上，那道从眉骨延伸到颧骨的旧伤显得尤其深刻——他从来没有主动提过这道伤疤的来历。苏荷看着他的眼睛，那里面有一团烧了多年的火，终于在今晚露出了苗头。

“五瓣梅银戒……和我乌铁牌上的五瓣梅，是同一个图案？”

顾长山沉默了很久，久到火堆里的明柴烧成灰烬，暗红色的余烬在风里一闪一闪。他终于点了点头。

“所以，你帮我查枯井，不全是为了帮我。”苏荷的声音很轻，但没有责怪的意思。

顾长山抬眼：“我帮你，是真心想帮你。但我也想知道，我父亲当年挡了谁的路。”

窑洞外的天边，第一缕灰白的晨光正在裂开夜色。

苏荷站起身，拍拍衣摆上的灰，把铁盒揣进怀里，又摸了摸贴着胸口的乌铁牌。“天亮了。”她朝窑洞外看了一眼，江面上泛着薄薄的雾，那艘渡船已经泊在码头边，老船夫佝偻的身影立在船头，手里提着一只竹篮，篮子里赫然放着一只陶罐——与昨夜那只一模一样的五瓣梅印记陶罐。

苏荷眯起眼，老人也看见了她，缓缓抬起手，朝她招了招。江风吹动他的衣摆，苏荷的喉咙忽然有些发紧——她终于知道一直萦绕在心头那种怪异感是什么了。

这位老船夫的身形，与磨坊纵火时那道驼背身影，几乎一模一样。但他站立时脊背挺直，毫无异样，像是练过一副好筋骨，唯有抬手的动作牵动肩胛时，左肩隐约矮了半分——极其细微，若非苏荷昨夜盯了那道背影一整夜，根本看不出差别。

“长山。”她压低声音，“船夫后背，有旧伤。”

顾长山微微一怔，随即压低声音：“你是说——”

“他可能就是磨坊里那个驼背。”

江风拂过，老船夫提着陶罐，在熹微晨光里咧开嘴，露出一口烟黄的牙齿。

“姑娘，粥熬好了，过了江再喝。”

他不是接他们去对岸的船夫，是送他们去汤底的引路人。

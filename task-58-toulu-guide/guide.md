# 短剧投流避坑指南

## 一、预算分配（新手）

- 测试期：总预算的 20%，单条素材 50-200 元测试
- 放大期：ROI 达标的素材，逐级加预算（1.2x → 1.5x → 2x）
- 止损线：单素材消耗达 3 倍预期成本仍无转化，立即关停

## 二、素材测试

- 一次测 3 个钩子版本（开头 3 秒）
- 前 3 集免费 + 付费点在第 4-11 集
- 关键指标：前 3 秒完播率（目标 50%+）、付费转化率

## 三、定向与投放

- 男频：25-45 男性，下沉市场；女频：20-40 女性
- 先宽定向测试，再按数据收窄
- 避开大促期（流量贵、竞争大）

## 四、ROI 计算

- ROI = 分账收入 / 投放成本
- 回本线 1.0，健康线 1.2+；低于 0.8 连续 3 天即停止
- 记得计入：制作成本、平台抽成、退款

## 五、常见坑

1. 一上来就砸大预算（先测试）
2. 素材不迭代（每周换钩子）
3. 只看播放不看付费（播放是虚荣指标）
4. 忽略自然流量（先自然流量验证，再投流放大）
5. 无版权/授权就投放（封号风险）

## 六、建议流程

样片 → 免费自然流量测试 → 收集完播/付费数据 → 小额投流验证 → ROI 达标再放大 → 每周复盘迭代

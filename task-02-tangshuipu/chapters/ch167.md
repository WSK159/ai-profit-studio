# 第167章 桥面石下的铁盒

灰夹克走后，围挡内安静得只剩下芦苇摇晃的声响。苏棠蹲在桥面上，手指沿着那块深色青石板的边缘摸索。石板与周围的青石之间有一道极细的缝隙，缝隙里填满了干涸的泥垢，若非刻意寻找，根本不可能发现。她掏出钥匙，把铜钥匙的齿尖对准缝隙，试了两次，钥匙刚好卡进那道缝里，像锁芯对准了锁眼。

“动了。”她说。

顾淮安过来帮她把石板边缘的泥垢清理干净，石板约莫两拳厚，边缘被凿出一个小小的凹槽，刚好可以让手指扣进去。两人合力，石板缓缓翘起，底下是一个约莫一尺深的浅坑，坑里放着一只铁盒，铁盒通体生锈，但锁扣仍扣得严实。锁扣上没有锁头，只缠着一圈绕了七八道的红线，线头已经发脆，苏棠一碰就断成几截。

她打开铁盒。盒内铺着一层油纸，油纸上放着一本巴掌大的旧笔记本，本皮是牛皮纸，边角磨得发白，封面上用钢笔写着一个字：“棠”。

苏棠翻开第一页，里面是外婆的笔迹，日期从三十七年前的春天开始，断断续续记了将近十年。她翻了几页，目光停在一段用红笔圈起的文字上：

“三月十六，周敬德又来铺里，说要买《归魂》方子。我说不卖。他说，你不卖，这条巷子总有天会拆到我手上来。我当他是气话。哪知他真的动了手，先是在糖记的招牌上做文章，后又找人篡了棠记的旧档。我在桥下埋这一本，是怕有一天连铺子里都留不住东西。”

苏棠的手指轻轻抚过那几行字，又往后翻，笔记本后段夹着一张折叠的纸，展开是半张票据——与外婆手稿夹层里那半张票据的纸张一模一样，边缘的撕痕曲折咬合，竟是能拼上的。她把笔记本和折纸都收进铁盒，又翻看盒底，发现盒底刻着一行极小的字：若开此盒，便欠下一碗糖水，须以归魂桥的水煮心交还。

“归魂桥的水？”苏棠皱眉，“桥下早就没水了，这怎么还？”

顾淮安看着那行字沉默了一会儿，说：“归魂桥的水，未必是河里的水。你外婆是糖水铺的手艺人，她说水，很可能指的是某种汤底或糖水的‘心’。你前头说过，《归魂》方子与归魂桥同名，这本笔记本里会不会记了方子的源头？”

苏棠把笔记本从头到尾翻了一遍，前大半部分是日常琐记，菜谱、客人喜好、天气与采买，直到三十年前那一页之后，笔迹明显变乱，叙事也变得支离破碎。有一页只写了半行字：“周敬德死了。债跟了他的儿子。我不该，可我累了。”另一页写着：“糖记改名那天，我在铺子里坐了一整夜，一碗姜撞奶都没卖出。”还有一页几乎被水渍洇透，字迹模糊，只勉强辨出几个词：“顾……糖……来取……”

“顾？”苏棠抬起头，“外婆提到了‘顾’。”

顾淮安的目光落在那个字上，久久没有移开。他沉默片刻，说：“我父亲顾长明失踪那晚，临水巷的人说他从我家里端走了一碗糖水。那晚送糖水的人，会不会就是你外婆？”

苏棠没有回答，她把笔记本放回铁盒，抱起铁盒站起身。围挡外的天色已经暗下来，远处的临水巷亮起零星的灯火。她走到铁皮缝隙边，侧耳听了听，外头没有脚步声，只有风刮过碎砖堆的呜咽声。

她回头看了一眼归魂桥。桥面正中那块青石板搁在桥边，露出黑黢黢的浅坑，像一只闭不上的眼睛。她忽然明白外婆说的“水走过的路”是什么意思——那不是河里的水，是那些年从巷子里流走的人、流走的糖水、流走的旧事。它们都从这桥下经过，最后都沉在了泥沙里，只等她来一口一口地捞起来。

顾淮安走到她身旁，说：“笔记本里还夹着东西。”

苏棠打开铁盒低头一看，油纸底下确实还有一样东西——一根银质顶针，顶针内侧刻着一个极小的“棠”字，与外间旧物铺里卖的那种劣质货色不同，这枚顶针边缘包了一圈缠枝莲纹，做工精细得不像寻常人家用的。苏棠把它拿起来，顶针内壁深处似乎有什么东西卡着，她用指甲轻轻一拨，一颗米粒大小的纸团滚落出来。

纸团展开，上面只有五个字：找沈酌，要针线。

沈酌。前些天在旧档案馆里替她翻出外婆旧档的那个年轻姑娘，沉默寡言，在档案室里整理旧户籍，姓沈，名酌。苏棠握着那枚顶针，指尖不由自主地收紧。外婆手稿里提到过沈家旧事，但只是一笔带过，她原本没放在心上。可如今外婆隔了三十多年，从桥下递出这根顶针，让她去找一个姓沈的姑娘“要针线”——这绝不是巧合。

归魂桥的晚风从河道里卷上来，带着淤泥与枯草的腥涩气味。苏棠把铁盒抱在怀里，走出围挡的铁皮裂口，临水巷的灯火在远处连成一条温暖的线，像一碗糖水从碗沿缓缓淌下的弧度。

“明天，”她说，“去找沈酌。”

顾淮安点了点头，没有说话。他走在苏棠侧后方半步的位置，目光落在她怀里的铁盒上。盒底那行字还在他脑子里转——“以归魂桥的水煮心交还。”他现在知道那碗糖水欠给谁了，但他不知道，他还糖水的那一天，会不会正好是真相彻底掀开的那一天。

夜色里，巷口棠记糖水铺的灯亮了，橘黄色的光透过木门缝隙漏出来，像外婆还坐在灶前等着锅里的糖水起泡。苏棠站在门外，没有急着推门。她把铁盒贴了贴胸口，像抱着一碗还没出锅的、滚烫的糖水。

# 第120章 药方残页

周明远那只骨节分明的手从西装内袋里抽出一张泛黄的纸，轻轻搁在糖水铺的木桌上。窗外台风过境的残雨还在滴答，巷口的灯笼被风吹得东倒西歪，店里只有一盏昏黄的吊灯亮着。

苏棠没有看那张纸，先看了周明远的眼睛。这个自称“糖记”连锁品牌创始人的人，眉目间有一种说不出的熟悉感，像在哪里见过，又想不起来。

“苏小姐，我替你先祖跑这一趟，是诚意。”周明远把那张纸往她面前推了推，“仁济堂的旧档案，你外婆手稿里缺的那半张方子，在我手里。”

苏棠垂眸。纸上墨迹褪色，依稀可见“归魂”二字，下头是几行小楷药名，与她外婆手稿夹层里那张拼不上的碎纸屑正好是同一笔迹。

“你怎么会有这东西？”她问。

周明远笑了笑：“六十年前的事，翻出来不容易。但我有我的渠道。”他的手指在纸上轻轻叩了两下，“苏小姐，你用半本手稿换这半张方子，不吃亏。”

顾淮安站在门边，手插在白大褂口袋里，一直没说话。此刻他开口：“归魂散这味药，是治什么的？”

周明远眼皮跳了一下，没接话。

“我查过仁济堂的旧档。”顾淮安走过来，在苏棠身边站定，“归魂散不是药，是毒。六十年前仁济堂失窃案里丢了整整三抽屉的药材，其中一味就是归魂散的主药，断肠草。这东西能让人五脏衰竭而死，仵作验不出。”

空气静了一瞬。

苏棠的目光从残页移到周明远脸上：“周老板，你手里拿着断肠草的方子，来找我换我外婆的手稿——你是想告诉我，我外婆跟六十年前那桩案子有关？”

“我没这么说。”周明远的表情第一次有了裂痕，“我只说这方子值钱。”

“值多少？”苏棠问。

周明远顿住，像没料到她会问得这么直接。片刻后，他伸出三根手指：“三十万。连同你铺子的拆迁补偿，我可以翻倍。”

苏棠看着他，忽然笑了。那笑意和外婆照片里的眉眼如出一辙，淡得近乎凉薄。

“周老板，”她说，“我外婆的手稿里有一页夹层，写着一句话：‘药是吃进肚里的，害人也是要害自己的。’您说，她老人家是要用归魂散去害谁？”

周明远的脸刷地白了。

他站起身，椅子在木地板上发出一声刺耳的刮擦。他收起那张残页，语气变了调：“苏小姐，你这是敬酒不吃吃罚酒。”

“糖水铺的规矩，”苏棠不为所动，“只敬客，不敬酒。”

门外雨声忽然大了一阵，一道闪电劈开天幕——紧接着一阵急促的脚步声从巷口传来，陈阿婆在大雨中跑得裙摆湿透，手里攥着一只布包，气喘吁吁地撞进门来。

“棠丫头！你外婆的东西！”陈阿婆的嗓子沙哑，“我去翻老屋的旧柜子，翻到一只包得严严实实的油纸包——上头写的字，是……是你外公的名字！”

周明远猛然回头。

油纸包在苏棠手里打开，里面是一张剪了角的旧处方笺，笔迹与那半张票据一模一样，落款处签着一个名字：

容盛。

不是马容盛，是容盛——仁济堂失踪的账房。

周明远定在原地，像被人钉住了脚。

苏棠抬头看他，一字一字地说：“周老板，你姓周——你爷爷是不是叫周永昌？”

雨打屋檐，灯影摇曳。顾淮安看见周明远拢在袖口里的手，微微地抖了一下。

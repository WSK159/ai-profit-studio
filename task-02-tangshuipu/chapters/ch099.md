# 第99章 花枝上的同心扣

那枝桂花被苏棠摆在吧台上，花萼上的红线结在灯下看得更清楚了。同心扣，外婆教过她两遍——一遍是她十岁那年端午，一遍是外婆临终前三天，手已经抖得几乎捏不住线。

“记好了，这个结只有咱家的人会打。”外婆那时候说，“旁的人打了不对。”

苏棠记得很清楚。可现在这根红线上的结，打得一丝不差。

“陈阿婆，”她把花枝举起来，“这结，你认识吗？”

陈阿婆脸上是少见的惊疑，她凑近看了片刻，忽然往后一退：“她回来了？”

“谁？”

“容玉容。”

三个字撞进空气里。顾淮安放下手里的杯子，微微皱眉：“她不是……”

“不是死了？”陈阿婆摇头，“周家那老头子说她失踪，可我知道的，她不是失踪。她是自己走的。”她顿了顿，声音压低了半度，“二十六岁那年，容玉容来找你外婆，说你太外公病重，要她回去见最后一面。你外婆让她住下来，她住了一夜，第二天一早就走了。”

“走了？去哪儿了？”

“没人知道。”陈阿婆说，“我最后一次见她，是在药房门口。她穿一件青灰色褂子，手里拎着个藤箱，我说容姑娘你去哪儿啊，她说——”陈阿婆的声音卡住了。“她说什么？”

“她说，去把属于她的名字拿回来。”

屋里安静了几秒。窗外有风吹过，桂花簌簌地落了满地。

“药房呢？”顾淮安问，“那间药房，和容玉容有什么关系？”

陈阿婆沉默了一会儿，刚要开口，门外传来一声喊：“苏姑娘！有你的信！”

送信的是巷口小卖部的刘叔，手里扬着一个牛皮纸信封。信封上没贴邮票，只有一个墨迹淋漓的地址——“临水巷棠记”，收信人写的是“容月”。

苏棠拿着信封，忽然觉得那两个字烫手。她撕开封口，抽出一张纸条，上面只写了一行字：“民国三十六年春，棠记第二任传人容玉容，亲手写下这张方子。”

纸条背面，用铅笔描着一幅极简的地图，几条线勾勒出巷子的轮廓，在一处画了个圆圈，圈旁标注三个字：“桂花井。”

陈阿婆凑过来看了一眼，脸色骤变：“桂花井……那不是早就填了吗？在老巷底，早年那一带是药房后院的井。填井那年，闹出过一场大火。”她回忆着，声音越来越低，“那火，烧的就是容玉容的住处。”

苏棠紧紧攥着纸条，转头看向顾淮安。顾淮安已经把手机屏幕递到她面前——档案库的记录：“桂花井，1991年填平，原因：地质沉降。周边建筑拆除时间：1992年来……旧产权登记人：容玉容。”

所有线索都指向一个方向：容玉容，和药房，和填掉的那口井。

“走。”苏棠把纸条叠好收进口袋，“去桂花井。”

“现在？”顾淮安看了眼窗外，“快九点了。”

“桂花井白天太亮，”苏棠说，“而且你看这个圆——”她指着纸条上的标记，“圈的边上有一点，铅笔描的。我外婆画儿不好，她那点，画的是一盏灯，她知道有人要夜里去。”

陈阿婆看着苏棠，想起了什么，忽然伸手从脖子上解下一枚墨色的玉坠子：“你外婆十五年前给我的，说什么好东西都要等对的时候再取。她那时候已经病了，说话颠三倒四的，我没当回事。”她把玉坠放到苏棠手心，“桂树底下应该有口暗渠，顺着走能到井底。”

苏棠握紧玉坠，与顾淮安一前一后出了门。桂花井在老巷底，离糖水铺步行十余分钟，那段巷子没有路灯，只有月光从屋檐的缝隙间漏下来。顾淮安走在前面，忽然停下来：“你说，那纸条是谁放的？”

苏棠看着他的背影，沉默了两秒：“我不确定。”

桂花井的旧址是一块长满荒草的空地，井口早被水泥抹平了，看不出原来的样子。苏棠蹲下去，用手机照亮地面。顾淮安从路边借了根铁尺，找到井点后使劲拨了拨土，忽然“咔”一声，砖缝之间露出一块青石板。

苏棠深呼吸，把那枚玉坠握得更紧。她把玉坠贴合石板缝隙，推门般动了动，青石板竟然松动了一角，露出一道黑漆漆的洞口，霉味涌上来。

苏棠正要侧身探下去，顾淮安一把扣住她手腕：“你在这儿等着，我下去。”

“凭什么？”

“我有执业医师证，”他说，“要摔了，我能现场急救。”

苏棠瞪了他一眼，却被他拉到身后。他侧身跳了下去，脚落在枯叶与碎石上，声音闷响传上来。几秒后，他抬头：“有东西。”

他把一只锈迹斑斑的铁盒举上来。苏棠打开盒盖——里面躺着一本蓝布封皮的笔记本，封面上用水墨写着三个字：

《容氏食单》。

她翻开第一页，看到那行字的瞬间，眼泪毫无预兆地落下来。那上面写着：阿姐，我把名字里那枚“玉”字留给你，你要替我传下去。

落款：容玉容。

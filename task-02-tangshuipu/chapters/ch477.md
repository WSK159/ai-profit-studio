# 第477章 井水甜

走回棠记糖水铺时，巷口的灯刚好亮了。暖黄的灯光罩在青石板路上，映出苏棠和顾淮安并肩的影子。陈阿婆坐在自家门口剥豌豆，见了他们，笑眯眯地招手：“小棠回来啦？阿婆给你留了碗桂花酒酿，搁在灶上温着。”

苏棠心里那根弦微微一松，笑着应了声“好”。她走到陈阿婆跟前，蹲下来帮她捡滚落的豌豆，像是无意间开口：“阿婆，今天下午有人来过巷子吗？我回来的时候看到墙根下有一排小脚印，像小孩子光脚踩的。”

陈阿婆手里的动作顿了一瞬，极短，若非苏棠正盯着她，几乎察觉不到。随即她笑着摇头：“哪有什么小孩，巷子里就我们几个老骨头。怕是野猫踩的吧。”

苏棠没再追问。她起身说去喝酒酿，进了铺子门，顾淮安已经站在灶台边，正在看那口旧铜锅。铜锅上还留着中午煮姜茶的痕迹，锅底余温未散，水面浮着几片切得薄薄的甘草片。

苏棠心口一紧。她中午煮姜茶放的是整根甘草，从没切过片。而下午他们离开时，铜锅已经刷干净、倒扣在灶台上晾干。可眼前的铜锅盛着半锅清水，水面上漂着甘草片，锅下还压着一小撮温热的灶灰——像是有人在他们离开后，用这口锅煮过什么东西。

“水还是温的。”顾淮安说，“比姜茶煮沸之后自然冷却的温度要高，像是刚添了柴，又及时熄了。”

苏棠放下手里的桂花酒酿碗，快步走到灶台后侧的柴堆旁——那里堆着新劈的木柴，旁边放着一把旧铁钳。铁钳的嘴夹着一片烧了一半的纸，纸色泛黄，边缘焦黑，但字迹还能辨认。她轻轻展开那片烧剩的纸，上面只有一个字：井。

是外婆的字迹。她认得那一撇一捺的走法，外婆写字行笔极快，“井”字两道横笔末尾都有个不起眼的小勾，是常年写菜谱落下的习惯。

“有人用外婆的纸上，在这口锅里煮过东西。”顾淮安走到她身边，看着那片烧剩的纸。

苏棠的太阳穴突突直跳。她把纸片仔细夹进手帕里收好，又去看那锅甘草水。水色淡黄，没有甜味，但有一丝极其细微的涩香——这是井水的味道。她在北城做甜品师时尝过各地水质，井水与自来水、矿泉水的区别一尝便知。这锅水，是从井里打上来的。

她抬头看了一眼铺子后门的方位——外婆在院角有一口老井，井口不大，井圈常年用青石砌着，平时总是压着一块厚木板，是外婆在世时的习惯。苏棠从没见过那井里打出水来。

她心里涌起一个念头：会不会，下午有人从还债堂里的那幅竹篾图找到了井底暗渠，一路走到了铺子后院的井口？

顾淮安看她神色，便知她在想什么。两人走到后院。那口老井静默地立在桂花树影下，井口的厚木板还在，但木板边缘的灰土有一道新鲜的擦痕，像是刚被掀起过又合上的。

苏棠蹲下来，用手轻轻掀起木板一角。井里没有水汽，反而涌上来一股干燥的、混着陈旧木料和一点淡淡桂花蜜的气味。她的视线落向井壁内沿——那里新添了一道刮痕，弯弯绕绕，像是有人用硬物在砖上刻了一道线。

那线条的走向，与还债堂竹篾图上那道波浪线几乎一模一样——从井口延伸下去，中段弯出一个圆环，标着“井”字的位置。

顾淮安从口袋里掏出一只细长的手电筒，照亮井壁下方。在井壁中段，他照到一样东西：挂着一只巴掌大的油纸包，用红绳系在从砖缝中探出的一根铁钉上，红绳还打了个漂亮的蝴蝶结——是陈阿婆惯用的系法。

苏棠伸手将那油纸包取下来，拆开时手指微微发抖。纸里包着一块黄色的糕，桂花糕，还是温的。糕上压着一枚小铜钱。她翻过来一看——铜钱上刻着一朵六瓣梅花，花心是“棠”字，背面那刚才在石板缝里看到的“非”字刻痕，深了一分。

而在桂花糕底下，压着一张窄长的纸条，上面只写了一行字，是陈阿婆的笔迹：“井水甜，但井底有眼睛。今晚别开井，明早我在梅树下等你。”

苏棠捏着那张纸条，指尖微微发白。她想起外婆手稿里那句“欠的还了才敢尝”，又想起陈阿婆刚刚在门口剥豌豆时的笑——那老人家眼底的温和之下，藏着一层她此刻才看出来的东西。

是等待，也是防备。

顾淮安伸手将井盖木板重新合上。他沉思片刻，低声说：“她让你明早去梅树下，那今晚？”

苏棠把那块桂花糕收进衣襟里，握紧那枚铜钱，嗓音低沉：“今晚，我守着这口井。”

夜色渐渐漫上来，桂花树影碎在井圈的青石面上，像一盏盏熄灭过半的灯。而苏棠听到从井底极深处，传来一声极轻极轻的水响——像是那口井里，真的有什么东西，在睁着眼睛。

# 第574章 缸底的账本

黄泥封口的陶罐捧在苏棠手里，沉得不像话。晨光从桂树断桩的裂口斜斜漏下来，照在陶罐表面那层干裂的黄泥上，像一张老得起了皱的脸。

顾淮安蹲在坑边，用匕首轻轻刮开泥封的一角，一股极淡的桂花香便从那道细缝里钻出来，三十年的光阴忽然有了味道——不是陈腐，而是某种被小心翼翼保存着的、不肯散去的甜。

“别全打开。”苏棠按住他的手，“里面的茶，怕是比我们两个的年纪加起来还要大。”

顾淮安点头，把陶罐小心放到一旁叠好的雨衣上。坑底还有一沓账本，牛皮纸封皮已经发脆发黄，边缘被虫蛀出细密的孔洞。苏棠戴上手套，一页一页翻过去。

1963年，花岭供销社。账簿的笔迹有两种，一种方正规矩，墨色浓重，一笔一划都像是刻出来的——那是外公的字，苏棠认得，外婆的旧木匣里存着他年轻时寄来的信。另一种则娟秀纤细，落笔轻，收笔快，带着明显的南方口音——那是外婆的笔迹。两种笔迹交替出现在同一本账上，间隔从不超过三天。

四月十七，棠桂取桂花茶二斤，付现。四月二十，莫绣补桂花茶三斤，赊。四月二十二，棠桂付清欠款，另取干桂花一包。四月二十五，莫绣取冰糖四两。四月二十七，棠桂还竹篮一只，取桂花糖二斤，托供销社代送。

苏棠的手指停在那行字上，久久没动。托供销社代送——送往哪里？账簿上没有写。但下一页，供销社的收货记录里，出现了一行新字：五月二日，收花岭小学教师莫绣寄包裹一件，内为桂花糖二斤，收件人：棠桂。

花岭小学教师。

苏棠抬头看向顾淮安，声音有些发紧：“外公在花岭小学教过书？”

顾淮安接过账簿翻了翻，指着边角处一行极淡的铅笔批注：“这里——‘绣调任，冬后归’。”

苏棠心里那根弦轻轻颤了一下。外公调任走了，外婆留在花岭。那桂花树下的约定，就是在那个时候定下的？冬至后来取，树下留铃为证——铜铃是他们约定的信物，桂花茶是他们约定的信物，那面背面贴了照片的黄铜小圆镜，也是。

缸底还有东西。顾淮安伸手下去，摸出一把铜锁，锁孔里插着钥匙，已经锈在一起打不开了。旁边是那面黄铜小圆镜，镜背贴着的照片已经泛黄，边缘卷起，但照片上的人还看得清楚——年轻的外婆，大约二十岁出头的模样，站在桂花树下，辫子垂在胸前，嘴角抿着一点极淡的笑。

照片底部有一行小字，是外公的笔迹：吾妻棠桂，冬至夜，桂花树下不见不散。落款：莫绣。

苏棠看着那行字，眼眶忽然就热了。她的外婆，她从小叫到大的阿婆，她以为外婆一辈子都在糖水铺里守着锅勺、守着那些甜腻腻的方子——可她不知道，外婆年轻的时候，有个男人叫她棠桂，站在桂花树下等过她。她也不知道，外婆的名字里那个“棠”字，原来从来都不是随随便便取的。

“苏棠。”顾淮安的声音从头顶传来，带着一点迟疑，“你外婆的名字——”

“我外婆叫苏桂芳。”苏棠低头看着照片上那张年轻的脸，“不叫棠桂。”

沉默了一会儿。风从花岭的坡上刮下来，吹得断桩旁那棵老树的残叶沙沙响。

顾淮安忽然说：“你看这张账本的背面——有人写过字。”

苏棠把账本翻过来。牛皮纸的背面，有一行铅笔写的字，笔迹很新，和她前两日在戏台楼下找到铜铃时看见的那行字一样，是灰衫老太太的字迹。字很小，像是怕被人看见似的：

“她等了四十年。你来了，她就该走了。”

苏棠捏着账本的手微微收紧。

顾淮安站在坑边，忽然极轻地叹了口气：“苏棠，那个灰衫老太太——她知道你外婆真正等的那个人，从来就不是冬至那碗茶。”

苏棠没说话。风把账本最后几页吹得翻动起来，她看见账簿最后一页夹着一张薄薄的纸，纸已经和牛皮纸黏在一起，要很小心才能揭开。她一点一点把它剥下来，展开——

那是一张收款收据，抬头是“花岭县卫生所”，日期是1964年春天。收款事由那一栏填得潦草：“产妇住院费”。交款人：莫绣。

苏棠愣住了。

1964年春天。外公调任离开是在1963年冬天，如果外婆在1964年春天住院生产——那孩子呢？她外婆明明只有苏棠母亲一个女儿，而苏棠母亲生于1965年秋。

那这张1964年的住院费的收据，是谁的？

她翻到收据背面。那里有一行几乎看不清的铅笔字，已被水渍洇成模糊的一片，但末尾两个字还清清楚楚——“葬女”。

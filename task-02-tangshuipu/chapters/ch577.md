# 第577章 有人来过

那截青灰色布料线头被夹在旗杆基座缝隙里，像是什么人蹲下来，在里面摸索过一番。苏棠蹲下去，用指甲小心翼翼地把线头抽出来——棉麻质地，颜色洗得发白，像是旧衣服上掉下来的。线头边缘没有毛刺，反而整齐，像是被什么锋利的物件剪断的，而不是系在木屑上蹭掉的。

顾淮安接过线头，对着日光看了看，眉毛轻轻一蹙：“这是老年装的袖口布料。方向是往外的，说明人从里面往外抽手，被旗杆夹住了，用力拉断。”

苏棠心里一沉：“有人提前来过，在缸里找东西？”

“但是锁没有被撬。”顾淮安蹲在缸边，指尖沿着缸沿的泥痕摩挲，“缸盖上的土封还是原来的，锁孔也没有新痕。你开锁的时候，我听见锁簧响，是原装的。”

“那这个人不是来找缸的。”苏棠的目光缓缓移向戏台，“他在找别的。”

她站起来，绕到戏台后面。台后的地面是夯实的泥地，干硬板结，上面覆着一层薄薄的落叶和浮土。靠近后墙的地方，泥土浮起一小片浅浅的压痕，已经半干了，但轮廓还在——像是一个人的鞋底，半尺长，前掌比后掌宽。是平底布鞋的印子，穿着它的人，脚不大，年纪应该不小。

苏棠正要细看，余光扫到后墙根一条干涸的水沟。沟里被人翻动过，淤泥翻上来，露出底下几块碎瓷片。陶片没什么特别，灰褐色的，像是旧瓦罐。她伸手扒开，把碎瓷片拎起来，拼了两块，忽然愣住了——拼缝处，有一道釉下彩的墨痕，画的是半朵桂花。

“这瓦罐，”顾淮安蹲在她身边，目光沉沉，“和缸是同一种釉。碎的时间不算太长。”他拈起一片陶片的边缘，釉面断口光洁，没有太多风化，他眉头微蹙：“最多十天。有人把一只罐子打碎了，又把碎片扔回沟里。”

“埋在墙根下的罐子。”苏棠的心跳快起来，她站起来，手掌按在戏台后墙上，“那里面装的是什么？被人拿走的是那东西？”

顾淮安没答，只伸手在墙根摸索。忽然，他的指腹触到一处细微的凹凸——一块青砖侧面的刻痕。他低头细看，又拿出手电照了照，只见砖面上刻着一行极小极浅的字，笔画生涩，像是用指甲或针尖硬刻上去的。字迹经历了不少年岁，缝隙里嵌着灰，但有几道刻痕明显比别的浅亮，是近期被什么东西磨出的。

那行字只有四个字：

“莫再找了。”

苏棠呼吸一窒。这四个字没有署名，但那个“莫”字的起笔带了一个微小的顿锋，和账本上外公莫绣的字迹一模一样。

“外公写的？”她问。

顾淮安摇了摇头：“刻痕不是新的，应该有几十年的光景了。但边上那几道磨痕是近期的，是有人用手摩挲出来的。”

“有人来过，看到这四个字，然后走了。”苏棠把那条青灰色线头攥紧，压在掌心，声音压低，“而他把缸里的东西留给了我们。”

顾淮安站在她身侧，忽然说：“陈阿婆。”

“什么？”

“陈阿婆告诉你外婆的事之后，她说过她有个旧邻居，穿灰布衣裳，近些年搬走了。”顾淮安的目光平静地看着苏棠，“我们走之前，我查了巷子里的住户登记。陈阿婆那排老房子，最后一间户主栏写的是——陈桂英。”

苏棠猛地抬头。

“陈桂英，陈阿婆的堂姐，1964年花岭卫生所的经办护士。”顾淮安把手机屏幕递过来，他提前存好的一张转录照，“影印档里记载，她当年体弱多病，很早就内退了。退休后，她搬回临水巷，跟陈阿婆做了几十年邻居。而她的丈夫，姓莫。”

姓莫。

苏棠的心像被一只手狠狠攥住。莫绣。外公的姓氏。而陈桂英的丈夫姓莫……她低头看着手里那张外婆与陈阿娇的合影，年轻的外婆笑容干净，旁边站着的陈阿娇眉眼温柔。那一瞬，她忽然觉得照片里两个人的神情，有些她说不上来的相似。

“顾淮安，”她说，嗓音发哑，“我外公当年，到底娶了几个老婆？”

顾淮安没有立刻回答。他用手电筒的光，缓缓扫过戏台后墙那四个刻字，又扫过那条干涸水沟里的碎瓷片，最后落回苏棠脸上，声音很低：“苏棠，你可能要重新认识你的外婆了。”

风卷着枯叶从戏台后面吹过，发出细细的声响，像有什么人，在很远的地方叹了口气。

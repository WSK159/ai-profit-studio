# 第115章 影子里的砖缝

那串朱砂手串在油灯下泛着沉郁的光。马容盛的手指从珠子上一颗一颗滑过，从第一颗数到最后一颗，又从最后一颗数回第一颗。

他今年已经记不清自己有多少岁，只记得墙上的砖换了三次。这间屋里没有镜子，他照过水碗，水面上的脸早就不是当年马老五那张瘦脸了。那匹马被时光拆了骨头，填进去的全是等人等出来的皱纹。

可手串还是那串手串。棠秋编完珠子给他的时候，他的手指还没长满茧子，还在替人画铺面的图纸。那会儿正是春末，糖水铺里飘着姜汁的味道，棠秋把最后一颗珠子穿进绳里，打一个结，往他手心一塞。说了什么来着？

“戴好了，丢了可就找不回来了。”

他找了。三十岁那年他去过省城，四十岁那年托人问过南边几个镇子，五十岁那年腿脚走不动了，就在这二楼窗口一坐一整天，看巷子拐角会不会冒出个梳长辫子的身影。再后来，他连辫子都不盼了，只盼一碗姜撞奶的味道从巷口飘过来。

可那味道再也没有出现过。他在这间屋子里煮过无数锅姜汁，倒掉，再煮，再倒掉。煮不出棠秋的手艺，他早该认了。

门外传来楼梯响。那脚步声在门口停了片刻，门缝下塞进来一张折成四折的纸。

老人盯着那张纸，很久才弯腰捡起来。红头文件，临水巷二期拆迁范围，里头列着他这栋老屋的门牌号。

他把纸放在桌上，手掌覆上去，纸面被压出细密的褶皱。半晌，他拉开床头最底下那个抽屉，抽屉空了很久，只躺着半张票据——纸已经黄得发脆，边角毛了，上面墨迹褪浅，依稀能辨出“仁济药房”四个字。

马容盛坐在床沿上，把那半张票据和朱砂手串放在一起。窗外的光照进来，照亮他手背上青褐色的老人斑。

二楼之下，巷子里传来糖水铺开张的动静。苏棠的声音隔着墙透进来：“顾淮安，你帮我看看这砖缝里是不是塞了什么东西——”

他听着，忽然嘴角抽了一下。像是想笑，又像是疼。

那扇门，终于还是有人来敲了。

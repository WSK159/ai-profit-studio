# 第522章 锈末与门缝

苏棠把指甲盖里那一点锈末小心翼翼地装进随身带的小玻璃瓶里，是早上从井底木门插销上刮下来的。她站在临水巷社区卫生服务中心门口，玻璃瓶隔着衣袋硌着大腿，像一枚未拆的信。

服务中心的院子不大，白墙绿窗，墙根的冬青修剪得整整齐齐。一楼诊室门半掩着，苏棠推门进去，看见顾淮安正低头整理桌上的病历本。他的白大褂袖口挽到小臂，露出一截清瘦的腕骨，上面有道浅浅的疤痕，苏棠第一次注意到。

“怎么来了？”顾淮安抬头，目光在她脸上停了一瞬，语气淡淡的，“脸色不太好。”

“来查点东西。”苏棠把小玻璃瓶放在他桌面上，瓶中锈末在日光灯下泛着暗红，“井底那扇木门的插销，刮下来的锈末，我想知道你诊所有没有类似的东西可以比对。”

顾淮安拿起瓶子，凑到窗边光线处细看。他转动瓶身，锈末在瓶壁内侧留下一道浅浅的痕迹。“不是铁锈。”他忽然说。

苏棠愣了一下：“什么？”

“铁锈是红褐色的，遇水会结块。这个偏赭，带着一点金属反光，更像是黄铜的氧化层和铁质混合。”顾淮安放下瓶子，从抽屉里翻出一个放大镜，对着瓶身又看了一会儿，“而且这个刮痕的深度，更像是有人反复用指甲去抠，或者是用某种薄片工具去撬过。”

苏棠心里一紧。她昨晚在井底看得分明——那道刮痕绕着插销一周，细密而有规律，像是有意为之，而且是近几个月内的痕迹。

“有配比工具吗？”她问。

“隔壁化验室有显微镜。”顾淮安起身，走了两步又回头，“你应该不只是想比对锈末吧？”

苏棠没说话，跟着他穿过走廊。化验室不大，仪器紧凑，顾淮安从柜子里取出载玻片，挑了一点锈末放在上面，压上盖玻片，推到显微镜下。他调了一会儿焦，示意苏棠来看。

她低头凑过去。视野里，赭色颗粒呈不规则块状，边缘参差，有几处极细的划痕呈平行线排列。“不是自然剥落。”苏棠轻声说，“自然锈蚀的颗粒边缘是圆钝的，这个……是硬物刮下来的，而且刮得很有力。”

顾淮安没接话，把自己白大褂口袋里的东西掏出来，一个小密封袋，里面有几粒同样颜色的碎屑。“我上周也刮过一处。养老院杂物间那扇铁门的门轴，锈得差不多掉光了，但门闩上也有这种赭色附着物。”他说着，把两处样本并排放在显微镜下对比，“颜色一致，成分应该差不多。”

苏棠的心跳快了一拍。养老院杂物间——她想起陈阿婆提过，外婆晚年常去养老院给一个“老朋友”送酸梅汤，那个老朋友后来搬走了，谁也没说搬去了哪里。

“杂物间那扇门通向哪里？”她问。

“后院围墙，门锁焊死的，很久没人开过。”顾淮安的声音顿了顿，“但我上周检查的时候，发现焊点有一处是新的。”

两人对视。窗外有风灌进来，白大褂下摆微微晃动。苏棠伸手拿起那两片载玻片，指尖触到玻璃的凉意。她忽然想到一个可能——如果那些锈末不仅来自井底的木门，也来自养老院杂物间的铁门，那两扇门之间会不会有一条相通的路径？井底暗渠那个金属声，她听见过的。

“顾淮安，”苏棠抬头看他，声音压得极低，“你能帮我查一件事吗？养老院杂物间钥匙在谁手里？”

顾淮安看着她，目光里有一瞬的犹豫，很快被别的情绪盖过。他伸出手，在显微镜旁边的一张便签纸上写了一个名字，推过来。纸上字迹工整：周明远的姑姑，周淑芬，养老院的保洁。

苏棠盯着那个名字，瞳孔微缩。周明远——糖记连锁的老板，拆迁逼得最紧的人。他姑姑是养老院的保洁，而外婆常去养老院送酸梅汤。苏棠把便签纸折好放进衣袋，转身往门口走，走到门边又停下来。

“你今天值班到几点？”

“六点。”

“那六点半，我在巷口等你。”苏棠没回头，声音比刚才轻了一些。

顾淮安没有立刻回答，过了几秒才说：“好。”

苏棠走出服务中心，才发觉手心攥出了一层薄汗。她揉了揉指尖，抬头看见天边云层压得低，灰蒙蒙一片，像是又要下雨。她走回临水巷，路过那棵老桂花树时，看见陈阿婆正坐在树下的小马扎上择菜，旁边放着一小篮栀子花。

陈阿婆抬头看她一眼，没问去哪了，只把篮子推过来：“拿两朵去，放铺子里，甜汤闻着香。”

苏棠弯腰拿了一朵，别在衣襟上。她正要直起身，陈阿婆忽然开口：“你阿婆以前也爱把栀子花别在襟口，下井的时候摘下来，放在井沿上。”

苏棠动作一顿：“下井？”

陈阿婆低头择菜，嘴角浮起一丝说不清道不明的弧度：“那口井，你阿婆每月十五都下去一趟，提着灯笼，出来的时候总带一身茉莉味。”她抬起眼皮，目光落在苏棠别着栀子花的衣襟上，“最近这些日子，我倒一直没问你——你下去那口井，闻着什么了？”

苏棠想起井底那股湿冷的土腥气，以及压过土腥气的那一点若有若无的茉莉香气。她没有回答陈阿婆，但衣襟上的栀子花在风里轻轻抖了一下。她忽然想，外婆每月十五提着灯笼下井——她去见的不是“水银底下那个东西”，而是别的什么。

苏棠没有进铺子，绕到后院，掀开井盖看了一眼。井沿上，她看见了一小片花瓣。是茉莉。刚才顾淮安不在的时候，没有别的人来过。她缓缓蹲下来，指尖触到那片花瓣，凉丝丝的，还带着露水。

她抬起头，往巷子深处望去。井台正前方的墙上，那盏“棠记”的老灯座，灯罩边缘不知何时有人抹去了一层灰，露出里面一点暗红色的印记——像是半个指印。

苏棠的手停在花瓣上，没有动。风从巷口灌进来，卷起尘土，那枚指印在她视野里越来越清晰。她想起便签纸上那个名字，想起锈末的赭色，想起井底木门上那道被反复撬动的刮痕——有些门锁着，不是因为里面关了谁，而是因为外面的人不敢开。

她站起身，把花瓣收进衣袋里，和玻璃瓶并排放着。然后她朝巷子另一头走去——那里新开了一家“糖记”分店，卷帘门上贴着一张招聘启事，启事上的联系人，写着“周淑芬”。

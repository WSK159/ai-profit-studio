# 第260章 石阶尽处

手电光往下打了三米就耗尽了力气，光线被黑暗吞得干干净净，只剩苏棠鞋底踩到石阶的湿滑触感告诉她，这条路还没到底。

顾淮安走在她前面半步，一手扶墙，一手反握着手电筒往脚下照。他肩胛骨的位置微微绷着，像是随时准备停下来听一听什么动静。苏棠已经习惯了他这种走路的姿势——在卫生服务中心值夜班练出来的，对暗处的警惕几乎刻进了骨头。

“还有台阶。”他声音压得很低，在逼仄的石道里却能撞出回声，闷闷的，像敲在一口封死的缸上。

苏棠的手指无意识地攥住口袋里那张从“棠记药糖”招牌夹层里取出的信纸。纸边已经脆得发毛，她指尖摩挲过外婆笔迹的凹陷处，那句话说了一遍又一遍——“阿棠，若你走到这里，便替阿婆去看一眼，那扇门后面，到底还留着什么。”

她不知道“这里”指的是哪里。但此刻脚下这条往地底延伸的石阶，似乎正一寸一寸地朝着外婆信上那个未标明的终点逼近。

台阶拐了三个弯，每一拐，空气里那股子潮味就重一分。起初还是泥土的腥，后来渐渐掺进来一种异常甜腻的、像被水泡久了的冰糖化开的气味。苏棠脚步一顿，顾淮安也停了。

“闻到了？”他问。

她点了点头。又想起昏暗中他可能看不见，补了一句：“像煮过糖水的锅，放了一百年没刷。”

顾淮安把手电往斜上方晃了一圈。光束扫过两壁，苏棠这才看清，他们站的地方已经不再是那种粗糙的石凿墙面——墙面上开始出现规则的凹槽，一道道，大约一掌宽，顺着墙角延伸往更深处，像是某种引流用的沟渠。

她蹲下去，手指贴着凹槽内壁划过。指尖触到一层干涸的、黏稠的泛着焦糖色的残留物。

“是糖浆。”她声音里有自己都没察觉的微颤，“有人在里面流过熬化了的糖，往……”

她顺着凹槽的方向抬起头，石阶到了尽头。面前是一扇木门，门框比起上面那间药房的窄门要宽出一倍，门板是整块的杉木，被地下潮气浸得发黑发胀，门缝里渗出一丝极淡的香气。

顾淮安跨上最后两级台阶，侧身在门板前站定，手掌贴着木门推了推，纹丝不动。他换了个角度，把肩膀抵上去，用了一个不大不小的力——门发出一声沉闷的“嘎呀”，从内里缓缓开了条缝。

那股甜腻的气息陡然加浓，几乎像实体一样扑面而来。苏棠下意识捂了捂鼻子，却挡不住那股混着陈年药香、麦芽甜和某种说不清的果酸的气味，把人整个地罩住。

门彻底打开的一瞬，顾淮安的手电光束照进去，两人同时愣住了。

那是一个比上面药房大上三四倍的房间。四壁砌着青砖，墙角垒着一圈足有半人高的黑陶缸，缸口盖着木盖，积灰落了厚厚一层。房间正中是一口石砌的灶台，灶膛早已冷透，但灶台上架着一只紫铜大锅，锅底的糖渍积了铜绿，泛着青黑的光。

最醒目的是靠墙立着的那排木架。架上整齐码放着一只只巴掌大的陶罐，罐身无一例外都贴着一张红纸条，因为年代久远，红纸褪成了淡粉色，上面的字迹却仍然清晰。

苏棠走近架子，举起手电，一张一张照过去。

第一罐：沉烟糖·旧方。
第二罐：沉烟糖·改方甲（周家小儿试服）。
第三罐：沉烟糖·改方乙（周家小儿加量）。
第四罐：沉烟糖·改方丙（双倍紫苏，未成）。

她手电的光停在了第四罐上。那罐子的盖边，压着一截已经枯黄卷曲的东西——像是半张叠起来的纸。

苏棠伸手去抽，纸片被顾淮安先一步按住：“别直接扯，会碎。”

他从口袋里摸出一只薄薄的乳胶手套戴上，小心地拨开纸片周围的尘土，一点一点把那张纸从陶罐的缝隙里抽了出来。展开，是一张两指宽、手掌长的纸条，边缘是锯齿状的撕痕——正好和外婆遗信里那半张票据残缺的接口吻合。

纸条上的字迹，却是另一个人的。落款处三个字：周绣。信上的字是她外婆的字，这张纸上的字，却因为激动而微微发抖：“棠姐，家迁羊城，小二病体日沉，沉烟糖方若成，烦寄羊城临江巷七号。过了冬，我们便等不了了。”

顾淮安抬头看苏棠。她嘴唇动了动，半天，挤出一句话：“羊城临江巷七号……我家小时候住的那条巷子，就是临江巷。”

她的指尖触上那张发脆的纸条，突然发现纸条背面还叠着一层，她翻开——

一张新的地图，完完整整地，从正堂药房门厅，到她们走下来的这条石阶，再往东南方向延伸出一条虚线，尽头画着一颗小小的五角星。

五角星旁边，压着一行比周绣的字更老的字迹，笔画有力，是外婆的：

“若小儿命在，此糖不毒。”

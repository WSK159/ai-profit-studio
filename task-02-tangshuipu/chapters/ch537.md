# 第537章 桂花引线

苏棠动作利落地把白瓷罐和纸片塞回铁皮匣，盖上盖子，顺手将匣子推到桌下的阴影里。顾淮安已经把灯吹熄，堂屋里只剩一片青灰色的暗光。

巷口的声响又响了一次，这次听清了——是脚步声，一步、一停，像是踩在旧青砖上试探着什么。

“从井那头来的。”顾淮安低声说。

苏棠猫着腰走到窗边，从窗纸破洞里往外看。月光下，一个瘦小的身影站在巷口的水井边，手里提着一盏纸灯，灯色昏黄，却照不亮那人的脸。

那人弯腰，从井沿边拾起什么东西——是一截暗红色的线头，正系在井边的桂花树根上，顺着地面，一路延伸向棠记后院的方向。

“是你阿婆系的那根桂花油引线。”顾淮安也看见了，“有人顺着它找过来了。”

苏棠心里一急。陈阿婆说过，那根引线是外婆遗言的一部分，要留给持钥匙的人。若被人取走，井底的秘密便断了一半。

“得把那截线头抢回来。”她压低声音。

顾淮安按住她的手腕：“别急。你看那人——”

那人直起身，纸灯抬起一寸，露出一张脸。苏棠心头猛地一缩：竟然是住在巷尾的李叔，平日里在巷口卖菜，见谁都笑呵呵的。可此刻他脸上的表情，没有半分笑意，绷得紧紧的，像是一层皮被人扯住了。

李叔把线头在指间绕了两圈，又从怀里摸出一样东西，弯腰在井边捣鼓了一阵。片刻后，井里传出一声闷响——“咚”。紧接着又是一声“咚”。第三声时，苏棠感觉脚下的青砖微微颤动了一下。

“井底三声。”顾淮安低声，“他在开门。”

苏棠心里如遭遇雷击。外婆留下的地图上写着：“灯照三重，井底三声。若无问路之心，勿启此门。”李叔一个卖菜的，怎么会知道这个口诀？他手里那件东西，又是什么？

她来不及细想，顾淮安已经起身，从门后取了外婆留的那盏铜灯，塞进她手里：“你拿着灯，从后院绕过去，断他的退路。我从巷前出去截他。”他顿了顿，补了一句，“小心井边的石板，那下面有暗渠。”

苏棠握紧铜灯，点点头。两人一前一后出了正堂，苏棠贴着墙根绕到后院，脚步放得极轻。月光把她的影子拉得很长，树影间，那条暗红色的引线像一条细蛇，沿着墙根蜿蜒向东。

她循线走到后院墙角，正好挨着那口老井的背面。隔着井台，能听见李叔低低的嘟囔声：“不该是这时候……不该是这时候……”

然后他像是察觉了什么，猛一抬头，正好撞上苏棠从墙后探出的目光。李叔手里的纸灯“啪”地掉在地上，烛火扑闪了两下，灭了。

苏棠没给他反应的时间，一个箭步上前，一把扣住李叔的手腕，把那截暗红引线从他指间抽了出来。李叔张嘴想说什么，却听见顾淮安的脚步声从巷前逼近，他脸色一变，猛地甩开苏棠的手，转身朝井台的暗处跌跌撞撞地跑了几步——脚下一滑，整个人跌进井口边那丛矮竹里，发出一阵窸窣声后，身影消失在墙角的暗影中。

苏棠喘着气，低头看自己手心的那截引线。线头被她攥得汗湿了，却依然结实。线的一端系着一枚小小的铜环，环上刻着半朵桂花的纹样。

顾淮安赶到她身边，看了一眼那枚铜环，神色微变：“这枚环……”他声音压得更低，“我在陈阿婆的交待里提过——‘桂花引线连铜环，铜环归处是沈家。若见半花，持灯前行，门自开。’”

苏棠抬起头，目光越过顾淮安，望向井口。井面上浮着几片桂花叶，不知何时，那些叶子正打着旋儿，顺着一个看不见的涡流，缓缓向下沉去。

井底深处，传来一声极轻的，像是笑，又像是回响的声响。

# 第425章 壁画上的影子

从石室退回窄道，苏棠一口气走了二十多步才停下来，后背抵着青石壁，大口喘气。汗从鬓角滑下来，凉的。顾淮安手电的光晃动着扫过前方的窄道，壁上的青苔被照亮又隐入黑暗，整条通道安静得只剩下她自己的呼吸声。

“听到刚才那声音了吗？”她哑着嗓子问。

顾淮安没有立刻回答。他站在原地，侧耳听了片刻，才缓缓摇头：“现在没有了。那一带石壁回声重，不好判断是从井里透上来的，还是从裂缝里传出来的。”

苏棠咬了咬唇：“画里那个影子——”

“我看到了。”顾淮安语气平得不像在聊撞鬼的事，“三个影子。画里只有一个人。”

两个人沉默了一会儿。苏棠的呼吸渐渐平稳下来，三颗红痣的灼热感也退了大半。她松开攥紧的拳头，发现掌心里全是汗，指尖冰凉。

“刚才我们看到的那些——”她咽了咽口水，“画是怎么回事？我外婆留下的手稿里从来没提过她见过什么无脸画。”

“你外婆没见过，不代表画不在。”顾淮安把手电关掉，只剩火把的光在窄道里跳动，“沈家塘的井龙王传说，你听过没有？”

苏棠想了想。小时候外婆给她讲过临水巷的旧事，其中有一条关于沈家塘的：井里有龙王，欠债的人把铜钱投进井里，龙王记账，来世上门来讨。她当时当童话听，现在想起来，那些传说背后像真藏着什么东西。

“你是说，那口井真有什么……井龙王？”

“沈家塘的老规矩，挂铃解铃，投钱记账。九只铜铃九笔债，还债井就是记账的地方。”顾淮安的声音压得很低，“刚才井壁刻字你看到了——沈海潮以桂花蜜抵债，末注说‘解铃须问桂花，还债须找姓苏之人’。你姓苏，井里那枚铜钱上也有半道‘棠’字——不是巧合。”

苏棠心里乱得像一锅翻沸的水，可她从顾淮安的话里敏锐地抓住了一个点：“你对沈家塘的规矩知道得这么清楚，至少不是从书上看来的。”

顾淮安没否认。他沉默了几秒，说：“我小时候在临水的乡下住过几年，隔壁村有个姓沈的老人，专门替人做中保、管债事。他家里有本账，记的都是些过了几十年没还的旧债，每笔债名下拴一条红绳。他说，绳子拴的是良心，解的是命。”

“那本账里的债——”苏棠看着他，“也有还债井的？”

顾淮安的嘴角牵了牵，没接话。他往窄道前方走了两步，火把的光照出一段台阶，往上延伸，转了个弯。他停下脚步，用手电照了照台阶旁的墙面，忽然“嗯”了一声。

“怎么了？”

“这里。”他指着墙面，苏棠凑过去看，在火光下，台阶旁边的石壁上有一处浅浅的划痕——很简单的图案，一朵桂花，五个瓣，每一瓣里一道短纹。苏棠瞳孔一缩：“跟外婆手稿里那幅简笔画一模一样的桂花？”

“对。”顾淮安说，“而且位置不像自然风化出来的，像最近才划上去的。边缘石粉还是白的，没氧化。”

苏棠的心又提了起来。那道裂缝里有人的动静，台阶旁有新划的花纹，那口井有人供奉过，这个地下空间的某处，藏着活人——活人就在他们附近。

她忽然想起外婆手稿里的那句话：“桂花落尽，巷口人归。”桂花落尽……现在巷里的桂花树早就开败了。

“这花是什么时候划的？”她问。

“不出三天。”

苏棠后背一凉，三天前，她人已经在临水巷了，那这个地下空间里出入的人，跟她几乎是同一时间段在活动。她想起外婆临终前床头柜上那罐消失的蜜，心里冒出一个念头：外婆是不是把蜜给了这里住着的“人”？那个枯桂花树桩下，又埋着什么？

“上去。”顾淮安说，“今天看得够多了，再不回去天要黑透。”

苏棠点点头，两人沿着台阶往上走。走到转角处，苏棠无意间用手撑了一下墙面，手心碰到一处凉得像冰的石面，她低头一看，在台阶边沿贴壁的位置，有一块手掌大小的石块被磨得光滑如镜，表面隐约有纹路，不是天然的，像被人凿出来的东西。

她侧过身让火把照过来，看清了那块石面上的刻痕，是一竖行极小的字，笔画纤细，像用针尖刻上去的：“你外婆找了一辈子的人，一直住在这口井底下。”

苏棠的呼吸骤然停了，她盯着那行字，指尖发凉。顾淮安察觉她停住了，走回来：“怎么了？”

“你看这个。”

他看了许久。字迹工整有力，是上个时代的写法，有些笔画的习惯已经没人用了，像几十年前的东西。他轻声道：“这句话不是对你写的。”

苏棠明白他的意思——这句“你外婆”，显然是留给某个更晚来的人看的。也就是说，在她之前，还有别人来过这里，读到过这行字，并且知道她外婆找了什么人一辈子。那个人，很可能就是一直在供奉井口那团东西的人，也是三天内进出过裂缝的人。

他可能没有离开这个地下空间。他可能还在某处，透过哪道缝隙，正看着他们。

苏棠抬头，往台阶上方看了一眼。台阶尽头转弯处，一片昏暗中，有一个黑乎乎的影子一晃而过，速度很快，快得像看花了眼。

她屏住呼吸，没有喊出声。她只把顾淮安的手腕紧紧攥住，对着他的视线，微微摇了摇头。

顾淮安看懂了她的意思，两人放轻脚步，一步一步，往台阶上走。风声从窄道上方灌下来，带着泥土和桂花的味道——这个季节不该有的桂花香，又浓又冷，从他们头顶拂过，像一只看不见的手拂过人的后颈。

苏棠没有回头，可她耳朵里清清楚楚地听到——身后台阶下，传来了一声极轻的脚步声，像有人踩着他们刚才踩过的位置，跟着他们往上走。

一步，一步，一步。

不多不少，始终隔着一个拐角的距离。

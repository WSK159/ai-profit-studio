# 第592章 太平药房

铁皮盒里那半张票据在苏棠指尖微微发颤。纸面已经脆得像秋天的落叶，捏重一点就要碎成齑粉。她小心翼翼地把反面朝上——那行字她看过了，又看了一遍，“金方不可外传”五个字是外婆的笔迹，但跟前头那些手稿的圆润不同，这几个字落笔很重，几乎要划破纸背。

顾淮安蹲在她对面，把那张丙申年的老照片举到黄昏的光线里。照片上外婆还不到二十岁，站在春和楼的灶台前，围裙上挂着一只蝴蝶绣的别针，她旁边站着一个高瘦的年轻男人，眉目清朗，右手搭在砧板上，指尖压着一把菜刀。两人中间，灶台边上放着一只砂锅，锅盖半掀，腾腾的热气模糊了背景里的案板。

“这锅，”苏棠凑过去，“看起来像炖汤的。”

顾淮安没说锅的事，而是指着照片右下角一行小字：“师父摄于丙申年春。”

“丙申年，1956年。”苏棠算了算，“外婆那年二十一。师父还活着的话，现在该九十多了。”

她把票据收回铁皮盒里，又看一眼盒底的衬布。那层墨绿色的棉布铺得平平整整，苏棠正要合上盖子，忽然用手按了按盒底——布底下有什么东西硌着。

她掀开衬布，露出下一层：一束用红棉线绑得整整齐齐的干桂花，花早就枯成了暗褐色，但那股甜香还锁在花瓣里，隔着几十年的光阴，依然清晰地冲入鼻端。桂花下面压着一张纸片，折成四方块，展开来是半行字，像是写了一半被人打断的——“若是她肯来”。

“是谁肯来？”苏棠把纸片递给顾淮安。

顾淮安看了很久，说：“这个‘她’字，笔迹和信里的不一样。”

“你是说，这半行字不是周承远写的？”

“嗯。你看这撇捺的走势，绵软圆滑，像女人写的。”

苏棠心里头猛跳了一下。“外婆的信。”她张开手，“把那封信给我。”

陈阿婆之前交出来的那封1978年信还在她随身的小包里，苏棠摸出来，跟纸片上的字迹对了一眼。对上了。一样的绵软，一样的收笔带钩。外婆的字。

“外婆在周承远留的纸条底下，又藏了一句话。”苏棠说，“‘若是她肯来’——她写这个‘她’的时候，在等谁？”

两个人沉默了一阵。黄昏的光从老槐树的枝叶间漏下来，落在铁皮盒上，把那束干桂花镀成金色。

顾淮安忽然问：“太平药房的旧址，你在哪儿找到的那块招牌？”

“巷尾拐角，卖杂货的老赵家后墙。”苏棠说，“上回我去查的时候，那墙上的棠记招牌是后钉上去的，铁钉锈得深，至少钉了有二三十年。”

“走，去看看。”顾淮安站起来，拍了拍膝盖上的土，“趁天还没黑透。”

太平药房旧址在临水巷最末端的拐角，外墙刷白，石灰已经起了皮。杂货铺老赵早歇了摊，卷帘门半拉不拉地垂着。苏棠带顾淮安绕到屋后，那面墙上果然钉着一块黑底金字的老招牌——“棠记糖水”，“糖”字的偏旁磨掉了半边，只剩“米”和“唐”凑在一起，乍一看像个错别字。

顾淮安凑近看了看，用指甲抠了一下招牌边缘的漆皮。漆皮掉了，露出底下另一层黑漆，漆面上隐约还有字。他用手机打光，一个字一个字地认：“太、平、药、房——”

“叠着刷的。”苏棠说，“棠记糖水的招牌，原来是钉在太平药房的招牌上面。”

“那你外婆说的‘寄存在彼处的东西’，就藏在这面墙后头。”顾淮安敲了敲招牌周围的砖，那几块砖的声音比别处闷，是空心的。

两个人对视一眼。苏棠四下看了看，巷子空无一人，几只麻雀在电线杆上理毛。她伸手去扣那块松动的砖，指尖刚刚碰到，身后忽然响起一个声音。

“小姑娘，那墙上的东西，你可不能动。”

苏棠猛地回头。

一个老太太拄着拐杖，站在巷子口，逆着光，看不清脸面。她穿一件洗得发白的蓝布褂子，身形佝偻，声音却稳得很：“那墙上钉的，是我家老头子上辈子亏的债。你要揭，得先跟我说一声。”她顿了顿，“你外婆的脾气我知道。东西在她手里存了四十年，她没动，你也不能乱动。”

苏棠心跳如擂鼓：“您认识我外婆？”

老太太拄着拐走近了两步，站在那面墙前，抬头看了看那块棠记招牌，忽然笑了一声：“你这孩子，跟你外婆真像。看见个东西就非要挖到底。”她转过脸来——花白的头发，眼角的皱纹深得像刀刻，唯独一双眼睛亮得惊人，“当年周承远托我守这面墙。他说，等棠记的后人走到这里来，我就得把一样东西交给她。”

她伸手进蓝布褂子的内袋，掏出一把黄铜钥匙，递到苏棠面前：“太平药房的柜子钥匙，你外婆的东西，还在里头锁着。”老太太的目光扫过苏棠的脸，“但你先别急着去开锁。钥匙我守了四十年了，总得先跟你说清楚——那柜子里锁的是什么，你外婆被这个东西缠了一辈子。你要是接过来，可就甩不掉了。”

苏棠低头看着那把黄铜钥匙。钥匙的手柄处磨得锃亮，像是被人攥了很多年。

“我接。”她说。

老太太笑了：“那就跟我来。”

她转身往巷子里走，走了两步，又回头说了一句话。那句话轻得像飘在风里，可苏棠听见了。

“你外婆年轻的时候也说过这两个字。一模一样。”

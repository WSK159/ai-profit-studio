# 第118章 归魂

后厨的煤炉上坐着一锅陈皮红豆沙，咕嘟咕嘟冒着细密的泡。苏棠坐在灶台边的矮凳上，乌木匣子摊开在膝头，那页写着“归魂”的契约背面已经被她翻来覆去看了不下十遍。

“第三十七味药‘归魂’三钱为剂，误服无解。”

她轻声念了一遍，指尖沿着棠秋的字迹描过。外婆的字一贯秀气，唯独这一行写得急促，收笔处有细微的颤抖——像是在极短的时间内写下的。

“什么无解？”

顾淮安的声音从门口传来。他穿着白大褂，显然是午休时间直接走过来的，右手拎着两盒烧腊饭，左手还夹着一本厚得离谱的蓝色封皮书。

苏棠抬眼看他，没答话，把契约翻过来给他看。

顾淮安放下饭盒，将蓝皮书搁在案板上，接过那张泛黄的纸看了片刻。他眉头缓缓蹙起来：“归魂……我不记得《本草纲目》里有这味药。”

“《本草纲目》当然没有。”苏棠站起来，拍了拍裙摆上的灰，“我查了一上午，归魂是民间底方里的说法，指一种能让人‘魂魄归位’的药。说是药，其实是某种药材经过特殊炮制后的别名。”

顾淮安的目光从纸面移到她脸上：“谁跟你说的？”

“陈阿婆。”

苏棠走到灶台边，拿木勺搅了搅红豆沙，盛了一碗递给他。“陈阿婆说，她小时候听她娘讲过，仁济堂的老药师有一味压箱底的药，叫归魂。寻常人不给配，说是吃下去人看着没事，三天之后魂魄就散了，救不回。”

她顿了顿，看着顾淮安：“周永昌就是仁济堂的承租方。”

顾淮安接过碗，却没喝。他沉默了几秒，说：“你知不知道，我今天去翻了卫生中心的档案库。”

“嗯？”

“六十年前，仁济堂关门那年，城东发生了一桩……到现在还悬着的案子。”

苏棠手里的木勺顿住了。

“当年有户姓容的人家，一家三口，男主人是走街串巷的货郎，据说得罪了什么人。一天夜里全家喝了街上买的药茶，第二天没事，第三天清晨——全都没醒。”顾淮安声音不高，语速很慢，“法医当时没查出死因，只记了八个字：‘神志恍惚，如梦中亡’。”

后厨里安静得只剩红豆沙翻滚的声响。

苏棠忽然觉得脊背有点凉。她想起外婆手稿里夹的那张照片上，棠秋站在“仁济堂”招牌下的模样——那么年轻，眉眼间却已经藏着说不清的东西。

“那户容家——”她听见自己的声音有点涩，“是不是有个女儿，叫容玉？”

顾淮安没有立刻回答。他看了她一眼，那眼神里的意思是——你怎么知道？

苏棠把碗放下来，手指微微发颤：“马容盛家的墙上，挂着一张旧照片。全家福。照片背面写着三个名字：容盛、容玉、容芳。还有一行字——‘阿玉走失，不知所踪’。”

她看着顾淮安：“马容盛的原姓，是容。”

一阵穿堂风从后门灌进来，煤炉上的火苗晃了晃，红豆沙的香气被吹得散了些。顾淮安放下碗，声音放得更轻：“马容盛……你确定？”

“他亲口跟我说的，说他在等人。”苏棠抿了抿唇，“他在等一个可能永远不会回来的人。”

顾淮安沉默了一会儿，将那本蓝色封皮书推到苏棠面前：“你猜我今天为什么带这本东西来？”

苏棠低头，封面上印着一行烫金小字：《临水县医药卫生志·1950—1970》。她翻开来，书页间夹了一张手写的便签，是顾淮安的字迹，上面记着一条页数索引。

她循着索引翻过去，看到一段简短记载：

“仁济堂，原址临水巷南口，经营药材兼售汤饮，1958年因药材失窃案停业清盘。案涉白银若干，当事职员两人入狱，承租人周某随后迁离本县，去向未详。”

药材失窃案。苏棠盯着那行字，脑海里浮现出乌木匣子里另一样东西——外婆手稿夹层里的半张票据。

票据上的落款，正是仁济堂。

她正要开口说话，前厅传来“叮铃”一声门铃响。接着是一个男人的声音，带着点笑意，客客气气的：

“请问——苏棠小姐在吗？”

苏棠和顾淮安同时转头看向后厨通往前厅的门帘。

那个声音她认得。几天前在电话里听过的，客客气气，温和斯文，像在拜访一位老朋友。

周明远。

他说过，下周回临水巷。

他提前来了。

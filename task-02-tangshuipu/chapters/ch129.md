# 第129章 听证会上的阵雨

临水巷居委会的会议室不大，平时摆下四张长桌就没了转圜的余地，今天却坐满了人。苏棠推门进去的时候，靠窗一溜排的老街坊齐刷刷回过头来，陈阿婆坐在第一排，怀里抱着一盆茉莉，朝她使了个眼色——靠墙那一侧，黑西装的男人正低头看手机，旁边坐着一个戴金丝眼镜的中年女人，膝盖上摊着一摞文件。

苏棠在陈阿婆旁边坐下。顾淮安在她身后站定，没有坐。

台上主持人敲了一下铃，宣布听证会开始。先说了片区改造的整体规划，再说补偿方案，念到“棠记糖水铺”时，金丝眼镜女人站起来，声音清亮：“我方代表容盛集团，对棠记的百年老店资质提出异议。我方认为，原告方提交的凭证系后人补造，不具备法律效力。”

会议室里嗡地炸开了锅。陈阿婆一拍椅子扶手：“你们说补造就补造？那地契可是光绪年间的！我家老头子年轻时候就见棠记的招牌挂在巷口，那是假的？”

金丝眼镜女人不为所动，从文件夹里抽出一页纸，推过来：“这份民国三十七年的房产登记档案影印件上，临水巷十二号的产权人登记的是‘周永昌’，而非‘苏陈氏’。再者——”她顿了一下，“这座铺面的实际经营者，自民国三十五年起即登记为‘仁济堂’名下，棠记并未独立立户。”

苏棠脑子轰的一声。“仁济堂”三个字像一根针，一下扎在了她没来得及合拢的伤口上。她想起牛皮纸上外公的字迹——“药在仁济堂库中”，想起那栋两层小楼，那个标注着西厢库房的院子。她一直以为外婆手里的地契是棠记的，原来这间铺子的地根本就是仁济堂的？

她站起来，声音稳住：“那请问这位女士，仁济堂的负责人是谁？如果产权登记为仁济堂，那么仁济堂的继承权又归谁？”

金丝眼镜女人微微一顿，显然没料到她会反问。“仁济堂已于五十年代注销。”她说，“按现行法规，注销企业的资产收归国有，由属地统一处置。”

这时，一直低头看手机的黑西装男人忽然开口：“苏小姐，容盛集团不是来抢房子的。”他语气平和，目光却没有笑意，“我们只是希望，能以合法的途径让这座铺子发挥更大的价值。如果苏小姐愿意，我们可以谈合作——棠记的招牌可以保留，甚至可以做品牌联合。”

“不卖。”苏棠说。

会议室安静了一瞬。黑西装男人微微一笑：“苏小姐不妨再考虑考虑。下周我们还会再来。”

他说完便站起来，金丝眼镜女人收起文件，两人一前一后出了门。陈阿婆气得直拍桌子：“这就是个局！他们拿仁济堂来压你——那仁济堂不是早就没人了吗！”

苏棠站在原地，没有动。她忽然觉得那块从银杏树下翻出来的青石板，可能不只是外公留给外婆的信，还有别的。一个大胆的念头涨了上来，她没有当场说出来，只谢过老街坊们，散了会。

顾淮安走到她身边，语气平静：“你刚才想说，仁济堂的继承人，不是他们。”

苏棠抬头看他：“仁济堂是外公的。外公不在，仁济堂就算注销了，它的地也应该归外公的继承人。外婆的手稿里夹着外公的照片，外公姓什么，你知道吗？”

顾淮安目光微动。

苏棠从口袋里摸出那张牛皮纸，展开，指着图纸右下角“仁济堂”三个字旁边的一行小字——她方才在来的路上才注意到，那行字和正文笔迹不同，像是后补上去的。字迹潦草，只写了两个字：

“容归。”

她低声念出这两个字，又补了一句：“我妈说，外婆当年叫她‘小囡’，但外公给她取的名字，叫容归。她从来没提过外公姓什么。”

顾淮安沉默了一会儿，说：“那你知道容盛集团的法人，叫什么吗？”

苏棠一怔。

“容盛。”顾淮安说，“法人代表，容盛。他有两次改名记录，原名——容归。”

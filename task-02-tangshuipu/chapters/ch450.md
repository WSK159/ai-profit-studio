# 第450章 一碗酸梅汤的凉意

酸梅汤的碗沿贴着她的指尖，凉意顺着指纹往掌心钻。苏棠低头看了三秒——标签上的“棠”字是外婆的笔迹，最后一笔带了个不明显的回钩，像年轻时写信的人习惯在落款处停一停。

“送汤的人呢？”

白大褂男子把双手插回口袋，露出袖口一截深蓝色的线头，漫不经心地说：“他只说，你喝了自然知道是谁。”

苏棠没有急着喝。她端着碗转向他，目光从他脸上扫过——和周明远确实有几分像，尤其是眉骨和下颌的弧度，但眼睛不像。周明远的眼睛是豢养出来的精明，眼前这人却带着一种旧纸堆里翻出来的倦。

“你在卫生服务中心上班？”她问。

“临时借调。”他微微侧身，朝巷口医务室的方向抬了抬下巴，“顾医生不在，这两天我替他值夜班。他走之前交代过，你可能会过来拿东西。”

苏棠眼皮一跳：“顾淮安走了？去哪儿了？”

“说是去省城一趟，办点私事，没细讲。”男子看了看手表，“汤我送到了，话也带到了。你要是有什么需要，随时去中心找我，我姓杜。”

杜。这个姓氏像一粒石子投进她脑子里，漾开一圈模糊的涟漪。她还没来得及问什么，男子已经转身朝巷口走去，白大褂下摆被风掀起一角，露出里面深灰色的裤子和一双旧布鞋——不像医生，倒像是做了一辈子粗活的手艺人。

苏棠收回目光，重新看手里的酸梅汤。汤色澄澈透亮，沉在底下的乌梅已经泡到了火候，面上浮着几粒干桂花，是陈阿婆常撒的那种。她犹豫了一下，还是端起碗，浅浅地啜了一口。

酸。很纯正的酸，酸里透着一股苦，苦完才有回甘，回甘里裹着一种说不清道不明的甜——像小时候外婆在灶台边熬酸梅汤的味道，又不太一样，多了一丝她说不出来的东西。

她放下碗，突然发现碗底有一圈浅浅的刻痕，在水光里显出两个字来。

“棠，记。”

苏棠的呼吸滞了一瞬。她翻过碗底去看——粗陶碗底被人用利器刻出两个小字，笔痕老旧，边缘已经被无数次清洗磨得圆钝。这不是新刻的，是很多年前的旧痕。她忽然想起外婆的手稿里夹过一张纸条，写着“碗底有记，认碗不认人”。

杜慎行。她已经猜到了那个白大褂男子的去处。周深说过，杜家是周家的老对头，而杜慎行这个人，躲在井底不敢见天日。

巷口的桂花树桩静静卧在夕阳里，苏棠摸着口袋里的铁钥匙，指尖碰到红绳上的半边铜铃，铜铃发出一声极轻的脆响。

“认碗不认人。”她低声念了一遍，抬头看向巷口医务室的方向，白大褂男子的身影已经拐进巷子尾，消失不见了。

她把酸梅汤喝完，碗底两字在水光里微微晃动，汤色褪尽后，露出粗陶本来的颜色——碗沿内侧有一道极细的裂纹，裂纹里嵌着一根头发，灰白色，绕了整整一圈，像是谁有意放进去的。

苏棠把碗翻过来，倒扣在掌心，对着光去看那道裂纹。灰白的头发在粗糙的陶面上紧紧地贴着，像一条干涸的河流。她忽然想起外婆生前说过的话：“碗破了不要扔，拿头发箍一箍，还能再用一辈子。”

她蹲下身，把碗放在门槛边，手指轻抚过那圈头发，指尖微微发烫——掌心的飞鸟印记又开始泛红了。

陈阿婆从屋里走出来，手里端着一碗新煮的桂花糖芋苗，看到门槛边的碗，脚步顿了一下：“那碗……哪儿来的？”

“有人送来的。”苏棠站起来，“酸梅汤，碗底刻着棠记两个字。”

陈阿婆沉默了一会儿，把糖芋苗放进她手里，弯腰拾起那只碗，翻来覆去看了两遍：“你外婆在世时说过，棠记的碗有两只，一只埋在井底，一只流在外面。埋着的那只，等钥匙齐全了才能挖出来。流在外面这只……她等了几十年，一直没等到。”

苏棠握紧口袋里的铁钥匙，感觉到半边铜铃随着她的心跳微微震动。

“阿婆，你说顾淮安他……”她话没说完，巷口忽然传来一阵急促的脚步声。

一个穿校服的男孩跑进来，脸涨得通红，手里攥着一张皱巴巴的纸条：“苏棠姐！有人让我把这个给你，说是从省城寄来的，加急！”

苏棠接过纸条，展开一看，上面只有一行字，用蓝黑墨水写的，是她没有见过的笔迹——

“桂花开时，棠记关门。来省城，找你外婆的故人。”

落款处没有名字，只画了一个小小的圈，圈里写着一个“沈”字。沈。她猛地想起账册封面上“担保人沈”三个字，又想起铁匣里那张暗黄纸角上没写完的姓氏。她抬头看向巷口，白大褂男子已经不见了，那碗酸梅汤的凉意却还留在她指尖，像一枚小小的印记。

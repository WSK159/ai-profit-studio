# 第398章 井沿上的第二道记号

天刚蒙蒙亮，巷子里的雾气还没散尽，苏棠就蹲在了井沿边。

她手里攥着一把旧牙刷，本想趁早起人少把井沿上那两道刻痕拓印下来，却在低头的一瞬愣住了——刻痕边上，多了一道浅浅的新痕。

那痕像是用指甲掐出来的，细而深，斜斜地划在“周缙”二字的右下方。苏棠凑近了看，那确实是一个符号，不是字，像一把缺了柄的勺子，又像半弯残月，尾端微微上翘，仿佛在勾着什么。

她伸手摸了摸，指腹触及的瞬间，一道细细的凉意从指尖窜上来，像是井水的气息。

苏棠站起身，四下张望。清晨的临水巷静得出奇，石板路上只有露水的光，铺子门板都紧紧地关着。她蹲回井沿，把那道新痕连同“周缙”二字一起拓在了宣纸上，墨迹未干，她盯着看了很久，总觉得那符号在哪儿见过。

井泉会规矩，债主若肯听解释，留下一道横杠暗号。可眼下这道符号不是横杠——它像一把钥匙，又像一件器物。

“不是催债的。”杜慎行的声音从身后响起。

苏棠回头，见他依旧站在廊下的阴影里，目光落在她手心的宣纸上。他今日没有穿那件灰布长衫，而是一件深青色的旧棉袄，腰间挂着那把铜锁，铜锁在晨光里泛着暗哑的光。

“你昨夜没睡？”苏棠问。

杜慎行没有答，只缓步走到井沿边，低头看了片刻，说：“这道记号，是井泉会里‘寻物’的意思。”

“寻物？”

“债主不愿听解释，也不急着催逼，他先要找一样东西。”杜慎行的声音低缓，“这符号所指之物，若能找到，债可缓；若找不到，按规矩，就要取走欠债人一件等值之物。”

苏棠把那道符号又看了一遍，缺柄的勺子、半弯残月、尾端上翘。她脑中忽然闪过什么，转身就往铺子里跑。

杜慎行没有跟进去，只是站在井沿边，目光沉静地看着那道新痕，眉头微不可察地蹙了一下。

苏棠一头扎进柜房，从抽屉深处取出外婆的旧手稿。她翻到夹层那一页——半张票据旁边，那张旧照片上，外婆年轻时与一个男人并肩而立，那人手里托着一只碗，碗里盛的正是姜撞奶。

她的目光落在那人腰间的挂饰上——那是一个银质的挂件，形状像半弯残月，尾端微翘，与井沿上的新痕一模一样。

苏棠的手一抖，照片险些落地。她定住心神，想起手稿里“周缙那碗糖水我至今没端给他过”那句，又想起票据背后两人并列夹一碗汤的图案——那图案她也终于看懂了。

两个人各持半张票据，拼合在一起，中间是一个空碗的位置。而周缙腰间那半弯残月的挂件，恰似那空碗缺的一角。

“欠的不是钱，是那碗糖水。”苏棠喃喃自语，抬起头，目光落在窗外那口井上——井沿上的符号分明在回答她：寻物，寻的就是那碗糖水。

可是糖水早在几十年前就已经凉了。

她重新合上手稿，手指触到封皮夹层时，却觉出底下多了一样东西。那触感粗糙而绵软，像一片干枯的叶子。她小心地拨开封皮，从夹层里抽出一张泛黄的纸笺来。

纸笺极薄，折成四方，边缘已经发脆。展开一看，上面只有一行褪色的钢笔字——

“糖水不会等人，但井会等。”

字迹是外婆的，笔画比手稿正文更瘦更急，像是匆忙间写下的。纸笺背面，画着一口井，井边立着一个人影，人影的手里，端端正正地捧着一只碗。

苏棠把纸笺翻来覆去看了几遍，没有落款，没有日期，也没有任何解释。她心里那根弦绷得更紧了——这纸笺，外婆分明是想留给她的，却把它藏在了手稿封皮的夹层里，连陈阿婆都不知道。

她忽然想起昨夜杜慎行说的话——“井泉会的债，吃到肚子里才算还清。”

那碗糖水，若端到该端的人面前，债也许就不存在了。可周缙已经死了，井沿上的刻痕是他留下的，那月牙形的挂件呢？是谁从井底带上来的？

苏棠捏着纸笺走回廊下，杜慎行正蹲在井边，用指尖蘸了井水，在石板上画出那道符号的轮廓。见她出来，他抬眼问了一个她来不及想的问题——

“当年周缙托食堂的人传话，说‘井里有东西’。你外婆后来没有下过井？”

苏棠摇头，诚实道：“手稿里没有写。”

“那她有没有托别人下过？”杜慎行说着，目光落在铺子对面陈阿婆的家门口——那扇门，已经三天没开过了。

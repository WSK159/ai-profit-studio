# 第554章 冷库门后的光

深夜的高速路上，只有车灯切开浓稠的夜色。苏棠坐在副驾驶，铁盒搁在膝头，那把黄铜钥匙握在掌心。她反复摩挲着钥匙柄上那道细痕——像是被什么东西刮过，又像是被刻意刻上去的记号，横着三道，长短不一。

“顾淮安，你说这把钥匙，是开门的，不是开锁的。那窄门上的锁呢？”

顾淮安目光没离开路面，声音平淡：“窄门是嵌在墙里的，没有锁孔。钥匙的齿纹是推杆式的，插进去之后要转半圈。”

苏棠低头看了半天。钥匙的齿根本不是寻常锁孔的形状，更像某种机械的闩栓。

“你见过？”

“我爷留下来的笔记本上画过类似的。”顾淮安顿了顿，“他晚年记忆时好时坏，但那本笔记上画得极细致。说是民国年间，梧城冰厂的老库房用来存贵重物件，门都是特制的。钥匙是看门人那套，不是主人家那套。”

苏棠一怔：“看门人？”

“对。我在他笔记里读到一句——‘看门人只认钥匙，不认人。’”

车子在午夜前进入梧城地界。街灯渐密，旧城的轮廓在远处墨蓝的天幕下变得清晰。苏棠看着窗外，忽然想起了什么：“你爷笔记里，有没有提过窄门后面是什么？”

顾淮安沉默了片刻：“只画了一扇门，门后面是一团墨。旁边写了两个字——”

“什么？”

“莫入。”

莫家冰厂旧址比上次来时更显破败，夜风从断裂的玻璃窗间穿过来，呜呜作响。两人带着手电往深处走，冷库里那股沁骨的寒意依旧不散。第七格尽头的墙面上，那道窄门安静地嵌在阴影里。

门高一米左右，宽窄正如地图所标。苏棠蹲下来，用电筒照着门框边缘，看到一圈深色的旧漆，漆皮剥落处露出底下暗红色的铁锈，而门板中央嵌着一个圆形凹槽，大小和钥匙的柄端吻合。

顾淮安把手电递给她，接过钥匙。他蹲下来，将钥匙柄对准凹槽，缓缓插入，再向右转半圈。咔哒一声轻响，像是极远的某个地方有金属弹开。

窄门没有打开。整面墙却传来沉闷的震动，那声音像是从地下深处滚上来的。苏棠后退半步，电筒光跟着晃了一下，照见门缝间渗出的一线昏黄的光——那光极暖，不像是电灯的白，反倒像油灯或烛火的颜色，明明灭灭地跳动着。

“光是热的。”她把手指贴在门缝边，真切地感到一丝暖意从缝隙里涌出来。

顾淮安没有动。他盯着那线光，声音低了下来：“苏棠，这墙后面是冰库的旧墙体，按理说不可能有光源。”

苏棠心头一凛。那光确实在跳，不是稳定的电光，更像火的呼吸。她正要伸手去推门，手机忽然震了一下。屏幕上跳出一条新短信，发件人依然是那个虚拟号码。

“进去以后，别碰最里面的那口缸。”

两人对视一眼。苏棠回拨过去，依旧是忙音。她低头看短信底下的发信时间——十一点五十九分，还有半分钟就是新的一天。

顾淮安重新握住门板的边缘，掌下发力，窄门向外缓缓打开。

门后的甬道极窄，只能容一人侧身通过。那昏黄的光从甬道尽头弥漫出来，在墙壁上投下一层薄薄的暖色，像旧照片里滤过的调子。甬道两侧的墙面贴着老旧的瓷砖，白底蓝边，是民国年间医院和仓库常用的式样。瓷砖表面蒙着厚厚的灰，但有几处却被擦得发亮，像是近期有人走过。

苏棠数着步子，大约走了二十来步，尽头是一间两米见方的小室。

室内果然有一口陶缸，粗陶，缸壁挂着水珠，缸口覆着木板。缸旁的墙面上钉着一只老式挂钟，指针停在十二点整。挂钟下面的墙上嵌着一只小小的神龛，里面供着一块木牌。木牌上写着一行字：

“莫家冰厂第七看门人沈秀禾之位。”

苏棠盯着那一行字，后背一寸一寸地发凉。

沈秀禾。那是外婆的名字。

神龛前搁着一只空碗，碗底残留着一层薄薄的、白而微凉的液渍。她凑近闻了闻——是姜撞奶，隔了不知多少年的、早已干涸的姜撞奶。碗底有一枚小小的青花瓷片，和那只方牌的质地一模一样。

顾淮安站在她身后，声音轻得像怕惊动什么：“这里没人来过。碗上的灰积了起码几十年。”

“那短信里的照片是谁拍的？”

话一出口，小室的深处传来一声极轻的响动，像是陶缸里有什么东西，隔着水，隔着缸壁，轻轻地敲了一下。一下。又一下。三道敲击声，节奏不快不慢，像是在回答她。

苏棠缓缓转头，看向那口覆着木板的陶缸。缸沿上搭着一段暗红色的毛线头，在昏黄的光下，微微颤动。

门外，甬道尽头传来脚步声，一步一步，不疾不徐地，朝这里走过来。

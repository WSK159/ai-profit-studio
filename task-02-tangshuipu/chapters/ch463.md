# 第463章 桂花树下的香

那枚银牌就躺在顾淮安掌心里，苏棠没有去接。她盯着“沈家塘，欠，还”那行小字看了很久，铜锅的提梁还攥在手里，锅沿的冰凉一直渗到指尖。

“你早知道了。”苏棠把锅抱起来，往铺子里走，“从井底那具骨架开始，你就知道了。”

顾淮安跟在她身后，脚步声和平时不太一样，比往常沉。他没有否认，也没有解释，只是说：“知道一部分。断玉是我小时候就有的，爷爷去世前交给我的，说将来有人拿同半枚来，就把我的赔给人家的。”

“赔给人家？”苏棠站在门槛前，回头看他，“所以你一直以为，你爷爷欠了人东西？”

“嗯。”顾淮安的目光落在她怀里的铜锅上，“欠了一条命。”

苏棠抿了下唇，把锅抱进铺子，放在灶台上。铜锅落锅灶的声响闷闷的，锅沿磕在瓷片上，发出一声细得几乎听不见的嗡鸣。顾淮安跟进来，在门槛外的台阶上坐着，没有进屋。

“邵伯说的香，”苏棠说，“明早我煮姜茶端过去。”

“我陪你去。”

“不用。”苏棠说，“我自己去。”

顾淮安没再坚持，他低头看了一眼掌心的银牌，又收进怀里，手指在胸口的位置停了片刻，垂下眼：“那棵树，你外婆认识。我爷爷也认识。”

“他们三个人……”

“应该是四个。”顾淮安说，“我爷爷、你外婆、井泉会的‘守账的’，还有一个——把债记下的那个人。邵伯说‘债主还没等到人’，等到的人是我。但账本上记的，可能不只是我爷爷一个人的名字。”

苏棠想起那口石缸里的布鞋，鞋面上绣的半朵梅花，和骨架胸前那半朵梅花一模一样。她忽然觉得那朵梅花不只是一道辨认身份的记号，更像是某种信物——断成两半，一半在身，一半在土。

“明早我去桂花树那儿。”苏棠说，“你在这儿等我。”

她没去看顾淮安的表情，转身进了里间。橱柜里找到半包红糖，是陈阿婆前些日子送来的，说是土法熬的，比市面上那些精制的香得多。她捏了捏米缸，米还够，又翻出几颗干红枣，掰开看了看芯，没坏。

她一边准备着明早的姜茶，一边像受了指引似的，又去最里面的橱柜底下摸索。手指碰到一块松动的青砖，砖缝里嵌着个油纸包，她拨开土，那油纸包比手掌略大，被蜡封得严严实实。沈家塘石室里陈阿婆的话忽然在她耳边响起：“别让老太太知道是我给的。”

她拆开蜡封，油纸一层层剥开，里面折着一方暗红色的棉布。展开来，是一幅手绣的图案——桂花树，树下两个人影，一个穿裙子，一个穿长衫，两人中间搁着一口锅。锅边绣了三个字，用极细的线钉进去的，不凑近了根本看不出来。

苏棠把那三个字翻来覆去认了几遍，手里的棉布忽然烫起来：“欠，债，人。”

苏棠蹲在地上，那方棉布摊在她膝头，桂花树的枝桠一路绣到布角，枝头缀着细密的花苞——每一朵都绣了六瓣，只有最顶端那一朵，只有五瓣，缺了一瓣，像是绣的人故意留的。她忽然想起外婆手稿里夹着的那张照片，照片里外婆站在桂花树下，身后有一大片浓密的树影。当时她没在意，此刻她猛地意识到——照片里外婆身后那棵桂花树的枝头，也有一朵只有五瓣的花。

苏棠收起棉布，蹲着又去找那半包红糖。窗外月光移过铺檐，在青石板上投下斜长的影子。她起身时，铜锅锅里还剩一点没干透的红糖水渍，正对着锅底那道裂纹最细的地方，缓慢地往下渗。

像是一口井，等她往里填东西。

# 第160章 银顶针的第三层

阁楼里只剩下呼吸声。

苏棠的手指捏着那枚银顶针，指腹摩挲过针身上的细密纹路。顶针内壁有一圈极浅的凹槽，若不是方才电筒光斜打到那个角度，根本发现不了。她用指甲轻轻扣了扣，凹槽边缘有一丝几乎看不见的缝隙。

“有夹层。”顾淮安的声音低而稳，将手电凑近了些。

苏棠把银顶针翻转，对着光细看。那缝隙沿着内壁走了一圈，像是底盖被旋上去的。可顶针底部是浑圆的，看不出任何接口。她试着转动，纹丝不动。

“可能是螺纹。”顾长宁从工具箱里翻出一把小镊子，递过来，“试试逆时针。”

镊子尖探进那道缝里，太浅，打滑。苏棠换了个角度，用了点力，咔——很轻的一声，像是挤压的橡胶回弹。银顶针的底部竟然松动了一毫。

她屏住呼吸，一点一点旋。三圈半之后，底盖脱落，掉出一卷比棉线还细的银箔纸。

银箔纸展开，只有小指甲盖大小，上面压出一行极细的字。苏棠拿到灯下，眯着眼读：“六月十八，周府后院，桂树下。”

顾淮安身子明显一僵。

苏棠转头看他。他的脸色在昏黄的电筒光里白了半分，嘴唇抿成一条线。她记得顾长明遗信上写的——“她不是自杀的，有人进过她家后院。”信里提到的后院，会不会就是周府后院？而周府，是周明远家祖宅。

“六月十八……”顾淮安声音微哑，“如果我没记错，那是我大伯母过世的日子。”

“大伯母？”苏棠心头一跳。

顾淮安没接话，他目光落在那卷银箔纸上，久久不动。阁楼外风声掠过瓦檐，像是有什么在窗外经过。

“你外公家祖宅，还在吗？”苏棠问。

顾淮安低头，像是在把某段记忆从很深的地方捞出来。“在，”他说，“离这里四十里，常山镇。老宅没人住，院子里的桂花树——我小时候还有，后来周叔说树死了，锯了。”

死了？锯了？苏棠攥紧银箔纸。“什么时候锯的？”

顾淮安沉默了一会儿：“那年六月，暑天。”

那年六月。银箔纸上写的正是六月十八。她心底一阵发寒——若是那棵树还活着，挖开下面的土，有没有可能还留着什么？

“去看看。”她把银箔纸小心收进包里，“现在就去。”

顾淮安看着她：“天快黑了，常山镇路不好走。而且……”他顿了一下，“你忘了在巷口看见那两个跟踪你的人？”

苏棠目光稳稳地落在他脸上：“我不怕他们跟着。我怕的是——我先找到答案之前，那棵树先被处理掉。”

顾长宁在旁边举起手机：“我查了地图，凤鸣镇到常山镇走县道不到四十公里，大约五十分钟车程。如果怕人跟着，可以绕陈家湾那条岔路。”

苏棠站起来，拍了拍衣角的灰：“走。”

下楼时她回头看了阁楼一眼。外婆的遗书、顾长明的信、银顶针里这卷薄薄的银箔——像一条线，从几十年前一路牵到现在，越来越紧。牵线的另一头，在常山镇那棵据说已经死了的桂花树下。

她隐隐觉得，那棵树下面，埋着的可能不止是答案，还有那个让外婆等了半生的人留下的东西。

车灯划破渐沉暮色，两个镇之间隔着大片田野和丘陵。顾淮安开车，目光始终注视前方，偶尔从后视镜里看一眼后座。

苏棠坐在副驾，把那卷银箔纸摊开在手心，月光照进来，银箔上的字像是活的，泛着幽幽的光。她忽然想起外婆手稿里那一页——写的是桂花糖藕的方子。当时她只觉得平常，现在回想，那页方子的下方空隙里，有一行几乎被水渍洇掉的添笔，她曾以为是做笔记时随手画的线。

现在她猛地明白了，那不是什么线——是桂花树的枝条。

她闭上眼，在心里重新描那行添笔的形状，然后睁开眼：“淮安，你爷爷家桂花树，是金桂还是银桂？”

顾淮安一愣：“银桂。”

“银桂。”苏棠低声重复了一遍这个词。外婆手稿里那一页，正好画了十三根枝条——十三，六月十八。

六月十八，在农历里是六月十三？不对。她算了算——那一年的农历六月十八，正好是……她掏出手机，翻了翻万年历，又算了算七十年代末的农历换算。那年的六月十八，对应公历七月末。而外婆手稿里桂花糖藕方子页角落里的添笔，像是歪歪扭扭的“十三”——也在那一页的页码位置。

不，不对。她重新展开那页手稿的复印件，翻到桂花糖藕那一页的上角，那里原有一行小字标注页码，但水渍晕开了。她拿手指仔细摸了摸，水渍中间有一点硬物凸起。她翻过纸页，用手电从背面打过去——一个数字浮现出来。

不是十三。是十八。

六月十八。她的心跳重重地撞了一下，呼吸都跟着灼热起来。她忽然有一种预感——外婆和顾长明，和周府那棵树，和那年夏天的某件事，纠缠得比她想象中深得多。而这一切，即将在常山镇的桂花树下揭开。

车灯翻过最后一道坡，常山镇的轮廓在夜色里显现出来。一片沉静的瓦房之间，有一棵巨大的枯树冠，孤零零地立在老宅院子里，像一只伸向天空的手。

那棵树，还立着。没被锯掉。

苏棠攥紧那卷银箔纸，掌心全是汗。

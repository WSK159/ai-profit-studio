# 第288章 账本上的红圈

杂货铺后屋的光线从半掩的木窗漏进来，照在账本发黄的纸页上，那三个红圈像三滴干涸的血。

苏棠的手指悬在纸面上方，不敢落下去。她认出了那笔迹——和外婆手稿里的批注一模一样，只是写这些字的时候，笔锋更利，力道更沉，像是用尽全身力气才把笔尖按下去。

“阮明州、杳城口音、左手六指，这三行被外婆圈起来了。”她低声说。

陈阿婆坐在旁边的矮凳上，两只手交叠放在膝头，指节发白。她刚才看到那六指手形记号时脸色就变了，此刻更是一片灰白，仿佛随时要昏倒。

顾淮安蹲下身，从苏棠手里接过账本，仔细端详那三个红圈。“这三笔用的是朱砂墨，不是普通红墨。账房记账用的红笔是洋红，朱砂墨在民国的时候是……”他顿了顿，“是写信封用的，或者画符用的。”

“画符？”苏棠心头一跳。

陈阿婆终于开口，声音像是从喉咙深处挤出来的：“她画的不是符。她画的是……标记。”

“标记什么？”

“标记她记住了一个人。”

陈阿婆垂下眼帘，手指开始神经质地摩挲膝头的布料。沉默了足足有半盏茶的功夫，她才又说：“棠丫头的阿婆，年轻的时候有一桩心事，从来不对人说。我认识她几十年，她只提过一回——那是九几年的事了，有一天晚上她喝了酒，跟我说起年轻时候的事。她说她这辈子只做过一件后悔事。”

苏棠屏住呼吸。

“她没说是什么事，只说了句：‘当年要是拉住他，也许就不会走散。’我当时以为她说的是阮沉烟。可后来越想越不对——阮沉烟走的时候，她自己也才十八九岁，一个姑娘家，怎么拉得住一个要走的男人？她说的‘他’，未必是阮沉烟。”

“那还能是谁？”

陈阿婆苦笑了一下：“你阿婆的命里，有两个留不住的人。一个叫阮沉烟，另一个……就是那个伙计，阮明州。”

后屋静得能听见梁上灰尘落下来的声音。

苏棠转头看向顾淮安。他的脸色倒还算平静，只是捏着账本边缘的指腹微微泛白。她知道他在想什么——他父亲最后叫的名字，也是“明州”。

“陈阿婆，”顾淮安问，声音很稳，“你认识阮明州吗？”

“我没见过他。”陈阿婆摇头，“我是后来搬来临水巷的，比你阿婆晚了二十多年。你也知道，这条巷子的人搬来搬去，真有交情的老街坊，一只手数得过来。你阿婆的事，我是断断续续听来的，她不爱说，我也不爱打听。”

“那六指手形呢？”苏棠追问，“你怎么看一眼就怕了？”

陈阿婆的嘴唇动了动，没出声。她伸手摸了摸自己左手的小指，那个动作很轻，像是无意识的。然后她站起身来，走到墙角的一只樟木箱前，弯腰打开，翻了半天，翻出一张叠得四四方方的牛皮纸。

纸已经脆得像秋天的落叶，陈阿婆小心翼翼地展开，递到苏棠面前。

那是一只手的拓印。

准确地说，是一个左手的墨印，像是有人把墨涂满了手掌，然后按在纸上留下的。手指细长，轮廓清晰。而那只手的尾指旁边，清清楚楚多出了一根指头。

六指。

墨印旁边写着几个字，字体方方正正，虽然有些褪色，但依然能辨认出——

“试菜留档，乙亥年腊月。”

“这是我叔公留下的。”陈阿婆说，“他早年在县城开过一间饭馆，请过一个帮厨，左手六指。那年腊月饭馆盘出去，他留了一手印做存念。我是后来整理遗物翻出来的，认了这个墨印……可不就是阮明州。”

苏棠盯着那枚墨印，心脏跳得厉害：“你叔公的饭馆在哪？”

“杳城。”

顾淮安站起来：“陈阿婆，你叔公……有没有提过这个人后来去哪了？”

陈阿婆沉默了很久，久到苏棠以为她不会回答了。然后她抬起头，看着顾淮安的脸，目光有些恍惚，像是透过他在看另一个人。

“你跟你爸，长得真像。”

这句话毫无征兆地砸下来，连顾淮安都愣住了。

陈阿婆慢慢回到矮凳上坐下，声音轻得像自言自语：“我叔公说，那个六指的帮厨，在他饭馆干了不到半年。人老实，话少，做菜有天分。走的那天，说是去找一个人。”

“找谁？”

“他说，去找他的师娘。”

窗外一阵风卷过巷口，把晾在绳上的床单吹得鼓起来，阳光一晃，照亮了屋里浮动的尘埃。

苏棠握着那张牛皮纸，手指轻轻摩挹过墨印上那根多余的指头。

她忽然想到一件事——外婆手稿的那些记号，那些六指手形，她一直以为是在记“阮明州这个人”。

可如果她记得是另有其人呢？

如果外婆画下的每一个六指手形，都是在提醒自己——那个人还没有被找到？

“顾淮安，”她转头，“你爸的房间，还能进吗？”

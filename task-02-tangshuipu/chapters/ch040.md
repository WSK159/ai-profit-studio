# 第40章 桂花树下的地契

晨光刚爬上临水巷的屋脊，苏棠就蹲在桂花树西墙下，盯着昨夜挖出的那个油纸包发呆。油纸已泛黄发脆，拆开时边缘簌簌掉渣。配方纸的背面洇着水渍，旧墨里夹着一行更小的字，薛定谔般只露出半个“方”字，其余被撕裂的纸缘吃掉了。

她将配方纸平铺在糖水铺的木桌上，用镇尺压住四角。这碗“桂花酸梅汤”的方子她昨夜已研究到凌晨——乌梅和山楂的比例比寻常酸梅汤偏甜一分，多了一味她从未见过的“霜糖渍桂芯”，处理步骤繁复，像是要锁住花瓣里最后一缕香。

“这方子，不是给人吃的。”顾淮安的声音从门口传来，他手里提着一袋生煎，白雾在晨光里袅袅升起，“是给人记的。”

苏棠抬头看他。他今天没穿白大褂，换了件浅灰的薄夹克，眼下有些发青，显然也没睡好。她把配方纸推过去：“你看，每味料的用量尾数——乌梅三十二克，山楂二十七克，冰糖四十四克，桂花九克。这些数字拆开，是日期。三十二年前，三月二十七日，四十四天后，就是四月九日。桂花九克，农历九月。”

顾淮安放下生煎，指尖在纸上轻轻划过：“四月九日……你外婆从广州回临水巷的日子？”

“陈阿婆说的，那年清明后一周。”苏棠抿了抿唇，“外婆从广州回来那天，身上只有一只藤箱和这个搪瓷杯。但她没有直接回铺子，先去了一趟桂花树下，在树根旁站了很久。”

“三十七号那位方姓厨工呢？老档案里写过他哪年搬来的吗？”

苏棠摇头：“只有个‘厨工’的登记，连全名都没有，迁入迁出栏空白，像是被人为抹掉的。顾淮安，你说一个人得多怕暴露，才会连名字都不留？”

顾淮安没有立刻回答，他低头看着配方纸上那个残缺的“方”字，忽然说：“昨天我回卫生中心查了旧防疫档案，三十七号在三十三年前的春天做过一次入户健康登记，户主登记的行业是‘糖水师傅’，年龄比我大一些，姓方，但拼音缩写和别名混在一起，档案翻页时粘住了，我只看到‘方’和‘糖’两个字。”

苏棠的呼吸停了一瞬：“那他还在不在临水巷？”

“最后一针疫苗记录停留在一个月后，之后档案被销号，写的是‘迁出，去向不明’。”

“去向不明……”苏棠念着这四个字，指尖轻轻摩擦着搪瓷杯的杯沿。秦姨就在这时推门进来，怀里抱着一卷泛黄的图纸，气喘吁吁：“苏棠！我儿子在阁楼翻到他爷爷做木匠时收的旧房契，说这巷子以前不止一间糖水铺——你看这张！”

她摊开图纸，上面是三十多年前临水巷的手绘平面图，用铅笔标注了每间屋子的归属。苏棠的目光一下子钉在画上——桂花树西墙那一侧，标注着三间连排铺位，最中间一间用红笔圈着，写着两个字：“方记”。

“方记？”苏棠心跳骤然加快，“这不是糖水铺？”

“写的是‘方记·糖水’。”秦姨点着那张图，“这一排三个铺面，你外婆的棠记在最东头，中间是方家，西头是家杂货铺。后来方家那间屋子的产权在三十三年前被过户了，之后就再没开过门。房契上写，买主是——‘苏桂芬’。”

苏棠愣住了。外婆，用登记名买了方家的铺子？

顾淮安站在她身后，声音低缓：“你外婆不是买他的铺子，是买他的沉默。”

门外突然传来一阵摩托车轰鸣，随即是周明远助理的声音：“苏老板！周总让我送这个来——”

苏棠快步走到门口，一个信封搁在门槛上。她拆开，里面是一张打印纸，上面只有四个字：“你查错了。”

落款处印着“糖记”的LOGO，枫叶形状，张牙舞爪。

# 第449章 桂花树下有人等

井道里的空气凝成一股甜腻的姜奶味，苏棠循着味道往石门缝看去，缝隙间只余黑暗，什么也看不见。但那味道分明就在几步之遥。

“是外婆的方子，”她说，“北城五年，我复刻不出来的那一味姜汁比例——就是这个味道。”

顾淮安没有质疑她。他只是仔细检查了石门四周的接缝，指腹摩挲过门侧壁面时，忽然停住：“这里有新刻的痕迹。”

苏棠凑过去。门侧一块不起眼的砖面上，有人刻了一棵桂花树，枝条横斜，树下一道简笔画的人形——站在树旁，抬着手，像是在等谁。

“这和手稿里的画一样。”苏棠声音发紧，“外婆那本手稿，夹层里就有一张草图，也是这样一棵树，树下一个女人的背影。”

她抬手将要触那刻痕，指尖还没碰到砖面，那道刻痕的线条深处竟渗出一滴浅金色的汁液，顺着砖缝滑落。苏棠用指尖接了，凑到鼻尖——是桂花蜜，浓稠的，带着陈年暗香。

顾淮安神色微变：“这块砖是被桂花蜜浆泡透的，有人常年往砖缝里滴蜜。”

苏棠想起陈阿婆提过的“红糖桂花蜜，是伺候井里醒着的那位的”，她摇头：“井婆婆供的是红糖桂花蜜。但这里的蜜，是新鲜的——不到一个月。”

两人交换一眼，却没有再说下去。顾淮安率先转身，沿着那石门后的通道往回走，苏棠跟上。通道里铺着浅浅一层水，她走到方才那棵巨大桂花树的幻影消失处，水已经没有方才深了，露出湿润的泥底。她弯腰，见泥底深处印着一串足迹。

是光脚踩出来的，脚印不大，边沿圆润，像是孩子的。

“不是阿婆的脚。”苏棠低声道。

那脚印从通道深处一路延伸，爬到树根处消失了。树根盘虬，根部却有一截被劈断过，断口泛白，露出的木质纹理像是被人在近几日动过。苏棠在断口处蹲下，指尖探进裂罅，触到一层油纸。

她把油纸抽出，展开。纸里包着一根铁钥匙——通体乌黑，没有锈迹，钥齿形状复杂，与石门上细小刻纹的走向吻合。钥匙根部系着一根红绳，绳上挂了半边小铜铃，铃身刻着一个字。

苏棠翻过来看：“棠。”

她心口一阵酸热。她记得小时候，外婆针线盒里就有这样一枚铜铃，说是她外公留下的旧物，后来搬家时找不着了。

“第三口井的铁钥匙。”顾淮安说。

苏棠攥着钥匙站起，环顾四周——她仍身处陶然亭那口井的底道上，可她怎么也说不清，自己方才到底有没有真的离开过那间石室。她抬头，洞口透入的光线已变成傍晚的暖橘色。这时，洞口边沿滑下来一团东西，砸在她脚边，滚了两圈。

是一截桂枝，翠绿的，叶子还挂着水珠。

桂枝上缠着一根灰白的头发。苏棠捡起桂枝，发丝绕在指尖，长度齐肩，粗细均匀，发根处带着一点白。

她还没开口，头顶传来陈阿婆的声音，沙哑而稳：“丫头，出来吧。天快黑了。”

苏棠握紧桂枝，快步向洞口走去。出了井口，陈阿婆就蹲在井沿边上，手里捏着一把枯桂花，正在朝井里撒。她看到苏棠手里的桂枝和铁钥匙，眼睛眯了一下。

“找到了就好。”她拍了拍手上的灰，站起来，“你外婆当年也打这口井里捞到过一根桂枝，她说，‘等的人回来了，树就发新枝了。’”

苏棠看着手里的桂枝，翠绿鲜活，没有半点枯意。她问：“陈阿婆，这口井……第三口井在哪？”

陈阿婆没答，只是朝巷尾那棵枯桂花树桩努了努嘴：“树根底下，早就埋着井。只是井口叫树根盖住了，谁也看不见。”

她顿了顿，又补了一句：“只有拿钥匙的人，才看得见井口。”

苏棠低头看手中铁钥匙，匙柄的顶部有一道细小划痕，正是一只飞鸟的轮廓。她再看掌心的飞鸟印记，与那划痕的走向竟分毫不差。

这时，巷口传来一声轻响。她抬头，夕阳里，一个人影站在巷口，逆着光。那人穿白大褂，身形颀长，手里提着两碗用油纸封口的糖水——一碗姜撞奶的暖黄，一碗酸梅汤的深褐。不是顾淮安。顾淮安刚才明明还在她身后，此刻却不知什么时候离开了井边。

那人向前走了一步。苏棠终于看清他的脸——三十上下，眉眼温和，笑意浅浅，与周明远有几分相似，又有几分陌生。

他开口，声音不高：“你是苏棠？有人托我把这碗酸梅汤带给你。她说，你喝了，就知道她是谁了。”

苏棠看着他递来的碗，汤色深褐如旧。碗沿贴着一个小小的“棠”字——是一张旧标签，米黄色的纸，边缘被水浸皱。

正是外婆生前常用的那一种。

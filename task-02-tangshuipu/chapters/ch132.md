# 第132章 听证会前夜

听证会改到明天下午，这个消息像一颗石子投进死水，巷子里的老老少少全炸了锅。

苏棠把青石板翻过来时，天已经彻底黑了。石板上密密麻麻刻着细小的字，被青苔糊了大半，顾淮安打着手电筒蹲在旁边，一个字一个字替她辨认。那些字迹潦草得像落笔的人手在抖，结尾几个字被雨水洇得模糊，只剩下半句：“……若我回不来，把方子毁了，棠记留给她……”

“她”是谁，不言自明。

苏棠蹲在原地，膝盖压得发麻，半晌没动弹。风从巷口灌进来，吹得她后脖颈凉飕飕的。她伸手摸了摸那些刻痕，指腹摩擦过粗粝的石面，像在抚摸一个人的遗言。

“这字迹跟瓮里那张字条一样。”顾淮安把手电筒的光收拢，声音压得很低，“是同一个人的字——你外公。”

“仁济堂……”苏棠把那三个字含在嘴里嚼了嚼，像嚼一颗苦涩的杏仁，“宣统年间就注销了药房，可我外公的字条上说‘药在仁济堂库中’——什么药，能让一个药房掌柜抛下妻女失踪几十年？”

顾淮安答不上来。他从来不是话多的人，只是把外套脱下来披在苏棠肩上，说了句“明天听证会，你还有一堆材料要理”。

两人回到棠记时，堂屋里已经坐了一屋子人。陈阿婆坐在最中间那把藤椅上，旁边围着一圈老街坊，有巷口修鞋的孙伯、卖鱼丸的林叔、教小孩写字的周老师，还有几个苏棠叫不上名字却面熟的面孔。桌上摊着一摞发黄的纸片，全是各家各户的老地契、旧照片、户口本复印件，压得那张八仙桌水泄不通。

“棠丫头，你只管去，材料我们凑。”陈阿婆一拍大腿，“临水巷的地，是祖上踩出来的，不是开发商画个圈就能拿走的。”

苏棠眼眶一热，好半天才把那口气咽下去。她蹲在桌边一张张翻那些材料，翻到最底下时，手指忽然停住了——那是一个牛皮纸信封，封口用红蜡封着，蜡上压了一枚印章。

“这是什么？”她抬头问。

陈阿婆瞟了一眼，脸色微变：“哪来的？我没见过这个。”

信是夹在一本1962年的粮油供应证里。苏棠把封蜡剥开，抽出里面一张薄薄的纸，展开一看，是一份手写的《棠记糖水铺产业契约》，落款处贴着三张印花税票，时间是民国三十七年。契约最后一行小字写着：“如遇征收征用，凭此契至北城仁济堂旧址东厢换取正式红契。”

屋子里安静了几秒。

“北城仁济堂。”顾淮安站在门口，声音不大，“今天在柳树巷找到的那张老地图，终点画的也是城北西郊。”

苏棠把契约折好放回信封，又看了看桌上的青石板拓片，心里隐隐把那根线牵了起来——外公留下的字条指向仁济堂库房；仁济堂在城北西郊；而这份契约说，正式红契也在仁济堂旧址。兜兜转转，所有线索都汇在一个地方。

她正要开口，门外忽然传来一阵急促的脚步声，紧接着“砰”一声，王伯气喘吁吁推门进来，手里攥着手机：“棠、棠丫头——明天听证会的听证员名单出来了！”

他把手机递过来，屏幕上是一则政务公示，苏棠逐行扫下去，目光定在第三行——听证员：容盛（市规划局退休干部）。

容盛。那个与“归魂案”有关的名字，顾淮安一直在查的人。她抬起头，隔着半个堂屋对上顾淮安的视线，两人都没说话，但心里同时涌起同一个念头：明天的听证会，恐怕不是一场普通拆迁听证会。

窗外，巷口路灯下，一个佝偻的身影提着一只空碗，站了很久很久。

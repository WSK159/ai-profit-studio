# 第558章 钥匙扣上的刻痕

苏棠回过神来的时候，顾淮安已经蹲在她身侧，手指捻起那截暗红毛线头对着从气窗漏进来的光端详。他的动作很轻，像在对待某件易碎的瓷器。

“这块毛线打的结，是‘永’字扣。”他说。

苏棠心脏猛地一跳。红绳铜钱上那个“永”字——外婆纸条与顾长砚账本里的“永”字——那个被称为“误其一生之味”的“永”字。她伸手想接过来看，顾淮安却把毛线头收进了随身药箱侧袋里。

“先收好。”他看了一眼神龛方向，“她不是说，欠了一碗糖水，要还么。东西留在这里，怕是会有人来取。”

苏棠抿了抿嘴，没有追问。她低头看向手里的铜钱钥匙扣。铜质已经发暗发绿，但边缘棱角仍在，看得出是被常年摩挲过的。钥匙扣的款式极老，铜钱正中凿了个小孔，穿着一截红绳，与外婆手稿夹层里那半张票据上的绳结材质一模一样。她翻过铜钱背面，借着光，看到上面有四道极浅的刻痕，像是有人用针尖一类的东西划上去的。三道已深，第四道只是浅浅一道印子。

“这个……”顾淮安目光停在她指尖，“像是一年一道。”

苏棠心里算了一下。四道刻痕，如果是三年多前开始划的——正好是外婆去世前后。

“老太太说，顾长砚留下的。”她声音有点干涩，“他说欠了一碗糖水，要还。”

顾淮安没有接话。空气里姜撞奶的香气已经散得差不多了，但甜味还腻在舌尖，仿佛老门房灶台上那碗奶的余温还残留着。挂钟指针不知何时已经跳过十二点零一，正走向十二点零二。秒针走动的声音极轻，但在死寂里格外清晰。

“先出去。”顾淮安忽然说，“莫家冰厂旧址不是久留之地。”

苏棠握紧钥匙扣，点了点头。两人重新穿过甬道，推开窄门，回到冰厂旧址的大堂。雪白的灯光落下来，把两人的影子拖得又长又矮。陈旧的墙面砖缝里还有乌黑的霜痕，像是一层结了几十年的寒气。门外的风声隐约灌进来，带着傍晚特有的凉意。

走出窄门那一瞬，苏棠回头看了一眼甬道深处——那里漆黑如常，但神龛前的烛火似乎又矮了一截。她不确定是不是自己的错觉，只觉得那火光低低地摇，像有人正俯身端起了那碗姜撞奶。

回到巷子里的时候，天色已经暗了。临水巷的糖水铺亮着暖黄的灯，门板上“棠记”二字在暮色里泛着旧漆的光。苏棠站在门口，钥匙扣在掌心硌出一圈浅印。顾淮安在她身后停了几秒，开口道：“你今天做了什么？”

“什么？”苏棠回头。

“姜撞奶。”他语气平淡，“你做了几碗？”

苏棠一怔。先是老门房灶台那一碗，后来又端了一碗到神龛前——两碗。不对，加上她在窄门后小室里重做的那碗，一共三碗。但老太太说那空碗是她放的……她心里一沉。

“我做了两碗。”她说，“但那神龛前的空碗，不是我放的。”

顾淮安嗯了一声，没有再说。他转身朝卫生服务中心的方向走，走出几步又停下。“那枚铜钱，”他没有回头，“背面应该有字。你翻过来看看。”

苏棠翻过铜钱。之前她只注意到正面那四道刻痕，翻到背面才发现，铜钱的边缘刻着极小的两个字，像是用刻刀一笔一笔凿出来的，笔画极浅，几乎被铜锈盖住。她凑近灯下辨认了许久，才认出那两个字——

“顾沈”。

是一个姓氏和另一个姓氏，被凿在同一枚铜钱上。顾长砚的顾，与外婆本姓沈的沈。她抬头想叫住顾淮安，巷口已经没有人影了。只有风把远处陈阿婆花摊上的塑料膜吹得哗啦响。

苏棠捏着那枚铜钱，站在铺子门口，忽然觉得这枚小小的钥匙扣，像一把没插进锁眼的钥匙。它让她看见一扇门，却还没让她推开。她推开铺门走进去，把铜钱放在案板上。灯光照下来，那“顾沈”二字在暖光里泛着暗黄的光。

她盯着看了很久，然后翻开外婆手稿，找到那一页——外婆写“江”又划掉，旁边用水笔重新写上“沈时圆”的那一页。她比了比铜钱上“顾沈”二字的笔迹，再去比对稿纸上那些字的收笔起势——那“顾”字的横画微微上挑，收笔处有一个极轻的顿挫。

和外婆手稿里某页边角处一个被反复摩挲、几乎要磨破纸面的“顾”字，一模一样。

苏棠指尖微颤。她翻过手稿最后一页，那页背面，纸已经泛黄发脆，角落里有一行极细的字，像是用铅笔写的，又像是被人反复描过。她凑近看，那行字是：“我欠他一把钥匙，还了他两扇门。”

钥匙扣、铜钱、“顾沈”二字、那一行字——“欠了一碗糖水，要还”——

苏棠放下手稿，走到灶台前，重新生火。她心想，也许明天，她该去顾淮安的卫生服务中心坐一坐。

# 第458章 井底的桂花叶

井底传来的哼唱声在潮湿的空气中荡开，像一层薄雾贴着水面蔓延。苏棠蹲在塌洞边缘，手指攥着那枚铜顶针箍，冰凉的金属硌着掌心，她却没有松开。那哼唱声唱着不成调的曲子，三五个音节反复回旋，竟像是临水巷老人哄孩子睡觉时哼的童谣。

顾淮安站在她身后两步远的地方，呼吸放得很轻。他朝洞口探了探身，手电光扫过水面，只见几片桂花叶浮在水上缓缓打转，叶片青翠，像刚被风吹落的水面。老粮仓塌下来的砖石堆在洞壁周围，水泥地面开裂成蛛网般的纹路，缝隙里渗出暗色的水渍。

“这井……”他顿了一下，“还活着。”

苏棠没有回答。她把顶针箍举到眼前，借着光看清内壁那个“缙”字，笔划是錾子凿出来的，边缘磨得发亮。她想起外婆的手稿里有一页画过一枚顶针，旁边写着一行小字——“套在指上，压住针脚，日子就密了。”

哼唱声停了下来。水面忽然颤动了一下，那些桂花叶被不知哪儿来的波纹推向井壁，又缓缓散开。苏棠听见自己身后传来细碎的脚步声，回头一看，陈阿婆已经从坡上走下来了，花白的头发被细密的雨珠沾湿，手里捧着一只粗瓷碗。

“年轻人，”陈阿婆的声音沙哑而平静，“那顶针箍，是我丈夫的。”

苏棠站起来，手腕还有些发酸。她把顶针箍递过去，陈阿婆却没有接，只低头看了看那件旧物，像看着一个久别的人，抿了抿嘴角。

“他姓陈，给人做木匠活，替苏家守过几年井。”陈阿婆慢慢说道，目光落向黑洞洞的井口，“他欠苏家一笔钱，一直没还清。那年腊月，他从这井里捞上来一只铜扣，说那东西不该在井底，回头要还给苏家人。”

“铜扣？”苏棠心头一跳，“什么铜扣？”

“圆肚，碗沿大小，中间一个‘棠’字，半边被泥锈蚀了。”陈阿婆说，“他没来得及还。第二天出门去沈家塘送货，人就没回来。后来有人在河滩上捡到他的鞋，说大概是掉水里了。那铜扣，跟着他一起不见了。”

井底忽然又传来一声响动，闷闷的，像什么东西在水下翻转。三人都安静下来，手电光齐齐投向井底，只见水面上那几片桂花叶慢慢沉了下去，像被什么东西从水下拽住了。

“这井里……”苏棠犹豫了一下，“有人吗？”

陈阿婆没有回答这个问题。她弯下腰，把手里那只粗瓷碗轻轻放在井沿上，碗里装着半碗红糖桂花蜜，颜色殷红，桂花瓣浮在表面，隐约散发出温甜的气息。她嘴里低声念叨了一句什么，像祝祷，又像唤人，苏棠只听清几个字——“吃一点吧。”

那碗桂花蜜放到井沿上之后，井底的水声忽然停了。像有什么东西安静下来，认真听着地面上的动静。

顾淮安走上前两步，目光落在那只粗瓷碗的碗沿上，微微一怔。他从口袋里掏出一只透明密封袋，蹲下身，小心地把碗沿上一根沾着糖蜜的灰白发丝夹进袋中，封好口。

“这根头发……”他站起来，看向陈阿婆，“是您留下的？”

陈阿婆没答话，只静静地看了他一眼，然后转过身，朝坡上走去。她的背影被雨雾吞没几步，又传来一句：“它认得那碗糖蜜。每年腊月初八，我都给它端一碗。今年端早了。”

苏棠站在原地，雨水顺着屋檐滴下来，打在塌洞边缘的砖石上，溅起细碎的水花。她低头看着那碗桂花蜜，又看看手里那枚顶针箍，忽然想起什么，从口袋里摸出外婆手稿的夹层——那张发黄的照片背面，用铅笔写着一行极淡的字：

“腊月初八，井水变甜，有人来。”

她怔住了。外婆手稿里的字迹，和陈阿婆方才那句话，几乎一模一样。

“腊月初八。”她低声念出来。

顾淮安走到她身侧，声音也压得低：“你外婆的手稿里，写的是哪口井？”

苏棠翻过照片背面，那个“井”字被水渍洇得有些模糊，但笔划的收尾处微微上扬，像画了一条弯曲的弧线。她看了很久，忽然意识到什么，抬起头看向老粮仓深处。

“不是这口。”她说，“手稿写的第三口井。”

就在她话音落下的瞬间，井底传来一阵轻柔的水声，像有人从水面下浮上来。苏棠和顾淮安同时屏住呼吸。手电光落下去，只见水面上浮起一枚圆润的桂花叶，叶片正中穿着一根细长的红线，红线上系着一只小小的铜铃铛，湿漉漉地贴在叶面上。

铃铛在水面上晃了一下。没有发出声音。

但苏棠看见——那根红线的另一端，一直延伸到井壁深处，消失在砖缝之间。

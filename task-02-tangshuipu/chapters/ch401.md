# 第401章 井边的灯

苏棠站在陈阿婆家门槛上，夜风裹着桂花的甜腥味扑面而来。巷子尽头，临水井的方向，一盏红灯笼不知被谁挂了起来，在风里明明灭灭地晃着，像一只半睁半闭的眼睛。

“那是井泉会的引路灯。”陈阿婆扶着门框站在她身后，声音沙哑，“挂灯的意思是——今晚有人要下井。这是最后一道规矩了。灯亮，人下；灯灭，人走。你若想让周深取走井底那半张票据，现在赶过去还来得及拦住他，否则那东西落了周家人的手，你外婆藏了六十年的账，就再也翻不回来了。”

苏棠转头看她：“阿婆，你方才说那纸条是你自己写的。当归不归——是你写给谁的？”

陈阿婆沉默了一阵，忽然笑了，笑意里带着几分说不清道不明的凄怆：“写给我自己的。也写给你外婆的。当年你外婆对我说，她这辈子欠周家一碗糖水，等哪天有人能做得出那碗糖水的味道，就把当归从井里捞出来。可我等了六十年，等到你来了，等到你今天追着井沿记号跑到我门口——我却已经认不出那碗糖水的味道了。”

她弯下腰，剧烈咳起来。苏棠连忙上前拍她的背，指尖却触到陈阿婆手心里攥着的一枚冰凉的东西。陈阿婆摊开手——是一把黄铜钥匙，齿纹极深，形状奇诡，像是刻着某种字的笔画。

“桂花树根底下那把。”陈阿婆喘着气道，“我原说要等桂花落尽再挖。可今晚……桂花等不及了。你拿着它，去井边。灯亮的时候，钥匙插进井沿第三块砖的砖缝里，横着转三圈。你外婆留下的路，就能走通了。”

苏棠接过钥匙，掌心传来一阵冰凉的震颤。她捏紧了钥匙，又忍不住问：“那你呢？”

陈阿婆靠在门框上，火光映着她满是沟壑的脸：“我在这儿等你。等你回来了，我想尝一口你做的姜撞奶——像你外婆当年做给我喝的那样。”她顿了顿，“去吧。别叫周深抢了先。”

苏棠别无选择。她攥着钥匙跑向巷口，井边的红灯笼在风中越晃越烈，灯火如豆，将井口染成一片晕开的红色。她跑到井沿边，俯身望去——水面上浮着一层细碎的桂花，像是有人刚刚将一整捧花洒进了井里。

井底深处，传来了极轻的、像是水滴砸在铜器上的声响。

铛——。

苏棠蹲下身，将钥匙对准井沿第三块砖的砖缝。钥匙齿纹恰好嵌入缝隙，她屏住呼吸，横着转了三圈。

咔哒。

井壁内部发出一声沉闷的机括弹动之声，像是什么沉睡了多年的锁被打开了。与此同时，她身后的巷子里，传来一声幽幽的叹息——不是陈阿婆的声音。是一个极苍老的、像从井底水汽里浮上来的女人声音，轻轻说：“你来了。我等了你六十年。”

苏棠猛地回头。身后没有人。再转回井口时，水面上的桂花忽然散开，露出一张极淡的、像是浸泡在水中的旧照片——照片上的人，穿月白旗袍，眉目清冷，跟外婆手稿夹层里那张照片上的女子，一模一样。那张脸在水面上停留了一瞬，便又散去了。

而井边的红灯笼，不知何时熄灭了。井泉会的规矩——灯灭，人走。可灯灭了，人还站在原地。苏棠站在黑暗里，掌心全是汗。她伏低身子，朝井底再看一眼，只见水面上缓缓浮起一柄铜铃，铃舌轻轻晃动，发出细得几乎听不见的响声——那声响，像是一个人的名字。有人在叫她。

“苏棠。”顾淮安的声音从巷口传来，带着急跑的喘息。她回头看见他跑来的身影，在他身后不远处，陈阿婆家的门缝里透出一线灯火，一明，一暗，像有人在轻声喘气。苏棠低头看向手中那枚已经发烫的铜钥匙，钥匙柄上不知何时多了一行极小的字，她举起钥匙对着月光仔细辨认——是四个字：

【糖水归井】

# 第443章 门里门外

门外的声音没有催促，像是在等着她权衡。

苏棠把碗无声地放在脚边，指尖在碗沿上摩挲了一下。她记得外婆手稿里写过一句话：桂花碗盛过的东西，都要还。

“你说的人是谁？”她没让声音发抖，“我外婆的票据，怎么会在你手里？”

门外那人笑了，笑声像旧木门转动时吱呀作响：“你外婆当年下井，带了两样东西上来。一张票据，一把钥匙。票据换了一碗姜撞奶，钥匙换了一条命。现在我手里拿的，是当年她押给我的那张。”

苏棠听到顾淮安在她身后呼吸顿了一瞬。

他走到她身边，声音很低，刚好只让她听见：“别开门。他说的票据，是你外婆手稿夹层里的那半张——另一半在周缙手里。”

苏棠想起那半张票据上模糊的药房名，想起陈阿婆说过的话：“你外婆欠的不是钱，是债。”

门外再度响起叩门声，这次只有两声，像是催促，又像是试探。

“阿棠，你不想知道你外婆最后一页上写了什么？”那个声音变得轻柔，像哄小孩，“你开门，我把票据还给你，你把碗还给我。公平。”

苏棠低头看着脚边那口碗。碗里的桂花不知何时已经沉到碗底，油线刻出的花痕在微弱火光下泛着暗光。她忽然想起外婆手稿里那行字：“别怕水底之物。”

她没动。

“我不开门。”她说，声音稳下来，“你想要碗，门缝就能递。”

门外沉默了。

那盏在门外晃动着的灯，缓缓移开了。光透进来的角度变了，不再正对着锁孔。苏棠听见一声几乎听不到的叹息，像风从水面上刮过。

“那就等你想开门的时候再说。”

脚步声沿着来路退去，渐远，却没有彻底消失——最后停在了某处，影子的轮廓被门缝里那缕光投进来，歪歪斜斜地拖在石阶上，一动不动。像是守在拐角，等着她从里面出来。

苏棠转过身。石井还亮着最后一盏灯，火苗在水面上微微摇曳，把对面的石壁照得忽明忽暗。她看见那只眼睛图案旁边，多了一行湿痕形成的小字——和之前那行字同出一人的笔迹，却细得几乎看不清。

“第三口井，桂花树下，铁钥匙埋在你出生那年的正月。”

苏棠攥紧了铜胎裹银铜钱。她终于明白外婆那句“别怕水底之物”的意思了——井底的东西从来没有害过她，它只是在等一个能把它说出口的人。

“顾淮安，”她忽然问，“我出生那年的正月，你在哪儿？”

他沉默了片刻，手指轻轻按在石壁那行字上：“我爷爷——苏贞——就是那年在桂花树下埋下一个铁匣子的。他说，等棠家的女儿回来，把铁匣子交给她。里面是一封信，还有半张票据。”

苏棠的指尖微微发颤。

“你爷爷……他姓苏？”

“他原名苏贞，后来改姓顾。”顾淮安的声音很轻，“你外婆年轻时教他做过一碗姜撞奶——他说那一碗姜撞奶，他记了一辈子。”

石井里的灯焰猛地跳了一下。

紧接着，井底深处传来一声闷响——像有什么东西撞在了石壁上，力道比之前任何一次都要沉重。水面上的油灯应声倾斜，火焰挣扎了两下，扑进水里熄灭了。

石室瞬间陷入黑暗。

黑暗中，苏棠听见顾淮安的气息就近在耳侧：“别动。”

井底的水声在黑暗中变得格外清晰，咕嘟、咕嘟，像有人在井底大口吞咽着什么，又像水在往某个深处倒流。苏棠听见石壁裂缝里传来细碎的碎裂声，什么东西正在缓慢地移动。

然后，她摸到了那口瓷碗的碗沿。

碗里不知何时多了一样东西——冒着热气的，形状圆润，指尖触到的表面微微发烫。她捏起来，鼻尖掠过一丝熟悉的姜味和奶香。

一碗姜撞奶。温热的姜撞奶。

在这口百年古井的深处，在没有火、没有任何人伸手的情况下，那碗姜撞奶就那样出现在她掌心里，温度刚好入口，姜味刚好呛鼻。

苏棠听见井底传来一个女人的声音，极轻、极远，像是从水下浮上来的：“苏……棠……棠。”

顾淮安的手掌按上她的背，指尖微凉。石门外那缕光再次移动，在锁孔处停住，轻轻碰了一下锁扣。

“有人回来了。”他说。

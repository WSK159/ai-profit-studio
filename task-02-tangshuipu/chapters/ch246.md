# 第246章 灰烬里的甜

雨是后半夜开始下的。

苏棠是被窗棂的响动惊醒的。她翻了个身，听见雨点砸在檐角的瓦片上，噼里啪啦的，像有人在往屋顶撒豆子。屋里很黑，只有墙角的夜灯泛着一圈朦朦胧胧的暖光。她摸到床头柜上的手机，凌晨三点四十分，屏幕亮起的那一瞬，她忽然闻到了一股味道。

甜味。

焦糊的甜味，像糖熬过了头，又像什么东西被火烤得发苦。

她一下子坐起来，赤脚踩在冰凉的水磨石地上，走到窗边推开木窗。冷风裹着雨丝扑进来，巷子对面那片老宅子的方向，隐约有一点橙红的光，在雨幕里一闪一闪的。那不是灯笼。

苏棠披了件外套，趿拉着拖鞋下楼，推开糖水铺的后门。雨斜着打过来，她缩了缩肩膀，顺着巷子往东走了二十来步，在拐角处站住了。

是陈旧的木料烧着的气味。

她看见消防车从巷口开进来，红蓝灯光在雨水的折射里碎成一片。老街坊们三三两两站在屋檐底下张望，有人披着雨衣，有人裹着被子，几个人在低声说话。

“怎么了？”苏棠拦住一个认识的大婶。

“陈阿婆的杂货间烧起来了，”大婶搓着手，“说是电线老化了，半夜起的火。人没事，就是里头的东西——哎呦，烧了个干净。”

苏棠心里一紧，压了压心口那阵不安：“陈阿婆呢？”

“派出所去录口供了，她人没事，就是精神不太好。”

雨还在下。消防员把水带拖进巷子，水柱冲进那间堆满了旧纸箱和干花的杂货间，黑色的烟从门缝里往外涌，混着雨气，把整个巷口染成了一片湿漉漉的灰。

天亮的时候，陈阿婆被街坊扶回了自己的屋子。苏棠端了一碗热姜茶过去，推开门的时候，看见老太太坐在床沿上，怀里抱着一个铁皮饼干盒。

那个盒子苏棠认识——陈阿婆平日里最宝贝的东西，谁都不让碰，锁在她的樟木箱子最底下。

“阿婆，”苏棠把姜茶放在床头柜上，“您没事吧？”

陈阿婆抬起头，眼睛红红的，但没哭。她拍了拍身边的床沿，苏棠坐过去。

“棠棠，”陈阿婆的声音沙哑，“你外婆当年跟我说的最后一句话，你猜是什么？”

苏棠没答话，只是看着老太太怀里的铁皮盒子。

“她说，‘阿珍，我等到他了。你莫要为我难过。’”陈阿婆低头，手指抚过盒面上褪色的牡丹花纹，“我那时候不知道她说的是什么意思。直到去年……去年腊月，你外婆走的前一天，她把这个盒子交给我，叫我好好收着，说——‘等小棠回来，你把这个给她。’”

老太太打开铁皮盒。里面是空的，只有盒底垫着一张泛黄的油纸。

油纸上画着一张地图，从临水巷出发，沿着青石河往南走三里，在第三个渡口拐弯，再穿过一片杨梅林——尽头画着一座宅子，宅子的门口画着一棵树，树的旁边写着两个字：杳城。

苏棠的指尖微微发凉。

“这是什么？”她问。

“你外婆年轻的时候住过的地方，”陈阿婆说，“她叫我藏了一辈子。她说，若有一天你想找她，就照着这张图去。她说她在那棵树下埋了一样东西。”

“什么东西？”

陈阿婆摇了摇头：“她没说。她说你见了自然会懂。”

窗外雨声渐歇，天色灰蒙蒙的，像一块没洗干净的旧布。苏棠握着那张油纸，纸边已经脆了，轻轻一碰就掉下一片渣。

她忽然想起。外婆的糖水铺里，灶台底下有一块松动的青砖。

她以前问外婆，那块砖怎么总是凸出来的，外婆笑着说：“那是老砖，累了，歇一歇。”

——苏棠忽然知道那个铁皮盒里该装什么了。

她看了一眼窗台上那袋昨晚周明远留下的糖，绳结绑得端端正正，像一排牙齿，正在朝着她咧嘴。

她转回头，对陈阿婆说：“阿婆，我明天要出一趟远门。”

陈阿婆看着她，半晌，慢慢点了点头。

“去吧，”她说，“你这脾气，跟你外婆一模一样。一辈子都在跑，跑完了才知道——回头路才是最短的那条。”

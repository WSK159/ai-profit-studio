# 第112章 墙上的糖水铺招牌

台风过后的第一个晴天，临水巷的水渍还没晒干，苏棠已经开了一锅新姜。

姜撞奶讲究一个“撞”字，热奶从高处冲入姜汁，一气呵成，多一分则老，少一分则嫩。苏棠手腕一翻，白瓷碗里的姜汁被滚烫的奶液砸出一个旋涡，不过三息，碗面凝起一层薄薄的奶皮。

“今日头一碗，给陈阿婆。”她把碗放进托盘，趁热端出门。

陈阿婆坐在巷口的花摊前，手里捏着一朵半蔫的白玉兰，目光却落在对面墙上。那面灰墙上不知何时被人用粉笔画了一只糖水碗，碗沿冒热气，旁边歪歪扭扭写了三个字——“棠记甜”。

“谁画的？”苏棠把姜撞奶搁在花摊边角，顺着她的视线看去。

“一大早就有个穿蓝布衫的老头，蹲在那里画了半天。”陈阿婆接过碗，低头闻了闻，“画完就走了，一句话没说。”

苏棠心里一动。她想起章末那夜拆迁测量队来过又离开的事，又想起顾淮安说过，最近巷子里多了些脸生的人。

“老太婆我活了七十多年，知道一件事。”陈阿婆用小勺搅了搅奶皮，忽然没头没尾地说，“走掉的人，会回来的。就像这碗姜撞奶，当年你外婆……”她顿住了，像被热气烫了舌头，改口道，“你这手艺，有你外婆七分火候。”

苏棠没有追问。这半个月来她已经学会了，陈阿婆想说的时候自然会说，不想说的时候，撬也撬不开。

她回到铺子里，择完一把小葱，正要往灶间走，余光瞥见柜台下方露出半截泛黄的纸角。她蹲下去，从柜台和墙缝之间的夹层里抽出一张对折的纸。纸很旧，边缘发脆，打开后是一幅铅笔画——画的是这间铺子的正面，门头挂着一块匾，匾上写着“棠记糖水铺”，但檐角的装饰花纹和她现在看到的不太一样。

画的下方有一行小字，笔迹苍劲，与外婆手稿的娟秀完全不同：

“1954年春，余重绘此图，以志故人。铺在人亡，唯余一墙。”

落款是三个字——马容盛。

苏棠握着这张纸，指节发白。马容盛。这个从井底碑文上刻下的名字，外婆手稿夹层里半张票据背后写着的名字，那个可能已经死了七十年的男人，居然在这间铺子里留下过一张画。画的纸角有炭笔细细描过的一行备注：“西窗下，第三块砖。”

苏棠回头看向铺子西面那扇窗。窗下是一面老墙，去年翻修时她只在表面刷了一层白灰，底下的青砖原封未动。她走过去，蹲下，手指从窗台左侧起数到第三块砖。那块砖的边角有一道浅浅的凿痕，像被人刻意做过记号。苏棠从灶台拿了把小铲子，小心地撬动砖缝。灰浆是旧灰浆，一碰就碎，她没费太大力气就把那块砖抽了出来。砖后的墙洞里，躺着一个油纸包。

油纸被虫蛀了不少洞，但包得极妥帖。苏棠一层层揭开，里面是一张泛黄的旧纸——不，是一张契纸。纸头上写着“房屋买卖契”，落款日期是“一九五四年二月”，卖主一栏写着“马容盛”，买主一栏写着“棠”。她认得出，那是外婆的笔迹。

“外婆……你买了这间铺子？”

可是不对。苏棠记得阿婆的遗物里有几张租契，是五十年代从房管所租来的，直到八十年代落实政策时才转为私产。如果这间铺子在1954年就被外婆买下了，那后来的租契又是怎么回事？除非——外婆当年买的，根本不是这间铺子。

苏棠把契纸重新卷好，放进油纸包里，正要塞回墙洞，忽然听到铺子门口有人喊了一声：“苏老板在家吗？”

她把油纸包连那张铅笔画一起塞进围裙口袋里，转身迎出去。门口站着一个戴金丝眼镜的中年男人，穿着一件熨帖的白衬衫，手里夹着一个公文包，笑容和气。

“我是周记甜品法务部的小陈，我们周总让我来给苏老板送一份东西。”

他递过来一个牛皮纸信封。苏棠没接，只是问：“周总？周明远？”

“是。”那人笑容不变，“周总说，上次在比赛会场见过苏老板的手艺，十分佩服。听说临水巷要拆迁二期了，周总有点消息，想跟苏老板私下聊聊。”

苏棠接过信封，拆开。里面是一张名片，和一张打印出来的通知——临水巷二期拆迁范围划定公告，落款是市城建局，日期是昨天。

“周总说，如果苏老板有兴趣，今晚六点，在巷口那家糖记新店见。”那人说完，微微欠身，转身走了。

苏棠站在门口，太阳晒在她脸上，风从巷子那头吹过来，带着糖水铺里新姜的辛辣气。她攥着那张公告，又摸了摸口袋里那张马容盛的铅笔画。西窗下，第三块砖。外婆在等一个人，等了一辈子。那个人会是谁？跟周明远又有什么关系？

她拨通了顾淮安的电话。

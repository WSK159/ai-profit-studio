# 第484章 三天之约

苏棠把那枚铜胎裹银铜钱攥在手心里，从窄巷里走出来时，太阳已经偏西了。临水巷的青石板被晒了一整天，泛着温吞吞的热气，她踩着那些光斑往回走，脑子里全是灰衣老者最后那句话——“三天后临水巷口桂花开时，烧一碗姜撞奶放井沿上。”

她推开棠记后门，灶房里还维持着她离开时的样子，锅台擦得锃亮，灶膛里的灰已经冷透了。她把铜钱放在案板上，盯着那半个“棠”字看了半天，指尖摩挲过铜钱的边缘，那里有一道极细的磨损痕迹，像是被人反复捏过千万次。

顾淮安从窄巷那头绕过来，在后门口拍了拍鞋底的泥，抬眼看她。“他走了？”

“嗯。”苏棠把那枚铜钱翻了个面，“他说三天后桂花开的时候，让我烧一碗姜撞奶放井沿上。可现在才二月，桂花哪里开了？”

顾淮安走过来，在她对面坐下，目光落在那枚铜钱上。“他说的桂花开，未必是真桂花。”

苏棠抬眼看他。

“你外婆临终前床头放的是姜撞奶，他问是不是放了双倍的糖——说明他知道你外婆的习惯。你不是说过，外婆做姜撞奶，从来只放一份糖，只有高兴的时候才放双份？”顾淮安停了停，“他说的是‘桂花开’，临水巷口的桂花树，是不是有一棵？”

苏棠心里一紧。巷口那棵老桂花树，枯了大半，去年秋天只开了稀稀落落的几朵花，陈阿婆还念叨过，说那棵树怕是撑不过今年了。可枯树也是树，若它撑过了冬天，三月里……她猛地想起什么，转身就往灶房外走。

“你去哪儿？”

“巷口。”苏棠头也不回，“我去看看那棵桂花树。”

临水巷口的老桂花树比苏棠印象中还要枯败，树干上裂开一道深口子，半边树皮剥落，露出白生生的木质。可苏棠蹲下去细看时，发现在树根背阴的那一面，有几根青灰色的枝条伸出来，顶端竟然缀着几个米粒大的花苞，青白色，被枯枝衬得格外醒目。

十一月了，桂花不该在这个时候开。可那花苞是真的，一颗一颗，紧紧攥着，像是憋了一整个冬天的力气，攒着要撑开那一层薄皮。苏棠伸手碰了碰，花苞硬硬的，还小，但确确实实活着。

“三天。”顾淮安在她身后说，“这花苞，三天后应该能开。”

苏棠站起来，拍了拍手上的土，没说话。她心里翻涌着一种说不清的滋味，外婆等了一辈子的人，一直住在她家井底，却没来见她最后一面。那人隔着井壁问“是不是放了双倍的糖”，说的是姜撞奶，说的也不只是姜撞奶。

“你还记得那张照片吗？”苏棠忽然问。

顾淮安点头。外婆手稿夹层里那张泛黄的照片，年轻男人站在桂花树下，穿灰布长衫，手里捏着一根桂枝。那张照片的背景，就是临水巷口的这棵桂花树，树上还挂着满枝的花。

“他在等桂花开。”苏棠轻声说，“可桂花一年只开一次，他住在我家井底，能看见吗？”

顾淮安沉默了。他望向那棵桂花树，目光缓缓移动到树根附近的土面上，那里有一圈被踩实的脚印，不深，但边缘整齐，像是有人经常站在同一个位置，站了很久。

“他看得见。”顾淮安说，“这棵树的位置，正好对着棠记灶房的西山墙。每天晚上灶房里点了灯，光会从窗口透出来，打在树上——他能看见花开了没有。”

苏棠怔住。她想起自己刚回临水巷的第一晚，灶房里的灯亮到深夜，她翻外婆的手稿翻到快天亮。那盏灯的光，从西山墙的小窗透出去，照在那棵桂花树上。那时候，井底的人是不是正在看着那一点光？

她掐了自己的掌心一下，把那股酸涩压下去。“三天后，我给他烧姜撞奶。”

顾淮安没接话。苏棠转头看他，发现他的目光落在桂花树另一侧的墙根下，那里的泥地上有一行新鲜的脚印，很浅，但能看出是两个人的。

“有人来过了。”顾淮安蹲下去，用手指量了一下那脚印的宽度，“一个穿布鞋的，一个穿皮鞋的。皮鞋的印子很深，踩在这里站了一会儿才走的。”

苏棠心里一沉。她想起灰衣老者消失前说过的话——“三天后临水巷口桂花开时”，那个约定，是约定，也是诱饵。如果别人也知道这个约定，那三天后，这棵桂花树下面，来的就不止她一个人。

“你认得出穿皮鞋的是谁吗？”苏棠问。

顾淮安没有立刻回答。他盯着那枚鞋印看了很久，慢慢站起来，拍了拍手上的土，声音比平时低了几分。

“这双皮鞋的尺码，和我在档案室里看过的一个人很像。”

苏棠心里打了个突。“谁？”

顾淮安没有看她，目光落在桂花树枯裂的树皮上，那里有一道新的划痕，像是被人用指甲刮过的，露出里面湿漉漉的青白色木质。他沉默了一会儿，才吐出一个名字。

“周缙的养子。”

苏棠猛地一震。周缙——那个名字她已经很久没听到了，上一次出现，还是在井底的牛皮纸上。她刚要开口追问，巷口那头忽然传来一阵脚步声，不紧不慢的。她转头去看，夕阳的逆光里，一个人穿着灰色夹克，正朝她这边走过来。那人走到离桂花树还有四五步远的地方停住了，冲她和顾淮安笑了笑，嘴角牵出一个弧度。

“苏小姐，”那人说，“我姓周，周延。想跟您打听个人——上次在井边看到的那位老人家，您还见得到吗？”=======

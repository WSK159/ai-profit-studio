# 第301章 腊月十九，晴

腊月十九的早晨，天格外好。

阳光穿过云层，给临水巷灰扑扑的屋檐镀了一层暖融融的金色。巷口那棵老槐树的枯枝上，居然落着一只灰喜鹊，尾巴一翘一翘的，叫了两声又飞走了。

苏棠站在棠记门口，把昨夜烧好的姜撞奶端出来。瓷碗里浮着薄薄一层姜汁凝结的白雾，奶面微微颤着，像一块刚凝好的玉。她把碗放在门前的石阶上，安安静静地等着。

陈阿婆挎着篮子经过，停下脚：“丫头，等谁呢？”

苏棠笑了笑：“等人。”

陈阿婆也不问更多，拍拍她的手走了。巷子里陆陆续续传来早点摊的吆喝声、自行车铃铛声、小孩子跑过的脚步声，都跟往常一样。

上午十点，顾淮安来了。他没穿白大褂，换了一件深灰色大衣，手里提着一个旧铁盒，走到苏棠面前，把盒子递过来。

“这个？”她接过去。

“昨晚从我家老柜子底下翻出来的。”他声音平静，“里面有几封信，是给我爸的。收件人写的是‘顾长渊，临水巷打铁铺’。”

苏棠小心地掀开铁盒盖子。几封泛黄的信封叠得整整齐齐，上面的字迹清瘦有力，用蓝黑墨水写的。她抽出一封，翻到背面——正中间有一枚浅浅的印花，已经模糊得几乎看不见了，但依稀可以辨认出轮廓，是一扇门。

一扇城门。

她没急着打开信封，把铁盒收好，端起石阶上那碗姜撞奶，往北城门方向走去。顾淮安跟在她身后，谁也没说话。

北城门下，阳光从城门洞穿过来，在地面上投下一道长长的影子。

柴奇今天格外早就来了，站在城门边上，手边放着一只用旧布仔细包着的青花瓷坛。他见两人走来，张了张口，又朝两人身后看了一圈：“……就你们俩？”

“就我们俩。”顾淮安说，“不过今天肯定还有人要来。”

苏棠把姜撞奶放在城门边的石墩上。奶面还冒着热气，在冬日的晨光里氤氲出一小团白雾。

十一点二十三分，街角传来脚步声。

很慢，很稳，像是走很久很长的路，终于走到这里。

一个头发花白、身形佝偻的老人，拄一根磨得发亮的黑色木杖，一步一步走过临水巷的拐角，走到北城门下。他穿一件旧棉袄，脖子上围着一条褪色的灰色围巾，左手的虎口处，一道深疤从食指根斜划到腕子。

顾长渊。

他站定在城门洞口，眯着眼，看看城楼上荒草，又看看城墙砖，目光最终落在那碗姜撞奶上。

他忽然笑了。那张布满沟壑的脸上，绽开一个从容的笑容：“奶还热着啊。”

苏棠嗓子发紧，一句话也说不出来。

“丫头。”顾长渊朝她点头，“你是棠记的？”

“是。”

“你外婆的糖水铺。”

“是。”

顾长渊点了点头，缓缓弯下腰，双手捧起那碗姜撞奶，凑到唇边，一口一口喝完了。他喝完，把碗放回石墩上。冬日的阳光照在他脸上，眉眼间那层风霜仿佛淡了一些。

“这一口，”他说，“我欠了二十六年。”

他转身，接过柴奇递来的青花瓷坛，食指摩挲过坛壁上那道暗痕，像在抚摸一个故人的脸颊：“腊月十九，坛子开了——人到了，东西就到了。”

他抬起头，看着苏棠：“你外婆有没有告诉过你，何深姓什么？”

苏棠怔住了。手稿上、照片上、陈阿婆口中，所有人都只叫她“何深”。

顾长渊替她回答了：“何深的何，是不肯改的。她的本姓，姓顾。”

“她是我的妹妹。亲妹妹。”

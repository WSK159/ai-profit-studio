# 第235章 门头的红绸

苏棠和顾淮安赶回临水巷时，巷口已经围了一圈人。两个穿着工装的年轻男人站在梯子上，正把“棠记”那块黑底金字的匾额往下拆，牌匾四角包着的铜皮在太阳底下闪着不吉利的冷光。陈阿婆站在人群最前面，枯瘦的手死死攥着梯子腿：“你们这是干什么！老匾比你们爷爷的爷爷年纪都大，谁给的胆子说拆就拆！”

为首的工头一脸为难，手里扬着一张盖了红戳的单子：“阿婆，街道统一市容改造，门头都要换统一的，有文件，您别为难我们——”

“文件在哪儿？拿来我看。”苏棠从人缝里挤进去，声音不高，却让乱哄哄的嘈杂忽然安静了一瞬。她接过来扫了两眼，抬头时脸上带着那种让顾淮安说过“像糖水一样不烫但捂人”的笑意：“这文件盖的是北城某区的章，咱们临水镇是哪个区？烦请你们哪位先去查清楚，再来拆也不迟。”

围观的人一阵哄笑。工头面子上挂不住，正要开口争辩，巷尾突然传来一个不紧不慢的声音：“都是一场误会。”来人四十出头，西装外套搭在胳膊上，领带松着，笑容比春日的太阳还和煦——周明远，连锁品牌“糖记”的老板，也是苏棠觉得越看越眼熟的那个人。

“棠记的新门头设计图早就出了，是我们品牌方跟街道共建的项目，本意是给老铺子免费翻新。”周明远走到苏棠面前，语气熟络得像在跟老邻居说话，“不过既然苏老板不乐意，那今天就先不动。都下来，下来。”

工人们麻利地收了梯子。周明远朝街道办的方向抬了抬下巴，压低声音：“拆迁二期的事你知道吧？老宅子统一改造，门头是第一步。你要是愿意，我下午叫设计师来跟你聊，做那种古色古香的铝合金边框，又结实又好看。”

顾淮安不知何时走到了梯子边，正低头看着那两名工人收起的工具袋。他突然开口：“这是夹扣式挂件，拆下来的时候在边框上留了痕迹——如果重新安装一次，原本的榫卯结构就废了。”

话说完，整个巷子都静了。

周明远脸上那层笑纹僵了一瞬，转而又自然地融开：“到底是医生，眼神好。”他整了整西装的领口，“那今天多有打扰，改天我再登门赔罪。”他转身走了几步，又回过头来，目光落在苏棠脸上，像在看一个模糊的印象：“对了，苏老板，我母亲以前也做糖水，她说这种店，招牌不是挂在门上的，是挂在人嘴上的。”

等人走远了，陈阿婆才松了攥在梯子上的手，掌心被铁角硌出一道红印。她盯着周明远离去的方向，喃喃地说了句话，被风剪碎了大半，苏棠只接住几个字：“……真像……长得真像。”

“像谁？”苏棠追着问。

陈阿婆浑浊的眼珠转了转，却把话头咽了回去，转而叹了口气：“你外婆在世的时候，跟我说过一句话。她说，周家的人，上门来的时候，都带着刀子裹了糖。”

她弯下腰，从墙角捡起一片被工人碰掉的匾额铜皮，塞进苏棠手心。铜皮背面刻着一行细小的字，是外婆的字迹：“棠记百年，不改其味。”

苏棠攥着那片凉冰冰的铜皮，一眼也没有看周明远离去的方向。

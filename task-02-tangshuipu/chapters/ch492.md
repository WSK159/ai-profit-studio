# 第492章 井底的脚步声

苏棠蹲在灶房的青砖地上，面前摊开那本泛黄的账页，指尖抚过那一行行蓝黑钢笔字迹。窗外的桂花树影斜斜地落进来，在纸面上投下斑驳的光。

门外传来脚步声，不急不缓的，带着某种熟悉的韵律。苏棠抬头，看见顾淮安站在门槛外，手里拿着一卷泛黄的图纸，白大褂的衣角沾着一点尘土。

“你去了哪儿？”苏棠站起身，拍了拍膝上的灰，“我打了几遍电话都没通。”

顾淮安走进来，将图纸铺在灶台上，展开。那是一张手绘的地形图，墨线勾勒，标注着密密麻麻的名目——水井、巷道、暗沟、涵洞。苏棠的目光掠过纸面，落在图纸右下角的一行小字上：“临水巷地脉勘合图，民国三十七年”。

“区档案馆的库房，前天刚整理出一批旧城建档案。”顾淮安指尖点在图纸中央的一个标记上，“这是棠记灶房的位置。你来看。”

苏棠凑过去。灶房的位置画着一个方形，方形的西侧——正是那口井的方向——有一条细线向南延伸，穿过几道虚线，最终汇入一条标注着“沈家塘”的暗渠。

“那口井，和沈家塘暗河是连通的？”

“图纸上是这么画的。”顾淮安说，“但我在档案里查到另一份记录——上世纪六十年代修地下水道时，这段暗河被人为封堵了，用青石和糯米浆砌死。封堵的位置，就在棠记灶房以南约十五丈。”

苏棠的脊背微微发凉。十五丈，不到五十米。外婆那口井的底部，她曾经听见过水声的地方，居然真的连着一道被砌死的旧河道。

“井底的凹槽，是暗河渡口的痕迹。”她低声说，“周延说的对应关系，不是隐喻，是真的。”

顾淮安没有立刻接话，而是将图纸翻过来，背面贴着另一张更小的纸条，黄旧脆薄，字迹已经模糊。苏棠仔细辨认，只依稀认出几个字——“逢望日，井底燃灯，沿河东行，见三岔口，取右道”。

她心头一跳。

“这纸条，是从哪里来的？”

“夹在档案卷宗最后一页的封底里。档案编号是城建临水巷六七——一份一九六四年的地下管网验收记录。负责验收的工程师，姓沈。”

姓沈。

苏棠深吸一口气，视线又落回那行字上。逢望日——她外婆账页上的十二笔账，也是逢望日。井底燃灯，沿河东行——那口井下面，果然有一条能走人的通道。

“周延说的‘今晚’是什么？”顾淮安的声音轻而稳。

苏棠攥着账页的手微微收紧：“我问他，什么时候去找沈家塘的人，他说，旧渠逢望日水退，今夜恰好是望日。”她顿了一下，“我在想，他说的‘去’，不是从地面上走过去。”

“井底通道。水退之后可以从暗河直接到沈家塘。”顾淮安抬腕看了一眼手表，“现在是下午四点，天黑之后大约六点半。望日……水什么时候退？”

“周延没说。”

两人沉默了一会儿。外面传来街坊的声音——隔壁卖杂货的林婶在喊她家孙子吃饭，声音远远的，带着烟火气。苏棠把脸转向窗外，桂花树上那些细碎的花瓣在午后的光里轻轻摇着。

“我得下去一趟。”她说。

顾淮安没有反对，也没说支持。他把图纸卷好，从口袋里掏出一只扁平的铁皮手电，推到苏棠面前：“井口那几块青石的位置，我记得。就算水退了，底下的泥也有人脚踩过的痕迹。你如果一定要去，天黑之前我跟你一起下去。”

苏棠看着那只手电。铁皮面有些锈，开关处磨得发亮，一看就是用了许多年的旧物。

“你……怎么会有这个？”

顾淮安顿了一下：“小时候在沈家塘住过一段，河边的老屋，也有一口井。”

他没有多解释。苏棠也没有追问。她把那张纸条收好，和账页叠在一起，又翻了一下黑漆木匣里那叠信纸。最后一封信仍是那封，印着桂花糖渍的痕迹。

她从井台边沿摸到那只铜钱，又看了看井口——日头偏西，光照落进井里，直直地打在砖壁上。那些旧砖缝里，似乎比前几日多了一道细痕。

她伸手去摸那道细痕，指尖触到一个尖锐的石棱。那石棱微微松动，像是被人新近撬开过。她用力一抠——石棱居然脱落了，露出一个拳头大的黑洞。

洞里躺着一样东西。

苏棠探手去摸——指尖触到一团湿滑的油纸，包裹着硬板板的东西。她把油纸掏出来，一层层展开：里面是一块巴掌大的木牌，桐油浸过，边缘烧出一圈焦黑，正面刻着一个“棠”字，背面却刻着三个字。

沈长庚。

顾淮安站在她身后，看见那个名字，目光微微凝住。

苏棠握着木牌，指尖发颤。外婆的手稿里从未出现过这个名字。但顾淮安查到的那份存根上，担保人一栏签的就是沈长庚的名字——而她外婆林秀梅，以铺为抵，担保了这个人二十六年。

“他为什么……”苏棠说到一半，声音哑了。

井底在这时发出一声闷响，像有什么东西从深处震了一下。

她低头去看，只见井水水面泛起一圈极细的涟漪，自深处缓缓荡开来。然后，从那片涟漪下面，传上来一阵声音——沉闷的、断续的、像脚步踩在湿泥地上。

不是她想象中回声，是从井壁另一侧递过来的脚步声。

顾淮安的手已经按在井沿上，肌肉绷紧。苏棠把那块木牌紧紧攥在手里，她知道，井下的那个通道里有人——而她手中的木牌，也许是对方等了太久的门牌。

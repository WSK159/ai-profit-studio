# 第476章 门外苍老声

门外的声音又响了一遍，带着一种奇怪的韵律，像是旧时货郎摇鼓时唱的调子：“有人在吗——收旧账咯——”

苏棠脊背一僵，手里那枚青白玉佩差点滑落。顾淮安已经不动声色地退后半步，右手探向腰间——那里挂着一串钥匙，铜的，指节长短，在灯下泛着幽光。

“收旧账”三个字像一根细针，扎进她心里。外婆那封信上就写着——棠记债，旧时账。而他们此刻正站在外婆遗物指引的还债堂里，手里攥着一坛子来历不明的甘草片，以及一枚与陈阿婆那玉佩成对的玉。

“这声音……不像人的嗓子。”顾淮安低声说。

苏棠凝神细听。那声音听着苍老，但总有一种说不出的“飘”，像隔着几层棉布在说话，字与字之间有几不可闻的停顿，不自然，不透亮。她想起外婆手稿里写的一句：“井底的人说话，声音是圆的。”

门外安静了一瞬。

然后那道苍老声音又响起来，这回带了几分笑：“不碍事，不碍事。我就在井台上坐一坐，不走。你们忙你们的。”

苏棠和顾淮安对视一眼，心里同时浮起一个词——守井人。

她压低声音：“咱们进来的时候还债堂的门是从里面闩的，那道木闩能承受多少力？”

顾淮安走到门边，指尖轻轻抚过那道黑漆斑驳的木闩，细看之下，木闩两侧各有一道浅槽，像是被什么东西反复磨过，槽内残留着暗红色的旧漆。他眉头微皱：“这木闩不是原配的，比门框新。而且——”

他顿住，指尖在门框内侧摸到一处凸起，凑近一看，是一截埋在木头里的铁丝，锈迹斑斑，被人为折弯成一个勾状，约莫小指长短，正好卡在门框与闩槽之间。这像是一种老式的暗锁：从门外伸进铁丝，可以挑开这道木闩。

“这扇门，从外面能打开。”他说。

苏棠心跳加速，忽听到门外的声音又响起来，这回唱了一句完整的调子：“井水甜，井水凉，井边的娃娃别着慌。一碗糖水一个钱，欠的还了才敢尝——”

那调子拐了三个弯，最后一个字拖得极长，像老式留声机放久了走调的唱片。苏棠浑身一震，这曲调她听过——外婆去世前的那个夏天，坐在桂花树下，手里摇着蒲扇，有一搭没一搭地哼过。她问外婆唱的是什么，外婆笑了笑说：“老掉牙的童谣，巷子里的孩子都唱过。”

可外婆哼的调子里没有“一碗糖水一个钱”这一句。

“走，从后窗翻出去。”顾淮安果断道。

还债堂深处有一扇半人高的小窗，用粗麻布挡着。苏棠将青白玉佩揣入怀里，又把那枚银簪插回发间。顾淮安先翻过去，回头伸手接她。苏棠跨过窗棂时回头望了一眼——还债堂那颗黑釉坛子安静地立在储物架第三层，坛口朝着窗子，像是有人刻意摆的这个角度。

她在翻出窗的瞬间，恍惚看到坛内壁那道甘草片的影子，在烛光下一闪而过，似乎多了几片。

窗外是一条窄巷，两侧是斑驳的高墙，青苔沿着墙根一直爬到半人高。顾淮安拉着她快步走了二十多步，拐过墙角，才停下来。

“你看到什么了？”他问。

苏棠抿了抿嘴唇：“坛子里的甘草片，好像多了。”

顾淮安眉头拧紧：“有人在我们进来之后，往坛子里添过东西？”

他这句话让苏棠后背起了一层细密的疙瘩。还债堂只有一扇门和那扇小窗，门从外面传来访客的声音，窗子是他们刚刚翻出来的唯一出口——如果有人在开堂前就藏在里面……她想不下去，再想就要撞进外婆那封信里“他还活着”的字眼上了。

两人沿着窄巷往回走。巷子两侧不见人影，但苏棠总觉得自己脚下踩着的地面微微发烫，像是底下有什么东西在烤着。

走到巷子尽头要拐上大路时，顾淮安忽然停住脚步。他蹲下来，看着墙根处青苔的边缘——那里有一排脚印，光脚的，很小，约莫六七岁孩童的脚掌大小，脚趾印清晰，正正地踩在青苔上。青苔很干，但那脚印的凹陷处却泛着湿润的水光。

“这是井边那道脚印的主人。”苏棠低声说。

之前她在井口看到的那些光脚印，与眼前这一排几乎一样。而这排脚印的方向，是一路朝着还债堂去的。

苏棠的目光顺着脚印一路延伸，在距离还债堂后窗三四步远的地方，脚印消失了。那里有一块青石板，比周围的颜色更深，像是被人经常踩踏。她蹲下身，指腹拂过石板边缘的缝隙，干燥平整，但缝隙里塞着一小撮白灰。她捻起那白灰凑近了看——不是石灰，是烧过的草木灰，极细极匀。这种灰，只有做桂花糕时才筛得这么细。

而临水巷里，只有陈阿婆家的桂花糕用这种细筛。

她抬头看顾淮安，他的眼神也沉了下来。两人都没说话，但心里都清楚——陈阿婆，或者陈阿婆身边的人，来过这里。

就在苏棠准备站起来时，她的指尖在石板缝隙深处触到一个硬物。她顺势一抠，掏出一枚铜钱。那铜钱比寻常的薄，边缘被磨得极为圆滑，铜面上刻着一朵六瓣梅花，花心是一个“棠”字。

与她之前在水井边捡到的那枚铜钱一模一样。但这一枚的背面，多了一道新的划痕——一个“非”字，笔画歪歪扭扭，像急着写完的。

非，是否定，也是背离。

苏棠握紧那枚铜钱，听到巷口的风吹过来，带着一丝桂花蜜的甜味。而更远处，传来一声极轻的叹息，像是从还债堂的方向飘过来的。她没回头，却知道顾淮安也听到了。

两人并肩走出窄巷，天色将暗未暗，临水巷里的糖水铺子亮起了灯。而苏棠心里那根弦绷得越来越紧——外婆说“账已清了”，可眼前的账，似乎永远也清不完。

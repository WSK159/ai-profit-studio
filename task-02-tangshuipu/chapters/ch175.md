# 第175章 归来

顾淮安的手电光扫过耳房屋顶，尘土在光线里浮游，像某种迟来的告白。

“你看这里。”他把光束定在灶台背面一块凸起的青砖上，“砖缝里的灰是新的。”

苏棠快步走过去，指尖触到那块砖的边缘，轻轻一抠——砖块果然松动。她屏住呼吸将它抽出来，砖洞深处，一卷牛皮纸用麻绳扎得严严实实。她轻轻拉出来，解开绳子，展开。

是一张铺面契书。

“民国三十七年，临水巷七号，棠记糖水铺……”她的手指在契书末尾的签名上停住，“立契人不是外婆，是周敬德的父亲，周怀山。”

顾淮安皱眉：“周家把铺子卖给外婆的？”

“不是卖。”苏棠翻过契书背面，有一行褪色的墨字，笔迹与外婆手稿如出一辙——“周家祖业，托付青棠，若周氏后人归来，以归魂锅为凭，铺归原主。”

“归魂锅……”苏棠猛然抬头看向灶台上那口锈迹斑斑的铁锅，“周家赔了外婆一口锅，外婆赔了周家一辈子。”

顾淮安沉默片刻：“也就是说——这口锅，一直存放在本该属于周家的铺子里，而周家后人以为你还不知情？”

“周明远他知道。”苏棠攥紧契书，“他知道这铺子本姓周，才拼了命想夺回去。”

她走回灶台，指尖划过铁锅边缘斑驳的锈迹。以前只觉这是一口普通的老锅，现在再看，锅沿内侧隐约有一圈细纹——像某种印记被岁月磨去了棱角，却依然固执地留在原处。她的手指突然卡在锅底一圈凸痕上，那不是锈，是刻痕，和井底外婆刻字的纹路如出一辙。

“锅底有夹层。”顾淮安轻声道。

苏棠蹲下身，用钥匙尖顺着刻痕的轨迹轻轻划动，一声极轻的“咔嗒”，锅底松动了。她屏息揭开那层铁皮，里面压着一张泛黄的纸，叠成了极小的方块。她展开——

是一张药方，母亲的名字她认得，是外婆的笔迹。可上面的内容，每一味药材她都见过，却组成了她从未听过的一道配方：姜、奶、梅、蜜、艾……最末一行写着：归魂，需以隔年霜后梅瓣为引，佐以唐氏姜汁撞之，趁热饮尽，魂魄自归。

“她不是在配药。”苏棠声音发颤，“她是在配——姜撞奶。”

顾淮安的目光落在那行字上，缓缓道：“归魂方第三味……原来根本不是药引。是外婆告诉你，这碗姜撞奶，就是归魂汤。”

一阵风从窗棂缝隙灌进来，铁锅发出低沉的嗡鸣。

苏棠把那页纸小心地收进怀里，又把契书卷好，站起身：“走。明天拍卖会之前，我去一趟档案馆。”

“你去做什么？”

“查周怀山当年所有的铺面过户记录。”她转头看向门外夜色中沉静的临水巷，“如果棠记本属周家——那周明远要夺的，从来就不是铺子，是他的根。而他费尽心机攻打了一辈子的地方——”

她微微一停：“或许他也不知道，外婆早就留了一手，准备把铺子还给他。”

“那你呢？”

苏棠望着手里的契书，笑了笑：“我外婆守了一辈子的东西，不是一间铺面。是一碗等人喝懂的糖水。”

她踏出席间，巷口的风带着初秋桂花的甜意，拍卖会在几个小时后开场。而她怀里，那张药方与那份契书，像一个跨越了七十年的答案，终于等到了它该被打开的那一天。

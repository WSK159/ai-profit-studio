# 第353章 拆招牌的人

棠记门口已经围着不少人。地上一片狼藉，水管被挖断的裂口喷出混浊的水柱，漫过青石板路的缝隙，把门前几盆石榴花冲得东倒西歪。两个工人模样的人正站在架子上，手里的撬棍已经插进“棠记”那块木匾的一角。

“住手！”苏棠挤进人群，声音发沉。她抬头看向那两个人，是生面孔，穿的是糖记统一的黑色工服，袖口绣着金色“糖”字。

一个戴安全帽的男人从一旁踱出来，手里拿着拆迁二期批文复印件，在苏棠面前晃了晃：“苏老板是吧？别为难我们打工的。二期批文下来了，这一片都在征收范围里。你要是有什么意见，去找街道办，找规划局。我们只负责干活。”

“你们负责干活之前，有没有人负责先让水管关掉？”顾淮安从后面走上来，站到苏棠身侧，目光扫过那根断管，“这是居民用水主管，挖断了整条巷子都得停水。”

戴安全帽的愣了一下，显然没料到有人说这个。他啧了一声：“那是施工队的事，我们是拆招牌的。”

“施工队也是你们糖记的。”顾淮安语气平静，“管道权属单位过来之前，我建议你先让人把水阀关了。不然整个临水巷的住户都出来看，你这场拆招牌的戏怕是唱不下去。”

人群里已经有老街坊掏出手机在拍。戴安全帽的脸色变了变，朝那两人挥挥手：“先关阀。”

水管的事暂时稳住了。苏棠却没松气。她盯着那块“棠记”木匾——那是外婆年轻时挂上去的，木头已经发黑发亮，被风风雨雨养出了一层温润的包浆。现在撬棍已经从一角插进去，楔出一道歪斜的裂缝，像一道划在她脸上的口子。

“拆下来的这块匾，你们打算放到哪儿去？”苏棠的声音不高不低，“糖记拆别人的招牌，是要统一销毁，展示，还是卖废品？”

戴安全帽的打量她：“你什么意思？”

“我外婆的招牌，上面有字。‘棠记’两个字是当年巷口的老秀才写的，有落款、有年月。”苏棠说，“这是民国的木刻匾，有文物价值。你们拆得，我告得。”

那男人笑了：“苏老板，我听说了，你是个甜品师，不是律师。”

“她不是律师，我是。”人群里忽然挤进一个女人，剪着利落的短发，夹着公文包，大步走到苏棠身边，递上名片，“姜兰芝，大成律师事务所。苏小姐的代理人。棠记的房屋产权、营业执照、历史沿革材料我们都在整理。在公示期内，任何人为破坏业主合法财产的行为，走的就是破坏财物。”

苏棠愣了一下。她认得姜兰芝——这女人是外婆生前的邻居，在巷尾住了十几年，听说在做律师，但一直不声不响的，没想到这时候会冒出来。

戴安全帽的看看苏棠，又看看姜兰芝，手里的批文复印件被他捏得发皱。他掏出手机打了一个电话，低声说了几句，挂断后脸色不怎么好看：“行，今天先不动。但批文就在这儿，明天我们再来，你们最好有个说法。”

他带着人撤了。几个工人把那根撬棍从匾上拔下来，木匾发出“嘎”的一声闷响，歪斜地挂在原位，像一颗被打落了一半的牙齿。

人群渐渐散了。苏棠站在门口，伸手拨了一下那块匾，用指尖轻轻抚过“棠记”二字的笔画，那些凹下去的纹路里嵌着几十年的灰尘和油烟味。

“姜姐。”她转向姜兰芝，“你怎么知道我这儿会出事？”

姜兰芝从包里抽出一张折皱的纸：“你外婆生前找过我，说她要是走了，让我有个机会就照应你一下。”她顿了顿，“她当时还给我留了一个东西，说等招牌被人拆的时候再给你。”

苏棠接过来，是一张薄薄的纸，折成方胜形，打开来，上面只有一句话，用外婆圆润的字体写着：

**“匾后面有东西，记住，不要当着外人的面取。”**

苏棠的心跳快了一拍。她不动声色地看了顾淮安一眼，后者也微微蹙眉。外婆说的“匾后面”，是那块木匾的背面？

顾淮安抬头看那块匾——挂得不高，他一伸手就能够到。但他没有立即动作，只是对苏棠轻声说：“等天黑。”

暮色沉下来，巷子里的灯一盏一盏亮起。被挖断的水管已经修好了，青石板上还积着一层薄薄的水，映出昏黄的灯光。苏棠搬了梯子靠在门口，顾淮安爬上两步，将木匾从铁钩上取下来。翻过来的那一刻，背面的木板露了出来——上面刻着几行歪歪扭扭的小字，像是用刀尖一笔一划剜进去的：

**“周缙若归，命悬一线。救他的药，在沈家塘。沈家塘的水井里，有一坛酒，九坛水。取酒之法，要问掌灯人。”**

字迹下面是外婆的落款，日期是她搬来临水巷那年——距今三十七年整。

苏棠站在梯子下面，看到那几行字，忽然明白了一件事：那半张药方，外婆手稿里的照片，周缙写给她那封断了半页的信，还有灰衣老头口中的“掌灯人”——所有的线，全都指向同一个方向。

沈家塘。

她抬起眼，远处巷口有一盏煤油灯幽幽地亮着。那是灰衣老头挂在周宅檐下的灯，灯罩上蒙着蓝布，在夜风里轻轻摇晃，像一只沉默的眼睛。

顾淮安从梯子上跳下来，在她身边站定：“沈家塘不是地名。”

苏棠转头看他。

“我祖父留下的那两张纸，我原本没看明白。今天看到这几个字我忽然懂了——”顾淮安的声音低而稳，“沈家塘，是一个人的名字。”

苏棠怔住了。

远处那盏蓝布罩的煤油灯，忽然灭了。

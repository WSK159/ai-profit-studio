# 第158章 青砖之下

苏棠蹲在坑边，指尖触着那块刻了“梅香妆台”的青砖边缘，砖缝里嵌着干涸的灰浆，硬得像铁。她抬头看了顾淮安一眼，他正用手机电筒照亮砖面，光柱微微颤抖，不知是因为冷还是因为别的什么。

“撬开吗？”顾长宁蹲在她对面，雨衣上的水珠顺着帽檐滴进坑底，砸出一声极轻的啪嗒。

苏棠没急着答，从坑底捡起一片碎瓦，顺着砖缝刮了几下，灰浆簌簌落下。青砖比四周的土壁要更新，像是后来砌进去的，砖面平整，边角几乎没有磨损，和坑壁那些饱经风霜的老砖截然不同。她记得外婆以前说过，金水桥酒家做的是“江湖菜”，灶台底下砌暗格是常事，防的是战乱年月的兵匪。

“撬。”她说。

顾淮安收了手机，从工具箱里翻出一柄扁口螺丝刀，递给苏棠。她没有接，反而往旁边退了半步，示意他来。他微微怔了一下，也没推辞，蹲下身把螺丝刀插进砖缝，手腕一沉，砖角松动，碎石粒滚落的声音在狭窄的空间里被无限放大。

砖被整个撬起，底下是一方油纸包，方方正正，比手掌略大，用麻绳十字捆扎，油纸上洇出一片深褐色的水渍。苏棠的心猛地收紧了——这油纸的包法，跟外婆手稿夹层里那些照片的裹法一模一样。

她伸手去拿，指尖触到油纸的一瞬，旁边顾淮安忽然按住她的手腕：“等一下。”

苏棠抬头，他正盯着油纸侧边露出来的一角纸页，里面夹着一张黑白照片样式的东西。他慢慢松开手，声音很轻：“你认识那个人吗？”

苏棠将油纸包整个取出来，绷开麻绳，掀开油纸。里面是一张四寸黑白照片，边角卷曲，画面里是一面旧式梳妆台，台上搁着一碗糖水，碗沿上凝着糖霜。照片背面有人用铅笔写了一行字，字迹娟秀：

“梅香妆台，第三格。”

苏棠反反复复念了几遍，目光落回照片里的糖水碗上。那碗糖水，颜色浅黄，表面浮着细密的姜末——分明是一碗姜撞奶。

“是外婆的字。”苏棠的声音发涩，“这面梳妆台，是她老人家的嫁妆。”

顾长宁凑过来看了看，摇了摇头：“我从没见过这面妆台。”

顾淮安却像想起了什么，转身看向坑壁上方那条贯穿老宅墙体的裂缝：“糖水铺的阁楼上，我去拿东西时见过一面旧镜子，木质背板，边角雕着玉兰。”他顿了一下，“当时没在意，现在想起来，那道梁上隔板里还塞着一卷黄纸。”

苏棠猛地站起来，膝盖撞在坑沿上，疼得她倒吸一口冷气，可她没有停，蹬着泥土就往老宅外面跑去。雨不知什么时候停了，天边有一线灰白的光透下来，落在糖水铺破败的招牌上。

她推开阁楼的木门，灰尘扑面而来。那面旧镜子还在角落，背板上的玉兰花纹已经模糊，可刀法苍劲有力，与婚书落款处的徽记别无二致。镜子和墙之间有道极窄的缝隙，她伸进两个指尖，碰到一卷纸，硬挺挺的，裹着红绸。

她慢慢抽出来，红绸褪色到近乎白色，里面掉出一张对折的宣纸。展开，是一道菜谱。

“梅香妆台——取梅子腌渍七日，以山楂为底，蜜渍金橘走肺经，陈皮入脾经。此味甜中带苦，非失意人不知其味。”

底下一行小字，落笔比上面要深：

“长明哥，你要找的东西不在这张桌上，在人心底。你信不信，我们做糖水的人，从来都是一碗换一碗，不欠债的。”

苏棠盯着那行字，眼眶忽然发酸。这是外婆的语气，她太熟悉了——说理的时候看着温柔，字底下全是骨头。

顾淮安和顾长宁跟着上了阁楼，见她手里的宣纸，两人都安静下来。顾长宁别过头，用力揉了一把眼睛：“我哥找了一辈子的东西……在这儿。”

苏棠把宣纸折好，贴胸放着。她低头看那面镜子，镜面蒙了灰，擦开一角，里头映出她年轻的脸。她忽然想起外婆说过的一句话：妆台是人一生的镜子，站久了，能看到自己的来路。

她打算把镜子搬开，看看后面那面墙是不是也别有洞天，手伸到镜框边时，她愣住了——

镜框缝隙里还夹着一张小纸条，比指甲盖大不了多少，字迹是另一种，笔画凌厉：

“棠记最险的那一碗，你还没端出来。”

苏棠攥住那张纸条，手指发凉。最险的那一碗，是什么？

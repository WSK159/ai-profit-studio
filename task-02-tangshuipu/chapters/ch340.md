# 第340章 地窖回字

灰布衫老头陈守敬的话像一块石头砸进水里，巷口的风忽然变得黏稠起来。

苏棠攥着手中那块有裂痕的玉佩，指尖微微发凉。两块玉佩合在一处，严丝合缝，裂纹恰好彼此咬合，仿佛原本就是一体的。她抬头看向周明礼，这个自认“上月挖开地窖坛子又埋回”的年轻人，此刻站在巷口的老槐树下，脸色平静得像一潭死水。

“你祖母是周绣。”苏棠的声音不自觉地发紧，“杜慎行的母亲。”

周明礼点了点头，目光落在两块玉佩上：“我祖母一辈子没有提过这件事，直到临终前三天，才把我叫到床前，把这东西交给我。”他顿了一顿，“她说，她对不起沈桂芝，也对不起自己的儿子。但族约压下来的时候，她只是一个刚过门的媳妇，不敢违逆。”

“族约？”顾淮安站在苏棠身侧，目光沉静，“什么族约能让一对有情人被拆散？”

周明礼沉默了一会儿，从怀里摸出一张泛黄的纸页，边缘已经脆裂。他展开来，上面是工整的小楷，写的是“杜氏宗规”第三十七条：“凡杜氏子孙，不得与操持贱业者通婚，违者除族，永不入谱。”

苏棠看清“操持贱业”四个字时，胸口像被什么狠狠扎了一下。外婆年轻时是名动一方的大厨，在那个年代，女人掌勺做饭卖钱，在有些人家眼里确实算“贱业”。

“所以杜慎行的母亲——周绣，为了保住儿子的族籍，亲手拆了他的婚事。”苏棠声音有些哑，“她让杜慎行入蜀，去跟苏青梧定亲？”

周明礼点头，又摇头：“确切地说，族里给她两个选择：要么杜慎行按族约娶苏青梧，要么他被除族，从此跟杜家再无关系。我祖母选了前者。她以为这样是对儿子好，可她不知道——”他的声音忽然压低了，“她不知道杜慎行根本不可能娶苏青梧。”

“为什么？”顾淮安问。

周明礼的目光扫过巷口，落在陈守敬脸上：“因为杜慎行答应过沈桂芝，等他安顿好家里的事，就回来娶她。他宁肯被除族，也不要那虚无的族籍。”

陈守敬慢慢点了点头，灰布衫在风里轻轻抖动：“我知道。我兄长陈守真留下的信里写过——杜慎行临行前说：我这一趟入蜀，不是去娶亲，是去退亲。”

这句话像一块石头扔进湖心，苏棠只觉得满脑子轰鸣。杜慎行宁可退亲也要回来找外婆，那外婆收到的那封说他已在蜀中成家的信，又是谁写的？

“信是周承先补的字。”她忽然记起陈守敬先前的话，“周承先是周明远的祖父。”

陈守敬看着她，眼神复杂：“我兄长说，那封信写得蹊跷。杜慎行明明跟苏青梧退了亲，可苏青梧收到的信上却说他已然成婚——一个说退，一个说成，中间一定有人动了手脚。”

周明礼忽然开口：“我查过周家的账册。周承先年轻时在永和药行做过三年的账房，正是杜慎行入蜀那年。他补字的本事，是在药行里学的——那些药方上的字被水洇了，就得有人照着原样补全。”

苏棠的心猛地一跳。她想起外婆手稿里那张被撕掉一半的纸页，上面的字迹在边缘处模糊不清，仿佛被人刻意抹掉了什么。她原以为那只是旧纸泛黄褪色，现在看来——

“所以周承先补的不是药方，”顾淮安的声音低缓，“是杜慎行寄回来的那封信。他把‘退亲’补成了‘成婚’。”

巷口的空气仿佛冻结了。苏棠握着玉佩的手又收紧了三分，掌心的汗湿透了玉面。

柴奇站在几步开外，一直在搓手。他终于忍不住插嘴：“苏老板，陈阿婆让我转告你一句话，她说——”他咽了口唾沫，“她说你外婆最后一次见杜慎行，约在棠记地窖。地窖墙上有个‘回’字刻痕，就是你外婆刻的。她在那里等了一整夜，灯油都烧尽了，人没来。”

苏棠的呼吸猛地滞住。

“地窖里的‘回’字刻痕，”她说，“是外婆刻的？”

柴奇点头：“陈阿婆说，那是你外婆年轻时跟杜慎行约定的暗号——‘回’就是‘回来’。她在地窖里刻下那个字，是告诉杜慎行，她在这儿等他。可他没来。”

“因为他根本没有收到那个约。”顾淮安忽然说，目光转向周明礼，“杜慎行入蜀退亲之后，在哪里等着回来？他是不是也写了一封信约沈桂芝见面，但那封信也被截了？”

周明礼沉默了很久，然后把玉佩翻了过来。玉面背面有一行极细的刻字，苏棠凑近去看，是整齐的小字：“七月廿七，棠记地窖，灯灭为限。”

“这块玉佩是两块的，”周明礼说，“我祖母说，当年杜慎行把刻字的半块托顾月桂转交沈桂芝，另一块留给自己。可顾月桂按约定把玉佩交到了沈桂芝手里，也把信送到了——”

他顿住，目光与苏棠碰上。

“但顾月桂送信那日，遇上了周承先。他拦下她，说要看看信的内容，然后说杜慎行改了主意，让顾月桂不用送那封信了。”

苏棠的指尖开始发颤。顾月桂——顾淮安的外婆。那是把信截下来的人。

“顾淮安。”她转头看他。

顾淮安面色微白，但眼神没有躲闪：“我知道。我外婆去年离世之前，亲口告诉我这件事。她说她是被人骗了——周承先告诉她，沈桂芝已经答应了别人的婚约，杜慎行那封信不必送去。”他的声音有一瞬的涩，“她信了。后来知道真相的时候，杜慎行已经……死在船难里。”

苏棠闭了闭眼。那条河上的一夜风浪，把两个年轻人分开。一个在山壁刻下“回”字等到灯灭，一个在船头握着信以为被辜负。而真正的罪魁，躲在暗处补了一个字、拦了一封信，让所有误会比河更深。

“那个‘回’字，”她睁开眼睛，声音清晰，“我在地窖里见过。外婆刻那一笔的时候，大概已经等了很久了。”

陈守敬忽然开口：“小苏老板，你外婆做的最后一碗姜撞奶，你还记得法子吗？”

苏棠不知道他为什么忽然问这个，但还是点了点头：“记得。外婆手稿最后一页，就是方子。”

陈守敬笑了，灰布衫的老头子笑起来时眼角全是皱纹：“那就再熬一碗。等你想明白那碗奶里为什么搁了两钱陈皮的时候——杜慎行就该回来了。”

风从巷口灌进来，吹得老槐树沙沙作响。苏棠站在树影里，握着那块刻字的玉佩，忽然觉得，外婆等了六十年的答案，好像就藏在那碗奶里。

# 第582章 铁皮盒的两把钥匙

雨已经小了些，但琴巷口一号楼后的地洞口仍然湿滑泥泞。苏棠蹲在洞口，手里捧着那只锈迹斑斑的铁皮饼干盒，指尖微微发颤。盒子上的漆皮剥落了大半，露出底下暗红色的铁锈，像一层干涸的血。

“你早就知道这里有东西？”苏棠抬头看向顾淮安。

顾淮安撑伞站在她身侧，雨水顺着伞骨滴落，砸在青石板上溅起细碎的水花。他没有直接回答，目光落在她手里的铁皮盒上，沉默片刻才开口：“陈阿婆让我每年三月初二来琴巷口看一次，说是有个约定。”

“约定？”

“我小时候病得厉害，陈阿婆带我来找过一位老中医，住在琴巷口二号。老中医说我这病要养，给了我一副药方，让我每年三月初二来琴巷口转一圈，说是‘接接地气，换换运气’。”顾淮安的声音低而平，像在陈述别人的事，“小时候不懂，大了才觉得奇怪——哪有药方是让人四处走路的。”

苏棠的指腹抚过铁皮盒的边沿，那里有一道细小的划痕，像是被人用指甲反复抠过。她试着掀开盒盖，却纹丝不动。

“锁死了？”顾淮安走近两步。

苏棠把盒子翻过来，底部有一圈凸起的纹路，像是某种图案，但被锈蚀得模糊不清。她皱了皱眉：“不是锁，是盒盖和盒身之间被什么东西焊住了——不，不对，是封腊。”她凑近闻了闻，一股陈旧的蜂蜡气味。

“能打开吗？”

苏棠从口袋里摸出一把折叠刀——是她回临水巷后习惯随身带着的，开铺子拆纸箱用的。刀尖沿着盒盖边缘小心翼翼地剔了半圈，蜡屑簌簌落下，露出下面一圈泛黄的铜质卡扣。她正要用力撬，忽然听见身后传来脚步声。

不是一个人的。

苏棠和顾淮安同时转头。雨幕中，周明远撑着黑伞快步走来，身后跟着两个穿深色西装的年轻人，手里各提着一只半人高的工具箱。周明远在离他们四五步远的地方停下，雨水顺着伞沿淌成一条线。

他把手里的东西往前一递——也是一只铁皮饼干盒，样式和苏棠手里这只几乎一模一样，只是盒面上贴着一张泛黄的纸条，毛笔字写得端端正正：“桂秋亲启”。

苏棠的心猛地一缩。桂秋——沈桂秋，外婆的本名。

“苏小姐，顾医生。”周明远的声调客气，但眼睛盯着苏棠手里的盒子，眼里闪过一丝复杂的光，“我猜你今天会来。没想到你手脚比我想象中更快。”

苏棠没动，也没有把盒子藏起来，只是把那只铁皮盒抱得更紧了：“周总，你手里那只盒子，从哪来的？”

“我父亲留下的。”周明远顿了顿，“他去世前半年，反复提起琴巷口一号院后有东西要取。我那时候年轻，没当回事。去年整理遗物，翻出这只盒子，才想起父亲的话。”

“所以你一直在等？”

“等一个能打开盒子的人。”周明远说，“我试过很多办法——找人撬开、加热、泡药水，都没用。后来请了个老锁匠看，他说这盒子是双扣套锁，需要两把钥匙同时转动才能开。”

两把钥匙。

苏棠目光不自觉又落到自己手里那只铁皮盒上，盒底的凸起纹路，确实隐约像是两个互相咬合的圆环。

“苏小姐。”周明远跨前半步，雨水打湿了他的裤脚，“你手里那只盒子和我的是一只一对，是当年你外公和我父亲各执一只。我父亲晚年神志不清，嘴里常常念叨‘对不起桂秋’——那话不是对生意伙伴说的，是对一位故人说的。你外婆的事，我查过，但查到的都是断的。你不是想知道你外婆为什么隐姓埋名吗？不把盒子打开，你永远不知道全部。”

顾淮安往前走了半步，挡在苏棠身侧，声音没抬，但带着一股不容置疑的稳：“周总，你带人深夜来这，不像是来谈合作的。”

周明远身后那两个年轻男人的手已经从工具箱提手上滑开，像是随时能掏出什么的姿态。周明远回头看了他们一眼，那两人又把动作收住了。

“顾医生，你多虑了。”周明远说，“我就带了两把手电筒和一个高压水枪，等着冲洗盒缝里的淤蜡。你们要是信不过我，工具给你们用，你们自己开。”

苏棠盯着周明远的眼睛——那里面没有狡黠，倒有一种疲惫的诚恳，像是困在某个谜题里太久的玩家终于遇见了同样被困的对手。她把盒子举高了些，借着远处的路灯光看了看盒底的纹路，又看了看周明远手上那只。

两只盒子的底部，纹路一模一样。

“周总，你父亲留下的那只盒子里，有配的钥匙吗？”

周明远摇头：“没有。盒子是空壳，里面什么也没有，就是一个容器。我父亲的意思大概是——钥匙不在盒子里，钥匙在桂秋那边。”

苏棠的心忽然一沉。她想到了什么。外婆的手稿——那本被反复翻看、夹层里藏过照片和票据的老旧食谱——在最深一页的背面，她见过一个圆形的印记，当时还以为是外婆随手画的圈圈。如果用那个印记来对这只铁皮盒底部的纹路……

“顾淮安。”苏棠把铁皮盒塞进他手里，转身就要往外跑，“回铺子！我外婆的手稿里有一个图案，和这个盒底的纹路一模一样！”

风雨从巷口扑进来，打在她脸上，凉得她在奔跑中忍不住打了个寒战。身后传来周明远的声音：“苏小姐，等等——你外婆的手稿里真有个图案？”

苏棠没有回头。

她跑出琴巷口，奔进窄巷，雨水砸在青石板上溅起白茫茫的水雾。巷尾的路灯在风雨中闪烁了一下，把她的影子拉得很长。

她猛然顿住脚步。前方拐角处，一顶黑伞横在路中央，伞下站着一个矮小的身影——佝偻着背，手里拄着一根竹拐杖，杖头上系着一根细细的红绳。

“苏丫头。”那人抬了头，声音沙哑，像是风灌进了喉咙，“跑这么急，是要去拿什么？”

是陈阿婆。

# 第248章 一碗沉烟糖的来处

苏棠坐在棠记的柜台后面，手指尖还残留着杳城泥土的气息。她面前摆着一只青花瓷碗，碗底沉着半勺浅琥珀色的糖浆——这是顾淮安送来时，碗里剩下的底子。她伸出食指，蘸了一点，搁在舌尖。

甜。极淡的甜，像风穿过竹林时带来的那种凉意，然后才是沉，沉到喉咙深处，像一块石头落进深潭，咕咚一声，涟漪散开，再无声息。这味道和她在杳城陶坛里尝过的那一口一模一样。

她翻出那本旧账册，一页页往下看。毛笔小楷，工整秀丽，是外婆的字。账册记的不只是收支，每页末尾还有一行备注，比如“今日阿婆来，教我用陈皮三片，去腥”——又比如“周家送信物一枚，铜质，刻莲花纹，置于樟木匣中”。苏棠翻到三月十七日那一页，手指停了。

“周家送信物一枚，铜质，刻莲花纹，置于樟木匣中。”

她合上账册，抬头望向窗外。暮色浓稠，巷口的路灯亮起来，晕开一团暖黄的光。门口传来脚步声，她以为是顾淮安，抬头却见陈阿婆挟着一阵花香进来，怀里抱着一把晚香玉。

“小棠啊，还没走？”

“阿婆，您来得正好。”苏棠起身，泡了壶茶，“您上回说，外婆有个小师妹，姓周——您记得她叫什么名字吗？”

陈阿婆放下花，在竹椅上坐下，想了想：“叫……周婉容。长得白净，瘦瘦的，话不多。你外婆那会儿管她叫小容。后来有一年，小容跟一个外乡人走了，就再没回来过。你外婆那阵子蔫了好些天，我也没敢多问。”

“后来呢？一点消息都没有？”

陈阿婆摇头，又像是想起来什么，顿了顿：“倒是有一次，大概是……三十多年前了，有人来巷子里打听过你外婆，说是一个姓周的年轻人，问棠记还有没有开。我当时在门口浇花，跟他说开着呢。他没进门，站了一会儿就走了。后来我也忘了问。”

苏棠把茶杯放下，心口那根弦绷得更紧。周明远。他姓周。他的糖记，主打的招牌产品是果糖和奶茶，从不做传统糖水，却在铺子门口放了一碗沉烟糖——味道和杳城陶坛里一模一样。他要的东西，恐怕从来不是一间铺子这么简单。

送走陈阿婆，苏棠关好门窗，重新打开那封外婆留下的信。信纸已经泛黄，折痕处几乎要断裂。外婆在信末写的话她早已背下来——“棠儿，糖水这东西，三分靠方子，七分靠心。我这一生没亏欠过谁，只有一个人，我说过要等他，却没等到。你替我记着，若有一日，有人能在我的姜撞奶里喝出姜的辣和奶的甜之外的那一层味道，那便是他回来了。你让他来见我。”

苏棠愣愣地看着最后那行字。等一个人。外婆说她在等一个人——可她的信里写的是顾远山。她等到的是顾淮安的爷爷，还是等到了别的人？

她拿起手机，翻到顾淮安的对话框，打了一行字，又删掉。再打，又删。最后发了一句：“那碗沉烟糖，是谁送的？你问过了吗？”

消息发出去，对面没有立刻回。她盯着屏幕等了好一会儿，放下手机去关窗。窗户合上的那一瞬，巷口的路灯下似乎有个人影，顿了顿，像是朝这边看了一眼，然后拐进了巷尾的阴影里。

手机亮了。顾淮安回了一条：“联防那边说监控没拍清楚，是个穿灰外套的中年男人，放下碗就走了。门口的摄像头被贴了块黑胶布。”

苏棠握着手机的手紧了紧。有人不想让她看到那张脸。

# 第10章 老配方之争：巷口新开的连锁店

糖记的招牌挂出来那天，临水巷的清晨比往常热闹了三分。红色的遮阳棚，崭新锃亮的玻璃门，门口摆着两排花篮，音响循环播放着“正宗港式糖水，开业大酬宾”。

苏棠站在自家铺子的门槛上，隔着三十来米的青石板路，看着对面人进人出。开业头三天，糖记卖六块钱一碗的杨枝甘露，比市面价便宜一半。巷子里的老太太们拎着保温杯，排着队去尝鲜。

陈阿婆坐在自家花摊前，一边剪枝叶一边说：“六块钱一碗，亏本卖，图什么？图你门口排长队，把你的老客户都拉过去。”

苏棠没接话。她转身回了铺子，从柜子底下翻出外婆的旧手稿——那本封皮发黄、边角卷曲的牛皮纸本子。她之前的注意力都在夹层里的照片和票据上，手稿正文只潦草翻过几页，写的都是每日糖水的配方和火候记录。但昨晚重看时，她发现目录页码对不上。手稿有一百多页，但目录只列到第九十八页，页码从九十八直接跳到了一百零三。

中间那五页，被撕掉了。

留下来的是第103页。纸上只有一行字，墨迹褪得几乎看不清，勉强能辨认出“桂花乌梅”四个字，下面有一道横线，横线下写着：“此方为棠记祖传，望后人谨守。”

苏棠盯着那行字看了很久。外婆的字迹她认得，但这行字写得比平日里更加工整，一笔一划，像是郑重其事地立规矩。可“桂花乌梅”这道糖水，外婆从没做过，手稿里也没出现过完整配方。那四页被撕掉的，很可能就是配方本身。

门铃响了。一个中年妇女端着一只碗走进来：“老板娘，你尝尝这个，糖记新出的酸梅汤，我看你家的菜单上没有酸梅汤，想问问你会不会做。”

苏棠接过碗，低头闻了闻。烟熏乌梅的味道很足，洛神花放得也多，颜色红得近乎发黑，喝一口，酸味直冲舌根，甜味绵长，层次确实不错。她正要开口夸两句，忽然眉头一皱——不对，这味道里有一层她熟悉的东西，极淡的青草气，像是甘草，又像是某种更清冽的植物。

她翻出手稿，找到第103页，把纸凑近碗口。那种气味隐约对上了。

“桂花乌梅”四个字忽然变得刺眼。苏棠把碗还给那妇人，脸上不动声色：“做得挺好的，我手艺比不上人家。”

妇人走后，苏棠关上门，重新翻那段被撕过页的痕迹。撕得很齐整，像是用刀片裁的，不是急急撕掉的。外婆藏起的不只一张照片和半张票据，还有一页配方。而糖记的酸梅汤里，居然有用到相同配料的痕迹。

傍晚时分，顾淮安来了。他没穿白大褂，换了件灰蓝色的外套，手里拎着一个纸袋，放在柜台上：“卫生中心有位老同事，家里是开调料行的。他看了糖记的开业传单，说了一句奇怪的话——”

他打开纸袋，里面是几颗干的乌梅。“他说，糖记的酸梅汤，用的乌梅是‘南山上品’，这种乌梅产量极少，三十年前几乎全是卖给临水巷一家铺子的。”

苏棠的瞳孔微微一缩。

“那家铺子就是棠记。”顾淮安说，“你外婆当年也做酸梅汤，配方里有桂花，是南山上品乌梅搭配桂花提香的用法。后来这配方失传了，市面上再没人这么做过。”

苏棠咬住下唇。“那糖记怎么会有？”

顾淮安沉默了两秒。“你觉不觉得，那个来发传单的经理，有点眼熟？”

苏棠一怔，猛地想起那人临走前那意味深长的目光。那张藏在老照片里被撕掉的脸，似乎就在这种目光里活了过来——不是本人，而是极其相似的轮廓。

她抓起手稿，翻到夹层，把那半张票据抽出来。票据是上世纪六十年代的，抬头印着“方氏甜品坊”，款项内容写的是“原料采购费”。票据的日期，和外婆照片里那场争议是同一年。

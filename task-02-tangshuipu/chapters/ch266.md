# 第266章 石阶尽头

石阶往下走了不知道多少级，手机信号早就没了，顾淮安举着老式手电筒，光束在潮湿的砖壁上照出一圈圈青苔的痕迹。空气里有一股说不清的味道，像药材，又像陈年的糖浆，混在一起，甜得发闷。

苏棠走在他身后，指尖扶着墙壁，砖面上每一块都刻着浅浅的纹路，仔细摸才能感觉到，像某种花——是桂花。

“这地方……”她低声说，“有人住过。”

顾淮安没回头，但脚步放慢了半拍：“砖缝里的灰是细的，不是自然堆积的。常年有人走动才会这样。”

又往下走了十几级，手电筒的光忽然开阔起来。石阶尽头是一间地下石室，四四方方，大约二十来步见方，角落里摆着一张老旧的木桌，桌上放着一盏煤油灯，灯罩上落了灰，但灯芯还是完好的。

苏棠走过去，摸了摸桌面。桌面上刻着一行字，笔画很深，像是用刀尖硬生生划出来的——

“棠记药糖，第捌代传人沈月娘，庚子年立。”

苏棠的指尖一顿。沈月娘。这是外婆的名字。

“庚子年……”顾淮安站在她旁边，看了眼说，“那应该是很久以前的事了。你外婆在这个地底下做过糖？”

苏棠没说话，她把手电筒往桌下照去。桌子底下有一口铁箱，箱口锁着，锁头锈得几乎看不出原样，但锁孔旁边挂着一枚小小的铜钥匙，用红绳系着，红绳已经褪成灰白色，可打的结还是完好的——那是外婆才会打的结，她在苏棠小时候教过她。

苏棠蹲下去，捏起那枚钥匙，手有点抖。钥匙插进锁孔，微微用力，锈迹簌簌掉落，锁“咔”的一声开了。

铁箱里是一层油纸，油纸掀开，底下整齐地码着一叠纸，纸页泛黄，边角卷曲，但上面的字迹是外婆的，一笔一画写得很认真。最上面一张纸，写着四个字——

“沉烟糖方。”

苏棠愣了一下，拿起那张纸，就着手电筒的光往下看。方子写得极其详细，每一步配比、火候、时间都标注得清清楚楚，甚至每一味药的炮制方法都有注释。而在方子的右下角，外婆用朱笔画了一个小圆圈，圈里写着一个字：“成”。

“这是成方。”苏棠说，声音有点哑——她自己都没察觉。

顾淮安接过去看了一眼，眉头微微皱起来：“配比里有一味‘天香子’，后来市面上几乎绝迹了。这味药性偏燥，必须配合……等等。”

他忽然不说话了，目光定在纸页的下半段。那里另外用蓝笔写了几行字，字迹比上面要新，笔力也浅一些。

“棠丫头：若你看到这方子，说明你已经走到地下来了。外婆这辈子只做成过两次沉烟糖，一次是为了你外公，一次是为了一个没见过面的孩子。第二次的方子我没留在手稿里，只留在这里。你若要试，先记住一句话——沉烟糖最怕急火，就像人心最怕急事。”

蓝笔字写到这儿就断了。顾淮安翻到下一张纸，那是一张已经发脆的旧信纸，叠成四方，折痕很深，打开时纸边掉了一小块下来，苏棠连忙接住。

信的抬头是“绣姐姐”。苏棠的心猛地沉了一下——周绣。外婆那封遗信里提到的，那个搬走失联的女子。

信很短，她看了两遍才彻底读懂。

“绣姐姐：方子我已制成，沉烟糖的苦味压下去了，入口是桂花的清甜，后调会泛回一丝药香，不算坏事。孩子要是受了寒咳，每日一小勺，温水化开服下，三日后当有大效。东西我放在老地方，你若得空，来取就是。你知我知，不必声张。”

没有落款，没有日期。但苏棠知道，这封信大概从没送到——外婆说周绣搬走了，全家一夜消失，连告别都没来得及。

她捧着那张薄薄的纸，掌心的汗把纸角洇出一小块水痕。她忽然有些明白外婆为什么把这方子藏在这里，而不是放在手稿里——这不是普通的糖方，这是一笔没能还上的债。

“苏棠。”顾淮安的声音从旁边传来，带着一线异样的紧绷，“你看这个。”

她抬起头，顺着他的目光望向石室的角落。那儿摆着一个老式的木架，架子上放着一只粗陶罐，罐口用蜡封着，蜡面上落了一层灰。走近了才看见，蜡封上按着一个指印，指印旁边刻着一个字——“顾”。

苏棠转头看他。顾淮安的神情有些不太好形容，他看着那个“顾”字，喉结动了一下，很久才开口：“我爷爷的名字，就叫顾承。”

陶罐在手里比想象中轻，摇了摇，里面没有声音，像空的。苏棠没敢立刻揭蜡，她捧着罐子，回头看了一眼外婆的那封信，又看了一眼石室尽头黑洞洞的通道——那条通道在木架后面，拐了个弯，手电筒照不到底。

“等下再走那条路，”顾淮安似乎看出她的念头，“先打开看看。”

她揭蜡的时候指尖微微发抖，蜡壳裂开一条缝，里面没有糖，没有药材，只有一卷折得极细的纸，卷成一个筒，塞在罐底。展开来，是一张手绘的路线图，笔迹和外婆手稿里的如出一辙。图上标注着一条从临水巷延伸出去的线路，弯弯绕绕穿过半座城，终点画着一间小房子，房子旁边写着四个字——

“你阿公来过。”

苏棠僵在原地。外婆的字迹，还字迹泼洒得有些乱，能看出写这行字时，她并不平静。

通道深处忽然传来一声响动，像什么东西落在地上，又像一声极轻的咳嗽。苏棠和顾淮安同时望向那条黑洞洞的通道，手电筒的光照过去，只见拐角处有什么东西一闪而过，像一角衣摆，又像一片影子。

“有人。”顾淮安低声说，往前迈了一步。

苏棠把那张地图叠好，塞进口袋里，深吸一口气：“走。”

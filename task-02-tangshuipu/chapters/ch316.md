# 第316章 账簿里的字

铁皮箱盖掀开的那一刻，一股陈年纸墨的气味混着铁锈味扑面而来。苏棠蹲在豁口处，手指轻轻抚过靛蓝布面账簿的封皮，“棠记玉棠屋·甲辰年往来账”几个字用墨笔写就，笔锋清瘦，透着旧式账房先生的规矩。

她翻开第一页，入目是一行行端正的小楷，每笔每划都像是用尺子量过似的齐整。日期、品名、数量、银钱——从糖料到器具，从柴火到工钱，事无巨细，逐一记着。

“甲辰年……”顾淮安站在她身侧，目光落在那年份上，“往前推六十年。”

“那会儿外婆还没出生呢。”苏棠低声道，指腹在纸页上轻轻摩挲，仿佛这样便能触到那年代的余温。她翻过几页，忽然停住——某一页的品名栏里写着“玉棠花蜜”，数量一栏却标注“无价”，后面缀着一行小字：“凡取用者，必留一花为凭。”

和她手中那本手稿末句一模一样。

“这玉棠屋到底做的是什么生意？”柴奇探过头来，粗眉拧着，“糖水铺子记账还能记出‘无价’来？”

苏棠没答话，又向后翻了几页。账簿的记载并不连续，每隔几页便有大段空白，像是写账的人特意留出的余地。她翻到将近末尾时，夹层里滑出一页泛黄的纸片，上面只有一句话：

“戊申年腊月初八，杜先生来取旧账。以玉棠花三朵为凭。自此，玉棠屋不复开张。”

是杜先生。

陈守真信笺里那个姓氏，外婆手稿里讳莫如深的人，此刻端端正正印在这页薄纸上，无声无息，却像一记闷雷砸在苏棠心头。

“阿婆。”陈阿婆的声音忽然从身后传来，带着几分急切，“你们看这箱子底下——”

苏棠回头，见陈阿婆蹲在另一只铁皮箱前，手指颤抖地指着箱底。她走过去，借着天光一看，箱底刻着一朵玉棠花，花瓣线条粗粝，像是用刀尖仓促划出来的。花蕊中央，嵌着一枚小小的铜片，铜片表面锈迹斑驳，却隐约可见一个“杜”字。

“这箱子是姓杜的人留的？”柴奇蹲下来，试图将铜片抠出来，手刚碰到，陈阿婆猛地按住他手腕。

“别动。”她声音低哑，目光直直盯着那枚铜片，像是在辨认一个久别多年的人，“这是杜家的记号……他给棠记的东西，从来都是刻着自家名号的。”

“陈阿婆认识这个姓杜的？”顾淮安问。

陈阿婆没有立即回答。她沉默许久，手指轻轻抚过箱边的刻痕，才开口：“我小时候见过他一面。那年我十一岁，来巷子里找我娘，路过棠记门口，见一个穿长衫的男人站在门槛外头，手里擎着一枝玉棠花。阿棠姐——就是棠记当时的东家——站在门里头，接过那枝花，把门关上了。”

“后来呢？”

“后来我再没见过那人。”陈阿婆收回手，目光落在箱底的铜片上，声音轻得像叹息，“可我娘说，那天之后，棠记的糖水里，多了一味谁都不知道的底料。”

苏棠心里“咯噔”一声。外婆的姜撞奶她是喝过的，那股说不清道不明的回甘，她一直以为是姜汁和糖的比例调得好，如今听陈阿婆的话音——莫非那糖水铺百年不传的底料，和这位杜先生有关？

她正要追问，巷尾老邱家裁缝铺方向忽然传来车轮碾过石板的声响。几人循声望去，一辆黑色轿车正缓缓停在裁缝铺门口。

车门打开，下来一个穿藏青西装的中年男人，身形笔挺，头发梳得一丝不苟。苏棠只觉那侧脸有几分眼熟，一时又想不起在哪儿见过。男人走到裁缝铺门前，抬手敲了三下门，没人应，便在门口站定了，像在等人。

老邱家裁缝铺，门挂红绸，内有刻痕——顾淮安的目光暗了暗。他认出那人了。

“苏棠。”他声音压得极低，“那人姓周。”

苏棠猛地抬眼。姓周。

周明远的人？

“他怎么会来这里？”柴奇眉头拧得更紧，“拆迁的事不是已经平了吗？”

顾淮安没有回答，目光紧盯着那道身影。那人敲门的手势很稳，一下一下，像是在等一个早就约好的回应。可裁缝铺的门始终没开。片刻后，他从口袋里摸出一张纸，折成细条，从门缝底端塞了进去，然后转身上车，扬长而去。

苏棠收回目光，低头看向手中那页薄纸——戊申年腊月初八，杜先生来取旧账。

甲辰年。戊申年。中间只隔了四年。

那人塞进裁缝铺的纸，又是给谁的？

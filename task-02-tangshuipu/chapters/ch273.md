# 第273章 白纸盒

那天傍晚，临水巷的糖水铺难得没有亮灯。苏棠坐在小院里的竹椅上，手里捏着一只简易的塑封袋——里面是半张从石室地上捡起来的纸角，约莫拇指盖大小，边角烧焦，纸面上残留着半个字，笔画收得很紧，像是一个人专心致志写下的时候被人打断。

陈阿婆端着两碗绿豆汤走进来，“看到你灯没亮，猜你又在发呆。”她把碗搁在石桌上，目光落在那半张纸角上，顿了一下，“这纸哪里来的？”

苏棠抬起头，看着陈阿婆花白的头发和眼角的细纹，犹豫了一下，还是把下午的事说了一遍，略去了顾淮安爷爷那封信的具体内容，但提到周沉这个名字。

陈阿婆手里捣着蒲扇的手忽然停住了。

“你说他叫周沉？”她的声音比平时低了半个调。

苏棠站起来：“您认识他？”

陈阿婆没立刻答话，缓缓坐下来，绿豆汤的热气在暮色里袅袅升起来。过了好一会儿，她才说：“周家的孩子。你外婆要是活着，看到他这个岁数，也该放心了。”

“您知道他母亲周绣去哪了？”

陈阿婆摇摇头，扇子又慢慢摇起来，扇出的风带着绿豆的香甜。“周绣那年离开临水巷的时候，才二十二岁。你外婆帮她翻墙走的，天亮前的事，我就站在巷口看着。她走之前来过我这里一趟，也没说去哪里，就留下一个纸盒子，托我交给……”她顿了顿，“托我交给该拿的人。”

苏棠呼吸一滞：“那个纸盒子？”

“我后来给了你外婆。她认得那个盒子，说里面的东西她保管比谁都合适。”

苏棠心里的弦轻轻绷了一下。外婆保管着周绣托陈阿婆转交的白纸盒，而周沉手里又有一个白纸盒——他说是外婆寄给他母亲的。

两个白纸盒，一来一往。

“陈阿婆，”苏棠蹲下来，平视着老人，“那个白纸盒里面，你看到过是什么吗？”

陈阿婆的扇子停了一瞬间，然后继续摇。风把檐角垂下来的绿萝叶子吹得轻轻摆动。

“我不识字。但纸盒面上有几个字，你外婆教过我，”她眯起眼回忆，“‘相见欢’。”

苏棠僵住了。相见欢——那是外婆手稿第一页写下的一句词牌名，她一直以为是外婆随手写的引子，没想到会是一个纸盒的名字。

“后来中秋节，你外婆做了一碗糖水，跟我说那就是相见欢的方子调出来的糖浆，只是缺了最后一样东西。”陈阿婆的声音低下去，“她说，等东西凑齐了，就能把这碗糖水做出来了。”

苏棠慢慢站起来，心跳快得发慌。她想起外婆手稿里那句话：“方子不在纸上，在味里。”——那半张票据，石室里的铜锅和糖渣，白纸盒，周沉的出现……所有零碎的线索，像一根糖丝，正在慢慢拉长、拧紧。

她转身跑进屋里，打开储物柜最底层那个樟木盒子，外婆留下的白纸盒还在，盒盖边缘的纸角却缺了一小块——和她在石室地上捡到的那半张角对得上。

那个纸盒被人动过。

苏棠攥着纸盒呆了几秒，猛地拨通了顾淮安的电话。响了很久才接通，顾淮安的声音有些哑，带着一点杂音，像在路上：“我刚从卫生院出来。你——”他顿了顿，“我爷爷的旧相册里翻到一张照片，背面写着三个字。”

“什么字？”

“周沉。周石沉。”顾淮安语气里有一种奇怪的平静，“我爷爷写过一本笔记，里面提到他替人照顾过一个孩子，那孩子在临水巷住过三年。那孩子的奶名叫……”电话那头背景音嘈杂，他后半句话被一阵车辆鸣笛声吞没了，但苏棠还是清清楚楚地听见了两个字——

“阿棠。”

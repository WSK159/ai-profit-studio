# 第509章 正堂的地基

那一夜苏棠没睡好。那只青碗被她端进屋里，放在桌上，碗里的水一夜未动，到天明也没有少一滴。她恍惚间觉得自己盯着碗看了很久，又好像只看了几秒就被窗外的鸡鸣拉回了神。

天刚蒙蒙亮，她就下了床。

顾淮安比她更早。她走到后院时，他已经蹲在井口边上，手里拿着一根长长的细铁丝，正探进井壁的缝隙里试探着什么。听到脚步声，他没抬头：“这口井的井壁是双层的。”

苏棠蹲到他身边：“什么意思？”

“你看这里，”他指着井壁下方一处破损的砖缝，“外层砌的是青砖，里面还有一层薄薄的灰浆层，隔水用的。我昨晚回去翻了翻临水巷的旧城建档案——民国年间，临水巷所有的水井都是单层的，唯独井泉家的两口井，是双层井壁。”

“他们家为什么要做双层？”

顾淮安收回铁丝，站起来：“档案上没有写。但双层井壁有一个用途——如果夹层里填了密封材料，井水就能和外面的地下水彻底隔绝。换句话说，这口井里的水，自成一个体系。”

苏棠脑中那道闪电又劈了一下。她猛地想起那只碗里的水，那种甜得发陈的味道，那种封存了几十年的质地——如果井水与外界隔绝，那水里溶解的东西就永远不会被冲走。三十二年来，井底的水银还在，井壁的浮雕还在，那水里的“味道”也在。

她转身快步往堂屋走。

顾淮安跟上来：“你想到什么了？”

“昨天陈阿婆说，”苏棠一边走一边说，“地下暗渠朝东北方向，通向正堂地基。”她推开堂屋侧门，蹲下身子，手指一寸一寸地摸索着青砖地面，“外婆铺这块地的时候，用的砖和别的屋子不一样。”

她指着一块颜色微微泛青的方砖：“这块砖比旁边的旧得多，根本不是铺地用的。它是墙砖。”

顾淮安也蹲了下来。苏棠试着抠了抠砖缝，纹丝不动。她从口袋里摸出一把折叠刀——那是她开包装箱用的，平时不离身——沿着砖缝刮了两下，竟刮出了细碎的暗红色粉末。

“是蜡。”顾淮安接过来捻了捻，“封缝用的，混了朱砂。防止水汽往外渗的。”他在粉末里又捻出几粒砂样的东西，凑近了看，“还有碎瓷。”

苏棠心里升起一个微妙的念头。她盯着那块旧墙砖，又看了看堂屋正中那张外婆用来放糖水罐的老案板。案板是整块樟木做的，几十年了，油光发亮。她突然伸手推动案板，案板比她想象得轻——嗒的一声，底下露出一圈略微凹陷的痕迹，正好是一块方砖的大小。

顾淮安帮她一起把案板搬开，露出底下那块青灰色的方砖。苏棠用刀尖撬了两下，砖竟然动了。它松松地嵌在泥土里，像是被人重新放回去过。

她把它掀起来。

下面是一个浅浅的凹坑，坑里放着一只陶罐。陶罐没有盖，罐口被一块油布包着，扎得严严实实。油布上，用墨笔写着一行字，字迹她认得，是外婆手稿里的字：

“井水不犯河水。”

顾淮安帮她一起解开油布，罐口朝下，倒出来三样东西：一张泛黄的照片，一把缠着红线的铜钥匙，以及半页纸——纸页的边缘是撕扯过的痕迹，与外婆手稿夹层里那半张票据的断裂纹路完全一致。

苏棠拿起那张纸，对到光下看了很久，看到最后一行字的时候，她整个人都僵住了。

只听她声音低低地读了出来：“井迟那年不是自己跳的井——是被人放下去找东西的。”她捏纸的手指微微发抖，又念出下一句，“他找到了，但他没上来。”

她抬头看向顾淮安，眼眶红了一圈：“所以井迟不是死——他是替谁死的？”

顾淮安没回答。他拿起那张旧照片。照片已经模糊泛黄，但还能看清：一个瘦小的男孩站在水井前，穿着灰布衫，身后站着一个看不清脸的女人。男孩大约七八岁，唇角有一颗痣——很小，几乎看不见。

他目光一顿，将那照片翻了过来。照片背面写着一行字，用极淡的铅笔字写就：

“井迟，甲午年生，替井家取水。庚子年七月十一日没。”

七月十一。苏棠几乎脱口而出——那正是外婆每年中元节前烧纸的日子。她年年烧，烧了三十二年，烧的不是神佛，也不是故去的丈夫——她烧的，是一个替井家取水、再也没上来的孩子。

门口传来“吱呀”一声轻响。两人同时转头，看到陈阿婆站在那里，手里拿着一把沾着露水的栀子花，脸上是一种苍老到极点的悲凉：“你们都看到了。”她说，“那钥匙，是九曲回廊后头第三间屋子的。我守了它三十二年，该交出来了。”

苏棠握住那把缠着红线的铜钥匙，指尖触到冰冷的铜锈，像是触到了什么极深的、泛着陈甜味的水底——而井底深处，传来一声几乎不可闻的轻响，像是一个孩子在水下笑了一下。

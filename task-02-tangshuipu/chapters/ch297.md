# 第297章 坛口蜡封

糖水铺后屋的灯亮起时，苏棠才发现自己双手在微微发抖。

她将钥匙插进旧铜锁，转动三下才锁开了，推门时门轴发出一声低哑的呻吟，像是被这一夜的潮气泡软了骨头。屋里的陈设和外婆生前并无二致：靠墙的木架子上码着几只大小不一的陶罐、瓷坛，落了一层细密的灰。她目光锁定最上层靠右的那只青花瓷坛——坛身约莫一尺高，瓶口覆着老旧的蜡封，封蜡已经泛出焦褐的颜色，表面还有几道细裂纹，像干涸河床上被晒裂的泥。

顾淮安跟在后面，并没有急着动手，而是先环视了一圈屋子，最后落在墙角一只竹篮里。他走过去，从篮底翻出一柄旧铁钎，钎头被磨得发亮，显然是外婆常用的物件。他把铁钎递给苏棠：“用这个撬蜡，比刀稳。”

苏棠接过来，指尖触到铁钎磨得温润的把柄，上面有一道浅浅的凹痕，正好是拇指扣住的位置。她握住那处凹痕，沿着蜡封边缘轻轻一挑，封蜡裂开一条缝，露出一段深褐色的塞子——不是木塞，而是一段干燥的莲藕，藕孔里塞满了蜡泥，密密实实封了多年。

“外婆用莲藕封坛。”苏棠有些意外，俯身凑近闻了闻，藕香味淡得几乎不剩，倒有一股极浅的甜酿气息从坛口边缘渗出来。她抬头看顾淮安，“是酒？”

顾淮安蹲下来，从随身的背包里取出手电筒，照向坛口内部。光柱打进坛腹深处，映出半坛浅琥珀色的液体，液面上浮着几片发了黑的果干，底下似乎沉着什么东西。苏棠把光往回收了收，看清底部的轮廓——一只圆肚小瓷瓶，白釉，巴掌大小，被埋在那层沉淀物中间。

“是个瓶子。”她说。

顾淮安的目光在坛口和屋里之间来回扫了一圈，最后落在旧木架靠角的暗格里——那里嵌着一只铁钩，钩头裹着已经发黑的棉布。他取下铁钩，递给苏棠：“试试能不能捞。”

苏棠将铁钩沿坛口探入，钩身狭窄，几乎刚好够到那只小瓷瓶的瓶颈。她屏住呼吸，手腕稳稳地转了半圈，钩子卡住瓶沿，轻轻往上提。坛口的窄颈限制着瓶身，她耐着性子转了几个角度，终于将瓷瓶带出——瓶身沾满湿润的褐色沉淀，在灯下泛着一层温润的旧光。

苏棠把瓶子放在桌上，用毛巾仔细擦净表面的附着物。白瓷瓶露出来时，瓶身上隐约刻着一行极细的字。她凑近辨认：“分明另有清秋。”六个字，刻得深浅不一，像是用簪子或者发钗一笔一笔划过，到“秋”字最后一撇时，笔迹明显顿了一下，留下一个微小的凹陷。

“分明另有清秋。”苏棠喃喃念道，觉得这半句话像是裁切过——前面应当还有半句才对。

顾淮安没有接话，他的视线落在瓶子底部——那里贴着一小片已经褪色的红纸，纸上写着一个字，笔画歪斜，稚气十足：“禾。”

禾。贺兰的兰，也是顾长渊口中那个“阿禾”的禾。

苏棠盯着那个字，指尖停在那道笔痕上。忽然想起外婆地窖里那本册子，第十四页的边角写着一行极其隐蔽的小字，当时她以为是注记，没有细看，如今隐隐约约想起来——那行字好像也有一个“禾”字。

“那个瓶子，”苏棠抬头，“里面还有东西。”

瓶口用蜡封得严严实实，但比坛口的蜡薄得多，苏棠用铁钎轻轻一挑便开了。她侧过瓶口，一片老旧的纸卷滑出来，边缘发黄，折痕处已经有些酥脆。她小心展开，纸上是一幅笔法简陋的素描——两个简单的人影并肩站在一座城门楼前，身上穿着宽大的围裙，像是厨人打扮。城楼上依稀画着几面旗，被风吹得扬起来。纸的右下角有一行褪色的钢笔字，写的是：

“贺兰与何深，戊子年秋，北城门。”

何深。苏棠愣住——外婆的夫家姓何，外婆早年本名贺兰，后来又改名“阿禾”。那么何深，应该就是外婆那个从未在她面前提过一句的外公。她一直以为那是某户寻常人家，原来他有名字。贺兰与何深，戊子年秋，北城门。

顾淮安在她身旁蹲下，目光扫过那行字，眉心微微一动。他沉默了一会儿，忽然低声说：“我父亲病房的床头柜里，有一张他年轻时的照片，也是在北城门拍的。门前那对石狮的右耳上，有一道裂痕。”他停顿片刻，“这张画里的城门楼上，你仔细看，右角画的那道线——”

苏棠闻言低头细看，果然，城楼右上角有一条突兀横斜的短笔痕，初看像是涂抹的瑕疵，再看那位置，恰好与石狮右耳所在的方位一致。她后背升起一阵凉意，这半张旧画上的城门，与顾长渊照片中的同一座城门，旧墙残迹，连裂痕都严丝合缝。

“所以，”她的声音有些哑，“外婆年轻时，和我外公——还有顾长渊——都到过同一座城门。”

顾淮安没有回答，他的目光落在画纸右下角的那个日期上：戊子年秋。顾长渊说过，他被逐出林家是二十六年前，那时他二十四岁。而外婆那半页被撕走的手稿上，“正月初九之约”落款的时间是庚辰年冬。两张纸隔着大半个年头，却指向同一段往事。

窗外起了风，巷口的糖水铺幌子被吹得啪嗒作响，像旧话本翻到某一页又落回去。苏棠把那张画纸小心收进封口袋，和那张“贺兰入门”的旧纸片放在一起。

屋外传来一声低低的口哨，是陈阿婆的声音——她在巷口对暗号，意思是有人来了。

苏棠和顾淮安对视一眼，默契地将一切归回原位：瓷瓶放回坛中，莲藕塞回坛口，蜡封重新压平，铁钎放回竹篮。两人刚退回前厅，门被从外推开一条缝，陈阿婆探进半个头，压低声音说：

“巷子口停了一辆车，车里坐着周明远的人。他没进来，就坐在车上往这看了好几趟。”

夜色里那辆车静静停在路灯下，车窗摇下一条缝，看不清里面坐着谁，只有一点烟头的红光明明灭灭。

苏棠捏着口袋里那两张纸，指节泛白。

那个坐着的人，隔着整条巷子的夜色，不知在等什么——但她隐约觉得，他在等的东西，就藏在那只青花瓷坛深处，藏在那个被“禾”字封住的瓶子里，也藏在外婆那坛始终没有揭开过的秘密里。

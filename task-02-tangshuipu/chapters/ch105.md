# 第105章 一碗杏仁糊的定心丸

雨一直到傍晚才歇。两人回到临水巷时，巷道里积着浅浅的水洼，倒映着头顶灰白的云。陈阿婆蹲在自家门口收拾被雨淋湿的茉莉花，见他们回来，隔着半条巷子就喊：“棠丫头，你铺子门口有个人等你半天了！”

苏棠心里一紧，三步并作两步跑回棠记门口。台阶上蹲着一个穿灰色旧中山装的老头，驼背，手里拄着一根木拐杖，旁边的编织袋里鼓鼓囊囊装着什么。他听见脚步声抬起头，浑浊的眼睛眯了眯：“你是马秀莲的外孙女？”

“……是。”苏棠心头一跳，“您是？”

“我姓周，周海生。”老头颤巍巍站起身，从编织袋里掏出一个布包，递给苏棠，“这是你外婆当年存在我这里的，说等她老了再给后人。”

顾淮安已经走到近前，目光落在老头脸上，忽然一顿：“您是周明远的什么人？”

老头的手抖了一下，半晌才说：“周明远是我侄子。我来这里，他不知道。”

苏棠接过布包，拆开一看，里面是一本蓝布封面的旧账册，扉页上写着“棠记收支总录，一九五二年”。她翻开几页，都是外婆年轻时一笔笔工整的账目，直到翻到某一年，她忽然看见一条夹在账目里的便笺——

“老周今日来，说他儿子病愈，送来二十斤细白糖。我留着半包，等那人回来，给他煮一碗最甜的那口。”

苏棠抬头看向周海生：“老人家，这上面写的‘那人’，您认识吗？”

周海生沉默了很久，巷子里的风卷着雨后的潮气，把他的白发吹得乱糟糟的。他终于开口：“你外婆等的那个人，姓容，叫容盛。”他顿了顿，“她等了他四十三年。”

苏棠心口像被温热的糖水烫了一下，又疼又涩：“容盛……他在哪儿？”

“死了。”周海生说到这里，声音带了灰，“八五年就死了。死在马家老屋那口井里。”

顾淮安脸色一白，声音沉下去：“井里？您是说，井里捞出过尸体？”

周海生摇头：“没有捞出。他是自己爬进去的，再无出来。那年秋天雨季涨水，暗渠满了，人才知道他失踪了。后来你外婆跪在井边三天三夜，滴水未进，最后是我把她背回去的。”

苏棠捏着账册的指尖泛白，眼前浮现出外婆卧房里那只上了锁的老木箱——她搬进铺子那天就想撬开，却一直没能找到钥匙。现在她忽然明白了外婆那句“等那人回来”，不是等活人，是等一个交代。

周海生说完这些，从口袋里摸出一个烟盒大的铁皮盒，放在苏棠手心：“这是容盛留下的，你外婆让我保管。”

苏棠打开，里面是一张折得四四方方的票据，泛黄发脆，右边沿整整齐齐撕掉了半张。苏棠脑中轰的一声——外婆手稿夹层里那半张票据，边缘的撕裂纹路与它严丝合缝。

“多谢您。”她嗓音发哑。

周海生摆摆手，转身拄着拐杖慢慢走出巷口。陈阿婆远远看着他离去的背影，低声嘟囔了一句：“怎么又一个老的跑回来了。”

苏棠没听见这句话。她蹲在铺子门口，用铁皮盒里的半张票据对着手稿夹层里那半张拼合。票据抬头上印着一行字：北城仁济药房合并凭证，一九五三年。

票据背面，有人用钢笔写了一行小字，墨迹已褪了大半，但还依稀可辨——“以我身，换她活。”

顾淮安蹲下来，看了那行字很久，才说：“他终于还是从井里出来了。”

苏棠抬起头，看见巷口的路灯一盏一盏亮起来，昏黄的光映在青石板的水洼里，像许多年前外婆在铺子里守着的那盏油灯。她深吸一口气，站起来擦了擦眼角：“今晚我熬一碗老方的杏仁糊，你给我打下手。”

顾淮安怔了怔，忽然笑了：“好。”

他走进铺子，苏棠在后头看着他宽厚的背影，心里忽然浮上一个念头——外婆等的那个人是容盛，那顾淮安七岁那年从井里递药渣出来的人，是容盛还是别的什么人？井底那面瓷片墙上的字，究竟是谁写下的？

而她手里那行“以我身，换她活”，又是什么意思——谁的身体？换谁的活？

风从巷口灌进来，吹得门檐下的风铃叮当响。苏棠把两张票据叠好收进围裙口袋，转身进了灶间。灶火亮起来的一刹那，她把所有的怀疑都先按进了锅底，让杏仁的香气把一整条巷子慢慢填满。

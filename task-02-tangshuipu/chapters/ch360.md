# 第360章 灯座下的纹路

煤油灯的光在甬道里微微晃动，青灰色的石门像一块巨大的旧碑，沉默地立在那儿。苏棠盯着门上的刻字，指尖沿着那道笔画缓缓划过——“掌灯人至，方得开门”。

“你说这灯还没点着，”她转过头，看向那个佝偻老人，“可外婆三十七年前把它点着了。她提着灯上来，说你认出了她。”

老人的眼珠浑浊，像泡了太久的陈皮水。他歪着头，嘴角扯出一丝说不清是笑还是苦涩的纹路：“她是点着了，可那是她点的。灯认她，不认灯。”

顾淮安站在苏棠身后半步，手轻轻搭在她肩头。他没说话，只是把煤油灯往石门凑近了些，光亮照在门边的石壁上，那些被岁月磨平的纹路显出隐约的轮廓。

苏棠猛地蹲下身。

石门的右下角，距地面只一掌的高度，刻着一朵花——五瓣，瓣瓣圆润，花心是一点浅坑。她认得这花，外婆手稿里画过无数次，棠记最老的那张招牌上刻的也是它。那是木棉花，糖水铺的百年标记。

可此刻刻在石门上的这朵木棉花，花心里缺了一块。缺口的形状，像极了灯座底部的裂纹。

她回头看向那盏煤油灯。灯座是铜的，年岁久了，釉色沉着，裂纹从底部延伸而上，在灯座的边缘收住，恰好是一道月牙弯。

“灯座裂纹，”顾淮安的声音在甬道里低而清晰，“和这朵花的心，是同一个形状。”

老人静默地看着苏棠俯身对比灯座与石门花纹的动作。他的眼睛在昏暗中像两粒将熄的炭火，忽然亮了一下，又暗下去。

“你叫什么名字？”他突然问。

“苏棠。”

“棠……是棠云秀的棠。”老人的声音轻得像自言自语，“她把名字都传给你了。”

他颤巍巍地转过身，朝石门右侧走了两步，枯瘦的手按在石壁上一块不起眼的凸起处。那凸起像一颗黄豆大小，若不是他主动碰触，苏棠根本不会注意到。老人用力一压，石壁内传来一声闷响，像是某种机关被拨动了。

石门没有开。

但从石门上方落下一层薄灰，灰烬间，一片巴掌大的铜片掉在苏棠脚边。铜片背面锈迹斑斑，正面却被打磨得光亮，映着煤油灯的火光，露出一行细小的字。

苏棠捡起来，凑到灯下看。

字迹是旧式的繁体，刻得极浅，像是怕太深了会伤着什么似的：

“灯亮了，人还在。灯灭了，人便不在了。若你见到这面铜片，说明灯亮过，人也回来过。”

苏棠的手指微微发颤。这是外婆的字。她认得，外婆手稿里每一页都是这样的笔迹，横细竖粗，收笔时总爱带一个小小的勾。

“这是外婆留下的，”她抬头看向老人，“她点完灯下来过，还把这铜片放回了机关里。”

老人没有回答。他望着铜片，眼底那点火光像被风吹了一下，颤了又颤，最终熄下去。

“她把铜片放回去，是因为她知道还会有人来，”顾淮安替他说完了话，“她在等一个人，等她点完灯之后，那个人也走到这扇门面前。”

老人终于开口：“那个人，不一定是人。”

苏棠眉头微皱：“什么意思？”

“掌灯人是谁，灯认谁，只有开了这扇门才知道。你外婆点过灯，可她没能开门。她把铜片放回去，也是把这个位置留给了后来的人。”

他顿了顿，目光落在苏棠手中的铜片上：“你外婆下井前，有人问过她一句话——‘你把灯点着了，可你愿意把灯提进门里去吗？’”

“她怎么回答的？”

老人沉默了很长一段时间。甬道里的风声像从很远的地方漏进来，呜咽着穿过青石缝隙。煤油灯的火焰忽然跳了一下，灯座底部那道月牙裂纹里，透出一缕极淡的白烟。

“她说：愿意。”

老人的声音沙哑得像含了一口砂：“可她提灯上来之后，再也没有回过井。她把这面铜片放回机关里，不是留给你开门的钥匙。她是把门锁死了。”

苏棠攥紧铜片，手心被边缘硌得生疼。

“锁死，为了什么？”

“为了灯不灭。”

老人说完这句话，忽然剧烈地咳嗽起来，整个人佝偻成一团，顾淮安上前扶住他。咳嗽声在甬道里回荡了许久，老人喘息着摆摆手，像是不让他们碰他。

苏棠低头看铜片。背面除了那行字，右下角还有一个小小的凹痕，像是被什么尖锐的东西磕过。她翻转铜片，借着灯光仔细看——那凹痕的底部，残留着一粒暗红色，像干涸的血，又像某种漆料。

顾淮安目光落在那粒暗红上，声音低沉：“是印泥。”

“印泥？”

“摁手印用的那种印泥。有人把指纹留在过这里。”

苏棠把铜片翻过来，正对了灯。光线穿过铜片边缘时，一道极淡的纹路显形——那不是刻痕，是某种液体干透后留下的。淡褐色，顺着铜片边缘蜿蜒成一道弧线，像是有人用手指蘸着什么，顺着铜片边缘画了一道。

老人不知何时缓过气来，眼睛盯着那道淡褐色的弧线，目光忽然变得极亮：“这个是顺着画上去的，不是摁上去的。”

“有什么分别？”

“有。摁上去，是指纹；顺着画上去，是路。”

苏棠怔住。那弧线的走向，从铜片右下角的凹痕起始，绕过一个不规则的缺口，最后收在铜片正上方的一个小孔处。如果把这个小孔对准石门上木棉花花心里的那个缺口——弧线的走向，是不是恰好指认了暗门开启的方向？

她回头再看石门。石门表面不再是平整的青色，她忽然注意到，在煤油灯光照不到的阴影里，石门正中偏左的位置，有一条几乎看不出的细缝，从石门上沿一直垂到地面，像被谁用刀笔划过一道。

苏棠把铜片放进口袋里，抬起头，声音平静却带着不可动摇的坚定：“你说灯认人不认灯。可你刚刚说，外婆把铜片放回去，是把门锁死了。”

老人看着她。

“她把门锁死，钥匙却放在机关里，”苏棠一字一句地说，“她没有锁门。她是在告诉我——灯点完，要顺着路走，不能回头。”

老人沉默良久，最后轻轻地笑了一声，浑浊的眼底泛起点什么东西：“她的孙女，倒比她当年还聪明些。”

他拄着一根看不出材质的杖，缓缓向甬道深处走去，声音被黑暗吞了一半：“明天棠记，带着灯来。开不开得成门，得看那盏灯认不认你。”

苏棠和顾淮安站在石门面前，甬道里只剩下煤油灯“噼啪”的焰跳声。她低头，口袋里那块铜片的轮廓隔着衣料硌着掌心，像外婆遥遥递来的一只手。

那行字又浮上心头：灯亮了，人还在。

可石门背后，到底藏着什么人？

# 第73章 树根之下

推土机的声音断断续续响了一上午，但巷子里的人都知道，拆迁队还没敢动老槐树——那棵树太老了，树枝上挂着红布条，树身直径少说有一米，是临水巷的“招牌树”。

苏棠趁午后人少，拎着一把铁锹出了糖水铺。她猫着腰绕过巷口菜摊，走到老槐树底下。顾淮安已经在树下了，他蹲在树根处，用手慢慢摸索着那棵树的根部。

“小时候听老人说过，老树根底下有东西。”他抬起头，声音压低，“我找了一圈，这块青石板底下有松动的痕迹。”

苏棠蹲下来，看见一块嵌在树根旁的青石板，表面刻着模糊的梅花纹路——和她在药房角落里发现的那些碎瓷片上的纹路如出一辙。

“会不会是外婆埋的？”她问。

“不一定。”顾淮安说着，用铁锹沿着石板边缘往下挖了两尺。泥土松软潮湿，显然近年不断被雨水滋浸过。几锹下去，铁锹碰到了什么，发出“当”的一声闷响。

他放下铁锹，用手拨开泥土——是一个破旧的铁皮盒子，锈迹斑斑，但锁扣尚未锈死，一用力就弹开了。

盒子里用油纸包着三样东西：一张保存完好的黑白照片，照片上是两个年轻女子，一个穿旗袍，气质清冷；一个穿布衫，眉眼温婉。苏棠认出那个穿旗袍的正是年轻时的外婆，而另一个穿布衫的——虽然角度有些侧，但那轮廓，那张脸，分明是她在城东药房角落里见过的那张旧照上，母亲周蓝青年轻时的样子。

“她们认识。”苏棠轻声道，“外婆和周阿姨——她们早就认识。”

顾淮安没有答话，继续翻开盒底，抽出一个已经泛黄的牛皮纸信封。封面上没有字，信封口被人用红蜡封住了，蜡印是一个清晰的五瓣梅花印。

苏棠的手指微微发颤，小心地挑开蜡封，从信封里抽出一张半透明的薄纸——那是一张信笺，字迹娟秀，分明是外婆的手笔：

“蓝青：

若你看到此信，大约是我已不在人世了。

有件事，我瞒了你许多年。当年济世堂那桩事，你爹娘并非出于自愿——他们是被人利用了。那人知晓我研出三瓣梅饮的方子，要我交出秘方，我不肯，便拿你爹娘作要挟。你爹娘为了护我，才在出库单上按了手印，并非他们背叛我。

是我负了他们这么多年。

若你怨恨便怨恨我，莫要迁怒旁人。更莫要寻人。那人的后人如今也在巷中安稳度日，冤冤相报，终是了无休期。

——外婆 梅氏 绝笔”

苏棠读完最后一个字，手已经抖得不成样子。她抬头看顾淮安，发现他也一直在看这封信，目光凝在“那人的后人如今也在巷中安稳度日”这行字上，许久没有移开。

“那人的后人……”苏棠声音有些哑，“会是谁？”

顾淮安缓缓闭了一下眼睛，再睁开时，目光里多了一层什么东西：“你看信封上的蜡印，是五瓣梅。但外婆留在信末的三个字‘梅氏’——她的手印应该是五瓣梅。而她那份转让协议上的手印——”他停了一下，“正是五瓣梅。”

苏棠心头一沉：“所以，那份协议——”

“那份协议上的手印，确实是你外婆的。”顾淮安的声音很轻，但每一个字都清清楚楚，“但她并没有自愿交出方子——她是被人逼的。”

苏棠攥紧了手里的信笺。那些年的冤屈、沉默、隐忍，在这一刻忽然有了答案。外婆不是隐姓埋名——她是在等，等一个机会说出真相。

“那……”她犹豫着开口，“那位‘后人’现在，会不会是周明远？”

顾淮安没有回答。他低头看着树根旁被挖开的泥土，忽然问：“你注意到没有——这片土里，除了这个铁皮盒，还埋着别的东西。”

苏棠顺着他的目光看过去，铁锹翻起的泥块中，有几片碎瓷——白瓷底，青花边，一共三片，拼起来隐约可见半个“周”字。

巷口，推土机的声音忽然停了。

紧接着，一阵发动机的低鸣由远及近——一辆黑色轿车驶入巷口，停在了老槐树不远处。车窗降下，露出周明远那张从容的面孔。

“苏小姐，”他笑得温文尔雅，“这么巧，您在这儿挖什么呢？”

# 第510章 九曲回廊

陈阿婆的手瘦得像干枯的树枝，那把铜钥匙在她掌心里躺了三十年，表面已经磨出了包浆。钥匙齿刃锋利，形制古朴，与井壁浮雕上的纹路如出一辙。

苏棠伸出手，指尖触到钥匙的瞬间，一阵细微的震颤从金属上传过来——那是错觉，还是井底某处传来的回响？

“九曲回廊……在哪儿？”顾淮安问。

陈阿婆垂下眼帘，沉默片刻后说：“你们以为这巷子只有地上这些房子？临水巷的老地基，往下三层，都是通的。九曲回廊是最底下一层，入口在巷尾那棵老槐树底下，要过了子时才能进。”

她顿了顿，“老规矩，走九曲回廊的人，不能带灯，不能出声，不能回头。”

“那怎么看得见？”苏棠皱眉。

“看得见的自然会看见，看不见的，进去了也没用。”陈阿婆叹了口气，把钥匙往苏棠手心里一扣，“三十二年前我就该把这东西还回去。拖到今天，我这把老骨头总算能松口气了。”

苏棠攥紧钥匙，铜齿硌着掌心，一种说不清的重量压在心底。她抬头看向陈阿婆：“您为什么不自己进去？”

陈阿婆笑了笑，眼角的皱纹层层叠叠：“我答应过你外婆，这东西只能交给姓苏的传人。”

子时，老槐树底下。

夜风穿过巷子，卷起一蓬干枯的槐叶。顾淮安握着手电筒站在井盖边，苏棠蹲下身，用钥匙柄沿井盖边缘划了一圈——泥土松动，露出下方一段向下的石阶。石阶很窄，仅容一人侧身通行。砖缝之间塞着干透的苔藓和几枚铜钱，是陈旧得泛黑的嘉庆通宝。

苏棠把钥匙插进锁孔，拧了三圈。井盖无声开启，一股凉气从底下涌上来，带着泥土和朽木的气味，夹杂着一丝极淡的甜。

“按阿婆说的，不带灯。”顾淮安把手电筒放在地上，看向苏棠，“你确定？”

苏棠深吸一口气，踏下第一级石阶。黑暗像水一样漫上来。三步之后，她发现自己的眼睛逐渐适应了黑暗——两侧墙壁上嵌着一种奇异的矿石，泛着极淡的蓝绿色荧光，像夏夜萤火虫的光。

九曲回廊。

两壁石墙蜿蜒向前，每一段折角处都立着一尊浮雕人面，面容沉静，双眼闭阖，唇边微微上挑，像是在做一个漫长的梦。廊道两侧每隔数步便有一扇石门，门上刻着不同纹样，有莲花，有云纹，有鱼鳞，还有一只持碗的手。

苏棠数到第三扇门，门上的纹样正是那只持碗的手。掌心朝上，碗中浮着一滴水珠，线条古朴苍劲。

她抬起铜钥匙，对准门上的锁孔。钥匙刚伸进去，门内忽然传来一阵极轻的水声，像是有什么东西在水中翻了个身。

三人同时屏住呼吸。门缓缓向内开启，露出一间小屋。

屋里没有水，只有一口石砌的水池，池底铺着青砖，砖缝间渗出暗色的水渍。池子正中央，摆着一只陶碗，碗沿磕了一角，碗内残留着一层干涸的白色粉末。

苏棠弯腰端详那只碗，瞳孔猛地一缩。碗底的图案她见过——和外婆手稿夹层里那张照片背面的印章一模一样，是棠记最初的老字号印记。

顾淮安站在她身后，目光却落在墙壁上。墙上凿着一行字，字迹纤细秀丽，是女人的手笔：

“井深九丈，水甜三分。泉眼仍在，人不归来。”

字迹下方刻着一尾鱼，鱼腹处有一个细小圆孔。顾淮安伸手探了进去，指尖碰到一卷东西，抽出来一看，是一张油纸包裹的薄册子。

册子封面上没有字，翻开第一页，画着一个男人蹲在井底，头顶是一束从井口垂落的光。第二页，那男人手里捧着一只碗，碗中盛着水，水里浮着一粒金色的东西。

第三页，男人抬头望向井口，嘴边沾着水渍，却在笑。

册子最后一页，画着一扇门，门上挂着一把缠红线的铜锁。

苏棠的呼吸骤然停住。那把锁，和她手里的钥匙在形状上完全吻合。

“有人把东西留在这里，等了三十二年。”顾淮安的声音有些低，“就是为了让人看到这组画。”

苏棠握着钥匙，觉得指尖微微发烫。她听见身后那口石池底部，忽然传来一声极轻的叩击——像是有人从更深处敲了敲石板。

三下。不多不少，和外婆生前每晚用汤匙碗沿敲三下的习惯一模一样。

她猛地回头，石池底部的青砖缝隙里，正慢慢渗出一线清水。水的颜色是琥珀色的，带着姜和奶交融后的暖甜气味。

九曲回廊深处，不知哪一扇门后，传来一声几不可闻的轻笑。

# 第264章 地下有风

石阶向下延伸了整整三层楼的高度，空气从干燥变潮，从潮变凉，最后凉意像水一样浸透了衣料。苏棠数了数，一共一百零七级。她每走一步，手电光就在前方的黑暗里削出一片薄薄的亮，像刀片划过皮肉。

顾淮安走在她后面，一只手虚虚搭在她肩膀后三寸的位置，没碰到，但始终悬着。他们谁都没说话。石阶尽头是一扇锈蚀的铁门，门把手上有新断的锁——锁断口泛着银白色的金属光泽，是最近六七天内才被弄断的。

“有人来过。”苏棠说。

顾淮安蹲下去，指腹在断口上碾了一下：“钳子剪的，手法很专业，不是撬锁，是直接剪断。”

苏棠的喉头紧了紧。她能闻到一股细微的甜味从门缝里渗出来，像熬了三天三夜的糖浆，浓稠得能粘住呼吸。这不是糖水铺的味道，更不是药糖的味道，是第三种——她没在任何一本外婆手稿里见过的焦甜。

推开门的那一瞬间，风从门内吹出来，顶着她手背的汗毛倒竖起来。地下空间比她想象的要大得多，至少有三间铺面那么大，顶极高，隐约能看到穹顶上嵌着一排排铁钩子，像屠宰场挂肉的钩子，又像挂糖坯的架子。

“制糖坊。”顾淮安站在她身后，声音很轻，却在这片空旷里荡出回响。

苏棠把光扫过去。一圈操作台靠墙排开，石台上嵌着五口大铁锅，锅壁上凝着一层褐黑色的垢，结了厚厚一层，像被烧焦的琥珀。墙角的木架上摆着几百个瓦罐，罐口封着黄泥，泥面上用毛笔写着一串串编号——

“甲七、甲九、乙三、丙十二……”苏棠凑近了看，她认得这是一种记账格式。外婆手稿里出现过一模一样的编号格式，是棠记私家配料的排序法。

但外婆手稿里最多只写到甲五。这里的编号排到了“壬”字头。

“你过来看。”顾淮安的声音变了调。她转身，看见他站在最里面的角落里，手电光照着一面墙。墙上钉着一排木架，架子上放着一只只白瓷罐。罐子不大，巴掌高，密封得很好。每一只罐子肚子上都贴着一方红纸，纸上墨字写的是——

**周绣 收**

苏棠是愣住的。

“周绣——”她闻到自己的声音有回响，像有人把它也挂在了钩子上，“外婆的信里说，她给周绣的儿子做了沉烟糖方，但是周绣全家搬走，没来得及交付。所以这批罐子……是从那个年代留到现在的？”

顾淮安没说话。他伸手拿起最边上的一只罐子，拧开密封盖。罐子里没有药糖，也没有糖浆——是一张折成方块的桑皮纸，纸上写着什么，字迹已经泛黄，但墨色还清晰。纸头一行字写着：“棠氏沉烟，为幼子试方。忌东行过岭，忌寅时落泪，忌第三锅断火。”

顾淮安的指尖顿在纸上的最后一列字上，缓缓抬起来。

苏棠看见他的表情变了。他认得这列字。他也认得“忌寅时落泪”这几个字是什么意思——他见过同样的字，在他母亲的遗物里。

“这纸上说，”顾淮安的声音低得几乎听不见，“沉烟糖，能续一口气。”他停了一下，把那张桑皮纸翻过来，纸背面还有一行更小更淡的字，像是外婆匆忙写下的：“若服者命中有劫，一丸可暂缓三日。”

地下空间里的风停了。取而代之的是一种更冷的东西，从顾淮安指缝间那页桑皮纸里渗出来，一点点爬上苏棠的脊背。她正要开口问周绣儿子的身世究竟和他有什么关系，墙角最深处传来一声极轻的“咔”，像某个年代已久的木架终于撑不住重量，又像有人在那头按下了什么机关。

她回过头。手电光照到那面墙的底部，露出半截焦黑的木梯，直直探向下层更深处的黑暗。梯口挂着一块歪斜的旧木牌，上面的字被锈迹吃掉了大半，只剩下一个“禁”字。

而梯口的尘土上，印着一行崭新的鞋印。

# 第503章 第五代传人

灯笼的光晃了一下，沈家第五代的眼神落在那只黑漆匣子敞开的盖子上，看到那根银簪时，目光微微一滞，又移开了。

“我姓沈，叫沈望。”他开口，“纸灯笼沿巷子走了一夜，找到你们的时候天快亮了。家祖母知道有人动了她埋的碗，才让我下来看看——没想到，等到了该来的人。”

老人站在井口边，看见沈望的脸，沉默了一会儿，然后轻轻点了点头。

“沈家那丫头，长这么大了。”老人说，“你奶奶，可好？”

沈望顿了顿：“奶奶上月走的，九十三岁。走之前，让我把这把钥匙交给‘来开井的人’。”

他说着，把手中的黄铜钥匙递过来。苏棠没有接，她只是看着沈望，她忽然明白那碗桂花圆子是谁煮的了。

“那碗圆子，是你包的？”苏棠问。

沈望点了点头：“奶奶教我包了一天一夜，她说，苏家的姑娘第一次下井，吃了沈家的圆子，才算认识。”

苏棠看了那碗沿的青瓷缺口一眼，又看了看沈望的手。他缺了无名指，但食指和中指上有深深的老茧——那是常年捏面团磨出来的痕迹。她忽然想起外婆还在世的时候，每年冬天都会包一次桂花圆子，皮薄馅大，三道褶子收口，和整条临水巷的包法都不一样。

外婆说那是“一位老朋友教的手艺，一辈子都忘不掉”。

现在，她知道了那位老朋友的姓。

“你奶奶，和我外婆——”苏棠话没说完，沈望就接了过去。

“她们是拜过把子的姐妹。”沈望说，“我奶奶姓容，原名容桂。但沈家是外婆家的姓，奶奶是入赘到沈家的，所以改了宗姓，做了井泉记的第四代传人。”

他说到这里，顿了一下，看了一眼那册硬壳账簿：“奶奶生前总说，她欠苏阿婆一句话。苏阿婆想听的，她到死都没说出口。”

苏棠一怔。“什么话？”

沈望沉默了很久，纸灯笼的光在他脸上晃出一层明暗，然后他说：“当年带走那样东西的，不是沈家，是容家的人。我奶奶——容桂，她是替她表兄背了半辈子黑锅。”

石室里的空气像被人抽走了一层。老人听了这话，嘴角动了动，却没出声。

苏棠低头看了一眼账簿最后一页的那行字：“沈云启带走一件东西……”

“你外婆记的没错。”沈望的声音很轻，“但带走东西的人，署名是沈云启，印章是井泉记的——那枚章，当年在容家人手里。”

他抬起那只缺了手指的左手，在灯笼光下晃了晃：“我奶奶的祖母，就是用这根手指头起过誓，说容家的人，这辈子不沾井泉记的方子。她替表兄背了那个名，也断了一根手指——后来她嫁进沈家，才算把这条咒续了过去。”

苏棠觉得自己听懂了，又没有完全听懂。

“所以，到底是什么东西被带走了？”她问，“外婆记了一辈子账，沈家等了三代人——到底是张方子，还是别的什么？”

沈望没答，而是把手伸进怀里，掏出一块包着蓝布的物件。他一层层打开蓝布，露出来的是一只青瓷圆碗——碗不大，碗底烧着一朵桂花，花心处有一道细细的裂纹，像一条冰裂纹从碗心延伸到碗沿。

他看着那只碗，说了四个字：“井泉青，核心。”

顾淮安的眉头轻轻皱了一下。他口袋里的那片青瓷碎片还在，他把碎片掏出来，和沈望手中的青瓷碗放在一起——碎片一贴近碗沿，自然而然地嵌了进去，严丝合缝，正是“井泉青”第七片。

“苏阿婆带走了这只碗的第七片碎片。”沈望看着那片合拢的瓷，“沈家一直守着一个规矩——井泉青的碗，凑齐七片，才能烧出真正的青花。而那只碗的碎片，散了三代人，如今——”他看了一眼苏棠手中的铜钥匙和黑漆匣子，“或许凑齐了。”

苏棠握着钥匙，指节发白。

她想起外婆手稿中间夹层的那半张票据，指向的是一家早已注销的药房；想起顾家地窖水缸底的“井泉家”三个字；想起外婆临终前握着她的手，只说了半句话：“小棠，糖水铺的井，你替阿婆——看着。”

原来外婆说的井，从来不是巷口那口枯井。

“那口井里，”苏棠望向石室中央的古井，声音轻得几乎只剩气声，“装着什么？”

沈望没有回答，而是走到井沿边，蹲下身，把手中的青瓷碗轻轻放在井台的青石板上，然后从怀里掏出一根极细的银丝线，一头系在碗沿的缺口处，另一头缓缓垂入井中。

银丝线入水的瞬间，苏棠听见井底传来一声极悠长的回响——像有什么东西从水底深处应了一声。

老人忽然开口，声音变得极低：“井泉青的碗底，印着临水巷的地图。当年容家带走的是碗，沈家守的是井。你外婆带走的，是井泉青的根谱。”

她看向苏棠，目光浑浊却有神：“你外婆不是不想还沈家的账，她是在等沈家人回来接井。你来了，沈家人也来了——这碗根谱，你该烧了它，还是替沈家续下去？”

老人说完，像是消耗了极大的心力，慢慢靠回石壁边，合上了眼睛。

石室里安静得只剩银丝轻轻颤动的声响。水面泛开一圈涟漪，那只青瓷碗在井台上缓缓转动了一个角度——碗底的桂花，正好朝向苏棠站着的位置。

沈望抬头看她，没有说话，但他的眼神里带着一种等了整整三代人才等到今天开口的沉默。

苏棠低头看着那只青瓷碗，碗底的桂花在煤油灯的光里微微泛亮。

她忽然想起，外婆手稿最后一页那行字，她已经见过。

那行字是：“井泉记的根谱，烧了，沉香养水；不烧，留青碗续脉。小棠，你替阿婆做决定。”

但她当时以为，那是一句话里最轻的嘱咐。

现在她才知道，那是外婆交给她最重的一把钥匙。

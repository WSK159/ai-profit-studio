# 第152章 灰夹克

脚步声在门外停驻的那一刻，苏棠的心跳漏了一拍。她手里的处方笺还泛着旧纸的暗黄，“长明，你若平安，来棠记找我”几个字像是隔着二十多年的光阴，轻轻硌着她的指尖。

顾淮安已经直起身，目光越过她，落向店门。黄昏的日光从玻璃门缝里挤进来，在青砖地上拉出一道细长的影子。那影子动了一下，随即是一声轻轻的咳嗽，苍老而疲倦。

“棠记还开着吗？”

声音沙哑，带着某种小心翼翼的试探。苏棠把处方笺迅速收进围裙口袋里，深吸一口气，走过去拉开了门。

门外的老人大约七十来岁，身形瘦削，穿一件洗得发白的灰夹克，袖口磨出毛边。他站在门槛外半步远的地方，像是在犹豫该不该踏进来。他的脸很陌生，可苏棠盯着他看了一瞬，莫名觉得那双眼睛里有东西在动——像深冬的河面上，冰层底下有什么在游。

“您……喝糖水吗？”她问。

老人没答话，目光越过她的肩，落在铺子里那棵老樟木柜上。他看了很久，久到苏棠几乎要再问一遍，他才慢慢点了点头，说：“有姜撞奶吗？”

苏棠一愣。姜撞奶是外婆的招牌，临水巷的老街坊都知道，可一个陌生老人进来第一句话就点这道，总有些不对劲。她侧身让他进来，指了靠窗的位子：“您坐，马上好。”

顾淮安已经从柜台后走出来，不动声色地站在灶台边上，目光淡淡地扫过老人的鞋——那双布鞋的鞋底沾着泥，是刚下过雨的路面才有的那种湿泥。凤鸣镇昨夜刚下过雨，临水巷的巷口到今天上午还汪着水洼。

老人坐下后，把灰夹克的扣子解开一颗，又系上，反复了两次。他像是不知道该把手放哪儿，最后从口袋里摸出一个旧的铝饭盒，放在桌上，轻轻推了推，又收回来。

苏棠背对着他做姜撞奶，牛奶在小锅里微微冒泡，老姜的汁水已经铺在碗底。她听见身后的人忽然开口，声音轻得像自言自语：“这铺子，当年有个姑娘，做的姜撞奶特别好喝。”

她的手顿了顿，没有回头。

“那姑娘，短头发，笑起来左边有个酒窝。”老人又说，像是并不需要谁接话，“她在等一个人。等了很久。”

顾淮安看了苏棠一眼，她端着碗走过去，把姜撞奶放在老人面前，白瓷碗里的奶面微微颤动，像一块搁在光里的玉。老人低头看着那碗糖水，却半晌没动。

“您认识我外婆？”苏棠在他对面坐下，声音平静，手却在桌下攥紧了围裙的边。

老人没有回答。他拿起勺子，舀了一勺放进嘴里，停了一会儿，然后慢慢咽下去。他放下勺子的时候，手指在微微发抖。

“一样的。”他说，“跟她做的一模一样。”

他从夹克内侧口袋里摸出一样东西，放在桌上——是一张照片，边角已经卷了，被透明胶带反复粘过。照片上是一个短发女人，站在糖水铺门口，围着白围裙，对着镜头笑，左边脸上一枚浅浅的酒窝。

苏棠的喉咙一下子紧了。那是外婆，看起来不过二十五六岁，比她在手稿里见过的任何一张照片都年轻。

“我姓周。”老人说，“周明远的那个周。”

顾淮安在她身后微微倾身，像是一只猎豹听到动静。苏棠没有动，只是盯着那张照片，声音极轻：“周肇是您什么人？”

老人把勺子搁回碗沿，像是用尽了全身的力气，才说出那两个字：“是我哥。”

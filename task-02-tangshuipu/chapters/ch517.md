# 第517章 泉眼之下

楼梯很窄，仅容一人侧身而过，石阶上覆着一层细密的青苔，但中间被踩出一条干净的通道，形状像一只脚的轮廓，比苏棠的脚小了一号。

陈阿婆跟在她身后，看到那道脚印，声音颤了：“这是你外婆的脚形。”

苏棠没应声。她打着手电筒，光线一晃一晃地往下移动，楼梯拐了三个弯，每一道弯都有供人歇脚的石台，石台边沿全都磨得光滑，显然被坐过无数次。在最后一个石台上，刻着一行小字，笔迹潦草：

“阿棠满月，井水甜了。”

苏棠的鼻尖一酸——外婆给喂她的米汤，用的居然是井水。

楼梯尽头是一道铁门，门环是旧式的黄铜，但黄铜上刻着一朵棠花，花瓣中间嵌着一个小孔——大小、形状，恰好和那粒龙眼玉一样。

苏棠站在门前，忽然明白了一件事：这粒玉从头到尾不是信物，是钥匙。

“你外婆——”陈阿婆的声音有些发哑，“当年填井，不是‘丢了玉’，是‘把门锁了’。”

“可玉粒被我从池底取出来了。”苏棠的手搭在门环上，掌心的老茧正好抵在棠花的花蕊上，“我开门。”

“你确定？”

问话的是顾淮安。他站在楼梯口，没有下来，光线把他一半的脸照成暖色，另一半落进阴影里，“底下有你知道一半的水银，有连外婆都要封起来的秘密，这条通道她老人家走了几十年，却从没告诉过任何人。”

“正因为她走了几十年，所以这条路不是封路，是铺路。”苏棠看着那行字：阿棠满月，井水甜了。

顾淮安没有再劝，他从口袋里掏出一卷纱布朝她扔过来：“缠上，别直接碰到铁门。”

苏棠照做了，将纱布缠上手掌，按进花蕊。咔嗒，铁门内部传来一声轻响，像什么东西从插销上滑脱。门没有完全打开，只露出一条窄缝，缝隙里飘出陈腐的气味，夹着一股隐隐的、很干净的甜味。

苏棠推开门。

门后是一个圆形石室，大小约莫一间老屋的厅堂，穹顶上是交错的砖拱，正中央有一口井——不是枯井，井口溢出清水，沿着一条浅浅的石槽流进暗渠方向的孔洞。井台上放着一只铁皮匣，样式老旧，锁扣已经锈死，但盖上贴着一张泛黄的纸条。

纸条上的字，是外婆的笔迹：“阿棠，看到这些，说明你已经走到这一步了。”

苏棠走过去，放下铁皮匣，指尖蘸了一点井水——是甜的，带着姜糖水的气味。

外面忽然传来“叮”一声，那枚消失的龙眼玉，从井台上方的一根铜管里滚落出来，像被人吐出来的，落进苏棠缠纱布的掌心。玉粒上的热度已经退了，表面多了一道裂纹，从正中蜿蜒到边缘，像一条河流。

傅先生的手电光照进石室，他看见井台边沿的壁面上刻着一排名字，第一个是“沈桂芳”，外婆的名字。第二个是“沈桂兰”，第三个，是两个字，被磨掉了，看不清。

“阿棠——”陈阿婆的声音从身后传来，一个字一个字地落进石室：“你外婆，不是一个人回来的。”

苏棠回头，铁门在人影后合上，铜锁从内扣死。门外传来陈阿婆最后一句模糊不清的话语：“她在南洋，带着一个孩子。孩子丢了。”

石室里，只剩苏棠一个人，和掌心那粒裂了缝的玉。

她低头看井水。水面倒映出她的脸。那水里有一双眼睛——一双不属于她的眼睛，在井底深处，睁开又闭上。

# 第33章 萝卜糕

第二天清晨，苏棠拆了陈阿婆送的搪瓷盆，里面整整齐齐码着八块萝卜糕，煎得两面金黄，边上还煨着一小碟蒜蓉辣酱。她尝了一块，萝卜丝切得细细的，腊味和虾米的比例恰到好处，粉浆调得偏软，入口即化，是地道的老广手艺。

她把萝卜糕吃完了，但心里那根弦没松。红布条的事她思来想去，还是决定先不告诉顾淮安，毕竟人证物证都没齐，单凭一块褪色的布料说明不了什么。她用白棉布把《周氏食单》包好，塞进二楼床头柜最里面那层，又把那张字据拍了照片存进手机。

上午十点，铺子里来了头一拨客人。两个骑共享单车的年轻人，说是从大众点评上看到“百年糖水铺”的帖子来的，点了一碗姜撞奶、一碗杏仁糊，又要了一份桂花糕。苏棠在灶台前忙活，听着他们小声讨论铺子门口的拆迁告示，语气里是看热闹的惋惜。她没有接话，把两碗糖水端上去，杏仁糊上面撒了薄薄一层桂花，香气随着热气升腾起来。

年轻人走后，巷子里安静了一阵。苏棠正在擦台面，门口又有人进来。这回是个中年男人，穿着深灰色夹克，戴一副金丝边眼镜，看气度像是公职人员。他扫了一眼店里，目光在墙上挂着的那张糖水铺老照片上停了几秒，才在靠窗的位置坐下。

“老板，有什么招牌？”他问，口音不像是本地人。

“姜撞奶、酸梅汤、杏仁糊，要什么都有。”苏棠递上菜单。

男人翻了两页，点了一碗双皮奶。苏棠应了声，转身去取牛奶。她热奶的时候，余光瞥见男人从口袋里摸出一部手机，对着墙上的老照片拍了一张。快门声很轻，但店里太静，她听得一清二楚。

双皮奶做好端过去，男人尝了一口，点点头：“正宗。老板是棠记的传人？”

“外婆传下来的手艺。”苏棠说。

“老字号不容易。”男人放下勺子，从兜里摸出一张名片放在桌上，“我是市规划局的老周，负责老城区改造这一片的前期调研。听说这铺子有百来年历史了，想了解一下，如果将来真要做保护性修复，有没有什么需要留意的。”

苏棠接过名片，名片上印着“周明远”三个字。她心里“咯噔”一下——那不是连锁糖水品牌“糖记”老板的名字吗？又看了看头衔，确实是规划局的，职务是调研员。她面上没露声色，把名片收进围裙口袋里：“周先生要是有什么想看的，提前打个招呼就行。铺子里的老物件不多，就墙上这些照片还有些年头。”

“客气了。”周明远笑了笑，又说，“对了，听说这铺子以前是个大户人家的宅子？门口的老街坊说，墙角的那些雕花石柱是原来的旧物。”

苏棠心头警钟一响。她想起方鹤年手记里那张周家老宅平面图——图上画的院子范围，恰好就是现在糖水铺加上东厢房和后面那排杂物间的地界。这个自称规划局的周明远，怎么会这么清楚这宅子的旧事？

“周先生对这座宅子的历史很了解？”她笑着问，把声音压得和平时一样平。

“谈不上了解，”周明远推了推眼镜，语气很淡，“就是搞调研的时候翻了翻县志，看到些老照片罢了。临水巷原来有座周家大宅，在县志里是有记载的，就是不知道宅子的地界精确到哪儿。要是老板哪天空了，可以带我在院子周围转转。”

苏棠点点头，正要说话，门口又走进来一个人——顾淮安。他今天没穿白大褂，换了件浅蓝色衬衫，袖子卷到小臂，手里提着两袋菜，像是从菜市场回来的。他看见周明远，脚步顿了一下，很自然地笑着打招呼：“周处长？您怎么在这儿。”

周明远也抬起头：“小顾啊，我来看看这铺子。你们认识？”

“我常来这边吃饭。”顾淮安把菜放在门口的一张椅子上，走到苏棠身边，看向周明远的目光带着一点恰到好处的热络，“周处长的调研项目，我之前在社区卫生服务中心开会时听说过，说是要摸清老城区有保留价值的建筑底数，打算做一轮保护规划。”

“是是。”周明远点头，“都说不准的事，还在前期。”

顾淮安又说：“这铺子确实有年头了，我听居委会主任说，连门头那块木匾的年份都考据出来过，好像是同治年间挂的。周处长要是需要什么材料，我认识几个街坊，可以帮您收集。”

“那敢情好。”周明远笑了笑，站起身来，把双皮奶的钱放在桌上，“谢谢老板的糖水，味道很好。回头我再带同事来。”

等他的身影消失在巷口，苏棠才压着声音说：“他是‘糖记’那个周明远？我去网上查过，糖记的老板就叫周明远。”

顾淮安点了点头，神色平静，但目光里有一丝很淡的沉凝：“我在医院见过他的体检报告，确实是他本人。他来这儿看铺子，不像是调研那么简单。那片旧宅院的地界，牵涉到他家祖上的关系。”

苏棠攥着围裙的边角，心里翻涌着许多念头。她想到了那个在灶台暗格里睡了一夜的饼干盒，想到了那张写着“周家后人铭感于心”的字据，想到了方鹤年手记里那行“周家败落，人财两散”——眼前这个周明远，和当年那个周家，到底有什么渊源？他来看糖水铺，是真为了调研，还是想找那个暗柜？

巷口传来一阵摩托车声，是快递员送来一箱食材。苏棠收完货，走回灶台前，这才发现刚才周明远坐过的位置，地砖上落着一小块纸片，已经被人踩了一脚。她弯腰捡起来，不是垃圾，是一张被折过几折的收据上撕下来的一角。收据印着某家老字号药材行的抬头，日期是十年前的，金额栏被撕掉了，但底下还留着半行字——“苁蓉，二两”。

苁蓉。又是苁蓉。

苏棠攥紧那半张收据，抬起头，看见顾淮安也正看着她。窗外有人经过，风把门口悬挂的木牌吹得轻轻晃动，发出细碎的声音。

# 第405章 沈二娘

祠堂里光线暗沉，香案上一炉细香燃至半截，白烟笔直朝上，不散不乱。苏棠的眼睛适应了片刻，才看清太师椅上坐着的老太太。

她穿一身藏青布衣，头发梳得一丝不乱，满头的白发像落了霜。手里握着一根龙头拐杖，杖头的龙头已经被摩挲得发了亮。

老太太睁着眼看她，那双眼睛竟极清亮，半点不浑浊。

“棠丫头。”她开口，声音干哑，却带着不容置疑的笃定，“你跟你外婆年轻时长得很像。”

苏棠愣了一下神，随即点头：“阿婆，我来——”

“来要井里的东西。”沈二娘替她接完了话，又看向顾淮安，“这位，也坐。”

顾淮安拱手称谢，在侧首的椅子上坐下。苏棠把铜铃从布包里取出来，递到沈二娘面前：“阿婆，这枚铜铃是我外婆投进井里的，我把它捞上来了。我今儿来，是想问清楚一件事，我外婆和沈家塘之间，到底有——”

“有什么？”沈二娘的目光落在铜铃上，指尖轻轻触了一下那排水波纹，忽然笑了一声，“你外婆没说。她那个人，一辈子都不爱欠人情，也不爱让人知道她还不还得起。”

老太太顿了顿，忽然问：“你知道沈家塘为什么叫沈家塘吗？”

苏棠摇头。

“因为这塘底下，确实有一户姓沈的。”沈二娘说，“民国时候，沈家是这一带的大户，在塘边有自己的码头，自己的船队，还有一口井，据说那井通着一条地下河，河底有暗门，暗门后有屋。”

苏棠手指骤然收紧，地下有屋，铜铃上的字是这样写的。

“后来沈家败了，”沈二娘说，“人走的走、死的死。塘主换了姓氏，但这条塘、这口井、井底的东西，始终是沈家的。你外婆当年在这巷子里长大，跟我沈家有过交情，救过我的命。若不是她，我十六岁那年就溺死在塘底了。”

苏棠嗓子发干：“那她为什么把铜铃投进井里？”

沈二娘沉默了很久，久到香炉里那柱香落下一整截灰。

“你外婆说，她欠这巷子一条命。”老太太的声音低了下来，“不是她欠的，是她替别人还的。那铜铃是她当年定亲的聘礼之一。她把它投进井里，是把那段债还给塘底的人。井水不犯河水，从此两清。”

“可井泉会的账册里少了一册，经手人姓苏。”顾淮安忽然开口，“二娘可知道？”

沈二娘抬眸看向他，目光定了片刻，缓缓道：“你姓顾。”

“是。”

“你父亲顾秉文，是临水镇上的文书。”沈二娘说，“你祖父顾长庚，当年也是沈家塘的常客。你祖父常常来塘边钓甲鱼，你父亲也来过，那会儿你还没出生。”

顾淮安的指尖微微顿住了。

“井泉会那册丢失的账册，我看过几页。”沈二娘说，“是十四年冬季的账，记的是沈家塘封塘之前最后一笔收支。经手人姓苏，是你外婆的本姓。她不是贪那笔钱，她是把账给平了。平的是谁家的账，我不知道。”

苏棠攥紧铜铃，指节发白：“那笔账，和我外婆等的人有关系吗？”

沈二娘垂下眼帘：“你外婆等的人，已经不在了。”

苏棠胸口像被捶了一记。

“但她等的不是一个人。”沈二娘忽然说，声音很轻，却字字清楚，“她等的是一句话——‘对不住’。”老太太抬起眼，“当年对不住她的人，没来得及说这三个字，就走了。你外婆守了一辈子，是想替他说出来。”

雨忽然下了起来，打在瓦片上的声响，密而急。

沈二娘从袖中取出一个油纸包，递向苏棠：“你外婆的账，我替她存着。你拿回去看，看完烧了，也算清了。”

苏棠接过油纸包时，触到里面硬邦邦的东西。她没打开看，只问：“最后一件事。外婆手稿里写的‘井龙王’，到底是什么？”

沈二娘笑了，那笑意里有说不清的东西：“井龙王不是龙，是你外婆当年养的一条鲤鱼。她给它起了这个名，说它通人性，认路。”老太太顿了顿，“那鱼，就在这口井底下。铜铃投井那日，鲤鱼跟着铜铃一起沉了下去。”

苏棠脑中骤然闪过一个画面，井底横木与暗门之间，有一条银白色的鱼，一闪而过。

雨声更大了。沈二娘缓缓闭上眼：“棠丫头，你回来得晚了些，但不迟。有些债，等多久都不算迟。去吧。”

苏棠把那油纸包贴身收好，向沈二娘深深鞠了一躬。顾淮安也跟着起身行礼。两人转身走出祠堂时，雨幕里那口老井的石沿上，一只红蜻蜓停在井绳的末端，翅膀上缀着雨珠，一动不动。像是等了很久，等着看她们要往哪条路走。

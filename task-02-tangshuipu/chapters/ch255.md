# 第255章 药秤下的糖碗

那一夜雨没停过。

顾淮安走后，我翻来覆去没睡着。天亮时雨歇了，巷口的青石板被冲刷得发亮。陈阿婆拄着拐棍路过铺子门口，递进来一枝带着水珠的白兰：“昨夜那后生又来了？我看他伞都破了一把。”

我接过白兰，指尖却触到陈阿婆手心里一个冰凉的东西。低头一看，是一枚铜制的药秤坠子，小拇指尖大小，秤杆上刻着极细的花纹——是一朵糖画似的木棉花。

“哪来的？”我抬眼问陈阿婆。

陈阿婆眯着眼想了好一会儿：“昨夜我睡觉时发现的。不知是谁塞在门口花盆底下，用指甲油的壳子装着，壳子上贴着名字。”她口袋还在摸，摸出一张皱巴巴的纸条，上面写着三个字：给苏棠。

我给陈阿婆倒了碗热姜茶，坐在门槛上端详那枚药秤坠子。秤坠背面刻着三个小字：周世昌。

周世昌。周绣的兄长，照片里那个站在外婆与周绣之间、手握药秤的人。可这枚秤坠上，在木棉花纹里藏着更小的两个字——一个“顾”字，一个“易”字。

顾易。两个字好像被人凿刻后又磨掉了一半，笔画浅得几乎摸不出来。

我回屋翻了外婆的樟木箱。箱底压着一条旧手帕，帕角绣着一杆小秤，秤钩上挂着一颗糖丸，针脚细密，和昨夜里周绣归还的那条空白手帕出自同一人之手。手帕里包着一张褪色的药方纸，上面写着一行字：

“沉烟糖三钱，加老姜两片，蜜枣三枚，水七分，文火熬一夜。可解百药之毒。”

落款是“周世昌谨记”，旁边又用朱笔补了一行：“此法不可传于外人。”

我握着那张药方，手心的汗几乎要把纸浸透了。外婆手稿里划掉的那一行“易糖为药”——原来不是无的放矢，是外公周世昌留下的方子，外婆却不肯用。

她又怕什么？

午后我从档案馆回来，巷子口围了一圈人。老吴的修车铺前支起了两张长桌，桌上铺着大红绒布，摆满了碗碟——周明远的连锁店“糖记”在巷尾搞试吃活动，横幅上写着“百年配方，正宗传承”。

我站在人群外头，没挤进去。却看见顾淮安从人群中走出来，他手里端着一碗糖记的招牌姜撞奶，低头凑近闻了闻，忽然皱起眉，把碗放下，转身走了。

我跟上去，他在巷尾拐角的墙根下停住，像是早料到我会跟来。他转过身，把那碗姜撞奶翻过来给我看碗底——碗底竟印着小小一方红章，篆刻的四个字我认得：

“棠记手作。”

那碗是糖记试吃摊上的碗，碗底却盖着棠记的印。周明远用的是棠记才有的碗，印着棠记的章，卖着号称正宗的东西。

“我刚看过了，”顾淮安把碗底的红章摩挲了一下，“这章不是新刻的，边角的磨损至少得用了三十年。”

三十年前，我外婆还没关铺子。周明远的糖记，那时候又在哪？

我还没开口，巷子另一头传来一声清亮的咳嗽。转头看，周绣站在糖水铺门口，一身月白旗袍，手里拎着个旧布包袱，朝我笑了笑：“苏棠，我整理了一些你外婆留下的旧账本，你跟我来。”

她说完才看见顾淮安，神色微微一滞，那包袱在手中攥紧了一下，像藏着什么不该入第三人之眼的东西。

雨又落下来了。

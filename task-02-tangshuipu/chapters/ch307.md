# 第307章 花开之时

那两把铜锁像是刚刚被打磨过，在灯光下泛着冷冽的光，和地窖里那些生了铜绿的旧物截然不同。苏棠下意识看了一眼手中的钥匙——柄上的刻字，和锁孔上方的两个微小标记正对。一把刻着棠记，一把刻着林宅。

“这两把锁是后配的。”顾淮安蹲下身，指尖擦过锁身侧面一道极细的划痕，“五金店那种批量压制的锁，近十年内的东西。”

林见秋的呼吸明显重了。他说：“这栋老宅十年前就已经没人住了，爷爷搬去养老院，这宅子一直空着，钥匙在我手上。”他顿了顿，“我从来没有打开过这里的后门。”

苏棠没说话。她将“棠记仓”钥匙插入左锁，拧动，弹簧“咔”地弹开；又用“林宅井”钥匙开了右锁。两把锁同时脱落，黄铜落地的声音在地窖里回荡了很久。

门内是一个小小的井窖。井口用青石板围着，井壁上刻着一行字——不是年份，不是人名，而是一句诗：“此去经年，应是良辰好景虚设。”

苏棠的呼吸猛地一顿。这句诗，她在外婆手稿最后一页见过，写在“方子”二字的旁边，当时她以为是外婆随手抄录的词句，没有在意。可如今，这句话刻在井壁上，说明外婆不是随手写下的——她是在刻。

井不算深，井底该是干涸多年的，底部铺着一层干草，草上放着一只木匣。木匣没有锁，只是扣着一个铜扣。

苏棠弯腰把木匣抱上来，掂了掂重量，轻得出奇。她打开铜扣，掀开盒盖，里面只有两样东西：一幅卷得极紧的画轴，和一张折叠成四方形的纸。

她先展开那张纸。纸已经脆得发黄，折痕处几乎要断裂。上面的笔迹她不陌生——是外婆的，但比手稿里任何一页都要工整，像是郑重其事写下来的：

“阿棠之方，原非吾创。吾师阮沉烟，庚辰年正月初九，以此方授吾于棠记仓。当日说好吾此后以师名姓开铺，凡五十年，期满归还。吾年廿三，师年四十有一，师便离城云游，言花开之时当归。今花已开过五十七回，师未归。吾将方录于手稿，传吾孙女。若师后人寻来，以此方相还，则棠记仍归师门。”

苏棠读完这张纸，抬起头，声音里带了一丝连她自己都没察觉的颤抖：“阮沉烟……”

这个名字，在她外公去世那一年，她曾听外婆提过一次。当时外婆病着，神志不太清楚，拉着她的手说：“你外公欠了阮家一条命，我这铺子，也欠阮家一个方子。”她只当是老太太的胡话，之后外婆再也没提起过。

可原来，这份“欠”的并不是一场胡话。

林见秋的目光也定在那张纸上。他沉默片刻，说：“阮沉烟，我爷爷的师娘。”

苏棠猛地转头看他。林见秋摘下眼镜，缓缓道：“我爷爷年轻时在阮家帮厨，阮家开了一间大饭店，阮沉烟是掌柜的媳妇，掌勺的名厨。我爷爷曾说过，阮沉烟的徒弟里，最出挑的是一个姓沈的姑娘——也就是你外婆。后来阮家出了变故，阮沉烟把方子给了徒弟，让她改名换姓，去别处开铺。”

“那阮沉烟呢？”苏棠问。

“走了。她把铺子给了徒弟，就再没了消息。”林见秋的目光落在那只木匣上，“可我爷爷说，她走之前留了一句话，说那一走，是去还一条命债。”

一阵穿堂风从井壁涌上来，吹得苏棠手里的纸哗哗作响。她想起外婆手稿最后一页上的那句话——“方子不是秘密”，忽然间，她懂了。

“这画轴是什么？”顾淮安问。

苏棠展开画轴。画上是一幅小像，墨笔勾勒，是一个年轻女人的侧影，正低头搅着一碗糖水。碗里水汽氤氲，女人眉目清柔，唇角噙着一丝笑意。画角题着一行小字：“阮氏沉烟于棠记仓，庚辰年正月初九。”

是她外婆年轻时的画像。

不——画像上女人的衣领，绣着一朵五瓣梅花，红漆梅花，与手稿中那半张喜帖的底纹一模一样。

苏棠盯着那朵梅花，忽然想起什么，急急从怀里掏出那叠从青灰陶坛里取出的牛皮纸信封。她数了数，一共十封，每一封上都画着一朵梅花，一朵比一朵大，一朵比一朵红。最上面那一封，是最后一朵——花开得最盛。

她拆开最后一封。里面只有一张字条，写着两行字：“花开之时当归。玉棠，我回来了。”

落款——阮沉烟。

而底部的日期，正是外婆去世前三天。

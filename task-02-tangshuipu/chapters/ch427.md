# 第427章 门外之人

脚步声在石门外停下，一声一声，不急不缓，像有人在用指节叩门，又像是沉闷的鼓点敲在人心上。

苏棠攥紧手中的铁皮盒子，指尖微微发白。老太太却没什么惊慌神色，银发下的眼睛朝石门方向望了一眼，嘴角甚至浮起一丝若有若无的笑意。

“三十多年了，他终于肯来见人。”

“他是谁？”顾淮安上前半步，将苏棠挡在身后。

老太太没有回答，只是缓缓起身，枯瘦的手指拂过衣襟上的盘扣：“把姜撞奶端起来，让他闻到味儿。”

苏棠低头看向那碗姜撞奶。先前在井底石室时，这碗奶已经微微凝住，此刻在怀中一路颠簸，却始终没有洒出分毫。奶面光滑如镜，隐约映出头顶石缝里渗进来的水光。

石门外的脚步声停了片刻，又响起来。这一次更沉，更像拖着一条腿在走。

“他每次走，都是这个声音。”老太太低声说，“四十三年前，我头一回在这井底听见脚步声，也像今天这样害怕。”

“您等他等了三十多年？”苏棠问。

老太太摇了摇头:“不是等他，是等姓苏的姑娘来，把我学的这碗姜撞奶还给她。”她看向苏棠怀中的铁皮盒子，“你外婆的信里写了什么，你念出来。”

苏棠犹豫了一下，还是打开铁皮盒子。信纸已经泛黄，但字迹清晰，笔力遒劲，正是外婆的手笔——

“贞娘谨启：债已清，人未等。若有一日苏家姑娘持匣至此，烦请以一碗姜撞奶，了却旧事。”

落款是“苏贞”二字，墨色渗入纸背，像是写了不止一遍。

老太太接过信纸，指尖在“贞娘”二字上停住，良久才开口：“我姓周，闺名一个贞字。年轻的时候在棠记帮工，你外婆教我姜撞奶，说这是棠家的传家手艺，让我替她守着。”

“那杜慎行……”苏棠说。

“是货郎，也是井泉会的人。”老太太的声音轻下去，“他替你外婆带糖料，半路遇劫，别人都说他死了，棺材都埋了。可是——”她顿了顿，“他没死。有人看见他被拖进井里，拖到这个地方。”

门外传来一声低沉的叹息。像是印证老太太的话。

顾淮安望向石门，目光沉静：“他活着，这四十三年都在井下？”

老太太点了点头：“苦得很。可他不能上来。他要是上了这地面，当年那些人就知道你外婆的血脉还活着，苏家种的那个因，就得苏家人来收。”

苏棠没有说话，低头看着手中的碗。姜撞奶微微晃动，热气已经散了大半，可那股甜香反而更浓了一些。

她想起外婆生前总在灶台前念叨——热奶下撞，火候不到，奶凝不住；火候过了，又老了。做糖水，跟做人一样，急不得。

门外那沉重的脚步声又动了。这一回，它慢慢往下移了几级台阶，发出“咚、咚”的钝响，像是往更深处走。

老太太忽然睁大眼睛：“他走了！快去追——”

顾淮安一把推开石门，门外是一段向下延伸的窄道，头顶滴着水，两侧石壁上生着青苔。昏暗中，他看见一个佝偻的身影拖着一条腿，正朝更深的地方走去。那人穿着一件洗得发白的灰布褂子，头发花白，身形枯瘦，背微微弓着，像是一棵树干了年岁，却没有倒下。

“杜慎行——”苏棠追出门去，喊了一声。

那人脚步微微一顿，却没有回头。他抬起一只手，朝身后摆了摆，像是在说“别来”。那只手的指节粗大，虎口处有一道旧疤，从大拇指根一直拉到小指根，几乎横贯整个掌心。

老太太在门边站着，忽然轻声道：“他说，他等的不止是一碗姜撞奶。他等的是你外婆的一句话。”

“什么话？”

“她欠他的，不是债。”老太太声音发涩，“是一句‘对不起’。她当年跟他说，等他回来就成亲——他没回来，她嫁进了棠家。”

苏棠怔住，低头看向手中的碗。

窄道深处传来低沉的、像笑声又像叹息的声音，然后是水声，仿佛有人涉过一片浅水，去往更深的暗处。窄道尽头的水痕旁，那佝偻的身影渐渐隐入黑暗，只留下一个模糊的轮廓，越来越远，越来越淡。

苏棠端着那碗姜撞奶，站在窄道口，忽然觉得手中的温度不再。她低头看了一眼——奶面上不知何时凝出一层细纹，像是有人隔着很远，朝这碗奶呵了一口气一般，在奶面留下浅浅的、几乎看不清的印痕。

“他的声音透进奶面了。”老太太走过来，看着那层细纹，目光深长，“他认得这碗奶的方子。你在井底做的那碗姜撞奶，用的料和手法，跟你外婆当年做的一模一样。他尝出来了。”

苏棠慢慢收拢五指，指尖陷入碗壁温热的粗瓷纹路里。窄道深处的水声渐渐平息，那一团模糊的轮廓彻底消失。石门外的寂静重新涌上来，仿佛整座井底只剩下她们三个人。

顾淮安蹲在窄道口，捻了捻地上的水痕。指尖触上去，水痕是凉的，却带着一丝极淡的桂花香。“他来过，走了。”他站起来，目光落在窄道尽头的黑暗里，“但这条路他还回来。”

老太太转过头，看着苏棠，忽然把手伸进衣襟最里层，摸索着取出一枚铜钮扣大小的物件，递到苏棠掌心。那东西是旧的，磨得发亮，是一枚刻着“棠”字的铜扣，背面有道细痕，像是掰断过又被粘回去的。

“四十三年了，我守着他出来还的，就是这个。”老太太说，“他说，等姓苏的姑娘来，把这个还给她。棠家的东西，不能落在别人手里。”

苏棠握紧那枚铜扣，指腹压过“棠”字刻痕，像是握住外婆那个年代，一道被时间磨薄却始终没能磨断的线。

窄道深处，水声忽然又响了一下。不是脚步，像是有什么东西从水面下冒了出来，轻轻破开水面，又沉了下去。

顾淮安向窄道尽头望去，一线水光在黑暗中晃了晃，像是有人在水底睁开了眼睛。

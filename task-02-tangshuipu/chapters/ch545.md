# 第545章 她等的不是人

苏棠把桂花枝头那根暗红毛线头取下来的时候，指尖刚碰到绒面，就闻到一股很淡的桂花香——不对，桂花是八月的事，眼下刚过了清明，树上哪来的桂花味。

那香味是从毛线头里渗出来的，像是浸过桂花蜜又晾干了，藏了许多年。

顾淮安站在她身后半步远，没出声。苏棠把毛线头举到灯下，暗红色，粗绒线，手工纺的，捻线方向跟机器织的相反。她翻过线头在指尖绕了两圈，然后在打结处看见一小截银白色的东西，嵌在绒线里，被磨得光亮。

那是一粒银珠子，绿豆大小，中间穿了个孔，像是从什么饰品上掉下来的。

“陈阿婆的帕子上绣的是什么花？”苏棠问。

顾淮安想了想：“木槿。她帕角绣的木槿，花瓣是紫红色的。”

“紫红色。”苏棠低头看着手里那根暗红毛线头，声音轻了下去，“紫红色洗久了褪色，就成了暗红。”

她没再说下去。巷子里的老人都知道，陈阿婆年轻时候是有名的绣娘，绣花用的绒线都是自己染色，桂花蜜调色，染出来的颜色又亮又牢。但有一种颜色她从来不染——红色。她说红色不吉利，绣了红线的衣裳，是要送走人的。

顾淮安把那粒银珠子捻在指腹上，对着灯看了一会儿，忽然开口：“这种银珠，我小时候见过。”

苏棠转头看他。

“我外婆有一对银耳坠，坠子就是这个样式，”他说得慢，像在回忆里逐寸翻找，“后来丢了一只，她说是在巷子里掉的，找了很久没找到。”

苏棠心里那根线忽然绷紧了。顾淮安的外婆，姓沈。

沈家，沈云启，沈名舟。那条线从四十年前一直牵到今天，从梧城冰厂牵到临水巷，从井底的涡流笑声牵到桂花树上挂着的暗红毛线头。

“你外婆……”苏棠斟酌着措辞，“她跟陈阿婆很熟？”

顾淮安沉默了一会儿，把那粒银珠小心放回毛线头的结里，神色平静，但苏棠看见他握着线头的手指微微收紧：“我外婆走那年，陈阿婆来吊唁，在灵前坐了一整夜。她走的时候，跟我说了一句话。”

“什么话？”

“她说，你外婆等的不是人。”

苏棠脊背一凉。那种凉意从尾椎骨一路窜上来，像井底的水气穿过石板缝，悄无声息地漫上来，浸透了整个灶间。她听见灶台上那口铁锅里的水烧开了，咕嘟咕嘟地响，水汽顶得锅盖一上一下。

“她等的不是人。”苏棠重复了一遍这句话。外婆手稿里写的——“有些回来的人，不是人。”一模一样的意思。陈阿婆说的是顾淮安的外婆，外婆的手稿说的是她自己。两个老太太，各等了一辈子，等的都是“不是人”的东西。

苏棠把那根暗红毛线头摊在手心里，盯着那粒银珠看了很久，忽然问出一个她自己都觉得荒诞的问题：

“顾淮安，你外婆叫什么名字？”

“沈秀禾。”

苏棠手里的毛线头差点掉下去。沈秀禾。她见过这个名字——在外婆手稿夹层里那张旧照片的背面，蓝圆珠笔写了三行字，第一行是个“江”字，第二行是日期，第三行就是“秀禾”。她一直以为那是外婆写的“绣禾”两个字，以为是形容绣娘的，原来是人名。

“你外婆，是大厨吗？”苏棠的声音有点哑。

顾淮安的呼吸顿了一下，眼底渐渐浮起一丝极淡的困惑：“她……会做饭，但从不进灶房。她说她闻到油烟味就头晕，一辈子没下过厨。”

苏棠慢慢闭上眼。手稿里有一页写着——“秀禾说她不进灶房，可她调的那碗糖水，我这辈子再没喝过第二碗。”她终于明白那句话的意思了。不是“她调的那碗糖水”，是“她”。沈秀禾，不进灶房的沈秀禾，调了一碗糖水。而那碗糖水的手艺，被外婆记在了一本密密的、藏在灶台夹层里的手稿里。

“你家……还有什么老物件是外婆留下的？”苏棠睁开眼。

顾淮安沉默地看了她一会儿，说：“有一个铜铃铛。我外婆说，是她的嫁妆。”

铜铃铛。苏棠脑子里嗡了一下——外婆手稿的最后一页，夹层里那只小布包，装着一只铜铃铛，铃铛内壁有一道浅浅的刻痕，像是一个“永”字。外婆临终前握着她的手说：“找到另一只铃铛，就知道你外公还活着。”

“那只铃铛呢？”苏棠声音发紧。

顾淮安望着她，那双平日里温和从容的眼睛此刻被灶间昏黄的灯光照出一点幽深的暗色：“在井里。”

“什么？”

“我小时候不小心掉进过井里，”他说，“外婆把她的铃铛挂在我脖子上，说能保平安。后来井里出过事，铃铛掉下去，再没捞上来。”

苏棠觉得有什么东西在脑子里“咔嚓”一声响了，像锁舌归位。她低头看着手里的暗红毛线头，又抬头看向井台方向。夜色里，那口老井静静地等在巷尾，黑洞洞的井口像一只睁着的眼睛，井底传来极轻极轻的水声。

“顾淮安，”苏棠一字一字地说，“那只铃铛，可能还在井底。”

顾淮安没有答话。苏棠看见他垂下眼，手攥成了拳，指节泛白。她知道他在想什么——井底有水，四十年前的井底有过涡流，有过笑声，有过湿脚印一直延伸到巷尾拐角凭空消失。如果那只铃铛真的在井底，那它沉在那个地方，四十年来，听见过什么，看见过什么。

苏棠忽然听见灶间门板外面传来一声细弱的猫叫。

黑猫。那声音她认得，是那只——会用人声说“饿”的黑猫。

她正要抬头，顾淮安忽然伸手按住她的肩膀，力道不重，但苏棠能感觉到他掌心的温度隔着布料传过来，像一堵墙。他低声道：“别动。听。”

苏棠屏住呼吸。门外的猫叫声停住了，接着是一串极轻的脚步声——不是猫的爪子落在青石板上的声音，是人穿着布鞋踩在泥地上的声音，一轻一重，一轻一重，带着明显的跛态。

跛脚的人。那脚步声从巷口方向来，经过棠记门口，停顿了三息，然后继续往前走。走到井台方向，停了。

然后，苏棠听见井底传来一声轻微的金属碰撞声——像是什么东西被从水里捞起来，又落了下去，叮。

顾淮安的瞳孔骤然一缩。他也听见了。

那枚铜铃铛，在井底响了。

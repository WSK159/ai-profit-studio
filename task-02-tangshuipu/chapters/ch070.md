# 第70章 旧账本

夜色像一锅熬过头的老姜茶，浓稠地糊在临水巷的屋檐上。苏棠坐在棠记的柜台后面，老式吊扇呼呼转着，吹得账本纸页哗啦响。她已经在柜底翻了大半个时辰，指腹划过一层又一层积灰，终于摸到一本硬壳的蓝布封面东西——被压在几本旧菜谱最底下，像是被人刻意藏过。

她抽出那东西，灰尘扑了满脸，忍不住打了好几个喷嚏。

“又在翻东西？”门外传来顾淮安的声音，他推门进来，风衣上带着初夏夜晚的潮气，手里拎着两杯热饮，一看就是从巷口便利店顺来的速溶咖啡。

苏棠没抬头，把那本蓝布册子摊开在柜台上。封皮没有字，内页泛黄发脆，边角被虫蛀出细密的孔洞，但钢笔字迹依然清晰。第一页日期是三十七年前的春天，抬头写着四个字：棠记往来。

“账本？”顾淮安把咖啡搁在柜角，凑过来看。

苏棠翻页的动作顿了一下。这账本记的不是糖水铺的进项出项，而是一笔笔外人看不懂的条目：三月初七，白铁皮一箱，付讫。三月廿三，黄铜锁两把，欠。四月十五，樟木箱一只，托人送去城南，路费三钱。字迹工整，却是外婆年轻时的笔体——和苏棠在旧手稿里见过的一样，横竖之间微微往右倾，像是写信的人总赶着时间。

她再往后翻，发现每隔几页就有一笔“托人送去城南”的记录，收件人一栏都只写一个字：梅。

“梅若谷。”顾淮安低声说。

苏棠点头。她想起那天在济世堂药房角落找到的油纸包——那封外婆写给梅若谷的信还锁在自己卧室抽屉里，始终没有拆开。她拿不准自己是不敢，还是觉得时候未到。

“这账本记到哪一年？”顾淮安问。

苏棠翻到最后一页，日期是二十一年前的深秋。账目只有一行：五瓣梅饮方，交梅氏旧人，私约，永不重制。下面画了一朵五瓣梅，花瓣边缘微微晕开，像是写这行字时落了泪——或者，落了雨。

她盯着那朵梅花，指尖轻轻压住那几道花瓣的纹路，心里浮起一个说不清的念头。顾淮安显然也在想同一件事，沉默了一会儿才开口：“你外婆写‘永不重制’，但那协议上你母亲签了字，把三瓣梅饮的配方转给了糖记。”

“所以外婆不知道。”苏棠慢慢说，“母亲是背着她签的。”

店堂里安静下来，外头巷弄里有只猫在高一声低一声地叫。

苏棠把那本账本翻回前面几页，忽然停住了——第七页里夹着一张薄得几乎透明的纸，被折成了很小的一方，不仔细根本看不出来。她小心展开，纸上是另一种笔迹，笔画瘦硬，骨架端方，像是练过多年毛笔字的老师傅写的。纸上只有两行话，右下角落款是“梅守正”，日期是外婆“永不重制”那一年的春天。

纸上写的是：阿蓝，那孩子我看了，眉眼像你，性子像他。你若舍不得，带回去吧，别叫外头人知道。我会跟人说我女儿殁了。

苏棠的呼吸一下紧了。她反反复复将那两行字读了三遍，忽然抬头看顾淮安——他凤眼微眯，也从她手里接过那张纸，看过后久久不语，末了才说：“你外婆年轻的时候……有一个孩子？”

话出口他自己都愣了一下，像是反应过来什么，瞳孔微微缩紧。苏棠的手扣住柜台边缘，指节泛白。

“梅守正的女儿叫梅若兰，梅若兰的关门弟子是周蓝——我母亲。”她一字一句说，“那张照片上四个人，梅若谷说过，他姐姐梅若兰当年有个女儿，十几岁就送到外地养了。如果那个女孩就是周蓝……”

她说不下去了。如果周蓝是梅若兰的女儿，那外婆周阿蓝交出去的“那孩子”，绝不是周蓝，而是——”

“是你母亲生下的孩子。”顾淮安替她说完了这句话，声音很低，“周蓝有个孩子，寄养在梅家。梅守正让外婆把孩子带回来，外婆回信说‘不必，自有去处’。后来那个孩子去哪儿了？”

苏棠垂下眼睛。她想起顾淮安上次说，他父亲顾长海房契上的手印，和协议书上周蓝的手印有诡异的相似。她再看他那副眉眼时，总觉得某些东西在悄悄往一处合拢——但又觉得荒唐，不敢深想。

风从门缝里灌进来，把账本又吹翻了两页。一张硬纸片从夹层里滑落，掉在苏棠脚边。她弯腰拾起，翻过来看，是一张老式诊所处方笺，患者姓名一栏写着字迹潦草的“顾某”，下方主治医生签名却清清楚楚——梅若谷。诊断栏写着：青霉素过敏史，忌用；慢性胃炎，忌辛辣。最下面有一行小字：患儿出生时脐带绕颈，疑有轻微缺氧，观察三月。

“顾某”后面没写全名，但苏棠知道顾淮安的病历本上，在过敏史那一栏，也用红色水笔写着三个字——青霉素。

她慢慢把处方笺放到柜台上，抬眼看顾淮安：“你听说过一个人叫梅守正吗？”

顾淮安握咖啡杯的手微微用力，杯壁凹下一小块。他没有回答，但苏棠已经从他眼睛里读到了答案——他听过。或者说，他父亲顾长海，这辈子只提起过一个和自己没有血缘关系的人的名字，就是梅守正。

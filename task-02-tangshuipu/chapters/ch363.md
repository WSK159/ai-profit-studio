# 第363章 西门渡头

酉时过，天色彻底暗下来。

苏棠穿了件灰布外套，将绵纸地图叠好贴身收着，出门前想拿煤油灯，犹豫片刻，还是没带。她握着那枚银片，拇指反复摩挲刻字凹痕，心里在想同一个问题：周缙为什么要约在西门渡头？

临水巷靠南有一条青石渡，早年通水路，后来河道改道，只剩一段废弃的旧码头。西门渡头在渡口最西边，长年没人走，野草齐腰，连巷子里的孩子都不去那里玩。

她拐进老巷，穿过后街，绕过龟背石——果然有一块青灰色大石头，形状像龟壳，地图上的标记没错。再往前，走进一片半人高的荒草地，土地松软，脚下一步一个印。尽头处，一座破旧的石砌台阶伸向漆黑的河面，台阶末端没入水中，铁环锈蚀。渡头边的老柳树歪着身子，枝条垂进水里，在夜风里微微摆动。

四下无人。水声轻拍石阶，一下一下，像心跳。

苏棠站在柳树下，等了约莫半刻，正要掏银片再看一眼，忽然听见身后有脚步声。很轻，像踏在草尖上。

她回头。柳树斑驳的影子下，站着一个身形清瘦的老人。灰白的头发很短，穿着深灰色旧中山装，袖口卷到手肘，露出干瘦的小臂。他面朝着她，脸上皱纹纵横，像一片风干的老树皮。但那双眼睛很亮，亮得像夜里也烧着一盏灯。

他在朝她笑。嘴角牵动这些皱纹，像很多年来第一次笑，有点不自然，有点不知所措。

“你长得像你外婆。”他说。声音比她预想的轻，带着沙哑的尾音，“尤其是眼睛。”

苏棠喉咙发紧，半天才挤出一句：“你叫周缙？”

老人没答话。他慢慢走下台阶，停在她面前三步远的地方，从口袋里掏出一样东西递过来。蓝布包，四四方方，外头扎着细麻绳。

“棠记钥匙。”他说，“你外婆当年给我配的。我走的那天放在身上，六十年，没敢丢。”

钥匙。苏棠接过来时指尖发抖，绕开麻绳一层层展开蓝布，里面是一把老式黄铜钥匙，样式和她手上那把几乎一模一样，只是钥匙柄上多了一圈细纹，像箍了一道银丝。

“你外婆走的那年，我在北边河滩上看到一株油菜花开了。”他没有解释钥匙连接着的六十年，忽然转了话头，“我蹲在那里看了很久，想起她说，油菜花开的时候，巷口的糖水也该换方子了。”

苏棠攥着钥匙，说不出话。

周缙转头看向河面，水面倒映着零星的灯影：“她给你留手稿，留灯，留铜片——都是留给我的。她怕我不记得路。其实我记得。”他顿了顿，微微叹了口气，“只是不敢回。”

“为什么不敢？”

“那年我欠了债。”他说，“欠周家，也欠她。周家的人找上门来，要我拿棠记的方子抵债。我不肯得罪她，也不肯出卖祖宗，只能走。走之前我把方子抄了一份，埋在沈家塘井底的青石板下——我以为迟早能回来取。但我一走，就被运到南边修桥，修了十三年。回来后，西门外已经通了汽车，旧航道填了大半。棠记还在，我却不敢进去。”

他说完，从蓝布包夹层里又取出一张纸，很薄，叠成窄长条：“这是那晚我在井边写的一页信。没寄出去。你替我看吧。”

纸展开，字迹与绵纸背面一致——“塔，你等了我六十年。我把钥匙还给你，方子埋在青石板下。若哪天你有空，去撬开看看。里面不止是方子。”甲申年，春。

“不止是方子？”苏棠看向他。

周缙沉吟片刻，道：“那块青石板下，除了方子，还有一个木匣子。匣子里头是什么，我没敢看过。我只知道，你外婆把那个匣子跟我埋下去的时候，她说，‘若有一日棠记撑不下去了，用这东西作保。’”

苏棠心头猛然一震。她想起沈家塘井底，甬道深处那扇石门前，用砖头封着的东西。不是方子——是外婆留给她的另一把钥匙。

她正要再问，身后的柳树阴影里，忽然传来一个陌生的声音：

“周缙，三十年没见，你做事还是这么不干净。”

周缙身形一僵。两人同时转头。

柳树根部的阴影里，走出一个穿灰色风衣的男人。四十来岁，头发梳得一丝不苟，步子稳健，嘴角带着笑。他身后还跟着两个人，站在更远处，看不清面孔。男人停在几步外，目光从周缙脸上掠过，落在那块露出泥面的青石板上：“你埋的东西，我都挖出来了。”

周缙的脸一下子变了颜色。

“棠记的钥匙呢？”男人伸出手，语气客气，眼神却凉，“给我。”

苏棠攥紧蓝布包往后退了一步。男人笑了笑，从风衣内侧抽出一样东西，在夜色中晃了晃——是一张照片，黑白旧照，上面两个年轻女子站在糖水铺门口，一人穿素色旗袍，一人穿浅蓝布衣，眉眼之间有七八分相似。

“你外婆有个姐姐，”他说，“你知道吧？”

苏棠愣住了。外婆从没提过。

“她姐姐，叫姜兰芝。”男人说，“活不见人，死不见尸。”他指了指照片上那个穿素色旗袍的女子，声音平静得像在报菜名，“周缙走的第二年，她就从临水巷消失了。有人最后看见她的地方，是西门渡头。”他说完，把照片收回口袋，又看向苏棠的手，“所以——钥匙，给我。”

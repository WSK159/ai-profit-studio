# 第69章 梅花银扣

周晚照顺着苏棠的目光回头，看见了门外的顾淮安。她下意识将皮箱合上，动作极快，但那张旧照片的一角已经从箱底翻了出来，明晃晃地折着边儿。

顾淮安收了伞，雨水顺着伞尖淌在门槛外的石板上。“我来送……”他声音顿了顿，像是一时找不回自己要说什么，“送个东西。”他从口袋里掏出一只小纸袋，是下午苏棠托他打听的药，又补了一句，“顺路。”这句话说得不太顺。

苏棠接过纸袋，侧身道：“进来坐吧。”她朝周晚照看了一眼，又望向顾淮安，“这位是周阿姨，外婆故人的妹妹。”

顾淮安的目光从周晚照身上滑过，落在她脚边的皮箱上，又移开了。“不坐了，”他说，“铺子里同事还等我回话。”他语气依旧是那样平平稳稳的，苏棠却觉得他今天说“不坐了”三个字的时候，比平时快了半拍。

周晚照却忽然开了口：“你姓顾？”

顾淮安站在门口，回过头来。借着檐下的灯光，周晚照看清了他的脸——尤其是眉骨到鼻梁那一段轮廓，她的手无意识地攥紧了皮箱的提手。“你父亲——”她顿了一下，像是在斟酌用词，“是顾长海么？”

顾淮安没有立即回答。他站在那里，雨水从伞尖滴落在石板上，一下，一下。半晌，他说：“他去世了。三年前。”

周晚照闭上了眼睛。她把皮箱重新放到地上，那件蓝布衣裳的领口上，银扣在昏光里微微闪着。

“你进屋来，”周晚照终于说，“我给你讲个故事。”

顾淮安站在门外，像一株长在屋檐下的树，过了好一会儿，他才跨过门槛，在桌边坐下，伞靠在墙角，伞面的水珠慢慢洇成一圈湿痕。

周晚照重新打开皮箱，将那张旧照片取了出来。泛黄的相纸上，一个穿蓝布衣裳的年轻女子站在糖水铺的门前，身后是木雕的“棠记”二字。女子眉眼温婉，嘴角微微弯着，手里端着一碗冒着热气的糖水。

“这是我姐，周蓝青。”周晚照说，“四十二年前，她在这里做学徒。”

苏棠站在灶台前，手里捏着一只碗。外婆手稿里写过这个人，只写过一次，字迹旁边还有一处被水渍晕开的痕，记着“蓝青苦命”。

“那批川乌，”周晚照缓缓道，“是我姐经的手。但她不是有心害人——她是被人骗了。那人说那是喂马的药材，让她把货从药房调去码头。等出了事，她才知道那批川乌熬进了糖水里，喝下去的人，有你外公，还有一个姓顾的年轻人。”

顾淮安的手指微微收紧。

“姓顾的年轻人——”周晚照看向他，“是你爷爷辈的人。他喝下那碗糖水，伤了一条腿，后来搬离了临水巷，再没回来。我姐背不了这个罪，投了井。”

屋里静得能听见灶上粥米翻滚的声音。苏棠的喉咙紧紧发涩，她想说什么，又说不出来。

“你外婆没有追查。”周晚照说，“所有人都以为她是不想追究。但我知道，她是在等。等那个姓顾的年轻人回巷子里来找她——她欠他一句对不起。”

顾淮安忽然开口：“我爷爷叫顾长水。”

周晚照一怔：“顾长水？”她低声念了两遍，像是从记忆深处捞起什么东西，“我记得这个名字。你爷爷，是那条腿伤的左腿还是右腿？”

“左腿。”

屋里再次寂然。门外的雨已经停了，屋檐下滴落的水珠在积水的石板上砸出叮叮咚咚的声响。苏棠看着顾淮安，他的脸色在灯下微微发白，但眼神还是平静的。他站起身，向周晚照微微欠了欠身：“谢谢您告诉我这些。”

周晚照看着他，眼圈泛红：“你爷爷哪里，替我姐……”

“他后来过得还行。”顾淮安打断了她，声音平淡，“做了一辈子木匠。倒是常念叨临水巷的糖水。”

周晚照别过头去，拿袖口擦了一下眼睛。

苏棠走上前，从柜台下面翻出一只布包。那是她前几日从铺子地砖缝里挖出来的：另一枚梅花银扣，五瓣俱全，和周晚照箱里那枚缺了一瓣的正好凑成一对。

周晚照盯着那枚银扣，嘴唇翕动：“这是……”

“外婆留在灶台底下的。”苏棠说着，又补了一句话，“她说，等有一天周家人来了，就把它还回去。”

周晚照接过那枚银扣，指尖发颤。她低头看了很久，然后抬起头来，目光异样的平静：“你外婆从头到尾都知道。她知道我姐是被人骗的，她知道那姓顾的年轻人搬去了哪里，她还知道……”

她停下来，像是有些说不下去。

“她还知道什么？”苏棠问。

周晚照轻轻摩挲着银扣上的花瓣，声音低得像是在自言自语：“她还知道，当年那个偷方子的人，本姓顾，后来却改姓换名叫周明远。”她的目光移向苏棠，“你们说的那个‘糖记’老板周明远——他就是当年偷方子那人的孙子。”

苏棠手里的碗差点跌在灶台上。顾淮安站直了身子，眉间拧出一个深深的结。

雨夜的风从巷口卷进来，檐下的风铃“叮”地响了一声。苏棠看见外婆那摞手稿压在柜台一角，封面被风吹得掀开一角，露出一行字来：

“三瓣梅饮，非为外人道也。然梅有落处，人有归时。”

窗外，巷口远处的路灯下，一个撑着黑伞的身影正缓缓走过。苏棠的目光扫过去，那人顿了顿，折进岔路里，消失在雨后的黑暗中。

# 第362章 灯座的余温

晨光从窗棂斜斜切进来时，苏棠正蹲在柜台前擦拭那盏煤油灯。

她一夜没睡好。铜片上的字在梦里反复浮现——“灯亮了，人还在。灯灭了，人便不在了。”这句话念起来像咒语，也像遗言。她总觉得外婆写下这行字的时候，手指是抖的。

灯罩上的“周”字刻痕在晨光里泛着暗铜色光泽。苏棠用细绒布轻轻擦拭，指腹忽然停在一条极浅的划痕上——那是昨夜佝偻老人触碰过的位置，与刻痕呈六十度角，像是常被人捏着那处转动灯罩。

她试着握住灯罩，逆时针轻旋。纹丝不动。

又试顺时针。“咔。”一声极轻的响动，像是什么东西松开又扣住。苏棠心头一跳，还没来得及细看，铺门被人拍响。

“棠棠！开门！出事了！”

是陈阿婆的声音，急得变了调。苏棠放下灯，快步拉开门闩。

陈阿婆站在门口，怀里抱着那盆快要谢了的栀子花，脸色发白：“昨晚上，有个老头在沈家塘边来回走动，后半夜被人看见浑身湿透坐在井沿上。今早人不见了，井边丢了一双布鞋。”

苏棠的呼吸顿住。

“鞋什么样？”

“黑面白底，千层纳的，针脚细得跟绣花似的。”陈阿婆压低声音，“这鞋我看着眼熟，像是——像是当年周家人穿的那种。”

苏棠心里一沉。她抓起外套就往外跑。

沈家塘边已经围了好几个人，交头接耳。井沿的湿痕还在，一圈水渍沿着一块青砖往下淌。布鞋并排摆在井口正南，鞋尖朝着石门的方向，整整齐齐，像有人夜里脱下来，郑重其事地放好。

苏棠蹲下身，手指触到鞋底。潮的，但不湿透，只有边缘一层水汽。

“他走了。”一个嘶哑的声音从人群外传来。众人回头，槐树下站着佝偻老人。他的背似乎更弯了，手里拄着一根新削的竹杖。晨光里，脸色比昨夜更白，白得发灰。

老人却没看她，只盯着那双布鞋：“他回来了，又走了。”

“谁？”苏棠问。

老人没答。他慢慢走到井边，弯腰拾起一只鞋，翻过来，从鞋底夹层里抽出一片薄薄的油纸。油纸已经泛黄，边角却齐整。老人展开油纸，看了一眼，又合上，递向苏棠。

“他留给你的。”

苏棠接过。油纸里包着一根枯黄的芦苇叶，叶子中央用细针刻着一行小字：“灯座底，三圈半，酉时三刻，西门渡头。”

她猛然抬头：“这话什么意思？”

老人却没有再说。他将鞋放回原处，拄着竹杖转身，一步步朝巷尾走去。晨风掀动他灰白的衣角，像一片随时会被吹散的影子。

苏棠捏着油纸，心口像被什么攥住。她转身跑回棠记，抓起煤油灯，翻过来看灯座底部。黄铜底座下有一圈银白色的焊痕，不仔细看根本发现不了。她用手指按着焊痕边缘，逆时针旋了三圈半——“咔嗒”，底座松了。

里面掉出一卷薄如蝉翼的绵纸。

展开，是一张手绘地图。线条已经褪成淡褐色，但能认出是临水巷的巷道布局。从棠记出发，穿过沈家塘，沿暗渠往东，绕过一个叫“龟背石”的标记，终点落在巷子最南端的碎瓦岗——她以前在那儿捡过碎瓷片的地方。地图背面同样有一行字，笔迹与油纸上的完全不同，遒劲有力，像是男子的手笔：

“她等了我六十年。我不该让她再等了。”

末行小字：“周缙，丙申年冬，留。”

苏棠整个人怔在原地。那行字用的是繁体，但“缙”字最后一横捺得极长，微微上挑，像是写这字的人习惯性地把最后一笔拖远。她见过这个字——外婆手稿最后一页的边角，有一个被水渍洇开的“缙”字，只有半边，笔锋几乎一模一样。

原来外婆等的人叫周缙。原来他一直活着。

她攥紧那张绵纸，呼吸急促，忽然想起油纸上的话——“酉时三刻，西门渡头。”她抬头看天色。日头刚过中天，距离酉时还剩下半天。她没说话，先将绵纸和油纸叠好，放进贴身衣袋，又拿起煤油灯放回柜台。指尖碰到灯座的瞬间，她顿住了。

灯座内侧，贴着焊痕边缘，一个极浅的指纹印。指腹的涡旋清晰可辨，比她的手指小一圈，像是女子留下的。

外婆的指纹。她按这个位置，旋过很多次灯座。

苏棠的心忽然软了一下。她想起幼年时外婆坐在藤椅上擦这个灯座的样子，一遍一遍，从来不腻。当时她以为是爱惜物件。如今才知道，那不是擦拭——是在等。

她正在愣神，顾淮安的声音从铺门口传来：“苏棠。”

她回头。他穿着白大褂，像是从卫生服务中心直接过来的。手里捏着一个透明密封袋，里面装着什么东西。他走近，将密封袋放在柜台上，里面是一截黄铜色的细链，链头挂着个拇指盖大小的铜铃铛，铃身刻着一朵木棉花。

“拆迁队在沈家塘东侧挖排水沟时，从泥土里翻出来的。”他说，“沾着青苔和淤泥，但铃铛里的石子还在，摇起来能响。我认得这朵花。”

苏棠拿起密封袋。铃铛很轻，摇晃时发出闷闷的“嗒”一声——里面确实有东西。

她把铃铛贴在耳边晃了一下，第二声时，她猛然怔住。那声音不是石子磕在铜壁上的响，像是一截细细的金属管在里头翻转，带着一种奇异的空荡回声。而且，这铃铛的花纹和煤油灯座底部的焊痕边缘几乎一模一样，同一种錾刻手法，同一种角度。

“铜铃里有东西。”她说，“得撬开。”

顾淮安看了她一眼，没说话，从口袋里掏出一把医用镊子和一把细头钳。他打开密封袋，将铃铛固定在自己掌心，用镊子尖端沿着铃身接缝轻轻一挑——“咔”。铃身裂开一条缝，里面滚出一样东西。

不是石子。是一枚折叠得极小的银片，展开后约莫拇指大小，表面刻着一行极细的字：

“灯灭之日，来沈家塘。周缙叩首。”

苏棠的脸一下子白了。她看看银片，又看看手心的煤油灯，再抬头望向窗外。天色开始发灰。她不知道墙上的时钟已经指向未时三刻——离酉时，还有大约一个时辰。

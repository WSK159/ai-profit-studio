# 第541章 井底的碗

苏棠一夜没睡踏实。木坠被她放在枕下，翻来覆去，总梦见一扇半开的石门，门缝里伸出一只手，递出一只碗，碗里的糖水黑得像墨。她想接，手却怎么也够不着。那只手的指节修长，骨节分明，指甲修得齐整，像是握笔的人的手。

天亮时她被巷口的鸡鸣吵醒，枕下那枚木坠硌着耳廓，冰凉一片。她坐起来，木坠还系着昨夜的红绳，绳头松了半个结，像是有什么东西牵着它往某个方向使力。

她穿好衣服，把木坠挂在颈上，坠子贴着锁骨，凉得她打了个激灵。灶间里陈阿婆已经熬好了一锅米粥，见她进来，只拿眼角扫了她一下：“醒了？睡得不好？”

“做了个梦。”苏棠端起粥碗，热汽扑在脸上，她顿了顿，“梦见一只递碗的手。”

陈阿婆没接话，只是将手里洗着的一把菜放下，慢慢将手在围裙上擦干。过了好一阵，她说：“今天巷口有人来问铺子的事了。”

苏棠端着碗的动作停住：“什么人？”

“穿灰西装，戴金丝眼镜，手里拿了个文件夹。”陈阿婆的目光落在窗外，“一看就是城里来的。他问棠记最近有没有开张，有没有出让的打算。我说没有，他留了张名片走了。”

苏棠放下粥碗，走到灶间门口。清晨的巷子还没完全醒，薄雾浮在石板路面上，远处巷口一株歪脖子槐树的影子拉得长长的。她看见那棵树下停着一辆黑色的车，车窗深色，看不清里面坐着的人。

她折回灶间，陈阿婆已经从口袋里摸出一张名片递给她。名片极素，白底黑字，没有头衔，只印着一个名字——

周明远。

底下是一行小字：糖记食品有限公司。

苏棠捏着那张名片，指腹压过“周”字的凹印。糖记。她想起外婆手稿里那半张票据上的字迹——票据的落款，也带一个“周”字，她当时没有细想，此刻却觉得那两个字像是井底的水面被人搅动了一下，起了圈细微的涟漪。

“阿婆，”她将名片收起来，“周明远……您认识吗？”

陈阿婆的背影顿了一下，随即继续揉面，声音平得没有起伏：“不认识。听说过，城里头开连锁甜水铺的。”她又揉了两下，回过头，“他要是再来，你别跟他多说话。他问什么，你都说不知道就行。”

“为什么？”

陈阿婆的目光越过她的肩头，落在院子那口井上。井盖压得严严实实，铜环隐在青苔底下，像一只闭上的眼睛。

“你外婆当年从门里回来以后，第一个找上门来的，就是一个姓周的。”

苏棠的呼吸滞了一瞬。她刚要追问，门外响起脚步声，不多时，李叔的身影出现在院门口，肩上扛着一把铁锹，锹头沾着半干的泥，像是从哪里挖过什么东西。他看见苏棠，脚步顿了一下，目光掠过她颈间露出的一截红绳，眉头一皱。

“昨夜里下了井了？”

“下了。”

李叔没说话，低头去井边用锹头拨了拨井沿的青苔。过了好半晌，他直起身：“底下的事，少跟人说。”他停了一下，又补了一句，“尤其是来了城里的人。”

苏棠盯着他的背影，李叔已经往巷外走了，脚步拖沓，像是一条知道太多但不愿开口的老狗。她收回视线，转身回到灶间，把那张名片塞进抽屉最深处，然后蹲下来，从灶台下摸出那盏熄了的铜灯——灯身还残留着一丝井底的潮气，她拨开灯芯，发现铜灯的内壁上，不知什么时候多了几道浅浅的刻痕。

那是几笔图样：一口井，一扇门，一个人端着一只碗，走过去。

刻痕极浅极轻，像是用指甲刮出来的。末尾那个人影的背上，画着一道细细的线。线连着井口，一直延伸到灯底。

苏棠翻过铜灯，底部有一圈暗色的环——像是被什么液体常年浸泡过。她凑近了闻，那股气味淡得几乎不可辨，却和她昨夜在井底那碗干涸糖水的气味一模一样。

陈阿婆揉面的手不知何时停了。她站在灶台后面，隔着案板，远远望着苏棠手里的铜灯，声音很低：“那盏灯……你外婆下井的时候，也用的它。”

苏棠抬头：“您去过？”

陈阿婆没有答话，目光落在那灯壁的刻痕上，良久，她说了一句话：

“苏丫头，你外婆当年进门的时候，灯壁上刻的是四道痕。你昨天下去，你数数——现在有几道了？”

苏棠翻过铜灯，就着透进灶间的晨光，一寸一寸地数。那些浅浅的刻痕在灯壁上排成整齐的一列，她仔细辨认，心口猛地一沉。

五道。

多了一道新的，指甲刮出的痕迹，还微微带潮。

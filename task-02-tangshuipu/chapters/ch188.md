# 第188章 药柜第三格

暮色漫过临水巷的时候，苏棠终于站在了"江南药局"的旧址前。

说是旧址，其实只剩下半堵颓墙和一堆碎瓦。墙面上还残留着褪色的对联，上联"妙手回春"还能辨认，下联已经被爬山虎吃掉了大半。苏棠站在墙根下，低头看着手里的铜钥匙，指尖微微发颤。

外婆留给她的东西，指引她从井底到祠堂，从祠堂到这里。每一步都像是精心布下的棋局，而她只是一枚被推着走的棋子。

她蹲下来，把碎瓦拨开。药柜比她预想的要完整——虽然柜门已经脱落，漆面龟裂如蛛网，但木骨尚在。第一排药柜，第三格。她数清楚了，将铜钥匙插进锁孔。

锁芯已经锈死，钥匙转了两圈，发出尖涩的"嘎吱"声。一声闷响，抽屉弹开来。

里面只有一样东西：一只白瓷罐，罐口用油纸封着，系着麻绳。苏棠把它捧出来，罐身冰凉，掂在手里有些分量。她揭开油纸，一股酸涩的甜香扑鼻而来——是话梅的味道，混着一点陈皮、一点甘草，还有一丝她怎么也想不起来的药香。

罐里盛着黑褐色的膏状物，稠稠的，像熬了很久的浓缩糖浆。罐底垫着一层油纸，纸上用毛笔写着几行字，墨迹已经泛黄：

"酸梅膏一罐，临水巷老井水熬，收四十九担梅子得此一罐。吾妻秋棠，若见此物，当知吾心。梅子酸，人情更酸。吾负你半生，此膏代偿——周怀山。辛巳年冬。"

苏棠的手指停在纸的最后一角，那里还压着一道细痕，像是被人反复抚摸过。

"周怀山……"她把名字念出声来，觉得舌尖微微发麻。外婆手稿里从未提过这个名字，但那些字条、铜牌、半张票据，处处都有他的影子——他是外婆的丈夫？还是那个让她"隐姓埋名"等待的人？

她把油纸原样包好，将瓷罐小心放入背囊之中。可就在她起身的瞬间，脚边的一根枯枝发出断裂声。

不是她踩的。

苏棠猛地转身，那半堵残墙的阴影里站着一个人影。暮色压得低，对方穿了一件灰色夹克，戴着口罩，看不清五官，但从身形来看，是个男人。

巷口的风忽然紧了，吹起一地碎叶。

"你是什么人？"苏棠尽量稳住声音，手却悄悄攥紧了背囊的带子。

那人没答话，往前走了两步。他脚下踩过一片积水，水花溅开，折射着最后的天光——苏棠突然注意到，他的鞋底沾着一层褐黄色的泥。那种泥，她在井底也见过。暗河冲上来的沉积土，带着特有的铁锈味儿。

是追她到井底的那个人。

"把东西放下。"那人开口了，声音沙哑低沉，像被砂纸打磨过，"你拿不走它。"

"这药膏是周怀山留给我外婆的，跟你有什么关系？"

男人的瞳孔微微收缩，像是在苏棠口中听到那个名字让他有些意外。他沉默了片刻，忽然拉下口罩——一张四十出头的脸，颧骨高耸，眼角有一道旧疤，下巴微扬的弧度带着某种说不清道不明的熟悉感。

"他是我父亲。"

那道疤落在左眼角，像一枚旧印章。苏棠忽然想起外婆手稿里夹着的那张老照片——照片上风华正茂的男人，眉心间也有类似的一道浅痕。

父子。

"周怀山已经死了。"男人补充道，声音里没有悲伤，只有陈述的平静，"他死前让我来找这道配方。可他的女儿——就是你外婆——把消息瞒了一辈子。我找了十五年。"

他看着苏棠背囊的方向，"那罐酸梅膏，是我父亲的遗物。它该回到我手上。"

苏棠攥紧背囊，后退一步，脊背抵住了残墙。

"可你父亲把它留给我外婆。"她说，"梅子酸，人情更酸——他是来道歉的，不是来索债的。"

男人盯着她看了很久，久到巷口的路灯咔哒一声亮了。橘黄的光落在他脸上，那道旧疤被光照亮，像一枚烙进年轮里的记号。

"你知道那罐酸梅膏里泡着什么吗？"他忽然问。

苏棠没答话。

"除了梅子和甘草，"他顿了顿，"还有一味药引——归魂锅的锅底灰。"

风忽然安静了。

归魂锅。外婆的炉灶下埋着的那口铁锅，那口据说被追了半辈子的锅，那口下落成谜的锅。苏棠脑海里的线头终于连成了一串：外婆让她去井底，再从祠堂找到这里，每一步都是绕开那些追锅的人，把最后的线索藏进连敌人都想不到的地方。

"你爸把锅底灰泡进酸梅膏里？"

"他怕它被人夺走，"周怀山的儿子说，"于是把它熬成了一罐谁也看不透的糖水。他让我来取，说这是他对你外婆的最后一笔债。"

他伸出手："给我，我立刻走。你继续开你的糖水铺，我不会再来。"

苏棠半晌未动。巷口的灯火在风里晃了晃，她低头看自己掌心的铜钥匙，又看看那个男人的眼睛——一个等了十五年的人，眼里的执拗像熬久了的糖浆，黏稠不散。

她解开背囊，把瓷罐取出来，却没有递过去。

"你告诉我，"她说，"我外婆到底还在不在世上？"

男人微微一怔。那表情苏棠看得很清楚——不是惊讶，不是回避，而是一种被戳到旧伤口的下意识僵滞。

他还没来得及回答，身后忽然传来一声清亮的呼喊——

"苏棠姐！"

苏棠一偏头，巷口路灯下站着一个穿校服的半大孩子，是巷尾阿婆的孙子小满，手里举着手机，屏幕亮着："顾医生找你有急事，说铺子的炉灶下面——又挖出东西了！"

灰夹克男人趁她分神，猛地出手，指尖擦过瓷罐边缘。苏棠一个侧身，护住背囊，他扑了个空。

他站稳后，看了她一眼，忽然从口袋里掏出一枚东西，丢在她脚边——是一枚半旧的铜扣，上面刻着一个"棠"字。

"等你见到你外婆，"他说，"把这个给她看。"

他转身走入巷子的阴影里，脚步很快，像一缕散入夜色的烟。

苏棠弯腰捡起那枚铜扣，指腹摩挲着"棠"字刻痕。它的边缘已经磨亮了，像是被人贴身带了很多年。

她攥紧铜扣，转身朝铺子方向跑起来。脑底只有一个念头：顾淮安的微颤声音，和小满说的"又挖出东西了"，在黑暗里连成了一条她看不清尽头的线。

# 第486章 桂花树下的暗哨

清晨的临水巷笼着一层薄雾，苏棠推开棠记的木板门时，檐角滴下隔夜的露水，在青石板上砸出细碎的声响。

她还没来得及把炉子生起来，便听见巷口传来一阵窸窣的动静。探头一看，两个穿灰蓝色工装的男人正蹲在桂花树下，手里拿着卷尺和本子，对着那棵枯了半边的老树比比画画。

苏棠心里咯噔一下。她放下手里的铜壶，快步走过去。

“师傅，这是做什么？”

其中一个年轻些的抬头看她，笑了笑：“您是这巷子里的住户吧？我们是市园林局的，接到市民反映，说这棵桂花树树根有松动迹象，担心台风天倒伏，来做个评估。”

“松动？”苏棠蹲下身，果然看见树根处的泥土有一圈新翻的痕迹，边缘整齐，像是被人用工具撬开过又回填的。她伸手摸了一下土面，手指触到一粒硬物，拨开一看，是一截没烧完的纸烟头，烟嘴上还印着半个模糊的字。

“这土是这两天翻过的。”她说。

两个工装男人对视一眼，年轻的那个搓了搓手：“我们昨天下午来初勘过，可能是那时候留下的。”

苏棠没接话，把烟头捏在指间，起身道：“这棵树是我外婆家的，要动它的话，是不是得跟我这个家属打声招呼？”

年长些的男人打着哈哈：“当然当然，今天只是量尺寸，出报告之前肯定要跟您沟通的。”说着招呼年轻同伴收好卷尺，快步走了。

苏棠目送他们拐出巷口，低头又看那烟头。烟蒂上的半截字被烧得卷曲，但她还是认出了轮廓——那是一个“周”字的右半边。她将烟头收进围裙口袋，转身回了铺子。

傍晚，桂花树的花苞明显胀大了，米粒样的青灰花苞挤在枝头，有几颗已经裂开一条缝，露出里头白里透黄的瓣尖。苏棠蹲在树根边，用早上捡的烟头在泥地上轻轻画了个圈。

顾淮安是天黑以后来的。他走进棠记时，手里多了一卷泛黄的复印纸，额角还挂着细汗。

“市档案馆那边，我托了人查那批借调档案的登记目录。”他把纸卷摊在灶台上，苏棠凑过去看，上面是一份复印件，表格里的借调单位写得清清楚楚——临水民间文化研究会，借调人签名处是一个工整的“周”字。“借调日期是半年前，一共两箱，编号甲字头到丙字头。”

“丙字头？”苏棠脑子里转了一下，“今天我听那两个人说，桂花树根有松动，可能是台风影响。但他们说昨天下午初勘过——你不觉得奇怪吗，量一棵树的评估，犯得着两个人一起？”

“你是说，他们不是园林局的？”

苏棠没直接回答，把手伸进口袋，把那截烟头放在桌上：“你看这个字。”

顾淮安捏起烟头端详片刻，瞳孔微缩：“周？”

“我查过，周明远手底下‘糖记’那几个连锁店的采购，有个叫周宏的，抽的就是这种带字烟的牌子。乡下小厂出的，只有他们那边才买得到。”苏棠说完，见顾淮安眉间拧得更深，又补了一句，“当然，也可能是巧合。”

“今天早上去的人，量的是桂花树。”顾淮安声音低沉，“如果真是周明远的人，他们量一棵枯树做什么？”

两人沉默了片刻，灶上那锅红豆正咕嘟咕嘟翻着泡，白雾袅袅升腾。

“明天就是三天约定期限了。”苏棠把火拢小，“树要是没开呢？”

顾淮安低头看着桌上那截烟头，指腹在焦黄的纸面上按了按：“那就不是花没开的问题，是有人不想让它开。”

苏棠怔了怔，顺着他的话想下去——若是有人不想让桂花如期开放，那便是不想让灰衣老者收到那碗姜撞奶。而知道这个约定的人……除了她和顾淮安，还有谁？

她心里一沉。那日灰衣老者在窄巷与她对话时，隔着一扇窗，窗口正对着巷口的方向——会不会，早有一双眼睛，看得清清楚楚？

晚上打烊后，苏棠没有急着上楼。她从灶膛里撮了一把冷灰，用一个粗瓷碗装着，走到桂花树下，沿着树根撒了一圈。灰白的粉末在夜色里泛着微微的光，贴着泥土铺展开来。

她蹲下来，用手掌把粉末抹匀，末了拍拍手上沾的灰，对着枯树轻声说：“外婆，您要是真在这树底下听着呢，明天一早，给我留个准信。”

夜风穿过巷口，树叶沙沙响了几声，像是有谁在远处应了一句。

苏棠直起身，往回走时，余光扫过巷口对面那排旧屋的屋檐，第二间窗后，似乎有一道更深的黑影晃动了一下。她脚步一顿，再细看时，黑影已经融进夜色里，只剩一盏没亮的路灯，孤零零地立在墙根。

她攥紧口袋里那截烟头，推门进了铺子。
